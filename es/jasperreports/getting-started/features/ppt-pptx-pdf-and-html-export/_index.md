{{% alert color="info" %}} 

JasperReports y JasperServer no disponen de capacidades incorporadas para exportar informes como presentaciones de Microsoft PowerPoint, pero con Aspose.Slides for JasperReports obtienes acceso a formatos de exportación adicionales:

- Presentación de Microsoft PowerPoint (PPT)
- Presentación de Microsoft PowerPoint (PPTX)
- HTML
- PDF

{{% /alert %}} 

Para crear documentos en estos formatos, Aspose.Slides for JasperReports se basa en una versión incorporada de [Aspose.Slides for Java](https://products.aspose.com/slides/es/java/), la biblioteca líder del mercado para el procesamiento de presentaciones de Aspose. Microsoft PowerPoint no se utiliza para generar los documentos.
