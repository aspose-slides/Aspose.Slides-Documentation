## **JasperReports**

Aspose.Slides for JasperReports funciona con JasperReports 3.7.2 a 6.16.0. La descarga incluye un jar independiente para cada uno de los tres rangos de versiones — vea [Instalando Aspose.Slides para JasperReports](/slides/es/jasperreports/installing-aspose-slides-for-jasperreports/) para saber cuál usar. No hay jar para JasperReports 6.17.0 o posterior, incluido JasperReports 7.

El soporte para JasperReports 2.0.3 a 3.7.1 finalizó en Aspose.Slides for JasperReports 17.6. Las versiones 17.5 y anteriores también admitían esas versiones.

## **Java**

Los jars están compilados para Java 6 o superior, como indica *JDK 1.6* en sus nombres de carpeta, por lo que la versión de Java que necesita es la que requiere su versión de JasperReports. Con JasperReports 6.16.0, las exportaciones se ejecutan con Java 11, 17, 21 y 25.

## **Operating system**

Los jars contienen solo clases y recursos Java, sin bibliotecas nativas, y no utilizan Microsoft PowerPoint. En Linux, JasperReports necesita fontconfig y al menos una fuente instalada para rellenar un informe.

## **JasperReports Server**

Para JasperReports Server, utilice ambos jars de la carpeta que coincida con la versión de JasperReports que ejecuta su servidor — vea [Integración con JasperServer](/slides/es/jasperreports/integration-with-jasperserver/).
