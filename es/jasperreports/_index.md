**Bienvenido a Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports es una biblioteca diseñada y desarrollada especialmente para desarrolladores que necesitan exportar fácilmente informes de JasperReports a formatos Microsoft PowerPoint Presentation (PPT) y Microsoft PowerPoint Show (PPS) en sus aplicaciones Java. Todas las funciones del informe se convierten con el máximo grado de precisión a presentaciones Microsoft PowerPoint. Aspose.Slides for JasperReports incluye soporte para JasperReports 5+.
