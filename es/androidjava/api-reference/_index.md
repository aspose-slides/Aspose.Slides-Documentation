{{% alert color="info" %}} 

Aspose.Slides for Android via Java es una biblioteca de clases que permite a las aplicaciones Java para Android leer y escribir documentos de presentación sin utilizar Microsoft PowerPoint® u otro software. Aspose.Slides for Android via Java le permite gestionar texto, formas, tablas y animaciones; añadir audio y vídeo a las diapositivas; previsualizar diapositivas; y exportar diapositivas a SVG, formato PDF y más.

La referencia más reciente de la API se puede encontrar en [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/es/androidjava/).
