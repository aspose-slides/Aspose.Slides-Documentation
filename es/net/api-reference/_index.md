{{% alert color="info" %}} 

Aspose.Slides for .NET es una biblioteca de clases que permite a las aplicaciones .NET leer y escribir documentos de presentación sin usar Microsoft PowerPoint® u otros. Aspose.Slides for .NET permite gestionar texto, formas, tablas y animaciones, añadir audio y vídeo a las diapositivas, previsualizar diapositivas, exportar diapositivas a formato SVG, PDF y más.

La referencia de la API más reciente se puede encontrar en [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/es/net).
