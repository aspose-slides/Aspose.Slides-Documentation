**Bienvenido a Aspose.Slides para Node.js a través de Java**

![Aspose.Slides for Node.js via Java Product Logo](aspose_slides-for-nodejs-via-java.png)

Aspose.Slides para Node.js a través de Java es una biblioteca de clases que permite a sus aplicaciones leer y escribir documentos PowerPoint® sin usar Microsoft PowerPoint®.

Aspose.Slides para Node.js a través de Java es el primer y único componente que brinda la funcionalidad para gestionar documentos PowerPoint®.

Aspose.Slides para Node.js a través de Java ofrece muchas características clave, como la gestión de texto, formas, tablas & animaciones, la incorporación de audio y vídeo a las diapositivas, la vista previa de diapositivas, la exportación de diapositivas a formato SVG, PDF y más.
