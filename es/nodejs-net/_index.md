**Bienvenido a Aspose.Slides for Node.js via .NET**

![Aspose.Slides for Node.js via .NET Product Logo](aspose_slides-for-nodejs-via-net.png)

Aspose.Slides for Node.js via .NET es una biblioteca de clases que permite a sus aplicaciones leer y escribir documentos PowerPoint® sin utilizar Microsoft PowerPoint®.

Aspose.Slides for Node.js via .NET es el primer y único componente que ofrece la funcionalidad para gestionar documentos PowerPoint®.

Aspose.Slides for Node.js via .NET proporciona muchas características clave, como la gestión de texto, formas, tablas y animaciones, la incorporación de audio y vídeo a las diapositivas, la vista previa de diapositivas, la exportación de diapositivas a formato SVG, PDF y mucho más.
