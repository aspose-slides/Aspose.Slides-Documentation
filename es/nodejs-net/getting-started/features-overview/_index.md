## **Plataformas compatibles**
Aspose.Slides for Node.js via .NET es una API independiente de la plataforma. Puede usarse en cualquier plataforma (Windows, Linux, macOS, etc.) donde Node.js 7 o superior esté instalado. Oracle JDK 8 o superior es otro requisito.

## **Formatos de archivo y conversiones**
Aspose.Slides for Node.js via .NET admite la mayoría de los formatos de documentos PowerPoint. También le permite exportarlos a los formatos de archivo populares que las organizaciones utilizan y comparten entre sí. Revise estos detalles:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET ofrece el procesamiento más rápido para este formato de documento de presentación.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET admite la conversión de PPT a PPTX|
|Portable Document Format (PDF)|Puede exportar todos los formatos de archivo compatibles a documentos Adobe Portable Document Format (PDF) con un solo método.|
|XML Parser Specification (XPS)|Puede exportar todos los formatos de archivo compatibles a documentos XML Parser Specification (XPS) con un solo método.|
|Tagged Image File Format (TIFF)|Puede exportar todos los formatos de archivo de presentación compatibles a Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET admite la conversión de PresentationEx a formato HTML.|

## **Renderizado de presentaciones**
Aspose.Slides for Node.js via .NET admite el renderizado de alta fidelidad de diapositivas en presentaciones a diferentes formatos gráficos. Revise estos detalles:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|.NET Supported Image Formats|Con Aspose.Slides for Node.js via .NET, puede renderizar diapositivas de presentación e imágenes en diapositivas a todos los formatos gráficos compatibles con .NET, como TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via .NET también proporciona métodos incorporados que le permiten exportar diapositivas de presentación a formatos Scalable Vector Graphics (SVG).|

## **Características del contenido**
Aspose.Slides for Node.js via .NET le permite acceder, modificar o crear casi todos los elementos o contenidos de los documentos de presentación. Revise estos detalles:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Master Slides|Las diapositivas maestras definen el diseño de las diapositivas normales. Aspose.Slides for Node.js via .NET le permite acceder y modificar las diapositivas maestras de los documentos de presentación|
|Normal Slides|Con Aspose.Slides for Node.js via .NET, puede crear nuevas diapositivas de diferentes tipos; también puede acceder y modificar diapositivas existentes en las presentaciones|
|Cloning / Copying Slides|Hay métodos incorporados proporcionados por Aspose.Slides for Node.js via .NET que permiten clonar o copiar diapositivas existentes dentro de una presentación. También puede usar diapositivas copiadas y clonadas de una presentación a otra. Dado que una diapositiva hereda su diseño de la diapositiva maestra, los métodos de clonación incorporados copian automáticamente la maestra al clonar|
|Managing Slides sections|Métodos para organizar diapositivas en diferentes secciones dentro de una presentación|
|Place Holders and Text Holders|Puede acceder a los marcadores de posición y marcadores de texto en una diapositiva. Además, puede crear una diapositiva con marcadores de texto desde cero usando el método apropiado|
|Header and Footers|Aspose.Slides for Node.js via .NET facilita la gestión de encabezados/pies de página en las diapositivas|
|Notes in Slides|Con Aspose.Slides for Node.js via .NET, puede acceder y modificar notas asociadas a una diapositiva y también agregar nuevas notas|
|Finding a Shape|También puede encontrar una forma concreta en una diapositiva usando el texto alternativo asociado a la forma|
|Backgrounds|Aspose.Slides for Node.js via .NET le permite trabajar con fondos asociados a una diapositiva maestra o normal en una presentación|
|Text Boxes|Los cuadros de texto pueden crearse desde cero. Puede acceder a cuadros de texto existentes. También puede modificar sus textos sin perder el formato original|
|Rectangle Shapes|Puede crear o modificar formas rectangulares con Aspose.Slides for Node.js via .NET|
|Poly Line Shapes|Puede crear o modificar formas de polilínea con Aspose.Slides for Node.js via .NET|
|Ellipse Shapes|Puede crear o modificar formas elípticas con Aspose.Slides for Node.js via .NET|
|Group Shapes|Aspose.Slides for Node.js via .NET admite formas agrupadas|
|Auto Shapes|Aspose.Slides for Node.js via .NET admite formas automáticas|
|SmartArt|Aspose.Slides for Node.js via .NET proporciona soporte para formas SmartArt en MS PowerPoint|
|Charts|Aspose.Slides for Node.js via .NET proporciona soporte para Gráficos MSO en PowerPoint|
|Shapes Serialization|Aspose.Slides for Node.js via .NET admite una gran cantidad de formas. Cuando Aspose.Slides for Node.js via .NET no tiene soporte para una forma, puede usar un método de serialización mediante el cual puede serializar esa forma a partir de una diapositiva existente. De esta manera, puede reutilizar la forma según sus requisitos|
|Picture Frames|Puede gestionar imágenes en marcos de imagen con Aspose.Slides for Node.js via .NET|
|Audio Frames|Puede enlazar o incrustar archivos de audio en marcos de audio en las diapositivas con Aspose.Slides for Node.js via .NET|
|Video Frames|Puede manejar archivos de video en marcos de video. Aspose.Slides for Node.js via .NET también proporciona soporte para videos vinculados e incrustados|
|OLE Frame|Puede gestionar objetos OLE en marcos OLE con Aspose.Slides for Node.js via .NET|
|Tables|Aspose.Slides for Node.js via .NET admite tablas en diapositivas|
|ActiveX Controls|Soporte para controles ActiveX|
|VBA Macros|Soporte para gestionar macros VBA dentro de presentaciones.|
|Text Frame|Puede acceder al texto de cualquier forma a través del marco de texto asociado a esa forma|
|Text Scanning|Puede escanear texto en una presentación a nivel de presentación o diapositiva mediante métodos de escaneo incorporados.|
|Animations|Puede aplicar animaciones a las formas|
|Slide Shows|Aspose.Slides for Node.js via .NET admite presentaciones de diapositivas y transiciones de diapositivas|

## **Características de formato**
Con Aspose.Slides for Node.js via .NET, puede formatear textos y formas en diapositivas de presentaciones. Revise estos detalles:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Text Formatting|<p>En Aspose.Slides for Node.js via .NET, puede gestionar textos a través de los marcos de texto asociados a las formas. Por lo tanto, puede formatear textos usando los párrafos y fragmentos asociados a los marcos de texto. Estos elementos de texto pueden formatearse mediante Aspose.Slides for Node.js via .NET.</p><p>- Tipo de fuente</p><p>- Tamaño de fuente</p><p>- Color de fuente</p><p>- Sombras de fuente</p><p>- Alineación de párrafo</p><p>- Viñetas de párrafo</p><p>- Orientación de párrafo</p>|
|Shape Formatting|<p>En Aspose.Slides for Node.js via .NET, el elemento básico de una diapositiva es una forma. Puede formatear estos elementos de forma con Aspose.Slides for Node.js via .NET:</p><p>- Posición</p><p>- Tamaño</p><p>- Línea</p><p>- Relleno (incluyendo Patrón, Degradado, Sólido)</p><p>- Texto</p><p>- Imagen</p>|
