{{% alert color="info" %}}

Aspose.Slides for Java es una biblioteca de clases que permite a las aplicaciones Java leer y escribir documentos de presentación sin utilizar Microsoft PowerPoint® u otros. Aspose.Slides for Java permite gestionar texto, formas, tablas y animaciones, añadir audio y vídeo a las diapositivas, previsualizar diapositivas, exportar diapositivas a formato SVG, PDF y más.

La última referencia de la API se puede encontrar en [Aspose.Slides for Java API Reference](https://reference.aspose.com/slides/es/java).
