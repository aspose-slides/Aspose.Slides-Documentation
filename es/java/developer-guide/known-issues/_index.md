## **Resumen**

Esta sección no contiene una lista de problemas abiertos en la versión actual. Contiene tres páginas:

- [Object Preview Placeholder When Adding OleObjectFrame](/slides/es/java/object-preview-issue-when-adding-oleobjectframe/) explica por qué un objeto OLE añadido con Aspose.Slides muestra una imagen "EMBEDDED OLE OBJECT" hasta que se actualiza su vista previa, y cómo establecer su propia imagen de vista previa. Este es un comportamiento previsto en la versión actual.
- [Known Issues in Aspose.Slides for Java 14.3.0 (Historical)](/slides/es/java/known-issues-in-aspose-slides-for-java-14-3-0/) y [Known Issues in Aspose.Slides for Java 14.4.0 (Historical)](/slides/es/java/known-issues-in-aspose-slides-for-java-14-4-0/) son listas publicadas con esas versiones, conservadas como referencia.

Para los cambios y correcciones en cada versión, consulte las [notas de la versión](https://releases.aspose.com/slides/es/java/release-notes/). Los campos de metadatos que Aspose.Slides escribe con valores fijos se describen en [Limitaciones de los metadatos de salida](/slides/es/java/api-limitations/). Para comprobar si un problema ya es conocido, o para informar de uno, utilice el [foro de soporte](https://forum.aspose.com/c/slides/es/11).
