{{% alert color="info" title="Note" %}}

Esta es una página histórica. Enumera los problemas conocidos publicados con Aspose.Slides for Java 14.3.0 y no describe la versión actual. Para los cambios en cada versión, consulte las [release notes](https://releases.aspose.com/slides/es/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) ofrece una implementación completamente nueva del procesamiento de PPT. Hay muchas mejoras, conversión parcial de PPTX a PPT. Pero hay algunas funciones no implementadas:

- Algunas formas tienen geometría incorrecta en documentos PPT serializados (Call outs)
- No todas las funciones de formato de texto de PPTX son compatibles en la serialización a PPT
- La información sobre el idioma del texto y la configuración ortográfica no está presente en los documentos PPT serializados
- No todas las funciones de los temas PPTX son compatibles en la serialización a PPT

**Hay algunas diferencias en comparación con Aspose.Slides for Java 8.6.0:**

- Existen problemas conocidos en la serialización OLE/ActiveX de PPT a PPT

**Hay algunas diferencias en comparación con Aspose.Slides for .NET 14.3.0:**

- El soporte de impresión de presentaciones actualmente no está disponible en Aspose.Slides for Java
