{{% alert color="info" title="Note" %}}

Esta es una página histórica. Enumera las restricciones y los problemas conocidos publicados con Aspose.Slides for Java 14.4.0 y no describe la versión actual. Para los cambios en cada versión, consulte las [notas de la versión](https://releases.aspose.com/slides/es/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.4.0 ofrece una nueva solución para el procesamiento de documentos PowerPoint. Hay algunas restricciones y problemas conocidos, que se eliminarán en próximas versiones:

- Algunas formas tienen geometría incorrecta en los documentos PPT serializados (arco, flecha circular, anotaciones).
- No todas las funciones de formato de texto de PPTX son compatibles en la serialización a PPT (limitaciones de tabulación, sangría y formato de párrafo).
- La información sobre el idioma del texto y la configuración ortográfica no está presente en los documentos PPT serializados.
- No todas las características del tema PPTX son compatibles en la serialización a PPT (solo la serialización de formatos de relleno, formatos de línea y fuentes).
- Existen problemas conocidos en la serialización OLE/ActiveX de PPT a PPT.
- La serialización y renderizado de WordArt no son compatibles.
