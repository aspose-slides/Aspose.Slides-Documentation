Una nueva [Aspose.Slides for Java API](/slides/es/java/) ha sido publicada y ahora este único producto admite la capacidad de generar documentos PowerPoint desde cero y de editar los existentes.

{{% /alert %}} 
## **Compatibilidad con código heredado**
Para utilizar el código heredado desarrollado con versiones de Aspose.Slides for Java anteriores a la 13.x, es necesario realizar algunos cambios menores en su código y éste seguirá funcionando como antes. Todas las clases que estaban presentes en el antiguo Aspose.Slides for Java bajo los espacios de nombres Aspose.Slide y Aspose.Slides.Pptx ahora están combinadas en un único espacio de nombres Aspose.Slides.
