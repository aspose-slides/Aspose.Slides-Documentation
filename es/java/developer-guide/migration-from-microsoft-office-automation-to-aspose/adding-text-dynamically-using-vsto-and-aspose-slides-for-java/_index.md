Una tarea común que los desarrolladores deben llevar a cabo es añadir texto a las diapositivas de forma dinámica. Este artículo muestra ejemplos de código para añadir texto dinámicamente usando [VSTO](/slides/es/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/) y [Aspose.Slides for Java](/slides/es/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/).

## **Agregar texto dinámicamente**
Ambos métodos siguen estos pasos:

1. Crear una presentación.
1. Añadir una diapositiva en blanco.
1. Añadir un cuadro de texto.
1. Establecer algo de texto.
1. Guardar la presentación.
