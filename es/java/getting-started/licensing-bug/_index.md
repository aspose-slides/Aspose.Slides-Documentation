Esta es una página histórica. Describe un error en Aspose.Slides for Java versiones 23.2 a 23.7, que se publicaron en 2023, y las versiones que lo corrigieron. No describe la versión actual. Para la licencia en la versión actual, consulte [Licencias](/slides/es/java/licensing/).

{{% /alert %}}

## **Descripción general**

Este artículo describe un error de licencia encontrado en Aspose.Slides for Java versiones 23.2, 23.3, 23.4, 23.5, 23.6 y 23.7. Este error hacía que las licencias perpetuas quedaran temporalmente inutilizables después de que finalizara su suscripción.

## **Síntomas**

Después de que expire la suscripción de su licencia perpetua, Aspose.Slides for Java versiones 23.2 - 23.7 puede reportar la licencia como expirada, pasando todas las funciones al modo de evaluación.  
Este comportamiento es incorrecto y no afecta a versiones anteriores a 23.2 ni posteriores a 23.7.

## **Resolución**

Aspose.Slides for Java abordó este problema y lanzó versiones actualizadas (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) con la corrección.

Si está utilizando una de las versiones afectadas de Aspose.Slides for Java en su proyecto, cambie a la versión corregida.

## **Productos y versiones afectados**

Tenga en cuenta que este error solo afecta a Aspose.Slides for Java versiones 23.2 a 23.7. **Otros productos de Aspose y otras versiones de Aspose.Slides no se ven afectadas**.
