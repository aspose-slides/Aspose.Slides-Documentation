{{% alert color="info" %}}
La [Especificación del analizador XML](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) es un lenguaje de descripción de páginas y un formato de documento fijo desarrollado originalmente por Microsoft. Al igual que PDF, XPS está diseñado para preservar la fidelidad del documento y proporcionar una apariencia independiente del dispositivo.
{{% /alert %}}
## **XPS en Aspose.Slides para Java**
Cualquier documento de presentación que pueda ser cargado por Aspose.Slides para Java puede convertirse al formato XPS. Aspose.Slides para Java utiliza el motor de maquetación y renderizado de alta fidelidad para generar la salida en formato de documento XPS de diseño fijo.
Puede obtener información sobre la exportación de documentos de presentación a documentos XPS mediante Aspose.Slides para Java en [Convertir a XPS](https://docs.aspose.com/slides/es/java/convert-powerpoint-to-xps/).
