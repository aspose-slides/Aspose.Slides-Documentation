Para los formatos que Aspose.Slides for Java carga, importa, guarda y renderiza, y la API de cada uno, consulte [Supported File Formats](/slides/es/java/supported-file-formats/). {{% /alert %}}

{{% alert color="info" title="Note" %}}

El [XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) es un lenguaje de descripción de páginas y un formato de documento fijo desarrollado originalmente por Microsoft. Al igual que PDF, XPS está diseñado para preservar la fidelidad del documento y proporcionar una apariencia de documento independiente del dispositivo.

{{% /alert %}}

## **XPS en Aspose.Slides for Java**
Cualquier documento de presentación que pueda ser cargado por Aspose.Slides for Java puede convertirse al formato XPS. Aspose.Slides for Java utiliza el motor de diseño y renderizado de alta fidelidad para producir una salida en formato de documento XPS de diseño fijo.
Puede obtener información sobre la exportación de documentos de presentación a documentos XPS a través de Aspose.Slides for Java en [Convert PowerPoint Presentations to XPS](/slides/es/java/convert-powerpoint-to-xps/).
