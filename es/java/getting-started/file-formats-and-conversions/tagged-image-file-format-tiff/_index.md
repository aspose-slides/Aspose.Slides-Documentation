## **Acerca de TIFF**

El [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) , conocido por almacenar múltiples imágenes en un solo documento, fue creado originalmente por Aldus. Este formato es ampliamente compatible con escáneres, fax y otras aplicaciones de manipulación de imágenes.

## **TIFF en Aspose.Slides for Java**

Cualquier documento que pueda cargarse en Aspose.Slides for Java también puede convertirse directamente a documento TIFF mediante Aspose.Slides for Java, eliminando la necesidad de cualquier componente de terceros. Además, puede definir opcionalmente el tamaño de las imágenes en el documento TIFF resultante. Puede encontrar información sobre cómo exportar los documentos de presentación a documentos TIFF a través de Aspose.Slides for Java en [Convertir presentaciones de PowerPoint a TIFF](/slides/es/java/convert-powerpoint-to-tiff/).
