{{% alert color="info" %}} 

La conversión de PPT a PPTX es compatible con Aspose.Slides for Java. La mayoría de las características de la presentación - diapositivas maestras, estructura, etc. - se conservan al convertir de un formato a otro, pero existen [algunas limitaciones](/slides/es/java/ppt-to-pptx-conversion/).

{{% /alert %}} 
## **Características admitidas en la conversión**
Aspose.Slides for Java ofrece soporte parcial para convertir el formato de archivo PPT a PPTX. El soporte para la conversión se ha introducido recientemente en Aspose.Slides for Java, por lo que tiene algunas limitaciones y funciona mejor con presentaciones simples. La principal ventaja que Aspose.Slides for Java proporciona al convertir PPT a PPTX es lo fácil que es usar la API. Para ver ejemplos del código, consulte [Convertir PPT a PPTX](). A continuación, las listas explican qué características son compatibles y cuáles no lo son para la conversión de PPT a PPTX.

## **Características compatibles**
The following features are supported for conversion:

- Conversión de la estructura de maestros, diseños y diapositivas.
- Conversión de gráficos.
- Formas agrupadas.
- Conversión de autoshapes, incluidos rectángulos y elipses. 
- Formas con geometría personalizada.
- Texturas y estilos de relleno de imágenes para autoshapes.
- Conversión de marcadores de posición.
- Conversión de líneas y polilíneas.
- Formatos de línea y relleno.
- Estilos de relleno degradado.
- Marcos OLE, tablas, marcos de vídeo y audio, etc.
- Propiedades de animación y presentación.
- Conversión de texto en cuadros de texto y contenedores de texto.
