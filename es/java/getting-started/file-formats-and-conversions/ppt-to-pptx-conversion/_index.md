La conversión de PPT a PPTX está soportada por Aspose.Slides for Java. La mayoría de las características de la presentación —maestros, estructura, etc.— se conservan al convertir de un formato a otro, aunque existen algunas limitaciones.
{{% /alert %}}

## **Características compatibles en la conversión**
Aspose.Slides for Java ofrece soporte parcial para convertir el formato de archivo PPT a PPTX. El soporte de conversión se ha introducido recientemente en Aspose.Slides for Java, por lo que presenta algunas limitaciones y funciona mejor con presentaciones simples. La principal ventaja que Aspose.Slides for Java proporciona al convertir PPT a PPTX es la facilidad de uso de la API. Para ver ejemplos de código, consulte [Convertir PPT a PPTX](/slides/es/java/convert-ppt-to-pptx/). ## **Características admitidas**
Las siguientes características son compatibles para la conversión:

- Conversión de la estructura de maestros, diseños y diapositivas.
- Conversión de gráficos.
- Formas agrupadas.
- Conversión de autoshapes, incluidos rectángulos y elipses.
- Formas con geometría personalizada.
- Estilos de relleno de texturas e imágenes para autoshapes.
- Conversión de marcadores de posición.
- Conversión de líneas y polilíneas.
- Formatos de línea y relleno.
- Estilos de relleno degradado.
- Marcos OLE, tablas, marcos de vídeo y audio, etc.
- Propiedades de animación y presentación.
- Conversión de texto en marcos de texto y contenedores de texto.
