{{% alert color="info" %}} 

Aspose.Slides for C++ es una biblioteca de clases que permite a las aplicaciones C++ leer y escribir documentos de presentación sin utilizar Microsoft PowerPoint® u otros. Aspose.Slides for C++ permite gestionar texto, formas, tablas y animaciones, añadir audio y vídeo a las diapositivas, previsualizar diapositivas, exportar diapositivas a formato SVG, PDF y más.

La última referencia de API se puede encontrar en [Aspose.Slides for C++ API Reference](https://reference.aspose.com/slides/es/cpp/).
