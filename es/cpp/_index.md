**Bienvenido a Aspose.Slides for C++**

Aspose.Slides for C++ es una API de gestión de Microsoft PowerPoint® que permite a las aplicaciones C++ leer y escribir documentos PowerPoint® sin usar Microsoft PowerPoint®. Aspose.Slides for C++ es el primer y único componente que ofrece la funcionalidad para gestionar documentos PowerPoint®. Aspose.Slides for C++ ofrece muchas características clave, como la gestión de texto, formas, tablas & animaciones, la incorporación de audio y vídeo a las diapositivas, la previsualización de diapositivas, la exportación de diapositivas a formato SVG, PDF y más.
