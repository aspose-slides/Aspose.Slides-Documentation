{{% alert color="info" %}} 

Todos los componentes Aspose C++ requieren el conjunto de permisos Full Trust. La razón es que los componentes Aspose C++ necesitan acceder a la configuración del registro, a archivos del sistema además del directorio virtual para ciertas operaciones como analizar fuentes, etc. Además, los componentes Aspose C++ se basan en clases centrales del sistema C++ que también requieren el conjunto de permisos Full Trust en muchos casos. 

{{% /alert %}}
