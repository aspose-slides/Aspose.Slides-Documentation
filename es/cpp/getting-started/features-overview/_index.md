## **Formatos de archivo y conversiones**
Aspose.Slides for C++ admite la mayoría de los formatos de documentos PowerPoint y también los exporta a formatos populares ampliamente utilizados para el intercambio entre organizaciones. La tabla siguiente enumera estos formatos:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/es/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ proporciona el procesamiento más rápido para este formato de documento de presentación.|
|[Portable Document Format (PDF)](/slides/es/cpp/portable-document-format-pdf/)|Los formatos de archivo compatibles pueden exportarse a documentos Adobe Portable Document Format (PDF) con un solo método.|
|[XML Parser Specification (XPS)](/slides/es/cpp/xml-parser-specification-xps/)|Todos los formatos de archivo compatibles pueden exportarse a documentos XML Parser Specification (XPS) con un solo método.|
|[PresentationML (PPTX, XML)](/slides/es/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ soporta el procesamiento del formato de presentación OOXML también conocido como PresentationML o PPTX.|
|[Conversión de PPTX a HTML](https://docs.aspose.com/slides/es/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ admite la conversión de presentaciones a formato HTML.|

## **Renderizado de presentaciones**
Aspose.Slides for C++ permite el renderizado de alta fidelidad de diapositivas en los documentos de presentación a varios formatos gráficos como se indica a continuación:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Formatos de imagen compatibles con C++|Con Aspose.Slides for C++ podrá renderizar no solo diapositivas de presentación, sino también imágenes en diapositivas a todos los formatos gráficos compatibles con C++ como PNG, BMP y JPEG.|
|Formato SVG|Aspose.Slides for C++ también proporciona un método incorporado para exportar diapositivas de presentación a formatos Scalable Vector Graphics (SVG).|

## **Características de contenido**
Aspose.Slides for C++ le permite acceder, modificar o crear casi todo el contenido posible de los documentos de presentación.

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Diapositivas maestras|Las diapositivas maestras definen el diseño de las diapositivas normales. Aspose.Slides for C++ le permite acceder y modificar las diapositivas maestras de los documentos de presentación.|
|Diapositivas normales|Con Aspose.Slides for C++ puede crear nuevas diapositivas de diferentes tipos, así como acceder y modificar las diapositivas existentes en los documentos de presentación.|
|Clonar / Copiar diapositivas|Aspose.Slides for C++ ofrece métodos incorporados para clonar o copiar diapositivas existentes, tanto dentro de una presentación como de una presentación a otra. Dado que una diapositiva hereda su diseño de la diapositiva maestra, los métodos de clonación incorporados copian automáticamente la maestra al clonar.|
|Marcadores de posición y marcadores de texto|También puede acceder a los marcadores de posición y a los marcadores de texto en una diapositiva. Además, puede crear una diapositiva con marcadores de texto desde cero mediante el método adecuado.|
|Encabezados y pies de página|Aspose.Slides for C++ también facilita la gestión de encabezados/pies de página en las diapositivas.|
|Notas en diapositivas|Con Aspose.Slides for C++ puede acceder y modificar notas asociadas a una diapositiva, así como añadir notas.|
|Buscar una forma|También puede encontrar una forma concreta en una diapositiva utilizando el texto alternativo asociado a la forma.|
|Fondos|Aspose.Slides for C++ permite trabajar con el fondo asociado a una diapositiva maestra o normal de la presentación.|
|Cuadros de texto|Los cuadros de texto pueden crearse desde cero. Los cuadros de texto existentes pueden accederse y su contenido puede modificarse sin perder el formato original del texto.|
|Formas rectangulares|Las formas rectangulares pueden crearse o modificarse con Aspose.Slides for C++.|
|Formas de polilínea|Las formas de polilínea también pueden crearse o modificarse con Aspose.Slides for C++.|
|Formas elípticas|Las formas elípticas también pueden crearse o modificarse con Aspose.Slides for C++.|
|Formas agrupadas|Aspose.Slides for C++ admite formas agrupadas.|
|Formas automáticas|Las formas automáticas también son compatibles con Aspose.Slides for C++.|
|Serialización de formas|Aunque Aspose.Slides for C++ soporta una gran cantidad de formas, si una forma no es compatible, existe un método de serialización proporcionado por Aspose.Slides for C++ mediante el cual puede serializar esa forma de una diapositiva existente para su posterior uso por Aspose.Slides for C++ según sea necesario.|
|Marcos de imagen|Las imágenes se gestionan en marcos de imagen mediante Aspose.Slides for C++.|
|Marcos de audio|Los archivos de audio pueden enlazarse o incrustarse en diapositivas mediante marcos de audio con Aspose.Slides for C++.|
|Marcos de vídeo|Los archivos de vídeo se gestionan en marcos de vídeo a través de Aspose.Slides for C++.|
|Marco OLE|Los objetos OLE se gestionan en marcos OLE mediante Aspose.Slides for C++.|
|Tablas|Las tablas en las diapositivas también son compatibles con Aspose.Slides for C++.|
|Marco de texto|El texto asociado a cualquier forma puede accederse mediante el marco de texto asociado a esa forma.|
|Escaneo de texto|El texto de una presentación puede escanearse a nivel de presentación o de diapositiva mediante los métodos de escaneo incorporados.|
|Animaciones|Se pueden aplicar animaciones a las formas.|
|Presentaciones|Los pase de diapositivas, transiciones de diapositivas y transiciones Morph también son compatibles.|

## **Características de formato**
Es posible dar formato al texto y a las formas en las diapositivas de un documento de presentación usando Aspose.Slides for C++.

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Formato de texto|<p>En Aspose.Slides for C++, el texto se gestiona a través de marcos de texto asociados a las formas. Por ello, el texto puede formatearse utilizando los párrafos y fragmentos asociados a los marcos de texto. Los siguientes elementos de texto pueden formatearse mediante Aspose.Slides for C++.</p><p>- Tipo de fuente</p><p>- Tamaño de fuente</p><p>- Color de fuente</p><p>- Sombras de fuente</p><p>- Alineación de párrafo</p><p>- Viñetas de párrafo</p><p>- Orientación de párrafo</p>|
|Formato de forma|<p>En Aspose.Slides for C++, el elemento básico de una diapositiva es la forma. Los siguientes elementos de forma pueden formatearse con Aspose.Slides for C++:</p><p>- Posición</p><p>- Tamaño</p><p>- Línea</p><p>- Relleno (incluyendo patrón, degradado, sólido)</p><p>- Texto</p><p>- Imagen</p>|

## **FAQ**

### ¿Necesito instalar Microsoft PowerPoint en el servidor/PC para que la biblioteca funcione?

No. PowerPoint no es necesario; Aspose.Slides es un motor independiente para crear, editar, convertir y renderizar presentaciones.

### ¿Cómo funciona la multihilo? ¿Se puede paralelizar el procesamiento?

Es seguro procesar documentos diferentes en hilos distintos; el mismo [presentación](https://reference.aspose.com/slides/es/cpp/aspose.slides/presentation/) no debe ser utilizado por [múltiples hilos](/slides/es/cpp/multithreading/) al mismo tiempo.

### ¿Se admiten contraseñas y cifrado de archivos?

Sí. [Puede](/slides/es/cpp/password-protected-presentation/) abrir presentaciones cifradas, establecer o eliminar una contraseña de apertura y escritura, y comprobar el estado de protección.

### ¿Debo preocuparme por los paquetes de fuentes en contenedores Linux?

Sí. Se recomienda instalar paquetes de fuentes comunes y/o especificar explícitamente [directorios de fuentes](/slides/es/cpp/custom-font/) en su aplicación para evitar sustituciones inesperadas.

### ¿Existen limitaciones en la versión de evaluación?

En el [modo de evaluación](/slides/es/cpp/licensing/), se añade una marca de agua a la salida y se aplican ciertas limitaciones; una [licencia temporal de 30 días](https://purchase.aspose.com/temporary-license/) está disponible para pruebas con todas las funciones.

### ¿Se admite la importación de formatos externos a una presentación (PDF/HTML → PPTX)?

Sí. Puede añadir [páginas PDF y contenido HTML](/slides/es/cpp/import-presentation/) a una presentación, convirtiéndolos en diapositivas.
