## **Formatos de archivo y conversiones**
Aspose.Slides forC++ admite la mayoría de los formatos de documentos PowerPoint y también los exporta a formatos populares usados ampliamente para el intercambio entre organizaciones. La tabla siguiente enumera estos formatos:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/es/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ ofrece el procesamiento más rápido para este formato de documento de presentación.|
|[Portable Document Format (PDF)](/slides/es/cpp/portable-document-format-pdf/)|Los formatos de archivo compatibles pueden exportarse a documentos Adobe Portable Document Format (PDF) con un solo método.|
|[XML Parser Specification (XPS)](/slides/es/cpp/xml-parser-specification-xps/)|Todos los formatos de archivo compatibles pueden exportarse a documentos XML Parser Specification (XPS) con un solo método.|
|[PresentationML (PPTX, XML)](/slides/es/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ admite el procesamiento del formato de presentación OOXML también conocido como PresentationML o PPTX.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/es/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ admite la conversión de presentaciones a formato HTML.|

## **Renderizado**
Aspose.Slides for C++ admite la renderización de alta fidelidad de diapositivas en los documentos de presentación a varios formatos gráficos como se indica a continuación:

|**Funcionalidad**|**Descripción**|
| :- | :- |
|C++ Supported Image Formats|Con Aspose.Slides for C++ podrás renderizar no solo diapositivas de presentación, sino también imágenes en las diapositivas a todos los formatos gráficos compatibles con C++ como PNG, BMP y JPEG.|
|SVG Format|Aspose.Slides for C++ también proporciona un método incorporado para exportar diapositivas de presentación a formatos Scalable Vector Graphics (SVG).|

## **Características de contenido**
Aspose.Slides forC++ le permite acceder, modificar o crear casi todo el contenido posible de los documentos de presentación.

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Master Slides|Las diapositivas maestras definen el diseño de las diapositivas normales. Aspose.Slides for C++ le permite acceder y modificar las diapositivas maestras de los documentos de presentación.|
|Normal Slides|Con Aspose.Slides for C++, no solo puede crear nuevas diapositivas de diferentes tipos, sino también acceder y modificar las diapositivas existentes en los documentos de presentación.|
|Cloning / Copying Slides|Aspose.Slides for C++ ofrece métodos incorporados para clonar o copiar diapositivas existentes no solo dentro de una presentación, sino también de una presentación a otra. Como una diapositiva hereda su diseño de la diapositiva maestra, los métodos de clonación incorporados copian automáticamente la maestra durante la clonación.|
|Place Holders and Text Holders|También puede acceder a los marcadores de posición y a los marcadores de texto en una diapositiva. Además, puede crear una diapositiva con marcadores de texto desde cero utilizando el método adecuado.|
|Header and Footers|Aspose.Slides for C++ también facilita la gestión de encabezados/pies de página en las diapositivas.|
|Notes in Slides|Con Aspose.Slides for C++, no solo puede acceder y modificar notas asociadas a una diapositiva, sino también añadir notas.|
|Finding a Shape|También puede encontrar una forma concreta en una diapositiva mediante el texto alternativo asociado a la forma.|
|Backgrounds|Aspose.Slides for C++ permite trabajar con el fondo asociado a una diapositiva maestra o normal de la presentación.|
|Text Boxes|Los cuadros de texto pueden crearse desde cero. Los cuadros de texto existentes pueden accederse y su texto también puede modificarse sin perder el formato original.|
|Rectangle Shapes|Las formas rectangulares pueden crearse o modificarse con Aspose.Slides for C++.|
|Poly Line Shapes|Las formas de polilínea también pueden crearse o modificarse con Aspose.Slides for C++.|
|Ellipse Shapes|Las formas elípticas también pueden crearse o modificarse con Aspose.Slides for C++.|
|Group Shapes|Aspose.Slides for C++ también admite formas agrupadas.|
|Auto Shapes|Las formas automáticas también son compatibles con Aspose.Slides for C++.|
|Shapes Serialization|Aunque Aspose.Slides for C++ admite una gran cantidad de formas, si una forma no es compatible, existe un método de serialización proporcionado por Aspose.Slides for C++ que le permite serializar esa forma a partir de una diapositiva existente para su uso posterior según sea necesario.|
|Picture Frames|Las imágenes se gestionan en marcos de imagen mediante Aspose.Slides for C++.|
|Audio Frames|Los archivos de audio pueden enlazarse o incrustarse en las diapositivas mediante marcos de audio con Aspose.Slides for C++.|
|Video Frames|Los archivos de video se gestionan en marcos de video mediante Aspose.Slides for C++.|
|OLE Frame|Los objetos OLE se gestionan en marcos OLE mediante Aspose.Slides for C++.|
|Tables|Las tablas en las diapositivas también son compatibles con Aspose.Slides for C++.|
|Text Frame|El texto asociado a cualquier forma puede accederse mediante el marco de texto asociado a esa forma.|
|Text Scanning|El texto de una presentación puede escanearse a nivel de presentación o diapositiva mediante los métodos de escaneo incorporados.|
|Animations|Se pueden aplicar animaciones a las formas.|
|Slide Shows|Las presentaciones de diapositivas, transiciones de diapositivas y transiciones Morph también son compatibles.|

## **Características de formato**
Es posible dar formato al texto y a las formas en diapositivas de un documento de presentación usando Aspose.Slides for C++.

|**Funcionalidad**|**Descripción**|
| :- | :- |
|Text Formatting|<p>En Aspose.Slides for C++, el texto se gestiona mediante marcos de texto asociados a las formas. Por lo tanto, el texto puede formatearse usando los párrafos y fragmentos asociados a los marcos de texto. Los siguientes elementos de texto pueden formatearse mediante Aspose.Slides for C++.</p><p>- Tipo de fuente</p><p>- Tamaño de fuente</p><p>- Color de fuente</p><p>- Tonos de fuente</p><p>- Alineación de párrafo</p><p>- Viñetas de párrafo</p><p>- Orientación de párrafo</p>|
|Shape Formatting|<p>En Aspose.Slides for C++, el elemento básico de una diapositiva es la forma. Los siguientes elementos de forma pueden formatearse usando Aspose.Slides for C++:</p><p>- Posición</p><p>- Tamaño</p><p>- Línea</p><p>- Relleno (incluyendo Patrón, Degradado, Sólido)</p><p>- Texto</p><p>- Imagen</p>|

## **Preguntas frecuentes**

**¿Necesito instalar Microsoft PowerPoint en el servidor/PC para que la biblioteca funcione?**

No. PowerPoint no es necesario; Aspose.Slides es un motor independiente para crear, editar, convertir y renderizar presentaciones.

**¿Cómo funciona el multihilo? ¿Puede paralelizarse el procesamiento?**

Es seguro procesar diferentes documentos en hilos distintos; el mismo [presentación](https://reference.aspose.com/slides/es/cpp/aspose.slides/presentation/) objeto no debe ser usado por [múltiples hilos](/slides/es/cpp/multithreading/) al mismo tiempo.

**¿Se admiten contraseñas de archivo y cifrado?**

Sí. [Puede](/slides/es/cpp/password-protected-presentation/) abrir presentaciones cifradas, establecer o eliminar una contraseña de apertura y escritura, y comprobar el estado de protección.

**¿Debo preocuparme por los paquetes de fuentes en contenedores Linux?**

Sí. Se recomienda instalar paquetes de fuentes comunes y/o especificar explícitamente los [directorios de fuentes](/slides/es/cpp/custom-font/) en su aplicación para evitar sustituciones inesperadas.

**¿Existen limitaciones en la versión de evaluación?**

En el [modo de evaluación](/slides/es/cpp/licensing/), se añade una marca de agua a la salida y se aplican ciertas limitaciones; una [licencia temporal de 30 días](https://purchase.aspose.com/temporary-license/) está disponible para pruebas con todas las funciones.

**¿Se admite la importación de formatos externos a una presentación (PDF/HTML → PPTX)?**

Sí. Puede añadir [páginas PDF y contenido HTML](/slides/es/cpp/import-presentation/) a una presentación, convirtiéndolos en diapositivas.
