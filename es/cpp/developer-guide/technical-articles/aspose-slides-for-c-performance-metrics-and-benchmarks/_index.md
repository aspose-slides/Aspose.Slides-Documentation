## **Propósito**
El rendimiento suele ser el primer factor crítico al elegir un componente. Este artículo mide el rendimiento de Aspose.Slides for C++ y VSTO 2008. Las pruebas simples se realizan en sistemas operativos, componentes de hardware y configuraciones similares. 

Este artículo presenta mediciones de rendimiento de los productos, entre ellos **Aspose.Slides for C++** y **VSTO 2008**. Las estimaciones de rendimiento que se presentan aquí pretenden ayudarle a entender qué esperar de los distintos componentes en algunos escenarios de uso frecuente bajo configuraciones similares en hardware estándar que ejecuta sistemas operativos ampliamente utilizados. Naturalmente, el rendimiento de su aplicación depende de sus datos, los patrones de acceso a los datos, el tamaño de la caché, otros parámetros de configuración, el sistema operativo y el hardware, etc. La referencia pretende ilustrar cómo funcionan los componentes bajo condiciones de hardware mínimas; cuanto más rápido sea el hardware, más rápidamente se procesarán las tareas por parte de los componentes.

## **Metodología de Pruebas**
Todas las pruebas de rendimiento se llevaron a cabo en combinaciones comunes de hardware y sistema operativo, sin configuraciones personalizadas, ajustes ni otras técnicas de mejora del rendimiento. Todas las pruebas se ejecutaron con las instalaciones de los componentes en el mismo sistema, que de otro modo estaba inactivo. Para obtener lecturas precisas, realizamos todas las tareas dos o tres veces consecutivas para evaluar mejor un componente y obtener lecturas exactas.
