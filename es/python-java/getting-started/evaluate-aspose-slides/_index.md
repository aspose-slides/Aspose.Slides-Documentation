Puede descargar Aspose.Slides for Python via Java para evaluar sus funcionalidades. El paquete de evaluación es idéntico al paquete con licencia. Para usarlo sin limitaciones de evaluación, agregue unas pocas líneas de código para aplicar una licencia.

La versión de evaluación de Aspose.Slides (utilizada sin una licencia) proporciona la funcionalidad completa del producto, pero inserta una marca de agua de evaluación en la parte superior del documento al abrirlo o guardarlo. La extracción de texto está limitada a una diapositiva por presentación.
