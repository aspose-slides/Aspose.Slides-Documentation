## **Descripción general**

Utilice el foro de soporte de Aspose.Slides para hacer preguntas, informar problemas y solicitar funciones para Aspose.Slides for Python via Java. Este artículo explica qué comprobar antes de abrir un tema y qué información ayuda al equipo de soporte a reproducir un problema.

## **Soporte técnico**

{{% alert color="info" title="Note" %}}

Aspose ofrece soporte técnico gratuito a todos los usuarios, incluidos los que están evaluando el producto. Consulte las [políticas de soporte gratuito](https://forum.aspose.com/t/free-support-policies/162313) para obtener más detalles.

{{% /alert %}}

Publique preguntas técnicas en el [foro de soporte de Aspose.Slides](https://forum.aspose.com/c/slides/es/11). Indique **Aspose.Slides for Python via Java** en su informe para que el equipo pueda identificar el producto y el entorno correctos.

Para asistencia prioritaria, consulte el [helpdesk de soporte de pago](https://helpdesk.aspose.com/). El soporte de pago requiere una suscripción independiente y no está incluido con la licencia del producto.

## **Antes de informar un problema**

1. Compruebe las [descargas](https://releases.aspose.com/slides/es/python-java/) y las [notas de la versión](https://releases.aspose.com/slides/es/python-java/release-notes/) para ver si existe una versión más reciente que pueda resolver el problema. Si es posible, reproduzca el problema con la última versión en un entorno de pruebas.  
2. Busque en el foro de soporte, la [documentación](/slides/es/python-java/) y la [referencia de API](https://reference.aspose.com/slides/es/python-java/) para encontrar una respuesta existente.  
3. Para problemas de instalación o de inicio de la JVM, revise la [guía de instalación](/slides/es/python-java/installation/) y confirme que Python y Java utilizan arquitecturas coincidentes.  
4. Reduzca el problema al ejemplo más pequeño y a la presentación de entrada que aún lo reproduzca.

## **Prepare un informe de problema**

Incluya la siguiente información en su tema del foro:

- **Entorno:** versión de Aspose.Slides for Python via Java, versión de Python, versión y proveedor de Java, versión de JPype, sistema operativo y arquitectura.  
- **Pasos y código:** un ejemplo mínimo ejecutable en Python, incluidos los imports y la inicialización de la JVM, y los pasos necesarios para reproducir el problema.  
- **Archivos de entrada:** la presentación y cualquier archivo relacionado requerido por el ejemplo. Combine varios archivos en un archivo ZIP.  
- **Resultados esperados y reales:** describa la diferencia y adjunte la salida generada o capturas de pantalla cuando sea útil. Para problemas de renderizado, identifique las diapositivas y fuentes afectadas.  
- **Detalles del error:** el mensaje de error completo y la traza de pila, si se produce una excepción.

Utilice un tema por problema. Añada información de seguimiento sobre el mismo problema al tema existente para que el equipo de soporte pueda continuar la investigación.

## **Preguntas frecuentes**

**¿Puedo obtener ayuda mientras evalúo Aspose.Slides for Python via Java?**

Sí. El soporte técnico gratuito está disponible a través del foro de soporte de Aspose.Slides durante la evaluación y también después de la compra.

**¿Qué debo incluir cuando la JVM no arranca?**

Proporcione sus versiones de Python, Java y JPype, el sistema operativo, las arquitecturas de Python y Java, el código de inicialización de la JVM y el mensaje de error completo. estos detalles ayudan al equipo de soporte a reproducir su configuración.

**¿Cómo debo informar un problema que apareció después de una actualización?**

Incluya la última versión que funcionaba, la primera versión en la que observó el problema y un ejemplo mínimo con los archivos de entrada. Describa cualquier otro cambio en el entorno realizado durante la actualización.
