{{% alert color="info" title="Nota" %}}

Aspose.Slides for Python via Java es una biblioteca de clases que permite a las aplicaciones Python leer y escribir presentaciones sin requerir Microsoft PowerPoint®. Permite gestionar texto, formas, tablas y animaciones; añadir audio y vídeo a las diapositivas; previsualizar diapositivas; y exportar diapositivas a SVG, PDF y otros formatos.

Para obtener más información, consulte la [Referencia de la API de Aspose.Slides para Python via Java](https://reference.aspose.com/slides/es/python-java/).
