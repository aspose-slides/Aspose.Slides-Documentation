## **Versiones compatibles de Microsoft PowerPoint**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint para Mac

## **Formatos de archivo compatibles**

Aspose.Slides for SharePoint convierte presentaciones PPT y PPTX almacenadas en una biblioteca de documentos de SharePoint. Los archivos de otros tipos no se convierten.

|**Formato**|**Descripción**|**Convertir desde**|**Convertir a**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|Presentación de PowerPoint 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|Presentación de PowerPoint 2007 y posteriores|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|Formato de documento portátil, con diapositivas o con la vista de notas| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|Imagen TIFF, con diapositivas o con la vista de notas| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|Especificación de papel XML| |{{< emoticons/tick >}}|

|[PPS](https://docs.fileformat.com/presentation/pps/)|Presentación de diapositivas PowerPoint 97 - 2003| |{{< emoticons/tick >}}|
