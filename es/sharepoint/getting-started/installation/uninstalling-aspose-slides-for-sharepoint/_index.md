Para desinstalar Aspose.Slides for SharePoint:

1. Ejecute el programa de instalación que utilizó para instalarlo, por ejemplo *Setup2019.exe* en SharePoint Server 2019.
   Cuando detecta la misma versión instalada, el programa de instalación ofrece repararla o eliminarla. Cuando detecta una versión diferente, ofrece actualizarla o eliminarla.
2. Seleccione **Remove** y haga clic en **Next** para desinstalar Aspose.Slides for SharePoint.
