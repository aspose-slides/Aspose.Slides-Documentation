## **Descripción del producto**

Aspose.Slides for SharePoint convierte presentaciones de PowerPoint almacenadas en bibliotecas de documentos de SharePoint a otros formatos, en el servidor.

Convierte los siguientes formatos de PowerPoint:

- PPT – presentación Microsoft PowerPoint 97 - 2003
- PPTX – presentación Office Open XML

Los convierte a PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX y POTM. Consulte [Formatos de archivo compatibles](/slides/es/sharepoint/supported-file-formats/) para obtener más información.

La descarga contiene un programa de instalación separado y un paquete de solución para cada uno de los siguientes productos:

- SharePoint 2007
- SharePoint 2010
- SharePoint Server 2013
- SharePoint Server 2016
- SharePoint Server 2019
