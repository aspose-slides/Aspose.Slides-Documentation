{{% alert color="info" title="Note" %}}

Con Aspose.Slides for SharePoint, puedes convertir presentaciones de PowerPoint a muchos formatos de documento populares desde una biblioteca de documentos de SharePoint.

{{% /alert %}}

## **Formatos de entrada compatibles**

Aspose.Slides for SharePoint convierte los siguientes formatos de entrada:

- PPT – Presentación de Microsoft PowerPoint 97 - 2003
- PPTX – Presentación Office Open XML

{{% alert color="info" title="Note" %}}

Para convertir documentos, Aspose.Slides for SharePoint se basa en una versión incorporada de [Aspose.Slides for .NET](https://products.aspose.com/slides/es/net/).

{{% /alert %}}

## **Formatos de salida compatibles**

La lista **Convert to** en la página de conversión ofrece los siguientes formatos de salida, en este orden:

- PDF – Documento portátil Adobe
- TIFF – Paquete de imágenes
- XPS – Especificación de papel XML
- PPS – Presentación de diapositivas
- PPSX – Presentación de diapositivas Open XML de Microsoft PowerPoint
- ODP – Presentación OpenDocument
- PPTM – Presentación con macros habilitadas Open XML de Microsoft PowerPoint
- PPSM – Presentación de diapositivas con macros habilitadas Open XML de Microsoft PowerPoint
- POTX – Plantilla de Microsoft PowerPoint
- POTM – Plantilla de presentación con macros habilitadas Open XML de PowerPoint
- PDFNotes – Vista de notas de la presentación en formato PDF
- HTML – Presentación en formato HTML
- TIFFNotes – Vista de notas de la presentación como imagen TIFF multipágina
- SWF – Película Shockwave Flash
- SWFNotes – Vista de notas de la presentación como SWF multipágina
