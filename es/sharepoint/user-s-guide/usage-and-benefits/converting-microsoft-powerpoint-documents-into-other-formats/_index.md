{{% alert color="info" title="Note" %}}

Cuando Aspose.Slides for SharePoint está instalado en el servidor SharePoint y activado para una colección de sitios, agrega el elemento **Convert via Aspose.Slides** al menú de documentos en sus bibliotecas de documentos, como se muestra a continuación. En SharePoint 2007, el elemento se llama **Convert with Aspose.Slides**.

**Instalar Aspose.Slides for SharePoint agrega el elemento Convert via Aspose.Slides a los menús de documentos**

![Un menú de documento con el elemento Convert via Aspose.Slides](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **Convertir una presentación**

Para convertir una presentación de Microsoft PowerPoint (PPT o PPTX) desde una biblioteca de documentos de SharePoint:

1. Seleccione una presentación de Microsoft PowerPoint en una biblioteca de documentos.
2. Abra su menú y haga clic en **Convert via Aspose.Slides**.

   **El menú del archivo Presentation 2, mostrando el elemento Convert via Aspose.Slides**

   ![El menú de una presentación en una biblioteca de documentos, con el elemento Convert via Aspose.Slides resaltado](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. Seleccione el formato de salida bajo **Convert to**. Si lo desea, cambie el nombre del archivo de salida y la carpeta de destino.
4. Haga clic en **Convert** para convertir el archivo.

   **La página de conversión le permite seleccionar el formato de salida, el nombre del archivo y el destino**

   ![La página de conversión con el formato de salida, el archivo de destino y la carpeta de destino](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. Cuando la conversión se complete, se mostrará un mensaje de éxito.

   **La conversión fue exitosa**

   ![La página de resultados de la conversión](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. Haga clic en **Source Library** (para ir a la carpeta de origen) o en **Destination Library** (para ir a la carpeta donde se guardó el archivo).

   El documento convertido aparece en la biblioteca de documentos.

   **El documento convertido mostrado en la biblioteca donde se guardó**

   ![El archivo convertido en la biblioteca de documentos](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

Las capturas de pantalla se tomaron con una versión anterior, que ofrecía solo los formatos PDF, TIFF y XPS. La página de conversión actual ofrece más formatos de salida; consulte [Multiple Format Support](/slides/es/sharepoint/multiple-format-support/).

{{% /alert %}}

En SharePoint 2010 y posteriores, también puede seleccionar una o varias presentaciones en la biblioteca y hacer clic en **Convert Slides** en la pestaña de cinta **Aspose Tools**. Se abre la misma página de conversión.
