Para convertir una presentación en una biblioteca de documentos:

1. Abra el menú del archivo PPT o PPTX (su Edit Control Block) y seleccione **Convertir mediante Aspose.Slides**. En SharePoint 2007, el elemento del menú se llama **Convertir con Aspose.Slides**.

   **Seleccionar Convertir con Aspose.Slides en el menú de un documento en SharePoint 2007**

   ![El menú de un documento en una biblioteca de documentos de SharePoint 2007, con el elemento Convertir con Aspose.Slides](convert-one-file_1.png)

2. En la página de conversión, seleccione el formato de salida bajo **Convertir a**. Si lo desea, cambie el nombre del archivo de destino y la carpeta de destino.
3. Haga clic en **Convertir**.
4. Cuando la conversión haya finalizado, haga clic en **Biblioteca de origen** o **Biblioteca de destino** para volver a una biblioteca de documentos. El archivo convertido está en la carpeta de destino.

Los mismos pasos, con capturas de pantalla de cada página, se encuentran en [Conversión de documentos Microsoft PowerPoint a otros formatos](/slides/es/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
