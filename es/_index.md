## Aspose.Slides for .NET

{{% alert color="info" %}}

![Logotipo del producto Aspose.Slides for .NET](home_1.png)

Aspose.Slides for .NET es una API de gestión de Microsoft PowerPoint® que permite a las aplicaciones .NET leer y escribir documentos PowerPoint® sin utilizar Microsoft PowerPoint®. Aspose.Slides for .NET es el primer y único componente que ofrece la funcionalidad para gestionar documentos PowerPoint®. Aspose.Slides for .NET proporciona muchas características clave, como la gestión de texto, formas, tablas y animaciones, la incorporación de audio y vídeo en las diapositivas, la vista previa de diapositivas, la exportación de diapositivas a SVG, PDF y más.
