## **Evaluación de Aspose.Slides**

Puede descargar Aspose.Slides para evaluación. El paquete de evaluación es idéntico al paquete adquirido; se licencia después de añadir unas pocas líneas de código para aplicar la licencia.

Sin una licencia, Aspose.Slides ofrece toda su funcionalidad en modo de evaluación, con dos limitaciones: añade un cuadro de texto con marca de agua de evaluación a cada diapositiva de cada presentación que guarda, y el texto que su código lee de una presentación se trunca a sus primeros caracteres, seguido de un aviso sobre la limitación de evaluación. El texto que su código escribe se guarda completo.

{{% alert color="info" title="Note" %}}

Si desea probar Aspose.Slides sin las limitaciones de la versión de evaluación, puede solicitar una **Licencia temporal de 30 días**. Consulte [Cómo obtener una licencia temporal?](https://purchase.aspose.com/temporary-license) para obtener más información.

{{% /alert %}}

## **Preguntas frecuentes**

### ¿Puedo probar varias presentaciones en paralelo en diferentes hilos en modo de evaluación?

Sí. Puede procesar diferentes documentos en paralelo; no debe compartir el mismo objeto de presentación [entre hilos](/slides/es/python-net/multithreading/). El modo de evaluación no afecta a esto.

### ¿Necesito instalar Microsoft PowerPoint para evaluar la biblioteca en un servidor o en CI?

No. Aspose.Slides es un motor independiente y no requiere que PowerPoint esté instalado ni para la evaluación ni para producción.

### ¿Puedo probar completamente la conversión de PPT/PPTX a PDF e imágenes en modo de evaluación?

Sí. Los [convertidores](/slides/es/python-net/convert-presentation/) funcionan; la salida incluirá una marca de agua.

### ¿Puedo usar una licencia temporal para pruebas de carga sin marca de agua?

Sí. Una licencia temporal de 30 días elimina las limitaciones del modo de evaluación y permite realizar pruebas sin una marca de agua.
