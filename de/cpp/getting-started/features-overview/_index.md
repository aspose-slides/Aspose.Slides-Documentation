## **Dateiformate und Konvertierungen**
Aspose.Slides for C++ unterstützt die meisten PowerPoint‑Dokumentformate und exportiert sie auch in beliebte Formate, die weit verbreitet zum Austausch zwischen Organisationen verwendet werden. Die folgende Tabelle listet diese Formate auf:

|**Funktion**|**Beschreibung**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/de/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ bietet die schnellste Verarbeitung für dieses Präsentationsdokumentformat.|
|[Portable Document Format (PDF)](/slides/de/cpp/portable-document-format-pdf/)|Die unterstützten Dateiformate können mit einer einzigen Methode in Adobe Portable Document Format (PDF)-Dokumente exportiert werden.|
|[XML Parser Specification (XPS)](/slides/de/cpp/xml-parser-specification-xps/)|Alle unterstützten Dateiformate können mit einer einzigen Methode in XML Parser Specification (XPS)-Dokumente exportiert werden.|
|[PresentationML (PPTX, XML)](/slides/de/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ unterstützt die Verarbeitung des OOXML‑Präsentationsformats, das auch als PresentationML oder PPTX bekannt ist.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/de/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ unterstützt die Konvertierung von Präsentationen in das HTML-Format.|

## **Präsentationsdarstellung**
Aspose.Slides for C++ unterstützt das hochqualitative Rendern von Folien in den Präsentationsdokumenten in verschiedene Grafikformate, wie unten aufgeführt:

|**Funktion**|**Beschreibung**|
| :- | :- |
|C++ unterstützte Bildformate|Mit Aspose.Slides for C++ können Sie nicht nur Präsentationsfolien, sondern auch Bilder auf Folien in alle von C++ unterstützten Grafikformate wie PNG, BMP und JPEG rendern.|
|SVG-Format|Aspose.Slides for C++ bietet zudem eine integrierte Methode, um Präsentationsfolien in Scalable Vector Graphics (SVG)-Formate zu exportieren.|

## **Inhaltsfunktionen**
Aspose.Slides for C++ ermöglicht den Zugriff, die Änderung oder das Erstellen fast aller möglichen Inhalte von Präsentationsdokumenten.

|**Funktion**|**Beschreibung**|
| :- | :- |
|Masterfolien|Die Masterfolien definieren das Layout der normalen Folien. Aspose.Slides for C++ ermöglicht den Zugriff auf und die Änderung der Masterfolien der Präsentationsdokumente.|
|Normale Folien|Mit Aspose.Slides for C++ können Sie nicht nur neue Folien verschiedener Typen erstellen, sondern auch vorhandene Folien in den Präsentationsdokumenten öffnen und bearbeiten.|
|Klonen / Kopieren von Folien|Aspose.Slides for C++ stellt integrierte Methoden zum Klonen oder Kopieren vorhandener Folien bereit, sowohl innerhalb einer Präsentation als auch von einer Präsentation zur anderen. Da eine Folie ihr Layout vom Master übernimmt, kopieren die integrierten Klonmethoden beim Klonen auch automatisch den Master.|
|Platzhalter und Textplatzhalter|Sie können ebenfalls die Platzhalter und Textplatzhalter einer Folie öffnen. Außerdem können Sie mit der entsprechenden Methode eine Folie von Grund auf mit Textplatzhaltern erstellen.|
|Kopf- und Fußzeilen|Aspose.Slides for C++ erleichtert auch die Handhabung von Kopf‑ und Fußzeilen in den Folien.|
|Notizen in Folien|Mit Aspose.Slides for C++ können Sie nicht nur Notizen, die einer Folie zugeordnet sind, öffnen und ändern, sondern auch Notizen hinzufügen.|
|Form finden|Sie können auch eine bestimmte Form auf einer Folie anhand des alternativen Textes, der der Form zugeordnet ist, finden.|
|Hintergründe|Aspose.Slides for C++ ermöglicht die Arbeit mit dem Hintergrund, der einem Master oder einer normalen Folie der Präsentation zugeordnet ist.|
|Textfelder|Textfelder können von Grund auf erstellt werden. Auf bestehende Textfelder kann zugegriffen und ihr Text kann ebenfalls geändert werden, ohne das ursprüngliche Textformat zu verlieren.|
|Rechteckformen|Rechteckformen können von Aspose.Slides for C++ erstellt oder geändert werden.|
|Polylinienformen|Polylinienformen können ebenfalls von Aspose.Slides for C++ erstellt oder geändert werden.|
|Ellipseformen|Ellipseformen können von Aspose.Slides for C++ erstellt oder geändert werden.|
|Gruppenformen|Aspose.Slides for C++ unterstützt ebenfalls Gruppenformen.|
|Autoformen|Autoformen werden ebenfalls von Aspose.Slides for C++ unterstützt.|
|Form‑Serialisierung|Obwohl Aspose.Slides for C++ eine große Anzahl von Formen unterstützt, gibt es für nicht unterstützte Formen eine Serialisierungsmethode, die von Aspose.Slides for C++ bereitgestellt wird. Damit können Sie die Form von einer bestehenden Folie serialisieren und bei Bedarf wieder von Aspose.Slides for C++ verwendet werden.|
|Bildrahmen|Bilder werden in Bildrahmen mit Aspose.Slides for C++ verwaltet.|
|Audiorahmen|Audiodateien können von Aspose.Slides for C++ auf Folien in Audiorahmen verlinkt oder eingebettet werden.|
|Videorahmen|Videodateien werden in Videorahmen durch Aspose.Slides for C++ verarbeitet.|
|OLE‑Rahmen|OLE‑Objekte werden von Aspose.Slides for C++ in OLE‑Rahmen verwaltet.|
|Tabellen|Tabellen auf Folien werden ebenfalls von Aspose.Slides for C++ unterstützt.|
|Textrahmen|Der Text, der einer Form zugeordnet ist, kann über den Textrahmen dieser Form aufgerufen werden.|
|Textdurchsuchung|Text in einer Präsentation kann auf Präsentations‑ oder Foliensatzebene mittels integrierter Scan‑Methoden durchsucht werden.|
|Animationen|Animationen können auf Formen angewendet werden.|
|Bildschirmpräsentationen|Bildschirmpräsentationen, Folienübergänge und Morph‑Übergänge werden ebenfalls unterstützt.|

## **Formatierungsfunktionen**
Es ist möglich, Text und Formen auf Folien in einem Präsentationsdokument mit Aspose.Slides for C++ zu formatieren.

|**Funktion**|**Beschreibung**|
| :- | :- |
|Textformatierung|<p>In Aspose.Slides for C++ wird der Text über Textrahmen verwaltet, die den Formen zugeordnet sind. Daher kann der Text über die Absätze und Textteile, die den Textrahmen zugeordnet sind, formatiert werden. Die folgenden Textelemente können über Aspose.Slides for C++ formatiert werden.</p><p>- Schriftart</p><p>- Schriftgröße</p><p>- Schriftfarbe</p><p>- Schriftabschattungen</p><p>- Absatzausrichtung</p><p>- Absatzaufzählung</p><p>- Absatzorientierung</p>|
|Formformatierung|<p>In Aspose.Slides for C++ ist das Grundelement einer Folie die Form. Die folgenden Formelemente können mit Aspose.Slides for C++ formatiert werden:</p><p>- Position</p><p>- Größe</p><p>- Linie</p><p>- Füllung (einschließlich Muster, Verlauf, einfarbig)</p><p>- Text</p><p>- Bild</p>|

## **FAQ**

### Do I need to install Microsoft PowerPoint on the server/PC for the library to work?
Nein. PowerPoint ist nicht erforderlich; Aspose.Slides ist eine eigenständige Engine zum Erstellen, Bearbeiten, Konvertieren und Rendern von Präsentationen.

### How does multithreading work? Can processing be parallelized?
Es ist sicher, verschiedene Dokumente in unterschiedlichen Threads zu verarbeiten; das gleiche [presentation](https://reference.aspose.com/slides/de/cpp/aspose.slides/presentation/)‑Objekt darf nicht gleichzeitig von [multiple threads](/slides/de/cpp/multithreading/) verwendet werden.

### Are file passwords and encryption supported?
Ja. [You can](/slides/de/cpp/password-protected-presentation/) verschlüsselte Präsentationen öffnen, ein Öffnungs‑ und Schreibpasswort festlegen oder entfernen und den Schutzstatus prüfen.

### Do I need to care about font packages in Linux containers?
Ja. Es wird empfohlen, gängige Schriftpakete zu installieren und/oder in Ihrer Anwendung ausdrücklich [specify font directories](/slides/de/cpp/custom-font/) anzugeben, um unerwartete Ersetzungen zu vermeiden.

### Are there limitations in the evaluation version?
Im [evaluation mode](/slides/de/cpp/licensing/) wird dem Ergebnis ein Wasserzeichen hinzugefügt und es gelten bestimmte Einschränkungen; eine [30‑day temporary license](https://purchase.aspose.com/temporary-license/) steht für Tests mit vollem Funktionsumfang zur Verfügung.

### Is importing external formats into a presentation (PDF/HTML → PPTX) supported?
Ja. Sie können [PDF pages and HTML content](/slides/de/cpp/import-presentation/) zu einer Präsentation hinzufügen und in Folien umwandeln.
