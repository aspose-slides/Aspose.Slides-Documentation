## Aspose.Slides für .NET

{{% alert color="info" %}}

![Aspose.Slides für .NET Produktlogo](home_1.png)

Aspose.Slides für .NET ist eine Microsoft PowerPoint®‑Verwaltungs‑API, die .NET‑Anwendungen das Lesen und Schreiben von PowerPoint®‑Dokumenten ermöglicht, ohne Microsoft PowerPoint® zu verwenden. Aspose.Slides für .NET ist die erste und einzige Komponente, die die Funktionalität zur Verwaltung von PowerPoint®‑Dokumenten bereitstellt. Aspose.Slides für .NET bietet zahlreiche wichtige Funktionen wie die Verwaltung von Text, Formen, Tabellen & Animationen, das Hinzufügen von Audio und Video zu Folien, die Vorschau von Folien, das Exportieren von Folien nach SVG, PDF‑Format und mehr.
