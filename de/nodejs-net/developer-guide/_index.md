Dieses **Developer Guide** zeigt, wie man gängige Präsentationsaufgaben in JavaScript mit Aspose.Slides für Node.js über .NET erledigt. Jeder Artikel enthält ausführbare Beispiele. Bevor Sie sie ausführen, richten Sie ein Projekt ein, wie in [Installation](/slides/de/nodejs-net/installation/) beschrieben.

- [**Präsentation erstellen**](/slides/de/nodejs-net/create-presentation/) – Erstellen Sie eine Präsentation, fügen Sie ein Textfeld und Folien hinzu, legen Sie die Foliengröße fest und speichern Sie das Ergebnis als PPTX.
- [**Präsentation öffnen**](/slides/de/nodejs-net/open-presentation/) – Öffnen Sie eine Präsentation aus einer Datei oder einem Puffer, lesen Sie die Folienanzahl und speichern Sie sie in einem anderen Format.
- [**PowerPoint zu PDF**](/slides/de/nodejs-net/convert-powerpoint-to-pdf/) – Konvertieren Sie eine Präsentation in PDF, einschließlich PDF/A für die Archivierung.
- [**Folie zu Bild**](/slides/de/nodejs-net/convert-slide/) – Rendern Sie Folien als PNG‑Bilder mit einem Skalierungsfaktor oder mit einer genauen Größe in Pixeln.
- [**Text verwalten**](/slides/de/nodejs-net/manage-text/) – Fügen Sie ein Textfeld hinzu und ändern Sie anschließend dessen Text, Schriftgröße und Fettdarstellung.
