## **Unterstützte Plattformen**
Aspose.Slides für Node.js via .NET ist eine plattformunabhängige API. Sie kann auf jeder Plattform (Windows, Linux, macOS usw.) verwendet werden, auf der Node.js 7 oder höher installiert ist. Oracle JDK 8 oder höher ist eine weitere Voraussetzung.

## **Dateiformate und Konvertierungen**
Aspose.Slides für Node.js via .NET unterstützt die meisten PowerPoint‑Dokumentformate. Es ermöglicht Ihnen außerdem, diese in die gängigen Dateiformate zu exportieren, die Organisationen verwenden und untereinander teilen. Lesen Sie die folgenden Details:

|**Funktion**|**Beschreibung**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides für Node.js via .NET bietet die schnellste Verarbeitung für dieses Präsentationsdokumentformat.|
|PPT‑zu‑PPTX‑Konvertierung|Aspose.Slides für Node.js via .NET unterstützt die PPT‑zu‑PPTX‑Konvertierung.|
|Portable Document Format (PDF)|Sie können alle unterstützten Dateiformate mit einer einzigen Methode in Adobe Portable Document Format (PDF)‑Dokumente exportieren.|
|XML Parser Specification (XPS)|Sie können alle unterstützten Dateiformate mit einer einzigen Methode in XML Parser Specification (XPS)‑Dokumente exportieren.|
|Tagged Image File Format (TIFF)|Sie können alle unterstützten Präsentationsdateiformate in Tagged Image File Format (TIFF) exportieren.|
|PPTX‑zu‑HTML‑Konvertierung|Aspose.Slides für Node.js via .NET unterstützt die Konvertierung von PresentationEx in das HTML‑Format.|

## **Präsentationsrendering**
Aspose.Slides für Node.js via .NET unterstützt das hochauflösende Rendering von Folien in Präsentationen in verschiedene Grafikformate. Lesen Sie die folgenden Details:

|**Funktion**|**Beschreibung**|
| :- | :- |
|.NET Supported Image Formats|Mit Aspose.Slides für Node.js via .NET können Sie Präsentationsfolien und Bilder auf Folien in alle von .NET unterstützten Grafikformate wie TIFF, PNG, BMP, JPEG und GIF rendern.|
|SVG‑Format|Aspose.Slides für Node.js via .NET bietet zudem integrierte Methoden, mit denen Sie Präsentationsfolien in Scalable Vector Graphics (SVG)‑Formate exportieren können.|

## **Inhaltsfunktionen**
Aspose.Slides für Node.js via .NET ermöglicht den Zugriff, die Änderung oder das Erstellen fast aller Elemente oder Inhalte von Präsentationsdokumenten. Lesen Sie die folgenden Details:

|**Funktion**|**Beschreibung**|
| :- | :- |
|Master‑Folien|Die Master‑Folien definieren das Layout der normalen Folien. Aspose.Slides für Node.js via .NET ermöglicht den Zugriff auf und die Änderung der Master‑Folien von Präsentationsdokumenten.|
|Normale Folien|Mit Aspose.Slides für Node.js via .NET können Sie neue Folien verschiedener Typen erstellen; Sie erhalten außerdem Zugriff auf und können vorhandene Folien in den Präsentationen ändern.|
|Klonen / Kopieren von Folien|Aspose.Slides für Node.js via .NET stellt integrierte Methoden bereit, mit denen Sie vorhandene Folien innerhalb einer Präsentation klonen oder kopieren können. Sie können kopierte und geklonte Folien von einer Präsentation zur anderen verwenden. Da eine Folie ihr Layout vom Master‑Folie erbt, kopieren die integrierten Klonmethoden den Master automatisch beim Klonen.|
|Verwalten von Folienabschnitten|Methoden zum Organisieren von Folien in verschiedene Abschnitte innerhalb einer Präsentation.|
|Platzhalter und Textplatzhalter|Sie können die Platzhalter und Textplatzhalter in einer Folie aufrufen. Außerdem können Sie mithilfe der entsprechenden Methode eine Folie von Grund auf mit Textplatzhaltern erstellen.|
|Kopf‑ und Fußzeilen|Aspose.Slides für Node.js via .NET erleichtert die Handhabung von Kopf‑ und Fußzeilen in Folien.|
|Notizen in Folien|Mit Aspose.Slides für Node.js via .NET können Sie auf Notizen zu einer Folie zugreifen, diese ändern und neue Notizen hinzufügen.|
|Form finden|Sie können eine bestimmte Form auf einer Folie anhand des alternativen Textes der Form finden.|
|Hintergründe|Aspose.Slides für Node.js via .NET ermöglicht die Arbeit mit Hintergründen, die einem Master‑ oder normalen Folien in einer Präsentation zugeordnet sind.|
|Textfelder|Textfelder können von Grund auf erstellt werden. Sie können vorhandene Textfelder aufrufen. Sie können deren Texte ändern, ohne das ursprüngliche Textformat zu verlieren.|
|Rechteckformen|Sie können Rechteckformen mit Aspose.Slides für Node.js via .NET erstellen oder ändern.|
|Polylinienformen|Sie können Polylinienformen mit Aspose.Slides für Node.js via .NET erstellen oder ändern.|
|Ellipsenformen|Sie können Ellipsenformen mit Aspose.Slides für Node.js via .NET erstellen oder ändern.|
|Gruppenformen|Aspose.Slides für Node.js via .NET unterstützt Gruppenformen.|
|Autoformen|Aspose.Slides für Node.js via .NET unterstützt Autoformen.|
|SmartArt|Aspose.Slides für Node.js via .NET bietet Unterstützung für SmartArt‑Formen in MS PowerPoint.|
|Diagramme|Aspose.Slides für Node.js via .NET bietet Unterstützung für MSO‑Diagramme in PowerPoint.|
|Serialisierung von Formen|Aspose.Slides für Node.js via .NET unterstützt eine große Anzahl von Formen. Wenn Aspose.Slides für Node.js via .NET keine Unterstützung für eine Form bietet, können Sie ein Serialisierungsverfahren verwenden, mit dem Sie diese Form von einer vorhandenen Folie serialisieren können. Auf diese Weise können Sie die Form nach Ihren Anforderungen weiter verwenden.|
|Bildrahmen|Sie können Bilder in Bildrahmen mit Aspose.Slides für Node.js via .NET verwalten.|
|Audio‑Frames|Sie können Audiodateien in Audio‑Frames auf Folien verlinken oder einbetten mit Aspose.Slides für Node.js via .NET.|
|Video‑Frames|Sie können Videodateien in Video‑Frames verarbeiten. Aspose.Slides für Node.js via .NET bietet zudem Unterstützung für verlinkte und eingebettete Videos.|
|OLE‑Frame|Sie können OLE‑Objekte in OLE‑Frames mit Aspose.Slides für Node.js via .NET verwalten.|
|Tabellen|Aspose.Slides für Node.js via .NET unterstützt Tabellen in Folien.|
|ActiveX‑Steuerelemente|Unterstützung für ActiveX‑Steuerelemente.|
|VBA‑Makros|Unterstützung zur Verwaltung von VBA‑Makros in Präsentationen.|
|Text‑Frame|Sie können über den Text‑Frame, der mit einer Form verbunden ist, auf den Text jeder Form zugreifen.|
|Text‑Scanning|Sie können Text in einer Präsentation auf Präsentations‑ oder Foliensatzebene mittels integrierter Scan‑Methoden durchsuchen.|
|Animationen|Sie können Animationen auf Formen anwenden.|
|Bildschirmpräsentationen|Aspose.Slides für Node.js via .NET unterstützt Bildschirmpräsentationen und Folienübergänge.|

## **Formatierungsfunktionen**
Mit Aspose.Slides für Node.js via .NET können Sie Texte und Formen auf Folien in Präsentationen formatieren. Lesen Sie die folgenden Details:

|**Funktion**|**Beschreibung**|
| :- | :- |
|Textformatierung|<p>In Aspose.Slides für Node.js via .NET können Sie Texte über die Text‑Frames, die mit den Formen verbunden sind, verwalten. So können Sie Texte mithilfe der Absätze und Textabschnitte, die den Text‑Frames zugeordnet sind, formatieren. Diese Textelemente können über Aspose.Slides für Node.js via .NET formatiert werden.</p><p>- Schriftart</p><p>- Schriftgröße</p><p>- Schriftfarbe</p><p>- Schriftton</p><p>- Absatzausrichtung</p><p>- Aufzählungszeichen im Absatz</p><p>- Absatzorientierung</p>|
|Formformatierung|<p>In Aspose.Slides für Node.js via .NET ist das Basiselement einer Folie eine Form. Sie können diese Formelemente mit Aspose.Slides für Node.js via .NET formatieren:</p><p>- Position</p><p>- Größe</p><p>- Linie</p><p>- Füllung (einschließlich Muster, Verlauf, einfarbig)</p><p>- Text</p><p>- Bild</p>|
