Aspose.Slides for SharePoint ist eine Farmlösung für SharePoint 2007 bis 2019, die PowerPoint‑Präsentationen, die in Dokumentbibliotheken auf dem Server gespeichert sind, ohne Microsoft PowerPoint und ohne Code zu schreiben, konvertiert.

Sie konvertiert PPT‑ und PPTX‑Dateien in PDF, TIFF, XPS, HTML, SWF und ODP sowie in die PowerPoint‑Formate PPS, PPSX, PPTM, PPSM, POTX und POTM und speichert das Ergebnis in einer Dokumentbibliothek.

## **Ihr erster Export**

Aspose.Slides for SharePoint ist einmalig auf dem Farm installiert und dann von jeder Dokumentbibliothek aus nutzbar, in der es aktiviert ist:

1. Laden Sie das ZIP‑Archiv von der [Download‑Seite](https://releases.aspose.com/slides/sharepoint/) herunter und entpacken Sie es auf einem Server in Ihrer SharePoint‑Farm.
2. Führen Sie das Setup‑Programm aus, das zu Ihrer SharePoint‑Version passt: *Setup2007.exe*, *Setup2010.exe*, *Setup2013.exe*, *Setup2016.exe* oder *Setup2019.exe*. Verwenden Sie ein Konto, das SharePoint‑Lösungen installieren und bereitstellen kann. Akzeptieren Sie die Lizenzvereinbarung, wählen Sie die Websitesammlungen aus, in denen das Feature aktiviert werden soll, und lassen Sie das Setup die Lösung bereitstellen. Jeder Bildschirm wird in [Installation](/slides/de/sharepoint/installing-aspose-slides-for-sharepoint/) beschrieben.
3. Öffnen Sie eine Dokumentbibliothek in einer dieser Websitesammlungen, öffnen Sie das Menü einer PPT‑ oder PPTX‑Datei und wählen Sie **Convert via Aspose.Slides**. In SharePoint 2007 heißt das Menüelement **Convert with Aspose.Slides**.
4. Unter **Convert to** wählen Sie **PDF - Adobe Portable Document**. Ändern Sie bei Bedarf den Zieldateinamen und -ordner und klicken Sie auf **Convert**.
5. Wenn die Konvertierung abgeschlossen ist, klicken Sie auf **Destination Library**, um den Ordner zu öffnen, der die neue PDF‑Datei enthält.

Ohne Lizenz enthält die konvertierte Datei ein Evaluierungs‑Wasserzeichen — siehe [Lizenzierung](/slides/de/sharepoint/installing-aspose-slides-for-sharepoint-license/). Für dieselben Schritte mit Screenshots siehe [Konvertieren von Microsoft PowerPoint‑Dokumenten in andere Formate](/slides/de/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
