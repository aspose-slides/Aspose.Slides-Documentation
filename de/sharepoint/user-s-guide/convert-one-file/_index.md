Um eine Präsentation in einer Dokumentbibliothek zu konvertieren:

1. Öffnen Sie das Menü der PPT‑ oder PPTX‑Datei (ihr Edit Control Block) und wählen Sie **Convert via Aspose.Slides**. In SharePoint 2007 heißt das Menüelement **Convert with Aspose.Slides**.

   **Auswahl von Convert with Aspose.Slides im Menü eines Dokuments in SharePoint 2007**

   ![Das Menü eines Dokuments in einer SharePoint‑2007‑Dokumentbibliothek mit dem Eintrag Convert with Aspose.Slides](convert-one-file_1.png)

2. Wählen Sie auf der Konvertierungsseite das Ausgabeformat unter **Convert to** aus. Optional können Sie den Ziel‑Dateinamen und den Zielordner ändern.
3. Klicken Sie auf **Convert**.
4. Nachdem die Konvertierung abgeschlossen ist, klicken Sie auf **Source Library** oder **Destination Library**, um zur Dokumentbibliothek zurückzukehren. Die konvertierte Datei befindet sich im Zielordner.

Die gleichen Schritte mit Screenshots jeder Seite finden Sie in [Konvertieren von Microsoft PowerPoint‑Dokumenten in andere Formate](/slides/de/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
