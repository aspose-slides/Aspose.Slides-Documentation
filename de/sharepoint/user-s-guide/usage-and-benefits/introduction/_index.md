{{% alert color="info" title="Note" %}}

SharePoint-Websites dienen der Zusammenarbeit, Kommunikation und der Speicherung von Inhalten, um bestimmte Geschäftsanforderungen zu erfüllen. Sie ermöglichen einer Gruppe von Personen, ein gemeinsames Ziel zu erreichen, indem sie das Teilen von Informationen und die Kommunikation erleichtern. Die Informationen stehen meistens als Website zur Verfügung und werden über einen Webbrowser aufgerufen.

{{% /alert %}}

## **Was ist SharePoint und Aspose.Slides?**

Aspose.Slides für SharePoint ist eine Lösung zum Konvertieren von Microsoft PowerPoint-Präsentationen (PPT und PPTX) in andere Formate: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX und POTM. Sie ermöglicht das Konvertieren von PowerPoint-Dateien in einer SharePoint-Website, ohne Microsoft PowerPoint zu verwenden. Die vollständige Liste der Formate finden Sie unter [Unterstützte Dateiformate](/slides/de/sharepoint/supported-file-formats/).
