{{% alert color="info" title="Note" %}}

Der Evaluierungs‑Download von Aspose.Slides für SharePoint ist identisch mit dem gekauften Download. Er wird zur lizenzierten Version, wenn Sie das Lizenzlösungs‑Paket auf dem Farm installieren; siehe [Installation der Aspose.Slides für SharePoint Lizenz](/slides/de/sharepoint/installing-aspose-slides-for-sharepoint-license/). Es ist kein Code erforderlich.

Ohne Lizenz konvertiert Aspose.Slides für SharePoint in jedes unterstützte Format, aber die konvertierten Dateien tragen ein Evaluierungswasserzeichen, und die Konvertierungsseite zeigt einen Evaluierungshinweis.
