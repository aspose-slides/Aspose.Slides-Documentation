So deinstallieren Sie Aspose.Slides für SharePoint:

1. Führen Sie das Setup‑Programm aus, das Sie zur Installation verwendet haben, z. B. *Setup2019.exe* auf SharePoint Server 2019.  
   Erkennt es dieselbe bereits installierte Version, bietet das Setup‑Programm an, die Installation zu reparieren oder zu entfernen. Erkennt es eine andere Version, bietet es an, ein Upgrade durchzuführen oder zu entfernen.
2. Wählen Sie **Entfernen** und klicken Sie auf **Weiter**, um Aspose.Slides für SharePoint zu deinstallieren.
