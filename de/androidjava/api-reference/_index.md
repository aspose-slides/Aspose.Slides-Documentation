{{% alert color="info" %}}

Aspose.Slides for Android via Java ist eine Klassenbibliothek, die Java-Anwendungen für Android ermöglicht, Präsentationsdokumente zu lesen und zu schreiben, ohne Microsoft PowerPoint® oder andere Software zu verwenden. Aspose.Slides for Android via Java erlaubt Ihnen, Text, Formen, Tabellen und Animationen zu verwalten; Audio und Video zu Folien hinzuzufügen; Folienvorschauen zu erstellen; und Folien in SVG, PDF und weitere Formate zu exportieren.

Die aktuelle API-Referenz finden Sie unter [Aspose.Slides für Android via Java API-Referenz](https://reference.aspose.com/slides/de/androidjava/).

{{% /alert %}}
