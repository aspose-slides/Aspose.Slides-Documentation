## **Lizenzunterstützung**

Die Evaluierungsversion von Aspose.Slides for Reporting Services ist dasselbe Paket wie die erworbene Version, von seiner [Downloadseite](https://releases.aspose.com/slides/de/reportingservices/), und bietet dieselbe Funktionalität. Ohne Lizenz arbeitet sie im Evaluierungsmodus und fügt exportierten Präsentationen ein Evaluationswasserzeichen ein.

Die Evaluierungsversion wird lizenziert, wenn Sie eine Lizenzdatei auf den Bericht‑Server kopieren. Es ist kein Code erforderlich.

Wenn Sie mit Ihrer Evaluation zufrieden sind, können Sie eine [Lizenz erwerben](https://purchase.aspose.com/pricing/slides/de/reporting-services/). Wir empfehlen, die verschiedenen Abonnementtypen zu prüfen. Bei Fragen kontaktieren Sie das Aspose‑Vertriebsteam.

## **Lizenzierung in Aspose.Slides for Reporting Services**

* Die Lizenz ist eine reine Text‑XML‑Datei, die Details wie den Produktnamen, die Anzahl der lizenzierten Entwickler, das Ablaufdatum des Abonnements usw. enthält.
* Die Lizenzdatei ist digital signiert, daher dürfen Sie sie nicht verändern. Selbst das versehentliche Hinzufügen eines zusätzlichen Zeilenumbruchs zum Inhalt der Datei macht sie ungültig.

So wenden Sie die Lizenz an:

1. Kopieren Sie die Lizenzdatei in den *ReportServer\bin*-Ordner jeder Bericht‑Server‑Instanz, in dem *Aspose.Slides.ReportingServices.dll* installiert ist – zum Beispiel *C:\Program Files\Microsoft SQL Server Reporting Services\SSRS\ReportServer\bin*. [Manuell installieren](/slides/de/reportingservices/install-manually/#find-the-report-server-folder) listet die Standardordner auf.
2. Stellen Sie sicher, dass die Datei einen der von der Erweiterung erwarteten Namen hat: *Aspose.Slides.ReportingServices.lic*, *Aspose.Slides.Reporting.Services.lic*, *Aspose.Slides.Product.Family.lic*, *Aspose.Total.ReportingServices.lic*, *Aspose.Total.Reporting.Services.lic*, *Aspose.Total.Product.Family.lic* oder *Aspose.Total.lic*.
3. Exportieren Sie einen beliebigen Bericht als Präsentation. Wenn kein Wasserzeichen enthalten ist, ist die Lizenz aktiv.

Die Erweiterung sucht die Lizenzdatei außerdem in *%ProgramData%\Aspose\Slides* (normalerweise *C:\ProgramData\Aspose\Slides*), sodass eine Kopie dort jede Instanz auf dem Rechner bedient.

**Lizenzierter Modus**

Wenn eine gültige Lizenzdatei gefunden wird, enthalten exportierte Präsentationen kein Evaluationswasserzeichen.

![Ein Bericht, exportiert mit Lizenz: kein Evaluationswasserzeichen](license-aspose-slides-for-reporting-services_2.png)

**Evaluierungsmodus**

Ohne Lizenz fügt Aspose.Slides for Reporting Services ein Evaluationswasserzeichen in exportierte Präsentationen ein.

![Ein Bericht, exportiert im Evaluierungsmodus, mit dem Evaluationswasserzeichen](license-aspose-slides-for-reporting-services_1.png)
