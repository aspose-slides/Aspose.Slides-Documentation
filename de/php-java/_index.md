**Willkommen bei Aspose.Slides für PHP via Java**

![Aspose.Slides für PHP via Java Produktlogo](aspose_slides-for-php-via-java.png)

Aspose.Slides für PHP via Java ist eine Klassenbibliothek, die es Ihren Anwendungen ermöglicht, PowerPoint®‑Dokumente zu lesen und zu schreiben, ohne Microsoft PowerPoint® zu verwenden.

Aspose.Slides für PHP via Java ist die erste und einzige Komponente, die die Funktionalität zur Verwaltung von PowerPoint®‑Dokumenten bereitstellt.

Aspose.Slides für PHP via Java bietet zahlreiche Schlüssel‑Features wie die Verwaltung von Text, Formen, Tabellen und Animationen, das Hinzufügen von Audio und Video zu Folien, die Vorschau von Folien, den Export von Folien nach SVG, PDF und mehr.
