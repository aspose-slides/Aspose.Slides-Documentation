{{% alert color="info" title="Hinweis" %}}

Aspose.Slides for Python via Java ist eine Klassenbibliothek, die es Python‑Anwendungen ermöglicht, Präsentationen zu lesen und zu schreiben, ohne Microsoft PowerPoint® zu benötigen. Sie erlaubt das Verwalten von Text, Formen, Tabellen und Animationen; das Hinzufügen von Audio und Video zu Folien; die Vorschau von Folien; und den Export von Folien nach SVG, PDF und anderen Formaten.

Weitere Details finden Sie in der [Aspose.Slides for Python via Java API Reference](https://reference.aspose.com/slides/de/python-java/).
