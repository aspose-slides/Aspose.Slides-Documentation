## **Übersicht**

Aspose.Slides for Python via Java kann PowerPoint- und OpenDocument‑Präsentationen laden und sie ohne Microsoft PowerPoint, OpenOffice oder LibreOffice in viele andere Formate speichern oder rendern. Sie können veraltete PPT‑Dateien in das moderne PPTX‑Format konvertieren, Präsentationen in festformatige Dokumente wie PDF und XPS exportieren, Folien als HTML veröffentlichen oder Folien als Bilddateien für Vorschaubilder, Thumbnails und Archive rendern.

Die meisten Dokumentkonvertierungen folgen dem gleichen allgemeinen Workflow: Laden der Quelldatei, Auswahl des gewünschten Ausgabeformats und Anwendung format­spezifischer Optionen bei Bedarf. Für Bildformate wird jede Folie separat gerendert und dann als Raster‑ oder Vektor­bild gespeichert. Die unten verlinkten Artikel enthalten die Implementierungsdetails für die einzelnen Fälle.

## **PowerPoint- und OpenDocument-Konvertierung**

Aspose.Slides for Python via Java unterstützt die Konvertierung von häufig verwendeten Präsentationsformaten wie PPT, PPTX, PPS, PPSX, POT, POTX und ODP. Die gleiche Konvertierungs‑API wird für PowerPoint‑ und OpenDocument‑Dateien verwendet, sodass ein Workflow, der eine PPTX‑Datei zu PDF speichert, in der Regel auf eine ODP‑Datei angewendet werden kann, indem nur die Eingabedatei geändert wird.

Beim Konvertieren von ODP‑Dateien ist zu beachten, dass PowerPoint‑ und OpenDocument‑Anwendungen nicht jedes Layout‑ und Formatierungsmerkmal exakt gleich unterstützen. Wenn eine ODP‑Datei in LibreOffice oder OpenOffice Impress erstellt wurde, prüfen Sie die Ausgabe und verwenden Sie die in [OpenDocument‑Präsentationen konvertieren](/slides/de/python-java/convert-openoffice-odp/) beschriebenen Optionen, wenn Sie format­spezifische Hinweise benötigen.

## **PPT zu PPTX Konvertierung**

PPT ist das ältere binäre PowerPoint‑Format, während PPTX das moderne Office Open XML‑Format ist. Aspose.Slides for Python via Java unterstützt eine hochpräzise PPT‑zu‑PPTX‑Konvertierung und bewahrt dabei komplexe Präsentationsstrukturen wie Master, Layouts, Folien, Diagramme, gruppierte Formen, Platzhalter, Textfelder, Texturen und Bildfüllungen.

Weitere Details finden Sie unter [PPT zu PPTX konvertieren](/slides/de/python-java/convert-ppt-to-pptx/) und [PPT vs PPTX](/slides/de/python-java/ppt-vs-pptx/).

## **Export von Festlayout-Dokumenten**

PDF, XPS und TIFF sind nützlich, wenn die Ausgabe auf allen Geräten identisch aussehen und nicht als Präsentation bearbeitet werden soll. Die jeweiligen Artikel zu PDF, XPS und TIFF erklären, wie Sie Konformität, ausgeblendete Folien, Notizen, Bildqualität, Kompression, Pixelformat und Ausgabengröße steuern.

## **HTML- und Bildexport**

HTML‑ und HTML5‑Export sind für die Anzeige im Browser, Web‑Publikationen und leichtgewichtiges Teilen geeignet. Der Bild‑Export ist nützlich, wenn jede Folie zu einer separaten Vorschau, Miniaturansicht oder Raster‑Ressource werden soll. Verwenden Sie die PNG‑, JPG‑ und SVG‑Artikel für format­spezifische Rendering‑Hinweise.

## **FAQ**

**Brauche ich Microsoft PowerPoint, um Präsentationen zu konvertieren?**

Nein. Aspose.Slides für Python via Java ist eine eigenständige Bibliothek und benötigt weder Microsoft PowerPoint noch Office‑Automatisierung.

**Kann ich viele Präsentationen stapelweise konvertieren?**

Ja. Laden Sie jede Präsentation, speichern Sie sie im gewünschten Format und geben Sie das Präsentationsobjekt nach der Verarbeitung frei. Für Parallelverarbeitung verwenden Sie separate Präsentationsinstanzen und folgen Sie den [Multithreading](/slides/de/python-java/multithreading/)-Hinweisen.

**Kann ich nur ausgewählte Folien exportieren?**

Ja. Mehrere Exportmethoden ermöglichen das Übergaben von Folienindizes oder das Rendern einzelner Folien, je nach Ausgabeformat. Siehe den entsprechenden Artikel für das Ziel‑Format.

**Kann ich ausgeblendete Folien beim Export zu PDF oder XPS einbeziehen?**

Ja. Verwenden Sie die Export‑Einstellungen für ausgeblendete Folien, die in den [PDF](/slides/de/python-java/convert-powerpoint-to-pdf/)- und [XPS](/slides/de/python-java/convert-powerpoint-to-xps/)-Konvertierungsartikeln beschrieben sind.

**Kann ich PDF/A-Ausgabe erstellen?**

Ja. PDF‑Konformitätseinstellungen stehen für den PDF‑Export zur Verfügung. Siehe [PowerPoint zu PDF konvertieren](/slides/de/python-java/convert-powerpoint-to-pdf/) für Details.

**Wie werden Schriften während der Konvertierung behandelt?**

Aspose.Slides kann eingebettete Schriften, Schrift‑Fallback und Schrift‑Ersatz‑Einstellungen verwenden. Siehe [Eingebettete Schrift](/slides/de/python-java/embedded-font/), [Fallback‑Schrift](/slides/de/python-java/fallback-font/), und [Schrift‑Substitution](/slides/de/python-java/font-substitution/).
