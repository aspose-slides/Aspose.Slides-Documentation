## **Übersicht**

Aspose.Slides für Python via Java liest und schreibt PowerPoint‑ und OpenDocument‑Präsentationen. Außerdem importiert es PDF‑ und HTML‑Inhalte in Folien und exportiert Präsentationen oder einzelne Folien in Dokument‑, Web‑ und Bildformate.

Die Tabelle unten unterscheidet das Laden von Präsentationen vom Import von Inhalten und dem Rendern von Folien. Für einen Überblick über Bearbeitungs‑ und Rendering‑Funktionen siehe [Funktionsübersicht](/slides/de/python-java/features-overview/).

## **Import‑ und Export‑Hinweise**

- **PDF‑ und HTML‑Import:** Verwenden Sie [SlideCollection.addFromPdf](https://reference.aspose.com/slides/de/python-java/aspose.slides/slidecollection/#addfrompdf) oder [SlideCollection.addFromHtml](https://reference.aspose.com/slides/de/python-java/aspose.slides/slidecollection/#addfromhtml), um Folien aus dem Quellinhalt zu erstellen und einer Präsentation hinzuzufügen.
- **Präsentationsausgabe:** [SaveFormat](https://reference.aspose.com/slides/de/python-java/aspose.slides/saveformat/) listet die verfügbaren Speicherformate für Präsentationen, einschließlich separater Optionen für HTML‑ und HTML5‑Export.
- **Bildaussgabe:** Der Export einer Folie zu einem Bild erzeugt eine visuelle Darstellung dieser Folie. Die Spalte „Laden / Importieren“ beschreibt nicht, ob ein Bild in eine Präsentation eingefügt werden kann.

## **FAQ**

**Kann ich eine PPT‑Präsentation in PPTX oder ODP konvertieren?**

Ja. PPT wird als Eingabeformat unterstützt, PPTX und ODP als Ausgabeformate. Das Ergebnis der Konvertierung hängt von den in dem Zielformat verfügbaren Funktionen ab.

**Öffnet der PDF‑ oder HTML‑Import die Quelle als PowerPoint‑Datei?**

Nein. Der Import erzeugt Folien aus PDF‑Seiten bzw. HTML‑Inhalten. Anschließend können Sie die resultierende Präsentation in einem unterstützten Präsentationsformat speichern.

**Kann ich ein exportiertes PNG oder SVG als bearbeitbare Präsentation laden?**

Nein. Diese Exporte stellen das Aussehen der Folien dar. Bewahren Sie die Originalpräsentation, wenn Sie später Text, Formen, Diagramme und andere Objekte bearbeiten möchten.
