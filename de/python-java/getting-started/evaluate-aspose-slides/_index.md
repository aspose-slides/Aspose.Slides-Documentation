Sie können Aspose.Slides für Python via Java herunterladen, um seine Funktionen zu testen. Das Evaluierungspaket ist identisch mit dem lizenzierten Paket. Um es ohne Evaluierungsbeschränkungen zu verwenden, fügen Sie ein paar Codezeilen zu [eine Lizenz anwenden](/slides/de/python-java/licensing/) hinzu.

Die Evaluierungsversion von Aspose.Slides (ohne Lizenz verwendet) bietet die volle Produktfunktionalität, jedoch mit zwei Einschränkungen:

- Sie fügt jedem Folienblatt jeder Präsentation, die sie speichert, ein Evaluierungs‑Wasserzeichen‑Textfeld hinzu. Das Öffnen einer Präsentation fügt keines hinzu, aber das Speichern einer Datei, die bereits das Wasserzeichen trägt, fügt ein weiteres hinzu.
- Text, den Ihr Code liest, wird auf die ersten wenigen Zeichen gekürzt, gefolgt von einem Hinweis zur Evaluierungsbeschränkung. Dies gilt für jede Folie sowie für Text, den Ihr Code gerade gesetzt hat, und für aus einer Datei geladene Texte. Text, den Ihr Code schreibt, wird vollständig gespeichert.

{{% alert color="info" title="Note" %}}

Um Aspose.Slides ohne Evaluierungsbeschränkungen zu testen, können Sie eine **30‑tägige temporäre Lizenz** anfordern. Siehe [Temporäre Lizenz erhalten](https://purchase.aspose.com/temporary-license) für weitere Informationen.
