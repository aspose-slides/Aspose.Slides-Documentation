## **JasperReports**

Aspose.Slides für JasperReports funktioniert mit JasperReports 3.7.2 bis 6.16.0. Der Download enthält ein separates JAR für jeden der drei Versionsbereiche — siehe [Installing Aspose.Slides for JasperReports](/slides/de/jasperreports/installing-aspose-slides-for-jasperreports/) welches zu verwenden ist. Es gibt kein JAR für JasperReports 6.17.0 oder neuer, einschließlich JasperReports 7.

Die Unterstützung für JasperReports 2.0.3 bis 3.7.1 endete in Aspose.Slides für JasperReports 17.6. Version 17.5 und früher unterstützte ebenfalls diese Versionen.

## **Java**

Die JARs sind für Java 6 oder höher kompiliert, wie das *JDK 1.6* in ihren Ordnernamen sagt, daher ist die benötigte Java‑Version die, die Ihre JasperReports‑Version erfordert. Mit JasperReports 6.16.0 laufen Exporte auf Java 11, 17, 21 und 25.

## **Operating system**

Die JARs enthalten nur Java‑Klassen und -Ressourcen, ohne native Bibliotheken, und verwenden nicht Microsoft PowerPoint. Unter Linux benötigt JasperReports fontconfig und mindestens eine installierte Schriftart, um einen Bericht auszufüllen.

## **JasperReports Server**

Für JasperReports Server verwenden Sie beide JARs aus dem Ordner, der zur JasperReports‑Version Ihres Servers passt — siehe [Integration with JasperServer](/slides/de/jasperreports/integration-with-jasperserver/).
