Sie können Aspose.Slides for JasperReports zum Testen von der [Download-Seite](https://releases.aspose.com/slides/de/jasperreport/) herunterladen. Der Evaluierungsdownload ist identisch mit dem lizenzierten: Er wird lizenziert, sobald Sie eine Lizenz anwenden, wie in [Licensing](/slides/de/jasperreports/licensing/) beschrieben.

Ohne Lizenz exportieren die Exporter weiterhin jede Seite des Berichts, fügen jedoch ein Evaluierungswasserzeichen in der Mitte jeder Folie oder Seite ein. Das Wasserzeichen zeigt "Evaluation only.", "Created with Aspose.Slides for JasperReports" gefolgt von der Produktversion und einer Copyright-Zeile. Es erscheint in allen vier Ausgabeformaten: PPT, PPTX, PDF und HTML.

![Ein Bericht, der ohne Lizenz exportiert wurde, mit dem Evaluierungswasserzeichen in der Mitte der Folie](evaluate-aspose-slides_1.png)

{{% alert color="info" title="Hinweis" %}}
Um Aspose.Slides for JasperReports ohne das Evaluierungswasserzeichen zu testen, fordern Sie eine 30-tägige [temporäre Lizenz](https://purchase.aspose.com/temporary-license) an.
{{% /alert %}}
