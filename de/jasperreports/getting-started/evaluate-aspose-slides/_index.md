Sie können Aspose.Slides ganz einfach zum Testen herunterladen. Der Evaluationsdownload ist derselbe wie der gekaufte Download. Die Evaluationsversion wird einfach lizenziert, wenn Sie ein paar Codezeilen hinzufügen, um die Lizenz anzuwenden.

Die Evaluationsversion von Aspose.Slides (ohne angegebene Lizenz) bietet die volle Produktfunktionalität, fügt jedoch beim Öffnen und Speichern ein Evaluationswasserzeichen oben im Dokument ein und beschränkt beim Extrahieren des Textes aus Präsentationsfolien auf eine Folie.

Wenn Sie Aspose.Slides ohne die Einschränkungen der Evaluationsversion testen möchten, können Sie auch eine 30‑tägige temporäre Lizenz anfordern. Weitere Informationen finden Sie unter [Wie erhalten Sie eine temporäre Lizenz?](https://purchase.aspose.com/temporary-license)
