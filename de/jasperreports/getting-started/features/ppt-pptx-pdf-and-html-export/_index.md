{{% alert color="info" %}} 

JasperReports und JasperServer haben keine integrierten Möglichkeiten, Berichte als Microsoft PowerPoint‑Präsentationen zu exportieren, aber mit Aspose.Slides for JasperReports erhalten Sie Zugriff auf zusätzliche Exportformate:

- Microsoft PowerPoint‑Präsentation (PPT)
- Microsoft PowerPoint‑Präsentation (PPTX)
- HTML
- PDF

{{% /alert %}} 

Um Dokumente in diesen Formaten zu erstellen, verwendet Aspose.Slides for JasperReports eine eingebaute Version von [Aspose.Slides for Java](https://products.aspose.com/slides/de/java/), der marktführenden Bibliothek für die Verarbeitung von Präsentationen von Aspose. Microsoft PowerPoint wird nicht zur Erzeugung der Dokumente eingesetzt.
