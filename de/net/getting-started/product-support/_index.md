## **Übersicht**

Dieser Artikel erklärt, wie Sie Support für Aspose.Slides erhalten und Probleme effektiv melden können. Er beschreibt den wichtigsten Support‑Kanal, gibt Empfehlungen zum Einreichen eines Problems und verweist auf nützliche technische Ressourcen wie die Produktseite, den Blog, Downloads, das Support‑Forum, die Dokumentation und die API‑Referenz. Der Artikel beantwortet außerdem häufige Fragen zu kostenpflichtigem Support, Eskalation von Problemen und Support für ältere Bibliotheksversionen.

## **Technischer Support**
{{% alert color="info" %}}

Aspose bietet unbegrenzten kostenlosen technischen Support für alle seine Produkte. Der Support steht allen Benutzern zur Verfügung (einschließlich Benutzer von Evaluierungspaketen).

{{% /alert %}} 

Wenn Sie Hilfe zu Aspose.Slides für .NET benötigen, beachten Sie Folgendes:

- Der Hauptweg für Support ist das [Aspose.Forums](https://forum.aspose.com/c/slides/de/11). Stellen Sie Ihre Frage im Aspose.Slides‑Forum – sie wird innerhalb weniger Stunden beantwortet. Das Aspose.Slides‑Support‑Team beantwortet Fragen im Forum direkt.
- Bitte beachten Sie, dass Aspose keinen technischen Support per Telefon anbietet. Telefonischer Support ist nur für Verkaufs‑ und Kauffragen verfügbar.
- Wenn Sie auf eine Antwort im Forum warten, haben Sie Geduld und berücksichtigen Sie Zeitzonendifferenzen.

Wenn Sie ein Problem mit Aspose.Slides für .NET feststellen, folgen Sie diesen Richtlinien, um es möglichst effizient zu lösen:

- Prüfen und bestätigen Sie, dass Sie die neueste Version von Aspose.Slides für .NET verwenden, bevor Sie das Problem melden. Vielleicht wurde das von Ihnen erlebte Problem bereits in einem Update behoben.

  Siehe Aspose.Slides‑Download, um Informationen zur neuesten Version zu erhalten.

- Bevor Sie ein Problem melden, sollten Sie unsere Foren, diese Dokumentation und die API‑Referenz durchsuchen. Vielleicht wurde Ihre Frage bereits beantwortet.

- Beim Melden eines Problems fügen Sie bitte das Originaldokument und (wenn möglich) einen Codeausschnitt, der das Problem betrifft, bei. Wenn Sie mehrere Dateien anhängen müssen, packen Sie sie in ein ZIP‑Archiv.

  Sie können Ihre Dokumente sicher im Aspose.Forums anhängen, da **nur** Sie und Aspose‑Entwickler Zugriff auf die angehängten Dateien haben.

- Erstellen und verwenden Sie einen Thread für ein konkretes Problem. Wenn Sie ein weiteres Problem haben, müssen Sie einen neuen Thread erstellen, um es zu melden.

## **FAQ**

### Welche kostenpflichtigen Support‑Stufen gibt es und wie unterscheiden sie sich?

[Developer, Business und Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). Sie unterscheiden sich durch die Anzahl der enthaltenen Vorfälle, die Priorität der Antwort und die verfügbaren Kommunikationskanäle.

### Kann ich einen Bug direkt an das Engineering‑Team eskalieren?

Ja. [Kostenpflichtiger Support](https://helpdesk.aspose.com/) ermöglicht die Eskalation an die Entwickler, wenn ein Problem einer tieferen Untersuchung bedarf.

### Werden ältere Bibliotheksversionen unterstützt und werden für sie Korrekturen veröffentlicht?

Sie können ältere Versionen verwenden, aber Korrekturen werden nur für die aktuelle Version bereitgestellt; Patches für Legacy‑Versionen werden nicht veröffentlicht.
