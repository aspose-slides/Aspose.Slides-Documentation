## **Was ist OpenXML?**
OpenXML SDK ist ein .NET‑SDK von Microsoft, um Dateiformate von Microsoft Office 2007 und höher zu verarbeiten. Diese Dateiformate sind im Wesentlichen ZIP‑Pakete, und das Open XML SDK für Office vereinfacht das Arbeiten mit Open‑XML‑Paketen sowie den zugrunde liegenden Open‑XML‑Schemas innerhalb eines Pakets. Die Klassen im Open XML SDK kapseln viele gängige Aufgaben, die Entwickler mit Open‑XML‑Paketen ausführen, sodass Sie komplexe Vorgänge mit wenigen Codezeilen erledigen können.

Nachdem Sie das Open XML SDK 2.5 installiert haben, öffnen Sie Ihr bestehendes Projekt oder Ihre Anwendung in Visual Studio oder erstellen ein neues Projekt bzw. eine neue Anwendung. Fügen Sie dann in Ihrem Projekt oder Ihrer Anwendung Verweise auf die folgenden Komponenten hinzu:

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides für .NET**
Aspose.Slides für .NET ist eine einzigartige PowerPoint®‑Verwaltungskomponente, die .NET‑Anwendungen das Lesen, Schreiben und Manipulieren von PowerPoint‑Dokumenten ermöglicht, ohne Microsoft PowerPoint zu verwenden.

Aspose.Slides für .NET ist die erste und einzige .NET‑Komponente, die Funktionen zur Verwaltung von PowerPoint‑Dokumenten innerhalb Ihrer eigenen Anwendungen bereitstellt. Wie alle Aspose‑.NET‑Komponenten ist Aspose.Slides in verwaltetem C# geschrieben, erstaunlich preiswert und blitzschnell.

## **Einleitung**
Entwickler, die nach Bibliotheken für Dateiformate suchen, müssen die Funktionen der auf dem Markt verfügbaren Bibliotheken prüfen. Dabei werden hauptsächlich zwei Faktoren berücksichtigt:

- Funktionen
- Aufwand, der erforderlich ist, um die Bibliothek zu nutzen

Wenn Sie ein .NET‑Entwickler sind, der eine schnellere, einfachere und leichtgewichtige Bibliothek zur Verarbeitung von Dateien sucht, sollten Sie VSTO (Visual Studio‑Tool für Office) mit Aspose vergleichen. In diesem Fall hilft Ihnen dieses Projekt, die Funktionen und den Code beider Bibliotheken gegenüberzustellen.
