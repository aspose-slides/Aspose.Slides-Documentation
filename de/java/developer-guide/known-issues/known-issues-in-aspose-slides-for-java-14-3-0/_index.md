{{% alert color="info" title="Hinweis" %}}

Dies ist eine historische Seite. Sie listet die bekannten Probleme auf, die mit Aspose.Slides for Java 14.3.0 veröffentlicht wurden, und beschreibt nicht die aktuelle Version. Für die Änderungen in jeder Version siehe die [Release-Notizen](https://releases.aspose.com/slides/de/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) bietet eine völlig neue Implementierung der PPT-Verarbeitung. Es gibt viele Verbesserungen, teilweisen Konvertierung von PPTX zu PPT. Aber es gibt einige nicht implementierte Funktionen:

- Einige Formen haben in serialisierten PPT-Dokumenten falsche Geometrie (Call outs)
- Nicht alle PPTX-Textformatierungsfunktionen werden bei der PPT-Serialisierung unterstützt
- Informationen über Textsprache und Rechtschreibeinstellungen fehlen in serialisierten PPT-Dokumenten
- Nicht alle Funktionen von PPTX-Themes werden bei der PPT-Serialisierung unterstützt

**Es gibt einige Unterschiede im Vergleich zu Aspose.Slides for Java 8.6.0:**

- Es gibt bekannte Probleme bei der OLE/ActiveX PPT-Serialisierung zu PPT

**Es gibt einige Unterschiede im Vergleich zu Aspose.Slides for .NET 14.3.0:**

- Die Druckunterstützung für Präsentationen ist derzeit in Aspose.Slides for Java nicht verfügbar
