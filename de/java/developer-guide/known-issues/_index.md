## **Übersicht**

Dieser Abschnitt enthält keine Liste offener Probleme in der aktuellen Version. Er enthält drei Seiten:

- [Objektvorschau-Platzhalter beim Hinzufügen von OleObjectFrame](/slides/de/java/object-preview-issue-when-adding-oleobjectframe/) erklärt, warum ein mit Aspose.Slides hinzugefügtes OLE‑Objekt ein Bild mit der Aufschrift „EMBEDDED OLE OBJECT“ anzeigt, bis seine Vorschau aktualisiert wird, und wie Sie Ihr eigenes Vorschaubild festlegen können. Dies ist das vorgesehene Verhalten der aktuellen Version.
- [Bekannte Probleme in Aspose.Slides für Java 14.3.0 (Historisch)](/slides/de/java/known-issues-in-aspose-slides-for-java-14-3-0/) und [Bekannte Probleme in Aspose.Slides für Java 14.4.0 (Historisch)](/slides/de/java/known-issues-in-aspose-slides-for-java-14-4-0/) sind Listen, die mit diesen Versionen veröffentlicht wurden und zur Referenz aufbewahrt werden.

Für die Änderungen und Fehlerbehebungen in jeder Version siehe die [Versionshinweise](https://releases.aspose.com/slides/de/java/release-notes/). Die Metadatenfelder, die Aspose.Slides mit festen Werten schreibt, werden in [Einschränkungen der Ausgabe‑Metadaten](/slides/de/java/api-limitations/) beschrieben. Um zu prüfen, ob ein Problem bereits bekannt ist, oder um eines zu melden, nutzen Sie das [Support‑Forum](https://forum.aspose.com/c/slides/de/11).
