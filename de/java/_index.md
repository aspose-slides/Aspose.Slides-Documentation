**Willkommen bei Aspose.Slides für Java!**

Aspose.Slides für Java ist eine Microsoft PowerPoint®-Verwaltungs‑API, die es Java‑Anwendungen ermöglicht, PowerPoint®‑Dokumente ohne Microsoft PowerPoint® zu lesen und zu schreiben. Aspose.Slides für Java ist die erste und einzige Komponente, die die Funktionalität zur Verwaltung von PowerPoint®‑Dokumenten bereitstellt. Aspose.Slides für Java bietet zahlreiche wichtige Funktionen, wie die Verwaltung von Text, Formen, Tabellen & Animationen, das Hinzufügen von Audio & Video zu Folien, die Vorschau von Folien, den Export von Folien nach SVG, PDF und anderen Formaten.
