## **Übersicht**

Dieser Artikel beschreibt einen Lizenzierungsfehler, der in Aspose.Slides for Java Versionen 23.2, 23.3, 23.4, 23.5, 23.6 und 23.7 aufgetreten ist. Dieser Fehler führte dazu, dass unbefristete Lizenzen nach Ablauf ihres Abonnements vorübergehend nicht mehr nutzbar waren.

## **Symptome**

Nach Ablauf Ihres unbefristeten Lizenzabonnements können Aspose.Slides for Java Versionen 23.2 – 23.7 die Lizenz als abgelaufen melden und alle Funktionen in den Bewertungsmodus schalten.
Dieses Verhalten ist falsch und betrifft nicht Versionen vor 23.2 und nach 23.7.

## **Lösung**

Aspose.Slides for Java hat dieses Problem behoben und aktualisierte Versionen (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) veröffentlicht.

Wenn Sie eine der betroffenen Versionen von Aspose.Slides for Java in Ihrem Projekt verwenden, wechseln Sie bitte zur korrigierten Version.

Bitte beachten Sie, dass dieser Fehler nur Aspose.Slides for Java Versionen 23.2 bis 23.7 betrifft. **Andere Aspose‑Produkte und andere Versionen von Aspose.Slides sind nicht betroffen**.
