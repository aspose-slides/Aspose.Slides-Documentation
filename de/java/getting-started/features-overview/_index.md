## **Unterstützte Plattformen**
Aspose.Slides for Java unterstützt die beliebtesten Entwicklungs- und Bereitstellungsplattformen.

|**Funktion**|**Beschreibung**|
| :- | :- |
|Desktop‑Anwendungen|Aspose.Slides for Java kann verwendet werden, um Windows Forms‑Anwendungen zu entwickeln.|
|Unternehmens‑Webanwendungen|Mit Aspose.Slides for Java lässt sich die Erstellung von Web‑Anwendungen unterstützen. Unterstützung für die Verwendung von Aspose.Slides for Java mit PHP ist ebenfalls enthalten.|
|Linux/Unix|Aspose.Slides for Java ist eine plattformunabhängige API und kann in Linux‑ und Unix‑Umgebungen arbeiten.|

## **Dateiformate und Konvertierungen**

|**Funktion**|**Beschreibung**|
| :- | :- |

## **Inhalts‑Funktionen**

|**Funktion**|**Beschreibung**|
| :- | :- |
|Master‑Folien|Die Master‑Folien definieren das Layout der normalen Folien. Aspose.Slides for Java ermöglicht den Zugriff auf und die Änderung der Master‑Folien einer Präsentation.|
|Normale Folien|Mit Aspose.Slides for Java können Sie nicht nur neue Folien verschiedener Typen erstellen, sondern auch vorhandene Folien zugreifen und ändern.|
|Klonen / Kopieren von Folien|Aspose.Slides for Java bietet Methoden zum Klonen oder Kopieren vorhandener Folien, nicht nur innerhalb einer Präsentation, sondern auch von einer Präsentation zur anderen. Da eine Folie ihr Layout vom Master‑Slide erbt, kopieren die integrierten Klonmethoden den Master automatisch beim Klonen.|
|Verwalten von Folienabschnitten|Möglichkeit, Folien in verschiedene Abschnitte innerhalb einer Präsentation zu organisieren.|
|Platzhalter und Textplatzhalter|Zugriff auf Platzhalter und Textplatzhalter in einer Folie. Darüber hinaus können Sie mit der entsprechenden Methode eine Folie mit Textplatzhaltern von Grund auf neu erstellen.|
|Kopf‑ und Fußzeilen|Aspose.Slides for Java erleichtert ebenfalls die Handhabung von Kopf‑/Fußzeilen in den Folien.|
|Notizen in Folien|Mit Aspose.Slides for Java können Sie nicht nur auf Notizen einer Folie zugreifen und diese ändern, sondern auch Notizen hinzufügen.|
|Eine Form finden|Sie können eine bestimmte Form auf einer Folie anhand des alternativen Textes der Form finden.|
|Hintergründe|Aspose.Slides for Java ermöglicht die Arbeit mit dem Hintergrund, der einem Master‑ oder normalen Slide zugeordnet ist.|
|Textfelder|Textfelder können von Grund auf neu erstellt werden. Auf vorhandene Textfelder kann zugegriffen werden und deren Text kann geändert werden, ohne das ursprüngliche Textformat zu verlieren.|
|Rechteckformen|Rechteckformen können von Aspose.Slides for Java erstellt oder geändert werden.|
|Polylinienformen|Polylinienformen können ebenfalls von Aspose.Slides for Java erstellt oder geändert werden.|
|Ellipsenformen|Ellipsenformen können ebenfalls von Aspose.Slides for Java erstellt oder geändert werden.|
|Gruppenformen|Aspose.Slides for Java unterstützt Gruppenformen.|
|Autoformen|Autoformen werden ebenfalls von Aspose.Slides for Java unterstützt.|
|SmartArt|Unterstützung für SmartArt‑Formen, die in MS PowerPoint verfügbar sind.|
|Diagramme|Unterstützung für von PowerPoint unterstützte MSO‑Diagramme.|
|Bildrahmen|Bilder werden in Bildrahmen mit Aspose.Slides for Java verwaltet.|
|Audio‑Frames|Audiodateien können in Folien in Audio‑Frames von Aspose.Slides for Java verlinkt oder eingebettet werden.|
|Video‑Frames|Videodateien werden in Video‑Frames durch Aspose.Slides for Java verarbeitet. Unterstützung für verlinkte sowie eingebettete Videos ist verfügbar.|
|OLE‑Frame|OLE‑Objekte werden in OLE‑Frames von Aspose.Slides for Java verwaltet.|
|ActiveX‑Steuerelemente|Unterstützung für ActiveX‑Steuerelemente ist verfügbar.|
|VBA‑Makros|Unterstützung für die Verwaltung von VBA‑Makros innerhalb einer Präsentation.|
|Tabellen|Tabellen auf Folien werden ebenfalls von Aspose.Slides for Java unterstützt.|
|Text‑Frame|Der Text, der zu einer Form gehört, kann über den zu dieser Form zugehörigen Text‑Frame abgerufen werden.|
|Text‑Scannen|Text in einer Präsentation kann auf Präsentations‑ oder Folienebene mittels integrierter Scan‑Methoden gescannt werden.|

## **Formatierungs‑Funktionen**
Es ist möglich, Text und Formen auf Folien in einem Präsentationsdokument mit Aspose.Slides for Java zu formatieren.

|**Funktion**|**Beschreibung**|
| :- | :- |
|Textformatierung|<p>In Aspose.Slides for Java wird Text über Textframes verwaltet, die mit Formen verknüpft sind. Daher wird Text über Absätze und Abschnitte formatiert, die den Textframes zugeordnet sind. Die folgenden Textelemente können formatiert werden.</p><p>- Schriftart.</p><p>- Schriftgröße.</p><p>- Schriftfarbe.</p><p>- Schriftfarbnuancen.</p><p>- Absatzausrichtung.</p><p>- Aufzählungszeichen im Absatz.</p><p>- Absatzorientierung.</p>|
|Formformatierung|<p>In Aspose.Slides for Java ist das Basiselement einer Folie die Form. Die folgenden Form‑Elemente können mit Aspose.Slides for Java formatiert werden:</p><p>- Position</p><p>- Größe</p><p>- Linie</p><p>- Füllung (einschließlich Muster, Farbverlauf und einfarbig).</p><p>- Text</p><p>- Bild</p>|

## **FAQ**

### Muss ich Microsoft PowerPoint auf dem Server/PC installieren, damit die Bibliothek funktioniert?
Nein. PowerPoint ist nicht erforderlich; Aspose.Slides ist eine eigenständige Engine zum Erstellen, Bearbeiten, Konvertieren und Rendern von Präsentationen.

### Wie funktioniert Multithreading? Kann die Verarbeitung parallelisiert werden?
Es ist sicher, unterschiedliche Dokumente in verschiedenen Threads zu verarbeiten; dasselbe [Präsentation](https://reference.aspose.com/slides/de/java/com.aspose.slides/presentation/)‑Objekt darf nicht gleichzeitig von [mehreren Threads](/slides/de/java/multithreading/) verwendet werden.

### Werden Dateipasswörter und Verschlüsselung unterstützt?
Ja. [Sie können](/slides/de/java/password-protected-presentation/) verschlüsselte Präsentationen öffnen, ein Öffnungs‑ und Schreibpasswort setzen oder entfernen und den Schutzstatus prüfen.

### Muss ich mich um Schriftpakete in Linux‑Containern kümmern?
Ja. Es wird empfohlen, gängige Schriftpakete zu installieren und/oder in Ihrer Anwendung ausdrücklich [Schriftverzeichnisse anzugeben](/slides/de/java/custom-font/), um unerwartete Ersetzungen zu vermeiden.

### Gibt es Einschränkungen in der Evaluierungs‑Version?
Im [Evaluierungsmodus](/slides/de/java/licensing/) wird dem Ergebnis ein Wasserzeichen hinzugefügt und bestimmte Einschränkungen gelten; eine [30‑tägige temporäre Lizenz](https://purchase.aspose.com/temporary-license/) steht für Tests mit vollem Funktionsumfang zur Verfügung.

### Wird das Importieren externer Formate in eine Präsentation (PDF/HTML → PPTX) unterstützt?
Ja. Sie können [PDF‑Seiten und HTML‑Inhalte](/slides/de/java/import-presentation/) zu einer Präsentation hinzufügen und sie in Folien umwandeln.
