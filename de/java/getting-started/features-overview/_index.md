## **Übersicht**

Aspose.Slides for Java ist eine Klassenbibliothek zum Erstellen, Lesen, Bearbeiten, Konvertieren und Rendern von PowerPoint- und OpenDocument-Präsentationen. Sie hat keine eigene Benutzeroberfläche und erfordert weder Microsoft PowerPoint noch Microsoft Office. Dieser Artikel fasst zusammen, was die Bibliothek abdeckt, und enthält Links zu den Artikeln, die jeden Bereich beschreiben.

## **Unterstützte Plattformen**

Aspose.Slides for Java ist eine einzelne JAR‑Datei, die im Maven‑Repository von Aspose mit dem Klassifizierer `jdk16` veröffentlicht wird. Sie ist in reinem Java geschrieben: Die JAR‑Datei enthält keine nativen Bibliotheken und hängt von keinen anderen Paketen ab.

- **Java:** Java 8 oder höher. Aspose.Slides for Java 26.9 und frühere Versionen laufen auch unter Java 6 und 7, welche Version 26.10 nicht mehr unterstützt; siehe die [26.9 release notes](https://releases.aspose.com/slides/de/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/).
- **Betriebssysteme:** jedes Betriebssystem mit einer Java‑Laufzeit, z. B. Windows, Linux und macOS. Unter Linux müssen die fontconfig‑Bibliothek und mindestens eine Schriftart installiert sein.

[Installation](/slides/de/java/installation/) zeigt, wie die Bibliothek zu einem Projekt hinzugefügt wird und listet die Linux‑Voraussetzungen auf. [System Requirements](/slides/de/java/system-requirements/) listet die unterstützten Plattformen im Detail auf.

## **Dateiformate und Konvertierungen**

Aspose.Slides öffnet und speichert PPT, PPTX, PPS, POT, PPSX, POTX, PPTM, PPSM, POTM, ODP, OTP, FODP und PowerPoint‑XML‑Präsentationen. Es importiert PDF‑ und HTML‑Inhalte in Folien und speichert Präsentationen als PDF, XPS, HTML, HTML5, TIFF, animiertes GIF, SWF, Markdown und XAML. [Supported File Formats](/slides/de/java/supported-file-formats/) listet jedes Format zusammen mit der API auf, die es liest oder schreibt.

## **Präsentations‑Rendering**

Aspose.Slides rendert Folien und einzelne Formen als PNG-, JPEG-, BMP-, GIF-, TIFF‑ und SVG‑Bilder sowie Folien als EMF‑Metadateien. Siehe [Präsentationsfolien in Bilder konvertieren](/slides/de/java/convert-slide/), [Präsentationsfolien als SVG‑Bilder rendern](/slides/de/java/render-a-slide-as-an-svg-image/) und [Miniaturansichten von Präsentationsformen erstellen](/slides/de/java/create-shape-thumbnails/).

## **FAQ**

**Muss ich Microsoft PowerPoint auf dem Server oder PC installieren, damit die Bibliothek funktioniert?**

Nein. PowerPoint ist nicht erforderlich; Aspose.Slides ist eine eigenständige Engine zum Erstellen, Bearbeiten, Konvertieren und Rendern von Präsentationen.

**Wie funktioniert Multithreading? Kann die Verarbeitung parallelisiert werden?**

Es ist sicher, verschiedene Dokumente in unterschiedlichen Threads zu verarbeiten; das gleiche [Presentation](https://reference.aspose.com/slides/de/java/com.aspose.slides/presentation/)‑Objekt darf nicht gleichzeitig von [mehreren Threads](/slides/de/java/multithreading/) verwendet werden.

**Werden Dateipasswörter und Verschlüsselung unterstützt?**

Ja. [Sie können](/slides/de/java/password-protected-presentation/) verschlüsselte Präsentationen öffnen, ein Öffnungs‑ und Schreibpasswort setzen oder entfernen und den Schutzstatus überprüfen.

**Muss ich mich um Schriftarten in Linux‑Containern kümmern?**

Ja. Unter Linux müssen die fontconfig‑Bibliothek und mindestens eine Schriftart installiert sein, und die in Ihren Präsentationen verwendeten Schriftarten bzw. geeignete Ersatzschriften müssen installiert sein, damit Text korrekt dargestellt wird. Sie können außerdem in Ihrer Anwendung [Schriftarten‑Verzeichnisse angeben](/slides/de/java/custom-font/). Siehe [Installation](/slides/de/java/installation/#linux).

**Gibt es Einschränkungen in der Evaluierungs‑Version?**

Ja. Ohne eine [Lizenz](/slides/de/java/licensing/) fügt Aspose.Slides jedem gespeicherten Folien ein Evaluierungs‑Wasserzeichen hinzu und kürzt Text, den Ihr Code über die API liest. Eine [30‑tägige temporäre Lizenz](https://purchase.aspose.com/temporary-license/) steht für Tests mit allen Funktionen zur Verfügung.

**Wird das Importieren externer Formate in eine Präsentation (PDF oder HTML zu PPTX) unterstützt?**

Ja. Sie können [PDF‑Seiten und HTML‑Inhalte](/slides/de/java/import-presentation/) zu einer Präsentation hinzufügen, die dann in Folien umgewandelt werden.
