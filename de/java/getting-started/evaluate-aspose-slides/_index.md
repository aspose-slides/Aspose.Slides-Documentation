## **Aspose.Slides Evaluation**

Sie können Aspose.Slides zur Evaluation herunterladen. Der Evaluierungs‑Download ist identisch mit dem erworbenen Download; er wird lizenziert, nachdem Sie ein paar Codezeilen hinzugefügt haben, um die Lizenz anzuwenden.

Ohne Lizenz stellt Aspose.Slides seine volle Funktionalität im Evaluierungsmodus bereit, jedoch mit zwei Einschränkungen: Es fügt jedem Folieninhalt jeder gespeicherten Präsentation ein Wasserzeichen‑Textfeld hinzu, und Text, den Ihr Code über die API liest, einschließlich Text, den er gerade gesetzt hat, wird auf die ersten Zeichen gekürzt und mit einem Hinweis auf die Evaluierungsbeschränkung versehen. Text, den Ihr Code schreibt, wird vollständig gespeichert. Die Methode [getPresentationText](https://reference.aspose.com/slides/de/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) , die Text extrahiert, ohne die gesamte Präsentation zu laden, gibt nur Evaluierungshinweise und keinen Folientext zurück.

## **FAQ**

### Kann ich mehrere Präsentationen parallel über verschiedene Threads im Evaluierungsmodus testen?

Ja. Sie können verschiedene Dokumente parallel verarbeiten; Sie sollten dasselbe Präsentationsobjekt nicht [über Threads](/slides/de/java/multithreading/) gemeinsam nutzen. Der Evaluierungsmodus hat darauf keinen Einfluss.

### Muss ich Microsoft PowerPoint installieren, um die Bibliothek auf einem Server oder in CI zu evaluieren?

Nein. Aspose.Slides ist eine eigenständige Engine und erfordert weder für die Evaluation noch für die Produktion die Installation von PowerPoint.

### Kann ich die Konvertierung von PPT/PPTX nach PDF und Bildern im Evaluierungsmodus vollständig testen?

Ja. Die [Konverter](/slides/de/java/convert-presentation/) funktionieren; die Ausgabe enthält ein Wasserzeichen.

### Kann ich eine temporäre Lizenz für Load‑Testing ohne Wasserzeichen verwenden?

Ja. Eine 30‑tägige temporäre Lizenz entfernt die Einschränkungen des Evaluierungsmodus und ermöglicht Tests ohne Wasserzeichen.
