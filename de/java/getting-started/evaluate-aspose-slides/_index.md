## **Aspose.Slides Testversion**

Sie können Aspose.Slides ganz einfach zum Test herunterladen. Der Test‑Download ist identisch mit dem käuflich erworbenen Download. Die Testversion wird einfach lizenziert, wenn Sie ein paar Codezeilen hinzufügen, um die Lizenz anzuwenden.

Die Testversion von Aspose.Slides (ohne angegebene Lizenz) bietet die volle Funktionsfähigkeit des Produkts, fügt jedoch beim Öffnen und Speichern ein Evaluierungs‑Wasserzeichen oben im Dokument ein und beschränkt die Textextraktion aus den Präsentationsfolien auf eine Folie.

## **FAQ**

### Kann ich mehrere Präsentationen parallel über verschiedene Threads im Testmodus testen?
Ja. Sie können verschiedene Dokumente parallel verarbeiten; Sie sollten das gleiche Präsentationsobjekt nicht [über Threads](/slides/de/java/multithreading/) teilen. Der Testmodus hat darauf keinen Einfluss.

### Muss ich Microsoft PowerPoint installieren, um die Bibliothek auf einem Server oder in CI zu evaluieren?
Nein. Aspose.Slides ist eine eigenständige Engine und erfordert keine Installation von PowerPoint, weder für die Evaluation noch für die Produktion.

### Kann ich die Konvertierung von PPT/PPTX nach PDF und Bildern im Testmodus vollständig testen?
Ja. Die [Konverter](/slides/de/java/convert-presentation/) funktionieren; die Ausgabe enthält ein Wasserzeichen.

### Kann ich eine temporäre Lizenz für Belastungstests ohne Wasserzeichen verwenden?
Ja. Eine 30‑tägige temporäre Lizenz entfernt die Beschränkungen des Testmodus und ermöglicht Tests ohne Wasserzeichen.
