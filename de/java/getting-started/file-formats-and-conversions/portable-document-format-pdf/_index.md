{{% alert color="info" %}}

Das [Portable Document Format](https://en.wikipedia.org/wiki/PDF) ist ein Dateiformat, das von Adobe Systems erstellt wurde, um Dokumente zwischen Organisationen auszutauschen. Der Zweck des Formats war es, Inhalt und Layout unverändert zu lassen, unabhängig von der Plattform, auf der es angezeigt wird. Aspose.Slides for Java ermöglicht die Konvertierung von Präsentationsdateien in PDF.

{{% /alert %}}

## **PDF in Aspose.Slides for Java**
Jede Präsentation, die in Aspose.Slides for Java geladen werden kann, lässt sich in ein PDF konvertieren, das je nach Auswahl dem [PDF 1.5](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) oder [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) entspricht. Aspose.Slides for Java exportiert Präsentationen nach PDF und in den meisten Fällen sieht das erzeugte PDF exakt wie die ursprüngliche Präsentation aus.

Aspose.Slides unterstützt beim Konvertieren nach PDF die folgenden Präsentationsfunktionen:

- Bilder, Textfelder und andere Formen.
- Text und Formatierung.
- Absätze und Formatierung.
- Hyperlinks.
- Kopf- und Fußzeilen.
- Aufzählungszeichen.
- Tabellen.

Sie können Präsentationen direkt mit Aspose.Slides for Java in PDFs exportieren: Sie benötigen keine weitere Komponente. Außerdem können Sie den Export von Präsentationen nach PDF mit verschiedenen Optionen anpassen, wie im Abschnitt [Konvertieren nach PDF](/slides/de/java/converting-a-presentation/) erläutert.
