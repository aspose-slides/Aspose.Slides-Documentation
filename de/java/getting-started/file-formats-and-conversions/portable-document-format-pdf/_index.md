{{% alert color="info" title="Hinweis" %}}

Das Portable Document Format (PDF) ist ein Dateiformat, das von Adobe Systems zur Übertragung von Dokumenten zwischen Organisationen erstellt wurde. Ziel des Formats war es, Inhalt und Layout unverändert zu behalten, unabhängig von der Plattform, auf der es angezeigt wird. Aspose.Slides for Java ermöglicht das Konvertieren von Präsentationsdateien in PDF.

{{% /alert %}}

## **PDF in Aspose.Slides for Java**
Jede Präsentation, die in Aspose.Slides for Java geladen werden kann, lässt sich in ein PDF konvertieren, das je nach Auswahl den Standards [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) oder [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) entspricht. Aspose.Slides for Java exportiert Präsentationen nach PDF und in den meisten Fällen sieht das erzeugte PDF exakt wie die Originalpräsentation aus.

Aspose.Slides unterstützt beim PDF‑Export die folgenden Präsentations‑Features:

- Bilder, Textfelder und andere Formen.
- Text und Formatierung.
- Absätze und Formatierung.
- Hyperlinks.
- Kopf‑ und Fußzeilen.
- Aufzählungszeichen.
- Tabellen.

Sie können Präsentationen mit Aspose.Slides for Java direkt in PDFs exportieren: Sie benötigen keine weitere Komponente. Außerdem können Sie den Export von Präsentationen nach PDF mit verschiedenen Optionen anpassen, wie in [Convert PPT and PPTX to PDF](/slides/de/java/convert-powerpoint-to-pdf/) beschrieben.
