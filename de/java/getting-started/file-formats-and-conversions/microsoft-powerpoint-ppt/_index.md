{{% alert color="info" title="Note" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) ist das Präsentationsdokumentdateiformat, das von verschiedenen Versionen von Microsoft PowerPoint erstellt, gelesen, bearbeitet und geschrieben werden kann. Dies ist das binäre Format für Präsentationsdokumente, das von Microsoft entwickelt wurde.

{{% /alert %}}

## **PPT in Aspose.Slides für Java**
Aspose.Slides für Java kann PPT-Dateien lesen, die mit der unten aufgeführten Software erstellt wurden.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Ebenso können PPT-Dateien, die von Aspose.Slides für Java erstellt wurden, von der oben genannten Software gelesen werden.

## **Umfassende Unterstützung für PPT**
Aspose.Slides für Java bietet Unterstützung für fast alle Funktionen, die vom PPT-Dokumentdateiformat unterstützt werden. Es deckt nicht nur die Basis‑ und erweiterten Funktionen ab, die von den verschiedenen Microsoft‑PowerPoint‑Versionen für PPT‑Dokumentmanipulationen bereitgestellt werden, sondern auch Funktionen, die von Microsoft PowerPoint nicht einmal unterstützt werden. Der Hauptvorteil der Verwendung der Aspose.Slides für Java API‑Bibliothek ist die einfache Handhabung solcher Funktionen.

Zusätzlich zu den grundlegenden Aufgaben im Zusammenhang mit dem Erstellen, Lesen und Schreiben von PPT‑Dokumentdateien bietet Aspose.Slides für Java mehrere Funktionen:

- Importieren anderer Microsoft‑Office‑Dateiformate als [OLE objects into PPT documents](/slides/de/java/manage-ole/).
- [Exportieren von PPT‑Dokumenten nach PDF](/slides/de/java/convert-powerpoint-to-pdf/).
- Exportieren von Folien in den PPT‑Dokumenten in SVG‑Formate.
- Rendern von Folien in jedes Bildformat, das vom Java‑Framework unterstützt wird.
- Festlegen der Größe von Folien in PPT‑Dokumenten.
- Verwalten von Animationen auf Formen.
- Verwalten von Bildschirmpräsentationen.
- [Formatieren von Text auf Folien](/slides/de/java/text-formatting/).
- Extrahieren von Text aus PPT‑Dokumenten.
- [Umgang mit Tabellen auf Folien](/slides/de/java/powerpoint-table/).
- Automatisches Kopieren von Masterfolien mithilfe der [the cloning feature](/slides/de/java/clone-slides/).
