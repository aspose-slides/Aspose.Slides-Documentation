Die PPT-zu-PPTX-Konvertierung wird von Aspose.Slides für Java unterstützt. Die meisten Präsentationsfunktionen – Masterfolien, Struktur usw. – bleiben erhalten, wenn sie von einem Format ins andere konvertiert werden, es gibt jedoch [einige Einschränkungen](/slides/de/java/ppt-to-pptx-conversion/).

{{% /alert %}} 
## **Unterstützte Funktionen bei der Konvertierung**
Aspose.Slides für Java bietet teilweisen Support für die Konvertierung des PPT-Dateiformats in PPTX. Die Unterstützung für die Konvertierung wurde erst kürzlich in Aspose.Slides für Java eingeführt, daher gibt es einige Einschränkungen und sie funktioniert am besten bei einfachen Präsentationen. Der Hauptvorteil, den Aspose.Slides für Java bei der Konvertierung von PPT zu PPTX bietet, ist die einfache Handhabung der API. Um Codebeispiele zu sehen, lesen Sie über [Konvertierung von PPT zu PPTX](). Im Folgenden erklären Listen, welche Funktionen bei der PPT‑zu‑PPTX‑Konvertierung unterstützt werden und welche nicht.

## **Unterstützte Funktionen**
The following features are supported for conversion:

- Konvertierung der Struktur von Masterfolien, Layouts und Folien.
- Konvertierung von Diagrammen.
- Gruppierte Formen.
- Konvertierung von Autoformen, einschließlich Rechtecken und Ellipsen. 
- Formen mit benutzerdefinierter Geometrie.
- Textur‑ und Bildfüllstile für Autoformen.
- Konvertierung von Platzhaltern.
- Konvertierung von Linien und Polylinien.
- Linien‑ und Füllformate.
- Verlaufsfüllstile.
- OLE‑Frames, Tabellen, Video‑ und Audio‑Frames usw.
- Animations‑ und Vorführungs‑Eigenschaften.
- Konvertierung von Text in Textfeldern und Textcontainern.
