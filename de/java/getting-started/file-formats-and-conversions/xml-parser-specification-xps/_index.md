{{% alert color="info" %}} 

Die [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) ist eine Seitenbeschreibungssprache und ein Fixed-Document-Format, das ursprünglich von Microsoft entwickelt wurde. Wie PDF ist XPS darauf ausgelegt, die Dokumenttreue zu erhalten und ein geräteunabhängiges Erscheinungsbild des Dokuments zu gewährleisten. 

{{% /alert %}} 

## **XPS in Aspose.Slides für Java**
Jedes Präsentationsdokument, das von Aspose.Slides für Java geladen werden kann, lässt sich in das XPS-Format konvertieren. Aspose.Slides für Java verwendet die hochpräzise Seitenlayout‑ und Rendering‑Engine, um Ausgaben im festgelegten XPS‑Dokumentenlayout zu erzeugen.
Weitere Informationen zum Exportieren von Präsentationsdokumenten in XPS‑Dokumente über Aspose.Slides für Java finden Sie unter [Konvertieren zu XPS](https://docs.aspose.com/slides/de/java/convert-powerpoint-to-xps/).
