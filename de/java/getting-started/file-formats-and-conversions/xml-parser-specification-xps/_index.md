{{% alert color="info" title="Note" %}}

Die [XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) ist eine Seitenbeschreibungssprache und ein festes Dokumentenformat, das ursprünglich von Microsoft entwickelt wurde. Wie PDF ist XPS darauf ausgelegt, die Dokumententreue zu erhalten und ein geräteunabhängiges Dokumentenlayout zu bieten.

{{% /alert %}}

## **XPS in Aspose.Slides for Java**
Jedes Präsentationsdokument, das von Aspose.Slides for Java geladen werden kann, kann in das XPS‑Format konvertiert werden. Aspose.Slides for Java verwendet die hochpräzise Seitenlayout‑ und Rendering‑Engine, um Ausgaben im festgelegten XPS‑Dokumentenformat zu erzeugen. Informationen zum Exportieren von Präsentationsdokumenten in XPS‑Dokumente mit Aspose.Slides for Java finden Sie in [PowerPoint‑Präsentationen in XPS konvertieren](/slides/de/java/convert-powerpoint-to-xps/).
