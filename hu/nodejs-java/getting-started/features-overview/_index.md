## **Támogatott platformok**
Aspose.Slides for Node.js via Java egy platformfüggetlen API. Bármilyen platformon használható (Windows, Linux, macOS stb.), ahol a Node.js 7 vagy újabb telepítve van. Az Oracle JDK 8 vagy újabb szintén követelmény.

## **FAQ**

### Szükséges-e a Microsoft PowerPoint telepítése a szerveren/PC-n a könyvtár működéséhez?
No. A PowerPoint nem szükséges; az Aspose.Slides egy önálló motor a prezentációk létrehozásához, szerkesztéséhez, konvertálásához és rendereléséhez.

### Hogyan működik a több szálas feldolgozás? Párhuzamosítható-e a feldolgozás?
Biztonságosan feldolgozhatók különböző dokumentumok különböző szálakon; ugyanazt a [prezentáció](https://reference.aspose.com/slides/hu/nodejs-java/aspose.slides/presentation/) objektumot nem szabad egyszerre [több szál](/slides/hu/nodejs-java/multithreading/) által használni.

### Támogatottak-e a fájljelszavak és a titkosítás?
Igen. [Megnyithatja](/slides/hu/nodejs-java/password-protected-presentation/) a titkosított prezentációkat, beállíthat vagy eltávolíthat nyitási és írási jelszót, és ellenőrizheti a védelem állapotát.

### Szükséges-e foglalkozni a betűcsomagokkal Linux konténerekben?
Igen. Ajánlott a gyakori betűcsomagokat telepíteni és/vagy kifejezetten [betűkészlet könyvtárakat megadni](/slides/hu/nodejs-java/custom-font/) az alkalmazásában, hogy elkerülje a váratlan helyettesítéseket.

### Vannak-e korlátozások az értékelő verzióban?
Az [értékelő módban](/slides/hu/nodejs-java/licensing/) a kimenethez vízjelet adunk, és bizonyos korlátozások érvényesek; egy [30 napos ideiglenes licenc](https://purchase.aspose.com/temporary-license/) érhető el a teljes funkcionalitás teszteléséhez.

### Támogatott-e külső formátumok importálása egy prezentációba (PDF/HTML → PPTX)?
Igen. Hozzáadhat [PDF oldalakat és HTML tartalmat](/slides/hu/nodejs-java/import-presentation/) egy prezentációhoz, és diákra alakíthatja őket.
