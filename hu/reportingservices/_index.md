Az Aspose.Slides for Reporting Services az egyetlen megoldás a piacon, amely lehetővé teszi valódi PPT és PPS jelentések létrehozását a Microsoft SQL Server 2005, 2008, 2012, 2016 és 2017 Reporting Services (32‑bit és 64‑bit) környezetben. Az összes RDL jelentésfunkció, beleértve a táblázatokat, mátrixokat, diagramokat és képeket, a legmagasabb pontossággal kerül átalakításra a Microsoft PowerPoint prezentációkká.
