Ez egy történeti oldal, a meglévő hivatkozások miatt megtartva. Nem a Aspose.Slides for Java aktuális verzióját írja le. Az Aspose.Slides for Java által betöltött, importált, mentett és megjelenített formátumok, valamint azok API-ja megtalálható a [Támogatott fájlformátumok](/slides/hu/java/supported-file-formats/). Az aktuális PDF‑konvertálási útmutatóért lásd a [PPT és PPTX konvertálása PDF‑be](/slides/hu/java/convert-powerpoint-to-pdf/).
{{% /alert %}}

{{% alert color="info" title="Note" %}}
A [Portable Document Format](https://en.wikipedia.org/wiki/PDF) egy az Adobe Systems által létrehozott fájlformátum, amelyet szervezetek közötti dokumentumcsere céljából fejlesztettek ki. A formátum célja, hogy a tartalom és a megjelenés változatlan maradjon, függetlenül attól, hogy melyik platformon tekintik meg. Az Aspose.Slides for Java lehetővé teszi a prezentációs fájlok PDF‑be konvertálását.
{{% /alert %}}

## **PDF az Aspose.Slides for Java-ban**
Bármely prezentáció, amely betölthető az Aspose.Slides for Java‑ban, PDF‑be konvertálható, amely megfelel a [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) vagy [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) szabványnak a választásának megfelelően. Az Aspose.Slides for Java a prezentációkat PDF‑be exportálja, és a legtöbb esetben a kimeneti PDF pontosan úgy néz ki, mint az eredeti prezentáció.

Az Aspose.Slides a következő prezentációs funkciókat támogatja PDF‑re konvertáláskor:

- Képek, szövegdobozok és egyéb alakzatok.
- Szöveg és formázás.
- Bekezdések és formázás.
- Hiperhivatkozások.
- Fejlécek és láblécek.
- Felsorolásjelzők.
- Táblázatok.

A prezentációkat közvetlenül exportálhatja PDF‑be az Aspose.Slides for Java használatával: nem szükséges semmilyen más komponens. Továbbá testreszabhatja a prezentáció PDF exportját különféle beállításokkal, ahogyan a [PPT és PPTX konvertálása PDF‑be](/slides/hu/java/convert-powerpoint-to-pdf/) leírásában talál.
