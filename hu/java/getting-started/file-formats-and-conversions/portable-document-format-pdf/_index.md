{{% alert color="info" %}} 

A [Portable Document Format](https://en.wikipedia.org/wiki/PDF) egy az Adobe Systems által létrehozott fájlformátum, amelyet a szervezetek közötti dokumentumcsere céljából fejlesztettek ki. A formátum célja, hogy a tartalom és a megjelenítés ugyanaz maradjon, függetlenül attól, hogy melyik platformon tekintik meg. Az Aspose.Slides for Java lehetővé teszi, hogy bemutató fájlokat PDF-re konvertáljon.

{{% /alert %}} 

## **PDF az Aspose.Slides for Java-ban**
Bármely bemutató, amely betölthető az Aspose.Slides for Java-ba, PDF-re konvertálható, amely megfelel a [PDF 1.5](https://en.wikipedia.org/wiki/PDF/A), a [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), a [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) vagy a [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) szabványnak a választásától függően. Az Aspose.Slides for Java exportálja a bemutatókat PDF-be, és a legtöbb esetben a kimeneti PDF pontosan úgy néz ki, mint az eredeti bemutató.

Az Aspose.Slides a következő bemutató‑jellemzőket támogatja PDF‑konvertáláskor:

- Képek, szövegdobozok és egyéb alakzatok.
- Szöveg és formázás.
- Bekezdések és formázás.
- Hiperhivatkozások.
- Fejléc és lábléc.
- Felsorolásjelek.
- Táblázatok.

A bemutatókat közvetlenül exportálhatja PDF‑be az Aspose.Slides for Java használatával: nincs szükség más komponensre. Továbbá a bemutató PDF‑exportálását különféle beállításokkal testre szabhatja, amint azt a [Converting to PDF](/slides/hu/java/converting-a-presentation/) részben ismertetjük.
