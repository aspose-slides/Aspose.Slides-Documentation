## **Konverzióban Támogatott Funkciók**
Az Aspose.Slides for Java részleges támogatást nyújt a PPT fájlformátum PPTX‑re konvertálásához. A konverzió támogatása mostanában került bevezetésre az Aspose.Slides for Java‑ba, ezért néhány korlátozással rendelkezik, és leginkább egyszerű bemutatók esetén működik a legjobban. Az a legnagyobb előnye, hogy az Aspose.Slides for Java a PPT‑ről PPTX‑re konvertálásakor mennyire egyszerűen használható az API. A kódrészletek példáiért lásd a [Convert PPT to PPTX](/slides/hu/java/convert-ppt-to-pptx/). Az alábbi lista mutatja, mely funkciók támogatottak a PPT‑ről PPTX‑re konvertálás során.

## **Támogatott Funkciók**
A következő funkciók támogatottak a konverzió során:

- A mesterek, elrendezések és diák struktúrájának konvertálása.
- Diagramok konvertálása.
- Csoportos alakzatok.
- Automatikus alakzatok (például téglalapok és ellipszisek) konvertálása.
- Egyedi geometriájú alakzatok.
- Szövetek és képek kitöltési stílusai az automatikus alakzatokhoz.
- Helyettesítők konvertálása.
- Vonalak és vonalláncok konvertálása.
- Vonal- és kitöltésformátumok.
- Gradient kitöltési stílusok.
- OLE keretek, táblázatok, video- és hangkeretek stb.
- Animációs és diavetítés tulajdonságok.
- Szöveg konvertálása szövegdobozokban és szöveghelyekben.
