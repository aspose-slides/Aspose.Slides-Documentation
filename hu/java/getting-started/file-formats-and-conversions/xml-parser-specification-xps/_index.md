{{% alert color="info" %}} 

Az [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) egy oldal leíró nyelv és egy rögzített dokumentumformátum, amelyet eredetileg a Microsoft fejlesztett ki. A PDF-hez hasonlóan az XPS-et úgy tervezték, hogy megőrizze a dokumentum pontosságát és eszközfüggetlen megjelenést biztosítson. 

{{% /alert %}} 

## **XPS az Aspose.Slides for Java-ban**
Bármely prezentációs dokumentum, amely betölthető az Aspose.Slides for Java segítségével, átalakítható XPS formátumba. Az Aspose.Slides for Java a nagy pontosságú oldalelrendezési és renderelő motorját használja, hogy kimenetet állítson elő rögzített elrendezésű XPS dokumentumformátumban.
További információt a prezentációs dokumentumok XPS formátumba exportálásáról az [Converting to XPS](https://docs.aspose.com/slides/hu/java/convert-powerpoint-to-xps/) oldalon találsz.
