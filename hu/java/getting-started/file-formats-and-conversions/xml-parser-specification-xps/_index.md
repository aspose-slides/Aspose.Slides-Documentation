{{% alert color="info" title="Note" %}}

Ez egy történelmi oldal, amely a meglévő hivatkozások miatt megmaradt. Nem a jelenlegi Aspose.Slides for Java verziót írja le. Azokért a formátumokért, amelyeket az Aspose.Slides for Java betölt, importál, ment és megjelenít, valamint az egyes formátumok API-ért, lásd a [Supported File Formats](/slides/hu/java/supported-file-formats/). A jelenlegi XPS konverziós útmutatóért lásd a [Convert PowerPoint Presentations to XPS](/slides/hu/java/convert-powerpoint-to-xps/).

{{% /alert %}}

{{% alert color="info" title="Note" %}}

Az [XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) egy lapleíró nyelv és egy rögzített dokumentumformátum, amelyet eredetileg a Microsoft fejlesztett ki. A PDF-hez hasonlóan az XPS is a dokumentum hűségének megőrzésére és az eszközfüggetlen megjelenés biztosítására lett tervezve.

{{% /alert %}}

## **XPS az Aspose.Slides for Java-ban**
Bármely prezentációs dokumentum, amely betölthető az Aspose.Slides for Java-val, konvertálható XPS formátumba. Az Aspose.Slides for Java a magas hűségű oldalelrendezési és renderelő motorját használja a fix elrendezésű XPS dokumentumformátumba történő kimenet előállításához. Az XPS dokumentumokba történő exportálásról az Aspose.Slides for Java segítségével bővebben a [Convert PowerPoint Presentations to XPS](/slides/hu/java/convert-powerpoint-to-xps/) oldalon olvashat.
