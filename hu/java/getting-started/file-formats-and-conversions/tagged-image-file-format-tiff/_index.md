Ez egy történelmi oldal, a meglévő hivatkozások megőrzésére szolgál. Nem írja le az Aspose.Slides for Java jelenlegi verzióját. Az Aspose.Slides for Java által betöltött, importált, mentett és renderelt formátumok, valamint az egyes formátumok API-ja tekinthető meg a [Támogatott fájlformátumok](/slides/hu/java/supported-file-formats/) oldalon. Az aktuális TIFF konvertálási útmutató megtalálható a [PowerPoint-prezentációk konvertálása TIFF formátumba](/slides/hu/java/convert-powerpoint-to-tiff/) oldalon.

{{% /alert %}}

## **A TIFF-ről**

A [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF), amely több kép tárolására egy dokumentumban ismert, eredetileg az Aldus hozta létre. Ez a formátum széles körben támogatott a szkennelés, faxolás és egyéb képfeldolgozó alkalmazások által.

## **TIFF az Aspose.Slides for Java-ban**

Bármely dokumentum, amely betölthető az Aspose.Slides for Java-ban, közvetlenül az Aspose.Slides for Java segítségével TIFF-dokumentummá konvertálható, anélkül, hogy bármilyen harmadik fél komponensre lenne szükség. Továbbá opcionálisan meghatározhatja a képek méretét a létrehozott TIFF-dokumentumban. Az Aspose.Slides for Java segítségével a prezentációs dokumentumok TIFF-dokumentumokká exportálásával kapcsolatos információkat a [PowerPoint-prezentációk konvertálása TIFF formátumba](/slides/hu/java/convert-powerpoint-to-tiff/) oldalon találja.
