{{% alert color="info" title="Note" %}}

Ez egy történelmi oldal. A dokumentáció felsorolja az Aspose.Slides for Java 14.3.0-hoz közzétett ismert problémákat, és nem írja le az aktuális verziót. Az egyes verziók változásairól lásd a [kiadási megjegyzések](https://releases.aspose.com/slides/hu/java/release-notes/).

{{% /alert %}}

Az Aspose.Slides for Java 14.3.0 (14.4.0) teljesen új PPT-feldolgozási megvalósítást biztosít. Számos fejlesztés történt, például a PPTX‑ről PPT‑re részleges átalakítás. Vannak azonban néhány megvalósítatlan funkció:

- Néhány alakzat helytelen geometriát tartalmaz a sorosított PPT-dokumentumokban (Call outs)
- Nem minden PPTX‑szövegformázási funkció támogatott a PPT‑sorosításban
- A szöveg nyelvéről és helyesírási beállításairól szóló információ nem szerepel a sorosított PPT‑dokumentumokban
- Nem minden PPTX‑téma funkció támogatott a PPT‑sorosításban

**Vannak eltérések az Aspose.Slides for Java 8.6.0‑hoz képest:**

- Ismert problémák vannak OLE/ActiveX PPT‑sorosításnál PPT‑be

**Vannak eltérések az Aspose.Slides for .NET 14.3.0‑hoz képest:**

- A prezentáció nyomtatásának támogatása jelenleg nem érhető el az Aspose.Slides for Java‑ban
