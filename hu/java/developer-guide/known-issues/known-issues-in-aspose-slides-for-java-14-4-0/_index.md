{{% alert color="info" %}} 

Az Aspose.Slides for Java 14.4.0 új megoldást biztosít a PowerPoint dokumentumok feldolgozásához. Vannak bizonyos korlátozások és ismert hibák, amelyek a jövőbeni kiadásokban eltávolításra kerülnek:

- Néhány alakzat helytelen geometriát tartalmaz a sorosított PPT dokumentumokban (ív, kör alakú nyíl, feliratok).
- Nem minden PPTX szövegformázási funkció támogatott a PPT sorosításakor (tabuláció, behúzás és bekezdésformázási korlátozások).
- A szöveg nyelvével és helyesírási beállításaival kapcsolatos információ nem jelenik meg a sorosított PPT dokumentumokban.
- Nem minden PPTX témafunkció támogatott a PPT sorosításakor (csak a kitöltési formátumok, vonalformátumok és betűtípusok sorosítása).
- Ismert problémák vannak az OLE/ActiveX PPT sorosításban PPT-be.
- A WordArt sorosítása és renderelése nem támogatott.

{{% /alert %}}
