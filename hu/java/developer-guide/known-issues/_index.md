## **Áttekintés**

Ez a szakasz nem tartalmaz nyitott hibák listáját a jelenlegi verzióban. Három oldalt tartalmaz:

- [Objektum előnézet helyőrző OleObjectFrame hozzáadásakor](/slides/hu/java/object-preview-issue-when-adding-oleobjectframe/) elmagyarázza, miért jelenik meg egy Aspose.Slides‑kel hozzáadott OLE objektum esetén egy “EMBEDDED OLE OBJECT” kép, amíg az előnézete nem frissül, valamint hogyan állíthatja be saját előnézeti képét. Ez a jelenlegi verzió tervezett viselkedése.
- [Known Issues in Aspose.Slides for Java 14.3.0 (Historical)](/slides/hu/java/known-issues-in-aspose-slides-for-java-14-3-0/) és [Known Issues in Aspose.Slides for Java 14.4.0 (Historical)](/slides/hu/java/known-issues-in-aspose-slides-for-java-14-4-0/) listák, amelyeket az adott verziókkal együtt adtak ki, és referenciaként megtartottak.

A verziónkénti módosítások és javítások megtekintéséhez lásd a [kiadási jegyzetek](https://releases.aspose.com/slides/hu/java/release-notes/). Az Aspose.Slides által rögzített rögzített értékű metaadatmezőket a [Kimeneti metaadat korlátozások](/slides/hu/java/api-limitations/) ismertetik. Annak ellenőrzéséhez, hogy egy probléma már ismert-e, vagy egy újat bejelenteni, használja a [támogatási fórum](https://forum.aspose.com/c/slides/hu/11).
