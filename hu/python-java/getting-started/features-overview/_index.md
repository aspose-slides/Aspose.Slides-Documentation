Ez a cikk leírja az Aspose.Slides for Python via Java prezentációfeldolgozási képességeit. A támogatott operációs rendszerek és függőségek listájáért tekintse meg a [Rendszerkövetelmények](/slides/hu/python-java/system-requirements/).

## **Fájlformátumok és konverziók**

Az Aspose.Slides for Python via Java lehetővé teszi a prezentációformátumok közötti átalakítást, valamint a prezentációk exportálását dokumentum- és webformátumokba. A teljes formátumtáblázatért, valamint a prezentációk betöltése, tartalom importálása és exportálása közötti különbségekért tekintse meg a [Támogatott fájlformátumok](/slides/hu/python-java/supported-file-formats/) oldalt.

## **Prezentáció renderelése**

Az Aspose.Slides for Python via Java magas pontosságú dia renderelést biztosít raszteres vagy vektoros képek formájában előnézetekhez és egyéb vizuális kimenetekhez. Emellett lehetővé teszi képek renderelését diákon. Az elérhető képtípusok és exportálási megjegyzésekért tekintse meg a [Támogatott fájlformátumok](/slides/hu/python-java/supported-file-formats/#supported-file-formats) oldalt.

## **Formázási funkciók**

Az Aspose.Slides for Python via Java lehetővé teszi a szöveg és alakzatok formázását a prezentációs diákon, ahogyan az alább le van írva:

|**Funkció**|**Leírás**|
| :- | :- |
|Text Formatting|<p>A szöveget az alakzatokhoz tartozó szövegkereteken keresztül kezelheti, és egyes bekezdéseket és szövegrétegeket formázhat. Az alábbi formázási lehetőségek érhetők el:</p><p>- Betűtípus</p><p>- Betűméret</p><p>- Betűszín</p><p>- Betűárnyalat</p><p>- Bekezdés igazítása</p><p>- Bekezdés behúzása és tabulátorok</p><p>- Bekezdés felsorolás</p><p>- Bekezdés irány</p>|
|Shape Formatting|<p>Az alakzatok a dia alapvető elemei. Az alábbi alakzattulajdonságok állíthatók:</p><p>- Pozíció</p><p>- Méret</p><p>- Forgatás</p><p>- Vonalstílusok</p><p>- Kitöltés (beleértve a szilárd, fokozatos, minta, textúra és képkitöltéseket)</p><p>- Szöveg</p><p>- Kép</p>|
