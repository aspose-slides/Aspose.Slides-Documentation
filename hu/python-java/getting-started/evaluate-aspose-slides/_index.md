Letöltheti az Aspose.Slides for Python via Java-t, hogy kipróbálja funkcióit. Az értékelő csomag azonos a licencelt csomaggal. Az értékelési korlátozások nélküli használathoz adjon hozzá néhány kódsort a [licenc alkalmazásához](/slides/hu/python-java/licensing/).

Az Aspose.Slides értékelő verziója (licenc nélkül használva) teljes termékfunkcionalitást biztosít, két korláttal:

- Minden mentett prezentáció minden diájához hozzáad egy értékelési vízjel szövegdobozt. Egy prezentáció megnyitása nem ad hozzá ilyet, de egy már vízjelet tartalmazó fájl mentése egy újat ad hozzá.
- A kód által olvasott szöveg csak az első néhány karakterére van csonkolva, amit egy az értékelési korlátról szóló megjegyzés követ. Ez minden diára, valamint a kód által most beállított szövegre és a fájlból betöltött szövegre is vonatkozik. A kód által írt szöveg teljes egészében kerül mentésre.

{{% alert color="info" title="Note" %}}

Az Aspose.Slides értékelési korlátozások nélküli teszteléséhez kérhet **30 napos ideiglenes licencet**. További információért tekintse meg a [Ideiglenes licenc kérése](https://purchase.aspose.com/temporary-license).
