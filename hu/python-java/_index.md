**Üdvözöljük az Aspose.Slides for Python via Java-ban**

![Aspose.Slides for Python via Java terméklogója](aspose_slides-for-python-via-java.png)

Az Aspose.Slides for Python via Java egy osztálykönyvtár, amely lehetővé teszi Python‑alkalmazásainak a PowerPoint® prezentációk olvasását és írását anélkül, hogy a Microsoft PowerPoint®‑ra szükség lenne.

Főbb funkciói közé tartozik a szöveg, alakzatok, táblázatok és animációk kezelése; hang és videó hozzáadása a diákhoz; a diák előnézete; valamint a diák exportálása SVG, PDF és egyéb formátumokba.
