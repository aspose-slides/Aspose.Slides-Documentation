**Üdvözöljük az Aspose.Slides for Python via Java-ban**

![Aspose.Slides for Python via Java terméklogó](aspose_slides-for-python-via-java.png)

Az Aspose.Slides for Python via Java egy osztálykönyvtár, amely lehetővé teszi Python alkalmazásai számára, hogy Microsoft PowerPoint® nélkül olvassanak és írjanak PowerPoint® prezentációkat.

Főbb jellemzői közé tartozik a szöveg, alakzatok, táblázatok és animációk kezelése; hang és videó hozzáadása a diákhoz; diák előnézete; valamint a diák exportálása SVG, PDF és egyéb formátumokba.

{{% /alert %}}
