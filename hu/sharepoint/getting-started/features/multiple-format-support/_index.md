{{% alert color="info" title="Megjegyzés" %}}

Az Aspose.Slides for SharePoint segítségével a SharePoint dokumentumtárból számos népszerű dokumentumformátumba konvertálhat PowerPoint előadásokat.

{{% /alert %}}

## **Támogatott bemeneti formátumok**

Az Aspose.Slides for SharePoint a következő bemeneti formátumokat konvertálja:

- PPT – Microsoft PowerPoint bemutató 97‑2003
- PPTX – Office Open XML bemutató

{{% alert color="info" title="Megjegyzés" %}}

A dokumentumok konvertálásához az Aspose.Slides for SharePoint egy beépített [Aspose.Slides for .NET](https://products.aspose.com/slides/net/) verziót használ.

{{% /alert %}}

## **Támogatott kimeneti formátumok**

A konverziós oldalon található **Convert to** lista a következő kimeneti formátumokat kínálja ebben a sorrendben:

- PDF – Adobe hordozható dokumentum
- TIFF – Képcsomag
- XPS – XML papír specifikáció
- PPS – Diavetítés bemutató
- PPSX – Microsoft PowerPoint Open XML diavetítés
- ODP – OpenDocument bemutató
- PPTM – Microsoft PowerPoint Open XML makróval bővített bemutató
- PPSM – Microsoft PowerPoint Open XML makróval bővített diavetítés
- POTX – Microsoft PowerPoint sablon
- POTM – PowerPoint Open XML makróval bővített bemutató sablon
- PDFNotes – Bemutató jegyzetek PDF formátumban
- HTML – Bemutató HTML formátumban
- TIFFNotes – Bemutató jegyzetek többoldalas TIFF képként
- SWF – Shockwave Flash film
- SWFNotes – Bemutató jegyzetek többoldalas SWF formátumban

**A kimeneti formátum kiválasztása a Conversion Settings oldalon**

![A Conversion Settings oldal a Convert to lista kimeneti formátumokkal](multiple-format-support_1.png)

A képernyőkép egy korábbi verzióról készült, amely csak a PDF, TIFF és XPS formátumokat kínálta.
