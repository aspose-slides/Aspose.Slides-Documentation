A prezentáció átalakításához dokumentumtárban:

1. Nyissa meg a PPT vagy PPTX fájl menüjét (az Edit Control Block-ot) és válassza a **Convert via Aspose.Slides** lehetőséget. SharePoint 2007‑nél a menüpont neve **Convert with Aspose.Slides**.

   **Convert with Aspose.Slides kiválasztása egy dokumentum menüjében a SharePoint 2007‑en**

   ![The menu of a document in a SharePoint 2007 document library, with the Convert with Aspose.Slides item](convert-one-file_1.png)

2. A konverzió oldalon válassza ki a kimeneti formátumot a **Convert to** alatt. Ha kívánja, módosíthatja a célfájl nevét és a célmappát.
3. Kattintson a **Convert** gombra.
4. Amikor a konverzió befejeződött, kattintson a **Source Library** vagy a **Destination Library** hivatkozásra a dokumentumtárba való visszatéréshez. A konvertált fájl a célmappában található.

Ugyanazok a lépések, minden oldal képernyőképekkel, megtalálhatók a [Converting Microsoft PowerPoint Documents into Other Formats](/slides/hu/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
