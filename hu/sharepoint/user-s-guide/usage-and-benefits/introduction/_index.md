## **Mi az a SharePoint és az Aspose.Slides?**

Az Aspose.Slides for SharePoint egy megoldás a Microsoft PowerPoint prezentációk (PPT és PPTX) más formátumokra történő konvertálására: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX és POTM. Lehetővé teszi, hogy PowerPoint-fájlokat konvertáljon egy SharePoint helyen anélkül, hogy a Microsoft PowerPointot használná. A formátumok teljes listája a [Támogatott fájlformátumok](/slides/hu/sharepoint/supported-file-formats/) oldalon található.
