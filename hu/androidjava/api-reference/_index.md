{{% alert color="info" %}} 

Az Aspose.Slides for Android via Java egy osztálykönyvtár, amely lehetővé teszi az Androidra fejlesztett Java‑alkalmazások számára, hogy Microsoft PowerPoint® vagy más szoftver használata nélkül olvassanak és írjanak prezentációs dokumentumokat. Az Aspose.Slides for Android via Java lehetővé teszi szöveg, alakzat, táblázat és animáció kezelését; hang és videó hozzáadását a diához; a diák előnézetét; valamint a diák exportálását SVG, PDF formátumba és egyebekbe.

A legfrissebb API‑referenciát megtalálja a [Aspose.Slides for Android via Java API-referencia](https://reference.aspose.com/slides/hu/androidjava/).

{{% /alert %}}
