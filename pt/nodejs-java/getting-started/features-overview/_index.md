## **Plataformas Suportadas**
Aspose.Slides for Node.js via Java é uma API independente de plataforma. Pode ser usada em qualquer plataforma (Windows, Linux, macOS, etc.) onde o Node.js 7 ou superior esteja instalado. O Oracle JDK 8 ou superior é outro requisito.

## **Formatos de Arquivo e Conversões**
Aspose.Slides for Node.js via Java suporta a maioria dos formatos de documentos PowerPoint. Também permite exportá-los para os formatos de arquivo populares que as organizações utilizam e compartilham entre si. Veja os detalhes abaixo:

|**Recurso**|**Descrição**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java fornece o processamento mais rápido para este formato de documento de apresentação.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java suporta a conversão de PPT para PPTX|
|Portable Document Format (PDF)|Você pode exportar todos os formatos de arquivo suportados para documentos Adobe Portable Document Format (PDF) com um único método.|
|XML Parser Specification (XPS)|Você pode exportar todos os formatos de arquivo suportados para documentos XML Parser Specification (XPS) com um único método.|
|Tagged Image File Format (TIFF)|Você pode exportar todos os formatos de arquivo de apresentação suportados para Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java suporta a conversão de PresentationEx para o formato HTML.|

## **Renderização de Apresentação**
Aspose.Slides for Node.js via Java suporta renderização de alta fidelidade dos slides de apresentações em diferentes formatos gráficos. Veja os detalhes abaixo:

|**Recurso**|**Descrição**|
| :- | :- |
|Java Supported Image Formats|Usando Aspose.Slides for Node.js via Java, você pode renderizar slides de apresentação e imagens nos slides para todos os formatos gráficos suportados pelo Java, como TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via Java também fornece métodos incorporados que permitem exportar slides de apresentação para formatos Scalable Vector Graphics (SVG).|

## **Perguntas Frequentes**

### Preciso instalar o Microsoft PowerPoint no servidor/PC para que a biblioteca funcione?
Não. O PowerPoint não é necessário; o Aspose.Slides é um motor independente para criar, editar, converter e renderizar apresentações.

### Como o multithreading funciona? O processamento pode ser paralelizado?
É seguro processar documentos diferentes em threads diferentes; o mesmo [presentation](https://reference.aspose.com/slides/pt/nodejs-java/aspose.slides/presentation/) objeto não deve ser usado por [multiple threads](/slides/pt/nodejs-java/multithreading/) ao mesmo tempo.

### Senhas de arquivo e criptografia são suportadas?
Sim. [You can](/slides/pt/nodejs-java/password-protected-presentation/) abrir apresentações criptografadas, definir ou remover uma senha de abertura e gravação, e verificar o status de proteção.

### Preciso me preocupar com pacotes de fontes em contêineres Linux?
Sim. Recomenda-se instalar pacotes de fontes comuns e/ou especificar explicitamente [specify font directories](/slides/pt/nodejs-java/custom-font/) em sua aplicação para evitar substituições inesperadas.

### Existem limitações na versão de avaliação?
No [evaluation mode](/slides/pt/nodejs-java/licensing/), uma marca d'água é adicionada à saída e certas limitações se aplicam; uma [30-day temporary license](https://purchase.aspose.com/temporary-license/) está disponível para testes com todos os recursos.

### A importação de formatos externos para uma apresentação (PDF/HTML → PPTX) é suportada?
Sim. Você pode adicionar [PDF pages and HTML content](/slides/pt/nodejs-java/import-presentation/) a uma apresentação, convertendo-os em slides.
