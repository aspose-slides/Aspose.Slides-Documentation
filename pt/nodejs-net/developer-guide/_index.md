Este **Guia do Desenvolvedor** mostra como realizar tarefas comuns de apresentação em JavaScript com Aspose.Slides para Node.js via .NET. Cada artigo contém exemplos executáveis. Antes de executá-los, configure um projeto conforme descrito em [Instalação](/slides/pt/nodejs-net/installation/).

- [**Criar Apresentação**](/slides/pt/nodejs-net/create-presentation/) – criar uma apresentação, adicionar uma caixa de texto e slides, definir o tamanho do slide e salvar o resultado como PPTX.
- [**Abrir Apresentação**](/slides/pt/nodejs-net/open-presentation/) – abrir uma apresentação a partir de um arquivo ou buffer, ler sua contagem de slides e salvá‑la em outro formato.
- [**PowerPoint para PDF**](/slides/pt/nodejs-net/convert-powerpoint-to-pdf/) – converter uma apresentação para PDF, incluindo PDF/A para arquivamento.
- [**Slide para Imagem**](/slides/pt/nodejs-net/convert-slide/) – renderizar slides como imagens PNG com um fator de escala ou com tamanho exato em pixels.
- [**Gerenciar Texto**](/slides/pt/nodejs-net/manage-text/) – adicionar uma caixa de texto, então alterar seu texto, tamanho da fonte e estilo em negrito.
