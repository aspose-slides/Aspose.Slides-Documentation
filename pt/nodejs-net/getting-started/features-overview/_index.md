## **Plataformas Suportadas**
Aspose.Slides for Node.js via .NET é uma API independente de plataforma. Pode ser usada em qualquer plataforma (Windows, Linux, macOS, etc.) onde o Node.js 7 ou superior esteja instalado. O Oracle JDK 8 ou superior é outro requisito.

## **Formatos de Arquivo e Conversões**
Aspose.Slides for Node.js via .NET suporta a maioria dos formatos de documento do PowerPoint. Também permite exportá‑los para os formatos de arquivo populares que as organizações usam e compartilham entre si. Confira os detalhes:

|**Feature**|**Description**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET oferece o processamento mais rápido para este formato de documento de apresentação.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET suporta a conversão de PPT para PPTX|
|Portable Document Format (PDF)|Você pode exportar todos os formatos de arquivo suportados para documentos Adobe Portable Document Format (PDF) com um único método.|
|XML Parser Specification (XPS)|Você pode exportar todos os formatos de arquivo suportados para documentos XML Parser Specification (XPS) com um único método.|
|Tagged Image File Format (TIFF)|Você pode exportar todos os formatos de arquivo de apresentação suportados para Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET suporta a conversão de PresentationEx para o formato HTML.|

## **Renderização de Apresentação**
Aspose.Slides for Node.js via .NET suporta renderização de alta fidelidade dos slides de uma apresentação para diferentes formatos gráficos. Confira os detalhes:

|**Feature**|**Description**|
| :- | :- |
|.NET Supported Image Formats|Usando Aspose.Slides for Node.js via .NET, você pode renderizar slides de apresentação e imagens nos slides para todos os formatos gráficos suportados pelo .NET, como TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via .NET também fornece métodos integrados que permitem exportar slides de apresentação para formatos Scalable Vector Graphics (SVG).|

## **Recursos de Conteúdo**
Aspose.Slides for Node.js via .NET permite acessar, modificar ou criar quase todos os itens ou conteúdos de documentos de apresentação. Confira os detalhes:

|**Feature**|**Description**|
| :- | :- |
|Slides Mestre|Os Slides Mestre definem o layout dos slides normais. Aspose.Slides for Node.js via .NET permite acessar e modificar os Slides Mestre dos documentos de apresentação|

Você também pode usar slides copiados e clonados de uma apresentação para outra. Como um slide herda seu layout do slide mestre, os métodos de clonagem integrados copiam automaticamente o mestre ao clonar|
|Gerenciamento de Seções de Slides|Métodos para organizar slides em diferentes seções dentro de uma apresentação|
|Espaços Reservados e Espaços de Texto|Você pode acessar os espaços reservados e espaços de texto em um slide. Além disso, pode criar um slide com espaços de texto do zero usando o método apropriado|
|Cabeçalhos e Rodapés|Aspose.Slides for Node.js via .NET facilita o gerenciamento de cabeçalhos/rodapés nos slides|
|Notas nos Slides|Com Aspose.Slides for Node.js via .NET, você pode acessar e modificar notas associadas a um slide e também adicionar novas notas|
|Localizar uma Forma|Você também pode encontrar uma forma específica em um slide usando o texto alternativo associado à forma|
|Fundos|Aspose.Slides for Node.js via .NET permite trabalhar com fundos associados a um slide mestre ou normal em uma apresentação|
|Caixas de Texto|Caixas de texto podem ser criadas do zero. Você pode acessar caixas de texto existentes. Também pode modificar seus textos sem perder o formato original|
|Formas Retangulares|Você pode criar ou modificar formas retangulares com Aspose.Slides for Node.js via .NET|
|Formas de Polilinha|Você pode criar ou modificar formas de polilinha com Aspose.Slides for Node.js via .NET|
|Formas Elípticas|Você pode criar ou modificar formas elípticas com Aspose.Slides for Node.js via .NET|
|Formas Agrupadas|Aspose.Slides for Node.js via .NET suporta formas agrupadas|
|Formas Automáticas|Aspose.Slides for Node.js via .NET suporta formas automáticas|
|SmartArt|Aspose.Slides for Node.js via .NET oferece suporte a formas SmartArt no MS PowerPoint|
|Charts|Aspose.Slides for Node.js via .NET oferece suporte a gráficos MSO no PowerPoint|
|Serialização de Formas|Aspose.Slides for Node.js via .NET suporta um grande número de formas. Quando o Aspose.Slides for Node.js via .NET não oferece suporte a uma forma, você pode usar um método de serialização que permite serializar essa forma a partir de um slide existente. Dessa forma, você pode usar a forma posteriormente conforme suas necessidades |
|Molduras de Imagem|Você pode gerenciar imagens em molduras de imagem com Aspose.Slides for Node.js via .NET|
|Molduras de Áudio|Você pode vincular ou incorporar arquivos de áudio em molduras de áudio nos slides com Aspose.Slides for Node.js via .NET|
|Molduras de Vídeo|Você pode manipular arquivos de vídeo em molduras de vídeo. Aspose.Slides for Node.js via .NET também oferece suporte a vídeos vinculados e incorporados|
|Moldura OLE|Você pode gerenciar objetos OLE em molduras OLE com Aspose.Slides for Node.js via .NET|
|Tables|Aspose.Slides for Node.js via .NET suporta tabelas em slides|
|ActiveX Controls|Suporte a controles ActiveX|
|VBA Macros|Suporte ao gerenciamento de macros VBA dentro de apresentações.|
|Quadro de Texto|Você pode acessar o texto de qualquer forma através do quadro de texto associado a essa forma|
|Digitalização de Texto|Você pode digitalizar texto em uma apresentação no nível da apresentação ou do slide por meio de métodos de digitalização integrados.|
|Animations|Você pode aplicar animações em formas|
|Slide Shows|Aspose.Slides for Node.js via .NET suporta apresentações de slides e transições de slides|

## **Recursos de Formatação**
Com Aspose.Slides for Node.js via .NET, você pode formatar textos e formas em slides de apresentações. Confira os detalhes:

|**Feature**|**Description**|
| :- | :- |
|Formatação de Texto|<p>No Aspose.Slides for Node.js via .NET, você pode gerenciar textos através dos quadros de texto associados às formas. Assim, você pode formatar textos usando os parágrafos e partes associados aos quadros de texto. Esses elementos de texto podem ser formatados através do Aspose.Slides for Node.js via .NET.</p><p>- Tipo de Fonte</p><p>- Tamanho da Fonte</p><p>- Cor da Fonte</p><p>- Tons da Fonte</p><p>- Alinhamento de Parágrafo</p><p>- Marcadores de Parágrafo</p><p>- Orientação de Parágrafo</p>|
|Formatação de Forma|<p>No Aspose.Slides for Node.js via .NET, o elemento básico de um slide é uma forma. Você pode formatar esses elementos de forma com Aspose.Slides for Node.js via .NET:</p><p>- Posição</p><p>- Tamanho</p><p>- Linha</p><p>- Preenchimento (incluindo Padrão, Gradiente, Sólido)</p><p>- Texto</p><p>- Imagem</p>|
