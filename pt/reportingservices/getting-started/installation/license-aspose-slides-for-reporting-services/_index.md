## **Suporte de Licença**

A versão de avaliação do Aspose.Slides for Reporting Services é o mesmo pacote da versão comprada, a partir da sua [página de download](https://releases.aspose.com/slides/pt/reportingservices/), e fornece a mesma funcionalidade. Sem uma licença, ele funciona em modo de avaliação e insere uma marca d'água de avaliação nas apresentações exportadas.

A versão de avaliação se torna licenciada quando você copia um arquivo de licença para o servidor de relatórios. Nenhum código é envolvido.

Quando estiver satisfeito com sua avaliação, você pode [comprar uma licença](https://purchase.aspose.com/pricing/slides/pt/reporting-services/). Recomendamos que você reveja os diferentes tipos de assinatura. Se tiver dúvidas, entre em contato com a equipe de vendas da Aspose.

## **Licenciamento no Aspose.Slides for Reporting Services**

* A licença é um arquivo XML de texto simples que contém detalhes como o nome do produto, o número de desenvolvedores licenciados, a data de expiração da assinatura, etc.
* O arquivo de licença é assinado digitalmente, portanto você não deve modificá‑lo. Mesmo a adição inadvertida de uma quebra de linha extra ao conteúdo do arquivo o invalidará.

Para aplicar a licença:

1. Copie o arquivo de licença para a pasta *ReportServer\bin* de cada instância do servidor de relatórios, onde *Aspose.Slides.ReportingServices.dll* está instalado — por exemplo, *C:\Program Files\Microsoft SQL Server Reporting Services\SSRS\ReportServer\bin*. [Instalar manualmente](/slides/pt/reportingservices/install-manually/#find-the-report-server-folder) lista as pastas padrão.
2. Certifique‑se de que o arquivo tenha um dos nomes que a extensão procura: *Aspose.Slides.ReportingServices.lic*, *Aspose.Slides.Reporting.Services.lic*, *Aspose.Slides.Product.Family.lic*, *Aspose.Total.ReportingServices.lic*, *Aspose.Total.Reporting.Services.lic*, *Aspose.Total.Product.Family.lic* ou *Aspose.Total.lic*.
3. Exporte qualquer relatório como uma apresentação. Se não contiver marca d'água, a licença está ativa.

A extensão também procura o arquivo de licença em *%ProgramData%\Aspose\Slides* (geralmente *C:\ProgramData\Aspose\Slides*), portanto uma cópia ali atende a todas as instâncias na máquina.

**Modo Licenciado**

Quando um arquivo de licença válido é encontrado, as apresentações exportadas não carregam marca d'água de avaliação.

![Um relatório exportado com licença: sem marca d'água de avaliação](license-aspose-slides-for-reporting-services_2.png)

**Modo de Avaliação**

Sem uma licença, o Aspose.Slides for Reporting Services insere uma marca d'água de avaliação nas apresentações exportadas.

![Um relatório exportado em modo de avaliação, com a marca d'água de avaliação](license-aspose-slides-for-reporting-services_1.png)
