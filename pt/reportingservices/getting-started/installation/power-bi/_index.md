## **Power BI**

Você pode instalar o Aspose.Slides for Reporting Services no Power BI Report Server através dos mesmos processos de instalação:

* [Instalar com Instalador MSI](/slides/pt/reportingservices/install-with-msi-installer/). O programa de instalação detecta automaticamente o Power BI Report Server instalado, instala o produto e o configura para o seu ambiente de trabalho.
* [Instalar manualmente](/slides/pt/reportingservices/install-manually/). Use o assembly da pasta *Bin\Universal* do pacote ZIP.

Aspose.Slides for Reporting Services exporta relatórios paginados (RDL) do Power BI Report Server. Para os requisitos, incluindo .NET Framework 3.5 na máquina host, consulte [Requisitos do Sistema](/slides/pt/reportingservices/system-requirements/).
