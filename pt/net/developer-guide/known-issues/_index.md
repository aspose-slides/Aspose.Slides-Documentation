## **Visão geral**

Esta seção não contém uma lista de problemas abertos na versão atual. Ela contém duas páginas:

- [Placeholder de visualização de objeto ao adicionar OleObjectFrame](/slides/pt/net/object-preview-issue-when-adding-oleobjectframe/) explica por que um objeto OLE adicionado com Aspose.Slides exibe uma imagem "EMBEDDED OLE OBJECT" até que sua visualização seja atualizada, e como definir sua própria imagem de visualização. Esse é um comportamento intencional da versão atual.
- [Problemas conhecidos no Aspose.Slides for .NET 14.1.0 (Histórico)](/slides/pt/net/known-issues-in-aspose-slides-for-net-14-1-0/) é uma lista publicada com a versão 14.1.0 em 2014, mantida para referência.

Para as alterações e correções em cada versão, consulte as [notas de lançamento](https://releases.aspose.com/slides/pt/net/release-notes/). Os campos de metadados que o Aspose.Slides grava com valores fixos são descritos em [Limitações de Metadados de Saída](/slides/pt/net/api-limitations/). Para verificar se um problema já é conhecido ou para relatar um, use o [fórum de suporte](https://forum.aspose.com/c/slides/pt/11).
