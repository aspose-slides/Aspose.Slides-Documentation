{{% alert color="info" %}} 
Aspose.Slides for .NET é uma biblioteca de classes que permite que aplicativos .NET leiam e gravem documentos de apresentação sem usar o Microsoft PowerPoint® ou outros. Aspose.Slides for .NET permite gerenciar texto, formas, tabelas & animações, adicionar áudio e vídeo aos slides, visualizar slides, exportar slides para SVG, formato PDF e muito mais.

A referência da API mais recente pode ser encontrada em [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/pt/net).
