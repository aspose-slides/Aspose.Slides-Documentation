Os artigos nesta seção são visões gerais mais antigas de formatos de arquivos individuais, mantidos para links existentes. Eles não descrevem a versão atual do Aspose.Slides for Java. Para os formatos que o Aspose.Slides for Java carrega, importa, salva e renderiza, e a API de cada um, veja [Supported File Formats](/slides/pt/java/supported-file-formats/). Para guias de conversão, veja [Convert Presentations](/slides/pt/java/convert-presentation/).
