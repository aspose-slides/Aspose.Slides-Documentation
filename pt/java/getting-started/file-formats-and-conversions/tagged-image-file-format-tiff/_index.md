## **Sobre TIFF**

O Tagged Image File Format, conhecido por armazenar várias imagens em um único documento, foi originalmente criado pela Aldus. Esse formato é amplamente suportado por scanners, fax e outras aplicações de manipulação de imagem.

## **TIFF no Aspose.Slides for Java**

Qualquer documento que pode ser carregado no Aspose.Slides for Java também pode ser convertido diretamente para documento TIFF pelo Aspose.Slides for Java, eliminando a necessidade de qualquer componente de terceiros. Além disso, você pode opcionalmente definir o tamanho das imagens no documento TIFF resultante. Você pode encontrar informações sobre a exportação de documentos de apresentação para documentos TIFF através do Aspose.Slides for Java em [Converter Apresentações PowerPoint para TIFF](/slides/pt/java/convert-powerpoint-to-tiff/).
