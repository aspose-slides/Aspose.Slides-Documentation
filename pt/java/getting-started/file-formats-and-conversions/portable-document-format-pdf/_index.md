O [Portable Document Format](https://en.wikipedia.org/wiki/PDF) é um formato de arquivo criado pela Adobe Systems para troca de documentos entre organizações. O objetivo do formato era manter o conteúdo e o layout iguais, independentemente da plataforma em que fosse visualizado. O Aspose.Slides for Java permite converter arquivos de apresentação para PDF.

{{% /alert %}}

## **PDF no Aspose.Slides for Java**
Qualquer apresentação que possa ser carregada no Aspose.Slides for Java pode ser convertida em um PDF que segue [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) ou [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) dependendo da sua escolha. O Aspose.Slides for Java exporta apresentações para PDF e, na maioria dos casos, o PDF resultante tem exatamente a mesma aparência da apresentação original.

O Aspose.Slides oferece suporte aos seguintes recursos de apresentação ao converter para PDF:

- Imagens, caixas de texto e outras formas.
- Texto e formatação.
- Parágrafos e formatação.
- Hiperlinks.
- Cabeçalhos e rodapés.
- Marcadores.
- Tabelas.

Você pode exportar apresentações para PDFs diretamente usando o Aspose.Slides for Java: não precisa de nenhum outro componente. Além disso, você pode personalizar a exportação da apresentação para PDF com várias opções, conforme explicado em [Convert PPT and PPTX to PDF](/slides/pt/java/convert-powerpoint-to-pdf/).
