## **Plataformas Suportadas**
Aspose.Slides for Java oferece suporte às plataformas de desenvolvimento e implantação mais populares.

|**Recurso**|**Descrição**|
| :- | :- |
|Aplicações Desktop|Aspose.Slides for Java pode ser usado para desenvolver aplicações Windows Forms.|
|Aplicações Web Corporativas|Usar Aspose.Slides for Java ajuda a construir aplicações Web. Também é fornecido suporte ao uso do Aspose.Slides for Java com PHP.|
|Linux/Unix|Aspose.Slides for Java é uma API independente de plataforma e pode funcionar em ambientes Linux e Unix.|

## **Formatos de Arquivo e Conversões**
Aspose.Slides for Java oferece suporte à maioria dos formatos de documentos do Microsoft PowerPoint e os exporta para formatos populares amplamente usados por organizações.

|**Recurso**|**Descrição**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/pt/java/microsoft-powerpoint-ppt/)|Aspose.Slides for Java fornece o processamento mais rápido para este formato de documento de apresentação.|
|[PresentationML (PPTX, XML)](/slides/pt/java/presentationml-pptx-xml/)|Aspose.Slides for Java oferece suporte ao processamento do formato de apresentação OOXML (também conhecido como PresentationML ou PPTX).|
|[PPT to PPTX conversion](/slides/pt/java/ppt-to-pptx-conversion/)|Aspose.Slides for Java suporta a conversão de PPT para PPTX.|
|[Portable Document Format (PDF)](/slides/pt/java/developer-guide/)|Os formatos de arquivo suportados podem ser exportados para documentos Adobe Portable Document Format (PDF) com um único método.|
|[XML Parser Specification (XPS)](/slides/pt/java/xml-parser-specification-xps/)|Todos os formatos de arquivo suportados podem ser exportados para documentos XML Parser Specification (XPS) com um único método.|
|[Tagged Image File Format (TIFF)](https://docs.aspose.com/slides/pt/java/convert-powerpoint-to-tiff/)|Os formatos de arquivo de apresentação suportados pelo Aspose.Slides for Java também podem ser exportados para Tagged Image File Format (TIFF).|
|[ODP to PPTX Conversion](https://docs.aspose.com/slides/pt/java/convert-odp-to-pptx/)|Aspose.Slides for Java oferece suporte ao carregamento de OpenDocument Presentation (ODP) e à conversão para PPTX.|
|[Presentation To HTML Conversion](https://docs.aspose.com/slides/pt/java/convert-powerpoint-to-html/)|Aspose.Slides for Java oferece suporte à conversão de PresentationEx para o formato HTML.|

## **Recursos de Formatação**
É possível formatar texto e formas em slides de um documento de apresentação usando Aspose.Slides for Java.

|**Recurso**|**Descrição**|
| :- | :- |
|Formatação de Texto|<p>No Aspose.Slides for Java, o texto é gerenciado por meio de quadros de texto associados a formas. Assim, o texto é formatado usando parágrafos e porções associadas aos quadros de texto. Os seguintes elementos de texto podem ser formatados.</p><p>- Tipo de fonte.</p><p>- Tamanho da fonte.</p><p>- Cor da fonte.</p><p>- Tons da fonte.</p><p>- Alinhamento do parágrafo.</p><p>- Marcadores do parágrafo.</p><p>- Orientação do parágrafo.</p>|
|Formatação de Forma|<p>No Aspose.Slides for Java, o elemento básico de um slide é a forma. Os seguintes elementos de Forma podem ser formatados usando Aspose.Slides for Java:</p><p>- Posição</p><p>- Tamanho</p><p>- Linha</p><p>- Preenchimento (incluindo padrão, gradiente e sólido).</p><p>- Texto</p><p>- Imagem</p>|

## **Perguntas Frequentes**

### Preciso instalar o Microsoft PowerPoint no servidor/PC para que a biblioteca funcione?

Não. O PowerPoint não é necessário; Aspose.Slides é um mecanismo autônomo para criar, editar, converter e renderizar apresentações.

### Como o multithreading funciona? O processamento pode ser paralelizado?

É seguro processar documentos diferentes em threads diferentes; o mesmo [apresentação](https://reference.aspose.com/slides/pt/java/com.aspose.slides/presentation/) objeto não deve ser usado por [várias threads](/slides/pt/java/multithreading/) ao mesmo tempo.

### São suportadas senhas de arquivos e criptografia?

Sim. [Você pode](/slides/pt/java/password-protected-presentation/) abrir apresentações criptografadas, definir ou remover uma senha de abertura e gravação, e verificar o status da proteção.

### Preciso me preocupar com pacotes de fontes em contêineres Linux?

Sim. É recomendável instalar pacotes de fontes comuns e/ou especificar explicitamente [diretórios de fontes](/slides/pt/java/custom-font/) em sua aplicação para evitar substituições inesperadas.

### Existem limitações na versão de avaliação?

No [modo de avaliação](/slides/pt/java/licensing/), uma marca d'água é adicionada à saída e certas limitações se aplicam; uma [licença temporária de 30 dias](https://purchase.aspose.com/temporary-license/) está disponível para testes com todos os recursos.

### O suporte à importação de formatos externos para uma apresentação (PDF/HTML → PPTX) está disponível?

Sim. Você pode adicionar [páginas PDF e conteúdo HTML](/slides/pt/java/import-presentation/) a uma apresentação, transformando-os em slides.
