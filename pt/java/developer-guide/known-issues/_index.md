## **Visão geral**

Esta seção não contém uma lista de problemas abertos na versão atual. Ela contém três páginas:

- [Object Preview Placeholder When Adding OleObjectFrame](/slides/pt/java/object-preview-issue-when-adding-oleobjectframe/) explica por que um objeto OLE adicionado com Aspose.Slides exibe uma imagem "EMBEDDED OLE OBJECT" até que sua visualização seja atualizada, e como definir sua própria imagem de visualização. Este é um comportamento intencional da versão atual.
- [Known Issues in Aspose.Slides for Java 14.3.0 (Historical)](/slides/pt/java/known-issues-in-aspose-slides-for-java-14-3-0/) e [Known Issues in Aspose.Slides for Java 14.4.0 (Historical)](/slides/pt/java/known-issues-in-aspose-slides-for-java-14-4-0/) são listas publicadas com essas versões, mantidas para referência.

Para as alterações e correções em cada versão, veja as [release notes](https://releases.aspose.com/slides/pt/java/release-notes/). Os campos de metadata que o Aspose.Slides grava com valores fixos são descritos em [Output Metadata Limitations](/slides/pt/java/api-limitations/). Para verificar se um problema já é conhecido ou para relatar um, use o [support forum](https://forum.aspose.com/c/slides/pt/11).
