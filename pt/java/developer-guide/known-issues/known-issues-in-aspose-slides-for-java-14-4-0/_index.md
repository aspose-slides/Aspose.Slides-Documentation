{{% alert color="info" title="Note" %}}

Esta é uma página histórica. Ela lista as restrições e problemas conhecidos publicados com Aspose.Slides for Java 14.4.0 e não descreve a versão atual. Para as alterações em cada versão, veja as [notas de versão](https://releases.aspose.com/slides/pt/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.4.0 oferece nova decisão para o processamento de documentos PowerPoint. Existem algumas restrições e problemas conhecidos, que serão removidos nas próximas versões:

- Algumas formas têm geometria incorreta em documentos PPT serializados (arco, seta circular, balões de chamada).
- Nem todos os recursos de formatação de texto do PPTX são suportados na serialização para PPT (limitações de tabulação, indentação e formatação de parágrafos).
- Informações sobre idioma do texto e configurações de ortografia não estão presentes em documentos PPT serializados.
- Nem todos os recursos de tema do PPTX são suportados na serialização para PPT (apenas a serialização de formatos de preenchimento, formatos de linha e fonte).
- Existem problemas conhecidos na serialização OLE/ActiveX de PPT para PPT.
- A serialização e renderização de WordArt não são suportadas.
