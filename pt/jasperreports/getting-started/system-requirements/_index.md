## **JasperReports**

Aspose.Slides for JasperReports funciona com JasperReports 3.7.2 a 6.16.0. O download possui um jar separado para cada uma das três faixas de versão — veja [Installing Aspose.Slides for JasperReports](/slides/pt/jasperreports/installing-aspose-slides-for-jasperreports/) para saber qual usar. Não há jar para JasperReports 6.17.0 ou posterior, incluindo JasperReports 7.

O suporte ao JasperReports 2.0.3 a 3.7.1 terminou no Aspose.Slides for JasperReports 17.6. A versão 17.5 e anteriores também suportavam essas versões.

## **Java**

Os jars são compilados para Java 6 ou posterior, como indica o *JDK 1.6* nos nomes das pastas, portanto a versão do Java que você precisa é a que sua versão do JasperReports requer. Com JasperReports 6.16.0, as exportações são executadas em Java 11, 17, 21 e 25.

## **Operating system**

Os jars contêm apenas classes e recursos Java, sem bibliotecas nativas, e não utilizam o Microsoft PowerPoint. No Linux, o JasperReports precisa do fontconfig e de pelo menos uma fonte instalada para preencher um relatório.

## **JasperReports Server**

Para o JasperReports Server, use ambos os jars da pasta que corresponde à versão do JasperReports que seu servidor executa — veja [Integration with JasperServer](/slides/pt/jasperreports/integration-with-jasperserver/).
