Esta seção fornece uma descrição detalhada dos recursos do Aspose.Slides for JasperReports. Clique nos links da tabela para saber mais sobre os recursos.

|**Recurso** |**Descrição** |
| :- | :- |
|[Exportação PPT, PPTX, PDF e HTML](/slides/pt/jasperreports/ppt-pptx-pdf-and-html-export/)|Exporte relatórios como apresentações PPT e PPTX, documentos PDF e arquivos HTML a partir de sua aplicação sem usar o Microsoft PowerPoint.|
|Alta fidelidade ao design do relatório|Os relatórios PPT e PPTX têm o mesmo layout e aparência que PDFs e outros formatos.|
|Implantação fácil e leve|Aspose.Slides for JasperReports é um exportador para JasperReports e JasperServer para o formato Microsoft PowerPoint.|
|[Licenciamento simples e acessível](/slides/pt/jasperreports/licensing/)|Uma licença por servidor ou uma licença para todos os seus servidores.|
|[Suporte técnico gratuito de classe mundial](/slides/pt/jasperreports/technical-support/)|Suporte técnico ilimitado é fornecido diretamente pelos desenvolvedores que trabalham no produto.|
