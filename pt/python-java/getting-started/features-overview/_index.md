## **Plataformas Suportadas**
Aspose.Slides for Python via Java é uma API independente de plataforma. Pode ser usada em qualquer plataforma (Windows, Linux, macOS, etc.) onde o Python 3.7 ou superior esteja instalado. JDK 8 ou superior é outro requisito.

## **Formatos de Arquivo e Conversões**
Aspose.Slides for Python via Java suporta a maioria dos formatos de documento do PowerPoint. Também permite exportá‑los para os formatos de arquivo populares que as organizações usam e compartilham entre si. Confira os detalhes a seguir:

|**Feature**|**Description**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java fornece o processamento mais rápido para este formato de documento de apresentação.|
|Conversão de PPT para PPTX|Aspose.Slides for Python via Java suporta a conversão de PPT para PPTX|
|Portable Document Format (PDF)|Você pode exportar todos os formatos de arquivo suportados para documentos Adobe Portable Document Format (PDF) com um único método.|
|XML Parser Specification (XPS)|Você pode exportar todos os formatos de arquivo suportados para documentos XML Parser Specification (XPS) com um único método.|
|Tagged Image File Format (TIFF)|Você pode exportar todos os formatos de apresentação suportados para Tagged Image File Format (TIFF).|
|Conversão de PPTX para HTML|Aspose.Slides for Python via Java suporta a conversão de PresentationEx para o formato HTML.|

## **Renderização de Apresentação**
Aspose.Slides for Python via Java suporta renderização de alta fidelidade dos slides de apresentação para diferentes formatos gráficos. Confira os detalhes a seguir:

|**Feature**|**Description**|
| :- | :- |
|Formatos de Imagem Compatíveis com Java|Usando Aspose.Slides for Python via Java, você pode renderizar slides de apresentação e imagens nos slides para todos os formatos gráficos compatíveis com Java, como TIFF, PNG, BMP, JPEG e GIF.|
|Formato SVG|Aspose.Slides for Python via Java também fornece métodos embutidos que permitem exportar slides de apresentação para formatos Scalable Vector Graphics (SVG).|

## **Recursos de Conteúdo**
Aspose.Slides for Python via Java permite acessar, modificar ou criar quase todos os itens ou conteúdos de documentos de apresentação. Confira os detalhes a seguir:

|**Feature**|**Description**|
| :- | :- |
|Slides Mestre|Os Slides Mestre definem o layout dos slides normais. Aspose.Slides for Python via Java permite acessar e modificar os Slides Mestre de documentos de apresentação|
|Slides Normais|Com Aspose.Slides for Python via Java, você pode criar novos slides de diferentes tipos; também pode acessar e modificar slides existentes nas apresentações|
|Clonagem / Cópia de Slides|Existem métodos embutidos fornecidos por Aspose.Slides for Python via Java que permitem clonar ou copiar slides existentes dentro de uma apresentação. Você também pode usar slides copiados e clonados de uma apresentação para outra. Como um slide herda seu layout do slide mestre, os métodos de clonagem embutidos copiam automaticamente o mestre durante a clonagem|
|Gerenciamento de Seções de Slides|Métodos para organizar slides em diferentes seções dentro de uma apresentação|
|Marcadores de Espaço e Marcadores de Texto|Você pode acessar os marcadores de espaço e os marcadores de texto em um slide. Além disso, pode criar um slide com marcadores de texto do zero usando o método apropriado|
|Cabeçalhos e Rodapés|Aspose.Slides for Python via Java facilita o tratamento de cabeçalhos/rodapés nos slides|
|Anotações em Slides|Com Aspose.Slides for Python via Java, você pode acessar e modificar notas associadas a um slide e também adicionar novas notas|
|Encontrar uma Forma|Você também pode encontrar uma forma específica em um slide usando o texto alternativo associado à forma|
|Fundos|Aspose.Slides for Python via Java permite trabalhar com fundos associados a um slide mestre ou normal em uma apresentação|
|Caixas de Texto|Caixas de texto podem ser criadas do zero. Você pode acessar caixas de texto existentes. Também pode modificar seus textos sem perder o formato original|
|Formas Retangulares|Você pode criar ou modificar formas retangulares com Aspose.Slides for Python via Java|
|Formas de Polilinha|Você pode criar ou modificar formas de polilinha com Aspose.Slides for Python via Java|
|Formas Elípticas|Você pode criar ou modificar formas elípticas com Aspose.Slides for Python via Java|
|Formas Agrupadas|Aspose.Slides for Python via Java suporta formas agrupadas|
|Formas Automáticas|Aspose.Slides for Python via Java suporta auto shapes|
|SmartArt|Aspose.Slides for Python via Java oferece suporte a formas SmartArt no MS PowerPoint|
|Charts|Aspose.Slides for Python via Java oferece suporte a Gráficos MSO no PowerPoint|
|Serialização de Formas|Aspose.Slides for Python via Java suporta um grande número de formas. Quando Aspose.Slides for Python via Java não oferece suporte a uma forma, você pode usar um método de serialização que permite serializar essa forma a partir de um slide existente. Dessa forma, você pode reutilizar a forma conforme necessário|
|Quadros de Imagem|Você pode gerenciar imagens em quadros de imagem com Aspose.Slides for Python via Java|
|Quadros de Áudio|Você pode vincular ou incorporar arquivos de áudio em quadros de áudio nos slides com Aspose.Slides for Python via Java|
|Quadros de Vídeo|Você pode manipular arquivos de vídeo em quadros de vídeo. Aspose.Slides for Python via Java também oferece suporte a vídeos vinculados e incorporados|
|Quadro OLE|Você pode gerenciar objetos OLE em quadros OLE com Aspose.Slides for Python via Java|
|Tabelas|Aspose.Slides for Python via Java suporta tabelas em slides|
|Controles ActiveX|Suporte a controles ActiveX|
|Macros VBA|Suporte ao gerenciamento de macros VBA dentro de apresentações.|
|Quadro de Texto|Você pode acessar o texto de qualquer forma através do quadro de texto associado a essa forma|
|Escaneamento de Texto|Você pode escanear texto em uma apresentação no nível da apresentação ou do slide por meio de métodos de escaneamento embutidos.|
|Animações|Você pode aplicar animações em formas|
|Apresentações de Slides|Aspose.Slides for Python via Java suporta apresentações de slides e transições de slides|

## **Recursos de Formatação**
Com Aspose.Slides for Python via Java, você pode formatar textos e formas nos slides de apresentações. Confira os detalhes a seguir:

|**Feature**|**Description**|
| :- | :- |
|Text Formatting|<p>No Aspose.Slides for Python via Java, você pode gerenciar textos por meio dos quadros de texto associados às formas. Assim, você pode formatar textos usando os parágrafos e trechos associados aos quadros de texto. Esses elementos de texto podem ser formatados através do Aspose.Slides for Python via Java.</p><p>- Tipo de Fonte</p><p>- Tamanho da Fonte</p><p>- Cor da Fonte</p><p>- Tons da Fonte</p><p>- Alinhamento de Parágrafo</p><p>- Marcadores de Parágrafo</p><p>- Orientação de Parágrafo</p>|
|Shape Formatting|<p>No Aspose.Slides for Python via Java, o elemento básico de um slide é uma forma. Você pode formatar esses elementos de forma com Aspose.Slides for Python via Java:</p><p>- Posição</p><p>- Tamanho</p><p>- Linha</p><p>- Preenchimento (incluindo Padrão, Gradiente, Sólido)</p><p>- Texto</p><p>- Imagem</p>|
