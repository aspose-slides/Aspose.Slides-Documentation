Este artigo descreve as capacidades de processamento de apresentações do Aspose.Slides for Python via Java. Para sistemas operacionais suportados e dependências, veja [System Requirements](/slides/pt/python-java/system-requirements/).

## **Formatos de Arquivo e Conversões**

Aspose.Slides for Python via Java permite converter entre formatos de apresentação e exportar apresentações para formatos de documento e web. Consulte [Supported File Formats](/slides/pt/python-java/supported-file-formats/) para a tabela completa de formatos e a distinção entre carregamento de apresentações, importação de conteúdo e exportação de saída.

## **Renderização de Apresentação**

Aspose.Slides for Python via Java fornece renderização de slides com alta fidelidade como imagens raster ou vetoriais para visualizações e outras saídas visuais. Também permite renderizar imagens em slides. Para formatos de imagem disponíveis e notas de exportação, veja [Supported File Formats](/slides/pt/python-java/supported-file-formats/#supported-file-formats).

|Layouts de Slide|Você pode trabalhar com layouts de slide.|

|Seções de Slide|Você pode organizar slides em seções dentro de uma apresentação.|
|Placeholders e Text Holders|Você pode acessar placeholders e text holders em um slide, bem como criar slides com text holders do zero.|
|Cabeçalhos e Rodapés|Aspose.Slides for Python via Java permite gerenciar cabeçalhos e rodapés.|
|Notas de Slide|Você pode acessar, adicionar e modificar notas de slide, e incluí‑las ao exportar para PDF ou TIFF.|
|Encontrar uma Forma|Você pode encontrar uma forma específica em um slide usando seu texto alternativo.|
|Texto Alternativo|Você pode ler e atualizar o texto alternativo de formas.|
|Hiperenlaces|Você pode ler e atualizar hiperenlaces em formas e adicionar hiperenlaces ao texto.|
|Fundos|Você pode trabalhar com os fundos de slides mestres e slides normais em uma apresentação.|
|Caixas de Texto|Você pode criar caixas de texto do zero, acessar caixas de texto existentes e modificar seu texto preservando a formatação original.|
|Formas Retangulares|Você pode criar e modificar formas retangulares.|
|Formas de Linha|Você pode criar e modificar formas de linha.|
|Formas Polilinha|Você pode criar e modificar formas polilinha.|

|Gráficos|Você pode criar e editar gráficos do Microsoft Office em apresentações do PowerPoint.|
|Serialização de Formas|Aspose.Slides for Python via Java suporta muitos tipos de forma. Para formas não suportadas, você pode usar serialização para preservar uma forma de um slide existente para reutilização.|
|Bloqueios de Forma|Você pode aplicar bloqueios de forma para restringir ações de edição.|
|Quadros de Imagem|Você pode gerenciar imagens em quadros de imagem.|
|Quadros de Áudio|Você pode vincular ou incorporar arquivos de áudio em quadros de áudio nos slides.|
|Quadros de Vídeo|Você pode gerenciar vídeos vinculados e incorporados em quadros de vídeo.|
|Quadros OLE|Você pode gerenciar objetos OLE em quadros OLE.|
|Tabelas|Você pode criar, mover e redimensionar tabelas; adicionar, excluir e redimensionar linhas e colunas; e ler e modificar o conteúdo das células, bordas, preenchimentos e formatação de texto.|
|Controles ActiveX|Aspose.Slides for Python via Java suporta controles ActiveX.|
|Macros VBA|Você pode gerenciar macros VBA em apresentações.|
|Quadros de Texto|Você pode acessar o texto de uma forma através do seu quadro de texto associado e ajustar as margens do quadro de texto e a quebra de linha.|
|Fontes|Você pode gerenciar as fontes usadas nas apresentações.|
|Digitalização de Texto|Métodos incorporados permitem escanear texto em toda a apresentação ou em slides individuais.|
|Animações|Você pode adicionar e modificar efeitos de animação em formas.|

## **Recursos de Formatação**

Aspose.Slides for Python via Java permite formatar texto e formas em slides de apresentação, conforme descrito abaixo:

|**Feature**|**Description**|
| :- | :- |
|Formatação de Texto|<p>Você pode gerenciar texto através dos quadros de texto associados às formas e formatar parágrafos individuais e trechos de texto. As seguintes opções de formatação estão disponíveis:</p><p>- Tipo de fonte</p><p>- Tamanho da fonte</p><p>- Cor da fonte</p><p>- Sombreamento da fonte</p><p>- Alinhamento de parágrafo</p><p>- Recuo e tabulação de parágrafo</p><p>- Marcadores de parágrafo</p><p>- Orientação do parágrafo</p>|
|Formatação de Forma|<p>Formas são os elementos básicos de um slide. Você pode ajustar as seguintes propriedades da forma:</p><p>- Posição</p><p>- Tamanho</p><p>- Rotação</p><p>- Estilos de linha</p><p>- Preenchimento (incluindo sólido, gradiente, padrão, textura e preenchimentos de imagem)</p><p>- Texto</p><p>- Imagem</p>|
