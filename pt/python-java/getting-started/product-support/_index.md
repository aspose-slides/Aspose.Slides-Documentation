## **Visão geral**

Use o fórum de suporte do Aspose.Slides para fazer perguntas, relatar problemas e solicitar recursos para o Aspose.Slides for Python via Java. Este artigo explica o que verificar antes de abrir um tópico e quais informações ajudam a equipe de suporte a reproduzir um problema.

## **Suporte técnico**

{{% alert color="info" title="Nota" %}}

A Aspose fornece suporte técnico gratuito a todos os usuários, inclusive aos que estão avaliando o produto. Consulte as [políticas de suporte gratuito](https://forum.aspose.com/t/free-support-policies/162313) para mais detalhes.

{{% /alert %}}

Publique perguntas técnicas no [fórum de suporte do Aspose.Slides](https://forum.aspose.com/c/slides/pt/11). Especifique **Aspose.Slides for Python via Java** em seu relatório para que a equipe possa identificar o produto e o ambiente corretos.

Para assistência prioritária, consulte o [helpdesk de suporte pago](https://helpdesk.aspose.com/). O suporte pago requer uma assinatura separada e não está incluído na licença do produto.

## **Antes de relatar um problema**

1. Verifique os [downloads](https://releases.aspose.com/slides/pt/python-java/) e as [notas de versão](https://releases.aspose.com/slides/pt/python-java/release-notes/) para ver se há uma versão mais recente que possa resolver o problema. Se possível, reproduza o problema com a versão mais recente em um ambiente de teste.  
2. Pesquise no fórum de suporte, na [documentação](/slides/pt/python-java/) e na [referência da API](https://reference.aspose.com/slides/pt/python-java/) para encontrar uma resposta já existente.  
3. Para problemas de instalação ou de inicialização da JVM, revise o [guia de instalação](/slides/pt/python-java/installation/) e confirme que Python e Java utilizam arquiteturas correspondentes.  
4. Reduza o problema ao menor exemplo e apresentação de entrada que ainda o reproduzam.

## **Prepare um relatório de problema**

Inclua as seguintes informações no seu tópico do fórum:

- **Ambiente:** versão do Aspose.Slides for Python via Java, versão do Python, versão e fornecedor do Java, versão do JPype, sistema operacional e arquitetura.  
- **Etapas e código:** um exemplo mínimo executável em Python, incluindo importações e inicialização da JVM, e as etapas necessárias para reproduzir o problema.  
- **Arquivos de entrada:** a apresentação e quaisquer arquivos relacionados exigidos pelo exemplo. Combine vários arquivos em um arquivo ZIP.  
- **Resultados esperados e reais:** descreva a diferença e anexe a saída gerada ou capturas de tela quando for útil. Para problemas de renderização, identifique os slides e fontes afetados.  
- **Detalhes do erro:** a mensagem completa de erro e o rastreamento de pilha, se ocorrer uma exceção.

Use um tópico por problema. Adicione informações de acompanhamento sobre o mesmo problema ao tópico existente para que a equipe de suporte possa acompanhar a investigação.

## **Perguntas frequentes**

**Posso obter ajuda enquanto avalio o Aspose.Slides for Python via Java?**

Sim. O suporte técnico gratuito está disponível através do fórum de suporte do Aspose.Slides durante a avaliação e também após a compra.

**O que devo incluir quando a JVM não iniciar?**

Forneça as versões do Python, Java e JPype, o sistema operacional, as arquiteturas do Python e do Java, o código de inicialização da JVM e a mensagem completa de erro. Esses detalhes ajudam a equipe de suporte a reproduzir sua configuração.

**Como devo relatar um problema que apareceu após uma atualização?**

Inclua a última versão que funcionou, a primeira versão em que o problema foi observado e um exemplo mínimo com os arquivos de entrada. Descreva quaisquer outras alterações no ambiente feitas durante a atualização.
