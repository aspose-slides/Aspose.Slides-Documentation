Você pode baixar Aspose.Slides for Python via Java para avaliar seus recursos. O pacote de avaliação é idêntico ao pacote licenciado. Para usá-lo sem limitações de avaliação, adicione algumas linhas de código para aplicar uma licença.

A versão de avaliação do Aspose.Slides (usada sem licença) fornece toda a funcionalidade do produto, mas insere uma marca d'água de avaliação no topo do documento ao abri‑lo ou salvá‑lo. A extração de texto é limitada a um slide por apresentação.

![Marca d'água de avaliação do Aspose.Slides em um slide de apresentação](evaluate-aspose-slides_1.png)

{{% alert color="info" title="Note" %}}

Para testar o Aspose.Slides sem limitações de avaliação, você pode solicitar uma **licença temporária de 30 dias**. Veja [Obter uma Licença Temporária](https://purchase.aspose.com/temporary-license) para mais informações.
