Você pode baixar Aspose.Slides for Python via Java para avaliar seus recursos. O pacote de avaliação é idêntico ao pacote licenciado. Para usá-lo sem limitações de avaliação, adicione algumas linhas de código a [aplicar uma licença](/slides/pt/python-java/licensing/).

A versão de avaliação do Aspose.Slides (usada sem licença) oferece funcionalidade completa do produto, com duas limitações:

- Ele adiciona uma caixa de texto com marca d'água de avaliação a cada slide de cada apresentação que salva. Abrir uma apresentação não adiciona uma, mas salvar um arquivo que já contém a marca d'água adiciona outra.
- O texto que seu código lê é truncado aos primeiros caracteres, seguido por um aviso sobre a limitação de avaliação. Isso se aplica a cada slide, e ao texto que seu código acabou de definir, bem como ao texto carregado de um arquivo. O texto que seu código grava é salvo completamente.

{{% alert color="info" title="Note" %}}

Para testar o Aspose.Slides sem limitações de avaliação, você pode solicitar uma **licença temporária de 30 dias**. Veja [Obter uma Licença Temporária](https://purchase.aspose.com/temporary-license) para mais informações.
