{{% alert color="info" title="Note" %}}

Aspose.Slides for Python via Java é uma biblioteca de classes que permite que aplicações Python leiam e escrevam apresentações sem exigir Microsoft PowerPoint®. Ela permite gerenciar texto, formas, tabelas e animações; adicionar áudio e vídeo aos slides; visualizar slides; e exportar slides para SVG, PDF e outros formatos.

Para obter detalhes, veja a [Aspose.Slides for Python via Java API Reference](https://reference.aspose.com/slides/pt/python-java/).
