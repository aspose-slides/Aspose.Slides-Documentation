{{% alert color="info" title="Note" %}}

Com o Aspose.Slides for SharePoint, você pode converter apresentações do PowerPoint para muitos formatos de documentos populares a partir de uma biblioteca de documentos do SharePoint.

{{% /alert %}}

## **Formatos de Entrada Compatíveis**

O Aspose.Slides for SharePoint converte os seguintes formatos de entrada:

- PPT – Apresentação Microsoft PowerPoint 97 - 2003
- PPTX – Apresentação Office Open XML

{{% alert color="info" title="Note" %}}

Para converter documentos, o Aspose.Slides for SharePoint depende de uma versão incorporada do [Aspose.Slides for .NET](https://products.aspose.com/slides/pt/net/).

{{% /alert %}}

## **Formatos de Saída Compatíveis**

A lista **Convert to** na página de conversão oferece os seguintes formatos de saída, nesta ordem:

- PDF – Documento Portátil Adobe
- TIFF – Pacote de Imagens
- XPS – Especificação de Papel XML
- PPS – Apresentação de Slides
- PPSX – Apresentação de Slides Open XML do Microsoft PowerPoint
- ODP – Apresentação OpenDocument
- PPTM – Apresentação do Microsoft PowerPoint Open XML com Macro
- PPSM – Apresentação de Slides do Microsoft PowerPoint Open XML com Macro
- POTX – Modelo do Microsoft PowerPoint
- POTM – Modelo de Apresentação do PowerPoint Open XML com Macro
- PDFNotes – Visualização de notas da apresentação em formato PDF
- HTML – Apresentação em formato HTML
- TIFFNotes – Visualização de notas da apresentação como imagem TIFF de várias páginas
- SWF – Filme Shockwave Flash
- SWFNotes – Visualização de notas da apresentação como SWF de várias páginas
