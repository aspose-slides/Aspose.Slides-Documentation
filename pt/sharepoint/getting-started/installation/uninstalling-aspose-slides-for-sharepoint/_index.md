Para desinstalar o Aspose.Slides for SharePoint:

1. Execute o programa de instalação que você usou para instalá-lo, por exemplo *Setup2019.exe* no SharePoint Server 2019.
   Quando ele encontra a mesma versão instalada, o programa de instalação oferece reparar ou remover. Quando encontra uma versão diferente, oferece atualizar ou remover.
2. Selecione **Remove** e clique em **Next** para desinstalar o Aspose.Slides for SharePoint.
