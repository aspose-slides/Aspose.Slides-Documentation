## **Versões do Microsoft PowerPoint suportadas**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **Formatos de arquivo suportados**

Aspose.Slides for SharePoint converte apresentações PPT e PPTX armazenadas em uma biblioteca de documentos do SharePoint. Arquivos de outros tipos não são convertidos.

|**Formato**|**Descrição**|**Converter de**|**Converter para**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|Apresentação PowerPoint 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|Apresentação PowerPoint 2007 e posterior|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|Formato de Documento Portátil, com os slides ou com a visualização de notas| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|Imagem TIFF, com os slides ou com a visualização de notas| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|Especificação de Papel XML| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|Apresentação em formato HTML| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Filme Shockwave Flash, com os slides ou com a visualização de notas| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|Apresentação OpenDocument| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|Apresentação de slides PowerPoint 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|Apresentação de slides PowerPoint 2007 e posterior| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|Apresentação PowerPoint habilitada para macros| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|Apresentação de slides PowerPoint com macros habilitadas| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|Modelo PowerPoint| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|Modelo PowerPoint com macros habilitadas| |{{< emoticons/tick >}}|

O formato de saída é selecionado em **Convert to** na página de conversão; veja [Multiple Format Support](/slides/pt/sharepoint/multiple-format-support/) para a lista completa de opções.
