Para converter uma apresentação em uma biblioteca de documentos:

1. Abra o menu do arquivo PPT ou PPTX (seu Edit Control Block) e selecione **Convert via Aspose.Slides**. No SharePoint 2007, o item de menu se chama **Convert with Aspose.Slides**.

   **Selecionando Convert with Aspose.Slides no menu de um documento no SharePoint 2007**

   ![O menu de um documento em uma biblioteca de documentos do SharePoint 2007, com o item Convert with Aspose.Slides](convert-one-file_1.png)

2. Na página de conversão, selecione o formato de saída em **Convert to**. Se desejar, altere o nome do arquivo de destino e a pasta de destino.
3. Clique em **Convert**.
4. Quando a conversão for concluída, clique em **Source Library** ou **Destination Library** para retornar a uma biblioteca de documentos. O arquivo convertido está na pasta de destino.

Os mesmos passos, com capturas de tela de cada página, estão em [Convertendo documentos Microsoft PowerPoint em outros formatos](/slides/pt/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
