{{% alert color="info" %}} 

Todos os componentes Aspose C++ requerem o conjunto de permissões Full Trust. O motivo é que os componentes Aspose C++ precisam acessar configurações do registro, arquivos do sistema além do diretório virtual para certas operações, como análise de fontes etc. Além disso, os componentes Aspose C++ são baseados nas classes de sistema core C++ que também exigem o conjunto de permissões Full Trust em muitos casos. 

{{% /alert %}}
