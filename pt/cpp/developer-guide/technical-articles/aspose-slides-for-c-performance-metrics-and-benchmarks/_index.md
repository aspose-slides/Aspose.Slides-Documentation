## **Objetivo**
O desempenho costuma ser o primeiro fator crítico ao escolher um componente. Este artigo mede o desempenho do Aspose.Slides for C++ e VSTO 2008. Os testes simples são realizados em sistemas operacionais, componentes de hardware e configurações semelhantes. 


Este artigo apresenta medições de desempenho para produtos incluindo **Aspose.Slides for C++** e **VSTO 2008**. As estimativas de desempenho apresentadas aqui destinam‑se a ajudá‑lo a entender o que esperar de diferentes componentes em alguns cenários comumente usados sob configurações semelhantes em hardware convencional executando sistemas operacionais amplamente utilizados. Naturalmente, o desempenho da sua aplicação depende dos seus dados, padrões de acesso a dados, tamanho do cache, outros parâmetros de configuração, sistema operacional e hardware etc. O benchmark visa ilustrar como os componentes se comportam em condições mínimas de hardware; quanto mais rápido o hardware, mais rapidamente as tarefas serão processadas pelos componentes.

## **Metodologia de Teste**
Todos os testes de desempenho foram conduzidos em combinações comuns de hardware e sistema operacional, sem configuração personalizada, ajuste ou quaisquer outras técnicas de aprimoramento de desempenho. Todos os testes foram executados com as instalações dos componentes no mesmo sistema que, de outra forma, permanecia inativo. Para obter leituras precisas, realizamos todas as tarefas duas ou três vezes consecutivas para avaliar melhor um componente e obter leituras precisas.
