Για να μετατρέψετε μια παρουσίαση σε μια βιβλιοθήκη εγγράφων:

1. Ανοίξτε το μενού του αρχείου PPT ή PPTX (το Edit Control Block του) και επιλέξτε **Convert via Aspose.Slides**. Στο SharePoint 2007, το στοιχείο μενού ονομάζεται **Convert with Aspose.Slides**.

   **Επιλογή Convert with Aspose.Slides στο μενού ενός εγγράφου στο SharePoint 2007**

   ![Το μενού ενός εγγράφου σε μια βιβλιοθήκη εγγράφων SharePoint 2007, με το στοιχείο Convert with Aspose.Slides](convert-one-file_1.png)

2. Στη σελίδα μετατροπής, επιλέξτε τη μορφή εξόδου κάτω από **Convert to**. Εάν θέλετε, αλλάξτε το όνομα του αρχείου προορισμού και το φάκελο προορισμού.
3. Κάντε κλικ στο **Convert**.
4. Όταν ολοκληρωθεί η μετατροπή, κάντε κλικ στο **Source Library** ή στο **Destination Library** για να επιστρέψετε σε μια βιβλιοθήκη εγγράφων. Το μετατρεπόμενο αρχείο βρίσκεται στον φάκελο προορισμού.

Τα ίδια βήματα, με στιγμιότυπα οθόνης κάθε σελίδας, περιλαμβάνονται στο [Converting Microsoft PowerPoint Documents into Other Formats](/slides/el/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
