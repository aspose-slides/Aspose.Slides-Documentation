## **Μετατροπή παρουσίασης**

To convert a Microsoft PowerPoint presentation (PPT or PPTX) from a SharePoint document library:

1. Select a Microsoft PowerPoint presentation in a document library.
2. Open its menu and click **Convert via Aspose.Slides**.

   **Το μενού του αρχείου Presentation 2, όπου εμφανίζεται το στοιχείο Convert via Aspose.Slides**

   ![Το μενού μιας παρουσίασης σε βιβλιοθήκη εγγράφων, με το στοιχείο Convert via Aspose.Slides επισημασμένο](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. Select the output format under **Convert to**. If you wish, change the output file name and the destination folder.
4. Click **Convert** to convert the file.

   **Η σελίδα μετατροπής σας επιτρέπει να επιλέξετε τη μορφή εξόδου, το όνομα του αρχείου και τον προορισμό**

   ![Η σελίδα μετατροπής με τη μορφή εξόδου, το αρχείο προορισμού και το φάκελο προορισμού](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. When the conversion is complete, a success message is displayed.

   **Η μετατροπή ολοκληρώθηκε με επιτυχία**

   ![Η σελίδα αποτελεσμάτων της μετατροπής](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. Click **Source Library** (to go to the source folder) or **Destination Library** (to go to the folder the file was saved to).

   The converted document appears in the document library.

   **Το μετατρεπόμενο έγγραφο που εμφανίζεται στη βιβλιοθηκή στην οποία αποθηκεύτηκε**

   ![Το μετατρεπόμενο αρχείο στη βιβλιοθήκη εγγράφων](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

Τα στιγμιότυπα οθόνης ελήφθησαν με μια παλαιότερη έκδοση, η οποία πρόσφερε μόνο τις μορφές PDF, TIFF και XPS. Η τρέχουσα σελίδα μετατροπής προσφέρει περισσότερες μορφές εξόδου· δείτε [Multiple Format Support](/slides/el/sharepoint/multiple-format-support/).

{{% /alert %}}

On SharePoint 2010 and later, you can also select one or more presentations in the library and click **Convert Slides** on the **Aspose Tools** ribbon tab. It opens the same conversion page.
