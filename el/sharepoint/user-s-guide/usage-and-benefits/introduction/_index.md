## **Τι είναι το SharePoint και το Aspose.Slides?**

Το Aspose.Slides για SharePoint είναι μια λύση για τη μετατροπή παρουσιάσεων Microsoft PowerPoint (PPT και PPTX) σε άλλες μορφές: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX και POTM. Σας επιτρέπει να μετατρέψετε αρχεία PowerPoint σε έναν ιστότοπο SharePoint χωρίς να χρησιμοποιήσετε το Microsoft PowerPoint. Η πλήρης λίστα μορφών βρίσκεται στο [Supported File Formats](/slides/el/sharepoint/supported-file-formats/).
