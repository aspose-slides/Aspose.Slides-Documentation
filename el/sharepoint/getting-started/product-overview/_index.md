## **Επισκόπηση Προϊόντος**

Το Aspose.Slides for SharePoint μετατρέπει τις παρουσιάσεις PowerPoint που αποθηκεύονται σε βιβλιοθήκες εγγράφων του SharePoint σε άλλες μορφές, στον διακομιστή.

Μετατρέπει τις ακόλουθες μορφές PowerPoint:

- PPT – Παρουσίαση Microsoft PowerPoint 97‑2003
- PPTX – Παρουσίαση Office Open XML

Τα μετατρέπει σε PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX και POTM. Δείτε [Υποστηριζόμενες Μορφές Αρχείων](/slides/el/sharepoint/supported-file-formats/) για λεπτομέρειες.

Η λήψη περιέχει ξεχωριστό πρόγραμμα εγκατάστασης και πακέτο λύσης για καθεμία από τις παρακάτω προϊόντα:

- SharePoint 2007
- SharePoint 2010
- SharePoint Server 2013
- SharePoint Server 2016
- SharePoint Server 2019

**Χρησιμοποιήστε το Aspose.Slides for SharePoint για να μετατρέψετε έγγραφα από τη βιβλιοθήκη εγγράφων του SharePoint**
