Για απεγκατάσταση του Aspose.Slides for SharePoint:

1. Εκτελέστε το πρόγραμμα εγκατάστασης που χρησιμοποιήσατε για την εγκατάστασή του, π.χ. *Setup2019.exe* σε SharePoint Server 2019.
   Όταν εντοπίσει την ίδια έκδοση εγκατεστημένη, το πρόγραμμα εγκατάστασης προσφέρει την επισκευή ή την κατάργηση. Όταν εντοπίσει διαφορετική έκδοση, προσφέρει την αναβάθμιση ή την κατάργηση.
2. Επιλέξτε **Remove** και κάντε κλικ στο **Next** για απεγκατάσταση του Aspose.Slides for SharePoint.
