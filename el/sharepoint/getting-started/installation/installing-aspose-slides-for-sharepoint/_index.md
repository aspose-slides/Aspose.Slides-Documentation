## **Περιεχόμενα Πακέτου**

Το Aspose.Slides for SharePoint κατεβάζεται από τη [σελίδα λήψης](https://releases.aspose.com/slides/el/sharepoint/) ως αρχείο ZIP. Το αρχείο περιέχει ένα πακέτο λύσης SharePoint (WSP) και ένα πρόγραμμα εγκατάστασης για κάθε υποστηριζόμενη έκδοση του SharePoint:

| Έκδοση SharePoint | Πρόγραμμα εγκατάστασης | Πακέτο λύσης |
| :- | :- | :- |
| SharePoint 2007 | Setup2007.exe | Aspose.Slides.SharePoint2007.wsp |
| SharePoint 2010 | Setup2010.exe | Aspose.Slides.SharePoint2010.wsp |
| SharePoint Server 2013 | Setup2013.exe | Aspose.Slides.SharePoint2013.wsp |
| SharePoint Server 2016 | Setup2016.exe | Aspose.Slides.SharePoint2016.wsp |
| SharePoint Server 2019 | Setup2019.exe | Aspose.Slides.SharePoint2019.wsp |

Κάθε πρόγραμμα εγκατάστασης διαθέτει ένα αρχείο διαμόρφωσης δίπλα του (π.χ., *Setup2019.exe.config*) που καθορίζει το πακέτο λύσης που εγκαθιστά. Ο φάκελος *License* περιέχει έναν σύνδεσμο προς τη συμφωνία χρήστη τελικού χρήστη και τις σημειώσεις αδειών τρίτων.

Το Aspose.Slides for SharePoint πακετοποιείται ως λύση SharePoint, η οποία αναπτύσσεται από το SharePoint σε όλο το αγρό κεντρικού υπολογιστή. Η δυνατότητα του ενεργοποιείται ή απενεργοποιείται ανά συλλογή τοποθεσιών.

## **Διαδικασία Εγκατάστασης**

Πριν από την εγκατάσταση, το πρόγραμμα εγκατάστασης εκτελεί έναν έλεγχο συστήματος. Επαληθεύει ότι:

- Το SharePoint είναι εγκατεστημένο στον διακομιστή.
- Ο τρέχων χρήστης έχει άδεια να εγκαθιστά και να αναπτύσσει λύσεις SharePoint.
- Η υπηρεσία SharePoint Administration είναι ενεργοποιημένη.
- Η υπηρεσία SharePoint Timer είναι ενεργοποιημένη.
- Το πακέτο λύσης που ορίζεται στο αρχείο διαμόρφωσης υπάρχει.

Οι υπηρεσίες Administration και Timer απαιτούνται επειδή ορισμένες ενέργειες εγκατάστασης εκτελούνται ως εργασίες χρονοδιακόπτη που διαδίδουν τη λύση σε όλους τους διακομιστές του αγρού.

### **Εκτέλεση της Εγκατάστασης**

Για να εγκαταστήσετε το Aspose.Slides for SharePoint:

1. Αποσυμπιέστε το αρχείο ZIP σε τοπικό δίσκο σε έναν διακομιστή του αγρού SharePoint.
2. Εκτελέστε το πρόγραμμα εγκατάστασης που ταιριάζει με την έκδοση του SharePoint σας (δείτε τον πίνακα παραπάνω) και ακολουθήστε τις οδηγίες στην οθόνη. Το πρόγραμμα εγκατάστασης:
   1. Εκτελεί τον έλεγχο συστήματος. Η εγκατάσταση δεν συνεχίζει εάν κάποιος έλεγχος αποτύχει.

      **Εκτέλεση ελέγχου συστήματος**

      ![Οθόνη ελέγχου συστήματος του προγράμματος εγκατάστασης](installing-aspose-slides-for-sharepoint_1.png)

   2. Εμφανίζει τη συμφωνία άδειας τελικού χρήστη. Πρέπει να τη δεχτείτε για να συνεχίσετε.

      **Η συμφωνία άδειας**

      ![Οθόνη συμφωνίας άδειας του προγράμματος εγκατάστασης](installing-aspose-slides-for-sharepoint_2.png)

   3. Εμφανίζει τους στόχους ανάπτυξης. Επιλέξτε τις εφαρμογές web και τις συλλογές τοποθεσιών για τις οποίες θα ενεργοποιηθεί η δυνατότητα.

      **Επιλογή στόχων ανάπτυξης**

      ![Οθνη στόχων ανάπτυξης συλλογών τοποθεσιών του προγράμματος εγκατάστασης](installing-aspose-slides-for-sharepoint_3.png)

   4. Αναπτύσσει τη λύση στον αγρό.

      **Η πρόοδος εγκατάστασης**

      ![Οθνη προόδου εγκατάστασης του προγράμματος εγκατάστασης](installing-aspose-slides-for-sharepoint_4.png)

   5. Ενεργοποιεί το Aspose.Slides for SharePoint στις επιλεγμένες συλλογές τοποθεσιών.
   6. Παραθέτει τις εφαρμογές web και τις συλλογές τοποθεσιών όπου η λύση έχει αναπτυχθεί και ενεργοποιηθεί.

      **Επιτυχής εγκατάσταση**

      ![Οθνη ολοκλήρωσης εγκατάστασης του προγράμματος εγκατάστασης](installing-aspose-slides-for-sharepoint_5.png)

{{% alert color="info" title="Note" %}}
Τα στιγμιότυπα οθόνης ελήφθησαν στο SharePoint 2007. Τα προγράμματα εγκατάστασης για μεταγενέστερες εκδόσεις περνούν από τις ίδιες οθόνες.
{{% /alert %}}

Εάν η ίδια έκδοση του Aspose.Slides for SharePoint είναι ήδη εγκατεστημένη, το πρόγραμμα εγκατάστασης προσφέρει να το επισκευάσει ή να το αφαιρέσει. Εάν άλλη έκδοση είναι εγκατεστημένη, προσφέρει να το αναβαθμίσει ή να το αφαιρέσει.

Μετά την εγκατάσταση, ένα στοιχείο **Μετατροπή μέσω Aspose.Slides** εμφανίζεται στο μενού αρχείων στις βιβλιοθήκες εγγράφων των επιλεγμένων συλλογών τοποθεσιών (στο SharePoint 2007, **Μετατροπή με Aspose.Slides**). Για να μετατρέψετε την πρώτη παρουσίαση, δείτε [Μετατροπή εγγράφων Microsoft PowerPoint σε άλλες μορφές](/slides/el/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/). Αυτό που προσθέτει η λύση στον αγρό περιγράφεται στο [Ανάπτυξη και Ενεργοποίηση](/slides/el/sharepoint/deployment-and-activation/).

## **Συχνές Ερωτήσεις**

**Ποιο πρόγραμμα εγκατάστασης πρέπει να τρέξω;**

Αυτό που το όνομα του ταιριάζει με την έκδοση του SharePoint σας. Για παράδειγμα, εκτελέστε *Setup2016.exe* σε έναν αγρό SharePoint Server 2016. Κάθε πρόγραμμα εγκατάστασης εγκαθιστά μόνο το δικό του πακέτο λύσης.

**Χρειάζομαι ξεχωριστή λήψη για την έκδοση με άδεια;**

Όχι. Το ίδιο πακέτο λειτουργεί σε λειτουργία δοκιμής μέχρι να εγκαταστήσετε τη λύση άδειας· δείτε [Εγκατάσταση άδειας Aspose.Slides για SharePoint](/slides/el/sharepoint/installing-aspose-slides-for-sharepoint-license/).

**Πώς αφαιρώ το προϊόν;**

Εκτελέστε ξανά το ίδιο πρόγραμμα εγκατάστασης και επιλέξτε **Κατάργηση**· δείτε [Κατάργηση εγκατάστασης Aspose.Slides για SharePoint](/slides/el/sharepoint/uninstalling-aspose-slides-for-sharepoint/).
