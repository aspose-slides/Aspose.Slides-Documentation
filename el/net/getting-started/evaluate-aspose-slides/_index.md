## **Aspose.Slides Evaluation**

Μπορείτε εύκολα να κατεβάσετε το Aspose.Slides για αξιολόγηση. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο. Η έκδοση αξιολόγησης μετατρέπεται απλώς σε αδειοδοτημένη αφού προσθέσετε μερικές γραμμές κώδικα για την εφαρμογή της άδειας. 

Η έκδοση αξιολόγησης του Aspose.Slides (χωρίς καθορισμένη άδεια) παρέχει πλήρη λειτουργικότητα του προϊόντος, αλλά εισάγει ένα υδατογράφημα αξιολόγησης στην κορυφή του εγγράφου κατά το άνοιγμα και την αποθήκευση. Επίσης περιορίζεστε σε μία διαφάνεια κατά την εξαγωγή κειμένου από τις διαφάνειες της παρουσίασης.

## **Install the Evaluation Package**

```bash
dotnet add package Aspose.Slides.NET
```

## **Apply a License**

Αυτές είναι οι «μερικές γραμμές κώδικα» που μετατρέπουν το πακέτο αξιολόγησης σε αδειοδοτημένο. Εφαρμόστε την άδεια μία φορά κατά την εκκίνηση της εφαρμογής, πριν δημιουργηθεί οποιοδήποτε αντικείμενο `Presentation` — μια παρουσίαση που δημιουργήθηκε νωρίτερα διατηρεί το υδατογράφημα αξιολόγησης.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` δέχεται επίσης ένα `Stream`, το οποίο είναι η καλύτερη επιλογή όταν η άδεια παρέχεται ως ενσωματωμένος πόρος αντί για αρχείο στο δίσκο. Εάν η διαδρομή είναι λανθασμένη ή το αρχείο έχει λήξει, η κλήση ρίχνει εξαίρεση, έτσι τα σφάλματα εμφανίζονται αμέσως κατά την εκκίνηση αντί να επιστρέφουν σιωπηλά σε λειτουργία αξιολόγησης.

Μόλις εφαρμοστεί η άδεια, το υδατογράφημα εξαφανίζεται και το όριο εξαγωγής κειμένου από μία διαφάνεια αφαιρείται.

## **FAQ**

### Can I test multiple presentations in parallel across different threads in evaluation mode?

Μπορώ να δοκιμάσω πολλαπλές παρουσιάσεις παράλληλα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα παράλληλα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [μεταξύ νημάτων](/slides/el/net/multithreading/). Η λειτουργία αξιολόγησης δεν επηρεάζει αυτό.

### Do I need to install Microsoft PowerPoint to evaluate the library on a server or in CI?

Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι μια αυτόνομη μηχανή και δεν απαιτεί την εγκατάσταση του PowerPoint ούτε για αξιολόγηση ούτε για παραγωγή.

### Can I fully test conversion of PPT/PPTX to PDF and images in evaluation mode?

Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναι. Οι [μετατροπείς](/slides/el/net/convert-presentation/) λειτουργούν· η έξοδος θα περιλαμβάνει ένα υδατογράφημα.

### Can I use a temporary license for load testing without a watermark?

Μπορώ να χρησιμοποιήσω μια προσωρινή άδεια για δοκιμές φόρτου χωρίς υδατογράφημα;

Ναι. Μια 30‑ήμερη προσωρινή άδεια αφαιρεί τους περιορισμούς της λειτουργίας αξιολόγησης και επιτρέπει δοκιμές χωρίς υδατογράφημα.
