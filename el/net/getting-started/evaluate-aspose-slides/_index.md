## **Αξιολόγηση Aspose.Slides**

Μπορείτε να κατεβάσετε το Aspose.Slides για αξιολόγηση. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο· γίνεται αδειοδοτημένο αφού προσθέσετε μερικές γραμμές κώδικα για να εφαρμόσετε την άδεια.

Χωρίς άδεια, το Aspose.Slides παρέχει όλη τη λειτουργικότητά του σε λειτουργία αξιολόγησης, με δύο περιορισμούς: προσθέτει ένα πλαίσιο υδατογραφήματος αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει, και το κείμενο που διαβάζει ο κώδικάς σας από μια παρουσίαση περικοπεί στα πρώτα του χαρακτήρες, ακολουθούμενο από ειδοποίηση για τον περιορισμό της αξιολόγησης. Το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρως.

## **Εγκατάσταση του πακέτου αξιολόγησης**

```bash
dotnet add package Aspose.Slides.NET
```

Σε Linux και macOS, μπορείτε να χρησιμοποιήσετε το πακέτο Aspose.Slides.NET6.CrossPlatform· δείτε την [Εγκατάσταση](/slides/el/net/installation/).

## **Εφαρμογή άδειας**

Αυτές είναι οι «μικρές γραμμές κώδικα» που μετατρέπουν το πακέτο αξιολόγησης σε αδειοδοτημένο. Εφαρμόστε την άδεια μία φορά κατά την εκκίνηση της εφαρμογής, πριν δημιουργηθεί οποιοδήποτε αντικείμενο `Presentation`· μια παρουσίαση που δημιουργήθηκε νωρίτερα διατηρεί το υδατογράφημα αξιολόγησης.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` δέχεται επίσης ένα `Stream`, που αποτελεί την καλύτερη επιλογή όταν η άδεια αποστέλλεται ως ενσωματωμένος πόρος αντί για αρχείο στο δίσκο. Εάν η διαδρομή είναι λανθασμένη ή το αρχείο έχει λήξει, η κλήση προκαλεί εξαίρεση, έτσι τα σφάλματα εμφανίζονται αμέσως κατά την εκκίνηση αντί να επιστρέφουν αθόρυβα σε λειτουργία αξιολόγησης.

Μόλις εφαρμοστεί η άδεια, οι αποθηκευμένες παρουσιάσεις δεν περιέχουν πλέον το υδατογράφημα και το κείμενο διαβάζεται πλήρως.

## **FAQ**

### Μπορώ να δοκιμάσω πολλές παρουσιάσεις παράλληλα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα παράλληλα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [μεταξύ νημάτων](/slides/el/net/multithreading/). Η λειτουργία αξιολόγησης δεν επηρεάζει αυτό.

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι μια αυτόνομη μηχανή και δεν απαιτεί εγκατεστημένο το PowerPoint, ούτε για αξιολόγηση ούτε για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναι. Οι [μετατροπείς](/slides/el/net/convert-presentation/) λειτουργούν· η έξοδος θα περιλαμβάνει υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμές φόρτου χωρίς υδατογράφημα;

Ναι. Μια προσωρινή άδεια 30 ημερών αφαιρεί τους περιορισμούς της λειτουργίας αξιολόγησης και επιτρέπει δοκιμές χωρίς υδατογράφημα.
