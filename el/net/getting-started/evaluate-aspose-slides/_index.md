## **Aspose.Slides Αξιολόγηση**

Μπορείτε να κατεβάσετε το Aspose.Slides για αξιολόγηση. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο· γίνεται αδειοδοτημένο μετά την προσθήκη μερικών γραμμών κώδικα για την εφαρμογή της άδειας.

Χωρίς άδεια, το Aspose.Slides παρέχει όλη τη λειτουργικότητά του σε λειτουργία αξιολόγησης, με δύο περιορισμούς: προσθέτει ένα πλαίσιο κειμένου με υδατογράφημα αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει και το κείμενο που ο κώδικάς σας διαβάζει από μια παρουσίαση περικόπτεται στους πρώτους του χαρακτήρες, ακολουθούμενο από ειδοποίηση σχετικά με τον περιορισμό της αξιολόγησης. Το κείμενο που ο κώδικάς σας γράφει αποθηκεύεται πλήρως.

## **Εγκατάσταση του Πακέτου Αξιολόγησης**

```bash
dotnet add package Aspose.Slides.NET
```

Σε Linux και macOS, μπορείτε αντί αυτού να χρησιμοποιήσετε το πακέτο Aspose.Slides.NET6.CrossPlatform· δείτε [Εγκατάσταση](/slides/el/net/installation/).

## **Εφαρμογή Άδειας**

Αυτές είναι οι «μερικές γραμμές κώδικα» που μετατρέπουν το πακέτο αξιολόγησης σε αδειοδοτημένο. Εφαρμόστε την άδεια μία φορά κατά την εκκίνηση της εφαρμογής, πριν δημιουργηθεί οποιοδήποτε αντικείμενο `Presentation` — μια παρουσίαση που δημιουργήθηκε νωρίτερα διατηρεί το υδατογράφημα αξιολόγησης.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` δέχεται επίσης ένα `Stream`, που είναι η καλύτερη επιλογή όταν η άδεια παρέχεται ως ενσωματωμένος πόρος αντί για αρχείο στο δίσκο. Εάν η διαδρομή είναι λανθασμένη ή το αρχείο έχει λήξει, η κλήση ρίχνει εξαίρεση, έτσι τα σφάλματα εμφανίζονται αμέσως κατά την εκκίνηση αντί να επιστρέφουν σιωπηλά σε λειτουργία αξιολόγησης.

Μόλις εφαρμοστεί η άδεια, οι αποθηκευμένες παρουσιάσεις δεν περιέχουν πλέον το υδατογράφημα και το κείμενο διαβάζεται πλήρως.

## **Συχνές ερωτήσεις**

### Μπορώ να δοκιμάσω πολλαπλές παρουσιάσεις ταυτόχρονα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα ταυτόχρονα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [μεταξύ νημάτων](/slides/el/net/multithreading/). Η λειτουργία αξιολόγησης δεν επηρεάζει αυτό.

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι ένας ανεξάρτητος μηχανισμός και δεν απαιτεί εγκατάσταση του PowerPoint, είτε για αξιολόγηση είτε για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναι. Οι [μετατροπείς](/slides/el/net/convert-presentation/) λειτουργούν· η έξοδος θα περιέχει υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμή φόρτου χωρίς υδατογράφημα;

Ναι. Μια προσωρινή άδεια 30 ημερών αφαιρεί τους περιορισμούς λειτουργίας αξιολόγησης και επιτρέπει δοκιμές χωρίς υδατογράφημα.
