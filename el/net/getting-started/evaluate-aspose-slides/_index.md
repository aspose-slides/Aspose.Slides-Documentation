## **Αξιολόγηση Aspose.Slides**

Μπορείτε εύκολα να κατεβάσετε το Aspose.Slides για αξιολόγηση. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο. Η έκδοση αξιολόγησης γίνεται απλώς αδειοδοτημένη αφού προσθέσετε μερικές γραμμές κώδικα για την εφαρμογή της άδειας. 

Η έκδοση αξιολόγησης του Aspose.Slides (χωρίς καθορισμένη άδεια) παρέχει πλήρη λειτουργικότητα του προϊόντος, αλλά προσθέτει ένα υδατογράφημα αξιολόγησης στην κορυφή του εγγράφου κατά το άνοιγμα και την αποθήκευση. Επίσης περιορίζεστε σε μία διαφάνεια όταν εξάγετε κείμενο από τις διαφάνειες παρουσίασης.

## **Εγκατάσταση του Πακέτου Αξιολόγησης**

```bash
dotnet add package Aspose.Slides.NET
```

## **Εφαρμογή Άδειας**

Αυτές είναι οι «μερικές γραμμές κώδικα» που μετατρέπουν το πακέτο αξιολόγησης σε αδειοδοτημένο. Εφαρμόστε την άδεια μία φορά κατά την εκκίνηση της εφαρμογής, πριν δημιουργηθεί οποιοδήποτε αντικείμενο `Presentation` — μια παρουσίαση που δημιουργήθηκε νωρίτερα διατηρεί το υδατογράφημα αξιολόγησης.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` δέχεται επίσης ένα `Stream`, που είναι η καλύτερη επιλογή όταν η άδεια παρέχεται ως ενσωματωμένος πόρος αντί για αρχείο στο δίσκο. Εάν η διαδρομή είναι λανθασμένη ή το αρχείο έχει λήξει, η κλήση πετάει εξαίρεση, ώστε τα σφάλματα να εμφανίζονται άμεσα κατά την εκκίνηση αντί να επιστρέφουν σιωπηρά σε κατάσταση αξιολόγησης.

Μόλις εφαρμοστεί η άδεια, το υδατογράφημα αφαιρείται και το όριο εξαγωγής κειμένου από μία διαφάνεια καταργείται.

## **Συχνές Ερωτήσεις**

### Μπορώ να δοκιμάσω πολλές παρουσιάσεις ταυτόχρονα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα ταυτόχρονα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [μεταξύ νήματων](/slides/el/net/multithreading/). Η λειτουργία αξιολόγησης δεν επηρεάζει αυτό.

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για την αξιολόγηση της βιβλιοθήκης σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι ένας ανεξάρτητος μηχανισμός και δεν απαιτεί εγκατάσταση του PowerPoint είτε για αξιολόγηση είτε για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναί. Οι [μετατροπείς](/slides/el/net/convert-presentation/) λειτουργούν· η έξοδος θα περιλαμβάνει ένα υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμές φόρτου χωρίς υδατογράφημα;

Ναί. Μια 30ήμερη προσωρινή άδεια αφαιρεί τους περιορισμούς της λειτουργίας αξιολόγησης και επιτρέπει δοκιμές χωρίς υδατογράφημα.
