{{% alert color="info" %}} 

Όλα τα συστατικά Aspose .NET απαιτούν το σύνολο δικαιωμάτων Full Trust επειδή μερικές φορές πρέπει να έχουν πρόσβαση στις ρυθμίσεις μητρώου, σε αρχεία συστήματος και σε αρχεία που είναι αποθηκευμένα σε άλλες τοποθεσίες (εκτός του εικονικού καταλόγου) για ορισμένες λειτουργίες (για παράδειγμα, ανάλυση γραμματοσειρών). Επιπλέον, τα Συστατικά Aspose .NET βασίζονται σε βασικές κλάσεις του .NET, οι οποίες απαιτούν το σύνολο δικαιωμάτων Full Trust σε πολλές περιπτώσεις. 

{{% /alert %}} 

Οι Πάροχοι Υπηρεσιών Διαδικτύου (ISP), που φιλοξενούν πολλαπλές εφαρμογές από διαφορετικές εταιρείες, κυρίως επιβάλλουν το επίπεδο ασφαλείας Medium Trust. Σε περίπτωση .NET 2.0, ένα τέτοιο επίπεδο ασφαλείας εφαρμόζει τους εξής περιορισμούς: 

- OleDbPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να χρησιμοποιήσετε τον διαχειριζόμενο προμηθευτή δεδομένων OLE DB του ADO.NET για πρόσβαση σε βάσεις δεδομένων.
- EventLogPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να έχετε πρόσβαση στο αρχείο καταγραφής συμβάντων των Windows.
- ReflectionPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να χρησιμοποιήσετε την αντανάκλαση.
- RegistryPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να έχετε πρόσβαση στο μητρώο.
- WebPermission είναι περιορισμένο. Αυτό σημαίνει ότι η εφαρμογή σας μπορεί να επικοινωνεί μόνο με μια διεύθυνση ή το εύρος διευθύνσεων που ορίσατε στο στοιχείο <trust>.
- FileIOPermission είναι περιορισμένο. Αυτό σημαίνει ότι μπορείτε να έχετε πρόσβαση μόνο σε αρχεία στην ιεραρχία του εικονικού καταλόγου της εφαρμογής σας.

{{% alert color="info" %}} 

Λόγω των παραπάνω λόγων, τα συστατικά Aspose .NET μπορούν να χρησιμοποιηθούν μόνο σε διακομιστές που παρέχουν το σύνολο δικαιωμάτων Full Trust. 

{{% /alert %}}
