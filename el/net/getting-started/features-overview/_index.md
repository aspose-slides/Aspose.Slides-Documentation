## **FAQ**

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint στον server/PC για να λειτουργήσει η βιβλιοθήκη;
Όχι. Το PowerPoint δεν απαιτείται· το Aspose.Slides είναι μια αυτόνομη μηχανή για δημιουργία, επεξεργασία, μετατροπή και απόδοση παρουσιάσεων.

### Πώς λειτουργεί η πολυνηματική εκτέλεση; Μπορεί η επεξεργασία να παραλληλοποιηθεί;
Είναι ασφαλές να επεξεργάζεστε διαφορετικά έγγραφα σε διαφορετικά νήματα· το ίδιο αντικείμενο [presentation](https://reference.aspose.com/slides/el/net/aspose.slides/presentation/) δεν πρέπει να χρησιμοποιείται από [multiple threads](/slides/el/net/multithreading/) ταυτόχρονα.

### Υποστηρίζονται κωδικοί πρόσβασης αρχείων και κρυπτογράφηση;
Ναι. [Μπορείτε](/slides/el/net/password-protected-presentation/) να ανοίξετε κρυπτογραφημένες παρουσιάσεις, να θέσετε ή να αφαιρέσετε κωδικό ανοίγματος ή εγγραφής και να ελέγξετε την κατάσταση προστασίας.

### Πρέπει να ανησυχήσω για τα πακέτα γραμματοσειρών σε περιβάλλοντα Linux;
Ναι. Συνιστάται η εγκατάσταση κοινών πακέτων γραμματοσειρών και/ή η ρητή [specify font directories](/slides/el/net/custom-font/) στην εφαρμογή σας για αποφυγή αναπάντεχων αντικαταστάσεων.

### Υπάρχουν περιορισμοί στην δοκιμαστική έκδοση;
Σε [evaluation mode](/slides/el/net/licensing/), προστίθεται υδατογράφημα στο αποτέλεσμα και ισχύουν ορισμένοι περιορισμοί· μια [30-day temporary license](https://purchase.aspose.com/temporary-license/) είναι διαθέσιμη για πλήρη δοκιμή όλων των λειτουργιών.

### Υποστηρίζεται η εισαγωγή εξωτερικών μορφών σε μια παρουσίαση (PDF/HTML → PPTX);
Ναι. Μπορείτε να προσθέσετε [PDF pages and HTML content](/slides/el/net/import-presentation/) σε μια παρουσίαση, μετατρέποντάς τα σε διαφάνειες.
