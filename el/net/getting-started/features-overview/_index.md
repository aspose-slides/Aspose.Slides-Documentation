## **Επισκόπηση**

Το Aspose.Slides for .NET είναι μια βιβλιοθήκη κλάσεων για δημιουργία, ανάγνωση, επεξεργασία, μετατροπή και απόδοση παρουσιάσεων PowerPoint και OpenDocument. Δεν διαθέτει δικό της περιβάλλον χρήστη και δεν απαιτεί το Microsoft PowerPoint ή το Office, ώστε να μπορεί να χρησιμοποιηθεί σε εφαρμογές κονσόλας, σε εφαρμογές επιφάνειας εργασίας όπως τα Windows Forms, σε εφαρμογές Web και σε υπηρεσίες Web. Αυτό το άρθρο συνοψίζει τι καλύπτει η βιβλιοθήκη και παρέχει συνδέσμους προς τα άρθρα που περιγράφουν κάθε περιοχή.

## **Υποστηριζόμενες Πλατφόρμες**

Το Aspose.Slides for .NET διανέμεται ως δύο πακέτα NuGet με το ίδιο API:

|**Πακέτο**|**Κατασκευές στο πακέτο**|**Λειτουργικά Συστήματα**|
| :- | :- | :- |
|[Aspose.Slides.NET](https://www.nuget.org/packages/Aspose.Slides.NET/)|.NET Framework 4.6.2, .NET Standard 2.0 και .NET 6. Χρησιμοποιήστε το με .NET Framework 4.6.2 ή νεότερη έκδοση, ή με .NET 6 ή νεότερη.|Windows. Linux και macOS με τη βιβλιοθήκη `libgdiplus` και τη μεταβλητή `System.Drawing.EnableUnixSupport`.|
|[Aspose.Slides.NET6.CrossPlatform](https://www.nuget.org/packages/Aspose.Slides.NET6.CrossPlatform/)|.NET 6. Χρησιμοποιήστε το με .NET 6 ή νεότερη έκδοση.|Windows (x86, x64), Linux (x64 με glibc 2.23 ή νεότερο, ARM64 με glibc 2.39 ή νεότερο) και macOS (x64, ARM64).|

[Εγκατάσταση](/slides/el/net/installation/) εξηγεί ποιο πακέτο να επιλέξετε και τι απαιτεί το καθένα σε Linux. [Απαιτήσεις Συστήματος](/slides/el/net/system-requirements/) παραθέτει λεπτομερώς τις υποστηριζόμενες πλατφόρμες.

## **Μορφές Αρχείων και Μετατροπές**

Εισάγει περιεχόμενο PDF και HTML σε διαφάνειες και αποθηκεύει παρουσιάσεις ως PDF, XPS, HTML, HTML5, TIFF, κινούμενο GIF, SWF, Markdown και XAML. [Υποστηριζόμενες Μορφές Αρχείων](/slides/el/net/supported-file-formats/) καταγράφει κάθε μορφή μαζί με το API που την διαβάζει ή τη γράφει.

## **Απόδοση Παρουσίασης**

Το Aspose.Slides αποδίδει διαφάνειες και μεμονωμένα σχήματα ως εικόνες PNG, JPEG, BMP, GIF, TIFF και SVG, και διαφάνειες ως μετααρχείο EMF. Δείτε [Μετατροπή Διαφανειών Παρουσίασης σε Εικόνες](/slides/el/net/convert-slide/), [Απόδοση Διαφάνειας ως Εικόνα SVG](/slides/el/net/render-a-slide-as-an-svg-image/) και [Δημιουργία Μικρογραφιών Σχημάτων](/slides/el/net/create-shape-thumbnails/).

## **Συχνές Ερωτήσεις**

**Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint στον διακομιστή ή στον υπολογιστή για να λειτουργήσει η βιβλιοθήκη;**

Όχι. Το PowerPoint δεν είναι απαραίτητο· το Aspose.Slides είναι μια αυτόνομη μηχανή για δημιουργία, επεξεργασία, μετατροπή και απόδοση παρουσιάσεων.

**Πώς λειτουργεί η πολυνηματικότητα; Μπορεί η επεξεργασία να παραλληλοποιηθεί;**

Είναι ασφαλές να επεξεργάζεστε διαφορετικά έγγραφα σε διαφορετικά νήματα· το ίδιο αντικείμενο [Presentation](https://reference.aspose.com/slides/net/aspose.slides/presentation/) δεν πρέπει να χρησιμοποιείται από [πολλαπλά νήματα](/slides/el/net/multithreading/) ταυτόχρονα.

**Υποστηρίζονται κωδικοί πρόσβασης αρχείων και κρυπτογράφηση;**

Ναι. [Μπορείτε](/slides/el/net/password-protected-presentation/) να ανοίγετε κρυπτογραφημένες παρουσιάσεις, να ορίζετε ή να αφαιρείτε κωδικούς ανοίγματος και εγγραφής και να ελέγχετε την κατάσταση προστασίας.

**Πρέπει να ανησυχήσω για τις γραμματοσειρές σε κοντέινερ Linux;**

Ναι. Οι γραμματοσειρές που χρησιμοποιούνται στις παρουσιάσεις σας, ή κατάλληλες εναλλακτικές, πρέπει να είναι εγκατεστημένες στο σύστημα για ορθή απόδοση του κειμένου. Μπορείτε επίσης [να καθορίσετε καταλόγους γραμματοσειρών](/slides/el/net/custom-font/) στην εφαρμογή σας. Η [Εγκατάσταση](/slides/el/net/installation/) παραθέτει τις προαπαιτήσεις Linux για κάθε πακέτο.

**Υπάρχουν περιορισμοί στην έκδοση αξιολόγησης;**

Ναι. Χωρίς [άδεια](/slides/el/net/licensing/), το Aspose.Slides προσθέτει υδατογράφημα αξιολόγησης σε κάθε διαφάνεια που αποθηκεύεται και περικόπτει το κείμενο που διαβάζεται από τις παρουσιάσεις. Διατίθεται [προσωρινή άδεια 30 ημερών](https://purchase.aspose.com/temporary-license/) για πλήρη δοκιμή όλων των λειτουργιών.

**Υποστηρίζεται η εισαγωγή εξωτερικών φορμάτ σε παρουσίαση (PDF ή HTML σε PPTX);**

Ναι. Μπορείτε να προσθέσετε [σελίδες PDF και περιεχόμενο HTML](/slides/el/net/import-presentation/) σε μια παρουσίαση, μετατρέποντάς τα σε διαφάνειες.
