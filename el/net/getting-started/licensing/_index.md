## **Επισκόπηση**

Το Aspose.Slides μπορεί να χρησιμοποιηθεί σε λειτουργία αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την άδεια έκδοση, αλλά προσθέτει υδατογράφημα αξιολόγησης όταν τα παρουσιάσματα ανοίγονται ή αποθηκεύονται και περιορίζει την εξαγωγή κειμένου σε μία διαφάνεια.

Το άρθρο αυτό εξηγεί πώς λειτουργεί η αδειοδότηση στο Aspose.Slides και πώς να εφαρμόσετε μια άδεια πριν χρησιμοποιήσετε τη βιβλιοθήκη. Μια άδεια μπορεί να φορτωθεί από αρχείο, ροή ή ενσωματωμένο πόρο χρησιμοποιώντας την κλάση `License`. Το άρθρο επίσης δείχνει πώς να επαληθεύσετε αν μια άδεια έχει εφαρμοστεί σωστά.

## **Αδειοδότηση στο Aspose.Slides**
* Μια έκδοση αξιολόγησης γίνεται αδειοδοτημένη αφού αγοράσετε μια άδεια και προσθέσετε μερικές γραμμές κώδικα (για την εφαρμογή της άδειας).
* Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα του προϊόντος, ο αριθμός των προγραμματιστών για τους οποίους αδειοδοτείται, η ημερομηνία λήξης της συνδρομής, κ.λπ.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, οπότε δεν πρέπει να το τροποποιήσετε. Ακόμα και η ακούσια προσθήκη ενός επιπλέον line break στο περιεχόμενο του αρχείου θα το ακυρώσει.
* Το Aspose.Slides for .NET συνήθως προσπαθεί να βρει την άδεια σε αυτές τις τοποθεσίες:
  * Συγκεκριμένη διαδρομή
  * Ο φάκελος που περιέχει το dll του συστατικού (περιλαμβάνεται στο Aspose.Slides)
  * Ο φάκελος που περιέχει την συναρμολόγηση που κάλεσε το dll του συστατικού (περιλαμβάνεται στο Aspose.Slides)
  * Ο φάκελος που περιέχει την αρχική συναρμολόγηση (το .exe σας)
  * Ένας ενσωματωμένος πόρος στην συναρμολόγηση που κάλεσε το dll του συστατικού (περιλαμβάνεται στο Aspose.Slides).
* Για να αποφύγετε τους περιορισμούς που σχετίζονται με την έκδοση αξιολόγησης, πρέπει να ορίσετε άδεια πριν χρησιμοποιήσετε το Aspose.Slides. Πρέπει να ορίσετε άδεια μόνο μία φορά ανά εφαρμογή ή διεργασία.

{{% alert color="info" %}} 

Ίσως θελήσετε να δείτε [Metered Licensing](https://docs.aspose.com/slides/el/net/metered-licensing/).

{{% /alert %}} 


## **Εφαρμογή Άδειας**
Μια άδεια μπορεί να φορτωθεί από **αρχείο**, **ροή** ή **ενσωματωμένο πόρο**. 

{{% alert color="info" %}}

Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/el/net/aspose.slides/license) για τις λειτουργίες αδειοδότησης.

{{% /alert %}} 

{{% alert color="warning" %}} 

Οι νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με την έκδοση 21.4 ή νεότερη. Παλιότερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν θα αναγνωρίσουν αυτές τις άδειες.

{{% /alert %}}

### **Αρχείο**
Η πιο απλή μέθοδος ορισμού άδειας απαιτεί να τοποθετήσετε το αρχείο άδειας στον ίδιο φάκελο που περιέχει το DLL του συστατικού (περιλαμβάνεται στο Aspose.Slides) και να καθορίσετε μόνο το όνομα του αρχείου χωρίς τη διαδρομή.

Αυτός ο κώδικας C# δείχνει πώς να ορίσετε ένα αρχείο άδειας:

``` csharp
// Δημιουργεί μια παρουσία της κλάσης License 
Aspose.Slides.License license = new Aspose.Slides.License();

// Ορίζει τη διαδρομή του αρχείου άδειας
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" %}} 

Αν τοποθετήσετε το αρχείο άδειας σε διαφορετικό κατάλογο, όταν καλέσετε τη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/net/aspose.slides/license/setlicense/#setlicense_1), το όνομα του αρχείου άδειας στο τέλος της συγκεκριμένης ρητής διαδρομής πρέπει να είναι το ίδιο με το αρχείο άδειας σας.

Για παράδειγμα, μπορείτε να αλλάξετε το όνομα του αρχείου άδειας σε *Aspose.Slides.lic.xml*. Στη συνέχεια, στον κώδικά σας, πρέπει να περάσετε τη διαδρομή προς το αρχείο (τελειώνει με *Aspose.Slides.lic.xml*) στη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/net/aspose.slides/license/setlicense/#setlicense_1).

{{% /alert %}}

### **Ροή**
Μπορείτε να φορτώσετε μια άδεια από ροή. Αυτός ο κώδικας C# δείχνει πώς να εφαρμόσετε μια άδεια από ροή:

``` csharp
// Δημιουργεί μια παρουσία της κλάσης License
Aspose.Slides.License license = new Aspose.Slides.License();

// Ανοίγει το αρχείο άδειας ως ροή
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// Ορίζει την άδεια μέσω ροής
license.SetLicense(licenseStream);
```

### **Ενσωματωμένος Πόρος**
Μπορείτε να συσκευάσετε την άδεια με την εφαρμογή σας (για να μην την χάσετε) προσθέτοντας την άδεια ως ενσωματωμένο πόρο σε μία από τις συναρμολογήσεις που καλούν το DLL του συστατικού (περιλαμβάνεται στο Aspose.Slides). 

Αυτός είναι ο τρόπος με τον οποίο προσθέτετε ένα αρχείο άδειας ως ενσωματωμένο πόρο:

1. Στο Visual Studio, προσθέστε το αρχείο άδειας (.lic) στο έργο με τον εξής τρόπο: Μεταβείτε στο **File** > **Add Existing Item** > **Add**. 
2. Επιλέξτε το αρχείο στο **Solution Explorer**.
3. Στο παράθυρο **Properties**, ορίστε το **Build Action** σε **Embedded Resource**.
4. Για να έχετε πρόσβαση στην άδεια ενσωματωμένη στη συναρμολόγηση, προσθέστε το αρχείο άδειας ως ενσωματωμένο πόρο στο έργο και, στη συνέχεια, περάστε το όνομα του αρχείου άδειας στη μέθοδο `SetLicense`. 

Η κλάση `License` βρίσκει αυτόματα το αρχείο άδειας στους ενσωματωμένους πόρους. Δεν χρειάζεται να καλέσετε τις μεθόδους `GetExecutingAssembly` και `GetManifestResourceStream` της κλάσης `System.Reflection.Assembly` στο Microsoft .NET Framework.

Αυτός ο κώδικας C# δείχνει πώς να ορίσετε μια άδεια ως ενσωματωμένο πόρο:

``` csharp
// Δημιουργεί μια παρουσία της κλάσης License
Aspose.Slides.License license = new Aspose.Slides.License();

// Περνά το όνομα του αρχείου άδειας ενσωματωμένο στη συναρμολόγηση
license.SetLicense("Aspose.Slides.lic");
```

## **Επικύρωση Άδειας**
Για να ελέγξετε αν μια άδεια έχει οριστεί σωστά, μπορείτε να την επικυρώσετε. Αυτός ο κώδικας C# δείχνει πώς να επικυρώσετε μια άδεια:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **Ασφάλεια Σνημάτων**
{{% alert title="Note" color="warning" %}} 

Η μέθοδος [license.SetLicense](https://reference.aspose.com/slides/el/net/aspose.slides/license/setlicense/) δεν είναι ασφαλής για πολλαπλά νήματα. Αν αυτή η μέθοδος πρέπει να κληθεί ταυτόχρονα από πολλά νήματα, ίσως θελήσετε να χρησιμοποιήσετε συναρμολογήσεις συγχρονισμού (όπως κλείδωμα) για να αποφύγετε προβλήματα. 

{{% /alert %}}
