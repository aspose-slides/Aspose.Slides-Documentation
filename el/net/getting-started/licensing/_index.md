## **Επισκόπηση**

Το Aspose.Slides μπορεί να χρησιμοποιηθεί σε λειτουργία αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την έκδοση με άδεια, αλλά προσθέτει υδατογράφημα αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει και περικοπεί το κείμενο που το πρόγραμμα σας διαβάζει από παρουσιάσεις.

Αυτό το άρθρο εξηγεί πώς λειτουργούν οι άδειες στο Aspose.Slides και πώς να εφαρμόσετε μια άδεια πριν χρησιμοποιήσετε τη βιβλιοθήκη. Μια άδεια μπορεί να φορτωθεί από αρχείο, ροή ή ενσωματωμένο πόρο χρησιμοποιώντας την κλάση `License`. Το άρθρο δείχνει επίσης πώς να επαληθεύσετε εάν μια άδεια έχει εφαρμοστεί σωστά.

## **Αξιολόγηση Aspose.Slides**

{{% alert color="info" title="Note" %}}

Μπορείτε να κατεβάσετε μια έκδοση αξιολόγησης του **Aspose.Slides for .NET** από [τη σελίδα λήψης NuGet του](https://www.nuget.org/packages/Aspose.Slides.NET/). Η έκδοση αξιολόγησης παρέχει τις ίδιες λειτουργίες με την έκδοση με άδεια του προϊόντος. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο. Η έκδοση αξιολόγησης απλώς γίνεται με άδεια αφού προσθέσετε μερικές γραμμές κώδικα (για την εφαρμογή της άδειας).

Μόλις είστε ικανοποιημένοι με την αξιολόγηση του **Aspose.Slides**, μπορείτε να [αγοράσετε μια άδεια](https://purchase.aspose.com/pricing/slides/el/net/). Σας συνιστούμε να εξετάσετε τους διαφορετικούς τύπους συνδρομής. Αν έχετε ερωτήσεις, επικοινωνήστε με την ομάδα πωλήσεων της Aspose.

Κάθε άδεια Aspose συνοδεύεται από ετήσια συνδρομή δωρεάν αναβαθμίσεων σε νέες εκδόσεις ή διορθώσεις που κυκλοφορούν εντός της περιόδου συνδρομής. Οι χρήστες με προϊόντα με άδεια ή ακόμη και οι χρήστες εκδόσεων αξιολόγησης λαμβάνουν δωρεάν και απεριόριστη τεχνική υποστήριξη.

{{% /alert %}} 

**Περιορισμοί έκδοσης αξιολόγησης**

* Η έκδοση αξιολόγησης (χωρίς καθορισμένη άδεια) παρέχει πλήρη λειτουργικότητα του προϊόντος, αλλά προσθέτει πλαίσιο κειμένου υδατογραφήματος αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει.
* Το κείμενο που το πρόγραμμά σας διαβάζει από μια παρουσίαση περικοπεί στα πρώτα του χαρακτήρες, ακολουθούμενο από ειδοποίηση για τον περιορισμό αξιολόγησης. Το κείμενο που το πρόγραμμά σας γράφει αποθηκεύεται πλήρως.

{{% alert color="info" title="Note" %}}

Για να δοκιμάσετε το Aspose.Slides χωρίς περιορισμούς, μπορείτε να ζητήσετε **30‑ημερήσια προσωρινή άδεια**. Δείτε τη σελίδα [Πώς να λάβετε μια προσωρινή άδεια](https://purchase.aspose.com/temporary-license) για περισσότερες πληροφορίες.

{{% /alert %}}

## **Αδειοδότηση στο Aspose.Slides**
* Μια έκδοση αξιολόγησης γίνεται με άδεια αφού αγοράσετε μια άδεια και προσθέσετε μερικές γραμμές κώδικα (για την εφαρμογή της άδειας).
* Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα του προϊόντος, ο αριθμός των προγραμματιστών προς τους οποίους αδειοδοτείται, η ημερομηνία λήξης της συνδρομής κ.λπ.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, επομένως δεν πρέπει να το τροποποιήσετε. Ακόμη και η τυχαία προσθήκη μιας επιπλέον αλλαγής γραμμής στα περιεχόμενα του αρχείου θα το ακυρώσει.
* Το Aspose.Slides for .NET συνήθως προσπαθεί να βρει την άδεια στις εξής τοποθεσίες:
  * Ένας ρητός δρόμος
  * Ο φάκελος που περιέχει το dll του εξαρτήματος (περιλαμβάνεται στο Aspose.Slides)
  * Ο φάκελος που περιέχει το assembly που κάλεσε το dll του εξαρτήματος (περιλαμβάνεται στο Aspose.Slides)
  * Ο φάκελος που περιέχει το entry assembly (το .exe σας)
  * Ένας ενσωματωμένος πόρος στο assembly που κάλεσε το dll του εξαρτήματος (περιλαμβάνεται στο Aspose.Slides).
* Για να αποφύγετε τους περιορισμούς που σχετίζονται με την έκδοση αξιολόγησης, πρέπει να ορίσετε μια άδεια πριν χρησιμοποιήσετε το Aspose.Slides. Απαιτείται να ορίσετε την άδεια μόνο μία φορά ανά εφαρμογή ή διαδικασία.

{{% alert color="info" title="Note" %}}

Μπορείτε να δείτε το [Metered Licensing](/slides/el/net/metered-licensing/).

{{% /alert %}} 


## **Εφαρμογή άδειας**
Μια άδεια μπορεί να φορτωθεί από **αρχείο**, **ροή** ή **ενσωματωμένο πόρο**. 

{{% alert color="info" title="Note" %}}

Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/el/net/aspose.slides/license) για λειτουργίες αδειοδότησης.

{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}

Νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με έκδοση 21.4 ή νεότερη. Παλαιότερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν θα αναγνωρίσουν αυτές τις άδειες.

{{% /alert %}}

### **Αρχείο**
Η πιο εύκολη μέθοδος ορισμού άδειας απαιτεί να τοποθετήσετε το αρχείο άδειας στον ίδιο φάκελο που περιέχει το DLL του εξαρτήματος (περιλαμβάνεται στο Aspose.Slides) και να καθορίσετε μόνο το όνομα του αρχείου χωρίς διαδρομή.

Αυτός ο κώδικας C# δείχνει πώς να ορίσετε ένα αρχείο άδειας:

``` csharp
// Δημιουργεί ένα αντικείμενο της κλάσης License 
Aspose.Slides.License license = new Aspose.Slides.License();

// Ορίζει τη διαδρομή του αρχείου άδειας
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" title="Warning" %}}

Αν τοποθετήσετε το αρχείο άδειας σε διαφορετικό κατάλογο, όταν καλέσετε τη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/net/aspose.slides/license/setlicense/#setlicense_1), το όνομα του αρχείου άδειας στο τέλος της καθορισμένης διαδρομής πρέπει να είναι το ίδιο με το όνομα του αρχείου άδειας σας.

Για παράδειγμα, μπορείτε να αλλάξετε το όνομα του αρχείου άδειας σε *Aspose.Slides.lic.xml*. Στη συνέχεια, στον κώδικά σας, πρέπει να περάσετε τη διαδρομή προς το αρχείο (που λήγει σε *Aspose.Slides.lic.xml*) στη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/net/aspose.slides/license/setlicense/#setlicense_1).

{{% /alert %}}

### **Ροή**
Μπορείτε να φορτώσετε μια άδεια από ροή. Αυτός ο κώδικας C# δείχνει πώς να εφαρμόσετε μια άδεια από ροή:

``` csharp
// Δημιουργεί ένα αντικείμενο της κλάσης License
Aspose.Slides.License license = new Aspose.Slides.License();

// Ανοίγει το αρχείο άδειας ως ροή
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// Ορίζει την άδεια μέσω ροής
license.SetLicense(licenseStream);
```

### **Ενσωματωμένος πόρος**
Μπορείτε να συσκευάσετε την άδεια με την εφαρμογή σας (για να μην τη χάσετε) προσθέτοντας την άδεια ως ενσωματωμένο πόρο σε ένα από τα assemblies που καλούν το DLL του εξαρτήματος (περιλαμβάνεται στο Aspose.Slides). 

Αυτός είναι ο τρόπος προσθήκης ενός αρχείου άδειας ως ενσωματωμένου πόρου:

1. Στο Visual Studio, προσθέστε το αρχείο άδειας (.lic) στο έργο με τον εξής τρόπο: Πηγαίνετε στο **File** > **Add Existing Item** > **Add**. 
2. Επιλέξτε το αρχείο στον **Solution Explorer**.
3. Στο παράθυρο **Properties**, ορίστε το **Build Action** σε **Embedded Resource**.
4. Για πρόσβαση στην άδεια που είναι ενσωματωμένη στο assembly, προσθέστε το αρχείο άδειας ως ενσωματωμένο πόρο στο έργο και, στη συνέχεια, περάστε το όνομα του αρχείου άδειας στη μέθοδο `SetLicense`. 


Η κλάση `License` βρίσκει αυτόματα το αρχείο άδειας στους ενσωματωμένους πόρους. Δεν χρειάζεται να καλέσετε τις μεθόδους `GetExecutingAssembly` και `GetManifestResourceStream` της κλάσης `System.Reflection.Assembly` στο Microsoft .NET Framework.

Αυτός ο κώδικας C# δείχνει πώς να ορίσετε μια άδεια ως ενσωματωμένο πόρο:

``` csharp
// Δημιουργεί ένα αντικείμενο της κλάσης License
Aspose.Slides.License license = new Aspose.Slides.License();

// Περνά το όνομα του αρχείου άδειας ενσωματωμένο στο assembly
license.SetLicense("Aspose.Slides.lic");
```

## **Επαλήθευση άδειας**

Για να ελέγξετε εάν μια άδεια έχει οριστεί σωστά, μπορείτε να την επαληθεύσετε. Αυτός ο κώδικας C# δείχνει πώς να επαληθεύσετε μια άδεια:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **Ασφάλεια νήματος**

{{% alert color="warning" title="Warning" %}}

Η μέθοδος [license.SetLicense](https://reference.aspose.com/slides/el/net/aspose.slides/license/setlicense/) δεν είναι ασφαλής για νήματα. Αν αυτή η μέθοδος πρέπει να κληθεί ταυτόχρονα από πολλά νήματα, ίσως θελήσετε να χρησιμοποιήσετε πρωτότυπα συγχρονισμού (όπως κλείδωμα) για να αποφύγετε προβλήματα. 

{{% /alert %}}
