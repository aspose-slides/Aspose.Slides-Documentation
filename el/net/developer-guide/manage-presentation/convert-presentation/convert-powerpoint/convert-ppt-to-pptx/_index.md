## **Επισκόπηση**

Το PPT είναι η παλαιά δυαδική μορφή του PowerPoint, ενώ το PPTX είναι η νεότερη μορφή Open XML. Το Aspose.Slides για .NET μπορεί να φορτώσει ένα αρχείο PPT και να το αποθηκεύσει ως PPTX χωρίς το Microsoft PowerPoint. Αυτό το άρθρο δείχνει πώς να μετατρέψετε ένα αρχείο ή έναν φάκελο αρχείων και εξηγεί τι πρέπει να ελέγξετε μετά τη μετατροπή.

## **Μετατροπή ενός αρχείου PPT σε PPTX**

Φορτώστε το πηγαίο αρχείο με τη κλάση [Presentation](https://reference.aspose.com/slides/el/net/aspose.slides/presentation/). Στη συνέχεια, καλέστε το [IPresentation.Save](https://reference.aspose.com/slides/el/net/aspose.slides/ipresentation/save/) με το [SaveFormat.Pptx](https://reference.aspose.com/slides/el/net/aspose.slides.export/saveformat/). Η δήλωση `using` απελευθερώνει την παρουσίαση και απελευθερώνει τους πόρους της όταν λήξει η εμβέλεια.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

// Φορτώστε την παλαιά παρουσίαση PPT.
using var presentation = new Presentation("presentation.ppt");

// Αποθηκεύστε την παρουσίαση σε μορφή PPTX.
presentation.Save("presentation.pptx", SaveFormat.Pptx);
```

Η επέκταση αρχείου δεν επιλέγει από μόνη της τη μορφή εξόδου· το όρισμα [SaveFormat.Pptx](https://reference.aspose.com/slides/el/net/aspose.slides.export/saveformat/) το κάνει. Διατηρήστε διαφορετικές διαδρομές εισόδου και εξόδου εάν χρειάζεται να διατηρήσετε το αρχικό αρχείο PPT.

## **Μετατροπή πολλαπλών αρχείων PPT**

Το παρακάτω παράδειγμα μετατρέπει κάθε αρχείο `.ppt` σε έναν φάκελο. Κάθε αρχείο επεξεργάζεται ανεξάρτητα, έτσι μια αποτυχία μετατροπής δεν σταματά το υπόλοιπο σύνολο.

```csharp
using System;
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

var inputDirectory = "input";
var outputDirectory = "output";
Directory.CreateDirectory(outputDirectory);

foreach (var inputPath in Directory.EnumerateFiles(inputDirectory, "*.ppt", SearchOption.TopDirectoryOnly))
{
    var outputFileName = Path.GetFileNameWithoutExtension(inputPath) + ".pptx";
    var outputPath = Path.Combine(outputDirectory, outputFileName);

    try
    {
        using var presentation = new Presentation(inputPath);
        presentation.Save(outputPath, SaveFormat.Pptx);
        Console.WriteLine($"Converted: {inputPath}");
    }
    catch (Exception exception)
    {
        Console.Error.WriteLine($"Failed: {inputPath} ({exception.Message})");
    }
}
```

Για παραγωγικές εργασίες, καταγράψτε την πλήρη εξαίρεση, αποφασίστε αν μπορεί να αντικατασταθεί ένα υπάρχον αρχείο εξόδου και γράψτε τα ονόματα των αποτυχημένων αρχείων σε σειρά επανάληψης ή ανασκόπησης. Κατεστραμμένα αρχεία, αρχεία προστατευμένα με κωδικό που ανοίγονται χωρίς τον απαιτούμενο κωδικό, μη προσβάσιμες διαδρομές και μη υποστηριζόμενο περιεχόμενο μπορούν να προκαλέσουν αποτυχία μετατροπής. Δείτε [Password-Protected Presentations](/slides/el/net/password-protected-presentation/) για τη φόρτωση κρυπτογραφημένων αρχείων.

## **Ακρίβεια και Παλαιές Λειτουργίες**

Η μετατροπή συνήθως διατηρεί τις διαφάνειες, τα master, τις διατάξεις, το κείμενο, τα σχήματα, τις εικόνες, τους πίνακες και τα γραφήματα. Ωστόσο, τα PPT και PPTX δεν αντιπροσωπεύουν κάθε λειτουργία με τον ίδιο ακριβή τρόπο. Μια παλαιά λειτουργία που δεν έχει ισοδύναμο σε PPTX ή δεν υποστηρίζεται από τη βιβλιοθήκη, μπορεί να κανονικοποιηθεί, να παραληφθεί ή να εμφανιστεί διαφορετικά.

Ελέγξτε το μετατραπείσες αρχείο όταν περιέχει κινούμενα σκηνικά, μεταβάσεις, ενσωματωμένα ή συνδεμένα αντικείμενα OLE, ελέγχους ActiveX, ενσωματωμένα πολυμέσα, σπάνιες γραμματοσειρές ή μακροεντολές VBA. Ένα απλό αρχείο PPTX δεν είναι μορφή που υποστηρίζει μακροεντολές, οπότε χρησιμοποιήστε μια κατάλληλη ροή εργασίας με υποστήριξη μακροεντολών όταν πρέπει να διατηρηθεί το VBA. Επίσης, βεβαιωθείτε ότι οι απαιτούμενες γραμματοσειρές και οι εξωτερικοί πόροι είναι παρόντες στο περιβάλλον όπου η μετατρεπόμενη παρουσίαση θα ανοίξει ή θα αποδοθεί.

Για σημαντικά έγγραφα, ανοίξτε ξανά το δημιουργημένο PPTX προγραμματισμένα και ελέγξτε τα βασικά πλήθη διαφανειών και το περιεχόμενο, στη συνέχεια συγκρίνετε την εμφάνισή του και τη συμπεριφορά της παρουσίασης στον επιθυμητό θεατή. Μην θεωρείτε μια επιτυχής κλήση του [IPresentation.Save](https://reference.aspose.com/slides/el/net/aspose.slides/ipresentation/save/) ως απόδειξη ότι κάθε παλαιά λειτουργία έχει ακριβή αντιπροσώπευση σε PPTX.

## **Πότε να Χρησιμοποιήσετε το PPTX**

Χρησιμοποιήστε το PPTX όταν η παρουσίαση θα επεξεργαστεί σε τρέχουσες εκδόσεις του PowerPoint, ανταλλαχθεί με συστήματα που λειτουργούν με πακέτα Open XML ή αποθηκευτεί σε μορφή που είναι πιο εύκολη στην επισκόπηση και αποκατάσταση από το παλαιό δυαδικό PPT. Διατηρήστε το αρχικό PPT ως αρχείο αρχειοθέτησης ή αντιγράφου επαναφοράς μέχρι η μετατρεπόμενη παρουσίαση να περάσει τους ελέγχους ακρίβειας.

Εάν χρειάζεστε PDF, HTML, εικόνες, XPS ή άλλο τύπο εξόδου αντί αυτού, χρησιμοποιήστε τις οδηγίες κατά μορφή στο [Convert Presentations to Multiple Formats](/slides/el/net/convert-presentation/) αντί να υποθέτετε ότι όλοι οι προορισμοί διατηρούν επεξεργάσιμες λειτουργίες του PowerPoint.

**Μπορώ να μετατρέψω PPT σε PPTX χωρίς εγκατεστημένο το Microsoft PowerPoint;**

Διατηρεί το κοινό περιεχόμενο παρουσίασης, αλλά η ακριβής ακρίβεια δεν εγγυάται για κάθε παλαιά ή μη υποστηριζόμενη λειτουργία. Ελέγξτε το δημιουργημένο αρχείο όταν περιέχει μακροεντολές, αντικείμενα OLE ή ActiveX, πολυμέσα, εξειδικευμένες κινήσεις ή σπάνιες γραμματοσειρές.

Ναι, εφόσον παρέχετε τον σωστό κωδικό κατά τη φόρτωση του αρχείου. Ένα λείπον ή λανθασμένο συνθηματικό προκαλεί αποτυχία της λειτουργίας φόρτωσης.

**Θα πρέπει να διαγράψω το αρχείο PPT μετά τη μετατροπή;**

Διατηρήστε το αρχικό μέχρι να επαληθεύσετε το PPTX στους θεατές και στις ροές εργασίας που σας ενδιαφέρουν. Αυτό παρέχει ένα αντίγραφο επαναφοράς εάν μια παλαιά λειτουργία μετατρέπεται διαφορετικά.
