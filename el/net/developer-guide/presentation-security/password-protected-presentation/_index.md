## **Εισαγωγή**

Όταν προστατεύετε έναν πίνακα παρουσίασης με κωδικό πρόσβασης, ορίζετε έναν κωδικό που επιβάλλει ορισμένους περιορισμούς στην παρουσίαση. Για να αφαιρέσετε αυτούς τους περιορισμούς, πρέπει να εισαχθεί ο κωδικός πρόσβασης. Μια παρουσίαση που προστατεύεται με κωδικό θεωρείται κλειδωμένη παρουσίαση.

Συνήθως, μπορείτε να ορίσετε έναν κωδικό για την επιβολή αυτών των περιορισμών σε μια παρουσίαση:

- **Τροποποίηση**

Αν θέλετε μόνο ορισμένοι χρήστες να τροποποιούν την παρουσίασή σας, μπορείτε να ορίσετε περιορισμό τροποποίησης. Αυτός ο περιορισμός εμποδίζει τους ανθρώπους από το να τροποποιούν, αλλάζουν ή αντιγράφουν στοιχεία στην παρουσίασή σας εκτός αν παρέχουν τον κωδικό.

Ωστόσο, ακόμη και χωρίς τον κωδικό, ένας χρήστης θα μπορεί να έχει πρόσβαση και να ανοίξει το έγγραφό σας. Σε αυτή τη λειτουργία μόνο για ανάγνωση, ο χρήστης μπορεί να δει το περιεχόμενο—συμπεριλαμβανομένων των υπερσυνδέσμων, των κινήσεων, των εφέ και άλλων στοιχείων—μέσα στην παρουσίασή σας, αλλά δεν μπορεί να αντιγράψει αντικείμενα ή να αποθηκεύσει την παρουσίαση.

- **Άνοιγμα**

Αν θέλετε μόνο ορισμένοι χρήστες να ανοίγουν την παρουσίασή σας, μπορείτε να ορίσετε περιορισμό ανοίγματος. Αυτός ο περιορισμός εμποδίζει τους ανθρώπους ακόμη και από το να δουν το περιεχόμενο της παρουσίασής σας εκτός αν παρέχουν τον κωδικό.

Τεχνικά, ο περιορισμός ανοίγματος εμποδίζει επίσης τους χρήστες από το να τροποποιούν τις παρουσιάσεις σας—αν οι άνθρωποι δεν μπορούν να ανοίξουν μια παρουσίαση, δεν μπορούν να την τροποποιήσουν ή να κάνουν αλλαγές.

**Σημείωση:** Όταν προστατεύετε με κωδικό μια παρουσίαση για να αποτρέψετε το άνοιγμα, το αρχείο παρουσίασης κρυπτογραφείται.

## **Προστασία με κωδικό στην Aspose.Slides**

**Υποστηριζόμενες μορφές**

Η Aspose.Slides υποστηρίζει προστασία με κωδικό, κρυπτογράφηση και παρόμοιες λειτουργίες για παρουσιάσεις σε αυτές τις μορφές:

- PPTX και PPT – Παρουσιάσεις Microsoft PowerPoint
- ODP – Παρουσιάσεις OpenDocument
- OTP – Πρότυπα Παρουσιάσεων OpenDocument

**Υποστηριζόμενες λειτουργίες**

Η Aspose.Slides σας επιτρέπει να χρησιμοποιήσετε προστασία με κωδικό σε παρουσιάσεις για την αποτροπή τροποποιήσεων με τους ακόλουθους τρόπους:

- Κρυπτογράφηση μιας παρουσίασης
- Ορισμός προστασίας εγγραφής σε μια παρουσίαση

**Άλλες λειτουργίες**

Η Aspose.Slides σας επιτρέπει να εκτελέσετε πρόσθετες εργασίες που αφορούν προστασία με κωδικό και κρυπτογράφηση με τους ακόλουθους τρόπους:

- Αποκρυπτογράφηση μιας παρουσίασης· άνοιγμα μιας κρυπτογραφημένης παρουσίασης
- Αφαίρεση κρυπτογράφησης· απενεργοποίηση προστασίας με κωδικό
- Αφαίρεση προστασίας εγγραφής από μια παρουσίαση
- Ανάκτηση των ιδιοτήτων μιας κρυπτογραφημένης παρουσίασης
- Έλεγχος εάν μια παρουσίαση είναι προστατευμένη με κωδικό πριν τη φόρτωση
- Έλεγχος εάν μια παρουσίαση είναι κρυπτογραφημένη
- Έλεγχος εάν μια παρουσίαση είναι προστατευμένη με κωδικό

## **Προστασία παρουσίασης με κωδικό**

Μπορείτε να κρυπτογραφήσετε μια παρουσίαση ορίζοντας έναν κωδικό. Στη συνέχεια, για να τροποποιήσετε την κλειδωμένη παρουσίαση, ο χρήστης πρέπει να παράσχει τον κωδικό.

Για να κρυπτογραφήσετε (ή να προστατεύσετε με κωδικό) μια παρουσίαση, χρησιμοποιήστε τη μέθοδο `Encrypt` από [ProtectionManager](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager) για να ορίσετε έναν κωδικό. Περάστε τον κωδικό στη μέθοδο `Encrypt`, στη συνέχεια χρησιμοποιήστε τη μέθοδο `Save` για να αποθηκεύσετε την πλέον κρυπτογραφημένη παρουσίαση.

Αυτό το παράδειγμα κώδικα σας δείχνει πώς να κρυπτογραφήσετε μια παρουσίαση:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.Encrypt("123123");
    presentation.Save("encrypted-pres.pptx", SaveFormat.Pptx);
}
```

## **Ορισμός προστασίας εγγραφής σε παρουσίαση** 

Μπορείτε να προσθέσετε μια ένδειξη «Μην τροποποιείτε» σε μια παρουσίαση. Αυτό ενημερώνει τους χρήστες ότι δεν θέλετε να κάνουν αλλαγές στην παρουσίαση.

**Σημείωση:** Η διαδικασία προστασίας εγγραφής δεν κρυπτογραφεί την παρουσίαση. Συνεπώς, οι χρήστες—αν το επιλέξουν—μπορούν να τροποποιήσουν την παρουσίαση, αλλά για να αποθηκεύσουν τις αλλαγές, θα πρέπει να την αποθηκεύσουν με διαφορετικό όνομα.

Για να ορίσετε προστασία εγγραφής, χρησιμοποιήστε τη μέθοδο `SetWriteProtection`. Αυτό το παράδειγμα κώδικα σας δείχνει πώς να ορίσετε προστασία εγγραφής σε μια παρουσίαση:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.SetWriteProtection("123123");
    presentation.Save("write-protected-pres.pptx", SaveFormat.Pptx);
}
```

## **Φόρτωση κρυπτογραφημένης παρουσίασης**

Η Aspose.Slides σας επιτρέπει να φορτώσετε μια κρυπτογραφημένη παρουσίαση περνώντας τον σωστό κωδικό πρόσβασης. Αυτό το παράδειγμα κώδικα σας δείχνει πώς να φορτώσετε μια κρυπτογραφημένη παρουσίαση:

```c#
using Aspose.Slides;

LoadOptions loadOptions = new LoadOptions { Password = "123123" };
using (Presentation presentation = new Presentation("pres.pptx", loadOptions))
{
    // Εργασία με την αποκρυπτογραφημένη παρουσίαση.
}
```

## **Αφαίρεση κρυπτογράφησης από παρουσίαση**

Μπορείτε να αφαιρέσετε την κρυπτογράφηση ή την προστασία με κωδικό από μια παρουσίαση, επιτρέποντας στους χρήστες να έχουν πρόσβαση ή να την τροποποιήσουν χωρίς περιορισμούς.

Για να αφαιρέσετε κρυπτογράφηση ή προστασία με κωδικό, καλέστε τη μέθοδο [RemoveEncryption](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager/methods/removeencryption). Αυτό το παράδειγμα κώδικα σας δείχνει πώς να αφαιρέσετε την κρυπτογράφηση από μια παρουσίαση:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

LoadOptions loadOptions = new LoadOptions { Password = "123123" };
using (Presentation presentation = new Presentation("pres.pptx", loadOptions))
{
    presentation.ProtectionManager.RemoveEncryption();
    presentation.Save("encryption-removed.pptx", SaveFormat.Pptx);
}
```

## **Αφαίρεση προστασίας εγγραφής από παρουσίαση**

Μπορείτε να χρησιμοποιήσετε την Aspose.Slides για να αφαιρέσετε την προστασία εγγραφής από ένα αρχείο παρουσίασης. Με αυτόν τον τρόπο, οι χρήστες μπορούν να το τροποποιήσουν όπως θέλουν—και δεν θα λαμβάνουν προειδοποιήσεις κατά την εκτέλεση τέτοιων εργασιών.

Μπορείτε να αφαιρέσετε την προστασία εγγραφής χρησιμοποιώντας τη μέθοδο [RemoveWriteProtection](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager/methods/removewriteprotection). Αυτό το παράδειγμα κώδικα σας δείχνει πώς να αφαιρέσετε την προστασία εγγραφής από μια παρουσίαση:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.RemoveWriteProtection();
    presentation.Save("write-protection-removed.pptx", SaveFormat.Pptx);
}
```

## **Ανάκτηση ιδιοτήτων κρυπτογραφημένης παρουσίασης**

Συνήθως, οι χρήστες δυσκολεύονται να ανακτήσουν τις ιδιότητες εγγράφου μιας κρυπτογραφημένης ή προστατευμένης με κωδικό παρουσίασης. Ωστόσο, η Aspose.Slides προσφέρει έναν μηχανισμό που επιτρέπει την προστασία μιας παρουσίασης με κωδικό ενώ διατηρεί τη δυνατότητα των χρηστών να έχουν πρόσβαση στις ιδιότητές της.

**Σημείωση:** Από προεπιλογή, όταν η Aspose.Slides κρυπτογραφεί μια παρουσίαση, οι ιδιότητες εγγράφου της παρουσίασης προστατεύονται επίσης με κωδικό. Εάν χρειάζεται να κάνετε τις ιδιότητες εγγράφου προσβάσιμες ακόμη και μετά την κρυπτογράφηση, η Aspose.Slides σας επιτρέπει να το κάνετε ακριβώς αυτό.

Αν θέλετε οι χρήστες να διατηρήσουν τη δυνατότητα πρόσβασης στις ιδιότητες μιας κρυπτογραφημένης παρουσίασης, ορίστε την ιδιότητα `EncryptDocumentProperties` του [IProtectionManager](https://reference.aspose.com/slides/el/net/aspose.slides/iprotectionmanager/) σε `false`. Αυτό το παράδειγμα κώδικα σας δείχνει πώς να κρυπτογραφήσετε μια παρουσίαση ενώ εξακολουθείτε να παρέχετε στους χρήστες πρόσβαση στις ιδιότητες εγγράφου της:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("pres.pptx");

presentation.ProtectionManager.EncryptDocumentProperties = false;
presentation.ProtectionManager.Encrypt("123123");
presentation.Save("encrypted-pres.pptx", SaveFormat.Pptx);
```

## **Φόρτωση μόνο ιδιοτήτων εγγράφου από κρυπτογραφημένη παρουσίαση**

Για να εξετάσετε τα μεταδεδομένα μιας κρυπτογραφημένης παρουσίασης χωρίς να φορτώσετε τις διαφάνειες ή άλλο περιεχόμενο, δημιουργήστε ένα αντικείμενο [LoadOptions](https://reference.aspose.com/slides/el/net/aspose.slides/loadoptions/) και ορίστε το [OnlyLoadDocumentProperties](https://reference.aspose.com/slides/el/net/aspose.slides/loadoptions/onlyloaddocumentproperties/) σε `true`. Σε αυτή τη λειτουργία, η Aspose.Slides αγνοεί τον κωδικό και φορτώνει μόνο τις ιδιότητες εγγράφου που είναι δημόσια προσβάσιμες.

Το ακόλουθο παράδειγμα κώδικα διαβάζει τις ενσωματωμένες και προσαρμοσμένες ιδιότητες εγγράφου μέσω του [IPresentation.DocumentProperties](https://reference.aspose.com/slides/el/net/aspose.slides/ipresentation/documentproperties/):

```c#
using Aspose.Slides;

var loadOptions = new LoadOptions
{
    OnlyLoadDocumentProperties = true
};

using var presentation = new Presentation("encrypted-pres.pptx", loadOptions);
var documentProperties = presentation.DocumentProperties;

// Read built-in document properties.
Console.WriteLine("Title: " + documentProperties.Title);
Console.WriteLine("Author: " + documentProperties.Author);

// Read custom document properties.
var customPropertyCount = documentProperties.CountOfCustomProperties;

for (var propertyIndex = 0; propertyIndex < customPropertyCount; propertyIndex++)
{
    var propertyName = documentProperties.GetCustomPropertyName(propertyIndex);
    var propertyValue = documentProperties[propertyName];

    Console.WriteLine(propertyName + ": " + propertyValue);
}
```

Αυτή η ροή εργασίας λειτουργεί μόνο όταν οι ιδιότητες εγγράφου έχουν μείνει μη κρυπτογραφημένες (δημόσιες) κατά την κρυπτογράφηση της παρουσίασης. Εάν οι ιδιότητες εγγράφου είναι κρυπτογραφημένες, ο ορισμός του `OnlyLoadDocumentProperties` σε `true` προκαλεί εξαίρεση επειδή ο κωδικός παραβλέπεται σε αυτή τη λειτουργία. Για να έχετε πρόσβαση σε κρυπτογραφημένες ιδιότητες εγγράφου ή να φορτώσετε ολόκληρη την παρουσίαση, συμπεριλαμβανομένων των διαφανειών και άλλου περιεχομένου, δώστε τη σωστή τιμή `Password` στις [LoadOptions](https://reference.aspose.com/slides/el/net/aspose.slides/loadoptions/).

## **Έλεγχος εάν η παρουσίαση είναι προστατευμένη με κωδικό**

Πριν φορτώσετε μια παρουσίαση, ίσως θέλετε να ελέγξετε ότι δεν έχει προστατευθεί με κωδικό. Αυτό σας βοηθά να αποφύγετε σφάλματα και παρόμοια προβλήματα που προκύπτουν όταν μια παρουσίαση που είναι προστατευμένη με κωδικό φορτώνεται χωρίς τον σωστό κωδικό.

Αυτός ο κώδικας C# σας δείχνει πώς να εξετάσετε μια παρουσίαση για να δείτε αν είναι προστατευμένη με κωδικό χωρίς να τη φορτώσετε πραγματικά:

```c#
using Aspose.Slides;

var presentationInfo = PresentationFactory.Instance.GetPresentationInfo("example.pptx");
Console.WriteLine("The presentation is password protected: " + presentationInfo.IsPasswordProtected);
```

## **Έλεγχος εάν η παρουσίαση είναι κρυπτογραφημένη**

Η Aspose.Slides σας επιτρέπει να ελέγξετε εάν μια παρουσίαση είναι κρυπτογραφημένη. Για να εκτελέσετε αυτή τη λειτουργία, μπορείτε να χρησιμοποιήσετε την ιδιότητα [IsEncrypted](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager/properties/isencrypted), η οποία επιστρέφει `true` αν η παρουσίαση είναι κρυπτογραφημένη ή `false` αν δεν είναι.

Αυτό το παράδειγμα κώδικα σας δείχνει πώς να ελέγξετε εάν μια παρουσίαση είναι κρυπτογραφημένη:

```c#
using Aspose.Slides;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    bool isEncrypted = presentation.ProtectionManager.IsEncrypted;
}
```

## **Έλεγχος εάν η παρουσίαση είναι προστατευμένη εγγραφής**

Η Aspose.Slides σας επιτρέπει να ελέγξετε εάν μια παρουσίαση είναι προστατευμένη εγγραφής. Για να εκτελέσετε αυτή τη λειτουργία, μπορείτε να χρησιμοποιήσετε την ιδιότητα [IsWriteProtected](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager/properties/iswriteprotected), η οποία επιστρέφει `true` αν η παρουσίαση είναι προστατευμένη εγγραφής ή `false` αν δεν είναι.

Αυτό το παράδειγμα κώδικα σας δείχνει πώς να ελέγξετε εάν μια παρουσίαση είναι προστατευμένη εγγραφής:

```c#
using Aspose.Slides;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    bool isEncrypted = presentation.ProtectionManager.IsWriteProtected;
}
```

## **Επαλήθευση χρήσης κωδικού σε παρουσίαση**

Μπορεί να θέλετε να ελέγξετε και να επιβεβαιώσετε ότι ένας συγκεκριμένος κωδικός έχει χρησιμοποιηθεί για την προστασία ενός εγγράφου παρουσίασης. Η Aspose.Slides παρέχει τα μέσα για να επικυρώσετε έναν κωδικό.

Αυτό το παράδειγμα κώδικα σας δείχνει πώς να επικυρώσετε έναν κωδικό:

```c#
using Aspose.Slides;

using (IPresentation presentation = new Presentation("pres.pptx"))
{
    // Ελέγξτε εάν ο κωδικός ταιριάζει.
    bool isWriteProtected = presentation.ProtectionManager.CheckWriteProtection("my_password");
}
```

Επιστρέφει `true` εάν η παρουσίαση έχει κρυπτογραφηθεί με τον συγκεκριμένο κωδικό· διαφορετικά, επιστρέφει `false`.

## **Συχνές ερωτήσεις**

**Ποιες μέθοδοι κρυπτογράφησης υποστηρίζει η Aspose.Slides;**

Η Aspose.Slides υποστηρίζει σύγχρονες μεθόδους κρυπτογράφησης, συμπεριλαμβανομένων αλγορίθμων βασισμένων στο AES, εξασφαλίζοντας υψηλό επίπεδο ασφάλειας δεδομένων για τις παρουσιάσεις σας.

**Τι συμβαίνει εάν εισαχθεί εσφαλμένος κωδικός κατά την προσπάθεια ανοίγματος μιας παρουσίασης;**

Γίνεται εξαίρεση εάν χρησιμοποιηθεί λανθασμένος κωδικός, ενημερώνοντας ότι η πρόσβαση στην παρουσίαση έχει απορριφθεί. Αυτό βοηθά στην αποτροπή μη εξουσιοδοτημένης πρόσβασης και προστατεύει το περιεχόμενο της παρουσίασης.

**Υπάρχουν επιπτώσεις στην απόδοση όταν εργάζεστε με παρουσιάσεις που προστατεύονται με κωδικό;**

Η διαδικασία κρυπτογράφησης και αποκρυπτογράφησης μπορεί να προκαλέσει ελαφρώς επιπλέον φόρτο κατά τις λειτουργίες ανοίγματος και αποθήκευσης. Στις περισσότερες περιπτώσεις, αυτή η επίδραση στην απόδοση είναι ελάχιστη και δεν επηρεάζει σημαντικά το συνολικό χρόνο επεξεργασίας των εργασιών παρουσίασής σας.
