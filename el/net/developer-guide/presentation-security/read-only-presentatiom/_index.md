## **Εισαγωγή**

Στο PowerPoint 2019, η Microsoft εισήγαγε τη ρύθμιση **Always Open Read-Only** ως μία από τις επιλογές που μπορούν να χρησιμοποιήσουν οι χρήστες για την προστασία των παρουσιάσεών τους. Μπορεί να θέλετε να χρησιμοποιήσετε αυτήν τη ρύθμιση μόνο για ανάγνωση ώστε να προστατεύσετε μια παρουσίαση όταν

- Θέλετε να αποτρέψετε τυχαίες επεργασίες και να διατηρήσετε το περιεχόμενο της παρουσίασής σας ασφαλές. 
- Θέλετε να ενημερώσετε τους ανθρώπους ότι η παρουσίαση που παρέχετε είναι η τελική έκδοση. 

Αφού επιλέξετε την επιλογή **Always Open Read-Only** για μια παρουσίαση, όταν οι χρήστες την ανοίξουν, βλέπουν τη σύσταση **Read-Only** και μπορεί να εμφανιστεί μήνυμα της μορφής: *Για να αποτραπούν τυχαίες αλλαγές, ο συγγραφέας έχει ορίσει αυτό το αρχείο να ανοίγει μόνο για ανάγνωση.*

Η σύσταση **Read-Only** είναι ένας απλός αλλά αποτελεσματικός αποτρεπτικός μηχανισμός που αποθαρρύνει την επεξεργασία, καθώς οι χρήστες πρέπει να εκτελέσουν μια ενέργεια για να την αφαιρέσουν πριν τους επιτραπεί η επεξεργασία της παρουσίασης. Εάν δεν θέλετε οι χρήστες να κάνουν αλλαγές σε μια παρουσίαση και θέλετε να το τους πείτε με ευγενικό τρόπο, τότε η σύσταση **Read-Only** μπορεί να είναι μια καλή επιλογή για εσάς. 

> Εάν μια παρουσίαση με προστασία **Read-Only** ανοίξει σε μία παλαιότερη έκδοση του Microsoft PowerPoint—η οποία δεν υποστηρίζει τη πρόσφατα εισαγόμενη λειτουργία—η σύσταση **Read-Only** αγνοείται (η παρουσίαση ανοίγει κανονικά).

## **Εφαρμογή Λειτουργίας Μόνο για Ανάγνωση**

Το Aspose.Slides for .NET σας επιτρέπει να ορίσετε μια παρουσίαση σε **Read-Only**, που σημαίνει ότι οι χρήστες (αφού ανοίξουν την παρουσίαση) βλέπουν τη σύσταση **Read-Only**. Αυτό το δείγμα κώδικα δείχνει πώς να ορίσετε μια παρουσίαση σε **Read-Only** σε C# χρησιμοποιώντας το Aspose.Slides:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation())
{
    pres.ProtectionManager.ReadOnlyRecommended = true;
    pres.Save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
}
```

{{% alert color="info" %}} 

**Σημείωση**: Η σύσταση **Read-Only** προορίζεται απλώς να αποθαρρύνει την επεξεργασία ή να εμποδίζει τυχαίες αλλαγές σε μια παρουσίαση PowerPoint. Εάν ένα άτομο με προαίρεση—που γνωρίζει τι κάνει—αποφασίσει να επεξεργαστεί την παρουσίασή σας, μπορεί εύκολα να αφαιρέσει τη ρύθμιση μόνο για ανάγνωση. Εάν χρειάζεστε σοβαρή αποτροπή μη εξουσιοδοτημένης επεξεργασίας, είναι προτιμότερο να χρησιμοποιήσετε [more stringent protections that involve encryptions and passwords](https://docs.aspose.com/slides/el/net/password-protected-presentation/). 

{{% /alert %}} 

## **Συχνές ερωτήσεις**

### Πώς διαφέρει το 'Read-Only recommended' από την πλήρη προστασία με κωδικό;

Το 'Read-Only recommended' εμφανίζει μόνο μια πρόταση για άνοιγμα του αρχείου σε λειτουργία μόνο για ανάγνωση και είναι εύκολο να παρακαμφθεί. [Password protection](/slides/el/net/password-protected-presentation/) περιορίζει πραγματικά το άνοιγμα ή την επεξεργασία και είναι κατάλληλο όταν χρειάζεστε πραγματικό έλεγχο ασφαλείας.

### Μπορεί το 'Read-Only recommended' να συνδυαστεί με υδατογραφήματα για περαιτέρω αποτροπή επεξεργασιών;

Ναι. Η σύσταση μπορεί να συνδυαστεί με [watermarks](/slides/el/net/watermark/) ως οπτικό αποτρεπτικό μέτρο· είναι ξεχωριστοί μηχανισμοί που λειτουργούν καλά μαζί.

### Μπορεί ένα μακρο ή εξωτερικό εργαλείο να τροποποιήσει ακόμη το αρχείο όταν είναι ενεργοποιημένη η σύσταση;

Ναι. Η σύσταση δεν εμποδίζει προγραμματιστικές αλλαγές. Για την αποτροπή αυτοματοποιημένων επεξεργασιών, χρησιμοποιήστε [passwords and encryption](/slides/el/net/password-protected-presentation/).

### Πώς σχετίζεται το 'Read-Only recommended' με τις σημαδοδοτήσεις 'IsEncrypted' και 'IsWriteProtected';

Είναι διαφορετικά σήματα. Το 'Read-Only recommended' είναι ένα ήπιο, προαιρετικό προτρεπτικό μήνυμα· [IsWriteProtected](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager/iswriteprotected/) και [IsEncrypted](https://reference.aspose.com/slides/el/net/aspose.slides/protectionmanager/isencrypted/) υποδεικνύουν πραγματικούς περιορισμούς εγγραφής ή ανάγνωσης που εξαρτώνται από κωδικούς ή κρυπτογράφηση.
