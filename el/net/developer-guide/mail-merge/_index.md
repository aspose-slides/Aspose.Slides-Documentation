## **Συγχώνευση αλληλογραφίας σε παρουσιάσεις PowerPoint**

Aspose.Slides for .NET σας επιτρέπει να δημιουργείτε αυτόματα παρουσιάσεις PowerPoint χρησιμοποιώντας ένα πρότυπο και μια πηγή δεδομένων. Η Συγχώνευση αλληλογραφίας γεμίζει τα σύμβολα κράτησης θέσης του προτύπου με δεδομένα και δημιουργεί είτε μία ενιαία παρουσίαση που περιέχει επαναλαμβανόμενες διαφάνειες προτύπου για κάθε σύνολο δεδομένων είτε ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων.

Αυτή η λειτουργία είναι χρήσιμη για τη δημιουργία καταλόγων προϊόντων, εξατομικευμένων παρουσιάσεων, αναφορών, πιστοποιητικών, προτάσεων, τιμοκαταλόγων και άλλων εγγράφων στα οποία η δομή της παρουσίασης παραμένει η ίδια ενώ το περιεχόμενο διαφέρει.

## **Πώς λειτουργεί η Συγχώνευση αλληλογραφίας**

Η Συγχώνευση αλληλογραφίας χρησιμοποιεί μια παρουσίαση PowerPoint ως πρότυπο και αντικαθιστά τα σύμβολα κράτησης θέσης με τιμές από μια πηγή δεδομένων.

![Ροή εργασίας Συγχώνευσης αλληλογραφίας](mail-merge-workflow.png)

Ένα σύμβολο κράτησης θέσης είναι ένα όνομα πεδίου περικλεισμένο σε διπλές αγκύλες, όπως `{{title}}` ή `{{price}}`. Τα σύμβολα μπορούν να τοποθετηθούν σε κείμενο σε σχήματα, κελιά πίνακα, ομαδοποιημένα σχήματα και σημειώσεις ομιλητή.

Για παράδειγμα, μια διαφάνεια προτύπου μπορεί να περιέχει το παρακάτω κείμενο:

- `Product: {{title}}`
- `Price: {{price}}`
- `Description: {{description}}`

Όταν η πηγή δεδομένων περιέχει τις ακόλουθες τιμές:

| Πεδίο | Τιμή |
|---|---|
| title | Laptop X1 |
| price | $999 |
| description | 14-inch display, 16 GB RAM |

Η Συγχώνευση αλληλογραφίας αντικαθιστά τα σύμβολα με τις αντίστοιχες τιμές, δημιουργώντας μια διαφάνεια με τις πραγματικές πληροφορίες του προϊόντος.

Τα ονόματα πεδίων δεν διακρίνουν πεζά-κεφαλαία, έτσι `{{title}}` και `{{Title}}` αναφέρονται στο ίδιο πεδίο.

Οι ακόλουθοι κανόνες ισχύουν κατά την αντικατάσταση συμβόλων κράτησης θέσης:

- Τα σύμβολα αντικαθίστανται στις διαφάνειες, συμπεριλαμβανομένων των ομαδοποιημένων σχημάτων και των κελιών πίνακα, καθώς και στις σημειώσεις ομιλητή.
- Τα σύμβολα στις κύριες διαφάνειες και στις διαφάνειες διάταξης δεν αντικαθίστανται.
- Ένα σύμβολο που το πεδίο του δεν υπάρχει στο σύνολο δεδομένων παραμένει αμετάβλητο.
- Μία κενή τιμή πεδίου αντικαθιστά το σύμβολο του με κενή συμβολοσειρά.
- Το εισαχθέν κείμενο κληρονομεί τη μορφοποίηση του πρώτου χαρακτήρα του συμβόλου.
- Οι τιμές δεν πρέπει να περιέχουν κείμενο συμβόλου κράτησης θέσης, διότι το εισαχθέν κείμενο μπορεί να υποστεί επεξεργασία ξανά και να αντικατασταθεί από άλλο πεδίο.

Η αρχική παρουσίαση προτύπου δεν τροποποιείται κατά τη διάρκεια της λειτουργίας συγχώνευσης και πρέπει να περιέχει τουλάχιστον μία διαφάνεια.

## **Υποστηριζόμενες πηγές δεδομένων**

Η Συγχώνευση αλληλογραφίας υποστηρίζει δύο τρόπους παροχής δεδομένων:

- Δημιουργήστε μια πηγή δεδομένων προγραμματικά χρησιμοποιώντας το `IMailMergeDataSource`.
- Αναγνώστε δεδομένα από αρχείο ή ροή CSV, XLSX, JSON ή XML.

Η μορφή των δεδομένων εντοπίζεται από το περιεχόμενό του, όχι από την επέκταση του αρχείου. Υποστηρίζονται επίσης ροές που δεν υποστηρίζουν αναζήτηση.

Η πηγή δεδομένων πρέπει να περιέχει τουλάχιστον ένα σύνολο δεδομένων. Κάθε σύνολο δεδομένων αντιπροσωπεύει ένα αντίγραφο του προτύπου που θα γεμίσει με τις τιμές του.

Εάν το περιεχόμενο των δεδομένων δεν μπορεί να αναγνωριστεί ως μια υποστηριζόμενη μορφή, προκαλείται `NotSupportedException`. Εάν το περιεχόμενο αναγνωρίζεται αλλά δεν συμμορφώνεται με τις απαιτήσεις της μορφής, προκαλείται `InvalidDataException`. Το μήνυμα της εξαίρεσης περιέχει τη θέση του σφάλματος στα δεδομένα.

### **JSON**

Η πηγή δεδομένων JSON πρέπει να έχει ένα αντικείμενο ρίζας που περιέχει έναν πίνακα `sets`. Κάθε στοιχείο του πίνακα αντιπροσωπεύει ένα σύνολο δεδομένων και πρέπει να περιέχει έναν πίνακα `fields`. Κάθε πεδίο πρέπει να έχει ένα `name` και μια συμβολοσειρά `value`.

Η προαιρετική ιδιότητα `version` πρέπει να είναι `"1.0"`, και η προαιρετική ιδιότητα `type` ενός πεδίου πρέπει να είναι `"text"`. Τα ονόματα των ιδιοτήτων διακρίνουν πεζά-κεφαλαία. Οι άγνωστες ιδιότητες αγνοούνται.

Τα δεδομένα JSON διαβάζονται ως UTF-8, ή ως UTF-16 όταν τα δεδομένα αρχίζουν με ένα byte order mark (BOM).

Το παρακάτω παράδειγμα περιέχει δύο σύνολα δεδομένων:

```json
{
  "version": "1.0",
  "sets": [
    {
      "fields": [
        { "name": "title", "value": "Laptop X1" },
        { "name": "price", "value": "$999" }
      ]
    },
    {
      "fields": [
        { "name": "title", "value": "Tablet S2" },
        { "name": "price", "value": "$499" }
      ]
    }
  ]
}
```

### **XML**

Η πηγή δεδομένων XML πρέπει να έχει ένα στοιχείο ρίζας `template` που περιέχει το στοιχείο `sets`. Κάθε στοιχείο `set` περιέχει στοιχεία `field`, και κάθε πεδίο πρέπει να περιέχει στοιχεία `name` και `value`.

Ένα κενό στοιχείο `value` αντιμετωπίζεται ως κενή συμβολοσειρά. Τα ονόματα των στοιχείων διακρίνουν πεζά-κεφαλαία. Τα άγνωστα στοιχεία και τα σχόλια παραλείπονται. Η κωδικοποίηση καθορίζεται από τη δήλωση XML. Δεν επιτρέπονται ορισμοί τύπου εγγράφου (DTD).

```xml
<?xml version="1.0" encoding="utf-8"?>
<template>
  <sets>
    <set>
      <field>
        <name>title</name>
        <value>Laptop X1</value>
      </field>
      <field>
        <name>price</name>
        <value>$999</value>
      </field>
    </set>
    <set>
      <field>
        <name>title</name>
        <value>Tablet S2</value>
      </field>
      <field>
        <name>price</name>
        <value>$499</value>
      </field>
    </set>
  </sets>
</template>
```

### **CSV**

Τα δεδομένα CSV χρησιμοποιούν άνω τελείες ως διαχωριστικά τιμών.

Η πρώτη γραμμή περιέχει τα ονόματα πεδίων και τελειώνει στο πρώτο κενό όνομα πεδίου. Κάθε επόμενη γραμμή αντιπροσωπεύει ένα σύνολο δεδομένων. Τα δεδομένα λήγουν στην πρώτη κενή γραμμή.

Ισχύουν οι ακόλουθοι κανόνες:

- Οι ελλιπείς τιμές στο τέλος μιας γραμμής αντιμετωπίζονται ως κενές συμβολοσειρές.
- Οι τιμές πέρα από τα ορισμένα ονόματα πεδίων παραλείπονται.
- Μια τιμή που περιέχει άνω τελεία, εισαγωγικό ή αλλαγή γραμμής πρέπει να περιβάλλεται από εισαγωγικά.
- Τα εισαγωγικά μέσα σε μια τιμή που είναι ήδη σε εισαγωγικά πρέπει να διπλασιαστούν.
- Τα δεδομένα διαβάζονται ως UTF-8, ή ως UTF-16 όταν αρχίζουν με byte order mark (BOM).

Παράδειγμα:

```csv
title;price;description
Laptop X1;$999;"14"" display; 16 GB RAM"
Tablet S2;$499;
```

### **XLSX**

Τα δεδομένα XLSX διαβάζονται από το πρώτο φύλλο εργασίας.

Το φύλλο εργασίας ακολουθεί τους ίδιους κανόνες με το CSV:

- Η πρώτη γραμμή περιέχει τα ονόματα πεδίων και τελειώνει στο πρώτο κενό κελί.
- Κάθε επόμενη γραμμή αντιπροσωπεύει ένα σύνολο δεδομένων.
- Τα δεδομένα λήγουν στην πρώτη κενή γραμμή.
- Τα κενά κελιά αντιμετωπίζονται ως κενές συμβολοσειρές.
- Οι αριθμητικές τιμές μετατρέπονται σε κείμενο χρησιμοποιώντας την αμετάβλητη πολιτισμική ρύθμιση.

## **Δημιουργία μίας παρουσίασης**

Η μέθοδος `MergeToSinglePresentation` δημιουργεί μία παρουσίαση που περιέχει ένα αντίγραφο των διαφανειών προτύπου για κάθε σύνολο δεδομένων. Κάθε αντίγραφο γεμίζει με τα αντίστοιχα δεδομένα.

Η σειρά των συνόλων δεδομένων καθορίζει τη σειρά των ομάδων διαφανειών στην προκύπτουσα παρουσίαση.

### **Συγχώνευση δεδομένων από αρχείο**

Το παρακάτω παράδειγμα φορτώνει ένα πρότυπο και ένα αρχείο δεδομένων JSON, δημιουργεί μία παρουσίαση που περιέχει τις διαφάνειες για όλα τα σύνολα δεδομένων, και αποθηκεύει το αποτέλεσμα.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, "products.json"))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

Τα δεδομένα μπορούν επίσης να διαβαστούν από ροή. Η ροή διαβάζεται από την τρέχουσα θέση της και δεν κλείνει από τη λειτουργία Συγχώνευσης αλληλογραφίας.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xml"))
using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, data))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

### **Δημιουργία πηγής δεδομένων σε κώδικα**

Μπορείτε να δημιουργήσετε μια πηγή δεδομένων προγραμματικά χρησιμοποιώντας τα `MailMergeDataSource` και `MailMergeDataSet`. Προσθέστε ένα σύνολο δεδομένων για κάθε εγγραφή και ορίστε τα πεδία του χρησιμοποιώντας τη μέθοδο `AddText`.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet laptop = source.AddDataSet();
laptop.AddText("title", "Laptop X1");
laptop.AddText("price", "$999");

IMailMergeDataSet tablet = source.AddDataSet();
tablet.AddText("title", "Tablet S2");
tablet.AddText("price", "$499");

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, source))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

Σε αυτό το παράδειγμα, οι διαφάνειες προτύπου επαναλαμβάνονται δύο φορές: μία για το laptop και μία για το tablet. Τα σύμβολα γεμίζονται με τις τιμές που ορίζονται σε κάθε σύνολο δεδομένων.

## **Δημιουργία πολλαπλών παρουσιάσεων**

Αν χρειάζεστε ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων, χρησιμοποιήστε τη μέθοδο `MergeToMultiplePresentations`.

Αυτή η μέθοδος επεξεργάζεται τα σύνολα δεδομένων ένα-ένα, δημιουργεί μια παρουσίαση από το πρότυπο, τη γεμίζει με τα τρέχοντα δεδομένα και περνά τη δημιουργημένη παρουσίαση σε έναν επεξεργαστή (handler).

Ο επεξεργαστής καλείται μία φορά για κάθε σύνολο δεδομένων, με τη σειρά των αρχικών δεδομένων.

### **Αποθήκευση κάθε παρουσίασης**

Το παρακάτω παράδειγμα διαβάζει δεδομένα από αρχείο CSV και αποθηκεύει κάθε δημιουργημένη παρουσίαση ως ξεχωριστό αρχείο.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.csv",
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

Η ιδιότητα `args.Index` παρέχει τον δείκτη μηδενικής βάσης του τρέχοντος συνόλου δεδομένων. Στο παράδειγμα, χρησιμοποιείται για τη δημιουργία διαδοχικών ονομάτων αρχείων ξεκινώντας από το `product_1.pptx`.

Τα δεδομένα μπορούν επίσης να διαβαστούν από ροή:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xlsx"))
using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        data,
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

### **Χρήση τιμών συνόλων δεδομένων για ονομασία αρχείων**

Ο επεξεργαστής λαμβάνει τόσο τη δημιουργημένη παρουσίαση όσο και τις πληροφορίες σχετικά με το σύνολο δεδομένων που χρησιμοποιήθηκε για τη δημιουργία της. Μπορείτε να χρησιμοποιήσετε τις τιμές του συνόλου δεδομένων για να δημιουργήσετε περιγραφικά ονόματα αρχείων.

Για παράδειγμα, ο παρακάτω κώδικας αποθηκεύει κάθε παρουσίαση χρησιμοποιώντας τον τίτλο του προϊόντος:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string title = args.DataSet.GetText("title");
            string fileName = title != null
                ? title
                : "product_" + (args.Index + 1);

            presentation.Save(fileName + ".pptx", SaveFormat.Pptx);
        });
}
```

Η ιδιότητα `DataSet` επιστρέφει το σύνολο δεδομένων που χρησιμοποιείται για τη συμπλήρωση της τρέχουσας παρουσίασης. Η μέθοδος `GetText` ανακτά την τιμή ενός συγκεκριμένου πεδίου, ή `null` εάν το πεδίο δεν υπάρχει.

Αυτό σας επιτρέπει να χρησιμοποιήσετε τις τιμές δεδομένων για ονομασία αρχείων, οργάνωση εξόδου ή εφαρμογή πρόσθετης επεξεργασίας στον επεξεργαστή.

## **Διαχείριση παραγόμενων παρουσιάσεων**

`MergeToMultiplePresentations` χρησιμοποιεί το delegate `MailMergedPresentationHandler` για την επεξεργασία κάθε παραγόμενης παρουσίασης.

Ο επεξεργαστής λαμβάνει δύο επιχειρήματα:

- `presentation` — η παρουσίαση που δημιουργείται από το πρότυπο και γεμίζεται με το τρέχον σύνολο δεδομένων.
- `args` — πληροφορίες για τη δημιουργημένη παρουσίαση, συμπεριλαμβανομένου του δείκτη του συνόλου δεδομένων και του ίδιου του συνόλου δεδομένων.

Η δημιουργημένη παρουσίαση ανήκει στη λειτουργία Συγχώνευσης αλληλογραφίας και απορρίπτεται αμέσως μετά την επιστροφή του επεξεργαστή. Συνεπώς, πρέπει να την αποθηκεύσετε ή να αντιγράψετε τυχόν απαιτούμενα δεδομένα μέσα στον επεξεργαστή. Μην διατηρείτε αναφορά σε αυτήν μετά την επιστροφή του επεξεργαστή ή να την απορρίψετε χειροκίνητα.

Ο επεξεργαστής εκτελείται στο νήμα κλήσης, μία παρουσίαση τη φορά, με τη σειρά των συνόλων δεδομένων. Μία μόνο παραγόμενη παρουσίαση διατηρείται στη μνήμη τη δεδομένη στιγμή, καθιστώντας αυτή την προσέγγιση κατάλληλη για επεξεργασία μεγάλων πηγών δεδομένων χωρίς να διατηρούνται όλες οι παραγόμενες παρουσιάσεις στη μνήμη ταυτόχρονα.

Εάν ο επεξεργαστής ρίξει μια εξαίρεση, η λειτουργία Συγχώνευσης αλληλογραφίας σταματά και η εξαίρεση προωθείται στον καλούντα αμετάβλητη. Οι παρουσιάσεις που έχουν ήδη υποβληθεί σε επεξεργασία παραμένουν αμετάβλητες, και τα υπόλοιπα σύνολα δεδομένων δεν επεξεργάζονται.

Το παρακάτω παράδειγμα αποθηκεύει τις παραγόμενες παρουσιάσεις σε έναν αφιερωμένο κατάλογο:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

string outputFolder = "output";
Directory.CreateDirectory(outputFolder);

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string path = Path.Combine(
                outputFolder,
                "product_" + (args.Index + 1) + ".pptx");

            presentation.Save(path, SaveFormat.Pptx);
        });
}
```

## **Εργασία με δεδομένα Συγχώνευσης αλληλογραφίας**

Η κλάση `MailMergeDataSource` αντιπροσωπεύει μια ταξινομημένη συλλογή συνόλων δεδομένων. Μπορεί να χρησιμοποιηθεί για τη δημιουργία δεδομένων σε κώδικα, τον έλεγχο του αριθμού των συνόλων δεδομένων, και την πρόσβαση σε μεμονωμένα σύνολα δεδομένων με δείκτη.

### **Ανάκτηση του αριθμού των συνόλων δεδομένων**

Η ιδιότητα `Count` επιστρέφει τον αριθμό των συνόλων δεδομένων στην πηγή.

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine("Presentations to create: " + source.Count);
```

### **Πρόσβαση σε σύνολο δεδομένων με δείκτη**

Η ιδιότητα `Item(int)` παρέχει πρόσβαση σε σύνολο δεδομένων στον καθορισμένο δείκτη μηδενικής βάσης.

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine(source[1].GetText("title"));
```

Αυτό το παράδειγμα ανακτά τον τίτλο του δεύτερου συνόλου δεδομένων.

### **Προσθήκη πεδίων κειμένου**

Η μέθοδος `AddText` προσθέτει ένα ονομαστικό πεδίο κειμένου σε ένα σύνολο δεδομένων. Η τιμή του πεδίου αντικαθιστά όλα τα αντίστοιχα σύμβολα στο πρότυπο.

```csharp
MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet dataSet = source.AddDataSet();
dataSet.AddText("title", "Laptop X1");
dataSet.AddText("subtitle", string.Empty);
```

Μία κενή τιμή αφαιρεί το αντίστοιχο σύμβολο από το προκύπτον κείμενο. Εάν το πεδίο δεν προστεθεί στο σύνολο δεδομένων, το σύμβολο παραμένει αμετάβλητο.

### **Ανάγνωση πεδίων κειμένου**

Η μέθοδος `GetText` ανακτά την τιμή ενός πεδίου με βάση το όνομα. Τα ονόματα πεδίων δεν διακρίνουν πεζά-κεφαλαία.

```csharp
IMailMergeDataSet dataSet = source[0];

string title = dataSet.GetText("title");
string price = dataSet.GetText("price");
```

Εάν το πεδίο δεν υπάρχει ή το καθορισμένο όνομα πεδίου είναι `null`, η `GetText` επιστρέφει `null`.

## **Σύνοψη**

Η Συγχώνευση αλληλογραφίας στο Aspose.Slides for .NET παρέχει έναν βολικό τρόπο για τη δημιουργία παρουσιάσεων που βασίζονται σε δεδομένα από ένα επαναχρησιμοποιήσιμο πρότυπο.

Μπορείτε να τη χρησιμοποιήσετε για:

- Να γεμίσετε πρότυπα παρουσιάσεων με τιμές από πηγές δεδομένων.
- Να δημιουργήσετε μία παρουσίαση που περιέχει επαναλαμβανόμενες διαφάνειες προτύπου για πολλαπλά σύνολα δεδομένων.
- Να δημιουργήσετε ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων.
- Να διαβάζετε δεδομένα από αρχεία ή ροές CSV, XLSX, JSON και XML.
- Να δημιουργείτε πηγές δεδομένων απευθείας στον κώδικα.
- Να επεξεργάζεστε και να αποθηκεύετε τις παραγόμενες παρουσιάσεις διαδοχικά χρησιμοποιώντας έναν επεξεργαστή.

Συνδυάζοντας επαναχρησιμοποιήσιμα πρότυπα με δομημένα δεδομένα, μπορείτε να αυτοματοποιήσετε τη δημιουργία μεγάλου αριθμού παρουσιάσεων, διατηρώντας το σχεδιασμό του προτύπου και τη λογική επεξεργασίας δεδομένων ξεχωριστά.

## **Συχνές ερωτήσεις**

**Μπορώ να χρησιμοποιήσω το ίδιο σύμβολο κράτησης θέσης πολλές φορές σε ένα πρότυπο;**

Ναι. Κάθε εμφάνιση ενός συμβόλου με το αντίστοιχο όνομα πεδίου αντικαθίσταται με την αντίστοιχη τιμή από το τρέχον σύνολο δεδομένων.

**Τα ονόματα πεδίων είναι ευαίσθητα σε πεζά-κεφαλαία;**

Όχι. Τα ονόματα των συμβόλων και των πεδίων δεδομένων δεν διακρίνουν πεζά-κεφαλαία. Για παράδειγμα, `{{title}}`, `{{Title}}` και `{{TITLE}}` αναφέρονται στο ίδιο πεδίο.

**Τι συμβαίνει αν λείπει ένα πεδίο από ένα σύνολο δεδομένων;**

Εάν το σύνολο δεδομένων δεν περιέχει ένα πεδίο που αναφέρεται σε ένα σύμβολο, το σύμβολο παραμένει αμετάβλητο στην παραγόμενη παρουσίαση.

**Τι συμβαίνει αν ένα πεδίο έχει κενή τιμή;**

Μία κενή τιμή πεδίου αντικαθιστά το σύμβολο με κενή συμβολοσειρά. Το κείμενο του συμβόλου αφαιρείται, αφήνοντας κανένα κείμενο στη θέση του.

**Μπορώ να διατηρήσω τη μορφοποίηση ενός συμβόλου όταν το αντικαθιστώ;**

Το κείμενο αντικατάστασης κληρονομεί τη μορφοποίηση του πρώτου χαρακτήρα του συμβόλου. Εφαρμόστε τη ζητούμενη μορφοποίηση στο κείμενο του συμβόλου στο πρότυπο πριν εκτελέσετε τη συγχώνευση.

**Η Συγχώνευση αλληλογραφίας αντικαθιστά σύμβολα στις κύριες διαφάνειες ή στις διαφάνειες διάταξης;**

Όχι. Η Συγχώνευση αλληλογραφίας αντικαθιστά σύμβολα μόνο στο υποστηριζόμενο περιεχόμενο των διαφανειών παρουσίασης, συμπεριλαμβανομένων των σχημάτων, των ομαδοποιημένων σχημάτων, των κελιών πινάκων και των σημειώσεων ομιλητή. Τα σύμβολα στις κύριες διαφάνειες και στις διαφάνειες διάταξης δεν αντικαθίστανται.

**Τροποποιείται η παρουσίαση προτύπου κατά τη διάρκεια της συγχώνευσης;**

Όχι. Η αρχική παρουσίαση προτύπου δεν τροποποιείται από τη λειτουργία συγχώνευσης. Μπορείτε να τη χρησιμοποιήσετε ξανά για τη δημιουργία παρουσιάσεων από τις ίδιες ή διαφορετικές πηγές δεδομένων.

**Μπορώ να δημιουργήσω ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων;**

Ναι. Χρησιμοποιήστε το `MergeToMultiplePresentations` και αποθηκεύστε κάθε παραγόμενη παρουσίαση μέσα στον επεξεργαστή. Ο επεξεργαστής καλείται διαδοχικά για κάθε σύνολο δεδομένων.

**Μπορώ να συνδυάσω όλα τα σύνολα δεδομένων σε μία παρουσίαση;**

Ναι. Χρησιμοποιήστε το `MergeToSinglePresentation`. Δημιουργεί μία έξοδο παρουσίαση που περιέχει ένα αντίγραφο των διαφανειών προτύπου για κάθε σύνολο δεδομένων, με τη σειρά της πηγής δεδομένων.

**Μπορώ να χρησιμοποιήσω πηγή δεδομένων χωρίς να την αποθηκεύσω σε αρχείο;**

Ναι. Μπορείτε να δημιουργήσετε ένα `MailMergeDataSource` στον κώδικα, να προσθέσετε σύνολα δεδομένων, και να γεμίσετε τα πεδία χρησιμοποιώντας το `AddText`. Αυτό είναι χρήσιμο όταν τα δεδομένα σας είναι ήδη διαθέσιμα στην εφαρμογή σας.

**Η Συγχώνευση αλληλογραφίας εντοπίζει τη μορφή των δεδομένων από την επέκταση του αρχείου;**

Όχι. Η μορφή των δεδομένων εντοπίζεται από το περιεχόμενο, επομένως μια υποστηριζόμενη πηγή δεδομένων δεν χρειάζεται να χρησιμοποιεί συγκεκριμένη επέκταση αρχείου.

**Μπορώ να διαβάσω δεδομένα από ροή που δεν υποστηρίζει αναζήτηση;**

Ναι. Η Συγχώνευση αλληλογραφίας υποστηρίζει ροές που δεν υποστηρίζουν αναζήτηση.

**Τι συμβαίνει αν η πηγή δεδομένων είναι κενή ή δεν περιέχει σύνολα δεδομένων;**

Η πηγή δεδομένων πρέπει να περιέχει τουλάχιστον ένα σύνολο δεδομένων. Βεβαιωθείτε ότι περιλαμβάνει τουλάχιστον μία εγγραφή πριν ξεκινήσετε τη λειτουργία συγχώνευσης.

**Τι συμβαίνει αν η πηγή δεδομένων έχει μη έγκυρη μορφή;**

Εάν το περιεχόμενο δεν αναγνωρίζεται ως μία από τις υποστηριζόμενες μορφές δεδομένων, προκαλείται `NotSupportedException`. Εάν αναγνωρίζεται αλλά είναι κατεστραμμένο, προκαλείται `InvalidDataException`. Το μήνυμα της εξαίρεσης περιλαμβάνει πληροφορίες για τη θέση του σφάλματος.

**Μπορώ να χρησιμοποιήσω τη δημιουργημένη παρουσίαση μετά την επιστροφή του επεξεργαστή;**

Η παρουσίαση που περνάει στον επεξεργαστή `MergeToMultiplePresentations` ανήκει στη Συγχώνευση αλληλογραφίας και απορρίπτεται μετά την επιστροφή του επεξεργαστή. Αποθηκεύστε τη ή αντιγράψτε το περιεχόμενο που χρειάζεστε μέσα στον επεξεργαστή, και μην τη διατηρείτε ή την απορρίψετε εσείς.

**Καλείται ο επεξεργαστής παράλληλα;**

Όχι. Οι παραγόμενες παρουσιάσεις επεξεργάζονται διαδοχικά, στο νήμα του καλούντος. Μία μόνο παραγόμενη παρουσίαση διατηρείται στη μνήμη τη δεδομένη στιγμή από αυτή τη λειτουργία.

**Τι συμβαίνει αν προκύψει εξαίρεση μέσα στον επεξεργαστή;**

Η λειτουργία συγχώνευσης σταματά και η εξαίρεση προωθείται στον καλούντα αμετάβλητη. Οι παρουσιάσεις που έχουν ήδη υποβληθεί σε επεξεργασία δεν επηρεάζονται, και τα επόμενα σύνολα δεδομένων δεν επεξεργάζονται.

**Μπορώ να χρησιμοποιήσω τιμές πεδίων για τη δημιουργία ονομάτων αρχείων εξόδου;**

Ναι. Ο επεξεργαστής παρέχει το τρέχον σύνολο δεδομένων μέσω των επιχειρημάτων του. Χρησιμοποιήστε τη `GetText` για να ανακτήσετε τα πεδία και να δημιουργήσετε ένα όνομα αρχείου για κάθε παραγόμενη παρουσίαση. Βεβαιωθείτε ότι οι τιμές είναι έγκυρες για ονόματα αρχείων στο περιβάλλον σας.
