# Συγχώνευση αλληλογραφίας σε παρουσιάσεις PowerPoint

Aspose.Slides for .NET σάς επιτρέπει να δημιουργείτε αυτόματα παρουσιάσεις PowerPoint χρησιμοποιώντας ένα πρότυπο και μια πηγή δεδομένων. Το Mail Merge γεμίζει τα σύμβολα κράτησης θέσης του προτύπου με δεδομένα και δημιουργεί είτε μία ενιαία παρουσίαση που περιέχει επαναλαμβανόμενες διαφάνειες προτύπου για κάθε σύνολο δεδομένων, είτε ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων.

Αυτή η λειτουργία είναι χρήσιμη για τη δημιουργία καταλόγων προϊόντων, προσωποποιημένων παρουσιάσεων, αναφορών, πιστοποιητικών, προτάσεων, τιμοκαταλόγων και άλλων εγγράφων όπου η δομή της παρουσίασης παραμένει η ίδια ενώ το περιεχόμενο διαφέρει.

## Πώς λειτουργεί το Mail Merge

Το Mail Merge χρησιμοποιεί μια παρουσίαση PowerPoint ως πρότυπο και αντικαθιστά τα σύμβολα κράτησης θέσης με τιμές από μια πηγή δεδομένων.

![Mail Merge workflow](mail-merge-workflow.png)

Ένα σύμβολο κράτησης θέσης είναι ένα όνομα πεδίου περικλεισμένο σε διπλές άγκιστρους, όπως `{{title}}` ή `{{price}}`. Τα σύμβολα μπορούν να τοποθετηθούν σε κείμενο σε σχήματα, κελιά πινάκων, ομαδοποιημένα σχήματα και σημειώσεις ομιλητή.

Για παράδειγμα, μια διαφάνεια προτύπου μπορεί να περιέχει το ακόλουθο κείμενο:

- `Product: {{title}}`
- `Price: {{price}}`
- `Description: {{description}}`

Όταν η πηγή δεδομένων περιέχει τις ακόλουθες τιμές:

| Πεδίο | Τιμή |
|---|---|
| title | Laptop X1 |
| price | $999 |
| description | 14‑inch display, 16 GB RAM |

Το Mail Merge αντικαθιστά τα σύμβολα κράτησης θέσης με τις αντίστοιχες τιμές, παράγοντας μια διαφάνεια με τις πραγματικές πληροφορίες προϊόντος.

Τα ονόματα πεδίων δεν διακρίνουν πεζά‑κεφαλαία, έτσι `{{title}}` και `{{Title}}` αναφέρονται στο ίδιο πεδίο.

Οι παρακάτω κανόνες ισχύουν κατά την αντικατάσταση των συμβόλων:

- Τα σύμβολα αντικαθίστανται σε διαφάνειες, συμπεριλαμβανομένων των ομαδοποιημένων σχημάτων και των κελιών πινάκων, καθώς και στις σημειώσεις ομιλητή.
- Τα σύμβολα σε κύριες διαφάνειες (master) και διαφάνειες διάταξης (layout) δεν αντικαθίστανται.
- Ένα σύμβολο του οποίου το πεδίο δεν υπάρχει στο σύνολο δεδομένων παραμένει αμετάβλητο.
- Μια κενή τιμή πεδίου αντικαθιστά το σύμβολο με κενή συμβολοσειρά.
- Το εισαχθέν κείμενο κληρονομεί τη μορφοποίηση του πρώτου χαρακτήρα του συμβόλου.
- Οι τιμές δεν πρέπει να περιέχουν κείμενο συμβόλου, διότι το εισαχθέν κείμενο μπορεί να υποβληθεί ξανά σε επεξεργασία και να αντικατασταθεί από άλλο πεδίο.

Η αρχική παρουσίαση προτύπου δεν τροποποιείται κατά τη λειτουργία συγχώνευσης και πρέπει να περιέχει τουλάχιστον μία διαφάνεια.

## Υποστηριζόμενες πηγές δεδομένων

Το Mail Merge υποστηρίζει δύο τρόπους παροχής δεδομένων:

- Δημιουργία πηγής δεδομένων προγραμματιστικά χρησιμοποιώντας το `IMailMergeDataSource`.
- Ανάγνωση δεδομένων από αρχείο ή ροή CSV, XLSX, JSON ή XML.

Η μορφή των δεδομένων εντοπίζεται από το περιεχόμενό της, όχι από την επέκταση αρχείου. Υποστηρίζονται επίσης ροές που δεν υποστηρίζουν αναζήτηση.

Η πηγή δεδομένων πρέπει να περιέχει τουλάχιστον ένα σύνολο δεδομένων. Κάθε σύνολο δεδομένων αντιπροσωπεύει ένα αντίτυπο του προτύπου που θα γεμίσει με τις δικές του τιμές.

Αν το περιεχόμενο των δεδομένων δεν μπορεί να αναγνωριστεί ως υποστηριζόμενη μορφή, ρωτάται `NotSupportedException`. Αν το περιεχόμενο αναγνωριστεί αλλά δεν πληροί τις απαιτήσεις μορφής, ρωτάται `InvalidDataException`. Το μήνυμα της εξαίρεσης περιέχει τη θέση του σφάλματος στα δεδομένα.

### JSON

Η πηγή δεδομένων JSON πρέπει να έχει αντικείμενο ρίζας που περιέχει έναν πίνακα `sets`. Κάθε στοιχείο του πίνακα αντιπροσωπεύει ένα σύνολο δεδομένων και πρέπει να περιέχει έναν πίνακα `fields`. Κάθε πεδίο πρέπει να έχει συμβολοσειρές `name` και `value`.

Η προαιρετική ιδιότητα `version` πρέπει να είναι `"1.0"` και η προαιρετική ιδιότητα `type` ενός πεδίου πρέπει να είναι `"text"`. Τα ονόματα ιδιοτήτων διακρίνουν πεζά‑κεφαλαία. Άγνωστες ιδιότητες αγνοούνται.

Τα δεδομένα JSON διαβάζονται ως UTF-8, ή ως UTF-16 όταν το αρχείο ξεκινά με byte order mark (BOM).

Το παρακάτω παράδειγμα περιέχει δύο σύνολα δεδομένων:

```json
{
  "version": "1.0",
  "sets": [
    {
      "fields": [
        { "name": "title", "value": "Laptop X1" },
        { "name": "price", "value": "$999" }
      ]
    },
    {
      "fields": [
        { "name": "title", "value": "Tablet S2" },
        { "name": "price", "value": "$499" }
      ]
    }
  ]
}
```

### XML

Η πηγή δεδομένων XML πρέπει να έχει στοιχείο ρίζας `template` που περιέχει το στοιχείο `sets`. Κάθε στοιχείο `set` περιέχει στοιχεία `field`, και κάθε `field` πρέπει να περιέχει στοιχεία `name` και `value`.

Ένα κενό στοιχείο `value` θεωρείται κενή συμβολοσειρά. Τα ονόματα στοιχείων διακρίνουν πεζά‑κεφαλαία. Άγνωστα στοιχεία και σχόλια αγνοούνται. Η κωδικοποίηση καθορίζεται από τη δήλωση XML. Δεν επιτρέπονται ορισμοί τύπου (DTD).

```xml
<?xml version="1.0" encoding="utf-8"?>
<template>
  <sets>
    <set>
      <field>
        <name>title</name>
        <value>Laptop X1</value>
      </field>
      <field>
        <name>price</name>
        <value>$999</value>
      </field>
    </set>
    <set>
      <field>
        <name>title</name>
        <value>Tablet S2</value>
      </field>
      <field>
        <name>price</name>
        <value>$499</value>
      </field>
    </set>
  </sets>
</template>
```

### CSV

Τα δεδομένα CSV χρησιμοποιούν ερωτηματικά (;) ως διαχωριστές τιμών.

Η πρώτη γραμμή περιέχει ονόματα πεδίων και τελειώνει στο πρώτο κενό όνομα πεδίου. Κάθε επόμενη γραμμή αντιπροσωπεύει ένα σύνολο δεδομένων. Τα δεδομένα τελειώνουν στην πρώτη κενή γραμμή.

Οι παρακάτω κανόνες ισχύουν:

- Οι ελλιπείς τιμές στο τέλος μιας γραμμής θεωρούνται κενές συμβολοσειρές.
- Τιμές πέρα από τα καθορισμένα ονόματα πεδίων αγνοούνται.
- Μια τιμή που περιέχει ερωτηματικό, εισαγωγικά ή αλλαγή γραμμής πρέπει να περικλείεται σε εισαγωγικά.
- Τα εισαγωγικά μέσα σε τιμή που είναι ήδη σε εισαγωγικά πρέπει να διπλασιαστούν.
- Τα δεδομένα διαβάζονται ως UTF-8, ή ως UTF-16 όταν ξεκινούν με byte order mark (BOM).

Παράδειγμα:

```csv
title;price;description
Laptop X1;$999;"14"" display; 16 GB RAM"
Tablet S2;$499;
```

### XLSX

Τα δεδομένα XLSX διαβάζονται από το πρώτο φύλλο εργασίας.

Το φύλλο εργασίας ακολουθεί τους ίδιους κανόνες με το CSV:

- Η πρώτη γραμμή περιέχει ονόματα πεδίων και τελειώνει στο πρώτο κενό κελί.
- Κάθε επόμενη γραμμή αντιπροσωπεύει ένα σύνολο δεδομένων.
- Τα δεδομένα τελειώνουν στην πρώτη κενή γραμμή.
- Τα κενά κελιά θεωρούνται κενές συμβολοσειρές.
- Οι αριθμητικές τιμές μετατρέπονται σε κείμενο χρησιμοποιώντας την αμετάβλητη κουλτούρα.

## Δημιουργία μίας μόνο παρουσίασης

Η μέθοδος `MergeToSinglePresentation` δημιουργεί μία παρουσίαση που περιέχει ένα αντίτυπο των διαφανειών προτύπου για κάθε σύνολο δεδομένων. Κάθε αντίτυπο γεμίζεται με τα αντίστοιχα δεδομένα.

Η σειρά των συνόλων δεδομένων καθορίζει τη σειρά των ομάδων διαφανειών στην τελική παρουσίαση.

### Συγχώνευση δεδομένων από αρχείο

Το παρακάτω παράδειγμα φορτώνει ένα πρότυπο και ένα αρχείο δεδομένων JSON, δημιουργεί μία παρουσίαση που περιέχει τις διαφάνειες για όλα τα σύνολα δεδομένων και αποθηκεύει το αποτέλεσμα.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, "products.json"))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

Τα δεδομένα μπορούν επίσης να διαβαστούν από ροή. Η ροή διαβάζεται από την τρέχουσα θέση της και δεν κλείνει από τη λειτουργία Mail Merge.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xml"))
using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, data))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

### Δημιουργία πηγής δεδομένων στον κώδικα

Μπορείτε να δημιουργήσετε μια πηγή δεδομένων προγραμματιστικά χρησιμοποιώντας τα `MailMergeDataSource` και `MailMergeDataSet`. Προσθέστε ένα σύνολο δεδομένων για κάθε εγγραφή και ορίστε τα πεδία του χρησιμοποιώντας τη μέθοδο `AddText`.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet laptop = source.AddDataSet();
laptop.AddText("title", "Laptop X1");
laptop.AddText("price", "$999");

IMailMergeDataSet tablet = source.AddDataSet();
tablet.AddText("title", "Tablet S2");
tablet.AddText("price", "$499");

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, source))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

Σε αυτό το παράδειγμα, οι διαφάνειες προτύπου επαναλαμβάνονται δύο φορές: μία για το laptop και μία για το tablet. Τα σύμβολα γεμίζονται με τις τιμές που ορίστηκαν σε κάθε σύνολο δεδομένων.

## Δημιουργία πολλαπλών παρουσιάσεων

Αν χρειάζεστε ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων, χρησιμοποιήστε τη μέθοδο `MergeToMultiplePresentations`.

Αυτή η μέθοδος επεξεργάζεται τα σύνολα δεδομένων ένα‑ένα, δημιουργεί μια παρουσίαση από το πρότυπο, τη γεμίζει με τα τρέχοντα δεδομένα και περνά την προκύπτουσα παρουσίαση σε έναν χειριστή.

Ο χειριστής καλείται μία φορά για κάθε σύνολο δεδομένων, με την αρχική σειρά των δεδομένων.

### Αποθήκευση κάθε παρουσίασης

Το παρακάτω παράδειγμα διαβάζει δεδομένα από αρχείο CSV και αποθηκεύει κάθε δημιουργημένη παρουσίαση ως ξεχωριστό αρχείο.

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.csv",
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

Η ιδιότητα `args.Index` παρέχει το μηδενικό δείκτη του τρέχοντος συνόλου δεδομένων. Στο παράδειγμα, χρησιμοποιείται για να δημιουργήσει διαδοχικά ονόματα αρχείων ξεκινώντας από `product_1.pptx`.

Τα δεδομένα μπορούν επίσης να διαβαστούν από ροή:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xlsx"))
using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        data,
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

### Χρήση τιμών συνόλου δεδομένων για ονομασία αρχείων

Ο χειριστής λαμβάνει τόσο την παραγόμενη παρουσίαση όσο και πληροφορίες για το σύνολο δεδομένων που χρησιμοποιήθηκε για τη δημιουργία της. Μπορείτε να χρησιμοποιήσετε τις τιμές του συνόλου δεδομένων για να δημιουργήσετε περιγραφικά ονόματα αρχείων.

Για παράδειγμα, ο κώδικας παρακάτω αποθηκεύει κάθε παρουσίαση χρησιμοποιώντας τον τίτλο του προϊόντος:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string title = args.DataSet.GetText("title");
            string fileName = title != null
                ? title
                : "product_" + (args.Index + 1);

            presentation.Save(fileName + ".pptx", SaveFormat.Pptx);
        });
}
```

Η ιδιότητα `DataSet` επιστρέφει το σύνολο δεδομένων που χρησιμοποιήθηκε για το γέμισμα της τρέχουσας παρουσίασης. Η μέθοδος `GetText` ανακτά την τιμή ενός συγκεκριμένου πεδίου ή `null` αν το πεδίο δεν υπάρχει.

Αυτό σας επιτρέπει να χρησιμοποιήσετε τιμές δεδομένων για ονομασία αρχείων, οργάνωση εξόδου ή επιπλέον επεξεργασία στον χειριστή.

## Διαχείριση των παραγόμενων παρουσιάσεων

Η `MergeToMultiplePresentations` χρησιμοποιεί τον εκτελεστή `MailMergedPresentationHandler` για την επεξεργασία κάθε παραγόμενης παρουσίασης.

Ο εκτελεστής λαμβάνει δύο παραμέτρους:

- `presentation` — η παρουσίαση που δημιουργήθηκε από το πρότυπο και γεμίστηκε με το τρέχον σύνολο δεδομένων.
- `args` — πληροφορίες για την παραγόμενη παρουσίαση, συμπεριλαμβανομένου του δείκτη του συνόλου δεδομένων και του ίδιου του συνόλου.

Η παραγόμενη παρουσίαση είναι ιδιοκτησία της λειτουργίας Mail Merge και διαγράφεται αμέσως μετά την επιστροφή του εκτελεστή. Συνεπώς, πρέπει να την αποθηκεύσετε ή να αντιγράψετε τυχόν απαιτούμενα δεδομένα μέσα στον εκτελεστή. Μην διατηρείτε αναφορά σε αυτήν μετά την επιστροφή του εκτελεστή ούτε τη διαγράψετε χειροκίνητα.

Ο εκτελεστής εκτελείται στο νήμα που κάλεσε τη μέθοδο, μία παρουσίαση τη φορά, με τη σειρά των συνόλων δεδομένων. Μία μόνο παραγόμενη παρουσίαση διατηρείται στη μνήμη τη φορά, καθιστώντας αυτήν την προσέγγιση κατάλληλη για επεξεργασία μεγάλων πηγών δεδομένων χωρίς να απαιτείται η ταυτόχρονη αποθήκευση όλων των παραγόμενων παρουσιάσεων.

Αν ο εκτελεστής ρίξει εξαίρεση, η λειτουργία Mail Merge σταματά και η εξαίρεση διαβιβάζεται στον καλούντα χωρίς αλλαγές. Οι παρουσιάσεις που έχουν ήδη υποστεί επεξεργασία παραμένουν αμετάβλητες, ενώ τα υπόλοιπα σύνολα δεδομένων δεν επεξεργάζονται.

Το παρακάτω παράδειγμα αποθηκεύει τις παραγόμενες παρουσιάσεις σε έναν αφιερωμένο φάκελο:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

string outputFolder = "output";
Directory.CreateDirectory(outputFolder);

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string path = Path.Combine(
                outputFolder,
                "product_" + (args.Index + 1) + ".pptx");

            presentation.Save(path, SaveFormat.Pptx);
        });
}
```

## Εργασία με δεδομένα Mail Merge

Η κλάση `MailMergeDataSource` αντιπροσωπεύει μια διατεταγμένη συλλογή συνόλων δεδομένων. Μπορεί να χρησιμοποιηθεί για τη δημιουργία δεδομένων στον κώδικα, την επισκόπηση του αριθμού των συνόλων και την πρόσβαση σε μεμονωμένα σύνολα μέσω δείκτη.

### Λήψη του αριθμού των συνόλων δεδομένων

Η ιδιότητα `Count` επιστρέφει τον αριθμό των συνόλων δεδομένων στην πηγή.

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine("Presentations to create: " + source.Count);
```

### Πρόσβαση σε σύνολο δεδομένων μέσω δεικτοδότησης

Η ιδιότητα `Item(int)` παρέχει πρόσβαση σε ένα σύνολο δεδομένων στο συγκεκριμένο μηδενικό δείκτη.

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine(source[1].GetText("title"));
```

Αυτό το παράδειγμα ανακτά τον τίτλο του δεύτερου συνόλου δεδομένων.

### Προσθήκη πεδίων κειμένου

Η μέθοδος `AddText` προσθέτει ένα πεδίο κειμένου με όνομα σε ένα σύνολο δεδομένων. Η τιμή του πεδίου αντικαθιστά όλα τα αντίστοιχα σύμβολα στο πρότυπο.

```csharp
MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet dataSet = source.AddDataSet();
dataSet.AddText("title", "Laptop X1");
dataSet.AddText("subtitle", string.Empty);
```

Μια κενή τιμή αφαιρεί το αντίστοιχο σύμβολο από το τελικό κείμενο. Αν το πεδίο δεν προστεθεί στο σύνολο δεδομένων, το σύμβολο παραμένει αμετάβλητο.

### Ανάγνωση πεδίων κειμένου

Η μέθοδος `GetText` ανακτά την τιμή ενός πεδίου με βάση το όνομα. Τα ονόματα πεδίων δεν διακρίνουν πεζά‑κεφαλαία.

```csharp
IMailMergeDataSet dataSet = source[0];

string title = dataSet.GetText("title");
string price = dataSet.GetText("price");
```

Αν το πεδίο δεν υπάρχει ή το όνομα πεδίου είναι `null`, η `GetText` επιστρέφει `null`.

## Σύνοψη

Το Mail Merge στο Aspose.Slides for .NET παρέχει έναν βολικό τρόπο για τη δημιουργία παρουσιάσεων βασισμένων σε δεδομένα από ένα επαναχρησιμοποιήσιμο πρότυπο.

Μπορείτε να το χρησιμοποιήσετε για:

- Να γεμίσετε πρότυπα παρουσίασης με τιμές από πηγές δεδομένων.
- Να δημιουργήσετε μία παρουσίαση που περιέχει επαναλαμβανόμενες διαφάνειες προτύπου για πολλαπλά σύνολα δεδομένων.
- Να δημιουργήσετε ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων.
- Να διαβάζετε δεδομένα από αρχεία ή ροές CSV, XLSX, JSON και XML.
- Να δημιουργείτε πηγές δεδομένων άμεσα στον κώδικα.
- Να επεξεργάζεστε και να αποθηκεύετε τις παραγόμενες παρουσιάσεις διαδοχικά με έναν χειριστή.

Συνδυάζοντας επαναχρησιμοποιήσιμα πρότυπα με δομημένα δεδομένα, μπορείτε να αυτοματοποιήσετε τη δημιουργία μεγάλου αριθμού παρουσιάσεων, διατηρώντας ξεχωριστά το σχεδιασμό του προτύπου και τη λογική επεξεργασίας δεδομένων.

## Συχνές ερωτήσεις

### Μπορώ να χρησιμοποιήσω το ίδιο σύμβολο κράτησης θέσης πολλές φορές σε ένα πρότυπο;

Ναι. Κάθε εμφάνιση ενός συμβόλου με το ίδιο όνομα πεδίου αντικαθίσταται με την αντίστοιχη τιμή του τρέχοντος συνόλου δεδομένων.

### Διακρίνονται τα ονόματα πεδίων;

Όχι. Τα ονόματα συμβόλων και πεδίων δεν διακρίνουν πεζά‑κεφαλαία. Για παράδειγμα, `{{title}}`, `{{Title}}` και `{{TITLE}}` αναφέρονται στο ίδιο πεδίο.

### Τι συμβαίνει αν λείπει ένα πεδίο από ένα σύνολο δεδομένων;

Αν το σύνολο δεδομένων δεν περιέχει ένα πεδίο που αναφέρεται σε σύμβολο, το σύμβολο παραμένει αμετάβλητο στην παραγόμενη παρουσίαση.

### Τι συμβαίνει αν ένα πεδίο έχει κενή τιμή;

Μια κενή τιμή πεδίου αντικαθιστά το σύμβολο με κενή συμβολοσειρά. Το κείμενο του συμβόλου αφαιρείται, χωρίς υπόλοιπο κείμενο στη θέση του.

### Μπορώ να διατηρήσω τη μορφοποίηση ενός συμβόλου όταν το αντικαθιστώ;

Το κείμενο αντικατάστασης κληρονομεί τη μορφοποίηση του πρώτου χαρακτήρα του συμβόλου. Εφαρμόστε την επιθυμητή μορφοποίηση στο κείμενο του συμβόλου στο πρότυπο πριν την εκκίνηση της συγχώνευσης.

### Αντικαθιστά το Mail Merge σύμβολα σε κύριες ή διαφάνειες διάταξης;

Όχι. Το Mail Merge αντικαθιστά σύμβολα μόνο στο περιεχόμενο των διαφανειών παρουσίασης, συμπεριλαμβανομένων σχημάτων, ομαδοποιημένων σχημάτων, κελιών πινάκων και σημειώσεων ομιλητή. Τα σύμβολα σε κύριες (master) και διαφάνειες διάταξης (layout) δεν αντικαθίστανται.

### Τροποποιείται η παρουσίαση προτύπου κατά τη συγχώνευση;

Όχι. Το αρχικό πρότυπο δεν τροποποιείται από τη λειτουργία συγχώνευσης. Μπορείτε να το επαναχρησιμοποιήσετε για δημιουργία παρουσιάσεων από την ίδια ή διαφορετικές πηγές δεδομένων.

### Μπορώ να δημιουργήσω ξεχωριστή παρουσίαση για κάθε σύνολο δεδομένων;

Ναι. Χρησιμοποιήστε το `MergeToMultiplePresentations` και αποθηκεύστε κάθε παραγόμενη παρουσίαση μέσα στον χειριστή. Ο χειριστής καλείται διαδοχικά για κάθε σύνολο δεδομένων.

### Μπορώ να συνδυάσω όλα τα σύνολα δεδομένων σε μία παρουσίαση;

Ναι. Χρησιμοποιήστε το `MergeToSinglePresentation`. Δημιουργεί μία ενιαία παρουσίαση που περιέχει αντίτυπα των διαφανειών προτύπου για κάθε σύνολο δεδομένων, με τη σειρά της πηγής δεδομένων.

### Μπορώ να χρησιμοποιήσω πηγή δεδομένων χωρίς να την αποθηκεύσω σε αρχείο;

Ναι. Μπορείτε να δημιουργήσετε ένα `MailMergeDataSource` στον κώδικα, να προσθέσετε σύνολα δεδομένων και να γεμίσετε τα πεδία με `AddText`. Αυτό είναι χρήσιμο όταν τα δεδομένα είναι ήδη διαθέσιμα στην εφαρμογή σας.

### Ανιχνεύει το Mail Merge τη μορφή δεδομένων από την επέκταση αρχείου;

Όχι. Η μορφή των δεδομένων ανιχνεύεται από το περιεχόμενο, οπότε μια υποστηριζόμενη πηγή δεδομένων δεν απαιτεί συγκεκριμένη επέκταση αρχείου.

### Μπορώ να διαβάσω δεδομένα από ροή που δεν υποστηρίζει αναζήτηση;

Ναι. Το Mail Merge υποστηρίζει ροές χωρίς δυνατότητα αναζήτησης.

### Τι συμβαίνει αν η πηγή δεδομένων είναι άδεια ή δεν περιέχει σύνολα δεδομένων;

Η πηγή δεδομένων πρέπει να περιέχει τουλάχιστον ένα σύνολο δεδομένων. Βεβαιωθείτε ότι περιλαμβάνει τουλάχιστον μία εγγραφή πριν ξεκινήσετε τη λειτουργία συγχώνευσης.

### Τι συμβαίνει αν η πηγή δεδομένων έχει μη έγκυρη μορφή;

Αν το περιεχόμενο δεν αναγνωριστεί ως μία από τις υποστηριζόμενες μορφές, ρωτάται `NotSupportedException`. Αν αναγνωριστεί αλλά είναι ακατάλληλο, ρωτάται `InvalidDataException`. Το μήνυμα της εξαίρεσης περιλαμβάνει πληροφορίες για τη θέση του σφάλματος.

### Μπορώ να χρησιμοποιήσω την παραγόμενη παρουσίαση μετά την επιστροφή του χειριστή;

Η παρουσίαση που περνάται στον χειριστή του `MergeToMultiplePresentations` ανήκει στο Mail Merge και διαγράφεται μετά την επιστροφή του χειριστή. Αποθηκεύστε την ή αντιγράψτε τα απαραίτητα δεδομένα μέσα στον χειριστή και μην τη διατηρείτε ή διαγράψετε εσείς.

### Καλείται ο χειριστής σε παράλληλη εκτέλεση;

Όχι. Οι παραγόμενες παρουσιάσεις επεξεργάζονται διαδοχικά, στο νήμα του καλούντος. Μία μόνο παρουσίαση διατηρείται στη μνήμη τη φορά με αυτήν τη λειτουργία.

### Τι συμβαίνει αν προκύψει εξαίρεση μέσα στον χειριστή;

Η λειτουργία συγχώνευσης σταματά και η εξαίρεση διαβιβάζεται στον καλούντα χωρίς αλλαγές. Οι παρουσιάσεις που έχουν ήδη υποστεί επεξεργασία δεν επηρεάζονται, ενώ τα υπόλοιπα σύνολα δεδομένων δεν επεξεργάζονται.

### Μπορώ να χρησιμοποιήσω τις τιμές πεδίων για δημιουργία ονομάτων αρχείων;

Ναι. Ο χειριστής παρέχει το τρέχον σύνολο δεδομένων μέσω των ορισμάτων του. Χρησιμοποιήστε τη `GetText` για να ανακτήσετε τα πεδία και να δημιουργήσετε ένα όνομα αρχείου για κάθε παραγόμενη παρουσίαση. Φροντίστε οι τιμές να είναι έγκυρες για ονόματα αρχείων στο περιβάλλον στόχο.
