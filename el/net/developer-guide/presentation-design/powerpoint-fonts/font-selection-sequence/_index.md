## **Επισκόπηση**

Όταν φορτώνεται, αποδίδεται ή μετατρέπεται μια παρουσίαση σε άλλη μορφή, το Aspose.Slides ελέγχει εάν οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν λείπει μια απαιτούμενη γραμματοσειρά, το Aspose.Slides επιλέγει μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποιούσε το PowerPoint.

Aspose.Slides πρώτα αναζητά τη επιλεγμένη γραμματοσειρά στο λειτουργικό σύστημα. Εάν η γραμματοσειρά βρεθεί, χρησιμοποιείται. Εάν δεν βρεθεί, εφαρμόζεται μια κατάλληλη εναλλακτική. Όταν ορίζονται κανόνες αντικατάστασης γραμματοσειρών μέσω `FontSubstRule`, αυτά τακτικές λαμβάνονται επίσης υπόψη.

Μπορείτε επίσης να προσθέσετε γραμματοσειρές κατά την εκτέλεση της εφαρμογής, να χρησιμοποιήσετε ενσωματωμένες γραμματοσειρές από μια παρουσίαση ή να φορτώσετε εξωτερικές γραμματοσειρές για έγγραφα εξόδου όπως αρχεία PDF.

## **Επιλογή Γραμματοσειράς**

Ορισμένοι κανόνες ισχύουν για τις γραμματοσειρές σε μια παρουσίαση όταν αυτή φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή. Για παράδειγμα, όταν προσπαθείτε να μετατρέψετε μια παρουσίαση (τις διαφάνειές της) σε εικόνες, οι γραμματοσειρές της παρουσίασης ελέγχονται για να επαληθευτεί ότι οι επιλεγμένες γραμματοσειρές είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν οι γραμματοσειρές επιβεβαιωθούν ότι λείπουν, αντικαθίστανται — δείτε **Font Replacement** και **Font Substitution**.

Αυτή είναι η διαδικασία που ακολουθεί το Aspose.Slides όταν διαχειρίζεται γραμματοσειρές:

1. Το Aspose.Slides αναζητά τις γραμματοσειρές στο λειτουργικό σύστημα για να βρει τη γραμματοσειρά που ταιριάζει με την επιλεγμένη γραμματοσειρά της παρουσίασης. 
2. Εάν η επιλεγμένη γραμματοσειρά βρεθεί, το Aspose.Slides τη χρησιμοποιεί. Διαφορετικά, το Aspose.Slides χρησιμοποιεί μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποιούσε το PowerPoint.
3. Εάν έχουν οριστεί κανόνες αντικατάστασης γραμματοσειράς μέσω FontSubstRule, εφαρμόζονται. 

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές κατά την εκτέλεση της εφαρμογής και στη συνέχεια να τις χρησιμοποιήσετε. Δείτε **Custom fonts**. 

Όταν επιπλέον γραμματοσειρές τοποθετούνται μέσα σε μια παρουσίαση, ονομάζονται **Embedded fonts**.

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές που εφαρμόζονται *μόνο* σε έγγραφα εξόδου. Για παράδειγμα, εάν μια παρουσίαση που θέλετε να μετατρέψετε σε PDF περιέχει γραμματοσειρές που λείπουν από το σύστημά σας και ενσωματωμένες γραμματοσειρές, μπορείτε να προσθέσετε ή να φορτώσετε τις απαραίτητες γραμματοσειρές ως **external fonts**. 

{{% alert title="Note" color="info" %}} 
Δεν διανέμουμε καμία γραμματοσειρά, είτε επί πληρωμή είτε δωρεάν. Το API μας σας επιτρέπει να φορτώνετε εξωτερικές γραμματοσειρές και να τις ενσωματώνετε σε έγγραφα, αλλά το κάνετε με τις γραμματοσειρές με τη δική σας διακριτική ευχέρεια και ευθύνη.
{{% /alert %}}

## **Συχνές Ερωτήσεις**

### Πώς μπορώ να προσδιορίσω ποιες γραμματοσειρές χρησιμοποιούνται στην πραγματικότητα σε μια παρουσίαση πριν από τη μετατροπή;

Το Aspose.Slides σας επιτρέπει να ελέγξετε τις χρησιμοποιούμενες γραμματοσειρές μέσω του [διαχειριστή γραμματοσειρών](https://reference.aspose.com/slides/el/net/aspose.slides/presentation/fontsmanager/), ώστε να μπορείτε να αποφασίσετε αν θα κάνετε [ενσωμάτωση](/slides/el/net/embedded-font/), [αντικατάσταση](/slides/el/net/font-replacement/) ή να προσθέσετε [εξωτερικές πηγές](/slides/el/net/custom-font/). Αυτό σας βοηθά να αποτρέψετε ανεπιθύμητες αντικαταστάσεις κατά την απόδοση και εξαγωγή.

### Μπορώ να προσθέσω επιπλέον καταλόγους γραμματοσειρών χωρίς να τους εγκαταστήσω στο λειτουργικό σύστημα;

Ναι. Μπορείτε να καταχωρίσετε εξωτερικές πηγές γραμματοσειρών, όπως φακέλους ή ροές στη μνήμη, για απόδοση και εξαγωγή. Αυτό αφαιρεί την εξάρτηση από τις γραμματοσειρές του κεντρικού συστήματος και διατηρεί τη διάταξη προβλέψιμη.

### Πώς μπορώ να αποτρέψω μια σιωπηρή εναλλαγή σε ακατάλληλη γραμματοσειρά όταν λείπει ένα γλύφη;

Ορίστε ρητές κανόνες αντικατάστασης γραμματοσειράς και κανόνες fallBack εκ των προτέρων. Αναλύοντας τις χρησιμοποιούμενες γραμματοσειρές και θέτοντας ελεγχόμενη προτεραιότητα για τις εναλλακτικές, διασφαλίζετε συνεπή τυπογραφία και αποφεύγετε ανεπιθύμητα αποτελέσματα.
