SVG—ένα ακρωνύμιο για Scalable Vector Graphics—είναι ένας τυπικός τύπος ή μορφή γραφικών που χρησιμοποιείται για την απόδοση δισδιάστατων εικόνων. Το SVG αποθηκεύει τις εικόνες ως διανύσματα σε XML με λεπτομέρειες που ορίζουν τη συμπεριφορά ή την εμφάνισή τους. 

Το SVG είναι ένα από τους λίγους τύπους εικόνων που πληρούν πολύ υψηλά πρότυπα σε αυτούς τους όρους: κλιμάκωση, διαδραστικότητα, απόδοση, προσβασιμότητα, προγραμματισιμότητα και άλλα. Για αυτούς τους λόγους, χρησιμοποιείται συνήθως στην ανάπτυξη ιστού. 

Μπορεί να θέλετε να χρησιμοποιήσετε αρχεία SVG σε αυτές τις περιπτώσεις:

- όταν σχεδιάζετε να εκτυπώσετε την παρουσίασή σας σε πολύ μεγάλο φορμάτ. Οι εικόνες SVG μπορούν να κλιμακωθούν σε οποιαδήποτε ανάλυση ή επίπεδο. Μπορείτε να αλλάξετε το μέγεθος των εικόνων SVG όσες φορές χρειαστεί χωρίς όμως να μειωθεί η ποιότητά τους.
- όταν προτίθεστε να χρησιμοποιήσετε διαγράμματα και γραφήματα από τις διαφάνειές σας σε διαφορετικά μέσα ή πλατφόρμες. Οι περισσότεροι αναγνώστες μπορούν να ερμηνεύσουν αρχεία SVG. 
- όταν χρειάζεται να χρησιμοποιήσετε τα μικρότερα δυνατότερα μεγέθη εικόνων. Τα αρχεία SVG είναι γενικά μικρότερα από τα αντίστοιχα υψηλής ανάλυσης σε άλλες μορφές, ειδικά εκείνες που βασίζονται σε bitmap (JPEG ή PNG).

Aspose.Slides for .NET σας επιτρέπει να εξάγετε τις διαφάνειες στις παρουσιάσεις σας ως εικόνες **SVG**. Για να δημιουργήσετε μια εικόνα SVG από οποιαδήποτε, κάντε τα εξής:

- Δημιουργήστε ένα αντικείμενο της κλάσης Presentation. 
- Διασχίστε όλες τις διαφάνειες στην παρουσίαση. 
- Γράψτε κάθε διαφάνεια σε το δικό της αρχείο SVG μέσω FileStream.

{{% alert color="info" %}} 

Μπορεί να θέλετε να δοκιμάσετε τη [δωρεάν διαδικτυακή εφαρμογή](https://products.aspose.app/slides/el/conversion/ppt-to-svg) στην οποία υλοποιήσαμε τη λειτουργία μετατροπής PPT σε SVG από το Aspose.Slides for .NET.

{{% /alert %}} 

Αυτό το δείγμα κώδικα σε C# σας δείχνει πώς να μετατρέψετε PPT σε SVG χρησιμοποιώντας το Aspose.Slides:

``` csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("pres.pptx"))
{
    for (var index = 0; index < pres.Slides.Count; index++)
    {
        ISlide slide = pres.Slides[index];

        using (FileStream fileStream = new FileStream($"slide-{index}.svg", FileMode.Create, FileAccess.Write))
        {
            slide.WriteAsSvg(fileStream);   
        }
    }
}
```
