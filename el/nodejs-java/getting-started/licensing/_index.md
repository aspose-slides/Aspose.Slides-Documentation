## **Αξιολογήστε το Aspose.Slides**
Μπορείτε εύκολα να κατεβάσετε το Aspose.Slides για αξιολόγηση. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο. Η έκδοση αξιολόγησης απλώς αδειοδοτείται αφού προσθέσετε μερικές γραμμές κώδικα για την εφαρμογή της άδειας.

## **Περιορισμός Έκδοσης Αξιολόγησης**
Η έκδοση αξιολόγησης του Aspose.Slides (χωρίς καθορισμένη άδεια) παρέχει τη πλήρη λειτουργικότητα του προϊόντος, με δύο περιορισμούς:

* Προσθέτει ένα πλαίσιο κειμένου σήματος αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει.
* Κείμενο μεγαλύτερο από πέντε χαρακτήρες που διαβάζει ο κώδικάς σας από μια παρουσίαση κόβεται στους πρώτους πέντε χαρακτήρες, ακολουθούμενο από `... text has been truncated due to evaluation version limitation.` Κείμενο πέντε χαρακτήρων ή λιγότερο επιστρέφεται αμετάβλητο, και το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρως.

## **Σχετικά με την Άδεια**
Μπορείτε εύκολα να κατεβάσετε μια έκδοση αξιολόγησης του Aspose.Slides για Node.js μέσω Java από τη [σελίδα λήψης](https://releases.aspose.com/slides/nodejs-java/). Η έκδοση αξιολόγησης έχει τις ίδιες δυνατότητες με την αδειοδοτημένη έκδοση, με τους περιορισμούς που περιγράφηκαν παραπάνω. Επιπλέον, η έκδοση αξιολόγησης απλώς αδειοδοτείται αφού αγοράσετε μια άδεια και προσθέσετε μερικές γραμμές κώδικα για την εφαρμογή της άδειας.

Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα προϊόντος, αριθμό προγραμματιστών που αδειοδοείται, ημερομηνία λήξης συνδρομής κ.λπ. Το αρχείο είναι ψηφιακά υπογεγραμμένο, οπότε μην το τροποποιήσετε. Ακόμα και η αθέλητη προσθήκη μιας επιπλέον αλλαγής γραμμής στο περιεχόμενο του αρχείου θα το ακυρώσει.

Για να αποφύγετε τους περιορισμούς που σχετίζονται με την έκδοση αξιολόγησης, πρέπει να ορίσετε μια άδεια πριν χρησιμοποιήσετε το **Aspose.Slides**. Απαιτείται να ορίσετε την άδεια μόνο μία φορά ανά εφαρμογή ή διαδικασία.

### **Ρύθμιση Άδειας στο Aspose.Slides για Node.js μέσω Java**

Οι άδειες μπορούν να εφαρμοστούν από τις ακόλουθες θέσεις:

* Σαφής διαδρομή
* Ροή
* Ως Metered License – ένας νέος μηχανισμός αδειοδότησης

{{% alert color="info" title="Note" %}}
Χρησιμοποιήστε τη μέθοδο **setLicense** για να αδειοδοτήσετε ένα στοιχείο.

Ενώ πολλαπλές κλήσεις στη **setLicense** δεν είναι επιβλαβείς, είναι σπατάλη πόρων (επεξεργαστή).
{{% /alert %}}

#### **Εφαρμογή Άδειας με Χρήση Αρχείου**

Αυτό το απόσπασμα κώδικα χρησιμοποιείται για τον ορισμό ενός αρχείου άδειας:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");

const license = new asposeSlides.License();
license.setLicense("Aspose.Slides.lic");
console.log("The license was applied.");

// Aspose.Slides εκτελείται σε εικονική μηχανή Java που κρατά το Node.js ενεργό, οπότε τερματίστε τη διαδικασία ρητά.
process.exit(0);
```

Κατά την κλήση της μεθόδου setLicense, το όνομα της άδειας πρέπει να είναι το ίδιο με το όνομα του αρχείου άδειας. Για παράδειγμα, μπορείτε να αλλάξετε το όνομα του αρχείου άδειας σε "Aspose.Slides.lic.xml". Στη συνέχεια, στον κώδικά σας, πρέπει να περάσετε το νέο όνομα άδειας (Aspose.Slides.lic.xml) στη μέθοδο setLicense. Εάν το αρχείο λείπει ή δεν περιέχει έγκυρη άδεια, το [setLicense](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) προκαλεί εξαίρεση, η οποία τερματίζει το σκριπτ με σφάλμα.

#### **Εφαρμογή Άδειας από Ροή**

Για να εφαρμόσετε μια άδεια από ροή, περάστε το αντικείμενο [License](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/) και μια ροή ανάγνωσης στη στατική μέθοδο [setLicenseFromStream](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/). Η ροή διαβάζεται ασύγχρονα, και η κλήση επιστροφής λαμβάνει σφάλμα εάν η ροή δεν περιέχει έγκυρη άδεια:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");
const fs = require("fs");

const license = new asposeSlides.License();
const readStream = fs.createReadStream("Aspose.Slides.lic");
asposeSlides.License.setLicenseFromStream(license, readStream, function (error) {
    if (error) {
        console.error("The license was not applied:", error.message);
    } else {
        console.log("The license was applied.");
    }

    // Aspose.Slides εκτελείται σε εικονική μηχανή Java που κρατά το Node.js ενεργό, οπότε τερματίστε τη διαδικασία ρητά.
    process.exit(0);
});
```

Η άδεια εφαρμόζεται όταν έχει διαβαστεί ολόκληρη η ροή, ακριβώς πριν εκτελεστεί η κλήση επιστροφής, οπότε ξεκινήστε άλλες εργασίες του Aspose.Slides από την κλήση επιστροφής.

Και τα δύο παραδείγματα καλούν `process.exit(0)` όταν ολοκληρωθούν, επειδή η εικονική μηχανή Java που τρέχει το Aspose.Slides διατηρεί το Node.js ενεργό. Σε μια εφαρμογή, συνεχίστε με τον κώδικά σας του Aspose.Slides αντί να τερματίσετε τη διαδικασία.
