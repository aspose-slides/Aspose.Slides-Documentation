## **Επισκόπηση**

Το Aspose.Slides μπορεί να χρησιμοποιηθεί σε κατάσταση αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την αδειοδοτημένη έκδοση, αλλά προσθέτει υδατογράφημα αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει και περικόπτει το κείμενο που διαβάζει ο κώδικάς σας από παρουσιάσεις.

## **Αξιολόγηση Aspose.Slides**

Μπορείτε να κατεβάσετε μια έκδοση αξιολόγησης του **Aspose.Slides for Python via .NET** από τη [σελίδα λήψης](https://pypi.org/project/Aspose.Slides/). Η έκδοση αξιολόγησης παρέχει τις ίδιες δυνατότητες με το αδειοδοτημένο προϊόν. Το πακέτο αξιολόγησης είναι πανομοιότυπο με το αγορασμένο πακέτο και γίνεται αδειοδοτημένο αφού προσθέσετε μερικές γραμμές κώδικα για την εφαρμογή της άδειας.

Όταν είστε ικανοποιημένοι με την αξιολόγησή σας του **Aspose.Slides**, μπορείτε να [αγοράσετε άδεια](https://purchase.aspose.com/pricing/slides/python-net/). Συνιστούμε να εξετάσετε τις διαθέσιμες επιλογές συνδρομής. Αν έχετε ερωτήσεις, επικοινωνήστε με την ομάδα πωλήσεων της Aspose.

Κάθε άδεια Aspose περιλαμβάνει ετήσια συνδρομή με δωρεάν αναβαθμίσεις σε νέες εκδόσεις και διορθώσεις που κυκλοφορούν κατά την περίοδο αυτή. Τanto οι χρήστες αδειοδοτημένοι όσο και οι χρήστες αξιολόγησης λαμβάνουν δωρεάν, απεριόριστη τεχνική υποστήριξη.

**Περιορισμοί της Έκδοσης Αξιολόγησης**

* Η έκδοση αξιολόγησης (όταν δεν έχει εφαρμοστεί άδεια) παρέχει πλήρη λειτουργικότητα, αλλά προσθέτει ένα πλαίσιο κειμένου υδατογραφήματος αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει.
* Το κείμενο που διαβάζει ο κώδικάς σας από μια παρουσίαση περικόπτεται στα πρώτα του γράμματα, ακολουθούμενο από σημείωση σχετικά με τον περιορισμό της αξιολόγησης. Το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρως.

## **Αδειοδότηση στο Aspose.Slides**

* Μια έκδοση αξιολόγησης γίνεται αδειοδοτημένη μετά την αγορά άδειας και την προσθήκη μερικών γραμμών κώδικα για την εφαρμογή της.
* Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα του προϊόντος, ο αριθμός των προγραμματιστών που καλύπτει, η ημερομηνία λήξης της συνδρομής, κ.λπ.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, επομένως δεν πρέπει να το τροποποιήσετε. Ακόμη και η προσθήκη ενός μόνο διαλείμματος θα το ακυρώσει.
* Το Aspose.Slides for Python via .NET αναζητά την άδεια στη διαδρομή που του παρέχετε. Μια σχετική διαδρομή ή ένα όνομα αρχείου χωρίς διαδρομή επιλύεται σε σχέση με τον τρέχοντα κατάλογο εργασίας, ο οποίος δεν είναι απαραίτητα ο φάκελος που περιέχει το script Python.
* Για να αποφύγετε τους περιορισμούς αξιολόγησης, ορίστε την άδεια πριν χρησιμοποιήσετε το Aspose.Slides. Χρειάζεται να το κάνετε μόνο μία φορά ανά εφαρμογή ή διεργασία.

## **Εφαρμογή Άδειας**

Μια άδεια μπορεί να φορτωθεί από **αρχείο** ή **ροή**.

{{% alert color="info" title="Σημείωση" %}}
Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/python-net/aspose.slides/license/) για τη διαχείριση αδειοδότησης.
{{% /alert %}}

{{% alert color="warning" title="Προειδοποίηση" %}}
Νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με την έκδοση 21.4 ή νεότερη. Παλαιότερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν θα αναγνωρίσουν αυτές τις άδειες.
{{% /alert %}}

### **Αρχείο**

Ο πιο απλός τρόπος για να ορίσετε μια άδεια είναι να περάσετε τη διαδρομή του αρχείου άδειας στη μέθοδο [set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/). Αν περάσετε μόνο το όνομα του αρχείου, όπως στο παρακάτω παράδειγμα, το Aspose.Slides αναζητά το αρχείο στον τρέχοντα κατάλογο εργασίας.

Ο ακόλουθος κώδικας Python δείχνει πώς να ορίσετε το αρχείο άδειας:

```py
import aspose.slides as slides

# Δημιουργεί ένα αντικείμενο της κλάσης License. 
license = slides.License()

# Ορίζει τη διαδρομή του αρχείου άδειας.
license.set_license("Aspose.Slides.lic")
```

{{% alert color="warning" title="Προειδοποίηση" %}}
Αν τοποθετήσετε το αρχείο άδειας σε διαφορετικό φάκελο, όταν καλέσετε τη μέθοδο [License.set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/#str), το όνομα αρχείου στο τέλος της ρητής διαδρομής πρέπει να ταιριάζει με το όνομα του αρχείου άδειάς σας.

Για παράδειγμα, μπορείτε να μετονομάσετε το αρχείο άδειας σε *Aspose.Slides.lic.xml*. Στη συνέχεια, στον κώδικά σας, περάστε την πλήρη διαδρομή προς αυτό το αρχείο (τελειώνοντας με Aspose.Slides.lic.xml) στη μέθοδο [License.set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/#str).
{{% /alert %}}

### **Ροή**

Μπορείτε να φορτώσετε μια άδεια από ροή. Το παρακάτω παράδειγμα Python δείχνει πώς να εφαρμόσετε μια άδεια από ροή:

```py
import aspose.slides as slides

# Δημιουργεί ένα αντικείμενο της κλάσης License.
license = slides.License()

# Ορίζει την άδεια από μια ροή.
with open("Aspose.Slides.lic", "rb") as stream:
    license.set_license(stream)
```

## **Επαλήθευση Άδειας**

Για να επιβεβαιώσετε ότι η άδεια έχει εφαρμοστεί σωστά, μπορείτε να την επαληθεύσετε. Ο ακόλουθος κώδικας Python δείχνει πώς να επαληθεύσετε μια άδεια:

```py
import aspose.slides as slides

license = slides.License()

license.set_license("Aspose.Slides.lic")

if license.is_licensed():
    print("License is good!")
```

Εάν πρέπει να την καλέσετε ταυτόχρονα από πολλαπλά νήματα, χρησιμοποιήστε ένα primitive συγχρονισμού, όπως `threading.Lock`, για να αποφύγετε προβλήματα.
{{% /alert %}}
