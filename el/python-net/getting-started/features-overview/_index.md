## **Υποστηριζόμενες Πλατφόρμες**
Οι πλατφόρμες Aspose.Slides for Python via .NET μπορούν να χρησιμοποιηθούν σε Windows x64 ή x86 και σε ευρύ φάσμα διανομών Linux με εγκατεστημένο Python 3.5 ή νεότερο. Υπάρχουν πρόσθετες απαιτήσεις για την πλατφόρμα Linux-στόχο:
- Βιβλιοθήκες χρόνου εκτέλεσης GCC-6 (ή νεότερες)
- Εξαρτήσεις του .NET Core Runtime. Η εγκατάσταση του .NET Core Runtime δεν απαιτείται
- Για Python 3.5‑3.7: Απαιτείται η έκδοση `pymalloc` του Python. Η επιλογή κατασκευής Python `--with-pymalloc` ενεργοποιείται εξ ορισμού. Συνήθως, η έκδοση `pymalloc` του Python χαρακτηρίζεται με το επίθεμα `m` στο όνομα αρχείου.
- `libpython` κοινόχρηστη βιβλιοθήκη Python. Η επιλογή κατασκευής Python `--enable-shared` απενεργοποιείται εξ ορισμού· ορισμένες διανομές Python δεν περιέχουν τη βιβλιοθήκη `libpython`. Για ορισμένες πλατφόρμες Linux, η βιβλιοθήκη `libpython` μπορεί να εγκατασταθεί μέσω του διαχειριστή πακέτων, π.χ.: `sudo apt-get install libpython3.7`. Το κοινό πρόβλημα είναι ότι η βιβλιοθήκη `libpython` εγκαθίσταται σε διαφορετική τοποθεσία από την τυπική θέση των κοινόχρηστων βιβλιοθηκών του συστήματος. Το πρόβλημα μπορεί να διορθωθεί χρησιμοποιώντας τις επιλογές κατασκευής του Python για να οριστούν εναλλακτικές διαδρομές βιβλιοθηκών κατά τη μεταγλώττιση του Python, ή δημιουργώντας συμβολικός σύνδεσμος προς το αρχείο βιβλιοθήκης `libpython` στη τυπική θέση των κοινόχρηστων βιβλιοθηκών. Συνήθως, το όνομα αρχείου της κοινόχρηστης βιβλιοθήκης `libpython` είναι `libpythonX.Ym.so.1.0` για Python 3.5‑3.7, ή `libpythonX.Y.so.1.0` για Python 3.8 ή νεότερο (π.χ.: `libpython3.7m.so.1.0`, `libpython3.9.so.1.0`).

Αν χρειάζεστε υποστήριξη για περισσότερες πλατφόρμες, ψάξτε για τα προϊόντα «αδελφά» Aspose.Slides for .NET ή Aspose.Slides for Java.

## **Συχνές Ερωτήσεις**

### Πρέπει να εγκαταστήσω το Microsoft PowerPoint στον διακομιστή/PC για να λειτουργεί η βιβλιοθήκη;

Όχι. Το PowerPoint δεν απαιτείται· το Aspose.Slides είναι μια αυτόνομη μηχανή δημιουργίας, επεξεργασίας, μετατροπής και απόδοσης παρουσιάσεων.

### Πώς λειτουργούν τα νήματα; Μπορεί η επεξεργασία να παραλληλοποιηθεί;

Είναι ασφαλές να επεξεργάζεστε διαφορετικά έγγραφα σε διαφορετικά νήματα· το ίδιο αντικείμενο [παρουσίασης](https://reference.aspose.com/slides/el/python-net/aspose.slides/presentation/) δεν πρέπει να χρησιμοποιείται από [πολλαπλά νήματα](/slides/el/python-net/multithreading/) ταυτόχρονα.

### Υποστηρίζονται κωδικοί πρόσβασης αρχείων και κρυπτογράφηση;

Ναι. [Μπορείτε](/slides/el/python-net/password-protected-presentation/) να ανοίγετε κρυπτογραφημένες παρουσιάσεις, να ορίζετε ή να αφαιρείτε κωδικούς ανοίγματος και εγγραφής, και να ελέγχετε την κατάσταση προστασίας.

### Πρέπει να ανησυχώ για πακέτα γραμματοσειρών σε κοντέινερ Linux;

Ναι. Συνιστάται η εγκατάσταση κοινών πακέτων γραμματοσειρών και/ή η ρητή [καθορισμός καταλόγων γραμματοσειρών](/slides/el/python-net/custom-font/) στην εφαρμογή σας για αποφυγή μη αναμενόμενων αντικαταστάσεων.
