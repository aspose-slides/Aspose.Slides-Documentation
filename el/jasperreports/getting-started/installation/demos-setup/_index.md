Όλες οι δοκιμαστικές εφαρμογές που παρέχονται με Aspose.Slides for JasperReports είναι τροποποιημένες τυπικές δοκιμαστικές εφαρμογές. Είναι καλύτερο να αντιγράψετε όλες τις δοκιμαστικές εφαρμογές στον φάκελο demo του JasperReports:
...\jasperreports-x.x.x\demo\samples\

Χρησιμοποιήστε την τυπική ακολουθία εντολών για να δημιουργήσετε και να εξάγετε τις αναφορές:

- ant javac
- ant compile
- ant fill
- ant ppt

{{% alert color="info" %}} 
Παρακαλώ μην ξεχάσετε να εκτελέσετε το HSQLDB με τη δοκιμαστική βάση δεδομένων για να γεμίσετε τις αναφορές με δεδομένα και να αντιγράψετε το aspose.slides.jasperreports.library-xx.x.jar από το \lib\JasperReports X.X.X - X.X.X φάκελο του aspose-slides-xx.x-jasperreports.zip στον φάκελο &#60;InstallDir&#62;\lib.
{{% /alert %}} 

Οι περισσότερες δοκιμαστικές εφαρμογές (εκτός των Charts) έχουν ήδη παραχθεί παρουσιάσεις, οπότε μπορείτε να παραλείψετε όλα τα βήματα “ant” και να ελέγξετε τα αποτελέσματα αμέσως.
