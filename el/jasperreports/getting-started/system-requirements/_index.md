## **JasperReports**

Το Aspose.Slides for JasperReports λειτουργεί με JasperReports 3.7.2 έως 6.16.0. Η λήψη περιλαμβάνει ξεχωριστό jar για κάθε μία από τις τρεις περιοχές έκδοσης — δείτε [Εγκατάσταση Aspose.Slides για JasperReports](/slides/el/jasperreports/installing-aspose-slides-for-jasperreports/) για το ποιο να χρησιμοποιήσετε. Δεν υπάρχει jar για JasperReports 6.17.0 ή νεότερο, συμπεριλαμβανομένου του JasperReports 7.

Η υποστήριξη για JasperReports 2.0.3 έως 3.7.1 τερματίστηκε στο Aspose.Slides for JasperReports 17.6. Η έκδοση 17.5 και παλαιότερες επίσης υποστήριζαν αυτές τις εκδόσεις.

## **Java**

Τα jars είναι μεταγλωττισμένα για Java 6 ή νεότερο, όπως αναφέρει το *JDK 1.6* στα ονόματα των φακέλων τους, έτσι η έκδοση Java που χρειάζεστε είναι αυτή που απαιτεί η έκδοση του JasperReports σας. Με JasperReports 6.16.0, οι εξαγωγές εκτελούνται σε Java 11, 17, 21 και 25.

## **Operating system**

Τα jars περιέχουν μόνο κλάσεις και πόρους Java, χωρίς εγγενείς βιβλιοθήκες, και δεν χρησιμοποιούν το Microsoft PowerPoint. Σε Linux, το JasperReports χρειάζεται το fontconfig και τουλάχιστον μία εγκατεστημένη γραμματοσειρά για να δημιουργήσει μια αναφορά.

## **JasperReports Server**

Για το JasperReports Server, χρησιμοποιήστε και τα δύο jars από τον φάκελο που ταιριάζει με την έκδοση του JasperReports που εκτελεί ο διακομιστής σας — δείτε [Ενσωμάτωση με JasperServer](/slides/el/jasperreports/integration-with-jasperserver/).
