{{% alert color="info" %}} 

Aspose.Slides for Android via Java είναι μια βιβλιοθήκη κλάσεων που επιτρέπει στις εφαρμογές Java για Android να διαβάζουν και να γράφουν έγγραφα παρουσίασης χωρίς να χρησιμοποιούν το Microsoft PowerPoint® ή άλλο λογισμικό. Aspose.Slides for Android via Java σας επιτρέπει να διαχειρίζεστε κείμενο, σχήματα, πίνακες και κινήσεις· να προσθέτετε ήχο και βίντεο στις διαφάνειες· να προβάλλετε διαφάνειες· και να εξάγετε τις διαφάνειες σε μορφές SVG, PDF και άλλα.

Η πιο πρόσφατη αναφορά API μπορεί να βρεθεί στο [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/el/androidjava/).

{{% /alert %}}
