## **Επισκόπηση**

Το Aspose.Slides μπορεί να χρησιμοποιηθεί σε λειτουργία αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την άδεια έκδοση, αλλά προσθέτει υδατογράφημα αξιολόγησης όταν ανοίγονται ή αποθηκεύονται παρουσιάσεις και περιορίζει την εξαγωγή κειμένου σε μία διαφάνεια.

Αυτό το άρθρο εξηγεί πώς λειτουργεί η αδειοδότηση στο Aspose.Slides και πώς να εφαρμόσετε μια άδεια πριν χρησιμοποιήσετε τη βιβλιοθήκη. Μια άδεια μπορεί να φορτωθεί από αρχείο, ροή ή ενσωματωμένο πόρο χρησιμοποιώντας την κλάση `License`. Το άρθρο δείχνει επίσης πώς να επαληθεύσετε εάν η άδεια έχει εφαρμοστεί σωστά.

## **Αδειοδότηση στο Aspose.Slides**

* Μια έκδοση αξιολόγησης γίνεται αδειοδοτημένη αφού αγοράσετε μια άδεια και προσθέσετε λίγες γραμμές κώδικα (για την εφαρμογή της άδειας).
* Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα του προϊόντος, τον αριθμό των προγραμματιστών στα οποία αδειοδοτείται, την ημερομηνία λήξης της συνδρομής κ.λπ.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, επομένως δεν πρέπει να το τροποποιήσετε. Ακόμη και μια ακούσια προσθήκη κενής γραμμής στο περιεχόμενο θα το ακυρώσει.
* Το Aspose.Slides for Android via Java συνήθως προσπαθεί να βρει την άδεια σε αυτές τις θέσεις:
  * Ένας ρητός διαδρομή
  * Ο φάκελος που περιέχει το Aspose.Slides.jar

* Για να αποφύγετε τους περιορισμούς της έκδοσης αξιολόγησης, πρέπει να ορίσετε μια άδεια πριν χρησιμοποιήσετε το **Aspose.Slides**. Η άδεια ορίζεται μία φορά ανά εφαρμογή ή διαδικασία.

## **Εφαρμογή άδειας**

Μια άδεια μπορεί να φορτωθεί από **αρχείο** ή **ροή**.

{{% alert color="info" %}}

Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/license/) για λειτουργίες αδειοδότησης.

{{% /alert %}} 

{{% alert color="warning" %}}

Οι νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με έκδοση 21.4 ή νεότερη. Παλαιότερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν αναγνωρίζουν αυτές τις άδειες.

{{% /alert %}}

### **Αρχείο**

Η πιο εύκολη μέθοδος ορισμού άδειας απαιτεί να τοποθετήσετε το αρχείο άδειας στον φάκελο που περιέχει το Aspose.Slides.jar ή το jar της εφαρμογής σας.

Αυτός ο κώδικας Java δείχνει πώς να ορίσετε ένα αρχείο άδειας:

``` java
// Δημιουργεί ένα αντικείμενο της κλάσης License
com.aspose.slides.License license = new com.aspose.slides.License();

// Ορίζει τη διαδρομή του αρχείου άδειας
license.setLicense("Aspose.Slides.Android.via.Java.lic");
```

{{% alert color="warning" %}} 

Εάν τοποθετήσετε το αρχείο άδειας σε διαφορετικό κατάλογο, όταν καλέσετε τη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-) το όνομα του αρχείου άδειας στο τέλος της ρητής διαδρομής πρέπει να είναι το ίδιο με το όνομα του αρχείου σας.

Για παράδειγμα, μπορείτε να αλλάξετε το όνομα του αρχείου άδειας σε *Aspose.Slides.Android.via.Java.lic.xml*. Στη συνέχεια, στον κώδικά σας, πρέπει να περάσετε τη διαδρομή προς το αρχείο (τελειώνοντας με *Aspose.Slides.Android.via.Java.lic.xml*) στη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-).

{{% /alert %}}

### **Ροή**

Μπορείτε να φορτώσετε μια άδεια από ροή. Αυτός ο κώδικας Java δείχνει πώς να εφαρμόσετε άδεια από ροή:

``` java
// Δημιουργεί ένα αντικείμενο της κλάσης License
com.aspose.slides.License license = new com.aspose.slides.License();

// Ορίζει την άδεια μέσω ροής
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Android.via.Java.lic"));
```

## **Επικύρωση άδειας**

Για να ελέγξετε εάν η άδεια έχει οριστεί σωστά, μπορείτε να την επικυρώσετε. Αυτός ο κώδικας Java δείχνει πώς να επικυρώσετε μια άδεια:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Android.via.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **Ασφάλεια νήματος**

{{% alert title="Note" color="warning" %}} 

Η μέθοδος [SetLicense](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/license/#setLicense-java.io.InputStream-) δεν είναι ασφαλής ως προς το νήμα. Αν αυτή η μέθοδος πρέπει να κληθεί ταυτόχρονα από πολλά νήματα, μπορεί να θέλετε να χρησιμοποιήσετε πρωτόκολλα συγχρονισμού (όπως κλείδωμα) για να αποφύγετε προβλήματα. 

{{% /alert %}}
