## **Εισαγωγή**

Το εναλλακτικό κείμενο βοηθά τα άτομα που χρησιμοποιούν βοηθητικές τεχνολογίες να κατανοήσουν το νόημα εικόνων, διαγραμμάτων και άλλων ενημερωτικών σχημάτων. Αυτό το άρθρο εξηγεί πώς να διαβάζετε και να ενημερώνετε τίτλους και περιγραφές εναλλακτικού κειμένου με το Aspose.Slides για Android μέσω Java, πώς να διακρίνετε τις περιγραφές προσβασιμότητας από τα ονόματα σχημάτων που χρησιμοποιούνται στον κώδικα και πώς να ελέγξετε αν ένα σχήμα έχει επισημανθεί ως διακοσμητικό.

Αυτά τα χαρακτηριστικά υποστηρίζουν την προσβασιμότητα των παρουσιάσεων, αλλά δεν την εγγυώνται. Η σειρά ανάγνωσης, η αντίθεση χρωμάτων, η αναγνωσιμότητα του κειμένου και άλλες απαιτήσεις προσβασιμότητας απαιτούν επίσης έλεγχο.

## **Διαχείριση Τίτλων και Περιγραφών Εναλλακτικού Κειμένου**

Χρησιμοποιήστε εναλλακτικό κείμενο για να εξηγήσετε το νόημα εικόνων, διαγραμμάτων και άλλων ενημερωτικών σχημάτων σε άτομα που δεν μπορούν να τα δουν. Οι παρακάτω μέθοδοι και περιεχόμενα εξυπηρετούν διαφορετικούς σκοπούς:

| Μέθοδος ή περιεχόμενο | Σκοπός |
| --- | --- |
| [getAlternativeTextTitle](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/ishape/#getAlternativeTextTitle--) | Μια σύντομη ετικέτα για την εναλλακτική περιγραφή. |
| [getAlternativeText](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/ishape/#getAlternativeText--) | Μια ουσιαστική περιγραφή του περιεχομένου ή του σκοπού του σχήματος στο πλαίσιο της διαφάνειας. |
| [getName](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/ishape/#getName--) | Το όνομα του σχήματος, το οποίο μπορεί να χρησιμοποιηθεί από τον κώδικα για την εύρεση ενός συγκεκριμένου σχήματος στην παρουσίαση. |
| Ορατό κείμενο | Περιεχόμενο που εμφανίζεται στη διαφάνεια, όπως το κείμενο ενός σχήματος ή ο τίτλος και οι ετικέτες ενός διαγράμματος. Η ενημέρωση του εναλλακτικού κειμένου δεν αλλάζει αυτό το περιεχόμενο. |

Όταν μια παρουσίαση επαναχρησιμοποιείται ως πρότυπο, ο κώδικας μπορεί να βρει ένα σχήμα με βάση το όνομα που επιστρέφει η μέθοδος [getName](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/ishape/#getName--) πριν το ενημερώσει. Αυτό το όνομα εξυπηρετεί διαφορετικό σκοπό από το εναλλακτικό κείμενο, το οποίο εξηγεί τι μεταδίδει το οπτικό στοιχείο στον αναγνώστη. Η αναζήτηση με όνομα επιτρέπει στους δημιουργούς να βελτιώσουν ή να μεταφράσουν τις περιγραφές χωρίς να αλλάξει ο τρόπος με τον οποίο ο κώδικας εντοπίζει το σχήμα. Τα ονόματα μπορούν να επεξεργαστούν και δεν εγγυώνται μοναδικότητα, γι’ αυτό ελέγξτε ότι το όνομα ταιριάζει με το προοριζόμενο σχήμα· δείτε την ενότητα [Identify and Find Shapes](/slides/el/androidjava/shape-manipulations/#identify-and-find-shapes).

Το παρακάτω παράδειγμα απαιτεί το αρχείο `input.pptx` με μια εικόνα της εισόδου ενός γραφείου ως πρώτο σχήμα στην πρώτη διαφάνεια. Η εικόνα δεν πρέπει να είναι σημειωμένη ως διακοσμητική. Το παράδειγμα διαβάζει και εκτυπώνει τον τρέχοντα τίτλο και την περιγραφή εναλλακτικού κειμένου, ενημερώνει και τις δύο τιμές και αποθηκεύει την παρουσίαση ως `output.pptx`. Προσαρμόστε τη διατύπωση στην πραγματική εικόνα και τις πληροφορίες που μεταδίδει.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);

    System.out.println("Alternative text title: " + shape.getAlternativeTextTitle());
    System.out.println("Alternative text description: " + shape.getAlternativeText());

    shape.setAlternativeTextTitle("Office entrance");
    shape.setAlternativeText("The office entrance has a wheelchair ramp to the right of the steps.");

    presentation.save("output.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

Η προσθήκη εναλλακτικού κειμένου από μόνη της δεν εγγυάται την προσβασιμότητα της παρουσίασης ή τη συμμόρφωση με τα πρότυπα προσβασιμότητας. Ελέγξτε τις περιγραφές για ακρίβεια και συνάφεια και επίσης ελέγξτε τη σειρά ανάγνωσης, την αντίθεση χρωμάτων, το αναγνώσιμο κείμενο και άλλες απαιτήσεις προσβασιμότητας. Τα ενημερωτικά οπτικά στοιχεία δεν πρέπει να σημειώνονται ως διακοσμητικά· η επόμενη ενότητα δείχνει πώς να ελέγξετε το [isDecorative](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/ishape/#isDecorative--).

## **Σήμανση ως Διακοσμητικό**

Η σημαία «σήμανση ως διακοσμητικό» δηλώνει καθαρά διακοσμητικά οπτικά στοιχεία ώστε τα προγράμματα ανάγνωσης οθόνης να τα αγνοούν, μειώνοντας τον θόρυβο και διατηρώντας την εστίαση στο ουσιαστικό περιεχόμενο. Εφαρμόζεται σε παρασκήνια, διακοσμητικά στοιχεία και διαχωριστικά—ποτέ σε διαγράμματα, εικονίδια ή εικόνες που μεταδίδουν πληροφορίες. Το Aspose.Slides εκθέτει αυτή τη σημαία για ανίχνευση και επικύρωση, επιτρέποντας αυτοματοποιημένους ελέγχους προσβασιμότητας και καθαρισμό.

![Σήμανση ως Διακοσμητικό](mark_as_decorative.png)

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("sample.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);
    System.out.println("Is shape decorative: " + shape.isDecorative());
} finally {
    presentation.dispose();
}
```

## **Συχνές Ερωτήσεις**

**Τι πρέπει να τοποθετήσω στον τίτλο εναλλακτικού κειμένου και στην περιγραφή;**

Χρησιμοποιήστε έναν σύντομο τίτλο για να ταυτοποιήσετε το θέμα και μια περιγραφή για να εξηγήσετε τις πληροφορίες που μεταδίδει το οπτικό στοιχείο στο πλαίσιο της διαφάνειας. Για ένα διάγραμμα, περιγράψτε τη σχετική τάση ή σύγκριση αντί να λέτε απλώς «διάγραμμα».

**Πρέπει να χρησιμοποιώ εναλλακτικό κείμενο για την εύρεση σχημάτων σε πρότυπο;**

Προτιμήστε την εύρεση του σχήματος με βάση το όνομα που επιστρέφει η μέθοδος [getName](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/ishape/#getName--) και ελέγξτε εάν είναι το αναμενόμενο σχήμα. Το εναλλακτικό κείμενο μπορεί να επεξεργαστεί ή να μεταφραστεί, κάτι που μπορεί να διακόψει τον κώδικα που ψάχνει για ακριβή περιγραφή· δείτε την ενότητα [Identify and Find Shapes](/slides/el/androidjava/shape-manipulations/).

**Πότε πρέπει ένα σχήμα να σημειώνεται ως διακοσμητικό;**

Χρησιμοποιήστε τη σημαία διακοσμητικού για οπτικά στοιχεία που δεν προσφέρουν πληροφορίες, όπως διακοσμητικά στοιχεία. Οι εικόνες και τα διαγράμματα που μεταφέρουν νόημα χρειάζονται κατάλληλη περιγραφή.

**Η προσθήκη εναλλακτικού κειμένου κάνει μια παρουσίαση πλήρως προσβάσιμη;**

Όχι. Το εναλλακτικό κείμενο αντιμετωπίζει μόνο ένα μέρος της προσβασιμότητας. Ελέγξτε επίσης τη σειρά ανάγνωσης, την αντίθεση χρωμάτων, την αναγνωσιμότητα του κειμένου και άλλες σχετικές απαιτήσεις· η ρύθμιση αυτών των ιδιοτήτων από μόνη της δεν εξασφαλίζει συμμόρφωση.
