## **Επισκόπηση**

Όταν φορτώνεται μια παρουσίαση, αποδίδεται ή μετατρέπεται σε άλλη μορφή, το Aspose.Slides ελέγχει εάν οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν λείπει μια απαιτούμενη γραμματοσειρά, το Aspose.Slides επιλέγει μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποίησε το PowerPoint.

Το Aspose.Slides πρώτα αναζητά τη συγκεκριμένη γραμματοσειρά στο λειτουργικό σύστημα. Εάν βρεθεί, χρησιμοποιείται. Εάν δεν βρεθεί, εφαρμόζεται μια κατάλληλη εναλλακτική. Όταν οι κανόνες υποκατάστασης γραμματοσειρών ορίζονται μέσω `FontSubstRule`, λαμβάνονται επίσης υπόψη.

Μπορείτε επίσης να προσθέσετε γραμματοσειρές κατά τη διάρκεια εκτέλεσης της εφαρμογής, να χρησιμοποιήσετε ενσωματωμένες γραμματοσειρές από μια παρουσίαση ή να φορτώσετε εξωτερικές γραμματοσειρές για έγγραφα εξόδου όπως αρχεία PDF.

## **Επιλογή γραμματοσειρών**

Ορισμένοι κανόνες ισχύουν για τις γραμματοσειρές σε μια παρουσίαση όταν αυτή φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή. Για παράδειγμα, όταν προσπαθείτε να μετατρέψετε μια παρουσίαση (τις διαφάνειές της) σε εικόνες, ελέγχονται οι γραμματοσειρές της παρουσίασης για να διασφαλιστεί ότι οι επιλεγμένες γραμματοσειρές είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν διαπιστωθεί ότι οι γραμματοσειρές λείπουν, αντικαθίστανται — δείτε [**Αντικατάσταση γραμματοσειρών**](https://docs.aspose.com/slides/el/androidjava/font-replacement/) και [**Υποκατάσταση γραμματοσειρών**](https://docs.aspose.com/slides/el/androidjava/font-substitution/).

Αυτή είναι η διαδικασία που ακολουθεί το Aspose.Slides κατά την επεξεργασία των γραμματοσειρών:

1. Το Aspose.Slides αναζητά γραμματοσειρές στο λειτουργικό σύστημα για να βρει τη γραμματοσειρά που ταιριάζει με την επιλεγμένη γραμματοσειρά της παρουσίασης. 
2. Εάν η επιλεγμένη γραμματοσειρά βρεθεί, το Aspose.Slides τη χρησιμοποιεί. Διαφορετικά, το Aspose.Slides χρησιμοποιεί μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποίησε το PowerPoint.
3. Εάν έχουν οριστεί κανόνες αντικατάστασης γραμματοσειρών μέσω [FontSubstRule](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/fontsubstrule/), εφαρμόζονται.

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές κατά τη διάρκεια εκτέλεσης της εφαρμογής και στη συνέχεια να τις χρησιμοποιήσετε. Δείτε [**Προσαρμοσμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/androidjava/custom-font/).

Όταν επιπλέον γραμματοσειρές τοποθετούνται μέσα σε μια παρουσίαση, ονομάζονται [**Ενσωματωμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/androidjava/embedded-font/).

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές που εφαρμόζονται μόνο σε έγγραφα εξόδου. Για παράδειγμα, εάν μια παρουσίαση που θέλετε να μετατρέψετε σε PDF περιέχει γραμματοσειρές που λείπουν από το σύστημα και τις ενσωματωμένες γραμματοσειρές, μπορείτε να προσθέσετε ή να φορτώσετε τις απαιτούμενες γραμματοσειρές ως **εξωτερικές γραμματοσειρές**. 

{{% alert title="Σημείωση" color="info" %}} 
Δεν διανείμουμε καμία γραμματοσειρά, είτε πληρωμένη είτε δωρεάν. Το API μας σας επιτρέπει να φορτώνετε εξωτερικές γραμματοσειρές και να τις ενσωματώνετε σε έγγραφα, αλλά το κάνετε με τις γραμματοσειρές με τη δική σας κρίση και ευθύνη.
{{% /alert %}}

## **Συχνές ερωτήσεις**

### Πώς μπορώ να προσδιορίσω ποιες γραμματοσειρές χρησιμοποιούνται πραγματικά σε μια παρουσίαση πριν από τη μετατροπή;

Το Aspose.Slides σάς επιτρέπει να εξετάσετε τις χρησιμοποιούμενες γραμματοσειρές μέσω του [διαχειριστή γραμματοσειρών](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/fontsmanager/), ώστε να αποφασίσετε αν θα [ενσωματώσετε](/slides/el/androidjava/embedded-font/), [αντικαταστήσετε](/slides/el/androidjava/font-replacement/) ή προσθέσετε [εξωτερικές πηγές](/slides/el/androidjava/custom-font/). Αυτό σας βοηθά να αποτρέψετε ανεπιθύμητες υποκαταστάσεις κατά την απόδοση και την εξαγωγή.

### Μπορώ να προσθέσω επιπλέον καταλόγους γραμματοσειρών χωρίς να τους εγκαταστήσω στο λειτουργικό σύστημα;

Ναι. Μπορείτε να καταχωρίσετε [εξωτερικές πηγές γραμματοσειρών](/slides/el/androidjava/custom-font/) όπως φακέλους ή ροές μνήμης για απόδοση και εξαγωγή. Αυτό αφαιρεί τη Dependence από τις γραμματοσειρές του κεντρικού συστήματος και διατηρεί τη διάταξη προβλέψιμη.

### Πώς αποτρέπω ένα σιωπηλό fallback σε μη κατάλληλη γραμματοσειρά όταν λείπει ένα γλύφημα;

Ορίστε ρητές [αντικαταστάσεις γραμματοσειρών](/slides/el/androidjava/font-replacement/) και κανόνες [fallback γραμματοσειρών](/slides/el/androidjava/fallback-font/) εκ των προτέρων. Αναλύοντας τις χρησιμοποιούμενες γραμματοσειρές και ορίζοντας ελεγχόμενη προτεραιότητα για τα υποκατάστατα, εξασφαλίζετε συνεπή τυπογραφία και αποφεύγετε ανεπιθύμητα αποτελέσματα.
