## **Μετατροπή PPT σε PPTX**

Το Aspose.Slides for Android μέσω Java διευκολύνει πλέον τους προγραμματιστές να έχουν πρόσβαση στο PPT χρησιμοποιώντας το αντικείμενο κλάσης [Presentation](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/presentation) και να το μετατρέπουν στη σχετική μορφή [PPTX](https://docs.fileformat.com/presentation/pptx/). Επί του παρόντος, υποστηρίζει μερική μετατροπή του [PPT](https://docs.fileformat.com/presentation/ppt/) σε PPTX.

Το Aspose.Slides for Android μέσω Java προσφέρει την κλάση [Presentation](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/presentation) που αντιπροσωπεύει ένα αρχείο παρουσίασης **PPTX**. Η κλάση Presentation μπορεί πλέον επίσης να έχει πρόσβαση σε **PPT** μέσω Presentation όταν δημιουργείται το αντικείμενο. Το παρακάτω παράδειγμα δείχνει πώς να μετατρέψετε μια παρουσίαση PPT σε παρουσίαση PPTX.

```java
import com.aspose.slides.*;

// Δημιουργεί ένα αντικείμενο Presentation που αντιπροσωπεύει ένα αρχείο PPT
Presentation pres = new Presentation("Aspose.ppt");
try {
// Αποθηκεύει την παρουσίαση PPT σε μορφή PPTX
    pres.save("ConvertedAspose.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```
