## **Εισαγωγή**

Στο PowerPoint 2019, η Microsoft εισήγαγε τη ρύθμιση **Always Open Read-Only** ως μία από τις επιλογές που μπορούν οι χρήστες να χρησιμοποιήσουν για να προστατεύσουν τις παρουσιάσεις τους. Μπορεί να θέλετε να χρησιμοποιήσετε αυτήν τη ρύθμιση Read-Only για να προστατέψετε μια παρουσίαση όταν

- Θέλετε να αποτρέψετε τυχαίες επεμβάσεις και να διατηρήσετε το περιεχόμενο της παρουσίασής σας ασφαλές.
- Θέλετε να ειδοποιήσετε τους ανθρώπους ότι η παρουσίαση που παρέχετε είναι η τελική έκδοση.

Αφού επιλέξετε την επιλογή **Always Open Read-Only** για μια παρουσίαση, όταν οι χρήστες ανοίξουν την παρουσίαση, βλέπουν την σύσταση **Read-Only** και μπορεί να δουν ένα μήνυμα σε αυτή τη μορφή: *Για να αποτραπούν τυχαίες αλλαγές, ο δημιουργός έχει ορίσει αυτό το αρχείο να ανοίγει ως read-only.*

Η σύσταση Read-Only είναι ένα απλό αλλά αποτελεσματικό αποτρεπτικό μέτρο που αποθαρρύνει την επεξεργασία, επειδή οι χρήστες πρέπει να εκτελέσουν μια ενέργεια για να το αφαιρέσουν προτού τους επιτραπεί η επεξεργασία μιας παρουσίασης. Εάν δεν θέλετε οι χρήστες να κάνουν αλλαγές σε μια παρουσίαση και θέλετε να το δηλώσετε με ευγενικό τρόπο, τότε η σύσταση Read-Only μπορεί να είναι μια καλή επιλογή για εσάς.

> Εάν μια παρουσίαση με την προστασία **Read-Only** ανοιχτεί σε μια παλαιότερη εφαρμογή Microsoft PowerPoint—που δεν υποστηρίζει τη πρόσφατα εισαγόμενη λειτουργία—η σύσταση **Read-Only** παραβλέπεται (η παρουσίαση ανοίγει κανονικά).

## **Εφαρμογή λειτουργίας Read-Only**

Το Aspose.Slides for Android μέσω Java σας επιτρέπει να ορίσετε μια παρουσίαση σε **Read-Only**, πράγμα που σημαίνει ότι οι χρήστες (μετά το άνοιγμα της παρουσίασης) βλέπουν τη σύσταση **Read-Only**. Αυτό το δείγμα κώδικα σας δείχνει πώς να ορίσετε μια παρουσίαση σε **Read-Only** σε Java χρησιμοποιώντας το Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 
**Σημείωση**: Η σύσταση **Read-Only** προορίζεται απλώς να αποθαρρύνει την επεξεργασία ή να εμποδίσει τους χρήστες από το να κάνουν τυχαίες αλλαγές σε μια παρουσίαση PowerPoint. Εάν ένα κίνητο πρόσωπο—που γνωρίζει τι κάνει—αποφασίσει να επεξεργαστεί την παρουσίασή σας, μπορεί εύκολα να αφαιρέσει τη ρύθμιση Read-Only. Εάν χρειάζεστε σοβαρά την πρόληψη μη εξουσιοδοτημένης επεξεργασίας, είναι καλύτερο να χρησιμοποιήσετε [πιο αυστηρές προστασίες που περιλαμβάνουν κρυπτογραφήσεις και κωδικούς πρόσβασης](https://docs.aspose.com/slides/el/androidjava/password-protected-presentation/).
{{% /alert %}} 

## **Συχνές ερωτήσεις**

### Πώς διαφέρει το 'Read-Only recommended' από την πλήρη προστασία με κωδικό;

'Read-Only recommended' εμφανίζει μόνο μια προτεινόμενη ενέργεια να ανοίξετε το αρχείο σε λειτουργία μόνο για ανάγνωση και είναι εύκολο να παρακαμφθεί. [Προστασία με κωδικό](/slides/el/androidjava/password-protected-presentation/) περιορίζει πραγματικά το άνοιγμα ή την επεξεργασία και είναι κατάλληλη όταν χρειάζεστε πραγματικούς ελέγχους ασφαλείας.

### Μπορεί το 'Read-Only recommended' να συνδυαστεί με υδατογραφήματα για να αποθαρρυνθεί περαιτέρω η επεξεργασία;

Ναι. Η σύσταση μπορεί να συνδυαστεί με [υδατογραφήματα](/slides/el/androidjava/watermark/) ως οπτικό αποτρεπτικό μέτρο· είναι ξεχωριστοί μηχανισμοί και λειτουργούν καλά μαζί.

### Μπορεί ακόμα ένα μακρό ή εξωτερικό εργαλείο να τροποποιήσει το αρχείο όταν η σύσταση είναι ενεργοποιημένη;

Ναι. Η σύσταση δεν εμποδίζει τις προγραμματιστικές αλλαγές. Για να αποτρέψετε αυτόματες επεμβάσεις, χρησιμοποιήστε [κωδικούς πρόσβασης και κρυπτογράφηση](/slides/el/androidjava/password-protected-presentation/).

### Πώς σχετίζεται το 'Read-Only recommended' με τις μεθόδους 'isEncrypted' και 'isWriteProtected';

Είναι διαφορετικά σήματα. Το 'Read-Only recommended' είναι μια ήπια, προαιρετική προτροπή· τα [isWriteProtected](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/protectionmanager/#isWriteProtected--) και [isEncrypted](https://reference.aspose.com/slides/el/androidjava/com.aspose.slides/protectionmanager/#isEncrypted--) υποδεικνύουν πραγματικούς περιορισμούς εγγραφής ή ανάγνωσης που εξαρτώνται από κωδικούς πρόσβασης ή κρυπτογράφηση.
