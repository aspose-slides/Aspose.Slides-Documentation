## **Αξιολόγηση Aspose.Slides**

Μπορείτε εύκολα να κατεβάσετε το Aspose.Slides για αξιολόγηση. Η λήψη αξιολόγησης είναι η ίδια με τη λήψη που αγοράζετε. Η έκδοση αξιολόγησης απλώς ενεργοποιείται ως άδεια όταν προσθέσετε μερικές γραμμές κώδικα για την εφαρμογή της άδειας.

Η έκδοση αξιολόγησης του Aspose.Slides (χωρίς καθορισμένη άδεια) παρέχει πλήρη λειτουργικότητα του προϊόντος, αλλά προσθέτει υδατογράφημα αξιολόγησης στην κορυφή του εγγράφου κατά το άνοιγμα και την αποθήκευση, και περιορίζει σε μία διαφάνεια όταν εξάγετε το κείμενο από τις διαφάνειες παρουσίασης.

## **Συχνές ερωτήσεις**

### Μπορώ να δοκιμάσω πολλαπλές παρουσιάσεις παράλληλα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργάζεστε διαφορετικά έγγραφα παράλληλα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [across threads](/slides/el/cpp/multithreading/). Η λειτουργία αξιολόγησης δεν το επηρεάζει.

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι μια αυτόνομη μηχανή και δεν απαιτεί την εγκατάσταση του PowerPoint είτε για αξιολόγηση είτε για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή του PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναι. Οι [converters](/slides/el/cpp/convert-presentation/) λειτουργούν· η έξοδος θα περιλαμβάνει υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμές φόρτωσης χωρίς υδατογράφημα;

Ναι. Μια προσωρινή άδεια 30‑ήμερη αφαιρεί τους περιορισμούς της λειτουργίας αξιολόγησης και επιτρέπει τη δοκιμή χωρίς υδατογράφημα.
