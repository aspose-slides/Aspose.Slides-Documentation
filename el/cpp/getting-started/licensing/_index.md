## **Overview**

Το Aspose.Slides μπορεί να χρησιμοποιηθεί σε λειτουργία αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την έκδοση με άδεια, αλλά προσθέτει υδατογράφημα αξιολόγησης όταν οι παρουσιάσεις ανοίγονται ή αποθηκεύονται και περιορίζει την εξαγωγή κειμένου σε μία διαφάνεια.

Αυτό το άρθρο εξηγεί πώς λειτουργούν οι άδειες στο Aspose.Slides και πώς να εφαρμόσετε μια άδεια πριν χρησιμοποιήσετε τη βιβλιοθήκη. Μια άδεια μπορεί να φορτωθεί από αρχείο, ροή ή ενσωματωμένο πόρο χρησιμοποιώντας την κλάση `License`. Το άρθρο δείχνει επίσης πώς να επικυρώσετε εάν η άδεια έχει εφαρμοστεί σωστά.

## **Licensing in Aspose.Slides**

* Μια έκδοση αξιολόγησης γίνεται αδειοδοτημένη μετά την αγορά άδειας και την εφαρμογή της προσθέτοντας μερικές γραμμές κώδικα.
* Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα προϊόντος, ο αριθμός των προγραμματιστών στα οποία αδειοδοτείται, η ημερομηνία λήξης της συνδρομής κ.ά.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, επομένως δεν πρέπει να τροποποιηθεί. Ακόμη και μια τυχαία αλλαγή—όπως η προσθήκη μιας αλλαγής γραμμής—θα ακυρώσει το αρχείο.
* Το Aspose.Slides for C++ συνήθως αναζητά το αρχείο άδειας στις ακόλουθες τοποθεσίες:
  * Ένα μονοπάτι που καθορίζεται ρητά στον κώδικά σας
  * Ο φάκελος που περιέχει το DLL του στοιχείου (περιλαμβάνεται στο Aspose.Slides)
  * Ο φάκελος που περιέχει το assembly που καλεί το DLL του στοιχείου
* Για να αποφύγετε τους περιορισμούς της έκδοσης αξιολόγησης, πρέπει να ορίσετε την άδεια πριν χρησιμοποιήσετε το Aspose.Slides. Η άδεια χρειάζεται να οριστεί μόνο μία φορά ανά εφαρμογή ή διαδικασία.

## **Apply a License**

Μια άδεια μπορεί να φορτωθεί από **αρχεία**, **ροές**, ή **ενσωματωμένους πόρους**.

{{% alert color="info" %}}
Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/el/cpp/class/aspose.slides.license/) για λειτουργίες αδειοδότησης.
{{% /alert %}} 

{{% alert color="warning" %}}
Οι νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με την έκδοση 21.4 ή μεταγενέστερη. Παλαιότερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν θα αναγνωρίσουν αυτές τις άδειες.
{{% /alert %}}

### **File**

Ο πιο εύκολος τρόπος για να ορίσετε μια άδεια είναι να τοποθετήσετε το αρχείο άδειας στον ίδιο φάκελο με το DLL του στοιχείου (περιλαμβάνεται στο Aspose.Slides) και να καθορίσετε μόνο το όνομα του αρχείου, χωρίς το μονοπάτι.

Ο παρακάτω κώδικας C++ δείχνει πώς να ορίσετε ένα αρχείο άδειας:

```c++
#include <Util/License.h>
#include <system/smart_ptr.h>
#include <system/string.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    return 0;
}
```

{{% alert color="warning" %}} 
Εάν τοποθετήσετε το αρχείο άδειας σε διαφορετικό κατάλογο, τότε κατά την κλήση της μεθόδου [License::SetLicense](https://reference.aspose.com/slides/el/cpp/aspose.slides/license/setlicense/), το όνομα αρχείου στο τέλος του ρητά καθορισμένου μονοπατιού πρέπει να ταιριάζει ακριβώς με το όνομα του αρχείου άδειας σας.

Για παράδειγμα, εάν μετονομάσετε το αρχείο άδειας σε *Aspose.Slides.lic.xml*, πρέπει να περάσετε το πλήρες μονοπάτι που τελειώνει σε *Aspose.Slides.lic.xml* στη μέθοδο [License::SetLicense](https://reference.aspose.com/slides/el/cpp/aspose.slides/license/setlicense/) στον κώδικά σας.
{{% /alert %}}

### **Stream**

Μπορείτε να φορτώσετε μια άδεια από ροή. Ο παρακάτω κώδικας C++ δείχνει πώς να εφαρμόσετε μια άδεια από ροή:

```c++
#include <Util/License.h>
#include <system/io/file.h>
#include <system/smart_ptr.h>
using namespace Aspose::Slides;
using namespace System;
using namespace System::IO;

auto license = MakeObject<License>();

auto stream = File::OpenRead(u"Aspose.Slides.lic");

license->SetLicense(stream);
```

## **Validate a License**

Για να ελέγξετε εάν μια άδεια έχει οριστεί σωστά, μπορείτε να την επικυρώσετε. Ο παρακάτω κώδικας C++ δείχνει πώς να επικυρώσετε μια άδεια:

```c++
#include <Util/License.h>
#include <system/console.h>
using namespace Aspose::Slides;
using namespace System;

auto license = MakeObject<License>();

license->SetLicense(u"Aspose.Slides.lic");

if (license->IsLicensed())
{
    Console::WriteLine(u"License is good!");
    Console::ReadKey();
}
```

## **Thread Safety**

{{% alert title="Note" color="warning" %}} 
Η μέθοδος [License::SetLicense](https://reference.aspose.com/slides/el/cpp/aspose.slides/license/setlicense/) δεν είναι **thread-safe**. Εάν χρειάζεται να καλέσετε αυτή τη μέθοδο από πολλαπλά νήματα ταυτόχρονα, συνιστάται να χρησιμοποιήσετε πρωτόκολλα συγχρονισμού (όπως κλειδώματα) για να αποτρέψετε πιθανές προβλήματα.
{{% /alert %}}

## **FAQ**

### Can I apply the license in a completely offline environment (no internet access)?

Ναι. Η επικύρωση της άδειας εκτελείται τοπικά χρησιμοποιώντας το αρχείο άδειας· δεν απαιτείται σύνδεση στο διαδίκτυο.

### What happens after the one-year subscription expires? Will the library stop working?

Όχι. Η άδεια είναι διαρκής: μπορείτε να συνεχίσετε να χρησιμοποιείτε εκδόσεις που κυκλοφόρησαν πριν από την ημερομηνία λήξης της συνδρομής σας· απλώς δεν θα μπορείτε να χρησιμοποιήσετε νεότερες εκδόσεις χωρίς ανανέωση.
