## **Επισκόπηση**

Το Aspose.Slides υποστηρίζει αρχεία παρουσίασης από το Microsoft PowerPoint 97 έως το Office 365, συμπεριλαμβανομένου του Microsoft PowerPoint για Mac. Αυτό το άρθρο παραθέτει τις εκδόσεις του PowerPoint που υποστηρίζονται από τη βιβλιοθήκη και παρέχει έναν πίνακα με μορφές αρχείων που μπορούν να φορτωθούν, να αποθηκευτούν ή και τα δύο.

Το άρθρο απαντά επίσης σε συχνές ερωτήσεις σχετικά με τη συμμόρφωση PDF, την ενσωμάτωση γραμματοσειρών, αρχεία προστατευμένα με κωδικό πρόσβασης, προσαρμοσμένες γραμματοσειρές, εναλλακτικές γραμματοσειρές και επιλογές εξαγωγής XPS.

## **Υποστηριζόμενες Εκδόσεις Microsoft PowerPoint**
- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint για MAC
- Office 365

## **Συχνές Ερωτήσεις**

**Μπορώ να αποθηκεύσω παρουσιάσεις σε PDF που πληρούν τα πρότυπα αρχειοθέτησης και προσβασιμότητας (PDF/A και PDF/UA);**

Ναι. Το Aspose.Slides υποστηρίζει εξαγωγή σε PDF με επίπεδα συμμόρφωσης όπως PDF/A‑2a, PDF/A‑2b, PDF/A‑2u, PDF/A‑3a, PDF/A‑3b, καθώς και PDF/UA μέσω της ρύθμισης **[compliance](https://reference.aspose.com/slides/el/cpp/aspose.slides.export/pdfoptions/set_compliance/)** στις **[επιλογές εξαγωγής PDF](https://reference.aspose.com/slides/el/cpp/aspose.slides.export/pdfoptions/)**.

**Η βιβλιοθήκη υποστηρίζει ενσωμάτωση γραμματοσειρών κατά την εξαγωγή σε PDF, με λεπτομερή έλεγχο του τι ενσωματώνεται;**

Ναι. Μπορείτε να ελέγξετε αν οι γραμματοσειρές ενσωματώνονται πλήρως ή με υποσύνολο (μόνο τα χρησιμοποιηθέντα σύμβολα), να ορίσετε πώς αντιμετωπίζονται οι κοινές γραμματοσειρές του συστήματος και να διαμορφώσετε τη συμπεριφορά για κείμενο ASCII μέσω των **[επιλογών εξαγωγής PDF](https://reference.aspose.com/slides/el/cpp/aspose.slides.export/pdfoptions/)**.

**Μπορώ να εντοπίσω αν ένα αρχείο είναι προστατευμένο με κωδικό πριν το φορτώσω;**

Ναι. Χρησιμοποιώντας το **[API επιθεώρησης βάσει εργοστασίου](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentationfactory/)**, μπορείτε να ερωτήσετε ένα αρχείο παρουσίασης για το αν είναι προστατευμένο με κωδικό χωρίς να το ανοίξετε πλήρως.

**Υπάρχουν μηχανισμοί εναλλακτικής γραμματοσειράς και υποστήριξη προσαρμοσμένων γραμματοσειρών;**

Ναι. Η βιβλιοθήκη υποστηρίζει **[φόρτωση](/slides/el/cpp/custom-font/)** και **[ενσωμάτωση](/slides/el/cpp/embedded-font/)** προσαρμοσμένων γραμματοσειρών και παρέχει **[κανόνες εναλλακτικής γραμματοσειράς](/slides/el/cpp/fallback-font/)** για την αποφυγή ελλιπών συμβόλων κατά την απόδοση και τη μετατροπή.

**Μπορώ να εξάγω διαφάνειες σε XPS και υπάρχουν επιλογές για τη βελτιστοποίηση του αποτελέσματος XPS;**

Ναι. Η **[εξαγωγή σε XPS](/slides/el/cpp/convert-powerpoint-to-xps/)** υποστηρίζεται, και μπορείτε να ρυθμίσετε τις σχετικές **[επιλογές αποθήκευσης](https://reference.aspose.com/slides/el/cpp/aspose.slides.export/xpsoptions/)** για να ελέγξετε την ποιότητα και το περιεχόμενο του εγγράφου XPS.
