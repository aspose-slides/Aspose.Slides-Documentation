{{% alert color="info" %}}

Aspose.Slides for C++ είναι μια βιβλιοθήκη κλάσεων που επιτρέπει στις εφαρμογές C++ να διαβάζουν και να γράφουν έγγραφα παρουσίασης χωρίς τη χρήση του Microsoft PowerPoint® ή άλλων. Το Aspose.Slides for C++ παρέχει διαχείριση κειμένου, σχημάτων, πινάκων & κινήσεων, προσθήκη ήχου και βίντεο στις διαφάνειες, προεπισκόπηση διαφανειών, εξαγωγή διαφανειών σε μορφές SVG, PDF και άλλα.

Η πιο πρόσφατη αναφορά API μπορεί να βρεθεί στη [Aspose.Slides for C++ API Reference](https://reference.aspose.com/slides/el/cpp/).

{{% /alert %}}
