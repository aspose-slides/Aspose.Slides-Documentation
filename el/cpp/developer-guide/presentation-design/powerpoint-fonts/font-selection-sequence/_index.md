## **Επισκόπηση**

Όταν φορτώνεται, αποδίδεται ή μετατρέπεται μια παρουσίαση σε διαφορετική μορφή, το Aspose.Slides ελέγχει αν οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν λείπει μια απαιτούμενη γραμματοσειρά, το Aspose.Slides επιλέγει μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποίησε το PowerPoint.

Το Aspose.Slides πρώτα αναζητά τη επιλεγμένη γραμματοσειρά στο λειτουργικό σύστημα. Εάν η γραμματοσειρά βρεθεί, χρησιμοποιείται. Εάν δεν βρεθεί, εφαρμόζεται μια κατάλληλη εναλλακτική. Όταν οι κανόνες αντικατάστασης γραμματοσειρών ορίζονται μέσω `FontSubstRule`, λαμβάνονται επίσης υπόψη.

Μπορείτε επίσης να προσθέσετε γραμματοσειρές κατά τη διάρκεια εκτέλεσης της εφαρμογής, να χρησιμοποιήσετε ενσωματωμένες γραμματοσειρές από μια παρουσίαση ή να φορτώσετε εξωτερικές γραμματοσειρές για έγγραφα εξόδου όπως αρχεία PDF.

## **Επιλογή γραμματοσειράς**

Ορισμένοι κανόνες εφαρμόζονται στις γραμματοσειρές μιας παρουσίασης όταν η παρουσίαση φορτώνεται, αποδίδεται ή μετατρέπεται σε διαφορετική μορφή. Για παράδειγμα, όταν προσπαθείτε να μετατρέψετε μια παρουσίαση (τις διαφάνειές της) σε εικόνες, οι γραμματοσειρές της παρουσίασης ελέγχονται για να διαπιστωθεί αν οι επιλεγμένες γραμματοσειρές είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν επιβεβαιωθεί ότι οι γραμματοσειρές λείπουν, αντικαθίστανται — δείτε [**Αντικατάσταση γραμματοσειράς**](https://docs.aspose.com/slides/el/cpp/font-replacement/) και [**Αντικατάσταση γραμματοσειρών**](https://docs.aspose.com/slides/el/cpp/font-substitution/).

Αυτή είναι η διαδικασία που ακολουθεί το Aspose.Slides όταν διαχειρίζεται γραμματοσειρές:

1. Το Aspose.Slides αναζητά γραμματοσειρές στο λειτουργικό σύστημα για να βρει τη γραμματοσειρά που ταιριάζει με τη γραμματοσειρά που έχει επιλεγεί στην παρουσίαση. 
2. Εάν η επιλεγμένη γραμματοσειρά βρεθεί, το Aspose.Slides τη χρησιμοποιεί. Διαφορετικά, το Aspose.Slides χρησιμοποιεί μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποίησε το PowerPoint.
3. Εάν έχουν οριστεί κανόνες αντικατάστασης γραμματοσειρών μέσω [FontSubstRule](https://reference.aspose.com/slides/el/cpp/aspose.slides/fontsubstrule/), εφαρμόζονται. 

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές στη διάρκεια εκτέλεσης της εφαρμογής και στη συνέχεια να τις χρησιμοποιήσετε. Δείτε [**Προσαρμοσμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/cpp/custom-font/). 

Όταν επιπλέον γραμματοσειρές τοποθετούνται μέσα σε μια παρουσίαση, ονομάζονται [**Ενσωματωμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/cpp/embedded-font/).

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές που εφαρμόζονται μόνο σε έγγραφα εξόδου. Για παράδειγμα, εάν μια παρουσίαση που θέλετε να μετατρέψετε σε PDF περιέχει γραμματοσειρές που λείπουν από το σύστημά σας και ενσωματωμένες γραμματοσειρές, μπορείτε να προσθέσετε ή να φορτώσετε τις απαιτούμενες γραμματοσειρές ως **εξωτερικές γραμματοσειρές**. 

{{% alert title="Note" color="info" %}} 
Δεν διανέμουμε καμία γραμματοσειρά, ούτε επί πληρωμή ούτε δωρεάν. Το API μας σας επιτρέπει να φορτώνετε εξωτερικές γραμματοσειρές και να τις ενσωματώνετε σε έγγραφα, αλλά το κάνετε με τις γραμματοσειρές κατά δική σας διακριτική ευχέρεια και ευθύνη.
{{% /alert %}}

## **Συχνές Ερωτήσεις**

### Πώς μπορώ να προσδιορίσω ποιες γραμματοσειρές χρησιμοποιούνται πραγματικά σε μια παρουσίαση πριν από τη μετατροπή;

Το Aspose.Slides σας επιτρέπει να ελέγξετε τις χρησιμοποιούμενες γραμματοσειρές μέσω του [διαχειριστής γραμματοσειρών](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentation/get_fontsmanager/), ώστε να αποφασίσετε αν θα [ενσωματώσετε](/slides/el/cpp/embedded-font/), [αντικαταστήσετε](/slides/el/cpp/font-replacement/) ή προσθέσετε [εξωτερικές πηγές](/slides/el/cpp/custom-font/). Αυτό σας βοηθά να αποτρέψετε ανεπιθύμητες αντικαταστάσεις κατά την απόδοση και την εξαγωγή.

### Μπορώ να προσθέσω επιπλέον καταλόγους γραμματοσειρών χωρίς να τους εγκαταστήσω στο λειτουργικό σύστημα;

Ναι. Μπορείτε να καταχωρίσετε [εξωτερικές πηγές γραμματοσειρών](/slides/el/cpp/custom-font/) όπως φακέλους ή ροές μνήμης για απόδοση και εξαγωγή. Αυτό αφαιρεί την εξάρτηση από τις γραμματοσειρές του συστήματος υποδοχής και διατηρεί τη διάταξη προβλέψιμη.

### Πώς μπορώ να αποτρέψω μια σιωπηρή πτώση σε ακατάλληλη γραμματοσειρά όταν λείπει κάποιο γλυφίδα;

Καθορίστε ρητά [αντικατάσταση γραμματοσειράς](/slides/el/cpp/font-replacement/) και κανόνες [fallback γραμματοσειρών](/slides/el/cpp/fallback-font/) εκ των προτέρων. Αναλύοντας τις χρησιμοποιούμενες γραμματοσειρές και ορίζοντας μια ελεγχόμενη προτεραιότητα για τις εναλλακτικές, εξασφαλίζετε συνεπή τυπογραφία και αποφεύγετε ανεπιθύμητα αποτελέσματα.
