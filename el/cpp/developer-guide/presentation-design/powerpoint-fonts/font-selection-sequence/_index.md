## **Επισκόπηση**

Όταν μια παρουσίαση φορτώνεται, αποδίδεται ή μετατρέπεται σε διαφορετική μορφή, το Aspose.Slides ελέγχει εάν οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν λείπει μια απαιτούμενη γραμματοσειρά, το Aspose.Slides επιλέγει μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτήν που θα χρησιμοποιούσε το PowerPoint.

Το Aspose.Slides πρώτα αναζητά την επιλεγμένη γραμματοσειρά στο λειτουργικό σύστημα. Εάν η γραμματοσειρά βρεθεί, χρησιμοποιείται. Εάν δεν βρεθεί, εφαρμόζεται μια κατάλληλη εναλλακτική. Όταν οι κανόνες αντικατάστασης γραμματοσειρών ορίζονται μέσω του `FontSubstRule`, λαμβάνονται επίσης υπόψη.

Μπορείτε επίσης να προσθέσετε γραμματοσειρές κατά την εκτέλεση της εφαρμογής, να χρησιμοποιήσετε ενσωματωμένες γραμματοσειρές από μια παρουσίαση ή να φορτώσετε εξωτερικές γραμματοσειρές για έγγραφα εξόδου όπως αρχεία PDF.

## **Επιλογή γραμματοσειράς**

Ορισμένοι κανόνες ισχύουν για τις γραμματοσειρές σε μια παρουσίαση όταν η παρουσίαση φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή. Για παράδειγμα, όταν προσπαθείτε να μετατρέψετε μια παρουσίαση (τις διαφάνειές της) σε εικόνες, οι γραμματοσειρές της παρουσίασης ελέγχονται για να διαπιστωθεί αν οι επιλεγμένες γραμματοσειρές είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν επιβεβαιωθεί ότι λείπουν, αντικαθίστανται — δείτε [**Αντικατάσταση γραμματοσειράς**](https://docs.aspose.com/slides/el/cpp/font-replacement/) και [**Υποκατάσταση γραμματοσειράς**](https://docs.aspose.com/slides/el/cpp/font-substitution/).

Αυτή είναι η διαδικασία που ακολουθεί το Aspose.Slides κατά τη διαχείριση των γραμματοσειρών:

1. Το Aspose.Slides αναζητά τις γραμματοσειρές στο λειτουργικό σύστημα για να βρει τη γραμματοσειρά που ταιριάζει με τη γραμματοσειρά που επέλεξε η παρουσίαση. 
2. Εάν η επιλεγμένη γραμματοσειρά βρεθεί, το Aspose.Slides τη χρησιμοποιεί. Διαφορετικά, το Aspose.Slides χρησιμοποιεί μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτήν που θα χρησιμοποιούσε το PowerPoint.
3. Εάν έχουν οριστεί κανόνες αντικατάστασης γραμματοσειρών μέσω του [FontSubstRule](https://reference.aspose.com/slides/el/cpp/aspose.slides/fontsubstrule/), εφαρμόζονται. 

Το Aspose.Slides σάς επιτρέπει να προσθέσετε γραμματοσειρές κατά την εκτέλεση της εφαρμογής και έπειτα να τις χρησιμοποιήσετε. Δείτε [**Προσαρμοσμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/cpp/custom-font/). 

Όταν επιπλέον γραμματοσειρές τοποθετούνται μέσα σε μια παρουσίαση, ονομάζονται [**Ενσωματωμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/cpp/embedded-font/).

Το Aspose.Slides σάς επιτρέπει να προσθέσετε γραμματοσειρές που εφαρμόζονται *μόνο* σε έγγραφα εξόδου. Για παράδειγμα, εάν μια παρουσίαση που θέλετε να μετατρέψετε σε PDF περιέχει γραμματοσειρές που λείπουν από το σύστημά σας και ενσωματωμένες γραμματοσειρές, μπορείτε να προσθέσετε ή να φορτώσετε τις απαραίτητες γραμματοσειρές ως **εξωτερικές γραμματοσειρές**. 

{{% alert title="Note" color="primary" %}} 
Δεν διανέμουμε καμία γραμματοσειρά, είτε επί πληρωμή είτε δωρεάν. Το API μας σας επιτρέπει να φορτώσετε εξωτερικές γραμματοσειρές και να τις ενσωματώσετε σε έγγραφα, αλλά το κάνετε με τις γραμματοσειρές κατά τη δική σας κρίση και ευθύνη.
{{% /alert %}}

## **Συχνές ερωτήσεις**

**Πώς μπορώ να καθορίσω ποιες γραμματοσειρές χρησιμοποιούνται πραγματικά σε μια παρουσίαση πριν από τη μετατροπή;**

Το Aspose.Slides σας επιτρέπει να εξετάσετε τις χρησιμοποιούμενες γραμματοσειρές μέσω του [διαχειριστή γραμματοσειρών](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentation/get_fontsmanager/), ώστε να αποφασίσετε αν θα [ενσωματώσετε](/slides/el/cpp/embedded-font/), [αντικαταστήσετε](/slides/el/cpp/font-replacement/) ή προσθέσετε [εξωτερικές πηγές](/slides/el/cpp/custom-font/). Αυτό σας βοηθά να αποτρέψετε ανεπιθύμητες αντικαταστάσεις κατά την απόδοση και την εξαγωγή.

**Μπορώ να προσθέσω πρόσθετους φακέλους γραμματοσειρών χωρίς να τους εγκαταστήσω στο λειτουργικό σύστημα;**

Ναι. Μπορείτε να καταχωρίσετε [εξωτερικές πηγές γραμματοσειρών](/slides/el/cpp/custom-font/) όπως φακέλους ή ροές μνήμης για την απόδοση και την εξαγωγή. Αυτό αφαιρεί την εξάρτηση από τις γραμματοσειρές του συστήματος-φιλοξενίας και διατηρεί τη διάταξη προβλέψιμη.

**Πώς μπορώ να αποτρέψω μια σιωπηρή εναλλαγή σε ακατάλληλη γραμματοσειρά όταν λείπει ένα γλυφ;**

Ορίστε ρητά [αντικατάσταση γραμματοσειράς](/slides/el/cpp/font-replacement/) και [fallBack rules](/slides/el/cpp/fallback-font/) εκ των προτέρων. Αναλύοντας τις χρησιμοποιούμενες γραμματοσειρές και ορίζοντας προτεραιότητα ελεγχόμενη για τις εναλλακτικές, εξασφαλίζετε συνεπή τυπογραφία και αποφεύγετε ανεπιθύμητα αποτελέσματα.
