## **Επισκόπηση**

Το Aspose.Slides σάς επιτρέπει να καθορίζετε τις προεπιλεγμένες γραμματοσειρές που χρησιμοποιούνται όταν αποδίδεται μια παρουσίαση. Αυτό είναι χρήσιμο κατά τη δημιουργία μικρογραφιών διαφάνειας ή την εξαγωγή μιας παρουσίασης σε μορφές όπως PDF και XPS. Οι προεπιλεγμένες γραμματοσειρές διαμορφώνονται μέσω του `LoadOptions` πριν φορτωθεί η παρουσίαση.

Η μέθοδος `set_DefaultRegularFont` ορίζει την προεπιλεγμένη γραμματοσειρά για κανονικό κείμενο, ενώ η `set_DefaultAsianFont` ορίζει την προεπιλεγμένη γραμματοσειρά για ασιατικό κείμενο. Αφού οριστούν αυτές οι επιλογές, η παρουσίαση μπορεί να φορτωθεί και να αποδοθεί χρησιμοποιώντας τις καθορισμένες γραμματοσειρές.

## **Χρήση προεπιλεγμένων γραμματοσειρών για την απόδοση μιας παρουσίασης**
Το Aspose.Slides σας επιτρέπει να ορίσετε την προεπιλεγμένη γραμματοσειρά για την απόδοση της παρουσίασης σε PDF, XPS ή μικρογραφίες. Αυτό το άρθρο δείχνει πώς να ορίσετε τις DefaultRegular Font και DefaultAsian Font για χρήση ως προεπιλεγμένες γραμματοσειρές. Ακολουθήστε τα παρακάτω βήματα για φόρτωση γραμματοσειρών από εξωτερικούς καταλόγους χρησιμοποιώντας το Aspose.Slides για C++ API:

1. Δημιουργήστε ένα αντικείμενο LoadOptions.
1. Ορίστε την DefaultRegularFont στην επιθυμητή γραμματοσειρά σας. Στο παρακάτω παράδειγμα, χρησιμοποίησα τη Wingdings.
1. Ορίστε την DefaultAsianFont στην επιθυμητή γραμματοσειρά σας. Χρησιμοποίησα τη Wingdings στο παρακάτω δείγμα.
1. Φορτώστε την παρουσίαση χρησιμοποιώντας το Presentation και ορίζοντας τις επιλογές φόρτωσης.
1. Τώρα, δημιουργήστε τη μικρογραφία της διαφάνειας, το PDF και το XPS για να επαληθεύσετε τα αποτελέσματα.

Η υλοποίηση του παραπάνω παρέχεται παρακάτω.

```cpp
// Χρησιμοποιήστε τις επιλογές φόρτωσης για να καθορίσετε τις προεπιλεγμένες κανονικές και ασιατικές γραμματοσειρές
auto loadOptions = MakeObject<LoadOptions>(LoadFormat::Auto);
loadOptions->set_DefaultRegularFont(u"Wingdings");
loadOptions->set_DefaultAsianFont(u"Wingdings");

auto pptx = MakeObject<Presentation>(u"DefaultFonts.pptx", loadOptions);

auto image = pptx->get_Slide(0)->GetImage(1, 1);
image->Save(u"DefaultFonts_out.png", ImageFormat::Png);
image->Dispose();

pptx->Save(u"DefaultFonts_out.pdf", SaveFormat::Pdf);
pptx->Save(u"DefaultFonts_out.xps", SaveFormat::Xps);

pptx->Dispose();
```

## **ΣΥΧΝΕΣ ΕΡΩΤΗΣΕΙΣ**

**Τι ακριβώς επηρεάζουν οι DefaultRegularFont και DefaultAsianFont—μόνο την εξαγωγή ή επίσης τις μικρογραφίες, PDF, XPS, HTML και SVG;**

Συμμετέχουν στην αλυσίδα απόδοσης για όλες τις υποστηριζόμενες εξόδους. Αυτό περιλαμβάνει τις μικρογραφίες διαφάνειας, [PDF](/slides/el/cpp/convert-powerpoint-to-pdf/), [XPS](/slides/el/cpp/convert-powerpoint-to-xps/), [εικόνες raster](/slides/el/cpp/convert-powerpoint-to-png/), [HTML](/slides/el/cpp/convert-powerpoint-to-html/), και [SVG](/slides/el/cpp/render-a-slide-as-an-svg-image/), επειδή το Aspose.Slides χρησιμοποιεί την ίδια λογική διάταξης και ανάλυσης γλυφών σε αυτούς τους στόχους.

**Εφαρμόζονται οι προεπιλεγμένες γραμματοσειρές όταν απλώς διαβάζουμε και αποθηκεύουμε ένα PPTX χωρίς καμία απόδοση;**

Όχι. Οι προεπιλεγμένες γραμματοσειρές είναι σημαντικές όταν το κείμενο πρέπει να μετρηθεί και να σχεδιαστεί. Ένας απλός άνοιγμα‑αποθήκευση μιας παρουσίασης δεν αλλάζει τις αποθηκευμένες ακολουθίες γραμματοσειρών ή τη δομή του αρχείου. Οι προεπιλεγμένες γραμματοσειρές παρεμβάλλονται κατά τις λειτουργίες που αποδίδουν ή επαναδιατάσσουν το κείμενο.

**Εάν προσθέσω δικούς μου φακέλους γραμματοσειρών ή παρέχω γραμματοσειρές από τη μνήμη, θα ληφθούν υπόψη κατά την επιλογή των προεπιλεγμένων γραμματοσειρών;**

Ναι. [Custom font sources](/slides/el/cpp/custom-font/) επεκτείνουν τον κατάλογο των διαθέσιμων οικογενειών και γλυφών που μπορεί να χρησιμοποιήσει η μηχανή. Οι προεπιλεγμένες γραμματοσειρές και τυχόν [κανόνες εναλλακτικών γραμματοσειρών](/slides/el/cpp/fallback-font/) θα επιλυθούν πρώτα απέναντι σε αυτές τις πηγές, παρέχοντας πιο αξιόπιστη κάλυψη σε διακομιστές και σε κοντέινερ.

**Θα επηρεάσουν οι προεπιλεγμένες γραμματοσειρές τις μετρικές κειμένου (συνάφεια, προοδευτικά), και κατά συνέπεια τις αλλαγές γραμμής και τη συσσώρευση;**

Ναι. Η αλλαγή της γραμματοσειράς αλλάζει τις μετρικές των γλυφών και μπορεί να τροποποιήσει τις αλλαγές γραμμής, τη συσσώρευση και την σελιδοποίηση κατά την απόδοση. Για σταθερότητα διάταξης, [ενσωματώστε τις αρχικές γραμματοσειρές](/slides/el/cpp/embedded-font/) ή επιλέξτε προεπιλεγμένες και εναλλακτικές οικογένειες συμβατές μετρικά.

**Υπάρχει κάποιο νόημα στο να ορίσετε προεπιλεγμένες γραμματοσειρές εάν όλες οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι ενσωματωμένες;**

Συχνά δεν είναι απαραίτητο, επειδή οι [ενσωματωμένες γραμματοσειρές](/slides/el/cpp/embedded-font/) εξασφαλίζουν ήδη συνεπή εμφάνιση. Οι προεπιλεγμένες γραμματοσειρές εξακολουθούν να βοηθούν ως δίχτυ ασφαλείας για χαρακτήρες που δεν καλύπτονται από το ενσωματωμένο υποσύνολο ή όταν ένα αρχείο συνδυάζει ενσωματωμένο και μη ενσωματωμένο κείμενο.
