## **Επισκόπηση**

Η αντικατάσταση γραμματοσειράς επιτρέπει στο Aspose.Slides να χρησιμοποιεί άλλη γραμματοσειρά όταν η αρχική γραμματοσειρά παρουσίασης δεν είναι διαθέσιμη κατά τη διάρκεια απόδοσης ή μετατροπής. Μπορείτε να ελέγξετε ποιες γραμματοσειρές αντικαταστάθηκαν χρησιμοποιώντας τη μέθοδο `GetSubstitutions` από τη διεπαφή `IFontsManager`.

Το Aspose.Slides επίσης επιτρέπει τον ορισμό κανόνων αντικατάστασης γραμματοσειρών. Για παράδειγμα, μπορείτε να ορίσετε ότι μια μη προσβάσιμη γραμματοσειρά πρέπει να αντικατασταθεί με μια άλλη διαθέσιμη γραμματοσειρά και στη συνέχεια να εφαρμόσετε αυτούς τους κανόνες μέσω του διαχειριστή γραμματοσειρών της παρουσίασης.

## **Ορισμός κανόνων αντικατάστασης γραμματοσειρών**

Το Aspose.Slides σας επιτρέπει να ορίσετε κανόνες για γραμματοσειρές που καθορίζουν τι πρέπει να γίνει σε ορισμένες συνθήκες (π.χ., όταν μια γραμματοσειρά δεν είναι προσβάσιμη) με αυτόν τον τρόπο:

1. Φορτώστε την αντίστοιχη παρουσίαση.  
2. Φορτώστε τη γραμματοσειρά που θα αντικατασταθεί.  
3. Φορτώστε τη νέα γραμματοσειρά.  
4. Προσθέστε έναν κανόνα για την αντικατάσταση.  
5. Προσθέστε τον κανόνα στη συλλογή κανόνων αντικατάστασης γραμματοσειρών της παρουσίασης.  
6. Δημιουργήστε την εικόνα της διαφάνειας για να παρατηρήσετε το αποτέλεσμα.

Αυτός ο κώδικας C++ επιδεικνύει τη διαδικασία αντικατάστασης γραμματοσειρών:

```c++
// Η διαδρομή προς τον φάκελο εγγράφων.
const String outPath = u"../out/RuleBasedFontsReplacement_out.pptx";
const String templatePath = u"../templates/DefaultFonts.pptx";


// Φορτώνει μια παρουσίαση
SharedPtr<Presentation> pres = MakeObject<Presentation>(templatePath);

// Ορίζει τη γραμματοσειρά που θα αντικατασταθεί και τη νέα γραμματοσειρά
SharedPtr<IFontData> sourceFont = MakeObject<FontData>(u"SomeRareFont");
SharedPtr<IFontData> destFont = MakeObject<FontData>(u"Arial");
	
// Προσθέτει κανόνα γραμματοσειράς για αντικατάσταση γραμματοσειράς
SharedPtr<FontSubstRule> fontSubstRule = MakeObject<FontSubstRule>(sourceFont, destFont, FontSubstCondition::WhenInaccessible);

// Προσθέτει τον κανόνα στη συλλογή κανόνων υποκατάστασης γραμματοσειρών
SharedPtr<FontSubstRuleCollection> fontSubstRuleCollection = MakeObject<FontSubstRuleCollection>();
fontSubstRuleCollection->Add(fontSubstRule);

// Προσθέτει τη συλλογή κανόνων γραμματοσειρών στη λίστα κανόνων
pres->get_FontsManager()->set_FontSubstRuleList ( fontSubstRuleCollection);


// Αποθηκεύει το PPTX στο δίσκο
pres->Save(outPath, Aspose::Slides::Export::SaveFormat::Pptx);
```

## **Περιορισμοί για γραμματοσειρές μαθηματικών εξισώσεων**

Οι κανόνες αντικατάστασης γραμματοσειρών συμμετέχουν στη στάνταρ διαδικασία επιλογής γραμματοσειράς που χρησιμοποιείται κατά την απόδοση και τη μετατροπή. Είναι κατάλληλοι για κανονικά σενάρια κειμένου όπου το Aspose.Slides μπορεί να αντικαταστήσει μια μη προσβάσιμη γραμματοσειρά με άλλη διαθέσιμη σύμφωνα με τον διαμορφωμένο κανόνα.

Ωστόσο, οι μαθηματικές εξισώσεις του Office έχουν έναν σημαντικό περιορισμό. Εάν μια εξίσωση δημιουργήθηκε με **Cambria Math**, το Aspose.Slides ενδέχεται ακόμα να απαιτεί την αρχική γραμματοσειρά **Cambria Math** για να υπολογίσει και να αποδώσει σωστά τη διάταξη της εξίσωσης. Λόγω αυτού, η αντικατάσταση της **Cambria Math** με άλλη μαθηματική γραμματοσειρά, όπως η **STIX Two Math**, δεν υποστηρίζεται για την απόδοση εξίσωσης και ενδέχεται ακόμη να προκαλέσει εξαίρεση που υποδεικνύει ότι απαιτείται η **Cambria Math**.

Για να μετατρέψετε τέτοιες παρουσιάσεις με επιτυχία, βεβαιωθείτε ότι η **Cambria Math** είναι διαθέσιμη στο Aspose.Slides κατά τη διάρκεια εκτέλεσης. Μπορείτε να εγκαταστήσετε τη γραμματοσειρά στο λειτουργικό σύστημα ή να τη παρέχετε ως [εξωτερική γραμματοσειρά](/slides/el/cpp/custom-font/) ώστε να συμμετέχει στη φυσική διαδικασία επιλογής γραμματοσειράς κατά την απόδοση και τη μετατροπή.

Αυτός ο περιορισμός είναι συγκεκριμένος για την απόδοση εξίσωσης. Οι τυπικοί κανόνες αντικατάστασης γραμματοσειρών που περιγράφονται παραπάνω εξακολουθούν να ισχύουν για το κανονικό κείμενο παρουσίασης όταν η αρχική γραμματοσειρά δεν είναι προσβάσιμη.

## **FAQ**

**Ποια είναι η διαφορά μεταξύ αντικατάστασης γραμματοσειράς και υποκατάστασης γραμματοσειράς;**

Το [Αντικατάσταση](/slides/el/cpp/font-replacement/) είναι μια εξαναγκασμένη αντικατάσταση μιας γραμματοσειράς με άλλη σε ολόκληρη την παρουσίαση. Η υποκατάσταση είναι ένας κανόνας που ενεργοποιείται υπό συγκεκριμένη κατάσταση, για παράδειγμα όταν η αρχική γραμματοσειρά δεν είναι διαθέσιμη, και τότε χρησιμοποιείται μια καθορισμένη εναλλακτική γραμματοσειρά.

**Πότε εφαρμόζονται ακριβώς οι κανόνες υποκατάστασης;**

Οι κανόνες συμμετέχουν στην τυπική ακολουθία [επιλογής γραμματοσειράς](/slides/el/cpp/font-selection-sequence/) που αξιολογείται κατά τη φόρτωση, την απόδοση και τη μετατροπή· εάν η επιλεγμένη γραμματοσειρά δεν είναι διαθέσιμη, εφαρμόζεται η αντικατάσταση ή η υποκατάσταση.

**Ποια είναι η προεπιλεγμένη συμπεριφορά εάν δεν έχει διαμορφωθεί ούτε αντικατάσταση ούτε υποκατάσταση και η γραμματοσειρά λείπει από το σύστημα;**

Η βιβλιοθήκη θα προσπαθήσει να επιλέξει την πλησιέστερη διαθέσιμη γραμματοσειρά συστήματος, παρόμοια με το πώς θα λειτουργούσε το PowerPoint.

**Μπορώ να προσθέσω προσαρμοσμένες εξωτερικές γραμματοσειρές κατά την εκτέλεση για να αποφύγω την υποκατάσταση;**

Ναι. Μπορείτε να [προσθέσετε εξωτερικές γραμματοσειρές](/slides/el/cpp/custom-font/) κατά την εκτέλεση ώστε η βιβλιοθήκη να τις λαμβάνει υπόψη για επιλογή και απόδοση, συμπεριλαμβανομένων των επόμενων μετατροπών.

**Διανέμει η Aspose κάποια γραμματοσειρά με τη βιβλιοθήκη;**

Όχι. Η Aspose δεν διανέμει πληρωμένες ή δωρεάν γραμματοσειρές· εσείς προσθέτετε και χρησιμοποιείτε γραμματοσειρές με τη δική σας κρίση και ευθύνη.

**Υπάρχουν διαφορές στη συμπεριφορά υποκατάστασης σε Windows, Linux και macOS;**

Ναι. Η ανακάλυψη γραμματοσειρών ξεκινά από τους καταλόγους γραμματοσειρών του λειτουργικού συστήματος. Το σύνολο των προεπιλεγμένων διαθέσιμων γραμματοσειρών και οι διαδρομές αναζήτησης διαφέρουν ανά πλατφόρμα, κάτι που επηρεάζει τη διαθεσιμότητα και την ανάγκη υποκατάστασης.

**Πώς πρέπει να προετοιμάσω το περιβάλλον για να μειώσω τις απροσδόκητες υποκαταστάσεις κατά τη διάρκεια μαζικών μετατροπών;**

Συγχρονίστε το σύνολο γραμματοσειρών μεταξύ μηχανών ή containers, [προσθέστε τις εξωτερικές γραμματοσειρές](/slides/el/cpp/custom-font/) που απαιτούνται για τα τελικά έγγραφα, και [ενσωματώστε γραμματοσειρές](/slides/el/cpp/embedded-font/) στις παρουσιάσεις όταν είναι δυνατόν, ώστε οι επιλεγμένες γραμματοσειρές να είναι διαθέσιμες κατά την απόδοση.
