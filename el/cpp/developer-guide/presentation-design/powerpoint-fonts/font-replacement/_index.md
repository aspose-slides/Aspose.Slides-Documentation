## **Επισκόπηση**

Το Aspose.Slides σας επιτρέπει να αντικαταστήσετε μια γραμματοσειρά με άλλη σε ολόκληρη την παρουσίαση. Όταν μια γραμματοσειρά αντικαθίσταται, όλες οι εμφανίσεις της αρχικής γραμματοσειράς αλλάζουν στη νέα γραμματοσειρά.

Για να εκτελέσετε αντικατάσταση γραμματοσειράς, φορτώστε την παρουσίαση, ορίστε τη γραμματοσειρά προέλευσης και τη γραμματοσειρά αντικατάστασης, καλέστε τη μέθοδο αντικατάστασης γραμματοσειράς και αποθηκεύστε την τροποποιημένη παρουσίαση ως αρχείο PPTX. Αυτή η προσέγγιση είναι χρήσιμη όταν θέλετε σκόπιμα να μεταβείτε από μία οικογένεια γραμματοσειρών σε άλλη σε όλη την παρουσίαση.

## **Αντικατάσταση Γραμματοσειρών**

Αν αλλάξετε γνώμη σχετικά με τη χρήση μιας γραμματοσειράς, μπορείτε να την αντικαταστήσετε με άλλη γραμματοσειρά. Όλες οι εμφανίσεις της παλιάς γραμματοσειράς θα αντικατασταθούν από τη νέα.

Το Aspose.Slides σας επιτρέπει να αντικαταστήσετε μια γραμματοσειρά με αυτόν τον τρόπο:

1. Φορτώστε την σχετική παρουσίαση. 
2. Φορτώστε τη γραμματοσειρά που θα αντικατασταθεί. 
3. Φορτώστε τη νέα γραμματοσειρά. 
4. Αντικαταστήστε τη γραμματοσειρά. 
5. Γράψτε την τροποποιημένη παρουσίαση ως αρχείο PPTX.

Αυτός ο κώδικας C++ δείχνει την αντικατάσταση γραμματοσειράς:

``` cpp
// Φορτώνει μια παρουσίαση
auto presentation = System::MakeObject<Presentation>(u"Fonts.pptx");

// Φορτώνει τη γραμματοσειρά προέλευσης που θα αντικατασταθεί
auto sourceFont = System::MakeObject<FontData>(u"Arial");

// Φορτώνει τη νέα γραμματοσειρά
auto destFont = System::MakeObject<FontData>(u"Times New Roman");

// Αντικαθιστά τις γραμματοσειρές
presentation->get_FontsManager()->ReplaceFont(sourceFont, destFont);

// Αποθηκεύει την παρουσίαση
presentation->Save(u"UpdatedFont_out.pptx", SaveFormat::Pptx);
```

{{% alert title="Note" color="warning" %}} 
Για να ορίσετε κανόνες που καθορίζουν τι συμβαίνει σε ορισμένες συνθήκες (π.χ. εάν δεν είναι προσβάσιμη μια γραμματοσειρά), δείτε [**Αντικατάσταση Γραμματοσειρών**](/slides/el/cpp/font-substitution/). 
{{% /alert %}}

## **Συχνές Ερωτήσεις**

**Ποια είναι η διαφορά μεταξύ «αντικατάσταση γραμματοσειράς», «αντικατάσταση» και «εφεδρικές γραμματοσειρές»;**

Η αντικατάσταση είναι μια σκόπιμη μετάβαση από μία οικογένεια σε άλλη σε όλο το έγγραφο. Η [Αντικατάσταση](/slides/el/cpp/font-substitution/) είναι ένας κανόνας όπως «εάν η γραμματοσειρά δεν είναι διαθέσιμη, χρησιμοποιήστε X». Η [Εφεδρική γραμματοσειρά](/slides/el/cpp/fallback-font/) εφαρμόζεται επιλεκτικά για μεμονωμένα γλύφους όταν η βασική γραμματοσειρά είναι εγκατεστημένη αλλά δεν περιέχει τους απαιτούμενους χαρακτήρες.

**Εφαρμόζεται η αντικατάσταση στις κύριες διαφάνειες, διατάξεις, σημειώσεις και σχόλια;**

Ναι. Η αντικατάσταση επηρεάζει όλα τα αντικείμενα παρουσίασης που χρησιμοποιούν την αρχική γραμματοσειρά, συμπεριλαμβανομένων των κύριων διαφανειών και των σημειώσεων· τα σχόλια επίσης αποτελούν μέρος του εγγράφου και λαμβάνονται υπόψη από τη μηχανή γραμματοσειρών.

**Θα αλλάξει η γραμματοσειρά μέσα σε ενσωματωμένα αντικείμενα OLE (π.χ. Excel);**

Όχι. Το [περιεχόμενο OLE](/slides/el/cpp/manage-ole/) ελέγχεται από τη δική του εφαρμογή. Η αντικατάσταση στην παρουσίαση δεν μορφοποιεί εκ νέου τα εσωτερικά δεδομένα OLE· μπορεί να εμφανίζεται ως εικόνα ή ως εξωτερικά επεξεργάσιμο περιεχόμενο.

**Μπορώ να αντικαταστήσω μια γραμματοσειρά μόνο σε μέρος της παρουσίασης (κατά διαφάνειες ή περιοχές);**

Η στοχευμένη αντικατάσταση είναι δυνατή εάν αλλάξετε τη γραμματοσειρά στο επίπεδο των απαιτούμενων αντικειμένων/περιοχών αντί να εφαρμόσετε μια καθολική αντικατάσταση σε ολόκληρο το έγγραφο. Η συνολική λογική επιλογής γραμματοσειράς κατά τη απόδοση παραμένει η ίδια.

**Πώς μπορώ να προσδιορίσω εκ των προτέρων ποιες γραμματοσειρές χρησιμοποιεί η παρουσίαση;**

Χρησιμοποιήστε το [διαχειριστής γραμματοσειρών](https://reference.aspose.com/slides/el/cpp/aspose.slides/fontsmanager/): παρέχει μια λίστα με τις [οικογένειες σε χρήση](https://reference.aspose.com/slides/el/cpp/aspose.slides/fontsmanager/getfonts/) και πληροφορίες για τις [υποκαταστάσεις/«άγνωστες» γραμματοσειρές](https://reference.aspose.com/slides/el/cpp/aspose.slides/fontsmanager/getsubstitutions/), που βοηθούν στον σχεδιασμό της αντικατάστασης.

**Λειτουργεί η αντικατάσταση γραμματοσειράς κατά τη μετατροπή σε PDF/εικόνες;**

Ναι. Κατά την εξαγωγή, το Aspose.Slides εφαρμόζει την ίδια [ακολουθία επιλογής/υποκατάστασης γραμματοσειράς](/slides/el/cpp/font-selection-sequence/), έτσι ώστε μια προληπτική αντικατάσταση να τηρείται κατά τη μετατροπή.

**Πρέπει να εγκαταστήσω τη γραμματοσειρά-στόχο στο σύστημα ή μπορώ να επισυνάψω έναν φάκελο γραμματοσειρών;**

Η εγκατάσταση δεν απαιτείται: η βιβλιοθήκη επιτρέπει τη [φόρτωση εξωτερικών γραμματοσειρών](/slides/el/cpp/custom-font/) από φακέλους χρήστη για χρήση κατά τη [απόδοση και εξαγωγή](/slides/el/cpp/convert-powerpoint/).

**Θα διορθώσει η αντικατάσταση τα «tofu» (τετράγωνα) αντί για χαρακτήρες;**

Μόνο εάν η γραμματοσειρά-στόχος περιέχει πραγματικά τα απαιτούμενα γλύφια. Εάν όχι, [ρυθμίστε την εφεδρική γραμματοσειρά](/slides/el/cpp/fallback-font/) για να καλύψετε τους χαρακτήρες που λείπουν.
