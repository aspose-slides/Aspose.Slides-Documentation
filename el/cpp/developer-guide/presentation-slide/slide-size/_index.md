## **Εισαγωγή**

Το Aspose.Slides παρέχει ολοκληρωμένα εργαλεία για τη ρύθμιση του μεγέθους διαφάνειας και της λόγου διαστάσεων σε παρουσιάσεις PowerPoint, κρίσιμα τόσο για εκτύπωση όσο και για προβολή στην οθόνη.

Δημοφιλή Μεγέθη Διαφανειών και Λόγοι:

- **Κανονικό (4:3 Λόγος Διαστάσεων)**: Ιδανικό για παλαιότερες οθόνες και συσκευές.
- **Widescreen (16:9 Λόγος Διαστάσεων)**: Συνιστάται για σύγχρονα προβολέα και οθόνες.

Διασφαλίστε τη σταθερότητα σε όλη την παρουσίαση, καθώς ένα ενιαίο μέγεθος διαφάνειας και λόγος διαστάσεων εφαρμόζεται σε όλες τις διαφάνειες. Για βέλτιστα αποτελέσματα, ορίστε τις διαστάσεις της διαφάνειας στην αρχή της διαδικασίας δημιουργίας της παρουσίασής σας, ώστε να αποφύγετε προβλήματα.

{{% alert color="info" %}} 
Από προεπιλογή, οι παρουσιάσεις που δημιουργούνται με το Aspose.Slides χρησιμοποιούν τον τυπικό λόγο 4:3.
{{% /alert %}}

Οι σελίδες σημειώσεων και διανεμητικών υλικών έχουν διαφορετικές διαστάσεις από τις κανονικές διαφάνειες. Δείτε το [Μέγεθος Σελίδας Σημειώσεων](/slides/el/cpp/notes-size/) για να αλλάξετε το μέγεθος και τον προσανατολισμό τους.

## **Αλλαγή του Μεγέθους Διαφάνειας σε Παρουσιάσεις**

Αυτό το δείγμα κώδικα σας δείχνει πώς να αλλάξετε το μέγεθος διαφάνειας σε μια παρουσίαση σε C++ χρησιμοποιώντας το Aspose.Slides:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **Καθορισμός Προσαρμοσμένων Μεγεθών Διαφάνειας σε Παρουσιάσεις**

Εάν θεωρείτε ότι τα κοινά μεγέθη διαφανειών (4:3 και 16:9) δεν είναι κατάλληλα για τη δουλειά σας, μπορεί να αποφασίσετε να χρησιμοποιήσετε ένα συγκεκριμένο ή μοναδικό μέγεθος διαφάνειας. Για παράδειγμα, εάν σκοπεύετε να εκτυπώσετε πλήρους μεγέθους διαφάνειες από την παρουσίασή σας σε μια προσαρμοσμένη διάταξη σελίδας ή εάν προτίθεστε να προβάλτε την παρουσίαση σας σε συγκεκριμένους τύπους οθόνης, είναι πιθανό να ωφεληθείτε από τη χρήση μιας προσαρμοσμένης ρύθμισης μεγέθους για την παρουσίασή σας.

Αυτό το δείγμα κώδικα σας δείχνει πώς να χρησιμοποιήσετε το Aspose.Slides για C++ για να καθορίσετε προσαρμοσμένο μέγεθος διαφάνειας σε μια παρουσίαση σε C++:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// Μέγεθος χαρτιού A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **Διαχείριση Περιεχομένου Διαφάνειας μετά την Αλλαγή Μεγέθους**

Αφού αλλάξετε το μέγεθος διαφάνειας για μια παρουσίαση, το περιεχόμενο των διαφανειών (εικόνες ή αντικείμενα, για παράδειγμα) μπορεί να παραμορφωθεί. Από προεπιλογή, τα αντικείμενα αλλάζουν αυτόματα το μέγεθός τους ώστε να ταιριάζουν με το νέο μέγεθος διαφάνειας. Ωστόσο, όταν αλλάζετε το μέγεθος διαφάνειας μιας παρουσίασης, μπορείτε να ορίσετε μια ρύθμιση που καθορίζει πώς το Aspose.Slides χειρίζεται το περιεχόμενο στις διαφάνειες.

Ανάλογα με το τι σκοπεύετε να κάνετε ή να πετύχετε, μπορείτε να χρησιμοποιήσετε οποιαδήποτε από αυτές τις ρυθμίσεις:

- `DoNotScale`

  Αν ΔΕΝ θέλετε τα αντικείμενα στις διαφάνειες να αλλάξουν μέγεθος, χρησιμοποιήστε αυτή τη ρύθμιση.

- `EnsureFit`

  Αν θέλετε να κλιμακώσετε σε μικρότερο μέγεθος διαφάνειας και χρειάζεστε το Aspose.Slides να μειώσει τα αντικείμενα των διαφανειών ώστε να ταιριάζουν όλες στις διαφάνειες (με αυτόν τον τρόπο, αποφεύγετε την απώλεια περιεχομένου), χρησιμοποιήστε αυτή τη ρύθμιση.

- `Maximize`

  Αν θέλετε να κλιμακώσετε σε μεγαλύτερο μέγεθος διαφάνειας και χρειάζεστε το Aspose.Slides να αυξήσει τα αντικείμενα των διαφανειών ώστε να είναι ανάλογα με το νέο μέγεθος διαφάνειας, χρησιμοποιήστε αυτή τη ρύθμιση.

Αυτό το δείγμα κώδικα σας δείχνει πώς να χρησιμοποιήσετε τη ρύθμιση `Maximize` όταν αλλάζετε το μέγεθος της διαφάνειας μιας παρουσίασης:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **Συχνές Ερωτήσεις**

### Μπορώ να ορίσω προσαρμοσμένο μέγεθος διαφάνειας χρησιμοποιώντας μονάδες διαφορετικές από ίντσες (για παράδειγμα, σημεία ή χιλιοστά);

Ναι. Το Aspose.Slides χρησιμοποιεί εσωτερικά σημεία, όπου 1 σημείο ισούται με 1/72 της ίντσας. Μπορείτε να μετατρέψετε οποιαδήποτε μονάδα (όπως χιλιοστά ή εκατοστά) σε σημεία και να χρησιμοποιήσετε τις μετατρεπόμενες τιμές για τον ορισμό του πλάτους και του ύψους της διαφάνειας.

### Θα επηρεάσει ένα πολύ μεγάλο προσαρμοσμένο μέγεθος διαφάνειας την απόδοση και τη χρήση μνήμης κατά την απόδοση;

Ναι. Μεγαλύτερες διαστάσεις διαφάνειας (σε σημεία) σε συνδυασμό με υψηλότερη κλίμακα απόδοσης οδηγούν σε αυξημένη κατανάλωση μνήμης και μεγαλύτερο χρόνο επεξεργασίας. Στοχεύστε σε ένα πρακτικό μέγεθος διαφάνειας και ρυθμίστε την κλίμακα απόδοσης μόνο όταν απαιτείται για την επίτευξη της επιθυμητής ποιότητας εξόδου.

### Μπορώ να ορίσω ένα μη τυπικό μέγεθος διαφάνειας και στη συνέχεια να συγχωνεύσω διαφάνειες από παρουσιάσεις που έχουν διαφορετικά μεγέθη;

Δεν μπορείτε να [συγχωνεύσετε παρουσιάσεις](/slides/el/cpp/merge-presentation/) ενώ έχουν διαφορετικά μεγέθη διαφάνειας — πρώτα, αλλάξτε το μέγεθος μιας παρουσίασης ώστε να ταιριάζει με την άλλη. Κατά την αλλαγή του μεγέθους διαφάνειας, μπορείτε να επιλέξετε πώς θα διαχειρίζεται το υπάρχον περιεχόμενο μέσω της επιλογής [SlideSizeScaleType](https://reference.aspose.com/slides/el/cpp/aspose.slides/slidesizescaletype/). Μετά την εναρμόνιση των μεγεθών, μπορείτε να συγχωνεύσετε τις διαφάνειες διατηρώντας τη μορφοποίηση.

### Μπορώ να δημιουργήσω μικρογραφίες για μεμονωμένα σχήματα ή συγκεκριμένες περιοχές μιας διαφάνειας, και θα τηρούν το νέο μέγεθος διαφάνειας;

Ναι. Το Aspose.Slides μπορεί να αποδώσει μικρογραφίες για [ολόκληρες διαφάνειες](https://reference.aspose.com/slides/el/cpp/aspose.slides/slide/getimage/) καθώς και για [επιλεγμένα σχήματα](https://reference.aspose.com/slides/el/cpp/aspose.slides/shape/getimage/). Οι παραγόμενες εικόνες αντανακλούν το τρέχον μέγεθος διαφάνειας και λόγο διαστάσεων, εξασφαλίζοντας συνεπή συνθέση και γεωμετρία.
