## **Εισαγωγή**

Στο PowerPoint 2019, η Microsoft εισήγαγε τη ρύθμιση **Always Open Read-Only** ως μία από τις επιλογές που μπορούν να χρησιμοποιήσουν οι χρήστες για να προστατεύσουν τις παρουσιάσεις τους. Μπορεί να θέλετε να χρησιμοποιήσετε αυτήν τη ρύθμιση Read-Only για να προστατεύσετε μια παρουσίαση όταν

- Θέλετε να αποτρέψετε τυχαίες επεμβάσεις και να διατηρήσετε το περιεχόμενο της παρουσίασής σας ασφαλές. 
- Θέλετε να ενημερώσετε τους ανθρώπους ότι η παρουσίαση που παρέχετε είναι η τελική έκδοση. 

Αφού επιλέξετε την επιλογή **Always Open Read-Only** για μια παρουσίαση, όταν οι χρήστες ανοίξουν την παρουσίαση, βλέπουν την πρόταση **Read-Only** και μπορεί να δούν ένα μήνυμα σε αυτή τη μορφή: *Για να αποτρέψετε τυχαίες αλλαγές, ο δημιουργός έχει ορίσει αυτό το αρχείο να ανοίγει μόνο για ανάγνωση.*

Η πρόταση Read-Only είναι μια απλή αλλά αποτελεσματική αποτρεπτική μέτρηση που αποθαρρύνει την επεξεργασία, καθώς οι χρήστες πρέπει να εκτελέσουν κάποιο βήμα για να την αφαιρέσουν πριν τους επιτραπεί η επεξεργασία μιας παρουσίασης. Εάν δεν θέλετε οι χρήστες να κάνουν αλλαγές σε μια παρουσίαση και θέλετε να το τους γνωστοποιήσετε με ευγενικό τρόπο, τότε η πρόταση Read-Only μπορεί να είναι μια καλή επιλογή για εσάς. 

> Εάν μια παρουσίαση με την προστασία **Read-Only** ανοίξει σε παλαιότερη εφαρμογή του Microsoft PowerPoint—η οποία δεν υποστηρίζει τη πρόσφατα εισαγόμενη λειτουργία—η πρόταση **Read-Only** αγνοείται (η παρουσίαση ανοίγει κανονικά).

## **Εφαρμογή Λειτουργίας Read-Only**

Το Aspose.Slides for C++ επιτρέπει να ορίσετε μια παρουσίαση σε **Read-Only**, πράγμα που σημαίνει ότι οι χρήστες (αφού ανοίξουν την παρουσίαση) βλέπουν την πρόταση **Read-Only**. Αυτό το παράδειγμα κώδικα δείχνει πώς να ορίσετε μια παρουσίαση σε **Read-Only** σε C++ χρησιμοποιώντας το Aspose.Slides:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>();
pres->get_ProtectionManager()->set_ReadOnlyRecommended(true);
pres->Save(u"ReadOnlyPresentation.pptx", SaveFormat::Pptx);
```

{{% alert color="info" %}} 
**Σημείωση**: Η πρόταση **Read-Only** προορίζεται απλώς να αποθαρρύνει την επεξεργασία ή να εμποδίσει τους χρήστες από τυχαίες αλλαγές σε μια παρουσίαση PowerPoint. Εάν ένα κίνητο άτομο—που ξέρει τι κάνει—αποφασίσει να επεξεργαστεί την παρουσίασή σας, μπορεί εύκολα να αφαιρέσει τη ρύθμιση Read-Only. Εάν χρειάζεστε σοβαρά την αποτροπή μη εξουσιοδοτημένης επεξεργασίας, είναι καλύτερο να χρησιμοποιήσετε [πιο αυστηρές προστασίες που περιλαμβάνουν κρυπτογραφήσεις και κωδικούς πρόσβασης](https://docs.aspose.com/slides/el/cpp/password-protected-presentation/). 
{{% /alert %}} 

## **Συχνές ερωτήσεις**

### Πώς διαφέρει το 'Read-Only recommended' από την πλήρη προστασία με κωδικό πρόσβασης;

Το 'Read-Only recommended' εμφανίζει μόνο μια πρόταση να ανοίξετε το αρχείο σε λειτουργία μόνο για ανάγνωση και είναι εύκολο να παρακαμφθεί. Η [Password protection](/slides/el/cpp/password-protected-presentation/) περιορίζει στην πραγματικότητα το άνοιγμα ή την επεξεργασία και είναι κατάλληλη όταν χρειάζεστε πραγματικό έλεγχο ασφαλείας.

### Μπορεί το 'Read-Only recommended' να συνδυαστεί με υδατογραφήματα για να αποθαρρυνθούν περαιτέρω οι επεμβάσεις;

Ναι. Η πρόταση μπορεί να συνδυαστεί με [watermarks](/slides/el/cpp/watermark/) ως οπτικό αποτρεπτικό μέσο· είναι ξεχωριστοί μηχανισμοί και λειτουργούν καλά μαζί.

### Μπορεί ένα μακροεντολή ή εξωτερικό εργαλείο ακόμη να τροποποιήσει το αρχείο όταν η πρόταση είναι ενεργοποιημένη;

Ναι. Η πρόταση δεν εμποδίζει προγραμματιστικές αλλαγές. Για να αποτρέψετε αυτόματες επεμβάσεις, χρησιμοποιήστε [passwords and encryption](/slides/el/cpp/password-protected-presentation/).

### Πώς σχετίζεται το 'Read-Only recommended' με τις σημαίες 'is encrypted' και 'is write protected';

Είναι διαφορετικά σήματα. Το 'Read-Only recommended' είναι ήπιο, προαιρετικό μήνυμα· τα [get_IsWriteProtected](https://reference.aspose.com/slides/el/cpp/aspose.slides/protectionmanager/get_iswriteprotected/) και [get_IsEncrypted](https://reference.aspose.com/slides/el/cpp/aspose.slides/protectionmanager/get_isencrypted/) υποδεικνύουν πραγματικούς περιορισμούς ανάγνωσης ή εγγραφής που εξαρτώνται από κωδικούς πρόσβασης ή κρυπτογράφηση.
