## **Επισκόπηση**

Αυτό το άρθρο εξηγεί πώς να εργάζεστε με μπάρες σφάλματος σε διαγράμματα παρουσίασης χρησιμοποιώντας το Aspose.Slides. Δείχνει πώς να προσθέσετε μπάρες σφάλματος σε μια σειρά διαγράμματος, να διαμορφώσετε τις ρυθμίσεις των μπάρων σφάλματος X και Y, και να εφαρμόσετε διαφορετικούς τύπους τιμών όπως σταθερές, ποσοστιαίες και προσαρμοσμένες τιμές.

Επίσης, παρουσιάζει πώς να αντιστοιχίσετε προσαρμοσμένες τιμές μπάρες σφάλματος για μεμονωμένα σημεία δεδομένων σε μια σειρά χρησιμοποιώντας τη σχετική συλλογή σημείων δεδομένων. Επιπλέον, το άρθρο περιλαμβάνει σύντομες σημειώσεις για το πώς οι μπάρες σφάλματος συμπεριφέρονται κατά την εξαγωγή, τη συμβατότητά τους με δείκτες και ετικέτες δεδομένων, καθώς και πού να βρείτε τις σχετικές κλάσεις και τις απαριθμήσεις του API.

## **Προσθήκη Μπαρών Σφάλματος**
Aspose.Slides για C++ παρέχει ένα απλό API για τη διαχείριση τιμών μπαρών σφάλματος. Ο δείγματος κώδικας εφαρμόζεται όταν χρησιμοποιείται προσαρμοσμένος τύπος τιμής. Για να καθορίσετε μια τιμή, χρησιμοποιήστε την ιδιότητα **ErrorBarCustomValues** ενός συγκεκριμένου σημείου δεδομένων στη συλλογή **DataPoints** της σειράς:

1. Δημιουργήστε ένα αντικείμενο της κλάσης [Presentation](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentation/).
2. Προσθέστε ένα διάγραμμα φυσαλίδας στη ζητούμενη διαφάνεια.
3. Πρόσβαση στην πρώτη σειρά διαγράμματος και ορίστε τη μορφή X για τη μπάρα σφάλματος.
4. Πρόσβαση στην πρώτη σειρά διαγράμματος και ορίστε τη μορφή Y για τη μπάρα σφάλματος.
5. Ορίστε τις τιμές και τη μορφή των μπαρών.

## **Προσθήκη Προσαρμοσμένων Μπαρών Σφάλματος**
Aspose.Slides για C++ παρέχει ένα απλό API για τη διαχείριση προσαρμοσμένων τιμών μπαρών σφάλματος. Ο δείγματος κώδικας εφαρμόζεται όταν η ιδιότητα **IErrorBarsFormat.ValueType** είναι ίση με **Custom**. Για να καθορίσετε μια τιμή, χρησιμοποιήστε την ιδιότητα **ErrorBarCustomValues** ενός συγκεκριμένου σημείου δεδομένων στη συλλογή **DataPoints** της σειράς:

1. Δημιουργήστε ένα αντικείμενο της κλάσης [Presentation](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentation/).
2. Προσθέστε ένα διάγραμμα φυσαλίδας στη ζητούμενη διαφάνεια.
3. Πρόσβαση στην πρώτη σειρά διαγράμματος και ορίστε τη μορφή X για τη μπάρα σφάλματος.
4. Πρόσβαση στην πρώτη σειρά διαγράμματος και ορίστε τη μορφή Y για τη μπάρα σφάλματος.
5. Πρόσβαση στα μεμονωμένα σημεία δεδομένων της σειράς διαγράμματος και ορισμός των τιμών της μπάρας σφάλματος για ένα μεμονωμένο σημείο δεδομένων της σειράς.
6. Ορίστε τις τιμές και τη μορφή των μπαρών.
7. Γράψτε την τροποποιημένη παρουσίαση σε αρχείο PPTX.

## **Συχνές Ερωτήσεις**

**Τι συμβαίνει με τις μπάρες σφάλματος όταν εξάγετε μια παρουσίαση σε PDF ή εικόνες;**

Αποδίδονται ως μέρος του διαγράμματος και διατηρούνται κατά τη μετατροπή μαζί με την υπόλοιπη μορφοποίηση του διαγράμματος, υπό την προϋπόθεση ότι χρησιμοποιείται συμβατή έκδοση ή μηχανή rendering.

**Μπορούν οι μπάρες σφάλματος να συνδυαστούν με δείκτες και ετικέτες δεδομένων;**

Ναι. Οι μπάρες σφάλματος είναι ξεχωριστό στοιχείο και είναι συμβατές με δείκτες και ετικέτες δεδομένων· εάν τα στοιχεία επικαλύπτονται, ενδέχεται να χρειαστεί να προσαρμόσετε τη μορφοποίηση.

**Πού μπορώ να βρω τη λίστα των ιδιοτήτων και των απαριθμήσεων για την εργασία με μπάρες σφάλματος στο API;**

Στην αναφορά API: η κλάση [ErrorBarsFormat](https://reference.aspose.com/slides/el/cpp/aspose.slides.charts/errorbarsformat/) και οι σχετικές απαριθμήσεις [ErrorBarType](https://reference.aspose.com/slides/el/cpp/aspose.slides.charts/errorbartype/) και [ErrorBarValueType](https://reference.aspose.com/slides/el/cpp/aspose.slides.charts/errorbarvaluetype/).
