## **Επισκόπηση**

Αυτό το άρθρο εξηγεί πώς να προσθέσετε γραμμές τάσης σε διαγράμματα παρουσίασης χρησιμοποιώντας το Aspose.Slides. Δείχνει πώς να δημιουργήσετε ένα διάγραμμα, να προσθέσετε γραμμές τάσης σε σειρές διαγράμματος και να εργαστείτε με διάφορους τύπους γραμμών τάσης, όπως εκθετική, γραμμική, λογαριθμική, κινούμενο μέσο, πολυωνυμική και δύναμη.

Περιγράφει επίσης πώς να προσθέσετε μια προσαρμοσμένη γραμμή σε ένα διάγραμμα εισάγοντας ένα σχήμα γραμμής και περιλαμβάνει μια σύντομη Συχνές Ερωτήσεις σχετικά με τις τιμές πρόβλεψης της γραμμής τάσης προς τα εμπρός και προς τα πίσω και αν οι γραμμές τάσης διατηρούνται κατά την εξαγωγή σε PDF ή SVG και κατά τη μετατροπή διαγραμμάτων σε εικόνες.

## **Προσθήκη Γραμμής Τάσης**
Το Aspose.Slides for C++ παρέχει ένα απλό API για τη διαχείριση διαφορετικών Γραμμών Τάσης διαγράμματος:

1. Δημιουργήστε μια实例 του [Παρουσίαση](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentation/) class.
2. Λάβετε μια αναφορά σε μια διαφάνεια με το δείκτη της.
3. Προσθέστε ένα διάγραμμα με προεπιλεγμένα δεδομένα μαζί με οποιονδήποτε επιθυμητό τύπο (το παράδειγμα χρησιμοποιεί ChartType.ClusteredColumn).
4. Προσθήκη της εκθετικής γραμμής τάσης για τη σειρά διαγράμματος 1.
5. Προσθήκη μιας γραμμής τάσης γραμμική για τη σειρά διαγράμματος 1.
6. Προσθήκη μιας λογαριθμικής γραμμής τάσης για τη σειρά διαγράμματος 2.
7. Προσθήκη γραμμής τάσης κινούμενου μέσου για τη σειρά διαγράμματος 2.
8. Προσθήκη μιας πολυωνυμικής γραμμής τάσης για τη σειρά διαγράμματος 3.
9. Προσθήκη μιας γραμμής τάσης δύναμης για τη σειρά διαγράμματος 3.
10. Γράψτε την τροποποιημένη παρουσίαση σε αρχείο PPTX.

Ο ακόλουθος κώδικας χρησιμοποιείται για τη δημιουργία διαγράμματος με Γραμμές Τάσης.

## **Προσθήκη Προσαρμοσμένης Γραμμής**
Το Aspose.Slides for C++ παρέχει ένα απλό API για την προσθήκη προσαρμοσμένων γραμμών σε ένα διάγραμμα. Για να προσθέσετε μια απλή ευθεία γραμμή σε μια επιλεγμένη διαφάνεια της παρουσίασης, ακολουθήστε τα παρακάτω βήματα:

- Δημιουργήστε μια实例 του κλάσης Presentation
- Λάβετε την αναφορά μιας διαφάνειας χρησιμοποιώντας το Index της
- Δημιουργήστε ένα νέο διάγραμμα χρησιμοποιώντας τη μέθοδο AddChart που εκτίθεται από το αντικείμενο Shapes
- Προσθέστε ένα AutoShape τύπου Line χρησιμοποιώντας τη μέθοδο AddAutoShape που εκτίθεται από το αντικείμενο Shapes
- Ορίστε το Χρώμα των γραμμών του σχήματος.
- Γράψτε την τροποποιημένη παρουσίαση ως αρχείο PPTX

Ο ακόλουθος κώδικας χρησιμοποιείται για τη δημιουργία διαγράμματος με Προσαρμοσμένες Γραμμές.

## **Συχνές Ερωτήσεις**

**Τι εννοούν τα 'forward' και 'backward' για μια γραμμή τάσης;**

Αυτά είναι τα μήκη της γραμμής τάσης που προβάλλονται προς τα εμπρός/πίσω: για διαγράμματα διασποράς (XY) — σε μονάδες άξονα· για μη-διασπορικά διαγράμματα — σε αριθμό κατηγοριών. Επιτρέπονται μόνο μη αρνητικές τιμές.

**Θα διατηρηθεί η γραμμή τάσης κατά την εξαγωγή της παρουσίασης σε PDF ή SVG ή κατά την μετατροπή μιας διαφάνειας σε εικόνα;**

Ναι. Το Aspose.Slides μετατρέπει τις παρουσιάσεις σε [PDF](/slides/el/cpp/convert-powerpoint-to-pdf/)/[SVG](/slides/el/cpp/render-a-slide-as-an-svg-image/) και αποδίδει διαγράμματα σε εικόνες· οι γραμμές τάσης, ως μέρος του διαγράμματος, διατηρούνται κατά αυτές τις λειτουργίες. Διατίθεται επίσης μέθοδος για [εξαγωγή εικόνας του διαγράμματος](/slides/el/cpp/create-shape-thumbnails/).
