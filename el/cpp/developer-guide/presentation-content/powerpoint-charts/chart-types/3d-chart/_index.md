## **Επισκόπηση**

Αυτό το άρθρο εξηγεί πώς να προσαρμόσετε ένα 3Δ γράφημα στο Aspose.Slides διαμορφώνοντας τις ρυθμίσεις `Rotation3D` όπως `RotationX`, `RotationY`, `DepthPercents` και `RightAngleAxes`. Περιγράφει τη δημιουργία μιας παρουσίασης, την προσθήκη ενός 3Δ γραφήματος με προεπιλεγμένα δεδομένα, την εφαρμογή των απαιτούμενων ρυθμίσεων προβολής 3Δ και την αποθήκευση της τροποποιημένης παρουσίασης ως αρχείο PPTX.

## **Ορίστε τις ιδιότητες RotationX, RotationY και DepthPercents σε ένα 3Δ γράφημα**

Το Aspose.Slides for C++ παρέχει ένα απλό API για τον ορισμό αυτών των ιδιοτήτων. Το ακόλουθο άρθρο θα σας βοηθήσει να ορίσετε διάφορες ιδιότητες όπως η περιστροφή X, Y, **DepthPercents** κλπ. Ο παραδειγματικός κώδικας εφαρμόζει τη ρύθμιση των προαναφερθέντων ιδιοτήτων.

1. Δημιουργήστε μια παρουσία του κλάσης[Presentation](https://reference.aspose.com/slides/el/cpp/aspose.slides/presentation/).
2. Αποκτήστε την πρώτη διαφάνεια.
3. Προσθέστε γράφημα με προεπιλεγμένα δεδομένα.
4. Ορίστε τις ιδιότητες Rotation3D.
5. Γράψτε την τροποποιημένη παρουσίαση σε αρχείο PPTX.

## **Συχνές ερωτήσεις**

**Ποιοι τύποι γραφημάτων υποστηρίζουν τη λειτουργία 3Δ στο Aspose.Slides;**

Το Aspose.Slides υποστηρίζει 3Δ παραλλαγές των διαγραμμάτων στήλης, συμπεριλαμβανομένων των Column 3D, Clustered Column 3D, Stacked Column 3D και 100% Stacked Column 3D, καθώς και συναφείς 3Δ τύπους που εκτίθενται μέσω της απαρίθμησης[ChartType](https://reference.aspose.com/slides/el/cpp/aspose.slides.charts/charttype/). Για μια ακριβή, ενημερωμένη λίστα, ελέγξτε τα μέλη του[ChartType](https://reference.aspose.com/slides/el/cpp/aspose.slides.charts/charttype/) στην τεκμηρίωση API της εγκατεστημένης έκδοσής σας.

**Μπορώ να λάβω μια ραστερ εικόνα ενός 3Δ γραφήματος για αναφορά ή web;**

Ναι. Μπορείτε να εξάγετε ένα γράφημα σε εικόνα μέσω του[chart API](https://reference.aspose.com/slides/el/cpp/aspose.slides/shape/getimage/) ή να[αποδώσετε ολόκληρη τη διαφάνεια](/slides/el/cpp/convert-powerpoint-to-png/) σε μορφές όπως PNG ή JPEG. Αυτό είναι χρήσιμο όταν χρειάζεστε μια απόλυτη προεπισκόπηση pixel-perfect ή θέλετε να ενσωματώσετε το γράφημα σε έγγραφα, πίνακες ελέγχου ή ιστοσελίδες χωρίς την ανάγκη PowerPoint.

**Πόσο αποδοτική είναι η δημιουργία και απόδοση μεγάλων 3Δ γραφημάτων;**

Η απόδοση εξαρτάται από τον όγκο των δεδομένων και την οπτική πολυπλοκότητα. Για τα καλύτερα αποτελέσματα, κρατήστε τα εφέ 3Δ στο ελάχιστο, αποφύγετε βαριές υφές σε τοίχους και περιοχές γραφήματος, περιορίστε τον αριθμό των σημείων δεδομένων ανά σειρά όταν είναι δυνατόν, και αποδώστε σε αρχείο εξόδου κατάλληλου μεγέθους (ανάλυση και διαστάσεις) ώστε να ταιριάζει με την προβλεπόμενη οθόνη ή τις ανάγκες εκτύπωσης.
