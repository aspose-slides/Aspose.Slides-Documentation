## **Επισκόπηση**

Το Aspose.Slides for Node.js via .NET είναι ένα πακέτο npm για αξιολόγηση και παραγωγή. Χωρίς άδεια, λειτουργεί σε λειτουργία αξιολόγησης. Αφού αγοράσετε άδεια ή λάβετε μια δωρεάν 30‑ήμερη προσωρινή άδεια, την εφαρμόζετε με μερικές γραμμές κώδικα και οι περιορισμοί αξιολόγησης δεν ισχύουν πια.

{{% alert color="info" title="Note" %}}
Γενικές πολιτικές σχετικά με την αξιολόγηση, την άδεια και την αγορά προϊόντων Aspose συλλέγονται στις [Πολιτικές Αγοράς και Συχνές Ερωτήσεις](https://purchase.aspose.com/policies). Οι τιμές αναφέρονται στη σελίδα [Πληροφορίες Τιμών](https://purchase.aspose.com/pricing/slides/family).
{{% /alert %}}

## **Περιορισμοί Έκδοσης Αξιολόγησης**

Η έκδοση αξιολόγησης παρέχει τη πλήρη λειτουργικότητα του προϊόντος, με δύο περιορισμούς:

- **Υδατογράφημα.** Κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύετε λαμβάνει ένα υδατογράφημα αξιολόγησης: ένα κλειδωμένο πλαίσιο κειμένου στο κέντρο της διαφάνειας που γράφει «Evaluation only». Το ίδιο υδατογράφημα εμφανίζεται στις εξαγωγές PDF, XPS και HTML και στις εικόνες διαφανειών.
- **Κομμένο κείμενο.** Το κείμενο που ο κώδικάς σας διαβάζει από ένα πλαίσιο κειμένου, παράγραφο ή τμήμα κόβεται στους πρώτους πέντε χαρακτήρες, ακολουθούμενο από την σημείωση «... text has been truncated due to evaluation version limitation.» Οι εξαγωγές Markdown και HTML5 κόβονται με τον ίδιο τρόπο. Το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρως.

[Αξιολογήστε το Aspose.Slides](/slides/el/nodejs-net/evaluate-aspose-slides/) περιγράφει αναλυτικά και τους δύο περιορισμούς και περιλαμβάνει ένα script που τους δείχνει.

{{% alert color="success" title="Tip" %}}
Για να δοκιμάσετε το Aspose.Slides χωρίς τους περιορισμούς αξιολόγησης, ζητήστε μια δωρεάν **30-ήμερη προσωρινή άδεια**. Δείτε [Πώς να λάβετε μια προσωρινή άδεια?](https://purchase.aspose.com/temporary-license) για λεπτομέρειες.
{{% /alert %}}

## **Σχετικά με την Άδεια**

Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα του προϊόντος, ο αριθμός των προγραμματιστών στους οποίους αδειοδοτείται και η ημερομηνία λήξης της συνδρομής. Το αρχείο είναι ψηφιακά υπογεγραμμένο, οπότε μην το τροποποιήσετε· ακόμη και μια επιπλέον γραμμή που προστίθεται κατά λάθος το ακυρώνει.

## **Εφαρμογή Άδειας**

Εφαρμόστε την άδεια με τη μέθοδο `setLicense` της κλάσης `License`. Καλέστε τη μία φορά ανά διεργασία, πριν δημιουργήσετε οποιοδήποτε αντικείμενο `Presentation`. Η επαναλαμβανόμενη κλήση δεν προκαλεί προβλήματα, αλλά επαναλαμβάνει εργασία που έχει ήδη γίνει.

Το παρακάτω script εφαρμόζει μια άδεια από ένα αρχείο με όνομα `Aspose.Slides.lic`. Αντικαταστήστε το όνομα με το όνομα ή την πλήρη διαδρομή του αρχείου άδειάς σας· το αρχείο μπορεί να έχει οποιοδήποτε όνομα.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { License } = asposeSlides;

const license = new License();
try {
    license.setLicense("Aspose.Slides.lic");
    console.log("License applied.");
} catch (error) {
    console.log("License not applied:", error.message);
}
```

Ένα όνομα αρχείου ή σχετική διαδρομή επιλύεται σε σχέση με το τρέχον φάκελο, αυτόν από τον οποίο εκτελείτε `node`. Διατηρήστε το αρχείο άδειας στο φάκελο του έργου σας και εκτελέστε τα scripts από εκεί, ή περάστε την πλήρη διαδρομή.

Εάν το αρχείο δεν βρεθεί ή δεν είναι έγκυρη άδεια, το `setLicense` ρίχνει σφάλμα και το Aspose.Slides παραμένει σε λειτουργία αξιολόγησης. Το script παγιδεύει το σφάλμα και εκτυπώνει το μήνυμά του. Για ένα απολεσθέν αρχείο, το μήνυμα ξεκινά με `License "Aspose.Slides.lic" doesn't exist or access is restricted.` και παραθέτει κάθε θέση που αναζητήθηκε.

Σε αυτό το πακέτο, η άδεια εφαρμόζεται μόνο από αρχείο. Το `License` δεν δέχεται ροή και το πακέτο δεν εκθέτει αδειοδότηση με μέτρηση. Για την κλάση που τυλίγει το πακέτο, δείτε [Άδεια](https://reference.aspose.com/slides/net/aspose.slides/license/) στην αναφορά API του Aspose.Slides για .NET.
