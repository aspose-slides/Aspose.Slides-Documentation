## **Υποστηριζόμενες Πλατφόρμες**
Το Aspose.Slides for Node.js via .NET είναι ένα ανεξάρτητο από την πλατφόρμα API. Μπορεί να χρησιμοποιηθεί σε οποιαδήποτε πλατφόρμα (Windows, Linux, macOS κ.λπ.) όπου είναι εγκατεστημένο το Node.js 7 ή νεότερο. Το Oracle JDK 8 ή νεότερο είναι άλλη απαίτηση.

## **Μορφές Αρχείων και Μετατροπές**
Το Aspose.Slides for Node.js via .NET υποστηρίζει τις περισσότερες μορφές εγγράφων PowerPoint. Σας επιτρέπει επίσης να τα εξάγετε στις δημοφιλείς μορφές αρχείων που χρησιμοποιούν οι οργανισμοί και μοιράζονται μεταξύ τους. Δείτε τις λεπτομέρειες:

|**Χαρακτηριστικό**|**Περιγραφή**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Το Aspose.Slides for Node.js via .NET παρέχει την πιο γρήγορη επεξεργασία για αυτήν τη μορφή εγγράφου παρουσίασης.| 
|PPT to PPTX conversion|Το Aspose.Slides for Node.js via .NET υποστηρίζει τη μετατροπή PPT σε PPTX|
|Portable Document Format (PDF)|Μπορείτε να εξάγετε όλες τις υποστηριζόμενες μορφές αρχείων σε έγγραφα Adobe Portable Document Format (PDF) με μία μόνο μέθοδο.|
|XML Parser Specification (XPS)|Μπορείτε να εξάγετε όλες τις υποστηριζόμενες μορφές αρχείων σε έγγραφα XML Parser Specification (XPS) με μία μόνο μέθοδο.|
|Tagged Image File Format (TIFF)|Μπορείτε να εξάγετε όλες τις υποστηριζόμενες μορφές αρχείων παρουσίασης σε μορφή Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Το Aspose.Slides for Node.js via .NET υποστηρίζει τη μετατροπή του PresentationEx σε μορφή HTML.|

## **Απόδοση Παρουσίασης**
Το Aspose.Slides for Node.js via .NET υποστηρίζει υψηλής πιστότητας απόδοση των διαφανειών σε παρουσίαση σε διαφορετικές μορφές γραφικών. Δείτε τις λεπτομέρειες:

|**Χαρακτηριστικό**|**Περιγραφή**|
| :- | :- |
|.NET Supported Image Formats|Χρησιμοποιώντας το Aspose.Slides for Node.js via .NET, μπορείτε να αποδίδετε διαφάνειες παρουσίασης και εικόνες στις διαφάνειες σε όλες τις μορφές γραφικών που υποστηρίζει το .NET, όπως TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Το Aspose.Slides for Node.js via .NET παρέχει επίσης ενσωματωμένες μεθόδους που σας επιτρέπουν να εξάγετε διαφάνειες παρουσίασης σε μορφές Scalable Vector Graphics (SVG).|

## **Λειτουργίες Περιεχομένου**
Το Aspose.Slides for Node.js via .NET σας επιτρέπει να έχετε πρόσβαση, να τροποποιήσετε ή να δημιουργήσετε σχεδόν όλα τα στοιχεία ή τα περιεχόμενα των εγγράφων παρουσίασης. Δείτε τις λεπτομέρειες:

|**Χαρακτηριστικό**|**Περιγραφή**|
| :- | :- |
|Master Slides|Οι κύριες διαφάνειες (Master Slides) ορίζουν τη διάταξη των κανονικών διαφανειών. Το Aspose.Slides for Node.js via .NET επιτρέπει την πρόσβαση και τροποποίηση των Master Slides των εγγράφων παρουσίασης.|
|Normal Slides|Με το Aspose.Slides for Node.js via .NET, μπορείτε να δημιουργήσετε νέες διαφάνειες διαφορετικών τύπων· μπορείτε επίσης να έχετε πρόσβαση και να τροποποιήσετε υπάρχουσες διαφάνειες στις παρουσιάσεις.|
|Cloning / Copying Slides|Υπάρχουν ενσωματωμένες μέθοδοι που παρέχονται από το Aspose.Slides for Node.js via .NET που σας επιτρέπουν να κλωνοποιήσετε ή να αντιγράψετε υπάρχουσες διαφάνειες σε μια παρουσίαση. Μπορείτε επίσης να χρησιμοποιήσετε τις αντιγραμμένες και κλωνοποιημένες διαφάνειες από μια παρουσίαση σε άλλη. Καθώς μια διαφάνεια κληρονομεί τη διάταξη της κύριας διαφάνειας, οι ενσωματωμένες μέθοδοι κλωνοποίησης αντιγράφουν αυτόματα την κύρια διαφάνεια κατά την κλωνοποίηση.|
|Managing Slides sections|Μέθοδοι για οργάνωση των διαφανειών σε διαφορετικές ενότητες μέσα σε μια παρουσίαση.|
|Place Holders and Text Holders|Μπορείτε να έχετε πρόσβαση στα placeholders και στα text holders σε μια διαφάνεια. Επιπλέον, μπορείτε να δημιουργήσετε μια διαφάνεια με text holders από το μηδέν χρησιμοποιώντας τη σχετική μέθοδο.|
|Header and Footers|Το Aspose.Slides for Node.js via .NET διευκολύνει τη διαχείριση των κεφαλίδων/υποσέλιδων στις διαφάνειες.|
|Notes in Slides|Με το Aspose.Slides for Node.js via .NET, μπορείτε να έχετε πρόσβαση και να τροποποιήσετε τις σημειώσεις που συνδέονται με μια διαφάνεια και επίσης να προσθέσετε νέες σημειώσεις.|
|Finding a Shape|Μπορείτε επίσης να βρείτε ένα συγκεκριμένο σχήμα σε μια διαφάνεια χρησιμοποιώντας το εναλλακτικό κείμενο που συνδέεται με το σχήμα.|
|Backgrounds|Το Aspose.Slides for Node.js via .NET σας επιτρέπει να εργάζεστε με φόντα που σχετίζονται με μια κύρια ή κανονική διαφάνεια σε μια παρουσίαση.| 
|Text Boxes|Τα πλαίσια κειμένου μπορούν να δημιουργηθούν από το μηδέν. Μπορείτε να έχετε πρόσβαση σε υπάρχοντα πλαίσια κειμένου. Μπορείτε επίσης να τροποποιήσετε το κείμενό τους χωρίς να χάσετε την αρχική μορφοποίηση.| 
|Rectangle Shapes|Μπορείτε να δημιουργήσετε ή να τροποποιήσετε σχήματα ορθογώνιων με το Aspose.Slides for Node.js via .NET.| 
|Poly Line Shapes|Μπορείτε να δημιουργήσετε ή να τροποποιήσετε σχήματα πολυγραμμής με το Aspose.Slides for Node.js via .NET.| 
|Ellipse Shapes|Μπορείτε να δημιουργήσετε ή να τροποποιήσετε σχήματα έλλειψης (Ellipse) με το Aspose.Slides for Node.js via .NET.| 
|Group Shapes|Το Aspose.Slides for Node.js via .NET υποστηρίζει ομαδικά σχήματα.| 
|Auto Shapes|Το Aspose.Slides for Node.js via .NET υποστηρίζει αυτόματα σχήματα.| 
|SmartArt|Το Aspose.Slides for Node.js via .NET παρέχει υποστήριξη για σχήματα SmartArt στο MS PowerPoint.| 
|Charts|Το Aspose.Slides for Node.js via .NET παρέχει υποστήριξη για διαγράμματα MSO στο PowerPoint.| 
|Shapes Serialization|Το Aspose.Slides for Node.js via .NET υποστηρίζει μεγάλο αριθμό σχημάτων. Όταν το Aspose.Slides for Node.js via .NET δεν υποστηρίζει κάποιο σχήμα, μπορείτε να χρησιμοποιήσετε μια μέθοδο σειριοποίησης μέσω της οποίας μπορείτε να σειριοποιήσετε αυτό το σχήμα από μία υπάρχουσα διαφάνεια. Με αυτόν τον τρόπο, μπορείτε να χρησιμοποιήσετε το σχήμα περαιτέρω σύμφωνα με τις απαιτήσεις σας.| 
|Picture Frames|Μπορείτε να διαχειριστείτε εικόνες σε πλαίσια εικόνας με το Aspose.Slides for Node.js via .NET.| 
|Audio Frames|Μπορείτε να συνδέσετε ή να ενσωματώσετε αρχεία ήχου σε audio frames σε διαφάνειες με το Aspose.Slides for Node.js via .NET.| 
|Video Frames|Μπορείτε να διαχειριστείτε αρχεία βίντεο σε video frames. Το Aspose.Slides for Node.js via .NET παρέχει επίσης υποστήριξη για συνδεδεμένα και ενσωματωμένα βίντεο.| 
|OLE Frame|Μπορείτε να διαχειριστείτε αντικείμενα OLE σε OLE frames με το Aspose.Slides for Node.js via .NET.| 
|Tables|Το Aspose.Slides for Node.js via .NET υποστηρίζει πίνακες σε διαφάνειες.| 
|ActiveX Controls|Υποστήριξη για ελέγχους ActiveX.| 
|VBA Macros|Υποστήριξη για διαχείριση μακροεντολών VBA εντός παρουσιάσεων.| 
|Text Frame|Μπορείτε να έχετε πρόσβαση στο κείμενο οποιουδήποτε σχήματος μέσω του πλαισίου κειμένου (text frame) που σχετίζεται με αυτό το σχήμα.| 
|Text Scanning|Μπορείτε να σαρώσετε κείμενο σε μια παρουσίαση σε επίπεδο παρουσίασης ή διαφάνειας μέσω ενσωματωμένων μεθόδων σάρωσης.| 
|Animations|Μπορείτε να εφαρμόσετε κίνηση σε σχήματα.| 
|Slide Shows|Το Aspose.Slides for Node.js via .NET υποστηρίζει παρουσιάσεις διαφανειών (slide shows) και μεταβάσεις διαφανειών.|

|**Χαρακτηριστικό**|**Περιγραφή**|
| :- | :- |
|Text Formatting|<p>Στο Aspose.Slides for Node.js via .NET, μπορείτε να διαχειριστείτε κείμενα μέσω των πλαισίων κειμένου (text frames) που σχετίζονται με τα σχήματα. Έτσι, μπορείτε να μορφοποιήσετε κείμενα χρησιμοποιώντας τις παραγράφους και τα τμήματα που σχετίζονται με τα πλαίσια κειμένου. Τα στοιχεία κειμένου μπορούν να μορφοποιηθούν μέσω του Aspose.Slides for Node.js via .NET.</p><p>- Τύπος γραμματοσειράς</p><p>- Μέγεθος γραμματοσειράς</p><p>- Χρώμα γραμματοσειράς</p><p>- Σκιάσεις γραμματοσειράς</p><p>- Στοίχιση παραγράφου</p><p>- Κουκίδες παραγράφου</p><p>- Προσανατολισμός παραγράφου</p>|
|Shape Formatting|<p>Στο Aspose.Slides for Node.js via .NET, το βασικό στοιχείο μιας διαφάνειας είναι ένα σχήμα.
