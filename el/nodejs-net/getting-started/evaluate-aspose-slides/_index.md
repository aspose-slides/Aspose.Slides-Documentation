## **Επισκόπηση**

Η έκδοση αξιολόγησης του Aspose.Slides για Node.js μέσω .NET είναι το ίδιο πακέτο npm με την άδεια έκδοση. Χωρίς άδεια, λειτουργεί σε κατάσταση αξιολόγησης: όλες οι δυνατότητες λειτουργούν, αλλά οι αποθηκευμένες παρουσιάσεις και οι περισσότερες εξαγωγές περιλαμβάνουν υδατογράφημα, και το κείμενο που διαβάζει ο κώδικάς σας περικόπτεται. Αυτό το άρθρο περιγράφει και τις δύο περιορισμούς και δείχνει πώς να τους αφαιρέσετε.

## **Περιορισμοί Αξιολόγησης**

**Υδατογράφημα αξιολόγησης σε κάθε διαφάνεια.** Όταν αποθηκεύετε μια παρουσίαση χωρίς άδεια, το Aspose.Slides προσθέτει ένα πλαίσιο κειμένου στη μέση κάθε διαφάνειας του αποθηκευμένου αρχείου. Το πλαίσιο κειμένου είναι κλειδωμένο και εμφανίζει το κείμενο «Evaluation only.» ακολουθούμενο από γραμμή προϊόντος και γραμμή πνευματικών δικαιωμάτων. Το υδατογράφημα ενσωματώνεται στο αποθηκευμένο αρχείο, όχι στην παρουσίαση στη μνήμη, και το άνοιγμα μιας παρουσίασης δεν προσθέτει νέο υδατογράφημα. Ωστόσο, ένα αρχείο που αποθηκεύτηκε σε κατάσταση αξιολόγησης περιέχει ήδη το πλαίσιο κειμένου· έτσι το άνοιγμα και η επαναποθήκευση του προσθέτουν δεύτερο υδατογράφημα σε κάθε διαφάνεια.

Το ίδιο υδατογράφημα σχεδιάζεται στην έξοδο όταν εξάγετε σε PDF, XPS ή HTML, ή αποδίδετε διαφάνειες ως εικόνες. Αν αποδώσετε μια παρουσίαση που είχε ήδη αποθηκευτεί σε κατάσταση αξιολόγησης, η εικόνα εμφανίζει τόσο το αποθηκευμένο υδατογράφημα όσο και το νεοσχεδιασμένο.

**Περικομμένο κείμενο όταν ο κώδικάς σας το διαβάζει.** Το κείμενο που διαβάζει ο κώδικάς σας μέσω της ιδιότητας `text` ενός πλαισίου κειμένου, παραγράφου ή τμήματος περικόπτεται στα πρώτα πέντε χαρακτήρες, ακολουθούμενο από την ειδοποίηση «... text has been truncated due to evaluation version limitation.» Κείμενο πέντε χαρακτήρων ή λιγότερο επιστρέφεται πλήρες. Αυτό ισχύει σε κάθε διαφάνεια και ακόμη και για κείμενο που μόλις έχετε ορίσει. Οι εξαγωγές σε Markdown και HTML5 περικόπτονται με τον ίδιο τρόπο.

Το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρες: τα αρχεία PPTX, οι σελίδες PDF και οι εικόνες διαφανειών περιέχουν το πλήρες κείμενο.

## **Δείτε τους Περιορισμούς σε Σενάριο**

Το παρακάτω σενάριο δείχνει και τους δύο περιορισμούς. Υποθέτει ότι έχετε εγκαταστήσει το πακέτο όπως περιγράφεται στην [Εγκατάσταση](/slides/el/nodejs-net/installation/) και ότι το εκτελείτε από το φάκελο του έργου. Προσθέτει ένα ορθογώνιο με μια πρόταση στην πρώτη διαφάνεια, διαβάζει την πρόταση πίσω, αποθηκεύει την παρουσίαση ως `evaluation.pptx`, και έπειτα ξανανοίγει το αρχείο για να μετρήσει τα σχήματα στη διαφάνεια.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { Presentation, ShapeType, SaveFormat } = asposeSlides;

const presentation = new Presentation();
try {
    const slide = presentation.slides.get(0);
    const rectangle = slide.shapes.addAutoShape(ShapeType.Rectangle, 50, 50, 500, 100);
    rectangle.textFrame.text = "Quarterly results are ready for review.";

    // Χωρίς άδεια, επιστρέφονται μόνο οι πρώτοι πέντε χαρακτήρες.
    console.log("Text read back:", rectangle.textFrame.text);

    // Η αποθήκευση προσθέτει το υδατογράφημα αξιολόγησης σε κάθε διαφάνεια του αρχείου.
    presentation.save("evaluation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}

const savedPresentation = new Presentation("evaluation.pptx");
try {
    // Η διαφάνεια τώρα περιέχει το ορθογώνιο και το πλαίσιο κειμένου του υδατογραφήματος.
    console.log("Shapes on the saved slide:", savedPresentation.slides.get(0).shapes.count);
} finally {
    savedPresentation.dispose();
}
```

Χωρίς άδεια, το σενάριο εμφανίζει:

```text
Text read back: Quart... text has been truncated due to evaluation version limitation.
Shapes on the saved slide: 2
```

Το δεύτερο σχήμα είναι το πλαίσιο κειμένου του υδατογραφήματος. Ανοίξτε το `evaluation.pptx` για να δείτε την πλήρη πρόταση στο ορθογώνιο και το υδατογράφημα στη μέση της διαφάνειας.

## **Συχνές Ερωτήσεις**

**Περιορίζει η κατάσταση αξιολόγησης τον αριθμό των διαφανειών;**

Όχι. Οι παρουσιάσεις δημιουργούνται, ανοίγονται και αποθηκεύονται με όλες τις διαφάνειές τους. Το υδατογράφημα και η περικοπή κειμένου εφαρμόζονται σε κάθε διαφάνεια με τον ίδιο τρόπο.

**Γιατί οι εξαγόμενες εικόνες των διαφανειών εμφανίζουν το υδατογράφημα δύο φορές;**

Η παρουσίαση αποθηκεύτηκε σε κατάσταση αξιολόγησης πριν την αποδώσετε, επομένως περιέχει ήδη ένα πλαίσιο κειμένου υδατογραφήματος, και η απόδοση χωρίς άδεια προσθέτει ένα ακόμα επάνω του.

**Μπορώ να ελέγξω ότι ο κώδικάς μου παράγει το σωστό κείμενο ενώ είμαι σε κατάσταση αξιολόγησης;**

Ναι. Ανοίξτε το αποθηκευμένο αρχείο ή το εξαγόμενο PDF: περιέχουν το πλήρες κείμενο. Μόνο το κείμενο που διαβάζει ο κώδικάς σας, καθώς και η έξοδος σε Markdown ή HTML5, περικόπτονται.
