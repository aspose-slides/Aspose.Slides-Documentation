## **Επισκόπηση**

Όταν μια παρουσίαση φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή, το Aspose.Slides ελέγχει εάν οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν λείπει κάποια απαιτούμενη γραμματοσειρά, το Aspose.Slides επιλέγει μια αντικαταστατική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποιούσε το PowerPoint.

Το Aspose.Slides πρώτα αναζητά τη σχεδιασμένη γραμματοσειρά στο λειτουργικό σύστημα. Εάν βρεθεί, χρησιμοποιείται. Εάν δεν βρεθεί, εφαρμόζεται μια κατάλληλη αντικατάσταση. Όταν οι κανόνες αντικατάστασης γραμματοσειρών ορίζονται μέσω [FontSubstRule](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsubstrule/), λαμβάνονται επίσης υπόψη.

Μπορείτε επίσης να προσθέσετε γραμματοσειρές κατά το χρόνο εκτέλεσης της εφαρμογής, να χρησιμοποιήσετε ενσωματωμένες γραμματοσειρές από μια παρουσίαση ή να φορτώσετε εξωτερικές γραμματοσειρές για έγγραφα εξόδου όπως αρχεία PDF.

## **Επιλογή γραμματοσειράς**

Ορισμένοι κανόνες ισχύουν για τις γραμματοσειρές σε μια παρουσίαση όταν αυτή φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή. Για παράδειγμα, όταν προσπαθείτε να μετατρέψετε μια παρουσίαση (τις διαφάνειές της) σε εικόνες, ελέγχονται οι γραμματοσειρές της παρουσίασης ώστε να επιβεβαιωθεί ότι οι επιλεγμένες γραμματοσειρές είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν οι γραμματοσειρές διαπιστωθούν ότι λείπουν, αντικαθίστανται — δείτε [Αντικατάσταση γραμματοσειράς](/slides/el/python-java/font-replacement/) και [Υποκατάσταση γραμματοσειράς](/slides/el/python-java/font-substitution/).

Αυτή είναι η διαδικασία που ακολουθεί το Aspose.Slides όταν διαχειρίζεται γραμματοσειρές:

1. Το Aspose.Slides αναζητά γραμματοσειρές στο λειτουργικό σύστημα για να βρει τη γραμματοσειρά που ταιριάζει με την επιλεγμένη γραμματοσειρά της παρουσίασης.
2. Εάν η επιλεγμένη γραμματοσειρά βρεθεί, το Aspose.Slides τη χρησιμοποιεί. Διαφορετικά, το Aspose.Slides χρησιμοποιεί μια αντικαταστατική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτή που θα χρησιμοποιούσε το PowerPoint.
3. Εάν έχουν οριστεί κανόνες αντικατάστασης γραμματοσειρών μέσω [FontSubstRule](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsubstrule/), εφαρμόζονται.

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές κατά το χρόνο εκτέλεσης της εφαρμογής και, στη συνέχεια, να τις χρησιμοποιήσετε. Δείτε [Προσαρμοσμένες γραμματοσειρές](/slides/el/python-java/custom-font/).

Όταν επιπρόσθετες γραμματοσειρές τοποθετούνται μέσα σε μια παρουσίαση, ονομάζονται [Ενσωματωμένες γραμματοσειρές](/slides/el/python-java/embedded-font/).

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές που εφαρμόζονται *μόνο* σε έγγραφα εξόδου. Για παράδειγμα, εάν μια παρουσίαση που θέλετε να μετατρέψετε σε PDF χρησιμοποιεί γραμματοσειρές που δεν είναι εγκατεστημένες στο σύστημά σας ούτε είναι ενσωματωμένες στην παρουσίαση, μπορείτε να προσθέσετε ή να φορτώσετε τις απαιτούμενες γραμματοσειρές ως **εξωτερικές γραμματοσειρές**.

{{% alert title="Note" color="info" %}}
Δεν διανέμουμε καμία γραμματοσειρά, είτε πληρωμένη είτε δωρεάν. Το API μας σας επιτρέπει να φορτώνετε εξωτερικές γραμματοσειρές και να τις ενσωματώνετε σε έγγραφα, αλλά το κάνετε με δική σας κρίση και ευθύνη.
{{% /alert %}}

## **Συχνές ερωτήσεις**

**Πώς μπορώ να καθορίσω ποιες γραμματοσειρές χρησιμοποιούνται πραγματικά σε μια παρουσίαση πριν από τη μετατροπή;**

Το Aspose.Slides σάς επιτρέπει να ελέγξετε τις χρησιμοποιούμενες γραμματοσειρές μέσω του [διαχειριστή γραμματοσειρών](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsmanager/), ώστε να αποφασίσετε αν θα [ενσωματώσετε](/slides/el/python-java/embedded-font/), [αντικαταστήσετε](/slides/el/python-java/font-replacement/) ή προσθέσετε [εξωτερικές πηγές](/slides/el/python-java/custom-font/). Αυτό σας βοηθά να αποτρέψετε ανεπιθύμητες αντικαταστάσεις κατά την απόδοση και την εξαγωγή.

**Μπορώ να προσθέσω πρόσθετους φακέλους γραμματοσειρών χωρίς να τους εγκαταστήσω στο λειτουργικό σύστημα;**

Ναι. Μπορείτε να καταχωρίσετε [εξωτερικές πηγές γραμματοσειρών](/slides/el/python-java/custom-font/) όπως φακέλους ή ροές μνήμης για απόδοση και εξαγωγή. Αυτό αφαιρεί την εξάρτηση από τις γραμματοσειρές του συστήματος υποδοχής και διατηρεί την διάταξη προβλέψιμη.

**Πώς αποτρέπω μια σιωπηρή πτώση σε ακατάλληλη γραμματοσειρά όταν λείπει ένα γλύφο;**

Ορίστε ρητά [αντικατάσταση γραμματοσειράς](/slides/el/python-java/font-replacement/) και κανόνες [εναλλακτικών γραμματοσειρών](/slides/el/python-java/fallback-font/) εκ των προτέρων. Αναλύοντας τις χρησιμοποιούμενες γραμματοσειρές και θέτοντας ελεγχόμενη προτεραιότητα για τις υποκαταστάσεις, διασφαλίζετε συνεπή τυπογραφία και αποφεύγετε ανεπιθύμητα αποτελέσματα.
