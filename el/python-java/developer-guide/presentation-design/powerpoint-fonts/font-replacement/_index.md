## **Επισκόπηση**

Aspose.Slides σας επιτρέπει να αντικαταστήσετε μια γραμματοσειρά με άλλη σε ολόκληρη την παρουσίαση. Όταν αντικαθίσταται μια γραμματοσειρά, όλες οι εμφανίσεις της αρχικής γραμματοσειράς αλλάζουν στη νέα γραμματοσειρά.

Για να πραγματοποιήσετε αντικατάσταση γραμματοσειράς, φορτώστε την παρουσίαση, ορίστε τη γραμματοσειρά προέλευσης και τη γραμματοσειρά αντικατάστασης, καλέστε τη μέθοδο αντικατάστασης γραμματοσειράς και αποθηκεύστε την τροποποιημένη παρουσίαση ως αρχείο PPTX. Αυτή η προσέγγιση είναι χρήσιμη όταν σκοπεύετε να αλλάξετε σκόπιμα από μία οικογένεια γραμματοσειρών σε άλλη σε όλη την παρουσίαση.

## **Αντικατάσταση Γραμματοσειρών**

Εάν αλλάξετε γνώμη σχετικά με τη χρήση μιας γραμματοσειράς, μπορείτε να την αντικαταστήσετε με άλλη γραμματοσειρά. Όλες οι εμφανίσεις της παλιάς γραμματοσειράς θα αντικατασταθούν από τη νέα γραμματοσειρά.

Aspose.Slides σας επιτρέπει να αντικαταστήσετε μια γραμματοσειρά με αυτόν τον τρόπο:

1. Φορτώστε την σχετική παρουσίαση. 
2. Φορτώστε τη γραμματοσειρά που θα αντικατασταθεί. 
3. Φορτώστε τη νέα γραμματοσειρά. 
4. Αντικαταστήστε τη γραμματοσειρά. 
5. Γράψτε την τροποποιημένη παρουσίαση ως αρχείο PPTX.

Αυτός ο κώδικας Python δείχνει την αντικατάσταση γραμματοσειράς:

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontData, Presentation, SaveFormat

# Φορτώστε μια παρουσίαση.
presentation = Presentation("Fonts.pptx")
try:
    # Φορτώστε τη γραμματοσειρά προέλευσης που θα αντικατασταθεί.
    source_font = FontData("Arial")

    # Φορτώστε τη νέα γραμματοσειρά.
    destination_font = FontData("Times New Roman")

    # Αντικαταστήστε τη γραμματοσειρά.
    presentation.getFontsManager().replaceFont(source_font, destination_font)

    # Αποθηκεύστε την παρουσίαση.
    presentation.save("UpdatedFont_out.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

Για να ορίσετε κανόνες που καθορίζουν τι συμβαίνει σε ορισμένες συνθήκες (π.χ. εάν δεν είναι δυνατή η πρόσβαση σε μια γραμματοσειρά), δείτε [Αντικατάσταση Γραμματοσειράς](/slides/el/python-java/font-substitution/).

## **Συχνές Ερωτήσεις**

**Ποια είναι η διαφορά μεταξύ «αντικατάστασης γραμματοσειράς», «αντικατάστασης γραμματοσειράς» και «εφεδρικών γραμματοσειρών»;**

Η αντικατάσταση είναι μια σκόπιμη αλλαγή από μία οικογένεια σε άλλη σε ολόκληρο το έγγραφο. Η [Αντικατάσταση](/slides/el/python-java/font-substitution/) είναι ένας κανόνας όπως «αν η γραμματοσειρά δεν είναι διαθέσιμη, χρησιμοποιήστε την X». Η [εφεδρική γραμματοσειρά](/slides/el/python-java/fallback-font/) εφαρμόζεται σε μεμονωμένα ελλιπή γλύφη όταν η βασική γραμματοσειρά είναι εγκατεστημένη αλλά δεν περιέχει τους απαιτούμενους χαρακτήρες.

**Ισχύει η αντικατάσταση στα master slides, layouts, notes και comments;**

Ναι. Η αντικατάσταση επηρεάζει όλα τα αντικείμενα παρουσίασης που χρησιμοποιούν την αρχική γραμματοσειρά, συμπεριλαμβανομένων των master slides και των σημειώσεων· τα σχόλια είναι επίσης μέρος του εγγράφου και λαμβάνονται υπόψη από τη μηχανή γραμματοσειρών.

**Θα αλλάξει η γραμματοσειρά μέσα σε ενσωματωμένα αντικείμενα OLE (π.χ. Excel);**

Όχι. Το [περιεχόμενο OLE](/slides/el/python-java/manage-ole/) ελέγχεται από τη δική του εφαρμογή. Η αντικατάσταση στην παρουσίαση δεν αναδιαμορφώνει τα εσωτερικά δεδομένα OLE· μπορεί να εμφανιστεί ως εικόνα ή ως εξωτερικά επεξεργάσιμο περιεχόμενο.

**Μπορώ να αντικαταστήσω μια γραμματοσειρά μόνο σε μέρος της παρουσίασης (κατά διαφάνειες ή περιοχές);**

Η στοχευμένη αντικατάσταση είναι εφικτή εάν αλλάξετε τη γραμματοσειρά στο επίπεδο των απαιτούμενων αντικειμένων/σειρών αντί να εφαρμόσετε καθολική αντικατάσταση σε όλο το έγγραφο. Η λογική επιλογής γραμματοσειράς κατά τη σχεδίαση παραμένει η ίδια.

**Πώς μπορώ να προσδιορίσω εκ των προτέρων ποιες γραμματοσειρές χρησιμοποιεί η παρουσίαση;**

Χρησιμοποιήστε το [διαχειριστή γραμματοσειρών](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsmanager/): παρέχει λίστα των [οικογενειών σε χρήση](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsmanager/#getFonts) και πληροφορίες για [αντικαταστάσεις/«άγνωστες» γραμματοσειρές](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsmanager/#getSubstitutions), που βοηθά στον προγραμματισμό της αντικατάστασης.

**Λειτουργεί η αντικατάσταση γραμματοσειράς κατά τη μετατροπή σε PDF/εικόνες;**

Ναι. Κατά την εξαγωγή, το Aspose.Slides εφαρμόζει την ίδια [ακολουθία επιλογής/αντικατάστασης γραμματοσειράς](/slides/el/python-java/font-selection-sequence/), οπότε μια εκ των προτέρων εκτελεσμένη αντικατάσταση θα τηρηθεί κατά τη μετατροπή.

**Πρέπει να εγκαταστήσω τη γραμματοσειρά-στόχο στο σύστημα ή μπορώ να επισυνάψω φάκελο γραμματοσειρών;**

Η εγκατάσταση δεν απαιτείται: η βιβλιοθήκη επιτρέπει [φόρτωση εξωτερικών γραμματοσειρών](/slides/el/python-java/custom-font/) από φακέλους χρήστη για χρήση κατά [σχεδίαση και εξαγωγή](/slides/el/python-java/convert-powerpoint/).

**Θα διορθώσει η αντικατάσταση το πρόβλημα «tofu» (τετράγωνα) αντί χαρακτήρων;**

Μόνο εάν η γραμματοσειρά-στόχος περιλαμβάνει πραγματικά τα απαιτούμενα γλύφη. Αν όχι, [ρυθμίστε την εφεδρική γραμματοσειρά](/slides/el/python-java/fallback-font/) για να καλύψετε τους ελλείποντες χαρακτήρες.
