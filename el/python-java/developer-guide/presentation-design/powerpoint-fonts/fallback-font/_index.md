## **Εισαγωγή**

Οι εναλλακτικές γραμματοσειρές χρησιμοποιούνται όταν η γραμματοσειρά που έχει οριστεί για το κείμενο είναι διαθέσιμη στο σύστημα αλλά δεν περιέχει το απαιτούμενο σύμβολο. Σε αυτήν την περίπτωση, το Aspose.Slides μπορεί να χρησιμοποιήσει μία από τις καθορισμένες εναλλακτικές γραμματοσειρές για να αντικαταστήσει το ελλιπές σύμβολο.

## **Εναλλακτική Γραμματοσειρά**

Το Aspose.Slides σάς επιτρέπει να δημιουργήσετε εναλλακτικές γραμματοσειρές, να τις προσθέσετε σε μια συλλογή εναλλακτικών γραμματοσειρών, να ορίσετε τη συλλογή εναλλακτικών γραμματοσειρών για μια συγκεκριμένη παρουσίαση, να αφαιρέσετε εναλλακτικές γραμματοσειρές από την παρουσίαση, να καθορίσετε τους κανόνες εφαρμογής εναλλακτικών γραμματοσειρών και να εκτελέσετε άλλες συναφείς λειτουργίες.

## **Συχνές Ερωτήσεις**

**Πώς διαφέρουν οι εναλλακτικές γραμματοσειρές από την αντικατάσταση γραμματοσειράς;**

Η εναλλακτική εφαρμόζεται ανά χαρακτήρα ή ανά περιοχή Unicode όταν η κύρια γραμματοσειρά λείπουν συγκεκριμένα σύμβολα· συμπληρώνει μόνο τους χαρακτήρες που λείπουν. [Αντικατάσταση](/slides/el/python-java/font-substitution/) αντικαθιστά μια ελλειπούσα ή μη διαθέσιμη γραμματοσειρά για ολόκληρη μια σειρά ή τμήμα κειμένου με άλλη γραμματοσειρά. Μπορούν να συνδυαστούν, αλλά το εύρος και η λογική επιλογής τους είναι διαφορετικά.

**Αποθηκεύονται οι ρυθμίσεις εναλλακτικής γραμματοσειράς μέσα στο αρχείο παρουσίασης;**

Όχι. Η διαμόρφωση εναλλακτικής γραμματοσειράς υπάρχει μόνο κατά τη διάρκεια της επεξεργασίας/απόδοσης στη βιβλιοθήκη και δεν σειριοποιείται στο PPTX. Η παρουσίαση δεν αποθηκεύει τους κανόνες εναλλακτικής γραμματοσειράς.

**Επηρεάζει η εναλλακτική γραμματοσειρά στοιχεία που δημιουργούνται από αντικείμενα PowerPoint (SmartArt, διαγράμματα, WordArt);**

Ναι. Το κείμενο μέσα σε αυτά τα αντικείμενα περνάει από την ίδια αλυσίδα απόδοσης, έτσι οι ίδιοι κανόνες εναλλακτικής γραμματοσειράς ισχύουν για αυτό όπως και για το κανονικό κείμενο.
