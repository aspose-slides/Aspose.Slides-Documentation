## **Εισαγωγή**

Τόσο η οπτική εμφάνιση όσο και η διαδραστική συμπεριφορά λαμβάνονται υπόψη όταν δημιουργούνται παρουσιάσεις.

**PowerPoint animation** παίζει σημαντικό ρόλο στο να κάνει μια παρουσίαση ελκυστική και ενδιαφέρουσα για τους θεατές. Το Aspose.Slides παρέχει ένα ευρύ φάσμα επιλογών για την προσθήκη κινήσεων σε παρουσιάσεις PowerPoint:

- Εφαρμόστε διάφορους τύπους εφέ κίνησης PowerPoint σε σχήματα, διαγράμματα, πίνακες, αντικείμενα OLE και άλλα στοιχεία παρουσίασης.
- Χρησιμοποιήστε πολλαπλά εφέ κίνησης PowerPoint σε ένα μόνο σχήμα.
- Χρησιμοποιήστε τη γραμμή χρόνου της κίνησης για να ελέγξετε τα εφέ κίνησης.
- Δημιουργήστε προσαρμοσμένες κινήσεις.

Στο Aspose.Slides, διάφορα εφέ κίνησης μπορούν να εφαρμοστούν σε σχήματα. Δεδομένου ότι κάθε στοιχείο σε μία διαφάνεια, συμπεριλαμβανομένου του κειμένου, των εικόνων, των αντικειμένων OLE και των πινάκων, θεωρείται σχήμα, τα εφέ κίνησης μπορούν να εφαρμοστούν σε οποιοδήποτε στοιχείο της διαφάνειας.

## **Εφέ Κίνησης**

Το Aspose.Slides υποστηρίζει **150+ εφέ κίνησης**, συμπεριλαμβανομένων βασικών εφέ όπως Bounce, PathFootball και Zoom, καθώς και συγκεκριμένων εφέ όπως OLEObjectShow και OLEObjectOpen. Μπορείτε να βρείτε μια πλήρη λίστα στην κλάση [EffectType](https://reference.aspose.com/slides/el/python-java/aspose.slides/effecttype/).

Επιπλέον, αυτά τα εφέ κίνησης μπορούν να χρησιμοποιηθούν σε συνδυασμό με τις ακόλουθες συμπεριφορές:

- [MotionEffect](https://reference.aspose.com/slides/el/python-java/aspose.slides/motioneffect/)

## **Προσαρμοσμένη Κίνηση**

Για πλήρη παραδείγματα Python μέσω Java που δημιουργούν, ελέγχουν και τροποποιούν συμπεριφορές και επεξεργάσιμες διαδρομές κίνησης, δείτε [Custom Animation](/slides/el/python-java/custom-animation/).

Είναι δυνατόν να δημιουργήσετε τις δικές σας **προσαρμοσμένες κινήσεις** στο Aspose.Slides. Αυτό μπορεί να επιτευχθεί συνδυάζοντας πολλές συμπεριφορές σε ένα νέο προσαρμοσμένο εφέ κίνησης.

[Behavior](https://reference.aspose.com/slides/el/python-java/aspose.slides/behavior/) είναι ένα δομικό στοιχείο ενός εφέ κίνησης PowerPoint. Συνδυάστε συμπεριφορές για να προσαρμόσετε ένα εφέ ή προσθέστε μια συμπεριφορά για να επεκτείνετε ένα προ‑καθορισμένο εφέ. Η επανάληψη ρυθμίζεται μέσω ρυθμίσεων χρόνου αντί για ξεχωριστή συμπεριφορά επανάληψης.

[Point](https://reference.aspose.com/slides/el/python-java/aspose.slides/point/) είναι το σημείο στο οποίο πρέπει να εφαρμοστεί μια συμπεριφορά.

## **Γραμμή Χρόνου Κίνησης**
[Sequence](https://reference.aspose.com/slides/el/python-java/aspose.slides/sequence/) είναι μια συλλογή εφέ κίνησης που μπορούν να στοχεύσουν διαφορετικά σχήματα.

[AnimationTimeLine](https://reference.aspose.com/slides/el/python-java/aspose.slides/animationtimeline/) είναι ένα σύνολο ακολουθιών που χρησιμοποιείται σε μια συγκεκριμένη διαφάνεια. Αντικατοπτρίζει τη μηχανή κινήσεων που εισήχθη στο PowerPoint 2002. Σε παλαιότερες εκδόσεις του PowerPoint, η προσθήκη εφέ κίνησης σε παρουσίαση ήταν δύσκολη και απαιτούσε εναλλακτικές λύσεις. Η γραμμή χρόνου προσφέρει πιο σαφή μοντέλο αντικειμένων για τις κινήσεις PowerPoint. Μία διαφάνεια μπορεί να έχει μόνο μία γραμμή χρόνου κίνησης.

## **FAQ**

**Will animations be preserved when exporting to PDF?**

Όχι. Το PDF είναι στατική μορφή, έτσι τα εφέ κίνησης και οι [slide transitions](/slides/el/python-java/slide-transition/) δεν εκτελούνται. Αν χρειάζεστε κίνηση, εξάγετε σε [HTML5](/slides/el/python-java/export-to-html5/), [animated GIF](/slides/el/python-java/convert-powerpoint-to-animated-gif/) ή [video](/slides/el/python-java/convert-powerpoint-to-video/) αντί αυτού.

**Can I turn an animated presentation into a video and control the frame rate and frame size?**

Ναι. Μπορείτε να [render the presentation as frames](/slides/el/python-java/convert-powerpoint-to-video/) και να τα κωδικοποιήσετε σε βίντεο (π.χ., μέσω ffmpeg), επιλέγοντας το FPS και την ανάλυση. Τα εφέ κίνησης και οι μεταβάσεις διαφανειών αναπαράγονται κατά την απόδοση.

**Will animations remain intact when working with ODP (not just PPTX)?**

Τα PPT, PPTX και ODP υποστηρίζονται για [reading](/slides/el/python-java/open-presentation/) και [writing](/slides/el/python-java/save-presentation/), αλλά αυτό δεν εγγυάται την διατήρηση των εφέ κίνησης. Τα δεδομένα προσαρμοσμένης κίνησης μπορούν να χαθούν κατά τη μετατροπή σε ODP. Δείτε το [Custom Animation](/slides/el/python-java/custom-animation/) για παραδείγματα και καθοδήγηση σχετικά με τον έλεγχο της συμβατότητας μορφής.
