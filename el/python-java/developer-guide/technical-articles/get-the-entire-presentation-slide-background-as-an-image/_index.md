## **Επισκόπηση**

Σε παρουσιάσεις PowerPoint, το φόντο μιας διαφάνειας μπορεί να αποτελείται από πολλαπλά στοιχεία, όπως η εικόνα φόντου της διαφάνειας, το θέμα της παρουσίασης, το χρωματικό σχήμα και τα αντικείμενα που τοποθετούνται στη διαφάνεια προτύπου ή στη διαφάνεια διάταξης.

Αυτό το άρθρο δείχνει πώς να εξάγετε ολόκληρο το φόντο της διαφάνειας ως εικόνα χρησιμοποιώντας το Aspose.Slides for Python via Java. Δεδομένου ότι δεν υπάρχει μια ενιαία μέθοδος για αυτήν την εργασία, η προσέγγιση περιλαμβάνει κλωνοποίηση της επιλεγμένης διαφάνειας σε μια προσωρινή παρουσίαση, αφαίρεση των σχημάτων της διαφάνειας και, στη συνέχεια, μετατροπή του προκύπτοντος φόντου της διαφάνειας σε εικόνα.

## **Απόκτηση ολόκληρου φόντου διαφάνειας**

Το Aspose.Slides for Python via Java δεν παρέχει απλή μέθοδο για εξαγωγή του πλήρους φόντου της διαφάνειας παρουσίασης ως εικόνα, αλλά μπορείτε να ακολουθήσετε τα παρακάτω βήματα:

1. Φορτώστε την παρουσίαση χρησιμοποιώντας την κλάση [Παρουσίαση](https://reference.aspose.com/slides/el/python-java/aspose.slides/presentation/).
1. Λάβετε το μέγεθος της διαφάνειας από την παρουσίαση.
1. Επιλέξτε μια διαφάνεια.
1. Δημιουργήστε μια προσωρινή παρουσίαση.
1. Ορίστε το ίδιο μέγεθος διαφάνειας στην προσωρινή παρουσίαση.
1. Κλωνοποιήστε τη επιλεγμένη διαφάνεια στην προσωρινή παρουσίαση.
1. Διαγράψτε τα σχήματα από τη κλωνοποιημένη διαφάνεια.
1. Μετατρέψτε τη κλωνοποιημένη διαφάνεια σε εικόνα.

Το παρακάτω παράδειγμα κώδικα εξάγει ολόκληρο το φόντο της διαφάνειας παρουσίασης ως εικόνα.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation, SlideSizeScaleType, ImageFormat

slide_index = 0
image_scale = 1.0

presentation = Presentation("sample.pptx")
try:
    slide_size = presentation.getSlideSize().getSize()
    slide = presentation.getSlides().get_Item(slide_index)

    temp_presentation = Presentation()
    try:
        slide_width = jpype.JFloat(slide_size.getWidth())
        slide_height = jpype.JFloat(slide_size.getHeight())
        temp_presentation.getSlideSize().setSize(slide_width, slide_height, SlideSizeScaleType.DoNotScale)

        cloned_slide = temp_presentation.getSlides().addClone(slide)
        cloned_slide.getShapes().clear()

        background = cloned_slide.getImage(image_scale, image_scale)
        try:
            background.save("output.png", ImageFormat.Png)
        finally:
            background.dispose()
    finally:
        temp_presentation.dispose()
finally:
    presentation.dispose()
```
