## **Επισκόπηση**

Αυτές οι Συχνές Ερωτήσεις καλύπτουν τα υποστηριζόμενα μορφότυπα αρχείων, τη χρήση μνήμης με μεγάλες παρουσιάσεις, τα μεγέθη και τις προεπισκοπήσεις των διαφανειών, την εξαγωγή κειμένου, τα σύνορα πινάκων, την τοποθέτηση εικόνων και τις διαφορές γραμματοσειρών κατά τη μετατροπή παρουσιάσεων σε PDF ή εικόνες.

## **ΣΥΧΝΕΣ ΕΡΩΤΗΣΕΙΣ**

### **Υποστηριζόμενα μορφότυπα αρχείων**

**Ποια μορφότυπα αρχείων υποστηρίζει το Aspose.Slides for Python via Java;**

Δείτε το [Μορφότυπα αρχείων που υποστηρίζονται](/slides/el/python-java/supported-file-formats/) για τα υποστηριζόμενα μορφότυπα παρουσιάσεων, εγγράφων και εικόνων καθώς και τις δυνατότητες εισαγωγής και εξαγωγής τους.

### **Εξαιρέσεις**

**Γιατί λαμβάνω σφάλμα έλλειψης μνήμης κατά τη φόρτωση μεγάλης παρουσίασης με εικόνες; Υπάρχει όριο μεγέθους αρχείου;**

Δεν υπάρχει ένα ενιαίο όριο μεγέθους αρχείου που να προβλέπει αν μια παρουσίαση θα χωρέσει στη μνήμη. Οι απαιτήσεις μνήμης εξαρτώνται από τη δομή της παρουσίασης, τις αποσυμπιεσμένες εικόνες, τα εφέ και τις ενέργειες που εκτελείτε. Οι εικόνες μπορούν να καταλαμβάνουν πολύ περισσότερη μνήμη από το συμπιεσμένο μέγεθός τους στο δίσκο.

Το Aspose.Slides for Python via Java χρησιμοποιεί τη μηχανή Java μέσω JPype, επομένως η δέσμη μνήμης (heap) του JVM πρέπει να έχει αρκετό χώρο για την επεξεργασία. Η διαθεσιμότητα μνήμης RAM του συστήματος από μόνη της δεν δείχνει πόση μνήμη μπορεί να χρησιμοποιήσει το JVM. Αποδεσμεύστε τις παρουσιάσεις με [Presentation.dispose](https://reference.aspose.com/slides/el/python-java/aspose.slides/presentation/#dispose) όταν τελειώσετε τη χρήση τους. Για τη ρύθμιση του περιβάλλοντος, δείτε τις [System Requirements](/slides/el/python-java/system-requirements/) και την [Installation](/slides/el/python-java/installation/).

### **Εργασία με διαφάνειες**

**Μπορώ να αλλάξω το μέγεθος των διαφανειών σε μια παρουσίαση;**

Ναι. Χρησιμοποιήστε το [Presentation.getSlideSize](https://reference.aspose.com/slides/el/python-java/aspose.slides/presentation/#getslidesize) για να αποκτήσετε πρόσβαση στις ρυθμίσεις μεγέθους διαφανειών της παρουσίασης, έπειτα χρησιμοποιήστε το [SlideSize.setSize](https://reference.aspose.com/slides/el/python-java/aspose.slides/slidesize/#setsize) για να ορίσετε τις διαστάσεις και να επιλέξετε πώς κλιμακώνεται το υπάρχον περιεχόμενο.

**Μπορούν οι διαφάνειες στην ίδια παρουσίαση να έχουν διαφορετικά μεγέθη;**

Όχι. Τα έγγραφα Microsoft PowerPoint ορίζουν το μέγεθος της διαφάνειας σε επίπεδο παρουσίασης, οπότε όλες οι διαφάνειες μοιράζονται τις ίδιες διαστάσεις.

**Μπορώ να προεπισκοπήσω μια διαφάνεια πριν αποθηκεύσω την παρουσίαση;**

Ναι. Αποδώστε τη διαφάνεια σε εικόνα και εμφανίστε αυτήν την εικόνα στην εφαρμογή σας. Δεν χρειάζεται να αποθηκεύσετε πρώτα την παρουσίαση.

### **Εργασία με κείμενο**

**Μπορώ να ανακτήσω όλο το κείμενο από μια παρουσίαση;**

Ναι. Η κλάση [SlideUtil](https://reference.aspose.com/slides/el/python-java/aspose.slides/slideutil/) παρέχει μεθόδους για την ανάκτηση κειμένου από παρουσιάσεις και μεμονωμένες διαφάνειες.

**Γιατί τα μεγέθη παραγράφων είναι διαφορετικά στα Windows και Linux;**

Οι διαστάσεις της παραγράφου εξαρτώνται από τις μετρικές των γραμματοσειρών που χρησιμοποιούνται για την απόδοση του κειμένου. Εάν λείπει μια γραμματοσειρά, η υποκατάσταση ενδέχεται να έχει διαφορετικά πλάτη χαρακτήρων και ύψος γραμμών, γεγονός που αλλάζει την αναδίπλωση των γραμμών και τις διαστάσεις της παραγράφου. Εγκαταστήστε τις ίδιες γραμματοσειρές και στα δύο συστήματα ή φορτώστε τα ίδια αρχεία γραμματοσειρών με το [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsloader/#loadexternalfonts) πριν δημιουργήσετε ή φορτώσετε παρουσιάσεις.

### **Μορφοποίηση και εικόνες**

**Πώς μπορώ να ορίσω το χρώμα του περιγράμματος ενός πίνακα;**

Χρησιμοποιήστε το [Cell.getCellFormat](https://reference.aspose.com/slides/el/python-java/aspose.slides/cell/#getcellformat) για να αποκτήσετε πρόσβαση στη μορφοποίηση του περιγράμματος κάθε κελιού και να ορίσετε το χρώμα γεμίσματος για τα σχετικά περιγράμματα. Για να αλλάξετε κάθε περίγραμμα, επεξεργαστείτε όλα τα κελιά. Για να αλλάξετε μόνο το εξωτερικό περίγραμμα του πίνακα, ενημερώστε μόνο τα περιγράμματα που κοιτάζουν προς τα έξω των κελιών κατά μήκος των άκρων του.

**Ποιες μονάδες χρησιμοποιούνται για την τοποθέτηση και το μέγεθος των εικόνων;**

Οι συντεταγμένες και οι διαστάσεις των σχημάτων μετριούνται σε σημεία (points). Ένα ίντσα ισούται με 72 σημεία· αυτές οι τιμές δεν είναι συντεταγμένες εικονοστοιχείων (pixel).

### **Εργασία με γραμματοσειρές**

**Γιατί αλλάζουν οι γραμματοσειρές όταν μετατρέπω μια παρουσίαση σε PDF ή εικόνες;**

Οι απαιτούμενες γραμματοσειρές ενδέχεται να λείπουν από το μηχάνημα που εκτελεί τη μετατροπή. Εγκαταστήστε τις αρχικές γραμματοσειρές ή χρησιμοποιήστε το [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/el/python-java/aspose.slides/fontsloader/#loadexternalfonts) για να προσθέσετε φακέλους που τις περιέχουν. Φορτώστε εξωτερικές γραμματοσειρές πριν δημιουργήσετε ή ανοίξετε παρουσιάσεις.

Το παρακάτω παράδειγμα καταχωρεί έναν φάκελο γραμματοσειρών. Αντικαταστήστε τη διαδρομή με έναν υπάρχοντα φάκελο που περιέχει τα αρχεία γραμματοσειρών σας. Υποθέτει το περιβάλλον που περιγράφεται στην [Installation](/slides/el/python-java/installation/).

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontsLoader

font_folders = jpype.JArray(jpype.JString)(["path_to_a_folder_with_fonts"])
FontsLoader.loadExternalFonts(font_folders)
```

Το παράδειγμα αφήνει το JVM σε λειτουργία για επακόλουθες λειτουργίες παρουσίασης. Για χρήση σε σημειωματάρια και περιορισμούς του κύκλου ζωής του JVM, δείτε τις [Limitations and API Differences](/slides/el/python-java/limitations-and-api-differences/).
