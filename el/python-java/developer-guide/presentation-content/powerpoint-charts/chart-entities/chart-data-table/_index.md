## **Επισκόπηση**

Αυτό το άρθρο εξηγεί πώς να εργάζεστε με πίνακες δεδομένων διαγραμμάτων στο Aspose.Slides. Δεικνύει πώς να εμφανίσετε έναν πίνακα δεδομένων για ένα διάγραμμα και να προσαρμόσετε τη μορφοποίηση του κειμένου του ορίζοντας ιδιότητες γραμματοσειράς όπως έντονη γραφή και ύψος γραμματοσειράς. Το παράδειγμα παρουσιάζει τη δημιουργία μιας παρουσίασης, την προσθήκη ενός διαγράμματος, την ενεργοποίηση του πίνακα δεδομένων του διαγράμματος, την εφαρμογή ρυθμίσεων γραμματοσειράς και την αποθήκευση της ενημερωμένης παρουσίασης.

Περιλαμβάνει επίσης σύντομες απαντήσεις σε συχνές ερωτήσεις σχετικά με την εμφάνιση κλειδιών υπομνήματος σε πίνακα δεδομένων διαγράμματος, τη διατήρηση του πίνακα κατά την εξαγωγή, την εργασία με διαγράμματα που φορτώνονται από υπάρχουσες παρουσιάσεις ή πρότυπα, και την ταυτοποίηση διαγραμμάτων όπου ο πίνακας δεδομένων είναι ενεργοποιημένος.

## **Ορισμός Ιδιοτήτων Γραμματοσειράς για Πίνακα Δεδομένων Διαγράμματος**

Το Aspose.Slides for Python via Java σας επιτρέπει να εμφανίσετε τον πίνακα δεδομένων ενός διαγράμματος και να αλλάξετε τις ιδιότητες γραμματοσειράς του κειμένου του.

1. Δημιουργήστε ένα αντικείμενο της κλάσης [Presentation](https://reference.aspose.com/slides/el/python-java/aspose.slides/presentation/).
1. Προσθέστε ένα διάγραμμα στη διαφάνεια.
1. Εμφανίστε τον πίνακα δεδομένων του διαγράμματος.
1. Ορίστε το έντονο στυλ και το ύψος γραμματοσειράς του κειμένου του πίνακα δεδομένων.
1. Αποθηκεύστε την τροποποιημένη παρουσίαση.

Το παρακάτω παράδειγμα παρουσιάζει αυτά τα βήματα.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import ChartType, NullableBool, Presentation, SaveFormat

# Δημιουργία κενής παρουσίασης.
presentation = Presentation()
try:
    chart = presentation.getSlides().get_Item(0).getShapes().addChart(ChartType.ClusteredColumn, 50, 50, 600, 400)

    chart.setDataTable(True)

    portion_format = chart.getChartDataTable().getTextFormat().getPortionFormat()
    portion_format.setFontBold(NullableBool.True_)
    portion_format.setFontHeight(20)

    presentation.save("output.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

## **Συχνές Ερωτήσεις**

**Μπορώ να εμφανίσω μικρά κλειδιά υπομνήματος δίπλα στις τιμές στον πίνακα δεδομένων του διαγράμματος;**

Ναι. Ο πίνακας δεδομένων υποστηρίζει [κλειδιά υπομνήματος](https://reference.aspose.com/slides/el/python-java/aspose.slides/datatable/#setShowLegendKey), και μπορείτε να τα ενεργοποιήσετε ή να τα απενεργοποιήσετε.

**Θα διατηρηθεί ο πίνακας δεδομένων κατά την εξαγωγή της παρουσίασης σε PDF, HTML ή εικόνες;**

Ναι. Το Aspose.Slides αποδίδει το διάγραμμα ως μέρος της διαφάνειας, έτσι το εξαχθέν [PDF](/slides/el/python-java/convert-powerpoint-to-pdf/)/[HTML](/slides/el/python-java/convert-powerpoint-to-html/)/[image](/slides/el/python-java/convert-powerpoint-to-png/) περιλαμβάνει το διάγραμμα με τον πίνακα δεδομένων του.

**Υποστηρίζονται πίνακες δεδομένων για διαγράμματα που προέρχονται από αρχείο προτύπου;**

Ναι. Για κάθε διάγραμμα που φορτώνεται από υπάρχουσα παρουσίαση ή πρότυπο, μπορείτε να ελέγξετε και να αλλάξετε αν ένας πίνακας δεδομένων [είναι εμφανισμένος](https://reference.aspose.com/slides/el/python-java/aspose.slides/chart/#hasDataTable) χρησιμοποιώντας τις ιδιότητες του διαγράμματος.

**Πώς μπορώ γρήγορα να βρω ποια διαγράμματα σε ένα αρχείο έχουν ενεργοποιημένο τον πίνακα δεδομένων;**

Εξετάστε την ιδιότητα κάθε διαγράμματος που υποδηλώνει αν ο πίνακας δεδομένων [είναι εμφανισμένος](https://reference.aspose.com/slides/el/python-java/aspose.slides/chart/#hasDataTable) και περάστε όλες τις διαφάνειες για να εντοπίσετε τα διαγράμματα όπου είναι ενεργοποιημένος.
