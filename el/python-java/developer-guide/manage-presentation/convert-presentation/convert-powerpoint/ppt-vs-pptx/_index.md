## **Επισκόπηση**

PPT και PPTX είναι μορφές παρουσιάσεων PowerPoint με διαφορετικές εσωτερικές δομές και υποστήριξη χαρακτηριστικών. Το PPT είναι η κληρονομική δυαδική μορφή που χρησιμοποιούταν στο PowerPoint 97–2003. Το PPTX είναι η μορφή Office Open XML που εισήχθη με το PowerPoint 2007. Αυτό το άρθρο συγκρίνει τις μορφές και δείχνει πώς να μετατρέψετε ένα αρχείο PPT σε PPTX με το Aspose.Slides for Python via Java.

## **Τι είναι το PPT;**

[PPT](https://docs.fileformat.com/presentation/ppt/) αποθηκεύει δεδομένα παρουσίασης σε δυαδική δομή. Η ανάγνωση ή η τροποποίηση του περιεχομένου του απαιτεί λογισμικό που καταλαβαίνει αυτή τη δομή. Το PPT είναι χρήσιμο όταν ανταλλάσσετε αρχεία με παλαιότερες εκδόσεις του PowerPoint, αλλά η δυνατότητά του να αντιπροσωπεύει νεότερα χαρακτηριστικά παρουσίασης είναι περιορισμένη.

## **Τι είναι το PPTX;**

[PPTX](https://docs.fileformat.com/presentation/pptx/) βασίζεται στο Office Open XML. Ένα αρχείο PPTX είναι ένα πακέτο ZIP που περιέχει XML μέρη, πολυμέσα και σχέσεις μεταξύ αυτών των μερών. Αυτή η δομή κάνει τη μορφή πιο εύκολη στην επισκόπηση και την επέκταση σε σύγκριση με το δυαδικό PPT. Το PowerPoint χρησιμοποιεί PPTX ως προεπιλεγμένη μορφή παρουσίασης από το PowerPoint 2007.

## **PPT vs PPTX**

| Πτυχή | PPT | PPTX |
| --- | --- | --- |
| Εσωτερική δομή | Δυαδικές εγγραφές | Πακέτο ZIP με XML και πολυμέσα |
| Τυπικές απαιτήσεις συμβατότητας | Ροές εργασίας PowerPoint 97–2003 | Ροές εργασίας PowerPoint 2007 και μετά |
| Νεότερα χαρακτηριστικά παρουσίασης | Περιορισμένη υποστήριξη· ορισμένο περιεχόμενο μπορεί να απλοποιηθεί | Ευρύτερη υποστήριξη για νεότερα αντικείμενα και εφέ |
| Συνιστώμενη χρήση | Ανταλλαγή με συστήματα που απαιτούν PPT | Νέες παρουσιάσεις και συνεχή επεξεργασία |

Η μετατροπή μεταξύ των μορφών απαιτεί περισσότερα από μια αλλαγή στην επέκταση του αρχείου. Ορισμένα χαρακτηριστικά του PPTX δεν έχουν άμεσο ισοδύναμο στο PPT. Το PowerPoint μπορεί να αποθηκεύσει πρόσθετες πληροφορίες σε ειδικές εγγραφές PPT, όπως δεδομένα MetroBlob, για να διατηρήσει το νεότερο περιεχόμενο για μελλοντική χρήση. Οι παλαιότερες εκδόσεις του PowerPoint δεν μπορούν να εμφανίσουν όλο αυτό το περιεχόμενο, επομένως η αποθήκευση του δεν εγγυάται ότι μια παρουσίαση θα φαίνεται ή θα συμπεριφέρεται το ίδιο σε κάθε προβολέα.

Aspose.Slides for Python via Java παρέχει ένα κοινό API για τη φόρτωση και αποθήκευση και των δύο μορφών. Υποστηρίζει τη μετατροπή και προς τις δύο κατευθύνσεις, αλλά οι διαφορές μορφής και τα μη υποστηριζόμενα χαρακτηριστικά μπορούν να επηρεάσουν το αποτέλεσμα. Προτιμήστε το PPTX όπου είναι δυνατόν και ελέγξτε τις παρουσιάσεις που έχουν μετατραπεί σε PPT στον προγραμματισμένο προβολέα.

## **Μετατροπή PPT σε PPTX με Python**

Φορτώστε το αρχείο PPT με την κλάση [Presentation](https://reference.aspose.com/slides/el/python-java/aspose.slides/presentation/) και κατόπιν καλέστε [Presentation.save](https://reference.aspose.com/slides/el/python-java/aspose.slides/presentation/#save) με το [SaveFormat.Pptx](https://reference.aspose.com/slides/el/python-java/aspose.slides/saveformat/#Pptx). Δεν απαιτείται το Microsoft PowerPoint.

Το παράδειγμα ξεκινά τη εικονική μηχανή Java αν χρειαστεί και απελευθερώνει τους πόρους παρουσίασης σε ένα μπλοκ `finally`. Αντικαταστήστε τις διαδρομές εισόδου και εξόδου με τα δικά σας ονόματα αρχείων.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat

# Φορτώστε την παλαιά παρουσίαση PPT.
presentation = Presentation("presentation.ppt")
try:
    # Αποθηκεύστε την παρουσίαση σε μορφή PPTX.
    presentation.save("presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

Για περισσότερα παραδείγματα, δείτε τη σελίδα [Convert PPT to PPTX in Python](/slides/el/python-java/convert-ppt-to-pptx/). Για την αντίστροφη μετατροπή και τις σχετικές παραμέτρους συμβατότητας, δείτε τη σελίδα [Convert PPTX to PPT in Python](/slides/el/python-java/convert-pptx-to-ppt/).

**Υπάρχει λόγος να διατηρώ παλιές παρουσιάσεις σε PPT αν ανοίγουν χωρίς σφάλματα;**

Μπορείτε να διατηρήσετε το PPT όταν απαιτείται από μια υπάρχουσα ροή εργασίας. Για συνεχή επεξεργασία και νεότερα χαρακτηριστικά, σκεφτείτε τη [μετατροπή σε PPTX](/slides/el/python-java/convert-ppt-to-pptx/). Κρατήστε το αρχικό αρχείο μέχρι να ελέγξετε τη μετατραπείσα παρουσίαση.

**Ποιες παρουσιάσεις πρέπει να μετατρέψω πρώτα σε PPTX;**

Δώστε προτεραιότητα σε αρχεία που επεξεργάζονται ή μοιράζονται συχνά, περιέχουν σύνθετα [charts](/slides/el/python-java/create-chart/) ή [shapes](/slides/el/python-java/shape-manipulations/), ή προκαλούν προειδοποιήσεις συμβατότητας όταν [opened](/slides/el/python-java/open-presentation/). Ελέγξτε την εμφάνιση και τη συμπεριφορά παρουσίασης μετά τη μετατροπή.

Μην υποθέτετε ότι η προστασία εξόδου ταιριάζει αυτόματα με την πηγή. Παρέχετε τον απαιτούμενο κωδικό πρόσβασης όταν φορτώνετε κρυπτογραφημένο αρχείο, ρυθμίστε ρητά την προστασία εξόδου και επαληθεύστε το αποθηκευμένο αρχείο. Δείτε τη σελίδα [Password‑Protected Presentations](/slides/el/python-java/password-protected-presentation/).

**Γιατί ορισμένα εφέ εξαφανίζονται ή απλοποιούνται όταν μετατρέπουμε PPTX σε PPT;**

Το PPT δεν μπορεί να αναπαραστήσει κάθε νέο αντικείμενο, ιδιότητα ή εφέ. Ορισμένες πληροφορίες μπορεί να διατηρηθούν για μελλοντική αποκατάσταση, αλλά οι παλαιότεροι προβολείς δεν μπορούν να εμφανίσουν όλα τα δεδομένα. Διατηρήστε το αρχικό PPTX όταν χρειάζεται να διατηρήσετε τα νεότερα χαρακτηριστικά.
