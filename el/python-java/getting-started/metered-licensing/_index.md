## **Εισαγωγή**

Η χρεωστική άδεια είναι ένας μηχανισμός αδειοδότησης που μπορεί να χρησιμοποιηθεί παράλληλα με τις υπάρχουσες μεθόδους αδειοδότησης. Εάν θέλετε να χρεώνεστε με βάση τη χρήση των λειτουργιών του Aspose.Slides API, επιλέξτε χρεωστική άδεια.

## **Εφαρμογή Κλειδιών Χρεώσεων**

{{% alert color="info" title="Note" %}}

Η χρεωστική άδεια είναι ένας νέος μηχανισμός αδειοδότησης που μπορεί να χρησιμοποιηθεί παράλληλα με τις υπάρχουσες μεθόδους αδειοδότησης. Εάν θέλετε να χρεώνεστε με βάση τη χρήση των λειτουργιών του Aspose.Slides API, επιλέξτε χρεωστική άδεια.

Όταν αγοράζετε μια χρεωστική άδεια, λαμβάνετε κλειδιά (και όχι αρχείο άδειας). Αυτό το κλειδί χρέωσης μπορεί να εφαρμοστεί χρησιμοποιώντας την κλάση [Metered](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/) που παρέχει η Aspose για λειτουργίες χρέωσης. Για περισσότερες λεπτομέρειες, δείτε το [Metered Licensing FAQ](https://purchase.aspose.com/faqs/licensing/metered).

{{% /alert %}}

1. Δημιουργήστε μια παρουσία της κλάσης [Metered](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/).

1. Περάστε τα δημόσια και ιδιωτικά κλειδιά σας στη μέθοδο [setMeteredKey](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/#setMeteredKey).

1. Εκτελέστε κάποια επεξεργασία (εκτελέστε εργασίες).

1. Καλέστε τη μέθοδο [getConsumptionQuantity](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/#getConsumptionQuantity) της κλάσης [Metered](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/).

Θα πρέπει να δείτε το ποσό/πόσο των αιτήσεων API που έχετε καταναλώσει μέχρι τώρα.

Αυτός ο κώδικας δείχνει πώς να χρησιμοποιήσετε τη χρεωστική άδεια:

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Metered

# Δημιουργήστε μια παρουσία της κλάσης Metered.
metered = Metered()

try:
    # Περάστε τα δημόσια και ιδιωτικά κλειδιά στο αντικείμενο Metered.
    metered.setMeteredKey("<valid public key>", "<valid private key>")

    # Λάβετε την καταναλημένη ποσότητα πριν από τις κλήσεις API.
    amount_before = Metered.getConsumptionQuantity()
    print("Amount consumed before:", amount_before)

    # Κάντε κάτι με το API του Aspose.Slides εδώ.
    # ...

    # Λάβετε την καταναλημένη ποσότητα μετά τις κλήσεις API.
    amount_after = Metered.getConsumptionQuantity()
    print("Amount consumed after:", amount_after)
except Exception as error:
    print(error)
```

{{% alert color="warning" title="Warning"  %}}

Για να χρησιμοποιήσετε τη χρεωστική άδεια, χρειάζεστε μια σταθερή σύνδεση στο διαδίκτυο, επειδή ο μηχανισμός αδειοδότησης χρησιμοποιεί το διαδίκτυο για συνεχή αλληλεπίδραση με τις υπηρεσίες μας και για υπολογισμούς.

{{% /alert %}}

## **Συχνές Ερωτήσεις**

**Μπορώ να χρησιμοποιήσω μια χρεωστική άδεια μαζί με μια κανονική (μόνιμη ή προσωρινή) στην ίδια εφαρμογή;**

Ναι. Η χρεωστική είναι ένας επιπρόσθετος μηχανισμός αδειοδότησης που μπορεί να χρησιμοποιηθεί παράλληλα με τις υπάρχουσες [μεθόδους αδειοδότησης](/slides/el/python-java/licensing/). Επιλέγετε ποιος μηχανισμός θα εφαρμοστεί όταν η εφαρμογή ξεκινά.

**Τι ακριβώς μετριέται ως κατανάλωση σε μια χρεωστική άδεια: λειτουργίες ή αρχεία;**

Η χρήση του API μετριέται, δηλαδή ο αριθμός των αιτήσεων ή των λειτουργιών. Μπορείτε να λάβετε την τρέχουσα κατανάλωση μέσω των [μεθόδων παρακολούθησης κατανάλωσης](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/).

**Είναι η χρεωστική κατάλληλη για μικροϋπηρεσίες και περιβάλλοντα serverless όπου οι εκτελέσεις επανεκκινώνται συχνά;**

Ναι. Καθώς η λογιστική γίνεται σε επίπεδο κλήσης API, τα σενάρια με συχνές ψυχρές εκκινήσεις είναι συμβατά, εφόσον υπάρχει σταθερή πρόσβαση δικτύου για τους υπολογισμούς της χρέωσης.

**Διαφέρουν οι λειτουργίες της βιβλιοθήκης όταν χρησιμοποιείται χρεωστική άδεια σε σύγκριση με μόνιμη άδεια;**

Όχι. Αφορά μόνο τον μηχανισμό αδειοδότησης και χρέωσης· οι δυνατότητες του προϊόντος παραμένουν οι ίδιες.

**Πώς σχετίζεται η χρεωστική με την έκδοση δοκιμής και την προσωρινή άδεια;**

Η έκδοση δοκιμής έχει περιορισμούς και υδατογραφήματα, η [προσωρινή άδεια](https://purchase.aspose.com/temporary-license/) αφαιρεί περιορισμούς για 30 ημέρες, και η χρεωστική αφαιρεί περιορισμούς και χρεώνει βάσει πραγματικής χρήσης.

**Μπορώ να ελέγξω τον προϋπολογισμό αν ενεργοποιήσω αυτόματα μια ενέργεια όταν ξεπεραστεί ένα όριο κατανάλωσης;**

Ναι. Ένα συνηθισμένο pattern είναι η περιοδική ανάγνωση της τρέχουσας κατανάλωσης μέσω [μεθόδων παρακολούθησης](https://reference.aspose.com/slides/el/python-java/aspose.slides/metered/) και η υλοποίηση των δικών σας ορίων ή ειδοποιήσεων στο επίπεδο της εφαρμογής ή της παρακολούθησης.
