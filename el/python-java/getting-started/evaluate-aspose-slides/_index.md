Μπορείτε να κατεβάσετε το Aspose.Slides για Python μέσω Java για να αξιολογήσετε τις δυνατότητές του. Το πακέτο αξιολόγησης είναι πανομοιότυπο με το πακέτο με άδεια. Για να το χρησιμοποιήσετε χωρίς περιορισμούς αξιολόγησης, προσθέστε μερικές γραμμές κώδικα για να εφαρμόσετε μια άδεια.

Η έκδοση αξιολόγησης του Aspose.Slides (χρησιμοποιούμενη χωρίς άδεια) παρέχει πλήρη λειτουργικότητα του προϊόντος, αλλά εισάγει ένα υδατογράφημα αξιολόγησης στην κορυφή του εγγράφου όταν το ανοίγετε ή το αποθηκεύετε. Η εξαγωγή κειμένου περιορίζεται σε μία διαφάνεια ανά παρουσίαση.
