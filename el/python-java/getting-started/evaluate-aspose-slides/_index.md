Μπορείτε να κατεβάσετε το Aspose.Slides for Python via Java για να αξιολογήσετε τις δυνατότητές του. Το πακέτο αξιολόγησης είναι πανομοιότυπο με το πακέτο με άδεια. Για να το χρησιμοποιήσετε χωρίς περιορισμούς αξιολόγησης, προσθέστε μερικές γραμμές κώδικα στο [εφαρμογή άδειας](/slides/el/python-java/licensing/).

Η έκδοση αξιολόγησης του Aspose.Slides (χρησιμοποιείται χωρίς άδεια) παρέχει πλήρη λειτουργικότητα του προϊόντος, με δύο περιορισμούς:

- Προσθέτει ένα πλαίσιο κειμένου με υδατογράφημα αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει. Το άνοιγμα μιας παρουσίασης δεν προσθέτει κανένα, αλλά η αποθήκευση ενός αρχείου που ήδη περιέχει το υδατογράφημα προσθέτει ένα ακόμη.
- Το κείμενο που διαβάζει ο κώδικάς σας περικόπτεται στα πρώτα του λίγα χαρακτήρες, ακολουθούμενο από ειδοποίηση σχετικά με τον περιορισμό αξιολόγησης. Αυτό ισχύει για κάθε διαφάνεια, καθώς και για το κείμενο που ο κώδικάς σας μόλις ορίσει, καθώς και για το κείμενο που φορτώνεται από αρχείο. Το κείμενο που ο κώδικάς σας γράφει αποθηκεύεται πλήρως.

{{% alert color="info" title="Note" %}}
Για να δοκιμάσετε το Aspose.Slides χωρίς περιορισμούς αξιολόγησης, μπορείτε να ζητήσετε μια **αδειοδότηση προσωρινή 30 ημερών**. Δείτε το [Πάρε μια προσωρινή άδεια](https://purchase.aspose.com/temporary-license) για περισσότερες πληροφορίες.
