## **Επισκόπηση**

Aspose.Slides for Python via Java διαβάζει και γράφει παρουσιάσεις PowerPoint και OpenDocument. Επίσης εισάγει περιεχόμενο PDF και HTML σε διαφάνειες και εξάγει παρουσιάσεις ή μεμονωμένες διαφάνειες σε μορφές εγγράφων, ιστού και εικόνων.

Ο παρακάτω πίνακας διαχωρίζει τη φόρτωση παρουσίασης από την εισαγωγή περιεχομένου και την απόδοση διαφάνειας. Για επισκόπηση των δυνατοτήτων επεξεργασίας και απόδοσης, δείτε [Features Overview](/slides/el/python-java/features-overview/).

## **Υποστηριζόμενες εκδόσεις Microsoft PowerPoint**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac
- PowerPoint for Microsoft 365 (formerly Office 365)

## **Σημειώσεις εισαγωγής και εξαγωγής**

- **PDF και HTML εισαγωγή:** Χρησιμοποιήστε [SlideCollection.addFromPdf](https://reference.aspose.com/slides/el/python-java/aspose.slides/slidecollection/#addfrompdf) ή [SlideCollection.addFromHtml](https://reference.aspose.com/slides/el/python-java/aspose.slides/slidecollection/#addfromhtml) για δημιουργία διαφανειών από το πηγαίο περιεχόμενο και προσθήκη τους σε μια παρουσίαση.
- **Έξοδος παρουσίασης:** [SaveFormat](https://reference.aspose.com/slides/el/python-java/aspose.slides/saveformat/) παραθέτει τις διαθέσιμες μορφές αποθήκευσης παρουσίασης, συμπεριλαμβανομένων ξεχωριστών επιλογών εξαγωγής σε HTML και HTML5.
- **Έξοδος εικόνας:** Η εξαγωγή μιας διαφάνειας σε εικόνα παράγει μια οπτική αναπαράσταση της διαφάνειας. Η στήλη εισόδου δεν περιγράφει εάν μια εικόνα μπορεί να εισαχθεί σε παρουσίαση.

## **Συχνές ερωτήσεις**

**Μπορώ να μετατρέψω μια παρουσίαση PPT σε PPTX ή ODP;**

Ναι. Το PPT υποστηρίζεται ως μορφή εισόδου, ενώ τόσο το PPTX όσο και το ODP υποστηρίζονται ως μορφές εξόδου. Τα αποτελέσματα της μετατροπής εξαρτώνται από τις δυνατότητες που διατίθενται στη μορφή προορισμού.

**Η εισαγωγή PDF ή HTML ανοίγει το πηγαίο αρχείο ως αρχείο PowerPoint;**

Όχι. Η εισαγωγή δημιουργεί διαφάνειες από τις σελίδες PDF ή το περιεχόμενο HTML. Στη συνέχεια μπορείτε να αποθηκεύσετε την προκύπτουσα παρουσίαση σε μια υποστηριζόμενη μορφή παρουσίασης.

**Μπορώ να φορτώσω ένα εξαγόμενο PNG ή SVG ως επεξεργάσιμη παρουσίαση;**

Όχι. Αυτές οι εξαγωγές αντιπροσωπεύουν την εμφάνιση της διαφάνειας. Διατηρήστε την αρχική παρουσίαση όταν χρειαστεί να επεξεργαστείτε το κείμενο, τα σχήματα, τα γραφήματα και άλλα αντικείμενα αργότερα.
