## **Επισκόπηση**

Αυτό το άρθρο δείχνει πώς να εργαστείτε με ένα διάγραμμα δακτυλίου στο Aspose.Slides προσθέτοντας το διάγραμμα σε μια διαφάνεια, ορίζοντας το μέγεθος της κεντρικής τρύπας και αποθηκεύοντας την παρουσίαση. Επικεντρώνεται στη μέθοδο `setDoughnutHoleSize` και παρουσιάζει τα βασικά βήματα που απαιτούνται για την προσαρμογή αυτού του τύπου διαγράμματος με κώδικα.

Περιλαμβάνει επίσης μια σύντομη ενότητα Συχνών Ερωτήσεων (FAQ) που καλύπτει σχετικές περιπτώσεις διαγραμμάτων δακτυλίου, όπως η χρήση πολλαπλών σειρών για τη δημιουργία πολλαπλών δαχτυλιδιών, η εργασία με εκρήγνυμενα διαγράμματα δακτυλίου και η εξαγωγή ενός διαγράμματος ως εικονογραφία raster ή SVG.

## **Καθορίστε το κεντρικό κενό σε ένα διάγραμμα δακτυλίου**
{{% alert color="info" %}} 
Το Aspose.Slides για Java υποστηρίζει πλέον τον καθορισμό του μεγέθους της τρύπας σε ένα διάγραμμα δακτυλίου. Σε αυτό το θέμα, θα δούμε με παράδειγμα πώς να ορίσουμε το μέγεθος της τρύπας σε ένα διάγραμμα δακτυλίου.
{{% /alert %}} 

Για να καθορίσετε το μέγεθος της τρύπας σε ένα διάγραμμα δακτυλίου, ακολουθήστε τα παρακάτω βήματα:

1. Δημιουργήστε ένα αντικείμενο [Presentation](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentation).
1. Προσθέστε διάγραμμα δακτυλίου στη διαφάνεια.
1. Καθορίστε το μέγεθος της τρύπας σε ένα διάγραμμα δακτυλίου.
1. Αποθηκεύστε την παρουσίαση στο δίσκο.

Στο παρακάτω παράδειγμα, έχουμε ορίσει το μέγεθος της τρύπας σε ένα διάγραμμα δακτυλίου.

```java
import com.aspose.slides.*;

// Δημιουργήστε ένα στιγμιότυπο της κλάσης Presentation
Presentation pres = new Presentation();
try {
    IChart chart = pres.getSlides().get_Item(0).getShapes().addChart(ChartType.Doughnut, 50, 50, 400, 400);
    
    chart.getChartData().getSeriesGroups().get_Item(0).setDoughnutHoleSize((byte)90);

    // Αποθηκεύστε την παρουσίαση στο δίσκο
    pres.save("DoughnutHoleSize_out.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **Συχνές Ερωτήσεις**

### Μπορώ να δημιουργήσω ένα πολυεπίπεδο διάγραμμα δακτυλίου με πολλαπλά δαχτυλίδια;

Ναι. Προσθέστε πολλαπλές σειρές σε ένα μόνο διάγραμμα δακτυλίου — κάθε σειρά γίνεται ξεχωριστό δαχτυλίδι. Η σειρά των δαχτυλιδιών καθορίζεται από τη σειρά των σειρών στη συλλογή.

### Υποστηρίζεται ένα «εκρήγνυμενο» διάγραμμα δακτυλίου (διαχωριστά κομμάτια);

Ναι. Υπάρχει ο τύπος διαγράμματος Exploded Doughnut [chart type](https://reference.aspose.com/slides/el/java/com.aspose.slides/charttype/) και μια ιδιότητα έκρηξης στα σημεία δεδομένων· μπορείτε να διαχωρίσετε μεμονωμένα κομμάτια.

### Πώς μπορώ να αποκτήσω μια εικόνα ενός διαγράμματος δακτυλίου (PNG/SVG) για αναφορά;

Ένα διάγραμμα είναι ένα σχήμα· μπορείτε να το αποδώσετε ως [raster image](https://reference.aspose.com/slides/el/java/com.aspose.slides/shape/#getImage-int-float-float-) ή να το εξάγετε σε [SVG image](https://reference.aspose.com/slides/el/java/com.aspose.slides/shape/#writeAsSvg-java.io.OutputStream-com.aspose.slides.ISVGOptions-).
