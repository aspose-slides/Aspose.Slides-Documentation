## **Εισαγωγή**

Το εναλλακτικό κείμενο βοηθά άτομα που χρησιμοποιούν βοηθητικές τεχνολογίες να κατανοήσουν το νόημα των εικόνων, των διαγραμμάτων και άλλων ενημερωτικών σχημάτων. Αυτό το άρθρο εξηγεί πώς να διαβάσετε και να ενημερώσετε τους τίτλους και τις περιγραφές εναλλακτικού κειμένου με το Aspose.Slides for Java, να διακρίνετε τις περιγραφές προσβασιμότητας από τα ονόματα σχημάτων που χρησιμοποιούνται στον κώδικα και να ελέγξετε εάν ένα σχήμα έχει σημασθεί ως διακοσμητικό.

Αυτά τα χαρακτηριστικά υποστηρίζουν την προσβασιμότητα των παρουσιάσεων, αλλά δεν την εγγυώνται. Η σειρά ανάγνωσης, η αντίθεση χρωμάτων, η αναγνωσιμότητα του κειμένου και άλλες απαιτήσεις προσβασιμότητας επίσης χρειάζονται έλεγχο.

## **Διαχείριση Τίτλων και Περιγραφών Εναλλακτικού Κειμένου**

Χρησιμοποιήστε εναλλακτικό κείμενο για να εξηγήσετε το νόημα των εικόνων, των διαγραμμάτων και άλλων ενημερωτικών σχημάτων σε άτομα που δεν μπορούν να τα δουν. Οι παρακάτω μέθοδοι και περιεχόμενα εξυπηρετούν διαφορετικούς σκοπούς:

| Μέθοδος ή περιεχόμενο | Σκοπός |
| --- | --- |
| [getAlternativeTextTitle](https://reference.aspose.com/slides/el/java/com.aspose.slides/ishape/#getAlternativeTextTitle--) | Ένας σύντομος τίτλος για την εναλλακτική περιγραφή. |
| [getAlternativeText](https://reference.aspose.com/slides/el/java/com.aspose.slides/ishape/#getAlternativeText--) | Μια σημαντική περιγραφή του περιεχομένου ή του σκοπού του σχήματος στο πλαίσιο της διαφάνειας. |
| [getName](https://reference.aspose.com/slides/el/java/com.aspose.slides/ishape/#getName--) | Το όνομα του σχήματος, το οποίο μπορεί να χρησιμοποιήσει ο κώδικας για να βρει ένα συγκεκριμένο σχήμα στην παρουσίαση. |
| Visible text | Περιεχόμενο που εμφανίζεται στη διαφάνεια, όπως το κείμενο ενός σχήματος ή ο τίτλος και οι ετικέτες ενός διαγράμματος. Η ενημέρωση του εναλλακτικού κειμένου δεν αλλάζει αυτό το περιεχόμενο. |

Όταν μια παρουσίαση επαναχρησιμοποιείται ως πρότυπο, ο κώδικας μπορεί να βρει ένα σχήμα με το όνομα που επιστρέφει το [getName](https://reference.aspose.com/slides/el/java/com.aspose.slides/ishape/#getName--) πριν το ενημερώσει. Αυτό το όνομα εξυπηρετεί διαφορετικό σκοπό από το εναλλακτικό κείμενο, το οποίο εξηγεί τι επικοινωνεί το οπτικό στοιχείο στον αναγνώστη. Η αναζήτηση με βάση το όνομα επιτρέπει στους συγγραφείς να βελτιώσουν ή να μεταφράσουν τις περιγραφές χωρίς να αλλάξουν τον τρόπο με τον οποίο ο κώδικας εντοπίζει το σχήμα. Τα ονόματα μπορούν να επεξεργαστούν και δεν εγγυώνται μοναδικότητα, επομένως ελέγξτε ότι το όνομα ταιριάζει με το προοριζόμενο σχήμα· δείτε [Identify and Find Shapes](/slides/el/java/shape-manipulations/#identify-and-find-shapes).

Το παρακάτω παράδειγμα απαιτεί `input.pptx` με μια εικόνα μιας εισόδου γραφείου ως το πρώτο σχήμα στην πρώτη διαφάνεια. Η εικόνα δεν πρέπει να είναι σημειωμένη ως διακοσμητική. Το παράδειγμα διαβάζει και εκτυπώνει τον τρέχοντα τίτλο και την περιγραφή του εναλλακτικού κειμένου, ενημερώνει και τις δύο τιμές και αποθηκεύει την παρουσίαση ως `output.pptx`. Προσαρμόστε τη διατύπωση στην πραγματική εικόνα και τις πληροφορίες που μεταφέρει.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);

    System.out.println("Alternative text title: " + shape.getAlternativeTextTitle());
    System.out.println("Alternative text description: " + shape.getAlternativeText());

    shape.setAlternativeTextTitle("Office entrance");
    shape.setAlternativeText("The office entrance has a wheelchair ramp to the right of the steps.");

    presentation.save("output.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

Η προσθήκη εναλλακτικού κειμένου από μόνη της δεν εγγυάται προσβασιμότητα της παρουσίασης ή συμμόρφωση με τα πρότυπα προσβασιμότητας. Εξετάστε τις περιγραφές για ακρίβεια και συνάφεια, καθώς επίσης ελέγξτε τη σειρά ανάγνωσης, την αντίθεση χρωμάτων, το αναγνώσιμο κείμενο και άλλες απαιτήσεις προσβασιμότητας. Τα ενημερωτικά οπτικά στοιχεία δεν πρέπει να σημειώνονται ως διακοσμητικά· η επόμενη ενότητα δείχνει πώς να ελέγξετε το [isDecorative](https://reference.aspose.com/slides/el/java/com.aspose.slides/ishape/#isDecorative--).

## **Σήμανση ως Διακοσμητικό**

Σημειώστε ως διακοσμητικό τα καθαρά διακοσμητικά οπτικά στοιχεία ώστε οι αναγνώστες οθόνης να τα παραλείπουν, μειώνοντας το «θόρυβο» και διατηρώντας την εστίαση στο ουσιώδες περιεχόμενο. Εφαρμόστε το σε φόντους, διακοσμητικά στοιχεία και κενά· ποτέ σε διαγράμματα, εικονίδια ή εικόνες που μεταφέρουν πληροφορίες. Το Aspose.Slides εκθέτει αυτή τη σημαία για ανίχνευση και επικύρωση, επιτρέποντας αυτοματοποιημένους ελέγχους προσβασιμότητας και καθαρισμό.

![Σήμανση ως Διακοσμητικό](mark_as_decorative.png)

Ο παρακάτω κώδικας δείχνει πώς να προσδιορίσετε εάν ένα σχήμα είναι σημειωμένο ως διακοσμητικό.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("sample.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);
    System.out.println("Is shape decorative: " + shape.isDecorative());
} finally {
    presentation.dispose();
}
```

## **Συχνές Ερωτήσεις**

**Τι πρέπει να βάλω στον τίτλο και την περιγραφή του εναλλακτικού κειμένου;**

Χρησιμοποιήστε έναν σύντομο τίτλο για να προσδιορίσετε το θέμα και μια περιγραφή για να εξηγήσετε τις πληροφορίες που μεταφέρει το οπτικό στοιχείο στο πλαίσιο της διαφάνειας. Για ένα διάγραμμα, περιγράψτε τη σχετική τάση ή σύγκριση αντί να λέτε μόνο «διάγραμμα».

**Πρέπει να χρησιμοποιώ το εναλλακτικό κείμενο για τον εντοπισμό σχημάτων σε ένα πρότυπο;**

Προτιμήστε τον εντοπισμό του σχήματος με το όνομα που επιστρέφει το [getName](https://reference.aspose.com/slides/el/java/com.aspose.slides/ishape/#getName--) και ελέγξτε ότι είναι το αναμενόμενο σχήμα. Το εναλλακτικό κείμενο μπορεί να επεξεργαστεί ή να μεταφραστεί, κάτι που μπορεί να σπάσει κώδικα που ψάχνει για ακριβή περιγραφή· δείτε [Identify and Find Shapes](/slides/el/java/shape-manipulations/).

**Πότε πρέπει ένα σχήμα να σημειωθεί ως διακοσμητικό;**

Χρησιμοποιήστε τη σημαία διακοσμητικού για οπτικά στοιχεία που δεν προσθέτουν καμία πληροφορία, όπως διακοσμητικά μοτίβα. Εικόνες και διαγράμματα που μεταφέρουν νόημα χρειάζονται κατάλληλη περιγραφή αντί για διακοσμητική σήμανση.

**Κάνει η προσθήκη εναλλακτικού κειμένου μια παρουσίαση πλήρως προσιτή;**

Όχι. Το εναλλακτικό κείμενο αντιμετωπίζει μόνο μέρος των απαιτήσεων προσβασιμότητας. Εξετάστε επίσης τη σειρά ανάγνωσης, την αντίθεση χρωμάτων, την αναγνωσιμότητα του κείμενου και άλλες σχετικές απαιτήσεις· ο καθορισμός αυτών των ιδιοτήτων από μόνος του δεν εξασφαλίζει συμμόρφωση.
