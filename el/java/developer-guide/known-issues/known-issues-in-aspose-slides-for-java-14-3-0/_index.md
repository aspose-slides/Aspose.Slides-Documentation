{{% alert color="info" title="Σημείωση" %}}

Αυτή είναι μια ιστορική σελίδα. Καταγράφει τα γνωστά προβλήματα που δημοσιεύτηκαν με το Aspose.Slides for Java 14.3.0 και δεν περιγράφει την τρέχουσα έκδοση. Για τις αλλαγές σε κάθε έκδοση, δείτε τις [σημειώσεις έκδοσης](https://releases.aspose.com/slides/el/java/release-notes/).

{{% /alert %}}

Το Aspose.Slides for Java 14.3.0 (14.4.0) προσφέρει εντελώς νέα υλοποίηση επεξεργασίας PPT. Υπάρχουν πολλές βελτιώσεις, μερική μετατροπή PPTX σε PPT. Ωστόσο, υπάρχουν ορισμένα μη υλοποιημένα χαρακτηριστικά:

- Ορισμένα σχήματα έχουν λανθασμένη γεωμετρία σε σειριοποιημένα έγγραφα PPT (Call outs)
- Δεν υποστηρίζονται όλες οι δυνατότητες μορφοποίησης κειμένου PPTX στη σειριοποίηση PPT
- Πληροφορίες για τη γλώσσα του κειμένου και τις ρυθμίσεις ορθογραφίας δεν υπάρχουν σε σειριοποιημένα έγγραφα PPT
- Δεν υποστηρίζονται όλες οι δυνατότητες θεμάτων PPTX στη σειριοποίηση PPT

**Υπάρχουν ορισμένες διαφορές σε σύγκριση με το Aspose.Slides for Java 8.6.0:**

- Υπάρχουν γνωστά προβλήματα στην σειριοποίηση OLE/ActiveX PPT σε PPT

**Υπάρχουν ορισμένες διαφορές σε σύγκριση με το Aspose.Slides for .NET 14.3.0:**

- Η υποστήριξη εκτύπωσης παρουσίασης δεν είναι επί του παρόντος διαθέσιμη στο Aspose.Slides for Java
