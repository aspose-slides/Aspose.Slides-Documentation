{{% alert color="info" title="Note" %}}

Αυτή είναι μια ιστορική σελίδα. Παρέχει κατάλογο των περιορισμών και των γνωστών προβλημάτων που δημοσιεύτηκαν με το Aspose.Slides for Java 14.4.0 και δεν περιγράφει την τρέχουσα έκδοση. Για τις αλλαγές σε κάθε έκδοση, δείτε τις [σημειώσεις κυκλοφορίας](https://releases.aspose.com/slides/el/java/release-notes/).

{{% /alert %}}

Το Aspose.Slides for Java 14.4.0 παρέχει νέα δυνατότητα για την επεξεργασία εγγράφων PowerPoint. Υπάρχουν ορισμένοι περιορισμοί και γνωστά προβλήματα, που θα αφαιρεθούν σε επόμενες κυκλοφορίες:

- Ορισμένα σχήματα έχουν λανθασμένη γεωμετρία σε σειριοποιημένα αρχεία PPT (τόξο, κυκλική βέλος, επεξηγήσεις).
- Δεν υποστηρίζονται όλες οι δυνατότητες μορφοποίησης κειμένου PPTX στην σειριοποίηση PPT (στηλοθέτηση, εσοχή και περιορισμοί μορφοποίησης παραγράφων).
- Οι πληροφορίες σχετικά με τη γλώσσα του κειμένου και τις ρυθμίσεις ορθογραφίας δεν περιλαμβάνονται σε σειριοποιημένα αρχεία PPT.
- Δεν υποστηρίζονται όλες οι δυνατότητες θέματος PPTX στην σειριοποίηση PPT (μόνο σειριοποίηση μορφών γεμίσματος, γραμμών και γραμματοσειράς).
- Υπάρχουν γνωστά προβλήματα στη σειριοποίηση OLE/ActiveX PPT σε PPT.
- Η σειριοποίηση και η απόδοση του WordArt δεν υποστηρίζονται.
