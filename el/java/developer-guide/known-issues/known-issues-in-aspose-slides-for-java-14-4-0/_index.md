{{% alert color="info" %}} 
Το Aspose.Slides for Java 14.4.0 προσφέρει νέα δυνατότητα για την επεξεργασία εγγράφων PowerPoint. Υπάρχουν ορισμένοι περιορισμοί και γνωστά προβλήματα, τα οποία θα αφαιρεθούν σε επερχόμενες εκδόσεις:

- Ορισμένα σχήματα έχουν λανθασμένη γεωμετρία σε σειριοποιημένα έγγραφα PPT (τόξο, κυκλικό βέλος, επεξηγήσεις).
- Δεν υποστηρίζονται όλες οι δυνατότητες μορφοποίησης κειμένου PPTX στην σειριοποίηση PPT (στηλοθέτηση, εσοχή και περιορισμοί μορφοποίησης παραγράφων).
- Οι πληροφορίες για τη γλώσσα του κειμένου και τις ρυθμίσεις ορθογραφίας δεν εμφανίζονται σε σειριοποιημένα έγγραφα PPT.
- Δεν υποστηρίζονται όλες οι δυνατότητες θέματος PPTX στην σειριοποίηση PPT (μόνο η σειριοποίηση μορφών γεμίσματος, μορφών γραμμής και γραμματοσειράς).
- Υπάρχουν γνωστά προβλήματα στην σειριοποίηση OLE/ActiveX PPT σε PPT.
- Η σειριοποίηση και η απόδοση του WordArt δεν υποστηρίζονται.

{{% /alert %}}
