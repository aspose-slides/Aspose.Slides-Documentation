## **Επισκόπηση**

Αυτή η ενότητα δεν περιέχει λίστα ανοιχτών προβλημάτων στην τρέχουσα έκδοση. Περιλαμβάνει τρεις σελίδες:

- [Αντικαταστάτης Προεπισκόπισης Αντικειμένου Κατά την Προσθήκη OleObjectFrame](/slides/el/java/object-preview-issue-when-adding-oleobjectframe/) εξηγεί γιατί ένα αντικείμενο OLE που προστέθηκε με το Aspose.Slides εμφανίζει μια εικόνα «EMBEDDED OLE OBJECT» μέχρι να ενημερωθεί η προεπισκόπηση του, και πώς να ορίσετε τη δική σας εικόνα προεπισκόπησης. Αυτό είναι η σχεδιασμένη συμπεριφορά της τρέχουσας έκδοσης.
- [Γνωστά Προβλήματα στο Aspose.Slides για Java 14.3.0 (Ιστορικό)](/slides/el/java/known-issues-in-aspose-slides-for-java-14-3-0/) και [Γνωστά Προβλήματα στο Aspose.Slides για Java 14.4.0 (Ιστορικό)](/slides/el/java/known-issues-in-aspose-slides-for-java-14-4-0/) είναι λίστες που δημοσιεύτηκαν με αυτές τις εκδόσεις, διατηρημένες για αναφορά.

Για τις αλλαγές και τις διορθώσεις σε κάθε έκδοση, δείτε τις [σημειώσεις έκδοσης](https://releases.aspose.com/slides/el/java/release-notes/). Τα πεδία μεταδεδομένων που το Aspose.Slides γράφει με σταθερές τιμές περιγράφονται στους [Περιορισμοί Μεταδεδομένων Εξόδου](/slides/el/java/api-limitations/). Για να ελέγξετε αν ένα πρόβλημα είναι ήδη γνωστό ή για να το αναφέρετε, χρησιμοποιήστε το [φόρουμ υποστήριξης](https://forum.aspose.com/c/slides/el/11).
