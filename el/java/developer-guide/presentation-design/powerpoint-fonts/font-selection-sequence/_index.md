## **Επισκόπηση**

Όταν μια παρουσίαση φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή, το Aspose.Slides ελέγχει αν οι γραμματοσειρές που χρησιμοποιούνται στην παρουσίαση είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν λείπει μια απαιτούμενη γραμματοσειρά, το Aspose.Slides επιλέγει μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτήν που θα χρησιμοποιούσε το PowerPoint.

Το Aspose.Slides πρώτα αναζητά την επιλεγμένη γραμματοσειρά στο λειτουργικό σύστημα. Εάν η γραμματοσειρά βρεθεί, χρησιμοποιείται. Εάν δεν βρεθεί, εφαρμόζεται μια κατάλληλη εναλλακτική. Όταν οι κανόνες υποκατάστασης γραμματοσειρών ορίζονται μέσω `FontSubstRule`, λαμβάνονται επίσης υπόψη.

Μπορείτε επίσης να προσθέσετε γραμματοσειρές κατά την εκτέλεση της εφαρμογής, να χρησιμοποιήσετε ενσωματωμένες γραμματοσειρές από μια παρουσίαση ή να φορτώσετε εξωτερικές γραμματοσειρές για έγγραφα εξόδου όπως αρχεία PDF.

## **Επιλογή γραμματοσειράς**

Ορισμένοι κανόνες εφαρμόζονται στις γραμματοσειρές μιας παρουσίασης όταν η παρουσίαση φορτώνεται, αποδίδεται ή μετατρέπεται σε άλλη μορφή. Για παράδειγμα, όταν προσπαθείτε να μετατρέψετε μια παρουσίαση (τις διαφάνειές της) σε εικόνες, οι γραμματοσειρές της παρουσίασης ελέγχονται για να διαπιστωθεί αν οι επιλεγμένες γραμματοσειρές είναι διαθέσιμες στο λειτουργικό σύστημα. Εάν οι γραμματοσειρές διαπιστωθεί ότι λείπουν, αντικαθίστανται — δείτε [**Αντικατάσταση γραμματοσειράς**](https://docs.aspose.com/slides/el/java/font-replacement/) και [**Υποκατάσταση γραμματοσειράς**](https://docs.aspose.com/slides/el/java/font-substitution/).

Αυτή είναι η διαδικασία που ακολουθεί το Aspose.Slides όταν διαχειρίζεται γραμματοσειρές:

1. Το Aspose.Slides αναζητά γραμματοσειρές στο λειτουργικό σύστημα για να βρει τη γραμματοσειρά που ταιριάζει με τη γραμματοσειρά που επιλέχθηκε στην παρουσίαση. 
2. Εάν η επιλεγμένη γραμματοσειρά βρεθεί, το Aspose.Slides τη χρησιμοποιεί. Διαφορετικά, το Aspose.Slides χρησιμοποιεί μια εναλλακτική γραμματοσειρά που είναι όσο το δυνατόν πιο κοντά σε αυτήν που θα χρησιμοποιούσε το PowerPoint.
3. Εάν έχουν οριστεί κανόνες αντικατάστασης γραμματοσειράς μέσω [FontSubstRule](https://reference.aspose.com/slides/el/java/com.aspose.slides/fontsubstrule/), εφαρμόζονται. 

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές κατά την εκτέλεση της εφαρμογής και στη συνέχεια να τις χρησιμοποιήσετε. Δείτε [**Προσαρμοσμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/java/custom-font/). 

Όταν επιπλέον γραμματοσειρές τοποθετούνται μέσα σε μια παρουσίαση, ονομάζονται [**Ενσωματωμένες γραμματοσειρές**](https://docs.aspose.com/slides/el/java/embedded-font/).

Το Aspose.Slides σας επιτρέπει να προσθέσετε γραμματοσειρές που εφαρμόζονται *μόνο* σε έγγραφα εξόδου. Για παράδειγμα, εάν μια παρουσίαση που θέλετε να μετατρέψετε σε PDF περιέχει γραμματοσειρές που λείπουν από το σύστημά σας και ενσωματωμένες γραμματοσειρές, μπορείτε να προσθέσετε ή να φορτώσετε τις απαιτούμενες γραμματοσειρές ως **εξωτερικές γραμματοσειρές**. 

{{% alert title="Note" color="info" %}} 
Δεν διανέμουμε καμία γραμματοσειρά, είτε πληρωμένη είτε δωρεάν. Το API μας σας επιτρέπει να φορτώσετε εξωτερικές γραμματοσειρές και να τις ενσωματώσετε σε έγγραφα, αλλά το κάνετε με τις γραμματοσειρές με τη δική σας διακριτική ευχέρεια και ευθύνη.
{{% /alert %}}

## **Συχνές ερωτήσεις**

### Πώς μπορώ να προσδιορίσω ποιες γραμματοσειρές χρησιμοποιούνται πραγματικά σε μια παρουσίαση πριν από τη μετατροπή;

Το Aspose.Slides σας επιτρέπει να ελέγξετε τις χρησιμοποιούμενες γραμματοσειρές μέσω του [font manager](https://reference.aspose.com/slides/el/java/com.aspose.slides/fontsmanager/), ώστε να αποφασίσετε αν θα [ενσωμάτωση](/slides/el/java/embedded-font/), [αντικατάσταση](/slides/el/java/font-replacement/), ή προσθήκη [εξωτερικές πηγές](/slides/el/java/custom-font/). Αυτό σας βοηθά να αποτρέψετε ανεπιθύμητες υποκαταστάσεις κατά την απόδοση και την εξαγωγή.

### Μπορώ να προσθέσω επιπλέον καταλόγους γραμματοσειρών χωρίς να τους εγκαταστήσω στο λειτουργικό σύστημα;

Ναι. Μπορείτε να καταχωρίσετε [εξωτερικές πηγές γραμματοσειρών](/slides/el/java/custom-font/) όπως φακέλους ή ροές στη μνήμη για απόδοση και εξαγωγή. Αυτό αφαιρεί την εξάρτηση από τις γραμματοσειρές του συστήματος κεντρικού υπολογιστή και διατηρεί τη διάταξη προβλέψιμη.

### Πώς μπορώ να αποτρέψω μια σιωπηρή επαναφορά σε ακατάλληλη γραμματοσειρά όταν λείπει ένα γλύφο;

Ορίστε ρητά [αντικατάσταση γραμματοσειράς](/slides/el/java/font-replacement/) και γραμματοσειράς [κανόνες εναλλακτικής](/slides/el/java/fallback-font/) εκ των προτέρων. Με την ανάλυση των χρησιμοποιούμενων γραμματοσειρών και τη ρύθμιση ελεγχόμενης προτεραιότητας για τις υποκαταστάσεις, διασφαλίζετε συνεπή τυπογραφία και αποτρέπετε απρόσμενα αποτελέσματα.
