## **Υποστήριξη για Παλαιό Κώδικα**
Για να χρησιμοποιήσετε τον παλιό κώδικα που αναπτύχθηκε με εκδόσεις του Aspose.Slides for Java προγενέστερες της 13.x, πρέπει να κάνετε ορισμένες μικρές αλλαγές στον κώδικά σας και ο κώδικας θα λειτουργεί όπως πριν. Όλες οι κλάσεις που υπήρχαν στην παλιά έκδοση του Aspose.Slides for Java στα namespaces Aspose.Slide και Aspose.Slides.Pptx έχουν πλέον συγχωνευτεί σε ένα ενιαίο namespace Aspose.Slides. Δείτε το παρακάτω απλό απόσπασμα κώδικα για τη δημιουργία ενός εγγράφου Παρουσίασης Hello World στην κληρονομική API του Aspose.Slides και ακολουθήστε τα βήματα που περιγράφουν πώς να μεταβείτε στο νέο συγχωνευμένο API.
