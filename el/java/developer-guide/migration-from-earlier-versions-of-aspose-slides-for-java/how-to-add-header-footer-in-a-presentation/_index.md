## **Υποστήριξη Παλαιού Κώδικα**
Για να χρησιμοποιήσετε τον κληρονομικό κώδικα που αναπτύχθηκε με εκδόσεις του Aspose.Slides for Java πριν από την 13.x, πρέπει να κάνετε κάποιες μικρές αλλαγές στον κώδικά σας και ο κώδικας θα λειτουργεί όπως παλιότερα. Όλες οι κλάσεις που υπήρχαν στην παλιά έκδοση του Aspose.Slides for Java στα ονόματα χώρου Aspose.Slide και Aspose.Slides.Pptx έχουν πλέον ενωθεί σε ένα ενιαίο όνομα χώρου Aspose.Slides. Δείτε το παρακάτω απλό απόσπασμα κώδικα για την προσθήκη κεφαλίδας/υποσέλιδου σε παρουσίαση στην κληρονομική API του Aspose.Slides και ακολουθήστε τα βήματα που περιγράφουν πώς να μεταβείτε στη νέα ενοποιημένη API.
