## **Υποστήριξη για Παλαιό Κώδικα**
Για να χρησιμοποιήσετε τον παλαιό κώδικα που αναπτύχθηκε με εκδόσεις του Aspose.Slides for Java πριν από την 14.x.x, χρειάζεται να κάνετε μερικές μικρές αλλαγές στον κώδικά σας ώστε να λειτουργεί όπως πριν. Όλες οι κλάσεις που υπήρχαν στην παλιά έκδοση του Aspose.Slides for Java στα namespaces com.aspose.slides και com.aspose.slides.pptx έχουν συγχωνευτεί σε ενιαίο namespace com.aspose.slides. Δείτε το παρακάτω απλό κομμάτι κώδικα για δημιουργία ενός κανονικού διαγράμματος από την αρχή σε παρουσίαση χρησιμοποιώντας το κληρονομημένο API του Aspose.Slides και ακολουθήστε τα βήματα που περιγράφουν πώς να μεταβείτε στο νέο συγχωνευμένο API.
