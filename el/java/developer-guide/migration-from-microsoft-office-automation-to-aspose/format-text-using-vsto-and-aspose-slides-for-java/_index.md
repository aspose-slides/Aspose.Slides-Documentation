Μερικές φορές, χρειάζεται να μορφοποιήσετε το κείμενο στις διαφάνειες προγραμματιστικά. Αυτό το άρθρο δείχνει πώς να διαβάσετε μια παράδειγμα παρουσίαση με κάποιο κείμενο στην πρώτη διαφάνεια χρησιμοποιώντας είτε [VSTO](/slides/el/java/format-text-using-vsto-and-aspose-slides-for-java/) είτε [Aspose.Slides for Java](/slides/el/java/format-text-using-vsto-and-aspose-slides-for-java/). Ο κώδικας μορφοποιεί το κείμενο στο τρίτο textbox της διαφάνειας ώστε να μοιάζει με το κείμενο στο τελευταίο textbox.

{{% /alert %}} 
## **Διαμόρφωση Κειμένου**
Και οι μέθοδοι VSTO και Aspose.Slides ακολουθούν τα εξής βήματα:

1. Ανοίξτε την πηγαία παρουσίαση.
1. Προσπελάστε την πρώτη διαφάνεια.
1. Προσπελάστε το τρίτο πλαίσιο κειμένου.
1. Αλλάξτε τη μορφοποίηση του κειμένου στο τρίτο πλαίσιο κειμένου.
1. Αποθηκεύστε την παρουσίαση στο δίσκο.
