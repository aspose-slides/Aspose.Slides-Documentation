## **Εισαγωγή**

Καθώς οι παρουσιάσεις προορίζονται να παρουσιάζουν κάτι, η οπτική τους εμφάνιση και η διαδραστική συμπεριφορά λαμβάνονται πάντα υπόψη κατά τη δημιουργία.

**PowerPoint animation** παίζει σημαντικό ρόλο στο να κάνει μια παρουσίαση ελκυστική και ενδιαφέρουσα για τους θεατές. Η Aspose.Slides παρέχει μια ευρεία γκάμα επιλογών για την προσθήκη κινήσεων σε παρουσιάσεις PowerPoint:

- Εφαρμόστε διάφορους τύπους εφέ κίνησης PowerPoint σε σχήματα, διαγράμματα, πίνακες, αντικείμενα OLE και άλλα στοιχεία της παρουσίασης.
- Χρησιμοποιήστε πολλαπλά εφέ κίνησης PowerPoint σε ένα μόνο σχήμα.
- Αξιοποιήστε τη χρονογραμμή κίνησης για να ελέγξετε τα εφέ κίνησης.
- Δημιουργήστε προσαρμοσμένες κινήσεις.

Στην Aspose.Slides, διάφορα εφέ κίνησης μπορούν να εφαρμοστούν σε σχήματα. Επειδή κάθε στοιχείο σε μια διαφάνεια, συμπεριλαμβανομένου του κειμένου, των εικόνων, των αντικειμένων OLE και των πινάκων, θεωρείται σχήμα, τα εφέ κίνησης μπορούν να εφαρμοστούν σε οποιοδήποτε στοιχείο της διαφάνειας.

## **Εφέ Κίνησης**
Η Aspose.Slides υποστηρίζει **πάνω από 150 εφέ κίνησης**, συμπεριλαμβανομένων βασικών εφέ όπως το Bounce, PathFootball και Zoom, καθώς και συγκεκριμένων εφέ όπως OLEObjectShow και OLEObjectOpen. Μπορείτε να βρείτε μια πλήρη λίστα στην κλάση [EffectType](https://reference.aspose.com/slides/el/java/com.aspose.slides/effecttype/).

Επιπλέον, αυτά τα εφέ κίνησης μπορούν να χρησιμοποιηθούν σε συνδυασμό με τις ακόλουθες συμπεριφορές:

- [ColorEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/ColorEffect)
- [CommandEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/CommandEffect)
- [FilterEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/FilterEffect)
- [MotionEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/MotionEffect)
- [PropertyEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/PropertyEffect)
- [RotationEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/RotationEffect)
- [ScaleEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/ScaleEffect)
- [SetEffect](https://reference.aspose.com/slides/el/java/com.aspose.slides/SetEffect)

## **Προσαρμοσμένη Κίνηση**
Για πλήρη παραδείγματα Java που δημιουργούν, ελέγχουν και τροποποιούν συμπεριφορές και επεξεργάσιμες διαδρομές κίνησης, δείτε το [Custom Animation](/slides/el/java/custom-animation/).

Μπορείτε να δημιουργήσετε τις δικές σας **προσαρμοσμένες κινήσεις** στην Aspose.Slides. Αυτό μπορεί να επιτευχθεί συνδυάζοντας πολλές συμπεριφορές σε μια νέα προσαρμοσμένη κίνηση.

Το [Behavior](https://reference.aspose.com/slides/el/java/com.aspose.slides/behavior/) είναι ένα δομικό στοιχείο ενός εφέ κίνησης PowerPoint. Συνδυάστε συμπεριφορές για να προσαρμόσετε ένα εφέ ή προσθέστε μια συμπεριφορά για να επεκτείνετε ένα προεγκεκριμένο εφέ. Η επανάληψη ρυθμίζεται μέσω των ρυθμίσεων χρόνου αντί για ξεχωριστή συμπεριφορά επανάληψης.

Το [Animation Point](https://reference.aspose.com/slides/el/java/com.aspose.slides/point/) είναι ένα σημείο στο οποίο πρέπει να εφαρμοστεί μια συμπεριφορά.

## **Γραμμή Χρόνου Κίνησης**
Το [Sequence](https://reference.aspose.com/slides/el/java/com.aspose.slides/sequence/) είναι μια συλλογή εφέ κίνησης που μπορεί να στοχεύει διαφορετικά σχήματα.

Το [Timeline](https://reference.aspose.com/slides/el/java/com.aspose.slides/animationtimeline/) είναι ένα σύνολο ακολουθιών που χρησιμοποιείται σε μια συγκεκριμένη διαφάνεια. Είναι μια μηχανή κίνησης που εισήχθη στο PowerPoint 2002. Σε παλαιότερες εκδόσεις του PowerPoint, η προσθήκη εφέ κίνησης σε παρουσιάσεις ήταν δύσκολη και μπορούσε να επιτευχθεί μόνο με διάφορες παρακάμψεις. Η γραμμή χρόνου παρέχει ένα πιο σαφές μοντέλο αντικειμένων για τις κινήσεις PowerPoint. Μια διαφάνεια μπορεί να έχει μόνο μία γραμμή χρόνου κίνησης.

## **Διαδραστική Κίνηση**

## **ΣΥΧΝΑ ΕΡΩΤΗΜΑΤΑ**

**Θα διατηρηθούν οι κινήσεις κατά την εξαγωγή σε PDF;**

Όχι. Το PDF είναι στατικό φορμά, επομένως οι κινήσεις και οι [slide transitions](/slides/el/java/slide-transition/) δεν αναπαράγονται. Εάν χρειάζεστε κίνηση, εξάγετε σε [HTML5](/slides/el/java/export-to-html5/), [animated GIF](/slides/el/java/convert-powerpoint-to-animated-gif/), ή [video](/slides/el/java/convert-powerpoint-to-video/) αντί αυτού.

**Μπορώ να μετατρέψω μια κινούμενη παρουσίαση σε βίντεο και να ελέγξω το ρυθμό καρέ και το μέγεθος του καρέ;**

Ναι. Μπορείτε να [render the presentation as frames](/slides/el/java/convert-powerpoint-to-video/) και να τα κωδικοποιήσετε σε βίντεο (π.χ., με ffmpeg), επιλέγοντας τα FPS και την ανάλυση. Οι κινήσεις και οι μεταβάσεις διαφάνειας αναπαράγονται κατά τη διάρκεια της απόδοσης.

**Θα παραμείνουν αμετάβλητες οι κινήσεις όταν δουλεύετε με ODP (όχι μόνο PPTX);**

Τα PPT, PPTX και ODP υποστηρίζονται για [reading](/slides/el/java/open-presentation/) και [writing](/slides/el/java/save-presentation/), αλλά αυτό δεν εγγυάται τη διατήρηση των κινήσεων. Τα δεδομένα προσαρμοσμένων κινήσεων μπορούν να χαθούν κατά τη μετατροπή σε ODP. Δείτε το [Custom Animation](/slides/el/java/custom-animation/) για παραδείγματα και οδηγίες σχετικά με τον έλεγχο της συμβατότητας μορφής.
