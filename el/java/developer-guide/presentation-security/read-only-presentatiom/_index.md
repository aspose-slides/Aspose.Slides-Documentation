## **Εισαγωγή**

Στο PowerPoint 2019, η Microsoft παρουσίασε τη ρύθμιση **Always Open Read-Only** ως μία από τις επιλογές που μπορούν να χρησιμοποιήσουν οι χρήστες για την προστασία των παρουσιάσεών τους. Μπορεί να θέλετε να χρησιμοποιήσετε αυτή τη ρύθμιση Read-Only για να προστατέψετε μια παρουσίαση όταν

- Θέλετε να αποτρέψετε ακούσιες επεμβάσεις και να διατηρήσετε το περιεχόμενο της παρουσίασής σας ασφαλές.  
- Θέλετε να ενημερώσετε τους χρήστες ότι η παρεχόμενη παρουσίαση είναι η τελική έκδοση.  

Αφού επιλέξετε την επιλογή **Always Open Read-Only** για μια παρουσίαση, όταν οι χρήστες την ανοίγουν βλέπουν τη σύσταση **Read-Only** και μπορεί να εμφανιστεί μήνυμα της μορφής: *Για να αποτρέψετε ακούσιες αλλαγές, ο δημιουργός έχει ορίσει αυτό το αρχείο να ανοίγει ως read-only.*

Η σύσταση **Read-Only** είναι ένας απλός αλλά αποτελεσματικός αποτρεπτικός μηχανισμός που αποθαρρύνει την επεξεργασία, επειδή οι χρήστες πρέπει να εκτελέσουν μια ενέργεια για να το αφαιρέσουν πριν τους επιτραπεί η επεξεργασία της παρουσίασης. Εάν δεν θέλετε οι χρήστες να κάνουν αλλαγές σε μια παρουσίαση και θέλετε να το εκφράσετε με ευγενικό τρόπο, η σύσταση **Read-Only** μπορεί να αποτελεί καλή επιλογή για εσάς.

> Εάν μια παρουσίαση με προστασία **Read-Only** ανοιχτεί σε μια παλαιότερη έκδοση του Microsoft PowerPoint—που δεν υποστηρίζει τη νεοεισαγμένη λειτουργία—η σύσταση **Read-Only** παραβλέπεται (η παρουσίαση ανοίγει κανονικά).

## **Εφαρμογή λειτουργίας Read-Only**

Το Aspose.Slides for Java σας επιτρέπει να ορίσετε μια παρουσίαση σε **Read-Only**, πράγμα που σημαίνει ότι οι χρήστες (αφού ανοίξουν την παρουσίαση) θα δουν τη σύσταση **Read-Only**. Αυτό το δείγμα κώδικα δείχνει πώς να ορίσετε μια παρουσίαση σε **Read-Only** σε Java χρησιμοποιώντας το Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 

**Σημείωση**: Η σύσταση **Read-Only** προορίζεται απλώς να αποθαρρύνει την επεξεργασία ή να εμποδίσει ακούσιες αλλαγές σε μια παρουσίαση PowerPoint. Εάν κάποιος με προθυμία—που ξέρει τι κάνει—αποφασίσει να επεξεργαστεί την παρουσίασή σας, μπορεί εύκολα να αφαιρέσει τη ρύθμιση Read-Only. Εάν χρειάζεται σοβαρά να αποτρέψετε μη εξουσιοδοτημένη επεξεργασία, είναι καλύτερο να χρησιμοποιήσετε [more stringent protections that involve encryptions and passwords](https://docs.aspose.com/slides/el/java/password-protected-presentation/). 

{{% /alert %}} 

## **Συχνές Ερωτήσεις**

### Πώς διαφέρει το «Read-Only recommended» από την πλήρη προστασία με κωδικό;

Το «Read-Only recommended» εμφανίζει μόνο μια πρόταση για άνοιγμα του αρχείου σε λειτουργία ανάγνωσης και είναι εύκολο να παρακαμφθεί. Η [Password protection](/slides/el/java/password-protected-presentation/) περιορίζει πραγματικά το άνοιγμα ή την επεξεργασία και είναι κατάλληλη όταν χρειάζεστε πραγματικούς ελέγχους ασφαλείας.

### Μπορεί το «Read-Only recommended» να συνδυαστεί με υδατογραφήματα για περαιτέρω αποθάρρυνση των επεξεργασιών;

Ναι. Η σύσταση μπορεί να συνδυαστεί με [watermarks](/slides/el/java/watermark/) ως οπτικό αποτρεπτικό μέτρο· είναι ξεχωριστοί μηχανισμοί και λειτουργούν καλά μαζί.

### Μπορεί ένα μακροεντολή ή εξωτερικό εργαλείο να τροποποιήσει ακόμα το αρχείο όταν η σύσταση είναι ενεργή;

Ναι. Η σύσταση δεν μπλοκάρει προγραμματιστικές αλλαγές. Για να αποτρέψετε αυτοματοποιημένες επεξεργασίες, χρησιμοποιήστε [passwords and encryption](/slides/el/java/password-protected-presentation/).

### Πώς σχετίζεται το «Read-Only recommended» με τις μεθόδους «isEncrypted» και «isWriteProtected»;

Είναι διαφορετικά σήματα. Το «Read-Only recommended» είναι μια ήπια, προαιρετική προτροπή· τα [isWriteProtected](https://reference.aspose.com/slides/el/java/com.aspose.slides/protectionmanager/#isWriteProtected--) και [isEncrypted](https://reference.aspose.com/slides/el/java/com.aspose.slides/protectionmanager/#isEncrypted--) υποδεικνύουν πραγματικούς περιορισμούς εγγραφής ή ανάγνωσης που εξαρτώνται από κωδικούς ή κρυπτογράφηση.
