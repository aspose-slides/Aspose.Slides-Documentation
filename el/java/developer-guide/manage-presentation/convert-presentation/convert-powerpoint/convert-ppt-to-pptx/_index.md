## **Μετατροπή PPT σε PPTX**

Το Aspose.Slides for Java διευκολύνει τώρα τους προγραμματιστές να έχουν πρόσβαση στο PPT χρησιμοποιώντας το αντικείμενο κλάσης [Presentation](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentation) και να το μετατρέπουν στη σχετική μορφή [PPTX](https://docs.fileformat.com/presentation/pptx/). Προς το παρόν, υποστηρίζει μερική μετατροπή του [PPT ](https://docs.fileformat.com/presentation/ppt/) σε PPTX. Για περισσότερες λεπτομέρειες σχετικά με τα χαρακτηριστικά που υποστηρίζονται και δεν υποστηρίζονται στη μετατροπή PPT σε PPTX, προχωρήστε στην τεκμηρίωση [link](/slides/el/java/ppt-to-pptx-conversion/).

Το Aspose.Slides for Java προσφέρει την κλάση [Presentation](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentation) που αντιπροσωπεύει ένα αρχείο παρουσίασης **PPTX**. Η κλάση Presentation μπορεί τώρα επίσης να προσπελάσει **PPT** μέσω του Presentation όταν το αντικείμενο δημιουργείται. Το παρακάτω παράδειγμα δείχνει πώς να μετατρέψετε μια παρουσίαση PPT σε παρουσίαση PPTX.

```java
import com.aspose.slides.*;

// Δημιουργήστε ένα αντικείμενο Presentation που αντιπροσωπεύει ένα αρχείο PPT
Presentation pres = new Presentation("Aspose.ppt");
try {
// Αποθήκευση της παρουσίασης PPT σε μορφή PPTX
    pres.save("ConvertedAspose.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```
