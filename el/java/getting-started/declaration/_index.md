## **Επισκόπηση**

Ο Διαχειριστής Ασφαλείας Java περιορίζει τι μπορεί να κάνει ο κώδικας σύμφωνα με μια πολιτική ασφαλείας. Η Java 17 τον κατέστησε παρωχημένο για απομάκρυνση ([JEP 411](https://openjdk.org/jeps/411)), και η Java 24 τον απενεργοποίησε μόνιμα ([JEP 486](https://openjdk.org/jeps/486)). Αυτό το άρθρο εξηγεί τι χρειάζεται το Aspose.Slides για Java όταν μια εφαρμογή εξακολουθεί να εκτελείται με Διαχειριστή Ασφαλείας. Εάν η εφαρμογή σας δεν ενεργοποιεί κάποιον, όπως είναι η προεπιλογή, δεν υπάρχει κάτι προς ρύθμιση.

## **Java 23 και Παλαιότερα**

Όταν ένας Διαχειριστής Ασφαλείας είναι ενεργοποιημένος, η πολιτική ασφαλείας πρέπει να χορηγεί αυτές τις άδειες στο αρχείο JAR του Aspose.Slides και στον κώδικα της εφαρμογής που το καλεί:

- `java.util.PropertyPermission "*", "read"`: Aspose.Slides διαβάζει τις ιδιότητες συστήματος.
- `java.io.FilePermission "<<ALL FILES>>", "read"`: Aspose.Slides διαβάζει αρχεία γραμματοσειρών και άλλα αρχεία.
- `java.io.FilePermission "<<ALL FILES>>", "execute"`: Aspose.Slides εκκινεί προγράμματα του λειτουργικού συστήματος, για παράδειγμα `reg` στα Windows και `fc-match` στο Linux.
- `java.io.FilePermission` με τη δράση `write` για τους φακέλους όπου η εφαρμογή σας αποθηκεύει αρχεία.

Η χορήγηση των αδειών στο αρχείο JAR μόνο δεν είναι επαρκής: ο κώδικας που καλεί το Aspose.Slides τις χρειάζεται επίσης. Η χορήγηση του `java.security.AllPermission` και στα δύο λειτουργεί επίσης.

Χωρίς την άδεια να διαβάζει τις ιδιότητες συστήματος ή να εκκινεί προγράμματα, το Aspose.Slides αποτυγχάνει στην πρώτη χρήση: η δημιουργία ενός αντικειμένου [Παρουσίαση](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentation/) ρίχνει ένα `ExceptionInInitializerError`. Χωρίς πρόσβαση ανάγνωσης στα αρχεία γραμματοσειρών, η αποθήκευση μιας παρουσίασης ως PDF αποτυγχάνει με το σφάλμα "Cannot find any fonts installed on the system".

## **Java 24 και Μετέπειτα**

Ο Διαχειριστής Ασφαλείας δεν μπορεί να ενεργοποιηθεί στην Java 24 και μεταγενέστερες εκδόσεις, επομένως δεν υπάρχουν άδειες προς χορήγηση. Το Aspose.Slides εκτελείται με τις άδειες του λογαριασμού που εκτελεί την εφαρμογή σας. Για να περιοριστεί αυτό που μπορεί να προσπελάσει μια εφαρμογή, το έργο OpenJDK προτείνει τεχνολογίες εκτός του JDK, όπως containers, hypervisors και δυνατότητες απομονωμού του λειτουργικού συστήματος. Δείτε το [JEP 486](https://openjdk.org/jeps/486).

## **Συχνές Ερωτήσεις**

**Μπορώ να χρησιμοποιήσω το Aspose.Slides σε περιβάλλον που εκτελεί εφαρμογές κάτω από περιοριστική πολιτική Διαχειριστή Ασφαλείας;**

Μόνο εάν η πολιτική χορηγεί τις παραπάνω άδειες τόσο στο Aspose.Slides όσο και στον κώδικα που το καλεί. Περιλαμβάνουν την ανάγνωση όλων των αρχείων και την εκκίνηση οποιουδήποτε προγράμματος.
