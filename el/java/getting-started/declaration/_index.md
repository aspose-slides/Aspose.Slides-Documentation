{{% alert color="info" %}} 

Όλα τα στοιχεία Aspose Java απαιτούν το σύνολο δικαιωμάτων Full Trust. Ο λόγος είναι ότι τα στοιχεία Aspose Java χρειάζονται πρόσβαση στις ρυθμίσεις του μητρώου, στα συστήματικά αρχεία εκτός του εικονικού καταλόγου για ορισμένες λειτουργίες όπως η ανάλυση γραμματοσειρών κ.λπ. Επιπλέον, τα στοιχεία Aspose Java βασίζονται σε βασικές κλάσεις του συστήματος Java που επίσης απαιτούν το σύνολο δικαιωμάτων Full Trust σε πολλές περιπτώσεις. 

{{% /alert %}} 

Οι παρόχοι υπηρεσιών Internet που φιλοξενούν πολλαπλές εφαρμογές από διαφορετικές εταιρείες, κυρίως επιβάλλουν επίπεδο ασφαλείας Medium Trust: 

- OleDbPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να χρησιμοποιήσετε τον διαχειριζόμενο παροχέα δεδομένων ADO.NET OLE DB για πρόσβαση σε βάσεις δεδομένων.
- EventLogPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να αποκτήσετε πρόσβαση στο αρχείο καταγραφής συμβάντων των Windows.
- ReflectionPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να χρησιμοποιήσετε την ανάκλαση.
- RegistryPermission δεν είναι διαθέσιμο. Αυτό σημαίνει ότι δεν μπορείτε να αποκτήσετε πρόσβαση στο μητρώο.
- WebPermission είναι περιορισμένο. Αυτό σημαίνει ότι η εφαρμογή σας μπορεί να επικοινωνεί μόνο με μια διεύθυνση ή περιοχή διευθύνσεων που ορίζετε στο στοιχείο <trust>.
- FileIOPermission είναι περιορισμένο. Αυτό σημαίνει ότι μπορείτε να έχετε πρόσβαση μόνο σε αρχεία στην ιεραρχία του εικονικού καταλόγου της εφαρμογής σας.

{{% alert color="info" %}} 

Λόγω των παραπάνω λόγων, τα στοιχεία Aspose Java δεν μπορούν να χρησιμοποιηθούν σε διακομιστές που χορηγούν σύνολο δικαιωμάτων διαφορετικό από Full Trust. 

{{% /alert %}}
