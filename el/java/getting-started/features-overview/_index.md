## **Επισκόπηση**

Το Aspose.Slides for Java είναι μια βιβλιοθήκη κλάσεων για δημιουργία, ανάγνωση, επεξεργασία, μετατροπή και απόδοση παρουσιάσεων PowerPoint και OpenDocument. Δεν διαθέτει δικό της περιβάλλον χρήστη και δεν απαιτεί το Microsoft PowerPoint ή το Microsoft Office. Αυτό το άρθρο συνοψίζει τι καλύπτει η βιβλιοθήκη και παρέχει συνδέσμους προς τα άρθρα που περιγράφουν κάθε περιοχή.

## **Υποστηριζόμενες Πλατφόρμες**

Aspose.Slides for Java είναι ένα ενιαίο αρχείο JAR, δημοσιευμένο στο Maven αποθετήριο της Aspose με τον ταξινομητή `jdk16`. Έχει γραφτεί καθαρά σε Java: το JAR δεν περιλαμβάνει εγγενείς βιβλιοθήκες και δεν εξαρτάται από άλλα πακέτα.

- **Java:** Java 8 ή νεότερη. Η Aspose.Slides for Java 26.9 και οι προηγούμενες εκδόσεις τρέχουν επίσης σε Java 6 και 7, τα οποία η έκδοση 26.10 δεν υποστηρίζει πλέον· δείτε τις [26.9 release notes](https://releases.aspose.com/slides/el/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/).
- **Operating systems:** οποιοδήποτε λειτουργικό σύστημα με περιβάλλον εκτέλεσης Java, όπως Windows, Linux και macOS. Σε Linux, πρέπει να εγκατασταθεί η βιβλιοθήκη fontconfig και τουλάχιστον μια γραμματοσειρά.

[Installation](/slides/el/java/installation/) δείχνει πώς να προσθέσετε τη βιβλιοθήκη σε ένα έργο και παραθέτει τις προαπαιτούμενες ρυθμίσεις για Linux. [System Requirements](/slides/el/java/system-requirements/) καταγράφει τις υποστηριζόμενες πλατφόρμες λεπτομερώς.

## **Μορφές Αρχείων και Μετατροπές**

Το Aspose.Slides ανοίγει και αποθηκεύει παρουσιάσεις PPT, PPTX, PPS, POT, PPSX, POTX, PPTM, PPSM, POTM, ODP, OTP, FODP και PowerPoint XML. Εισάγει περιεχόμενο PDF και HTML σε διαφάνειες και αποθηκεύει τις παρουσιάσεις ως PDF, XPS, HTML, HTML5, TIFF, animated GIF, SWF, Markdown και XAML. [Supported File Formats](/slides/el/java/supported-file-formats/) καταγράφει κάθε μορφή με το API που τη διαβάζει ή τη γράφει.

## **Απόδοση Παρουσίασης**

Το Aspose.Slides αποδίδει διαφάνειες και μεμονωμένα σχήματα ως εικόνες PNG, JPEG, BMP, GIF, TIFF και SVG, και διαφάνειες ως αρχεία μεταδεδομένων EMF. Δείτε [Convert Presentation Slides to Images](/slides/el/java/convert-slide/), [Render Presentation Slides as SVG Images](/slides/el/java/render-a-slide-as-an-svg-image/) και [Create Thumbnails of Presentation Shapes](/slides/el/java/create-shape-thumbnails/).

## **Συχνές Ερωτήσεις**

**Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint στον διακομιστή ή στον υπολογιστή για να λειτουργήσει η βιβλιοθήκη;**

Όχι. Το PowerPoint δεν απαιτείται· το Aspose.Slides είναι μια αυτόνομη μηχανή για δημιουργία, επεξεργασία, μετατροπή και απόδοση παρουσιάσεων.

**Πώς λειτουργεί η πολυνηματικότητα; Μπορούν οι διαδικασίες να παραλληλοποιηθούν;**

Είναι ασφαλές να επεξεργάζεστε διαφορετικά έγγραφα σε διαφορετικά νήματα· το ίδιο αντικείμενο [Presentation](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentation/) δεν πρέπει να χρησιμοποιείται από [πολλαπλά νήματα](/slides/el/java/multithreading/) ταυτόχρονα.

**Υποστηρίζονται κωδικοί πρόσβασης αρχείων και κρυπτογράφηση;**

Ναι. [Μπορείτε](/slides/el/java/password-protected-presentation/) να ανοίξετε κρυπτογραφημένες παρουσιάσεις, να ορίσετε ή να αφαιρέσετε κωδικό ανοίγματος και εγγραφής, και να ελέγξετε την κατάσταση προστασίας.

**Πρέπει να ανησυχήσω για τις γραμματοσειρές σε κοντέινερ Linux;**

Ναι. Σε Linux, η βιβλιοθήκη fontconfig και τουλάχιστον μια γραμματοσειρά πρέπει να εγκατασταθεί, και οι γραμματοσειρές που χρησιμοποιούνται στις παρουσιάσεις σας, ή κατάλληλες εναλλακτικές, πρέπει να εγκατασταθούν ώστε το κείμενο να αποδίδεται σωστά. Μπορείτε επίσης να [καθορίσετε καταλόγους γραμματοσειρών](/slides/el/java/custom-font/) στην εφαρμογή σας. Δείτε την [Εγκατάσταση](/slides/el/java/installation/#linux).

**Υπάρχουν περιορισμοί στην έκδοση αξιολόγησης;**

Ναι. Χωρίς [άδεια](/slides/el/java/licensing/), το Aspose.Slides προσθέτει υδατογράφημα αξιολόγησης σε κάθε διαφάνεια που αποθηκεύει και κόβει το κείμενο που διαβάζει ο κώδικάς σας μέσω του API. Μια [30-day temporary license](https://purchase.aspose.com/temporary-license/) είναι διαθέσιμη για πλήρη δοκιμή όλων των λειτουργιών.

**Υποστηρίζεται η εισαγωγή εξωτερικών μορφών σε μια παρουσίαση (PDF ή HTML σε PPTX);**

Ναι. Μπορείτε να προσθέσετε [σελίδες PDF και περιεχόμενο HTML](/slides/el/java/import-presentation/) σε μια παρουσίαση, μετατρέποντάς τα σε διαφάνειες.
