{{% alert color="info" title="Note" %}}

Αυτή είναι μια ιστορική σελίδα. Περιγράφει ένα σφάλμα στο Aspose.Slides for Java εκδόσεις 23.2 έως 23.7, που κυκλοφόρησαν το 2023, και τις εκδόσεις που το διόρθωσαν. Δεν περιγράφει την τρέχουσα έκδοση. Για αδειοδότηση στην τρέχουσα έκδοση, δείτε [Αδειοδότηση](/slides/el/java/licensing/).

{{% /alert %}}

## **Επισκόπηση**

Αυτό το άρθρο περιγράφει ένα σφάλμα αδειοδότησης που εμφανίστηκε στις εκδόσεις Aspose.Slides for Java 23.2, 23.3, 23.4, 23.5, 23.6 και 23.7. Το σφάλμα αυτό προκάλεσε τις διαρκείς άδειες να καταστούν προσωρινά μη χρησιμοποιήσιμες μετά τη λήξη της συνδρομής τους.

## **Συμπτώματα**

Μετά τη λήξη της συνδρομής της διαρκούς άδειας, οι εκδόσεις Aspose.Slides for Java 23.2 - 23.7 μπορεί να αναφέρουν ότι η άδεια έληξε, μεταβαίνοντας όλες τις λειτουργίες σε λειτουργία αξιολόγησης. Αυτή η συμπεριφορά είναι λανθασμένη και δεν επηρεάζει τις εκδόσεις πριν από την 23.2 και μετά την 23.7.

## **Επίλυση**

Η Aspose.Slides for Java διόρθωσε αυτό το ζήτημα και έκδοσε ενημερωμένες εκδόσεις (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) με τη διόρθωση.

## **Προϊόντα και εκδόσεις που επηρεάζονται**

Σημειώστε ότι αυτό το σφάλμα επηρεάζει μόνο τις εκδόσεις Aspose.Slides for Java 23.2 έως 23.7. **Άλλα προϊόντα Aspose και άλλες εκδόσεις του Aspose.Slides δεν επηρεάζονται**.
