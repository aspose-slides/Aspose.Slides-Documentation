## **Αλλαγή Κατηγοριοποιητή Καταλλήλου από `jdk16` σε `jdk8`**

Από την έκδοση **26.10**, έχουμε αλλάξει τον κατηγοριοποιητή που χρησιμοποιείται στα δημοσιευμένα καταλλήλ μας από **`jdk16`** (Java 6) σε **`jdk8`** (Java 8).

### **Τι άλλαξε**

| | Πριν | Μετά |
|---|---|---|
| Κατηγοριοποιητής | `jdk16` | `jdk8` |
| Ελάχιστη έκδοση Java | Java 1.6 | Java 8 |

**Πριν:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**Μετά:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **Γιατί κάναμε αυτήν την αλλαγή**

Μετά από εσωτερική αξιολόγηση, αποφασίσαμε να **κατάργουμε την υποστήριξη για παλαιότερες εκδόσεις Java** που δεν προσέφεραν πια αξία και εμποδίζαν ενεργά τη συντήρηση. Η Java 8 επιλέχθηκε ως η νέα, ασφαλής βάση για όλους τους χρήστες.

Στο πλαίσιο αυτό, ο κατηγοριοποιητής ενημερώθηκε ώστε να αντανακλά την πραγματική ελάχιστη υποστηριζόμενη έκδοση. Επίσης ευθυγραμμιστήκαμε με την τρέχουσα ονομαστική σύμβαση της Oracle, όπου το προϊόν αναφέρεται επίσημα ως **JDK 8** (αντί της κληρονομικής μορφής `1.8`).

### **Τι πρέπει να κάνετε**

1. **Ενημερώστε τον κατηγοριοποιητή** στις δηλώσεις εξαρτήσεων σας από `jdk16` σε `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **Επαληθεύστε το περιβάλλον εκτέλεσής σας** ότι είναι Java 8 ή νεότερο.

3. **Ανανεώστε τυχόν αρχεία κλειδώματος** ή τις κρυφές μνήμες εξαρτήσεων που «κλειδώνουν» τον παλιό κατηγοριοποιητή.

### **Σημείωση Μετανάστευσης: jdk16 και jdk8**

Από την έκδοση 26.10, και οι δύο κατηγοριοποιητές jdk16 και jdk8 θα παρέχουν JARs συμβατά με Java 8 (δημιουργημένα με συμβατότητα source/target ορισμένη στην Java 8).

- `jdk16` → συνεχίζει να κυκλοφορεί για συμβατότητα με παλαιότερες εκδόσεις (υπάρχουσες ενσωματώσεις).
- `jdk8` → εισήχθη ως ο νέος προτιμώμενος κατηγοριοποιητής για περιβάλλοντα Java 8.

⚠️ Σημείωση: Αυτή η φάση διπλής έκδοσης αναμένεται να λήξει στις 31 Μαρτίου 2027. Μετά από αυτήν την ημερομηνία, ο κατηγοριοποιητής jdk16 θα αποσυρθεί και μόνο το jdk8 θα υποστηρίζεται.

### **Σημειώσεις Συμβατότητας**

- Ο κατηγοριοποιητής `jdk16` **δεν δημοσιεύεται πλέον** μετά τις **31 Μαρτίου 2027**.
- Εάν εξακολουθείτε να χρειάζεστε υποστήριξη για Java 1.6, παραμείνετε στην προηγούμενη κύρια σειρά εκδόσεων μέχρι να μπορείτε να μεταναστεύσετε.
