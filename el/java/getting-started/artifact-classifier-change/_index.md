## **Αλλαγή Κατηγοριοποιητή του Τεχνήματος από `jdk16` σε `jdk8`**

Από την έκδοση **26.10**, αλλάξαμε τον κατηγοριοποιητή που χρησιμοποιείται στα δημοσιευμένα τεχνήματά μας από **`jdk16`** (Java 6) σε **`jdk8`** (Java 8).

### **Τι άλλαξε**

| | Πριν | Μετά |
|---|---|---|
| Κατηγοριοποιητής | `jdk16` | `jdk8` |
| Ελάχιστη έκδοση Java | Java 1.6 | Java 8 |

**Πριν:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**Μετά:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **Γιατί κάναμε αυτή την αλλαγή**

Μετά από εσωτερική αξιολόγηση, αποφασίσαμε να **απομακρύνουμε την υποστήριξη για παλιότερες εκδόσεις Java** που δεν παρείχαν πλέον αξία και επιδρούσαν αρνητικά στη συντήρηση. Η Java 8 επιλέχθηκε ως το νέο, ασφαλές σημείο βάσης για όλους τους χρήστες.

Στο πλαίσιο αυτό, ο κατηγοριοποιητής ενημερώθηκε ώστε να αντανακλά την πραγματική ελάχιστη υποστηριζόμενη έκδοση. Επίσης, ευθυγραμμισθήκαμε με την τρέχουσα ονομαστική σύμβαση της Oracle, όπου το προϊόν αναφέρεται επίσημα ως **JDK 8** (αντί της παλαιού μορφής `1.8`).

### **Τι πρέπει να κάνετε**

1. **Ενημερώστε τον κατηγοριοποιητή** στις δηλώσεις εξαρτήσεων σας από `jdk16` σε `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **Βεβαιωθείτε ότι το περιβάλλον εκτέλεσης** είναι Java 8 ή νεώτερο.

3. **Ανανεώστε τυχόν αρχεία κλειδώματος** ή κρύπτες εξαρτήσεων που «καρφώνουν» τον παλιό κατηγοριοποιητή.

### **Σημείωση Μεταφοράς: jdk16 και jdk8**

Από την έκδοση 26.10​, και οι δύο κατηγοριοποιητές jdk16 και jdk8 θα παρέχουν JARs συμβατά με Java 8 (χτισμένα με συμβατότητα πηγαίου/στόχου ορισμένη στην Java 8).

 - `jdk16` → συνεχίζει να δημοσιεύεται για συμβατότητα με παλαιότερες εκδόσεις (υπάρχες ενσωματώσεις).
 - `jdk8` → παρουσιάζεται ως ο νέος προτιμώμενος κατηγοριοποιητής για περιβάλλοντα Java 8.

⚠️ Σημείωση: Αυτή η φάση διπλής δημοσίευσης προγραμματίζεται να λήξει στις 31 Μαρτίου 2027​. Μετά από αυτή την ημερομηνία, ο κατηγοριοποιητής jdk16 θα αποσυρθεί, και μόνο το jdk8 θα υποστηρίζεται.

### **Σημειώσεις Συμβατότητας**

- Ο `jdk16` κατηγοριοποιητής **δεν δημοσιεύεται πλέον** μετά τις **31 Μαρτίου 2027**.
- Αν εξακολουθείτε να χρειάζεστε υποστήριξη για Java 1.6, παραμείνετε στην προηγούμενη σειρά κύριας έκδοσης έως ότου μπορείτε να μεταβείτε.

### **Χρειάζεστε βοήθεια;**

Αν αντιμετωπίσετε προβλήματα κατά τη μεταφορά, παρακαλούμε επικοινωνήστε με την [υποστήριξη Aspose](https://forum.aspose.com/) για περαιτέρω βοήθεια.
