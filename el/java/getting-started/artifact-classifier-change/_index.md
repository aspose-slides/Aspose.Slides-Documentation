## Αλλαγή ταξινομητή τεχνημάτων από `jdk16` σε `jdk8`

Από την έκδοση **26.10**, έχουμε αλλάξει τον ταξινομητή που χρησιμοποιείται στα δημοσιευμένα τεχνητά μας από **`jdk16`** (Java 6) σε **`jdk8`** (Java 8).

### Τι άλλαξε

| | Πριν | Μετά |
|---|---|---|
| Ταξινομητής | `jdk16` | `jdk8` |
| Ελάχιστη έκδοση Java | Java 1.6 | Java 8 |

**Πριν:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**Μετά:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### Γιατί κάναμε αυτή την αλλαγή

Μετά από εσωτερική αξιολόγηση, αποφασίσαμε να **διακόψουμε την υποστήριξη για παλαιότερες εκδόσεις Java** που δεν παρείχαν πλεονέκτημα και παρεμπόδιζαν ενεργά τη συντήρηση. Η Java 8 επιλέχθηκε ως η νέα, ασφαλής βάση για όλους τους χρήστες.

Στο πλαίσιο αυτό, ο ταξινομητής ενημερώθηκε ώστε να αντικατοπτρίζει την πραγματική ελάχιστη υποστηριζόμενη έκδοση. Επιπλέον, ευθυγραμμιστήκαμε με την τρέχουσα συμβατική ονοματοδοσία της Oracle, όπου το προϊόν αναφέρεται επίσημα ως **JDK 8** (αντί της παλαιάς μορφής `1.8`).

### Τι πρέπει να κάνετε

1. **Ενημερώστε τον ταξινομητή** στις δηλώσεις εξαρτήσεων από `jdk16` σε `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **Επαληθεύστε ότι το περιβάλλον εκτέλεσής σας** είναι Java 8 ή νεότερο.

3. **Ανανεώστε τυχόν αρχεία κλειδώματος** ή μνήμες εξαρτήσεων που κρατούν τον παλιό ταξινομητή.

### Σημείωση μετανάστευσης: jdk16 και jdk8

Από την έκδοση 26.10, και οι ταξινομητές jdk16 και jdk8 θα παρέχουν JAR αρχεία συμβατά με Java 8 (δημιουργημένα με συμβατότητα πηγαίου/στόχου ορισμένη σε Java 8).

- `jdk16` → συνεχίζει να δημοσιεύεται για συμβατότητα προς τα πίσω (υπάρχουσες ενσωματώσεις).
- `jdk8` → εισάγεται ως ο νέος προτιμώμενος ταξινομητής για περιβάλλοντα Java 8.

⚠️ Σημείωση: Αυτή η φάση διπλής έκδοσης είναι προγραμματισμένη να ολοκληρωθεί την 31 Μαρτίου 2027. Μετά από αυτήν την ημερομηνία, ο ταξινομητής jdk16 θα αφαιρεθεί και θα υποστηρίζεται μόνο το jdk8.

### Σημειώσεις συμβατότητας

- Ο ταξινομητής `jdk16` **δεν δημοσιεύεται πλέον** μετά την **31 Μαρτίου 2027**.
- Εάν εξακολουθείτε να χρειάζεστε υποστήριξη Java 1.6, παραμείνετε στην προηγούμενη κύρια έκδοση μέχρι να μπορείτε να μεταναστεύσετε.

### Χρειάζεστε βοήθεια;

Εάν αντιμετωπίσετε προβλήματα κατά τη διάρκεια της μετάβασης, παρακαλούμε επικοινωνήστε με [Υποστήριξη Aspose](https://forum.aspose.com/) για περαιτέρω βοήθεια.
