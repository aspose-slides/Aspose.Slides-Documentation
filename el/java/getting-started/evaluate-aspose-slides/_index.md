## **Αξιολόγηση Aspose.Slides**

Μπορείτε να κατεβάσετε το Aspose.Slides για αξιολόγηση. Η λήψη αξιολόγησης είναι η ίδια με την αγορά· γίνεται αδειοδοτημένη μετά την προσθήκη μερικών γραμμών κώδικα για την εφαρμογή της άδειας.

Χωρίς άδεια, το Aspose.Slides παρέχει πλήρη λειτουργικότητα σε λειτουργία αξιολόγησης, με δύο περιορισμούς: προσθέτει ένα πλαίσιο κειμένου υδατογράφημα αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει, και το κείμενο που διαβάζει ο κώδικάς σας μέσω του API, συμπεριλαμβανομένου του κειμένου που μόλις έθεσε, περικόπτεται στους πρώτους του χαρακτήρες, ακολουθούμενο από μια σημείωση σχετικά με τον περιορισμό αξιολόγησης. Το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρως. Η μέθοδος [getPresentationText](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) που εξάγει κείμενο χωρίς να φορτώνει όλη την παρουσίαση, επιστρέφει μόνο τις σημειώσεις αξιολόγησης και κανένα κείμενο διαφάνειας.

## **Συχνές Ερωτήσεις**

### Μπορώ να δοκιμάσω πολλές παρουσιάσεις παράλληλα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα παράλληλα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [across threads](/slides/el/java/multithreading/). Η λειτουργία αξιολόγησης δεν το επηρεάζει.

### Πρέπει να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι ανεξάρτητος κινητήρας και δεν απαιτεί εγκατάσταση PowerPoint, τόσο για αξιολόγηση όσο και για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναι. Οι [converters](/slides/el/java/convert-presentation/) λειτουργούν· η έξοδος θα περιλαμβάνει υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμή φόρτου χωρίς υδατογράφημα;

Ναι. Μια 30‑ήμερη προσωρινή άδεια αφαιρεί τους περιορισμούς λειτουργίας αξιολόγησης και επιτρέπει δοκιμές χωρίς υδατογράφημα.
