## **Aspose.Slides Evaluation**

Μπορείτε να κατεβάσετε το Aspose.Slides για αξιολόγηση. Η λήψη αξιολόγησης είναι η ίδια με την αγορά λήψης· γίνεται αδειοδοτημένη αφού προσθέσετε μερικές γραμμές κώδικα για να εφαρμόσετε την άδεια.

Χωρίς άδεια, το Aspose.Slides παρέχει πλήρη λειτουργικότητα σε κατάσταση αξιολόγησης, με δύο περιορισμούς: προσθέτει ένα πλαίσιο κειμένου υδατογραφήματος αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει, και το κείμενο που διαβάζει ο κώδικάς σας μέσω του API, συμπεριλαμβανομένου του κειμένου που μόλις ορίστηκε, περικόπτεται στα πρώτα του λίγα χαρακτήρες, ακολουθούμενο από ειδοποίηση για τον περιορισμό της αξιολόγησης. Το κείμενο που γράφει ο κώδικάς σας αποθηκεύεται πλήρως. Η μέθοδος [getPresentationText](https://reference.aspose.com/slides/el/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) εξάγει κείμενο χωρίς να φορτώνει ολόκληρη την παρουσίαση, επιστρέφει μόνο τις ειδοποιήσεις αξιολόγησης και κανένα κείμενο διαφάνειας.

## **Συχνές ερωτήσεις**

### Μπορώ να δοκιμάσω πολλαπλές παρουσιάσεις παράλληλα σε διαφορετικά νήματα σε κατάσταση αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα παράλληλα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [διαμέσου νημάτων](/slides/el/java/multithreading/). Η κατάσταση αξιολόγησης δεν επηρεάζει αυτό.

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι ανεξάρτητος κινητήρας και δεν απαιτεί εγκατάσταση του PowerPoint ούτε για αξιολόγηση ούτε για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε κατάσταση αξιολόγησης;

Ναι. Οι [μετατροπείς](/slides/el/java/convert-presentation/) λειτουργούν· το αποτέλεσμα θα περιλαμβάνει υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμές φορτίου χωρίς υδατογράφημα;

Ναι. Μια 30‑ημερη προσωρινή άδεια αφαιρεί τους περιορισμούς της κατάστασης αξιολόγησης και επιτρέπει δοκιμές χωρίς υδατογράφημα.
