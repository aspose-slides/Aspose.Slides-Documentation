## **Επισκόπηση**

Το Aspose.Slides μπορεί να χρησιμοποιηθεί σε λειτουργία αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την έκδοση με άδεια, αλλά προσθέτει υδατογράφημα αξιολόγησης όταν οι παρουσιάσεις ανοίγονται ή αποθηκεύονται και περιορίζει την εξαγωγή κειμένου σε μία διαφάνεια.

Αυτό το άρθρο εξηγεί πώς λειτουργεί η άδεια στο Aspose.Slides και πώς να εφαρμόσετε μια άδεια πριν χρησιμοποιήσετε τη βιβλιοθήκη. Μια άδεια μπορεί να φορτωθεί από αρχείο, ροή ή ενσωματωμένο πόρο χρησιμοποιώντας την κλάση `License`. Το άρθρο δείχνει επίσης πώς να επαληθεύσετε αν η άδεια έχει εφαρμοστεί σωστά.

## **Άδεια στο Aspose.Slides**

* Μια έκδοση αξιολόγησης γίνεται με άδεια μετά την αγορά μιας άδειας και την προσθήκη μερικών γραμμών κώδικα (για την εφαρμογή της άδειας).
* Η άδεια είναι ένα αρχείο XML απλού κειμένου που περιέχει λεπτομέρειες όπως το όνομα του προϊόντος, ο αριθμός των προγραμματιστών στους οποίους αδειοδοτείται, η ημερομηνία λήξης της συνδρομής κλπ.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, επομένως δεν πρέπει να τροποποιήσετε το αρχείο. Ακόμα και μια ακούσια προσθήκη ενός επιπλέον διαχωριστικού γραμμής στο περιεχόμενο του αρχείου θα το ακυρώσει.
* Το Aspose.Slides for Java συνήθως προσπαθεί να βρει την άδεια στις ακόλουθες θέσεις:
  * Ένας ρητός διαδρομή
  * Ο φάκελος που περιέχει το Aspose.Slides.jar
* Για να αποφύγετε τους περιορισμούς που σχετίζονται με την έκδοση αξιολόγησης, πρέπει να ορίσετε μια άδεια πριν χρησιμοποιήσετε το **Aspose.Slides**. Πρέπει να ορίσετε μια άδεια μόνο μία φορά ανά εφαρμογή ή διαδικασία.

## **Εφαρμογή Άδειας**

Μια άδεια μπορεί να φορτωθεί από **αρχείο** ή **ροή**.

{{% alert color="info" %}}

Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/el/java/com.aspose.slides/License) για λειτουργίες αδειοδότησης.

{{% /alert %}} 

{{% alert color="warning" %}}

Νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με την έκδοση 21.4 ή νεότερη. Παλαιότερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν θα αναγνωρίσουν αυτές τις άδειες.

{{% /alert %}}

### **Αρχείο**

Η πιο εύκολη μέθοδος για την ορισμό άδειας απαιτεί να τοποθετήσετε το αρχείο άδειας στον φάκελο που περιέχει το Aspose.Slides.jar ή το jar της εφαρμογής σας.

Αυτός ο κώδικας Java σας δείχνει πώς να ορίσετε ένα αρχείο άδειας:

``` java
// Δημιουργεί ένα αντικείμενο της κλάσης License
com.aspose.slides.License license = new com.aspose.slides.License();

// Ορίζει τη διαδρομή του αρχείου άδειας
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" %}} 

Εάν τοποθετήσετε το αρχείο άδειας σε διαφορετικό κατάλογο, όταν καλέσετε τη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/java/com.aspose.slides/License#setLicense-java.lang.String-), το όνομα του αρχείου άδειας στο τέλος της ρητής διαδρομής πρέπει να είναι το ίδιο με το αρχείο άδειας σας.

Για παράδειγμα, μπορείτε να αλλάξετε το όνομα του αρχείου άδειας σε *Aspose.Slides.Java.lic.xml*. Στη συνέχεια, στον κώδικά σας, πρέπει να περάσετε τη διαδρομή του αρχείου (τελειώνοντας με *Aspose.Slides.Java.lic.xml*) στη μέθοδο [SetLicense](https://reference.aspose.com/slides/el/java/com.aspose.slides/License#setLicense-java.lang.String-).

{{% /alert %}}

### **Ροή**

Μπορείτε να φορτώσετε μια άδεια από μια ροή. Αυτός ο κώδικας Java σας δείχνει πώς να εφαρμόσετε μια άδεια από ροή:

``` java
// Δημιουργεί ένα αντικείμενο της κλάσης License
com.aspose.slides.License license = new com.aspose.slides.License();

// Ορίζει την άδεια μέσω μιας ροής
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **Γέφυρα PHP/Java**

Αν χρησιμοποιείτε το Aspose.Slides για PHP μέσω Java, μπορείτε να ορίσετε άδεια μέσω μιας γέφυρας PHP/Java. Αυτή η γέφυρα σας επιτρέπει να χρησιμοποιήσετε κλάσεις Java σε σύνταξη PHP. Για περισσότερες πληροφορίες, δείτε το [License in PHP](/slides/el/php-java/licensing/).

## **Επικύρωση Άδειας**

Για να ελέγξετε αν μια άδεια έχει οριστεί σωστά, μπορείτε να την επικυρώσετε. Αυτός ο κώδικας Java σας δείχνει πώς να επικυρώσετε μια άδεια:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **Συχνές Ερωτήσεις**

### Μπορώ να εφαρμόσω την άδεια σε ένα εντελώς χωρίς σύνδεση περιβάλλον (χωρίς πρόσβαση στο διαδίκτυο);

Ναι. Η επικύρωση της άδειας γίνεται τοπικά χρησιμοποιώντας το αρχείο άδειας· δεν απαιτείται σύνδεση στο διαδίκτυο.

### Τι συμβαίνει μετά τη λήξη της ετήσιας συνδρομής; Θα σταματήσει η βιβλιοθήκη να λειτουργεί;

Όχι. Η άδεια είναι διαρκής: μπορείτε να συνεχίσετε να χρησιμοποιείτε τις εκδόσεις που κυκλοφόρησαν πριν από την ημερομηνία λήξης της συνδρομής σας· απλώς δεν θα μπορείτε να χρησιμοποιήσετε νεότερες εκδόσεις χωρίς ανανέωση.
