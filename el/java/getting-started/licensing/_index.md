## **Επισκόπηση**

Aspose.Slides μπορεί να χρησιμοποιηθεί σε λειτουργία αξιολόγησης ή με έγκυρη άδεια. Η έκδοση αξιολόγησης παρέχει την ίδια λειτουργικότητα με την άδεια έκδοση, αλλά προσθέτει υδατογράφημα αξιολόγησης σε κάθε διαφάνεια κάθε παρουσίασης που αποθηκεύει και περικόπτει το κείμενο που διαβάζει ο κώδικάς σας μέσω του API.

Αυτό το άρθρο εξηγεί πώς λειτουργεί η αδειοδότηση στο Aspose.Slides και πώς να εφαρμόσετε μια άδεια πριν χρησιμοποιήσετε τη βιβλιοθήκη. Μια άδεια μπορεί να φορτωθεί από αρχείο, ρεύμα ή ενσωματωμένο πόρο χρησιμοποιώντας την κλάση `License`. Το άρθρο δείχνει επίσης πώς να επικυρώσετε εάν μια άδεια έχει εφαρμοστεί σωστά.

Η έκδοση αξιολόγησης απλώς γίνεται άδεια μετά την προσθήκη μερικών γραμμών κώδικα (για την εφαρμογή της άδειας).

Κάθε άδεια Aspose συνοδεύεται από ετήσια συνδρομή για δωρεάν αναβαθμίσεις σε νέες εκδόσεις ή διορθώσεις που κυκλοφορούν εντός της περιόδου συνδρομής. Οι χρήστες με αδειοδοτημένα προϊόντα (ή ακόμη και εκδόσεις αξιολόγησης) λαμβάνουν δωρεάν και απεριόριστη τεχνική υποστήριξη.

## **Αδειοδότηση στο Aspose.Slides**

* Μια έκδοση αξιολόγησης γίνεται αδειοδοτημένη αφού αγοράσετε μια άδεια και προσθέσετε μερικές γραμμές κώδικα (για την εφαρμογή της άδειας).
* Η άδεια είναι ένα απλό αρχείο XML κειμένου που περιέχει στοιχεία όπως το όνομα προϊόντος, ο αριθμός των προγραμματιστών που αδειοδούεται, η ημερομηνία λήξης της συνδρομής κ.λπ.
* Το αρχείο άδειας είναι ψηφιακά υπογεγραμμένο, επομένως δεν πρέπει να το τροποποιήσετε. Ακόμη και μια ακούσια προσθήκη μιας επιπλέον αλλαγής γραμμής στο περιεχόμενο του αρχείου θα το ακυρώσει.
* Το Aspose.Slides for Java συνήθως προσπαθεί να βρει την άδεια σε αυτές τις θέσεις:
  * Ένας ρητός διαδρομή
  * Ο φάκελος που περιέχει το Aspose.Slides.jar
* Για να αποφύγετε τους περιορισμούς που σχετίζονται με την έκδοση αξιολόγησης, πρέπει να ορίσετε μια άδεια πριν χρησιμοποιήσετε το **Aspose.Slides**. Πρέπει να ορίσετε την άδεια μόνο μία φορά ανά εφαρμογή ή διεργασία.

{{% alert color="info" title="Σημείωση" %}}

Ίσως θέλετε να δείτε το [Metered Licensing](/slides/el/java/metered-licensing/).

{{% /alert %}} 


## **Εφαρμογή Άδειας**

Μια άδεια μπορεί να φορτωθεί από **αρχείο** ή **ρεύμα**.

{{% alert color="info" title="Σημείωση" %}}

Το Aspose.Slides παρέχει την κλάση [License](https://reference.aspose.com/slides/java/com.aspose.slides/license/) για λειτουργίες αδειοδότησης.

{{% /alert %}} 

{{% alert color="warning" title="Προειδοποίηση" %}}

Οι νέες άδειες μπορούν να ενεργοποιήσουν το Aspose.Slides μόνο με έκδοση 21.4 ή νεότερη. Παλύτερες εκδόσεις χρησιμοποιούν διαφορετικό σύστημα αδειοδότησης και δεν θα αναγνωρίσουν αυτές τις άδειες.

{{% /alert %}}

### **Αρχείο**

Η πιο εύκολη μέθοδος καθορισμού άδειας απαιτεί να τοποθετήσετε το αρχείο άδειας στον φάκελο που περιέχει το Aspose.Slides.jar ή το jar της εφαρμογής σας.

Αυτός ο κώδικας Java δείχνει πώς να ορίσετε ένα αρχείο άδειας:

``` java
// Δημιουργεί μια παρουσία της κλάσης License
com.aspose.slides.License license = new com.aspose.slides.License();

// Ορίζει τη διαδρομή του αρχείου άδειας
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" title="Προειδοποίηση" %}}

Εάν τοποθετήσετε το αρχείο άδειας σε διαφορετικό κατάλογο, όταν καλέσετε τη μέθοδο [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-) το όνομα του αρχείου άδειας στο τέλος της καθορισμένης διαδρομής πρέπει να είναι το ίδιο με το όνομα του αρχείου άδειας σας.

Για παράδειγμα, μπορείτε να αλλάξετε το όνομα του αρχείου άδειας σε *Aspose.Slides.Java.lic.xml*. Στη συνέχεια, στον κώδικά σας, πρέπει να περάσετε τη διαδρομή προς το αρχείο (τελειώνοντας με *Aspose.Slides.Java.lic.xml*) στη μέθοδο [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-).

{{% /alert %}}

### **Ρεύμα**

Μπορείτε να φορτώσετε μια άδεια από ρεύμα. Αυτός ο κώδικας Java δείχνει πώς να εφαρμόσετε μια άδεια από ρεύμα:

``` java
// Δημιουργεί μια παρουσία της κλάσης License
com.aspose.slides.License license = new com.aspose.slides.License();

// Ορίζει την άδεια μέσω ρεύματος
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **PHP/Java Bridge**

Εάν χρησιμοποιείτε το Aspose.Slides for PHP μέσω Java, μπορείτε να ορίσετε άδεια μέσω μιας γέφυρας PHP/Java. Αυτή η γέφυρα σας επιτρέπει να χρησιμοποιείτε κλάσεις Java σε σύνταξη PHP. Για περισσότερες πληροφορίες, δείτε το [License in PHP](/slides/el/php-java/licensing/).

## **Επικύρωση Άδειας**

Για να ελέγξετε εάν μια άδεια έχει οριστεί σωστά, μπορείτε να την επικυρώσετε. Αυτός ο κώδικας Java δείχνει πώς να επικυρώσετε μια άδεια:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **Ασφάλεια Νημάτων**

{{% alert color="warning" title="Προειδοποίηση" %}}

Η μέθοδος [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.io.InputStream-) δεν είναι ασφαλής για νήματα. Εάν αυτή η μέθοδος πρέπει να κληθεί ταυτόχρονα από πολλά νήματα, ίσως θελήσετε να χρησιμοποιήσετε πρωτόκολλα συγχρονισμού (όπως κλείδωμα) για να αποφύγετε προβλήματα.

{{% /alert %}}

## **Συχνές Ερωτήσεις**

### Μπορώ να εφαρμόσω την άδεια σε περιβάλλον πλήρως εκτός σύνδεσης (χωρίς πρόσβαση στο διαδίκτυο);

Ναι. Η επικύρωση της άδειας εκτελείται τοπικά χρησιμοποιώντας το αρχείο άδειας· δεν απαιτείται σύνδεση στο διαδίκτυο.

### Τι συμβαίνει μετά τη λήξη της ετήσιας συνδρομής; Θα σταματήσει η λειτουργία της βιβλιοθήκης;

Όχι. Η άδεια είναι διαρκής: μπορείτε να συνεχίσετε να χρησιμοποιείτε εκδόσεις που κυκλοφόρησαν πριν από την ημερομηνία λήξης της συνδρομής· απλώς δεν θα μπορείτε να χρησιμοποιήσετε νεότερες κυκλοφορίες χωρίς ανανέωση.
