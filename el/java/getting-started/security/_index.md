## **Εισαγωγή**

Αυτό το άρθρο συγκεντρώνει τις πληροφορίες που συνήθως χρειάζεται μια αξιολόγηση ασφαλείας μιας εφαρμογής που χρησιμοποιεί το Aspose.Slides for Java: πώς η βιβλιοθήκη επεξεργάζεται παρουσιάσεις, τι προσθέτει στις εξαρτήσεις του έργου σας, πώς να ελέγξετε ότι το αρχείο JAR προέρχεται από την Aspose και ποια τρίτα συστατικά περιέχει το αρχείο JAR.

## **Ασφάλεια στο Aspose.Slides**

Aspose εφαρμόζει βέλτιστες πρακτικές κατά την ανάπτυξη των προϊόντων της.

* Το Aspose.Slides for Java χρησιμοποιείται για τη δημιουργία, τροποποίηση και μετατροπή παρουσιάσεων. Δεν εκτελεί σενάρια σε παρουσιάσεις. Το Aspose.Slides αναλύει τη δομή της παρουσίασης και επιτρέπει στον κώδικά σας να δουλεύει με το αντικειμενοστραφές μοντέλο.
* Το Aspose.Slides λειτουργεί ως βιβλιοθήκη που αναλύει και ερμηνεύει έγγραφα χωρίς να εκτελεί απομακρυσμένο κώδικα. Όλα τα προϊόντα Aspose εκτελούνται στους δικούς σας υπολογιστές. Δεν μεταβιβάζουν δεδομένα στην Aspose. Η μόνη εξαίρεση είναι η [metered licensing](/slides/el/java/metered-licensing/): εάν τη χρησιμοποιήσετε, επεξεργάζονται μόνο τις πληροφορίες χρήσης του API σας.
* Τα στοιχεία Aspose εκτελούνται στο ίδιο περιβάλλον χρήστη με τις κανονικές εφαρμογές. Συνεπώς, τα στοιχεία Aspose δεν αποτελούν κίνδυνο για κρίσιμους πόρους του συστήματος. Επιπλέον, όταν ένα στοιχείο Aspose ανοίγει ένα έγγραφο, οι μακροεντολές δεν εκτελούνται αυτόματα.

## **Εξαρτήσεις Maven**

Το αντικείμενο Maven του Aspose.Slides for Java, `com.aspose:aspose-slides`, δεν δηλώνει εξαρτήσεις: το αρχείο POM του περιέχει μόνο τις συντεταγμένες του ίδιου αντικειμένου. Όταν το προσθέτετε σε ένα έργο, το Maven προσθέτει αυτό το μοναδικό αρχείο JAR και τίποτα άλλο. Για να παραθέσετε κάθε αντικείμενο που επιλύει το έργο σας, συμπεριλαμβανομένων των διευθετικών εξαρτήσεων, εκτελέστε αυτήν την εντολή στον φάκελο του έργου:

```bash
mvn dependency:tree
```

Στο έργο από το [Installation](/slides/el/java/installation/), η έξοδος εμφανίζει το Aspose.Slides ως τη μοναδική εξάρτηση:

```text
[INFO] com.example:hello-slides:jar:1.0
[INFO] \- com.aspose:aspose-slides:jar:jdk16:26.9:compile
```

## **Επαλήθευση του αρχείου JAR**

Η Aspose υπογράφει το αρχείο JAR. Για να ελέγξετε την υπογραφή, εκτελέστε το εργαλείο `jarsigner` από το JDK στο φάκελο που περιέχει το αρχείο JAR:

```bash
jarsigner -verify aspose-slides-26.9-jdk16.jar
```

Η εντολή εκτυπώνει `jar verified.` όταν η υπογραφή είναι έγκυρη και καμία καταχώρηση δεν έχει αλλάξει από τη στιγμή που υπεγράφη το αρχείο. Αυτό το μήνυμα δεν αναφέρει το όνομα του υπογράφοντος. Για να επιβεβαιώσετε ότι η Aspose υπέγραψε το αρχείο, προσθέστε τις επιλογές `-verbose` και `-certs` και ελέγξτε ότι το πιστοποιητικό του υπογράφοντος εκδίδεται σε `CN=ASPOSE PTY LTD`. Όταν το Maven κατεβάζει το αρχείο JAR, ελέγχει επίσης το άθροισμα ελέγχου SHA-1 που δημοσιεύει το αποθετήριο δίπλα στο αρχείο.

## **Συστατικά τρίτων**

Το Aspose.Slides for Java περιλαμβάνει κώδικα και δεδομένα από συστατικά τρίτων. Είναι μέρος του αρχείου JAR, όχι ξεχωριστά αντικείμενα Maven, έτσι το `mvn dependency:tree` και άλλα εργαλεία που διαβάζουν εξαρτήσεις Maven δεν τα εμφανίζουν. Το αρχείο JAR περιέχει την ειδοποίηση *META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf*, η οποία καταχωρεί τα συστατικά και τις άδειές τους:

| Συστατικό | Άδεια όπως αναφέρεται στην ειδοποίηση |
|---|---|
| DotNetZip | Microsoft Public License (Ms-PL) |
| Bouncy Castle | MIT-style license |
| Mono | MIT license; some parts under other licenses that the notice lists |
| RSWOP.ICM color profile | Microsoft license terms |
| sRGB_v4_ICC_preference.icc color profile | ICC permission to use, copy, and distribute the unchanged file |
| Apache | Apache License 2.0 |
| ANTLR | BSD License |
| sfntly | Apache License 2.0 |

Για να εξάγετε την ειδοποίηση από το αρχείο JAR, εκτελέστε το εργαλείο `jar` από το JDK στο φάκελο που περιέχει το αρχείο JAR:

```bash
jar xf aspose-slides-26.9-jdk16.jar "META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf"
```

## **Συχνές ερωτήσεις**

**Χρησιμοποιεί το Aspose.Slides for Java εξωτερικά πακέτα;**

Δεν έχει εξαρτήσεις Maven, όπως δείχνει η ενότητα [Maven Dependencies](#maven-dependencies), αλλά περιλαμβάνει τα συστατικά τρίτων που αναφέρονται στην ενότητα [Third-Party Components](#third-party-components). Συμπεριλάβετε τόσο το αρχείο JAR όσο και αυτά τα συστατικά στην αξιολόγηση ασφαλείας σας.

**Χρειάζεται το Aspose.Slides for Java πρόσβαση στο δίκτυο;**

Όχι. Η δημιουργία, αποθήκευση και απόδοση παρουσιάσεων λειτουργούν σε σύστημα χωρίς καμία σύνδεση δικτύου. Η μόνη δυνατότητα που στέλνει δεδομένα στην Aspose είναι η [metered licensing](/slides/el/java/metered-licensing/), η οποία αναφέρει τη χρήση του API.

**Περιέχει το Aspose.Slides for Java εγγενή κώδικα;**

Όχι. Το αρχείο JAR περιέχει μόνο κλάσεις Java και πόρους, επομένως δεν προσθέτει εγγενείς βιβλιοθήκες στην εφαρμογή σας. Στο Linux, η υποστήριξη γραμματοσειρών της Java runtime απαιτεί τη βιβλιοθήκη fontconfig και γραμματοσειρές από το λειτουργικό σύστημα· δείτε τις [System Requirements](/slides/el/java/system-requirements/#linux).
