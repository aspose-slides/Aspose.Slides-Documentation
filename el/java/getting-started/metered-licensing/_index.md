## **Εισαγωγή**

Η άδεια με μέτρηση είναι ένας μηχανισμός αδειοδότησης που μπορεί να χρησιμοποιηθεί παράλληλα με τις υπάρχουσες μεθόδους αδειοδότησης. Εάν θέλετε να χρεώνονται βάσει της χρήσης των λειτουργιών του Aspose.Slides API, επιλέγετε την άδεια με μέτρηση.

## **Εφαρμογή κλειδιών Metered**

{{% alert color="info" %}} 

Η άδεια με μέτρηση είναι ένας νέος μηχανισμός αδειοδότησης που μπορεί να χρησιμοποιηθεί παράλληλα με τις υπάρχουσες μεθόδους αδειοδότησης. Εάν θέλετε να χρεώνονται βάσει της χρήσης των λειτουργιών του Aspose.Slides API, επιλέγετε την άδεια με μέτρηση.

Όταν αγοράζετε μια άδεια με μέτρηση, λαμβάνετε κλειδιά (και όχι αρχείο άδειας). Αυτό το κλειδί Metered μπορεί να εφαρμοστεί χρησιμοποιώντας την κλάση [Metered](https://reference.aspose.com/slides/el/java/com.aspose.slides/metered/) που παρέχει η Aspose για λειτουργίες μέτρησης. Για περισσότερες λεπτομέρειες, δείτε το [Metered Licensing FAQ](https://purchase.aspose.com/faqs/licensing/metered).

{{% /alert %}} 

1. Δημιουργήστε μια παρουσία της κλάσης [Metered](https://reference.aspose.com/slides/el/java/com.aspose.slides/metered/).

1. Μετάβιβασε τα δημόσια και ιδιωτικά κλειδιά σου στη μέθοδο [setMeteredKey](https://reference.aspose.com/slides/el/java/com.aspose.slides/metered/#setMeteredKey-java.lang.String-java.lang.String-).

1. Εκτελέστε κάποια επεξεργασία (εκτελέστε εργασίες).

1. Κάλεσε τη μέθοδο [getConsumptionQuantity](https://reference.aspose.com/slides/el/java/com.aspose.slides/metered/#getConsumptionQuantity--) της κλάσης `Metered`.

Θα πρέπει να δείτε το ποσό/ποσότητα των αιτημάτων API που έχετε καταναλώσει μέχρι τώρα.

Αυτό το παράδειγμα κώδικα δείχνει πώς να χρησιμοποιήσετε την άδεια με μέτρηση:

```java
// Δημιουργεί μια παρουσία της κλάσης Metered
com.aspose.slides.Metered metered = new com.aspose.slides.Metered();

try {
    // Περνά τα δημόσια και ιδιωτικά κλειδιά στο αντικείμενο Metered
    metered.setMeteredKey("<valid public key>", "<valid private key>");

    // Λαμβάνει την τιμή της καταναλωμένης ποσότητας πριν από τις κλήσεις API
    double amountBefore = com.aspose.slides.Metered.getConsumptionQuantity();
    System.out.println("Amount consumed before: " + amountBefore);

    // Κάντε κάτι με το API του Aspose.Slides εδώ
    // ...
    // Λαμβάνει την τιμή της καταναλωμένης ποσότητας μετά τις κλήσεις API
    double amountAfter = com.aspose.slides.Metered.getConsumptionQuantity();
    System.out.println("Amount consumed after: " + amountAfter);
} catch (Exception ex) {
    ex.printStackTrace();
}
```

{{% alert color="warning" title="NOTE"  %}} 

Για να χρησιμοποιήσετε την άδεια με μέτρηση, χρειάζεστε σταθερή σύνδεση στο Διαδίκτυο, επειδή ο μηχανισμός αδειοδότησης χρησιμοποιεί το Διαδίκτυο για συνεχή αλληλεπίδραση με τις υπηρεσίες μας και εκτέλεση υπολογισμών.

{{% /alert %}} 

## **FAQ**

### Μπορώ να χρησιμοποιήσω μια άδεια Metered μαζί με μια κανονική (μόνιμη ή προσωρινή) στην ίδια εφαρμογή;

Ναι. Η Metered είναι ένας πρόσθετος μηχανισμός αδειοδότησης που μπορεί να χρησιμοποιηθεί παράλληλα με τις υπάρχουσες [μεθόδους αδειοδότησης](/slides/el/java/licensing/). Επιλέγετε ποιος μηχανισμός θα εφαρμοστεί όταν ξεκινά η εφαρμογή.

### Τι ακριβώς μετράται ως κατανάλωση υπό μια άδεια Metered: λειτουργίες ή αρχεία;

Η χρήση του API μετράται, δηλαδή ο αριθμός των αιτημάτων ή των λειτουργιών. Μπορείτε να λάβετε την τρέχουσα κατανάλωση μέσω των [μεθόδων παρακολούθησης κατανάλωσης](https://reference.aspose.com/slides/el/java/com.aspose.slides/metered/).

### Είναι η Metered κατάλληλη για μικροϋπηρεσίες και περιβάλλοντα serverless όπου οι παρουσίες επανεκκινούνται συχνά;

Ναι. Επειδή η λογιστική γίνεται σε επίπεδο κλήσεων API, τα σενάρια με συχνές εκκινήσεις είναι συμβατά, αρκεί να υπάρχει σταθερή πρόσβαση δικτύου για τους υπολογισμούς Metered.

### Διαφέρει η λειτουργικότητα της βιβλιοθήκης όταν χρησιμοποιείται άδεια Metered σε σύγκριση με μόνιμη άδεια;

Όχι. Αυτό αφορά μόνο τον μηχανισμό αδειοδότησης και χρέωσης· οι δυνατότητες του προϊόντος παραμένουν ίδιες.

### Πώς σχετίζεται η Metered με την έκδοση δοκιμής και την προσωρινή άδεια;

Η έκδοση δοκιμής έχει περιορισμούς και υδατογραφήματα, η [προσωρινή άδεια](https://purchase.aspose.com/temporary-license/) αφαιρεί περιορισμούς για 30 ημέρες, και η Metered αφαιρεί περιορισμούς και χρεώνει βάσει πραγματικής χρήσης.

### Μπορώ να ελέγξω τον προϋπολογισμό αντιδρώντας αυτόματα όταν ξεπεραστεί ένα όριο κατανάλωσης;

Ναι. Συνηθισμένη πρακτική είναι η περιοδική ανάγνωση της τρέχουσας κατανάλωσης μέσω των [μεθόδων παρακολούθησης](https://reference.aspose.com/slides/el/java/com.aspose.slides/metered/) και η υλοποίηση δικών σας ορίων ή ειδοποιήσεων σε επίπεδο εφαρμογής ή παρακολούθησης.
