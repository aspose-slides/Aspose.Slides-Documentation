Η μετατροπή από PPT σε PPTX υποστηρίζεται από το Aspose.Slides for Java. Τα περισσότερα χαρακτηριστικά παρουσίασης - κύριες διαφάνειες, δομή κ.λπ. - διατηρούνται όταν μετατρέπονται από τη μία μορφή στην άλλη, αλλά υπάρχουν [μερικοί περιορισμοί](/slides/el/java/ppt-to-pptx-conversion/).

{{% /alert %}} 
## **Features Supported in Conversion**
Το Aspose.Slides for Java παρέχει μερική υποστήριξη για τη μετατροπή του αρχείου PPT σε PPTX. Η υποστήριξη για τη μετατροπή μόλις εισήχθη στο Aspose.Slides for Java, επομένως έχει μερικούς περιορισμούς και λειτουργεί καλύτερα για απλές παρουσιάσεις. Το κύριο πλεονέκτημα που προσφέρει το Aspose.Slides for Java κατά τη μετατροπή PPT σε PPTX είναι η ευκολία χρήσης του API. Για να δείτε παραδείγματα κώδικα, διαβάστε για την [Μετατροπή PPT σε PPTX](). Παρακάτω, οι λίστες εξηγούν ποια χαρακτηριστικά υποστηρίζονται και ποια όχι για τη μετατροπή PPT σε PPTX.

## **Supported Features**
The following features are supported for conversion:

- Μετατροπή της δομής των κύριων διαφανειών, διατάξεων και διαφανειών.
- Μετατροπή γραφημάτων.
- Ομαδικά σχήματα.
- Μετατροπή αυτόματων σχημάτων, συμπεριλαμβανομένων των ορθογωνίων και των έλλειψών. 
- Σχήματα με προσαρμοσμένη γεωμετρία.
- Στυλ γεμίσματος με υφές και εικόνες για αυτόματα σχήματα.
- Μετατροπή δεσμευτικών θέσεων.
- Μετατροπή γραμμών και πολυγραμμών.
- Μορφές γραμμής και γεμίσματος.
- Στυλ γεμίσματος διαβάθμισης.
- Πλαίσια OLE, πίνακες, πλαίσια βίντεο και ήχου κ.λπ.
- Ιδιότητες κινήσεων και παρουσίασης.
- Μετατροπή κειμένου σε πλαίσια κειμένου και δεσμευτές κειμένου.
