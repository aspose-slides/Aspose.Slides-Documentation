## **Χαρακτηριστικά που Υποστηρίζονται στη Μετατροπή**
Το Aspose.Slides for Java παρέχει μερική υποστήριξη για τη μετατροπή της μορφής αρχείου PPT σε PPTX. Η υποστήριξη για τη μετατροπή μόλις εισήχθη στο Aspose.Slides for Java, οπότε έχει ορισμένους περιορισμούς και λειτουργεί καλύτερα για απλές παρουσιάσεις. Το κύριο πλεονέκτημα που προσφέρει το Aspose.Slides for Java κατά τη μετατροπή από PPT σε PPTX είναι η ευκολία χρήσης του API. Για να δείτε παραδείγματα κώδικα, δείτε [Convert PPT to PPTX](/slides/el/java/convert-ppt-to-pptx/). Η παρακάτω λίστα εμφανίζει ποια χαρακτηριστικά υποστηρίζονται για τη μετατροπή από PPT σε PPTX.

## **Υποστηριζόμενα Χαρακτηριστικά**
Τα παρακάτω χαρακτηριστικά υποστηρίζονται για τη μετατροπή:

- Μετατροπή της δομής των κύριων προτύπων, διατάξεων και διαφανειών.
- Μετατροπή διαγραμμάτων.
- Ομαδικά σχήματα.
- Μετατροπή αυτόματων σχημάτων, συμπεριλαμβανομένων ορθογώνιων και ελλειπτικών σχημάτων.
- Σχήματα με προσαρμοσμένη γεωμετρία.
- Υφές και στυλ γεμίσματος εικόνων για αυτόματες μορφές.
- Μετατροπή δεσμευτικών θέσεων.
- Μετατροπή γραμμών και πολυγραμμών.
- Μορφές γραμμής και γεμίσματος.
- Στυλ διαβάθμισης γεμίσματος.
- Πλαίσια OLE, πίνακες, βίντεο και ηχητικά πλαίσια κ.ά.
- Ιδιότητες κίνησης και παρουσίασης.
- Μετατροπή κειμένου σε πλαίσια κειμένου και δεσμευτές κειμένου.
