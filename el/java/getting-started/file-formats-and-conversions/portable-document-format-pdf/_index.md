{{% alert color="info" title="Note" %}}

Το [Portable Document Format](https://en.wikipedia.org/wiki/PDF) είναι μια μορφή αρχείου που δημιουργήθηκε από την Adobe Systems για την ανταλλαγή εγγράφων μεταξύ οργανισμών. Ο σκοπός της μορφής ήταν η διατήρηση του περιεχομένου και της διάταξης ανεξάρτητα από την πλατφόρμα προβολής. Το Aspose.Slides for Java σας επιτρέπει να μετατρέπετε αρχεία παρουσίασης σε PDF.

{{% /alert %}}

## **PDF στο Aspose.Slides for Java**
Οποιαδήποτε παρουσίαση μπορεί να φορτωθεί στο Aspose.Slides for Java μπορεί να μετατραπεί σε PDF που συμμορφώνεται με [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) ή [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) ανάλογα με την επιλογή σας. Το Aspose.Slides for Java εξάγει παρουσιάσεις σε PDF και στις περισσότερες περιπτώσεις, το παραγόμενο PDF φαίνεται ακριβώς όπως η αρχική παρουσίαση.

Το Aspose.Slides υποστηρίζει τα ακόλουθα χαρακτηριστικά παρουσίασης κατά τη μετατροπή σε PDF:

- Εικόνες, πλαίσια κειμένου και άλλα σχήματα.
- Κείμενο και μορφοποίηση.
- Παράγραφοι και μορφοποίηση.
- Υπερσύνδεσμοι.
- Κεφαλίδες και υποσέλιδα.
- Κουκίδες.
- Πίνακες.

Μπορείτε να εξάγετε παρουσιάσεις σε PDF απευθείας χρησιμοποιώντας το Aspose.Slides for Java: δεν χρειάζεστε κανένα άλλο στοιχείο. Επιπλέον, μπορείτε να προσαρμόσετε την εξαγωγή παρουσίασης σε PDF με διάφορες επιλογές όπως εξηγείται στο [Convert PPT and PPTX to PDF](/slides/el/java/convert-powerpoint-to-pdf/).
