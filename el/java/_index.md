Το Aspose.Slides for Java είναι μια βιβλιοθήκη κλάσεων για δημιουργία, ανάγνωση, επεξεργασία και μετατροπή παρουσιάσεων PowerPoint και OpenDocument σε εφαρμογές Java, χωρίς το Microsoft PowerPoint.

Φορτώνει και αποθηκεύει αρχεία PPT, PPTX, PPS, POT και ODP, συμπεριλαμβανομένων των εκδόσεων με μακροεντολές και προτύπων, και εξάγει σε PDF, XPS, HTML, SVG, TIFF, Markdown και εικόνες.

<a name="your-first-presentation"></a>

## **Η πρώτη σας παρουσίαση**

Το Aspose.Slides for Java δημοσιεύεται στο δικό του αποθετήριο Maven της Aspose, όχι στο Maven Central. Δημιουργήστε έναν φάκελο για ένα έργο Maven και αποθηκεύστε αυτό το *pom.xml* μέσα του. Καθορίζει το αποθετήριο, προσθέτει τη βιβλιοθήκη και ορίζει την κλάση που θα εκτελεστεί:

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0">
    <modelVersion>4.0.0</modelVersion>
    <groupId>com.example</groupId>
    <artifactId>hello-slides</artifactId>
    <version>1.0</version>

    <properties>
        <maven.compiler.release>11</maven.compiler.release>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <exec.mainClass>HelloSlides</exec.mainClass>
    </properties>

    <repositories>
        <repository>
            <id>AsposeJavaAPI</id>
            <name>Aspose Java API</name>
            <url>https://releases.aspose.com/java/repo/</url>
        </repository>
    </repositories>

    <dependencies>
        <dependency>
            <groupId>com.aspose</groupId>
            <artifactId>aspose-slides</artifactId>
            <version>26.9</version>
            <classifier>jdk16</classifier>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.15.0</version>
            </plugin>
        </plugins>
    </build>
</project>
```

Αποθηκεύστε αυτόν τον κώδικα ως *src/main/java/HelloSlides.java*:

```java
import com.aspose.slides.*;

public class HelloSlides {
    public static void main(String[] args) {
        // Δημιουργήστε μια παρουσίαση. Περιέχει ήδη μία κενή διαφάνεια.
        Presentation presentation = new Presentation();
        try {
            // Λάβετε την πρώτη διαφάνεια.
            ISlide slide = presentation.getSlides().get_Item(0);

            // Προσθέστε ένα σχήμα σύννεφο και τοποθετήστε κείμενο σε αυτό.
            IAutoShape autoShape = slide.getShapes().addAutoShape(ShapeType.Cloud, 20, 20, 200, 80);
            autoShape.getTextFrame().setText("Hello, Aspose!");

            // Αποθηκεύστε την παρουσίαση ως αρχείο PPTX.
            presentation.save("new_presentation.pptx", SaveFormat.Pptx);
        } finally {
            presentation.dispose();
        }
    }
}
```

Στη συνέχεια, με εγκατεστημένο το JDK 11 ή νεότερο και το Apache Maven, τρέξτε αυτήν την εντολή στον φάκελο του έργου:

```bash
mvn compile exec:java
```

Το πρόγραμμα αποθηκεύει το *new_presentation.pptx* στον φάκελο του έργου, με μία διαφάνεια που περιέχει ένα σχήμα σύννεφων με κείμενο. Σε Linux, πρέπει να είναι εγκατεστημένο το fontconfig και τουλάχιστον μία γραμματοσειρά· δείτε την [Installation](/slides/el/java/installation/#linux). Χωρίς άδεια, το αποθηκευμένο αρχείο φέρει υδατογράφημα αξιολόγησης — δείτε το [Licensing](/slides/el/java/licensing/). Για περισσότερους τρόπους δημιουργίας και γεμίσματος μιας παρουσίασης, δείτε το [Create Presentations](/slides/el/java/create-presentation/).
