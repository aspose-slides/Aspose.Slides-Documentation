Το Aspose.Slides for PHP via Java είναι μια βιβλιοθήκη κλάσεων για δημιουργία, ανάγνωση, επεξεργασία και μετατροπή παρουσιάσεων PowerPoint και OpenDocument σε εφαρμογές PHP, χωρίς το Microsoft PowerPoint ή την αυτοματοποίηση του Office.

Φορτώνει και αποθηκεύει αρχεία PPT, PPTX, PPS, POT και ODP, συμπεριλαμβανομένων των εκδόσεων με μακροεντολές και προτύπων, και εξάγει σε PDF, XPS, HTML, SVG, TIFF, Markdown και εικόνες.

## **Η πρώτη σας παρουσίαση**

Το Aspose.Slides for PHP via Java εκτελείται σε Java μέσα στον Apache Tomcat, και τα PHP σενάρια σας το προσεγγίζουν μέσω του PHP/Java Bridge. [Εγκατάσταση](/slides/el/php-java/installation/) ρυθμίζει το PHP 8.3 ή παλαιότερο, τη Java, τον Tomcat και τη γέφυρα, και στη συνέχεια εγκαθιστά το πακέτο από το Packagist σε φάκελο έργου:

```bash
composer require aspose/slides
```

Κατόπιν αντιγράψτε το αρχείο JAR του πακέτου στη γέφυρα και επανεκκινήστε τον Tomcat, όπως στο βήμα 4 της [Εγκατάσταση σε Linux](/slides/el/php-java/installation/#install-on-linux) ή στο βήμα 6 της [Εγκατάσταση σε Windows](/slides/el/php-java/installation/#install-on-windows). Με τον Tomcat σε λειτουργία, αποθηκεύστε αυτό το σενάριο ως *hello.php* στον φάκελο του έργου και εκτελέστε `php hello.php`:

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/lib/aspose.slides.php");

use aspose\slides\Presentation;
use aspose\slides\SaveFormat;
use aspose\slides\ShapeType;

$presentation = new Presentation();
try {
    $slide = $presentation->getSlides()->get_Item(0);
    $shape = $slide->getShapes()->addAutoShape(ShapeType::Rectangle, 50, 50, 400, 100);
    $shape->getTextFrame()->setText("Hello, Aspose.Slides!");
    $presentation->save(__DIR__ . "/hello.pptx", SaveFormat::Pptx);
} finally {
    $presentation->dispose();
}
```

Το σενάριο αποθηκεύει το *hello.pptx* δίπλα του, με μία διαφάνεια που περιέχει ένα πλαίσιο κειμένου. Χωρίς άδεια, το αποθηκευμένο αρχείο φέρει υδατογράφημα αξιολόγησης — δείτε την [Άδεια χρήσης](/slides/el/php-java/licensing/). Για περισσότερους τρόπους δημιουργίας και πλήρωσης μιας παρουσίασης, δείτε την [Δημιουργία παρουσιάσεων](/slides/el/php-java/create-presentation/).
