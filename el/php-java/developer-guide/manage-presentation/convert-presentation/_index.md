## **Επισκόπηση**

Aspose.Slides for PHP via Java μπορεί να φορτώσει παρουσιάσεις PowerPoint και OpenDocument και να τις αποθηκεύσει ή να τις μετατρέψει σε πολλές άλλες μορφές χωρίς το Microsoft PowerPoint, το OpenOffice ή το LibreOffice. Μπορείτε να μετατρέψετε παλαιά αρχεία PPT σε σύγχρονα PPTX, να εξάγετε παρουσιάσεις σε έγγραφα σταθερής διάταξης όπως PDF και XPS, να δημοσιεύσετε διαφάνειες ως HTML ή να αποδώσετε διαφάνειες ως αρχεία εικόνας για προεπισκοπήσεις, μικρογραφίες και αρχεία.

Οι περισσότερες μετατροπές εγγράφων ακολουθούν την ίδια γενική ροή εργασίας: φορτώνετε το αρχείο προέλευσης, επιλέγετε τη μορφή εξόδου που απαιτείται και εφαρμόζετε επιλογές συγκεκριμένες για τη μορφή, εφόσον χρειάζεται. Για μορφές εικόνας, κάθε διαφάνεια αποδίδεται χωριστά και στη συνέχεια αποθηκεύεται ως ραστερ ή διάνυσμα εικόνας. Τα ειδικά άρθρα που συνδέονται παρακάτω παρέχουν τις λεπτομέρειες υλοποίησης για κάθε περίπτωση.

## **Μετατροπή PowerPoint και OpenDocument**

Aspose.Slides for PHP via Java υποστηρίζει μετατροπή από κοινά χρησιμοποιούμενες μορφές παρουσίασης όπως PPT, PPTX, PPS, PPSX, POT, POTX και ODP. Το ίδιο API μετατροπής χρησιμοποιείται για αρχεία PowerPoint και OpenDocument, έτσι μια ροή εργασίας που αποθηκεύει ένα αρχείο PPTX σε PDF μπορεί συνήθως να εφαρμοστεί σε αρχείο ODP αλλάζοντας μόνο το αρχείο εισόδου.

Κατά τη μετατροπή αρχείων ODP, θυμηθείτε ότι οι εφαρμογές PowerPoint και OpenDocument δεν υποστηρίζουν κάθε διάταξη και χαρακτηριστικό μορφοποίησης με ακριβώς τον ίδιο τρόπο. Εάν ένα αρχείο ODP δημιουργήθηκε στο LibreOffice ή στο OpenOffice Impress, ελέγξτε το αποτέλεσμα και χρησιμοποιήστε τις επιλογές που περιγράφονται σε [Convert OpenDocument Presentations](/slides/el/php-java/convert-openoffice-odp/) όταν χρειάζεστε καθοδήγηση ειδική για τη μορφή.

## **Μετατροπή PPT σε PPTX**

PPT είναι η παλαιότερη δυαδική μορφή PowerPoint, ενώ PPTX είναι η σύγχρονη μορφή Office Open XML. Aspose.Slides for PHP via Java υποστηρίζει μετατροπή υψηλής πιστότητας από PPT σε PPTX διατηρώντας πολύπλοκες δομές παρουσίασης όπως master, layout, διαφάνειες, διαγράμματα, ομαδοποιημένα σχήματα, placeholders, πλαίσια κειμένου, υφές και γεμίσματα εικόνας.

Για λεπτομέρειες, δείτε [Convert PPT to PPTX](/slides/el/php-java/convert-ppt-to-pptx/) και [PPT vs PPTX](/slides/el/php-java/ppt-vs-pptx/).

## **Εξαγωγή Σταθερής Διάταξης**

PDF, XPS και TIFF είναι χρήσιμα όταν η έξοδος πρέπει να παραμένει η ίδια σε όλες τις συσκευές και δεν πρέπει να επεξεργαστεί ως παρουσίαση. Τα ειδικά άρθρα PDF, XPS και TIFF εξηγούν πώς να ελέγξετε τη συμμόρφωση, κρυφές διαφάνειες, σημειώσεις, ποιότητα εικόνας, συμπίεση, μορφή pixel και μέγεθος εξόδου.

## **Εξαγωγή HTML και Εικόνας**

Η εξαγωγή σε HTML και HTML5 είναι χρήσιμη για προβολή σε περιηγητές, δημοσίευση στο web και ελαφριά κοινή χρήση. Η εξαγωγή εικόνας είναι χρήσιμη όταν κάθε διαφάνεια πρέπει να γίνει ξεχωριστή προεπισκόπηση, μικρογραφία ή raster στοιχείο. Χρησιμοποιήστε τα άρθρα PNG, JPG και SVG για οδηγίες απόδοσης ειδικές για τη μορφή.

## **Συχνές Ερωτήσεις**

**Χρειάζομαι το Microsoft PowerPoint για τη μετατροπή παρουσιάσεων;**

Όχι. Το Aspose.Slides for PHP via Java είναι μια αυτόνομη βιβλιοθήκη και δεν απαιτεί το Microsoft PowerPoint ή αυτοματισμό του Office.

**Μπορώ να κάνω μαζική μετατροπή πολλών παρουσιάσεων;**

Ναι. Φορτώστε κάθε παρουσίαση, αποθηκεύστε την στη ζητούμενη μορφή και απελευθερώστε το αντικείμενο παρουσίασης μετά την επεξεργασία. Για παράλληλη επεξεργασία, χρησιμοποιήστε ξεχωριστά αντικείμενα παρουσίασης και ακολουθήστε τις οδηγίες [multithreading](/slides/el/php-java/multithreading/).

**Μπορώ να εξάγω μόνο επιλεγμένες διαφάνειες;**

Ναι. Σε πολλές μεθόδους εξαγωγής μπορείτε να περάσετε δείκτες διαφανειών ή να αποδώσετε μεμονωμένες διαφάνειες, ανάλογα με τη μορφή εξόδου. Δείτε το ειδικό άρθρο για τη μορφή-στόχο.

**Μπορώ να συμπεριλάβω κρυφές διαφάνειες κατά την εξαγωγή σε PDF ή XPS;**

Ναι. Χρησιμοποιήστε τις ρυθμίσεις εξαγωγής κρυφής διαφάνειας που περιγράφονται στα άρθρα [PDF](/slides/el/php-java/convert-powerpoint-to-pdf/) και [XPS](/slides/el/php-java/convert-powerpoint-to-xps/).

**Μπορώ να δημιουργήσω έξοδο PDF/A;**

Ναι. Υπάρχουν ρυθμίσεις συμμόρφωσης PDF για εξαγωγή PDF. Δείτε το [Convert PowerPoint to PDF](/slides/el/php-java/convert-powerpoint-to-pdf/) για λεπτομέρειες.

**Πώς διαχειρίζονται οι γραμματοσειρές κατά τη μετατροπή;**

Το Aspose.Slides μπορεί να χρησιμοποιήσει ενσωματωμένες γραμματοσειρές, εναλλακτική (fallback) γραμματοσειρά και ρυθμίσεις αντικατάστασης γραμματοσειράς. Δείτε [Embedded Font](/slides/el/php-java/embedded-font/), [Fallback Font](/slides/el/php-java/fallback-font/) και [Font Substitution](/slides/el/php-java/font-substitution/).
