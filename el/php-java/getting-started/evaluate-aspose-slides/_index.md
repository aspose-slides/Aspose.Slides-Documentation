## **Αξιολόγηση Aspose.Slides**

Μπορείτε να κατεβάσετε το Aspose.Slides για αξιολόγηση. Το πακέτο αξιολόγησης είναι το ίδιο με το αγορασμένο πακέτο· γίνεται αδειοδοτημένο αφού προσθέσετε μερικές γραμμές κώδικα για να εφαρμόσετε την άδεια. Δείτε [Εγκατάσταση](/slides/el/php-java/installation/) για να το ρυθμίσετε και [Άδεια](/slides/el/php-java/licensing/) για να εφαρμόσετε μια άδεια.

Χωρίς άδεια, το Aspose.Slides προσφέρει πλήρη λειτουργικότητα σε λειτουργία αξιολόγησης, με δύο περιορισμούς: προσθέτει ένα πλαίσιο κειμένου υδατογράφημα αξιολόγησης στη μέση κάθε διαφάνειας κάθε παρουσίασης που αποθηκεύει, και το κείμενο που ο κώδικάς σας διαβάζει από μια παρουσίαση περικόπτεται στους πρώτους μερικούς χαρακτήρες, ακολουθούμενο από μια ειδοποίηση σχετικά με τον περιορισμό αξιολόγησης. Το κείμενο που ο κώδικάς σας γράφει αποθηκεύεται πλήρως.

{{% alert color="info" title="Note" %}}
Αν θέλετε να δοκιμάσετε το Aspose.Slides χωρίς τους περιορισμούς της έκδοσης αξιολόγησης, μπορείτε να ζητήσετε μια **30ήμερη Προσωρινή Άδεια**. Παρακαλούμε ανατρέξτε στο [How to get a Temporary License?](https://purchase.aspose.com/temporary-license) για περισσότερες πληροφορίες.
{{% /alert %}}

## **Συχνές ερωτήσεις**

### Μπορώ να δοκιμάσω πολλές παρουσιάσεις ταυτόχρονα σε διαφορετικά νήματα σε λειτουργία αξιολόγησης;

Ναι. Μπορείτε να επεξεργαστείτε διαφορετικά έγγραφα παράλληλα· δεν πρέπει να μοιράζεστε το ίδιο αντικείμενο παρουσίασης [μέσω νημάτων](/slides/el/php-java/multithreading/). Η λειτουργία αξιολόγησης δεν επηρεάζει αυτό.

### Χρειάζεται να εγκαταστήσω το Microsoft PowerPoint για να αξιολογήσω τη βιβλιοθήκη σε διακομιστή ή σε CI;

Όχι. Το Aspose.Slides είναι μια ανεξάρτητη μηχανή και δεν απαιτείται εγκατάσταση του PowerPoint ούτε για αξιολόγηση ούτε για παραγωγή.

### Μπορώ να δοκιμάσω πλήρως τη μετατροπή PPT/PPTX σε PDF και εικόνες σε λειτουργία αξιολόγησης;

Ναι. Οι [μετατροπείς](/slides/el/php-java/convert-presentation/) λειτουργούν· η έξοδος θα περιλαμβάνει υδατογράφημα.

### Μπορώ να χρησιμοποιήσω προσωρινή άδεια για δοκιμή φορτίου χωρίς υδατογράφημα;

Ναι. Μια **30ήμερη προσωρινή άδεια** αφαιρεί τους περιορισμούς της λειτουργίας αξιολόγησης και επιτρέπει δοκιμή χωρίς υδατογράφημα.
