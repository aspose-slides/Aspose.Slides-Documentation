## **Vue d'ensemble**

Cet article explique comment obtenir du support pour Aspose.Slides et comment signaler les problèmes efficacement. Il décrit le canal de support principal, fournit des recommandations pour soumettre un problème, et pointe vers des ressources techniques utiles telles que la page produit, le blog, les téléchargements, le forum de support, la documentation et la référence de l'API. L'article répond également aux questions fréquentes concernant le support payant, l'escalade des problèmes et le support des versions plus anciennes de la bibliothèque.

## **Support technique**
{{% alert color="info" %}}

Aspose fournit un support technique gratuit et illimité pour tous ses produits. Le support est disponible pour tous les utilisateurs (y compris les utilisateurs avec des packages d'évaluation).

{{% /alert %}} 

Lorsque vous avez besoin d'aide avec Aspose.Slides pour .NET, considérez ce qui suit :

- Le principal canal de support est le [Aspose.Forums](https://forum.aspose.com/c/slides/fr/11). Publiez votre question dans le forum Aspose.Slides—elle sera répondue en quelques heures. L'équipe de support Aspose.Slides répond directement aux questions postées sur le forum.
- Veuillez noter qu'Aspose ne fournit pas de support technique par téléphone. Le support téléphonique est uniquement disponible pour les questions de vente et d'achat.
- Lorsque vous attendez une réponse sur les forums, veuillez être patient et tenir compte des différences de fuseau horaire.

Lorsque vous rencontrez un problème avec Aspose.Slides pour .NET, suivez ces directives pour le résoudre de la manière la plus efficace :

- Vérifiez et confirmez que vous utilisez la dernière version d'Aspose.Slides pour .NET avant de signaler le problème. Il se peut que le problème que vous avez rencontré ait déjà été résolu dans une mise à jour.  
  Voir le téléchargement Aspose.Slides pour obtenir des informations sur la dernière version.
- Avant de signaler un problème, vous pouvez consulter nos forums, cette documentation et la référence de l'API. Il se peut que la réponse à votre question ait déjà été fournie. 
- Lors du signalement d'un problème, veuillez inclure le document original et (si possible) un fragment de votre code concernant le problème. Si vous devez joindre plusieurs fichiers, placez-les dans un package ZIP.  
  Vous pouvez joindre vos documents en toute sécurité sur Aspose.Forums car **seul** vous et les développeurs d'Aspose avez accès aux fichiers joints.
- Créez et utilisez un fil de discussion unique pour un problème spécifique. Si vous rencontrez un autre problème, vous devez créer un autre fil pour le signaler.

## **FAQ**

### Quels niveaux de support payant sont disponibles et comment diffèrent‑ils ?

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). Ils diffèrent par le nombre d'incidents inclus, la priorité de réponse et les canaux de communication disponibles.

### Puis‑je escalader un bug directement à l'équipe d'ingénierie ?

Oui. Le [paid support](https://helpdesk.aspose.com/) permet d'escalader aux développeurs lorsqu'un problème nécessite une enquête approfondie.

### Les versions plus anciennes de la bibliothèque sont‑elles prises en charge, et publiez‑vous des correctifs pour elles ?

Vous pouvez utiliser les versions plus anciennes, mais les correctifs sont fournis uniquement pour la version actuelle ; les correctifs pour les versions héritées ne sont pas publiés.
