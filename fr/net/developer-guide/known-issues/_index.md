## **Vue d'ensemble**

Cette section ne contient pas de liste de problèmes ouverts dans la version actuelle. Elle contient deux pages :

- [Aperçu d'objet placeholder lors de l'ajout d'OleObjectFrame](/slides/fr/net/object-preview-issue-when-adding-oleobjectframe/) explique pourquoi un objet OLE ajouté avec Aspose.Slides affiche une image « EMBEDDED OLE OBJECT » jusqu'à ce que son aperçu soit mis à jour, et comment définir votre propre image d'aperçu. Il s'agit d'un comportement prévu dans la version actuelle.
- [Problèmes connus dans Aspose.Slides for .NET 14.1.0 (Historique)](/slides/fr/net/known-issues-in-aspose-slides-for-net-14-1-0/) est une liste publiée avec la version 14.1.0 en 2014, conservée à titre de référence.

Pour les modifications et correctifs de chaque version, consultez les [notes de version](https://releases.aspose.com/slides/net/release-notes/). Les champs de métadonnées que Aspose.Slides écrit avec des valeurs fixes sont décrits dans [Limites des métadonnées de sortie](/slides/fr/net/api-limitations/). Pour vérifier si un problème est déjà connu ou pour en signaler un, utilisez le [forum d'assistance](https://forum.aspose.com/c/slides/11).
