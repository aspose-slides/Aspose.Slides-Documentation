**Bienvenue sur Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports est une bibliothèque spécialement conçue et développée pour les développeurs qui doivent exporter facilement des rapports JasperReports vers les formats Microsoft PowerPoint Presentation (PPT) et Microsoft PowerPoint Show (PPS) dans leurs applications Java. Toutes les fonctionnalités de rapport sont converties avec le plus haut degré de précision en présentations Microsoft PowerPoint. Aspose.Slides for JasperReports inclut la prise en charge de JasperReports 5+.
