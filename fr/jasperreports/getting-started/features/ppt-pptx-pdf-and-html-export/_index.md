{{% alert color="info" %}} 

JasperReports et JasperServer ne possèdent pas de fonctionnalités intégrées pour exporter les rapports sous forme de présentations Microsoft PowerPoint, mais avec Aspose.Slides pour JasperReports, vous avez accès à des formats d'exportation supplémentaires:

- Microsoft PowerPoint Presentation (PPT)
- Microsoft PowerPoint Presentation (PPTX)
- HTML
- PDF

{{% /alert %}} 

Pour créer des documents dans ces formats, Aspose.Slides pour JasperReports s'appuie sur une version intégrée de [Aspose.Slides for Java](https://products.aspose.com/slides/fr/java/), la bibliothèque de traitement de présentations leader du marché d'Aspose. Microsoft PowerPoint n'est pas utilisé pour générer les documents.
