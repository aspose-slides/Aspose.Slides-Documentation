## **JasperReports**

Aspose.Slides for JasperReports fonctionne avec JasperReports 3.7.2 à 6.16.0. Le téléchargement comprend un jar distinct pour chacune des trois plages de versions — voir [Installation d'Aspose.Slides pour JasperReports](/slides/fr/jasperreports/installing-aspose-slides-for-jasperreports/) pour savoir lequel utiliser. Il n'existe aucun jar pour JasperReports 6.17.0 ou ultérieur, y compris JasperReports 7.

Le support de JasperReports 2.0.3 à 3.7.1 a pris fin dans Aspose.Slides for JasperReports 17.6. Les versions 17.5 et antérieures prenaient également en charge ces versions.

## **Java**

Les jars sont compilés pour Java 6 ou version ultérieure, comme l’indique le *JDK 1.6* dans leurs noms de dossiers, de sorte que la version Java requise est celle dont votre version de JasperReports a besoin. Avec JasperReports 6.16.0, les exportations s’exécutent sur Java 11, 17, 21 et 25.

## **Operating system**

Les jars contiennent uniquement des classes et des ressources Java, sans bibliothèques natives, et ils n’utilisent pas Microsoft PowerPoint. Sous Linux, JasperReports nécessite fontconfig et au moins une police installée pour remplir un rapport.

## **JasperReports Server**

Pour JasperReports Server, utilisez les deux jars du dossier correspondant à la version de JasperReports utilisée par votre serveur — voir [Intégration avec JasperServer](/slides/fr/jasperreports/integration-with-jasperserver/).
