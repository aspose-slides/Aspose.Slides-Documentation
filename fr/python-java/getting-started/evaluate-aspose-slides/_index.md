Vous pouvez télécharger Aspose.Slides pour Python via Java afin d'évaluer ses fonctionnalités. Le package d'évaluation est identique au package sous licence. Pour l'utiliser sans les limitations d'évaluation, ajoutez quelques lignes de code à [appliquer une licence](/slides/fr/python-java/licensing/).

La version d'évaluation d'Aspose.Slides (utilisée sans licence) offre l'intégralité des fonctionnalités du produit, avec deux limitations :

- Elle ajoute une zone de texte de filigrane d'évaluation à chaque diapositive de chaque présentation qu'elle enregistre. L'ouverture d'une présentation n'en ajoute pas, mais l'enregistrement d'un fichier contenant déjà le filigrane en ajoute un autre.
- Le texte que votre code lit est tronqué aux premiers caractères, suivi d'un avis concernant la limitation d'évaluation. Cela s'applique à chaque diapositive, ainsi qu'au texte que votre code vient de définir ainsi qu'au texte chargé depuis un fichier. Le texte que votre code écrit est enregistré en entier.

{{% alert color="info" title="Note" %}}
Pour tester Aspose.Slides sans les limitations d'évaluation, vous pouvez demander une **licence temporaire de 30 jours**. Voir [Obtenir une licence temporaire](https://purchase.aspose.com/temporary-license) pour plus d'informations.
