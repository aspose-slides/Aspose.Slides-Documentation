{{% alert color="info" title="Note" %}}

Aspose.Slides pour Python via Java est une bibliothèque de classes qui permet aux applications Python de lire et d'écrire des présentations sans nécessiter Microsoft PowerPoint®. Elle vous permet de gérer le texte, les formes, les tableaux et les animations ; d'ajouter de l'audio et de la vidéo aux diapositives ; de prévisualiser les diapositives ; et d'exporter les diapositives au format SVG, PDF et autres formats.

Pour plus de détails, voir la [Référence de l'API Aspose.Slides pour Python via Java](https://reference.aspose.com/slides/fr/python-java/).
