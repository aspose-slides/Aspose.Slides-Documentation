**Bienvenue sur Aspose.Slides for Java !**

Aspose.Slides for Java est une API de gestion Microsoft PowerPoint® qui permet aux applications Java de lire et d'écrire des documents PowerPoint® sans Microsoft PowerPoint®. Aspose.Slides for Java est le premier et le seul composant qui offre la fonctionnalité de gérer les documents PowerPoint®. Aspose.Slides for Java propose de nombreuses fonctionnalités clés, telles que la gestion du texte, des formes, des tableaux et des animations, l'ajout d'audio et de vidéo aux diapositives, l'aperçu des diapositives, l'exportation des diapositives au format SVG, PDF et d'autres formats.
