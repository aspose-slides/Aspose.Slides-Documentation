{{% alert color="info" title="Note" %}}

Il s'agit d'une page historique. Elle répertorie les problèmes connus publiés avec Aspose.Slides for Java 14.3.0 et ne décrit pas la version actuelle. Pour les changements dans chaque version, consultez les [notes de version](https://releases.aspose.com/slides/fr/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) propose une implémentation entièrement nouvelle du traitement PPT. Il y a de nombreuses améliorations, la conversion partielle de PPTX en PPT. Mais certaines fonctionnalités ne sont pas implémentées :

- Certaines formes ont une géométrie incorrecte dans les documents PPT sérialisés (Call outs)
- Toutes les fonctionnalités de mise en forme du texte PPTX ne sont pas prises en charge dans la sérialisation PPT
- Les informations sur la langue du texte et les paramètres d'orthographe ne sont pas présentes dans les documents PPT sérialisés
- Toutes les fonctionnalités des thèmes PPTX ne sont pas prises en charge dans la sérialisation PPT

**Il existe quelques différences par rapport à Aspose.Slides for Java 8.6.0 :**

- Des problèmes connus existent dans la sérialisation PPT OLE/ActiveX vers PPT

**Il existe quelques différences par rapport à Aspose.Slides for .NET 14.3.0 :**

- Le support de l'impression de présentations n'est actuellement pas disponible dans Aspose.Slides for Java
