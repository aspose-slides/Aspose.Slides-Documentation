## **Aperçu**

Cette section ne contient pas de liste de problèmes ouverts dans la version actuelle. Elle contient trois pages :

- [Espace réservé d'aperçu d'objet lors de l'ajout d'OleObjectFrame](/slides/fr/java/object-preview-issue-when-adding-oleobjectframe/) explique pourquoi un objet OLE ajouté avec Aspose.Slides affiche une image "EMBEDDED OLE OBJECT" jusqu'à ce que son aperçu soit mis à jour, et comment définir votre propre image d'aperçu. Il s'agit d'un comportement prévu de la version actuelle.
- [Problèmes connus dans Aspose.Slides for Java 14.3.0 (Historical)](/slides/fr/java/known-issues-in-aspose-slides-for-java-14-3-0/) et [Problèmes connus dans Aspose.Slides for Java 14.4.0 (Historical)](/slides/fr/java/known-issues-in-aspose-slides-for-java-14-4-0/) sont des listes publiées avec ces versions, conservées à titre de référence.

Pour les modifications et correctifs de chaque version, consultez les [notes de version](https://releases.aspose.com/slides/fr/java/release-notes/). Les champs de métadonnées que Aspose.Slides écrit avec des valeurs fixes sont décrits dans [Limites des métadonnées de sortie](/slides/fr/java/api-limitations/). Pour vérifier si un problème est déjà connu, ou pour en signaler un, utilisez le [forum de support](https://forum.aspose.com/c/slides/fr/11).
