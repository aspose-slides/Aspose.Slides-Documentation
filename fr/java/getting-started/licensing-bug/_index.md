{{% alert color="info" title="Note" %}}

Il s'agit d'une page historique. Elle décrit un bug dans Aspose.Slides for Java versions 23.2 à 23.7, publiées en 2023, ainsi que les versions qui l'ont corrigé. Elle ne décrit pas la version actuelle. Pour la licence dans la version actuelle, voir [Licensing](/slides/fr/java/licensing/).

{{% /alert %}}

## **Vue d'ensemble**

Cet article décrit un bug de licence rencontré dans Aspose.Slides for Java versions 23.2, 23.3, 23.4, 23.5, 23.6 et 23.7. Ce bug rendait les licences perpétuelles temporairement inutilisables après l'expiration de leur abonnement.

## **Symptômes**

Après l'expiration de votre abonnement de licence perpétuelle, Aspose.Slides for Java versions 23.2 - 23.7 peut indiquer que la licence est expirée, passant toutes les fonctions en mode d'évaluation. Ce comportement est incorrect et n'affecte pas les versions antérieures à 23.2 ni celles postérieures à 23.7.

## **Résolution**

Aspose.Slides for Java a résolu ce problème et a publié des versions mises à jour (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) contenant le correctif.

Si vous utilisez l'une des versions concernées d'Aspose.Slides for Java dans votre projet, veuillez passer à la version corrigée.

## **Produits et versions affectés**

Veuillez noter que ce bug n'affecte que les versions Aspose.Slides for Java 23.2 à 23.7. **Les autres produits Aspose et les autres versions d'Aspose.Slides ne sont pas concernées**.
