Ceci est une page historique, conservée pour les liens existants. Elle ne décrit pas la version actuelle d'Aspose.Slides for Java. Pour les formats qu'Aspose.Slides for Java charge, importe, enregistre et rend, ainsi que l'API correspondante, voyez [Formats de fichiers pris en charge](/slides/fr/java/supported-file-formats/). Pour comparer PPT à PPTX, voyez [Comprendre la différence : PPT vs PPTX](/slides/fr/java/ppt-vs-pptx/).

{{% /alert %}}

{{% alert color="info" title="Note" %}}

PPT est le format de fichier de présentation qui peut être créé, lu, manipulé et écrit par différentes versions de Microsoft PowerPoint. Il s'agit du format binaire pour les documents de présentation développé par Microsoft.

{{% /alert %}}

## **PPT dans Aspose.Slides for Java**
Aspose.Slides for Java peut lire les fichiers PPT créés par les logiciels listés ci-dessous.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

De même, les fichiers PPT créés par Aspose.Slides for Java peuvent être lus par l'ensemble de logiciels ci‑dessus.

## **Prise en charge complète du PPT**
Aspose.Slides for Java offre une prise en charge de presque toutes les fonctionnalités du format de fichier PPT. Il couvre non seulement les fonctions de base et avancées fournies par les différentes versions de Microsoft PowerPoint pour la manipulation des documents PPT, mais également des fonctionnalités qui ne sont même pas supportées par Microsoft PowerPoint. Le principal avantage d'utiliser la bibliothèque API Aspose.Slides for Java est la facilité d'utilisation pour gérer ces fonctionnalités.

En plus des tâches de base liées à la création, à la lecture et à l'écriture des fichiers de documents PPT, plusieurs fonctionnalités sont fournies par Aspose.Slides for Java :

- Importer d'autres formats de fichiers Microsoft Office en tant qu'[objets OLE dans les documents PPT](/slides/fr/java/manage-ole/).
- [Exporter les documents PPT au format PDF](/slides/fr/java/convert-powerpoint-to-pdf/).
- Exporter les diapositives des documents PPT au format SVG.
- Rendre les diapositives dans n'importe quel format d'image pris en charge par le framework Java.
- Définir la taille des diapositives dans les documents PPT.
- Gérer les animations sur les formes.
- Gérer les diaporamas.
- [Formater le texte sur les diapositives](/slides/fr/java/text-formatting/).
- Extraire le texte des documents PPT.
- [Gérer les tableaux sur les diapositives](/slides/fr/java/powerpoint-table/).
- Copier automatiquement les maîtres en utilisant [la fonction de clonage](/slides/fr/java/clone-slides/).
