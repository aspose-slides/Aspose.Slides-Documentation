{{% alert color="info" title="Note" %}}

Les articles de cette section sont des présentations plus anciennes de formats de fichiers individuels, conservées pour les liens existants. Ils ne décrivent pas la version actuelle d'Aspose.Slides for Java. Pour les formats qu'Aspose.Slides for Java charge, importe, enregistre et rend, ainsi que l'API de chacun, consultez [Supported File Formats](/slides/fr/java/supported-file-formats/). Pour les guides de conversion, consultez [Convert Presentations](/slides/fr/java/convert-presentation/).
