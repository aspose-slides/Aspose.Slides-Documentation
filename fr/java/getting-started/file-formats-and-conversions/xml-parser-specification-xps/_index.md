{{% alert color="info" %}} 

Le [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) est un langage de description de page et un format de document fixe initialement développé par Microsoft. Comme le PDF, XPS est conçu pour préserver la fidélité du document et offrir une apparence indépendante du dispositif. 

{{% /alert %}} 

## **XPS dans Aspose.Slides pour Java**
Tout document de présentation pouvant être chargé par Aspose.Slides pour Java peut être converti au format XPS. Aspose.Slides pour Java utilise le moteur de mise en page et de rendu haute fidélité pour produire une sortie au format XPS à mise en page fixe.
Vous pouvez en savoir plus sur l’exportation des documents de présentation vers des documents XPS via Aspose.Slides pour Java dans [Conversion vers XPS](https://docs.aspose.com/slides/fr/java/convert-powerpoint-to-xps/).
