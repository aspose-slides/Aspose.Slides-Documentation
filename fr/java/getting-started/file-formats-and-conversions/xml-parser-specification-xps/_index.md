{{% alert color="info" title="Note" %}}

Le [XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) est un langage de description de page et un format de document fixe développé à l'origine par Microsoft. À l'instar du PDF, le XPS est conçu pour préserver la fidélité du document et offrir une apparence indépendante du dispositif.

{{% /alert %}}

## **XPS dans Aspose.Slides for Java**
Tout document de présentation pouvant être chargé par Aspose.Slides for Java peut être converti au format XPS. Aspose.Slides for Java utilise le moteur de mise en page et de rendu à haute fidélité pour produire une sortie au format de document XPS à mise en page fixe. Vous pouvez en savoir plus sur l'exportation des documents de présentation vers des documents XPS via Aspose.Slides for Java dans [Convert PowerPoint Presentations to XPS](/slides/fr/java/convert-powerpoint-to-xps/).
