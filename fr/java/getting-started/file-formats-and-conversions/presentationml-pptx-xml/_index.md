{{% alert color="info" title="Note" %}}

PresentationML est le nom d'une famille de formats basés sur XML pour les documents de présentation. Office OpenXML (OOXML) est le format basé sur XML introduit dans les applications Microsoft Office 2007. Office OpenXML est un format conteneur pour plusieurs langages de balisage spécialisés basés sur XML. PresentationML est le langage de balisage utilisé par Microsoft Office PowerPoint 2007 pour stocker les documents.

{{% /alert %}}

## **PresentationML dans Aspose.Slides for Java**
Les documents OOXML PresentationML sont fournis sous forme de fichiers PPTX, des packages XML compressés qui respectent la spécification [OOXML ECMA-376](https://ecma-international.org/publications-and-standards/standards/ecma-376/). Aspose.Slides for Java prend en charge de manière approfondie la création, la lecture, la manipulation et l'écriture de documents PresentationML. De plus, Aspose.Slides for Java peut exporter des documents PresentationML vers un format de document largement utilisé comme le PDF. Cela est possible parce qu'Aspose.Slides for Java a été conçu pour gérer de façon complète les documents de présentation, et PresentationML stocke essentiellement la présentation interne des documents sous forme d'un package XML compressé.

## **PresentationML est ouvert, pourquoi utiliser Aspose.Slides for Java ?**
Comme PresentationML est basé sur XML, il est tout à fait possible de créer des applications pour traiter et générer des documents PresentationML en utilisant des classes XML sans dépendre d'une bibliothèque tierce telle qu'Aspose.Slides for Java. Cependant, plusieurs avantages existent à utiliser Aspose.Slides for Java plutôt que des classes XML lorsqu'on travaille avec des documents PresentationML.

La spécification OOXML compte plusieurs milliers de pages ; pour gérer correctement les documents PresentationML, il faut consacrer beaucoup de temps et d'efforts à comprendre le format. En revanche, avec Aspose.Slides for Java, il suffit d'utiliser les classes ainsi que leurs méthodes et propriétés pour effectuer des opérations qui semblent complexes si elles sont réalisées via des classes XML.

Certaines des fonctionnalités offertes par Aspose.Slides ne sont même pas disponibles lorsque l'on travaille avec des documents PresentationML via des classes XML :

- Exporter des documents PPT au format PDF.
- Rendre une diapositive dans n'importe quel format d'image pris en charge par le framework Java.
- Copier automatiquement les masques d'une présentation source à l'aide de la fonction de clonage.
- Appliquer une protection aux formes.

Voici un exemple de document PresentationML contenant une seule diapositive avec une zone de texte affichant le texte « Hello World ». Pour lire ce texte avec des classes XML, il faut écrire un programme capable d'analyser ce texte simple à partir du fragment suivant. Aspose.Slides le fait pour vous.

  <p:cSld>
    <p:spTree>
      <p:nvGrpSpPr>
        <p:cNvPr id="1" name=""/>
        <p:cNvGrpSpPr/>
        <p:nvPr/>
      </p:nvGrpSpPr>
      <p:grpSpPr>
        <a:xfrm>
          <a:off x="0" y="0"/>
          <a:ext cx="0" cy="0"/>
          <a:chOff x="0" y="0"/>
          <a:chExt cx="0" cy="0"/>
        </a:xfrm></p:grpSpPr><p:sp>
          <p:nvSpPr><p:cNvPr id="4" name="TextBox 3"/>
          <p:cNvSpPr txBox="1"/>
            <p:nvPr/>
          </p:nvSpPr>
          <p:spPr>

              <a:off x="2819400" y="2590800"/>
