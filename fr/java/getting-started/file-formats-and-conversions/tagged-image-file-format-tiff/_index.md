## **À propos du TIFF**

Le [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) connu pour stocker plusieurs images dans un même document a été créé à l'origine par Aldus. Ce format est largement supporté par les applications de numérisation, de fax et d'autres manipulations d'images.

## **TIFF dans Aspose.Slides for Java**

Tout document pouvant être chargé dans Aspose.Slides for Java peut également être converti directement en document TIFF par Aspose.Slides for Java, éliminant ainsi le besoin de tout composant tiers. De plus, vous pouvez éventuellement définir la taille des images dans le document TIFF résultant. Vous trouverez des informations sur l'exportation des documents de présentation vers des documents TIFF via Aspose.Slides for Java dans [Convert PowerPoint Presentations to TIFF](/slides/fr/java/convert-powerpoint-to-tiff/).
