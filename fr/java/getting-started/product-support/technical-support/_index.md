## **Vue d'ensemble**

Cet article explique comment obtenir de l'assistance pour Aspose.Slides et comment signaler les problèmes efficacement. Il décrit le principal canal de support, fournit des recommandations pour soumettre un problème, et indique des ressources techniques utiles telles que la page produit, le blog, les téléchargements, le forum de support, la documentation et la Référence API. L'article répond également aux questions fréquentes concernant le support payant, l'escalade des incidents et le support des versions plus anciennes de la bibliothèque.

## **Support technique**

{{% alert color="info" %}} 

Aspose offre un support technique gratuit et illimité pour tous ses produits. Le support est disponible pour tous les utilisateurs, y compris en mode évaluation.

{{% /alert %}} 

Si vous avez besoin d'aide avec Aspose.Slides for Java, considérez les points suivants :

- Le principal canal de support est le Aspose.Forums. Publiez votre question dans le forum Aspose.Slides et elle recevra une réponse en quelques heures. Les questions sont répondues directement par l'équipe de support Aspose.Slides.
- Veuillez noter qu'Aspose ne fournit pas de support technique par téléphone. Le support téléphonique est uniquement disponible pour les questions de vente et d'achat.
- Lorsqu'une réponse est attendue sur les forums, veuillez tenir compte des différences de fuseaux horaires.

Si vous rencontrez un problème avec Aspose.Slides for Java, suivez ces étapes simples pour vous assurer qu'il soit résolu de la manière la plus efficace :

- Assurez‑vous d'utiliser la dernière version d'Aspose.Slides for Java avant de signaler le problème, voir le téléchargement Aspose.Slides pour connaître la version la plus récente.
- Consultez les forums, cette documentation et la Référence API avant de signaler le problème ; il est possible que votre question ait déjà reçu une réponse.
- Lors du signalement d'un problème, veuillez inclure le document original et éventuellement un fragment de votre code qui cause le dysfonctionnement. Si vous devez joindre plusieurs fichiers, compressez‑les dans une archive zip. Il est sûr de joindre vos documents sur Aspose.Forums puisque seuls vous et les développeurs d'Aspose auront accès aux fichiers joints.
- Essayez de signaler un seul problème par fil de discussion. Si vous avez un autre problème, créez un fil séparé.

## **FAQ**

### Quels niveaux de support payant sont disponibles et comment diffèrent‑ils ?

[Développeur, Business et Entreprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). Ils diffèrent par le nombre d'incidents inclus, la priorité de réponse et les canaux de communication disponibles.

### Puis‑je escalader un bug directement à l'équipe d'ingénierie ?

Oui. [Support payant](https://helpdesk.aspose.com/) permet l'escalade aux développeurs lorsqu'un problème nécessite une enquête plus approfondie.

### Les versions plus anciennes de la bibliothèque sont‑elles prises en charge, et publiez‑vous des correctifs pour elles ?

Vous pouvez utiliser des versions plus anciennes, mais les correctifs sont fournis pour la version actuelle ; les correctifs pour les versions héritées ne sont pas publiés.
