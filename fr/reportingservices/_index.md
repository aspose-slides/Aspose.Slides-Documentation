Aspose.Slides for Reporting Services est une extension de rendu pour Microsoft SQL Server Reporting Services et Power BI Report Server qui ajoute les formats de présentation à la liste d’exportation des rapports paginés (RDL), sans nécessiter Microsoft PowerPoint sur le serveur.

Il exporte les rapports vers les présentations et diaporamas PPT, PPTX, PPS et PPSX, vers ODP et vers XPS.

## **Votre première exportation**

Il n’y a aucun code à écrire : vous installez l’extension sur le serveur de rapports, et ses formats apparaissent dans la liste d’exportation de chaque rapport paginé sur ce serveur.

1. Vérifiez que le serveur de rapports répond aux [system requirements](/slides/fr/reportingservices/system-requirements/), y compris .NET Framework 3.5.  
2. Depuis la [download page](https://releases.aspose.com/slides/reportingservices/), téléchargez le programme d’installation MSI, *Aspose.Slides for Reporting Services*. Pour installer manuellement, téléchargez le paquet ZIP, *Aspose.Slides for Reporting Services (DLLs Only)*.  
3. Installez l’extension sur le serveur de rapports : exécutez le MSI en tant qu’administrateur, comme décrit dans [Install with the MSI installer](/slides/fr/reportingservices/install-with-msi-installer/), ou suivez [Install manually](/slides/fr/reportingservices/install-manually/) pour le paquet ZIP.  
4. Dans un navigateur, ouvrez le portail web du serveur de rapports (Report Manager sur SQL Server 2014 et versions antérieures). Par défaut, son adresse est `https://<ComputerName>/reports`.  
5. Ouvrez un rapport paginé. Dans la barre d’outils du rapport, ouvrez la liste **Export** et sélectionnez **PPTX - PowerPoint 2007 Presentation via Aspose.Slides**. Si la barre d’outils possède un bouton **Export** distinct, comme le fait Report Manager, cliquez dessus.  
6. Ouvrez ou enregistrez le fichier PPTX que le navigateur télécharge.

Sans licence, la présentation exportée comporte un filigrane d’évaluation — voir [Licensing](/slides/fr/reportingservices/license-aspose-slides-for-reporting-services/). Pour les autres formats de la liste d’exportation, voir [Supported File Formats](/slides/fr/reportingservices/supported-file-formats/).
