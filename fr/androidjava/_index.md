**Bienvenue dans Aspose.Slides for Android via Java**

Aspose.Slides for Android via Java est une API de gestion Microsoft PowerPoint® qui permet aux applications Android de lire et d'écrire des documents PowerPoint® sans Microsoft PowerPoint®. Aspose.Slides for Android via Java est le premier et le seul composant qui fournit les fonctionnalités nécessaires à la gestion des documents PowerPoint® sur les plateformes Android. Aspose.Slides for Android offre de nombreuses fonctionnalités clés qui vous permettent d'ajouter, de modifier et de manipuler du texte, des formes, des tableaux et des animations, des audio et des vidéos dans les diapositives.
