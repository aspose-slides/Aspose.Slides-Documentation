{{% alert color="info" %}}

Aspose.Slides for Android via Java est une bibliothèque de classes qui permet aux applications Java pour Android de lire et d’écrire des documents de présentation sans utiliser Microsoft PowerPoint® ou d’autres logiciels. Aspose.Slides for Android via Java vous permet de gérer le texte, les formes, les tableaux et les animations ; d’ajouter de l’audio et de la vidéo aux diapositives ; de prévisualiser les diapositives ; et d’exporter les diapositives au format SVG, PDF, et plus encore.

La dernière référence API se trouve à [Référence de l’API Aspose.Slides for Android via Java](https://reference.aspose.com/slides/fr/androidjava/).
