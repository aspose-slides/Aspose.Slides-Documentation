{{% alert color="info" title="Note" %}}

Avec Aspose.Slides for SharePoint, vous pouvez convertir des présentations PowerPoint en de nombreux formats de documents populaires depuis une bibliothèque de documents SharePoint.

{{% /alert %}}

## **Formats d’entrée pris en charge**

Aspose.Slides for SharePoint convertit les formats d’entrée suivants :

- PPT – Présentation Microsoft PowerPoint 97 - 2003
- PPTX – Présentation Office Open XML

{{% alert color="info" title="Note" %}}

Pour convertir des documents, Aspose.Slides for SharePoint s’appuie sur une version intégrée de [Aspose.Slides for .NET](https://products.aspose.com/slides/net/).

{{% /alert %}}

## **Formats de sortie pris en charge**

La liste **Convertir en** de la page de conversion propose les formats de sortie suivants, dans cet ordre :

- PDF – Document portable Adobe
- TIFF – Paquet d’images
- XPS – Spécification de papier XML
- PPS – Présentation diaporama
- PPSX – Diaporama Open XML Microsoft PowerPoint
- ODP – Présentation OpenDocument
- PPTM – Présentation Microsoft PowerPoint Open XML avec macros
- PPSM – Diaporama Open XML Microsoft PowerPoint avec macros
- POTX – Modèle Microsoft PowerPoint
- POTM – Modèle de présentation Open XML PowerPoint avec macros
- PDFNotes – Vue des notes de présentation au format PDF
- HTML – Présentation au format HTML
- TIFFNotes – Vue des notes de présentation sous forme d’image TIFF multipage
- SWF – Film Shockwave Flash
- SWFNotes – Vue des notes de présentation sous forme de SWF multipage
