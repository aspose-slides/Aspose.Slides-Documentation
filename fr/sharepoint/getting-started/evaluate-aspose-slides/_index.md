{{% alert color="info" title="Note" %}}

Le téléchargement d'évaluation d'Aspose.Slides pour SharePoint est identique au téléchargement acheté. Il devient la version sous licence lorsque vous installez le package de solution de licence sur le ferme ; voir [Installation de la licence Aspose.Slides pour SharePoint](/slides/fr/sharepoint/installing-aspose-slides-for-sharepoint-license/). Aucun code n'est impliqué.

Sans licence, Aspose.Slides pour SharePoint convertit vers tous les formats pris en charge, mais les fichiers convertis portent un filigrane d'évaluation, et la page de conversion affiche un avis d'évaluation.

Si vous souhaitez tester Aspose.Slides sans les limitations d'évaluation, vous pouvez également demander une licence temporaire de 30 jours. Voir [Comment obtenir une licence temporaire?](https://purchase.aspose.com/temporary-license)
