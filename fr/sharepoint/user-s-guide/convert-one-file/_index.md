Pour convertir une présentation dans une bibliothèque de documents :

1. Ouvrez le menu du fichier PPT ou PPTX (son Edit Control Block) et sélectionnez **Convert via Aspose.Slides**. Sur SharePoint 2007, l'élément du menu s'appelle **Convert with Aspose.Slides**.

   **Sélection de Convert with Aspose.Slides dans le menu d'un document sur SharePoint 2007**

   ![Le menu d'un document dans une bibliothèque de documents SharePoint 2007, avec l'élément Convert with Aspose.Slides](convert-one-file_1.png)

2. Sur la page de conversion, choisissez le format de sortie sous **Convert to**. Si vous le souhaitez, modifiez le nom du fichier de destination et le dossier de destination.
3. Cliquez sur **Convert**.
4. Lorsque la conversion est terminée, cliquez sur **Source Library** ou **Destination Library** pour revenir à une bibliothèque de documents. Le fichier converti se trouve dans le dossier de destination.

Les mêmes étapes, avec des captures d'écran de chaque page, sont disponibles dans [Conversion de documents Microsoft PowerPoint vers d'autres formats](/slides/fr/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
