Les sites SharePoint sont conçus pour la collaboration, la communication et le stockage de contenu afin de répondre à des besoins métier spécifiques. Ils permettent à un groupe d’individus d’atteindre un objectif commun en facilitant le partage d’informations et la communication. L’information est le plus souvent disponible sous forme de site Web et est accessible via un navigateur.

{{% /alert %}}

## **Qu'est-ce que SharePoint et Aspose.Slides ?**

Aspose.Slides for SharePoint est une solution de conversion des présentations Microsoft PowerPoint (PPT et PPTX) vers d’autres formats : PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX et POTM. Elle vous permet de convertir des fichiers PowerPoint dans un site SharePoint sans utiliser Microsoft PowerPoint. La liste complète des formats est disponible dans [Supported File Formats](/slides/fr/sharepoint/supported-file-formats/).
