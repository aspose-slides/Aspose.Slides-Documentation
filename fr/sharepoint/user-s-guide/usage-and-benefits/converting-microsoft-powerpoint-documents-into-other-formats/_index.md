{{% alert color="info" title="Note" %}}

Lorsque Aspose.Slides for SharePoint est installé sur le serveur SharePoint et activé pour une collection de sites, il ajoute l'élément **Convert via Aspose.Slides** au menu des documents de ses bibliothèques de documents, comme indiqué ci‑dessous. Sur SharePoint 2007, l'élément s’appelle **Convert with Aspose.Slides**.

**L'installation d'Aspose.Slides for SharePoint ajoute l'élément Convert via Aspose.Slides aux menus des documents**

![Un menu de document avec l'élément Convert via Aspose.Slides](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **Conversion d'une présentation**

1. Sélectionnez une présentation Microsoft PowerPoint dans une bibliothèque de documents.  
2. Ouvrez son menu et cliquez sur **Convert via Aspose.Slides**.

   **Le menu du fichier Presentation 2, affichant l'élément Convert via Aspose.Slides**

   ![Le menu d’une présentation dans une bibliothèque de documents, avec l’élément Convert via Aspose.Slides mis en évidence](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. Sélectionnez le format de sortie sous **Convert to**. Si vous le souhaitez, modifiez le nom du fichier de sortie et le dossier de destination.  
4. Cliquez sur **Convert** pour convertir le fichier.

   **La page de conversion vous permet de sélectionner le format de sortie, le nom du fichier et la destination**

   ![La page de conversion avec le format de sortie, le fichier de destination et le dossier de destination](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. Lorsque la conversion est terminée, un message de succès s’affiche.

   **La conversion a réussi**

   ![La page des résultats de conversion](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. Cliquez sur **Source Library** (pour accéder au dossier source) ou **Destination Library** (pour accéder au dossier où le fichier a été enregistré).

   Le document converti apparaît dans la bibliothèque de documents.

   **Le document converti affiché dans la bibliothèque où il a été enregistré**

   ![Le fichier converti dans la bibliothèque de documents](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

Les captures d’écran ont été réalisées avec une version antérieure, qui ne proposait que les formats PDF, TIFF et XPS. La page de conversion actuelle propose davantage de formats de sortie ; consultez [Prise en charge de plusieurs formats](/slides/fr/sharepoint/multiple-format-support/).

{{% /alert %}}

Sur SharePoint 2010 et versions ultérieures, vous pouvez également sélectionner une ou plusieurs présentations dans la bibliothèque et cliquer sur **Convert Slides** dans l’onglet ruban **Aspose Tools**. Cela ouvre la même page de conversion.
