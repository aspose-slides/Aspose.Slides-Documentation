## **Évaluation d'Aspose.Slides**

Vous pouvez télécharger Aspose.Slides pour l'évaluation. Le package d'évaluation est identique au package acheté ; il devient sous licence après que vous ayez ajouté quelques lignes de code pour appliquer la licence, comme indiqué dans [Licensing](/slides/fr/cpp/licensing/).

Sans licence, Aspose.Slides offre toutes ses fonctionnalités en mode évaluation, avec deux limitations :

* Il ajoute une zone de texte de filigrane d'évaluation au centre de chaque diapositive de chaque présentation qu'il enregistre. L'ouverture d'une présentation n'ajoute aucun filigrane, mais un filigrane enregistré précédemment est chargé comme forme sur sa diapositive. Ainsi, si vous ouvrez une présentation qui a été enregistrée en mode évaluation et que vous l'enregistrez à nouveau, chaque diapositive comporte deux filigranes.
* Le texte que votre code lit à partir d'une présentation est tronqué à ses premiers caractères, suivi d'un avis concernant la limitation d'évaluation. Cela s'applique à chaque diapositive, ainsi qu'au texte que votre code vient de définir. Le texte que votre code écrit est enregistré en totalité.

Si vous souhaitez tester Aspose.Slides sans les limitations de la version d'évaluation, vous pouvez également demander une licence temporaire de 30 jours. Veuillez consulter [Comment obtenir une licence temporaire ?](https://purchase.aspose.com/temporary-license)

## **FAQ**

### Puis-je tester plusieurs présentations en parallèle sur différents threads en mode évaluation ?

Oui. Vous pouvez traiter différents documents en parallèle ; vous ne devez pas partager le même objet de présentation [across threads](/slides/fr/cpp/multithreading/). Le mode évaluation n'affecte pas cela.

### Dois-je installer Microsoft PowerPoint pour évaluer la bibliothèque sur un serveur ou dans une intégration continue ?

Non. Aspose.Slides est un moteur autonome et ne nécessite pas l'installation de PowerPoint, que ce soit pour l'évaluation ou la production.

### Puis-je tester complètement la conversion de PPT/PPTX en PDF et en images en mode évaluation ?

Oui. Les [converters](/slides/fr/cpp/convert-presentation/) fonctionnent ; la sortie comprendra un filigrane.

### Puis-je utiliser une licence temporaire pour les tests de charge sans filigrane ?

Oui. Une licence temporaire de 30 jours supprime les limitations du mode évaluation et permet de tester sans filigrane.
