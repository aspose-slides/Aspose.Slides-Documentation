{{% alert color="info" title="Note" %}}

När Aspose.Slides för SharePoint är installerat på SharePoint‑servern och aktiverat för en webbplatskollektion, lägger det till **Convert via Aspose.Slides**‑objektet i dokumentmenyn i dess dokumentbibliotek, som visas nedan. På SharePoint 2007 heter objektet **Convert with Aspose.Slides**.

**Att installera Aspose.Slides för SharePoint lägger till Convert via Aspose.Slides‑objektet i dokumentmenyer**

![En dokumentmeny med Convert via Aspose.Slides‑objektet](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **Konvertera en presentation**

För att konvertera en Microsoft PowerPoint‑presentation (PPT eller PPTX) från ett SharePoint‑dokumentbibliotek:

1. Välj en Microsoft PowerPoint‑presentation i ett dokumentbibliotek.
2. Öppna dess meny och klicka på **Convert via Aspose.Slides**.

   **Meny för Presentation 2‑filen, som visar Convert via Aspose.Slides‑objektet**

   ![Meny för en presentation i ett dokumentbibliotek, med Convert via Aspose.Slides‑objektet markerat](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. Välj utskriftsformatet under **Convert to**. Om du vill, ändra utskriftsfilens namn och mål‑mappen.
4. Klicka på **Convert** för att konvertera filen.

   **Konverteringssidan låter dig välja utskriftsformat, filnamn och destination**

   ![Konverteringssidan med utskriftsformat, destinationsfil och destinationsmapp](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. När konverteringen är klar visas ett bekräftelsemeddelande.

   **Konverteringen lyckades**

   ![Resultatsidan för konverteringen](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. Klicka på **Source Library** (för att gå till källmappen) eller **Destination Library** (för att gå till mappen där filen sparades).

   Det konverterade dokumentet visas i dokumentbiblioteket.

   **Det konverterade dokumentet som visas i biblioteket där det sparades**

   ![Den konverterade filen i dokumentbiblioteket](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

Skärmbilderna togs med en tidigare version, som endast erbjöd PDF-, TIFF‑ och XPS‑formaten. Den aktuella konverteringssidan erbjuder fler utskriftsformat; se [Multiple Format Support](/slides/sv/sharepoint/multiple-format-support/).

{{% /alert %}}

På SharePoint 2010 och senare kan du också välja en eller flera presentationer i biblioteket och klicka på **Convert Slides** på fliken **Aspose Tools** i menyfliksområdet. Den öppnar samma konverteringssida.
