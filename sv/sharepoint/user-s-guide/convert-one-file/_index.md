För att konvertera en presentation i ett dokumentbibliotek:

1. Öppna menyn för PPT‑ eller PPTX‑filen (dess Edit Control Block) och välj **Konvertera via Aspose.Slides**. På SharePoint 2007 heter menyalternativet **Konvertera med Aspose.Slides**.

   **Välja Konvertera med Aspose.Slides i menyn för ett dokument på SharePoint 2007**

   ![Meny för ett dokument i ett SharePoint 2007‑dokumentbibliotek, med alternativet Konvertera med Aspose.Slides](convert-one-file_1.png)

2. På konverteringssidan väljer du utdataformat under **Konvertera till**. Om du vill kan du ändra målfilnamnet och målmappen.  
3. Klicka på **Konvertera**.  
4. När konverteringen är klar klickar du på **Källbibliotek** eller **Målbibliotek** för att återgå till ett dokumentbibliotek. Den konverterade filen finns i målmappen.

Samma steg, med skärmdumpar av varje sida, finns i [Konvertera Microsoft PowerPoint-dokument till andra format](/slides/sv/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
