För att avinstallera Aspose.Slides för SharePoint:

1. Kör installationsprogrammet som du använde för att installera det, till exempel *Setup2019.exe* på SharePoint Server 2019.  
   När den hittar samma version installerad erbjuder installationsprogrammet att reparera eller ta bort den. När den hittar en annan version erbjuder den att uppgradera eller ta bort den.
2. Välj **Remove** och klicka på **Next** för att avinstallera Aspose.Slides för SharePoint.
