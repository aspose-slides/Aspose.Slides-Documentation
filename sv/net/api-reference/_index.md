{{% alert color="info" %}} 

Aspose.Slides for .NET är ett klassbibliotek som gör det möjligt för .NET-applikationer att läsa och skriva presentationsdokument utan att använda Microsoft PowerPoint® eller andra. Aspose.Slides for .NET möjliggör hantering av text, former, tabeller & animationer, lägga till ljud och video i bilder, förhandsgranska bilder, exportera bilder till SVG, PDF-format och mer.

Den senaste API-referensen finns på [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/sv/net).
