## **Översikt**

Det här avsnittet innehåller ingen lista över öppna problem i den aktuella versionen. Det innehåller två sidor:

- [Object Preview Placeholder When Adding OleObjectFrame](/slides/sv/net/object-preview-issue-when-adding-oleobjectframe/) förklarar varför ett OLE-objekt som läggs till med Aspose.Slides visar en "EMBEDDED OLE OBJECT"-bild tills dess förhandsgranskning uppdateras, och hur du ställer in din egen förhandsgranskningsbild. Detta är ett avsiktligt beteende i den aktuella versionen.
- [Known Issues in Aspose.Slides for .NET 14.1.0 (Historical)](/slides/sv/net/known-issues-in-aspose-slides-for-net-14-1-0/) är en lista som publicerades med version 14.1.0 år 2014, behållen för referens.

För ändringarna och korrigeringarna i varje version, se [release notes](https://releases.aspose.com/slides/sv/net/release-notes/). Metafälten som Aspose.Slides skriver med fasta värden beskrivs i [Output Metadata Limitations](/slides/sv/net/api-limitations/). För att kontrollera om ett problem redan är känt, eller för att rapportera ett, använd [support forum](https://forum.aspose.com/c/slides/sv/11).
