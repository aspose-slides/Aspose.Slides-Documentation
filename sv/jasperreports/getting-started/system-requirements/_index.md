## **JasperReports**

Aspose.Slides for JasperReports fungerar med JasperReports 3.7.2 till 6.16.0. Nedladdningen har en separat jar för var och en av tre versionintervall — se [Installing Aspose.Slides for JasperReports](/slides/sv/jasperreports/installing-aspose-slides-for-jasperreports/) för att veta vilken som ska användas. Det finns ingen jar för JasperReports 6.17.0 eller senare, inklusive JasperReports 7.

Support för JasperReports 2.0.3 till 3.7.1 avslutades i Aspose.Slides for JasperReports 17.6. Version 17.5 och tidigare stödde också dessa versioner.

## **Java**

Jars-filerna är kompilerade för Java 6 eller senare, som *JDK 1.6* i deras mappnamn visar, så den Java-version du behöver är den som din JasperReports-version kräver. Med JasperReports 6.16.0 körs exporterna på Java 11, 17, 21 och 25.

## **Operativsystem**

Jars-filerna innehåller endast Java-klasser och resurser, utan inhemska bibliotek, och de använder inte Microsoft PowerPoint. På Linux kräver JasperReports fontconfig och minst ett installerat teckensnitt för att fylla i en rapport.

## **JasperReports Server**

För JasperReports Server, använd båda jars-filerna från den mapp som motsvarar den JasperReports-version som din server kör — se [Integration with JasperServer](/slides/sv/jasperreports/integration-with-jasperserver/).
