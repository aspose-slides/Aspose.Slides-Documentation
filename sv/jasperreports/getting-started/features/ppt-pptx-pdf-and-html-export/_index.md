{{% alert color="info" %}} 
JasperReports och JasperServer har inte inbyggda möjligheter att exportera rapporter som Microsoft PowerPoint‑presentationer, men med Aspose.Slides for JasperReports får du tillgång till ytterligare exportformat:

- Microsoft PowerPoint Presentation (PPT)
- Microsoft PowerPoint Presentation (PPTX)
- HTML
- PDF
{{% /alert %}} 
För att skapa dokument i dessa format förlitar sig Aspose.Slides for JasperReports på en inbyggd version av [Aspose.Slides for Java](https://products.aspose.com/slides/sv/java/), den marknadsledande presentationsbearbetningsbiblioteket från Aspose. Microsoft PowerPoint används inte för att generera dokumenten.
