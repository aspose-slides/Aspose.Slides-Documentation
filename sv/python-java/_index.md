**Välkommen till Aspose.Slides för Python via Java**

![Aspose.Slides för Python via Java produktlogotyp](aspose_slides-for-python-via-java.png)

Aspose.Slides för Python via Java är ett klassbibliotek som gör att dina Python‑applikationer kan läsa och skriva PowerPoint®‑presentationer utan att kräva Microsoft PowerPoint®.

Dess viktigaste funktioner inkluderar hantering av text, former, tabeller och animationer; lägga till ljud och video till bilder; förhandsgranska bilder; och exportera bilder till SVG, PDF och andra format.
