{{% alert color="info" title="Obs" %}}

Aspose.Slides for Python via Java är ett klassbibliotek som gör det möjligt för Python‑applikationer att läsa och skriva presentationer utan att kräva Microsoft PowerPoint®. Det låter dig hantera text, former, tabeller och animationer; lägga till ljud och video på bilder; förhandsgranska bilder; och exportera bilder till SVG, PDF och andra format.

För mer information, se [Aspose.Slides for Python via Java API-referens](https://reference.aspose.com/slides/sv/python-java/).
