Du kan ladda ner Aspose.Slides för Python via Java för att utvärdera dess funktioner. Utvärderingspaketet är identiskt med det licensierade paketet. För att använda det utan utvärderingsbegränsningar, lägg till några kodrader i [ansök om licens](/slides/sv/python-java/licensing/).

Utvärderingsversionen av Aspose.Slides (använd utan licens) erbjuder full produktfunktionalitet, med två begränsningar:

- Den lägger till en vattenstämplingstextlåda för utvärdering på varje bild i varje presentation den sparar. Att öppna en presentation lägger inte till någon, men att spara en fil som redan har vattenstämpeln lägger till en till.
- Text som din kod läser av trunkeras till de första tecknen, följt av ett meddelande om utvärderingsbegränsningen. Detta gäller för varje bild, och för text som din kod just har satt såväl som text som lästs in från en fil. Text som din kod skriver sparas i sin helhet.

{{% alert color="info" title="Note" %}}
För att testa Aspose.Slides utan utvärderingsbegränsningar kan du begära en **30‑dagars tillfällig licens**. Se [Få en tillfällig licens](https://purchase.aspose.com/temporary-license) för mer information.
