Du kan ladda ner Aspose.Slides för Python via Java för att utvärdera dess funktioner. Utvärderingspaketet är identiskt med det licensierade paketet. För att använda det utan utvärderingsbegränsningar, lägg till några rader kod för att tillämpa en licens.

Utvärderingsversionen av Aspose.Slides (använd utan licens) erbjuder full produktfunktionalitet, men den lägger in ett utvärderingsvattenmärke högst upp i dokumentet när du öppnar eller sparar det. Textutdrag är begränsat till en bild per presentation.

![Utvärderingsvattenmärke för Aspose.Slides på en presentationsbild](evaluate-aspose-slides_1.png)

{{% alert color="info" title="Obs" %}}
För att testa Aspose.Slides utan utvärderingsbegränsningar kan du begära en **30-dagars temporär licens**. Se [Få en temporär licens](https://purchase.aspose.com/temporary-license) för mer information.
