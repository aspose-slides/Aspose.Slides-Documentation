## **Stödda plattformar**
Aspose.Slides for Node.js via .NET är ett plattformsoberoende API. Det kan användas på alla plattformar (Windows, Linux, macOS osv.) där Node.js 7 eller högre är installerat. Oracle JDK 8 eller högre är ett annat krav.

## **Filformat och konverteringar**
Aspose.Slides for Node.js via .NET stöder de flesta PowerPoint-dokumentformat. Det låter dig också exportera dem till de populära filformat som organisationer använder och delar med varandra. Gå igenom dessa detaljer:

|**Funktion**|**Beskrivning**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET erbjuder den snabbaste bearbetningen för detta presentationsdokumentformat.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET stöder PPT till PPTX-konvertering|
|Portable Document Format (PDF)|Du kan exportera alla stödda filformat till Adobe Portable Document Format (PDF)-dokument med en enda metod.|
|XML Parser Specification (XPS)|Du kan exportera alla stödda filformat till XML Parser Specification (XPS)-dokument med en enda metod.|
|Tagged Image File Format (TIFF)|Du kan exportera alla stödda presentationsfilformat till Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET stöder konvertering av PresentationEx till HTML-format.|

## **Rendering av presentation**
Aspose.Slides för Node.js via .NET stöder högkvalitativ rendering av bilder i en presentation till olika grafikformat. Gå igenom dessa detaljer:

|**Funktion**|**Beskrivning**|
| :- | :- |
|.NET Supported Image Formats|Med Aspose.Slides for Node.js via .NET kan du rendera presentationsbilder och bilder på bilder till alla .NET‑stödda grafikformat såsom TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via .NET erbjuder även inbyggda metoder som låter dig exportera presentationsbilder till Scalable Vector Graphics (SVG)-format.|

|**Funktion**|**Beskrivning**|
| :- | :- |

|Cloning / Copying Slides|Det finns inbyggda metoder i Aspose.Slides for Node.js via .NET som låter dig klona eller kopiera befintliga bilder inom en presentation. Du kan också använda kopierade och klonade bilder från en presentation till en annan. Eftersom en bild ärver sin layout från master‑bilden kopierar de inbyggda kloningsmetoderna automatiskt master‑bilden vid kloning.|
|Managing Slides sections|Metoder för att organisera bilder i olika sektioner inom en presentation.|
|Place Holders and Text Holders|Du kan komma åt platshållare och texthållare i en bild. Dessutom kan du skapa en bild med texthållare från grunden med lämplig metod.|
|Header and Footers|Aspose.Slides for Node.js via .NET underlättar hanteringen av sidhuvuden/sidfötter i bilder.|

|Finding a Shape|Du kan också hitta en specifik form i en bild genom att använda den alternativa texten som är kopplad till formen.|
|Backgrounds|Aspose.Slides for Node.js via .NET låter dig arbeta med bakgrunder som är kopplade till en master‑ eller vanlig bild i en presentation.|
|Text Boxes|Textrutor kan skapas från grunden. Du kan komma åt befintliga textrutor. Du kan också ändra deras texter utan att förlora det ursprungliga textformatet.|
|Rectangle Shapes|Du kan skapa eller ändra rektangelformer med Aspose.Slides for Node.js via .NET.|
|Poly Line Shapes|Du kan skapa eller ändra polylinjefigurer med Aspose.Slides for Node.js via .NET.|
|Ellipse Shapes|Du kan skapa eller ändra ellipsformer med Aspose.Slides for Node.js via .NET.|
|Group Shapes|Aspose.Slides for Node.js via .NET stöder gruppformer|

|Shapes Serialization|Aspose.Slides for Node.js via .NET stöder ett stort antal former. |VBA Macros|Stöd för hantering av VBA‑makron i presentationer.|
|Text Frame|Du kan komma åt texten i vilken form som helst via textramen som är kopplad till den formen.|
|Text Scanning|Du kan skanna text i en presentation på presentations- eller bildnivå genom inbyggda skanningsmetoder.|
|Animations|Du kan applicera animationer på former.|
|Slide Shows|Aspose.Slides for Node.js via .NET stöder bildspel och bildövergångar.|
