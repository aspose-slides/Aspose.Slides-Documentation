**Välkommen till Aspose.Slides för Node.js via .NET**

![Aspose.Slides för Node.js via .NET Produktlogotyp](aspose_slides-for-nodejs-via-net.png)

Aspose.Slides för Node.js via .NET är ett klassbibliotek som gör att dina applikationer kan läsa och skriva PowerPoint®-dokument utan att använda Microsoft PowerPoint®.

Aspose.Slides för Node.js via .NET är den första och enda komponenten som erbjuder funktionalitet för att hantera PowerPoint®-dokument.

Aspose.Slides för Node.js via .NET erbjuder många viktiga funktioner såsom hantering av text, former, tabeller och animationer, att lägga till ljud och video i bilder, förhandsgranska bilder, exportera bilder till SVG, PDF-format och mer.
