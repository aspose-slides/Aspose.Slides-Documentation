{{% alert color="info" %}} 

Aspose.Slides for C++ är ett klassbibliotek som gör det möjligt för C++-applikationer att läsa och skriva presentationsdokument utan att använda Microsoft PowerPoint® eller andra program. Aspose.Slides for C++ möjliggör hantering av text, former, tabeller och animationer, lägga till ljud och video i bilder, förhandsgranska bilder, exportera bilder till SVG, PDF-format och mer.

Den senaste API-referensen finns på [Aspose.Slides for C++ API-referens](https://reference.aspose.com/slides/sv/cpp/).
