## **Filformat och konverteringar**
Aspose.Slides forC++ supports most of the PowerPoint document formats and also exports them to popular formats used widely for exchange among organizations. Following table enlists these formats:

|**Funktion**|**Beskrivning**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/sv/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ ger den snabbaste bearbetningen för detta presentationsdokumentformat.|
|[Portable Document Format (PDF)](/slides/sv/cpp/portable-document-format-pdf/)|De stödjade filformaten kan exporteras till Adobe Portable Document Format (PDF) dokument med en enda metod.|
|[XML Parser Specification (XPS)](/slides/sv/cpp/xml-parser-specification-xps/)|Alla de stödjade filformaten kan exporteras till XML Parser Specification (XPS) dokument med en enda metod.|
|[PresentationML (PPTX, XML)](/slides/sv/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ stöder bearbetning av OOXML-presentationsformatet även känt som PresentationML eller PPTX.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/sv/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ stöder konvertering av presentation till HTML-format.|

## **FAQ**

**Behöver jag installera Microsoft PowerPoint på servern/PC:n för att biblioteket ska fungera?**

Nej. PowerPoint krävs inte; Aspose.Slides är en fristående motor för att skapa, redigera, konvertera och rendera presentationer.

**Hur fungerar multitrådning? Kan bearbetning parallelliseras?**

Det är säkert att bearbeta olika dokument i separata trådar; samma [presentation](https://reference.aspose.com/slides/sv/cpp/aspose.slides/presentation/)-objekt får inte användas av [flera trådar](/slides/sv/cpp/multithreading/) samtidigt.

**Stöds fillösenord och kryptering?**

Ja. [Du kan](/slides/sv/cpp/password-protected-presentation/) öppna krypterade presentationer, ange eller ta bort ett öppnings- och skrivlösenord, och kontrollera skyddstatusen.

**Behöver jag bry mig om typsnittspaket i Linux-containrar?**

Ja. Det rekommenderas att installera vanliga typsnittspaket och/eller uttryckligen [ange typsnittskataloger](/slides/sv/cpp/custom-font/) i din applikation för att undvika oväntade ersättningar.

**Finns det begränsningar i evalueringsversionen?**

I [utvärderingsläge](/slides/sv/cpp/licensing/) läggs en vattenstämpel till i resultatet och vissa begränsningar gäller; en [30-dagars temporär licens](https://purchase.aspose.com/temporary-license/) är tillgänglig för fullständig funktionstestning.

**Stöds import av externa format till en presentation (PDF/HTML → PPTX)?**

Ja. Du kan lägga till [PDF-sidor och HTML-innehåll](/slides/sv/cpp/import-presentation/) i en presentation, vilket omvandlar dem till bilder.
