**Välkommen till Aspose.Slides for C++**

Aspose.Slides for C++ är ett Microsoft PowerPoint®‑hanterings‑API som gör det möjligt för C++‑applikationer att läsa och skriva PowerPoint®‑dokument utan att använda Microsoft PowerPoint®. Aspose.Slides for C++ är den första och enda komponenten som erbjuder funktionalitet för att hantera PowerPoint®‑dokument. Aspose.Slides for C++ erbjuder många viktiga funktioner såsom hantering av text, former, tabeller & animationer, tillsättning av ljud och video till bilder, förhandsgranskning av bilder, export av bilder till SVG‑ och PDF‑format samt mer.
