**Välkommen till Aspose.Slides for C++**

Aspose.Slides for C++ är ett Microsoft PowerPoint®-hanterings-API som möjliggör för C++-applikationer att läsa och skriva PowerPoint®-dokument utan att använda Microsoft PowerPoint®. Aspose.Slides for C++ är den första och enda komponenten som tillhandahåller funktionaliteten för att hantera PowerPoint®-dokument. Aspose.Slides for C++ erbjuder många viktiga funktioner såsom hantering av text, former, tabeller och animationer, lägga till ljud och video i bilder, förhandsgranska bilder, exportera bilder till SVG, PDF-format och mer.
