**Välkommen till Aspose.Slides for Android via Java**

Aspose.Slides for Android via Java är ett Microsoft PowerPoint®-hanterings-API som gör det möjligt för Android-applikationer att läsa och skriva PowerPoint®-dokument utan Microsoft PowerPoint®. Aspose.Slides for Android via Java är den första och enda komponenten som tillhandahåller de funktioner som krävs för att hantera PowerPoint®-dokument på Android-plattformar. Aspose.Slides for Android erbjuder många nyckelfunktioner som låter dig lägga till, ändra och manipulera text, former, tabeller och animationer, ljud och video i bilder.
