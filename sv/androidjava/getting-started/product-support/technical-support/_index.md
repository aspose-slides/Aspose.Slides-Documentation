## **Översikt**

Den här artikeln förklarar hur du får support för Aspose.Slides och hur du rapporterar problem på ett effektivt sätt. Den beskriver huvudsupportkanalen, ger rekommendationer för hur du skickar in ett problem och pekar på användbara tekniska resurser som produktsidan, bloggen, nedladdningar, supportforum, dokumentation och API-Referens. Artikeln svarar också på vanliga frågor om betald support, eskalering av ärenden och support för äldre versioner av biblioteket.

## **Teknisk support**

{{% alert color="info" %}} 

Aspose erbjuder obegränsad gratis teknisk support för alla sina produkter. Supporten är tillgänglig för alla användare (inklusive användare med utvärderingspaket).

{{% /alert %}} 

När du behöver hjälp med Aspose.Slides för Android via Java, överväg följande:

- Den huvudsakliga supportvägen är Aspose.Forums. Posta din fråga i Aspose.Slides‑forumet – och den besvaras inom några timmar. Aspose.Slides supportteam svarar direkt på frågor som postas i forumet.
- Observera att Aspose inte erbjuder teknisk support via telefon. Telefonstöd är endast tillgängligt för försäljnings- och inköpsfrågor.
- När du förväntar dig ett svar i forumet, var vänlig ha tålamod och ta hänsyn till tidszonskillnader.

När du stöter på ett problem med Aspose.Slides för Android via Java, följ dessa riktlinjer för att lösa det på det mest effektiva sättet:

- Kontrollera och bekräfta att du använder den senaste versionen av Aspose.Slides för Android via Java innan du rapporterar problemet. Kanske var problemet du upplevde redan löst i en uppdatering.

  Se Aspose.Slides download för att få information om den senaste versionen.

- Innan du rapporterar ett problem kan du vilja gå igenom våra forum, den här dokumentationen och API-Referensen. Kanske har svaret på din fråga redan givits.

- När du rapporterar ett problem, inkludera gärna originaldokumentet och (om möjligt) ett kodfragment som rör problemet. Om du behöver bifoga flera filer, lägg dem i ett ZIP‑paket.

  Du kan säkert bifoga dina dokument i Aspose.Forums eftersom bara du och Aspose‑utvecklare har åtkomst till de bifogade filerna.

- Skapa och använd en tråd för ett specifikt problem. Om du stöter på ett annat problem måste du skapa en ny tråd för att rapportera det.

## **FAQ**

### Vilka betalda supportnivåer finns tillgängliga och hur skiljer de sig?

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). De skiljer sig åt med avseende på antalet incidenter som ingår, svarsprioritet och tillgängliga kommunikationskanaler.

### Kan jag eskalera ett fel direkt till ingenjörsteamet?

Ja. [Betald support](https://helpdesk.aspose.com/) möjliggör eskalering till utvecklarna när ett problem kräver djupare undersökning.

### Stöds äldre biblioteksversioner, och släpper ni korrigeringar för dem?

Du kan använda äldre versioner, men korrigeringar tillhandahålls endast för den aktuella releasen; patchar för äldre versioner utfärdas inte.
