## **Stöd för äldre kod**
För att kunna använda den äldre koden som utvecklats med Aspose.Slides för Java versioner före 13.x måste du göra några mindre ändringar i din kod så att den fungerar som tidigare. Alla klasser som fanns i den gamla Aspose.Slides för Java under namnutrymmena Aspose.Slide och Aspose.Slides.Pptx har nu slagits samman i ett enda Aspose.Slides‑namnutrymme. Titta på följande enkla kodexempel för att skapa ett Hello World‑presentationsdokument i den äldre Aspose.Slides‑API:n och följ stegen som beskriver hur du migrerar till det nya sammanslagna API‑et.
