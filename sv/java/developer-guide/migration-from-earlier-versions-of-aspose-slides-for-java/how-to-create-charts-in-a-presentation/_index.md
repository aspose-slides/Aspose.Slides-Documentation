En ny [Aspose.Slides for Java API](https://docs.aspose.com/slides/sv/java/) har släppts och nu stöder denna enda produkt möjligheten att skapa PowerPoint-dokument från grunden och redigera befintliga.

{{% /alert %}} 
## **Stöd för gammalkod**
För att använda den äldre koden som utvecklats med Aspose.Slides for Java versioner före 14.x.x måste du göra några mindre ändringar i din kod, och koden kommer att fungera som tidigare. Alla klasser som fanns i den gamla Aspose.Slides for Java under namnrymderna com.aspose.slides och com.aspose.slides.pptx har nu slagits ihop i ett enda namnrum com.aspose.slides. Ta en titt på följande enkla kodexempel för att skapa ett vanligt diagram från grunden i en presentation med det äldre Aspose.Slides API:et och följ stegen som beskriver hur du migrerar till det nya sammanslagna API-et.
