{{% alert color="info" title="Note" %}}

Det här är en historisk sida. Den listar de kända problemen som publicerats med Aspose.Slides for Java 14.3.0 och beskriver inte den aktuella versionen. För förändringarna i varje version, se [versionsanteckningar](https://releases.aspose.com/slides/sv/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) erbjuder en helt ny implementation av PPT-bearbetning. Det finns många förbättringar, delvis konvertering från PPTX till PPT. Men det finns vissa oimplementerade funktioner:

- Vissa former har fel geometrik i serialiserade PPT-dokument (Call outs)
- Inte alla PPTX-textformateringsfunktioner stöds i PPT-serialisering
- Information om textspråk och stavningsinställningar saknas i serialiserade PPT-dokument
- Inte alla PPTX-temafunktioner stöds i PPT-serialisering

**Det finns vissa skillnader jämfört med Aspose.Slides for Java 8.6.0:**

- Det finns kända problem i OLE/ActiveX PPT-serialisering till PPT

**Det finns vissa skillnader jämfört med Aspose.Slides for .NET 14.3.0:**

- Stöd för utskrift av presentationer är för närvarande inte tillgängligt i Aspose.Slides for Java
