## **Översikt**

Detta avsnitt innehåller inte en lista över öppna problem i den aktuella versionen. Det innehåller tre sidor:

- [Objektförhandsgranskningsplatshållare när OleObjectFrame läggs till](/slides/sv/java/object-preview-issue-when-adding-oleobjectframe/) förklarar varför ett OLE‑objekt som lagts till med Aspose.Slides visar en "EMBEDDED OLE OBJECT"-bild tills dess förhandsgranskning uppdateras, och hur du ställer in din egen förhandsgranskningsbild. Detta är avsedd funktion i den aktuella versionen.
- [Kända problem i Aspose.Slides för Java 14.3.0 (historisk)](/slides/sv/java/known-issues-in-aspose-slides-for-java-14-3-0/) och [Kända problem i Aspose.Slides för Java 14.4.0 (historisk)](/slides/sv/java/known-issues-in-aspose-slides-for-java-14-4-0/) är listor som publicerades med dessa versioner, bevarade för referens.

För ändringar och korrigeringar i varje version, se [versionsanteckningar](https://releases.aspose.com/slides/sv/java/release-notes/). Metadatafält som Aspose.Slides skriver med fasta värden beskrivs i [Begränsningar för utdata‑metadata](/slides/sv/java/api-limitations/). För att kontrollera om ett problem redan är känt, eller för att rapportera ett, använd [supportforum](https://forum.aspose.com/c/slides/sv/11).
