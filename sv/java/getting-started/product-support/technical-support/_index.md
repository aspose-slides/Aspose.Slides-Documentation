## **Översikt**

Den här artikeln förklarar hur du får support för Aspose.Slides och hur du rapporterar problem på ett effektivt sätt. Den beskriver huvudstödkanelen, ger rekommendationer för att skicka in ett problem och pekar på användbara tekniska resurser såsom produktsidan, bloggen, nedladdningar, supportforum, dokumentation och API-referens. Artikeln svarar också på vanliga frågor om betald support, ärendeeskalering och support för äldre versioner av biblioteket.

## **Teknisk support**

{{% alert color="info" %}} 
Aspose erbjuder obegränsad gratis teknisk support för alla sina produkter. Supporten är tillgänglig för alla användare, inklusive utvärdering.
{{% /alert %}} 

Om du behöver hjälp med Aspose.Slides för Java, överväg följande:

- Huvudvägen för support är Aspose.Forums. Lägg upp din fråga i Aspose.Slides‑forumet så svaras den inom några timmar. Frågorna besvaras direkt av Aspose.Slides supportteam.
- Observera att Aspose inte erbjuder teknisk support via telefon. Telefonsupport är endast tillgänglig för frågor om försäljning och köp.
- När du förväntar dig ett svar i forumen, vänligen ta hänsyn till tidsskillnader.

Om du har ett problem med Aspose.Slides för Java, följ dessa enkla steg för att säkerställa att det löses på det mest effektiva sättet:

- Se till att du använder den senaste versionen av Aspose.Slides för Java innan du rapporterar problemet, se Aspose.Slides‑nedladdning för att ta reda på den senaste versionen.
- Titta igenom forumen, den här dokumentationen och API‑referensen innan du rapporterar problemet; kanske har din fråga redan besvarats.
- När du rapporterar ett problem, inkludera gärna originaldokumentet och eventuellt ett kodfragment som orsakar problemet. Om du behöver bifoga flera filer, packa dem i en zip‑fil. Det är säkert att bifoga dina dokument i Aspose.Forums eftersom endast du och Aspose‑utvecklarna har åtkomst till de bifogade filerna.
- Försök att rapportera ett problem per tråd. Om du har ett annat problem, rapportera det i en separat tråd.

## **FAQ**

### Vilka betalda supportnivåer finns tillgängliga och hur skiljer de sig?

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). De skiljer sig åt med avseende på antalet inkluderade incidenter, svarsprioritet och tillgängliga kommunikationskanaler.

### Kan jag eskalera ett fel direkt till ingenjörsteamet?

Ja. [Paid support](https://helpdesk.aspose.com/) möjliggör eskalering till utvecklarna när ett problem kräver djupare undersökning.

### Stöds äldre biblioteksversioner, och släpper ni korrigeringar för dem?

Du kan använda äldre versioner, men korrigeringar tillhandahålls för den aktuella releasen; patchar för äldre versioner utfärdas inte.
