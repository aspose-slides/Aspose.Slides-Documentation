{{% alert color="info" title="Note" %}}

Detta är en historisk sida. Den beskriver ett fel i Aspose.Slides för Java versionerna 23.2 till 23.7, som släpptes 2023, samt de versioner som åtgärdade det. Den beskriver inte den aktuella versionen. För licensiering i den aktuella versionen, se [Licensing](/slides/sv/java/licensing/).

{{% /alert %}}

## **Översikt**

Denna artikel beskriver ett licensfel som uppstod i Aspose.Slides för Java versionerna 23.2, 23.3, 23.4, 23.5, 23.6 och 23.7. Detta fel gjorde att eviga licenser blev tillfälligt oåtkomliga efter att deras prenumeration löpte ut.

## **Symptom**

När din eviga licensprenumeration löper ut kan Aspose.Slides för Java versionerna 23.2 - 23.7 rapportera licensen som utgången, vilket övergår alla funktioner till utvärderingsläge.
Detta beteende är felaktigt och påverkar inte versioner före 23.2 och efter 23.7.

## **Lösning**

Aspose.Slides för Java åtgärdade detta problem och släppte uppdaterade versioner (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) med korrigeringen.

Om du använder någon av de drabbade versionerna av Aspose.Slides för Java i ditt projekt, byt till den korrigerade versionen.

Om du upplever några licensproblem med Aspose.Slides för Java:

- Kontrollera den version du använder och säkerställ att den inte påverkas av felet som beskrivits ovan.
- Se [Licensing](/slides/sv/java/licensing/) för hur du tillämpar och validerar en licens.
- Kontakta [Aspose support](https://forum.aspose.com/c/slides/sv/11) för ytterligare hjälp.

## **Påverkade produkter och versioner**

Observera att detta fel endast påverkar Aspose.Slides för Java versionerna 23.2 till 23.7. **Andra Aspose‑produkter och andra versioner av Aspose.Slides är inte påverkade**.
