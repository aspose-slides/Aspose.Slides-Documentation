{{% alert color="info" title="Note" %}}

Konvertering från PPT till PPTX stöds av Aspose.Slides för Java. De flesta presentationsfunktioner – masterbilder, struktur med mera – bevaras när de konverteras från ett format till ett annat, men det finns några begränsningar.

{{% /alert %}}
## **Funktioner som stöds i konvertering**
Aspose.Slides för Java erbjuder partiellt stöd för att konvertera PPT‑filformatet till PPTX. Stödet för konvertering har precis introducerats i Aspose.Slides för Java, så det har några begränsningar och fungerar bäst för enkla presentationer. Den största fördelen med Aspose.Slides för Java vid konvertering från PPT till PPTX är hur enkelt API:et är att använda. För att se exempel på koden, se [Konvertera PPT till PPTX](/slides/sv/java/convert-ppt-to-pptx/). Listan nedan visar vilka funktioner som stöds för PPT‑till‑PPTX‑konvertering.

## **Stödda funktioner**
Följande funktioner stöds för konvertering:

- Konvertering av strukturen för masterbilder, layouter och bilder.
- Konvertering av diagram.
- Grupperade former.
- Konvertering av automatiska former, inklusive rektanglar och ellipser.
- Former med anpassad geometri.
- Textur‑ och bildfyllningsstilar för automatiska former.
- Konvertering av platshållare.
- Konvertering av linjer och polylinjer.
- Linje‑ och fyllningsformat.
- Gradientfyllningsstilar.
- OLE‑ramar, tabeller, video‑ och audio‑ramar osv.
- Animations‑ och bildspels‑egenskaper.
- Konvertering av text i textramar och textbehållare.
