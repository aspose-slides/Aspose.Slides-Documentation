PPT‑till‑PPTX‑konvertering stöds i Aspose.Slides for Java. De flesta presentationsfunktioner – masterbilder, struktur och så vidare – behålls när de konverteras från ett format till det andra, men det finns [några begränsningar](/slides/sv/java/ppt-to-pptx-conversion/).

## **Funktioner som stöds vid konvertering**
Aspose.Slides for Java ger partiellt stöd för att konvertera PPT‑filformatet till PPTX. Stödet för konvertering har precis införts i Aspose.Slides for Java, så det har några begränsningar och fungerar bäst för enkla presentationer. Den främsta fördelen som Aspose.Slides for Java erbjuder vid konvertering av PPT till PPTX är hur enkelt API:et är att använda. För att se exempel på koden, läs om [Konvertera PPT till PPTX](). Nedan förklarar listorna vilka funktioner som stöds och vilka som inte gör det för PPT‑till‑PPTX‑konvertering.

## **Funktioner som stöds**
Följande funktioner stöds för konvertering:

- Konvertera strukturen för masterbilder, layouter och bilder.
- Konvertera diagram.
- Grupperade former.
- Konvertera autogestalter inklusive rektanglar och ellipser. 
- Former med anpassad geometri.
- Textur‑ och bildfyllnadsstilar för autogestalter.
- Konvertera platshållare.
- Konvertera linjer och polylinjer.
- Linje‑ och fyllnadsformat.
- Gradientfyllnadsstilar.
- OLE‑ramar, tabeller, video‑ och ljudramar, osv.
- Animations‑ och bildsparsegenskaper.
- Konvertera text i textramar och texthållare.
