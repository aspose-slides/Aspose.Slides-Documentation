[Portable Document Format](https://en.wikipedia.org/wiki/PDF) är ett filformat skapat av Adobe Systems för att utbyta dokument mellan organisationer. Syftet med formatet var att hålla innehåll och layout oförändrade, oavsett vilken plattform det visas på. Aspose.Slides for Java låter dig konvertera presentationsfiler till PDF.

{{% /alert %}}

## **PDF i Aspose.Slides for Java**
Alla presentationer som kan laddas in i Aspose.Slides for Java kan konverteras till en PDF som följer [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) eller [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) beroende på ditt val. Aspose.Slides for Java exporterar presentationer till PDF och i de flesta fall ser den genererade PDF‑filen exakt likadan ut som originalpresentationen.

Aspose.Slides stödjer följande presentationsfunktioner vid konvertering till PDF:

- Bilder, textrutor och andra former.
- Text och formatering.
- Stycken och formatering.
- Hyperlänkar.
- Sidhuvuden och sidfötter.
- Punkter.
- Tabeller.

Du kan exportera presentationer till PDF direkt med Aspose.Slides for Java: du behöver ingen annan komponent. Du kan dessutom anpassa exporten från presentation till PDF med olika alternativ som förklaras i [Convert PPT and PPTX to PDF](/slides/sv/java/convert-powerpoint-to-pdf/).
