{{% alert color="info" title="Note" %}}
[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) är presentationsdokumentets filformat som kan skapas, läsas, manipuleras och skrivas av olika versioner av Microsoft PowerPoint. Detta är det binära formatet för presentationsdokument som utvecklats av Microsoft.
{{% /alert %}}

## **PPT i Aspose.Slides för Java**
Aspose.Slides för Java kan läsa PPT‑filer som skapats av programvaran som listas nedan.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

På samma sätt kan PPT‑filer skapade av Aspose.Slides för Java läsas av programvarorna ovan.

## **Omfattande stöd för PPT**
Aspose.Slides för Java erbjuder stöd för nästan alla funktioner som stöds av PPT‑dokumentformatet. Det täcker inte bara de grundläggande och avancerade funktionerna som erbjuds av olika Microsoft PowerPoint‑versioner för PPT‑dokumentmanipulationer, utan även funktioner som inte ens stöds av Microsoft PowerPoint. Den största fördelen med att använda Aspose.Slides för Java API‑biblioteket är dess användarvänlighet för hantering av sådana funktioner.

Förutom de grundläggande uppgifterna relaterade till att skapa, läsa och skriva PPT‑dokumentfiler finns flera funktioner som erbjuds av Aspose.Slides för Java:

- Importera andra Microsoft Office‑filformat som [OLE‑objekt i PPT‑dokument](/slides/sv/java/manage-ole/).
- [Exportera PPT‑dokument till PDF](/slides/sv/java/convert-powerpoint-to-pdf/).
- Exportera bildspel i PPT‑dokument till SVG‑format.
- Rendera bildspel till vilket bildformat som helst som stöds av Java‑ramverket.
- Ställ in storleken på bildspel i PPT‑dokument.
- Hantera animationer på former.
- Hantera bildspelsvisningar.
- [Formatera text på bildspel](/slides/sv/java/text-formatting/).
- Extrahera text från PPT‑dokument.
- [Hantera tabeller på bildspel](/slides/sv/java/powerpoint-table/).
- Kopiera automatiskt masterbilder med [kloningsfunktionen](/slides/sv/java/clone-slides/).
