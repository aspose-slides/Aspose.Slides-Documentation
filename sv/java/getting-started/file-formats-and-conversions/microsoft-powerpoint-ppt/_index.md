{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) är dokumentformatet för presentationsfiler som kan skapas, läsas, manipuleras och skrivas av olika versioner av Microsoft PowerPoint. Detta är det binära formatet för presentationsdokument som utvecklats av Microsoft.

{{% /alert %}} 

## **PPT i Aspose.Slides för Java**
Aspose.Slides för Java kan läsa PPT-filer som skapats av programmen nedan.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

På samma sätt kan PPT-filer som skapats av Aspose.Slides för Java läsas av ovanstående programvara.

## **Omfattande stöd för PPT**
Aspose.Slides för Java erbjuder stöd för nästan alla funktioner som PPT-dokumentformatet stödjer. Det täcker inte bara de grundläggande och avancerade funktionerna som tillhandahålls av olika Microsoft PowerPoint-versioner för PPT-dokumentmanipulationer, utan även funktioner som inte ens stöds av Microsoft PowerPoint. Den största fördelen med att använda Aspose.Slides för Java API-biblioteket är dess enkla användning för att hantera sådana funktioner.

Förutom de grundläggande uppgifterna att skapa, läsa och skriva PPT-dokumentfiler finns flera funktioner som tillhandahålls av Aspose.Slides för Java:

- Importera andra Microsoft Office-filformat som [OLE-objekt i PPT-dokument]().
- [Exportera PPT-dokument till PDF](/slides/sv/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- Exportera bilder i PPT-dokument till SVG-format.
- Rendera bilder till valfritt bildformat som stöds av Java-ramverket.
- Ställ in storleken på bilder i PPT-dokument.
- Hantera animationer på former.
- Hantera bildspel.
- [Formatera text på bilder]().
- Extrahera text från PPT-dokument.
- [Hantera tabeller på bilder]().
- Kopiera automatiskt masters med [kloningsfunktionen]().
