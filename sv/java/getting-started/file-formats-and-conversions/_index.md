Artiklarna i det här avsnittet är äldre översikter av enskilda filformat, bevarade för befintliga länkar. De beskriver inte den aktuella versionen av Aspose.Slides för Java. För de format som Aspose.Slides för Java laddar, importerar, sparar och renderar, samt API:et för var och en, se [Stödda filformat](/slides/sv/java/supported-file-formats/). För konverteringsguider, se [Konvertera presentationer](/slides/sv/java/convert-presentation/).
