## **Om TIFF**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) som är känt för att lagra flera bilder i ett dokument skapades ursprungligen av Aldus. Detta format stödjs brett av skannings-, fax- och andra bildbehandlingsprogram.

## **TIFF i Aspose.Slides för Java**

Alla dokument som kan läsas in i Aspose.Slides för Java kan också konverteras till TIFF-dokument direkt av Aspose.Slides för Java, vilket eliminerar behovet av någon tredje parts komponent. Dessutom kan du valfritt ange storleken på bilderna i det resulterande TIFF-dokumentet. Information om hur du exporterar presentationsdokument till TIFF-dokument via Aspose.Slides för Java finns i [Convert PowerPoint Presentations to TIFF](/slides/sv/java/convert-powerpoint-to-tiff/).
