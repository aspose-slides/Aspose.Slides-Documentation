Det här är en historisk sida, sparad för befintliga länkar. Den beskriver inte den aktuella versionen av Aspose.Slides för Java. För de format som Aspose.Slides för Java laddar, importerar, sparar och renderar, samt API:t för var och en, se [Stödda filformat](/slides/sv/java/supported-file-formats/). För den aktuella XPS‑konverteringsguiden, se [Konvertera PowerPoint‑presentationer till XPS](/slides/sv/java/convert-powerpoint-to-xps/).

{{% /alert %}}

{{% alert color="info" title="Obs" %}}

[XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) är ett sidbeskrivningsspråk och ett fast‑dokumentformat som ursprungligen utvecklades av Microsoft. Liksom PDF är XPS utformat för att bevara dokumentets återgivning och ge en enhetsoberoende dokumentpresentation.

{{% /alert %}}

## **XPS i Aspose.Slides för Java**
Alla presentationsdokument som kan laddas av Aspose.Slides för Java kan konverteras till XPS‑format. Aspose.Slides för Java använder en högupplöst sidlayout‑ och renderingsmotor för att producera utdata i ett fast layout XPS‑dokumentformat.
Du kan läsa mer om export av presentationsdokument till XPS‑dokument via Aspose.Slides för Java i [Konvertera PowerPoint‑presentationer till XPS](/slides/sv/java/convert-powerpoint-to-xps/).
