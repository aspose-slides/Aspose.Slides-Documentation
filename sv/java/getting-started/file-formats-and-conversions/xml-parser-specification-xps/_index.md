{{% alert color="info" %}} 

XML‑Parser‑Specifikationen är ett sidbeskrivningsspråk och ett fast‑dokumentformat som ursprungligen utvecklades av Microsoft. Precis som PDF är XPS designat för att bevara dokumentets trohet och erbjuda en enhetsoberoende dokumentutseende. 

{{% /alert %}} 

## **XPS i Aspose.Slides för Java**
Alla presentationsdokument som kan laddas av Aspose.Slides för Java kan konverteras till XPS-format. Aspose.Slides för Java använder den högupplösta sidlayout‑ och renderingsmotorn för att producera utdata i ett fast‑layout XPS-dokumentformat. Du kan lära dig mer om att exportera presentationsdokument till XPS-dokument via Aspose.Slides för Java i [Konvertera till XPS](https://docs.aspose.com/slides/sv/java/convert-powerpoint-to-xps/).
