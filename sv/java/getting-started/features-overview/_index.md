## **Stödda plattformar**
Aspose.Slides for Java supports the most popular development and deployment platforms.

|**Funktion**|**Beskrivning**|
| :- | :- |
|Desktop Applications|Aspose.Slides for Java kan användas för att utveckla Windows Forms-applikationer|
|Enterprise Web Applications|Med Aspose.Slides for Java kan du bygga webbapplikationer. Stöd för att använda Aspose.Slides for Java med PHP finns också.|
|Linux/Unix|Aspose.Slides for Java är ett plattformsoberoende API och kan fungera i en Linux- och Unix-miljö.|

## **Filformat och konverteringar**
Aspose.Slides for Java supports most of the Microsoft PowerPoint document formats and exports them to popular formats used widely by organizations.

|**Funktion**|**Beskrivning**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/sv/java/microsoft-powerpoint-ppt/)|Aspose.Slides for Java erbjuder den snabbaste bearbetningen för detta presentationsdokumentformat.|
|[PresentationML (PPTX, XML)](/slides/sv/java/presentationml-pptx-xml/)|Aspose.Slides for Java stöder bearbetning av OOXML presentationsformat (även känt som PresentationML eller PPTX).|
|[PPT to PPTX conversion](/slides/sv/java/ppt-to-pptx-conversion/)|Aspose.Slides for Java stödjer konvertering från PPT till PPTX.|
|[Portable Document Format (PDF)](/slides/sv/java/developer-guide/)|De stödda filformaten kan exporteras till Adobe Portable Document Format (PDF)-dokument med en enda metod.|
|[XML Parser Specification (XPS)](/slides/sv/java/xml-parser-specification-xps/)|Alla de stödda filformaten kan exporteras till XML Parser Specification (XPS)-dokument med en enda metod.|
|[Tagged Image File Format (TIFF)](https://docs.aspose.com/slides/sv/java/convert-powerpoint-to-tiff/)|De presentationsfilformat som stöds av Aspose.Slides for Java kan också exporteras till Tagged Image File Format (TIFF).|
|[ODP to PPTX Conversion](https://docs.aspose.com/slides/sv/java/convert-odp-to-pptx/)|Aspose.Slides for Java stödjer inläsning av OpenDocument Presentation (ODP) och konvertering till PPTX.|
|[Presentation To HTML Conversion](https://docs.aspose.com/slides/sv/java/convert-powerpoint-to-html/)|Aspose.Slides for Java stödjer konvertering av PresentationEx till HTML-format.|

## **Vanliga frågor**

### Behöver jag installera Microsoft PowerPoint på servern/PC:n för att biblioteket ska fungera?
Nej. PowerPoint krävs inte; Aspose.Slides är en fristående motor för att skapa, redigera, konvertera och rendera presentationer.

### Hur fungerar multitrådad körning? Kan bearbetning parallelliseras?
Det är säkert att bearbeta olika dokument i olika trådar; samma [presentation](https://reference.aspose.com/slides/sv/java/com.aspose.slides/presentation/) objekt får inte användas av [flera trådar](/slides/sv/java/multithreading/) samtidigt.

### Stöds fillösenord och kryptering?
Ja. [Du kan](/slides/sv/java/password-protected-presentation/) öppna krypterade presentationer, ange eller ta bort ett öppnings- och skrivlösenord samt kontrollera skyddsstatusen.

### Behöver jag tänka på teckensnittspaket i Linux-containrar?
Ja. Det rekommenderas att installera vanliga teckensnittspaket och/eller explicit [ange teckensnittskataloger](/slides/sv/java/custom-font/) i din applikation för att undvika oväntade ersättningar.

### Finns det begränsningar i evalueringsversionen?
I [utvärderingsläge](/slides/sv/java/licensing/) läggs ett vattenmärke till i utskriften och vissa begränsningar gäller; en [30-dagars temporär licens](https://purchase.aspose.com/temporary-license/) finns tillgänglig för fullständig testning av funktionerna.

### Stöds import av externa format till en presentation (PDF/HTML → PPTX)?
Ja. Du kan lägga till [PDF-sidor och HTML-innehåll](/slides/sv/java/import-presentation/) till en presentation och omvandla dem till bilder.
