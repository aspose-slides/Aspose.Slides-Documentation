**Välkommen till Aspose.Slides för Node.js via Java**

![Aspose.Slides för Node.js via Java produktlogotyp](aspose_slides-for-nodejs-via-java.png)

Aspose.Slides för Node.js via Java är ett klassbibliotek som möjliggör för dina applikationer att läsa och skriva PowerPoint®-dokument utan att använda Microsoft PowerPoint®.

Aspose.Slides för Node.js via Java är den första och enda komponenten som tillhandahåller funktionaliteten för att hantera PowerPoint®-dokument.

Aspose.Slides för Node.js via Java erbjuder en mängd viktiga funktioner såsom hantering av text, former, tabeller & animationer, lägga till ljud och video till bilder, förhandsgranska bilder, exportera bilder till SVG, PDF‑format och mer.
