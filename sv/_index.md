## Aspose.Slides för .NET

{{% alert color="info" %}}

![Aspose.Slides för .NET produktlogotyp](home_1.png)

Aspose.Slides för .NET är ett Microsoft PowerPoint®‑hanterings‑API som gör det möjligt för .NET‑applikationer att läsa och skriva PowerPoint®‑dokument utan att använda Microsoft PowerPoint®. Aspose.Slides för .NET är den första och enda komponenten som tillhandahåller funktionaliteten för att hantera PowerPoint®‑dokument. Aspose.Slides för .NET erbjuder många viktiga funktioner såsom hantering av text, former, tabeller & animationer, att lägga till ljud och video till bilder, förhandsgranska bilder, exportera bilder till SVG, PDF‑format och mer.
