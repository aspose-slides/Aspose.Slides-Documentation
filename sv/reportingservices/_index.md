Aspose.Slides for Reporting Services är ett återgivningstillägg för Microsoft SQL Server Reporting Services och Power BI Report Server som lägger till presentationsformat i exportlistan för paginerade (RDL) rapporter, utan Microsoft PowerPoint på servern.

Det exporterar rapporter till PPT-, PPTX-, PPS- och PPSX-presentationer och bildspel, till ODP och till XPS.

## **Din första export**

Det finns ingen kod att skriva: du installerar tillägget på rapportsservern, och dess format visas i exportlistan för varje paginerad rapport på den servern.

1. Kontrollera att rapportsservern uppfyller [systemkraven](/slides/sv/reportingservices/system-requirements/), inklusive .NET Framework 3.5.
1. Från [nedladdningssidan](https://releases.aspose.com/slides/reportingservices/), ladda ner MSI‑installationsprogrammet, *Aspose.Slides for Reporting Services*. För att installera manuellt istället, ladda ner ZIP‑paketet, *Aspose.Slides for Reporting Services (DLLs Only)*.
1. Installera tillägget på rapportsservern: kör MSI‑filen som administratör, enligt beskrivningen i [Installera med MSI‑installationsprogrammet](/slides/sv/reportingservices/install-with-msi-installer/), eller följ [Installera manuellt](/slides/sv/reportingservices/install-manually/) för ZIP‑paketet.
1. I en webbläsare, öppna rapportsserverns webbportal (Report Manager på SQL Server 2014 och tidigare). Som standard är dess adress `https://<ComputerName>/reports`.
1. Öppna en paginerad rapport. På rapportverktygsfältet, öppna **Export**‑listan och välj **PPTX – PowerPoint 2007‑presentation via Aspose.Slides**. Om verktygsfältet har en separat **Export**‑knapp, som Report Manager har, välj den.
1. Öppna eller spara PPTX‑filen som webbläsaren laddar ner.

Utan licens har den exporterade presentationen ett utvärderingsvattenmärke — se [Licensiering](/slides/sv/reportingservices/license-aspose-slides-for-reporting-services/). För de övriga formaten i exportlistan, se [Stödda filformat](/slides/sv/reportingservices/supported-file-formats/).
