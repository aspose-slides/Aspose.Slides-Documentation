Эта статья описывает возможности обработки презентаций в Aspose.Slides for Python via Java. Для поддерживаемых операционных систем и зависимостей см. [System Requirements](/slides/ru/python-java/system-requirements/).

## **Форматы файлов и преобразования**

Aspose.Slides for Python via Java позволяет конвертировать между форматами презентаций и экспортировать презентации в документные и веб-форматы. См. [Supported File Formats](/slides/ru/python-java/supported-file-formats/) для полной таблицы форматов и различий между загрузкой презентаций, импортом содержимого и экспортом вывода.

## **Отображение презентаций**

Aspose.Slides for Python via Java обеспечивает высококачественный рендеринг слайдов в виде растровых или векторных изображений для предварительного просмотра и другого визуального вывода. Также он позволяет рендерить изображения на слайдах. Для доступных форматов изображений и заметок об экспорте см. [Supported File Formats](/slides/ru/python-java/supported-file-formats/#supported-file-formats).

## **Функции форматирования**

Aspose.Slides for Python via Java позволяет форматировать текст и фигуры на слайдах презентации, как описано ниже:

|**Функция**|**Описание**|
| :- | :- |
|Форматирование текста|<p>Вы можете управлять текстом через текстовые рамки, связанные с фигурами, и форматировать отдельные абзацы и части текста. Доступны следующие параметры форматирования:</p><p>- Тип шрифта</p><p>- Размер шрифта</p><p>- Цвет шрифта</p><p>- Заливка шрифта</p><p>- Выравнивание абзаца</p><p>- Отступы и табуляция абзаца</p><p>- Маркеры абзаца</p><p>- Ориентация абзаца</p>|
|Форматирование фигур|<p>Фигуры являются базовыми элементами слайда. Вы можете настраивать следующие свойства фигур:</p><p>- Позиция</p><p>- Размер</p><p>- Поворот</p><p>- Стили линий</p><p>- Заливка (включая сплошную, градиентную, узорную, текстурную и заливку изображением)</p><p>- Текст</p><p>- Изображение</p>|
