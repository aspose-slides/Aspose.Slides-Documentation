## **Поддерживаемые платформы**
Aspose.Slides for Python via Java — это независимый от платформы API. Его можно использовать на любой платформе (Windows, Linux, macOS и т.д.), где установлен Python 3.7 или выше. Требуется также JDK 8 или новее.

## **Форматы файлов и конвертации**
Aspose.Slides for Python via Java поддерживает большинство форматов документов PowerPoint. Он также позволяет экспортировать их в популярные форматы файлов, которые используют организации для обмена. Подробнее:

|**Функция**|**Описание**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java обеспечивает самую быструю обработку этого формата презентационных документов.|
|Конвертация PPT в PPTX|Aspose.Slides for Python via Java поддерживает конвертацию PPT в PPTX|
|Portable Document Format (PDF)|Вы можете экспортировать все поддерживаемые форматы файлов в документы Adobe Portable Document Format (PDF) одним методом.|
|XML Parser Specification (XPS)|Вы можете экспортировать все поддерживаемые форматы файлов в документы XML Parser Specification (XPS) одним методом.|
|Tagged Image File Format (TIFF)|Вы можете экспортировать все поддерживаемые форматы файлов презентаций в Tagged Image File Format (TIFF).|
|Конвертация PPTX в HTML|Aspose.Slides for Python via Java поддерживает конвертацию PresentationEx в формат HTML.|

## **Отображение презентаций**
Aspose.Slides for Python via Java поддерживает высококачественное рендеринг слайдов презентаций в различные графические форматы. Подробнее:

|**Функция**|**Описание**|
| :- | :- |
|Поддерживаемые Java форматы изображений|С помощью Aspose.Slides for Python via Java вы можете рендерить слайды презентаций и изображения на слайдах во все графические форматы, поддерживаемые Java, такие как TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Python via Java также предоставляет встроенные методы, позволяющие экспортировать слайды презентации в форматы Scalable Vector Graphics (SVG).|

## **Возможности содержимого**
Aspose.Slides for Python via Java позволяет получать доступ, изменять или создавать почти все элементы и содержимое документов презентаций. Подробнее:

|**Функция**|**Описание**|
| :- | :- |
|Слайды‑шаблоны|Слайды‑шаблоны определяют макет обычных слайдов. Aspose.Slides for Python via Java позволяет получить доступ к слайдам‑шаблонам презентаций и изменять их.|
|Обычные слайды|С помощью Aspose.Slides for Python via Java вы можете создавать новые слайды разных типов; вы также можете получить доступ к существующим слайдам в презентациях и изменять их.|
|Клонирование / копирование слайдов|В Aspose.Slides for Python via Java есть встроенные методы, позволяющие клонировать или копировать существующие слайды в пределах презентации. Вы также можете использовать скопированные и клонированные слайды из одной презентации в другую. Поскольку слайд наследует свой макет от слайда‑шаблона, встроенные методы клонирования автоматически копируют шаблон при клонировании.|
|Управление секциями слайдов|Методы для организации слайдов в разные секции внутри презентации.|
|Заполнители и текстовые заполнители|Вы можете получить доступ к заполнителям и текстовым заполнителям на слайде. Более того, вы можете создать слайд с текстовыми заполнителями с нуля, используя соответствующий метод.|
|Колонтитулы|Aspose.Slides for Python via Java упрощает работу с колонтитулами на слайдах.|
|Заметки на слайдах|С помощью Aspose.Slides for Python via Java вы можете получать доступ к заметкам, связанным со слайдом, изменять их и добавлять новые заметки.|
|Поиск фигуры|Вы также можете найти определённую фигуру на слайде, используя альтернативный текст, связанный с фигурой.|
|Фоны|Aspose.Slides for Python via Java позволяет работать с фонами, связанными с мастером или обычным слайдом в презентации.|
|Текстовые блоки|Текстовые блоки можно создавать с нуля. Вы можете получить доступ к существующим текстовым блокам. Вы также можете изменять их текст, не теряя оригинальное форматирование.|
|Прямоугольные фигуры|Вы можете создавать или изменять прямоугольные фигуры с помощью Aspose.Slides for Python via Java.|
|Фигуры полилинии|Вы можете создавать или изменять фигуры полилинии с помощью Aspose.Slides for Python via Java.|
|Эллипсные фигуры|Вы можете создавать или изменять фигуры эллипса с помощью Aspose.Slides for Python via Java.|
|Групповые фигуры|Aspose.Slides for Python via Java поддерживает групповые фигуры.|
|Автофигуры|Aspose.Slides for Python via Java поддерживает автофигуры.|
|SmartArt|Aspose.Slides for Python via Java предоставляет поддержку фигур SmartArt в MS PowerPoint.|
|Диаграммы|Aspose.Slides for Python via Java предоставляет поддержку диаграмм MSO в PowerPoint.|
|Сериализация фигур|Aspose.Slides for Python via Java поддерживает большое количество фигур. Когда Aspose.Slides for Python via Java не поддерживает какую‑то фигуру, вы можете использовать метод сериализации, позволяющий сериализовать эту фигуру с существующего слайда. |Кадры с изображениями|Вы можете управлять изображениями в кадрах с помощью Aspose.Slides for Python via Java.|
|Кадры с аудио|Вы можете связывать или внедрять аудиофайлы в аудио‑кадры на слайдах с помощью Aspose.Slides for Python via Java.|
|Кадры с видео|Вы можете работать с видеофайлами в видеокадрах. Aspose.Slides for Python via Java также поддерживает связанные и внедрённые видео.|
|OLE‑кадр|Вы можете управлять объектами OLE в OLE‑кадрах с помощью Aspose.Slides for Python via Java.|

|Элементы управления ActiveX|Поддержка элементов управления ActiveX.|
|VBA Macros|Поддержка управления макросами VBA внутри презентаций.|
|Текстовый кадр|Вы можете получить доступ к тексту любой фигуры через текстовый кадр, связанный с этой фигурой.|
|Сканирование текста|Вы можете сканировать текст в презентации на уровне всей презентации или отдельного слайда с помощью встроенных методов сканирования.|

| :- | :- |
|Форматирование текста|<p>В Aspose.Slides for Python via Java вы можете управлять текстами через текстовые кадры, связанные с фигурами. Таким образом, вы можете форматировать тексты, используя абзацы и фрагменты, связанные с текстовыми кадрами. Эти элементы текста можно форматировать с помощью Aspose.Slides for Python via Java.</p><p>- Тип шрифта</p><p>- Размер шрифта</p><p>- Цвет шрифта</p><p>- Оттенки шрифта</p><p>- Выравнивание абзаца</p><p>- Маркировка абзаца</p><p>- Ориентация абзаца</p>|
|Форматирование фигур|<p>В Aspose.Slides for Python via Java базовым элементом слайда является фигура.
