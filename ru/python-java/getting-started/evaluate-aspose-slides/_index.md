Вы можете скачать Aspose.Slides для Python через Java, чтобы оценить его возможности. Оценочный пакет идентичен лицензированному пакету. Чтобы использовать его без ограничений оценки, добавьте несколько строк кода в [применить лицензию](/slides/ru/python-java/licensing/).

Оценочная версия Aspose.Slides (используемая без лицензии) предоставляет полный функционал продукта, но имеет два ограничения:

- Она добавляет текстовое поле с водяным знаком оценки на каждый слайд каждой презентации при сохранении. Открытие презентации не добавляет его, но сохранение файла, уже содержащего водяной знак, добавляет ещё один.
- Текст, который ваш код читает, усекается до первых нескольких символов, за которыми следует уведомление об ограничении оценки. Это применимо к каждому слайду, к тексту, который ваш код только что установил, а также к тексту, загруженному из файла. Текст, который ваш код записывает, сохраняется полностью.
