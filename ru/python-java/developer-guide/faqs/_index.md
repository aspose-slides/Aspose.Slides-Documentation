## **Обзор**

В этом FAQ рассматриваются поддерживаемые форматы файлов, использование памяти при работе с большими презентациями, размеры и предпросмотр слайдов, извлечение текста, границы таблиц, размещение изображений и различия шрифтов при конвертации презентаций в PDF или изображения.

## **FAQ**

### **Поддерживаемые форматы файлов**

**Какие форматы файлов поддерживает Aspose.Slides for Python via Java?**

Смотрите [Supported File Formats](/slides/ru/python-java/supported-file-formats/) для получения информации о поддерживаемых форматах презентаций, документов и изображений, а также о их возможностях импорта и экспорта.

### **Исключения**

**Почему я получаю ошибку недостатка памяти при загрузке большой презентации с изображениями? Существует ли ограничение размера файла?**

Не существует единого порога размера файла, позволяющего предсказать, поместится ли презентация в памяти. Требования к памяти зависят от структуры презентации, распакованных изображений, эффектов и выполняемых вами операций. Изображения могут занимать значительно больше памяти, чем их сжатый размер на диске.

Aspose.Slides for Python via Java использует Java‑движок через JPype, поэтому куча JVM должна иметь достаточно места для обработки. Доступный объём оперативной памяти системы не указывает, сколько памяти может использовать JVM. Освобождайте презентации с помощью [Presentation.dispose](https://reference.aspose.com/slides/ru/python-java/aspose.slides/presentation/#dispose), когда заканчиваете их использовать. Для настройки окружения см. [System Requirements](/slides/ru/python-java/system-requirements/) и [Installation](/slides/ru/python-java/installation/).

### **Работа со слайдами**

**Могу ли я изменить размер слайдов в презентации?**

Да. Используйте [Presentation.getSlideSize](https://reference.aspose.com/slides/ru/python-java/aspose.slides/presentation/#getslidesize) для доступа к настройкам размера слайдов презентации, затем используйте [SlideSize.setSize](https://reference.aspose.com/slides/ru/python-java/aspose.slides/slidesize/#setsize) для установки размеров и выбора способа масштабирования существующего содержимого.

**Могут ли слайды в одной презентации иметь разные размеры?**

Нет. Документы Microsoft PowerPoint определяют размер слайда на уровне презентации, поэтому все слайды имеют одинаковые размеры.

**Могу ли я просмотреть слайд перед сохранением презентации?**

Да. Отрендерите слайд в изображение и отобразите его в приложении. Сохранять презентацию предварительно не требуется.

### **Работа с текстом**

**Могу ли я извлечь весь текст из презентации?**

Да. Класс [SlideUtil](https://reference.aspose.com/slides/ru/python-java/aspose.slides/slideutil/) предоставляет методы для получения текста из презентаций и отдельных слайдов.

**Почему размеры абзацев различаются в Windows и Linux?**

Размеры абзацев зависят от метрик шрифтов, используемых для отображения текста. Если шрифт отсутствует, заменяющий может иметь другую ширину символов и высоту строк, что изменяет переносы строк и размеры абзацев. Установите одинаковые шрифты на обеих системах или загрузите одинаковые файлы шрифтов с помощью [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/ru/python-java/aspose.slides/fontsloader/#loadexternalfonts) перед созданием или загрузкой презентаций.

### **Форматирование и изображения**

**Как задать цвет границы таблицы?**

Используйте [Cell.getCellFormat](https://reference.aspose.com/slides/ru/python-java/aspose.slides/cell/#getcellformat) для доступа к форматированию границ каждой ячейки и задайте цвет заливки для соответствующих границ. Чтобы изменить каждую границу, обработайте все ячейки. Чтобы изменить только контур таблицы, обновите только наружные границы ячеек по её краям.

**Какие единицы измерения используются для позиционирования и задания размеров изображений?**

Координаты и размеры фигур измеряются в пунктах. Один дюйм равен 72 пунктам; эти значения не являются пиксельными координатами.

### **Работа со шрифтами**

**Почему шрифты изменяются при конвертации презентации в PDF или изображения?**

Необходимые шрифты могут отсутствовать на машине, выполняющей конвертацию. Установите оригинальные шрифты или используйте [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/ru/python-java/aspose.slides/fontsloader/#loadexternalfonts) для добавления папок, содержащих их. Загружайте внешние шрифты перед созданием или открытием презентаций.

Следующий пример регистрирует папку шрифтов. Замените путь на существующую папку, содержащую ваши файлы шрифтов. Предполагается среда, описанная в [Installation](/slides/ru/python-java/installation/).

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontsLoader

font_folders = jpype.JArray(jpype.JString)(["path_to_a_folder_with_fonts"])
FontsLoader.loadExternalFonts(font_folders)
```

Пример оставляет JVM работающей для последующих операций с презентациями. Для использования в ноутбуках и ограничений жизненного цикла JVM см. [Limitations and API Differences](/slides/ru/python-java/limitations-and-api-differences/).
