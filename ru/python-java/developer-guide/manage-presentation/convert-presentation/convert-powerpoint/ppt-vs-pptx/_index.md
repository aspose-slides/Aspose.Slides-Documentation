## **Обзор**

PPT и PPTX — это форматы презентаций PowerPoint с разными внутренними структурами и поддержкой функций. PPT — это наследуемый бинарный формат, используемый в PowerPoint 97–2003. PPTX — это формат Office Open XML, введённый в PowerPoint 2007. В этой статье сравниваются форматы и показывается, как преобразовать файл PPT в PPTX с помощью Aspose.Slides for Python via Java.

## **Что такое PPT?**

[PPT](https://docs.fileformat.com/presentation/ppt/) хранит данные презентации в бинарной структуре. Чтение или изменение её содержимого требует программного обеспечения, которое понимает эту структуру. PPT полезен при обмене файлами со старыми версиями PowerPoint, но его способность представлять новые функции презентаций ограничена.

## **Что такое PPTX?**

[PPTX](https://docs.fileformat.com/presentation/pptx/) основан на Office Open XML. Файл PPTX представляет собой ZIP‑пакет, содержащий XML‑части, медиа‑файлы и отношения между этими частями. Такая структура упрощает изучение и расширение формата по сравнению с бинарным PPT. PowerPoint использует PPTX в качестве формата презентаций по умолчанию с версии PowerPoint 2007.

## **PPT против PPTX**

| Аспект | PPT | PPTX |
| --- | --- | --- |
| Внутренняя структура | Бинарные записи | ZIP‑пакет с XML и медиа |
| Типичные требования совместимости | Рабочие процессы PowerPoint 97–2003 | Рабочие процессы PowerPoint 2007 и новее |
| Новые функции презентаций | Ограниченная поддержка; некоторый контент может быть упрощён | Широкая поддержка новых объектов и эффектов |
| Рекомендуемое использование | Обмен с системами, требующими PPT | Новые презентации и продолжающееся редактирование |

Преобразование между форматами подразумевает больше, чем просто изменение расширения файла. Некоторые функции PPTX не имеют прямого эквивалента в PPT. PowerPoint может сохранять дополнительную информацию в специальных PPT‑записях, таких как данные MetroBlob, чтобы сохранить новое содержимое для последующего использования. Старые версии PowerPoint не могут отображать всё это содержимое, поэтому его сохранение не гарантирует, что презентация будет выглядеть или вести себя одинаково во всех средствах просмотра.

Aspose.Slides for Python via Java предоставляет единый API для загрузки и сохранения обоих форматов. Он поддерживает преобразование в обоих направлениях, но различия форматов и неподдерживаемые функции могут влиять на результат. По возможности используйте PPTX и проверяйте презентации, преобразованные в PPT, в целевом средстве просмотра.

## **Конвертация PPT в PPTX на Python**

Загрузите файл PPT с помощью класса [Presentation](https://reference.aspose.com/slides/ru/python-java/aspose.slides/presentation/), затем вызовите [Presentation.save](https://reference.aspose.com/slides/ru/python-java/aspose.slides/presentation/#save) с параметром [SaveFormat.Pptx](https://reference.aspose.com/slides/ru/python-java/aspose.slides/saveformat/#Pptx). Microsoft PowerPoint не требуется.

В примере при необходимости запускается виртуальная машина Java, а ресурсы презентации освобождаются в блоке `finally`. Замените пути ввода и вывода на свои собственные имена файлов.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat

# Загрузить устаревшую презентацию PPT.
presentation = Presentation("presentation.ppt")
try:
    # Сохранить презентацию в формате PPTX.
    presentation.save("presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

Больше примеров см. в разделе [Convert PPT to PPTX in Python](/slides/ru/python-java/convert-ppt-to-pptx/). Для обратного преобразования и вопросов совместимости см. [Convert PPTX to PPT in Python](/slides/ru/python-java/convert-pptx-to-ppt/).

## **FAQ**

**Есть ли смысл сохранять старые презентации в PPT, если они открываются без ошибок?**  
Вы можете сохранять PPT, если текущий рабочий процесс требует его. Для дальнейшего редактирования и новых функций рассмотрите [конвертацию в PPTX](/slides/ru/python-java/convert-ppt-to-pptx/). Сохраняйте оригинал, пока не проверите преобразованную презентацию.

**Какие презентации следует конвертировать в PPTX в первую очередь?**  
Отдавайте приоритет файлам, которые часто редактируются или рассылаются, содержат сложные [charts](/slides/ru/python-java/create-chart/) или [shapes](/slides/ru/python-java/shape-manipulations/), или вызывают предупреждения о совместимости при [открытии](/slides/ru/python-java/open-presentation/). Проверьте их внешний вид и поведение слайд‑шоу после конвертации.

**Сохранится ли защита паролем при конвертации между PPT и PPTX?**  
Не следует автоматически полагать, что защита выходного файла будет соответствовать исходному. Укажите необходимый пароль при загрузке зашифрованного файла, явно настройте защиту вывода и проверьте сохранённый файл. См. [Password-Protected Presentations](/slides/ru/python-java/password-protected-presentation/).

**Почему некоторые эффекты исчезают или упрощаются при конвертации PPTX в PPT?**  
PPT не может представить каждый новый объект, свойство или эффект. Некоторая информация может быть сохранена для последующего восстановления, но старые средства просмотра не могут отобразить её полностью. Сохраняйте оригинальный PPTX, если необходимо сохранить новые функции.
