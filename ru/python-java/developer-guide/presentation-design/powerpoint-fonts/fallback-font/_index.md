## **Введение**

Шрифты‑запасные (fallback) используются, когда указанный для текста шрифт установлен в системе, но не содержит нужного символа. В этом случае Aspose.Slides может использовать один из указанных запасных шрифтов для замены отсутствующего символа.

## **Запасной шрифт**

Aspose.Slides позволяет создавать запасные шрифты, добавлять их в коллекцию запасных шрифтов, задавать коллекцию запасных шрифтов для конкретной презентации, удалять запасные шрифты из презентации, указывать правила применения запасных шрифтов и выполнять другие связанные операции.

## **Часто задаваемые вопросы**

**Чем запасные шрифты отличаются от замены шрифтов?**

Запасные шрифты применяются к каждому символу или диапазону Unicode, когда основной шрифт не содержит конкретных глифов; они заполняют только отсутствующие символы. [Substitution](/slides/ru/python-java/font-substitution/) заменяет отсутствующий или недоступный шрифт для всего фрагмента текста или его части другим шрифтом. Их можно комбинировать, но область применения и логика выбора различаются.

**Сохраняются ли настройки запасных шрифтов внутри файла презентации?**

Нет. Конфигурация запасных шрифтов существует только во время обработки/рендеринга в библиотеке и не сериализуется в файл PPTX. Презентация не сохраняет ваши правила запасных шрифтов.

**Влияет ли запасной шрифт на элементы, созданные объектами PowerPoint (SmartArt, диаграммы, WordArt)?**

Да. Текст внутри этих объектов проходит тот же конвейер рендеринга, поэтому к нему применяются те же правила запасных шрифтов, что и к обычному тексту.
