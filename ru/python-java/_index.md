**Добро пожаловать в Aspose.Slides for Python via Java**

![Логотип продукта Aspose.Slides for Python via Java](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java — это библиотека классов, позволяющая вашим Python‑приложениям читать и записывать презентации PowerPoint® без необходимости иметь Microsoft PowerPoint®.

Ключевые функции включают управление текстом, фигурами, таблицами и анимацией; добавление аудио и видео на слайды; просмотр слайдов; а также экспорт слайдов в SVG, PDF и другие форматы.
