## **Поддержка лицензий**

Оценочная версия Aspose.Slides for Reporting Services — это тот же пакет, что и приобретённый, доступный со [страницы загрузки](https://releases.aspose.com/slides/ru/reportingservices/), и предоставляет те же функции. Без лицензии она работает в режиме оценки и вставляет водяной знак оценки в экспортированные презентации.

Оценочная версия становится лицензированной, когда вы копируете файл лицензии на сервер отчетов. При этом не требуется писать код.

Когда вы будете довольны оценкой, вы можете [приобрести лицензию](https://purchase.aspose.com/pricing/slides/ru/reporting-services/). Мы рекомендуем ознакомиться с различными типами подписки. Если у вас есть вопросы, свяжитесь с командой продаж Aspose.

## **Лицензирование в Aspose.Slides for Reporting Services**

* Лицензия — это простой текстовый XML‑файл, содержащий такие детали, как название продукта, количество разработчиков, на которых она выдана, дата окончания подписки и т.д.
* Файл лицензии подписан цифровой подписью, поэтому его нельзя изменять. Даже случайное добавление лишнего переноса строки в содержимое файла сделает его недействительным.

Для применения лицензии:

1. Скопируйте файл лицензии в папку *ReportServer\bin* каждого экземпляра сервера отчётов, где установлена *Aspose.Slides.ReportingServices.dll* — например, *C:\Program Files\Microsoft SQL Server Reporting Services\SSRS\ReportServer\bin*. [Установить вручную](/slides/ru/reportingservices/install-manually/#find-the-report-server-folder) перечисляет папки по умолчанию.
2. Убедитесь, что файл имеет одно из имён, которые ищет расширение: *Aspose.Slides.ReportingServices.lic*, *Aspose.Slides.Reporting.Services.lic*, *Aspose.Slides.Product.Family.lic*, *Aspose.Total.ReportingServices.lic*, *Aspose.Total.Reporting.Services.lic*, *Aspose.Total.Product.Family.lic* или *Aspose.Total.lic*.
3. Экспортируйте любой отчёт в формате презентации. Если в нём нет водяного знака, лицензия активна.

Расширение также ищет файл лицензии в *%ProgramData%\Aspose\Slides* (обычно *C:\ProgramData\Aspose\Slides*), поэтому одна копия там обслуживает каждый экземпляр на машине.

**Лицензированный режим**

Когда найден действительный файл лицензии, экспортированные презентации не содержат водяного знака оценки.

![Отчёт, экспортированный с лицензией: без водяного знака оценки](license-aspose-slides-for-reporting-services_2.png)

**Режим оценки**

Без лицензии Aspose.Slides for Reporting Services вставляет водяной знак оценки в экспортированные презентации.

![Отчёт, экспортированный в режиме оценки, с водяным знаком оценки](license-aspose-slides-for-reporting-services_1.png)
