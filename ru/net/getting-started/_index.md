## **Обзор**

Последовательно выполните четыре шага ниже. Каждый шаг указывает, что нужно сделать, и содержит ссылку на статью с подробностями. Оценка, лицензирование и поддержка рассматриваются после шагов.

## **Шаг 1: Проверьте системные требования**

Aspose.Slides for .NET работает на Windows, Linux и macOS. [Системные требования](/slides/ru/net/system-requirements/) перечисляет поддерживаемые операционные системы и версии .NET для каждого пакета, а также библиотеки, необходимые дополнительно для Linux.

## **Шаг 2: Установите пакет**

Aspose.Slides for .NET распространяется через NuGet в виде двух пакетов, предоставляющих одинаковые классы. Добавьте один из них в свой проект:

- В Windows: `dotnet add package Aspose.Slides.NET`
- В Linux и macOS: `dotnet add package Aspose.Slides.NET6.CrossPlatform`. В Linux сначала установите библиотеку `fontconfig`.
- На Alpine Linux и на Linux‑системах, где glibc старее 2.23 (x64) или 2.39 (ARM64): Aspose.Slides.NET с установленной библиотекой `libgdiplus`.

[Установка](/slides/ru/net/installation/) содержит команды для Linux, дополнительную настройку запуска, необходимую Aspose.Slides.NET в Linux, и шаги для Visual Studio.

## **Шаг 3: Создайте свою первую презентацию**

[Быстрый старт на главной странице Aspose.Slides for .NET](/slides/ru/net/#your-first-presentation) представляет собой полностью готовую консольную программу: она добавляет текстовое поле на слайд и сохраняет презентацию в файл PPTX. ## **Оценка и лицензирование**

Без лицензии Aspose.Slides работает в режиме оценки: к каждому сохраняемому слайду добавляется водяной знак, а текст, считанный из презентаций, обрезается.

- [Оценить Aspose.Slides](/slides/ru/net/evaluate-aspose-slides/) описывает ограничения оценки и способы получения временной лицензии.
- [Лицензирование](/slides/ru/net/licensing/) показывает, как применить лицензию из файла, потока или встроенного ресурса.
- [Лицензирование по использованию](/slides/ru/net/metered-licensing/) охватывает лицензии, оплачиваемые по факту использования.
- [Поддерживаемые форматы файлов](/slides/ru/net/supported-file-formats/) перечисляет форматы, которые Aspose.Slides может загружать и сохранять.

## **FAQ**

**Нужен ли установленный Microsoft PowerPoint?**

Нет. Aspose.Slides читает и записывает файлы презентаций самостоятельно и не использует PowerPoint, поэтому он также работает на серверах и в Linux.

**Какой пакет использовать для приложения .NET Framework?**

Aspose.Slides.NET. Он включает сборки для .NET Framework 4.6.2 и новее, .NET 6 и новее, а также .NET Standard 2.0. Aspose.Slides.NET6.CrossPlatform требует .NET 6 или новее.
