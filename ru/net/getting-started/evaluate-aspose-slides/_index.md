## **Aspose.Slides Evaluation**

Вы можете скачать Aspose.Slides для оценки. Оценочный пакет идентичен приобретённому пакету; он получает лицензию после того, как вы добавите несколько строк кода для применения лицензии.

Без лицензии Aspose.Slides предоставляет весь свой функционал в режиме оценки, но с двумя ограничениями: к каждому слайду каждой сохраняемой презентации добавляется текстовое поле с водяным знаком оценки, а текст, который ваш код читает из презентации, обрезается до первых нескольких символов с указанием ограничения оценки. Текст, который ваш код записывает, сохраняется полностью.

## **Install the Evaluation Package**

```bash
dotnet add package Aspose.Slides.NET
```

В Linux и macOS вместо этого можно использовать пакет Aspose.Slides.NET6.CrossPlatform; см. [Installation](/slides/ru/net/installation/).

## **Apply a License**

Это «несколько строк кода», которые преобразуют оценочный пакет в лицензированный. Применяйте
лицензию один раз при запуске приложения, до создания любого объекта `Presentation` — презентация,
созданная ранее, сохраняет водяной знак оценки.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` также принимает `Stream`, что является лучшим вариантом, когда лицензия поставляется как встроенный
ресурс, а не как файл на диске. Если путь неверен или срок действия файла истёк, вызов бросает исключение, поэтому
ошибки проявляются сразу при запуске, а не тихо переключаются в режим оценки.

После применения лицензии сохранённые презентации больше не содержат водяного знака, и текст читается полностью.

## **FAQ**

### Можно ли тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует совместно использовать один и тот же объект презентации [across threads](/slides/ru/net/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — автономный движок и не требует установки PowerPoint ни для оценки, ни для производства.

### Можно ли полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [Конвертеры](/slides/ru/net/convert-presentation/) работают; в выводе будет присутствовать водяной знак.

### Можно ли использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия снимает ограничения режима оценки и позволяет проводить тестирование без водяного знака.
