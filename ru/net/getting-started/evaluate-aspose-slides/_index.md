## **Оценка Aspose.Slides**

Вы можете легко скачать Aspose.Slides для оценки. Пакет оценки совпадает с приобретённым пакетом. Версия оценки просто становится лицензированной после того, как вы добавите несколько строк кода для применения лицензии.

Версия оценки Aspose.Slides (без указания лицензии) предоставляет полный набор функций продукта, но вставляет водяной знак оценки в верхнюю часть документа при открытии и сохранении. Кроме того, при извлечении текста из слайдов презентации вы ограничены одним слайдом.

## **Установить пакет оценки**

```bash
dotnet add package Aspose.Slides.NET
```

## **Применить лицензию**

Это «несколько строк кода», которые превращают пакет оценки в лицензированный. Примените лицензию один раз при запуске приложения, до создания любого объекта `Presentation` — презентация, созданная ранее, сохраняет водяной знак оценки.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` также принимает `Stream`, что является лучшим вариантом, когда лицензия поставляется как встроенный ресурс, а не как файл на диске. Если путь неверен или файл истёк, вызов бросает исключение, поэтому ошибки проявляются сразу при запуске, а не тихо переключаются в режим оценки.

После применения лицензии водяной знак исчезает, и ограничение на извлечение текста с одного слайда снимается.

## **Часто задаваемые вопросы**

### Могу ли я тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует делиться одним и тем же объектом презентации [между потоками](/slides/ru/net/multithreading/). Режим оценки на это не влияет.

### Нужна ли установка Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — самостоятельный движок и не требует установки PowerPoint ни для оценки, ни для эксплуатации.

### Могу ли я полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [Конвертеры](/slides/ru/net/convert-presentation/) работают; вывод будет содержать водяной знак.

### Могу ли я использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30-дневная временная лицензия устраняет ограничения режима оценки и позволяет тестировать без водяного знака.
