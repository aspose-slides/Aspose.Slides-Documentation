## **Оценка Aspose.Slides**

Вы можете загрузить Aspose.Slides для оценки. Пакет оценки такой же, как и приобретённый пакет; он становится лицензированным после того, как вы добавите несколько строк кода для применения лицензии.

Без лицензии Aspose.Slides предоставляет полную функциональность в режиме оценки, но с двумя ограничениями: он добавляет текстовое поле с водяным знаком оценки на каждый слайд каждой сохраняемой презентации, а текст, который ваш код читает из презентации, усекается до первых нескольких символов, после чего следует сообщение об ограничении оценки. Текст, который ваш код записывает, сохраняется полностью.

## **Установить пакет оценки**

```bash
dotnet add package Aspose.Slides.NET
```

В Linux и macOS вы можете использовать пакет Aspose.Slides.NET6.CrossPlatform вместо него; см. [Установка](/slides/ru/net/installation/).

## **Применить лицензию**

Это «несколько строк кода», которые превращают пакет оценки в лицензированный. Применяйте лицензию один раз при запуске приложения, до создания любого объекта `Presentation` — презентация, созданная ранее, сохраняет водяной знак оценки.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` также принимает `Stream`, что является лучшим вариантом, когда лицензия поставляется как встроенный ресурс, а не как файл на диске. Если путь неверен или файл истёк, вызов бросает исключение, поэтому ошибки проявляются сразу при запуске, а не тихо переключаются в режим оценки.

После применения лицензии сохранённые презентации больше не содержат водяного знака, и текст читается полностью.

## **Часто задаваемые вопросы**

### Могу ли я тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует использовать один и тот же объект презентации [между потоками](/slides/ru/net/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — это автономный движок и не требует установки PowerPoint ни для оценки, ни для эксплуатации.

### Могу ли я полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [Конвертеры](/slides/ru/net/convert-presentation/) работают; вывод будет содержать водяной знак.

### Могу ли я использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия устраняет ограничения режима оценки и позволяет тестировать без водяного знака.
