## **Обзор**

В этой статье объясняется, когда разработчики могут выбрать Open XML SDK или Aspose.Slides для работы с документами презентаций. Описывается Open XML SDK как библиотеку для манипулирования пакетами OOXML и их базовыми XML‑элементами, тогда как Aspose.Slides представлена как библиотека обработки презентаций с высокоуровневой объектной моделью и поддержкой множества задач, связанных с PowerPoint.

Статья сравнивает оба варианта по поддерживаемым форматам, программной модели, возможностям рендеринга и печати, поддержке платформ и типичным сценариям использования. Также уточняется, что Open XML SDK может подойти для базовых операций с PPTX или прямого доступа к элементам OOXML, тогда как Aspose.Slides более уместен для сложных задач презентаций, таких как работа с несколькими форматами PowerPoint, копирование или клонирование фигур, замена текста, применение анимаций и конвертация презентаций в PDF, TIFF или XPS.

## **Что такое Open XML SDK?**
Иногда мы получаем вопрос: *«Почему мы должны использовать продукты Aspose, а не бесплатный Open XML SDK?»* 

Мы легко отвечаем на этот вопрос, сравнивая функции и возможности. 

Согласно [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK определяется так: 

> "Open XML SDK 2.0 упрощает задачу манипулирования пакетами Open XML и базовыми элементами схемы Open XML внутри пакета. Open XML SDK 2.0 инкапсулирует многие распространённые задачи, которые разработчики выполняют с пакетами Open XML, так что вы можете выполнять сложные операции с помощью всего нескольких строк кода. Документы OOXML по сути являются архивированными XML‑файлами, а Open XML SDK ‑ это набор классов, позволяющих работать с содержимым документов OOXML типобезопасным способом. Вместо разархивирования файла для извлечения XML, загрузки этого XML в DOM‑дерево и работы с элементами и атрибутами напрямую, Open XML SDK предоставляет классы для выполнения этих действий."

## **Что такое Aspose.Slides?**
Aspose.Slides — это библиотека классов, позволяющая приложениям выполнять следующие задачи обработки презентаций: 

- Программирование с использованием объектной модели презентации.  
- Высококачественное преобразование всех популярных поддерживаемых форматов PowerPoint, включая конвертацию в PDF, XPS, TIFF и печать.  
- Создание миниатюр слайдов в известных форматах, таких как PNG, JPEG и BMP, а также экспорт слайдов в SVG.  
- Создание презентаций с нуля или комбинирование элементов из одного или нескольких документов.  
- Добавление анимаций, OLE‑фреймов, таблиц, создание и управление диаграммами.  
- Управление (полный контроль) и форматирование текста на уровнях TextFrames, Paragraphs и Portions.  

  Подробнее о доступных функциях см. страницу [Aspose.Slides Features](/slides/ru/net/product-overview/).

## **Заключение**
Open XML SDK и Aspose.Slides не являются прямыми конкурентами, поскольку они решают существенно разные задачи и ориентированы на разную аудиторию. 

{{% alert color="info" %}} 

Open XML SDK — это библиотека классов, предоставляющая типобезопасный способ работы с документами OOXML, тогда как Aspose.Slides — это чрезвычайно полезная библиотека обработки презентаций, обеспечивающая отличную поддержку почти всех форматов файлов Microsoft PowerPoint. 

{{% /alert %}} 

Если ваш рабочий процесс сводится к базовым программным операциям с документом PPTX, то Open XML SDK может стать хорошим выбором. С Open XML SDK вы сможете выполнять простые задачи, такие как создание простого PPTX‑документа, удаление комментариев, заголовков/нижних колонтитулов, извлечение изображений и др. Некоторые задачи можно выполнить только с помощью Open XML SDK, но не с Aspose.Slides. Например, если необходимо напрямую работать с XML‑элементами и атрибутами документа OOXML, следует использовать Open XML SDK. 

Если же требуется выполнять сложные задачи с документами — например, задачи из списка ниже — то Aspose.Slides является лучшим вариантом. 

- Операции с более старыми форматами PowerPoint (и с PPTX).  
- Копирование или клонирование фигур внутри слайдов с сохранением сочетаний объектов, стилей и других элементов форматирования.  
- Замена форматированного или неформатированного текста.  
- Применение анимаций и использование соединителей между фигурами.  
- Конвертация документа в PDF, TIFF или XPS с результатом, идентичным конвертации в Microsoft PowerPoint.  
- Разработка приложений .NET или Java как для настольных, так и для веб‑сред.
