## **Обзор**

В этой статье объясняется, когда разработчики могут выбрать Open XML SDK или Aspose.Slides для работы с презентационными документами. Описывается Open XML SDK как библиотеку для манипулирования пакетами OOXML и их базовыми XML‑элементами, тогда как Aspose.Slides представляется как библиотека обработки презентаций с объектной моделью высокого уровня и поддержкой множества задач, связанных с PowerPoint.

Статья сравнивает оба варианта по поддерживаемым форматам, программной модели, возможностям рендеринга и печати, поддерживаемым платформам и типичным сценариям использования. Также уточняется, что Open XML SDK может подойти для базовых операций с PPTX или прямого доступа к элементам OOXML, тогда как Aspose.Slides более уместен для сложных задач, таких как работа с несколькими форматами PowerPoint, копирование или клонирование фигур, замена текста, применение анимаций и конвертация презентаций в PDF, TIFF или XPS.

## **Что такое Open XML SDK?**
Иногда мы получаем вопрос: *Почему стоит использовать продукты Aspose, а не бесплатный Open XML SDK?* 

Мы легко отвечаем на этот вопрос, опираясь на функции и возможности. 

Согласно [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK определяется так: 

> "Open XML SDK 2.0 упрощает задачу манипулирования пакетами Open XML и базовыми элементами схемы Open XML внутри пакета. Open XML SDK 2.0 инкапсулирует многие распространённые задачи, которые разработчики выполняют с пакетами Open XML, так что вы можете выполнять сложные операции, написав всего несколько строк кода. Документы OOXML по сути являются заархивированными XML‑файлами, а Open XML SDK — это набор классов, позволяющих работать с содержимым OOXML‑документов типобезопасным способом. Вместо того чтобы распаковывать файл для извлечения XML, загружать этот XML в дерево DOM и работать напрямую с элементами и атрибутами XML, Open XML SDK предоставляет классы для выполнения этих действий."

## **Что такое Aspose.Slides?**
Aspose.Slides — это библиотека классов, позволяющая приложениям выполнять следующие задачи обработки презентаций: 

- Программирование с использованием объектной модели презентации.  
- Высококачественное преобразование всех популярных поддерживаемых форматов PowerPoint, включая конвертацию в PDF, XPS, TIFF и печать.  
- Генерация миниатюр слайдов в широко известных форматах, таких как PNG, JPEG и BMP, а также экспорт слайдов в SVG.  
- Создание презентаций с нуля или комбинирование элементов из одного или нескольких документов.  
- Добавление анимаций, OLE‑фреймов, таблиц, создание и управление диаграммами.  
- Управление (расширенный контроль) и настройка форматирования текста на уровнях TextFrames, Paragraphs и Portions.  

  Для получения дополнительных сведений о доступных функциях см. страницу [Aspose.Slides Features](/slides/ru/net/product-overview/).

## **Заключение**
Open XML SDK и Aspose.Slides не конкурируют напрямую, поскольку они решают существенно разные задачи и ориентированы на разные аудитории. 

{{% alert color="primary" %}} 

Open XML SDK — это библиотека классов, предоставляющая типобезопасный способ работы с OOXML‑документами, тогда как Aspose.Slides — чрезвычайно полезная библиотека обработки презентаций, обеспечивающая отличную поддержку почти всех форматов файлов Microsoft PowerPoint. 

{{% /alert %}} 

Если ваш рабочий процесс представляет собой базовую программную операцию с документом PPTX, то Open XML SDK может быть хорошим выбором. С Open XML SDK вы сможете выполнять простые задачи, такие как создание простого PPTX‑документа, удаление комментариев, колонтитулов, извлечение изображений и т.д. Некоторые задачи могут быть выполнены с помощью Open XML SDK, но невозможны в Aspose.Slides. Например, если требуется прямой доступ к XML‑элементам и атрибутам OOXML‑документа, следует использовать Open XML SDK. 

Если необходимо выполнять сложные задачи с документами — такие, как перечисленные ниже — тогда Aspose.Slides это ваш лучший вариант. 

- Операции с более старыми форматами PowerPoint (и PPTX тоже).  
- Копирование или клонирование фигур внутри слайдов способом, комбинирующим объекты, стили и другие элементы форматирования надлежащим образом.  
- Замена форматированного или неформатированного текста.  
- Применение анимаций и использование соединителей с фигурами.  
- Конвертация документа в PDF, TIFF или XPS так, как если бы конвертацию выполнил Microsoft PowerPoint.  
- Разработка .NET или Java‑приложения как для настольных, так и для веб‑сред.
