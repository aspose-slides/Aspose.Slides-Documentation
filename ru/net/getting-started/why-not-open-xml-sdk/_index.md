## **Обзор**

В этой статье объясняется, когда разработчики могут выбрать Open XML SDK или Aspose.Slides для работы с презентационными документами. Описывается Open XML SDK как библиотеку для манипулирования пакетами OOXML и их базовыми XML‑элементами, тогда как Aspose.Slides представлена как библиотека обработки презентаций с высокоуровневой объектной моделью и поддержкой множества задач, связанных с PowerPoint.

Статья сравнивает оба варианта по поддерживаемым форматам, программной модели, рендерингу, поддержке платформ и типичным сценариям использования. Также уточняется, что Open XML SDK может подойти для базовых операций с PPTX или прямого доступа к элементам OOXML, тогда как Aspose.Slides более уместна для сложных задач, таких как работа с несколькими форматами PowerPoint, копирование или клонирование фигур, замена текста, применение анимаций и конвертация презентаций в PDF, TIFF или XPS.

## **Что такое Open XML SDK?**
Иногда мы получаем такой вопрос: *Почему стоит использовать продукты Aspose, а не бесплатный Open XML SDK?* 

Мы легко отвечаем на него, опираясь на функции и возможности. 

Согласно [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK определяется так: 

> "Open XML SDK 2.0 упрощает задачу манипулирования пакетами Open XML и базовыми элементами схемы Open XML внутри пакета. Open XML SDK 2.0 инкапсулирует многие общие задачи, которые разработчики выполняют с пакетами Open XML, так что вы можете выполнять сложные операции, написав лишь несколько строк кода. Документы OOXML по сути являются zip‑файлами с XML, а Open XML SDK — это набор классов, позволяющих работать с содержимым документов OOXML типобезопасным способом. Вместо того чтобы распаковывать файл для извлечения XML, загружать этот XML в дерево DOM и работать напрямую с элементами и атрибутами XML, Open XML SDK предоставляет классы для выполнения этих действий."

## **Что такое Aspose.Slides?**
Aspose.Slides — это библиотека классов, позволяющая приложениям выполнять следующие задачи обработки презентаций: 

- Программирование с помощью объектной модели презентации.  
- Высококачественное преобразование всех популярных поддерживаемых форматов PowerPoint, включая конвертацию в PDF, XPS и TIFF.  
- Генерация миниатюр слайдов в известных форматах, таких как PNG, JPEG и BMP, а также экспорт слайдов в SVG.  
- Создание презентаций с нуля или путем комбинирования элементов из одного или нескольких документов.  
- Добавление анимаций, OLE‑фреймов, таблиц, создание и управление диаграммами.  
- Управление (полный контроль) и изменение форматирования текста на уровнях TextFrames, Paragraphs и Portions.  

  Подробнее о доступных возможностях см. страницу [Aspose.Slides Features](/slides/ru/net/product-overview/).

## **Заключение**
Open XML SDK и Aspose.Slides не конкурируют напрямую, потому что они решают существенно разные задачи и ориентированы на разные аудитории. 

{{% alert color="info" %}} 

Open XML SDK — это библиотека классов, предоставляющая типобезопасный способ работы с документами OOXML, тогда как Aspose.Slides — невероятно полезная библиотека обработки презентаций, обеспечивающая отличную поддержку почти всех форматов файлов Microsoft PowerPoint. 

{{% /alert %}} 

Если ваш рабочий процесс ограничивается базовыми программными операциями над документом PPTX, то Open XML SDK может стать хорошим выбором. С Open XML SDK вы сможете выполнять простые задачи, такие как создание простого PPTX‑документа, удаление комментариев, заголовков/нижних колонтитулов, извлечение изображений и др. Некоторые задачи можно выполнить с помощью Open XML SDK, но нельзя — с Aspose.Slides. Например, если требуется прямой доступ к XML‑элементам и атрибутам документа OOXML, следует использовать Open XML SDK. 

Если же вам необходимо выполнять сложные задачи над документами — такие как перечисленные ниже — то Aspose.Slides это ваш лучший вариант. 

- Операции с более старыми форматами PowerPoint (и PPTX тоже).  
- Копирование или клонирование фигур внутри слайдов способом, комбинирующим объекты, стили и другие элементы форматирования надлежащим образом.  
- Замена отформатированного или неотформатированного текста.  
- Применение анимаций и использование соединителей с фигурами.  
- Конвертация документа в PDF, TIFF или XPS с результатом, как будто преобразование выполнил Microsoft PowerPoint.  
- Разработка .NET или Java‑приложения как для настольных, так и для веб‑сред.
