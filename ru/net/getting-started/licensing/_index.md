## **Обзор**

Aspose.Slides можно использовать в режиме оценки или с действующей лицензией. Версия оценки предоставляет тот же набор функций, что и лицензированная версия, но добавляет водяной знак оценки на каждый слайд каждой презентации, которую она сохраняет, и обрезает текст, который ваш код считывает из презентаций.

В этой статье объясняется, как работает лицензирование в Aspose.Slides и как применить лицензию перед использованием библиотеки. Лицензию можно загрузить из файла, потока или встраиваемого ресурса с помощью класса `License`. В статье также показано, как проверить, правильно ли применена лицензия.

* Оценочная версия (без указания лицензии) предоставляет полный функционал продукта, но добавляет текстовое поле с водяным знаком оценки на каждый слайд каждой презентации, которую она сохраняет.

## **Лицензирование в Aspose.Slides**
* Оценочная версия становится лицензированной после покупки лицензии и добавления пары строк кода (для применения лицензии).
* Лицензия представляет собой простой XML‑файл, содержащий такие детали, как название продукта, количество разработчиков, которым она выдана, дата истечения подписки и т.д.
* Файл лицензии подписан цифровой подписью, поэтому его нельзя изменять. Даже случайное добавление лишнего перевода строки сделает файл недействительным.
* Aspose.Slides for .NET обычно ищет лицензию в следующих местах:
  * Явный путь
  * Папка, содержащая DLL компонента (включена в Aspose.Slides)
  * Папка, содержащая сборку, которая вызвала DLL компонента (включена в Aspose.Slides)
  * Папка, содержащая исполняемую сборку (ваш .exe)
  * Встроенный ресурс в сборке, которая вызвала DLL компонента (включена в Aspose.Slides).
* Чтобы избавиться от ограничений оценочной версии, необходимо установить лицензию перед использованием Aspose.Slides. Лицензию нужно установить только один раз для каждого приложения или процесса.

Возможно, вам будет интересно посмотреть [Metered Licensing](/slides/ru/net/metered-licensing/).

## **Применение лицензии**
Лицензия может быть загружена из **файла**, **потока** или **встроенного ресурса**. 

{{% alert color="info" title="Note" %}}

Aspose.Slides предоставляет класс [License](https://reference.aspose.com/slides/ru/net/aspose.slides/license) для операций с лицензиями.

{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}

Новые лицензии могут активировать Aspose.Slides только начиная с версии 21.4 и новее. Более ранние версии используют другую систему лицензирования и не распознают эти лицензии.

{{% /alert %}}

### **Файл**
Самый простой способ установить лицензию — разместить файл лицензии в той же папке, где находится DLL компонента (включена в Aspose.Slides), и указать только имя файла без пути.

Этот C#‑код показывает, как установить файл лицензии:

``` csharp
// Создает экземпляр класса License 
Aspose.Slides.License license = new Aspose.Slides.License();

// Устанавливает путь к файлу лицензии
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" title="Warning" %}}

Если вы поместите файл лицензии в другую директорию, при вызове метода [SetLicense](https://reference.aspose.com/slides/ru/net/aspose.slides/license/setlicense/#setlicense_1) имя файла лицензии в конце указанного пути должно совпадать с именем вашего файла лицензии.

Например, вы можете переименовать файл лицензии в *Aspose.Slides.lic.xml*. Затем в коде вам нужно передать путь к файлу (заканчивающийся на *Aspose.Slides.lic.xml*) методу [SetLicense](https://reference.aspose.com/slides/ru/net/aspose.slides/license/setlicense/#setlicense_1).

{{% /alert %}}

### **Поток**
Вы можете загрузить лицензию из потока. Этот C#‑код показывает, как применить лицензию из потока:

``` csharp
// Создает экземпляр класса License
Aspose.Slides.License license = new Aspose.Slides.License();

// Открывает файл лицензии как поток
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// Устанавливает лицензию через поток
license.SetLicense(licenseStream);
```

### **Встроенный ресурс**
Вы можете упаковать лицензию вместе с приложением (чтобы не потерять её), добавив лицензию как встроенный ресурс в одну из сборок, вызывающих DLL компонента (включена в Aspose.Slides). 

Это способ добавить файл лицензии как встроенный ресурс:

1. В Visual Studio добавьте файл лицензии (.lic) в проект следующим образом: **File** > **Add Existing Item** > **Add**. 
2. Выберите файл в **Solution Explorer**.
3. В окне **Properties** установите **Build Action** в значение **Embedded Resource**.
4. Чтобы получить доступ к лицензии, встроенной в сборку, добавьте файл лицензии как встроенный ресурс в проект, а затем передайте имя файла лицензии методу `SetLicense`. 


Класс `License` автоматически ищет файл лицензии во встроенных ресурсах. Вам не нужно вызывать методы `GetExecutingAssembly` и `GetManifestResourceStream` класса `System.Reflection.Assembly` в Microsoft .NET Framework.

Этот C#‑код показывает, как установить лицензию как встроенный ресурс:

``` csharp
// Создает экземпляр класса License
Aspose.Slides.License license = new Aspose.Slides.License();

// Передает имя файла лицензии, встроенное в сборку
license.SetLicense("Aspose.Slides.lic");
```

## **Проверка лицензии**

Чтобы убедиться, что лицензия установлена правильно, вы можете её проверить. Этот C#‑код показывает, как проверить лицензию:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **Безопасность потоков**

{{% alert color="warning" title="Warning" %}}

Метод [license.SetLicense](https://reference.aspose.com/slides/ru/net/aspose.slides/license/setlicense/) не является потокобезопасным. Если этот метод вызывается одновременно из многих потоков, рекомендуется использовать примитивы синхронизации (например, lock), чтобы избежать проблем. 

{{% /alert %}}

## **FAQ**

### Можно ли применить лицензию в полностью автономной среде (без доступа к интернету)?

Да. Проверка лицензии выполняется локально с использованием файла лицензии; подключение к интернету не требуется.

### Что происходит после истечения годовой подписки? Прекратит ли библиотека работу?

Нет. Лицензия является бессрочной: вы можете продолжать использовать версии, выпущенные до даты окончания подписки; однако вы не сможете использовать более новые версии без продления подписки.
