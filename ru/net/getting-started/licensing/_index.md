## **Обзор**

Aspose.Slides можно использовать в режиме оценки или с действующей лицензией. Оценочная версия предоставляет тот же набор функций, что и лицензированная, но добавляет водяной знак оценки при открытии или сохранении презентаций и ограничивает извлечение текста одной слайдом.

В этой статье объясняется, как работает лицензирование в Aspose.Slides и как применить лицензию перед использованием библиотеки. Лицензию можно загрузить из файла, потока или встроенного ресурса с помощью класса `License`. Статья также показывает, как проверить, была ли лицензия применена корректно.

## **Лицензирование в Aspose.Slides**
* Оценочная версия становится лицензированной после покупки лицензии и добавления пары строк кода (для применения лицензии).
* Лицензия — это обычный XML‑файл, содержащий такие данные, как название продукта, количество разработчиков, на которых она распространяется, дата истечения подписки и т.д. 
* Файл лицензии подписан цифровой подписью, поэтому его нельзя изменять. Даже случайное добавление лишнего перевода строки сделает её недействительной.
* Aspose.Slides for .NET обычно ищет лицензию в следующих местах:
  * Явный путь
  * Папка, содержащая DLL компонента (включена в Aspose.Slides)
  * Папка, содержащая сборку, которая вызвала DLL компонента (включена в Aspose.Slides)
  * Папка, содержащая исполняемую сборку (ваш .exe)
  * Встроенный ресурс в сборке, которая вызвала DLL компонента (включена в Aspose.Slides).
* Чтобы избавиться от ограничений оценочной версии, необходимо установить лицензию до использования Aspose.Slides. Лицензию нужно установить только один раз за приложение или процесс.

{{% alert color="info" %}} 

Возможно, вам будет интересен раздел [Metered Licensing](https://docs.aspose.com/slides/ru/net/metered-licensing/).

{{% /alert %}} 


## **Применение лицензии**
Лицензию можно загрузить из **файла**, **потока** или **встроенного ресурса**. 

{{% alert color="info" %}}

Aspose.Slides предоставляет класс [License](https://reference.aspose.com/slides/ru/net/aspose.slides/license) для операций с лицензиями.

{{% /alert %}} 

{{% alert color="warning" %}} 

Новые лицензии могут активировать Aspose.Slides только начиная с версии 21.4 и выше. Ранние версии используют другую систему лицензирования и не распознают эти лицензии.

{{% /alert %}}

### **Файл**
Самый простой способ установки лицензии требует разместить файл лицензии в той же папке, где находится DLL компонента (включена в Aspose.Slides), и указать только имя файла без пути.

Этот C#‑код показывает, как установить файл лицензии:

``` csharp
// Создает экземпляр класса License 
Aspose.Slides.License license = new Aspose.Slides.License();

// Устанавливает путь к файлу лицензии
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" %}} 

Если вы поместите файл лицензии в другую директорию, при вызове метода [SetLicense](https://reference.aspose.com/slides/ru/net/aspose.slides/license/setlicense/#setlicense_1) имя файла лицензии в конце указанного явного пути должно совпадать с именем вашего файла лицензии.

Например, вы можете переименовать файл лицензии в *Aspose.Slides.lic.xml*. Тогда в коде нужно передать путь к файлу (оканчивающийся на *Aspose.Slides.lic.xml*) в метод [SetLicense](https://reference.aspose.com/slides/ru/net/aspose.slides/license/setlicense/#setlicense_1).

{{% /alert %}}

### **Поток**
Лицензия может быть загружена из потока. Этот C#‑код показывает, как применить лицензию из потока:

``` csharp
// Создает экземпляр класса License
Aspose.Slides.License license = new Aspose.Slides.License();

// Открывает файл лицензии как поток
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// Устанавливает лицензию через поток
license.SetLicense(licenseStream);
```

### **Встроенный ресурс**
Вы можете упаковать лицензию вместе с приложением (чтобы не потерять её), добавив файл лицензии как встроенный ресурс в одну из сборок, вызывающих DLL компонента (включена в Aspose.Slides). 

Вот как добавить файл лицензии как встроенный ресурс:

1. В Visual Studio добавьте файл лицензии (.lic) в проект так: **File** > **Add Existing Item** > **Add**. 
2. Выберите файл в **Solution Explorer**.
3. В окне **Properties** установите **Build Action** в **Embedded Resource**.
4. Чтобы получить доступ к лицензии, встроенной в сборку, добавьте файл лицензии как встроенный ресурс в проект, а затем передайте имя файла лицензии в метод `SetLicense`. 


Класс `License` автоматически ищет файл лицензии во встроенных ресурсах. Вам не нужно вызывать методы `GetExecutingAssembly` и `GetManifestResourceStream` класса `System.Reflection.Assembly` в Microsoft .NET Framework.

Этот C#‑код показывает, как установить лицензию как встроенный ресурс:

``` csharp
// Создает экземпляр класса License
Aspose.Slides.License license = new Aspose.Slides.License();

// Передает имя файла лицензии, встроенного в сборку
license.SetLicense("Aspose.Slides.lic");
```

## **Проверка лицензии**

Чтобы убедиться, что лицензия установлена правильно, её можно проверить. Этот C#‑код демонстрирует проверку лицензии:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **Потокобезопасность**

{{% alert title="Note" color="warning" %}} 

Метод [license.SetLicense](https://reference.aspose.com/slides/ru/net/aspose.slides/license/setlicense/) не является потокобезопасным. Если его нужно вызывать одновременно из нескольких потоков, рекомендуется использовать примитивы синхронизации (например, lock), чтобы избежать проблем. 

{{% /alert %}}

## **FAQ**

### Можно ли применить лицензию в полностью офлайн‑среде (без доступа к интернету)?

Да. Проверка лицензии выполняется локально с использованием файла лицензии; подключение к интернету не требуется.

### Что происходит после истечения годовой подписки? Перестанет ли работать библиотека?

Нет. Лицензия perpetual: вы можете продолжать использовать версии, выпущенные до даты окончания подписки; вы просто не сможете пользоваться новыми выпусками без продления подписки.
