## **Введение**

В PowerPoint 2019 компания Microsoft представила параметр **Always Open Read-Only** как одну из возможностей, которые пользователи могут использовать для защиты своих презентаций. Вы можете захотеть использовать этот параметр только для чтения, чтобы защитить презентацию, когда

- Вы хотите предотвратить случайные изменения и сохранить содержимое вашей презентации в безопасности. 
- Вы хотите предупредить людей, что предоставленная вами презентация является финальной версией. 

После того как вы выберете параметр **Always Open Read-Only** для презентации, при её открытии пользователи увидят рекомендацию **Read-Only** и могут увидеть сообщение следующего вида: *To prevent accidental changes, the author has set this file to open as read-only.*

Рекомендация **Read-Only** — это простое, но эффективное средство, отпугивающее редактирование, поскольку пользователи должны выполнить действие, чтобы удалить её, прежде чем им будет разрешено редактировать презентацию. Если вы не хотите, чтобы пользователи вносили изменения в презентацию, и хотите сообщить им об этом вежливым способом, то рекомендация **Read-Only** может быть хорошим вариантом для вас. 

> Если презентация с защитой **Read-Only** открывается в более старой версии Microsoft PowerPoint, которая не поддерживает недавно введённую функцию, рекомендация **Read-Only** игнорируется (презентация открывается в обычном режиме).

## **Применение режима только для чтения**

Aspose.Slides for .NET позволяет установить презентацию в режим **Read-Only**, что означает, что пользователи (после открытия презентации) увидят рекомендацию **Read-Only**. Ниже приводится пример кода, показывающий, как установить презентацию в режим **Read-Only** на C# с использованием Aspose.Slides:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation())
{
    pres.ProtectionManager.ReadOnlyRecommended = true;
    pres.Save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
}
```

{{% alert color="info" %}} 

**Примечание**: Рекомендация **Read-Only** предназначена просто для того, чтобы отпугнуть редактирование или предотвратить случайные изменения PowerPoint‑презентации. Если мотивированный пользователь — знающий, что делает — решит отредактировать вашу презентацию, он легко снимет параметр только для чтения. Если вам действительно нужно предотвратить неавторизованное редактирование, лучше воспользоваться [более строгими мерами защиты, включающими шифрование и пароли](https://docs.aspose.com/slides/ru/net/password-protected-presentation/).

## **Часто задаваемые вопросы**

### Чем 'Read-Only recommended' отличается от полной защиты паролем?

`Read-Only recommended` лишь отображает предложение открыть файл в режиме только для чтения и легко обходится. [Защита паролем](/slides/ru/net/password-protected-presentation/) действительно ограничивает открытие или редактирование и подходит, когда требуются настоящие средства безопасности.

### Можно ли комбинировать 'Read-Only recommended' с водяными знаками для дополнительного отпугивания правок?

Да. Рекомендацию можно сочетать с [водяными знаками](/slides/ru/net/watermark/) в качестве визуального отпугивающего средства; они являются отдельными механизмами и хорошо работают вместе.

### Может ли макрос или внешнее средство всё ещё изменять файл, когда рекомендация включена?

Да. Рекомендация не блокирует программные изменения. Чтобы предотвратить автоматические правки, используйте [пароли и шифрование](/slides/ru/net/password-protected-presentation/).

### Как 'Read-Only recommended' соотносится с флагами 'IsEncrypted' и 'IsWriteProtected'?

Это разные сигналы. `Read-Only recommended` — мягкое, необязательное предложение; [IsWriteProtected](https://reference.aspose.com/slides/ru/net/aspose.slides/protectionmanager/iswriteprotected/) и [IsEncrypted](https://reference.aspose.com/slides/ru/net/aspose.slides/protectionmanager/isencrypted/) указывают на реальные ограничения записи или чтения, зависящие от паролей или шифрования.
