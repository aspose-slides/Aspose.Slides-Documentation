## **Обзор**

Этот раздел не содержит списка открытых проблем в текущей версии. Он содержит две страницы:

- [Заполнитель предварительного просмотра объекта при добавлении OleObjectFrame](/slides/ru/net/object-preview-issue-when-adding-oleobjectframe/) объясняет, почему OLE‑объект, добавленный с помощью Aspose.Slides, отображает изображение «EMBEDDED OLE OBJECT», пока его превью не будет обновлено, и как установить собственное изображение превью. Это поведение, запланированное в текущей версии.
- [Известные проблемы в Aspose.Slides для .NET 14.1.0 (исторические)](/slides/ru/net/known-issues-in-aspose-slides-for-net-14-1-0/) является списком, опубликованным с версией 14.1.0 в 2014 году, сохранённым для справки.

Для изменений и исправлений в каждой версии см. [примечания к выпуску](https://releases.aspose.com/slides/ru/net/release-notes/). Поля метаданных, которые Aspose.Slides записывает со фиксированными значениями, описаны в разделе [Ограничения метаданных вывода](/slides/ru/net/api-limitations/). Чтобы проверить, известна ли уже проблема, или сообщить о новой, используйте [форум поддержки](https://forum.aspose.com/c/slides/ru/11).
