## **Введение**

Aspose.Slides for .NET предоставляет комплексные инструменты для настройки размера слайда и соотношения сторон в презентациях PowerPoint, что критически важно как для печати, так и для отображения на экране. 

Популярные размеры слайдов и соотношения:

- **Standard (4:3 Aspect Ratio)**: Идеально для старых экранов и устройств.
- **Widescreen (16:9 Aspect Ratio)**: Рекомендуется для современных проекторов и дисплеев.

Обеспечьте согласованность во всей презентации, так как один размер слайда и одно соотношение сторон применяются ко всем слайдам. Для оптимального результата задайте размеры слайда в начале процесса создания презентации, чтобы избежать осложнений.

{{% alert color="info" %}} 
По умолчанию презентации, созданные с помощью Aspose.Slides, используют стандартное соотношение 4:3.
{{% /alert %}}

Страницы заметок и раздаточные листы имеют отдельные размеры от обычных слайдов. См. [Размер страницы заметок](/slides/ru/net/notes-size/) для изменения их размера и ориентации.

## **Как изменить размер слайда в презентации**

Этот пример демонстрирует изменение размера слайда презентации с помощью Aspose.Slides на C#:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **Указать пользовательские размеры слайдов**

Настройка размера слайда под ваши специфические требования, например, для уникальных форматов бумаги или экранных спецификаций, может быть полезна. Ниже показано, как задать пользовательский размер слайда с Aspose.Slides for .NET:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // Формат бумаги A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **Обрабатывать содержимое слайда после изменения размера**

После изменения размера содержимое слайдов может искажаться. Вы можете управлять тем, как Aspose.Slides обрабатывает это изменение:

- **`DoNotScale`**: Оставить объекты в исходных размерах, чтобы избежать масштабирования.
- **`EnsureFit`**: Масштабировать объекты, чтобы они помещались на меньших слайдах, предотвращая потерю содержания.
- **`Maximize`**: Увеличить объекты для соответствия большим слайдам, обеспечивая визуальную согласованность.

Пример использования настройки `Maximize` для изменения размера слайда:

```csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **FAQ**

### Могу ли я задать пользовательский размер слайда, используя единицы измерения, отличные от дюймов (например, пункты или миллиметры)?

Да. Aspose.Slides использует пункты внутри, где 1 пункт равен 1/72 дюйма. Вы можете преобразовать любую единицу (например, миллиметры или сантиметры) в пункты и использовать полученные значения для определения ширины и высоты слайда.

### Влияет ли очень большой пользовательский размер слайда на производительность и использование памяти при рендеринге?

Да. Большие размеры слайда (в пунктах) в сочетании с более высоким масштабом рендеринга приводят к увеличенному потреблению памяти и более длительному времени обработки. Стремитесь к практичному размеру слайда и регулируйте масштаб рендеринга только при необходимости для достижения желаемого качества вывода.

### Могу ли я определить один нестандартный размер слайда, а затем объединять слайды из презентаций с разными размерами?

Вы не можете [объединять презентации](/slides/ru/net/merge-presentation/) при разных размерах слайдов — сначала измените размер одной презентации, чтобы он соответствовал другой. При изменении размера слайда вы можете выбрать, как будет обрабатываться существующее содержание, используя параметр [SlideSizeScaleType](https://reference.aspose.com/slides/ru/net/aspose.slides/slidesizescaletype/). После согласования размеров можно объединять слайды, сохраняя форматирование.

### Могу ли я генерировать миниатюры для отдельных фигур или конкретных областей слайда, и будут ли они учитывать новый размер слайда?

Да. Aspose.Slides может создавать миниатюры для [полных слайдов](https://reference.aspose.com/slides/ru/net/aspose.slides/slide/getimage/) а также для [выбранных фигур](https://reference.aspose.com/slides/ru/net/aspose.slides/shape/getimage/). Полученные изображения отражают текущий размер слайда и соотношение сторон, обеспечивая согласованную кадрацию и геометрию.
