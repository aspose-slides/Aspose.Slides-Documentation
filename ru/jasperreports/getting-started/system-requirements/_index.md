## **JasperReports**

Aspose.Slides for JasperReports работает с JasperReports 3.7.2‑6.16.0. Для загрузки имеется отдельный jar для каждого из трёх диапазонов версий — см. [Installing Aspose.Slides for JasperReports](/slides/ru/jasperreports/installing-aspose-slides-for-jasperreports/) чтобы узнать, какой использовать. Для JasperReports 6.17.0 и более новых, включая JasperReports 7, jar не предусмотрен.

Поддержка JasperReports 2.0.3‑3.7.1 завершилась в Aspose.Slides for JasperReports 17.6. Версии 17.5 и более ранние также поддерживали эти версии.

## **Java**

Jars собраны для Java 6 или новее, как указано в их названиях папок *JDK 1.6*, поэтому версия Java, которую вам требуется, соответствует версии, необходимой вашему JasperReports. При работе с JasperReports 6.16.0 экспорт выполняется на Java 11, 17, 21 и 25.

## **Operating system**

Jars содержат только Java‑классы и ресурсы, без нативных библиотек, и не используют Microsoft PowerPoint. В Linux JasperReports требует fontconfig и минимум один установленный шрифт для заполнения отчёта.

## **JasperReports Server**

Для JasperReports Server используйте оба jar из папки, соответствующей версии JasperReports, на которой работает ваш сервер — см. [Integration with JasperServer](/slides/ru/jasperreports/integration-with-jasperserver/).
