Вы можете легко загрузить Aspose.Slides для оценки. Загрузка для оценки совпадает с загрузкой после покупки. Оценочная версия просто становится лицензированной, когда вы добавляете несколько строк кода для применения лицензии.

Оценочная версия Aspose.Slides (без указания лицензии) предоставляет полный функционал продукта, но вставляет водяной знак оценки в верхнюю часть документа при открытии и сохранении, а также ограничивает извлечение текста из слайдов презентации одним слайдом.
