**Добро пожаловать в Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports — это библиотека, специально разработанная для разработчиков, которым необходимо легко экспортировать отчёты из JasperReports в форматы Microsoft PowerPoint Presentation (PPT) и Microsoft PowerPoint Show (PPS) в их Java‑приложениях. Все возможности отчётов конвертируются с высочайшей точностью в презентации Microsoft PowerPoint. Aspose.Slides for JasperReports включает поддержку JasperReports 5+.
