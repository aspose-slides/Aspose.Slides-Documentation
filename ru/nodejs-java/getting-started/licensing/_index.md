## **Оценить Aspose.Slides**
Вы можете легко загрузить Aspose.Slides для оценки. Пакет оценки идентичен приобретаемому пакету. Версия оценки просто становится лицензированной после того, как вы добавите несколько строк кода для применения лицензии.

## **Ограничения версии оценки**
Версия оценки Aspose.Slides (без указания лицензии) предоставляет полный функционал продукта, но с двумя ограничениями:

* Она добавляет текстовое поле с водяным знаком оценки на каждый слайд каждой сохраняемой презентации.
* Текст длинее пяти символов, который ваш код читает из презентации, обрезается до первых пяти символов, за которыми следует `... text has been truncated due to evaluation version limitation.` Текст из пяти или менее символов возвращается без изменений, а текст, который ваш код записывает, сохраняется полностью.

## **Об лицензии**
Вы можете легко загрузить версию оценки Aspose.Slides для Node.js через Java со своей [страницы загрузки](https://releases.aspose.com/slides/nodejs-java/). Версия оценки имеет те же функции, что и лицензированная версия, с описанными выше ограничениями. Кроме того, версия оценки просто становится лицензированной после покупки лицензии и добавления пары строк кода для её применения.

Лицензия представляет собой обычный XML‑файл, содержащий такие сведения, как название продукта, количество разработчиков, для которых она лицензирована, дата окончания подписки и т.д. Файл подписан цифровой подписью, поэтому его нельзя изменять. Даже случайное добавление лишнего перевода строки в содержимое файла сделает его недействительным.

Чтобы избежать ограничений, связанных с версией оценки, необходимо установить лицензию перед использованием **Aspose.Slides**. Лицензию требуется установить только один раз за приложение или процесс.

### **Установка лицензии в Aspose.Slides для Node.js через Java**
Лицензии можно применять из следующих источников:

* Явный путь
* Поток
* Как лицензия по счётчику – новый механизм лицензирования

{{% alert color="info" title="Note" %}}
Используйте метод **setLicense** для лицензирования компонента.

Хотя несколько вызовов **setLicense** не вредят, они являются пустой тратой ресурсов (процессора).
{{% /alert %}}

#### **Применение лицензии с помощью файла**
Этот фрагмент кода используется для установки файла лицензии:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");

const license = new asposeSlides.License();
license.setLicense("Aspose.Slides.lic");
console.log("The license was applied.");

// Aspose.Slides работает в виртуальной машине Java, которая удерживает Node.js запущенным, поэтому завершите процесс явно.
process.exit(0);
```

При вызове метода setLicense имя лицензии должно совпадать с именем вашего файла лицензии. Например, вы можете переименовать файл лицензии в "Aspose.Slides.lic.xml". Затем в коде вам нужно передать новое имя лицензии (Aspose.Slides.lic.xml) методу setLicense. Если файл отсутствует или не содержит действительную лицензию, [setLicense](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) генерирует исключение, которое завершает скрипт с ошибкой.

#### **Применение лицензии из потока**
Чтобы применить лицензию из потока, передайте объект [License](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/) и читаемый поток статическому методу [setLicenseFromStream](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/). Поток читается асинхронно, и обратный вызов получает ошибку, если поток не содержит действительной лицензии:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");
const fs = require("fs");

const license = new asposeSlides.License();
const readStream = fs.createReadStream("Aspose.Slides.lic");
asposeSlides.License.setLicenseFromStream(license, readStream, function (error) {
    if (error) {
        console.error("The license was not applied:", error.message);
    } else {
        console.log("The license was applied.");
    }

    // Aspose.Slides работает в виртуальной машине Java, которая удерживает Node.js запущенным, поэтому завершите процесс явно.
    process.exit(0);
});
```

Лицензия применяется после полного чтения потока, непосредственно перед выполнением обратного вызова, поэтому начинайте другие операции Aspose.Slides из обратного вызова.

Оба примера вызывают `process.exit(0)` по завершении, поскольку виртуальная машина Java, запускающая Aspose.Slides, удерживает Node.js в работе. В приложении продолжайте работу с кодом Aspose.Slides вместо завершения процесса.

## **FAQ**

### Могу ли я применить лицензию в полностью офлайн‑среде (без доступа к интернету)?
Да. Проверка лицензии выполняется локально с использованием файла лицензии; подключение к интернету не требуется.

### Что происходит после истечения годовой подписки? Перестанет ли библиотека работать?
Нет. Лицензия бессрочная: вы можете продолжать использовать версии, выпущенные до даты окончания вашей подписки; вы просто не сможете использовать более новые выпуски без продления.
