## **Оценка Aspose.Slides**

Вы можете загрузить Aspose.Slides для оценки. Пакет оценки идентичен приобретённому пакету; он становится лицензированным после того, как вы добавите несколько строк кода для применения лицензии. Чтобы установить его, см. [Установка](/slides/ru/nodejs-java/installation/).

Без лицензии Aspose.Slides предоставляет весь свой функционал в режиме оценки, но с двумя ограничениями: он добавляет текстовое поле с водяным знаком оценки на каждый слайд каждой презентации, которую сохраняет, а текст длиной более пяти символов, который ваш код считывает из презентации, обрезается до первых пяти символов, после чего добавляется `... text has been truncated due to evaluation version limitation.` Текст из пяти символов или короче возвращается без изменений, а текст, который ваш код записывает, сохраняется полностью. Каждое сохранение добавляет водяной знак, поэтому презентация, открытая и сохранённая повторно в режиме оценки, содержит один водяной знак за каждое сохранение на каждом слайде.

## **Часто задаваемые вопросы**

### Можно ли тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует делиться одним и тем же объектом презентации [в разных потоках](/slides/ru/nodejs-java/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — это автономный движок и не требует установки PowerPoint ни для оценки, ни для эксплуатации.

### Можно ли полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [Конвертеры](/slides/ru/nodejs-java/convert-presentation/) работают; вывод будет содержать водяной знак.

### Можно ли использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия снимает ограничения режима оценки и позволяет проводить тестирование без водяного знака.
