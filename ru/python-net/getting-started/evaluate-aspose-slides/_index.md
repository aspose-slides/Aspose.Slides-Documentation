## **Оценка Aspose.Slides**

Вы можете загрузить Aspose.Slides для оценки. Пакет оценки идентичен купленному пакету; он получает лицензию после того, как вы добавите несколько строк кода для применения лицензии.

Без лицензии Aspose.Slides предоставляет всю свою функциональность в режиме оценки, но с двумя ограничениями: к каждому слайду каждой сохраняемой презентации добавляется текстовое поле с водяным знаком оценки, а текст, который ваш код читает из презентации, усекается до первых нескольких символов с последующим уведомлением об ограничении оценки. Текст, записываемый вашим кодом, сохраняется полностью.

## **FAQ**

### Могу ли я тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует использовать один и тот же объект презентации [в разных потоках](/slides/ru/python-net/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — самостоятельный движок и не требует установки PowerPoint ни для оценки, ни для продакшена.

### Могу ли я полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [Конвертеры](/slides/ru/python-net/convert-presentation/) работают; результат будет содержать водяной знак.

### Могу ли я использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия устраняет ограничения режима оценки и позволяет тестировать без водяного знака.
