## **Введение**

В PowerPoint 2019 компания Microsoft представила параметр **Always Open Read-Only** в качестве одной из опций, которые пользователи могут использовать для защиты своих презентаций. Вы можете захотеть использовать эту настройку «Только чтение», чтобы защитить презентацию, когда

- Вы хотите предотвратить случайные правки и сохранить содержимое презентации в безопасном виде. 
- Вы хотите проинформировать людей о том, что предоставленная вами презентация является окончательной версией. 

После того как вы выбираете параметр **Always Open Read-Only** для презентации, при её открытии пользователи видят рекомендацию **Read-Only** и могут увидеть сообщение в следующем виде: *To prevent accidental changes, the author has set this file to open as read-only.*

Рекомендация **Read-Only** — простое, но эффективное средство, отталкивающее от редактирования, поскольку пользователям нужно выполнить действие, чтобы снять её, прежде чем они смогут редактировать презентацию. Если вы не хотите, чтобы пользователи вносили изменения в презентацию и хотите вежливо сообщить им об этом, рекомендация **Read-Only** может быть хорошим вариантом для вас. 

> Если презентация с защитой **Read-Only** открывается в более старой версии Microsoft PowerPoint, которая не поддерживает недавно введённую функцию, рекомендация **Read-Only** игнорируется (презентация открывается обычным образом).

## **Применить режим только чтения**

Aspose.Slides for Android via Java позволяет установить презентацию в режим **Read-Only**, что означает, что пользователи (после открытия презентации) видят рекомендацию **Read-Only**. В этом примере кода показано, как установить презентацию в режим **Read-Only** на Java с помощью Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 

**Примечание**: Рекомендация **Read-Only** просто предназначена для того, чтобы отговорить от редактирования или предотвратить случайные изменения PowerPoint‑презентации. Если мотивированный пользователь — знающий, что делает — решит отредактировать вашу презентацию, он легко может снять настройку Read-Only. Если вам действительно нужно предотвратить неавторизованные изменения, лучше использовать [более строгие защиты, включающие шифрование и пароли](https://docs.aspose.com/slides/ru/androidjava/password-protected-presentation/).

## **FAQ**

### Чем «Read-Only recommended» отличается от полной защиты паролем?

«Read-Only recommended» лишь отображает предложение открыть файл в режиме только чтения и легко обходится. [Защита паролем](/slides/ru/androidjava/password-protected-presentation/) действительно ограничивает открытие или редактирование и подходит, когда нужны реальные средства защиты.

### Можно ли сочетать «Read-Only recommended» с водяными знаками для более сильного отталкивания от правки?

Да. Рекомендацию можно сочетать с [водяными знаками](/slides/ru/androidjava/watermark/) в качестве визуального отталкивающего фактора; это отдельные механизмы, которые хорошо работают вместе.

### Может ли макрос или внешнее средство всё равно изменить файл, когда рекомендация включена?

Да. Рекомендация не блокирует программные изменения. Чтобы предотвратить автоматические правки, используйте [пароли и шифрование](/slides/ru/androidjava/password-protected-presentation/).

### Как «Read-Only recommended» соотносится с методами «isEncrypted» и «isWriteProtected»?

Это разные сигналы. «Read-Only recommended» — мягкое, необязательное предложение; [isWriteProtected](https://reference.aspose.com/slides/ru/androidjava/com.aspose.slides/protectionmanager/#isWriteProtected--) и [isEncrypted](https://reference.aspose.com/slides/ru/androidjava/com.aspose.slides/protectionmanager/#isEncrypted--) указывают на реальные ограничения записи или чтения, зависящие от паролей или шифрования.
