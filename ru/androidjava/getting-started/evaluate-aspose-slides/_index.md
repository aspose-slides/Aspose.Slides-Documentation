## **Оценка Aspose.Slides**

Вы можете скачать Aspose.Slides для оценки. Оценочный пакет идентичен приобретённому; он становится лицензированным после добавления нескольких строк кода для применения лицензии.

Без лицензии Aspose.Slides предоставляет всю свою функциональность в оценочном режиме, но с двумя ограничениями: к каждому слайду каждой сохраняемой презентации добавляется текстовое поле с водяным знаком оценки, а текст, который ваш код читает из презентации, усекается до нескольких первых символов и сопровождается уведомлением об ограничениях оценки. Текст, который ваш код записывает, сохраняется полностью.

## **Часто задаваемые вопросы**

### Могу ли я тестировать несколько презентаций параллельно в разных потоках в оценочном режиме?

Да. Вы можете обрабатывать разные документы параллельно; не следует использовать один и тот же объект презентации [в разных потоках](/slides/ru/androidjava/multithreading/). Оценочный режим не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — автономный движок и не требует установки PowerPoint ни для оценки, ни для продакшена.

### Могу ли я полностью протестировать конвертацию PPT/PPTX в PDF и изображения в оценочном режиме?

Да. [Конвертеры](/slides/ru/androidjava/convert-presentation/) работают; в результате будет присутствовать водяной знак.

### Могу ли я использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия снимает ограничения оценочного режима и позволяет тестировать без водяного знака.
