Aspose.Slides for Android via Java — это библиотека классов, позволяющая Java‑приложениям для Android читать и записывать презентационные документы без использования Microsoft PowerPoint® или другого программного обеспечения. Aspose.Slides for Android via Java позволяет управлять текстом, фигурами, таблицами и анимациями; добавлять аудио и видео на слайды; просматривать слайды; а также экспортировать слайды в формат SVG, PDF и другие.

Последнюю справку по API можно найти на [Справка по API Aspose.Slides for Android via Java](https://reference.aspose.com/slides/ru/androidjava/).
