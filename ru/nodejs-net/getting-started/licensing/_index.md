## **Обзор**

Aspose.Slides for Node.js via .NET — это один npm‑пакет как для оценки, так и для производства. Без лицензии он работает в режиме оценки. После покупки лицензии или получения бесплатной 30‑дневной временной лицензии вы применяете её несколькими строками кода, и ограничения оценки более не действуют.

## **Ограничения версии оценки**

Версия оценки предоставляет полный набор функций продукта, но имеет два ограничения:

- **Водяной знак.** Каждый слайд каждой презентации, которую вы сохраняете, получает водяной знак оценки: заблокированный текстовый блок в центре слайда с надписью «Evaluation only». Тот же водяной знак добавляется при экспорте в PDF, XPS и HTML, а также к изображениям слайдов.
- **Обрезанный текст.** Текст, который ваш код читает из текстового кадра, абзаца или части, обрезается до первых пяти символов с последующим уведомлением «... text has been truncated due to evaluation version limitation». Экспорты в Markdown и HTML5 обрезаются аналогично. Текст, который ваш код записывает, сохраняется полностью.

[Оценить Aspose.Slides](/slides/ru/nodejs-net/evaluate-aspose-slides/) подробно описывает оба ограничения и включает скрипт, демонстрирующий их.

## **О лицензии**

Лицензия — это обычный XML‑файл, содержащий такие сведения, как название продукта, количество разработчиков, для которых предоставлена лицензия, и дата окончания подписки. Файл подписан цифровой подписью, поэтому не изменяйте его: даже случайный дополнительный перевод строки делает его недействительным.

## **Применение лицензии**

Примените лицензию с помощью метода `setLicense` класса `License`. Вызовите его один раз за процесс, до создания любого объекта `Presentation`. Повторный вызов не вреден, но повторяет уже выполненную работу.

Следующий скрипт применяет лицензию из файла с именем `Aspose.Slides.lic`. Замените имя на имя или полный путь к вашему файлу лицензии; файл может иметь любое название.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { License } = asposeSlides;

const license = new License();
try {
    license.setLicense("Aspose.Slides.lic");
    console.log("License applied.");
} catch (error) {
    console.log("License not applied:", error.message);
}
```

Имя файла или относительный путь разрешается относительно текущей папки, из которой вы запускаете `node`. Держите файл лицензии в папке проекта и запускайте скрипты из неё, либо передайте полный путь.

Если файл не найден или не является действительной лицензией, `setLicense` генерирует ошибку, и Aspose.Slides остаётся в режиме оценки. Скрипт перехватывает ошибку и выводит её сообщение. Для отсутствующего файла сообщение начинается с `License "Aspose.Slides.lic" doesn't exist or access is restricted.` и перечисляет все проверенные пути.

В этом пакете лицензия применяется только из файла. `License` не принимает поток, и пакет не предоставляет метерного лицензирования. Для класса, который оборачивает пакет, см. [License](https://reference.aspose.com/slides/net/aspose.slides/license/) в справочнике API Aspose.Slides for .NET.
