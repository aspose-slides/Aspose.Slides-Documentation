Вы можете легко скачать Aspose.Slides для оценки. Оценочный пакет идентичен приобретенному пакету. Оценочная версия становится полностью лицензированной после добавления нескольких строк кода для применения лицензии.

Оценочная версия Aspose.Slides (без указания лицензии) предоставляет полный набор функций продукта, но при открытии и сохранении вставляет водяной знак оценки в верхнюю часть документа. Кроме того, при извлечении текста из слайдов презентации вы ограничены одним слайдом.
