## **Обзор**

Оценочная версия Aspose.Slides for Node.js через .NET является тем же npm‑пакетом, что и лицензированная версия. Без лицензии она работает в режиме оценки: все функции работают, но сохранённые презентации и большинство экспортов содержат водяной знак, а текст, который ваш код считывает обратно, обрезается. Эта статья описывает обе ограничения и показывает, как их убрать.

## **Ограничения оценки**

**Водяной знак оценки на каждом слайде.** Когда вы сохраняете презентацию без лицензии, Aspose.Slides добавляет текстовое поле в центр каждого слайда сохраняемого файла. Текстовое поле заблокировано и содержит надпись "Evaluation only." с последующей строкой продукта и строкой авторского права. Водяной знак записывается в сохранённый файл, а не в презентацию в памяти, и открытие презентации не добавляет его. Однако файл, сохранённый в режиме оценки, уже содержит текстовое поле, поэтому при открытии и повторном сохранении к каждому слайду добавляется второй водяной знак.

Тот же водяной знак рисуется на выводе при экспорте в PDF, XPS или HTML, а также при рендеринге слайдов в изображения. Если вы рендерите презентацию, уже сохранённую в режиме оценки, изображение отображает как сохранённый водяной знак, так и отрисованный.

**Обрезанный текст при чтении вашим кодом.** Текст, который ваш код читает через свойство `text` текстового кадра, абзаца или части, сокращается до первых пяти символов, после чего добавляется уведомление "... text has been truncated due to evaluation version limitation." Текст из пяти и менее символов возвращается полностью. Это относится к каждому слайду, включая текст, который ваш код только что присвоил. Экспорты в Markdown и HTML5 обрезаются аналогичным образом.

Текст, который ваш код записывает, сохраняется полностью: файлы PPTX, страницы PDF и изображения слайдов содержат полный текст.

## **Посмотрите ограничения в скрипте**

Следующий скрипт демонстрирует оба ограничения. Предполагается, что вы установили пакет, как описано в [Installation](/slides/ru/nodejs-net/installation/), и запускаете его из папки проекта. Он добавляет прямоугольник с предложением на первый слайд, считывает предложение обратно, сохраняет презентацию как `evaluation.pptx`, а затем снова открывает файл, чтобы подсчитать фигуры на слайде.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { Presentation, ShapeType, SaveFormat } = asposeSlides;

const presentation = new Presentation();
try {
    const slide = presentation.slides.get(0);
    const rectangle = slide.shapes.addAutoShape(ShapeType.Rectangle, 50, 50, 500, 100);
    rectangle.textFrame.text = "Quarterly results are ready for review.";

    // Без лицензии возвращаются только первые пять символов.
    console.log("Text read back:", rectangle.textFrame.text);

    // Сохранение добавляет оценочный водяной знак к каждому слайду файла.
    presentation.save("evaluation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}

const savedPresentation = new Presentation("evaluation.pptx");
try {
    // Слайд теперь содержит прямоугольник и текстовое поле с водяным знаком.
    console.log("Shapes on the saved slide:", savedPresentation.slides.get(0).shapes.count);
} finally {
    savedPresentation.dispose();
}
```

Без лицензии скрипт выводит:

```text
Text read back: Quart... text has been truncated due to evaluation version limitation.
Shapes on the saved slide: 2
```

Вторая фигура — это текстовое поле с водяным знаком. Откройте `evaluation.pptx`, чтобы увидеть полное предложение в прямоугольнике и водяной знак в центре слайда.

## **FAQ**

**Ограничивает ли режим оценки количество слайдов?**

Нет. Презентации создаются, открываются и сохраняются со всеми их слайдами. Водяной знак и обрезка текста применяются к каждому слайду одинаково.

**Почему мои экспортированные изображения слайдов показывают водяной знак дважды?**

Презентация была сохранена в режиме оценки до того, как вы её отрисовали, поэтому в ней уже содержится текстовое поле с водяным знаком, а рендеринг без лицензии рисует ещё один поверх него.

**Могу ли я проверить, что мой код генерирует правильный текст в режиме оценки?**

Да. Откройте сохранённый файл или экспортированный PDF: они содержат полный текст. Только текст, который ваш код считывает обратно, а также вывод в Markdown или HTML5, обрезаются.
