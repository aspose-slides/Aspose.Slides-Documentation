## **Оценка Aspose.Slides**
Вы можете легко скачать Aspose.Slides для оценки. Пакет оценки идентичен покупному пакету. Версия оценки просто становится лицензированной после того, как вы добавите несколько строк кода для применения лицензии. 

## **Ограничения версии оценки**
Версия оценки Aspose.Slides (без указания лицензии) предоставляет полный функционал продукта, но с двумя ограничениями:

* Она добавляет текстовое поле с водяным знаком оценки в центр каждого слайда каждой сохраняемой презентации.
* Текст, который ваш код читает из презентации, обрезается до первых нескольких символов, после чего добавляется уведомление об ограничении оценки. Текст, который ваш код записывает, сохраняется полностью.

{{% alert color="info" title="Примечание" %}}
Если вы хотите протестировать Aspose.Slides без ограничений версии оценки, вы можете запросить **30‑дневную временную лицензию**. Пожалуйста, обратитесь к [Как получить временную лицензию?](https://purchase.aspose.com/temporary-license) для получения дополнительной информации.
{{% /alert %}} 

## **О лицензии**
Вы можете легко скачать версию оценки Aspose.Slides для PHP через Java со своей [страницы загрузки](https://packagist.org/packages/aspose/slides). Версия оценки предоставляет абсолютно **те же возможности**, что и лицензированная версия Aspose.Slides. Кроме того, версия оценки просто становится лицензированной после того, как вы приобретёте лицензию и добавите несколько строк кода для её применения.

Лицензия представляет собой обычный XML‑файл, содержащий такие детали, как название продукта, количество разработчиков, которым лицензия предоставлена, дата истечения подписки и т.д. Файл подписан цифровой подписью, поэтому его нельзя изменять. Даже случайное добавление лишнего символа переноса строки в содержимое файла сделает его недействительным.

Чтобы избежать ограничений, связанных с версией оценки, необходимо установить лицензию перед использованием **Aspose.Slides**. Устанавливать лицензию требуется только один раз для приложения или процесса.

{{% alert color="info" title="Примечание" %}}
Возможно, вам будет интересно ознакомится с [Измеряемое лицензирование](/slides/ru/php-java/metered-licensing/).
{{% /alert %}}

### **Установка лицензии в Aspose.Slides для PHP через Java**

Лицензии могут быть применены из следующих источников:

* Явный путь
* Поток
* Как измеряемая лицензия – новый механизм лицензирования

{{% alert color="info" title="Примечание" %}}
Используйте метод **setLicense** для лицензирования компонента.

Несмотря на то, что множественные вызовы **setLicense** не вредят, они расходуют ресурсы (процессор).
{{% /alert %}}

{{% alert color="warning" title="Warning" %}}
Новые лицензии могут активировать Aspose.Slides только начиная с версии 21.4. Более ранние версии используют другую систему лицензирования и не распознают эти лицензии.
{{% /alert %}}

#### **Применение лицензии с помощью файла**

Этот фрагмент кода используется для установки файла лицензии:

**PHP**

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/ru/lib/aspose.slides.php");

use aspose\slides\License;

$license = new License();
$license->setLicense(__DIR__ . "/Aspose.Slides.lic");
```

В примере ожидается, что файл лицензии находится рядом со скриптом, и передаётся его абсолютный путь: Aspose.Slides работает внутри Tomcat, поэтому он не разрешает относительный путь относительно папки вашего скрипта. При вызове метода setLicense имя лицензии должно совпадать с именем вашего файла лицензии. Например, вы можете переименовать файл лицензии в «Aspose.Slides.lic.xml». Затем в коде необходимо передать новое имя лицензии (Aspose.Slides.lic.xml) в метод setLicense.

#### **Применение лицензии из потока**

Этот фрагмент кода используется для применения лицензии из потока:

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/ru/lib/aspose.slides.php");

use aspose\slides\License;

$stream = new Java("java.io.FileInputStream", __DIR__ . "/Aspose.Slides.lic");

$license = new License();
$license->setLicense($stream);

$stream->close();
```

## **Часто задаваемые вопросы**

### Могу ли я применить лицензию в полностью офлайн‑среде (без доступа к интернету)?
Да. Проверка лицензии выполняется локально с использованием файла лицензии; подключение к интернету не требуется.

### Что происходит после истечения годовой подписки? Перестанет ли работать библиотека?
Нет. Лицензия является постоянной: вы можете продолжать использовать версии, выпущенные до даты окончания вашей подписки; просто вы не сможете использовать более новые версии без продления подписки.
