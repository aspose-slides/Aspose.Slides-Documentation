## **Оценка Aspose.Slides**

Вы можете загрузить Aspose.Slides для оценки. Пакет оценки идентичен коммерческому пакету; он будет лицензирован после того, как вы добавите несколько строк кода для применения лицензии. Смотрите [Установка](/slides/ru/php-java/installation/) для настройки и [Лицензирование](/slides/ru/php-java/licensing/) для применения лицензии.

Без лицензии Aspose.Slides предоставляет полную функциональность в режиме оценки, но с двумя ограничениями: он добавляет текстовое поле с водяным знаком оценки в центр каждого слайда каждой сохраняемой презентации, а текст, который ваш код считывает из презентации, обрезается до первых нескольких символов с последующим уведомлением об ограничении оценки. Текст, который ваш код записывает, сохраняется полностью.

{{% alert color="info" title="Note" %}}

Если вы хотите протестировать Aspose.Slides без ограничений версии оценки, вы можете запросить **30‑дневную временную лицензию**. Пожалуйста, обратитесь к [Как получить временную лицензию?](https://purchase.aspose.com/temporary-license) для получения дополнительной информации.

## **Часто задаваемые вопросы**

### Могу ли я тестировать несколько презентаций одновременно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует делиться одним объектом презентации [между потоками](/slides/ru/php-java/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — это автономный движок и не требует установки PowerPoint ни для оценки, ни для продакшена.

### Могу ли я полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [Конвертеры](/slides/ru/php-java/convert-presentation/) работают; вывод будет содержать водяной знак.

### Можно ли использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия устраняет ограничения режима оценки и позволяет тестировать без водяного знака.
