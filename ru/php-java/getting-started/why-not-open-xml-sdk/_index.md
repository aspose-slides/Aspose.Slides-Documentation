## **Обзор**

В этой статье объясняется, когда разработчикам может потребоваться выбрать Open XML SDK или Aspose.Slides для работы с презентационными документами. В ней Open XML SDK описывается как библиотека для манипуляций пакетами OOXML и их базовыми XML‑элементами, тогда как Aspose.Slides представляется как библиотека обработки презентаций с высокоуровневой объектной моделью и поддержкой множества задач, связанных с PowerPoint.

Статья сравнивает оба варианта по поддерживаемым форматам, программной модели, рендерингу, поддерживаемым платформам и типичным сценариям использования. Также уточняется, что Open XML SDK может подойти для базовых операций с PPTX или прямого доступа к элементам OOXML, тогда как Aspose.Slides более уместен для сложных задач, таких как работа с множеством форматов PowerPoint, копирование или клонирование фигур, замена текста, применение анимаций и конвертация презентаций в PDF, TIFF или XPS.

## **Что такое Open XML SDK?**
Согласно [Библиотека MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK определяется как:

Open XML SDK 2.0 упрощает задачу манипулирования пакетами Open XML и базовыми элементами схемы Open XML внутри пакета. Open XML SDK 2.0 инкапсулирует многие распространённые задачи, которые разработчики выполняют с пакетами Open XML, позволяя выполнять сложные операции всего несколькими строками кода.

Документы OOXML по сути являются сжатыми XML‑файлами, а Open XML SDK — это набор классов, позволяющих работать с содержимым OOXML‑документов типобезопасным способом. Вместо распаковки файла для извлечения XML, загрузки этого XML в DOM‑дерево и работы с элементами и атрибутами напрямую, Open XML SDK предоставляет классы для выполнения этих действий.

## **Что такое Aspose.Slides?**
Aspose.Slides — это библиотека классов, позволяющая вашему приложению выполнять следующие задачи обработки презентаций:

- Программирование с использованием объектной модели **Presentation**.
- Высококачественные конвертации между всеми популярными поддерживаемыми форматами презентаций PowerPoint, включая конвертацию в PDF, XPS и TIFF.
- Возможность генерировать эскизы слайдов в известных форматах, таких как PNG, JPEG и BMP, а также экспортировать слайды в SVG.
- Возможность создавать презентации с нуля или комбинировать их из одного или нескольких документов.
- Поддержка добавления анимаций, Ole‑фреймов, таблиц, создания и управления диаграммами.
- Наличие обширных возможностей управления форматированием текста на уровнях TextFrames, Paragraphs и Portions.

Для получения более подробной информации о поддерживаемых функциях, пожалуйста, посетите [Функции Aspose.Slides](/slides/ru/php-java/product-overview/).

## **Заключение**
{{% alert color="info" %}} 

Open XML SDK и Aspose.Slides не конкурируют напрямую, потому что они решают довольно разные задачи и ориентированы на разную аудиторию. Open XML SDK — это библиотека классов, предоставляющая типобезопасный способ работы с OOXML‑документами. Aspose.Slides — очень полезная библиотека обработки презентаций, обеспечивающая отличную поддержку почти всех форматов файлов Microsoft PowerPoint.

Если вам нужно лишь выполнить довольно простую программную операцию над документом PPTX, то Open XML SDK может стать подходящим выбором. С Open XML SDK вам будет удобно выполнять простые задачи, такие как генерация простого PPTX‑документа, удаление комментариев, заголовков/нижних колонтитулов, извлечение изображений и т.д. Некоторые задачи можно решить с помощью Open XML SDK, но нельзя с помощью Aspose.Slides. Например, если необходимо напрямую обращаться к XML‑элементам и атрибутам OOXML‑документа, следует использовать Open XML SDK. Однако если требуется выполнять сложные операции над документами, такие как некоторые из перечисленных ниже, использование Aspose.Slides будет наилучшим вариантом:

- Поддержка более старых форматов PowerPoint в дополнение к PPTX.
- Копирование или клонирование фигур в слайдах таким образом, чтобы объединять объекты, стили и прочее форматирование надлежащим образом.
- Замена отформатированного или неформатированного текста.
- Применение анимаций и использование соединителей с фигурой.
- Конвертация документа в PDF, TIFF или XPS так, чтобы он выглядел точно так же, как при конвертации в Microsoft PowerPoint.
- Разработка .NET или Java приложения как для настольных, так и для веб‑сред.
