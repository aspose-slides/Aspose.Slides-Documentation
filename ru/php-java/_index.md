**Добро пожаловать в Aspose.Slides for PHP via Java**

![Aspose.Slides for PHP via Java Product Logo](aspose_slides-for-php-via-java.png)

Aspose.Slides for PHP via Java — это библиотека классов, позволяющая вашим приложениям читать и записывать документы PowerPoint® без использования Microsoft PowerPoint®.

Aspose.Slides for PHP via Java — первый и единственный компонент, предоставляющий возможность управлять документами PowerPoint®.

Aspose.Slides for PHP via Java предлагает множество ключевых функций, таких как управление текстом, фигурами, таблицами и анимацией, добавление аудио и видео на слайды, предварительный просмотр слайдов, экспорт слайдов в SVG, PDF и многое другое.
