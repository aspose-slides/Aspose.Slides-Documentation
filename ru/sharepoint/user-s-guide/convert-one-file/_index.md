Для преобразования презентации в библиотеке документов:

1. Откройте меню файла PPT или PPTX (его блок управления редактированием) и выберите **Convert via Aspose.Slides**. В SharePoint 2007 пункт меню называется **Convert with Aspose.Slides**.

   **Выбор Convert with Aspose.Slides в меню документа в SharePoint 2007**

   ![Меню документа в библиотеке документов SharePoint 2007, с пунктом Convert with Aspose.Slides](convert-one-file_1.png)

2. На странице конвертации выберите формат вывода в разделе **Convert to**. При желании измените имя целевого файла и целевую папку.
3. Нажмите **Convert**.
4. Когда конвертация завершена, нажмите **Source Library** или **Destination Library**, чтобы вернуться в библиотеку документов. Преобразованный файл находится в целевой папке.

Те же шаги с скриншотами каждой страницы находятся в [Converting Microsoft PowerPoint Documents into Other Formats](/slides/ru/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
