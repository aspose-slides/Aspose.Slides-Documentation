Для удаления Aspose.Slides for SharePoint:

1. Запустите программу установки, которую использовали для установки, например *Setup2019.exe* на SharePoint Server 2019.
   Если обнаружена установленная та же версия, программа установки предлагает восстановить или удалить её. Если обнаружена другая версия, она предлагает выполнить обновление или удалить её.
2. Выберите **Remove** и нажмите **Next**, чтобы удалить Aspose.Slides for SharePoint.
