## **Форматы файлов и конвертации**
Aspose.Slides forC++ supports most of the PowerPoint document formats and also exports them to popular formats used widely for exchange among organizations. Following table enlists these formats:

|**Функция**|**Описание**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ru/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ обеспечивает самую быструю обработку этого формата презентационных документов.|
|[Portable Document Format (PDF)](/slides/ru/cpp/portable-document-format-pdf/)|Поддерживаемые форматы файлов могут быть экспортированы в документы Adobe Portable Document Format (PDF) одним методом.|
|[XML Parser Specification (XPS)](/slides/ru/cpp/xml-parser-specification-xps/)|Все поддерживаемые форматы файлов могут быть экспортированы в документы XML Parser Specification (XPS) одним методом.|
|[PresentationML (PPTX, XML)](/slides/ru/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ поддерживает обработку формата презентаций OOXML, также известного как PresentationML или PPTX.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/ru/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ поддерживает конвертацию презентаций в формат HTML.|

## **Отрисовка презентаций**
Aspose.Slides for C++ supports high fidelity rendering of slides in the presentation documents to various graphics formats as listed below:

|**Функция**|**Описание**|
| :- | :- |
|C++ Supported Image Formats|С помощью Aspose.Slides for C++ вы сможете отрисовывать не только слайды презентаций, но и изображения на слайдах во все поддерживаемые C++ графические форматы, такие как PNG, BMP и JPEG.|

## **Часто задаваемые вопросы**

### Нужно ли устанавливать Microsoft PowerPoint на сервер/ПК, чтобы библиотека работала?

Нет. PowerPoint не требуется; Aspose.Slides — это автономный движок для создания, редактирования, конвертации и отрисовки презентаций.

### Как работает многопоточность? Можно ли выполнять обработку параллельно?

Можно безопасно обрабатывать разные документы в разных потоках; один и тот же объект [presentation](https://reference.aspose.com/slides/ru/cpp/aspose.slides/presentation/) не должен использоваться [multiple threads](/slides/ru/cpp/multithreading/) одновременно.

### Поддерживаются ли пароли и шифрование файлов?

Да. [You can](/slides/ru/cpp/password-protected-presentation/) открыть зашифрованные презентации, установить или удалить пароль для открытия и записи, и проверить статус защиты.

### Нужно ли беспокоиться о пакетах шрифтов в контейнерах Linux?

Да. Рекомендуется установить общие пакеты шрифтов и/или явно [specify font directories](/slides/ru/cpp/custom-font/) в вашем приложении, чтобы избежать непредвидённых замен.

### Есть ли ограничения в оценочной версии?

В [evaluation mode](/slides/ru/cpp/licensing/) к выводу добавляется водяной знак и применяются определённые ограничения; доступна [30‑day temporary license](https://purchase.aspose.com/temporary-license/) для полного тестирования функций.

### Поддерживается ли импорт внешних форматов в презентацию (PDF/HTML → PPTX)?

Да. Вы можете добавить [PDF pages and HTML content](/slides/ru/cpp/import-presentation/) в презентацию, превратив их в слайды.
