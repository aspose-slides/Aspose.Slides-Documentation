## **Обзор**

Aspose.Slides можно использовать в режиме оценки или с действующей лицензией. Оценочная версия предоставляет тот же функционал, что и лицензированная, но добавляет водяной знак оценки при открытии или сохранении презентаций и ограничивает извлечение текста одной слайдом.

Эта статья объясняет, как работает лицензирование в Aspose.Slides и как применить лицензию перед использованием библиотеки. Лицензия может быть загружена из файла, потока или встроенного ресурса с помощью класса `License`. В статье также показано, как проверить, была ли лицензия применена корректно.

## **Лицензирование в Aspose.Slides**

* Оценочная версия становится лицензированной после покупки лицензии и её применения с помощью нескольких строк кода.
* Лицензия представляет собой обычный XML‑файл, содержащий такие детали, как название продукта, количество разработчиков, которым она выдана, дата окончания подписки и прочее.
* Файл лицензии цифрово подписан, поэтому его нельзя изменять. Даже случайное изменение — например, добавление разрыва строки — аннулирует файл.
* Aspose.Slides for C++ обычно ищет файл лицензии в следующих местах:
  * Путь, явно указанный в вашем коде
  * Папка, содержащая DLL компонента (входит в состав Aspose.Slides)
  * Папка, содержащая сборку, которая вызывает DLL компонента
* Чтобы избежать ограничений оценочной версии, необходимо установить лицензию до использования Aspose.Slides. Лицензию требуется установить только один раз за приложение или процесс.

## **Применение лицензии**

Лицензия может быть загружена из **файла**, **потока** или **встроенного ресурса**.

{{% alert color="info" %}}

Aspose.Slides предоставляет класс [License](https://reference.aspose.com/slides/ru/cpp/class/aspose.slides.license/) для операций с лицензиями.

{{% /alert %}} 

{{% alert color="warning" %}}

Новые лицензии могут активировать Aspose.Slides только, начиная с версии 21.4. Ранние версии используют другую систему лицензирования и не распознают эти лицензии.

{{% /alert %}}

### **Файл**

Самый простой способ установить лицензию — разместить файл лицензии в той же папке, что и DLL компонента (входит в состав Aspose.Slides), и указать только имя файла без пути.

Следующий код C++ показывает, как установить файл лицензии:

```c++
#include <Util/License.h>
#include <system/smart_ptr.h>
#include <system/string.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    return 0;
}
```

{{% alert color="warning" %}} 

Если вы разместите файл лицензии в другой директории, то при вызове метода [License::SetLicense](https://reference.aspose.com/slides/ru/cpp/aspose.slides/license/setlicense/) имя файла в конце явно указанного пути должно точно соответствовать имени вашего файла лицензии.

Например, если вы переименуете файл лицензии в *Aspose.Slides.lic.xml*, вам нужно передать полный путь, заканчивающийся на *Aspose.Slides.lic.xml*, методу [License::SetLicense](https://reference.aspose.com/slides/ru/cpp/aspose.slides/license/setlicense/) в вашем коде.

{{% /alert %}}

### **Поток**

Вы можете загрузить лицензию из потока. Следующий код C++ демонстрирует, как применить лицензию из потока:

```c++
#include <Util/License.h>
#include <system/io/file.h>
#include <system/smart_ptr.h>
using namespace Aspose::Slides;
using namespace System;
using namespace System::IO;

auto license = MakeObject<License>();

auto stream = File::OpenRead(u"Aspose.Slides.lic");

license->SetLicense(stream);
```

## **Проверка лицензии**

Чтобы проверить, была ли лицензия установлена правильно, вы можете её валидировать. Следующий код C++ показывает, как проверить лицензию:

```c++
#include <Util/License.h>
#include <system/console.h>
using namespace Aspose::Slides;
using namespace System;

auto license = MakeObject<License>();

license->SetLicense(u"Aspose.Slides.lic");

if (license->IsLicensed())
{
    Console::WriteLine(u"License is good!");
    Console::ReadKey();
}
```

## **Потокобезопасность**

{{% alert title="Note" color="warning" %}} 

Метод [License::SetLicense](https://reference.aspose.com/slides/ru/cpp/aspose.slides/license/setlicense/) **не является потокобезопасным**. Если вам необходимо вызывать этот метод одновременно из нескольких потоков, рекомендуется использовать primitives синхронизации (например, блокировку), чтобы предотвратить потенциальные проблемы.

{{% /alert %}}

## **FAQ**

### Можно ли применить лицензию в полностью офлайн‑среде (без доступа к интернету)?

Да. Проверка лицензии выполняется локально с использованием файла лицензии; подключение к интернету не требуется.

### Что происходит после истечения годовой подписки? Прекратит ли библиотека работу?

Нет. Лицензия является пожизненной: вы можете продолжать использовать версии, выпущенные до даты окончания вашей подписки; вы просто не сможете пользоваться более новыми выпусками без продления подписки.
