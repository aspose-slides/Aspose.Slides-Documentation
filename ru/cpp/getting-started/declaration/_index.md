{{% alert color="info" %}} 

Все компоненты Aspose C++ требуют набор разрешений Full Trust. Причина в том, что компоненты Aspose C++ необходимо получать доступ к настройкам реестра, системным файлам, отличным от виртуального каталога, для некоторых операций, таких как разбор шрифтов и т.п. Более того, компоненты Aspose C++ основаны на основных системных классах C++, которые во многих случаях также требуют набор разрешений Full Trust. 

{{% /alert %}}
