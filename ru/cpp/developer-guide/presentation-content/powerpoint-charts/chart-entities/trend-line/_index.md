## **Обзор**

Эта статья объясняет, как добавить линии тренда к диаграммам презентаций с помощью Aspose.Slides. В ней показывается, как создать диаграмму, добавить линии тренда к сериям диаграммы и работать с несколькими типами линий тренда, включая экспоненциальные, линейные, логарифмические, скользящее среднее, полиномиальные и степенные.

Также описывается, как добавить пользовательскую линию к диаграмме, вставив форму линии, и включён короткий FAQ о значениях проекции линии тренда вперёд и назад и сохраняются ли линии тренда при экспорте в PDF или SVG и при рендеринге диаграмм как изображений.

## **Добавить пользовательскую линию**
Aspose.Slides для C++ предоставляет простой API для добавления пользовательских линий в диаграмму. Чтобы добавить простую обычную линию на выбранный слайд презентации, выполните следующие шаги:

- Создать экземпляр класса Presentation
- Получить ссылку на слайд, используя его Index
- Создать новую диаграмму с помощью метода AddChart, доступного через объект Shapes
- Добавить AutoShape типа Line с помощью метода AddAutoShape, доступного через объект Shapes
- Установить цвет линий формы.
- Сохранить изменённую презентацию в файл PPTX

## **FAQ**

**Что означают «forward» и «backward» для линии тренда?**

Это длины линии тренда, проецируемой вперёд/назад: для точечных (XY) диаграмм — в единицах осей; для не точечных диаграмм — в количестве категорий. Допустимы только неотрицательные значения.

**Сохранится ли линия тренда при экспорте презентации в PDF или SVG, или при рендеринге слайда в изображение?**

Да. Aspose.Slides конвертирует презентации в [PDF](/slides/ru/cpp/convert-powerpoint-to-pdf/)/[SVG](/slides/ru/cpp/render-a-slide-as-an-svg-image/) и рендерит диаграммы в изображения; линии тренда, как часть диаграммы, сохраняются при этих операциях. Также доступен метод для [экспорта изображения диаграммы](/slides/ru/cpp/create-shape-thumbnails/).
