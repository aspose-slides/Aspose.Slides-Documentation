## **Обзор**

Aspose.Slides for C++ может загружать презентации PowerPoint и OpenDocument и сохранять или отображать их во многих других форматах без Microsoft PowerPoint, OpenOffice или LibreOffice. Вы можете конвертировать устаревшие файлы PPT в современные PPTX, экспортировать презентации в фиксированные документы, такие как PDF и XPS, публиковать слайды как HTML или рендерить слайды в виде файлов изображений для предварительного просмотра, миниатюр и архивов.

Большинство преобразований документов используют один и тот же общий рабочий процесс: загрузить исходный файл, выбрать требуемый формат вывода и при необходимости применить параметры, специфичные для формата. Для графических форматов каждый слайд рендерится отдельно, а затем сохраняется как растровое или векторное изображение. Ниже приведённые статьи содержат детали реализации для каждого случая.

## **Конвертация PowerPoint и OpenDocument**

Aspose.Slides for C++ поддерживает конвертацию из часто используемых форматов презентаций, таких как PPT, PPTX, PPS, PPSX, POT, POTX и ODP. Один и тот же API конвертации используется как для файлов PowerPoint, так и для OpenDocument, поэтому рабочий процесс, сохраняющий файл PPTX в PDF, обычно можно применить к файлу ODP, изменив только входной файл.

При конвертации файлов ODP помните, что приложения PowerPoint и OpenDocument не поддерживают каждый макет и каждый параметр форматирования одинаково. Если файл ODP был создан в LibreOffice или OpenOffice Impress, проверьте результат и используйте параметры, описанные в статье [Конвертировать презентации OpenDocument](/slides/ru/cpp/convert-openoffice-odp/), когда требуется руководство по конкретному формату.

## **Преобразование PPT в PPTX**

PPT — старый бинарный формат PowerPoint, тогда как PPTX — современный формат Office Open XML. Aspose.Slides for C++ поддерживает высокоточное преобразование PPT в PPTX с сохранением сложных структур презентации, таких как мастера, макеты, слайды, диаграммы, группированные фигуры, заполнители, текстовые рамки, текстуры и заливки изображениями.

Подробности см. в статье [Конвертировать PPT в PPTX](/slides/ru/cpp/convert-ppt-to-pptx/).

## **Экспорт в фиксированный макет**

PDF, XPS и TIFF полезны, когда вывод должен выглядеть одинаково на разных устройствах и не должен редактироваться как презентация. Специализированные статьи по PDF, XPS и TIFF объясняют, как управлять совместимостью, скрытыми слайдами, заметками, качеством изображений, сжатием, пиксельным форматом и размером вывода.

## **Экспорт в HTML и изображения**

Экспорт в HTML и HTML5 полезен для просмотра в браузере, публикации в интернете и лёгкого обмена. Экспорт изображений нужен, когда каждый слайд должен стать отдельным предварительным просмотром, миниатюрой или растровым ресурсом. Используйте статьи по PNG, JPG и SVG для рекомендаций по рендерингу в каждом формате.

## **FAQ**

**Нужен ли Microsoft PowerPoint для конвертации презентаций?**

Нет. Aspose.Slides for C++ — автономная библиотека и не требует Microsoft PowerPoint или автоматизации Office.

**Можно ли пакетно конвертировать большое количество презентаций?**

Да. Загружайте каждую презентацию, сохраняйте её в требуемом формате и освобождайте объект презентации после обработки. Для параллельной обработки используйте отдельные экземпляры презентаций и следуйте рекомендациям по [многопоточности](/slides/ru/cpp/multithreading/).

**Можно ли экспортировать только выбранные слайды?**

Да. Несколько методов экспорта позволяют передать индексы слайдов или рендерить отдельные слайды, в зависимости от целевого формата. См. специализированную статью для нужного формата.

**Можно ли включать скрытые слайды при экспорте в PDF или XPS?**

Да. Используйте параметры экспорта скрытых слайдов, описанные в статьях по [PDF](/slides/ru/cpp/convert-powerpoint-to-pdf/) и [XPS](/slides/ru/cpp/convert-powerpoint-to-xps/).

**Можно ли создать вывод PDF/A?**

Да. Для экспорта PDF доступны настройки соответствия PDF‑стандарту. Подробности см. в статье [Конвертировать PowerPoint в PDF](/slides/ru/cpp/convert-powerpoint-to-pdf/).

**Как обрабатываются шрифты при конвертации?**

Aspose.Slides может использовать внедрённые шрифты, резервные шрифты и настройки замены шрифтов. См. статьи [Внедрённый шрифт](/slides/ru/cpp/embedded-font/), [Резервный шрифт](/slides/ru/cpp/fallback-font/) и [Замена шрифтов](/slides/ru/cpp/font-substitution/).
