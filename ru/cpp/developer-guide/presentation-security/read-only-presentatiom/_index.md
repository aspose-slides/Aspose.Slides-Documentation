## **Введение**

В PowerPoint 2019 Microsoft представила параметр **Always Open Read-Only** как одну из возможностей, которыми пользователи могут защищать свои презентации. Вы можете захотеть использовать этот режим только для чтения, чтобы защитить презентацию, когда

- Вы хотите предотвратить случайные изменения и сохранить содержимое вашей презентации в безопасности. 
- Вы хотите предупредить людей, что предоставленная вами презентация является финальной версией. 

После того как вы выберете опцию **Always Open Read-Only** для презентации, при её открытии пользователи увидят рекомендацию **Read-Only** и могут увидеть сообщение следующего вида: *Для предотвращения случайных изменений автор установил этот файл в режим только для чтения.*

Рекомендация **Read-Only** — простое, но эффективное средство, отпугивающее редактирование, поскольку пользователям необходимо выполнить действие, чтобы снять её, прежде чем они смогут редактировать презентацию. Если вы не хотите, чтобы пользователи вносили изменения в презентацию и хотите вежливо уведомить их об этом, рекомендация **Read-Only** может стать хорошим вариантом для вас. 

> Если презентация с защитой **Read-Only** открывается в более старой версии Microsoft PowerPoint, которая не поддерживает недавно введённую функцию, рекомендация **Read-Only** игнорируется (презентация открывается обычным образом).

## **Применить режим только для чтения**

Aspose.Slides for C++ позволяет установить презентацию в режим **Read-Only**, что означает, что пользователи (после открытия презентации) видят рекомендацию **Read-Only**. Этот пример кода показывает, как установить презентацию в режим **Read-Only** на C++ с использованием Aspose.Slides:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>();
pres->get_ProtectionManager()->set_ReadOnlyRecommended(true);
pres->Save(u"ReadOnlyPresentation.pptx", SaveFormat::Pptx);
```

{{% alert color="info" %}} 

**Примечание**: рекомендация **Read-Only** предназначена просто для того, чтобы отговорить от редактирования или предотвратить случайные изменения PowerPoint‑презентации. Если мотивированный человек — который знает, что делает — решит отредактировать вашу презентацию, он легко может снять настройку Read-Only. Если вам действительно нужно предотвратить несанкционированное редактирование, лучше использовать [более строгие защиты, включающие шифрование и пароли](https://docs.aspose.com/slides/ru/cpp/password-protected-presentation/). 

{{% /alert %}} 

## **FAQ**

### Чем отличается «Read-Only recommended» от полной защиты паролем?

`Read-Only recommended` только отображает предложение открыть файл в режиме только для чтения и легко обходится. [Защита паролем](/slides/ru/cpp/password-protected-presentation/) действительно ограничивает открытие или редактирование и подходит, когда необходимы реальные средства безопасности.

### Можно ли сочетать «Read-Only recommended» с водяными знаками для дальнейшего отпугивания правок?

Да. Рекомендацию можно сочетать с [водяными знаками](/slides/ru/cpp/watermark/) в качестве визуального отпугивания; они являются отдельными механизмами и хорошо работают вместе.

### Может ли макрос или внешнее средство всё ещё изменять файл, когда рекомендация включена?

Да. Рекомендация не блокирует программные изменения. Чтобы предотвратить автоматические правки, используйте [пароли и шифрование](/slides/ru/cpp/password-protected-presentation/).

### Как «Read-Only recommended» соотносится с флагами «is encrypted» и «is write protected»?

Это разные сигналы. `Read-Only recommended` — мягкое, необязательное предложение; [get_IsWriteProtected](https://reference.aspose.com/slides/ru/cpp/aspose.slides/protectionmanager/get_iswriteprotected/) и [get_IsEncrypted](https://reference.aspose.com/slides/ru/cpp/aspose.slides/protectionmanager/get_isencrypted/) указывают на реальные ограничения записи или чтения, зависящие от паролей или шифрования.
