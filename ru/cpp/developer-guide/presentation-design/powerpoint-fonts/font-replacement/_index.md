## **Обзор**

Aspose.Slides позволяет заменять один шрифт другим во всей презентации. При замене шрифта все вхождения исходного шрифта изменяются на новый шрифт.

Чтобы выполнить замену шрифта, загрузите презентацию, укажите исходный шрифт и шрифт‑заменитель, вызовите метод замены шрифта и сохраните изменённую презентацию как файл PPTX. Такой подход полезен, когда вы намеренно хотите переключить семью шрифтов во всей презентации.

## **Замена шрифтов**

Если вы решили не использовать шрифт, его можно заменить другим шрифтом. Все вхождения старого шрифта будут заменены новым шрифтом.

Aspose.Slides позволяет выполнить замену шрифта следующим образом:

1. Загрузите нужную презентацию.  
2. Загрузите шрифт, который будет заменён.  
3. Загрузите новый шрифт.  
4. Выполните замену шрифта.  
5. Сохраните изменённую презентацию как файл PPTX.

Этот C++‑код демонстрирует замену шрифтов:

``` cpp
// Загружает презентацию
auto presentation = System::MakeObject<Presentation>(u"Fonts.pptx");

// Загружает исходный шрифт, который будет заменён
auto sourceFont = System::MakeObject<FontData>(u"Arial");

// Загружает новый шрифт
auto destFont = System::MakeObject<FontData>(u"Times New Roman");

// Заменяет шрифты
presentation->get_FontsManager()->ReplaceFont(sourceFont, destFont);

// Сохраняет презентацию
presentation->Save(u"UpdatedFont_out.pptx", SaveFormat::Pptx);
```

{{% alert title="Note" color="warning" %}} 
Чтобы задать правила, определяющие, что происходит в определённых условиях (например, если шрифт недоступен), см. [**Подстановка шрифтов**](/slides/ru/cpp/font-substitution/).

## **FAQ**

**В чём разница между "заменой шрифтов", "подстановкой шрифтов" и "резервными шрифтами"?**

Замена — намеренный переход от одной семьи шрифтов к другой во всём документе. [Подстановка](/slides/ru/cpp/font-substitution/) — правило типа «если шрифт недоступен, использовать X». [Резервный шрифт](/slides/ru/cpp/fallback-font/) применяется выборочно для отдельных отсутствующих глифов, когда базовый шрифт установлен, но не содержит нужных символов.

**Применяется ли замена к мастер‑слайдам, макетам, заметкам и комментариям?**

Да. Замена влияет на все объекты презентации, использующие исходный шрифт, включая мастер‑слайды и заметки; комментарии также являются частью документа и учитываются шрифтовым движком.

**Изменится ли шрифт внутри встроенных OLE‑объектов (например, Excel)?**

Нет. [OLE‑контент](/slides/ru/cpp/manage-ole/) управляется своим приложением. Замена в презентации не переоформляет внутренние данные OLE; они могут отображаться как изображение или как внешне редактируемый контент.

**Можно ли заменить шрифт только в части презентации (по слайдам или областям)?**

Целевая замена возможна, если менять шрифт на уровне требуемых объектов/диапазонов, а не применять глобальную замену ко всему документу. Общая логика выбора шрифта при рендеринге остаётся той же.

**Как заранее определить, какие шрифты использует презентация?**

Используйте [менеджер шрифтов]https://reference.aspose.com/slides/ru/cpp/aspose.slides/fontsmanager/: он предоставляет список [используемых семейств]https://reference.aspose.com/slides/ru/cpp/aspose.slides/fontsmanager/getfonts/ и информацию о [подстановках/«неизвестных» шрифтах]https://reference.aspose.com/slides/ru/cpp/aspose.slides/fontsmanager/getsubstitutions/, что помогает планировать замену.

**Работает ли замена шрифтов при преобразовании в PDF/изображения?**

Да. При экспорте Aspose.Slides применяет ту же [последовательность выбора/подстановки шрифтов](/slides/ru/cpp/font-selection-sequence/), поэтому заранее выполненная замена будет учтена при конвертации.

**Нужно ли устанавливать целевой шрифт в системе или можно подключить папку со шрифтами?**

Установка не требуется: библиотека позволяет [загружать внешние шрифты](/slides/ru/cpp/custom-font/) из пользовательских папок для использования при [рендеринге и экспорте](/slides/ru/cpp/convert-powerpoint/).

**Исправит ли замена проблему «тофу» (квадратики вместо символов)?**

Только если целевой шрифт действительно содержит необходимые глифы. Если нет, [настройте резервный шрифт](/slides/ru/cpp/fallback-font/) для покрытия недостающих символов.
