## **Введение**

В этой статье собрана информация, обычно необходимая для проверки безопасности приложения, использующего Aspose.Slides for Java: как библиотека обрабатывает презентации, что она добавляет к зависимостям вашего проекта, как проверить, что JAR‑файл поступает от Aspose, и какие сторонние компоненты содержатся в JAR‑файле.

## **Безопасность в Aspose.Slides**

* Aspose.Slides for Java используется для создания, изменения и конвертации презентаций. Он не исполняет сценарии в презентациях. Aspose.Slides разбирает структуру презентации и позволяет вашему коду работать с объектной моделью.
* Aspose.Slides функционирует как библиотека, которая разбирает и интерпретирует документы без выполнения удалённого кода. Все продукты Aspose работают на ваших машинах. Они не передают никаких данных в Aspose. Единственное исключение — [metered licensing](/slides/ru/java/metered-licensing/): если вы используете его, обрабатывается только информация об использовании вашего API.
* Компоненты Aspose работают в том же пользовательском контексте, что и обычные приложения. Поэтому компоненты Aspose не представляют угрозу важным системным ресурсам. Кроме того, при открытии документа компонентом Aspose макросы не запускаются автоматически.

## **Зависимости Maven**

Maven‑артефакт Aspose.Slides for Java, `com.aspose:aspose-slides`, не объявляет зависимостей: его POM‑файл содержит только координаты самого артефакта. Когда вы добавляете его в проект, Maven добавляет только этот один JAR‑файл и ничего более. Чтобы вывести список всех артефактов, которые разрешает ваш проект, включая транзитивные зависимости, выполните эту команду в каталоге проекта:

```bash
mvn dependency:tree
```

В проекте из [Installation](/slides/ru/java/installation/) вывод показывает Aspose.Slides как единственную зависимость:

```text
[INFO] com.example:hello-slides:jar:1.0
[INFO] \- com.aspose:aspose-slides:jar:jdk16:26.9:compile
```

## **Проверка JAR‑файла**

Aspose подписывает JAR‑файл. Чтобы проверить подпись, запустите инструмент `jarsigner` из JDK в каталоге, содержащем JAR‑файл:

```bash
jarsigner -verify aspose-slides-26.9-jdk16.jar
```

Команда выводит `jar verified.`, когда подпись действительна и ни одна запись не изменилась после подписания файла. Это сообщение не указывает подписанта. Чтобы подтвердить, что файл подписан Aspose, добавьте параметры `-verbose` и `-certs` и проверьте, что сертификат подписанта выдан `CN=ASPOSE PTY LTD`. При загрузке JAR‑файла Maven также проверяет SHA‑1 контрольную сумму, опубликованную репозиторием рядом с файлом.

## **Сторонние компоненты**

Aspose.Slides for Java включает код и данные сторонних компонентов. Они находятся внутри JAR‑файла, а не в отдельных Maven‑артефактах, поэтому `mvn dependency:tree` и другие инструменты, читающие зависимости Maven, их не отображают. JAR‑файл содержит уведомление *META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf*, в котором перечислены компоненты и их лицензии:

| Компонент | Лицензия, указанная в уведомлении |
|---|---|
| DotNetZip | Microsoft Public License (Ms-PL) |
| Bouncy Castle | MIT-style license |
| Mono | MIT license; некоторые части под другими лицензиями, перечисленными в уведомлении |
| RSWOP.ICM color profile | Условия лицензии Microsoft |
| sRGB_v4_ICC_preference.icc color profile | Разрешение ICC на использование, копирование и распространение неизменённого файла |
| Apache | Apache License 2.0 |
| ANTLR | BSD License |
| sfntly | Apache License 2.0 |

Чтобы извлечь уведомление из JAR‑файла, запустите инструмент `jar` из JDK в каталоге, содержащем JAR‑файл:

```bash
jar xf aspose-slides-26.9-jdk16.jar "META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf"
```

## **Часто задаваемые вопросы**

**Использует ли Aspose.Slides for Java внешние пакеты?**

У него нет Maven‑зависимостей, как показано в разделе [Maven Dependencies](#maven-dependencies), но он включает сторонние компоненты, перечисленные в разделе [Third-Party Components](#third-party-components). Включите как JAR‑файл, так и эти компоненты в вашу проверку безопасности.

**Нужен ли Aspose.Slides for Java доступ к сети?**

Нет. Создание, сохранение и визуализация презентаций работают в системе без сетевого подключения. Единственная функция, отправляющая данные в Aspose, — [metered licensing](/slides/ru/java/metered-licensing/), которая сообщает об использовании API.

**Содержит ли Aspose.Slides for Java нативный код?**

Нет. JAR‑файл содержит только Java‑классы и ресурсы, поэтому он не добавляет нативных библиотек в ваше приложение. В Linux поддержка шрифтов в среде выполнения Java требует библиотеку fontconfig и шрифты из операционной системы; см. [System Requirements](/slides/ru/java/system-requirements/#linux).
