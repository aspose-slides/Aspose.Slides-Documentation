{{% alert color="info" title="Примечание" %}}

Статьи в этом разделе являются более старыми обзорами отдельных форматов файлов, сохранёнными для существующих ссылок. Они не описывают текущую версию Aspose.Slides for Java. Для форматов, которые Aspose.Slides for Java загружает, импортирует, сохраняет и рендерит, а также API для каждого из них, см. [Supported File Formats](/slides/ru/java/supported-file-formats/). Для руководств по конвертации см. [Convert Presentations](/slides/ru/java/convert-presentation/).
