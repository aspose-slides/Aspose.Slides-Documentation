{{% alert color="info" %}} 

PDF (Portable Document Format) — это файловый формат, созданный компанией Adobe Systems для обмена документами между организациями. Цель формата — сохранить содержимое и раскладку одинаковыми независимо от платформы, на которой документ просматривается. Aspose.Slides for Java позволяет конвертировать файлы презентаций в PDF.

{{% /alert %}} 

## **PDF в Aspose.Slides for Java**
Любая презентация, которую можно загрузить в Aspose.Slides for Java, может быть преобразована в PDF, соответствующий [PDF 1.5](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) или [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) в зависимости от вашего выбора. Aspose.Slides for Java экспортирует презентации в PDF, и в большинстве случаев полученный PDF выглядит точно так же, как оригинальная презентация.

Aspose.Slides поддерживает следующие элементы презентации при конвертации в PDF:

- Изображения, текстовые блоки и другие фигуры.
- Текст и его форматирование.
- Абзацы и их форматирование.
- Гиперссылки.
- Колонтитулы.
- Маркеры.
- Таблицы.

Вы можете экспортировать презентации в PDF непосредственно с помощью Aspose.Slides for Java: никаких дополнительных компонентов не требуется. Кроме того, вы можете настроить экспорт презентации в PDF с помощью различных параметров, как описано в [Конвертация в PDF](/slides/ru/java/converting-a-presentation/).
