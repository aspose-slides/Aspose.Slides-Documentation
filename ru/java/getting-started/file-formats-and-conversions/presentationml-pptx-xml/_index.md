PresentationML — это название семейства XML‑основанных форматов для презентационных документов. Office OpenXML (OOXML) — XML‑формат, представленный в приложениях Microsoft Office 2007. Office OpenXML является контейнерным форматом для нескольких специализированных XML‑языков разметки. PresentationML — язык разметки, используемый Microsoft Office PowerPoint 2007 для хранения документов.

{{% /alert %}}

## **PresentationML в Aspose.Slides for Java**
Документы OOXML PresentationML представлены в виде файлов PPTX, упакованных ZIP‑архивом XML‑пакетов, соответствующих спецификации [OOXML ECMA-376](https://ecma-international.org/publications-and-standards/standards/ecma-376/). Aspose.Slides for Java широко поддерживает создание, чтение, изменение и запись документов PresentationML. Кроме того, Aspose.Slides for Java может экспортировать документы PresentationML в широко используемый формат PDF. Это возможно, потому что Aspose.Slides for Java разрабатывался с целью всесторонней работы с презентационными документами, а PresentationML по‑сути хранит внутреннее представление документов в виде ZIP‑архива XML.

## **PresentationML открыт, почему использовать Aspose.Slides for Java?**
Поскольку PresentationML основан на XML, вполне возможно создавать приложения для обработки и генерации документов PresentationML, используя XML‑классы без обращения к сторонним библиотекам, таким как Aspose.Slides for Java. Однако использование Aspose.Slides for Java имеет несколько преимуществ перед XML‑классами при работе с документами PresentationML.

Спецификация OOXML насчитывает несколько тысяч страниц, поэтому для правильной работы с документами PresentationML требуется потратить значительное время и усилия на изучение формата. С Aspose.Slides for Java вы просто используете классы, их методы и свойства для выполнения операций, которые выглядели бы сложными при работе через XML‑классы.

Некоторые функции, предлагаемые Aspose.Slides, даже недоступны при работе с документами PresentationML через XML‑классы:

- Экспортировать документы PPT в формат PDF.
- Отрисовывать слайд в любой графический формат, поддерживаемый Java‑фреймворком.
- Автоматически копировать шаблоны из исходной презентации с помощью функции клонирования.
- Применять защиту к объектам.

Ниже приведён пример документа PresentationML с одним слайдом, содержащим текстовое поле с текстом «Hello World». Чтобы считать текст с помощью XML‑классов, необходимо написать программу, которая разбирает этот простой фрагмент. Aspose.Slides делает это за вас.

**XML**

``` xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<p:sld xmlns:a="http://schemas.openxmlformats.org/drawingml/2006/main" xmlns:r="http://schemas.openxmlformats.org/officeDocument/2006/relationships" xmlns:p="http://schemas.openxmlformats.org/presentationml/2006/main">
  <p:cSld>
    <p:spTree>
      <p:nvGrpSpPr>
        <p:cNvPr id="1" name=""/>
        <p:cNvGrpSpPr/>
        <p:nvPr/>
      </p:nvGrpSpPr>
      <p:grpSpPr>
        <a:xfrm>
          <a:off x="0" y="0"/>
          <a:ext cx="0" cy="0"/>
          <a:chOff x="0" y="0"/>
          <a:chExt cx="0" cy="0"/>
        </a:xfrm></p:grpSpPr><p:sp>
          <p:nvSpPr><p:cNvPr id="4" name="TextBox 3"/>
          <p:cNvSpPr txBox="1"/>
            <p:nvPr/>
          </p:nvSpPr>
          <p:spPr>
            <a:xfrm>
              <a:off x="2819400" y="2590800"/>
              <a:ext cx="1297086" cy="369332"/>
            </a:xfrm>
            <a:prstGeom prst="rect">
              <a:avLst/>
            </a:prstGeom>
            <a:noFill/>
          </p:spPr>
          <p:txBody>
            <a:bodyPr wrap="none" rtlCol="0">
              <a:spAutoFit/>
            </a:bodyPr>
            <a:lstStyle/>
            <a:p>
              <a:r>
                <a:rPr lang="en-US"/>
                <a:t>Hello World
                </a:t>
              </a:r>
              <a:endParaRPr lang="en-US"/>
            </a:p>
          </p:txBody>
        </p:sp>
    </p:spTree>
  </p:cSld>
  <p:clrMapOvr>
    <a:masterClrMapping/>
  </p:clrMapOvr>
</p:sld>
```
