{{% alert color="info" %}} 

[Спецификация XML‑парсера](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) — это язык описания страниц и формат фиксированных документов, изначально разработанный Microsoft. Как и PDF, XPS предназначен для сохранения точности документа и обеспечения независимого от устройства отображения. 

{{% /alert %}} 

## **XPS в Aspose.Slides for Java**
Любой файл презентации, который может быть загружен Aspose.Slides for Java, может быть преобразован в формат XPS. Aspose.Slides for Java использует высокоточный движок разметки страниц и рендеринга для создания вывода в формате фиксированного макета XPS.
Подробнее о экспорте презентаций в XPS через Aspose.Slides for Java можно узнать в [Конвертация в XPS](https://docs.aspose.com/slides/ru/java/convert-powerpoint-to-xps/).
