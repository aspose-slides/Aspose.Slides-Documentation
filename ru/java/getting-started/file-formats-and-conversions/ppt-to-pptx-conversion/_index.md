## **Поддерживаемые функции при конвертации**
Aspose.Slides for Java предоставляет частичную поддержку преобразования формата файлов PPT в PPTX. Поддержка конвертации только что была введена в Aspose.Slides for Java, поэтому она имеет несколько ограничений и лучше всего работает с простыми презентациями. Основное преимущество Aspose.Slides for Java при конвертации PPT в PPTX — простота использования API. Примеры кода можно посмотреть в [Convert PPT to PPTX](/slides/ru/java/convert-ppt-to-pptx/). ## **Поддерживаемые функции**
Следующие функции поддерживаются при конвертации:

- Преобразование структуры мастеров, макетов и слайдов.
- Преобразование диаграмм.
- Группировка фигур.
- Преобразование автофигур, включая прямоугольники и эллипсы.
- Фигуры с пользовательской геометрией.
- Текстуры и стили заливки изображениями для автофигур.
- Преобразование заполнителей.
- Преобразование линий и полилиний.
- Форматы линий и заливок.
- Стили градиентной заливки.
- OLE‑кадры, таблицы, видеокадры и аудиокадры и т.д.
- Свойства анимации и слайд‑шоу.
- Преобразование текста в текстовых кадрах и держателях текста.
