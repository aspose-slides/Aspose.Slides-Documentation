Конвертация PPT в PPTX поддерживается в Aspose.Slides for Java. Большинство функций презентации — мастер‑слайды, структура и т.д. — сохраняются при преобразовании из одного формата в другой, но существуют [несколько ограничений](/slides/ru/java/ppt-to-pptx-conversion/).
{{% /alert %}} 
## **Поддерживаемые функции при преобразовании**
Aspose.Slides for Java предоставляет частичную поддержку преобразования формата файлов PPT в PPTX. Поддержка конвертации только что была введена в Aspose.Slides for Java, поэтому она имеет несколько ограничений и лучше всего подходит для простых презентаций. Основное преимущество Aspose.Slides for Java при конвертации PPT в PPTX — простота использования API. Чтобы увидеть примеры кода, прочитайте статью о [Конвертации PPT в PPTX](). Ниже приведены списки, объясняющие, какие функции поддерживаются, а какие нет при конвертации PPT в PPTX.

## **Поддерживаемые функции**
Следующие функции поддерживаются при конвертации:

- Преобразование структуры мастеров, макетов и слайдов.
- Преобразование диаграмм.
- Групповые фигуры.
- Преобразование автофигур, включая прямоугольники и эллипсы. 
- Фигуры с пользовательской геометрией.
- Текстурные и изображенческие стили заливки для автофигур.
- Преобразование заполнителей.
- Преобразование линий и полилиний.
- Форматы линий и заливок.
- Стили градиентной заливки.
- OLE‑кадры, таблицы, видеокадры и аудиокадры и т.д.
- Свойства анимации и слайдшоу.
- Преобразование текста в текстовых кадрах и текстовых контейнерах.
