{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) — формат файла презентаций, который может быть создан, прочитан, изменён и записан различными версиями Microsoft PowerPoint. Это бинарный формат для презентационных документов, разработанный Microsoft.

{{% /alert %}} 

## **PPT в Aspose.Slides for Java**
Aspose.Slides for Java может читать файлы PPT, созданные указанным ниже программным обеспечением.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Аналогично, файлы PPT, созданные Aspose.Slides for Java, могут быть прочитаны перечисленными выше программами.

## **Полная поддержка PPT**
Aspose.Slides for Java предоставляет поддержку почти всех возможностей формата файла PPT. Он охватывает как базовые, так и расширенные функции различных версий Microsoft PowerPoint для работы с документами PPT, а также функции, которые даже не поддерживаются Microsoft PowerPoint. Главное преимущество использования библиотеки API Aspose.Slides for Java — простота работы с такими возможностями.

Помимо базовых задач по созданию, чтению и записи файлов PPT, Aspose.Slides for Java предоставляет ряд дополнительных возможностей:

- Импортировать другие форматы файлов Microsoft Office в виде [OLE‑объекты в PPT‑документы]().
- [Экспортировать PPT‑документы в PDF](/slides/ru/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- Экспортировать слайды из PPT‑документов в форматы SVG.
- Рендерить слайды в любой графический формат, поддерживаемый Java Framework.
- Задавать размер слайдов в PPT‑документах.
- Управлять анимациями фигур.
- Управлять слайд‑шоу.
- [Форматировать текст на слайдах]().
- Извлекать текст из PPT‑документов.
- [Работать с таблицами на слайдах]().
- Автоматически копировать мастер‑страницы с помощью [функцию клонирования]().
