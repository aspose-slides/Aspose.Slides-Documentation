## **Обзор**

Выполните четыре приведённых ниже шага последовательно. Каждый шаг указывает, что нужно сделать, и содержит ссылку на статью с подробностями. Оценка, лицензирование и поддержка рассматриваются после шагов.

## **Шаг 1: Проверьте системные требования**

Aspose.Slides for Java — это один файл JAR без нативного кода, поэтому он работает на любой операционной системе с поддерживаемой Java‑runtime. [Системные требования](/slides/ru/java/system-requirements/) перечисляет поддерживаемые операционные системы и версии Java. Для проекта и команд в последующих шагах требуется JDK 11 или новее, а для пути Maven — [Apache Maven](https://maven.apache.org/install.html).

## **Шаг 2: Добавьте библиотеку в проект**

Aspose.Slides for Java публикуется в собственном репозитории Maven от Aspose, а не в Maven Central. Выберите один из следующих вариантов:

- С Maven: объявите репозиторий `https://releases.aspose.com/java/repo/` в вашем *pom.xml* и добавьте зависимость `com.aspose:aspose-slides` с классификатором `jdk16`.
- Без Maven: скачайте файл JAR, имя которого заканчивается на *-jdk16.jar*, из репозитория и поместите его в путь к классам.

В Linux также установите библиотеку fontconfig и хотя бы один шрифт. Без них сохранение презентации завершится ошибкой «Fontconfig head is null, check your fonts or fonts configuration».

[Установка](/slides/ru/java/installation/) предоставляет записи для *pom.xml*, загрузку JAR и команду для Linux.

## **Шаг 3: Создайте первую презентацию**

[Быстрый старт на главной странице Aspose.Slides for Java](/slides/ru/java/#your-first-presentation) представляет собой готовый Maven‑проект: файл *pom.xml* и программу, которая добавляет облачную форму с текстом на слайд и сохраняет презентацию в файл PPTX. Запустить её можно командой `mvn compile exec:java`. [Создание презентаций](/slides/ru/java/create-presentation/) подробно объясняет эту программу шаг за шагом. Чтобы открыть существующую презентацию и сохранить её в другом формате, см. [Открытие презентаций](/slides/ru/java/open-presentation/) и [Сохранение презентаций](/slides/ru/java/save-presentation/).

## **Оценка и лицензирование**

Без лицензии Aspose.Slides работает в режиме оценки: он добавляет водяной знак к каждому сохраняемому слайду и обрезает текст, который ваш код читает из презентаций.

- [Оценить Aspose.Slides](/slides/ru/java/evaluate-aspose-slides/) описывает ограничения оценки и то, как запросить временную лицензию.
- [Лицензирование](/slides/ru/java/licensing/) показывает, как применить лицензию из файла или потока.
- [Лицензирование по мере использования](/slides/ru/java/metered-licensing/) охватывает лицензии, оплачиваемые по использованию.
- [Поддерживаемые форматы файлов](/slides/ru/java/supported-file-formats/) перечисляет форматы, которые Aspose.Slides может загружать и сохранять.

## **Часто задаваемые вопросы**

**Нужен ли установленный Microsoft PowerPoint?**

Нет. Aspose.Slides самостоятельно читает и записывает файлы презентаций и не использует PowerPoint, поэтому он также работает на серверах и в Linux.

**Почему Maven не находит Aspose.Slides for Java?**

Библиотека не находится в Maven Central. Объявите репозиторий Aspose в вашем *pom.xml*, как показано в [Установка](/slides/ru/java/installation/), и Maven загрузит библиотеку оттуда.

**Означает ли классификатор `jdk16`, что библиотеке нужен Java 16?**

Нет. Классификатор выбирает сборку библиотеки для Java SE; другая сборка предназначена для Android. Эта же сборка работает на текущих JDK, например JDK 21.
