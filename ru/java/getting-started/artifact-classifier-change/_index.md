## Изменение классификатора артефактов с `jdk16` на `jdk8`

Начиная с версии **26.10**, мы изменили классификатор, используемый в публикуемых артефактах, с **`jdk16`** (Java 6) на **`jdk8`** (Java 8).

### Что изменилось

| | До | После |
|---|---|---|
| Классификатор | `jdk16` | `jdk8` |
| Минимальная версия Java | Java 1.6 | Java 8 |

**До:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**После:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### Почему мы внесли это изменение

После внутреннего обзора мы решили **отказаться от поддержки более старых версий Java**, которые перестали приносить пользу и активно мешали обслуживанию. Java 8 была выбрана в качестве новой безопасной базовой версии для всех потребителей.

В рамках этого классификатор был обновлён, чтобы отражать фактическую минимально поддерживаемую версию. Мы также привели его в соответствие с текущей номенклатурой Oracle, где продукт официально называется **JDK 8** (в отличие от устаревшего формата `1.8`).

### Что вам нужно сделать

1. **Обновите классификатор** в ваших декларациях зависимостей с `jdk16` на `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **Проверьте, что ваша среда выполнения** использует Java 8 или выше.

3. **Обновите любые lock‑файлы** или кэши зависимостей, которые фиксируют старый классификатор.

### Примечание к миграции: jdk16 и jdk8

Начиная с версии 26.10, оба классификатора jdk16 и jdk8 будут предоставлять совместимые с Java 8 JAR‑файлы (скомпилированные с настройкой source/target, соответствующей Java 8).

- `jdk16` → продолжит публиковаться для обратной совместимости (существующие интеграции).
- `jdk8` → введён в качестве нового предпочтительного классификатора для сред Java 8.

⚠️ Примечание: Эта фаза двойной публикации запланирована к завершению 31 марта 2027 года. После этой даты классификатор jdk16 будет прекращён, и будет поддерживаться только jdk8.

### Примечания к совместимости

- `jdk16` классификатор **больше не публикуется** после **31 марта 2027**.
- Если вам всё ещё требуется поддержка Java 1.6, пожалуйста, оставайтесь на предыдущей мажорной версии, пока не сможете выполнить миграцию.

### Нужна помощь?

Если вы сталкиваетесь с проблемами во время миграции, пожалуйста, свяжитесь с [службой поддержки Aspose](https://forum.aspose.com/) для получения дополнительной помощи.
