## **Изменение классификатора артефактов с `jdk16` на `jdk8`**

Начиная с версии **26.10**, мы изменили классификатор, используемый в публикуемых артефактах, с **`jdk16`** (Java 6) на **`jdk8`** (Java 8).

### **Что изменилось**

| | До | После |
|---|---|---|
| Классификатор | `jdk16` | `jdk8` |
| Минимальная версия Java | Java 1.6 | Java 8 |

**До:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**После:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **Почему мы внесли это изменение**

После внутреннего обзора мы решили **отказаться от поддержки старых версий Java**, которые больше не приносили пользы и активно усложняли обслуживание. Java 8 была выбрана в качестве новой безопасной базовой версии для всех потребителей.

В рамках этого классификатор был обновлён, чтобы отражать фактическую минимально поддерживаемую версию. Мы также привели название в соответствие с текущей конвенцией Oracle, где продукт официально называется **JDK 8** (а не устаревший формат `1.8`).

### **Что вам нужно сделать**

1. **Обновить классификатор** в декларациях зависимостей с `jdk16` на `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **Убедиться, что ваша среда выполнения** — Java 8 или выше.

3. **Обновить любые lock-файлы** или кэши зависимостей, привязывающие старый классификатор.

### **Замечание по миграции: jdk16 и jdk8**

Начиная с версии 26.10, оба классификатора jdk16 и jdk8 будут предоставлять JAR‑файлы, совместимые с Java 8 (с установленной совместимостью source/target = Java 8).

- `jdk16` → продолжит публиковаться для обратной совместимости (существующие интеграции).
- `jdk8` → введён как новый предпочтительный классификатор для окружений Java 8.

⚠️ Примечание: Эта фаза двойного опубликования запланирована до 31 марта 2027 года. После этой даты классификатор jdk16 будет снят, и поддерживаться будет только jdk8.

### **Заметки о совместимости**

- Классификатор `jdk16` **больше не будет публиковаться** после **31 марта 2027**.
- Если вам всё ещё требуется поддержка Java 1.6, пожалуйста, оставайтесь на предыдущей мажорной версии, пока не сможете мигрировать.

### **Нужна помощь?**

Если у вас возникнут проблемы во время миграции, пожалуйста, обратитесь к [Поддержка Aspose](https://forum.aspose.com/) для получения дальнейшей помощи.
