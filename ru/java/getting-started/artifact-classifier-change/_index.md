## **Изменение классификатора артефакта с `jdk16` на `jdk8`**

Начиная с версии **26.10**, мы изменили классификатор, используемый в наших опубликованных артефактах, с **`jdk16`** (Java 6) на **`jdk8`** (Java 8).

### **Что изменилось**

| | До | После |
|---|---|---|
| Классификатор | `jdk16` | `jdk8` |
| Минимальная версия Java | Java 1.6 | Java 8 |

**До:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**После:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **Зачем мы сделали это изменение**

После внутреннего обзора мы решили **отказаться от поддержки более старых версий Java**, которые больше не приносили пользы и активно мешали обслуживанию. Java 8 была выбрана в качестве новой, безопасной базовой версии для всех потребителей.

В рамках этого классификатор был обновлён, чтобы отражать фактическую минимально поддерживаемую версию. Мы также привели его в соответствие с текущей конвенцией именования Oracle, где продукт официально называется **JDK 8** (а не устаревший формат `1.8`).

### **Что вам нужно сделать**

1. **Обновите классификатор** в декларациях зависимостей с `jdk16` на `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **Проверьте, что ваша среда выполнения** — Java 8 или выше.

3. **Обновите любые lock‑файлы** или кэши зависимостей, фиксирующие старый классификатор.

### **Примечание к миграции: jdk16 и jdk8**

Начиная с версии 26.10​, оба классификатора jdk16 и jdk8 будут поставлять JAR‑файлы, совместимые с Java 8 (сборка с установленной совместимостью source/target на Java 8).

 - `jdk16` → по‑прежнему публикуется для обратной совместимости (существующие интеграции).
 - `jdk8` → введён как новый предпочтительный классификатор для сред Java 8.

⚠️ Примечание: Эта фаза двойной публикации запланирована до 31 марта 2027 года. После этой даты классификатор jdk16 будет снят, и будет поддерживаться только jdk8.

### **Примечания о совместимости**

- Классификатор `jdk16` **больше не публикуется** после **31 марта 2027 года**.
- Если вам всё ещё нужна поддержка Java 1.6, пожалуйста, оставайтесь на предыдущей основной ветке версии, пока не сможете выполнить миграцию.

### **Нужна помощь?**

Если вы столкнётесь с проблемами во время миграции, пожалуйста, обратитесь в [поддержку Aspose](https://forum.aspose.com/) за дальнейшей помощью.
