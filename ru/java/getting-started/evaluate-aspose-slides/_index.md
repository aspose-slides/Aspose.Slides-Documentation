## **Оценка Aspose.Slides**

Вы можете скачать Aspose.Slides для оценки. Оценочный скачивание такое же, как и купленное; оно становится лицензированным после того, как вы добавите несколько строк кода для применения лицензии.

Без лицензии Aspose.Slides предоставляет всю свою функциональность в режиме оценки, но с двумя ограничениями: он добавляет текстовое поле водяного знака оценки на каждый слайд каждой презентации при сохранении, а текст, который ваш код читает через API, включая только что установленный текст, обрезается до первых нескольких символов с последующим уведомлением об ограничении оценки. Текст, который ваш код записывает, сохраняется полностью. Метод [getPresentationText](https://reference.aspose.com/slides/ru/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) который извлекает текст без загрузки всей презентации, возвращает только уведомления об оценке и не содержит текста слайдов.

## **FAQ**

### Можно ли тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует использовать один и тот же объект презентации [across threads](/slides/ru/java/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — это автономный движок и не требует установки PowerPoint ни для оценки, ни для производства.

### Можно ли полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [converters](/slides/ru/java/convert-presentation/) работают; вывод будет содержать водяной знак.

### Можно ли использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия устраняет ограничения режима оценки и позволяет тестировать без водяного знака.
