## **Оценка Aspose.Slides**

Вы можете загрузить Aspose.Slides для оценки. Загрузка для оценки идентична платной загрузке; она становится лицензированной после того, как вы добавите несколько строк кода для применения лицензии.

Без лицензии Aspose.Slides предоставляет всю свою функциональность в режиме оценки, с двумя ограничениями: он добавляет текстовое поле с водяным знаком оценки на каждый слайд каждой презентации при сохранении, а текст, который ваш код читает через API, включая только что установленный, обрезается до первых нескольких символов, после чего следует уведомление об ограничении оценки. Текст, записываемый вашим кодом, сохраняется полностью. Метод [getPresentationText](https://reference.aspose.com/slides/ru/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) , который извлекает текст без загрузки всей презентации, возвращает только уведомления об оценке и не содержит текста слайдов.

## **FAQ**

### Можно ли тестировать несколько презентаций параллельно в разных потоках в режиме оценки?

Да. Вы можете обрабатывать разные документы параллельно; не следует использовать один и тот же объект презентации [across threads](/slides/ru/java/multithreading/). Режим оценки не влияет на это.

### Нужно ли устанавливать Microsoft PowerPoint для оценки библиотеки на сервере или в CI?

Нет. Aspose.Slides — это автономный движок и не требует установленного PowerPoint ни для оценки, ни для производства.

### Можно ли полностью протестировать конвертацию PPT/PPTX в PDF и изображения в режиме оценки?

Да. [converters](/slides/ru/java/convert-presentation/) работают; вывод будет включать водяной знак.

### Можно ли использовать временную лицензию для нагрузочного тестирования без водяного знака?

Да. 30‑дневная временная лицензия удаляет ограничения режима оценки и позволяет тестировать без водяного знака.
