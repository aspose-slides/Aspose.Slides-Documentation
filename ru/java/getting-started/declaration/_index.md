## **Обзор**

Менеджер безопасности Java ограничивает, что код может делать, в соответствии с политикой безопасности. В Java 17 он был помечен как устаревший для последующего удаления ([JEP 411](https://openjdk.org/jeps/411)), а в Java 24 навсегда отключён ([JEP 486](https://openjdk.org/jeps/486)). Эта статья объясняет, что требуется Aspose.Slides for Java, когда приложение всё ещё работает с менеджером безопасности. Если ваше приложение не включает его, что является настройкой по умолчанию, конфигурировать ничего не нужно.

## **Java 23 и более ранние версии**

Когда менеджер безопасности включён, политика безопасности должна предоставлять следующие разрешения файлу JAR Aspose.Slides и коду приложения, которое его вызывает:

- `java.util.PropertyPermission "*", "read"`: Aspose.Slides читает системные свойства.
- `java.io.FilePermission "<<ALL FILES>>", "read"`: Aspose.Slides читает файлы шрифтов и другие файлы.
- `java.io.FilePermission "<<ALL FILES>>", "execute"`: Aspose.Slides запускает программы операционной системы, например `reg` в Windows и `fc-match` в Linux.
- `java.io.FilePermission` с действием `write` для папок, куда ваше приложение сохраняет файлы.

Предоставление разрешений только файлу JAR недостаточно: код, вызывающий Aspose.Slides, также нуждается в них. Предоставление `java.security.AllPermission` обоим тоже работает.

Без разрешения на чтение системных свойств или запуск программ Aspose.Slides падает при первом использовании: создание объекта [Presentation](https://reference.aspose.com/slides/ru/java/com.aspose.slides/presentation/) бросает `ExceptionInInitializerError`. Без доступа к чтению файлов шрифтов сохранение презентации в PDF завершается ошибкой «Cannot find any fonts installed on the system».

## **Java 24 и более поздние версии**

Менеджер безопасности нельзя включить в Java 24 и позже, поэтому нет разрешений для предоставления. Aspose.Slides работает с правами учетной записи, под которой запущено ваше приложение. Чтобы ограничить доступ приложения, проект OpenJDK рекомендует использовать технологии вне JDK, такие как контейнеры, гипервизоры и функции изоляции операционной системы. См. [JEP 486](https://openjdk.org/jeps/486).

## **FAQ**

**Могу ли я использовать Aspose.Slides в среде, где приложения работают под ограничительной политикой менеджера безопасности?**

Только если политика предоставляет перечисленные выше разрешения как Aspose.Slides, так и коду, который его вызывает. Они включают чтение всех файлов и запуск любой программы.
