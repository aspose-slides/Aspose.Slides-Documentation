{{% alert color="info" %}} 

Все компоненты Aspose Java требуют набор разрешений Full Trust. Причина в том, что компонентам Aspose Java необходимо получать доступ к настройкам реестра, системным файлам за пределами виртуального каталога для некоторых операций, таких как разбор шрифтов и т.п. Кроме того, компоненты Aspose Java основаны на базовых классах системы Java, которые также во многих случаях требуют набор разрешений Full Trust. 

{{% /alert %}} 

Интернет‑провайдеры, размещающие несколько приложений разных компаний, в основном применяют уровень безопасности Medium Trust: 

- OleDbPermission недоступен. Это означает, что вы не можете использовать управляемый провайдер данных ADO.NET OLE DB для доступа к базам данных.
- EventLogPermission недоступен. Это означает, что вы не можете получить доступ к журналу событий Windows.
- ReflectionPermission недоступен. Это означает, что вы не можете использовать рефлексию.
- RegistryPermission недоступен. Это означает, что вы не можете получить доступ к реестру.
- WebPermission ограничен. Это означает, что ваше приложение может обращаться только к адресу или диапазону адресов, которые вы определяете в элементе <trust>.
- FileIOPermission ограничен. Это означает, что вы можете обращаться только к файлам в иерархии виртуального каталога вашего приложения.

{{% alert color="info" %}} 

По вышеуказанным причинам компоненты Aspose Java нельзя использовать на серверах, предоставляющих набор разрешений, отличный от Full Trust. 

{{% /alert %}}
