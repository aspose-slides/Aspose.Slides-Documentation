Это историческая страница. Она описывает ошибку в Aspose.Slides for Java версиях 23.2‑23.7, выпущенных в 2023 году, и версии, в которых она была исправлена. Текущая версия не описывается. Для информации о лицензировании в текущей версии см. [Лицензирование](/slides/ru/java/licensing/).

{{% /alert %}}

## **Обзор**

В этой статье описывается ошибка лицензирования, обнаруженная в Aspose.Slides for Java версиях 23.2, 23.3, 23.4, 23.5, 23.6 и 23.7. Эта ошибка приводила к тому, что постоянные лицензии становились временно недоступными после истечения их подписки.

## **Симптомы**

После истечения срока действия вашей постоянной лицензии, версии Aspose.Slides for Java 23.2 - 23.7 могут сообщать, что лицензия истекла, переводя все функции в режим оценки. Такое поведение некорректно и не затрагивает версии до 23.2 и после 23.7.

## **Решение**

Aspose.Slides for Java устранил эту проблему и выпустил обновлённые версии (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) с исправлением.

Если вы используете одну из затронутых версий Aspose.Slides for Java в своём проекте, перейдите на исправленную версию.

Если вы сталкиваетесь с проблемами лицензирования Aspose.Slides for Java:

- Проверьте используемую версию и убедитесь, что она не подпадает под описанную выше ошибку.
- Обратитесь к [Лицензирование](/slides/ru/java/licensing/) для получения инструкций по применению и проверке лицензии.
- Свяжитесь с [поддержкой Aspose](https://forum.aspose.com/c/slides/ru/11) для дальнейшей помощи.

## **Затронутые продукты и версии**

Обратите внимание, что эта ошибка затрагивает только версии Aspose.Slides for Java 23.2‑23.7. **Другие продукты Aspose и другие версии Aspose.Slides не затронуты**.
