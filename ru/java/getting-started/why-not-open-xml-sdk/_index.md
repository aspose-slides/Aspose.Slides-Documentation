## **Обзор**

В этой статье объясняется, когда разработчики могут выбрать Open XML SDK или Aspose.Slides для работы с документами презентаций. Она описывает Open XML SDK как библиотеку для управления пакетами OOXML и их базовыми XML‑элементами, в то время как Aspose.Slides представлена как библиотека обработки презентаций с высокоуровневой объектной моделью и поддержкой многих задач, связанных с PowerPoint.

Статья сравнивает оба варианта по поддерживаемым форматам, программной модели, рендерингу, поддержке платформ и типичным сценариям использования. Также уточняется, что Open XML SDK может быть подходящим для базовых операций с PPTX или прямого доступа к элементам OOXML, тогда как Aspose.Slides более предпочтителен для сложных задач презентаций, таких как работа с несколькими форматами PowerPoint, копирование или клонирование объектов, замена текста, применение анимаций и преобразование презентаций в PDF, TIFF или XPS.

## **Что такое Open XML SDK?**
According to the [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK is defined as: 

Open XML SDK 2.0 упрощает задачу управления пакетами Open XML и базовыми элементами схемы Open XML внутри пакета. Open XML SDK 2.0 инкапсулирует многие распространённые задачи, которые разработчики выполняют с пакетами Open XML, позволяя выполнять сложные операции всего в несколько строк кода.

Документы OOXML по сути являются zip‑архивами XML‑файлов, а Open XML SDK — это набор классов, позволяющих работать с содержимым документов OOXML типобезопасным способом. Вместо того чтобы распаковывать файл для извлечения XML, загружать его в DOM‑дерево и работать непосредственно с элементами и атрибутами XML, Open XML SDK предоставляет классы для выполнения этих действий.

## **Что такое Aspose.Slides?**
Aspose.Slides — это библиотека классов, позволяющая вашему приложению выполнять следующие задачи обработки презентаций:

- Программирование с объектной моделью **Presentation**.
- Высококачественное преобразование между всеми популярными поддерживаемыми форматами PowerPoint, включая конвертацию в PDF, XPS и TIFF.
- Возможность генерировать миниатюры слайдов в известных форматах, таких как PNG, JPEG и BMP, а также экспортировать слайды в SVG.
- Возможность создавать презентации с нуля или комбинировать их из одного или нескольких документов.
- Поддержка добавления анимаций, Ole‑фреймов, таблиц, создания и управления диаграммами.
- Широкий контроль над форматированием текста в уровнях TextFrames, Paragraphs и Portions.

Для получения более подробной информации о поддерживаемых функциях, пожалуйста, посетите [Aspose.Slides Features](/slides/ru/java/product-overview/).

## **Заключение**
{{% alert color="info" %}} 

Open XML SDK и Aspose.Slides не конкурируют напрямую, поскольку они ориентированы на разные потребности и аудитории. Open XML SDK — это библиотека классов, предоставляющая типобезопасный способ работы с документами OOXML. Aspose.Slides — очень полезная библиотека обработки презентаций, обеспечивающая отличную поддержку почти всех форматов файлов Microsoft PowerPoint.

Если ваша задача ограничивается достаточно базовой программной операцией над документом PPTX, то Open XML SDK может быть подходящим выбором. С Open XML SDK вы легко справитесь с простыми задачами, такими как генерация простого PPTX‑документа, удаление комментариев, заголовков/нижних колонтитулов, извлечение изображений и т.п. Некоторые задачи могут быть выполнены с помощью Open XML SDK, но недоступны в Aspose.Slides. Например, если необходимо напрямую обращаться к элементам и атрибутам XML‑документа OOXML, следует использовать Open XML SDK. Однако если требуется выполнять сложные операции над документами, такие как перечисленные ниже, то лучшим вариантом будет Aspose.Slides:

- Поддержка старых форматов PowerPoint в дополнение к PPTX.
- Копирование или клонирование фигур в слайдах с сохранением комбинаций объектов, стилей и прочего форматирования.
- Замена форматированного или неформатированного текста.
- Применение анимаций и использование соединителей между фигурами.
- Преобразование документа в PDF, TIFF или XPS с точным воспроизведением того, как это делает Microsoft PowerPoint.
- Разработка приложений на .NET или Java как для настольных, так и для веб‑окружений.
