## **Обзор**

Эта статья объясняет, когда разработчикам может быть целесообразно выбрать Open XML SDK или Aspose.Slides для работы с презентационными документами. В ней Open XML SDK описывается как библиотека для манипулирования пакетами OOXML и их базовыми элементами XML, тогда как Aspose.Slides представлена как библиотека обработки презентаций с высокоуровневой объектной моделью и поддержкой множества задач, связанных с PowerPoint.

Статья сравнивает оба варианта по поддерживаемым форматам, программной модели, возможностям рендеринга и печати, поддержке платформ и типичным сценариям использования. Также разъясняется, что Open XML SDK может подойти для базовых операций с PPTX или прямого доступа к элементам OOXML, тогда как Aspose.Slides более подходит для сложных задач, таких как работа с несколькими форматами PowerPoint, копирование или клонирование фигур, замена текста, применение анимаций и преобразование презентаций в PDF, TIFF или XPS.

## **Что такое Open XML SDK?**
Согласно [Библиотека MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK определяется так:

Open XML SDK 2.0 упрощает задачу манипулирования пакетами Open XML и базовыми элементами схемы Open XML внутри пакета. Open XML SDK 2.0 инкапсулирует многие распространённые задачи, которые разработчики выполняют с пакетами Open XML, позволяя выполнять сложные операции всего несколькими строками кода.

Документы OOXML по сути являются zip‑архивами XML‑файлов, а Open XML SDK — это набор классов, позволяющих работать с содержимым OOXML‑документов типобезопасным способом. Вместо распаковки файла для извлечения XML, загрузки этого XML в дерево DOM и работы с элементами и атрибутами напрямую, Open XML SDK предоставляет классы для выполнения этих действий.

## **Что такое Aspose.Slides?**
Aspose.Slides — это библиотека классов, позволяющая вашему приложению выполнять следующие задачи обработки презентаций:

- Программирование с объектной моделью **Presentation**.
- Высококачественное преобразование между всеми популярными поддерживаемыми форматами презентаций PowerPoint, включая преобразование в PDF, XPS и TIFF.
- Возможность создавать эскизы слайдов в известных форматах, таких как PNG, JPEG и BMP, а также экспортировать слайды в SVG.
- Возможность создавать презентации с нуля или комбинировать их из одного или нескольких документов.
- Поддержка добавления анимаций, Ole Frames, таблиц, создания и управления диаграммами.
- Наличие обширного контроля над форматированием текста на уровнях TextFrames, Paragraphs и Portions.

Для получения более подробной информации о поддерживаемых функциях, пожалуйста, посетите [Функции Aspose.Slides](/slides/ru/java/product-overview/).

## **Заключение**
{{% alert color="info" %}} 

Open XML SDK и Aspose.Slides не конкурируют напрямую, потому что они ориентированы на совсем разные потребности и аудитории. Open XML SDK — это библиотека классов, предоставляющая типобезопасный способ работы с OOXML‑документами. Aspose.Slides — очень полезная библиотека обработки презентаций, обеспечивающая отличную поддержку почти всех форматов файлов Microsoft PowerPoint.

Если вам нужно выполнить лишь довольно простую программную операцию над документом PPTX, то Open XML SDK может быть подходящим выбором. С Open XML SDK вам будет комфортно выполнять такие простые задачи, как создание простого PPTX‑документа, удаление комментариев, колонок/колонтитулов, извлечение изображений и прочее. Некоторые задачи можно решить с помощью Open XML SDK, но нельзя решить с помощью Aspose.Slides. Например, если необходимо напрямую обращаться к элементам XML и атрибутам OOXML‑документа, следует использовать Open XML SDK. Однако если требуется выполнять сложные операции над документами, такие как ниже перечисленные задачи, то лучшим вариантом будет использование Aspose.Slides:

- Поддержка старых форматов PowerPoint помимо PPTX.
- Копирование или клонирование фигур в слайдах способом, который объединяет объекты, стили и другое форматирование соответствующим образом.
- Замена отформатированного или неотформатированного текста.
- Применение анимаций и использование соединителей с фигурами.
- Преобразование документа в PDF, TIFF или XPS, чтобы он выглядел точно так же, как при конвертации в Microsoft PowerPoint.
- Разработка .NET или Java приложения как для настольных, так и для веб‑окружений.
