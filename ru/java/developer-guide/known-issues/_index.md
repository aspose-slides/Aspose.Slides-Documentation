## **Обзор**

Этот раздел не содержит список открытых проблем в текущей версии. В нём три страницы:

- [Заполнитель предварительного просмотра объекта при добавлении OleObjectFrame](/slides/ru/java/object-preview-issue-when-adding-oleobjectframe/) объясняет, почему OLE‑объект, добавленный с помощью Aspose.Slides, отображает изображение «EMBEDDED OLE OBJECT», пока его предварительный просмотр не обновится, и как задать собственное изображение предварительного просмотра. Это поведение, предусмотренное в текущей версии.
- [Известные проблемы в Aspose.Slides for Java 14.3.0 (Historical)](/slides/ru/java/known-issues-in-aspose-slides-for-java-14-3-0/) и [Известные проблемы в Aspose.Slides for Java 14.4.0 (Historical)](/slides/ru/java/known-issues-in-aspose-slides-for-java-14-4-0/) являются списками, опубликованными вместе с этими версиями, сохраняются для справки.

Для изменений и исправлений в каждой версии см. [примечания к выпуску](https://releases.aspose.com/slides/ru/java/release-notes/). Поля метаданных, которые Aspose.Slides записывает со фиксированными значениями, описаны в разделе [Ограничения метаданных вывода](/slides/ru/java/api-limitations/). Чтобы проверить, известна ли уже проблема, или сообщить о новой, используйте [форум поддержки](https://forum.aspose.com/c/slides/ru/11).
