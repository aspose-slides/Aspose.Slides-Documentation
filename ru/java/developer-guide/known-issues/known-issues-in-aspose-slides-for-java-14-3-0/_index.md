{{% alert color="info" title="Note" %}}

Это историческая страница. Она перечисляет известные проблемы, опубликованные в Aspose.Slides for Java 14.3.0, и не описывает текущую версию. Для изменений в каждой версии см. [release notes](https://releases.aspose.com/slides/ru/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) предоставляет полностью новую реализацию обработки PPT. Есть множество улучшений, частичное преобразование PPTX в PPT. Но есть некоторые не реализованные функции:

- Некоторые фигуры имеют неправильную геометрию в сериализованных PPT‑документах (Call outs)
- Не все функции форматирования текста PPTX поддерживаются при сериализации в PPT
- Информация о языке текста и настройках правописания отсутствует в сериализованных PPT‑документах
- Не все функции тем PPTX поддерживаются при сериализации в PPT

**Есть некоторые различия по сравнению с Aspose.Slides for Java 8.6.0:**

- Известные проблемы при сериализации OLE/ActiveX PPT в PPT

**Есть некоторые различия по сравнению с Aspose.Slides for .NET 14.3.0:**

- Поддержка печати презентаций в настоящее время недоступна в Aspose.Slides for Java
