{{% alert color="info" title="Note" %}}

Это историческая страница. Она перечисляет ограничения и известные проблемы, опубликованные вместе с Aspose.Slides for Java 14.4.0, и не описывает текущую версию. Для изменений в каждой версии см. [release notes](https://releases.aspose.com/slides/ru/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.4.0 предоставляет новое решение для обработки документов PowerPoint. Существуют некоторые ограничения и известные проблемы, которые будут устранены в будущих версиях:

- Некоторые фигуры имеют неправильную геометрию в сериализованных PPT‑документах (дуги, круговые стрелки, выноски).
- Не все функции форматирования текста PPTX поддерживаются при сериализации в PPT (ограничения табуляции, отступов и форматирования абзацев).
- Информация о языке текста и настройках орфографии отсутствует в сериализованных PPT‑документах.
- Не все возможности темы PPTX поддерживаются при сериализации в PPT (только сериализация форматов заливки, линий и шрифта).
- Известны проблемы при сериализации OLE/ActiveX PPT в PPT.
- Сериализация и визуализация WordArt не поддерживаются.
