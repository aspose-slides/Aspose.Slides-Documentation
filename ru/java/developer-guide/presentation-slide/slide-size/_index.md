## **Введение**

Aspose.Slides предоставляет комплексные инструменты для настройки размера слайда и соотношения сторон в презентациях PowerPoint, что важно как для печати, так и для отображения на экране. 

Популярные размеры слайдов и соотношения сторон:

- **Standard (соотношение сторон 4:3)**: Идеально для старых экранов и устройств.
- **Widescreen (соотношение сторон 16:9)**: Рекомендуется для современных проекторов и дисплеев.

Обеспечьте согласованность всей презентации, поскольку один размер слайда и соотношение сторон применяются ко всем слайдам. Для получения оптимальных результатов задавайте размеры слайдов в начале создания презентации, чтобы избежать проблем.

{{% alert color="info" title="Note" %}}
По умолчанию презентации, созданные с помощью Aspose.Slides, используют стандартное соотношение сторон 4:3.
{{% /alert %}}

Страницы заметок и раздаточных материалов имеют отдельные размеры, отличные от обычных слайдов. См. [Notes Page Size](/slides/ru/java/notes-size/) чтобы изменить их размер и ориентацию.

## **Изменение размера слайда в презентациях**

Этот пример кода показывает, как изменить размер слайда в презентации на Java с помощью Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **Указание пользовательских размеров слайдов в презентациях**

Если стандартные размеры слайдов (4:3 и 16:9) не подходят для вашей работы, вы можете выбрать конкретный или уникальный размер слайда. Например, если вы планируете печатать полноразмерные слайды из презентации на пользовательском формате страницы или хотите отображать презентацию на определённых типах экранов, использование пользовательского размера слайда может быть полезным.

Этот пример кода показывает, как использовать Aspose.Slides для Java, чтобы задать пользовательский размер слайда для презентации на Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // Размер бумаги A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **Обработка содержимого слайда после изменения размера**

После изменения размера слайда в презентации содержимое слайдов (например, изображения или объекты) может стать искажённым. По умолчанию объекты автоматически масштабируются, чтобы соответствовать новому размеру слайда. Однако при изменении размера слайда презентации можно указать параметр, определяющий, как Aspose.Slides обрабатывает содержимое на слайдах.

В зависимости от того, чего вы планируете достичь, вы можете использовать любой из следующих параметров:

- `DoNotScale`

  Если вы НЕ хотите, чтобы объекты на слайдах масштабировались, используйте этот параметр.

- `EnsureFit`

  Если вы хотите масштабировать до меньшего размера слайда и нуждаетесь в том, чтобы Aspose.Slides уменьшил объекты слайдов, обеспечивая их полное размещение на слайде (чтобы избежать потери содержимого), используйте этот параметр.

- `Maximize`

  Если вы хотите масштабировать до большего размера слайда и нуждаетесь в том, чтобы Aspose.Slides увеличил объекты слайдов, делая их пропорциональными новому размеру, используйте этот параметр.

Этот пример кода показывает, как использовать параметр `Maximize` при изменении размера слайда презентации:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **Часто задаваемые вопросы**

**Можно ли задать пользовательский размер слайда в единицах, отличных от дюймов (например, пункты или миллиметры)?**

Да. Aspose.Slides использует пункты (points) внутри, где 1 пункт = 1/72 дюйма. Вы можете преобразовать любую единицу (например, миллиметры или сантиметры) в пункты и использовать полученные значения для определения ширины и высоты слайда.

**Появится ли влияние очень большого пользовательского размера слайда на производительность и использование памяти при рендеринге?**

Да. Большие размеры слайда (в пунктах) в сочетании с более высоким масштабом рендеринга приводят к увеличению расхода памяти и удлинению времени обработки. Стремитесь к практичному размеру слайда и регулируйте масштаб рендеринга только при необходимости для получения требуемого качества вывода.

**Можно ли задать один нестандартный размер слайда, а затем объединять слайды из презентаций с разными размерами?**

Вы не можете [объединять презентации](/slides/ru/java/merge-presentation/), пока у них разные размеры слайдов — сначала измените размер одной презентации, чтобы он совпал с другой. При изменении размера слайда можно выбрать, как обрабатывать существующее содержимое, используя параметр [SlideSizeScaleType](https://reference.aspose.com/slides/ru/java/com.aspose.slides/slidesizescaletype/). После согласования размеров вы сможете объединять слайды, сохраняя форматирование.

**Можно ли генерировать миниатюры для отдельных фигур или конкретных областей слайда, и будут ли они учитывать новый размер слайда?**

Да. Aspose.Slides может создавать миниатюры для [полных слайдов](https://reference.aspose.com/slides/ru/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) и для [выбранных фигур](https://reference.aspose.com/slides/ru/java/com.aspose.slides/shape/#getImage-int-float-float-). Полученные изображения отражают текущий размер слайда и соотношение сторон, обеспечивая согласованную кадрацию и геометрию.
