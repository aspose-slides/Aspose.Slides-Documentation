Обычная задача, которую разработчики решают, — динамически добавлять текст на слайды. В этой статье показаны примеры кода для динамического добавления текста с использованием [VSTO](/slides/ru/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/) и [Aspose.Slides for Java](/slides/ru/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/).

## **Динамическое добавление текста**
Оба метода следуют этим шагам:

1. Создать презентацию.
1. Добавить пустой слайд.
1. Добавить текстовое поле.
1. Установить текст.
1. Записать презентацию.
