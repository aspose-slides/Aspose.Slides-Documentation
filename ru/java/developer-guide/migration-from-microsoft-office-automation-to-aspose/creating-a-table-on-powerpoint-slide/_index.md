Таблицы широко используются для отображения данных на слайдах презентаций. В этой статье показано, как программно создать таблицу 15 × 15 с размером шрифта 10, сначала с помощью [VSTO 2008](/slides/ru/java/creating-a-table-on-powerpoint-slide/), а затем с помощью [Aspose.Slides for Java](/slides/ru/java/creating-a-table-on-powerpoint-slide/).

{{% /alert %}} 
## **Создание таблиц**
### **Пример VSTO 2008**
Следующие шаги добавляют таблицу в слайд Microsoft PowerPoint с помощью VSTO:

1. Создать презентацию.
1. Добавить пустой слайд в презентацию.
1. Добавить таблицу 15 × 15 на слайд.
1. Добавить текст в каждую ячейку таблицы с размером шрифта 10.
1. Сохранить презентацию на диск.
