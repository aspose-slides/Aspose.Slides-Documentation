## **Обзор**

Aspose.Slides for Java может загружать презентации PowerPoint и OpenDocument и сохранять или отображать их во многих других форматах без Microsoft PowerPoint, OpenOffice или LibreOffice. Вы можете преобразовать устаревшие файлы PPT в современные PPTX, экспортировать презентации в документы фиксированного макета, такие как PDF и XPS, публиковать слайды как HTML или рендерить слайды в графические файлы для превью, миниатюр и архивов.

Большинство конверсий документов используют один и тот же общий рабочий процесс: загрузить исходный файл, выбрать требуемый формат вывода и при необходимости применить параметры, специфичные для формата. Для графических форматов каждый слайд рендерится отдельно, а затем сохраняется как растровое или векторное изображение. Специализированные статьи, указанные ниже, предоставляют детали реализации для каждого случая.

## **Конверсия PowerPoint и OpenDocument**

Aspose.Slides for Java поддерживает конверсию из часто используемых форматов презентаций, таких как PPT, PPTX, PPS, PPSX, POT, POTX и ODP. Один и тот же API конверсии используется для файлов PowerPoint и OpenDocument, поэтому рабочий процесс, сохраняющий файл PPTX в PDF, обычно можно применить к файлу ODP, изменив только входной файл.

При конвертации ODP‑файлов помните, что приложения PowerPoint и OpenDocument не поддерживают каждую компоновку и форматирование одинаково. Если ODP‑файл был создан в LibreOffice или OpenOffice Impress, проверьте результат и используйте параметры, описанные в [Преобразовать презентации OpenDocument](/slides/ru/java/convert-openoffice-odp/), когда требуется руководство по конкретному формату.

## **Конверсия PPT в PPTX**

PPT — это старый двоичный формат PowerPoint, а PPTX — современный формат Office Open XML. Aspose.Slides for Java поддерживает высокоточное преобразование PPT в PPTX с сохранением сложных структур презентации, таких как мастера, макеты, слайды, диаграммы, группированные фигуры, заполнительные объекты, текстовые рамки, текстуры и заливки изображениями.

Для деталей см. [Преобразовать PPT в PPTX](/slides/ru/java/convert-ppt-to-pptx/) и [PPT против PPTX](/slides/ru/java/ppt-vs-pptx/).

## **Экспорт фиксированного макета**

PDF, XPS и TIFF полезны, когда вывод должен выглядеть одинаково на разных устройствах и не должен редактироваться как презентация. Специализированные статьи по PDF, XPS и TIFF объясняют, как управлять соответствием стандартам, скрытыми слайдами, заметками, качеством изображений, сжатием, форматом пикселей и размером вывода.

## **Экспорт HTML и изображений**

Экспорт в HTML и HTML5 полезен для просмотра в браузере, веб‑публикаций и лёгкого обмена. Экспорт изображений полезен, когда каждый слайд должен стать отдельным превью, миниатюрой или растровым ресурсом. Используйте статьи по PNG, JPG и SVG для получения рекомендаций по рендерингу, специфичному для формата.

## **FAQ**

**Нужен ли мне Microsoft PowerPoint для конверсии презентаций?**

Нет. Aspose.Slides for Java — это автономная библиотека и не требует Microsoft PowerPoint или автоматизации Office.

**Можно ли пакетно конвертировать множество презентаций?**

Да. Загружайте каждую презентацию, сохраняйте её в требуемом формате и освобождайте объект презентации после обработки. Для параллельной обработки используйте отдельные экземпляры презентаций и следуйте рекомендациям по [многопоточности](/slides/ru/java/multithreading/).

**Можно ли экспортировать только выбранные слайды?**

Да. Несколько методов экспорта позволяют передавать индексы слайдов или рендерить отдельные слайды в зависимости от формата вывода. См. специализированную статью для нужного формата.

**Можно ли включать скрытые слайды при экспорте в PDF или XPS?**

Да. Используйте параметры экспорта скрытых слайдов, описанные в статьях [PDF](/slides/ru/java/convert-powerpoint-to-pdf/) и [XPS](/slides/ru/java/convert-powerpoint-to-xps/).

**Можно ли создать вывод PDF/A?**

Да. Параметры соответствия PDF доступны при экспорте в PDF. См. [Преобразовать PowerPoint в PDF](/slides/ru/java/convert-powerpoint-to-pdf/) для подробностей.

**Как обрабатываются шрифты при конверсии?**

Aspose.Slides может использовать встроенные шрифты, резервные шрифты и настройки замены шрифтов. См. [Embedded Font](/slides/ru/java/embedded-font/), [Fallback Font](/slides/ru/java/fallback-font/) и [Font Substitution](/slides/ru/java/font-substitution/).
