## **Введение**

В PowerPoint 2019 Microsoft представила настройку **Always Open Read-Only** как одну из опций, которые пользователи могут использовать для защиты своих презентаций. Вы можете захотеть использовать эту настройку только для чтения, чтобы защитить презентацию, когда

- Вы хотите предотвратить случайные правки и сохранить содержимое презентации в безопасности. 
- Вы хотите предупредить людей, что предоставленная вами презентация является окончательной версией. 

После того как вы выберете опцию **Always Open Read-Only** для презентации, при открытии пользователями этой презентации они увидят рекомендацию **Read-Only** и могут увидеть сообщение в следующем виде: *Чтобы предотвратить случайные изменения, автор установил открытие этого файла только для чтения.*

Рекомендация **Read-Only** — это простое, но эффективное средство сдерживания, которое препятствует редактированию, поскольку пользователи должны выполнить действие, чтобы удалить её, прежде чем им будет разрешено редактировать презентацию. Если вы не хотите, чтобы пользователи вносили изменения в презентацию и хотите вежливо об этом сообщить, то рекомендация **Read-Only** может быть хорошим вариантом для вас. 

> Если презентация с защитой **Read-Only** открывается в более старой версии Microsoft PowerPoint, которая не поддерживает недавно введённую функцию, рекомендация **Read-Only** игнорируется (презентация открывается обычным способом).

## **Применить режим только для чтения**

Aspose.Slides for Java позволяет установить презентацию в режим **Read-Only**, что означает, что пользователи (после открытия презентации) видят рекомендацию **Read-Only**. Этот пример кода показывает, как установить презентацию в режим **Read-Only** в Java с помощью Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 
**Примечание**: Рекомендация **Read-Only** предназначена лишь для того, чтобы отговорить от редактирования или от случайных изменений PowerPoint‑презентации. Если мотивированный человек, который знает, что делает, решит отредактировать вашу презентацию, он легко сможет снять настройку только для чтения. Если вам действительно нужно предотвратить несанкционированное редактирование, лучше использовать [более строгие защиты, включающие шифрование и пароли](https://docs.aspose.com/slides/ru/java/password-protected-presentation/). 
{{% /alert %}} 

## **Часто задаваемые вопросы**

### Чем 'Read-Only recommended' отличается от полной защиты паролем?

'Read-Only recommended' только отображает предложение открыть файл в режиме только для чтения и легко обходится. [Защита паролем](/slides/ru/java/password-protected-presentation/) действительно ограничивает открытие или редактирование и подходит, когда нужны реальные средства безопасности.

### Можно ли комбинировать 'Read-Only recommended' с водяными знаками для дополнительного ограничения правки?

Да. Рекомендацию можно сочетать с [водяными знаками](/slides/ru/java/watermark/) как визуальным сдерживателем; они являются отдельными механизмами и хорошо работают вместе.

### Может ли макрос или внешнее приложение всё равно изменить файл, когда рекомендация включена?

Да. Рекомендация не блокирует программные изменения. Чтобы предотвратить автоматические правки, используйте [пароли и шифрование](/slides/ru/java/password-protected-presentation/).

### Как 'Read-Only recommended' соотносится с методами 'isEncrypted' и 'isWriteProtected'?

Это разные сигналы. 'Read-Only recommended' — мягкое, необязательное предложение; [isWriteProtected](https://reference.aspose.com/slides/ru/java/com.aspose.slides/protectionmanager/#isWriteProtected--) и [isEncrypted](https://reference.aspose.com/slides/ru/java/com.aspose.slides/protectionmanager/#isEncrypted--) указывают на реальные ограничения записи или чтения, зависящие от паролей или шифрования.
