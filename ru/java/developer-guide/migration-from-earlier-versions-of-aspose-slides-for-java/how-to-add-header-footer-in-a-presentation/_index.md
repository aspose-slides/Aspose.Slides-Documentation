## **Поддержка устаревшего кода**
Чтобы использовать устаревший код, разработанный с Aspose.Slides for Java версиями до 13.x, необходимо внести небольшие изменения в ваш код, и он будет работать как раньше. Все классы, которые присутствовали в старых версиях Aspose.Slides for Java в пространствах имён Aspose.Slide и Aspose.Slides.Pptx, теперь объединены в единый пространство имён Aspose.Slides. Пожалуйста, ознакомьтесь со следующим простым примером кода для добавления колонтитула в презентацию в устаревшем API Aspose.Slides и следуйте шагам, описывающим миграцию на новый объединённый API.
