## **Поддержка устаревшего кода**
Чтобы использовать устаревший код, разработанный для Aspose.Slides for Java версии ниже 13.x, вам необходимо внести небольшие изменения в ваш код, и он будет работать так же, как прежде. Все классы, которые находились в старых версиях Aspose.Slides for Java в пространствах имён Aspose.Slide и Aspose.Slides.Pptx, теперь объединены в единое пространство имён Aspose.Slides. Пожалуйста, ознакомьтесь со следующим простым фрагментом кода для создания презентации Hello World в устаревшем API Aspose.Slides и выполните шаги, описывающие миграцию к новому объединённому API.
