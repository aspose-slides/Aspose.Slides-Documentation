## **Поддержка устаревшего кода**
Чтобы использовать устаревший код, разработанный с Aspose.Slides for Java версий ранее 14.x.x, необходимо внести небольшие изменения в ваш код, и он будет работать как раньше. Все классы, которые ранее находились в пространствах имен com.aspose.slides и com.aspose.slides.pptx, теперь объединены в едином пространстве имен com.aspose.slides. Обратите внимание на следующий простой фрагмент кода для создания обычной диаграммы с нуля в презентации с использованием устаревшего API Aspose.Slides и следуйте шагам, описывающим миграцию к новому объединённому API.
