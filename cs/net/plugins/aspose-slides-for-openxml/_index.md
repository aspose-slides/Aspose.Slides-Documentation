## **Co je OpenXML?**
OpenXML SDK je .NET SDK od Microsoftu určené ke zpracování souborových formátů Microsoft Office 2007 a novějších. Tyto souborové formáty jsou v podstatě zabalené ZIP balíky a Open XML SDK pro Office zjednodušuje úkol manipulace s Open XML balíky a podkladovými schématy Open XML uvnitř balíku. Třídy v Open XML SDK zapouzdřují mnoho běžných úkolů, které vývojáři provádějí s Open XML balíky, takže můžete provádět složité operace pomocí několika řádků kódu.

Po instalaci Open XML SDK 2.5 otevřete svůj existující projekt nebo aplikaci ve Visual Studiu, nebo vytvořte nový projekt či aplikaci. Poté ve svém projektu nebo aplikaci přidejte odkazy na následující komponenty:

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides pro .NET**
Aspose.Slides pro .NET je jedinečná komponenta pro správu PowerPoint® umožňující .NET aplikacím číst, zapisovat a manipulovat s PowerPoint dokumenty bez použití Microsoft PowerPoint.

Aspose.Slides pro .NET je první a jediná .NET komponenta, která poskytuje funkčnost pro správu PowerPoint dokumentů ve vašich vlastních aplikacích. Stejně jako všechny Aspose .NET komponenty je Aspose.Slides napsán v řízeném C#, cenově dostupný a bleskově rychlý.

## **Úvod**
Vývojáři hledající knihovny pro práci se souborovými formáty mohou potřebovat projít funkce nabízené knihovnami dostupnými na trhu. Především se při výběru možnosti zvažují dva faktory:

- Funkce
- Námaha potřebná k použití knihovny

Pokud jste .NET vývojář hledající rychlou, snadnou a lehkou knihovnu pro zpracování souborů, možná budete chtít porovnat VSTO (Visual Studio Tools for Office) s Aspose. V tomto případě vám tento projekt pomůže porovnat funkce a kód v obou knihovnách.
