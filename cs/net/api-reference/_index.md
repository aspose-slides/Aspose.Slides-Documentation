{{% alert color="info" %}} 

Aspose.Slides pro .NET je knihovna tříd, která umožňuje .NET aplikacím číst a zapisovat prezentační dokumenty bez použití Microsoft PowerPoint® nebo jiných. Aspose.Slides pro .NET umožňuje spravovat text, tvary, tabulky a animace, přidávat audio a video do snímků, náhled snímků, exportovat snímky do SVG, PDF formátu a další.

Nejnovější referenci API naleznete na [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/cs/net).

{{% /alert %}}
