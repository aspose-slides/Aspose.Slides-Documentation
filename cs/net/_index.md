**Vítejte v Aspose.Slides pro .NET**

![Logo produktu Aspose.Slides pro .NET](home_1.png)

Aspose.Slides pro .NET je rozhraní API pro správu Microsoft PowerPoint®, které umožňuje aplikacím .NET číst a zapisovat dokumenty PowerPoint® bez použití Microsoft PowerPoint®.

Aspose.Slides pro .NET je první a jediná komponenta, která poskytuje funkce potřebné ke správě dokumentů PowerPoint®.

Aspose.Slides pro .NET nabízí řadu hlavních funkcí, jako je správa textu, tvarů, tabulek a animací, přidávání audia a videa do snímků, náhled snímků, export snímků do SVG, PDF a dalších formátů a mnoho dalších možností.
