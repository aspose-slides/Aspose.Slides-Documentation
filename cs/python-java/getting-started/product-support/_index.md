## **Přehled**

Použijte supportní fórum Aspose.Slides k položení otázek, nahlášení problémů a požádání o funkce pro Aspose.Slides pro Python via Java. Tento článek vysvětluje, co zkontrolovat před otevřením tématu a jaké informace pomáhají podpůrnému týmu reprodukovat problém.

## **Technická podpora**

{{% alert color="info" title="Poznámka" %}}

Aspose poskytuje bezplatnou technickou podporu všem uživatelům, včetně těch, kteří produkt hodnotí. Podrobnosti najdete v [zasady bezplatné podpory](https://forum.aspose.com/t/free-support-policies/162313).

{{% /alert %}}

Pokládejte technické otázky na [supportní fórum Aspose.Slides](https://forum.aspose.com/c/slides/cs/11). Uveďte **Aspose.Slides for Python via Java** ve své zprávě, aby tým mohl identifikovat správný produkt a prostředí.

Pro prioritní asistenci navštivte [placený helpdesk podpory](https://helpdesk.aspose.com/). Placená podpora vyžaduje samostatné předplatné a není součástí licence produktu.

## **Před nahlášením problému**

1. Zkontrolujte [stahování](https://releases.aspose.com/slides/cs/python-java/) a [poznámky k vydání](https://releases.aspose.com/slides/cs/python-java/release-notes/) pro novější verzi, která může problém vyřešit. Pokud je to možné, reprodukujte problém s nejnovějším vydáním v testovacím prostředí.
2. Prohledejte supportní fórum, [dokumentaci](/slides/cs/python-java/), a [referenci API](https://reference.aspose.com/slides/cs/python-java/) pro existující odpověď.
3. U problémů s instalací nebo spouštěním JVM si projděte [průvodce instalací](/slides/cs/python-java/installation/) a potvrďte, že Python a Java používají odpovídající architektury.
4. Zredukujte problém na nejmenší ukázku a vstupní prezentaci, která jej stále reprodukuje.

## **Připravte hlášení problému**

Do svého tématu na fóru zahrňte následující informace:

- **Prostředí:** Aspose.Slides for Python via Java verze, verze Pythonu, verze a dodavatel Javy, verze JPype, operační systém a architektura.
- **Kroky a kód:** Minimální spustitelný příklad v Pythonu, včetně importů a inicializace JVM, a kroky potřebné k reprodukci problému.
- **Vstupní soubory:** Prezentace a jakékoli související soubory potřebné pro příklad. Kombinujte více souborů do ZIP archivu.
- **Očekávané a skutečné výsledky:** Popište rozdíl a připojte vygenerovaný výstup nebo screenshoty, pokud jsou užitečné. U problémů s vykreslováním uveďte postižené snímky a písma.
- **Detaily chyby:** Kompletní chybová zpráva a zásobník volání, pokud dojde k výjimce.

Používejte jedno téma na každý problém. Přidejte doplňující informace o stejném problému do existujícího tématu, aby podpůrný tým mohl sledovat vyšetřování.

## **FAQ**

**Mohu získat pomoc během hodnocení Aspose.Slides pro Python via Java?**

Ano. Bezplatná technická podpora je k dispozici prostřednictvím supportního fóra Aspose.Slides během hodnocení i po zakoupení.

**Co mám zahrnout, když JVM selže při spuštění?**

Uveďte verze Pythonu, Javy a JPype, operační systém, architektury Pythonu a Javy, kód inicializace JVM a kompletní chybovou zprávu. Tyto podrobnosti pomohou podpůrnému týmu reprodukovat vaše prostředí.

**Jak mám nahlásit problém, který se objevil po aktualizaci?**

Uveďte poslední verzi, která fungovala, první verzi, ve které jste problém zaznamenali, a minimální příklad s vstupními soubory. Popište všechny další změny prostředí provedené během aktualizace.
