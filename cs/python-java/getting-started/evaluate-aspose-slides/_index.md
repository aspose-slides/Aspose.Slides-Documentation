Aspose.Slides pro Python via Java si můžete stáhnout, abyste si vyzkoušeli jeho funkce. Evaluační balíček je identický s licencovaným balíčkem. Abyste ho použili bez evaluačních omezení, přidejte několik řádků kódu do [použít licenci](/slides/cs/python-java/licensing/).

Evaluační verze Aspose.Slides (používaná bez licence) poskytuje plnou funkčnost produktu, s dvěma omezeními:

- Přidá evaluační vodoznakový textový rámeček do každého snímku každé prezentace, kterou uloží. Otevření prezentace vodoznak nepřidá, ale uložení souboru, který již vodoznak nese, přidá další.
- Text, který váš kód čte, je oříznut na několik prvních znaků, za kterými následuje upozornění na evaluační omezení. To platí pro každý snímek i pro text, který váš kód právě nastavil, stejně jako pro text načtený ze souboru. Text, který váš kód zapisuje, je uložen celý.
