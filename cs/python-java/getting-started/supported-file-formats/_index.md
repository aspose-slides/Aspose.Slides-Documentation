## **Přehled**

Aspose.Slides for Python via Java čte a zapisuje prezentace PowerPoint a OpenDocument. Také importuje obsah PDF a HTML do snímků a exportuje prezentace nebo jednotlivé snímky do formátů dokumentů, webu a obrázků.

Níže uvedená tabulka rozlišuje načítání prezentací od importu obsahu a vykreslování snímků. Pro přehled o možnostech úprav a vykreslování viz [Přehled funkcí](/slides/cs/python-java/features-overview/).

## **Poznámky k importu a exportu**

- **Import PDF a HTML:** Použijte [SlideCollection.addFromPdf](https://reference.aspose.com/slides/cs/python-java/aspose.slides/slidecollection/#addfrompdf) nebo [SlideCollection.addFromHtml](https://reference.aspose.com/slides/cs/python-java/aspose.slides/slidecollection/#addfromhtml) k vytvoření snímků ze zdrojového obsahu a jejich připojení k prezentaci.
- **Výstup prezentace:** [SaveFormat](https://reference.aspose.com/slides/cs/python-java/aspose.slides/saveformat/) uvádí dostupné formáty ukládání prezentací, včetně samostatných možností exportu do HTML a HTML5.
- **Výstup obrázku:** Exportovaní snímku do obrázku vytvoří vizuální reprezentaci tohoto snímku. Sloupec vstup nepopisuje, zda lze obrázek do prezentace vložit.

## **Často kladené otázky**

**Mohu převést prezentaci PPT na PPTX nebo ODP?**

Ano. PPT je podporováno jako vstupní formát a jak PPTX, tak ODP jsou podporovány jako výstupní formáty. Výsledky konverze závisí na funkcích dostupných v cílovém formátu.

**Otevírá import PDF nebo HTML zdroj jako soubor PowerPoint?**

Ne. Import vytváří snímky z PDF stránek nebo HTML obsahu. Poté můžete výslednou prezentaci uložit v podporovaném formátu prezentace.

**Mohu načíst exportovaný PNG nebo SVG jako editovatelnou prezentaci?**

Ne. Tyto exporty představují vzhled snímků. Uchovejte původní prezentaci, pokud potřebujete později upravovat její text, tvary, grafy a další objekty.
