## **Přehled**

Tato část vám pomůže připravit prostředí a začít používat [Aspose.Slides for Python via Java](https://products.aspose.com/slides/python-java/). Postupujte podle níže uvedených kroků nastavení a poté prozkoumejte funkce knihovny a pokyny relevantní pro váš projekt.

## **Nastavení knihovny**

1. Zkontrolujte [Požadavky systému](/slides/cs/python-java/system-requirements/), abyste ověřili požadavky na operační systém, Python, Java a JPype.
2. Postupujte podle průvodce [Instalace](/slides/cs/python-java/installation/), nainstalujte požadované balíčky a ověřte nastavení pomocí příkladu.
3. Přečtěte si [Vyhodnocení Aspose.Slides](/slides/cs/python-java/evaluate-aspose-slides/), abyste pochopili omezení vyhodnocení a možnosti dočasné licence.
4. Postupujte podle průvodce [Licencování](/slides/cs/python-java/licensing/), abyste použili svou licenci.

## **Prozkoumejte funkce a kompatibilitu**

- [Přehled produktu](/slides/cs/python-java/product-overview/) představuje knihovnu a její schopnosti zpracování prezentací.
- [Podporované formáty souborů](/slides/cs/python-java/supported-file-formats/) uvádí formáty dostupné pro načítání, import, ukládání a export prezentací.
- [Přehled funkcí](/slides/cs/python-java/features-overview/) shrnuje funkce převodu, renderování, úprav a formátování.
- [Omezení a rozdíly API](/slides/cs/python-java/limitations-and-api-differences/) vysvětluje omezení a rozdíly, které je třeba vzít v úvahu při používání Java API z Pythonu.

## **Získat pomoc**

Viz [Podpora produktu](/slides/cs/python-java/product-support/) pro pokyny k odstraňování problémů, instrukce pro hlášení problémů a odkazy na další zdroje.

## **Často kladené dotazy**

**Kde bych měl začít, pokud jsem nikdy nepoužil Aspose.Slides pro Python přes Java?**

Začněte s průvodci Požadavky systému a Instalace uvedenými výše. Průvodce instalací obsahuje příklad, který můžete spustit k ověření svého prostředí.

**Kde mohu zkontrolovat, zda knihovna podporuje formát mé prezentace?**

Použijte Podporované formáty souborů k ověření vstupních a výstupních formátů, poté konzultujte Přehled funkcí pro operace dostupné pro váš úkol.

**Co bych měl přečíst před úpravou příkladů z Javy pro Python?**

Přečtěte si Omezení a rozdíly API pro pokyny týkající se importů, úklidu zdrojů a manipulace se soubory v Pythonu přes Javu.
