## **Přehled**

Tato sekce vám pomůže připravit prostředí a začít používat Aspose.Slides pro Python přes Java. Proveďte níže uvedené kroky nastavení a poté prozkoumejte možnosti knihovny a doporučení relevantní pro váš projekt.

## **Nastavení knihovny**

1. Prohlédněte si [Systémové požadavky](/slides/cs/python-java/system-requirements/), abyste zkontrolovali operační systém, Python, Java a požadavky na JPype.  
2. Postupujte podle průvodce [Instalace](/slides/cs/python-java/installation/), kde nainstalujete potřebné balíčky a ověříte nastavení pomocí příkladu.  
3. Přečtěte si [Vyhodnocení Aspose.Slides](/slides/cs/python-java/evaluate-aspose-slides/) a objevte omezení hodnocení a možnosti dočasné licence.  
4. Následujte průvodce [Licencování](/slides/cs/python-java/licensing/), abyste použili svou licenci.

## **Prozkoumejte funkce a kompatibilitu**

- [Přehled produktu](/slides/cs/python-java/product-overview/) představuje knihovnu a její schopnosti zpracování prezentací.  
- [Podporované formáty souborů](/slides/cs/python-java/supported-file-formats/) uvádí formáty dostupné pro načítání, import, ukládání a export prezentací.  
- [Přehled funkcí](/slides/cs/python-java/features-overview/) shrnuje převod, vykreslování, úpravy a formátování.  
- [Omezení a rozdíly v API](/slides/cs/python-java/limitations-and-api-differences/) popisuje omezení a rozdíly, které je třeba zvážit při používání Java API z Pythonu.

## **Získat pomoc**

Viz [Podpora produktu](/slides/cs/python-java/product-support/) pro návody na řešení problémů, instrukce pro hlášení chyb a odkazy na další zdroje.

## **Často kladené otázky**

**Kde mám začít, pokud jsem nikdy nepoužíval Aspose.Slides pro Python přes Java?**

Začněte s průvodci Systémové požadavky a Instalace uvedenými výše. Průvodce instalací obsahuje příklad, který můžete spustit a ověřit tak své prostředí.

**Kde mohu zkontrolovat, zda knihovna podporuje formát mé prezentace?**

Použijte sekci Podporované formáty souborů k ověření vstupních a výstupních formátů, poté se podívejte na Přehled funkcí, kde najdete operace dostupné pro váš úkol.

**Co bych měl přečíst před úpravou příkladů v Javě pro Python?**

Přečtěte si sekci Omezení a rozdíly v API, kde najdete pokyny ohledně importů, uvolňování prostředků a manipulace se soubory v Pythonu přes Java.
