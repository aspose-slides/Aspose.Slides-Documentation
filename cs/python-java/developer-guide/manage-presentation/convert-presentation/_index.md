## **Přehled**

Aspose.Slides for Python via Java dokáže načíst prezentace PowerPoint a OpenDocument a uložit je nebo vykreslit do mnoha dalších formátů bez Microsoft PowerPoint, OpenOffice nebo LibreOffice. Můžete převést staré soubory PPT na moderní PPTX, exportovat prezentace do dokumentů s pevnou rozlohou, jako jsou PDF a XPS, publikovat snímky jako HTML nebo vykreslit snímky jako obrázkové soubory pro náhledy, miniatury a archivy.

Většina konverzí dokumentů používá stejný obecný postup: načíst zdrojový soubor, vybrat požadovaný výstupní formát a v případě potřeby aplikovat formátově specifické volby. Pro formáty obrázků se každý snímek vykreslí samostatně a poté uloží jako rastrový nebo vektorový obrázek. Níže uvedené články poskytují podrobnosti o implementaci pro jednotlivé případy.

## **Konverze PowerPoint a OpenDocument**

Aspose.Slides for Python via Java podporuje konverzi z běžně používaných formátů prezentací, jako jsou PPT, PPTX, PPS, PPSX, POT, POTX a ODP. Stejné API pro konverzi se používá pro soubory PowerPoint i OpenDocument, takže workflow, který uloží soubor PPTX do PDF, lze obvykle použít i pro soubor ODP změnou pouze vstupního souboru.

Při konverzi souborů ODP mějte na paměti, že aplikace PowerPoint a OpenDocument nepodporují každé rozložení a formátovací funkce naprosto stejným způsobem. Pokud byl soubor ODP vytvořen v LibreOffice nebo OpenOffice Impress, zkontrolujte výstup a použijte volby popsané v [Convert OpenDocument Presentations](/slides/cs/python-java/convert-openoffice-odp/), když potřebujete formátově specifické pokyny.

## **Převod PPT na PPTX**

PPT je starý binární formát PowerPointu, zatímco PPTX je moderní formát Office Open XML. Aspose.Slides for Python via Java podporuje vysoce věrný převod PPT na PPTX při zachování složitých struktur prezentace, jako jsou mastery, rozložení, snímky, grafy, seskupené tvary, zástupné objekty, textové rámečky, textury a výplně obrázků.

Podrobnosti naleznete v [Convert PPT to PPTX](/slides/cs/python-java/convert-ppt-to-pptx/) a [PPT vs PPTX](/slides/cs/python-java/ppt-vs-pptx/).

## **Export s pevnou rozlohou**

PDF, XPS a TIFF jsou užitečné, když má výstup vypadat stejně na všech zařízeních a neměl by být upravován jako prezentace. Vyhrazené články o PDF, XPS a TIFF vysvětlují, jak řídit shodu, skryté snímky, poznámky, kvalitu obrázku, kompresi, formát pixelů a velikost výstupu.

## **Export HTML a obrázků**

Export do HTML a HTML5 je užitečný pro prohlížení v prohlížeči, webové publikování a lehké sdílení. Export obrázků je užitečný, když každý snímek musí být samostatný náhled, miniatura nebo rastrový zdroj. Použijte články o PNG, JPG a SVG pro formátově specifické pokyny k vykreslování.

## **Často kladené otázky**

**Potřebuji Microsoft PowerPoint k převodu prezentací?**

Ne. Aspose.Slides for Python via Java je samostatná knihovna a nevyžaduje Microsoft PowerPoint ani automatizaci Office.

**Mohu dávkově převádět mnoho prezentací?**

Ano. Načtěte každou prezentaci, uložte ji do požadovaného formátu a po zpracování objekt prezentace uvolněte. Pro paralelní zpracování použijte samostatné instance prezentací a řiďte se pokyny v [multithreading](/slides/cs/python-java/multithreading/).

**Mohu exportovat jen vybrané snímky?**

Ano. Několik metod exportu umožňuje předat indexy snímků nebo vykreslit jednotlivé snímky, v závislosti na výstupním formátu. Viz vyhrazený článek pro cílový formát.

**Mohu zahrnout skryté snímky při exportu do PDF nebo XPS?**

Ano. Použijte nastavení exportu skrytých snímků popsaná v článcích o [PDF](/slides/cs/python-java/convert-powerpoint-to-pdf/) a [XPS](/slides/cs/python-java/convert-powerpoint-to-xps/).

**Mohu vytvořit výstup PDF/A?**

Ano. Nastavení shody PDF jsou k dispozici pro export PDF. Podrobnosti najdete v [Convert PowerPoint to PDF](/slides/cs/python-java/convert-powerpoint-to-pdf/).

**Jak jsou během konverze zacházeno s písmy?**

Aspose.Slides může používat vložená písma, záložní písma a nastavení substituce písem. Viz [Embedded Font](/slides/cs/python-java/embedded-font/), [Fallback Font](/slides/cs/python-java/fallback-font/) a [Font Substitution](/slides/cs/python-java/font-substitution/).
