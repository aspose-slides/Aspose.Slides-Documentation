## Aspose.Slides for .NET

{{% alert color="info" %}}

![Aspose.Slides for .NET Product Logo](home_1.png)

Aspose.Slides for .NET je Microsoft PowerPoint® management API, které umožňuje .NET aplikacím číst a zapisovat PowerPoint® dokumenty bez použití Microsoft PowerPoint®. Aspose.Slides for .NET je první a jediná komponenta, která poskytuje funkci spravovat PowerPoint® dokumenty. Aspose.Slides for .NET nabízí mnoho klíčových funkcí, jako je správa textu, tvarů, tabulek a animací, přidávání audia a videa do snímků, náhled snímků, export snímků do SVG, PDF formátu a další.
