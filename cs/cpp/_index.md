**Vítejte v Aspose.Slides pro C++**

Aspose.Slides for C++ je API pro správu Microsoft PowerPoint® , které umožňuje aplikacím v C++ číst a zapisovat dokumenty PowerPoint® bez použití Microsoft PowerPoint®. Aspose.Slides for C++ je první a jediná komponenta, která poskytuje funkčnost pro správu dokumentů PowerPoint®. Aspose.Slides for C++ nabízí řadu klíčových funkcí, jako je správa textu, tvarů, tabulek a animací, přidávání audia a videa do snímků, náhled snímků, export snímků do formátu SVG, PDF a další.
