## **Přehled**

Tato sekce neobsahuje seznam otevřených problémů v aktuální verzi. Obsahuje tři stránky:

- [Zástupný prvek náhledu objektu při přidání OleObjectFrame](/slides/cs/java/object-preview-issue-when-adding-oleobjectframe/) vysvětluje, proč OLE objekt přidaný pomocí Aspose.Slides zobrazuje obrázek „EMBEDDED OLE OBJECT“, dokud není jeho náhled aktualizován, a jak nastavit vlastní obrázek náhledu. Jedná se o zamýšlené chování aktuální verze.
- [Známé problémy v Aspose.Slides pro Java 14.3.0 (historické)](/slides/cs/java/known-issues-in-aspose-slides-for-java-14-3-0/) a [Známé problémy v Aspose.Slides pro Java 14.4.0 (historické)](/slides/cs/java/known-issues-in-aspose-slides-for-java-14-4-0/) jsou seznamy publikované s těmito verzemi, zachovány pro referenci.

Pro změny a opravy v jednotlivých verzích viz [poznámky k vydání](https://releases.aspose.com/slides/cs/java/release-notes/). Metaznačovací pole, která Aspose.Slides zapisuje s pevnými hodnotami, jsou popsána v [Omezení výstupní metadata](/slides/cs/java/api-limitations/). Pro kontrolu, zda je problém již znám, nebo pro jeho nahlášení, použijte [fórum podpory](https://forum.aspose.com/c/slides/cs/11).
