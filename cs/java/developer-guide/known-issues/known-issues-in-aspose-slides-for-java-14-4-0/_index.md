{{% alert color="info" %}} 

Aspose.Slides pro Java 14.4.0 poskytuje nové rozhodnutí pro zpracování dokumentů PowerPoint. Existují některá omezení a známé problémy, které budou v nadcházejících verzích odstraněny:

- Některé tvary mají v serializovaných PPT dokumentech nesprávnou geometrii (oblouk, kruhová šipka, popisky).
- Ne všechny funkce formátování textu v PPTX jsou podporovány při serializaci do PPT (omezení tabulátorů, odsazení a formátování odstavců).
- Informace o jazykových a pravopisných nastaveních textu nejsou v serializovaných PPT dokumentech přítomny.
- Ne všechny funkce motivu PPTX jsou podporovány při serializaci do PPT (pouze serializace výplní, formátů čar a písma).
- Existují známé problémy při OLE/ActiveX serializaci PPT do PPT.
- Serializace a vykreslování WordArt není podporována.
