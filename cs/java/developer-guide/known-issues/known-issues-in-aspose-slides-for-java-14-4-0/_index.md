{{% alert color="info" title="Note" %}}

Toto je historická stránka. Uvádí omezení a známé problémy publikované s Aspose.Slides pro Java 14.4.0 a nepopisuje aktuální verzi. Pro změny v jednotlivých verzích viz [release notes](https://releases.aspose.com/slides/cs/java/release-notes/).

{{% /alert %}}

Aspose.Slides pro Java 14.4.0 poskytuje nové řešení pro zpracování dokumentů PowerPoint. Existují některá omezení a známé problémy, které budou v budoucích verzích odstraněny:

- Některé tvary mají nesprávnou geometrii v serializovaných PPT dokumentech (oblouk, kruhová šipka, bubliny).
- Ne všechny funkce formátování textu v PPTX jsou podporovány při serializaci do PPT (tabulace, odsazení a omezení formátování odstavců).
- Informace o jazyce textu a nastavení pravopisu nejsou v serializovaných PPT dokumentech přítomny.
- Ne všechny funkce motivu PPTX jsou podporovány při serializaci do PPT (pouze serializace výplní, čar a písma).
- Existují známé problémy při serializaci OLE/ActiveX PPT do PPT.
- Serializace a vykreslování WordArtu nejsou podporovány.
