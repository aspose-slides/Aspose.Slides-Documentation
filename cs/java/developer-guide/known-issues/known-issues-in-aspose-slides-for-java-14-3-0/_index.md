{{% alert color="info" title="Note" %}}

Toto je historická stránka. Obsahuje seznam známých problémů zveřejněných s Aspose.Slides for Java 14.3.0 a nepopisuje aktuální verzi. Pro změny v jednotlivých verzích viz [poznámky k vydání](https://releases.aspose.com/slides/cs/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) poskytuje zcela novou implementaci zpracování PPT. Existuje mnoho vylepšení, částečná konverze PPTX na PPT. Avšak některé funkce ještě nejsou implementovány:

- Některé tvary mají nesprávnou geometrii v serializovaných PPT dokumentech (Call outs)
- Nejsou podporovány všechny funkce formátování textu PPTX při serializaci do PPT
- Informace o jazyce textu a nastaveních pravopisu nejsou v serializovaných PPT dokumentech přítomny
- Nejsou podporovány všechny funkce motivů PPTX při serializaci do PPT

**Existují některé rozdíly ve srovnání s Aspose.Slides for Java 8.6.0:**

- V serializaci PPT z OLE/ActiveX jsou známy problémy

**Existují některé rozdíly ve srovnání s Aspose.Slides for .NET 14.3.0:**

- Podpora tisku prezentací není v současné době v Aspose.Slides for Java k dispozici
