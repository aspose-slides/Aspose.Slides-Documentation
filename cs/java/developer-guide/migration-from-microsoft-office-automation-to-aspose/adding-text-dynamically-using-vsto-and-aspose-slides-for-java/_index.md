Běžnou úlohou, kterou vývojáři často vykonávají, je dynamické přidávání textu do snímků. Tento článek ukazuje ukázky kódu pro dynamické přidávání textu pomocí [VSTO](/slides/cs/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/) a [Aspose.Slides for Java](/slides/cs/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/).
{{% /alert %}} 
## **Adding Text Dynamically**
Obě metody následují tyto kroky:

1. Vytvořte prezentaci.
1. Přidejte prázdný snímek.
1. Přidejte textové pole.
1. Nastavte nějaký text.
1. Uložte prezentaci.
