## **Podpora starého kódu**
Aby bylo možné použít starý kód vyvinutý pro Aspose.Slides pro Java ve verzích před 13.x, musíte provést některé drobné úpravy ve vašem kódu a kód bude fungovat jako dříve. Všechny třídy, které byly ve starém Aspose.Slides pro Java v jmenných prostorech Aspose.Slide a Aspose.Slides.Pptx, jsou nyní sloučeny do jednoho jmenného prostoru Aspose.Slides. Podívejte se na následující jednoduchý ukázkový kód pro přidání záhlaví a zápatí do prezentace ve starém API Aspose.Slides a postupujte podle kroků popisujících, jak migrovat na nově sloučené API.
