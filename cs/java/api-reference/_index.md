{{% alert color="info" %}}

Aspose.Slides for Java je knihovna tříd, která umožňuje aplikacím Java číst a zapisovat prezentační dokumenty bez použití Microsoft PowerPoint® nebo jiných. Aspose.Slides for Java umožňuje spravovat text, tvary, tabulky a animace, přidávat audio a video do snímků, zobrazovat náhledy snímků, exportovat snímky do formátu SVG, PDF a další.

Nejnovější referenční API lze najít na [Reference API Aspose.Slides for Java](https://reference.aspose.com/slides/cs/java).

{{% /alert %}}
