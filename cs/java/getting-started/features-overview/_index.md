## **Podporované platformy**
Aspose.Slides pro Java podporuje nejoblíbenější vývojové a nasazovací platformy.

|**Funkce**|**Popis**|
| :- | :- |
|Desktopové aplikace|Aspose.Slides pro Java může být použito k vývoji aplikací Windows Forms|
|Podnikové webové aplikace|Použití Aspose.Slides pro Java pomáhá vytvářet webové aplikace. Podpora použití Aspose.Slides pro Java s PHP je také poskytována.|

## **Často kladené otázky**

### Musím mít nainstalovaný Microsoft PowerPoint na serveru/PC, aby knihovna fungovala?
Ne. PowerPoint není vyžadován; Aspose.Slides je samostatný engine pro vytváření, úpravu, konverzi a renderování prezentací.

### Jak funguje multithreading? Může být zpracování paralelizováno?
Je bezpečné zpracovávat různé dokumenty v různých vláknech; stejný [prezentace](https://reference.aspose.com/slides/cs/java/com.aspose.slides/presentation/) objekt nesmí být používán [více vlákny](/slides/cs/java/multithreading/) současně.

### Jsou podporována hesla a šifrování souborů?
Ano. [Můžete](/slides/cs/java/password-protected-presentation/) otevřít šifrované prezentace, nastavit nebo odstranit otevření a zápis hesla a zkontrolovat stav ochrany.

### Musím se starat o balíčky písem v Linux kontejnerech?
Ano. Doporučuje se nainstalovat běžné balíčky písem a/nebo výslovně [specifikovat adresáře písem](/slides/cs/java/custom-font/) ve vaší aplikaci, aby se předešlo neočekávaným náhradám.

### Existují omezení v evaluační verzi?
V [evaluačním režimu](/slides/cs/java/licensing/) je do výstupu přidán vodoznak a platí určitá omezení; [30denní dočasná licence](https://purchase.aspose.com/temporary-license/) je k dispozici pro testování všech funkcí.

### Je podporováno importování externích formátů do prezentace (PDF/HTML → PPTX)?
Ano. Můžete přidat [PDF stránky a HTML obsah](/slides/cs/java/import-presentation/) do prezentace, čímž je převodíte na snímky.
