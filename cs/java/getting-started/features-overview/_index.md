## **Přehled**

Aspose.Slides for Java je knihovna tříd pro vytváření, čtení, úpravu, konverzi a vykreslování prezentací PowerPoint a OpenDocument. Nemá vlastní uživatelské rozhraní a nevyžaduje Microsoft PowerPoint ani Microsoft Office. Tento článek shrnuje, co knihovna zahrnuje, a odkazuje na články, které popisují jednotlivé oblasti.

## **Podporované platformy**

Aspose.Slides for Java je jediný soubor JAR, publikovaný v Maven repozitáři Aspose s klasifikátorem `jdk16`. Je napsán čistě v Javě: soubor JAR neobsahuje nativní knihovny a nezávisí na dalších balíčcích.

- **Java:** Java 8 nebo novější. Aspose.Slides for Java 26.9 a starší verze běží také na Java 6 a 7, podporu pro které verze 26.10 již neposkytuje; viz [poznámky k vydání 26.9](https://releases.aspose.com/slides/cs/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/).
- **Operační systémy:** libovolný operační systém s Java runtime, například Windows, Linux a macOS. Na Linuxu musí být nainstalována knihovna fontconfig a alespoň jeden font.

[Instalace](/slides/cs/java/installation/) ukazuje, jak přidat knihovnu do projektu a uvádí předpoklady pro Linux. [Systémové požadavky](/slides/cs/java/system-requirements/) podrobně uvádí podporované platformy.

## **Formáty souborů a konverze**

Aspose.Slides otevírá a ukládá prezentace PPT, PPTX, PPS, POT, PPSX, POTX, PPTM, PPSM, POTM, ODP, OTP, FODP a PowerPoint XML. Importuje obsah PDF a HTML do snímků a ukládá prezentace jako PDF, XPS, HTML, HTML5, TIFF, animovaný GIF, SWF, Markdown a XAML. [Podporované formáty souborů](/slides/cs/java/supported-file-formats/) uvádí každý formát s API, které jej čte nebo zapisuje.

## **Vykreslování prezentací**

Aspose.Slides vykresluje snímky a jednotlivé tvary jako PNG, JPEG, BMP, GIF, TIFF a SVG obrázky a snímky jako EMF metafily. ## **Často kladené otázky**

**Potřebuji nainstalovat Microsoft PowerPoint na server nebo PC, aby knihovna fungovala?**

Ne. PowerPoint není vyžadován; Aspose.Slides je samostatný engine pro vytváření, úpravu, konverzi a vykreslování prezentací.

**Jak funguje multithreading? Lze zpracování paralelizovat?**

Je bezpečné zpracovávat různé dokumenty v různých vláknech; stejný objekt [Presentation](https://reference.aspose.com/slides/cs/java/com.aspose.slides/presentation/) nesmí být používán [více vlákny](/slides/cs/java/multithreading/) současně.

**Jsou podporována hesla souborů a šifrování?**

Ano. [Můžete](/slides/cs/java/password-protected-presentation/) otevřít šifrované prezentace, nastavit nebo odebrat heslo pro otevření i zápis a zkontrolovat stav ochrany.

**Musím řešit fonty v Linux kontejnerech?**

Ano. Na Linuxu musí být nainstalována knihovna fontconfig a alespoň jeden font, a fonty použité ve vašich prezentacích nebo vhodné náhrady musí být nainstalovány, aby se text správně vykresloval. V aplikaci můžete také [specifikovat adresáře s fonty](/slides/cs/java/custom-font/). Viz [Instalace](/slides/cs/java/installation/#linux).

**Existují omezení ve zkušební verzi?**

Ano. Bez [licence](/slides/cs/java/licensing/) Aspose.Slides přidává do každého uloženého snímku vodotisk pro hodnocení a zkracuje text, který váš kód čte přes API. Pro plnohodnotné testování je k dispozici [30denní dočasná licence](https://purchase.aspose.com/temporary-license/).

**Je podporován import externích formátů do prezentace (PDF nebo HTML do PPTX)?**

Ano. Můžete přidat [stránky PDF a HTML obsah](/slides/cs/java/import-presentation/) do prezentace, čímž se převádějí na snímky.
