## **O TIFF**

Formát Tagged Image File Format, který je známý ukládáním více obrázků do jednoho dokumentu, byl původně vytvořen společností Aldus. Tento formát je široce podporován skenovacími, faxovacími a dalšími aplikacemi pro manipulaci s obrázky.

## **TIFF v Aspose.Slides pro Java**

Jakýkoli dokument, který lze načíst v Aspose.Slides pro Java, lze také přímo převést do TIFF dokumentu pomocí Aspose.Slides pro Java, což eliminuje potřebu jakýchkoli komponent třetích stran. Dále můžete volitelně definovat velikost obrázků v výsledném TIFF dokumentu. Informace o exportu prezentačních dokumentů do TIFF dokumentů pomocí Aspose.Slides pro Java najdete v [Konvertovat prezentace PowerPoint do TIFF](/slides/cs/java/convert-powerpoint-to-tiff/).
