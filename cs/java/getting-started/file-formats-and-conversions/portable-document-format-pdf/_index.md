[Portable Document Format](https://en.wikipedia.org/wiki/PDF) je souborový formát vytvořený společností Adobe Systems pro výměnu dokumentů mezi organizacemi. Účelem formátu bylo zachovat obsah a rozvržení beze změny, bez ohledu na platformu, na které byl zobrazen. Aspose.Slides pro Java vám umožňuje převádět soubory prezentací do PDF.

{{% /alert %}}

## **PDF v Aspose.Slides pro Java**
Každou prezentaci, kterou lze načíst do Aspose.Slides pro Java, lze převést do PDF, který odpovídá standardu [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) nebo [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) podle vašeho výběru. Aspose.Slides pro Java exportuje prezentace do PDF a ve většině případů výstupní PDF vypadá přesně jako původní prezentace.

Aspose.Slides podporuje při převodu do PDF následující funkce prezentace:

- Obrázky, textová pole a další tvary.
- Text a formátování.
- Odstavce a formátování.
- Hyperlinky.
- Záhlaví a zápatí.
- Odrážky.
- Tabulky.

Prezentace můžete exportovat do PDF přímo pomocí Aspose.Slides pro Java: nepotřebujete žádnou další komponentu. Navíc můžete přizpůsobit export prezentace do PDF pomocí různých možností, jak je vysvětleno v [Převod PPT a PPTX do PDF](/slides/cs/java/convert-powerpoint-to-pdf/).
