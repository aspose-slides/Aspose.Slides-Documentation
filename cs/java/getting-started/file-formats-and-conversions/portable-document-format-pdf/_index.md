{{% alert color="info" %}} 

Portable Document Format je souborový formát vytvořený společností Adobe Systems pro výměnu dokumentů mezi organizacemi. Účelem formátu je zachovat obsah a rozvržení beze změny, bez ohledu na platformu, na které je prohlížen. Aspose.Slides for Java vám umožňuje převádět soubory prezentací do formátu PDF.

{{% /alert %}} 

## **PDF v Aspose.Slides for Java**
Jakákoli prezentace, kterou lze načíst do Aspose.Slides for Java, může být převedena do PDF, které odpovídá standardu [PDF 1.5](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) nebo [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) podle vašeho výběru. Aspose.Slides for Java exportuje prezentace do PDF a ve většině případů vypadá výstupní PDF přesně jako původní prezentace.

Aspose.Slides podporuje následující funkce prezentace při převodu do PDF:

- Obrázky, textová pole a další tvary.
- Text a formátování.
- Odstavce a formátování.
- Hypertextové odkazy.
- Záhlaví a závěry.
- Odrážky.
- Tabulky.

Můžete exportovat prezentace do PDF přímo pomocí Aspose.Slides for Java: nepotřebujete žádnou další komponentu. Dále můžete přizpůsobit export prezentace do PDF pomocí různých možností, jak je vysvětleno v [Převod do PDF](/slides/cs/java/converting-a-presentation/).
