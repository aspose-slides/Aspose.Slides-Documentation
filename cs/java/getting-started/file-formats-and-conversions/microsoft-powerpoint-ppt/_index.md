{{% alert color="info" title="Poznámka" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) je formát souboru prezentačního dokumentu, který může být vytvořen, čten, upravován a zapisován různými verzemi Microsoft PowerPoint. Jedná se o binární formát prezentačních dokumentů vyvinutý společností Microsoft.

{{% /alert %}}

## **PPT v Aspose.Slides for Java**
Aspose.Slides for Java může číst soubory PPT vytvořené následujícím softwarem.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Obdobně soubory PPT vytvořené pomocí Aspose.Slides for Java mohou být čteny výše uvedeným softwarem.

## **Komplexní podpora pro PPT**
Aspose.Slides for Java poskytuje podporu pro téměř všechny funkce, které formát souboru PPT podporuje. Nepokrývá jen základní a pokročilé funkce různých verzí Microsoft PowerPoint pro manipulaci s PPT dokumenty, ale také funkce, které Microsoft PowerPoint vůbec nepodporuje. Hlavní výhodou používání knihovny Aspose.Slides for Java API je snadnost použití při práci s těmito funkcemi.

Kromě základních úkolů souvisejících s vytvářením, čtením a zápisem souborů PPT existuje několik funkcí, které Aspose.Slides for Java poskytuje:

- Importovat další formáty souborů Microsoft Office jako [OLE objekty do PPT dokumentů](/slides/cs/java/manage-ole/).
- [Exportovat PPT dokumenty do PDF](/slides/cs/java/convert-powerpoint-to-pdf/).
- Exportovat snímky v PPT dokumentech do formátu SVG.
- Vykreslovat snímky do libovolného formátu obrázku podporovaného Java Frameworkem.
- Nastavit velikost snímků v PPT dokumentech.
- Spravovat animace na tvarech.
- Spravovat prezentace.
- [Formátovat text na snímcích](/slides/cs/java/text-formatting/).
- Extrahovat text z PPT dokumentů.
- [Zpracovávat tabulky na snímcích](/slides/cs/java/powerpoint-table/).
- Automaticky kopírovat mastery pomocí [funkce klonování](/slides/cs/java/clone-slides/).
