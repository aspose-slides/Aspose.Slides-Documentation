Toto je historická stránka, zachovaná pro existující odkazy. Nepopisuje aktuální verzi Aspose.Slides pro Java. Pro formáty, které Aspose.Slides pro Java načítá, importuje, ukládá a vykresluje, a API pro každý z nich, viz [Supported File Formats](/slides/cs/java/supported-file-formats/). {{% /alert %}}

{{% alert color="info" title="Note" %}}

Specifikace XML Paper (XML Paper Specification) je jazyk pro popis stránek a formát fixovaného dokumentu, původně vyvinutý společností Microsoft. Podobně jako PDF je XPS navržen tak, aby zachoval věrnost dokumentu a poskytoval nezávislý vzhled dokumentu na zařízení.

{{% /alert %}}

## **XPS v Aspose.Slides pro Java**
Jakýkoli prezentační dokument, který lze načíst pomocí Aspose.Slides pro Java, lze převést do formátu XPS. Aspose.Slides pro Java používá vysoce věrný engine rozvržení stránky a vykreslování k vytvoření výstupu ve formátu XPS s pevně daným rozvržením. O exportu prezentačních dokumentů do XPS dokumentů pomocí Aspose.Slides pro Java se můžete dozvědět v [Convert PowerPoint Presentations to XPS](/slides/cs/java/convert-powerpoint-to-xps/).
