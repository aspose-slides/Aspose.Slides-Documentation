## **Přehled**

Tento článek vysvětluje, jak získat podporu pro Aspose.Slides a jak efektivně hlásit problémy. Popisuje hlavní kanál podpory, poskytuje doporučení pro podání problému a odkazuje na užitečné technické zdroje, jako je stránka produktu, blog, ke stažení, fórum podpory, dokumentace a API Reference. Článek také odpovídá na časté otázky o placené podpoře, eskalaci problémů a podpoře starších verzí knihovny.

## **Technická podpora**

{{% alert color="info" %}} 

Aspose poskytuje neomezenou bezplatnou technickou podporu pro všechny své produkty. Podpora je k dispozici všem uživatelům, včetně testovacích verzí.

{{% /alert %}} 

Pokud potřebujete pomoc s Aspose.Slides pro Java, zvažte následující:

- Hlavním kanálem podpory jsou Aspose.Forums. Zveřejněte svůj dotaz ve fóru Aspose.Slides a bude zodpovězen během několika hodin. Na otázky odpovídá přímo tým podpory Aspose.Slides.
- Všimněte si, že Aspose neposkytuje technickou podporu po telefonu. Telefonická podpora je k dispozici pouze pro dotazy týkající se prodeje a nákupu.
- Při čekání na odpověď ve fórech zohledněte rozdíly v časových pásmech.

Pokud máte problém s Aspose.Slides pro Java, postupujte podle těchto jednoduchých kroků, aby byl vyřešen co nejefektivněji:

- Ujistěte se, že používáte nejnovější verzi Aspose.Slides pro Java před nahlášením problému, viz Aspose.Slides download a zjistěte nejnovější verzi.
- Prohlédněte si fóra, tuto dokumentaci a API Reference před nahlášením problému; možná je váš dotaz již zodpovězen.
- Při hlášení problému připojte původní dokument a případně fragment kódu, který problém způsobuje. Pokud potřebujete připojit více souborů, zkomprimujte je do jednoho zipu. Je bezpečné připojit dokumenty na Aspose.Forums, protože k připojeným souborům mají přístup jen vy a vývojáři Aspose.
- Pokuste se hlásit jeden problém na jedno vlákno. Pokud máte další problém, vytvořte samostatné vlákno.

## **Často kladené otázky**

### Jaké úrovně placené podpory jsou k dispozici a jak se liší?

[Vývojář, Obchodní a Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). Liší se počtem zahrnutých incidentů, prioritou odezvy a dostupnými komunikačními kanály.

### Mohu eskalovat chybu přímo na tým inženýrů?

Ano. [Placená podpora](https://helpdesk.aspose.com/) umožňuje eskalaci k vývojářům, když problém vyžaduje podrobnější vyšetření.

### Jsou podporovány starší verze knihovny a vydáváte pro ně opravy?

Starší verze můžete používat, ale opravy jsou poskytovány pouze pro aktuální vydání; opravy pro starší verze nejsou vydávány.
