Aspose.Slides for Reporting Services je rozšíření pro Microsoft SQL Server Reporting Services a Power BI Report Server, které přidává formáty prezentací do seznamu exportu stránkovaných (RDL) zpráv, aniž by na serveru byl nainstalován Microsoft PowerPoint.

Exportuje zprávy do PPT, PPTX, PPS a PPSX prezentací a prezentací snímků, do ODP a do XPS.

## **Váš první export**

Není třeba psát žádný kód: rozšíření nainstalujete na server zpráv a jeho formáty se objeví v seznamu exportu každé stránkované zprávy na tomto serveru.

1. Zkontrolujte, že server zpráv splňuje [systémové požadavky](/slides/cs/reportingservices/system-requirements/), včetně .NET Framework 3.5.
2. Ze [stránky ke stažení](https://releases.aspose.com/slides/reportingservices/), stáhněte MSI instalátor, *Aspose.Slides for Reporting Services*. Pro ruční instalaci místo toho stáhněte ZIP balíček, *Aspose.Slides for Reporting Services (DLLs Only)*.
3. Nainstalujte rozšíření na server zpráv: spusťte MSI jako administrátor, jak je popsáno v [Instalace pomocí MSI instalátoru](/slides/cs/reportingservices/install-with-msi-installer/), nebo postupujte podle [Instalace ručně](/slides/cs/reportingservices/install-manually/) pro ZIP balíček.
4. V prohlížeči otevřete webový portál serveru zpráv (Report Manager na SQL Serveru 2014 a starších). Ve výchozím nastavení je jeho adresa `https://<ComputerName>/reports`.
5. Otevřete stránkovanou zprávu. Na panelu nástrojů zprávy otevřete seznam **Export** a vyberte **PPTX - PowerPoint 2007 Presentation via Aspose.Slides**. Pokud má panel nástrojů samostatné tlačítko **Export**, jako má Report Manager, vyberte jej.
6. Otevřete nebo uložte soubor PPTX, který prohlížeč stáhne.

Bez licence má exportovaná prezentace vodotisk s hodnocením — viz [Licencování](/slides/cs/reportingservices/license-aspose-slides-for-reporting-services/). Pro ostatní formáty v seznamu exportu viz [Podporované formáty souborů](/slides/cs/reportingservices/supported-file-formats/).
