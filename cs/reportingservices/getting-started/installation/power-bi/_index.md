## **Power BI**

Aspose.Slides for Reporting Services můžete nainstalovat na Power BI Report Server stejnými instalačními postupy:

* [Instalovat pomocí MSI instalátoru](/slides/cs/reportingservices/install-with-msi-installer/). Instalační program automaticky detekuje nainstalovaný Power BI Report Server, nainstaluje produkt a poté jej nakonfiguruje pro vaše pracovní prostředí.
* [Instalovat ručně](/slides/cs/reportingservices/install-manually/). Použijte sestavení z adresáře *Bin\Universal* balíčku ZIP.

Aspose.Slides for Reporting Services exportuje stránkované reporty (RDL) z Power BI Report Server. Pro požadavky, včetně .NET Framework 3.5 na hostitelském počítači, viz [Požadavky systému](/slides/cs/reportingservices/system-requirements/).
