## **Podporované platformy**
Aspose.Slides for Node.js via .NET je platformně nezávislé API. Lze jej použít na jakékoli platformě (Windows, Linux, macOS atd.), kde je nainstalován Node.js verze 7 nebo vyšší. Oracle JDK 8 nebo vyšší je dalším požadavkem.

## **Formáty souborů a konverze**
Aspose.Slides for Node.js via .NET podporuje většinu formátů dokumentů PowerPoint. Umožňuje také export do populárních formátů souborů, které organizace používají a sdílejí mezi sebou. Projděte si tyto podrobnosti:

|**Funkce**|**Popis**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET poskytuje nejrychlejší zpracování tohoto formátu prezentačního dokumentu.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET podporuje konverzi PPT na PPTX.|
|Portable Document Format (PDF)|Pomocí jedné metody můžete exportovat všechny podporované formáty souborů do dokumentů Adobe Portable Document Format (PDF).|
|XML Parser Specification (XPS)|Pomocí jedné metody můžete exportovat všechny podporované formáty souborů do dokumentů XML Parser Specification (XPS).|
|Tagged Image File Format (TIFF)|Pomocí jedné metody můžete exportovat všechny podporované prezentační formáty souborů do Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET podporuje konverzi PresentationEx do formátu HTML.|

Aspose.Slides for Node.js via .NET podporuje vysoce kvalitní renderování snímků v prezentaci do různých grafických formátů. Projděte si tyto podrobnosti:

|**Funkce**|**Popis**|
| :- | :- |
|.NET Supported Image Formats|Pomocí Aspose.Slides for Node.js via .NET můžete vykreslovat snímky prezentace a obrázky na snímcích do všech grafických formátů podporovaných .NET, jako jsou TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via .NET také poskytuje zabudované metody, které umožňují exportovat snímky prezentace do formátů Scalable Vector Graphics (SVG).|
