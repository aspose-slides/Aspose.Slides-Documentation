## **Přehled**

Aspose.Slides for Android via Java může načíst prezentace PowerPoint a OpenDocument a uložit nebo vykreslit je do mnoha dalších formátů bez Microsoft PowerPoint, OpenOffice nebo LibreOffice. Můžete převést staré soubory PPT na moderní PPTX, exportovat prezentace do dokumentů s pevnou podobou, jako jsou PDF a XPS, publikovat snímky jako HTML nebo vykreslit snímky jako soubory obrázků pro náhledy, miniatury a archivy.

Většina konverzí dokumentů používá stejný obecný postup: načíst zdrojový soubor, vybrat požadovaný výstupní formát a v případě potřeby použít možnosti specifické pro formát. Pro obrazové formáty se každý snímek vykreslí samostatně a pak uloží jako rastrový nebo vektorový obrázek. Níže uvedené články poskytují podrobnosti o implementaci pro každý případ.

## **Konverze PowerPoint a OpenDocument**

Aspose.Slides for Android via Java podporuje konverzi ze běžně používaných formátů prezentací, jako jsou PPT, PPTX, PPS, PPSX, POT, POTX a ODP. Stejná konverzní API se používá pro soubory PowerPoint i OpenDocument, takže pracovní postup, který uloží soubor PPTX do PDF, lze obvykle použít i pro soubor ODP pouhou změnou vstupního souboru.

Při konverzi ODP souborů mějte na paměti, že aplikace PowerPoint a OpenDocument nepodporují každé rozložení a formátovací funkce přesně stejným způsobem. Pokud byl ODP soubor vytvořen v LibreOffice nebo OpenOffice Impress, zkontrolujte výstup a použijte možnosti popsané v [Převést OpenDocument prezentace](/slides/cs/androidjava/convert-openoffice-odp/) když potřebujete vodítko specifické pro formát.

## **Konverze PPT na PPTX**

PPT je starší binární formát PowerPoint, zatímco PPTX je moderní formát Office Open XML. Aspose.Slides for Android via Java podporuje vysoce věrnou konverzi PPT na PPTX při zachování komplexních struktur prezentace, jako jsou mastery, rozvržení, snímky, grafy, seskupené tvary, rezervované prostory, textové rámečky, textury a výplně obrázky.

Podrobnosti najdete v [Převést PPT na PPTX](/slides/cs/androidjava/convert-ppt-to-pptx/) a [PPT vs PPTX](/slides/cs/androidjava/ppt-vs-pptx/).

## **Export s pevnou podobou**

PDF, XPS a TIFF jsou užitečné, když má výstup vypadat stejně na různých zařízeních a neměl by být editován jako prezentace. Vyhrazené články o PDF, XPS a TIFF vysvětlují, jak řídit shodu, skryté snímky, poznámky, kvalitu obrazu, kompresi, pixelový formát a velikost výstupu.

## **Export do HTML a obrázků**

Export do HTML a HTML5 je užitečný pro prohlížení v prohlížeči, webové publikování a lehké sdílení. Export obrázků je vhodný, když má každý snímek být samostatným náhledem, miniaturou nebo rastrovým aktivem. Použijte články o PNG, JPG a SVG pro vodítka specifická pro formát.

## **Často kladené otázky**

**Potřebuji Microsoft PowerPoint k převodu prezentací?**

Ne. Aspose.Slides for Android via Java je samostatná knihovna a nevyžaduje Microsoft PowerPoint ani automatizaci Office.

**Mohu hromadně převést mnoho prezentací?**

Ano. Načtěte každou prezentaci, uložte ji do požadovaného formátu a po zpracování objekt prezentace uvolněte. Pro paralelní zpracování použijte samostatné instance prezentací a řiďte se radami o [vícevláknovém zpracování](/slides/cs/androidjava/multithreading/).

**Mohu exportovat jen vybrané snímky?**

Ano. Několik metod exportu vám umožní předat indexy snímků nebo vykreslit jednotlivé snímky, v závislosti na výstupním formátu. Viz vyhrazený článek pro cílový formát.

**Mohu zahrnout skryté snímky při exportu do PDF nebo XPS?**

Ano. Použijte nastavení exportu skrytých snímků popsaná v článcích o [PDF](/slides/cs/androidjava/convert-powerpoint-to-pdf/) a [XPS](/slides/cs/androidjava/convert-powerpoint-to-xps/).

**Mohu vytvořit výstup PDF/A?**

Ano. Pro export PDF jsou k dispozici nastavení shody PDF/A. Podrobnosti najdete v [Převést PowerPoint na PDF](/slides/cs/androidjava/convert-powerpoint-to-pdf/).

**Jak jsou písma zpracovávána během konverze?**

Aspose.Slides může používat vložená písma, náhradní písma a nastavení substituce písem. Viz [Vložené písmo](/slides/cs/androidjava/embedded-font/), [Náhradní písmo](/slides/cs/androidjava/fallback-font/) a [Substituce písem](/slides/cs/androidjava/font-substitution/).
