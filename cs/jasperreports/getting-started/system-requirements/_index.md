## **JasperReports**

Aspose.Slides pro JasperReports funguje s JasperReports 3.7.2 až 6.16.0. Ke stažení je samostatný jar pro každé ze tří rozsahů verzí — viz [Instalace Aspose.Slides pro JasperReports](/slides/cs/jasperreports/installing-aspose-slides-for-jasperreports/) pro výběr správného. Pro JasperReports 6.17.0 a novější, včetně JasperReports 7, není k dispozici žádný jar.

Podpora pro JasperReports 2.0.3 až 3.7.1 skončila v Aspose.Slides pro JasperReports 17.6. Verze 17.5 a starší také podporovaly tyto verze.

## **Java**

Jar soubory jsou kompilovány pro Java 6 nebo novější, jak uvádí *JDK 1.6* v názvech složek, takže verze Javy, kterou potřebujete, je ta, kterou vyžaduje vaše verze JasperReports. S JasperReports 6.16.0 běží exporty na Java 11, 17, 21 a 25.

## **Operating system**

Jar soubory obsahují pouze třídy Java a zdroje, nemají žádné nativní knihovny a nepoužívají Microsoft PowerPoint. Na Linuxu JasperReports potřebuje fontconfig a alespoň jeden nainstalovaný font k vytvoření zprávy.

## **JasperReports Server**

Pro JasperReports Server použijte oba jar soubory ze složky, která odpovídá verzi JasperReports, na které server běží — viz [Integrace s JasperServer](/slides/cs/jasperreports/integration-with-jasperserver/).
