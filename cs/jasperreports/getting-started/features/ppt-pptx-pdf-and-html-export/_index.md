{{% alert color="info" %}} 

JasperReports a JasperServer nemají vestavěné možnosti exportovat zprávy jako prezentace Microsoft PowerPoint, ale s Aspose.Slides for JasperReports získáte přístup k dalším exportním formátům:

- Microsoft PowerPoint prezentace (PPT)
- Microsoft PowerPoint prezentace (PPTX)
- HTML
- PDF

{{% /alert %}} 

Pro vytváření dokumentů v těchto formátech Aspose.Slides for JasperReports používá vestavěnou verzi [Aspose.Slides for Java](https://products.aspose.com/slides/cs/java/), přední knihovnu pro zpracování prezentací na trhu od společnosti Aspose. Microsoft PowerPoint se nepoužívá k vytvoření dokumentů.
