{{% alert color="info" title="Note" %}}

S Aspose.Slides for SharePoint můžete převádět prezentace PowerPoint do mnoha populárních formátů dokumentů přímo z knihovny dokumentů SharePoint.

{{% /alert %}}

## **Podporované vstupní formáty**

Aspose.Slides for SharePoint převádí následující vstupní formáty:

- PPT – Microsoft PowerPoint prezentace 97-2003
- PPTX – Office Open XML prezentace

{{% alert color="info" title="Note" %}}

Pro převod dokumentů Aspose.Slides for SharePoint spoléhá na vestavěnou verzi [Aspose.Slides for .NET](https://products.aspose.com/slides/cs/net/).

{{% /alert %}}

## **Podporované výstupní formáty**

Seznam Convert to na stránce převodu nabízí následující výstupní formáty v tomto pořadí:

- PDF – Adobe Portable Document
- TIFF – balík obrázků
- XPS – specifikace XML Paper
- PPS – prezentace pro promítání snímků
- PPSX – Microsoft PowerPoint Open XML Slide Show
- ODP – OpenDocument prezentace
- PPTM – Microsoft PowerPoint Open XML prezentace s makry
- PPSM – Microsoft PowerPoint Open XML promítání snímků s makry
- POTX – šablona Microsoft PowerPoint
- POTM – šablona Microsoft PowerPoint Open XML s makry
- PDFNotes – poznámky prezentace ve formátu PDF
- HTML – prezentace ve formátu HTML
- TIFFNotes – poznámky prezentace jako vícestránkový TIFF obrázek
- SWF – Shockwave Flash film
- SWFNotes – poznámky prezentace jako vícestránkový SWF
