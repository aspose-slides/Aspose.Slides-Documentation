Weby SharePoint jsou určeny pro spolupráci, komunikaci a ukládání obsahu za účelem naplnění konkrétních obchodních potřeb. Umožňují skupině lidí dosáhnout společného cíle usnadněním sdílení informací a komunikace. Informace jsou nejčastěji k dispozici jako webová stránka a jsou přístupné prostřednictvím webového prohlížeče.

{{% /alert %}}

## **Co je SharePoint a Aspose.Slides?**

Aspose.Slides pro SharePoint je řešení pro převod prezentací Microsoft PowerPoint (PPT a PPTX) do dalších formátů: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX a POTM. Umožňuje převádět soubory PowerPoint na webu SharePoint bez použití Microsoft PowerPoint. Úplný seznam formátů je v [Supported File Formats](/slides/cs/sharepoint/supported-file-formats/).
