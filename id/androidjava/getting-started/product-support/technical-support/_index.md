## **Gambaran Umum**

Artikel ini menjelaskan cara mendapatkan dukungan untuk Aspose.Slides dan cara melaporkan masalah secara efektif. Artikel ini menjelaskan saluran dukungan utama, memberikan rekomendasi untuk mengirimkan masalah, dan mengarahkan ke sumber daya teknis yang berguna seperti halaman produk, blog, unduhan, forum dukungan, dokumentasi, dan Referensi API. Artikel ini juga menjawab pertanyaan umum tentang dukungan berbayar, eskalasi masalah, dan dukungan untuk versi perpustakaan yang lebih lama.

## **Dukungan Teknis**

{{% alert color="info" %}} 
Aspose menyediakan dukungan teknis gratis tak terbatas untuk semua produknya. Dukungan tersedia untuk semua pengguna (termasuk pengguna dengan paket evaluasi).
{{% /alert %}} 

Ketika Anda membutuhkan bantuan dengan Aspose.Slides untuk Android via Java, pertimbangkan hal berikut:

- Jalur utama untuk dukungan adalah Aspose.Forums. Kirim pertanyaan Anda di forum Aspose.Slides—dan pertanyaan Anda akan dijawab dalam beberapa jam. Tim dukungan Aspose.Slides secara langsung menjawab pertanyaan yang diposting di forum.
- Harap dicatat bahwa Aspose tidak menyediakan dukungan teknis melalui telepon. Dukungan telepon hanya tersedia untuk pertanyaan penjualan dan pembelian.
- Saat mengharapkan balasan di forum, harap bersabar dan pertimbangkan perbedaan zona waktu.

Ketika Anda mengalami masalah dengan Aspose.Slides untuk Android via Java, ikuti pedoman ini untuk menyelesaikannya dengan cara paling efisien:

- Periksa dan pastikan bahwa Anda menggunakan versi terbaru Aspose.Slides untuk Android via Java sebelum melaporkan masalah. Mungkin masalah yang Anda alami sudah teratasi dalam pembaruan. 

  Lihat unduhan Aspose.Slides untuk mendapatkan informasi tentang versi terbaru.

- Sebelum melaporkan masalah, Anda mungkin ingin menelusuri forum kami, dokumentasi ini, dan Referensi API. Mungkin jawaban atas pertanyaan Anda sudah tersedia. 

- Saat melaporkan masalah, sertakan dokumen asli dan (jika memungkinkan) potongan kode yang terkait dengan masalah tersebut. Jika Anda perlu melampirkan beberapa file, letakkan dalam paket ZIP. 

  Anda dapat dengan aman melampirkan dokumen Anda di Aspose.Forums karena hanya Anda dan pengembang Aspose yang memiliki akses ke file yang dilampirkan.

- Buat dan gunakan satu thread untuk masalah tertentu. Jika Anda mengalami masalah lain, Anda harus membuat thread lain untuk melaporkannya. 

## **FAQ**

### Tier dukungan berbayar apa yang tersedia dan bagaimana perbedaannya?

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). Mereka berbeda berdasarkan jumlah insiden yang termasuk, prioritas respons, dan saluran komunikasi yang tersedia.

### Apakah saya dapat mengeskalasi bug langsung ke tim teknik?

Ya. [Dukungan berbayar](https://helpdesk.aspose.com/) memungkinkan eskalasi ke pengembang ketika sebuah masalah memerlukan penyelidikan lebih dalam.

### Apakah versi perpustakaan yang lebih lama didukung, dan apakah Anda merilis perbaikan untuknya?

Anda dapat menggunakan versi lama, tetapi perbaikan hanya disediakan untuk rilis saat ini; patch untuk versi legacy tidak diterbitkan.
