{{% alert color="info" %}} 

Aspose.Slides for Java 14.4.0 menyediakan keputusan baru untuk pemrosesan dokumen PowerPoint. Ada beberapa pembatasan dan masalah yang diketahui, yang akan dihapus pada rilis mendatang:

- Beberapa bentuk memiliki geometri yang salah dalam dokumen PPT yang diserialkan (busur, panah melingkar, balon penjelasan).
- Tidak semua fitur pemformatan teks PPTX didukung dalam penyerialan PPT (pembatasan pada tabulasi, indentasi, dan pemformatan paragraf).
- Informasi tentang bahasa teks dan pengaturan ejaan tidak ada dalam dokumen PPT yang diserialkan.
- Tidak semua fitur tema PPTX didukung dalam penyerialan PPT (hanya penyerialan format isi, format garis, dan font).
- Terdapat masalah yang diketahui dalam penyerialan OLE/ActiveX PPT ke PPT.
- Penyerialan dan rendering WordArt tidak didukung.

{{% /alert %}}
