## **Ikhtisar**

Bagian ini tidak berisi daftar masalah terbuka di versi saat ini. Ini berisi tiga halaman:

- [Placeholder Pratinjau Objek Saat Menambahkan OleObjectFrame](/slides/id/java/object-preview-issue-when-adding-oleobjectframe/) menjelaskan mengapa objek OLE yang ditambahkan dengan Aspose.Slides menampilkan gambar "EMBEDDED OLE OBJECT" hingga pratinjau‑nya diperbarui, dan cara mengatur gambar pratinjau Anda sendiri. Ini merupakan perilaku yang dirancang pada versi saat ini.
- [Masalah Dikenal di Aspose.Slides untuk Java 14.3.0 (Historis)](/slides/id/java/known-issues-in-aspose-slides-for-java-14-3-0/) dan [Masalah Dikenal di Aspose.Slides untuk Java 14.4.0 (Historis)](/slides/id/java/known-issues-in-aspose-slides-for-java-14-4-0/) adalah daftar yang dipublikasikan bersama versi tersebut, disimpan untuk referensi.

Untuk perubahan dan perbaikan di setiap versi, lihat [catatan rilis](https://releases.aspose.com/slides/id/java/release-notes/). Kolom metadata yang ditulis oleh Aspose.Slides dengan nilai tetap dijelaskan dalam [Batasan Metadata Output](/slides/id/java/api-limitations/). Untuk memeriksa apakah sebuah masalah sudah diketahui, atau untuk melaporkannya, gunakan [forum dukungan](https://forum.aspose.com/c/slides/id/11).
