{{% alert color="info" %}}
Aspose.Slides for Java adalah perpustakaan kelas yang memungkinkan aplikasi Java untuk membaca dan menulis dokumen presentasi tanpa menggunakan Microsoft PowerPoint® atau lainnya. Aspose.Slides for Java memungkinkan mengelola teks, bentuk, tabel & animasi, menambahkan audio dan video ke slide, menampilkan pratinjau slide, mengekspor slide ke format SVG, PDF, dan lainnya.

Referensi API terbaru dapat ditemukan di [Aspose.Slides for Java API Reference](https://reference.aspose.com/slides/id/java).
{{% /alert %}}
