## **Evaluasi Aspose.Slides**

Anda dapat mengunduh Aspose.Slides untuk evaluasi. Unduhan evaluasi sama dengan unduhan yang dibeli; ia menjadi berlisensi setelah Anda menambahkan beberapa baris kode untuk menerapkan lisensi.

Tanpa lisensi, Aspose.Slides memberikan fungsionalitas lengkapnya dalam mode evaluasi, dengan dua batasan: ia menambahkan kotak teks watermark evaluasi ke setiap slide dari setiap presentasi yang disimpan, dan teks yang dibaca kode Anda melalui API, termasuk teks yang baru saja diatur, dipotong menjadi beberapa karakter pertama, diikuti dengan pemberitahuan tentang batasan evaluasi. Teks yang ditulis kode Anda disimpan secara lengkap. Metode [getPresentationText](https://reference.aspose.com/slides/id/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) yang mengekstrak teks tanpa memuat seluruh presentasi, hanya mengembalikan pemberitahuan evaluasi dan tidak ada teks slide.

## **FAQ**

### Dapatkah saya menguji beberapa presentasi secara paralel di thread yang berbeda dalam mode evaluasi?

Ya. Anda dapat memproses dokumen yang berbeda secara paralel; Anda tidak boleh berbagi objek presentasi yang sama [across threads](/slides/id/java/multithreading/). Mode evaluasi tidak memengaruhi hal ini.

### Apakah saya perlu menginstal Microsoft PowerPoint untuk mengevaluasi perpustakaan ini di server atau dalam CI?

Tidak. Aspose.Slides adalah mesin mandiri dan tidak memerlukan PowerPoint terinstal, baik untuk evaluasi maupun produksi.

### Dapatkah saya menguji sepenuhnya konversi PPT/PPTX ke PDF dan gambar dalam mode evaluasi?

Ya. [Converters](/slides/id/java/convert-presentation/) berfungsi; output akan menyertakan watermark.

### Dapatkah saya menggunakan lisensi sementara untuk pengujian beban tanpa watermark?

Ya. Lisensi sementara selama 30 hari menghapus batasan mode evaluasi dan memungkinkan pengujian tanpa watermark.
