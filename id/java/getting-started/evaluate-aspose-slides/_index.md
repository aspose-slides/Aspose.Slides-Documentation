## **Evaluasi Aspose.Slides**

Anda dapat mengunduh Aspose.Slides untuk evaluasi. Unduhan evaluasi sama dengan unduhan yang dibeli; menjadi berlisensi setelah Anda menambahkan beberapa baris kode untuk menerapkan lisensi.

Tanpa lisensi, Aspose.Slides menyediakan semua fungsinya dalam mode evaluasi, dengan dua keterbatasan: ia menambahkan kotak teks watermark evaluasi ke setiap slide pada setiap presentasi yang disimpan, dan teks yang dibaca kode Anda melalui API, termasuk teks yang baru saja diatur, dipotong menjadi beberapa karakter pertama, diikuti dengan pemberitahuan tentang keterbatasan evaluasi. Teks yang ditulis kode Anda disimpan secara lengkap. Metode [getPresentationText](https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) yang mengekstrak teks tanpa memuat seluruh presentasi, hanya mengembalikan pemberitahuan evaluasi dan tidak ada teks slide.

## **FAQ**

### Apakah saya dapat menguji beberapa presentasi secara paralel di berbagai thread dalam mode evaluasi?

Ya. Anda dapat memproses dokumen yang berbeda secara paralel; Anda tidak boleh berbagi objek presentasi yang sama [di seluruh thread](/slides/id/java/multithreading/). Mode evaluasi tidak memengaruhi hal ini.

### Apakah saya perlu menginstal Microsoft PowerPoint untuk mengevaluasi pustaka ini di server atau dalam CI?

Tidak. Aspose.Slides adalah mesin mandiri dan tidak memerlukan PowerPoint terinstal baik untuk evaluasi maupun produksi.

### Apakah saya dapat sepenuhnya menguji konversi PPT/PPTX ke PDF dan gambar dalam mode evaluasi?

Ya. [Konverter](/slides/id/java/convert-presentation/) berfungsi; output akan menyertakan watermark.

### Apakah saya dapat menggunakan lisensi sementara untuk pengujian beban tanpa watermark?

Ya. Lisensi sementara selama 30 hari menghilangkan batasan mode evaluasi dan memungkinkan pengujian tanpa watermark.
