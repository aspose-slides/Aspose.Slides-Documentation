Ini adalah halaman historis. Halaman ini menjelaskan bug pada Aspose.Slides for Java versi 23.2 hingga 23.7, yang dirilis pada tahun 2023, serta versi yang memperbaikinya. Halaman ini tidak menjelaskan versi saat ini. Untuk lisensi pada versi saat ini, lihat [Licensing](/slides/id/java/licensing/).

{{% /alert %}}

## **Gambaran Umum**

Artikel ini menjelaskan bug lisensi yang terjadi pada Aspose.Slides for Java versi 23.2, 23.3, 23.4, 23.5, 23.6, dan 23.7. Bug ini menyebabkan lisensi perpetual menjadi tidak dapat digunakan sementara setelah langganan mereka berakhir.

## **Gejala**

Setelah langganan lisensi perpetual Anda berakhir, Aspose.Slides for Java versi 23.2 - 23.7 dapat melaporkan lisensi sebagai kedaluwarsa, mengubah semua fungsi menjadi mode evaluasi. Perilaku ini tidak tepat dan tidak memengaruhi versi sebelum 23.2 maupun setelah 23.7.

## **Solusi**

Aspose.Slides for Java menangani masalah ini dan merilis versi yang diperbarui (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) dengan perbaikan.

Jika Anda menggunakan salah satu versi yang terpengaruh dari Aspose.Slides for Java dalam proyek Anda, silakan beralih ke versi yang telah diperbaiki.

Harap dicatat bahwa bug ini hanya memengaruhi Aspose.Slides for Java versi 23.2 hingga 23.7. **Produk Aspose lainnya dan versi lain dari Aspose.Slides tidak terpengaruh**.
