## **Fitur yang Didukung dalam Konversi**
Aspose.Slides untuk Java menyediakan dukungan parsial untuk mengonversi format file PPT ke PPTX. Dukungan konversi baru saja diperkenalkan ke Aspose.Slides untuk Java, sehingga memiliki beberapa keterbatasan dan paling cocok untuk presentasi sederhana. Keuntungan utama yang diberikan Aspose.Slides untuk Java saat mengonversi PPT ke PPTX adalah betapa mudahnya API yang digunakan. Untuk melihat contoh kode, lihat [Convert PPT to PPTX](/slides/id/java/convert-ppt-to-pptx/). Daftar di bawah menunjukkan fitur apa saja yang didukung untuk konversi PPT ke PPTX.

## **Fitur yang Didukung**
Fitur berikut didukung untuk konversi:

- Mengonversi struktur master, layout, dan slide.
- Mengonversi diagram.
- Bentuk grup.
- Mengonversi autoshape termasuk persegi panjang dan elips.
- Bentuk dengan geometri kustom.
- Tekstur dan gaya isian gambar untuk autoshape.
- Mengonversi placeholder.
- Mengonversi garis dan polyline.
- Format garis dan isian.
- Gaya isian gradien.
- Frame OLE, tabel, frame video dan audio, dll.
- Properti animasi dan slideshow.
- Mengonversi teks dalam bingkai teks dan penampung teks.
