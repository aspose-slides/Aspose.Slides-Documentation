{{% alert color="info" %}} 

Spesifikasi [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) adalah bahasa deskripsi halaman dan format dokumen tetap yang awalnya dikembangkan oleh Microsoft. Seperti PDF, XPS dirancang untuk mempertahankan kesetiaan dokumen dan menyediakan tampilan dokumen yang independen terhadap perangkat. 

{{% /alert %}} 

## **XPS dalam Aspose.Slides for Java**
Setiap dokumen presentasi yang dapat dimuat oleh Aspose.Slides for Java dapat dikonversi ke format XPS. Aspose.Slides for Java menggunakan tata letak halaman dan mesin rendering berkualitas tinggi untuk menghasilkan output dalam format dokumen XPS dengan tata letak tetap.
Anda dapat mempelajari tentang mengekspor dokumen presentasi ke dokumen XPS melalui Aspose.Slides for Java di [Mengonversi ke XPS](https://docs.aspose.com/slides/id/java/convert-powerpoint-to-xps/).
