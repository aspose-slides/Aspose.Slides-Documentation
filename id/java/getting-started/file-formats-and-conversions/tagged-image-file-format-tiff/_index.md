## **Tentang TIFF**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) yang dikenal karena dapat menyimpan beberapa gambar dalam satu dokumen awalnya dibuat oleh Aldus. Format ini secara luas didukung oleh pemindai, faks, dan aplikasi manipulasi gambar lainnya.

## **TIFF di Aspose.Slides for Java**

Setiap dokumen yang dapat dimuat di Aspose.Slides for Java juga dapat dikonversi langsung menjadi dokumen TIFF oleh Aspose.Slides for Java tanpa memerlukan komponen pihak ketiga. Selain itu, Anda dapat secara opsional menentukan ukuran gambar dalam dokumen TIFF yang dihasilkan. Anda dapat menemukan informasi tentang mengekspor dokumen presentasi ke dokumen TIFF melalui Aspose.Slides for Java di [Konversi Presentasi PowerPoint ke TIFF](/slides/id/java/convert-powerpoint-to-tiff/).
