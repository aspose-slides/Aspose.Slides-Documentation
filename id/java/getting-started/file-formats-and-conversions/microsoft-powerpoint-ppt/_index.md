{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) adalah format file dokumen presentasi yang dapat dibuat, dibaca, dimanipulasi, dan ditulis oleh berbagai versi Microsoft PowerPoint. Ini adalah format biner untuk dokumen presentasi yang dikembangkan oleh Microsoft.

{{% /alert %}} 

## **PPT di Aspose.Slides untuk Java**
Aspose.Slides untuk Java dapat membaca file PPT yang dibuat oleh perangkat lunak yang tercantum di bawah ini.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Demikian pula, file PPT yang dibuat oleh Aspose.Slides untuk Java dapat dibaca oleh kumpulan perangkat lunak di atas.

## **Dukungan Komprehensif untuk PPT**
Aspose.Slides untuk Java menyediakan dukungan untuk hampir semua fitur yang didukung oleh format file dokumen PPT. Ini tidak hanya mencakup fitur dasar dan lanjutan yang disediakan oleh berbagai versi Microsoft PowerPoint untuk manipulasi dokumen PPT, tetapi juga fitur yang bahkan tidak didukung oleh Microsoft PowerPoint. Keuntungan utama menggunakan perpustakaan API Aspose.Slides untuk Java adalah kemudahan penggunaan untuk menangani fitur‑fitur tersebut.

Selain tugas dasar terkait pembuatan, pembacaan, dan penulisan file dokumen PPT, ada beberapa fitur yang disediakan oleh Aspose.Slides untuk Java:

- Ekspor slide dalam dokumen PPT ke format SVG.
- Render slide ke format gambar apa pun yang didukung oleh Kerangka Java.
- Atur ukuran slide dalam dokumen PPT.
- Kelola animasi pada bentuk.
- Kelola pertunjukan slide.

- Ekstrak teks dari dokumen PPT.
- [Tangani tabel pada slide]().
- Secara otomatis menyalin master menggunakan [fitur kloning]().
