## **Power BI**

Anda dapat menginstal Aspose.Slides for Reporting Services pada Power BI Report Server melalui proses instalasi yang sama:

* [Install with MSI Installer](/slides/id/reportingservices/install-with-msi-installer/). Program instalasi secara otomatis mendeteksi Power BI Report Server yang terpasang, menginstal produk, dan kemudian mengkonfigurasikannya untuk lingkungan kerja Anda.
* [Install Manually](/slides/id/reportingservices/install-manually/). Gunakan assembly dari folder *Bin\Universal* dalam paket ZIP.

Aspose.Slides for Reporting Services mengekspor laporan berhalaman (RDL) dari Power BI Report Server. Untuk persyaratan, termasuk .NET Framework 3.5 pada mesin host, lihat [System Requirements](/slides/id/reportingservices/system-requirements/).
