## **Platform yang Didukung**
Aspose.Slides for Python via Java adalah API yang independen platform. Itu dapat digunakan pada platform apa pun (Windows, Linux, MacOS, dll.) di mana Python 3.7 atau lebih tinggi telah terinstal. JDK 8 atau lebih tinggi adalah persyaratan lain.

## **Format File dan Konversi**
Aspose.Slides for Python via Java mendukung sebagian besar format dokumen PowerPoint. Ini juga memungkinkan Anda mengekspor mereka ke format file populer yang digunakan dan dibagikan organisasi. Lihat detail berikut:

|**Fitur**|**Deskripsi**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java menyediakan pemrosesan tercepat untuk format dokumen presentasi ini.|
|PPT to PPTX conversion|Aspose.Slides for Python via Java mendukung konversi PPT ke PPTX|
|Portable Document Format (PDF)|Anda dapat mengekspor semua format file yang didukung ke dokumen Adobe Portable Document Format (PDF) dengan satu metode.|
|XML Parser Specification (XPS)|Anda dapat mengekspor semua format file yang didukung ke dokumen XML Parser Specification (XPS) dengan satu metode.|
|Tagged Image File Format (TIFF)|Anda dapat mengekspor semua format file presentasi yang didukung ke Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java mendukung konversi PresentationEx ke format HTML.|

## **Rendering Presentasi**
Aspose.Slides for Python via Java mendukung rendering slide presentasi dengan fidelitas tinggi ke berbagai format grafik. Lihat detail berikut:

|**Fitur**|**Deskripsi**|
| :- | :- |
|Java Supported Image Formats|Dengan menggunakan Aspose.Slides for Python via Java, Anda dapat merender slide presentasi dan gambar pada slide ke semua format grafik yang didukung Java seperti TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Python via Java juga menyediakan metode bawaan yang memungkinkan Anda mengekspor slide presentasi ke format Scalable Vector Graphics (SVG).|

Aspose.Slides for Python via Java memungkinkan Anda mengakses, memodifikasi, atau membuat hampir semua item atau konten dokumen presentasi. Lihat detail berikut:

|**Fitur**|**Deskripsi**|
| :- | :- |

Anda juga dapat menggunakan slide yang disalin dan dikloning dari satu presentasi ke yang lain. Karena slide mewarisi tata letaknya dari master slide, metode kloning bawaan secara otomatis menyalin master saat mengkloning.|
|Managing Slides sections|Metode untuk mengatur slide dalam berbagai seksi di dalam sebuah presentasi|
|Place Holders and Text Holders|Anda dapat mengakses placeholder dan text holder dalam sebuah slide. Selain itu, Anda dapat membuat slide dengan text holder dari awal menggunakan metode yang sesuai|
|Header and Footers|Aspose.Slides for Python via Java memudahkan penanganan header/footer pada slide|
|Notes in Slides|Dengan Aspose.Slides for Python via Java, Anda dapat mengakses dan memodifikasi catatan yang terkait dengan sebuah slide serta menambahkan catatan baru|
|Finding a Shape|Anda juga dapat menemukan bentuk tertentu dari slide menggunakan teks alternatif yang terkait dengan bentuk tersebut|
|Backgrounds|Aspose.Slides for Python via Java memungkinkan Anda bekerja dengan latar belakang yang terkait dengan master atau slide normal dalam sebuah presentasi|
|Text Boxes|Kotak teks dapat dibuat dari awal. Anda dapat mengakses kotak teks yang ada. Anda juga dapat memodifikasi teksnya tanpa kehilangan format teks asli|
|Rectangle Shapes|Anda dapat membuat atau memodifikasi bentuk persegi panjang dengan Aspose.Slides for Python via Java|
|Poly Line Shapes|Anda dapat membuat atau memodifikasi bentuk poly line dengan Aspose.Slides for Python via Java|
|Ellipse Shapes|Anda dapat membuat atau memodifikasi bentuk Ellipse dengan Aspose.Slides for Python via Java|
|Group Shapes|Aspose.Slides for Python via Java mendukung grup shape|
|Auto Shapes|Aspose.Slides for Python via Java mendukung auto shape|
|SmartArt|Aspose.Slides for Python via Java menyediakan dukungan untuk shape SmartArt di MS PowerPoint|
|Charts|Aspose.Slides for Python via Java menyediakan dukungan untuk Chart MSO di PowerPoint|
|Shapes Serialization|Aspose.Slides for Python via Java mendukung sejumlah besar shape. Dengan cara ini, Anda dapat menggunakan shape tersebut lebih lanjut sesuai kebutuhan Anda.|
|Picture Frames|Anda dapat mengelola gambar dalam picture frame dengan Aspose.Slides for Python via Java|
|Audio Frames|Anda dapat menautkan atau menyematkan file audio dalam audio frame pada slide dengan Aspose.Slides for Python via Java|
|Video Frames|Anda dapat menangani file video dalam video frame. Aspose.Slides for Python via Java juga menyediakan dukungan untuk video yang ditautkan dan disematkan|
|OLE Frame|Anda dapat mengelola OLE Object dalam OLE frame dengan Aspose.Slides for Python via Java|
|Tables|Aspose.Slides for Python via Java mendukung tabel dalam slide|
|ActiveX Controls|Dukungan untuk kontrol ActiveX|
|VBA Macros|Dukungan untuk mengelola makro VBA di dalam presentasi.|
|Text Frame|Anda dapat mengakses teks pada bentuk apa pun melalui text frame yang terkait dengan bentuk tersebut|
|Text Scanning|Anda dapat memindai teks dalam sebuah presentasi pada tingkat presentasi atau slide melalui metode pemindaian bawaan.|
|Animations|Anda dapat menerapkan animasi pada shape|
|Slide Shows|Aspose.Slides for Python via Java mendukung slide show dan transisi slide|

## **Fitur Pemformatan**
Dengan Aspose.Slides for Python via Java, Anda dapat memformat teks dan shape pada slide dalam presentasi. Lihat detail berikut:

|**Fitur**|**Deskripsi**|
| :- | :- |
|Text Formatting|<p>Di Aspose.Slides for Python via Java, Anda dapat mengelola teks melalui text frame yang terkait dengan shape. Oleh karena itu, Anda dapat memformat teks menggunakan paragraf dan bagian yang terkait dengan text frame. Elemen teks ini dapat diformat melalui Aspose.Slides for Python via Java.</p><p>- Jenis Font</p><p>- Ukuran Font</p><p>- Warna Font</p><p>- Nuansa Font</p><p>- Perataan Paragraf</p><p>- Penomoran Paragraf</p><p>- Orientasi Paragraf</p>|
|Shape Formatting|<p>Di Aspose.Slides for Python via Java, elemen dasar sebuah slide adalah shape. Anda dapat memformat elemen shape ini dengan Aspose.Slides for Python via Java:</p><p>- Posisi</p><p>- Ukuran</p><p>- Garis</p><p>- Isi (termasuk Pola, Gradasi, Solid)</p><p>- Teks</p><p>- Gambar</p>|
