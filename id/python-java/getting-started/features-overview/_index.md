Artikel ini menjelaskan kemampuan pemrosesan presentasi dari Aspose.Slides for Python via Java. Untuk sistem operasi dan dependensi yang didukung, lihat [Persyaratan Sistem](/slides/id/python-java/system-requirements/).

## **Format File dan Konversi**

Aspose.Slides for Python via Java memungkinkan Anda mengonversi antara format presentasi dan mengekspor presentasi ke format dokumen dan web. Lihat [Format File yang Didukung](/slides/id/python-java/supported-file-formats/) untuk tabel format lengkap serta perbedaan antara memuat presentasi, mengimpor konten, dan mengekspor output.

## **Rendering Presentasi**

Aspose.Slides for Python via Java menyediakan rendering slide dengan fidelitas tinggi sebagai gambar raster atau vektor untuk pratinjau dan output visual lainnya. Ini juga memungkinkan Anda merender gambar pada slide. Untuk format gambar yang tersedia dan catatan ekspor, lihat [Format File yang Didukung](/slides/id/python-java/supported-file-formats/#supported-file-formats).

## **Fitur Konten**

Aspose.Slides for Python via Java memungkinkan Anda mengakses, memodifikasi, dan membuat hampir semua jenis konten presentasi, seperti yang dijelaskan di bawah ini:

|**Fitur**|**Deskripsi**|
| :- | :- |
|Presentasi|Anda dapat membuat presentasi dari awal atau membuka file yang sudah ada.|
|Properti Dokumen|Anda dapat membaca dan mengubah properti dokumen.|
|Perlindungan Presentasi|Anda dapat menerapkan perlindungan password dan mengelola pengaturan perlindungan presentasi.|
|Slide Master|Slide master mendefinisikan tata letak slide normal. Aspose.Slides for Python via Java memungkinkan Anda mengakses dan mengubah slide master dalam presentasi.|
|Slide Normal|Anda dapat menambah, mengakses, mengedit, mengatur urutan, dan menghapus slide dalam presentasi.|
|Layout Slide|Anda dapat bekerja dengan layout slide.|
|Penggandaan dan Penyalinan Slide|Metode bawaan memungkinkan Anda menggandakan atau menyalin slide dalam satu presentasi atau antar presentasi. Metode ini secara otomatis menyalin slide master yang terkait saat menggandakan slide.|
|Bagian Slide|Anda dapat mengorganisir slide menjadi bagian dalam sebuah presentasi.|
|Placeholder dan Text Holder|Anda dapat mengakses placeholder dan text holder pada slide, serta membuat slide dengan text holder dari awal.|
|Header dan Footer|Aspose.Slides for Python via Java memungkinkan Anda mengelola header dan footer.|
|Catatan Slide|Anda dapat mengakses, menambah, dan mengubah catatan slide, serta menyertakannya saat mengekspor ke PDF atau TIFF.|
|Mencari Bentuk|Anda dapat menemukan bentuk tertentu pada slide menggunakan teks alternatifnya.|
|Teks Alternatif|Anda dapat membaca dan memperbarui teks alternatif untuk bentuk.|
|Hyperlink|Anda dapat membaca dan memperbarui hyperlink pada bentuk dan menambahkan hyperlink ke teks.|
|Latar Belakang|Anda dapat bekerja dengan latar belakang slide master dan slide normal dalam sebuah presentasi.|
|Kotak Teks|Anda dapat membuat kotak teks dari awal, mengakses kotak teks yang ada, dan mengubah teksnya sambil mempertahankan format asli.|
|Bentuk Persegi Panjang|Anda dapat membuat dan mengubah bentuk persegi panjang.|
|Bentuk Garis|Anda dapat membuat dan mengubah bentuk garis.|
|Bentuk Polyline|Anda dapat membuat dan mengubah bentuk polyline.|
|Bentuk Elips|Anda dapat membuat dan mengubah bentuk elips.|
|Bentuk Kelompok|Aspose.Slides for Python via Java mendukung bentuk kelompok.|
|AutoShapes|Aspose.Slides for Python via Java mendukung AutoShapes.|
|SmartArt|Anda dapat membuat dan mengedit bentuk SmartArt dalam presentasi.|
|Diagram|Anda dapat membuat dan mengedit diagram Microsoft Office dalam presentasi PowerPoint.|
|Serialisasi Bentuk|Aspose.Slides for Python via Java mendukung banyak jenis bentuk. Untuk bentuk yang tidak didukung, Anda dapat menggunakan serialisasi untuk mempertahankan bentuk dari slide yang ada untuk penggunaan kembali.|
|Kunci Bentuk|Anda dapat menerapkan kunci bentuk untuk membatasi tindakan pengeditan.|
|Bingkai Gambar|Anda dapat mengelola gambar dalam bingkai gambar.|
|Bingkai Audio|Anda dapat menautkan atau menyematkan file audio dalam bingkai audio pada slide.|
|Bingkai Video|Anda dapat mengelola video yang ditautkan dan disematkan dalam bingkai video.|
|Bingkai OLE|Anda dapat mengelola objek OLE dalam bingkai OLE.|
|Tabel|Anda dapat membuat, memindahkan, dan mengubah ukuran tabel; menambah, menghapus, dan mengubah ukuran baris dan kolom; serta membaca dan mengubah konten sel, batas, isian, dan format teks.|
|Kontrol ActiveX|Aspose.Slides for Python via Java mendukung kontrol ActiveX.|
|Makro VBA|Anda dapat mengelola makro VBA dalam presentasi.|
|Bingkai Teks|Anda dapat mengakses teks bentuk melalui bingkai teks yang terkait dan menyesuaikan margin bingkai teks serta pembungkus teks.|
|Font|Anda dapat mengelola font yang digunakan dalam presentasi.|
|Pemindaian Teks|Metode bawaan memungkinkan Anda memindai teks di seluruh presentasi atau pada slide individual.|
|Animasi|Anda dapat menambah dan mengubah efek animasi pada bentuk.|
|Slide Show|Aspose.Slides for Python via Java mendukung slide show dan transisi slide, termasuk transisi Morph.|

## **Fitur Pemformatan**

Aspose.Slides for Python via Java memungkinkan Anda memformat teks dan bentuk pada slide presentasi, seperti yang dijelaskan di bawah ini:

|**Fitur**|**Deskripsi**|
| :- | :- |
|Pemformatan Teks|<p>Anda dapat mengelola teks melalui bingkai teks yang terkait dengan bentuk dan memformat paragraf serta bagian teks secara individual. Opsi pemformatan berikut tersedia:</p><p>- Jenis huruf</p><p>- Ukuran huruf</p><p>- Warna huruf</p><p>- Bayangan huruf</p><p>- Penjajaran paragraf</p><p>- Indentasi dan tabulasi paragraf</p><p>- Bullet paragraf</p><p>- Orientasi paragraf</p>|
|Pemformatan Bentuk|<p>Bentuk adalah elemen dasar sebuah slide. Anda dapat menyesuaikan properti bentuk berikut:</p><p>- Posisi</p><p>- Ukuran</p><p>- Rotasi</p><p>- Gaya garis</p><p>- Isian (termasuk isian solid, gradien, pola, tekstur, dan gambar)</p><p>- Teks</p><p>- Gambar</p>|
