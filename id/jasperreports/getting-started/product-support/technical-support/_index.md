{{% alert color="info" %}}

Aspose menyediakan dukungan teknis gratis tak terbatas untuk semua produknya. Dukungan tersedia untuk semua pengguna, termasuk evaluasi.

{{% /alert %}}

Jika Anda memerlukan bantuan dengan Aspose.Slides for JasperReports, pertimbangkan hal berikut:

- Jalur utama untuk dukungan adalah [**Aspose.Forum**](https://forum.aspose.com/c/slides/id/11). Posting pertanyaan Anda di forum Aspose.Slides dan akan dijawab dalam beberapa jam. Pertanyaan dijawab langsung oleh tim dukungan Aspose.Slides.
- Harap dicatat, Aspose tidak menyediakan dukungan teknis melalui telepon. Dukungan telepon hanya tersedia untuk pertanyaan penjualan dan pembelian.
- Saat mengharapkan balasan di forum, harap perhitungkan perbedaan zona waktu.

Jika Anda mengalami masalah dengan Aspose.Slides for JasperReports, ikuti langkah‑langkah sederhana ini untuk memastikan masalah diselesaikan dengan cara paling efisien:

- Pastikan Anda menggunakan versi terbaru Aspose.Slides for JasperReports sebelum melaporkan masalah, lihat unduhan Aspose.Slides untuk mengetahui versi terbaru.
- Lihatlah forum, dokumentasi ini, dan Referensi API sebelum melaporkan masalah; mungkin pertanyaan Anda sudah dijawab.
- Saat melaporkan masalah, sertakan dokumen asli dan mungkin cuplikan kode Anda yang menyebabkan masalah. Jika Anda perlu melampirkan beberapa file, zip menjadi satu. Aman untuk melampirkan dokumen Anda di Aspose.Forums karena hanya Anda dan pengembang Aspose yang dapat mengakses file yang dilampirkan.
- Coba laporkan satu masalah per thread. Jika Anda memiliki masalah lain, laporkan di thread terpisah.
