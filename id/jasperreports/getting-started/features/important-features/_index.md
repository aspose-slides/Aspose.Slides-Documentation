| :- | :- |
|[Ekspor PPT, PPTX, PDF, dan HTML](/slides/id/jasperreports/ppt-pptx-pdf-and-html-export/)|Ekspor laporan sebagai presentasi PPT dan PPTX, dokumen PDF, serta file HTML dari aplikasi Anda tanpa menggunakan Microsoft PowerPoint. |

|Penempatan Mudah dan Ringan|Aspose.Slides for JasperReports adalah pengekspor JasperReports dan JasperServer ke format Microsoft PowerPoint. |
|[Lisensi Sederhana dan Terjangkau](/slides/id/jasperreports/licensing/)|Satu lisensi per server atau satu lisensi untuk semua server Anda. |
