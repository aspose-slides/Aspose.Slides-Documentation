**Selamat datang di Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports adalah perpustakaan yang dirancang khusus dan dikembangkan untuk pengembang yang perlu mengekspor laporan dari JasperReports ke format Microsoft PowerPoint Presentation (PPT) dan Microsoft PowerPoint Show (PPS) dengan mudah dalam aplikasi Java mereka. Semua fitur laporan dikonversi dengan tingkat presisi tertinggi ke presentasi Microsoft PowerPoint. Aspose.Slides for JasperReports menyertakan dukungan untuk JasperReports 5+.
