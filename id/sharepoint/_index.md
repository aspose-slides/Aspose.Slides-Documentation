Aspose.Slides for SharePoint adalah solusi farm untuk SharePoint 2007 hingga 2019 yang mengkonversi presentasi PowerPoint yang disimpan di pustaka dokumen di server, tanpa Microsoft PowerPoint dan tanpa menulis kode.

Ini mengkonversi file PPT dan PPTX ke PDF, TIFF, XPS, HTML, SWF, dan ODP, serta ke format PowerPoint PPS, PPSX, PPTM, PPSM, POTX, dan POTM, dan menyimpan hasilnya di pustaka dokumen.

## **Ekspor pertama Anda**

Aspose.Slides for SharePoint diinstal sekali pada farm dan kemudian digunakan dari pustaka dokumen mana pun yang telah diaktifkan:

1. Unduh arsip ZIP dari [halaman unduhan](https://releases.aspose.com/slides/sharepoint/) dan ekstrak di server dalam farm SharePoint Anda.
2. Jalankan program instalasi yang sesuai dengan versi SharePoint Anda: *Setup2007.exe*, *Setup2010.exe*, *Setup2013.exe*, *Setup2016.exe* atau *Setup2019.exe*. Gunakan akun yang dapat menginstal dan menyebarkan solusi SharePoint. Terima perjanjian lisensi, pilih koleksi situs tempat mengaktifkan fitur, dan biarkan instalasi menyebarkan solusi. Setiap layar dijelaskan dalam [Instalasi](/slides/id/sharepoint/installing-aspose-slides-for-sharepoint/).
3. Buka pustaka dokumen di salah satu koleksi situs tersebut, buka menu file PPT atau PPTX, dan pilih **Konversi via Aspose.Slides**. Pada SharePoint 2007, item menu bernama **Konversi dengan Aspose.Slides**.
4. Di bawah **Convert to**, pilih **PDF - Adobe Portable Document**. Ubah nama file tujuan dan folder jika perlu, lalu klik **Convert**.
5. Setelah konversi selesai, klik **Destination Library** untuk membuka folder yang berisi file PDF baru.

Tanpa lisensi, file yang dikonversi akan menampilkan watermark evaluasi — lihat [Lisensi](/slides/id/sharepoint/installing-aspose-slides-for-sharepoint-license/). Untuk langkah yang sama dengan tangkapan layar, lihat [Mengonversi Dokumen Microsoft PowerPoint ke Format Lain](/slides/id/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
