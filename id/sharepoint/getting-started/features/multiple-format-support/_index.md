{{% alert color="info" title="Catatan" %}}

Dengan Aspose.Slides for SharePoint, Anda dapat mengonversi presentasi PowerPoint ke banyak format dokumen populer dari dalam perpustakaan dokumen SharePoint.

{{% /alert %}}

## **Format Input yang Didukung**

Aspose.Slides for SharePoint mengonversi format input berikut:

- PPT – Microsoft PowerPoint Presentation 97 - 2003
- PPTX – Office Open XML Presentation

{{% alert color="info" title="Catatan" %}}

Untuk mengonversi dokumen, Aspose.Slides for SharePoint bergantung pada versi bawaan [Aspose.Slides for .NET](https://products.aspose.com/slides/id/net/).

{{% /alert %}}

## **Format Output yang Didukung**

Daftar **Convert to** pada halaman konversi menawarkan format output berikut, dalam urutan ini:

- PDF – Adobe Portable Document
- TIFF – Paket gambar
- XPS – XML Paper Specification
- PPS – Presentasi slide show
- PPSX – Microsoft PowerPoint Open XML Slide Show
- ODP – OpenDocument presentation
- PPTM – Microsoft PowerPoint Open XML Macro-Enabled Presentation
- PPSM – Microsoft PowerPoint Open XML Macro-Enabled Slide Show
- POTX – Microsoft PowerPoint Template
- POTM – PowerPoint Open XML Macro-Enabled Presentation Template
- PDFNotes – Tampilan catatan presentasi dalam format PDF
- HTML – Presentasi dalam format HTML
- TIFFNotes – Tampilan catatan presentasi sebagai gambar TIFF multi‑halaman
- SWF – Shockwave Flash Movie
- SWFNotes – Tampilan catatan presentasi sebagai SWF multi‑halaman

**Memilih format output pada halaman Pengaturan Konversi**

![Halaman Pengaturan Konversi dengan daftar Convert to format output](multiple-format-support_1.png)

Tangkapan layar diambil dengan versi sebelumnya, yang hanya menawarkan format PDF, TIFF, dan XPS.
