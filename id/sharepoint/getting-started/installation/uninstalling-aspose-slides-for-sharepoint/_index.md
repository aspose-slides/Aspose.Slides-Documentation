Untuk menghapus instalasi Aspose.Slides for SharePoint:

1. Jalankan program setup yang Anda gunakan untuk menginstalnya, misalnya *Setup2019.exe* pada SharePoint Server 2019.  
   Jika menemukan versi yang sama terpasang, program setup menawarkan untuk memperbaiki atau menghapusnya. Jika menemukan versi yang berbeda, program tersebut menawarkan untuk meningkatkan atau menghapusnya.
2. Pilih **Remove** dan klik **Next** untuk menghapus instalasi Aspose.Slides for SharePoint.
