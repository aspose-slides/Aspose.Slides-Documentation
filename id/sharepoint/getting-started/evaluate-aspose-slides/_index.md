{{% alert color="info" title="Note" %}}

Unduhan evaluasi Aspose.Slides untuk SharePoint sama dengan unduhan yang dibeli. Versi berlisensi akan muncul ketika Anda menginstal paket solusi lisensi pada farm; lihat [Menginstal Lisensi Aspose.Slides untuk SharePoint](/slides/id/sharepoint/installing-aspose-slides-for-sharepoint-license/). Tidak ada kode yang terlibat.

Tanpa lisensi, Aspose.Slides untuk SharePoint dapat mengonversi ke semua format yang didukung, tetapi file yang dikonversi akan menampilkan watermark evaluasi, dan halaman konversi menampilkan pemberitahuan evaluasi.
