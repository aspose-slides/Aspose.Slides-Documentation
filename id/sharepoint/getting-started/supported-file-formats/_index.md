## **Versi Microsoft PowerPoint yang Didukung**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **Format File yang Didukung**

Aspose.Slides for SharePoint mengonversi presentasi PPT dan PPTX yang disimpan di perpustakaan dokumen SharePoint. File dengan tipe lain tidak dikonversi.

|**Format**|**Deskripsi**|**Konversi dari**|**Konversi ke**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|PowerPoint presentation 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|PowerPoint presentation 2007 and later|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|Portable Document Format, with the slides or with the notes view| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|TIFF image, with the slides or with the notes view| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML Paper Specification| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|Presentation in HTML format| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Shockwave Flash movie, with the slides or with the notes view| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|OpenDocument presentation| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|PowerPoint slide show 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|PowerPoint slide show 2007 and later| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|PowerPoint macro-enabled presentation| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|PowerPoint macro-enabled slide show| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|PowerPoint template| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|PowerPoint macro-enabled template| |{{< emoticons/tick >}}|

Format output dipilih di bawah **Convert to** pada halaman konversi; lihat [Multiple Format Support](/slides/id/sharepoint/multiple-format-support/) untuk daftar lengkap opsi.
