Untuk mengonversi presentasi dalam perpustakaan dokumen:

1. Buka menu file PPT atau PPTX (Edit Control Block) dan pilih **Convert via Aspose.Slides**. Pada SharePoint 2007, item menu bernama **Convert with Aspose.Slides**.

   **Memilih Convert with Aspose.Slides di menu dokumen pada SharePoint 2007**

   ![Menu dokumen dalam perpustakaan dokumen SharePoint 2007, dengan item Convert with Aspose.Slides](convert-one-file_1.png)

2. Pada halaman konversi, pilih format output di bawah **Convert to**. Jika ingin, ubah nama file tujuan dan folder tujuan.
3. Klik **Convert**.
4. Setelah konversi selesai, klik **Source Library** atau **Destination Library** untuk kembali ke perpustakaan dokumen. File yang telah dikonversi berada di folder tujuan.

Langkah yang sama, dengan tangkapan layar setiap halaman, terdapat di [Mengonversi Dokumen Microsoft PowerPoint ke Format Lain](/slides/id/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
