Situs SharePoint dimaksudkan untuk kolaborasi, komunikasi, dan penyimpanan konten guna memenuhi kebutuhan bisnis tertentu. Mereka memungkinkan sekelompok individu mencapai tujuan bersama dengan memfasilitasi berbagi informasi dan komunikasi. Informasi biasanya tersedia sebagai situs web dan diakses melalui peramban web.

{{% /alert %}}

## **Apa itu SharePoint dan Aspose.Slides?**

Aspose.Slides for SharePoint adalah solusi untuk mengonversi presentasi Microsoft PowerPoint (PPT dan PPTX) ke format lain: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX, dan POTM. Ini memungkinkan Anda mengonversi file PowerPoint di situs SharePoint tanpa menggunakan Microsoft PowerPoint. Daftar lengkap format tersedia di [Format File yang Didukung](/slides/id/sharepoint/supported-file-formats/).
