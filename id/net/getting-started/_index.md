Kerjakan empat langkah di bawah ini secara berurutan. Setiap langkah menyebutkan apa yang harus dilakukan dan menautkan artikel dengan detailnya. Evaluasi, lisensi, dan dukungan dibahas setelah langkah‑langkah tersebut.

## **Langkah 1: Periksa Persyaratan Sistem**

[Aspose.Slides untuk .NET](https://products.aspose.com/slides/net/) berjalan di Windows, Linux, dan macOS. [Persyaratan Sistem](/slides/id/net/system-requirements/) mencantumkan sistem operasi dan versi .NET yang didukung oleh masing‑masing paket, serta pustaka tambahan yang diperlukan Linux.

## **Langkah 2: Instal Paket**

Aspose.Slides untuk .NET didistribusikan melalui NuGet sebagai dua paket yang menyediakan kelas yang sama. Tambahkan salah satu ke proyek Anda:

- Di Windows: `dotnet add package Aspose.Slides.NET`
- Di Linux dan macOS: `dotnet add package Aspose.Slides.NET6.CrossPlatform`. Di Linux, instal terlebih dahulu pustaka `fontconfig`.
- Di Alpine Linux, dan pada sistem Linux yang glibc‑nya lebih lama dari 2.23 (x64) atau 2.39 (ARM64): Aspose.Slides.NET, dengan pustaka `libgdiplus` terpasang.

[Instalasi](/slides/id/net/installation/) memberikan perintah Linux, pengaturan startup tambahan yang diperlukan Aspose.Slides.NET di Linux, serta langkah‑langkah untuk Visual Studio.

## **FAQ**

**Apakah saya perlu menginstal Microsoft PowerPoint?**

Tidak. Aspose.Slides membaca dan menulis berkas presentasi secara mandiri dan tidak menggunakan PowerPoint, sehingga dapat dijalankan di server maupun di Linux.

**Paket mana yang harus saya gunakan untuk aplikasi .NET Framework?**

Aspose.Slides.NET. Paket ini mencakup build untuk .NET Framework 4.6.2 ke atas, .NET 6 ke atas, dan .NET Standard 2.0. Aspose.Slides.NET6.CrossPlatform memerlukan .NET 6 atau yang lebih baru.
