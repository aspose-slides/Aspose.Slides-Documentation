## **Langkah 1: Periksa Persyaratan Sistem**

Aspose.Slides for .NET berjalan di Windows, Linux, dan macOS. [Persyaratan Sistem](/slides/id/net/system-requirements/) mencantumkan sistem operasi dan versi .NET yang didukung oleh setiap paket, serta pustaka tambahan yang diperlukan di Linux.

## **Langkah 2: Instal Paket**

Aspose.Slides for .NET didistribusikan melalui NuGet sebagai dua paket yang menyediakan kelas yang sama. Tambahkan salah satu ke proyek Anda:

- Di Windows: `dotnet add package Aspose.Slides.NET`
- Di Linux dan macOS: `dotnet add package Aspose.Slides.NET6.CrossPlatform`. Di Linux, instal pustaka `fontconfig` terlebih dahulu.
- Di Alpine Linux, dan pada sistem Linux yang glibc‑nya lebih lama dari 2.23 (x64) atau 2.39 (ARM64): Aspose.Slides.NET, dengan pustaka `libgdiplus` terinstal.

[Instalasi](/slides/id/net/installation/) memberi perintah Linux, pengaturan startup tambahan yang diperlukan Aspose.Slides.NET di Linux, dan langkah‑langkah untuk Visual Studio.

Tanpa lisensi, Aspose.Slides berjalan dalam mode evaluasi: menambahkan watermark pada setiap slide yang disimpan dan memotong teks yang dibaca dari presentasi.

## **FAQ**

**Apakah saya perlu menginstal Microsoft PowerPoint?**

Tidak. Aspose.Slides membaca dan menulis file presentasi secara mandiri dan tidak menggunakan PowerPoint, sehingga juga dapat berjalan di server dan di Linux.

**Paket mana yang harus saya gunakan untuk aplikasi .NET Framework?**

Aspose.Slides.NET. Paket ini mencakup build untuk .NET Framework 4.6.2 ke atas, .NET 6 ke atas, dan .NET Standard 2.0. Aspose.Slides.NET6.CrossPlatform memerlukan .NET 6 atau yang lebih baru.
