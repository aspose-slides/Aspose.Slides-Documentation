**Selamat datang di Aspose.Slides untuk .NET**

![Logo Produk Aspose.Slides untuk .NET](home_1.png)

Aspose.Slides untuk .NET adalah API manajemen Microsoft PowerPoint® yang memungkinkan aplikasi .NET untuk membaca dan menulis dokumen PowerPoint® tanpa menggunakan Microsoft PowerPoint®.

Aspose.Slides untuk .NET adalah komponen pertama dan satu-satunya yang menyediakan fungsionalitas yang diperlukan untuk mengelola dokumen PowerPoint®.

Aspose.Slides untuk .NET menawarkan banyak fitur utama seperti mengelola teks, bentuk, tabel & animasi, menambahkan audio dan video ke slide, menampilkan pratinjau slide, mengekspor slide ke SVG, PDF, dan berbagai format, serta banyak kemampuan lainnya.
