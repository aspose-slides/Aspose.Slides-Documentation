## **Format File dan Konversi**
Aspose.Slides for C++ mendukung sebagian besar format dokumen PowerPoint dan juga mengekspornya ke format populer yang banyak digunakan untuk pertukaran antar organisasi. Tabel berikut mencantumkan format-format tersebut:

|**Fitur**|**Deskripsi**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/id/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ menyediakan pemrosesan tercepat untuk format dokumen presentasi ini.|
|[Portable Document Format (PDF)](/slides/id/cpp/portable-document-format-pdf/)|Format file yang didukung dapat diekspor ke dokumen Adobe Portable Document Format (PDF) dengan satu metode.|
|[XML Parser Specification (XPS)](/slides/id/cpp/xml-parser-specification-xps/)|Semua format file yang didukung dapat diekspor ke dokumen XML Parser Specification (XPS) dengan satu metode.|
|[PresentationML (PPTX, XML)](/slides/id/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ mendukung pemrosesan format presentasi OOXML yang juga dikenal sebagai PresentationML atau PPTX.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/id/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ mendukung konversi Presentasi ke format HTML.|

## **Render Presentasi**
Aspose.Slides for C++ mendukung render dengan fidelitas tinggi dari slide dalam dokumen presentasi ke berbagai format grafis seperti yang tercantum di bawah:

|**Fitur**|**Deskripsi**|
| :- | :- |
|Format Gambar yang Didukung C++|Dengan menggunakan Aspose.Slides for C++, Anda dapat merender bukan hanya slide presentasi, tetapi juga gambar pada slide ke semua format grafis yang didukung C++ seperti PNG, BMP, dan JPEG|
|Format SVG|Aspose.Slides for C++ juga menyediakan metode bawaan untuk mengekspor slide presentasi ke format Scalable Vector Graphics (SVG).|

## **Fitur Konten**
Aspose.Slides for C++ memungkinkan Anda mengakses, memodifikasi, atau membuat hampir semua konten yang mungkin ada dalam dokumen presentasi.

|**Fitur**|**Deskripsi**|
| :- | :- |
|Master Slide|Master Slide menentukan tata letak slide normal. Aspose.Slides for C++ memungkinkan Anda mengakses dan memodifikasi Master Slide dari dokumen presentasi|
|Slide Normal|Dengan Aspose.Slides for C++, Anda tidak hanya dapat membuat slide baru dengan berbagai jenis, tetapi juga mengakses dan memodifikasi slide yang ada dalam dokumen presentasi|
|Mengkloning / Menyalin Slide|Ada metode bawaan yang disediakan oleh Aspose.Slides for C++ untuk mengkloning atau menyalin slide yang ada, tidak hanya dalam satu presentasi, tetapi juga dari satu presentasi ke presentasi lain. Karena slide mewarisi tata letaknya dari master slide, metode kloning bawaan secara otomatis menyalin master juga saat melakukan kloning|
|Placeholder dan Penampung Teks|Anda juga dapat mengakses placeholder dan penampung teks dalam sebuah slide. Selain itu, Anda dapat membuat slide dengan penampung teks dari awal menggunakan metode yang sesuai|
|Header dan Footer|Aspose.Slides for C++ juga memudahkan penanganan header/footer pada slide|
|Catatan pada Slide|Dengan Aspose.Slides for C++, Anda tidak hanya dapat mengakses dan memodifikasi catatan yang terkait dengan sebuah slide, tetapi juga menambahkan catatan|
|Menemukan Bentuk|Anda juga dapat menemukan bentuk tertentu dari sebuah slide menggunakan teks alternatif yang terkait dengan bentuk tersebut|
|Latar Belakang|Aspose.Slides for C++ memungkinkan pekerjaan dengan latar belakang yang terkait dengan master atau slide normal dari Presentasi|
|Kotak Teks|Kotak teks dapat dibuat dari awal. Kotak teks yang ada dapat diakses dan teksnya juga dapat dimodifikasi tanpa kehilangan format teks asli|
|Bentuk Persegi Panjang|Bentuk persegi panjang dapat dibuat atau dimodifikasi oleh Aspose.Slides for C++|
|Bentuk Poly Line|Bentuk poly line juga dapat dibuat atau dimodifikasi oleh Aspose.Slides for C++|
|Bentuk Elips|Bentuk elips juga dapat dibuat atau dimodifikasi oleh Aspose.Slides for C++|
|Bentuk Grup|Aspose.Slides for C++ juga mendukung bentuk grup|
|Auto Shapes|Auto shapes juga didukung oleh Aspose.Slides for C++|
|Serialisasi Bentuk|Meskipun Aspose.Slides for C++ mendukung sejumlah besar bentuk, jika sebuah bentuk tidak didukung oleh Aspose.Slides for C++, terdapat metode serialisasi yang disediakan oleh Aspose.Slides for C++ yang memungkinkan Anda menserialisasi bentuk tersebut dari slide yang ada untuk penggunaan lebih lanjut oleh Aspose.Slides for C++ sesuai kebutuhan|

## **Tanya Jawab**

### Apakah saya perlu menginstal Microsoft PowerPoint di server/PC agar pustaka dapat bekerja?
Tidak. PowerPoint tidak diperlukan; Aspose.Slides adalah mesin mandiri untuk membuat, mengedit, mengonversi, dan merender presentasi.

### Bagaimana cara kerja multithreading? Apakah pemrosesan dapat diparalelkan?
Aman untuk memproses dokumen yang berbeda dalam thread yang berbeda; objek [presentasi](https://reference.aspose.com/slides/id/cpp/aspose.slides/presentation/) yang sama tidak boleh digunakan oleh [multiple threads](/slides/id/cpp/multithreading/) secara bersamaan.

### Apakah kata sandi file dan enkripsi didukung?
Ya. [Anda dapat](/slides/id/cpp/password-protected-presentation/) membuka presentasi yang dienkripsi, mengatur atau menghapus kata sandi buka dan tulis, serta memeriksa status perlindungan.

### Apakah saya perlu memperhatikan paket font di kontainer Linux?
Ya. Disarankan untuk menginstal paket font umum dan/atau secara eksplisit [menentukan direktori font](/slides/id/cpp/custom-font/) dalam aplikasi Anda untuk menghindari substitusi yang tidak terduga.

### Apakah ada batasan dalam versi evaluasi?
Dalam [mode evaluasi](/slides/id/cpp/licensing/), watermark ditambahkan pada output dan beberapa batasan berlaku; [lisensi sementara 30 hari](https://purchase.aspose.com/temporary-license/) tersedia untuk pengujian semua fitur.

### Apakah mengimpor format eksternal ke dalam presentasi (PDF/HTML → PPTX) didukung?
Ya. Anda dapat menambahkan [halaman PDF dan konten HTML](/slides/id/cpp/import-presentation/) ke dalam sebuah presentasi, mengubahnya menjadi slide.
