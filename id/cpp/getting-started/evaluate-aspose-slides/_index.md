## **Aspose.Slides Evaluasi**

Anda dapat mengunduh Aspose.Slides untuk evaluasi. Paket evaluasi sama dengan paket yang dibeli; paket ini menjadi berlisensi setelah Anda menambahkan beberapa baris kode untuk menerapkan lisensi, seperti yang ditunjukkan di [Licensing](/slides/id/cpp/licensing/).

Tanpa lisensi, Aspose.Slides menyediakan fungsionalitas penuh dalam mode evaluasi, dengan dua batasan:

* Ia menambahkan satu kotak teks watermark evaluasi di tengah setiap slide dari setiap presentasi yang disimpannya. Membuka sebuah presentasi tidak menambahkan watermark, tetapi watermark yang disimpan sebelumnya dimuat sebagai bentuk di slide‑nya. Jadi jika Anda membuka sebuah presentasi yang disimpan dalam mode evaluasi dan menyimpannya lagi, setiap slide akan memiliki dua watermark.
* Teks yang dibaca kode Anda dari sebuah presentasi dipotong hingga beberapa karakter pertama, diikuti dengan pemberitahuan tentang batasan evaluasi. Ini berlaku untuk setiap slide, serta untuk teks yang baru saja ditetapkan oleh kode Anda. Teks yang ditulis kode Anda disimpan secara lengkap.

## **FAQ**

### Dapatkah saya menguji banyak presentasi secara paralel di berbagai thread dalam mode evaluasi?

Ya. Anda dapat memproses dokumen yang berbeda secara paralel; Anda tidak boleh berbagi objek presentasi yang sama [di seluruh thread](/slides/id/cpp/multithreading/). Mode evaluasi tidak memengaruhinya.

### Apakah saya perlu menginstal Microsoft PowerPoint untuk mengevaluasi perpustakaan ini di server atau dalam CI?

Tidak. Aspose.Slides adalah mesin mandiri dan tidak memerlukan PowerPoint terinstal baik untuk evaluasi maupun produksi.

### Dapatkah saya menguji sepenuhnya konversi PPT/PPTX ke PDF dan gambar dalam mode evaluasi?

Ya. [konverter](/slides/id/cpp/convert-presentation/) berfungsi; output akan menyertakan watermark.

### Dapatkah saya menggunakan lisensi sementara untuk pengujian beban tanpa watermark?

Ya. Lisensi sementara selama 30 hari menghapus batasan mode evaluasi dan memungkinkan pengujian tanpa watermark.
