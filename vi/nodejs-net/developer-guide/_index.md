This **Hướng dẫn cho nhà phát triển** shows how to do common presentation tasks in JavaScript with Aspose.Slides for Node.js via .NET. Every article contains runnable examples. Before you run them, set up a project as described in [Cài đặt](/slides/vi/nodejs-net/installation/).

- [**Tạo Bài Thuyết Trình**](/slides/vi/nodejs-net/create-presentation/) – tạo một bài thuyết trình, thêm một hộp văn bản và các slide, đặt kích thước slide, và lưu kết quả dưới dạng PPTX.
- [**Mở Bài Thuyết Trình**](/slides/vi/nodejs-net/open-presentation/) – mở một bài thuyết trình từ tệp hoặc bộ đệm, đọc số lượng slide, và lưu nó sang định dạng khác.
- [**PowerPoint sang PDF**](/slides/vi/nodejs-net/convert-powerpoint-to-pdf/) – chuyển đổi một bài thuyết trình sang PDF, bao gồm PDF/A cho lưu trữ.
- [**Slide sang Hình Ảnh**](/slides/vi/nodejs-net/convert-slide/) – kết xuất các slide thành hình ảnh PNG với hệ số tỷ lệ hoặc với kích thước chính xác tính bằng pixel.
- [**Quản Lý Văn Bản**](/slides/vi/nodejs-net/manage-text/) – thêm một hộp văn bản, sau đó thay đổi nội dung, kích thước phông chữ và kiểu chữ đậm.
