Để gỡ cài đặt Aspose.Slides for SharePoint:

1. Chạy chương trình cài đặt mà bạn đã dùng để cài đặt nó, ví dụ *Setup2019.exe* trên SharePoint Server 2019.
   Khi nó phát hiện phiên bản giống đã được cài đặt, chương trình cài đặt sẽ đề nghị sửa chữa hoặc gỡ bỏ. Khi nó phát hiện phiên bản khác, nó sẽ đề nghị nâng cấp hoặc gỡ bỏ.
2. Chọn **Remove** và nhấp **Next** để gỡ cài đặt Aspose.Slides for SharePoint.
