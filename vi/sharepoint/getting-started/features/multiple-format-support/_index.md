{{% alert color="info" title="Note" %}}

Với Aspose.Slides for SharePoint, bạn có thể chuyển đổi các bản trình chiếu PowerPoint sang nhiều định dạng tài liệu phổ biến ngay trong thư viện tài liệu SharePoint.

{{% /alert %}}

## **Định dạng đầu vào được hỗ trợ**

Aspose.Slides for SharePoint chuyển đổi các định dạng đầu vào sau:

- PPT – Bản trình chiếu Microsoft PowerPoint 97 - 2003
- PPTX – Bản trình chiếu Office Open XML

{{% alert color="info" title="Note" %}}

Để chuyển đổi tài liệu, Aspose.Slides for SharePoint dựa trên phiên bản tích hợp sẵn của [Aspose.Slides for .NET](https://products.aspose.com/slides/net/).

{{% /alert %}}

## **Định dạng đầu ra được hỗ trợ**

Danh sách **Convert to** trên trang chuyển đổi cung cấp các định dạng đầu ra sau, theo thứ tự này:

- PDF – Tài liệu Portable Adobe
- TIFF – Gói hình ảnh
- XPS – Định dạng XML Paper
- PPS – Bản trình chiếu dạng slide
- PPSX – Slide Show Microsoft PowerPoint Open XML
- ODP – Bản trình chiếu OpenDocument
- PPTM – Bản trình chiếu Microsoft PowerPoint Open XML có hỗ trợ macro
- PPSM – Slide Show Microsoft PowerPoint Open XML có hỗ trợ macro
- POTX – Mẫu Microsoft PowerPoint
- POTM – Mẫu bản trình chiếu PowerPoint Open XML có hỗ trợ macro
- PDFNotes – Ghi chú bản trình chiếu ở định dạng PDF
- HTML – Bản trình chiếu ở định dạng HTML
- TIFFNotes – Ghi chú bản trình chiếu dưới dạng ảnh TIFF đa trang
- SWF – Phim Shockwave Flash
- SWFNotes – Ghi chú bản trình chiếu dưới dạng SWF đa trang

**Chọn định dạng đầu ra trên trang Cài đặt Chuyển đổi**

![Trang Cài đặt Chuyển đổi với danh sách Convert to chứa các định dạng đầu ra](multiple-format-support_1.png)

Ảnh chụp màn hình được lấy bằng một phiên bản trước, chỉ cung cấp các định dạng PDF, TIFF và XPS.
