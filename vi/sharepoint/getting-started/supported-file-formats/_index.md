## **Các phiên bản Microsoft PowerPoint được hỗ trợ**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint cho Mac

## **Các định dạng tệp được hỗ trợ**

Aspose.Slides for SharePoint chuyển đổi các bản trình chiếu PPT và PPTX được lưu trong thư viện tài liệu SharePoint. Các tệp thuộc các loại khác không được chuyển đổi.

|**Định dạng**|**Mô tả**|**Chuyển đổi từ**|**Chuyển đổi sang**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|Bản trình chiếu PowerPoint 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|Bản trình chiếu PowerPoint 2007 và các phiên bản sau|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|Định dạng tài liệu di động, với các slide hoặc chế độ xem ghi chú| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|Hình ảnh TIFF, với các slide hoặc chế độ xem ghi chú| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|Đặc tả giấy XML| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|Bản trình chiếu ở định dạng HTML| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Phim Shockwave Flash, với các slide hoặc chế độ xem ghi chú| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|Bản trình chiếu OpenDocument| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|Trình chiếu PowerPoint 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|Trình chiếu PowerPoint 2007 và các phiên bản sau| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|Bản trình chiếu PowerPoint có macro| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|Trình chiếu PowerPoint có macro| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|Mẫu PowerPoint| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|Mẫu PowerPoint có macro| |{{< emoticons/tick >}}|

Định dạng đầu ra được chọn trong phần **Convert to** trên trang chuyển đổi; xem [Hỗ trợ Định dạng Nhiều](/slides/vi/sharepoint/multiple-format-support/) để biết danh sách tùy chọn chính xác.
