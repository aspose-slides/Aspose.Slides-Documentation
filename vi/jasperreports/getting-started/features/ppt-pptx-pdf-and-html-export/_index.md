{{% alert color="info" %}} 

JasperReports và JasperServer không có khả năng xuất báo cáo dưới dạng bản trình chiếu Microsoft PowerPoint mặc định, nhưng với Aspose.Slides cho JasperReports, bạn sẽ có quyền truy cập vào các định dạng xuất bổ sung:

- Bản trình chiếu Microsoft PowerPoint (PPT)
- Bản trình chiếu Microsoft PowerPoint (PPTX)
- HTML
- PDF

{{% /alert %}} 

Để tạo tài liệu ở các định dạng này, Aspose.Slides cho JasperReports dựa trên một phiên bản tích hợp sẵn của [Aspose.Slides for Java](https://products.aspose.com/slides/vi/java/), thư viện xử lý bản trình chiếu hàng đầu trên thị trường từ Aspose. Microsoft PowerPoint không được sử dụng để tạo ra các tài liệu.
