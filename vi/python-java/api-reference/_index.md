{{% alert color="info" title="Note" %}}

Aspose.Slides for Python via Java là một thư viện lớp cho phép các ứng dụng Python đọc và ghi các bản trình chiếu mà không cần Microsoft PowerPoint®. Nó cho phép bạn quản lý văn bản, hình dạng, bảng và hoạt ảnh; thêm âm thanh và video vào các slide; xem trước các slide; và xuất các slide ra định dạng SVG, PDF và các định dạng khác.

Để biết chi tiết, xem [Aspose.Slides for Python via Java API Reference](https://reference.aspose.com/slides/vi/python-java/).
