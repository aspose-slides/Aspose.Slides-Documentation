**Chào mừng tới Aspose.Slides for Python via Java**

![Aspose.Slides for Python via Java Product Logo](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java là một thư viện lớp cho phép các ứng dụng Python của bạn đọc và ghi các bản trình bày PowerPoint® mà không cần Microsoft PowerPoint®.

Các tính năng chính bao gồm quản lý văn bản, hình dạng, bảng và hoạt ảnh; thêm âm thanh và video vào slide; xem trước slide; và xuất slide sang SVG, PDF và các định dạng khác.

{{% /alert %}}
