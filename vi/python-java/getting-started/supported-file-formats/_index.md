## **Tổng quan**

Aspose.Slides for Python via Java đọc và ghi các bản trình bày PowerPoint và OpenDocument. Nó cũng nhập nội dung PDF và HTML vào các slide và xuất bản trình bày hoặc các slide riêng lẻ ra các định dạng tài liệu, web và hình ảnh.

Bảng dưới đây phân biệt việc tải bản trình bày với nhập nội dung và việc render slide. Để biết tổng quan về các khả năng chỉnh sửa và render, xem [Features Overview](/slides/vi/python-java/features-overview/).

## **Các phiên bản Microsoft PowerPoint được hỗ trợ**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint cho Mac
- PowerPoint cho Microsoft 365 (trước đây là Office 365)

## **Ghi chú nhập và xuất**

- **PDF và HTML import:** Sử dụng [SlideCollection.addFromPdf](https://reference.aspose.com/slides/vi/python-java/aspose.slides/slidecollection/#addfrompdf) hoặc [SlideCollection.addFromHtml](https://reference.aspose.com/slides/vi/python-java/aspose.slides/slidecollection/#addfromhtml) để tạo slide từ nội dung nguồn và thêm chúng vào bản trình bày.
- **Presentation output:** [SaveFormat](https://reference.aspose.com/slides/vi/python-java/aspose.slides/saveformat/) liệt kê các định dạng lưu bản trình bày khả dụng, bao gồm các tùy chọn xuất HTML và HTML5 riêng biệt.
- **Image output:** Xuất một slide ra hình ảnh tạo ra một biểu diễn hình ảnh của slide đó. Cột nhập không mô tả liệu một hình ảnh có thể được chèn vào bản trình bày hay không.

## **Câu hỏi thường gặp**

**Tôi có thể chuyển đổi một bản trình bày PPT sang PPTX hoặc ODP không?**

Có. PPT được hỗ trợ như một định dạng nhập, và cả PPTX và ODP đều được hỗ trợ như các định dạng xuất. Kết quả chuyển đổi phụ thuộc vào các tính năng có sẵn trong định dạng đích.

**Việc nhập PDF hoặc HTML có mở nguồn dưới dạng tệp PowerPoint không?**

Không. Việc nhập tạo các slide từ các trang PDF hoặc nội dung HTML. Sau đó bạn có thể lưu bản trình bày kết quả ở một định dạng bản trình bày được hỗ trợ.

**Tôi có thể tải một tệp PNG hoặc SVG đã xuất dưới dạng bản trình bày có thể chỉnh sửa không?**

Không. Các tệp xuất này chỉ thể hiện hình ảnh của slide. Hãy giữ bản trình bày gốc khi bạn cần chỉnh sửa văn bản, hình dạng, biểu đồ và các đối tượng khác sau này.
