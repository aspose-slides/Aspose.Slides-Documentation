## **Tổng quan**

Phần này giúp bạn chuẩn bị môi trường và bắt đầu sử dụng [Aspose.Slides for Python via Java](https://products.aspose.com/slides/python-java/). Thực hiện các bước thiết lập dưới đây, sau đó khám phá khả năng của thư viện và các hướng dẫn liên quan đến dự án của bạn.

1. Xem lại [Yêu cầu hệ thống](/slides/vi/python-java/system-requirements/) để kiểm tra hệ điều hành, Python, Java và các yêu cầu của JPype.  
2. Thực hiện hướng dẫn [Cài đặt](/slides/vi/python-java/installation/) để cài đặt các gói cần thiết và xác minh việc thiết lập bằng một ví dụ.  
3. Đọc [Đánh giá Aspose.Slides](/slides/vi/python-java/evaluate-aspose-slides/) để hiểu các giới hạn đánh giá và các tùy chọn giấy phép tạm thời.  
4. Thực hiện hướng dẫn [Cấp phép](/slides/vi/python-java/licensing/) để áp dụng giấy phép của bạn.

**Bạn nên bắt đầu từ đâu nếu chưa bao giờ sử dụng Aspose.Slides for Python via Java?**
