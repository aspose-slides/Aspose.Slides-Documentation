{{% alert color="info" %}}

Aspose.Slides for Android via Java là một thư viện lớp cho phép các ứng dụng Java cho Android đọc và ghi tài liệu trình chiếu mà không cần sử dụng Microsoft PowerPoint® hoặc phần mềm khác. Aspose.Slides for Android via Java cho phép bạn quản lý văn bản, hình dạng, bảng và hoạt ảnh; thêm âm thanh và video vào các slide; xem trước các slide; và xuất slide sang định dạng SVG, PDF và hơn nữa.

Tài liệu API mới nhất có thể được tìm thấy tại [Tham khảo API Aspose.Slides cho Android qua Java](https://reference.aspose.com/slides/vi/androidjava/).

{{% /alert %}}
