## **Nền tảng được hỗ trợ**
Aspose.Slides for Node.js via Java là một API độc lập với nền tảng. Nó có thể được sử dụng trên bất kỳ nền tảng nào (Windows, Linux, MacOS, v.v.) nơi Node.js 7 hoặc cao hơn đã được cài đặt. Oracle JDK 8 hoặc cao hơn là yêu cầu khác.

## **Định dạng tệp và chuyển đổi**
Aspose.Slides for Node.js via Java hỗ trợ hầu hết các định dạng tài liệu PowerPoint. Nó cũng cho phép bạn xuất chúng sang các định dạng tệp phổ biến mà các tổ chức sử dụng và chia sẻ với nhau. Xem chi tiết dưới đây:

|**Tính năng**|**Mô tả**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java cung cấp tốc độ xử lý nhanh nhất cho định dạng tài liệu trình chiếu này.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java hỗ trợ chuyển đổi PPT sang PPTX|
|Portable Document Format (PDF)|Bạn có thể xuất tất cả các định dạng tệp được hỗ trợ sang tài liệu Adobe Portable Document Format (PDF) bằng một phương thức duy nhất.|
|XML Parser Specification (XPS)|Bạn có thể xuất tất cả các định dạng tệp được hỗ trợ sang tài liệu XML Parser Specification (XPS) bằng một phương thức duy nhất.|
|Tagged Image File Format (TIFF)|Bạn có thể xuất tất cả các định dạng tệp trình chiếu được hỗ trợ sang Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java hỗ trợ chuyển đổi PresentationEx sang định dạng HTML.|

## **Kết xuất trình chiếu**
Aspose.Slides for Node.js via Java hỗ trợ kết xuất chất lượng cao các slide trong trình chiếu sang các định dạng đồ họa khác nhau. Xem chi tiết dưới đây:

|**Tính năng**|**Mô tả**|
| :- | :- |
|Java Supported Image Formats|Sử dụng Aspose.Slides for Node.js via Java, bạn có thể kết xuất các slide trình chiếu và hình ảnh trên slide sang mọi định dạng đồ họa được Java hỗ trợ như TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via Java cũng cung cấp các phương thức tích hợp cho phép bạn xuất các slide trình chiếu sang định dạng Scalable Vector Graphics (SVG).|

## **FAQ**

### Tôi có cần cài đặt Microsoft PowerPoint trên máy chủ/PC để thư viện hoạt động không?

Không. PowerPoint không bắt buộc; Aspose.Slides là một engine độc lập để tạo, chỉnh sửa, chuyển đổi và kết xuất các trình chiếu.

### Multithreading hoạt động như thế nào? Có thể xử lý song song không?

Có thể xử lý các tài liệu khác nhau trong các luồng riêng biệt một cách an toàn; cùng một đối tượng [presentation](https://reference.aspose.com/slides/vi/nodejs-java/aspose.slides/presentation/) không được [multiple threads](/slides/vi/nodejs-java/multithreading/) sử dụng đồng thời.

### Có hỗ trợ mật khẩu tệp và mã hoá không?

Có. [Bạn có thể](/slides/vi/nodejs-java/password-protected-presentation/) mở các trình chiếu được mã hoá, đặt hoặc xoá mật khẩu mở và ghi, và kiểm tra trạng thái bảo vệ.

### Tôi có cần chú ý đến các gói phông chữ trong các container Linux không?

Có. Đề nghị cài đặt các gói phông chữ phổ biến và/hoặc rõ ràng [chỉ định thư mục phông chữ](/slides/vi/nodejs-java/custom-font/) trong ứng dụng của bạn để tránh các sự thay thế không mong muốn.

### Có những hạn chế nào trong phiên bản đánh giá không?

Trong [chế độ đánh giá](/slides/vi/nodejs-java/licensing/), một watermark được thêm vào đầu ra và một số hạn chế được áp dụng; một [30-day temporary license](https://purchase.aspose.com/temporary-license/) có sẵn để thử nghiệm đầy đủ tính năng.

### Có hỗ trợ nhập các định dạng bên ngoài vào một trình chiếu (PDF/HTML → PPTX) không?

Có. Bạn có thể thêm [trang PDF và nội dung HTML](/slides/vi/nodejs-java/import-presentation/) vào một trình chiếu, chuyển chúng thành các slide.
