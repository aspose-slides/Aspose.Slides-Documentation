## **Power BI**

Bạn có thể cài đặt Aspose.Slides for Reporting Services trên Power BI Report Server bằng cùng quy trình cài đặt:

* [Cài đặt bằng Trình cài đặt MSI](/slides/vi/reportingservices/install-with-msi-installer/). Chương trình cài đặt tự động phát hiện Power BI Report Server đã được cài đặt, cài đặt sản phẩm và sau đó cấu hình cho môi trường làm việc của bạn.
* [Cài đặt thủ công](/slides/vi/reportingservices/install-manually/). Sử dụng assembly từ thư mục *Bin\Universal* của gói ZIP.

Aspose.Slides for Reporting Services xuất các báo cáo phân trang (RDL) từ Power BI Report Server. Đối với các yêu cầu, bao gồm .NET Framework 3.5 trên máy chủ, xem [Yêu cầu hệ thống](/slides/vi/reportingservices/system-requirements/).
