## **Hỗ trợ cho Mã Cũ**
Để sử dụng mã legacy được phát triển với Aspose.Slides cho Java phiên bản trước 13.x, bạn cần thực hiện một số thay đổi nhỏ trong mã của mình và mã sẽ hoạt động như trước. Tất cả các lớp từng có trong Aspose.Slides cho Java cũ dưới các không gian tên Aspose.Slide và Aspose.Slides.Pptx hiện đã được hợp nhất trong một không gian tên Aspose.Slides duy nhất. Vui lòng xem đoạn mã mẫu đơn giản sau để tạo tài liệu Trình chiếu Hello World trong API Aspose.Slides legacy và làm theo các bước mô tả cách di chuyển sang API mới đã hợp nhất.
