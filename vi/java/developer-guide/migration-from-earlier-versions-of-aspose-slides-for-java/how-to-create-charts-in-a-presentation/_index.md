## **Hỗ trợ mã Legacy**
Để sử dụng mã legacy được phát triển bằng các phiên bản Aspose.Slides for Java trước 14.x.x, bạn cần thực hiện một số thay đổi nhỏ trong mã của mình và mã sẽ hoạt động như trước. Tất cả các lớp từng có trong Aspose.Slides for Java cũ dưới các không gian tên com.aspose.slides và com.aspose.slides.pptx hiện đã được hợp nhất thành một không gian tên com.aspose.slides duy nhất. Vui lòng xem đoạn mã mẫu đơn giản dưới đây để tạo một biểu đồ bình thường từ đầu trong bản trình chiếu bằng API Aspose.Slides legacy và làm theo các bước mô tả cách di chuyển sang API mới đã hợp nhất.
