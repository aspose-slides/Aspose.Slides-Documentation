{{% alert color="info" %}} 
[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) là định dạng tệp tài liệu trình chiếu có thể được tạo, đọc, thao tác và ghi bởi các phiên bản khác nhau của Microsoft PowerPoint. Đây là định dạng nhị phân cho các tài liệu trình chiếu do Microsoft phát triển.
{{% /alert %}} 

## **PPT trong Aspose.Slides for Java**
Aspose.Slides for Java có thể đọc các tệp PPT được tạo bởi phần mềm liệt kê dưới đây.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Tương tự, các tệp PPT được tạo bởi Aspose.Slides for Java có thể được đọc bằng các phần mềm trên.

## **Hỗ trợ toàn diện cho PPT**
Aspose.Slides for Java cung cấp hỗ trợ cho hầu hết các tính năng của định dạng tệp tài liệu PPT. Nó không chỉ bao gồm các tính năng cơ bản và nâng cao do các phiên bản Microsoft PowerPoint khác nhau cung cấp cho việc thao tác tài liệu PPT, mà còn có những tính năng thậm chí Microsoft PowerPoint không hỗ trợ. Lợi thế chính của việc sử dụng thư viện API Aspose.Slides for Java là khả năng sử dụng dễ dàng để xử lý những tính năng này.

Ngoài các nhiệm vụ cơ bản liên quan đến việc tạo, đọc và ghi tệp tài liệu PPT, Aspose.Slides for Java còn cung cấp một số tính năng sau:

- Nhập các định dạng tệp Microsoft Office khác dưới dạng [OLE objects into PPT documents]().
- [Export PPT documents to PDF](/slides/vi/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- Xuất các slide trong tài liệu PPT sang định dạng SVG.
- Kết xuất slide sang bất kỳ định dạng hình ảnh nào được hỗ trợ bởi Java Framework.
- Đặt kích thước của slide trong tài liệu PPT.
- Quản lý hoạt họa trên các hình dạng.
- Quản lý trình chiếu.
- [Format text on slides]().
- Trích xuất văn bản từ tài liệu PPT.
- [Handle tables on slides]().
- Tự động sao chép master bằng [the cloning feature]().
