Đây là trang lịch sử, được giữ lại cho các liên kết hiện có. Nó không mô tả phiên bản hiện tại của Aspose.Slides for Java. Đối với các định dạng mà Aspose.Slides for Java tải, nhập, lưu và render, và API cho mỗi định dạng, xem [Định dạng tệp được hỗ trợ](/slides/vi/java/supported-file-formats/). {{% alert color="info" title="Note" %}}
[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) là định dạng tệp tài liệu trình chiếu có thể được tạo, đọc, thao tác và ghi bởi các phiên bản khác nhau của Microsoft PowerPoint. Đây là định dạng nhị phân cho tài liệu trình chiếu do Microsoft phát triển.
{{% /alert %}}

## **PPT trong Aspose.Slides for Java**
Aspose.Slides for Java có thể đọc các tệp PPT được tạo bởi phần mềm liệt kê dưới đây.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Tương tự, các tệp PPT được tạo bởi Aspose.Slides for Java cũng có thể được đọc bởi các phần mềm ở trên.

## **Hỗ trợ toàn diện cho PPT**
Aspose.Slides for Java cung cấp hỗ trợ cho hầu hết các tính năng được định dạng tệp PPT hỗ trợ. Nó không chỉ bao gồm các tính năng cơ bản và nâng cao do các phiên bản Microsoft PowerPoint khác nhau cung cấp cho việc thao tác tệp PPT, mà còn có các tính năng mà thậm chí Microsoft PowerPoint không hỗ trợ. Lợi thế chính của việc sử dụng thư viện API Aspose.Slides for Java là dễ dàng sử dụng để xử lý các tính năng này.

Ngoài các nhiệm vụ cơ bản liên quan đến tạo, đọc và ghi tệp PPT, có một số tính năng mà Aspose.Slides for Java cung cấp:

- Nhập các định dạng tệp Microsoft Office khác dưới dạng [đối tượng OLE vào tài liệu PPT](/slides/vi/java/manage-ole/).
- [Xuất tài liệu PPT sang PDF](/slides/vi/java/convert-powerpoint-to-pdf/).
- Xuất các slide trong tài liệu PPT sang định dạng SVG.
- Hiển thị các slide thành bất kỳ định dạng hình ảnh nào được Java Framework hỗ trợ.
- Đặt kích thước của các slide trong tài liệu PPT.
- Quản lý hoạt ảnh trên các hình dạng.
- Quản lý trình chiếu.
- [Định dạng văn bản trên slide](/slides/vi/java/text-formatting/).
- Trích xuất văn bản từ tài liệu PPT.
- [Xử lý bảng trên slide](/slides/vi/java/powerpoint-table/).
- Tự động sao chép master bằng [tính năng sao chép](/slides/vi/java/clone-slides/).
