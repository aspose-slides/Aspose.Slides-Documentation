## **Về TIFF**

Định dạng Tệp Hình ảnh Được Gắn Thẻ (Tagged Image File Format) mà được biết đến với khả năng lưu trữ nhiều hình ảnh trong một tài liệu, ban đầu được tạo ra bởi Aldus. Định dạng này được hỗ trợ rộng rãi bởi các ứng dụng quét, fax và các phần mềm xử lý ảnh khác.

## **TIFF trong Aspose.Slides for Java**

Bất kỳ tài liệu nào có thể được tải trong Aspose.Slides for Java cũng có thể được chuyển đổi trực tiếp sang tài liệu TIFF bằng Aspose.Slides for Java, loại bỏ nhu cầu sử dụng bất kỳ thành phần bên thứ ba nào. Thêm vào đó, bạn có thể tùy chọn định nghĩa kích thước của các hình ảnh trong tài liệu TIFF kết quả. Bạn có thể tìm thông tin về việc xuất các tài liệu trình chiếu sang tài liệu TIFF thông qua Aspose.Slides for Java trong [Convert PowerPoint Presentations to TIFF](/slides/vi/java/convert-powerpoint-to-tiff/).
