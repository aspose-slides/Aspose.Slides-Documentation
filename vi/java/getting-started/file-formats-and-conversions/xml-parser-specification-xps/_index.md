{{% alert color="info" %}} 

Bản mô tả trang [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) là một ngôn ngữ mô tả trang và một định dạng tài liệu cố định ban đầu do Microsoft phát triển. Giống như PDF, XPS được thiết kế để bảo toàn độ trung thực của tài liệu và cung cấp giao diện tài liệu không phụ thuộc vào thiết bị. 

{{% /alert %}} 

## **XPS trong Aspose.Slides for Java**
Bất kỳ tài liệu bản trình chiếu nào có thể được tải bởi Aspose.Slides for Java đều có thể chuyển đổi sang định dạng XPS. Aspose.Slides for Java sử dụng động cơ bố cục trang và kết xuất độ trung thực cao để tạo ra đầu ra ở định dạng tài liệu XPS với bố cục cố định.
Bạn có thể tìm hiểu về việc xuất tài liệu bản trình chiếu sang tài liệu XPS thông qua Aspose.Slides for Java trong [Converting to XPS](https://docs.aspose.com/slides/vi/java/convert-powerpoint-to-xps/).
