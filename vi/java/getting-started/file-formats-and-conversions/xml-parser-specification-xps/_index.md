{{% alert color="info" title="Note" %}}
Đây là một trang lịch sử, được giữ lại cho các liên kết hiện có. Nó không mô tả phiên bản hiện tại của Aspose.Slides for Java. Đối với các định dạng mà Aspose.Slides for Java tải, nhập, lưu và hiển thị, và API cho mỗi định dạng, xem [Supported File Formats](/slides/vi/java/supported-file-formats/). Đối với hướng dẫn chuyển đổi XPS hiện tại, xem [Convert PowerPoint Presentations to XPS](/slides/vi/java/convert-powerpoint-to-xps/).
{{% /alert %}}
{{% alert color="info" title="Note" %}}
[XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) là một ngôn ngữ mô tả trang và một định dạng tài liệu cố định, ban đầu được Microsoft phát triển. Giống như PDF, XPS được thiết kế để giữ nguyên độ trung thực của tài liệu và cung cấp diện mạo tài liệu độc lập với thiết bị.
{{% /alert %}}
## **XPS trong Aspose.Slides for Java**
Bất kỳ tài liệu trình chiếu nào có thể được tải bằng Aspose.Slides for Java đều có thể chuyển đổi sang định dạng XPS. Aspose.Slides for Java sử dụng công cụ bố trí trang và engine render độ trung thực cao để tạo ra đầu ra ở định dạng tài liệu XPS cố định.
Bạn có thể tìm hiểu về việc xuất các tài liệu trình chiếu sang tài liệu XPS thông qua Aspose.Slides for Java trong [Convert PowerPoint Presentations to XPS](/slides/vi/java/convert-powerpoint-to-xps/).
