{{% alert color="info" %}}

Aspose.Slides for Java là một thư viện lớp cho phép các ứng dụng Java đọc và viết tài liệu trình chiếu mà không cần sử dụng Microsoft PowerPoint® hoặc các phần mềm khác. Aspose.Slides for Java cho phép quản lý văn bản, hình dạng, bảng & hoạt ảnh, thêm âm thanh và video vào các slide, xem trước slide, xuất slide sang định dạng SVG, PDF và hơn nữa.

Tham khảo API mới nhất có thể được tìm thấy tại [Tham khảo API Aspose.Slides for Java](https://reference.aspose.com/slides/vi/java).

{{% /alert %}}
