{{% alert color="info" %}} 

Aspose.Slides for C++ هي مكتبة فئات تمكّن تطبيقات C++ من قراءة وكتابة مستندات العروض التقديمية دون الحاجة إلى Microsoft PowerPoint® أو غيره. يسمح Aspose.Slides for C++ بإدارة النصوص والأشكال والجداول والرسوم المتحركة، إضافة الصوت والفيديو إلى الشرائح، معاينة الشرائح، وتصدير الشرائح إلى صيغة SVG أو PDF والمزيد.

يمكن العثور على أحدث مرجع برمجي في [مرجع Aspose.Slides for C++ API](https://reference.aspose.com/slides/ar/cpp/).

{{% /alert %}}
