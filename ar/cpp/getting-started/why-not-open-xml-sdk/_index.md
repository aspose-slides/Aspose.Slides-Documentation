## **نظرة عامة**

توضح هذه المقالة متى قد يختار المطورون استخدام Open XML SDK أو Aspose.Slides للعمل مع مستندات العروض التقديمية. تصف Open XML SDK بأنها مكتبة للتعامل مع حزم OOXML وعناصر XML الأساسية الخاصة بها، بينما تُقدَّم Aspose.Slides كمكتبة معالجة العروض التقديمية ذات نموذج كائنات عالي المستوى ودعم للعديد من المهام المتعلقة بـ PowerPoint.

تقارن المقالة بين الخيارين بناءً على الصيغ المدعومة، نموذج البرمجة، العرض، دعم المنصات، وحالات الاستخدام الشائعة. كما توضح أن Open XML SDK قد تكون مناسبة للعمليات الأساسية على PPTX أو للوصول المباشر إلى عناصر OOXML، بينما Aspose.Slides أكثر ملاءمة للمهام المعقدة مثل العمل مع صيغ PowerPoint متعددة، نسخ أو استنساخ الأشكال، استبدال النص، تطبيق الرسوم المتحركة، وتحويل العروض إلى PDF أو TIFF أو XPS.

## **ما هي Open XML SDK؟**
نسمع أحيانًا هذا السؤال: لماذا نستخدم منتجات Aspose بدلًا من Open XML SDK المجانية؟ الجواب سهل: الميزات والوظائف. وفقًا لـ[MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، تُعرَّف Open XML SDK على النحو التالي: تبسط Open XML SDK 2.0 مهمة تعديل حزم Open XML وعناصر مخطط Open XML الأساسية داخل الحزمة. تُغلق Open XML SDK 2.0 العديد من المهام الشائعة التي يقوم بها المطورون على حزم Open XML، بحيث يمكنك تنفيذ عمليات معقدة ببضع أسطر من الشيفرة فقط. مستندات OOXML هي في الأساس ملفات XML مضغوطة، وOpen XML SDK عبارة عن مجموعة من الفئات التي تسمح لك بالعمل مع محتوى مستندات OOXML بطريقة ذات نوعية قوية. وهذا يعني بدلاً من فك ضغط ملف لاستخراج XML، تحميل هذا XML في شجرة DOM والعمل مباشرةً مع عناصر XML وسماتها، توفر Open XML SDK فئات للقيام بذلك.

## **ما هي Aspose.Slides؟**
Aspose.Slides هي مكتبة فئات تُتيح لتطبيقك أداء مهام معالجة العروض التالية:

- البرمجة باستخدام نموذج كائن **Presentation**.
- تحويلات عالية الجودة بين جميع صيغ PowerPoint الشائعة المدعومة، بما في ذلك التحويل إلى PDF وXPS.
- إمكانية إنشاء صور مصغرة للشرائح بصيغ معروفة مثل PNG وJPEG وBMP بالإضافة إلى تصدير الشرائح إلى SVG.
- إمكانية بناء عروض من الصفر أو بدمجها من مستند واحد أو أكثر.
- دعم إضافة الرسوم المتحركة، Ole Frames، الجداول، وإنشاء وإدارة المخططات.
- توفر تحكمًا واسعًا لإدارة تنسيق النص على مستويات TextFrames وParagraphs وPortions.
  للمزيد من التفاصيل حول الميزات المدعومة، يرجى زيارة [ميزات Aspose.Slides](/slides/ar/cpp/product-overview/).

## **الخلاصة**
لا تتنافس Open XML SDK و Aspose.Slides وجهًا لوجه لأنها تخدم احتياجات وجماهير مختلفة. Open XML SDK هي مكتبة فئات تقدم طريقة ذات نوعية قوية للعمل مع مستندات OOXML. Aspose.Slides هي مكتبة معالجة عروض مفيدة جدًا توفر دعمًا كبيرًا لمعظم صيغ ملفات Microsoft PowerPoint. إذا كان كل ما تحتاجه هو عملية برمجة أساسية إلى حد ما على مستند PPTX، فقد تكون Open XML SDK خيارًا مناسبًا. باستخدام Open XML SDK، ستتعامل بسهولة مع مهام بسيطة مثل إنشاء مستند PPTX بسيط أو إزالة التعليقات، الرؤوس/التذييلات، استخراج الصور أو غيرها. يمكن إنجاز بعض المهام باستخدام Open XML SDK، ولكن لا يمكن إنجازها باستخدام Aspose.Slides. على سبيل المثال، إذا كنت بحاجة إلى الوصول مباشرة إلى عناصر XML وسماتها في مستند OOXML، فعليك استخدام Open XML SDK. ومع ذلك، إذا كنت بحاجة إلى تنفيذ عمليات معقدة على المستندات، مثل بعض المهام التالية، فإن استخدام Aspose.Slides هو الخيار الأفضل لك:

- دعم صيغ PowerPoint القديمة بالإضافة إلى PPTX.
- نسخ أو استنساخ الأشكال داخل الشرائح بطريقة تجمع الكائنات والأنماط والتنسيقات الأخرى بشكل مناسب.
- استبدال النص المنسق أو غير المنسق.
- تطبيق الرسوم المتحركة واستخدام الموصلات مع الأشكال المستخدمة.
- تحويل مستند إلى PDF أو XPS بحيث يظهر بالضبط كما كان سيفعله Microsoft PowerPoint.
- تطوير تطبيق C++ في بيئات سطح المكتب ووحدات التحكم.
