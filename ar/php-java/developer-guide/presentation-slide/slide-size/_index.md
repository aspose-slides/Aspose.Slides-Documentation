## **المقدمة**

Aspose.Slides توفر أدوات شاملة لضبط حجم الشريحة والنسبة الباعية في عروض PowerPoint، وهو أمر حاسم لكل من الطباعة والعرض على الشاشة.

الأحجام الشائعة للنسبة:

- **القياسي (نسبة 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **عريض (نسبة 16:9)**: يُنصح به للعارضات الحديثة وأجهزة العرض.

تأكد من التناسق طوال العرض لأن حجم الشريحة والنسبة الباعية الواحدة تُطبق على جميع الشرائح. للحصول على أفضل النتائج، اضبط أبعاد الشريحة في بداية عملية إنشاء العرض لتجنب التعقيدات.

{{% alert color="primary" %}} 
بشكلٍ افتراضي، العروض التي تُنشئها Aspose.Slides تستخدم النسبة القياسية 4:3.
{{% /alert %}}

## **تغيير حجم الشريحة في العروض التقديمية**

هذا المثال البرمجي يُظهر لك كيفية تغيير حجم الشريحة في عرض تقديمي باستخدام Aspose.Slides:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **تحديد أحجام شرائح مخصصة في العروض التقديمية**

إذا وجدت أن الأحجام الشائعة للشرائح (4:3 و 16:9) غير ملائمة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بالحجم الكامل من عرضك على تخطيط صفحة مخصص أو إذا كنت تنوي عرض عرضك على أنواع شاشات معينة، فستستفيد على الأرجح من إعداد حجم مخصص للعرض.

هذا المثال البرمجي يُظهر لك كيفية استخدام Aspose.Slides للـ PHP عبر Java لتحديد حجم شريحة مخصص لعرض تقديمي:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// حجم ورق A4

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد أن تقوم بتغيير حجم الشريحة للعرض، قد يصبح محتوى الشرائح (الصور أو الكائنات، على سبيل المثال) مشوَّهًا. بشكلٍ افتراضي، تُعيد الكائنات تعديل حجمها تلقائيًا لتلائم حجم الشريحة الجديد. ومع ذلك، عند تغيير حجم شريحة العرض، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتويات على الشرائح.

اعتمادًا على ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد تعديل حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا كنت تريد تقليل حجم الشريحة وتحتاج إلى أن تقوم Aspose.Slides بتقليل حجم كائنات الشرائح لضمان ملئها داخل الشريحة (بهذا تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا كنت تريد زيادة حجم الشريحة وتحتاج إلى أن تقوم Aspose.Slides بتكبير كائنات الشرائح لتكون متناسبة مع حجم الشريحة الجديد، استخدم هذا الإعداد.

هذا المثال البرمجي يُظهر لك كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة العرض:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **الأسئلة الشائعة**

**هل يمكنني تعيين حجم شريحة مخصص باستخدام وحدات غير البوصة (مثل النقاط أو المليمترات)؟**

نعم. Aspose.Slides تستخدم النقاط داخليًا، حيث أن 1 نقطة تساوي 1/72 من البوصة. يمكنك تحويل أي وحدة (مثل المليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحوَّلة لتحديد عرض وارتفاع الشريحة.

**هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستخدام الذاكرة أثناء التصيير؟**

نعم. الأبعاد الأكبر للشرائح (بالنقاط) مع مقياس تصيير أعلى يؤدي إلى استهلاك أكبر للذاكرة وزمن معالجة أطول. استهدف حجم شريحة عملي وقم بتعديل مقياس التصيير فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

**هل يمكنني تعريف حجم شريحة غير قياسي واحد ثم دمج شرائح من عروض لديها أحجام مختلفة؟**

لا يمكنك [دمج العروض](/slides/ar/php-java/merge-presentation/) بينما لها أحجام شرائح مختلفة — أولًا، أعد تحجيم عرض واحد ليتطابق مع الآخر. عند تغيير حجم الشريحة، يمكنك اختيار كيفية معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/php-java/aspose.slides/slidesizescaletype/) . بعد توحيد الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

**هل يمكنني توليد صور مصغرة لأشكال فردية أو مناطق محددة من الشريحة، وهل ستحترم حجم الشريحة الجديد؟**

نعم. Aspose.Slides يمكنه إنشاء صور مصغرة لـ [الشرائح بالكامل](https://reference.aspose.com/slides/ar/php-java/aspose.slides/slide/#getImage) وكذلك لـ [الأشكال المحددة](https://reference.aspose.com/slides/ar/php-java/aspose.slides/shape/#getImage). الصور الناتجة تعكس حجم الشريحة الحالي والنسبة الباعية، مما يضمن تأطيرًا وتناسقًا ثابتًا.
