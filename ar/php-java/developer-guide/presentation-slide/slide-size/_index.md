## **المقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة العرض إلى الارتفاع في عروض PowerPoint التقديمية، وهو أمر ضروري لكل من الطباعة والعرض على الشاشات.

الأحجام والنسب الشائعة للشرائح:

- **قياسي (نسبة عرض إلى ارتفاع 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **عريض (نسبة عرض إلى ارتفاع 16:9)**: يوصى به لأجهزة العرض الحديثة والشاشات.

احرص على الحفاظ على التناسق عبر العرض التقديمي بأكمله حيث يُطبق حجم الشريحة ونسبة العرض إلى الارتفاع الواحد على جميع الشرائح. للحصول على أفضل النتائج، حدد أبعاد الشريحة في بداية عملية إنشاء العرض لتجنب التعقيدات.

{{% alert color="info" title="Note" %}}
بشكل افتراضي، تستخدم العروض التي تم إنشاؤها باستخدام Aspose.Slides نسبة عرض إلى ارتفاع قياسية 4:3.
{{% /alert %}}

لصفحات الملاحظات والنسخ الموزعة أبعاد منفصلة عن الشرائح العادية. راجع [حجم صفحة الملاحظات](/slides/ar/php-java/notes-size/) لتغيير حجمها واتجتها.

## **تغيير حجم الشريحة في العروض التقديمية**

يعرض هذا المثال البرمجي كيفية تغيير حجم الشريحة في عرض تقديمي باستخدام Aspose.Slides:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **تحديد أحجام شرائح مخصصة في العروض التقديمية**

إذا وجدت أن الأحجام الشائعة للشرائح (4:3 و16:9) غير ملائمة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بحجم كامل من العرض على تخطيط صفحة مخصص أو إذا كنت تريد عرض العرض على أنواع شاشات معينة، فمن المحتمل أن تستفيد من تعيين حجم مخصص للعرض.

يعرض هذا المثال البرمجي كيفية استخدام Aspose.Slides for PHP عبر Java لتحديد حجم شريحة مخصص لعرض تقديمي:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// حجم ورق A4

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد تغيير حجم الشريحة لعرض تقديمي، قد يصبح محتوى الشرائح (مثل الصور أو الكائنات) مشوّهًا. بشكل افتراضي، يتم تغيير حجم الكائنات تلقائيًا لتتناسب مع الحجم الجديد. ومع ذلك، عند تغيير حجم شريحة العرض، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتوى على الشرائح.

حسب ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد أن يتم تغيير حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا أردت التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن يقوم Aspose.Slides بتقليل حجم الكائنات لضمان ملاءتها جميعًا على الشرائح (وبهذا تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا أردت التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن يقوم Aspose.Slides بتكبير الكائنات لتصبح متناسبة مع الحجم الجديد، استخدم هذا الإعداد.

يعرض هذا المثال البرمجي كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة عرض تقديمي:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **الأسئلة الشائعة**

**هل يمكنني تعيين حجم شريحة مخصص باستخدام وحدات غير البوصة (مثلاً نقاط أو مليمترات)؟**

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث تساوي النقطة الواحدة 1/72 من البوصة. يمكنك تحويل أي وحدة (مثل المليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحوَّلة لتحديد عرض وارتفاع الشريحة.

**هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستهلاك الذاكرة أثناء التصيير؟**

نعم. الأبعاد الأكبر للشرائح (بالنقاط) مع مقياس تصيير أعلى تؤدي إلى زيادة استهلاك الذاكرة ووقت المعالجة. احرص على اختيار حجم شريحة عملي وضبط مقياس التصيير فقط عند الحاجة للحصول على جودة الإخراج المطلوبة.

**هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج شرائح من عروض تقديمية ذات أحجام مختلفة؟**

لا يمكنك [دمج العروض التقديمية](/slides/ar/php-java/merge-presentation/) بينما تكون أحجام الشرائح مختلفة — عليك أولاً تعديل حجم أحد العروض ليتطابق مع الآخر. عند تغيير حجم الشريحة، يمكنك اختيار كيفية معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/php-java/aspose.slides/slidesizescaletype/). بعد توحيد الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

**هل يمكنني إنشاء صور مصغرة لأشكال فردية أو مناطق محددة من الشريحة، وهل ستحترم حجم الشريحة الجديد؟**

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لـ [الشرائح بالكامل](https://reference.aspose.com/slides/ar/php-java/aspose.slides/slide/#getImage) وكذلك لـ [الأشكال المحددة](https://reference.aspose.com/slides/ar/php-java/aspose.slides/shape/#getImage). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة العرض إلى الارتفاع، مما يضمن تأطيرًا وتناسقًا جيوميتريًا ثابتًا.
