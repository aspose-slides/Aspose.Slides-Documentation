## **نظرة عامة**

تشرح هذه المقالة متى قد يختار المطورون Open XML SDK أو Aspose.Slides للعمل مع مستندات العروض التقديمية. تصف Open XML SDK بأنها مكتبة لتعديل حزم OOXML وعناصر XML الأساسية الخاصة بها، بينما تُقدم Aspose.Slides كمكتبة معالجة عروض تقديمية بنموذج كائن عالي المستوى ودعم للعديد من المهام المتعلقة بـ PowerPoint.

تقارن المقالة الخيارين من حيث الصيغ المدعومة، نموذج البرمجة، العرض، دعم المنصات، وحالات الاستخدام الشائعة. كما توضح أن Open XML SDK قد يكون مناسبًا للعمليات الأساسية على ملفات PPTX أو للوصول المباشر إلى عناصر OOXML، بينما Aspose.Slides أكثر ملاءمة للمهام المعقدة مثل التعامل مع صيغ PowerPoint المتعددة، نسخ أو استنساخ الأشكال، استبدال النص، تطبيق الرسوم المتحركة، وتحويل العروض إلى PDF أو TIFF أو XPS.

## **ما هو Open XML SDK؟**
وفقًا لـ [مكتبة MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، يتم تعريف Open XML SDK كالتالي:

يوّسط Open XML SDK 2.0 مهمة تعديل حزم Open XML وعناصر مخطط Open XML الأساسية داخل الحزمة. يضمّن Open XML SDK 2.0 العديد من المهام الشائعة التي يقوم بها المطورون على حزم Open XML، بحيث يمكنك تنفيذ عمليات معقدة ببضع أسطر من الشيفرة فقط.

مستندات OOXML هي في الأساس ملفات XML مضغوطة، وOpen XML SDK هو مجموعة من الفئات التي تسمح لك بالعمل مع محتوى مستندات OOXML بطريقة ذات نوعية قوية. وهذا يعني بدلاً من فك ضغط ملف لاستخراج XML، ثم تحميل هذا XML إلى شجرة DOM والعمل مع عناصر وسمات XML مباشرة، يوفر Open XML SDK فئات للقيام بذلك.

## **ما هو Aspose.Slides؟**
Aspose.Slides هي مكتبة فئات تتيح لتطبيقك تنفيذ مهام معالجة العروض التقديمية التالية:

- البرمجة باستخدام نموذج كائن **Presentation**.
- تحويلات عالية الجودة بين جميع صيغ PowerPoint المدعومة، بما في ذلك التحويل إلى PDF وXPS وTIFF.
- القدرة على إنشاء صور مصغرة للشرائح بصيغ معروفة مثل PNG وJPEG وBMP بالإضافة إلى تصدير الشرائح إلى SVG.
- القدرة على بناء عروض تقديمية من الصفر أو عبر الجمع بين مستند واحد أو عدة مستندات.
- دعم إضافة الرسوم المتحركة، وإطارات Ole، والجداول، وإنشاء وإدارة المخططات.
- إتاحة تحكم واسع في تنسيق النص داخل TextFrames والفقرات والـ Portions.

لمزيد من التفاصيل حول الميزات المدعومة، يرجى زيارة [ميزات Aspose.Slides](/slides/ar/php-java/product-overview/).

## **الخلاصة**
{{% alert color="info" %}} 

لا يتنافس Open XML SDK و Aspose.Slides مباشرةً لأنهما يلبيان احتياجات وجماهير مختلفة. Open XML SDK هي مكتبة فئات توفر طريقة ذات نوعية قوية للعمل مع مستندات OOXML. Aspose.Slides هي مكتبة معالجة عروض تقديمية مفيدة للغاية تقدم دعماً كبيراً لمعظم صيغ ملفات Microsoft PowerPoint.

إذا كان كل ما تحتاجه هو عملية برمجة أساسية إلى حد ما على مستند PPTX، فقد يكون Open XML SDK خيارًا مناسبًا. باستخدام Open XML SDK ستكون مرتاحًا للقيام بمهام بسيطة مثل إنشاء مستند PPTX بسيط أو إزالة التعليقات، رؤوس/تذييلات الصفحات، استخراج الصور أو غيرها. يمكن تحقيق بعض المهام باستخدام Open XML SDK، لكن لا يمكن تحقيقها باستخدام Aspose.Slides. على سبيل المثال، إذا كنت بحاجة إلى الوصول المباشر إلى عناصر XML وسمات مستند OOXML، فيجب عليك استخدام Open XML SDK. ومع ذلك، إذا كنت بحاجة إلى تنفيذ عمليات معقدة على المستندات، مثل بعض المهام التالية، فإن استخدام Aspose.Slides هو الخيار الأفضل:

- دعم صيغ PowerPoint القديمة بالإضافة إلى PPTX.
- نسخ أو استنساخ الأشكال داخل الشرائح بطريقة تجمع الكائنات والأنماط والتنسيق المناسب.
- استبدال النص المنسق أو غير المنسق.
- تطبيق الرسوم المتحركة واستخدام الموصلات مع الأشكال.
- تحويل مستند إلى PDF أو TIFF أو XPS بحيث يظهر تمامًا كما لو أن Microsoft PowerPoint قام بتحويله.
- تطوير تطبيق .NET أو Java في بيئات سطح المكتب والويب.
