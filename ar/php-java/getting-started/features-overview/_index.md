## **المنصات المدعومة**
Aspose.Slides for PHP via Java هو واجهة برمجة تطبيقات مستقلة عن النظام. يمكن استخدامها على أي نظام (Windows، Linux، MacOS، إلخ) حيث تم تثبيت PHP 7 أو أعلى. Oracle JDK 7 أو أعلى هو متطلب آخر.

## **تنسيقات الملفات والتحويلات**
Aspose.Slides for PHP via Java يدعم معظم تنسيقات مستندات PowerPoint. كما يتيح لك تصديرها إلى تنسيقات الملفات الشائعة التي تستخدمها المؤسسات وتشاركها مع بعضها البعض. اطلع على هذه التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java يوفر أسرع معالجة لهذا تنسيق مستند العرض التقديمي.|
|PPT to PPTX conversion|Aspose.Slides for PHP via Java يدعم التحويل من PPT إلى PPTX|
|Portable Document Format (PDF)|يمكنك تصدير جميع التنسيقات المدعومة إلى مستندات Adobe Portable Document Format (PDF) بطريقة واحدة.|
|XML Parser Specification (XPS)|يمكنك تصدير جميع التنسيقات المدعومة إلى مستندات XML Parser Specification (XPS) بطريقة واحدة.|
|Tagged Image File Format (TIFF)|يمكنك تصدير جميع تنسيقات ملفات العروض التقديمية المدعومة إلى Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for PHP via Java يدعم تحويل PresentationEx إلى تنسيق HTML.|

## **عرض العروض التقديمية**
Aspose.Slides for PHP via Java يدعم عرض عالي الدقة للشرائح في العروض إلى تنسيقات رسومية مختلفة. اطلع على هذه التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|Java Supported Image Formats|باستخدام Aspose.Slides for PHP via Java، يمكنك تصيير شرائح العرض والصور على الشرائح إلى جميع تنسيقات الرسومات المدعومة من Java مثل TIFF، PNG، BMP، JPEG، GIF.|
|SVG Format|Aspose.Slides for PHP via Java يوفر أيضاً طرقاً مدمجة تسمح لك بتصدير شرائح العرض إلى تنسيقات Scalable Vector Graphics (SVG).|

## **الأسئلة الشائعة**

### هل أحتاج إلى تثبيت Microsoft PowerPoint على الخادم/الكمبيوتر لتعمل المكتبة؟

لا. لا يلزم PowerPoint؛ Aspose.Slides هو محرك منفصل لإنشاء وتعديل وتحويل وعرض العروض التقديمية.

### كيف يعمل تعدد الخيوط؟ هل يمكن إ paralelo المعالجة؟

من الآمن معالجة مستندات مختلفة في خيوط مختلفة؛ يجب عدم استخدام نفس [presentation](https://reference.aspose.com/slides/ar/php-java/aspose.slides/presentation/) في [multiple threads](/slides/ar/php-java/multithreading/) في نفس الوقت.

### هل تُدعم كلمات مرور الملفات والتشفير؟

نعم. يمكنك [open encrypted presentations](/slides/ar/php-java/password-protected-presentation/)، ضبط أو إزالة كلمة مرور الفتح والكتابة، والتحقق من حالة الحماية.

### هل يجب القلق بشأن حزم الخطوط في حاويات Linux؟

نعم. يوصى بتثبيت حزم الخطوط الشائعة و/أو تحديد أدلة الخطوط صراحةً [/slides/ar/php-java/custom-font/] في تطبيقك لتجنب الاستبدالات غير المتوقعة.

### هل هناك قيود في نسخة التقييم؟

في وضع [evaluation](/slides/ar/php-java/licensing/)، يُضاف علامة مائية إلى المخرجات وتُطبق بعض القيود؛ يتوفر [رخصة مؤقتة لمدة 30 يومًا](https://purchase.aspose.com/temporary-license/) للاختبار الكامل للميزات.

### هل استيراد تنسيقات خارجية إلى عرض تقديمي (PDF/HTML → PPTX) مدعوم؟

نعم. يمكنك إضافة [PDF pages and HTML content](/slides/ar/php-java/import-presentation/) إلى عرض تقديمي، وتحويلها إلى شرائح.
