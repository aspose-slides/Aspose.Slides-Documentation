## **نظرة عامة**

Aspose.Slides for Python via Java يقرأ ويكتب عروض PowerPoint وOpenDocument. كما أنه يستورد محتوى PDF وHTML إلى الشرائح ويصدّر العروض أو الشرائح الفردية إلى صيغ المستندات والويب والصور.

الجدول أدناه يميّز تحميل العرض من استيراد المحتوى وعرض الشرائح. للحصول على نظرة عامة حول قدرات التحرير والعرض، راجع [نظرة عامة على الميزات](/slides/ar/python-java/features-overview/).

- PowerPoint for Microsoft 365 (formerly Office 365)

## **ملاحظات الاستيراد والتصدير**

- **استيراد PDF وHTML:** استخدم [SlideCollection.addFromPdf](https://reference.aspose.com/slides/ar/python-java/aspose.slides/slidecollection/#addfrompdf) أو [SlideCollection.addFromHtml](https://reference.aspose.com/slides/ar/python-java/aspose.slides/slidecollection/#addfromhtml) لإنشاء شرائح من المحتوى المصدر وإلحاقها بالعرض.
- **إخراج العرض:** يدرج [SaveFormat](https://reference.aspose.com/slides/ar/python-java/aspose.slides/saveformat/) صيغ حفظ العروض المتاحة، بما في ذلك خيارات التصدير إلى HTML وHTML5 المنفصلة.
- **إخراج الصورة:** تصدير شريحة إلى صورة ينتج تمثيلًا مرئيًا لتلك الشريحة. عمود الإدخال لا يصف ما إذا كان يمكن إدراج صورة في عرض.

## **الأسئلة الشائعة**

**هل يمكنني تحويل عرض PPT إلى PPTX أو ODP؟**

نعم. PPT مدعوم كصيغة إدخال، كما أن PPTX وODP مدعومان كصيغ إخراج. تعتمد نتائج التحويل على الميزات المتاحة في الصيغة الوجهة.

**هل يفتح استيراد PDF أو HTML المصدر كملف PowerPoint؟**

لا. الاستيراد يخلق شرائح من صفحات PDF أو محتوى HTML. يمكنك بعد ذلك حفظ العرض الناتج بصيغة عرض مدعومة.

**هل يمكنني تحميل PNG أو SVG المصدَّر كعرض قابل للتحرير؟**

لا. هذه الصادرات تمثّل مظهر الشريحة. احتفظ بالعرض الأصلي عندما تحتاج إلى تعديل النصوص أو الأشكال أو المخططات أو الكائنات الأخرى لاحقًا.
