يصف هذا المقال قدرات معالجة العروض التقديمية في Aspose.Slides for Python via Java. للأنظمة التشغيلية المدعومة والاعتمادات، راجع [متطلبات النظام](/slides/ar/python-java/system-requirements/).

## **تنسيقات الملفات والتحويلات**

يسمح Aspose.Slides for Python via Java لك بتحويل بين تنسيقات العروض وتصدير العروض إلى صيغ المستندات والويب. راجع [تنسيقات الملفات المدعومة](/slides/ar/python-java/supported-file-formats/) للاطلاع على جدول الصيغ الكامل والتمييز بين تحميل العروض، استيراد المحتوى، وتصدير الناتج.

## **معالجة عرض الشرائح**

يوفر Aspose.Slides for Python via Java عرضًا عالي الدقة للشرائح كصور نقطية أو متجهة للمعاينات والمخرجات البصرية الأخرى. كما يتيح لك تصيير الصور على الشرائح. للأنماط المتاحة من الصور وملاحظات التصدير، راجع [تنسيقات الملفات المدعومة](/slides/ar/python-java/supported-file-formats/#supported-file-formats).

| :- | :- |
|تنسيق النص|<p>يمكنك إدارة النص عبر إطارات النص المرتبطة بالأشكال وتنسيق الفقرات الفردية وأجزاء النص. الخيارات التنسيقية التالية متاحة:</p><p>- نوع الخط</p><p>- حجم الخط</p><p>- لون الخط</p><p>- تظليل الخط</p><p>- محاذاة الفقرة</p><p>- إزاحة الفقرة والمسافات</p><p>- تعداد الفقرة</p><p>- اتجاه الفقرة</p>|
