## **الأنظمة المدعومة**
Aspose.Slides for Python via Java هي واجهة برمجة تطبيقات مستقلة عن النظام. يمكن استخدامها على أي نظام (ويندوز، لينكس، ماك أو إس، إلخ) حيث تم تثبيت Python 3.7 أو أعلى. كما يتطلب وجود JDK 8 أو أعلى.

## **تنسيقات الملفات والتحويلات**
Aspose.Slides for Python via Java يدعم معظم تنسيقات مستندات PowerPoint. كما يتيح لك تصديرها إلى تنسيقات الملفات الشائعة التي تستخدمها المنظمات وتشاركها فيما بينها. إليك التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java يوفر أسرع معالجة لهذا التنسيق من مستندات العروض التقديمية.|
|تحويل PPT إلى PPTX|Aspose.Slides for Python via Java يدعم تحويل PPT إلى PPTX|
|Portable Document Format (PDF)|يمكنك تصدير جميع تنسيقات الملفات المدعومة إلى مستندات Adobe Portable Document Format (PDF) باستخدام طريقة واحدة.|
|XML Parser Specification (XPS)|يمكنك تصدير جميع تنسيقات الملفات المدعومة إلى مستندات XML Parser Specification (XPS) باستخدام طريقة واحدة.|
|Tagged Image File Format (TIFF)|يمكنك تصدير جميع تنسيقات ملفات العروض التقديمية المدعومة إلى Tagged Image File Format (TIFF).|
|تحويل PPTX إلى HTML|Aspose.Slides for Python via Java يدعم تحويل PresentationEx إلى تنسيق HTML.|

## **عرض الشرائح**
Aspose.Slides for Python via Java يدعم عرض عالي الدقة للشرائح في العروض التقديمية إلى تنسيقات رسومية مختلفة. إليك التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|تنسيقات الصور المدعومة في Java|باستخدام Aspose.Slides for Python via Java، يمكنك عرض شرائح العروض التقديمية والصور على الشرائح إلى جميع تنسيقات الرسومات المدعومة في Java مثل TIFF، PNG، BMP، JPEG، GIF.|
|تنسيق SVG|Aspose.Slides for Python via Java يوفر أيضًا أساليب مدمجة تسمح لك بتصدير شرائح العرض إلى تنسيقات Scalable Vector Graphics (SVG).|

## **ميزات التنسيق**
باستخدام Aspose.Slides for Python via Java، يمكنك تنسيق النصوص والأشكال على الشرائح في العروض التقديمية. إليك التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|تنسيق النص|<p>في Aspose.Slides for Python via Java، يمكنك إدارة النصوص من خلال إطارات النص المرتبطة بالأشكال. وبالتالي، يمكنك تنسيق النصوص باستخدام الفقرات والأجزاء المرتبطة بإطارات النص. يمكن تنسيق هذه العناصر النصية عبر Aspose.Slides for Python via Java.</p><p>- نوع الخط</p><p>- حجم الخط</p><p>- لون الخط</p><p>- تدرجات اللون</p><p>- محاذاة الفقرة</p><p>- تعداد الفقرة</p><p>- اتجاه الفقرة</p>|
|تنسيق الشكل|<p>في Aspose.Slides for Python via Java، العنصر الأساسي في الشريحة هو الشكل. يمكنك تنسيق هذه الأشكال باستخدام Aspose.Slides for Python via Java:</p><p>- الموضع</p><p>- الحجم</p><p>- الحدود</p><p>- التعبئة (بما فيها النمط، التدرج، الصلب)</p><p>- النص</p><p>- الصورة</p>|
