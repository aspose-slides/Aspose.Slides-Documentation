**مرحبًا بك في Aspose.Slides for Python via Java**

![شعار منتج Aspose.Slides for Python via Java](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java هي مكتبة فئات تمكن تطبيقات Python الخاصة بك من قراءة وكتابة عروض PowerPoint® دون الحاجة إلى Microsoft PowerPoint®.

تشمل ميزاته الرئيسية إدارة النصوص والأشكال والجداول والرسوم المتحركة؛ إضافة الصوت والفيديو إلى الشرائح؛ معاينة الشرائح؛ وتصدير الشرائح إلى SVG و PDF وغيرها من الصيغ.

{{% /alert %}}
