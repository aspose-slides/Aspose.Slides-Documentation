## **المقدمة**

تُستخدم خطوط الاحتياطي عندما يكون الخط المحدد للنص متوفرًا في النظام لكنه لا يحتوي على الحرف المطلوب. في هذه الحالة، يمكن لـ Aspose.Slides استخدام أحد خطوط الاحتياطي المحددة لاستبدال الحرف المفقود.

## **خط الاحتياطي**

يسمح Aspose.Slides بإنشاء خطوط احتياطية، وإضافتها إلى مجموعة خطوط الاحتياطي، وتعيين مجموعة خطوط الاحتياطي لعروض تقديمية معينة، وإزالة خطوط الاحتياطي من العرض التقديمي، وتحديد القواعد لتطبيق خطوط الاحتياطي، وأداء عمليات أخرى ذات صلة.

## **الأسئلة المتكررة**

**كيف تختلف خطوط الاحتياطي عن استبدال الخط؟**

يُطبق الاحتياطي لكل حرف أو لنطاق من Unicode عندما يفتقر الخط الأساسي إلى حروف معينة؛ فإنه يملأ فقط الحروف المفقودة. [استبدال](/slides/ar/python-java/font-substitution/) يستبدل خطًا مفقودًا أو غير متاح لجزء نص كامل أو مقطع بنص آخر. يمكن دمجهما، لكن نطاقهما ومنطق الاختيار مختلفان.

**هل تُحفظ إعدادات الاحتياطي داخل ملف العرض التقديمي؟**

لا. تُعَدّ تكوينات الاحتياطي أثناء المعالجة/العرض في المكتبة ولا يتم تسلسلها إلى ملف PPTX. لا يخزن العرض التقديمي قواعد الاحتياطي الخاصة بك.

**هل يؤثر الاحتياطي على العناصر التي تنشئها كائنات PowerPoint (SmartArt, charts, WordArt)؟**

نعم. يمر النص داخل هذه الكائنات عبر نفس خط أنابيب العرض، لذا تُطبق قواعد الاحتياطي نفسها عليه كما على النص العادي.
