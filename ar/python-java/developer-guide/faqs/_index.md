## **نظرة عامة**

تغطي هذه الأسئلة المتكررة تنسيقات الملفات المدعومة، واستخدام الذاكرة مع العروض التقديمية الكبيرة، وأحجام الشرائح ومعاينات الشرائح، واستخراج النص، وحدود الجداول، وتحديد موضع الصور، واختلافات الخطوط عند تحويل العروض التقديمية إلى PDF أو صور.

## **الأسئلة المتكررة**

### **تنسيقات الملفات المدعومة**

**ما هي تنسيقات الملفات التي يدعمها Aspose.Slides for Python via Java؟**

انظر [تنسيقات الملفات المدعومة](/slides/ar/python-java/supported-file-formats/) للحصول على تنسيقات العروض التقديمية والوثائق والصور المدعومة وإمكانات الاستيراد والتصدير الخاصة بها.

### **الاستثناءات**

**لماذا أحصل على خطأ نقص الذاكرة عند تحميل عرض تقديمي كبير يحتوي على صور؟ هل هناك حد لحجم الملف؟**

لا يوجد حد وحيد لحجم الملف يمكنه التنبؤ بما إذا كان العرض التقديمي سيتناسب مع الذاكرة. تعتمد متطلبات الذاكرة على بنية العرض التقديمي، والصور غير المضغوطة، والتأثيرات، والعمليات التي تجريها. يمكن للصور أن تشغل ذاكرة أكبر بكثير من حجمها المضغوط على القرص.

Aspose.Slides for Python via Java يستخدم محرك Java عبر JPype، لذا يجب أن يحتوي تجمع الذاكرة الخاص بـ JVM على مساحة كافية للمعالجة. لا يشير حجم الذاكرة المتاح في النظام وحده إلى مقدار الذاكرة التي يمكن أن يستخدمها JVM. حرّر العروض التقديمية باستخدام [Presentation.dispose](https://reference.aspose.com/slides/ar/python-java/aspose.slides/presentation/#dispose) عند الانتهاء منها. لإعداد البيئة، انظر [متطلبات النظام](/slides/ar/python-java/system-requirements/) و[التثبيت](/slides/ar/python-java/installation/).

### **العمل مع الشرائح**

**هل يمكنني تغيير حجم الشرائح في العرض التقديمي؟**

نعم. استخدم [Presentation.getSlideSize](https://reference.aspose.com/slides/ar/python-java/aspose.slides/presentation/#getslidesize) للوصول إلى إعدادات حجم الشرائح في العرض التقديمي، ثم استخدم [SlideSize.setSize](https://reference.aspose.com/slides/ar/python-java/aspose.slides/slidesize/#setsize) لتحديد الأبعاد واختيار طريقة تعديل حجم المحتوى الموجود.

**هل يمكن للشرائح في نفس العرض التقديمي أن تكون بأحجام مختلفة؟**

لا. تُحدد مستندات Microsoft PowerPoint حجم الشريحة على مستوى العرض التقديمي، لذا جميع الشرائح تشترك في نفس الأبعاد.

**هل يمكنني معاينة شريحة قبل حفظ العرض التقديمي؟**

نعم. قم بتحويل الشريحة إلى صورة واعرضها في تطبيقك. لا تحتاج إلى حفظ العرض التقديمي أولاً.

### **العمل مع النص**

**هل يمكنني استخراج كل النص من العرض التقديمي؟**

نعم. توفر فئة [SlideUtil](https://reference.aspose.com/slides/ar/python-java/aspose.slides/slideutil/) طرقًا لاستخراج النص من العروض التقديمية والشرائح الفردية.

**لماذا تختلف أحجام الفقرات بين Windows و Linux؟**

تعتمد أبعاد الفقرة على مقاييس الخطوط المستخدمة في عرض النص. إذا كان الخط مفقودًا، قد يكون للخط البديل عرض أحرف وارتفاع خطوط مختلفين، مما يغير التفاف السطر وأبعاد الفقرة. قم بتثبيت نفس الخطوط على النظامين أو حمّل ملفات الخط نفسها باستخدام [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/ar/python-java/aspose.slides/fontsloader/#loadexternalfonts) قبل إنشاء أو تحميل العروض التقديمية.

### **التنسيق والصور**

**كيف يمكنني ضبط لون حدود الجدول؟**

استخدم [Cell.getCellFormat](https://reference.aspose.com/slides/ar/python-java/aspose.slides/cell/#getcellformat) للوصول إلى تنسيق حدود كل خلية وتعيين لون التعبئة للحدود ذات الصلة. لتغيير جميع الحدود، عالج جميع الخلايا. لتغيير حدود الجدول فقط، حدّث الحدود الخارجية للخلايا على طول حواف الجدول.

**ما الوحدات المستخدمة لتحديد موضع وحجم الصور؟**

تقاس إحداثيات الأشكال وأبعادها بالنقاط. إن البوصة الواحدة تساوي 72 نقطة؛ هذه القيم ليست إحداثيات بكسل.

### **العمل مع الخطوط**

**لماذا تتغير الخطوط عند تحويل العرض التقديمي إلى PDF أو صور؟**

قد تكون الخطوط المطلوبة غير موجودة على الجهاز الذي يقوم بالتحويل. قم بتثبيت الخطوط الأصلية أو استخدم [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/ar/python-java/aspose.slides/fontsloader/#loadexternalfonts) لإضافة المجلدات التي تحتوي عليها. حمّل الخطوط الخارجية قبل إنشاء أو فتح العروض التقديمية.

المثال التالي يسجل مجلد خطوط. استبدل المسار بمجلد موجود يحتوي على ملفات الخطوط الخاصة بك. يفترض البيئة الموصوفة في [التثبيت](/slides/ar/python-java/installation/).

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontsLoader

font_folders = jpype.JArray(jpype.JString)(["path_to_a_folder_with_fonts"])
FontsLoader.loadExternalFonts(font_folders)
```

يترك المثال JVM يعمل للعمليات اللاحقة على العروض التقديمية. لاستخدام الدفتر القيود على دورة حياة JVM، انظر [القيود واختلافات API](/slides/ar/python-java/limitations-and-api-differences/).
