## **المقدمة**

تضمن إمكانية الوصول إلى العروض التقديمية أن الأشخاص الذين يستخدمون تقنيات المساعدة—مثل قارئات الشاشة، وشاشات برايل، أو التنقل عبر لوحة المفاتيح فقط—يمكنهم فهم شرائحك والتنقل فيها بفعالية مماثلة للجمهور البصري الذي يستخدم الفأرة. تركّز الممارسات الجيدة على ترتيب قراءة واضح، ونص بديل ذي معنى للمرئيات الإعلامية، وتباين ألوان كافٍ، وطباعة قابلة للقراءة، ونص رابط وصفي، وتجنّب نقل المعنى عبر اللون أو الموضع فقط. عندما تُخطَّط إمكانية الوصول من البداية، يترتب على ذلك بنية أنظف، مرئيات أكثر اتساقًا، ومحتوى يصل إلى كل مشاهد دون الحاجة إلى حلول بديلة.

## **علامة كزخرفة**

علامة كزخرفة تُشير إلى المرئيات الزخرفية البحتة بحيث يتخطاها قارئات الشاشة، مما يقلل الضوضاء ويحافظ على تركيز القارئ على المحتوى المفيد. يُطبق هذا على الخلفيات، والزخارف، والمسافات الفاصلة—ولا يُستخدم أبداً على المخططات أو الأيقونات أو الصور التي تنقل معلومات. تُتيح Aspose.Slides هذه العلامة للكشف والتحقق، مما يتيح فحص إمكانية الوصول الآلي وتنظيفه.

![علامة كزخرفة](mark_as_decorative.png)

يعرض المثال البرمجي التالي كيفية تحديد ما إذا كان الشكل مُعلَّمًا كزخرفة.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation

presentation = Presentation("sample.pptx")
try:
    shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0)
    print(f"Is shape decorative: {shape.isDecorative()}")
finally:
    presentation.dispose()
```
