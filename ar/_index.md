## Aspose.Slides لـ .NET

{{% alert color="info" %}}

![Aspose.Slides for .NET Product Logo](home_1.png)

Aspose.Slides لـ .NET هو واجهة برمجة تطبيقات لإدارة Microsoft PowerPoint® تمكّن تطبيقات .NET من قراءة وكتابة مستندات PowerPoint® دون الحاجة إلى Microsoft PowerPoint®. Aspose.Slides لـ .NET هو المكوّن الأول والوحيد الذي يوفر وظيفة إدارة مستندات PowerPoint®. يوفر Aspose.Slides لـ .NET العديد من الميزات الأساسية مثل إدارة النصوص والأشكال والجداول والرسوم المتحركة، إضافة الصوت والفيديو إلى الشرائح، معاينة الشرائح، تصدير الشرائح إلى SVG وصيغة PDF والمزيد.
