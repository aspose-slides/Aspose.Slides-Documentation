## **المنصات المدعومة**
Aspose.Slides for Node.js via Java هي واجهة برمجة تطبيقات مستقلة عن النظام الأساسي. يمكن استخدامها على أي منصة (Windows, Linux, MacOS، إلخ) حيث تم تثبيت Node.js 7 أو أعلى. Oracle JDK 8 أو أعلى هو متطلب آخر.

## **تنسيقات الملفات والتحويلات**
Aspose.Slides for Node.js عبر Java يدعم معظم تنسيقات مستندات PowerPoint. كما يتيح لك تصديرها إلى تنسيقات الملفات الشائعة التي تستخدمها المؤسسات وتشاركها فيما بينها. اطلع على التفاصيل التالية:

|**الميزة**|**الوصف**|
| :- | :- |
|Microsoft PowerPoint (PPT)|توفر Aspose.Slides for Node.js عبر Java أسرع معالجة لهذه تنسيق مستند العرض.|
|تحويل PPT إلى PPTX|تدعم Aspose.Slides for Node.js عبر Java تحويل PPT إلى PPTX|
|Portable Document Format (PDF)|يمكنك تصدير جميع تنسيقات الملفات المدعومة إلى مستندات Adobe Portable Document Format (PDF) باستخدام طريقة واحدة.|
|XML Parser Specification (XPS)|يمكنك تصدير جميع تنسيقات الملفات المدعومة إلى مستندات XML Parser Specification (XPS) باستخدام طريقة واحدة.|
|Tagged Image File Format (TIFF)|يمكنك تصدير جميع تنسيقات ملفات العرض المدعومة إلى Tagged Image File Format (TIFF).|
|تحويل PPTX إلى HTML|تدعم Aspose.Slides for Node.js عبر Java تحويل PresentationEx إلى تنسيق HTML.|

## **عرض العروض التقديمية**
تدعم Aspose.Slides for Node.js عبر Java عرضًا عالي الدقة للشرائح في العروض التقديمية إلى تنسيقات رسومية مختلفة. اطلع على التفاصيل التالية:

|**الميزة**|**الوصف**|
| :- | :- |
|تنسيقات الصور المدعومة من Java|باستخدام Aspose.Slides for Node.js عبر Java، يمكنك عرض شرائح العرض والرسومات على الشرائح بجميع تنسيقات الرسومات المدعومة من Java مثل TIFF و PNG و BMP و JPEG و GIF.|
|تنسيق SVG|توفر Aspose.Slides for Node.js عبر Java أيضًا طرقًا مدمجة تسمح لك بتصدير شرائح العرض إلى تنسيقات Scalable Vector Graphics (SVG).|

## **الأسئلة المتكررة**

### هل أحتاج إلى تثبيت Microsoft PowerPoint على الخادم/الكمبيوتر لتعمل المكتبة؟
لا. لا يلزم PowerPoint؛ Aspose.Slides هو محرك مستقل لإنشاء العروض التقديمية وتحريرها وتحويلها وعرضها.

### كيف يعمل تعدد الخيوط؟ هل يمكن موازاة المعالجة؟
من الآمن معالجة مستندات مختلفة في خيوط مختلفة؛ يجب عدم استخدام نفس [العرض التقديمي](https://reference.aspose.com/slides/ar/nodejs-java/aspose.slides/presentation/) عبر [خيوط متعددة](/slides/ar/nodejs-java/multithreading/) في نفس الوقت.

### هل تدعم كلمات مرور الملفات والتشفير؟
نعم. [يمكنك](/slides/ar/nodejs-java/password-protected-presentation/) فتح العروض التقديمية المشفرة، تعيين أو إزالة كلمة مرور للفتح والكتابة، والتحقق من حالة الحماية.

### هل يجب أن أهتم بحزم الخطوط في حاويات Linux؟
نعم. يُنصح بتثبيت حزم الخطوط الشائعة و/أو تحديد [دليل الخطوط](/slides/ar/nodejs-java/custom-font/) صراحةً في تطبيقك لتجنب الاستبدالات غير المتوقعة.

### هل هناك قيود في نسخة التقييم؟
في [وضع التقييم](/slides/ar/nodejs-java/licensing/)، يتم إضافة علامة مائية إلى الناتج وتطبق بعض القيود؛ يتوفر [رخصة مؤقتة لمدة 30 يومًا](https://purchase.aspose.com/temporary-license/) لاختبار جميع الميزات.

### هل يتم دعم استيراد تنسيقات خارجية إلى عرض تقديمي (PDF/HTML → PPTX)؟
نعم. يمكنك إضافة [صفحات PDF ومحتوى HTML](/slides/ar/nodejs-java/import-presentation/) إلى عرض تقديمي، وتحويلها إلى شرائح.
