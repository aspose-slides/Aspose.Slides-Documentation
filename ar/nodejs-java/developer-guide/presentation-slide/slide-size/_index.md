## **المقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة العرض إلى الارتفاع في عروض PowerPoint التقديمية، وهو أمر حاسم لكل من الطباعة والعرض على الشاشة.

الأحجام الشائعة للشرائح والنسب:

- **قياسي (نسبة 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **شاشات عريضة (نسبة 16:9)**: يُنصح به لأجهزة العرض الحديثة والشاشات.

احرص على التناسق في جميع شرائح العرض حيث يتم تطبيق حجم شريحة ونسبة عرض إلى ارتفاع موحدة على جميع الشرائح. للحصول على أفضل النتائج، اضبط أبعاد الشريحة في بداية عملية إنشاء العرض لتجنب المشكلات.

{{% alert color="primary" %}} 
بشكل افتراضي، تستخدم العروض التي تم إنشاؤها باستخدام Aspose.Slides نسبة 4:3 القياسية.
{{% /alert %}}

## **تغيير حجم الشريحة في العروض**

يعرض هذا المثال البرمجي كيفية تغيير حجم الشريحة في عرض باستخدام JavaScript و Aspose.Slides:

```javascript
var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **تحديد أحجام شرائح مخصصة في العروض**

إذا وجدت أحجام الشرائح الشائعة (4:3 و 16:9) غير مناسبة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تنوي طباعة شرائح بالحجم الكامل من عرضك على تخطيط صفحة مخصص أو إذا كنت ترغب في عرض العرض على أنواع معينة من الشاشات، فمن المحتمل أن تستفيد من استخدام إعداد حجم مخصص لعرضك.

يعرض هذا المثال البرمجي كيفية استخدام Aspose.Slides للـ Node.js عبر Java لتحديد حجم شريحة مخصص لعرض في JavaScript:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// حجم ورق A4
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **التعامل مع المشكلات عند تغيير حجم الشرائح في العروض**

بعد تغيير حجم الشريحة لعرض ما، قد يتشوه محتوى الشرائح (مثل الصور أو الكائنات). بشكل افتراضي، يتم تغيير حجم الكائنات تلقائيًا لتتناسب مع الحجم الجديد للشريحة. ومع ذلك، عند تغيير حجم شريحة العرض، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتوى على الشرائح.

اعتمادًا على ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد تعديل حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا كنت ترغب في التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن يقوم Aspose.Slides بتقليل حجم كائنات الشرائح لضمان أن جميعها يتناسب داخل الشرائح (بهذه الطريقة، تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا كنت ترغب في التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن يقوم Aspose.Slides بتكبير كائنات الشرائح لجعلها متناسبة مع الحجم الجديد للشريحة، استخدم هذا الإعداد.

يعرض هذا المثال البرمجي كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة عرض:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **الأسئلة المتداولة**

**هل يمكنني تحديد حجم شريحة مخصص باستخدام وحدات غير البوصة (مثل النقاط أو الملليمترات)؟**

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث يساوي 1 نقطة 1/72 من البوصة. يمكنك تحويل أي وحدة (مثل الملليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحولة لتحديد عرض وارتفاع الشريحة.

**هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستهلاك الذاكرة أثناء التصيير؟**

نعم. الأبعاد الأكبر للشرائح (بالنقاط) مع معدل تصيير أعلى يؤدي إلى زيادة استهلاك الذاكرة ووقت معالجة أطول. استهدف حجم شريحة عملي وقم بضبط مقياس التصيير فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

**هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج شرائح من عروض تحتوي على أحجام مختلفة؟**

لا يمكنك [دمج العروض](/slides/ar/nodejs-java/merge-presentation/) عندما تكون لديها أحجام شرائح مختلفة — أولاً، قم بتغيير حجم أحد العروض لتطابق الآخر. عند تغيير حجم الشريحة، يمكنك اختيار كيفية معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/nodejs-java/aspose.slides/slidesizescaletype/). بعد توحيد الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

**هل يمكنني إنشاء صور مصغرة لأشكال فردية أو مناطق محددة من شريحة، وهل ستحترم حجم الشريحة الجديد؟**

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لـ [شرائح كاملة](https://reference.aspose.com/slides/ar/nodejs-java/aspose.slides/slide/#getImage) وكذلك لـ [الأشكال المختارة](https://reference.aspose.com/slides/ar/nodejs-java/aspose.slides/shape/#getImage). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة العرض إلى الارتفاع، مما يضمن إطارات وهندسة متسقة.
