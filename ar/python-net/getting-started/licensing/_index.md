## **نظرة عامة**

يمكن استخدام Aspose.Slides في وضع التقييم أو برخصة صالحة. يوفر إصدار التقييم نفس الوظائف كالإصدار المرخص، لكنه يضيف علامة مائية للتقييم إلى كل شريحة من كل عرض تقديمي يتم حفظه ويقصر النص الذي يقرأه شفرتك من العروض التقديمية.

## **تقييم Aspose.Slides**

يمكنك تنزيل إصدار التقييم من **Aspose.Slides for Python via .NET** من [صفحة التنزيل](https://pypi.org/project/Aspose.Slides/). يوفر إصدار التقييم نفس الميزات كالمنتج المرخص. حزمة التقييم هي نفسها حزمة الشراء وتصبح مرخصة بعد أن تضيف بضع أسطر من الشيفرة لتطبيق الترخيص.

عند رضاك عن تقييمك لـ **Aspose.Slides**، يمكنك [شراء ترخيص](https://purchase.aspose.com/pricing/slides/python-net/). نوصي بمراجعة خيارات الاشتراك المتاحة. إذا كان لديك أسئلة، اتصل بفريق مبيعات Aspose.

كل ترخيص Aspose يشمل اشتراكًا لمدة سنة واحدة مع ترقيات مجانية إلى الإصدارات الجديدة وإصلاحات صادرة خلال تلك الفترة. يحصل كلٌ من المستخدمين المرخصين ومستخدمي التقييم على دعم فني مجاني غير محدود.

**قيود إصدار التقييم**

* إصدار التقييم (عند عدم تطبيق ترخيص) يوفر كافة الوظائف، لكنه يضيف مربع نص علامة مائية للتقييم إلى كل شريحة من كل عرض تقديمي يتم حفظه.
* النص الذي تقرأه الشفرة من عرض تقديمي يُقَص إلى أول بضعة أحرف، متبوعًا بإشارة إلى قيود التقييم. النص الذي تكتبُه الشفرة يُحفظ بالكامل.

## **الترخيص في Aspose.Slides**

* يصبح إصدار التقييم مرخصًا بعد شراء ترخيص وإضافة بضع أسطر من الشيفرة لتطبيقه.
* الترخيص هو ملف XML نص عادي يحتوي على تفاصيل مثل اسم المنتج، عدد المطورين الذين يغطيهم، تاريخ انتهاء الاشتراك، وما إلى ذلك.
* ملف الترخيص موقع رقميًا، لذا لا يجب تعديلّه. حتى إضافة سطر جديد واحد سيجعله غير صالح.
* يبحث Aspose.Slides for Python via .NET عن الترخيص في المسار الذي تمرره إليه. المسار النسبي أو اسم الملف بدون مسار يتم حله بالنسبة إلى دليل العمل الحالي، والذي قد لا يكون بالضرورة المجلد الذي يحتوي على سكريبت Python الخاص بك.
* لتجنب قيود التقييم، قم بتعيين الترخيص قبل استخدام Aspose.Slides. تحتاج إلى تعيينه مرة واحدة فقط لكل تطبيق أو عملية.

## **تطبيق الترخيص**

يمكن تحميل الترخيص من **ملف** أو **تيار**.

{{% alert color="info" title="Note" %}}
يوفر Aspose.Slides فئة [License](https://reference.aspose.com/slides/python-net/aspose.slides/license/) للتعامل مع الترخيص.
{{% /alert %}}

{{% alert color="warning" title="Warning" %}}
يمكن للتراخيص الجديدة تنشيط Aspose.Slides فقط مع الإصدار 21.4 أو أحدث. الإصدارات الأسبق تستخدم نظام ترخيص مختلف ولن تتعرف على هذه التراخيص.
{{% /alert %}}

### **ملف**

أبسط طريقة لتعيين الترخيص هي تمرير مسار ملف الترخيص إلى طريقة [set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/). إذا قمت بتمرير اسم الملف فقط، كما في المثال أدناه، يبحث Aspose.Slides عن الملف في دليل العمل الحالي.

الكود التالي بلغة Python يوضح كيفية تعيين ملف الترخيص:

```py
import aspose.slides as slides

# ينشئ فئة الترخيص. 
license = slides.License()

# يضبط مسار ملف الترخيص. 
license.set_license("Aspose.Slides.lic")
```

{{% alert color="warning" title="Warning" %}}
إذا وضعت ملف الترخيص في دليل مختلف، عند استدعاء [License.set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/#str)، يجب أن يتطابق اسم الملف في نهاية المسار الصريح مع اسم ملف الترخيص الخاص بك.

على سبيل المثال، يمكنك إعادة تسمية ملف الترخيص إلى *Aspose.Slides.lic.xml*. ثم، في الشفرة الخاصة بك، مرّر المسار الكامل إلى ذلك الملف (الذي ينتهي بـ Aspose.Slides.lic.xml) إلى طريقة [License.set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/#str).
{{% /alert %}}

### **تيار**

يمكنك تحميل ترخيص من تيار. المثال التالي بلغة Python يوضح كيفية تطبيق ترخيص من تيار:

```py
import aspose.slides as slides

# ينشئ فئة الترخيص.
license = slides.License()

# تعيين الترخيص من تيار.
with open("Aspose.Slides.lic", "rb") as stream:
    license.set_license(stream)
```

## **التحقق من الترخيص**

للتحقق من أن الترخيص قد تم تطبيقه بشكل صحيح، يمكنك التحقق منه. الكود التالي بلغة Python يوضح كيفية التحقق من ترخيص:

```py
import aspose.slides as slides

license = slides.License()

license.set_license("Aspose.Slides.lic")

if license.is_licensed():
    print("License is good!")
```

## **سلامة الخيوط**

{{% alert color="warning" title="Warning" %}}
طريقة [License.set_license](https://reference.aspose.com/slides/python-net/aspose.slides/license/set_license/) ليست آمنة لاستخدامها عبر خيوط متعددة. إذا كنت تحتاج إلى استدعائها بشكل متزامن من عدة خيوط، استخدم عنصر مزامنة، مثل `threading.Lock`، لتجنب المشكلات.
{{% /alert %}}

## **الأسئلة الشائعة**

### هل يمكنني تطبيق الترخيص في بيئة بالكامل دون اتصال (بدون وصول إلى الإنترنت)؟

نعم. يتم التحقق من الترخيص محليًا باستخدام ملف الترخيص؛ لا يلزم اتصال بالإنترنت.

### ماذا يحدث بعد انتهاء الاشتراك السنوي؟ هل سيتوقف المكتبة عن العمل؟

لا. الترخيص دائم: يمكنك الاستمرار في استخدام الإصدارات التي صُدرت قبل تاريخ انتهاء اشتراكك؛ فقط لن تكون مؤهلاً لاستخدام الإصدارات الأحدث دون التجديد.
