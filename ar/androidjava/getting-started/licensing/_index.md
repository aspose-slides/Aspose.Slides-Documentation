## **نظرة عامة**

يمكن استخدام Aspose.Slides في وضع التقييم أو باستخدام ترخيص صالح. يوفر الإصدار التجريبي نفس وظائف الإصدار المرخص، لكنه يضيف علامة مائية تقييمية عند فتح أو حفظ العروض التقديمية ويقيد استخراج النص بشرائح واحدة.

تشرح هذه المقالة كيفية عمل الترخيص في Aspose.Slides وكيفية تطبيق ترخيص قبل استخدام المكتبة. يمكن تحميل الترخيص من ملف أو تدفق أو مورد مدمج باستخدام الفئة `License`. تُظهر المقالة أيضًا كيفية التحقق من تطبيق الترخيص بشكل صحيح.

## **الترخيص في Aspose.Slides**

* تصبح النسخة التجريبية مرخصة بعد شراء الترخيص وإضافة بضع أسطر من الشيفرة لتطبيق الترخيص.
* الترخيص هو ملف XML نصي بسيط يحتوي على تفاصيل مثل اسم المنتج، عدد المطورين المسموح لهم باستخدامه، تاريخ انتهاء الاشتراك، وهكذا. 
* ملف الترخيص موقع رقمياً، لذا يجب عدم تعديل الملف. حتى إضافة سطر فارغ غير مقصودة إلى محتويات الملف سيجعله غير صالح.
* عادةً ما يحاول Aspose.Slides for Android via Java العثور على الترخيص في المواقع التالية:
  * مسار صريح
  * المجلد الذي يحتوي على Aspose.Slides.jar
* لتجنب القيود المرتبطة بالنسخة التجريبية، تحتاج إلى تعيين ترخيص قبل استخدام **Aspose.Slides**. يكفي تعيين الترخيص مرة واحدة لكل تطبيق أو عملية.

## **تطبيق ترخيص**

يمكن تحميل الترخيص من **ملف** أو **تدفق**.

{{% alert color="info" %}}

يوفر Aspose.Slides الفئة [License](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/license/) لعمليات الترخيص.

{{% /alert %}} 

{{% alert color="warning" %}}

يمكن للتراخيص الجديدة تفعيل Aspose.Slides فقط مع الإصدار 21.4 أو الأحدث. الإصدارات السابقة تستخدم نظام ترخيص مختلف ولن تتعرف على هذه التراخيص.

{{% /alert %}}

### **ملف**

أسهل طريقة لتعيين ترخيص هي وضع ملف الترخيص في المجلد الذي يحتوي على Aspose.Slides.jar أو jar الخاص بتطبيقك.

يظهر هذا الشيفرة في Java كيفية تعيين ملف ترخيص:

``` java
// يُنشئ فئة License
com.aspose.slides.License license = new com.aspose.slides.License();

// يحدد مسار ملف الترخيص
license.setLicense("Aspose.Slides.Android.via.Java.lic");
```

{{% alert color="warning" %}} 

إذا وضعت ملف الترخيص في دليل مختلف، عند استدعاء طريقة [SetLicense](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-)، يجب أن يكون اسم ملف الترخيص في نهاية المسار الصريح المحدد هو نفسه اسم ملف الترخيص لديك.

على سبيل المثال، يمكنك تغيير اسم ملف الترخيص إلى *Aspose.Slides.Android.via.Java.lic.xml*. ثم، في شيفرتك، عليك تمرير المسار إلى الملف (الذي ينتهي بـ *Aspose.Slides.Android.via.Java.lic.xml*) إلى طريقة [SetLicense](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-).

{{% /alert %}}

### **تدفق**

يمكنك تحميل ترخيص من تدفق. يوضح هذا الشيفرة في Java كيفية تطبيق ترخيص من تدفق:

``` java
// ينشئ فئة License
com.aspose.slides.License license = new com.aspose.slides.License();

// يضبط الترخيص عبر تدفق
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Android.via.Java.lic"));
```

## **التحقق من صحة الترخيص**

للتحقق مما إذا تم تعيين الترخيص بشكل صحيح، يمكنك التحقق منه. يوضح هذا الشيفرة في Java كيفية التحقق من الترخيص:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Android.via.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **سلامة الخيوط**

{{% alert title="Note" color="warning" %}} 

طريقة [SetLicense](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/license/#setLicense-java.io.InputStream-) غير آمنة في بيئة متعددة الخيوط. إذا كان يجب استدعاء هذه الطريقة في آنٍ واحد من عدة خيوط، قد ترغب في استخدام آليات التزامن (مثل القفل) لتجنب المشاكل. 

{{% /alert %}}

## **الأسئلة المتداولة**

### هل يمكنني تطبيق الترخيص في بيئة غير متصلة بالإنترنت تمامًا (بدون وصول إلى الإنترنت)؟

نعم. يتم التحقق من الترخيص محليًا باستخدام ملف الترخيص؛ لا يلزم اتصال بالإنترنت.

### ماذا يحدث بعد انتهاء الاشتراك لمدة سنة واحدة؟ هل ستتوقف المكتبة عن العمل؟

لا. الترخيص دائم: يمكنك الاستمرار في استخدام الإصدارات الصادرة قبل تاريخ انتهاء اشتراكك؛ فقط لن تكون مؤهلاً لاستخدام الإصدارات الأحدث دون تجديد.
