## **المقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة العرض إلى الارتفاع في عروض PowerPoint التقديمية، وهو أمر حاسم لكل من الطباعة والعرض على الشاشة.

أحجام الشرائح الشائعة والنسب:

- **قياسي (نسبة 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **عريض (نسبة 16:9)**: يوصى به لأجهزة العرض والشاشات الحديثة.

احرص على التناسق في جميع أنحاء العرض التقديمي حيث يُطبق حجم الشريحة ونسبة العرض إلى الارتفاع الواحد على جميع الشرائح. للحصول على أفضل النتائج، قم بتعيين أبعاد الشريحة في بداية عملية إنشاء العرض التقديمي لتجنب التعقيدات.

{{% alert color="info" title="Note" %}}
بشكل افتراضي، تستخدم العروض التقديمية التي يتم إنشاؤها باستخدام Aspose.Slides نسبة 4:3 القياسية.
{{% /alert %}}

لصفحات الملاحظات وملفات التوزيع أبعاد منفصلة عن الشرائح العادية. راجع [Notes Page Size](/slides/ar/androidjava/notes-size/) لتغيير حجمها وتوجيهها.

## **تغيير حجم الشريحة في العروض التقديمية**

 يوضح لك هذا المثال البرمجي كيفية تغيير حجم الشريحة في عرض تقديمي في Java باستخدام Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **تحديد أحجام شرائح مخصصة في العروض التقديمية**

إذا وجدت أن أحجام الشرائح الشائعة (4:3 و 16:9) غير مناسبة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بالحجم الكامل من عرضك التقديمي على تخطيط صفحة مخصص أو إذا كنت تريد عرض عرضك على أنواع شاشات معينة، فمن المحتمل أن تستفيد من إعداد حجم مخصص للعرض التقديمي.

يوضح لك هذا المثال البرمجي كيفية استخدام Aspose.Slides for Android عبر Java لتحديد حجم شريحة مخصص لعرض تقديمي في Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // حجم ورق A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد تغيير حجم الشريحة لعرض تقديمي، قد يتشوه محتوى الشرائح (مثل الصور أو الكائنات). بشكل افتراضي، يتم تعديل حجم الكائنات تلقائيًا لتناسب حجم الشريحة الجديد. ومع ذلك، عند تغيير حجم شريحة العرض التقديمي، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتوى على الشرائح.

اعتمادًا على ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد تعديل حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا كنت تريد التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن تقوم Aspose.Slides بتقليص كائنات الشرائح لضمان احتوائها جميعًا على الشرائح (وبذلك تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا كنت تريد التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن تقوم Aspose.Slides بتكبير كائنات الشرائح لتصبح متناسبة مع حجم الشريحة الجديد، استخدم هذا الإعداد.

يوضح لك هذا المثال البرمجي كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة عرض تقديمي:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **الأسئلة المتكررة**

**هل يمكنني تعيين حجم شريحة مخصص باستخدام وحدات غير الإنش (على سبيل المثال، نقاط أو ملليمترات)؟**

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث يساوي النقطة الواحدة 1/72 من الإنش. يمكنك تحويل أي وحدة (مثل الملليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحوّلة لتحديد عرض وارتفاع الشريحة.

**هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستهلاك الذاكرة أثناء التصيير؟**

نعم. تؤدي أبعاد الشرائح الأكبر (بالنقاط) مع مقياس تصيير أعلى إلى زيادة استهلاك الذاكرة وإطالة أوقات المعالجة. استهدف حجم شريحة عملي واضبط مقياس التصيير فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

**هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج شرائح من عروض تقديمية ذات أحجام مختلفة؟**

لا يمكنك [دمج العروض التقديمية](/slides/ar/androidjava/merge-presentation/) بينما لها أحجام شرائح مختلفة — أولاً، قم بتغيير حجم أحد العروض لمطابقة الآخر. عند تغيير حجم الشريحة، يمكنك اختيار طريقة معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/slidesizescaletype/). بعد توحيد الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

**هل يمكنني إنشاء صور مصغرة لأشكال فردية أو مناطق محددة من الشريحة، وهل ستحترم الحجم الجديد للشريحة؟**

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لل[الشرائح الكاملة](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) وكذلك لل[الأشكال المحددة](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/shape/#getImage-int-float-float-). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة العرض إلى الارتفاع، مما يضمن تأطيرًا وجيومتريًا متسقًا.
