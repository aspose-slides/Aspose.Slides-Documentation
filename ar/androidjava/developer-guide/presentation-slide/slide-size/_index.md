## **المقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة الأبعاد في عروض PowerPoint، وهو أمر حاسم لكل من الطباعة والعرض على الشاشة.

الأحجام الشائعة للشرائح والنسب:

- **قياسي (نسبة 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **شاشة عريضة (نسبة 16:9)**: يوصى به لأجهزة العرض الحديثة والشاشات.

احرص على التناسق في جميع أجزاء العرض الخاص بك حيث يُطبق حجم الشريحة ونسبة الأبعاد الواحدة على جميع الشرائح. لتحقيق أفضل النتائج، حدد أبعاد الشريحة في بداية عملية إنشاء العرض لتجنب التعقيدات.

{{% alert color="info" %}} 
بشكل افتراضي، العروض التي يتم إنشاؤها باستخدام Aspose.Slides تستخدم نسبة 4:3 القياسية.
{{% /alert %}}

## **تغيير حجم الشريحة في العروض**

 يوضح لك هذا المثال البرمجي كيفية تغيير حجم الشريحة في عرض باستخدام Java وAspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **تحديد أحجام شرائح مخصصة في العروض**

إذا وجدت الأحجام الشائعة للشرائح (4:3 و 16:9) غير مناسبة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بالحجم الكامل من العرض الخاص بك على تنسيق صفحة مخصص أو إذا كنت تنوي عرض العرض على أنواع معينة من الشاشات، قد تستفيد من ضبط حجم مخصص للعرض.

يظهر لك هذا المثال البرمجي كيفية استخدام Aspose.Slides for Android عبر Java لتحديد حجم شريحة مخصص لعرض باستخدام Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // حجم ورق A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد تغيير حجم الشريحة في عرض ما، قد يصبح محتوى الشرائح (مثل الصور أو الكائنات) مشوهًا. بشكل افتراضي، يتم تعديل حجم الكائنات تلقائيًا لتتناسب مع الحجم الجديد للشريحة. ومع ذلك، عند تغيير حجم شريحة العرض، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتوى على الشرائح.

اعتمادًا على ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد أن يتم تعديل حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا كنت تريد التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن يقوم Aspose.Slides بتقليل حجم كائنات الشرائح لضمان أن جميعها تتناسب داخل الشرائح (بهذه الطريقة، تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا كنت تريد التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن يقوم Aspose.Slides بتكبير كائنات الشرائح لجعلها متناسبة مع الحجم الجديد للشريحة، استخدم هذا الإعداد.

يظهر لك هذا المثال البرمجي كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة العرض:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **الأسئلة الشائعة**

### هل يمكنني ضبط حجم شريحة مخصص باستخدام وحدات غير البوصة (مثلاً، نقاط أو ملليمترات)؟

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث إن النقطة الواحدة تساوي 1/72 من البوصة. يمكنك تحويل أي وحدة (مثل الملليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحولة لتحديد عرض وارتفاع الشريحة.

### هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستهلاك الذاكرة أثناء التصيير؟

نعم. الأبعاد الأكبر للشرائح (بالنقاط) مع مقياس تصيير أعلى تؤدي إلى زيادة استهلاك الذاكرة ووقت المعالجة. استهدف حجم شريحة عملي وقم بتعديل مقياس التصيير فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

### هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج شرائح من عروض ذات أحجام مختلفة؟

لا يمكنك [دمج العروض](/slides/ar/androidjava/merge-presentation/) بينما لديها أحجام شرائح مختلفة — أولاً، قم بتغيير حجم أحد العروض لتطابق الآخر. عند تغيير حجم الشريحة، يمكنك اختيار طريقة التعامل مع المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/slidesizescaletype/). بعد مطابقة الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

### هل يمكنني إنشاء صور مصغرة لأشكال فردية أو مناطق محددة من شريحة، وهل ستحترم الحجم الجديد للشريحة؟

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لل[الشرائح بالكامل](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) وكذلك لل[الأشكال المحددة](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/shape/#getImage-int-float-float-). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة الأبعاد، مما يضمن تأطيرًا وتناسقًا هندسيًا ثابتًا.
