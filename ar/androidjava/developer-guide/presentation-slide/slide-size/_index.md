## **المقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة العرض إلى الارتفاع في عروض PowerPoint التقديمية، وهي أمر حيوي لكل من الطباعة والعرض على الشاشة.

أحجام ونسب الشرائح الشائعة:

- **Standard (نسبة العرض إلى الارتفاع 4:3)**: مثالية للشاشات والأجهزة القديمة.
- **Widescreen (نسبة العرض إلى الارتفاع 16:9)**: يوصى بها لأجهزة العرض الحديثة والشاشات.

تأكد من الحفاظ على التناسق طوال العرض التقديمي حيث يتم تطبيق حجم وشريحة واحدة ونسبة عرض إلى ارتفاع واحدة على جميع الشرائح. للحصول على أفضل النتائج، اضبط أبعاد الشريحة في بداية عملية إنشاء العرض التقديمي لتجنب المشكلات.

{{% alert color="primary" %}} 
بشكل افتراضي، تستخدم العروض التقديمية التي تم إنشاؤها باستخدام Aspose.Slides نسبة 4:3 القياسية.
{{% /alert %}}

## **تغيير حجم الشريحة في العروض التقديمية**

يعرض لك هذا المثال البرمجي كيفية تغيير حجم الشريحة في عرض تقديمي باستخدام Java و Aspose.Slides:

```java
Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **تحديد أحجام شرائح مخصصة في العروض التقديمية**

إذا وجدت أحجام الشرائح الشائعة (4:3 و 16:9) غير مناسبة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بالحجم الكامل من عرضك التقديمي على تخطيط صفحة مخصص أو إذا كنت تنوي عرض عرضك على أنواع معينة من الشاشات، فمن المحتمل أن تستفيد من إعداد حجم مخصص لعرضك.

يعرض لك هذا المثال البرمجي كيفية استخدام Aspose.Slides for Android عبر Java لتحديد حجم شريحة مخصص لعرض تقديمي في Java:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // حجم ورق A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد تغيير حجم الشريحة في عرض تقديمي، قد تصبح محتويات الشرائح (مثل الصور أو الكائنات) مشوهة. بشكل افتراضي، يتم تغيير حجم الكائنات تلقائيًا لتتناسب مع الحجم الجديد للشريحة. ومع ذلك، عند تغيير حجم شريحة العرض التقديمي، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتويات على الشرائح.

اعتمادًا على ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`
  
  إذا كنت لا تريد أن يتم تغيير حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`
  
  إذا كنت تريد التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن تقوم Aspose.Slides بتصغير كائنات الشرائح لضمان أن كلها تتناسب مع الشرائح (بهذه الطريقة، تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`
  
  إذا كنت تريد التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن تقوم Aspose.Slides بتكبير كائنات الشرائح لجعلها متناسبة مع الحجم الجديد للشريحة، استخدم هذا الإعداد.

يعرض لك هذا المثال البرمجي كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة العرض التقديمي:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **الأسئلة الشائعة**

**هل يمكنني ضبط حجم شريحة مخصص باستخدام وحدات غير البوصة (مثلاً النقاط أو المليمترات)؟**

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث يساوي 1 نقطة 1/72 بوصة. يمكنك تحويل أي وحدة (مثل المليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحولة لتحديد عرض وارتفاع الشريحة.

**هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستهلاك الذاكرة أثناء العرض؟**

نعم. الأبعاد الكبيرة للشرائح (بالنقاط) مع مقياس عرض أعلى تؤدي إلى زيادة استهلاك الذاكرة وزمن معالجة أطول. استهدف حجم شريحة عملي وقم بضبط مقياس العرض فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

**هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج الشرائح من عروض تقديمية ذات أحجام مختلفة؟**

لا يمكنك [دمج العروض التقديمية](/slides/ar/androidjava/merge-presentation/) بينما لديها أحجام شرائح مختلفة — أولاً، أعد ضبط حجم عرض تقديمي لتطابق الآخر. عند تغيير حجم الشريحة، يمكنك اختيار كيفية معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/slidesizescaletype/). بعد توحيد الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

**هل يمكنني إنشاء صور مصغرة لأشكال فردية أو مناطق محددة من شريحة، وهل ستحترم حجم الشريحة الجديد؟**

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لـ [الشرائح الكاملة](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) وكذلك لـ [الأشكال المحددة](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/shape/#getImage-int-float-float-). الصور الناتجة تعكس حجم الشريحة الحالي ونسبة العرض إلى الارتفاع، مما يضمن إطارًا وتنسيقًا ثابتًا.
