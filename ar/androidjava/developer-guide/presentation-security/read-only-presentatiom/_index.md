## **مقدمة**

في PowerPoint 2019، قدمت Microsoft إعداد **فتح دائم للقراءة فقط** كأحد الخيارات التي يمكن للمستخدمين استخدامها لحماية عروضهم التقديمية. قد ترغب في استخدام هذا الإعداد للقراءة فقط لحماية عرض تقديمي عندما

- تريد منع التعديلات غير المقصودة والحفاظ على محتوى العرض التقديمي آمنًا. 
- تريد إبلاغ الأشخاص بأن العرض التقديمي الذي قدمته هو النسخة النهائية. 

بعد اختيارك لخيار **فتح دائم للقراءة فقط** لعروض تقديمي، عندما يفتح المستخدمون العرض، يرون توصية **القراءة فقط** وقد يرون رسالة بهذا الشكل: *لمنع التغييرات غير المقصودة، قام المؤلف بتعيين هذا الملف للفتح كقراءة فقط.*

توصية القراءة فقط هي آلية بسيطة لكنها فعّالة تُثني عن التحرير لأن المستخدمين يجب أن يقوموا بعملية لإزالتها قبل أن يُسمح لهم بتعديل العرض. إذا كنت لا تريد أن يقوم المستخدمون بإجراء تغييرات على العرض وترغب بإخبارهم بذلك بطريقة مهذبة، فإن توصية القراءة فقط قد تكون خيارًا جيدًا لك. 

> إذا تم فتح عرض تقديمي محمي بـ **القراءة فقط** في نسخة أقدم من Microsoft PowerPoint — التي لا تدعم هذه الميزة الحديثة — يتم تجاهل توصية **القراءة فقط** (يُفتح العرض بصورة عادية).

## **تطبيق وضع القراءة فقط**

تتيح لك Aspose.Slides for Android via Java تعيين عرض تقديمي إلى **القراءة فقط**، مما يعني أن المستخدمين (بعد فتحهم للعرض) سيظهر لهم توصية **القراءة فقط**. يوضح لك هذا الكود النموذجي كيفية تعيين عرض تقديمي إلى **القراءة فقط** في Java باستخدام Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 

**ملاحظة**: توصية **القراءة فقط** تهدف ببساطة إلى تثبيط التحرير أو منع المستخدمين من إجراء تغييرات غير مقصودة على عرض PowerPoint. إذا قرر شخص متمكن—يعرف ما يفعله—تحرير عرضك، يمكنه بسهولة إزالة إعداد القراءة فقط. إذا كنت بحاجة فعليًا لمنع التحرير غير المصرح به، فقد يكون من الأفضل استخدام [حمايات أكثر صرامة تتضمن التشفير وكلمات المرور](https://docs.aspose.com/slides/ar/androidjava/password-protected-presentation/). 

{{% /alert %}} 

## **الأسئلة المتكررة**

### كيف يختلف «التوصية بالقراءة فقط» عن الحماية بكلمة مرور كاملة؟

«التوصية بالقراءة فقط» تعرض مجرد اقتراح لفتح الملف في وضع القراءة فقط ويسهل تجاوزه. [حماية كلمة المرور](/slides/ar/androidjava/password-protected-presentation/) تقيد الفتح أو التحرير فعليًا وتناسب الحالات التي تحتاج فيها إلى تحكم أمان حقيقي.

### هل يمكن دمج «التوصية بالقراءة فقط» مع العلامات المائية لتثبيط التعديلات أكثر؟

نعم. يمكن إقران التوصية مع [العلامات المائية](/slides/ar/androidjava/watermark/) كوسيلة بصرية للردع؛ هما آليتان منفصلتان وتعملان معًا بشكل جيد.

### هل لا يزال بإمكان ماكرو أو أداة خارجية تعديل الملف عندما تكون التوصية مفعلة؟

نعم. التوصية لا تمنع التغييرات البرمجية. لمنع التعديلات الآلية، استخدم [كلمات المرور والتشفير](/slides/ar/androidjava/password-protected-presentation/).

### كيف يرتبط «التوصية بالقراءة فقط» بالطرق «isEncrypted» و«isWriteProtected»؟

هما إشارتان مختلفتان. «التوصية بالقراءة فقط» هي مطالبة ناعمة اختيارية؛ [isWriteProtected](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/protectionmanager/#isWriteProtected--) و[isEncrypted](https://reference.aspose.com/slides/ar/androidjava/com.aspose.slides/protectionmanager/#isEncrypted--) تشير إلى قيود كتابة أو قراءة فعلية تعتمد على كلمات مرور أو تشفير.
