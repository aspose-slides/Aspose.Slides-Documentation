{{% alert color="info" %}}

Aspose.Slides for Android via Java هي مكتبة فئة تمكّن تطبيقات Java لنظام Android من قراءة وكتابة مستندات العروض التقديمية دون الحاجة إلى Microsoft PowerPoint® أو أي برنامج آخر. تتيح لك Aspose.Slides for Android via Java إدارة النصوص والأشكال والجداول والرسوم المتحركة؛ إضافة ملفات صوتية وفيديو إلى الشرائح؛ معاينة الشرائح؛ وتصدير الشرائح إلى SVG، وصيغة PDF، والمزيد.

يمكن العثور على أحدث مرجع API في [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/ar/androidjava/).

{{% /alert %}}
