**مرحبًا بكم في Aspose.Slides for .NET**

![شعار منتج Aspose.Slides for .NET](home_1.png)

Aspose.Slides for .NET هو واجهة برمجة تطبيقات لإدارة Microsoft PowerPoint® تتيح لتطبيقات .NET قراءة وكتابة مستندات PowerPoint® دون الحاجة إلى استخدام Microsoft PowerPoint®.

Aspose.Slides for .NET هو أول مكوّن وحيد يقدم الوظائف اللازمة لإدارة مستندات PowerPoint®.

Aspose.Slides for .NET يقدم الكثير من الميزات الرئيسية مثل إدارة النصوص، الأشكال، الجداول والرسوم المتحركة، إضافة الصوت والفيديو إلى الشرائح، معاينة الشرائح، تصدير الشرائح إلى SVG و PDF وتنسيقات مختلفة، والعديد من القدرات الأخرى.
