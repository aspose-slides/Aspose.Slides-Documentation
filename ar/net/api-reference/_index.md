{{% alert color="info" %}} 

Aspose.Slides for .NET هو مكتبة فئات تمكّن تطبيقات .NET من قراءة وكتابة مستندات العروض التقديمية دون الحاجة إلى Microsoft PowerPoint® أو غيرها. يسمح Aspose.Slides for .NET بإدارة النصوص، الأشكال، الجداول والرسوم المتحركة، إضافة الصوت والفيديو إلى الشرائح، معاينة الشرائح، تصدير الشرائح إلى صيغة SVG، PDF والمزيد.

يمكن العثور على أحدث مرجع API في [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/ar/net).

{{% /alert %}}
