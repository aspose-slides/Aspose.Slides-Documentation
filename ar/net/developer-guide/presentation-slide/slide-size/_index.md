## **المقدمة**

توفر Aspose.Slides for .NET أدوات شاملة لضبط حجم الشريحة ونسبة العرض إلى الارتفاع في عروض PowerPoint التقديمية، وهو أمر حاسم لكل من الطباعة والعرض على الشاشة.

الأحجام والنسب الشائعة للشرائح:

- **قياسي (نسبة عرض إلى ارتفاع 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **عريض (نسبة عرض إلى ارتفاع 16:9)**: يُنصح به لأجهزة العرض والشاشات الحديثة.

تأكد من الاتساق في جميع أنحاء عرضك التقديمي حيث يُطبق حجم شريحة واحد ونسبة عرض إلى ارتفاع واحدة على جميع الشرائح. للحصول على نتائج مثالية، اضبط أبعاد الشريحة في بداية عملية إنشاء العرض التقديمي لتجنب المشكلات.

{{% alert color="info" %}} 
افتراضيًا، تستخدم العروض التقديمية التي تم إنشاؤها باستخدام Aspose.Slides نسبة 4:3 القياسية.
{{% /alert %}}

لصفحات الملاحظات والنشرات أبعاد منفصلة عن الشرائح العادية. اطلع على [حجم صفحة الملاحظات](/slides/ar/net/notes-size/) لتغيير حجمها واتجاهها.

## **كيفية تغيير حجم الشريحة في عرض تقديمي**

يوضح هذا المثال كيفية تغيير حجم شريحة العرض التقديمي باستخدام Aspose.Slides في C#:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **تحديد أحجام شرائح مخصصة**

تخصيص حجم الشريحة وفقًا لاحتياجاتك الخاصة، مثل تنسيقات الورق الفريدة أو مواصفات الشاشات، يمكن أن يكون مفيدًا. إليك كيفية ضبط حجم شريحة مخصص باستخدام Aspose.Slides for .NET:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // حجم ورق A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **معالجة محتوى الشريحة بعد إعادة التحجيم**

بعد إعادة التحجيم، قد يتشوه محتوى الشريحة. يمكنك التحكم في طريقة إدارة Aspose.Slides لهذا التحجيم:

- **`DoNotScale`**: إبقاء الكائنات بحجمها الأصلي لتجنب التحجيم.
- **`EnsureFit`**: تحجيم الكائنات لتناسب الشرائح الأصغر، مما يمنع فقدان المحتوى.
- **`Maximize`**: تكبير الكائنات لتناسب الشرائح الأكبر للحصول على اتساق جمالي.

مثال على استخدام إعداد `Maximize` لضبط حجم الشريحة:

```csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **الأسئلة المتكررة**

### هل يمكنني ضبط حجم شريحة مخصص باستخدام وحدات غير البوصة (مثلاً، نقاط أو ملليمترات)؟

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث يعادل 1 نقطة 1/72 من البوصة. يمكنك تحويل أي وحدة (مثل الملليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحولة لتحديد عرض وارتفاع الشريحة.

### هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستخدام الذاكرة أثناء التصيير؟

نعم. تؤدي أبعاد الشرائح الكبيرة (بالنقاط) مع مقياس تصيير أعلى إلى زيادة استهلاك الذاكرة وطول أوقات المعالجة. استهدف حجم شريحة عملي وقم بتعديل مقياس التصيير فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

### هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج شرائح من عروض تقديمية بأحجام مختلفة؟

لا يمكنك [دمج العروض التقديمية](/slides/ar/net/merge-presentation/) أثناء امتلاكها لأحجام شرائح مختلفة — عليك أولاً تعديل حجم أحد العروض ليتطابق مع الآخر. عند تغيير حجم الشريحة، يمكنك اختيار طريقة معالجة المحتوى الحالي عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/net/aspose.slides/slidesizescaletype/). بعد مواءمة الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

### هل يمكنني إنشاء صور مصغرة للأشكال الفردية أو مناطق محددة من الشريحة، وهل ستحترم حجم الشريحة الجديد؟

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لـ [الشرائح الكاملة](https://reference.aspose.com/slides/ar/net/aspose.slides/slide/getimage/) وكذلك لـ [الأشكال المحددة](https://reference.aspose.com/slides/ar/net/aspose.slides/shape/getimage/). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة العرض إلى الارتفاع، مما يضمن تأطيرًا وتكوينًا متسقًا.
