## **نظرة عامة**

تشرح هذه المقالة متى قد يختار المطورون Open XML SDK أو Aspose.Slides للعمل مع مستندات العروض التقديمية. تصف Open XML SDK بأنها مكتبة لتلاعب حزم OOXML وعناصر XML الأساسية الخاصة بها، بينما تُقدم Aspose.Slides كمكتبة معالجة عروض تقديمية بنموذج كائن عالي المستوى ودعم للعديد من المهام المتعلقة بـ PowerPoint.

تقارن المقالة بين الخيارين من حيث التنسيقات المدعومة، نموذج البرمجة، قدرات العرض والطباعة، دعم المنصات، وحالات الاستخدام الشائعة. كما توضح أن Open XML SDK قد تكون مناسبة للعمليات الأساسية على PPTX أو للوصول المباشر إلى عناصر OOXML، بينما Aspose.Slides أكثر ملاءمة للمهام المعقدة مثل العمل مع تنسيقات PowerPoint المتعددة، نسخ أو استنساخ الأشكال، استبدال النص، تطبيق الرسوم المتحركة، وتحويل العروض إلى PDF أو TIFF أو XPS.

## **ما هو Open XML SDK؟**
أحيانًا نتلقى هذا السؤال: *لماذا نستخدم منتجات Aspose بدلًا من Open XML SDK المجاني؟*

نجد أن الإجابة على هذا السؤال سهلة من حيث المميزات والوظائف.

وفقًا لـ [مكتبة MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، يُعرّف Open XML SDK على النحو التالي:

> "يبسط Open XML SDK 2.0 مهمة التلاعب بحزم Open XML وعناصر مخطط Open XML الأساسية داخل الحزمة. يضمّن Open XML SDK 2.0 العديد من المهام الشائعة التي ينفذها المطورون على حزم Open XML، بحيث يمكنك إجراء عمليات معقدة ببضع أسطر من الشيفرة فقط. مستندات OOXML هي في الأساس ملفات XML مضغوطة، وOpen XML SDK هو مجموعة من الفئات التي تسمح لك بالعمل مع محتوى مستندات OOXML بطريقة ذات نوع قوي. هذا بدلاً من فك ضغط ملف لاستخراج XML، تحميل ذلك XML إلى شجرة DOM، والعمل مباشرةً مع عناصر وسمات XML؛ حيث يوفر Open XML SDK فئات للقيام بذلك."

## **ما هو Aspose.Slides؟**
Aspose.Slides هي مكتبة فئات تتيح للتطبيقات تنفيذ مهام معالجة العروض التقديمية التالية:

- البرمجة باستخدام نموذج كائن العرض التقديمي.
- تحويلات عالية الجودة تشمل جميع تنسيقات PowerPoint المدعومة، بما في ذلك التحويل إلى PDF وXPS وTIFF والطباعة.
- إنشاء صور مصغرة للشرائح بتنسيقات معروفة مثل PNG وJPEG وBMP إلى جانب تصدير الشرائح إلى SVG.
- بناء عروض تقديمية من الصفر أو بدمج عناصر من مستند واحد أو عدة مستندات.
- إضافة الرسوم المتحركة، إطارات OLE، الجداول، إنشاء وإدارة المخططات.
- التحكم (تحكم شامل) وإدارة تنسيق النص على مستويات TextFrames وParagraphs وPortions.

  لمزيد من التفاصيل حول الميزات المتاحة، يرجى زيارة صفحة [ميزات Aspose.Slides](/slides/ar/net/product-overview/) .

يُقارن هذا الجدول قدرات وميزات Open XML SDK مع Aspose.Slides.

| :- | :- | :- |
|تنسيقات العروض المدعومة|PPTX|PPT, POT, PPS, PPTX, POTX, PPSX, ODP|
|تحويل من PPT إلى PPTX |No|Yes|
|<p>البرمجة عالية المستوى باستخدام نموذج كائن مستند العرض (DOM): </p><p>- البحث والاستبدال بالنصوص.</p><p>- تجميع الشرائح في العروض.</p>|No|Yes|
|البرمجة التفصيلية باستخدام نموذج كائن المستند؛ الوصول إلى العناصر الفردية والتنسيق مثل TextHolders وTextFrames وParagraphs وPortions.|Yes|Yes|
|وصول منخفض المستوى مباشر وكامل إلى عناصر XML الأساسية والسمات مثل معرفات العلاقات، معرفات القوائم في مستند OOXML.|Yes|No|
|<p>العرض والطباعة:</p><p>- عرض العروض إلى PDF، PDF Notes، XPS، صور TIFF.</p><p>- عرض صور مصغرة للشرائح إلى PNG، JPEG، BMP، SVG وTIFF.</p><p>- تحديد دقة الصورة، الجودة، الضغط وخيارات أخرى.</p><p>- طباعة العروض باستخدام بنية الطباعة في .NET. المكوّن يحتوي على طريقة طباعة مدمجة لطباعة العروض كما هو موضح في معاينة الطباعة في MS PowerPoint.</p>|No|Yes|
|المنصات المدعومة|Windows, .NET|Windows, Linux, Java, .NET, Mono|

## **الخلاصة**
لا يتنافس Open XML SDK و Aspose.Slides مباشرةً لأنهما يلبيان احتياجات مختلفة بشكل كبير، ويستهدفان جمهورًا مختلفًا.

{{% alert color="info" %}} 

Open XML SDK هي مكتبة فئات توفر طريقة ذات نوع قوي للعمل مع مستندات OOXML بينما Aspose.Slides هي مكتبة معالجة عروض تقديمية ذات فائدة كبيرة وتوفر دعماً ممتازاً لمعظم تنسيقات ملفات Microsoft PowerPoint. 

{{% /alert %}} 

إذا كان سير العمل الخاص بك عملية برمجة أساسية على مستند PPTX، فقد يكون Open XML SDK خيارًا جيدًا. باستخدام Open XML SDK، يجب أن تكون مرتاحًا للقيام بمهام بسيطة مثل إنشاء مستند PPTX بسيط أو إزالة التعليقات، الترويسات/التذييلات، استخراج الصور أو غيرها. يمكن تنفيذ بعض المهام باستخدام Open XML SDK ولا يمكن تنفيذها باستخدام Aspose.Slides. على سبيل المثال، إذا كنت بحاجة إلى الوصول مباشرة إلى عناصر XML وسماتها في مستند OOXML، فعليك استخدام Open XML SDK.

إذا كنت بحاجة إلى تنفيذ مهام معقدة على المستندات—مثل المهام المذكورة أدناه—فإن Aspose.Slides هو الخيار الأنسب لك.

- عمليات تتضمن تنسيقات PowerPoint القديمة (وأيضًا PPTX).
- نسخ أو استنساخ الأشكال داخل الشرائح بطريقة تجمع الكائنات والأنماط وعناصر التنسيق الأخرى بالشكل المناسب.
- استبدال النص المنسق أو غير المنسق.
- تطبيق الرسوم المتحركة واستخدام الموصلات مع الأشكال.
- تحويل مستند إلى PDF أو TIFF أو XPS بحيث يبدو كما لو أن Microsoft PowerPoint قام بالتحويل.
- تطوير تطبيق .NET أو Java في بيئات سطح المكتب والويب على حد سواء.
