## **نظرة عامة**

تشرح هذه المقالة متى قد يختار المطورون استخدام Open XML SDK أو Aspose.Slides للعمل مع مستندات العروض التقديمية. تصف Open XML SDK بأنها مكتبة لمعالجة حزم OOXML وعناصر XML الأساسية الخاصة بها، بينما تُقدم Aspose.Slides كمكتبة معالجة عروض تقديمية بنموذج كائن عالي المستوى ودعم للعديد من المهام المتعلقة بـ PowerPoint.

تقارن هذه المقالة الخيارات من حيث الصيغ المدعومة، نموذج البرمجة، قدرات العرض والطباعة، دعم المنصات، وحالات الاستخدام الشائعة. كما توضح أن Open XML SDK قد يكون مناسبًا للعمليات الأساسية على PPTX أو للوصول المباشر إلى عناصر OOXML، بينما Aspose.Slides أكثر ملاءمة للمهام المعقدة مثل التعامل مع صيغ PowerPoint المتعددة، نسخ أو استنساخ الأشكال، استبدال النص، تطبيق الرسوم المتحركة، وتحويل العروض إلى PDF أو TIFF أو XPS.

## **ما هو Open XML SDK؟**
في بعض الأحيان، نتلقى هذا السؤال: *لماذا يجب أن نستخدم منتجات Aspose بدلاً من Open XML SDK المجاني؟*

نجد أن الإجابة على هذا السؤال سهلة من حيث الميزات والوظائف.

وفقًا لـ [مكتبة MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، يتم تعريف Open XML SDK بهذه الطريقة:

> "يبسط Open XML SDK 2.0 مهمة معالجة حزم Open XML وعناصر مخطط Open XML الأساسية داخل الحزمة. يدمج Open XML SDK 2.0 العديد من المهام الشائعة التي ينفذها المطورون على حزم Open XML، بحيث يمكنك القيام بعمليات معقدة ببضع أسطر من الشيفرة فقط. مستندات OOXML هي أساساً ملفات XML مضغوطة، وOpen XML SDK هو مجموعة من الفئات التي تسمح لك بالعمل مع محتوى مستندات OOXML بطريقة قوية النوع. أي بدلاً من فك ضغط ملف لاستخراج XML، وتحميل ذلك XML في شجرة DOM، والعمل مباشرةً مع عناصر XML وسماته، يوفر Open XML SDK فئات للقيام بذلك."

## **ما هو Aspose.Slides؟**
Aspose.Slides هي مكتبة فئات تسمح للتطبيقات بتنفيذ مهام معالجة العروض التقديمية التالية:

- البرمجة باستخدام نموذج كائن العرض التقديمي.
- تحويلات عالية الجودة تتضمن جميع صيغ عروض PowerPoint المدعومة الشائعة، بما في ذلك التحويل إلى PDF وXPS وTIFF والطباعة.
- إنشاء صور مصغرة للشرائح بصيغ معروفة مثل PNG وJPEG وBMP بالإضافة إلى تصدير الشرائح إلى SVG.
- إنشاء عروض تقديمية من الصفر أو بدمج عناصر من مستند واحد أو متعدد.
- إضافة الرسوم المتحركة، إطارات OLE، الجداول، إنشاء وإدارة المخططات.
- التحكم (تحكم شامل) وإدارة تنسيق النص على مستويات TextFrames والفقرات والأقسام.

لمزيد من التفاصيل حول الميزات المتاحة، يرجى الاطلاع على صفحة [ميزات Aspose.Slides](/slides/ar/net/product-overview/).

## **الخلاصة**
لا تتنافس Open XML SDK وAspose.Slides بشكل مباشر لأنهما يلبيان احتياجات مختلفة بشكل كبير، ويستهدفان جماهير مختلفة.

{{% alert color="primary" %}} 

Open XML SDK هي مكتبة فئات توفر طريقة قوية النوع للعمل مع مستندات OOXML بينما Aspose.Slides هي مكتبة معالجة عروض تقديمية مفيدة للغاية توفر دعماً كبيراً لمجموعة تقريباً جميع صيغ ملفات Microsoft PowerPoint. 

{{% /alert %}} 

إذا كان سير عملك عملية برمجية أساسية على مستند PPTX، فقد يكون Open XML SDK خيارًا جيدًا. باستخدام Open XML SDK، يجب أن تكون مرتاحًا لتنفيذ مهام بسيطة مثل إنشاء مستند PPTX بسيط أو إزالة التعليقات، رؤوس/تذييلات الصفحات، استخراج الصور أو غيرها. يمكن تنفيذ بعض المهام باستخدام Open XML SDK ولا يمكن تنفيذها باستخدام Aspose.Slides. على سبيل المثال، إذا كنت بحاجة إلى الوصول مباشرة إلى عناصر XML وسماتها في مستند OOXML، فيجب عليك استخدام Open XML SDK.

إذا كنت بحاجة إلى تنفيذ مهام معقدة على المستندات—مثل المهام المذكورة أدناه—فإن Aspose.Slides هو الخيار الأفضل لك.

- العمليات المتعلقة بصيغ PowerPoint القديمة (والـ PPTX أيضًا).
- نسخ أو استنساخ الأشكال داخل الشرائح بطريقة تجمع بين الكائنات والأنماط وعناصر التنسيق الأخرى بطريقة مناسبة.
- استبدال النص المنسق أو غير المنسق.
- تطبيق الرسوم المتحركة واستخدام الموصلات مع الأشكال.
- تحويل مستند إلى PDF أو TIFF أو XPS بحيث يبدو كما لو أن Microsoft PowerPoint قام بالتحويل.
- تطوير تطبيق .NET أو Java في بيئات سطح المكتب والويب.
