## **نظرة عامة**

يمكن استخدام Aspose.Slides في وضع التقييم أو باستخدام ترخيص صالح. توفر نسخة التقييم نفس الوظائف كنسخة الترخيص، لكنها تُضيف علامة مائية للتقييم عند فتح العروض التقديمية أو حفظها وتحد من استخراج النص إلى شريحة واحدة.

تشرح هذه المقالة كيفية عمل الترخيص في Aspose.Slides وكيفية تطبيق ترخيص قبل استخدام المكتبة. يمكن تحميل الترخيص من ملف أو تدفق أو مورد مدمج باستخدام الفئة `License`. كما تُظهر المقالة كيفية التحقق مما إذا تم تطبيق الترخيص بشكل صحيح.

بمجرد أن تكون راضيًا عن تقييمك لـ **Aspose.Slides**، يمكنك [شراء ترخيص](https://purchase.aspose.com/buy). نوصيك بالاطلاع على أنواع الاشتراكات المختلفة. إذا كان لديك أسئلة، تواصل مع فريق مبيعات Aspose.

كل ترخيص Aspose يأتي مع اشتراك سنة واحدة للترقيات المجانية إلى الإصدارات الجديدة أو التصحيحات التي تُصدر خلال فترة الاشتراك. يحصل المستخدمون الذين لديهم منتجات مرخصة أو حتى نسخ تقييم على دعم فني مجاني وغير محدود.

## **الترخيص في Aspose.Slides**
* تصبح نسخة التقييم مرخصة بعد شراء ترخيص وإضافة بضع أسطر من الشفرة إليها (لتطبيق الترخيص).
* الترخيص هو ملف XML نص عادي يحتوي على تفاصيل مثل اسم المنتج، عدد المطورين المرخص لهم، تاريخ انتهاء الاشتراك، وما إلى ذلك.
* ملف الترخيص موقع رقمياً، لذا لا يجب تعديل الملف. حتى إضافة غير مقصودة لسطر جديد في محتوى الملف سيجعله غير صالح.
* عادةً ما يحاول Aspose.Slides for .NET العثور على الترخيص في المواقع التالية:
  * مسار صريح
  * المجلد الذي يحتوي على ملف dll للمكوّن (المضمّن في Aspose.Slides)
  * المجلد الذي يحتوي على التجميعة التي استدعت ملف dll للمكوّن (المضمّن في Aspose.Slides)
  * المجلد الذي يحتوي على التجميعة الدخولية (ملف .exe الخاص بك)
  * مورد مدمج في التجميعة التي استدعت ملف dll للمكوّن (المضمّن في Aspose.Slides).
* لتجنب القيود المرتبطة بنسخة التقييم، تحتاج إلى ضبط ترخيص قبل استخدام Aspose.Slides. يكفي ضبط الترخيص مرة واحدة فقط لكل تطبيق أو عملية.

{{% alert color="info" %}} 

قد ترغب في الاطلاع على [الترخيص القائم على الاستهلاك](https://docs.aspose.com/slides/ar/net/metered-licensing/).

{{% /alert %}} 


## **تطبيق ترخيص**
يمكن تحميل الترخيص من **ملف**، **تدفق**، أو **مورد مدمج**. 

{{% alert color="info" %}}

توفر Aspose.Slides الفئة [License](https://reference.aspose.com/slides/ar/net/aspose.slides/license) لإجراءات الترخيص.

{{% /alert %}} 

{{% alert color="warning" %}} 

يمكن للتراخيص الجديدة تفعيل Aspose.Slides فقط مع الإصدار 21.4 أو أحدث. الإصدارات السابقة تستخدم نظام ترخيص مختلف ولن تتعرف على هذه التراخيص.

{{% /alert %}}

### **ملف**
أسهل طريقة لضبط ترخيص تتطلب وضع ملف الترخيص في نفس المجلد الذي يحتوي على DLL الخاص بالمكوّن (المضمّن في Aspose.Slides) وتحديد اسم الملف فقط دون مساره.

``` csharp
// ينشئ كائنًا من فئة License
Aspose.Slides.License license = new Aspose.Slides.License();

// يحدد مسار ملف الترخيص
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" %}} 

إذا وضعت ملف الترخيص في دليل مختلف، عند استدعاء طريقة [SetLicense](https://reference.aspose.com/slides/ar/net/aspose.slides/license/setlicense/#setlicense_1)، يجب أن يكون اسم ملف الترخيص في نهاية المسار الصريح المحدد هو نفسه اسم ملف الترخيص الخاص بك.

على سبيل المثال، يمكنك تغيير اسم ملف الترخيص إلى *Aspose.Slides.lic.xml*. ثم، في الشفرة، عليك تمرير المسار إلى الملف (الذي ينتهي بـ *Aspose.Slides.lic.xml*) إلى طريقة [SetLicense](https://reference.aspose.com/slides/ar/net/aspose.slides/license/setlicense/#setlicense_1).

{{% /alert %}}

### **تدفق**
يمكنك تحميل الترخيص من تدفق. يُظهر لك هذا الكود C# كيفية تطبيق ترخيص من تدفق:

``` csharp
// يُنشئ كائنًا من فئة License
Aspose.Slides.License license = new Aspose.Slides.License();

// يفتح ملف الترخيص كتيار
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// يضبط الترخيص عبر تيار
license.SetLicense(licenseStream);
```

### **مورد مدمج**
يمكنك تضمين الترخيص مع تطبيقك (لتجنب فقدانه) بإضافة الترخيص كمورد مدمج إلى إحدى التجميعات التي تستدعي DLL الخاص بالمكوّن (المضمّن في Aspose.Slides). 

هذه هي الطريقة لإضافة ملف الترخيص كمورد مدمج:

1. في Visual Studio، أضف ملف الترخيص (.lic) إلى المشروع بهذه الطريقة: اذهب إلى **File** > **Add Existing Item** > **Add**. 
2. اختر الملف في **Solution Explorer**.
3. في نافذة **Properties**، اضبط **Build Action** على **Embedded Resource**.
4. للوصول إلى الترخيص المدمج في التجميعة، أضف ملف الترخيص كمورد مدمج إلى المشروع، ثم مرّر اسم ملف الترخيص إلى طريقة `SetLicense`. 

الفئة `License` تجد ملف الترخيص تلقائيًا في الموارد المدمجة. لا تحتاج إلى استدعاء طريقتي `GetExecutingAssembly` و `GetManifestResourceStream` من فئة `System.Reflection.Assembly` في إطار عمل Microsoft .NET.

``` csharp
// يُنشئ كائنًا من فئة License
Aspose.Slides.License license = new Aspose.Slides.License();

// يمرّر اسم ملف الترخيص المدمج في التجميعة
license.SetLicense("Aspose.Slides.lic");
```

## **التحقق من الترخيص**

للتحقق مما إذا تم ضبط الترخيص بشكل صحيح، يمكنك التحقق منه. يُظهر لك هذا الكود C# كيفية التحقق من الترخيص:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **سلامة الخيوط**

{{% alert title="Note" color="warning" %}} 

طريقة [license.SetLicense](https://reference.aspose.com/slides/ar/net/aspose.slides/license/setlicense/) غير آمنة للاستخدام المتعدد الخيوط. إذا كان يجب استدعاء هذه الطريقة في وقت واحد من عدة خيوط، قد ترغب في استخدام أدوات التزامن (مثل القفل) لتجنب المشكلات. 

{{% /alert %}}

## **الأسئلة المتكررة**

### هل يمكنني تطبيق الترخيص في بيئة بدون اتصال بالإنترنت تمامًا (بدون وصول إلى الإنترنت)؟

نعم. يتم إجراء التحقق من الترخيص محليًا باستخدام ملف الترخيص؛ لا يلزم اتصال بالإنترنت.

### ماذا يحدث بعد انتهاء الاشتراك السنوي؟ هل سيتوقف المكتبة عن العمل؟

لا. الترخيص دائم: يمكنك الاستمرار في استخدام الإصدارات التي صدرت قبل تاريخ انتهاء الاشتراك؛ إلا أنك لن تكون مؤهلاً لاستخدام الإصدارات الأحدث دون التجديد.
