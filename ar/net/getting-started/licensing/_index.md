## **نظرة عامة**

يمكن استخدام Aspose.Slides في وضع التقييم أو مع ترخيص صالح. يوفر إصدار التقييم نفس الوظائف كالإصدار المرخص، لكنه يضيف علامة مائية للتقييم إلى كل شريحة من كل عرض تقديمي يتم حفظه ويقصر النص الذي يقرأه الكود من العروض التقديمية.

تشرح هذه المقالة كيفية عمل الترخيص في Aspose.Slides وكيفية تطبيق ترخيص قبل استخدام المكتبة. يمكن تحميل الترخيص من ملف أو تدفق أو مورد مضمّن باستخدام الفئة `License`. تُظهر المقالة أيضًا كيفية التحقق مما إذا تم تطبيق الترخيص بشكل صحيح.

## **الترخيص في Aspose.Slides**
* يصبح إصدار التقييم مرخصًا بعد شراء ترخيص وإضافة بضع أسطر من الشيفرة لتطبيق الترخيص.
* الترخيص هو ملف XML نصي بسيط يحتوي على تفاصيل مثل اسم المنتج، عدد المطورين المرخص لهم، تاريخ انتهاء الاشتراك، وما إلى ذلك.
* ملف الترخيص موقَّع رقمياً، لذا لا يجوز تعديل الملف. حتى إضافة سطر جديد غير مقصودة إلى محتويات الملف سيؤدي إلى إبطال الترخيص.
* عادةً ما تحاول Aspose.Slides for .NET العثور على الترخيص في المواقع التالية:
  * مسار صريح
  * المجلد الذي يحتوي على ملف الـ dll للمكوّن (مضمّن في Aspose.Slides)
  * المجلد الذي يحتوي على التجميع الذي استدعى ملف الـ dll للمكوّن (مضمّن في Aspose.Slides)
  * المجلد الذي يحتوي على التجميع الرئيسي (ملف .exe الخاص بك)
  * مورد مضمّن في التجميع الذي استدعى ملف الـ dll للمكوّن (مضمّن في Aspose.Slides).
* لتجنب القيود المرتبطة بإصدار التقييم، يجب تعيين ترخيص قبل استخدام Aspose.Slides. يكفي تعيين الترخيص مرة واحدة لكل تطبيق أو عملية.

{{% /alert %}} 

## **تطبيق ترخيص**
يمكن تحميل الترخيص من **ملف** أو **تدفق** أو **مورد مضمّن**. 

{{% alert color="info" title="ملاحظة" %}}
توفر Aspose.Slides فئة [License](https://reference.aspose.com/slides/ar/net/aspose.slides/license) لعمليات الترخيص.
{{% /alert %}} 

{{% alert color="warning" title="تحذير" %}}
يمكن للتراخيص الجديدة تفعيل Aspose.Slides فقط مع الإصدار 21.4 أو أحدث. الإصدارات الأقدم تستخدم نظام ترخيص مختلف ولن تتعرف على هذه التراخيص.
{{% /alert %}}

### **ملف**
الطريقة الأسهل لتعيين ترخيص هي وضع ملف الترخيص في نفس المجلد الذي يحتوي على DLL المكوّن (مضمّن في Aspose.Slides) وتحديد اسم الملف فقط دون مساره.

هذا الشيفرة C# يوضح لك كيفية تعيين ملف ترخيص:

``` csharp
// إنشاء كائن من فئة License 
Aspose.Slides.License license = new Aspose.Slides.License();

// تعيين مسار ملف الترخيص
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" title="تحذير" %}}
إذا وضعت ملف الترخيص في دليل مختلف، عند استدعاء طريقة [SetLicense](https://reference.aspose.com/slides/ar/net/aspose.slides/license/setlicense/#setlicense_1)، يجب أن يكون اسم ملف الترخيص في نهاية المسار المحدد هو نفسه اسم ملف الترخيص الخاص بك.
على سبيل المثال، يمكنك تغيير اسم ملف الترخيص إلى *Aspose.Slides.lic.xml*. ثم، في الشيفرة الخاصة بك، يجب تمرير المسار إلى الملف (المنتهي بـ *Aspose.Slides.lic.xml*) إلى طريقة [SetLicense](https://reference.aspose.com/slides/ar/net/aspose.slides/license/setlicense/#setlicense_1).
{{% /alert %}}

### **تدفق**
يمكنك تحميل ترخيص من تدفق. هذا الشيفرة C# يوضح لك كيفية تطبيق ترخيص من تدفق:

``` csharp
// إنشاء كائن من فئة License
Aspose.Slides.License license = new Aspose.Slides.License();

// فتح ملف الترخيص كتيار
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// تعيين الترخيص عبر تيار
license.SetLicense(licenseStream);
```

### **مورد مضمّن**
يمكنك حزم الترخيص مع تطبيقك (لتجنب فقدانه) عن طريق إضافة الترخيص كمورد مضمّن إلى أحد التجميعات التي تستدعي DLL المكوّن (مضمّن في Aspose.Slides).

هذه هي الطريقة لإضافة ملف ترخيص كمورد مضمّن:

1. في Visual Studio، أضف ملف الترخيص (.lic) إلى المشروع بهذه الطريقة: انتقل عبر **File** > **Add Existing Item** > **Add**. 
2. اختر الملف في **Solution Explorer**.
3. في نافذة **Properties**، اضبط **Build Action** إلى **Embedded Resource**.
4. للوصول إلى الترخيص المضمّن في التجميع، أضف ملف الترخيص كمورد مضمّن إلى المشروع، ثم مرّر اسم ملف الترخيص إلى طريقة `SetLicense`.

الفئة `License` تجد ملف الترخيص تلقائيًا في الموارد المضمّنة. لا تحتاج إلى استدعاء طريقتي `GetExecutingAssembly` و `GetManifestResourceStream` من فئة `System.Reflection.Assembly` في إطار عمل Microsoft .NET.

هذا الشيفرة C# يوضح لك كيفية تعيين ترخيص كمورد مضمّن:

``` csharp
// إنشاء كائن من فئة License
Aspose.Slides.License license = new Aspose.Slides.License();

// تمرير اسم ملف الترخيص المضمّن في التجميع
license.SetLicense("Aspose.Slides.lic");
```

## **التحقق من الترخيص**

للتحقق مما إذا تم تعيين الترخيص بشكل صحيح، يمكنك التحقق منه. هذا الشيفرة C# يوضح لك كيفية التحقق من الترخيص:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **سلامة الخيوط**

{{% alert color="warning" title="تحذير" %}}
طريقة [license.SetLicense](https://reference.aspose.com/slides/ar/net/aspose.slides/license/setlicense/) غير آمنة للاستخدام المتوازي. إذا كان يجب استدعاء هذه الطريقة في نفس الوقت من عدة خيوط، قد ترغب في استخدام أدوات التزامن (مثل القفل) لتجنب المشكلات.
{{% /alert %}}

## **الأسئلة الشائعة**

### هل يمكنني تطبيق الترخيص في بيئة غير متصلة بالإنترنت تمامًا (بدون اتصال بالإنترنت)؟

نعم. يتم إجراء التحقق من الترخيص محليًا باستخدام ملف الترخيص؛ لا يلزم اتصال بالإنترنت.

### ماذا يحدث بعد انتهاء الاشتراك لمدة سنة واحدة؟ هل سيتوقف المكتبة عن العمل؟

لا. الترخيص دائم: يمكنك الاستمرار في استخدام الإصدارات الصادرة قبل تاريخ انتهاء اشتراكك؛ لن تكون مؤهلاً لاستخدام الإصدارات الأحدث دون التجديد.
