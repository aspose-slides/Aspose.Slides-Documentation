**مرحبًا بكم في Aspose.Slides for Node.js via .NET**

![شعار منتج Aspose.Slides for Node.js عبر .NET](aspose_slides-for-nodejs-via-net.png)

Aspose.Slides for Node.js via .NET هي مكتبة فئات تمكّن تطبيقاتك من قراءة وكتابة مستندات PowerPoint® دون الحاجة إلى استخدام Microsoft PowerPoint®.

Aspose.Slides for Node.js via .NET هو المكوّن الأول والوحيد الذي يوفّر الوظيفة لإدارة مستندات PowerPoint®.

Aspose.Slides for Node.js via .NET يوفّر العديد من الميزات الرئيسية مثل إدارة النصوص والأشكال والجداول والرسوم المتحركة، وإضافة الصوت والفيديو إلى الشرائح، ومعاينة الشرائح، وتصدير الشرائح إلى صيغة SVG، PDF والمزيد.
