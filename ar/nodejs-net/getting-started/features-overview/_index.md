## **المنصات المدعومة**
Aspose.Slides for Node.js عبر .NET هو واجهة برمجة تطبيقات مستقلة عن المنصة. يمكن استخدامها على أي منصة (Windows، Linux، macOS، إلخ) حيث يتم تثبيت Node.js 7 أو أعلى. Oracle JDK 8 أو أعلى هو متطلب آخر.

## **تنسيقات الملفات والتحويلات**
Aspose.Slides for Node.js عبر .NET يدعم معظم تنسيقات مستندات PowerPoint. كما يتيح لك تصديرها إلى تنسيقات الملفات الشائعة التي تستخدمها المنظمات وتشاركها فيما بينها. استعرض هذه التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|Microsoft PowerPoint (PPT)|توفر Aspose.Slides for Node.js عبر .NET أسرع معالجة لهذا تنسيق مستند العرض التقديمي.|
|PPT to PPTX conversion|تدعم Aspose.Slides for Node.js عبر .NET تحويل PPT إلى PPTX|
|Portable Document Format (PDF)|يمكنك تصدير جميع تنسيقات الملفات المدعومة إلى مستندات Adobe Portable Document Format (PDF) باستخدام طريقة واحدة.|
|XML Parser Specification (XPS)|يمكنك تصدير جميع تنسيقات الملفات المدعومة إلى مستندات XML Parser Specification (XPS) باستخدام طريقة واحدة.|
|Tagged Image File Format (TIFF)|يمكنك تصدير جميع تنسيقات ملفات العرض التقديمي المدعومة إلى Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|تدعم Aspose.Slides for Node.js عبر .NET تحويل PresentationEx إلى تنسيق HTML.|

## **عرض العروض التقديمية**
Aspose.Slides for Node.js عبر .NET يدعم عرض عالي الدقة للشرائح في العرض التقديمي إلى تنسيقات رسومية مختلفة. استعرض هذه التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|.NET Supported Image Formats|باستخدام Aspose.Slides for Node.js عبر .NET، يمكنك تصيير شرائح العرض التقديمي والصور على الشرائح إلى جميع تنسيقات الرسومات المدعومة من .NET مثل TIFF وPNG وBMP وJPEG وGIF.|
|SVG Format|توفر Aspose.Slides for Node.js عبر .NET أيضًا طرقًا مدمجة تسمح لك بتصدير شرائح العرض التقديمي إلى تنسيقات Scalable Vector Graphics (SVG).|

## **ميزات المحتوى**
Aspose.Slides for Node.js عبر .NET يتيح لك الوصول إلى محتويات مستندات العرض التقديمي، تعديلها أو إنشائها تقريبًا جميعها. استعرض هذه التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|Master Slides|تحدد الشرائح الأساسية (Master Slides) تخطيط الشرائح العادية. تسمح لك Aspose.Slides for Node.js عبر .NET بالوصول إلى الشرائح الأساسية وتعديلها في مستندات العرض التقديمي.|
|Normal Slides|مع Aspose.Slides for Node.js عبر .NET، يمكنك إنشاء شرائح جديدة من أنواع مختلفة؛ كما يمكنك الوصول إلى الشرائح الحالية وتعديلها في العروض التقديمية.|
|Cloning / Copying Slides|توفر Aspose.Slides for Node.js عبر .NET طرقًا مدمجة تسمح لك باستنساخ أو نسخ الشرائح الموجودة داخل عرض تقديمي. يمكنك أيضًا استخدام الشرائح المنسوخة أو المستنسخة من عرض تقديمي إلى آخر. نظرًا لأن الشريحة تستمد تخطيطها من الشريحة الأساسية، تقوم طرق الاستنساخ المدمجة بنسخ الأساسية تلقائيًا أثناء الاستنساخ.|
|Managing Slides sections|طرق لتنظيم الشرائح في أقسام مختلفة داخل العرض التقديمي.|
|Place Holders and Text Holders|يمكنك الوصول إلى حاويات الأماكن (Place Holders) وحاويات النص (Text Holders) في الشريحة. علاوةً على ذلك، يمكنك إنشاء شريحة تحتوي على حاويات نص من الصفر باستخدام الطريقة المناسبة.|
|Header and Footers|تسهل Aspose.Slides for Node.js عبر .NET التعامل مع رؤوس وتذييلات الشرائح.|
|Notes in Slides|مع Aspose.Slides for Node.js عبر .NET، يمكنك الوصول إلى الملاحظات المرتبطة بشريحة وتعديلها، بالإضافة إلى إضافة ملاحظات جديدة.|
|Finding a Shape|يمكنك أيضًا العثور على شكل معين في شريحة باستخدام النص البديل المرتبط بالشكل.|
|Backgrounds|تتيح لك Aspose.Slides for Node.js عبر .NET العمل مع الخلفيات المرتبطة بشريحة أساسية أو شريحة عادية في العرض التقديمي.|
|Text Boxes|يمكن إنشاء صناديق النص من الصفر. يمكنك الوصول إلى صناديق النص الموجودة. كما يمكنك تعديل نصوصها دون فقدان تنسيق النص الأصلي.|
|Rectangle Shapes|يمكنك إنشاء أو تعديل أشكال المستطيل باستخدام Aspose.Slides for Node.js عبر .NET.|
|Poly Line Shapes|يمكنك إنشاء أو تعديل أشكال الخط المتعدد باستخدام Aspose.Slides for Node.js عبر .NET.|
|Ellipse Shapes|يمكنك إنشاء أو تعديل أشكال البيض باستخدام Aspose.Slides for Node.js عبر .NET.|
|Group Shapes|تدعم Aspose.Slides for Node.js عبر .NET أشكال المجموعات.|
|Auto Shapes|تدعم Aspose.Slides for Node.js عبر .NET الأشكال التلقائية.|
|SmartArt|توفر Aspose.Slides for Node.js عبر .NET دعمًا لأشكال SmartArt في MS PowerPoint.|
|Charts|توفر Aspose.Slides for Node.js عبر .NET دعمًا لمخططات MSO في PowerPoint.|
|Shapes Serialization|تدعم Aspose.Slides for Node.js عبر .NET عددًا كبيرًا من الأشكال. عندما لا تدعم Aspose.Slides for Node.js عبر .NET شكلًا معينًا، يمكنك استخدام طريقة التسلسل (serialization) التي تسمح لك بتسلسل ذلك الشكل من شريحة موجودة. بهذه الطريقة يمكنك استخدام الشكل لاحقًا وفقًا لمتطلباتك.|
|Picture Frames|يمكنك إدارة الصور داخل إطارات الصور باستخدام Aspose.Slides for Node.js عبر .NET.|
|Audio Frames|يمكنك ربط أو تضمين ملفات صوتية في إطارات صوتية على الشرائح باستخدام Aspose.Slides for Node.js عبر .NET.|
|Video Frames|يمكنك التعامل مع ملفات الفيديو في إطارات الفيديو. كما توفر Aspose.Slides for Node.js عبر .NET دعمًا للفيديوهات المرتبطة والمضمنة.|
|OLE Frame|يمكنك إدارة كائنات OLE في إطارات OLE باستخدام Aspose.Slides for Node.js عبر .NET.|
|Tables|تدعم Aspose.Slides for Node.js عبر .NET الجداول في الشرائح.|
|ActiveX Controls|دعم عناصر التحكم ActiveX.|
|VBA Macros|دعم إدارة ماكروات VBA داخل العروض التقديمية.|
|Text Frame|يمكنك الوصول إلى النص داخل أي شكل عبر إطار النص المرتبط بذلك الشكل.|
|Text Scanning|يمكنك مسح النص في عرض تقديمي على مستوى العرض أو الشريحة باستخدام طرق المسح المدمجة.|
|Animations|يمكنك تطبيق الرسوم المتحركة على الأشكال.|
|Slide Shows|تدعم Aspose.Slides for Node.js عبر .NET عروض الشرائح وانتقالات الشرائح.|

## **ميزات التنسيق**
مع Aspose.Slides for Node.js عبر .NET، يمكنك تنسيق النصوص والأشكال على الشرائح في العروض التقديمية. استعرض هذه التفاصيل:

|**الميزة**|**الوصف**|
| :- | :- |
|Text Formatting|<p>في Aspose.Slides for Node.js عبر .NET، يمكنك إدارة النصوص عبر إطارات النص المرتبطة بالأشكال. وبالتالي، يمكنك تنسيق النصوص باستخدام الفقرات والأجزاء المرتبطة بإطارات النص. يمكن تنسيق عناصر النص هذه من خلال Aspose.Slides for Node.js عبر .NET.</p><p>- نوع الخط</p><p>- حجم الخط</p><p>- لون الخط</p><p>- ظلال الخط</p><p>- محاذاة الفقرة</p><p>- تعداد الفقرة</p><p>- اتجاه الفقرة</p>|
|Shape Formatting|<p>في Aspose.Slides for Node.js عبر .NET، العنصر الأساسي للشرائح هو الشكل. يمكنك تنسيق هذه العناصر الشكلية باستخدام Aspose.Slides for Node.js عبر .NET:</p><p>- الموضع</p><p>- الحجم</p><p>- الخط</p><p>- التعبئة (بما في ذلك النمط، التدرج، الصلب)</p><p>- النص</p><p>- الصورة</p>|
