## **نظرة عامة**

الإصدار التجريبي لـ Aspose.Slides لـ Node.js عبر .NET هو نفس حزمة npm الخاصة بالإصدار المرخص. بدون ترخيص، يعمل في وضع التقييم: جميع الميزات تعمل، لكن العروض التقديمية المحفوظة ومعظم عمليات التصدير تحمل علامة مائية، والنص الذي يقرؤه الكود الخاص بك يُقصَر. تصف هذه المقالة كلا القيدين وتظهر كيفية إزالتهما.

## **قيود التقييم**

**علامة مائية تجريبية على كل شريحة.** عند حفظ عرض تقديمي بدون ترخيص، يضيف Aspose.Slides مربع نص في وسط كل شريحة من الملف المحفوظ. يتم قفل مربع النص ويظهر النص "Evaluation only." متبوعًا بسطر المنتج وسطر حقوق النشر. تُدرج العلامة المائية في الملف المحفوظ، وليس في العرض التقديمي في الذاكرة، ولا يُضيف فتح العرض التقديمي علامة مائية. الملف الذي تم حفظه في وضع التقييم يحتوي بالفعل على مربع النص، لذلك عند فتحه وحفظه مرة أخرى تُضاف علامة مائية ثانية إلى كل شريحة.

نفس العلامة المائية تُرسم في المخرجات عند التصدير إلى PDF أو XPS أو HTML، أو عند تصيير الشرائح كصور. إذا قمت بتصريف عرض تقديمي تم حفظه مسبقًا في وضع التقييم، تُظهر الصورة كلًا من العلامة المائية المحفوظة والمصيرة.

**قص النص عند قراءته بواسطة الكود.** النص الذي يقرأه الكود عبر خاصية `text` لإطار نص أو فقرة أو جزء يُقصَ إلى أول خمس حروف، يتبعها الإشعار "... text has been truncated due to evaluation version limitation." تُعاد النصوص التي لا تتجاوز خمس حروف بالكامل. ينطبق هذا على كل شريحة، وحتى على النص الذي قام الكود بتعيينه للتو. تُقص تصادرات Markdown وHTML5 بنفس الطريقة.

النص الذي يكتبه الكود يُحفظ بالكامل: ملفات PPTX، صفحات PDF وصور الشرائح تحتوي على النص الكامل.

## **عرض القيد في برنامج نصي**

البرنامج النصي التالي يُظهر كلا القيدين. يفترض أنك قد قمت بتثبيت الحزمة كما هو موضح في [التثبيت](/slides/ar/nodejs-net/installation/) وأنك تشغله من مجلد المشروع. يضيف مستطيلًا يحتوي على جملة إلى الشريحة الأولى، يقرأ الجملة مرة أخرى، يحفظ العرض التقديمي كملف `evaluation.pptx`، ثم يعيد فتح الملف لحساب الأشكال على الشريحة.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { Presentation, ShapeType, SaveFormat } = asposeSlides;

const presentation = new Presentation();
try {
    const slide = presentation.slides.get(0);
    const rectangle = slide.shapes.addAutoShape(ShapeType.Rectangle, 50, 50, 500, 100);
    rectangle.textFrame.text = "Quarterly results are ready for review.";

    // بدون ترخيص، يتم إرجاع الأحرف الخمسة الأولى فقط.
    console.log("Text read back:", rectangle.textFrame.text);

    // الحفظ يضيف العلامة المائية التجريبية إلى كل شريحة في الملف.
    presentation.save("evaluation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}

const savedPresentation = new Presentation("evaluation.pptx");
try {
    // الآن تحتوي الشريحة على المستطيل ومربع نص العلامة المائية.
    console.log("Shapes on the saved slide:", savedPresentation.slides.get(0).shapes.count);
} finally {
    savedPresentation.dispose();
}
```

بدون ترخيص، يطبع البرنامج النصي:

```text
Text read back: Quart... text has been truncated due to evaluation version limitation.
Shapes on the saved slide: 2
```

الشكل الثاني هو مربع النص الخاص بالعلامة المائية. افتح `evaluation.pptx` لرؤية الجملة الكاملة داخل المستطيل والعلامة المائية في وسط الشريحة.

## **الأسئلة المتكررة**

**هل يحد وضع التقييم من عدد الشرائح؟**

لا. تُنشأ العروض التقديمية وتُفتح وتُحفظ مع جميع شرائحها. تُطبق العلامة المائية وقص النص على كل شريحة على حد سواء.

**لماذا تظهر علامتي مائية على صور الشرائح المُصدرة؟**

تم حفظ العرض التقديمي في وضع التقييم قبل أن تقوم بتصريفه، لذا يحتوي بالفعل على مربع نص للعلامة المائية، وعند التصيير بدون ترخيص يُرسم آخر فوقه.

**هل يمكنني التحقق من أن الكود ينتج النص الصحيح أثناء وضع التقييم؟**

نعم. افتح الملف المحفوظ أو PDF المُصدر: يحتويان على النص الكامل. فقط النص الذي يقرؤه الكود، وإخراج Markdown أو HTML5، هو ما يُقصَر.
