{{% alert color="info" %}} 

Aspose.Slides for Java هي مكتبة فئات تمكّن تطبيقات Java من قراءة وكتابة مستندات العروض التقديمية دون استخدام Microsoft PowerPoint® أو غيره. Aspose.Slides for Java تسمح بإدارة النصوص، الأشكال، الجداول والرسوم المتحركة، إضافة الصوت والفيديو إلى الشرائح، معاينة الشرائح، تصدير الشرائح إلى صيغة SVG أو PDF والمزيد.

أحدث مرجع API يمكن العثور عليه في [مرجع Aspose.Slides for Java API](https://reference.aspose.com/slides/ar/java).

{{% /alert %}}
