{{% alert color="info" title="Note" %}}

هذه صفحة تاريخية. إنها تسرد المشكلات المعروفة المنشورة مع Aspose.Slides for Java 14.3.0 ولا تصف الإصدار الحالي. للاطلاع على التغييرات في كل إصدار، راجع [release notes](https://releases.aspose.com/slides/ar/java/release-notes/).

{{% /alert %}}

يقدم Aspose.Slides for Java 14.3.0 (14.4.0) تنفيذًا جديدًا تمامًا لمعالجة PPT. هناك الكثير من التحسينات، وتحويل جزئي من PPTX إلى PPT. ولكن هناك بعض الميزات غير المنفذة:

- بعض الأشكال لديها هندسة خاطئة في مستندات PPT المتسلسلة (Call outs)
- ليست جميع ميزات تنسيق النص في PPTX مدعومة في تسلسل PPT
- لا توجد معلومات حول لغة النص وإعدادات التدقيق الإملائي في مستندات PPT المتسلسلة
- ليست جميع ميزات سمات PPTX مدعومة في تسلسل PPT

**هناك بعض الاختلافات مقارنةً بـ Aspose.Slides for Java 8.6.0:**

- هناك مشكلات معروفة في تسلسل OLE/ActiveX من PPT إلى PPT

**هناك بعض الاختلافات مقارنةً بـ Aspose.Slides for .NET 14.3.0:**

- دعم طباعة العروض التقديمية غير متوفر حاليًا في Aspose.Slides for Java
