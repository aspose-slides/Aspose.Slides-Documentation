## **نظرة عامة**

هذا القسم لا يحتوي على قائمة بالمشكلات المفتوحة في الإصدار الحالي. يحتوي على ثلاث صفحات:

- [عنصر نائب للمعاينة عند إضافة OleObjectFrame](/slides/ar/java/object-preview-issue-when-adding-oleobjectframe/) يشرح لماذا يظهر كائن OLE مضاف باستخدام Aspose.Slides صورة "EMBEDDED OLE OBJECT" حتى يتم تحديث معاينته، وكيفية تعيين صورة المعاينة الخاصة بك. هذا سلوك مصمم لهذا الإصدار.
- [المشكلات المعروفة في Aspose.Slides for Java 14.3.0 (تاريخية)](/slides/ar/java/known-issues-in-aspose-slides-for-java-14-3-0/) و[المشكلات المعروفة في Aspose.Slides for Java 14.4.0 (تاريخية)](/slides/ar/java/known-issues-in-aspose-slides-for-java-14-4-0/) هي قوائم نشرت مع تلك الإصدارات، محفوظة للرجوع إليها.

للتغييرات والإصلاحات في كل إصدار، راجع [ملاحظات الإصدار](https://releases.aspose.com/slides/ar/java/release-notes/). الحقول التعريفية التي يكتبها Aspose.Slides بقيم ثابتة موصوفة في [قيود بيانات التعريف الخارجة](/slides/ar/java/api-limitations/). للتحقق ما إذا كانت المشكلة معروفة بالفعل، أو للإبلاغ عنها، استخدم [منتدى الدعم](https://forum.aspose.com/c/slides/ar/11).
