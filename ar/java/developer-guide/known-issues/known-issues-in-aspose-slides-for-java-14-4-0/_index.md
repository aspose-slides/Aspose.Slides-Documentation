{{% alert color="info" title="Note" %}}

هذه صفحة تاريخية. إنها تسرد القيود والمشكلات المعروفة التي نُشرت مع Aspose.Slides for Java 14.4.0 ولا تصف الإصدار الحالي. للتغييرات في كل إصدار، راجع [ملاحظات الإصدار](https://releases.aspose.com/slides/ar/java/release-notes/).

{{% /alert %}}

يوفر Aspose.Slides for Java 14.4.0 قرارًا جديدًا لمعالجة مستندات PowerPoint. هناك بعض القيود والمشكلات المعروفة، والتي سيتم إزالتها في الإصدارات القادمة:

- بعض الأشكال لديها هندسة غير صحيحة في مستندات PPT المتسلسلة (قوس، سهم دائري، توضيحات).
- ليس كل ميزات تنسيق النص في PPTX مدعومة في تسلسل PPT (قيود على المسافات، والمسافة البادئة وتنسيق الفقرات).
- لا تتوفر معلومات حول لغة النص وإعدادات التدقيق الإملائي في مستندات PPT المتسلسلة.
- ليس كل ميزات سمة PPTX مدعومة في تسلسل PPT (فقط تسلسل تنسيقات التعبئة، وتنسيقات الخطوط، والخط).
- هناك مشكلات معروفة في تسلسل OLE/ActiveX من PPT إلى PPT.
- لا يتم دعم تسلسل WordArt وعرضه.
