{{% alert color="info" %}} 

يقدم Aspose.Slides for Java 14.4.0 قرارات جديدة لمعالجة مستندات PowerPoint. هناك بعض القيود والمشكلات المعروفة، والتي ستتم إزالتها في الإصدارات القادمة:

- بعض الأشكال لها هندسة خاطئة في مستندات PPT المتسلسلة (قوس، سهم دائري، توضيحات).
- ليست جميع ميزات تنسيق النص في PPTX مدعومة في تسلسل PPT (الجدولة، المسافات البادئة وقيود تنسيق الفقرات).
- لا تتوفر معلومات حول لغة النص وإعدادات التدقيق الإملائي في مستندات PPT المتسلسلة.
- ليست جميع ميزات سمة PPTX مدعومة في تسلسل PPT (فقط تسلسل تنسيقات التعبئة، تنسيقات الخطوط والخط).
- هناك مشكلات معروفة في تسلسل OLE/ActiveX من PPT إلى PPT.
- لا يتم دعم تسلسل WordArt وعرضه.

{{% /alert %}}
