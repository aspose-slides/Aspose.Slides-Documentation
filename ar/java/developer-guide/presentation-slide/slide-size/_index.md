## **مقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة العرض إلى الارتفاع في عروض PowerPoint التقديمية، وهو أمر حاسم لكل من الطباعة والعرض على الشاشة.  

أحجام الشريحة الشائعة والنسب:

- **قياسية (نسبة عرض إلى ارتفاع 4:3)**: مثالية للشاشات والأجهزة القديمة.
- **عريضة (نسبة عرض إلى ارتفاع 16:9)**: يوصى بها لأجهزة العرض الحديثة والشاشات.

احرص على الاتساق في جميع أنحاء عرضك لأن حجم الشريحة ونسبة العرض إلى الارتفاع الموحدة تُطبق على جميع الشرائح. لتحقيق أفضل النتائج، ضع أبعاد الشريحة في بداية عملية إنشاء العرض لتجنب التعقيدات.

{{% alert color="info" %}} 
بشكل افتراضي، تستخدم العروض التي تم إنشاؤها باستخدام Aspose.Slides نسبة العرض إلى الارتفاع القياسية 4:3.
{{% /alert %}}

## **تغيير حجم الشريحة في العروض التقديمية**

يعرض هذا المثال البرمجي كيفية تغيير حجم الشريحة في عرض تقديمي باستخدام Java و Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **تحديد أحجام شرائح مخصصة في العروض التقديمية**

إذا وجدت أن أحجام الشرائح الشائعة (4:3 و 16:9) غير مناسبة لعملك، قد تقرر استخدام حجم شريحة معين أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بحجم كامل من عرضك على تخطيط صفحة مخصص أو إذا كنت تنوي عرض عرضك على أنواع معينة من الشاشات، فمن المرجح أن تستفيد من ضبط حجم مخصص لعرضك.

يعرض هذا المثال البرمجي كيفية استخدام Aspose.Slides for Java لتحديد حجم شريحة مخصص لعروض تقديمية باستخدام Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // حجم ورق A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد تغيير حجم الشريحة في عرض تقديمي، قد يصبح محتوى الشرائح (مثل الصور أو الكائنات) مشوّهًا. بشكل افتراضي، يتم تعديل حجم الكائنات تلقائيًا لتناسب الحجم الجديد للشريحة. ومع ذلك، عند تغيير حجم شريحة العرض، يمكنك تحديد إعداد يحدد كيفية تعامل Aspose.Slides مع المحتويات على الشرائح.

اعتمادًا على ما تنويه أو تسعى لتحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد تعديل حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا كنت تريد التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن يقوم Aspose.Slides بتصغير كائنات الشرائح لضمان توافرها جميعًا على الشرائح (بهذه الطريقة، تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا كنت تريد التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن يقوم Aspose.Slides بتكبير كائنات الشرائح لتصبح متناسبة مع الحجم الجديد للشريحة، استخدم هذا الإعداد.

يعرض هذا المثال البرمجي كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة عرض تقديمي:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **الأسئلة المتكررة**

### هل يمكنني ضبط حجم شريحة مخصص باستخدام وحدات غير البوصة (مثل النقاط أو المليمترات)؟

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث أن 1 نقطة تساوي 1/72 بوصة. يمكنك تحويل أي وحدة (مثل المليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحولة لتحديد عرض وارتفاع الشريحة.

### هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستهلاك الذاكرة أثناء عملية التصيير؟

نعم. الأبعاد الأكبر للشريحة (بالنقاط) مع مقياس تصيير أعلى تؤدي إلى زيادة استهلاك الذاكرة وطول أوقات المعالجة. استهدف حجم شريحة عملي وعدل مقياس التصيير فقط حسب الحاجة لتحقيق جودة الإخراج المطلوبة.

### هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج الشرائح من عروض تقديمية ذات أحجام مختلفة؟

لا يمكنك [دمج العروض](/slides/ar/java/merge-presentation/) بينما تكون لديها أحجام شرائح مختلفة — أولاً، قم بإعادة ضبط حجم أحد العروض لتطابق الآخر. عند تغيير حجم الشريحة، يمكنك اختيار كيفية معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/java/com.aspose.slides/slidesizescaletype/). بعد توحيد الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

### هل يمكنني إنشاء صور مصغرة للأشكال الفردية أو مناطق محددة من الشريحة، وهل ستحترم حجم الشريحة الجديد؟

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لـ [كل الشرائح](https://reference.aspose.com/slides/ar/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) وكذلك لـ [الأشكال المحددة](https://reference.aspose.com/slides/ar/java/com.aspose.slides/shape/#getImage-int-float-float-). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة العرض إلى الارتفاع، مما يضمن إطارًا وتكوينًا متسقًا.
