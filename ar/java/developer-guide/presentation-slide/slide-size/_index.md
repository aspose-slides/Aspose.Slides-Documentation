## **مقدمة**

توفر Aspose.Slides أدوات شاملة لضبط حجم الشريحة ونسبة الأبعاد في عروض PowerPoint التقديمية، وهو أمر حاسم للطباعة والعرض على الشاشة.

أحجام الشرائح الشائعة والنسب:

- **قياسي (نسبة الأبعاد 4:3)**: مثالي للشاشات والأجهزة القديمة.
- **عرض واسع (نسبة الأبعاد 16:9)**: يوصى به لأجهزة العرض الحديثة والشاشات.

احرص على الاتساق في جميع شرائح العرض حيث يتم تطبيق حجم شريحة واحد ونسبة أبعاد واحدة على جميع الشرائح. للحصول على أفضل النتائج، اضبط أبعاد الشريحة في بداية عملية إنشاء العرض لتجنب التعقيدات.

{{% alert color="info" title="Note" %}}
By default, presentations created with Aspose.Slides use the standard 4:3 aspect ratio.
{{% /alert %}}

صفحات الملاحظات والملخصات لها أبعاد منفصلة عن الشرائح العادية. راجع [حجم صفحة الملاحظات](/slides/ar/java/notes-size/) لتغيير حجمها واتجاهها.

## **تغيير حجم الشريحة في العروض**

هذا المثال البرمجي يوضح لك كيفية تغيير حجم الشريحة في عرض PowerPoint بلغة Java باستخدام Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **تحديد أحجام شرائح مخصصة في العروض**

إذا وجدت أحجام الشرائح الشائعة (4:3 و 16:9) غير مناسبة لعملك، قد تقرر استخدام حجم شريحة محدد أو فريد. على سبيل المثال، إذا كنت تخطط لطباعة شرائح بحجم كامل من العرض على تخطيط صفحة مخصص أو إذا كنت تنوي عرض العرض على أنواع معينة من الشاشات، فستستفيد على الأرجح من ضبط حجم مخصص للعرض.

هذا المثال البرمجي يوضح لك كيفية استخدام Aspose.Slides for Java لتحديد حجم شريحة مخصص لعرض في Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // حجم ورق A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **معالجة محتوى الشريحة بعد تغيير الحجم**

بعد تغيير حجم الشريحة في عرض تقديمي، قد يتشوه محتوى الشرائح (مثل الصور أو الكائنات). بصورة افتراضية، يتم تغيير حجم الكائنات تلقائيًا لتتناسب مع حجم الشريحة الجديد. ومع ذلك، عند تغيير حجم الشريحة، يمكنك تحديد إعداد يحدد طريقة تعامل Aspose.Slides مع المحتوى على الشرائح.

اعتمادًا على ما تنوي القيام به أو تحقيقه، يمكنك استخدام أي من هذه الإعدادات:

- `DoNotScale`

  إذا كنت لا تريد أن يتم تغيير حجم الكائنات على الشرائح، استخدم هذا الإعداد.

- `EnsureFit`

  إذا كنت ترغب في التحجيم إلى حجم شريحة أصغر وتحتاج إلى أن تقوم Aspose.Slides بتصغير كائنات الشرائح لضمان ملاءتها جميعًا على الشرائح (وبهذا تتجنب فقدان المحتوى)، استخدم هذا الإعداد.

- `Maximize`

  إذا كنت ترغب في التحجيم إلى حجم شريحة أكبر وتحتاج إلى أن تقوم Aspose.Slides بتكبير كائنات الشرائح لجعلها متناسبة مع حجم الشريحة الجديد، استخدم هذا الإعداد.

هذا المثال البرمجي يوضح لك كيفية استخدام إعداد `Maximize` عند تغيير حجم شريحة العرض:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **الأسئلة الشائعة**

**هل يمكنني ضبط حجم شريحة مخصص باستخدام وحدات غير البوصة (مثلاً ، نقاط أو ملليمترات)؟**

نعم. تستخدم Aspose.Slides النقاط داخليًا، حيث يساوي 1 نقطة 1/72 من البوصة. يمكنك تحويل أي وحدة (مثل الملليمترات أو السنتيمترات) إلى نقاط واستخدام القيم المحولة لتحديد عرض وارتفاع الشريحة.

**هل سيؤثر حجم شريحة مخصص كبير جدًا على الأداء واستخدام الذاكرة أثناء التصيير؟**

نعم. الأبعاد الأكبر للشريحة (بالنقاط) جنبًا إلى جنب مع مقياس تصيير أعلى تؤدي إلى استهلاك أكبر للذاكرة وأوقات معالجة أطول. استهدف حجم شريحة عملي وقم بضبط مقياس التصيير فقط بحسب الحاجة لتحقيق الجودة المطلوبة للمخرجات.

**هل يمكنني تعريف حجم شريحة غير قياسي ثم دمج الشرائح من عروض تقديمية ذات أحجام مختلفة؟**

لا يمكنك [دمج العروض](/slides/ar/java/merge-presentation/) أثناء وجود أحجام شرائح مختلفة — أولاً، أعد تحجيم أحد العروض لتطابق الآخر. عند تغيير حجم الشريحة، يمكنك اختيار طريقة معالجة المحتوى الموجود عبر خيار [SlideSizeScaleType](https://reference.aspose.com/slides/ar/java/com.aspose.slides/slidesizescaletype/). بعد مواءمة الأحجام، يمكنك دمج الشرائح مع الحفاظ على التنسيق.

**هل يمكنني إنشاء صور مصغرة لأشكال فردية أو مناطق محددة من شريحة، وهل ستحترم حجم الشريحة الجديد؟**

نعم. يمكن لـ Aspose.Slides إنشاء صور مصغرة لـ [الشرائح الكاملة](https://reference.aspose.com/slides/ar/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) وكذلك لـ [الأشكال المحددة](https://reference.aspose.com/slides/ar/java/com.aspose.slides/shape/#getImage-int-float-float-). تعكس الصور الناتجة حجم الشريحة الحالي ونسبة الأبعاد، مما يضمن تأطيرًا وهندسةً متسقة.
