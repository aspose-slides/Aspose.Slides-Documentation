تم إصدار نسخة جديدة من [Aspose.Slides for Java API](https://docs.aspose.com/slides/ar/java/) والآن يدعم هذا المنتج إمكانية إنشاء مستندات PowerPoint من الصفر وتعديل المستندات الموجودة.

{{% /alert %}} 
## **دعم الكود القديم**
من أجل استخدام الكود القديم المطور باستخدام إصدارات Aspose.Slides for Java السابقة للنسخة 14.x.x، تحتاج إلى إجراء بعض التغييرات البسيطة في الكود وسيعمل كما كان سابقاً. جميع الفئات التي كانت موجودة في Aspose.Slides for Java القديمة تحت مساحات الأسماء com.aspose.slides و com.aspose.slides.pptx مدمجة الآن في مساحة اسم واحدة هي com.aspose.slides. يرجى إلقاء نظرة على المًقتطف البرمجي البسيط التالي لإنشاء رسم بياني عادي من الصفر في عرض تقديمي باستخدام API Aspose.Slides القديمة واتبع الخطوات التي تصف كيفية الهجرة إلى API المدمج الجديد.
