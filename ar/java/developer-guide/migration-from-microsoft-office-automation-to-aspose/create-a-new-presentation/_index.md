{{% alert color="info" %}} 

تم تطوير VSTO للسماح للمطورين بإنشاء تطبيقات يمكن تشغيلها داخل Microsoft Office. VSTO يعتمد على COM ولكنه ملفوف داخل كائن .NET بحيث يمكن استخدامه في تطبيقات .NET. يحتاج VSTO إلى دعم .NET Framework بالإضافة إلى وقت تشغيل Microsoft Office القائم على CLR. على الرغم من أنه يمكن استخدامه لإنشاء إضافات Microsoft Office، إلا أنه يكاد يكون غير قابل للاستخدام كمكوّن من جانب الخادم. كما أنه يواجه مشكلات جدية في النشر.

Aspose.Slides for Java هو مكوّن يمكن استخدامه للتعامل مع عروض PowerPoint التقديمية، تمامًا مثل VSTO، لكنه يمتلك عدة مزايا:

- يحتوي Aspose.Slides على شفرة مُدارة فقط ولا يتطلب تثبيت وقت تشغيل Microsoft Office.
- يمكن استخدامه كمكوّن من جانب العميل أو كمكوّن من جانب الخادم.
- النشر سهل لأن Aspose.Slides موجود في ملف jar واحد.
