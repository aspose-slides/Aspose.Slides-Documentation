## **مرحبًا بك في Aspose.Slides for Java!**

Aspose.Slides for Java هو واجهة برمجة تطبيقات لإدارة Microsoft PowerPoint® تتيح لتطبيقات Java قراءة وكتابة مستندات PowerPoint® بدون الحاجة إلى Microsoft PowerPoint®.

Aspose.Slides for Java هو أول مكوّن وحيد يوفّر الوظائف المطلوبة لإدارة مستندات PowerPoint®.

يوفر Aspose.Slides for Java العديد من الميزات الأساسية مثل إدارة النصوص والأشكال والجداول والرسوم المتحركة، وإضافة ملفات الصوت والفيديو إلى الشرائح، ومعاينة الشرائح، وتصدير الشرائح إلى SVG وPDF وغيرها من الصيغ.

## **وصف المنتج**

لا يقتصر Aspose.Slides for Java على تمكينك من فتح ملفات PowerPoint من مصادر مختلفة فحسب، بل يسمح لك أيضًا بحفظ عروضك التقديمية بطرق متعددة. على سبيل المثال، يمكنك حفظ عروضك بصيغة PPT؛ كما يمكنك حفظ الشرائح كصور.

يوفر لك Aspose.Slides for Java تقريبًا جميع الميزات التي قد تجدها أو لا تجدها في Microsoft PowerPoint. نظرًا لتعدد استخدامات Aspose.Slides for Java، بجانب الجداول وأنواع الأشكال المختلفة، يمكنك أيضًا إضافة أنواع مختلفة من الإطارات—نصية، صوتية، وإطارات فيديو—إلى الشرائح.

كما يقدم Aspose.Slides for Java عروضًا تجريبية كاملة الوِجهات وأمثلة عملية للمطورين لفهم الواجهة برمجة التطبيقات بشكل أفضل.

### **ميزات العرض التقديمي**

- فتح عروض Microsoft PowerPoint من مصادر مختلفة.
- حفظ العروض بصيغ Microsoft PowerPoint المختلفة.
- إنشاء عروض تقديمية من الصفر.
- تحويل العروض إلى مستندات PDF دون استخدام أي مكوّن آخر.
- القدرة على قراءة ملفات Open Document Presentation (ODP).
- القدرة على تحويل PPT إلى PPTX أو العكس.
- قراءة أو تعديل خصائص مستند العرض.
- تصدير العروض إلى PDF
- تصدير العروض إلى TIFF
- تصدير العروض إلى XPS
- تصدير العروض إلى SWF
- تصدير ملاحظات العرض إلى PDF / ملاحظات TIFF
- تصدير العروض إلى HTML

### **ميزات الشرائح**

- إنشاء شرائح جديدة من الصفر وإضافتها إلى العروض.
- الوصول إلى أي شريحة عبر موقعها في العرض.
- نسخ أو استنساخ الشرائح إلى نفس العرض أو عرض آخر.
- تحرير وحذف الشرائح.
- نسخ القوالب مع الشرائح تلقائيًا.
- معاينة الشرائح.
- الحصول على اسم الشريحة أو تعيينه.
- حفظ الشرائح كصور.
- تصدير الشرائح إلى صيغة SVG.
- العمل مع العديد من القوالب في العروض.
- ملء خلفية الشرائح بأي نمط مدعوم.
- إضافة ملاحظات شريحة جديدة أو إدارة الملاحظات الحالية.
- تعيين قوالب الشرائح الجديدة والأنماط بشكل ديناميكي.
- إضافة أو تعديل انتقال عرض الشرائح.
- إضافة انتقالات Morph

### **ميزات الرسومات والوسائط المتعددة**

- إنشاء أو إدارة الأشكال مثل الخطوط، المستطيلات، الأقواس، والمتعددات الخطية.
- إدارة أنماط الخطوط في الأشكال.
- الحصول على النص البديل للشكل.
- تدوير أو قلب الأشكال.
- ملء الأشكال بأنماط مختلفة، مثل الصلبة، التدرجية، النمطية، القوام والصورة.
- استخدام أي من الأنماط المحددة مسبقًا البالغ عددها 48 نمطًا و24 قوامًا.
- إسناد روابط إلى الأشكال.
- قراءة وتعديل وإضافة تأثيرات حركية جديدة إلى الشرائح والأشكال.
- إضافة صور جديدة إلى العروض وإدارة الصور الموجودة.
- إضافة نقاط صور جديدة إلى العروض وإدارة النقاط القائمة.
- إضافة إطارات صوتية جديدة إلى العروض وإدارة الإطارات القائمة.
- إضافة إطارات فيديو جديدة إلى العروض وإدارة الإطارات القائمة.

### **ميزات الجداول**

- إنشاء جداول من الصفر وإضافتها إلى الشرائح.
- تغيير حجم الجداول وتحريكها.
- الوصول إلى أي خلية في الجدول.
- تغيير تنسيق وحدود أي خلية.
- تغيير حجم الأعمدة والصفوف.
- إضافة وحذف الأعمدة والصفوف.
- ضبط عرض الحدود ولونها للجدول بأكمله.
- تطبيق أنماط مسبقة على الجداول

### **ميزات النص والفقرات**

- الحصول على النصوص وتعيينها في نواقل النص وإطارات النص.
- الحصول على نوع الناقل.
- تغيير تنسيق النص في إطار النص.
- إضافة خطوط جديدة أو إدارة الخطوط المستخدمة بالفعل في العرض.
- تغيير النصوص وتنسيق النص.
- إنشاء أو إدارة الروابط النصية.
- دعم الفواصل وعلامات التبويب الفعّالة.
- إضافة إطارات نص جديدة إلى تقريبًا أي نوع من الأشكال.
- الوصول إلى الهوامش وتعديل إعدادات لف النص لإطارات النص.
- الوصول إلى مسافة الفقرة وتعديلها.

### **ميزات متقدمة**

- الوصول إلى كائنات OLE المدمجة في العروض.
- قفل العروض.
- إضافة علامات مائية إلى العروض.
- تطبيق الرسوم المتحركة على الأشكال داخل الشرائح.

## **الأسئلة الشائعة**

### هل يدعم مستويات التوافق PDF للأرشفة وسهولة الوصول (PDF/A و PDF/UA)؟

نعم. يمكنك الحفظ إلى PDF مع PDF/A-2a/2b/2u، PDF/A-3a/3b، وكذلك PDF/UA عن طريق تكوين [خيارات تصدير PDF](https://reference.aspose.com/slides/ar/java/com.aspose.slides/pdfoptions/).

### هل هناك آلية استبدال الخطوط ودعم للخطوط المخصصة لضمان عرض صحيح؟

نعم. تتيح المكتبة لك [تحميل الخطوط المخصصة](/slides/ar/java/custom-font/) و[تحديد قواعد الاحتياطي](/slides/ar/java/fallback-font/) بحيث يتم استبدال الحروف المفقودة بشكل موثوق أثناء التحويل والعرض.

### هل يمكنني اكتشاف ما إذا كان الملف محميًا بكلمة مرور دون فتحه بالكامل؟

نعم. يمكنك [فحص العرض](/slides/ar/java/examine-presentation/) لتحديد ما إذا كان يتطلب كلمة مرور قبل تحميل المستند بالكامل.

### هل يلزم وجود Microsoft PowerPoint للمعالجة والتحويلات؟

لا. Aspose.Slides هو محرك مستقل؛ لا يلزم وجود PowerPoint على الخادم أو محطة العمل.

### هل من الآمن معالجة العروض من عدة خيوط؟

نعم، يمكنك معالجة مستندات مختلفة بشكل متوازي في خيوط منفصلة؛ فقط تجنب استخدام نفس نسخة العرض بشكل متزامن [عبر الخيوط](/slides/ar/java/multithreading/).

### هل يتم حفظ الماكروهات ويمكنني إدارة VBA في ملفات PPTM/PPSM؟

نعم. العروض التي تحتوي على ماكروهات [مدعومة](/slides/ar/java/presentation-via-vba/)، ويمكنك [فحص وإدارة مشروعات VBA](https://reference.aspose.com/slides/ar/java/com.aspose.slides/presentation/#getVbaProject--) في تلك الملفات.

### هل يمكنني تحويل PDF أو HTML مرة أخرى إلى شرائح PowerPoint؟

نعم. يمكنك [استيراد صفحات PDF أو محتوى HTML](/slides/ar/java/import-presentation/) لإنشاء أو ملء الشرائح في عرض تقديمي.

### هل يتم دعم تصدير XPS، وهل يمكنني التحكم في جودة ومحتوى مخرجات XPS؟

نعم. [التصدير إلى XPS](/slides/ar/java/convert-powerpoint-to-xps/) متاح، و[خيارات الحفظ](https://reference.aspose.com/slides/ar/java/com.aspose.slides/xpsoptions/) تتيح لك ضبط جودة المخرجات والمحتوى المتضمن.

### هل يمكنني تحويل الشرائح إلى صور والتحكم في جودة المخرجات؟

نعم. يمكن [تحويل الشرائح إلى PNG وJPEG وGIF وBMP وTIFF](/slides/ar/java/convert-powerpoint-to-png/) وغيرها من الصيغ مع تحكم دقيق في الحجم والجودة.

### هل يتم دعم الصيغ الرياضية (MathML/MathText) وهل يمكن تصديرها؟

نعم. يمكنك [إنشاء وتحرير النص الرياضي](/slides/ar/java/powerpoint-math-equations/) و[تصدير المعادلات](/slides/ar/java/exporting-math-equations/)، بما في ذلك إلى MathML.

### كيف تتعامل المكتبة مع التشفير وكلمات المرور (الفتح، التعيين، الإزالة)؟

[إنها تدعم](/slides/ar/java/password-protected-presentation/) فتح العروض المشفرة، وتعيين أو إزالة كلمات المرور للفتح والتعديل، والتحقق من حالة حماية الملف.
