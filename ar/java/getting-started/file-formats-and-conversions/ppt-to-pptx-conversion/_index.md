## **الميزات المدعومة في التحويل**
توفر Aspose.Slides for Java دعمًا جزئيًا لتحويل تنسيق ملف PPT إلى PPTX. تم إدخال دعم التحويل مؤخرًا إلى Aspose.Slides for Java، لذا يحتوي على بعض القيود ويعمل بشكل أفضل للعرض التقديمي البسيط. الميزة الرئيسية التي توفرها Aspose.Slides for Java عند تحويل PPT إلى PPTX هي سهولة استخدام API. لرؤية أمثلة على الشيفرة، اقرأ عن [تحويل PPT إلى PPTX](). أدناه، توضح القوائم أي الميزات مدعومة وأيها غير مدعومة في تحويل PPT إلى PPTX.

## **الميزات المدعومة**
الميزات التالية مدعومة للتحويل:

- تحويل بنية القوالب الأساسية، التخطيطات والشرائح.
- تحويل المخططات.
- مجموعات الأشكال.
- تحويل الأشكال الذاتية بما في ذلك المستطيلات والبيضات.
- الأشكال ذات الهندسة المخصصة.
- نقوش وصور أنماط تعبئة للأشكال الذاتية.
- تحويل العناصر النائبة.
- تحويل الخطوط والمتعددات.
- تنسيقات الخط والتعبئة.
- أنماط تعبئة التدرج.
- إطارات OLE، الجداول، إطارات الفيديو والصوت، إلخ.
- خصائص الرسوم المتحركة وعرض الشرائح.
- تحويل النص في إطارات النص وحاملات النص.
