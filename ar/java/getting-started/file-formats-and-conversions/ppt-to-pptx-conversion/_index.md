## **الميزات المدعومة في التحويل**
توفر Aspose.Slides for Java دعماً جزئياً لتحويل تنسيق ملف PPT إلى PPTX. تم تقديم دعم التحويل حديثاً في Aspose.Slides for Java، لذا يحتوي على بعض القيود ويعمل بشكل أفضل مع العروض التقديمية البسيطة. الميزة الرئيسية التي توفرها Aspose.Slides for Java عند تحويل PPT إلى PPTX هي سهولة استخدام واجهة برمجة التطبيقات. لرؤية أمثلة على الشيفرة، راجع [تحويل PPT إلى PPTX](/slides/ar/java/convert-ppt-to-pptx/). القائمة أدناه توضح الميزات المدعومة لتحويل PPT إلى PPTX.

## **الميزات المدعومة**
الميزات التالية مدعومة للتحويل:

- تحويل هيكل القوالب الرئيسية، التخطيطات والشرائح.
- تحويل المخططات.
- الأشكال المجموعة.
- تحويل الأشكال التلقائية بما في ذلك المستطيلات والدوائر البيضوية.
- الأشكال ذات الهندسة المخصصة.
- أنماط تعبئة القوام والصور للأشكال التلقائية.
- تحويل العناصر النائبة.
- تحويل الخطوط والمتعددة الخطوط.
- تنسيقات الخط والتعبئة.
- أنماط تعبئة التدرج.
- إطارات OLE، الجداول، إطارات الفيديو والصوت، إلخ.
- خصائص الرسوم المتحركة وعروض الشرائح.
- تحويل النص في إطارات النص وحاملات النص.
