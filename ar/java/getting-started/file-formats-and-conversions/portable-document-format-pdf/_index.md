{{% alert color="info" %}} 

[تنسيق المستندات القابل للنقل](https://en.wikipedia.org/wiki/PDF) هو تنسيق ملف أنشأته شركة Adobe Systems لتبادل المستندات بين المؤسسات. كان هدف تنسيق الملف هو الحفاظ على المحتوى والتخطيط كما هو، بغض النظر عن المنصة التي يُعرض عليها. تتيح لك Aspose.Slides for Java تحويل ملفات العروض التقديمية إلى PDF.

{{% /alert %}} 

## **PDF في Aspose.Slides لـ Java**
يمكن تحويل أي عرض تقديمي يمكن تحميله في Aspose.Slides for Java إلى PDF يتوافق مع [PDF 1.5](https://en.wikipedia.org/wiki/PDF/A)، [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A)، [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) أو [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) حسب اختيارك. تقوم Aspose.Slides for Java بتصدير العروض التقديمية إلى PDF وفي معظم الحالات يبدو PDF الناتج مطابقًا تمامًا للعرض التقديمي الأصلي.

تدعم Aspose.Slides الميزات التالية عند التحويل إلى PDF:

- الصور، مربعات النص وغيرها من الأشكال.
- النص والتنسيق.
- الفقرات والتنسيق.
- الروابط التشعبية.
- الترويسات وتذييلات الصفحات.
- القوائم المنقطة.
- الجداول.

يمكنك تصدير العروض التقديمية إلى PDFs مباشرةً باستخدام Aspose.Slides for Java: لا تحتاج إلى أي مكوّن آخر. علاوةً على ذلك، يمكنك تخصيص تصدير العرض التقديمي إلى PDF باستخدام خيارات متعددة كما هو موضح في [تحويل إلى PDF](/slides/ar/java/converting-a-presentation/).
