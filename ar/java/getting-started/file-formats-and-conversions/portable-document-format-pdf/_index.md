ال[تنسيق المستندات المحمولة](https://en.wikipedia.org/wiki/PDF) هو صيغة ملفات أنشأتها Adobe Systems لتبادل المستندات بين المنظمات. هدف الصيغة هو الحفاظ على المحتوى والتخطيط كما هو، بغض النظر عن المنصة التي يتم عرضها عليها. يتيح لك Aspose.Slides for Java تحويل ملفات العروض التقديمية إلى PDF.

{{% /alert %}}

## **PDF في Aspose.Slides for Java**
يمكن تحويل أي عرض تقديمي يمكن تحميله في Aspose.Slides for Java إلى PDF يتوافق مع [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) أو [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) حسب اختيارك. يصدر Aspose.Slides for Java العروض التقديمية إلى PDF وفي معظم الحالات يكون ملف PDF الناتج مطابقاً تماماً للعرض الأصلي.

يدعم Aspose.Slides الميزات التالية في العروض التقديمية عند التحويل إلى PDF:

- الصور، مربعات النص والأشكال الأخرى.
- النص والتنسيق.
- الفقرات والتنسيق.
- الروابط الفائقة.
- الترويسات والتذييلات.
- القوائم النقطية.
- الجداول.

يمكنك تصدير العروض التقديمية إلى ملفات PDF مباشرةً باستخدام Aspose.Slides for Java: لا تحتاج إلى أي مكوّن آخر. علاوةً على ذلك، يمكنك تخصيص تصدير العرض إلى PDF باستخدام خيارات متعددة كما هو موضح في [تحويل PPT و PPTX إلى PDF](/slides/ar/java/convert-powerpoint-to-pdf/).
