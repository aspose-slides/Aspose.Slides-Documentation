## **نظرة عامة**

يمكن استخدام Aspose.Slides في وضع التقييم أو باستخدام ترخيص صالح. يوفر الإصدار التجريبي نفس وظائف الإصدار المرخص، ولكنه يضيف علامة مائية للتقييم عند فتح أو حفظ العروض التقديمية ويقيد استخراج النص إلى شريحة واحدة.

تشرح هذه المقالة كيف يعمل الترخيص في Aspose.Slides وكيفية تطبيق ترخيص قبل استخدام المكتبة. يمكن تحميل الترخيص من ملف أو تدفق أو مورد مضمّن باستخدام الفئة `License`. كما تظهر المقالة كيفية التحقق مما إذا تم تطبيق الترخيص بشكل صحيح.

بمجرد أن تكون راضيًا عن تقييمك لـ **Aspose.Slides**، يمكنك [purchase a license](https://purchase.aspose.com/buy). نوصيك بالاطلاع على أنواع الاشتراكات المختلفة. إذا كان لديك أسئلة، تواصل مع فريق مبيعات Aspose.

كل ترخيص Aspose يأتي مع اشتراك سنة واحدة لترقيات مجانية إلى الإصدارات الجديدة أو التصحيحات التي تصدر خلال فترة الاشتراك. يحصل المستخدمون الذين لديهم منتجات مرخصة (أو حتى إصدارات تجريبية) على دعم فني مجاني وغير محدود.

## **الترخيص في Aspose.Slides**

* يصبح الإصدار التجريبي مرخصًا بعد شراء ترخيص وإضافة بضع أسطر من الكود إليه (لتطبيق الترخيص).
* الترخيص هو ملف XML نصي بسيط يحتوي على تفاصيل مثل اسم المنتج، عدد المطورين المسموح لهم باستخدامه، تاريخ انتهاء الاشتراك، وما إلى ذلك. 
* ملف الترخيص موقع رقمياً، لذا لا يجب تعديل الملف. حتى إضافة سطر فارغ غير مقصودة إلى محتويات الملف سيؤدي إلى إبطال صلاحية الترخيص.
* عادةً ما يحاول Aspose.Slides for Java العثور على الترخيص في المواقع التالية:
  * مسار صريح
  * المجلد الذي يحتوي على Aspose.Slides.jar
* لتجنب القيود المرتبطة بالإصدار التجريبي، يجب عليك تعيين ترخيص قبل استخدام **Aspose.Slides**. عليك تعيين الترخيص مرة واحدة فقط لكل تطبيق أو عملية.

{{% alert color="info" %}} 

قد ترغب في الاطلاع على [Metered Licensing](/slides/ar/java/metered-licensing/).

{{% /alert %}} 


## **تطبيق الترخيص**

يمكن تحميل الترخيص من **ملف** أو **تدفق**.

{{% alert color="info" %}}

توفر Aspose.Slides الفئة [License](https://reference.aspose.com/slides/ar/java/com.aspose.slides/License) لعمليات الترخيص.

{{% /alert %}} 

{{% alert color="warning" %}}

يمكن للتراخيص الجديدة تفعيل Aspose.Slides فقط مع الإصدار 21.4 أو أحدث. الإصدارات السابقة تستخدم نظام ترخيص مختلف ولن تتعرف على هذه التراخيص.

{{% /alert %}}

### **ملف**

أبسط طريقة لتعيين ترخيص هي وضع ملف الترخيص في المجلد الذي يحتوي على Aspose.Slides.jar أو ملف jar الخاص بتطبيقك.

يعرض هذا الكود Java كيفية تعيين ملف ترخيص:

``` java
// ينشئ كائن الفئة License
com.aspose.slides.License license = new com.aspose.slides.License();

// يضبط مسار ملف الترخيص
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" %}} 

إذا وضعت ملف الترخيص في دليل مختلف، عند استدعاء طريقة [SetLicense](https://reference.aspose.com/slides/ar/java/com.aspose.slides/License#setLicense-java.lang.String-)، يجب أن يكون اسم ملف الترخيص في النهاية مطابقًا لاسم ملف الترخيص الخاص بك.

على سبيل المثال، يمكنك تغيير اسم ملف الترخيص إلى *Aspose.Slides.Java.lic.xml*. ثم، في الكود الخاص بك، يجب تمرير المسار إلى الملف (الذي ينتهي بـ *Aspose.Slides.Java.lic.xml*) إلى طريقة [SetLicense](https://reference.aspose.com/slides/ar/java/com.aspose.slides/License#setLicense-java.lang.String-).

{{% /alert %}}

### **دفق**

يمكنك تحميل ترخيص من تدفق. يعرض هذا الكود Java كيفية تطبيق ترخيص من تدفق:

``` java
// ينشئ كائن الفئة License
com.aspose.slides.License license = new com.aspose.slides.License();

// يضبط الترخيص عبر تدفق
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **جسر PHP/Java**

إذا كنت تستخدم Aspose.Slides للـ PHP عبر Java، يمكنك تعيين ترخيص عبر جسر PHP/Java. يتيح لك هذا الجسر استخدام فئات Java بصيغة PHP. لمزيد من المعلومات، راجع [License in PHP](/slides/ar/php-java/licensing/).

## **التحقق من الترخيص**

للتحقق مما إذا تم تعيين الترخيص بشكل صحيح، يمكنك التحقق منه. يعرض هذا الكود Java كيفية التحقق من الترخيص:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **سلامة الخيوط**

{{% alert title="Note" color="warning" %}} 

طريقة [SetLicense](https://reference.aspose.com/slides/ar/java/com.aspose.slides/License#setLicense-java.io.InputStream-) ليست آمنة عند الاستخدام المتعدد للخطوط. إذا كان يجب استدعاء هذه الطريقة في نفس الوقت من عدة خطوط، قد ترغب في استخدام آليات المزامنة (مثل القفل) لتجنب المشكلات. 

{{% /alert %}}

## **الأسئلة الشائعة**

### هل يمكنني تطبيق الترخيص في بيئة غير متصلة بالإنترنت تمامًا (بدون وصول إلى الإنترنت)؟

نعم. يتم التحقق من الترخيص محليًا باستخدام ملف الترخيص؛ لا يلزم اتصال بالإنترنت.

### ماذا يحدث بعد انتهاء الاشتراك السنوي؟ هل سيتوقف المكتبة عن العمل؟

لا. الترخيص دائم: يمكنك الاستمرار في استخدام الإصدارات التي صدرت قبل تاريخ انتهاء اشتراكك؛ لن تكون قادرًا على استخدام الإصدارات الأحدث دون تجديد الاشتراك.
