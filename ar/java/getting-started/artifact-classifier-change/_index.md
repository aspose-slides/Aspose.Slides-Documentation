## **تغيير مصنف القطعة من `jdk16` إلى `jdk8`**

بدءًا بالإصدار **26.10**، قمنا بتغيير المصنف المستخدم في القطع المنشورة من **`jdk16`** (Java 6) إلى **`jdk8`** (Java 8).

### **ما تم تغييره**

| | قبل | بعد |
|---|---|---|
| المصنف | `jdk16` | `jdk8` |
| إصدار Java الأدنى | Java 1.6 | Java 8 |

**قبل:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**بعد:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **لماذا أجرينا هذا التغيير**

بعد مراجعة داخلية، قررنا **إلغاء الدعم لإصدارات Java القديمة** التي لم تعد تقدم قيمة وكانت تُعيق الصيانة بشكل فعال. تم اختيار Java 8 كخط أساس جديد وآمن لجميع المستهلكين.

كجزء من ذلك، تم تحديث المصنف ليعكس الحد الأدنى الفعلي للإصدار المدعوم. كما توافقنا مع تسمية Oracle الحالية، حيث يُشار إلى المنتج رسميًا باسم **JDK 8** (بدلاً من صيغة `1.8` القديمة).

### **ما الذي تحتاج إلى القيام به**

1. **تحديث المصنف** في إعلانات التبعيات الخاصة بك من `jdk16` إلى `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **تحقق من بيئة التشغيل الخاصة بك** هي Java 8 أو أعلى.

3. **تحديث أي ملفات قفل** أو مخازن التبعيات التي تثبت المصنف القديم.

### **ملاحظة الانتقال: jdk16 و jdk8**

بدءًا بالإصدار 26.10​، سيُوفر كلا المصنفين jdk16 و jdk8 ملفات JAR متوافقة مع Java 8 (تم بناؤها مع تعيين التوافق المصدر/الهدف إلى Java 8).

- `jdk16` → يستمر في النشر لتوافقية النسخ السابقة (التكاملات الحالية).
- `jdk8` → تم تقديمه كمصنف مفضل جديد لبيئات Java 8.

⚠️ ملاحظة: من المقرر أن تنتهي مرحلة النشر المزدوجة في 31 مارس 2027​. بعد هذا التاريخ، سيتم إيقاف المصنف jdk16، وسيتم دعم jdk8 فقط.

### **ملاحظات التوافق**

- المصنف `jdk16` **لم يعد يُنشر** بعد **31 مارس 2027**.
- إذا ما زلت تحتاج إلى دعم Java 1.6، يرجى البقاء على خط الإصدار الرئيسي السابق حتى تتمكن من الانتقال.
