## تم تغيير مصنف الأداة من `jdk16` إلى `jdk8`

بدءاً من الإصدار **26.10**، قمنا بتغيير المصنف المستخدم في الحزم التي ننشرها من **`jdk16`** (Java 6) إلى **`jdk8`** (Java 8).

### ما تم تغييره

| | قبل | بعد |
|---|---|---|
| المصنف | `jdk16` | `jdk8` |
| الحد الأدنى لإصدار Java | Java 1.6 | Java 8 |

**قبل:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**بعد:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### لماذا قمنا بهذا التعديل

بعد مراجعة داخلية، قررنا **إلغاء الدعم لإصدارات Java القديمة** التي لم تعد تقدم قيمة وكانت تُعقِّد الصيانة. تم اختيار Java 8 كأساس آمن جديد لجميع المستهلكين.

كجزء من ذلك، تم تحديث المصنف ليعكس الحد الأدنى الفعلي للنسخة المدعومة. كما توافقنا مع تسمية Oracle الحالية، حيث يُشار إلى المنتج رسمياً باسم **JDK 8** (بدلاً من الصيغة القديمة `1.8`).

### ما تحتاج إلى فعله

1. **تحديث المصنف** في إعلانات التبعيات من `jdk16` إلى `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **التحقق من بيئة التشغيل** لتكون Java 8 أو أعلى.

3. **تحديث أي ملفات قفل** أو ذاكرات التبعيات التي تثبت المصنف القديم.

### ملاحظة الترحيل: jdk16 و jdk8

بدءاً من الإصدار 26.10​، سيقدم كلا المصنفين jdk16 و jdk8 ملفات JAR متوافقة مع Java 8 (تم بناءها مع تعيين توافق المصدر/الهدف إلى Java 8).

- `jdk16` → يُستمر في نشره للتوافق الرجعي (التكاملات الحالية).
- `jdk8` → تم تقديمه كمصنف مفضل جديد لبيئات Java 8.

⚠️ ملاحظة: من المقرر انتهاء مرحلة النشر المزدوجة في 31 مارس 2027​. بعد هذا التاريخ، سيتم إيقاف مصنف jdk16، ولن يدعم إلا jdk8.

### ملاحظات التوافق

- لا يُنشر المصنف `jdk16` **بعد 31 مارس 2027**.
- إذا كنت لا تزال تحتاج إلى دعم Java 1.6، يرجى البقاء على خط الإصدار الرئيسي السابق حتى تستطيع الترحيل.
