## **تغيير مصنف العنصر من `jdk16` إلى `jdk8`**

بدءًا من الإصدار **26.10**، قمنا بتغيير المصنف المستخدم في الحزم المنشورة من **`jdk16`** (Java 6) إلى **`jdk8`** (Java 8).

### **ما الذي تغير**

| | قبل | بعد |
|---|---|---|
| المصنف | `jdk16` | `jdk8` |
| الحد الأدنى لإصدار Java | Java 1.6 | Java 8 |

**قبل:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**بعد:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **لماذا قمنا بإجراء هذا التغيير**

بعد مراجعة داخلية، قررنا **إلغاء الدعم لإصدارات Java القديمة** التي لم تعد توفر قيمة وكانت تعيق الصيانة. تم اختيار Java 8 كأساس آمن جديد لجميع المستهلكين.

كجزء من ذلك، تم تحديث المصنف ليعكس الحد الأدنى الفعلي للإصدار المدعوم. كما توافقنا مع تسمية Oracle الحالية، حيث يُشار إلى المنتج رسميًا باسم **JDK 8** (بدلاً من صيغة `1.8` القديمة).

### **ما الذي تحتاج إلى القيام به**

1. **تحديث المصنف** في تعريفات الاعتمادات من `jdk16` إلى `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **التحقق من بيئة التشغيل** للتأكد من أنها Java 8 أو أعلى.

3. **تحديث أي ملفات قفل** أو مخازن الاعتمادات التي تثبت المصنف القديم.

### **ملاحظة الترحيل: jdk16 و jdk8**

بدءًا من الإصدار 26.10، سيقدم كل من المصنفين jdk16 و jdk8 ملفات JAR متوافقة مع Java 8 (تم إعداد توافق المصدر/الهدف على Java 8).

- `jdk16` → يظل منشورًا للتوافق مع الإصدارات السابقة (التكاملات القائمة).
- `jdk8` → تم تقديمه كمصنف مفضل جديد لبيئات Java 8.

⚠️ ملاحظة: من المقرر أن تنتهي مرحلة النشر المزدوجة في 31 مارس 2027. بعد هذا التاريخ، سيتم إيقاف مصنف jdk16، وسيُدعم فقط jdk8.

### **ملاحظات التوافق**

- مصنف `jdk16` **لن يتم نشره** بعد **31 مارس 2027**.
- إذا كنت لا تزال تحتاج إلى دعم Java 1.6، يرجى البقاء على خط الإصدار الرئيسي السابق حتى تتمكن من الترحيل.
