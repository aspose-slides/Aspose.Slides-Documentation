لتحويل عرض تقديمي في مكتبة المستندات:

1. افتح قائمة ملف PPT أو PPTX (كتلة التحكم في التحرير) واختر **تحويل عبر Aspose.Slides**. في SharePoint 2007، يُسمّى عنصر القائمة **تحويل باستخدام Aspose.Slides**.

   **تحديد تحويل باستخدام Aspose.Slides في قائمة مستند على SharePoint 2007**

   ![قائمة مستند في مكتبة مستندات SharePoint 2007، مع عنصر تحويل باستخدام Aspose.Slides](convert-one-file_1.png)

2. في صفحة التحويل، اختر تنسيق الإخراج تحت **تحويل إلى**. إذا رغبت، غيّر اسم الملف الوجهة ومجلد الوجهة.  
3. اضغط **تحويل**.  
4. عند اكتمال التحويل، اضغط **مكتبة المصدر** أو **مكتبة الوجهة** للعودة إلى مكتبة المستندات. الملف المحوّل موجود في المجلد الوجهة.

الخطوات نفسها، مع لقطات شاشة لكل صفحة، موجودة في [تحويل مستندات Microsoft PowerPoint إلى صيغ أخرى](/slides/ar/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
