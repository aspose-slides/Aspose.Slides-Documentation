{{% alert color="info" title="ملاحظة" %}}

مع Aspose.Slides for SharePoint، يمكنك تحويل عروض PowerPoint إلى العديد من صيغ المستندات الشائعة من داخل مكتبة مستندات SharePoint.

{{% /alert %}}

## **الصيغ المدخلة المدعومة**

يقوم Aspose.Slides for SharePoint بتحويل الصيغ المدخلة التالية:

- PPT – عرض تقديمي Microsoft PowerPoint 97 - 2003
- PPTX – عرض تقديمي Office Open XML

{{% alert color="info" title="ملاحظة" %}}

لتحويل المستندات، يعتمد Aspose.Slides for SharePoint على نسخة مدمجة من [Aspose.Slides for .NET](https://products.aspose.com/slides/ar/net/).

{{% /alert %}}

## **الصيغ المخرجة المدعومة**

قائمة **Convert to** في صفحة التحويل تقدم الصيغ المخرجة التالية، بهذا الترتيب:

- PDF – مستند Adobe محمول
- TIFF – حزمة صور
- XPS – مواصفة ورق XML
- PPS – عرض شرائح تقديمي
- PPSX – عرض شرائح Microsoft PowerPoint Open XML
- ODP – عرض تقديمي OpenDocument
- PPTM – عرض تقديمي Microsoft PowerPoint Open XML مع تمكين الماكرو
- PPSM – عرض شرائح Microsoft PowerPoint Open XML مع تمكين الماكرو
- POTX – قالب Microsoft PowerPoint
- POTM – قالب عرض تقديمي Microsoft PowerPoint Open XML مع تمكين الماكرو
- PDFNotes – ملاحظات العرض التقديمي بصيغة PDF
- HTML – عرض تقديمي بصيغة HTML
- TIFFNotes – ملاحظات العرض التقديمي كصورة TIFF متعددة الصفحات
- SWF – فيلم Shockwave Flash
- SWFNotes – ملاحظات العرض التقديمي كفيلم SWF متعدد الصفحات

**اختيار الصيغة المخرجة في صفحة إعدادات التحويل**
