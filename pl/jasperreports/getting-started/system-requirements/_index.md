## **JasperReports**

Aspose.Slides for JasperReports działa z JasperReports od wersji 3.7.2 do 6.16.0. Pobranie zawiera osobny plik jar dla każdego z trzech zakresów wersji — zobacz [Installing Aspose.Slides for JasperReports](/slides/pl/jasperreports/installing-aspose-slides-for-jasperreports/) aby dowiedzieć się, którego użyć. Nie ma pliku jar dla JasperReports 6.17.0 i późniejszych, w tym JasperReports 7.

Wsparcie dla JasperReports 2.0.3 do 3.7.1 zakończono w Aspose.Slides for JasperReports 17.6. Wersja 17.5 i wcześniejsze również obsługiwały te wersje.

## **Java**

Pliki jar są kompilowane dla Java 6 lub nowszej, co wskazuje *JDK 1.6* w nazwach ich katalogów, dlatego wymagana wersja Java jest taka sama, jakiej wymaga Twoja wersja JasperReports. W przypadku JasperReports 6.16.0, eksporty działają na Java 11, 17, 21 i 25.

## **System operacyjny**

Pliki jar zawierają wyłącznie klasy i zasoby Java, bez bibliotek natywnych i nie używają Microsoft PowerPoint. W systemie Linux JasperReports wymaga fontconfig oraz co najmniej jednej zainstalowanej czcionki, aby wypełnić raport.

## **JasperReports Server**

W przypadku JasperReports Server użyj obu plików jar z folderu odpowiadającego wersji JasperReports, której używa Twój serwer — zobacz [Integration with JasperServer](/slides/pl/jasperreports/integration-with-jasperserver/).
