{{% alert color="info" %}} 

Aspose.Slides for Android via Java jest biblioteką klas, która umożliwia aplikacjom Java dla Androida odczytywanie i zapisywanie dokumentów prezentacji bez użycia Microsoft PowerPoint® ani innego oprogramowania. Aspose.Slides for Android via Java pozwala zarządzać tekstem, kształtami, tabelami i animacjami; dodawać dźwięk i wideo do slajdów; podglądać slajdy; oraz eksportować slajdy do formatu SVG, PDF i innych.

Najnowszą dokumentację API można znaleźć w [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/pl/androidjava/).

{{% /alert %}}
