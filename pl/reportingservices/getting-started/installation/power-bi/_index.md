## **Power BI**

Możesz zainstalować Aspose.Slides for Reporting Services na serwerze Power BI Report Server, korzystając z tych samych procesów instalacji:

* [Install with MSI Installer](/slides/pl/reportingservices/install-with-msi-installer/). Program instalacyjny automatycznie wykrywa zainstalowany Power BI Report Server, instaluje produkt, a następnie konfiguruje go dla Twojego środowiska pracy.
* [Install Manually](/slides/pl/reportingservices/install-manually/). Użyj zestawu z folderu *Bin\Universal* pakietu ZIP.

Aspose.Slides for Reporting Services eksportuje raporty stronicowane (RDL) z serwera Power BI Report Server. Aby poznać wymagania, w tym .NET Framework 3.5 na maszynie hosta, zobacz [Wymagania systemowe](/slides/pl/reportagingservices/system-requirements/).
