Aspose.Slides for Reporting Services jest rozszerzeniem renderującym dla Microsoft SQL Server Reporting Services i Power BI Report Server, które dodaje formaty prezentacji do listy eksportu raportów stronicowanych (RDL), bez konieczności posiadania Microsoft PowerPoint na serwerze.

Eksportuje raporty do prezentacji i pokazów slajdów w formatach PPT, PPTX, PPS i PPSX, do ODP oraz do XPS.

## **Twój pierwszy eksport**

Nie ma potrzeby pisać kodu: instalujesz rozszerzenie na serwerze raportów, a jego formaty pojawiają się na liście eksportu każdego raportu stronicowanego na tym serwerze.

1. Sprawdź, czy serwer raportów spełnia [wymagania systemowe](/slides/pl/reportingservices/system-requirements/), w tym .NET Framework 3.5.
2. Z [strony pobierania](https://releases.aspose.com/slides/reportingservices/) pobierz instalator MSI, *Aspose.Slides for Reporting Services*. Aby zainstalować ręcznie, pobierz pakiet ZIP, *Aspose.Slides for Reporting Services (DLLs Only)*.
3. Zainstaluj rozszerzenie na serwerze raportów: uruchom MSI jako administrator, zgodnie z opisem w [Instalacja przy użyciu instalatora MSI](/slides/pl/reportingservices/install-with-msi-installer/), lub postępuj zgodnie z [Instalacja ręczna](/slides/pl/reportingservices/install-manually/) dla pakietu ZIP.
4. W przeglądarce otwórz portal internetowy serwera raportów (Report Manager w SQL Server 2014 i starszych). Domyślnie jego adres to `https://<ComputerName>/reports`.
5. Otwórz raport stronicowany. Na pasku narzędzi raportu otwórz listę **Export** i wybierz **PPTX – PowerPoint 2007 Presentation via Aspose.Slides**. Jeśli pasek narzędzi ma osobny przycisk **Export**, tak jak w Report Manager, wybierz go.
6. Otwórz lub zapisz plik PPTX pobrany przez przeglądarkę.

Bez licencji wyeksportowana prezentacja zawiera znak wodny oceny — zobacz [Licencjonowanie](/slides/pl/reportingservices/license-aspose-slides-for-reporting-services/). Dla pozostałych formatów na liście eksportu zobacz [Obsługiwane formaty plików](/slides/pl/reportingservices/supported-file-formats/).
