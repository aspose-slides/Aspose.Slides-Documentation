## **Obsługiwane platformy**
Aspose.Slides for Node.js via Java jest niezależnym od platformy API. Może być używany na dowolnej platformie (Windows, Linux, macOS itp.), na której zainstalowano Node.js w wersji 7 lub wyższej. Wymagany jest także Oracle JDK 8 lub wyższy.

## **FAQ**

### Czy muszę zainstalować Microsoft PowerPoint na serwerze/PC, aby biblioteka działała?

Nie. PowerPoint nie jest wymagany; Aspose.Slides jest samodzielnym silnikiem do tworzenia, edytowania, konwertowania i renderowania prezentacji.

### How does multithreading work? Can processing be parallelized?

Bezpieczne jest przetwarzanie różnych dokumentów w różnych wątkach; tego samego obiektu [presentation](https://reference.aspose.com/slides/pl/nodejs-java/aspose.slides/presentation/) nie należy używać jednocześnie w [multiple threads](/slides/pl/nodejs-java/multithreading/).

### Czy obsługiwane są hasła i szyfrowanie plików?

Tak. [You can](/slides/pl/nodejs-java/password-protected-presentation/) otwierać zaszyfrowane prezentacje, ustawiać lub usuwać hasło otwierające i zapisu oraz sprawdzać status ochrony.

### Czy muszę dbać o pakiety czcionek w kontenerach Linux?

Tak. Zaleca się instalację popularnych pakietów czcionek i/lub wyraźne [specify font directories](/slides/pl/nodejs-java/custom-font/) w aplikacji, aby uniknąć nieoczekiwanych podstawień.

### Czy w wersji ewaluacyjnej istnieją ograniczenia?

W [evaluation mode](/slides/pl/nodejs-java/licensing/) do wyniku dodawany jest znak wodny i obowiązują pewne ograniczenia; dostępna jest [30-day temporary license](https://purchase.aspose.com/temporary-license/) umożliwiająca pełne testowanie funkcji.

### Czy importowanie zewnętrznych formatów do prezentacji (PDF/HTML → PPTX) jest obsługiwane?

Tak. Możesz dodać [PDF pages and HTML content](/slides/pl/nodejs-java/import-presentation/) do prezentacji, zamieniając je w slajdy.
