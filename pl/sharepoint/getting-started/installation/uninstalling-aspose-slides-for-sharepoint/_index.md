Aby odinstalować Aspose.Slides for SharePoint:

1. Uruchom program instalacyjny, którego użyłeś do jego instalacji, na przykład *Setup2019.exe* na SharePoint Server 2019.
   Gdy wykryje zainstalowaną tę samą wersję, program instalacyjny oferuje naprawę lub usunięcie. Gdy wykryje inną wersję, oferuje aktualizację lub usunięcie.
2. Wybierz **Remove** i kliknij **Next**, aby odinstalować Aspose.Slides for SharePoint.
