## **Przegląd produktu**

Aspose.Slides for SharePoint konwertuje prezentacje PowerPoint przechowywane w bibliotekach dokumentów SharePoint na inne formaty, na serwerze.

Konwertuje następujące formaty PowerPoint:

- PPT – prezentacja Microsoft PowerPoint 97-2003
- PPTX – prezentacja Office Open XML

Konwertuje je na PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX i POTM. Zobacz [Supported File Formats](/slides/pl/sharepoint/supported-file-formats/) po szczegóły.

Pobranie zawiera oddzielny program instalacyjny i pakiet rozwiązania dla każdego z następujących produktów:

- SharePoint 2007
- SharePoint 2010
- SharePoint Server 2013
- SharePoint Server 2016
- SharePoint Server 2019
