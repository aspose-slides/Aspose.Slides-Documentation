## **Czym jest SharePoint i Aspose.Slides?**

Aspose.Slides for SharePoint to rozwiązanie umożliwiające konwersję prezentacji Microsoft PowerPoint (PPT i PPTX) do innych formatów: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX i POTM. Pozwala konwertować pliki PowerPoint w witrynie SharePoint bez użycia Microsoft PowerPoint. Pełna lista formatów znajduje się w [Supported File Formats](/slides/pl/sharepoint/supported-file-formats/).
