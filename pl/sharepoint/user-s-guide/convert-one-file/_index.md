Aby przekonwertować prezentację w bibliotece dokumentów:

1. Otwórz menu pliku PPT lub PPTX (jego Edit Control Block) i wybierz **Convert via Aspose.Slides**. W SharePoint 2007 element menu nosi nazwę **Convert with Aspose.Slides**.

   **Wybieranie Convert with Aspose.Slides w menu dokumentu w SharePoint 2007**

   ![Menu dokumentu w bibliotece dokumentów SharePoint 2007, z pozycją Convert with Aspose.Slides](convert-one-file_1.png)

2. Na stronie konwersji wybierz format wyjściowy w sekcji **Convert to**. Jeśli chcesz, zmień nazwę pliku docelowego oraz folder docelowy.
3. Kliknij **Convert**.
4. Po zakończeniu konwersji kliknij **Source Library** lub **Destination Library**, aby powrócić do biblioteki dokumentów. Przekonwertowany plik znajduje się w folderze docelowym.

Te same kroki, wraz ze zrzutami ekranu każdej strony, znajdują się w [Konwertowanie dokumentów Microsoft PowerPoint do innych formatów](/slides/pl/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
