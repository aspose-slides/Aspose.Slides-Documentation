**Witamy w Aspose.Slides for Python via Java**

![Aspose.Slides for Python via Java Product Logo](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java jest biblioteką klas, która umożliwia aplikacjom Pythona odczytywanie i zapisywanie prezentacji PowerPoint® bez potrzeby posiadania Microsoft PowerPoint®.

Jej kluczowe funkcje obejmują zarządzanie tekstem, kształtami, tabelami i animacjami; dodawanie dźwięku i wideo do slajdów; podgląd slajdów; oraz eksportowanie slajdów do SVG, PDF i innych formatów.
