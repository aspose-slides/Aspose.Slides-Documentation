**Witamy w Aspose.Slides dla Pythona via Java**

![Aspose.Slides for Python via Java Product Logo](aspose_slides-for-python-via-java.png)

Aspose.Slides dla Pythona via Java to biblioteka klas, która umożliwia aplikacjom Pythona odczytywanie i zapisywanie prezentacji PowerPoint® bez wymogu posiadania Microsoft PowerPoint®.

Kluczowe funkcje obejmują zarządzanie tekstem, kształtami, tabelami i animacjami; dodawanie dźwięku i wideo do slajdów; podgląd slajdów; oraz eksport slajdów do SVG, PDF i innych formatów.
