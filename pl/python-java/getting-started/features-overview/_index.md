This article describes the presentation processing capabilities of Aspose.Slides for Python via Java. For supported operating systems and dependencies, see [System Requirements](/slides/pl/python-java/system-requirements/).

## **File Formats and Conversions**
Aspose.Slides for Python via Java lets you convert between presentation formats and export presentations to document and web formats. See [Supported File Formats](/slides/pl/python-java/supported-file-formats/) for the complete format table and the distinction between loading presentations, importing content, and exporting output.

## **Presentation Rendering**
Aspose.Slides for Python via Java provides high-fidelity slide rendering as raster or vector images for previews and other visual output. It also lets you render images on slides. For available image formats and export notes, see [Supported File Formats](/slides/pl/python-java/supported-file-formats/#supported-file-formats).

## **Content Features**
Aspose.Slides for Python via Java allows you to access, modify, and create almost all types of presentation content, as described below:

|**Funkcja**|**Opis**|
| :- | :- |
|Presentations|Możesz tworzyć prezentacje od podstaw lub otwierać istniejące pliki.|

|Slide Sections|Możesz organizować slajdy w sekcje w ramach prezentacji.|
|Placeholders and Text Holders|Możesz uzyskać dostęp do placeholderów i tekstowych holderów na slajdzie, a także tworzyć slajdy z tekstowymi holderami od podstaw.|
|Headers and Footers|Aspose.Slides for Python via Java umożliwia zarządzanie nagłówkami i stopkami.|
|Slide Notes|Możesz uzyskać dostęp, dodawać i modyfikować notatki slajdu oraz uwzględniać je podczas eksportu do PDF lub TIFF.|

|Alternative Text|Możesz odczytywać i aktualizować alternatywny tekst dla kształtów.|
|Hyperlinks|Możesz odczytywać i aktualizować hyperlinki na kształtach oraz dodawać hyperlinki do tekstu.|
|Backgrounds|Możesz pracować z tłem master slajdów i zwykłych slajdów w prezentacji.|
|Text Boxes|Możesz tworzyć pola tekstowe od podstaw, uzyskiwać dostęp do istniejących pól tekstowych i modyfikować ich tekst, zachowując oryginalne formatowanie.|

|Ellipse Shapes|Możesz tworzyć i modyfikować kształty elips.|

|SmartArt|Możesz tworzyć i edytować kształty SmartArt w prezentacjach.|

|Audio Frames|Możesz łączyć lub osadzać pliki audio w audio frames na slajdach.|

|OLE Frames|Możesz zarządzać obiektami OLE w OLE frames.|

|Text Scanning|Wbudowane metody umożliwiają skanowanie tekstu w całej prezentacji lub na poszczególnych slajdach.|

|Slide Shows|Aspose.Slides for Python via Java obsługuje pokazy slajdów i przejścia slajdów, w tym przejścia Morph.|

## **Formatting Features**
Aspose.Slides for Python via Java lets you format text and shapes on presentation slides, as described below:

|**Funkcja**|**Opis**|
| :- | :- |
|Text Formatting|<p>Możesz zarządzać tekstem poprzez ramki tekstowe powiązane z kształtami i formatować poszczególne akapity oraz fragmenty tekstu. Dostępne są następujące opcje formatowania:</p><p>- Typ czcionki</p><p>- Rozmiar czcionki</p><p>- Kolor czcionki</p><p>- Cieniowanie czcionki</p><p>- Wyrównanie akapitu</p><p>- Wcięcie akapitu i tabulatory</p><p>- Wypunktowanie akapitu</p><p>- Orientacja akapitu</p>|
|Shape Formatting|<p>Kształty są podstawowymi elementami slajdu. Możesz dostosować następujące właściwości kształtu:</p><p>- Pozycja</p><p>- Rozmiar</p><p>- Obrót</p><p>- Style linii</p><p>- Wypełnienie (w tym jednolite, gradientowe, wzorzowe, teksturowane i obrazy)</p><p>- Tekst</p><p>- Obraz</p>|
