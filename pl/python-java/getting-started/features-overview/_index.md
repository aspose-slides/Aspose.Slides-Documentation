## **Obsługiwane platformy**
Aspose.Slides for Python via Java jest niezależnym od platformy API. Może być używany na dowolnej platformie (Windows, Linux, macOS itp.), na której zainstalowany jest Python 3.7 lub nowszy. JDK 8 lub nowszy jest kolejnym wymogiem.

## **Formaty plików i konwersje**
Aspose.Slides for Python via Java obsługuje większość formatów dokumentów PowerPoint. Umożliwia także ich eksport do popularnych formatów plików, których organizacje używają i udostępniają sobie nawzajem. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java zapewnia najszybsze przetwarzanie tego formatu dokumentu prezentacji.|
|PPT to PPTX conversion|Aspose.Slides for Python via Java obsługuje konwersję PPT do PPTX|
|Portable Document Format (PDF)|Możesz wyeksportować wszystkie obsługiwane formaty plików do dokumentów Adobe Portable Document Format (PDF) przy użyciu jednej metody.|
|XML Parser Specification (XPS)|Możesz wyeksportować wszystkie obsługiwane formaty plików do dokumentów XML Parser Specification (XPS) przy użyciu jednej metody.|
|Tagged Image File Format (TIFF)|Możesz wyeksportować wszystkie obsługiwane formaty prezentacji do Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java obsługuje konwersję PresentationEx do formatu HTML.|

## **Renderowanie prezentacji**
Aspose.Slides for Python via Java obsługuje renderowanie slajdów w prezentacji o wysokiej wierności do różnych formatów graficznych. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Java Supported Image Formats|Korzystając z Aspose.Slides for Python via Java, możesz renderować slajdy prezentacji oraz obrazy na slajdach do wszystkich formatów graficznych obsługiwanych przez Javę, takich jak TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Python via Java oferuje także wbudowane metody umożliwiające eksport slajdów prezentacji do formatu Scalable Vector Graphics (SVG).|

## **Funkcje zawartości**
Aspose.Slides for Python via Java pozwala na dostęp, modyfikację lub tworzenie prawie wszystkich elementów lub treści dokumentów prezentacji. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Master Slides|Master Slides definiują układ zwykłych slajdów. Aspose.Slides for Python via Java pozwala na dostęp i modyfikację Master Slides dokumentów prezentacji|
|Normal Slides|Za pomocą Aspose.Slides for Python via Java możesz tworzyć nowe slajdy różnych typów; możesz także uzyskać dostęp i modyfikować istniejące slajdy w prezentacjach|
|Cloning / Copying Slides|Istnieją wbudowane metody udostępniane przez Aspose.Slides for Python via Java, które umożliwiają klonowanie lub kopiowanie istniejących slajdów w obrębie prezentacji. Możesz także używać skopiowanych i sklonowanych slajdów z jednej prezentacji do drugiej. Ponieważ slajd dziedziczy układ z master slajdu, wbudowane metody klonowania automatycznie kopiują master przy klonowaniu|
|Managing Slides sections|Metody organizacji slajdów w różnych sekcjach wewnątrz prezentacji|
|Place Holders and Text Holders|Możesz uzyskać dostęp do placeholderów i text holderów na slajdzie. Ponadto możesz od podstaw utworzyć slajd z text holderami, korzystając z odpowiedniej metody|
|Header and Footers|Aspose.Slides for Python via Java ułatwia obsługę nagłówków i stopek na slajdach|
|Notes in Slides|Za pomocą Aspose.Slides for Python via Java możesz uzyskać dostęp i modyfikować notatki powiązane ze slajdem oraz dodawać nowe notatki|
|Finding a Shape|Możesz także znaleźć konkretny kształt na slajdzie, używając tekstu alternatywnego powiązanego z kształtem|
|Backgrounds|Aspose.Slides for Python via Java pozwala pracować z tłami powiązanymi z master lub zwykłym slajdem w prezentacji|
|Text Boxes|Pola tekstowe można tworzyć od podstaw. Możesz uzyskać dostęp do istniejących pól tekstowych. Możesz także modyfikować ich teksty, nie tracąc pierwotnego formatowania tekstu|
|Rectangle Shapes|Możesz tworzyć lub modyfikować prostokątne kształty za pomocą Aspose.Slides for Python via Java|
|Poly Line Shapes|Możesz tworzyć lub modyfikować kształty linii wielokątnych za pomocą Aspose.Slides for Python via Java|
|Ellipse Shapes|Możesz tworzyć lub modyfikować kształty elips za pomocą Aspose.Slides for Python via Java|
|Group Shapes|Aspose.Slides for Python via Java obsługuje kształty grupowe|
|Auto Shapes|Aspose.Slides for Python via Java obsługuje autokształty|
|SmartArt|Aspose.Slides for Python via Java zapewnia obsługę kształtów SmartArt w MS PowerPoint|
|Charts|Aspose.Slides for Python via Java zapewnia obsługę wykresów MSO w PowerPoint|
|Shapes Serialization|Aspose.Slides for Python via Java obsługuje dużą liczbę kształtów. Gdy Aspose.Slides for Python via Java nie obsługuje danego kształtu, możesz użyć metody serializacji, dzięki której możesz zserializować ten kształt z istniejącego slajdu. W ten sposób możesz dalej wykorzystywać kształt zgodnie z własnymi potrzebami.|
|Picture Frames|Możesz zarządzać obrazami w ramach picture frames za pomocą Aspose.Slides for Python via Java|
|Audio Frames|Możesz linkować lub osadzać pliki audio w ramkach audio na slajdach przy użyciu Aspose.Slides for Python via Java|
|Video Frames|Możesz obsługiwać pliki wideo w ramach video frames. Aspose.Slides for Python via Java zapewnia także obsługę połączonych i osadzonych filmów|
|OLE Frame|Możesz zarządzać obiektami OLE w ramach OLE przy użyciu Aspose.Slides for Python via Java|
|Tables|Aspose.Slides for Python via Java obsługuje tabele na slajdach|
|ActiveX Controls|Obsługa kontrolek ActiveX|
|VBA Macros|Obsługa zarządzania makrami VBA w prezentacjach.|
|Text Frame|Możesz uzyskać dostęp do tekstu dowolnego kształtu poprzez ramkę tekstową powiązaną z tym kształtem|
|Text Scanning|Możesz skanować tekst w prezentacji na poziomie prezentacji lub slajdu za pomocą wbudowanych metod skanowania.|
|Animations|Możesz stosować animacje na kształtach|
|Slide Shows|Aspose.Slides for Python via Java obsługuje pokazy slajdów i przejścia między slajdami|

## **Funkcje formatowania**
Za pomocą Aspose.Slides for Python via Java możesz formatować teksty i kształty na slajdach w prezentacjach. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Text Formatting|<p>W Aspose.Slides for Python via Java możesz zarządzać tekstami poprzez ramki tekstowe powiązane z kształtami. Dzięki temu możesz formatować teksty używając akapitów i fragmentów powiązanych z ramkami tekstowymi. Elementy tekstowe można formatować za pomocą Aspose.Slides for Python via Java.</p><p>- Typ czcionki</p><p>- Rozmiar czcionki</p><p>- Kolor czcionki</p><p>- Odcienie czcionki</p><p>- Wyrównanie akapitu</p><p>- Wypunktowanie akapitu</p><p>- Orientacja akapitu</p>|
|Shape Formatting|<p>W Aspose.Slides for Python via Java podstawowym elementem slajdu jest kształt. Możesz formatować te elementy kształtów za pomocą Aspose.Slides for Python via Java:</p><p>- Pozycja</p><p>- Rozmiar</p><p>- Linia</p><p>- Wypełnienie (w tym wzór, gradient, jednolite)</p><p>- Tekst</p><p>- Obraz</p>|
