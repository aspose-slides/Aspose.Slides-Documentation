Możesz pobrać Aspose.Slides dla Pythona poprzez Java, aby ocenić jego funkcje. Pakiet ewaluacyjny jest identyczny z pakietem licencyjnym. Aby używać go bez ograniczeń ewaluacyjnych, dodaj kilka linii kodu do [zastosować licencję](/slides/pl/python-java/licensing/).

Wersja ewaluacyjna Aspose.Slides (używana bez licencji) zapewnia pełną funkcjonalność produktu, z dwoma ograniczeniami:

- Dodaje pole tekstowe z znakiem wodnym ewaluacji do każdego slajdu każdej prezentacji, którą zapisuje. Otwarcie prezentacji nie dodaje takiego pola, ale zapisanie pliku, który już zawiera znak wodny, dodaje kolejny.
- Tekst odczytywany przez Twój kod jest przycinany do kilku pierwszych znaków, po których pojawia się informacja o ograniczeniu wersji ewaluacyjnej. Dotyczy to każdego slajdu oraz tekstu, który Twój kod właśnie ustawił, jak i tekstu wczytanego z pliku. Tekst zapisywany przez Twój kod jest zapisywany w całości.
