## **Obsługiwane platformy**
Aspose.Slides for PHP via Java jest niezależnym od platformy interfejsem API. Może być używany na dowolnej platformie (Windows, Linux, macOS itp.), na której zainstalowano PHP w wersji 7 lub wyższej. Oracle JDK w wersji 7 lub wyższej jest kolejnym wymogiem.

Aspose.Slides for PHP via Java obsługuje większość formatów dokumentów PowerPoint. Umożliwia także eksport do popularnych formatów plików, które organizacje używają i udostępniają sobie nawzajem. Zapoznaj się z poniższymi szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java zapewnia najszybsze przetwarzanie tego formatu dokumentu prezentacji.|
|PPT to PPTX conversion|Aspose.Slides for PHP via Java obsługuje konwersję PPT do PPTX.|
|Portable Document Format (PDF)|Możesz wyeksportować wszystkie obsługiwane formaty plików do dokumentów Adobe Portable Document Format (PDF) za pomocą jednej metody.|
|XML Parser Specification (XPS)|Możesz wyeksportować wszystkie obsługiwane formaty plików do dokumentów XML Parser Specification (XPS) za pomocą jednej metody.|

|**Funkcja**|**Opis**|

## **FAQ**

### Czy muszę zainstalować Microsoft PowerPoint na serwerze/komputerze, aby biblioteka działała?

Nie. PowerPoint nie jest wymagany; Aspose.Slides jest samodzielnym silnikiem do tworzenia, edytowania, konwertowania i renderowania prezentacji.

### Jak działa wielowątkowość? Czy przetwarzanie można równolegle rozdzielić?

Bezpieczne jest przetwarzanie różnych dokumentów w osobnych wątkach; ten sam [prezentacji](https://reference.aspose.com/slides/pl/php-java/aspose.slides/presentation/) nie powinien być używany przez [wiele wątków](/slides/pl/php-java/multithreading/) jednocześnie.

### Czy obsługiwane są hasła do plików i szyfrowanie?

Tak. [Możesz](/slides/pl/php-java/password-protected-presentation/) otwierać zaszyfrowane prezentacje, ustawiać lub usuwać hasło otwierania i zapisu oraz sprawdzać status ochrony.

### Czy muszę się martwić o pakiety czcionek w kontenerach Linux?

Tak. Zaleca się instalację popularnych pakietów czcionek i/lub wyraźne [określenie katalogów czcionek](/slides/pl/php-java/custom-font/) w aplikacji, aby uniknąć nieoczekiwanych zamian.

### Czy istnieją ograniczenia w wersji ewaluacyjnej?

W [trybie ewaluacyjnym](/slides/pl/php-java/licensing/) do wyjścia dodawany jest znak wodny i obowiązują pewne ograniczenia; dostępna jest [30‑dniowa licencja tymczasowa](https://purchase.aspose.com/temporary-license/) umożliwiająca pełne testowanie funkcji.

### Czy importowanie zewnętrznych formatów do prezentacji (PDF/HTML → PPTX) jest obsługiwane?

Tak. Możesz dodać [strony PDF i treść HTML](/slides/pl/php-java/import-presentation/) do prezentacji, zamieniając je w slajdy.
