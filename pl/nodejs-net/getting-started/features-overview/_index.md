## **Obsługiwane platformy**
Aspose.Slides for Node.js via .NET jest API niezależnym od platformy. Może być używany na dowolnej platformie (Windows, Linux, macOS itp.), na której zainstalowano Node.js w wersji 7 lub wyższej. Wymagany jest również Oracle JDK w wersji 8 lub wyższej.

## **Formaty plików i konwersje**
Aspose.Slides for Node.js via .NET obsługuje większość formatów dokumentów PowerPoint. Umożliwia także eksport do popularnych formatów plików, które organizacje używają i współdzielą. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET zapewnia najszybsze przetwarzanie tego formatu dokumentu prezentacji.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET obsługuje konwersję PPT do PPTX|
|Portable Document Format (PDF)|Możesz wyeksportować wszystkie obsługiwane formaty plików do dokumentów Adobe Portable Document Format (PDF) przy użyciu jednej metody.|
|XML Parser Specification (XPS)|Możesz wyeksportować wszystkie obsługiwane formaty plików do dokumentów XML Parser Specification (XPS) przy użyciu jednej metody.|
|Tagged Image File Format (TIFF)|Możesz wyeksportować wszystkie obsługiwane formaty plików prezentacji do formatu Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET obsługuje konwersję PresentationEx do formatu HTML.|

## **Renderowanie prezentacji**
Aspose.Slides for Node.js via .NET wspiera renderowanie slajdów prezentacji o wysokiej wierności do różnych formatów graficznych. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|.NET Supported Image Formats|Korzystając z Aspose.Slides for Node.js via .NET, możesz renderować slajdy prezentacji oraz obrazy na slajdach do wszystkich formatów graficznych obsługiwanych przez .NET, takich jak TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via .NET udostępnia również wbudowane metody, które pozwalają na eksport slajdów prezentacji do formatu Scalable Vector Graphics (SVG).|

## **Funkcje zawartości**
Aspose.Slides for Node.js via .NET umożliwia dostęp, modyfikację lub tworzenie prawie wszystkich elementów lub treści dokumentów prezentacji. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Master Slides|Slajdy główne definiują układ normalnych slajdów. Aspose.Slides for Node.js via .NET pozwala na dostęp i modyfikację slajdów głównych dokumentów prezentacji|
|Normal Slides|Za pomocą Aspose.Slides for Node.js via .NET możesz tworzyć nowe slajdy różnych typów; możesz także uzyskać dostęp i modyfikować istniejące slajdy w prezentacjach|
|Cloning / Copying Slides|Istnieją wbudowane metody udostępniane przez Aspose.Slides for Node.js via .NET, które pozwalają klonować lub kopiować istniejące slajdy w ramach prezentacji. Możesz także używać skopiowanych i sklonowanych slajdów z jednej prezentacji do drugiej. Ponieważ slajd dziedziczy układ ze slajdu głównego, wbudowane metody klonowania automatycznie kopiują master przy klonowaniu|
|Managing Slides sections|Metody organizujące slajdy w różnych sekcjach wewnątrz prezentacji|
|Place Holders and Text Holders|Możesz uzyskać dostęp do place holderów i text holderów w slajdzie. Ponadto możesz utworzyć slajd z text holderami od podstaw, używając odpowiedniej metody|
|Header and Footers|Aspose.Slides for Node.js via .NET ułatwia obsługę nagłówków i stopek w slajdach|
|Notes in Slides|Za pomocą Aspose.Slides for Node.js via .NET możesz uzyskać dostęp i modyfikować notatki powiązane ze slajdem oraz dodawać nowe notatki|
|Finding a Shape|Możesz także znaleźć konkretny kształt w slajdzie, używając alternatywnego tekstu powiązanego z tym kształtem|
|Backgrounds|Aspose.Slides for Node.js via .NET pozwala pracować z tłami powiązanymi z masterem lub normalnym slajdem w prezentacji|
|Text Boxes|Pola tekstowe mogą być tworzone od podstaw. Możesz uzyskać dostęp do istniejących pól tekstowych. Możesz także modyfikować ich teksty bez utraty oryginalnego formatowania|
|Rectangle Shapes|Możesz tworzyć lub modyfikować kształty prostokątne przy użyciu Aspose.Slides for Node.js via .NET|
|Poly Line Shapes|Możesz tworzyć lub modyfikować kształty linii łamanej przy użyciu Aspose.Slides for Node.js via .NET|

|Group Shapes|Aspose.Slides for Node.js via .NET supports group shapes|
|Auto Shapes|Aspose.Slides for Node.js via .NET supports auto shapes|
|SmartArt|Aspose.Slides for Node.js via .NET provides support for SmartArt shapes in MS PowerPoint|
|Charts|Aspose.Slides for Node.js via .NET provides support for MSO Charts in PowerPoint|
|Shapes Serialization|Aspose.Slides for Node.js via .NET supports a large number of shapes. When Aspose.Slides for Node.js via .NET lacks support for a shape, you can use a serialization method through which you get to serialize that shape from an existing slide. This way, you get to use the shape further as per your requirements|
|Picture Frames|Możesz zarządzać obrazami w ramkach obrazów przy użyciu Aspose.Slides for Node.js via .NET|
|Audio Frames|Możesz łączyć lub osadzać pliki audio w ramkach dźwiękowych na slajdach przy użyciu Aspose.Slides for Node.js via .NET|
|Video Frames|Możesz obsługiwać pliki wideo w ramkach wideo. Aspose.Slides for Node.js via .NET udostępnia także wsparcie dla linkowanych i osadzonych wideo|
|OLE Frame|Możesz zarządzać obiektami OLE w ramkach OLE przy użyciu Aspose.Slides for Node.js via .NET|

|Slide Shows|Aspose.Slides for Node.js via .NET supports slide shows and slide transitions|

## **Funkcje formatowania**
Korzystając z Aspose.Slides for Node.js via .NET, możesz formatować teksty i kształty na slajdach w prezentacjach. Zapoznaj się ze szczegółami:

|**Funkcja**|**Opis**|
| :- | :- |
|Text Formatting|<p>W Aspose.Slides for Node.js via .NET możesz zarządzać tekstami poprzez ramki tekstowe powiązane z kształtami. Dzięki temu możesz formatować teksty używając akapitów i fragmentów powiązanych z ramkami tekstowymi. Te elementy tekstowe mogą być formatowane przy pomocy Aspose.Slides for Node.js via .NET.</p><p>- Typ czcionki</p><p>- Rozmiar czcionki</p><p>- Kolor czcionki</p><p>- Odcienie czcionki</p><p>- Wyrównanie akapitu</p><p>- Wypunktowanie akapitu</p><p>- Orientacja akapitu</p>|
|Shape Formatting|<p>W Aspose.Slides for Node.js via .NET podstawowym elementem slajdu jest kształt. Możesz formatować te elementy kształtów przy pomocy Aspose.Slides for Node.js via .NET:</p><p>- Pozycja</p><p>- Rozmiar</p><p>- Linia</p><p>- Wypełnienie (w tym Wzór, Gradient, Jednolity kolor)</p><p>- Tekst</p><p>- Obraz</p>|
