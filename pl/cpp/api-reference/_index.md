{{% alert color="info" %}}

Aspose.Slides for C++ jest biblioteką klas umożliwiającą aplikacjom C++ odczyt i zapis dokumentów prezentacji bez użycia Microsoft PowerPoint® ani innych. Aspose.Slides for C++ pozwala zarządzać tekstem, kształtami, tabelami i animacjami, dodawać dźwięk i wideo do slajdów, podglądać slajdy, eksportować slajdy do formatu SVG, PDF i więcej.

Najnowszą dokumentację API można znaleźć pod adresem [Aspose.Slides for C++ API Reference](https://reference.aspose.com/slides/pl/cpp/).

{{% /alert %}}
