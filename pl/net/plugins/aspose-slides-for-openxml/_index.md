## **Co to jest OpenXML?**
OpenXML SDK jest zestawem SDK .NET od Microsoft służącym do przetwarzania formatów plików Microsoft Office 2007 i nowszych. Formaty te są zasadniczo spakowanymi pakietami, a Open XML SDK dla Office upraszcza zadanie manipulacji pakietami Open XML oraz elementami schematu Open XML wewnątrz pakietu. Klasy w Open XML SDK kapsułkują wiele typowych zadań wykonywanych przez programistów na pakietach Open XML, dzięki czemu możesz wykonywać złożone operacje przy użyciu kilku linii kodu.

Po zainstalowaniu Open XML SDK 2.5 otwórz istniejący projekt lub aplikację w Visual Studio albo utwórz nowy projekt lub aplikację. Następnie w swoim projekcie lub aplikacji dodaj odwołania do następujących komponentów:

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides for .NET**
Aspose.Slides for .NET jest unikalnym komponentem zarządzania PowerPoint®, który umożliwia aplikacjom .NET odczyt, zapis i modyfikację dokumentów PowerPoint bez użycia Microsoft PowerPoint.

Aspose.Slides for .NET jest pierwszym i jedynym komponentem .NET, który zapewnia funkcjonalność zarządzania dokumentami PowerPoint w Twoich własnych aplikacjach. Podobnie jak wszystkie komponenty Aspose .NET, Aspose.Slides jest napisany w zarządzanym C#, jest niezwykle przystępny cenowo i błyskawicznie szybki.

## **Wprowadzenie**
Programiści poszukujący bibliotek obsługujących formaty plików mogą chcieć przejrzeć funkcje dostępne w bibliotekach dostępnych na rynku. Głównie przy wyborze opcji brane są pod uwagę dwa czynniki:

- Funkcje
- Wysiłek potrzebny do użycia biblioteki

Jeśli jesteś programistą .NET szukającym szybkiej, prostej i lekkiej biblioteki formatów plików do przetwarzania dokumentów, możesz potrzebować porównać VSTO (Visual Studio Tools for Office) z Aspose. W takim przypadku ten projekt pomoże Ci porównać funkcje i kod w obu bibliotekach.
