{{% alert color="info" %}} 

Aspose.Slides for .NET to biblioteka klas, która umożliwia aplikacjom .NET odczytywanie i zapisywanie dokumentów prezentacji bez użycia Microsoft PowerPoint® ani innych programów. Aspose.Slides for .NET pozwala zarządzać tekstem, kształtami, tabelami i animacjami, dodawać dźwięk oraz wideo do slajdów, przeglądać slajdy, eksportować slajdy do formatu SVG, PDF i inne.

Najnowszą dokumentację API można znaleźć pod adresem [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/pl/net).

{{% /alert %}}
