{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) jest formatem pliku dokumentu prezentacji, który może być tworzony, odczytywany, modyfikowany i zapisywany przez różne wersje Microsoft PowerPoint. Jest to binarny format dokumentów prezentacji opracowany przez firmę Microsoft.

{{% /alert %}} 

## **PPT w Aspose.Slides dla Javy**
Aspose.Slides dla Javy może odczytywać pliki PPT utworzone przez poniższe oprogramowanie.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Podobnie, pliki PPT utworzone przez Aspose.Slides dla Javy mogą być odczytywane przez wymienione wyżej programy.

## **Kompleksowe wsparcie dla PPT**
Aspose.Slides dla Javy zapewnia wsparcie prawie dla wszystkich funkcji obsługiwanych przez format pliku dokumentu PPT. Obejmuje nie tylko podstawowe i zaawansowane funkcje dostępne w różnych wersjach Microsoft PowerPoint do manipulacji dokumentami PPT, ale także funkcje, które nie są obsługiwane nawet przez Microsoft PowerPoint. Główną zaletą używania biblioteki API Aspose.Slides dla Javy jest łatwość obsługi tych funkcji.

Oprócz podstawowych zadań związanych z tworzeniem, odczytywaniem i zapisywaniem plików PPT, Aspose.Slides dla Javy oferuje kilka dodatkowych funkcji:

- Importuj inne formaty plików Microsoft Office jako [obiekty OLE do dokumentów PPT]().
- [Eksportuj dokumenty PPT do formatu PDF](/slides/pl/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- Eksportuj slajdy w dokumentach PPT do formatów SVG.
- Renderuj slajdy do dowolnego formatu obrazu obsługiwanego przez framework Java.
- Ustaw rozmiar slajdów w dokumentach PPT.
- Zarządzaj animacjami kształtów.
- Zarządzaj pokazami slajdów.
- [Formatuj tekst na slajdach]().
- Wydobądź tekst z dokumentów PPT.
- [Obsługuj tabele na slajdach]().
- Automatycznie kopiuj mastery przy użyciu [funkcji klonowania]()
