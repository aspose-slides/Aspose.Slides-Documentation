{{% alert color="info" title="Note" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) jest formatem pliku dokumentu prezentacji, który może być tworzony, odczytywany, modyfikowany i zapisywany przez różne wersje Microsoft PowerPoint. Jest to binarny format dokumentów prezentacji opracowany przez Microsoft.

{{% /alert %}}

## **PPT w Aspose.Slides for Java**
Aspose.Slides for Java może odczytać pliki PPT utworzone przez oprogramowanie wymienione poniżej.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Podobnie, pliki PPT utworzone przez Aspose.Slides for Java mogą być odczytane przez powyższy zestaw oprogramowania.

## **Kompleksowe wsparcie dla PPT**
Aspose.Slides for Java zapewnia wsparcie dla prawie wszystkich funkcji obsługiwanych przez format pliku dokumentu PPT. Obejmuje nie tylko podstawowe i zaawansowane funkcje dostarczane przez różne wersje Microsoft PowerPoint dla manipulacji dokumentami PPT, ale także funkcje, które nie są obsługiwane nawet przez Microsoft PowerPoint. Główną zaletą korzystania z biblioteki API Aspose.Slides for Java jest łatwość obsługi takich funkcji.

Oprócz podstawowych zadań związanych z tworzeniem, odczytem i zapisem plików PPT, Aspose.Slides for Java oferuje kilka dodatkowych funkcji:

- Importuj inne formaty plików Microsoft Office jako [obiekty OLE do dokumentów PPT](/slides/pl/java/manage-ole/).
- [Eksportuj dokumenty PPT do PDF](/slides/pl/java/convert-powerpoint-to-pdf/).
- Eksportuj slajdy w dokumentach PPT do formatów SVG.
- Renderuj slajdy do dowolnego formatu obrazu obsługiwanego przez Java Framework.
- Ustaw rozmiar slajdów w dokumentach PPT.
- Zarządzaj animacjami na kształtach.
- Zarządzaj pokazami slajdów.
- [Formatuj tekst na slajdach](/slides/pl/java/text-formatting/).
- Ekstrahuj tekst z dokumentów PPT.
- [Obsługuj tabele na slajdach](/slides/pl/java/powerpoint-table/).
- Automatycznie kopiuj mastery przy użyciu [funkcji klonowania](/slides/pl/java/clone-slides/).
