{{% alert color="info" %}} 
Specyfikacja [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) jest językiem opisu strony i formatem dokumentu stałego, pierwotnie opracowanym przez firmę Microsoft. Podobnie jak PDF, XPS jest zaprojektowany tak, aby zachować wierność dokumentu i zapewnić niezależny od urządzenia wygląd dokumentu. 
{{% /alert %}} 
## **XPS w Aspose.Slides dla Javy**
Każdy dokument prezentacji, który może zostać wczytany przez Aspose.Slides for Java, może zostać przekonwertowany na format XPS. Aspose.Slides for Java wykorzystuje wysokiej wierności układ strony i silnik renderowania, aby generować wyjście w formacie dokumentu XPS o stałym układzie. 
Więcej informacji o eksportowaniu dokumentów prezentacji do dokumentów XPS przy użyciu Aspose.Slides for Java znajdziesz w [Converting to XPS](https://docs.aspose.com/slides/pl/java/convert-powerpoint-to-xps/).
