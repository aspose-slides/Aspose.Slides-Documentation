{{% alert color="info" title="Uwaga" %}}

Specyfikacja papieru XML (XML Paper Specification) jest językiem opisu stron i formatem dokumentu o stałym układzie, pierwotnie opracowanym przez Microsoft. Podobnie jak PDF, XPS ma na celu zachowanie wierności dokumentu i zapewnienie niezależnego od urządzenia wyglądu dokumentu.

{{% /alert %}}

## **XPS w Aspose.Slides for Java**
Każdy dokument prezentacji, który może zostać załadowany przez Aspose.Slides for Java, może zostać skonwertowany do formatu XPS. Aspose.Slides for Java wykorzystuje wysokiej wierności silnik układu strony i renderowania, aby wyprodukować wyjście w formacie dokumentu XPS o stałym układzie.  
Możesz dowiedzieć się więcej o eksportowaniu dokumentów prezentacji do dokumentów XPS za pomocą Aspose.Slides for Java w [Konwertuj prezentacje PowerPoint na XPS](/slides/pl/java/convert-powerpoint-to-xps/).
