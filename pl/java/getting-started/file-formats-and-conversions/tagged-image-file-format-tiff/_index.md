## **O formacie TIFF**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF), znany z przechowywania wielu obrazów w jednym dokumencie, został pierwotnie stworzony przez firmę Aldus. Format ten jest szeroko obsługiwany przez skanery, faxy i inne aplikacje do manipulacji obrazami.

## **TIFF w Aspose.Slides for Java**

Każdy dokument, który można wczytać w Aspose.Slides for Java, może być również bezpośrednio skonwertowany do dokumentu TIFF przy użyciu Aspose.Slides for Java, eliminując potrzebę stosowania jakichkolwiek komponentów firm trzecich. Dodatkowo, można opcjonalnie określić rozmiar obrazów w wynikowym dokumencie TIFF. Informacje o eksportowaniu dokumentów prezentacji do dokumentów TIFF za pomocą Aspose.Slides for Java znajdziesz w [Convert PowerPoint Presentations to TIFF](/slides/pl/java/convert-powerpoint-to-tiff/).
