{{% alert color="info" title="Note" %}}

To jest strona historyczna. Opisuje błąd w Aspose.Slides for Java w wersjach 23.2-23.7, które zostały wydane w 2023 roku, oraz wersje, które go naprawiły. Nie opisuje bieżącej wersji. Informacje o licencjonowaniu w bieżącej wersji znajdziesz w [Licensing](/slides/pl/java/licensing/).

{{% /alert %}}

## **Przegląd**

Ten artykuł opisuje błąd licencjonowania występujący w Aspose.Slides for Java w wersjach 23.2, 23.3, 23.4, 23.5, 23.6 i 23.7. Błąd ten powodował, że licencje wieczyste stawały się tymczasowo nieużyteczne po wygaśnięciu ich subskrypcji.

## **Objawy**

Po wygaśnięciu subskrypcji licencji wieczystej, Aspose.Slides for Java w wersjach 23.2 - 23.7 może zgłaszać, że licencja jest wygasła, przełączając wszystkie funkcje w tryb ewaluacji. To zachowanie jest nieprawidłowe i nie dotyczy wersji wcześniejszych niż 23.2 oraz po 23.7.

## **Rozwiązanie**

Aspose.Slides for Java rozwiązało ten problem i wydało zaktualizowane wersje (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) zawierające poprawkę.

Jeśli w swoim projekcie używasz jednej z dotkniętych wersji Aspose.Slides for Java, przejdź na wersję poprawioną.

Jeśli napotkasz jakiekolwiek problemy z licencjonowaniem Aspose.Slides for Java:

- Sprawdź używaną wersję i upewnij się, że nie jest ona dotknięta opisanym powyżej błędem.
- Zapoznaj się z [Licensing](/slides/pl/java/licensing/), aby dowiedzieć się, jak zastosować i zweryfikować licencję.
- Skontaktuj się z [Aspose support](https://forum.aspose.com/c/slides/pl/11), aby uzyskać dalszą pomoc.

## **Zainfekowane produkty i wersje**

Należy pamiętać, że błąd ten wpływa tylko na Aspose.Slides for Java w wersjach od 23.2 do 23.7. **Inne produkty Aspose oraz inne wersje Aspose.Slides nie są objęte**.
