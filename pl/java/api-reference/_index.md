Aspose.Slides for Java to biblioteka klas, która umożliwia aplikacjom Java odczyt i zapis dokumentów prezentacji bez użycia Microsoft PowerPoint® ani innych. Aspose.Slides for Java pozwala zarządzać tekstem, kształtami, tabelami i animacjami, dodawać audio i wideo do slajdów, przeglądać slajdy, eksportować slajdy do formatu SVG, PDF i inne.

Najnowszą dokumentację API można znaleźć pod adresem [Aspose.Slides for Java API Reference](https://reference.aspose.com/slides/pl/java).
