## **Wsparcie dla kodu legacy**
Aby używać kodu legacy napisanego przy użyciu wersji Aspose.Slides for Java wcześniejszych niż 14.x.x, musisz wprowadzić kilka drobnych zmian w kodzie, a kod będzie działał tak jak wcześniej. Wszystkie klasy, które były dostępne w starszej wersji Aspose.Slides for Java w przestrzeniach nazw com.aspose.slides i com.aspose.slides.pptx, zostały teraz połączone w jedną przestrzeń nazw com.aspose.slides. Zapoznaj się z poniższym prostym fragmentem kodu tworzącym zwykły wykres od podstaw w prezentacji przy użyciu legacy API Aspose.Slides i postępuj zgodnie z krokami opisującymi, jak migrować do nowego, połączonego API.
