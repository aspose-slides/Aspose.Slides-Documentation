{{% alert color="info" title="Note" %}}

To jest strona historyczna. Zawiera listę znanych problemów opublikowanych z Aspose.Slides for Java 14.3.0 i nie opisuje bieżącej wersji. Aby zobaczyć zmiany w każdej wersji, zobacz [notatki o wydaniu](https://releases.aspose.com/slides/pl/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) oferuje całkowicie nową implementację przetwarzania plików PPT. Wprowadzono wiele ulepszeń, w tym częściową konwersję PPTX do PPT. Jednak niektóre funkcje nie zostały zaimplementowane:

- Niektóre kształty mają nieprawidłową geometrię w zserializowanych dokumentach PPT (Call outs)
- Nie wszystkie funkcje formatowania tekstu w PPTX są obsługiwane przy serializacji do PPT
- Informacje o języku tekstu i ustawieniach ortograficznych nie są obecne w zserializowanych dokumentach PPT
- Nie wszystkie funkcje motywów PPTX są obsługiwane przy serializacji do PPT

**Istnieją pewne różnice w porównaniu do Aspose.Slides for Java 8.6.0:**

- Istnieją znane problemy w serializacji OLE/ActiveX PPT do PPT

**Istnieją pewne różnice w porównaniu do Aspose.Slides for .NET 14.3.0:**

- Obsługa drukowania prezentacji jest obecnie niedostępna w Aspose.Slides for Java
