## **Przegląd**

Ta sekcja nie zawiera listy otwartych problemów w bieżącej wersji. Zawiera trzy strony:

- [Zastępnik podglądu obiektu przy dodawaniu OleObjectFrame](/slides/pl/java/object-preview-issue-when-adding-oleobjectframe/) wyjaśnia, dlaczego obiekt OLE dodany przy pomocy Aspose.Slides wyświetla obraz "EMBEDDED OLE OBJECT" aż do zaktualizowania podglądu oraz jak ustawić własny obraz podglądu. Jest to zachowanie zaprojektowane w bieżącej wersji.
- [Znane problemy w Aspose.Slides for Java 14.3.0 (Historical)](/slides/pl/java/known-issues-in-aspose-slides-for-java-14-3-0/) i [Znane problemy w Aspose.Slides for Java 14.4.0 (Historical)](/slides/pl/java/known-issues-in-aspose-slides-for-java-14-4-0/) są listami opublikowanymi wraz z tymi wersjami, zachowanymi jako odniesienie.

Aby zobaczyć zmiany i poprawki w każdej wersji, zobacz [notatki o wydaniu](https://releases.aspose.com/slides/pl/java/release-notes/). Metadane, które Aspose.Slides zapisuje z stałymi wartościami, są opisane w [Ograniczenia metadanych wyjściowych](/slides/pl/java/api-limitations/). Aby sprawdzić, czy problem jest już znany, lub aby go zgłosić, użyj [forum wsparcia](https://forum.aspose.com/c/slides/pl/11).
