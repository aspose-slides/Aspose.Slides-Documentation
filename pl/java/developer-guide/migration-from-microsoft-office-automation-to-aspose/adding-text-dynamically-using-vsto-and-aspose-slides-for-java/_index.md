Typowym zadaniem, które programiści muszą wykonać, jest dynamiczne dodawanie tekstu do slajdów. Ten artykuł pokazuje przykłady kodu dla dynamicznego dodawania tekstu przy użyciu [VSTO](/slides/pl/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/) i [Aspose.Slides for Java](/slides/pl/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/).

{{% /alert %}} 
## **Dynamiczne Dodawanie Tekstu**
Obie metody podążają za następującymi krokami:

1. Utwórz prezentację.
1. Dodaj pusty slajd.
1. Dodaj pole tekstowe.
1. Ustaw jakiś tekst.
1. Zapisz prezentację.
