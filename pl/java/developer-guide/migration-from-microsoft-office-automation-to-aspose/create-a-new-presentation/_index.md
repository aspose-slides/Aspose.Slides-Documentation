{{% alert color="info" %}} 

VSTO zostało opracowane, aby umożliwić programistom tworzenie aplikacji działających wewnątrz Microsoft Office. VSTO jest oparte na COM, ale jest opakowane w obiekt .NET, co pozwala na jego użycie w aplikacjach .NET. VSTO wymaga wsparcia .NET Framework oraz środowiska uruchomieniowego opartego na CLR dla Microsoft Office. Chociaż można go używać do tworzenia dodatków do Microsoft Office, jego użycie jako składnika po stronie serwera jest praktycznie niemożliwe. Ma także poważne problemy z wdrożeniem.

Aspose.Slides for Java jest komponentem, który może służyć do manipulacji prezentacjami Microsoft PowerPoint, podobnie jak VSTO, ale posiada kilka zalet:

- Aspose.Slides zawiera wyłącznie kod zarządzany i nie wymaga instalacji środowiska uruchomieniowego Microsoft Office.
- Może być używany jako komponent po stronie klienta lub po stronie serwera.
- Wdrożenie jest proste, ponieważ Aspose.Slides jest zawarte w pojedynczym pliku JAR.

{{% /alert %}}
