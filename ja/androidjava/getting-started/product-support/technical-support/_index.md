## **概要**

この記事では、Aspose.Slides のサポートを受ける方法と、問題を効果的に報告する方法を説明します。主なサポートチャネルの説明、問題提出の推奨事項、製品ページ、ブログ、ダウンロード、サポートフォーラム、ドキュメント、API リファレンスなどの有用な技術リソースへのリンクを示します。また、有料サポート、問題のエスカレーション、古いライブラリ バージョンのサポートに関する一般的な質問にも回答します。

## **技術サポート**

{{% alert color="info" %}} 
Aspose はすべての製品に対して無制限の無料技術サポートを提供しています。サポートはすべてのユーザー（評価版パッケージのユーザーを含む）に利用可能です。
{{% /alert %}} 

Aspose.Slides for Android via Java のサポートが必要なときは、次の点に留意してください。

- 主なサポート窓口は Aspose.Forums です。Aspose.Slides フォーラムに質問を投稿すれば、数時間以内に回答が得られます。Aspose.Slides サポートチームがフォーラム上の質問に直接回答します。
- Aspose は電話での技術サポートは提供していません。電話でのサポートは販売および購入に関する質問のみ利用可能です。
- フォーラムでの返信を待つ際は、時差を考慮して忍耐強くお待ちください。

Aspose.Slides for Android via Java で問題が発生した場合は、以下のガイドラインに従ってできるだけ効率的に解決してください。

- 問題を報告する前に、最新の Aspose.Slides for Android via Java バージョンを使用していることを確認してください。おそらく、問題はアップデートですでに解決されている可能性があります。  
  最新バージョンの情報は Aspose.Slides ダウンロード を参照してください。
- 問題を報告する前に、フォーラム、この記事のドキュメント、および API リファレンスを確認してください。質問への回答が既に提供されているかもしれません。
- 問題を報告する際は、元のドキュメントと（可能であれば）問題に関連するコードの断片を含めてください。複数のファイルを添付する必要がある場合は、ZIP パッケージにまとめてください。  
  Aspose.Forums にファイルを添付しても安全です。添付ファイルはあなたと Aspose の開発者だけがアクセスできます。
- 特定の問題ごとに 1 つのスレッドを作成して使用してください。別の問題が発生した場合は、別のスレッドを作成して報告してください。

## **FAQ**

### 利用できる有料サポートの階層とその違いは何ですか？

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。インシデント数、応答優先度、利用可能なコミュニケーションチャネルにより異なります。

### バグを直接エンジニアリングチームにエスカレーションできますか？

はい。[有料サポート](https://helpdesk.aspose.com/) を利用すると、問題が深い調査を要する場合に開発者へエスカレーションできます。

### 古いライブラリのバージョンはサポートされていますか？また、修正はリリースされますか？

古いバージョンを使用できますが、修正は現在のリリース向けに提供されます。レガシーバージョン向けのパッチは提供されません。
