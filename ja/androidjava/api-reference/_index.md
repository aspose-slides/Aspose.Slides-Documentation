{{% alert color="info" %}}

Aspose.Slides for Android via Java は、Microsoft PowerPoint® やその他のソフトウェアを使用せずに、Android 用 Java アプリケーションがプレゼンテーション 文書を読み書きできるクラス ライブラリです。Aspose.Slides for Android via Java を使用すると、テキスト、図形、テーブル、アニメーションの管理、スライドへの音声および動画の追加、スライドのプレビュー、SVG や PDF 形式へのエクスポートなどが可能です。

最新の API リファレンスは [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/ja/androidjava/) で確認できます。

{{% /alert %}}
