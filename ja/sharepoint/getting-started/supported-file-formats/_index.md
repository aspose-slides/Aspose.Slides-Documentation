## **サポートされている Microsoft PowerPoint バージョン**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **サポートされているファイル形式**

Aspose.Slides for SharePoint は、SharePoint のドキュメント ライブラリに保存されている PPT および PPTX プレゼンテーションを変換します。他の種類のファイルは変換されません。

|**形式**|**説明**|**変換元**|**変換先**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|PowerPoint プレゼンテーション 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|PowerPoint プレゼンテーション 2007 以降|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|スライドまたはノート表示を含む Portable Document Format| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|スライドまたはノート表示を含む TIFF 画像| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML Paper Specification| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|HTML 形式のプレゼンテーション| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|スライドまたはノート表示を含む Shockwave Flash ムービー| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|OpenDocument プレゼンテーション| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|PowerPoint スライドショー 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|PowerPoint スライドショー 2007 以降| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|マクロ対応 PowerPoint プレゼンテーション| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|マクロ対応 PowerPoint スライドショー| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|PowerPoint テンプレート| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|マクロ対応 PowerPoint テンプレート| |{{< emoticons/tick >}}|

出力形式は変換ページの **変換先** で選択します。正確なオプション一覧については、[Multiple Format Support](/slides/ja/sharepoint/multiple-format-support/) を参照してください。
