Aspose.Slides for SharePoint をアンインストールするには:

1. インストール時に使用したセットアッププログラムを実行します。たとえば SharePoint Server 2019 の *Setup2019.exe* です。  
   同じバージョンがインストールされていると検出した場合、セットアッププログラムは修復または削除を提案します。異なるバージョンが検出された場合は、アップグレードまたは削除を提案します。
2. **Remove** を選択し、**Next** をクリックして Aspose.Slides for SharePoint をアンインストールします。
