Aspose.Slides for SharePoint は、SharePoint 2007 から 2019 用のファーム ソリューションで、サーバー上のドキュメント ライブラリに保存された PowerPoint プレゼンテーションを、Microsoft PowerPoint を使用せず、コードを書かずに変換します。

PPT および PPTX ファイルを PDF、TIFF、XPS、HTML、SWF、ODP、並びに PPS、PPSX、PPTM、PPSM、POTX、POTM の PowerPoint フォーマットに変換し、結果をドキュメント ライブラリに保存します。

## **最初のエクスポート**

Aspose.Slides for SharePoint はファームに一度インストールされ、有効化された任意のドキュメント ライブラリから使用できます：

1. [download page](https://releases.aspose.com/slides/sharepoint/) から ZIP アーカイブをダウンロードし、SharePoint ファーム内のサーバーに展開します。
2. ご使用の SharePoint バージョンに対応するセットアップ プログラム（*Setup2007.exe*、*Setup2010.exe*、*Setup2013.exe*、*Setup2016.exe* または *Setup2019.exe*）を実行します。SharePoint ソリューションをインストールおよびデプロイできるアカウントを使用します。ライセンス契約に同意し、機能を有効化するサイト コレクションを選択し、セットアップによりソリューションをデプロイさせます。各画面の説明は [Installation](/slides/ja/sharepoint/installing-aspose-slides-for-sharepoint/) にあります。
3. それらのサイト コレクションのいずれかのドキュメント ライブラリを開き、PPT または PPTX ファイルのメニューを開いて **Convert via Aspose.Slides** を選択します。SharePoint 2007 では、メニュー項目は **Convert with Aspose.Slides** と表示されます。
4. **Convert to** の下で **PDF - Adobe Portable Document** を選択します。必要に応じて宛先のファイル名とフォルダーを変更し、**Convert** をクリックします。
5. 変換が完了したら、**Destination Library** をクリックして新しい PDF ファイルが保存されているフォルダーを開きます。

ライセンスがない場合、変換されたファイルには評価用の透かしが付加されます — [Licensing](/slides/ja/sharepoint/installing-aspose-slides-for-sharepoint-license/) を参照してください。同じ手順のスクリーンショットは [Converting Microsoft PowerPoint Documents into Other Formats](/slides/ja/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/) をご覧ください。
