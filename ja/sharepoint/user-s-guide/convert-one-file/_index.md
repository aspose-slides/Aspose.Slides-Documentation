ドキュメント ライブラリ内のプレゼンテーションを変換するには:

1. PPT または PPTX ファイル（その Edit Control Block）のメニューを開き、**Convert via Aspose.Slides** を選択します。SharePoint 2007 では、メニュー項目は **Convert with Aspose.Slides** と呼ばれます。

   **SharePoint 2007 のドキュメント メニューで Convert with Aspose.Slides を選択する**

   ![SharePoint 2007 ドキュメント ライブラリ内のドキュメント メニュー。Convert with Aspose.Slides 項目が表示されています](convert-one-file_1.png)

2. 変換ページで、**Convert to** の下にある出力形式を選択します。必要に応じて、宛先ファイル名や宛先フォルダーを変更できます。
3. **Convert** をクリックします。
4. 変換が完了したら、**Source Library** または **Destination Library** をクリックしてドキュメント ライブラリに戻ります。変換されたファイルは宛先フォルダーにあります。

同じ手順と各ページのスクリーンショットは、[Microsoft PowerPoint ドキュメントを他のフォーマットに変換](/slides/ja/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/) にあります。
