{{% alert color="info" title="Note" %}}

SharePoint サイトは、特定のビジネス ニーズを満たすために、コラボレーション、コミュニケーション、コンテンツの保存を目的としています。情報共有とコミュニケーションを促進することで、個人のグループが共通の目標を達成できるようにします。情報は主に Web サイトとして提供され、Web ブラウザーを通じてアクセスされます。

{{% /alert %}}

## **SharePoint と Aspose.Slides とは何ですか？**

Aspose.Slides for SharePoint は、Microsoft PowerPoint プレゼンテーション (PPT と PPTX) を他の形式に変換するソリューションです: PDF、TIFF、XPS、HTML、SWF、ODP、PPS、PPSX、PPTM、PPSM、POTX および POTM。Microsoft PowerPoint を使用せずに、SharePoint サイト内の PowerPoint ファイルを変換できます。すべての形式の一覧は、[Supported File Formats](/slides/ja/sharepoint/supported-file-formats/) にあります。
