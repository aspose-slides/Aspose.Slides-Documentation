{{% alert color="info" title="Note" %}}

Aspose.Slides for SharePoint が SharePoint サーバーにインストールされ、サイトコレクションで有効化されると、ドキュメント ライブラリのドキュメント メニューに **Convert via Aspose.Slides** 項目が追加されます（以下参照）。SharePoint 2007 では、この項目は **Convert with Aspose.Slides** と呼ばれます。

**Aspose.Slides for SharePoint のインストールにより、Convert via Aspose.Slides 項目がドキュメント メニューに追加されます**

![Convert via Aspose.Slides 項目が含まれるドキュメント メニュー](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **プレゼンテーションの変換**

1. ドキュメント ライブラリで Microsoft PowerPoint プレゼンテーションを選択します。
2. メニューを開き、**Convert via Aspose.Slides** をクリックします。

   **Presentation 2 ファイルのメニュー、Convert via Aspose.Slides 項目が表示されています**

   ![ドキュメント ライブラリ内のプレゼンテーションのメニューで、Convert via Aspose.Slides 項目がハイライト表示されています](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. **Convert to** の下で出力形式を選択します。必要に応じて、出力ファイル名と保存先フォルダーを変更できます。
4. ファイルを変換するには **Convert** をクリックします。

   **変換ページでは、出力形式、ファイル名、保存先を選択できます**

   ![出力形式、保存先ファイル、保存先フォルダーが表示された変換ページ](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. 変換が完了すると、成功メッセージが表示されます。

   **変換が成功しました**

   ![変換結果ページ](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. **Source Library** （元フォルダーへ移動）または **Destination Library** （ファイルが保存されたフォルダーへ移動）をクリックします。

   変換されたドキュメントがドキュメント ライブラリに表示されます。

   **保存先のライブラリに表示された変換済みドキュメント**

   ![ドキュメント ライブラリ内の変換済みファイル](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

これらのスクリーンショットは、PDF、TIFF、XPS 形式のみが提供されていた旧バージョンで撮影されたものです。現在の変換ページでは、より多くの出力形式が利用可能です。詳細は [Multiple Format Support](/slides/ja/sharepoint/multiple-format-support/) を参照してください。

{{% /alert %}}

SharePoint 2010 以降では、ライブラリ内で 1 つまたは複数のプレゼンテーションを選択し、**Aspose Tools** リボン タブの **Convert Slides** をクリックすることもできます。これにより、同じ変換ページが開きます。
