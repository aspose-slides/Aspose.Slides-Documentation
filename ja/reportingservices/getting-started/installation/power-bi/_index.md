## **Power BI**

Power BI Report Server に Aspose.Slides for Reporting Services をインストールするには、同じインストール手順を使用します。

* [MSI インストーラでインストール](/slides/ja/reportingservices/install-with-msi-installer/)。インストール プログラムはインストール済みの Power BI Report Server を自動的に検出し、製品をインストールして、作業環境用に構成します。
* [手動でインストール](/slides/ja/reportingservices/install-manually/)。ZIP パッケージの *Bin\Universal* フォルダーからアセンブリを使用します。

Aspose.Slides for Reporting Services は Power BI Report Server からページングされたレポート (RDL) をエクスポートします。ホスト マシン上の .NET Framework 3.5 などの要件については、[システム要件](/slides/ja/reportingservices/system-requirements/) を参照してください。
