**Aspose.Slides for Reporting Services へようこそ**

Aspose.Slides for Reporting Services は、市場で唯一、Microsoft SQL Server 2005、2008、2012、2016、2017 Reporting Services（32ビットおよび64ビット）で実際の PPT および PPS レポートを生成できるソリューションです。テーブル、マトリックス、チャート、画像を含むすべての RDL レポート機能は、最高精度で Microsoft PowerPoint プレゼンテーションに変換されます。
