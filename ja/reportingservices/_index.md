Aspose.Slides for Reporting Services は、Microsoft SQL Server Reporting Services および Power BI Report Server 用のレンダリング拡張機能で、サーバー上に Microsoft PowerPoint がなくてもページング (RDL) レポートのエクスポート リストにプレゼンテーション形式を追加します。

レポートを PPT、PPTX、PPS、PPSX プレゼンテーションやスライドショー、ODP、XPS にエクスポートできます。

## **初めてのエクスポート**

コードを書く必要はありません。拡張機能をレポート サーバーにインストールすれば、その形式がサーバー上のすべてのページング レポートのエクスポート リストに表示されます。

1. .NET Framework 3.5 を含む、レポート サーバーが[システム要件](/slides/ja/reportingservices/system-requirements/)を満たしているか確認してください。
1. [ダウンロードページ](https://releases.aspose.com/slides/reportingservices/)から MSI インストーラ *Aspose.Slides for Reporting Services* をダウンロードします。手動でインストールする場合は、ZIP パッケージ *Aspose.Slides for Reporting Services (DLLs Only)* をダウンロードしてください。
1. 拡張機能をレポート サーバーにインストールします。MSI を管理者として実行し、[MSI インストーラでインストール](/slides/ja/reportingservices/install-with-msi-installer/)に記載された手順に従うか、ZIP パッケージの場合は[手動でインストール](/slides/ja/reportingservices/install-manually/)の手順に従ってください。
1. ブラウザーでレポート サーバーの Web ポータル (SQL Server 2014 以前では Report Manager) を開きます。デフォルトのアドレスは `https://<ComputerName>/reports` です。
1. ページング レポートを開きます。レポート ツールバーの**Export**リストを開き、**PPTX - PowerPoint 2007 Presentation via Aspose.Slides** を選択します。ツールバーに別の**Export**ボタンがある場合はそれを選択してください。
1. ブラウザーがダウンロードした PPTX ファイルを開くか保存してください。

ライセンスがない場合、エクスポートされたプレゼンテーションには評価用の透かしが付加されます—[ライセンス](/slides/ja/reportingservices/license-aspose-slides-for-reporting-services/)を参照してください。エクスポート リストの他の形式については、[対応ファイル形式](/slides/ja/reportingservices/supported-file-formats/)をご覧ください。
