## **OpenXML とは何ですか？**
OpenXML SDK は、Microsoft が提供する .NET SDK で、Microsoft Office 2007 以降のファイル形式を処理するためのものです。これらのファイル形式は基本的に zip 形式のパッケージであり、Office 用 Open XML SDK は、パッケージ内の Open XML パッケージや基礎となる Open XML スキーマ要素の操作を簡素化します。Open XML SDK のクラスは、開発者が Open XML パッケージで実行する多くの一般的なタスクをカプセル化しており、数行のコードで複雑な操作を行うことができます。

Open XML SDK 2.5 をインストールしたら、Visual Studio で既存のプロジェクトまたはアプリケーションを開くか、新しいプロジェクトまたはアプリケーションを作成します。その後、プロジェクトまたはアプリケーションに以下のコンポーネントへの参照を追加します。

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides for .NET**
Aspose.Slides for .NET は、Microsoft PowerPoint を使用せずに .NET アプリケーションが PowerPoint ドキュメントを読み取り、書き込み、操作できるユニークな PowerPoint® 管理コンポーネントです。

Aspose.Slides for .NET は、独自のアプリケーション内で PowerPoint ドキュメントを管理する機能を提供する初めてで唯一の .NET コンポーネントです。すべての Aspose .NET コンポーネントと同様に、Aspose.Slides はマネージド C# で記述され、非常に低価格で高速です。

## **はじめに**
ファイル形式ライブラリを探している開発者は、市場に出回っているライブラリが提供する機能を確認する必要があります。主に、オプションを選択する際に考慮される要素は次の 2 つです。

- 機能
- ライブラリの使用に要する労力

ファイルの処理に高速で使いやすく軽量なファイル形式ライブラリを求める .NET 開発者であれば、VSTO（Visual Studio tool for Office）と Aspose を比較する必要があります。このプロジェクトは、両方のライブラリの機能とコードを比較する際の助けとなります。
## **システム要件とサポートプラットフォーム**
### **システム要件**
以下のいずれかの Visual Studio Tools for Office エディションが必要です。

- Microsoft Visual Studio 2005 Tools for the Microsoft Office System
- Microsoft Visual Studio 2005 Tools for the 2007 Microsoft Office System
- Visual Studio 2008 Professional Edition
- Visual Studio 2008 Team Suite Edition
- Microsoft Office のいずれかのバージョン:
- Microsoft Office Professional 2003 SP1
- 2007 Microsoft Office system
### **サポートされているオペレーティングシステム**
- Windows 2000; Windows Server 2003; Windows Vista; Windows XP
### **サポートされている .NET Framework バージョン**
- .NET Framework 2.0 以降のみ。
