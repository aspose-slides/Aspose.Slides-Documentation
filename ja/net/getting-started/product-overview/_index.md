## **Aspose.Slides for .NET へようこそ！**

Aspose.Slides は、Microsoft PowerPoint® の管理 API であり、アプリケーションが Microsoft PowerPoint® を使用せずに PowerPoint プレゼンテーションを読み取り、書き込み、作成、変更できるようにします。ライブラリは、プレゼンテーション、スライド、図形、テーブル、テキスト、アニメーション、オーディオ、ビデオ、およびその他のプレゼンテーション要素の操作をサポートしています。

Aspose.Slides を使用すると、開発者はさまざまなソースからプレゼンテーションを開き、さまざまな PowerPoint 形式で保存し、PDF、TIFF、XPS、SWF、HTML、SVG などの形式にエクスポートし、スライドを画像として保存できます。API は、ドキュメント プロパティの管理、保護の適用、スライドのプレビュー、スライド コンテンツの編集、スライド ノートの操作、埋め込み OLE オブジェクトなどの高度なプレゼンテーション要素の処理機能も提供します。

## **Aspose.Slides for .NET を使用すべき理由**

- Aspose.Slides for .NET は、PowerPoint® ドキュメントの管理に必要な機能を提供する唯一のコンポーネントです。
- Aspose.Slides for .NET は、テキスト、図形、テーブル、アニメーションの管理、スライドへのオーディオおよびビデオの追加、スライドのプレビュー、SVG、PDF などへのエクスポートなど、多くの主要機能を提供します。
- Aspose.Slides for .NET は、さまざまなソースから PowerPoint ファイルを開くだけでなく、さまざまな方法でプレゼンテーションを保存できます。たとえば、プレゼンテーションを PPT 形式で保存したり、スライドを画像として保存したりできます。

- Aspose.Slides for .NET は、Microsoft PowerPoint で利用できる機能のほぼすべてを提供します。表やさまざまな形状に加えて、テキスト、オーディオ、ビデオ フレームなどさまざまなフレームをスライドに追加して使用できます。
- Aspose.Slides for .NET は Managed C# で開発されています。C#、VB.NET、J# などの任意の .NET 言語で使用でき、Web アプリケーションでも Windows アプリケーションでも利用できます。
- Aspose.Slides for .NET には、完全なデモと実用的なサンプルが用意されており、開発者が API をより深く理解できるよう支援します。

## **Aspose.Slides の機能**
Aspose.Slides for .NET の機能は次のカテゴリに分かれます。

1. プレゼンテーション機能。
1. スライド機能。
1. グラフィックおよびマルチメディア機能。
1. テーブル機能。
1. テキストと段落機能。
1. 高度な機能。

### **プレゼンテーション機能**
- さまざまなソースから Microsoft PowerPoint プレゼンテーションを開く。
- プレゼンテーションをさまざまな Microsoft PowerPoint 形式で保存。
- ゼロからプレゼンテーションを作成。
- 他のコンポーネントを使用せずにプレゼンテーションを PDF に変換。
- プレゼンテーションのドキュメント プロパティを読み取りまたは変更。
- プレゼンテーションに保護を適用。
- プレゼンテーションを PDF にエクスポート。
- プレゼンテーションを TIFF にエクスポート。
- プレゼンテーションを XPS にエクスポート。
- プレゼンテーションを SWF にエクスポート。
- プレゼンテーションを PDF ノート / TIFF ノートにエクスポート。
- プレゼンテーションを HTML にエクスポート。

### **スライド機能**
- ゼロから新しいスライドを作成し、プレゼンテーションに追加。
- プレゼンテーション内の位置で任意のスライドにアクセス。
- 同一または別のプレゼンテーションへスライドをコピーまたはクローン。
- スライドの編集および削除。
- マスターをスライドと自動的にコピー。
- スライドをプレビュー。
- スライドの名前を取得または設定。
- スライドを画像として保存。
- スライドを SVG 形式でエクスポート。
- プレゼンテーション内の複数のマスターを操作。
- 任意のサポートされているスタイルでスライド背景を塗りつぶし。
- 新しいスライド ノートを追加または管理。
- 動的に新しいスライド マスターとスタイルを設定。
- スライドショーの遷移を追加または変更。
- モーフ遷移を追加。

### **グラフィック & マルチメディア機能**
- 線、矩形、楕円、ポリラインなどの図形を作成または管理。
- 図形の線スタイルを管理。
- 図形の代替テキストを取得。
- 図形を回転・反転。
- 図形をさまざまなスタイルで塗りつぶし（例: 単色、グラデーション、パターン、テクスチャ、画像）。
- 48 の事前定義パターンと 24 のテクスチャを使用可能。
- 図形にリンクを割り当て。
- スライドと図形に新しいアニメーション効果を読み取り、変更、追加。
- プレゼンテーションに新しい画像を追加し、既存の画像を管理。
- プレゼンテーションに新しい画像バレットを追加し、既存のものを管理。
- プレゼンテーションに新しいオーディオ フレームを追加し、既存のものを管理。
- プレゼンテーションに新しいビデオ フレームを追加し、既存のものを管理。

### **テーブル機能**
- ゼロからテーブルを作成し、スライドに追加。
- テーブルのサイズ変更と移動。
- テーブル内の任意のセルにアクセス。
- 任意のセルの書式と罫線を変更。
- 行と列のサイズ変更。
- 行と列の追加および削除。
- テーブル全体の罫線幅と色を設定。

### **テキスト & 段落機能**
- テキスト プレースホルダーとテキスト フレームのテキストを取得および設定。
- プレースホルダーの種類を取得。
- テキスト フレーム内のテキスト書式を変更。
- 新しいフォントを追加またはプレゼンテーションで使用中のフォントを管理。
- テキストとテキスト書式を変更。
- テキストへのリンクを作成または管理。
- タブと有効タブをサポート。
- ほぼすべての形状に新しいテキスト フレームを追加。
- テキスト フレームの余白と折り返し設定にアクセスおよび変更。
- 段落インデントにアクセスおよび変更。

### **高度な機能**
- プレゼンテーションに埋め込まれた OLE オブジェクトにアクセス。
- プレゼンテーションをロック。

## **テクニカル サポート**
Aspose はすべての製品に対して無制限の無料テクニカルサポートを提供しています。サポートはすべてのユーザー（評価版ユーザーを含む）に利用可能です。Aspose.Slides for .NET について支援が必要な場合は、次の点をご検討ください。

- 主なサポート窓口は[Aspose Forums](https://forum.aspose.com/)です。[Aspose.Slides フォーラム](https://forum.aspose.com/c/slides/11)に質問を投稿すると、数時間以内に回答が得られます。Aspose.Slides のサポートチームが直接フォーラム上の質問に回答します。
- Aspose は電話によるテクニカルサポートは提供していません。電話サポートは販売・購入に関する質問のみ利用可能です。
- フォーラムでの返信を待つ際は、時差を考慮して辛抱強く待ってください。

Aspose.Slides for .NET に問題がある場合は、以下の手順に従ってできるだけ効率的に解決してください。

- 問題を報告する前に、まず最新バージョンの Aspose.Slides for .NET を使用していることを確認してください。問題はすでにアップデートで解決されている可能性があります。

  最新バージョンの情報は[Aspose.Slides ダウンロード](https://www.nuget.org/packages/Aspose.Slides.NET/)をご覧ください。

- 問題を報告する前に、フォーラム、ドキュメント、API リファレンスを確認してください。質問への回答が既に掲載されていることがあります。

- 問題を報告する際は、元のドキュメントと（可能であれば）問題に関連するコードの断片を添付してください。複数ファイルを添付する場合は ZIP パッケージにまとめます。

  Aspose.Forums にファイルを安全に添付できます。添付ファイルへアクセスできるのは投稿者と Aspose の開発者のみです。

- 特定の問題につき 1 つのスレッドを作成して使用してください。別の問題が発生した場合は、新しいスレッドを作成して報告してください。

## **信頼レベルの要件**

.NET Framework 上では、Aspose.Slides は完全信頼を必要とし、Medium Trust などの ASP.NET 部分信頼では動作しません。.NET 6 以降では信頼レベルの設定は不要です。詳細は[Trust Level Requirements](/slides/ja/net/declaration/)をご覧ください。

## **FAQ**

### アーカイブおよびアクセシビリティ用の PDF 準拠レベル（PDF/A、PDF/UA）をサポートしていますか？

はい。PDF/A-2a/2b/2u、PDF/A-3a/3b、PDF/UA での保存が可能で、[PDF エクスポート オプション](https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/)で設定できます。

### フォント置換機構やカスタム フォントのサポートはありますか？

はい。ライブラリは[カスタム フォントの読み込み](/slides/ja/net/custom-font/)と[フォント フォールバック ルールの定義](/slides/ja/net/fallback-font/)をサポートしており、変換やレンダリング時に不足 glyph を確実に置換できます。

### ファイルがパスワード保護されているかどうかを、完全に開かずに検出できますか？

はい。[プレゼンテーションを検査](/slides/ja/net/examine-presentation/)して、ロード前にパスワードが必要かどうかを判断できます。

### 処理や変換に Microsoft PowerPoint は必要ですか？

いいえ。Aspose.Slides は単体エンジンであり、サーバーやワークステーションに PowerPoint は不要です。

### 複数スレッドからの同時処理は安全ですか？

はい。別々のスレッドで異なるドキュメントを並列処理できます。ただし、同一プレゼンテーション インスタンスを複数スレッドで同時に使用しないでください（[マルチスレッド](/slides/ja/net/multithreading/)をご参照）。

### マクロは保持されますか？PPTM/PPSM ファイルの VBA を管理できますか？

はい。マクロ付きプレゼンテーションは[サポート](/slides/ja/net/presentation-via-vba/)されており、[VBA プロジェクトの検査と管理](https://reference.aspose.com/slides/net/aspose.slides.vba/)が可能です。

### PDF や HTML を PowerPoint スライドに変換できますか？

はい。[PDF ページや HTML コンテンツのインポート](/slides/ja/net/import-presentation/)でスライドを作成または追加できます。

### XPS エクスポートはサポートされており、品質や内容を制御できますか？

はい。[XPS へのエクスポート](/slides/ja/net/convert-powerpoint-to-xps/)が利用でき、[保存オプション](https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions/)で出力品質や含めるコンテンツを調整できます。

### スライドを画像に変換し、出力品質を制御できますか？

はい。スライドは[PNG、JPEG、GIF、BMP、TIFF](/slides/ja/net/convert-powerpoint-to-png/)などにレンダリングでき、サイズや品質を細かく設定可能です。

### 数式（MathML/MathText）はサポートされ、エクスポートできますか？

はい。[数式の作成と編集](/slides/ja/net/powerpoint-math-equations/)と[数式のエクスポート](/slides/ja/net/exporting-math-equations/)が可能で、MathML へのエクスポートもサポートしています。

### 暗号化とパスワードの取り扱い（開く、設定、削除）はどうですか？

はい。[暗号化されたプレゼンテーションのオープン](/slides/ja/net/password-protected-presentation/)、パスワードの設定・削除、保護状態のチェックをサポートしています。
