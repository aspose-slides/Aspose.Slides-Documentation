## **目的**
コンポーネントを選択する際、性能はしばしば最初の重要な要素になります。本稿では、Aspose.Slides for C++ と VSTO 2008 の性能を測定します。簡易テストは、同様のオペレーティングシステム、ハードウェア構成、設定の下で実施されています。  

本稿は **Aspose.Slides for C++** と **VSTO 2008** を含む製品の性能測定結果を提示します。ここに示す性能見積もりは、一般的に使用されるオペレーティングシステム上の標準ハードウェアで、類似した構成下におけるいくつかの一般的シナリオで、異なるコンポーネントから期待できる動作を理解する助けとなることを目的としています。もちろん、アプリケーションの性能はデータやデータアクセスパターン、キャッシュサイズ、その他の構成パラメータ、OS やハードウェアなどに依存します。本ベンチマークは、最低限のハードウェア条件下でコンポーネントがどのように動作するかを示すことを目的としており、ハードウェアが速ければ速いほど、コンポーネントによるタスク処理も高速になります。

## **テスト手法**
すべての性能テストは、カスタマイズされた構成やチューニング、その他の性能向上手法を用いず、共通のハードウェアとオペレーティングシステムの組み合わせで実施しました。テストは、他のプロセスが稼働していない同一システム上でコンポーネントをインストールした状態で実行されました。正確な測定値を得るために、すべてのタスクを二度または三度実行し、コンポーネントをより正確に評価しました。
