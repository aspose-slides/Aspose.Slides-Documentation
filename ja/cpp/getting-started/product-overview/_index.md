## **Aspose.Slides for C++ へようこそ！**

Aspose.Slides for C++ は、Microsoft PowerPoint® を使用せずに PowerPoint® ドキュメントの読み書きを可能にする Microsoft PowerPoint® 管理 API です。Aspose.Slides for C++ は、PowerPoint® ドキュメントの管理機能を提供する唯一のコンポーネントです。Aspose.Slides for C++ は、テキスト、図形、テーブルおよびアニメーションの管理、スライドへの音声・動画の追加、スライドのプレビュー、SVG や PDF 形式へのエクスポートなど、多くの主要機能を提供します。

## **製品の説明**
Aspose.Slides for C++ はネイティブ C++ で開発されています。現在は Windows x64 環境向けにコンパイルされていますが、Linux 環境向けにもコンパイルされる予定です。

Aspose.Slides for C++ は、さまざまなソースから PowerPoint ファイルを開くだけでなく、プレゼンテーションを多様な形式で保存できます。たとえば、プレゼンテーションを PPT だけでなく PDF 形式でも保存できます。さらに、スライドを画像として保存することも可能です。Aspose.Slides for C++ は、Microsoft PowerPoint で利用できるほぼすべての機能を提供します。Aspose.Slides for C++ の柔軟性は、テーブルやさまざまな形状をスライドに追加できるだけでなく、テキスト、音声、動画フレームといったさまざまなフレームも追加できる点にあります。

## **豊富な機能セット**
Aspose.Slides for C++ の機能は次の領域に分けられます。

1. プレゼンテーション機能。
1. スライド機能。
1. グラフィックおよびマルチメディア機能。
1. テーブル機能
1. テキスト & 段落機能
1. 高度な機能

### **プレゼンテーション機能**
- さまざまなソースから Microsoft PowerPoint プレゼンテーションを開く。
- 異なる Microsoft PowerPoint 形式でプレゼンテーションを保存。
- ゼロからプレゼンテーションを作成。
- 他のコンポーネントを使用せずにプレゼンテーションを PDF に変換。
- プレゼンテーションのドキュメントプロパティを読み取るまたは変更。
- プレゼンテーションに保護を適用。
- プレゼンテーションを PDF にエクスポート。
- プレゼンテーションを XPS にエクスポート。
- プレゼンテーションを SWF にエクスポート。
- プレゼンテーションのノートを PDF にエクスポート。
- プレゼンテーションを HTML にエクスポート。

### **スライド機能**
- ゼロから新しいスライドを作成し、プレゼンテーションに追加。
- プレゼンテーション内の位置で任意のスライドにアクセス。
- 同一または別のプレゼンテーションへスライドをコピーまたはクローン。
- スライドの編集と削除。
- マスタとスライドを自動的にコピー。
- スライドをプレビュー。
- スライドの名前を取得または設定。
- スライドを画像として保存。
- スライドを SVG 形式にエクスポート。
- プレゼンテーション内で多数のマスタを操作。
- 任意のサポートスタイルでスライドの背景を塗りつぶし。
- 新しいスライドノートを追加または管理。
- 動的に新しいスライドマスタとスタイルを設定。
- スライドショー遷移を追加または変更。
- モーフ遷移を追加。

### **グラフィック & マルチメディア機能**
- 線、矩形、楕円、ポリラインなどの形状を作成または管理。
- 形状の線スタイルを管理。
- 形状の代替テキストを取得。
- 形状を回転または反転。
- ソリッド、グラデーション、パターン、テクスチャ、画像などのさまざまなスタイルで形状を塗りつぶし。
- 48 個の事前定義パターンと 24 個のテクスチャを使用。
- 形状にリンクを割り当て。
- スライドおよび形状に新しいアニメーション効果を読み取り、変更、または追加。
- プレゼンテーションに新しい画像を追加または既存画像を管理。
- プレゼンテーションに新しい画像バレットを追加または既存バレットを管理。
- プレゼンテーションに新しい音声フレームを追加または既存フレームを管理。
- プレゼンテーションに新しい動画フレームを追加または既存フレームを管理。

### **テーブル機能**
- ゼロからテーブルを作成し、スライドに追加。
- テーブルのサイズ変更と移動。
- テーブル内の任意のセルにアクセス。
- 任意のセルの書式と罫線を変更。
- 列と行のサイズ変更。
- 列と行の追加および削除。
- テーブル全体の罫線幅と色を設定。

### **テキスト & 段落機能**
- テキストプレースホルダーとテキストフレームのテキストを取得および設定。
- プレースホルダーのタイプを取得。
- テキストフレーム内のテキスト書式を変更。
- プレゼンテーションで使用されるフォントを新規追加または既存フォントを管理。
- テキストとテキスト書式を変更。
- テキストへのリンクを作成または管理。
- タブと効果的なタブをサポート。
- ほぼすべての形状タイプに新しいテキストフレームを追加。
- テキストフレームの余白とテキスト折り返し設定にアクセスおよび変更。
- 段落インデントにアクセスおよび変更。

### **高度な機能**
- プレゼンテーションに埋め込まれた OLE オブジェクトにアクセス。
- プレゼンテーションをロック。

## **サポート対象プラットフォーム**

## **テクニカルサポート**
Aspose はすべての製品に対して無制限の無料テクニカルサポートを提供しています。評価版を含むすべてのユーザーが利用可能です。Aspose.Slides for C++ に関して支援が必要な場合、次の点を検討してください。

- 主なサポート窓口は[Aspose フォーラム](https://forum.aspose.com/)です。[Aspose.Slides フォーラム](https://forum.aspose.com/c/slides/ja/11)に質問を投稿すると、数時間以内に回答が得られます。質問は Aspose.Slides サポートチームが直接回答します。
- Aspose は電話によるテクニカルサポートは提供していません。電話サポートは販売・購入に関する質問のみ利用可能です。
- フォーラムでの返信を期待する場合、時差を考慮してください。

Aspose.Slides for C++ に問題がある場合、以下の手順で効率的に解決できるようにしてください。

- 問題を報告する前に、最新バージョンの Aspose.Slides for C++ を使用していることを確認してください。最新バージョンは[Aspose.Slides ダウンロード](https://downloads.aspose.com/slides/ja/cpp)で確認できます。
- フォーラムや本ドキュメント、API リファレンスを確認し、同様の質問が既に回答されていないか確認してください。
- 問題を報告するときは、元のドキュメントと問題を引き起こすコードの断片を必ず添付してください。複数ファイルを添付する場合は、1 つの zip にまとめてください。Aspose フォーラムでは、添付ファイルはあなたと Aspose の開発者だけがアクセスできます。
- 1 つのスレッドにつき 1 件の問題を報告してください。別の問題がある場合は、別スレッドで報告してください。

## **FAQ**

**PDF/A および PDF/UA など、アーカイブやアクセシビリティ向けの PDF 準拠レベルをサポートしていますか？**

はい。PDF/A-2a/2b/2u、PDF/A-3a/3b、PDF/UA での保存が可能です。詳細は[PDF エクスポートオプション](https://reference.aspose.com/slides/ja/cpp/aspose.slides.export/pdfoptions/)をご参照ください。

**フォント置換機構やカスタムフォントのサポートはあり、正しいレンダリングが保証されますか？**

はい。ライブラリは[カスタムフォントの読み込み](/slides/ja/cpp/custom-font/)と[フォールバック規則の定義](/slides/ja/cpp/fallback-font/)を提供し、欠損字形を確実に置換します。

**ファイルがパスワード保護されているかどうかを、完全に開かずに検出できますか？**

はい。[プレゼンテーションの検査](/slides/ja/cpp/examine-presentation/)により、ロード前にパスワードが必要かどうかを判断できます。

**Microsoft PowerPoint は処理や変換に必須ですか？**

いいえ。Aspose.Slides はスタンドアロンエンジンであり、サーバーやワークステーションに PowerPoint は不要です。

**複数スレッドから安全にプレゼンテーションを処理できますか？**

はい。異なるドキュメントを別スレッドで並行処理できますが、同一プレゼンテーションインスタンスをスレッド間で同時に使用しないでください。詳しくは[マルチスレッド処理](/slides/ja/cpp/multithreading/)をご覧ください。

**マクロは保持され、PPTM/PPSM ファイルの VBA を管理できますか？**

はい。マクロ付きプレゼンテーションは[サポート](/slides/ja/cpp/presentation-via-vba/)されており、[VBA プロジェクトの検査と管理](https://reference.aspose.com/slides/ja/cpp/aspose.slides.vba/)が可能です。

**PDF や HTML を PowerPoint スライドに変換できますか？**

はい。[PDF ページまたは HTML コンテンツのインポート](/slides/ja/cpp/import-presentation/)により、スライドを作成または充填できます。

**XPS エクスポートはサポートされており、品質や内容を制御できますか？**

はい。[XPS へのエクスポート](/slides/ja/cpp/convert-powerpoint-to-xps/)が利用可能で、[保存オプション](https://reference.aspose.com/slides/ja/cpp/aspose.slides.export/xpsoptions/)で出力品質や含めるコンテンツを調整できます。

**スライドを画像に変換し、出力品質を制御できますか？**

はい。スライドは PNG、JPEG、GIF、BMP、TIFF などに[レンダリング](/slides/ja/cpp/convert-powerpoint-to-png/)でき、サイズや品質を細かく制御できます。

**数式（MathML/MathText）はサポートされ、エクスポートできますか？**

はい。[数式テキストの作成と編集](/slides/ja/cpp/powerpoint-math-equations/)と[数式のエクスポート](/slides/ja/cpp/exporting-math-equations/)が可能で、MathML へのエクスポートもサポートしています。

**暗号化やパスワード（開く、設定、削除）の取り扱いはどうなっていますか？**

[暗号化されたプレゼンテーションのオープン](/slides/ja/cpp/password-protected-presentation/)、開閉や変更のパスワード設定・削除、保護状態の確認がサポートされています。
