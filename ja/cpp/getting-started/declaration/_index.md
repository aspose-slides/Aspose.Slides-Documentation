{{% alert color="info" %}} 

すべての Aspose C++ コンポーネントは Full Trust パーミッション セットが必要です。

その理由は、Aspose C++ コンポーネントがレジストリ設定や、フォントの解析などの特定の操作のために仮想ディレクトリ以外のシステムファイルにアクセスする必要があるためです。

さらに、Aspose C++ コンポーネントはコア C++ システムクラスに基づいており、多くの場合 Full Trust パーミッション セットが必要となります。

{{% /alert %}}
