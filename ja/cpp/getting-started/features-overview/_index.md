## **ファイル形式と変換**
Aspose.Slides forC++ は、ほとんどの PowerPoint ドキュメント形式をサポートし、組織間で広く使用されている一般的な形式へエクスポートも行います。以下の表にこれらの形式が列挙されています：

|**機能**|**説明**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ja/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ はこのプレゼンテーション ドキュメント形式の処理が最も高速です。|
|[ポータブルドキュメント形式 (PDF)](/slides/ja/cpp/portable-document-format-pdf/)|サポートされているファイル形式は、単一のメソッドで Adobe Portable Document Format (PDF) ドキュメントへエクスポートできます。|
|[XML パーサー仕様 (XPS)](/slides/ja/cpp/xml-parser-specification-xps/)|サポートされているすべてのファイル形式は、単一のメソッドで XML Parser Specification (XPS) ドキュメントへエクスポートできます。|
|[PresentationML (PPTX, XML)](/slides/ja/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ は、PresentationML（PPTX）としても知られる OOXML プレゼンテーション形式の処理をサポートします。|
|[PPTX から HTML への変換](https://docs.aspose.com/slides/ja/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ はプレゼンテーションを HTML 形式へ変換する機能を提供します。|

## **プレゼンテーションのレンダリング**
Aspose.Slides for C++ は、プレゼンテーション ドキュメント内のスライドを以下に示すさまざまなグラフィック形式へ高忠実度でレンダリングします：

|**機能**|**説明**|
| :- | :- |
|C++ がサポートする画像形式|Aspose.Slides for C++ を使用すると、プレゼンテーション スライドだけでなく、スライド上の画像も PNG、BMP、JPEG などのすべての C++ 対応グラフィック形式へレンダリングできます。|
|SVG 形式|Aspose.Slides for C++ は、プレゼンテーション スライドを Scalable Vector Graphics (SVG) 形式へエクスポートする組み込みメソッドも提供します。|

## **コンテンツ機能**
Aspose.Slides forC++ を使用すると、プレゼンテーション ドキュメントのほぼすべてのコンテンツにアクセス、変更、作成が可能です。

|**機能**|**説明**|
| :- | :- |
|マスタースライド|マスタースライドは通常のスライドのレイアウトを定義します。Aspose.Slides for C++ ではプレゼンテーション ドキュメントのマスタースライドにアクセスし、変更できます。|
|通常スライド|Aspose.Slides for C++ を使用すると、さまざまなタイプの新しいスライドを作成できるだけでなく、既存のスライドにアクセスして変更することもできます。|
|スライドの複製／コピー|Aspose.Slides for C++ には、スライドを同一プレゼンテーション内だけでなく別のプレゼンテーション間でもクローンまたはコピーする組み込みメソッドがあります。スライドはマスタースライドからレイアウトを継承するため、組み込みのクローンメソッドはマスターも自動的にコピーします。|
|プレースホルダーとテキストホルダー|スライド内のプレースホルダーとテキストホルダーにもアクセスできます。さらに、適切なメソッドを使用してテキストホルダーだけのスライドをゼロから作成できます。|
|ヘッダーとフッター|Aspose.Slides for C++ はスライドのヘッダー／フッターの操作もサポートします。|
|スライドのメモ|Aspose.Slides for C++ を使用すると、スライドに関連付けられたメモにアクセスして変更できるだけでなく、メモを追加することもできます。|
|シェイプの検索|シェイプに関連付けられた代替テキストを使用して、スライド内の特定のシェイプを検索できます。|
|背景|Aspose.Slides for C++ は、プレゼンテーションのマスターまたは通常スライドに関連付けられた背景の操作を可能にします。|
|テキスト ボックス|テキスト ボックスはゼロから作成できます。既存のテキスト ボックスにアクセスし、元のテキスト形式を失うことなくテキストを変更することもできます。|
|長方形シェイプ|長方形シェイプは Aspose.Slides for C++ によって作成または変更できます。|
|ポリライン シェイプ|ポリライン シェイプも Aspose.Slides for C++ によって作成または変更できます。|
|楕円シェイプ|楕円シェイプも Aspose.Slides for C++ によって作成または変更できます。|
|グループ シェイプ|Aspose.Slides for C++ はグループ シェイプもサポートします。|
|オート シェイプ|オート シェイプも Aspose.Slides for C++ がサポートしています。|
|シェイプのシリアライズ|Aspose.Slides for C++ は多数のシェイプをサポートしていますが、サポートされていないシェイプがある場合、既存のスライドからそのシェイプをシリアライズして後で使用できるメソッドが提供されています。|
|画像フレーム|画像は Aspose.Slides for C++ を使用して画像フレーム内で管理されます。|
|オーディオ フレーム|オーディオ ファイルは、オーディオ フレーム内でリンクまたは埋め込みとしてスライドに配置できます。|
|ビデオ フレーム|ビデオ ファイルは Aspose.Slides for C++ を通じてビデオ フレーム内で処理されます。|
|OLE フレーム|OLE オブジェクトは Aspose.Slides for C++ によって OLE フレーム内で管理されます。|
|テーブル|スライド上のテーブルも Aspose.Slides for C++ がサポートします。|
|テキスト フレーム|任意のシェイプに関連付けられたテキストは、そのシェイプに紐付くテキスト フレームを通じて取得できます。|
|テキスト スキャン|プレゼンテーション全体または個々のスライドレベルでテキストをスキャンできる組み込みスキャン メソッドがあります。|
|アニメーション|シェイプにアニメーションを適用できます。|
|スライドショー|スライドショー、スライド遷移、モーフ遷移もサポートされています。|

## **書式設定機能**
Aspose.Slides for C++ を使用すると、プレゼンテーション ドキュメント内のスライド上のテキストやシェイプをフォーマットできます。

|**機能**|**説明**|
| :- | :- |
|テキスト書式設定|<p>Aspose.Slides for C++ では、テキストはシェイプに紐付くテキスト フレームを通じて管理されます。そのため、テキストはテキスト フレームに関連付く段落と部分を使用して書式設定できます。以下のテキスト要素を Aspose.Slides for C++ で書式設定できます。</p><p>- フォント タイプ</p><p>- フォント サイズ</p><p>- フォント カラー</p><p>- フォント シェード</p><p>- 段落の配置</p><p>- 段落の箇条書き</p><p>- 段落の方向</p>|
|シェイプ書式設定|<p>Aspose.Slides for C++ では、スライドの基本要素はシェイプです。以下のシェイプ要素を Aspose.Slides for C++ で書式設定できます。</p><p>- 位置</p><p>- 大きさ</p><p>- 線</p><p>- 塗りつぶし（パターン、グラデーション、単色を含む）</p><p>- テキスト</p><p>- 画像</p>|

## **よくある質問**

### ライブラリを使用するためにサーバー/PC に Microsoft PowerPoint をインストールする必要がありますか？

いいえ。PowerPoint は必要ありません。Aspose.Slides はプレゼンテーションの作成、編集、変換、レンダリングのためのスタンドアロン エンジンです。

### マルチスレッドはどのように機能しますか？処理を並列化できますか？

異なるスレッドで異なるドキュメントを処理することは安全です。同一の[presentation](https://reference.aspose.com/slides/ja/cpp/aspose.slides/presentation/) オブジェクトを[複数のスレッド](/slides/ja/cpp/multithreading/)で同時に使用してはいけません。

### ファイルのパスワードと暗号化はサポートされていますか？

はい。[暗号化されたプレゼンテーション](/slides/ja/cpp/password-protected-presentation/)を開くことができ、開くパスワードと書き込みパスワードの設定または削除、保護状態の確認が可能です。

### Linux コンテナーでフォントパッケージに注意する必要がありますか？

はい。一般的なフォントパッケージをインストールするか、アプリケーションで[フォントディレクトリを明示的に指定](/slides/ja/cpp/custom-font/)することが推奨されます。これにより予期しない置換を防げます。

### 評価版に制限がありますか？

[評価モード](/slides/ja/cpp/licensing/)では、出力に透かしが追加され、いくつかの制限が適用されます。フル機能のテスト用に[30 日間の一時ライセンス](https://purchase.aspose.com/temporary-license/)が利用可能です。

### 外部形式（PDF/HTML → PPTX）のインポートはサポートされていますか？

はい。[PDF ページや HTML コンテンツ](/slides/ja/cpp/import-presentation/)をプレゼンテーションに追加し、スライドに変換できます。
