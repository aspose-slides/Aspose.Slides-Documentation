## **ファイル形式と変換**
Aspose.Slides for C++ はほとんどの PowerPoint 文書形式をサポートし、組織間で広く使用される一般的な形式にもエクスポートできます。以下の表にこれらの形式を列挙しています。

|**機能**|**説明**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ja/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ はこのプレゼンテーション文書形式に対して最速の処理を提供します。|
|[Portable Document Format (PDF)](/slides/ja/cpp/portable-document-format-pdf/)|サポートされているファイル形式は、1つのメソッドで Adobe Portable Document Format (PDF) ドキュメントにエクスポートできます。|
|[XML Parser Specification (XPS)](/slides/ja/cpp/xml-parser-specification-xps/)|サポートされているすべてのファイル形式は、1つのメソッドで XML Parser Specification (XPS) ドキュメントにエクスポートできます。|
|[PresentationML (PPTX, XML)](/slides/ja/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ は、PresentationML または PPTX とも呼ばれる OOXML プレゼンテーション形式の処理をサポートします。|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/ja/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ は、プレゼンテーションを HTML 形式に変換することをサポートします。|

## **レンダリング**
Aspose.Slides for C++ は、プレゼンテーション文書内のスライドを以下に示すさまざまなグラフィック形式に高忠実度でレンダリングします。

|**機能**|**説明**|
| :- | :- |
|C++ がサポートする画像形式|Aspose.Slides for C++ を使用すると、プレゼンテーションスライドだけでなく、スライド上の画像も PNG、BMP、JPEG など C++ がサポートするすべてのグラフィック形式でレンダリングできます。|
|SVG 形式|Aspose.Slides for C++ は、プレゼンテーションスライドを Scalable Vector Graphics (SVG) 形式にエクスポートする組み込みメソッドも提供します。|

## **コンテンツ機能**
Aspose.Slides for C++ を使用すると、プレゼンテーション文書のほぼすべてのコンテンツにアクセス、変更、作成できます。

|**機能**|**説明**|
| :- | :- |
|マスタースライド|マスタースライドは通常スライドのレイアウトを定義します。Aspose.Slides for C++ を使用すると、プレゼンテーション文書のマスタースライドにアクセスし、変更できます。|
|ノーマルスライド|Aspose.Slides for C++ を使用すると、さまざまなタイプの新しいスライドを作成できるだけでなく、プレゼンテーション文書内の既存スライドにアクセスして変更できます。|
|スライドのクローン作成/コピー|Aspose.Slides for C++ が提供する組み込みメソッドにより、スライドを同一プレゼンテーション内だけでなく、別のプレゼンテーションへもクローンまたはコピーできます。スライドはマスタースライドからレイアウトを継承するため、クローン作成時にマスターも自動的にコピーされます。|
|プレースホルダーとテキストホルダー|スライド内のプレースホルダーとテキストホルダーにもアクセスできます。また、適切なメソッドを使用してテキストホルダーを持つスライドをゼロから作成できます。|
|ヘッダーとフッター|Aspose.Slides for C++ はスライドのヘッダー/フッターの操作もサポートします。|
|スライドのノート|Aspose.Slides for C++ を使用すると、スライドに関連付けられたノートにアクセス・変更できるだけでなく、ノートを追加することもできます。|
|図形の検索|図形に関連付けられた代替テキストを使用して、スライド内の特定の図形を検索できます。|
|背景|Aspose.Slides for C++ は、プレゼンテーションのマスターまたは通常スライドに関連付けられた背景の操作を可能にします。|
|テキストボックス|テキストボックスはゼロから作成できます。既存のテキストボックスにアクセスし、そのテキストを元の書式を失わずに変更することもできます。|
|矩形図形|矩形図形は Aspose.Slides for C++ によって作成または変更できます。|
|ポリライン図形|ポリライン図形も Aspose.Slides for C++ によって作成または変更できます。|
|楕円形図形|楕円形図形も Aspose.Slides for C++ によって作成または変更できます。|
|グループ図形|Aspose.Slides for C++ はグループ図形もサポートします。|
|オートシェイプ|オートシェイプも Aspose.Slides for C++ がサポートします。|
|図形のシリアル化|Aspose.Slides for C++ は多くの図形をサポートしていますが、サポート外の図形が存在する場合、既存スライドからその図形をシリアル化し、後で Aspose.Slides for C++ で使用できるシリアル化メソッドが提供されています。|
|画像フレーム|画像は Aspose.Slides for C++ を使用して画像フレームで管理されます。|
|オーディオフレーム|オーディオファイルは Aspose.Slides for C++ によってスライド上のオーディオフレームにリンクまたは埋め込むことができます。|
|ビデオフレーム|ビデオファイルは Aspose.Slides for C++ を通じてビデオフレームで処理されます。|
|OLE フレーム|OLE オブジェクトは Aspose.Slides for C++ によって OLE フレームで管理されます。|
|テーブル|スライド上のテーブルも Aspose.Slides for C++ がサポートします。|
|テキストフレーム|任意の図形に関連付けられたテキストは、その図形に紐付くテキストフレームを介してアクセスできます。|
|テキストスキャン|プレゼンテーション全体またはスライド単位でテキストをスキャンする組み込みメソッドがあります。|

## **書式設定機能**
Aspose.Slides for C++ を使用すると、プレゼンテーション文書内のスライド上のテキストや図形の書式設定が可能です。

|**機能**|**説明**|
| :- | :- |
|テキスト書式設定|<p>Aspose.Slides for C++ では、テキストは図形に関連付くテキストフレームを通じて管理されます。そのため、テキストフレームに含まれる段落や部分を使用してテキストを書式設定できます。以下のテキスト要素を Aspose.Slides for C++ で書式設定できます。</p><p>- フォントタイプ</p><p>- フォントサイズ</p><p>- フォントカラー</p><p>- フォントシェード</p><p>- 段落の配置</p><p>- 段落の箇条書き</p><p>- 段落の方向</p>|
|図形書式設定|<p>Aspose.Slides for C++ では、スライドの基本要素は図形です。以下の図形要素を Aspose.Slides for C++ で書式設定できます。</p><p>- 位置</p><p>- サイズ</p><p>- 線</p><p>- 塗りつぶし（パターン、グラデーション、単色を含む）</p><p>- テキスト</p><p>- 画像</p>|

## **FAQ**

**ライブラリを使用するためにサーバー/PCに Microsoft PowerPoint をインストールする必要がありますか？**

いいえ。PowerPoint は必要ありません。Aspose.Slides は、プレゼンテーションの作成、編集、変換、レンダリングを行う単体エンジンです。

**マルチスレッドはどのように機能しますか？処理を並列化できますか？**

異なるスレッドで異なるドキュメントを処理することは安全です。同じ [presentation](https://reference.aspose.com/slides/ja/cpp/aspose.slides/presentation/) オブジェクトを同時に [複数のスレッド](/slides/ja/cpp/multithreading/) で使用してはいけません。

**ファイルのパスワードと暗号化はサポートされていますか？**

はい。 [できます](/slides/ja/cpp/password-protected-presentation/) 暗号化されたプレゼンテーションを開き、開くパスワードや書き込みパスワードを設定または削除でき、保護状態を確認できます。

**Linux コンテナでフォントパッケージに注意する必要がありますか？**

はい。予期しない置き換えを防ぐため、一般的なフォントパッケージをインストールするか、アプリケーションで明示的に [フォントディレクトリを指定](/slides/ja/cpp/custom-font/) することを推奨します。

**評価版に制限がありますか？**

[評価モード](/slides/ja/cpp/licensing/) では、出力に透かしが追加され、いくつかの制限が適用されます。フル機能のテストのために、[30日間の一時ライセンス](https://purchase.aspose.com/temporary-license/) が利用可能です。

**外部形式（PDF/HTML → PPTX）をプレゼンテーションにインポートすることはサポートされていますか？**

はい。[PDF ページと HTML コンテンツ](/slides/ja/cpp/import-presentation/) をプレゼンテーションに追加して、スライドに変換できます。
