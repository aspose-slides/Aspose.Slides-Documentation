**Aspose.Slides for C++ へようこそ**

Aspose.Slides for C++ は、Microsoft PowerPoint® を使用せずに、C++ アプリケーションが PowerPoint® ドキュメントを読み書きできる Microsoft PowerPoint® 管理 API です。Aspose.Slides for C++ は、PowerPoint® ドキュメントを管理する機能を提供する、唯一かつ最初のコンポーネントです。Aspose.Slides for C++ は、テキスト、図形、テーブルやアニメーションの管理、スライドへの音声および動画の追加、スライドのプレビュー、SVG や PDF 形式へのエクスポートなど、多くの主要機能を提供します。
