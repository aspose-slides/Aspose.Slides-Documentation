**Aspose.Slides for C++へようこそ**

Aspose.Slides for C++ は、Microsoft PowerPoint® を使用せずに C++ アプリケーションが PowerPoint® ドキュメントを読み書きできるようにする Microsoft PowerPoint® 管理 API です。Aspose.Slides for C++ は、PowerPoint® ドキュメントの管理機能を提供する最初で唯一のコンポーネントです。テキスト、図形、表やアニメーションの管理、スライドへの音声・動画の追加、スライドのプレビュー、スライドの SVG や PDF 形式へのエクスポートなど、多くの主要機能を提供します。
