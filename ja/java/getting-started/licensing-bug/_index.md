{{% alert color="info" title="Note" %}}
これは履歴ページです。2023年にリリースされた Aspose.Slides for Java のバージョン 23.2 から 23.7 のバグと、その修正バージョンについて説明しています。現在のバージョンについては説明していません。現在のバージョンのライセンスについては、[Licensing](/slides/ja/java/licensing/) を参照してください。
{{% /alert %}}

## **概要**

この記事では、Aspose.Slides for Java のバージョン 23.2、23.3、23.4、23.5、23.6、23.7 で発生したライセンス バグについて説明します。このバグにより、永続ライセンスがサブスクリプションの有効期限切れ後に一時的に使用不能になることがありました。

## **症状**

永続ライセンスのサブスクリプションが期限切れになると、Aspose.Slides for Java のバージョン 23.2〜23.7 はライセンスが期限切れであると報告し、すべての機能が評価モードに切り替わる場合があります。この動作は誤っており、23.2 より前および 23.7 より後のバージョンには影響しません。

## **対策**

Aspose.Slides for Java はこの問題に対処し、修正済みの更新バージョン (23.2.1、23.3.1、23.4.1、23.5.1、23.6.1、23.7.1) をリリースしました。

プロジェクトで影響を受けた Aspose.Slides for Java のバージョンのいずれかを使用している場合は、修正済みバージョンに切り替えてください。

Aspose.Slides for Java でライセンスに関する問題が発生した場合:

- 使用しているバージョンを確認し、上記のバグの影響を受けていないことを確認してください。
- ライセンスの適用方法と検証方法については、[Licensing](/slides/ja/java/licensing/) を参照してください。
- さらなるサポートが必要な場合は、[Aspose support](https://forum.aspose.com/c/slides/ja/11) にお問い合わせください。

## **影響を受ける製品とバージョン**

このバグは Aspose.Slides for Java のバージョン 23.2 から 23.7 のみが対象であることに注意してください。**他の Aspose 製品や Aspose.Slides の他のバージョンは影響を受けません**。
