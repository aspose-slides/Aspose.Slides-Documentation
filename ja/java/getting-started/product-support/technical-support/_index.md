## **概要**

この記事では、Aspose.Slides のサポート取得方法と効果的な問題報告方法について説明します。主なサポートチャネルを説明し、問題の提出に関する推奨事項を提供するとともに、製品ページ、ブログ、ダウンロード、サポートフォーラム、ドキュメント、API リファレンスなどの便利な技術リソースへのリンクを示します。また、有料サポート、問題のエスカレーション、古いライブラリ バージョンのサポートに関する一般的な質問にも回答しています。

## **テクニカルサポート**

{{% alert color="info" %}} 
Aspose はすべての製品に対して無制限の無料テクニカルサポートを提供しています。評価版を含むすべてのユーザーがサポートを利用できます。
{{% /alert %}} 

If you need help with Aspose.Slides for Java, consider the following:

- サポートの主な手段は Aspose.Forums です。Aspose.Slides フォーラムに質問を投稿すると、数時間以内に回答が得られます。質問は Aspose.Slides のサポートチームが直接回答します。
- ご注意ください。Aspose は電話によるテクニカルサポートは提供していません。電話サポートは販売や購入に関する質問にのみ利用可能です。
- フォーラムでの返信を期待する場合は、タイムゾーンの違いを考慮してください。

If you have an issue with Aspose.Slides for Java, follow these simple steps to make sure it is resolved in the most efficient way:

- 問題を報告する前に、最新の Aspose.Slides for Java バージョンを使用していることを確認してください。最新バージョンは Aspose.Slides ダウンロードページで確認できます。
- 問題を報告する前に、フォーラム、このドキュメント、API リファレンスを確認してください。質問はすでに回答されている可能性があります。
- 問題を報告する際は、元のドキュメントと、可能であれば問題を引き起こすコードの一部を添付してください。複数のファイルを添付する必要がある場合は、1つの zip にまとめてください。Aspose.Forums に添付したドキュメントは、あなたと Aspose の開発者だけがアクセスできるため、安全です。
- 1つのスレッドにつき1つの問題を報告するようにしてください。別の問題がある場合は、別のスレッドで報告してください。

## **よくある質問**

### 利用可能な有料サポート層とその違いは何ですか？

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。インシデント数、応答優先度、利用可能なコミュニケーションチャネルにより違いがあります。

### バグを直接エンジニアリングチームにエスカレーションできますか？

はい。[Paid support](https://helpdesk.aspose.com/) は、問題がより深い調査を必要とする場合に開発者へのエスカレーションを可能にします。

### 古いライブラリバージョンはサポートされていますか？また、修正はリリースされますか？

古いバージョンを使用することは可能ですが、修正は現在のリリースに対してのみ提供されます。レガシーバージョン向けのパッチは提供されません。
