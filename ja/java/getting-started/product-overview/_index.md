## **Aspose.Slides for Javaへようこそ！**

Aspose.Slides for Java は、Microsoft PowerPoint® を使用せずに Java アプリケーションが PowerPoint® ドキュメントの読み取りと書き込みを行える Microsoft PowerPoint® 管理 API です。

Aspose.Slides for Java は、PowerPoint® ドキュメントの管理に必要な機能を提供する、初めてかつ唯一のコンポーネントです。

Aspose.Slides for Java は、テキスト、図形、表およびアニメーションの管理、スライドへの音声・動画の追加、スライドのプレビュー、SVG、PDF などへのエクスポートなど、多くの主要機能を提供します。

## **製品の説明**

Aspose.Slides for Java は、さまざまなソースから PowerPoint ファイルを開くだけでなく、プレゼンテーションをさまざまな形式で保存することも可能です。たとえば、プレゼンテーションを PPT 形式で保存したり、スライドを画像として保存したりできます。

Aspose.Slides for Java は、Microsoft PowerPoint で見つかるかもしれない、あるいは見つからないほとんどすべての機能を提供します。Aspose.Slides for Java の汎用性により、表やさまざまな形状に加えて、テキスト、音声、動画のフレームといったさまざまなフレームをスライドに追加できます。

Aspose.Slides for Java では、開発者が API をよりよく理解できるように、完全な機能を備えたデモと実装例も提供しています。

### **プレゼンテーション機能**

- さまざまなソースから Microsoft PowerPoint プレゼンテーションを開く。
- さまざまな Microsoft PowerPoint 形式でプレゼンテーションを保存する。
- ゼロからプレゼンテーションを作成する。
- 他のコンポーネントを使用せずにプレゼンテーションを PDF ドキュメントに変換する。
- Open Document Presentation (ODP) を読み取る機能。
- PPT から PPTX、またはその逆への変換機能。
- プレゼンテーションのドキュメント プロパティを読み取ったり変更したりできる。
- プレゼンテーションを PDF にエクスポートする。
- プレゼンテーションを TIFF にエクスポートする。
- プレゼンテーションを XPS にエクスポートする。
- プレゼンテーションを SWF にエクスポートする。
- プレゼンテーションを PDF ノート / TIFF ノートにエクスポートする。
- プレゼンテーションを HTML にエクスポートする。

### **スライド機能**

- ゼロから新しいスライドを作成し、プレゼンテーションに追加する。
- プレゼンテーション内の位置で任意のスライドにアクセスする。
- 同一または別のプレゼンテーションにスライドをコピーまたはクローンする。
- スライドの編集と削除。
- マスタースライドを自動的にコピーする。
- スライドをプレビューする。
- スライドの名前を取得または設定する。
- スライドを画像として保存する。
- スライドを SVG 形式にエクスポートする。
- プレゼンテーションで多数のマスターを扱う。
- サポートされている任意のスタイルでスライドの背景を塗りつぶす。
- 新しいスライドノートを追加または管理する。
- 新しいスライドマスターとスタイルを動的に設定する。
- スライドショーのトランジションを追加または変更する。
- モーフ トランジションを追加する。

### **グラフィックとマルチメディア機能**

- 線、矩形、楕円、多角線などの図形を作成または管理する。
- 図形の線スタイルを管理する。
- 図形の代替テキストを取得する。
- 図形を回転または反転させる。
- 図形を単色、グラデーション、パターン、テクスチャ、画像などの様々なスタイルで塗りつぶす。
- 48 種類の事前定義パターンと 24 種類のテクスチャを使用できる。
- 図形にリンクを割り当てる。
- スライドや図形に対してアニメーション効果を読み取り、変更し、新規に追加する。
- プレゼンテーションに新しい画像を追加し、既存の画像を管理する。
- プレゼンテーションに新しい画像バレットを追加し、既存のものを管理する。
- プレゼンテーションに新しい音声フレームを追加し、既存のものを管理する。
- プレゼンテーションに新しい動画フレームを追加し、既存のものを管理する。

### **表機能**

- ゼロから表を作成し、スライドに追加する。
- 表のサイズ変更と移動。
- 表の任意のセルにアクセスする。
- 任意のセルの書式と枠線を変更する。
- 列と行のサイズ変更。
- 列と行の追加および削除。
- テーブル全体の枠線幅と色を設定する。
- テーブルにプリセットスタイルを適用する。

### **テキストと段落機能**

- テキストプレースホルダーやテキストフレーム内のテキストを取得・設定する。
- プレースホルダーのタイプを取得する。
- テキストフレーム内のテキスト書式を変更する。
- 新しいフォントを追加するか、プレゼンテーションで使用されているフォントを管理する。
- テキストとテキスト書式を変更する。
- テキストへのリンクを作成または管理する。
- タブと効果的なタブをサポートする。
- ほぼすべての形状に新しいテキストフレームを追加する。
- テキストフレームの余白およびテキスト折り返し設定にアクセスし、変更する。
- 段落のインデントにアクセスし、変更する。

### **高度な機能**

- プレゼンテーションに埋め込まれた OLE オブジェクトにアクセスする。
- プレゼンテーションをロックする。
- プレゼンテーションに透かしを追加する。
- スライド内の図形にアニメーションを適用する。

## **よくある質問**

### PDF の保存性とアクセシビリティのための準拠レベル (PDF/A および PDF/UA) をサポートしていますか？

はい。PDF/A-2a/2b/2u、PDF/A-3a/3b、ならびに PDF/UA で保存でき、[PDF エクスポート オプション](https://reference.aspose.com/slides/ja/java/com.aspose.slides/pdfoptions/) を構成することで実現できます。

### 正しいレンダリングを保証するためのフォント置換機構やカスタムフォントのサポートはありますか？

はい。ライブラリは[カスタムフォントをロード](/slides/ja/java/custom-font/)し、[フォールバック ルールを定義](/slides/ja/java/fallback-font/)できるので、欠損したグリフは変換やレンダリング時に確実に置換されます。

### ファイルがパスワードで保護されているかどうかを、完全に開かずに検出できますか？

はい。プレゼンテーションを[検査](/slides/ja/java/examine-presentation/)して、ロード前にパスワードが必要かどうかを判断できます。

### 処理や変換に Microsoft PowerPoint は必要ですか？

いいえ。Aspose.Slides はスタンドアロンエンジンであり、サーバーやワークステーションに PowerPoint は不要です。

### 複数のスレッドからプレゼンテーションを処理しても安全ですか？

はい、別々のスレッドで異なるドキュメントを並行して処理できます。ただし、同じプレゼンテーション インスタンスを同時に使用しないでください。[スレッド間での使用](/slides/ja/java/multithreading/) を避ける必要があります。

### マクロは保持され、PPTM/PPSM ファイルの VBA を管理できますか？

はい。マクロ付きプレゼンテーションは[サポート](/slides/ja/java/presentation-via-vba/)されており、[VBA プロジェクトを検査および管理](https://reference.aspose.com/slides/ja/java/com.aspose.slides/presentation/#getVbaProject--)が可能です。

### PDF や HTML を PowerPoint スライドに変換できますか？

はい。PDF ページや HTML コンテンツを[インポート](/slides/ja/java/import-presentation/)して、プレゼンテーション内にスライドを作成または追加できます。

### XPS エクスポートはサポートされており、出力の品質や内容を制御できますか？

はい。[XPS へのエクスポート](/slides/ja/java/convert-powerpoint-to-xps/)が利用可能で、[保存オプション](https://reference.aspose.com/slides/ja/java/com.aspose.slides/xpsoptions/)により出力品質や含めるコンテンツを調整できます。

### スライドを画像に変換し、出力品質を制御できますか？

はい。スライドは[PNG、JPEG、GIF、BMP、TIFF](/slides/ja/java/convert-powerpoint-to-png/)などに[レンダリング]でき、サイズや品質を細かく制御できます。

### 数式 (MathML/MathText) はサポートされており、エクスポートできますか？

はい。[数式の作成と編集](/slides/ja/java/powerpoint-math-equations/)および[エクスポート](/slides/ja/java/exporting-math-equations/)が可能で、MathML へのエクスポートも含まれます。

### ライブラリは暗号化とパスワードの取り扱い（開く、設定、削除）をどのように行いますか？

[暗号化されたプレゼンテーションのオープン](/slides/ja/java/password-protected-presentation/)、開く・変更用のパスワードの設定や削除、ファイルの保護状態の確認をサポートしています。
