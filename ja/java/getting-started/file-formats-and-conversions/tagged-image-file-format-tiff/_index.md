## **TIFF について**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF)（タグ付き画像ファイル形式）は、もともと Aldus によって作成され、1 つの文書に複数の画像を格納できることで知られています。この形式は、スキャン、FAX、その他の画像操作アプリケーションで広くサポートされています。

## **Aspose.Slides for Java の TIFF**

Aspose.Slides for Java で読み込める任意のドキュメントは、サードパーティ コンポーネントを必要とせず、Aspose.Slides for Java によって直接 TIFF ドキュメントに変換できます。さらに、生成された TIFF ドキュメント内の画像サイズを任意で指定することも可能です。Aspose.Slides for Java を使用してプレゼンテーション ドキュメントを TIFF ドキュメントにエクスポートする方法の情報は、[Convert PowerPoint Presentations to TIFF](/slides/ja/java/convert-powerpoint-to-tiff/) にて確認できます。
