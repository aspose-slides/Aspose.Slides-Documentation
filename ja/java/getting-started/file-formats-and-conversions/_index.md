このセクションの記事は、個々のファイル形式の古い概要で、既存のリンクのために保持されています。Aspose.Slides for Java の現在のバージョンについては説明していません。Aspose.Slides for Java が読み込み、インポート、保存、レンダリングする形式とそれぞれの API については、[Supported File Formats](/slides/ja/java/supported-file-formats/) を参照してください。変換ガイドについては、[Convert Presentations](/slides/ja/java/convert-presentation/) を参照してください。
