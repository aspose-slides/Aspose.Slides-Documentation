{{% alert color="info" title="Note" %}}
[Portable Document Format](https://en.wikipedia.org/wiki/PDF) は、Adobe Systems が組織間で文書をやり取りするために作成したファイル形式です。この形式の目的は、プラットフォームに関係なくコンテンツとレイアウトを同じに保つことです。Aspose.Slides for Java を使用すると、プレゼンテーションファイルを PDF に変換できます。
{{% /alert %}}

## **Aspose.Slides for Java の PDF**
Aspose.Slides for Java に読み込むことができるプレゼンテーションは、選択に応じて[PDF 1.5](https://en.wikipedia.org/wiki/PDF)、[PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A)、[PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) または[PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) に準拠した PDF に変換できます。Aspose.Slides for Java はプレゼンテーションを PDF にエクスポートし、ほとんどの場合、出力された PDF は元のプレゼンテーションとまったく同じに見えます。

Aspose.Slides は PDF に変換する際、次のプレゼンテーション機能をサポートします:
- 画像、テキストボックス、その他の図形。
- テキストと書式設定。
- 段落と書式設定。
- ハイパーリンク。
- ヘッダーとフッター。
- 箇条書き。
- 表。

Aspose.Slides for Java を使用すれば、プレゼンテーションを直接 PDF にエクスポートできます。他のコンポーネントは不要です。さらに、[Convert PPT and PPTX to PDF](/slides/ja/java/convert-powerpoint-to-pdf/) で説明されているように、さまざまなオプションでプレゼンテーションから PDF へのエクスポートをカスタマイズできます。
