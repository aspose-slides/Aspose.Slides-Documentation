{{% alert color="info" %}} 

The [Portable Document Format](https://en.wikipedia.org/wiki/PDF) は、Adobe Systems が組織間で文書をやり取りするために作成したファイル形式です。この形式の目的は、閲覧するプラットフォームに関係なく、コンテンツとレイアウトを同じに保つことです。Aspose.Slides for Java を使用すると、プレゼンテーションファイルを PDF に変換できます。

{{% /alert %}} 

## **Aspose.Slides for Java の PDF**
Aspose.Slides for Java に読み込むことができる任意のプレゼンテーションは、[PDF 1.5](https://en.wikipedia.org/wiki/PDF/A)、[PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A)、[PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) または [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) に準拠した PDF に変換できます（選択に応じて）。Aspose.Slides for Java はプレゼンテーションを PDF にエクスポートし、ほとんどの場合、出力された PDF は元のプレゼンテーションと全く同じ見た目になります。

Aspose.Slides は PDF への変換時に次のプレゼンテーション機能をサポートします。

- 画像、テキストボックスおよびその他の図形。
- テキストと書式設定。
- 段落と書式設定。
- ハイパーリンク。
- ヘッダーとフッター。
- 箇条書き。
- 表。

Aspose.Slides for Java を使用すれば、プレゼンテーションを直接 PDF にエクスポートできます。別のコンポーネントは必要ありません。さらに、[Converting to PDF](/slides/ja/java/converting-a-presentation/) で説明されているように、さまざまなオプションで PDF エクスポートをカスタマイズできます。
