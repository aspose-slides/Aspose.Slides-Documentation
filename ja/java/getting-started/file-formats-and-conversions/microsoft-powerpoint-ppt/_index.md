[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) は、さまざまなバージョンの Microsoft PowerPoint が作成、読み取り、操作、書き込みできるプレゼンテーション文書ファイル形式です。これは Microsoft が開発したプレゼンテーション文書のバイナリ形式です。

{{% /alert %}}

## **Aspose.Slides for Java の PPT**
Aspose.Slides for Java は、以下のソフトウェアで作成された PPT ファイルを読み取ることができます。

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

同様に、Aspose.Slides for Java で作成された PPT ファイルは、上記のソフトウェアで読み取ることができます。

## **PPT の包括的サポート**
Aspose.Slides for Java は、PPT 文書ファイル形式でサポートされているほぼすべての機能を提供します。これは、さまざまな Microsoft PowerPoint バージョンが提供する基本的および高度な機能だけでなく、Microsoft PowerPoint ですらサポートしていない機能もカバーしています。Aspose.Slides for Java API ライブラリを使用する主な利点は、これらの機能を簡単に扱えることです。

基本的な PPT 文書ファイルの作成、読み取り、書き込みに加えて、Aspose.Slides for Java が提供するいくつかの機能は次のとおりです。

- 他の Microsoft Office ファイル形式を[OLE オブジェクトとして PPT 文書へ](/slides/ja/java/manage-ole/)インポートします。
- [PPT 文書を PDF にエクスポート](/slides/ja/java/convert-powerpoint-to-pdf/)します。
- PPT 文書内のスライドを SVG 形式にエクスポートします。
- スライドを Java フレームワークがサポートする任意の画像形式にレンダリングします。
- PPT 文書内のスライドサイズを設定します。
- シェイプのアニメーションを管理します。
- スライドショーを管理します。
- [スライド上のテキストをフォーマット](/slides/ja/java/text-formatting/)します。
- PPT 文書からテキストを抽出します。
- [スライド上のテーブルを処理](/slides/ja/java/powerpoint-table/)します。
- [クローン機能](/slides/ja/java/clone-slides/)を使用してマスターを自動的にコピーします。
