Aspose.Slides for Java では PPT から PPTX への変換がサポートされています。ほとんどのプレゼンテーション機能（マスタースライド、構造など）は、形式を変換しても保持されますが、[いくつかの制限](/slides/ja/java/ppt-to-pptx-conversion/)があります。

{{% /alert %}} 
## **変換でサポートされる機能**
Aspose.Slides for Java は PPT ファイル形式から PPTX への変換に部分的に対応しています。変換機能は Aspose.Slides for Java に最近追加されたばかりで、いくつかの制限があり、シンプルなプレゼンテーションに最適です。PPT から PPTX への変換時に Aspose.Slides for Java が提供する最大の利点は、API が非常に使いやすいことです。コード例を見るには、[PPT を PPTX に変換](). 以下のリストは、PPT から PPTX 変換でサポートされる機能とサポートされない機能を説明しています。

## **サポートされる機能**
The following features are supported for conversion:

- マスタ、レイアウト、スライドの構造の変換
- チャートの変換
- グループ シェイプ
- 矩形や楕円を含むオートシェイプの変換
- カスタムジオメトリを持つシェイプ
- オートシェイプのテクスチャおよび画像塗りつぶしスタイル
- プレースホルダーの変換
- ラインとポリラインの変換
- ラインおよび塗りつぶしの書式
- グラデーション塗りつぶしスタイル
- OLE フレーム、テーブル、ビデオおよびオーディオ フレームなど
- アニメーションとスライドショーのプロパティ
- テキストフレームやテキストホルダー内のテキストの変換
