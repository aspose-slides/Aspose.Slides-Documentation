## **変換でサポートされている機能**
Aspose.Slides for Java は PPT ファイル形式から PPTX への変換に対して部分的なサポートを提供します。変換のサポートは Aspose.Slides for Java に最近導入されたばかりで、いくつかの制限があり、シンプルなプレゼンテーションに最適です。Aspose.Slides for Java が PPT から PPTX に変換する際の主な利点は、API の使いやすさです。コード例を見るには、[PPT から PPTX への変換](/slides/ja/java/convert-ppt-to-pptx/) を参照してください。以下のリストは、PPT から PPTX への変換でサポートされている機能を示しています。

## **サポートされている機能**
変換でサポートされている機能は以下の通りです：
- マスター、レイアウト、スライドの構造の変換。
- チャートの変換。
- グループ シェイプ。
- 矩形や楕円を含むオートシェイプの変換。
- カスタムジオメトリを持つシェイプ。
- オートシェイプ用のテクスチャおよび画像の塗りスタイル。
- プレースホルダーの変換。
- 線とポリラインの変換。
- 線と塗りのフォーマット。
- グラデーション塗りスタイル。
- OLE フレーム、テーブル、ビデオ・オーディオフレームなど。
- アニメーションおよびスライドショーのプロパティ。
- テキストフレームやテキストホルダー内のテキストの変換。
