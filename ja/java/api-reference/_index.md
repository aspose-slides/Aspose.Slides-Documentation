{{% alert color="info" %}} 

Aspose.Slides for Java は、Microsoft PowerPoint® などを使用せずに、Java アプリケーションがプレゼンテーション ドキュメントを読み書きできるクラス ライブラリです。Aspose.Slides for Java を使用すると、テキスト、図形、テーブルとアニメーションを管理し、スライドに音声や動画を追加し、スライドをプレビューし、SVG、PDF 形式などへエクスポートできます。

最新の API リファレンスは [Aspose.Slides for Java API Reference](https://reference.aspose.com/slides/ja/java) で確認できます。

{{% /alert %}}
