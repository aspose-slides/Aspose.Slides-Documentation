{{% alert color="info" title="Note" %}}
これは履歴ページです。Aspose.Slides for Java 14.3.0で公開された既知の問題を一覧にしており、現在のバージョンについては記述していません。各バージョンの変更点については、[release notes](https://releases.aspose.com/slides/ja/java/release-notes/)をご覧ください。
{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) は、PPT 処理の完全に新しい実装を提供します。多くの改善があり、PPTX から PPT への部分的変換が可能です。ただし、いくつか実装されていない機能があります:

- シリアライズされた PPT ドキュメント内の一部のシェイプのジオメトリが正しくありません（コールアウト）
- すべての PPTX テキスト書式設定機能が PPT のシリアライズでサポートされているわけではありません
- テキスト言語およびスペル設定に関する情報がシリアライズされた PPT ドキュメントに含まれていません
- すべての PPTX テーマ機能が PPT のシリアライズでサポートされているわけではありません

**Aspose.Slides for Java 8.6.0 と比較した場合のいくつかの違いがあります:**

- OLE/ActiveX の PPT へのシリアライズに既知の問題があります

**Aspose.Slides for .NET 14.3.0 と比較した場合のいくつかの違いがあります:**

- 現在、Aspose.Slides for Java ではプレゼンテーションの印刷サポートが利用できません
