{{% alert color="info" %}} 

Aspose.Slides for Java 14.4.0 は PowerPoint ドキュメントの処理に新しい機能を提供します。いくつかの制限と既知の問題があり、今後のリリースで解消される予定です：

- 一部のシェイプがシリアライズされた PPT ドキュメントでジオメトリが正しくありません（円弧、円形矢印、吹き出し）。
- すべての PPTX テキスト書式設定機能が PPT のシリアライズでサポートされているわけではありません（タブ設定、インデント、段落書式設定に制限があります）。
- テキストの言語やスペル設定に関する情報はシリアライズされた PPT ドキュメントに含まれていません。
- すべての PPTX テーマ機能が PPT のシリアライズでサポートされているわけではありません（塗りつぶし形式、線形式、フォントのシリアライズのみ）。
- OLE/ActiveX の PPT から PPT へのシリアライズに既知の問題があります。
- WordArt のシリアライズおよびレンダリングはサポートされていません。

{{% /alert %}}
