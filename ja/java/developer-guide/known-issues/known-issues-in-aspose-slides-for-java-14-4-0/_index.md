{{% alert color="info" title="Note" %}}

これは履歴ページです。Aspose.Slides for Java 14.4.0 に掲載された制限事項と既知の問題を一覧にしており、現在のバージョンについては説明していません。バージョンごとの変更点は、[リリースノート](https://releases.aspose.com/slides/ja/java/release-notes/)をご覧ください。

{{% /alert %}}

Aspose.Slides for Java 14.4.0 は PowerPoint ドキュメントの処理に新しい決定機能を提供します。いくつかの制限事項と既知の問題があり、今後のリリースで削除される予定です。

- シリアライズされた PPT ドキュメント内で、一部のシェイプのジオメトリが正しくありません（円弧、円形矢印、吹き出し）。
- PPT のシリアライズでは、すべての PPTX テキスト書式設定機能がサポートされているわけではありません（タブ、インデント、段落書式設定の制限）。
- テキストの言語およびスペル設定に関する情報がシリアライズされた PPT ドキュメントに含まれていません。
- PPT のシリアライズでは、すべての PPTX テーマ機能がサポートされているわけではありません（塗りつぶし形式、ライン形式、フォントのシリアライズのみ）。
- OLE/ActiveX の PPT へのシリアライズに既知の問題があります。
- WordArt のシリアライズおよびレンダリングはサポートされていません。
