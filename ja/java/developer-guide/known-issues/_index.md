## **概要**

このセクションには現在のバージョンの未解決問題の一覧は含まれていません。3つのページが含まれます。

- [OleObjectFrame の追加時におけるオブジェクトプレビューのプレースホルダー](/slides/ja/java/object-preview-issue-when-adding-oleobjectframe/) は、Aspose.Slides で追加された OLE オブジェクトがプレビューが更新されるまで「EMBEDDED OLE OBJECT」画像を表示する理由と、独自のプレビュー画像を設定する方法を説明します。これは現在のバージョンの設計上の動作です。
- [Aspose.Slides for Java 14.3.0 の既知の問題（過去版）](/slides/ja/java/known-issues-in-aspose-slides-for-java-14-3-0/) および [Aspose.Slides for Java 14.4.0 の既知の問題（過去版）](/slides/ja/java/known-issues-in-aspose-slides-for-java-14-4-0/) は、該当バージョンで公開された一覧で、参照用に保持されています。

各バージョンの変更点と修正については、[リリースノート](https://releases.aspose.com/slides/ja/java/release-notes/)をご覧ください。Aspose.Slides が固定値で書き込むメタデータ フィールドは、[出力メタデータの制限](/slides/ja/java/api-limitations/)で説明されています。問題が既に知られているか確認するか、報告するには、[サポートフォーラム](https://forum.aspose.com/c/slides/ja/11)をご利用ください。
