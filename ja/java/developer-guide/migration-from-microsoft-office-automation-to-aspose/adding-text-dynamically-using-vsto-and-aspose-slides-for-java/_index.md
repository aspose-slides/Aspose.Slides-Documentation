## **テキストの動的追加**
両方の方法は次の手順に従います:

1. プレゼンテーションを作成する。
1. 空白のスライドを追加する。
1. テキスト ボックスを追加する。
1. テキストを設定する。
1. プレゼンテーションを書き出す。
