{{% alert color="info" %}} 
テーブルはプレゼンテーションスライドでデータを表示するために広く使用されています。この項目では、最初に[VSTO 2008](/slides/ja/java/creating-a-table-on-powerpoint-slide/)を使用し、その後[Aspose.Slides for Java](/slides/ja/java/creating-a-table-on-powerpoint-slide/)を使用して、フォントサイズ10の15×15テーブルをプログラムで作成する方法を示します。
{{% /alert %}} 
## **テーブルの作成**
### **VSTO 2008 の例**
1. プレゼンテーションを作成します。
1. 空のスライドをプレゼンテーションに追加します。
1. スライドに15×15のテーブルを追加します。
1. フォントサイズ10でテーブルの各セルにテキストを追加します。
1. プレゼンテーションをディスクに保存します。

### **Aspose.Slides for Java の例**
1. プレゼンテーションを作成します。
1. 最初のスライドに15×15のテーブルを追加します。
1. フォントサイズ10でテーブルの各セルにテキストを追加します。
1. プレゼンテーションを書き出してディスクに保存します。
