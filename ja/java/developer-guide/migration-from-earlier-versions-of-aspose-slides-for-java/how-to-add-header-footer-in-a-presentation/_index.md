## **レガシーコードのサポート**
13.x 以前の Aspose.Slides for Java バージョンで開発されたレガシーコードを使用するには、コードに少し変更を加える必要がありますが、コードは以前と同様に動作します。以前の Aspose.Slides for Java で Aspose.Slide および Aspose.Slides.Pptx 名前空間に存在したすべてのクラスは、現在単一の Aspose.Slides 名前空間に統合されています。以下のシンプルなコードスニペットは、レガシー Aspose.Slides API でプレゼンテーションにヘッダーとフッターを追加する例です。新しい統合 API への移行手順をご確認ください。
