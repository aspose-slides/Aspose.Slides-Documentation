このセクションでは、Aspose.Slides for JasperReports の機能の詳細説明を提供します。テーブルのリンクをクリックして、機能の詳細をご覧ください。

|**機能**|**説明**|
| :- | :- |
|[PPT、PPTX、PDF および HTML エクスポート](/slides/ja/jasperreports/ppt-pptx-pdf-and-html-export/)|Microsoft PowerPoint を使用せずに、アプリケーションからレポートを PPT および PPTX プレゼンテーション、PDF ドキュメント、HTML ファイルとしてエクスポートします。|
|レポートデザインに対する高忠実度|PPT および PPTX レポートは、PDF やその他の形式と同じレイアウトと外観を保持します。|
|簡単で軽量なデプロイ|Aspose.Slides for JasperReports は、JasperReports および JasperServer 用の Microsoft PowerPoint 形式エクスポーターです。|
|[シンプルで手頃な価格のライセンス](/slides/ja/jasperreports/licensing/)|サーバーごとのライセンスまたはすべてのサーバーに対する単一ライセンスを提供します。|
|[世界クラスの無料テクニカルサポート](/slides/ja/jasperreports/technical-support/)|製品に携わる開発者が直接提供する無制限のテクニカルサポートが利用できます。|
