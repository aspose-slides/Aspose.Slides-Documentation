## **JasperReports**

Aspose.Slides for JasperReports は JasperReports 3.7.2 から 6.16.0 をサポートします。ダウンロードには 3 つのバージョン範囲ごとに別々の jar が用意されています。どれを使用すべきかは、[Installing Aspose.Slides for JasperReports](/slides/ja/jasperreports/installing-aspose-slides-for-jasperreports/) を参照してください。JasperReports 6.17.0 以降（JasperReports 7 を含む）には jar が用意されていません。

JasperReports 2.0.3 から 3.7.1 までのサポートは、Aspose.Slides for JasperReports 17.6 で終了しました。バージョン 17.5 以前も同様のバージョンをサポートしていました。

## **Java**

jar は *JDK 1.6* とフォルダー名にあるように、Java 6 以降向けにコンパイルされています。そのため必要な Java バージョンは、使用している JasperReports のバージョンが要求するものとなります。JasperReports 6.16.0 では、エクスポートは Java 11、17、21、25 上で実行できます。

## **Operating system**

jar には Java クラスとリソースのみが含まれ、ネイティブライブラリは含まれていません。また、Microsoft PowerPoint は使用しません。Linux では、JasperReports がレポートを正しく描画するために fontconfig と少なくとも 1 つのインストール済みフォントが必要です。

## **JasperReports Server**

JasperReports Server を使用する場合は、サーバーが実行している JasperReports のバージョンに一致するフォルダー内の両方の jar を使用してください。詳細は [Integration with JasperServer](/slides/ja/jasperreports/integration-with-jasperserver/) を参照してください。
