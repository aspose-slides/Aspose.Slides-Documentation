## **概要**

Aspose.Slides for Python via Java は PowerPoint および OpenDocument プレゼンテーションを読み書きします。また、PDF および HTML コンテンツをスライドにインポートし、プレゼンテーションや個々のスライドをドキュメント、Web、画像形式にエクスポートします。

以下の表は、プレゼンテーションのロード、コンテンツのインポート、スライドのレンダリングを区別しています。編集およびレンダリング機能の概要については、[機能概要](/slides/ja/python-java/features-overview/) を参照してください。

## **サポートされている Microsoft PowerPoint バージョン**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac
- PowerPoint for Microsoft 365 (formerly Office 365)

## **インポートおよびエクスポートの注意点**

- **PDF と HTML のインポート:** [SlideCollection.addFromPdf](https://reference.aspose.com/slides/ja/python-java/aspose.slides/slidecollection/#addfrompdf) または [SlideCollection.addFromHtml](https://reference.aspose.com/slides/ja/python-java/aspose.slides/slidecollection/#addfromhtml) を使用して、ソースコンテンツからスライドを作成し、プレゼンテーションに追加します。
- **プレゼンテーションの出力:** [SaveFormat](https://reference.aspose.com/slides/ja/python-java/aspose.slides/saveformat/) では、利用可能なプレゼンテーション保存形式が一覧表示されており、個別の HTML および HTML5 エクスポートオプションが含まれます。
- **画像の出力:** スライドを画像にエクスポートすると、そのスライドの視覚的表現が生成されます。入力列は、画像をプレゼンテーションに挿入できるかどうかを示していません。

## **よくある質問**

**PPT プレゼンテーションを PPTX または ODP に変換できますか？**

はい。PPT は入力形式としてサポートされており、PPTX と ODP の両方が出力形式としてサポートされています。変換結果は、対象形式で利用可能な機能に依存します。

**PDF または HTML のインポートは、ソースを PowerPoint ファイルとして開きますか？**

いいえ。インポートは PDF ページまたは HTML コンテンツからスライドを作成します。その後、生成されたプレゼンテーションをサポートされている形式で保存できます。

**エクスポートした PNG または SVG を編集可能なプレゼンテーションとして読み込めますか？**

いいえ。これらのエクスポートはスライドの外観を表すものです。テキスト、図形、チャート、その他のオブジェクトを後で編集する必要がある場合は、元のプレゼンテーションを保持してください。
