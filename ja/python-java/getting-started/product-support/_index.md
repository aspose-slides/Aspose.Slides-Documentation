## **概要**

Aspose.Slides のサポートフォーラムを使用して、質問をしたり、問題を報告したり、Aspose.Slides for Python via Java の機能要望を行ったりできます。本記事では、トピックを作成する前に確認すべきことと、サポートチームが問題を再現するために役立つ情報について説明します。

## **テクニカル サポート**

{{% alert color="info" title="Note" %}}
Aspose は、製品を評価中のユーザーを含むすべてのユーザーに無料のテクニカルサポートを提供しています。詳細は、[無料サポートポリシー](https://forum.aspose.com/t/free-support-policies/162313)をご覧ください。
{{% /alert %}}

テクニカルな質問は[ Aspose.Slides サポートフォーラム](https://forum.aspose.com/c/slides/ja/11) に投稿してください。レポートに **Aspose.Slides for Python via Java** を指定することで、チームが正しい製品と環境を特定できます。

優先的な支援が必要な場合は、[有料サポートヘルプデスク](https://helpdesk.aspose.com/)をご覧ください。有料サポートは別途サブスクリプションが必要で、製品ライセンスには含まれていません。

## **問題を報告する前に**

1. 問題を解決できる可能性のある新しいバージョンがないか、[ダウンロード](https://releases.aspose.com/slides/ja/python-java/) と[リリースノート](https://releases.aspose.com/slides/ja/python-java/release-notes/) を確認してください。可能であれば、テスト環境で最新リリースを使用して問題を再現してください。
2. サポートフォーラム、[ドキュメント](/slides/ja/python-java/) および[API リファレンス](https://reference.aspose.com/slides/ja/python-java/) を検索し、既存の回答がないか確認してください。
3. インストールや JVM の起動に関する問題については、[インストールガイド](/slides/ja/python-java/installation/) を確認し、Python と Java が同じアーキテクチャであることを確認してください。
4. 問題を最小限のサンプルと入力プレゼンテーションに絞り、再現できる状態にしてください。

## **問題レポートの作成**

フォーラムのトピックに次の情報を含めてください。

- **環境:** Aspose.Slides for Python via Java のバージョン、Python バージョン、Java バージョンとベンダー、JPype バージョン、OS、アーキテクチャ。
- **手順とコード:** インポートと JVM 初期化を含む最小限の実行可能 Python サンプル、および問題を再現する手順。
- **入力ファイル:** プレゼンテーションおよびサンプルで必要な関連ファイル。複数ファイルは ZIP アーカイブにまとめてください。
- **期待結果と実際の結果:** 差異を説明し、必要に応じて生成された出力やスクリーンショットを添付してください。レンダリングの問題の場合は、影響を受けたスライドとフォントを特定してください。
- **エラーの詳細:** 例外が発生した場合は、完全なエラーメッセージとスタックトレースを提供してください。

1つの問題につき1つのトピックを使用してください。同じ問題に関する追加入力は既存のトピックに追加し、サポートチームが調査を継続できるようにしてください。

## **FAQ**

**Aspose.Slides for Python via Java を評価中でもサポートを受けられますか？**

はい。評価中でも購入後でも、Aspose.Slides のサポートフォーラムを通じて無料のテクニカルサポートを利用できます。

**JVM が起動しない場合、何を含めるべきですか？**

Python、Java、JPype のバージョン、OS、Python と Java のアーキテクチャ、JVM 初期化コード、完全なエラーメッセージを提供してください。これらの情報はサポートチームが環境を再現するのに役立ちます。

**アップグレード後に発生した問題はどのように報告すべきですか？**

最後に正常に動作したバージョン、問題が発生し始めた最初のバージョン、入力ファイル付きの最小サンプルを含めてください。アップグレード時に行った環境の変更点も記述してください。
