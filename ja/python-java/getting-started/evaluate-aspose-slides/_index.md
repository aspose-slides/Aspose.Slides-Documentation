Aspose.Slides for Python via Java をダウンロードして機能を評価できます。評価パッケージはライセンスパッケージと同一です。評価制限なしで使用するには、[ライセンスを適用する](/slides/ja/python-java/licensing/) に数行のコードを追加してください。

ライセンスなしで使用する Aspose.Slides の評価版は、製品の全機能を提供しますが、以下の 2 つの制限があります：

- 保存する各プレゼンテーションのすべてのスライドに評価用の透かしテキストボックスが追加されます。プレゼンテーションを開くだけでは透かしは追加されませんが、既に透かしが付いたファイルを保存すると新たに透かしが追加されます。
- コードが読み取るテキストは最初の数文字に切り捨てられ、評価制限に関する通知が付加されます。これはすべてのスライド、およびコードが設定したテキストとファイルから読み込んだテキストの両方に適用されます。コードが書き込むテキストはそのまま全文が保存されます。

{{% alert color="info" title="Note" %}}
評価制限なしで Aspose.Slides をテストするには、**30 日間の一時ライセンス**をリクエストできます。詳細については、[一時ライセンスを取得する](https://purchase.aspose.com/temporary-license) をご覧ください。
