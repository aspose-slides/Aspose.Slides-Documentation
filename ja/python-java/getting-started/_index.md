## **概要**

このセクションでは、環境の準備と Aspose.Slides for Python via Java の使用開始を支援します。以下の設定手順に従った後、ライブラリの機能とプロジェクトに関連するガイダンスを確認してください。

## **ライブラリの設定**

1. [システム要件](/slides/ja/python-java/system-requirements/) を確認し、オペレーティングシステム、Python、Java、JPype の要件をチェックします。
2. [インストール](/slides/ja/python-java/installation/) ガイドに従って必要なパッケージをインストールし、サンプルで設定を検証します。
3. [Aspose.Slides の評価](/slides/ja/python-java/evaluate-aspose-slides/) を読んで、評価の制限と一時ライセンス オプションを理解します。
4. [ライセンス](/slides/ja/python-java/licensing/) ガイドに従ってライセンスを適用します。

## **機能と互換性の確認**

- [製品概要](/slides/ja/python-java/product-overview/) は、ライブラリとプレゼンテーション処理機能を紹介します。
- [サポートされているファイル形式](/slides/ja/python-java/supported-file-formats/) は、プレゼンテーションの読み込み、インポート、保存、エクスポートに利用できる形式を一覧表示します。
- [機能概要](/slides/ja/python-java/features-overview/) は、変換、レンダリング、編集、書式設定機能を要約します。
- [制限事項と API の違い](/slides/ja/python-java/limitations-and-api-differences/) は、Python から Java API を使用する際に考慮すべき制限や相違点を説明します。

## **サポートの取得**

トラブルシューティングのガイダンス、問題の報告方法、追加リソースへのリンクについては、[製品サポート](/slides/ja/python-java/product-support/) をご覧ください。

## **よくある質問**

**Aspose.Slides for Python via Java を初めて使用する場合、どこから始めるべきですか？**

システム要件とインストール ガイドから始めます。インストール ガイドには環境を確認できるサンプルが含まれています。

**ライブラリが自分のプレゼンテーション形式をサポートしているかはどこで確認できますか？**

[サポートされているファイル形式]で入力および出力形式を確認し、タスクに利用できる操作は[機能概要]で確認してください。

**Java のサンプルを Python 用に適応する前に読むべきものは何ですか？**

[制限事項と API の違い] を読んで、インポート、リソースのクリーンアップ、Python 経由での Java のファイル処理に関するガイダンスを確認してください。
