**Aspose.Slides for Python via Java へようこそ**

![Aspose.Slides for Python via Java 製品ロゴ](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java は、Microsoft PowerPoint® を必要とせずに、Python アプリケーションが PowerPoint® プレゼンテーションの読み書きを行えるクラス ライブラリです。

主な機能には、テキスト、シェイプ、テーブル、アニメーションの管理、スライドへの音声およびビデオの追加、スライドのプレビュー、そしてスライドを SVG、PDF、その他の形式へエクスポートすることが含まれます。

{{% /alert %}}
