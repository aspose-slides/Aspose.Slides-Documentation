## **サポートされているプラットフォーム**
Aspose.Slides for Node.js via .NET はプラットフォームに依存しない API です。Node.js 7 以降がインストールされている任意のプラットフォーム（Windows、Linux、MacOS など）で使用できます。Oracle JDK 8 以降も必要です。

## **ファイル形式と変換**
Aspose.Slides for Node.js via .NET はほとんどの PowerPoint ドキュメント形式をサポートしています。また、組織が使用・共有する一般的なファイル形式へエクスポートすることも可能です。以下の詳細をご覧ください:

|**機能**|**説明**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET はこのプレゼンテーション文書形式に対して最速の処理を提供します。|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET は PPT から PPTX への変換をサポートしています。|
|Portable Document Format (PDF)|サポートされているすべてのファイル形式を、1 つのメソッドで Adobe Portable Document Format (PDF) ドキュメントにエクスポートできます。|
|XML Parser Specification (XPS)|サポートされているすべてのファイル形式を、1 つのメソッドで XML Parser Specification (XPS) ドキュメントにエクスポートできます。|
|Tagged Image File Format (TIFF)|サポートされているすべてのプレゼンテーションファイル形式を Tagged Image File Format (TIFF) にエクスポートできます。|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET は PresentationEx から HTML 形式への変換をサポートしています。|

## **プレゼンテーションのレンダリング**
Aspose.Slides for Node.js via .NET は、プレゼンテーション内のスライドを高忠実度でさまざまなグラフィック形式にレンダリングすることをサポートしています。以下の詳細をご覧ください:

|**機能**|**説明**|
| :- | :- |
|.NET がサポートする画像形式|Aspose.Slides for Node.js via .NET を使用すると、プレゼンテーションのスライドやスライド上の画像を TIFF、PNG、BMP、JPEG、GIF など .NET がサポートするすべてのグラフィック形式にレンダリングできます。|
|SVG 形式|Aspose.Slides for Node.js via .NET は、プレゼンテーションのスライドを Scalable Vector Graphics (SVG) 形式にエクスポートできる組み込みメソッドも提供します。|

## **コンテンツ機能**
Aspose.Slides for Node.js via .NET は、プレゼンテーションドキュメントのほぼすべての項目やコンテンツにアクセス、修正、作成することができます。以下の詳細をご覧ください:

|**機能**|**説明**|
| :- | :- |
|マスタースライド|マスタースライドは通常のスライドのレイアウトを定義します。Aspose.Slides for Node.js via .NET を使用すると、プレゼンテーションドキュメントのマスタースライドにアクセスし、変更できます。|
|標準スライド|Aspose.Slides for Node.js via .NET を使用すると、さまざまなタイプの新しいスライドを作成でき、プレゼンテーション内の既存スライドにもアクセスし、変更できます。|
|スライドのクローン/コピー|Aspose.Slides for Node.js via .NET が提供する組み込みメソッドにより、プレゼンテーション内の既存スライドをクローンまたはコピーできます。また、コピーまたはクローンしたスライドを別のプレゼンテーションで使用することも可能です。スライドはマスタースライドからレイアウトを継承するため、組み込みのクローンメソッドはクローン時にマスターも自動的にコピーします。|
|スライドセクションの管理|プレゼンテーション内でスライドを異なるセクションに整理するためのメソッドです。|
|プレースホルダーとテキストホルダー|スライド内のプレースホルダーとテキストホルダーにアクセスできます。また、適切なメソッドを使用して、テキストホルダーを含むスライドをゼロから作成することも可能です。|
|ヘッダーとフッター|Aspose.Slides for Node.js via .NET はスライドのヘッダー/フッターの操作を容易にします。|
|スライドのノート|Aspose.Slides for Node.js via .NET を使用すると、スライドに関連付けられたノートにアクセスし、変更でき、さらに新しいノートを追加することもできます。|
|シェイプの検索|シェイプに関連付けられた代替テキストを使用して、スライドから特定のシェイプを検索することもできます。|
|背景|Aspose.Slides for Node.js via .NET を使用すると、プレゼンテーションのマスターまたは標準スライドに関連付けられた背景を操作できます。|
|テキストボックス|テキストボックスはゼロから作成でき、既存のテキストボックスにアクセスできます。また、元のテキスト形式を保持したままテキストを変更することが可能です。|
|矩形シェイプ|Aspose.Slides for Node.js via .NET を使用して、矩形シェイプを作成または変更できます。|
|ポリラインシェイプ|Aspose.Slides for Node.js via .NET を使用して、ポリラインシェイプを作成または変更できます。|
|楕円シェイプ|Aspose.Slides for Node.js via .NET を使用して、楕円シェイプを作成または変更できます。|
|グループシェイプ|Aspose.Slides for Node.js via .NET はグループシェイプをサポートしています。|
|オートシェイプ|Aspose.Slides for Node.js via .NET はオートシェイプをサポートしています。|
|SmartArt|Aspose.Slides for Node.js via .NET は、MS PowerPoint の SmartArt シェイプをサポートしています。|
|チャート|Aspose.Slides for Node.js via .NET は、PowerPoint の MSO チャートをサポートしています。|
|シェイプのシリアライズ|Aspose.Slides for Node.js via .NET は多数のシェイプをサポートしています。サポートされていないシェイプがある場合、既存のスライドからそのシェイプをシリアライズする方法を使用できます。この方法により、必要に応じてシェイプをさらに利用できます。|
|画像フレーム|Aspose.Slides for Node.js via .NET を使用して、画像フレーム内の画像を管理できます。|
|オーディオフレーム|Aspose.Slides for Node.js via .NET を使用して、スライド上のオーディオフレームに音声ファイルをリンクまたは埋め込むことができます。|
|ビデオフレーム|ビデオフレーム内の動画ファイルを扱うことができます。Aspose.Slides for Node.js via .NET は、リンクされた動画と埋め込まれた動画の両方をサポートしています。|
|OLE フレーム|Aspose.Slides for Node.js via .NET を使用して、OLE フレーム内の OLE オブジェクトを管理できます。|
|テーブル|Aspose.Slides for Node.js via .NET はスライド内のテーブルをサポートしています。|
|ActiveX コントロール|ActiveX コントロールのサポート|
|VBA マクロ|プレゼンテーション内の VBA マクロの管理をサポートします。|
|テキストフレーム|任意のシェイプに関連付けられたテキストフレームを通じてテキストにアクセスできます。|
|テキストスキャン|組み込みのスキャンメソッドを使用して、プレゼンテーション全体またはスライドレベルでテキストをスキャンできます。|
|アニメーション|シェイプにアニメーションを適用できます。|
|スライドショー|Aspose.Slides for Node.js via .NET はスライドショーとスライド遷移をサポートしています。|

## **書式設定機能**
Aspose.Slides for Node.js via .NET を使用すると、プレゼンテーションのスライド上のテキストやシェイプの書式設定が可能です。以下の詳細をご覧ください:

|**機能**|**説明**|
| :- | :- |
|テキスト書式設定|<p>Aspose.Slides for Node.js via .NET では、シェイプに関連付けられたテキストフレームを通じてテキストを管理できます。そのため、テキストフレームに紐付く段落と部分を使用してテキストの書式設定が可能です。これらのテキスト要素は Aspose.Slides for Node.js via .NET で書式設定できます。</p><p>- フォントの種類</p><p>- フォントサイズ</p><p>- フォント色</p><p>- フォントの濃淡</p><p>- 段落の配置</p><p>- 段落の箇条書き</p><p>- 段落の向き</p>|
|シェイプ書式設定|<p>Aspose.Slides for Node.js via .NET では、スライドの基本要素はシェイプです。これらのシェイプ要素は Aspose.Slides for Node.js via .NET を使用して書式設定できます。</p><p>- 位置</p><p>- サイズ</p><p>- 線</p><p>- 塗りつぶし（パターン、グラデーション、単色を含む）</p><p>- テキスト</p><p>- 画像</p>|
