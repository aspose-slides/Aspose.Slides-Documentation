**Aspose.Slides for Node.js via .NET へようこそ**

![Aspose.Slides for Node.js via .NET 製品ロゴ](aspose_slides-for-nodejs-via-net.png)

Aspose.Slides for Node.js via .NET は、Microsoft PowerPoint® を使用せずに PowerPoint® ドキュメントの読み取りと書き込みを可能にするクラス ライブラリです。

Aspose.Slides for Node.js via .NET は、PowerPoint® ドキュメントの管理機能を提供する初めての、唯一のコンポーネントです。

Aspose.Slides for Node.js via .NET は、テキスト、シェイプ、テーブルとアニメーションの管理、スライドへの音声および動画の追加、スライドのプレビュー、SVG や PDF 形式へのエクスポートなど、多くの主要機能を提供します。
