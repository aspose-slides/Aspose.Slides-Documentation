## **Piattaforme supportate**
Aspose.Slides for Node.js via .NET è un'API indipendente dalla piattaforma. Può essere utilizzata su qualsiasi piattaforma (Windows, Linux, macOS, ecc.) dove è installato Node.js 7 o superiore. Oracle JDK 8 o superiore è un altro requisito.

## **Formati di file e conversioni**
Aspose.Slides for Node.js via .NET supporta la maggior parte dei formati di documenti PowerPoint. Consente inoltre di esportarli nei formati di file più popolari che le organizzazioni utilizzano e condividono tra loro. Consulta i dettagli qui di seguito:

|**Funzionalità**|**Descrizione**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET offre l'elaborazione più veloce per questo formato di documento di presentazione.|
|Conversione da PPT a PPTX|Aspose.Slides for Node.js via .NET supporta la conversione da PPT a PPTX.|
|Portable Document Format (PDF)|È possibile esportare tutti i formati di file supportati in documenti Adobe Portable Document Format (PDF) con un unico metodo.|
|XML Parser Specification (XPS)|È possibile esportare tutti i formati di file supportati in documenti XML Parser Specification (XPS) con un unico metodo.|
|Tagged Image File Format (TIFF)|È possibile esportare tutti i formati di file di presentazione supportati in Tagged Image File Format (TIFF).|
|Conversione da PPTX a HTML|Aspose.Slides for Node.js via .NET supporta la conversione di PresentationEx in formato HTML.|

## **Rendering delle presentazioni**
Aspose.Slides for Node.js via .NET supporta il rendering ad alta fedeltà delle diapositive di una presentazione in diversi formati grafici. Consulta i dettagli qui di seguito:

|**Funzionalità**|**Descrizione**|
| :- | :- |
|Formati immagine supportati da .NET|Utilizzando Aspose.Slides per Node.js via .NET, è possibile rendere le diapositive della presentazione e le immagini sulle diapositive in tutti i formati grafici supportati da .NET, come TIFF, PNG, BMP, JPEG, GIF.|
|Formato SVG|Aspose.Slides per Node.js via .NET fornisce inoltre metodi integrati che consentono di esportare le diapositive della presentazione in formati Scalable Vector Graphics (SVG).|

## **Funzionalità del contenuto**
Aspose.Slides for Node.js via .NET consente di accedere, modificare o creare quasi tutti gli elementi o i contenuti dei documenti di presentazione. Consulta i dettagli qui di seguito:

|**Funzionalità**|**Descrizione**|
| :- | :- |
|Diapositive master|Le diapositive master definiscono il layout delle diapositive normali. Aspose.Slides for Node.js via .NET consente di accedere e modificare le diapositive master dei documenti di presentazione|
|Diapositive normali|Con Aspose.Slides for Node.js via .NET, è possibile creare nuove diapositive di diversi tipi; è inoltre possibile accedere e modificare le diapositive esistenti nelle presentazioni|
|Clonazione / Copia di diapositive|Sono disponibili metodi integrati forniti da Aspose.Slides per Node.js via .NET che consentono di clonare o copiare le diapositive esistenti all'interno di una presentazione. È inoltre possibile utilizzare diapositive copiate e clonate da una presentazione all'altra. Poiché una diapositiva eredita il layout dalla diapositiva master, i metodi di clonazione integrati copiano automaticamente il master durante la clonazione|
|Gestione delle sezioni delle diapositive|Metodi per organizzare le diapositive in diverse sezioni all'interno di una presentazione|
|Segnaposti e segnaposto di testo|È possibile accedere ai segnaposti e ai segnaposto di testo in una diapositiva. Inoltre, è possibile creare una diapositiva con segnaposto di testo da zero utilizzando il metodo appropriato|
|Intestazioni e piè di pagina|Aspose.Slides for Node.js via .NET semplifica la gestione di intestazioni/π piè di pagina nelle diapositive|
|Note nelle diapositive|Con Aspose.Slides per Node.js via .NET, è possibile accedere e modificare le note associate a una diapositiva e anche aggiungere nuove note|
|Ricerca di una forma|È inoltre possibile trovare una forma specifica in una diapositiva utilizzando il testo alternativo associato alla forma|
|Sfondi|Aspose.Slides for Node.js via .NET consente di lavorare con gli sfondi associati a una diapositiva master o normale in una presentazione|
|Caselle di testo|Le caselle di testo possono essere create da zero. È possibile accedere alle caselle di testo esistenti. È inoltre possibile modificare i loro testi senza perdere il formato del testo originale|
|Forme rettangolari|È possibile creare o modificare forme rettangolari con Aspose.Slides for Node.js via .NET|
|Forme di polilinea|È possibile creare o modificare forme di polilinea con Aspose.Slides for Node.js via .NET|
|Forme ellittiche|È possibile creare o modificare forme ellittiche con Aspose.Slides for Node.js via .NET|
|Forme raggruppate|Aspose.Slides per Node.js via .NET supporta le forme raggruppate|
|Forme automatiche|Aspose.Slides per Node.js via .NET supporta le forme automatiche|
|SmartArt|Aspose.Slides per Node.js via .NET fornisce il supporto per le forme SmartArt in MS PowerPoint|
|Grafici|Aspose.Slides per Node.js via .NET fornisce il supporto per i grafici MSO in PowerPoint|
|Serializzazione delle forme|Aspose.Slides per Node.js via .NET supporta un gran numero di forme. Quando Aspose.Slides for Node.js via .NET non supporta una determinata forma, è possibile utilizzare un metodo di serializzazione attraverso il quale è possibile serializzare quella forma da una diapositiva esistente. In questo modo è possibile riutilizzare la forma in base alle proprie esigenze|
|Cornici immagine|È possibile gestire le immagini nelle cornici immagine con Aspose.Slides per Node.js via .NET.|
|Cornici audio|È possibile collegare o incorporare file audio nelle cornici audio sulle diapositive con Aspose.Slides per Node.js via .NET.|
|Cornici video|È possibile gestire i file video nelle cornici video. Aspose.Slides per Node.js via .NET fornisce inoltre il supporto per video collegati e incorporati|
|Cornice OLE|È possibile gestire gli oggetti OLE nelle cornici OLE con Aspose.Slides per Node.js via .NET.|
|Tabelle|Aspose.Slides per Node.js via .NET supporta le tabelle nelle diapositive|
|Controlli ActiveX|Supporto per i controlli ActiveX|
|Macro VBA|Supporto per la gestione delle macro VBA all'interno delle presentazioni.|
|Quadro di testo|È possibile accedere al testo di qualsiasi forma attraverso il quadro di testo associato a quella forma.|
|Scansione del testo|È possibile scansionare il testo in una presentazione a livello di presentazione o diapositiva tramite metodi di scansione integrati.|
|Animazioni|È possibile applicare animazioni alle forme.|
|Presentazioni|Aspose.Slides per Node.js via .NET supporta presentazioni diapositive e transizioni tra diapositive|

## **Funzionalità di formattazione**
Con Aspose.Slides per Node.js via .NET, è possibile formattare testi e forme sulle diapositive delle presentazioni. Consulta i dettagli qui di seguito:

|**Funzionalità**|**Descrizione**|
| :- | :- |
|Formattazione del testo|<p>In Aspose.Slides per Node.js via .NET, è possibile gestire i testi tramite i riquadri di testo associati alle forme. Pertanto, è possibile formattare i testi usando i paragrafi e le porzioni associate ai riquadri di testo. Questi elementi di testo possono essere formattati tramite Aspose.Slides per Node.js via .NET.</p><p>- Tipo di carattere</p><p>- Dimensione del carattere</p><p>- Colore del carattere</p><p>- Tinte del carattere</p><p>- Allineamento del paragrafo</p><p>- Puntatura del paragrafo</p><p>- Orientamento del paragrafo</p>|
|Formattazione della forma|<p>In Aspose.Slides per Node.js via .NET, l'elemento base di una diapositiva è una forma. È possibile formattare questi elementi forma con Aspose.Slides per Node.js via .NET:</p><p>- Posizione</p><p>- Dimensione</p><p>- Linea</p><p>- Riempimento (inclusi Motivo, Gradiente, Solido)</p><p>- Testo</p><p>- Immagine</p>|
