Questa sezione fornisce una descrizione dettagliata delle funzionalità di Aspose.Slides for JasperReports. Fai clic sui collegamenti nella tabella per saperne di più sulle funzionalità.

|**Funzionalità**|**Descrizione**|
| :- | :- |
|[Export PPT, PPTX, PDF e HTML](/slides/it/jasperreports/ppt-pptx-pdf-and-html-export/)|Esporta i report come presentazioni PPT e PPTX, documenti PDF e file HTML dalla tua applicazione senza utilizzare Microsoft PowerPoint.|
|Alta fedeltà al design del report|I report PPT e PPTX hanno lo stesso layout e aspetto dei PDF e di altri formati.|
|Distribuzione semplice e leggera|Aspose.Slides for JasperReports è un esportatore per JasperReports e JasperServer verso il formato Microsoft PowerPoint.|
|[Licenza semplice ed economica](/slides/it/jasperreports/licensing/)|Una licenza per server o una licenza per tutti i tuoi server.|
|[Supporto tecnico gratuito di livello mondiale](/slides/it/jasperreports/technical-support/)|Supporto tecnico illimitato fornito direttamente dagli sviluppatori che lavorano al prodotto.|
