{{% alert color="info" %}} 

JasperReports e JasperServer non dispongono di funzionalità integrate per esportare i report come presentazioni Microsoft PowerPoint, ma con Aspose.Slides for JasperReports ottieni l'accesso a formati di esportazione aggiuntivi:

- Microsoft PowerPoint Presentation (PPT)
- Microsoft PowerPoint Presentation (PPTX)
- HTML
- PDF

{{% /alert %}} 

Per creare documenti in questi formati, Aspose.Slides for JasperReports si basa su una versione integrata di [Aspose.Slides for Java](https://products.aspose.com/slides/it/java/), la libreria leader di mercato per l'elaborazione di presentazioni di Aspose. Microsoft PowerPoint non è utilizzato per generare i documenti.
