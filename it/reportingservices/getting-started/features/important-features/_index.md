|**Funzionalità** |**Descrizione** |
| :- | :- |
|[Esportazione PPT, PPS, PPTX e PPSX](/slides/it/reportingservices/ppt-pps-pptx-and-ppsx-export/)|Esporta i report come presentazioni Microsoft PowerPoint da Microsoft SQL Server Reporting Services senza utilizzare Microsoft PowerPoint. |

|[Distribuzione facile e leggera](/slides/it/reportingservices/easy-and-lightweight-deployment/)|Aspose.Slides for Reporting Services è un'estensione di rendering per Microsoft SQL Server Reporting Services e Power BI Report Server (x86 e x64). Vedi [Requisiti di Sistema](/slides/it/reportingservices/system-requirements/) per le versioni supportate. |
|[Licenza semplice ed economica](/slides/it/reportingservices/simple-and-affordable-licensing/)|Una licenza per server o una licenza per tutti i server. Sviluppatori illimitati. |
|[Supporto tecnico gratuito di classe mondiale](/slides/it/reportingservices/world-class-free-technical-support/)|Supporto tecnico illimitato è fornito direttamente dagli sviluppatori del prodotto. |
