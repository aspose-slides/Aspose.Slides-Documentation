## **Power BI**

È possibile installare Aspose.Slides for Reporting Services su Power BI Report Server attraverso gli stessi processi di installazione:

* [Installa con MSI Installer](/slides/it/reportingservices/install-with-msi-installer/). Il programma di installazione rileva automaticamente il Power BI Report Server installato, installa il prodotto e poi lo configura per il tuo ambiente di lavoro.
* [Installa manualmente](/slides/it/reportingservices/install-manually/). Utilizza l'assembly dalla cartella *Bin\Universal* del pacchetto ZIP.

Aspose.Slides for Reporting Services esporta report paginati (RDL) da Power BI Report Server. Per i requisiti, incluso .NET Framework 3.5 sulla macchina host, vedere [Requisiti di sistema](/slides/it/reportingservices/system-requirements/).
