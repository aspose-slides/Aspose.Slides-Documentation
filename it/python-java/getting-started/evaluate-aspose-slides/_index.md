Puoi scaricare Aspose.Slides for Python via Java per valutare le sue funzionalità. Il pacchetto di valutazione è identico a quello con licenza. Per usarlo senza limitazioni di valutazione, aggiungi alcune righe di codice a [applica una licenza](/slides/it/python-java/licensing/).

La versione di valutazione di Aspose.Slides (usata senza licenza) fornisce la piena funzionalità del prodotto, con due limitazioni:

- Aggiunge una casella di testo con filigrana di valutazione a ogni diapositiva di ogni presentazione che salva. L'apertura di una presentazione non ne aggiunge una, ma il salvataggio di un file che contiene già la filigrana ne aggiunge un'altra.
- Il testo che il tuo codice legge è troncato ai primi caratteri, seguito da un avviso sulla limitazione di valutazione. Questo vale per ogni diapositiva, sia per il testo impostato dal tuo codice sia per il testo caricato da un file. Il testo che il tuo codice scrive viene salvato per intero.

{{% alert color="info" title="Note" %}}

Per testare Aspose.Slides senza limitazioni di valutazione, puoi richiedere una **licenza temporanea di 30 giorni**. Vedi [Ottieni una licenza temporanea](https://purchase.aspose.com/temporary-license) per ulteriori informazioni.
