È possibile scaricare Aspose.Slides per Python via Java per valutare le sue funzionalità. Il pacchetto di valutazione è identico al pacchetto con licenza. Per usarlo senza limitazioni di valutazione, aggiungi alcune righe di codice per applicare una licenza.

La versione di valutazione di Aspose.Slides (utilizzata senza licenza) fornisce tutte le funzionalità del prodotto, ma inserisce una filigrana di valutazione nella parte superiore del documento quando lo apri o lo salvi. L'estrazione del testo è limitata a una diapositiva per presentazione.

![Filigrana di valutazione di Aspose.Slides su una diapositiva di presentazione](evaluate-aspose-slides_1.png)
