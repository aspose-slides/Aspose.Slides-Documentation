Questo articolo descrive le funzionalità di elaborazione delle presentazioni di Aspose.Slides per Python via Java. Per i sistemi operativi supportati e le dipendenze, vedere [Requisiti di sistema](/slides/it/python-java/system-requirements/).

## **Formati di file e conversioni**

Aspose.Slides per Python via Java consente di convertire tra formati di presentazione ed esportare le presentazioni in formati documento e web. Vedere [Formati di file supportati](/slides/it/python-java/supported-file-formats/) per la tabella completa dei formati e la distinzione tra caricamento delle presentazioni, importazione del contenuto ed esportazione dell'output.

## **Rendering della presentazione**

Aspose.Slides per Python via Java offre rendering ad alta fedeltà delle diapositive come immagini raster o vettoriali per anteprime e altri output visivi. Consente inoltre di renderizzare immagini sulle diapositive. Per i formati immagine disponibili e le note di esportazione, vedere [Formati di file supportati](/slides/it/python-java/supported-file-formats/#supported-file-formats).

## **Funzionalità del contenuto**

Aspose.Slides per Python via Java permette di accedere, modificare e creare quasi tutti i tipi di contenuto di presentazione, come descritto di seguito:

|**Funzionalità**|**Descrizione**|
| :- | :- |
|Presentazioni|È possibile creare presentazioni da zero o aprire file esistenti.|
|Proprietà del documento|È possibile leggere e modificare le proprietà del documento.|
|Protezione della presentazione|È possibile applicare la protezione con password e gestire le impostazioni di protezione della presentazione.|
|Diapositive master|Le diapositive master definiscono il layout delle diapositive normali. Aspose.Slides per Python via Java consente di accedere e modificare le diapositive master nelle presentazioni.|
|Diapositive normali|È possibile aggiungere, accedere, modificare, riordinare ed eliminare le diapositive nelle presentazioni.|
|Layout delle diapositive|È possibile lavorare con i layout delle diapositive.|
|Clonazione e copia di diapositive|I metodi integrati consentono di clonare o copiare diapositive all'interno di una presentazione o tra presentazioni. Questi metodi copiano automaticamente la diapositiva master associata quando si clona una diapositiva.|
|Sezioni delle diapositive|È possibile organizzare le diapositive in sezioni all'interno di una presentazione.|
|Segnaposto e contenitori di testo|È possibile accedere ai segnaposto e ai contenitori di testo su una diapositiva, nonché creare diapositive con contenitori di testo da zero.|
|Intestazioni e piè di pagina|Aspose.Slides per Python via Java consente di gestire intestazioni e piè di pagina.|
|Note della diapositiva|È possibile accedere, aggiungere e modificare le note della diapositiva e includerle durante l'esportazione in PDF o TIFF.|
|Ricerca di una forma|È possibile trovare una forma specifica su una diapositiva usando il suo testo alternativo.|
|Testo alternativo|È possibile leggere e aggiornare il testo alternativo per le forme.|
|Collegamenti ipertestuali|È possibile leggere e aggiornare i collegamenti ipertestuali su forme e aggiungere collegamenti ipertestuali al testo.|
|Sfondi|È possibile lavorare con gli sfondi delle diapositive master e delle diapositive normali in una presentazione.|
|Caselle di testo|È possibile creare caselle di testo da zero, accedere a caselle di testo esistenti e modificarne il testo preservando la formattazione originale.|
|Forme rettangolari|È possibile creare e modificare forme rettangolari.|
|Forme lineari|È possibile creare e modificare forme lineari.|
|Forme poligonali|È possibile creare e modificare forme poligonali.|
|Forme ellittiche|È possibile creare e modificare forme ellittiche.|
|Forme raggruppate|Aspose.Slides per Python via Java supporta le forme raggruppate.|
|AutoShape|Aspose.Slides per Python via Java supporta AutoShape.|
|SmartArt|È possibile creare e modificare forme SmartArt nelle presentazioni.|
|Grafici|È possibile creare e modificare grafici Microsoft Office nelle presentazioni PowerPoint.|
|Serializzazione delle forme|Aspose.Slides per Python via Java supporta molti tipi di forma. Per forme non supportate, è possibile utilizzare la serializzazione per conservare una forma da una diapositiva esistente per riutilizzarla.|
|Blocchi forma|È possibile applicare blocchi forma per limitare le azioni di modifica.|
|Cornici immagine|È possibile gestire le immagini nelle cornici immagine.|
|Cornici audio|È possibile collegare o incorporare file audio nelle cornici audio sulle diapositive.|
|Cornici video|È possibile gestire video collegati e incorporati nelle cornici video.|
|Cornici OLE|È possibile gestire oggetti OLE nelle cornici OLE.|
|Tabelle|È possibile creare, spostare e ridimensionare tabelle; aggiungere, eliminare e ridimensionare righe e colonne; e leggere e modificare il contenuto delle celle, i bordi, i riempimenti e la formattazione del testo.|
|Controlli ActiveX|Aspose.Slides per Python via Java supporta i controlli ActiveX.|
|Macro VBA|È possibile gestire macro VBA nelle presentazioni.|
|Cornici di testo|È possibile accedere al testo di una forma tramite la sua cornice di testo associata e regolare i margini della cornice di testo e l'andamento del testo.|
|Font|È possibile gestire i font utilizzati nelle presentazioni.|
|Scansione del testo|I metodi integrati consentono di scansionare il testo su tutta la presentazione o su diapositive individuali.|
|Animazioni|È possibile aggiungere e modificare effetti di animazione sulle forme.|
|Presentazioni|Aspose.Slides per Python via Java supporta presentazioni diapositive e transizioni diapositive, incluse le transizioni Morph.|

## **Funzionalità di formattazione**

Aspose.Slides per Python via Java consente di formattare testo e forme sulle diapositive della presentazione, come descritto di seguito:

|**Funzionalità**|**Descrizione**|
| :- | :- |
|Formattazione del testo|<p>È possibile gestire il testo attraverso le cornici di testo associate alle forme e formattare paragrafi e porzioni di testo individuali. Sono disponibili le seguenti opzioni di formattazione:</p><p>- Tipo di carattere</p><p>- Dimensione del carattere</p><p>- Colore del carattere</p><p>- Ombreggiatura del carattere</p><p>- Allineamento del paragrafo</p><p>- Rientro del paragrafo e tabulazioni</p><p>- Elenchi puntati del paragrafo</p><p>- Orientamento del paragrafo</p>|
|Formattazione della forma|<p>Le forme sono gli elementi di base di una diapositiva. È possibile regolare le seguenti proprietà della forma:</p><p>- Posizione</p><p>- Dimensione</p><p>- Rotazione</p><p>- Stili di linea</p><p>- Riempimento (inclusi riempimenti solido, sfumatura, pattern, texture e immagine)</p><p>- Testo</p><p>- Immagine</p>|
