**Benvenuto in Aspose.Slides for Python via Java**

![Logo del prodotto Aspose.Slides for Python via Java](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java è una libreria di classi che consente alle tue applicazioni Python di leggere e scrivere presentazioni PowerPoint® senza richiedere Microsoft PowerPoint®.

Le sue funzionalità principali includono la gestione di testo, forme, tabelle e animazioni; l'aggiunta di audio e video alle diapositive; l'anteprima delle diapositive; e l'esportazione delle diapositive in SVG, PDF e altri formati.
