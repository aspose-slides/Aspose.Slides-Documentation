{{% alert color="info" title="Nota" %}}

Aspose.Slides for Python via Java è una libreria di classi che consente alle applicazioni Python di leggere e scrivere presentazioni senza richiedere Microsoft PowerPoint®. Permette di gestire testo, forme, tabelle e animazioni; aggiungere audio e video alle diapositive; visualizzare l'anteprima delle diapositive; ed esportare le diapositive in SVG, PDF e altri formati.

Per ulteriori dettagli, vedere la [Riferimento API di Aspose.Slides for Python via Java](https://reference.aspose.com/slides/it/python-java/).
