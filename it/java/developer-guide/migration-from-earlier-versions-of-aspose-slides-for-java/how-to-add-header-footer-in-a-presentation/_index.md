## **Supporto al codice legacy**
Per utilizzare il codice legacy sviluppato con Aspose.Slides per Java nelle versioni precedenti alla 13.x, è necessario apportare alcune piccole modifiche al proprio codice e il codice funzionerà come prima. Tutte le classi presenti nella vecchia Aspose.Slides per Java nei namespace Aspose.Slide e Aspose.Slides.Pptx sono ora fuse in un unico namespace Aspose.Slides.
