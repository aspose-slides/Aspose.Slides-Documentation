## **Panoramica**

Questa sezione non contiene un elenco di problemi aperti nella versione corrente. Contiene tre pagine:

- [Segnaposto anteprima oggetto quando si aggiunge OleObjectFrame](/slides/it/java/object-preview-issue-when-adding-oleobjectframe/) spiega perché un oggetto OLE aggiunto con Aspose.Slides mostra un'immagine "EMBEDDED OLE OBJECT" fino a quando la sua anteprima non viene aggiornata, e come impostare la tua immagine di anteprima. Questo è un comportamento progettato della versione corrente.
- [Problemi noti in Aspose.Slides per Java 14.3.0 (Storico)](/slides/it/java/known-issues-in-aspose-slides-for-java-14-3-0/) e [Problemi noti in Aspose.Slides per Java 14.4.0 (Storico)](/slides/it/java/known-issues-in-aspose-slides-for-java-14-4-0/) sono elenchi pubblicati con quelle versioni, conservati per riferimento.

Per le modifiche e le correzioni in ogni versione, consulta le [note di rilascio](https://releases.aspose.com/slides/it/java/release-notes/). I campi di metadati che Aspose.Slides scrive con valori fissi sono descritti in [Limitazioni sui metadati di output](/slides/it/java/api-limitations/). Per verificare se un problema è già noto, o per segnalarne uno, usa il [forum di supporto](https://forum.aspose.com/c/slides/it/11).
