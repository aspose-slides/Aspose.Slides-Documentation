{{% alert color="info" title="Note" %}}

Questa è una pagina storica. Elenca i problemi noti pubblicati con Aspose.Slides for Java 14.3.0 e non descrive la versione corrente. Per le modifiche in ogni versione, vedere le [note di rilascio](https://releases.aspose.com/slides/it/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) fornisce un'implementazione completamente nuova dell'elaborazione PPT. Ci sono molti miglioramenti, conversione parziale da PPTX a PPT. Tuttavia, ci sono alcune funzionalità non implementate:

- Alcune forme hanno una geometria errata nei documenti PPT serializzati (Call outs)
- Non tutte le funzionalità di formattazione del testo PPTX sono supportate nella serializzazione PPT
- Le informazioni sulla lingua del testo e le impostazioni di ortografia non sono presenti nei documenti PPT serializzati
- Non tutte le funzionalità dei temi PPTX sono supportate nella serializzazione PPT

**Ci sono alcune differenze rispetto ad Aspose.Slides for Java 8.6.0:**

- Sono presenti problemi noti nella serializzazione PPT OLE/ActiveX in PPT

**Ci sono alcune differenze rispetto ad Aspose.Slides for .NET 14.3.0:**

- Il supporto di stampa delle presentazioni al momento non è disponibile in Aspose.Slides for Java
