{{% alert color="info" title="Note" %}}
Questa è una pagina storica. Elenca le limitazioni e i problemi noti pubblicati con Aspose.Slides per Java 14.4.0 e non descrive la versione corrente. Per le modifiche in ciascuna versione, vedere le [note di rilascio](https://releases.aspose.com/slides/it/java/release-notes/).
{{% /alert %}}

Aspose.Slides per Java 14.4.0 offre nuove funzionalità per l'elaborazione dei documenti PowerPoint. Sono presenti alcune limitazioni e problemi noti, che saranno rimossi nelle prossime versioni:

- Alcune forme hanno una geometria errata nei documenti PPT serializzati (arco, freccia circolare, annotazioni).
- Non tutte le funzionalità di formattazione del testo di PPTX sono supportate nella serializzazione PPT (tabulazione, rientro e limitazioni nella formattazione dei paragrafi).
- Le informazioni sulla lingua del testo e le impostazioni di ortografia non sono presenti nei documenti PPT serializzati.
- Non tutte le funzionalità del tema PPTX sono supportate nella serializzazione PPT (solo la serializzazione dei formati di riempimento, dei formati di linea e dei caratteri).
- Sono presenti problemi noti nella serializzazione OLE/ActiveX da PPT a PPT.
- La serializzazione e il rendering di WordArt non sono supportati.
