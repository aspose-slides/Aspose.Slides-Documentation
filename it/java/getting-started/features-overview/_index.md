## **Panoramica**

Aspose.Slides per Java è una libreria di classi per creare, leggere, modificare, convertire e visualizzare presentazioni PowerPoint e OpenDocument. Non ha un'interfaccia utente propria e non richiede Microsoft PowerPoint o Microsoft Office. Questo articolo riassume ciò che la libreria copre e collega gli articoli che descrivono ogni area.

## **Piattaforme supportate**

Aspose.Slides per Java è un singolo file JAR, pubblicato nel repository Maven di Aspose con il classificatore `jdk16`. È scritto interamente in Java: il JAR non contiene librerie native e non dipende da altri pacchetti.

- **Java:** Java 8 o versioni successive. Aspose.Slides per Java 26.9 e versioni precedenti funzionano anche su Java 6 e 7, versione non più supportata da 26.10; vedi le [note di rilascio 26.9](https://releases.aspose.com/slides/it/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/).
- **Sistemi operativi:** qualsiasi sistema operativo con un runtime Java, come Windows, Linux e macOS. Su Linux è necessario installare la libreria fontconfig e almeno un carattere.

[Installazione](/slides/it/java/installation/) mostra come aggiungere la libreria a un progetto e elenca i prerequisiti per Linux. [Requisiti di sistema](/slides/it/java/system-requirements/) elenca in dettaglio le piattaforme supportate.

Aspose.Slides apre e salva presentazioni PPT, PPTX, PPS, POT, PPSX, POTX, PPTM, PPSM, POTM, ODP, OTP, FODP e PowerPoint XML. Importa contenuti PDF e HTML nelle diapositive e salva le presentazioni come PDF, XPS, HTML, HTML5, TIFF, GIF animati, SWF, Markdown e XAML. ## **Rendering della presentazione**

Aspose.Slides rende le diapositive e le singole forme come immagini PNG, JPEG, BMP, GIF, TIFF e SVG, e le diapositive come metafili EMF. Vedi [Convertire le diapositive della presentazione in immagini](/slides/it/java/convert-slide/), [Renderizzare le diapositive della presentazione come immagini SVG](/slides/it/java/render-a-slide-as-an-svg-image/) e [Creare miniature delle forme della presentazione](/slides/it/java/create-shape-thumbnails/).

## **FAQ**

**Devo installare Microsoft PowerPoint sul server o sul PC affinché la libreria funzioni?**

No. PowerPoint non è necessario; Aspose.Slides è un motore autonomo per creare, modificare, convertire e renderizzare presentazioni.

**Come funziona il multithreading? È possibile parallelizzare l'elaborazione?**

È sicuro elaborare documenti diversi in thread differenti; lo stesso oggetto [Presentazione](https://reference.aspose.com/slides/it/java/com.aspose.slides/presentation/) non deve essere usato da [thread multipli](/slides/it/java/multithreading/) contemporaneamente.

**Sono supportate le password dei file e la crittografia?**

Sì. [Puoi](/slides/it/java/password-protected-presentation/) aprire presentazioni crittografate, impostare o rimuovere una password di apertura e di scrittura, e verificare lo stato della protezione.

**Devo preoccuparmi dei caratteri nei container Linux?**

Sì. Su Linux è necessario installare la libreria fontconfig e almeno un carattere, e i caratteri usati nelle tue presentazioni, o sostituti adeguati, devono essere installati affinché il testo venga visualizzato correttamente. Puoi anche [specificare le directory dei caratteri](/slides/it/java/custom-font/) nella tua applicazione. Vedi [Installazione](/slides/it/java/installation/#linux).

**Ci sono limitazioni nella versione di valutazione?**

Sì. Senza una [licenza](/slides/it/java/licensing/), Aspose.Slides aggiunge una filigrana di valutazione a ogni diapositiva salvata e tronca il testo che il tuo codice legge tramite l'API. È disponibile una [licenza temporanea di 30 giorni](https://purchase.aspose.com/temporary-license/) per testare tutte le funzionalità.

**È supportata l'importazione di formati esterni in una presentazione (PDF o HTML in PPTX)?**

Sì. Puoi aggiungere [pagine PDF e contenuti HTML](/slides/it/java/import-presentation/) a una presentazione, trasformandoli in diapositive.
