{{% alert color="info" title="Nota" %}}

Il [XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) è un linguaggio di descrizione di pagina e un formato di documento fisso originariamente sviluppato da Microsoft. Come PDF, XPS è progettato per preservare la fedeltà del documento e fornire un aspetto del documento indipendente dal dispositivo.

{{% /alert %}}

## **XPS in Aspose.Slides for Java**
Qualsiasi documento di presentazione che può essere caricato da Aspose.Slides for Java può essere convertito in formato XPS. Aspose.Slides for Java utilizza il motore di layout di pagina e rendering ad alta fedeltà per produrre output nel formato di documento XPS a layout fisso.
È possibile apprendere come esportare i documenti di presentazione in documenti XPS tramite Aspose.Slides for Java in [Converti presentazioni PowerPoint in XPS](/slides/it/java/convert-powerpoint-to-xps/).
