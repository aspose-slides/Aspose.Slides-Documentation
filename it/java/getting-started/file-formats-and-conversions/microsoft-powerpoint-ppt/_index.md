Questa è una pagina storica, conservata per i collegamenti esistenti. Non descrive la versione corrente di Aspose.Slides per Java. Per i formati che Aspose.Slides per Java carica, importa, salva e renderizza, e per l’API di ciascuno, vedere [Formati di file supportati](/slides/it/java/supported-file-formats/). Per confrontare PPT con PPTX, vedere [Capire la differenza: PPT vs PPTX](/slides/it/java/ppt-vs-pptx/).

{{% /alert %}}

{{% alert color="info" title="Nota" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) è il formato di file per documenti di presentazione che può essere creato, letto, manipolato e scritto da diverse versioni di Microsoft PowerPoint. È il formato binario per i documenti di presentazione sviluppato da Microsoft.

{{% /alert %}}

## **PPT in Aspose.Slides per Java**
Aspose.Slides per Java può leggere i file PPT creati dal software elencato di seguito.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Allo stesso modo, i file PPT creati da Aspose.Slides per Java possono essere letti dal suddetto insieme di software.

## **Supporto completo per PPT**
Aspose.Slides per Java fornisce supporto per quasi tutte le funzionalità supportate dal formato di file documento PPT. Copre non solo le funzionalità di base e avanzate fornite dalle diverse versioni di Microsoft PowerPoint per la manipolazione dei documenti PPT, ma anche funzionalità non supportate nemmeno da Microsoft PowerPoint. Il principale vantaggio dell’utilizzo della libreria API Aspose.Slides per Java è la facilità d’uso nella gestione di tali funzionalità.

Oltre alle attività di base relative alla creazione, lettura e scrittura di file documento PPT, sono disponibili diverse funzionalità fornite da Aspose.Slides per Java:

- Importare altri formati di file Microsoft Office come [oggetti OLE nei documenti PPT](/slides/it/java/manage-ole/).
- [Esportare i documenti PPT in PDF](/slides/it/java/convert-powerpoint-to-pdf/).
- Esportare le diapositive nei documenti PPT in formati SVG.
- Renderizzare le diapositive in qualsiasi formato immagine supportato dal Framework Java.
- Impostare le dimensioni delle diapositive nei documenti PPT.
- Gestire le animazioni sulle forme.
- Gestire le presentazioni.
- [Formattare il testo sulle diapositive](/slides/it/java/text-formatting/).
- Estrarre il testo dai documenti PPT.
- [Gestire le tabelle sulle diapositive](/slides/it/java/powerpoint-table/).
- Copiare automaticamente i master utilizzando [la funzione di clonazione](/slides/it/java/clone-slides/).
