## **Informazioni su TIFF**

Il [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) noto per la memorizzazione di più immagini in un unico documento è stato originariamente creato da Aldus. Questo formato è ampiamente supportato da applicazioni di scansione, fax e altre manipolazioni di immagini.

## **TIFF in Aspose.Slides per Java**

Qualsiasi documento che può essere caricato in Aspose.Slides per Java può anche essere convertito direttamente in documento TIFF da Aspose.Slides per Java, eliminando la necessità di componenti di terze parti. Inoltre, è possibile definire facoltativamente le dimensioni delle immagini nel documento TIFF risultante. È possibile trovare informazioni sull'esportazione dei documenti di presentazione in documenti TIFF tramite Aspose.Slides per Java in [Convert PowerPoint Presentations to TIFF](/slides/it/java/convert-powerpoint-to-tiff/).
