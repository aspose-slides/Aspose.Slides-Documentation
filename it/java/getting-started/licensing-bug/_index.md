Questa è una pagina storica. Descrive un bug in Aspose.Slides for Java versioni 23.2 a 23.7, rilasciate nel 2023, e le versioni che lo hanno corretto. Non descrive la versione corrente. Per le licenze nella versione attuale, vedere [Licenze](/slides/it/java/licensing/).

## **Panoramica**

Questo articolo descrive un bug di licenza riscontrato in Aspose.Slides for Java versioni 23.2, 23.3, 23.4, 23.5, 23.6 e 23.7. Questo bug ha causato il temporaneo inutilizzo delle licenze perpetue dopo la scadenza della loro sottoscrizione.

## **Sintomi**

Dopo la scadenza della sottoscrizione della tua licenza perpetua, le versioni Aspose.Slides for Java 23.2 - 23.7 possono segnalare la licenza come scaduta, passando tutte le funzioni in modalità di valutazione.  
Questo comportamento è errato e non riguarda le versioni precedenti alla 23.2 e successive alla 23.7.

## **Risoluzione**

Aspose.Slides for Java ha risolto questo problema e ha rilasciato versioni aggiornate (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) con la correzione.

Se stai utilizzando una delle versioni interessate di Aspose.Slides for Java nel tuo progetto, passa alla versione corretta.

Si noti che questo bug interessa solo le versioni Aspose.Slides for Java 23.2 fino a 23.7. **Altri prodotti Aspose e altre versioni di Aspose.Slides non sono interessati**.
