{{% alert color="info" %}} 

Aspose.Slides for Java è una libreria di classi che consente alle applicazioni Java di leggere e scrivere documenti di presentazione senza utilizzare Microsoft PowerPoint® o altri. Aspose.Slides for Java permette di gestire testo, forme, tabelle e animazioni, aggiungere audio e video alle diapositive, visualizzare in anteprima le diapositive, esportare le diapositive in formato SVG, PDF e altro.

L'ultima Riferimento API può essere trovata su [Riferimento API di Aspose.Slides per Java](https://reference.aspose.com/slides/it/java).
