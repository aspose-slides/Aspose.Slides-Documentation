Per convertire una presentazione in una raccolta documenti:

1. Apri il menu del file PPT o PPTX (il suo Edit Control Block) e seleziona **Convert via Aspose.Slides**. In SharePoint 2007, la voce di menu si chiama **Convert with Aspose.Slides**.

   **Selezionare Convert with Aspose.Slides nel menu di un documento su SharePoint 2007**

   ![Il menu di un documento in una raccolta documenti SharePoint 2007, con la voce Convert with Aspose.Slides](convert-one-file_1.png)

2. Nella pagina di conversione, seleziona il formato di output sotto **Convert to**. Se lo desideri, modifica il nome del file di destinazione e la cartella di destinazione.
3. Fai clic su **Convert**.
4. Al termine della conversione, fai clic su **Source Library** o **Destination Library** per tornare a una raccolta documenti. Il file convertito si trova nella cartella di destinazione.

Gli stessi passaggi, con schermate di ogni pagina, sono disponibili in [Conversione di documenti Microsoft PowerPoint in altri formati](/slides/it/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
