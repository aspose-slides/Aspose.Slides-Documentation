{{% alert color="info" title="Note" %}}

I siti SharePoint sono progettati per la collaborazione, la comunicazione e l'archiviazione dei contenuti al fine di soddisfare esigenze aziendali specifiche. Consentono a un gruppo di persone di raggiungere un obiettivo comune facilitando la condivisione delle informazioni e la comunicazione. Le informazioni sono solitamente disponibili come sito web e sono accessibili tramite un browser web.

{{% /alert %}}

## **Cos'è SharePoint e Aspose.Slides?**

Aspose.Slides per SharePoint è una soluzione per la conversione delle presentazioni Microsoft PowerPoint (PPT e PPTX) in altri formati: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX e POTM. Consente di convertire i file PowerPoint in un sito SharePoint senza utilizzare Microsoft PowerPoint. L'elenco completo dei formati è disponibile in [Formati di file supportati](/slides/it/sharepoint/supported-file-formats/).
