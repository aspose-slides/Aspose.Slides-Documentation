Aspose.Slides for SharePoint è una soluzione farm per SharePoint 2007‑2019 che converte le presentazioni PowerPoint archiviate nelle raccolte documenti sul server, senza Microsoft PowerPoint e senza scrivere codice.

Converte i file PPT e PPTX in PDF, TIFF, XPS, HTML, SWF e ODP, e nei formati PowerPoint PPS, PPSX, PPTM, PPSM, POTX e POTM, e salva il risultato in una raccolta documenti.

## **La tua prima esportazione**

1. Scarica l'archivio ZIP dalla [pagina di download](https://releases.aspose.com/slides/sharepoint/) e estrailo su un server nella tua farm SharePoint.
2. Esegui il programma di installazione corrispondente alla tua versione di SharePoint: *Setup2007.exe*, *Setup2010.exe*, *Setup2013.exe*, *Setup2016.exe* o *Setup2019.exe*. Usa un account che possa installare e distribuire soluzioni SharePoint. Accetta il contratto di licenza, seleziona le collezioni di siti su cui attivare la funzionalità e lascia che il setup distribuisca la soluzione. Ogni schermata è descritta in [Installazione](/slides/it/sharepoint/installing-aspose-slides-for-sharepoint/).
3. Apri una raccolta documenti in una di queste collezioni di siti, apri il menu di un file PPT o PPTX e seleziona **Convert via Aspose.Slides**. Su SharePoint 2007, la voce di menu si chiama **Convert with Aspose.Slides**.
4. Nella sezione **Convert to**, seleziona **PDF - Adobe Portable Document**. Modifica il nome del file di destinazione e la cartella se necessario, e fai clic su **Convert**.
5. Quando la conversione è completata, fai clic su **Destination Library** per aprire la cartella che contiene il nuovo file PDF.

Senza licenza, il file convertito riporta un filigrana di valutazione — vedi [Licenza](/slides/it/sharepoint/installing-aspose-slides-for-sharepoint-license/). Per gli stessi passaggi con screenshot, vedi [Conversione di documenti Microsoft PowerPoint in altri formati](/slides/it/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
