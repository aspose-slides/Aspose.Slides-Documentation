{{% alert color="info" title="Note" %}}

Il download di valutazione di Aspose.Slides per SharePoint è lo stesso del download acquistato. Diventa la versione con licenza quando installi il pacchetto di soluzione di licenza sul farm; vedi [Installing Aspose.Slides for SharePoint License](/slides/it/sharepoint/installing-aspose-slides-for-sharepoint-license/). Nessun codice è coinvolto.

Senza licenza, Aspose.Slides per SharePoint converte in tutti i formati supportati, ma i file convertiti contengono una filigrana di valutazione e la pagina di conversione mostra un avviso di valutazione.
