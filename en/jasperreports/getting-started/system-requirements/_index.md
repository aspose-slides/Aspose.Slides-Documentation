## **JasperReports**

Aspose.Slides for JasperReports works with JasperReports 3.7.2 to 6.16.0. The download has a separate jar for each of three version ranges — see [Installing Aspose.Slides for JasperReports](/slides/jasperreports/installing-aspose-slides-for-jasperreports/) for which one to use. It has no jar for JasperReports 6.17.0 or later, including JasperReports 7.

Support for JasperReports 2.0.3 to 3.7.1 ended in Aspose.Slides for JasperReports 17.6. Version 17.5 and earlier also supported those versions.

## **Java**

The jars are compiled for Java 6 or later, as the *JDK 1.6* in their folder names says, so the Java version you need is the one that your JasperReports version needs. With JasperReports 6.16.0, exports run on Java 11, 17, 21 and 25.

## **Operating system**

The jars contain only Java classes and resources, with no native libraries, and they do not use Microsoft PowerPoint. On Linux, JasperReports needs fontconfig and at least one installed font to fill a report.

## **JasperReports Server**

For JasperReports Server, use both jars from the folder that matches the JasperReports version your server runs — see [Integration with JasperServer](/slides/jasperreports/integration-with-jasperserver/).
