## **Overview**

Use PPTX files as the input and output of a presentation workflow. Open a deck, inspect or edit its slides, and save a new copy that can be opened in PowerPoint. This feature is useful when updating templates, importing customer decks, or producing files that colleagues will continue editing.

## **FAQ**

**Does this page cover every PowerPoint file format?**

This page covers PPTX. Consult the selected edition's Supported File Formats page for other presentation formats and their read and write operations.
