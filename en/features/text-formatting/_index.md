## **Overview**

Format a whole text range or emphasize individual words with font size, weight, style, and color. Portions let several styles coexist in the same paragraph. This is useful for headings, labels, highlighted values, and consistently styled report text.

## **FAQ**

**Can part of a sentence use a different style?**

Yes. Split the sentence into portions and apply formatting to the portions that need a different appearance.
