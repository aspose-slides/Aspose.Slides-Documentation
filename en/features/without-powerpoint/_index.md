## **Overview**

Use Aspose.Slides in an application or server process without automating a desktop PowerPoint installation. The library performs presentation processing itself. Choose an edition for your application language and follow its installation and system requirements before deploying.

## **FAQ**

**Does this remove all environment requirements?**

No. Each edition still has runtime, operating system, and font requirements. Consult its installation guide for the deployment environment.
