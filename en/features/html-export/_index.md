## **Overview**

Save a presentation as HTML so readers can open it in a browser. Classic HTML export can package slide content into a self-contained document, using SVG for the slide body. Choose the output options to suit how your application stores and serves the result.

## **FAQ**

**Which export should I use for animation?**

See HTML5 export for browser navigation and supported animation. Its output and script dependencies differ from classic HTML.
