Prepare a Distribution Copy

Tested on Windows x64 with Arial and the exact .NET SDK8.0.427 in global.json; uses Aspose.Slides.NET26.10.0 (restored from NuGet), and an appropriate license for full-content assertions.
Set ASPOSE_LICENSE_PATH to your license; then run dotnet run --project Example.csproj --configuration Release

Prepare a separate distribution copy with an explicit removal list: speaker notes, comments, author/custom metadata and the VBA project. Add a visual watermark and a password-protected PDF. The synthetic original stays unchanged. This is not forensic sanitization: hyperlinks, embedded files, hidden objects and other properties require their own review.
Outputs appear in the working directory.
