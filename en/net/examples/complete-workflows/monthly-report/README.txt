Generate a Monthly Report

Tested on Windows x64 with Arial and the exact .NET SDK8.0.427 in global.json; uses Aspose.Slides.NET26.10.0 (restored from NuGet), and an appropriate license for full-content assertions.
Set ASPOSE_LICENSE_PATH to your license; then run dotnet run --project Example.csproj --configuration Release

Build a monthly report from a small JSON dataset and an original branded template. The project populates an editable chart/table, repeats a detail slide for every product and delivers PPTX plus PDF. It checks that chart totals reconcile to the source and preserves the template.
Outputs appear in the working directory.
