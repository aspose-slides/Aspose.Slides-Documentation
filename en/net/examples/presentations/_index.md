These examples work with complete presentation files and streams. Each recipe supplies a runnable C# project, generated input, and checks of the saved result.

- [Create, Open, and Save Presentations](/slides/net/examples/presentations/create-open-save/): Create a presentation, edit a saved copy, and verify that the original file is unchanged.
- [Work with Presentation Streams](/slides/net/examples/presentations/streams/): Load and save presentation streams while controlling their positions and lifetimes.
- [Merge Presentations](/slides/net/examples/presentations/merge/): Merge complete decks or selected slides and choose between source design and a destination layout.
- [Split Presentations](/slides/net/examples/presentations/split/): Save individual slides, a selected range, or named sections to separate presentation files.
- [Read and Update Presentation Properties](/slides/net/examples/presentations/properties/): Read file information, update metadata, and retain the presentation content and unrelated properties.
- [Add Presentation Watermarks](/slides/net/examples/presentations/watermarks/): Apply text and image watermarks to slides, then remove only the shapes identified by your application.

For operations on a single slide, shape, chart or other object, browse [Elements](/slides/net/examples/elements/).
