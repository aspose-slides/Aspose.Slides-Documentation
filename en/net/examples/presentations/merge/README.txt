# Merge Presentations

This complete C# example uses Aspose.Slides for .NET 26.10.0 on .NET 8. A valid license is needed to run all its fixture assertions.
Set ASPOSE_LICENSE_PATH to your own license file without placing that file in this directory or the download.

Run: dotnet restore Example.csproj --locked-mode
Then: dotnet run --project Example.csproj --configuration Release --no-restore

All inputs are generated from original synthetic data by Program.cs. Outputs are written to the current directory.
The program stops with an exception if a required check fails and writes result.json on success.
