## **Overview**

This section does not contain a list of open issues in the current version. It contains two pages:

- [Object Preview Placeholder When Adding OleObjectFrame](/slides/net/object-preview-issue-when-adding-oleobjectframe/) explains why an OLE object added with Aspose.Slides shows an "EMBEDDED OLE OBJECT" image until its preview is updated, and how to set your own preview image. This is by-design behavior of the current version.
- [Known Issues in Aspose.Slides for .NET 14.1.0 (Historical)](/slides/net/known-issues-in-aspose-slides-for-net-14-1-0/) is a list published with version 14.1.0 in 2014, kept for reference.

For the changes and fixes in each version, see the [release notes](https://releases.aspose.com/slides/net/release-notes/). The metadata fields that Aspose.Slides writes with fixed values are described in [Output Metadata Limitations](/slides/net/api-limitations/). To check whether a problem is already known, or to report one, use the [support forum](https://forum.aspose.com/c/slides/11).
