{{% alert color="info" title="Note" %}}

Aspose.Slides for Python via Java is a class library that enables Python applications to read and write presentations without requiring Microsoft PowerPoint®. It allows you to manage text, shapes, tables, and animations; add audio and video to slides; preview slides; and export slides to SVG, PDF, and other formats.

For details, see the [Aspose.Slides for Python via Java API Reference](https://reference.aspose.com/slides/python-java/).
