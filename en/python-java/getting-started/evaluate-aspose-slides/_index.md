You can download Aspose.Slides for Python via Java to evaluate its features. The evaluation package is identical to the licensed package. To use it without evaluation limitations, add a few lines of code to [apply a license](/slides/python-java/licensing/).

The evaluation version of Aspose.Slides (used without a license) provides full product functionality, with two limitations:

- It adds an evaluation watermark text box to every slide of each presentation it saves. Opening a presentation does not add one, but saving a file that already carries the watermark adds another.
- Text that your code reads is truncated to its first few characters, followed by a notice about the evaluation limitation. This applies to every slide, and to text your code has just set as well as text loaded from a file. Text that your code writes is saved in full.

{{% alert color="info" title="Note" %}}

To test Aspose.Slides without evaluation limitations, you can request a **30-day temporary license**. See [Get a Temporary License](https://purchase.aspose.com/temporary-license) for more information.
