## **Overview**

Use the Aspose.Slides support forum to ask questions, report issues, and request features for Aspose.Slides for Python via Java. This article explains what to check before opening a topic and what information helps the support team reproduce a problem.

## **Technical Support**

{{% alert color="info" title="Note" %}}

Aspose provides free technical support to all users, including those evaluating the product. See the [free support policies](https://forum.aspose.com/t/free-support-policies/162313) for details.

{{% /alert %}}

Post technical questions in the [Aspose.Slides support forum](https://forum.aspose.com/c/slides/11). Specify **Aspose.Slides for Python via Java** in your report so the team can identify the correct product and environment.

For priority assistance, see the [paid support helpdesk](https://helpdesk.aspose.com/). Paid support requires a separate subscription and is not included with a product license.

## **Before Reporting an Issue**

1. Check the [downloads](https://releases.aspose.com/slides/python-java/) and [release notes](https://releases.aspose.com/slides/python-java/release-notes/) for a newer version that may address the issue. If possible, reproduce the problem with the latest release in a test environment.
2. Search the support forum, [documentation](/slides/python-java/), and [API reference](https://reference.aspose.com/slides/python-java/) for an existing answer.
3. For installation or JVM startup problems, review the [installation guide](/slides/python-java/installation/) and confirm that Python and Java use matching architectures.
4. Reduce the problem to the smallest example and input presentation that still reproduce it.

## **Prepare an Issue Report**

Include the following information in your forum topic:

- **Environment:** Aspose.Slides for Python via Java version, Python version, Java version and vendor, JPype version, operating system, and architecture.
- **Steps and code:** A minimal runnable Python example, including imports and JVM initialization, and the steps needed to reproduce the problem.
- **Input files:** The presentation and any related files required by the example. Combine multiple files in a ZIP archive.
- **Expected and actual results:** Describe the difference and attach the generated output or screenshots when useful. For rendering issues, identify the affected slides and fonts.
- **Error details:** The complete error message and stack trace, if an exception occurs.

Use one topic per issue. Add follow-up information about the same issue to the existing topic so the support team can follow the investigation.

## **FAQ**

**Can I get help while evaluating Aspose.Slides for Python via Java?**

Yes. Free technical support is available through the Aspose.Slides support forum during evaluation as well as after purchase.

**What should I include when the JVM fails to start?**

Provide your Python, Java, and JPype versions, operating system, Python and Java architectures, JVM initialization code, and the complete error message. These details help the support team reproduce your setup.

**How should I report a problem that appeared after an upgrade?**

Include the last version that worked, the first version where you observed the problem, and a minimal example with input files. Describe any other environment changes made during the upgrade.
