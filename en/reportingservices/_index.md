Aspose.Slides for Reporting Services is a rendering extension for Microsoft SQL Server Reporting Services and Power BI Report Server that adds presentation formats to the export list of paginated (RDL) reports, without Microsoft PowerPoint on the server.

It exports reports to PPT, PPTX, PPS and PPSX presentations and slide shows, to ODP, and to XPS.

## **Your first export**

There is no code to write: you install the extension on the report server, and its formats appear in the export list of every paginated report on that server.

1. Check that the report server meets the [system requirements](/slides/reportingservices/system-requirements/), including .NET Framework 3.5.
1. From the [download page](https://releases.aspose.com/slides/reportingservices/), download the MSI installer, *Aspose.Slides for Reporting Services*. To install by hand instead, download the ZIP package, *Aspose.Slides for Reporting Services (DLLs Only)*.
1. Install the extension on the report server: run the MSI as an administrator, as described in [Install with the MSI installer](/slides/reportingservices/install-with-msi-installer/), or follow [Install manually](/slides/reportingservices/install-manually/) for the ZIP package.
1. In a browser, open the report server's web portal (Report Manager on SQL Server 2014 and earlier). By default, its address is `https://<ComputerName>/reports`.
1. Open a paginated report. On the report toolbar, open the **Export** list and select **PPTX - PowerPoint 2007 Presentation via Aspose.Slides**. If the toolbar has a separate **Export** button, as Report Manager does, select it.
1. Open or save the PPTX file that the browser downloads.

Without a license, the exported presentation carries an evaluation watermark — see [Licensing](/slides/reportingservices/license-aspose-slides-for-reporting-services/). For the other formats in the export list, see [Supported File Formats](/slides/reportingservices/supported-file-formats/).
