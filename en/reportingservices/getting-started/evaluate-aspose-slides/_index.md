## **Evaluation Version**

You can download Aspose.Slides for Reporting Services for evaluation from [its download page](https://releases.aspose.com/slides/reportingservices/). The evaluation download is the same as the purchased download. It becomes licensed when you copy a license file to the report server — no code is involved; see [Licensing](/slides/reportingservices/license-aspose-slides-for-reporting-services/).

The evaluation version (without a license) provides full product functionality, but it inserts an evaluation watermark into exported presentations.

![A report exported in evaluation mode, with the evaluation watermark](evaluate-aspose-slides_1.png)

## **Evaluate Without the Watermark**

If you want to test Aspose.Slides for Reporting Services without the evaluation watermark, you can request a 30-day temporary license. Please refer to [How to get a Temporary License?](https://purchase.aspose.com/temporary-license)
