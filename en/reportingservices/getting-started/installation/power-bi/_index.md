## **Power BI**

You can install Aspose.Slides for Reporting Services on Power BI Report Server through the same installation processes:

* [Install with MSI Installer](/slides/reportingservices/install-with-msi-installer/). The installation program automatically detects the installed Power BI Report Server, installs the product, and then configures it for your work environment.
* [Install Manually](/slides/reportingservices/install-manually/). Use the assembly from the *Bin\Universal* folder of the ZIP package.

Aspose.Slides for Reporting Services exports paginated reports (RDL) from Power BI Report Server. For the requirements, including .NET Framework 3.5 on the host machine, see [System Requirements](/slides/reportingservices/system-requirements/).
