{{% alert color="info" title="Note" %}}

This is a historical page. It describes a bug in Aspose.Slides for Java versions 23.2 to 23.7, which were released in 2023, and the versions that fixed it. It does not describe the current version. For licensing in the current version, see [Licensing](/slides/java/licensing/).

{{% /alert %}}

## **Overview**

This article describes a licensing bug encountered in Aspose.Slides for Java versions 23.2, 23.3, 23.4, 23.5, 23.6 and 23.7. This bug caused perpetual licenses to become temporarily unusable after their subscription expired.

## **Symptoms**

After your perpetual license subscription expires, Aspose.Slides for Java versions 23.2 - 23.7 may report the license as expired, transitioning all functions into evaluation mode.
This behavior is incorrect and does not affect versions prior to 23.2 and after 23.7.

## **Resolution**

Aspose.Slides for Java addressed this issue and released updated versions (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) with the fix.

If you are using one of the affected versions of Aspose.Slides for Java in your project, please switch to using the corrected version.

If you experience any licensing issues with Aspose.Slides for Java:

- Check the version you are using and ensure it's not affected by the bug described above.
- Refer to [Licensing](/slides/java/licensing/) for how to apply and validate a license.
- Contact [Aspose support](https://forum.aspose.com/c/slides/11) for further assistance.

## **Affected products and versions**

Please note that this bug only impacts Aspose.Slides for Java versions 23.2 through 23.7. **Other Aspose products and other versions of Aspose.Slides are not affected**.
