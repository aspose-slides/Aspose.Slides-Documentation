This **Developer Guide** shows how to do common presentation tasks in JavaScript with Aspose.Slides for Node.js via .NET. Every article contains runnable examples. Before you run them, set up a project as described in [Installation](/slides/nodejs-net/installation/).

- [**Create Presentation**](/slides/nodejs-net/create-presentation/) – create a presentation, add a text box and slides, set the slide size, and save the result as PPTX.
- [**Open Presentation**](/slides/nodejs-net/open-presentation/) – open a presentation from a file or a buffer, read its slide count, and save it in another format.
- [**PowerPoint to PDF**](/slides/nodejs-net/convert-powerpoint-to-pdf/) – convert a presentation to PDF, including PDF/A for archiving.
- [**Slide to Image**](/slides/nodejs-net/convert-slide/) – render slides as PNG images at a scale factor or at an exact size in pixels.
- [**Manage Text**](/slides/nodejs-net/manage-text/) – add a text box, then change its text, font size, and bold style.
