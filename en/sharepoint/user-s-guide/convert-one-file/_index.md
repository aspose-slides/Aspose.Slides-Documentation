To convert a presentation in a document library:

1. Open the menu of the PPT or PPTX file (its Edit Control Block) and select **Convert via Aspose.Slides**. On SharePoint 2007, the menu item is named **Convert with Aspose.Slides**.

   **Selecting Convert with Aspose.Slides in the menu of a document on SharePoint 2007**

   ![The menu of a document in a SharePoint 2007 document library, with the Convert with Aspose.Slides item](convert-one-file_1.png)

2. On the conversion page, select the output format under **Convert to**. If you wish, change the destination file name and the destination folder.
3. Click **Convert**.
4. When the conversion is complete, click **Source Library** or **Destination Library** to return to a document library. The converted file is in the destination folder.

The same steps, with screenshots of each page, are in [Converting Microsoft PowerPoint Documents into Other Formats](/slides/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
