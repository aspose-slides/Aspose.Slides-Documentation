{{% alert color="info" title="Note" %}}

SharePoint sites are meant for collaboration, communication and content storage in order to fulfill particular business needs. They enable a group of individuals to achieve a common goal by facilitating information sharing and communication. The information is most often available as a website and is accessed via a web browser.

{{% /alert %}}

## **What is SharePoint and Aspose.Slides?**

Aspose.Slides for SharePoint is a solution for converting Microsoft PowerPoint presentations (PPT and PPTX) to other formats: PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX and POTM. It allows you to convert PowerPoint files in a SharePoint site without using Microsoft PowerPoint. The full list of formats is in [Supported File Formats](/slides/sharepoint/supported-file-formats/).
