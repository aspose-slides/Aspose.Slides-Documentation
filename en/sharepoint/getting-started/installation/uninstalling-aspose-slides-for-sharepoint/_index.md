To uninstall Aspose.Slides for SharePoint:

1. Run the setup program that you used to install it, for example *Setup2019.exe* on SharePoint Server 2019.
   When it finds the same version installed, the setup program offers to repair or remove it. When it finds a different version, it offers to upgrade or remove it.
2. Select **Remove** and click **Next** to uninstall Aspose.Slides for SharePoint.
