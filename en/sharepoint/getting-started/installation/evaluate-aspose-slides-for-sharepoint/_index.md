{{% alert color="info" title="Note" %}}

Take advantage of the free Aspose.Slides for SharePoint evaluation: it has no time limit and comes with free technical support. We encourage you to evaluate the product before buying, so that you know it does what you need.

{{% /alert %}}

The evaluation and the paid version of Aspose.Slides for SharePoint are the same download. [Download Aspose.Slides for SharePoint](https://releases.aspose.com/slides/sharepoint/), [install it](/slides/sharepoint/installing-aspose-slides-for-sharepoint/), and it works in evaluation mode by default.

In evaluation mode, the converted document carries an evaluation watermark. When you have purchased a license, install the license solution over the installed evaluation copy, as described in [Installing Aspose.Slides for SharePoint License](/slides/sharepoint/installing-aspose-slides-for-sharepoint-license/), and Aspose.Slides for SharePoint works in licensed mode.
