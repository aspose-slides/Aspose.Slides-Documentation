Aspose.Slides for SharePoint is a farm solution for SharePoint 2007 to 2019 that converts PowerPoint presentations stored in document libraries on the server, without Microsoft PowerPoint and without writing code.

It converts PPT and PPTX files to PDF, TIFF, XPS, HTML, SWF and ODP, and to the PPS, PPSX, PPTM, PPSM, POTX and POTM PowerPoint formats, and saves the result in a document library.

## **Your first export**

Aspose.Slides for SharePoint is installed once on the farm and then used from any document library where it is activated:

1. Download the ZIP archive from the [download page](https://releases.aspose.com/slides/sharepoint/) and unpack it on a server in your SharePoint farm.
2. Run the setup program that matches your SharePoint version: *Setup2007.exe*, *Setup2010.exe*, *Setup2013.exe*, *Setup2016.exe* or *Setup2019.exe*. Use an account that can install and deploy SharePoint solutions. Accept the license agreement, select the site collections to activate the feature on, and let the setup deploy the solution. Each screen is described in [Installation](/slides/sharepoint/installing-aspose-slides-for-sharepoint/).
3. Open a document library in one of those site collections, open the menu of a PPT or PPTX file, and select **Convert via Aspose.Slides**. On SharePoint 2007, the menu item is named **Convert with Aspose.Slides**.
4. Under **Convert to**, select **PDF - Adobe Portable Document**. Change the destination file name and folder if you need to, and click **Convert**.
5. When the conversion is complete, click **Destination Library** to open the folder that holds the new PDF file.

Without a license, the converted file carries an evaluation watermark — see [Licensing](/slides/sharepoint/installing-aspose-slides-for-sharepoint-license/). For the same steps with screenshots, see [Converting Microsoft PowerPoint Documents into Other Formats](/slides/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
