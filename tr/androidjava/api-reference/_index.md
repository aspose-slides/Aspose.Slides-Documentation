{{% alert color="info" %}} 

Aspose.Slides for Android via Java, Microsoft PowerPoint® veya başka bir yazılım kullanmadan Android için Java uygulamalarının sunum belgelerini okumasını ve yazmasını sağlayan bir sınıf kitaplığıdır. Aspose.Slides for Android via Java, metin, şekiller, tablolar ve animasyonları yönetmenize; slaytlara ses ve video eklemenize; slaytları önizlemenize; ve slaytları SVG, PDF formatına ve daha fazlasına dışa aktarmanıza izin verir.

En son API Referansı şu adreste bulunabilir: [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/tr/androidjava/).
