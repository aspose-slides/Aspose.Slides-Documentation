Taşınabilir Belge Biçimi (https://en.wikipedia.org/wiki/PDF) Adobe Systems tarafından kuruluşlar arasında belge alışverişi için oluşturulan bir dosya biçimidir. Bu biçimin amacı, içeriği ve düzeni platformdan bağımsız olarak aynı tutmaktı. Aspose.Slides for Java, sunum dosyalarını PDF'ye dönüştürmenizi sağlar.

{{% /alert %}}

## **PDF, Aspose.Slides for Java'da**
Aspose.Slides for Java'ya yüklenebilen herhangi bir sunum, seçiminize bağlı olarak [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) veya [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) standardına uyan bir PDF'ye dönüştürülebilir. Aspose.Slides for Java sunumları PDF olarak dışa aktarır ve çoğu durumda, oluşturulan PDF, orijinal sunuma tam olarak benzer.

Aspose.Slides, PDF'ye dönüştürürken aşağıdaki sunum özelliklerini destekler:

- Resimler, metin kutuları ve diğer şekiller.
- Metin ve biçimlendirme.
- Paragraflar ve biçimlendirme.
- Köprüler.
- Üstbilgi ve altbilgi.
- Madde işaretleri.
- Tablolar.

Aspose.Slides for Java kullanarak sunumları doğrudan PDF'ye dışa aktarabilirsiniz: başka bir bileşene ihtiyacınız yoktur. Ayrıca, [PPT ve PPTX'i PDF'ye Dönüştür](/slides/tr/java/convert-powerpoint-to-pdf/) sayfasında açıklandığı gibi, PDF dışa aktarımını çeşitli seçeneklerle özelleştirebilirsiniz.
