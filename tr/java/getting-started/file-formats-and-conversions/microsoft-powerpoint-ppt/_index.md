{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint), farklı Microsoft PowerPoint sürümleri tarafından oluşturulabilen, okunabilen, değiştirilebilen ve yazılabilen bir sunum belge dosya formatıdır. Bu, Microsoft tarafından geliştirilen sunum belgeleri için ikili bir formattır.

{{% /alert %}} 

## **Aspose.Slides for Java'da PPT**
Aspose.Slides for Java, aşağıda listelenen yazılımlar tarafından oluşturulan PPT dosyalarını okuyabilir.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Benzer şekilde, Aspose.Slides for Java tarafından oluşturulan PPT dosyaları yukarıdaki yazılımlar tarafından okunabilir.

## **PPT için Kapsamlı Destek**
Aspose.Slides for Java, PPT belge dosya formatı tarafından desteklenen neredeyse tüm özellikleri destekler. Bu sadece farklı Microsoft PowerPoint sürümleri tarafından sağlanan temel ve gelişmiş özellikleri kapsamakla kalmaz, aynı zamanda Microsoft PowerPoint tarafından bile desteklenmeyen özellikleri de içerir. Aspose.Slides for Java API kitaplığını kullanmanın temel avantajı, bu özelliklerin kolayca işlenebilmesidir.

PPT belge dosyalarını oluşturma, okuma ve yazma ile ilgili temel görevlerin yanı sıra Aspose.Slides for Java tarafından sağlanan çeşitli özellikler şunlardır:

- Diğer Microsoft Office dosya formatlarını [OLE objects into PPT documents]().
- [Export PPT documents to PDF](/slides/tr/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- PPT belgelerindeki slaytları SVG formatlarına dışa aktar.
- Slaytları Java Çerçevesi tarafından desteklenen herhangi bir görüntü formatına render et.
- PPT belgelerindeki slayt boyutlarını ayarla.
- Şekillerdeki animasyonları yönet.
- Slayt gösterilerini yönet.
- [Format text on slides]().
- PPT belgelerinden metin çıkar.
- [Handle tables on slides]().
- [the cloning feature]() kullanarak otomatik olarak masterları kopyala.
