{{% alert color="info" title="Note" %}}

Bu, mevcut bağlantılar için tutulan tarihsel bir sayfadır. Aspose.Slides for Java'nın mevcut sürümünü açıklamaz. Aspose.Slides for Java'nın yüklediği, içe aktardığı, kaydettiği ve işlediği formatlar ve her birinin API'si için [Supported File Formats](/slides/tr/java/supported-file-formats/) sayfasına bakın. PPT ile PPTX'i karşılaştırmak için [Understanding the Difference: PPT vs PPTX](/slides/tr/java/ppt-vs-pptx/) sayfasına bakın.

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) farklı Microsoft PowerPoint sürümleri tarafından oluşturulabilen, okunabilen, değiştirilebilen ve yazılabilen sunum belge dosya formatıdır. Bu, Microsoft tarafından geliştirilen sunum belgeleri için ikili (binary) formattır.

{{% /alert %}}

## **PPT Aspose.Slides for Java'da**
Aspose.Slides for Java, aşağıda listelenen yazılımlar tarafından oluşturulan PPT dosyalarını okuyabilir.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Benzer şekilde, Aspose.Slides for Java tarafından oluşturulan PPT dosyaları, yukarıdaki yazılımlar tarafından okunabilir.

## **PPT için Kapsamlı Destek**
Aspose.Slides for Java, PPT belge dosya formatı tarafından desteklenen neredeyse tüm özelliklere destek sağlar. Bu, sadece farklı Microsoft PowerPoint sürümleri tarafından sağlanan temel ve gelişmiş PPT belge manipülasyon özelliklerini kapsamakla kalmaz, aynı zamanda Microsoft PowerPoint tarafından bile desteklenmeyen özellikleri de içerir. Aspose.Slides for Java API kütüphanesini kullanmanın temel avantajı, bu tür özelliklerin kolayca işlenebilmesidir.

- Diğer Microsoft Office dosya formatlarını [OLE nesneleri olarak PPT belgelerine](/slides/tr/java/manage-ole/) içe aktar.
- [PPT belgelerini PDF'ye dışa aktar](/slides/tr/java/convert-powerpoint-to-pdf/).
- PPT belgelerindeki slaytları SVG formatlarına dışa aktar.
- Slaytları Java Çerçevesi tarafından desteklenen herhangi bir görüntü formatına render et.
- PPT belgelerindeki slaytların boyutunu ayarla.
- Şekillerdeki animasyonları yönet.
- Slayt gösterilerini yönet.
- [Slaytlardaki metni biçimlendir](/slides/tr/java/text-formatting/).
- PPT belgelerinden metin çıkar.
- [Slaytlardaki tabloları işle](/slides/tr/java/powerpoint-table/).
- [klonlama özelliğini](/slides/tr/java/clone-slides/) kullanarak otomatik olarak masterları kopyala.
