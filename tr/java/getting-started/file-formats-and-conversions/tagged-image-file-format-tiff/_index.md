## **TIFF Hakkında**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) bir belgede birden çok görüntüyü depolamasıyla bilinen format, aslında Aldus tarafından oluşturulmuştur. Bu format tarama, faks ve diğer görüntü işleme uygulamaları tarafından geniş çapta desteklenir.

## **Aspose.Slides for Java'da TIFF**

Aspose.Slides for Java'da yüklenebilen herhangi bir belge, üçüncü taraf bileşen gerektirmeden doğrudan Aspose.Slides for Java tarafından TIFF belgesine dönüştürülebilir. Ayrıca, ortaya çıkan TIFF belgesindeki görüntülerin boyutlarını isteğe bağlı olarak tanımlayabilirsiniz. Aspose.Slides for Java aracılığıyla sunum belgelerini TIFF belgelerine dışa aktarma hakkında bilgi için [PowerPoint Sunumlarını TIFF'e Dönüştür](/slides/tr/java/convert-powerpoint-to-tiff/).
