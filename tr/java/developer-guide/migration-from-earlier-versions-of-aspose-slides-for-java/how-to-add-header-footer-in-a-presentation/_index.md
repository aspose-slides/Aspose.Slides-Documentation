Yeni bir [Aspose.Slides for Java API](https://docs.aspose.com/slides/tr/java/) yayınlandı ve artık bu tek ürün, PowerPoint belgelerini sıfırdan oluşturma ve mevcut belgeleri düzenleme yeteneğini destekliyor.
{{% /alert %}} 
## **Eski Kod Desteği**
Aspose.Slides for Java 13.x öncesi sürümleriyle geliştirilen eski kodu kullanmak için kodunuzda bazı küçük değişiklikler yapmanız gerekir ve kod eski gibi çalışacaktır. Eski Aspose.Slides for Java altında Aspose.Slide ve Aspose.Slides.Pptx ad alanlarında bulunan tüm sınıflar artık tek bir Aspose.Slides ad alanında birleştirildi. Lütfen eski Aspose.Slides API'sinde sunuma üst bilgi ve alt bilgi eklemek için aşağıdaki basit kod parçacığına bir göz atın ve yeni birleştirilmiş API'ye nasıl geçileceğini açıklayan adımları izleyin.
