## **Eski Kod Desteği**
Aspose.Slides for Java 13.x öncesi sürümlerle geliştirilen eski kodu kullanmak için kodunuzda bazı küçük değişiklikler yapmanız gerekir ve kod önceki gibi çalışacaktır. Eski Aspose.Slides for Java içinde Aspose.Slide ve Aspose.Slides.Pptx ad alanları altında bulunan tüm sınıflar artık tek bir Aspose.Slides ad alanında birleştirildi. Lütfen aşağıdaki basit kod örneğine bakın; bu örnek, eski Aspose.Slides API'sinde Hello World sunum belgesi oluşturmayı gösterir ve yeni birleştirilmiş API'ye nasıl geçileceğini anlatan adımları izleyin.
