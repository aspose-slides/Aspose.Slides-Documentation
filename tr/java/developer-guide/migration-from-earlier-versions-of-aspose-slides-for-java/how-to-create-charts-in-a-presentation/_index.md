Yeni bir [Aspose.Slides for Java API](https://docs.aspose.com/slides/tr/java/) yayınlandı ve artık bu tek ürün, sıfırdan PowerPoint belgeleri oluşturma ve mevcut belgeleri düzenleme yeteneğini destekliyor.

{{% /alert %}} 
## **Eski Kod Desteği**
Aspose.Slides for Java 14.x.x öncesi sürümlerle geliştirilen eski kodu kullanmak için kodunuzda birkaç küçük değişiklik yapmanız gerekir ve kod önceki gibi çalışacaktır. Eski Aspose.Slides for Java’da com.aspose.slides ve com.aspose.slides.pptx ad alanlarında bulunan tüm sınıflar artık tek bir com.aspose.slides ad alanında birleştirildi. Lütfen eski Aspose.Slides API kullanarak sunumda sıfırdan normal bir grafik oluşturmak için aşağıdaki basit kod örneğine göz atın ve yeni birleştirilmiş API'ye nasıl geçileceğini anlatan adımları izleyin.
