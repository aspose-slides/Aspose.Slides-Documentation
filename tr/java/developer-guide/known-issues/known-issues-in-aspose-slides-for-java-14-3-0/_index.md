{{% alert color="info" title="Note" %}}

Bu, tarihsel bir sayfadır. Aspose.Slides for Java 14.3.0 ile yayınlanan bilinen sorunları listeler ve mevcut sürümü açıklamaz. Her sürümdeki değişiklikler için [sürüm notlarına](https://releases.aspose.com/slides/tr/java/release-notes/) bakın.

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) PPT işleme için tamamen yeni bir uygulama sağlar. Birçok iyileştirme bulunmaktadır, PPTX'ten PPT'ye kısmi dönüşüm. Ancak bazı uygulanmamış özellikler vardır:

- Bazı şekiller, serileştirilmiş PPT belgelerinde hatalı geometriye sahiptir (Call outs)
- Tüm PPTX metin biçimlendirme özellikleri PPT serileştirmesinde desteklenmez
- Metin dili ve yazım denetimi ayarlarıyla ilgili bilgi serileştirilmiş PPT belgelerinde bulunmaz
- Tüm PPTX tema özellikleri PPT serileştirmesinde desteklenmez

**Aspose.Slides for Java 8.6.0 ile karşılaştırıldığında bazı farklılıklar vardır:**

- OLE/ActiveX PPT'den PPT serileştirmesinde bilinen sorunlar vardır

**Aspose.Slides for .NET 14.3.0 ile karşılaştırıldığında bazı farklılıklar vardır:**

- Sunum yazdırma desteği şu anda Aspose.Slides for Java’da mevcut değil.
