{{% alert color="info" title="Not" %}}

Bu bir tarihsel sayfadır. Aspose.Slides for Java 14.4.0 ile yayınlanan kısıtlamaları ve bilinen sorunları listeler ve mevcut sürümü açıklamaz. Her sürümdeki değişiklikler için [sürüm notları](https://releases.aspose.com/slides/tr/java/release-notes/) bölümüne bakın.

{{% /alert %}}

Aspose.Slides for Java 14.4.0, PowerPoint belgeleri işleme için yeni kararlar sunar. Gelecek sürümlerde kaldırılacak bazı kısıtlamalar ve bilinen sorunlar vardır:

- Bazı şekiller serileştirilmiş PPT belgelerinde yanlış geometriye sahiptir (yay, dairesel ok, açıklama balonları).
- PPT serileştirmesinde tüm PPTX metin biçimlendirme özellikleri desteklenmez (sekme, girinti ve paragraf biçimlendirme sınırlamaları).
- Metin dili ve yazım denetimi ayarları hakkında bilgi serileştirilmiş PPT belgelerinde bulunmaz.
- PPT serileştirmesinde tüm PPTX tema özellikleri desteklenmez (yalnızca dolgu formatları, çizgi formatları ve yazı tipi serileştirilir).
- PPT'ye OLE/ActiveX PPT serileştirmesinde bilinen sorunlar vardır.
- WordArt serileştirme ve rendering desteklenmez.
