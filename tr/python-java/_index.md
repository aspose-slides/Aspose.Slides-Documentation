**Aspose.Slides for Python via Java'e Hoş Geldiniz**

![Aspose.Slides for Python via Java Ürün Logosu](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java, Python uygulamalarınızın Microsoft PowerPoint® gerektirmeden PowerPoint® sunumlarını okumasını ve yazmasını sağlayan bir sınıf kitaplığıdır.

Ana özellikleri metin, şekil, tablo ve animasyonların yönetilmesi; slaytlara ses ve video eklenmesi; slaytların ön izlenmesi; ve slaytların SVG, PDF ve diğer formatlara dışa aktarılmasıdır.

{{% /alert %}}
