## **Desteklenen Platformlar**
Aspose.Slides for Node.js via Java, platform bağımsız bir API'dir. Node.js 7 veya üzeri yüklü olduğu sürece herhangi bir platformda (Windows, Linux, macOS vb.) kullanılabilir. Oracle JDK 8 veya üzeri bir diğer gereksinimdir.

## **Dosya Formatları ve Dönüştürmeler**
Aspose.Slides for Node.js via Java, çoğu PowerPoint belge formatını destekler. Ayrıca bunları, kuruluşların kullandığı ve paylaştığı popüler dosya formatlarına dışa aktarmanıza olanak tanır. Aşağıdaki detaylara göz atın:

|**Özellik**|**Açıklama**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java, bu sunum belge formatı için en hızlı işleme sağlar.|
|PPT'den PPTX'e dönüşüm|Aspose.Slides for Node.js via Java, PPT'den PPTX'e dönüşümü destekler.|
|Portable Document Format (PDF)|Desteklenen tüm dosya formatlarını tek bir yöntemle Adobe Portable Document Format (PDF) belgelerine dışa aktarabilirsiniz.|
|XML Parser Specification (XPS)|Desteklenen tüm dosya formatlarını tek bir yöntemle XML Parser Specification (XPS) belgelerine dışa aktarabilirsiniz.|
|Tagged Image File Format (TIFF)|Desteklenen tüm sunum dosya formatlarını Tagged Image File Format (TIFF) formatına dışa aktarabilirsiniz.|
|PPTX'den HTML Dönüştürme|Aspose.Slides for Node.js via Java, PresentationEx'in HTML formatına dönüştürülmesini destekler.|

| :- | :- |

## **FAQ**

### Kütüphanenin çalışması için sunucu/PC'de Microsoft PowerPoint yüklü olması gerekiyor mu?
Hayır. PowerPoint gerekli değildir; Aspose.Slides, sunum oluşturma, düzenleme, dönüştürme ve renderleme için bağımsız bir motorudur.

### Çoklu iş parçacığı (multithreading) nasıl çalışır? İşleme paralelleştirilebilir mi?
Farklı belgeleri farklı iş parçacıklarında işlemek güvenlidir; aynı [presentation](https://reference.aspose.com/slides/tr/nodejs-java/aspose.slides/presentation/) nesnesi, aynı anda [multiple threads](/slides/tr/nodejs-java/multithreading/) tarafından kullanılmamalıdır.

### Dosya şifreleri ve şifreleme destekleniyor mu?
Evet. [You can](/slides/tr/nodejs-java/password-protected-presentation/) şifrelenmiş sunumları açabilir, açma ve yazma şifresi ayarlayabilir veya kaldırabilir ve koruma durumunu kontrol edebilirsiniz.

### Linux konteynerlerinde font paketlerine dikkat etmem gerekiyor mu?
Evet. Beklenmeyen font değişimlerini önlemek için uygulamanıza yaygın font paketlerini kurmanız ve/veya açıkça [specify font directories](/slides/tr/nodejs-java/custom-font/) belirtmeniz önerilir.

### Değerlendirme sürümünde sınırlamalar var mı?
İn [evaluation mode](/slides/tr/nodejs-java/licensing/) çıktıya bir filigran eklenir ve belirli sınırlamalar uygulanır; tam özellik testi için bir [30-day temporary license](https://purchase.aspose.com/temporary-license/) mevcuttur.

### Sunuma harici formatların (PDF/HTML → PPTX) içe aktarılması destekleniyor mu?
Evet. Sunuma [PDF pages and HTML content](/slides/tr/nodejs-java/import-presentation/) ekleyebilir, bunları slaytlara dönüştürebilirsiniz.
