## **Desteklenen Platformlar**
Aspose.Slides for PHP via Java, platform bağımsız bir API'dir. PHP 7 veya üzeri yüklü olduğu herhangi bir platformda (Windows, Linux, MacOS vb.) kullanılabilir. Oracle JDK 7 veya üzeri başka bir gerekliliktir.

## **Dosya Biçimleri ve Dönüşümler**
Aspose.Slides for PHP via Java, çoğu PowerPoint belge formatını destekler. Ayrıca, bunları kuruluşların birbirleriyle kullandığı ve paylaştığı popüler dosya biçimlerine dışa aktarmanıza olanak tanır. Aşağıdaki ayrıntılara göz atın:

|**Özellik**|**Açıklama**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java, bu sunum belgesi formatı için en hızlı işleme sağlar.|
|PPT'den PPTX'e dönüşüm|Aspose.Slides for PHP via Java, PPT'den PPTX'e dönüşümü destekler.|
|Taşınabilir Belge Biçimi (PDF)|Tek bir yöntemle tüm desteklenen dosya biçimlerini Adobe Portable Document Format (PDF) belgelerine dışa aktarabilirsiniz.|
|XML Parser Specification (XPS)|Tek bir yöntemle tüm desteklenen dosya biçimlerini XML Parser Specification (XPS) belgelerine dışa aktarabilirsiniz.|
|Etiketli Görüntü Dosyası Biçimi (TIFF)|Tüm desteklenen sunum dosya biçimlerini Tagged Image File Format (TIFF) formatına dışa aktarabilirsiniz.|
|PPTX'ten HTML Dönüşümü|Aspose.Slides for PHP via Java, PresentationEx'in HTML biçimine dönüştürülmesini destekler.|

## **Sunum Renderleme**
Aspose.Slides for PHP via Java, sunumdaki slaytların yüksek doğrulukta farklı grafik biçimlerine render edilmesini destekler. Aşağıdaki ayrıntılara göz atın:

|**Özellik**|**Açıklama**|
| :- | :- |
|Java Destekli Görüntü Biçimleri|Aspose.Slides for PHP via Java kullanarak, slaytları ve slaytlardaki görüntüleri TIFF, PNG, BMP, JPEG, GIF gibi tüm Java destekli grafik biçimlerine render edebilirsiniz.|
|SVG Biçimi|Aspose.Slides for PHP via Java ayrıca sunum slaytlarını Scalable Vector Graphics (SVG) biçimlerine dışa aktarmanıza olanak tanıyan yerleşik yöntemler sağlar.|

## **SSS**

### Kitaplığın çalışması için sunucu/PC'ye Microsoft PowerPoint kurmam gerekiyor mu?

Hayır. PowerPoint gerekli değildir; Aspose.Slides, sunumları oluşturmak, düzenlemek, dönüştürmek ve render etmek için bağımsız bir motor sağlar.

### Çoklu iş parçacığı nasıl çalışır? İşlem paralelleştirilebilir mi?

Farklı belgeleri farklı iş parçacıklarında işlemek güvenlidir; aynı [presentation](https://reference.aspose.com/slides/tr/php-java/aspose.slides/presentation/) nesnesi [multiple threads](/slides/tr/php-java/multithreading/) tarafından aynı anda kullanılmamalıdır.

### Dosya şifreleri ve şifreleme destekleniyor mu?

Evet. [Şifreli sunumları açabilirsiniz](/slides/tr/php-java/password-protected-presentation/) şifreli sunumları açabilir, açma ve yazma şifresi ayarlayabilir veya kaldırabilir ve koruma durumunu kontrol edebilirsiniz.

### Linux konteynerlerinde font paketlerine dikkat etmem gerekiyor mu?

Evet. Ortak font paketlerini kurmanız ve/veya uygulamanızda font dizinlerini açıkça [font dizinlerini belirtin](/slides/tr/php-java/custom-font/) önerilir, böylece beklenmeyen yerine koymaların önüne geçilir.

### Değerlendirme sürümünde sınırlamalar var mı?

Değerlendirme modunda ([evaluation mode](/slides/tr/php-java/licensing/)), çıktıya bir filigran eklenir ve bazı sınırlamalar uygulanır; tam özellikli test için bir [30-day temporary license](https://purchase.aspose.com/temporary-license/) mevcuttur.

### Harici formatları bir sunuma (PDF/HTML → PPTX) içe aktarmak destekleniyor mu?

Evet. [PDF sayfalarını ve HTML içeriğini](/slides/tr/php-java/import-presentation/) sunuma ekleyebilir, bunları slaytlara dönüştürebilirsiniz.
