## **Desteklenen Platformlar**
Aspose.Slides for Node.js via .NET, platform bağımsız bir API'dir. Node.js 7 veya daha yüksek bir sürümün yüklü olduğu herhangi bir platformda (Windows, Linux, macOS, vb.) kullanılabilir. Oracle JDK 8 veya daha yüksek bir sürüm de başka bir gereksinimdir.

## **Dosya Biçimleri ve Dönüştürmeler**
Aspose.Slides for Node.js via .NET, çoğu PowerPoint belge biçimini destekler. Ayrıca bunları organizasyonların kullandığı ve paylaştığı popüler dosya biçimlerine dışa aktarabilirsiniz. Aşağıdaki detaylara göz atın:

|**Özellik**|**Açıklama**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET, bu sunum belge formatı için en hızlı işleme sağlar.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET, PPT'den PPTX'e dönüşümünü destekler.|
|Portable Document Format (PDF)|Desteklenen tüm dosya biçimlerini tek bir yöntemle Adobe Portable Document Format (PDF) belgelerine dışa aktarabilirsiniz.|
|XML Parser Specification (XPS)|Desteklenen tüm dosya biçimlerini tek bir yöntemle XML Parser Specification (XPS) belgelerine dışa aktarabilirsiniz.|
|Tagged Image File Format (TIFF)|Desteklenen tüm sunum dosya biçimlerini Tagged Image File Format (TIFF) formatına dışa aktarabilirsiniz.|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET, PresentationEx'in HTML formatına dönüştürülmesini destekler.|

## **Sunum Renderleme**
Aspose.Slides for Node.js via .NET, sunumdaki slaytların yüksek doğrulukta farklı grafik biçimlerine render edilmesini destekler. Aşağıdaki detaylara göz atın:

|**Özellik**|**Açıklama**|
| :- | :- |
|.NET Supported Image Formats|Aspose.Slides for Node.js via .NET kullanarak, sunum slaytlarını ve slaytlardaki görüntüleri TIFF, PNG, BMP, JPEG, GIF gibi .NET destekli tüm grafik biçimlerine render edebilirsiniz.|
|SVG Format|Aspose.Slides for Node.js via .NET ayrıca, sunum slaytlarını Scalable Vector Graphics (SVG) biçimlerine dışa aktarmanızı sağlayan yerleşik yöntemler sunar.|

## **İçerik Özellikleri**
Aspose.Slides for Node.js via .NET, sunum belgelerinin neredeyse tüm öğelerine veya içeriklerine erişmenizi, değiştirmenizi veya oluşturmanızı sağlar. Aşağıdaki detaylara göz atın:

|**Özellik**|**Açıklama**|
| :- | :- |
|Master Slides|Master Slides, normal slaytların düzenini tanımlar. Aspose.Slides for Node.js via .NET, sunum belgelerinin Master Slides'ına erişmenizi ve bunları değiştirmenizi sağlar.|
|Normal Slides|Aspose.Slides for Node.js via .NET ile, farklı tipte yeni slaytlar oluşturabilirsiniz; ayrıca mevcut slaytlara erişebilir ve onları değiştirebilirsiniz.|
|Cloning / Copying Slides|Aspose.Slides for Node.js via .NET tarafından sunulan yerleşik yöntemler, bir sunum içinde mevcut slaytları klonlamanıza veya kopyalamanıza olanak tanır. Kopyalanan ve klonlanan slaytları bir sunumdan diğerine de kullanabilirsiniz. Bir slayt, düzenini master slayttan devraldığından, yerleşik klonlama yöntemleri klonlama sırasında master'ı otomatik olarak kopyalar.|
|Managing Slides sections|Sunum içinde slaytları farklı bölümlerde düzenlemek için yöntemler.|
|Place Holders and Text Holders|Bir slayttaki yer tutuculara ve metin tutucularına erişebilirsiniz. Ayrıca, uygun yöntemi kullanarak sıfırdan metin tutucularına sahip bir slayt oluşturabilirsiniz.|
|Header and Footers|Aspose.Slides for Node.js via .NET, slaytlardaki üstbilgi/altbilgilerin yönetimini kolaylaştırır.|
|Notes in Slides|Aspose.Slides for Node.js via .NET ile, bir slaytla ilişkilendirilmiş notlara erişebilir ve bunları değiştirebilir, ayrıca yeni notlar ekleyebilirsiniz.|
|Finding a Shape|Bir slayttaki belirli bir şekli, şekille ilişkili alternatif metni kullanarak bulabilirsiniz.|
|Backgrounds|Aspose.Slides for Node.js via .NET, bir sunumdaki master veya normal slaytla ilişkili arka planlarla çalışmanıza olanak tanır.|
|Text Boxes|Metin kutuları sıfırdan oluşturulabilir. Mevcut metin kutularına erişebilirsiniz. Ayrıca, metinleri orijinal biçimini kaybetmeden değiştirebilirsiniz.|
|Rectangle Shapes|Aspose.Slides for Node.js via .NET ile dikdörtgen şekiller oluşturabilir veya bunları değiştirebilirsiniz.|
|Poly Line Shapes|Aspose.Slides for Node.js via .NET ile çoklu çizgi şekilleri oluşturabilir veya değiştirebilirsiniz.|
|Ellipse Shapes|Aspose.Slides for Node.js via .NET ile elips şekilleri oluşturabilir veya değiştirebilirsiniz.|
|Group Shapes|Aspose.Slides for Node.js via .NET grup şekillerini destekler|
|Auto Shapes|Aspose.Slides for Node.js via .NET otomatik şekilleri destekler.|
|SmartArt|Aspose.Slides for Node.js via .NET, MS PowerPoint'teki SmartArt şekilleri için destek sağlar.|
|Charts|Aspose.Slides for Node.js via .NET, PowerPoint'teki MSO Grafikler için destek sağlar.|
|Shapes Serialization|Aspose.Slides for Node.js via .NET, çok sayıda şekli destekler. Aspose.Slides for Node.js via .NET bir şekli desteklemediğinde, mevcut bir slayttan o şekli serileştirebileceğiniz bir serileştirme yöntemi kullanabilirsiniz. Böylece, şekli gereksinimlerinize göre daha sonra da kullanabilirsiniz.|
|Picture Frames|Aspose.Slides for Node.js via .NET ile resimleri picture frame içinde yönetebilirsiniz.|
|Audio Frames|Aspose.Slides for Node.js via .NET ile slaytlardaki audio frame'lere ses dosyalarını bağlayabilir veya yerleştirebilirsiniz.|
|Video Frames|Video frame'lerdeki video dosyalarını yönetebilirsiniz. Aspose.Slides for Node.js via .NET ayrıca bağlanmış ve gömülü videolar için destek sağlar.|
|OLE Frame|Aspose.Slides for Node.js via .NET ile OLE frame'lerde OLE nesnelerini yönetebilirsiniz.|
|Tables|Aspose.Slides for Node.js via .NET, slaytlarda tabloları destekler.|
|ActiveX Controls|ActiveX denetimleri için destek|
|VBA Macros|Sunumlar içinde VBA makrolarını yönetmek için destek.|
|Text Frame|Herhangi bir şeklin metin çerçevesi aracılığıyla şeklin metnine erişebilirsiniz.|
|Text Scanning|Yerleşik tarama yöntemleriyle bir sunumda veya slayt seviyesinde metin taraması yapabilirsiniz.|
|Animations|Şekillere animasyon uygulayabilirsiniz.|
|Slide Shows|Aspose.Slides for Node.js via .NET, slayt gösterileri ve slayt geçişlerini destekler.|
