{{% alert color="info" title="Not" %}}

Aspose.Slides for SharePoint ile bir SharePoint belge kitaplığının içinden PowerPoint sunumlarını birçok popüler belge formatına dönüştürebilirsiniz.

{{% /alert %}}

## **Desteklenen Giriş Biçimleri**

Aspose.Slides for SharePoint aşağıdaki giriş biçimlerini dönüştürür:

- PPT – Microsoft PowerPoint Sunumu 97 - 2003
- PPTX – Office Open XML Sunumu

{{% alert color="info" title="Not" %}}

Belgeleri dönüştürmek için Aspose.Slides for SharePoint, yerleşik bir [Aspose.Slides for .NET](https://products.aspose.com/slides/tr/net/) sürümüne dayanır.

{{% /alert %}}

## **Desteklenen Çıktı Biçimleri**

Dönüşüm sayfasındaki **Convert to** listesi aşağıdaki çıktı biçimlerini bu sırayla sunar:

- PDF – Adobe Taşınabilir Belge
- TIFF – Resim Paketi
- XPS – XML Kağıt Spesifikasyonu
- PPS – Slayt Gösterisi Sunumu
- PPSX – Microsoft PowerPoint Open XML Slayt Gösterisi
- ODP – OpenDocument Sunumu
- PPTM – Microsoft PowerPoint Open XML Makro Etkin Sunum
- PPSM – Microsoft PowerPoint Open XML Makro Etkin Slayt Gösterisi
- POTX – Microsoft PowerPoint Şablonu
- POTM – PowerPoint Open XML Makro Etkin Sunum Şablonu
- PDFNotes – Sunum notları PDF formatında
- HTML – Sunum HTML formatında
- TIFFNotes – Sunum notları çok sayfalı TIFF görüntüsü olarak
- SWF – Shockwave Flash Film
- SWFNotes – Sunum notları çok sayfalı SWF olarak
