## **Purpose**
性能通常是选择组件时的首要关键因素。本文衡量了 Aspose.Slides for C++ 和 VSTO 2008 的性能。简单测试在相似的操作系统、硬件组件和配置下进行。

本文提供了包括 **Aspose.Slides for C++** 和 **VSTO 2008** 在内的产品性能测量。此处给出的性能估计旨在帮助您了解在相似配置、普通硬件上运行的广泛使用操作系统的常见场景中，不同组件的预期表现。自然，您的应用程序性能受数据、数据访问模式、缓存大小、其他配置参数、操作系统和硬件等因素影响。基准测试旨在展示组件在最低硬件条件下的表现，硬件越快，组件处理任务的速度也越快。

## **Testing Methodology**
所有性能测试均在通用硬件和操作系统组合上进行，未进行自定义配置、调优或其他性能提升技术。所有测试均在相同系统上运行组件安装，且系统在其他情况下保持空闲。为了获得准确的读数，我们一次性多次（两到三次）执行所有任务，以更好地评估组件并获取准确的结果。
