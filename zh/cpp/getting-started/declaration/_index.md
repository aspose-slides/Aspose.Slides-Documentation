{{% alert color="info" %}}

所有 Aspose C++ 组件都需要 Full Trust 权限集。原因是，Aspose C++ 组件需要访问注册表设置、虚拟目录以外的系统文件，以执行诸如解析字体等特定操作。此外，Aspose C++ 组件基于核心 C++ 系统类，在许多情况下也需要 Full Trust 权限集。

{{% /alert %}}
