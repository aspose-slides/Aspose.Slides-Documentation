## **欢迎使用 Aspose.Slides for C++！**

Aspose.Slides for C++ 是一个 Microsoft PowerPoint® 管理 API，能够让 C++ 应用程序在无需使用 Microsoft PowerPoint® 的情况下读取和写入 PowerPoint® 文档。Aspose.Slides for C++ 是首个也是唯一提供 PowerPoint® 文档管理功能的组件。Aspose.Slides for C++ 提供了众多关键功能，例如管理文本、形状、表格和动画、向幻灯片添加音频和视频、预览幻灯片、将幻灯片导出为 SVG、PDF 等格式。

## **产品描述**
Aspose.Slides for C++ 使用原生 C++ 开发。当前已为 Windows x64 环境编译，未来也将提供 Linux 环境的编译版本。

Aspose.Slides for C++ 不仅能够打开来自不同来源的 PowerPoint 文件，还可以以多种方式保存演示文稿。例如，您不仅可以将演示文稿保存为 PPT，还可以保存为 PDF 格式。此外，还可以将幻灯片保存为图像。Aspose.Slides for C++ 提供了几乎所有在 Microsoft PowerPoint 中可以找到的功能。其多样性体现在，您不仅可以向幻灯片添加表格和各种形状，还可以添加不同类型的帧（即文本、音频和视频帧）。

## **功能丰富**
功能可分为以下几个领域：

1. 演示文稿功能。
2. 幻灯片功能。
3. 图形和多媒体功能。
4. 表格功能
5. 文本和段落功能
6. 高级功能

### **演示文稿功能**
- 打开来自不同来源的 Microsoft PowerPoint 演示文稿。
- 以不同的 Microsoft PowerPoint 格式保存演示文稿。
- 从头创建演示文稿。
- 在不使用其他组件的情况下将演示文稿转换为 PDF 文档。
- 读取或修改演示文稿的文档属性。
- 对演示文稿应用保护。
- 将演示文稿导出为 PDF。
- 将演示文稿导出为 XPS。
- 将演示文稿导出为 SWF。
- 将演示文稿的备注导出为 PDF。
- 将演示文稿导出为 HTML。

### **幻灯片功能**
- 从头创建新幻灯片并将其添加到演示文稿中。
- 通过在演示文稿中的位置访问任意幻灯片。
- 将幻灯片复制或克隆到同一或其他演示文稿。
- 编辑和删除幻灯片。
- 自动连同幻灯片复制母版。
- 预览幻灯片。
- 获取或设置幻灯片名称。
- 将幻灯片保存为图像。
- 将幻灯片导出为 SVG 格式。
- 在演示文稿中使用多个母版。
- 使用任何支持的样式填充幻灯片背景。
- 添加或管理幻灯片备注。
- 动态设置新的幻灯片母版和样式。
- 添加或修改幻灯片放映切换效果。
- 添加 Morph 过渡效果

### **图形和多媒体功能**
- 创建或管理线条、矩形、椭圆和多段线等形状。
- 管理形状的线条样式。
- 获取形状的替代文本。
- 旋转或翻转形状。
- 以不同样式填充形状，例如实色、渐变、图案、纹理和图片。
- 使用 48 种预定义图案和 24 种纹理。
- 为形状分配链接。
- 读取、修改或添加新的动画效果到幻灯片和形状。
- 向演示文稿添加新图片或管理已有图片。
- 向演示文稿添加新图片项目符号或管理已有的。
- 向演示文稿添加新音频帧或管理已有的。
- 向演示文稿添加新视频帧或管理已有的。

### **表格功能**
- 从头创建表格并添加到幻灯片。
- 调整表格大小并移动。
- 访问表格中的任意单元格。
- 更改任意单元格的格式和边框。
- 调整列和行的大小。
- 添加和删除列和行。
- 设置整个表格的边框宽度和颜色。

### **文本和段落功能**
- 获取和设置文本占位符及文本框中的文字。
- 获取占位符的类型。
- 更改文本框中的文字格式。
- 添加新字体或管理演示文稿中已使用的字体。
- 更改文字及其格式。
- 创建或管理指向文本的链接。
- 支持制表符和有效制表符。
- 向几乎所有形状添加新的文本框。
- 访问并修改文本框的边距和文本换行设置。
- 访问并修改段落缩进。

### **高级功能**
- 访问嵌入在演示文稿中的 OLE 对象。
- 锁定演示文稿。

## **支持平台**
- Windows x64/x86（Microsoft Visual Studio 2017 或更高版本）。
- Linux（Clang 3.9 或更高版本，GCC 6.1 或更高版本）。
- macOS（Xcode 13.4 或更高版本）。

## **常见问题**

**它是否支持用于归档和无障碍的 PDF 合规级别（PDF/A 和 PDF/UA）？**
是的。通过配置[PDF 导出选项](https://reference.aspose.com/slides/zh/cpp/aspose.slides.export/pdfoptions/)，您可以将文档保存为 PDF/A-2a/2b/2u、PDF/A-3a/3b 以及 PDF/UA。

**是否提供字体替代机制并支持自定义字体以确保正确渲染？**
是的。库允许您[加载自定义字体](/slides/zh/cpp/custom-font/)并[定义回退规则](/slides/zh/cpp/fallback-font/)，从而在转换和渲染过程中可靠地替代缺失的字形。

**是否可以在不完整打开文件的情况下检测文件是否受密码保护？**
是的。您可以[检查演示文稿](/slides/zh/cpp/examine-presentation/)，在加载完整文档之前判断是否需要密码。

**处理和转换是否必须使用 Microsoft PowerPoint？**
不需要。Aspose.Slides 是独立的引擎，服务器或工作站上无需安装 PowerPoint。

**是否可以安全地在多个线程中处理演示文稿？**
是的，您可以在不同线程中并行处理不同文档，只需避免在多个线程中同时使用同一演示文稿实例即可[跨线程](/slides/zh/cpp/multithreading/)。

**宏是否会被保留，且我能在 PPTM/PPSM 文件中管理 VBA 吗？**
是的。支持包含宏的演示文稿[（详见）](/slides/zh/cpp/presentation-via-vba/)，您可以[检查和管理 VBA 项目](https://reference.aspose.com/slides/zh/cpp/aspose.slides.vba/)。

**是否可以将 PDF 或 HTML 转回 PowerPoint 幻灯片？**
是的。您可以[导入 PDF 页面或 HTML 内容](/slides/zh/cpp/import-presentation/)，在演示文稿中创建或填充幻灯片。

**是否支持 XPS 导出，且可以控制 XPS 输出的质量和内容吗？**
是的。提供[导出为 XPS](/slides/zh/cpp/convert-powerpoint-to-xps/)功能，且[保存选项](https://reference.aspose.com/slides/zh/cpp/aspose.slides.export/xpsoptions/)可让您调节输出质量和包含的内容。

**是否可以将幻灯片转换为图像并控制输出质量？**
是的。幻灯片可以[渲染为 PNG、JPEG、GIF、BMP、TIFF](/slides/zh/cpp/convert-powerpoint-to-png/)等格式，并对尺寸和质量进行细粒度控制。

**是否支持数学公式（MathML/MathText），并且可以导出？**
是的。您可以[创建和编辑数学文本](/slides/zh/cpp/powerpoint-math-equations/)并[导出公式](/slides/zh/cpp/exporting-math-equations/)，包括导出为 MathML。

**库如何处理加密和密码（打开、设置、移除）？**
[它支持](/slides/zh/cpp/password-protected-presentation/)打开加密的演示文稿，设置或移除打开和修改的密码，并检查文件的保护状态。
