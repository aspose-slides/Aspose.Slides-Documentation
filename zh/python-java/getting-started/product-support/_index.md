## **概述**

使用 Aspose.Slides 支持论坛提出问题、报告问题并请求功能，适用于 Aspose.Slides for Python via Java。本文说明在打开主题之前需要检查的内容以及哪些信息有助于支持团队复现问题。

## **技术支持**

{{% alert color="info" title="注意" %}}

Aspose 为所有用户（包括评估产品的用户）提供免费技术支持。有关详情，请参阅[免费支持政策](https://forum.aspose.com/t/free-support-policies/162313)。

{{% /alert %}}

在 [Aspose.Slides 支持论坛](https://forum.aspose.com/c/slides/zh/11) 中提交技术问题。请在报告中指定 **Aspose.Slides for Python via Java**，以便团队识别正确的产品和环境。

如需优先协助，请参阅 [付费支持帮助台](https://helpdesk.aspose.com/)。付费支持需要单独订阅，并不包含在产品许可证内。

## **报告问题前的准备**

1. 检查 [下载](https://releases.aspose.com/slides/zh/python-java/) 和 [发行说明](https://releases.aspose.com/slides/zh/python-java/release-notes/) 是否有可以解决此问题的更新版本。如有可能，请在测试环境中使用最新版本复现问题。  
2. 在支持论坛、[文档](/slides/zh/python-java/) 和 [API 参考](https://reference.aspose.com/slides/zh/python-java/) 中搜索已有答案。  
3. 对于安装或 JVM 启动问题，请查看 [安装指南](/slides/zh/python-java/installation/) 并确认 Python 与 Java 使用匹配的体系结构。  
4. 将问题简化到最小示例和输入演示文稿，以便仍能复现问题。

## **准备问题报告**

在论坛主题中包含以下信息：

- **环境：** Aspose.Slides for Python via Java 版本、Python 版本、Java 版本及供应商、JPype 版本、操作系统和体系结构。  
- **步骤和代码：** 最小可运行的 Python 示例，包括导入语句和 JVM 初始化代码，以及复现问题的步骤。  
- **输入文件：** 演示文稿及示例所需的任何相关文件。将多个文件压缩为 ZIP 包。  
- **预期和实际结果：** 描述差异并在有用时附上生成的输出或截图。对渲染问题，请指明受影响的幻灯片和字体。  
- **错误详情：** 完整的错误信息和堆栈跟踪（若出现异常）。  

每个问题使用一个主题。将同一问题的后续信息添加到已有主题，以便支持团队跟进调查。

## **常见问题解答**

**在评估 Aspose.Slides for Python via Java 时可以获得帮助吗？**

可以。免费技术支持在评估期间以及购买后都可以通过 Aspose.Slides 支持论坛获得。

**JVM 启动失败时应提供哪些信息？**

提供您的 Python、Java 和 JPype 版本、操作系统、Python 与 Java 的体系结构、JVM 初始化代码以及完整的错误信息。这些细节有助于支持团队复现您的环境。

**如何报告升级后出现的问题？**

说明上一个可正常工作的版本、首次出现问题的版本以及包含输入文件的最小示例。描述升级期间所做的其他环境更改。
