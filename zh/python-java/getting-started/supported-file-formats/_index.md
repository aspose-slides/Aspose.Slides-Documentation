## **概览**

Aspose.Slides for Python via Java 可读取和写入 PowerPoint 与 OpenDocument 演示文稿。它还可以将 PDF 和 HTML 内容导入到幻灯片中，并将演示文稿或单个幻灯片导出为文档、网页和图像格式。

下表区分了演示文稿加载、内容导入和幻灯片渲染。有关编辑和渲染功能的概览，请参阅[功能概览](/slides/zh/python-java/features-overview/)。

## **支持的 Microsoft PowerPoint 版本**

- Microsoft PowerPoint 97  
- Microsoft PowerPoint 2000  
- Microsoft PowerPoint XP  
- Microsoft PowerPoint 2003  
- Microsoft PowerPoint 2007  
- Microsoft PowerPoint 2010  
- Microsoft PowerPoint 2013  
- Microsoft PowerPoint 2016  
- Microsoft PowerPoint 2019  
- Microsoft PowerPoint for Mac  
- PowerPoint for Microsoft 365（原 Office 365）

## **导入和导出注意事项**

- **PDF 和 HTML 导入：** 使用[SlideCollection.addFromPdf](https://reference.aspose.com/slides/zh/python-java/aspose.slides/slidecollection/#addfrompdf)或[SlideCollection.addFromHtml](https://reference.aspose.com/slides/zh/python-java/aspose.slides/slidecollection/#addfromhtml)从源内容创建幻灯片并追加到演示文稿中。  
- **演示文稿输出：** [SaveFormat](https://reference.aspose.com/slides/zh/python-java/aspose.slides/saveformat/) 列出了可用的演示文稿保存格式，包括单独的 HTML 和 HTML5 导出选项。  
- **图像输出：** 将幻灯片导出为图像会生成该幻灯片的视觉表示。输入列未说明图像是否可以插入到演示文稿中。

## **常见问题**

**我可以将 PPT 演示文稿转换为 PPTX 或 ODP 吗？**

是的。PPT 受支持作为输入格式，PPTX 和 ODP 同时受支持作为输出格式。转换结果取决于目标格式所支持的功能。

**PDF 或 HTML 导入会将源文件打开为 PowerPoint 文件吗？**

不会。导入会从 PDF 页面或 HTML 内容创建幻灯片。随后您可以将生成的演示文稿保存为受支持的演示文稿格式。

**我能将导出的 PNG 或 SVG 加载为可编辑的演示文稿吗？**

不能。这些导出仅表示幻灯片的外观。当您需要后续编辑文本、形状、图表及其他对象时，请保留源演示文稿。
