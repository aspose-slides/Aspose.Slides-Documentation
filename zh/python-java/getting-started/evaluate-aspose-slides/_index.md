您可以下载 Aspose.Slides for Python via Java 来评估其功能。评估包与授权包完全相同。若要在无评估限制的情况下使用它，请在代码中添加几行以[应用许可证](/slides/zh/python-java/licensing/)。

Aspose.Slides 的评估版（未使用许可证）提供完整的产品功能，但有两个限制：

- 它会在每个保存的演示文稿的每张幻灯片上添加一个评估水印文本框。打开演示文稿不会添加水印，但保存已经带有水印的文件时会再添加一个。
- 代码读取的文本会被截断为前几个字符，并附加评估限制的提示。这适用于每张幻灯片，以及代码刚设置的文本和从文件加载的文本。代码写入的文本会完整保存。

若要在不受评估限制的情况下测试 Aspose.Slides，您可以请求一个**30 天临时许可证**。有关详细信息，请参阅[获取临时许可证](https://purchase.aspose.com/temporary-license)。
