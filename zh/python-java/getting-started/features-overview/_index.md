本文档介绍了 Aspose.Slides for Python via Java 的演示文稿处理功能。有关受支持的操作系统和依赖项，请参阅[系统要求](/slides/zh/python-java/system-requirements/)。

## **文件格式和转换**

Aspose.Slides for Python via Java 允许在演示文稿格式之间进行转换，并将演示文稿导出为文档和 Web 格式。完整的格式表以及加载演示文稿、导入内容和导出输出之间的区别，请参阅[受支持的文件格式](/slides/zh/python-java/supported-file-formats/)。

## **演示文稿渲染**

Aspose.Slides for Python via Java 提供高保真度的幻灯片渲染，可生成光栅或矢量图像用于预览和其他视觉输出。它还允许在幻灯片上渲染图像。有关可用的图像格式和导出说明，请参阅[受支持的文件格式](/slides/zh/python-java/supported-file-formats/#supported-file-formats)。

## **内容功能**

Aspose.Slides for Python via Java 允许您访问、修改和创建几乎所有类型的演示文稿内容，如下所述：

|**功能**|**描述**|
| :- | :- |
|演示文稿|您可以从头创建演示文稿或打开现有文件。|
|文档属性|您可以读取和修改文档属性。|
|演示文稿保护|您可以应用密码保护并管理演示文稿保护设置。|
|母版幻灯片|母版幻灯片定义普通幻灯片的布局。Aspose.Slides for Python via Java 允许您访问和修改演示文稿中的母版幻灯片。|
|普通幻灯片|您可以在演示文稿中添加、访问、编辑、重新排序和删除幻灯片。|
|幻灯片布局|您可以使用幻灯片布局。|
|克隆和复制幻灯片|内置方法允许您在同一演示文稿或不同演示文稿之间克隆或复制幻灯片。这些方法在克隆幻灯片时会自动复制关联的母版幻灯片。|
|幻灯片分节|您可以在演示文稿中将幻灯片组织为分节。|
|占位符和文本占位符|您可以访问幻灯片上的占位符和文本占位符，也可以从头创建带有文本占位符的幻灯片。|
|页眉和页脚|Aspose.Slides for Python via Java 让您管理页眉和页脚。|
|幻灯片备注|您可以访问、添加和修改幻灯片备注，并在导出为 PDF 或 TIFF 时包含它们。|
|查找形状|您可以使用形状的替代文本查找特定形状。|
|替代文本|您可以读取和更新形状的替代文本。|
|超链接|您可以读取和更新形状上的超链接，并向文本添加超链接。|
|背景|您可以处理演示文稿中母版幻灯片和普通幻灯片的背景。|
|文本框|您可以从头创建文本框，访问现有文本框，并在保持原始格式的同时修改其文本。|
|矩形形状|您可以创建和修改矩形形状。|
|线条形状|您可以创建和修改线条形状。|
|折线形状|您可以创建和修改折线形状。|
|椭圆形状|您可以创建和修改椭圆形状。|
|组合形状|Aspose.Slides for Python via Java 支持组合形状。|
|自动形状|Aspose.Slides for Python via Java 支持自动形状。|
|SmartArt|您可以在演示文稿中创建和编辑 SmartArt 形状。|
|图表|您可以在 PowerPoint 演示文稿中创建和编辑 Microsoft Office 图表。|
|形状序列化|Aspose.Slides for Python via Java 支持多种形状类型。对于不受支持的形状，您可以使用序列化来保存现有幻灯片中的形状以供重用。|
|形状锁定|您可以应用形状锁定以限制编辑操作。|
|图片框|您可以管理图片框中的图片。|
|音频框|您可以在幻灯片的音频框中链接或嵌入音频文件。|
|视频框|您可以管理视频框中的链接视频和嵌入视频。|
|OLE 框|您可以管理 OLE 框中的 OLE 对象。|
|表格|您可以创建、移动和调整表格大小；添加、删除和调整行列大小；以及读取和修改单元格内容、边框、填充和文本格式。|
|ActiveX 控件|Aspose.Slides for Python via Java 支持 ActiveX 控件。|
|VBA 宏|您可以管理演示文稿中的 VBA 宏。|
|文本框|您可以通过形状关联的文本框访问形状的文本，并调整文本框的边距和换行方式。|
|字体|您可以管理演示文稿中使用的字体。|
|文本扫描|内置方法允许您扫描整个演示文稿或单个幻灯片上的文本。|
|动画|您可以为形状添加和修改动画效果。|
|幻灯片放映|Aspose.Slides for Python via Java 支持幻灯片放映和幻灯片切换，包括 Morph 切换。|

## **格式化功能**

Aspose.Slides for Python via Java 让您对演示文稿幻灯片上的文本和形状进行格式化，如下所述：

|**功能**|**描述**|
| :- | :- |
|文本格式化|<p>您可以通过与形状关联的文本框管理文本，并对单独的段落和文本片段进行格式化。可用的格式化选项包括：</p><p>- 字体类型</p><p>- 字体大小</p><p>- 字体颜色</p><p>- 字体着色</p><p>- 段落对齐</p><p>- 段落缩进和制表位</p><p>- 段落项目符号</p><p>- 段落方向</p>|
|形状格式化|<p>形状是幻灯片的基本元素。您可以调整以下形状属性：</p><p>- 位置</p><p>- 大小</p><p>- 旋转</p><p>- 线条样式</p><p>- 填充（包括纯色、渐变、图案、纹理和图片填充）</p><p>- 文本</p><p>- 图像</p>|
