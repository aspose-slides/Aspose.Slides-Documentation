## **Aspose.Slides 评估**

您可以下载 Aspose.Slides 进行评估。评估包与已购买的包相同；在添加几行代码以应用许可证后，它会转为已授权。

未授权时，Aspose.Slides 在评估模式下提供完整功能，但有两项限制：它会在每个演示文稿保存的每张幻灯片上添加一个评估水印文本框，并且代码从演示文稿读取的文本会被截断为前几个字符，并附带评估限制的提示。代码写入的文本会完整保存。

如果想在没有评估版限制的情况下测试 Aspose.Slides，您可以申请 **30 天临时许可证**。请参阅[如何获取临时许可证？](https://purchase.aspose.com/temporary-license)了解更多信息。

{{% /alert %}}

## **FAQ**

### 我可以在评估模式下并行跨不同线程测试多个演示文稿吗？

可以。您可以并行处理不同的文档；不应在多个线程之间共享同一演示文稿对象[跨线程](/slides/zh/python-net/multithreading/)。评估模式不影响此行为。

### 在服务器或 CI 上评估库是否需要安装 Microsoft PowerPoint？

不需要。Aspose.Slides 是独立的引擎，无论是评估还是生产都不需要安装 PowerPoint。

### 我能在评估模式下完整测试 PPT/PPTX 转 PDF 和图像的转换吗？

可以。[转换器](/slides/zh/python-net/convert-presentation/)可以使用；输出将包含水印。

### 我可以使用临时许可证进行无水印的负载测试吗？

可以。30 天临时许可证消除评估模式限制，允许在没有水印的情况下进行测试。
