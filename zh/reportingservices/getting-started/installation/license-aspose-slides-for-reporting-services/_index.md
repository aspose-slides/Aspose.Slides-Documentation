## **许可证支持**

Aspose.Slides for Reporting Services 的评估版与已购买的版本包相同，可从[其下载页面](https://releases.aspose.com/slides/zh/reportingservices/)获取，并提供相同的功能。未授权时，它以评估模式运行，并在导出的演示文稿中插入评估水印。

当您将许可证文件复制到报表服务器后，评估版即转为正式授权。此过程不涉及任何代码。

当您对评估满意后，可[购买许可证](https://purchase.aspose.com/pricing/slides/zh/reporting-services/)。我们建议您了解不同的订阅类型。如有疑问，请联系 Aspose 销售团队。

## **Aspose.Slides for Reporting Services 中的授权**

* 许可证是一个纯文本 XML 文件，包含产品名称、授权的开发人员数量、订阅到期日期等信息。  
* 许可证文件已进行数字签名，禁止对其进行任何修改。即使不小心在文件内容中添加了额外的换行，也会导致其失效。

应用许可证的步骤：

1. 将许可证文件复制到每个报表服务器实例的 *ReportServer\bin* 文件夹（该文件夹中已安装 *Aspose.Slides.ReportingServices.dll*），例如 *C:\Program Files\Microsoft SQL Server Reporting Services\SSRS\ReportServer\bin*。[手动安装](/slides/zh/reportingservices/install-manually/#find-the-report-server-folder) 列出了默认文件夹。  
1. 确保文件名为扩展名查找的以下任意一个：*Aspose.Slides.ReportingServices.lic*、*Aspose.Slides.Reporting.Services.lic*、*Aspose.Slides.Product.Family.lic*、*Aspose.Total.ReportingServices.lic*、*Aspose.Total.Reporting.Services.lic*、*Aspose.Total.Product.Family.lic* 或 *Aspose.Total.lic*。  
1. 将任意报表导出为演示文稿。如果没有出现水印，则说明许可证已生效。

扩展名还会在 *%ProgramData%\Aspose\Slides*（通常为 *C:\ProgramData\Aspose\Slides*）查找许可证文件，因此在该位置放置一份即可为机器上的所有实例提供服务。

**已授权模式**

找到有效的许可证文件后，导出的演示文稿中不再有评估水印。

![已授权的报表导出：无评估水印](license-aspose-slides-for-reporting-services_2.png)

**评估模式**

未授权时，Aspose.Slides for Reporting Services 会在导出的演示文稿中插入评估水印。

![评估模式下的报表导出，带有评估水印](license-aspose-slides-for-reporting-services_1.png)
