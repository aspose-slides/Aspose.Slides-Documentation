Aspose.Slides for Reporting Services 是针对 Microsoft SQL Server Reporting Services 和 Power BI Report Server 的渲染扩展，它在分页 (RDL) 报表的导出列表中添加了演示文稿格式，无需在服务器上安装 Microsoft PowerPoint。

它将报表导出为 PPT、PPTX、PPS 和 PPSX 演示文稿和幻灯片放映，ODP，以及 XPS。

## **首次导出**

无需编写代码：在报表服务器上安装扩展后，其格式会出现在该服务器上每个分页报表的导出列表中。

1. 检查报表服务器是否满足[系统要求](/slides/zh/reportingservices/system-requirements/)，包括 .NET Framework 3.5。  
2. 从[下载页面](https://releases.aspose.com/slides/reportingservices/)下载 MSI 安装程序 *Aspose.Slides for Reporting Services*。如果想手动安装，请下载 ZIP 包 *Aspose.Slides for Reporting Services (DLLs Only)*。  
3. 在报表服务器上安装扩展：以管理员身份运行 MSI，具体步骤请参阅[使用 MSI 安装程序安装](/slides/zh/reportingservices/install-with-msi-installer/)，或根据[手动安装](/slides/zh/reportingservices/install-manually/)的说明使用 ZIP 包。  
4. 在浏览器中打开报表服务器的 Web 门户（SQL Server 2014 及更早版本为 Report Manager）。默认地址为 `https://<ComputerName>/reports`。  
5. 打开一个分页报表。在报表工具栏中打开**导出**列表并选择**PPTX - PowerPoint 2007 演示文稿 via Aspose.Slides**。如果工具栏有单独的**导出**按钮（如 Report Manager 所示），请选择该按钮。  
6. 打开或保存浏览器下载的 PPTX 文件。

如果没有许可证，导出的演示文稿会带有评估水印——请参阅[许可证](/slides/zh/reportingservices/license-aspose-slides-for-reporting-services/)。有关导出列表中其他格式的信息，请参阅[支持的文件格式](/slides/zh/reportingservices/supported-file-formats/)。
