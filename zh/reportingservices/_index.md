**欢迎使用 Aspose.Slides for Reporting Services**

Aspose.Slides for Reporting Services 是市场上唯一能够在 Microsoft SQL Server 2005、2008、2012、2016 和 2017 Reporting Services（32 位和 64 位）中生成真正的 PPT 和 PPS 报表的解决方案。所有 RDL 报表功能，包括表格、矩阵、图表和图像，都以最高精度转换为 Microsoft PowerPoint 演示文稿。
