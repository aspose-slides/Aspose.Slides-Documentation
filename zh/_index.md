## Aspose.Slides for .NET

{{% alert color="info" %}}

![Aspose.Slides for .NET 产品徽标](home_1.png)

Aspose.Slides for .NET 是一个 Microsoft PowerPoint® 管理 API，使 .NET 应用程序能够在不使用 Microsoft PowerPoint® 的情况下读取和写入 PowerPoint® 文档。Aspose.Slides for .NET 是首个也是唯一提供管理 PowerPoint® 文档功能的组件。Aspose.Slides for .NET 提供了许多关键特性，例如文本、形状、表格和动画的管理，向幻灯片添加音频和视频，幻灯片预览，将幻灯片导出为 SVG、PDF 等格式。
