## **概述**

本文说明了如何获取 Aspose.Slides 的支持以及如何有效报告问题。它介绍了主要的支持渠道，提供了提交问题的建议，并指向了有用的技术资源，如产品页面、博客、下载、支持论坛、文档和 API 参考。本文还回答了有关付费支持、问题升级以及旧版库支持的常见问题。

## **技术支持**
{{% alert color="info" %}}
Aspose 为所有产品提供无限制的免费技术支持。该支持对所有用户（包括使用评估版的用户）均可用。
{{% /alert %}} 

当您需要 Aspose.Slides for .NET 的帮助时，请考虑以下内容：

- 支持的主要渠道是 [Aspose.Forums](https://forum.aspose.com/c/slides/zh/11)。在 Aspose.Slides 论坛发布您的问题——通常会在几小时内得到答复。Aspose.Slides 支持团队会直接在论坛上回答问题。
- 请注意，Aspose 不提供电话技术支持。电话支持仅用于销售和购买问题。
- 在论坛期待回复时，请耐心并考虑时区差异。

当您在 Aspose.Slides for .NET 中遇到问题时，请遵循以下指南以最高效的方式解决：

- 在报告问题之前，请检查并确认您使用的是最新版的 Aspose.Slides for .NET。也许您遇到的问题已在更新中得到解决。

  请查看 Aspose.Slides 下载页面以获取最新版信息。

- 在报告问题之前，您可以先浏览我们的论坛、本文档和 API 参考。也许您的问题已有答案。

- 报告问题时，请附上原始文档，并（如果可能）附上与问题相关的代码片段。如需附加多个文件，请将它们压缩成 ZIP 包。

  您可以在 Aspose.Forums 中安全地附加文档，因为 **仅** 您和 Aspose 开发人员可以访问这些附件。

- 为特定问题创建并使用一个主题。如果您遇到另一个问题，需要创建另一个主题来报告。

## **常见问题**

### 有哪些付费支持层级，区别是什么？

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。它们在包含的事件次数、响应优先级和可用的沟通渠道上有所不同。

### 我可以直接将 bug 升级给工程团队吗？

可以。[付费支持](https://helpdesk.aspose.com/) 在问题需要深入调查时允许升级到开发人员。

### 是否支持旧版库，并为其提供修复？

您可以使用旧版本，但修复仅针对当前发布的版本提供；不会为旧版发布补丁。
