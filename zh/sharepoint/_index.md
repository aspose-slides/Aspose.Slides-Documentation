Aspose.Slides for SharePoint 是一个适用于 SharePoint 2007 到 2019 的场部署解决方案，可在服务器上将存储在文档库中的 PowerPoint 演示文稿进行转换，无需 Microsoft PowerPoint，也无需编写代码。

它可以将 PPT 和 PPTX 文件转换为 PDF、TIFF、XPS、HTML、SWF 和 ODP，以及 PPS、PPSX、PPTM、PPSM、POTX 和 POTM PowerPoint 格式，并将结果保存在文档库中。

## **您的首次导出**

Aspose.Slides for SharePoint 只需在场部署一次，即可在任何已激活的文档库中使用：

1. 从[下载页面](https://releases.aspose.com/slides/sharepoint/)下载 ZIP 压缩包，并在 SharePoint 场部署的服务器上解压。
2. 运行与您 SharePoint 版本相匹配的安装程序：*Setup2007.exe*、*Setup2010.exe*、*Setup2013.exe*、*Setup2016.exe* 或 *Setup2019.exe*。使用具有安装和部署 SharePoint 解决方案权限的账户。接受许可协议，选择要激活功能的站点集，并让安装程序部署解决方案。每个屏幕的说明请参见[安装](/slides/zh/sharepoint/installing-aspose-slides-for-sharepoint/)。
3. 在其中一个站点集的文档库中，打开 PPT 或 PPTX 文件的菜单，选择**通过 Aspose.Slides 转换**。在 SharePoint 2007 上，此菜单项名称为**使用 Aspose.Slides 转换**。
4. 在**转换为**下，选择**PDF - Adobe 可移植文档**。如有需要，可更改目标文件名和文件夹，然后点击**转换**。
5. 转换完成后，点击**目标库**以打开保存新 PDF 文件的文件夹。

如果没有许可证，转换后的文件会带有评估水印——请参阅[授权](/slides/zh/sharepoint/installing-aspose-slides-for-sharepoint-license/)。相同步骤的截图请参见[将 Microsoft PowerPoint 文档转换为其他格式](/slides/zh/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/)。
