{{% alert color="info" title="Note" %}}

使用 Aspose.Slides for SharePoint，您可以在 SharePoint 文档库中将 PowerPoint 演示文稿转换为多种流行的文档格式。

{{% /alert %}}

## **支持的输入格式**

Aspose.Slides for SharePoint 转换以下输入格式：

- PPT – Microsoft PowerPoint 演示文稿 97 - 2003
- PPTX – Office Open XML 演示文稿

{{% alert color="info" title="Note" %}}

要转换文档，Aspose.Slides for SharePoint 依赖于内置的 [Aspose.Slides for .NET](https://products.aspose.com/slides/zh/net/)。

{{% /alert %}}

## **支持的输出格式**

转换页面上的 **Convert to** 列表按以下顺序提供以下输出格式：

- PDF – Adobe 可移植文档
- TIFF – 图片包
- XPS – XML 纸张规范
- PPS – 幻灯片放映演示文稿
- PPSX – Microsoft PowerPoint Open XML 幻灯片放映
- ODP – OpenDocument 演示文稿
- PPTM – Microsoft PowerPoint Open XML 宏启用演示文稿
- PPSM – Microsoft PowerPoint Open XML 宏启用幻灯片放映
- POTX – Microsoft PowerPoint 模板
- POTM – PowerPoint Open XML 宏启用演示文稿模板
- PDFNotes – PDF 格式的演示文稿备注视图
- HTML – HTML 格式的演示文稿
- TIFFNotes – 多页 TIFF 图像的演示文稿备注视图
- SWF – Shockwave Flash 影片
- SWFNotes – 多页 SWF 的演示文稿备注视图
