要卸载 Aspose.Slides for SharePoint：

1. 运行用于安装它的设置程序，例如 *Setup2019.exe*（在 SharePoint Server 2019 上）。 当检测到已安装相同版本时，设置程序会提供修复或删除选项。 当检测到不同版本时，它会提供升级或删除选项。
2. 选择 **Remove** 并点击 **Next** 以卸载 Aspose.Slides for SharePoint。
