{{% alert color="info" title="Note" %}}
利用免费的 Aspose.Slides for SharePoint 试用版：它没有时间限制，并提供免费技术支持。我们鼓励您在购买之前评估此产品，以确保它满足您的需求。
{{% /alert %}}
Aspose.Slides for SharePoint 的试用版和付费版是同一个下载文件。[下载 Aspose.Slides for SharePoint](https://releases.aspose.com/slides/sharepoint/)，[安装它](/slides/zh/sharepoint/installing-aspose-slides-for-sharepoint/)，默认情况下它以试用模式运行。

在试用模式下，转换后的文档会带有试用水印。购买许可证后，请按照 [安装 Aspose.Slides for SharePoint 许可证](/slides/zh/sharepoint/installing-aspose-slides-for-sharepoint-license/) 的描述，将许可证方案安装到已安装的试用副本上，Aspose.Slides for SharePoint 将以授权模式运行。
