## **产品概述**

Aspose.Slides for SharePoint 在服务器上将存储在 SharePoint 文档库中的 PowerPoint 演示文稿转换为其他格式。

它支持转换以下 PowerPoint 格式：

- PPT – Microsoft PowerPoint 演示文稿 97 - 2003
- PPTX – Office Open XML 演示文稿

它可将上述格式转换为 PDF、TIFF、XPS、HTML、SWF、ODP、PPS、PPSX、PPTM、PPSM、POTX 和 POTM。详细信息请参阅[支持的文件格式](/slides/zh/sharepoint/supported-file-formats/)。

下载内容包含针对以下每个产品的独立安装程序和解决方案包：

- SharePoint 2007
- SharePoint 2010
- SharePoint Server 2013
- SharePoint Server 2016
- SharePoint Server 2019
