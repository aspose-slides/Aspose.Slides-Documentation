## **支持的 Microsoft PowerPoint 版本**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **支持的文件格式**

Aspose.Slides for SharePoint 将存储在 SharePoint 文档库中的 PPT 和 PPTX 演示文稿进行转换。其他类型的文件不予转换。

|**格式**|**描述**|**转换自**|**转换为**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|PowerPoint 97 - 2003 演示文稿|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|PowerPoint 2007 及更高版本演示文稿|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|便携式文档格式，包含幻灯片或备注视图| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|TIFF 图像，包含幻灯片或备注视图| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML 纸张规范| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|HTML 格式的演示文稿| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Shockwave Flash 影片，包含幻灯片或备注视图| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|OpenDocument 演示文稿| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|PowerPoint 幻灯片放映 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|PowerPoint 幻灯片放映 2007 及更高版本| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|PowerPoint 含宏的演示文稿| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|PowerPoint 含宏的幻灯片放映| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|PowerPoint 模板| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|PowerPoint 含宏的模板| |{{< emoticons/tick >}}|

在转换页面中，可在 **Convert to** 下选择输出格式；有关完整选项列表，请参阅 [Multiple Format Support](/slides/zh/sharepoint/multiple-format-support/)。
