SharePoint 站点旨在用于协作、沟通和内容存储，以满足特定的业务需求。它们通过促进信息共享和交流，使一组人员能够实现共同目标。信息通常以网站的形式存在，可通过网页浏览器访问。

{{% /alert %}}

## **SharePoint 和 Aspose.Slides 是什么？**

Aspose.Slides for SharePoint 是一种将 Microsoft PowerPoint 演示文稿（PPT 和 PPTX）转换为其他格式的解决方案：PDF、TIFF、XPS、HTML、SWF、ODP、PPS、PPSX、PPTM、PPSM、POTX 和 POTM。它允许您在 SharePoint 站点中转换 PowerPoint 文件，而无需使用 Microsoft PowerPoint。完整的格式列表请参阅 [Supported File Formats](/slides/zh/sharepoint/supported-file-formats/)。
