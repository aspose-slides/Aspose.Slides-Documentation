{{% alert color="info" title="Note" %}}

当 Aspose.Slides for SharePoint 在 SharePoint 服务器上安装并在站点集合中激活后，它会在文档库的文档菜单中添加 **Convert via Aspose.Slides** 项，如下所示。在 SharePoint 2007 中，该项名称为 **Convert with Aspose.Slides**。

**安装 Aspose.Slides for SharePoint 会在文档菜单中添加 Convert via Aspose.Slides 项**

![包含 Convert via Aspose.Slides 项的文档菜单](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **转换演示文稿**

要从 SharePoint 文档库转换 Microsoft PowerPoint 演示文稿（PPT 或 PPTX）：

1. 在文档库中选择一个 Microsoft PowerPoint 演示文稿。
2. 打开其菜单并单击 **Convert via Aspose.Slides**。

   **Presentation 2 文件的菜单，显示 Convert via Aspose.Slides 项**

   ![文档库中演示文稿的菜单，突出显示 Convert via Aspose.Slides 项](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. 在 **Convert to** 下选择输出格式。如有需要，修改输出文件名和目标文件夹。
4. 单击 **Convert** 以转换文件。

   **转换页面允许您选择输出格式、文件名和目标位置**

   ![包含输出格式、目标文件和目标文件夹的转换页面](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. 转换完成后，会显示成功消息。

   **转换成功**

   ![转换结果页面](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. 单击 **Source Library**（转到源文件夹）或 **Destination Library**（转到保存文件的文件夹）。

   转换后的文档会出现在文档库中。

   **显示在保存所在库中的转换文档**

   ![文档库中的转换文件](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

这些截图取自早期版本，当时仅提供 PDF、TIFF 和 XPS 格式。当前的转换页面提供更多输出格式；请参阅[Multiple Format Support](/slides/zh/sharepoint/multiple-format-support/)。

{{% /alert %}}

在 SharePoint 2010 及更高版本中，您还可以在库中选择一个或多个演示文稿，然后单击 **Aspose Tools** 功能区选项卡上的 **Convert Slides**。它会打开相同的转换页面。
