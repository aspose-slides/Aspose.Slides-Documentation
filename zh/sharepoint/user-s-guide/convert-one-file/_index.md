要在文档库中转换演示文稿：

1. 打开 PPT 或 PPTX 文件的菜单（编辑控制块），然后选择 **通过 Aspose.Slides 转换**。在 SharePoint 2007 上，此菜单项名为 **使用 Aspose.Slides 转换**。

   **在 SharePoint 2007 文档的菜单中选择 “使用 Aspose.Slides 转换”**

   ![SharePoint 2007 文档库中文档的菜单，其中包含 “使用 Aspose.Slides 转换” 项目](convert-one-file_1.png)

2. 在转换页面中，在 **转换为** 下选择输出格式。如有需要，可更改目标文件名和目标文件夹。
3. 单击 **转换**。
4. 转换完成后，单击 **源库** 或 **目标库** 返回文档库。转换后的文件位于目标文件夹中。

相同的步骤以及每个页面的截图请参见[将 Microsoft PowerPoint 文档转换为其他格式](/slides/zh/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
