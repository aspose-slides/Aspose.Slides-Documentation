## **支持的平台**
Aspose.Slides for Node.js via .NET 是一个平台无关的 API。它可以在任何安装了 Node.js 7 或更高版本的平台（Windows、Linux、MacOS 等）上使用。Oracle JDK 8 或更高版本是另一项要求。

## **文件格式和转换**
Aspose.Slides for Node.js via .NET 支持大多数 PowerPoint 文档格式。它还允许您将这些文档导出为组织内部常用的文件格式并进行共享。请查看以下详细信息：

|**功能**|**描述**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET 为此演示文稿文档格式提供最快的处理速度。|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET 支持 PPT 到 PPTX 的转换。|
|Portable Document Format (PDF)|您可以使用单一方法将所有受支持的文件格式导出为 Adobe 可移植文档格式 (PDF) 文档。|
|XML Parser Specification (XPS)|您可以使用单一方法将所有受支持的文件格式导出为 XML 解析规范 (XPS) 文档。|
|Tagged Image File Format (TIFF)|您可以将所有受支持的演示文稿文件格式导出为标记图像文件格式 (TIFF)。|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET 支持将 PresentationEx 转换为 HTML 格式。|

## **演示文稿渲染**
Aspose.Slides for Node.js via .NET 支持将演示文稿中的幻灯片高保真渲染为不同的图形格式。请查看以下详细信息：

|**功能**|**描述**|
| :- | :- |
|.NET Supported Image Formats|使用 Aspose.Slides for Node.js via .NET，您可以将演示文稿幻灯片及幻灯片上的图像渲染为所有 .NET 支持的图形格式，如 TIFF、PNG、BMP、JPEG、GIF。|
|SVG Format|Aspose.Slides for Node.js via .NET 还提供内置方法，允许您将演示文稿幻灯片导出为可缩放矢量图形 (SVG) 格式。|

## **内容功能**
Aspose.Slides for Node.js via .NET 允许您访问、修改或创建几乎所有演示文稿文档的项目或内容。请查看以下详细信息：

|**功能**|**描述**|
| :- | :- |
|Master Slides|母版幻灯片定义普通幻灯片的布局。Aspose.Slides for Node.js via .NET 允许您访问和修改演示文稿的母版幻灯片。|
|Normal Slides|使用 Aspose.Slides for Node.js via .NET，您可以创建不同类型的新幻灯片；还可以访问和修改演示文稿中现有的幻灯片。|
|Cloning / Copying Slides|Aspose.Slides for Node.js via .NET 提供内置方法，允许您克隆或复制演示文稿中的现有幻灯片。您还可以将复制或克隆的幻灯片从一个演示文稿使用到另一个演示文稿。由于幻灯片从母版幻灯片继承布局，内置的克隆方法会自动复制母版。|
|Managing Slides sections|用于在演示文稿中将幻灯片组织到不同章节的方法。|
|Place Holders and Text Holders|您可以访问幻灯片中的占位符和文本占位符。此外，您可以使用相应方法从头创建带有文本占位符的幻灯片。|
|Header and Footers|Aspose.Slides for Node.js via .NET 方便处理幻灯片中的页眉/页脚。|
|Notes in Slides|使用 Aspose.Slides for Node.js via .NET，您可以访问和修改与幻灯片关联的注释，还可以添加新注释。|
|Finding a Shape|您还可以使用与形状关联的替代文本来查找幻灯片中的特定形状。|
|Backgrounds|Aspose.Slides for Node.js via .NET 允许您处理与母版或普通幻灯片关联的背景。|
|Text Boxes|可以从头创建文本框。您可以访问已有的文本框，并在不丢失原始文本格式的情况下修改其文本。|
|Rectangle Shapes|您可以使用 Aspose.Slides for Node.js via .NET 创建或修改矩形形状。|
|Poly Line Shapes|您可以使用 Aspose.Slides for Node.js via .NET 创建或修改折线形状。|
|Ellipse Shapes|您可以使用 Aspose.Slides for Node.js via .NET 创建或修改椭圆形状。|
|Group Shapes|Aspose.Slides for Node.js via .NET 支持组合形状|
|Auto Shapes|Aspose.Slides for Node.js via .NET 支持自动形状|
|SmartArt|Aspose.Slides for Node.js via .NET 为 MS PowerPoint 中的 SmartArt 形状提供支持|
|Charts|Aspose.Slides for Node.js via .NET 为 PowerPoint 中的 MSO 图表提供支持|
|Shapes Serialization|Aspose.Slides for Node.js via .NET 支持大量形状。当 Aspose.Slides for Node.js via .NET 缺少对某个形状的支持时，您可以使用序列化方法将该形状从现有幻灯片序列化。如此，您可以根据需求进一步使用该形状。|
|Picture Frames|您可以使用 Aspose.Slides for Node.js via .NET 管理图片框中的图片。|
|Audio Frames|您可以在幻灯片的音频框中链接或嵌入音频文件，使用 Aspose.Slides for Node.js via .NET。|
|Video Frames|您可以在视频框中处理视频文件。Aspose.Slides for Node.js via .NET 还提供对链接和嵌入视频的支持。|
|OLE Frame|您可以使用 Aspose.Slides for Node.js via .NET 管理 OLE 框中的 OLE 对象。|
|Tables|Aspose.Slides for Node.js via .NET 支持幻灯片中的表格。|
|ActiveX Controls|支持 ActiveX 控件|
|VBA Macros|支持在演示文稿中管理 VBA 宏。|
|Text Frame|您可以通过与形状关联的文本框访问该形状的文本。|
|Text Scanning|您可以使用内置扫描方法在演示文稿或幻灯片级别扫描文本。|
|Animations|您可以对形状应用动画。|
|Slide Shows|Aspose.Slides for Node.js via .NET 支持幻灯片放映和幻灯片切换|
