本 **Developer Guide** 展示了如何在 JavaScript 中使用 Aspose.Slides for Node.js via .NET 执行常见的演示任务。每篇文章都包含可运行的示例。在运行示例之前，请按照[安装](/slides/zh/nodejs-net/installation/)中的说明设置项目。

- [**创建演示文稿**](/slides/zh/nodejs-net/create-presentation/) – 创建演示文稿，添加文本框和幻灯片，设置幻灯片尺寸，并将结果保存为 PPTX。
- [**打开演示文稿**](/slides/zh/nodejs-net/open-presentation/) – 从文件或缓冲区打开演示文稿，读取其幻灯片计数，并将其保存为其他格式。
- [**PowerPoint 转 PDF**](/slides/zh/nodejs-net/convert-powerpoint-to-pdf/) – 将演示文稿转换为 PDF，包括用于归档的 PDF/A。
- [**幻灯片转图片**](/slides/zh/nodejs-net/convert-slide/) – 将幻灯片渲染为 PNG 图像，支持按比例因子或按像素的精确尺寸。
- [**管理文本**](/slides/zh/nodejs-net/manage-text/) – 添加文本框，然后更改其文本、字体大小和粗体样式。
