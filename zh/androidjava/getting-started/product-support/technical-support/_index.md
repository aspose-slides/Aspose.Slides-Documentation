## **概述**

本文说明如何获取 Aspose.Slides 的支持以及如何有效报告问题。它描述了主要的支持渠道，提供了提交问题的建议，并指向有用的技术资源，如产品页面、博客、下载、支持论坛、文档和 API 参考。文章还回答了关于付费支持、问题升级以及对旧版本库的支持等常见问题。

## **技术支持**

{{% alert color="info" %}} 

Aspose 为其所有产品提供无限免费技术支持。该支持对所有用户开放（包括使用评估版的用户）。

{{% /alert %}} 

当您需要 Aspose.Slides for Android via Java 的帮助时，请考虑以下内容：

- 主要的支持渠道是 Aspose.Forums。请在 Aspose.Slides 论坛发布您的问题——通常在几小时内得到回答。Aspose.Slides 支持团队会直接在论坛上回复问题。
- 请注意，Aspose 不提供电话技术支持。电话支持仅用于销售和购买相关问题。
- 在论坛等待回复时，请耐心，并考虑时区差异。

当您在 Aspose.Slides for Android via Java 中遇到问题时，请遵循以下指南以最高效地解决：

- 在报告问题之前，请检查并确认您使用的是最新的 Aspose.Slides for Android via Java 版本。也许您遇到的问题已在更新中得到解决。

  请参阅 Aspose.Slides 下载以获取最新版本信息。

- 在报告问题之前，您可以先浏览我们的论坛、本文档和 API 参考。也许您的问题已经得到解答。

- 报告问题时，请附上原始文档以及（如果可能）与问题相关的代码片段。若需附加多个文件，请将它们压缩为 ZIP 包。

  您可以放心地在 Aspose.Forums 中附加文档，因为只有您和 Aspose 开发人员可以访问这些文件。

- 针对每个具体问题创建并使用一个主题。如果您遇到其他问题，需要另开一个主题进行报告。

## **常见问题**

### 有哪些付费支持层级，它们有何区别？

[开发者、商业和企业](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。它们在包含的事件数量、响应优先级和可用的沟通渠道上有所不同。

### 我可以直接向工程团队升级错误吗？

是的。[付费支持](https://helpdesk.aspose.com/) 在问题需要更深入调查时允许升级至开发人员。

### 是否支持旧版本库，并为其发布修复？

您可以使用旧版本，但修复仅针对当前发布的版本提供；不会为旧版发布补丁。
