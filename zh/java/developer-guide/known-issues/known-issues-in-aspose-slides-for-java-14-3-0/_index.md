{{% alert color="info" title="Note" %}}

这是一个历史页面。它列出了 Aspose.Slides for Java 14.3.0 发布的已知问题，并不描述当前版本。有关每个版本的更改，请参阅[release notes](https://releases.aspose.com/slides/zh/java/release-notes/)。

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) 提供了 PPT 处理的全新实现。改进很多，支持 PPTX 到 PPT 的部分转换。但仍有一些未实现的功能：

- 某些形状在序列化的 PPT 文档中几何形状错误（标注）
- 并非所有 PPTX 文本格式化功能都在 PPT 序列化中受支持
- 序列化的 PPT 文档中不存在文本语言和拼写设置的信息
- 并非所有 PPTX 主题的功能都在 PPT 序列化中受支持

**与 Aspose.Slides for Java 8.6.0 相比，有一些差异：**

- 在 OLE/ActiveX PPT 序列化为 PPT 时存在已知问题

**与 Aspose.Slides for .NET 14.3.0 相比，有一些差异：**

- Aspose.Slides for Java 目前不支持演示文稿打印
