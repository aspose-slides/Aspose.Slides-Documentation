## **概述**

此部分不包含当前版本的未解决问题列表。它包含三个页面：

- [Object Preview Placeholder When Adding OleObjectFrame](/slides/zh/java/object-preview-issue-when-adding-oleobjectframe/) 解释了在使用 Aspose.Slides 添加 OLE 对象时，为什么会显示 “EMBEDDED OLE OBJECT” 图像，直到其预览更新为止，以及如何设置自己的预览图像。这是当前版本的设计行为。
- [Known Issues in Aspose.Slides for Java 14.3.0 (Historical)](/slides/zh/java/known-issues-in-aspose-slides-for-java-14-3-0/) 和 [Known Issues in Aspose.Slides for Java 14.4.0 (Historical)](/slides/zh/java/known-issues-in-aspose-slides-for-java-14-4-0/) 是随这些版本发布的列表，保留供参考。

有关每个版本的更改和修复，请参阅[release notes](https://releases.aspose.com/slides/zh/java/release-notes/)。Aspose.Slides 使用固定值写入的元数据字段在[Output Metadata Limitations](/slides/zh/java/api-limitations/) 中有说明。要检查问题是否已被知晓或报告新问题，请使用[support forum](https://forum.aspose.com/c/slides/zh/11)。
