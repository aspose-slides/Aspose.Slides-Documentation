## **概述**

Aspose.Slides for Java 可以加载 PowerPoint 和 OpenDocument 演示文稿，并在无需 Microsoft PowerPoint、OpenOffice 或 LibreOffice 的情况下将其保存或渲染为许多其他格式。您可以将旧版 PPT 文件转换为现代 PPTX，将演示文稿导出为 PDF、XPS 等固定布局文档，将幻灯片发布为 HTML，或将幻灯片渲染为用于预览、缩略图和归档的图像文件。

大多数文档转换使用相同的通用工作流：加载源文件，选择所需的输出格式，并在需要时应用特定格式的选项。对于图像格式，每张幻灯片分别渲染，然后保存为光栅或矢量图像。下面链接的专用文章提供了每种情况的实现细节。

## **PowerPoint 和 OpenDocument 转换**

Aspose.Slides for Java 支持从常用演示文稿格式（如 PPT、PPTX、PPS、PPSX、POT、POTX 和 ODP）进行转换。PowerPoint 和 OpenDocument 文件使用相同的转换 API，因此将 PPTX 文件保存为 PDF 的工作流通常只需更改输入文件即可应用于 ODP 文件。

转换 ODP 文件时，请记住 PowerPoint 和 OpenDocument 应用程序并未以完全相同的方式支持每种布局和格式化功能。如果 ODP 文件是在 LibreOffice 或 OpenOffice Impress 中创建的，请检查输出并在需要特定格式指导时使用[转换 OpenDocument 演示文稿](/slides/zh/java/convert-openoffice-odp/)中描述的选项。

## **PPT 转 PPTX 转换**

PPT 是较旧的二进制 PowerPoint 格式，而 PPTX 是现代的 Office Open XML 格式。Aspose.Slides for Java 支持高保真度的 PPT 到 PPTX 转换，能够保留复杂的演示结构，如母版、布局、幻灯片、图表、组合形状、占位符、文本框、纹理和图片填充。

详情请参见[将 PowerPoint 转换为 PPTX](/slides/zh/java/convert-ppt-to-pptx/)和[PPT 与 PPTX](/slides/zh/java/ppt-vs-pptx/)。

## **固定布局导出**

当输出需要在各种设备上保持一致且不应作为演示文稿进行编辑时，PDF、XPS 和 TIFF 非常有用。专用的 PDF、XPS 和 TIFF 文章解释了如何控制合规性、隐藏幻灯片、备注、图像质量、压缩、像素格式和输出尺寸。

## **HTML 与图像导出**

HTML 和 HTML5 导出适用于浏览器查看、网络发布和轻量级共享。图像导出在每张幻灯片必须成为单独的预览、缩略图或栅格资源时非常有用。请使用 PNG、JPG 和 SVG 文章获取特定格式的渲染指导。

## **常见问题**

**我需要 Microsoft PowerPoint 来转换演示文稿吗？**

不需要。Aspose.Slides for Java 是一个独立的库，不需要 Microsoft PowerPoint 或 Office 自动化。

**我可以批量转换多个演示文稿吗？**

可以。加载每个演示文稿，保存为所需格式，处理完后释放演示文稿对象。进行并行处理时，请使用独立的演示文稿实例并遵循[多线程](/slides/zh/java/multithreading/)指南。

**我可以仅导出选定的幻灯片吗？**

可以。多种导出方法允许您传递幻灯片索引或渲染单个幻灯片，具体取决于输出格式。请参阅对应格式的专用文章。

**导出为 PDF 或 XPS 时，我可以包括隐藏的幻灯片吗？**

可以。使用在[PDF](/slides/zh/java/convert-powerpoint-to-pdf/)和[XPS](/slides/zh/java/convert-powerpoint-to-xps/)转换文章中描述的隐藏幻灯片导出设置。

**我可以创建 PDF/A 输出吗？**

可以。PDF 导出提供合规性设置。详情请参见[将 PowerPoint 转换为 PDF](/slides/zh/java/convert-powerpoint-to-pdf/)。

**转换过程中如何处理字体？**

Aspose.Slides 可以使用嵌入字体、后备字体和字体替换设置。请参阅[嵌入字体](/slides/zh/java/embedded-font/)、[后备字体](/slides/zh/java/fallback-font/)和[字体替换](/slides/zh/java/font-substitution/)。
