## **概述**

本文说明了如何获取 Aspose.Slides 的支持以及如何有效报告问题。它描述了主要的支持渠道，提供了提交问题的建议，并指向有用的技术资源，如产品页面、博客、下载、支持论坛、文档和 API 参考。本文还回答了关于付费支持、问题升级以及旧版库支持的常见问题。

## **技术支持**

{{% alert color="info" %}} 

Aspose 为其所有产品提供无限制的免费技术支持。此支持面向所有用户，包括评估版用户。

{{% /alert %}} 

如果您需要 Aspose.Slides for Java 的帮助，请考虑以下内容：

- 主要的支持渠道是 Aspose.Forums。请在 Aspose.Slides 论坛中发帖提问，通常在几小时内得到答复。问题由 Aspose.Slides 支持团队直接回答。
- 请注意，Aspose 不提供电话技术支持。电话支持仅用于销售和购买相关问题。
- 在论坛期待回复时，请考虑时区差异。

如果您在使用 Aspose.Slides for Java 时遇到问题，请按照以下简单步骤操作，以确保以最高效的方式解决问题：

- 在报告问题之前，请确保使用最新的 Aspose.Slides for Java 版本，可查看 Aspose.Slides 下载以了解最新版本。
- 在报告问题之前，请浏览论坛、本文档以及 API 参考；可能您的问题已经得到解答。
- 报告问题时，请附上原始文档以及可能导致问题的代码片段。如果需要附加多个文件，请将它们压缩成一个 zip。将文档上传至 Aspose.Forums 是安全的，因为只有您和 Aspose 开发人员可以访问这些附件。
- 请尝试每个主题只报告一个问题。如有其他问题，请在单独的主题中报告。

## **常见问题**

### 有哪些付费支持层级，它们有什么区别？

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。它们在包含的事件数、响应优先级以及可用的沟通渠道上有所不同。

### 我可以直接将 Bug 升级给工程团队吗？

是的。[Paid support](https://helpdesk.aspose.com/) 在问题需要更深入调查时允许升级到开发人员。

### 是否支持旧版库，并会发布修复？

您可以使用旧版，但仅对当前发布提供修复；不会为旧版发布补丁。
