{{% alert color="info" title="Note" %}}
这是一个历史页面。它描述了 Aspose.Slides for Java 版本 23.2 至 23.7（发布于 2023 年）中的一个 bug，以及修复该 bug 的版本。它未描述当前版本。有关当前版本的授权，请参阅 [授权](/slides/zh/java/licensing/)。
{{% /alert %}}

## **概述**

本文描述了在 Aspose.Slides for Java 版本 23.2、23.3、23.4、23.5、23.6 和 23.7 中遇到的授权 bug。该 bug 导致永久授权在订阅到期后暂时不可用。

## **症状**

在永久授权的订阅到期后，Aspose.Slides for Java 版本 23.2 - 23.7 可能会报告授权已过期，将所有功能切换为评估模式。此行为不正确，且不影响 23.2 之前和 23.7 之后的版本。

## **解决方案**

Aspose.Slides for Java 已解决此问题并发布了包含修复的更新版本（23.2.1、23.3.1、23.4.1、23.5.1、23.6.1、23.7.1）。
如果您在项目中使用了受影响的 Aspose.Slides for Java 版本，请切换到已修正的版本。

如果您在使用 Aspose.Slides for Java 时遇到任何授权问题：

- 检查您使用的版本，确保它未受到上述 bug 的影响。
- 参考 [授权](/slides/zh/java/licensing/) 了解如何应用和验证授权。
- 联系 [Aspose 支持](https://forum.aspose.com/c/slides/zh/11) 获取进一步帮助。

## **受影响的产品和版本**

请注意，此 bug 仅影响 Aspose.Slides for Java 版本 23.2 至 23.7。**其他 Aspose 产品及 Aspose.Slides 的其他版本不受影响**。
