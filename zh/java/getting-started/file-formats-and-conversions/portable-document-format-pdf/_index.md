[便携式文档格式](https://en.wikipedia.org/wiki/PDF) 是由 Adobe Systems 创建的用于在组织之间交换文档的文件格式。该格式的目的是保持内容和布局一致，无论在何种平台上查看。Aspose.Slides for Java 允许您将演示文件转换为 PDF。

{{% /alert %}}

## **Aspose.Slides for Java 中的 PDF**
任何可以在 Aspose.Slides for Java 中加载的演示文稿都可以转换为符合 [PDF 1.5](https://en.wikipedia.org/wiki/PDF)、[PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A)、[PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) 或 [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA)（取决于您的选择）的 PDF。Aspose.Slides for Java 将演示文稿导出为 PDF，在大多数情况下，输出的 PDF 与原始演示文稿完全相同。

Aspose.Slides 在转换为 PDF 时支持以下演示文稿特性：

- 图像、文本框和其他形状。
- 文本和格式。
- 段落和格式。
- 超链接。
- 页眉和页脚。
- 项目符号。
- 表格。

您可以直接使用 Aspose.Slides for Java 将演示文稿导出为 PDF：无需任何其他组件。此外，您可以按照 [将 PPT 和 PPTX 转换为 PDF](/slides/zh/java/convert-powerpoint-to-pdf/) 中的说明，通过各种选项自定义演示文稿到 PDF 的导出。
