Aspose.Slides for Java 支持将 PPT 转换为 PPTX。大多数演示文稿功能——母版幻灯片、结构等——在格式转换时都会保留，但仍存在 [一些限制](/slides/zh/java/ppt-to-pptx-conversion/)。

{{% /alert %}} 
## **转换中支持的功能**
Aspose.Slides for Java 提供对将 PPT 文件格式转换为 PPTX 的部分支持。转换功能刚刚在 Aspose.Slides for Java 中引入，因此存在一些限制，最适合用于简单的演示文稿。Aspose.Slides for Java 在将 PPT 转换为 PPTX 时的主要优势在于 API 使用非常简便。要查看代码示例，请阅读 [转换 PPT 为 PPTX]()。下面的列表说明了在 PPT 转换为 PPTX 时哪些功能受支持，哪些不受支持。

## **支持的功能**
以下功能在转换时受支持：

- 转换母版、布局和幻灯片的结构。
- 转换图表。
- 分组形状。
- 转换包括矩形和椭圆在内的自动形状。
- 具有自定义几何形状的形状。
- 自动形状的纹理和图片填充样式。
- 转换占位符。
- 转换直线和折线。
- 线条和填充格式。
- 渐变填充样式。
- OLE 框架、表格、视频和音频框架等。
- 动画和幻灯片放映属性。
- 转换文本框和文本占位符中的文本。
