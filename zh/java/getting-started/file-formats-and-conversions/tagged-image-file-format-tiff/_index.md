## **关于 TIFF**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) 因能够在一个文档中存储多幅图像而闻名，最初由 Aldus 创建。此格式被扫描、传真和其他图像处理应用广泛支持。

## **Aspose.Slides for Java 中的 TIFF**

任何可以在 Aspose.Slides for Java 中加载的文档，都可以直接由 Aspose.Slides for Java 转换为 TIFF 文档，无需任何第三方组件。此外，您还可以选择定义生成的 TIFF 文档中图像的大小。有关通过 Aspose.Slides for Java 将演示文稿导出为 TIFF 文档的信息，请参阅 [Convert PowerPoint Presentations to TIFF](/slides/zh/java/convert-powerpoint-to-tiff/)。
