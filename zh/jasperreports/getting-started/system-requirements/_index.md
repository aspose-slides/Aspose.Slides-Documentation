## **JasperReports**

Aspose.Slides for JasperReports 支持 JasperReports 3.7.2 到 6.16.0。下载包含针对三个版本范围的各自 jar —— 请参阅[Installing Aspose.Slides for JasperReports](/slides/zh/jasperreports/installing-aspose-slides-for-jasperreports/)了解使用哪一个。对于 JasperReports 6.17.0 或更高版本（包括 JasperReports 7），没有对应的 jar。

Aspose.Slides for JasperReports 17.6 中已终止对 JasperReports 2.0.3 到 3.7.1 的支持。版本 17.5 及更早版本同样支持这些版本。

## **Java**

这些 jar 是为 Java 6 或更高版本编译的，正如其文件夹名称中的 *JDK 1.6* 所示，因此所需的 Java 版本取决于你的 JasperReports 版本。使用 JasperReports 6.16.0 时，导出可在 Java 11、17、21 和 25 上运行。

## **操作系统**

这些 jar 仅包含 Java 类和资源，没有本机库，也不使用 Microsoft PowerPoint。在 Linux 上，JasperReports 需要 fontconfig 并至少安装一种字体才能生成报告。

## **JasperReports Server**

对于 JasperReports Server，请使用与服务器运行的 JasperReports 版本对应文件夹中的两个 jar —— 请参阅[Integration with JasperServer](/slides/zh/jasperreports/integration-with-jasperserver/).
