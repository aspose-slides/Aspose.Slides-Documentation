## **支持的平台**
Aspose.Slides for PHP via Java 是一个平台无关的 API。它可以在任何安装了 PHP 7 或更高版本的平台（Windows、Linux、MacOS 等）上使用。Oracle JDK 7 或更高版本是另一项要求。

## **文件格式和转换**
Aspose.Slides for PHP via Java 支持大多数 PowerPoint 文档格式。它还允许将这些文档导出为组织之间常用的文件格式。请浏览以下详细信息：

|**功能**|**描述**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java 为此演示文档格式提供最快的处理速度。|
|PPT to PPTX conversion|Aspose.Slides for PHP via Java 支持 PPT 到 PPTX 的转换|
|Portable Document Format (PDF)|您可以使用单一方法将所有支持的文件格式导出为 Adobe 可携带文档格式（PDF）文档。|
|XML Parser Specification (XPS)|您可以使用单一方法将所有支持的文件格式导出为 XML 解析规范（XPS）文档。|
|Tagged Image File Format (TIFF)|您可以将所有支持的演示文稿文件格式导出为标记图像文件格式（TIFF）。|
|PPTX To HTML Conversion|Aspose.Slides for PHP via Java 支持将 PresentationEx 转换为 HTML 格式。|

## **演示文稿渲染**
Aspose.Slides for PHP via Java 支持高保真渲染演示文稿中的幻灯片为不同的图形格式。请浏览以下详细信息：

|**功能**|**描述**|
| :- | :- |
|Java Supported Image Formats|使用 Aspose.Slides for PHP via Java，您可以将演示文稿幻灯片及幻灯片上的图像渲染为所有 Java 支持的图形格式，如 TIFF、PNG、BMP、JPEG、GIF。|
|SVG Format|Aspose.Slides for PHP via Java 还提供内置方法，允许您将演示文稿幻灯片导出为可缩放矢量图形（SVG）格式。|

## **常见问题**

### 我需要在服务器/电脑上安装 Microsoft PowerPoint 才能使用该库吗？

不需要。PowerPoint 并非必需；Aspose.Slides 是一个独立的引擎，用于创建、编辑、转换和渲染演示文稿。

### 多线程是如何工作的？处理可以并行化吗？

在不同线程中处理不同文档是安全的；同一个[presentation](https://reference.aspose.com/slides/zh/php-java/aspose.slides/presentation/)对象不能同时被[multiple threads](/slides/zh/php-java/multithreading/)使用。

### 是否支持文件密码和加密？

是的。[You can](/slides/zh/php-java/password-protected-presentation/) 打开加密的演示文稿，设置或移除打开和写入密码，并检查保护状态。

### 在 Linux 容器中需要关注字体包吗？

是的。建议在您的应用程序中安装常见的字体包和/或显式[specify font directories](/slides/zh/php-java/custom-font/) 以避免意外的替换。

### 评估版是否有限制？

在[evaluation mode](/slides/zh/php-java/licensing/)下，输出会添加水印并存在某些限制；可使用[30-day temporary license](https://purchase.aspose.com/temporary-license/)进行完整功能测试。

### 是否支持将外部格式导入演示文稿（PDF/HTML → PPTX）？

是的。您可以将[PDF pages and HTML content](/slides/zh/php-java/import-presentation/) 添加到演示文稿中，将其转换为幻灯片。
