## **Aspose.Slides 评估**

您可以下载 Aspose.Slides 进行评估。评估包与购买的包相同；在添加几行代码以应用许可证后，它将获得授权。请参阅[Installation](/slides/zh/php-java/installation/)以进行设置，参阅[Licensing](/slides/zh/php-java/licensing/)以应用许可证。

在未授权的情况下，Aspose.Slides 在评估模式下提供全部功能，但有两项限制：它会在每个演示文稿保存的每张幻灯片中间添加一个评估水印文本框；以及代码从演示文稿读取的文本会被截断为前几个字符，并附加有关评估限制的通知。代码写入的文本会完整保存。

如果您想在没有评估版限制的情况下测试 Aspose.Slides，可以请求**30 Day Temporary License**。详情请参阅[How to get a Temporary License?](https://purchase.aspose.com/temporary-license)。
{{% /alert %}}

## **常见问题**

### 在评估模式下，我能否在不同线程中并行测试多个演示文稿？

是的。您可以并行处理不同的文档；但不应在[across threads](/slides/zh/php-java/multithreading/)之间共享同一个演示文稿对象。评估模式不会影响此行为。

### 我是否需要安装 Microsoft PowerPoint 来在服务器或 CI 上评估该库？

不需要。Aspose.Slides 是独立的引擎，无论是评估还是生产环境都不需要安装 PowerPoint。

### 我能在评估模式下完整测试 PPT/PPTX 到 PDF 和图像的转换吗？

可以。[converters](/slides/zh/php-java/convert-presentation/) 能正常工作，输出中会包含水印。

### 我可以在负载测试中使用临时许可证而不出现水印吗？

可以。30 天的临时许可证可移除评估模式限制，允许在没有水印的情况下进行测试。
