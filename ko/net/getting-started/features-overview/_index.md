## **지원되는 플랫폼**
Aspose.Slides for .NET은 가장 널리 사용되는 개발 및 배포 플랫폼을 지원합니다. 자세한 내용은 아래를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|ASP.NET Web Applications|Aspose.Slides for .NET을 사용하여 .NET Framework 버전 2.0부터 4.6.2까지를 대상으로 하는 ASP.NET 웹 애플리케이션을 구축합니다|
|Web Services|Aspose.Slides for .NET을 사용하여 웹 서비스를 배포합니다|
|WinForms Applications|Aspose.Slides for .NET은 Windows Forms 애플리케이션 개발에도 사용할 수 있습니다|

## **파일 형식 및 변환**
Aspose.Slides for .NET은 대부분의 PowerPoint 문서 형식을 지원합니다. 또한 조직에서 널리 사용하고 서로 교환하는 인기 형식으로 내보낼 수 있습니다. 자세한 내용은 아래를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ko/net/ppt-vs-pptx/)|Aspose.Slides for .NET은 이 프레젠테이션 문서 형식에 대해 가장 빠른 처리를 제공합니다.|
|[PPT to PPTX conversion](/slides/ko/net/convert-ppt-to-pptx/)|Aspose.Slides for .NET은 PPT를 PPTX로 변환하는 것을 지원합니다.|
|[Portable Document Format (PDF)](/slides/ko/net/convert-powerpoint-ppt-and-pptx-to-pdf/)|단일 메서드로 모든 지원 파일 형식을 Adobe Portable Document Format(PDF) 문서로 내보낼 수 있습니다.|
|[XML Parser Specification (XPS)](https://docs.aspose.com/slides/ko/net/convert-powerpoint-to-xps/)|단일 메서드로 모든 지원 파일 형식을 XML Parser Specification(XPS) 문서로 내보낼 수 있습니다.|
|[Tagged Image File Format (TIFF)](/slides/ko/net/convert-powerpoint-to-tiff/)|모든 지원 프레젠테이션 파일 형식을 Tagged Image File Format(TIFF)으로 내보낼 수 있습니다.|
|[PPTX To HTML Conversion](/slides/ko/net/convert-powerpoint-ppt-and-pptx-to-html/)|Aspose.Slides for .NET은 PresentationEx를 HTML 형식으로 변환하는 것을 지원합니다.|

## **프레젠테이션 렌더링**
Aspose.Slides for .NET은 프레젠테이션 문서의 슬라이드를 다양한 그래픽 형식으로 고품질 렌더링을 지원합니다. 자세한 내용은 아래를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|.NET Supported Image Formats|Aspose.Slides for .NET을 사용하면 TIFF, PNG, BMP, JPEG, GIF 및 메타파일과 같은 .NET 지원 그래픽 형식 모두에 프레젠테이션 슬라이드와 슬라이드 내 이미지를 렌더링할 수 있습니다.|
|SVG Format|Aspose.Slides for .NET은 Scalable Vector Graphics(SVG) 형식으로 프레젠테이션 슬라이드를 내보내는 내장 메서드도 제공합니다.|

## **콘텐츠 기능**
Aspose.Slides for .NET을 사용하면 프레젠테이션 문서의 거의 모든 항목이나 내용을 접근, 수정 또는 생성할 수 있습니다. 자세한 내용은 아래를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|Master Slides|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for .NET은 프레젠테이션 문서의 마스터 슬라이드에 접근하고 이를 수정할 수 있게 합니다.|
|Normal Slides|Aspose.Slides for .NET을 사용하면 다양한 유형의 새 슬라이드를 만들 수 있으며, 프레젠테이션 내 기존 슬라이드에 접근하고 이를 수정할 수 있습니다.|
|Cloning / Copying Slides|Aspose.Slides for .NET이 제공하는 내장 메서드를 통해 프레젠테이션 내 기존 슬라이드를 복제하거나 복사할 수 있습니다. 복제 및 복사된 슬라이드를 다른 프레젠테이션으로도 사용할 수 있습니다. 슬라이드는 마스터 슬라이드에서 레이아웃을 상속받기 때문에 복제 시 마스터도 자동으로 복사됩니다.|
|Managing Slides sections|프레젠테이션 내부에서 슬라이드를 다양한 섹션으로 조직하는 메서드입니다.|
|Place Holders and Text Holders|슬라이드 내 자리 표시자와 텍스트 자리 표시자에 접근할 수 있습니다. 또한 적절한 메서드를 사용해 텍스트 자리 표시자를 포함한 슬라이드를 처음부터 만들 수 있습니다.|
|Header and Footers|Aspose.Slides for .NET은 슬라이드의 머리글/바닥글 처리를 지원합니다.|
|Notes in Slides|Aspose.Slides for .NET을 사용하면 슬라이드에 연결된 메모에 접근하고 이를 수정하거나 새 메모를 추가할 수 있습니다.|
|Finding a Shape|도형에 연결된 대체 텍스트를 사용해 슬라이드에서 특정 도형을 찾을 수 있습니다.|

## **FAQ**

### 라이브러리를 사용하려면 서버/PC에 Microsoft PowerPoint를 설치해야 합니까?
아니요. PowerPoint는 필요하지 않으며, Aspose.Slides는 프레젠테이션을 만들고, 편집하고, 변환하고, 렌더링하기 위한 독립형 엔진입니다.

### 멀티스레딩은 어떻게 작동합니까? 처리를 병렬화할 수 있나요?
다른 스레드에서 서로 다른 문서를 처리하는 것은 안전합니다; 동일한[presentation](https://reference.aspose.com/slides/ko/net/aspose.slides/presentation/) 객체를 [multiple threads](/slides/ko/net/multithreading/)가 동시에 사용해서는 안 됩니다.

### 파일 비밀번호와 암호화가 지원되나요?
예. [You can](/slides/ko/net/password-protected-presentation/) 암호화된 프레젠테이션을 열고, 열기 및 쓰기 비밀번호를 설정하거나 제거하며, 보호 상태를 확인할 수 있습니다.

### Linux 컨테이너에서 폰트 패키지를 신경 써야 하나요?
예. 예기치 않은 대체를 방지하기 위해 일반적인 폰트 패키지를 설치하거나 애플리케이션에서 [specify font directories](/slides/ko/net/custom-font/)을 명시적으로 지정하는 것이 권장됩니다.

### 평가 버전에는 제한이 있나요?
[Evaluation mode](/slides/ko/net/licensing/)에서는 출력에 워터마크가 추가되고 특정 제한이 적용됩니다; 전체 기능 테스트를 위해 [30일 임시 라이선스](https://purchase.aspose.com/temporary-license/)를 사용할 수 있습니다.

### 외부 형식(PDF/HTML → PPTX)을 프레젠테이션에 가져오는 것이 지원되나요?
예. [PDF pages and HTML content](/slides/ko/net/import-presentation/)을 프레젠테이션에 추가하여 슬라이드로 변환할 수 있습니다.
