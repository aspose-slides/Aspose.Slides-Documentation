## **개요**

Aspose.Slides는 Microsoft PowerPoint 97부터 Office 365까지, 또한 Microsoft PowerPoint for Mac을 포함한 프레젠테이션 파일을 지원합니다. 이 문서에서는 라이브러리에서 지원하는 PowerPoint 버전을 나열하고, 로드하거나 저장하거나 모두 가능한 파일 형식 표를 제공합니다.

또한 이 문서는 PDF 컴플라이언스, 폰트 임베딩, 비밀번호 보호 파일, 사용자 정의 폰트, 폰트 대체, 그리고 XPS 내보내기 옵션에 대한 일반적인 질문에 답합니다.

## **지원되는 Microsoft PowerPoint 버전**
- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for MAC
- Office 365

## **자주 묻는 질문**

**프레젠테이션을 PDF/A 및 PDF/UA와 같은 보관 및 접근성 표준을 충족하도록 저장할 수 있습니까?**

예. Aspose.Slides는 PDF/A-2a, PDF/A-2b, PDF/A-2u, PDF/A-3a, PDF/A-3b와 같은 PDF/A 수준 및 PDF/UA를 지원하며, 이는 [PDF 내보내기 옵션]의 [컴플라이언스](https://reference.aspose.com/slides/ko/cpp/aspose.slides.export/pdfoptions/set_compliance/) 설정을 통해 사용할 수 있습니다.

**라이브러리가 PDF로 내보낼 때 폰트 임베딩을 지원하며, 임베딩할 내용을 세밀하게 제어할 수 있습니까?**

예. 폰트를 전체 임베드하거나 하위 집합(사용된 글리프만)으로 임베드할지, 일반 시스템 폰트를 어떻게 처리할지, ASCII 텍스트에 대한 동작을 [PDF 내보내기 옵션](https://reference.aspose.com/slides/ko/cpp/aspose.slides.export/pdfoptions/)을 통해 제어할 수 있습니다.

**파일을 실제로 로드하기 전에 비밀번호가 보호되어 있는지 감지할 수 있습니까?**

예. [팩토리 기반 검사 API](https://reference.aspose.com/slides/ko/cpp/aspose.slides/presentationfactory/)를 사용하면 프레젠테이션 파일을 완전히 열지 않고도 비밀번호 보호 여부를 확인할 수 있습니다.

**폰트 대체 메커니즘 및 사용자 정의 폰트 지원이 있습니까?**

예. 라이브러리는 [로드](/slides/ko/cpp/custom-font/) 및 [임베드](/slides/ko/cpp/embedded-font/) 사용자 정의 폰트를 지원하고, 렌더링 및 변환 중 누락된 글리프를 방지하기 위해 폰트 [대체 규칙](/slides/ko/cpp/fallback-font/)을 제공합니다.

**슬라이드를 XPS로 내보낼 수 있으며, XPS 출력 옵션을 조정할 수 있습니까?**

예. [XPS로 내보내기](/slides/ko/cpp/convert-powerpoint-to-xps/)가 지원되며, 관련 [저장 옵션](https://reference.aspose.com/slides/ko/cpp/aspose.slides.export/xpsoptions/)을 조정하여 XPS 문서의 품질 및 내용을 제어할 수 있습니다.
