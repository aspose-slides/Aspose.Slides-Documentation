## **파일 형식 및 변환**
Aspose.Slides for C++는 대부분의 PowerPoint 문서 형식을 지원하며, 조직 간에 널리 사용되는 인기 형식으로도 내보낼 수 있습니다. 다음 표에 이러한 형식이 열거되어 있습니다:

|**기능**|**설명**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ko/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++는 이 프레젠테이션 문서 형식에 대해 가장 빠른 처리를 제공합니다.|
|[Portable Document Format (PDF)](/slides/ko/cpp/portable-document-format-pdf/)|지원되는 파일 형식은 단일 메서드로 Adobe Portable Document Format (PDF) 문서로 내보낼 수 있습니다.|
|[XML Parser Specification (XPS)](/slides/ko/cpp/xml-parser-specification-xps/)|지원되는 모든 파일 형식은 단일 메서드로 XML Parser Specification (XPS) 문서로 내보낼 수 있습니다.|
|[PresentationML (PPTX, XML)](/slides/ko/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++는 PresentationML 또는 PPTX라고도 알려진 OOXML 프레젠테이션 형식 처리를 지원합니다.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/ko/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++는 프레젠테이션을 HTML 형식으로 변환하는 것을 지원합니다.|

## **렌더링**
Aspose.Slides for C++는 프레젠테이션 문서의 슬라이드를 다양한 그래픽 형식으로 고충실도 렌더링을 지원합니다:

|**기능**|**설명**|
| :- | :- |
|C++ Supported Image Formats|Aspose.Slides for C++를 사용하면 프레젠테이션 슬라이드뿐 아니라 슬라이드의 이미지도 PNG, BMP 및 JPEG와 같은 C++가 지원하는 모든 그래픽 형식으로 렌더링할 수 있습니다.|
|SVG Format|Aspose.Slides for C++는 또한 스케일러블 벡터 그래픽(SVG) 형식으로 프레젠테이션 슬라이드를 내보내는 내장 메서드를 제공합니다.|

## **콘텐츠 기능**
Aspose.Slides for C++는 프레젠테이션 문서의 거의 모든 가능한 내용을 액세스, 수정 또는 생성할 수 있게 합니다.

|**기능**|**설명**|
| :- | :- |
|Master Slides|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for C++를 사용하면 프레젠테이션 문서의 마스터 슬라이드에 액세스하고 수정할 수 있습니다.|
|Normal Slides|Aspose.Slides for C++를 사용하면 다양한 유형의 새 슬라이드를 만들 뿐 아니라 프레젠테이션 문서의 기존 슬라이드에 액세스하고 수정할 수 있습니다.|
|Cloning / Copying Slides|Aspose.Slides for C++는 프레젠테이션 내부뿐 아니라 한 프레젠테이션에서 다른 프레젠테이션으로도 기존 슬라이드를 복제하거나 복사하는 내장 메서드를 제공합니다. 슬라이드는 마스터 슬라이드의 레이아웃을 상속하므로, 내장 복제 메서드는 복제 시 마스터도 자동으로 복사합니다.|
|Place Holders and Text Holders|슬라이드의 플레이스홀더와 텍스트 홀더에 액세스할 수 있습니다. 또한 적절한 메서드를 사용하여 텍스트 홀더가 포함된 슬라이드를 처음부터 만들 수 있습니다.|
|Header and Footers|Aspose.Slides for C++는 슬라이드의 머리글/바닥글을 처리하는 기능도 제공합니다.|
|Notes in Slides|Aspose.Slides for C++를 사용하면 슬라이드와 연결된 노트에 액세스하고 수정할 수 있을 뿐 아니라 노트를 추가할 수도 있습니다.|
|Finding a Shape|도형에 연결된 대체 텍스트를 사용하여 슬라이드에서 특정 도형을 찾을 수 있습니다.|
|Backgrounds|Aspose.Slides for C++는 프레젠테이션의 마스터 또는 일반 슬라이드와 연결된 배경을 작업할 수 있게 합니다.|
|Text Boxes|텍스트 상자를 처음부터 만들 수 있습니다. 기존 텍스트 상자에 액세스하고 텍스트를 수정할 수 있으며 원래 텍스트 형식은 유지됩니다.|
|Rectangle Shapes|사각형 도형을 Aspose.Slides for C++로 만들거나 수정할 수 있습니다.|
|Poly Line Shapes|폴리라인 도형도 Aspose.Slides for C++로 만들거나 수정할 수 있습니다.|
|Ellipse Shapes|타원 도형도 Aspose.Slides for C++로 만들거나 수정할 수 있습니다.|
|Group Shapes|Aspose.Slides for C++는 그룹 도형도 지원합니다.|
|Auto Shapes|자동 도형도 Aspose.Slides for C++에서 지원됩니다.|
|Shapes Serialization|비록 Aspose.Slides for C++가 많은 도형을 지원하지만, 지원되지 않는 도형이 있는 경우 Aspose.Slides for C++에서 제공하는 직렬화 메서드를 통해 해당 도형을 기존 슬라이드에서 직렬화하여 필요에 따라 Aspose.Slides for C++가 이후에 사용할 수 있습니다.|
|Picture Frames|그림은 Aspose.Slides for C++를 사용하여 그림 프레임에서 관리됩니다.|
|Audio Frames|오디오 파일은 Aspose.Slides for C++를 통해 오디오 프레임에 링크하거나 슬라이드에 삽입할 수 있습니다.|
|Video Frames|비디오 파일은 Aspose.Slides for C++를 통해 비디오 프레임에서 처리됩니다.|
|OLE Frame|OLE 객체는 Aspose.Slides for C++에 의해 OLE 프레임에서 관리됩니다.|
|Tables|슬라이드의 표도 Aspose.Slides for C++에서 지원됩니다.|
|Text Frame|어떤 도형에 연결된 텍스트도 해당 도형의 텍스트 프레임을 통해 액세스할 수 있습니다.|
|Text Scanning|프레젠테이션 또는 슬라이드 수준에서 내장 스캔 메서드를 사용하여 텍스트를 스캔할 수 있습니다.|
|Animations|도형에 애니메이션을 적용할 수 있습니다.|
|Slide Shows|슬라이드 쇼, 슬라이드 전환 및 모프 전환도 지원됩니다.|

## **FAQ**

**서버/PC에 Microsoft PowerPoint를 설치해야 라이브러리를 사용할 수 있나요?**

아니요. PowerPoint는 필요하지 않습니다; Aspose.Slides는 프레젠테이션을 만들고, 편집하고, 변환하고, 렌더링하기 위한 독립형 엔진입니다.

**멀티스레딩은 어떻게 작동합니까? 처리를 병렬화할 수 있나요?**

다른 스레드에서 서로 다른 문서를 처리하는 것은 안전합니다; 동일한 [presentation](https://reference.aspose.com/slides/ko/cpp/aspose.slides/presentation/) 객체를 [multiple threads](/slides/ko/cpp/multithreading/)가 동시에 사용해서는 안 됩니다.

**파일 비밀번호 및 암호화를 지원합니까?**

예. [You can](/slides/ko/cpp/password-protected-presentation/) 암호화된 프레젠테이션을 열고, 열기 및 쓰기 비밀번호를 설정하거나 제거하며, 보호 상태를 확인할 수 있습니다.

**Linux 컨테이너에서 폰트 패키지를 신경써야 하나요?**

예. 일반적인 폰트 패키지를 설치하거나 애플리케이션에서 명시적으로 [specify font directories](/slides/ko/cpp/custom-font/)를 지정하여 예상치 못한 대체를 방지하는 것이 권장됩니다.

**평가 버전에는 제한이 있나요?**

[evaluation mode](/slides/ko/cpp/licensing/)에서는 출력에 워터마크가 추가되고 특정 제한이 적용됩니다; 전체 기능 테스트를 위해 [30-day temporary license](https://purchase.aspose.com/temporary-license/)를 사용할 수 있습니다.

**프레젠테이션에 외부 형식(PDF/HTML → PPTX) 가져오기가 지원되나요?**

예. 프레젠테이션에 [PDF pages and HTML content](/slides/ko/cpp/import-presentation/)을 추가하여 슬라이드로 변환할 수 있습니다.
