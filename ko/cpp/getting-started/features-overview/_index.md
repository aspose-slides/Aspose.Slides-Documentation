## **파일 형식 및 변환**
Aspose.Slides for C++는 대부분의 PowerPoint 문서 형식을 지원하며, 조직 간 널리 사용되는 인기 형식으로도 내보낼 수 있습니다. 다음 표에 이러한 형식이 나열되어 있습니다:

|**기능**|**설명**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ko/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++는 이 프레젠테이션 문서 형식에 대해 가장 빠른 처리를 제공합니다.|
|[Portable Document Format (PDF)](/slides/ko/cpp/portable-document-format-pdf/)|지원되는 파일 형식은 단일 메서드로 Adobe Portable Document Format (PDF) 문서로 내보낼 수 있습니다.|
|[XML Parser Specification (XPS)](/slides/ko/cpp/xml-parser-specification-xps/)|지원되는 모든 파일 형식은 단일 메서드로 XML Parser Specification (XPS) 문서로 내보낼 수 있습니다.|
|[PresentationML (PPTX, XML)](/slides/ko/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++는 PresentationML 또는 PPTX라고도 알려진 OOXML 프레젠테이션 형식 처리를 지원합니다.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/ko/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++는 프레젠테이션을 HTML 형식으로 변환하는 기능을 지원합니다.|

## **프레젠테이션 렌더링**
Aspose.Slides for C++는 프레젠테이션 문서의 슬라이드를 아래에 나열된 다양한 그래픽 형식으로 높은 충실도로 렌더링합니다:

|**기능**|**설명**|
| :- | :- |
|C++ 지원 이미지 형식|Aspose.Slides for C++를 사용하면 프레젠테이션 슬라이드뿐만 아니라 슬라이드의 이미지를 PNG, BMP 및 JPEG와 같은 모든 C++ 지원 그래픽 형식으로 렌더링할 수 있습니다.|
|SVG 형식|Aspose.Slides for C++는 Scalable Vector Graphics (SVG) 형식으로 프레젠테이션 슬라이드를 내보내는 내장 메서드도 제공합니다.|

## **콘텐츠 기능**
Aspose.Slides for C++는 프레젠테이션 문서의 거의 모든 가능한 콘텐츠에 접근, 수정 또는 생성할 수 있게 해줍니다.

|**기능**|**설명**|
| :- | :- |
|마스터 슬라이드|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for C++는 프레젠테이션 문서의 마스터 슬라이드에 접근하고 이를 수정할 수 있게 해줍니다.|
|일반 슬라이드|Aspose.Slides for C++를 사용하면 다양한 유형의 새 슬라이드를 만들 뿐만 아니라 프레젠테이션 문서의 기존 슬라이드에 접근하고 이를 수정할 수 있습니다.|
|슬라이드 복제/복사|Aspose.Slides for C++가 제공하는 내장 메서드를 사용하면 슬라이드를 프레젠테이션 안에서뿐만 아니라 다른 프레젠테이션으로도 복제하거나 복사할 수 있습니다. 슬라이드는 마스터 슬라이드의 레이아웃을 상속하므로, 복제 메서드는 복제 시 마스터도 자동으로 복사합니다.|
|플레이스홀더 및 텍스트 홀더|슬라이드에서 플레이스홀더와 텍스트 홀더에 접근할 수 있습니다. 또한 적절한 메서드를 사용하여 텍스트 홀더가 있는 슬라이드를 처음부터 만들 수 있습니다.|
|머리글 및 바닥글|Aspose.Slides for C++는 슬라이드의 머리글/바닥글을 처리하는 기능을 제공합니다.|
|슬라이드 노트|Aspose.Slides for C++를 사용하면 슬라이드와 연결된 노트에 접근하고 수정할 수 있을 뿐만 아니라 노트를 추가할 수도 있습니다.|
|모양 찾기|도형에 연결된 대체 텍스트를 사용하여 슬라이드에서 특정 도형을 찾을 수 있습니다.|
|배경|Aspose.Slides for C++는 프레젠테이션의 마스터 또는 일반 슬라이드와 연결된 배경을 작업할 수 있게 해줍니다.|
|텍스트 상자|텍스트 상자는 처음부터 만들 수 있습니다. 기존 텍스트 상자에 접근하고 텍스트를 수정할 수 있으며, 원본 텍스트 서식은 유지됩니다.|
|사각형 모양|사각형 모양을 Aspose.Slides for C++로 만들거나 수정할 수 있습니다.|
|폴리 라인 모양|폴리 라인 모양도 Aspose.Slides for C++로 만들거나 수정할 수 있습니다.|
|타원형 모양|타원형 모양도 Aspose.Slides for C++로 만들거나 수정할 수 있습니다.|
|그룹 모양|Aspose.Slides for C++는 그룹 모양을 지원합니다.|
|자동 모양|자동 모양도 Aspose.Slides for C++에서 지원됩니다.|
|모양 직렬화|Aspose.Slides for C++는 많은 도형을 지원하지만, 지원되지 않는 도형이 있을 경우 Aspose.Slides for C++가 제공하는 직렬화 메서드를 사용하여 기존 슬라이드에서 해당 도형을 직렬화한 뒤 필요에 따라 다시 사용할 수 있습니다.|

|비디오 프레임|비디오 파일은 Aspose.Slides for C++를 통해 비디오 프레임에서 처리됩니다.|

## **FAQ**

### 라이브러리를 사용하려면 서버/PC에 Microsoft PowerPoint를 설치해야 합니까?

No. PowerPoint는 필요하지 않으며, Aspose.Slides는 프레젠테이션을 생성, 편집, 변환 및 렌더링하기 위한 독립형 엔진입니다.

### 멀티스레딩은 어떻게 작동합니까? 처리를 병렬화할 수 있습니까?

It is safe to process different documents in different threads; the same [프레젠테이션](https://reference.aspose.com/slides/ko/cpp/aspose.slides/presentation/) object must not be used by [여러 스레드](/slides/ko/cpp/multithreading/) at the same time.

### 파일 비밀번호 및 암호화가 지원됩니까?

Yes. [가능합니다](/slides/ko/cpp/password-protected-presentation/) 암호화된 프레젠테이션을 열고, 열기 및 쓰기 비밀번호를 설정하거나 제거하며, 보호 상태를 확인할 수 있습니다.

### Linux 컨테이너에서 글꼴 패키지를 신경 써야 합니까?

Yes. 일반적인 글꼴 패키지를 설치하거나 애플리케이션에서 [글꼴 디렉터리 지정](/slides/ko/cpp/custom-font/)을 명시적으로 설정하여 예상치 못한 대체를 방지하는 것이 권장됩니다.

### 평가 버전에 제한이 있습니까?

In [평가 모드](/slides/ko/cpp/licensing/), 출력에 워터마크가 추가되고 특정 제한이 적용됩니다; 전체 기능 테스트를 위해 [30일 임시 라이선스](https://purchase.aspose.com/temporary-license/)를 사용할 수 있습니다.

### 외부 형식(PDF/HTML → PPTX)을 프레젠테이션으로 가져오는 것이 지원됩니까?

Yes. [PDF 페이지 및 HTML 콘텐츠](/slides/ko/cpp/import-presentation/)를 프레젠테이션에 추가하여 슬라이드로 변환할 수 있습니다.
