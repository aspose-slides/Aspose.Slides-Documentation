Aspose.Slides for Python via Java를 다운로드하여 기능을 평가할 수 있습니다. 평가 패키지는 라이선스 패키지와 동일합니다. 평가 제한 없이 사용하려면 [라이선스 적용](/slides/ko/python-java/licensing/)에 몇 줄의 코드를 추가하십시오.

라이선스 없이 사용되는 Aspose.Slides 평가 버전은 전체 제품 기능을 제공하지만 두 가지 제한이 있습니다:

- 저장하는 각 프레젠테이션의 모든 슬라이드에 평가 워터마크 텍스트 박스를 추가합니다. 프레젠테이션을 열 때는 추가되지 않지만, 이미 워터마크가 있는 파일을 저장하면 또 하나가 추가됩니다.
- 코드가 읽는 텍스트는 처음 몇 글자로 잘리고, 평가 제한에 대한 안내가 뒤에 붙습니다. 이는 모든 슬라이드와, 코드가 방금 설정한 텍스트 및 파일에서 로드한 텍스트 모두에 적용됩니다. 코드가 쓰는 텍스트는 전체가 저장됩니다.

{{% alert color="info" title="Note" %}}
평가 제한 없이 Aspose.Slides를 테스트하려면 **30일 임시 라이선스**를 요청할 수 있습니다. 자세한 내용은 [임시 라이선스 받기](https://purchase.aspose.com/temporary-license)를 참조하십시오.
{{% /alert %}}
