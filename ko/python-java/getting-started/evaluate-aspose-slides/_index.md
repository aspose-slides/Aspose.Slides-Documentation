Aspose.Slides for Python via Java를 다운로드하여 기능을 평가할 수 있습니다. 평가 패키지는 라이선스 패키지와 동일합니다. 평가 제한 없이 사용하려면 라이선스를 적용하는 몇 줄의 코드를 추가하십시오.

Aspose.Slides의 평가 버전(라이선스 없이 사용)은 전체 제품 기능을 제공하지만, 문서를 열거나 저장할 때 문서 상단에 평가 워터마크가 삽입됩니다. 텍스트 추출은 프레젠테이션당 한 슬라이드로 제한됩니다.

![프레젠테이션 슬라이드의 Aspose.Slides 평가 워터마크](evaluate-aspose-slides_1.png)

평가 제한 없이 Aspose.Slides를 테스트하려면 **30일 임시 라이선스**를 요청할 수 있습니다. 자세한 내용은 [임시 라이선스 받기](https://purchase.aspose.com/temporary-license)를 참조하십시오.
