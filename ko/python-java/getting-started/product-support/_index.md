## **개요**

Aspose.Slides 지원 포럼을 사용하여 질문을 하고, 문제를 보고하고, Aspose.Slides for Python via Java에 대한 기능을 요청하십시오. 이 문서는 주제를 열기 전에 확인해야 할 사항과 지원 팀이 문제를 재현하는 데 도움이 되는 정보를 설명합니다.

## **기술 지원**

{{% alert color="info" title="Note" %}}
Aspose는 제품을 평가하는 사용자를 포함한 모든 사용자에게 무료 기술 지원을 제공합니다. 자세한 내용은 [무료 지원 정책](https://forum.aspose.com/t/free-support-policies/162313)을 확인하십시오.
{{% /alert %}}

기술 질문은 [Aspose.Slides 지원 포럼](https://forum.aspose.com/c/slides/ko/11)에 게시하십시오. 보고서에 **Aspose.Slides for Python via Java**를 명시하면 팀이 올바른 제품 및 환경을 식별할 수 있습니다.

우선 지원이 필요하면 [유료 지원 헬프데스크](https://helpdesk.aspose.com/)를 확인하십시오. 유료 지원은 별도의 구독이 필요하며 제품 라이선스에 포함되지 않습니다.

## **문제 보고 전에**

1. 문제를 해결할 수 있는 최신 버전이 있는지 확인하려면 [다운로드](https://releases.aspose.com/slides/ko/python-java/)와 [릴리스 노트](https://releases.aspose.com/slides/ko/python-java/release-notes/)를 확인하십시오. 가능하면 최신 릴리스를 사용하여 테스트 환경에서 문제를 재현하십시오.
2. 지원 포럼, [문서](/slides/ko/python-java/), 및 [API 참조](https://reference.aspose.com/slides/ko/python-java/)에서 기존 답변을 검색하십시오.
3. 설치 또는 JVM 시작 문제에 대해서는 [설치 가이드](/slides/ko/python-java/installation/)를 검토하고 Python과 Java가 일치하는 아키텍처를 사용하는지 확인하십시오.
4. 문제를 최소한의 예제와 입력 프레젠테이션으로 축소하여 여전히 재현되는지 확인하십시오.

## **이슈 보고서 준비**

포럼 주제에 다음 정보를 포함하십시오:

- **Environment:** Aspose.Slides for Python via Java 버전, Python 버전, Java 버전 및 공급업체, JPype 버전, 운영 체제 및 아키텍처.
- **Steps and code:** 가져오기 및 JVM 초기화를 포함한 최소 실행 가능한 Python 예제와 문제를 재현하는 데 필요한 단계.
- **Input files:** 예제에 필요한 프레젠테이션 및 관련 파일. 여러 파일은 ZIP 압축 파일로 결합하십시오.
- **Expected and actual results:** 차이를 설명하고 필요시 생성된 출력물이나 스크린샷을 첨부하십시오. 렌더링 문제의 경우 영향을 받은 슬라이드와 글꼴을 식별하십시오.
- **Error details:** 예외가 발생한 경우 전체 오류 메시지와 스택 트레이스를 제공하십시오.

문제당 하나의 주제를 사용하십시오. 동일한 문제에 대한 후속 정보를 기존 주제에 추가하면 지원 팀이 조사를 계속할 수 있습니다.

## **자주 묻는 질문**

**Aspose.Slides for Python via Java를 평가하는 동안 도움을 받을 수 있나요?**

예. 평가 기간 동안 및 구매 후에도 Aspose.Slides 지원 포럼을 통해 무료 기술 지원을 이용할 수 있습니다.

**JVM이 시작되지 않을 때 무엇을 포함해야 합니까?**

Python, Java 및 JPype 버전, 운영 체제, Python과 Java 아키텍처, JVM 초기화 코드, 전체 오류 메시지를 제공하십시오. 이러한 세부 정보는 지원 팀이 귀하의 설정을 재현하는 데 도움이 됩니다.

**업그레이드 후에 나타난 문제를 어떻게 보고해야 합니까?**

작동하던 마지막 버전, 문제가 발생한 첫 번째 버전, 입력 파일이 포함된 최소 예제를 포함하십시오. 업그레이드 중에 발생한 기타 환경 변경 사항을 설명하십시오.
