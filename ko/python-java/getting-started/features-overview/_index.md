이 문서는 Aspose.Slides for Python via Java의 프레젠테이션 처리 기능을 설명합니다. 지원되는 운영 체제 및 종속성에 대해서는 [시스템 요구 사항](/slides/ko/python-java/system-requirements/)을 참조하십시오.

## **파일 형식 및 변환**

Aspose.Slides for Python via Java를 사용하면 프레젠테이션 형식 간 변환 및 프레젠테이션을 문서 및 웹 형식으로 내보낼 수 있습니다. 전체 형식 표와 프레젠테이션 로드, 콘텐츠 가져오기, 출력 내보내기의 구분에 대해서는 [지원 파일 형식](/slides/ko/python-java/supported-file-formats/)을 확인하십시오.

## **프레젠테이션 렌더링**

Aspose.Slides for Python via Java는 미리 보기 및 기타 시각 출력용으로 래스터 또는 벡터 이미지로 고품질 슬라이드 렌더링을 제공합니다. 또한 슬라이드의 이미지를 렌더링할 수 있습니다. 사용 가능한 이미지 형식 및 내보내기 참고 사항은 [지원 파일 형식](/slides/ko/python-java/supported-file-formats/#supported-file-formats)을 참조하십시오.

## **콘텐츠 기능**

Aspose.Slides for Python via Java를 사용하면 아래에 설명된 거의 모든 종류의 프레젠테이션 콘텐츠에 액세스하고, 수정하고, 생성할 수 있습니다.

|**기능**|**설명**|
| :- | :- |
|Presentations|새 프레젠테이션을 처음부터 만들거나 기존 파일을 열 수 있습니다.|
|Document Properties|문서 속성을 읽고 수정할 수 있습니다.|
|Presentation Protection|비밀번호 보호를 적용하고 프레젠테이션 보호 설정을 관리할 수 있습니다.|
|Master Slides|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for Python via Java를 사용하면 프레젠테이션의 마스터 슬라이드에 액세스하고 수정할 수 있습니다.|
|Normal Slides|프레젠테이션에서 슬라이드를 추가, 액세스, 편집, 순서 변경 및 삭제할 수 있습니다.|
|Slide Layouts|슬라이드 레이아웃을 작업할 수 있습니다.|
|Cloning and Copying Slides|내장 메서드를 사용하면 프레젠테이션 내 또는 프레젠테이션 간에 슬라이드를 복제하거나 복사할 수 있습니다. 슬라이드를 복제할 때 관련 마스터 슬라이드가 자동으로 복사됩니다.|
|Slide Sections|프레젠테이션 내에서 슬라이드를 섹션으로 구성할 수 있습니다.|
|Placeholders and Text Holders|슬라이드의 플레이스홀더와 텍스트 홀더에 액세스하고, 새 슬라이드를 텍스트 홀더와 함께 처음부터 만들 수 있습니다.|
|Headers and Footers|Aspose.Slides for Python via Java를 사용하면 머리글과 바닥글을 관리할 수 있습니다.|
|Slide Notes|슬라이드 노트를 액세스, 추가 및 수정할 수 있으며, PDF 또는 TIFF로 내보낼 때 포함할 수 있습니다.|
|Finding a Shape|대체 텍스트를 사용하여 슬라이드에서 특정 도형을 찾을 수 있습니다.|
|Alternative Text|도형의 대체 텍스트를 읽고 업데이트할 수 있습니다.|
|Hyperlinks|도형의 하이퍼링크를 읽고 업데이트하고, 텍스트에 하이퍼링크를 추가할 수 있습니다.|
|Backgrounds|프레젠테이션의 마스터 슬라이드 및 일반 슬라이드 배경을 작업할 수 있습니다.|
|Text Boxes|텍스트 상자를 처음부터 만들고, 기존 텍스트 상자에 액세스하며, 원래 서식을 보존하면서 텍스트를 수정할 수 있습니다.|
|Rectangle Shapes|사각형 도형을 만들고 수정할 수 있습니다.|
|Line Shapes|선 도형을 만들고 수정할 수 있습니다.|
|Polyline Shapes|폴리라인 도형을 만들고 수정할 수 있습니다.|
|Ellipse Shapes|타원 도형을 만들고 수정할 수 있습니다.|
|Group Shapes|Aspose.Slides for Python via Java는 그룹 도형을 지원합니다.|
|AutoShapes|Aspose.Slides for Python via Java는 AutoShapes를 지원합니다.|
|SmartArt|프레젠테이션에서 SmartArt 도형을 만들고 편집할 수 있습니다.|
|Charts|PowerPoint 프레젠테이션에서 Microsoft Office 차트를 만들고 편집할 수 있습니다.|
|Shape Serialization|Aspose.Slides for Python via Java는 많은 도형 유형을 지원합니다. 지원되지 않는 도형은 직렬화를 사용하여 기존 슬라이드의 도형을 보존하고 재사용할 수 있습니다.|
|Shape Locks|편집 작업을 제한하기 위해 도형 잠금을 적용할 수 있습니다.|
|Picture Frames|그림 프레임 내의 사진을 관리할 수 있습니다.|
|Audio Frames|슬라이드의 오디오 프레임에 오디오 파일을 연결하거나 내장할 수 있습니다.|
|Video Frames|비디오 프레임에서 연결된 비디오와 내장된 비디오를 관리할 수 있습니다.|
|OLE Frames|OLE 프레임에서 OLE 개체를 관리할 수 있습니다.|
|Tables|표를 만들고, 이동하고, 크기를 조정할 수 있으며; 행과 열을 추가, 삭제, 크기 조정하고, 셀 내용, 테두리, 채우기 및 텍스트 서식을 읽고 수정할 수 있습니다.|
|ActiveX Controls|Aspose.Slides for Python via Java는 ActiveX 컨트롤을 지원합니다.|
|VBA Macros|프레젠테이션에서 VBA 매크로를 관리할 수 있습니다.|
|Text Frames|도형에 연결된 텍스트 프레임을 통해 텍스트에 접근하고 텍스트 프레임 여백 및 텍스트 워핑을 조정할 수 있습니다.|
|Fonts|프레젠테이션에서 사용되는 글꼴을 관리할 수 있습니다.|
|Text Scanning|내장 메서드를 사용하면 전체 프레젠테이션 또는 개별 슬라이드에서 텍스트를 스캔할 수 있습니다.|
|Animations|도형에 애니메이션 효과를 추가하고 수정할 수 있습니다.|
|Slide Shows|Aspose.Slides for Python via Java는 슬라이드 쇼와 슬라이드 전환을 지원하며, Morph 전환도 포함됩니다.|

## **서식 지정 기능**

Aspose.Slides for Python via Java를 사용하면 프레젠테이션 슬라이드의 텍스트와 도형을 아래와 같이 서식 지정할 수 있습니다.

|**기능**|**설명**|
| :- | :- |
|Text Formatting|<p>도형에 연결된 텍스트 프레임을 통해 텍스트를 관리하고 개별 단락 및 텍스트 부분을 서식 지정할 수 있습니다. 다음 서식 옵션을 사용할 수 있습니다:</p><p>- 글꼴 종류</p><p>- 글꼴 크기</p><p>- 글꼴 색상</p><p>- 글꼴 음영</p><p>- 단락 정렬</p><p>- 단락 들여쓰기 및 탭</p><p>- 단락 글머리표</p><p>- 단락 방향</p>|
|Shape Formatting|<p>도형은 슬라이드의 기본 요소입니다. 다음 도형 속성을 조정할 수 있습니다:</p><p>- 위치</p><p>- 크기</p><p>- 회전</p><p>- 선 스타일</p><p>- 채우기(단색, 그라데이션, 패턴, 텍스처 및 그림 채우기 포함)</p><p>- 텍스트</p><p>- 이미지</p>|
