## **지원되는 플랫폼**
Aspose.Slides for Python via Java는 플랫폼에 독립적인 API입니다. Python 3.7 이상이 설치된 모든 플랫폼(Windows, Linux, macOS 등)에서 사용할 수 있습니다. JDK 8 이상이 또 다른 요구 사항입니다.

## **파일 형식 및 변환**
Aspose.Slides for Python via Java는 대부분의 PowerPoint 문서 형식을 지원합니다. 또한 조직에서 사용하고 공유하는 인기 있는 파일 형식으로 내보낼 수 있습니다. 다음 세부 정보를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java는 이 프레젠테이션 문서 형식에 대해 가장 빠른 처리를 제공합니다.|
|PPT to PPTX conversion|Aspose.Slides for Python via Java는 PPT를 PPTX로 변환을 지원합니다.|
|Portable Document Format (PDF)|Adobe Portable Document Format (PDF) 문서로 모든 지원되는 파일 형식을 단일 메서드로 내보낼 수 있습니다.|
|XML Parser Specification (XPS)|XML Parser Specification (XPS) 문서로 모든 지원되는 파일 형식을 단일 메서드로 내보낼 수 있습니다.|
|Tagged Image File Format (TIFF)|지원되는 모든 프레젠테이션 파일 형식을 Tagged Image File Format (TIFF)으로 내보낼 수 있습니다.|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java는 PresentationEx를 HTML 형식으로 변환을 지원합니다.|

## **프레젠테이션 렌더링**
Aspose.Slides for Python via Java는 프레젠테이션 슬라이드를 다양한 그래픽 형식으로 높은 정확도로 렌더링을 지원합니다. 다음 세부 정보를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|Java 지원 이미지 형식|Aspose.Slides for Python via Java를 사용하면 TIFF, PNG, BMP, JPEG, GIF와 같은 모든 Java 지원 그래픽 형식으로 프레젠테이션 슬라이드와 슬라이드의 이미지를 렌더링할 수 있습니다.|
|SVG Format|Aspose.Slides for Python via Java는 또한 프레젠테이션 슬라이드를 Scalable Vector Graphics (SVG) 형식으로 내보낼 수 있는 기본 제공 메서드를 제공합니다.|

## **콘텐츠 기능**
Aspose.Slides for Python via Java를 사용하면 프레젠테이션 문서의 거의 모든 항목이나 내용을 접근, 수정 또는 생성할 수 있습니다. 다음 세부 정보를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|마스터 슬라이드|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for Python via Java를 사용하면 프레젠테이션 문서의 마스터 슬라이드에 접근하고 수정할 수 있습니다.|
|일반 슬라이드|Aspose.Slides for Python via Java를 사용하면 다양한 유형의 새 슬라이드를 만들 수 있으며, 프레젠테이션의 기존 슬라이드에도 접근하고 수정할 수 있습니다.|
|슬라이드 복제/복사|Aspose.Slides for Python via Java에서 제공하는 기본 메서드를 사용하면 프레젠테이션 내 기존 슬라이드를 복제하거나 복사할 수 있습니다. 복제 및 복사된 슬라이드를 한 프레젠테이션에서 다른 프레젠테이션으로 사용할 수도 있습니다. 슬라이드는 마스터 슬라이드에서 레이아웃을 상속받기 때문에, 기본 복제 메서드는 복제 시 마스터도 자동으로 복사합니다.|
|슬라이드 섹션 관리|프레젠테이션 내부에서 슬라이드를 다양한 섹션으로 구성하는 메서드.|
|플레이스홀더 및 텍스트 홀더|슬라이드의 플레이스홀더와 텍스트 홀더에 접근할 수 있습니다. 또한 적절한 메서드를 사용하여 텍스트 홀더가 있는 슬라이드를 처음부터 만들 수 있습니다.|
|머리글 및 바닥글|Aspose.Slides for Python via Java는 슬라이드의 머리글/바닥글 처리를 용이하게 합니다.|
|슬라이드 노트|Aspose.Slides for Python via Java를 사용하면 슬라이드와 연결된 노트에 접근하고 수정할 수 있으며 새 노트를 추가할 수도 있습니다.|
|도형 찾기|도형에 연결된 대체 텍스트를 사용하여 슬라이드에서 특정 도형을 찾을 수 있습니다.|
|배경|Aspose.Slides for Python via Java는 프레젠테이션의 마스터 또는 일반 슬라이드와 연결된 배경을 작업할 수 있게 합니다.|
|텍스트 상자|텍스트 상자를 처음부터 만들 수 있습니다. 기존 텍스트 상자에 접근할 수 있으며 원래 텍스트 서식을 잃지 않고 텍스트를 수정할 수도 있습니다.|
|사각형 도형|Aspose.Slides for Python via Java를 사용하여 사각형 도형을 만들거나 수정할 수 있습니다.|
|폴리라인 도형|Aspose.Slides for Python via Java를 사용하여 폴리라인 도형을 만들거나 수정할 수 있습니다.|
|타원 도형|Aspose.Slides for Python via Java를 사용하여 타원 도형을 만들거나 수정할 수 있습니다.|
|그룹 도형|Aspose.Slides for Python via Java는 그룹 도형을 지원합니다.|
|자동 도형|Aspose.Slides for Python via Java는 자동 도형을 지원합니다.|
|SmartArt|Aspose.Slides for Python via Java는 MS PowerPoint의 SmartArt 도형을 지원합니다.|
|차트|Aspose.Slides for Python via Java는 PowerPoint의 MSO 차트를 지원합니다.|
|도형 직렬화|Aspose.Slides for Python via Java는 많은 도형을 지원합니다. 지원되지 않는 도형이 있을 경우 기존 슬라이드에서 해당 도형을 직렬화하는 방법을 사용하여 직렬화할 수 있습니다. 이를 통해 필요에 따라 해당 도형을 재사용할 수 있습니다.|
|그림 프레임|Aspose.Slides for Python via Java를 사용하면 그림 프레임 내의 이미지를 관리할 수 있습니다.|
|오디오 프레임|Aspose.Slides for Python via Java를 사용하면 슬라이드의 오디오 프레임에 오디오 파일을 링크하거나 삽입할 수 있습니다.|
|비디오 프레임|비디오 파일을 비디오 프레임에서 처리할 수 있습니다. Aspose.Slides for Python via Java는 링크된 비디오와 삽입된 비디오를 모두 지원합니다.|
|OLE 프레임|Aspose.Slides for Python via Java를 사용하면 OLE 프레임에서 OLE 개체를 관리할 수 있습니다.|
|테이블|Aspose.Slides for Python via Java는 슬라이드의 테이블을 지원합니다.|
|ActiveX 컨트롤|ActiveX 컨트롤을 지원합니다.|
|VBA 매크로|프레젠테이션 내부의 VBA 매크로 관리 지원.|
|텍스트 프레임|해당 도형과 연결된 텍스트 프레임을 통해 모든 도형의 텍스트에 접근할 수 있습니다.|
|텍스트 스캔|내장 스캔 메서드를 통해 프레젠테이션 수준 또는 슬라이드 수준에서 텍스트를 스캔할 수 있습니다.|
|애니메이션|도형에 애니메이션을 적용할 수 있습니다.|
|슬라이드 쇼|Aspose.Slides for Python via Java는 슬라이드 쇼와 슬라이드 전환을 지원합니다.|

## **서식 기능**
Aspose.Slides for Python via Java를 사용하면 프레젠테이션 슬라이드의 텍스트와 도형을 서식 지정할 수 있습니다. 다음 세부 정보를 확인하십시오:

|**기능**|**설명**|
| :- | :- |
|텍스트 서식|<p>Aspose.Slides for Python via Java에서는 도형에 연결된 텍스트 프레임을 통해 텍스트를 관리할 수 있습니다. 따라서 텍스트 프레임에 연결된 단락과 구성을 사용하여 텍스트를 서식 지정할 수 있습니다. 이러한 텍스트 요소는 Aspose.Slides for Python via Java를 통해 서식 지정할 수 있습니다.</p><p>- 글꼴 유형</p><p>- 글꼴 크기</p><p>- 글꼴 색상</p><p>- 글꼴 음영</p><p>- 단락 정렬</p><p>- 단락 글머리표</p><p>- 단락 방향</p>|
|도형 서식|<p>Aspose.Slides for Python via Java에서 슬라이드의 기본 요소는 도형입니다. Aspose.Slides for Python via Java를 사용하여 이러한 도형 요소를 서식 지정할 수 있습니다:</p><p>- 위치</p><p>- 크기</p><p>- 선</p><p>- 채우기(패턴, 그라디언트, 단색 포함)</p><p>- 텍스트</p><p>- 이미지</p>|
