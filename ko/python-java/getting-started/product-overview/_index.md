## **제품 설명**

Aspose.Slides for Python via Java은 Python 애플리케이션에서 프레젠테이션을 생성, 읽기, 편집, 변환 및 렌더링하기 위한 라이브러리입니다. Microsoft PowerPoint와 OpenDocument 프레젠테이션 형식을 지원하며 Microsoft PowerPoint를 설치할 필요가 없습니다.

이 라이브러리는 JPype를 통해 Aspose.Slides for Java 엔진을 사용하여 Python을 Java Virtual Machine (JVM)에 연결합니다. 지원되는 운영 체제 및 종속성은 [System Requirements](/slides/ko/python-java/system-requirements/)에서 확인하고, 설치 방법은 [Installation](/slides/ko/python-java/installation/)에서 확인하십시오.

### **Aspose.Slides for Python via Java를 사용해야 하는 이유**

- **프레젠테이션 워크플로 자동화:** 애플리케이션 데이터에서 보고서를 생성하고, 기존 프레젠테이션을 업데이트하며, 여러 파일의 슬라이드를 결합합니다.
- **프레젠테이션 콘텐츠 편집:** 슬라이드, 텍스트, 도형, 표, 차트, 이미지, 오디오 및 비디오를 다룹니다.
- **프레젠테이션 변환 및 미리보기:** 프레젠테이션을 PDF 및 HTML로 내보내거나 개별 슬라이드를 이미지로 렌더링하여 미리볼 수 있습니다.
- **애플리케이션 내 파일 처리:** Python 스크립트, 데스크톱 애플리케이션 또는 서버 애플리케이션에 프레젠테이션 처리를 통합합니다.

자세한 기능 목록은 [Features Overview](/slides/ko/python-java/features-overview/)를 확인하십시오. 지원되는 입력 및 출력 형식은 [Supported File Formats](/slides/ko/python-java/supported-file-formats/)에서 확인할 수 있습니다.

## **FAQ**

**Microsoft PowerPoint를 설치해야 합니까?**

아니요. Aspose.Slides는 프레젠테이션 파일을 직접 처리하므로 애플리케이션이 실행되는 머신에 Microsoft PowerPoint가 필요하지 않습니다.

**왜 Python 라이브러리가 Java가 필요합니까?**

Aspose.Slides for Python via Java는 JPype를 통해 Java 프레젠테이션 처리 엔진을 사용합니다. 호환되는 Python, Java 및 JPype 버전은 [System Requirements](/slides/ko/python-java/system-requirements/)에서 확인하십시오.

**프레젠테이션을 변환하고 슬라이드 미리보기를 생성할 수 있습니까?**

예. 프레젠테이션을 PDF, HTML 등 다양한 형식으로 내보낼 수 있으며, 개별 슬라이드를 PNG 또는 JPEG와 같은 이미지로 렌더링할 수 있습니다. 형식별 지원 여부는 [Supported File Formats](/slides/ko/python-java/supported-file-formats/)에서 확인하십시오.

**라이선스를 구매하기 전에 라이브러리를 평가할 수 있습니까?**

예. 평가 패키지를 사용하거나 임시 라이선스를 요청하여 제한 없이 테스트할 수 있습니다. 자세한 내용은 [Evaluate Aspose.Slides](/slides/ko/python-java/evaluate-aspose-slides/)를 참고하십시오.
