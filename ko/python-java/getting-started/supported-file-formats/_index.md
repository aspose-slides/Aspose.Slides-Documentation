## **개요**

Aspose.Slides for Python via Java은 PowerPoint 및 OpenDocument 프레젠테이션을 읽고 씁니다. 또한 PDF 및 HTML 콘텐츠를 슬라이드로 가져오고 프레젠테이션 또는 개별 슬라이드를 문서, 웹 및 이미지 형식으로 내보냅니다.

아래 표는 프레젠테이션 로드와 콘텐츠 가져오기 및 슬라이드 렌더링을 구분합니다. 편집 및 렌더링 기능에 대한 개요는 [Features Overview](/slides/ko/python-java/features-overview/)를 참조하십시오.

## **가져오기 및 내보내기 참고 사항**

- **PDF 및 HTML 가져오기:** [SlideCollection.addFromPdf](https://reference.aspose.com/slides/ko/python-java/aspose.slides/slidecollection/#addfrompdf) 또는 [SlideCollection.addFromHtml](https://reference.aspose.com/slides/ko/python-java/aspose.slides/slidecollection/#addfromhtml)을 사용하여 소스 콘텐츠에서 슬라이드를 생성하고 이를 프레젠테이션에 추가합니다.
- **프레젠테이션 출력:** [SaveFormat](https://reference.aspose.com/slides/ko/python-java/aspose.slides/saveformat/)은 사용 가능한 프레젠테이션 저장 형식을 나열하며, 별도의 HTML 및 HTML5 내보내기 옵션을 포함합니다.
- **이미지 출력:** 슬라이드를 이미지로 내보내면 해당 슬라이드의 시각적 표현이 생성됩니다. 입력 열은 이미지가 프레젠테이션에 삽입될 수 있는지 여부를 설명하지 않습니다.

## **FAQ**

**PPT 프레젠테이션을 PPTX 또는 ODP로 변환할 수 있나요?**

예. PPT는 입력 형식으로 지원되며, PPTX와 ODP 모두 출력 형식으로 지원됩니다. 변환 결과는 대상 형식에서 사용할 수 있는 기능에 따라 달라집니다.

**PDF 또는 HTML 가져오기가 소스를 PowerPoint 파일로 열나요?**

아니오. 가져오기는 PDF 페이지나 HTML 콘텐츠에서 슬라이드를 생성합니다. 그런 다음 결과 프레젠테이션을 지원되는 형식으로 저장할 수 있습니다.

**내보낸 PNG 또는 SVG를 편집 가능한 프레젠테이션으로 로드할 수 있나요?**

아니오. 이러한 내보내기는 슬라이드 모양을 나타냅니다. 텍스트, 도형, 차트 및 기타 개체를 나중에 편집해야 할 경우 원본 프레젠테이션을 유지하십시오.
