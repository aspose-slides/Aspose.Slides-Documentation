## **개요**

이 섹션에서는 환경을 준비하고 Aspose.Slides for Python via Java를 시작하는 방법을 안내합니다. 아래 설정 단계를 따라 진행한 후 라이브러리 기능과 프로젝트와 관련된 가이드를 살펴보세요.

## **라이브러리 설정**

1. 운영 체제, Python, Java 및 JPype 요구 사항을 확인하려면 [System Requirements](/slides/ko/python-java/system-requirements/)를 검토하십시오.
2. 필요한 패키지를 설치하고 예제를 통해 설정을 확인하려면 [Installation](/slides/ko/python-java/installation/) 가이드를 따르십시오.
3. 평가 제한 및 임시 라이선스 옵션을 이해하려면 [Evaluate Aspose.Slides](/slides/ko/python-java/evaluate-aspose-slides/)를 읽으십시오.
4. 라이선스를 적용하려면 [Licensing](/slides/ko/python-java/licensing/) 가이드를 따르십시오.

## **기능 및 호환성 살펴보기**

- [Product Overview](/slides/ko/python-java/product-overview/)는 라이브러리와 프레젠테이션 처리 기능을 소개합니다.
- [Supported File Formats](/slides/ko/python-java/supported-file-formats/)는 프레젠테이션을 로드, 가져오기, 저장 및 내보내기에 사용할 수 있는 형식을 나열합니다.
- [Features Overview](/slides/ko/python-java/features-overview/)는 변환, 렌더링, 편집 및 서식 지정 기능을 요약합니다.
- [Limitations and API Differences](/slides/ko/python-java/limitations-and-api-differences/)는 Python에서 Java API를 사용할 때 고려해야 할 제한 사항 및 차이점을 설명합니다.

## **지원 받기**

문제 해결 가이드, 이슈 보고 절차 및 추가 리소스 링크는 [Product Support](/slides/ko/python-java/product-support/)를 참조하십시오.

## **FAQ**

**Aspose.Slides for Python via Java를 처음 사용하는 경우 어디서 시작해야 할까요?**

위에 링크된 [System Requirements]와 [Installation] 가이드부터 시작하십시오. 설치 가이드에는 환경을 확인할 수 있는 예제가 포함되어 있습니다.

**라이브러리가 내 프레젠테이션 형식을 지원하는지 어디에서 확인할 수 있나요?**

[Supported File Formats]를 사용하여 입력 및 출력 형식을 확인하고, 작업에 사용할 수 있는 기능은 [Features Overview]를 참조하십시오.

**Java 예제를 Python에 적용하기 전에 무엇을 읽어야 하나요?**

Python via Java에서의 import, 리소스 정리 및 파일 처리에 대한 가이드는 [Limitations and API Differences]를 읽으십시오.
