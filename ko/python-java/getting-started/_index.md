## **개요**

이 섹션은 환경을 준비하고 [Aspose.Slides for Python via Java](https://products.aspose.com/slides/python-java/) 사용을 시작하도록 도와줍니다. 아래 설정 단계를 따라 진행한 후, 라이브러리의 기능과 프로젝트에 관련된 안내를 살펴보세요.

## **라이브러리 설정**

1. [시스템 요구 사항](/slides/ko/python-java/system-requirements/)을 검토하여 운영 체제, Python, Java 및 JPype 요구 사항을 확인합니다.
2. [설치](/slides/ko/python-java/installation/) 가이드를 따라 필요한 패키지를 설치하고 예제를 통해 설정을 확인합니다.
3. [Aspose.Slides 평가](/slides/ko/python-java/evaluate-aspose-slides/)를 읽어 평가 제한 사항 및 임시 라이선스 옵션을 이해합니다.
4. [라이선스](/slides/ko/python-java/licensing/) 가이드를 따라 라이선스를 적용합니다.

## **기능 및 호환성 탐색**

- [제품 개요](/slides/ko/python-java/product-overview/)는 라이브러리와 프레젠테이션 처리 기능을 소개합니다.
- [지원 파일 형식](/slides/ko/python-java/supported-file-formats/)은 프레젠테이션 로드, 가져오기, 저장 및 내보내기에 사용할 수 있는 형식을 나열합니다.
- [기능 개요](/slides/ko/python-java/features-overview/)는 변환, 렌더링, 편집 및 서식 지정 기능을 요약합니다.
- [제한 사항 및 API 차이점](/slides/ko/python-java/limitations-and-api-differences/)은 Python에서 Java API를 사용할 때 고려해야 할 제한 사항과 차이점을 설명합니다.

## **FAQ**

**Aspose.Slides for Python via Java를 처음 사용하는 경우 어디서 시작해야 할까요?**

위에 링크된 시스템 요구 사항 및 설치 가이드부터 시작하세요. 설치 가이드에는 환경을 확인할 수 있는 예제가 포함되어 있습니다.

**라이브러리가 내 프레젠테이션 형식을 지원하는지 어디에서 확인할 수 있나요?**

지원 파일 형식을 사용하여 입력 및 출력 형식을 확인하고, 기능 개요에서 작업에 사용할 수 있는 기능을 확인하세요.

**Java 예제를 Python에 적용하기 전에 무엇을 읽어야 할까요?**

Python을 통해 Java를 사용할 때의 임포트, 리소스 정리 및 파일 처리에 대한 안내를 위해 제한 사항 및 API 차이점을 읽으세요.
