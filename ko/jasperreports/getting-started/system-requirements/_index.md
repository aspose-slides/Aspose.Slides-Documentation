## **JasperReports**

Aspose.Slides for JasperReports는 JasperReports 3.7.2부터 6.16.0까지 작동합니다. 다운로드에는 세 가지 버전 범위마다 별도의 jar 파일이 제공됩니다 — 어느 것을 사용할지 보려면 [Installing Aspose.Slides for JasperReports](/slides/ko/jasperreports/installing-aspose-slides-for-jasperreports/)를 참고하세요. JasperReports 6.17.0 이상(또는 JasperReports 7 포함)용 jar 파일은 제공되지 않습니다.

JasperReports 2.0.3부터 3.7.1까지에 대한 지원은 Aspose.Slides for JasperReports 17.6에서 종료되었습니다. 버전 17.5 이전도 해당 버전들을 지원했습니다.

## **Java**

jar 파일은 폴더 이름에 *JDK 1.6*이 표시된 대로 Java 6 이상을 대상으로 컴파일되었습니다. 따라서 필요한 Java 버전은 사용 중인 JasperReports 버전이 요구하는 버전과 동일합니다. JasperReports 6.16.0에서는 내보내기가 Java 11, 17, 21 및 25에서 실행됩니다.

## **Operating system**

jar 파일에는 Java 클래스와 리소스만 포함되어 있으며 네이티브 라이브러리가 없고 Microsoft PowerPoint를 사용하지 않습니다. Linux에서는 JasperReports가 보고서를 채우기 위해 fontconfig와 최소 하나 이상의 설치된 글꼴이 필요합니다.

## **JasperReports Server**

JasperReports Server의 경우, 서버가 실행 중인 JasperReports 버전에 맞는 폴더에서 두 개의 jar 파일을 모두 사용하세요 — [Integration with JasperServer](/slides/ko/jasperreports/integration-with-jasperserver/).
