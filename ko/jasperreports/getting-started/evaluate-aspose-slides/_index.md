평가용으로 Aspose.Slides for JasperReports를 [download page](https://releases.aspose.com/slides/ko/jasperreport/)에서 다운로드할 수 있습니다. 평가용 다운로드는 라이선스 버전과 동일하며, 라이선스를 적용하면 라이선스가 적용됩니다. 자세한 내용은 [Licensing](/slides/ko/jasperreports/licensing/)를 참조하십시오.

라이선스가 없을 경우, 익스포터는 여전히 보고서의 모든 페이지를 내보내지만 각 슬라이드 또는 페이지 중앙에 평가 워터마크를 삽입합니다. 워터마크에는 "Evaluation only.", "Created with Aspose.Slides for JasperReports"와 제품 버전, 그리고 저작권 문구가 표시됩니다. 이 워터마크는 PPT, PPTX, PDF, HTML 네 가지 출력 형식 모두에 나타납니다.

![라이선스 없이 내보낸 보고서, 슬라이드 중앙에 평가 워터마크가 표시된 모습](evaluate-aspose-slides_1.png)

{{% alert color="info" title="Note" %}}
평가 워터마크 없이 Aspose.Slides for JasperReports를 테스트하려면 30일 임시 라이선스를 요청하십시오.{{% /alert %}}
