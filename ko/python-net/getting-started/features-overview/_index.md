## **지원 플랫폼**
Aspose.Slides for Python via .NET은 Windows x64 또는 x86 및 Python 3.5 이상이 설치된 다양한 Linux 배포판에서 사용할 수 있습니다. 대상 Linux 플랫폼에는 추가 요구 사항이 있습니다:
- GCC-6 런타임 라이브러리(또는 이후 버전)
- .NET Core 런타임의 종속성. .NET Core 런타임 자체를 설치할 필요는 없습니다
- Python 3.5-3.7 용: `pymalloc` 빌드의 Python이 필요합니다. `--with-pymalloc` Python 빌드 옵션은 기본적으로 활성화되어 있습니다. 일반적으로 `pymalloc` 빌드의 Python은 파일 이름에 `m` 접미사가 붙어 있습니다.
- `libpython` 공유 Python 라이브러리. `--enable-shared` Python 빌드 옵션은 기본적으로 비활성화되어 있으며, 일부 Python 배포판에는 `libpython` 공유 라이브러리가 포함되어 있지 않을 수 있습니다. 일부 Linux 플랫폼에서는 패키지 관리자를 사용하여 `libpython` 공유 라이브러리를 설치할 수 있습니다. 예: `sudo apt-get install libpython3.7`. 일반적인 문제는 `libpython` 라이브러리가 표준 시스템 공유 라이브러리 위치와 다른 곳에 설치된다는 점입니다. 이 문제는 Python을 컴파일할 때 빌드 옵션으로 대체 라이브러리 경로를 설정하거나, 시스템 표준 위치에 `libpython` 라이브러리 파일에 대한 심볼릭 링크를 생성하여 해결할 수 있습니다. 일반적으로 `libpython` 공유 라이브러리 파일 이름은 Python 3.5-3.7의 경우 `libpythonX.Ym.so.1.0`, Python 3.8 이후의 경우 `libpythonX.Y.so.1.0`(예: `libpython3.7m.so.1.0`, `libpython3.9.so.1.0`)입니다.

더 많은 플랫폼 지원이 필요하면 Aspose.Slides for .NET 또는 Aspose.Slides for Java와 같은 “쌍둥이” 제품을 확인하십시오.

## **FAQ**

### 라이브러리를 사용하기 위해 서버/PC에 Microsoft PowerPoint를 설치해야 합니까?

아니요. PowerPoint는 필요하지 않으며, Aspose.Slides는 프레젠테이션을 만들고, 편집하고, 변환하고, 렌더링하기 위한 독립 실행형 엔진입니다.

### 멀티스레딩은 어떻게 작동합니까? 처리를 병렬화할 수 있나요?

다른 스레드에서 서로 다른 문서를 처리하는 것은 안전합니다. 동일한 [presentation](https://reference.aspose.com/slides/ko/python-net/aspose.slides/presentation/) 객체를 [multiple threads](/slides/ko/python-net/multithreading/)가 동시에 사용해서는 안 됩니다.

### 파일 비밀번호 및 암호화가 지원됩니까?

예. [You can](/slides/ko/python-net/password-protected-presentation/) 암호화된 프레젠테이션을 열고, 열기 및 쓰기 비밀번호를 설정하거나 제거하고, 보호 상태를 확인할 수 있습니다.

### Linux 컨테이너에서 폰트 패키지를 신경 써야 합니까?

예. 일반적인 폰트 패키지를 설치하거나 애플리케이션에서 [specify font directories](/slides/ko/python-net/custom-font/)를 명시적으로 지정하여 예기치 않은 폰트 대체를 방지하는 것이 권장됩니다.

### 평가 버전에 제한이 있습니까?

[평가 모드](/slides/ko/python-net/licensing/)에서는 출력에 워터마크가 추가되고 일부 제한이 적용됩니다; 전체 기능 테스트를 위해 [30일 임시 라이선스](https://purchase.aspose.com/temporary-license/)를 사용할 수 있습니다.

### 외부 형식(PDF/HTML → PPTX)을 프레젠테이션에 가져오는 것이 지원됩니까?

예. [PDF 페이지 및 HTML 콘텐츠](/slides/ko/python-net/import-presentation/)를 프레젠테이션에 추가하여 슬라이드로 변환할 수 있습니다.
