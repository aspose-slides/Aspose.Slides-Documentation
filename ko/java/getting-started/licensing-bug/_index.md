{{% alert color="info" title="Note" %}}
이 페이지는 과거의 페이지입니다. 2023년에 릴리스된 Aspose.Slides for Java 버전 23.2부터 23.7까지의 버그와 이를 수정한 버전에 대해 설명합니다. 현재 버전에 대해서는 설명하지 않습니다. 현재 버전의 라이선싱에 대해서는 [Licensing](/slides/ko/java/licensing/)을 참조하십시오.
{{% /alert %}}

## **개요**

이 문서에서는 Aspose.Slides for Java 버전 23.2, 23.3, 23.4, 23.5, 23.6 및 23.7에서 발생한 라이선스 버그에 대해 설명합니다. 이 버그로 인해 영구 라이선스가 구독이 만료된 후 일시적으로 사용할 수 없게 됩니다.

## **증상**

영구 라이선스 구독이 만료된 후, Aspose.Slides for Java 버전 23.2 - 23.7에서는 라이선스가 만료된 것으로 보고 모든 기능이 평가 모드로 전환될 수 있습니다. 이 동작은 올바르지 않으며 23.2 이전 및 23.7 이후 버전에는 영향을 주지 않습니다.

## **해결 방법**

Aspose.Slides for Java는 이 문제를 해결하고 수정이 포함된 업데이트된 버전(23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1)을 릴리스했습니다.

프로젝트에서 영향을 받는 Aspose.Slides for Java 버전을 사용 중이라면, 수정된 버전으로 전환해 주세요.

Aspose.Slides for Java에서 라이선스 문제가 발생하는 경우:
- 사용 중인 버전을 확인하고 위에서 설명한 버그의 영향을 받지 않는지 확인하십시오.
- 라이선스를 적용하고 검증하는 방법은 [Licensing](/slides/ko/java/licensing/)을 참조하십시오.
- 추가 지원이 필요하면 [Aspose support](https://forum.aspose.com/c/slides/ko/11)에 문의하십시오.

## **영향을 받는 제품 및 버전**

이 버그는 Aspose.Slides for Java 버전 23.2부터 23.7까지에만 영향을 미칩니다. **다른 Aspose 제품 및 Aspose.Slides의 다른 버전은 영향을 받지 않습니다**.
