## **지원되는 플랫폼**
Aspose.Slides for Java는 가장 많이 사용되는 개발 및 배포 플랫폼을 지원합니다.

|**기능**|**설명**|
| :- | :- |
|데스크톱 애플리케이션|Aspose.Slides for Java를 사용하여 Windows Forms 애플리케이션을 개발할 수 있습니다.|
|엔터프라이즈 웹 애플리케이션|Aspose.Slides for Java를 사용하면 웹 애플리케이션을 구축할 수 있습니다. PHP와 함께 Aspose.Slides for Java를 사용하는 것도 지원됩니다.|
|Linux/Unix|Aspose.Slides for Java는 플랫폼에 독립적인 API이며 Linux 및 Unix 환경에서 작동할 수 있습니다.|

## **파일 형식 및 변환**
Aspose.Slides for Java는 대부분의 Microsoft PowerPoint 문서 형식을 지원하며, 이를 조직에서 널리 사용되는 인기 형식으로 내보낼 수 있습니다.

|**기능**|**설명**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/ko/java/microsoft-powerpoint-ppt/)|Aspose.Slides for Java는 이 프레젠테이션 문서 형식에 대해 가장 빠른 처리를 제공합니다.|
|[PresentationML (PPTX, XML)](/slides/ko/java/presentationml-pptx-xml/)|Aspose.Slides for Java는 OOXML 프레젠테이션 형식(또는 PresentationML, PPTX) 처리를 지원합니다.|
|[PPT to PPTX conversion](/slides/ko/java/ppt-to-pptx-conversion/)|Aspose.Slides for Java는 PPT에서 PPTX로의 변환을 지원합니다.|
|[Portable Document Format (PDF)](/slides/ko/java/developer-guide/)|지원되는 파일 형식은 단일 메서드로 Adobe Portable Document Format(PDF) 문서로 내보낼 수 있습니다.|
|[XML Parser Specification (XPS)](/slides/ko/java/xml-parser-specification-xps/)|지원되는 모든 파일 형식은 단일 메서드로 XML Parser Specification(XPS) 문서로 내보낼 수 있습니다.|
|[Tagged Image File Format (TIFF)](https://docs.aspose.com/slides/ko/java/convert-powerpoint-to-tiff/)|Aspose.Slides for Java가 지원하는 프레젠테이션 파일 형식은 Tagged Image File Format(TIFF)으로도 내보낼 수 있습니다.|
|[ODP to PPTX Conversion](https://docs.aspose.com/slides/ko/java/convert-odp-to-pptx/)|Aspose.Slides for Java는 OpenDocument Presentation(ODP)을 로드하고 PPTX로 변환하는 것을 지원합니다.|
|[Presentation To HTML Conversion](https://docs.aspose.com/slides/ko/java/convert-powerpoint-to-html/)|Aspose.Slides for Java는 PresentationEx를 HTML 형식으로 변환하는 것을 지원합니다.|

## **프레젠테이션 렌더링**
Aspose.Slides for Java는 프레젠테이션 슬라이드를 다양한 그래픽 형식으로 고품질 렌더링을 지원합니다:

|**기능**|**설명**|
| :- | :- |
|지원되는 이미지 형식|Aspose.Slides for Java를 사용하면 프레젠테이션 슬라이드뿐 아니라 슬라이드에 포함된 이미지도 TIFF, PNG, BMP, JPEG, GIF 및 메타파일과 같은 인기 있는 지원 그래픽 형식으로 렌더링할 수 있습니다.|
|SVG 형식|Aspose.Slides for Java는 프레젠테이션 슬라이드를 Scalable Vector Graphics(SVG) 형식으로 내보내는 내장 메서드를 제공합니다.|

## **콘텐츠 기능**
Aspose.Slides for Java를 사용하면 프레젠테이션의 거의 모든 콘텐츠에 접근하고, 수정하거나 생성할 수 있습니다.

|**기능**|**설명**|
| :- | :- |
|마스터 슬라이드|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for Java를 사용하면 프레젠테이션의 마스터 슬라이드에 접근하고 수정할 수 있습니다.|
|일반 슬라이드|Aspose.Slides for Java를 사용하면 다양한 유형의 새 슬라이드를 만들 뿐 아니라 기존 슬라이드에 접근하고 수정할 수 있습니다.|
|슬라이드 복제/복사|Aspose.Slides for Java는 프레젠테이션 내뿐 아니라 다른 프레젠테이션 간에도 기존 슬라이드를 복제하거나 복사하는 메서드를 제공합니다. 슬라이드는 마스터 슬라이드의 레이아웃을 상속하므로, 내장 복제 메서드는 복제 시 마스터도 자동으로 복사합니다.|
|슬라이드 섹션 관리|프레젠테이션 내부에서 슬라이드를 다양한 섹션으로 구성할 수 있습니다.|
|플레이스홀더 및 텍스트 홀더|슬라이드의 플레이스홀더와 텍스트 홀더에 접근할 수 있습니다. 또한 적절한 메서드를 사용하여 텍스트 홀더가 있는 슬라이드를 새로 만들 수 있습니다.|
|머리글 및 바닥글|Aspose.Slides for Java는 슬라이드의 머리글/바닥글을 관리하는 기능도 제공합니다.|
|슬라이드 노트|Aspose.Slides for Java를 사용하면 슬라이드에 연결된 노트에 접근하고 수정할 뿐 아니라 노트를 추가할 수도 있습니다.|
|도형 찾기|도형에 연결된 대체 텍스트를 사용하여 슬라이드에서 특정 도형을 찾을 수 있습니다.|
|배경|Aspose.Slides for Java를 사용하면 마스터 슬라이드 또는 일반 슬라이드와 연결된 배경을 작업할 수 있습니다.|
|텍스트 상자|텍스트 상자를 새로 만들 수 있습니다. 기존 텍스트 상자에 접근하고 텍스트를 원래 형식을 잃지 않게 수정할 수 있습니다.|
|사각형 도형|Aspose.Slides for Java를 사용하여 사각형 도형을 만들거나 수정할 수 있습니다.|

|그룹 도형|Aspose.Slides for Java는 그룹 도형을 지원합니다.|

## **FAQ**

### 라이브러리를 사용하려면 서버/PC에 Microsoft PowerPoint를 설치해야 합니까?

아니요. PowerPoint는 필요하지 않으며, Aspose.Slides는 프레젠테이션을 만들고, 편집하고, 변환하고, 렌더링하기 위한 독립 실행형 엔진입니다.

### 멀티스레딩은 어떻게 동작합니까? 처리를 병렬화할 수 있나요?

다른 스레드에서 서로 다른 문서를 처리하는 것은 안전합니다. 동일한 [presentation](https://reference.aspose.com/slides/ko/java/com.aspose.slides/presentation/) 객체를 [multiple threads](/slides/ko/java/multithreading/)와 동시에 사용하면 안 됩니다.

### 파일 암호 및 암호화가 지원됩니까?

예. [가능합니다](/slides/ko/java/password-protected-presentation/) 암호화된 프레젠테이션을 열고, 열기 및 쓰기 암호를 설정하거나 제거하며, 보호 상태를 확인할 수 있습니다.

### Linux 컨테이너에서 폰트 패키지를 신경 써야 합니까?

예. 예기치 않은 대체를 방지하기 위해 일반적인 폰트 패키지를 설치하거나 애플리케이션에서 폰트 디렉터리를 명시적으로 [폰트 디렉터리 지정](/slides/ko/java/custom-font/)하는 것이 권장됩니다.

### 평가 버전에는 제한이 있습니까?

평가 모드[/slides/ko/java/licensing/)에서는 출력에 워터마크가 추가되고 일부 제한이 적용됩니다; 전체 기능 테스트를 위해 [30-day temporary license](https://purchase.aspose.com/temporary-license/)을 사용할 수 있습니다.

### 외부 형식(PDF/HTML → PPTX)을 프레젠테이션으로 가져오는 것이 지원됩니까?

예. [PDF 페이지와 HTML 콘텐츠](/slides/ko/java/import-presentation/)를 프레젠테이션에 추가하여 슬라이드로 변환할 수 있습니다.
