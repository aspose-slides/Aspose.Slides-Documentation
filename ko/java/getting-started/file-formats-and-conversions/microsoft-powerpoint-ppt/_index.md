{{% alert color="info" title="Note" %}}

이 페이지는 기존 링크를 보존하기 위한 역사적 페이지입니다. 현재 버전의 Aspose.Slides for Java에 대한 설명은 아닙니다. Aspose.Slides for Java가 로드, 가져오기, 저장 및 렌더링하는 형식과 각 형식의 API에 대해서는 [Supported File Formats](/slides/ko/java/supported-file-formats/)를 확인하십시오. PPT와 PPTX를 비교하려면 [Understanding the Difference: PPT vs PPTX](/slides/ko/java/ppt-vs-pptx/)를 참조하십시오.

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) 는 다양한 버전의 Microsoft PowerPoint에서 생성, 읽기, 조작 및 작성할 수 있는 프레젠테이션 문서 파일 형식입니다. 이는 Microsoft가 개발한 프레젠테이션 문서의 바이너리 형식입니다.

{{% /alert %}}

## **Aspose.Slides for Java의 PPT**
Aspose.Slides for Java는 아래에 나열된 소프트웨어에서 만든 PPT 파일을 읽을 수 있습니다.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

마찬가지로, Aspose.Slides for Java가 만든 PPT 파일도 위 소프트웨어에서 읽을 수 있습니다.

## **PPT에 대한 포괄적인 지원**
Aspose.Slides for Java는 PPT 문서 파일 형식이 지원하는 거의 모든 기능을 지원합니다. 이는 다양한 Microsoft PowerPoint 버전이 제공하는 기본 및 고급 기능을 포함할 뿐만 아니라 Microsoft PowerPoint조차 지원하지 않는 기능도 포함합니다. Aspose.Slides for Java API 라이브러리를 사용하면 이러한 기능을 손쉽게 처리할 수 있다는 것이 주요 장점입니다.

PPT 문서 파일의 생성, 읽기 및 쓰기와 관련된 기본 작업 외에도 Aspose.Slides for Java가 제공하는 여러 기능이 있습니다:

- 다른 Microsoft Office 파일 형식을 [OLE 객체로 PPT 문서에 가져오기](/slides/ko/java/manage-ole/).
- [PPT 문서를 PDF로 내보내기](/slides/ko/java/convert-powerpoint-to-pdf/).
- PPT 문서의 슬라이드를 SVG 형식으로 내보내기.
- Java 프레임워크가 지원하는 모든 이미지 형식으로 슬라이드를 렌더링합니다.
- PPT 문서에서 슬라이드 크기를 설정합니다.
- 도형의 애니메이션을 관리합니다.
- 슬라이드 쇼를 관리합니다.
- [슬라이드의 텍스트 서식 지정](/slides/ko/java/text-formatting/).
- PPT 문서에서 텍스트를 추출합니다.
- [슬라이드의 표 처리](/slides/ko/java/powerpoint-table/).
- 복제 기능을 사용하여 마스터를 자동으로 복사합니다.
