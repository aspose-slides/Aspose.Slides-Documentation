## **변환에서 지원되는 기능**
Aspose.Slides for Java는 PPT 파일 형식을 PPTX로 변환하는 부분적인 지원을 제공합니다. 변환 지원은 Aspose.Slides for Java에 최근 도입되어 몇 가지 제한이 있으며 단순한 프레젠테이션에 가장 적합합니다. Aspose.Slides for Java가 PPT를 PPTX로 변환할 때 제공하는 주요 장점은 API 사용이 매우 간편하다는 점입니다. 코드 예제를 보려면 [PPT를 PPTX로 변환](/slides/ko/java/convert-ppt-to-pptx/)를 참조하십시오. 아래 목록은 PPT를 PPTX로 변환할 때 지원되는 기능을 보여줍니다.

## **지원되는 기능**
The following features are supported for conversion:

- 마스터, 레이아웃 및 슬라이드 구조 변환.
- 차트 변환.
- 그룹 도형.
- 사각형 및 타원을 포함한 자동 도형 변환.
- 사용자 지정 기하학을 가진 도형.
- 자동 도형에 대한 텍스처 및 이미지 채우기 스타일.
- 플레이스홀더 변환.
- 선 및 폴리라인 변환.
- 선 및 채우기 형식.
- 그라디언트 채우기 스타일.
- OLE 프레임, 표, 비디오 및 오디오 프레임 등.
- 애니메이션 및 슬라이드쇼 속성.
- 텍스트 프레임 및 텍스트 홀더의 텍스트 변환.
