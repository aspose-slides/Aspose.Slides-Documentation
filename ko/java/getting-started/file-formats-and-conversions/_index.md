{{% alert color="info" title="Note" %}}

이 섹션의 문서는 개별 파일 형식에 대한 오래된 개요이며 기존 링크를 위해 보관되어 있습니다. 현재 버전의 Aspose.Slides for Java에 대한 설명은 포함되지 않습니다. Aspose.Slides for Java가 로드하고, 가져오며, 저장하고, 렌더링하는 형식 및 각 형식에 대한 API는 [Supported File Formats](/slides/ko/java/supported-file-formats/)를 참조하십시오. 변환 가이드는 [Convert Presentations](/slides/ko/java/convert-presentation/)를 참조하십시오.

{{% /alert %}}
