## **TIFF에 대하여**

The [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) 은 한 문서에 여러 이미지를 저장할 수 있는 것으로 알려져 있으며 원래 Aldus가 만들었습니다. 이 형식은 스캔, 팩스 및 기타 이미지 처리 애플리케이션에서 널리 지원됩니다.

## **Aspose.Slides for Java의 TIFF**

Aspose.Slides for Java에서 로드할 수 있는 모든 문서는 Aspose.Slides for Java를 통해 직접 TIFF 문서로 변환할 수 있어 제3자 구성 요소가 필요하지 않습니다. 또한 결과 TIFF 문서의 이미지 크기를 선택적으로 지정할 수 있습니다. Aspose.Slides for Java를 사용하여 프레젠테이션 문서를 TIFF 문서로 내보내는 방법에 대한 정보는 [PowerPoint 프레젠테이션을 TIFF로 변환](/slides/ko/java/convert-powerpoint-to-tiff/)에서 확인할 수 있습니다.
