{{% alert color="info" title="Note" %}}

이 페이지는 기존 링크를 위해 보관된 역사적인 페이지입니다. 현재 버전의 Aspose.Slides for Java에 대한 설명이 아닙니다. Aspose.Slides for Java가 로드하고, 가져오고, 저장하고, 렌더링하는 형식 및 각 형식에 대한 API는 [Supported File Formats](/slides/ko/java/supported-file-formats/)를 참조하십시오. 현재 XPS 변환 가이드는 [Convert PowerPoint Presentations to XPS](/slides/ko/java/convert-powerpoint-to-xps/)를 참조하십시오.

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification)는 Microsoft에서 개발한 페이지 설명 언어이자 고정 문서 형식입니다. PDF와 마찬가지로 XPS는 문서의 충실성을 유지하고 장치에 독립적인 문서 모습을 제공하도록 설계되었습니다.

{{% /alert %}}

## **Aspose.Slides for Java에서 XPS**
Aspose.Slides for Java가 로드할 수 있는 모든 프레젠테이션 문서는 XPS 형식으로 변환할 수 있습니다. Aspose.Slides for Java는 고충실도 페이지 레이아웃 및 렌더링 엔진을 사용하여 고정 레이아웃 XPS 문서 형식으로 출력을 생성합니다.
Aspose.Slides for Java를 통해 프레젠테이션 문서를 XPS 문서로 내보내는 방법은 [Convert PowerPoint Presentations to XPS](/slides/ko/java/convert-powerpoint-to-xps/)에서 확인할 수 있습니다.
