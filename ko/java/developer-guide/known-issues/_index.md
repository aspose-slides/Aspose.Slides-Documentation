## **개요**

- [OleObjectFrame 추가 시 개체 미리보기 자리 표시자](/slides/ko/java/object-preview-issue-when-adding-oleobjectframe/)는 Aspose.Slides로 추가된 OLE 개체가 미리보기가 업데이트될 때까지 "EMBEDDED OLE OBJECT" 이미지가 표시되는 이유와 자체 미리보기 이미지를 설정하는 방법을 설명합니다. 이는 현재 버전에서 설계된 동작입니다.
- [Aspose.Slides for Java 14.3.0 (Historical)의 알려진 문제](/slides/ko/java/known-issues-in-aspose-slides-for-java-14-3-0/)와 [Aspose.Slides for Java 14.4.0 (Historical)의 알려진 문제](/slides/ko/java/known-issues-in-aspose-slides-for-java-14-4-0/)는 해당 버전과 함께 게시된 목록이며 참고용으로 유지됩니다.
- 각 버전의 변경 사항 및 수정 내용은 [release notes](https://releases.aspose.com/slides/ko/java/release-notes/)를 참조하십시오. Aspose.Slides가 고정값으로 기록하는 메타데이터 필드는 [Output Metadata Limitations](/slides/ko/java/api-limitations/)에 설명되어 있습니다. 문제가 이미 알려졌는지 확인하거나 보고하려면 [support forum](https://forum.aspose.com/c/slides/ko/11)을 사용하십시오.
