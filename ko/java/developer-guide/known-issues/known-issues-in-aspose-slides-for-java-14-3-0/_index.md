{{% alert color="info" title="Note" %}}

이 페이지는 이전 버전용입니다. Aspose.Slides for Java 14.3.0에 대해 게시된 알려진 문제들을 나열하며 현재 버전에 대해서는 설명하지 않습니다. 각 버전의 변경 사항은 [release notes](https://releases.aspose.com/slides/ko/java/release-notes/)를 참조하십시오.

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0)은 PPT 처리에 대한 완전히 새로운 구현을 제공합니다. 많은 개선 사항과 PPTX에서 PPT로의 부분 변환이 포함됩니다. 그러나 구현되지 않은 기능이 몇 가지 있습니다:

- 일부 도형이 직렬화된 PPT 문서에서 잘못된 기하학을 가집니다(말풍선)
- 모든 PPTX 텍스트 서식 기능이 PPT 직렬화에서 지원되지 않습니다
- 텍스트 언어 및 맞춤법 설정 정보가 직렬화된 PPT 문서에 포함되지 않습니다
- 모든 PPTX 테마 기능이 PPT 직렬화에서 지원되지 않습니다

**Aspose.Slides for Java 8.6.0과 비교했을 때 몇 가지 차이점이 있습니다:**

- OLE/ActiveX PPT 직렬화에서 알려진 문제가 있습니다

**Aspose.Slides for .NET 14.3.0과 비교했을 때 몇 가지 차이점이 있습니다:**

- 현재 Aspose.Slides for Java에서는 프레젠테이션 인쇄 지원이 제공되지 않습니다
