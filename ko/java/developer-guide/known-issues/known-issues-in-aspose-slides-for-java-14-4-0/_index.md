{{% alert color="info" title="Note" %}}

이 페이지는 기록용 페이지입니다. Aspose.Slides for Java 14.4.0에 대해 게시된 제한 사항 및 알려진 문제를 나열하며 현재 버전은 설명하지 않습니다. 각 버전의 변경 사항은 [release notes](https://releases.aspose.com/slides/ko/java/release-notes/)를 확인하십시오.

{{% /alert %}}

Aspose.Slides for Java 14.4.0은 PowerPoint 문서 처리를 위한 새로운 결정을 제공합니다. 일부 제한 사항 및 알려진 문제가 있으며, 이는 향후 릴리스에서 제거될 예정입니다:

- 일부 도형은 직렬화된 PPT 문서에서 잘못된 형상을 가지고 있습니다(호, 원형 화살표, 호출 상자).
- PPT 직렬화에서는 모든 PPTX 텍스트 서식 기능이 지원되지 않습니다(탭, 들여쓰기 및 단락 서식 제한).
- 텍스트 언어 및 맞춤법 설정에 대한 정보가 직렬화된 PPT 문서에 포함되지 않습니다.
- PPT 직렬화에서는 모든 PPTX 테마 기능이 지원되지 않습니다(채우기 형식, 선 형식 및 글꼴 직렬화만 지원).
- OLE/ActiveX PPT를 PPT로 직렬화할 때 알려진 문제가 있습니다.
- WordArt 직렬화 및 렌더링이 지원되지 않습니다.
