{{% alert color="info" %}} 

Aspose.Slides for Java 14.4.0은 PowerPoint 문서 처리를 위한 새로운 결정을 제공합니다. 다음과 같은 제한 사항 및 알려진 문제들이 있으며, 이는 차후 릴리스에서 제거될 예정입니다:

- 일부 도형은 직렬화된 PPT 문서에서 잘못된 기하학을 가지고 있습니다(호, 원형 화살표, 말풍선).
- 모든 PPTX 텍스트 서식 기능이 PPT 직렬화에서 지원되는 것은 아닙니다(탭, 들여쓰기 및 단락 서식 제한).
- 텍스트 언어 및 맞춤법 설정에 대한 정보가 직렬화된 PPT 문서에 없습니다.
- 모든 PPTX 테마 기능이 PPT 직렬화에서 지원되는 것은 아니며, 채우기 서식, 선 서식 및 글꼴의 직렬화만 지원됩니다.
- OLE/ActiveX PPT 직렬화를 PPT로 변환할 때 알려진 문제가 있습니다.
- WordArt 직렬화 및 렌더링이 지원되지 않습니다.

{{% /alert %}}
