{{% alert color="info" title="Note" %}}

Aspose.Slides for SharePoint를 사용하면 SharePoint 문서 라이브러리 내에서 PowerPoint 프레젠테이션을 다양한 인기 문서 형식으로 변환할 수 있습니다.

{{% /alert %}}

## **지원되는 입력 형식**

Aspose.Slides for SharePoint는 다음 입력 형식을 변환합니다:

- PPT – Microsoft PowerPoint 프레젠테이션 97 - 2003
- PPTX – Office Open XML 프레젠테이션

{{% alert color="info" title="Note" %}}

문서를 변환하려면 Aspose.Slides for SharePoint는 내장된 [Aspose.Slides for .NET](https://products.aspose.com/slides/net/) 버전에 의존합니다.

{{% /alert %}}

## **지원되는 출력 형식**

변환 페이지의 **Convert to** 목록에는 다음과 같은 출력 형식이 순서대로 제공됩니다:

- PDF – Adobe 포터블 문서
- TIFF – 이미지 패키지
- XPS – XML Paper Specification
- PPS – 슬라이드 쇼 프레젠테이션
- PPSX – Microsoft PowerPoint Open XML 슬라이드 쇼
- ODP – OpenDocument 프레젠테이션
- PPTM – Microsoft PowerPoint Open XML 매크로 사용 프레젠테이션
- PPSM – Microsoft PowerPoint Open XML 매크로 사용 슬라이드 쇼
- POTX – Microsoft PowerPoint 템플릿
- POTM – PowerPoint Open XML 매크로 사용 프레젠테이션 템플릿
- PDFNotes – PDF 형식의 프레젠테이션 노트 보기
- HTML – HTML 형식의 프레젠테이션
- TIFFNotes – 다중 페이지 TIFF 이미지로 된 프레젠테이션 노트 보기
- SWF – Shockwave Flash 동영상
- SWFNotes – 다중 페이지 SWF로 된 프레젠테이션 노트 보기
