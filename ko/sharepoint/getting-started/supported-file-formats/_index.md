## **지원되는 Microsoft PowerPoint 버전**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Mac용 Microsoft PowerPoint

## **지원되는 파일 형식**

Aspose.Slides for SharePoint converts PPT and PPTX presentations stored in a SharePoint document library. Files of other types are not converted.

|**형식**|**설명**|**Convert from**|**Convert to**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|PowerPoint 프레젠테이션 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|PowerPoint 프레젠테이션 2007 이후|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|휴대용 문서 형식, 슬라이드 또는 노트 보기와 함께| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|TIFF 이미지, 슬라이드 또는 노트 보기와 함께| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML 종이 사양| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|HTML 형식의 프레젠테이션| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Shockwave Flash 동영상, 슬라이드 또는 노트 보기와 함께| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|OpenDocument 프레젠테이션| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|PowerPoint 슬라이드 쇼 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|PowerPoint 슬라이드 쇼 2007 이후| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|PowerPoint 매크로 사용 프레젠테이션| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|PowerPoint 매크로 사용 슬라이드 쇼| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|PowerPoint 템플릿| |{{< emoticons/tick >}}|

출력 형식은 변환 페이지의 **Convert to** 아래에서 선택합니다; 정확한 옵션 목록은 [Multiple Format Support](/slides/ko/sharepoint/multiple-format-support/)를 확인하십시오.
