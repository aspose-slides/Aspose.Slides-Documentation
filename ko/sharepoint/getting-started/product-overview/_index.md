## **제품 개요**

Aspose.Slides for SharePoint는 SharePoint 문서 라이브러리에 저장된 PowerPoint 프레젠테이션을 서버에서 다른 형식으로 변환합니다.

다음 PowerPoint 형식을 변환합니다:

- PPT – Microsoft PowerPoint 프레젠테이션 97 - 2003
- PPTX – Office Open XML 프레젠테이션

이들을 PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX 및 POTM 형식으로 변환합니다. 자세한 내용은 [Supported File Formats](/slides/ko/sharepoint/supported-file-formats/)를 참조하십시오.

다운로드에는 다음 제품마다 별도의 설치 프로그램 및 솔루션 패키지가 포함됩니다:

- SharePoint 2007
- SharePoint 2010
- SharePoint Server 2013
- SharePoint Server 2016
- SharePoint Server 2019

**Aspose.Slides for SharePoint를 사용하여 SharePoint 문서 라이브러리의 문서를 변환합니다**
