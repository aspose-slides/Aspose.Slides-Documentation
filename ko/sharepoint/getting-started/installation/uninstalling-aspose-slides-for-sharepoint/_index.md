---
Aspose.Slides for SharePoint를 제거하려면:

1. 설치할 때 사용한 설정 프로그램을 실행합니다. 예: SharePoint Server 2019에서 *Setup2019.exe*.
   동일한 버전이 설치되어 있으면 설정 프로그램이 복구 또는 제거를 제안합니다. 다른 버전이 있으면 업그레이드 또는 제거를 제안합니다.
2. **Remove**를 선택하고 **Next**를 클릭하여 Aspose.Slides for SharePoint를 제거합니다.
