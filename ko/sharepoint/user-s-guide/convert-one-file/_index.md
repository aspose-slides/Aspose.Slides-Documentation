문서 라이브러리에서 프레젠테이션을 변환하려면:

1. PPT 또는 PPTX 파일(편집 컨트롤 블록)의 메뉴를 열고 **Convert via Aspose.Slides**를 선택합니다. SharePoint 2007에서는 메뉴 항목 이름이 **Convert with Aspose.Slides**입니다.

   **SharePoint 2007 문서 메뉴에서 Convert with Aspose.Slides 선택**

   ![SharePoint 2007 문서 라이브러리의 문서 메뉴이며, Convert with Aspose.Slides 항목이 표시됨](convert-one-file_1.png)

2. 변환 페이지에서 **Convert to** 아래에 있는 출력 형식을 선택합니다. 필요에 따라 대상 파일 이름과 대상 폴더를 변경합니다.
3. **Convert**를 클릭합니다.
4. 변환이 완료되면 **Source Library** 또는 **Destination Library**를 클릭하여 문서 라이브러리로 돌아갑니다. 변환된 파일은 대상 폴더에 있습니다.

같은 단계와 각 페이지의 스크린샷은 [Microsoft PowerPoint 문서를 다른 형식으로 변환](/slides/ko/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/)에 있습니다.
