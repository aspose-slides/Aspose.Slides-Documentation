Aspose.Slides for SharePoint가 SharePoint 서버에 설치되고 사이트 컬렉션에 활성화되면, 해당 문서 라이브러리의 문서 메뉴에 **Convert via Aspose.Slides** 항목이 추가됩니다(아래와 같이). SharePoint 2007에서는 이 항목이 **Convert with Aspose.Slides** 라고 명명됩니다.

**Aspose.Slides for SharePoint 설치 시 Convert via Aspose.Slides 항목이 문서 메뉴에 추가됩니다**

![Convert via Aspose.Slides 항목이 포함된 문서 메뉴](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **프레젠테이션 변환**

SharePoint 문서 라이브러리에서 Microsoft PowerPoint 프레젠테이션(PPT 또는 PPTX)을 변환하려면:

1. 문서 라이브러리에서 Microsoft PowerPoint 프레젠테이션을 선택합니다.
2. 메뉴를 열고 **Convert via Aspose.Slides**를 클릭합니다.

   **Presentation 2 파일의 메뉴, Convert via Aspose.Slides 항목이 표시됨**

   ![문서 라이브러리의 프레젠테이션 메뉴, Convert via Aspose.Slides 항목이 강조 표시된 모습](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. **Convert to** 아래에서 출력 형식을 선택합니다. 필요에 따라 출력 파일 이름과 대상 폴더를 변경할 수 있습니다.
4. 파일을 변환하려면 **Convert**를 클릭합니다.

   **변환 페이지에서 출력 형식, 파일 이름 및 대상 폴더를 선택할 수 있습니다**

   ![출력 형식, 대상 파일 및 대상 폴더가 표시된 변환 페이지](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. 변환이 완료되면 성공 메시지가 표시됩니다.

   **변환이 성공했습니다**

   ![변환 결과 페이지](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. **Source Library**(원본 폴더로 이동) 또는 **Destination Library**(파일이 저장된 폴더로 이동)를 클릭합니다.

   변환된 문서는 문서 라이브러리에 나타납니다.

   **저장된 라이브러리에 표시된 변환된 문서**

   ![문서 라이브러리의 변환된 파일](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="참고" %}}

스크린샷은 PDF, TIFF 및 XPS 형식만 제공하던 이전 버전에서 촬영되었습니다. 현재 변환 페이지에서는 더 많은 출력 형식을 제공하므로 [다중 형식 지원](/slides/ko/sharepoint/multiple-format-support/)를 참조하십시오.

{{% /alert %}}

SharePoint 2010 이상에서는 라이브러리에서 하나 이상의 프레젠테이션을 선택하고 **Aspose Tools** 리본 탭의 **Convert Slides**를 클릭할 수도 있습니다. 동일한 변환 페이지가 열립니다.
