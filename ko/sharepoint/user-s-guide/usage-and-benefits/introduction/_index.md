SharePoint 사이트는 특정 비즈니스 요구를 충족하기 위해 협업, 커뮤니케이션 및 콘텐츠 저장소 역할을 합니다. 그룹 구성원들이 정보 공유와 커뮤니케이션을 촉진함으로써 공동 목표를 달성할 수 있게 합니다. 정보는 대부분 웹사이트 형태로 제공되며 웹 브라우저를 통해 접근합니다.

{{% /alert %}}

## **SharePoint와 Aspose.Slides란?**

Aspose.Slides for SharePoint는 Microsoft PowerPoint 프레젠테이션(PPT 및 PPTX)을 다른 형식(PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX 및 POTM)으로 변환하는 솔루션입니다. Microsoft PowerPoint를 사용하지 않고도 SharePoint 사이트에서 PowerPoint 파일을 변환할 수 있습니다. 전체 형식 목록은 [Supported File Formats](/slides/ko/sharepoint/supported-file-formats/)에 있습니다.
