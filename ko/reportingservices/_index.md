Aspose.Slides for Reporting Services는 Microsoft SQL Server Reporting Services 및 Power BI Report Server용 렌더링 확장 기능으로, 서버에 Microsoft PowerPoint가 없어도 페이지 매김(RDL) 보고서의 내보내기 목록에 프레젠테이션 형식을 추가합니다.

보고서를 PPT, PPTX, PPS 및 PPSX 프레젠테이션 및 슬라이드 쇼, ODP, XPS 형식으로 내보냅니다.

## **첫 번째 내보내기**

작성할 코드가 없습니다: 보고서 서버에 확장을 설치하면 해당 서버의 모든 페이지 매김 보고서 내보내기 목록에 형식이 표시됩니다.

1. 보고서 서버가 .NET Framework 3.5를 포함한 [시스템 요구 사항](/slides/ko/reportingservices/system-requirements/)을 충족하는지 확인하십시오.
2. [다운로드 페이지](https://releases.aspose.com/slides/reportingservices/)에서 MSI 설치 프로그램인 *Aspose.Slides for Reporting Services*를 다운로드합니다. 대신 수동으로 설치하려면 ZIP 패키지인 *Aspose.Slides for Reporting Services (DLLs Only)*를 다운로드하십시오.
3. 보고서 서버에 확장을 설치합니다: MSI를 관리자 권한으로 실행합니다([MSI 설치 프로그램으로 설치](/slides/ko/reportingservices/install-with-msi-installer/)에 설명된 대로) 또는 ZIP 패키지에 대해서는 [수동 설치](/slides/ko/reportingservices/install-manually/)를 따르십시오.
4. 브라우저에서 보고서 서버의 웹 포털(SQL Server 2014 이하에서는 Report Manager)을 엽니다. 기본 주소는 `https://<ComputerName>/reports`입니다.
5. 페이지 매김 보고서를 엽니다. 보고서 도구 모음에서 **Export** 목록을 열고 **PPTX - PowerPoint 2007 Presentation via Aspose.Slides**를 선택합니다. 도구 모음에 별도의 **Export** 버튼이 있는 경우(Report Manager와 같이) 해당 버튼을 선택하십시오.
6. 브라우저가 다운로드한 PPTX 파일을 열거나 저장합니다.

라이선스가 없으면 내보낸 프레젠테이션에 평가 워터마크가 표시됩니다 — [라이선스](/slides/ko/reportingservices/license-aspose-slides-for-reporting-services/)를 참조하십시오. 내보내기 목록의 다른 형식에 대해서는 [지원 파일 형식](/slides/ko/reportingservices/supported-file-formats/)을 확인하십시오.
