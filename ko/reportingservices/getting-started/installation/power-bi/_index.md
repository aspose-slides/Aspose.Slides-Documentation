## **Power BI**

Aspose.Slides for Reporting Services를 Power BI Report Server에 동일한 설치 프로세스를 통해 설치할 수 있습니다:

* [Install with MSI Installer](/slides/ko/reportingservices/install-with-msi-installer/). 설치 프로그램은 설치된 Power BI Report Server를 자동으로 감지하고, 제품을 설치한 다음 작업 환경에 맞게 구성합니다.
* [Install Manually](/slides/ko/reportingservices/install-manually/). ZIP 패키지의 *Bin\Universal* 폴더에 있는 어셈블리를 사용합니다.

Aspose.Slides for Reporting Services는 Power BI Report Server에서 페이징된 보고서(RDL)를 내보냅니다. 호스트 머신에 .NET Framework 3.5를 포함한 요구 사항은 [System Requirements](/slides/ko/reportingservices/system-requirements/)를 참조하십시오.
