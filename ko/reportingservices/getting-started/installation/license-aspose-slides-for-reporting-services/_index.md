## **라이선스 지원**

Aspose.Slides for Reporting Services의 평가 버전은 구매 버전과 동일한 패키지이며, [its download page](https://releases.aspose.com/slides/ko/reportingservices/)에서 제공되고 동일한 기능을 제공합니다. 라이선스가 없으면 평가 모드로 동작하며 내보낸 프레젠테이션에 평가 워터마크를 삽입합니다.

평가 버전은 라이선스 파일을 보고 서버에 복사하면 라이선스가 적용됩니다. 코드가 필요하지 않습니다.

평가가 만족스러우면 [purchase a license](https://purchase.aspose.com/pricing/slides/ko/reporting-services/). 다양한 구독 유형을 확인하시기를 권장합니다. 질문이 있으면 Aspose 영업팀에 문의하세요.

## **Aspose.Slides for Reporting Services의 라이선스 관리**

* 라이선스는 제품명, 라이선스 대상 개발자 수, 구독 만료 일자 등과 같은 세부 정보를 포함하는 일반 텍스트 XML 파일입니다.
* 라이선스 파일은 디지털 서명되어 있으므로 수정해서는 안 됩니다. 파일 내용에 실수로 줄바꿈을 추가하는 것조차도 무효화됩니다.

라이선스를 적용하려면:

1. 각 보고 서버 인스턴스의 *ReportServer\bin* 폴더(예: *C:\Program Files\Microsoft SQL Server Reporting Services\SSRS\ReportServer\bin*)에 라이선스 파일을 복사합니다. 해당 폴더에 *Aspose.Slides.ReportingServices.dll*이 설치되어 있습니다. [Install Manually](/slides/ko/reportingservices/install-manually/#find-the-report-server-folder)에서 기본 폴더를 확인할 수 있습니다.
2. 파일 이름이 다음 중 하나인지 확인합니다: *Aspose.Slides.ReportingServices.lic*, *Aspose.Slides.Reporting.Services.lic*, *Aspose.Slides.Product.Family.lic*, *Aspose.Total.ReportingServices.lic*, *Aspose.Total.Reporting.Services.lic*, *Aspose.Total.Product.Family.lic* 또는 *Aspose.Total.lic*.
3. 보고서를 프레젠테이션으로 내보냅니다. 워터마크가 없으면 라이선스가 활성화된 것입니다.

확장 기능은 또한 %ProgramData%\Aspose\Slides(보통 *C:\ProgramData\Aspose\Slides*) 폴더에서도 라이선스 파일을 찾으며, 해당 위치에 한 개의 복사본을 두면 머신의 모든 인스턴스에 적용됩니다.

**라이선스 모드**

유효한 라이선스 파일이 발견되면 내보낸 프레젠테이션에 평가 워터마크가 표시되지 않습니다.

![라이선스로 내보낸 보고서: 평가 워터마크 없음](license-aspose-slides-for-reporting-services_2.png)

**평가 모드**

라이선스가 없으면 Aspose.Slides for Reporting Services는 내보낸 프레젠테이션에 평가 워터마크를 삽입합니다.

![평가 모드로 내보낸 보고서, 평가 워터마크 포함](license-aspose-slides-for-reporting-services_1.png)
