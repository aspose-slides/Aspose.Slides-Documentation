## **지원 플랫폼**
Aspose.Slides for Node.js via Java는 플랫폼에 독립적인 API입니다. Node.js 7 이상이 설치된 모든 플랫폼(Windows, Linux, macOS 등)에서 사용할 수 있습니다. Oracle JDK 8 이상도 필요합니다.

## **파일 형식 및 변환**
Aspose.Slides for Node.js via Java는 대부분의 PowerPoint 문서 형식을 지원합니다. 또한 조직에서 일반적으로 사용하고 공유하는 파일 형식으로 내보낼 수 있습니다. 자세한 내용은 아래를 확인하세요:

|**기능**|**설명**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java는 이 프레젠테이션 문서 형식에 대해 가장 빠른 처리 속도를 제공합니다.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java는 PPT에서 PPTX로의 변환을 지원합니다.|
|Portable Document Format (PDF)|지원되는 모든 파일 형식을 단일 메서드로 Adobe Portable Document Format(PDF) 문서로 내보낼 수 있습니다.|
|XML Parser Specification (XPS)|지원되는 모든 파일 형식을 단일 메서드로 XML Parser Specification(XPS) 문서로 내보낼 수 있습니다.|
|Tagged Image File Format (TIFF)|지원되는 모든 프레젠테이션 파일 형식을 Tagged Image File Format(TIFF)으로 내보낼 수 있습니다.|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java는 PresentationEx를 HTML 형식으로 변환하는 것을 지원합니다.|

## **프레젠테이션 렌더링**
Aspose.Slides for Node.js via Java는 프레젠테이션 슬라이드를 다양한 그래픽 형식으로 고충실도 렌더링합니다. 자세한 내용은 아래를 확인하세요:

|**기능**|**설명**|
| :- | :- |
|Java Supported Image Formats|Aspose.Slides for Node.js via Java를 사용하면 TIFF, PNG, BMP, JPEG, GIF와 같이 Java에서 지원하는 모든 그래픽 형식으로 프레젠테이션 슬라이드와 슬라이드의 이미지를 렌더링할 수 있습니다.|
|SVG Format|Aspose.Slides for Node.js via Java는 Scalable Vector Graphics(SVG) 형식으로 프레젠테이션 슬라이드를 내보내는 내장 메서드를 제공합니다.|

## **콘텐츠 기능**
Aspose.Slides for Node.js via Java를 사용하면 프레젠테이션 문서의 거의 모든 항목 및 내용을 액세스, 수정 또는 생성할 수 있습니다. 자세한 내용은 아래를 확인하세요:

|**기능**|**설명**|
| :- | :- |
|Master Slides|마스터 슬라이드는 일반 슬라이드의 레이아웃을 정의합니다. Aspose.Slides for Node.js via Java를 사용하면 프레젠테이션 문서의 마스터 슬라이드에 액세스하고 수정할 수 있습니다.|
|Normal Slides|Aspose.Slides for Node.js via Java를 사용하면 다양한 유형의 새 슬라이드를 만들 수 있으며, 프레젠테이션에 존재하는 슬라이드에 액세스하고 수정할 수도 있습니다.|
|Cloning / Copying Slides|Aspose.Slides for Node.js via Java에서 제공하는 내장 메서드를 사용하면 프레젠테이션 내 기존 슬라이드를 복제하거나 복사할 수 있습니다. 복제된 슬라이드와 복사된 슬라이드를 다른 프레젠테이션에 사용할 수도 있습니다. 슬라이드는 마스터 슬라이드의 레이아웃을 상속하므로, 내장 복제 메서드는 복제 시 자동으로 마스터를 복사합니다.|
|Managing Slides sections|프레젠테이션 내 슬라이드를 서로 다른 섹션으로 구성하는 메서드입니다.|
|Place Holders and Text Holders|슬라이드의 자리 표시자와 텍스트 자리 표시자에 액세스할 수 있습니다. 또한 적절한 메서드를 사용해 텍스트 자리 표시자를 포함한 슬라이드를 처음부터 만들 수 있습니다.|
|Header and Footers|Aspose.Slides for Node.js via Java는 슬라이드의 머리글/바닥글 처리를 지원합니다.|
|Notes in Slides|Aspose.Slides for Node.js via Java를 사용하면 슬라이드에 연결된 메모에 액세스하고 수정하거나 새 메모를 추가할 수 있습니다.|
|Finding a Shape|모양에 연결된 대체 텍스트를 사용해 특정 모양을 슬라이드에서 찾을 수 있습니다.|
|Backgrounds|Aspose.Slides for Node.js via Java를 사용하면 마스터 슬라이드 또는 일반 슬라이드에 연결된 배경을 작업할 수 있습니다.|
|Text Boxes|텍스트 상자를 처음부터 만들 수 있으며, 기존 텍스트 상자에 액세스하고 원본 텍스트 서식을 유지한 채 텍스트를 수정할 수 있습니다.|
|Rectangle Shapes|Aspose.Slides for Node.js via Java로 사각형 모양을 만들거나 수정할 수 있습니다.|

|Group Shapes|Aspose.Slides for Node.js via Java는 그룹 모양을 지원합니다.|

## **FAQ**

### 라이브러리를 사용하려면 서버/PC에 Microsoft PowerPoint를 설치해야 하나요?

아니요. PowerPoint는 필요하지 않으며, Aspose.Slides는 프레젠테이션을 생성, 편집, 변환 및 렌더링하기 위한 독립 실행형 엔진입니다.

### 멀티스레딩은 어떻게 작동합니까? 처리를 병렬화할 수 있나요?

다른 스레드에서 서로 다른 문서를 처리하는 것은 안전합니다. 동일한[presentation](https://reference.aspose.com/slides/ko/nodejs-java/aspose.slides/presentation/) 객체를 [multiple threads](/slides/ko/nodejs-java/multithreading/)가 동시에 사용하면 안 됩니다.

### 파일 비밀번호 및 암호화가 지원되나요?

예. [You can](/slides/ko/nodejs-java/password-protected-presentation/) 암호화된 프레젠테이션을 열고, 열기 및 쓰기 비밀번호를 설정하거나 제거하며, 보호 상태를 확인할 수 있습니다.

### Linux 컨테이너에서 폰트 패키지를 신경 써야 하나요?

예. 일반적인 폰트 패키지를 설치하거나 애플리케이션에서 [specify font directories](/slides/ko/nodejs-java/custom-font/)를 명시하는 것이 예상치 못한 대체를 방지하는 데 권장됩니다.

### 평가 버전에 제한이 있나요?

[Evaluation mode](/slides/ko/nodejs-java/licensing/)에서는 출력에 워터마크가 추가되고 특정 제한이 적용됩니다. 전체 기능 테스트를 위해 [30-day temporary license](https://purchase.aspose.com/temporary-license/)를 사용할 수 있습니다.

### 외부 형식(PDF/HTML → PPTX)을 프레젠테이션에 가져오는 것이 지원되나요?

예. [PDF pages and HTML content](/slides/ko/nodejs-java/import-presentation/)를 프레젠테이션에 추가하여 슬라이드로 변환할 수 있습니다.
