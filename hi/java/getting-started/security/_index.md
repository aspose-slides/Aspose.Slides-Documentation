## **परिचय**

यह लेख उन जानकारियों को एकत्र करता है जो Aspose.Slides for Java का उपयोग करने वाले अनुप्रयोग की सुरक्षा समीक्षा के लिए सामान्यतः आवश्यक होती हैं: लाइब्रेरी प्रस्तुतियों को कैसे प्रोसेस करती है, यह आपके प्रोजेक्ट की निर्भरताओं में क्या जोड़ती है, JAR फ़ाइल Aspose से है या नहीं कैसे जाँचें, और JAR फ़ाइल में कौन‑से तृतीय‑पक्ष घटक शामिल हैं।

## **Aspose.Slides में सुरक्षा**

Aspose अपने उत्पादों को विकसित करते समय सर्वोत्तम प्रथाओं का पालन करता है।

* Aspose.Slides for Java का उपयोग प्रस्तुतियों को बनाने, संशोधित करने और परिवर्तित करने के लिये किया जाता है। यह प्रस्तुतियों में स्क्रिप्ट नहीं चलाता। Aspose.Slides प्रस्तुति संरचना को पार्स करता है और आपके कोड को ऑब्जेक्ट मॉडल के साथ काम करने देता है।
* Aspose.Slides एक लाइब्रेरी के रूप में कार्य करता है जो दस्तावेज़ों को पार्स और व्याख्या करता है बिना रिमोट कोड निष्पादित किए। सभी Aspose उत्पाद आपके मशीनों पर चलते हैं। वे Aspose को कोई डेटा नहीं भेजते। केवल अपवाद [metered licensing](/slides/hi/java/metered-licensing/) है: यदि आप इसका उपयोग करते हैं, तो केवल आपके API उपयोग की जानकारी प्रोसेस की जाती है।
* Aspose घटक सामान्य अनुप्रयोगों के समान उपयोगकर्ता संदर्भ में चलते हैं। इसलिए, Aspose घटक महत्वपूर्ण सिस्टम संसाधनों के लिये जोखिम नहीं बनते। अतिरिक्त रूप से, जब कोई Aspose घटक दस्तावेज़ खोलता है, तो मैक्रो स्वतः नहीं चलते।

## **Maven निर्भरताएँ**

Aspose.Slides for Java का Maven आर्टिफैक्ट, `com.aspose:aspose-slides`, कोई निर्भरताएँ घोषित नहीं करता: इसका POM फ़ाइल केवल आर्टिफैक्ट के अपने कोऑर्डिनेट्स रखता है। जब आप इसे प्रोजेक्ट में जोड़ते हैं, तो Maven केवल इस एक JAR फ़ाइल को जोड़ता है और कुछ नहीं। अपने प्रोजेक्ट में हल की गई सभी आर्टिफैक्ट्स, जिसमें ट्रांज़िटिव निर्भरताएँ भी शामिल हैं, को सूचीबद्ध करने के लिये प्रोजेक्ट फ़ोल्डर में यह कमांड चलाएँ:

```bash
mvn dependency:tree
```

[Installation](/slides/hi/java/installation/) में दिखाए गये प्रोजेक्ट में, आउटपुट केवल Aspose.Slides को एकमात्र निर्भरता के रूप में दिखाता है:

```text
[INFO] com.example:hello-slides:jar:1.0
[INFO] \- com.aspose:aspose-slides:jar:jdk16:26.9:compile
```

## **JAR फ़ाइल की जाँच करें**

Aspose JAR फ़ाइल पर हस्ताक्षर करता है। हस्ताक्षर की जाँच के लिये, उस फ़ोल्डर में `jarsigner` टूल चलाएँ जहाँ JAR फ़ाइल स्थित है:

```bash
jarsigner -verify aspose-slides-26.9-jdk16.jar
```

यदि हस्ताक्षर वैध है और फ़ाइल पर हस्ताक्षर के बाद कोई प्रविष्टि नहीं बदली गई है तो कमांड `jar verified.` प्रदर्शित करता है। यह संदेश साइनर का नाम नहीं बताता। यह पुष्टि करने के लिये कि फ़ाइल Aspose ने साइन की है, `-verbose` और `-certs` विकल्प जोड़ें और देखें कि साइनर का प्रमाणपत्र `CN=ASPOSE PTY LTD` को जारी किया गया है। जब Maven JAR फ़ाइल डाउनलोड करता है, तो वह रिपॉज़िटरी द्वारा प्रकाशित SHA-1 चेकसम भी जाँचता है।

## **तृतीय‑पक्ष घटक**

Aspose.Slides for Java में तृतीय‑पक्ष घटकों से कोड और डेटा शामिल है। वे JAR फ़ाइल का हिस्सा हैं, अलग‑अलग Maven आर्टिफैक्ट नहीं, इसलिए `mvn dependency:tree` व अन्य Maven निर्भरताएँ पढ़ने वाले टूल उन्हें सूचीबद्ध नहीं करते। JAR फ़ाइल में नोटिस फ़ाइल *META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf* शामिल है, जो घटकों और उनके लाइसेंसों को सूचीबद्ध करता है:

| घटक | नोटिस में दिया गया लाइसेंस |
|---|---|
| DotNetZip | Microsoft Public License (Ms-PL) |
| Bouncy Castle | MIT‑style लाइसेंस |
| Mono | MIT लाइसेंस; कुछ हिस्से अन्य लाइसेंस के तहत हैं जो नोटिस में सूचीबद्ध हैं |
| RSWOP.ICM color profile | Microsoft लाइसेंस शर्तें |
| sRGB_v4_ICC_preference.icc color profile | ICC अनुमति उपयोग, प्रतिलिपि और बिना परिवर्तन के वितरण की |
| Apache | Apache License 2.0 |
| ANTLR | BSD लाइसेंस |
| sfntly | Apache License 2.0 |

JAR फ़ाइल से नोटिस निकालने के लिये, उस फ़ोल्डर में `jar` टूल चलाएँ जहाँ JAR फ़ाइल स्थित है:

```bash
jar xf aspose-slides-26.9-jdk16.jar "META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf"
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या Aspose.Slides for Java बाहरी पैकेजों का उपयोग करता है?**

जैसा कि [Maven Dependencies](#maven-dependencies) दिखाता है, इसमें कोई Maven निर्भरताएँ नहीं हैं, लेकिन इसमें [Third-Party Components](#third-party-components) में सूचीबद्ध तृतीय‑पक्ष घटक शामिल हैं। अपने सुरक्षा मूल्यांकन में JAR फ़ाइल और इन घटकों दोनों को सम्मिलित करें।

**क्या Aspose.Slides for Java को नेटवर्क एक्सेस की आवश्यकता है?**

नहीं। प्रस्तुतियों को बनाना, सहेजना और रेंडर करना बिना किसी नेटवर्क कनेक्शन के सिस्टम पर काम करता है। केवल वह सुविधा जो डेटा Aspose को भेजती है, वह [metered licensing](/slides/hi/java/metered-licensing/) है, जो API उपयोग रिपोर्ट करता है।

**क्या Aspose.Slides for Java में मूल (native) कोड शामिल है?**

नहीं। JAR फ़ाइल में केवल Java क्लासेस और संसाधन होते हैं, इसलिए यह आपके अनुप्रयोग में कोई मूल लाइब्रेरी नहीं जोड़ती। Linux पर, Java रनटाइम का फ़ॉन्ट समर्थन फ़ॉन्टकॉन्फ़िग लाइब्रेरी और ऑपरेटिंग सिस्टम के फ़ॉन्ट्स की आवश्यकता रखता है; अधिक जानकारी के लिये देखें [System Requirements](/slides/hi/java/system-requirements/#linux)।
