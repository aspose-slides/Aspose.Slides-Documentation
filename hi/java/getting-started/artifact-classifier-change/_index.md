## `jdk16` से `jdk8` तक आर्टिफैक्ट क्लासिफायर परिवर्तन

संस्करण **26.10** से, हमने प्रकाशित आर्टिफैक्ट्स में उपयोग किए जाने वाले क्लासिफायर को **`jdk16`** (जावा 6) से **`jdk8`** (जावा 8) में बदल दिया है।

### क्या बदला

| | पहले | बाद |
|---|---|---|
| क्लासिफायर | `jdk16` | `jdk8` |
| न्यूनतम जावा संस्करण | Java 1.6 | Java 8 |

**पहले:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**बाद:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### हमने यह परिवर्तन क्यों किया

आंतरिक समीक्षा के बाद, हमने **पुराने जावा संस्करणों के समर्थन को समाप्त करने** का निर्णय लिया, जो अब मूल्य नहीं जोड़ रहे थे और रखरखाव में बाधा बन रहे थे। सभी उपयोगकर्ताओं के लिए नया, सुरक्षित बेंचमार्क के रूप में Java 8 को चुना गया।

इसका हिस्सा बनते हुए, क्लासिफायर को वास्तविक न्यूनतम समर्थित संस्करण को दर्शाने के लिए अपडेट किया गया। हमने वर्तमान Oracle नामकरण नियम के साथ भी सुसंगतता रखी, जहाँ उत्पाद को आधिकारिक रूप से **JDK 8** कहा जाता है (पुराने `1.8` स्वरूप के बजाय)।

### आपको क्या करना चाहिए

1. अपने निर्भरता घोषणा में क्लासिफायर को `jdk16` से `jdk8` में **अपडेट करें**।

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **अपने रनटाइम वातावरण** की जाँच करें कि वह Java 8 या उससे ऊपर है।

3. पुराने क्लासिफायर को लॉक करने वाले **लॉक फ़ाइलें** या निर्भरता कैश को रीफ़्रेश करें।

### माइग्रेशन नोट: jdk16 और jdk8

संस्करण 26.10​ से, दोनों jdk16 और jdk8 क्लासिफायर Java 8‑संगत JARs प्रदान करेंगे (सोर्स/टार्गेट संगतता Java 8 पर सेट है)।

- `jdk16` → पीछे की संगतता के लिए जारी रहेगा (मौजूदा इंटीग्रेशन)।
- `jdk8` → Java 8 पर्यावरण के लिए नया प्राथमिक क्लासिफायर के रूप में पेश किया गया।

⚠️ नोट: यह दोहरा प्रकाशन चरण 31 मार्च 2027 को समाप्त होगा। इस तिथि के बाद, jdk16 क्लासिफायर को निरस्त कर दिया जाएगा, और केवल jdk8 समर्थित रहेगा।

### संगतता नोट्स

- `jdk16` क्लासिफायर **31 मार्च 2027** के बाद प्रकाशित नहीं किया जाएगा।
- यदि आपको अभी भी Java 1.6 समर्थन चाहिए, तो कृपया पिछले प्रमुख संस्करण लाइन पर रहें जब तक आप माइग्रेट न कर सकें।

### मदद चाहिए?

यदि माइग्रेशन के दौरान कोई समस्या आती है, तो कृपया [Aspose समर्थन](https://forum.aspose.com/) से संपर्क करें।
