## **आर्टिफैक्ट क्लासिफायर परिवर्तन `jdk16` से `jdk8` तक**

संस्करण **26.10** से हमने प्रकाशित आर्टिफैक्ट्स में उपयोग किए जाने वाले क्लासिफायर को **`jdk16`** (Java 6) से **`jdk8`** (Java 8) में बदल दिया है।

### **क्या बदला**

| | पहले | बाद |
|---|---|---|
| क्लासिफायर | `jdk16` | `jdk8` |
| न्यूनतम जावा संस्करण | Java 1.6 | Java 8 |

**पहले:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**बाद:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **हमने यह परिवर्तन क्यों किया**

आंतरिक समीक्षा के बाद, हमने उन पुराने जावा संस्करणों के समर्थन को **छोड़ने** का निर्णय लिया जो अब मूल्य प्रदान नहीं करते थे और रखरखाव में बाधा बन रहे थे। सभी उपयोगकर्ताओं के लिए नई, सुरक्षित आधाररेखा के रूप में Java 8 को चुना गया।

इसके हिस्से के रूप में, क्लासिफायर को वास्तविक न्यूनतम समर्थित संस्करण को दर्शाने के लिए अपडेट किया गया। हमने मौजूदा Oracle नामकरण प्रथा के साथ भी तालमेल बिठाया, जहाँ उत्पाद को आधिकारिक रूप से **JDK 8** कहा जाता है (पुरानी `1.8` स्वरूप की बजाय)।

### **आपको क्या करना चाहिए**

1. **क्लासिफायर को अपडेट करें** अपने निर्भरता घोषणाओं में `jdk16` से `jdk8` तक।

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **अपने रनटाइम पर्यावरण को सत्यापित करें** कि वह Java 8 या उससे अधिक है।

3. **कोई भी लॉक फ़ाइलें** या निर्भरता कैशेज़ को रिफ्रेश करें जो पुराने क्लासिफायर को पिन करते हैं।

### **माइग्रेशन नोट: jdk16 और jdk8**

संस्करण 26.10​ से, jdk16 और jdk8 दोनों क्लासिफायर Java 8‑संगत JARs प्रदान करेंगे (स्रोत/लक्ष्य संगतता Java 8 पर सेट के साथ निर्मित)।

 - `jdk16` → पूर्व-संगतता (मौजूदा एकीकरण) के लिए प्रकाशित होते रहेंगे।
 - `jdk8` → Java 8 पर्यावरण के लिए नया पसंदीदा क्लासिफायर के रूप में पेश किया गया।

⚠️ नोट: यह द्वि‑प्रकाशन चरण 31 मार्च, 2027 को समाप्त होने की योजना है। इस तिथि के बाद, jdk16 क्लासिफायर को समाप्त कर दिया जाएगा, और केवल jdk8 समर्थित रहेगा।

### **अनुकूलता नोट्स**

- `jdk16` क्लासिफायर **31 मार्च, 2027 के बाद प्रकाशित नहीं किया जाएगा**।
- यदि आपको अभी भी Java 1.6 समर्थन चाहिए, तो कृपया माइग्रेट करने तक पिछले प्रमुख संस्करण पर बने रहें।

### **सहायता चाहिए?**

यदि आप माइग्रेशन के दौरान समस्याओं का सामना करते हैं, तो कृपया आगे की सहायता के लिए [Aspose समर्थन](https://forum.aspose.com/) से संपर्क करें।
