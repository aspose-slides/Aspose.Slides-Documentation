## **अवलोकन**

Aspose.Slides को मूल्यांकन मोड में या वैध लाइसेंस के साथ उपयोग किया जा सकता है। मूल्यांकन संस्करण लाइसेंस प्राप्त संस्करण के समान कार्यक्षमता प्रदान करता है, लेकिन यह प्रस्तुति खोलने या सहेजने पर मूल्यांकन वॉटरमार्क जोड़ता है और टेक्स्ट निष्कर्षण को एक स्लाइड तक सीमित करता है।

यह लेख Aspose.Slides में लाइसेंसिंग कैसे काम करती है और लाइब्रेरी का उपयोग करने से पहले लाइसेंस कैसे लागू किया जाता है, समझाता है। लाइसेंस `License` क्लास का उपयोग करके फ़ाइल, स्ट्रीम या एंबेडेड रिसोर्स से लोड किया जा सकता है। यह लेख यह भी दिखाता है कि लाइसेंस सही तरीके से लागू हुआ है या नहीं, कैसे सत्यापित किया जाए।

## **Aspose.Slides का मूल्यांकन करें**

{{% alert color="info" %}} 

आप **Aspose.Slides for Java** का मूल्यांकन संस्करण उसकी [download page](https://releases.aspose.com/java/repo/com/aspose/aspose-slides/) से डाउनलोड कर सकते हैं। मूल्यांकन संस्करण उत्पाद के लाइसेंस प्राप्त संस्करण के समान कार्यक्षमता प्रदान करता है। मूल्यांकन पैकेज खरीदे हुए पैकेज के समान ही होता है। मूल्यांकन संस्करण केवल कुछ कोड पंक्तियों को जोड़ने (लाइसेंस लागू करने) के बाद लाइसेंस प्राप्त हो जाता है।

एक बार जब आप **Aspose.Slides** के मूल्यांकन से संतुष्ट हो जाएँ, तो आप [purchase a license](https://purchase.aspose.com/buy) कर सकते हैं। हम विभिन्न सब्सक्रिप्शन प्रकारों को देखना सलाह देते हैं। यदि आपके कोई प्रश्न हों, तो Aspose बिक्री टीम से संपर्क करें।

प्रत्येक Aspose लाइसेंस में एक साल की सब्सक्रिप्शन शामिल होती है, जिससे सब्सक्रिप्शन अवधि के भीतर जारी नई संस्करणों या सुधारों के मुफ्त अपग्रेड मिलते हैं। लाइसेंस प्राप्त उत्पाद (या यहाँ तक कि मूल्यांकन संस्करण) उपयोगकर्ताओं को मुफ्त और अनलिमिटेड तकनीकी समर्थन मिलता है।

## **Aspose.Slides में लाइसेंसिंग**

* मूल्यांकन संस्करण लाइसेंस खरीदने और कुछ कोड पंक्तियों को जोड़ने (लाइसेंस लागू करने) के बाद लाइसेंस प्राप्त हो जाता है।  
* लाइसेंस एक साधा‑टेक्स्ट XML फ़ाइल है जिसमें उत्पाद का नाम, लाइसेंस प्राप्त डेवलपर्स की संख्या, सब्सक्रिप्शन समाप्ति तिथि आदि विवरण होते हैं।  
* लाइसेंस फ़ाइल डिजिटल रूप से साइन की गई होती है, इसलिए इसे संशोधित नहीं करना चाहिए। फ़ाइल की सामग्री में अनजाने में भी एक अतिरिक्त लाइन ब्रेक जोड़ देना लाइसेंस को अमान्य कर देगा।  
* Aspose.Slides for Java आमतौर पर लाइसेंस को इन स्थानों पर खोजता है:
  * स्पष्ट पथ
  * Aspose.Slides.jar वाली फ़ोल्डर

* मूल्यांकन संस्करण की सीमाओं से बचने के लिए, आपको **Aspose.Slides** का उपयोग करने से पहले लाइसेंस सेट करना चाहिए। आपको एप्लिकेशन या प्रोसेस में केवल एक बार लाइसेंस सेट करना पड़ता है।

## **लाइसेंस लागू करना**

लाइसेंस को **फ़ाइल** या **स्ट्रीम** से लोड किया जा सकता है।

{{% alert color="info" %}}

Aspose.Slides लाइसेंसिंग ऑपरेशनों के लिए [License](https://reference.aspose.com/slides/hi/java/com.aspose.slides/License) क्लास प्रदान करता है।

{{% /alert %}} 

{{% alert color="warning" %}}

नए लाइसेंस केवल संस्करण 21.4 या बाद के साथ ही Aspose.Slides को सक्रिय कर सकते हैं। पहले के संस्करण अलग लाइसेंसिंग सिस्टम का उपयोग करते हैं और इन लाइसेंसों को पहचान नहीं पाएंगे।

{{% /alert %}}

### **फ़ाइल**

लाइसेंस सेट करने का सबसे आसान तरीका यह है कि लाइसेंस फ़ाइल को Aspose.Slides.jar या आपके एप्लिकेशन की jar वाली फ़ोल्डर में रखें।

यह Java कोड दिखाता है कि लाइसेंस फ़ाइल कैसे सेट करें:

``` java
// License क्लास का इंस्टेंस बनाता है
com.aspose.slides.License license = new com.aspose.slides.License();

// लाइसेंस फ़ाइल पथ सेट करता है
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" %}} 

यदि आप लाइसेंस फ़ाइल को किसी अन्य डायरेक्टरी में रखते हैं, तो जब आप [SetLicense](https://reference.aspose.com/slides/hi/java/com.aspose.slides/License#setLicense-java.lang.String-) मेथड को कॉल करेंगे, तो निर्दिष्ट स्पष्ट पथ के अंत में फ़ाइल नाम आपका लाइसेंस फ़ाइल नाम ही होना चाहिए।

उदाहरण के लिए, आप लाइसेंस फ़ाइल का नाम *Aspose.Slides.Java.lic.xml* बदल सकते हैं। फिर, अपने कोड में, आपको फ़ाइल के पथ (जो *Aspose.Slides.Java.lic.xml* पर समाप्त होता है) को [SetLicense](https://reference.aspose.com/slides/hi/java/com.aspose.slides/License#setLicense-java.lang.String-) मेथड को पास करना होगा।

{{% /alert %}}

### **स्ट्रीम**

आप लाइसेंस को स्ट्रीम से लोड कर सकते हैं। यह Java कोड दिखाता है कि स्ट्रीम से लाइसेंस कैसे लागू करें:

``` java
// License क्लास का इंस्टेंस बनाता है
com.aspose.slides.License license = new com.aspose.slides.License();

// स्ट्रीम के माध्यम से लाइसेंस सेट करता है
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **PHP/Java Bridge**

यदि आप Java के माध्यम से PHP के लिए Aspose.Slides उपयोग करते हैं, तो आप PHP/Java ब्रिज के जरिए लाइसेंस सेट कर सकते हैं। यह ब्रिज आपको PHP सिंटैक्स में Java क्लासों का उपयोग करने की अनुमति देता है। अधिक जानकारी के लिए देखें [License in PHP](/slides/hi/php-java/licensing/)।

## **लाइसेंस सत्यापित करना**

यह जांचने के लिए कि लाइसेंस सही तरीके से सेट हुआ है या नहीं, आप इसे सत्यापित कर सकते हैं। यह Java कोड दिखाता है कि लाइसेंस कैसे सत्यापित किया जाए:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं लाइसेंस को पूरी तरह ऑफ़लाइन पर्यावरण (इंटरनेट एक्सेस नहीं) में लागू कर सकता हूँ?

हां। लाइसेंस वैधता स्थानीय रूप से लाइसेंस फ़ाइल का उपयोग करके की जाती है; इंटरनेट कनेक्शन की आवश्यकता नहीं है।

### एक‑साल की सब्सक्रिप्शन समाप्त होने के बाद क्या होगा? क्या लाइब्रेरी काम करना बंद कर देगी?

नहीं। लाइसेंस स्थायी है: आप अपनी सब्सक्रिप्शन समाप्ति तिथि से पहले जारी संस्करणों का उपयोग जारी रख सकते हैं; केवल नया रिलीज़ उपयोग करने के लिए नवीनीकरण आवश्यक होगा।
