## **अवलोकन**

Aspose.Slides को मूल्यांकन मोड में या वैध लाइसेंस के साथ उपयोग किया जा सकता है। मूल्यांकन संस्करण लाइसेंस प्राप्त संस्करण के समान कार्यक्षमता प्रदान करता है, लेकिन यह प्रत्येक प्रस्तुति की प्रत्येक स्लाइड पर एक मूल्यांकन वॉटरमार्क जोड़ता है और API के माध्यम से आपका कोड जो पाठ पढ़ता है उसे छोटा कर देता है।

यह लेख Aspose.Slides में लाइसेंसिंग कैसे काम करती है और लाइब्रेरी का उपयोग करने से पहले लाइसेंस कैसे लागू किया जाए, इसे समझाता है। लाइसेंस को फ़ाइल, स्ट्रीम या एम्बेडेड रिसोर्स से `License` क्लास का उपयोग करके लोड किया जा सकता है। यह लेख यह भी दिखाता है कि लाइसेंस सही ढंग से लागू हुआ है या नहीं, इसे कैसे सत्यापित किया जाए।

## **Licensing in Aspose.Slides**

* एक मूल्यांकन संस्करण लाइसेंस प्राप्त बन जाता है जब आप लाइसेंस खरीदते हैं और कुछ पंक्तियों का कोड जोड़ते हैं (लाइसेंस लागू करने के लिए)।
* लाइसेंस एक साधारण‑पाठ XML फ़ाइल है जिसमें उत्पाद नाम, लाइसेंस प्राप्त डेवलपर्स की संख्या, सब्सक्रिप्शन समाप्ति तिथि आदि विवरण होते हैं। 
* लाइसेंस फ़ाइल डिजिटल रूप से साइन की गई होती है, इसलिए आप इसे संशोधित नहीं कर सकते। फ़ाइल की सामग्री में किसी अतिरिक्त लाइन ब्रेक को जोड़ने से भी यह अमान्य हो जाएगा।
* Aspose.Slides for Java आम तौर पर लाइसेंस को इन स्थानों पर खोजता है:
  * स्पष्ट पथ
  * वह फ़ोल्डर जिसमें Aspose.Slides.jar स्थित है
* मूल्यांकन संस्करण से जुड़ी सीमाओं से बचने के लिए, **Aspose.Slides** का उपयोग करने से पहले लाइसेंस सेट करना आवश्यक है। आपको प्रत्येक एप्लिकेशन या प्रक्रिया में केवल एक बार लाइसेंस सेट करना होता है।

## **Applying a License**

एक लाइसेंस **फ़ाइल** या **स्ट्रीम** से लोड किया जा सकता है।

{{% alert color="info" title="Note" %}}
Aspose.Slides लाइसेंसिंग कार्यों के लिये [License](https://reference.aspose.com/slides/java/com.aspose.slides/license/) क्लास प्रदान करता है।
{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}
नए लाइसेंस केवल संस्करण 21.4 या बाद के साथ ही Aspose.Slides को सक्रिय कर सकते हैं। पहले के संस्करण अलग लाइसेंसिंग प्रणाली का उपयोग करते हैं और इन लाइसेंस को पहचानेंगे नहीं।
{{% /alert %}}

### **File**

लाइसेंस सेट करने की सबसे आसान विधि यह है कि लाइसेंस फ़ाइल को Aspose.Slides.jar या आपके एप्लिकेशन के JAR वाले फ़ोल्डर में रखें।

इस Java कोड में दिखाया गया है कि लाइसेंस फ़ाइल कैसे सेट करें:

``` java
// License क्लास का उदाहरण बनाता है
com.aspose.slides.License license = new com.aspose.slides.License();

// लाइसेंस फ़ाइल पथ सेट करता है
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" title="Warning" %}}
यदि आप लाइसेंस फ़ाइल को किसी अलग निर्देशिका में रखते हैं, तो जब आप [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-) मेथड को कॉल करते हैं, तो निर्दिष्ट पथ के अंत में फ़ाइल नाम आपके लाइसेंस फ़ाइल नाम के समान होना चाहिए।

उदाहरण के लिये, आप लाइसेंस फ़ाइल नाम को *Aspose.Slides.Java.lic.xml* में बदल सकते हैं। फिर अपने कोड में आपको फ़ाइल का पथ (जो *Aspose.Slides.Java.lic.xml* पर समाप्त होता है) को [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-) मेथड को पास करना होगा।
{{% /alert %}}

### **Stream**

आप लाइसेंस को स्ट्रीम से लोड कर सकते हैं। यह Java कोड दिखाता है कि स्ट्रीम से लाइसेंस कैसे लागू करें:

``` java
// License क्लास का उदाहरण बनाता है
com.aspose.slides.License license = new com.aspose.slides.License();

// स्ट्रीम के माध्यम से लाइसेंस सेट करता है
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **PHP/Java Bridge**

यदि आप Java के माध्यम से PHP के लिए Aspose.Slides उपयोग करते हैं, तो आप PHP/Java ब्रिज के द्वारा लाइसेंस सेट कर सकते हैं। यह ब्रिज आपको PHP सिंटैक्स में Java क्लासेज़ का उपयोग करने देता है। अधिक जानकारी के लिए देखें [License in PHP](/slides/hi/php-java/licensing/)।

## **Validating a License**

यह जांचने के लिये कि लाइसेंस सही रूप से सेट किया गया है या नहीं, आप उसे मान्य कर सकते हैं। इस Java कोड में दिखाया गया है कि लाइसेंस कैसे वैधता जांचें:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **Thread Safety**

## **FAQ**

### क्या मैं लाइसेंस को पूरी तरह ऑफ़लाइन वातावरण (कोई इंटरनेट एक्सेस नहीं) में लागू कर सकता हूँ?

हाँ। लाइसेंस सत्यापन स्थानीय रूप से लाइसेंस फ़ाइल का उपयोग करके किया जाता है; इंटरनेट कनेक्शन की आवश्यकता नहीं होती।

### एक‑साल की सब्सक्रिप्शन समाप्त होने के बाद क्या होता है? क्या लाइब्रेरी काम करना बंद कर देगी?

नहीं। लाइसेंस स्थायी है: आप अपनी सब्सक्रिप्शन समाप्ति तिथि से पहले जारी किए गए संस्करणों का उपयोग जारी रख सकते हैं; केवल नया रिलीज़ बिना नवीनीकरण के उपयोग नहीं कर पाएँगे।
