सभी Aspose Java घटकों को Full Trust अनुमति सेट की आवश्यकता होती है। कारण यह है कि Aspose Java घटकों को रजिस्ट्री सेटिंग्स, वर्चुअल डायरेक्टरी के अलावा सिस्टम फ़ाइलों तक पहुँच की आवश्यकता होती है, जैसे फ़ॉन्ट पार्सिंग आदि के कुछ कार्यों के लिए। इसके अलावा, Aspose Java घटक कोर Java सिस्टम क्लासों पर आधारित होते हैं, जिन्हें कई मामलों में भी Full Trust अनुमति सेट की आवश्यकता होती है।

{{% /alert %}}

विभिन्न कंपनियों के कई अनुप्रयोगों की मेजबानी करने वाले इंटरनेट सेवा प्रदाता सामान्यतः Medium Trust सुरक्षा स्तर लागू करते हैं:

- OleDbPermission उपलब्ध नहीं है। इसका अर्थ है कि आप डेटाबेस तक पहुँचने के लिए ADO.NET प्रबंधित OLE DB डेटा प्रदाता का उपयोग नहीं कर सकते।
- EventLogPermission उपलब्ध नहीं है। इसका अर्थ है कि आप Windows इवेंट लॉग तक पहुँच नहीं सकते।
- ReflectionPermission उपलब्ध नहीं है। इसका अर्थ है कि आप रिफ्लेक्शन का उपयोग नहीं कर सकते।
- RegistryPermission उपलब्ध नहीं है। इसका अर्थ है कि आप रजिस्ट्री तक पहुँच नहीं सकते।
- WebPermission प्रतिबंधित है। इसका अर्थ है कि आपका अनुप्रयोग केवल उन पते या पतों की रेंज के साथ संवाद कर सकता है जिन्हें आप <trust> तत्व में परिभाषित करते हैं।
- FileIOPermission प्रतिबंधित है। इसका अर्थ है कि आप केवल अपनी अनुप्रयोग की वर्चुअल डायरेक्टरी पदानुक्रम में फ़ाइलों तक ही पहुँच सकते हैं।

{{% alert color="info" %}}

उपर्युक्त कारणों के कारण, Aspose Java घटकों को उन सर्वरों पर उपयोग नहीं किया जा सकता जो Full Trust के अलावा किसी भी अनुमति सेट को प्रदान करते हैं।

{{% /alert %}}
