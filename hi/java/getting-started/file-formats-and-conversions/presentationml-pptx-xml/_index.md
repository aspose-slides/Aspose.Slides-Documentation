यह एक ऐतिहासिक पृष्ठ है, मौजूदा लिंक के लिए रखा गया है। यह Aspose.Slides for Java के वर्तमान संस्करण का विवरण नहीं देता है। Aspose.Slides for Java द्वारा लोड, इम्पोर्ट, सेव और रेंडर किए जाने वाले फ़ॉर्मैट तथा प्रत्येक के API के बारे में जानने के लिए, देखें [समर्थित फ़ाइल स्वरूप](/slides/hi/java/supported-file-formats/)। PPTX और PPT की तुलना करने के लिए, देखें [अंतर को समझना: PPT बनाम PPTX](/slides/hi/java/ppt-vs-pptx/)।

{{% /alert %}}

{{% alert color="info" title="Note" %}}

PresentationML वह नाम है जो प्रस्तुति दस्तावेज़ों के लिए XML-आधारित फ़ॉर्मैट के परिवार को दर्शाता है। Office OpenXML (OOXML) Microsoft Office 2007 अनुप्रयोगों में प्रस्तुत किया गया XML-आधारित फ़ॉर्मैट है। Office OpenXML कई विशिष्ट XML-आधारित मार्कअप भाषाओं के लिए एक कंटेनर फ़ॉर्मैट है। PresentationML वह मार्कअप भाषा है जिसका उपयोग Microsoft Office PowerPoint 2007 द्वारा दस्तावेज़ों को संग्रहीत करने के लिए किया जाता है।

{{% /alert %}}

## **Aspose.Slides for Java में PresentationML**
OOXML PresentationML दस्तावेज़ PPTX फ़ाइलों के रूप में आते हैं, ज़िप्ड XML पैकेज जो [OOXML ECMA-376](https://ecma-international.org/publications-and-standards/standards/ecma-376/) स्पेसिफ़िकेशन का पालन करते हैं। Aspose.Slides for Java व्यापक रूप से PresentationML दस्तावेज़ों के निर्माण, पढ़ने, संशोधित करने और लिखने का समर्थन करता है। अतिरिक्त रूप से, Aspose.Slides for Java PresentationML दस्तावेज़ों को PDF जैसे व्यापक रूप से उपयोग किए जाने वाले दस्तावेज़ फ़ॉर्मैट में निर्यात करने में सक्षम है। यह संभव इसलिए है क्योंकि Aspose.Slides for Java को प्रस्तुति दस्तावेज़ों को व्यापक रूप से संभालने के उद्देश्य से डिज़ाइन किया गया था और PresentationML मूलतः दस्तावेज़ों की आंतरिक प्रस्तुति को ज़िप्ड XML पैकेज के रूप में रखता है।

## **PresentationML खुला है, Aspose.Slides for Java का उपयोग क्यों करें?**
चूँकि PresentationML XML आधारित है, XML क्लासेज़ का प्रयोग करके PresentationML दस्तावेज़ों को प्रोसेस और जनरेट करने वाले एप्लिकेशन बनाना संभव है बिना किसी थर्ड‑पार्टी क्लास लाइब्रेरी जैसे Aspose.Slides for Java पर निर्भर हुए। लेकिन PresentationML दस्तावेज़ों के साथ काम करते समय XML क्लासेज़ की तुलना में Aspose.Slides for Java का उपयोग करने के कई लाभ हैं।

OOXML स्पेसिफ़िकेशन कई हजार पृष्ठ लंबा है, इसलिए PresentationML दस्तावेज़ों को सही ढंग से संभालने के लिए आपको फ़ॉर्मैट को समझने में काफी समय और प्रयास लगाना पड़ता है। दूसरी ओर, Aspose.Slides for Java के साथ, आप केवल क्लासेज़ और उनके मेथड एवं प्रॉपर्टीज़ का उपयोग करके ऐसी ऑपरेशन्स कर सकते हैं जो XML क्लासेज़ द्वारा किए जाने पर जटिल लगते हैं।

Aspose.Slides द्वारा प्रदान की जाने वाली कुछ सुविधाएँ XML क्लासेज़ के माध्यम से PresentationML दस्तावेज़ों पर काम करते समय उपलब्ध नहीं होतीं:

- PPT दस्तावेज़ों को PDF प्रारूप में निर्यात करें।
- Java फ्रेमवर्क द्वारा समर्थित किसी भी इमेज फ़ॉर्मैट में स्लाइड को रेंडर करें।
- क्लोनिंग फीचर का उपयोग करके स्रोत प्रस्तुति से मास्टर को स्वचालित रूप से कॉपी करें।
- शैप्स पर सुरक्षा लागू करें।

नीचे एक PresentationML दस्तावेज़ का उदाहरण है जिसमें एक स्लाइड है, जो “Hello World” पाठ वाले टेक्स्ट बॉक्स को सम्मिलित करता है। XML क्लासेज़ का उपयोग करके इस पाठ को पढ़ने के लिए आपको एक प्रोग्राम लिखना पड़ेगा जो निम्नलिखित फ्रैगमेंट से इस साधारण पाठ को पार्स कर सके। Aspose.Slides यह आपके लिए करता है।
