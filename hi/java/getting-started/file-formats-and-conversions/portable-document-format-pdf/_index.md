यह एक ऐतिहासिक पृष्ठ है, जिसे मौजूदा लिंक के लिए रखा गया है। यह Aspose.Slides for Java के वर्तमान संस्करण का विवरण नहीं देता है। उन स्वरूपों के लिए जिन्हें Aspose.Slides for Java लोड, आयात, सहेज और रेंडर करता है, और प्रत्येक के लिए API, देखें [समर्थित फ़ाइल स्वरूप](/slides/hi/java/supported-file-formats/). वर्तमान PDF रूपांतरण गाइड के लिए, देखें [PPT और PPTX को PDF में बदलें](/slides/hi/java/convert-powerpoint-to-pdf/).

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[पोर्टेबल दस्तावेज़ स्वरूप](https://en.wikipedia.org/wiki/PDF) एक फ़ाइल स्वरूप है जिसे Adobe Systems ने संगठनों के बीच दस्तावेज़ों का आदान-प्रदान करने के लिए बनाया है। इस स्वरूप का उद्देश्य सामग्री और लेआउट को समान रखना था, चाहे वह किसी भी प्लेटफ़ॉर्म पर देखा जाए। Aspose.Slides for Java आपको प्रस्तुति फ़ाइलों को PDF में बदलने की अनुमति देता है।

{{% /alert %}}

## **Aspose.Slides for Java में PDF**
कोई भी प्रस्तुति जिसे Aspose.Slides for Java में लोड किया जा सकता है, उसे एक PDF में बदल सकता है जो आपके चयन के अनुसार [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) या [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) के अनुरूप हो। Aspose.Slides for Java प्रस्तुतियों को PDF में निर्यात करता है और अधिकांश मामलों में, उत्पन्न PDF बिल्कुल मूल प्रस्तुति जैसा दिखता है।

Aspose.Slides PDF में बदलते समय निम्नलिखित प्रस्तुति सुविधाओं का समर्थन करता है:

- छवियां, टेक्स्ट बॉक्स और अन्य आकार।
- टेक्स्ट और स्वरूपण।
- पैराग्राफ और स्वरूपण।
- हाइपरलिंक्स।
- हेडर और फूटर।
- बुलेट।
- टेबल।

आप Aspose.Slides for Java का उपयोग करके सीधे प्रस्तुतियों को PDF में निर्यात कर सकते हैं: आपको किसी अन्य घटक की आवश्यकता नहीं है। आगे, आप विभिन्न विकल्पों के साथ प्रस्तुति से PDF निर्यात को अनुकूलित कर सकते हैं जैसा कि [PPT और PPTX को PDF में बदलें](/slides/hi/java/convert-powerpoint-to-pdf/) में समझाया गया है।
