Aspose.Slides for Java में PPT से PPTX में रूपांतरण समर्थित है। अधिकांश प्रस्तुति सुविधाएँ - मास्टर स्लाइड्स, संरचना आदि - एक प्रारूप से दूसरे में बदले जाने पर बनाए रखी जाती हैं, लेकिन [कुछ सीमाएँ](/slides/hi/java/ppt-to-pptx-conversion/) हैं।

{{% /alert %}} 
## **Conversion में समर्थित सुविधाएँ**
Aspose.Slides for Java PPT फ़ाइल फ़ॉर्मेट को PPTX में बदलने के लिए आंशिक समर्थन प्रदान करता है। रूपांतरण के लिए समर्थन अभी-अभी Aspose.Slides for Java में पेश किया गया है, इसलिए इसमें कुछ सीमाएँ हैं और यह सरल प्रस्तुतियों के लिये सबसे उपयुक्त है। PPT को PPTX में बदलते समय Aspose.Slides for Java का मुख्य लाभ यह है कि API का उपयोग कितना आसान है। कोड के उदाहरण देखने के लिये, [PPT को PPTX में बदलना]() पढ़ें। नीचे, सूची यह बताती है कि कौन सी सुविधाएँ समर्थित हैं और कौन सी नहीं हैं PPT से PPTX में रूपांतरण के लिए।

## **समर्थित सुविधाएँ**
निम्नलिखित सुविधाएँ रूपांतरण के लिये समर्थित हैं:

- मास्टर, लेआउट और स्लाइड्स की संरचना का रूपांतरण।
- चार्ट्स का रूपांतरण।
- ग्रुप शेप्स का रूपांतरण।
- आटोषेप्स का रूपांतरण, जिसमें आयत और दीर्घवृत्त शामिल हैं।
- कस्टम ज्योमेट्री वाले शैप्स।
- आटोषेप्स के लिये टेक्सचर और चित्र भराव शैली।
- प्लेसहोल्डर्स का रूपांतरण।
- लाइन और पॉलीलाइन का रूपांतरण।
- लाइन और भराव प्रारूप।
- ग्रेडिएंट भराव शैली।
- OLE फ्रेम, टेबल, वीडियो और ऑडियो फ्रेम आदि।
- एनिमेशन और स्लाइडशो गुण।
- टेक्स्ट फ्रेम्स और टेक्स्ट होल्डर्स में टेक्स्ट का रूपांतरण।
