Aspose.Slides for Java से PPT को PPTX में रूपांतरण समर्थित है। अधिकांश प्रेजेंटेशन सुविधाएँ—मास्टर स्लाइड्स, संरचना आदि—एक फ़ॉर्मेट से दूसरे में परिवर्तित होने पर बरकरार रखी जाती हैं, लेकिन कुछ सीमाएँ हैं।

## **रूपांतरण में समर्थित सुविधाएँ**
Aspose.Slides for Java PPT फ़ाइल फ़ॉर्मेट को PPTX में परिवर्तित करने के लिये आंशिक समर्थन प्रदान करता है। रूपांतरण समर्थन अभी-अभी Aspose.Slides for Java में पेश किया गया है, इसलिए इसमें कुछ सीमाएँ हैं और यह सरल प्रस्तुतियों के लिये सबसे बेहतर काम करता है। जब PPT को PPTX में रूपांतरित किया जाता है, तो Aspose.Slides for Java का मुख्य लाभ यह है कि API का उपयोग बहुत आसान है। कोड के उदाहरण देखने के लिये, देखें [PPT को PPTX में परिवर्तित करें](/slides/hi/java/convert-ppt-to-pptx/)। नीचे दी गई सूची दर्शाती है कि PPT से PPTX रूपांतरण के लिये कौन सी सुविधाएँ समर्थित हैं।

## **समर्थित सुविधाएँ**
रूपांतरण के लिये निम्नलिखित सुविधाएँ समर्थित हैं:

- मास्टर, लेआउट और स्लाइड्स की संरचना का रूपांतरण।
- चार्ट का रूपांतरण।
- समूह आकार।
- आयत और अण्डाकार सहित ऑटोषेप्स का रूपांतरण।
- कस्टम ज्यामिति वाले आकार।
- ऑटोषेप्स के लिये टेक्सचर और चित्र भराव शैलियाँ।
- प्लेसहोल्डर्स का रूपांतरण।
- लाइन और पॉलीलाइन का रूपांतरण।
- लाइन और भराव फॉर्मेट।
- ग्रेडिएंट भराव शैलियाँ।
- OLE फ्रेम, टेबल, वीडियो और ऑडियो फ्रेम आदि।
- एनिमेशन और स्लाइडशो प्रॉपर्टीज़।
- टेक्स्ट फ्रेम और टेक्स्ट होल्डर्स में टेक्स्ट का रूपांतरण।
