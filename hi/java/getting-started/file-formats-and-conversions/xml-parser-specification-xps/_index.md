यह एक ऐतिहासिक पृष्ठ है, मौजूदा लिंक के लिए रखा गया है। यह Aspose.Slides for Java के वर्तमान संस्करण का वर्णन नहीं करता है। उन फ़ॉर्मैट्स के लिए जिन्हें Aspose.Slides for Java लोड करता है, आयात करता है, सहेजता है और रेंडर करता है, और प्रत्येक का API, देखें [Supported File Formats](/slides/hi/java/supported-file-formats/). वर्तमान XPS परिवर्तन मार्गदर्शिका के लिए, देखें [Convert PowerPoint Presentations to XPS](/slides/hi/java/convert-powerpoint-to-xps/).

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) एक पेज विवरण भाषा और एक फिक्स्ड-डॉक्यूमेंट फ़ॉर्मैट है जिसे मूल रूप से माइक्रोसॉफ्ट द्वारा विकसित किया गया था। PDF की तरह, XPS को दस्तावेज़ की सच्चाई को बनाए रखने और उपकरण-स्वतंत्र दस्तावेज़ रूप-रखा प्रदान करने के लिए डिज़ाइन किया गया है।

{{% /alert %}}

## **Aspose.Slides for Java में XPS**
कोई भी प्रस्तुति दस्तावेज़ जिसे Aspose.Slides for Java द्वारा लोड किया जा सकता है, XPS फ़ॉर्मैट में परिवर्तित किया जा सकता है। Aspose.Slides for Java उच्च-निष्ठा पेज लेआउट और रेंडरिंग इंजन का उपयोग करके फिक्स्ड-लेआउट XPS दस्तावेज़ फ़ॉर्मैट में आउटपुट उत्पन्न करता है। आप Aspose.Slides for Java के माध्यम से प्रस्तुति दस्तावेज़ों को XPS दस्तावेज़ों में निर्यात करने के बारे में [Convert PowerPoint Presentations to XPS](/slides/hi/java/convert-powerpoint-to-xps/) में सीख सकते हैं।
