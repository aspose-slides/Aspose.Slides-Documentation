{{% alert color="info" title="Note" %}}

यह एक ऐतिहासिक पृष्ठ है, मौजूदा लिंक के लिए रखा गया है। यह Aspose.Slides for Java के वर्तमान संस्करण का वर्णन नहीं करता है। उन फ़ॉर्मेट्स के लिए जिनको Aspose.Slides for Java लोड, आयात, सहेज और रेंडर करता है, तथा प्रत्येक की API, देखें [समर्थित फ़ाइल फॉर्मेट्स](/slides/hi/java/supported-file-formats/)। PPT और PPTX की तुलना करने के लिए, देखें [अंतर को समझें: PPT बनाम PPTX](/slides/hi/java/ppt-vs-pptx/)।

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) वह प्रेज़ेंटेशन दस्तावेज़ फ़ाइल फ़ॉर्मेट है जिसे विभिन्न संस्करणों के Microsoft PowerPoint द्वारा बनाया, पढ़ा, संशोधित और लिखा जा सकता है। यह Microsoft द्वारा विकसित प्रेज़ेंटेशन दस्तावेज़ों के लिए बाइनरी फ़ॉर्मेट है।

{{% /alert %}}

## **Aspose.Slides for Java में PPT**
Aspose.Slides for Java नीचे सूचीबद्ध सॉफ़्टवेयर द्वारा बनाए गए PPT फ़ाइलें पढ़ सकता है।

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

इसी प्रकार, Aspose.Slides for Java द्वारा बनाए गए PPT फ़ाइलें ऊपर दिए गए सॉफ़्टवेयर द्वारा पढ़ी जा सकती हैं।

## **PPT के लिए व्यापक समर्थन**
Aspose.Slides for Java PPT दस्तावेज़ फ़ॉर्मेट द्वारा समर्थित लगभग सभी सुविधाओं के लिए समर्थन प्रदान करता है। यह न केवल विभिन्न Microsoft PowerPoint संस्करणों द्वारा प्रदान की गई बुनियादी और उन्नत सुविधाओं को कवर करता है, बल्कि उन सुविधाओं को भी शामिल करता है जो Microsoft PowerPoint द्वारा समर्थित नहीं हैं। Aspose.Slides for Java API लाइब्रेरी का मुख्य लाभ इन सुविधाओं को संभालने में उपयोग में आसान होना है।

PPT दस्तावेज़ फ़ाइलों को बनाने, पढ़ने और लिखने से संबंधित बुनियादी कार्यों के अतिरिक्त, Aspose.Slides for Java द्वारा कई सुविधाएँ प्रदान की जाती हैं:

- अन्य Microsoft Office फ़ाइल फ़ॉर्मेट को [OLE ऑब्जेक्ट्स को PPT दस्तावेज़ों में](/slides/hi/java/manage-ole/) आयात करें।
- [PPT दस्तावेज़ को PDF में निर्यात करें](/slides/hi/java/convert-powerpoint-to-pdf/)।
- PPT दस्तावेज़ों में स्लाइड्स को SVG फ़ॉर्मेट में निर्यात करें।
- स्लाइड्स को Java फ़्रेमवर्क द्वारा समर्थित किसी भी इमेज फ़ॉर्मेट में रेंडर करें।
- PPT दस्तावेज़ों में स्लाइड्स का आकार सेट करें।
- शैप्स पर एनीमेशन प्रबंधित करें।
- स्लाइड शो प्रबंधित करें।
- [स्लाइड्स पर टेक्स्ट फॉर्मेट करें](/slides/hi/java/text-formatting/)।
- PPT दस्तावेज़ों से टेक्स्ट निकालें।
- [स्लाइड्स पर टेबल्स को संभालें](/slides/hi/java/powerpoint-table/)।
- स्वचालित रूप से मास्टर्स को कॉपी करने के लिए [क्लोनिंग फीचर](/slides/hi/java/clone-slides/) का उपयोग करें।
