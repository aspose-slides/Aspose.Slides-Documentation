[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) एक प्रस्तुति दस्तावेज़ फ़ाइल स्वरूप है जिसे विभिन्न संस्करणों के Microsoft PowerPoint द्वारा बनाया, पढ़ा, संशोधित और लिखा जा सकता है। यह Microsoft द्वारा विकसित प्रस्तुति दस्तावेज़ों के लिए बाइनरी स्वरूप है।

{{% /alert %}} 

## **Aspose.Slides for Java में PPT**
Aspose.Slides for Java नीचे सूचीबद्ध सॉफ़्टवेयर द्वारा बनाए गए PPT फ़ाइलों को पढ़ सकता है।

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

इसी तरह, Aspose.Slides for Java द्वारा बनाए गए PPT फ़ाइलों को उपर्युक्त सॉफ़्टवेयर द्वारा पढ़ा जा सकता है।

## **PPT के लिए व्यापक समर्थन**
Aspose.Slides for Java लगभग सभी विशेषताओं के लिए समर्थन प्रदान करता है जो PPT दस्तावेज़ फ़ाइल स्वरूप द्वारा समर्थित हैं। यह केवल विभिन्न Microsoft PowerPoint संस्करणों द्वारा प्रदान की गई बुनियादी और उन्नत सुविधाओं को ही नहीं, बल्कि उन सुविधाओं को भी कवर करता है जो Microsoft PowerPoint द्वारा समर्थित नहीं हैं। Aspose.Slides for Java API लाइब्रेरी का मुख्य लाभ इन सुविधाओं को संभालने की आसान उपयोगिता है।

बुनियादी कार्यों जैसे PPT दस्तावेज़ फ़ाइलों को बनाना, पढ़ना और लिखना के अलावा, Aspose.Slides for Java कई अतिरिक्त सुविधाएँ प्रदान करता है:

- अन्य Microsoft Office फ़ाइल फ़ॉर्मेट को [OLE वस्तुओं के रूप में PPT दस्तावेज़ों में]()
- [PPT दस्तावेज़ों को PDF में निर्यात करें](/slides/hi/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- PPT दस्तावेज़ों में स्लाइड्स को SVG स्वरूप में निर्यात करें।
- स्लाइड्स को Java फ़्रेमवर्क द्वारा समर्थित किसी भी छवि स्वरूप में रेंडर करें।
- PPT दस्तावेज़ों में स्लाइड्स का आकार सेट करें।
- आकारों पर एनीमेशन को प्रबंधित करें।
- स्लाइड शो को प्रबंधित करें।
- [स्लाइड्स पर पाठ को स्वरूपित करें]().
- PPT दस्तावेज़ों से पाठ निकालें।
- [स्लाइड्स पर तालिकाओं को संभालें]().
- [क्लोनिंग सुविधा] का उपयोग करके स्वचालित रूप से मास्टर्स को कॉपी करें।
