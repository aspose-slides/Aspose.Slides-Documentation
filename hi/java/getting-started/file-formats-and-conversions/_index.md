इस अनुभाग में लेख व्यक्तिगत फ़ाइल प्रारूपों के पुराने अवलोकन हैं, जो मौजूदा लिंक के लिए रखे गए हैं। ये Aspose.Slides for Java के वर्तमान संस्करण का वर्णन नहीं करते हैं। Aspose.Slides for Java द्वारा लोड, आयात, सहेज और रेंडर किए जाने वाले प्रारूपों तथा प्रत्येक के API के लिए, देखें [Supported File Formats](/slides/hi/java/supported-file-formats/)। रूपांतरण मार्गदर्शकों के लिए, देखें [Convert Presentations](/slides/hi/java/convert-presentation/)।
