## **TIFF के बारे में**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) एक ऐसा फ़ॉर्मेट है जो एक दस्तावेज़ में कई छवियों को संग्रहीत करने के लिए जाना जाता है, जिसे मूल रूप से Aldus ने बनाया था। यह फ़ॉर्मेट स्कैनिंग, फ़ैक्सिंग और अन्य छवि हेरफ़ेर अनुप्रयोगों द्वारा व्यापक रूप से समर्थित है।

## **Aspose.Slides for Java में TIFF**

Aspose.Slides for Java में लोड की जा सकने वाली कोई भी दस्तावेज़ सीधे Aspose.Slides for Java द्वारा TIFF दस्तावेज़ में बदला जा सकता है, जिससे किसी तीसरे पक्ष के घटक की आवश्यकता समाप्त हो जाती है। इसके अतिरिक्त, आप वैकल्पिक रूप से परिणामी TIFF दस्तावेज़ में छवियों का आकार निर्धारित कर सकते हैं। Aspose.Slides for Java के माध्यम से प्रस्तुति दस्तावेज़ों को TIFF दस्तावेज़ों में निर्यात करने के बारे में जानकारी आप [Convert PowerPoint Presentations to TIFF](/slides/hi/java/convert-powerpoint-to-tiff/) में पा सकते हैं।

**Aspose.Slides for Java के माध्यम से TIFF दस्तावेज़ में बदला गया एक प्रस्तुति दस्तावेज़**
