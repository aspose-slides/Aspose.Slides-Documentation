## **समर्थित प्लेटफ़ॉर्म**
Aspose.Slides for Java सबसे लोकप्रिय विकास और तैनाती प्लेटफ़ॉर्मों का समर्थन करता है।

|**फ़ीचर**|**विवरण**|
| :- | :- |
|डेस्कटॉप एप्लिकेशन|Aspose.Slides for Java का उपयोग Windows Forms एप्लिकेशन विकसित करने के लिए किया जा सकता है।|
|एंटरप्राइज़ वेब एप्लिकेशन|Aspose.Slides for Java वेब एप्लिकेशन बनाने में मदद करता है। Aspose.Slides for Java को PHP के साथ उपयोग करने का समर्थन भी प्रदान किया जाता है।|
|Linux/Unix|Aspose.Slides for Java एक प्लेटफ़ॉर्म स्वतंत्र API है और Linux और Unix वातावरण में कार्य कर सकता है।|

## **FAQ**

### क्या लाइब्रेरी के काम करने के लिए सर्वर/पीसी पर Microsoft PowerPoint स्थापित करना आवश्यक है?

नहीं। PowerPoint आवश्यक नहीं है; Aspose.Slides एक स्टैंडअलोन इंजन है जो प्रस्तुतियों को बनाने, संपादित करने, रूपांतरित करने और रेंडर करने के काम आता है।

### मल्टीथ्रेडिंग कैसे काम करती है? क्या प्रोसेसिंग को समानांतर किया जा सकता है?

विभिन्न थ्रेड्स में विभिन्न दस्तावेज़ों को प्रोसेस करना सुरक्षित है; एक ही [presentation](https://reference.aspose.com/slides/hi/java/com.aspose.slides/presentation/) ऑब्जेक्ट को [एकाधिक थ्रेड्स](/slides/hi/java/multithreading/) द्वारा एक साथ उपयोग नहीं करना चाहिए।

### क्या फ़ाइल पासवर्ड और एन्क्रिप्शन समर्थित हैं?

हां। आप एन्क्रिप्टेड प्रस्तुतियों को खोल सकते हैं, खोलने और लिखने के पासवर्ड सेट या हटा सकते हैं, और सुरक्षा स्थिति जांच सकते हैं। ([आप कर सकते हैं](/slides/hi/java/password-protected-presentation/))

### क्या Linux कंटेनरों में फ़ॉन्ट पैकेजों की देखरेख आवश्यक है?

हां। अप्रत्याशित प्रतिस्थापन से बचने के लिए सामान्य फ़ॉन्ट पैकेजों को स्थापित करने या अपने एप्लिकेशन में स्पष्ट रूप से [फ़ॉन्ट डायरेक्टरी निर्दिष्ट](/slides/hi/java/custom-font/) करने की सलाह दी जाती है।

### मूल्यांकन संस्करण में कोई सीमाएँ हैं?

[मूल्यांकन मोड](/slides/hi/java/licensing/) में आउटपुट में वॉटरमार्क जोड़ा जाता है और कुछ सीमाएँ लागू होती हैं; पूर्ण‑फ़ीचर परीक्षण के लिए एक [30‑दिवसीय अस्थायी लाइसेंस](https://purchase.aspose.com/temporary-license/) उपलब्ध है।

### क्या बाहरी फ़ॉर्मेट (PDF/HTML → PPTX) को प्रस्तुति में आयात करना समर्थित है?

हां। आप [PDF पेज़ और HTML सामग्री](/slides/hi/java/import-presentation/) को प्रस्तुति में जोड़ सकते हैं, जिससे वे स्लाइड्स में बदल जाती हैं।
