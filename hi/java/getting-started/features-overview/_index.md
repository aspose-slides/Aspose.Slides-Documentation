## **अवलोकन**

Aspose.Slides for Java एक क्लास लाइब्रेरी है जो PowerPoint और OpenDocument प्रेज़ेंटेशन बनाने, पढ़ने, संपादित करने, रूपांतरित करने और रेंडर करने के लिए प्रयोग की जाती है। इसका अपना कोई यूज़र इंटरफ़ेस नहीं है और इसे Microsoft PowerPoint या Microsoft Office की आवश्यकता नहीं होती। यह लेख लाइब्रेरी के कवरेज का सार प्रस्तुत करता है और उन लेखों के लिंक देता है जो प्रत्येक क्षेत्र का वर्णन करते हैं।

## **समर्थित प्लेटफ़ॉर्म**

Aspose.Slides for Java एकल JAR फ़ाइल है, जो Aspose के Maven रिपॉजिटरी में `jdk16` क्लासिफ़ायर के साथ प्रकाशित की गई है। यह शुद्ध Java में लिखी गई है: JAR में कोई नेटिव लाइब्रेरी नहीं है, और यह अन्य पैकेजों पर निर्भर नहीं करती।

- **Java:** Java 8 या बाद का। Aspose.Slides for Java 26.9 और पूर्व के संस्करण Java 6 और 7 पर भी चलते थे, जो संस्करण 26.10 अब समर्थित नहीं करता; देखें [26.9 रिलीज़ नोट्स](https://releases.aspose.com/slides/hi/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/)।
- **ऑपरेटिंग सिस्टम:** कोई भी ऑपरेटिंग सिस्टम जिसमें Java runtime हो, जैसे Windows, Linux, और macOS। Linux पर, fontconfig लाइब्रेरी और कम से कम एक फ़ॉन्ट स्थापित होना चाहिए।

[स्थापना](/slides/hi/java/installation/) दिखाता है कि लाइब्रेरी को प्रोजेक्ट में कैसे जोड़ें और Linux की पूर्वापेक्षाएँ सूचीबद्ध करता है। [सिस्टम आवश्यकताएँ](/slides/hi/java/system-requirements/) विस्तृत रूप से समर्थित प्लेटफ़ॉर्म की सूची देती हैं।

## **फ़ाइल फ़ॉर्मेट और रूपांतरण**

Aspose.Slides PPT, PPTX, PPS, POT, PPSX, POTX, PPTM, PPSM, POTM, ODP, OTP, FODP, और PowerPoint XML प्रेज़ेंटेशन खोलता और सहेजता है। यह PDF और HTML सामग्री को स्लाइड में आयात करता है, और प्रेज़ेंटेशन को PDF, XPS, HTML, HTML5, TIFF, एनिमेटेड GIF, SWF, Markdown, और XAML के रूप में सहेजता है। [समर्थित फ़ाइल फ़ॉर्मेट](/slides/hi/java/supported-file-formats/) प्रत्येक फ़ॉर्मेट को सूचीबद्ध करता है साथ ही वह API जो इसे पढ़ता या लिखता है।

## **प्रेज़ेंटेशन रेंडरिंग**

Aspose.Slides स्लाइड और व्यक्तिगत आकारों को PNG, JPEG, BMP, GIF, TIFF, और SVG छवियों के रूप में, और स्लाइड को EMF मेटाफाइल के रूप में रेंडर करता है। देखें [प्रेज़ेंटेशन स्लाइड को छवियों में बदलें](/slides/hi/java/convert-slide/), [प्रेज़ेंटेशन स्लाइड को SVG छवि के रूप में रेंडर करें](/slides/hi/java/render-a-slide-as-an-svg-image/), और [प्रेज़ेंटेशन आकारों के थंबनेल बनाएं](/slides/hi/java/create-shape-thumbnails/)।

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या लाइब्रेरी को काम करने के लिए सर्वर या पीसी पर Microsoft PowerPoint स्थापित करने की आवश्यकता है?**

नहीं। PowerPoint आवश्यक नहीं है; Aspose.Slides एक स्वतंत्र इंजन है जो प्रेज़ेंटेशन बनाने, संपादित करने, रूपांतरित करने और रेंडर करने के लिए है।

**मल्टीथ्रेडिंग कैसे कार्य करती है? क्या प्रोसेसिंग को समानांतर किया जा सकता है?**

विभिन्न थ्रेड में अलग-अलग दस्तावेज़ों को प्रोसेस करना सुरक्षित है; वही [Presentation](https://reference.aspose.com/slides/hi/java/com.aspose.slides/presentation/) ऑब्जेक्ट को [multiple threads](/slides/hi/java/multithreading/) द्वारा एक साथ उपयोग नहीं किया जाना चाहिए।

**क्या फ़ाइल पासवर्ड और एन्क्रिप्शन समर्थित हैं?**

हां। आप [पासवर्ड‑रक्षित प्रेज़ेंटेशन](/slides/hi/java/password-protected-presentation/) खोल सकते हैं, खोलने और लिखने का पासवर्ड सेट या हटाते हैं, और सुरक्षा स्थिति जाँचते हैं।

**क्या मुझे Linux कंटेनरों में फ़ॉन्ट्स के बारे में चिंता करनी चाहिए?**

हां। Linux पर, fontconfig लाइब्रेरी और कम से कम एक फ़ॉन्ट स्थापित होना चाहिए, और आपके प्रेज़ेंटेशन में उपयोग किए गए फ़ॉन्ट या उपयुक्त विकल्प स्थापित होने चाहिए ताकि टेक्स्ट सही ढंग से रेंडर हो सके। आप अपने एप्लिकेशन में [फ़ॉन्ट डायरेक्टरी](/slides/hi/java/custom-font/) भी निर्दिष्ट कर सकते हैं। देखें [स्थापना](/slides/hi/java/installation/#linux)।

**क्या मूल्यांकन संस्करण में कोई सीमाएँ हैं?**

हां। बिना [लाइसेंस](/slides/hi/java/licensing/) के, Aspose.Slides हर सहेजी गई स्लाइड पर मूल्यांकन वॉटरमार्क जोड़ता है और API के माध्यम से पढ़े गए टेक्स्ट को ट्रंकेट करता है। पूर्ण‑फ़ीचर परीक्षण के लिए एक [30‑दिन का अस्थायी लाइसेंस](https://purchase.aspose.com/temporary-license/) उपलब्ध है।

**क्या प्रेज़ेंटेशन में बाहरी फ़ॉर्मेट (PDF या HTML से PPTX) आयात करना समर्थित है?**

हां। आप [PDF पेज़ और HTML सामग्री](/slides/hi/java/import-presentation/) को प्रेज़ेंटेशन में जोड़ सकते हैं, उन्हें स्लाइड में बदलते हुए।
