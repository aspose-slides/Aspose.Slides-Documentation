एक नया [Aspose.Slides for Java API](/slides/hi/java/) जारी किया गया है और अब यह एकल उत्पाद स्क्रैच से PowerPoint दस्तावेज़ बनाने और मौजूदा दस्तावेज़ों को संपादित करने की क्षमता को समर्थन देता है।

{{% /alert %}} 
## **पुराने कोड के लिए समर्थन**
Aspose.Slides for Java के 13.x से पहले के संस्करणों में विकसित किए गए लेगसी कोड का उपयोग करने के लिए, आपको अपने कोड में कुछ छोटे बदलाव करने की आवश्यकता है और कोड पहले की तरह काम करेगा। Aspose.Slides for Java में पुराने Aspose.Slide और Aspose.Slides.Pptx नेमस्पेसेज़ में मौजूद सभी क्लासेज अब एकल Aspose.Slides नेमस्पेस में मर्ज कर दिए गए हैं। कृपया नीचे दिए गए सरल कोड स्निपेट को देखें जो लेगसी Aspose.Slides API में एक Hello World Presentation दस्तावेज़ बनाने के लिए है और नई मर्ज की गई API में माइग्रेट करने के चरणों का पालन करें।
