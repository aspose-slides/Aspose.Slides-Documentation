{{% alert color="info" %}} 
एक नया [Aspose.Slides for Java API](https://docs.aspose.com/slides/hi/java/) जारी किया गया है और अब यह एकल उत्पाद स्क्रैच से PowerPoint दस्तावेज़ बनाने और मौजूदा दस्तावेज़ों को संपादित करने की क्षमता का समर्थन करता है।
{{% /alert %}} 
## **पुराने कोड के लिए समर्थन**
Aspose.Slides for Java के 13.x से पहले के संस्करणों के साथ विकसित किए गए पुराने कोड का उपयोग करने के लिए आपको अपने कोड में कुछ छोटे परिवर्तन करने होंगे और कोड पहले की तरह काम करेगा। पुराने Aspose.Slides for Java में Aspose.Slide और Aspose.Slides.Pptx नेमस्पेसेस के अंतर्गत मौजूद सभी क्लासें अब एकल Aspose.Slides नेमस्पेस में मिल गई हैं। कृपया नीचे दिया गया सरल कोड स्निपेट देखें जो लेगेसी Aspose.Slides API में प्रस्तुति में हेडर फ़ूटर जोड़ता है और नई सम्मिलित API में माइग्रेट करने के चरणों का पालन करें।
