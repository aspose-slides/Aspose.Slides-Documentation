एक नया [Aspose.Slides for Java API](https://docs.aspose.com/slides/hi/java/) जारी किया गया है और अब यह एकल उत्पाद शुरू से PowerPoint दस्तावेज़ बनाने और मौजूदा दस्तावेज़ों को संपादित करने की क्षमता का समर्थन करता है।
{{% /alert %}} 
## **पुराने कोड के लिए समर्थन**
परम्परागत कोड जो Aspose.Slides for Java के 14.x.x से पहले के संस्करणों के साथ विकसित किया गया है, उसे उपयोग करने के लिए आपको अपने कोड में कुछ छोटे परिवर्तन करने होंगे और कोड पहले की तरह काम करेगा। पुराने Aspose.Slides for Java में com.aspose.slides और com.aspose.slides.pptx नामस्थान के तहत मौजूद सभी क्लासेज अब एक ही com.aspose.slides नामस्थान में मिलाए जा चुके हैं। कृपया नीचे दिया गया सरल कोड स्निपेट देखें जो परम्परागत Aspose.Slides API का उपयोग करके प्रस्तुति में शुरू से एक सामान्य चार्ट बनाने के लिए है और नए एकीकृत API में माइग्रेट करने के चरणों का अनुसरण करें।
