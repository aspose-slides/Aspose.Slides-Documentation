## **परिचय**

Aspose.Slides पावरपॉइंट प्रस्तुतियों में स्लाइड आकार और आस्पेक्ट अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करती है, जो प्रिंटिंग और ऑन-स्क्रीन प्रदर्शन दोनों के लिए महत्वपूर्ण है।

लोकप्रिय स्लाइड आकार और अनुपात:

- **मानक (4:3 आस्पेक्ट अनुपात)**: पुराने स्क्रीन और उपकरणों के लिए आदर्श।
- **वाइडस्क्रीन (16:9 आस्पेक्ट अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सुनिश्चित करें कि आपकी प्रस्तुति में संपूर्णता बनी रहे क्योंकि सभी स्लाइड पर एक ही स्लाइड आकार और आस्पेक्ट अनुपात लागू होते हैं। इष्टतम परिणामों के लिए, जटिलताओं से बचने हेतु अपनी प्रस्तुति निर्माण प्रक्रिया की शुरुआत में ही स्लाइड आयाम सेट करें।

{{% alert color="info" title="Note" %}}
डिफ़ॉल्ट रूप से, Aspose.Slides द्वारा बनाई गई प्रस्तुतियों में मानक 4:3 आस्पेक्ट अनुपात उपयोग होता है।
{{% /alert %}}

नोट्स और हैंडआउट पृष्ठों के आयाम सामान्य स्लाइडों से अलग होते हैं। उनका आकार और अभिविन्यास बदलने के लिए देखें [Notes Page Size](/slides/hi/java/notes-size/)।

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड दिखाता है कि Aspose.Slides का उपयोग करके जावा में प्रस्तुति के स्लाइड आकार को कैसे बदलें:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आप पाते हैं कि सामान्य स्लाइड आकार (4:3 और 16:9) आपके कार्य के लिए उपयुक्त नहीं हैं, तो आप विशिष्ट या अनोखा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रस्तुति से कस्टम पृष्ठ लेआउट पर पूर्ण‑आकार स्लाइड प्रिंट करने की योजना बनाते हैं या यदि आप अपनी प्रस्तुति को कुछ विशेष स्क्रीन प्रकारों पर प्रदर्शित करने का इरादा रखते हैं, तो कस्टम आकार सेटिंग का उपयोग करने से आपको लाभ मिल सकता है।

यह नमूना कोड दिखाता है कि जावा में Aspose.Slides for Java का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट किया जाए:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // A4 कागज़ आकार
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **स्लाइड आकार बदलने के बाद स्लाइड सामग्री को संभालें**

प्रस्तुति का स्लाइड आकार बदलने के बाद, स्लाइड की सामग्री (जैसे छवियाँ या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट नई स्लाइड आकार के अनुसार स्वचालित रूप से रिसाइज़ हो जाते हैं। हालांकि, प्रस्तुति के स्लाइड आकार को बदलते समय, आप एक सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करती है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालता है।

आप जो करने या प्राप्त करने की योजना बना रहे हैं, उसके आधार पर आप इन सेटिंग्स में से किसी का उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप नहीं चाहते कि स्लाइड पर मौजूद ऑब्जेक्ट रिसाइज़ हों, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार के लिए स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट को नीचे स्केल करे ताकि सभी स्लाइड पर फिट हो जाएँ (इस तरह आप सामग्री न खोने से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार के लिए स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट को बड़ा करे ताकि वे नए स्लाइड आकार के अनुपात में हों, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड दिखाता है कि प्रस्तुति की स्लाइड का आकार बदलते समय `Maximize` सेटिंग का उपयोग कैसे करें:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (उदाहरण के लिए, पॉइंट्स या मिलिमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?**

हाँ। Aspose.Slides आंतरिक रूप से पॉइंट्स उपयोग करता है, जहाँ 1 पॉइंट 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलिमीटर या सेंटीमीटर) को पॉइंट्स में परिवर्तित कर सकते हैं और परिवर्तित मानों का उपयोग करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित कर सकते हैं।

**क्या बहुत बड़ी कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगी?**

हाँ। बड़ी स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी उपयोग में वृद्धि और प्रक्रिया समय को लंबा कर देते हैं। व्यावहारिक स्लाइड आकार का लक्ष्य रखें और केवल आवश्यकतानुसार रेंडरिंग स्केल समायोजित करें ताकि इच्छित आउटपुट गुणवत्ता प्राप्त हो सके।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकार वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूँ?**

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों को [merge presentations](/slides/hi/java/merge-presentation/) नहीं कर सकते — पहले एक प्रस्तुति को दूसरे के आकार से मिलाने के लिए रिसाइज़ करें। स्लाइड आकार बदलते समय, आप मौजूदा सामग्री के संभालने का तरीका [SlideSizeScaleType](https://reference.aspose.com/slides/hi/java/com.aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार संरेखित करने के बाद, आप फ़ॉर्मेटिंग को संरक्षित रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

**क्या मैं किसी व्यक्तिगत आकार या स्लाइड के विशेष क्षेत्रों के थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?**

हाँ। Aspose.Slides [entire slides](https://reference.aspose.com/slides/hi/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) के थंबनेल तथा [selected shapes](https://reference.aspose.com/slides/hi/java/com.aspose.slides/shape/#getImage-int-float-float-) के थंबनेल दोनों उत्पन्न कर सकता है। परिणामी छवियाँ वर्तमान स्लाइड आकार और आस्पेक्ट अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में संगति बनी रहती है।
