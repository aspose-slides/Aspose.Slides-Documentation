## **परिचय**

Aspose.Slides प्रिंटिंग और स्क्रीन पर प्रदर्शन दोनों के लिए महत्वपूर्ण, PowerPoint प्रस्तुतियों में स्लाइड आकार और अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करता है।

लोकप्रिय स्लाइड आकार और अनुपात:

- **Standard (4:3 Aspect Ratio)**: पुराने स्क्रीन और उपकरणों के लिए आदर्श।
- **Widescreen (16:9 Aspect Ratio)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सभी स्लाइड्स पर एक ही स्लाइड आकार और अनुपात लागू होने के कारण अपनी प्रस्तुति में निरंतरता सुनिश्चित करें। इष्टतम परिणामों के लिए, प्रस्तुति निर्माण प्रक्रिया की शुरुआत में अपने स्लाइड आयाम सेट करें ताकि जटिलताओं से बचा जा सके।

{{% alert color="info" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides द्वारा बनाई गई प्रस्तुतियों में मानक 4:3 अनुपात उपयोग किया जाता है।
{{% /alert %}}

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड आपको Aspose.Slides का उपयोग करके जावा में प्रस्तुति में स्लाइड आकार कैसे बदलें, दिखाता है।

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आप सामान्य स्लाइड आकार (4:3 और 16:9) को अपने कार्य के लिए उपयुक्त नहीं पाते हैं, तो आप एक विशिष्ट या अनोखा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के रूप में, यदि आप अपनी प्रस्तुति से कस्टम पेज लेआउट पर पूरे आकार की स्लाइडें प्रिंट करने की योजना बनाते हैं या कुछ प्रकार की स्क्रीन पर अपनी प्रस्तुति दिखाने चाहते हैं, तो कस्टम आकार सेटिंग उपयोग करने से आपको लाभ मिल सकता है।

यह नमूना कोड आपको Java में Aspose.Slides का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार निर्दिष्ट करने का तरीका दिखाता है।

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // A4 कागज का आकार
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **आकार बदलने के बाद स्लाइड सामग्री संभालें**

प्रस्तुति में स्लाइड आकार बदलने के बाद, स्लाइड की सामग्री (जैसे चित्र या ऑब्जेक्ट) बिगड़ सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट्स स्वचालित रूप से नए स्लाइड आकार के अनुसार आकार बदल लेते हैं। हालांकि, प्रस्तुति का स्लाइड आकार बदलते समय, आप ऐसा सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करे कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालेगा।

आपके उद्देश्य के अनुसार आप इन सेटिंग्स में से कोई भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर ऑब्जेक्ट्स को री‑साइज़ नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार के लिए स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides सभी ऑब्जेक्ट्स को स्लाइड में फिट करने के लिए छोटे आकार में स्केल करे (इस प्रकार सामग्री का न खोने का सुनिश्चित करता है), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार के लिए स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट्स को नए स्लाइड आकार के अनुपात में बड़े आकार में बढ़ाए, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड दर्शाता है कि प्रस्तुति की स्लाइड का आकार बदलते समय `Maximize` सेटिंग का उपयोग कैसे करें:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट्स में बदल सकते हैं और परिवर्तित मानों का उपयोग स्लाइड की चौड़ाई और ऊँचाई निर्धारित करने के लिए कर सकते हैं।

### क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?

हां। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी खपत बढ़ाते हैं और प्रोसेसिंग समय को लंबा करते हैं। व्यावहारिक स्लाइड आकार निर्धारित करें और वांछित आउटपुट गुणवत्ता पाने के लिए केवल आवश्यकतानुसार रेंडरिंग स्केल समायोजित करें।

### क्या मैं एक गैर‑मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकार वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूँ?

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों को [merge presentations](/slides/hi/java/merge-presentation/) नहीं कर सकते — पहले एक प्रस्तुति को दूसरे के आकार से मिलाएँ। स्लाइड आकार बदलते समय आप मौजूदा सामग्री को कैसे संभालना है, यह [SlideSizeScaleType](https://reference.aspose.com/slides/hi/java/com.aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार समान करने के बाद, आप स्वरूपण बरकरार रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

### क्या मैं स्लाइड के व्यक्तिगत शैलियों या विशिष्ट क्षेत्रों के लिए थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?

हां। Aspose.Slides [entire slides](https://reference.aspose.com/slides/hi/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) और [selected shapes](https://reference.aspose.com/slides/hi/java/com.aspose.slides/shape/#getImage-int-float-float-) दोनों के लिए थंबनेल रेंडर कर सकता है। उत्पन्न छवियां वर्तमान स्लाइड आकार और अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और जियोमेट्री में निरंतरता बनी रहती है।
