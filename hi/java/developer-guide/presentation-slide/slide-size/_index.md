## **परिचय**

Aspose.Slides व्यापक उपकरण प्रदान करता है जिससे PowerPoint प्रस्तुतियों में स्लाइड आकार और एस्पेक्ट रेशियो को समायोजित किया जा सके, जो मुद्रण और स्क्रीन पर प्रदर्शित करने दोनों के लिए महत्वपूर्ण है।

प्रसिद्ध स्लाइड आकार और रेशियो:

- **स्टैंडर्ड (4:3 एस्पेक्ट रेशियो)**: पुराने स्क्रीन और डिवाइस के लिए आदर्श।
- **वाइडस्क्रीन (16:9 एस्पेक्ट रेशियो)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सुनिश्चित करें कि आपके प्रस्तुति में पूरे स्लाइड्स में एक ही स्लाइड आकार और एस्पेक्ट रेशियो लागू हो, जिससे सामंजस्य बना रहे। इष्टतम परिणामों के लिए, अपने स्लाइड के आयाम प्रस्तुति निर्माण प्रक्रिया की शुरुआत में ही निर्धारित करें ताकि बाद में जटिलताओं से बचा जा सके।

{{% alert color="primary" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides द्वारा बनाई गई प्रस्तुतियों में मानक 4:3 एस्पेक्ट रेशियो का उपयोग किया जाता है।
{{% /alert %}}

## **प्रस्तुति में स्लाइड आकार बदलें**

यह नमूना कोड दिखाता है कि Java में Aspose.Slides का उपयोग करके प्रस्तुति में स्लाइड आकार कैसे बदला जाए:

```java
Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **प्रस्तुति में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आपको सामान्य स्लाइड आकार (4:3 और 16:9) आपके कार्य के लिए उपयुक्त नहीं लगते हैं, तो आप एक विशिष्ट या अनूठा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रस्तुति से कस्टम पेज लेआउट पर पूर्ण आकार की स्लाइडें प्रिंट करने की योजना बनाते हैं या यदि आप अपनी प्रस्तुति को कुछ विशेष स्क्रीन प्रकारों पर प्रदर्शित करना चाहते हैं, तो कस्टम आकार सेटिंग का उपयोग करने से आपको लाभ हो सकता है।

यह नमूना कोड दिखाता है कि Java में Aspose.Slides for Java का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट किया जाए:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // A4 कागज आकार
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **आकार बदलने के बाद स्लाइड सामग्री को संभालें**

जब आप प्रस्तुति का स्लाइड आकार बदलते हैं, तो स्लाइड की सामग्री (जैसे छवियाँ या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट नई स्लाइड आकार में फिट होने के लिए स्वतः री-साइज़ हो जाते हैं। हालांकि, प्रस्तुति के स्लाइड आकार को बदलते समय, आप एक सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करती है कि Aspose.Slides स्लाइडों की सामग्री को कैसे संभालता है।

आपके लक्ष्य के आधार पर, आप इन सेटिंग्स में से कोई भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइडों पर मौजूद ऑब्जेक्ट को री-साइज़ नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार में स्केल करना चाहते हैं और Aspose.Slides को स्लाइडों के ऑब्जेक्ट को छोटा करके सभी को स्लाइड में फिट करना आवश्यक है (इससे सामग्री का नुकसान नहीं होता), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार में स्केल करना चाहते हैं और Aspose.Slides को स्लाइडों के ऑब्जेक्ट को बड़ा करके नए स्लाइड आकार के अनुपात में लाना है, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड दिखाता है कि प्रस्तुति के स्लाइड आकार को बदलते समय `Maximize` सेटिंग का उपयोग कैसे किया जाए:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट्स या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूं?**

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट्स में बदल सकते हैं और परिवर्तित मानों का उपयोग करके स्लाइड की चौड़ाई और ऊंचाई निर्धारित कर सकते हैं।

**क्या अत्यधिक बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हां। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी खपत बढ़ाते हैं और प्रोसेसिंग समय को लंबा करते हैं। व्यावहारिक स्लाइड आकार का लक्ष्य रखें और आवश्यकतानुसार रेंडरिंग स्केल को समायोजित करें ताकि वांछित आउटपुट गुणवत्ता प्राप्त हो सके।

**क्या मैं एक गैर-मानक स्लाइड आकार निर्धारित कर सकता हूं और फिर विभिन्न आकारों वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूं?**

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों के दौरान [merge presentations](/slides/hi/java/merge-presentation/) नहीं कर सकते — पहले, एक प्रस्तुति का आकार दूसरे के साथ मिलाने के लिए री-साइज़ करें। स्लाइड आकार बदलते समय, आप मौजूदा सामग्री को कैसे संभालना है, इसे [SlideSizeScaleType](https://reference.aspose.com/slides/hi/java/com.aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार को संरेखित करने के बाद, आप फ़ॉर्मेटिंग को संरक्षित रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

**क्या मैं व्यक्तिगत आकारों या स्लाइड के विशिष्ट क्षेत्रों के लिए थंबनेल बना सकता हूं, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?**

हां। Aspose.Slides [entire slides](https://reference.aspose.com/slides/hi/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) और [selected shapes](https://reference.aspose.com/slides/hi/java/com.aspose.slides/shape/#getImage-int-float-float-) दोनों के लिए थंबनेल रेंडर कर सकता है। उत्पन्न छवियां वर्तमान स्लाइड आकार और एस्पेक्ट रेशियो को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में समानता बनी रहती है।
