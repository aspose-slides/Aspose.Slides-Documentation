{{% alert color="info" title="नोट" %}}

यह एक ऐतिहासिक पृष्ठ है। यह Aspose.Slides for Java 14.3.0 के साथ प्रकाशित ज्ञात समस्याओं को सूचीबद्ध करता है और वर्तमान संस्करण का वर्णन नहीं करता है। प्रत्येक संस्करण में हुए परिवर्तनों के लिए देखें [रिलीज़ नोट्स](https://releases.aspose.com/slides/hi/java/release-notes/)।

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) PPT प्रोसेसिंग की पूरी नई कार्यान्वयन प्रदान करता है। कई सुधार किए गए हैं, PPTX से PPT के भागीय रूपांतरण संभव है। लेकिन कुछ अपर्याप्त सुविधाएँ हैं:

- कुछ आकारों की जालीबद्ध PPT दस्तावेज़ों (Call outs) में ज्यामिति गलत है
- सभी PPTX टेक्स्ट फ़ॉर्मेटिंग सुविधाओं का समर्थन PPT सीरीयलाइज़ेशन में नहीं है
- टेक्स्ट भाषा और वर्तनी सेटिंग्स की जानकारी जालीबद्ध PPT दस्तावेज़ों में मौजूद नहीं है
- सभी PPTX थीम सुविधाओं का समर्थन PPT सीरीयलाइज़ेशन में नहीं है

**Aspose.Slides for Java 8.6.0 की तुलना में कुछ अंतर हैं:**

- OLE/ActiveX PPT सीरीयलाइज़ेशन से PPT में ज्ञात समस्याएँ हैं

**Aspose.Slides for .NET 14.3.0 की तुलना में कुछ अंतर हैं:**

- Aspose.Slides for Java में वर्तमान में प्रस्तुति प्रिंटिंग समर्थन उपलब्ध नहीं है।
