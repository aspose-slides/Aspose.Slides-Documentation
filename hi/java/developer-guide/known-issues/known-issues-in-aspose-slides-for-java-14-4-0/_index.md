{{% alert color="info" title="Note" %}}

यह एक ऐतिहासिक पृष्ठ है। यह Aspose.Slides for Java 14.4.0 के साथ प्रकाशित प्रतिबंधों और ज्ञात समस्याओं की सूची देता है और वर्तमान संस्करण का विवरण नहीं देता। प्रत्येक संस्करण में बदलावों के लिए, देखें [रिलीज़ नोट्स](https://releases.aspose.com/slides/hi/java/release-notes/)।

{{% /alert %}}

Aspose.Slides for Java 14.4.0 पॉवरपॉइंट दस्तावेज़ों के प्रसंस्करण के लिए नई सुविधा प्रदान करता है। कुछ प्रतिबंध और ज्ञात समस्याएँ हैं, जो आने वाले रिलीज़ में हटा दी जाएँगी:

- कुछ आकारों की सीरियलाइज़्ड PPT दस्तावेज़ों में जियोमेट्री गलत है (आर्क, सर्कुलर एरो, कॉलआउट)।
- सभी PPTX टेक्स्ट फ़ॉर्मेटिंग सुविधाएँ PPT सीरियलाइज़ेशन में समर्थित नहीं हैं (टैब्यूलेशन, इंडेंटेशन और पैराग्राफ फ़ॉर्मेटिंग सीमाएँ)।
- सीरियलाइज़्ड PPT दस्तावेज़ों में टेक्स्ट भाषा और वर्तनी सेटिंग्स की जानकारी उपलब्ध नहीं है।
- सभी PPTX थीम सुविधाएँ PPT सीरियलाइज़ेशन में समर्थित नहीं हैं (केवल फ़िल फ़ॉर्मेट, लाइन फ़ॉर्मेट और फ़ॉन्ट का सीरियलाइज़ेशन)।
- OLE/ActiveX PPT सीरियलाइज़ेशन से PPT में ज्ञात समस्याएँ हैं।
- WordArt का सीरियलाइज़ेशन और रेंडरिंग समर्थित नहीं है।
