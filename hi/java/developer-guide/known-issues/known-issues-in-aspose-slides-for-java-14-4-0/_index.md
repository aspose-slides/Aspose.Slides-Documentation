Aspose.Slides for Java 14.4.0 पावरपॉइंट दस्तावेज़ प्रोसेसिंग के लिए नया समाधान प्रदान करता है। कुछ प्रतिबंध और ज्ञात समस्याएँ हैं, जिन्हें आने वाले रिलीज़ में हटाया जाएगा:

- कुछ आकारों की ज्यामिति सीरियलाइज़्ड PPT दस्तावेज़ों में गलत होती है (आर्क, सर्कुलर एरो, कॉलआउट)।
- सभी PPTX टेक्स्ट फ़ॉर्मेटिंग सुविधाएँ PPT सीरियलाइज़ेशन में समर्थित नहीं हैं (टैब्यूलेशन, इंडेंटेशन और पैराग्राफ फ़ॉर्मेटिंग सीमाएँ)।
- टेक्स्ट भाषा और वर्तनी सेटिंग्स की जानकारी सीरियलाइज़्ड PPT दस्तावेज़ों में उपस्थित नहीं है।
- सभी PPTX थीम सुविधाएँ PPT सीरियलाइज़ेशन में समर्थित नहीं हैं (केवल फ़िल फ़ॉर्मेट, लाइन फ़ॉर्मेट और फ़ॉन्ट का सीरियलाइज़ेशन)।
- OLE/ActiveX PPT से PPT सीरियलाइज़ेशन में ज्ञात समस्याएँ हैं।
- WordArt का सीरियलाइज़ेशन और रेंडरिंग समर्थित नहीं है।
