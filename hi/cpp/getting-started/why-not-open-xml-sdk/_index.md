## **समीक्षा**

यह लेख समझाता है कि विकासकर्ता प्रस्तुति दस्तावेज़ों के साथ काम करने के लिए Open XML SDK या Aspose.Slides कब चुन सकते हैं। इसमें Open XML SDK को OOXML पैकेजों और उनके अंतर्गत XML तत्वों को संभालने के लिए लाइब्रेरी के रूप में वर्णित किया गया है, जबकि Aspose.Slides को उच्च‑स्तरीय ऑब्जेक्ट मॉडल और कई PowerPoint‑संबंधित कार्यों के समर्थन के साथ एक प्रस्तुति प्रोसेसिंग लाइब्रेरी के रूप में प्रस्तुत किया गया है।

लेख दोनों विकल्पों की तुलना फ़ॉर्मेट समर्थन, प्रोग्रामिंग मॉडल, रेंडरिंग, प्लेटफ़ॉर्म समर्थन और सामान्य उपयोग मामलों के आधार पर करता है। यह यह भी स्पष्ट करता है कि Open XML SDK बुनियादी PPTX ऑपरेशनों या OOXML तत्वों तक प्रत्यक्ष पहुँच के लिए उपयुक्त हो सकता है, जबकि Aspose.Slides अधिक जटिल प्रस्तुति कार्यों जैसे कई PowerPoint फ़ॉर्मेट के साथ काम करना, शैप्स की कॉपी या क्लोन करना, टेक्स्ट बदलना, एनीमेशन लागू करना, तथा प्रस्तुतियों को PDF, TIFF या XPS में परिवर्तित करने के लिए अधिक उपयुक्त है।

## **Open XML SDK क्या है?**
हम अक्सर यह पूछते हैं: मुफ्त Open XML SDK की बजाय हमें Aspose उत्पादों का उपयोग क्यों करना चाहिए? इस प्रश्न का उत्तर सरल है: सुविधाएँ और कार्यक्षमता। According to the[MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk), Open XML SDK को इस प्रकार परिभाषित किया गया है: The Open XML SDK 2.0 simplifies the task of manipulating Open XML packages and the underlying Open XML schema elements within a package. The Open XML SDK 2.0 encapsulates many common tasks that developers perform on Open XML packages, so that you can perform complex operations with just a few lines of code. OOXML documents are essentially zipped XML files and Open XML SDK is a collection of classes that allows you to work with the content of OOXML documents in a strongly‑typed way. That is instead of unzipping a file to extract XML, loading that XML into a DOM tree and working with XML elements and attributes directly, Open XML SDK provides classes to do that.

## **Aspose.Slides क्या है?**
Aspose.Slides एक क्लास लाइब्रेरी है जो आपके अनुप्रयोग को निम्नलिखित प्रस्तुति प्रोसेसिंग कार्य करने की अनुमति देती है:

- **Presentation** ऑब्जेक्ट मॉडल के साथ प्रोग्रामिंग।
- सभी लोकप्रिय समर्थित PowerPoint प्रस्तुति फ़ॉर्मेट्स के बीच उच्च गुणवत्ता वाले रूपांतरण, जिसमें PDF और XPS में परिवर्तन शामिल है।
- PNG, JPEG और BMP जैसे सामान्य फ़ॉर्मेट में स्लाइड थंबनेल उत्पन्न करने तथा SVG में स्लाइड निर्यात करने की क्षमता।
- शून्य से या एक या अधिक दस्तावेज़ों को मिलाकर प्रस्तुति बनाने की क्षमता।
- एनीमेशन, Ole फ्रेम, टेबल, चार्ट बनाने और प्रबंधित करने का समर्थन।
- TextFrames, Paragraphs और Portions स्तर पर टेक्स्ट फ़ॉर्मेटिंग को नियंत्रित करने के लिए विस्तृत नियंत्रण।

अधिक विवरण के लिए, कृपया देखें [Aspose.Slides फीचर्स](/slides/hi/cpp/product-overview/)।

|डॉक्यूमेंट ऑब्जेक्ट मॉडल के साथ विस्तृत प्रोग्रामिंग, व्यक्तिगत तत्वों और फ़ॉर्मेटिंग (जैसे TextHolders, TextFrames, Paragraphs और Portions) तक पहुँच।|Yes|Yes|

|<p>रेंडरिंग:</p><p>- प्रस्तुतियों को PDF, PDF नोट्स, XPS, TIFF छवियों में रेंडर करना।</p><p>- स्लाइड थंबनेल को PNG, JPEG, BMP, SVG और TIFF में रेंडर करना।</p><p>- चित्र रिज़ॉल्यूशन, गुणवत्ता, संपीड़न और अन्य विकल्प निर्दिष्ट करना।</p>|No|Yes|

## **निष्कर्ष**
Open XML SDK और Aspose.Slides प्रत्यक्ष प्रतिस्पर्धी नहीं हैं क्योंकि वे काफी अलग आवश्यकताओं और दर्शकों को लक्षित करते हैं। Open XML SDK एक क्लास लाइब्रेरी है जो OOXML दस्तावेज़ों को टाइप‑सेफ़ तरीके से संभालने के लिए निर्मित है। Aspose.Slides एक बहुत उपयोगी प्रस्तुति प्रोसेसिंग लाइब्रेरी है जो लगभग सभी Microsoft PowerPoint फ़ाइल फ़ॉर्मेट्स के लिए उत्कृष्ट समर्थन प्रदान करती है। यदि आपको केवल PPTX दस्तावेज़ पर बुनियादी प्रोग्रामिंग ऑपरेशन करना है, तो Open XML SDK उपयुक्त विकल्प हो सकता है। Open XML SDK के साथ आप सरल कार्य जैसे कि एक साधारण PPTX दस्तावेज़ उत्पन्न करना, टिप्पणी, हेडर/फ़ूटर हटाना, छवियों को निकालना आदि आराम से कर सकते हैं। कुछ कार्य Open XML SDK से किए जा सकते हैं, लेकिन Aspose.Slides से नहीं। उदाहरण के लिए, यदि आपको OOXML दस्तावेज़ के XML तत्वों और एट्रिब्यूट्स तक सीधे पहुँच की आवश्यकता है, तो आपको Open XML SDK का उपयोग करना चाहिए। हालांकि, यदि आपको दस्तावेज़ों पर जटिल ऑपरेशन करने हैं, जैसे नीचे दिए गए कार्य, तो Aspose.Slides आपका सर्वोत्तम विकल्प है:

- PPTX के अलावा पुराने PowerPoint फ़ॉर्मेट्स का समर्थन।
- स्लाइड्स के भीतर शैप्स को कॉपी या क्लोन करना, जिससे ऑब्जेक्ट्स, शैलियों और अन्य फ़ॉर्मेटिंग का उपयुक्त संयोजन हो।
- फ़ॉर्मेटेड या अनफ़ॉर्मेटेड टेक्स्ट को बदलना।
- एनीमेशन लागू करना और शैप्स के साथ कनेक्टर का उपयोग करना।
- दस्तावेज़ को PDF या XPS में परिवर्तित करना ताकि वह Microsoft PowerPoint द्वारा उत्पन्न परिणाम के समान दिखे।
- डेस्कटॉप और कंसोल दोनों वातावरण में C++ अनुप्रयोग विकसित करना।
