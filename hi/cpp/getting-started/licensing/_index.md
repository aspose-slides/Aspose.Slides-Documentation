## **अवलोकन**

Aspose.Slides को मूल्यांकन मोड में या वैध लाइसेंस के साथ उपयोग किया जा सकता है। मूल्यांकन संस्करण लाइसेंस प्राप्त संस्करण के समान कार्यक्षमता प्रदान करता है, लेकिन प्रस्तुति खोलने या सहेजने पर मूल्यांकन वॉटरमार्क जोड़ता है और पाठ निष्कर्षण को एक स्लाइड तक सीमित करता है।

यह लेख Aspose.Slides में लाइसेंसिंग कैसे काम करती है और लाइब्रेरी का उपयोग करने से पहले लाइसेंस कैसे लागू किया जाए, समझाता है। लाइसेंस को फ़ाइल, स्ट्रीम, या एम्बेडेड रिसोर्स से `License` क्लास का उपयोग करके लोड किया जा सकता है। लेख यह भी दिखाता है कि लाइसेंस सही तरीके से लागू हुआ है या नहीं, कैसे सत्यापित किया जाए।

## **Aspose.Slides में लाइसेंसिंग**

* एक मूल्यांकन संस्करण लाइसेंस खरीदने और कुछ कोड पंक्तियों को जोड़कर लाइसेंस लागू करने के बाद लाइसेंस प्राप्त हो जाता है।
* लाइसेंस एक साधारण‑टेक्स्ट XML फ़ाइल है जिसमें उत्पाद का नाम, लाइसेंस प्राप्त डेवलपर्स की संख्या, सब्सक्रिप्शन समाप्ति तिथि और अन्य विवरण शामिल होते हैं।
* लाइसेंस फ़ाइल डिजिटल रूप से हस्ताक्षरित होती है, इसलिए इसे संशोधित नहीं किया जाना चाहिए। यहां तक कि एक आकस्मिक परिवर्तन—जैसे लाइन ब्रेक जोड़ना—भी फ़ाइल को अमान्य कर देगा।
* Aspose.Slides for C++ सामान्यतः लाइसेंस फ़ाइल को निम्नलिखित स्थानों पर खोजता है:
  * आपके कोड में स्पष्ट रूप से निर्दिष्ट पथ
  * घटक की DLL (Aspose.Slides में शामिल) वाला फ़ोल्डर
  * वह फ़ोल्डर जिसमें वह असेंबली है जो घटक की DLL को कॉल करती है
* मूल्यांकन संस्करण की सीमाओं से बचने के लिए, आपको Aspose.Slides का उपयोग करने से पहले लाइसेंस सेट करना चाहिए। एक लाइसेंस प्रत्येक एप्लिकेशन या प्रोसेस के लिए केवल एक बार सेट करने की आवश्यकता होती है।

## **लाइसेंस लागू करें**

लाइसेंस को **फ़ाइल**, **स्ट्रीम**, या **एंबेडेड रिसोर्स** से लोड किया जा सकता है।

{{% alert color="info" %}}

Aspose.Slides लाइसेंसिंग संचालन के लिए [License](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.license/) क्लास प्रदान करता है।

{{% /alert %}} 

{{% alert color="warning" %}}

नए लाइसेंस केवल संस्करण 21.4 या बाद के साथ Aspose.Slides को सक्रिय कर सकते हैं। पूर्व संस्करण एक अलग लाइसेंसिंग सिस्टम का उपयोग करते हैं और इन लाइसेंसों को पहचान नहीं पाएंगे।

{{% /alert %}}

### **फ़ाइल**

लाइसेंस सेट करने का सबसे आसान तरीका यह है कि लाइसेंस फ़ाइल को घटक की DLL (Aspose.Slides में शामिल) के समान फ़ोल्डर में रखें और केवल फ़ाइल नाम निर्दिष्ट करें, बिना पथ के।

नीचे दिया गया C++ कोड दिखाता है कि लाइसेंस फ़ाइल कैसे सेट करें:

```c++
#include <Util/License.h>
#include <system/smart_ptr.h>
#include <system/string.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    return 0;
}
```

{{% alert color="warning" %}} 

यदि आप लाइसेंस फ़ाइल को किसी अलग डायरेक्टरी में रखते हैं, तो जब आप [License::SetLicense](https://reference.aspose.com/slides/hi/cpp/aspose.slides/license/setlicense/) मेथड को कॉल करते हैं, तो निर्दिष्ट स्पष्ट पथ के अंत में फ़ाइल नाम बिल्कुल आपके लाइसेंस फ़ाइल के नाम से मेल खाना चाहिए।

उदाहरण के लिए, यदि आप अपनी लाइसेंस फ़ाइल का नाम *Aspose.Slides.lic.xml* रख देते हैं, तो आपको अपने कोड में [License::SetLicense](https://reference.aspose.com/slides/hi/cpp/aspose.slides/license/setlicense/) मेथड को *Aspose.Slides.lic.xml* समाप्त होने वाला पूर्ण पथ पास करना होगा।

{{% /alert %}}

### **स्ट्रीम**

आप लाइसेंस को स्ट्रीम से लोड कर सकते हैं। नीचे दिया गया C++ कोड दर्शाता है कि स्ट्रीम से लाइसेंस कैसे लागू किया जाए:

```c++
#include <Util/License.h>
#include <system/io/file.h>
#include <system/smart_ptr.h>
using namespace Aspose::Slides;
using namespace System;
using namespace System::IO;

auto license = MakeObject<License>();

auto stream = File::OpenRead(u"Aspose.Slides.lic");

license->SetLicense(stream);
```

## **लाइसेंस को मान्य करें**

जांचने के लिए कि लाइसेंस सही ढंग से सेट हुआ है या नहीं, आप इसे सत्यापित कर सकते हैं। नीचे दिया गया C++ कोड लाइसेंस को वैध करने का तरीका दिखाता है:

```c++
#include <Util/License.h>
#include <system/console.h>
using namespace Aspose::Slides;
using namespace System;

auto license = MakeObject<License>();

license->SetLicense(u"Aspose.Slides.lic");

if (license->IsLicensed())
{
    Console::WriteLine(u"License is good!");
    Console::ReadKey();
}
```

## **थ्रेड सुरक्षा**

{{% alert title="Note" color="warning" %}} 

[License::SetLicense](https://reference.aspose.com/slides/hi/cpp/aspose.slides/license/setlicense/) मेथड **थ्रेड‑सुरक्षित** नहीं है। यदि आपको इस मेथड को कई थ्रेड्स से एक साथ कॉल करने की आवश्यकता है, तो संभावित समस्याओं से बचने के लिए सिंक्रनाइज़ेशन प्रिमिटिव्स (जैसे लॉक) का उपयोग करने की सलाह दी जाती है।

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं लाइसेंस को बिल्कुल ऑफ़लाइन वातावरण (इंटरनेट कनेक्शन नहीं) में लागू कर सकता हूँ?

हाँ। लाइसेंस वैधता लाइसेंस फ़ाइल का उपयोग करके स्थानीय रूप से की जाती है; इंटरनेट कनेक्शन की आवश्यकता नहीं है।

### एक साल की सब्सक्रिप्शन समाप्त होने के बाद क्या होता है? क्या लाइब्रेरी काम करना बंद कर देगी?

नहीं। लाइसेंस निरंतर (परपेचुअल) है: आप अपनी सब्सक्रिप्शन समाप्ति तिथि से पहले जारी किए गए संस्करणों का उपयोग जारी रख सकते हैं; लेकिन बिना नवीनीकरण के आप नए रिलीज़ उपयोग नहीं कर पाएँगे।
