## **परिचय**

जब आप किसी प्रस्तुति को पासवर्ड से सुरक्षित करते हैं, तो इसका मतलब है कि आप एक पासवर्ड सेट कर रहे हैं जो प्रस्तुति पर कुछ प्रतिबंध लागू करता है। प्रतिबंधों को हटाने के लिए पासवर्ड दर्ज करना आवश्यक है। पासवर्ड‑सुरक्षित प्रस्तुति को लॉक्ड प्रस्तुति माना जाता है।

आम तौर पर, आप इन प्रतिबंधों को लागू करने के लिए प्रस्तुति पर पासवर्ड सेट कर सकते हैं:

- **संशोधन**

  यदि आप केवल कुछ उपयोगकर्ताओं को अपनी प्रस्तुति को संशोधित करने देना चाहते हैं, तो आप संशोधन प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध लोगों को आपकी प्रस्तुति को संशोधित, बदलने या कॉपी करने से रोकता है (जब तक वे पासवर्ड प्रदान नहीं करते)।

  हालांकि, इस मामले में, पासवर्ड के बिना भी उपयोगकर्ता आपका दस्तावेज़ एक्सेस कर सकेगा और खोल सकेगा। केवल‑पढ़ने की स्थिति में, उपयोगकर्ता आपकी प्रस्तुति की सामग्री—हाइपरलिंक, एनीमेशन, इफ़ेक्ट्स और अन्य—को देख सकता है, लेकिन वह आइटम कॉपी नहीं कर सकता या प्रस्तुति को सहेज नहीं सकता।

- **खोलना**

  यदि आप चाहते हैं कि केवल कुछ उपयोगकर्ता ही आपकी प्रस्तुति खोल सकें, तो आप खोलने का प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध लोगों को आपकी प्रस्तुति की सामग्री देखने से भी रोकता है (जब तक वे पासवर्ड प्रदान नहीं करते)।

  तकनीकी रूप से, खोलने का प्रतिबंध उपयोगकर्ताओं को आपकी प्रस्तुतियों को संशोधित करने से भी रोकता है: जब लोग प्रस्तुति नहीं खोल पाते, तो वे इसे संशोधित या परिवर्तन नहीं कर सकते।

  **ध्यान दें** कि जब आप प्रस्तुति को खोलने से रोकने के लिये पासवर्ड से सुरक्षित करते हैं, तो प्रस्तुति फ़ाइल एन्क्रिप्ट हो जाती है।

## **Aspose.Slides में प्रस्तुतियों के लिए पासवर्ड सुरक्षा**
**समर्थित प्रारूप**

Aspose.Slides पासवर्ड सुरक्षा, एन्क्रिप्शन और समान ऑपरेशंस को इन स्वरूपों में प्रस्तुतियों के लिए समर्थन करता है:

- PPTX and PPT - Microsoft PowerPoint प्रस्तुति
- ODP - OpenDocument प्रस्तुति
- OTP - OpenDocument प्रस्तुति टेम्प्लेट

**समर्थित ऑपरेशंस**

Aspose.Slides आपको इन तरीकों से प्रस्तुतियों पर पासवर्ड सुरक्षा का उपयोग करके संशोधनों को रोकने की सुविधा देता है:

- एक प्रस्तुति को एन्क्रिप्ट करना
- एक प्रस्तुति पर लिखने की सुरक्षा सेट करना

**अन्य ऑपरेशंस**

Aspose.Slides आपको पासवर्ड सुरक्षा और एन्क्रिप्शन से जुड़ी अन्य कार्यों को इन तरीकों से करने देता है:

- एक प्रस्तुति को डिक्रिप्ट करना; एन्क्रिप्टेड प्रस्तुति खोलना
- एन्क्रिप्शन हटाना; पासवर्ड सुरक्षा अक्षम करना
- एक प्रस्तुति से लिखने की सुरक्षा हटाना
- एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ प्राप्त करना
- यह जांचना कि प्रस्तुति एन्क्रिप्टेड है या नहीं
- यह जांचना कि प्रस्तुति पासवर्ड‑प्रोटेक्टेड है या नहीं।

## **एक प्रस्तुति को एन्क्रिप्ट करें**

आप पासवर्ड सेट करके एक प्रस्तुति को एन्क्रिप्ट कर सकते हैं। फिर, लॉक्ड प्रस्तुति को संशोधित करने के लिए उपयोगकर्ता को पासवर्ड प्रदान करना होगा।

एक प्रस्तुति को एन्क्रिप्ट या पासवर्ड‑प्रोटेक्ट करने के लिये, आपको एन्क्रिप्ट मेथड (from [ProtectionManager](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.protection_manager)) का उपयोग करके प्रस्तुति के लिये पासवर्ड सेट करना होगा। आप पासवर्ड को एन्क्रिप्ट मेथड में पास करते हैं और सेव मेथड का प्रयोग करके अब एन्क्रिप्ट की गई प्रस्तुति को सहेजते हैं।

यह नमूना कोड दिखाता है कि कैसे एक प्रस्तुति को एन्क्रिप्ट किया जाता है:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto presentation = System::MakeObject<Presentation>(u"pres.pptx");

presentation->get_ProtectionManager()->Encrypt(u"123123");
presentation->Save(u"encrypted-pres.pptx", SaveFormat::Pptx);
```

## **एक प्रस्तुति पर लिखने की सुरक्षा सेट करें** 

आप प्रस्तुति में “Do not modify” (बिना बदलाव के) टैग जोड़ सकते हैं। इस तरह आप उपयोगकर्ताओं को बता सकते हैं कि आप उन्हें प्रस्तुति में बदलाव नहीं करना चाहते।

**ध्यान दें** कि लिखने की सुरक्षा प्रक्रिया प्रस्तुति को एन्क्रिप्ट नहीं करती। इसलिए, उपयोगकर्ता—यदि वे चाहें—प्रस्तुति को संशोधित कर सकते हैं, लेकिन परिवर्तन सहेजने के लिये उन्हें अलग नाम से नई प्रस्तुति बनानी पड़ेगी।

लिखने की सुरक्षा सेट करने हेतु, आपको setWriteProtection मेथड का उपयोग करना होगा। यह नमूना कोड दिखाता है कि कैसे प्रस्तुति पर लिखने की सुरक्षा सेट की जाती है:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto presentation = System::MakeObject<Presentation>(u"pres.pptx");

presentation->get_ProtectionManager()->SetWriteProtection(u"123123");
presentation->Save(u"write-protected-pres.pptx", SaveFormat::Pptx);
```

## **एक एन्क्रिप्टेड प्रस्तुति लोड करें**

Aspose.Slides आपको पासवर्ड पास करके एक एन्क्रिप्टेड फ़ाइल को लोड करने देता है। एक प्रस्तुति को डिक्रिप्ट करने के लिये, आपको [RemoveEncryption](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.protection_manager#a422059278b430a0493680252aa975d4d) मेथड को बिना पैरामीटर के कॉल करना होगा। फिर आपको सही पासवर्ड दर्ज करके प्रस्तुति को लोड करना होगा।

यह नमूना कोड दिखाता है कि कैसे एक प्रस्तुति को डिक्रिप्ट किया जाता है:

``` cpp
#include <DOM/LoadOptions.h>
using namespace Aspose::Slides;

auto loadOptions = System::MakeObject<LoadOptions>();
loadOptions->set_Password(u"123123");
    
System::SharedPtr<Presentation> presentation = System::MakeObject<Presentation>(u"pres.pptx", loadOptions);

// डिक्रिप्टेड प्रस्तुति के साथ काम करें
```

## **प्रस्तुति से एन्क्रिप्शन हटाएं**

आप प्रस्तुति से एन्क्रिप्शन या पासवर्ड सुरक्षा हटा सकते हैं। इस तरह उपयोगकर्ता बिना किसी प्रतिबंध के प्रस्तुति तक पहुंच या संशोधन कर सकते हैं।

एन्क्रिप्शन या पासवर्ड सुरक्षा हटाने के लिये, आपको [RemoveEncryption](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.protection_manager#a422059278b430a0493680252aa975d4d) मेथड को कॉल करना होगा। यह नमूना कोड दिखाता है कि कैसे प्रस्तुति से एन्क्रिप्शन हटाया जाता है:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/LoadOptions.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto loadOptions = System::MakeObject<LoadOptions>();
loadOptions->set_Password(u"123123");
    
auto presentation = System::MakeObject<Presentation>(u"pres.pptx", loadOptions);

presentation->get_ProtectionManager()->RemoveEncryption();
presentation->Save(u"encryption-removed.pptx", SaveFormat::Pptx);
```

## **प्रेजेंटेशन से लिखने की सुरक्षा हटाएं**

आप Aspose.Slides का उपयोग करके प्रस्तुति फ़ाइल पर लागू लिखने की सुरक्षा को हटा सकते हैं। इस तरह उपयोगकर्ता अपनी इच्छा से संशोधन कर सकते हैं—और ऐसा करते समय उन्हें कोई चेतावनी नहीं दिखेगी।

आप लिखने की सुरक्षा को हटाने के लिए [RemoveWriteProtection](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.protection_manager#a9f9e6de5983965157dac0f270a0a9e50) मेथड का उपयोग कर सकते हैं। यह नमूना कोड दिखाता है कि कैसे लिखने की सुरक्षा हटाई जाती है:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto presentation = System::MakeObject<Presentation>(u"pres.pptx");

presentation->get_ProtectionManager()->RemoveWriteProtection();
presentation->Save(u"write-protection-removed.pptx", SaveFormat::Pptx);
```

## **एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ प्राप्त करें**

आमतौर पर, उपयोगकर्ताओं को एन्क्रिप्टेड या पासवर्ड‑प्रोटेक्टेड प्रस्तुति की दस्तावेज़ प्रॉपर्टीज़ प्राप्त करने में समस्या आती है। हालांकि, Aspose.Slides एक ऐसी सुविधा प्रदान करता है जिससे आप प्रस्तुति को पासवर्ड‑प्रोटेक्ट करते हुए भी उसकी दस्तावेज़ प्रॉपर्टीज़ तक पहुंच बना सकते हैं।

**ध्यान दें:** जब Aspose.Slides किसी प्रस्तुति को एन्क्रिप्ट करता है, तो प्रस्तुति की दस्तावेज़ प्रॉपर्टीज़ भी पासवर्ड‑प्रोटेक्ट हो जाती हैं। यदि आप एन्क्रिप्शन के बाद भी दस्तावेज़ प्रॉपर्टीज़ को सुलभ बनाना चाहते हैं, तो Aspose.Slides आपको यह करने की अनुमति देता है।

यदि आप चाहते हैं कि उपयोगकर्ता एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ तक पहुंच बना रखें, तो आपको `set_EncryptDocumentProperties` मेथड को `false` पास करना होगा जो [IProtectionManager](https://reference.aspose.com/slides/hi/cpp/aspose.slides/iprotectionmanager/) में है। यह नमूना कोड दिखाता है कि कैसे आप प्रस्तुति को एन्क्रिप्ट करते हुए भी उपयोगकर्ताओं को उसकी दस्तावेज़ प्रॉपर्टीज़ तक पहुंच प्रदान कर सकते हैं:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
using namespace Aspose::Slides;

auto presentation = System::MakeObject<Presentation>(u"pres.pptx");

presentation->get_ProtectionManager()->set_EncryptDocumentProperties(false);
presentation->get_ProtectionManager()->Encrypt(u"123123");
presentation->Save(u"encrypted-pres.pptx", SaveFormat::Pptx);
presentation->Dispose();
```

## **एन्क्रिप्टेड प्रस्तुति से केवल दस्तावेज़ प्रॉपर्टीज़ लोड करें**

एन्क्रिप्टेड प्रस्तुति की मेटाडाटा को स्लाइड्स या अन्य सामग्री लोड किए बिना जांचने के लिये, एक [LoadOptions](https://reference.aspose.com/slides/hi/cpp/aspose.slides/loadoptions/) ऑब्जेक्ट बनाएं और `set_OnlyLoadDocumentProperties` को `true` सेट करें। इस मोड में, Aspose.Slides पासवर्ड को अनदेखा कर केवल सार्वजनिक रूप से सुलभ दस्तावेज़ प्रॉपर्टीज़ लोड करता है।

निम्न कोड उदाहरण [IPresentation::get_DocumentProperties](https://reference.aspose.com/slides/hi/cpp/aspose.slides/ipresentation/get_documentproperties/) के माध्यम से निर्मित एवं कस्टम दस्तावेज़ प्रॉपर्टीज़ को पढ़ता है:

``` cpp
auto loadOptions = MakeObject<LoadOptions>();
loadOptions->set_OnlyLoadDocumentProperties(true);

auto presentation = MakeObject<Presentation>(u"encrypted-pres.pptx", loadOptions);
auto documentProperties = presentation->get_DocumentProperties();

// Read built-in document properties.
auto title = documentProperties->get_Title();
auto author = documentProperties->get_Author();
Console::WriteLine(String(u"Title: ") + title);
Console::WriteLine(String(u"Author: ") + author);

// Read custom document properties.
int customPropertyCount = documentProperties->get_CountOfCustomProperties();

for (int propertyIndex = 0; propertyIndex < customPropertyCount; propertyIndex++)
{
    auto propertyName = documentProperties->GetCustomPropertyName(propertyIndex);
    auto propertyValue = documentProperties->idx_get(propertyName);
    auto propertyValueText = ObjectExt::ToString(propertyValue);

    Console::WriteLine(propertyName + u": " + propertyValueText);
}

presentation->Dispose();
```

यह वर्कफ़्लो तभी काम करता है जब प्रस्तुति के एन्क्रिप्शन के समय दस्तावेज़ प्रॉपर्टीज़ को अनएन्क्रिप्टेड (सार्वजनिक) छोड़ा गया हो। यदि दस्तावेज़ प्रॉपर्टीज़ एन्क्रिप्टेड हैं, तो `LoadOptions::set_OnlyLoadDocumentProperties` को `true` करने से एक अपवाद उत्पन्न होगा क्योंकि इस मोड में पासवर्ड को अनदेखा किया जाता है। एन्क्रिप्टेड दस्तावेज़ प्रॉपर्टीज़ तक पहुंचने या पूरी प्रस्तुति (स्लाइड्स सहित) लोड करने के लिये, आपको सही पासवर्ड को `LoadOptions::set_Password` के साथ प्रदान करना होगा जो [LoadOptions](https://reference.aspose.com/slides/hi/cpp/aspose.slides/loadoptions/) में है।

## **जांचें कि प्रस्तुति पासवर्ड‑प्रोटेक्टेड है या नहीं**

प्रस्तुति को लोड करने से पहले, आप यह जांचना चाह सकते हैं कि क्या प्रस्तुति पासवर्ड से सुरक्षित नहीं है। इस तरह आप उन त्रुटियों और समान समस्याओं से बच सकते हैं जो पासवर्ड‑प्रोटेक्टेड प्रस्तुति को उसके पासवर्ड के बिना लोड करने पर उत्पन्न होती हैं।

यह C++ कोड दिखाता है कि कैसे आप प्रस्तुति की जाँच कर सकते हैं कि वह पासवर्ड‑प्रोटेक्टेड है या नहीं (बिना स्वयं प्रस्तुति को लोड किए):

```c++
#include <DOM/IPresentationInfo.h>
#include <DOM/PresentationFactory.h>
#include <system/console.h>
using namespace Aspose::Slides;
using namespace System;

auto presentationInfo = PresentationFactory::get_Instance()->GetPresentationInfo(u"example.pptx");
System::Console::WriteLine(System::String(u"The presentation is password protected: ") +
                           presentationInfo->get_IsPasswordProtected());
```

## **जांचें कि प्रस्तुति एन्क्रिप्टेड है या नहीं**

Aspose.Slides आपको यह जांचने की सुविधा देता है कि प्रस्तुति एन्क्रिप्टेड है या नहीं। इस कार्य को करने के लिये, आप [get_IsEncrypted()](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.protection_manager#ad88b984e44b378f335317ded49b34e68) मेथड का उपयोग कर सकते हैं, जो प्रस्तुति एन्क्रिप्टेड होने पर `true` और न होने पर `false` लौटाता है।

यह नमूना कोड दिखाता है कि कैसे आप यह जांच सकते हैं कि प्रस्तुति एन्क्रिप्टेड है या नहीं:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
using namespace Aspose::Slides;

auto presentation = System::MakeObject<Presentation>(u"pres.pptx");

bool isEncrypted = presentation->get_ProtectionManager()->get_IsEncrypted();
```

## **जांचें कि प्रस्तुति लिखने के लिए सुरक्षित है या नहीं**

Aspose.Slides आपको यह जांचने की सुविधा देता है कि प्रस्तुति लिखने‑प्रोटेक्टेड है या नहीं। इस कार्य को करने के लिये, आप [get_IsWriteProtected()](https://reference.aspose.com/slides/hi/cpp/class/aspose.slides.protection_manager#a0b4a82c0f7b3a32ca5762c5fcc8844a2) मेथड का उपयोग कर सकते हैं, जो प्रस्तुति एन्क्रिप्टेड होने पर `true` और न होने पर `false` लौटाता है।

यह नमूना कोड दिखाता है कि कैसे आप यह जांच सकते हैं कि प्रस्तुति लिखने‑प्रोटेक्टेड है या नहीं:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
using namespace Aspose::Slides;

auto presentation = System::MakeObject<Presentation>(u"pres.pptx");

bool isEncrypted = presentation->get_ProtectionManager()->get_IsWriteProtected();
```

## **प्रेजेंटेशन पासवर्ड उपयोग को सत्यापित करें**

आप यह जांचना और पुष्टि करना चाह सकते हैं कि कोई विशिष्ट पासवर्ड प्रस्तुति दस्तावेज़ को सुरक्षित करने के लिये उपयोग किया गया है या नहीं। Aspose.Slides आपको पासवर्ड वैधता जाँचने का साधन प्रदान करता है।

यह नमूना कोड दिखाता है कि कैसे आप पासवर्ड वैधता जाँच सकते हैं:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");

// जाँचें कि "pass" मेल खाता है या नहीं
bool isWriteProtected = pres->get_ProtectionManager()->CheckWriteProtection(u"my_password");
```

यह `true` लौटाता है यदि प्रस्तुति निर्दिष्ट पासवर्ड से एन्क्रिप्ट की गई हो। अन्यथा यह `false` लौटाता है।

## **अक्सर पूछे जाने वाले प्रश्न**

**Aspose.Slides द्वारा कौन‑से एन्क्रिप्शन मेथड समर्थित हैं?**

Aspose.Slides आधुनिक एन्क्रिप्शन मेथड, जिसमें AES‑आधारित एल्गोरिद्म शामिल हैं, का समर्थन करता है, जिससे आपके प्रस्तुतियों के डेटा को उच्च स्तर की सुरक्षा मिलती है।

**प्रस्तुति खोलने के प्रयास में यदि गलत पासवर्ड दर्ज किया जाए तो क्या होता है?**

गलत पासवर्ड उपयोग करने पर एक अपवाद फेंका जाता है, जो आपको सूचित करता है कि प्रस्तुति तक पहुंच अस्वीकार कर दी गई है। यह अनधिकृत पहुंच को रोकता है और प्रस्तुति की सामग्री की सुरक्षा करता है।

**पासवर्ड‑प्रोटेक्टेड प्रस्तुतियों के साथ काम करते समय कोई प्रदर्शन संबंधी प्रभाव पड़ते हैं क्या?**

एन्क्रिप्शन और डिक्रिप्शन प्रक्रिया खोलने और सहेजने के दौरान थोड़ा अतिरिक्त समय ले सकती है। अधिकांश मामलों में यह प्रदर्शन प्रभाव न्यूनतम होता है और आपके कार्यप्रवाह के समग्र प्रसंस्करण समय को महत्वपूर्ण रूप से नहीं प्रभावित करता।
