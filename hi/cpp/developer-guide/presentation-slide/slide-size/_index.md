## **परिचय**

Aspose.Slides पॉवरपॉइंट प्रस्तुतियों में स्लाइड आकार और अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शन दोनों के लिए महत्वपूर्ण हैं।

लोकप्रिय स्लाइड आकार और अनुपात:

- **मानक (4:3 अनुपात)**: पुराने स्क्रीन और डिवाइस के लिए आदर्श।
- **वाइडस्क्रीन (16:9 अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए सिफारिश किया गया।

सभी स्लाइडों पर एक ही स्लाइड आकार और अनुपात लागू करके प्रस्तुति में निरंतरता रखें। सर्वोत्तम परिणामों के लिए, प्रस्तुति बनाने की प्रक्रिया की शुरुआत में ही स्लाइड आयाम सेट करें ताकि बाद में जटिलताओं से बचा जा सके।

{{% alert color="info" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides के साथ बनाई गई प्रस्तुतियों में मानक 4:3 अनुपात उपयोग होता है।
{{% /alert %}}

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड दिखाता है कि C++ में Aspose.Slides का उपयोग करके प्रस्तुति में स्लाइड आकार कैसे बदला जाए:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि सामान्य स्लाइड आकार (4:3 और 16:9) आपके काम के लिए उपयुक्त नहीं हैं, तो आप विशिष्ट या अनूठा स्लाइड आकार उपयोग कर सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रस्तुति से पूर्ण आकार की स्लाइडें कस्टम पेज लेआउट पर प्रिंट करना चाहते हैं या विशेष स्क्रीन प्रकार पर प्रदर्शित करना चाहते हैं, तो कस्टम आकार सेट करने से आपको लाभ होगा।

यह नमूना कोड दर्शाता है कि C++ में Aspose.Slides का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट किया जाए:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// A4 काग़ज़ आकार
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **आकार बदलने के बाद स्लाइड सामग्री को संभालें**

जब आप प्रस्तुति का स्लाइड आकार बदलते हैं, तो स्लाइड की सामग्री (जैसे छवियाँ या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट स्वचालित रूप से नए स्लाइड आकार के अनुरूप आकार बदल लेते हैं। हालांकि, जब आप प्रस्तुति का स्लाइड आकार बदलते हैं, तो आप ऐसा सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करता है कि Aspose.Slides स्लाइडों की सामग्री के साथ कैसे व्यवहार करता है।

आपकी आवश्यकताओं के आधार पर आप इन सेटिंग्स में से कोई भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर ऑब्जेक्ट को आकार बदलना नहीं चाहते, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार पर स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides सभी ऑब्जेक्ट को छोटे आकार में फिट करने के लिए स्केल डाउन करे (इस तरह आप सामग्री खोने से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार पर स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides ऑब्जेक्ट को नया स्लाइड आकार के अनुपात में बड़ा करे, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड दिखाता है कि प्रस्तुति के स्लाइड आकार को बदलते समय `Maximize` सेटिंग का उपयोग कैसे किया जाए:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?

हाँ। Aspose.Slides आंतरिक रूप से पॉइंट का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट में परिवर्तित करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित कर सकते हैं।

### क्या बहुत बड़े कस्टम स्लाइड आकार से रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग पर असर पड़ेगा?

हाँ। बड़े स्लाइड आयाम (पॉइंट में) और उच्च रेंडरिंग स्केल संयोजन से मेमोरी खपत बढ़ती है और प्रोसेसिंग समय लंबा होता है। व्यावहारिक स्लाइड आकार चुनें और केवल आवश्यक होने पर रेंडरिंग स्केल समायोजित करें ताकि वांछित आउटपुट गुणवत्ता प्राप्त हो सके।

### क्या मैं एक गैर-मानक स्लाइड आकार निर्धारित कर सकता हूँ और फिर विभिन्न आकार वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूँ?

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों को [merge presentations](/slides/hi/cpp/merge-presentation/) नहीं कर सकते — पहले एक प्रस्तुति को दूसरे के आकार से मिलाएँ। स्लाइड आकार बदलते समय आप मौजूदा सामग्री को कैसे संभाला जाए, यह [SlideSizeScaleType](https://reference.aspose.com/slides/hi/cpp/aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार मिलाने के बाद आप फॉर्मेटिंग बनाए रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

### क्या मैं व्यक्तिगत शैप्स या स्लाइड के विशिष्ट क्षेत्रों के थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?

हाँ। Aspose.Slides [entire slides](https://reference.aspose.com/slides/hi/cpp/aspose.slides/slide/getimage/) के साथ-साथ [selected shapes](https://reference.aspose.com/slides/hi/cpp/aspose.slides/shape/getimage/) के थंबनेल रेंडर कर सकता है। उत्पन्न छवियाँ वर्तमान स्लाइड आकार और अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्योमेट्री में स्थिरता बनी रहती है।
