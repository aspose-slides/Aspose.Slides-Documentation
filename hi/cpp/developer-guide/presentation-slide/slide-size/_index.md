## **परिचय**

Aspose.Slides PowerPoint प्रस्तुतियों में स्लाइड आकार और अनुपात को समायोजित करने के लिए व्यापक टूल्स प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शित करने दोनों के लिए महत्वपूर्ण है। 

लोकप्रिय स्लाइड आकार और अनुपात:

- **मानक (4:3 अनुपात)**: पुराने स्क्रीन और डिवाइस के लिए आदर्श।
- **वाइडस्क्रीन (16:9 अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सुनिश्चित करें कि आपके पूरे प्रस्तुति में एक ही स्लाइड आकार और अनुपात सभी स्लाइड्स पर लागू हो। सर्वोत्तम परिणामों के लिए, प्रस्तुति बनाते समय प्रारंभिक चरण में ही स्लाइड आयाम सेट करें ताकि जटिलताओं से बचा जा सके।

{{% alert color="info" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides के साथ बनाई गई प्रस्तुतियों में मानक 4:3 अनुपात का उपयोग किया जाता है।
{{% /alert %}}

नोट्स और हैंडआउट पेजों के आयाम सामान्य स्लाइडों से अलग होते हैं। उनका आकार और अभिविन्यास बदलने के लिए देखें [Notes Page Size](/slides/hi/cpp/notes-size/)।

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड C++ में Aspose.Slides का उपयोग करके प्रस्तुति में स्लाइड आकार बदलने का तरीका दिखाता है:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आप पाते हैं कि सामान्य स्लाइड आकार (4:3 और 16:9) आपके कार्य के लिए उपयुक्त नहीं हैं, तो आप एक विशिष्ट या अनोखा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के तौर पर, यदि आप अपनी प्रस्तुति से कस्टम पेज लेआउट पर पूर्ण आकार स्लाइड प्रिंट करने की योजना बनाते हैं या यदि आप अपने प्रस्तुति को कुछ विशेष स्क्रीन प्रकारों पर प्रदर्शित करने की सोच रहे हैं, तो आप कस्टम आकार सेटिंग से लाभान्वित हो सकते हैं। 

यह नमूना कोड C++ के लिए Aspose.Slides का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार निर्दिष्ट करने का तरीका दिखाता है:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// A4 कागज़ आकार
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **आकार बदलने के बाद स्लाइड सामग्री को संभालें**

प्रस्तुति के लिए स्लाइड आकार बदलने के बाद, स्लाइड की सामग्री (जैसे चित्र या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट्स नई स्लाइड आकार के अनुसार स्वतः री-साइज़ हो जाते हैं। हालांकि, जब आप प्रस्तुति के स्लाइड आकार को बदलते हैं, तो आप एक सेटिंग निर्दिष्ट कर सकते हैं जो यह निर्धारित करती है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालता है।

आप जो करना चाहते हैं या प्राप्त करना चाहते हैं, उसके आधार पर आप इन सेटिंग्स में से किसी को भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइडों पर ऑब्जेक्ट्स को री-साइज़ नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार पर स्केल करना चाहते हैं और Aspose.Slides को स्लाइडों के ऑब्जेक्ट्स को घटाकर यह सुनिश्चित करना है कि सभी स्लाइड पर फिट हों (इससे आप सामग्री खोने से बचते हैं), तो इस सेटिंग का उपयोग करें। 

- `Maximize`

  यदि आप बड़े स्लाइड आकार पर स्केल करना चाहते हैं और Aspose.Slides को स्लाइडों के ऑब्जेक्ट्स को बड़ा करके उन्हें नए स्लाइड आकार के अनुपात में लाना है, तो इस सेटिंग का उपयोग करें। 

यह नमूना कोड प्रस्तुति की स्लाइड का आकार बदलते समय `Maximize` सेटिंग का उपयोग कैसे करें, यह दर्शाता है:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **बार-बार पूछे जाने वाले प्रश्न**

### क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट्स या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?

हाँ। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट्स में बदल सकते हैं और बदली हुई मानों का उपयोग करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित कर सकते हैं।

### क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?

हाँ। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी उपयोग बढ़ाते हैं और प्रोसेसिंग समय को लंबा करते हैं। व्यावहारिक स्लाइड आकार का लक्ष्य रखें और आवश्यक आउटपुट गुणवत्ता प्राप्त करने के लिए केवल आवश्यकतानुसार रेंडरिंग स्केल को समायोजित करें।

### क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकारों वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूँ?

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों को [प्रस्तुतियों को मिलाएँ](/slides/hi/cpp/merge-presentation/) नहीं कर सकते — पहले एक प्रस्तुति का आकार दूसरे के साथ मिलाएँ। स्लाइड आकार बदलते समय आप मौजूदा सामग्री को कैसे संभालना है, यह [SlideSizeScaleType](https://reference.aspose.com/slides/hi/cpp/aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकारों को संरेखित करने के बाद, आप फ़ॉर्मेटिंग को संरक्षित रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

### क्या मैं व्यक्तिगत शैप्स या स्लाइड के विशिष्ट क्षेत्रों के थंबनेल जनरेट कर सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?

हाँ। Aspose.Slides [पूरी स्लाइड](/slides/hi/cpp/notes-size/) और [चयनित शैप](/slides/hi/cpp/notes-size/) के थंबनेल रेंडर कर सकता है। परिणामी छवियां वर्तमान स्लाइड आकार और अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में निरंतरता बनी रहती है।
