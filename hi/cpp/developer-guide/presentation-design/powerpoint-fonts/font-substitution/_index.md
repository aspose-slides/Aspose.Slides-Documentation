## **अवलोकन**

फ़ॉन्ट प्रतिस्थापन Aspose.Slides को रेंडरिंग या रूपांतरण के दौरान मूल प्रस्तुति फ़ॉन्ट उपलब्ध न होने पर कोई अन्य फ़ॉन्ट उपयोग करने की अनुमति देता है। आप `IFontsManager` इंटरफ़ेस की `GetSubstitutions` विधि का उपयोग करके यह जाँच सकते हैं कि कौन से फ़ॉन्ट प्रतिस्थापित हुए हैं।

Aspose.Slides आपको फ़ॉन्ट प्रतिस्थापन नियम निर्धारित करने की सुविधा भी देता है। उदाहरण के लिए, आप यह निर्धारित कर सकते हैं कि एक अनुपलब्ध फ़ॉन्ट को किसी अन्य उपलब्ध फ़ॉन्ट से बदलना है और फिर उन नियमों को प्रस्तुति के फ़ॉन्ट मैनेजर के माध्यम से लागू कर सकते हैं।

## **फ़ॉन्ट प्रतिस्थापन नियम सेट करें**

Aspose.Slides आपको उन फ़ॉन्ट्स के लिए नियम सेट करने देता है जो कुछ शर्तों में क्या करना है (उदाहरण के लिए, जब फ़ॉन्ट तक पहुँच न हो) इस प्रकार:

1. संबंधित प्रस्तुति लोड करें।
2. वह फ़ॉन्ट लोड करें जिसे बदलना है।
3. नया फ़ॉन्ट लोड करें।
4. बदलाव के लिए एक नियम जोड़ें।
5. प्रस्तुति फ़ॉन्ट प्रतिस्थापन नियम संग्रह में नियम जोड़ें।
6. प्रभाव देखने के लिए स्लाइड छवि उत्पन्न करें।

यह C++ कोड फ़ॉन्ट प्रतिस्थापन प्रक्रिया को दर्शाता है:

```c++
// दस्तावेज़ निर्देशिका का पथ।
const String outPath = u"../out/RuleBasedFontsReplacement_out.pptx";
const String templatePath = u"../templates/DefaultFonts.pptx";


// Loads a presentation
SharedPtr<Presentation> pres = MakeObject<Presentation>(templatePath);

// Defines the font that will be replaced and the new font
SharedPtr<IFontData> sourceFont = MakeObject<FontData>(u"SomeRareFont");
SharedPtr<IFontData> destFont = MakeObject<FontData>(u"Arial");
	
// Adds a font rule for font replacement
SharedPtr<FontSubstRule> fontSubstRule = MakeObject<FontSubstRule>(sourceFont, destFont, FontSubstCondition::WhenInaccessible);

// Adds the rule to font substitute rules collection
SharedPtr<FontSubstRuleCollection> fontSubstRuleCollection = MakeObject<FontSubstRuleCollection>();
fontSubstRuleCollection->Add(fontSubstRule);

// Adds the font rule collection to the rule list
pres->get_FontsManager()->set_FontSubstRuleList ( fontSubstRuleCollection);


// Saves PPTX to disk
pres->Save(outPath, Aspose::Slides::Export::SaveFormat::Pptx);
```

## **गणित समीकरण फ़ॉन्ट के लिए सीमाएँ**

फ़ॉन्ट प्रतिस्थापन नियम रेंडरिंग और रूपांतरण के दौरान इस्तेमाल की जाने वाली मानक फ़ॉन्ट चयन प्रक्रिया में भाग लेते हैं। वे सामान्य पाठ स्थितियों के लिए उपयुक्त हैं जहाँ Aspose.Slides कॉन्फ़िगर किए गए नियम के अनुसार अनुपलब्ध फ़ॉन्ट को किसी अन्य उपलब्ध फ़ॉन्ट से बदल सकता है।

हालाँकि, Office गणित समीकरणों में एक महत्वपूर्ण सीमा है। यदि कोई समीकरण **Cambria Math** के साथ बनाया गया है, तो Aspose.Slides को समीकरण लेआउट को सही ढंग से गणना और रेंडर करने के लिए मूल **Cambria Math** फ़ॉन्ट की अभी भी आवश्यकता हो सकती है। इसलिए **Cambria Math** को किसी अन्य गणित फ़ॉन्ट, जैसे **STIX Two Math**, से बदलना समीकरण रेंडरिंग के लिए समर्थित नहीं है और इससे यह अपवाद उत्पन्न हो सकता है कि **Cambria Math** आवश्यक है।

ऐसे प्रस्तुतियों को सफलतापूर्वक रूपांतरित करने के लिए सुनिश्चित करें कि **Cambria Math** रन‑टाइम पर Aspose.Slides के लिए उपलब्ध हो। आप फ़ॉन्ट को ऑपरेटिंग सिस्टम में इंस्टॉल कर सकते हैं या इसे एक [external font](/slides/hi/cpp/custom-font/) के रूप में प्रदान कर सकते हैं ताकि यह रेंडरिंग और रूपांतरण के दौरान सामान्य फ़ॉन्ट चयन प्रक्रिया में भाग ले सके।

यह सीमा विशेष रूप से समीकरण रेंडरिंग के लिए लागू होती है। उपरोक्त वर्णित मानक फ़ॉन्ट प्रतिस्थापन नियम अभी भी सामान्य प्रस्तुति पाठ पर लागू होते हैं जब मूल फ़ॉन्ट उपलब्ध नहीं होता।

## **अक्सर पूछे जाने वाले प्रश्न**

**फ़ॉन्ट प्रतिस्थापन और फ़ॉन्ट प्रतिस्थापन (सबस्टीट्यूशन) में क्या अंतर है?**  
[Replacement](/slides/hi/cpp/font-replacement/) पूरे प्रस्तुति में एक फ़ॉन्ट को दूसरे फ़ॉन्ट से बाध्यकारी रूप से बदल देता है। प्रतिस्थापन एक नियम है जो विशिष्ट स्थिति में सक्रिय होता है, जैसे मूल फ़ॉन्ट अनुपलब्ध होने पर, और तब निर्धारित फ़ॉलबैक फ़ॉन्ट उपयोग किया जाता है।

**रूपांतरण नियम बिल्कुल कब लागू होते हैं?**  
ये नियम मानक [फ़ॉन्ट चयन](/slides/hi/cpp/font-selection-sequence/) क्रम में भाग लेते हैं जो लोडिंग, रेंडरिंग और रूपांतरण के दौरान मूल्यांकित होता है; यदि चयनित फ़ॉन्ट उपलब्ध नहीं है, तो प्रतिस्थापन या बदलाव लागू किया जाता है।

**यदि न तो प्रतिस्थापन न ही प्रतिस्थापन (सबस्टीट्यूशन) कॉन्फ़िगर किया गया है और सिस्टम में फ़ॉन्ट अनुपलब्ध है तो डिफ़ॉल्ट व्यवहार क्या होता है?**  
लाइब्रेरी सबसे निकटतम उपलब्ध सिस्टम फ़ॉन्ट को चुनने का प्रयास करेगी, ठीक उसी तरह जैसे PowerPoint करता है।

**क्या मैं रन‑टाइम पर कस्टम बाहरी फ़ॉन्ट संलग्न कर सकता हूँ ताकि प्रतिस्थापन से बचा जा सके?**  
हाँ। आप रन‑टाइम पर [add external fonts](/slides/hi/cpp/custom-font/) जोड़ सकते हैं ताकि लाइब्रेरी उन्हें चयन और रेंडरिंग के लिए विचार करे, जिसमें बाद के रूपांतरण भी शामिल हैं।

**क्या Aspose लाइब्रेरी के साथ कोई फ़ॉन्ट वितरित करता है?**  
नहीं। Aspose न तो पेड फ़ॉन्ट और न ही मुफ्त फ़ॉन्ट वितरित करता है; आप फ़ॉन्ट स्वयं जोड़ते और उपयोग करते हैं अपने विवेक और ज़िम्मेदारी के तहत।

**Windows, Linux और macOS पर प्रतिस्थापन व्यवहार में क्या अंतर हैं?**  
हाँ। फ़ॉन्ट खोज ऑपरेटिंग सिस्टम की फ़ॉन्ट निर्देशिकाओं से शुरू होती है। डिफ़ॉल्ट उपलब्ध फ़ॉन्ट्स और खोज पाथ्स प्लेटफ़ॉर्म के अनुसार अलग होते हैं, जिससे उपलब्धता और प्रतिस्थापन की आवश्यकता प्रभावित होती है।

**बैच रूपांतरण के दौरान अनपेक्षित प्रतिस्थापन को न्यूनतम करने के लिए मैं वातावरण कैसे तैयार करूँ?**  
मशीनों या कंटेनरों के बीच फ़ॉन्ट सेट को समन्वयित करें, आउटपुट दस्तावेज़ों के लिए आवश्यक [add the external fonts](/slides/hi/cpp/custom-font/) जोड़ें, और जब संभव हो तो प्रस्तुतियों में [embed fonts](/slides/hi/cpp/embedded-font/) संलग्न करें ताकि चयन के दौरान फ़ॉन्ट उपलब्ध रहें।
