## **JasperReports**

Aspose.Slides for JasperReports JasperReports 3.7.2 से 6.16.0 तक काम करता है। डाउनलोड में प्रत्येक तीन संस्करण रेंज के लिए एक अलग jar होता है — देखिए [Installing Aspose.Slides for JasperReports](/slides/hi/jasperreports/installing-aspose-slides-for-jasperreports/) कि कौन सा उपयोग करना है। इसमें JasperReports 6.17.0 या बाद के संस्करणों के लिए, JasperReports 7 सहित, कोई jar नहीं है।

JasperReports 2.0.3 से 3.7.1 के लिए समर्थन Aspose.Slides for JasperReports 17.6 में समाप्त हो गया। संस्करण 17.5 और उससे पहले भी उन संस्करणों को समर्थन देते थे।

## **Java**

jars Java 6 या उसके बाद के संस्करण के लिए संकलित हैं, जैसा कि उनके फ़ोल्डर नामों में *JDK 1.6* लिखा है, इसलिए आपको जिस Java संस्करण की आवश्यकता है, वह आपका JasperReports संस्करण मांगता है। JasperReports 6.16.0 के साथ, निर्यात Java 11, 17, 21 और 25 पर चलते हैं।

## **Operating system**

jars केवल Java क्लास और संसाधन रखते हैं, कोई नेेटिव लाइब्रेरी नहीं होती, और वे Microsoft PowerPoint का उपयोग नहीं करते। Linux पर, JasperReports को रिपोर्ट भरने के लिए fontconfig और कम से कम एक स्थापित फ़ॉन्ट की आवश्यकता होती है।

## **JasperReports Server**

JasperReports Server के लिए, अपने सर्वर द्वारा चलाए जा रहे JasperReports संस्करण से मेल खाने वाले फ़ोल्डर से दोनों jars का उपयोग करें — देखें [Integration with JasperServer](/slides/hi/jasperreports/integration-with-jasperserver/).
