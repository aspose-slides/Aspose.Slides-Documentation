## **अवलोकन**

Aspose.Slides for Python via Java PowerPoint और OpenDocument प्रस्तुतियों को पढ़ता और लिखता है। यह PDF और HTML सामग्री को स्लाइड्स में आयात करता है और प्रस्तुतियों या व्यक्तिगत स्लाइड्स को दस्तावेज़, वेब, और इमेज फ़ॉर्मेट में निर्यात करता है।

नीचे की तालिका प्रस्तुति लोडिंग को सामग्री आयात और स्लाइड रेंडरिंग से अलग करती है। संपादन और रेंडरिंग क्षमताओं के अवलोकन के लिए, देखें [फ़ीचर अवलोकन](/slides/hi/python-java/features-overview/)।

## **आयात और निर्यात नोट्स**

- **PDF और HTML आयात:** स्रोत सामग्री से स्लाइड्स बनाने और उन्हें प्रस्तुति में जोड़ने के लिए [SlideCollection.addFromPdf](https://reference.aspose.com/slides/hi/python-java/aspose.slides/slidecollection/#addfrompdf) या [SlideCollection.addFromHtml](https://reference.aspose.com/slides/hi/python-java/aspose.slides/slidecollection/#addfromhtml) का उपयोग करें।
- **प्रेजेंटेशन आउटपुट:** उपलब्ध प्रस्तुति सहेजने वाले फ़ॉर्मेट्स को सूचीबद्ध करने वाला [SaveFormat](https://reference.aspose.com/slides/hi/python-java/aspose.slides/saveformat/) है, जिसमें अलग HTML और HTML5 निर्यात विकल्प शामिल हैं।
- **इमेज आउटपुट:** स्लाइड को इमेज में निर्यात करने से उस स्लाइड का दृश्य प्रतिनिधित्व बनता है। इनपुट कॉलम यह नहीं वर्णन करता कि इमेज को प्रस्तुति में सम्मिलित किया जा सकता है या नहीं।

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं PPT प्रस्तुति को PPTX या ODP में बदल सकता हूँ?**

हां। PPT इनपुट फ़ॉर्मेट के रूप में समर्थित है, और दोनों PPTX और ODP आउटपुट फ़ॉर्मेट के रूप में समर्थित हैं। रूपांतरण परिणाम गंतव्य फ़ॉर्मेट में उपलब्ध सुविधाओं पर निर्भर करते हैं।

**क्या PDF या HTML आयात स्रोत को PowerPoint फ़ाइल के रूप में खोलता है?**

नहीं। आयात PDF पृष्ठों या HTML सामग्री से स्लाइड्स बनाता है। आप फिर परिणामी प्रस्तुति को समर्थित प्रस्तुति फ़ॉर्मेट में सहेज सकते हैं।

**क्या मैं निर्यातित PNG या SVG को एक संपादन योग्य प्रस्तुति के रूप में लोड कर सकता हूँ?**

नहीं। ये निर्यतन स्लाइड की उपस्थिति को दर्शाते हैं। जब आपको बाद में उसका टेक्स्ट, आकृतियाँ, चार्ट और अन्य ऑब्जेक्ट्स संपादित करने की आवश्यकता हो, तो स्रोत प्रस्तुति को रखें।
