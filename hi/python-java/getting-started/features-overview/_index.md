यह लेख Aspose.Slides for Python via Java की प्रस्तुति प्रसंस्करण क्षमताओं का विवरण देता है। समर्थित ऑपरेटिंग सिस्टम और निर्भरताओं के लिए देखें [सिस्टम आवश्यकताएँ](/slides/hi/python-java/system-requirements/)।

## **फ़ाइल स्वरूप और रूपांतरण**

Aspose.Slides for Python via Java आपको प्रस्तुति स्वरूपों के बीच रूपांतरण करने और प्रस्तुतियों को दस्तावेज़ और वेब स्वरूपों में निर्यात करने की अनुमति देता है। पूर्ण स्वरूप तालिका और लोडिंग प्रस्तुतियों, सामग्री आयात, तथा निर्यात आउटपुट के बीच अंतर के लिए देखें [समर्थित फ़ाइल स्वरूप](/slides/hi/python-java/supported-file-formats/)।

## **प्रस्तुति रेंडरिंग**

Aspose.Slides for Python via Java प्रीव्यू और अन्य दृश्य आउटपुट के लिए रास्टर या वेक्टर छवियों के रूप में उच्च-निष्ठा स्लाइड रेंडरिंग प्रदान करता है। यह आपको स्लाइड्स पर छवियों को रेंडर करने की भी अनुमति देता है। उपलब्ध छवि स्वरूपों और निर्यात नोट्स के लिए देखें [समर्थित फ़ाइल स्वरूप](/slides/hi/python-java/supported-file-formats/#supported-file-formats)।
