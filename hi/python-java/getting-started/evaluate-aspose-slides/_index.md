आप Aspose.Slides for Python via Java को डाउनलोड करके इसकी विशेषताओं का मूल्यांकन कर सकते हैं। मूल्यांकन पैकेज लाइसेंस वाले पैकेज के समान है। इसे बिना मूल्यांकन प्रतिबंधों के उपयोग करने के लिए, लाइसेंस लागू करने के लिए कुछ लाइनें कोड जोड़ें।

Aspose.Slides का मूल्यांकन संस्करण (बिना लाइसेंस के उपयोग किया गया) पूरी उत्पाद कार्यक्षमता प्रदान करता है, लेकिन जब आप दस्तावेज़ खोलते या सहेजते हैं तो यह दस्तावेज़ के शीर्ष पर एक मूल्यांकन वॉटरमार्क डालता है। टेक्स्ट निष्कर्षण प्रत्येक प्रस्तुति में एक स्लाइड तक सीमित है।
