आप Aspose.Slides for Python via Java को डाउनलोड करके इसकी सुविधाओं का मूल्यांकन कर सकते हैं। मूल्यांकन पैकेज लाइसेंस प्राप्त पैकेज के समान है। इसे मूल्यांकन सीमाओं के बिना उपयोग करने के लिए, [लाइसेंस लागू करें](/slides/hi/python-java/licensing/) में कुछ पंक्तियों का कोड जोड़ें।

Aspose.Slides का मूल्यांकन संस्करण (बिना लाइसेंस के उपयोग किया गया) पूर्ण उत्पाद कार्यक्षमता प्रदान करता है, लेकिन दो सीमाएँ हैं:

- यह प्रत्येक सहेजी गई प्रस्तुति की हर स्लाइड में एक मूल्यांकन वॉटरमार्क टेक्स्ट बॉक्स जोड़ता है। प्रस्तुति खोलने पर यह नहीं जोड़ा जाता, लेकिन जिसमें पहले से वॉटरमार्क है, ऐसी फ़ाइल को सहेजने से एक और वॉटरमार्क जुड़ता है।
- आपके कोड द्वारा पढ़ा गया टेक्स्ट उसके पहले कुछ अक्षरों तक छोटा कर दिया जाता है, जिसके बाद मूल्यांकन सीमा के बारे में एक नोटिस आता है। यह प्रत्येक स्लाइड पर लागू होता है, और वह टेक्स्ट भी लागू होता है जो आपके कोड ने अभी सेट किया है तथा फ़ाइल से लोड किया गया टेक्स्ट भी। आपके कोड द्वारा लिखा गया टेक्स्ट पूरी तरह से सहेजा जाता है।
