## **परिचय**

प्रेजेंटेशन अभिगम्यता सुनिश्चित करती है कि सहायक प्रौद्योगिकियों—जैसे स्क्रीन रीडर, ब्रेल डिस्प्ले, या केवल कीबोर्ड नेविगेशन—का उपयोग करने वाले लोग आपके स्लाइड्स को दृष्टि वाले, माउस उपयोग करने वाले दर्शकों के समान प्रभावी ढंग से समझ और नेविगेट कर सकें। अच्छी प्रैक्टिस स्पष्ट पढ़ने क्रम, जानकारीपूर्ण दृश्यों के लिए अर्थपूर्ण वैकल्पिक पाठ, पर्याप्त रंग कंट्रास्ट, पढ़ने योग्य टाइपोग्राफी, वर्णनात्मक लिंक टेक्स्ट, और केवल रंग या स्थान से अर्थ व्यक्त करने से बचने पर केंद्रित होती है। जब अभिगम्यता को शुरुआत से ही योजना में शामिल किया जाता है, तो परिणामस्वरूप एक स्वच्छ संरचना, अधिक सुसंगत दृश्यों, और ऐसा कंटेंट मिलता है जो सभी दर्शकों तक बिना किसी वर्कअराउंड के पहुंचता है।

## **सजावटी रूप में चिन्हित करें**

Mark as decorative वह फ़्लैग है जो केवल सजावटी दृश्यों को चिह्नित करता है ताकि स्क्रीन रीडर उन्हें स्किप कर दें, शोर घटे और अर्थपूर्ण सामग्री पर ध्यान बना रहे। इसे पृष्ठभूमियों, सजावटी तत्वों और स्पेसर पर लागू करें—कभी भी चार्ट, आइकन, या सूचना प्रदान करने वाली छवियों पर नहीं। Aspose.Slides इस फ़्लैग को पहचान और सत्यापन के लिए उजागर करता है, जिससे स्वचालित अभिगम्यता जाँच और सफ़ाई संभव होती है।

![सजावटी रूप में चिन्हित करें](mark_as_decorative.png)

निम्नलिखित कोड उदाहरण दर्शाता है कि कैसे निर्धारित किया जाए कि कोई आकार सजावटी रूप में चिन्हित है या नहीं।

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation

presentation = Presentation("sample.pptx")
try:
    shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0)
    print(f"Is shape decorative: {shape.isDecorative()}")
finally:
    presentation.dispose()
```
