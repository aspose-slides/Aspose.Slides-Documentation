## **समीक्षा**

यह FAQ समर्थित फ़ाइल फ़ॉर्मेट, बड़े प्रेजेंटेशन में मेमोरी उपयोग, स्लाइड आकार और प्रीव्यू, टेक्स्ट एक्सट्रैक्शन, टेबल बॉर्डर, चित्र स्थान और PDF या इमेजेज़ में प्रेजेंटेशन को परिवर्तित करते समय फ़ॉन्ट अंतर आदि को कवर करता है।

## **अक्सर पूछे जाने वाले प्रश्न**

### **समर्थित फ़ाइल फ़ॉर्मेट**

**Aspose.Slides for Python via Java कौन से फ़ाइल फ़ॉर्मेट को सपोर्ट करता है?**

समर्थित प्रस्तुति, दस्तावेज़, और छवि फ़ॉर्मेट तथा उनके आयात और निर्यात क्षमताओं के लिए [Supported File Formats](/slides/hi/python-java/supported-file-formats/) देखें।

### **अपवाद**

**छवियों के साथ बड़े प्रेजेंटेशन को लोड करते समय मुझे आउट‑ऑफ़‑मेमोरी त्रुटि क्यों मिलती है? क्या कोई फ़ाइल आकार सीमा है?**

कोई एकल फ़ाइल आकार सीमा नहीं है जो यह पूर्वानुमानित करे कि प्रेजेंटेशन मेमोरी में फिट होगा या नहीं। मेमोरी आवश्यकताएँ प्रेजेंटेशन की संरचना, डीकम्प्रेस्ड छवियों, इफ़ेक्ट्स, और आप द्वारा किए गए ऑपरेशन्स पर निर्भर करती हैं। छवियाँ डिस्क पर उनके संकुचित आकार से कहीं अधिक मेमोरी ले सकती हैं।

Aspose.Slides for Python via Java JPype के माध्यम से Java इंजन का उपयोग करता है, इसलिए JVM हीप को प्रोसेस करने के लिये पर्याप्त स्थान होना चाहिए। केवल उपलब्ध सिस्टम RAM यह नहीं दर्शाता कि JVM कितनी मेमोरी उपयोग कर सकता है। जब आप प्रेजेंटेशन का उपयोग समाप्त कर लें तो [Presentation.dispose](https://reference.aspose.com/slides/hi/python-java/aspose.slides/presentation/#dispose) से रिलीज़ करें। पर्यावरण सेटअप के लिए देखें [System Requirements](/slides/hi/python-java/system-requirements/) और [Installation](/slides/hi/python-java/installation/)।

### **स्लाइड के साथ काम करना**

**क्या मैं प्रेजेंटेशन में स्लाइड का आकार बदल सकता हूँ?**

हां। स्लाइड आकार सेटिंग्स तक पहुँचने के लिये [Presentation.getSlideSize](https://reference.aspose.com/slides/hi/python-java/aspose.slides/presentation/#getslidesize) का उपयोग करें, फिर [SlideSize.setSize](https://reference.aspose.com/slides/hi/python-java/aspose.slides/slidesize/#setsize) से आयाम सेट करें और तय करें कि मौजूदा कंटेंट कैसे स्केल होगा।

**क्या एक ही प्रेजेंटेशन में विभिन्न स्लाइड आकार हो सकते हैं?**

नहीं। Microsoft PowerPoint दस्तावेज़ स्लाइड आकार को प्रेजेंटेशन स्तर पर परिभाषित करता है, इसलिए सभी स्लाइड्स का आकार समान रहता है।

**क्या मैं प्रेजेंटेशन सहेजने से पहले स्लाइड का प्रीव्यू ले सकता हूँ?**

हां। स्लाइड को इमेज में रेंडर करें और अपने एप्लिकेशन में वह इमेज प्रदर्शित करें। आपको पहले प्रेजेंटेशन सहेजने की आवश्यकता नहीं है।

### **टेक्स्ट के साथ काम करना**

**क्या मैं प्रेजेंटेशन से सभी टेक्स्ट प्राप्त कर सकता हूँ?**

हां। [SlideUtil](https://reference.aspose.com/slides/hi/python-java/aspose.slides/slideutil/) क्लास प्रेजेंटेशन और व्यक्तिगत स्लाइड्स से टेक्स्ट प्राप्त करने के लिये मेथड्स प्रदान करती है।

**Windows और Linux पर पैराग्राफ आकार अलग क्यों होते हैं?**

पैराग्राफ आयाम उस फ़ॉन्ट के मेट्रिक्स पर निर्भर करते हैं जिसका उपयोग टेक्स्ट को रेंडर करने में किया जाता है। यदि कोई फ़ॉन्ट अनुपलब्ध है, तो उसके प्रतिस्थापन में विभिन्न अक्षर चौड़ाई और लाइन ऊँचाई हो सकती है, जिससे लाइन रैपिंग और पैराग्राफ आयाम बदलते हैं। दोनों सिस्टम पर समान फ़ॉन्ट स्थापित करें या प्रेजेंटेशन बनाने/लोड करने से पहले [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/hi/python-java/aspose.slides/fontsloader/#loadexternalfonts) से वही फ़ॉन्ट फ़ाइलें लोड करें।

### **फ़ॉर्मेटिंग और इमेजेज़**

**मैं टेबल बॉर्डर का रंग कैसे सेट करूँ?**

प्रत्येक सेल की बॉर्डर फ़ॉर्मेटिंग तक पहुँचने के लिये [Cell.getCellFormat](https://reference.aspose.com/slides/hi/python-java/aspose.slides/cell/#getcellformat) का उपयोग करें और सम्बंधित बॉर्डर के लिए फ़िल कलर सेट करें। सभी बॉर्डर बदलने के लिये सभी सेल्स प्रोसेस करें। केवल टेबल की आउटलाइन बदलने के लिये किनारों पर स्थित सेल्स के बाहरी बॉर्डर अपडेट करें।

**चित्रों को पोज़िशन और साइज करने के लिये कौन सी इकाइयाँ उपयोग की जाती हैं?**

शेप के कॉर्डिनेट्स और आयाम पॉइंट्स में मापे जाते हैं। एक इंच में 72 पॉइंट्स होते हैं; ये मान पिक्सेल कॉर्डिनेट नहीं होते।

### **फ़ॉन्ट्स के साथ काम करना**

**प्रेजेंटेशन को PDF या इमेजेज़ में परिवर्तित करते समय फ़ॉन्ट्स क्यों बदलते हैं?**

परिवर्तन करने वाली मशीन पर आवश्यक फ़ॉन्ट्स मौजूद नहीं हो सकते। मूल फ़ॉन्ट्स स्थापित करें या [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/hi/python-java/aspose.slides/fontsloader/#loadexternalfonts) से उन फ़ोल्डरों को जोड़ें जिनमें फ़ॉन्ट फ़ाइलें हों। प्रेजेंटेशन बनाने या खोलने से पहले बाहरी फ़ॉन्ट्स लोड करें।

निम्न उदाहरण एक फ़ॉन्ट फ़ोल्डर रजिस्टर करता है। पाथ को अपने फ़ॉन्ट फ़ाइलों वाले मौजूदा फ़ोल्डर से बदलें। यह [Installation](/slides/hi/python-java/installation/) में वर्णित पर्यावरण मानता है।

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontsLoader

font_folders = jpype.JArray(jpype.JString)(["path_to_a_folder_with_fonts"])
FontsLoader.loadExternalFonts(font_folders)
```

यह उदाहरण JVM को बाद के प्रेजेंटेशन ऑपरेशन्स के लिये चलाते रहता है। नोटबुक उपयोग और JVM जीवन‑चक्र प्रतिबंधों के लिये देखें [Limitations and API Differences](/slides/hi/python-java/limitations-and-api-differences/).
