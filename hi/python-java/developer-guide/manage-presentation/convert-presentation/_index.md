## **परिचय**

Aspose.Slides for Python via Java PowerPoint और OpenDocument प्रस्तुतियों को लोड कर सकता है और उन्हें कई अन्य स्वरूपों में सहेज या रेंडर कर सकता है, बिना Microsoft PowerPoint, OpenOffice, या LibreOffice के। आप लिगेसी PPT फ़ाइलों को आधुनिक PPTX में परिवर्तित कर सकते हैं, प्रस्तुतियों को PDF और XPS जैसे स्थिर‑लेआउट दस्तावेज़ों में निर्यात कर सकते हैं, स्लाइड्स को HTML के रूप में प्रकाशित कर सकते हैं, या स्लाइड्स को प्रीव्यू, थंबनेल और अभिलेखों के लिए इमेज फ़ाइलों के रूप में रेंडर कर सकते हैं।

अधिकांश दस्तावेज़ रूपांतरण एक ही सामान्य कार्यप्रवाह का उपयोग करते हैं: स्रोत फ़ाइल लोड करें, आवश्यक आउटपुट स्वरूप चुनें, और आवश्यकता होने पर स्वरूप‑विशिष्ट विकल्प लागू करें। इमेज स्वरूपों के लिए, प्रत्येक स्लाइड को अलग‑अलग रेंडर किया जाता है और फिर रास्टर या वेक्टर इमेज के रूप में सहेजा जाता है। नीचे लिंक किए गए विशिष्ट लेख प्रत्येक मामले के कार्यान्वयन विवरण प्रदान करते हैं।

## **PowerPoint और OpenDocument रूपांतरण**

Aspose.Slides for Python via Java PPT, PPTX, PPS, PPSX, POT, POTX, और ODP जैसे सामान्यतः प्रयुक्त प्रस्तुति स्वरूपों से रूपांतरण को समर्थन देता है। वही रूपांतरण API PowerPoint और OpenDocument फ़ाइलों के लिए उपयोग किया जाता है, इसलिए एक वर्कफ़्लो जो PPTX फ़ाइल को PDF में सहेजता है, आमतौर पर केवल इनपुट फ़ाइल बदलकर ODP फ़ाइल पर लागू किया जा सकता है।

ODP फ़ाइलों को रूपांतरित करते समय याद रखें कि PowerPoint और OpenDocument एप्लिकेशन हर लेआउट और फ़ॉर्मेटिंग सुविधा को बिल्कुल समान तरीके से समर्थन नहीं देते हैं। यदि ODP फ़ाइल LibreOffice या OpenOffice Impress में बनाई गई है, तो आउटपुट की समीक्षा करें और जब आपको स्वरूप‑विशिष्ट मार्गदर्शन चाहिए तो [OpenDocument प्रस्तुतियों को परिवर्तित करें](/slides/hi/python-java/convert-openoffice-odp/) में वर्णित विकल्पों का उपयोग करें।

## **PPT से PPTX रूपांतरण**

PPT पुराना बाइनरी PowerPoint स्वरूप है, जबकि PPTX आधुनिक Office Open XML स्वरूप है। Aspose.Slides for Python via Java जटिल प्रस्तुति संरचनाओं जैसे मास्टर्स, लेआउट्स, स्लाइड्स, चार्ट्स, ग्रुप्ड शैप्स, प्लेसहोल्डर्स, टेक्स्ट फ्रेम्स, टेक्सचर और पिक्चर फ़िल्स को संरक्षित रखते हुए उच्च‑फिडेलिटी PPT से PPTX रूपांतरण को समर्थन देता है।

For details, see [PPT को PPTX में परिवर्तित करें](/slides/hi/python-java/convert-ppt-to-pptx/) and [PPT बनाम PPTX](/slides/hi/python-java/ppt-vs-pptx/).

## **स्थिर‑लेआउट निर्यात**

जब आउटपुट को विभिन्न डिवाइसों पर समान दिखना चाहिए और इसे प्रस्तुति के रूप में संपादित नहीं किया जाना चाहिए, तब PDF, XPS, और TIFF उपयोगी होते हैं। विशिष्ट PDF, XPS, और TIFF लेख समझाते हैं कि अनुपालन, छिपी हुई स्लाइड्स, नोट्स, इमेज क्वालिटी, संपीड़न, पिक्सेल फ़ॉर्मेट और आउटपुट आकार को कैसे नियंत्रित किया जाए।

## **HTML और इमेज निर्यात**

HTML और HTML5 निर्यात ब्राउज़र दृश्य, वेब प्रकाशन और हल्के साझा करने के लिए उपयोगी हैं। इमेज निर्यात तब उपयोगी होता है जब प्रत्येक स्लाइड को अलग प्रीव्यू, थंबनेल या रास्टर संपत्ति बनना हो। स्वरूप‑विशिष्ट रेंडरिंग मार्गदर्शन के लिए PNG, JPG, और SVG लेखों का उपयोग करें।

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या प्रस्तुतियों को रूपांतरित करने के लिए मुझे Microsoft PowerPoint की आवश्यकता है?**

नहीं। Aspose.Slides for Python via Java एक स्वतंत्र लाइब्रेरी है और इसे Microsoft PowerPoint या Office ऑटोमेशन की आवश्यकता नहीं है।

**क्या मैं कई प्रस्तुतियों को बैच में रूपांतरित कर सकता हूँ?**

हाँ। प्रत्येक प्रस्तुति को लोड करें, उसे आवश्यक स्वरूप में सहेजें, और प्रोसेसिंग के बाद प्रस्तुति ऑब्जेक्ट को डिस्पोज़ कर दें। समानांतर प्रोसेसिंग के लिए, अलग-अलग प्रस्तुति इंस्टेंसेज़ का उपयोग करें और [बहु-धागा](/slides/hi/python-java/multithreading/) मार्गदर्शन का पालन करें।

**क्या मैं केवल चयनित स्लाइड्स को निर्यात कर सकता हूँ?**

हाँ। कई निर्यात विधियों से आप आउटपुट स्वरूप के अनुसार स्लाइड इंडेक्स पास कर सकते हैं या व्यक्तिगत स्लाइड्स को रेंडर कर सकते हैं। लक्ष्य स्वरूप के लिए विशिष्ट लेख देखें।

**क्या PDF या XPS में निर्यात करते समय छिपी हुई स्लाइड्स को शामिल किया जा सकता है?**

हाँ। [PDF](/slides/hi/python-java/convert-powerpoint-to-pdf/) और [XPS](/slides/hi/python-java/convert-powerpoint-to-xps/) रूपांतरण लेखों में वर्णित छिपी स्लाइड निर्यात सेटिंग्स का उपयोग करें।

**क्या मैं PDF/A आउटपुट बना सकता हूँ?**

हाँ। PDF निर्यात के लिए PDF अनुपालन सेटिंग्स उपलब्ध हैं। विवरण के लिए [PowerPoint को PDF में परिवर्तित करें](/slides/hi/python-java/convert-powerpoint-to-pdf/) देखें।

**रूपांतरण के दौरान फ़ॉन्ट्स कैसे संभाले जाते हैं?**

Aspose.Slides एम्बेडेड फ़ॉन्ट्स, फ़ॉन्ट फ़ॉलबैक, और फ़ॉन्ट प्रतिस्थापन सेटिंग्स का उपयोग कर सकता है। देखें [एम्बेडेड फ़ॉन्ट](/slides/hi/python-java/embedded-font/), [फ़ॉलबैक फ़ॉन्ट](/slides/hi/python-java/fallback-font/), और [फ़ॉन्ट प्रतिस्थापन](/slides/hi/python-java/font-substitution/).
