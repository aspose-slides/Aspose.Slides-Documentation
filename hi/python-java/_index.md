Aspose.Slides for Python via Java एक लाइब्रेरी है जो Python अनुप्रयोगों में PowerPoint और OpenDocument प्रस्तुतियों को बनाने, पढ़ने, संपादित करने और परिवर्तित करने के लिए है, बिना Microsoft PowerPoint के; यह आपके Python प्रक्रिया में JPype के माध्यम से Aspose.Slides Java इंजन चलाता है।

यह PPT, PPTX, PPS, POT और ODP फाइलों को लोड और सेव करता है, जिसमें मैक्रो-सक्षम और टेम्पलेट वेरिएंट शामिल हैं, और PDF, XPS, HTML, SVG, TIFF, Markdown और छवियों में निर्यात करता है।

## **आपकी पहली प्रस्तुति**

Python और JDK स्थापित करें, `JAVA_HOME` सेट करें, और [स्थापना](/slides/hi/python-java/installation/) में वर्णित अनुसार एक वर्चुअल एनवायरनमेंट बनाएं और सक्रिय करें। फिर JPype और Aspose.Slides को PyPI से इंस्टॉल करें:

```sh
python -m pip install JPype1 aspose-slides-java
```

इस कोड को *hello.py* के रूप में सहेजें। यह Java Virtual Machine शुरू करता है, नई प्रस्तुति की पहली स्लाइड में टेक्स्ट के साथ एक क्लाउड रूप जोड़ता है, और प्रस्तुति को सहेजता है:

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat, ShapeType

# एक खाली स्लाइड के साथ प्रस्तुति बनाएँ।
presentation = Presentation()
try:
    # पहली स्लाइड प्राप्त करें।
    slide = presentation.getSlides().get_Item(0)

    # एक क्लाउड आकार जोड़ें और उसका टेक्स्ट सेट करें।
    auto_shape = slide.getShapes().addAutoShape(ShapeType.Cloud, 20, 20, 200, 80)
    auto_shape.getTextFrame().setText("Hello, Aspose!")

    # प्रस्तुति को PPTX फ़ाइल के रूप में सहेजें।
    presentation.save("new_presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

इसे उसी वर्चुअल एनवायरनमेंट में चलाएँ:

```sh
python hello.py
```

यह स्क्रिप्ट *new_presentation.pptx* को एक स्लाइड के साथ सहेजता है, जिसमें क्लाउड रूप में टेक्स्ट "Hello, Aspose!" होता है। बिना लाइसेंस के, सहेजी गई फ़ाइल में मूल्यांकन वॉटरमार्क भी होता है — देखें [लाइसेंसिंग](/slides/hi/python-java/licensing/). अधिक तरीकों से प्रस्तुति बनाने और भरने के लिये, देखें [प्रस्तुतियों बनाना](/slides/hi/python-java/create-presentation/).
