**Aspose.Slides for Python via Java में आपका स्वागत है**

![Aspose.Slides for Python via Java उत्पाद लोगो](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java एक क्लास लाइब्रेरी है जो आपके Python एप्लिकेशन को Microsoft PowerPoint® की आवश्यकता के बिना PowerPoint® प्रस्तुतियों को पढ़ने और लिखने में सक्षम बनाती है।

इसके प्रमुख फीचर्स में टेक्स्ट, शैप्स, टेबल और एनीमेशन का प्रबंधन; स्लाइड्स में ऑडियो और वीडियो जोड़ना; स्लाइड्स का पूर्वावलोकन; और स्लाइड्स को SVG, PDF और अन्य फ़ॉर्मैट्स में एक्सपोर्ट करना शामिल है।
