## **समर्थित Microsoft PowerPoint संस्करण**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **समर्थित फ़ाइल प्रारूप**

Aspose.Slides for SharePoint SharePoint दस्तावेज़ पुस्तकालय में संग्रहीत PPT और PPTX प्रस्तुतियों को परिवर्तित करता है। अन्य प्रकार की फ़ाइलें परिवर्तित नहीं होतीं।

|**प्रारूप**|**विवरण**|**रूपांतरण स्रोत**|**रूपांतरण लक्ष्य**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|PowerPoint प्रस्तुति 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|PowerPoint प्रस्तुति 2007 और बाद में|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|पोर्टेबल डॉक्युमेंट फॉर्मेट, स्लाइड्स या नोट्स दृश्य के साथ| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|TIFF इमेज, स्लाइड्स या नोट्स दृश्य के साथ| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML पेपर स्पेसिफिकेशन| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|HTML फ़ॉर्मेट में प्रस्तुति| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Shockwave Flash मूवी, स्लाइड्स या नोट्स दृश्य के साथ| |{{< emoticons/tick >}}|

|[POTX](https://docs.fileformat.com/presentation/potx/)|PowerPoint टेम्प्लेट| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|PowerPoint मैक्रो-सक्षम टेम्प्लेट| |{{< emoticons/tick >}}|

आउटपुट फ़ॉर्मेट को रूपांतरण पृष्ठ पर **Convert to** के तहत चुना जाता है; सटीक विकल्पों की सूची के लिए देखें [Multiple Format Support](/slides/hi/sharepoint/multiple-format-support/)।
