{{% alert color="info" title="Note" %}}
Aspose.Slides for SharePoint के साथ, आप SharePoint दस्तावेज़ लाइब्रेररी के भीतर PowerPoint प्रस्तुतियों को कई लोकप्रिय दस्तावेज़ स्वरूपों में रूपांतरित कर सकते हैं।

{{% /alert %}}

## **समर्थित इनपुट स्वरूप**

Aspose.Slides for SharePoint निम्नलिखित इनपुट स्वरूपों को रूपांतरित करता है:

- PPT – Microsoft PowerPoint प्रस्तुति 97 - 2003
- PPTX – Office Open XML प्रस्तुति

{{% alert color="info" title="Note" %}}
दस्तावेज़ों को रूपांतरित करने के लिए, Aspose.Slides for SharePoint एक निर्मित संस्करण पर निर्भर करता है जो [Aspose.Slides for .NET](https://products.aspose.com/slides/net/) का है।

{{% /alert %}}

## **समर्थित आउटपुट स्वरूप**

रूपांतरण पृष्ठ पर **Convert to** सूची इस क्रम में निम्नलिखित आउटपुट स्वरूप प्रदान करती है:

- PDF – Adobe पोर्टेबल दस्तावेज़
- TIFF – चित्र पैकेज
- XPS – XML पेपर स्पेसिफिकेशन
- PPS – स्लाइड शो प्रस्तुति
- PPSX – Microsoft PowerPoint Open XML स्लाइड शो
- ODP – OpenDocument प्रस्तुति
- PPTM – Microsoft PowerPoint Open XML मैक्रो-सक्षम प्रस्तुति
- PPSM – Microsoft PowerPoint Open XML मैक्रो-सक्षम स्लाइड शो
- POTX – Microsoft PowerPoint टेम्प्लेट
- POTM – PowerPoint Open XML मैक्रो-सक्षम प्रस्तुति टेम्प्लेट
- PDFNotes – PDF स्वरूप में प्रस्तुति नोट्स दृश्य
- HTML – HTML स्वरूप में प्रस्तुति
- TIFFNotes – बहु-पृष्ठ TIFF छवि के रूप में प्रस्तुति नोट्स दृश्य
- SWF – Shockwave Flash फ़िल्म
- SWFNotes – बहु-पृष्ठ SWF के रूप में प्रस्तुति नोट्स दृश्य

**रूपांतरण सेटिंग्स पृष्ठ पर आउटपुट स्वरूप का चयन करना**

![रूपांतरण सेटिंग्स पृष्ठ जिसमें आउटपुट स्वरूप की Convert to सूची है](multiple-format-support_1.png)

स्क्रीनशॉट पहले के संस्करण के साथ लिया गया था, जिसमें केवल PDF, TIFF और XPS स्वरूप उपलब्ध थे।
