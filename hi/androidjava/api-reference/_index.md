Aspose.Slides for Android via Java एक क्लास लाइब्रेरी है जो Android के लिए Java अनुप्रयोगों को Microsoft PowerPoint® या अन्य सॉफ्टवेयर का उपयोग किए बिना प्रेजेंटेशन दस्तावेज़ पढ़ने और लिखने की सुविधा देती है। Aspose.Slides for Android via Java आपको टेक्स्ट, आकृतियों, तालिकाओं और एनीमेशन को प्रबंधित करने, स्लाइड्स में ऑडियो और वीडियो जोड़ने, स्लाइड्स का पूर्वावलोकन करने, तथा स्लाइड्स को SVG, PDF फॉर्मेट और अन्य रूपों में निर्यात करने की अनुमति देती है।

नवीनतम API रेफ़रेंस यहाँ पाया जा सकता है: [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/hi/androidjava/)।
