## **परिचय**

Aspose.Slides पॉवरपॉइंट प्रस्तुतियों में स्लाइड आकार और अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शन दोनों के लिए महत्वपूर्ण है।

प्रचलित स्लाइड आकार और अनुपात:

- **स्टैण्डर्ड (4:3 अनुपात)**: पुराने स्क्रीन और उपकरणों के लिए आदर्श।
- **वाइडस्क्रीन (16:9 अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सुनिश्चित करें कि आपके प्रस्तुति में पूरे स्लाइड आकार और अनुपात समान रहे, क्योंकि एक ही स्लाइड आकार और अनुपात सभी स्लाइड्स पर लागू होते हैं। सर्वोत्तम परिणामों के लिए, जटिलताओं से बचने हेतु अपनी प्रस्तुति निर्माण प्रक्रिया की शुरुआत में ही स्लाइड के आयाम निर्धारित करें।

{{% alert color="info" title="Note" %}}
डिफ़ॉल्ट रूप से, Aspose.Slides द्वारा बनाई गई प्रस्तुतियों में मानक 4:3 अनुपात उपयोग किया जाता है।
{{% /alert %}}

नोट्स और हैंडआउट पेजों के आयाम सामान्य स्लाइड्स से अलग होते हैं। उनका आकार और अभिविन्यास बदलने के लिए देखें [नोट्स पेज आकार](/slides/hi/androidjava/notes-size/)।

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड आपको Aspose.Slides का उपयोग करके जावा में प्रस्तुति का स्लाइड आकार कैसे बदलें, दिखाता है।

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि सामान्य स्लाइड आकार (4:3 और 16:9) आपके काम के लिए उपयुक्त नहीं लगते हैं, तो आप एक विशिष्ट या अनोखा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के तौर पर, यदि आप अपनी प्रस्तुति से कस्टम पेज लेआउट पर पूर्ण आकार की स्लाइडें प्रिंट करने की योजना बनाते हैं या यदि आप अपनी प्रस्तुति को कुछ विशेष स्क्रीन प्रकारों पर प्रदर्शित करने का इरादा रखते हैं, तो कस्टम आकार सेटिंग का उपयोग करने से आपको लाभ मिल सकता है।

यह नमूना कोड दिखाता है कि जावा के माध्यम से Aspose.Slides for Android का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट किया जाए:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // A4 कागज़ आकार
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **आकार बदलने के बाद स्लाइड सामग्री को संभालें**

जब आप किसी प्रस्तुति का स्लाइड आकार बदलते हैं, तो स्लाइड की सामग्री (जैसे छवियां या वस्तुएँ) विकृत हो सकती है। डिफ़ॉल्ट रूप से, वस्तुएँ स्वचालित रूप से नई स्लाइड आकार में फिट होने के लिए रीसेज़ हो जाती हैं। हालांकि, प्रस्तुति का स्लाइड आकार बदलते समय, आप ऐसा सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करता है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालता है।

आपकी इच्छा और लक्ष्य के आधार पर, आप इन सेटिंग्स में से कोई भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर वस्तुओं को रीसेज़ नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार में स्केल करना चाहते हैं और आप चाहते हैं कि Aspose.Slides स्लाइड की वस्तुओं को नीचे स्केल करे ताकि सभी वस्तुएँ स्लाइड पर फिट हो जाएँ (इस तरह आप सामग्री खोने से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार में स्केल करना चाहते हैं और आप चाहते हैं कि Aspose.Slides स्लाइड की वस्तुओं को बढ़ाए ताकि वे नई स्लाइड आकार के अनुपात में हों, तो इस सेटिंग का उपयोग करें।

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?**

हाँ। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट में परिवर्तित कर सकता हैं और परिवर्तित मानों का उपयोग करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित कर सकते हैं।

**क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हाँ। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी खपत को बढ़ाते हैं और प्रोसेसिंग समय को लंबा करते हैं। एक व्यावहारिक स्लाइड आकार लक्ष्य रखें और आवश्यक आउटपुट गुणवत्ता प्राप्त करने के लिए केवल आवश्यकतानुसार रेंडरिंग स्केल समायोजित करें।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकारों वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूँ?**

जब प्रस्तुतियों के स्लाइड आकार अलग होते हैं, तो आप [प्रस्तुतियों को मर्ज करें](/slides/hi/androidjava/merge-presentation/) नहीं कर सकते — पहले, एक प्रस्तुति का आकार दूसरे के समान करने के लिए रीसेज़ करें। स्लाइड आकार बदलते समय, आप मौजूदा सामग्री को कैसे संभालना है, इसे [SlideSizeScaleType](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकारों को संरेखित करने के बाद, आप फ़ॉर्मेटिंग को संरक्षित रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

**क्या मैं स्लाइड की व्यक्तिगत आकृतियों या विशिष्ट क्षेत्रों के लिए थंबनेल जेनरेट कर सकता हूँ, और क्या वे नई स्लाइड आकार का सम्मान करेंगे?**

हाँ। Aspose.Slides [पूरी स्लाइडें](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) के साथ-साथ [चयनित आकृतियों](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) के थंबनेल रेंडर कर सकता है। उत्पन्न छवियाँ वर्तमान स्लाइड आकार और अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और भूमिती में संगतता बनी रहती है।
