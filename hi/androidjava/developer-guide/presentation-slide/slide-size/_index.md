## **परिचय**

Aspose.Slides PowerPoint प्रस्तुतियों में स्लाइड आकार और पहलू अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शन दोनों के लिए महत्वपूर्ण हैं।

लोकप्रिय स्लाइड आकार और अनुपात:

- **Standard (4:3 Aspect Ratio)**: पुराने स्क्रीन और उपकरणों के लिए आदर्श।
- **Widescreen (16:9 Aspect Ratio)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

अपनी प्रस्तुति में निरंतरता सुनिश्चित करें क्योंकि एक ही स्लाइड आकार और पहलू अनुपात सभी स्लाइड पर लागू होता है। इष्टतम परिणामों के लिए, जटिलताओं से बचने हेतु अपनी प्रस्तुति निर्माण प्रक्रिया की शुरुआत में स्लाइड आयाम निर्धारित करें।

{{% alert color="primary" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides द्वारा बनाई गई प्रस्तुतियों में मानक 4:3 पहलू अनुपात उपयोग किया जाता है।
{{% /alert %}}

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड आपको दिखाता है कि Aspose.Slides का उपयोग करके जावा में प्रस्तुति में स्लाइड आकार कैसे बदलें:

```java
Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आप सामान्य स्लाइड आकार (4:3 और 16:9) को अपने काम के लिए अनुपयुक्त पाते हैं, तो आप किसी विशिष्ट या अनोखे स्लाइड आकार का उपयोग करने का निर्णय ले सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रस्तुति से कस्टम पेज लेआउट पर पूर्ण आकार स्लाइड प्रिंट करने की योजना बनाते हैं या यदि आप अपनी प्रस्तुति को कुछ स्क्रीन प्रकारों पर प्रदर्शित करना चाहते हैं, तो कस्टम आकार सेटिंग का उपयोग करने से आपको लाभ मिल सकता है।

यह नमूना कोड आपको दिखाता है कि जावा के माध्यम से Aspose.Slides for Android का उपयोग करके जावा में प्रस्तुति के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट करें:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // A4 कागज़ आकार
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **रिसाइज़ करने के बाद स्लाइड सामग्री को संभालें**

जब आप किसी प्रस्तुति के स्लाइड आकार को बदलते हैं, तो स्लाइड की सामग्री (जैसे चित्र या वस्तुएँ) विकृत हो सकती है। डिफ़ॉल्ट रूप से, वस्तुओं को नए स्लाइड आकार में फिट होने के लिए स्वतः रीफ़ाइंड किया जाता है। हालांकि, प्रस्तुति के स्लाइड आकार को बदलते समय, आप एक सेटिंग निर्दिष्ट कर सकते हैं जो तय करती है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालेगा।

आपके उद्देश्य या लक्ष्य के आधार पर, आप निम्नलिखित सेटिंग्स में से कोई भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर वस्तुओं को रीफ़ाइंड नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार में स्केल करना चाहते हैं और Aspose.Slides को स्लाइड की वस्तुओं को घटाकर यह सुनिश्चित करना है कि वे सभी स्लाइड में फिट हों (इस तरह आप सामग्री खोने से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार में स्केल करना चाहते हैं और Aspose.Slides को स्लाइड की वस्तुओं को बड़ा करके उन्हें नए स्लाइड आकार के अनुपात में लाना है, तो इस सेटिंग का उपयोग करें।

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट या मिलिमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?**

हाँ। Aspose.Slides आंतरिक रूप से पॉइंट का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलिमीटर या सेंटीमीटर) को पॉइंट में परिवर्तित करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित करने के लिए उपयोग कर सकते हैं।

**क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हाँ। बड़े स्लाइड आयाम (पॉइंट में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी खपत बढ़ाते हैं और प्रसंस्करण समय को लंबा करते हैं। व्यावहारिक स्लाइड आकार का लक्ष्य रखें और आवश्यकतानुसार आउटपुट गुणवत्ता प्राप्त करने के लिए रेंडरिंग स्केल को ही समायोजित करें।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर अलग आकार वाली प्रस्तुतियों से स्लाइड का मर्ज कर सकता हूँ?**

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों को [merge presentations](/slides/hi/androidjava/merge-presentation/) नहीं कर सकते — पहले एक प्रस्तुति का आकार दूसरे के साथ मिलाने के लिए री-साइज़ करें। स्लाइड आकार बदलते समय, आप मौजूदा सामग्री को कैसे संभालना है, इसे [SlideSizeScaleType](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार को संरेखित करने के बाद, आप फ़ॉर्मेटिंग को बनाए रखते हुए स्लाइड को मर्ज कर सकते हैं।

**क्या मैं एकल आकारों या स्लाइड के विशिष्ट क्षेत्रों के लिए थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?**

हाँ। Aspose.Slides [entire slides](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) और [selected shapes](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) दोनों के लिए थंबनेल रेंडर कर सकता है। उत्पन्न छवियाँ वर्तमान स्लाइड आकार और पहलू अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में निरंतरता सुनिश्चित होती है।
