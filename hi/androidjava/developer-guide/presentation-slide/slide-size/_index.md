## **परिचय**

Aspose.Slides पावरपॉइंट प्रेज़ेंटेशनों में स्लाइड आकार और अनुपात को समायोजित करने के लिए व्यापक टूल्स प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शन दोनों के लिए महत्वपूर्ण है।

लोकप्रिय स्लाइड आकार और अनुपात:

- **स्टैंडर्ड (4:3 अनुपात)**: पुराने स्क्रीन और डिवाइसेस के लिए आदर्श।
- **वाइडस्क्रीन (16:9 अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सुनिश्चित करें कि आपके प्रेज़ेंटेशन में संपूर्ण रूप से एक ही स्लाइड आकार और अनुपात सभी स्लाइडों पर लागू हो। सर्वोत्तम परिणामों के लिए, जटिलताओं से बचने हेतु अपने प्रेज़ेंटेशन निर्माण प्रक्रिया की शुरुआत में ही स्लाइड आयाम निर्धारित करें।

{{% alert color="info" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides के साथ निर्मित प्रेज़ेंटेशन मानक 4:3 अनुपात का उपयोग करते हैं।
{{% /alert %}}

## **प्रेज़ेंटेशन में स्लाइड आकार बदलें**

यह नमूना कोड आपको दिखाता है कि Java में Aspose.Slides का उपयोग करके प्रेज़ेंटेशन में स्लाइड आकार कैसे बदलें:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **प्रेज़ेंटेशन में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आपको सामान्य स्लाइड आकार (4:3 और 16:9) आपके काम के लिए उपयुक्त नहीं लगते, तो आप एक विशिष्ट या अनोखा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के लिए, यदि आप अपने प्रेज़ेंटेशन की पूर्ण आकार की स्लाइड कस्टम पेज लेआउट पर प्रिंट करने की योजना बनाते हैं या यदि आप अपने प्रेज़ेंटेशन को कुछ विशेष स्क्रीन प्रकारों पर दिखाना चाहते हैं, तो कस्टम आकार सेटिंग का उपयोग करने से आपको लाभ मिल सकता है।

यह नमूना कोड आपको दिखाता है कि Java के माध्यम से Aspose.Slides for Android का उपयोग करके प्रेज़ेंटेशन में कस्टम स्लाइड आकार कैसे निर्दिष्ट करें:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // A4 काग़ज़ आकार
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **स्लाइड आकार बदलने के बाद स्लाइड सामग्री को संभालें**

प्रेज़ेंटेशन के स्लाइड आकार बदलने के बाद, स्लाइड की सामग्री (जैसे चित्र या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट्स नए स्लाइड आकार में फिट होने के लिए स्वतः रिसाइज़ हो जाते हैं। हालांकि, प्रेज़ेंटेशन का स्लाइड आकार बदलते समय, आप एक सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करती है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालता है।

आपके इरादे या लक्ष्य के आधार पर, आप इन सेटिंग्स में से किसी का उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर ऑब्जेक्ट्स को रिसाइज़ नहीं चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार में स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट्स को नीचे स्केल करे ताकि सभी स्लाइड पर फिट हों (इस तरह आप सामग्री की हानि से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार में स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट्स को बढ़ाए ताकि वे नए स्लाइड आकार के अनुपातिक हों, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड आपको दिखाता है कि प्रेज़ेंटेशन की स्लाइड का आकार बदलते समय `Maximize` सेटिंग का उपयोग कैसे करें:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट्स या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट्स में बदल सकते हैं और परिवर्तित मानों का उपयोग करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित कर सकते हैं।

### क्या एक बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?

हां। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी उपयोग में वृद्धि और प्रोसेसिंग समय को लंबा कर देते हैं। व्यावहारिक स्लाइड आकार का लक्ष्य रखें और आवश्यकतानुसार रेंडरिंग स्केल को समायोजित करें ताकि इच्छित आउटपुट गुणवत्ता प्राप्त हो सके।

### क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकारों वाले प्रेज़ेंटेशन से स्लाइड्स को मिलाकर एक साथ जोड़ सकता हूँ?

आप विभिन्न स्लाइड आकार वाले प्रेज़ेंटेशन को [प्रेज़ेंटेशन मिलाएँ](/slides/hi/androidjava/merge-presentation/) नहीं कर सकते — पहले, एक प्रेज़ेंटेशन का आकार बदलकर दूसरे के समान बनाएं। स्लाइड आकार बदलते समय, आप मौजूद सामग्री को कैसे संभालना है, इसे [SlideSizeScaleType](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार मिलाने के बाद, आप फ़ॉर्मेटिंग को बनाए रखते हुए स्लाइड्स को मिलाकर जोड़ सकते हैं।

### क्या मैं व्यक्तिगत शैप्स या स्लाइड के विशिष्ट क्षेत्रों के लिए थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?

हां। Aspose.Slides [संपूर्ण स्लाइड्स](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) तथा [चुने हुए शैप्स](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) के लिए थंबनेल रेंडर कर सकता है। परिणामी छवियां वर्तमान स्लाइड आकार और अनुपात को प्रतिबिंबित करती हैं, जिससे फ्रेमिंग और ज्यामिति में निरंतरता बनी रहती है।
