## **PPT को PPTX में बदलें**
Aspose.Slides for Android via Java अब डेवलपर्स को [Presentation](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/presentation) क्लास इंस्टेंस का उपयोग करके PPT तक पहुँचने और उसे संबंधित [PPTX](https://docs.fileformat.com/presentation/pptx/) फ़ॉर्मेट में बदलने में सक्षम बनाता है। वर्तमान में, यह [PPT ](https://docs.fileformat.com/presentation/ppt/) को PPTX में आंशिक रूपांतरण का समर्थन करता है।

Aspose.Slides for Android via Java [Presentation](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/presentation) क्लास प्रदान करता है जो **PPTX** प्रस्तुति फ़ाइल का प्रतिनिधित्व करता है। जब ऑब्जेक्ट इंस्टैंसिएट किया जाता है तो Presentation क्लास अब **PPT** तक भी पहुँच सकता है। निम्न उदाहरण दर्शाता है कि PPT प्रस्तुति को PPTX प्रस्तुति में कैसे बदलें।

```java
import com.aspose.slides.*;

// एक Presentation ऑब्जेक्ट बनाएं जो PPT फ़ाइल का प्रतिनिधित्व करता है
Presentation pres = new Presentation("Aspose.ppt");
try {
    // PPT प्रस्तुति को PPTX फ़ॉर्मेट में सहेज रहा है
    pres.save("ConvertedAspose.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

### PPT और PPTX फ़ॉर्मेट में क्या अंतर है?

PPT माइक्रोसॉफ्ट PowerPoint द्वारा उपयोग किया जाने वाला पुराना बाइनरी फ़ाइल फ़ॉर्मेट है, जबकि PPTX माइक्रोसॉफ्ट Office 2007 के साथ प्रस्तुत किया गया नया XML‑आधारित फ़ॉर्मेट है। PPTX फ़ाइलें बेहतर प्रदर्शन, छोटी फ़ाइल आकार और सुधारित डेटा रिकवरी प्रदान करती हैं।

### क्या Aspose.Slides कई PPT फ़ाइलों को PPTX में बैच रूपांतरण का समर्थन करता है?

हाँ, आप लूप में Aspose.Slides का उपयोग करके कई PPT फ़ाइलों को प्रोग्रामेटिक रूप से PPTX में बदल सकते हैं, जो बैच रूपांतरण परिदृश्यों के लिए उपयुक्त है।

### क्या रूपांतरण के बाद सामग्री और फ़ॉर्मेटिंग बरकरार रहती है?

Aspose.Slides प्रस्तुति को बदलते समय उच्च फ़िडेलिटी बनाए रखता है। स्लाइड लेआउट, एनीमेशन, आकृतियाँ, चार्ट और अन्य डिज़ाइन तत्व PPT से PPTX रूपांतरण के दौरान संरक्षित रहते हैं।

### क्या मैं PPT फ़ाइलों को PDF या HTML जैसे अन्य फ़ॉर्मेट में बदल सकता हूँ?

हाँ, Aspose.Slides कई फ़ॉर्मेट ([multiple formats](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/saveformat/)) जैसे PDF, XPS, HTML, ODP और PNG तथा JPEG जैसी छवि फ़ॉर्मेट में PPT फ़ाइलों को बदलने का समर्थन करता है।

### क्या Microsoft PowerPoint स्थापित किए बिना PPT को PPTX में बदलना संभव है?

हाँ, Aspose.Slides एक स्टैंडअलोन API है और रूपांतरण करने के लिए Microsoft PowerPoint या किसी तृतीय‑पक्ष सॉफ़्टवेयर की आवश्यकता नहीं होती।

### क्या PPT से PPTX रूपांतरण के लिए कोई ऑनलाइन टूल उपलब्ध है?
