## **अवलोकन**

Aspose.Slides for Android via Java PowerPoint और OpenDocument प्रस्तुतियों को लोड कर सकता है और उन्हें कई अन्य फ़ॉर्मेट में सहेज या रेंडर कर सकता है बिना Microsoft PowerPoint, OpenOffice या LibreOffice के। आप पुरानी PPT फ़ाइलों को आधुनिक PPTX में बदल सकते हैं, प्रस्तुतियों को PDF और XPS जैसे स्थिर‑लेआउट दस्तावेज़ों में निर्यात कर सकते हैं, स्लाइड्स को HTML के रूप में प्रकाशित कर सकते हैं, या स्लाइड्स को प्रीव्यू, थंबनेल और अभिलेखों के लिए इमेज फ़ाइलों के रूप में रेंडर कर सकते हैं।

अधिकांश दस्तावेज़ रूपांतरण समान सामान्य वर्कफ़्लो का उपयोग करते हैं: स्रोत फ़ाइल लोड करें, आवश्यक आउटपुट फ़ॉर्मेट चुनें, और आवश्यकता पड़ने पर फ़ॉर्मेट‑विशिष्ट विकल्प लागू करें। इमेज फ़ॉर्मेट के लिए, प्रत्येक स्लाइड को अलग‑अलग रेंडर किया जाता है और फिर रास्टर या वेक्टर इमेज के रूप में सहेजा जाता है। नीचे लिंक किए गए समर्पित लेख प्रत्येक केस के कार्यान्वयन विवरण प्रदान करते हैं।

## **PowerPoint और OpenDocument रूपांतरण**

Aspose.Slides for Android via Java PPT, PPTX, PPS, PPSX, POT, POTX और ODP जैसे आम उपयोग में आने वाले प्रस्तुति फ़ॉर्मेट से रूपांतरण का समर्थन करता है। PowerPoint और OpenDocument फ़ाइलों के लिए समान रूपांतरण API उपयोग किया जाता है, इसलिए एक वर्कफ़्लो जो PPTX फ़ाइल को PDF में सहेजता है, आमतौर पर केवल इनपुट फ़ाइल बदलकर ODP फ़ाइल पर भी लागू किया जा सकता है।

ODP फ़ाइलों को रूपांतरित करते समय याद रखें कि PowerPoint और OpenDocument एप्लिकेशन हर लेआउट और फ़ॉर्मेटिंग फीचर को बिल्कुल समान तरीके से समर्थन नहीं करते। यदि ODP फ़ाइल LibreOffice या OpenOffice Impress में बनाई गई है, तो आउटपुट की समीक्षा करें और फ़ॉर्मेट‑विशिष्ट मार्गदर्शन के लिए [Convert OpenDocument Presentations](/slides/hi/androidjava/convert-openoffice-odp/) में वर्णित विकल्पों का उपयोग करें।

## **PPT से PPTX रूपांतरण**

PPT पुराना बाइनरी PowerPoint फ़ॉर्मेट है, जबकि PPTX आधुनिक Office Open XML फ़ॉर्मेट है। Aspose.Slides for Android via Java जटिल प्रस्तुति संरचनाओं जैसे मास्टर, लेआउट, स्लाइड, चार्ट, समूहित आकार, प्लेसहोल्डर, टेक्स्ट फ्रेम, टेक्सचर और पिक्चर फ़िल को संरक्षित रखते हुए उच्च‑फ़िडेलिटी PPT से PPTX रूपांतरण का समर्थन करता है।

विवरण के लिए देखें [Convert PPT to PPTX](/slides/hi/androidjava/convert-ppt-to-pptx/) और [PPT vs PPTX](/slides/hi/androidjava/ppt-vs-pptx/)।

## **स्थिर‑लेआउट निर्यात**

PDF, XPS और TIFF उपयोगी होते हैं जब आउटपुट को सभी डिवाइसों पर समान दिखना चाहिए और उसे प्रस्तुति के रूप में संपादित नहीं किया जाना चाहिए। समर्पित PDF, XPS और TIFF लेख compliance, hidden slides, notes, image quality, compression, pixel format और output size को नियंत्रित करने के तरीकों को समझाते हैं।

## **HTML और इमेज निर्यात**

HTML और HTML5 निर्यात ब्राउज़र में देखने, वेब प्रकाशन और हल्के साझा करने के लिए उपयोगी हैं। इमेज निर्यात तब उपयोगी होता है जब प्रत्येक स्लाइड को अलग प्रीव्यू, थंबनेल या रास्टर एसेट बनाना हो। फ़ॉर्मेट‑विशिष्ट रेंडरिंग मार्गदर्शन के लिए PNG, JPG और SVG लेख देखें।

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मुझे प्रस्तुतीकरण रूपांतरण के लिए Microsoft PowerPoint की आवश्यकता है?**

नहीं। Aspose.Slides for Android via Java एक स्टैंडअलोन लाइब्रेरी है और इसे Microsoft PowerPoint या Office ऑटोमेशन की आवश्यकता नहीं होती।

**क्या मैं कई प्रस्तुतियों को बैच में रूपांतरित कर सकता हूँ?**

हाँ। प्रत्येक प्रस्तुति को लोड करें, आवश्यक फ़ॉर्मेट में सहेजें, और प्रक्रिया समाप्त होने पर प्रस्तुति ऑब्जेक्ट को डिस्पोज़ करें। समानांतर प्रोसेसिंग के लिए, अलग‑अलग प्रस्तुति इंस्टेंस का उपयोग करें और [multithreading](/slides/hi/androidjava/multithreading/) मार्गदर्शन का पालन करें।

**क्या मैं केवल चयनित स्लाइड्स को निर्यात कर सकता हूँ?**

हाँ। कई निर्यात विधियाँ आपको स्लाइड इंडेक्स पास करने या व्यक्तिगत स्लाइड्स को रेंडर करने की अनुमति देती हैं, यह आउटपुट फ़ॉर्मेट पर निर्भर करता है। लक्षित फ़ॉर्मेट के समर्पित लेख देखें।

**क्या मैं PDF या XPS में निर्यात करते समय छिपी हुई स्लाइड्स को शामिल कर सकता हूँ?**

हाँ। छिपी‑स्लाइड निर्यात सेटिंग्स के लिए [PDF](/slides/hi/androidjava/convert-powerpoint-to-pdf/) और [XPS](/slides/hi/androidjava/convert-powerpoint-to-xps/) रूपांतरण लेख देखें।

**क्या मैं PDF/A आउटपुट बना सकता हूँ?**

हाँ। PDF निर्यात के लिए PDF compliance सेटिंग्स उपलब्ध हैं। विवरण के लिए देखें [Convert PowerPoint to PDF](/slides/hi/androidjava/convert-powerpoint-to-pdf/)।

**रूपांतरण के दौरान फ़ॉन्ट कैसे संभाले जाते हैं?**

Aspose.Slides एम्बेडेड फ़ॉन्ट, फ़ॉन्ट फ़ॉलबैक और फ़ॉन्ट सब्स्टिट्यूशन सेटिंग्स का उपयोग कर सकता है। देखें [Embedded Font](/slides/hi/androidjava/embedded-font/), [Fallback Font](/slides/hi/androidjava/fallback-font/) और [Font Substitution](/slides/hi/androidjava/font-substitution/).
