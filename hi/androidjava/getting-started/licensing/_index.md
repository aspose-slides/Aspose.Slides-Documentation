## **परिचय**

Aspose.Slides को मूल्यांकन मोड में या वैध लाइसेंस के साथ उपयोग किया जा सकता है। मूल्यांकन संस्करण लाइसेंस प्राप्त संस्करण के समान कार्यक्षमता प्रदान करता है, लेकिन प्रस्तुतियों को खोलने या सहेजने पर एक मूल्यांकन वॉटरमार्क जोड़ता है और टेक्स्ट एक्सट्रैक्शन को एक स्लाइड तक सीमित करता है।

यह लेख बताता है कि Aspose.Slides में लाइसेंसिंग कैसे काम करती है और लाइब्रेरी का उपयोग करने से पहले लाइसेंस कैसे लागू किया जाए। लाइसेंस को `License` क्लास का उपयोग करके फ़ाइल, स्ट्रीम या एम्बेडेड रिसोर्स से लोड किया जा सकता है। लेख यह भी दिखाता है कि लाइसेंस सही ढंग से लागू हुआ है या नहीं, इसे कैसे मान्य किया जाए।

## **Aspose.Slides का मूल्यांकन करें**

{{% alert color="info" %}} 

आप **Aspose.Slides for Android via Java** का मूल्यांकन संस्करण उसके [download page](https://releases.aspose.com/slides/hi/androidjava/) से डाउनलोड कर सकते हैं। मूल्यांकन संस्करण उत्पाद के लाइसेंस प्राप्त संस्करण के समान कार्यक्षमताएँ प्रदान करता है। मूल्यांकन पैकेज खरीदे गए पैकेज के समान है। मूल्यांकन संस्करण केवल कुछ कोड पंक्तियों को जोड़ने (लाइसेंस लागू करने) के बाद लाइसेंस प्राप्त हो जाता है।

एक बार जब आप **Aspose.Slides** का मूल्यांकन कर लें, तो आप [लाइसेन्स खरीदें](https://purchase.aspose.com/buy) कर सकते हैं। हम विभिन्न सब्सक्रिप्शन प्रकारों को देखने की सलाह देते हैं। यदि आपके कोई प्रश्न हैं, तो Aspose की बिक्री टीम से संपर्क करें।

प्रत्येक Aspose लाइसेंस में एक वर्ष की सब्सक्रिप्शन शामिल होती है, जिससे सब्सक्रिप्शन अवधि के भीतर नई संस्करणों या फिक्सेस के मुफ्त अपग्रेड मिलते हैं। लाइसेंस प्राप्त उत्पाद (या यहाँ तक कि मूल्यांकन संस्करण) वाले उपयोगकर्ताओं को मुफ्त और अनलिमिटेड तकनीकी सहायता मिलती है।

## **Aspose.Slides में लाइसेंसिंग**

* एक मूल्यांकन संस्करण लाइसेंस खरीदने और कुछ कोड पंक्तियों को जोड़ने (लाइसेंस लागू करने) के बाद लाइसेंस प्राप्त हो जाता है।  
* लाइसेंस एक साधारण‑टेक्स्ट XML फ़ाइल है जिसमें उत्पाद नाम, लाइसेंस प्राप्त डेवलपर्स की संख्या, सब्सक्रिप्शन समाप्ति तिथि आदि विवरण होते हैं।  
* लाइसेंस फ़ाइल डिजिटल रूप से साइन की गई होती है, इसलिए आपको फ़ाइल को संशोधित नहीं करना चाहिए। फ़ाइल की सामग्री में अनजाने में एक अतिरिक्त लाइन‑ब्रेक जोड़ने से भी लाइसेंस अमान्य हो जाएगा।  
* Aspose.Slides for Android via Java आम तौर पर लाइसेंस को इन स्थानों पर खोजता है:  
  * एक स्पष्ट पाथ  
  * वह फ़ोल्डर जिसमें Aspose.Slides.jar मौजूद है  
* मूल्यांकन संस्करण से जुड़ी सीमाओं से बचने के लिए, आपको **Aspose.Slides** का उपयोग करने से पहले लाइसेंस सेट करना आवश्यक है। आप केवल एक बार प्रति एप्लिकेशन या प्रक्रिया लाइसेंस सेट करते हैं।

## **लाइसेंस लागू करना**

लाइसेंस को **फ़ाइल** या **स्ट्रीम** से लोड किया जा सकता है।

{{% alert color="info" %}}

Aspose.Slides लाइसेंसिंग कार्यों के लिए [License](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/license/) क्लास प्रदान करता है।

{{% /alert %}} 

{{% alert color="warning" %}}

नए लाइसेंस केवल संस्करण 21.4 या बाद के साथ Aspose.Slides को सक्रिय कर सकते हैं। पुराने संस्करण अलग लाइसेंसिंग सिस्टम का उपयोग करते हैं और इन लाइसेंसों को पहचान नहीं पाएंगे।

{{% /alert %}}

### **फ़ाइल**

लाइसेंस सेट करने की सबसे आसान विधि के लिए आपको लाइसेंस फ़ाइल को Aspose.Slides.jar या आपके एप्लिकेशन की jar वाली फ़ोल्डर में रखना आवश्यक है।

``` java
// लाइसेंस क्लास का उदाहरण बनाता है
com.aspose.slides.License license = new com.aspose.slides.License();

// लाइसेंस फ़ाइल पथ सेट करता है
license.setLicense("Aspose.Slides.Android.via.Java.lic");
```

{{% alert color="warning" %}} 

यदि आप लाइसेंस फ़ाइल को किसी अलग डायरेक्टरी में रखते हैं, तो जब आप [SetLicense](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-) मेथड को कॉल करते हैं, तो निर्दिष्ट स्पष्ट पाथ के अंत में लाइसेंस फ़ाइल नाम आपके वास्तविक लाइसेंस फ़ाइल नाम के समान होना चाहिए।

उदाहरण के लिए, आप लाइसेंस फ़ाइल का नाम *Aspose.Slides.Android.via.Java.lic.xml* रख सकते हैं। फिर अपने कोड में आपको फ़ाइल का पाथ (जिसका अंत *Aspose.Slides.Android.via.Java.lic.xml* है) को [SetLicense](https://reference.aspose.com/slides/hi/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-) मेथड को पास करना होगा।

{{% /alert %}}

### **स्ट्रीम**

आप लाइसेंस को स्ट्रीम से लोड कर सकते हैं। यह Java कोड दिखाता है कि स्ट्रीम से लाइसेंस कैसे लागू किया जाए:

``` java
// लाइसेंस क्लास का उदाहरण बनाता है
com.aspose.slides.License license = new com.aspose.slides.License();

// स्ट्रीम के माध्यम से लाइसेंस सेट करता है
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Android.via.Java.lic"));
```

## **लाइसेंस की वैधता जाँच**

जाँचने के लिए कि लाइसेंस सही ढंग से सेट हुआ है या नहीं, आप इसे वैधता जांच सकते हैं। यह Java कोड दिखाता है कि लाइसेंस को कैसे वैधता जाँचें:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Android.via.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं लाइसेंस को पूरी तरह ऑफ़लाइन वातावरण में (कोई इंटरनेट एक्सेस नहीं) लागू कर सकता हूँ?

हाँ। लाइसेंस वैधता लाइसेंस फ़ाइल का उपयोग करके स्थानीय रूप से की जाती है; इंटरनेट कनेक्शन की आवश्यकता नहीं है।

### एक वर्ष की सब्सक्रिप्शन समाप्त होने के बाद क्या होगा? क्या लाइब्रेरी काम करना बंद कर देगी?

नहीं। लाइसेंस स्थायी है: आप अपनी सब्सक्रिप्शन समाप्ति तिथि से पहले जारी किए गए संस्करणों का उपयोग जारी रख सकते हैं; लेकिन बिना नवीनीकरण के आप नए रिलीज़ उपयोग नहीं कर पाएँगे।
