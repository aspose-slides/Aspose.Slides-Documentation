## Aspose.Slides for JasperReports

{{% alert color="info" %}}

![Aspose.Slides for JasperReports उत्पाद लोगो](home_7.png)

Aspose.Slides for JasperReports एक लाइब्रेरी है जो विशेष रूप से उन डेवलपर्स के लिए तैयार की गई है जिन्हें अपने Java अनुप्रयोगों में JasperReports से रिपोर्ट्स को Microsoft PowerPoint Presentation (PPT) और Microsoft PowerPoint Show (PPS) स्वरूपों में आसानी से निर्यात करने की आवश्यकता होती है। सभी रिपोर्ट फीचर को अत्यधिक शुद्धता के साथ Microsoft PowerPoint प्रस्तुतियों में परिवर्तित किया जाता है। Aspose.Slides for JasperReports JasperReports 5+ का समर्थन करता है।
