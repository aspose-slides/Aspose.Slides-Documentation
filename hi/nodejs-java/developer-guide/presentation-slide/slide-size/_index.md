## **परिचय**

Aspose.Slides PowerPoint प्रस्तुतियों में स्लाइड आकार और अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शित करने दोनों के लिए अत्यंत महत्वपूर्ण हैं।

प्रसिद्ध स्लाइड आकार और अनुपात:
- **Standard (4:3 अनुपात)**: पुराने स्क्रीन और उपकरणों के लिए आदर्श।
- **Widescreen (16:9 अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

अपनी प्रस्तुति में निरंतरता सुनिश्चित करें क्योंकि सभी स्लाइडों पर एक ही स्लाइड आकार और अनुपात लागू होता है। सर्वोत्तम परिणाम के लिए, जटिलताओं से बचने हेतु अपनी प्रस्तुति निर्माण प्रक्रिया की शुरुआत में ही स्लाइड आयाम सेट करें।

{{% alert color="primary" %}} 
डिफ़ॉल्ट रूप में, Aspose.Slides के साथ बनाई गई प्रस्तुतियों में मानक 4:3 अनुपात उपयोग किया जाता है।
{{% /alert %}}

## **प्रस्तुति में स्लाइड आकार बदलना**

यह नमूना कोड आपको JavaScript में Aspose.Slides का उपयोग करके प्रस्तुति में स्लाइड आकार बदलने का तरीका दिखाता है:

```javascript
var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **प्रस्तुति में कस्टम स्लाइड आकार निर्दिष्ट करना**

यदि आपको सामान्य स्लाइड आकार (4:3 और 16:9) आपके कार्य के लिए उपयुक्त नहीं लगते हैं, तो आप एक विशिष्ट या अनूठा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रस्तुति को कस्टम पृष्ठ लेआउट पर पूर्ण आकार में प्रिंट करने की योजना बनाते हैं या यदि आप अपनी प्रस्तुति को कुछ प्रकार की स्क्रीन पर प्रदर्शित करने का इरादा रखते हैं, तो कस्टम आकार सेटिंग का उपयोग आपके लिए लाभदायक होगा।

यह नमूना कोड आपको JavaScript में प्रस्तुति के लिए कस्टम स्लाइड आकार निर्दिष्ट करने हेतु Java के माध्यम से Node.js के लिए Aspose.Slides का उपयोग कैसे करें, दिखाता है:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// A4 कागज़ आकार
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **प्रस्तुति में स्लाइड आकार बदलते समय समस्याओं से निपटना**

प्रस्तुति के स्लाइड आकार को बदलने के बाद, स्लाइडों की सामग्री (जैसे छवि या वस्तुएँ) विकृत हो सकती है। डिफ़ॉल्ट रूप में, वस्तुओं को नई स्लाइड आकार में फिट करने के लिए स्वतः आकार बदल दिया जाता है। हालांकि, जब आप प्रस्तुति का स्लाइड आकार बदलते हैं, तो आप एक सेटिंग निर्दिष्ट कर सकते हैं जो तय करती है कि Aspose.Slides स्लाइडों की सामग्री को कैसे संभालता है।

आपकी इच्छित कार्रवाई या लक्ष्य के आधार पर, आप इन सेटिंग्स में से कोई भी उपयोग कर सकते हैं:
- `DoNotScale`

  यदि आप स्लाइडों पर वस्तुओं को पुनः आकार देना नहीं चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार में स्केल करना चाहते हैं और आप चाहते हैं कि Aspose.Slides स्लाइडों की वस्तुओं को छोटा करके सभी को स्लाइडों पर फिट कर दे (इससे सामग्री का नुकसान नहीं होगा), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार में स्केल करना चाहते हैं और आप चाहते हैं कि Aspose.Slides स्लाइडों की वस्तुओं को बड़ा करके उन्हें नई स्लाइड आकार के अनुपात में ले आए, तो इस सेटिंग का उपयोग करें।

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे, पॉइंट्स या मिलिमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?**

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलिमीटर या सेंटीमीटर) को पॉइंट्स में परिवर्तित कर सकते हैं और परिवर्तित मानों का उपयोग स्लाइड की चौड़ाई और ऊँचाई निर्धारित करने के लिए कर सकते हैं।

**क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हां। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल के संयोजन से मेमोरी उपयोग बढ़ता है और प्रसंस्करण समय लंबा हो जाता है। व्यावहारिक स्लाइड आकार का लक्ष्य रखें और आवश्यकतानुसार आउटपुट गुणवत्ता प्राप्त करने हेतु रेंडरिंग स्केल को ही समायोजित करें।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकारों वाले प्रस्तुतियों की स्लाइडें मर्ज कर सकता हूँ?**

आप विभिन्न स्लाइड आकार वाली प्रस्तुतियों को [प्रस्तुति मिलाएँ](/slides/hi/nodejs-java/merge-presentation/) नहीं कर सकते — पहले, एक प्रस्तुति को दूसरे के आकार से मिलाने के लिए उसका आकार बदलें। स्लाइड आकार बदलते समय, आप मौजूदा सामग्री को कैसे संभालना है, यह [SlideSizeScaleType](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार संरेखित करने के बाद, आप फॉर्मेटिंग को संरक्षित रखते हुए स्लाइडें मर्ज कर सकते हैं।

**क्या मैं व्यक्तिगत आकारों या स्लाइड के विशिष्ट क्षेत्रों के लिए थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?**

हां। Aspose.Slides [पूरी स्लाइडें](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/slide/#getImage) तथा [चयनित आकार](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/shape/#getImage) के लिए थंबनेल रेंडर कर सकता है। परिणामी छवियां वर्तमान स्लाइड आकार और अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में निरंतरता सुनिश्चित होती है।
