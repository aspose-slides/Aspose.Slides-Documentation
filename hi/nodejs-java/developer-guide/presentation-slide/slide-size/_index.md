## **परिचय**

Aspose.Slides PowerPoint प्रस्तुतियों में स्लाइड आकार और पहलू अनुपात को समायोजित करने के लिए व्यापक उपकरण प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर प्रदर्शन दोनों के लिए महत्वपूर्ण हैं।

प्रसिद्ध स्लाइड आकार और अनुपात:

- **Standard (4:3 Aspect Ratio)**: पुराने स्क्रीन और डिवाइसों के लिए आदर्श।
- **Widescreen (16:9 Aspect Ratio)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए सिफारिश की जाती है।

अपनी प्रस्तुति में निरंतरता सुनिश्चित करें क्योंकि एक ही स्लाइड आकार और पहलू अनुपात सभी स्लाइडों पर लागू होता है। सर्वोत्तम परिणामों के लिए, जटिलताओं से बचने हेतु अपनी प्रस्तुति निर्माण प्रक्रिया की शुरुआत में ही स्लाइड आयाम निर्धारित करें।

{{% alert color="info" title="Note" %}}
डिफ़ॉल्ट रूप से, Aspose.Slides से बनाई गई प्रस्तुतियों में मानक 4:3 पहलू अनुपात उपयोग किया जाता है।
{{% /alert %}}

नोट्स और हैंडआउट पेजों के आयाम सामान्य स्लाइडों से अलग होते हैं। उनके आकार और अभिविन्यास को बदलने के लिए [नोट्स पेज आकार](/slides/hi/nodejs-java/notes-size/) देखें।

## **प्रेज़ेंटेशन में स्लाइड आकार बदलना**

यह नमूना कोड दिखाता है कि Aspose.Slides का उपयोग करके JavaScript में प्रस्तुति के स्लाइड आकार को कैसे बदलें:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **प्रेज़ेंटेशन में कस्टम स्लाइड आकार निर्दिष्ट करना**

यदि आप सामान्य स्लाइड आकार (4:3 और 16:9) को अपने कार्य के लिए असुविधाजनक पाते हैं, तो आप विशिष्ट या अनूठा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के तौर पर, यदि आप अपने प्रेज़ेंटेशन से पूर्ण आकार की स्लाइडें कस्टम पेज लेआउट पर प्रिंट करने या कुछ विशेष स्क्रीन प्रकारों पर प्रदर्शित करने की योजना बनाते हैं, तो कस्टम आकार सेटिंग का उपयोग करने से आपको लाभ मिल सकता है।

यह नमूना कोड दिखाता है कि JavaScript में प्रेज़ेंटेशन के लिए कस्टम स्लाइड आकार निर्दिष्ट करने हेतु Java के माध्यम से Node.js के लिए Aspose.Slides का कैसे उपयोग किया जाए:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// A4 कागज का आकार
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **प्रेज़ेंटेशन में स्लाइड आकार बदलते समय उत्पन्न समस्याओं से निपटना**

प्रेज़ेंटेशन के स्लाइड आकार को बदलने के बाद, स्लाइड की सामग्री (जैसे चित्र या ऑब्जेक्ट) विकृति का शिकार हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट नए स्लाइड आकार में फिट होने के लिए स्वतः पुन: आकारित हो जाते हैं। हालांकि, प्रेज़ेंटेशन के स्लाइड आकार को बदलते समय आप एक सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करती है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालेगा।

आपकी इच्छित कार्य या लक्ष्य के आधार पर, आप इन सेटिंग्स में से कोई भी उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर ऑब्जेक्ट को पुन: आकारित नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार के लिए स्केल करना चाहते हैं और आप चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट को नीचे स्केल करे ताकि सभी ऑब्जेक्ट स्लाइड पर फिट हो जाएँ (इस प्रकार आप कंटेंट खोने से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार के लिए स्केल करना चाहते हैं और आप चाहते हैं कि Aspose.Slides स्लाइड के ऑब्जेक्ट को बड़ा करके नए स्लाइड आकार के अनुपात में बना दे, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड दिखाता है कि प्रेज़ेंटेशन की स्लाइड आकार बदलते समय `Maximize` सेटिंग का कैसे उपयोग किया जाए:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट्स या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?**

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट्स में परिवर्तित कर सकते हैं और रूपांतरित मानों का उपयोग करके स्लाइड की चौड़ाई और ऊँचाई निर्धारित कर सकते हैं।

**क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हां। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी उपयोग में वृद्धि और प्रोसेसिंग समय को लंबा कर देते हैं। एक व्यावहारिक स्लाइड आकार लक्ष्य रखें और आवश्यकतानुसार रेंडरिंग स्केल को समायोजित करें ताकि वांछित आउटपुट गुणवत्ता प्राप्त हो सके।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकार वाली प्रस्तुतियों की स्लाइड्स को मर्ज कर सकता हूँ?**

आप विभिन्न स्लाइड आकार रखने वाली प्रस्तुतियों को [प्रेज़ेंटेशन मर्ज करें](/slides/hi/nodejs-java/merge-presentation/) नहीं कर सकते — पहले, एक प्रेज़ेंटेशन को दूसरे के आकार के अनुसार पुनः आकार दें। स्लाइड आकार बदलते समय, आप [SlideSizeScaleType](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/slidesizescaletype/) विकल्प के माध्यम से मौजूदा सामग्री के संभालने का तरीका चुन सकते हैं। आकारों को समान करने के बाद, आप फ़ॉर्मेटिंग को बरकरार रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

**क्या मैं स्लाइड के व्यक्तिगत शैप्स या विशिष्ट क्षेत्रों के लिए थंबनेल जनरेट कर सकता हूँ, और क्या वे नए स्लाइड आकार का पालन करेंगे?**

हां। Aspose.Slides [सभी स्लाइड्स](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/slide/#getImage) तथा [चुनी हुई आकृतियाँ](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/shape/#getImage) के थंबनेल रेंडर कर सकता है। परिणामी छवियां वर्तमान स्लाइड आकार और पहलू अनुपात को दर्शाती हैं, जिससे सतत फ्रेमिंग और ज्यामिति सुनिश्चित होती है।
