## **परिचय**

जब आप एक प्रस्तुति को पासवर्ड से सुरक्षित करते हैं, तो आप एक पासवर्ड सेट कर रहे होते हैं जो प्रस्तुति पर कुछ प्रतिबंध लागू करता है। प्रतिबंध हटाने के लिए पासवर्ड दर्ज करना आवश्यक है। पासवर्ड‑सुरक्षित प्रस्तुति को लॉक्ड प्रस्तुति माना जाता है।

आमतौर पर, आप एक प्रस्तुति पर इन प्रतिबंधों को लागू करने के लिए पासवर्ड सेट कर सकते हैं:

- **Modification**

  यदि आप केवल कुछ उपयोगकर्ताओं को अपनी प्रस्तुति को संशोधित करने की अनुमति देना चाहते हैं, तो आप संशोधन प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध उपयोगकर्ताओं को आपकी प्रस्तुति में चीज़ों को संशोधित, बदल या कॉपी करने से रोकता है (जब तक वे पासवर्ड प्रदान नहीं करते)।

  हालांकि, इस स्थिति में पासवर्ड के बिना भी उपयोगकर्ता आपके दस्तावेज़ को एक्सेस कर पाएगा और इसे खोल सकेगा। इस केवल‑पढ़ने मोड में, उपयोगकर्ता आपकी प्रस्तुति के भीतर मौजूद हाइपरलिंक्स, एनीमेशन, इफ़ेक्ट और अन्य सामग्री देख सकता है, लेकिन वह वस्तुओं को कॉपी या प्रस्तुति को सहेज नहीं सकता।

- **Opening**

  यदि आप केवल कुछ उपयोगकर्ताओं को अपनी प्रस्तुति खोलने की अनुमति देना चाहते हैं, तो आप खोलने का प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध उपयोगकर्ताओं को आपकी प्रस्तुति की सामग्री देखने से रोकता है (जब तक वे पासवर्ड प्रदान नहीं करते)।

  तकनीकी रूप से, खोलने का प्रतिबंध उपयोगकर्ताओं को आपके प्रस्तुतियों को संशोधित करने से भी रोकता है: जब लोग प्रस्तुति नहीं खोल सकते, तो वे उसे संशोधित या बदलाव नहीं कर सकते।

  **Note** कि जब आप एक प्रस्तुति को खोलने से रोकने के लिए पासवर्ड से सुरक्षित करते हैं, तो प्रस्तुति फ़ाइल एन्क्रिप्ट हो जाती है।

## **Aspose.Slides में प्रस्तुतियों के लिए पासवर्ड सुरक्षा**
**Supported formats**

Aspose.Slides इन फ़ॉर्मैट की प्रस्तुतियों के लिए पासवर्ड सुरक्षा, एन्क्रिप्शन और समान कार्यों का समर्थन करता है:

- PPTX और PPT - Microsoft PowerPoint Presentation  
- ODP - OpenDocument Presentation  
- OTP - OpenDocument Presentation Template  

**Supported operations**

Aspose.Slides आपको इन तरीकों से प्रस्तुतियों पर पासवर्ड सुरक्षा का उपयोग करके संशोधन को रोकने की अनुमति देता है:

- प्रस्तुति को एन्क्रिप्ट करना  
- प्रस्तुति पर राइट प्रोटेक्शन सेट करना  

**Other operations**

Aspose.Slides आपको इन तरीकों से पासवर्ड सुरक्षा और एन्क्रिप्शन से संबंधित अन्य कार्य करने देता है:

- प्रस्तुति को डिक्रिप्ट करना; एन्क्रिप्टेड प्रस्तुति को खोलना  
- एन्क्रिप्शन हटाना; पासवर्ड सुरक्षा अक्षम करना  
- प्रस्तुति से राइट प्रोटेक्शन हटाना  
- एन्क्रिप्टेड प्रस्तुति के गुण प्राप्त करना  
- जाँचना कि प्रस्तुति एन्क्रिप्टेड है या नहीं  
- जाँचना कि प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं।

## **प्रेज़ेंटेशन को एन्क्रिप्ट करना**

आप पासवर्ड सेट करके एक प्रस्तुति को एन्क्रिप्ट कर सकते हैं। फिर, लॉक्ड प्रस्तुति को संशोधित करने के लिए उपयोगकर्ता को पासवर्ड प्रदान करना होगा।

प्रेज़ेंटेशन को एन्क्रिप्ट या पासवर्ड‑सुरक्षित करने के लिए आपको [ProtectionManager](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager) की encrypt मेथड का उपयोग करना होगा। आप पासवर्ड को encrypt मेथड में पास करते हैं और अब एन्क्रिप्टेड प्रस्तुति को सहेजने के लिए save मेथड का प्रयोग करते हैं।

यह नमूना कोड दिखाता है कि प्रस्तुति को कैसे एन्क्रिप्ट किया जाता है:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().encrypt("123123");
    presentation.save("encrypted-pres.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **प्रेज़ेंटेशन पर राइट प्रोटेक्शन सेट करना**

आप एक प्रस्तुति में “Do not modify” का चिह्न जोड़ सकते हैं। इस तरह, आप उपयोगकर्ताओं को बता सकते हैं कि आप उन्हें प्रस्तुति में परिवर्तन करने से रोकना चाहते हैं।

**Note** कि राइट प्रोटेक्शन प्रक्रिया प्रस्तुति को एन्क्रिप्ट नहीं करती। इसलिए, उपयोगकर्ता—यदि वे वास्तव में चाहते हैं—प्रेज़ेंटेशन को संशोधित कर सकते हैं, लेकिन बदलावों को सहेजने के लिए उन्हें एक अलग नाम के साथ नई प्रस्तुति बनानी होगी।

राइट प्रोटेक्शन सेट करने के लिए आपको [setWriteProtection](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager#setWriteProtection-java.lang.String-) मेथड का उपयोग करना होगा। यह नमूना कोड दिखाता है कि प्रस्तुति पर राइट प्रोटेक्शन कैसे सेट किया जाता है:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().setWriteProtection("123123");
    presentation.save("write-protected-pres.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **प्रेज़ेंटेशन को डिक्रिप्ट करना; एन्क्रिप्टेड प्रेज़ेंटेशन खोलना**

Aspose.Slides आपको पासवर्ड पास करके एन्क्रिप्टेड फ़ाइल लोड करने की अनुमति देता है। प्रस्तुति को डिक्रिप्ट करने के लिए आपको कोई पैरामीटर न लेकर [removeEncryption](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager#removeEncryption--) मेथड को कॉल करना होगा। फिर आपको सही पासवर्ड दर्ज करना होगा ताकि प्रस्तुति लोड हो सके।

यह नमूना कोड दिखाता है कि प्रस्तुति को कैसे डिक्रिप्ट किया जाता है:

```javascript
var loadOptions = new aspose.slides.LoadOptions();
loadOptions.setPassword("123123");
var presentation = new aspose.slides.Presentation("pres.pptx", loadOptions);
try {
    // डिक्रिप्टेड प्रस्तुति के साथ कार्य करें
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **एन्क्रिप्शन हटाना; पासवर्ड सुरक्षा अक्षम करना**

आप प्रस्तुति से एन्क्रिप्शन या पासवर्ड सुरक्षा को हटा सकते हैं। इस तरह, उपयोगकर्ता बिना किसी प्रतिबंध के प्रस्तुति को एक्सेस या संशोधित कर सकते हैं।

एन्क्रिप्शन या पासवर्ड सुरक्षा हटाने के लिए आपको [removeEncryption](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager#removeEncryption--) मेथड को कॉल करना होगा। यह नमूना कोड दिखाता है कि प्रस्तुति से एन्क्रिप्शन कैसे हटाया जाता है:

```javascript
var loadOptions = new aspose.slides.LoadOptions();
loadOptions.setPassword("123123");
var presentation = new aspose.slides.Presentation("pres.pptx", loadOptions);
try {
    presentation.getProtectionManager().removeEncryption();
    presentation.save("encryption-removed.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **प्रेज़ेंटेशन से राइट प्रोटेक्शन हटाना**

आप Aspose.Slides का उपयोग करके प्रस्तुति फ़ाइल पर लगाए गए राइट प्रोटेक्शन को हटा सकते हैं। इस तरह, उपयोगकर्ता अपनी इच्छा के अनुसार संशोधित कर सकते हैं—और उन्हें ऐसे कार्य करते समय कोई चेतावनी नहीं मिलेगी।

आप [removeWriteProtection](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager#removeWriteProtection--) मेथड का उपयोग करके प्रस्तुति से राइट प्रोटेक्शन हटा सकते हैं। यह नमूना कोड दिखाता है कि राइट प्रोटेक्शन को कैसे हटाया जाता है:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().removeWriteProtection();
    presentation.save("write-protection-removed.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **एन्क्रिप्टेड प्रस्तुति के गुण प्राप्त करना**

आमतौर पर, उपयोगकर्ता एन्क्रिप्टेड या पासवर्ड‑सुरक्षित प्रस्तुति के दस्तावेज़ गुणों को प्राप्त करने में कठिनाई महसूस करते हैं। हालांकि, Aspose.Slides एक तंत्र प्रदान करता है जो आपको प्रस्तुति को पासवर्ड‑सुरक्षित रखते हुए भी उपयोगकर्ताओं को उसके गुणों तक पहुंचने की अनुमति देता है।

**Note:** डिफ़ॉल्ट रूप से, जब Aspose.Slides एक प्रस्तुति को एन्क्रिप्ट करता है, तो प्रस्तुति के दस्तावेज़ गुण भी पासवर्ड‑सुरक्षित होते हैं। यदि आप एन्क्रिप्शन के बाद भी दस्तावेज़ गुणों को सुलभ बनाना चाहते हैं, तो Aspose.Slides आपको यही करने की अनुमति देता है।

यदि आप चाहते हैं कि उपयोगकर्ता एन्क्रिप्टेड प्रस्तुति के गुणों तक पहुंच बना रखें, तो [ProtectionManager](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/protectionmanager/) पर `setEncryptDocumentProperties` को `false` पास करें। यह नमूना कोड दिखाता है कि प्रस्तुति को एन्क्रिप्ट करते समय कैसे उपयोगकर्ताओं को उसके दस्तावेज़ गुणों तक पहुंच प्रदान की जा सकती है:

```javascript
const presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().setEncryptDocumentProperties(false);
    presentation.getProtectionManager().encrypt("123123");
    presentation.save("encrypted-pres.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **एन्क्रिप्टेड प्रस्तुति से केवल दस्तावेज़ गुण लोड करना**

एन्क्रिप्टेड प्रस्तुति के मेटाडेटा को स्लाइड्स या अन्य सामग्री लोड किए बिना जांचने के लिए, एक [LoadOptions](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/loadoptions/) ऑब्जेक्ट बनाएं और `setOnlyLoadDocumentProperties` को `true` पास करें। इस मोड में, Aspose.Slides पासवर्ड को अनदेखा करता है और केवल सार्वजनिक रूप से सुलभ दस्तावेज़ गुणों को लोड करता है।

निम्नलिखित कोड उदाहरण `Presentation` पर `getDocumentProperties` के माध्यम से बिल्ट‑इन और कस्टम दस्तावेज़ गुणों को पढ़ता है:

```javascript
const loadOptions = new aspose.slides.LoadOptions();
loadOptions.setOnlyLoadDocumentProperties(true);

const presentation = new aspose.slides.Presentation("encrypted-pres.pptx", loadOptions);
try {
    const documentProperties = presentation.getDocumentProperties();

    // बिल्ट‑इन दस्तावेज़ गुण पढ़ें।
    console.log("Title: " + documentProperties.getTitle());
    console.log("Author: " + documentProperties.getAuthor());

    // कस्टम दस्तावेज़ गुण पढ़ें।
    const customPropertyCount = documentProperties.getCountOfCustomProperties();

    for (let propertyIndex = 0; propertyIndex < customPropertyCount; propertyIndex++) {
        const propertyName = documentProperties.getCustomPropertyName(propertyIndex);
        const propertyValue = documentProperties.get_Item(propertyName);

        console.log(propertyName + ": " + propertyValue);
    }
} finally {
    presentation.dispose();
}
```

यह वर्कफ़्लो तभी काम करता है जब दस्तावेज़ गुण एन्क्रिप्ट हुए नहीं (सार्वजनिक) होते हैं। यदि दस्तावेज़ गुण एन्क्रिप्टेड हों, तो `LoadOptions.setOnlyLoadDocumentProperties` को `true` पास करने से अपवाद उत्पन्न होगा क्योंकि इस मोड में पासवर्ड अनदेखा किया जाता है। एन्क्रिप्टेड दस्तावेज़ गुणों तक पहुंच या पूरी प्रस्तुति (स्लाइड्स सहित) लोड करने के लिए, सही पासवर्ड `LoadOptions.setPassword` के माध्यम से प्रदान करें।

## **लोड करने से पहले यह जांचना कि प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं**

एक प्रस्तुति लोड करने से पहले आप यह जांचना चाह सकते हैं कि वह पासवर्ड से सुरक्षित है या नहीं। इस तरह, आप उन त्रुटियों और समान समस्याओं से बच सकते हैं जो पासवर्ड‑सुरक्षित प्रस्तुति को बिना पासवर्ड लोड करने पर उत्पन्न होती हैं।

यह JavaScript कोड दिखाता है कि प्रस्तुति को लोड किए बिना यह कैसे जांचा जाए कि वह पासवर्ड‑सुरक्षित है या नहीं:

```javascript
var presentationInfo = aspose.slides.PresentationFactory.getInstance().getPresentationInfo("example.pptx");
console.log("The presentation is password protected: " + presentationInfo.isPasswordProtected());
```

## **जांचना कि प्रस्तुति एन्क्रिप्टेड है या नहीं**

Aspose.Slides आपको यह जांचने की अनुमति देता है कि कोई प्रस्तुति एन्क्रिप्टेड है या नहीं। इस कार्य के लिए आप [isEncrypted](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager#isEncrypted--) प्रॉपर्टी का उपयोग कर सकते हैं, जो प्रस्तुति एन्क्रिप्टेड होने पर `true` और न होने पर `false` लौटाती है।

यह नमूना कोड दिखाता है कि प्रस्तुति एन्क्रिप्टेड है या नहीं, इसे कैसे जांचा जाए:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    var isEncrypted = presentation.getProtectionManager().isEncrypted();
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **जांचना कि प्रस्तुति राइट‑प्रोटेक्टेड है या नहीं**

Aspose.Slides आपको यह जांचने की अनुमति देता है कि कोई प्रस्तुति राइट‑प्रोटेक्टेड है या नहीं। इस कार्य के लिए आप [isWriteProtected](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/ProtectionManager#isWriteProtected--) प्रॉपर्टी का उपयोग कर सकते हैं, जो प्रस्तुति एन्क्रिप्टेड होने पर `true` और न होने पर `false` लौटाती है।

यह नमूना कोड दिखाता है कि प्रस्तुति राइट‑प्रोटेक्टेड है या नहीं, इसे कैसे जांचा जाए:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    var isEncrypted = presentation.getProtectionManager().isWriteProtected();
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **किसी विशिष्ट पासवर्ड के उपयोग की पुष्टि या वैधता जांचना**

आप यह जांचना और पुष्टि करना चाह सकते हैं कि कोई विशिष्ट पासवर्ड प्रस्तुति दस्तावेज़ को सुरक्षित करने के लिए उपयोग किया गया है या नहीं। Aspose.Slides आपको पासवर्ड वैधता जांचने का साधन प्रदान करता है।

यह नमूना कोड दिखाता है कि पासवर्ड को कैसे वैध किया जाए:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    // जाँचें कि "pass" मेल खा रहा है या नहीं
    var isWriteProtected = presentation.getProtectionManager().checkWriteProtection("my_password");
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

यदि प्रस्तुति निर्दिष्ट पासवर्ड से एन्क्रिप्टेड है तो यह `true` लौटाता है। अन्यथा यह `false` लौटाता है।

## **अक्सर पूछे जाने वाले प्रश्न**

**Aspose.Slides द्वारा समर्थित एन्क्रिप्शन विधियां कौन‑सी हैं?**

Aspose.Slides आधुनिक एन्क्रिप्शन विधियों, जिसमें AES‑आधारित एल्गोरिदम शामिल हैं, का समर्थन करता है, जिससे आपके प्रस्तुतियों के डेटा की उच्च स्तर की सुरक्षा सुनिश्चित होती है।

**अगर प्रस्तुति खोलने की कोशिश में गलत पासवर्ड दर्ज किया जाए तो क्या होता है?**

गलत पासवर्ड उपयोग करने पर एक अपवाद फेंका जाता है, जो यह सूचित करता है कि प्रस्तुति तक पहुंच अस्वीकार की गई है। इससे अनधिकृत पहुंच को रोका जाता है और प्रस्तुति की सामग्री सुरक्षित रहती है।

**क्या पासवर्ड‑सुरक्षित प्रस्तुतियों के साथ काम करने से प्रदर्शन पर कोई असर पड़ता है?**

एन्क्रिप्शन और डिक्रिप्शन प्रक्रिया खोलने और सहेजने के दौरान थोड़ा ओवरहेड जोड़ सकती है। अधिकांश मामलों में, यह प्रदर्शन प्रभाव न्यूनतम होता है और आपके प्रस्तुति कार्यों के कुल प्रोसेसिंग समय को महत्वपूर्ण रूप से प्रभावित नहीं करता।
