## **परिचय**

कभी-कभी, सर्वोत्तम मूल्यांकन परिणामों के लिए, व्यावहारिक दृष्टिकोण की आवश्यकता हो सकती है। इस कारण, Aspose.Slides विभिन्न खरीद योजनाएँ प्रदान करता है और मूल्यांकन के लिए एक फ्री ट्रायल और 30‑दिन का टेम्पररी लाइसेंस भी उपलब्ध कराता है।

## **Aspose.Slides का मूल्यांकन करें**

आप आसानी से Aspose.Slides को मूल्यांकन के लिए डाउनलोड कर सकते हैं। मूल्यांकन पैकेज खरीदे गए पैकेज के समान है। लाइसेंस लागू करने के लिए कुछ पंक्तियों का कोड जोड़ते ही मूल्यांकन संस्करण लाइसेंस प्राप्त हो जाता है।

## **मूल्यांकन संस्करण की सीमाएँ**

मूल्यांकन संस्करण (बिना निर्दिष्ट लाइसेंस के) पूर्ण उत्पाद कार्यक्षमता प्रदान करता है, लेकिन दो सीमाएँ हैं:

* यह सहेजी गई प्रत्येक प्रस्तुति की हर स्लाइड पर एक मूल्यांकन वॉटरमार्क टेक्स्ट बॉक्स जोड़ता है।
* पाँच अक्षरों से लंबा वह टेक्स्ट जो आपका कोड प्रस्तुति से पढ़ता है, पहले पाँच अक्षरों तक काट दिया जाता है, जिसके बाद `... text has been truncated due to evaluation version limitation.` जुड़ता है। पाँच या कम अक्षरों वाला टेक्स्ट बिना बदले वापस मिलता है, और आपका कोड जो टेक्स्ट लिखता है वह पूरी तरह से सहेजा जाता है।

{{% alert color="info" title="Note" %}}
यदि आप मूल्यांकन संस्करण की सीमाओं के बिना Aspose.Slides का परीक्षण करना चाहते हैं, तो आप **30 Day Temporary License** का अनुरोध कर सकते हैं। अधिक जानकारी के लिए कृपया [टेम्पररी लाइसेंस कैसे प्राप्त करें?](https://purchase.aspose.com/temporary-license) देखें।
{{% /alert %}}

## **लाइसेंस के बारे में**

आप आसानी से Aspose.Slides for Node.js via Java का मूल्यांकन संस्करण उसका [download page](https://releases.aspose.com/slides/nodejs-java/) से डाउनलोड कर सकते हैं। मूल्यांकन संस्करण में वही फीचर होते हैं जो लाइसेंस प्राप्त संस्करण में होते हैं, साथ ही ऊपर वर्णित सीमाएँ भी लागू होती हैं। इसके अतिरिक्त, लाइसेंस खरीदने और कुछ पंक्तियों का कोड जोड़ने पर मूल्यांकन संस्करण स्वयं लाइसेंस प्राप्त हो जाता है।

लाइसेंस एक सामान्य‑पाठ XML फ़ाइल है जिसमें उत्पाद नाम, लाइसेंस प्राप्त डेवलपर्स की संख्या, सदस्यता समाप्ति तिथि आदि विवरण होते हैं। फ़ाइल डिजिटल रूप से साइन की गई है, इसलिए उसे संशोधित न करें। फ़ाइल की सामग्री में एक अतिरिक्त लाइन‑ब्रेक भी जोड़ने से वह अमान्य हो जाएगा।

मूल्यांकन संस्करण की सीमाओं से बचने के लिए, आपको **Aspose.Slides** उपयोग करने से पहले लाइसेंस सेट करना आवश्यक है। आपको प्रत्येक एप्लीकेशन या प्रक्रिया में केवल एक बार लाइसेंस सेट करना होता है।

{{% alert color="info" title="Note" %}}
आप [Metered Licensing](/slides/hi/nodejs-java/metered-licensing/) देखना चाह सकते हैं।
{{% /alert %}}

### **Node.js के लिए Aspose.Slides में लाइसेंस सेट करना (Java के माध्यम से)**

लाइसेंस निम्नलिखित स्थानों से लागू किए जा सकते हैं:

* Explicit path
* Stream
* As a Metered License – a new licensing mechanism

{{% alert color="info" title="Note" %}}
**setLicense** मेथड का उपयोग करके किसी कॉम्पोनेन्ट को लाइसेंस किया जाता है।

जबकि कई बार **setLicense** कॉल करने से नुकसान नहीं होता, यह संसाधनों (प्रोसेसर) की बर्बादी है।
{{% /alert %}}

#### **फ़ाइल का उपयोग करके लाइसेंस लागू करना**

यह कोड स्निपेट लाइसेंस फ़ाइल सेट करने के लिए उपयोग किया जाता है:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");

const license = new asposeSlides.License();
license.setLicense("Aspose.Slides.lic");
console.log("The license was applied.");

// Aspose.Slides एक Java वर्चुअल मशीन में चलता है जो Node.js को चलाता रहता है, इसलिए प्रक्रिया को स्पष्ट रूप से समाप्त करें।
process.exit(0);
```

जब आप setLicense मेथड को कॉल करते हैं, तो लाइसेंस नाम आपके लाइसेंस फ़ाइल के नाम के समान होना चाहिए। उदाहरण के लिए, आप लाइसेंस फ़ाइल का नाम "Aspose.Slides.lic.xml" बदल सकते हैं। फिर कोड में आपको नया लाइसेंस नाम (Aspose.Slides.lic.xml) setLicense मेथड में पास करना होगा। यदि फ़ाइल अनुपलब्ध है या वैध लाइसेंस नहीं रखती, तो [setLicense](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) एक अपवाद फेंकता है, जिससे स्क्रिप्ट त्रुटि के साथ समाप्त हो जाती है।

#### **स्ट्रीम से लाइसेंस लागू करना**

स्ट्रीम से लाइसेंस लागू करने के लिए, [License](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/) ऑब्जेक्ट और एक रीडेबल स्ट्रीम को स्थिर [setLicenseFromStream](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) मेथड में पास करें। स्ट्रीम असिंक्रोनस रूप से पढ़ी जाती है, और यदि स्ट्रीम में वैध लाइसेंस नहीं है तो कॉलबैक को एक त्रुटि प्राप्त होती है:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");
const fs = require("fs");

const license = new asposeSlides.License();
const readStream = fs.createReadStream("Aspose.Slides.lic");
asposeSlides.License.setLicenseFromStream(license, readStream, function (error) {
    if (error) {
        console.error("The license was not applied:", error.message);
    } else {
        console.log("The license was applied.");
    }

    // Aspose.Slides एक Java वर्चुअल मशीन में चलता है जो Node.js को चलाता रहता है, इसलिए प्रक्रिया को स्पष्ट रूप से समाप्त करें।
    process.exit(0);
});
```

लाइसेंस तब लागू हो जाता है जब पूरी स्ट्रीम पढ़ ली जाती है, कॉलबैक चलने से ठीक पहले, इसलिए कॉलबैक से ही अन्य Aspose.Slides कार्य शुरू करें।

दोनों नमूने समाप्त होने पर `process.exit(0)` कॉल करते हैं, क्योंकि Aspose.Slides चलाने वाला जावा वर्चुअल मशीन Node.js को चलता रखता है। एप्लीकेशन में प्रक्रिया समाप्त करने के बजाय अपने Aspose.Slides कोड को जारी रखें।

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मैं पूरी तरह ऑफ़लाइन माहौल (कोई इंटरनेट ऐक्सेस नहीं) में लाइसेंस लागू कर सकता हूँ?

हां। लाइसेंस वैधता लाइसेंस फ़ाइल का उपयोग करके स्थानीय तौर पर की जाती है; इंटरनेट कनेक्शन की आवश्यकता नहीं है।

### एक साल की सदस्यता समाप्त होने के बाद क्या होता है? क्या लाइब्रेरी काम करना बंद कर देगी?

नहीं। लाइसेंस स्थायी है: आप अपनी सदस्यता समाप्ति तिथि से पहले जारी किए गए संस्करणों का उपयोग जारी रख सकते हैं; बस बिना नवीनीकरण के नए रिलीज़ का उपयोग नहीं कर पाएंगे।
