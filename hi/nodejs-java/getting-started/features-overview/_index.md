## **समर्थित प्लेटफ़ॉर्म**
Aspose.Slides for Node.js via Java एक प्लेटफ़ॉर्म स्वतंत्र API है। इसे किसी भी प्लेटफ़ॉर्म (Windows, Linux, macOS आदि) पर उपयोग किया जा सकता है जहाँ Node.js 7 या उसके बाद का संस्करण स्थापित हो। Oracle JDK 8 या उसके बाद का संस्करण भी आवश्यक है।

|**फ़ीचर**|**विवरण**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java इस प्रस्तुति दस्तावेज़ स्वरूप के लिए सबसे तेज़ प्रसंस्करण प्रदान करता है।|
|PPT से PPTX रूपांतरण|Aspose.Slides for Node.js via Java PPT से PPTX रूपांतरण का समर्थन करता है|

## **FAQ**

### क्या लाइब्रेरी को काम करने के लिए सर्वर/PC पर Microsoft PowerPoint स्थापित करना आवश्यक है?

नहीं। PowerPoint आवश्यक नहीं है; Aspose.Slides एक स्वतंत्र इंजन है जो प्रस्तुतियों को बनाने, संपादित करने, रूपांतरित करने और रेंडर करने के लिए प्रयुक्त होता है।

### मल्टीथ्रेडिंग कैसे काम करती है? क्या प्रोसेसिंग को समानांतर किया जा सकता है?

विभिन्न थ्रेड्स में विभिन्न दस्तावेज़ों को प्रोसेस करना सुरक्षित है; वही [presentation](https://reference.aspose.com/slides/hi/nodejs-java/aspose.slides/presentation/) ऑब्जेक्ट [multiple threads](/slides/hi/nodejs-java/multithreading/) द्वारा एक साथ उपयोग नहीं किया जाना चाहिए।

### क्या फ़ाइल पासवर्ड और एन्क्रिप्शन समर्थित हैं?

हाँ। आप एन्क्रिप्टेड प्रस्तुतियों को खोल सकते हैं, खोलने और लिखने का पासवर्ड सेट या हटाया जा सकता है, और सुरक्षा स्थिति की जाँच कर सकते हैं। ([You can](/slides/hi/nodejs-java/password-protected-presentation/))

### क्या Linux कंटेनरों में फ़ॉन्ट पैकेजों की देखभाल करनी चाहिए?

हाँ। सामान्य फ़ॉन्ट पैकेज स्थापित करने या अपने अनुप्रयोग में स्पष्ट रूप से [specify font directories](/slides/hi/nodejs-java/custom-font/) करने की सिफ़ारिश की जाती है ताकि अप्रत्याशित प्रतिस्थापन न हों।

### क्या मूल्यांकन संस्करण में सीमाएँ हैं?

[in evaluation mode](/slides/hi/nodejs-java/licensing/), आउटपुट में वाटरमार्क जोड़ा जाता है और कुछ सीमाएँ लागू होती हैं; पूर्ण‑फ़ीचर परीक्षण के लिए एक [30‑day temporary license](https://purchase.aspose.com/temporary-license/) उपलब्ध है।

### क्या प्रस्तुति में बाहरी स्वरूपों (PDF/HTML → PPTX) का आयात समर्थित है?

हाँ। आप [PDF pages and HTML content](/slides/hi/nodejs-java/import-presentation/) को प्रस्तुति में जोड़ सकते हैं, जो उन्हें स्लाइड्स में बदल देता है।
