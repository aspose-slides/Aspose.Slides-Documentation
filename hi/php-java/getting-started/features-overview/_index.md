## **समर्थित प्लेटफ़ॉर्म**
Aspose.Slides for PHP via Java एक प्लेटफ़ॉर्म स्वतंत्र API है। इसे किसी भी प्लेटफ़ॉर्म (Windows, Linux, MacOS, आदि) पर उपयोग किया जा सकता है जहाँ PHP 7 या उससे उच्च संस्करण स्थापित हो। Oracle JDK 7 या उससे उच्च संस्करण भी एक आवश्यकता है।

## **फ़ाइल प्रारूप और रूपांतरण**
Aspose.Slides for PHP via Java अधिकांश PowerPoint दस्तावेज़ प्रारूपों को सपोर्ट करता है। यह आपको इन्हें उन लोकप्रिय फ़ाइल प्रारूपों में निर्यात करने की भी सुविधा देता है जो संगठनों द्वारा उपयोग और साझा किए जाते हैं। नीचे विवरण देखें:

|**विशेषता**|**विवरण**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java इस प्रस्तुति दस्तावेज़ प्रारूप के लिए तेज़तम प्रसंस्करण प्रदान करता है।|
|PPT to PPTX conversion|Aspose.Slides for PHP via Java PPT से PPTX रूपांतरण का समर्थन करता है।|
|Portable Document Format (PDF)|आप एक ही मेथड से सभी समर्थित फ़ाइल प्रारूपों को Adobe Portable Document Format (PDF) दस्तावेज़ों में निर्यात कर सकते हैं।|
|XML Parser Specification (XPS)|आप एक ही मेथड से सभी समर्थित फ़ाइल प्रारूपों को XML Parser Specification (XPS) दस्तावेज़ों में निर्यात कर सकते हैं।|
|Tagged Image File Format (TIFF)|आप सभी समर्थित प्रस्तुति फ़ाइल प्रारूपों को Tagged Image File Format (TIFF) में निर्यात कर सकते हैं।|
|PPTX To HTML Conversion|Aspose.Slides for PHP via Java PresentationEx को HTML प्रारूप में रूपांतरित करने का समर्थन करता है।|

## **प्रेज़ेंटेशन रेंडरिंग**
Aspose.Slides for PHP via Java प्रस्तुति स्लाइडों को विभिन्न ग्राफ़िक प्रारूपों में उच्च फ़िडेलिटी रेंडरिंग प्रदान करता है। नीचे विवरण देखें:

|**विशेषता**|**विवरण**|
| :- | :- |
|Java Supported Image Formats|Aspose.Slides for PHP via Java का उपयोग करके आप प्रस्तुति स्लाइडों और स्लाइडों पर मौजूद चित्रों को सभी Java‑समर्थित ग्राफ़िक फ़ॉर्मेट जैसे TIFF, PNG, BMP, JPEG, GIF में रेंडर कर सकते हैं।|
|SVG Format|Aspose.Slides for PHP via Java अंतर्निर्मित मेथड प्रदान करता है जो आपको प्रस्तुति स्लाइडों को Scalable Vector Graphics (SVG) प्रारूप में निर्यात करने की अनुमति देता है।|

|Cloning / Copying Slides|Aspose.Slides for PHP via Java द्वारा प्रदान किए गए अंतर्निर्मित मेथड आपको प्रस्तुति के भीतर मौजूदा स्लाइडों को क्लोन या कॉपी करने की अनुमति देते हैं। आप एक प्रस्तुति से दूसरी प्रस्तुति में कॉपी की गई और क्लोन की गई स्लाइडें उपयोग कर सकते हैं। चूँकि स्लाइड अपना लेआउट मास्टर स्लाइड से विरासत में प्राप्त करती है, क्लोनिंग मेथड स्वचालित रूप से क्लोन पर मास्टर की प्रतिलिपि बनाते हैं।|

|Text Formatting|<p>Aspose.Slides for PHP via Java में आप आकारों से जुड़े टेक्स्ट फ़्रेम के माध्यम से टेक्स्ट को प्रबंधित कर सकते हैं। इस प्रकार आप टेक्स्ट फ़्रेम से जुड़े पैराग्राफ़ और भागों (portions) का उपयोग करके टेक्स्ट को फ़ॉर्मेट कर सकते हैं। ये टेक्स्ट तत्व Aspose.Slides for PHP via Java द्वारा फॉर्मेट किए जा सकते हैं।</p><p>- फ़ॉन्ट प्रकार</p><p>- फ़ॉन्ट आकार</p><p>- फ़ॉन्ट रंग</p><p>- फ़ॉन्ट शेड्स</p><p>- पैराग्राफ़ संरेखण</p><p>- पैराग्राफ़ बुलेटिंग</p><p>- पैराग्राफ़ अभिविन्यास</p>|

## **अक्सर पूछे जाने वाले प्रश्न**

### क्या मुझे लाइब्रेरी के काम करने के लिए सर्वर/पीसी पर Microsoft PowerPoint स्थापित करने की आवश्यकता है?
नहीं। PowerPoint आवश्यक नहीं है; Aspose.Slides एक स्वतंत्र इंजन है जो प्रस्तुतियों को बनाने, संपादित करने, रूपांतरण करने और रेंडर करने के लिए प्रयोग किया जाता है।

### मल्टीथ्रेडिंग कैसे काम करता है? क्या प्रोसेसिंग को समानांतर किया जा सकता है?
विभिन्न थ्रेड्स में विभिन्न दस्तावेज़ों को प्रोसेस करना सुरक्षित है; वही [presentation] (https://reference.aspose.com/slides/hi/php-java/aspose.slides/presentation/) ऑब्जेक्ट को [multiple threads](/slides/hi/php-java/multithreading/) द्वारा एक ही समय में उपयोग नहीं किया जाना चाहिए।

### क्या फ़ाइल पासवर्ड और एन्क्रिप्शन समर्थित हैं?
हां। आप एन्क्रिप्टेड प्रस्तुतियों को खोल सकते हैं, खोलने और लिखने के पासवर्ड को सेट या हटाएँ, और संरक्षण स्थिति की जाँच कर सकते हैं। देखें: [आप कर सकते हैं](/slides/hi/php-java/password-protected-presentation/)।

### क्या मुझे Linux कंटेनरों में फ़ॉन्ट पैकेजों की चिंता करनी चाहिए?
हां। सामान्य फ़ॉन्ट पैकेज स्थापित करने और/या अपने एप्लिकेशन में फ़ॉन्ट डायरेक्टरी को स्पष्ट रूप से [फ़ॉन्ट डायरेक्टरी निर्दिष्ट](/slides/hi/php-java/custom-font/) करने की सलाह दी जाती है ताकि अप्रत्याशित प्रतिस्थापन से बचा जा सके।

### क्या मूल्यांकन संस्करण में सीमाएँ हैं?
[मूल्यांकन मोड](/slides/hi/php-java/licensing/) में आउटपुट पर एक वॉटरमार्क जोड़ा जाता है और कुछ सीमाएँ लागू होती हैं; पूर्ण‑फ़ीचर परीक्षण के लिए एक [30‑day temporary license](https://purchase.aspose.com/temporary-license/) उपलब्ध है।

### क्या बाहरी प्रारूपों (PDF/HTML → PPTX) को प्रस्तुति में आयात करने का समर्थन है?
हां। आप प्रस्तुति में [PDF पृष्ठ और HTML सामग्री](/slides/hi/php-java/import-presentation/) जोड़ सकते हैं, जिससे वे स्लाइडों में बदल जाएंगे।
