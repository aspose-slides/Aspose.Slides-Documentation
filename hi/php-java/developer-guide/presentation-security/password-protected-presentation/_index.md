## **परिचय**

जब आप किसी प्रस्तुति को पासवर्ड से सुरक्षित करते हैं, तो इसका मतलब है कि आप एक पासवर्ड सेट कर रहे हैं जो प्रस्तुति पर कुछ प्रतिबंध लगाता है। प्रतिबंध हटाने के लिए पासवर्ड दर्ज करना आवश्यक है। पासवर्ड‑सुरक्षित प्रस्तुति को लॉक्ड प्रस्तुति माना जाता है।

आमतौर पर, आप प्रस्तुति पर ये प्रतिबंध लागू करने के लिए पासवर्ड सेट कर सकते हैं:

- **संशोधन**

  यदि आप चाहते हैं कि केवल कुछ उपयोगकर्ता ही आपकी प्रस्तुति को संशोधित करें, तो आप एक संशोधन प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध लोगों को आपके प्रस्तुति में संशोधन, परिवर्तन या कॉपी करने से रोकता है (जब तक वे पासवर्ड प्रदान न करें)। 

  हालाँकि, इस स्थिति में, पासवर्ड के बिना भी उपयोगकर्ता आपके दस्तावेज़ को एक्सेस कर सकेगा और इसे खोल सकेगा। इस पढ़ने‑केवल मोड में, उपयोगकर्ता आपकी प्रस्तुति के भीतर सामग्री या वस्तुएँ—हाइपरलिंक, एनीमेशन, इफ़ेक्ट आदि—देख सकता है, लेकिन वह आइटम कॉपी नहीं कर सकता या प्रस्तुति को सहेज नहीं सकता। 

- **खोलना**

  यदि आप चाहते हैं कि केवल कुछ उपयोगकर्ता ही आपकी प्रस्तुति खोलें, तो आप एक खोलने का प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध लोगों को आपकी प्रस्तुति की सामग्री देखने से भी रोकता है (जब तक वे पासवर्ड न दें)।

  तकनीकी रूप से, खोलने का प्रतिबंध उपयोगकर्ताओं को आपकी प्रस्तुति को संशोधित करने से भी रोकता है: जब लोग प्रस्तुति नहीं खोल सकते, तो वे इसे बदल या संशोधित नहीं कर सकते। 

  **नोट** कि जब आप प्रस्तुति को खोलने से रोकने के लिए पासवर्ड से सुरक्षित करते हैं, तो प्रस्तुति फ़ाइल एन्क्रिप्ट हो जाती है।

## **Aspose.Slides में प्रस्तुतियों के लिए पासवर्ड सुरक्षा**

**समर्थित प्रारूप**

Aspose.Slides पासवर्ड सुरक्षा, एन्क्रिप्शन और समान संचालन को इन प्रारूपों की प्रस्तुतियों के लिए समर्थन करता है:

- PPTX और PPT - Microsoft PowerPoint प्रस्तुति 
- ODP - OpenDocument प्रस्तुति 
- OTP - OpenDocument प्रस्तुति टेम्प्लेट 

**समर्थित संचालन**

Aspose.Slides आपको प्रस्तुति पर पासवर्ड सुरक्षा का उपयोग करके इन तरीकों से संशोधन रोकने की अनुमति देता है:

- प्रस्तुति को एन्क्रिप्ट करना
- प्रस्तुति पर लिखित संरक्षण सेट करना

**अन्य संचालन**

Aspose.Slides आपको पासवर्ड सुरक्षा और एन्क्रिप्शन से जुड़े अन्य कार्य इन तरीकों से करने देता है:

- प्रस्तुति को डिक्रिप्ट करना; एन्क्रिप्टेड प्रस्तुति खोलना
- एन्क्रिप्शन हटाना; पासवर्ड सुरक्षा अक्षम करना
- प्रस्तुति से लिखित संरक्षण हटाना
- एन्क्रिप्टेड प्रस्तुति की गुण प्राप्त करना
- जांचना कि प्रस्तुति एन्क्रिप्टेड है या नहीं
- जांचना कि प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं।

## **प्रस्तुति को एन्क्रिप्ट करें**

आप पासवर्ड सेट करके प्रस्तुति को एन्क्रिप्ट कर सकते हैं। फिर, लॉक्ड प्रस्तुति को संशोधित करने के लिए उपयोगकर्ता को पासवर्ड प्रदान करना होगा। 

प्रस्तुति को एन्क्रिप्ट या पासवर्ड‑सुरक्षित करने के लिए, आपको encrypt मेथड ( [ProtectionManager](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/) से) का उपयोग करके प्रस्तुति के लिए पासवर्ड सेट करना होगा। आप पासवर्ड को encrypt मेथड में पास करते हैं और save मेथड का उपयोग करके अब एन्क्रिप्टेड प्रस्तुति को सहेजते हैं।

यह उदाहरण कोड आपको दिखाता है कि प्रस्तुति को कैसे एन्क्रिप्ट किया जाता है:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->encrypt("123123");
    $presentation->save("encrypted-pres.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **प्रस्तुति पर लिखित संरक्षण सेट करें**

आप प्रस्तुति में “Do not modify” (संशोधित न करें) का चिह्न जोड़ सकते हैं। इस प्रकार, आप उपयोगकर्ताओं को बता सकते हैं कि आप नहीं चाहते कि वे प्रस्तुति में बदलाव करें।  

**नोट** कि लिखित संरक्षण प्रक्रिया प्रस्तुति को एन्क्रिप्ट नहीं करती है। इसलिए, उपयोगकर्ता—यदि वे चाहते हैं—प्रस्तुति को संशोधित कर सकते हैं, लेकिन परिवर्तन सहेजने के लिए उन्हें प्रस्तुति को अलग नाम से बनाना होगा। 

लिखित संरक्षण सेट करने के लिए, आपको [setWriteProtection](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#setWriteProtection) मेथड का उपयोग करना होगा। यह उदाहरण कोड आपको दिखाता है कि प्रस्तुति पर लिखित संरक्षण कैसे सेट किया जाता है:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->setWriteProtection("123123");
    $presentation->save("write-protected-pres.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **एन्क्रिप्टेड प्रस्तुति लोड करें**

Aspose.Slides आपको पासवर्ड पास करके एन्क्रिप्टेड फ़ाइल लोड करने देता है। प्रस्तुति को डिक्रिप्ट करने के लिए, आपको [removeEncryption](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#removeEncryption) मेथड को बिना पैरामीटर के कॉल करना होगा। तब आपको प्रस्तुति लोड करने के लिए सही पासवर्ड दर्ज करना पड़ेगा। 

यह उदाहरण कोड दिखाता है कि प्रस्तुति को कैसे डिक्रिप्ट किया जाता है: 

```php
  $loadOptions = new LoadOptions();
  $loadOptions->setPassword("123123");
  $presentation = new Presentation("pres.pptx", $loadOptions);
  try {
    # डिक्रिप्टेड प्रस्तुति के साथ काम करें
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **प्रस्तुति से एन्क्रिप्शन हटाएँ**

आप प्रस्तुति से एन्क्रिप्शन या पासवर्ड सुरक्षा हटा सकते हैं। इस प्रकार, उपयोगकर्ता किसी प्रतिबंध के बिना प्रस्तुति को एक्सेस या संशोधित कर सकते हैं। 

एन्क्रिप्शन या पासवर्ड सुरक्षा हटाने के लिए, आपको [removeEncryption](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#removeEncryption) मेथड को कॉल करना होगा। यह उदाहरण कोड आपको प्रस्तुति से एन्क्रिप्शन हटाने का तरीका दिखाता है:

```php
  $loadOptions = new LoadOptions();
  $loadOptions->setPassword("123123");
  $presentation = new Presentation("pres.pptx", $loadOptions);
  try {
    $presentation->getProtectionManager()->removeEncryption();
    $presentation->save("encryption-removed.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **प्रस्तुति से लिखित संरक्षण हटाएँ**

आप Aspose.Slides का उपयोग करके प्रस्तुति फ़ाइल पर लागू लिखित संरक्षण हटा सकते हैं। इस प्रकार, उपयोगकर्ता अपनी इच्छा अनुसार संशोधित कर सकते हैं—और उन्हें इस तरह के कार्य करने पर कोई चेतावनी नहीं मिलती। 

आप [removeWriteProtection](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#removeWriteProtection) मेथड का उपयोग करके प्रस्तुति से लिखित संरक्षण हटा सकते हैं। यह उदाहरण कोड आपको प्रस्तुति से लिखित संरक्षण हटाने का तरीका दिखाता है:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->removeWriteProtection();
    $presentation->save("write-protection-removed.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **एन्क्रिप्टेड प्रस्तुति की गुण प्राप्त करें**

आमतौर पर, उपयोगकर्ताओं को एन्क्रिप्टेड या पासवर्ड‑सुरक्षित प्रस्तुति के दस्तावेज़ गुण प्राप्त करने में कठिनाई होती है। फिर भी, Aspose.Slides एक तंत्र प्रदान करता है जिससे आप प्रस्तुति को पासवर्ड से सुरक्षित कर सकते हैं जबकि उपयोगकर्ताओं को उसके गुणों तक पहुँचने की क्षमता बनी रहती है। 

**नोट:** डिफ़ॉल्ट रूप से, जब Aspose.Slides प्रस्तुति को एन्क्रिप्ट करता है, तो प्रस्तुति के दस्तावेज़ गुण भी पासवर्ड‑सुरक्षित होते हैं। यदि आप एन्क्रिप्शन के बाद भी दस्तावेज़ गुणों को सुलभ रखना चाहते हैं, तो Aspose.Slides यह करने की सुविधा देता है। 

यदि आप चाहते हैं कि उपयोगकर्ता एन्क्रिप्टेड प्रस्तुति के गुणों तक पहुँच बनाए रखें, तो [ProtectionManager::setEncryptDocumentProperties](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#setEncryptDocumentProperties) को `false` पास करें। यह उदाहरण कोड दिखाता है कि कैसे प्रस्तुति को एन्क्रिप्ट किया जाए जबकि उपयोगकर्ताओं को उसके दस्तावेज़ गुणों तक पहुँच प्रदान की जाए:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->setEncryptDocumentProperties(false);
    $presentation->getProtectionManager()->encrypt("123123");
    $presentation->save("encrypted-pres.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **एन्क्रिप्टेड प्रस्तुति से केवल दस्तावेज़ गुण लोड करें**

एन्क्रिप्टेड प्रस्तुति के मेटाडेटा को उसके स्लाइड्स या अन्य सामग्री लोड किए बिना निरीक्षण करने के लिए, एक [LoadOptions](https://reference.aspose.com/slides/hi/php-java/aspose.slides/loadoptions/) ऑब्जेक्ट बनाएँ और [setOnlyLoadDocumentProperties](https://reference.aspose.com/slides/hi/php-java/aspose.slides/loadoptions/#setOnlyLoadDocumentProperties) को `true` पास करें। इस मोड में, Aspose.Slides पासवर्ड को अनदेखा करता है और केवल सार्वजनिक रूप से सुलभ दस्तावेज़ गुण लोड करता है। 

निम्नलिखित कोड उदाहरण [Presentation::getDocumentProperties](https://reference.aspose.com/slides/hi/php-java/aspose.slides/presentation/#getDocumentProperties) के माध्यम से निर्मित और कस्टम दस्तावेज़ गुण पढ़ता है:

```php
$loadOptions = new LoadOptions();
$loadOptions->setOnlyLoadDocumentProperties(true);

$presentation = new Presentation("encrypted-pres.pptx", $loadOptions);
try {
    $documentProperties = $presentation->getDocumentProperties();

    # निर्मित दस्तावेज़ गुण पढ़ें।
    echo("Title: " . $documentProperties->getTitle() . "\n");
    echo("Author: " . $documentProperties->getAuthor() . "\n");

    # कस्टम दस्तावेज़ गुण पढ़ें।
    $customPropertyCount = java_values($documentProperties->getCountOfCustomProperties());

    for ($propertyIndex = 0; $propertyIndex < $customPropertyCount; $propertyIndex++) {
        $propertyName = $documentProperties->getCustomPropertyName($propertyIndex);
        $propertyValue = java_values($documentProperties->get_Item($propertyName));

        echo($propertyName . ": " . $propertyValue . "\n");
    }
} finally {
    $presentation->dispose();
}
```

यह कार्यप्रवाह केवल तब काम करता है जब प्रस्तुति को एन्क्रिप्ट करते समय दस्तावेज़ गुण अपरिस्क्रिप्ट (सार्वजनिक) छोड़े गए हों। यदि दस्तावेज़ गुण एन्क्रिप्टेड हैं, तो [LoadOptions::setOnlyLoadDocumentProperties](https://reference.aspose.com/slides/hi/php-java/aspose.slides/loadoptions/#setOnlyLoadDocumentProperties) को `true` पास करने से अपवाद उत्पन्न होता है क्योंकि इस मोड में पासवर्ड को अनदेखा किया जाता है। एन्क्रिप्टेड दस्तावेज़ गुणों तक पहुँचने या पूरी प्रस्तुति, जिसमें उसके स्लाइड्स और अन्य सामग्री शामिल है, लोड करने के लिए, आपको सही पासवर्ड [LoadOptions::setPassword](https://reference.aspose.com/slides/hi/php-java/aspose.slides/loadoptions/#setPassword) के माध्यम से प्रदान करना होगा।

## **जाँचें कि कोई प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं**

प्रस्तुति लोड करने से पहले, आप यह जांचना चाह सकते हैं कि प्रस्तुति पासवर्ड से सुरक्षित नहीं है। इस प्रकार, आप उन त्रुटियों और समान मुद्दों से बच सकते हैं जो पासवर्ड‑सुरक्षित प्रस्तुति को बिना पासवर्ड के लोड करने पर उत्पन्न होते हैं। 

यह PHP कोड आपको दिखाता है कि प्रस्तुति को कैसे जांचा जाए कि वह पासवर्ड‑सुरक्षित है या नहीं (बिना प्रस्तुति को लोड किए):

```php
  $presentationInfo = PresentationFactory->getInstance()->getPresentationInfo("example.pptx");
  echo("The presentation is password protected: " . $presentationInfo->isPasswordProtected());

```

## **जाँचें कि प्रस्तुति एन्क्रिप्टेड है या नहीं**

Aspose.Slides आपको यह जांचने की अनुमति देता है कि प्रस्तुति एन्क्रिप्टेड है या नहीं। इस कार्य के लिए आप [isEncrypted](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#isEncrypted) मेथड का उपयोग कर सकते हैं, जो यदि प्रस्तुति एन्क्रिप्टेड है तो `true` और यदि नहीं है तो `false` लौटाता है। 

यह उदाहरण कोड दिखाता है कि प्रस्तुति एन्क्रिप्टेड है या नहीं, कैसे जांचा जाए:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $isEncrypted = $presentation->getProtectionManager()->isEncrypted();
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **जाँचें कि प्रस्तुति लिखित‑सुरक्षित है या नहीं**

Aspose.Slides आपको यह जांचने की अनुमति देता है कि प्रस्तुति लिखित‑सुरक्षित है या नहीं। इस कार्य के लिए आप [isWriteProtected](https://reference.aspose.com/slides/hi/php-java/aspose.slides/protectionmanager/#isWriteProtected) मेथड का उपयोग कर सकते हैं, जो यदि प्रस्तुति लिखित‑सुरक्षित है तो `true` और यदि नहीं है तो `false` लौटाता है। 

यह उदाहरण कोड दिखाता है कि प्रस्तुति लिखित‑सुरक्षित है या नहीं, कैसे जांचा जाए:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $isEncrypted = $presentation->getProtectionManager()->isWriteProtected();
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **पुष्ट करें कि विशिष्ट पासवर्ड का उपयोग किया गया है**

आप यह जांचना और पुष्टि करना चाहते हैं कि किसी प्रस्तुति दस्तावेज़ को सुरक्षित करने के लिए विशिष्ट पासवर्ड उपयोग किया गया है। Aspose.Slides आपको पासवर्ड सत्यापित करने की सुविधा प्रदान करता है। 

यह उदाहरण कोड दिखाता है कि पासवर्ड को कैसे सत्यापित किया जाता है:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    # जांचें कि "pass" मैच है या नहीं
    $isWriteProtected = $presentation->getProtectionManager()->checkWriteProtection("my_password");
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

यह `true` लौटाता है यदि प्रस्तुति निर्दिष्ट पासवर्ड से एन्क्रिप्ट की गई हो। अन्यथा, यह `false` लौटाता है।

## **अक्सर पूछे जाने वाले प्रश्न**

**Aspose.Slides द्वारा समर्थित एन्क्रिप्शन मेथड कौन‑से हैं?**

Aspose.Slides आधुनिक एन्क्रिप्शन मेथड्स का समर्थन करता है, जिसमें AES‑आधारित एल्गोरिद्म शामिल हैं, जो आपकी प्रस्तुतियों के डेटा की उच्च सुरक्षा सुनिश्चित करते हैं।

**प्रस्तुति खोलने के प्रयास में यदि गलत पासवर्ड दर्ज किया जाए तो क्या होता है?**

यदि गलत पासवर्ड प्रयुक्त होता है तो एक अपवाद उत्पन्न किया जाता है, जो आपको सूचित करता है कि प्रस्तुति तक पहुँच अस्वीकृत है। यह अनधिकृत पहुँच को रोकने और प्रस्तुति की सामग्री की रक्षा करने में मदद करता है।

**क्या पासवर्ड‑सुरक्षित प्रस्तुतियों के साथ काम करने पर कोई प्रदर्शन संबंधी प्रभाव पड़ते हैं?**

एन्क्रिप्शन और डिक्रिप्शन प्रक्रिया खोलने और सेव करने के दौरान थोड़ा अधिक ओवरहेड जोड़ सकती है। अधिकांश मामलों में, यह प्रदर्शन प्रभाव न्यूनतम होता है और आपके प्रस्तुति कार्यों के कुल प्रोसेसिंग समय को गंभीरता से प्रभावित नहीं करता।
