## **परिचय**

Aspose.Slides प्रेज़ेंटेशन में स्लाइड आकार और आस्पेक्ट अनुपात को समायोजित करने के लिए व्यापक टूल प्रदान करता है, जो प्रिंटिंग और स्क्रीन पर दिखाने दोनों के लिए महत्वपूर्ण है। 

लोकप्रिय स्लाइड आकार और अनुपात:

- **Standard (4:3 Aspect Ratio)**: पुराने स्क्रीन और उपकरणों के लिए आदर्श।
- **Widescreen (16:9 Aspect Ratio)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सुनिश्चित करें कि आपके प्रेज़ेंटेशन में पूरे स्लाइड्स पर एक ही स्लाइड आकार और आस्पेक्ट अनुपात लागू हो। सर्वोत्तम परिणाम के लिए, जटिलताओं से बचने हेतु प्रेज़ेंटेशन बनाते समय शुरुआत में ही स्लाइड आयाम निर्धारित करें।

{{% alert color="info" title="Note" %}}
डिफ़ॉल्ट रूप से, Aspose.Slides से बनाई गई प्रस्तुतियों में मानक 4:3 आस्पेक्ट अनुपात उपयोग होता है।
{{% /alert %}}

नोट्स और हैंडआउट पेज़ का आकार नियमित स्लाइड्स से अलग होता है। आकार और अभिविन्यास बदलने के लिए देखें [Notes Page Size](/slides/hi/php-java/notes-size/).

## **प्रेज़ेंटेशन में स्लाइड आकार बदलें**

यह नमूना कोड दिखाता है कि Aspose.Slides का उपयोग करके प्रेज़ेंटेशन में स्लाइड आकार कैसे बदलें:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **प्रेज़ेंटेशन में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि आपको सामान्य स्लाइड आकार (4:3 और 16:9) आपके काम के लिए उपयुक्त नहीं लगते हैं, तो आप एक विशिष्ट या अनूठा स्लाइड आकार उपयोग करने का निर्णय ले सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रेज़ेंटेशन की पूरी स्लाइड्स को कस्टम पेज लेआउट पर प्रिंट करने की योजना बनाते हैं या किसी विशेष स्क्रीन प्रकार पर प्रेज़ेंटेशन दिखाने का इरादा रखते हैं, तो कस्टम आकार सेटिंग का उपयोग आपके लिए लाभदायक हो सकता है।

यह नमूना कोड दिखाता है कि Aspose.Slides for PHP via Java का उपयोग करके प्रेज़ेंटेशन के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट करें:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// A4 कागज़ आकार

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **रिसाइज़ करने के बाद स्लाइड सामग्री संभालें**

जब आप किसी प्रेज़ेंटेशन का स्लाइड आकार बदलते हैं, तो स्लाइड की सामग्री (जैसे छवियां या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट नए स्लाइड आकार के अनुसार स्वचालित रूप से री-साइज़ हो जाते हैं। हालांकि, प्रेज़ेंटेशन के स्लाइड आकार को बदलते समय आप ऐसी सेटिंग निर्दिष्ट कर सकते हैं जो निर्धारित करे कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालता है।

आपकी आवश्यकता या लक्ष्य के आधार पर, आप इनमें से किसी भी सेटिंग का उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर ऑब्जेक्ट को री-साइज़ नहीं करना चाहते हैं, तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार के लिए स्केल करना चाहते हैं और Aspose.Slides को स्लाइड की वस्तुओं को डाउनस्केल करके सभी को स्लाइड पर फिट करना आवश्यक है (इस तरह आप सामग्री की हानि से बचते हैं), तो इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार के लिए स्केल करना चाहते हैं और Aspose.Slides को स्लाइड की वस्तुओं को बड़ा करके उन्हें नए स्लाइड आकार के अनुरूप बनाना आवश्यक है, तो इस सेटिंग का उपयोग करें।

यह नमूना कोड दिखाता है कि प्रेज़ेंटेशन की स्लाइड आकार बदलते समय `Maximize` सेटिंग का उपयोग कैसे करें:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे पॉइंट्स या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता/सकती हूँ?**

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच होता है। आप किसी भी इकाई (जैसे मिलीमीटर या सेंटीमीटर) को पॉइंट्स में बदल सकते हैं और परिवर्तित मानों का उपयोग स्लाइड की चौड़ाई और ऊँचाई निर्धारित करने के लिए कर सकते हैं।

**क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हां। बड़े स्लाइड आयाम (पॉइंट्स में) और उच्च रेंडरिंग स्केल मिलकर मेमोरी की खपत बढ़ाते हैं और प्रोसेसिंग समय को लंबा करते हैं। एक व्यावहारिक स्लाइड आकार का लक्ष्य रखें और इच्छित आउटपुट गुणवत्ता पाने के लिए केवल आवश्यकतानुसार रेंडरिंग स्केल को समायोजित करें।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता/सकती हूँ और फिर विभिन्न आकार वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता/सकती हूँ?**

आप अलग-अलग स्लाइड आकार वाली प्रस्तुतियों को [merge presentations](/slides/hi/php-java/merge-presentation/) नहीं कर सकते — पहले एक प्रस्तुति का आकार दूसरे के समान कर ले। स्लाइड आकार बदलते समय आप मौजूदा सामग्री को कैसे संभालना है, वह [SlideSizeScaleType](https://reference.aspose.com/slides/hi/php-java/aspose.slides/slidesizescaletype/) विकल्प के माध्यम से चुन सकते हैं। आकार संगत करने के बाद, आप स्वरूपण को बरकरार रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

**क्या मैं स्लाइड के व्यक्तिगत शेप्स या विशिष्ट क्षेत्रों के थंबनेल बना सकता/सकती हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?**

हां। Aspose.Slides [entire slides](https://reference.aspose.com/slides/hi/php-java/aspose.slides/slide/#getImage) तथा [selected shapes](https://reference.aspose.com/slides/hi/php-java/aspose.slides/shape/#getImage) के थंबनेल रेंडर कर सकता है। परिणामी छवियां वर्तमान स्लाइड आकार और आस्पेक्ट अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में स्थिरता बनी रहती है।
