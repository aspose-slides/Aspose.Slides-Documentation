## **परिचय**

Aspose.Slides PowerPoint प्रस्तुतियों में स्लाइड आकार और आस्पेक्ट रेशियो को समायोजित करने के लिए व्यापक टूल्स प्रदान करता है, जो प्रिंटिंग और ऑन‑स्क्रीन डिस्प्ले दोनों के लिए महत्वपूर्ण हैं।

प्रचलित स्लाइड आकार और अनुपात:

- **स्टैंडर्ड (4:3 अनुपात)**: पुराने स्क्रीन और डिवाइसों के लिए आदर्श।
- **वाइडस्क्रीन (16:9 अनुपात)**: आधुनिक प्रोजेक्टर और डिस्प्ले के लिए अनुशंसित।

सभी स्लाइड्स में एक ही स्लाइड आकार और अनुपात लागू होता है, इसलिए प्रस्तुति में निरंतरता बनाए रखें। सर्वोत्तम परिणाम के लिए, प्रस्तुति बनाते समय ही स्लाइड आयाम निर्धारित करें ताकि बाद में जटिलताओं से बचा जा सके।

{{% alert color="primary" %}} 
डिफ़ॉल्ट रूप से, Aspose.Slides के साथ बनाई गई प्रस्तुतियों में मानक 4:3 अनुपात का उपयोग किया जाता है।
{{% /alert %}}

## **प्रस्तुतियों में स्लाइड आकार बदलें**

यह नमूना कोड दिखाता है कि Aspose.Slides का उपयोग करके प्रस्तुति में स्लाइड आकार कैसे बदलें:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **प्रस्तुतियों में कस्टम स्लाइड आकार निर्दिष्ट करें**

यदि सामान्य स्लाइड आकार (4:3 और 16:9) आपके काम के लिए उपयुक्त नहीं हैं, तो आप विशिष्ट या अनोखा स्लाइड आकार चुन सकते हैं। उदाहरण के लिए, यदि आप अपनी प्रस्तुति से कस्टम पृष्ठ लेआउट पर पूर्ण आकार की स्लाइड प्रिंट करना चाहते हैं या कुछ स्क्रीन प्रकारों पर प्रस्तुति प्रदर्शित करना चाहते हैं, तो कस्टम आकार सेटिंग का उपयोग करना फायदेमंद रहेगा।

यह नमूना कोड दिखाता है कि Java के माध्यम से PHP के लिए Aspose.Slides का उपयोग करके प्रस्तुति के लिए कस्टम स्लाइड आकार कैसे निर्दिष्ट किया जाए :

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// A4 कागज का आकार

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **आकार बदलने के बाद स्लाइड सामग्री को संभालना**

जब आप प्रस्तुति के स्लाइड आकार को बदलते हैं, तो स्लाइड की सामग्री (जैसे छवियां या ऑब्जेक्ट) विकृत हो सकती है। डिफ़ॉल्ट रूप से, ऑब्जेक्ट्स को स्वचालित रूप से नए स्लाइड आकार में फिट करने के लिए रिसाइज़ किया जाता है। हालांकि, स्लाइड आकार बदलते समय आप एक सेटिंग निर्दिष्ट कर सकते हैं जो तय करती है कि Aspose.Slides स्लाइड की सामग्री को कैसे संभालेगा।

आपकी इच्छित परिणाम के आधार पर आप इनमें से कोई भी सेटिंग उपयोग कर सकते हैं:

- `DoNotScale`

  यदि आप स्लाइड पर ऑब्जेक्ट्स को रिसाइज़ नहीं करना चाहते तो इस सेटिंग का उपयोग करें।

- `EnsureFit`

  यदि आप छोटे स्लाइड आकार पर स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड की सभी ऑब्जेक्ट्स को छोटा करे ताकि वे सभी स्लाइड में फिट हो जाएँ (इससे आप सामग्री खोने से बचते हैं), इस सेटिंग का उपयोग करें।

- `Maximize`

  यदि आप बड़े स्लाइड आकार पर स्केल करना चाहते हैं और चाहते हैं कि Aspose.Slides स्लाइड की ऑब्जेक्ट्स को बड़ा करे ताकि वे नए स्लाइड आकार के अनुपात में हों, इस सेटिंग का उपयोग करें।

यह नमूना कोड दिखाता है कि प्रस्तुति के स्लाइड आकार को बदलते समय `Maximize` सेटिंग का उपयोग कैसे किया जाए:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मैं इंच के अलावा अन्य इकाइयों (जैसे, पॉइंट्स या मिलीमीटर) का उपयोग करके कस्टम स्लाइड आकार सेट कर सकता हूँ?**

हां। Aspose.Slides आंतरिक रूप से पॉइंट्स का उपयोग करता है, जहाँ 1 पॉइंट = 1/72 इंच के बराबर होता है। आप किसी भी इकाई (जैसे, मिलीमीटर या सेंटीमीटर) को पॉइंट्स में बदल सकते हैं और बदले हुए मानों का उपयोग स्लाइड की चौड़ाई और ऊँचाई निर्धारित करने के लिए कर सकते हैं।

**क्या बहुत बड़ा कस्टम स्लाइड आकार रेंडरिंग के दौरान प्रदर्शन और मेमोरी उपयोग को प्रभावित करेगा?**

हां। बड़े स्लाइड आयाम (पॉइंट्स में) उच्च रेंडरिंग स्केल के साथ मिलकर मेमोरी खपत और प्रोसेसिंग समय को बढ़ाते हैं। व्यावहारिक स्लाइड आकार को लक्ष्य रखें और रेंडरिंग स्केल को केवल आवश्यकतानुसार समायोजित करें ताकि वांछित आउटपुट गुणवत्ता प्राप्त हो सके।

**क्या मैं एक गैर-मानक स्लाइड आकार परिभाषित कर सकता हूँ और फिर विभिन्न आकार वाली प्रस्तुतियों से स्लाइड्स को मर्ज कर सकता हूँ?**

आप विभिन्न स्लाइड आकारों वाली प्रस्तुतियों को [प्रस्तुतियों को मर्ज करें](/slides/hi/php-java/merge-presentation/) नहीं मर्ज कर सकते — पहले एक प्रस्तुति का आकार दूसरे के साथ मिलाएँ। स्लाइड आकार बदलते समय आप मौजूद सामग्री को कैसे संभालना है, इसे [SlideSizeScaleType](https://reference.aspose.com/slides/hi/php-java/aspose.slides/slidesizescaletype/) विकल्प के द्वारा चुन सकते हैं। आकारों को समान करने के बाद, आप फ़ॉर्मेटिंग को बरकरार रखते हुए स्लाइड्स को मर्ज कर सकते हैं।

**क्या मैं स्लाइड के व्यक्तिगत आकारों या विशिष्ट क्षेत्रों के लिए थंबनेल बना सकता हूँ, और क्या वे नए स्लाइड आकार का सम्मान करेंगे?**

हां। Aspose.Slides [पूरे स्लाइड्स](https://reference.aspose.com/slides/hi/php-java/aspose.slides/slide/#getImage) तथा [चुने हुए आकारों](https://reference.aspose.com/slides/hi/php-java/aspose.slides/shape/#getImage) के लिए थंबनेल रेंडर कर सकता है। उत्पन्न छवियां वर्तमान स्लाइड आकार और अनुपात को दर्शाती हैं, जिससे फ्रेमिंग और ज्यामिति में संगतता बनी रहती है।
