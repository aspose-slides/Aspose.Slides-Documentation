## **समर्थित प्लेटफ़ॉर्म**
Aspose.Slides for Python via .NET को Windows x64 या x86 और Python 3.5 या बाद के संस्करण स्थापित किए गए विभिन्न Linux वितरणों पर उपयोग किया जा सकता है। लक्ष्य Linux प्लेटफ़ॉर्म के लिए अतिरिक्त आवश्यकताएँ हैं:
- GCC-6 रनटाइम लाइब्रेरी (या बाद की)
- .NET Core Runtime की निर्भरताएँ। स्वयं .NET Core Runtime स्थापित करना आवश्यक नहीं है
- Python 3.5-3.7 के लिए: Python का `pymalloc` बिल्ड आवश्यक है। `--with-pymalloc` Python बिल्ड विकल्प डिफ़ॉल्ट रूप से सक्षम है। सामान्यतः, `pymalloc` बिल्ड वाले Python फ़ाइलनाम में `m` प्रत्यय होता है।
- `libpython` साझा Python लाइब्रेरी। `--enable-shared` Python बिल्ड विकल्प डिफ़ॉल्ट रूप से निष्क्रिय है, कुछ Python वितरण में `libpython` साझा लाइब्रेरी नहीं होती। कुछ Linux प्लेटफ़ॉर्म पर `libpython` साझा लाइब्रेरी को पैकेज मैनेजर से स्थापित किया जा सकता है, उदाहरण के लिए: `sudo apt-get install libpython3.7`। सामान्य समस्या यह है कि `libpython` लाइब्रेरी मानक सिस्टम स्थान के बजाय किसी अन्य स्थान पर स्थापित होती है। इसे Python बिल्ड विकल्पों के द्वारा वैकल्पिक लाइब्रेरी पाथ सेट करके या सिस्टम के मानक स्थान में `libpython` लाइब्रेरी फ़ाइल का सिम्बॉलिक लिंक बनाकर हल किया जा सकता है। सामान्यतः, `libpython` साझा लाइब्रेरी फ़ाइल का नाम Python 3.5-3.7 के लिए `libpythonX.Ym.so.1.0` और Python 3.8 या बाद के लिए `libpythonX.Y.so.1.0` (उदाहरण: `libpython3.7m.so.1.0`, `libpython3.9.so.1.0`) होता है।

यदि आपको अधिक प्लेटफ़ॉर्म का समर्थन चाहिए, तो “twin brother” उत्पाद Aspose.Slides for .NET या Aspose.Slides for Java देखें।

## **FAQ**

### क्या लाइब्रेरी के कार्य करने के लिए सर्वर/पीसी पर Microsoft PowerPoint स्थापित करना आवश्यक है?

नहीं। PowerPoint आवश्यक नहीं है; Aspose.Slides एक स्टैंडअलोन इंजन है जो प्रस्तुतियों को बनाने, संपादित करने, रूपांतरण करने और रेंडर करने के लिए उपयोग होता है।

### मल्टीथ्रेडिंग कैसे काम करता है? क्या प्रोसेसिंग को समानांतर किया जा सकता है?

विभिन्न थ्रेड्स में विभिन्न दस्तावेज़ों को प्रोसेस करना सुरक्षित है; एक ही [presentation](https://reference.aspose.com/slides/hi/python-net/aspose.slides/presentation/) ऑब्जेक्ट को [multiple threads](/slides/hi/python-net/multithreading/) द्वारा एक साथ उपयोग नहीं किया जाना चाहिए।

### क्या फ़ाइल पासवर्ड और एन्क्रिप्शन समर्थित हैं?

हाँ। [आप](/slides/hi/python-net/password-protected-presentation/) एन्क्रिप्टेड प्रस्तुतियों को खोल सकते हैं, खोलने और लिखने के पासवर्ड को सेट या हटाए जा सकते हैं, और सुरक्षा स्थिति की जाँच कर सकते हैं।

### क्या Linux कंटेनरों में फ़ॉन्ट पैकेजों की देखभाल करनी चाहिए?

हाँ। यह अनुशंसा की जाती है कि सामान्य फ़ॉन्ट पैकेज स्थापित करें और/या अपने अनुप्रयोग में फ़ॉन्ट डायरेक्टरीज़ को स्पष्ट रूप से [specify font directories](/slides/hi/python-net/custom-font/) करें ताकि अप्रत्याशित प्रतिस्थापन से बचा जा सके।

### क्या मूल्यांकन संस्करण में सीमाएँ हैं?

[मूल्यांकन मोड](/slides/hi/python-net/licensing/) में आउटपुट में वॉटरमार्क जोड़ा जाता है और कुछ सीमाएँ लागू होती हैं; पूर्ण‑फ़ीचर परीक्षण के लिए एक [30‑day temporary license](https://purchase.aspose.com/temporary-license/) उपलब्ध है।

### क्या प्रस्तुति में बाहरी फ़ॉर्मेट (PDF/HTML → PPTX) आयात करने का समर्थन है?

हाँ। आप एक प्रस्तुति में [PDF pages and HTML content](/slides/hi/python-net/import-presentation/) जोड़ सकते हैं, जिससे वे स्लाइड्स में बदल जाएँ।
