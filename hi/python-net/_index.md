Aspose.Slides for Python via .NET एक Python लाइब्रेरी है जो PowerPoint और OpenDocument प्रस्तुतियों को बनाने, पढ़ने, संपादित करने और रूपांतरण करने के लिए उपयोग की जाती है, बिना Microsoft PowerPoint या Microsoft Office के।

यह PPT, PPTX, PPS, POT और ODP को लोड और सहेजता है, जिसमें मैक्रो-सक्षम और टेम्प्लेट प्रकार शामिल हैं, और PDF, XPS, HTML, SVG, TIFF, Markdown और चित्रों में निर्यात करता है।

## **आपकी पहली प्रस्तुति**

PyPI से पैकेज इंस्टॉल करें:

```bash
pip install aspose.slides
```

पैकेज में वह .NET रनटाइम शामिल है जो यह उपयोग करता है, इसलिए आपको .NET इंस्टॉल करने की आवश्यकता नहीं है। Linux पर, libgdiplus और ICU लाइब्रेरीज़ भी इंस्टॉल करें, और Debian या Ubuntu के सिस्टम Python के साथ, वर्चुअल एनवायरनमेंट में कमांड चलाएँ। macOS में अतिरिक्त पूर्वापेक्षाएँ हैं, और हमने वहां स्थापना की पुष्टि नहीं की है। कमांड, macOS की पूर्वापेक्षाएँ और समर्थित Python संस्करणों के लिए देखें [Installation](/slides/hi/python-net/installation/)।

इस कोड को *hello.py* के रूप में सहेजें:

```py
import aspose.slides as slides

# प्रेज़ेंटेशन फ़ाइल का प्रतिनिधित्व करने वाली Presentation क्लास का एक इंस्टेंस बनाएं।
with slides.Presentation() as presentation:
    # पहली स्लाइड प्राप्त करें।
    slide = presentation.slides[0]

    # CLOUD प्रकार का एक ऑटो-शेप जोड़ें।
    auto_shape = slide.shapes.add_auto_shape(slides.ShapeType.CLOUD, 20, 20, 200, 80)
    auto_shape.text_frame.text = "Hello, Aspose!"

    # प्रेज़ेंटेशन को PPTX फ़ाइल के रूप में सहेजें।
    presentation.save("new_presentation.pptx", slides.export.SaveFormat.PPTX)
```

इसे `python hello.py` के साथ चलाएँ। स्क्रिप्ट मौजूदा फ़ोल्डर में *new_presentation.pptx* सहेजती है, जिसमें एक स्लाइड होती है जिसमें एक क्लाउड आकार है जिसमें लिखा है “Hello, Aspose!”। बिना लाइसेंस के, सहेजी गई फ़ाइल पर एक मूल्यांकन वॉटरमार्क रहता है — देखें [Licensing](/slides/hi/python-net/licensing/)। प्रस्तुति बनाने और भरने के कई अन्य तरीकों के लिए, देखें [Create Presentations](/slides/hi/python-net/create-presentation/).
