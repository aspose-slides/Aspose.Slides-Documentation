## **Power BI**

आप Aspose.Slides for Reporting Services को Power BI Report Server पर समान स्थापना प्रक्रियाओं के माध्यम से स्थापित कर सकते हैं:

* [MSI इंस्टॉलर के साथ स्थापित करें](/slides/hi/reportingservices/install-with-msi-installer/). स्थापना कार्यक्रम स्वचालित रूप से स्थापित Power BI Report Server का पता लगाता है, उत्पाद स्थापित करता है, और फिर इसे आपके कार्य वातावरण के लिए कॉन्फ़िगर करता है।
* [हाथ से स्थापित करें](/slides/hi/reportingservices/install-manually/). ZIP पैकेज के *Bin\Universal* फ़ोल्डर से असेंबली का उपयोग करें।

Aspose.Slides for Reporting Services Power BI Report Server से पृष्ठांकित रिपोर्ट (RDL) निर्यात करता है। आवश्यकताओं के लिए, जिसमें होस्ट मशीन पर .NET Framework 3.5 शामिल है, देखें [सिस्टम आवश्यकताएँ](/slides/hi/reportingservices/system-requirements/).
