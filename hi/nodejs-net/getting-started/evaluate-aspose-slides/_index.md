## **सारांश**

एस्पोज़ स्लाइड्स फ़ॉर Node.js via .NET का मूल्यांकन संस्करण लाइसेंस प्राप्त संस्करण के समान npm पैकेज है। लाइसेंस के बिना यह मूल्यांकन मोड में चलता है: सभी सुविधाएं काम करती हैं, लेकिन सहेजे गए प्रस्तुतियों और अधिकांश निर्यातों में वॉटरमार्क रहता है, और आपका कोड जो टेक्स्ट पढ़ता है वह समाप्त हो जाता है। यह लेख दोनों सीमाओं का विवरण देता है और उन्हें हटाने का तरीका दिखाता है।

## **मूल्यांकन सीमाएँ**

**हर स्लाइड पर एक मूल्यांकन वॉटरमार्क।**  
जब आप बिना लाइसेंस के एक प्रस्तुति सहेजते हैं, Aspose.Slides हर सहेजी गई फ़ाइल की प्रत्येक स्लाइड के मध्य में एक टेक्स्ट बॉक्स जोड़ता है। टेक्स्ट बॉक्स लॉक्ड होता है और इसमें "Evaluation only." लिखा रहता है, जिसके बाद एक प्रोडक्ट लाइन और कॉपीराइट लाइन आती है। वॉटरमार्क सहेजी गई फ़ाइल में जाता है, मेमोरी में मौजूद प्रस्तुति में नहीं, और प्रस्तुति खोलने पर यह नहीं जोड़ा जाता। हालांकि, एक फ़ाइल जो मूल्यांकन मोड में सहेजी गई थी, उसमें पहले से ही टेक्स्ट बॉक्स मौजूद होता है, इसलिए उसे फिर से खोलकर सहेजने पर प्रत्येक स्लाइड पर दूसरा वॉटरमार्क जुड़ जाता है।

जब आप PDF, XPS या HTML में निर्यात करते हैं या स्लाइड को छवि के रूप में रेंडर करते हैं, तो समान वॉटरमार्क आउटपुट पर दिखाया जाता है। यदि आप ऐसी प्रस्तुति को रेंडर करते हैं जो पहले ही मूल्यांकन मोड में सहेजी गई है, तो छवि में सहेजे गए वॉटरमार्क और रेंडर किया गया वॉटरमार्क दोनों दिखते हैं।

**जब आपका कोड इसे पढ़ता है तो टेक्स्ट काटा जाता है।**  
आपके कोड द्वारा `text` प्रॉपर्टी के माध्यम से टेक्स्ट फ़्रेम, पैराग्राफ या भाग से पढ़ा गया टेक्स्ट पहले पाँच अक्षरों तक कट जाता है, उसके बाद नोटिस "... text has been truncated due to evaluation version limitation." आता है। पाँच अक्षरों या उससे कम का टेक्स्ट पूरी तरह लौटाया जाता है। यह हर स्लाइड पर लागू होता है, यहाँ तक कि उस टेक्स्ट पर भी जो आपका कोड अभी-अभी असाइन किया है। Markdown और HTML5 निर्यात समान रूप से कटते हैं।

आपके कोड द्वारा लिखा गया टेक्स्ट पूरी तरह सहेजा जाता है: PPTX फ़ाइलें, PDF पेज और स्लाइड छवियों में पूरा टेक्स्ट शामिल होता है।

## **स्क्रिप्ट में सीमाओं को देखें**

निम्न स्क्रिप्ट दोनों सीमाओं को दर्शाती है। यह मानती है कि आपने पैकेज को [स्थापना](/slides/hi/nodejs-net/installation/) में वर्णित अनुसार स्थापित किया है और इसे प्रोजेक्ट फोल्डर से चलाते हैं। यह पहली स्लाइड में एक वाक्य के साथ एक आयत जोड़ती है, वाक्य को पढ़ती है, प्रस्तुति को `evaluation.pptx` के रूप में सहेजती है, और फिर फ़ाइल को फिर से खोलकर स्लाइड पर आकृतियों की गिनती करती है।

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { Presentation, ShapeType, SaveFormat } = asposeSlides;

const presentation = new Presentation();
try {
    const slide = presentation.slides.get(0);
    const rectangle = slide.shapes.addAutoShape(ShapeType.Rectangle, 50, 50, 500, 100);
    rectangle.textFrame.text = "Quarterly results are ready for review.";

    // बिना लाइसेंस के, केवल पहले पाँच अक्षर लौटाए जाते हैं।
    console.log("Text read back:", rectangle.textFrame.text);

    // फ़ाइल की हर स्लाइड में मूल्यांकन वॉटरमार्क जोड़ता है।
    presentation.save("evaluation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}

const savedPresentation = new Presentation("evaluation.pptx");
try {
    // अब स्लाइड में आयत और वॉटरमार्क टेक्स्ट बॉक्स दोनों होते हैं।
    console.log("Shapes on the saved slide:", savedPresentation.slides.get(0).shapes.count);
} finally {
    savedPresentation.dispose();
}
```

लाइसेंस के बिना, स्क्रिप्ट प्रिंट करती है:

```text
Text read back: Quart... text has been truncated due to evaluation version limitation.
Shapes on the saved slide: 2
```

दूसरा आकार वॉटरमार्क टेक्स्ट बॉक्स है। `evaluation.pptx` खोलें ताकि आयत में पूरा वाक्य और स्लाइड के मध्य में वॉटरमार्क देखें।

## **अक्सर पूछे जाने वाले प्रश्न**

**क्या मूल्यांकन मोड स्लाइडों की संख्या को सीमित करता है?**  
नहीं। प्रस्तुतियों को उनकी सभी स्लाइडों के साथ बनाया, खोला और सहेजा जाता है। वॉटरमार्क और टेक्स्ट ट्रंकेशन प्रत्येक स्लाइड पर समान रूप से लागू होते हैं।

**मेरे निर्यातित स्लाइड चित्रों में वॉटरमार्क दो बार क्यों दिखता है?**  
प्रस्तुति को रेंडर करने से पहले मूल्यांकन मोड में सहेजा गया था, इसलिए उसमें पहले से ही एक वॉटरमार्क टेक्स्ट बॉक्स होता है, और लाइसेंस के बिना रेंडर करने पर उस पर एक और वॉटरमार्क खींचा जाता है।

**क्या मैं मूल्यांकन मोड में अपने कोड द्वारा सही टेक्स्ट उत्पन्न होने की जाँच कर सकता हूँ?**  
हां। सहेजी गई फ़ाइल या निर्यातित PDF खोलें: उनमें पूरा टेक्स्ट रहता है। केवल वह टेक्स्ट जो आपका कोड पढ़ता है, और Markdown या HTML5 आउटपुट, कटे हुए होते हैं।
