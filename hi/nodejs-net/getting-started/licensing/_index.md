## **अवलोकन**

Aspose.Slides for Node.js via .NET एक npm पैकेज है जो मूल्यांकन और उत्पादन दोनों के लिए है। बिना लाइसेंस के, यह मूल्यांकन मोड में चलता है। जब आप लाइसेंस खरीदते हैं, या एक मुफ्त 30-दिन का अस्थायी लाइसेंस प्राप्त करते हैं, तो आप इसे कुछ लाइनों कोड से लागू करते हैं, और मूल्यांकन सीमाएँ अब लागू नहीं रहतीं।

## **मूल्यांकन संस्करण सीमाएँ**

मूल्यांकन संस्करण उत्पाद की पूरी कार्यक्षमता प्रदान करता है, लेकिन दो सीमाओं के साथ:

- **Watermark.** प्रत्येक प्रस्तुति की प्रत्येक स्लाइड पर जब आप इसे सहेजते हैं तो एक मूल्यांकन वॉटरमार्क जुड़ जाता है: स्लाइड के मध्य में एक लॉक किया हुआ टेक्स्ट बॉक्स जिसमें लिखा होता है "Evaluation only." यही वॉटरमार्क PDF, XPS और HTML निर्यात तथा स्लाइड छवियों पर भी दिखाई देता है।
- **Truncated text.** कोड द्वारा टेक्स्ट फ्रेम, पैराग्राफ या भाग से पढ़ा गया टेक्स्ट उसके पहले पाँच अक्षरों तक सीमित रहता है, उसके बाद लिखा होता है "... text has been truncated due to evaluation version limitation." Markdown और HTML5 निर्यात भी इसी तरह सीमित होते हैं। आपका कोड जो टेक्स्ट लिखता है वह पूर्ण रूप से सहेजा जाता है।

[Evaluate Aspose.Slides](/slides/hi/nodejs-net/evaluate-aspose-slides/) दोनों सीमाओं का विस्तृत विवरण देता है और एक स्क्रिप्ट शामिल करता है जो उन्हें दिखाता है।

## **लाइसेंस के बारे में**

लाइसेंस एक सामान्य-टेक्स्ट XML फ़ाइल है जिसमें उत्पाद का नाम, लाइसेंस योग्य डेवलपर्स की संख्या, और सब्सक्रिप्शन समाप्ति तिथि जैसी विवरण होते हैं। फ़ाइल डिजिटल साइन की गई है, इसलिए इसे न बदलें: गलती से जो भी अतिरिक्त लाइन ब्रेक जोड़ दिया जाता है, वह इसे अमान्य कर देता है।

## **लाइसेंस लागू करें**

लाइसेंस को `License` क्लास की `setLicense` मेथड से लागू करें। इस मेथड को प्रक्रिया (process) में एक बार कॉल करें, किसी भी `Presentation` ऑब्जेक्ट को बनाने से पहले। इसे फिर से कॉल करने से कोई नुकसान नहीं होता, लेकिन यह पहले किए गए काम को दोहराता है।

निम्नलिखित स्क्रिप्ट `Aspose.Slides.lic` नामक फ़ाइल से लाइसेंस लागू करती है। नाम को अपने लाइसेंस फ़ाइल के नाम या पूर्ण पथ से बदलें; फ़ाइल का नाम कुछ भी हो सकता है।

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { License } = asposeSlides;

const license = new License();
try {
    license.setLicense("Aspose.Slides.lic");
    console.log("License applied.");
} catch (error) {
    console.log("License not applied:", error.message);
}
```

फ़ाइल नाम या सापेक्ष पथ वर्तमान फ़ोल्डर के सापेक्ष हल किया जाता है, वह फ़ोल्डर जिसमें आप `node` चलाते हैं। लाइसेंस फ़ाइल को अपने प्रोजेक्ट फ़ोल्डर में रखें और अपनी स्क्रिप्ट्स वहीं से चलाएँ, या पूर्ण पथ प्रदान करें।

यदि फ़ाइल नहीं मिलती या वह वैध लाइसेंस नहीं है, तो `setLicense` एक त्रुटि फेंकता है, और Aspose.Slides मूल्यांकन मोड में रहता है। स्क्रिप्ट त्रुटि को पकड़ी है और उसका संदेश प्रदर्शित करती है। यदि फ़ाइल अनुपलब्ध है, तो संदेश `License "Aspose.Slides.lic" doesn't exist or access is restricted.` से शुरू होता है और सभी खोजी गई स्थितियों को सूचीबद्ध करता है।

इस पैकेज में, लाइसेंस केवल फ़ाइल से ही लागू किया जाता है। `License` स्ट्रीम को स्वीकार नहीं करता, और पैकेज मीटरड लाइसेंसिंग को उजागर नहीं करता। जिस क्लास को पैकेज रैप करता है, उसके लिए देखें [License](https://reference.aspose.com/slides/hi/net/aspose.slides/license/) Aspose.Slides for .NET API रेफ़रेंस में।
