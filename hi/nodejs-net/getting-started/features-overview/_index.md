## **समर्थित प्लेटफ़ॉर्म**
Aspose.Slides for Node.js via .NET एक प्लेटफ़ॉर्म स्वतंत्र API है। इसे किसी भी प्लेटफ़ॉर्म (Windows, Linux, MacOS, आदि) पर उपयोग किया जा सकता है जहाँ Node.js 7 या उससे उच्च संस्करण स्थापित हो। Oracle JDK 8 या उससे अधिक संस्करण भी एक आवश्यकता है।

## **फ़ाइल फ़ॉर्मेट और रूपांतरण**

|**फ़ीचर**|**विवरण**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET इस प्रस्तुति दस्तावेज़ फ़ॉर्मेट के लिए सबसे तेज़ प्रोसेसिंग प्रदान करता है।|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET PPT से PPTX रूपांतरण का समर्थन करता है|
|Portable Document Format (PDF)|आप सभी समर्थित फ़ाइल फ़ॉर्मेट को एक ही मेथड से Adobe Portable Document Format (PDF) दस्तावेज़ों में निर्यात कर सकते हैं।|
|XML Parser Specification (XPS)|आप सभी समर्थित फ़ाइल फ़ॉर्मेट को एक ही मेथड से XML Parser Specification (XPS) दस्तावेज़ों में निर्यात कर सकते हैं।|
|Tagged Image File Format (TIFF)|आप सभी समर्थित प्रस्तुति फ़ाइल फ़ॉर्मेट को Tagged Image File Format (TIFF) में निर्यात कर सकते हैं।|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET PresentationEx को HTML फ़ॉर्मेट में रूपांतरण का समर्थन करता है।|

## **प्रेज़ेंटेशन रेंडरिंग**
Aspose.Slides for Node.js via .NET प्रेज़ेंटेशन में स्लाइड्स की उच्च गुणवत्ता वाली रेंडरिंग को विभिन्न ग्राफ़िक्स फ़ॉर्मेट में समर्थन करता है। इन विवरणों को देखें:

|**फ़ीचर**|**विवरण**|
| :- | :- |
|.NET Supported Image Formats|Aspose.Slides for Node.js via .NET का उपयोग करके, आप प्रस्तुति स्लाइड्स और स्लाइड्स पर छवियों को सभी .NET समर्थित ग्राफ़िक्स फ़ॉर्मेट जैसे TIFF, PNG, BMP, JPEG, GIF में रेंडर कर सकते हैं।|
|SVG Format|Aspose.Slides for Node.js via .NET बिल्ट‑इन मेथड्स भी प्रदान करता है जो आपको प्रस्तुति स्लाइड्स को Scalable Vector Graphics (SVG) फ़ॉर्मेट में निर्यात करने देते हैं।|
