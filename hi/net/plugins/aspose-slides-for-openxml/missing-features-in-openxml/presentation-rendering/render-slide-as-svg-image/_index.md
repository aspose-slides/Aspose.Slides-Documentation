SVG—Scalable Vector Graphics का संक्षिप्त रूप है—एक मानक ग्राफिक्स प्रकार या फ़ॉर्मेट है जिसका उपयोग द्वि‑आयामी छवियों को रेंडर करने के लिए किया जाता है। SVG छवियों को XML में वेक्टर के रूप में संग्रहीत करता है, जिसमें उनके व्यवहार या रूप‑रेखा को परिभाषित करने वाले विवरण होते हैं।  

SVG उन कुछ छवि फ़ॉर्मेट्स में से एक है जो इन पहलुओं में अत्यधिक मानदंडों को पूरा करता है: स्केलेबिलिटी, इंटरएक्टिविटी, प्रदर्शन, एक्सेसेबिलिटी, प्रोग्रामेबिलिटी आदि। इन कारणों से, इसे वेब विकास में आमतौर पर उपयोग किया जाता है।  

आप निम्नलिखित परिस्थितियों में SVG फ़ाइलों का उपयोग करना चाह सकते हैं:

- जब आप अपनी प्रस्तुति को बहुत बड़े फ़ॉर्मेट में प्रिंट करने की योजना बनाते हैं। SVG छवियों को किसी भी रिज़ॉल्यूशन या स्तर तक स्केल किया जा सकता है। आप आवश्यकतानुसार SVG छवियों का आकार कई बार बदल सकते हैं, गुणवत्ता को प्रभावित किए बिना।  
- जब आप अपनी स्लाइड्स के चार्ट और ग्राफ़ को विभिन्न माध्यमों या प्लेटफ़ॉर्म पर उपयोग करने का इरादा रखते हैं। अधिकांश रीडर SVG फ़ाइलों को पढ़ सकते हैं।  
- जब आपको छवियों का सबसे छोटा संभव आकार चाहिए। SVG फ़ाइलें आमतौर पर अन्य फ़ॉर्मेट्स में उनके उच्च‑रिज़ॉल्यूशन समकक्षों से छोटी होती हैं, विशेष रूप से बिटमैप (JPEG या PNG) पर आधारित फ़ॉर्मेट्स।  

Aspose.Slides for .NET आपको आपकी प्रस्तुतियों की स्लाइड्स को **SVG** छवियों के रूप में एक्सपोर्ट करने की अनुमति देता है। किसी भी स्लाइड से SVG छवि बनाने के लिए, यह करें:

- Presentation क्लास का एक इंस्टेंस बनाएं।  
- प्रेजेंटेशन में सभी स्लाइड्स पर इटरट करें।  
- प्रत्येक स्लाइड को FileStream के माध्यम से अपनी स्वयं की SVG फ़ाइल में लिखें।  

{{% alert color="info" %}} 
आप हमारे [नि:शुल्क वेब एप्लिकेशन](https://products.aspose.app/slides/hi/conversion/ppt-to-svg) को आज़माना चाह सकते हैं, जिसमें हमने Aspose.Slides for .NET से PPT को SVG में परिवर्तन फ़ंक्शन लागू किया है। 
{{% /alert %}} 

``` csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("pres.pptx"))
{
    for (var index = 0; index < pres.Slides.Count; index++)
    {
        ISlide slide = pres.Slides[index];

        using (FileStream fileStream = new FileStream($"slide-{index}.svg", FileMode.Create, FileAccess.Write))
        {
            slide.WriteAsSvg(fileStream);   
        }
    }
}
```
