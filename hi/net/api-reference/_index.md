{{% alert color="info" %}}

Aspose.Slides for .NET एक क्लास लाइब्रेरी है जो .NET एप्लिकेशन को Microsoft PowerPoint® या अन्य अनुप्रयोगों का उपयोग किए बिना प्रेजेंटेशन दस्तावेज़ पढ़ने और लिखने की सुविधा देती है। Aspose.Slides for .NET पाठ, आकृतियों, तालिकाओं और एनीमेशन को प्रबंधित करने, स्लाइड्स में ऑडियो और वीडियो जोड़ने, स्लाइड्स का पूर्वावलोकन करने, स्लाइड्स को SVG, PDF फ़ॉर्मेट में निर्यात करने और अधिक करने की अनुमति देता है।

नवीनतम API रेफ़रेंस यहाँ पाया जा सकता है: [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/hi/net).
