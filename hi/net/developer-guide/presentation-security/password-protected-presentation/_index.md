## **परिचय**

जब आप एक प्रस्तुति को पासवर्ड‑रक्षित करते हैं, तो इसका अर्थ है कि आप एक पासवर्ड सेट कर रहे हैं जो प्रस्तुति पर कुछ प्रतिबंध लागू करता है। इन प्रतिबंधों को हटाने के लिए पासवर्ड दर्ज करना आवश्यक है। पासवर्ड‑रक्षित प्रस्तुति को लॉक्ड प्रस्तुति माना जाता है।

आमतौर पर, आप प्रस्तुति पर इन प्रतिबंधों को लागू करने के लिए पासवर्ड सेट कर सकते हैं:

- **संशोधन**

  यदि आप चाहते हैं कि केवल कुछ उपयोगकर्ता आपकी प्रस्तुति को संशोधित कर सकें, तो आप संशोधन प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध लोगों को आपके प्रस्तुतिकरण के तत्वों को संशोधित, बदलने या कॉपी करने से रोकता है जब तक वे पासवर्ड प्रदान न करें।  

  हालांकि, पासवर्ड के बिना भी उपयोगकर्ता आपके दस्तावेज़ को एक्सेस कर सकते हैं और खोल सकते हैं। इस केवल‑पढ़ने मोड में, उपयोगकर्ता सामग्री—हाइपरलिंक, एनीमेशन, इफेक्ट और अन्य तत्वों सहित—को देख सकता है, लेकिन आइटम कॉपी नहीं कर सकता या प्रस्तुति सहेज नहीं सकता।

- **खोलना**

  यदि आप चाहते हैं कि केवल कुछ उपयोगकर्ता आपकी प्रस्तुति खोल सकें, तो आप खोलने का प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध लोगों को आपके प्रस्तुतिकरण की सामग्री देख ही नहीं देता जब तक वे पासवर्ड न दें।

  तकनीकी रूप से, खोलने का प्रतिबंध उपयोगकर्ताओं को आपकी प्रस्तुतियों को संशोधित करने से भी रोकता है—यदि लोग प्रस्तुति नहीं खोल सकते, तो वे इसे संशोधित या बदल नहीं सकते।

**ध्यान दें:** जब आप प्रस्तुति को खोलने से रोकने के लिए पासवर्ड‑रक्षित करते हैं, तो प्रस्तुति फ़ाइल एन्क्रिप्ट हो जाती है।

## **Aspose.Slides में पासवर्ड सुरक्षा**

**समर्थित फ़ॉर्मेट**

Aspose.Slides इन फ़ॉर्मेट में प्रस्तुतियों के लिए पासवर्ड सुरक्षा, एन्क्रिप्शन और समान कार्यों का समर्थन करता है:

- PPTX और PPT – Microsoft PowerPoint प्रस्तुतियाँ
- ODP – OpenDocument प्रस्तुतियाँ
- OTP – OpenDocument प्रस्तुति टेम्पलेट्स

**समर्थित ऑपरेशन्स**

Aspose.Slides आपको निम्नलिखित तरीकों से संशोधन को रोकने के लिए प्रस्तुतियों पर पासवर्ड सुरक्षा का उपयोग करने की अनुमति देता है:

- प्रस्तुति को एन्क्रिप्ट करना
- प्रस्तुति पर राइट प्रोटेक्शन सेट करना

**अन्य ऑपरेशन्स**

Aspose.Slides आपको पासवर्ड सुरक्षा और एन्क्रिप्शन से संबंधित अतिरिक्त कार्य करने की अनुमति देता है:

- प्रस्तुति को डिक्रिप्ट करना; एन्क्रिप्टेड प्रस्तुति खोलना
- एन्क्रिप्शन हटाना; पासवर्ड सुरक्षा अक्षम करना
- प्रस्तुति से राइट प्रोटेक्शन हटाना
- एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ प्राप्त करना
- लोड करने से पहले यह जांचना कि प्रस्तुति पासवर्ड‑रक्षित है या नहीं
- यह जांचना कि प्रस्तुति एन्क्रिप्टेड है या नहीं
- यह जांचना कि प्रस्तुति पासवर्ड‑रक्षित है या नहीं

## **एक प्रस्तुति को पासवर्ड से सुरक्षित करें**

आप पासवर्ड सेट करके एक प्रस्तुति को एन्क्रिप्ट कर सकते हैं। फिर, लॉक्ड प्रस्तुति को संशोधित करने के लिए उपयोगकर्ता को पासवर्ड प्रदान करना होगा।

एक प्रस्तुति को एन्क्रिप्ट (या पासवर्ड‑रक्षित) करने के लिए, [ProtectionManager](https://reference.aspose.com/slides/hi/net/aspose.slides/protectionmanager) की `Encrypt` मेथड का उपयोग करके पासवर्ड सेट करें। पासवर्ड को `Encrypt` मेथड में पास करें, फिर अब एन्क्रिप्ट की गई प्रस्तुति को सहेजने के लिए `Save` मेथड का उपयोग करें।

यह नमूना कोड दिखाता है कि कैसे एक प्रस्तुति को एन्क्रिप्ट किया जाए:

```c#
using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.Encrypt("123123");
    presentation.Save("encrypted-pres.pptx", SaveFormat.Pptx);
}
```

## **प्रेजेंटेशन पर राइट प्रोटेक्शन सेट करें** 

आप एक प्रस्तुति में "Do not modify" जैसा चिह्न जोड़ सकते हैं। यह उपयोगकर्ताओं को बताता है कि आप चाहते हैं कि वे प्रस्तुति में बदलाव न करें।

**ध्यान दें:** राइट प्रोटेक्शन प्रक्रिया प्रस्तुति को एन्क्रिप्ट नहीं करती। इसलिए, उपयोगकर्ता—यदि वे चाहें—प्रस्तुति को संशोधित कर सकते हैं, लेकिन परिवर्तन सहेजने के लिए उन्हें अलग नाम से सहेजना पड़ेगा।

राइट प्रोटेक्शन सेट करने के लिए, `SetWriteProtection` मेथड का उपयोग करें। यह नमूना कोड दिखाता है कि कैसे एक प्रस्तुति पर राइट प्रोटेक्शन सेट किया जाए:

```c#
using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.SetWriteProtection("123123");
    presentation.Save("write-protected-pres.pptx", SaveFormat.Pptx);
}
```

## **एनक्रिप्टेड प्रस्तुति लोड करें**

Aspose.Slides आपको सही पासवर्ड प्रदान करके एक एन्क्रिप्टेड प्रस्तुति लोड करने की अनुमति देता है। यह नमूना कोड दिखाता है कि कैसे एक एन्क्रिप्टेड प्रस्तुति लोड की जाए:

```c#
LoadOptions loadOptions = new LoadOptions { Password = "123123" };
using (Presentation presentation = new Presentation("pres.pptx", loadOptions))
{
    // डिक्रिप्टेड प्रस्तुति के साथ काम करें।
}
```

## **प्रेजेंटेशन से एन्क्रिप्शन हटाएं**

आप प्रस्तुति से एन्क्रिप्शन या पासवर्ड सुरक्षा हटा सकते हैं, जिससे उपयोगकर्ता बिना किसी प्रतिबंध के उसे एक्सेस या संशोधित कर सकें।

एन्क्रिप्शन या पासवर्ड सुरक्षा हटाने के लिए, [RemoveEncryption](https://reference.aspose.com/slides/hi/net/aspose.slides/protectionmanager/methods/removeencryption) मेथड को कॉल करें। यह नमूना कोड दिखाता है कि कैसे प्रस्तुति से एन्क्रिप्शन हटाया जाए:

```c#
LoadOptions loadOptions = new LoadOptions { Password = "123123" };
using (Presentation presentation = new Presentation("pres.pptx", loadOptions))
{
    presentation.ProtectionManager.RemoveEncryption();
    presentation.Save("encryption-removed.pptx", SaveFormat.Pptx);
}
```

## **प्रेजेंटेशन से राइट प्रोटेक्शन हटाएं**

आप Aspose.Slides का उपयोग करके प्रस्तुति फ़ाइल से राइट प्रोटेक्शन हटा सकते हैं। इस तरह, उपयोगकर्ता इसे अपनी इच्छा अनुसार संशोधित कर सकते हैं—और इस प्रक्रिया में उन्हें कोई चेतावनी नहीं मिलेगी।

राइट प्रोटेक्शन हटाने के लिए, [RemoveWriteProtection](https://reference.aspose.com/slides/hi/net/aspose.slides/protectionmanager/methods/removewriteprotection) मेथड का उपयोग करें। यह नमूना कोड दिखाता है कि कैसे प्रस्तुति से राइट प्रोटेक्शन हटाया जाए:

```c#
using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.RemoveWriteProtection();
    presentation.Save("write-protection-removed.pptx", SaveFormat.Pptx);
}
```

## **एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ प्राप्त करें**

आम तौर पर, उपयोगकर्ताओं को एन्क्रिप्टेड या पासवर्ड‑रक्षित प्रस्तुति की डॉक्युमेंट प्रॉपर्टीज़ प्राप्त करने में कठिनाई होती है। हालांकि, Aspose.Slides एक तंत्र प्रदान करता है जो आपको प्रस्तुति को पासवर्ड‑रक्षित रखने के साथ-साथ उपयोगकर्ताओं को उसकी प्रॉपर्टीज़ तक पहुँच प्रदान करता है।

**ध्यान दें:** डिफ़ॉल्ट रूप से, जब Aspose.Slides एक प्रस्तुति को एन्क्रिप्ट करता है, तो प्रस्तुति की डॉक्युमेंट प्रॉपर्टीज़ भी पासवर्ड‑रक्षित हो जाती हैं। यदि आपको एन्क्रिप्शन के बाद भी डॉक्युमेंट प्रॉपर्टीज़ को एक्सेस करने योग्य बनाना है, तो Aspose.Slides यह करने की अनुमति देता है।

यदि आप चाहते हैं कि उपयोगकर्ता एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ तक पहुँच बनाए रखें, तो [IProtectionManager](https://reference.aspose.com/slides/hi/net/aspose.slides/iprotectionmanager/) की `EncryptDocumentProperties` प्रॉपर्टी को `false` सेट करें। यह नमूना कोड दिखाता है कि कैसे प्रस्तुति को एन्क्रिप्ट करते हुए भी उपयोगकर्ताओं को उसकी डॉक्युमेंट प्रॉपर्टीज़ तक पहुँच प्रदान की जाए:

```c#
using var presentation = new Presentation("pres.pptx");

presentation.ProtectionManager.EncryptDocumentProperties = false;
presentation.ProtectionManager.Encrypt("123123");
presentation.Save("encrypted-pres.pptx", SaveFormat.Pptx);
```

## **एन्क्रिप्टेड प्रस्तुति से केवल डॉक्युमेंट प्रॉपर्टीज़ लोड करें**

एन्क्रिप्टेड प्रस्तुति की स्लाइड्स या अन्य सामग्री लोड किए बिना उसकी मेटाडेटा की जाँच करने के लिए, एक [LoadOptions](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/) ऑब्जेक्ट बनाएं और [OnlyLoadDocumentProperties](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/onlyloaddocumentproperties/) को `true` सेट करें। इस मोड में, Aspose.Slides पासवर्ड को अनदेखा करता है और केवल सार्वजनिक रूप से उपलब्ध डॉक्युमेंट प्रॉपर्टीज़ लोड करता है।

निम्नलिखित कोड उदाहरण [IPresentation.DocumentProperties](https://reference.aspose.com/slides/hi/net/aspose.slides/ipresentation/documentproperties/) के माध्यम से निर्मित और कस्टम डॉक्युमेंट प्रॉपर्टीज़ पढ़ता है:

```c#
var loadOptions = new LoadOptions
{
    OnlyLoadDocumentProperties = true
};

using var presentation = new Presentation("encrypted-pres.pptx", loadOptions);
var documentProperties = presentation.DocumentProperties;

// Read built-in document properties.
Console.WriteLine("Title: " + documentProperties.Title);
Console.WriteLine("Author: " + documentProperties.Author);

// Read custom document properties.
var customPropertyCount = documentProperties.CountOfCustomProperties;

for (var propertyIndex = 0; propertyIndex < customPropertyCount; propertyIndex++)
{
    var propertyName = documentProperties.GetCustomPropertyName(propertyIndex);
    var propertyValue = documentProperties[propertyName];

    Console.WriteLine(propertyName + ": " + propertyValue);
}
```

यह कार्यप्रवाह केवल तभी काम करता है जब डॉक्युमेंट प्रॉपर्टीज़ एन्क्रिप्ट नहीं की गई हों (सार्वजनिक) और प्रस्तुति एन्क्रिप्ट की गई हो। यदि डॉक्युमेंट प्रॉपर्टीज़ एन्क्रिप्ट की गई हों, तो `OnlyLoadDocumentProperties` को `true` सेट करने से एक अपवाद उत्पन्न होगा क्योंकि इस मोड में पासवर्ड अनदेखा किया जाता है। एन्क्रिप्टेड डॉक्युमेंट प्रॉपर्टीज़ तक पहुँचने या पूरी प्रस्तुति, जिसमें उसकी स्लाइड्स और अन्य सामग्री शामिल हैं, लोड करने के लिए, [LoadOptions](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/) में सही `Password` मान प्रदान करें।

## **जाँचें कि प्रस्तुति पासवर्ड‑रक्षित है या नहीं**

प्रेजेंटेशन लोड करने से पहले, आप यह जाँचना चाह सकते हैं कि वह पासवर्ड‑रक्षित तो नहीं है। यह आपको उस स्थिति में त्रुटियों और समान समस्याओं से बचने में मदद करता है जब पासवर्ड‑रक्षित प्रस्तुति सही पासवर्ड के बिना लोड की जाती है।

यह C# कोड दिखाता है कि कैसे एक प्रस्तुति को लोड किए बिना यह जांचा जाए कि वह पासवर्ड‑रक्षित है या नहीं:

```c#
var presentationInfo = PresentationFactory.Instance.GetPresentationInfo("example.pptx");
Console.WriteLine("The presentation is password protected: " + presentationInfo.IsPasswordProtected);
```

## **जाँचें कि प्रस्तुति एन्क्रिप्टेड है या नहीं**
