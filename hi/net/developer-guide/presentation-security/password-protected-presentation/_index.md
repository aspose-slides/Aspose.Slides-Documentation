## **परिचय**

जब आप किसी प्रस्तुति को पासवर्ड‑प्रोटेक्ट करते हैं, इसका मतलब है कि आप एक पासवर्ड सेट कर रहे हैं जो प्रस्तुति पर कुछ प्रतिबंध लागू करता है। इन प्रतिबंधों को हटाने के लिए पासवर्ड दर्ज करना आवश्यक है। पासवर्ड‑सुरक्षित प्रस्तुति को लॉक्ड प्रस्तुति माना जाता है।

सामान्यतः, आप प्रस्तुति पर इन प्रतिबंधों को लागू करने के लिए पासवर्ड सेट कर सकते हैं:

- **संशोधन**

यदि आप केवल कुछ उपयोगकर्ताओं को अपनी प्रस्तुति में बदलाव करने देना चाहते हैं, तो आप संशोधन प्रतिबंध सेट कर सकते हैं। यह प्रतिबंध तब तक लोगों को प्रस्तुति के तत्वों को संशोधित, बदलने या कॉपी करने से रोकता है जब तक वे पासवर्ड नहीं देते।

हालांकि, बिना पासवर्ड के भी उपयोगकर्ता आपके दस्तावेज़ को एक्सेस कर सकता है और खोल सकता है। इस केवल‑पढ़ने मोड में, उपयोगकर्ता सामग्री—हाइपरलिंक, एनीमेशन, इफ़ेक्ट और अन्य तत्व सहित—देख सकता है, लेकिन वह आइटम कॉपी नहीं कर सकता या प्रस्तुति को सहेज नहीं सकता।

- **खोलना**

यदि आप केवल कुछ उपयोगकर्ताओं को अपनी प्रस्तुति खोलने देना चाहते हैं, तो आप खोलने का प्रतिबंध सेट करें। यह प्रतिबंध तब तक लोगों को आपकी प्रस्तुति की सामग्री देखना भी रोकता है जब तक वे पासवर्ड नहीं प्रदान करते।

तकनीकी रूप से, खोलने का प्रतिबंध उपयोगकर्ताओं को आपकी प्रस्तुति संशोधित करने से भी रोकता है—यदि लोग प्रस्तुति नहीं खोल सकते, तो वे इसे संशोधित या बदल नहीं सकते।

**नोट:** जब आप प्रस्तुति को खोलने से रोकने के लिए पासवर्ड‑प्रोटेक्ट करते हैं, तो प्रस्तुति फ़ाइल एन्क्रिप्ट हो जाती है।

## **Aspose.Slides में पासवर्ड सुरक्षा**

**समर्थित प्रारूप**

- PPTX और PPT – Microsoft PowerPoint प्रस्तुतियां
- ODP – OpenDocument प्रस्तुतियां
- OTP – OpenDocument प्रस्तुति टेम्पलेट्स

**समर्थित संचालन**

Aspose.Slides आपको प्रस्तुतियों पर पासवर्ड सुरक्षा का उपयोग करके संशोधनों को रोकने के लिए निम्नलिखित तरीकों की अनुमति देता है:

- प्रस्तुति को एन्क्रिप्ट करना
- प्रस्तुति पर लिखने की सुरक्षा सेट करना

**अन्य संचालन**

Aspose.Slides आपको पासवर्ड सुरक्षा और एन्क्रिप्शन से जुड़े अतिरिक्त कार्य करने की अनुमति देता है निम्नलिखित तरीकों से:

- प्रस्तुति को डिक्रिप्ट करना; एन्क्रिप्टेड प्रस्तुति खोलना
- एन्क्रिप्शन हटाना; पासवर्ड सुरक्षा अक्षम करना
- प्रस्तुति से लिखने की सुरक्षा हटाना
- एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ प्राप्त करना
- लोड करने से पहले जाँचना कि प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं
- जाँचना कि प्रस्तुति एन्क्रिप्टेड है या नहीं
- जाँचना कि प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं

## **पासवर्ड से प्रस्तुति सुरक्षित करें**

आप पासवर्ड सेट करके एक प्रस्तुति को एन्क्रिप्ट कर सकते हैं। फिर, लॉक्ड प्रस्तुति को संशोधित करने के लिए उपयोगकर्ता को पासवर्ड प्रदान करना होगा।

प्रस्तुति को एन्क्रिप्ट (या पासवर्ड‑प्रोटेक्ट) करने के लिए, पासवर्ड सेट करने हेतु [ProtectionManager](https://reference.aspose.com/slides/hi/net/aspose.slides/protectionmanager) की `Encrypt` मेथड का उपयोग करें। पासवर्ड को `Encrypt` मेथड में पास करें, फिर एन्क्रिप्टेड प्रस्तुति को सहेजने के लिए `Save` मेथड का उपयोग करें।

यह उदाहरण कोड दर्शाता है कि प्रस्तुति को कैसे एन्क्रिप्ट करें:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.Encrypt("123123");
    presentation.Save("encrypted-pres.pptx", SaveFormat.Pptx);
}
```

## **प्रेज़ेंटेशन पर लिखने की सुरक्षा सेट करें** 

आप प्रस्तुति में "Do not modify" (संशोधन न करें) का चिह्न जोड़ सकते हैं। यह उपयोगकर्ताओं को बताता है कि आप उन्हें प्रस्तुति में परिवर्तन नहीं करने देना चाहते हैं।

**नोट:** लिखने की सुरक्षा प्रक्रिया प्रस्तुति को एन्क्रिप्ट नहीं करती। इसलिए, उपयोगकर्ता—यदि वे चाहें—प्रस्तुति को संशोधित कर सकते हैं, लेकिन परिवर्तन सहेजने के लिए उन्हें अलग नाम से सहेजना पड़ेगा।

लिखने की सुरक्षा सेट करने के लिए, `SetWriteProtection` मेथड का उपयोग करें। यह उदाहरण कोड दर्शाता है कि प्रस्तुति पर लिखने की सुरक्षा कैसे सेट करें:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.SetWriteProtection("123123");
    presentation.Save("write-protected-pres.pptx", SaveFormat.Pptx);
}
```

## **एन्क्रिप्टेड प्रस्तुति लोड करें**

Aspose.Slides आपको सही पासवर्ड पास करके एन्क्रिप्टेड प्रस्तुति लोड करने देता है। यह उदाहरण कोड दर्शाता है कि एन्क्रिप्टेड प्रस्तुति को कैसे लोड करें:

```c#
using Aspose.Slides;

LoadOptions loadOptions = new LoadOptions { Password = "123123" };
using (Presentation presentation = new Presentation("pres.pptx", loadOptions))
{
    // डिक्रिप्टेड प्रस्तुति के साथ काम करें.
}
```

## **प्रेज़ेंटेशन से एन्क्रिप्शन हटाएँ**

आप प्रस्तुति से एन्क्रिप्शन या पासवर्ड सुरक्षा हटाकर उपयोगकर्ताओं को बिना किसी प्रतिबंध के उसे एक्सेस या संशोधित करने दे सकते हैं।

एन्क्रिप्शन या पासवर्ड सुरक्षा हटाने के लिए, [RemoveEncryption](https://reference.aspose.com/slides/hi/net/aspose.slides/protectionmanager/methods/removeencryption) मेथड को कॉल करें। यह कोड दर्शाता है कि प्रस्तुति से एन्क्रिप्शन कैसे हटाएँ:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

LoadOptions loadOptions = new LoadOptions { Password = "123123" };
using (Presentation presentation = new Presentation("pres.pptx", loadOptions))
{
    presentation.ProtectionManager.RemoveEncryption();
    presentation.Save("encryption-removed.pptx", SaveFormat.Pptx);
}
```

## **प्रेज़ेंटेशन से लिखने की सुरक्षा हटाएँ**

आप Aspose.Slides का उपयोग करके प्रस्तुति फ़ाइल से लिखने की सुरक्षा हटा सकते हैं। इस तरह, उपयोगकर्ता इसे अपनी इच्छानुसार संशोधित कर सकते हैं—और उन्हें ऐसी क्रियाओं पर कोई चेतावनी नहीं मिलेगी।

लिखने की सुरक्षा को हटाने के लिए, आप [RemoveWriteProtection](https://reference.aspose.com/slides/hi/net/aspose.slides/protectionmanager/methods/removewriteprotection) मेथड का उपयोग कर सकते हैं। यह उदाहरण कोड दर्शाता है कि प्रस्तुति से लिखने की सुरक्षा कैसे हटाएँ:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation("pres.pptx"))
{
    presentation.ProtectionManager.RemoveWriteProtection();
    presentation.Save("write-protection-removed.pptx", SaveFormat.Pptx);
}
```

## **एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ प्राप्त करें**

सामान्यतः, उपयोगकर्ताओं को एन्क्रिप्टेड या पासवर्ड‑सुरक्षित प्रस्तुति की डॉक्यूमेंट प्रॉपर्टीज़ प्राप्त करने में कठिनाई होती है। हालांकि, Aspose.Slides एक तंत्र प्रदान करता है जो आपको प्रस्तुति को पासवर्ड‑सेक्योर करने की अनुमति देता है जबकि उपयोगकर्ता अभी भी उसकी प्रॉपर्टीज़ तक पहुंच सकें।

**नोट:** डिफ़ॉल्ट रूप से, जब Aspose.Slides प्रस्तुति को एन्क्रिप्ट करता है, तो प्रस्तुति की डॉक्यूमेंट प्रॉपर्टीज़ भी पासवर्ड‑सुरक्षित हो जाती हैं। यदि आपको एन्क्रिप्शन के बाद भी डॉक्यूमेंट प्रॉपर्टीज़ को सुलभ बनाना है, तो Aspose.Slides यह करने की सुविधा देता है।

यदि आप चाहते हैं कि उपयोगकर्ता एन्क्रिप्टेड प्रस्तुति की प्रॉपर्टीज़ तक पहुंच बना रखें, तो [IProtectionManager](https://reference.aspose.com/slides/hi/net/aspose.slides/iprotectionmanager/) की `EncryptDocumentProperties` प्रॉपर्टी को `false` सेट करें। यह कोड दर्शाता है कि प्रस्तुति को एन्क्रिप्ट करते हुए उपयोगकर्ताओं को उसकी डॉक्यूमेंट प्रॉपर्टीज़ तक पहुंच कैसे प्रदान करें:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("pres.pptx");

presentation.ProtectionManager.EncryptDocumentProperties = false;
presentation.ProtectionManager.Encrypt("123123");
presentation.Save("encrypted-pres.pptx", SaveFormat.Pptx);
```

## **एन्क्रिप्टेड प्रस्तुति से केवल डॉक्यूमेंट प्रॉपर्टीज़ लोड करें**

एन्क्रिप्टेड प्रस्तुति की मेटाडाटा को उसकी स्लाइड्स या अन्य सामग्री लोड किए बिना जांचने के लिए, एक [LoadOptions](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/) ऑब्जेक्ट बनाएं और [OnlyLoadDocumentProperties](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/onlyloaddocumentproperties/) को `true` सेट करें। इस मोड में, Aspose.Slides पासवर्ड को नज़रअंदाज़ करता है और केवल सार्वजनिक रूप से उपलब्ध डॉक्यूमेंट प्रॉपर्टीज़ लोड करता है।

निम्नलिखित कोड उदाहरण [IPresentation.DocumentProperties](https://reference.aspose.com/slides/hi/net/aspose.slides/ipresentation/documentproperties/) के माध्यम से अंतर्निर्मित और कस्टम डॉक्यूमेंट प्रॉपर्टीज़ पढ़ता है:

```c#
using Aspose.Slides;

var loadOptions = new LoadOptions
{
    OnlyLoadDocumentProperties = true
};

using var presentation = new Presentation("encrypted-pres.pptx", loadOptions);
var documentProperties = presentation.DocumentProperties;

// निर्मित दस्तावेज़ गुण पढ़ें.
Console.WriteLine("Title: " + documentProperties.Title);
Console.WriteLine("Author: " + documentProperties.Author);

// कस्टम दस्तावेज़ गुण पढ़ें.
var customPropertyCount = documentProperties.CountOfCustomProperties;

for (var propertyIndex = 0; propertyIndex < customPropertyCount; propertyIndex++)
{
    var propertyName = documentProperties.GetCustomPropertyName(propertyIndex);
    var propertyValue = documentProperties[propertyName];

    Console.WriteLine(propertyName + ": " + propertyValue);
}
```

यह कार्यप्रवाह केवल तभी काम करता है जब प्रस्तुति एन्क्रिप्ट करते समय डॉक्यूमेंट प्रॉपर्टीज़ को एन्क्रिप्ट नहीं किया गया हो (सार्वजनिक)। यदि डॉक्यूमेंट प्रॉपर्टीज़ एन्क्रिप्टेड हैं, तो `OnlyLoadDocumentProperties` को `true` सेट करने से अपवाद उत्पन्न होता है क्योंकि इस मोड में पासवर्ड को नज़रअंदाज़ किया जाता है। एन्क्रिप्टेड डॉक्यूमेंट प्रॉपर्टीज़ तक पहुंचने या पूरी प्रस्तुति, जिसमें उसकी स्लाइड्स और अन्य सामग्री शामिल हैं, लोड करने के लिए, [LoadOptions](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/) में सही `Password` मान प्रदान करें।

## **जाँचें कि प्रस्तुति पासवर्ड‑सुरक्षित है या नहीं**

प्रस्तुति लोड करने से पहले, आप यह जाँचना चाह सकते हैं कि उसका पासवर्ड सुरक्षा नहीं लगा है। इससे आप त्रुटियों और समान समस्याओं से बच सकते हैं जो तब होती हैं जब सही पासवर्ड के बिना पासवर्ड‑सुरक्षित प्रस्तुति लोड की जाती है।

यह C# कोड दर्शाता है कि प्रस्तुति को वास्तव में लोड किए बिना यह जाँचें कि वह पासवर्ड‑सुरक्षित है या नहीं:

```c#
using Aspose.Slides;

var presentationInfo = PresentationFactory.Instance.GetPresentationInfo("example.pptx");
Console.WriteLine("The presentation is password protected: " + presentationInfo.IsPasswordProtected);
```

## **जाँचें कि प्रस्तुति एन्क्रिप्टेड है या नहीं**
