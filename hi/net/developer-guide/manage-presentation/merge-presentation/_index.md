## **अवलोकन**

Aspose.Slides आपको एक प्रस्तुति से दूसरी प्रस्तुति में स्लाइड्स को क्लोन करके प्रस्तुतियों को मिलाने की सुविधा देता है। यह लेख बताता है कि पूरी प्रस्तुतियों या चयनित स्लाइड्स को कैसे मिलाया जाए, मर्ज के दौरान स्लाइड मास्टर या विशिष्ट लेआउट का उपयोग कैसे किया जाए, विभिन्न स्लाइड आकार वाली प्रस्तुतियों को कैसे संभाला जाए, और मर्ज की गई स्लाइड्स को प्रस्तुति सेक्शन में कैसे जोड़ा जाए। यह मर्ज किए गए कंटेंट से संबंधित व्यावहारिक नोट्स को भी कवर करता है, जिसमें स्पीकर नोट्स, कमेंट्स, पासवर्ड‑प्रोटेक्टेड स्रोत फ़ाइलें, और थ्रेड उपयोग शामिल हैं।

## **अपनी प्रस्तुति मर्जिंग को अनुकूलित करें**

With [Aspose.Slides for .NET](https://products.aspose.com/slides/hi/net/), सहजता से PowerPoint प्रस्तुतियों को शैली, लेआउट और सभी तत्वों को संरक्षित रखते हुए मिलाएँ। अन्य उपकरणों के विपरीत, Aspose.Slides गुणवत्ता में कमी या डेटा खोए बिना प्रस्तुतियों को मिलाता है। पूरी प्रस्तुतियों, विशिष्ट स्लाइड्स, और विभिन्न फ़ाइल फ़ॉर्मेट (PPT से PPTX आदि) को भी मर्ज करें।

### **मर्जिंग विकल्प**

आप विकल्प लागू कर सकते हैं जो निर्धारित करते हैं कि

* आउटपुट प्रस्तुति की प्रत्येक स्लाइड अपनी विशिष्ट शैली बनाए रखे  
* सभी स्लाइड्स के लिए एक विशिष्ट शैली का उपयोग किया जाए।  

प्रस्तुतियों को मर्ज करने के लिए, Aspose.Slides [AddClone](https://reference.aspose.com/slides/hi/net/aspose.slides/islidecollection/methods/addclone) मेथड्स प्रदान करता है (जो [ISlideCollection](https://reference.aspose.com/slides/hi/net/aspose.slides/islidecollection) इंटरफ़ेस से आते हैं)। `AddClone` मेथड्स की कई कार्यान्वयन हैं जो प्रस्तुति मर्ज प्रक्रिया के पैरामीटर को परिभाषित करती हैं। प्रत्येक Presentation ऑब्जेक्ट में एक [Slides](https://reference.aspose.com/slides/hi/net/aspose.slides/presentation/properties/slides) संग्रह होता है, इसलिए आप उस प्रस्तुति से `AddClone` मेथड को कॉल कर सकते हैं जिसमें आप स्लाइड्स मर्ज करना चाहते हैं।  

`AddClone` मेथड एक `ISlide` ऑब्जेक्ट लौटाता है, जो स्रोत स्लाइड की क्लोन होती है। आउटपुट प्रस्तुति की स्लाइड्स केवल स्रोत स्लाइड्स की कॉपी होती हैं। इसलिए आप परिणामी स्लाइड्स में परिवर्तन (जैसे शैलियाँ, फॉर्मेटिंग विकल्प या लेआउट लागू करना) कर सकते हैं, बिना स्रोत प्रस्तुतियों पर असर की चिंता के।  

## **प्रेजेंटेशन मर्ज करें** 

Aspose.Slides [**AddClone (ISlide)**](https://reference.aspose.com/slides/hi/net/aspose.slides/islidecollection/methods/addclone) मेथड प्रदान करता है जो आपको स्लाइड्स को संयोजित करने देता है जबकि स्लाइड्स अपने लेआउट और शैलियों को बनाए रखती हैं (डिफ़ॉल्ट पैरामीटर)।  

यह C# कोड दर्शाता है कि आप प्रस्तुतियों को कैसे मर्ज कर सकते हैं:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    foreach (ISlide slide in pres2.Slides)
    {
        pres1.Slides.AddClone(slide);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

## **स्लाइड मास्टर के साथ प्रस्तुतियों को मर्ज करें** 

Aspose.Slides [**AddClone (ISlide, IMasterSlide, Boolean)**](https://reference.aspose.com/slides/hi/net/aspose.slides.islidecollection/addclone/methods/2) मेथड प्रदान करता है जो स्लाइड मास्टर प्रस्तुति टेम्पलेट लागू करते हुए स्लाइड्स को संयोजित करने देता है। इस प्रकार, आवश्यक होने पर आप आउटपुट प्रस्तुति की स्लाइड्स की शैली बदल सकते हैं।  

नीचे दिया गया C# कोड इस ऑपरेशन को दर्शाता है:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    foreach (ISlide slide in pres2.Slides)
    {
        pres1.Slides.AddClone(slide, pres2.Masters[0], allowCloneMissingLayout: true);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

{{% alert title="Note" color="warning" %}}  

स्लाइड मास्टर के लिए स्लाइड लेआउट स्वतः निर्धारित किया जाता है। जब उपयुक्त लेआउट निर्धारित नहीं हो पाता, यदि `AddClone` मेथड का `allowCloneMissingLayout` बूलियन पैरामीटर true पर सेट हो, तो स्रोत स्लाइड का लेआउट उपयोग किया जाता है। अन्यथा, [PptxEditException](https://reference.aspose.com/slides/hi/net/aspose.slides/pptxeditexception) उत्पन्न होगा।  

{{% /alert %}}  

यदि आप आउटपुट प्रस्तुति की स्लाइड्स के लिए अलग लेआउट चाहते हैं, तो मर्ज करते समय [AddClone (ISlide, ILayoutSlide)](https://reference.aspose.com/slides/hi/net/aspose.slides.islidecollection/addclone/methods/1) मेथड का उपयोग करें।  

## **प्रस्तुतियों से विशिष्ट स्लाइड्स मर्ज करें** 

कई प्रस्तुतियों से विशिष्ट स्लाइड्स को मर्ज करना कस्टम स्लाइड डेक बनाने में उपयोगी है। Aspose.Slides for .NET आपको केवल आवश्यक स्लाइड्स का चयन और आयात करने देता है। API मूल स्लाइड्स की फॉर्मेटिंग, लेआउट और डिजाइन को बरकरार रखती है।  

नीचे दिया गया C# कोड एक नई प्रस्तुति बनाता है, दो अन्य प्रस्तुतियों से शीर्षक स्लाइड्स जोड़ता है, और परिणाम को फ़ाइल में सहेजता है:

```cs
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation())
using (Presentation presentation1 = new Presentation("presentation1.pptx"))
using (Presentation presentation2 = new Presentation("presentation2.pptx"))
{
    presentation.Slides.RemoveAt(0);

    ISlide slide1 = GetTitleSlide(presentation1);

    if (slide1 != null)
        presentation.Slides.AddClone(slide1);

    ISlide slide2 = GetTitleSlide(presentation2);

    if (slide2 != null)
        presentation.Slides.AddClone(slide2);

    presentation.Save("combined.pptx", SaveFormat.Pptx);
}

static ISlide GetTitleSlide(IPresentation presentation)
{
    foreach (ISlide slide in presentation.Slides)
    {
        if (slide.LayoutSlide.LayoutType == SlideLayoutType.Title)
        {
            return slide;
        }
    }
    return null;
}
```
```cs
using Aspose.Slides;

static ISlide GetTitleSlide(IPresentation presentation)
{
    foreach (ISlide slide in presentation.Slides)
    {
        if (slide.LayoutSlide.LayoutType == SlideLayoutType.Title)
        {
            return slide;
        }
    }
    return null;
}
```

## **स्लाइड लेआउट के साथ प्रस्तुतियों को मर्ज करें** 

यह C# कोड बताता है कि आप प्रस्तुतियों की स्लाइड्स को कैसे संयोजित करें तथा अपना पसंदीदा स्लाइड लेआउट लागू करके एक आउटपुट प्रस्तुति प्राप्त करें:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    foreach (ISlide slide in pres2.Slides)
    {
        pres1.Slides.AddClone(slide, pres2.LayoutSlides[0]);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

## **विभिन्न स्लाइड आकारों के साथ प्रस्तुतियों को मर्ज करें** 

{{% alert title="Note" color="warning" %}}  

विभिन्न स्लाइड आकार वाली प्रस्तुतियों को मर्ज करने से कोई त्रुटि नहीं आती, लेकिन मर्ज की गई स्लाइड्स लक्ष्य प्रस्तुति के स्लाइड आकार को ले लेती हैं जबकि उनके आकार मूल स्थिति और आकार बनाए रखते हैं, इसलिए सामग्री गलत जगह पर या स्लाइड की सीमा के बाहर जा सकती है।  

{{% /alert %}}  

दो विभिन्न स्लाइड आकार वाली प्रस्तुतियों को मर्ज करने और उनकी सामग्री को सही ढंग से व्यवस्थित रखने के लिए, एक प्रस्तुति का आकार बदल कर उसे दूसरी प्रस्तुति के आकार से मिलाएँ।  

यह नमूना कोड इस ऑपरेशन को दर्शाता है:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
   pres2 = new Presentation("pres2.pptx"))
{
   pres2.SlideSize.SetSize(pres1.SlideSize.Size.Width, pres1.SlideSize.Size.Height, SlideSizeScaleType.EnsureFit);
 
   foreach (ISlide slide in pres2.Slides)
   {
       pres1.Slides.AddClone(slide);
   }
 
   pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

## **स्लाइड्स को प्रस्तुति सेक्शन में मर्ज करें** 

यह C# कोड बताता है कि आप किसी विशिष्ट स्लाइड को प्रस्तुति के एक सेक्शन में कैसे मर्ज कर सकते हैं:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    for (var index = 0; index < pres2.Slides.Count; index++)
    {
        ISlide slide = pres2.Slides[index];
        pres1.Slides.AddClone(slide, pres1.Sections[0]);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

स्लाइड को सेक्शन के अंत में जोड़ा जाता है।

## **अक्सर पूछे जाने वाले प्रश्न** 

### क्या स्पीकर नोट्स मर्ज के दौरान संरक्षित रहते हैं?

हाँ। स्लाइड क्लोन करते समय, Aspose.Slides सभी स्लाइड तत्वों को, जिसमें नोट्स, फॉर्मेटिंग और एनीमेशन शामिल हैं, साथ ले जाता है।  

### क्या टिप्पणियाँ और उनके लेखक स्थानांतरित होते हैं?

टिप्पणियाँ, स्लाइड कंटेंट का हिस्सा होने के नाते, स्लाइड के साथ कॉपी हो जाती हैं। टिप्पणी लेखक लेबल परिणामस्वरूप प्रस्तुति में टिप्पणी ऑब्जेक्ट्स के रूप में संरक्षित रहते हैं।  

### यदि स्रोत प्रस्तुति पासवर्ड‑सुरक्षित हो तो क्या करें?

इसे [पासवर्ड के साथ खोलना](/slides/hi/net/password-protected-presentation/) चाहिए [LoadOptions.Password](https://reference.aspose.com/slides/hi/net/aspose.slides/loadoptions/password/) का उपयोग करके; लोड करने के बाद, उन स्लाइड्स को सुरक्षित रूप से अनप्रोटेक्टेड लक्ष्य फ़ाइल में क्लोन किया जा सकता है (या प्रोटेक्टेड फ़ाइल में भी)।  

### मर्ज ऑपरेशन कितना थ्रेड‑सेफ़ है?

एक ही [Presentation](https://reference.aspose.com/slides/hi/net/aspose.slides/presentation/) इंस्टेंस को कई [थ्रेड्स](/slides/hi/net/multithreading/) से उपयोग न करें। अनुशंसित नियम है “एक डॉक्यूमेंट — एक थ्रेड”; विभिन्न फ़ाइलें अलग थ्रेड में समानांतर प्रोसेस की जा सकती हैं।
