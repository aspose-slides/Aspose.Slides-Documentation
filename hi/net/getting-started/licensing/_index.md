## **अवलोकन**

Aspose.Slides को मूल्यांकन मोड में या वैध लाइसेंस के साथ उपयोग किया जा सकता है। मूल्यांकन संस्करण लाइसेंस प्राप्त संस्करण के समान कार्यक्षमता प्रदान करता है, लेकिन यह सहेजी गई प्रत्येक प्रस्तुति की हर स्लाइड पर एक मूल्यांकन वॉटरमार्क जोड़ता है और प्रस्तुतियों से आपका कोड जो पाठ पढ़ता है उसे छोटा कर देता है।

यह लेख Aspose.Slides में लाइसेंसिंग कैसे काम करती है और लाइब्रेरी का उपयोग करने से पहले लाइसेंस कैसे लागू करें, यह समझाता है। लाइसेंस को `License` क्लास का उपयोग करके फ़ाइल, स्ट्रीम या एम्बेडेड रिसोर्स से लोड किया जा सकता है। यह लेख यह भी दिखाता है कि लाइसेंस सही ढंग से लागू हुआ है या नहीं, इसे कैसे मान्य किया जाए।

## **Aspose.Slides में लाइसेंसिंग**
* एक मूल्यांकन संस्करण लाइसेंस प्राप्त हो जाता है जब आप लाइसेंस खरीदते हैं और उसमें कुछ पंक्तियों का कोड जोड़ते हैं (लाइसेंस लागू करने के लिए)।
* लाइसेंस एक साधारण‑पाठ XML फ़ाइल है जिसमें उत्पाद का नाम, लाइसेंस प्राप्त डेवलपर्स की संख्या, सदस्यता समाप्ति तिथि आदि विवरण होते हैं। 
* लाइसेंस फ़ाइल डिजिटल रूप से साइन की गई होती है, इसलिए आपको फ़ाइल को संशोधित नहीं करना चाहिए। फ़ाइल की सामग्री में अनजाने में एक अतिरिक्त लाइन‑ब्रेक जोड़ना भी इसे अमान्य कर देगा।
* Aspose.Slides for .NET आमतौर पर लाइसेंस को इन स्थानों में खोजता है:
  * एक स्पष्ट पथ
  * कंपोनेंट की dll वाला फ़ोल्डर (Aspose.Slides में शामिल)
  * वह फ़ोल्डर जिसमें वह असेंबली है जिसने कंपोनेंट की dll को कॉल किया (Aspose.Slides में शामिल)
  * एंट्री असेंबली (your .exe) वाला फ़ोल्डर
  * कंपोनेंट की dll को कॉल करने वाली असेंबली में एम्बेडेड रिसोर्स (Aspose.Slides में शामिल)।
* मूल्यांकन संस्करण से जुड़ी सीमाओं से बचने के लिए, आपको Aspose.Slides का उपयोग करने से पहले लाइसेंस सेट करना आवश्यक है। आपको प्रत्येक एप्लिकेशन या प्रोसेस में केवल एक बार लाइसेंस सेट करना होता है।

लाइसेंस को **फ़ाइल**, **स्ट्रीम**, या **एम्बेडेड रिसोर्स** से लोड किया जा सकता है। 

{{% alert color="info" title="Note" %}}
Aspose.Slides लाइसेंसिंग संचालन के लिए [License](https://reference.aspose.com/slides/hi/net/aspose.slides/license) क्लास प्रदान करता है।

{{% alert color="warning" title="Warning" %}}

{{% /alert %}}

### **फ़ाइल**
लाइसेंस सेट करने का सबसे आसान तरीका यह है कि लाइसेंस फ़ाइल को कंपोनेंट की DLL (Aspose.Slides में शामिल) वाले उसी फ़ोल्डर में रखें और केवल फ़ाइल नाम बिना पथ के निर्दिष्ट करें।

यह C# कोड दिखाता है कि लाइसेंस फ़ाइल कैसे सेट की जाए:

``` csharp
// License क्लास का उदाहरण बनाता है 
Aspose.Slides.License license = new Aspose.Slides.License();

// लाइसेंस फ़ाइल पथ सेट करता है
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" title="Warning" %}}
यदि आप लाइसेंस फ़ाइल को किसी अलग निर्देशिका में रखते हैं, तो जब आप [SetLicense](https://reference.aspose.com/slides/hi/net/aspose.slides/license/setlicense/#setlicense_1) मेथड को कॉल करते हैं, तो निर्दिष्ट पथ के अंत में लाइसेंस फ़ाइल का नाम आपके लाइसेंस फ़ाइल नाम के समान होना चाहिए।

उदाहरण के लिए, आप लाइसेंस फ़ाइल का नाम *Aspose.Slides.lic.xml* में बदल सकते हैं। फिर, अपने कोड में, आपको फ़ाइल का पथ (जो *Aspose.Slides.lic.xml* पर समाप्त होता है) को [SetLicense](https://reference.aspose.com/slides/hi/net/aspose.slides/license/setlicense/#setlicense_1) मेथड को पास करना होगा।
{{% /alert %}}

### **स्ट्रीम**
आप लाइसेंस को स्ट्रीम से लोड कर सकते हैं। यह C# कोड दिखाता है कि स्ट्रीम से लाइसेंस कैसे लागू किया जाए:

``` csharp
// License क्लास का एक उदाहरण बनाता है
Aspose.Slides.License license = new Aspose.Slides.License();

// लाइसेंस फ़ाइल को स्ट्रीम के रूप में खोलता है
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// स्ट्रीम के माध्यम से लाइसेंस सेट करता है
license.SetLicense(licenseStream);
```

### **एम्बेडेड रिसोर्स**
आप लाइसेंस को अपने एप्लिकेशन के साथ पैकेज कर सकते हैं (इसे खोने से बचाने के लिए) लाइसेंस को एम्बेडेड रिसोर्स के रूप में उन असेंबली में जोड़कर जो कंपोनेंट की DLL को कॉल करती हैं (Aspose.Slides में शामिल)। 

यह रहा लाइसेंस फ़ाइल को एम्बेडेड रिसोर्स के रूप में जोड़ने का तरीका:

1. Visual Studio में, लाइसेंस (.lic) फ़ाइल को इस प्रकार प्रोजेक्ट में जोड़ें: **File** > **Add Existing Item** > **Add** पर जाएँ। 
2. **Solution Explorer** में फ़ाइल का चयन करें।
3. **Properties** विंडो में, **Build Action** को **Embedded Resource** पर सेट करें।
4. असेंबली में एम्बेडेड लाइसेंस तक पहुँचने के लिए, लाइसेंस फ़ाइल को प्रोजेक्ट में एम्बेडेड रिसोर्स के रूप में जोड़ें, और फिर `SetLicense` मेथड को लाइसेंस फ़ाइल नाम पास करें। 

`License` क्लास एम्बेडेड रिसोर्स में लाइसेंस फ़ाइल को स्वतः खोज लेती है। आपको Microsoft .NET Framework में `System.Reflection.Assembly` क्लास की `GetExecutingAssembly` और `GetManifestResourceStream` मेथड को कॉल करने की आवश्यकता नहीं है।

यह C# कोड दिखाता है कि लाइसेंस को एम्बेडेड रिसोर्स के रूप में कैसे सेट किया जाए:

``` csharp
// License क्लास का उदाहरण बनाता है
Aspose.Slides.License license = new Aspose.Slides.License();

// असेंबली में एम्बेडेड लाइसेंस फ़ाइल नाम पास करता है
license.SetLicense("Aspose.Slides.lic");
```

## **लाइसेंस को मान्य करें**
जाँचने के लिए कि लाइसेंस सही ढंग से सेट हुआ है या नहीं, आप इसे मान्य कर सकते हैं। यह C# कोड दिखाता है कि लाइसेंस को कैसे मान्य किया जाए:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **थ्रेड सुरक्षा**
{{% alert color="warning" title="Warning" %}}
`license.SetLicense` मेथड थ्रेड‑सेफ़ नहीं है। यदि इस मेथड को कई थ्रेड्स से एक साथ कॉल करना पड़े, तो समस्याओं से बचने के लिए आप सिंक्रोनाइज़ेशन प्रिमिटिव्स (जैसे लॉक) का उपयोग करना चाहेंगे। 
{{% /alert %}}

## **FAQ**

### क्या मैं लाइसेंस को पूरी तरह ऑफ़लाइन वातावरण (इंटरनेट एक्सेस नहीं) में लागू कर सकता हूँ?
हाँ। लाइसेंस सत्यापन स्थानीय रूप से लाइसेंस फ़ाइल का उपयोग करके किया जाता है; इंटरनेट कनेक्शन की आवश्यकता नहीं होती।

### एक‑साल की सदस्यता समाप्त होने के बाद क्या होता है? क्या लाइब्रेरी काम करना बंद कर देगी?
नहीं। लाइसेंस शाश्वत है: आप अपनी सदस्यता समाप्ति तिथि से पहले जारी किए गए संस्करणों को उपयोग जारी रख सकते हैं; लेकिन नवीनीकरण के बिना आप नए रिलीज़ का उपयोग नहीं कर पाएँगे।
