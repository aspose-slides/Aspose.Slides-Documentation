Aspose.Slides for .NET एक क्लास लाइब्रेरी है जो .NET अनुप्रयोगों में Microsoft PowerPoint या Office Automation के बिना PowerPoint और OpenDocument प्रस्तुतियों को बनाने, पढ़ने, संपादित करने और रूपांतरित करने की सुविधा देती है।

यह PPT, PPTX, PPS, POT और ODP फ़ाइलों को लोड और सहेजता है, जिसमें मैक्रो‑सक्षम और टेम्पलेट संस्करण शामिल हैं, और PDF, XPS, HTML, SVG, TIFF, Markdown और छवियों में निर्यात करता है।

## **अपनी पहली प्रस्तुति**

.NET SDK 6 या बाद का उपयोग करके एक कंसोल एप्लीकेशन बनाएँ:

```bash
dotnet new console -n HelloSlides
cd HelloSlides
```

फिर अपने प्लेटफ़ॉर्म के लिए एक पैकेज जोड़ें:

- Windows पर: `dotnet add package Aspose.Slides.NET`
- Linux और macOS पर: `dotnet add package Aspose.Slides.NET6.CrossPlatform` — देखें [Installation](/slides/hi/net/installation/) Linux पूर्वापेक्षा और उन प्रणालियों के लिए जो Aspose.Slides.NET की आवश्यकता रखते हैं।

*Program.cs* की सामग्री को इस कोड से बदलें और `dotnet run` चलाएँ:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];
var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 50, 400, 100);
shape.TextFrame.Text = "Hello, Aspose.Slides!";
presentation.Save("hello.pptx", SaveFormat.Pptx);
```

प्रोग्राम *hello.pptx* को एक स्लाइड के साथ सहेजता है जिसमें एक टेक्स्ट बॉक्स होता है। बिना लाइसेंस के, सहेजी गई फ़ाइल में मूल्यांकन वॉटरमार्क होता है — देखें [लाइसेंसिंग](/slides/hi/net/licensing/). प्रस्तुति बनाने और भरने के अधिक तरीकों के लिए, देखें [प्रस्तुति बनाना](/slides/hi/net/create-presentation/).
