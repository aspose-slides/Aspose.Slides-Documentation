سایت‌های SharePoint برای همکاری، ارتباط و ذخیره‌سازی محتوا به منظور رفع نیازهای تجاری خاص طراحی شده‌اند. آنها به گروهی از افراد امکان می‌دهند تا با تسهیل به اشتراک‌گذاری اطلاعات و ارتباط، هدف مشترکی را دنبال کنند. اطلاعات معمولاً به شکل یک وب‌سایت در دسترس هستند و از طریق مرورگر وب قابل دسترسی‌اند.

{{% /alert %}}

## **SharePoint و Aspose.Slides چیست؟**

Aspose.Slides for SharePoint یک راه‌حل برای تبدیل ارائه‌های Microsoft PowerPoint (PPT و PPTX) به سایر فرمت‌ها: PDF، TIFF، XPS، HTML، SWF، ODP، PPS، PPSX، PPTM، PPSM، POTX و POTM است. این امکان را به شما می‌دهد تا فایل‌های PowerPoint را در یک سایت SharePoint بدون استفاده از Microsoft PowerPoint تبدیل کنید. فهرست کامل فرمت‌ها در [فرمت‌های پشتیبانی‌شده](/slides/fa/sharepoint/supported-file-formats/) موجود است.
