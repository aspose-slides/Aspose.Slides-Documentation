برای حذف Aspose.Slides for SharePoint:

1. برنامه نصب را که برای نصب آن استفاده کرده‌اید اجرا کنید، به عنوان مثال *Setup2019.exe* روی SharePoint Server 2019.
   اگر نسخهٔ مشابهی نصب شده باشد، برنامه نصب گزینهٔ تعمیر یا حذف را ارائه می‌دهد. اگر نسخهٔ متفاوتی پیدا کند، گزینهٔ ارتقا یا حذف را ارائه می‌دهد.
2. گزینهٔ **Remove** را انتخاب کنید و برای حذف Aspose.Slides for SharePoint روی **Next** کلیک کنید.
