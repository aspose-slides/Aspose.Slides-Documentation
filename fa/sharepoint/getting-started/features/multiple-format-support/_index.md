{{% alert color="info" title="Note" %}}

با Aspose.Slides for SharePoint، می‌توانید ارائه‌های پاورپوینت را به بسیاری از فرمت‌های محبوب سند از داخل کتابخانه اسناد SharePoint تبدیل کنید.

{{% /alert %}}

## **قالب‌های ورودی پشتیبانی‌شده**

Aspose.Slides for SharePoint قالب‌های ورودی زیر را تبدیل می‌کند:

- PPT – ارائه Microsoft PowerPoint 97 - 2003
- PPTX – ارائه Office Open XML

{{% alert color="info" title="Note" %}}

برای تبدیل اسناد، Aspose.Slides for SharePoint بر نسخه داخلی [Aspose.Slides for .NET](https://products.aspose.com/slides/fa/net/) وابسته است.

{{% /alert %}}

## **قالب‌های خروجی پشتیبانی‌شده**

فهرست **Convert to** در صفحه تبدیل، فرمت‌های خروجی زیر را به این ترتیب ارائه می‌دهد:

- PDF – سند قابل حمل Adobe
- TIFF – بسته تصاویر
- XPS – مشخصات کاغذ XML
- PPS – ارائه اسلاید شو
- PPSX – اسلاید شو Microsoft PowerPoint Open XML
- ODP – ارائه OpenDocument
- PPTM – ارائه Microsoft PowerPoint Open XML با ماکرو
- PPSM – اسلاید شو Microsoft PowerPoint Open XML با ماکرو
- POTX – قالب Microsoft PowerPoint
- POTM – قالب ارائه PowerPoint Open XML با ماکرو
- PDFNotes – نمایش نکات ارائه به قالب PDF
- HTML – ارائه در قالب HTML
- TIFFNotes – نمایش نکات ارائه به صورت تصویر چندصفحه‌ای TIFF
- SWF – فیلم Shockwave Flash
- SWFNotes – نمایش نکات ارائه به صورت SWF چندصفحه‌ای
