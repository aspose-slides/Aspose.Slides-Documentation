## **نسخه‌های پشتیبانی‌شده Microsoft PowerPoint**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **فرمت‌های فایل پشتیبانی‌شده**

Aspose.Slides برای SharePoint ارائه‌های PPT و PPTX ذخیره‌شده در کتابخانه اسناد SharePoint را تبدیل می‌کند. پرونده‌های از انواع دیگر تبدیل نمی‌شوند.

|**فرمت**|**توضیحات**|**تبدیل از**|**تبدیل به**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|ارائه PowerPoint 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|ارائه PowerPoint 2007 و بعد|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|قالب قابل حمل سند (PDF)، با اسلایدها یا با نمای یادداشت‌ها| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|تصویر TIFF، با اسلایدها یا با نمای یادداشت‌ها| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML Paper Specification| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|ارائه در قالب HTML| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|فیلم Shockwave Flash، با اسلایدها یا با نمای یادداشت‌ها| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|ارائه OpenDocument| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|نمایش اسلاید PowerPoint 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|نمایش اسلاید PowerPoint 2007 و بعد| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|ارائه PowerPoint با ماکرو| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|نمایش اسلاید PowerPoint با ماکرو| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|قالب PowerPoint| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|قالب PowerPoint با ماکرو| |{{< emoticons/tick >}}|

قالب خروجی در صفحه تبدیل زیر **تبدیل به** انتخاب می‌شود؛ برای فهرست دقیق گزینه‌ها، به [Multiple Format Support](/slides/fa/sharepoint/multiple-format-support/) مراجعه کنید.
