**به Aspose.Slides for Node.js via .NET خوش آمدید**

![لوگوی محصول Aspose.Slides for Node.js via .NET](aspose_slides-for-nodejs-via-net.png)

Aspose.Slides for Node.js via .NET یک کتابخانهٔ کلاس است که به برنامه‌های شما امکان خواندن و نوشتن اسناد PowerPoint® را بدون استفاده از Microsoft PowerPoint® می‌دهد.

Aspose.Slides for Node.js via .NET اولین و تنها مؤلفه‌ای است که قابلیت مدیریت اسناد PowerPoint® را فراهم می‌کند.

Aspose.Slides for Node.js via .NET ویژگی‌های کلیدی فراوانی ارائه می‌دهد از جمله مدیریت متن، اشکال، جدول‌ها و انیمیشن‌ها، افزودن صدا و ویدئو به اسلایدها، پیش‌نمایش اسلایدها، صادرات اسلایدها به فرمت‌های SVG، PDF و موارد دیگر.
