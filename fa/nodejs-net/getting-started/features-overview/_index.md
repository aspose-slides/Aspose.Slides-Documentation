## **پلتفرم‌های پشتیبانی‌شده**
Aspose.Slides for Node.js via .NET یک API مستقل از پلتفرم است. می‌تواند در هر پلتفرمی (Windows, Linux, MacOS و غیره) که Node.js 7 یا بالاتر نصب شده باشد، استفاده شود. Oracle JDK نسخه 8 یا بالاتر نیز یک نیاز دیگر است.

## **فرمت‌ها و تبدیل‌های فایل**
Aspose.Slides for Node.js via .NET از اکثر فرمت‌های سند PowerPoint پشتیبانی می‌کند. همچنین امکان خروجی گرفتن به فرمت‌های رایج فایل که سازمان‌ها از آن استفاده و به اشتراک می‌گذارند را فراهم می‌کند. به جزئیات زیر مراجعه کنید:

|**ویژگی**|**توضیح**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET سریع‌ترین پردازش را برای این فرمت سند ارائه می‌دهد.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET از تبدیل PPT به PPTX پشتیبانی می‌کند.|
|Portable Document Format (PDF)|شما می‌توانید تمام فرمت‌های فایل پشتیبانی‌شده را با یک متد به اسناد Adobe Portable Document Format (PDF) خروجی بگیرید.|
|XML Parser Specification (XPS)|شما می‌توانید تمام فرمت‌های فایل پشتیبانی‌شده را با یک متد به اسناد XML Parser Specification (XPS) خروجی بگیرید.|
|Tagged Image File Format (TIFF)|شما می‌توانید تمام فرمت‌های فایل ارائه پشتیبانی‌شده را به Tagged Image File Format (TIFF) خروجی بگیرید.|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET از تبدیل PresentationEx به فرمت HTML پشتیبانی می‌کند.|

## **رندرینگ ارائه**
Aspose.Slides for Node.js via .NET رندرینگ با دقت بالا از اسلایدهای ارائه به فرمت‌های گرافیکی مختلف را پشتیبانی می‌کند. به جزئیات زیر مراجعه کنید:

|**ویژگی**|**توضیح**|
| :- | :- |
|.NET Supported Image Formats|با استفاده از Aspose.Slides for Node.js via .NET، می‌توانید اسلایدهای ارائه و تصاویر موجود در اسلایدها را به تمام فرمت‌های گرافیکی پشتیبانی‌شده توسط .NET مانند TIFF، PNG، BMP، JPEG و GIF رندر کنید.|
|SVG Format|Aspose.Slides for Node.js via .NET روش‌های داخلی برای خروجی گرفتن اسلایدهای ارائه به فرمت Scalable Vector Graphics (SVG) نیز فراهم می‌کند.|

## **ویژگی‌های محتوا**
Aspose.Slides for Node.js via .NET به شما امکان دسترسی، اصلاح یا ایجاد تقریباً تمام آیتم‌ها یا محتویات اسناد ارائه را می‌دهد. به جزئیات زیر مراجعه کنید:

|**ویژگی**|**توضیح**|
| :- | :- |
|Master Slides|اسلایدهای مستر چیدمان اسلایدهای عادی را تعریف می‌کنند. Aspose.Slides for Node.js via .NET به شما امکان دسترسی و اصلاح اسلایدهای مستر اسناد ارائه را می‌دهد.|
|Normal Slides|با Aspose.Slides for Node.js via .NET، می‌توانید اسلایدهای جدید با انواع مختلف ایجاد کنید؛ همچنین می‌توانید به اسلایدهای موجود در ارائه‌ها دسترسی پیدا کنید و آن‌ها را اصلاح کنید.|
|Cloning / Copying Slides|روش‌های داخلی ارائه‌شده توسط Aspose.Slides for Node.js via .NET به شما امکان می‌دهد اسلایدهای موجود در یک ارائه را کلون یا کپی کنید. همچنین می‌توانید اسلایدهای کپی شده و کلون شده را از یک ارائه به ارائه دیگر انتقال دهید. از آنجا که یک اسلاید چیدمان خود را از اسلاید مستر به ارث می‌برد، روش‌های داخلی کلون‌سازی به طور خودکار مستر را هنگام کلون‌کردن کپی می‌کنند.|
|Managing Slides sections|روش‌هایی برای سازماندهی اسلایدها در بخش‌های مختلف داخل یک ارائه|
|Place Holders and Text Holders|شما می‌توانید به جای‌دارها (Place Holders) و متن‌دارها (Text Holders) در یک اسلاید دسترسی پیدا کنید. علاوه بر این، می‌توانید با استفاده از متد مناسب، اسلایدی با متن‌دارها از ابتدا ایجاد کنید.|
|Header and Footers|Aspose.Slides for Node.js via .NET مدیریت سرصفحه‌ها/پاصفحه‌ها در اسلایدها را تسهیل می‌کند.|
|Notes in Slides|با Aspose.Slides for Node.js via .NET، می‌توانید به یادداشت‌های مرتبط با یک اسلاید دسترسی پیدا کنید و آن‌ها را اصلاح کنید و همچنین یادداشت‌های جدید اضافه کنید.|
|Finding a Shape|شما می‌توانید با استفاده از متن جایگزین مرتبط با شکل، شکل خاصی را در یک اسلاید پیدا کنید.|
|Backgrounds|Aspose.Slides for Node.js via .NET به شما امکان کار با پس‌زمینه‌های مرتبط با یک اسلاید مستر یا عادی در یک ارائه را می‌دهد.|
|Text Boxes|جعبه‌های متن می‌توانند از ابتدا ایجاد شوند. شما می‌توانید به جعبه‌های متن موجود دسترسی پیدا کنید. همچنین می‌توانید متن‌های آن‌ها را بدون از دست دادن قالب‌بندی اصلی متن اصلاح کنید.|
|Rectangle Shapes|می‌توانید با Aspose.Slides for Node.js via .NET، اشکال مستطیل را ایجاد یا اصلاح کنید.|
|Poly Line Shapes|می‌توانید با Aspose.Slides for Node.js via .NET، اشکال پلی‌لاین را ایجاد یا اصلاح کنید.|
|Ellipse Shapes|می‌توانید با Aspose.Slides for Node.js via .NET، اشکال بیضی را ایجاد یا اصلاح کنید.|
|Group Shapes|Aspose.Slides for Node.js via .NET از گروه‌بندی اشکال پشتیبانی می‌کند.|
|Auto Shapes|Aspose.Slides for Node.js via .NET از اشکال خودکار پشتیبانی می‌کند.|
|SmartArt|Aspose.Slides for Node.js via .NET پشتیبانی از اشکال SmartArt در MS PowerPoint را فراهم می‌کند.|
|Charts|Aspose.Slides for Node.js via .NET پشتیبانی از نمودارهای MSO در PowerPoint را فراهم می‌کند.|
|Shapes Serialization|Aspose.Slides for Node.js via .NET از تعداد زیادی شکل پشتیبانی می‌کند. زمانی که Aspose.Slides for Node.js via .NET از یک شکل پشتیبانی نمی‌کند، می‌توانید از روش سریال‌سازی استفاده کنید که به شما امکان می‌دهد آن شکل را از یک اسلاید موجود سریال‌سازی کرده و سپس بر اساس نیازهای خود از آن استفاده کنید.|
|Picture Frames|می‌توانید تصاویر را در چارچوب‌های تصویر با Aspose.Slides for Node.js via .NET مدیریت کنید.|
|Audio Frames|می‌توانید فایل‌های صوتی را در چارچوب‌های صدا بر روی اسلایدها با Aspose.Slides for Node.js via .NET لینک یا تعبیه کنید.|
|Video Frames|می‌توانید فایل‌های ویدئویی را در چارچوب‌های ویدئو مدیریت کنید. Aspose.Slides for Node.js via .NET همچنین پشتیبانی از ویدئوهای لینک‌شده و تعبیه‌شده را فراهم می‌کند.|
|OLE Frame|می‌توانید اشیاء OLE را در چارچوب‌های OLE با Aspose.Slides for Node.js via .NET مدیریت کنید.|
|Tables|Aspose.Slides for Node.js via .NET از جداول در اسلایدها پشتیبانی می‌کند.|
|ActiveX Controls|پشتیبانی از کنترل‌های ActiveX|
|VBA Macros|پشتیبانی از مدیریت ماکروهای VBA داخل ارائه‌ها.|
|Text Frame|می‌توانید متن هر شکل را از طریق قاب متن مرتبط با آن شکل دسترسی یابید.|
|Text Scanning|می‌توانید متن را در ارائه، در سطح ارائه یا اسلاید، از طریق روش‌های اسکن داخلی، اسکن کنید.|
|Animations|می‌توانید انیمیشن‌ها را بر روی اشکال اعمال کنید.|
|Slide Shows|Aspose.Slides for Node.js via .NET از نمایش اسلایدها و انتقال‌های اسلاید پشتیبانی می‌کند.|
