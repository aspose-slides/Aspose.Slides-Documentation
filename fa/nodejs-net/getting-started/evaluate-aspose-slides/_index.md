## **نمای کلی**

نسخه ارزیابی Aspose.Slides برای Node.js via .NET همان بسته npm نسخه دارای licence است. بدون لایسنس، در حالت ارزیابی اجرا می‌شود: همه ویژگی‌ها کار می‌کنند، اما ارائه‌های ذخیره‌شده و بیشتر خروجی‌ها دارای واترمارک هستند، و متنی که کد شما باز می‌خواند کوتاه می‌شود. این مقاله هر دو محدودیت را توصیف می‌کند و نشان می‌دهد چگونه آنها را حذف کنید.

## **محدودیت‌های ارزیابی**

**یک واترمارک ارزیابی بر روی هر اسلاید.** وقتی ارائه‌ای را بدون لایسنس ذخیره می‌کنید، Aspose.Slides یک کادر متن در وسط هر اسلاید فایل ذخیره‌شده اضافه می‌کند. این کادر متن قفل است و نشان می‌دهد "Evaluation only." به همراه یک خط محصول و یک خط حق کپی‌رایت. واترمارک در فایل ذخیره‌شده می‌رود، نه در ارائه‌ای که در حافظه است، و باز کردن ارائه واترمارکی اضافه نمی‌کند. با این حال، فایلی که در حالت ارزیابی ذخیره شده قبلاً حاوی این کادر متن است، بنابراین باز کردن و دوباره ذخیره کردن آن، یک واترمارک دوم به هر اسلاید اضافه می‌کند.

همان واترمارک هنگام خروجی به PDF، XPS یا HTML، یا رندر کردن اسلایدها به تصویر کشیده می‌شود. اگر ارائه‌ای را که قبلاً در حالت ارزیابی ذخیره شده رندر کنید، تصویر هم واترمارک ذخیره‌شده و هم واترمارک رندر شده را نشان می‌دهد.

**متن کوتاه‌شده هنگامی که کد شما آن را می‌خواند.** متنی که کد شما از طریق ویژگی `text` یک قاب متن، پاراگراف یا بخش می‌خواند، به اولین پنج کاراکترش کوتاه می‌شود و سپس پیام "... text has been truncated due to evaluation version limitation." را اضافه می‌کند. متن پنج کاراکتر یا کمتر به‌صورت کامل بازگردانده می‌شود. این مورد برای هر اسلاید اعمال می‌شود و حتی برای متنی که کد شما تازه به آن اختصاص داده است. خروجی‌های Markdown و HTML5 به همان شکل کوتاه می‌شوند.

متنی که کد شما می‌نویسد به‌صورت کامل ذخیره می‌شود: فایل‌های PPTX، صفحات PDF و تصاویر اسلاید شامل متن کامل هستند.

## **مشاهده محدودیت‌ها در اسکریپت**

اسکریپت زیر هر دو محدودیت را نشان می‌دهد. فرض می‌کند که بسته را همان‌طور که در [Installation](/slides/fa/nodejs-net/installation/) توضیح داده شده نصب کرده‌اید و آن را از پوشه پروژه اجرا می‌کنید. یک مستطیل حاوی یک جمله به اولین اسلاید اضافه می‌کند، جمله را می‌خواند، ارائه را به عنوان `evaluation.pptx` ذخیره می‌کند، و سپس فایل را باز کرده و تعداد اشکال موجود در اسلاید را شمارش می‌کند.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { Presentation, ShapeType, SaveFormat } = asposeSlides;

const presentation = new Presentation();
try {
    const slide = presentation.slides.get(0);
    const rectangle = slide.shapes.addAutoShape(ShapeType.Rectangle, 50, 50, 500, 100);
    rectangle.textFrame.text = "Quarterly results are ready for review.";

    // بدون لایسنس، فقط اولین پنج کاراکتر برگردانده می‌شوند.
    console.log("Text read back:", rectangle.textFrame.text);

    // ذخیره‌سازی واترمارک ارزیابی را به هر اسلاید فایل اضافه می‌کند.
    presentation.save("evaluation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}

const savedPresentation = new Presentation("evaluation.pptx");
try {
    // اسلاید اکنون شامل مستطیل و جعبه متن واترمارک است.
    console.log("Shapes on the saved slide:", savedPresentation.slides.get(0).shapes.count);
} finally {
    savedPresentation.dispose();
}
```

بدون لایسنس، اسکریپت چاپ می‌کند:

```text
Text read back: Quart... text has been truncated due to evaluation version limitation.
Shapes on the saved slide: 2
```

شکل دوم کادر متن واترمارک است. `evaluation.pptx` را باز کنید تا جمله کامل در مستطیل و واترمارک در وسط اسلاید را ببینید.

## **حذف محدودیت‌ها**

برای حذف هر دو محدودیت، قبل از ایجاد هر شیء `Presentation` یک لایسنس اعمال کنید. [Licensing](/slides/fa/nodejs-net/licensing/) نشان می‌دهد چگونه یک فایل لایسنس اعمال شود.

## **سؤالات متداول**

**آیا حالت ارزیابی تعداد اسلایدها را محدود می‌کند؟**

خیر. ارائه‌ها با تمام اسلایدهای خود ایجاد، باز و ذخیره می‌شوند. واترمارک و کوتاه شدن متن برای هر اسلاید به‌طور مساوی اعمال می‌شود.

**چرا تصاویر اسلایدهای خروجی‌ام واترمارک دو بار نمایش می‌دهد؟**

ارائه پیش از رندر شدن در حالت ارزیابی ذخیره شده بود، بنابراین قبلاً شامل یک کادر متن واترمارک است و رندر بدون لایسنس یک واترمارک دیگر را روی آن می‌کشد.

**آیا می‌توانم در حالت ارزیابی متن صحیح تولید شده توسط کدم را بررسی کنم؟**

بله. فایل ذخیره‌شده یا PDF خروجی را باز کنید: آنها متن کامل را شامل می‌شوند. فقط متنی که کد شما باز می‌خواند و خروجی‌های Markdown یا HTML5 کوتاه می‌شوند.
