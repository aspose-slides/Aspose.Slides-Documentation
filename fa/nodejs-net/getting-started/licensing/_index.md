## **مرور کلی**

Aspose.Slides for Node.js via .NET یک بسته npm برای ارزیابی و تولید است. بدون داشتن لایسنس، در حالت ارزیابی اجرا می‌شود. پس از خرید لایسنس یا دریافت یک لایسنس موقت رایگان 30‑روزه، آن را با چند خط کد اعمال می‌کنید و محدودیت‌های ارزیابی دیگر اعمال نمی‌شوند.

سیاست‌های کلی برای ارزیابی، لایسنس و خرید محصولات Aspose در [سیاست‌های خرید و پرسش‌های متداول](https://purchase.aspose.com/policies) جمع‌آوری شده‌اند. قیمت‌ها در صفحه [اطلاعات قیمت‌گذاری](https://purchase.aspose.com/pricing/slides/family) نمایش داده می‌شود.

## **محدودیت‌های نسخه ارزیابی**

نسخه ارزیابی تمام قابلیت‌های محصول را فراهم می‌کند، اما دو محدودیت دارد:

- **واترمارک.** هر اسلاید از هر ارائه‌ای که ذخیره می‌کنید، یک واترمارک ارزیابی دریافت می‌کند: یک کادر متن قفل‌شده در وسط اسلاید که می‌گوید «Evaluation only». همان واترمارک در خروجی‌های PDF، XPS و HTML و همچنین در تصاویر اسلاید نمایش داده می‌شود.
- **متن کوتاه‌شده.** متنی که کد شما از یک فریم متن، پاراگراف یا بخش می‌خواند، به پنج کاراکتر اول محدود می‌شود و پس از آن پیام «... text has been truncated due to evaluation version limitation.» اضافه می‌شود. خروجی‌های Markdown و HTML5 نیز به همین شکل کوتاه می‌شوند. متنی که کد شما می‌نویسد به‌طور کامل ذخیره می‌شود.

[ارزیابی Aspose.Slides](/slides/fa/nodejs-net/evaluate-aspose-slides/) هر دو محدودیت را به‌تفصیل توصیف می‌کند و اسکریپتی برای نمایش آن‌ها ارائه می‌دهد.

برای تست Aspose.Slides بدون محدودیت‌های ارزیابی، یک **لایسنس موقت رایگان 30‑روزه** درخواست کنید. برای جزئیات به [چگونه یک لایسنس موقت دریافت کنیم؟](https://purchase.aspose.com/temporary-license) مراجعه کنید.

## **درباره لایسنس**

لایسنس یک فایل XML متنی ساده است که شامل جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که به آن لایسنس داده شده و تاریخ انقضای اشتراک می‌شود. این فایل به‌صورت دیجیتالی امضا شده است، بنابراین آن را تغییر ندهید: حتی افزودن یک خط جدید به‌صورت ناخواسته آن را نامعتبر می‌کند.

## **اعمال لایسنس**

لایسنس را با متد `setLicense` از کلاس `License` اعمال کنید. این متد را یک بار برای هر فرایند، قبل از ایجاد هر شی `Presentation` صدا بزنید. فراخوانی مجدد آن آسیبی نمی‌رساند، اما کاری را که قبلاً انجام شده تکرار می‌کند.

اسکریپت زیر لایسنس را از فایلی به نام `Aspose.Slides.lic` اعمال می‌کند. نام را به نام یا مسیر کامل فایل لایسنس خود تغییر دهید؛ فایل می‌تواند هر نامی داشته باشد.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { License } = asposeSlides;

const license = new License();
try {
    license.setLicense("Aspose.Slides.lic");
    console.log("License applied.");
} catch (error) {
    console.log("License not applied:", error.message);
}
```

یک نام فایل یا مسیر نسبی نسبت به پوشه جاری، یعنی پوشه‌ای که `node` از آن اجرا می‌شود، حل می‌شود. فایل لایسنس را در پوشه پروژه خود نگه دارید و اسکریپت‌ها را از آنجا اجرا کنید، یا مسیر کامل را بدهید.

اگر فایل پیدا نشود یا لایسنس معتبر نباشد، `setLicense` یک خطا پرتاب می‌کند و Aspose.Slides در حالت ارزیابی باقی می‌ماند. اسکریپت خطا را می‌گیرد و پیام آن را چاپ می‌کند. برای فایل‌های گمشده، پیام با `License "Aspose.Slides.lic" doesn't exist or access is restricted.` شروع می‌شود و تمام مسیرهای جستجو شده را فهرست می‌کند.

در این بسته، لایسنس فقط از یک فایل اعمال می‌شود. `License` استریم را قبول نمی‌کند و بسته قابلیت لایسنس‌گذاری متره‌ای را افشا نمی‌کند. برای کلاس‌‎هایی که بسته آن‌ها را می‌پیچد، به [License](https://reference.aspose.com/slides/net/aspose.slides/license/) در مرجع API Aspose.Slides for .NET مراجعه کنید.
