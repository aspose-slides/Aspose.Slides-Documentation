**به Aspose.Slides برای Android از طریق Java خوش آمدید**

Aspose.Slides for Android via Java یک API مدیریت Microsoft PowerPoint® است که به برنامه‌های Android امکان خواندن و نوشتن اسناد PowerPoint® را بدون نیاز به Microsoft PowerPoint® می‌دهد. Aspose.Slides for Android via Java اولین و تنها مؤلفه‌ای است که کارکردهای لازم برای مدیریت اسناد PowerPoint® در پلتفرم‌های Android را فراهم می‌کند. Aspose.Slides for Android ویژگی‌های کلیدی بسیاری ارائه می‌دهد که به شما اجازه می‌دهد متن، اشکال، جدول‌ها و انیمیشن‌ها، صداها و ویدیوها را در اسلایدها اضافه، اصلاح و دست‌کاری کنید.
