{{% alert color="info" %}} 

Aspose.Slides for Android via Java یک کتابخانه کلاسی است که به برنامه‌های Java برای Android امکان خواندن و نوشتن اسناد ارائه را بدون استفاده از Microsoft PowerPoint® یا نرم‌افزارهای دیگر می‌دهد. Aspose.Slides for Android via Java به شما اجازه می‌دهد متن، اشکال، جداول و انیمیشن‌ها را مدیریت کنید؛ صوت و ویدیو را به اسلایدها اضافه کنید؛ پیش‌نمایش اسلایدها را ببینید؛ و اسلایدها را به فرمت‌های SVG، PDF و موارد دیگر صادر کنید.

آخرین مرجع API را می‌توانید در [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/fa/androidjava/) پیدا کنید.
