## **تبدیل PPT به PPTX**
Aspose.Slides برای Android از طریق Java اکنون به توسعه‌دهندگان امکان دسترسی به PPT را از طریق کلاس [Presentation](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/presentation) و تبدیل آن به فرمت مربوطهٔ [PPTX](https://docs.fileformat.com/presentation/pptx/) را می‌دهد. در حال حاضر، این کتابخانه از تبدیل جزئی [PPT](https://docs.fileformat.com/presentation/ppt/) به PPTX پشتیبانی می‌کند.

Aspose.Slides برای Android از طریق Java کلاس [Presentation](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/presentation) را ارائه می‌دهد که نمایانگر یک فایل ارائه **PPTX** است. کلاس Presentation اکنون می‌تواند با استفاده از شیء موجود، به **PPT** نیز دسترسی داشته باشد. مثال زیر نشان می‌دهد چگونه یک ارائه PPT را به ارائه PPTX تبدیل کنیم.

```java
import com.aspose.slides.*;

// یک شیء Presentation ایجاد می‌کند که یک فایل PPT را نمایندگی می‌کند
Presentation pres = new Presentation("Aspose.ppt");
try {
// ذخیرهٔ ارائه PPT به فرمت PPTX
    pres.save("ConvertedAspose.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **سوالات متداول**

### تفاوت بین فرمت‌های PPT و PPTX چیست؟

PPT فرمت باینری قدیمی است که توسط Microsoft PowerPoint استفاده می‌شود، در حالی که PPTX فرمت مبتنی بر XML جدیدی است که از Microsoft Office 2007 معرفی شد. فایل‌های PPTX عملکرد بهتر، حجم کوچکتر و بازیابی دادهٔ بهبود یافته‌ای ارائه می‌دهند.

### آیا Aspose.Slides از تبدیل دسته‌ای چندین فایل PPT به PPTX پشتیبانی می‌کند؟

بله، می‌توانید از Aspose.Slides در یک حلقه برای تبدیل برنامه‌نویسی چندین فایل PPT به PPTX استفاده کنید که برای سناریوهای تبدیل دسته‌ای مناسب است.

### آیا محتوا و قالب‌بندی پس از تبدیل حفظ می‌شود؟

Aspose.Slides حفظ بالایی از جزئیات در تبدیل ارائه‌ها دارد. طرح‌بندی اسلایدها، انیمیشن‌ها، اشکال، نمودارها و سایر عناصر طراحی در حین تبدیل PPT به PPTX حفظ می‌شوند.

### آیا می‌توانم فرمت‌های دیگری مانند PDF یا HTML را از فایل‌های PPT تبدیل کنم؟

بله، Aspose.Slides از تبدیل فایل‌های PPT به [فرمت‌های متعدد](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/saveformat/) از جمله PDF، XPS، HTML، ODP و فرمت‌های تصویر مانند PNG و JPEG پشتیبانی می‌کند.

بله، Aspose.Slides یک API مستقل است و برای انجام تبدیل نیاز به Microsoft PowerPoint یا هیچ نرم‌افزار شخص ثالثی ندارد.
