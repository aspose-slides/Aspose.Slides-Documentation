## **مقدمه**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش هر دو مهم هستند.

اندازه‌ها و نسبت‌های پرطرفدار اسلاید:

- **استاندارد (نسبت ۴:۳)**: مناسب برای صفحات و دستگاه‌های قدیمی.
- **عریض‌صفحه (نسبت ۱۶:۹)**: برای پروژکتور و نمایشگرهای مدرن توصیه می‌شود.

از یکپارچگی در سراسر ارائه خود اطمینان حاصل کنید، زیرا یک اندازه اسلاید و نسبت ابعاد برای تمام اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید خود را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به صورت پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت استاندارد ۴:۳ استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این کد نمونه نشان می‌دهد که چگونه می‌توانید با استفاده از Aspose.Slides در Java اندازه اسلاید را در یک ارائه تغییر دهید:

```java
Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مشخص کردن اندازه‌های سفارشی اسلاید در ارائه‌ها**

اگر اندازه‌های معمول اسلاید (۴:۳ و ۱۶:۹) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصربه‌فرد استفاده کنید. به عنوان مثال، اگر قصد دارید اسلایدهای تمام‌صفحه را از ارائه خود بر روی یک طرح صفحه سفارشی چاپ کنید یا ارائه خود را روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً استفاده از تنظیم اندازه سفارشی برای ارائه مفید خواهد بود.

این کد نمونه نشان می‌دهد که چگونه می‌توانید با استفاده از Aspose.Slides برای Android از طریق Java، یک اندازه اسلاید سفارشی برای یک ارائه در Java مشخص کنید:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتوای اسلایدها (مثلاً تصاویر یا اشیاء) ممکن است مخدوش شوند. به طور پیش‌فرض، اشیاء به‌صورت خودکار برای تناسب با اندازه جدید اسلاید مقیاس می‌شوند. با این حال، هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را مشخص کنید که نحوه‌ی رسیدگی Aspose.Slides به محتویات اسلایدها را تعیین می‌کند.

بسته به آنچه می‌خواهید انجام دهید یا به دست آورید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها مقیاس شوند، این تنظیم را استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به یک اندازه اسلاید کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کوچک کند تا همه‌ها در اسلایدها جا بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به یک اندازه اسلاید بزرگتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ‌نمایی کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد که چگونه می‌توانید تنظیم `Maximize` را هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **سوالات متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهای دیگری بجز اینچ (مثلاً نقطه یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از نقطه‌ها استفاده می‌کند، به‌طوری که ۱ نقطه برابر با ۱/۷۲ اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقطه تبدیل کنید و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه هنگام رندر تأثیر خواهد گذاشت؟**

بله. ابعاد بزرگتر اسلاید (به نقطه) همراه با مقیاس رندر بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندر را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟**

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/androidjava/merge-presentation/) کنید در حالی که اندازه اسلایدهای آنها متفاوت است — ابتدا یک ارائه را به اندازه دیگر تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید نحوه‌ٔ مدیریت محتویات موجود را از طریق گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هم‌ترازی اندازه‌ها، می‌توانید اسلایدها را ادغام کنید در حالی که قالب‌بندی حفظ می‌شود.

**آیا می‌توانم برای اشکال جداگانه یا مناطق خاص یک اسلاید تصویر کوچک (thumbnail) تولید کنم و آیا این تصاویر اندازه جدید اسلاید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [کل اسلایدها](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) و همچنین برای [اشکال انتخاب شده](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) رندر کند. تصاویر حاصل اندازه و نسبت ابعاد فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسهٔ سازگاری را تضمین می‌نمایند.
