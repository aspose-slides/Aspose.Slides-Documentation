## **معرفی**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش بر روی صفحه نمایش اهمیت دارد.

اندازه‌ها و نسبت‌های پرطرفدار اسلاید:

- **استاندارد (نسبت ابعاد 4:3)**: مناسب برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **عریض (نسبت ابعاد 16:9)**: توصیه شده برای پروژکتورها و نمایشگرهای مدرن.

برای حفظ ثبات در سراسر ارائه‌تان، یک اندازه اسلاید و نسبت ابعاد واحد برای تمام اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید خود را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" title="Note" %}}
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت ابعاد استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و جزوه ابعاد جداگانه‌ای نسبت به اسلایدهای معمول دارند. برای تغییر اندازه و جهت‌گیری آن‌ها، به [اندازه صفحه یادداشت](/slides/fa/androidjava/notes-size/) مراجعه کنید.

## **تغییر اندازه اسلاید در ارائه‌ها**

این کد نمونه نشان می‌دهد چگونه با استفاده از Aspose.Slides در Java اندازه اسلاید یک ارائه را تغییر دهید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مشخص کردن اندازه‌های سفارشی اسلاید در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. به عنوان مثال، اگر قصد دارید اسلایدهای تمام‌سایزی را از ارائه‌تان بر روی یک چیدمان صفحه سفارشی چاپ کنید یا اگر می‌خواهید ارائه‌تان را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً از تنظیم اندازه سفارشی برای ارائه خود بهره‌مند خواهید شد.

این کد نمونه نشان می‌دهد چگونه با استفاده از Aspose.Slides برای Android از طریق Java یک اندازه اسلید سفارشی برای یک ارائه در Java مشخص کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (برای مثال تصاویر یا اشیاء) ممکن است دچار اعوجاج شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای مناسب شدن با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید یک ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتویات اسلایدها برخورد کند.

بسته به هدف یا نیازی که دارید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه یابند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کوچک کند تا همه آنها در اسلاید جا بگیرند (به این ترتیب، از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه، از تنظیم `Maximize` استفاده کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **سوالات متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهای دیگری غیر از اینچ (مثلاً نقطه یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از نقطه (point) استفاده می‌کند که 1 نقطه برابر است با 1/72 اینچ. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقطه تبدیل کرده و مقادیر تبدیل‌شده را برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا یک اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه در هنگام رندرینگ تأثیر می‌گذارد؟**

بله. ابعاد بزرگتر اسلاید (به نقطه) همراه با مقیاس رندرینگ بالاتر منجر به افزایش مصرف حافظه و زمان پردازش بیشتر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدهای ارائه‌هایی که اندازه‌های متفاوت دارند را ادغام کنم؟**

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/androidjava/merge-presentation/) را انجام دهید در حالی که اندازه اسلایدها متفاوت است — ابتدا یک ارائه را برای مطابقت با دیگری تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید نحوه‌ٔ پردازش محتویات موجود را از طریق گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هم‌ارزی اندازه‌ها، می‌توانید اسلایدها را با حفظ قالب‌بندی ادغام کنید.

**آیا می‌توانم برای اشکال فردی یا نواحی خاص یک اسلاید تصویر کوچک (thumbnail) تولید کنم و آیا این تصاویر از اندازه جدید اسلاید پیروی می‌کنند؟**

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [تمام اسلایدها](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) و همچنین برای [اشکال انتخاب‌شده](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) رندر کند. تصاویر حاصل، اندازه و نسبت ابعاد کنونی اسلاید را بازتاب می‌دهند و چارچوب و هندسهٔ یکسانی را تضمین می‌کنند.
