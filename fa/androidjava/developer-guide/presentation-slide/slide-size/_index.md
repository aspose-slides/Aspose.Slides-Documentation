## **مقدمه**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت تصویر در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش مهم است.

اندازه‌ها و نسبت‌های پرطرفدار اسلاید:

- **استاندارد (نسبت تصویر ۴:۳)**: ایده‌آل برای صفحات نمایش و دستگاه‌های قدیمی.
- **گسترده (نسبت تصویر ۱۶:۹)**: توصیه‌شده برای پروژکتورها و نمایشگرهای مدرن.

سازگاری در سراسر ارائه خود را حفظ کنید، زیرا یک اندازه اسلاید و نسبت تصویر برای تمام اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" %}}به‌طور پیش‌فرض، ارائه‌های ساخته‌شده با Aspose.Slides از نسبت تصویر استاندارد ۴:۳ استفاده می‌کنند.{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این کد نمونه نشان می‌دهد چگونه اندازه اسلاید را در یک ارائه با Java و Aspose.Slides تغییر دهید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مشخص کردن اندازه‌های اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های معمول اسلاید (۴:۳ و ۱۶:۹) برای کار شما مناسب نیستند، می‌توانید یک اندازه اسلاید خاص یا منحصر به فرد انتخاب کنید. به عنوان مثال، اگر قصد دارید اسلایدهای تمام‌اندازه را بر روی یک صفحه‌بندی سفارشی چاپ کنید یا ارائه خود را روی انواع خاصی از نمایشگرها نمایش دهید، احتمالاً از تنظیم اندازه سفارشی برای ارائه خود بهره‌مند خواهید شد.

این کد نمونه نشان می‌دهد چگونه با استفاده از Aspose.Slides برای Android از طریق Java یک اندازه اسلاید سفارشی برای یک ارائه در Java مشخص کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (تصاویر یا اشیاء، برای مثال) ممکن است مخدوش شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای تناسب با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید ارائه می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتویات اسلایدها برخورد کند.

بسته به آنچه می‌خواهید انجام دهید یا به‌دست آورید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر **نمی‌خواهید** اشیاء روی اسلایدها تغییر اندازه بدهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس دهید و نیاز دارید Aspose.Slides اشیاء اسلایدها را به‌گونه‌ای کوچک کند که همه آنها در اسلاید جا بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگتر مقیاس دهید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ‌نمایی کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه از تنظیم `Maximize` استفاده کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **پرسش‌های متداول**

### آیا می‌توانم اندازه اسلاید سفارشی را با واحدهایی غیر از اینچ (مثلاً نقطه یا میلی‌متر) تنظیم کنم؟

بله. Aspose.Slides به‌صورت داخلی از نقطه استفاده می‌کند که ۱ نقطه برابر ۱/۷۲ اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقطه تبدیل کنید و از مقادیر تبدیل‌شده برای تعیین عرض و ارتفاع اسلاید استفاده کنید.

### آیا یک اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه هنگام رندرینگ تأثیر می‌گذارد؟

بله. ابعاد بزرگ‌تر اسلاید (به نقطه) همراه با مقیاس رندرینگ بالاتر منجر به افزایش مصرف حافظه و زمان پردازش می‌شود. سعی کنید یک اندازه اسلاید عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دست‌یابی به کیفیت خروجی مطلوب تنظیم کنید.

### آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟

نمی‌توانید [ادغام ارائه‌ها](/slides/fa/androidjava/merge-presentation/) را هنگام داشتن اندازه‌های اسلاید متفاوت انجام دهید — ابتدا یک ارائه را به اندازه دیگر تغییر دهید. هنگام تغییر اندازه اسلاید می‌توانید نحوه برخورد با محتویات موجود را از طریق گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هم‌تنظیم کردن اندازه‌ها، می‌توانید اسلایدها را ترکیب کنید و قالب‌بندی را حفظ کنید.

### آیا می‌توانم برای اشکال فردی یا مناطق خاصی از یک اسלاید تصویر بندانگشتی تولید کنم و آیا اینها اندازه اسלاید جدید را رعایت می‌کنند؟

بله. Aspose.Slides می‌تواند تصاویر بندانگشتی برای [تمام اسלایدها](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) و همچنین برای [اشکال انتخابی](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) تولید کند. تصاویر حاصل نسبت به اندازه اسלاید فعلی و نسبت تصویر جاری انعکاس می‌دهند و اطمینان می‌دهند چارچوب و هندسه به‌صورت ثابت باقی بماند.
