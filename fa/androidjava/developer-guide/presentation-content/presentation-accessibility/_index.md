## **مقدمه**

متن جایگزین به افرادی که از فناوری‌های کمکی استفاده می‌کنند کمک می‌کند معنای تصاویر، نمودارها و سایر اشکال اطلاعاتی را درک کنند. این مقاله توضیح می‌دهد چگونه عنوان‌ها و توضیحات متن جایگزین را با Aspose.Slides برای Android از طریق Java بخوانید و به‌روز کنید، توضیحات دسترس‌پذیری را از نام‌های اشکال استفاده شده در کد متمایز کنید و بررسی کنید آیا یک شکل به‌عنوان تزئینی علامت‌گذاری شده است یا نه.

این ویژگی‌ها از دسترس‌پذیری ارائه پشتیبانی می‌کنند، اما تضمین‌کننده آن نیستند. ترتیب خواندن، کنتراست رنگ، قابلیت خواندن متن و سایر الزامات دسترس‌پذیری نیز باید بررسی شوند.

## **مدیریت عناوین متن جایگزین و توضیحات**

از متن جایگزین برای توضیح معنای تصاویر، نمودارها و سایر اشکال اطلاعاتی به افرادی که نمی‌توانند آنها را ببینند استفاده کنید. روش‌ها و محتواهای زیر اهداف متفاوتی دارند:

| روش یا محتوا | هدف |
| --- | --- |
| [getAlternativeTextTitle](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/ishape/#getAlternativeTextTitle--) | یک عنوان کوتاه برای توصیف جایگزین. |
| [getAlternativeText](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/ishape/#getAlternativeText--) | توصیف معنادار محتوا یا هدف شکل در زمینهٔ اسلاید. |
| [getName](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/ishape/#getName--) | نام شکل که کد می‌تواند از آن برای یافتن یک شکل خاص در ارائه استفاده کند. |
| متن قابل مشاهده | محتوایی که بر روی اسلاید نمایش داده می‌شود، مانند متن یک شکل یا عنوان و برچسب‌های یک نمودار. به‌روزرسانی متن جایگزین این محتوا را تغییر نمی‌دهد. |

هنگامی که یک ارائه به‌عنوان قالب مجدداً استفاده می‌شود، کد ممکن است قبل از به‌روزرسانی، شکل را با نامی که توسط [getName](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/ishape/#getName--) برگردانده می‌شود پیدا کند. این نام هدف متفاوتی نسبت به متن جایگزین دارد که توضیح می‌دهد تصویر چه اطلاعاتی را به خواننده منتقل می‌کند. جستجو بر پایه نام به نویسندگان اجازه می‌دهد توضیحات را بهبود یا ترجمه کنند بدون اینکه نحوهٔ یافتن شکل توسط کد تغییر یابد. نام‌ها قابل ویرایش هستند و تضمین نمی‌شود که یکتا باشند، بنابراین اطمینان حاصل کنید که نام با شکل مورد نظر مطابقت دارد؛ برای اطلاعات بیشتر به [شناسایی و یافتن اشکال](/slides/fa/androidjava/shape-manipulations/#identify-and-find-shapes) مراجعه کنید.

مثال زیر نیاز به فایلی به نام `input.pptx` دارد که شامل تصویری از ورودی یک دفتر به عنوان اولین شکل در اسلاید اول باشد. این تصویر نباید به‌عنوان تزئینی علامت‌گذاری شود. مثال عنوان و توصیف متن جایگزین فعلی را می‌خواند و چاپ می‌کند، هر دو مقدار را به‌روزرسانی می‌کند و ارائه را به‌عنوان `output.pptx` ذخیره می‌کند. متن را بر مبنای تصویر واقعی و اطلاعاتی که منتقل می‌کند تنظیم کنید.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);

    System.out.println("Alternative text title: " + shape.getAlternativeTextTitle());
    System.out.println("Alternative text description: " + shape.getAlternativeText());

    shape.setAlternativeTextTitle("Office entrance");
    shape.setAlternativeText("The office entrance has a wheelchair ramp to the right of the steps.");

    presentation.save("output.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

افزودن متن جایگزین به تنهایی تضمین نمی‌کند که ارائه کاملاً دسترس‌پذیر یا مطابق با استانداردهای دسترس‌پذیری باشد. توصیفات را برای دقت و مرتبط بودن بررسی کنید و همچنین ترتیب خواندن، کنتراست رنگ، متن قابل خواندن و سایر الزامات دسترس‌پذیری را بررسی نمایید. تصاویر اطلاعاتی نباید به‌عنوان تزئینی علامت‌گذاری شوند؛ بخش بعدی نشان می‌دهد چگونه [isDecorative](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/ishape/#isDecorative--) را بررسی کنید.

## **علامت‌گذاری به عنوان تزئینی**

علامت‌گذاری به عنوان تزئینی برای تصاویر صرفاً تزیینی استفاده می‌شود تا خوانندگان صفحه‌نمایش آن‌ها را نادیده بگیرند، بنابراین نویز کاهش یافته و تمرکز بر محتوای معنادار باقی می‌ماند. این ویژگی را برای پس‌زمینه‌ها، تزئینات و فاصل‌گذارها اعمال کنید—هرگز برای نمودارها، آیکون‌ها یا تصاویری که اطلاعاتی منتقل می‌کنند. Aspose.Slides این پرچم را برای شناسایی و اعتبارسنجی فراهم می‌کند و امکان انجام بررسی‌های خودکار دسترس‌پذیری و پاکسازی را می‌دهد.

![علامت‌گذاری به عنوان تزئینی](mark_as_decorative.png)

کد نمونهٔ زیر نشان می‌دهد چگونه تعیین کنید آیا یک شکل به‌عنوان تزئینی علامت‌گذاری شده است یا خیر.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("sample.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);
    System.out.println("Is shape decorative: " + shape.isDecorative());
} finally {
    presentation.dispose();
}
```

## **پرسش‌های متداول**

**چه چیزی باید در عنوان و توصیف متن جایگزین قرار دهم؟**  
یک عنوان کوتاه برای شناسایی موضوع استفاده کنید و توصیفی برای توضیح اطلاعاتی که تصویر در قالب اسلاید منتقل می‌کند ارائه دهید. برای یک نمودار، روند یا مقایسهٔ مرتبط را توصیف کنید نه فقط «نمودار» بنویسید.

**آیا باید از متن جایگزین برای یافتن اشکال در یک قالب استفاده کنم؟**  
به‌جای آن، ترجیحاً شکل را با نامی که توسط [getName](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/ishape/#getName--) برگردانده می‌شود پیدا کنید و اطمینان حاصل کنید که همان شکل مورد انتظار است. متن جایگزین ممکن است ویرایش یا ترجمه شود و می‌تواند کد جستجو برای توصیف دقیق را بشکند؛ برای جزئیات به [شناسایی و یافتن اشکال](/slides/fa/androidjava/shape-manipulations/) مراجعه کنید.

**چه زمانی یک شکل باید به‌عنوان تزئینی علامت‌گذاری شود؟**  
پرچم تزئینی را برای تصاویری که هیچ اطلاعاتی اضافه نمی‌کنند، مانند تزئینات تزیینی، استفاده کنید. تصاویر و نمودارهایی که معنایی دارند باید توصیف مناسب داشته باشند.

**آیا افزودن متن جایگزین باعث می‌شود ارائه کاملاً دسترس‌پذیر شود؟**  
خیر. متن جایگزین تنها بخشی از دسترس‌پذیری را پوشش می‌دهد. همچنین باید ترتیب خواندن، کنتراست رنگ، قابلیت خواندن متن و سایر الزامات مرتبط را بررسی کنید؛ تنظیم این ویژگی‌ها به تنهایی سازگاری را تضمین نمی‌کند.
