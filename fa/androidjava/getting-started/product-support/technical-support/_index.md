## **بررسی کلی**

این مقاله توضیح می‌دهد که چگونه می‌توانید پشتیبانی Aspose.Slides را دریافت کنید و چگونه به‌صورت مؤثر مشکلات را گزارش دهید. این مقاله کانال اصلی پشتیبانی را شرح می‌دهد، توصیه‌هایی برای ارسال یک مشکل ارائه می‌کند و به منابع فنی مفیدی مانند صفحه محصول، بلاگ، دانلودها، انجمن پشتیبانی، مستندات و API Reference اشاره می‌کند. همچنین به سؤالات رایج درباره پشتیبانی پولی، ارتقاء مشکل و پشتیبانی از نسخه‌های قدیمی کتابخانه پاسخ می‌دهد.

## **پشتیبانی فنی**

{{% alert color="info" %}} 

Aspose پشتیبانی فنی نامحدود و رایگان برای تمام محصولات خود ارائه می‌دهد. این پشتیبانی برای تمام کاربران (از جمله کاربران با بسته‌های ارزیابی) در دسترس است.

{{% /alert %}} 

هنگامی که به کمک برای Aspose.Slides for Android via Java نیاز دارید، موارد زیر را در نظر بگیرید:

- مسیر اصلی پشتیبانی، Aspose.Forums است. سؤال خود را در انجمن Aspose.Slides ارسال کنید و ظرف چند ساعت پاسخی دریافت خواهید کرد. تیم پشتیبانی Aspose.Slides به‌صورت مستقیم به سؤالات ارسال شده در انجمن پاسخ می‌دهد.
- لطفاً توجه داشته باشید که Aspose پشتیبانی فنی از طریق تلفن ارائه نمی‌دهد. پشتیبانی تلفنی فقط برای سؤالات فروش و خرید در دسترس است.
- هنگام انتظار برای پاسخ در انجمن‌ها، صبور باشید و اختلافات ساعتی منطقه زمانی را در نظر بگیرید.

وقتی با مشکلی در Aspose.Slides for Android via Java مواجه می‌شوید، برای حل آن به‌کارآمدترین شکل ممکن، این راهنمایی‌ها را دنبال کنید:

- پیش از گزارش مشکل، اطمینان حاصل کنید که از آخرین نسخه Aspose.Slides for Android via Java استفاده می‌کنید. شاید مشکلی که تجربه کردید در به‌روزرسانی قبلی رفع شده باشد.  

  برای دریافت اطلاعات درباره آخرین نسخه به دانلود Aspose.Slides مراجعه کنید.

- پیش از گزارش یک مشکل، ممکن است بخواهید انجمن‌ها، این مستندات و API Reference را مرور کنید. شاید پاسخ سؤال شما قبلاً ارائه شده باشد.

- هنگام گزارش یک مشکل، لطفاً سند اصلی و (در صورت امکان) بخشی از کد مربوط به مشکل را ضمیمه کنید. اگر نیاز به پیوست چندین فایل دارید، آنها را در یک بسته ZIP قرار دهید.  

  می‌توانید به‌صورت ایمن اسناد خود را در Aspose.Forums پیوست کنید، زیرا فقط شما و توسعه‌دهندگان Aspose به فایل‌های پیوست‌شده دسترسی دارند.

- برای هر مشکل خاص یک موضوع ایجاد و استفاده کنید. اگر مشکل دیگری دارید، باید یک موضوع دیگر ایجاد کنید تا آن را گزارش دهید.

## **سؤالات متداول**

### چه سطوح پشتیبانی پولی در دسترس هستند و چگونه با هم متفاوتند؟

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). این سطوح بر اساس تعداد حوادث شامل‌شده، اولویت پاسخ و کانال‌های ارتباطی موجود متفاوت هستند.

### آیا می‌توانم یک باگ را مستقیماً به تیم مهندسی ارجاع دهم؟

بله. [Paid support](https://helpdesk.aspose.com/) امکان ارتقاء به توسعه‌دهندگان را هنگامی که یک مشکل نیاز به بررسی عمیق‌تر دارد، فراهم می‌کند.

### آیا نسخه‌های قدیمی کتابخانه پشتیبانی می‌شوند و آیا برای آنها اصلاحات منتشر می‌کنید؟

می‌توانید از نسخه‌های قدیمی استفاده کنید، اما اصلاحات فقط برای نسخه جاری ارائه می‌شود؛ برای نسخه‌های قدیمی پچی منتشر نمی‌شود.
