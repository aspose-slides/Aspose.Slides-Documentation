## **بررسی کلی**

Aspose.Slides می‌تواند در حالت ارزیابی یا با یک مجوز معتبر مورد استفاده قرار گیرد. نسخه ارزیابی همان عملکرد نسخه دارای مجوز را ارائه می‌دهد، اما هنگام باز یا ذخیره‌سازی ارائه‌ها یک واترمارک ارزیابی اضافه می‌کند و استخراج متن را به یک اسلاید محدود می‌کند.

این مقاله توضیح می‌دهد که مجوزدهی در Aspose.Slides چگونه کار می‌کند و چگونه قبل از استفاده از کتابخانه یک مجوز اعمال شود. یک مجوز می‌تواند از یک فایل، جریان یا منبع تعبیه‌شده با استفاده از کلاس `License` بارگذاری شود. مقاله همچنین نشان می‌دهد چگونه اعتبارسنجی کنید که آیا مجوز به درستی اعمال شده است یا خیر.

پس از اینکه از ارزیابی **Aspose.Slides** راضی شدید، می‌توانید [خرید یک مجوز](https://purchase.aspose.com/buy) را انجام دهید. توصیه می‌کنیم انواع مختلف اشتراک را بررسی کنید. اگر سؤال دارید، با تیم فروش Aspose تماس بگیرید.

هر مجوز Aspose همراه با یک سال اشتراک برای ارتقاهای رایگان به نسخه‌های جدید یا رفع‌خطاهایی که در دورهٔ اشتراک منتشر می‌شوند، ارائه می‌شود. کاربران با محصولات دارای مجوز (یا حتی نسخه‌های ارزیابی) پشتیبانی فنی رایگان و نامحدود دریافت می‌کنند.

## **مجوزدهی در Aspose.Slides**

* یک نسخه ارزیابی پس از خرید مجوز و افزودن چند خط کد (برای اعمال مجوز) به یک نسخه دارای مجوز تبدیل می‌شود.
* مجوز یک فایل XML متنی ساده است که جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که برای آن مجوز صادر شده است، تاریخ انقضای اشتراک و غیره را شامل می‌شود. 
* فایل مجوز به صورت دیجیتالی امضا شده است، بنابراین نباید آن را اصلاح کنید. حتی افزودن یک خط جدید ناخواسته به محتوای فایل باعث عدم اعتبار آن می‌شود.
* Aspose.Slides for Android via Java معمولاً سعی می‌کند مجوز را در این مکان‌ها پیدا کند:
  * مسیر صریح
  * پوشه‌ای که Aspose.Slides.jar در آن قرار دارد
* برای جلوگیری از محدودیت‌های نسخه ارزیابی، باید قبل از استفاده از **Aspose.Slides** یک مجوز تنظیم کنید. تنها یک بار در هر برنامه یا پردازش کافی است مجوز تنظیم شود.

## **اعمال یک مجوز**

یک مجوز می‌تواند از یک **فایل** یا **جریان** بارگذاری شود.

{{% alert color="info" %}}

Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/license/) را برای عملیات مجوزدهی فراهم می‌کند.

{{% /alert %}} 

{{% alert color="warning" %}}

مجوزهای جدید تنها می‌توانند Aspose.Slides را با نسخهٔ 21.4 یا بالاتر فعال کنند. نسخه‌های قبلی از یک سیستم مجوزدهی متفاوت استفاده می‌کنند و این مجوزها را شناسایی نمی‌کنند.

{{% /alert %}}

### **فایل**

سطح آسان‌ترین روش تنظیم مجوز این است که فایل مجوز را در پوشه‌ای که Aspose.Slides.jar یا فایل jar برنامهٔ شما قرار دارد، بگذارید.

این کد Java نشان می‌دهد چگونه یک فایل مجوز تنظیم شود:

``` java
// یک نمونه از کلاس License ایجاد می‌کند
com.aspose.slides.License license = new com.aspose.slides.License();

// مسیر فایل مجوز را تنظیم می‌کند
license.setLicense("Aspose.Slides.Android.via.Java.lic");
```

{{% alert color="warning" %}} 

اگر فایل مجوز را در مسیر دیگری قرار دهید، هنگام فراخوانی متد [SetLicense](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-)، نام فایل مجوز در انتهای مسیر صریح باید همان نام فایل مجوز شما باشد.

به عنوان مثال می‌توانید نام فایل مجوز را به *Aspose.Slides.Android.via.Java.lic.xml* تغییر دهید. سپس در کد خود باید مسیر فایل (با انتهای *Aspose.Slides.Android.via.Java.lic.xml*) را برای متد [SetLicense](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-) ارسال کنید.

{{% /alert %}}

### **جریان**

می‌توانید مجوز را از یک جریان بارگذاری کنید. این کد Java نشان می‌دهد چگونه یک مجوز را از یک جریان اعمال کنید:

``` java
// یک نمونه از کلاس License ایجاد می‌کند
com.aspose.slides.License license = new com.aspose.slides.License();

// مجوز را از طریق یک جریان تنظیم می‌کند
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Android.via.Java.lic"));
```

## **اعتبارسنجی یک مجوز**

برای بررسی اینکه آیا یک مجوز به درستی تنظیم شده است یا نه، می‌توانید آن را اعتبارسنجی کنید. این کد Java نشان می‌دهد چگونه یک مجوز را اعتبارسنجی کنید:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Android.via.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **ایمنی رشته**

{{% alert title="Note" color="warning" %}} 

متد [SetLicense](https://reference.aspose.com/slides/fa/androidjava/com.aspose.slides/license/#setLicense-java.io.InputStream-) ایمن در برابر ریسک‌های همزمانی نیست. اگر این متد نیاز به فراخوانی همزمان از چندین رشته داشته باشد، بهتر است از سازوکارهای همگام‌سازی (مانند یک قفل) برای جلوگیری از مشکلات استفاده کنید. 

{{% /alert %}}

## **سوالات متداول**

### آیا می‌توانم مجوز را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی مجوز به صورت محلی با استفاده از فایل مجوز انجام می‌شود؛ نیازی به اتصال اینترنتی نیست.

### پس از انقضای یک‌سالهٔ اشتراک چه اتفاقی می‌افتد؟ آیا کتابخانه متوقف می‌شود؟

خیر. مجوز دائمی است: می‌توانید از نسخه‌هایی که قبل از تاریخ پایان اشتراک‌تان منتشر شده‌اند استفاده کنید؛ اما بدون تمدید نمی‌توانید از نسخه‌های جدیدتر استفاده کنید.
