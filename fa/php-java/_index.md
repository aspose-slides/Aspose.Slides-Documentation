**به Aspose.Slides for PHP via Java خوش آمدید**

![لوگوی محصول Aspose.Slides برای PHP از طریق Java](aspose_slides-for-php-via-java.png)

Aspose.Slides for PHP via Java یک کتابخانهٔ کلاس است که به برنامه‌های شما امکان خواندن و نوشتن اسناد PowerPoint® را بدون استفاده از Microsoft PowerPoint® می‌دهد.

Aspose.Slides for PHP via Java اولین و تنها مؤلفه‌ای است که قابلیت مدیریت اسناد PowerPoint® را فراهم می‌کند.

Aspose.Slides for PHP via Java ویژگی‌های کلیدی فراوانی ارائه می‌دهد از جمله مدیریت متن، اشکال، جداول و انیمیشن‌ها، افزودن صوت و ویدئو به اسلایدها، پیش‌نمایش اسلایدها، خروجی گرفتن اسلایدها به فرمت SVG، PDF و موارد دیگر.
