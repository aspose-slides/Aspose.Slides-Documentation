## **پلتفرم‌های پشتیبانی‌شده**
Aspose.Slides for PHP via Java یک API مستقل از پلتفرم است. می‌توان آن را بر روی هر پلتفرمی (Windows، Linux، macOS و غیره) که PHP 7 یا بالاتر نصب شده باشد، استفاده کرد. Oracle JDK 7 یا بالاتر نیز یک پیش‌نیاز دیگر است.

## **فرمت‌های فایل و تبدیل‌ها**
Aspose.Slides for PHP via Java بیشترین فرمت‌های سند PowerPoint را پشتیبانی می‌کند. همچنین امکان صادرات این اسناد به فرمت‌های رایج که سازمان‌ها برای به‌اشتراک‌گذاری استفاده می‌کنند، را فراهم می‌آورد. جزئیات زیر را مرور کنید:

|**ویژگی**|**توضیح**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java سریع‌ترین پردازش را برای این فرمت ارائه می‌دهد.|
|تبدیل PPT به PPTX|Aspose.Slides for PHP via Java از تبدیل PPT به PPTX پشتیبانی می‌کند|
|Portable Document Format (PDF)|می‌توانید همه فرمت‌های فایل پشتیبانی‌شده را با یک متد به سندهای Adobe Portable Document Format (PDF) صادر کنید.|
|XML Parser Specification (XPS)|می‌توانید همه فرمت‌های فایل پشتیبانی‌شده را با یک متد به سندهای XML Parser Specification (XPS) صادر کنید.|
|Tagged Image File Format (TIFF)|می‌توانید همه فرمت‌های پرونده ارائه را به Tagged Image File Format (TIFF) صادر کنید.|
|تبدیل PPTX به HTML|Aspose.Slides for PHP via Java تبدیل PresentationEx به فرمت HTML را پشتیبانی می‌کند.|

## **رندر ارائه**
Aspose.Slides for PHP via Java رندر با دقت بالا از اسلایدهای ارائه به فرمت‌های گرافیکی مختلف را پشتیبانی می‌کند. جزئیات زیر را مرور کنید:

|**ویژگی**|**توضیح**|
| :- | :- |
|فرمت‌های تصویری پشتیبانی‌شده توسط Java|با استفاده از Aspose.Slides for PHP via Java، می‌توانید اسلایدهای ارائه و تصاویری روی اسلایدها را به تمام فرمت‌های گرافیکی پشتیبانی‌شده توسط Java مانند TIFF، PNG، BMP، JPEG، GIF رندر کنید.|
|فرمت SVG|Aspose.Slides for PHP via Java همچنین متدهای داخلی برای صادر کردن اسلایدهای ارائه به فرمت Scalable Vector Graphics (SVG) فراهم می‌آورد.|

## **سوالات متداول**

### آیا برای عملکرد کتابخانه نیاز به نصب Microsoft PowerPoint بر روی سرور/کامپیوتر دارم؟

خیر. PowerPoint لازم نیست؛ Aspose.Slides یک موتور مستقل برای ایجاد، ویرایش، تبدیل و رندر ارائه‌ها است.

### چندنخی چگونه کار می‌کند؟ آیا می‌توان پردازش را به صورت موازی انجام داد؟

ایمن است که اسناد مختلف را در نخ‌های متفاوت پردازش کنید؛ شیٔ [presentation](https://reference.aspose.com/slides/fa/php-java/aspose.slides/presentation/) نباید همزمان توسط [multiple threads](/slides/fa/php-java/multithreading/) استفاده شود.

### آیا رمزهای عبور فایل‌ها و رمزنگاری پشتیبانی می‌شود؟

بله. [You can](/slides/fa/php-java/password-protected-presentation/) می‌توانید ارائه‌های رمزگذاری‌شده را باز کنید، رمزهای باز و نوشتن را تنظیم یا حذف کنید و وضعیت حفاظت را بررسی کنید.

### آیا در کانتینرهای لینوکس باید به بسته‌های قلم توجه کنم؟

بله. توصیه می‌شود بسته‌های قلم رایج را نصب کنید و/یا به‌طور صریح [specify font directories](/slides/fa/php-java/custom-font/) را در برنامه‌تان مشخص کنید تا از جایگزینی‌های غیرمنتظره جلوگیری شود.

### آیا در نسخه ارزیابی محدودیتی وجود دارد؟

در [evaluation mode](/slides/fa/php-java/licensing/) یک واترمارک به خروجی اضافه می‌شود و محدودیت‌های خاصی اعمال می‌گردد؛ یک [30-day temporary license](https://purchase.aspose.com/temporary-license/) برای تست کامل ویژگی‌ها در دسترس است.

### آیا وارد کردن فرمت‌های خارجی به ارائه (PDF/HTML → PPTX) پشتیبانی می‌شود؟

بله. می‌توانید [PDF pages and HTML content](/slides/fa/php-java/import-presentation/) را به یک ارائه اضافه کنید و آن‌ها را به اسلاید تبدیل کنید.
