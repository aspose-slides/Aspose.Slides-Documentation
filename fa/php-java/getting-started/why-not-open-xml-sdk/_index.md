## **بررسی کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است برای کار با اسناد ارائه، Open XML SDK یا Aspose.Slides را انتخاب کنند. Open XML SDK را به‌عنوان کتابخانه‌ای برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن توصیف می‌کند، در حالی که Aspose.Slides به‌عنوان کتابخانه‌ای پردازش ارائه با مدل شیء سطح‑بالا و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، رندرینگ، پشتیبانی از پلتفرم‌ها و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیده‌تر ارائه مانند کار با چندین فرمت PowerPoint، کپی یا کلون کردن اشکال، جایگزینی متن، اعمال انیمیشن‌ها و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
طبق [کتابخانه MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به‌صورت زیر تعریف می‌شود: 

Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر اسکیمای Open XML زیرین یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای رایج که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند را در خود خلاصه کرده است، به‌طوری که می‌توانید عملیات پیچیده را فقط با چند خط کد انجام دهید.

اسناد OOXML اساساً فایل‌های فشرده XML هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما امکان می‌دهد محتویات اسناد OOXML را به‌صورت قوی‑تایپ‌دار مدیریت کنید. به‌عبارت دیگر، به‌جای استخراج XML از فایل فشرده، بارگذاری آن در یک درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی فراهم می‌کند که این کارها را برای شما انجام می‌دهد.

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانهٔ کلاس است که به برنامهٔ شما امکان انجام وظایف زیر را می‌دهد:

- برنامه‌نویسی با مدل شیء **Presentation**.
- تبدیل با کیفیت بالا بین تمام فرمت‌های محبوب پشتیبانی‌شدهٔ PowerPoint، از جمله تبدیل به PDF، XPS و TIFF.
- توانایی تولید تصویرک‌های اسلاید در قالب‌های شناخته‌شده مانند PNG، JPEG و BMP به‌همراه خروجی اسلاید به SVG.
- توانایی ساخت ارائه‌ها از صفر یا ترکیب آن‌ها از یک یا چند سند.
- پشتیبانی از افزودن انیمیشن‌ها، فریم‌های OLE، جدول‌ها، ایجاد و مدیریت نمودارها.
- در دسترس بودن کنترل گسترده برای مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر دربارهٔ ویژگی‌های پشتیبانی‌شده، لطفاً به [ویژگی‌های Aspose.Slides](/slides/fa/php-java/product-overview/) مراجعه کنید.

## **نتیجه‌گیری**
{{% alert color="info" %}} 

Open XML SDK و Aspose.Slides با هم رقابت مستقیم ندارند زیرا نیازها و مخاطبان متفاوتی را هدف قرار می‌دهند. Open XML SDK یک کتابخانهٔ کلاس است که شیء‑تایپ‌دار قوی‌ای برای کار با اسناد OOXML فراهم می‌کند. Aspose.Slides کتابخانه‌ای بسیار مفید برای پردازش ارائه‌هاست که پشتیبانی عالی‌ای برای تقریباً تمام فرمت‌های فایل Microsoft PowerPoint ارائه می‌دهد.

اگر تنها نیاز دارید عملی برنامه‌نویسی نسبتاً ساده بر روی سند PPTX انجام دهید، Open XML SDK می‌تواند انتخاب مناسبی باشد. با Open XML SDK می‌توانید به راحتی کارهای ساده‌ای مانند تولید یک سند PPTX ساده، حذف نظرات، سرصفحه‌ها/پاصفحه‌ها، استخراج تصویرها یا موارد مشابه را انجام دهید. برخی وظایف می‌توانند با Open XML SDK انجام شوند ولی با Aspose.Slides قابل انجام نیستند. به‌عنوان مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML داشته باشید، باید از Open XML SDK استفاده کنید. اما اگر نیاز به انجام عملیات پیچیده بر روی اسناد داشته باشید، مانند برخی از وظایف زیر، استفاده از Aspose.Slides بهترین گزینهٔ شماست:

- پشتیبانی از فرمت‌های قدیمی PowerPoint علاوه بر PPTX.
- کپی یا کلون کردن اشکال در اسلایدها به‑نحوی که اشیاء، سبک‌ها و دیگر قالب‌بندی‌ها به‌درستی ترکیب شوند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از اتصالات بین اشکال.
- تبدیل سند به PDF، TIFF یا XPS به‌طوری که دقیقاً همان‌گونه که Microsoft PowerPoint تبدیل می‌کند، نمایش داده شود.
- توسعهٔ برنامهٔ .NET یا Java در هر دو محیط دسکتاپ و وب.
