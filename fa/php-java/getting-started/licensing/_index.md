## **ارزیابی Aspose.Slides**
می‌توانید به راحتی Aspose.Slides را برای ارزیابی دانلود کنید. بسته ارزیابی دقیقاً همان بسته خریداری شده است. نسخه ارزیابی پس از افزودن چند خط کد برای اعمال لایسنس به طور خودکار لایسنس‌دار می‌شود.

## **محدودیت نسخه ارزیابی**
نسخه ارزیابی Aspose.Slides (بدون لایسنس مشخص) تمام قابلیت‌های محصول را فراهم می‌کند، اما دو محدودیت دارد:

* یک جعبه متن واترمارک ارزیابی را در وسط هر اسلاید از هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند.  
* متنی که کد شما از یک ارائه می‌خواند به چند کاراکتر اول محدود می‌شود و سپس یک اعلان درباره محدودیت ارزیابی اضافه می‌شود. متنی که کد شما می‌نویسد به‌صورت کامل ذخیره می‌شود.

{{% alert color="info" title="Note" %}}
اگر می‌خواهید Aspose.Slides را بدون محدودیت‌های نسخه ارزیابی تست کنید، می‌توانید یک **مجوز موقت 30 روزه** درخواست کنید. لطفاً برای اطلاعات بیشتر به [چگونه یک مجوز موقت دریافت کنیم؟](https://purchase.aspose.com/temporary-license) مراجعه کنید.
{{% /alert %}} 

## **درباره لایسنس**
می‌توانید به راحتی نسخه ارزیابی Aspose.Slides برای PHP via Java را از [صفحه دانلود](https://packagist.org/packages/aspose/slides) دریافت کنید. نسخه ارزیابی کاملاً **همان قابلیت‌ها** را به عنوان نسخه لایسنس‌دار Aspose.Slides فراهم می‌کند. علاوه بر این، نسخه ارزیابی پس از خرید لایسنس و افزودن چند خط کد برای اعمال لایسنس لایسنس‌دار می‌شود.

لایسنس یک فایل XML متنی ساده است که شامل جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که برای آن لایسنس صادر شده، تاریخ انقضای اشتراک و غیره می‌باشد. این فایل به صورت دیجیتال امضا شده است، بنابراین آن را اصلاح نکنید. حتی افزودن یک خط جدید ناخواسته به محتوای فایل نیز اعتبار آن را از بین می‌برد.

برای جلوگیری از محدودیت‌های مرتبط با نسخه ارزیابی، باید قبل از استفاده **Aspose.Slides** یک لایسنس تنظیم کنید. شما فقط یک بار در هر برنامه یا فرآیند نیاز به تنظیم لایسنس دارید.

{{% alert color="info" title="Note" %}}
ممکن است بخواهید [مجوز متره‌ای](/slides/fa/php-java/metered-licensing/) را نیز ببینید.
{{% /alert %}}

### **تنظیم لایسنس در Aspose.Slides برای PHP از طریق Java**

لایسنس می‌تواند از این مکان‌ها اعمال شود:

* مسیر صریح
* جریان
* به‌عنوان لایسنس متره‌ای – یک مکانیزم جدید لایسنسینگ

{{% alert color="info" title="Note" %}}
از روش **setLicense** برای لایسنس‌گذاری یک مؤلفه استفاده کنید.

در حالی که چندین فراخوانی به **setLicense** ضرری ندارد، اما منبع (پردازنده) را هدر می‌دهد.
{{% /alert %}}

{{% alert color="warning" title="Warning" %}}
لایسنس‌های جدید می‌توانند Aspose.Slides را تنها با نسخه 21.4 یا بالاتر فعال کنند. نسخه‌های قدیمی‌تر از یک سیستم لایسنسینگ متفاوت استفاده می‌کنند و این لایسنس‌ها را شناسایی نمی‌کنند.
{{% /alert %}}

#### **اعمال لایسنس با استفاده از فایل**

این قطعه کد برای تنظیم یک فایل لایسنس استفاده می‌شود:

**PHP**

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/fa/lib/aspose.slides.php");

use aspose\slides\License;

$license = new License();
$license->setLicense(__DIR__ . "/Aspose.Slides.lic");
```

نمونه انتظار دارد فایل لایسنس در کنار اسکریپت باشد و مسیر مطلق آن را دریافت کند: Aspose.Slides داخل Tomcat اجرا می‌شود، بنابراین مسیر نسبی نسبت به پوشه اسکریپت شما حل نمی‌شود. هنگام فراخوانی متد setLicense، نام لایسنس باید همان نام فایل لایسنس شما باشد. برای مثال می‌توانید نام فایل لایسنس را به "Aspose.Slides.lic.xml" تغییر دهید. سپس در کد خود باید نام لایسنس جدید (Aspose.Slides.lic.xml) را به متد setLicense پاس کنید.

#### **اعمال لایسنس از یک جریان**

این قطعه کد برای اعمال لایسنس از یک جریان استفاده می‌شود:

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/fa/lib/aspose.slides.php");

use aspose\slides\License;

$stream = new Java("java.io.FileInputStream", __DIR__ . "/Aspose.Slides.lic");

$license = new License();
$license->setLicense($stream);

$stream->close();
```

## **سوالات متداول**

### آیا می‌توانم لایسنس را در محیطی کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ نیازی به اتصال اینترنت نیست.

### پس از انقضای اشتراک یک‌ساله چه اتفاقی می‌افتد؟ آیا کتابخانه متوقف می‌شود؟

خیر. لایسنس دائم است: می‌توانید از نسخه‌هایی که قبل از تاریخ پایان اشتراک شما منتشر شده‌اند استفاده کنید؛ فقط بدون تمدید، دسترسی به نسخه‌های جدیدتر ممکن نخواهد بود.
