## **معرفی**

هنگامی که یک ارائه را با رمز عبور محافظت می‌کنید، به این معناست که رمز عبوری تنظیم می‌کنید که محدودیت‌های خاصی بر ارائه اعمال می‌کند. برای حذف این محدودیت‌ها باید رمز عبور وارد شود. یک ارائه محافظت‌شده با رمز عبور به‌عنوان یک ارائه قفل‌شده در نظر گرفته می‌شود.

به‌طور معمول، می‌توانید برای اعمال این محدودیت‌ها بر یک ارائه، رمز عبور تنظیم کنید:

- **تغییر**

  اگر می‌خواهید فقط کاربران خاصی بتوانند ارائه شما را تغییر دهند، می‌توانید یک محدودیت تغییر را تنظیم کنید. این محدودیت از تغییر، اصلاح یا کپی‌کردن موارد در ارائه شما جلوگیری می‌کند (مگر اینکه رمز عبور را ارائه دهند).

  با این حال، در این حالت حتی بدون رمز عبور، کاربر می‌تواند به سند شما دسترسی پیدا کرده و آن را باز کند. در این حالت فقط‑خواندنی، کاربر می‌تواند محتوای ارائه شامل پیوندها، انیمیشن‌ها، جلوه‌ها و سایر موارد را مشاهده کند، اما نمی‌تواند موارد را کپی کرده یا ارائه را ذخیره کند.

- **باز کردن**

  اگر می‌خواهید فقط کاربران خاصی بتوانند ارائه شما را باز کنند، می‌توانید یک محدودیت باز کردن را تنظیم کنید. این محدودیت از مشاهده محتوای ارائه حتی جلوگیری می‌کند (مگر اینکه رمز عبور را ارائه دهند).

  از نظر فنی، محدودیت باز کردن همچنین از اصلاح ارائه‌های شما جلوگیری می‌کند: وقتی افراد نمی‌توانند یک ارائه را باز کنند، نمی‌توانند آن را تغییر دهند یا تغییراتی اعمال کنند.

**توجه** داشته باشید که وقتی یک ارائه را با رمز عبور برای جلوگیری از باز کردن محافظت می‌کنید، فایل ارائه رمزنگاری می‌شود.

## **حفاظت با رمز عبور از ارائه‌ها در Aspose.Slides**
**فرمت‌های پشتیبانی‌شده**

Aspose.Slides برای ارائه‌ها در این فرمت‌ها از حفاظت با رمز عبور، رمزنگاری و عملیات مشابه پشتیبانی می‌کند:

- PPTX و PPT - ارائه مایکروسافت پاورپوینت
- ODP - ارائه OpenDocument
- OTP - قالب ارائه OpenDocument

**عملیات‌های پشتیبانی‌شده**

Aspose.Slides به شما امکان می‌دهد با استفاده از حفاظت با رمز عبور از ارائه‌ها جلوگیری از تغییرات به این روش‌ها انجام دهید:

- رمزنگاری یک ارائه
- تنظیم محافظت نوشتاری برای یک ارائه

**سایر عملیات**

Aspose.Slides به شما اجازه می‌دهد کارهای دیگری که شامل حفاظت با رمز عبور و رمزنگاری می‌شود، به این روش‌ها انجام دهید:

- رمزگشایی یک ارائه؛ باز کردن یک ارائه رمزنگاری‌شده
- حذف رمزنگاری؛ غیرفعال‌سازی حفاظت با رمز عبور
- حذف محافظت نوشتاری از یک ارائه
- دریافت ویژگی‌های یک ارائه رمزنگاری‌شده
- بررسی اینکه آیا یک ارائه رمزنگاری شده است
- بررسی اینکه آیا یک ارائه با رمز عبور محافظت شده است.

## **رمزنگاری یک ارائه**

می‌توانید با تنظیم یک رمز عبور، یک ارائه را رمزنگاری کنید. سپس برای اصلاح ارائه قفل‌شده، کاربر باید رمز عبور را ارائه دهد.

برای رمزنگاری یا محافظت با رمز عبور از یک ارائه، باید از متد encrypt (از [ProtectionManager](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/)) برای تنظیم رمز عبور برای ارائه استفاده کنید. رمز عبور را به متد encrypt پاس می‌دهید و با استفاده از متد save، ارائه حالا رمزنگاری‌شده را ذخیره می‌کنید.

این کد نمونه نشان می‌دهد چگونه یک ارائه را رمزنگاری کنید:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->encrypt("123123");
    $presentation->save("encrypted-pres.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **تنظیم محافظت نوشتاری برای یک ارائه**

می‌توانید علامتی با متن «تغییر نشد» به یک ارائه اضافه کنید. به این ترتیب به کاربران می‌گویید که نمی‌خواهید آن‌ها تغییراتی در ارائه اعمال کنند.

**توجه** داشته باشید که فرآیند محافظت نوشتاری، ارائه را رمزنگاری نمی‌کند. بنابراین، کاربران—اگر واقعاً بخواهند—می‌توانند ارائه را تغییر دهند، اما برای ذخیره تغییرات باید ارائه‌ای با نام متفاوت ایجاد کنند.

برای تنظیم محافظت نوشتاری، باید از متد [setWriteProtection](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#setWriteProtection) استفاده کنید. این کد نمونه نشان می‌دهد چگونه یک محافظت نوشتاری به یک ارائه تنظیم کنید:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->setWriteProtection("123123");
    $presentation->save("write-protected-pres.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **بارگذاری یک ارائه رمزنگاری‌شده**

Aspose.Slides به شما امکان می‌دهد یک فایل رمزنگاری‌شده را با پاس دادن رمز عبور آن بارگذاری کنید. برای رمزگشایی یک ارائه، باید متد [removeEncryption](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#removeEncryption) را بدون پارامتر فراخوانی کنید. سپس باید رمز عبور صحیح را وارد کنید تا ارائه بارگذاری شود.

این کد نمونه نشان می‌دهد چگونه یک ارائه را رمزگشایی کنید:

```php
  $loadOptions = new LoadOptions();
  $loadOptions->setPassword("123123");
  $presentation = new Presentation("pres.pptx", $loadOptions);
  try {
    # کار با ارائه رمزگشایی‌شده
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **حذف رمزنگاری از یک ارائه**

می‌توانید رمزنگاری یا حفاظت با رمز عبور را از یک ارائه حذف کنید. به این ترتیب کاربران قادر خواهند شد بدون محدودیت‌ها به ارائه دسترسی پیدا کنند یا آن را اصلاح کنند.

برای حذف رمزنگاری یا حفاظت با رمز عبور، باید متد [removeEncryption](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#removeEncryption) را فراخوانی کنید. این کد نمونه نشان می‌دهد چگونه رمزنگاری را از یک ارائه حذف کنید:

```php
  $loadOptions = new LoadOptions();
  $loadOptions->setPassword("123123");
  $presentation = new Presentation("pres.pptx", $loadOptions);
  try {
    $presentation->getProtectionManager()->removeEncryption();
    $presentation->save("encryption-removed.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **حذف محافظت نوشتاری از یک ارائه**

می‌توانید از Aspose.Slides برای حذف محافظت نوشتاری استفاده شده بر روی یک فایل ارائه استفاده کنید. به این صورت، کاربران می‌توانند همان‌طور که می‌خواهند تغییرات انجام دهند و هیچ هشدارهایی هنگام انجام این کار دریافت نمی‌کنند.

می‌توانید با استفاده از متد [removeWriteProtection](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#removeWriteProtection) محافظت نوشتاری را از یک ارائه حذف کنید. این کد نمونه نشان می‌دهد چگونه محافظت نوشتاری را از یک ارائه حذف کنید:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->removeWriteProtection();
    $presentation->save("write-protection-removed.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **دریافت ویژگی‌های یک ارائه رمزنگاری‌شده**

به‌طور معمول، کاربران برای بازیابی ویژگی‌های سند یک ارائه رمزنگاری‌شده یا محافظت‌شده با رمز عبور مشکل دارند. با این حال، Aspose.Slides مکانیزمی ارائه می‌دهد که به شما امکان می‌دهد ارائه را با رمز عبور محافظت کنید در حالی که همچنان قابلیت دسترسی کاربران به ویژگی‌های آن حفظ می‌شود.

**توجه:** به‌صورت پیش‌فرض، وقتی Aspose.Slides یک ارائه را رمزنگاری می‌کند، ویژگی‌های سند ارائه نیز با رمز عبور محافظت می‌شوند. اگر نیاز دارید ویژگی‌های سند حتی پس از رمزنگاری قابل دسترسی باشند، Aspose.Slides این امکان را دقیقاً برای شما فراهم می‌کند.

اگر می‌خواهید کاربران توانایی دسترسی به ویژگی‌های یک ارائه رمزنگاری‌شده را حفظ کنند، مقدار `false` را به [ProtectionManager::setEncryptDocumentProperties](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#setEncryptDocumentProperties) پاس دهید. این کد نمونه نشان می‌دهد چگونه یک ارائه را رمزنگاری کنید در حالی که همچنان به کاربران دسترسی به ویژگی‌های سند آن ارائه می‌شود:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $presentation->getProtectionManager()->setEncryptDocumentProperties(false);
    $presentation->getProtectionManager()->encrypt("123123");
    $presentation->save("encrypted-pres.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **بارگذاری فقط ویژگی‌های سند از یک ارائه رمزنگاری‌شده**

برای بازرسی متادیتاهای یک ارائه رمزنگاری‌شده بدون بارگذاری اسلایدها یا محتوای دیگر، یک شیء [LoadOptions](https://reference.aspose.com/slides/fa/php-java/aspose.slides/loadoptions/) ایجاد کنید و مقدار `true` را به [setOnlyLoadDocumentProperties](https://reference.aspose.com/slides/fa/php-java/aspose.slides/loadoptions/#setOnlyLoadDocumentProperties) پاس دهید. در این حالت، Aspose.Slides رمز عبور را نادیده می‌گیرد و فقط ویژگی‌های سندی را که عمومی هستند بارگذاری می‌کند.

کد مثال زیر ویژگی‌های سند داخلی و سفارشی را از طریق [Presentation::getDocumentProperties](https://reference.aspose.com/slides/fa/php-java/aspose.slides/presentation/#getDocumentProperties) می‌خواند:

```php
$loadOptions = new LoadOptions();
$loadOptions->setOnlyLoadDocumentProperties(true);

$presentation = new Presentation("encrypted-pres.pptx", $loadOptions);
try {
    $documentProperties = $presentation->getDocumentProperties();

    # خواندن ویژگی‌های سند داخلی.
    echo("Title: " . $documentProperties->getTitle() . "\n");
    echo("Author: " . $documentProperties->getAuthor() . "\n");

    # خواندن ویژگی‌های سفارشی سند.
    $customPropertyCount = java_values($documentProperties->getCountOfCustomProperties());

    for ($propertyIndex = 0; $propertyIndex < $customPropertyCount; $propertyIndex++) {
        $propertyName = $documentProperties->getCustomPropertyName($propertyIndex);
        $propertyValue = java_values($documentProperties->get_Item($propertyName));

        echo($propertyName . ": " . $propertyValue . "\n");
    }
} finally {
    $presentation->dispose();
}
```

این گردش کار فقط زمانی کار می‌کند که ویژگی‌های سند هنگام رمزنگاری ارائه، عمومی (غیررمزنگاری) باقی مانده باشند. اگر ویژگی‌های سند رمزنگاری شده باشند، پاس کردن مقدار `true` به [LoadOptions::setOnlyLoadDocumentProperties](https://reference.aspose.com/slides/fa/php-java/aspose.slides/loadoptions/#setOnlyLoadDocumentProperties) منجر به استثنا می‌شود زیرا رمز عبور در این حالت نادیده گرفته می‌شود. برای دسترسی به ویژگی‌های سند رمزنگاری‌شده یا بارگذاری کامل ارائه، از جمله اسلایدها و محتوای دیگر، رمز عبور صحیح را از طریق [LoadOptions::setPassword](https://reference.aspose.com/slides/fa/php-java/aspose.slides/loadoptions/#setPassword) فراهم کنید.

## **بررسی اینکه آیا یک ارائه با رمز عبور محافظت شده است**

قبل از بارگذاری یک ارائه، ممکن است بخواهید بررسی و تأیید کنید که ارائه با رمز عبور محافظت نشده است. به این ترتیب می‌توانید از خطاها و مشکلات مشابهی که هنگام بارگذاری یک ارائه محافظت‌شده بدون رمز عبور رخ می‌دهد، جلوگیری کنید.

این کد PHP نشان می‌دهد چگونه یک ارائه را بررسی کنید تا ببینید آیا با رمز عبور محافظت شده است (بدون بارگذاری خود ارائه):

```php
  $presentationInfo = PresentationFactory->getInstance()->getPresentationInfo("example.pptx");
  echo("The presentation is password protected: " . $presentationInfo->isPasswordProtected());

```

## **بررسی اینکه آیا یک ارائه رمزنگاری شده است**

Aspose.Slides به شما اجازه می‌دهد بررسی کنید که آیا یک ارائه رمزنگاری شده است یا خیر. برای انجام این کار می‌توانید از متد [isEncrypted](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#isEncrypted) استفاده کنید که اگر ارائه رمزنگاری شده باشد `true` و در غیر این صورت `false` برمی‌گرداند.

این کد نمونه نشان می‌دهد چگونه بررسی کنید که آیا یک ارائه رمزنگاری شده است:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $isEncrypted = $presentation->getProtectionManager()->isEncrypted();
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **بررسی اینکه آیا یک ارائه محافظت نوشتاری دارد**

Aspose.Slides به شما اجازه می‌دهد بررسی کنید که آیا یک ارائه محافظت نوشتاری دارد یا خیر. برای انجام این کار می‌توانید از متد [isWriteProtected](https://reference.aspose.com/slides/fa/php-java/aspose.slides/protectionmanager/#isWriteProtected) استفاده کنید که اگر ارائه محافظت نوشتاری داشته باشد `true` و در غیر این صورت `false` برمی‌گرداند.

این کد نمونه نشان می‌دهد چگونه بررسی کنید که آیا یک ارائه محافظت نوشتاری دارد:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    $isEncrypted = $presentation->getProtectionManager()->isWriteProtected();
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

## **اعتبارسنجی یا تأیید اینکه رمز عبور خاصی استفاده شده است**

ممکن است بخواهید بررسی و تأیید کنید که رمز عبور خاصی برای محافظت از سند یک ارائه استفاده شده است. Aspose.Slides ابزاری فراهم می‌کند تا بتوانید یک رمز عبور را اعتبارسنجی کنید.

این کد نمونه نشان می‌دهد چگونه یک رمز عبور را اعتبارسنجی کنید:

```php
  $presentation = new Presentation("pres.pptx");
  try {
    # بررسی کنید آیا "pass" مطابقت دارد
    $isWriteProtected = $presentation->getProtectionManager()->checkWriteProtection("my_password");
  } finally {
    if (!java_is_null($presentation)) {
      $presentation->dispose();
    }
  }
```

این مقدار `true` را برمی‌گرداند اگر ارائه با رمز عبور مشخص شده رمزنگاری شده باشد. در غیر این صورت مقدار `false` برمی‌گردد.

## **سوالات متداول**

**کدام روش‌های رمزنگاری توسط Aspose.Slides پشتیبانی می‌شوند؟**

Aspose.Slides روش‌های رمزنگاری مدرن، از جمله الگوریتم‌های مبتنی بر AES، را پشتیبانی می‌کند و سطح بالایی از امنیت داده‌ها را برای ارائه‌های شما تضمین می‌نماید.

**اگر رمز عبور نادرستی هنگام تلاش برای باز کردن یک ارائه وارد شود، چه می‌شود؟**

در صورت استفاده از رمز عبور نادرست، استثنا رخ می‌دهد و به شما اطلاع داده می‌شود که دسترسی به ارائه رد شده است. این امر به جلوگیری از دسترسی غیرمجاز و حفاظت از محتوای ارائه کمک می‌کند.

**آیا کار با ارائه‌های محافظت‌شده با رمز عبور تأثیراتی بر عملکرد دارد؟**

فرآیند رمزنگاری و رمزگشایی ممکن است بار کمی بر عملیات باز کردن و ذخیره‌سازی ایجاد کند. در اکثر موارد، این تاثیر بر عملکرد کم است و به‌طور قابل توجهی زمان پردازش کلی وظایف ارائه شما را تحت تاثیر قرار نمی‌دهد.
