## **مقدمه**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت تصویر در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش هم اهمیت دارد.

اندازه‌ها و نسبت‌های متداول اسلاید:

- **استاندارد (نسبت تصویر 4:3)**: مناسب برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **نمای گسترده (نسبت تصویر 16:9)**: توصیه می‌شود برای پروژکتور‌ها و نمایشگرهای مدرن.

برای همه اسلایدها یک اندازه اسلاید و نسبت تصویر یکسان اعمال می‌شود؛ بنابراین سازگاری در تمام ارائه شما حفظ می‌شود. برای نتایج بهینه، ابعاد اسلاید خود را در ابتدای فرایند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" title="Note" %}}
به صورت پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت تصویر استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و نسخه‌پیشنویس ابعاد جداگانه‌ای نسبت به اسلایدهای معمولی دارند. برای تغییر اندازه و جهت آن‌ها به [اندازه صفحه یادداشت](/slides/fa/php-java/notes-size/) مراجعه کنید.

## **تغییر اندازه اسلاید در ارائه‌ها**

این کد نمونه نشان می‌دهد چگونه با استفاده از Aspose.Slides اندازه اسلاید را در یک ارائه تغییر دهید:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **مشخص کردن اندازه‌های سفارشی اسلاید در ارائه‌ها**

اگر اندازه‌های متداول اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، می‌توانید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. به عنوان مثال، اگر قصد دارید اسلایدهای تمام‌اندازهٔ ارائه خود را بر روی قالب صفحهٔ سفارشی چاپ کنید یا می‌خواهید ارائه‌تان را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً استفاده از تنظیم اندازه سفارشی برای ارائه مفید خواهد بود.

این کد نمونه نشان می‌دهد چگونه از Aspose.Slides برای PHP از طریق Java برای تعیین یک اندازه اسلاید سفارشی در یک ارائه استفاده کنید:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// اندازه کاغذ A4

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیاء) ممکن است مخدوش شوند. به طور پیش‌فرض، اشیاء به طور خودکار برای متناسب شدن با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید یک ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتویات اسلایدها برخورد کند.

بسته به هدف و نیات شما، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به یک اندازه اسلاید کوچکتر مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کاهش دهد تا همهٔ آن‌ها در اسلاید جای بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌شود)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به یک اندازه اسلاید بزرگتر مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ‌نمایی کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد چگونه از تنظیم `Maximize` هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **پرسش‌های متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهای غیر اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند که 1 پوینت برابر 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به پوینت تبدیل کرده و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا اندازهٔ سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه در حین رندرینگ تاثیر می‌گذارد؟**

بله. ابعاد بزرگ‌تر اسلاید (بر حسب پوینت) همراه با مقیاس رندرینگ بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازهٔ عملی برای اسلاید انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی موردنظر تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟**

نمی‌توانید [ادغام ارائه‌ها](/slides/fa/php-java/merge-presentation/) را انجام دهید در حالی که اندازه‌های اسلاید متفاوت هستند — ابتدا یک ارائه را به اندازهٔ دیگر تغییر دهید. هنگام تغییر اندازهٔ اسلاید، می‌توانید با استفاده از گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/php-java/aspose.slides/slidesizescaletype/) تعیین کنید که محتویات موجود چگونه مدیریت شود. پس از هم‌ترازی اندازه‌ها، می‌توانید اسلایدها را با حفظ قالب‌بندی ترکیب کنید.

**آیا می‌توانم برای اشکال جداگانه یا مناطق خاصی از یک اسلاید تصویرهای کوچک (thumbnail) تولید کنم و آیا این تصاویر به اندازهٔ جدید اسلاید احترام می‌گذارند؟**

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [کل اسلایدها](https://reference.aspose.com/slides/fa/php-java/aspose.slides/slide/#getImage) و همچنین برای [اشکال انتخابی](https://reference.aspose.com/slides/fa/php-java/aspose.slides/shape/#getImage) تولید کند. تصاویر حاصل اندازه و نسبت ابعاد فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسهٔ سازگار را تضمین می‌نمایند.
