## **مقدمه**

Aspose.Slides ابزارهای جامعی برای تنظیم اندازه اسلاید و نسبت نمایش در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه‌نمایش هم‌زمان مهم است. 

اندازه‌ها و نسبت‌های محبوب اسلاید:

- **استاندارد (نسبت 4:3)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **پهن‌صفحه (نسبت 16:9)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

سازگاری را در سراسر ارائه خود حفظ کنید، زیرا یک اندازه اسلاید و نسبت نمایش برای همه اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این نمونه کد نشان می‌دهد چگونه با استفاده از Aspose.Slides اندازه اسلاید را در یک ارائه تغییر دهید:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **مشخص کردن اندازه‌های سفارشی اسلاید در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. به‌عنوان مثال، اگر قصد دارید اسلایدهای تمام‌اندازه را از ارائه خود روی یک قالب صفحه سفارشی چاپ کنید یا ارائه خود را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً از تنظیم اندازه سفارشی برای ارائه خود سود خواهید برد.

این نمونه کد نشان می‌دهد چگونه از Aspose.Slides برای PHP از طریق Java برای تعیین اندازه سفارشی اسلاید برای یک ارائه استفاده کنید:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// اندازه کاغذ A4

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتوای اسلایدها (مانند تصاویر یا اشیاء) ممکن است دچار افت شکل شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای نگه داشتن اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتواهای موجود در اسلایدها برخورد می‌کند.

بسته به آنچه می‌خواهید انجام دهید یا به‌دست آورید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء موجود در اسلایدها تغییر اندازه یابند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اسلایدی با اندازه کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را به‌صورت کوچک کند تا همه آنها در اسلایدها جا بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌شود)، از این تنظیم استفاده کنید. 

- `Maximize`

  اگر می‌خواهید به اسلایدی با اندازه بزرگتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگتر کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید. 

این نمونه کد نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه از تنظیم `Maximize` استفاده کنید:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **سوالات متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهای دیگری غیر از اینچ تنظیم کنم (مثلاً پوینت یا میلی‌متر)؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند، به‌طوری که 1 پوینت برابر با 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتیمتر) را به پوینت تبدیل کنید و مقادیر تبدیل‌شده را برای تعیین عرض و ارتفاع اسلاید به‌کار ببرید.

**آیا اندازه سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه هنگام رندر شدن تأثیر خواهد گذاشت؟**

بله. ابعاد بزرگ‌تر اسلاید (به‌پویینت) همراه با مقیاس رندر بالاتر منجر به مصرف بیشتر حافظه و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی را انتخاب کنید و مقیاس رندر را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مورد نظر تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیراستاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟**

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/php-java/merge-presentation/) را انجام دهید در حالی که اندازه‌های اسلاید متفاوت دارند — ابتدا یک ارائه را به اندازه دیگری تغییر دهید. هنگام تغییر اندازه اسلاید، می‌توانید با استفاده از گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/php-java/aspose.slides/slidesizescaletype/) تعیین کنید محتواهای موجود چگونه پردازش شوند. پس از هم‌تراز کردن اندازه‌ها، می‌توانید اسلایدها را ادغام کنید در حالی که قالب‌بندی حفظ می‌شود.

**آیا می‌توانم برای شکل‌های منفرد یا مناطق خاصی از یک اسلاید تصویر کوچک (thumbnail) تولید کنم و آیا این تصاویر اندازه جدید اسلاید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [کل اسلایدها](https://reference.aspose.com/slides/fa/php-java/aspose.slides/slide/#getImage) و همچنین برای [شکل‌های انتخابی](https://reference.aspose.com/slides/fa/php-java/aspose.slides/shape/#getImage) رندر کند. تصاویر حاصل اندازه و نسبت نمایش فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسه‌ای یکسان را تضمین می‌نمایند.
