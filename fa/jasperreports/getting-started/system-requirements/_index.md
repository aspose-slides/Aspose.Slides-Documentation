## **JasperReports**

Aspose.Slides for JasperReports با JasperReports 3.7.2 تا 6.16.0 کار می‌کند. دانلود شامل یک فایل jar جداگانه برای هر یک از سه بازه نسخه است — برای انتخاب مورد مناسب به [Installing Aspose.Slides for JasperReports](/slides/fa/jasperreports/installing-aspose-slides-for-jasperreports/) مراجعه کنید. برای JasperReports 6.17.0 یا نسخه‌های بعدی، از جمله JasperReports 7، هیچ jar ای موجود نیست.

پشتیبانی از JasperReports 2.0.3 تا 3.7.1 در Aspose.Slides for JasperReports 17.6 پایان یافت. نسخه 17.5 و قبلی نیز این نسخه‌ها را پشتیبانی می‌کردند.

## **Java**

jarها برای Java 6 یا نسخه‌های بعدی کامپایل شده‌اند، همان‌طور که *JDK 1.6* در نام پوشه‌هایشان نشان می‌دهد، بنابراین نسخه Java مورد نیاز همان نسخه‌ای است که نسخه JasperReports شما به آن نیاز دارد. با JasperReports 6.16.0، خروجی‌ها روی Java 11, 17, 21 و 25 اجرا می‌شوند.

## **Operating system**

jarها فقط شامل کلاس‌ها و منابع Java هستند و هیچ کتابخانه بومی ندارند و از Microsoft PowerPoint استفاده نمی‌کنند. در Linux، JasperReports برای پر کردن گزارش نیاز به fontconfig و حداقل یک قلم نصب شده دارد.

## **JasperReports Server**

برای JasperReports Server، هر دو jar را از پوشه‌ای که با نسخه JasperReports سرور شما منطبق است استفاده کنید — برای جزئیات به [Integration with JasperServer](/slides/fa/jasperreports/integration-with-jasperserver/) نگاه کنید.
