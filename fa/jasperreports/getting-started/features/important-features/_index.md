این بخش توصیف دقیق ویژگی‌های Aspose.Slides برای JasperReports را ارائه می‌دهد. برای یادگیری بیشتر درباره ویژگی‌ها، روی پیوندهای موجود در جدول کلیک کنید.

|**ویژگی** |**توضیح** |
| :- | :- |
|[صدور PPT، PPTX، PDF و HTML](/slides/fa/jasperreports/ppt-pptx-pdf-and-html-export/)|گزارش‌ها را به صورت ارائه‌های PPT و PPTX، اسناد PDF و فایل‌های HTML از برنامهٔ خود بدون استفاده از Microsoft PowerPoint صادر کنید. |
|دقت بالا نسبت به طراحی گزارش|گزارش‌های PPT و PPTX همان چیدمان و ظاهر را مانند PDF و سایر فرمت‌ها دارند. |
|استقرار آسان و کم‌وزن|Aspose.Slides for JasperReports یک صادرکنندهٔ JasperReports و JasperServer برای فرمت Microsoft PowerPoint است. |
|[مجوز ساده و مقرون به صرفه](/slides/fa/jasperreports/licensing/)|یک مجوز برای هر سرور یا یک مجوز برای تمام سرورهای شما. |
|[پشتیبانی فنی رایگان سطح جهانی](/slides/fa/jasperreports/technical-support/)|پشتیبانی فنی نامحدود به‌صورت مستقیم توسط توسعه‌دهندگانی که بر روی محصول کار می‌کنند، ارائه می‌شود. |
