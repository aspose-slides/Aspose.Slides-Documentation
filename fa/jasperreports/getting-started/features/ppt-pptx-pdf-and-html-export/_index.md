{{% alert color="info" %}} 

JasperReports و JasperServer توانایی‌های داخلی برای استخراج گزارش‌ها به‌صورت ارائه‌های Microsoft PowerPoint ندارند، اما با Aspose.Slides for JasperReports می‌توانید به فرمت‌های خروجی اضافی دسترسی پیدا کنید:

- Microsoft PowerPoint Presentation (PPT)
- Microsoft PowerPoint Presentation (PPTX)
- HTML
- PDF

{{% /alert %}} 

برای ایجاد اسناد در این فرمت‌ها، Aspose.Slides for JasperReports بر نسخه داخلی [Aspose.Slides for Java](https://products.aspose.com/slides/fa/java/) که کتابخانه پیشرو در بازار پردازش ارائه‌ها از Aspose است، تکیه دارد. Microsoft PowerPoint برای تولید این اسناد مورد استفاده قرار نمی‌گیرد.
