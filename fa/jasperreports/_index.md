**به Aspose.Slides for JasperReports خوش آمدید**

Aspose.Slides for JasperReports یک کتابخانه است که به‌طور ویژه برای توسعه‌دهندگانی طراحی و توسعه یافته است که نیاز دارند به‌راحتی گزارش‌ها را از JasperReports به فرمت‌های Microsoft PowerPoint Presentation (PPT) و Microsoft PowerPoint Show (PPS) در برنامه‌های Java خود صادر کنند. تمام ویژگی‌های گزارش با بالاترین دقت به ارائه‌های Microsoft PowerPoint تبدیل می‌شوند. Aspose.Slides for JasperReports از JasperReports نسخه 5 به بالا پشتیبانی می‌کند.
