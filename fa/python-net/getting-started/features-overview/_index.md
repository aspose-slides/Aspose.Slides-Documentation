## **پلتفرم‌های پشتیبانی‌شده**
پلتفرم‌هایی که Aspose.Slides for Python via .NET می‌تواند بر روی آن‌ها استفاده شود شامل Windows x64 یا x86 و طیف گسترده‌ای از توزیع‌های Linux با نصب Python 3.5 یا بالاتر می‌باشد. برای پلتفرم هدف لینوکس نیازمندی‌های اضافی نیز وجود دارد:
- کتابخانه‌های زمان اجرا GCC-6 (یا جدیدتر)
- وابستگی‌های .NET Core Runtime. نصب خود .NET Core Runtime **ضروری نیست**
- برای Python 3.5‑3.7: نسخه `pymalloc` پایتون لازم است. گزینه ساخت پایتون `--with-pymalloc` به‌طور پیش‌فرض فعال است. معمولاً نسخه `pymalloc` پایتون با پسوند `m` در نام فایل مشخص می‌شود.
- کتابخانه مشترک `libpython`. گزینه ساخت پایتون `--enable-shared` به‌طور پیش‌فرض غیرفعال است و برخی توزیع‌های پایتون این کتابخانه مشترک را شامل نمی‌شوند. برای برخی پلتفرم‌های لینوکس می‌توانید کتابخانه `libpython` را با مدیر بسته نصب کنید، برای مثال: `sudo apt-get install libpython3.7`. مشکل رایج این است که کتابخانه `libpython` در مسیری متفاوت از مسیر استاندارد سیستم برای کتابخانه‌های مشترک نصب می‌شود. می‌توانید با تنظیم گزینه‌های ساخت پایتون مسیرهای جایگزین کتابخانه را تعریف کنید یا با ایجاد یک لینک نمادین به فایل کتابخانه `libpython` در موقعیت استاندارد سیستم این مشکل را رفع کنید. به‌طور معمول نام فایل کتابخانه مشترک `libpython` برای Python 3.5‑3.7 به شکل `libpythonX.Ym.so.1.0` و برای Python 3.8 یا بالاتر به شکل `libpythonX.Y.so.1.0` است (برای مثال: `libpython3.7m.so.1.0`، `libpython3.9.so.1.0`).

اگر به پشتیبانی برای پلتفرم‌های بیشتری نیاز دارید، به محصولات «برادر دوقلو» Aspose.Slides for .NET یا Aspose.Slides for Java نگاه کنید.

## **FAQ**

### آیا برای کارکرد کتابخانه لازم است Microsoft PowerPoint را روی سرور/کامپیوتر نصب کنم؟

نه. PowerPoint لازم نیست؛ Aspose.Slides یک موتور مستقل برای ایجاد، ویرایش، تبدیل و رندر ارائه‌ها است.

### چندنخی چگونه کار می‌کند؟ آیا می‌توان پردازش را موازی‌سازی کرد؟

ایمن است که اسناد مختلف را در نخ‌های متفاوت پردازش کنید؛ شیء [presentation](https://reference.aspose.com/slides/fa/python-net/aspose.slides/presentation/) یک‌باره نباید توسط [multiple threads](/slides/fa/python-net/multithreading/) همزمان استفاده شود.

### آیا رمز عبور فایل‌ها و رمزنگاری پشتیبانی می‌شود؟

بله. می‌توانید [پیشنهادات](/slides/fa/python-net/password-protected-presentation/) ارائه‌های رمزنگاری‌شده را باز کنید، رمز عبور باز کردن و نوشتن را تنظیم یا حذف کنید و وضعیت حفاظت را بررسی کنید.

### آیا در کانتینرهای لینوکس باید به بسته‌های فونت توجه داشته باشم؟

بله. توصیه می‌شود بسته‌های فونت معمولی را نصب کنید و/یا به‌طور صریح [دایرکتوری‌های فونت](/slides/fa/python-net/custom-font/) را در برنامه‌تان مشخص کنید تا از جایگزینی‌های ناخواسته جلوگیری شود.

### آیا در نسخه ارزیابی محدودیت‌هایی وجود دارد؟

در [حالت ارزیابی](/slides/fa/python-net/licensing/) یک واترمارک به خروجی اضافه می‌شود و محدودیت‌های خاصی اعمال می‌شود؛ یک [مجوز موقت 30 روزه](https://purchase.aspose.com/temporary-license/) برای تست کامل ویژگی‌ها قابل دسترسی است.

### آیا وارد کردن فرمت‌های خارجی به یک ارائه (PDF/HTML → PPTX) پشتیبانی می‌شود؟

بله. می‌توانید [صفحات PDF و محتوای HTML](/slides/fa/python-net/import-presentation/) را به یک ارائه اضافه کنید و آن‌ها را به اسلاید تبدیل کنید.
