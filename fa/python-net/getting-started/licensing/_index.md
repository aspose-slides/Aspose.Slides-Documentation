## **نمای کلی**

Aspose.Slides می‌تواند در حالت ارزیابی یا با یک لایسنس معتبر استفاده شود. نسخه ارزیابی همان عملکرد نسخه لایسنس‌دار را فراهم می‌کند، اما یک واترمارک ارزیابی به هر اسلاید هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند و متن‌هایی را که کد شما از ارائه‌ها می‌خواند کوتاه می‌کند.

## **ارزیابی Aspose.Slides**

می‌توانید نسخه ارزیابی **Aspose.Slides for Python via .NET** را از [صفحه دانلود](https://pypi.org/project/Aspose.Slides/) دریافت کنید. نسخه ارزیابی همان ویژگی‌های محصول لایسنس‌دار را فراهم می‌کند. بسته ارزیابی دقیقاً مشابه بسته خریداری‌شده است و پس از افزودن چند خط کد برای اعمال لایسنس، لایسنس‌دار می‌شود.

وقتی از ارزیابی **Aspose.Slides** رضایت یافتید، می‌توانید [یک لایسنس خریداری کنید](https://purchase.aspose.com/pricing/slides/fa/python-net/). توصیه می‌کنیم گزینه‌های اشتراک موجود را بررسی کنید. اگر سؤالی دارید، با تیم فروش Aspose تماس بگیرید.

هر لایسنس Aspose شامل یک اشتراک یک‌ساله با ارتقاءهای رایگان به نسخه‌های جدید و اصلاحاتی است که در طول آن دوره منتشر می‌شوند. هم کاربران لایسنس‌دار و هم کاربران ارزیابی، پشتیبانی فنی رایگان و نامحدود دریافت می‌کنند.

**محدودیت‌های نسخه ارزیابی**

* نسخه ارزیابی (زمانی که لایسنس اعمال نشده است) تمام عملکردها را فراهم می‌کند، اما یک جعبه متن واترمارک ارزیابی به هر اسلاید هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند.
* متنی که کد شما از یک ارائه می‌خواند به اولین چند کاراکتر محدود می‌شود و سپس یک اعلان درباره محدودیت ارزیابی اضافه می‌شود. متنی که کد شما می‌نویسد به‌صورت کامل ذخیره می‌شود.

{{% alert color="info" title="Note" %}}
برای تست Aspose.Slides بدون محدودیت، می‌توانید **لایسنس موقت 30 روزه** درخواست کنید. برای جزئیات، صفحه [چگونه لایسنس موقت دریافت کنیم](https://purchase.aspose.com/temporary-license) را ببینید.
{{% /alert %}}

## **مجوزدهی در Aspose.Slides**

* پس از خرید لایسنس و افزودن چند خط کد برای اعمال آن، نسخه ارزیابی لایسنس‌دار می‌شود.
* لایسنس یک فایل XML متنی ساده است که جزئیاتی نظیر نام محصول، تعداد توسعه‌دهندگانی که تحت پوشش آن است، تاریخ انقضای اشتراک و غیره را شامل می‌شود.
* فایل لایسنس به‌صورت دیجیتالی امضا شده است، بنابراین نباید آن را تغییر دهید. حتی افزودن یک خط جدید می‌تواند اعتبار آن را از بین ببرد.
* Aspose.Slides for Python via .NET لایسنس را در مسیری که به آن می‌گویید جستجو می‌کند. یک مسیر نسبی یا نام فایل بدون مسیر، نسبت به پوشه کاری جاری حل می‌شود که لزوماً پوشه‌ای که اسکریپت پایتون شما در آن قرار دارد، نیست.
* برای جلوگیری از محدودیت‌های ارزیابی، قبل از استفاده از Aspose.Slides لایسنس را تنظیم کنید. تنها یک‌بار در هر برنامه یا فرآیند نیاز به تنظیم آن دارید.

## **اعمال لایسنس**

لایسنس می‌تواند از **فایل** یا **جریان** بارگذاری شود.

{{% alert color="info" title="Note" %}}
Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/python-net/aspose.slides/license/) را برای مدیریت لایسنس فراهم می‌کند.
{{% /alert %}}

{{% alert color="warning" title="Warning" %}}
لایسنس‌های جدید می‌توانند Aspose.Slides را فقط با نسخه 21.4 یا بالاتر فعال کنند. نسخه‌های قبلی از سیستم لایسنس متفاوتی استفاده می‌کنند و این لایسنس‌ها را تشخیص نمی‌دهند.
{{% /alert %}}

### **فایل**

ساده‌ترین روش برای تنظیم لایسنس، عبور مسیر فایل لایسنس به متد [set_license](https://reference.aspose.com/slides/fa/python-net/aspose.slides/license/set_license/) است. اگر فقط نام فایل را عبور دهید، همان‌طور که در مثال زیر آمده است، Aspose.Slides فایل را در پوشه کاری جاری جستجو می‌کند.

کد پایتون زیر نحوه تنظیم فایل لایسنس را نشان می‌دهد:
```py
import aspose.slides as slides

# کلاس License را نمونه‌سازی می‌کند.
license = slides.License()

# مسیر فایل مجوز را تنظیم می‌کند.
license.set_license("Aspose.Slides.lic")
```

{{% alert color="warning" title="Warning" %}}
اگر فایل لایسنس را در یک دایرکتوری متفاوت قرار دهید، هنگام فراخوانی [License.set_license](https://reference.aspose.com/slides/fa/python-net/aspose.slides/license/set_license/#str)، نام فایل در انتهای مسیر صریح باید با نام فایل لایسنس شما مطابقت داشته باشد.

برای مثال، می‌توانید فایل لایسنس را به *Aspose.Slides.lic.xml* تغییر نام دهید. سپس در کد خود، مسیر کامل به آن فایل (که با Aspose.Slides.lic.xml پایان می‌یابد) را به متد [License.set_license](https://reference.aspose.com/slides/fa/python-net/aspose.slides/license/set_license/#str) بدهید.
{{% /alert %}}

### **جریان**

می‌توانید لایسنس را از یک جریان بارگذاری کنید. مثال پایتون زیر نحوه اعمال لایسنس از یک جریان را نشان می‌دهد:
```py
import aspose.slides as slides

# کلاس License را نمونه‌سازی می‌کند.
license = slides.License()

# مجوز را از یک جریان تنظیم می‌کند.
with open("Aspose.Slides.lic", "rb") as stream:
    license.set_license(stream)
```

## **اعتبارسنجی لایسنس**

برای تأیید اینکه لایسنس به‌درستی اعمال شده است، می‌توانید آن را اعتبارسنجی کنید. کد پایتون زیر نشان می‌دهد چگونه لایسنس را اعتبارسنجی کنید:
```py
import aspose.slides as slides

license = slides.License()

license.set_license("Aspose.Slides.lic")

if license.is_licensed():
    print("License is good!")
```

## **ایمنی در میان‌ریسمان‌ها**

{{% alert color="warning" title="Warning" %}}
متد [License.set_license](https://reference.aspose.com/slides/fa/python-net/aspose.slides/license/set_license/) ایمنی بین‌ریسمانی ندارد. اگر نیاز دارید که آن را به‌صورت همزمان از چندین ریسمان فراخوانی کنید، از یک سازوکار هم‌زمانی مانند `threading.Lock` استفاده کنید تا از بروز مشکلات جلوگیری کنید.
{{% /alert %}}

## **FAQ**

### آیا می‌توانم لایسنس را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ اتصال به اینترنت لازم نیست.

### بعد از پایان اشتراک یک‌ساله چه اتفاقی می‌فتد؟ آیا کتابخانه کارکرد خود را متوقف می‌کند؟

خیر. لایسنس دائم است: می‌توانید از نسخه‌هایی که قبل از تاریخ پایان اشتراک شما منتشر شده‌اند استفاده کنید؛ فقط بدون تمدید نمی‌توانید از نسخه‌های جدیدتر استفاده کنید.
