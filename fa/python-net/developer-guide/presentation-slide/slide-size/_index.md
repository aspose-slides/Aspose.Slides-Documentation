## **معرفی**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت تصویر در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش حیاتی است.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت تصویر 4:3)**: برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی ایده‌آل است.
- **عرض‌پهن (نسبت تصویر 16:9)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

برای حفظ سازگاری در سراسر ارائه خود، یک اندازه اسلاید و نسبت تصویر واحد برای همه اسلایدها اعمال می‌شود. برای دستیابی به نتایج بهینه، ابعاد اسلاید خود را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت تصویر استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در یک ارائه**

این کد نمونه نشان می‌دهد چگونه با استفاده از Aspose.Slides در Python، اندازه اسلاید در یک ارائه را تغییر دهید:

```py
import aspose.slides as slides

with slides.Presentation(path + "AccessSlides.pptx") as pres:
    pres.slide_size.set_size(slides.SlideSizeType.ON_SCREEN16X9, slides.SlideSizeScaleType.DO_NOT_SCALE)
    pres.save("pres-4x3-aspect-ratio.pptx", slides.export.SaveFormat.PPTX)
```

## **مشخص کردن اندازه‌های سفارشی اسلاید**

اگر اندازه‌های رایج اسلاید (4:3 و 16:9) برای کار شما مناسب نباشند، می‌توانید از یک اندازه اسلاید خاص یا منحصر به‌فرد استفاده کنید. به عنوان مثال، اگر برنامه‌ریزی می‌کنید اسلایدهای کامل‌اندازه را روی یک طرح‌بندی صفحه سفارشی چاپ کنید یا می‌خواهید ارائه خود را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً از تنظیم اندازه سفارشی برای ارائه خود بهره‌مند خواهید شد.

این کد نمونه نشان می‌دهد چگونه با استفاده از Aspose.Slides برای Python از طریق .NET، یک اندازه اسلاید سفارشی برای یک ارائه در Python مشخص کنید:

```py
import aspose.slides as slides

with slides.Presentation(path + "AccessSlides.pptx") as pres:
    pres.slide_size.set_size(780, 540, slides.SlideSizeScaleType.DO_NOT_SCALE) # اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", slides.export.SaveFormat.PPTX)
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

بعد از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیاء) ممکن است مخدوش شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای متناسب شدن با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتواهای موجود در اسلایدها برخورد می‌کند.

بسته به آنچه می‌خواهید انجام دهید یا به‌دست آورید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DO_NOT_SCALE`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه یابند، از این تنظیم استفاده کنید.

- `ENSURE_FIT`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را به‌صورت کوچک‌تر مقیاس‌بندی کند تا همه آنها در اسلاید جا بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌شود)، از این تنظیم استفاده کنید.

- `MAXIMIZE`

  اگر می‌خواهید به اندازه اسلاید بزرگتر مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ‌تر کند تا با اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه، تنظیم `MAXIMIZE` را به کار ببرید:

```py
import aspose.slides as slides

with slides.Presentation(path + "AccessSlides.pptx") as pres:
   pres.slide_size.set_size(slides.SlideSizeType.LEDGER, slides.SlideSizeScaleType.MAXIMIZE)
```

## **سؤالات متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهایی غیر از اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند که 1 پوینت برابر 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به پوینت تبدیل کنید و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا اندازه سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه هنگام رندرینگ تأثیر می‌گذارد؟**

بله. ابعاد بزرگتر اسلاید (به پوینت) همراه با مقیاس رندرینگ بالاتر منجر به افزایش مصرف حافظه و زمان پردازش می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کرده و سپس اسلایدها را از ارائه‌هایی با اندازه‌های متفاوت ترکیب کنم؟**

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/python-net/merge-presentation/) را انجام دهید در حالی که اندازه‌های اسلاید متفاوت هستند — ابتدا یک ارائه را به اندازه دیگری تغییر اندازه دهید تا مطابقت داشته باشد. هنگام تغییر اندازه اسلاید، می‌توانید نحوه‌ی مدیریت محتواهای موجود را از طریق گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/python-net/aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هم‌ترازی اندازه‌ها، می‌توانید اسلایدها را ترکیب کنید و قالب‌بندی را حفظ کنید.

**آیا می‌توانم تصاویر بندانگشتی برای اشکال جداگانه یا مناطقی خاص از یک اسلاید ایجاد کنم و آیا این تصاویر اندازه جدید اسلاید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصاویر بندانگشتی برای [کل اسلایدها](https://reference.aspose.com/slides/fa/python-net/aspose.slides/slide/get_image/) و همچنین برای [اشکال انتخابی](https://reference.aspose.com/slides/fa/python-net/aspose.slides/shape/get_image/) ایجاد کند. تصاویر حاصل اندازه جاری اسلاید و نسبت تصویر را منعکس می‌کنند و چارچوب و هندسه‌ی ثابت را تضمین می‌نمایند.
