## **معرفی**

Aspose.Slides ابزارهای جامعی برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش ضروری است.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت ابعاد ۴:۳)**: مناسب برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **واید اسکرین (نسبت ابعاد ۱۶:۹)**: برای پروژکتور‌ها و نمایشگرهای مدرن توصیه می‌شود.

برای حفظ سازگاری در طول ارائه خود، یک اندازه اسلاید و نسبت ابعاد ثابت برای تمام اسلایدها استفاده کنید. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرایند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" title="Note" %}}
به طور پیش‌فرض، ارائه‌های ساخته‌شده با Aspose.Slides از نسبت ابعاد استاندارد ۴:۳ استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و جزوات ابعاد جداگانه‌ای نسبت به اسلایدهای معمولی دارند. برای تغییر اندازه و جهت‌گیری آن‌ها به [اندازه صفحه یادداشت](/slides/fa/python-net/notes-size/) مراجعه کنید.

## **تغییر اندازه اسلاید در یک ارائه**

این نمونه کد نشان می‌دهد چگونه اندازه اسلاید را در یک ارائه با استفاده از Aspose.Slides در Python تغییر دهید:

```py
import aspose.slides as slides

with slides.Presentation("AccessSlides.pptx") as pres:
    pres.slide_size.set_size(slides.SlideSizeType.ON_SCREEN_16X9, slides.SlideSizeScaleType.DO_NOT_SCALE)
    pres.save("pres-16x9-aspect-ratio.pptx", slides.export.SaveFormat.PPTX)
```

## **مشخص کردن اندازه‌های اسلاید سفارشی**

اگر اندازه‌های رایج اسلاید (۴:۳ و ۱۶:۹) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه خاص یا منحصربه‌فرد اسلاید استفاده کنید. به عنوان مثال، اگر قصد دارید اسلایدهای تمام‌جا را روی یک قالب صفحه سفارشی چاپ کنید یا ارائه خود را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، استفاده از تنظیمات اندازه سفارشی برای ارائه می‌تواند مفید باشد.

این نمونه کد نشان می‌دهد چگونه با استفاده از Aspose.Slides برای Python از طریق .NET اندازه سفارشی اسلاید را برای یک ارائه در Python تعیین کنید:

```py
import aspose.slides as slides

with slides.Presentation("AccessSlides.pptx") as pres:
    pres.slide_size.set_size(780, 540, slides.SlideSizeScaleType.DO_NOT_SCALE) # اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", slides.export.SaveFormat.PPTX)
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتوای اسلایدها (مانند تصاویر یا اشیاء) ممکن است دچار اعوجاج شوند. به طور پیش‌فرض، اشیاء به‌صورت خودکار برای متناسب شدن با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را تعیین کنید که نحوهٔ برخورد Aspose.Slides با محتوای اسلایدها را مشخص می‌کند.

بسته به هدف یا کاری که می‌خواهید انجام دهید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DO_NOT_SCALE`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه یابند، از این تنظیم استفاده کنید.

- `ENSURE_FIT`

  اگر می‌خواهید به یک اندازه اسلاید کوچکتر مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کوچک کند تا همه به‌درستی در اسلایدها قرار بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌کنید)، این تنظیم را استفاده کنید.

- `MAXIMIZE`

  اگر می‌خواهید به یک اندازه اسلاید بزرگتر مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این نمونه کد نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه، تنظیم `MAXIMIZE` را استفاده کنید:

```py
import aspose.slides as slides

with slides.Presentation("AccessSlides.pptx") as pres:
   pres.slide_size.set_size(slides.SlideSizeType.LEDGER, slides.SlideSizeScaleType.MAXIMIZE)
```

## **پرسش‌های متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهای غیر اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند که ۱ پوینت برابر با ۱/۷۲ اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به پوینت تبدیل کنید و از مقادیر تبدیل‌شده برای تعیین عرض و ارتفاع اسلاید استفاده نمایید.

**آیا اندازه سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه هنگام رندر کردن تأثیر خواهد گذاشت؟**

بله. ابعاد بزرگتر اسلاید (به پوینت) همراه با مقیاس رندر بالاتر باعث مصرف بیشتر حافظه و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندر را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم نمایید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدهای ارائه‌هایی با اندازه‌های مختلف را ترکیب کنم؟**

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/python-net/merge-presentation/) را زمانی که اندازه‌های اسلاید متفاوت دارند انجام دهید — ابتدا یک ارائه را به اندازهٔ دیگر تنظیم کنید. هنگام تغییر اندازه اسلاید، می‌توانید با استفاده از گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/python-net/aspose.slides/slidesizescaletype/) نحوهٔ پردازش محتوای موجود را انتخاب کنید. پس از هماهنگ‌سازی اندازه‌ها، می‌توانید اسلایدها را ادغام کنید در حالی که قالب‌بندی حفظ می‌شود.

**آیا می‌توانم برای اشکال تک‌تک یا نواحی خاصی از یک اسلاید تصویر بندانگشتی ایجاد کنم و آیا این تصاویر اندازه جدید اسلاید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصویرهای بندانگشتی برای [کل اسلایدها](https://reference.aspose.com/slides/fa/python-net/aspose.slides/slide/get_image/) و همچنین برای [اشکال انتخاب شده](https://reference.aspose.com/slides/fa/python-net/aspose.slides/shape/get_image/) ایجاد کند. تصاویر حاصل با اندازه و نسبت ابعاد فعلی اسلاید منعکس می‌شوند و چارچوب و هندسهٔ ثابت را تضمین می‌کنند.
