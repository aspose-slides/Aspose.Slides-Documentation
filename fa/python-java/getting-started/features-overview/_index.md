این مقاله قابلیت‌های پردازش ارائه Aspose.Slides for Python via Java را توصیف می‌کند. برای سیستم‌عامل‌ها و وابستگی‌های پشتیبانی‌شده، به [System Requirements](/slides/fa/python-java/system-requirements/) مراجعه کنید.

## **فرمت‌های فایل و تبدیل‌ها**
Aspose.Slides for Python via Java به شما امکان تبدیل بین فرمت‌های ارائه و خروجی استخراج ارائه‌ها به فرمت‌های سند و وب را می‌دهد. برای جدول کامل فرمت‌ها و تمایز بین بارگذاری ارائه‌ها، وارد کردن محتوا و خروجی‌سازی، به [Supported File Formats](/slides/fa/python-java/supported-file-formats/) مراجعه کنید.

## **رندر ارائه**
Aspose.Slides for Python via Java رندر اسلاید با دقت بالا را به صورت تصویر رستر یا برداری برای پیش‌نمایش‌ها و خروجی‌های بصری دیگر فراهم می‌کند. همچنین به شما امکان رندر تصویر روی اسلایدها را می‌دهد. برای فرمت‌های تصویر قابل استفاده و نکات خروجی، به [Supported File Formats](/slides/fa/python-java/supported-file-formats/#supported-file-formats) مراجعه کنید.
