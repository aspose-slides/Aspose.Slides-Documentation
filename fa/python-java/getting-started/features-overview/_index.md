## **پلتفرم‌های پشتیبانی‌شده**
Aspose.Slides for Python via Java یک API مستقل از پلتفرم است. می‌تواند بر روی هر پلتفرمی (Windows، Linux، macOS و غیره) که Python 3.7 یا بالاتر نصب باشد، استفاده شود. JDK 8 یا بالاتر نیز یکی دیگر از نیازمندی‌هاست.

## **قالب‌های فایل و تبدیل‌ها**
Aspose.Slides for Python via Java اکثر فرمت‌های اسناد PowerPoint را پشتیبانی می‌کند. همچنین امکان صادرات آن‌ها به فرمت‌های فایل محبوب که سازمان‌ها استفاده و به اشتراک می‌گذارند را فراهم می‌کند. جزئیات را مرور کنید:

|**قابلیت**|**توضیح**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java سریع‌ترین پردازش را برای این فرمت سند ارائه می‌دهد.|
|PPT to PPTX conversion|Aspose.Slides for Python via Java از تبدیل PPT به PPTX پشتیبانی می‌کند.|
|Portable Document Format (PDF)|می‌توانید تمام فرمت‌های فایل پشتیبانی‌شده را با یک متد به اسناد Adobe Portable Document Format (PDF) صادر کنید.|
|XML Parser Specification (XPS)|می‌توانید تمام فرمت‌های فایل پشتیبانی‌شده را با یک متد به اسناد XML Parser Specification (XPS) صادر کنید.|
|Tagged Image File Format (TIFF)|می‌توانید تمام فرمت‌های فایل ارائه را به Tagged Image File Format (TIFF) صادر کنید.|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java از تبدیل PresentationEx به فرمت HTML پشتیبانی می‌کند.|

## **رندرینگ ارائه**
Aspose.Slides for Python via Java از رندرینگ با دقت بالا اسلایدهای ارائه به فرمت‌های گرافیکی مختلف پشتیبانی می‌کند. جزئیات را مرور کنید:

|**قابلیت**|**توضیح**|
| :- | :- |
|Java Supported Image Formats|با استفاده از Aspose.Slides for Python via Java می‌توانید اسلایدهای ارائه و تصاویر موجود در اسلایدها را به تمام فرمت‌های گرافیکی پشتیبانی‌شده توسط Java مانند TIFF، PNG، BMP، JPEG و GIF رندر کنید.|
|SVG Format|Aspose.Slides for Python via Java همچنین متدهای داخلیی دارد که امکان صادرات اسلایدهای ارائه به فرمت Scalable Vector Graphics (SVG) را فراهم می‌آورد.|

## **قابلیت‌های محتوا**
Aspose.Slides for Python via Java به شما امکان دسترسی، اصلاح یا ایجاد تقریباً تمام آیتم‌ها یا محتویات اسناد ارائه را می‌دهد. جزئیات را مرور کنید:

|**قابلیت**|**توضیح**|
| :- | :- |
|Master Slides|اسلایدهای Master چیدمان اسلایدهای معمولی را تعریف می‌کنند. Aspose.Slides for Python via Java به شما اجازه می‌دهد به اسلایدهای Master اسناد ارائه دسترسی پیدا کنید و آن‌ها را اصلاح کنید.|
|Normal Slides|با Aspose.Slides for Python via Java می‌توانید اسلایدهای جدید از انواع مختلف ایجاد کنید؛ همچنین می‌توانید به اسلایدهای موجود در ارائه دسترسی پیدا کنید و آن‌ها را اصلاح کنید.|
|Cloning / Copying Slides|متدهای داخلیی ارائه‌شده توسط Aspose.Slides for Python via Java اجازه می‌دهند اسلایدهای موجود در یک ارائه را کلون یا کپی کنید. همچنین می‌توانید اسلایدهای کپی‌شده و کلون‌شده را از یک ارائه به ارائه دیگر منتقل کنید. چون یک اسلاید چیدمان خود را از اسلاید master ارث‌بری می‌کند، متدهای کلونینگ داخلی به‌طور خودکار master را هنگام کلون کردن کپی می‌کنند.|
|Managing Slides sections|متدهایی برای سازماندهی اسلایدها در بخش‌های مختلف داخل یک ارائه وجود دارد.|
|Place Holders and Text Holders|می‌توانید به محل نگهدارنده‌ها (place holders) و متن نگهدارنده‌ها (text holders) در یک اسلاید دسترسی پیدا کنید. علاوه بر این، می‌توانید یک اسلاید با متن نگهدارنده‌ها از ابتدا با استفاده از متد مناسب ایجاد کنید.|
|Header and Footers|Aspose.Slides for Python via Java مدیریت سرصفحه‌ها/پاورقی‌ها در اسلایدها را تسهیل می‌کند.|
|Notes in Slides|با Aspose.Slides for Python via Java می‌توانید به یادداشت‌های مرتبط با یک اسلاید دسترسی پیدا کنید و آن‌ها را اصلاح کنید و همچنین یادداشت‌های جدید اضافه کنید.|
|Finding a Shape|همچنین می‌توانید یک شکل خاص را در اسلاید با استفاده از متن جایگزین (alternative text) مرتبط با آن شکل پیدا کنید.|
|Backgrounds|Aspose.Slides for Python via Java به شما امکان کار با پس‌زمینه‌های مرتبط با اسلاید master یا اسلاید معمولی در یک ارائه را می‌دهد.|
|Text Boxes|جعبه‌های متن می‌توانند از ابتدا ایجاد شوند. می‌توانید به جعبه‌های متن موجود دسترسی پیدا کنید. همچنین می‌توانید متن آن‌ها را بدون از دست دادن قالب‌بندی اصلی اصلاح کنید.|
|Rectangle Shapes|می‌توانید شکل‌های مستطیلی را با Aspose.Slides for Python via Java ایجاد یا اصلاح کنید.|
|Poly Line Shapes|می‌توانید شکل‌های خط چندضلعی (poly line) را با Aspose.Slides for Python via Java ایجاد یا اصلاح کنید.|
|Ellipse Shapes|می‌توانید شکل‌های بیضی (Ellipse) را با Aspose.Slides for Python via Java ایجاد یا اصلاح کنید.|
|Group Shapes|Aspose.Slides for Python via Java از گروه‌بندی اشکال پشتیبانی می‌کند.|
|Auto Shapes|Aspose.Slides for Python via Java از اشکال خودکار (auto shapes) پشتیبانی می‌کند.|
|SmartArt|Aspose.Slides for Python via Java پشتیبانی از اشکال SmartArt در MS PowerPoint را فراهم می‌کند.|
|Charts|Aspose.Slides for Python via Java پشتیبانی از نمودارهای MSO در PowerPoint را فراهم می‌کند.|
|Shapes Serialization|Aspose.Slides for Python via Java از تعداد زیادی شکل پشتیبانی می‌کند. وقتی Aspose.Slides for Python via Java از یک شکل پشتیبانی نمی‌کند، می‌توانید از یک متد سریال‌سازی استفاده کنید تا آن شکل را از یک اسلاید موجود سریال‌سازی کنید. به این ترتیب می‌توانید شکل را بر حسب نیازهای خود استفاده کنید.|
|Picture Frames|می‌توانید تصاویر را در فریم‌های تصویر با Aspose.Slides for Python via Java مدیریت کنید.|
|Audio Frames|می‌توانید فایل‌های صوتی را در فریم‌های صوتی بر روی اسلایدها لینک یا جاسازی کنید با Aspose.Slides for Python via Java.|
|Video Frames|می‌توانید فایل‌های ویدئویی را در فریم‌های ویدئویی مدیریت کنید. Aspose.Slides for Python via Java همچنین پشتیبانی از ویدئوهای لینک‌شده و جاسازی‌شده را فراهم می‌کند.|
|OLE Frame|می‌توانید اشیای OLE را در فریم‌های OLE با Aspose.Slides for Python via Java مدیریت کنید.|
|Tables|Aspose.Slides for Python via Java از جداول در اسلایدها پشتیبانی می‌کند.|
|ActiveX Controls|پشتیبانی از کنترل‌های ActiveX.|
|VBA Macros|پشتیبانی از مدیریت ماکروهای VBA داخل ارائه‌ها.|
|Text Frame|می‌توانید متن را از طریق فریم متنی مرتبط با هر شکلی دسترسی پیدا کنید.|
|Text Scanning|می‌توانید متن را در سطح ارائه یا اسلاید با استفاده از متدهای اسکن داخلی اسکن کنید.|
|Animations|می‌توانید انیمیشن‌ها را روی اشکال اعمال کنید.|
|Slide Shows|Aspose.Slides for Python via Java از نمایش اسلایدها و انتقالات اسلاید پشتیبانی می‌کند.|
