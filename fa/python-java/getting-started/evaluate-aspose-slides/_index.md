می‌توانید Aspose.Slides for Python via Java را برای ارزیابی ویژگی‌های آن دانلود کنید. بسته ارزیابی دقیقاً مشابه بسته دارای لایسنس است. برای استفاده بدون محدودیت‌های ارزیابی، چند خط کد را به [اعمال لایسنس](/slides/fa/python-java/licensing/) اضافه کنید.

نسخه ارزیابی Aspose.Slides (که بدون لایسنس استفاده می‌شود) تمام عملکردهای محصول را فراهم می‌کند، اما دو محدودیت دارد:

- به هر اسلاید از هر ارائه‌ای که ذخیره می‌کند، یک جعبه متن حاوی واترمارک ارزیابی اضافه می‌کند. باز کردن یک ارائه واترمارک اضافه نمی‌کند، اما ذخیره فایلی که قبلاً واترمارک دارد، یک واترمارک دیگر اضافه می‌کند.
- متنی که کد شما می‌خواند به چند کاراکتر ابتدایی‌اش کوتاه می‌شود و پس از آن اخطاری در مورد محدودیت ارزیابی قرار می‌گیرد. این اعمال برای هر اسلاید و برای متنی که کد شما به تازگی تنظیم کرده یا از فایل بارگذاری شده است، برقرار است. متنی که کد شما می‌نویسد به طور کامل ذخیره می‌شود.
