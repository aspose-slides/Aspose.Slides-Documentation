## **نمایش کلی**

Aspose.Slides برای Python از طریق Java ارائه‌های PowerPoint و OpenDocument را می‌خواند و می‌نویسد. همچنین محتویات PDF و HTML را به اسلایدها وارد می‌کند و ارائه‌ها یا اسلایدهای تک‌تایی را به فرمت‌های سند، وب و تصویر صادر می‌سازد.

جدول زیر بارگذاری ارائه را از وارد کردن محتوا و رندر اسلاید متمایز می‌کند. برای یک نمای کلی از قابلیت‌های ویرایش و رندر، به [Features Overview](/slides/fa/python-java/features-overview/) مراجعه کنید.

## **نکات واردات و خروجی**

- **واردات PDF و HTML:** از [SlideCollection.addFromPdf](https://reference.aspose.com/slides/fa/python-java/aspose.slides/slidecollection/#addfrompdf) یا [SlideCollection.addFromHtml](https://reference.aspose.com/slides/fa/python-java/aspose.slides/slidecollection/#addfromhtml) برای ایجاد اسلایدها از محتویات منبع استفاده کنید و آن‌ها را به یک ارائه اضافه کنید.
- **خروجی ارائه:** [SaveFormat](https://reference.aspose.com/slides/fa/python-java/aspose.slides/saveformat/) فرمت‌های ذخیره‌سازی ارائه موجود را فهرست می‌کند، از جمله گزینه‌های خروجی جداگانه HTML و HTML5.
- **خروجی تصویر:** خروجی یک اسلاید به‌صورت تصویر، نمای بصری آن اسلاید را تولید می‌کند. ستون ورودی توصیف نمی‌کند که آیا می‌توان تصویر را به ارائه وارد کرد یا نه.

## **سؤال‌های متداول**

**آیا می‌توانم یک ارائه PPT را به PPTX یا ODP تبدیل کنم؟**

بله. فرمت PPT به‌عنوان ورودی پشتیبانی می‌شود و هر دو فرمت PPTX و ODP به‌عنوان خروجی پشتیبانی می‌شوند. نتایج تبدیل بستگی به ویژگی‌های موجود در فرمت مقصد دارد.

**آیا واردات PDF یا HTML منبع را به‌عنوان فایل PowerPoint باز می‌کند؟**

خیر. واردات اسلایدها را از صفحات PDF یا محتویات HTML ایجاد می‌کند. سپس می‌توانید ارائه حاصل را در یک فرمت ارائه پشتیبانی‌شده ذخیره کنید.

**آیا می‌توانم یک PNG یا SVG صادر‌شده را به‌عنوان ارائه قابل ویرایش بارگذاری کنم؟**

خیر. این خروجی‌ها نمای ظاهر اسلاید را نشان می‌دهند. برای ویرایش متن، اشکال، نمودارها و سایر اشیاء ارائه، باید نسخه منبع را نگه دارید.
