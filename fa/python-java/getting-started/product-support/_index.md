## **نمای کلی**

از انجمن پشتیبانی Aspose.Slides برای پرسش سوالات، گزارش مشکلات و درخواست ویژگی‌ها برای Aspose.Slides for Python via Java استفاده کنید. این مقاله توضیح می‌دهد قبل از ایجاد یک موضوع چه مواردی را بررسی کنید و چه اطلاعاتی به تیم پشتیبانی کمک می‌کند تا مشکل را بازتولید کنند.

## **پشتیبانی فنی**

{{% alert color="info" title="Note" %}}

Aspose پشتیبانی فنی رایگان را به تمام کاربران، از جمله کسانی که محصول را ارزیابی می‌کنند، ارائه می‌دهد. برای جزئیات، به [سیاست‌های پشتیبانی رایگان](https://forum.aspose.com/t/free-support-policies/162313) مراجعه کنید.

{{% /alert %}}

سؤال‌های فنی را در [انجمن پشتیبانی Aspose.Slides](https://forum.aspose.com/c/slides/fa/11) ارسال کنید. در گزارش خود **Aspose.Slides for Python via Java** را مشخص کنید تا تیم بتواند محصول و محیط صحیح را شناسایی کند.

برای دریافت کمک با اولویت، به [مرکز پشتیبانی پرداختی](https://helpdesk.aspose.com/) مراجعه کنید. پشتیبانی پرداختی نیاز به اشتراک جداگانه دارد و در مجوز محصول گنجانده نشده است.

## **قبل از گزارش یک مشکل**

1. به [بارگیری‌ها](https://releases.aspose.com/slides/fa/python-java/) و [یادداشت‌های انتشار](https://releases.aspose.com/slides/fa/python-java/release-notes/) نگاه کنید تا نسخه جدیدتری که ممکن است مشکل را رفع کند، پیدا کنید. در صورت امکان، مشکل را با جدیدترین نسخه در یک محیط آزمایشی بازتولید کنید.
2. در انجمن پشتیبانی، [مستندات](/slides/fa/python-java/) و [مرجع API](https://reference.aspose.com/slides/fa/python-java/) به دنبال پاسخی موجود بگردید.
3. برای مشکلات نصب یا راه‌اندازی JVM، راهنمای [نصب](/slides/fa/python-java/installation/) را مرور کنید و اطمینان حاصل کنید که Python و Java معماری‌های مطابقت‌پذیری دارند.
4. مشکل را به کوچک‌ترین مثال و ارائه ورودی که هنوز آن را بازتولید می‌کند، کاهش دهید.

## **آماده‌سازی گزارش مشکل**

اطلاعات زیر را در موضوع انجمن خود قرار دهید:

- **محیط:** نسخه Aspose.Slides for Python via Java، نسخه Python، نسخه و فروشنده Java، نسخه JPype، سیستم عامل و معماری.
- **مراحل و کد:** یک مثال ساده قابل اجرا در Python، شامل ایمپورت‌ها و راه‌اندازی JVM، و مراحلی که برای بازتولید مشکل لازم است.
- **فایل‌های ورودی:** ارائه و هر فایل مرتبط دیگری که مثال به آن نیاز دارد. فایل‌های متعدد را در یک آرشیو ZIP ترکیب کنید.
- **نتایج مورد انتظار و واقعی:** تفاوت را توصیف کنید و در صورت مؤثر، خروجی تولید شده یا اسکرین‌شات‌ها را ضمیمه کنید. برای مشکلات رندر، اسلایدها و فونت‌های تحت تأثیر را شناسایی کنید.
- **جزئیات خطا:** پیام کامل خطا و ردیابی استک (stack trace) در صورت بروز استثناء.

برای هر مشکل از یک موضوع استفاده کنید. اطلاعات پیگیری مربوط به همان مشکل را به موضوع موجود اضافه کنید تا تیم پشتیبانی بتواند تحقیقات خود را ادامه دهد.

## **سوالات متداول**

**آیا می‌توانم هنگام ارزیابی Aspose.Slides for Python via Java کمک دریافت کنم؟**

بله. پشتیبانی فنی رایگان از طریق انجمن پشتیبانی Aspose.Slides هم در زمان ارزیابی و هم پس از خرید در دسترس است.

**هنگام عدم توانایی راه‌اندازی JVM چه مواردی باید گنجانده شود؟**

نسخه‌های Python، Java و JPype، سیستم عامل، معماری‌های Python و Java، کد راه‌اندازی JVM و پیام کامل خطا را ارائه دهید. این جزئیات به تیم پشتیبانی کمک می‌کند تا تنظیمات شما را بازتولید کنند.

**چگونه مشکلی که پس از ارتقاء ظاهر شد را گزارش دهم؟**

آخرین نسخه‌ای که کار می‌کرد، اولین نسخه‌ای که مشکل را مشاهده کردید و یک مثال ساده با فایل‌های ورودی را شامل کنید. هر تغییر دیگری در محیط که در طول ارتقاء ایجاد شده است را نیز توصیف کنید.
