**به Aspose.Slides for Python via Java خوش آمدید**

![آرم محصول Aspose.Slides for Python via Java](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java یک کتابخانه کلاسی است که به برنامه‌های Python شما اجازه می‌دهد ارائه‌های PowerPoint® را بدون نیاز به Microsoft PowerPoint® بخوانند و بنویسند.

ویژگی‌های کلیدی آن شامل مدیریت متن، اشکال، جداول و انیمیشن‌ها؛ افزودن صدا و ویدئو به اسلایدها؛ پیش‌نمایش اسلایدها؛ و استخراج اسلایدها به فرمت‌های SVG، PDF و دیگر قالب‌ها می‌باشد.

{{% /alert %}}

{{% alert color="info" title="توجه" %}}
