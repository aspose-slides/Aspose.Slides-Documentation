**به Aspose.Slides for Python via Java خوش آمدید**

![آرم محصول Aspose.Slides for Python via Java Product Logo](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java یک کتابخانه کلاس است که به برنامه‌های Python شما امکان خواندن و نوشتن ارائه‌های PowerPoint® را بدون نیاز به Microsoft PowerPoint® می‌دهد.

ویژگی‌های کلیدی آن شامل مدیریت متن، شکل‌ها، جداول و انیمیشن‌ها؛ اضافه کردن صدا و ویدئو به اسلایدها؛ پیش‌نمایش اسلایدها؛ و استخراج اسلایدها به SVG، PDF و سایر فرمت‌ها است.

{{% /alert %}}
