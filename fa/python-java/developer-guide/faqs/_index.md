## **نمای کلی**

این سؤالات متداول شامل قالب‌های فایل پشتیبانی‌شده، استفاده از حافظه در ارائه‌های بزرگ، اندازه و پیش‌نمایش اسلایدها، استخراج متن، مرزهای جدول، قرارگیری تصویر، و تفاوت‌های قلم هنگام تبدیل ارائه‌ها به PDF یا تصاویر می‌باشد.

## **پرسش‌های متداول**

### **قالب‌های فایل پشتیبانی‌شده**

**کدام قالب‌های فایل Aspose.Slides برای Python از طریق Java را پشتیبانی می‌کند؟**

برای مشاهده قالب‌های ارائه، سند و تصویر پشتیبانی‌شده و قابلیت‌های واردات و صادرات آنها، به [قالب‌های فایل پشتیبانی‌شده](/slides/fa/python-java/supported-file-formats/) مراجعه کنید.

### **استثناها**

**چرا هنگام بارگذاری یک ارائه بزرگ با تصاویر خطای کمبود حافظه دریافت می‌کنم؟ آیا محدودیتی برای حجم فایل وجود دارد؟**

هیچ آستانهٔ واحدی برای حجم فایل وجود ندارد که بتواند پیش‌بینی کند آیا یک ارائه در حافظه جا می‌گیرد یا نه. نیازهای حافظه به ساختار ارائه، تصاویر فشرده‌نشده، افکت‌ها و عملیات‌های انجام‌شده بستگی دارد. تصاویر می‌توانند حافظهٔ بسیار بیشتری نسبت به اندازهٔ فشردهٔ آنها بر روی دیسک اشغال کنند.

Aspose.Slides برای Python از طریق Java از موتور جاوا از طریق JPype استفاده می‌کند، بنابراین هپ JVM باید فضای کافی برای پردازش داشته باشد. تنها RAM موجود در سیستم نشانگر میزان حافظه‌ای که JVM می‌تواند استفاده کند نیست. پس از پایان استفاده، ارائه‌ها را با [Presentation.dispose](https://reference.aspose.com/slides/fa/python-java/aspose.slides/presentation/#dispose) آزاد کنید. برای تنظیم محیط، به [System Requirements](/slides/fa/python-java/system-requirements/) و [Installation](/slides/fa/python-java/installation/) مراجعه کنید.

### **کار با اسلایدها**

**آیا می‌توانم اندازهٔ اسلایدهای یک ارائه را تغییر دهم؟**

بله. برای دسترسی به تنظیمات اندازهٔ اسلاید ارائه، از [Presentation.getSlideSize](https://reference.aspose.com/slides/fa/python-java/aspose.slides/presentation/#getslidesize) استفاده کنید، سپس با استفاده از [SlideSize.setSize](https://reference.aspose.com/slides/fa/python-java/aspose.slides/slidesize/#setsize) ابعاد را تنظیم کنید و تعیین کنید محتوای موجود چگونه مقیاس‌بندی شود.

**آیا اسلایدهای یک ارائه می‌توانند اندازهٔ متفاوتی داشته باشند؟**

نه. اسناد Microsoft PowerPoint اندازهٔ اسلاید را در سطح ارائه تعریف می‌کنند، بنابراین همهٔ اسلایدها همان ابعاد را دارند.

**آیا می‌توانم پیش‌نمایش یک اسلاید را قبل از ذخیرهٔ ارائه مشاهده کنم؟**

بله. اسلاید را به تصویری رندرسازی کنید و آن تصویر را در برنامهٔ خود نمایش دهید. نیازی به ذخیرهٔ پیش از آن ارائه نیست.

### **کار با متن**

**آیا می‌توانم تمام متن یک ارائه را بازیابی کنم؟**

بله. کلاس [SlideUtil](https://reference.aspose.com/slides/fa/python-java/aspose.slides/slideutil/) متدهایی برای بازیابی متن از ارائه‌ها و اسلایدهای منفرد فراهم می‌کند.

**چرا اندازهٔ پاراگراف‌ها در ویندوز و لینوکس متفاوت است؟**

ابعاد پاراگراف به معیارهای قلم‌های استفاده‌شده برای رندرسازی متن وابسته است. اگر قلمی موجود نباشد، جایگزین ممکن است پهنای کاراکتر و ارتفاع خط متفاوتی داشته باشد که باعث تغییر در بسته شدن خطوط و ابعاد پاراگراف می‌شود. همان قلم‌ها را روی هر دو سیستم نصب کنید یا قبل از ایجاد یا بارگذاری ارائه‌ها، فایل‌های قلم را با [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/fa/python-java/aspose.slides/fontsloader/#loadexternalfonts) بارگذاری کنید.

### **قالب‌بندی و تصاویر**

**چگونه می‌توانم رنگ حاشیهٔ جدول را تنظیم کنم؟**

از [Cell.getCellFormat](https://reference.aspose.com/slides/fa/python-java/aspose.slides/cell/#getcellformat) برای دسترسی به قالب‌بندی حاشیهٔ هر سلول استفاده کنید و رنگ پر برای حاشیه‌های مربوطه تنظیم کنید. برای تغییر تمام حاشیه‌ها، همهٔ سلول‌ها را پردازش کنید. برای تغییر فقط خطوط بیرونی جدول، تنها حاشیه‌های بیرونی سلول‌های قرار گرفته در لبه‌های جدول را به‌روز کنید.

**از چه واحدهایی برای موقعیت‌یابی و اندازه‌گیری تصاویر استفاده می‌شود؟**

مختصات و ابعاد اشکال بر حسب پوینت اندازه‌گیری می‌شود. یک اینچ برابر با ۷۲ پوینت است؛ این مقادیر مختصات پیکسل نیستند.

### **کار با قلم‌ها**

**چرا قلم‌ها هنگام تبدیل یک ارائه به PDF یا تصاویر تغییر می‌کنند؟**

قلم‌های مورد نیاز ممکن است بر روی دستگاهی که تبدیل را انجام می‌دهد موجود نباشند. قلم‌های اصلی را نصب کنید یا با استفاده از [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/fa/python-java/aspose.slides/fontsloader/#loadexternalfonts) پوشه‌های حاوی آنها را اضافه کنید. قبل از ایجاد یا باز کردن ارائه‌ها، قلم‌های خارجی را بارگذاری کنید.

مثال زیر یک پوشهٔ قلم را ثبت می‌کند. مسیر را با پوشه‌ای که حاوی فایل‌های قلم شما است جایگزین کنید. این مثال فرض می‌کند محیط مطابق با توضیحات آمده در [Installation](/slides/fa/python-java/installation/) است.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontsLoader

font_folders = jpype.JArray(jpype.JString)(["path_to_a_folder_with_fonts"])
FontsLoader.loadExternalFonts(font_folders)
```

این مثال JVM را برای عملیات‌های بعدی ارائه باز نگه می‌دارد. برای استفاده در دفترچه‌ها و محدودیت‌های چرخهٔ حیات JVM، به [Limitations and API Differences](/slides/fa/python-java/limitations-and-api-differences/) مراجعه کنید.
