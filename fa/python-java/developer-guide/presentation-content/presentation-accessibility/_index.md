## **مقدمه**

دسترسی‌پذیری ارائه‌ها اطمینان می‌دهد که افرادی که از فناوری‌های کمکی — مانند خوانندگان صفحه، نمایشگرهای بریل یا ناوبری فقط با صفحه‌کلید — می‌توانند اسلایدهای شما را همانند مخاطبان بینایی‌پذیر که از ماوس استفاده می‌کنند، درک و مرور کنند. بهترین تمرین‌ها بر ترتیب واضح خواندن، متن جایگزین معنادار برای تصاویر آموزنده، کنتراست رنگ کافی، تایپوگرافی قابل خواندن، متن لینک توصیفی و عدم انتقال معنا فقط از طریق رنگ یا موقعیت تمرکز می‌کنند. وقتی دسترسی‌پذیری از ابتدا برنامه‌ریزی شود، ساختاری تمیزتر، تصاویر سازگارتر و محتوایی که بدون نیاز به راه‌حل‌های جایگزین به هر بیننده می‑رسد به دست می‌آید.

## **علامت‌گذاری به عنوان تزئینی**

علامت‌گذاری به عنوان تزئینی، برای تصاویر صرفاً تزئینی استفاده می‌شود تا خوانندگان صفحه از آن‌ها عبور کنند، نویز را کاهش داده و تمرکز را بر محتوای معنادار نگه‌دارند. این کار را برای پس‌زمینه‌ها، تزئینات و فواصل اعمال کنید—هرگز برای نمودارها، آیکون‌ها یا تصاویری که اطلاعات منتقل می‌کنند. Aspose.Slides این پرچم را برای تشخیص و اعتبارسنجی در دسترس می‌گذارد و امکان انجام بررسی‌های خودکار دسترسی‌پذیری و پاکسازی را فراهم می‌کند.

![علامت‌گذاری به عنوان تزئینی](mark_as_decorative.png)

نمونه کد زیر نشان می‌دهد چگونه می‌توان تعیین کرد که آیا شکلی به عنوان تزئینی علامت‌گذاری شده است یا خیر.

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation

presentation = Presentation("sample.pptx")
try:
    shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0)
    print(f"Is shape decorative: {shape.isDecorative()}")
finally:
    presentation.dispose()
```
