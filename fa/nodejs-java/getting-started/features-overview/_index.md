## **پلتفرم‌های پشتیبانی‌شده**
Aspose.Slides for Node.js via Java یک API مستقل از پلتفرم است. می‌تواند بر روی هر پلتفرمی (Windows، Linux، macOS و غیره) که Node.js نسخه 7 یا بالاتر نصب شده باشد، استفاده شود. Oracle JDK نسخه 8 یا بالاتر نیز یک پیش‌نیاز دیگر است.

## **قالب‌های فایل و تبدیل‌ها**
Aspose.Slides for Node.js via Java اکثر قالب‌های سند PowerPoint را پشتیبانی می‌کند. همچنین امکان استخراج این اسناد به قالب‌های پرکاربردی که سازمان‌ها برای به اشتراک‌گذاری استفاده می‌کنند، را فراهم می‌آورد. به جزئیات زیر نگاهی بیندازید:

|**ویژگی**|**توضیح**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java سریع‌ترین پردازش را برای این قالب ارائه می‌دهد.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java از تبدیل PPT به PPTX پشتیبانی می‌کند.|
|Portable Document Format (PDF)|می‌توانید تمام قالب‌های فایل پشتیبانی‌شده را با یک متد به اسناد Adobe Portable Document Format (PDF) استخراج کنید.|
|XML Parser Specification (XPS)|می‌توانید تمام قالب‌های فایل پشتیبانی‌شده را با یک متد به اسناد XML Parser Specification (XPS) استخراج کنید.|
|Tagged Image File Format (TIFF)|می‌توانید تمام قالب‌های فایل ارائه را به Tagged Image File Format (TIFF) استخراج کنید.|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java از تبدیل PresentationEx به قالب HTML پشتیبانی می‌کند.|

## **رندر ارائه**
Aspose.Slides for Node.js via Java رندر با دقت بالا از اسلایدهای ارائه به قالب‌های گرافیکی مختلف را پشتیبانی می‌کند. به جزئیات زیر نگاهی بیندازید:

|**ویژگی**|**توضیح**|
| :- | :- |
|Java Supported Image Formats|با استفاده از Aspose.Slides for Node.js via Java می‌توانید اسلایدهای ارائه و تصاویری که در اسلایدها قرار دارند را به تمام قالب‌های گرافیکی پشتیبانی‌شده توسط Java مثل TIFF، PNG، BMP، JPEG، GIF رندر کنید.|
|SVG Format|Aspose.Slides for Node.js via Java همچنین متدهای توکار برای استخراج اسلایدهای ارائه به قالب Scalable Vector Graphics (SVG) فراهم می‌آورد.|

## **پرسش‌های متداول**

### آیا برای کارکرد کتابخانه نیاز به نصب Microsoft PowerPoint بر روی سرور/کامپیوتر دارم؟

خیر. PowerPoint نیازی نیست؛ Aspose.Slides یک موتور مستقل برای ایجاد، ویرایش، تبدیل و رندر ارائه‌هاست.

### چندنخی‌کاری چگونه کار می‌کند؟ آیا می‌توان پردازش را موازی کرد؟

ایمن است که اسناد مختلف را در رشته‌های (threads) متفاوت پردازش کنید؛ شیء [presentation](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/presentation/) نباید همزمان توسط [multiple threads](/slides/fa/nodejs-java/multithreading/) استفاده شود.

### آیا گذرواژه‌های فایل و رمزنگاری پشتیبانی می‌شود؟

بله. می‌توانید [presentations](/slides/fa/nodejs-java/password-protected-presentation/) رمزگذاری‌شده را باز کنید، گذرواژه باز کردن و نوشتن را تنظیم یا حذف کنید و وضعیت حفاظت را بررسی کنید.

### آیا در کانتینرهای لینوکس باید به بسته‌های فونت توجه داشته باشم؟

بله. توصیه می‌شود بسته‌های فونت رایج را نصب کنید و/یا به‌طور صریح [font directories](/slides/fa/nodejs-java/custom-font/) را در برنامه خود مشخص کنید تا از جایگزینی‌های ناخواسته جلوگیری شود.

### آیا در نسخه ارزیابی محدودیتی وجود دارد؟

در [evaluation mode](/slides/fa/nodejs-java/licensing/) یک واترمارک به خروجی اضافه می‌شود و محدودیت‌های خاصی اعمال می‌گردد؛ یک [30‑day temporary license](https://purchase.aspose.com/temporary-license/) برای تست کامل ویژگی‌ها موجود است.

### آیا وارد کردن فرمت‌های خارجی به یک ارائه (PDF/HTML → PPTX) پشتیبانی می‌شود؟

بله. می‌توانید [PDF pages and HTML content](/slides/fa/nodejs-java/import-presentation/) را به یک ارائه اضافه کنید و آن‌ها را به اسلاید تبدیل کنید.
