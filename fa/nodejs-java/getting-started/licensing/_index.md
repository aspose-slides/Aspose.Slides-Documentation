## **ارزیابی Aspose.Slides**
می‌توانید به راحتی Aspose.Slides را برای ارزیابی دانلود کنید. بسته ارزیابی همان بسته خریداری شده است. نسخه ارزیابی پس از افزودن چند خط کد برای اعمال مجوز به سادگی مجوزدار می‌شود.

## **محدودیت‌های نسخه ارزیابی**
نسخه ارزیابی Aspose.Slides (بدون مجوز مشخص) تمام عملکردهای محصول را ارائه می‌دهد، اما دو محدودیت دارد:

* یک جعبه متن نشان‌دار ارزیابی را به هر اسلاید از هر ارائه‌ای که ذخیره می‌کند، اضافه می‌کند.
* متنی که طول آن بیش از پنج کاراکتر باشد و کد شما آن را از یک ارائه می‌خواند، به اولین پنج کاراکترش کوتاه می‌شود و پس از آن `... text has been truncated due to evaluation version limitation.` اضافه می‌شود. متنی با طول پنج کاراکتر یا کمتر بدون تغییر بازگردانده می‌شود و متنی که کد شما می‌نویسد به‌صورت کامل ذخیره می‌شود.

## **درباره مجوز**
می‌توانید به راحتی نسخه ارزیابی Aspose.Slides برای Node.js از طریق Java را از [صفحه دانلود](https://releases.aspose.com/slides/nodejs-java/) دریافت کنید. نسخه ارزیابی همان ویژگی‌های نسخه دارای مجوز را دارد، به‌جز محدودیت‌های توضیح داده شده در بالا. علاوه بر این، پس از خرید مجوز و افزودن چند خط کد برای اعمال مجوز، نسخه ارزیابی به سادگی مجوزدار می‌شود.

مجوز یک فایل XML متنی ساده است که جزئیاتی نظیر نام محصول، تعداد توسعه‌دگرانی که برای آنها مجوز دارد، تاریخ انقضای اشتراک و غیره را شامل می‌شود. این فایل به‌صورت دیجیتال امضا شده است، بنابراین آن را تغییر ندهید. حتی افزودن ناخواسته یک خط جدید به محتوای فایل آن را نامعتبر می‌کند.

برای دور زدن محدودیت‌های مرتبط با نسخه ارزیابی، لازم است قبل از استفاده از **Aspose.Slides** یک مجوز تنظیم کنید. شما تنها یک بار در هر برنامه یا فرآیند نیاز به تنظیم مجوز دارید.

{{% alert color="info" title="Note" %}}
ممکن است بخواهید به [Metered Licensing](/slides/fa/nodejs-java/metered-licensing/) نگاه کنید.
{{% /alert %}}

### **تنظیم مجوز در Aspose.Slides برای Node.js از طریق Java**

مجوزها می‌توانند از این مکان‌ها اعمال شوند:

* مسیر صریح
* جریان
* به‌عنوان مجوز متری – یک مکانیزم جدید مجوزدهی

{{% alert color="info" title="Note" %}}
از متد **setLicense** برای اعطای مجوز به یک مؤلفه استفاده کنید.

در حالی که چندین فراخوانی برای **setLicense** مضر نیستند، اما منابع (پردازنده) را هدر می‌دهند.
{{% /alert %}}

#### **اعمال مجوز با استفاده از فایل**

این قطعه کد برای تنظیم یک فایل مجوز استفاده می‌شود:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");

const license = new asposeSlides.License();
license.setLicense("Aspose.Slides.lic");
console.log("The license was applied.");

// Aspose.Slides در یک ماشین مجازی جاوا اجرا می‌شود که Node.js را فعال نگه می‌دارد، بنابراین فرآیند را به‌صورت صریح پایان دهید.
process.exit(0);
```

در هنگام فراخوانی متد setLicense، نام مجوز باید همانند نام فایل مجوز شما باشد. برای مثال می‌توانید نام فایل مجوز را به "Aspose.Slides.lic.xml" تغییر دهید. سپس در کد خود باید نام جدید مجوز (Aspose.Slides.lic.xml) را به متد setLicense پاس دهید. اگر فایل موجود نباشد یا شامل مجوز معتبر نباشد، [setLicense](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) یک استثنا پرتاب می‌کند که اسکریپت را با خطا پایان می‌دهد.

#### **اعمال مجوز از یک جریان**

برای اعمال مجوز از یک جریان، شیء [License](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/) و یک جریان قابل خواندن را به متد ایستاتیک [setLicenseFromStream](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) پاس دهید. جریان به‌صورت ناهمزمان خوانده می‌شود و اگر جریان شامل مجوز معتبر نباشد، کال‌بک یک خطا دریافت می‌کند:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");
const fs = require("fs");

const license = new asposeSlides.License();
const readStream = fs.createReadStream("Aspose.Slides.lic");
asposeSlides.License.setLicenseFromStream(license, readStream, function (error) {
    if (error) {
        console.error("The license was not applied:", error.message);
    } else {
        console.log("The license was applied.");
    }

    // Aspose.Slides در یک ماشین مجازی جاوا اجرا می‌شود که Node.js را فعال نگه می‌دارد، بنابراین فرآیند را به‌صورت صریح پایان دهید.
    process.exit(0);
});
```

مجوز زمانی که کل جریان خوانده شد، درست پیش از اجرا شدن کال‌بک اعمال می‌شود، بنابراین کارهای دیگر Aspose.Slides را از داخل کال‌بک آغاز کنید.

هر دو نمونه پس از اتمام با `process.exit(0)` خاتمه می‌یابند، زیرا ماشین مجازی جاوا که Aspose.Slides را اجرا می‌کند، Node.js را فعال نگه می‌دارد. در یک برنامه، به جای خاتمه دادن به فرآیند، به کد Aspose.Slides خود ادامه دهید.

## **سؤالات متداول**

### آیا می‌توانم مجوز را در محیطی کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی مجوز به‌صورت محلی با استفاده از فایل مجوز انجام می‌شود؛ نیازی به اتصال به اینترنت نیست.

### بعد از انقضای اشتراک یک‌ساله چه اتفاقی می‌افتد؟ آیا کتابخانه کار خود را متوقف می‌کند؟

خیر. مجوز دائمی است: می‌توانید از نسخه‌های منتشرشده قبل از تاریخ پایان اشتراک خود استفاده کنید؛ فقط بدون تمدید، برای استفاده از نسخه‌های جدیدتر صلاحیت نخواهید داشت.
