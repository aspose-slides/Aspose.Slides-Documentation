**به Aspose.Slides برای Node.js از طریق Java خوش آمدید**

![آرم محصول Aspose.Slides برای Node.js از طریق Java](aspose_slides-for-nodejs-via-java.png)

Aspose.Slides برای Node.js از طریق Java یک کتابخانهٔ کلاس است که به برنامه‌های شما امکان خواندن و نوشتن اسناد PowerPoint® را بدون استفاده از Microsoft PowerPoint® می‌دهد.

Aspose.Slides برای Node.js از طریق Java اولین و تنها مؤلفه‌ای است که قابلیت مدیریت اسناد PowerPoint® را فراهم می‌کند.

Aspose.Slides برای Node.js از طریق Java ویژگی‌های کلیدی بسیاری ارائه می‌دهد از جمله مدیریت متن، شکل‌ها، جدول‌ها و انیمیشن‌ها، افزودن صدا و ویدئو به اسلایدها، پیش‌نمایش اسلایدها، استخراج اسلایدها به قالب SVG، PDF و غیره.
