## **مقدمه**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند، که برای چاپ و نمایش روی صفحه‌نمایش بسیار مهم است.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت 4:3)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **عرض کامل (نسبت 16:9)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

از یکنواختی در تمام ارائه خود اطمینان حاصل کنید؛ یک اندازه اسلاید و نسبت ابعاد برای همه اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرایند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" title="Note" %}}
به‌صورت پیش‌فرض، ارائه‌های ساخته‌شده با Aspose.Slides از نسبت استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و تک‌نویس ابعاد جداگانه‌ای نسبت به اسلایدهای معمولی دارند. برای تغییر اندازه و چرخش آن‌ها به [Notes Page Size](/slides/fa/nodejs-java/notes-size/) مراجعه کنید.

## **تغییر اندازه اسلاید در ارائه‌ها**

 این نمونه کد نشان می‌دهد چگونه اندازه اسلاید را در یک ارائه JavaScript با استفاده از Aspose.Slides تغییر دهید:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **مشخص کردن اندازه اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های معمولی اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، می‌توانید از یک اندازه اسلاید خاص یا منحصربه‌فرد استفاده کنید. برای مثال، اگر قصد دارید اسلایدهای کامل‌سایز را روی یک طرح‌بندی سفارشی چاپ کنید یا ارائه خود را روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، تنظیم اندازه سفارشی می‌تواند مفید باشد.

این نمونه کد نشان می‌دهد چگونه از Aspose.Slides برای Node.js از طریق Java برای تعیین اندازه اسلاید سفارشی در یک ارائه JavaScript استفاده کنید:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **برخورد با مشکلات هنگام تغییر اندازه اسلایدها در ارائه‌ها**

پس از تغییر اندازه اسلاید برای یک ارائه، محتوای اسلایدها (مانند تصاویر یا اشیاء) ممکن است دچار اعوجاج شوند. به‌صورت پیش‌فرض، اشیاء به‌صورت خودکار برای تناسب با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتوای اسلایدها برخورد کند.

بسته به هدف و نیات شما، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء را کوچک کند تا همه آن‌ها در اسلاید جا بگیرند (به این ترتیب از دست رفتن محتوا جلوگیری می‌شود)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء را بزرگ کند تا با اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این نمونه کد نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه از تنظیم `Maximize` استفاده کنید:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **سوالات متداول**

**آیا می‌توانم با استفاده از واحدهای دیگری غیر از اینچ (مثلاً نقطه یا میلی‌متر) اندازه اسلاید سفارشی تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از نقطه استفاده می‌کند که 1 نقطه برابر با 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقطه تبدیل کنید و مقدارهای تبدیل‌شده را برای تعریف عرض و ارتفاع اسلاید به‌کار ببرید.

**آیا اندازه اسلاید سفارشی بسیار بزرگ بر روی عملکرد و مصرف حافظه هنگام رندرینگ تأثیر منفی دارد؟**

بله. ابعاد بزرگتر اسلاید (به نقطه) همراه با مقیاس رندرینگ بالاتر منجر به افزایش مصرف حافظه و زمان پردازش می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را تنها در صورت نیاز برای رسیدن به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه متفاوت دارند ترکیب کنم؟**

شما نمی‌توانید [merge presentations](/slides/fa/nodejs-java/merge-presentation/) را در حالی که اندازه اسلایدهای آن‌ها متفاوت است انجام دهید — ابتدا یک ارائه را برای هماهنگ شدن با دیگری تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید نحوه برخورد با محتوای موجود را از طریق گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هماهنگ‌سازی اندازه‌ها، می‌توانید اسلایدها را ترکیب کنید در حالی که قالب‌بندی حفظ می‌شود.

**آیا می‌توانم برای شکل‌های فردی یا نواحی خاصی از اسلاید تصویرهای بندانگشتی تولید کنم و آیا این تصویرها به اندازه اسلاید جدید احترام می‌گذارند؟**

بله. Aspose.Slides می‌تواند برای [entire slides](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/slide/#getImage) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/shape/#getImage) تصویر بندانگشتی رندر کند. تصاویر حاصل، اندازه اسلاید فعلی و نسبت ابعاد را منعکس می‌کند و چارچوب و هندسهٔ یکنواختی را تضمین می‌کند.
