## **مقدمه**

Aspose.Slides ابزارهای کاملی برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه‌نمایش هر دو حیاتی است.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت ابعاد ۴:۳)**: مناسب برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **پهن‌نمای (نسبت ابعاد ۱۶:۹)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

در سراسر ارائه خود ثبات را حفظ کنید؛ یک اندازه اسلاید و نسبت ابعاد واحد برای همه اسلایدها اعمال می‌شود. برای به‌دست آوردن نتایج بهینه، ابعاد اسلاید را در آغاز فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت ابعاد استاندارد ۴:۳ استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این کد نمونه نشان می‌دهد چگونه می‌توانید اندازه اسلاید را در یک ارائه با استفاده از Aspose.Slides در JavaScript تغییر دهید:

```javascript
var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **مشخص‌کردن اندازه‌های اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (۴:۳ و ۱۶:۹) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. به‌عنوان مثال، اگر قصد دارید اسلایدهای با ابعاد کامل را از ارائه خود روی یک طرح صفحه سفارشی چاپ کنید یا اگر می‌خواهید ارائه خود را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً استفاده از تنظیمات اندازه سفارشی برای ارائه‌تان مفید خواهد بود.

این کد نمونه نشان می‌دهد چگونه می‌توانید از Aspose.Slides برای Node.js از طریق Java برای تعیین اندازه اسلاید سفارشی در یک ارائه با JavaScript استفاده کنید:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **رفع مشکلات هنگام تغییر اندازه اسلایدها در ارائه‌ها**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیاء) ممکن است دچار اعوجاج شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای متناسب شدن با اندازه جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید یک ارائه، می‌توانید تنظیماتی را تعیین کنید که مشخص می‌کند Aspose.Slides چگونه با محتویات اسلایدها رفتار می‌کند.

بسته به هدف یا نیازی که دارید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء موجود در اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس‌بندی کنید و لازم دارید Aspose.Slides اشیاء اسلایدها را کوچک کند تا همه در اسلایدها جا بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگ‌تر مقیاس‌بندی کنید و لازم دارید Aspose.Slides اشیاء اسلایدها را بزرگ کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد چگونه می‌توانید از تنظیم `Maximize` هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **سوالات متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهایی غیر از اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند، به‌طوری که ۱ پوینت برابر است با ۱/۷۲ اینچ. می‌توانید هر واحدی (مانند میلی‌متر یا سانتیمتر) را به پوینت تبدیل کنید و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا یک اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه هنگام رندرینگ تأثیر می‌گذارد؟**

بله. ابعاد بزرگتر اسلاید (به پوینت) همراه با مقیاس رندرینگ بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید به‌یک اندازه اسلاید عملی هدف بگذارید و مقیاس رندرینگ را فقط در صورت لزوم برای دست‌یابی به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌های با اندازه‌های متفاوت ادغام کنم؟**

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/nodejs-java/merge-presentation/) انجام دهید وقتی اندازه اسلایدها متفاوت است — ابتدا یک ارائه را به اندازه دیگری تغییر دهید. هنگام تغییر اندازه اسلاید، می‌توانید با استفاده از گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/slidesizescaletype/) تعیین کنید که محتویات موجود چگونه پردازش شوند. پس از هم‌تراز کردن اندازه‌ها، می‌توانید اسلایدها را با حفظ قالب‌بندی ادغام کنید.

**آیا می‌توانم برای اشکال فردی یا نواحی خاصی از یک اسلاید تصویر پیش‌نمایش (thumbnail) تولید کنم و آیا این‌ها اندازه اسلاید جدید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصاویر پیش‌نمایش برای [کل اسلایدها](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/slide/#getImage) و همچنین برای [اشکال انتخابی](https://reference.aspose.com/slides/fa/nodejs-java/aspose.slides/shape/#getImage) تولید کند. تصاویر به‌دست‌آمده اندازه و نسبت ابعاد فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسهٔ سازگاری را تضمین می‌نمایند.
