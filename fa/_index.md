## Aspose.Slides برای .NET

{{% alert color="info" %}}

![Aspose.Slides for .NET Product Logo](home_1.png)

Aspose.Slides برای .NET یک API مدیریت Microsoft PowerPoint® است که به برنامه‌های .NET امکان خواندن و نوشتن اسناد PowerPoint® را بدون استفاده از Microsoft PowerPoint® می‌دهد. Aspose.Slides برای .NET اولین و تنها مؤلفه‌ای است که امکان مدیریت اسناد PowerPoint® را فراهم می‌کند. Aspose.Slides برای .NET ویژگی‌های کلیدی زیادی مانند مدیریت متن، اشکال، جدول‌ها و انیمیشن‌ها، افزودن صدا و ویدیو به اسلایدها، پیش‌نمایش اسلایدها، خروجی اسلایدها به فرمت SVG، PDF و موارد دیگر را ارائه می‌دهد.
