## **مقدمه**

Aspose.Slides ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت عرض به ارتفاع در ارائه‌های PowerPoint ارائه می‌دهد که برای چاپ و نمایش روی صفحه‌نمایش هم اهمیت دارد.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (4:3 Aspect Ratio)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- ** widescreen (16:9 Aspect Ratio)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

برای حفظ یکپارچگی در سراسر ارائه خود، یک اندازه اسلاید و نسبت عرض به ارتفاع واحد برای تمام اسلایدها اعمال شود. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرایند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به‌صورت پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت عرض به ارتفاع 4:3 استاندارد استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

 این کد نمونه نشان می‌دهد چگونه اندازه اسلاید را در یک ارائهٔ Java با استفاده از Aspose.Slides تغییر دهید:

```java
Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مشخص‌کردن اندازه اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، می‌توانید تصمیم بگیرید که از یک اندازهٔ خاص یا منحصر به فرد استفاده کنید. به‌عنوان مثال، اگر قصد دارید اسلایدهای تمام‌سایز را از ارائه‌تان روی یک قالب صفحهٔ سفارشی چاپ کنید یا ارائه‌تان را روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً استفاده از تنظیمات اندازهٔ سفارشی برای ارائه‌تان مفید خواهد بود.

این کد نمونه نشان می‌دهد چگونه به‌وسیله Aspose.Slides for Java یک اندازهٔ اسلاید سفارشی برای یک ارائهٔ Java تعریف کنید:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتوای اسلایدها (مانند تصویرها یا اشیاء) ممکن است دچار اعوجاج شوند. به‌صورت پیش‌فرض، اشیاء به‌صورت خودکار برای تناسب با اندازهٔ جدید اسلاید تغییر اندازه می‌یابند. با این حال، هنگام تغییر اندازه اسلاید یک ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتواهای موجود در اسلایدها برخورد کند.

بسته به آن‌چه می‌خواهید انجام دهید یا به‌دست آورید، می‌توانید از هر‌یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازهٔ کوچک‌تر اسلاید مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کوچک کند تا همهٔ آن‌ها در اسلاید جا بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازهٔ بزرگ‌تر اسلاید مقیاس‌بندی کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ کند تا نسبت به اندازهٔ جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این کد نمونه نشان می‌دهد چگونه هنگام تغییر اندازه اسلاید یک ارائه از تنظیم `Maximize` استفاده کنید:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **پرسش‌های متداول**

**آیا می‌توانم اندازهٔ سفارشی اسلاید را با واحدهایی غیر از اینچ (مثلاً نقطه یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از نقطه استفاده می‌کند که 1 نقطه برابر با 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقطه تبدیل کنید و از مقادیر تبدیل‌شده برای تعیین عرض و ارتفاع اسلاید استفاده کنید.

**آیا اندازهٔ سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه هنگام رندرینگ تاثیر می‌گذارد؟**

بله. ابعاد بزرگ‌تر اسلاید (به نقطه) همراه با مقیاس رندرینگ بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازهٔ عملی برای اسلاید انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی موردنظر تنظیم کنید.

**آیا می‌توانم یک اندازهٔ اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازهٔ متفاوت دارند ترکیب کنم؟**

نمی‌توانید [merge presentations](/slides/fa/java/merge-presentation/) را هنگام داشتن اندازه‌های مختلف اسلاید انجام دهید — ابتدا یک ارائه را به‌صورت اندازهٔ دیگر تغییر دهید تا مطابقت داشته باشد. هنگام تغییر اندازه اسلاید می‌توانید نحوهٔ مدیریت محتوای موجود را از طریق گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/java/com.aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هم‌راستاسازی اندازه‌ها، می‌توانید اسلایدها را ترکیب کنید و قالب‌بندی را حفظ کنید.

**آیا می‌توانم تصاویر کوچک برای شکل‌های جداگانه یا مناطق خاصی از اسلاید تولید کنم و آیا این تصاویر با اندازهٔ جدید اسلاید سازگار خواهند بود؟**

بله. Aspose.Slides می‌تواند تصاویر کوچک برای [entire slides](https://reference.aspose.com/slides/fa/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/java/com.aspose.slides/shape/#getImage-int-float-float-) تولید کند. تصاویر تولید شده اندازه و نسبت عرض به ارتفاع فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسهٔ ثابت را تضمین می‌نمایند.
