## **مقدمه**

Aspose.Slides ابزارهای جامعی برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش اهمیت دارد.

اندازه‌ها و نسبت‌های معمول اسلاید:

- **استاندارد (نسبت 4:3)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **پهن‌صفحه (نسبت 16:9)**: توصیه‌شده برای پروژکتورها و نمایشگرهای مدرن.

سازگاری را در سرتاسر ارائه خود حفظ کنید، زیرا یک اندازه اسلاید و نسبت ابعاد واحد برای تمام اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید خود را در آغاز فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" %}} 
به‌طور پیش‌فرض، ارائه‌های ایجادشده با Aspose.Slides از نسبت استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این نمونه کد نشان می‌دهد که چگونه می‌توانید اندازه اسلاید را در یک ارائه با استفاده از Aspose.Slides در جاوا تغییر دهید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مشخص‌کردن اندازه‌های اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به‌فرد استفاده کنید. برای مثال، اگر برنامه‌ریزی می‌کنید اسلایدهای تمام‌اندازه را از ارائه خود بر روی یک قالب صفحه سفارشی چاپ کنید یا قصد دارید ارائه خود را بر روی برخی انواع صفحه‌نمایش‌ها نمایش دهید، احتمالاً از تنظیم اندازه سفارشی برای ارائه خود بهره‌مند خواهید شد.

این نمونه کد نشان می‌دهد که چگونه می‌توانید از Aspose.Slides برای جاوا استفاده کرده و یک اندازه اسلاید سفارشی را برای یک ارائه در جاوا مشخص کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیاء) ممکن است مخدوش شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای متناسب شدن با اندازه جدید اسلاید تغییر اندازه می‌یابند. اما هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتویات اسلایدها برخورد می‌کند.

با توجه به هدف یا نیازی که دارید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه یابند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را به‌صورت کوچکتر مقیاس کند تا همهٔ آنها در اسلایدها جا بگیرند (به این ترتیب، از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگتر کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این نمونه کد نشان می‌دهد که چگونه می‌توانید از تنظیم `Maximize` هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **سوالات متداول**

### آیا می‌توانم اندازه اسلاید سفارشی را با استفاده از واحدهایی غیر از اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟

بله. Aspose.Slides به‌صورت داخلی از پوینت‌ها استفاده می‌کند، به‌طوری که 1 پوینت برابر 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به پوینت تبدیل کنید و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

### آیا اندازهٔ سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه هنگام رندر کردن تأثیر خواهد گذاشت؟

بله. ابعاد بزرگ‌تر اسلاید (بر حسب پوینت) همراه با مقیاس رندر بالا منجر به مصرف بیشتر حافظه و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازهٔ عملی برای اسلاید انتخاب کنید و مقیاس رندر را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

### آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوت دارند ادغام کنم؟

شما نمی‌توانید [ادغام ارائه‌ها](/slides/fa/java/merge-presentation/) را انجام دهید در حالی که اندازه‌های اسلاید متفاوت هستند — ابتدا یک ارائه را به اندازهٔ دیگری تغییر دهید. هنگام تغییر اندازه اسلاید، می‌توانید با استفاده از گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/java/com.aspose.slides/slidesizescaletype/) انتخاب کنید که محتویات موجود چگونه مدیریت شوند. پس از هم‌تراز کردن اندازه‌ها، می‌توانید اسلایدها را ادغام کنید در حالی که قالب‌بندی حفظ می‌شود.

### آیا می‌توانم برای شکل‌های تک‌تک یا نواحی خاص یک اسلاید، تصویرهای بندانگشتی تولید کنم و آیا این تصاویر اندازهٔ جدید اسلاید را رعایت می‌کنند؟

بله. Aspose.Slides می‌تواند تصویرهای بندانگشتی برای [تمام اسلایدها](https://reference.aspose.com/slides/fa/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) و همچنین برای [اشکال انتخاب‌شده](https://reference.aspose.com/slides/fa/java/com.aspose.slides/shape/#getImage-int-float-float-) تولید کند. تصاویر خروجی اندازهٔ فعلی اسلاید و نسبت ابعاد را منعکس می‌کنند و تضمین می‌کنند که قاب‌بندی و هندسهٔ یکسانی حفظ شوند.
