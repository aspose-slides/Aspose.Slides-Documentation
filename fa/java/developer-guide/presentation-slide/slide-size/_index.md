## **مقدمه**

Aspose.Slides ابزارهای کاملی برای تنظیم اندازه اسلاید و نسبت عرض به ارتفاع در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه‌نمایش حیاتی است.

اندازه‌ها و نسبت‌های متداول اسلاید:

- **استاندارد (نسبت 4:3)**: مناسب برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **عریض (نسبت 16:9)**: برای پروژکتور‌ها و نمایشگرهای مدرن توصیه می‌شود.

سازگاری را در تمام ارائه خود حفظ کنید زیرا یک اندازه اسلاید و نسبت عرض به ارتفاع برای همه اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" title="Note" %}}
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و برگه‌های توزیع اندازه‌های جداگانه‌ای نسبت به اسلایدهای معمولی دارند. برای تغییر اندازه و جهت‌گیری آن‌ها به [Notes Page Size](/slides/fa/java/notes-size/) مراجعه کنید.

## **تغییر اندازه اسلاید در ارائه‌ها**

 این کد نمونه نشان می‌دهد چگونه اندازه اسلاید را در یک ارائهٔ Java با Aspose.Slides تغییر دهید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مشخص کردن اندازه اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های متداول اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، می‌توانید اندازهٔ خاص یا منحصر به‌فردی را انتخاب کنید. به‌عنوان مثال، اگر قصد دارید اسلایدهای تمام‑اندازه را روی یک صفحهٔ سفارشی چاپ کنید یا ارائه خود را روی نوع خاصی از صفحه‌نمایش نمایش دهید، تنظیم اندازه سفارشی می‌تواند مفید باشد.

این کد نمونه نشان می‌دهد چگونه با Aspose.Slides برای Java اندازهٔ اسلاید سفارشی را برای یک ارائهٔ Java تعیین کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

بعد از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیاء) ممکن است مختل شوند. به‌صورت پیش‌فرض، اشیاء به‌طور خودکار برای متناسب شدن با اندازهٔ جدید اسلاید تغییر اندازه می‌دهند. با این حال، هنگام تغییر اندازهٔ اسلاید، می‌توانید تنظیمی را مشخص کنید که نحوهٔ برخورد Aspose.Slides با محتویات اسلایدها را تعیین می‌کند.

بسته به هدف شما، می‌توانید از هر یک از تنظیمات زیر استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازهٔ اسلاید کوچکتر مقیاس دهید و نیاز دارید Aspose.Slides اشیاء را کوچک کند تا همهٔ آن‌ها در اسلایدها جا بگیرند (به این ترتیب از از دست دادن محتوا جلوگیری می‌شود)، این تنظیم را به کار بگیرید.

- `Maximize`

  اگر می‌خواهید به اندازهٔ اسلاید بزرگتر مقیاس دهید و نیاز دارید Aspose.Slides اشیاء را بزرگ کند تا با اندازهٔ جدید اسلاید تناسب داشته باشند، این تنظیم را انتخاب کنید.

این کد نمونه نشان می‌دهد چگونه هنگام تغییر اندازهٔ اسلاید یک ارائه از تنظیم `Maximize` استفاده کنید:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **پرسش‌های رایج**

**آیا می‌توانم اندازهٔ اسلاید سفارشی را با واحدهای دیگری جز اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند که 1 پوینت برابر 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتیمتر) را به پوینت تبدیل کرده و مقادیر تبدیل‌شده را برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا اندازهٔ سفارشی بسیار بزرگ باعث کاهش عملکرد و استفاده بیشتر از حافظه در زمان رندر می‌شود؟**

بله. ابعاد بزرگ‌تر اسلاید (به پوینت) به همراه مقیاس رندر بالاتر منجر به مصرف بیشتر حافظه و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازهٔ عملی برای اسلاید انتخاب کنید و مقیاس رندر را فقط در صورت نیاز برای رسیدن به کیفیت خروجی مطلوب تغییر دهید.

**آیا می‌توانم یک اندازهٔ اسلاید غیر استاندارد تعریف کنم و سپس اسلایدهای ارائه‌های با اندازه‌های مختلف را ادغام کنم؟**

شما نمی‌توانید [merge presentations](/slides/fa/java/merge-presentation/) را وقتی که اندازهٔ اسلایدها متفاوت است انجام دهید — ابتدا یک ارائه را به اندازهٔ دیگر تغییر دهید. هنگام تغییر اندازه اسلاید می‌توانید تعیین کنید محتویات موجود چگونه مدیریت شوند؛ برای این کار از گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/java/com.aspose.slides/slidesizescaletype/) استفاده کنید. پس از هماهنگ کردن اندازه‌ها، می‌توانید اسلایدها را ادغام کنید و قالب‌بندی را حفظ کنید.

**آیا می‌توانم تصویرهایی کوچک (thumbnail) برای اشکال منفرد یا نواحی خاصی از اسلاید تولید کنم و آیا این تصاویر اندازهٔ جدید اسلاید را در نظر می‌گیرند؟**

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [entire slides](https://reference.aspose.com/slides/fa/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/java/com.aspose.slides/shape/#getImage-int-float-float-) تولید کند. تصاویر حاصل اندازه و نسبت عرض به ارتفاع فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسهٔ ثابت را تضمین می‌نمایند.
