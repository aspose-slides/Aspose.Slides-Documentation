{{% alert color="info" %}} 

یک [Aspose.Slides for Java API](https://docs.aspose.com/slides/fa/java/) جدید منتشر شده است و اکنون این محصول واحد قابلیت تولید اسناد PowerPoint از صفر و ویرایش اسناد موجود را پشتیبانی می‌کند.

{{% /alert %}} 
## **پشتیبانی از کدهای قدیمی**
برای استفاده از کدهای قدیمی که با نسخه‌های Aspose.Slides for Java قبل از 13.x توسعه یافته‌اند، باید تغییرات جزئی در کد خود اعمال کنید و کد همانند قبل کار خواهد کرد. تمام کلاس‌هایی که در Aspose.Slides for Java قدیمی تحت فضای‌نام‌های Aspose.Slide و Aspose.Slides.Pptx وجود داشتند، حالا در یک فضای‌نام واحد Aspose.Slides ادغام شده‌اند. لطفاً به قطعه کد ساده زیر برای افزودن سرصفحه و پاصفحه در ارائه در API قدیمی Aspose.Slides نگاه کنید و مراحل مهاجرت به API جدید ادغام‌شده را دنبال کنید.
