## **تبدیل PPT به PPTX**
Aspose.Slides for Java اکنون به توسعه‌دهندگان امکان می‌دهد با استفاده از نمونهٔ کلاس [Presentation](https://reference.aspose.com/slides/fa/java/com.aspose.slides/presentation) به فایل PPT دسترسی پیدا کنند و آن را به فرمت مربوطهٔ [PPTX](https://docs.fileformat.com/presentation/pptx/) تبدیل کنند. در حال حاضر، تبدیل جزئی از [PPT ](https://docs.fileformat.com/presentation/ppt/) به PPTX را پشتیبانی می‌کند. برای جزئیات بیشتر دربارهٔ ویژگی‌های پشتیبانی‌شده و پشتیبانی‌نشده در تبدیل PPT به PPTX، لطفاً به این مستندات [لینک](/slides/fa/java/ppt-to-pptx-conversion/) مراجعه کنید.

Aspose.Slides for Java کلاس [Presentation] را ارائه می‌دهد که نمایانگر یک فایل ارائهٔ **PPTX** است. کلاس Presentation اکنون می‌تواند همچنین به **PPT** از طریق Presentation دسترسی پیدا کند هنگامی که شیء نمونه‌سازی می‌شود. مثال زیر نشان می‌دهد چگونه یک ارائهٔ PPT را به ارائهٔ PPTX تبدیل کنیم.

```java
import com.aspose.slides.*;

// ایجاد یک شیء Presentation که نمایانگر یک فایل PPT است
Presentation pres = new Presentation("Aspose.ppt");
try {
// ذخیرهٔ ارائهٔ PPT به فرمت PPTX
    pres.save("ConvertedAspose.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **سؤالات متداول**

### تفاوت بین فرمت‌های PPT و PPTX چیست؟

PPT فرمت باینری قدیمی است که توسط Microsoft PowerPoint استفاده می‌شود، در حالی که PPTX فرمت مبتنی بر XML جدیدی است که از Microsoft Office 2007 معرفی شد. فایل‌های PPTX عملکرد بهتر، حجم فایل کمتر و بازیابی داده‌های پیشرفته‌تری ارائه می‌دهند.

### آیا Aspose.Slides از تبدیل دسته‌ای چندین فایل PPT به PPTX پشتیبانی می‌کند؟

بله، می‌توانید از Aspose.Slides در یک حلقه استفاده کنید تا به‌صورت برنامه‌نویسی چندین فایل PPT را به PPTX تبدیل کنید، که آن را برای سناریوهای تبدیل دسته‌ای مناسب می‌سازد.

### آیا محتوا و قالب‌بندی پس از تبدیل حفظ می‌شود؟

Aspose.Slides وفاداری بالایی در تبدیل ارائه‌ها حفظ می‌کند. طرح‌بندی اسلایدها، انیمیشن‌ها، اشکال، نمودارها و سایر عناصر طراحی هنگام تبدیل PPT به PPTX حفظ می‌شوند.

### آیا می‌توانم سایر فرمت‌ها مانند PDF یا HTML را از فایل‌های PPT تبدیل کنم؟

بله، Aspose.Slides از تبدیل فایل‌های PPT به [فرمت‌های متعدد](https://reference.aspose.com/slides/fa/java/com.aspose.slides/saveformat/) شامل PDF، XPS، HTML، ODP و فرمت‌های تصویری مانند PNG و JPEG پشتیبانی می‌کند.
