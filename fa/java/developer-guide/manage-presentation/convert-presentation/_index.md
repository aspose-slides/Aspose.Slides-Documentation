## **نمای کلی**

Aspose.Slides for Java می‌تواند ارائه‌های PowerPoint و OpenDocument را بارگیری کرده و بدون نیاز به Microsoft PowerPoint، OpenOffice یا LibreOffice، آن‌ها را در فرمت‌های مختلف دیگر ذخیره یا رندر کند. می‌توانید فایل‌های PPT قدیمی را به PPTX مدرن تبدیل کنید، ارائه‌ها را به اسناد ثابت‌چیدمان مانند PDF و XPS صادر کنید، اسلایدها را به صورت HTML منتشر کنید یا اسلایدها را به‌عنوان فایل‌های تصویری برای پیش‌نمایش، تصویر کوچک و آرشیو رندر نمایید.

اکثر تبدیل‌های سند از همان جریان کاری کلی استفاده می‌کند: بارگیری فایل منبع، انتخاب فرمت خروجی مورد نیاز و اعمال گزینه‌های خاص فرمت در صورت نیاز. برای فرمت‌های تصویری، هر اسلاید به‌صورت جداگانه رندر شده و سپس به عنوان تصویر رستری یا برداری ذخیره می‌شود. مقالات ویژه‌ای که در ادامه لینک شده‌اند، جزئیات پیاده‌سازی برای هر مورد را ارائه می‌دهند.

## **تبدیل PowerPoint و OpenDocument**

Aspose.Slides for Java از تبدیل فرمت‌های ارائه متداول مانند PPT، PPTX، PPS، PPSX، POT، POTX و ODP پشتیبانی می‌کند. همان API تبدیل برای فایل‌های PowerPoint و OpenDocument استفاده می‌شود، بنابراین یک جریان کاری که فایل PPTX را به PDF ذخیره می‌کند، معمولاً می‌تواند با تغییر تنها فایل ورودی به ODP اعمال شود.

هنگام تبدیل فایل‌های ODP، به یاد داشته باشید که برنامه‌های PowerPoint و OpenDocument هر ویژگی چیدمان و قالب‌بندی را به‌طور دقیق یکسان پشتیبانی نمی‌کنند. اگر یک فایل ODP در LibreOffice یا OpenOffice Impress ایجاد شده باشد، خروجی را بررسی کنید و هنگام نیاز به راهنمایی خاص فرمت، از گزینه‌های توضیح داده شده در [تبدیل ارائه‌های OpenDocument](/slides/fa/java/convert-openoffice-odp/) استفاده کنید.

## **تبدیل PPT به PPTX**

PPT فرمت باینری قدیمی PowerPoint است، در حالی که PPTX فرمت مدرن Office Open XML است. Aspose.Slides for Java از تبدیل دقیق PPT به PPTX با حفظ ساختارهای پیچیده ارائه مانند مسترها، چیدمان‌ها، اسلایدها، نمودارها، شکل‌های گروهی، نمایشگرهای متنی، فریم‌های متن، بافت‌ها و پرکننده‌های تصویر پشتیبانی می‌کند.

برای جزئیات، به [تبدیل PPT به PPTX](/slides/fa/java/convert-ppt-to-pptx/) و [PPT در مقایسه با PPTX](/slides/fa/java/ppt-vs-pptx/) مراجعه کنید.

## **صادر کردن ثابت‌چیدمان**

PDF، XPS و TIFF زمانی مفید هستند که خروجی باید در تمام دستگاه‌ها یکسان به‌نظر برسد و به‌عنوان یک ارائه ویرایش نشود. مقالات ویژه PDF، XPS و TIFF توضیح می‌دهند که چگونه انطباق، اسلایدهای مخفی، یادداشت‌ها، کیفیت تصویر، فشرده‌سازی، فرمت پیکسل و اندازه خروجی را کنترل کنید.

## **صادر کردن HTML و تصویر**

صادر کردن HTML و HTML5 برای مشاهده در مرورگر، انتشار وب و به‌اشتراک‌گذاری سبک مفید است. صادر کردن تصویر وقتی مفید است که هر اسلاید باید به‌صورت پیش‌نمایش، تصویر کوچک یا دارایی رستری جداگانه تبدیل شود. برای راهنمایی‌های خاص هر فرمت، از مقالات PNG، JPG و SVG استفاده کنید.

## **پرسش‌های متداول**

**آیا برای تبدیل ارائه‌ها به Microsoft PowerPoint نیاز دارم؟**

خیر. Aspose.Slides for Java یک کتابخانه مستقل است و به Microsoft PowerPoint یا اتوماسیون Office نیاز ندارد.

**آیا می‌توانم بسیاری از ارائه‌ها را به‌صورت دسته‌ای تبدیل کنم؟**

بله. هر ارائه را بارگیری کنید، به فرمت مورد نیاز ذخیره کنید و پس از پردازش شی ارائه را آزاد کنید. برای پردازش موازی، از نمونه‌های جداگانه ارائه استفاده کنید و دستورالعمل‌های [multithreading](/slides/fa/java/multithreading/) را دنبال کنید.

**آیا می‌توانم تنها اسلایدهای انتخابی را صادر کنم؟**

بله. چندین روش صادرات امکان پاس دادن ایندکس‌های اسلاید یا رندر اسلایدهای منفرد را بسته به فرمت خروجی فراهم می‌کند. مقاله ویژه فرمت هدف را مشاهده کنید.

**آیا می‌توانم اسلایدهای مخفی را هنگام صادرات به PDF یا XPS گنجانده شود؟**

بله. از تنظیمات صادرات اسلایدهای مخفی که در مقالات تبدیل [PDF](/slides/fa/java/convert-powerpoint-to-pdf/) و [XPS](/slides/fa/java/convert-powerpoint-to-xps/) توضیح داده شده است استفاده کنید.

**آیا می‌توانم خروجی PDF/A ایجاد کنم؟**

بله. تنظیمات انطباق PDF برای صادرات PDF در دسترس است. برای جزئیات به [تبدیل PowerPoint به PDF](/slides/fa/java/convert-powerpoint-to-pdf/) مراجعه کنید.

**فونت‌ها در طول تبدیل چگونه مدیریت می‌شوند؟**

Aspose.Slides می‌تواند از فونت‌های تعبیه‌شده، جایگزینی فونت و تنظیمات بازگشت فونت استفاده کند. به [Embedded Font](/slides/fa/java/embedded-font/)، [Fallback Font](/slides/fa/java/fallback-font/) و [Font Substitution](/slides/fa/java/font-substitution/) مراجعه کنید.
