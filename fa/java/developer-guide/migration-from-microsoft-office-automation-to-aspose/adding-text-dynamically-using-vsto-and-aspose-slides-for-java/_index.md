یک کار رایج که توسعه‌دهندگان برای انجام آن تلاش می‌کنند، افزودن متن به اسلایدها به‌صورت پویا است. این مقاله مثال‌های کد برای افزودن متن به‌صورت پویا با استفاده از [VSTO](/slides/fa/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/) و [Aspose.Slides for Java](/slides/fa/java/adding-text-dynamically-using-vsto-and-aspose-slides-for-java/) را نشان می‌دهد.

## **افزودن متن به‌صورت پویا**
هر دو روش این مراحل را دنبال می‌کنند:

1. یک ارائه ایجاد کنید.
1. یک اسلاید خالی اضافه کنید.
1. یک جعبه متن اضافه کنید.
1. متنی تنظیم کنید.
1. ارائه را بنویسید.
