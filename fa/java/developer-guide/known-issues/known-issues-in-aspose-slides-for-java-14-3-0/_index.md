{{% alert color="info" title="Note" %}}

این یک صفحه تاریخی است. این صفحه مشکلات شناخته شده منتشر شده با Aspose.Slides for Java 14.3.0 را فهرست می‌کند و نسخهٔ فعلی را توصیف نمی‌کند. برای تغییرات در هر نسخه، یادداشت‌های انتشار را ببینید[release notes](https://releases.aspose.com/slides/fa/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) اجرای کاملاً جدیدی از پردازش PPT فراهم می‌کند. بهبودهای بسیاری وجود دارد، تبدیل جزئی PPTX به PPT. اما برخی ویژگی‌های پیاده‌نشده وجود دارند:

- برخی از اشکال در اسناد PPT سریالی‌شده هندسهٔ نادرستی دارند (Call outs)
- تمام ویژگی‌های قالب‌بندی متن PPTX در سریال‌سازی PPT پشتیبانی نمی‌شوند
- اطلاعات مربوط به زبان متن و تنظیمات املایی در اسناد PPT سریالی‌شده موجود نیست
- تمام ویژگی‌های تم‌های PPTX در سریال‌سازی PPT پشتیبانی نمی‌شوند

**برخی تفاوت‌ها در مقایسه با Aspose.Slides for Java 8.6.0 وجود دارد:**

- مشکلات شناخته‌شده‌ای در سریال‌سازی OLE/ActiveX PPT به PPT وجود دارد.

**برخی تفاوت‌ها در مقایسه با Aspose.Slides for .NET 14.3.0 وجود دارد:**

- پشتیبانی از چاپ ارائه در حال حاضر در Aspose.Slides for Java موجود نیست.
