## **نمای کلی**

این بخش شامل فهرست مشکلات باز در نسخه فعلی نیست. این بخش شامل سه صفحه است:

- [نگهدارنده پیش‌نمایش شیء هنگام افزودن OleObjectFrame](/slides/fa/java/object-preview-issue-when-adding-oleobjectframe/) توضیح می‌دهد چرا یک شیء OLE که با Aspose.Slides اضافه می‌شود تصویر «EMBEDDED OLE OBJECT» را نشان می‌دهد تا پیش‌نمایش آن به‌روز شود، و چگونه تصویر پیش‌نمایش خودتان را تنظیم کنید. این رفتار به‌صورت پیش‌فرض در نسخه فعلی وجود دارد.
- [مشکلات شناخته‌شده در Aspose.Slides برای Java 14.3.0 (Historical)](/slides/fa/java/known-issues-in-aspose-slides-for-java-14-3-0/) و [مشکلات شناخته‌شده در Aspose.Slides برای Java 14.4.0 (Historical)](/slides/fa/java/known-issues-in-aspose-slides-for-java-14-4-0/) فهرست‌هایی هستند که با آن نسخه‌ها منتشر شده‌اند و برای مرجع نگهداری می‌شوند.

برای تغییرات و اصلاحات در هر نسخه، به [یادداشت‌های انتشار](https://releases.aspose.com/slides/fa/java/release-notes/) مراجعه کنید. فیلدهای متاداده‌ای که Aspose.Slides با مقادیر ثابت می‌نویسد در [محدودیت‌های متاداده خروجی](/slides/fa/java/api-limitations/) توضیح داده شده‌اند. برای بررسی اینکه آیا مشکلی قبلاً شناخته شده است یا برای گزارش یک مشکل، از [انجمن پشتیبانی](https://forum.aspose.com/c/slides/fa/11) استفاده کنید.
