{{% alert color="info" %}} 

Aspose.Slides for Java 14.4.0 تصمیم جدیدی برای پردازش اسناد PowerPoint ارائه می‌دهد. برخی محدودیت‌ها و مشکلات شناخته‌شده وجود دارد که در نسخه‌های آینده حذف خواهند شد:

- برخی شکل‌ها در اسناد PPT سریال‌سازی شده دارای هندسه نادرست هستند (قوس، فلش دایروی، حاشیه‌ها).
- تمام ویژگی‌های قالب‌بندی متن PPTX در سریال‌سازی PPT پشتیبانی نمی‌شوند (محدودیت‌های تب، تورفتگی و قالب‌بندی پاراگراف).
- اطلاعات مربوط به زبان متن و تنظیمات املایی در اسناد PPT سریال‌سازی شده موجود نیست.
- تمام ویژگی‌های تم PPTX در سریال‌سازی PPT پشتیبانی نمی‌شوند (فقط سریال‌سازی فرمت‌های پر، فرمت‌های خط و قلم).
- مشکلات شناخته‌شده‌ای در سریال‌سازی OLE/ActiveX از PPT به PPT وجود دارد.
- سریال‌سازی و رندرینگ WordArt پشتیبانی نمی‌شود.
