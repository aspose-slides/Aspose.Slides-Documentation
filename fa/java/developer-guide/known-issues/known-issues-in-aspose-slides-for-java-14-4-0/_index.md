{{% alert color="info" title="Note" %}}

این یک صفحه تاریخی است. این صفحه محدودیت‌ها و مشکلات شناخته‌شده‌ای که همراه با Aspose.Slides for Java 14.4.0 منتشر شده‌اند را فهرست می‌کند و نسخه فعلی را توصیف نمی‌کند. برای تغییرات در هر نسخه، به [یادداشت‌های انتشار](https://releases.aspose.com/slides/fa/java/release-notes/) مراجعه کنید.

{{% /alert %}}

Aspose.Slides for Java 14.4.0 تصمیم جدیدی برای پردازش اسناد PowerPoint ارائه می‌دهد. برخی محدودیت‌ها و مشکلات شناخته‌شده وجود دارد که در نسخه‌های آینده حذف خواهند شد:

- برخی اشکال در اسناد PPT سریال‌سازی شده دارای هندسه اشتباه هستند (قوس، فلش دایره‌ای، حاشیه‌نویسی).
- تمام ویژگی‌های قالب‌بندی متن PPTX در سریال‌سازی PPT پشتیبانی نمی‌شوند (تب‌گذاری، تورفتگی و محدودیت‌های قالب‌بندی پاراگراف).
- اطلاعات درباره زبان متن و تنظیمات املایی در اسناد PPT سریال‌سازی شده موجود نیست.
- تمام ویژگی‌های تم PPTX در سریال‌سازی PPT پشتیبانی نمی‌شوند (فقط سریال‌سازی فرمت‌های پر کردن، فرمت‌های خط و قلم).
- مشکلات شناخته‌شده‌ای در سریال‌سازی OLE/ActiveX PPT به PPT وجود دارد.
- سریال‌سازی و رندرینگ WordArt پشتیبانی نمی‌شود.
