## **معرفی**

متن جایگزین به افرادی که از فناوری‌های کمکی استفاده می‌کنند کمک می‌کند معنای تصاویر، نمودارها و سایر شکل‌های اطلاعاتی را درک کنند. این مقاله توضیح می‌دهد چگونه عناوین و توصیفات متن جایگزین را با Aspose.Slides برای Java بخوانید و به‌روزرسانی کنید، توصیفات دسترسی‌پذیری را از نام‌های شکل که در کد استفاده می‌شوند متمایز کنید، و بررسی کنید آیا یک شکل به‌عنوان تزئینی علامت‌گذاری شده است یا نه.

این ویژگی‌ها از دسترسی‌پذیری ارائه‌ها پشتیبانی می‌کنند، اما تضمین‌کننده آن نیستند. ترتیب خواندن، کنتراست رنگ، قابلیت خواندن متن و سایر نیازهای دسترسی‌پذیری نیز باید بررسی شوند.

## **مدیریت عناوین و توصیفات متن جایگزین**

از متن جایگزین برای توضیح معنای تصاویر، نمودارها و سایر شکل‌های اطلاعاتی برای افرادی که نمی‌توانند آن‌ها را ببینند استفاده کنید. روش‌ها و محتواهای زیر اهداف متفاوتی دارند:

| روش یا محتوا | هدف |
| --- | --- |
| [getAlternativeTextTitle](https://reference.aspose.com/slides/fa/java/com.aspose.slides/ishape/#getAlternativeTextTitle--) | عنوان کوتاهی برای توصیف جایگزین. |
| [getAlternativeText](https://reference.aspose.com/slides/fa/java/com.aspose.slides/ishape/#getAlternativeText--) | توضیح معنی‌داری از محتوای شکل یا هدف آن در زمینه اسلاید. |
| [getName](https://reference.aspose.com/slides/fa/java/com.aspose.slides/ishape/#getName--) | نام شکل که کد می‌تواند برای یافتن یک شکل خاص در ارائه از آن استفاده کند. |
| Visible text | متنی که روی اسلاید نمایش داده می‌شود، مانند متن یک شکل یا عنوان و برچسب‌های یک نمودار. به‌روزرسانی متن جایگزین این محتوا را تغییر نمی‌دهد. |

هنگامی که یک ارائه به عنوان قالب مجددا استفاده می‌شود، کد ممکن است قبل از به‌روزرسانی، شکل را با نامی که توسط [getName](https://reference.aspose.com/slides/fa/java/com.aspose.slides/ishape/#getName--) برگردانده می‌شود پیدا کند. این نام هدف متفاوتی دارد از متن جایگزین که توضیح می‌دهد تصویر برای خواننده چه اطلاعاتی را منتقل می‌کند. جستجو بر اساس نام به نویسندگان امکان می‌دهد توصیفات را بهبود دهند یا ترجمه کنند بدون اینکه نحوه یافتن شکل توسط کد تغییر کند. نام‌ها می‌توانند ویرایش شوند و تضمین نمی‌شود که یکتا باشند، بنابراین اطمینان حاصل کنید که نام با شکل مورد نظر مطابقت دارد؛ برای جزئیات بیشتر به [Identify and Find Shapes](/slides/fa/java/shape-manipulations/#identify-and-find-shapes) مراجعه کنید.

مثال زیر به فایلی به نام `input.pptx` نیاز دارد که شامل عکسی از ورودی یک دفتر به عنوان اولین شکل در اولین اسلاید باشد. این تصویر نباید به‌عنوان تزئینی علامت‌گذاری شده باشد. مثال متن جایگزین عنوان و توصیف فعلی را می‌خواند و چاپ می‌کند، هر دو مقدار را به‌روزرسانی می‌کند و ارائه را به‌عنوان `output.pptx` ذخیره می‌کند. متن را متناسب با تصویر واقعی و اطلاعاتی که انتقال می‌دهد تنظیم کنید.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);

    System.out.println("Alternative text title: " + shape.getAlternativeTextTitle());
    System.out.println("Alternative text description: " + shape.getAlternativeText());

    shape.setAlternativeTextTitle("Office entrance");
    shape.setAlternativeText("The office entrance has a wheelchair ramp to the right of the steps.");

    presentation.save("output.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

افزودن تنها متن جایگزین تضمین‌کننده دسترسی‌پذیری ارائه یا رعایت استانداردهای دسترسی‌پذیری نیست. توصیفات را از نظر دقت و ارتباط بررسی کنید و همچنین ترتیب خواندن، کنتراست رنگ، متن قابل خواندن و سایر الزامات دسترسی‌پذیری را بررسی کنید. تصاویر اطلاعاتی نباید به‌عنوان تزئینی علامت‌گذاری شوند؛ بخش بعدی نشان می‌دهد چگونه [isDecorative](https://reference.aspose.com/slides/fa/java/com.aspose.slides/ishape/#isDecorative--) را بررسی کنید.

## **علامت‌گذاری به‌عنوان تزئینی**

پرچم علامت‌گذاری به‌عنوان تزئینی برای جلوه‌های صرفاً تزئینی استفاده می‌شود تا خواننده‌های صفحه نمایش آن‌ها را نادیده بگیرند، باعث کاهش نویز و تمرکز بر محتوای معنادار می‌شود. این پرچم را بر روی پس‌زمینه‌ها، تزئینات و فضاهای خالی اعمال کنید—هرگز بر روی نمودارها، نمادها یا تصاویری که اطلاعات منتقل می‌کنند. Aspose.Slides این پرچم را برای تشخیص و اعتبارسنجی در اختیار می‌گذارد و امکان انجام بررسی‌های خودکار دسترسی‌پذیری و تمییزکاری را فراهم می‌کند.

![علامت‌گذاری به‌عنوان تزئینی](mark_as_decorative.png)

نمونه کد زیر نشان می‌دهد چگونه تعیین کنید آیا یک شکل به‌عنوان تزئینی علامت‌گذاری شده است یا خیر.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("sample.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);
    System.out.println("Is shape decorative: " + shape.isDecorative());
} finally {
    presentation.dispose();
}
```

## **سؤالات متداول**

**چه چیزی باید در عنوان و توصیف متن جایگزین قرار دهم؟**

از یک عنوان کوتاه برای شناسایی موضوع و یک توصیف برای توضیح اطلاعاتی که تصویر در زمینه اسلاید منتقل می‌کند استفاده کنید. برای یک نمودار، روند یا مقایسه مرتبط را توصیف کنید نه اینکه تنها بگویید «نمودار».

**آیا باید از متن جایگزین برای یافتن اشکال در یک قالب استفاده کنم؟**

به‌جای استفاده از متن جایگزین، ترجیحاً شکل را با نامی که توسط [getName](https://reference.aspose.com/slides/fa/java/com.aspose.slides/ishape/#getName--) برگردانده می‌شود پیدا کنید و اطمینان حاصل کنید که همان شکل مورد انتظار است. متن جایگزین ممکن است ویرایش یا ترجمه شود که می‌تواند باعث شکستن کدی شود که به دنبال توصیف دقیق می‌گردد؛ برای جزئیات بیشتر به [Identify and Find Shapes](/slides/fa/java/shape-manipulations/) مراجعه کنید.

**چه زمانی یک شکل باید به‌عنوان تزئینی علامت‌گذاری شود؟**

پرچم تزئینی را برای عناصر بصری که هیچ اطلاعاتی اضافه نمی‌کنند، مانند تزئینات زینتی، استفاده کنید. تصاویر و نمودارهایی که معنایی منتقل می‌کنند باید به‌جای آن توصیف مناسب داشته باشند.

**آیا افزودن متن جایگزین یک ارائه را کاملاً قابل دسترس می‌کند؟**

خیر. متن جایگزین فقط بخشی از دسترسی‌پذیری را پوشش می‌دهد. همچنین ترتیب خواندن، کنتراست رنگ، خوانایی متن و سایر الزامات مربوطه را بررسی کنید؛ تنظیم تنها این ویژگی‌ها گواهی بر رعایت کامل نیست.
