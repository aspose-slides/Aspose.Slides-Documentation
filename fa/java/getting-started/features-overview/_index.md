## **بررسی کلی**

Aspose.Slides for Java یک کتابخانهٔ کلاس برای ایجاد، خواندن، ویرایش، تبدیل و رندر ارائه‌های PowerPoint و OpenDocument است. این کتابخانه رابط کاربری خود را ندارد و نیازی به Microsoft PowerPoint یا Microsoft Office ندارد. این مقاله خلاصه‌ای از موارد پوشش داده‌شده توسط کتابخانه را ارائه می‌دهد و به مقالاتی که هر حوزه را توضیح می‌دهند لینک می‌دهد.

## **پلتفرم‌های پشتیبانی‌شده**

Aspose.Slides for Java یک فایل JAR واحد است که در مخزن Maven Aspose با دسته‌بند `jdk16` منتشر می‌شود. این کتابخانه به‌صورت خالص Java نوشته شده است: JAR شامل هیچ کتابخانهٔ بومی نیست و به بسته‌های دیگر وابسته نیست.

- **Java:** Java 8 یا بالاتر. نسخه‌های Aspose.Slides for Java 26.9 و پیشین همچنین بر روی Java 6 و 7 اجرا می‌شدند، که نسخه 26.10 دیگر از آن‌ها پشتیبانی نمی‌کند؛ برای جزئیات به [یادداشت‌های انتشار ۲۶.۹](https://releases.aspose.com/slides/fa/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/) مراجعه کنید.
- **سیستم‌عامل‌ها:** هر سیستم‌عاملی که ران‌تایم Java داشته باشد، مانند Windows، Linux و macOS. در Linux، کتابخانهٔ fontconfig و حداقل یک قلم باید نصب شوند.

[نصب](/slides/fa/java/installation/) نشان می‌دهد چگونه کتابخانه را به یک پروژه اضافه کنید و پیش‌نیازهای Linux را فهرست می‌کند. [نیازمندی‌های سیستم](/slides/fa/java/system-requirements/) پلتفرم‌های پشتیبانی‌شده را به‌صورت جزئیات شرح می‌دهد.

## **قالب‌های فایل و تبدیل‌ها**

Aspose.Slides فایل‌های PPT، PPTX، PPS، POT، PPSX، POTX، PPTM، PPSM، POTM، ODP، OTP، FODP و ارائه‌های XML PowerPoint را باز و ذخیره می‌کند. این کتابخانه محتویات PDF و HTML را به اسلایدها وارد می‌کند و ارائه‌ها را به صورت PDF، XPS، HTML، HTML5، TIFF، GIF انیمیشنی، SWF، Markdown و XAML ذخیره می‌کند. [قالب‌های فایل پشتیبانی‌شده](/slides/fa/java/supported-file-formats/) هر قالب را به همراه API مربوط به خواندن یا نوشتن آن فهرست می‌کند.

## **رندر ارائه**

Aspose.Slides اسلایدها و اشکال فردی را به عنوان تصاویر PNG، JPEG، BMP، GIF، TIFF و SVG، و اسلایدها را به فرمت‌های متا‑فایل EMF رندر می‌کند. برای جزئیات بیشتر به [تبدیل اسلایدهای ارائه به تصاویر](/slides/fa/java/convert-slide/)، [رندر اسلایدهای ارائه به تصویر SVG](/slides/fa/java/render-a-slide-as-an-svg-image/) و [ایجاد تصویر بند انگشتی از اشکال ارائه](/slides/fa/java/create-shape-thumbnails/) مراجعه کنید.

## **سوالات متداول**

**آیا برای کارکرد کتابخانه نیاز است که Microsoft PowerPoint روی سرور یا کامپیوتر کاربر نصب باشد؟**

خیر. PowerPoint لازم نیست؛ Aspose.Slides یک موتور مستقل برای ایجاد، ویرایش، تبدیل و رندر ارائه‌ها است.

**چگونه چندنخی‌سازی کار می‌کند؟ آیا پردازش می‌تواند به صورت موازی انجام شود؟**

ایمن است که اسناد مختلف را در نخ‌های مختلف پردازش کنید؛ شیء [Presentation](https://reference.aspose.com/slides/fa/java/com.aspose.slides/presentation/) یک‌باره نمی‌تواند توسط [چندین نخ](/slides/fa/java/multithreading/) همزمان استفاده شود.

**آیا رمزهای عبور فایل و رمزنگاری پشتیبانی می‌شود؟**

بله. می‌توانید [ارائه‌های رمزگذاری‌شده](/slides/fa/java/password-protected-presentation/) را باز کنید، رمز عبور باز کردن یا نوشتن را تنظیم یا حذف کنید و وضعیت محافظت را بررسی نمایید.

**آیا در کانتینرهای Linux باید نسبت به قلم‌ها نگرانی داشته باشم؟**

بله. در Linux کتابخانهٔ fontconfig و حداقل یک قلم باید نصب شوند و قلم‌های مورد استفاده در ارائه‌های شما (یا جایگزین‌های مناسب) باید نصب شوند تا متن به‌درستی رندر شود. همچنین می‌توانید در برنامهٔ خود [دایرکتوری‌های قلم](/slides/fa/java/custom-font/) را مشخص کنید. به [نصب](/slides/fa/java/installation/#linux) مراجعه کنید.

**آیا نسخه ارزیابی محدودیتی دارد؟**

بله. بدون داشتن [مجوز](/slides/fa/java/licensing/)، Aspose.Slides به هر اسلایدی که ذخیره می‌کند یک واترمارک ارزیابی اضافه می‌کند و متن‌هایی که کد شما از طریق API می‌خواند را کوتاه می‌کند. یک [مجوز موقت ۳۰ روزه](https://purchase.aspose.com/temporary-license/) برای تست کامل ویژگی‌ها موجود است.

**آیا وارد کردن فرمت‌های خارجی به یک ارائه (PDF یا HTML به PPTX) پشتیبانی می‌شود؟**

بله. می‌توانید [صفحات PDF و محتویات HTML](/slides/fa/java/import-presentation/) را به یک ارائه اضافه کنید و آن‌ها را به اسلاید تبدیل کنید.
