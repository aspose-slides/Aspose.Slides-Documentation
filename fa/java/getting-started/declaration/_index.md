{{% alert color="info" %}} 

تمام اجزای Aspose Java به مجموعهٔ مجوز Full Trust نیاز دارند. دلیل این است که اجزای Aspose Java برای انجام برخی عملیات مانند پردازش قلم‌ها و غیره نیاز به دسترسی به تنظیمات رجیستری، فایل‌های سیستم خارج از دایرکتوری مجازی دارند. علاوه بر این، اجزای Aspose Java بر پایه کلاس‌های اصلی سیستم Java ساخته شده‌اند که در بسیاری از موارد نیز به مجموعهٔ مجوز Full Trust نیاز دارند. 

{{% /alert %}} 

ارائه‌دهندگان خدمات اینترنتی (ISP) که برنامه‌های متعدد از شرکت‌های مختلف را میزبانی می‌کنند، عموماً سطح امنیتی Medium Trust را اعمال می‌کنند: 

- OleDbPermission در دسترس نیست. این به این معنی است که شما نمی‌توانید از ارائه‌دهنده دادهٔ مدیریت‌شدهٔ OLE DB در ADO.NET برای دسترسی به پایگاه‌های داده استفاده کنید.
- EventLogPermission در دسترس نیست. این به این معنی است که شما نمی‌توانید به رویدادنامهٔ ویندوز دسترسی پیدا کنید.
- ReflectionPermission در دسترس نیست. این به این معنی است که شما نمی‌توانید از Reflection استفاده کنید.
- RegistryPermission در دسترس نیست. این به این معنی است که شما نمی‌توانید به رجیستری دسترسی پیدا کنید.
- WebPermission محدود شده است. این به این معنی است که برنامهٔ شما فقط می‌تواند با آدرسی یا محدوده‌ای از آدرس‌ها که در عنصر <trust> تعریف می‌کنید، ارتباط برقرار کند.
- FileIOPermission محدود شده است. این به این معنی است که شما فقط می‌توانید به فایل‌های موجود در سلسله‌مراتب دایرکتوری مجازی برنامهٔ خود دسترسی داشته باشید.

{{% alert color="info" %}} 

به دلایل مذکور، اجزای Aspose Java نمی‌توانند بر روی سرورهایی که مجموعهٔ مجوزی غیر از Full Trust می‌دهند، استفاده شوند. 

{{% /alert %}}
