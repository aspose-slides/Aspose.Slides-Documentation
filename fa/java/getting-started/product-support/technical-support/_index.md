## **مرور کلی**

این مقاله توضیح می‌دهد که چگونه می‌توانید از پشتیبانی Aspose.Slides استفاده کنید و به‌صورت مؤثر خطاها را گزارش کنید. کانال اصلی پشتیبانی را توصیف می‌کند، توصیه‌هایی برای ارسال یک مشکل ارائه می‌دهد و به منابع فنی مفیدی مانند صفحه محصول، وبلاگ، دانلودها، انجمن پشتیبانی، مستندات و مرجع API اشاره می‌کند. همچنین به سؤالات رایج درباره پشتیبانی با هزینه، ارتقاء مشکل و پشتیبانی از نسخه‌های قدیمی کتابخانه پاسخ می‌دهد.

## **پشتیبانی فنی**

{{% alert color="info" %}} 
Aspose پشتیبانی فنی رایگان نامحدود برای تمام محصولات خود ارائه می‌دهد. این پشتیبانی برای همه کاربران، از جمله نسخه ارزیابی، در دسترس است.
{{% /alert %}} 

اگر به کمک برای Aspose.Slides for Java نیاز دارید، موارد زیر را در نظر بگیرید:

- مسیر اصلی پشتیبانی، Aspose.Forums است. سؤال خود را در انجمن Aspose.Slides ارسال کنید و در عرض چند ساعت پاسخ دریافت کنید. سؤالات توسط تیم پشتیبانی Aspose.Slides به‌صورت مستقیم پاسخ داده می‌شوند.
- لطفاً توجه داشته باشید که Aspose پشتیبانی فنی از طریق تلفن ارائه نمی‌دهد. پشتیبانی تلفنی فقط برای سوالات مرتبط با فروش و خرید در دسترس است.
- هنگامی که منتظر پاسخ در انجمن‌ها هستید، لطفاً اختلافات زمانی را در نظر بگیرید.

اگر مشکلی در Aspose.Slides for Java دارید، مراحل ساده زیر را دنبال کنید تا مطمئن شوید به مؤثرترین شکل حل می‌شود:

- قبل از گزارش مشکل، مطمئن شوید که از آخرین نسخه Aspose.Slides for Java استفاده می‌کنید؛ برای اطلاع از آخرین نسخه، به صفحه دانلود Aspose.Slides مراجعه کنید.
- قبل از گزارش مشکل، انجمن‌ها، این مستندات و مرجع API را مرور کنید؛ شاید سؤال شما قبلاً پاسخ داده شده باشد.
- هنگام گزارش یک مشکل، لطفاً سند اصلی و در صورت امکان بخشی از کدی که منجر به مشکل می‌شود را ضمیمه کنید. اگر نیاز به پیوست چندین فایل دارید، آن‌ها را در یک فایل فشرده (zip) بگذارید. ضمیمه کردن اسناد در Aspose.Forums امن است زیرا فقط شما و توسعه‌دهندگان Aspose به فایل‌های پیوست شده دسترسی دارند.
- لطفاً سعی کنید هر بار فقط یک مشکل را در یک رشته گزارش کنید. اگر مشکل دیگری دارید، آن را در یک رشته جداگانه گزارش کنید.

## **پرسش‌های متداول**

### چه سطوح پشتیبانی با هزینه‌ای موجود است و چگونه متفاوت هستند؟

[توسعه‌دهنده، کسب‌وکار و سازمانی](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services). آنها بر اساس تعداد حوادث شامل‌شده، اولویت پاسخ‌دهی و کانال‌های ارتباطی موجود متفاوت هستند.

### آیا می‌توانم یک باگ را مستقماً به تیم مهندسی ارجاع دهم؟

بله. [پشتیبانی با هزینه](https://helpdesk.aspose.com/) امکان ارجاع به توسعه‌دهندگان را زمانی که مشکلی نیاز به بررسی عمیق‌تر دارد، فراهم می‌کند.

### آیا نسخه‌های قدیمی کتابخانه پشتیبانی می‌شوند و آیا برای آن‌ها اصلاحات منتشر می‌کنید؟

می‌توانید از نسخه‌های قدیمی استفاده کنید، اما اصلاحات فقط برای نسخه فعلی ارائه می‌شود؛ برای نسخه‌های قدیمی پچ منتشر نمی‌شود.
