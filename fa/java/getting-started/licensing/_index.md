## **بررسی کلی**

Aspose.Slides را می‌توان در حالت ارزیابی یا با لایسنس معتبر استفاده کرد. نسخه ارزیابی همان عملکرد نسخه دارای لایسنس را دارد، اما یک واترمارک ارزیابی به هر اسلاید از هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند و متنی که کد شما از طریق API می‌خواند را کوتاه می‑نماید.

این مقاله توضیح می‌دهد که لایسنس در Aspose.Slides چگونه کار می‌کند و چگونه قبل از استفاده از کتابخانه یک لایسنس اعمال شود. یک لایسنس می‌تواند از فایل، جریان (stream) یا منبع جاسازی‌شده با استفاده از کلاس `License` بارگذاری شود. مقاله همچنین نشان می‌دهد چگونه اعتبارسنجی شود که آیا لایسنس به‌درستی اعمال شده است یا خیر.

## **ارزیابی Aspose.Slides**

{{% alert color="info" title="Note" %}}

می‌توانید یک نسخه ارزیابی **Aspose.Slides for Java** را از [صفحهٔ دانلود](https://releases.aspose.com/java/repo/com/aspose/aspose-slides/) دریافت کنید. نسخه ارزیابی همان عملکردهای نسخه دارای لایسنس محصول را فراهم می‌کند. بسته ارزیابی همان بسته خریداری‌شده است. نسخه ارزیابی پس از افزودن چند خط کد (برای اعمال لایسنس) به‌صورت لایسنس شده تبدیل می‌شود.

پس از این‌که از ارزیابی **Aspose.Slides** راضی شدید، می‌توانید [یک لایسنس خریداری کنید](https://purchase.aspose.com/pricing/slides/fa/java/). توصیه می‌شود انواع اشتراک‌های مختلف را بررسی کنید. اگر سؤال دارید، با تیم فروش Aspose تماس بگیرید.

هر لایسنس Aspose یک اشتراک یک‌ساله برای ارتقاءهای رایگان به نسخه‌های جدید یا اصلاحات منتشرشده در دورهٔ اشتراک ارائه می‌دهد. کاربران دارای محصولات دارای لایسنس (یا حتی نسخه‌های ارزیابی) پشتیبانی فنی رایگان و نامحدود دریافت می‌کنند.

{{% /alert %}} 

**محدودیت‌های نسخه ارزیابی**

* نسخه ارزیابی (بدون لایسنس مشخص) تمام عملکردهای محصول را فراهم می‌کند، اما یک جعبهٔ متن واترمارک ارزیابی به هر اسلاید از هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند.
* متنی که کد شما از طریق API می‌خواند، از جمله متنی که تازه تنظیم کرده‌است، به چند کاراکتر اول خود کوتاه می‌شود و پس از آن اطلاعیه‌ای دربارهٔ محدودیت ارزیابی می‌آید. متنی که کد شما می‌نویسد به‌صورت کامل ذخیره می‌شود.

{{% alert color="info" title="Note" %}}

برای تست Aspose.Slides بدون محدودیت‌ها، می‌توانید یک **لایسنس موقت ۳۰ روزه** درخواست کنید. برای اطلاعات بیشتر به صفحهٔ [چگونه لایسنس موقت دریافت کنیم](https://purchase.aspose.com/temporary-license) مراجعه کنید.

{{% /alert %}}

## **لایسنس‌گذاری در Aspose.Slides**

* یک نسخه ارزیابی پس از خرید لایسنس و افزودن چند خط کد (برای اعمال لایسنس) به‌صورت لایسنس شده می‌شود.
* لایسنس یک فایل XML متنی ساده است که جزئیاتی چون نام محصول، تعداد توسعه‌دهندگانی که به آن لایسنس داده شده‌اند، تاریخ انقضای اشتراک و غیره را شامل می‌شود.
* فایل لایسنس به‌صورت دیجیتالی امضا شده است، بنابراین نباید آن را تغییر دهید. حتی افزودن یک خط جدید ناخواسته به محتویات فایل، اعتبار آن را از بین می‌برد.
* Aspose.Slides for Java معمولاً سعی می‌کند لایسنس را در این مسیرها پیدا کند:
  * مسیر صریح
  * پوشهٔ حاوی Aspose.Slides.jar
* برای حذف محدودیت‌های مرتبط با نسخه ارزیابی، باید قبل از استفاده از **Aspose.Slides** یک لایسنس تنظیم کنید. تنها یک بار در هر برنامه یا فرآیند کافی است لایسنس تنظیم شود.

{{% alert color="info" title="Note" %}}

ممکن است مایل باشید به [لایسنس‌گذاری بر پایه مصرف](/slides/fa/java/metered-licensing/) مراجعه کنید.

{{% /alert %}} 


## **اعمال لایسنس**

یک لایسنس می‌تواند از **فایل** یا **جریان** (stream) بارگذاری شود.

{{% alert color="info" title="Note" %}}

Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/java/com.aspose.slides/license/) را برای عملیات لایسنس‌گذاری ارائه می‌دهد.

{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}

لایسنس‌های جدید می‌توانند Aspose.Slides را تنها با نسخه 21.4 یا بالاتر فعال کنند. نسخه‌های قبلی از سیستم لایسنس‌گذاری متفاوتی استفاده می‌کنند و این لایسنس‌ها را تشخیص نمی‌دهند.

{{% /alert %}}

### **فایل**

آسان‌ترین روش برای تنظیم لایسنس این است که فایل لایسنس را در پوشهٔ حاوی Aspose.Slides.jar یا jar برنامهٔ خود قرار دهید.

این کد جاوا نشان می‌دهد چگونه یک فایل لایسنس تنظیم شود:

``` java
// نمونه‌سازی کلاس License
com.aspose.slides.License license = new com.aspose.slides.License();

// تنظیم مسیر فایل لایسنس
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" title="Warning" %}}

اگر فایل لایسنس را در مسیر دیگری قرار دهید، هنگامی که متد [setLicense](https://reference.aspose.com/slides/fa/java/com.aspose.slides/license/#setLicense-java.lang.String-) را فراخوانی می‌کنید، نام فایل لایسنس در انتهای مسیر مشخص شده باید با نام فایل لایسنس شما یکسان باشد.

به‌عنوان مثال می‌توانید نام فایل لایسنس را به *Aspose.Slides.Java.lic.xml* تغییر دهید. سپس در کد خود باید مسیر فایل (که با *Aspose.Slides.Java.lic.xml* پایان می‌یابد) را به متد [setLicense](https://reference.aspose.com/slides/fa/java/com.aspose.slides/license/#setLicense-java.lang.String-) پاس کنید.

{{% /alert %}}

### **جریان**

می‌توانید لایسنس را از یک جریان بارگذاری کنید. این کد جاوا نشان می‌دهد چگونه یک لایسنس از جریان اعمال شود:

``` java
// نمونه‌سازی کلاس License
com.aspose.slides.License license = new com.aspose.slides.License();

// تنظیم لایسنس از طریق یک جریان
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **پل PHP/Java**

اگر از Aspose.Slides for PHP از طریق Java استفاده می‌کنید، می‌توانید لایسنس را از طریق یک پل PHP/Java تنظیم کنید. این پل امکان استفاده از کلاس‌های Java در نحو PHP را می‌دهد. برای اطلاعات بیشتر، به [License in PHP](/slides/fa/php-java/licensing/) مراجعه کنید.

## **اعتبارسنجی لایسنس**

برای بررسی اینکه آیا لایسنس به‌درستی تنظیم شده است یا خیر، می‌توانید آن را اعتبارسنجی کنید. این کد جاوا نشان می‌دهد چگونه یک لایسنس اعتبارسنجی شود:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **ایمنی در برابر نخ‌ها**

{{% alert color="warning" title="Warning" %}}

متد [setLicense](https://reference.aspose.com/slides/fa/java/com.aspose.slides/license/#setLicense-java.io.InputStream-) ایمن برای نخ‌ها نیست. اگر این متد باید همزمان از چندین نخ فراخوانی شود، ممکن است بخواهید از primitives همگام‌سازی (مانند قفل) برای جلوگیری از مشکلات استفاده کنید.

{{% /alert %}}

## **سوالات متداول**

### آیا می‌توانم لایسنس را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ اتصال به اینترنت لازم نیست.

### پس از پایان اشتراک یک‌ساله چه می‌شود؟ آیا کتابخانه کار خود را متوقف می‌کند؟

نه. لایسنس دائمی است: می‌توانید از نسخه‌های منتشرشده قبل از تاریخ پایان اشتراک خود استفاده کنید؛ فقط بدون تمدید، حق استفاده از نسخه‌های جدیدتر را نخواهید داشت.
