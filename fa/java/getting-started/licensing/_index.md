## **بررسی کلی**

Aspose.Slides می‌تواند در حالت ارزیابی یا با یک لایسنس معتبر استفاده شود. نسخه ارزیابی همان عملکرد نسخه لایسنس‌دار را ارائه می‌دهد، اما هنگام باز یا ذخیره‌سازی ارائه‌ها یک واترمارک ارزیابی اضافه می‌کند و استخراج متن را به یک اسلاید محدود می‌کند.

این مقاله توضیح می‌دهد که لایسنس در Aspose.Slides چگونه کار می‌کند و چگونه قبل از استفاده از کتابخانه یک لایسنس اعمال کنید. یک لایسنس می‌تواند از فایل، استریم یا منبع جاسازی‌شده توسط کلاس `License` بارگذاری شود. مقاله همچنین نشان می‌دهد چگونه بررسی کنید که آیا لایسنس به‌درستی اعمال شده است یا خیر.

## **ارزیابی Aspose.Slides**

{{% alert color="info" %}} 

می‌توانید یک نسخه ارزیابی از **Aspose.Slides for Java** را از [صفحه دانلود](https://releases.aspose.com/java/repo/com/aspose/aspose-slides/) دریافت کنید. نسخه ارزیابی همان قابلیت‌های نسخه لایسنس‌دار محصول را فراهم می‌کند. بسته ارزیابی همان بسته خریداری‌شده است. نسخه ارزیابی پس از افزودن چند خط کد (برای اعمال لایسنس) به‌صورت لایسنس‌دار تبدیل می‌شود.

پس از رضایت از ارزیابی **Aspose.Slides**، می‌توانید [یک لایسنس خریداری کنید](https://purchase.aspose.com/buy). توصیه می‌کنیم انواع مختلف اشتراک را بررسی کنید. اگر سؤال دارید، با تیم فروش Aspose تماس بگیرید.

هر لایسنس Aspose همراه با یک اشتراک یک‌ساله برای ارتقاءهای رایگان به نسخه‌های جدید یا اصلاحات منتشرشده در طول دورهٔ اشتراک است. کاربران محصولات لایسنس‌دار (یا حتی نسخه‌های ارزیابی) پشتیبانی فنی رایگان و نامحدود دریافت می‌کنند.

## **لایسنس‌دهی در Aspose.Slides**

* یک نسخه ارزیابی پس از خرید لایسنس و افزودن چند خط کد (برای اعمال لایسنس) لایسنس‌دار می‌شود.
* لایسنس یک فایل XML متنی ساده است که جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که به آنها لایسنس داده شده، تاریخ انقضای اشتراک و غیره را شامل می‌شود. 
* فایل لایسنس به‌صورت دیجیتالی امضا شده است، بنابراین نباید فایل را تغییر دهید. حتی افزودن یک خط جدید ناخواسته به محتویات فایل، اعتبار آن را از بین می‌برد.
* Aspose.Slides for Java معمولاً سعی می‌کند لایسنس را در این مکان‌ها پیدا کند:
  * مسیر صریح
  * پوشه‌ای که Aspose.Slides.jar در آن قرار دارد
* برای جلوگیری از محدودیت‌های نسخه ارزیابی، قبل از استفاده از **Aspose.Slides** باید یک لایسنس تنظیم کنید. کافی است لایسنس را یک‌بار برای هر برنامه یا فرآیند تنظیم کنید.

{{% alert color="info" %}} 

ممکن است بخواهید [لایسنس‌گیری متریک](/slides/fa/java/metered-licensing/) را ببینید.

{{% /alert %}} 


## **اعمال لایسنس**

یک لایسنس می‌تواند از **فایل** یا **استریم** بارگذاری شود.

{{% alert color="info" %}}

Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/java/com.aspose.slides/License) را برای عملیات لایسنس‌دهی فراهم می‌کند.

{{% /alert %}} 

{{% alert color="warning" %}}

لایسنس‌های جدید می‌توانند Aspose.Slides را فقط از نسخه 21.4 به بالا فعال کنند. نسخه‌های قبلی از سیستم لایسنس‌دهی متفاوتی استفاده می‌کنند و این لایسنس‌ها را شناسایی نمی‌کنند.

{{% /alert %}}

### **فایل**

ساده‌ترین روش تنظیم لایسنس این است که فایل لایسنس را در پوشه‌ای که Aspose.Slides.jar یا jar برنامهٔ شما قرار دارد، بگذارید.

این کد جاوا نشان می‌دهد چگونه یک فایل لایسنس تنظیم کنید:

``` java
// نمونه‌سازی کلاس License
com.aspose.slides.License license = new com.aspose.slides.License();

// مسیر فایل لایسنس را تنظیم می‌کند
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" %}} 

اگر فایل لایسنس را در مسیر دیگری قرار دهید، وقتی متد [SetLicense](https://reference.aspose.com/slides/fa/java/com.aspose.slides/License#setLicense-java.lang.String-) را فراخوانی می‌کنید، نام فایل لایسنس در انتهای مسیر صریح باید همان نام فایل لایسنس شما باشد.

به‌عنوان مثال، می‌توانید نام فایل لایسنس را به *Aspose.Slides.Java.lic.xml* تغییر دهید. سپس در کد خود باید مسیر فایل (که با *Aspose.Slides.Java.lic.xml* تمام می‌شود) را به متد [SetLicense](https://reference.aspose.com/slides/fa/java/com.aspose.slides/License#setLicense-java.lang.String-) پاس کنید.

{{% /alert %}}

### **استریم**

می‌توانید یک لایسنس را از استریم بارگذاری کنید. این کد جاوا نشان می‌دهد چگونه یک لایسنس را از استریم اعمال کنید:

``` java
// نمونه‌سازی کلاس License
com.aspose.slides.License license = new com.aspose.slides.License();

// تنظیم مجوز از طریق یک استریم
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **پل PHP/Java**

اگر از Aspose.Slides برای PHP از طریق Java استفاده می‌کنید، می‌توانید لایسنس را از طریق یک پل PHP/Java تنظیم کنید. این پل امکان استفاده از کلاس‌های Java در سینتکس PHP را فراهم می‌کند. برای اطلاعات بیشتر، به [License in PHP](/slides/fa/php-java/licensing/) مراجعه کنید.

## **اعتبارسنجی لایسنس**

برای بررسی اینکه آیا لایسنس به‌درستی تنظیم شده است یا خیر، می‌توانید آن را اعتبارسنجی کنید. این کد جاوا نشان می‌دهد چگونه یک لایسنس را اعتبارسنجی کنید:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **ایمنی در استفاده از چندین رشته**

{{% alert title="Note" color="warning" %}} 

متد [SetLicense](https://reference.aspose.com/slides/fa/java/com.aspose.slides/License#setLicense-java.io.InputStream-) ایمن برای استفاده همزمان از چندین رشته نیست. اگر این متد باید هم‌زمان از چندین رشته فراخوانی شود، ممکن است بخواهید از سازوکارهای همگام‌سازی (مانند یک قفل) برای جلوگیری از مشکلات استفاده کنید. 

{{% /alert %}}

## **سؤالات متداول**

### آیا می‌توانم لایسنس را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ اتصال به اینترنت لازم نیست.

### پس از انقضای یک‌سالهٔ اشتراک چه می‌شود؟ آیا کتابخانه کار خود را متوقف می‌کند؟

نه. لایسنس دائمی است: می‌توانید از نسخه‌های منتشرشده قبل از تاریخ پایان اشتراک خود استفاده کنید؛ فقط برای استفاده از نسخه‌های جدیدتر بدون تمدید مجاز نخواهید بود.
