این یک صفحه تاریخی است. این صفحه یک اشکال را در Aspose.Slides for Java نسخه‌های 23.2 تا 23.7 که در سال 2023 منتشر شده‌اند و نسخه‌های اصلاح‌کننده آن توصیف می‌کند. این صفحه نسخه فعلی را توصیف نمی‌کند. برای دریافت اطلاعات مربوط به مجوز در نسخه فعلی، به [مجوز](/slides/fa/java/licensing/) مراجعه کنید.

{{% /alert %}}

## **مرور کلی**

این مقاله یک اشکال مربوط به مجوز را که در Aspose.Slides for Java نسخه‌های 23.2، 23.3، 23.4، 23.5، 23.6 و 23.7 رخ داده است، توصیف می‌کند. این اشکال باعث شد که مجوزهای دائمی پس از پایان دوره اشتراک، موقتاً قابل استفاده نباشند.

## **علائم**

پس از پایان دوره اشتراک مجوز دائمی شما، نسخه‌های Aspose.Slides for Java 23.2 - 23.7 ممکن است مجوز را به عنوان منقضی گزارش دهند و تمام عملکردها به حالت ارزیابی منتقل شوند. این رفتار نادرست است و بر نسخه‌های پیش از 23.2 و پس از 23.7 تأثیری ندارد.

## **راه‌حل**

Aspose.Slides for Java این مشکل را برطرف کرد و نسخه‌های به‌روز شده (23.2.1، 23.3.1، 23.4.1، 23.5.1، 23.6.1، 23.7.1) را با اصلاح منتشر کرد.
اگر در پروژه خود از یکی از نسخه‌های تحت تأثیر Aspose.Slides for Java استفاده می‌کنید، لطفاً به نسخه اصلاح‌شده سوئیچ کنید.

اگر با هر مشکلی در زمینه مجوز Aspose.Slides for Java مواجه شدید:

- نسخه‌ای که استفاده می‌کنید را بررسی کنید و اطمینان حاصل کنید که تحت تأثیر اشکال توضیح داده شده بالا نیست.
- برای نحوه اعمال و اعتبارسنجی مجوز، به [مجوز](/slides/fa/java/licensing/) مراجعه کنید.
- برای دریافت کمک بیشتر با [Aspose support](https://forum.aspose.com/c/slides/fa/11) تماس بگیرید.

## **محصولات و نسخه‌های تحت تأثیر**

لطفاً توجه داشته باشید که این اشکال فقط بر نسخه‌های Aspose.Slides for Java 23.2 تا 23.7 تأثیر می‌گذارد. **سایر محصولات Aspose و سایر نسخه‌های Aspose.Slides تحت تأثیر نیستند**.
