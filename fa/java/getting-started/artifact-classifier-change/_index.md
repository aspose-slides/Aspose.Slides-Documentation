## **تغییر طبقه‌بند آرتیفکت از `jdk16` به `jdk8`**

Starting with version **26.10**, we have changed the classifier used in our published artifacts from **`jdk16`** (Java 6) to **`jdk8`** (Java 8).

### **چه تغییر کرد**

| | قبل | بعد |
|---|---|---|
| طبقه‌بند | `jdk16` | `jdk8` |
| حداقل نسخه جاوا | Java 1.6 | Java 8 |

**قبل:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**بعد:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **چرا این تغییر را انجام دادیم**

پس از بررسی داخلی، تصمیم گرفتیم **پشتیبانی از نسخه‌های قدیمی جاوا** را که دیگر ارزش ارائه نمی‌دادند و به‌طور فعال مانع نگهداری می‌شدند، رها کنیم. جاوا 8 به‌عنوان پایه جدید و ایمن برای تمام کاربران انتخاب شد.

به‌عنوان بخشی از این کار، طبقه‌بند به‌روز شد تا نسخه حداقل واقعی پشتیبانی‌شده را نشان دهد. همچنین با استاندارد نام‌گذاری فعلی اوراکل هماهنگ شدیم، جایی که محصول به‌صورت رسمی به‌عنوان **JDK 8** (به‌جای قالب قدیمی `1.8`) شناخته می‌شود.

### **چه کاری باید انجام دهید**

1. **به‌روزرسانی طبقه‌بند** در اعلان‌های وابستگی شما از `jdk16` به `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **تأیید محیط اجرایی شما** نسخه جاوا 8 یا بالاتر باشد.

3. **به‌روزرسانی هر فایل قفل** یا کش‌های وابستگی که طبقه‌بند قدیمی را ثابت می‌کنند.

### **یادداشت مهاجرت: jdk16 و jdk8**

از نسخه 26.10 به بعد، هر دو طبقه‌بند jdk16 و jdk8 JARهای سازگار با جاوا 8 را ارائه می‌دهند (ساخته شده با سازگاری source/target تنظیم‌شده بر روی جاوا 8).

- `jdk16` → انتشار خود را برای سازگاری عقب‌گرد (یکپارچه‌سازی‌های موجود) ادامه می‌دهد.
- `jdk8` → به‌عنوان طبقه‌بند ترجیحی جدید برای محیط‌های جاوا 8 معرفی شد.

⚠️ نکته: این فاز انتشار دوگانه قرار است تا 31 مارس 2027 به پایان برسد. پس از این تاریخ، طبقه‌بند jdk16 منقضی خواهد شد و تنها jdk8 مورد پشتیبانی قرار خواهد گرفت.

### **نکات سازگاری**

- `jdk16` دیگر پس از **31 مارس 2027** **منتشر نمی‌شود**.
- اگر هنوز به پشتیبانی جاوا 1.6 نیاز دارید، لطفاً تا زمان امکان مهاجرت در خط نسخه اصلی قبلی بمانید.

### **نیاز به کمک دارید؟**

اگر در حین مهاجرت با مشکلی مواجه شدید، لطفاً به [پشتیبانی Aspose](https://forum.aspose.com/) مراجعه کنید.
