## **تغییر طبقه‌بند Artifact از `jdk16` به `jdk8`**

از نسخه **26.10** به بعد، طبقه‌بند مورد استفاده در artifacts منتشر شده ما از **`jdk16`** (Java 6) به **`jdk8`** (Java 8) تغییر کرده است.

### **چه چیزی تغییر کرد**

| | قبل | بعد |
|---|---|---|
| طبقه‌بند | `jdk16` | `jdk8` |
| حداقل نسخه Java | Java 1.6 | Java 8 |

**قبل:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**بعد:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### **چرا این تغییر را انجام دادیم**

پس از بررسی داخلی، تصمیم گرفتیم **پشتیبانی از نسخه‌های قدیمی Java** را که دیگر ارزشی نداشتند و به‌طور فعال مانع نگهداری می‌شدند، خاتمه دهیم. Java 8 به‌عنوان پایه امن جدید برای همه مصرف‌کنندگان انتخاب شد.

به عنوان بخشی از این کار، طبقه‌بند برای بازتاب حداقل نسخه پشتیبانی‌شده واقعی به‌روز شد. همچنین با استاندارد نام‌گذاری جاری Oracle هم‌راستا شدیم، جایی که محصول به‌صورت رسمی به عنوان **JDK 8** (به‌جای قالب قدیمی `1.8`) شناخته می‌شود.

### **چه کاری باید انجام دهید**

1. **به‌روزرسانی طبقه‌بند** در اعلان‌های وابستگی خود از `jdk16` به `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **بررسی محیط اجرای خود** Java 8 یا بالاتر باشد.

3. **به‌روزرسانی هر فایل قفل** یا کش‌های وابستگی که طبقه‌بند قدیمی را ثابت کرده‌اند.

### **یادداشت مهاجرت: jdk16 و jdk8**

از نسخه 26.10، هر دو طبقه‌بندهای jdk16 و jdk8 JARهای سازگار با Java 8 را فراهم می‌کنند (ساخته شده با سازگاری source/target بر روی Java 8 تنظیم شده).

- `jdk16` → به انتشار برای سازگاری به‌عقب ادامه می‌دهد (یکپارچگی‌های موجود).
- `jdk8` → به‌عنوان طبقه‌بند ترجیحی جدید برای محیط‌های Java 8 معرفی شد.

⚠️ نکته: این دوره انتشار دوگانه تا 31 مارس 2027 برنامه‌ریزی شده است تا پایان یابد. پس از این تاریخ، طبقه‌بند jdk16 منقبض خواهد شد و فقط jdk8 پشتیبانی می‌شود.

### **نکات سازگاری**

- طبقه‌بند `jdk16` **دیگر منتشر نمی‌شود** پس از **31 مارس 2027**.
- اگر هنوز به پشتیبانی Java 1.6 نیاز دارید، لطفاً تا زمان امکان مهاجرت در خط نسخهٔ اصلی قبلی بمانید.
