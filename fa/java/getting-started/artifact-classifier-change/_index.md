## تغییر طبقه‌بندی Artifact از `jdk16` به `jdk8`

### چه چیزی تغییر کرد

| | قبل | بعد |
|---|---|---|
| طبقه‌بندی | `jdk16` | `jdk8` |
| حداقل نسخه جاوا | Java 1.6 | Java 8 |

**قبل:**  
```
com.aspose:aspose-slides:26.10:jdk16
```

**بعد:**  
```
com.aspose:aspose-slides:26.10:jdk8
```

### دلیل این تغییر

پس از بررسی داخلی، تصمیم گرفتیم **پشتیبانی از نسخه‌های قدیمی جاوا** که دیگر ارزش ارائه نمی‌دادند و فعالانه مانع نگهداری می‌شدند را حذف کنیم. Java 8 به عنوان پایه امن جدید برای همه مصرف‌کنندگان انتخاب شد.

در این راستا، طبقه‌بندی برای انعکاس حداقل نسخه پشتیبانی‌شده واقعی به‌روزرسانی شد. همچنین با نامگذاری فعلی اوراکل هماهنگ شدیم، به‌طوری که محصول به‌صورت رسمی **JDK 8** نامیده می‌شود (به‌جای قالب قدیمی `1.8`). 

### چه کاری باید انجام دهید

1. **طبقه‌بندی را به‌روزرسانی کنید** در اعلان‌های وابستگی خود از `jdk16` به `jdk8`.

   **Maven:**  
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**  
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **اطمینان حاصل کنید که محیط زمان اجرا** شما Java 8 یا بالاتر است.

3. **هر فایل قفل** یا کش‌های وابستگی که طبقه‌بندی قدیمی را ثابت می‌کنند، تازه‌سازی کنید.

### یادداشت مهاجرت: jdk16 و jdk8

از نسخه 26.10​ به‌بعد، هر دو طبقه‌بندی jdk16 و jdk8 JARهای سازگار با Java 8 را فراهم می‌کنند (ساخته‌شده با سازگاری source/target تنظیم‌شده روی Java 8).

- `jdk16` → همچنان برای سازگاری عقب‌گرد (یکپارچگی‌های موجود) منتشر می‌شود.  
- `jdk8` → به‌عنوان طبقه‌بندی مورد ترجیح جدید برای محیط‌های Java 8 معرفی شد.

⚠️ نکته: این فاز انتشار دوگانه قرار است تا 31 مارس 2027 پایان یابد​. پس از این تاریخ، طبقه‌بندی jdk16 منقضی خواهد شد و تنها jdk8 پشتیبانی خواهد شد.

### نکات سازگاری

- طبقه‌بندی `jdk16` **دیگر منتشر نمی‌شود** پس از **31 مارس 2027**.  
- اگر همچنان به پشتیبانی از Java 1.6 نیاز دارید، لطفاً در خط نسخه اصلی قبلی بمانید تا بتوانید مهاجرت کنید.

### نیاز به راهنمایی دارید؟

اگر در طول مهاجرت با مشکلی مواجه شدید، لطفاً برای دریافت کمک بیشتر با [پشتیبانی Aspose](https://forum.aspose.com/) تماس بگیرید.
