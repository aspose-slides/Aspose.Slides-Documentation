{{% alert color="info" %}} 

[مشخصات تجزیه‌گر XML](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) یک زبان توصیف صفحه و قالب سند ثابت است که در اصل توسط مایکروسافت توسعه یافته است. مشابه PDF، XPS برای حفظ صحت سند و ارائه ظاهر دستگاه‑مستقل طراحی شده است. 

{{% /alert %}} 

## **XPS در Aspose.Slides for Java**
هر سند ارائه‌ای که توسط Aspose.Slides for Java بارگذاری شود می‌تواند به فرمت XPS تبدیل شود. Aspose.Slides for Java از موتور چیدمان صفحه با دقت بالا و رندرینگ استفاده می‌کند تا خروجی را در قالب سند XPS با چیدمان ثابت تولید کند.
می‌توانید درباره صادر کردن اسناد ارائه به اسناد XPS از طریق Aspose.Slides for Java در [تبدیل به XPS](https://docs.aspose.com/slides/fa/java/convert-powerpoint-to-xps/) بیشتر بیاموزید.
