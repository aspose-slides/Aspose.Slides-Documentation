این یک صفحه تاریخی است که برای پیوندهای موجود نگه داشته شده است. این صفحه نسخه فعلی Aspose.Slides for Java را توصیف نمی‌کند. برای قالب‌هایی که Aspose.Slides for Java بارگذاری، وارد، ذخیره و رندر می‌کند و API مربوط به هر یک، به [قالب‌های فایل پشتیبانی‌شده](/slides/fa/java/supported-file-formats/) مراجعه کنید. برای راهنمای تبدیل TIFF فعلی، به [تبدیل ارائه‌های پاورپوینت به TIFF](/slides/fa/java/convert-powerpoint-to-tiff/) نگاه کنید.

{{% /alert %}}

## **درباره TIFF**

[فرمت فایل تصویر برچسب‌خورده](https://en.wikipedia.org/wiki/TIFF) که به خاطر ذخیره‌سازی چند تصویر در یک سند شناخته می‌شود، در اصل توسط Aldus ایجاد شد. این فرمت به‌طور گسترده توسط برنامه‌های اسکن، فکس و سایر برنامه‌های دستکاری تصویر پشتیبانی می‌شود.

## **TIFF در Aspose.Slides for Java**

هر سندی که می‌تواند در Aspose.Slides for Java بارگذاری شود، می‌تواند به‌صورت مستقیم توسط Aspose.Slides for Java به سند TIFF تبدیل شود و نیازی به مؤلفهٔ شخص ثالث نیست. علاوه بر این، می‌توانید به‌اختیاری اندازهٔ تصاویر را در سند TIFF حاصل تعریف کنید. می‌توانید اطلاعات دربارهٔ خروجی سندهای ارائه به سندهای TIFF از طریق Aspose.Slides for Java را در [تبدیل ارائه‌های پاورپوینت به TIFF](/slides/fa/java/convert-powerpoint-to-tiff/) بیابید.
