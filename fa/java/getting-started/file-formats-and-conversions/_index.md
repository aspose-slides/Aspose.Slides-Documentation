{{% alert color="info" title="Note" %}}

مقالات این بخش مرورهای قدیمی‌تری از فرمت‌های فایل جداگانه هستند که برای لینک‌های موجود نگه داشته شده‌اند. آنها نسخه فعلی Aspose.Slides for Java را توصیف نمی‌کنند. برای فرمت‌هایی که Aspose.Slides for Java بارگذاری، واردات، ذخیره و رندر می‌کند و API هر یک، به [فرمت‌های فایل پشتیبانی‌شده](/slides/fa/java/supported-file-formats/) مراجعه کنید. برای راهنماهای تبدیل، به [تبدیل ارائه‌ها](/slides/fa/java/convert-presentation/) نگاه کنید.

{{% /alert %}}
