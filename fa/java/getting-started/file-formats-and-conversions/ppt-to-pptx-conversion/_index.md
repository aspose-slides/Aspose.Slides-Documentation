این یک صفحه تاریخی است که برای پیوندهای موجود نگه داشته شده است. این صفحه نسخه فعلی Aspose.Slides for Java را توضیح نمی‌دهد. برای فرمت‌هایی که Aspose.Slides for Java بارگذاری، وارد، ذخیره و رندر می‌کند و API مربوط به هر یک، به [فرمت‌های فایل پشتیبانی‌شده](/slides/fa/java/supported-file-formats/) مراجعه کنید. برای راهنمای تبدیل فعلی، به [تبدیل PPT به PPTX](/slides/fa/java/convert-ppt-to-pptx/) نگاه کنید.

{{% /alert %}}

{{% alert color="info" title="Note" %}}

تبدیل PPT به PPTX از Aspose.Slides for Java پشتیبانی می‌شود. اکثر ویژگی‌های ارائه‌نامه ‑ اسلایدهای اصلی، ساختار و غیره ‑ هنگام تبدیل از یک فرمت به فرمت دیگر حفظ می‌شوند، اما محدودیت‌های کمی وجود دارد.

{{% /alert %}}
## **ویژگی‌های پشتیبانی‌شده در تبدیل**
Aspose.Slides for Java پشتیبانی جزئی برای تبدیل فرمت فایل PPT به PPTX را فراهم می‌کند. پشتیبانی از تبدیل به‌تازگی به Aspose.Slides for Java اضافه شده است، بنابراین محدودیت‌هایی دارد و برای ارائه‌نامه‌های ساده‌ترین بهترین است. مزیت اصلی که Aspose.Slides for Java هنگام تبدیل PPT به PPTX ارائه می‌دهد، سادگی استفاده از API است. برای مشاهده نمونه‌های کد، به [تبدیل PPT به PPTX](/slides/fa/java/convert-ppt-to-pptx/) مراجعه کنید. لیست زیر نشان می‌دهد کدام ویژگی‌ها برای تبدیل PPT به PPTX پشتیبانی می‌شوند.

## **ویژگی‌های پشتیبانی‌شده**
ویژگی‌های زیر برای تبدیل پشتیبانی می‌شوند:

- تبدیل ساختار اسلایدهای اصلی، طرح‌بندی‌ها و اسلایدها.
- تبدیل نمودارها.
- شکل‌های گروهی.
- تبدیل اشکال خودکار شامل مستطیل‌ها و شکل بیضی.
- اشکال با هندسه سفارشی.
- سبک‌های پر کردن با بافت و تصویر برای اشکال خودکار.
- تبدیل متغیرهای جایگزین.
- تبدیل خطوط و پلی‌لاین‌ها.
- فرمت‌های خط و پر.
- سبک‌های پر کردن گرادیان.
- فریم‌های OLE، جداول، فریم‌های ویدئویی و صوتی و غیره.
- خواص انیمیشن و اسلایدشو.
- تبدیل متن در فریم‌های متنی و نگهدارنده‌های متن.
