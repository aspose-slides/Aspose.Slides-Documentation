تبدیل PPT به PPTX در Aspose.Slides for Java پشتیبانی می‌شود. اکثر ویژگی‌های ارائه - اسلایدهای مستر، ساختار و غیره - زمانی که از یک قالب به قالب دیگر تبدیل می‌شوند، حفظ می‌شوند، اما چند محدودیت وجود دارد[چند محدودیت](/slides/fa/java/ppt-to-pptx-conversion/).

{{% /alert %}} 
## **ویژگی‌های پشتیبانی‌شده در تبدیل**
Aspose.Slides for Java پشتیبانی جزئی از تبدیل قالب فایل PPT به PPTX را فراهم می‌کند. پشتیبانی از تبدیل به تازگی به Aspose.Slides for Java اضافه شده است، بنابراین چند محدودیت دارد و برای ارائه‌های ساده بهترین عملکرد را دارد. مزیت اصلی که Aspose.Slides for Java هنگام تبدیل PPT به PPTX ارائه می‌دهد، سادگی استفاده از API است. برای دیدن نمونه‌های کد، درباره [تبدیل PPT به PPTX]() بخوانید. در زیر، فهرست‌هایی توضیح می‌دهند که کدام ویژگی‌ها پشتیبانی می‌شوند و کدام برای تبدیل PPT به PPTX پشتیبانی نمی‌شوند.

## **ویژگی‌های پشتیبانی‌شده**
ویژگی‌های زیر برای تبدیل پشتیبانی می‌شوند:

- تبدیل ساختار مسترها، طرح‌ها و اسلایدها.
- تبدیل نمودارها.
- اشکال گروهی.
- تبدیل اشکال خودکار شامل مستطیل‌ها و بیضی‌ها.
- اشکال با هندسه سفارشی.
- استایل‌های پرکننده بافت و تصویر برای اشکال خودکار.
- تبدیل جای‌نگهدارها.
- تبدیل خطوط و پلی‌لاین‌ها.
- قالب‌های خط و پرکننده.
- استایل‌های پرکننده گرادیان.
- فریم‌های OLE، جدول‌ها، فریم‌های ویدئو و صدا، و غیره.
- ویژگی‌های انیمیشن و اسلایدشو.
- تبدیل متن در فریم‌های متنی و نگهدارنده‌های متن.
