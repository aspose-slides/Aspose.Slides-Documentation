{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) فرمت فایل سند ارائه است که می‌تواند توسط نسخه‌های مختلف Microsoft PowerPoint ایجاد، خوانده، دستکاری و نوشته شود. این فرمت باینری برای اسناد ارائه است که توسط مایکروسافت توسعه یافته است.

{{% /alert %}} 

## **PPT در Aspose.Slides for Java**
Aspose.Slides for Java می‌تواند فایل‌های PPT ایجاد شده توسط نرم‌افزارهای زیر را بخواند.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

به‌طور مشابه، فایل‌های PPT ایجاد شده توسط Aspose.Slides for Java می‌توانند توسط مجموعه نرم‌افزارهای فوق خوانده شوند.

## **پشتیبانی جامع برای PPT**
Aspose.Slides for Java پشتیبانی تقریباً تمام ویژگی‌های فرمت فایل سند PPT را فراهم می‌کند. این کتابخانه نه تنها ویژگی‌های پایه و پیشرفته‌ای را که توسط نسخه‌های مختلف Microsoft PowerPoint برای دستکاری اسناد PPT ارائه می‌شود پوشش می‌دهد، بلکه ویژگی‌هایی را نیز شامل می‌شود که حتی توسط Microsoft PowerPoint پشتیبانی نمی‌شوند. مزیت اصلی استفاده از کتابخانه API Aspose.Slides for Java سهولت استفاده برای اداره چنین ویژگی‌هایی است.

علاوه بر وظایف پایه مربوط به ایجاد، خواندن و نوشتن فایل‌های سند PPT، چندین ویژگی دیگر توسط Aspose.Slides for Java ارائه می‌شود:

- وارد کردن سایر فرمت‌های فایل Microsoft Office به عنوان [اِشیاءهای OLE در اسناد PPT]().
- [صادر کردن اسناد PPT به PDF](/slides/fa/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- صادر کردن اسلایدها در اسناد PPT به فرمت‌های SVG.
- رندر کردن اسلایدها به هر فرمت تصویری که توسط چارچوب Java پشتیبانی می‌شود.
- تنظیم اندازه اسلایدها در اسناد PPT.
- مدیریت انیمیشن‌ها روی اشکال.
- مدیریت نمایش اسلایدها.
- [قالب‌بندی متن روی اسلایدها]().
- استخراج متن از اسناد PPT.
- [مدیریت جداول روی اسلایدها]().
- به‌صورت خودکار کپی مسترها با استفاده از [قابلیت کلونینگ]()
