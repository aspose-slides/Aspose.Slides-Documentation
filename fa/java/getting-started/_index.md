## **نمای کلی**

در چهار مرحله‌ی زیر به ترتیب پیش بروید. هر مرحله کاری را که باید انجام شود نام می‌برد و مقاله‌ای با جزئیات مرتبط می‌کند. ارزیابی، لایسنس و پشتیبانی پس از مراحل پوشش داده می‌شوند.

## **مرحله ۱: بررسی نیازمندی‌های سیستم**

Aspose.Slides for Java یک فایل JAR تک است که کد بومی ندارد، بنابراین بر روی هر سیستم‌عاملی که یک runtime جاوا پشتیبانی‌شده داشته باشد اجرا می‌شود. [System Requirements](/slides/fa/java/system-requirements/) سیستم‌عامل‌ها و نسخه‌های جاوا پشتیبانی‌شده را فهرست می‌کند. پروژه و دستورات در مراحل بعدی به JDK 11 یا بالاتر نیاز دارند و برای مسیر Maven، [Apache Maven](https://maven.apache.org/install.html) مورد نیاز است.

## **مرحله ۲: افزودن کتابخانه به پروژه‌تان**

Aspose.Slides for Java در مخزن Maven خود Aspose منتشر می‌شود، نه در Maven Central. یکی از این مسیرها را انتخاب کنید:

- With Maven: در *pom.xml* خود مخزن `https://releases.aspose.com/java/repo/` را اعلام کنید و وابستگی `com.aspose:aspose-slides` را با کلاس‌دسته `jdk16` اضافه کنید.
- Without Maven: فایل JAR که نام آن با *-jdk16.jar* پایان می‌یابد را از مخزن دانلود کنید و در مسیر کلاس قرار دهید.

در لینوکس، کتابخانه fontconfig و حداقل یک فونت را نیز نصب کنید. بدون اینها، ذخیره‌سازی یک ارائه با خطای «Fontconfig head is null, check your fonts or fonts configuration» شکست می‌خورد.

[Installation](/slides/fa/java/installation/) ورودی‌های *pom.xml*، دانلود JAR و دستور لینوکس را ارائه می‌دهد.

## **مرحله ۳: ایجاد اولین ارائه شما**

[quick start on the Aspose.Slides for Java home page](/slides/fa/java/#your-first-presentation) یک پروژه کامل Maven است: یک فایل *pom.xml* و برنامه‌ای که یک شکل ابر با متن به یک اسلاید اضافه می‌کند و ارائه را به صورت فایل PPTX ذخیره می‌سازد. شما آن را با `mvn compile exec:java` اجرا می‌کنید. [Create Presentations](/slides/fa/java/create-presentation/) همان برنامه را گام به گام توضیح می‌دهد. برای باز کردن یک ارائه‌ی موجود و ذخیره آن در قالب دیگری، به [Open Presentations](/slides/fa/java/open-presentation/) و [Save Presentations](/slides/fa/java/save-presentation/) مراجعه کنید.

## **ارزیابی و لایسنس**

بدون لایسنس، Aspose.Slides در حالت ارزیابی اجرا می‌شود: به هر اسلایدی که ذخیره می‌کند یک واترمارک اضافه می‌کند و متنی که کد شما از ارائه‌ها می‌خواند را کوتاه می‌کند.

- [ارزیابی Aspose.Slides](/slides/fa/java/evaluate-aspose-slides/) محدودیت‌های ارزیابی و نحوه درخواست لایسنس موقت را توصیف می‌کند.
- [مجوزدهی](/slides/fa/java/licensing/) نحوه اعمال لایسنس از یک فایل یا جریان را نشان می‌دهد.
- [مجوزدهی متری](/slides/fa/java/metered-licensing/) مجوزدهی مبتنی بر مصرف را پوشش می‌دهد.
- [فرمت‌های فایل پشتیبانی‌شده](/slides/fa/java/supported-file-formats/) فرمت‌هایی که Aspose.Slides می‌تواند بارگذاری و ذخیره کند را فهرست می‌کند.

## **سوالات متداول**

**آیا نیاز به نصب Microsoft PowerPoint دارم؟**

خیر. Aspose.Slides خود فایل‌های ارائه را می‌خواند و می‌نویسد و از PowerPoint استفاده نمی‌کند، بنابراین بر روی سرورها و لینوکس نیز اجرا می‌شود.

**چرا Maven کتابخانه Aspose.Slides for Java را پیدا نمی‌کند؟**

این کتابخانه در Maven Central نیست. مخزن Aspose را در *pom.xml* خود اعلام کنید، همان‌طور که در [Installation](/slides/fa/java/installation/) نشان داده شده است، و Maven کتابخانه را از آنجا دانلود می‌کند.

**آیا کلاس‌دسته `jdk16` به این معنی است که کتابخانه به Java 16 نیاز دارد؟**

خیر. این کلاس‌دسته ساخت Java SE کتابخانه را انتخاب می‌کند؛ ساخت دیگر برای Android است. همان ساخت بر روی JDKهای فعلی، مانند JDK 21، اجرا می‌شود.
