## **بررسی کلی**

این مقاله توضیح می‌دهد که توسعه‌دهندگان چه زمانی ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. این مقاله Open XML SDK را به عنوان یک کتابخانه برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن توصیف می‌کند، در حالی که Aspose.Slides به عنوان یک کتابخانه پردازش ارائه با مدل شیء سطح بالا و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، رندرینگ، پشتیبانی از پلتفرم‌ها و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیده ارائه مانند کار با چندین فرمت PowerPoint، کپی یا کلون کردن اشکال، جایگزینی متن، اعمال انیمیشن‌ها و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
بر اساس [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به صورت زیر تعریف می‌شود: 

Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر schema زیرین آن‌ها را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای عمومی که توسعه‌دهندگان روی بسته‌های Open XML انجام می‌دهند را در بر می‌گیرد، به طوری که می‌توانید عملیات پیچیده را تنها با چند خط کد انجام دهید.

اسناد OOXML در واقع فایل‌های XML فشرده هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما امکان می‌دهد محتویات اسناد OOXML را به صورت strongly‑typed مدیریت کنید. به این معنی که به جای باز کردن یک فایل برای استخراج XML، بارگذاری آن XML در یک درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی را فراهم می‌کند که این کار را برای شما انجام می‌دهند.

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانهٔ کلاس است که به برنامهٔ شما اجازه می‌دهد کارهای زیر را روی ارائه‌ها انجام دهد:

- برنامه‌نویسی با مدل شیء **Presentation**.
- تبدیل با کیفیت بالا بین تمام فرمت‌های محبوب پشتیبانی‌شدهٔ ارائه PowerPoint، از جمله تبدیل به PDF، XPS و TIFF.
- قابلیت تولید تصویر کوچک اسلاید در فرمت‌های شناخته‌شده مانند PNG، JPEG و BMP به همراه خروجی اسلاید به SVG.
- قابلیت ساخت ارائه‌ها از ابتدا یا ترکیب آن‌ها از یک یا چند سند.
- پشتیبانی از افزودن انیمیشن‌ها، فریم‌های OLE، جدول‌ها، ایجاد و مدیریت نمودارها.
- دسترسی به کنترل گسترده برای مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر درباره ویژگی‌های پشتیبانی‌شده، لطفاً به [ویژگی‌های Aspose.Slides](/slides/fa/java/product-overview/) مراجعه کنید.

## **نتیجه‌گیری**
{{% alert color="info" %}} 

Open XML SDK و Aspose.Slides رقیب مستقیم نیستند چون نیازها و مخاطبان کاملاً متفاوتی دارند. Open XML SDK یک کتابخانهٔ کلاس است که روشی strongly‑typed برای کار با اسناد OOXML فراهم می‌کند. Aspose.Slides یک کتابخانهٔ پردازش ارائه بسیار مفید است که پشتیبانی بسیار خوبی برای تقریباً تمام فرمت‌های فایل Microsoft PowerPoint ارائه می‌دهد.

اگر تنها به یک عملیات برنامه‌نویسی ساده روی سند PPTX نیاز دارید، Open XML SDK می‌تواند گزینهٔ مناسبی باشد. با Open XML SDK می‌توانید به راحتی کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرصفحه/پاصفحه، استخراج تصاویر یا موارد مشابه را انجام دهید. برخی کارها با Open XML SDK قابل انجام هستند اما با Aspose.Slides امکان‌پذیر نیستند. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML داشته باشید، باید از Open XML SDK استفاده کنید. اما اگر نیاز به انجام عملیات پیچیده روی اسناد دارید، مانند برخی از کارهای زیر، استفاده از Aspose.Slides بهترین گزینه است:

- پشتیبانی از فرمت‌های PowerPoint قدیمی علاوه بر PPTX.
- کپی یا کلون کردن اشکال در اسلایدها به‌گونه‌ای که اشیاء، سبک‌ها و سایر قالب‌بندی‌ها به‌صورت مناسب ترکیب شوند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از کانکتورها با اشکال.
- تبدیل سند به PDF، TIFF یا XPS به‌طوری که دقیقاً همانند تبدیل توسط Microsoft PowerPoint باشد.
- توسعهٔ برنامهٔ .NET یا Java در محیط‌های دسکتاپ و وب.
