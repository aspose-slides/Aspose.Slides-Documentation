## **بررسی کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. این مقاله Open XML SDK را به عنوان کتابخانه‌ای برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن معرفی می‌کند، در حالی که Aspose.Slides به‌عنوان کتابخانه پردازش ارائه با مدل شیء سطح بالا و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint ارائه شده است.

مقاله هر دو گزینه را بر اساس قالب‌های پشتیبانی‌شده، مدل برنامه‌نویسی، قابلیت‌های رندرینگ و چاپ، پشتیبانی پلتفرم و موارد استفاده معمول مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیده‌تر ارائه مانند کار با چندین فرمت PowerPoint، کپی یا کلون‌کردن اشکال، جایگزینی متن، اعمال انیمیشن و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
بر اساس [کتابخانه MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK به‌صورت زیر تعریف می‌شود:

Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر اسکیماهای زیرین یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای رایجی را که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند، در خود محصور می‌کند، به‌طوری که می‌توانید عملیات پیچیده را تنها با چند خط کد انجام دهید.

اسناد OOXML در واقع فایل‌های فشرده XML هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما اجازه می‌دهد محتویات اسناد OOXML را به‌صورت قوی‌تایپی کار کنید. به عبارت دیگر، به‌جای استخراج فایل، بارگذاری XML در یک درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی فراهم می‌کند که این کار را برای شما انجام می‌دهند.

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانه کلاس‌ است که به برنامه شما امکان انجام وظایف زیر پردازش ارائه را می‌دهد:

- برنامه‌نویسی با مدل شیء **Presentation**.
- تبدیل با کیفیت بالا بین تمام فرمت‌های محبوب پشتیبانی‌شده PowerPoint، از جمله تبدیل به PDF، XPS و TIFF.
- قابلیت تولید تصویر کوچک اسلایدها در فرمت‌های شناخته‌شده مانند PNG، JPEG و BMP به همراه خروجی اسلاید به SVG.
- قابلیت ساخت ارائه از صفر یا ترکیب از یک یا چند سند.
- پشتیبانی از افزودن انیمیشن‌ها، فریم‌های Ole، جدول‌ها، ایجاد و مدیریت نمودارها.
- امکان کنترل گسترده برای مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر درباره ویژگی‌های پشتیبانی‌شده، لطفاً به [ویژگی‌های Aspose.Slides](/slides/fa/java/product-overview/) مراجعه کنید.

## **نتیجه‌گیری**
{{% alert color="info" %}} 

Open XML SDK و Aspose.Slides رقیب مستقیم یکدیگر نیستند زیرا نیازها و مخاطبان متفاوتی را هدف قرار می‌دهند. Open XML SDK یک کتابخانه کلاس‌ است که راهی قوی‌تایپی برای کار با اسناد OOXML فراهم می‌کند. Aspose.Slides یک کتابخانه پردازش ارائه بسیار مفید است که پشتیبانی عالی از تقریباً تمام فرمت‌های فایل Microsoft PowerPoint را ارائه می‌دهد.

اگر تنها نیاز شما انجام یک عملیات برنامه‌نویسی نسبتاً پایه‌ای بر روی سند PPTX است، Open XML SDK ممکن است گزینه مناسبی باشد. با Open XML SDK می‌توانید کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرصفحه/پاصفحه، استخراج تصاویر و غیره را به‌راحتی انجام دهید. برخی وظایف با Open XML SDK قابل انجام است، اما با Aspose.Slides نیست. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML دارید، باید از Open XML SDK استفاده کنید. اما اگر نیاز به انجام عملیات پیچیده بر روی اسناد دارید، مانند برخی از وظایف زیر، استفاده از Aspose.Slides بهترین گزینه برای شماست:

- پشتیبانی از فرمت‌های PowerPoint قدیمی علاوه بر PPTX.
- کپی یا کلون‌کردن اشکال در اسلایدها به طریقی که اشیاء، سبک‌ها و قالب‌بندی‌های دیگر را به‌صورت مناسب ترکیب کند.
- جایگزین کردن متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از کانکتورها با اشکال استفاده شده.
- تبدیل یک سند به PDF، TIFF یا XPS به‌گونه‌ای که دقیقاً همانند تبدیل توسط Microsoft PowerPoint باشد.
- توسعه یک برنامه .NET یا Java در محیط‌های دسکتاپ و وب.
