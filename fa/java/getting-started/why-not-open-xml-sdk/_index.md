## **نمای کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است برای کار با اسناد ارائه، Open XML SDK یا Aspose.Slides را انتخاب کنند. Open XML SDK به عنوان کتابخانه‌ای برای دست‌کاری بسته‌های OOXML و عناصر XML زیرین آنها توصیف می‌شود، در حالی که Aspose.Slides به عنوان کتابخانه‌ای پردازش ارائه با مدل شیء سطح بالا و پشتیبانی از بسیاری از کارهای مرتبط با PowerPoint معرفی شده است.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، رندرینگ، پشتیبانی از پلتفرم‌ها و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیده‌تر ارائه مانند کار با فرمت‌های متعدد PowerPoint، کپی یا کلون‌کردن اشکال، جایگزینی متن، اعمال انیمیشن‌ها و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
بر اساس [کتابخانه MSDN](https://learn.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به صورت زیر تعریف می‌شود:

Open XML SDK 2.0 کار دست‌کاری بسته‌های Open XML و عناصر طرح‌نامهٔ Open XML زیرین یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از وظایف رایجی که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند را دربر می‌گیرد، به‌طوری که بتوانید عملیات پیچیده را تنها با چند خط کد انجام دهید.

اسناد OOXML در واقع فایل‌های XML فشرده‌شده هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما امکان کار با محتوای اسناد OOXML به‌صورت strongly‑typed را می‌دهد. به‌جای استخراج فایل برای دریافت XML، بارگذاری آن XML در یک درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی فراهم می‌کند که این کار را انجام می‌دهند.

## **Aspose.Slides چیست؟**
Aspose.Slides کتابخانه‌ای کلاس‑محور است که به برنامه شما امکان انجام وظایف زیر پردازش ارائه را می‌دهد:

- برنامه‌نویسی با مدل شیء **Presentation**.
- تبدیل با کیفیت بالا بین تمام فرمت‌های محبوب پشتیبانی‌شدهٔ PowerPoint، از جمله تبدیل به PDF، XPS و TIFF.
- قابلیت تولید تصاویر بندانگشتی اسلاید در فرمت‌های شناخته‌شده مانند PNG, JPEG و BMP همراه با خروجی اسلاید به SVG.
- قابلیت ساخت ارائه‌ها از صفر یا ترکیب از یک یا چند سند.
- پشتیبانی از افزودن انیمیشن‌ها، Ole Frames، جدول‌ها، ایجاد و مدیریت نمودارها.
- دسترسی گسترده برای مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر درباره ویژگی‌های پشتیبانی‌شده، لطفاً به [ویژگی‌های Aspose.Slides](/slides/fa/java/product-overview/) مراجعه کنید.

## **نتیجه‌گیری**
{{% alert color="info" title="Note" %}}
Open XML SDK و Aspose.Slides رقابت سرسختی ندارند زیرا نیازها و مخاطبان بسیار متفاوتی را هدف قرار می‌دهند. Open XML SDK کتابخانه‌ای کلاس‑محور است که راهی strongly‑typed برای کار با اسناد OOXML فراهم می‌کند. Aspose.Slides کتابخانه‌ای بسیار مفید برای پردازش ارائه‌هاست که پشتیبانی عالی از تقریباً تمام فرمت‌های فایل Microsoft PowerPoint را ارائه می‌دهد.

اگر فقط نیاز به انجام یک عملیات برنامه‌نویسی نسبتاً پایه‌ای بر روی سند PPTX دارید، Open XML SDK می‌تواند گزینهٔ مناسبی باشد. با Open XML SDK می‌توانید به‌راحتی کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرصفحه/پاصفحه، استخراج تصاویر یا موارد مشابه را انجام دهید. برخی وظایف می‌توانند با Open XML SDK انجام شوند ولی با Aspose.Slides قابل انجام نیستند. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML داشته باشید، باید از Open XML SDK استفاده کنید. اما اگر نیاز به انجام عملیات پیچیده بر روی اسناد داشته باشید، مانند برخی از وظایف زیر، استفاده از Aspose.Slides بهترین گزینهٔ شماست:

- پشتیبانی از فرمت‌های قدیمی PowerPoint علاوه بر PPTX.
- کپی یا کلون کردن اشکال در اسلایدها به‌گونه‌ای که اشیاء، سبک‌ها و سایر قالب‌بندی‌ها به‌صورت مناسب ترکیب شوند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از connectorها با اشکال.
- تبدیل سند به PDF، TIFF یا XPS به‌طوری که دقیقاً همان‌طور که PowerPoint مایکروسافت آن را تبدیل می‌کرد نمایش داده شود.
- توسعه یک برنامه .NET یا Java در محیط‌های دسکتاپ و وب.
