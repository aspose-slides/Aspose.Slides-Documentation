{{% alert color="info" %}}

Aspose.Slides for C++ یک کتابخانهٔ کلاس است که به برنامه‌های C++ امکان خواندن و نوشتن اسناد ارائه را بدون استفاده از Microsoft PowerPoint® یا دیگر برنامه‌ها می‌دهد. Aspose.Slides for C++ اجازه می‌دهد متن، اشکال، جدول‌ها و انیمیشن‌ها را مدیریت کنید، صدا و ویدیو به اسلایدها اضافه کنید، پیش‌نمایش اسلایدها را ببینید، اسلایدها را به فرمت‌های SVG، PDF و موارد دیگر صادر کنید.

آخرین مرجع API را می‌توانید در [مرجع API Aspose.Slides for C++](https://reference.aspose.com/slides/fa/cpp/) بیابید.
