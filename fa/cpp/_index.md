**به Aspose.Slides for C++ خوش آمدید**

Aspose.Slides for C++ یک API مدیریت Microsoft PowerPoint® است که به برنامه‌های C++ امکان خواندن و نوشتن اسناد PowerPoint® را بدون استفاده از Microsoft PowerPoint® می‌دهد. Aspose.Slides for C++ اولین و تنها مؤلفه‌ای است که قابلیت مدیریت اسناد PowerPoint® را فراهم می‌کند. Aspose.Slides for C++ ویژگی‌های کلیدی بسیاری ارائه می‌دهد از جمله مدیریت متن، اشکال، جداول و انیمیشن‌ها، افزودن صدا و ویدئو به اسلایدها، پیش‌نمایش اسلایدها، صادر کردن اسلایدها به فرمت SVG، PDF و موارد دیگر.
