## **مقدمه**

Aspose.Slides ابزارهای کاملی را برای تنظیم اندازه اسلاید و نسبت عرض به ارتفاع در ارائه‌های PowerPoint فراهم می‌کند، که برای چاپ و نمایش روی صفحه نمایش اهمیت دارد.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت عرض به ارتفاع 4:3)**: برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی ایده‌آل است.
- **عریض (نسبت عرض به ارتفاع 16:9)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

برای اطمینان از ثبات در کل ارائه، یک اندازه اسلاید و نسبت عرض به ارتفاع برای تمام اسلایدها اعمال می‌شود. برای دریافت نتایج بهینه، ابعاد اسلاید خود را در ابتدای فرآیند ساخت ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" %}} 
به طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت عرض به ارتفاع استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این نمونه کد نشان می‌دهد چگونه با استفاده از Aspose.Slides در C++ اندازه اسلاید یک ارائه را تغییر دهید:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **مشخص کردن اندازه‌های اسلاید سفارشی در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (4:3 و 16:9) برای کار شما مناسب نیستند، می‌توانید تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. برای مثال، اگر قصد چاپ اسلایدهای تمام‌اندازه از ارائه خود بر روی یک صفحه‌بندی سفارشی یا نمایش ارائه بر روی انواع خاصی از صفحه‌نمایش‌ها را دارید، استفاده از تنظیمات اندازه سفارشی می‌تواند برای شما مفید باشد.

این نمونه کد نشان می‌دهد چگونه با استفاده از Aspose.Slides برای C++ یک اندازه اسلاید سفارشی برای یک ارائه در C++ مشخص کنید:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// اندازه کاغذ A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتوای اسلایدها (مانند تصاویر یا اشیاء) ممکن است مخدوش شود. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای تناسب با اندازه جدید اسلاید تغییر اندازه می‌یابد. با این حال، هنگام تغییر اندازه اسلاید یک ارائه، می‌توانید تنظیمی را مشخص کنید که تصمیم می‌گیرد Aspose.Slides چگونه با محتواهای موجود در اسلایدها رفتار کند.

بسته به آنچه می‌خواهید انجام دهید یا به دست آورید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کاهش دهد تا همه آن‌ها در اسلایدها جای بگیرند (به این ترتیب از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این نمونه کد نشان می‌دهد چگونه از تنظیم `Maximize` هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **پرسش‌های متداول**

### آیا می‌توانم اندازه اسلاید سفارشی را با استفاده از واحدهای دیگری به جز اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند، جایی که 1 پوینت برابر 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به پوینت تبدیل کرده و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

### آیا اندازه اسلاید سفارشی بسیار بزرگ می‌تواند بر عملکرد و مصرف حافظه در هنگام رندرینگ تأثیر بگذارد؟

بله. ابعاد بزرگ‌تر اسلاید (به پوینت) همراه با مقیاس رندرینگ بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورتی که برای دستیابی به کیفیت خروجی موردنظر لازم باشد، تنظیم کنید.

### آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدهای ارائه‌هایی با اندازه‌های متفاوت را ادغام کنم؟

نمی‌توانید [ادغام ارائه‌ها](/slides/fa/cpp/merge-presentation/) را زمانی که اندازه‌های اسلاید متفاوت دارند انجام دهید — ابتدا یک ارائه را برای مطابقت با دیگری تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید با استفاده از گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/cpp/aspose.slides/slidesizescaletype/) تعیین کنید محتوای موجود چگونه مدیریت شود. پس از هم‌تراز کردن اندازه‌ها، می‌توانید اسلایدها را ادغام کنید و قالب‌بندی را حفظ کنید.

### آیا می‌توانم تصویرهای کوچک (thumbnail) برای اشکال منفرد یا مناطق خاصی از یک اسلاید تولید کنم و آیا این تصویرها نسبت به اندازه جدید اسلاید احترام می‌گذارند؟

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [تمام اسلایدها](https://reference.aspose.com/slides/fa/cpp/aspose.slides/slide/getimage/) و همچنین برای [اشکال انتخابی](https://reference.aspose.com/slides/fa/cpp/aspose.slides/shape/getimage/) ایجاد کند. تصاویر حاصل، اندازه و نسبت عرض به ارتفاع فعلی اسلاید را منعکس می‌کنند و چارچوب‌بندی و هندسهٔ ثابت را تضمین می‌نمایند.
