## **مقدمه**

Aspose.Slides ابزارهای جامعی برای تنظیم اندازه اسلاید و نسبت تصویر در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه نمایش اهمیت دارد.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت تصویر ۴:۳)**: مناسب برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **پهن‌صفحه (نسبت تصویر ۱۶:۹)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

سازگاری در کل ارائه خود را تضمین کنید زیرا یک اندازه اسلاید و نسبت تصویر برای همه اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید خود را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" %}} 
به‌صورت پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت تصویر استاندارد ۴:۳ استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و جزوه ابعاد جداگانه‌ای نسبت به اسلایدهای عادی دارند. برای تغییر اندازه و جهت آن‌ها می‌توانید به [اندازه صفحه یادداشت](/slides/fa/cpp/notes-size/) مراجعه کنید.

## **تغییر اندازه اسلاید در ارائه‌ها**

این مثال کد نشان می‌دهد که چگونه می‌توانید اندازه اسلاید را در یک ارائه با استفاده از Aspose.Slides در C++ تغییر دهید:
``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **مشخص کردن اندازه‌های سفارشی اسلاید در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (۴:۳ و ۱۶:۹) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. به عنوان مثال، اگر قصد دارید اسلایدهای تمام‌اندازه را از ارائه خود روی یک صفحه‌بندی سفارشی چاپ کنید یا اگر می‌خواهید ارائه خود را بر روی برخی انواع صفحه‌نمایش‌ها نمایش دهید، احتمالاً استفاده از تنظیم اندازه سفارشی برای ارائه‌تان مفید خواهد بود.

این مثال کد نشان می‌دهد که چگونه می‌توانید از Aspose.Slides برای C++ برای تعیین یک اندازه اسلاید سفارشی برای یک ارائه در C++ استفاده کنید:
``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// اندازه کاغذ A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیا) ممکن است مخدوش شوند. به‌طور پیش‌فرض، اشیا به‌صورت خودکار برای مطابقت با اندازه جدید اسلاید تغییر اندازه می‌یابند. اما هنگام تغییر اندازه اسلاید ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتواهای موجود در اسلایدها رفتار می‌کند.

بسته به این‌که چه کاری می‌خواهید انجام دهید یا چه هدفی دارید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیا در اسلایدها تغییر اندازه یابند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به یک اندازه اسلاید کوچکتر مقیاس‌دهی کنید و نیاز دارید Aspose.Slides اشیای اسلایدها را به‌طوری کاهش دهد که همه آنها در اسلایدها جا بگیرند (به این ترتیب، از از دست رفتن محتوا جلوگیری می‌کنید)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به یک اندازه اسلاید بزرگتر مقیاس‌دهی کنید و نیاز دارید Aspose.Slides اشیای اسلایدها را بزرگ کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این مثال کد نشان می‌دهد که چگونه می‌توانید از تنظیم `Maximize` هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:
``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **سؤالات متداول**

### آیا می‌توانم اندازه اسلاید سفارشی را با واحدهای دیگر به جز اینچ (مثلاً نقطه یا میلی‌متر) تنظیم کنم؟

بله. Aspose.Slides به‌صورت داخلی از نقطه‌ها استفاده می‌کند، به‌طوری که 1 نقطه برابر است با 1/72 اینچ. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقطه تبدیل کنید و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

### آیا اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه هنگام رندرینگ تأثیر می‌گذارد؟

بله. ابعاد بزرگ‌تر اسلاید (به نقطه) همراه با مقیاس رندرینگ بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

### آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟

نمی‌توانید [ادغام ارائه‌ها](/slides/fa/cpp/merge-presentation/) را در حالی انجام دهید که اندازه اسلایدهای آن‌ها متفاوت باشد — ابتدا یک ارائه را برای مطابقت با دیگری تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید از گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/cpp/aspose.slides/slidesizescaletype/) برای تعیین نحوهٔ برخورد با محتویات موجود استفاده کنید. پس از هماهنگ‌سازی اندازه‌ها، می‌توانید اسلایدها را ادغام کنید و قالب‌بندی را حفظ نمایید.

### آیا می‌توانم برای اشکال منفرد یا نواحی خاص یک اسلید، تصاویر بندانگشتی تولید کنم و آیا این تصاویر اندازه جدید اسلید را رعایت می‌کنند؟

بله. Aspose.Slides می‌تواند تصاویر بندانگشتی برای [کل اسلایدها](https://reference.aspose.com/slides/fa/cpp/aspose.slides/slide/getimage/) و همچنین برای [اشکال انتخابی](https://reference.aspose.com/slides/fa/cpp/aspose.slides/shape/getimage/) رندر کند. تصاویر حاصل اندازه و نسبت تصویر فعلی اسلاید را منعکس می‌کند و چارچوب و هندسهٔ یکنواختی را تضمین می‌نماید.
