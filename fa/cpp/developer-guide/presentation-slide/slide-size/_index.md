## **مقدمه**

Aspose.Slides ابزارهای جامعی برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه مهم است.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت ابعاد ۴:۳)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **عرض‌صفحه (نسبت ابعاد ۱۶:۹)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

سازگاری را در تمام ارائه خود حفظ کنید زیرا یک اندازه اسلاید و نسبت ابعاد برای تمام اسلایدها اعمال می‌شود. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت ابعاد استاندارد ۴:۳ استفاده می‌کنند.
{{% /alert %}}

## **تغییر اندازه اسلاید در ارائه‌ها**

این نمونه کد نشان می‌دهد چگونه اندازه اسلاید را در یک ارائه با استفاده از Aspose.Slides در C++ تغییر دهید:

``` cpp
auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **مشخص کردن اندازه اسلایدهای سفارشی در ارائه‌ها**

اگر اندازه‌های رایج اسلاید (۴:۳ و ۱۶:۹) برای کار شما مناسب نیستند، ممکن است تصمیم بگیرید از یک اندازه اسلاید خاص یا منحصر به فرد استفاده کنید. به عنوان مثال، اگر قصد دارید اسلایدهای کامل‌اندازه را از ارائه خود روی یک قالب صفحه سفارشی چاپ کنید یا اگر می‌خواهید ارائه خود را بر روی انواع خاصی از صفحه‌نمایش‌ها نمایش دهید، احتمالاً از تنظیمات اندازه سفارشی برای ارائه خود بهره‌مند خواهید شد.

این نمونه کد نشان می‌دهد چگونه از Aspose.Slides برای C++ برای تعیین یک اندازه اسلاید سفارشی برای یک ارائه در C++ استفاده کنید:

``` cpp
auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// اندازه کاغذ A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه اسلاید برای یک ارائه، محتویات اسلایدها (مانند تصاویر یا اشیاء) ممکن است دچار اعوجاج شوند. به‌طور پیش‌فرض، اشیاء به‌صورت خودکار برای تطبیق با اندازه جدید اسلاید تغییر اندازه می‌یابند. اما هنگام تغییر اندازه اسلاید یک ارائه، می‌توانید تنظیمی را مشخص کنید که تعیین می‌کند Aspose.Slides چگونه با محتویات اسلایدها برخورد می‌کند.

بسته به این‌که چه کاری می‌خواهید انجام دهید یا به چه هدفی می‌رسید، می‌توانید از هر یک از این تنظیمات استفاده کنید:

- `DoNotScale`

  اگر نمی‌خواهید اشیاء روی اسلایدها تغییر اندازه دهند، از این تنظیم استفاده کنید.

- `EnsureFit`

  اگر می‌خواهید به اندازه اسلاید کوچکتر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را کوچک کند تا همه آنها در اسلایدها جا بگیرند (به این ترتیب از دست رفتن محتوا جلوگیری می‌شود)، از این تنظیم استفاده کنید.

- `Maximize`

  اگر می‌خواهید به اندازه اسلاید بزرگ‌تر مقیاس کنید و نیاز دارید Aspose.Slides اشیاء اسلایدها را بزرگ‌نمایی کند تا نسبت به اندازه جدید اسلاید متناسب شوند، از این تنظیم استفاده کنید.

این نمونه کد نشان می‌دهد چگونه از تنظیم `Maximize` هنگام تغییر اندازه اسلاید یک ارائه استفاده کنید:

``` cpp
auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **سؤال‌های متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با استفاده از واحدهایی غیر از اینچ (مثلاً پوینت یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از پوینت استفاده می‌کند، به‌طوری که ۱ پوینت برابر با ۱/۷۲ اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به پوینت تبدیل کنید و از مقادیر تبدیل‌شده برای تعیین عرض و ارتفاع اسلاید استفاده کنید.

**آیا اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه هنگام رندرینگ تأثیر می‌گذارد؟**

بله. ابعاد بزرگ‌تر اسلاید (به پوینت) همراه با مقیاس رندرینگ بالاتر منجر به افزایش مصرف حافظه و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای رسیدن به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟**

شما نمی‌توانید [merge presentations](/slides/fa/cpp/merge-presentation/) را زمانی که اندازه‌های اسلاید متفاوت دارند انجام دهید — ابتدا یک ارائه را به اندازه دیگری تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید با استفاده از گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/cpp/aspose.slides/slidesizescaletype/) تعیین کنید محتویات موجود چگونه مدیریت شوند. پس از هم‌ترازی اندازه‌ها، می‌توانید اسلایدها را ترکیب کنید در حالی که قالب‌بندی حفظ می‌شود.

**آیا می‌توانم برای هر شکل جداگانه یا نواحی خاصی از یک اسلاید تصویر بند انگشتی تولید کنم و آیا آن‌ها اندازه جدید اسلاید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصاویر بند انگشتی برای [entire slides](https://reference.aspose.com/slides/fa/cpp/aspose.slides/slide/getimage/) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/cpp/aspose.slides/shape/getimage/) تولید کند. تصاویر حاصل اندازه و نسبت ابعاد فعلی اسلاید را منعکس می‌کنند و چارچوب و هندسهٔ یکسانی را تضمین می‌نمایند.
