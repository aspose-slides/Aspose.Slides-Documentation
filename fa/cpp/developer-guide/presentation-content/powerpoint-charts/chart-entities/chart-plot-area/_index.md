## **مرور کلی**

این مقاله نشان می‌دهد که چگونه با ناحیهٔ نمودار (Plot Area) در Aspose.Slides کار کنید. توضیح می‌دهد چگونه موقعیت و اندازهٔ واقعی ناحیهٔ نمودار را با اعتبارسنجی طرح نمودار و سپس خواندن مقادیر X، Y، عرض و ارتفاع آن به دست آورید.

همچنین نحوه پیکربندی حالت طرح ناحیهٔ نمودار را زمانی که طرح به‌صورت دستی تنظیم شده است، نشان می‌دهد؛ با استفاده از `LayoutTargetType` برای تعریف اینکه ناحیهٔ نمودار بر اساس ناحیهٔ داخلی یا ناحیهٔ خارجی همراه با محور‌ها و برچسب‌های محور محاسبه شود.

## **دریافت عرض و ارتفاع ناحیهٔ نمودار**
Aspose.Slides for C++ یک API ساده برای این کار فراهم می‌کند.

1. یک نمونه از کلاس [Presentation](https://reference.aspose.com/slides/fa/cpp/class/aspose.slides.presentation) ایجاد کنید.
1. به اولین اسلاید دسترسی پیدا کنید.
1. نموداری با داده‌های پیش‌فرض اضافه کنید.
1. قبل از به‌دست آوردن مقادیر واقعی، متد IChart::ValidateChartLayout() را فراخوانی کنید.
1. موقعیت X واقعی (چپ) عنصر نمودار را نسبت به گوشهٔ چپ‑بالای نمودار دریافت می‌کند.
1. بالای واقعی عنصر نمودار را نسبت به گوشهٔ چپ‑بالای نمودار دریافت می‌کند.
1. عرض واقعی عنصر نمودار را دریافت می‌کند.
1. ارتفاع واقعی عنصر نمودار را دریافت می‌کند.

``` cpp
auto pres = System::MakeObject<Presentation>(u"test.Pptx");
    
auto chart = System::ExplicitCast<Chart>(pres->get_Slides()->idx_get(0)->get_Shapes()->AddChart(ChartType::ClusteredColumn, 100.0f, 100.0f, 500.0f, 350.0f));
chart->ValidateChartLayout();

double x = chart->get_PlotArea()->get_ActualX();
double y = chart->get_PlotArea()->get_ActualY();
double w = chart->get_PlotArea()->get_ActualWidth();
double h = chart->get_PlotArea()->get_ActualHeight();

// ذخیرهٔ ارائه با نمودار
pres->Save(u"Chart_out.pptx", SaveFormat::Pptx);
```

## **تنظیم حالت طرح ناحیهٔ نمودار**
Aspose.Slides for C++ یک API ساده برای تنظیم حالت طرح ناحیهٔ نمودار فراهم می‌کند. ویژگی **LayoutTargetType** به کلاس‌های **ChartPlotArea** و **IChartPlotArea** افزوده شده است. اگر طرح ناحیهٔ نمودار به‌صورت دستی تعریف شود، این ویژگی مشخص می‌کند که ناحیهٔ نمودار بر اساس داخل (بدون شامل کردن محور و برچسب‌های محور) یا خارج (شامل محور و برچسب‌های محور) طرح‌بندی شود. دو مقدار ممکن وجود دارد که در شمارندهٔ **LayoutTargetType** تعریف شده‌اند.

- **LayoutTargetType.Inner** - مشخص می‌کند که اندازهٔ ناحیهٔ نمودار، اندازهٔ ناحیهٔ نمودار را تعیین می‌کند و علامت‌گذاری‌ها و برچسب‌های محور را شامل نمی‌شود.
- **LayoutTargetType.Outer** - مشخص می‌کند که اندازهٔ ناحیهٔ نمودار، اندازهٔ ناحیهٔ نمودار، علامت‌گذاری‌ها و برچسب‌های محور را تعیین می‌کند.

## **پرسش‌های متداول**

**واحدهای بازگردانده‌شده برای ActualX، ActualY، ActualWidth و ActualHeight چیست؟**

در نقاط (points)؛ ۱ اینچ = ۷۲ نقطه. این‌ها واحدهای مختصات Aspose.Slides هستند.

**ناحیهٔ نمودار (Plot Area) از ناحیهٔ نمودار (Chart Area) از نظر محتوا چه تفاوتی دارد؟**

ناحیهٔ Plot Area ناحیهٔ رسم داده‌ها (سری‌ها، خطوط شبکه، خطوط روند و غیره) است؛ ناحیهٔ Chart Area شامل عناصری که آن را احاطه می‌کنند (عنوان، افسانه و غیره) می‌شود. در نمودارهای سه‑بعدی، ناحیهٔ Plot Area همچنین شامل دیوارها/کف و محورها می‌شود.

**هنگام تنظیم دستی طرح، مقادیر X، Y، عرض و ارتفاع ناحیهٔ Plot Area چگونه تفسیر می‌شوند؟**

آن‌ها کسری (۰‑۱) از اندازهٔ کلی نمودار هستند؛ در این حالت، موقعیت‌یابی خودکار غیرفعال می‌شود و کسری که تنظیم کرده‌اید استفاده می‌شود.

**چرا موقعیت ناحیهٔ Plot Area پس از افزودن/جابه‌جایی افسانه تغییر کرد؟**

افسانه در ناحیهٔ نمودار بیرون از Plot Area قرار می‌گیرد اما بر طرح و فضای موجود تأثیر می‌گذارد، بنابراین در صورت فعال بودن موقعیت‌یابی خودکار، ممکن است Plot Area جابه‌جا شود. (این رفتار استاندارد نمودارهای PowerPoint است.)
