## **قالب‌های فایل و تبدیل‌ها**
Aspose.Slides for C++ بیشترین فرمت‌های سند پاورپوینت را پشتیبانی می‌کند و همچنین آنها را به فرمت‌های محبوبی که به‌ طور گسترده‌ای برای تبادل میان سازمان‌ها استفاده می‌شود، صادر می‌کند. جدول زیر این فرمت‌ها را فهرست می‌کند:

|**ویژگی**|**توضیح**|
| :- | :- |
|[مایکروسافت پاورپوینت (PPT)](/slides/fa/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ سریع‌ترین پردازش را برای این قالب مستند ارائه فراهم می‌کند.|
|[قالب سند قابل حمل (PDF)](/slides/fa/cpp/portable-document-format-pdf/)|قالب‌های فایل پشتیبانی‌شده می‌توانند با یک متد به اسناد Adobe Portable Document Format (PDF) صادر شوند.|
|[مشخصات تجزیه‌گر XML (XPS)](/slides/fa/cpp/xml-parser-specification-xps/)|تمام قالب‌های فایل پشتیبانی‌شده می‌توانند با یک متد به اسناد XML Parser Specification (XPS) صادر شوند.|
|[PresentationML (PPTX، XML)](/slides/fa/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ از پردازش قالب ارائه OOXML که به عنوان PresentationML یا PPTX شناخته می‌شود، پشتیبانی می‌کند.|
|[تبدیل PPTX به HTML](https://docs.aspose.com/slides/fa/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ از تبدیل ارائه به قالب HTML پشتیبانی می‌کند.|

## **رندرینگ**
Aspose.Slides for C++ رندرینگ با کیفیت بالا از اسلایدهای موجود در اسناد ارائه را به فرمت‌های گرافیکی مختلفی که در زیر فهرست شده‌اند، پشتیبانی می‌کند:

|**ویژگی**|**توضیح**|
| :- | :- |
|قالب‌های تصویر پشتیبانی‌شده توسط C++|با استفاده از Aspose.Slides for C++ می‌توانید نه تنها اسلایدهای ارائه، بلکه تصاویر موجود بر روی اسلایدها را به تمام فرمت‌های گرافیکی پشتیبانی‌شده توسط C++ مانند PNG، BMP و JPEG رندر کنید.|
|فرمت SVG|Aspose.Slides for C++ همچنین روش توکار برای صادرات اسلایدهای ارائه به فرمت‌های گرافیکی برداری مقیاس‌پذیر (SVG) فراهم می‌کند.|

## **ویژگی‌های محتوا**
Aspose.Slides for C++ به شما امکان دسترسی، اصلاح یا ایجاد تقریباً تمام محتوای ممکن اسناد ارائه را می‌دهد.

|**ویژگی**|**توضیح**|
| :- | :- |
|اسلایدهای اصلی|اسلایدهای اصلی چیدمان اسلایدهای عادی را تعریف می‌کنند. Aspose.Slides for C++ به شما امکان دسترسی و اصلاح اسلایدهای اصلی مستندات ارائه را می‌دهد.|
|اسلایدهای عادی|با استفاده از Aspose.Slides for C++ می‌توانید نه تنها اسلایدهای جدید با انواع مختلف ایجاد کنید، بلکه به اسلایدهای موجود در مستندات ارائه دسترسی و آن‌ها را اصلاح کنید.|
|شبیه‌سازی / کپی اسلایدها|روش‌های توکار توسط Aspose.Slides for C++ برای شبیه‌سازی یا کپی کردن اسلایدهای موجود نه تنها درون یک ارائه، بلکه از یک ارائه به ارائه دیگر فراهم شده است. از آنجا که یک اسلاید چیدمان خود را از اسلاید اصلی به ارث می‌برد، روش‌های شبیه‌سازی توکار به‌طور خودکار اسلاید اصلی را نیز هنگام شبیه‌سازی کپی می‌کنند.|
|نگهدارنده‌های مکان و متن|می‌توانید به نگهدارنده‌های مکان و متن در یک اسلاید دسترسی پیدا کنید. علاوه بر این، می‌توانید با استفاده از روش مناسب، اسلایدی با نگهدارنده‌های متن از ابتدا ایجاد کنید.|
|سرصفحه‌ها و پاصصفحه‌ها|Aspose.Slides for C++ همچنین امکان مدیریت سرصفحه‌ها/پاصصفحه‌ها در اسلایدها را فراهم می‌کند.|
|یادداشت‌ها در اسلایدها|با Aspose.Slides for C++ می‌توانید نه تنها به یادداشت‌های مرتبط با یک اسلاید دسترسی و آن‌ها را اصلاح کنید، بلکه یادداشت نیز اضافه کنید.|
|یافتن یک شکل|می‌توانید با استفاده از متن جایگزین مرتبط با شکل، یک شکل خاص را در اسلاید پیدا کنید.|
|پس‌زمینه‌ها|Aspose.Slides for C++ امکان کار با پس‌زمینه مرتبط با اسلاید اصلی یا عادی ارائه را فراهم می‌کند.|
|جعبه‌های متن|جعبه‌های متن می‌توانند از ابتدا ایجاد شوند. جعبه‌های متن موجود می‌توانند دسترسی یافته و متن آن‌ها بدون از دست دادن فرمت متن اصلی، اصلاح شود.|
|اشکال مستطیلی|اشکال مستطیلی می‌توانند توسط Aspose.Slides for C++ ایجاد یا اصلاح شوند.|
|اشکال خط چندضلعی|اشکال خط چندضلعی نیز می‌توانند توسط Aspose.Slides for C++ ایجاد یا اصلاح شوند.|
|اشکال بیضی|اشکال بیضی نیز توسط Aspose.Slides for C++ ایجاد یا اصلاح می‌شوند.|
|اشکال گروهی|Aspose.Slides for C++ از اشکال گروهی نیز پشتیبانی می‌کند.|
|اشکال خودکار|اشکال خودکار نیز توسط Aspose.Slides for C++ پشتیبانی می‌شوند.|
|سریال‌سازی اشکال|اگرچه Aspose.Slides for C++ از تعداد زیادی شکل پشتیبانی می‌کند، اما اگر شکلی توسط Aspose.Slides for C++ پشتیبانی نشود، روش سریال‌سازی توسط Aspose.Slides for C++ فراهم شده است که می‌توانید آن شکل را از یک اسلاید موجود سریال‌سازی کنید و برای استفاده‌های بعدی توسط Aspose.Slides for C++ به کار ببرید.|
|فریم‌های تصویری|تصاویر در فریم‌های تصویری توسط Aspose.Slides for C++ مدیریت می‌شوند.|
|فریم‌های صوتی|فایل‌های صوتی می‌توانند در فریم‌های صوتی به‌صورت لینک‌شده یا جاسازی‌شده در اسلایدها توسط Aspose.Slides for C++ قرار گیرند.|
|فریم‌های ویدئویی|فایل‌های ویدئویی در فریم‌های ویدئویی توسط Aspose.Slides for C++ مدیریت می‌شوند.|
|فریم OLE|اشیای OLE در فریم‌های OLE توسط Aspose.Slides for C++ مدیریت می‌شوند.|
|جداول|جداول در اسلایدها نیز توسط Aspose.Slides for C++ پشتیبانی می‌شوند.|
|فریم متن|متن مرتبط با هر شکل می‌تواند از طریق فریم متن مرتبط با آن شکل دسترسی یابد.|
|اسکن متن|متن در یک ارائه می‌تواند با استفاده از روش‌های اسکن توکار در سطح ارائه یا اسلاید اسکن شود.|
|انیمیشن‌ها|انیمیشن‌ها می‌توانند بر روی اشکال اعمال شوند.|
|نمایش اسلایدها|نمایش اسلایدها، انتقال‌های اسلاید و انتقال‌های مورف نیز پشتیبانی می‌شوند.|

## **پرسش‌های متداول**

**آیا برای استفاده از کتابخانه لازم است مایکروسافت پاورپوینت را روی سرور/کامپیوتر نصب کنم؟**

خیر. پاورپوینت مورد نیاز نیست؛ Aspose.Slides یک موتور مستقل برای ایجاد، ویرایش، تبدیل و رندرینگ ارائه‌هاست.

**چندریسمانی (multithreading) چگونه کار می‌کند؟ آیا پردازش می‌تواند به‌صورت موازی انجام شود؟**

ایمن است که اسناد مختلف را در رشته‌های متفاوت پردازش کنید؛ شیء همان [ارائه](https://reference.aspose.com/slides/fa/cpp/aspose.slides/presentation/) نباید توسط [چندین رشته](/slides/fa/cpp/multithreading/) همزمان استفاده شود.

**آیا رمز عبور فایل‌ها و رمزنگاری پشتیبانی می‌شود؟**

بله. [می‌توانید](/slides/fa/cpp/password-protected-presentation/) ارائه‌های رمزنگاری‌شده را باز کنید، رمز عبور بازکردن و نوشتن را تنظیم یا حذف کنید و وضعیت حفاظت را بررسی کنید.

**آیا باید در مورد بسته‌های فونت در کانتینرهای لینوکس نگران باشم؟**

بله. توصیه می‌شود بسته‌های فونت عمومی را نصب کنید و/یا به‌صورت صریح [دایرکتوری‌های فونت](/slides/fa/cpp/custom-font/) را در برنامه‌تان مشخص کنید تا از جایگزینی‌های ناخواسته جلوگیری شود.

**آیا در نسخه ارزیابی محدودیتی وجود دارد؟**

در [حالت ارزیابی](/slides/fa/cpp/licensing/)، یک نشان آبکی به خروجی اضافه می‌شود و محدودیت‌های خاصی اعمال می‌شود؛ یک [مجوز موقت 30 روزه](https://purchase.aspose.com/temporary-license/) برای تست کامل ویژگی‌ها در دسترس است.

**آیا وارد کردن فرمت‌های خارجی به یک ارائه (PDF/HTML → PPTX) پشتیبانی می‌شود؟**

بله. می‌توانید [صفحات PDF و محتوای HTML](/slides/fa/cpp/import-presentation/) را به یک ارائه اضافه کنید و آنها را به اسلاید تبدیل کنید.
