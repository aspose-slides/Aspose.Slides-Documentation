## **قالب‌های فایل و تبدیل‌ها**
Aspose.Slides for C++ اکثر قالب‌های اسناد PowerPoint را پشتیبانی می‌کند و همچنین آن‌ها را به قالب‌های محبوبی که به‌طور گسترده برای تبادل میان سازمان‌ها استفاده می‌شوند، صادر می‌نماید. جدول زیر این قالب‌ها را فهرست می‌کند:

|**ویژگی**|**توضیح**|
| :- | :- |
|[مایکروسافت پاورپوینت (PPT)](/slides/fa/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ سریع‌ترین پردازش را برای این قالب سند ارائه‌ای فراهم می‌کند.|
|[قالب سند قابل حمل (PDF)](/slides/fa/cpp/portable-document-format-pdf/)|قالب‌های فایل پشتیبانی شده می‌توانند با یک متد به اسناد Adobe Portable Document Format (PDF) صادر شوند.|
|[مشخصات تجزیه‌گر XML (XPS)](/slides/fa/cpp/xml-parser-specification-xps/)|تمام قالب‌های فایل پشتیبانی شده می‌توانند با یک متد به اسناد XML Parser Specification (XPS) صادر شوند.|
|[PresentationML (PPTX, XML)](/slides/fa/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ پردازش قالب ارائه OOXML را که به عنوان PresentationML یا PPTX شناخته می‌شود، پشتیبانی می‌کند.|
|[تبدیل PPTX به HTML](https://docs.aspose.com/slides/fa/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ تبدیل ارائه به قالب HTML را پشتیبانی می‌کند.|

## **رندر ارائه**
Aspose.Slides for C++ رندر با دقت بالا از اسلایدهای اسناد ارائه را به قالب‌های گرافیکی مختلفی که در زیر فهرست شده‌اند، فراهم می‌سازد:

|**ویژگی**|**توضیح**|
| :- | :- |
|قالب‌های تصویر پشتیبانی‌شده در C++|با استفاده از Aspose.Slides for C++ می‌توانید نه تنها اسلایدهای ارائه، بلکه تصاویر موجود در اسلایدها را به تمام قالب‌های گرافیکی پشتیبانی‌شده در C++ مانند PNG, BMP و JPEG رندر کنید.|
|قالب SVG|Aspose.Slides for C++ همچنین متد داخلی برای صادر کردن اسلایدهای ارائه به قالب Scalable Vector Graphics (SVG) فراهم می‌کند.|

## **ویژگی‌های محتوا**
Aspose.Slides for C++ به شما امکان دسترسی، اصلاح یا ایجاد تقریباً تمام محتویات ممکن اسناد ارائه را می‌دهد.

|**ویژگی**|**توضیح**|
| :- | :- |
|اسلایدهای اصلی|اسلایدهای اصلی چیدمان اسلایدهای عادی را تعریف می‌کنند. Aspose.Slides for C++ امکان دسترسی و اصلاح اسلایدهای اصلی اسناد ارائه را فراهم می‌کند.|
|اسلایدهای عادی|با استفاده از Aspose.Slides for C++ می‌توانید نه تنها اسلایدهای جدید با انواع مختلف ایجاد کنید، بلکه به اسلایدهای موجود در اسناد ارائه دسترسی و آن‌ها را اصلاح نمایید.|
|کلون/کپی اسلایدها|متدهای داخلی ارائه‌شده توسط Aspose.Slides for C++ برای کلون یا کپی کردن اسلایدهای موجود نه تنها درون یک ارائه، بلکه از یک ارائه به ارائه دیگر وجود دارد. از آنجا که یک اسلاید چیدمان خود را از اسلاید اصلی به ارث می‌برد، متدهای کلون داخلی به‌طور خودکار اسلاید اصلی را نیز در هنگام کلون کپی می‌کنند.|
|محافظت‌کننده‌ها و نگهدارنده‌های متن|می‌توانید به محافظت‌کننده‌ها و نگهدارنده‌های متن در یک اسلاید دسترسی داشته باشید. علاوه بر این، می‌توانید با استفاده از متد مناسب از ابتدا یک اسلاید با نگهدارنده‌های متن ایجاد کنید.|
|سرصفحه و پاورصفحه|Aspose.Slides for C++ همچنین مدیریت سرصفحه/پاورصفحه در اسلایدها را تسهیل می‌کند.|
|یادداشت‌ها در اسلایدها|با Aspose.Slides for C++ می‌توانید نه تنها به یادداشت‌های مرتبط با یک اسلاید دسترسی و آن‌ها را اصلاح کنید، بلکه یادداشت جدیدی نیز اضافه کنید.|
|یافتن شکل|می‌توانید با استفاده از متن جایگزین مرتبط با شکل، یک شکل خاص را در اسلاید پیدا کنید.|
|پس‌زمینه‌ها|Aspose.Slides for C++ امکان کار با پس‌زمینه مرتبط با اسلاید اصلی یا عادی ارائه را فراهم می‌کند.|
|جعبه‌های متن|جعبه‌های متن می‌توانند از ابتدا ایجاد شوند. جعبه‌های متن موجود می‌توانند دسترسی داشته و متن آن‌ها نیز بدون از دست دادن قالب‌بندی اصلی اصلاح شود.|
|اشکال مستطیلی|اشکال مستطیلی می‌توانند توسط Aspose.Slides for C++ ایجاد یا اصلاح شوند.|
|اشکال خط چندضلعی|اشکال خط چندضلعی نیز می‌توانند توسط Aspose.Slides for C++ ایجاد یا اصلاح شوند.|
|اشکال بیضوی|اشکال بیضوی نیز توسط Aspose.Slides for C++ ایجاد یا اصلاح می‌شوند.|
|اشکال گروهی|Aspose.Slides for C++ از اشکال گروهی نیز پشتیبانی می‌کند.|

|سریال‌سازی اشکال|اگرچه Aspose.Slides for C++ از تعداد زیادی از اشکال پشتیبانی می‌کند، اما اگر شکلی توسط Aspose.Slides for C++ پشتیبانی نشود، متد سریال‌سازی ارائه‌شده توسط Aspose.Slides for C++ به شما امکان می‌دهد آن شکل را از یک اسلاید موجود سریال‌سازی کرده و برای استفادهٔ بعدی توسط Aspose.Slides for C++ ذخیره کنید.|

|قاب‌های ویدئویی|فایل‌های ویدئویی توسط Aspose.Slides for C++ در قاب‌های ویدئویی مدیریت می‌شوند.|

## **سوالات متداول**

### آیا برای کارکرد کتابخانه نیاز به نصب Microsoft PowerPoint روی سرور/کامپیوتر دارم؟

نه. PowerPoint لازم نیست؛ Aspose.Slides یک موتور مستقل برای ایجاد، ویرایش، تبدیل و رندر ارائه‌ها است.

### چندنخی (multithreading) چگونه کار می‌کند؟ آیا پردازش می‌تواند به‌صورت موازی انجام شود؟

ایمن است که اسناد مختلف را در رشته‌های متفاوت پردازش کنید؛ شیء [presentation](https://reference.aspose.com/slides/fa/cpp/aspose.slides/presentation/) یکسان نباید همزمان توسط [multiple threads](/slides/fa/cpp/multithreading/) استفاده شود.

### آیا رمزهای عبور فایل و رمزنگاری پشتیبانی می‌شوند؟

بله. [You can](/slides/fa/cpp/password-protected-presentation/) ارائه‌های رمزنگاری‌شده را باز کنید، رمز باز کردن و نوشتن را تنظیم یا حذف کنید و وضعیت حفاظت را بررسی کنید.

### آیا باید در کانتینرهای لینوکس به بسته‌های قلم (font) توجه کنم؟

بله. توصیه می‌شود بسته‌های قلم رایج را نصب کنید و/یا به‌وضوح [specify font directories](/slides/fa/cpp/custom-font/) را در برنامهٔ خود مشخص کنید تا از جایگزینی‌های ناخواسته جلوگیری شود.

### آیا در نسخه ارزیابی محدودیتی وجود دارد؟

در [evaluation mode](/slides/fa/cpp/licensing/) یک watermark به خروجی اضافه می‌شود و برخی محدودیت‌ها اعمال می‌شوند؛ یک [30-day temporary license](https://purchase.aspose.com/temporary-license/) برای تست کامل ویژگی‌ها در دسترس است.

### آیا وارد کردن قالب‌های خارجی به ارائه (PDF/HTML → PPTX) پشتیبانی می‌شود؟

بله. می‌توانید [PDF pages and HTML content](/slides/fa/cpp/import-presentation/) را به یک ارائه اضافه کنید و آن‌ها را به اسلایدها تبدیل نمایید.
