## **بررسی کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. این مقاله Open XML SDK را به عنوان کتابخانه‌ای برای دستکاری بسته‌های OOXML و عناصر XML پایه آن توصیف می‌کند، در حالی که Aspose.Slides به‌عنوان کتابخانه‌ای برای پردازش ارائه‌ها با مدل شیء سطح بالا و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، رندرینگ، پشتیبانی پلتفرم و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات‌های پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیده‌تر ارائه مانند کار با چندین فرمت PowerPoint، کپی یا کلون‌کردن اشکال، جایگزینی متن، اعمال انیمیشن‌ها و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**

ما گاهی این سؤال را می‌شنویم: چرا باید به جای Open XML SDK رایگان، از محصولات Aspose استفاده کنیم؟ پاسخ این سؤال ساده است: ویژگی‌ها و عملکرد. بر اساس [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به‌صورت زیر تعریف می‌شود: Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر اسکیماهای Open XML پایه داخل یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای رایج که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند را محصور می‌کند، به‌طوری که بتوانید عملیات پیچیده را تنها با چند خط کد انجام دهید. اسناد OOXML در واقع فایل‌های XML فشرده‌شده هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما امکان کار با محتوای اسناد OOXML را به‌صورت strongly‑typed می‌دهد. به این معنی که به‌جای استخراج یک فایل ZIP برای دسترسی به XML، بارگذاری آن XML در یک درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی برای انجام این کار فراهم می‌کند.

## **Aspose.Slides چیست؟**

Aspose.Slides یک کتابخانه کلاس است که به برنامه شما امکان انجام وظایف پردازش ارائه زیر را می‌دهد:

- برنامه‌نویسی با مدل شیء **Presentation**.
- تبدیل‌های با کیفیت بالا بین تمام فرمت‌های محبوب و پشتیبانی‌شده ارائه PowerPoint، شامل تبدیل به PDF و XPS.
- قابلیت تولید تصویر بندانگشتی اسلاید در قالب‌های مشهور مانند PNG، JPEG و BMP به‌همراه خروجی اسلاید به SVG.
- قابلیت ساخت ارائه‌ها از ابتدا یا با ترکیب یک یا چند سند.
- پشتیبانی از افزودن انیمیشن‌ها، Ole Frames، جداول، ایجاد و مدیریت نمودارها.
- دسترس‌پذیری کنترل گسترده برای مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر درباره ویژگی‌های پشتیبانی‌شده، لطفاً به [Aspose.Slides Features](/slides/fa/cpp/product-overview/) مراجعه کنید.

## **نتیجه‌گیری**

Open XML SDK و Aspose.Slides به‌صورت مستقیم رقابت نمی‌کنند زیرا نیازها و مخاطبان بسیار متفاوتی را هدف قرار می‌دهند. Open XML SDK یک کتابخانه کلاس است که روشی strongly‑typed برای کار با اسناد OOXML فراهم می‌کند. Aspose.Slides کتابخانه‌ای بسیار مفید برای پردازش ارائه‌هاست که حمایت فراوانی از تقریباً تمام فرمت‌های فایل Microsoft PowerPoint ارائه می‌دهد. اگر تنها کاری که نیاز دارید انجام دهید یک عملیات برنامه‌نویسی پایه‌ای روی سند PPTX باشد، Open XML SDK می‌تواند انتخاب مناسبی باشد. با Open XML SDK می‌توانید به‌راحتی کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرفصل/پانویس، استخراج تصاویر و غیره را انجام دهید. برخی وظایف را می‌توان با Open XML SDK انجام داد، اما با Aspose.Slides قابل انجام نیست. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML داشته باشید، باید از Open XML SDK استفاده کنید. اما اگر نیاز به انجام عملیات پیچیده روی اسناد دارید، مانند برخی از کارهای زیر، استفاده از Aspose.Slides بهترین گزینه شماست:

- پشتیبانی از فرمت‌های قدیمی PowerPoint علاوه بر PPTX.
- کپی یا کلون‌کردن اشکال داخل اسلایدها به‌طوری که اشیاء، سبک‌ها و سایر قالب‌بندی‌ها به شکل مناسب ترکیب شوند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از رابط‌ها با اشکال مورد استفاده.
- تبدیل سند به PDF یا XPS به‌طوری که دقیقاً مشابه تبدیل توسط Microsoft PowerPoint باشد.
- توسعه یک برنامه C++ در هر دو محیط دسکتاپ و کنسول.
