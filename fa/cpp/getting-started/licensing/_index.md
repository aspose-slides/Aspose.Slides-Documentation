## **نمای کلی**

Aspose.Slides می‌تواند در حالت ارزیابی یا با یک لایسنس معتبر استفاده شود. نسخه ارزیابی همان عملکرد نسخه لایسنس‌دار را دارد، اما یک واترمارک ارزیابی به هر اسلاید از هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند و متنی که کد شما از ارائه‌ها می‌خواند را کوتاه می‌کند.

این مقاله توضیح می‌دهد که لایسنسیون در Aspose.Slides چگونه کار می‌کند و چگونه قبل از استفاده از کتابخانه یک لایسنس اعمال می‌شود. یک لایسنس می‌تواند از یک فایل یا یک جریان با استفاده از کلاس `License` بارگذاری شود. مقاله همچنین نشان می‌دهد چگونه اعتبارسنجی شود که آیا لایسنس به‌درستی اعمال شده است یا نه.

## **لایسنس‌گذاری در Aspose.Slides**

* یک نسخه ارزیابی پس از خرید لایسنس و اعمال آن با افزودن چند خط کد، تبدیل به نسخه لایسنس‌دار می‌شود.
* لایسنس یک فایل XML متنی ساده است که جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که به آن لایسنس داده شده، تاریخ انقضای اشتراک و موارد دیگر را شامل می‌شود.
* فایل لایسنس به صورت دیجیتالی امضا شده است، بنابراین نباید تغییر یابد. حتی یک تغییر تصادفی—مانند اضافه کردن یک خط جدید—ملف فایل را نامعتبر می‌کند.
* وقتی نام فایلی بدون مسیر می‌دهید، Aspose.Slides for C++ فقط در دایرکتوری کاری فعلی به دنبال فایل لایسنس می‌گردد. این مسیر، پوشه‌ی اجرایی یا کتابخانه Aspose.Slides را جستجو نمی‌کند، بنابراین هنگام ذخیره لایسنس در جای دیگر، مسیر کامل را ارائه دهید.
* برای جلوگیری از محدودیت‌های نسخه ارزیابی، باید قبل از استفاده از Aspose.Slides لایسنس را تنظیم کنید. یک لایسنس فقط یک‌بار برای هر برنامه یا فرآیند باید تنظیم شود.

## **اعمال لایسنس**

یک لایسنس می‌تواند از **فایل** یا **جریان** بارگذاری شود.

{{% alert color="info" title="Note" %}}
Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/cpp/aspose.slides/license/) را برای عملیات لایسنس‌گذاری فراهم می‌کند.
{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}
لایسنس‌های جدید فقط می‌توانند Aspose.Slides را با نسخه 21.4 یا بالاتر فعال کنند. نسخه‌های قبلی از یک سیستم لایسنس‌گذاری متفاوت استفاده می‌کنند و این لایسنس‌ها را تشخیص نمی‌دهند.
{{% /alert %}}

### **فایل**

آسان‌ترین راه برای تنظیم لایسنس این است که فایل لایسنس را در دایرکتوری کاری برنامه‌تان قرار دهید و فقط نام فایل را بدون مسیر مشخص کنید. در غیر این صورت، مسیر کامل فایل را تعیین کنید.

کد C++ زیر لایسنس فایل *Aspose.Slides.lic* را از دایرکتوری کاری برنامه اعمال می‌کند:
```c++
#include <Util/License.h>
#include <system/smart_ptr.h>
#include <system/string.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    return 0;
}
```

اگر لایسنس معتبر باشد، [License::SetLicense](https://reference.aspose.com/slides/fa/cpp/aspose.slides/license/setlicense/) باز می‌گردد و برنامه بدون خروجی پایان می‌یابد؛ از آن پس Aspose.Slides بدون محدودیت‌های ارزیابی کار می‌کند. اگر فایل در دایرکتوری کاری موجود نباشد، متد یک [FileNotFoundException](https://reference.aspose.com/slides/fa/cpp/system.io/filenotfoundexception/) با پیام *License "Aspose.Slides.lic" doesn't exist or access is restricted* پرتاب می‌کند. مثال استثنا را مدیریت نمی‌کند، بنابراین برنامه متوقف می‌شود.

{{% alert color="warning" title="Warning" %}}
اگر فایل لایسنس را در دایرکتوری متفاوتی قرار دهید، هنگام فراخوانی متد [License::SetLicense]، نام فایل در انتهای مسیر صریح مشخص شده باید دقیقاً با نام فایل لایسنس شما مطابقت داشته باشد.

به‌عنوان مثال، اگر فایل لایسنس خود را به *Aspose.Slides.lic.xml* تغییر نام دهید، باید مسیر کامل که با *Aspose.Slides.lic.xml* پایان می‌یابد را به متد [License::SetLicense] در کد خود بدهید.
{{% /alert %}}

### **جریان**

یک لایسنس را از یک جریان بارگذاری کنید وقتی برنامه شما لایسنس را به عنوان فایلی که می‌تواند نام‌گذاری شود نگه‌داری نمی‌کند، به عنوان مثال زمانی که لایسنس را از یک پایگاه‌داده می‌خواند. [License::SetLicense] هر [Stream] حاوی لایسنس را می‌پذیرد. برای کوتاه نگه داشتن مثال، کد C++ زیر *Aspose.Slides.lic* را در دایرکتوری کاری با [File::OpenRead] باز می‌کند و لایسنس را از آن جریان اعمال می‌نماید:
```c++
#include <Util/License.h>
#include <system/io/file.h>
#include <system/smart_ptr.h>

using namespace Aspose::Slides;
using namespace System;
using namespace System::IO;

int main()
{
    auto license = MakeObject<License>();
    auto stream = File::OpenRead(u"Aspose.Slides.lic");
    license->SetLicense(stream);

    return 0;
}
```

یک لایسنس معتبر همان نتیجه را همانند مثال فایل می‌دهد. اگر فایل موجود نباشد، [File::OpenRead] قبل از اعمال لایسنس یک [FileNotFoundException] پرتاب می‌کند و برنامه متوقف می‌شود.

## **اعتبارسنجی لایسنس**

برای بررسی اینکه آیا لایسنس به‌درستی تنظیم شده است یا نه، متد [License::IsLicensed] را صدا بزنید. این متد فقط پس از اعمال یک لایسنس معتبر `true` باز می‌گرداند و پیش از آن `false`.

کد C++ زیر لایسنس فایل را از دایرکتوری کاری اعمال می‌کند و سپس آن را بررسی می‌کند:
```c++
#include <Util/License.h>
#include <system/console.h>
#include <system/smart_ptr.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    if (license->IsLicensed())
    {
        Console::WriteLine(u"License is good!");
    }

    return 0;
}
```

با یک لایسنس معتبر، برنامه عبارت *License is good!* را چاپ می‌کند. اگر فایل موجود نباشد یا لایسنس نباشد، [License::SetLicense] قبل از بررسی یک استثنا پرتاب می‌کند و برنامه بدون چاپ هیچ چیزی متوقف می‌شود. اگر فایل یک لایسنس باشد که امضای آن مطابقت ندارد، به‌عنوان مثال به‌دلیل ویرایش، SetLicense بدون خطا باز می‌گردد اما `IsLicensed` `false` برمی‌گرداند، بنابراین هیچ چیزی چاپ نمی‌شود و Aspose.Slides در حالت ارزیابی می‌ماند.

## **ایمنی چندنخی**

{{% alert color="warning" title="Warning" %}}
متد [License::SetLicense] **ایمن برای چندنخی نیست**. اگر نیاز داشته باشید این متد را همزمان از چندین رشته فراخوانی کنید، توصیه می‌شود از primitives همگام‌سازی (مانند قفل) برای جلوگیری از مشکلات احتمالی استفاده کنید.
{{% /alert %}}

## **FAQ**

### آیا می‌توانم لایسنس را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ نیازی به اتصال اینترنت نیست.

### پس از انقضای اشتراک یک‌ساله چه اتفاقی می‌افتد؟ آیا کتابخانه متوقف خواهد شد؟

خیر. لایسنس دائمی است: می‌توانید از نسخه‌های منتشر شده قبل از تاریخ پایان اشتراک خود استفاده کنید؛ فقط بدون تمدید، مجاز به استفاده از نسخه‌های جدیدتر نخواهید بود.
