## **بررسی کلی**

Aspose.Slides می‌تواند در حالت ارزیابی یا با یک لایسنس معتبر استفاده شود. نسخه ارزیابی همان قابلیت‌های نسخه لایسنس‌دار را دارد، اما هنگام باز یا ذخیره‌سازی ارائه‌ها یک واترمارک ارزیابی اضافه می‌کند و استخراج متن محدود به یک اسلاید می‌شود.

این مقاله نحوه کار لایسنس در Aspose.Slides و چگونگی اعمال لایسنس قبل از استفاده از کتابخانه را توضیح می‌دهد. یک لایسنس می‌تواند از فایل، استریم یا منبع جاسازی‌شده با استفاده از کلاس `License` بارگذاری شود. مقاله همچنین نشان می‌دهد چگونه اعتبارسنجی کنید که آیا لایسنس به‌درستی اعمال شده است یا خیر.

## **لایسنس در Aspose.Slides**

* یک نسخه ارزیابی پس از خرید لایسنس و اعمال آن با افزودن چند خط کد، به نسخه لایسنس‌دار تبدیل می‌شود.
* لایسنس فایلی متنی ساده XML است که شامل جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که لایسنس به آن‌ها اختصاص یافته، تاریخ انقضای اشتراک و موارد دیگر می‌شود.
* فایل لایسنس به‌صورت دیجیتالی امضا شده است، بنابراین نباید تغییر یابد. حتی یک تغییر تصادفی مانند افزودن یک خط جدید می‌تواند فایل را نامعتبر کند.
* Aspose.Slides for C++ معمولاً به دنبال فایل لایسنس در مکان‌های زیر می‌گردد:
  * مسیری که به‌صورت صریح در کد شما مشخص شده است
  * پوشه‌ای که DLL کامپوننت در آن قرار دارد (شامل در Aspose.Slides)
  * پوشه‌ای که اسمبلی فراخوانی‌کننده DLL کامپوننت در آن است
* برای حذف محدودیت‌های نسخه ارزیابی، باید قبل از استفاده از Aspose.Slides لایسنس را تنظیم کنید. یک لایسنس فقط یک‌بار برای هر برنامه یا فرآیند نیاز دارد.

## **اعمال لایسنس**

یک لایسنس می‌تواند از **فایل**، **استریم** یا **منبع جاسازی‌شده** بارگذاری شود.

{{% alert color="info" %}}

Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/cpp/class/aspose.slides.license/) را برای عملیات لایسنس‌گذاری فراهم می‌کند.

{{% /alert %}} 

{{% alert color="warning" %}}

لایسنس‌های جدید می‌توانند Aspose.Slides را فقط از نسخه 21.4 به بعد فعال کنند. نسخه‌های قبلی از سیستم لایسنس متفاوتی استفاده می‌کنند و این لایسنس‌ها را شناسایی نمی‌کنند.

{{% /alert %}}

### **فایل**

ساده‌ترین روش برای تنظیم لایسنس، قرار دادن فایل لایسنس در همان پوشه‌ای است که DLL کامپوننت (شامل در Aspose.Slides) قرار دارد و صرفاً نام فایل را بدون مسیر مشخص کنید.

کد C++ زیر نشان می‌دهد چگونه یک فایل لایسنس تنظیم شود:

```c++
#include <Util/License.h>
#include <system/smart_ptr.h>
#include <system/string.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    return 0;
}
```

{{% alert color="warning" %}} 

اگر فایل لایسنس را در یک دایرکتوری متفاوت قرار دهید، هنگام فراخوانی متد [License::SetLicense](https://reference.aspose.com/slides/fa/cpp/aspose.slides/license/setlicense/)، نام فایل در انتهای مسیر صریح باید دقیقاً با نام فایل لایسنس شما مطابقت داشته باشد.

به‌عنوان مثال، اگر نام فایل لایسنس خود را به *Aspose.Slides.lic.xml* تغییر دهید، باید مسیر کامل پایان‌دار به *Aspose.Slides.lic.xml* را به متد [License::SetLicense](https://reference.aspose.com/slides/fa/cpp/aspose.slides/license/setlicense/) در کد خود پاس کنید.

{{% /alert %}}

### **استریم**

می‌توانید لایسنس را از یک استریم بارگذاری کنید. کد C++ زیر نشان می‌دهد چگونه لایسنس را از یک استریم اعمال کنید:

```c++
#include <Util/License.h>
#include <system/io/file.h>
#include <system/smart_ptr.h>
using namespace Aspose::Slides;
using namespace System;
using namespace System::IO;

auto license = MakeObject<License>();

auto stream = File::OpenRead(u"Aspose.Slides.lic");

license->SetLicense(stream);
```

## **اعتبارسنجی لایسنس**

برای بررسی اینکه آیا لایسنس به‌درستی تنظیم شده است یا نه، می‌توانید آن را اعتبارسنجی کنید. کد C++ زیر نشان می‌دهد چگونه یک لایسنس را اعتبارسنجی کنید:

```c++
#include <Util/License.h>
#include <system/console.h>
using namespace Aspose::Slides;
using namespace System;

auto license = MakeObject<License>();

license->SetLicense(u"Aspose.Slides.lic");

if (license->IsLicensed())
{
    Console::WriteLine(u"License is good!");
    Console::ReadKey();
}
```

## **ایمنی در برابر چندنخی**

{{% alert title="Note" color="warning" %}} 

متد [License::SetLicense](https://reference.aspose.com/slides/fa/cpp/aspose.slides/license/setlicense/) **Thread-safe نیست**. اگر نیاز دارید این متد را همزمان از چندین نخ صدا بزنید، توصیه می‌شود از primitives همگام‌سازی (مانند قفل) استفاده کنید تا از مشکلات احتمالی جلوگیری شود.

{{% /alert %}}

## **سوالات متداول**

### آیا می‌توانم لایسنس را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ اتصال به اینترنت لازم نیست.

### پس از پایان اشتراک یک‌ساله چه اتفاقی می‌افتد؟ آیا کتابخانه متوقف می‌شود؟

نه. لایسنس دائمی است: می‌توانید از نسخه‌های منتشر شده پیش از تاریخ پایان اشتراک خود استفاده کنید؛ فقط برای استفاده از نسخه‌های جدیدتر بدون تمدید اشتراک مجاز نخواهید بود.
