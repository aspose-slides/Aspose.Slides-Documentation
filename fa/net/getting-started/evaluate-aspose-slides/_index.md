## **ارزیابی Aspose.Slides**

به‌راحتی می‌توانید Aspose.Slides را برای ارزیابی دانلود کنید. بسته ارزیابی همان بسته خریداری شده است. نسخه ارزیابی به سادگی پس از افزودن چند خط کد برای اعمال لایسنس به نسخه دارای مجوز تبدیل می‌شود.

نسخه ارزیابی Aspose.Slides (بدون مشخص کردن لایسنس) تمام عملکردهای محصول را فراهم می‌کند، اما یک واترمارک ارزیابی در بالای سند هنگام باز کردن و ذخیره‌سازی اضافه می‌کند. همچنین هنگام استخراج متن از اسلایدهای ارائه به یک اسلید محدود می‌شوید.

## **نصب بسته ارزیابی**

```bash
dotnet add package Aspose.Slides.NET
```

## **اعمال لایسنس**

این‌ها «چند خط کد» هستند که بسته ارزیابی را به یک بسته دارای لایسنس تبدیل می‌کنند. لایسنس را یک بار در زمان راه‌اندازی برنامه، قبل از ایجاد هر شیء `Presentation` اعمال کنید — ارائه‌ای که قبلاً ساخته شده باشد واترمارک ارزیابی را حفظ می‌کند.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` همچنین یک `Stream` را می‌پذیرد، که گزینه بهتری است زمانی که لایسنس به‌صورت منبع جاسازی‌شده ارسال می‌شود نه به‌عنوان فایل روی دیسک. اگر مسیر اشتباه باشد یا فایل منقضی شده باشد، فراخوانی استثنا می‌اندازد، بنابراین خطاها بلافاصله در زمان راه‌اندازی ظاهر می‌شوند و به‌صورت خاموش به حالت ارزیابی باز نمی‌گردند.

پس از اعمال لایسنس، واترمارک ناپدید می‌شود و محدودیت استخراج متن یک اسلایدی رفع می‌گردد.

## **پرسش‌های متداول**

### آیا می‌توانم چندین ارائه را به‌صورت همزمان در رشته‌های مختلف در حالت ارزیابی تست کنم؟

بله. می‌توانید اسناد مختلف را به‌صورت همزمان پردازش کنید؛ نباید همان شیء ارائه را [در سراسر رشته‌ها](/slides/fa/net/multithreading/) به‌اشتراک بگذارید. حالت ارزیابی بر این امر تأثیری ندارد.

### آیا برای ارزیابی کتابخانه روی سرور یا در CI نیاز به نصب Microsoft PowerPoint دارم؟

خیر. Aspose.Slides یک موتور مستقل است و برای ارزیابی یا تولید نیازی به نصب PowerPoint ندارد.

### آیا می‌توانم تبدیل کامل PPT/PPTX به PDF و تصاویر را در حالت ارزیابی تست کنم؟

بله. [مبدل‌ها](/slides/fa/net/convert-presentation/) کار می‌کنند؛ خروجی شامل واترمارک خواهد بود.

### آیا می‌توانم برای تست بارگذاری از یک لایسنس موقت بدون واترمارک استفاده کنم؟

بله. یک لایسنس موقت 30 روزه محدودیت‌های حالت ارزیابی را حذف می‌کند و امکان تست بدون واترمارک را فراهم می‌سازد.
