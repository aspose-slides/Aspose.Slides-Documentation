## **بررسی کلی**

Aspose.Slides می‌تواند در حالت ارزیابی یا با یک لایسنس معتبر استفاده شود. نسخه ارزیابی همان عملکرد نسخه دارای لایسنس را فراهم می‌کند، اما هنگام باز کردن یا ذخیره ارائه‌ها، یک واترمارک ارزیابی اضافه می‌کند و استخراج متن را به یک اسلاید محدود می‌سازد.

این مقاله توضیح می‌دهد که لایسنس در Aspose.Slides چگونه کار می‌کند و چگونه قبل از استفاده از کتابخانه یک لایسنس اعمال کنید. لایسنس می‌تواند از فایل، جریان (stream) یا منبع جاسازی‌شده با استفاده از کلاس `License` بارگذاری شود. همچنین مقاله نشان می‌دهد چگونه صحت اعمال لایسنس را اعتبارسنجی کنید.

## **لایسنس در Aspose.Slides**
* یک نسخه ارزیابی پس از خرید لایسنس و افزودن چند خط کد برای اعمال لایسنس، به نسخه دارای لایسنس تبدیل می‌شود.
* لایسنس یک فایل XML متنی ساده است که جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که به آن لایسنس داده شده، تاریخ انقضای اشتراک و غیره را شامل می‌شود. 
* فایل لایسنس به‌صورت دیجیتال امضا شده است، بنابراین نباید آن را تغییر دهید. حتی اضافه کردن ناخواسته یک خط جدید به محتویات فایل نیز آن را نامعتبر می‌کند.
* Aspose.Slides for .NET معمولاً سعی می‌کند لایسنس را در این مسیرها پیدا کند:
  * مسیر صریح
  * پوشه‌ای که شامل dll مؤلفه است (در Aspose.Slides گنجانده شده)
  * پوشه‌ای که شامل اسمبلی است که dll مؤلفه را فراخوانی می‌کند (در Aspose.Slides گنجانده شده)
  * پوشه‌ای که شامل اسمبلی ورودی است (فایل .exe شما)
  * منبع جاسازی‌شده در اسمبلی که dll مؤلفه را فراخوانی می‌کند (در Aspose.Slides گنجانده شده).
* برای حذف محدودیت‌های مرتبط با نسخه ارزیابی، لازم است قبل از استفاده از Aspose.Slides یک لایسنس تنظیم کنید. شما فقط یک بار در هر برنامه یا فرایند نیاز به تنظیم لایسنس دارید.

## **اعمال لایسنس**
یک لایسنس می‌تواند از **فایل**، **جریان** یا **منبع جاسازی‌شده** بارگذاری شود. 

{{% alert color="info" %}}

Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/net/aspose.slides/license) را برای عملیات لایسنس‌گذاری فراهم می‌کند.

{{% /alert %}} 

{{% alert color="warning" %}} 

لایسنس‌های جدید می‌توانند Aspose.Slides را تنها از نسخه 21.4 به بالا فعال کنند. نسخه‌های قبلی از یک سیستم لایسنس متفاوت استفاده می‌کنند و این لایسنس‌ها را شناسایی نمی‌کنند.

{{% /alert %}}

### **فایل**
ساده‌ترین روش تنظیم لایسنس این است که فایل لایسنس را در همان پوشه‌ای که DLL مؤلفه در آن قرار دارد (در Aspose.Slides گنجانده شده) بگذارید و فقط نام فایل را بدون مسیر مشخص کنید.

این کد C# نشان می‌دهد چگونه یک فایل لایسنس تنظیم کنید:

``` csharp
// نمونه‌سازی کلاس License 
Aspose.Slides.License license = new Aspose.Slides.License();

// مسیر فایل مجوز را تنظیم می‌کند
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" %}} 

اگر فایل لایسنس را در مسیر دیگری قرار دهید، هنگام فراخوانی متد [SetLicense](https://reference.aspose.com/slides/fa/net/aspose.slides/license/setlicense/#setlicense_1)، نام فایل لایسنس در انتهای مسیر صریح باید دقیقاً همان نام فایل لایسنس شما باشد.

به‌عنوان مثال، می‌توانید نام فایل لایسنس را به *Aspose.Slides.lic.xml* تغییر دهید. سپس در کد خود باید مسیر کامل به فایل (که به *Aspose.Slides.lic.xml* ختم می‌شود) را به متد [SetLicense](https://reference.aspose.com/slides/fa/net/aspose.slides/license/setlicense/#setlicense_1) پاس بدهید.

{{% /alert %}}

### **جریانی**
می‌توانید لایسنس را از یک جریان بارگذاری کنید. این کد C# نشان می‌دهد چگونه لایسنس را از یک جریان اعمال کنید:

``` csharp
// نمونه‌سازی کلاس License
Aspose.Slides.License license = new Aspose.Slides.License();

// فایل مجوز را به‌عنوان جریان باز می‌کند
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// تنظیم مجوز از طریق یک جریان
license.SetLicense(licenseStream);
```

### **منبع جاسازی‌شده**
می‌توانید لایسنس را همراه برنامه خود بپوشانید (تا از گم شدن جلوگیری کنید) با افزودن لایسنس به عنوان یک منبع جاسازی‌شده در یکی از اسمبلی‌هایی که DLL مؤلفه را فراخوانی می‌کنند (در Aspose.Slides گنجانده شده). 

این روند افزودن فایل لایسنس به عنوان منبع جاسازی‌شده است:

1. در Visual Studio، فایل لایسنس (.lic) را به پروژه اضافه کنید به این صورت: از **File** > **Add Existing Item** > **Add** مرور کنید. 
2. فایل را در **Solution Explorer** انتخاب کنید.
3. در پنجره **Properties**، **Build Action** را روی **Embedded Resource** تنظیم کنید.
4. برای دسترسی به لایسنس جاسازی‌شده در اسمبلی، فایل لایسنس را به عنوان منبع جاسازی‌شده به پروژه اضافه کنید و سپس نام فایل لایسنس را به متد `SetLicense` پاس بدهید. 


کلاس `License` به‌طور خودکار فایل لایسنس را در منابع جاسازی‌شده پیدا می‌کند. نیازی به فراخوانی متدهای `GetExecutingAssembly` و `GetManifestResourceStream` از کلاس `System.Reflection.Assembly` در چارچوب Microsoft .NET ندارید.

این کد C# نشان می‌دهد چگونه یک لایسنس را به عنوان منبع جاسازی‌شده تنظیم کنید:

``` csharp
// نمونه‌سازی کلاس License
Aspose.Slides.License license = new Aspose.Slides.License();

// نام فایل مجوز جاسازی‌شده در اسمبلی را پاس می‌دهد
license.SetLicense("Aspose.Slides.lic");
```

## **اعتبارسنجی لایسنس**

برای بررسی اینکه آیا لایسنس به درستی تنظیم شده است یا نه، می‌توانید آن را اعتبارسنجی کنید. این کد C# نشان می‌دهد چگونه یک لایسنس را اعتبارسنجی کنید:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **ایمنیت در برابر چند رشته‌ای (Thread Safety)**

{{% alert title="Note" color="warning" %}} 

متد [license.SetLicense](https://reference.aspose.com/slides/fa/net/aspose.slides/license/setlicense/) ایمنیت در برابر چند رشته‌ای (thread‑safe) نیست. اگر این متد مجبور باشد همزمان از چندین رشته فراخوانی شود، ممکن است بخواهید از سازوکارهای همگام‌سازی (مانند lock) برای جلوگیری از مشکلات استفاده کنید. 

{{% /alert %}}

## **سوالات متداول (FAQ)**

### آیا می‌توانم لایسنس را در یک محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ نیازی به اتصال به اینترنت نیست.

### پس از پایان دوره یک‌ساله اشتراک چه می‌شود؟ آیا کتابخانه متوقف به کار کردن می‌شود؟

نه. لایسنس دائمی است: می‌توانید از نسخه‌هایی که قبل از تاریخ پایان اشتراک شما منتشر شده‌اند استفاده کنید؛ فقط برای استفاده از نسخه‌های جدیدتر بدون تمدید اشتراک مجاز نخواهید بود.
