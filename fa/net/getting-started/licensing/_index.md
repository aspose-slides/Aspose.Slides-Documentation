## **نمای کلی**

Aspose.Slides را می‌توان در حالت ارزیابی یا با یک لایسنس معتبر استفاده کرد. نسخه ارزیابی همان عملکرد نسخه دارای لایسنس را ارائه می‌دهد، اما یک واترمارک ارزیابی را به هر اسلاید از هر ارائه‌ای که ذخیره می‌کند اضافه می‌کند و متن‌هایی که کد شما از ارائه‌ها می‌خواند کوتاه می‌شود.

این مقاله توضیح می‌دهد که مجوزدهی در Aspose.Slides چگونه کار می‌کند و چگونه قبل از استفاده از کتابخانه یک لایسنس اعمال کنید. می‌توانید لایسنس را با استفاده از کلاس `License` از یک فایل، جریان یا منبع جاسازی‌شده بارگذاری کنید. مقاله همچنین نشان می‌دهد چگونه اعتبارسنجی کنید که آیا لایسنس به‌درستی اعمال شده است یا نه.

## **مجوزدهی در Aspose.Slides**
* نسخهٔ ارزیابی پس از خرید لایسنس و افزودن چند خط کد (برای اعمال لایسنس) به آن، دارای لایسنس می‌شود.
* لایسنس یک فایل XML متنی ساده است که شامل جزئیاتی مانند نام محصول، تعداد توسعه‌دهندگانی که به آن لایسنس داده شده است، تاریخ انقضای اشتراک و غیره می‌باشد.
* فایل لایسنس به‌صورت دیجیتالی امضا شده است، بنابراین نباید آن را تغییر دهید. حتی افزودن تصادفی یک خط جدید به محتوای فایل، آن را نامعتبر می‌کند.
* Aspose.Slides for .NET معمولاً سعی می‌کند لایسنس را در این مکان‌ها پیدا کند:
  * یک مسیر صریح
  * پوشهٔ حاوی dll مؤلفه (شامل در Aspose.Slides)
  * پوشهٔ حاوی اسمبلی که dll مؤلفه را فراخوانی کرده است (شامل در Aspose.Slides)
  * پوشهٔ حاوی اسمبلی ورودی (فایل .exe شما)
  * یک منبع جاسازی‌شده در اسمبلی که dll مؤلفه را فراخوانی کرده است (شامل در Aspose.Slides).
* برای جلوگیری از محدودیت‌های مرتبط با نسخهٔ ارزیابی، باید قبل از استفاده از Aspose.Slides یک لایسنس تنظیم کنید. فقط یک بار برای هر برنامه یا فرایند کافی است لایسنس تنظیم شود.

{{% alert color="info" title="Note" %}}
ممکن است بخواهید [مجوزدهی متری](/slides/fa/net/metered-licensing/) را ببینید.
{{% /alert %}} 

## **اعمال لایسنس**
یک لایسنس می‌تواند از **فایل**، **جریان** یا **منبع جاسازی‌شده** بارگذاری شود. 

{{% alert color="info" title="Note" %}}
Aspose.Slides کلاس [License](https://reference.aspose.com/slides/fa/net/aspose.slides/license) را برای عملیات‌ مجوزدهی فراهم می‌کند.
{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}
لایسنس‌های جدید می‌توانند Aspose.Slides را فقط با نسخهٔ 21.4 یا بالاتر فعال کنند. نسخه‌های قبلی از سیستم مجوزدهی متفاوتی استفاده می‌کنند و این لایسنس‌ها را شناسایی نخواهند کرد.
{{% /alert %}}

### **فایل**
ساده‌ترین روش برای تنظیم لایسنس این است که فایل لایسنس را در همان پوشه‌ای که DLL مؤلفه (شامل در Aspose.Slides) قرار دارد بگذارید و فقط نام فایل را بدون مسیر مشخص کنید.

این کد C# نشان می‌دهد چگونه یک فایل لایسنس تنظیم شود:
``` csharp
// نمونه‌سازی کلاس License 
Aspose.Slides.License license = new Aspose.Slides.License();

// مسیر فایل مجوز را تنظیم می‌کند
license.SetLicense("Aspose.Slides.lic");
```
{{% alert color="warning" title="Warning" %}}
اگر فایل لایسنس را در یک دایرکتوری متفاوت قرار دهید، هنگام فراخوانی متد [SetLicense](https://reference.aspose.com/slides/fa/net/aspose.slides/license/setlicense/#setlicense_1)، نام فایل لایسنس در انتهای مسیر مشخص شده باید همان نام فایل لایسنس شما باشد.

به‌عنوان مثال، می‌توانید نام فایل لایسنس را به *Aspose.Slides.lic.xml* تغییر دهید. سپس در کد خود باید مسیر فایل (که با *Aspose.Slides.lic.xml* پایان می‌یابد) را به متد [SetLicense](https://reference.aspose.com/slides/fa/net/aspose.slides/license/setlicense/#setlicense_1) پاس بدهید.
{{% /alert %}}

### **جریان**
می‌توانید لایسنس را از یک جریان بارگذاری کنید. این کد C# نشان می‌دهد چگونه لایسنس را از یک جریان اعمال کنید:
``` csharp
// نمونه‌سازی کلاس License
Aspose.Slides.License license = new Aspose.Slides.License();

// فایل مجوز را به‌عنوان یک جریان باز می‌کند
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// تنظیم مجوز از طریق یک جریان
license.SetLicense(licenseStream);
```

### **منبع جاسازی‌شده**
می‌توانید لایسنس را به همراه برنامه خود بسط دهید (برای جلوگیری از گم شدن) با افزودن لایسنس به عنوان یک منبع جاسازی‌شده در یکی از اسمبلی‌هایی که DLL مؤلفه (شامل در Aspose.Slides) را فراخوانی می‌کنند.

این روش افزودن فایل لایسنس به‌عنوان منبع جاسازی‌شده است:

1. در Visual Studio، فایل لایسنس (.lic) را به پروژه این‌گونه اضافه کنید: از **File** > **Add Existing Item** > **Add** عبور کنید. 
2. فایل را در **Solution Explorer** انتخاب کنید.
3. در پنجره **Properties**، مقدار **Build Action** را به **Embedded Resource** تنظیم کنید.
4. برای دسترسی به لایسنس جاسازی‌شده در اسمبلی، فایل لایسنس را به‌عنوان منبع جاسازی‌شده به پروژه اضافه کنید و سپس نام فایل لایسنس را به متد `SetLicense` پاس بدهید. 

کلاس `License` به‌طور خودکار فایل لایسنس را در منابع جاسازی‌شده پیدا می‌کند. نیازی به فراخوانی متدهای `GetExecutingAssembly` و `GetManifestResourceStream` کلاس `System.Reflection.Assembly` در چارچوب Microsoft .NET ندارید.

این کد C# نشان می‌دهد چگونه یک لایسنس را به‌عنوان منبع جاسازی‌شده تنظیم کنید:
``` csharp
// نمونه‌سازی کلاس License
Aspose.Slides.License license = new Aspose.Slides.License();

// نام فایل مجوز جاسازی‌شده در اسمبلی را می‌گذارد
license.SetLicense("Aspose.Slides.lic");
```

## **اعتبارسنجی لایسنس**

برای بررسی اینکه آیا لایسنس به‌درستی تنظیم شده است یا نه، می‌توانید آن را اعتبارسنجی کنید. این کد C# نشان می‌دهد چگونه یک لایسنس را اعتبارسنجی کنید:
```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **ایمنی‌نخی**
{{% alert color="warning" title="Warning" %}}
متد [license.SetLicense](https://reference.aspose.com/slides/fa/net/aspose.slides/license/setlicense/) ایمن‌نخ نیست. اگر این متد باید همزمان از چندین نخ فراخوانی شود، ممکن است بخواهید از primitiveهای همگام‌سازی (مانند lock) برای جلوگیری از مشکلات استفاده کنید. 
{{% /alert %}}

## **FAQ**

### آیا می‌توانم لایسنس را در محیط کاملاً آفلاین (بدون دسترسی به اینترنت) اعمال کنم؟

بله. اعتبارسنجی لایسنس به‌صورت محلی با استفاده از فایل لایسنس انجام می‌شود؛ نیازی به اتصال اینترنت نیست.

### پس از پایان اشتراک یک‌ساله چه اتفاقی می‌افتد؟ آیا کتابخانه کار کردن خود را متوقف می‌کند؟

خیر. لایسنس دائمی است: می‌توانید از نسخه‌های منتشرشده قبل از تاریخ پایان اشتراک خود استفاده کنید؛ اما بدون تمدید، قابل استفاده برای نسخه‌های جدیدتر نخواهید بود.
