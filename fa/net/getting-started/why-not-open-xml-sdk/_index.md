## **بررسی کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. Open XML SDK به عنوان کتابخانه‌ای برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن توصیف می‌شود، در حالی که Aspose.Slides به عنوان کتابخانه پردازش ارائه با مدل شیء سطح بالا و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، قابلیت‌های رندر و چاپ، پشتیبانی از پلتفرم و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیده‌تری مانند کار با چندین فرمت PowerPoint، کپی یا تکثیر اشکال، جایگزینی متن، اعمال انیمیشن و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
گاهی این سؤال را می‌شنویم: *چرا باید به جای استفاده از Open XML SDK رایگان، از محصولات Aspose استفاده کنیم؟* 

پاسخ به این سؤال را به‌راحتی می‌توان از نظر ویژگی‌ها و عملکردها داد. 

بر اساس [کتابخانه MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به‌صورت زیر تعریف می‌شود:

> "Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر طرح‌نامه Open XML زیرین درون یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای رایج که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند محصور می‌سازد، به‌طوری که بتوانید عملیات پیچیده را تنها با چند خط کد انجام دهید. اسناد OOXML عملاً فایل‌های XML فشرده هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما امکان کار با محتوای اسناد OOXML را به‌صورت نوع‌دار می‌دهد. به‌جای استخراج فایل برای به‌دست آوردن XML، بارگذاری آن XML در یک درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی را برای این کار فراهم می‌کند."

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانهٔ کلاس است که به برنامه‌ها اجازه می‌دهد این وظایف پردازش ارائه را انجام دهند:

- برنامه‌نویسی با یک مدل شیء ارائه.  
- تبدیل‌های با کیفیت بالا شامل تمام فرمت‌های پشتیبانی‌شدهٔ محبوب ارائه PowerPoint، از جمله تبدیل به PDF، XPS، TIFF و چاپ.  
- تولید تصویر بندانگشتی اسلاید در فرمت‌های شناخته‌شده‌ای مانند PNG، JPEG و BMP به همراه استخراج اسلاید به SVG.  
- ساخت ارائه‌ها از صفر یا با ترکیب عناصر از یک یا چند سند.  
- افزودن انیمیشن‌ها، فریم‌های OLE، جدول‌ها، ایجاد و مدیریت نمودارها.  
- کنترل (کنترل گسترده) و مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.  

برای جزئیات بیشتر دربارهٔ ویژگی‌های موجود، لطفاً صفحهٔ [ویژگی‌های Aspose.Slides](/slides/fa/net/product-overview/) را ببینید.

## **نتیجه‌گیری**
Open XML SDK و Aspose.Slides به‌صورت مستقیم با یکدیگر رقابت نمی‌کنند زیرا نیازهای به‌مراتب متفاوتی را برآورده می‌سازند و مخاطبان متفاوتی دارند. 

{{% alert color="primary" %}} 

Open XML SDK یک کتابخانهٔ کلاس است که روش نوع‌دار قوی برای کار با اسناد OOXML فراهم می‌کند، در حالی که Aspose.Slides یک کتابخانهٔ پردازش ارائه فوق‌العاده مفید است که حمایت عالی برای تقریباً تمام فرمت‌های فایل Microsoft PowerPoint ارائه می‌دهد. 

{{% /alert %}} 

اگر جریان کاری شما یک عملیات برنامه‌نویسی پایه‌ای بر روی سند PPTX باشد، ممکن است Open XML SDK گزینهٔ مناسبی باشد. با Open XML SDK می‌توانید به راحتی وظایف ساده‌ای مانند تولید سند PPTX ساده یا حذف نظرات، سرصفحه/پاصفحه، استخراج تصاویر و غیره را انجام دهید. برخی وظایف می‌توانند با Open XML SDK انجام شوند اما با Aspose.Slides امکان‌پذیر نیستند. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML دارید، باید از Open XML SDK استفاده کنید. 

اگر نیاز به انجام وظایف پیچیده بر روی اسناد دارید—مانند موارد زیر—آنگاه Aspose.Slides بهترین گزینهٔ شماست. 

- عملیات مربوط به فرمت‌های قدیمی PowerPoint (و همچنین PPTX).  
- کپی یا تکثیر اشکال داخل اسلایدها به روشی که اشیاء، سبک‌ها و سایر عناصر قالب‌بندی را به‌صورت مناسب ترکیب کند.  
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.  
- اعمال انیمیشن‌ها و استفاده از کانکتورها با اشکال.  
- تبدیل سند به PDF، TIFF یا XPS به‌طوری که همانند تبدیل Microsoft PowerPoint به نظر برسد.  
- توسعه برنامهٔ .NET یا Java در هر دو محیط دسکتاپ و وب.
