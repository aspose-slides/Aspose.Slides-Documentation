## **بررسی کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. Open XML SDK به‌عنوان کتابخانه‌ای برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن توصیف می‌شود، در حالی که Aspose.Slides به‌عنوان کتابخانهٔ پردازش ارائه با مدل شیء‑سطح بالایی و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس قالب‌های پشتیبانی‌شده، مدل برنامه‌نویسی، رندرینگ، پشتیبانی از پلتفرم و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیدهٔ ارائه مانند کار با چندین فرمت PowerPoint، کپی یا تکثیر اشکال، جایگزینی متن، اعمال انیمیشن‌ها و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
گاهی این سؤال پیش می‌آید: *چرا به جای استفاده از Open XML SDK رایگان، باید از محصولات Aspose استفاده کنیم؟*

پاسخ به این سؤال را به راحتی می‌توان از نظر ویژگی‌ها و کارکردها داد.

بر اساس [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به این شکل تعریف می‌شود:

> "Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر schema زیرین آن‌ها را ساده می‌کند. این SDK بسیاری از وظایف رایجی که توسعه‌دهندگان روی بسته‌های Open XML انجام می‌دهند را در خود گنجانده است، به طوری که بتوانید عملیات پیچیده را تنها با چند خط کد انجام دهید. اسناد OOXML در واقع فایل‌های XML فشرده هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما امکان کار با محتوای اسناد OOXML را به صورت strongly‑typed می‌دهد. به‌عبارت‌دیگر، به‌جای استخراج فایل، بارگذاری XML در درخت DOM و کار مستقیم با عناصر و ویژگی‌های XML، Open XML SDK کلاس‌هایی برای انجام این کارها فراهم می‌کند."

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانهٔ کلاس است که به برنامه‌ها اجازه می‌دهد وظایف پردازش ارائه زیر را انجام دهند:

- برنامه‌نویسی با یک مدل شیء ارائه.
- تبدیل‌های با کیفیت بالا شامل تمام فرمت‌های محبوب پشتیبانی‌شدهٔ PowerPoint، از جمله تبدیل به PDF، XPS و TIFF.
- تولید تصویرهای بندانگشتی اسلاید در قالب‌های شناخته‌شده مانند PNG، JPEG و BMP به‌همراه خروجی اسلاید به SVG.
- ساخت ارائه‌ها از صفر یا ترکیب عناصر از یک یا چند سند.
- افزودن انیمیشن‌ها، فریم‌های OLE، جداول، ایجاد و مدیریت نمودارها.
- کنترل (کنترل گسترده) و مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر دربارهٔ ویژگی‌های موجود، لطفاً صفحهٔ [Aspose.Slides Features](/slides/fa/net/product-overview/) را ببینید.

| :- | :- | :- |

|برنامه‌نویسی دقیق با یک مدل شیء سند؛ دسترسی به عناصر فردی و قالب‌بندی مانند TextHolders، TextFrames، Paragraphs و Portions.|Yes|Yes|
|دسترسی مستقیم و کامل به عناصر XML زیرین و ویژگی‌ها مانند شناسه‌های رابطه‌، شناسه‌های فهرست یک سند OOXML.|Yes|No|

## **نتیجه‌گیری**
Open XML SDK و Aspose.Slides به‌طور مستقیم با یکدیگر رقابت نمی‌کنند زیرا نیازهای بسیار متفاوتی را برآورده می‌سازند و مخاطبان متفاوتی دارند.

{{% alert color="info" %}} 

Open XML SDK یک کتابخانهٔ کلاس است که روش strongly‑typed برای کار با اسناد OOXML فراهم می‌کند، در حالی که Aspose.Slides یک کتابخانهٔ پردازش ارائه فوق‌العاده مفید است که پشتیبانی عالی از تقریباً تمام فرمت‌های فایل Microsoft PowerPoint را ارائه می‌دهد. 

{{% /alert %}} 

اگر جریان کار شما یک عملیات برنامه‌نویسی پایه‌ای روی یک سند PPTX باشد، Open XML SDK می‌تواند گزینهٔ مناسبی باشد. با Open XML SDK باید بتوانید کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرصفحات/پانوشت‌ها، استخراج تصاویر و غیره را انجام دهید. برخی وظایف می‌توانند با Open XML SDK انجام شوند ولی با Aspose.Slides امکان‌پذیر نیستند. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و ویژگی‌های XML یک سند OOXML دارید، باید از Open XML SDK استفاده کنید.

اگر نیاز به انجام کارهای پیچیده روی اسناد دارید — مانند موارد زیر — Aspose.Slides گزینهٔ بهترین شماست.

- عملیات مرتبط با فرمت‌های قدیمی PowerPoint (و همچنین PPTX).
- کپی یا تکثیر اشکال داخل اسلایدها به‑صورتی که اشیاء، سبک‌ها و سایر عناصر قالب‌بندی به‌صورت مناسب ترکیب شوند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از کانکتورها با اشکال.
- تبدیل سند به PDF، TIFF یا XPS به‌گونه‌ای که گویی Microsoft PowerPoint تبدیل را انجام داده است.
- توسعهٔ برنامهٔ .NET یا Java در هر دو محیط دسکتاپ و وب.
