## **بررسی کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. Open XML SDK را به‌عنوان کتابخانه‌ای برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن توصیف می‌کند، در حالی که Aspose.Slides به‌عنوان کتابخانه‌ای برای پردازش ارائه‌ها با مدل شیء سطح بالا و پشتیبانی از بسیاری از کارهای مربوط به PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، قابلیت‌های رندرینگ و چاپ، پشتیبانی از پلتفرم‌ها و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات‌های پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای کارهای پیچیده ارائه مثل کار با فرمت‌های متعدد PowerPoint، کپی یا کلون‌سازی اشکال، جایگزینی متن، اعمال انیمیشن و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
گاهی این سؤال پیش می‌آید: *چرا باید به‌جای Open XML SDK رایگان از محصولات Aspose استفاده کنیم؟*

پاسخ به این سؤال را می‌توان به‌سادگی از نظر ویژگی‌ها و عملکردها داد.

بر اساس [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به‌این شکل تعریف می‌شود:

> "Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر اسکیمای Open XML زیرین یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای رایج که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند را در بر می‌گیرد، به‌طوری که بتوانید عملیات‌های پیچیده را فقط با چند خط کد انجام دهید. اسناد OOXML در اصل فایل‌های XML فشرده شده هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به‌صورت strongly‑typed به شما امکان کار با محتوای اسناد OOXML را می‌دهد. به‌عبارت دیگر، به‌جای از‑فشردن یک فایل برای استخراج XML، بارگذاری آن XML در یک درخت DOM و کار مستقیم با عناصر و صفات XML، Open XML SDK کلاس‌هایی را برای انجام این کارها فراهم می‌کند."

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانه کلاسی است که به برنامه‌ها امکان انجام این وظایف پردازش ارائه را می‌دهد:

- برنامه‌نویسی با مدل شیء ارائه.
- تبدیل‌های با کیفیت بالا شامل تمام فرمت‌های محبوب پشتیبانی‌شده PowerPoint، از جمله تبدیل به PDF، XPS، TIFF و چاپ.
- تولید تصویرهای بندانگشتی اسلاید در فرمت‌های شناخته‌شده مانند PNG، JPEG و BMP همراه با صادر کردن اسلاید به SVG.
- ساخت ارائه‌ها از ابتدا یا ترکیب عناصر از یک یا چند سند.
- افزودن انیمیشن‌ها، فریم‌های OLE، جدول‌ها، ایجاد و مدیریت نمودارها.
- کنترل (کنترل گسترده) و مدیریت فرمت‌بندی متن در سطوح TextFrames، Paragraphs و Portions.

برای جزئیات بیشتر درباره ویژگی‌های موجود، لطفاً صفحه [Aspose.Slides Features](/slides/fa/net/product-overview/) را ببینید.

این جدول قابلیت‌ها و ویژگی‌های Open XML SDK را با Aspose.Slides مقایسه می‌کند.

|**ویژگی یا دسته ویژگی**|**Open XML SDK**|**Aspose.Slides**|
| :- | :- | :- |
|فرمت‌های ارائه پشتیبانی‌شده|PPTX|PPT, POT, PPS, PPTX, POTX, PPSX, ODP|
|تبدیل از PPT به PPTX|No|Yes|
|<p>برنامه‌نویسی سطح بالا با مدل شیء سند ارائه (DOM): </p><p>- جستجو و جایگزینی متن.</p><p>- ترکیب اسلایدها در ارائه‌ها.</p>|No|Yes|
|برنامه‌نویسی دقیق با مدل شیء سند؛ دسترسی به عناصر و قالب‌بندی‌های فردی مانند TextHolders، TextFrames، Paragraphs و Portions.|Yes|Yes|
|دسترسی مستقیم و کامل به عناصر و صفات XML زیرین مانند شناسه‌های رابطه، شناسه‌های لیست یک سند OOXML.|Yes|No|
|<p>رندرینگ و چاپ:</p><p>- رندرینگ ارائه‌ها به PDF، PDF Notes، XPS، تصاویر TIFF.</p><p>- رندرینگ تصویرهای بندانگشتی اسلاید به PNG، JPEG، BMP، SVG و TIFF.</p><p>- تعیین رزولوشن تصویر، کیفیت، فشرده‌سازی و گزینه‌های دیگر.</p><p>- چاپ ارائه‌ها با استفاده از زیرساخت چاپ .NET. این مؤلفه متد چاپ داخلی دارد که ارائه‌ها را همان‌گونه که در Print Preview مایکروسافت PowerPoint نمایش داده می‌شود چاپ می‌کند.</p>|No|Yes|
|پلتفرم‌های پشتیبانی‌شده|Windows, .NET|Windows, Linux, Java, .NET, Mono|

## **نتیجه‌گیری**
Open XML SDK و Aspose.Slides به‌صورت مستقیم رقابت نمی‌کنند زیرا نیازهای بسیار متفاوتی را برآورده می‌سازند و مخاطبان متفاوتی دارند.

{{% alert color="info" %}} 

Open XML SDK یک کتابخانه کلاسی است که روش strongly‑typed برای کار با اسناد OOXML فراهم می‌کند، در حالی که Aspose.Slides یک کتابخانه پردازش ارائه فوق‌العاده مفید است که پشتیبانی عالی برای تقریباً تمام فرمت‌های فایل Microsoft PowerPoint را ارائه می‌دهد. 

{{% /alert %}} 

اگر جریان کار شما یک عملیات برنامه‌نویسی پایه‌ای بر روی یک سند PPTX باشد، Open XML SDK می‌تواند گزینهٔ مناسبی باشد. با Open XML SDK باید بتوانید کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرصفحه/پابرگ، استخراج تصاویر یا موارد مشابه را انجام دهید. برخی کارها می‌توانند با Open XML SDK انجام شوند ولی با Aspose.Slides قابل انجام نیستند. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و صفات XML یک سند OOXML دارید، باید از Open XML SDK استفاده کنید.

اگر نیاز به انجام کارهای پیچیده روی اسناد دارید — همان‌طور که در فهرست زیر آمده است — Aspose.Slides گزینهٔ بهترین شماست.

- عملیات مربوط به فرمت‌های قدیمی PowerPoint (و PPTX نیز).
- کپی یا کلون‌سازی اشکال داخل اسلایدها به‌طریقی که اشیاء، سبک‌ها و سایر عناصر قالب‌بندی را به‑صورت مناسب ترکیب کند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن‌ها و استفاده از کانکتورها با اشکال.
- تبدیل سند به PDF، TIFF یا XPS به‌گونه‌ای که همان‌طور که Microsoft PowerPoint تبدیل می‌کرد، به‌نظر برسد.
- توسعه برنامهٔ .NET یا Java در هر دو محیط دسکتاپ و وب.
