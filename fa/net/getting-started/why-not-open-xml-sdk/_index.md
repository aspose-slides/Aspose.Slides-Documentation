## **نمای کلی**

این مقاله توضیح می‌دهد که چه زمانی توسعه‌دهندگان ممکن است Open XML SDK یا Aspose.Slides را برای کار با اسناد ارائه انتخاب کنند. Open XML SDK به عنوان یک کتابخانه برای دستکاری بسته‌های OOXML و عناصر XML زیرین آن توصیف می‌شود، در حالی که Aspose.Slides به عنوان یک کتابخانه پردازش ارائه با مدل شیء سطح بالا و پشتیبانی از بسیاری از وظایف مرتبط با PowerPoint معرفی می‌شود.

مقاله هر دو گزینه را بر اساس فرمت‌های پشتیبانی‌شده، مدل برنامه‌نویسی، رندر، پشتیبانی پلتفرم و موارد استفاده رایج مقایسه می‌کند. همچنین روشن می‌کند که Open XML SDK ممکن است برای عملیات پایه‌ای PPTX یا دسترسی مستقیم به عناصر OOXML مناسب باشد، در حالی که Aspose.Slides برای وظایف پیچیدهٔ ارائه مانند کار با چندین فرمت PowerPoint، کپی یا کلون کردن اشکال، جایگزینی متن، اعمال انیمیشن‌ها و تبدیل ارائه‌ها به PDF، TIFF یا XPS مناسب‌تر است.

## **Open XML SDK چیست؟**
گاهی این سؤال را می‌شنویم: *چرا باید به جای Open XML SDK رایگان از محصولات Aspose استفاده کنیم؟*

پاسخ این سؤال برای ما به لحاظ ویژگی‌ها و قابلیت‌ها آسان است.

بر اساس [MSDN Library](https://learn.microsoft.com/en-us/office/open-xml/open-xml-sdk)، Open XML SDK به این شکل تعریف شده است:

> "Open XML SDK 2.0 کار دستکاری بسته‌های Open XML و عناصر اسکیمای Open XML زیرین یک بسته را ساده می‌کند. Open XML SDK 2.0 بسیاری از کارهای رایجی که توسعه‌دهندگان روی بسته‌های Open XML انجام می‌دهند، محصور می‌کند، به طوری که بتوانید عملیات پیچیده را تنها با چند خط کد انجام دهید. اسناد OOXML اساساً فایل‌های فشردهٔ XML هستند و Open XML SDK مجموعه‌ای از کلاس‌هاست که به شما اجازه می‌دهد محتویات اسناد OOXML را به‌صورت قوی‌تایپی کار کنید. به این معنی که به‌جای استخراج فایل برای به‌دست آوردن XML، بارگذاری آن XML در یک درخت DOM و کار مستقیم با عناصر و صفات XML، Open XML SDK کلاس‌هایی برای انجام این کارها فراهم می‌کند."

## **Aspose.Slides چیست؟**
Aspose.Slides یک کتابخانهٔ کلاسی است که به برنامه‌ها اجازه می‌دهد این وظایف پردازش ارائه را انجام دهند:

- برنامه‌نویسی با یک مدل شیء ارائه.
- تبدیل‌های با کیفیت بالا که شامل تمام فرمت‌های محبوب پشتیبانی‌شده PowerPoint می‌شود، از جمله تبدیل به PDF، XPS و TIFF.
- تولید تصویرهای کوچک اسلاید در قالب‌های شناخته‌شده مانند PNG، JPEG و BMP به همراه استخراج اسلاید به SVG.
- ساخت ارائه‌ها از صفر یا با ترکیب عناصر از یک یا چند سند.
- اضافه‌کردن انیمیشن‌ها، فریم‌های OLE، جداول، ساخت و مدیریت نمودارها.
- کنترل (کنترلی گسترده) و مدیریت قالب‌بندی متن در سطوح TextFrames، Paragraph و Portion.

برای جزئیات بیشتر درباره ویژگی‌های موجود، لطفاً صفحه [Aspose.Slides Features](/slides/fa/net/product-overview/) را ببینید.

| :- | :- | :- |
|فرمت‌های ارائهٔ پشتیبانی‌شده|PPTX|PPT, POT, PPS, PPTX, POTX, PPSX, ODP|
|تبدیل از PPT به PPTX |No|Yes|
|<p>برنامه‌نویسی سطح بالا با یک شیء مدلسازی سند ارائه (DOM): </p><p>- یافتن و جایگزینی متن‌ها.</p><p>- ترکیب اسلایدها در ارائه‌ها.</p>|No|Yes|
|برنامه‌نویسی دقیق با یک مدل شیء سند؛ دسترسی به عناصر فردی و قالب‌بندی‌هایی مانند TextHolders، TextFrames، Paragraph و Portions.|Yes|Yes|
|دسترسی مستقیم و کامل سطح پایین به عناصر و صفات XML زیرین مانند شناسه‌های رابطه، شناسه‌های لیست یک سند OOXML.|Yes|No|

|پلتفرم‌های پشتیبانی‌شده|Windows, .NET|Windows, Linux, Java, .NET, Mono|

## **نتیجه‌گیری**
Open XML SDK و Aspose.Slides به‌صورت مستقیم با یکدیگر رقابت نمی‌کنند زیرا نیازهای متفاوتی را برآورده می‌سازند و مخاطبان متفاوتی دارند.

{{% alert color="info" title="Note" %}}
Open XML SDK یک کتابخانهٔ کلاسی است که روش قوی‌تایپی برای کار با اسناد OOXML فراهم می‌کند، در حالی که Aspose.Slides یک کتابخانهٔ پردازش ارائهٔ بسیار مفید است که پشتیبانی عالی از تقریباً تمام فرمت‌های فایل Microsoft PowerPoint را ارائه می‌دهد.
{{% /alert %}}

اگر گردش کار شما یک عملیات برنامه‌نویسی پایه‌ای بر روی یک سند PPTX باشد، Open XML SDK می‌تواند گزینهٔ مناسب باشد. با Open XML SDK می‌توانید کارهای ساده‌ای مانند تولید یک سند PPTX ساده یا حذف نظرات، سرصفحه/پاصفحه، استخراج تصاویر یا موارد مشابه را به راحتی انجام دهید. برخی کارها می‌توانند با Open XML SDK انجام شوند ولی با Aspose.Slides قابل انجام نیستند. برای مثال، اگر نیاز به دسترسی مستقیم به عناصر و صفات XML یک سند OOXML دارید، باید از Open XML SDK استفاده کنید.

اگر نیاز به انجام کارهای پیچیده روی اسناد دارید—مانند موارد زیر—آنگاه Aspose.Slides بهترین گزینهٔ شماست.

- عملیات مربوط به فرمت‌های قدیمی PowerPoint (و PPTX نیز).
- کپی یا کلون کردن اشکال داخل اسلایدها به‌گونه‌ای که اشیاء، سبک‌ها و سایر عناصر قالب‌بندی به‌طور مناسب ترکیب شوند.
- جایگزینی متن قالب‌بندی‌شده یا بدون قالب‌بندی.
- اعمال انیمیشن و استفاده از کانکتورهای بین اشکال.
- تبدیل یک سند به PDF، TIFF یا XPS به‌گونه‌ای که گویی Microsoft PowerPoint تبدیل را انجام داده است.
- توسعهٔ برنامهٔ .NET یا Java در هر دو محیط دسکتاپ و وب.
