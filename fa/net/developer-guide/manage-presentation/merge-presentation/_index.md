## **بررسی کلی**

Aspose.Slides به شما امکان می‌دهد ارائه‌ها را با کپی کردن اسلایدها از یک ارائه به ارائه دیگر ترکیب کنید. این مقاله نحوه ترکیب کل ارائه‌ها یا اسلایدهای انتخابی، استفاده از اسلاید‑مستر یا چیدمان خاص در حین ترکیب، مدیریت ارائه‌هایی با اندازه اسلاید متفاوت، و افزودن اسلایدهای ترکیب‌شده به یک بخش ارائه را توضیح می‌دهد. همچنین نکات عملی مرتبط با محتوای ترکیب‌شده، از جمله یادداشت‌های سخنران، نظرات، پرونده‌های منبع دارای رمز عبور و استفاده از نخ‌ها را پوشش می‌دهد.

## **بهینه‌سازی ترکیب ارائه‌ها**

با استفاده از [Aspose.Slides for .NET](https://products.aspose.com/slides/fa/net/)، به راحتی ارائه‌های PowerPoint را ترکیب کنید در حالی که سبک‌ها، چیدمان‌ها و همه عناصر حفظ می‌شوند. برخلاف ابزارهای دیگر، Aspose.Slides ارائه‌ها را بدون کاهش کیفیت یا از دست رفتن داده‌ها ترکیب می‌کند. کل ارائه‌ها، اسلایدهای خاص و حتی فرمت‌های مختلف فایل (PPT به PPTX و غیره) را ترکیب کنید.

- **ترکیب کل ارائه:** تمام اسلایدها را در یک فایل واحد جمع‌آوری کنید.

### **گزینه‌های ترکیب**

می‌توانید گزینه‌هایی اعمال کنید که تعیین می‌کند آیا

* هر اسلاید در ارائهٔ خروجی سبک منحصر به‌فرد خود را حفظ می‌کند
* یک سبک خاص برای تمام اسلایدهای ارائهٔ خروجی استفاده می‌شود. 

برای ترکیب ارائه‌ها، Aspose.Slides متدهای [AddClone](https://reference.aspose.com/slides/fa/net/aspose.slides/islidecollection/methods/addclone) را (از رابط [ISlideCollection](https://reference.aspose.com/slides/fa/net/aspose.slides/islidecollection)) ارائه می‌دهد. چندین پیاده‌سازی از متدهای `AddClone` وجود دارد که پارامترهای فرآیند ترکیب ارائه را تعریف می‌کند. هر شیء Presentation یک کالکشن [Slides](https://reference.aspose.com/slides/fa/net/aspose.slides/presentation/properties/slides) دارد، لذا می‌توانید متد `AddClone` را از ارائه‌ای که می‌خواهید اسلایدها به آن ترکیب شوند، فراخوانی کنید. 

متد `AddClone` یک شیء `ISlide` برمی‌گرداند که یک کپی از اسلاید منبع است. اسلایدهای یک ارائهٔ خروجی به سادگی کپی‌ای از اسلایدهای منبع هستند. بنابراین می‌توانید بدون نگرانی از تأثیر بر ارائه‌های منبع، تغییراتی مانند اعمال سبک‌ها یا گزینه‌های قالب‌بندی یا چیدمان‌ها را بر اسلایدهای نتیجـه‌گیری اعمال کنید. 

## **ترکیب ارائه‌ها** 

Aspose.Slides متد [**AddClone (ISlide)**](https://reference.aspose.com/slides/fa/net/aspose.slides/islidecollection/methods/addclone) را ارائه می‌دهد که به شما اجازه می‌دهد اسلایدها را ترکیب کنید در حالی که اسلایدها چیدمان و سبک‌های خود را حفظ می‌کنند (پارامترهای پیش‌فرض). 

این کد C# نشان می‌دهد چگونه ارائه‌ها را ترکیب کنید:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    foreach (ISlide slide in pres2.Slides)
    {
        pres1.Slides.AddClone(slide);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

## **ترکیب ارائه‌ها با اسلاید‑مستر**

Aspose.Slides متد [**AddClone (ISlide, IMasterSlide, Boolean)**](https://reference.aspose.com/slides/fa/net/aspose.slides.islidecollection/addclone/methods/2) را فراهم می‌کند که به شما اجازه می‌دهد اسلایدها را ترکیب کنید در حالی که یک الگو (اسلاید‑مستر) به آنها اعمال می‌شود. به این ترتیب، در صورت نیاز می‌توانید سبک اسلایدهای ارائهٔ خروجی را تغییر دهید. 

این کد C# عملیات توضیح‌داده‌شده را نشان می‌دهد:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    foreach (ISlide slide in pres2.Slides)
    {
        pres1.Slides.AddClone(slide, pres2.Masters[0], allowCloneMissingLayout: true);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

{{% alert title="یادداشت" color="warning" %}} 

چیدمان اسلاید برای اسلاید‑مستر به‌صورت خودکار تعیین می‌شود. وقتی چیدمان مناسب امکان‌پذیر نباشد و پارامتر بولی `allowCloneMissingLayout` متد `AddClone` روی true تنظیم باشد، چیدمان اسلاید منبع استفاده می‌شود. در غیر این‌صورت، استثنای [PptxEditException](https://reference.aspose.com/slides/fa/net/aspose.slides/pptxeditexception) پرتاب می‌شود. 

{{% /alert %}}

اگر می‌خواهید اسلایدهای ارائهٔ خروجی چیدمان متفاوتی داشته باشند، به جای آن از متد [AddClone (ISlide, ILayoutSlide)](https://reference.aspose.com/slides/fa/net/aspose.slides.islidecollection/addclone/methods/1) هنگام ترکیب استفاده کنید. 

## **ترکیب اسلایدهای خاص از ارائه‌ها**

ترکیب اسلایدهای خاص از چندین ارائه برای ساخت مجموعه اسلایدهای سفارشی کاربرد دارد. Aspose.Slides for .NET به شما اجازه می‌دهد فقط اسلایدهای مورد نیاز را انتخاب و وارد کنید. API قالب‌بندی، چیدمان و طراحی اسلایدهای اصلی را حفظ می‌کند.

کد C# زیر یک ارائهٔ جدید ایجاد می‌کند، اسلایدهای عنوان را از دو ارائه دیگر اضافه می‌کند و نتیجه را در فایلی ذخیره می‌نماید:

```cs
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation presentation = new Presentation())
using (Presentation presentation1 = new Presentation("presentation1.pptx"))
using (Presentation presentation2 = new Presentation("presentation2.pptx"))
{
    presentation.Slides.RemoveAt(0);

    ISlide slide1 = GetTitleSlide(presentation1);

    if (slide1 != null)
        presentation.Slides.AddClone(slide1);

    ISlide slide2 = GetTitleSlide(presentation2);

    if (slide2 != null)
        presentation.Slides.AddClone(slide2);

    presentation.Save("combined.pptx", SaveFormat.Pptx);
}

static ISlide GetTitleSlide(IPresentation presentation)
{
    foreach (ISlide slide in presentation.Slides)
    {
        if (slide.LayoutSlide.LayoutType == SlideLayoutType.Title)
        {
            return slide;
        }
    }
    return null;
}
```
```cs
using Aspose.Slides;

static ISlide GetTitleSlide(IPresentation presentation)
{
    foreach (ISlide slide in presentation.Slides)
    {
        if (slide.LayoutSlide.LayoutType == SlideLayoutType.Title)
        {
            return slide;
        }
    }
    return null;
}
```

## **ترکیب ارائه‌ها با چیدمان اسلاید**

این کد C# نشان می‌دهد چگونه اسلایدها را از ارائه‌ها ترکیب کنید در حالی که چیدمان دلخواه خود را بر روی آنها اعمال می‌کنید تا یک ارائهٔ خروجی به دست آورید:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    foreach (ISlide slide in pres2.Slides)
    {
        pres1.Slides.AddClone(slide, pres2.LayoutSlides[0]);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

## **ترکیب ارائه‌ها با اندازه اسلایدهای متفاوت**

{{% alert title="یادداشت" color="warning" %}} 

ترکیب ارائه‌هایی با اندازه اسلاید متفاوت خطایی ایجاد نمی‌کند، اما اسلایدهای ترکیب‌شده اندازه اسلاید هدف را می‌پذیرند در حالی که اشکال آنها موقعیت و اندازه اصلی خود را حفظ می‌کنند؛ بنابراین محتوا ممکن است جابجا یا خارج از محدوده اسلاید شود. 

{{% /alert %}}

برای ترکیب 2 ارائه با اندازه اسلاید متفاوت و حفظ صحیح محتوا، یکی از ارائه‌ها را طوری تغییر اندازه دهید که به اندازهٔ ارائهٔ دیگر منطبق شود. 

این نمونه کد عملیات توصیف‌شده را نشان می‌دهد:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
   pres2 = new Presentation("pres2.pptx"))
{
   pres2.SlideSize.SetSize(pres1.SlideSize.Size.Width, pres1.SlideSize.Size.Height, SlideSizeScaleType.EnsureFit);
 
   foreach (ISlide slide in pres2.Slides)
   {
       pres1.Slides.AddClone(slide);
   }
 
   pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

## **ترکیب اسلایدها به یک بخش ارائه**

این کد C# نشان می‌دهد چگونه یک اسلاید خاص را به یک بخش در ارائه ترکیب کنید:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres1 = new Presentation("pres1.pptx"),
    pres2 = new Presentation("pres2.pptx"))
{
    for (var index = 0; index < pres2.Slides.Count; index++)
    {
        ISlide slide = pres2.Slides[index];
        pres1.Slides.AddClone(slide, pres1.Sections[0]);
    }

    pres1.Save("combined.pptx", SaveFormat.Pptx);
}
```

اسلاید در انتهای بخش اضافه می‌شود.

## **سوالات متداول**

### آیا یادداشت‌های سخنران در زمان ترکیب حفظ می‌شوند؟

بله. هنگام کپی کردن اسلایدها، Aspose.Slides تمام عناصر اسلاید از جمله یادداشت‌ها، قالب‌بندی و انیمیشن‌ها را منتقل می‌کند.

### آیا نظرات و نویسندگان آن‌ها منتقل می‌شوند؟

نظرات به عنوان بخشی از محتوای اسلاید کپی می‌شوند. برچسب‌های نویسندهٔ نظر به عنوان شیء نظر در ارائهٔ حاصل حفظ می‌شوند.

### اگر ارائهٔ منبع دارای رمز عبور باشد چه می‌شود؟

باید با استفاده از [LoadOptions.Password](https://reference.aspose.com/slides/fa/net/aspose.slides/loadoptions/password/) و [باز کردن با رمز عبور](/slides/fa/net/password-protected-presentation/) باز شود؛ پس از بارگذاری، می‌توان آن اسلایدها را با امنیت به یک پروندهٔ هدف بدون رمز یا حتی دارای رمز کپی کرد.

### عملیات ترکیب تا چه حد ایمن برای استفاده در چندنخی است؟

از استفاده هم‌زمان از یک شیء [Presentation](https://reference.aspose.com/slides/fa/net/aspose.slides/presentation/) در [چندین نخ](/slides/fa/net/multithreading/) خودداری کنید. قانون پیشنهادی «یک سند — یک نخ» است؛ می‌توانید فایل‌های مختلف را به‌صورت موازی در نخ‌های جداگانه پردازش کنید.
