## **مقدمه**

Aspose.Slides for .NET ابزارهای جامع برای تنظیم اندازه اسلاید و نسبت عرض به ارتفاع در ارائه‌های PowerPoint فراهم می‌کند، که برای چاپ و نمایش روی صفحه نمایش اهمیت دارد.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **استاندارد (نسبت 4:3)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **ویدئوسکین (نسبت 16:9)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

اطمینان حاصل کنید که در سراسر ارائه یک اندازه اسلاید و نسبت عرض به ارتفاع واحد باشد. برای نتایج بهینه، ابعاد اسلاید را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="primary" %}} 
به‌طور پیش‌فرض، ارائه‌های ساخته‌شده با Aspose.Slides از نسبت استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

## **چگونه اندازه اسلاید را در یک ارائه تغییر دهیم**

این مثال نشان می‌دهد که چگونه اندازه اسلاید یک ارائه را با Aspose.Slides در C# تغییر دهید:

```csharp
using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **مشخص کردن اندازه‌های اسلاید سفارشی**

تنظیم اندازه اسلاید بر اساس نیازهای خاص شما، مانند قالب‌بندی‌های کاغذی منحصر به فرد یا مشخصات صفحه نمایش، می‌تواند مفید باشد. در اینجا نحوه تنظیم اندازه اسلاید سفارشی با Aspose.Slides for .NET آورده شده است:

```csharp
using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازهٔ کاغذ A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه، ممکن است محتوای اسلاید دچار تخریب شود. می‌توانید کنترل کنید که Aspose.Slides چگونه این تغییر اندازه را مدیریت کند:

- **`DoNotScale`**: اشیاء را با اندازه‌های اصلی حفظ می‌کند تا از مقیاس‌بندی جلوگیری شود.
- **`EnsureFit`**: اشیاء را برای مطابق شدن با اسلایدهای کوچکتر مقیاس می‌کند، تا از از دست رفتن محتوا جلوگیری شود.
- **`Maximize`**: اشیاء را برای سازگاری با اسلایدهای بزرگتر بزرگ می‌کند تا سازگاری ظاهری حفظ شود.

مثال استفاده از تنظیم `Maximize` برای تنظیم اندازه اسلاید:

```csharp
using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **سوالات متداول**

**آیا می‌توانم اندازه اسلاید سفارشی را با واحدهایی غیر از اینچ (مثلاً نقاط یا میلی‌متر) تنظیم کنم؟**

بله. Aspose.Slides به‌صورت داخلی از نقاط استفاده می‌کند، به‌طوری که 1 نقطه برابر 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقاط تبدیل کنید و از مقادیر تبدیل‌شده برای تعریف عرض و ارتفاع اسلاید استفاده کنید.

**آیا یک اندازه اسلاید سفارشی بسیار بزرگ بر عملکرد و مصرف حافظه هنگام رندرینگ تأثیر می‌گذارد؟**

بله. ابعاد بزرگتر اسلاید (به نقاط) همراه با مقیاس رندرینگ بالاتر باعث افزایش مصرف حافظه و زمان پردازش می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

**آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی که اندازه‌های متفاوتی دارند ترکیب کنم؟**

نمی‌توانید [merge presentations](/slides/fa/net/merge-presentation/) را زمانی که اندازه اسلایدهای متفاوت دارند، انجام دهید — ابتدا یک ارائه را به اندازهٔ دیگری تغییر اندازه دهید. هنگام تغییر اندازه اسلاید، می‌توانید انتخاب کنید که محتوای موجود چگونه مدیریت شود از طریق گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/net/aspose.slides/slidesizescaletype/). پس از تطبیق اندازه‌ها، می‌توانید اسلایدها را ترکیب کنید و قالب‌بندی را حفظ کنید.

**آیا می‌توانم برای اشکال فردی یا مناطق خاصی از اسلاید تصویرهای کوچک (thumbnail) تولید کنم و آیا آن‌ها اندازهٔ جدید اسلاید را رعایت می‌کنند؟**

بله. Aspose.Slides می‌تواند تصویرهای کوچک برای [entire slides](https://reference.aspose.com/slides/fa/net/aspose.slides/slide/getimage/) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/net/aspose.slides/shape/getimage/) رندر کند. تصاویر تولید شده ابعاد و نسبت عرض به ارتفاع فعلی اسلاید را منعکس می‌کنند و قاب و هندسهٔ سازگار را تضمین می‌کنند.
