## **مقدمه**

Aspose.Slides for .NET ابزارهای جامعی را برای تنظیم اندازه اسلاید و نسبت تصویر در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه‌نمایش هر دو حائز اهمیت است.

اندازه‌ها و نسبت‌های رایج اسلاید:

- **Standard (4:3 Aspect Ratio)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **Widescreen (16:9 Aspect Ratio)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

اطمینان حاصل کنید که تمام اسلایدهای ارائه شما از یک اندازه اسلاید و نسبت تصویر استفاده می‌کنند. برای دست‌یابی به نتایج بهینه، ابعاد اسلاید را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" %}} 
به‌صورت پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت تصویر استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

## **چگونه اندازه اسلاید را در یک ارائه تغییر دهیم**

این مثال، تغییر اندازه اسلاید یک ارائه را با Aspose.Slides در C# نشان می‌دهد:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **تعیین اندازه‌های سفارشی اسلاید**

تنظیم اندازه اسلاید بر اساس نیازهای خاص شما، مانند طرح‌بندی‌های خاص کاغذ یا مشخصات صفحه‌نمایش، می‌تواند مفید باشد. در اینجا نحوه تنظیم اندازه سفارشی اسلاید با Aspose.Slides for .NET آمده است:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه، محتویات اسلاید ممکن است دچار اعوجاج شوند. می‌توانید نحوهٔ مدیریت این تغییر اندازه توسط Aspose.Slides را کنترل کنید:

- **`DoNotScale`**: نگه داشتن اشیاء با اندازهٔ اولیه برای جلوگیری از مقیاس‌بندی.
- **`EnsureFit`**: مقیاس‌بندی اشیاء برای متناسب شدن با اسلایدهای کوچکتر، جلوگیری از از دست رفتن محتوا.
- **`Maximize`**: بزرگ‌نمایی اشیاء برای سازگاری با اسلایدهای بزرگتر به منظور حفظ یکپارچگی ظاهری.

مثال استفاده از تنظیم `Maximize` برای تنظیم اندازه اسلاید:

```csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **پرسش‌های متداول**

### آیا می‌توانم اندازهٔ سفارشی اسلاید را با واحدهای دیگر غیر از اینچ (مثلاً نقاط یا میلی‌متر) تنظیم کنم؟

بله. Aspose.Slides به‌صورت داخلی از نقاط استفاده می‌کند که 1 نقطه برابر با 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقاط تبدیل کرده و مقادیر تبدیل‌شده را برای تعیین عرض و ارتفاع اسلاید به کار ببرید.

### آیا اندازهٔ سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه در زمان رندر تأثیر می‌گذارد؟

بله. ابعاد بزرگ‌تر اسلاید (به نقاط) همراه با مقیاس رندر بالاتر منجر به مصرف حافظه بیشتر و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازهٔ اسلایدی عملی انتخاب کنید و مقیاس رندر را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

### آیا می‌توانم یک اندازهٔ اسلاید غیر‌استاندارد تعریف کنم و سپس اسلایدها را از ارائه‌هایی با اندازه‌های متفاوت ادغام کنم؟

شما نمی‌توانید [merge presentations](/slides/fa/net/merge-presentation/) را وقتی اندازهٔ اسلایدها متفاوت است انجام دهید — ابتدا یک ارائه را برای تطبیق با دیگری دوباره اندازه‌بندی کنید. هنگام تغییر اندازهٔ اسلاید، می‌توانید نحوهٔ مدیریت محتوای موجود را با گزینهٔ [SlideSizeScaleType](https://reference.aspose.com/slides/fa/net/aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هماهنگ‌سازی اندازه‌ها، می‌توانید اسلایدها را ادغام کنید و قالب‌بندی را حفظ نمایید.

### آیا می‌توانم تصویرهای بندانگشتی برای اشکال منفرد یا نواحی خاصی از اسلاید تولید کنم و آیا این تصاویر اندازهٔ جدید اسلاید را رعایت می‌کنند؟

بله. Aspose.Slides می‌تواند تصویرهای بندانگشتی برای [entire slides](https://reference.aspose.com/slides/fa/net/aspose.slides/slide/getimage/) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/net/aspose.slides/shape/getimage/) تولید کند. تصاویر حاصل، اندازهٔ فعلی اسلاید و نسبت تصویر را منعکس می‌کنند و تضمین می‌شود که قاب‌بندی و هندسه به‌درستی حفظ شوند.
