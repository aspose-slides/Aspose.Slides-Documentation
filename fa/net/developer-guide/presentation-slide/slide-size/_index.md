## **مقدمه**

Aspose.Slides برای .NET ابزارهای جامعی برای تنظیم اندازه اسلاید و نسبت ابعاد در ارائه‌های PowerPoint فراهم می‌کند که برای چاپ و نمایش روی صفحه مهم است.

اندازه‌ها و نسبت‌های محبوب اسلاید:

- **استاندارد (نسبت 4:3)**: ایده‌آل برای صفحه‌نمایش‌ها و دستگاه‌های قدیمی.
- **عریض (نسبت 16:9)**: برای پروژکتورها و نمایشگرهای مدرن توصیه می‌شود.

برای حفظ یکسانی تمام اسلایدها، یک اندازه اسلاید و نسبت ابعاد برای همه اسلایدها اعمال می‌شود. برای نتایج بهینه، اندازه اسلایدها را در ابتدای فرآیند ایجاد ارائه تنظیم کنید تا از بروز مشکلات جلوگیری شود.

{{% alert color="info" %}} 
به‌طور پیش‌فرض، ارائه‌های ایجاد شده با Aspose.Slides از نسبت استاندارد 4:3 استفاده می‌کنند.
{{% /alert %}}

صفحات یادداشت و تک‌صفحه‌ها ابعاد جداگانه‌ای نسبت به اسلایدهای معمولی دارند. برای تغییر اندازه و جهت آن‌ها به [Notes Page Size](/slides/fa/net/notes-size/) مراجعه کنید.

## **چگونه اندازه اسلاید را در یک ارائه تغییر دهیم**

این مثال نحوه تغییر اندازه اسلاید یک ارائه با Aspose.Slides در C# را نشان می‌دهد:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **مشخص کردن اندازه‌های سفارشی اسلاید**

سفارشی‌سازی اندازه اسلاید وفق نیازهای خاص شما، مانند چیدمان‌های کاغذی منحصر به فرد یا مشخصات صفحه‌نمایش، می‌تواند مفید باشد. در اینجا نحوه تعیین اندازه اسلاید سفارشی با Aspose.Slides برای .NET آمده است:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // اندازه کاغذ A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **مدیریت محتوای اسلاید پس از تغییر اندازه**

پس از تغییر اندازه، محتوای اسلاید ممکن است دچار تحریف شود. می‌توانید نحوه مدیریت این تغییر اندازه توسط Aspose.Slides را کنترل کنید:

- `DoNotScale`: اشیاء را با اندازه‌های اصلی حفظ می‌کند تا از مقیاس‌بندی جلوگیری شود.
- `EnsureFit`: اشیاء را برای اسلایدهای کوچکتر مقیاس می‌دهد تا از از دست رفتن محتوا جلوگیری کند.
- `Maximize`: اشیاء را برای اسلایدهای بزرگتر بزرگ می‌کند تا یکدستی ظاهری حفظ شود.

مثالی از استفاده از تنظیم `Maximize` برای تنظیم اندازه اسلاید:

```csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **سوالات متداول**

### آیا می‌توانم اندازه اسلاید سفارشی را با واحدهایی غیر از اینچ (مثلاً نقاط یا میلی‌متر) تنظیم کنم؟

بله. Aspose.Slides به‌صورت داخلی از نقاط (points) استفاده می‌کند که 1 نقطه معادل 1/72 اینچ است. می‌توانید هر واحدی (مانند میلی‌متر یا سانتی‌متر) را به نقاط تبدیل کرده و مقادیر تبدیل‌شده را برای تعریف عرض و ارتفاع اسلاید به‌کار ببرید.

### آیا اندازه سفارشی بسیار بزرگ اسلاید بر عملکرد و مصرف حافظه در زمان رندرینگ تأثیر می‌گذارد؟

بله. ابعاد بزرگ‌تر اسلاید (به نقطه) همراه با مقیاس رندرینگ بالاتر منجر به مصرف بیشتر حافظه و زمان پردازش طولانی‌تر می‌شود. سعی کنید اندازه اسلایدی عملی انتخاب کنید و مقیاس رندرینگ را فقط در صورت نیاز برای دستیابی به کیفیت خروجی مطلوب تنظیم کنید.

### آیا می‌توانم یک اندازه اسلاید غیر استاندارد تعریف کنم و سپس اسلایدهایی را از ارائه‌هایی با اندازه‌های متفاوت ادغام کنم؟

نمی‌توانید [merge presentations](/slides/fa/net/merge-presentation/) را در حالی که اندازه اسلایدها متفاوت هستند انجام دهید — ابتدا باید یک ارائه را به اندازه دیگر تغییر دهید. هنگام تغییر اندازه اسلاید، می‌توانید نحوه مدیریت محتوای موجود را از طریق گزینه [SlideSizeScaleType](https://reference.aspose.com/slides/fa/net/aspose.slides/slidesizescaletype/) انتخاب کنید. پس از هماهنگ‌سازی اندازه‌ها، می‌توانید اسلایدها را ادغام کنید و قالب‌بندی را حفظ کنید.

### آیا می‌توانم برای اشکال فردی یا مناطق خاصی از اسلاید تصاویر کوچک (thumbnail) تولید کنم و آیا این تصاویر اندازه جدید اسلاید را رعایت می‌کنند؟

بله. Aspose.Slides می‌تواند تصاویر کوچک برای [entire slides](https://reference.aspose.com/slides/fa/net/aspose.slides/slide/getimage/) و همچنین برای [selected shapes](https://reference.aspose.com/slides/fa/net/aspose.slides/shape/getimage/) تولید کند. تصاویر حاصل اندازه فعلی اسلاید و نسبت ابعاد را منعکس می‌کنند و چارچوب و هندسهٔ ثابت را تضمین می‌سازند.
