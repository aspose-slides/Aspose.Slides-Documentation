## **OpenXML چیست؟**
OpenXML SDK یک SDK .NET از مایکروسافت است که برای پردازش فرمت‌های فایل Microsoft Office 2007 و بالاتر استفاده می‌شود. این فرمت‌ها در اصل بسته‌های فشرده هستند و Open XML SDK برای Office کار دستکاری بسته‌های Open XML و عناصر اسکیمای Open XML داخل بسته را ساده می‌کند. کلاس‌های Open XML SDK وظایف رایجی را که توسعه‌دهندگان بر روی بسته‌های Open XML انجام می‌دهند، محصور می‌کنند؛ به‌طوری که بتوانید عملیات پیچیده را با چند خط کد انجام دهید.

پس از نصب Open XML SDK 2.5، پروژه یا برنامه موجود خود را در Visual Studio باز کنید یا یک پروژه یا برنامه جدید ایجاد کنید. سپس در پروژه یا برنامه خود، مراجع به اجزاء زیر را اضافه کنید:

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides برای .NET**
Aspose.Slides برای .NET یک مؤلفه منحصر به فرد مدیریت PowerPoint® است که به برنامه‌های .NET امکان خواندن، نوشتن و دستکاری اسناد PowerPoint را بدون استفاده از Microsoft PowerPoint می‌دهد.

Aspose.Slides برای .NET اولین و تنها مؤلفه .NET است که قابلیت مدیریت اسناد PowerPoint را در داخل برنامه‌های شما فراهم می‌کند. همانند تمام مؤلفه‌های Aspose .NET، Aspose.Slides به زبان C# مدیریت‌شده نوشته شده، قیمت‌گذاری بسیار مناسب دارد و سرعت فوق‌العاده‌ای دارد.

## **مقدمه**
توسعه‌دهندگانی که به دنبال کتابخانه‌های فرمت فایل هستند، ممکن است نیاز داشته باشند ویژگی‌های ارائه‌شده توسط کتابخانه‌های موجود در بازار را بررسی کنند. عمدتاً دو عامل هنگام انتخاب یک گزینه در نظر گرفته می‌شود:

- ویژگی‌ها
- تلاش‌های لازم برای استفاده از کتابخانه

اگر یک توسعه‌دهنده .NET هستید و به دنبال کتابخانه‌ای سریع، آسان و کم‌حجم برای پردازش فایل‌ها می‌گردید، ممکن است نیاز داشته باشید VSTO (Visual Studio tool for Office) را با Aspose مقایسه کنید. در این حالت، این پروژه به شما کمک می‌کند ویژگی‌ها و کدهای هر دو کتابخانه را مقایسه کنید.

### **نیازمندی‌های سیستم**

- Visual Studio 2008 Professional Edition
- Visual Studio 2008 Team Suite Edition
- یک نسخه از Microsoft Office:
- Microsoft Office Professional 2003 SP1
- 2007 Microsoft Office system
### **سیستم‌عامل‌های پشتیبانی‌شده**
- Windows 2000; Windows Server 2003; Windows Vista; Windows XP
### **نسخه‌های .NET Framework پشتیبانی‌شده**
- فقط .NET framework 2.0 یا بالاتر.
