SVG—مخفف Scalable Vector Graphics—یک نوع یا قالب گرافیکی استاندارد است که برای رندر تصاویر دو‑بعدی استفاده می‌شود. SVG تصاویر را به صورت بردارها در XML ذخیره می‌کند با جزئیاتی که رفتار یا ظاهر آن‌ها را تعریف می‌کند.

SVG یکی از تعداد کمی از قالب‌های تصویر است که در این موارد معیارهای بسیار بالایی را برآورده می‌کند: مقیاس‌پذیری، تعامل‌پذیری، عملکرد، دسترسی‌پذیری، قابلیت برنامه‌نویسی و غیره. به همین دلایل، به‌طور رایج در توسعه وب مورد استفاده قرار می‌گیرد.

ممکن است بخواهید در این موارد از فایل‌های SVG استفاده کنید:

- زمانی که قصد دارید ارائه خود را در فرمت بسیار بزرگ چاپ کنید. تصاویر SVG می‌توانند به هر رزولوشن یا سطحی مقیاس‌بندی شوند. می‌توانید تصاویر SVG را هر بار که لازم باشد بدون از دست دادن کیفیت تغییر اندازه دهید.
- زمانی که می‌خواهید نمودارها و گراف‌ها را از اسلایدهای خود در رسانه‌ها یا پلتفرم‌های مختلف استفاده کنید. اکثر خوانندگان می‌توانند فایل‌های SVG را تفسیر کنند.
- زمانی که نیاز به کوچک‌ترین حجم ممکن برای تصاویر دارید. فایل‌های SVG عموماً از معادل‌های با وضوح بالا در قالب‌های دیگر کوچک‌تر هستند، به‌ویژه قالب‌های مبتنی بر بیت‌مپ (JPEG یا PNG).

Aspose.Slides for .NET به شما امکان می‌دهد اسلایدهای ارائه خود را به‌صورت تصویر **SVG** صادر کنید. برای تولید یک تصویر SVG از هر اسلاید، این کارها را انجام دهید:

- یک نمونه از کلاس Presentation بسازید.
- از تمام اسلایدهای موجود در ارائه عبور کنید.
- هر اسلاید را از طریق FileStream به یک فایل SVG جداگانه بنویسید.

{{% alert color="info" %}} 
ممکن است بخواهید [برنامه وب رایگان](https://products.aspose.app/slides/fa/conversion/ppt-to-svg) ما را امتحان کنید که در آن عملکرد تبدیل PPT به SVG از Aspose.Slides برای .NET پیاده‌سازی شده است.
{{% /alert %}} 

این نمونه کد در C# نشان می‌دهد چگونه PPT را به SVG تبدیل کنید با استفاده از Aspose.Slides:

``` csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("pres.pptx"))
{
    for (var index = 0; index < pres.Slides.Count; index++)
    {
        ISlide slide = pres.Slides[index];

        using (FileStream fileStream = new FileStream($"slide-{index}.svg", FileMode.Create, FileAccess.Write))
        {
            slide.WriteAsSvg(fileStream);   
        }
    }
}
```
