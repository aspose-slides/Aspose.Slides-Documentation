{{% alert color="info" %}} 

Aspose.Slides for .NET کتابخانه‌ای کلاس است که به برنامه‌های .NET امکان خواندن و نوشتن اسناد ارائه را بدون استفاده از Microsoft PowerPoint® یا سایر برنامه‌ها می‌دهد. Aspose.Slides for .NET امکان مدیریت متن، اشکال، جداول و انیمیشن‌ها، افزودن صدا و ویدیو به اسلایدها، پیش‌نمایش اسلایدها، صادرات اسلایدها به فرمت SVG، PDF و موارد دیگر را فراهم می‌کند.

آخرین مرجع API را می‌توانید در [مرجع API Aspose.Slides برای .NET](https://reference.aspose.com/slides/fa/net) بیابید.

{{% /alert %}}
