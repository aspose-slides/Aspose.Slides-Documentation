## **Power BI**

U kunt Aspose.Slides for Reporting Services op Power BI Report Server installeren via dezelfde installatieprocedures:

* [Installeren met MSI-installatieprogramma](/slides/nl/reportingservices/install-with-msi-installer/). Het installatieprogramma detecteert automatisch de geïnstalleerde Power BI Report Server, installeert het product en configureert het vervolgens voor uw werkomgeving.
* [Handmatig installeren](/slides/nl/reportingservices/install-manually/). Gebruik de assembly uit de map *Bin\Universal* van het ZIP-pakket.

Aspose.Slides for Reporting Services exporteert paginagerapporteerde rapporten (RDL) vanaf Power BI Report Server. Voor de vereisten, inclusief .NET Framework 3.5 op de hostmachine, zie [Systeemvereisten](/slides/nl/reportingservices/system-requirements/).
