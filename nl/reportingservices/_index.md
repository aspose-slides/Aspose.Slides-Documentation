Aspose.Slides for Reporting Services is een renderextensie voor Microsoft SQL Server Reporting Services en Power BI Report Server die presentatieformaten toevoegt aan de exportlijst van gepagineerde (RDL) rapporten, zonder Microsoft PowerPoint op de server.

Het exporteert rapporten naar PPT-, PPTX-, PPS- en PPSX-presentaties en diavoorstellingen, naar ODP en naar XPS.

## **Uw eerste export**

Er is geen code nodig: u installeert de extensie op de rapportserver, en de formaten verschijnen in de exportlijst van elk gepagineerd rapport op die server.

1. Controleer of de rapportserver voldoet aan de [systeemvereisten](/slides/nl/reportingservices/system-requirements/), inclusief .NET Framework 3.5.
2. Van de [downloadpagina](https://releases.aspose.com/slides/reportingservices/) downloadt u de MSI-installer, *Aspose.Slides for Reporting Services*. Om handmatig te installeren, downloadt u het ZIP‑pakket, *Aspose.Slides for Reporting Services (DLLs Only)*.
3. Installeer de extensie op de rapportserver: voer de MSI uit als administrator, zoals beschreven in [Installeren met de MSI-installer](/slides/nl/reportingservices/install-with-msi-installer/), of volg [Handmatig installeren](/slides/nl/reportingservices/install-manually/) voor het ZIP‑pakket.
4. Open in een browser de webportaal van de rapportserver (Report Manager op SQL Server 2014 en ouder). Standaard is het adres `https://<ComputerName>/reports`.
5. Open een gepagineerd rapport. Open op de rapportwerkbalk de **Export**‑lijst en selecteer **PPTX – PowerPoint 2007‑presentatie via Aspose.Slides**. Als de werkbalk een aparte **Export**‑knop heeft, zoals in Report Manager, selecteer die.
6. Open of sla het PPTX‑bestand op dat de browser downloadt.

Zonder licentie bevat de geëxporteerde presentatie een evaluatiewatermerk — zie [Licenties](/slides/nl/reportingservices/license-aspose-slides-for-reporting-services/). Voor de andere formaten in de exportlijst, zie [Ondersteunde bestandsformaten](/slides/nl/reportingservices/supported-file-formats/).
