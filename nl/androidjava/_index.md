**Welkom bij Aspose.Slides for Android via Java**

Aspose.Slides for Android via Java is een Microsoft PowerPoint®-beheers-API die Android‑applicaties in staat stelt PowerPoint®‑documenten te lezen en te schrijven zonder Microsoft PowerPoint®. Aspose.Slides for Android via Java is de eerste en enige component die de functionaliteiten biedt die nodig zijn om PowerPoint®‑documenten op Android‑platformen te beheren. Aspose.Slides for Android biedt veel belangrijke functies waarmee u tekst, vormen, tabellen & animaties, audio‑ en video‑bestanden in dia's kunt toevoegen, wijzigen en manipuleren.
