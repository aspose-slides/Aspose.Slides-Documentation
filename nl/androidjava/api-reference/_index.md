{{% alert color="info" %}} 

Aspose.Slides for Android via Java is een klassikale bibliotheek die Java‑toepassingen voor Android in staat stelt presentatiedocumenten te lezen en te schrijven zonder Microsoft PowerPoint® of andere software te gebruiken. Aspose.Slides for Android via Java stelt je in staat tekst, vormen, tabellen en animaties te beheren; audio en video aan dia's toe te voegen; dia's te bekijken; en dia's te exporteren naar SVG, PDF en meer.

De nieuwste API‑referentie is te vinden op [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/nl/androidjava/).
