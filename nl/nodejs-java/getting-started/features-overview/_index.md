## **Ondersteunde platformen**
Aspose.Slides for Node.js via Java is een platformonafhankelijke API. Het kan op elk platform (Windows, Linux, macOS, enz.) worden gebruikt waar Node.js 7 of hoger is geïnstalleerd. Oracle JDK 8 of hoger is een andere vereiste.

## **Bestandsformaten en conversies**
Aspose.Slides for Node.js via Java ondersteunt de meeste PowerPoint‑documentformaten. Het stelt u ook in staat ze te exporteren naar de populaire bestandsformaten die organisaties gebruiken en onderling delen. Bekijk de details:

|**Functie**|**Beschrijving**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java biedt de snelste verwerking voor dit presentatiedocumentformaat.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java ondersteunt PPT‑naar‑PPTX‑conversie|
|Portable Document Format (PDF)|U kunt alle ondersteunde bestandsformaten met één methode exporteren naar Adobe Portable Document Format (PDF)-documenten.|
|XML Parser Specification (XPS)|U kunt alle ondersteunde bestandsformaten met één methode exporteren naar XML Parser Specification (XPS)-documenten.|
|Tagged Image File Format (TIFF)|U kunt alle ondersteunde presentatiedocumentformaten exporteren naar Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java ondersteunt de conversie van PresentationEx naar HTML-formaat.|

## **Presentatieweergave**

|**Functie**|**Beschrijving**|

## **Veelgestelde vragen**

### Moet ik Microsoft PowerPoint op de server/PC installeren om de bibliotheek te laten werken?

Nee. PowerPoint is niet vereist; Aspose.Slides is een zelfstandige engine voor het maken, bewerken, converteren en renderen van presentaties.

### Hoe werkt multithreading? Kan verwerking parallel worden uitgevoerd?

Het is veilig om verschillende documenten in verschillende threads te verwerken; hetzelfde [presentatie](https://reference.aspose.com/slides/nl/nodejs-java/aspose.slides/presentation/) object mag niet gelijktijdig door [meerdere threads](/slides/nl/nodejs-java/multithreading/) worden gebruikt.

### Worden bestandswachtwoorden en versleuteling ondersteund?

Ja. [U kunt](/slides/nl/nodejs-java/password-protected-presentation/) versleutelde presentaties openen, een open‑ en schrijf‑wachtwoord instellen of verwijderen, en de beschermingsstatus controleren.

### Moet ik me bekommeren om lettertype‑pakketten in Linux‑containers?

Ja. Het wordt aanbevolen om gangbare lettertype‑pakketten te installeren en/of expliciet [lettertype‑mappen](/slides/nl/nodejs-java/custom-font/) op te geven in uw toepassing om onverwachte substituties te voorkomen.

### Zijn er beperkingen in de evaluatieversie?

In [evaluatiemodus](/slides/nl/nodejs-java/licensing/) wordt een watermerk toegevoegd aan de uitvoer en gelden bepaalde beperkingen; een [30‑daagse tijdelijke licentie](https://purchase.aspose.com/temporary-license/) is beschikbaar voor volledige functionele testing.

### Wordt het importeren van externe formaten in een presentatie (PDF/HTML → PPTX) ondersteund?

Ja. U kunt [PDF‑pagina's en HTML‑inhoud](/slides/nl/nodejs-java/import-presentation/) aan een presentatie toevoegen, waardoor ze in dia's worden omgezet.
