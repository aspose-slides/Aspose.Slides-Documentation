{{% alert color="info" title="Opmerking" %}}

De evaluatie‑download van Aspose.Slides for SharePoint is dezelfde als de gekochte download. Het wordt de gelicentieerde versie wanneer je het licentie‑oplossingspakket op de farm installeert; zie [Installatie van Aspose.Slides for SharePoint‑licentie](/slides/nl/sharepoint/installing-aspose-slides-for-sharepoint-license/). Er is geen code betrokken.

Zonder licentie converteert Aspose.Slides for SharePoint naar elk ondersteund formaat, maar de geconverteerde bestanden dragen een evaluatiewatermerk, en de conversiepagina toont een evaluatienotificatie.
