{{% alert color="info" title="Note" %}}

Met Aspose.Slides for SharePoint kunt u PowerPoint‑presentaties converteren naar vele populaire documentformaten vanuit een SharePoint‑documentbibliotheek.

{{% /alert %}}

## **Ondersteunde invoerformaten**

Aspose.Slides for SharePoint converteert de volgende invoerformaten:

- PPT – Microsoft PowerPoint‑presentatie 97 - 2003
- PPTX – Office Open XML‑presentatie

{{% alert color="info" title="Note" %}}

Om documenten te converteren maakt Aspose.Slides for SharePoint gebruik van een ingebouwde versie van [Aspose.Slides for .NET](https://products.aspose.com/slides/nl/net/).

{{% /alert %}}

## **Ondersteunde uitvoerformaten**

De **Convert to**‑lijst op de conversie‑pagina biedt de volgende uitvoerformaten, in deze volgorde:

- PDF – Adobe Portable Document
- TIFF – Afbeeldingenpakket
- XPS – XML Paper Specification
- PPS – Dia‑showpresentatie
- PPSX – Microsoft PowerPoint Open XML-diashow
- ODP – OpenDocument‑presentatie
- PPTM – Microsoft PowerPoint Open XML-macro‑enabled presentatie
- PPSM – Microsoft PowerPoint Open XML-macro‑enabled diashow
- POTX – Microsoft PowerPoint‑sjabloon
- POTM – PowerPoint Open XML macro‑enabled presentatiesjabloon
- PDFNotes – Presentatienotitiesweergave in PDF‑formaat
- HTML – Presentatie in HTML‑formaat
- TIFFNotes – Presentatienotitiesweergave als meerpagina‑TIFF‑afbeelding
- SWF – Shockwave Flash‑film
- SWFNotes – Presentatienotitiesweergave als meerpagina‑SWF

**Selecteren van het uitvoerformaat op de pagina Conversie‑instellingen**
