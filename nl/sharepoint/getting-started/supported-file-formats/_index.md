- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **Ondersteunde bestandsformaten**

Aspose.Slides for SharePoint converteert PPT‑ en PPTX‑presentaties die opgeslagen zijn in een SharePoint‑documentbibliotheek. Bestanden van andere types worden niet geconverteerd.
