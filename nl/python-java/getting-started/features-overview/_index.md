## **Ondersteunde platforms**
Aspose.Slides for Python via Java is een platformonafhankelijke API. Het kan op elk platform (Windows, Linux, macOS, enz.) worden gebruikt waar Python 3.7 of hoger is geïnstalleerd. JDK 8 of hoger is een andere vereiste.

## **Bestandsformaten en conversies**
Aspose.Slides for Python via Java ondersteunt de meeste PowerPoint‑documentformaten. Het maakt ook export naar de populaire bestandsformaten mogelijk die organisaties gebruiken en onderling delen. Bekijk deze details:

|**Feature**|**Description**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java biedt de snelste verwerking voor dit presentatiedocumentformaat.|
|PPT to PPTX conversion|Aspose.Slides for Python via Java ondersteunt conversie van PPT naar PPTX.|
|Portable Document Format (PDF)|U kunt alle ondersteunde bestandsformaten met één methode exporteren naar Adobe Portable Document Format (PDF).|
|XML Parser Specification (XPS)|U kunt alle ondersteunde bestandsformaten met één methode exporteren naar XML Parser Specification (XPS).|
|Tagged Image File Format (TIFF)|U kunt alle ondersteunde presentatiedocumentformaten exporteren naar Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java ondersteunt de conversie van PresentationEx naar HTML‑formaat.|

## **Presentatie‑rendering**
Aspose.Slides for Python via Java ondersteunt hoge‑kwaliteit rendering van dia's in presentaties naar verschillende grafische formaten. Bekijk deze details:

|**Feature**|**Description**|
| :- | :- |
|Java Supported Image Formats|Met Aspose.Slides for Python via Java kunt u presentatiedia's en afbeeldingen op dia's renderen naar alle door Java ondersteunde grafische formaten zoals TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Python via Java biedt ook ingebouwde methoden waarmee u presentatiedia's kunt exporteren naar Scalable Vector Graphics (SVG).|

## **Inhouds‑functies**
Aspose.Slides for Python via Java stelt u in staat om bijna alle items of inhoud van presentatiedocumenten te benaderen, te wijzigen of te creëren. Bekijk deze details:

|**Feature**|**Description**|
| :- | :- |
|Master Slides|De master‑dia's definiëren de lay‑out van de normale dia's. Aspose.Slides for Python via Java stelt u in staat de master‑dia's van presentatiedocumenten te benaderen en te wijzigen.|
|Normal Slides|Met Aspose.Slides for Python via Java kunt u nieuwe dia's van verschillende typen maken; u kunt ook bestaande dia's in de presentaties benaderen en wijzigen.|
|Cloning / Copying Slides|Er zijn ingebouwde methoden beschikbaar in Aspose.Slides for Python via Java die u in staat stellen bestaande dia's binnen een presentatie te klonen of te kopiëren. U kunt gekopieerde en gekloonde dia's van de ene presentatie naar de andere gebruiken. Omdat een dia zijn lay‑out erft van de master‑dia, kopiëren de ingebouwde kloonmethoden automatisch de master bij het klonen.|
|Managing Slides sections|Methoden om dia's in verschillende secties binnen een presentatie te organiseren.|
|Place Holders and Text Holders|U kunt de place‑holders en tekst‑holders in een dia benaderen. Bovendien kunt u een dia met tekst‑holders vanaf nul maken met de juiste methode.|
|Header and Footers|Aspose.Slides for Python via Java vergemakkelijkt het omgaan met kop‑ en voetteksten in dia's.|
|Notes in Slides|Met Aspose.Slides for Python via Java kunt u notities die aan een dia zijn gekoppeld benaderen en wijzigen, en ook nieuwe notities toevoegen.|
|Finding a Shape|U kunt ook een specifieke vorm op een dia vinden via de alternatieve tekst die aan de vorm is gekoppeld.|
|Backgrounds|Aspose.Slides for Python via Java stelt u in staat te werken met achtergronden die aan een master‑ of normale dia zijn gekoppeld.|
|Text Boxes|Tekstvakken kunnen vanaf nul worden aangemaakt. U kunt bestaande tekstvakken benaderen. U kunt hun tekst wijzigen zonder de oorspronkelijke opmaak te verliezen.|
|Rectangle Shapes|U kunt rechthoekige vormen maken of wijzigen met Aspose.Slides for Python via Java.|
|Poly Line Shapes|U kunt poly‑lijn vormen maken of wijzigen met Aspose.Slides for Python via Java.|
|Ellipse Shapes|U kunt ellipsvormen maken of wijzigen met Aspose.Slides for Python via Java.|
|Group Shapes|Aspose.Slides for Python via Java ondersteunt groep‑vormen.|
|Auto Shapes|Aspose.Slides for Python via Java ondersteunt auto‑vormen.|
|SmartArt|Aspose.Slides for Python via Java biedt ondersteuning voor SmartArt‑vormen in MS PowerPoint.|
|Charts|Aspose.Slides for Python via Java biedt ondersteuning voor MSO‑grafieken in PowerPoint.|
|Shapes Serialization|Aspose.Slides for Python via Java ondersteunt een groot aantal vormen. Wanneer een vorm niet rechtstreeks wordt ondersteund, kunt u een serialisatiemethode gebruiken om die vorm van een bestaande dia te serialiseren. Zo kunt u de vorm later verder gebruiken volgens uw behoeften.|
|Picture Frames|U kunt afbeeldingen beheren in picture frames met Aspose.Slides for Python via Java.|
|Audio Frames|U kunt audio‑bestanden linken of insluiten in audio‑frames op dia's met Aspose.Slides for Python via Java.|
|Video Frames|U kunt videobestanden beheren in video‑frames. Aspose.Slides for Python via Java biedt ook ondersteuning voor gekoppelde en ingesloten video's.|
|OLE Frame|U kunt OLE‑objecten beheren in OLE‑frames met Aspose.Slides for Python via Java.|
|Tables|Aspose.Slides for Python via Java ondersteunt tabellen in dia's.|
|ActiveX Controls|Ondersteuning voor ActiveX‑besturingselementen.|
|VBA Macros|Ondersteuning voor het beheren van VBA‑macro’s in presentaties.|
|Text Frame|U kunt de tekst van elke vorm benaderen via het tekst‑frame dat aan die vorm is gekoppeld.|
|Text Scanning|U kunt tekst in een presentatie scannen op presentatieniveau of dia‑niveau via ingebouwde scanmethoden.|
|Animations|U kunt animaties toepassen op vormen.|
|Slide Shows|Aspose.Slides for Python via Java ondersteunt diavoorstellingen en dia‑overgangen.|
