Dit artikel beschrijft de presentatieverwerkingsmogelijkheden van Aspose.Slides for Python via Java. Voor ondersteunde besturingssystemen en afhankelijkheden, zie [Systeemvereisten](/slides/nl/python-java/system-requirements/).

## **Bestandsformaten en conversies**

Aspose.Slides for Python via Java laat u presentatieformaten converteren en presentaties exporteren naar document- en webformaten. Zie [Ondersteunde bestandsformaten](/slides/nl/python-java/supported-file-formats/) voor de volledige formatentabel en het onderscheid tussen het laden van presentaties, het importeren van inhoud en het exporteren van de output.

## **Presentatieweergave**

Aspose.Slides for Python via Java biedt hooggetrouwe dia‑weergave als raster‑ of vectorafbeeldingen voor voorbeelden en andere visuele output. Het laat u ook afbeeldingen op dia's renderen. Voor beschikbare afbeeldingsformaten en exportnotities, zie [Ondersteunde bestandsformaten](/slides/nl/python-java/supported-file-formats/#supported-file-formats).

## **Inhoudsfuncties**

Aspose.Slides for Python via Java stelt u in staat bijna alle soorten presentatiewaarde te benaderen, te wijzigen en te maken, zoals hieronder beschreven:

|**Functie**|**Beschrijving**|
| :- | :- |
|Presentations|U kunt presentaties van de grond af maken of bestaande bestanden openen.|
|Document Properties|U kunt documenteigenschappen lezen en wijzigen.|
|Presentation Protection|U kunt wachtwoordbeveiliging toepassen en instellingen voor presentatiebeveiliging beheren.|
|Master Slides|Masterdia's definiëren de lay-out van normale dia's. Aspose.Slides for Python via Java stelt u in staat masterdia's in presentaties te openen en te wijzigen.|
|Normal Slides|U kunt dia's in presentaties toevoegen, openen, bewerken, herschikken en verwijderen.|
|Slide Layouts|U kunt werken met dia‑lay-outs.|
|Cloning and Copying Slides|Ingebouwde methoden stellen u in staat dia's binnen een presentatie of tussen presentaties te klonen of te kopiëren. Deze methoden kopiëren automatisch de bijbehorende masterdia bij het klonen van een dia.|
|Slide Sections|U kunt dia's binnen een presentatie in secties organiseren.|
|Placeholders and Text Holders|U kunt plaatsaanduidingen en tekstvullingen op een dia openen, evenals dia's met tekstvullingen van de grond af maken.|
|Headers and Footers|Aspose.Slides for Python via Java laat u kop‑ en voetteksten beheren.|
|Slide Notes|U kunt dia‑aantekeningen openen, toevoegen en wijzigen, en opnemen bij het exporteren naar PDF of TIFF.|
|Finding a Shape|U kunt een specifieke vorm op een dia vinden via de alternatieve tekst.|
|Alternative Text|U kunt de alternatieve tekst van vormen lezen en bijwerken.|
|Hyperlinks|U kunt hyperlinks op vormen lezen en bijwerken en hyperlinks aan tekst toevoegen.|
|Backgrounds|U kunt werken met de achtergronden van masterdia's en normale dia's in een presentatie.|
|Text Boxes|U kunt tekstvakken van de grond af maken, bestaande tekstvakken openen en hun tekst wijzigen, terwijl de oorspronkelijke opmaak behouden blijft.|
|Rectangle Shapes|U kunt rechthoekige vormen maken en wijzigen.|
|Line Shapes|U kunt lijnvormen maken en wijzigen.|
|Polyline Shapes|U kunt polylijngedeelten maken en wijzigen.|
|Ellipse Shapes|U kunt ellipsvormen maken en wijzigen.|
|Group Shapes|Aspose.Slides for Python via Java ondersteunt groepvormen.|
|AutoShapes|Aspose.Slides for Python via Java ondersteunt AutoShapes.|
|SmartArt|U kunt SmartArt‑vormen in presentaties maken en bewerken.|
|Charts|U kunt Microsoft Office‑grafieken in PowerPoint‑presentaties maken en bewerken.|
|Shape Serialization|Aspose.Slides for Python via Java ondersteunt vele vormtypes. Voor niet‑ondersteunde vormen kunt u serialisatie gebruiken om een vorm van een bestaande dia te behouden voor hergebruik.|
|Shape Locks|U kunt vormvergrendelingen toepassen om bewerkingsacties te beperken.|
|Picture Frames|U kunt afbeeldingen beheren in afbeeldingskaders.|
|Audio Frames|U kunt audiobestanden koppelen of insluiten in audio‑kaders op dia's.|
|Video Frames|U kunt gekoppelde en ingesloten video’s beheren in video‑kaders.|
|OLE Frames|U kunt OLE‑objecten beheren in OLE‑kaders.|
|Tables|U kunt tabellen maken, verplaatsen en van grootte wijzigen; rijen en kolommen toevoegen, verwijderen en van grootte wijzigen; en celinhoud, randen, opvullingen en tekstopmaak lezen en wijzigen.|
|ActiveX Controls|Aspose.Slides for Python via Java ondersteunt ActiveX‑besturingselementen.|
|VBA Macros|U kunt VBA‑macro’s in presentaties beheren.|
|Text Frames|U kunt de tekst van een vorm benaderen via het bijbehorende tekstkader en de marges en tekstomloop van het tekstkader aanpassen.|
|Fonts|U kunt de in presentaties gebruikte lettertypen beheren.|
|Text Scanning|Ingebouwde methoden laten u tekst scannen over een volledige presentatie of op individuele dia’s.|
|Animations|U kunt animatie‑effecten op vormen toevoegen en wijzigen.|
|Slide Shows|Aspose.Slides for Python via Java ondersteunt diavoorstellingen en dia‑overgangen, inclusief Morph‑overgangen.|

## **Opmaakfuncties**

Aspose.Slides for Python via Java laat u tekst en vormen op presentatiedia's opmaken, zoals hieronder beschreven:

|**Functie**|**Beschrijving**|
| :- | :- |
|Text Formatting|<p>U kunt tekst beheren via de tekstkaders die aan vormen zijn gekoppeld en individuele alinea’s en tekstdelen opmaken. De volgende opmaakopties zijn beschikbaar:</p><p>- Lettertype</p><p>- Lettergrootte</p><p>- Letterkleur</p><p>- Letterschaduw</p><p>- Alinea‑uitlijning</p><p>- Alinea‑inspringing en tabs</p><p>- Alinea‑opsommingstekens</p><p>- Alinea‑oriëntatie</p>|
|Shape Formatting|<p>Vormen zijn de basiselementen van een dia. U kunt de volgende vormeigenschappen aanpassen:</p><p>- Positie</p><p>- Grootte</p><p>- Rotatie</p><p>- Lijnstijlen</p><p>- Opvulling (inclusief effen, verloop, patroon, textuur en afbeeldingsopvullingen)</p><p>- Tekst</p><p>- Afbeelding</p>|
