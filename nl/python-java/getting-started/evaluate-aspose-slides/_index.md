U kunt Aspose.Slides voor Python via Java downloaden om de functionaliteit te evalueren. Het evaluatiepakket is identiek aan het gelicentieerde pakket. Om het zonder evaluatiebeperkingen te gebruiken, voegt u een paar regels code toe om een licentie toe te passen.

De evaluatieversie van Aspose.Slides (gebruikt zonder licentie) biedt volledige functionaliteit van het product, maar plaatst een evaluatiewatermerk bovenaan het document wanneer u het opent of opslaat. Tekstextractie is beperkt tot één dia per presentatie.
