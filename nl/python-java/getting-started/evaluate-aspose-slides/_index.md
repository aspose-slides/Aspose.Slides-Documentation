U kunt Aspose.Slides voor Python via Java downloaden om de functionaliteit te evalueren. Het evaluatiepakket is identiek aan het gelicentieerde pakket. Om het zonder evaluatiebeperkingen te gebruiken, voegt u een paar regels code toe aan [een licentie toepassen](/slides/nl/python-java/licensing/).

De evaluatieversie van Aspose.Slides (gebruikt zonder licentie) biedt volledige productfunctionaliteit, met twee beperkingen:

- Het voegt een evaluatiewatermerk‑tekstvak toe aan elke dia van elke presentatie die het opslaat. Het openen van een presentatie voegt er geen toe, maar het opslaan van een bestand dat al een watermerk bevat, voegt er nog één toe.
- Tekst die uw code leest, wordt afgekapt tot de eerste paar tekens, gevolgd door een melding over de evaluatiebeperking. Dit geldt voor elke dia, en voor tekst die uw code net heeft ingesteld evenals tekst die uit een bestand is geladen. Tekst die uw code schrijft, wordt volledig opgeslagen.

{{% alert color="info" title="Note" %}}

Om Aspose.Slides zonder evaluatiebeperkingen te testen, kunt u een **30‑daagse tijdelijke licentie** aanvragen. Zie [Een tijdelijke licentie verkrijgen](https://purchase.aspose.com/temporary-license) voor meer informatie.
