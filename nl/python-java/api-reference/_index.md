{{% alert color="info" title="Opmerking" %}}

Aspose.Slides voor Python via Java is een class library die Python-toepassingen in staat stelt presentaties te lezen en te schrijven zonder dat Microsoft PowerPoint® vereist is. Het stelt u in staat tekst, vormen, tabellen en animaties te beheren; audio en video aan dia's toe te voegen; dia's te bekijken; en dia's te exporteren naar SVG, PDF en andere formaten.

Voor meer informatie, zie de [Aspose.Slides for Python via Java API-referentie](https://reference.aspose.com/slides/nl/python-java/).
