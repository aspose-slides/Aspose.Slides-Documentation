{{% alert color="info" title="Note" %}}

Dit is een historische pagina. Het bevat de beperkingen en bekende problemen die gepubliceerd zijn met Aspose.Slides for Java 14.4.0 en beschrijft niet de huidige versie. Voor de wijzigingen per versie, zie de [release notes](https://releases.aspose.com/slides/nl/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.4.0 biedt een nieuwe beslissing voor de verwerking van PowerPoint‑documenten. Er zijn enkele beperkingen en bekende problemen, die in komende releases zullen worden verwijderd:

- Sommige vormen hebben een verkeerde geometrie in geserialiseerde PPT‑documenten (boog, cirkelvormige pijl, aantekeningen).
- Niet alle PPTX‑tekstopmaakfuncties worden ondersteund bij PPT‑serialisatie (tabulatie, inspringing en alinea‑opmaakbeperkingen).
- Informatie over teksttaal en spellinginstellingen is niet aanwezig in geserialiseerde PPT‑documenten.
- Niet alle PPTX‑thematische kenmerken worden ondersteund bij PPT‑serialisatie (alleen serialisatie van opvulformaten, lijnformaten en lettertype).
- Er zijn bekende problemen bij OLE/ActiveX PPT‑serialisatie naar PPT.
- Serialisatie en weergave van WordArt worden niet ondersteund.
