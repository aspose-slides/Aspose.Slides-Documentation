Er is een nieuwe [Aspose.Slides for Java API](/slides/nl/java/) gereleased en nu ondersteunt dit enkele product de mogelijkheid om PowerPoint‑documenten vanaf nul te genereren en bestaande documenten te bewerken.

{{% /alert %}} 
## **Ondersteuning voor legacy‑code**
Om de legacy‑code te gebruiken die is ontwikkeld met Aspose.Slides for Java versies vóór 13.x, moet u enkele kleine wijzigingen in uw code aanbrengen en zal de code zoals eerder functioneren. Alle klassen die aanwezig waren in de oude Aspose.Slides for Java onder de Aspose.Slide‑ en Aspose.Slides.Pptx‑namespaces zijn nu samengevoegd in één enkele Aspose.Slides‑namespace. Bekijk de volgende eenvoudige code‑fragment voor het maken van een Hello‑World‑presentatiedocument in de legacy Aspose.Slides‑API en volg de stappen die beschrijven hoe u moet migreren naar de nieuwe samengevoegde API.
