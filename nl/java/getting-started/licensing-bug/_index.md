Dit is een historische pagina. Het beschrijft een bug in Aspose.Slides for Java versies 23.2 tot 23.7, die in 2023 zijn uitgebracht, en de versies die het hebben opgelost. Het beschrijft niet de huidige versie. Voor licenties in de huidige versie, zie [Licensing](/slides/nl/java/licensing/).
{{% /alert %}}

## **Overzicht**

Dit artikel beschrijft een licentiebug die is aangetroffen in Aspose.Slides for Java versies 23.2, 23.3, 23.4, 23.5, 23.6 en 23.7. Deze bug zorgde ervoor dat permanente licenties tijdelijk onbruikbaar werden nadat hun abonnement was verlopen.

## **Symptomen**

Nadat uw abonnement voor een permanente licentie verloopt, kunnen Aspose.Slides for Java versies 23.2 - 23.7 de licentie als verlopen melden, waardoor alle functies in de evaluatiemodus worden gezet. Dit gedrag is onjuist en heeft geen invloed op versies vóór 23.2 en na 23.7.

## **Oplossing**

Aspose.Slides for Java heeft dit probleem aangepakt en bijgewerkte versies (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) met de oplossing uitgebracht.

Als u een van de getroffen versies van Aspose.Slides for Java in uw project gebruikt, schakel dan over naar de gecorrigeerde versie.
