## **Over TIFF**

Het [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) dat bekend staat om het opslaan van meerdere afbeeldingen in één document, werd oorspronkelijk gemaakt door Aldus. Dit formaat wordt breed ondersteund door scan-, fax- en andere afbeeldingsbewerkingsapplicaties.

## **TIFF in Aspose.Slides for Java**

Elk document dat kan worden geladen in Aspose.Slides for Java kan ook rechtstreeks door Aspose.Slides for Java worden geconverteerd naar een TIFF-document, waardoor geen derde-partijcomponent meer nodig is. Bovendien kunt u optioneel de grootte van de afbeeldingen in het resulterende TIFF-document definiëren. Informatie over het exporteren van presentatiedocumenten naar TIFF-documenten via Aspose.Slides for Java vindt u in [PowerPoint-presentaties converteren naar TIFF](/slides/nl/java/convert-powerpoint-to-tiff/).
