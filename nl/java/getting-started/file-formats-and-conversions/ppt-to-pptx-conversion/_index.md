## **Features Supported in Conversion**
Aspose.Slides for Java biedt gedeeltelijke ondersteuning voor het converteren van het PPT‑bestandformaat naar PPTX. De ondersteuning voor conversie is pas recent toegevoegd aan Aspose.Slides for Java, waardoor er enkele beperkingen zijn en de tool het beste werkt voor eenvoudige presentaties. Het belangrijkste voordeel van Aspose.Slides for Java bij het omzetten van PPT naar PPTX is hoe eenvoudig de API te gebruiken is. Zie voorbeelden van de code in [Converting PPT to PPTX](). Hieronder worden de lijsten uitgelegd die aangeven welke kenmerken wel en niet worden ondersteund bij PPT‑naar‑PPTX-conversie.

## **Supported Features**
The following features are supported for conversion:

- Converting the structure of masters, layouts and slides.
- Converting charts.
- Group shapes.
- Converting autoshapes including rectangles and ellipses. 
- Shapes with custom geometry.
- Textures and pictures fill styles for autoshapes.
- Converting placeholders.
- Converting lines and polylines.
- Line and fill formats.
- Gradient fill styles.
- OLE frames, tables, video and audio frames, etc.
- Animation and slideshow properties.
- Converting text in text frames and text holders.
