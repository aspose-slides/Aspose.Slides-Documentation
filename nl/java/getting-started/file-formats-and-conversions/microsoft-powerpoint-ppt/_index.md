{{% alert color="info" %}} 

PPT is het presentatie‑documentbestandformaat dat kan worden gemaakt, gelezen, gemanipuleerd en geschreven door verschillende versies van Microsoft PowerPoint. Dit is het binaire formaat voor presentatiedocumenten ontwikkeld door Microsoft.

{{% /alert %}} 

## **PPT in Aspose.Slides voor Java**
Aspose.Slides for Java kan PPT‑bestanden lezen die zijn gemaakt met de onderstaande software.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Evenzo kunnen PPT‑bestanden die door Aspose.Slides for Java zijn gemaakt, gelezen worden door de bovenstaande software.

## **Uitgebreide ondersteuning voor PPT**
Aspose.Slides for Java biedt ondersteuning voor bijna alle functies die door het PPT‑documentformaat worden ondersteund. Het dekt niet alleen de basis‑ en geavanceerde functies die door verschillende versies van Microsoft PowerPoint worden geleverd voor het manipuleren van PPT‑documenten, maar ook functies die niet eens door Microsoft PowerPoint worden ondersteund. Het belangrijkste voordeel van het gebruik van de Aspose.Slides for Java‑API‑bibliotheek is het gebruiksgemak bij het afhandelen van dergelijke functies.

Naast de basis­taken met betrekking tot het maken, lezen en schrijven van PPT‑documentbestanden, biedt Aspose.Slides for Java verschillende functies:

- Importeer andere Microsoft Office‑bestandsformaten als [OLE‑objecten in PPT‑documenten]().
- [Exporteer PPT‑documenten naar PDF](/slides/nl/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- Exporteer dia's in de PPT‑documenten naar SVG‑formaten.
- Render dia's naar elk beeldformaat dat door het Java‑framework wordt ondersteund.
- Stel de grootte van dia's in PPT‑documenten in.
- Beheer animaties op vormen.
- Beheer diavoorstellingen.
- [Formateer tekst op dia's]().
- Extraheer tekst uit PPT‑documenten.
- [Verwerk tabellen op dia's]().
- Kopieer masters automatisch met behulp van [de kloongefunctie]().
