{{% alert color="info" title="Note" %}}
[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) is het presentatiedocumentformaat dat kan worden aangemaakt, gelezen, bewerkt en weggeschreven door verschillende versies van Microsoft PowerPoint. Dit is het binaire formaat voor presentatiedocumenten ontwikkeld door Microsoft.
{{% /alert %}}

## **PPT in Aspose.Slides for Java**
Aspose.Slides for Java kan PPT-bestanden lezen die zijn gemaakt met de onderstaande software.

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

Evenzo kunnen PPT-bestanden die met Aspose.Slides for Java zijn gemaakt, worden gelezen door de bovenstaande set software.

## **Uitgebreide ondersteuning voor PPT**
Aspose.Slides for Java biedt ondersteuning voor bijna alle functies die worden ondersteund door het PPT-documentformaat. Het omvat niet alleen de basis- en geavanceerde functies die door verschillende versies van Microsoft PowerPoint worden geleverd voor PPT-documentbewerkingen, maar ook functies die zelfs niet door Microsoft PowerPoint worden ondersteund. Het belangrijkste voordeel van het gebruik van de Aspose.Slides for Java API-bibliotheek is het gebruiksgemak bij het verwerken van dergelijke functies.

Naast de basis taken die verband houden met het maken, lezen en schrijven van PPT-documentbestanden, biedt Aspose.Slides for Java verschillende extra functies:
- Importeer andere Microsoft Office-bestandsformaten als [OLE objects into PPT documents](/slides/nl/java/manage-ole/).
- [Export PPT‑documenten naar PDF](/slides/nl/java/convert-powerpoint-to-pdf/).
- Exporteer dia's in de PPT‑documenten naar SVG-formaten.
- Render dia's naar elk afbeeldingsformaat dat door het Java-framework wordt ondersteund.
- Stel de grootte van dia's in PPT‑documenten in.
- Beheer animaties op vormen.
- Beheer diavoorstellingen.
- [Opmaak van tekst op dia's](/slides/nl/java/text-formatting/).
- Extraheer tekst uit PPT‑documenten.
- [Tabellen op dia's verwerken](/slides/nl/java/powerpoint-table/).
- Kopieer automatisch masters met behulp van [de kloonfunctie](/slides/nl/java/clone-slides/).
