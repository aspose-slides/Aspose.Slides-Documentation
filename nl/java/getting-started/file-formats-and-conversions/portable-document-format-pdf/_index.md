{{% alert color="info" title="Opmerking" %}}

Het [Portable Document Format](https://en.wikipedia.org/wiki/PDF) is een bestandsformaat dat door Adobe Systems is gecreëerd om documenten tussen organisaties uit te wisselen. Het doel van het formaat was om inhoud en lay-out gelijk te houden, ongeacht het platform waarop het wordt bekeken. Aspose.Slides for Java maakt het mogelijk om presentaties om te zetten naar PDF.

{{% /alert %}}

## **PDF in Aspose.Slides voor Java**
Elke presentatie die kan worden geladen in Aspose.Slides for Java kan worden geconverteerd naar een PDF die voldoet aan [PDF 1.5](https://en.wikipedia.org/wiki/PDF), [PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A), [PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) of [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA), afhankelijk van uw keuze. Aspose.Slides for Java exporteert presentaties naar PDF en in de meeste gevallen ziet de gegenereerde PDF er precies uit als de oorspronkelijke presentatie.

Aspose.Slides ondersteunt de volgende presentatie‑eigenschappen bij het converteren naar PDF:

- Afbeeldingen, tekstvakken en andere vormen.
- Tekst en opmaak.
- Alinea’s en opmaak.
- Hyperlinks.
- Kop‑ en voetteksten.
- Opsommingstekens.
- Tabellen.

U kunt presentaties rechtstreeks exporteren naar PDF met Aspose.Slides for Java: u heeft geen ander component nodig. Bovendien kunt u de export van presentatie naar PDF aanpassen met verschillende opties zoals uitgelegd in [Converteer PPT en PPTX naar PDF](/slides/nl/java/convert-powerpoint-to-pdf/).
