Dit is een historische pagina, bewaard voor bestaande koppelingen. Hij beschrijft niet de huidige versie van Aspose.Slides voor Java. Voor de formaten die Aspose.Slides voor Java laadt, importeert, opslaat en rendert, en de API voor elk ervan, zie [Ondersteunde bestandsformaten](/slides/nl/java/supported-file-formats/). {{% /alert %}}

{{% alert color="info" title="Opmerking" %}}

De [XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) is een paginabeschrijvingstaal en een vaste‑documentindeling die oorspronkelijk door Microsoft is ontwikkeld. Net als PDF is XPS ontworpen om de documentgetrouwheid te behouden en een apparaat‑onafhankelijke weergave van het document te bieden.

{{% /alert %}}

## **XPS in Aspose.Slides voor Java**
Elk presentatiedocument dat kan worden geladen door Aspose.Slides voor Java, kan worden geconverteerd naar XPS‑indeling. Aspose.Slides voor Java gebruikt de high‑fidelity paginalay‑out‑ en renderengine om output te produceren in een vaste‑layout XPS‑documentindeling.
U kunt meer leren over het exporteren van presentatiedocumenten naar XPS‑documenten via Aspose.Slides voor Java in [PowerPoint‑presentaties converteren naar XPS](/slides/nl/java/convert-powerpoint-to-xps/).
