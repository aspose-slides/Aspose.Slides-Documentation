{{% alert color="info" %}}

De [XML Parser Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) is een paginabeschrijvingstaal en een vastdocumentformaat dat oorspronkelijk door Microsoft is ontwikkeld. Net als PDF is XPS ontworpen om documentgetrouwheid te behouden en een apparaatonafhankelijke weergave van documenten te bieden.

{{% /alert %}}

## **XPS in Aspose.Slides voor Java**
Elk presentatiedocument dat door Aspose.Slides for Java kan worden geladen, kan worden geconverteerd naar XPS‑formaat. Aspose.Slides for Java gebruikt de hooggetrouwe paginalay‑out en renderengine om output te produceren in een vast‑lay‑out XPS‑documentformaat.
U kunt meer leren over het exporteren van presentatiedocumenten naar XPS‑documenten via Aspose.Slides for Java in [Converteren naar XPS](https://docs.aspose.com/slides/nl/java/convert-powerpoint-to-xps/).
