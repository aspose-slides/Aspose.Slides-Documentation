## **Ondersteunde Platforms**
Aspose.Slides for PHP via Java is een platformonafhankelijke API. Het kan worden gebruikt op elk platform (Windows, Linux, macOS, enz.) waar PHP 7 of hoger is geïnstalleerd. Oracle JDK 7 of hoger is een andere vereiste.

## **Bestandsformaten en Conversies**
Aspose.Slides for PHP via Java ondersteunt de meeste PowerPoint‑documentformaten. Het laat u ook toe ze te exporteren naar de populaire bestandsformaten die organisaties onderling gebruiken en delen. Ga door deze details:

|**Functie**|**Beschrijving**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java biedt de snelste verwerking voor dit presentatiedocumentformaat.|
|PPT naar PPTX conversie|Aspose.Slides for PHP via Java ondersteunt PPT naar PPTX conversie|
|Portable Document Format (PDF)|U kunt alle ondersteunde bestandsformaten met één methode exporteren naar Adobe Portable Document Format (PDF) documenten.|
|XML Parser Specification (XPS)|U kunt alle ondersteunde bestandsformaten met één methode exporteren naar XML Parser Specification (XPS) documenten.|
|Tagged Image File Format (TIFF)|U kunt alle ondersteunde presentatiebestandsformaten exporteren naar Tagged Image File Format (TIFF).|
|PPTX naar HTML Conversie|Aspose.Slides for PHP via Java ondersteunt de conversie van PresentationEx naar HTML‑formaat.|

## **Presentatie Rendering**
Aspose.Slides for PHP via Java ondersteunt rendering met hoge getrouwheid van dia's in presentaties naar verschillende grafische formaten. Bekijk deze details:

|**Functie**|**Beschrijving**|
| :- | :- |
|Java‑ondersteunde afbeeldingsformaten|Met Aspose.Slides for PHP via Java kunt u presentatiedia's en afbeeldingen op dia's renderen naar alle door Java ondersteunde grafische formaten, zoals TIFF, PNG, BMP, JPEG, GIF.|
|SVG‑formaat|Aspose.Slides for PHP via Java biedt ook ingebouwde methoden waarmee u presentatiedia's kunt exporteren naar Scalable Vector Graphics (SVG)-formaten.|

## **Veelgestelde Vragen**

### Moet ik Microsoft PowerPoint op de server/PC installeren zodat de bibliotheek werkt?

Nee. PowerPoint is niet vereist; Aspose.Slides is een zelfstandige engine voor het maken, bewerken, converteren en renderen van presentaties.

### Hoe werkt multithreading? Kan verwerking worden geparallelliseerd?

Het is veilig om verschillende documenten in verschillende threads te verwerken; hetzelfde [presentatie](https://reference.aspose.com/slides/nl/php-java/aspose.slides/presentation/) object mag niet gelijktijdig worden gebruikt door [meerdere threads](/slides/nl/php-java/multithreading/) .

### Worden wachtwoorden en versleuteling van bestanden ondersteund?

Ja. [U kunt](/slides/nl/php-java/password-protected-presentation/) versleutelde presentaties openen, een open‑ en schrijfwachtwoord instellen of verwijderen, en de beschermingsstatus controleren.

### Moet ik me bekommeren om lettertype‑pakketten in Linux‑containers?

Ja. Het wordt aanbevolen om veelvoorkomende lettertype‑pakketten te installeren en/of expliciet [lettertype‑mappen op te geven](/slides/nl/php-java/custom-font/) in uw applicatie om onverwachte substituties te voorkomen.

### Zijn er beperkingen in de evaluatieversie?

In [evaluatiemodus](/slides/nl/php-java/licensing/) wordt een watermerk aan de output toegevoegd en gelden bepaalde beperkingen; een [30‑daagse tijdelijke licentie](https://purchase.aspose.com/temporary-license/) is beschikbaar voor volledig‑functietesten.

### Wordt het importeren van externe formaten in een presentatie (PDF/HTML → PPTX) ondersteund?

Ja. U kunt [PDF‑pagina's en HTML‑inhoud](/slides/nl/php-java/import-presentation/) aan een presentatie toevoegen, waardoor ze in dia’s worden omgezet.
