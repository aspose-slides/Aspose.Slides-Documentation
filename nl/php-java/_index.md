**Welkom bij Aspose.Slides for PHP via Java**

![Aspose.Slides for PHP via Java productlogo](aspose_slides-for-php-via-java.png)

Aspose.Slides for PHP via Java is een class library die uw applicaties in staat stelt PowerPoint®-documenten te lezen en te schrijven zonder Microsoft PowerPoint® te gebruiken.

Aspose.Slides for PHP via Java is de eerste en enige component die de functionaliteit biedt om PowerPoint®-documenten te beheren.

Aspose.Slides for PHP via Java biedt vele belangrijke functies, zoals het beheren van tekst, vormen, tabellen en animaties, het toevoegen van audio en video aan dia's, het bekijken van dia's, het exporteren van dia's naar SVG, PDF-formaat en meer.
