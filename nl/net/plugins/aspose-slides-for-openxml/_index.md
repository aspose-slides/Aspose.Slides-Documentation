## **Wat is OpenXML?**
OpenXML SDK is een .NET‑SDK van Microsoft om Microsoft Office‑bestandsformaten vanaf 2007 te verwerken. Deze bestandsformaten zijn in wezen zip‑pakketten en de Open XML SDK for Office vereenvoudigt het manipuleren van Open XML‑pakketten en de onderliggende Open XML‑schema‑elementen in een pakket. De klassen in de Open XML SDK kapselen vele veelvoorkomende taken die ontwikkelaars uitvoeren op Open XML‑pakketten, zodat je complexe bewerkingen kunt uitvoeren met enkele regels code.

Nadat je Open XML SDK 2.5 hebt geïnstalleerd, open je je bestaande project of applicatie in Visual Studio, of maak je een nieuw project of een nieuwe applicatie aan. Voeg vervolgens in je project of applicatie referenties toe aan de volgende componenten:

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides for .NET**
Aspose.Slides for .NET is een unieke PowerPoint®‑beheerscomponent die .NET‑toepassingen in staat stelt PowerPoint‑documenten te lezen, te schrijven en te bewerken zonder Microsoft PowerPoint te gebruiken.

Aspose.Slides for .NET is de eerste en enige .NET‑component die functionaliteit biedt om PowerPoint‑documenten binnen je eigen applicaties te beheren. Zoals alle Aspose‑.NET‑componenten is Aspose.Slides geschreven in managed C#, heeft een ongelooflijke prijs‑/waarde‑verhouding en is razendsnel.
## **Aspose.Slides for OpenXML**
## **Inleiding**
Ontwikkelaars die op zoek zijn naar bestandsformaat‑bibliotheken moeten de mogelijkheden die door de beschikbare bibliotheken op de markt worden geboden, doornemen. Over het algemeen worden twee factoren in overweging genomen bij het kiezen van een optie:

- Functionaliteit
- Inspanning die nodig is om de bibliotheek te gebruiken

Ben je een .NET‑ontwikkelaar die op zoek is naar een snellere, eenvoudige en lichtgewicht bibliotheek om bestandsformaten te verwerken, dan kun je VSTO (Visual Studio Tools for Office) vergelijken met Aspose. In dit geval helpt dit project je om functionaliteit en code in beide bibliotheken te vergelijken.
