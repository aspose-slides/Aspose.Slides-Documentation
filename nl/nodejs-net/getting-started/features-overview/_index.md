## **Ondersteunde platformen**
Aspose.Slides for Node.js via .NET is een platformonafhankelijke API. Het kan op elk platform (Windows, Linux, macOS, enz.) gebruikt worden waar Node.js 7 of hoger geïnstalleerd is. Oracle JDK 8 of hoger is een aanvullende vereiste.

## **Bestandsformaten en conversies**
Aspose.Slides for Node.js via .NET ondersteunt de meeste PowerPoint‑documentformaten. Het stelt u ook in staat om ze te exporteren naar de populaire bestandsformaten die organisaties gebruiken en onderling delen. Bekijk deze details:

|**Functie**|**Beschrijving**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET biedt de snelste verwerking voor dit presentatie‑documentformaat.|
|PPT‑naar‑PPTX-conversie|Aspose.Slides for Node.js via .NET ondersteunt PPT‑naar‑PPTX-conversie|
|Portable Document Format (PDF)|U kunt alle ondersteunde bestandsformaten met één enkele methode exporteren naar Adobe Portable Document Format (PDF)-documenten.|
|XML Parser Specification (XPS)|U kunt alle ondersteunde bestandsformaten met één enkele methode exporteren naar XML Parser Specification (XPS)-documenten.|
|Tagged Image File Format (TIFF)|U kunt alle ondersteunde presentatie‑bestandsformaten exporteren naar Tagged Image File Format (TIFF).|
|PPTX‑naar‑HTML-conversie|Aspose.Slides for Node.js via .NET ondersteunt de conversie van PresentationEx naar HTML-formaat.|

## **Presentatie‑weergave**
Aspose.Slides for Node.js via .NET ondersteunt het renderen van dia's in een presentatie met hoge getrouwheid naar verschillende grafische formaten. Bekijk deze details:

|**Functie**|**Beschrijving**|
| :- | :- |
|.NET‑ondersteunde beeldformaten|Met Aspose.Slides for Node.js via .NET kunt u presentatiedia's en afbeeldingen op dia's renderen naar alle door .NET ondersteunde grafische formaten, zoals TIFF, PNG, BMP, JPEG, GIF.|
|SVG‑formaat|Aspose.Slides for Node.js via .NET biedt ook ingebouwde methoden waarmee u presentatiedia's kunt exporteren naar Scalable Vector Graphics (SVG)-formaten.|

## **Inhoudsfuncties**
Aspose.Slides for Node.js via .NET stelt u in staat om bijna alle items of inhoud van presentatiedocumenten te openen, te wijzigen of te maken. Bekijk deze details:

|**Functie**|**Beschrijving**|
| :- | :- |
|Master‑dia's|De master‑dia's bepalen de lay‑out van de normale dia's. Aspose.Slides for Node.js via .NET stelt u in staat om de master‑dia's van presentatiedocumenten te openen en te wijzigen.|
|Normale dia's|Met Aspose.Slides for Node.js via .NET kunt u nieuwe dia's van verschillende typen maken; u kunt ook bestaande dia's in de presentaties openen en wijzigen.|
|Dia’s klonen / kopiëren|Er zijn ingebouwde methoden die door Aspose.Slides for Node.js via .NET worden geleverd en waarmee u bestaande dia's binnen een presentatie kunt klonen of kopiëren. U kunt gekopieerde en gekloonde dia's ook van de ene presentatie naar de andere gebruiken. Omdat een dia zijn lay‑out erft van de master‑dia, kopiëren de ingebouwde kloonmethoden de master automatisch bij het klonen.|
|Dia‑secties beheren|Methoden om dia's in verschillende secties binnen een presentatie te organiseren.|
|Plaathouders en tekst‑holders|U kunt de plaatsaanduidingen en tekst‑holders in een dia openen. Bovendien kunt u een dia met tekst‑holders vanaf nul maken met de juiste methode.|
|Kop‑ en voetteksten|Aspose.Slides for Node.js via .NET vergemakkelijkt het beheer van kop‑ en voetteksten in dia's.|
|Notities in dia's|Met Aspose.Slides for Node.js via .NET kunt u notities die aan een dia zijn gekoppeld openen en wijzigen, en ook nieuwe notities toevoegen.|
|Een vorm vinden|U kunt ook een specifieke vorm op een dia vinden met behulp van de alternatieve tekst die aan de vorm is gekoppeld.|
|Achtergronden|Aspose.Slides for Node.js via .NET stelt u in staat om met achtergronden te werken die gekoppeld zijn aan een master‑ of normale dia in een presentatie.|
|Tekstvakken|Tekstvakken kunnen vanaf nul gemaakt worden. U kunt bestaande tekstvakken openen. U kunt hun tekst ook wijzigen zonder de oorspronkelijke opmaak te verliezen.|
|Rechthoekige vormen|U kunt rechthoekige vormen maken of wijzigen met Aspose.Slides for Node.js via .NET.|
|Polylijn‑vormen|U kunt polylijn‑vormen maken of wijzigen met Aspose.Slides for Node.js via .NET.|
|Ellipsvormen|U kunt ellipsvormen maken of wijzigen met Aspose.Slides for Node.js via .NET.|
|Groepsvormen|Aspose.Slides for Node.js via .NET ondersteunt groepsvormen.|
|Auto‑vormen|Aspose.Slides for Node.js via .NET ondersteunt auto‑vormen.|
|SmartArt|Aspose.Slides for Node.js via .NET biedt ondersteuning voor SmartArt‑vormen in MS PowerPoint.|
|Charts|Aspose.Slides for Node.js via .NET biedt ondersteuning voor MSO‑grafieken in PowerPoint.|
|Vorm‑serialisatie|Aspose.Slides for Node.js via .NET ondersteunt een groot aantal vormen. Wanneer Aspose.Slides for Node.js via .NET geen ondersteuning biedt voor een bepaalde vorm, kunt u een serialisatiemethode gebruiken om die vorm van een bestaande dia te serialiseren. Op deze manier kunt u de vorm verder gebruiken volgens uw wensen.|
|Afbeeldingsframes|U kunt afbeeldingen in afbeeldingsframes beheren met Aspose.Slides for Node.js via .NET.|
|Audio‑frames|U kunt audio‑bestanden koppelen of insluiten in audio‑frames op dia's met Aspose.Slides for Node.js via .NET.|
|Video‑frames|U kunt videobestanden beheren in video‑frames. Aspose.Slides for Node.js via .NET biedt ook ondersteuning voor gekoppelde en ingesloten video's.|
|OLE‑frame|U kunt OLE‑objecten beheren in OLE‑frames met Aspose.Slides for Node.js via .NET.|
|Tabellen|Aspose.Slides for Node.js via .NET ondersteunt tabellen in dia's.|
|ActiveX‑besturingselementen|Ondersteuning voor ActiveX‑besturingselementen.|
|VBA‑macro's|Ondersteuning voor het beheren van VBA‑macro's binnen presentaties.|
|Tekstframe|U kunt de tekst van elke vorm benaderen via het tekstframe dat aan die vorm is gekoppeld.|
|Tekstscannen|U kunt tekst in een presentatie op presentatie‑ of dia‑niveau scannen met ingebouwde scanmethoden.|
|Animaties|U kunt animaties op vormen toepassen.|
|Diavoorstellingen|Aspose.Slides for Node.js via .NET ondersteunt diavoorstellingen en dia‑overgangen.|

## **Opmaakeigenschappen**
Met Aspose.Slides for Node.js via .NET kunt u teksten en vormen op dia's in presentaties opmaken. Bekijk deze details:

|**Functie**|**Beschrijving**|
| :- | :- |
|Tekstopmaak|<p>In Aspose.Slides for Node.js via .NET kunt u teksten beheren via de tekstframes die aan de vormen zijn gekoppeld. Hierdoor kunt u teksten opmaken met behulp van de alinea’s en delen die aan de tekstframes zijn gekoppeld. Deze tekstelementen kunnen worden opgemaakt via Aspose.Slides for Node.js via .NET.</p><p>- Lettertype</p><p>- Lettergrootte</p><p>- Letterkleur</p><p>- Lettertinten</p><p>- Uitlijning van alinea</p><p>- Alinea‑opsomming</p><p>- Oriëntatie van alinea</p>|
|Vormopmaak|<p>In Aspose.Slides for Node.js via .NET is het basiselement van een dia een vorm. U kunt deze vorm‑elementen opmaken met Aspose.Slides for Node.js via .NET:</p><p>- Positie</p><p>- Grootte</p><p>- Lijn</p><p>- Opvulling (inclusief patroon, verloop, effen)</p><p>- Tekst</p><p>- Afbeelding</p>|
