## **目的**
效能通常是選擇元件時的第一個關鍵因素。本文衡量了 Aspose.Slides for C++ 和 VSTO 2008 的效能。簡單的測試在相似的作業系統、硬體元件和配置下進行。

本文提供包括 **Aspose.Slides for C++** 和 **VSTO 2008** 在內的產品效能測量。此處提出的效能估計旨在協助您了解在相似配置、普通硬體上執行的常見情境中，不同元件的預期表現。當然，您的應用程式效能受到資料、資料存取模式、快取大小、其他配置參數、作業系統與硬體等因素的影響。此基準測試旨在示範元件在最小硬體條件下的運作表現，硬體越快，元件處理任務的速度也越快。

## **測試方法論**
所有效能測試均在通用硬體與作業系統組合上執行，未使用客製化配置、調校或其他效能提升技術。所有測試皆在同一系統上以元件安裝執行，該系統在其他情況下保持閒置。為取得精確的讀數，我們一次執行所有任務兩至三次，以更好評估元件並取得精確讀數。
