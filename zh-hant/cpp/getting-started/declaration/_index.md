{{% alert color="info" %}}

所有 Aspose C++ 元件都需要 Full Trust 權限集。原因是，Aspose C++ 元件必須存取註冊表設定、系統檔案（虛擬目錄之外）以執行某些操作，如字型解析等。此外，Aspose C++ 元件是基於核心 C++ 系統類別，而這些類別在許多情況下也需要 Full Trust 權限集。

{{% /alert %}}
