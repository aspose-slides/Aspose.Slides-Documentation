## **歡迎使用 Aspose.Slides for C++！**

Aspose.Slides for C++ 是一套 Microsoft PowerPoint® 管理 API，讓 C++ 應用程式能在不使用 Microsoft PowerPoint® 的情況下讀寫 PowerPoint® 文件。Aspose.Slides for C++ 是首個也是唯一提供管理 PowerPoint® 文件功能的元件。Aspose.Slides for C++ 提供許多關鍵功能，例如管理文字、形狀、表格和動畫、為投影片加入音訊與視訊、預覽投影片、將投影片匯出為 SVG、PDF 格式等。

## **產品說明**
Aspose.Slides for C++ 使用原生 C++ 開發。目前已編譯為 Windows x64 環境，未來也會編譯支援 Linux 環境。

Aspose.Slides for C++ 不僅能開啟來自不同來源的 PowerPoint 檔案，還允許以多種方式儲存簡報。例如，您可以將簡報儲存為 PPT，也可以儲存為 PDF 格式。此外，還能將投影片儲存為影像。Aspose.Slides for C++ 幾乎提供了 Microsoft PowerPoint 中所有功能。其多樣性在於，您不僅可以在投影片中加入表格和各種形狀，還可以加入不同類型的框架（文字、音訊與視訊框架）。

## **豐富的功能集合**
Aspose.Slides for C++ 的功能可分為以下領域：

1. 簡報功能。
1. 投影片功能。
1. 圖形與多媒體功能。
1. 表格功能
1. 文字與段落功能
1. 進階功能

### **簡報功能**
- 從不同來源開啟 Microsoft PowerPoint 簡報。
- 以不同的 Microsoft PowerPoint 格式儲存簡報。
- 從頭建立簡報。
- 在不使用其他元件的情況下將簡報轉換為 PDF 文件。
- 讀取或修改簡報的文件屬性。
- 為簡報套用保護。
- 匯出簡報為 PDF。
- 匯出簡報為 XPS。
- 匯出簡報為 SWF。
- 匯出簡報為 PDF 附註。
- 匯出簡報為 HTML。

### **投影片功能**
- 從頭建立新投影片並加入簡報。
- 依投影片在簡報中的位置存取任意投影片。
- 複製或克隆投影片至相同或其他簡報。
- 編輯與刪除投影片。
- 自動複製含投影片的母片。
- 預覽投影片。
- 取得或設定投影片名稱。
- 將投影片儲存為影像。
- 匯出投影片為 SVG 格式。
- 在簡報中使用多個母片。
- 以任何支援的樣式填滿投影片背景。
- 新增或管理投影片備註。
- 動態設定新的投影片母片與樣式。
- 新增或修改投影片放映過渡效果。
- 新增 Morph 轉場。

### **圖形與多媒體功能**
- 建立或管理線條、矩形、橢圓、折線等形狀。
- 管理形狀的線條樣式。
- 取得形狀的替代文字。
- 旋轉或翻轉形狀。
- 以不同樣式填充形狀，例如純色、漸層、圖案、紋理與圖片。
- 使用 48 種預先定義的圖案與 24 種紋理。
- 為形狀指派連結。
- 讀取、修改或新增投影片與形狀的動畫效果。
- 新增圖片至簡報或管理現有圖片。
- 為簡報新增圖片項目符號或管理現有項目符號。
- 為簡報新增音訊框架或管理現有音訊框架。
- 為簡報新增視訊框架或管理現有視訊框架。

### **表格功能**
- 從頭建立表格並加入投影片。
- 調整表格大小與位置。
- 存取表格中的任意儲存格。
- 變更任意儲存格的格式與邊框。
- 調整欄寬與列高。
- 新增與刪除欄與列。
- 為整個表格設定邊框寬度與顏色。

### **文字與段落功能**
- 取得與設定文字佔位符與文字框中的文字。
- 取得佔位符的類型。
- 變更文字框內的文字格式。
- 新增或管理簡報中使用的字型。
- 變更文字與文字格式。
- 建立或管理文字連結。
- 支援 Tab 與有效的 Tab。
- 為幾乎所有形狀類型新增文字框。
- 存取並修改文字框的邊距與文字環繞設定。
- 存取並修改段落縮排。

### **進階功能**
- 存取簡報中嵌入的 OLE 物件。
- 鎖定簡報。

## **支援平台**
- Windows x64/x86（Microsoft Visual Studio 2017 以上）。
- Linux（Clang 3.9 以上，GCC 6.1 以上）。
- macOS（Xcode 13.4 以上）。

## **常見問答**

**它是否支援 PDF 存檔與可及性等級（PDF/A 與 PDF/UA）？**

是的。您可以透過設定 [PDF 匯出選項](https://reference.aspose.com/slides/zh-hant/cpp/aspose.slides.export/pdfoptions/) 將檔案儲存為 PDF/A-2a/2b/2u、PDF/A-3a/3b 以及 PDF/UA。

**是否提供字型替代機制並支援自訂字型以確保正確呈現？**

是的。程式庫允許您 [載入自訂字型](/slides/zh-hant/cpp/custom-font/) 並 [定義回退規則](/slides/zh-hant/cpp/fallback-font/)，在轉換與呈現過程中可靠地替代缺少的字形。

**我能在未完整開啟檔案的情況下偵測其是否有密碼保護嗎？**

可以。您可以 [檢查簡報](/slides/zh-hant/cpp/examine-presentation/) 以判斷是否需要密碼才能載入完整文件。

**處理與轉換是否需要安裝 Microsoft PowerPoint？**

不需要。Aspose.Slides 是獨立的引擎，伺服器或工作站上不必安裝 PowerPoint。

**在多執行緒環境中處理簡報是否安全？**

是的，您可以在不同執行緒中平行處理不同文件；只要避免在多執行緒間同時使用同一個簡報實例即可，請參考 [跨執行緒使用](/slides/zh-hant/cpp/multithreading/)。

**巨集是否會被保留，且我能管理 PPTM/PPSM 檔案中的 VBA 嗎？**

會的。支援含巨集的簡報，您可以 [檢查與管理 VBA 專案](/slides/zh-hant/cpp/presentation-via-vba/)，相關 API 位於 [VBA 參考](/slides/zh-hant/cpp/presentation-via-vba/)。

**我可以將 PDF 或 HTML 轉回 PowerPoint 投影片嗎？**

可以。您能 [匯入 PDF 頁面或 HTML 內容](/slides/zh-hant/cpp/import-presentation/) 以建立或填充簡報投影片。

**是否支援 XPS 匯出，且能控制 XPS 輸出的品質與內容？**

是的。提供 [匯出至 XPS](/slides/zh-hant/cpp/convert-powerpoint-to-xps/) 功能，且透過 [儲存選項](/slides/zh-hant/cpp/convert-powerpoint-to-xps/) 可調整輸出品質與所含內容。

**我能將投影片轉為影像並控制輸出品質嗎？**

可以。投影片可 [渲染為 PNG、JPEG、GIF、BMP、TIFF](/slides/zh-hant/cpp/convert-powerpoint-to-png/) 等格式，並可細部調整尺寸與品質。

**是否支援數學公式（MathML/MathText）且能匯出？**

支援。您可以 [建立與編輯數學文字](/slides/zh-hant/cpp/powerpoint-math-equations/) 並 [匯出方程式](/slides/zh-hant/cpp/exporting-math-equations/)，包括匯出為 MathML。

**程式庫如何處理加密與密碼（開啟、設定、移除）？**

[支援](/slides/zh-hant/cpp/password-protected-presentation/) 開啟已加密的簡報、設定或移除開啟與修改的密碼，並可檢查檔案的保護狀態。
