## **檔案格式與轉換**
Aspose.Slides forC++ 支援大多數 PowerPoint 文件格式，並將它們匯出為在組織間廣泛使用的流行格式。以下表格列出這些格式：

|**功能**|**說明**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/zh-hant/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ 提供此簡報文件格式最快速的處理速度。|
|[Portable Document Format (PDF)](/slides/zh-hant/cpp/portable-document-format-pdf/)|支援的檔案格式可透過單一方法匯出為 Adobe Portable Document Format (PDF) 文件。|
|[XML Parser Specification (XPS)](/slides/zh-hant/cpp/xml-parser-specification-xps/)|所有支援的檔案格式都能以單一方法匯出為 XML Parser Specification (XPS) 文件。|
|[PresentationML (PPTX, XML)](/slides/zh-hant/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ 支援 OOXML 簡報格式（亦稱 PresentationML 或 PPTX）的處理。|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/zh-hant/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ 支援將簡報轉換為 HTML 格式。|

## **渲染**
Aspose.Slides for C++ 支援將簡報文件中的投影片高保真度渲染為下列各種圖形格式：

|**功能**|**說明**|
| :- | :- |
|C++ 支援的影像格式|使用 Aspose.Slides for C++，您不僅可以渲染簡報投影片，還能將投影片上的影像渲染成所有 C++ 支援的圖形格式，如 PNG、BMP 與 JPEG。|
|SVG 格式|Aspose.Slides for C++ 亦提供內建方法將簡報投影片匯出為可伸縮向量圖形（SVG）格式。|

|**功能**|**說明**|

## **FAQ**

**是否需要在伺服器或 PC 上安裝 Microsoft PowerPoint 才能使用本函式庫？**

不需要。PowerPoint 並非必備，Aspose.Slides 是一套獨立的引擎，提供建立、編輯、轉換與渲染簡報的功能。

**多執行緒是如何運作的？可以平行化處理嗎？**

在不同執行緒中處理不同的文件是安全的；同一個 [presentation](https://reference.aspose.com/slides/zh-hant/cpp/aspose.slides/presentation/) 物件不能同時被 [multiple threads](/slides/zh-hant/cpp/multithreading/) 使用。

**是否支援檔案密碼與加密？**

是的。您可以 [開啟受保護的簡報](/slides/zh-hant/cpp/password-protected-presentation/)、設定或移除開啟與寫入密碼，並檢查保護狀態。

**在 Linux 容器中需要特別處理字型套件嗎？**

需要。建議安裝常見的字型套件，或在應用程式中明確 [指定字型目錄](/slides/zh-hant/cpp/custom-font/)，以避免意外的字型替代。

**評估版有什麼限制？**

在 [evaluation mode](/slides/zh-hant/cpp/licensing/) 下，輸出會加入浮水印，且會有特定限制；可取得 [30 天暫時授權](https://purchase.aspose.com/temporary-license/) 以完整測試所有功能。

**是否支援將外部格式匯入簡報（PDF/HTML → PPTX）？**

支援。您可以將 [PDF 頁面與 HTML 內容](/slides/zh-hant/cpp/import-presentation/) 加入簡報，並將其轉換為投影片。
