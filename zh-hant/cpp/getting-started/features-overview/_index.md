## **檔案格式與轉換**
Aspose.Slides forC++ 支援大多數 PowerPoint 文件格式，並可將它們匯出為在組織間廣泛使用的流行格式。以下表格列出這些格式：

|**功能**|**說明**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/zh-hant/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ 提供此簡報文件格式的最快速處理。|
|[Portable Document Format (PDF)](/slides/zh-hant/cpp/portable-document-format-pdf/)|支援的檔案格式可透過單一方法匯出為 Adobe Portable Document Format (PDF) 文件。|
|[XML Parser Specification (XPS)](/slides/zh-hant/cpp/xml-parser-specification-xps/)|所有支援的檔案格式皆可透過單一方法匯出為 XML Parser Specification (XPS) 文件。|
|[PresentationML (PPTX, XML)](/slides/zh-hant/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ 支援 OOXML 簡報格式，也稱為 PresentationML 或 PPTX 的處理。|
|[PPTX 轉 HTML 轉換](https://docs.aspose.com/slides/zh-hant/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ 支援將簡報轉換為 HTML 格式。|

## **簡報渲染**
Aspose.Slides for C++ 支援將簡報文件中的投影片高忠實度地渲染為以下列出的各種圖形格式：

|**功能**|**說明**|
| :- | :- |
|C++ Supported Image Formats|使用 Aspose.Slides for C++，您不僅可以渲染簡報投影片，還可以將投影片上的影像渲染為所有 C++ 支援的圖形格式，如 PNG、BMP 和 JPEG。|
|SVG Format|Aspose.Slides for C++ 也提供內建方法將簡報投影片匯出為可縮放向量圖形（SVG）格式。|

## **內容功能**
Aspose.Slides forC++ 讓您能存取、修改或建立簡報文件中幾乎所有可能的內容。

|**功能**|**說明**|
| :- | :- |
|Master Slides|母片投影片定義一般投影片的版面配置。Aspose.Slides for C++ 讓您能存取並修改簡報文件的母片投影片。|

|Text Boxes|文字框可從頭建立。也可存取現有文字框並修改其文字，而不會失去原始文字格式。|
|Rectangle Shapes|矩形圖形可由 Aspose.Slides for C++ 建立或修改。|
|Poly Line Shapes|折線圖形也可由 Aspose.Slides for C++ 建立或修改。|
|Ellipse Shapes|橢圓圖形也由 Aspose.Slides for C++ 建立或修改。|
|Group Shapes|Aspose.Slides for C++ 支援群組圖形。|

|Shapes Serialization|雖然 Aspose.Slides for C++ 支援大量圖形，但如果有圖形不受支援，Aspose.Slides for C++ 提供序列化方法，您可透過此方法將現有投影片中的該圖形序列化，供日後 Aspose.Slides for C++ 依需求使用。|

## **FAQ**

### 我是否需要在伺服器/電腦上安裝 Microsoft PowerPoint 才能使用此函式庫？

不需要。PowerPoint 並非必要；Aspose.Slides 是一個獨立的引擎，用於建立、編輯、轉換與渲染簡報。

### 多執行緒如何運作？能否平行化處理？

在不同執行緒中處理不同文件是安全的；同一個 [presentation](https://reference.aspose.com/slides/zh-hant/cpp/aspose.slides/presentation/) 物件不得同時被 [multiple threads](/slides/zh-hant/cpp/multithreading/) 使用。

### 是否支援檔案密碼與加密？

是的。[You can](/slides/zh-hant/cpp/password-protected-presentation/) 開啟受保護的簡報、設定或移除開啟與寫入密碼，並檢查保護狀態。

### 我需要在 Linux 容器中關注字型套件嗎？

是的。建議在您的應用程式中安裝常見的字型套件和/或明確 [specify font directories](/slides/zh-hant/cpp/custom-font/) 以避免意外的替代。

### 評估版是否有限制？

在 [evaluation mode](/slides/zh-hant/cpp/licensing/) 中，輸出會加上浮水印，且會有某些限制；可使用 [30-day temporary license](https://purchase.aspose.com/temporary-license/) 獲得完整功能測試的 30 天臨時授權。

### 是否支援將外部格式匯入簡報 (PDF/HTML → PPTX)？

是的。您可以將 [PDF pages and HTML content](/slides/zh-hant/cpp/import-presentation/) 新增至簡報，將它們轉換為投影片。
