{{% alert color="info" %}} 

Aspose.Slides for C++ 是一個類別庫，可讓 C++ 應用程式在不使用 Microsoft PowerPoint® 或其他軟體的情況下讀寫簡報文件。Aspose.Slides for C++ 允許管理文字、形狀、表格與動畫，向投影片加入音訊與影片，預覽投影片，將投影片匯出為 SVG、PDF 等格式，及其他功能。

最新的 API 參考可於 [Aspose.Slides for C++ API Reference](https://reference.aspose.com/slides/zh-hant/cpp/) 找到。
