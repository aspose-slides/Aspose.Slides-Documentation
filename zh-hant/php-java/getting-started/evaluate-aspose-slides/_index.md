## **Aspose.Slides 評估**

您可以下載 Aspose.Slides 進行評估。評估套件與購買的套件相同；在您加入少量程式碼以套用授權後，即會取得授權。請參閱 [Installation](/slides/zh-hant/php-java/installation/) 以進行設定，並參閱 [Licensing](/slides/zh-hant/php-java/licensing/) 以套用授權。

未取得授權時，Aspose.Slides 在評估模式下仍提供完整功能，但有兩項限制：它會在每個儲存的簡報的每張投影片中間加入評估浮水印文字方塊，且程式碼從簡報讀取的文字會被截斷為前幾個字元，並附加有關評估限制的通知。程式碼寫入的文字則會完整保存。

{{% alert color="info" title="Note" %}}
如果您想在不受評估版限制的情況下測試 Aspose.Slides，可以申請 **30 天暫時授權**。更多資訊請參閱 [How to get a Temporary License?](https://purchase.aspose.com/temporary-license)。
{{% /alert %}}

## **常見問題**

### 我可以在評估模式下於不同執行緒中平行測試多個簡報嗎？

是的。您可以平行處理不同的文件；不應在不同執行緒之間共用相同的簡報物件 [across threads](/slides/zh-hant/php-java/multithreading/)。評估模式不會影響此行為。

### 我需要安裝 Microsoft PowerPoint 來於伺服器或 CI 環境評估此函式庫嗎？

不需要。Aspose.Slides 為獨立引擎，無論在評估或正式環境都不需要安裝 PowerPoint。

### 我能在評估模式下完整測試 PPT/PPTX 轉 PDF 與影像的轉換嗎？

是的。[converters](/slides/zh-hant/php-java/convert-presentation/) 可以正常運作；輸出結果會包含浮水印。

### 我可以使用暫時授權進行負載測試且不產生浮水印嗎？

是的。30 天的暫時授權會移除評估模式的限制，讓測試時不會產生浮水印。
