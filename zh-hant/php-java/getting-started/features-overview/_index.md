## **受支援的平台**
Aspose.Slides for PHP via Java 是一個平台無關的 API。它可在任何安裝了 PHP 7 或更高版本的平臺（Windows、Linux、macOS 等）上使用。Oracle JDK 7 或更高版本是另一項需求。

## **檔案格式與轉換**
Aspose.Slides for PHP via Java 支援大多數 PowerPoint 文件格式。它亦讓您將它們匯出為組織間常用且可共享的檔案格式。詳情如下：

|**功能**|**說明**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for PHP via Java 為此簡報文件格式提供最快的處理速度。|
|PPT to PPTX conversion|Aspose.Slides for PHP via Java 支援 PPT 轉換為 PPTX。|
|Portable Document Format (PDF)|您可以使用單一方法將所有支援的檔案格式匯出為 Adobe 可攜式文件格式（PDF）文件。|
|XML Parser Specification (XPS)|您可以使用單一方法將所有支援的檔案格式匯出為 XML 解析器規範（XPS）文件。|
|Tagged Image File Format (TIFF)|您可以將所有支援的簡報檔案格式匯出為標記圖像檔案格式（TIFF）。|
|PPTX To HTML Conversion|Aspose.Slides for PHP via Java 支援將 PresentationEx 轉換為 HTML 格式。|

## **簡報渲染**
Aspose.Slides for PHP via Java 支援將簡報投影片高保真度渲染為不同的圖形格式。詳情如下：

|**功能**|**說明**|
| :- | :- |
|Java Supported Image Formats|使用 Aspose.Slides for PHP via Java，您可以將簡報投影片及投影片上的影像渲染為所有 Java 支援的圖形格式，例如 TIFF、PNG、BMP、JPEG、GIF。|
|SVG Format|Aspose.Slides for PHP via Java 也提供內建方法，讓您將簡報投影片匯出為可縮放向量圖形（SVG）格式。|

## **常見問題**

### 我需要在伺服器 / PC 上安裝 Microsoft PowerPoint 才能使用此函式庫嗎？

不需要。PowerPoint 不是必需的；Aspose.Slides 是一個獨立的引擎，用於建立、編輯、轉換與渲染簡報。

### 多執行緒如何運作？能否平行處理？

在不同執行緒中處理不同文件是安全的；同一個[presentation](https://reference.aspose.com/slides/zh-hant/php-java/aspose.slides/presentation/) 物件不得同時被[multiple threads](/slides/zh-hant/php-java/multithreading/) 使用。

### 是否支援檔案密碼與加密？

是的。您可以[/slides/zh-hant/php-java/password-protected-presentation/](https://reference.aspose.com/slides/zh-hant/php-java/password-protected-presentation/) 開啟加密的簡報，設定或移除開啟與寫入密碼，並檢查保護狀態。

### 在 Linux 容器中需要關注字型套件嗎？

是的。建議安裝常見的字型套件，或在應用程式中明確[specify font directories](/slides/zh-hant/php-java/custom-font/) 以避免意外的字型替換。

### 評估版有什麼限制？

在[evaluation mode](/slides/zh-hant/php-java/licensing/) 下，輸出會加入浮水印，且會有特定限制；可使用[30-day temporary license](https://purchase.aspose.com/temporary-license/) 進行完整功能測試。

### 是否支援將外部格式匯入簡報（PDF/HTML → PPTX）？

是的。您可以將[/slides/zh-hant/php-java/import-presentation/](/slides/zh-hant/php-java/import-presentation/) 的 PDF 頁面與 HTML 內容加入簡報，轉換為投影片。
