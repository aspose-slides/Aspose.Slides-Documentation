您可以下載 Aspose.Slides for Python via Java 以評估其功能。評估套件與授權套件完全相同。若要在沒有評估限制的情況下使用，請在程式碼中加入幾行以[套用授權](/slides/zh-hant/python-java/licensing/)。

Aspose.Slides 的評估版（未使用授權）提供完整的產品功能，但有兩項限制：

- 它會在每個已儲存的簡報的每張投影片上新增一個評估浮水印文字框。開啟簡報時不會新增，但儲存已帶有浮水印的檔案時會再新增一個。
- 程式碼讀取的文字會被截斷，只保留前幾個字元，並附上評估限制的說明。此限制會套用於每張投影片，以及程式碼剛設定的文字與從檔案載入的文字。程式碼寫入的文字會完整儲存。

{{% alert color="info" title="Note" %}}
若要在不受評估限制的情況下測試 Aspose.Slides，您可以申請 **30 天臨時授權**。請參閱[取得臨時授權](https://purchase.aspose.com/temporary-license)以獲得更多資訊。
