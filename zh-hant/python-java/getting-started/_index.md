## **概覽**

本節說明如何準備環境並開始使用 Aspose.Slides for Python via Java。請先完成以下設定步驟，然後探索函式庫的功能以及與您專案相關的指引。

## **設定函式庫**

1. 檢閱[系統需求](/slides/zh-hant/python-java/system-requirements/)以確認作業系統、Python、Java 與 JPype 的要求。  
2. 依照[安裝說明](/slides/zh-hant/python-java/installation/)安裝必要套件，並使用範例驗證設定。  
3. 閱讀[評估 Aspose.Slides](/slides/zh-hant/python-java/evaluate-aspose-slides/)以了解評估限制與暫時授權選項。  
4. 依照[授權](/slides/zh-hant/python-java/licensing/)說明套用您的授權。

## **探索功能與相容性**

- [產品概述](/slides/zh-hant/python-java/product-overview/) 介紹函式庫及其簡報處理功能。  
- [支援的檔案格式](/slides/zh-hant/python-java/supported-file-formats/) 列出可載入、匯入、儲存與匯出的簡報格式。  
- [功能概覽](/slides/zh-hant/python-java/features-overview/) 彙整轉換、渲染、編輯與格式設定功能。  
- [限制與 API 差異](/slides/zh-hant/python-java/limitations-and-api-differences/) 說明在 Python 中使用 Java API 時需留意的限制與差異。

## **取得協助**

請參閱[產品支援](/slides/zh-hant/python-java/product-support/)以獲得故障排除指引、問題回報方式與其他資源連結。

## **常見問題**

**如果我從未使用過 Aspose.Slides for Python via Java，應從哪裡開始？**

先從上方的系統需求與安裝說明開始。安裝說明中包含可執行的範例，您可以藉此驗證環境。

**我該在哪裡檢查函式庫是否支援我的簡報格式？**

請使用支援的檔案格式檢查輸入與輸出格式，之後參考功能概覽了解可執行的操作。

**在將 Java 範例改寫為 Python 時，我應先閱讀哪些內容？**

請閱讀限制與 API 差異，以取得有關匯入、資源清理與檔案處理的指引。
