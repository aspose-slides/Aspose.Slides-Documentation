本文說明 Aspose.Slides for Python via Java 的簡報處理功能。欲了解支援的作業系統與相依性，請參閱 [系統需求](/slides/zh-hant/python-java/system-requirements/)。

## **檔案格式與轉換**

Aspose.Slides for Python via Java 讓您在簡報格式之間轉換並將簡報匯出為文件與網頁格式。請參閱 [支援的檔案格式](/slides/zh-hant/python-java/supported-file-formats/) 以取得完整格式表，並了解載入簡報、匯入內容與匯出輸出的區別。

## **簡報呈現**

Aspose.Slides for Python via Java 提供高保真度的投影片呈現，可輸出為點陣圖或向量圖以供預覽及其他視覺輸出。它亦允許您在投影片上渲染圖像。欲了解可用的圖像格式與匯出說明，請參閱 [支援的檔案格式](/slides/zh-hant/python-java/supported-file-formats/#supported-file-formats)。

## **內容功能**

Aspose.Slides for Python via Java 允許您存取、修改與建立幾乎所有類型的簡報內容，說明如下：

|**功能**|**說明**|
| :- | :- |
|簡報|您可以從頭建立簡報或開啟現有檔案。|
|文件屬性|您可以讀取與修改文件屬性。|
|簡報保護|您可以設定密碼保護並管理簡報保護設定。|
|母片|母片定義普通投影片的版面配置。Aspose.Slides for Python via Java 允許您在簡報中存取與修改母片。|
|普通投影片|您可以在簡報中新增、存取、編輯、重新排序與刪除投影片。|
|投影片版面配置|您可以使用投影片版面配置。|
|複製與克隆投影片|內建方法允許您在同一簡報或不同簡報之間克隆或複製投影片。克隆投影片時，這些方法會自動複製相關的母片。|
|投影片分節|您可以在簡報中將投影片組織成分節。|
|版位與文字持有者|您可以存取投影片上的版位與文字持有者，亦可從頭建立含文字持有者的投影片。|
|頁首與頁腳|Aspose.Slides for Python via Java 讓您管理頁首與頁腳。|
|投影片備註|您可以存取、加入與修改投影片備註，並於匯出為 PDF 或 TIFF 時一併包含。|
|尋找圖形|您可以使用圖形的替代文字在投影片上找出特定圖形。|
|替代文字|您可以讀取與更新圖形的替代文字。|
|超連結|您可以讀取與更新圖形上的超連結，並為文字加入超連結。|
|背景|您可以處理簡報中母片與普通投影片的背景。|
|文字方塊|您可以從頭建立文字方塊、存取現有文字方塊，並在保留原始格式的情況下修改其文字。|
|矩形圖形|您可以建立與修改矩形圖形。|
|線條圖形|您可以建立與修改線條圖形。|
|折線圖形|您可以建立與修改折線圖形。|
|橢圓圖形|您可以建立與修改橢圓圖形。|
|群組圖形|Aspose.Slides for Python via Java 支援群組圖形。|
|AutoShapes|Aspose.Slides for Python via Java 支援 AutoShapes。|
|SmartArt|您可以在簡報中建立與編輯 SmartArt 圖形。|
|圖表|您可以在 PowerPoint 簡報中建立與編輯 Microsoft Office 圖表。|
|圖形序列化|Aspose.Slides for Python via Java 支援多種圖形類型。對於不支援的圖形，您可以使用序列化以保留現有投影片中的圖形以供重新使用。|
|圖形鎖定|您可以套用圖形鎖定以限制編輯操作。|
|圖片框|您可以管理圖片框中的圖片。|
|音訊框|您可以在投影片的音訊框中連結或嵌入音訊檔案。|
|影片框|您可以管理影片框中的連結與嵌入影片。|
|OLE 框|您可以管理 OLE 框中的 OLE 物件。|
|表格|您可以建立、移動與調整表格大小；新增、刪除與調整列與欄的大小；以及讀取與修改儲存格內容、邊框、填色與文字格式。|
|ActiveX 控制項|Aspose.Slides for Python via Java 支援 ActiveX 控制項。|
|VBA 巨集|您可以在簡報中管理 VBA 巨集。|
|文字框|您可以透過圖形關聯的文字框存取其文字，並調整文字框的邊距與文字換行方式。|
|字型|您可以管理簡報中使用的字型。|
|文字掃描|內建方法允許您掃描整個簡報或單一投影片的文字。|
|動畫|您可以為圖形加入與修改動畫效果。|
|投影片放映|Aspose.Slides for Python via Java 支援投影片放映與投影片過場效果，包括 Morph 過場。|

## **格式化功能**

Aspose.Slides for Python via Java 讓您對簡報投影片上的文字與圖形進行格式化，如下所述：

|**功能**|**說明**|
| :- | :- |
|文字格式化|<p>您可以透過與圖形關聯的文字框管理文字，並格式化各段落與文字片段。提供以下格式化選項：</p><p>- 字型類型</p><p>- 字型大小</p><p>- 字型顏色</p><p>- 字型陰影</p><p>- 段落對齊</p><p>- 段落縮排與 Tab 鍵</p><p>- 段落項目符號</p><p>- 段落方向</p>|
|圖形格式化|<p>圖形是投影片的基本元素。您可以調整以下圖形屬性：</p><p>- 位置</p><p>- 大小</p><p>- 旋轉</p><p>- 線條樣式</p><p>- 填充（包括純色、漸層、圖案、紋理與圖片填充）</p><p>- 文字</p><p>- 圖像</p>|
