## **受支援的平台**
Aspose.Slides for Python via Java 是一個跨平台的 API。它可以在任何安裝了 Python 3.7 或更高版本的平臺（Windows、Linux、MacOS 等）上使用。JDK 8 或更高版本是另一項要求。

## **檔案格式與轉換**
Aspose.Slides for Python via Java 支援大多數 PowerPoint 文件格式。它亦允許您將它們匯出為組織常用且彼此共享的流行檔案格式。請參閱以下詳細資訊：

|**功能**|**說明**|
| :- | :- |
|Microsoft PowerPoint（PPT）|Aspose.Slides for Python via Java 為此簡報文件格式提供最快的處理速度。|
|PPT 轉換為 PPTX|Aspose.Slides for Python via Java 支援 PPT 轉換為 PPTX。|
|Portable Document Format（PDF）|您可以使用單一方法將所有受支援的檔案格式匯出為 Adobe Portable Document Format（PDF）文件。|
|XML Parser Specification（XPS）|您可以使用單一方法將所有受支援的檔案格式匯出為 XML Parser Specification（XPS）文件。|
|Tagged Image File Format（TIFF）|您可以將所有受支援的簡報檔案格式匯出為 Tagged Image File Format（TIFF）。|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java 支援將 PresentationEx 轉換為 HTML 格式。|

## **簡報渲染**
Aspose.Slides for Python via Java 支援將簡報中的投影片高保真度渲染為不同的圖形格式。請參閱以下詳細資訊：

|**功能**|**說明**|
| :- | :- |
|支援的 Java 圖像格式|使用 Aspose.Slides for Python via Java，您可以將簡報投影片及投影片上的圖像渲染為所有 Java 支援的圖形格式，例如 TIFF、PNG、BMP、JPEG、GIF。|
|SVG Format|Aspose.Slides for Python via Java 亦提供內建方法，可將簡報投影片匯出為可縮放向量圖形（SVG）格式。|

## **內容功能**
Aspose.Slides for Python via Java 允許您存取、修改或建立幾乎所有簡報文件的項目或內容。請參閱以下詳細資訊：

|**功能**|**說明**|
| :- | :- |
|母片投影片|母片投影片定義一般投影片的版面配置。Aspose.Slides for Python via Java 允許您存取與修改簡報文件的母片投影片。|
|一般投影片|使用 Aspose.Slides for Python via Java，您可以建立不同類型的新投影片；亦可存取與修改簡報中現有的投影片。|
|克隆 / 複製 投影片|Aspose.Slides for Python via Java 提供內建方法，允許您在同一簡報中克隆或複製現有投影片。您亦可將複製或克隆的投影片從一個簡報使用到另一個簡報。由於投影片會從母片繼承版面配置，內建的克隆方法會自動在克隆時複製母片。|
|管理投影片區段|用於在簡報內將投影片組織於不同區段的方法。|
|保留區與文字保留區|您可以存取投影片中的保留區與文字保留區。此外，您亦可使用相應方法從頭建立含有文字保留區的投影片。|
|頁首與頁尾|Aspose.Slides for Python via Java 方便處理投影片中的頁首/頁尾。|
|投影片備註|使用 Aspose.Slides for Python via Java，您可以存取與修改投影片相關的備註，亦可新增備註。|
|尋找形狀|您亦可透過形狀的替代文字在投影片中尋找特定形狀。|
|背景|Aspose.Slides for Python via Java 允許您處理簡報中母片或一般投影片的背景。|
|文字方塊|文字方塊可從頭建立。您可以存取現有的文字方塊，也能在不失去原始文字格式的情況下修改其文字。|
|矩形形狀|您可以使用 Aspose.Slides for Python via Java 建立或修改矩形形狀。|
|折線形狀|您可以使用 Aspose.Slides for Python via Java 建立或修改折線形狀。|
|橢圓形狀|您可以使用 Aspose.Slides for Python via Java 建立或修改橢圓形狀。|
|群組形狀|Aspose.Slides for Python via Java 支援群組形狀|
|自動形狀|Aspose.Slides for Python via Java 支援自動形狀|
|SmartArt|Aspose.Slides for Python via Java 提供對 MS PowerPoint 中 SmartArt 形狀的支援|
|圖表|Aspose.Slides for Python via Java 提供對 PowerPoint 中 MSO 圖表的支援|
|形狀序列化|當 Aspose.Slides for Python via Java 尚未支援某個形狀時，您可以使用序列化方法，將該形狀從現有投影片序列化。如此您即可依需求進一步使用該形狀。|
|圖片框|您可以使用 Aspose.Slides for Python via Java 管理圖片框中的圖片。|
|音訊框|您可以在投影片的音訊框中鏈結或嵌入音訊檔案，使用 Aspose.Slides for Python via Java。|
|影片框|您可以在影片框中處理影片檔案。Aspose.Slides for Python via Java 亦支援鏈結與嵌入式影片。|
|OLE 框|您可以使用 Aspose.Slides for Python via Java 管理 OLE 框中的 OLE 物件。|
|表格|Aspose.Slides for Python via Java 支援投影片中的表格。|
|ActiveX 控制項|支援 ActiveX 控制項|
|VBA 巨集|支援在簡報內管理 VBA 巨集。|
|文字框|您可以透過與形狀相關聯的文字框存取該形狀的文字。|
|文字掃描|您可以使用內建掃描方法，在簡報或投影片層級掃描文字。|
|動畫|您可以對形狀套用動畫。|
|投影片放映|Aspose.Slides for Python via Java 支援投影片放映與投影片過渡效果|

## **格式化功能**
使用 Aspose.Slides for Python via Java，您可以格式化簡報投影片上的文字與形狀。請參閱以下詳細資訊：

|**功能**|**說明**|
| :- | :- |
|文字格式化|<p>在 Aspose.Slides for Python via Java 中，您可以透過與形狀相關聯的文字框來管理文字。因此，您可以使用文字框內的段落和文字片段來格式化文字。這些文字元素可透過 Aspose.Slides for Python via Java 進行格式化。</p><p>- 字型</p><p>- 字型大小</p><p>- 字型顏色</p><p>- 字型色階</p><p>- 段落對齊</p><p>- 段落項目符號</p><p>- 段落方向</p>|
|形狀格式化|<p>在 Aspose.Slides for Python via Java 中，投影片的基本元素是形狀。您可以使用 Aspose.Slides for Python via Java 格式化這些形狀元素：</p><p>- 位置</p><p>- 大小</p><p>- 線條</p><p>- 填充（包含圖案、漸層、純色）</p><p>- 文字</p><p>- 圖片</p>|
