**歡迎使用 Aspose.Slides for Python via Java**

![Aspose.Slides for Python via Java 產品標誌](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java 是一個類別庫，使您的 Python 應用程式能夠讀寫 PowerPoint® 簡報，且無需安裝 Microsoft PowerPoint®。

其主要功能包括管理文字、形狀、表格與動畫；向投影片加入音訊與視訊；預覽投影片；以及將投影片匯出為 SVG、PDF 及其他格式。
