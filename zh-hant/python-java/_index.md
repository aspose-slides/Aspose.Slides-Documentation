**歡迎使用 Aspose.Slides for Python via Java**

![Aspose.Slides for Python via Java 產品標誌](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java 是一個類別庫，使您的應用程式能在不使用 Microsoft PowerPoint® 的情況下讀寫 PowerPoint® 文件。

Aspose.Slides for Python via Java 是首個且唯一提供管理 PowerPoint® 文件功能的元件。

Aspose.Slides for Python via Java 提供許多關鍵功能，包括管理文字、形狀、表格與動畫、向投影片加入音訊與影片、投影片預覽、將投影片匯出為 SVG、PDF 格式等。
