{{% alert color="info" title="Note" %}}

Aspose.Slides for Python via Java 是一個類別庫，使 Python 應用程式能夠讀寫簡報，而無需 Microsoft PowerPoint®。它允許您管理文字、形狀、表格和動畫；向投影片加入音訊和影片；預覽投影片；以及將投影片匯出為 SVG、PDF 及其他格式。

欲了解更多，請參閱 [Aspose.Slides for Python via Java API Reference](https://reference.aspose.com/slides/zh-hant/python-java/)。
