Aspose.Slides for SharePoint 是一種適用於 SharePoint 2007 到 2019 的農場解決方案，可在伺服器上的文件庫中轉換 PowerPoint 簡報，無需 Microsoft PowerPoint，也無需編寫程式碼。

它可將 PPT 和 PPTX 檔案轉換為 PDF、TIFF、XPS、HTML、SWF 與 ODP，亦可轉換為 PPS、PPSX、PPTM、PPSM、POTX 與 POTM 等 PowerPoint 格式，並將結果儲存於文件庫中。

## **您的首次匯出**

Aspose.Slides for SharePoint 只需在農場上安裝一次，之後即可在任何已啟用的文件庫中使用：

1. 從[下載頁面](https://releases.aspose.com/slides/sharepoint/)下載 ZIP 壓縮檔，並在 SharePoint 農場的伺服器上解壓縮。
2. 執行與您的 SharePoint 版本相符的安裝程式：*Setup2007.exe*、*Setup2010.exe*、*Setup2013.exe*、*Setup2016.exe* 或 *Setup2019.exe*。使用具備安裝與部署 SharePoint 解決方案權限的帳號。接受授權協議，選取要啟用功能的站台集合，讓安裝程式部署解決方案。每個畫面皆在[安裝](/slides/zh-hant/sharepoint/installing-aspose-slides-for-sharepoint/)中說明。
3. 在其中一個站台集合的文件庫中，開啟 PPT 或 PPTX 檔案的功能表，選取**Convert via Aspose.Slides**。在 SharePoint 2007 上，功能表項目稱為**Convert with Aspose.Slides**。
4. 在**Convert to**下，選取**PDF - Adobe Portable Document**。如有需要可更改目標檔案名稱和資料夾，然後點擊**Convert**。
5. 轉換完成後，點擊**Destination Library**以開啟包含新 PDF 檔案的資料夾。

若未取得授權，轉換後的檔案會帶有評估浮水印 — 請參閱[授權許可](/slides/zh-hant/sharepoint/installing-aspose-slides-for-sharepoint-license/)。若需搭配螢幕擷取圖的相同步驟，請參閱[將 Microsoft PowerPoint 文件轉換為其他格式](/slides/zh-hant/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/)。
