要在文件庫中轉換簡報：

1. 開啟 PPT 或 PPTX 檔案的功能表（其編輯控制方塊），並選取 **Convert via Aspose.Slides**。在 SharePoint 2007 上，功能表項目名稱為 **Convert with Aspose.Slides**。

   **在 SharePoint 2007 文件的功能表中選取 Convert with Aspose.Slides**

   ![SharePoint 2007 文件庫中檔案的功能表，包含 Convert with Aspose.Slides 項目](convert-one-file_1.png)

2. 在轉換頁面上，於 **Convert to** 下選取輸出格式。如有需要，可變更目標檔案名稱和目標資料夾。
3. 按一下 **Convert**。
4. 轉換完成後，按一下 **Source Library** 或 **Destination Library** 以返回文件庫。已轉換的檔案位於目標資料夾。

相同的步驟與每個頁面的螢幕截圖可參見[Converting Microsoft PowerPoint Documents into Other Formats](/slides/zh-hant/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/)。
