SharePoint 站點旨在協作、溝通與內容儲存，以滿足特定業務需求。它們讓一群人透過資訊共享與溝通，達成共同目標。這些資訊通常以網站形式呈現，並可透過網頁瀏覽器存取。

{{% /alert %}}

## **什麼是 SharePoint 與 Aspose.Slides？**

Aspose.Slides for SharePoint 是將 Microsoft PowerPoint 簡報（PPT 及 PPTX）轉換為其他格式的解決方案：PDF、TIFF、XPS、HTML、SWF、ODP、PPS、PPSX、PPTM、PPSM、POTX 與 POTM。它允許您在 SharePoint 站點中轉換 PowerPoint 檔案，而無需使用 Microsoft PowerPoint。完整格式清單請參考 [Supported File Formats](/slides/zh-hant/sharepoint/supported-file-formats/)。
