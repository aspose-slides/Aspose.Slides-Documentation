當 Aspose.Slides for SharePoint 安裝在 SharePoint 伺服器上並在網站集合中啟用後，它會在其文件庫的文件選單中新增 **Convert via Aspose.Slides** 項目，如下圖所示。在 SharePoint 2007 中，此項目名稱為 **Convert with Aspose.Slides**。

**安裝 Aspose.Slides for SharePoint 會在文件選單中加入 Convert via Aspose.Slides 項目**

![文件選單中包含 Convert via Aspose.Slides 項目](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **轉換簡報**

要從 SharePoint 文件庫轉換 Microsoft PowerPoint 簡報（PPT 或 PPTX）：

1. 在文件庫中選取 Microsoft PowerPoint 簡報。
2. 開啟其選單並點選 **Convert via Aspose.Slides**。

   **Presentation 2 檔案的選單，顯示 Convert via Aspose.Slides 項目**

   ![文件庫中簡報的選單，已突顯 Convert via Aspose.Slides 項目](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. 在 **Convert to** 下選取輸出格式。如有需要，可變更輸出檔名及目標資料夾。
4. 點選 **Convert** 以轉換檔案。

   **轉換頁面允許您選取輸出格式、檔名與目標位置**

   ![包含輸出格式、目標檔案與目標資料夾的轉換頁面](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. 轉換完成後，會顯示成功訊息。

   **轉換成功**

   ![轉換結果頁面](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. 點選 **Source Library**（前往來源資料夾）或 **Destination Library**（前往檔案已儲存的資料夾）。

   已轉換的文件會出現在文件庫中。

   **已轉換的文件顯示於儲存的文件庫中**

   ![文件庫中的已轉換檔案](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

這些螢幕截圖取自較早的版本，該版本僅提供 PDF、TIFF 與 XPS 格式。目前的轉換頁面提供更多輸出格式；請參閱 [Multiple Format Support](/slides/zh-hant/sharepoint/multiple-format-support/)。

{{% /alert %}}

在 SharePoint 2010 及之後的版本，您也可以在文件庫中選取一個或多個簡報，然後在 **Aspose Tools** 功能帶索引標籤上點選 **Convert Slides**。它會開啟相同的轉換頁面。
