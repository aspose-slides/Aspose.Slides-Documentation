## **支援的 Microsoft PowerPoint 版本**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac

## **支援的檔案格式**

Aspose.Slides for SharePoint converts PPT and PPTX presentations stored in a SharePoint document library. Files of other types are not converted.

|**格式**|**描述**|**從**|**至**|
| :- | :- | :- | :- |
|[PPT](https://docs.fileformat.com/presentation/ppt/)|PowerPoint 簡報 97 - 2003|{{< emoticons/tick >}}| |
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|PowerPoint 簡報 2007 及以上|{{< emoticons/tick >}}| |
|[PDF](https://docs.fileformat.com/pdf/)|可攜式文件格式，含投影片或備註檢視| |{{< emoticons/tick >}}|
|[TIFF](https://docs.fileformat.com/image/tiff/)|TIFF 圖像，含投影片或備註檢視| |{{< emoticons/tick >}}|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|XML 紙張規格| |{{< emoticons/tick >}}|
|[HTML](https://docs.fileformat.com/web/html/)|HTML 格式的簡報| |{{< emoticons/tick >}}|
|[SWF](https://docs.fileformat.com/page-description-language/swf/)|Shockwave Flash 影片，含投影片或備註檢視| |{{< emoticons/tick >}}|
|[ODP](https://docs.fileformat.com/presentation/odp/)|OpenDocument 簡報| |{{< emoticons/tick >}}|
|[PPS](https://docs.fileformat.com/presentation/pps/)|PowerPoint 投影片秀 97 - 2003| |{{< emoticons/tick >}}|
|[PPSX](https://docs.fileformat.com/presentation/ppsx/)|PowerPoint 投影片秀 2007 及以上| |{{< emoticons/tick >}}|
|[PPTM](https://docs.fileformat.com/presentation/pptm/)|PowerPoint 含巨集的簡報| |{{< emoticons/tick >}}|
|[PPSM](https://docs.fileformat.com/presentation/ppsm/)|PowerPoint 含巨集的投影片秀| |{{< emoticons/tick >}}|
|[POTX](https://docs.fileformat.com/presentation/potx/)|PowerPoint 範本| |{{< emoticons/tick >}}|
|[POTM](https://docs.fileformat.com/presentation/potm/)|PowerPoint 含巨集的範本| |{{< emoticons/tick >}}|

在轉換頁面的 **Convert to** 下選擇輸出格式；請參閱 [Multiple Format Support](/slides/zh-hant/sharepoint/multiple-format-support/) 以取得完整的選項清單。
