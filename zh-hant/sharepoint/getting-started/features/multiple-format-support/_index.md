{{% alert color="info" title="Note" %}}

使用 Aspose.Slides for SharePoint，您可以在 SharePoint 文件庫中將 PowerPoint 簡報轉換為多種流行的文件格式。

{{% /alert %}}

## **支援的輸入格式**

Aspose.Slides for SharePoint 可轉換以下輸入格式：

- PPT – Microsoft PowerPoint 簡報 97 - 2003
- PPTX – Office Open XML 簡報

{{% alert color="info" title="Note" %}}

要轉換文件，Aspose.Slides for SharePoint 依賴內建的 [Aspose.Slides for .NET](https://products.aspose.com/slides/net/)。

{{% /alert %}}

## **支援的輸出格式**

轉換頁面上的 **Convert to** 列表依序提供以下輸出格式：

- PDF – Adobe 可攜式文件
- TIFF – 圖片套件
- XPS – XML 紙張規格
- PPS – 投影片展示簡報
- PPSX – Microsoft PowerPoint Open XML 投影片秀
- ODP – OpenDocument 簡報
- PPTM – Microsoft PowerPoint Open XML 含巨集簡報
- PPSM – Microsoft PowerPoint Open XML 含巨集投影片秀
- POTX – Microsoft PowerPoint 範本
- POTM – PowerPoint Open XML 含巨集簡報範本
- PDFNotes – 以 PDF 格式呈現簡報備註
- HTML – 以 HTML 格式呈現簡報
- TIFFNotes – 以多頁 TIFF 圖像呈現簡報備註
- SWF – Shockwave Flash 影片
- SWFNotes – 以多頁 SWF 呈現簡報備註
