## **產品概觀**

Aspose.Slides for SharePoint 會在伺服器上將儲存在 SharePoint 文件庫中的 PowerPoint 簡報轉換為其他格式。

它能轉換以下 PowerPoint 格式：

- PPT – Microsoft PowerPoint 簡報 97 - 2003
- PPTX – Office Open XML 簡報

它會將它們轉換為 PDF、TIFF、XPS、HTML、SWF、ODP、PPS、PPSX、PPTM、PPSM、POTX 與 POTM。詳情請參閱[Supported File Formats](/slides/zh-hant/sharepoint/supported-file-formats/)。

下載包含針對以下每個產品的獨立安裝程式和解決方案套件：

- SharePoint 2007
- SharePoint 2010
- SharePoint Server 2013
- SharePoint Server 2016
- SharePoint Server 2019
