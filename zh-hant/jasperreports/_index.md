**歡迎使用 Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports 是專為需要在 Java 應用程式中輕鬆將 JasperReports 報告匯出為 Microsoft PowerPoint 簡報 (PPT) 與 Microsoft PowerPoint 幻燈片放映 (PPS) 格式而設計的函式庫。所有報告功能都會以最高精確度轉換為 Microsoft PowerPoint 簡報。Aspose.Slides for JasperReports 包含對 JasperReports 5 以上版本的支援。
