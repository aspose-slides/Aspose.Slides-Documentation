## **JasperReports**

Aspose.Slides for JasperReports 支援 JasperReports 3.7.2 到 6.16.0。下載中針對三個版本範圍各提供一個 jar，請參閱 [Installing Aspose.Slides for JasperReports](/slides/zh-hant/jasperreports/installing-aspose-slides-for-jasperreports/) 以了解該使用哪一個。對於 JasperReports 6.17.0 之後的版本（包括 JasperReports 7）則沒有相應的 jar。  
對 JasperReports 2.0.3 到 3.7.1 的支援已於 Aspose.Slides for JasperReports 17.6 結束。版本 17.5 及更早版本同樣支援這些版本。

## **Java**

這些 jar 是以 Java 6 或更高版本編譯的，正如其資料夾名稱中的 *JDK 1.6* 所示，因此您需要的 Java 版本與您的 JasperReports 版本所需的相同。使用 JasperReports 6.16.0 時，匯出可在 Java 11、17、21 與 25 上執行。

## **作業系統**

這些 jar 只包含 Java 類別與資源，沒有原生程式庫，也不使用 Microsoft PowerPoint。於 Linux 上，JasperReports 需要 fontconfig 並至少安裝一種字型才能產生報表。

## **JasperReports Server**

對於 JasperReports Server，請從與伺服器所執行的 JasperReports 版本相符的資料夾中使用兩個 jar ──請參閱 [Integration with JasperServer](/slides/zh-hant/jasperreports/integration-with-jasperserver/)。
