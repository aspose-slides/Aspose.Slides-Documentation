{{% alert color="info" %}} 

JasperReports 和 JasperServer 本身不具備將報表匯出為 Microsoft PowerPoint 簡報的功能，但使用 Aspose.Slides for JasperReports，您即可使用額外的匯出格式：

- Microsoft PowerPoint 簡報 (PPT)
- Microsoft PowerPoint 簡報 (PPTX)
- HTML
- PDF

{{% /alert %}} 

若要以這些格式建立文件，Aspose.Slides for JasperReports 依賴內建的 [Aspose.Slides for Java](https://products.aspose.com/slides/zh-hant/java/)，該套件是 Aspose 市場領先的簡報處理函式庫。Microsoft PowerPoint 並未用於產生這些文件。
