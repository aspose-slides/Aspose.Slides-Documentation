## **支援的平台**
Aspose.Slides for Java 支援最受歡迎的開發與部署平台。

|**功能**|**說明**|
| :- | :- |
|Desktop Applications|可使用 Aspose.Slides for Java 開發 Windows Forms 應用程式|
|Enterprise Web Applications|使用 Aspose.Slides for Java 可協助建立目標為 Web 的應用程式，同時也提供對於使用 Aspose.Slides for Java 搭配 PHP 的支援。|
|Linux/Unix|Aspose.Slides for Java 是跨平台的 API，能在 Linux 與 Unix 環境中運作。|

## **檔案格式與轉換**
Aspose.Slides for Java 支援大多數 Microsoft PowerPoint 文件格式，並可匯出為組織廣泛使用的流行格式。

|**功能**|**說明**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/zh-hant/java/microsoft-powerpoint-ppt/)|Aspose.Slides for Java 為此簡報文件格式提供最快的處理速度。|
|[PresentationML (PPTX, XML)](/slides/zh-hant/java/presentationml-pptx-xml/)|Aspose.Slides for Java 支援處理 OOXML 簡報格式（亦稱為 PresentationML 或 PPTX）。|
|[PPT to PPTX conversion](/slides/zh-hant/java/ppt-to-pptx-conversion/)|Aspose.Slides for Java 支援將 PPT 轉換為 PPTX。|
|[Portable Document Format (PDF)](/slides/zh-hant/java/developer-guide/)|支援的檔案格式可使用單一方法匯出為 Adobe 可攜式文件格式 (PDF) 文件。|
|[XML Parser Specification (XPS)](/slides/zh-hant/java/xml-parser-specification-xps/)|所有支援的檔案格式可使用單一方法匯出為 XML 解析規格 (XPS) 文件。|
|[Tagged Image File Format (TIFF)](https://docs.aspose.com/slides/zh-hant/java/convert-powerpoint-to-tiff/)|Aspose.Slides for Java 支援的簡報檔案格式亦可匯出為標記式影像檔案格式 (TIFF)。|
|[ODP to PPTX Conversion](https://docs.aspose.com/slides/zh-hant/java/convert-odp-to-pptx/)|Aspose.Slides for Java 支援載入 OpenDocument 簡報 (ODP) 並將其轉換為 PPTX。|
|[Presentation To HTML Conversion](https://docs.aspose.com/slides/zh-hant/java/convert-powerpoint-to-html/)|Aspose.Slides for Java 支援將簡報轉換為 HTML 格式。|

## **簡報渲染**
Aspose.Slides for Java 支援高保真度地將簡報中的投影片渲染為各種圖形格式：

|**功能**|**說明**|
| :- | :- |
|Supported Image Formats|使用 Aspose.Slides for Java，您不僅能將簡報投影片渲染，亦能渲染投影片中的圖像，並匯出為常見的圖形格式，如 TIFF、PNG、BMP、JPEG、GIF 以及圖形檔案。|
|SVG Format|Aspose.Slides for Java 提供內建方法將簡報投影片匯出為可縮放向量圖形 (SVG) 格式。|

|Place Holders and Text Holders|存取投影片中的版位持有者與文字持有者。此外，您也可使用相應方法從頭建立含文字持有者的投影片。|

|Text Boxes|文字方塊可從頭建立。可存取現有文字方塊並修改其文字，且不會遺失原始格式。|
|Rectangle Shapes|Aspose.Slides for Java 可建立或修改矩形形狀。|

|SmartArt|支援 Microsoft PowerPoint 中的 SmartArt 形狀。|

|Audio Frames|音訊檔案可透過 Aspose.Slides for Java 以音訊框的形式連結或嵌入投影片。|

使用 Aspose.Slides for Java，可對簡報文件中的文字與形狀進行格式化。

|**功能**|**說明**|
| :- | :- |
|Text Formatting|<p>在 Aspose.Slides for Java 中，文字透過與形狀關聯的文字框來管理。因此，文字的格式化透過文字框中的段落與段落片段完成。以下文字元素可進行格式化。</p><p>- 字型類型。</p><p>- 字型大小。</p><p>- 字型顏色。</p><p>- 字型色階。</p><p>- 段落對齊。</p><p>- 段落項目符號。</p><p>- 段落方向。</p>|

## **常見問題**

### 是否需要在伺服器/電腦上安裝 Microsoft PowerPoint 才能使用此函式庫？

不需要。PowerPoint 不是必要條件；Aspose.Slides 是一個獨立的引擎，用於建立、編輯、轉換與渲染簡報。

### 多執行緒如何運作？處理程序可以平行化嗎？

在不同執行緒中處理不同文件是安全的；相同的[簡報](https://reference.aspose.com/slides/zh-hant/java/com.aspose.slides/presentation/)物件不能同時被[多個執行緒](/slides/zh-hant/java/multithreading/)使用。

### 是否支援檔案密碼與加密？

是的。[您可以](/slides/zh-hant/java/password-protected-presentation/) 開啟受加密的簡報、設定或移除開啟與寫入密碼，並檢查保護狀態。

### 是否需要在 Linux 容器中關注字型套件？

是的。建議在您的應用程式中安裝常見字型套件和/或明確[指定字型目錄](/slides/zh-hant/java/custom-font/)，以避免意外的字型替換。

### 評估版是否有任何限制？

在[評估模式](/slides/zh-hant/java/licensing/)下，輸出會加入浮水印並套用某些限制；可取得[30 天暫時授權](https://purchase.aspose.com/temporary-license/)以完整測試全部功能。

### 是否支援將外部格式匯入簡報（PDF/HTML → PPTX）？

是的。您可以將[PDF 頁面與 HTML 內容](/slides/zh-hant/java/import-presentation/)加入簡報，將其轉換為投影片。
