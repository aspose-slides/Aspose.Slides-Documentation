## **概觀**

Aspose.Slides for Java 是一個類別庫，用於建立、讀取、編輯、轉換和算繪 PowerPoint 與 OpenDocument 簡報。它沒有自己的使用者介面，也不需要 Microsoft PowerPoint 或 Microsoft Office。本文概述了此庫的功能，並提供描述各領域的文章連結。

## **支援平台**

Aspose.Slides for Java 是單一 JAR 檔，於 Aspose 的 Maven 套件庫中以 `jdk16` 分類器發布。它純粹以 Java 撰寫：JAR 不含本機程式庫，也不依賴其他套件。

- **Java:** Java 8 或更高版。Aspose.Slides for Java 26.9 以及更早版本亦可在 Java 6 與 7 上執行，26.10 版已不再支援；請參閱[26.9 版本說明](https://releases.aspose.com/slides/zh-hant/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/)。
- **作業系統:** 任一具 Java 執行環境的作業系統，例如 Windows、Linux 與 macOS。於 Linux 必須安裝 fontconfig 程式庫以及至少一種字型。

[安裝](/slides/zh-hant/java/installation/)說明如何將函式庫加入專案並列出 Linux 前置需求。[系統需求](/slides/zh-hant/java/system-requirements/)詳細列出支援的平台。

## **檔案格式與轉換**

Aspose.Slides 可開啟與儲存 PPT、PPTX、PPS、POT、PPSX、POTX、PPTM、PPSM、POTM、ODP、OTP、FODP 與 PowerPoint XML 簡報。它可將 PDF 與 HTML 內容匯入投影片，並可將簡報儲存為 PDF、XPS、HTML、HTML5、TIFF、動畫 GIF、SWF、Markdown 與 XAML。[支援檔案格式](/slides/zh-hant/java/supported-file-formats/)列出每種格式以及對應的讀寫 API。

|**功能**|**說明**|
| :- | :- |
|[PPT 與 PPTX](/slides/zh-hant/java/ppt-vs-pptx/)|讀寫二進位 PowerPoint 97-2003 格式與 Office Open XML 格式。|
|[PPT 轉換為 PPTX](/slides/zh-hant/java/convert-ppt-to-pptx/)|將舊版 PPT 簡報轉換為 PPTX。|
|[ODP 轉換為 PPTX](/slides/zh-hant/java/convert-odp-to-pptx/)|開啟與儲存 ODP、OTP 與 FODP 簡報，並將 ODP 簡報轉換為 PPTX。|
|[可攜式文件格式 (PDF)](/slides/zh-hant/java/convert-powerpoint-to-pdf/)|將簡報匯出為 PDF，包括 PDF/A 與 PDF/UA 文件。|
|[XML 紙張規格 (XPS)](/slides/zh-hant/java/convert-powerpoint-to-xps/)|將簡報匯出為 XPS 文件。|

## **簡報算繪**

Aspose.Slides 可將投影片與單一圖形算繪為 PNG、JPEG、BMP、GIF、TIFF 與 SVG 影像，亦可將投影片算繪為 EMF 中繼檔。請參閱[將簡報投影片轉換為影像](/slides/zh-hant/java/convert-slide/)、[將簡報投影片算繪為 SVG 影像](/slides/zh-hant/java/render-a-slide-as-an-svg-image/)以及[建立簡報圖形的縮圖](/slides/zh-hant/java/create-shape-thumbnails/)。

## **常見問題**

**我需要在伺服器或電腦上安裝 Microsoft PowerPoint 才能使用此函式庫嗎？**

不需要。PowerPoint 並非必須；Aspose.Slides 為獨立的引擎，可用於建立、編輯、轉換與算繪簡報。

**多執行緒如何運作？處理程序可以平行化嗎？**

可以在不同執行緒中安全地處理不同文件；同一個[Presentation](https://reference.aspose.com/slides/zh-hant/java/com.aspose.slides/presentation/)物件不得同時被[多個執行緒](/slides/zh-hant/java/multithreading/)使用。

**是否支援檔案密碼與加密？**

是的。您可以[開啟受密碼保護的簡報](/slides/zh-hant/java/password-protected-presentation/)、設定或移除開啟與寫入密碼，並檢查保護狀態。

**在 Linux 容器中需要特別注意字型嗎？**

是的。Linux 必須安裝 fontconfig 程式庫與至少一種字型，且簡報中使用的字型或適當的替代字型必須安裝，才能正確算繪文字。您也可以在應用程式中[指定字型目錄](/slides/zh-hant/java/custom-font/)。請參閱[安裝](/slides/zh-hant/java/installation/#linux)。

**評估版有什麼限制？**

有。若未取得[授權](/slides/zh-hant/java/licensing/)，Aspose.Slides 會在每張儲存的投影片上加上評估水印，並截斷 API 讀取的文字內容。可使用[30 天臨時授權](https://purchase.aspose.com/temporary-license/)進行完整功能測試。

**是否支援將外部格式匯入簡報（例如 PDF 或 HTML 轉為 PPTX）？**

支援。您可以將[PDF 頁面與 HTML 內容](/slides/zh-hant/java/import-presentation/)加入簡報，將它們轉換為投影片。
