## **Aspose.Slides 評估版**

您可以輕鬆下載 Aspose.Slides 進行評估。評估下載與正式購買下載相同。只要在程式碼中加入幾行授權設定，即可將評估版變為正式授權版。

未指定授權的 Aspose.Slides 評估版提供完整的產品功能，但在開啟與儲存文件時會在文件頂部插入評估水印，且在從簡報投影片中擷取文字時僅限一張投影片。

## **常見問題**

### 我可以在評估模式下，同時在不同執行緒中測試多個簡報嗎？

可以。您可以平行處理不同的文件；不應在執行緒間共用同一個簡報物件[跨執行緒](/slides/zh-hant/java/multithreading/)。評估模式不會影響此行為。

### 在伺服器或 CI 環境中評估此函式庫，是否需要安裝 Microsoft PowerPoint？

不需要。Aspose.Slides 是獨立的引擎，無論是評估或正式使用，都不需安裝 PowerPoint。

### 我能在評估模式下完整測試 PPT/PPTX 轉 PDF 及影像的功能嗎？

可以。[轉換器](/slides/zh-hant/java/convert-presentation/) 可以正常運作；輸出結果會包含水印。

### 我可以使用臨時授權進行負載測試而不出現水印嗎？

可以。30 天的臨時授權會移除評估模式的限制，允許在沒有水印的情況下進行測試。
