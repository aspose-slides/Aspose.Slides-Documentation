## **概覽**

本文說明如何取得 Aspose.Slides 的支援以及如何有效回報問題。它描述了主要的支援渠道，提供提交問題的建議，並指向有用的技術資源，如產品頁面、部落格、下載、支援論壇、文件與 API 參考。本文亦回答了關於付費支援、問題升級以及舊版函式庫支援的常見問題。

## **技術支援**

{{% alert color="info" %}} 
Aspose 為其所有產品提供無限制的免費技術支援。此支援對所有使用者皆可使用，包括評估版。
{{% /alert %}} 

如果您需要 Aspose.Slides for Java 的協助，請考慮以下事項：

- 主要的支援管道是 Aspose.Forums。請在 Aspose.Slides 論壇發表您的問題，通常會在數小時內得到回覆。問題由 Aspose.Slides 支援團隊直接回答。
- 請注意，Aspose 並未提供電話技術支援。電話支援僅適用於銷售與購買相關問題。
- 在論壇等待回覆時，請考慮時區差異。

如果您在使用 Aspose.Slides for Java 時遇到問題，請遵循以下簡單步驟，以確保問題能以最高效率得到解決：

- 在回報問題之前，請確保使用最新的 Aspose.Slides for Java 版本，請參閱 Aspose.Slides 下載頁面以取得最新版本資訊。
- 在回報問題前，請先瀏覽論壇、本文檔與 API 參考；您的問題可能已經得到回答。
- 回報問題時，請附上原始文件以及可能導致問題的程式碼片段。如需附加多個檔案，請將它們壓縮成一個 zip。將文件上傳至 Aspose.Forums 是安全的，因為只有您與 Aspose 開發人員可以存取這些附加檔案。
- 請盡量於每個討論串只回報一個問題。若有其他問題，請另開新討論串回報。

## **常見問題**

### 有哪些付費支援層級，且它們有何差異？

[Developer, Business, and Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。它們在包含的事件數量、回應優先級以及可用的通訊渠道上有所不同。

### 我可以直接將錯誤升級給工程團隊嗎？

可以。[Paid support](https://helpdesk.aspose.com/) 允許在問題需要更深入調查時升級給開發人員。

### 舊版函式庫是否受到支援，且會釋出修復嗎？

您可以使用較舊的版本，但僅提供當前發行版的修正；不會為舊版發佈補丁。
