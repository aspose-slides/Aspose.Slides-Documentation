{{% alert color="info" %}} 
支援從 Aspose.Slides for Java 進行 PPT 轉換為 PPTX。大多數簡報功能——母片、結構等——在不同格式之間轉換時會被保留，但仍有[一些限制](/slides/zh-hant/java/ppt-to-pptx-conversion/)。

{{% /alert %}} 
## **轉換中支援的功能**
Aspose.Slides for Java 為 PPT 檔案格式轉換為 PPTX 提供部分支援。此轉換功能剛在 Aspose.Slides for Java 中加入，因此有些限制，最適合用於簡單的簡報。Aspose.Slides for Java 在 PPT 轉換為 PPTX 時的主要優勢在於 API 使用非常簡便。若要查看程式碼範例，請閱讀[將 PPT 轉換為 PPTX]()。以下清單說明了在 PPT 轉換為 PPTX 時哪些功能受支援，哪些不受支援。

## **受支援的功能**
以下功能在轉換時受支援：

- 轉換母片、版面配置與投影片的結構
- 轉換圖表
- 群組圖形
- 轉換包含矩形與橢圓的自動圖形
- 具有自訂幾何形狀的圖形
- 自動圖形的紋理與圖片填充樣式
- 轉換占位符
- 轉換直線與折線
- 線條與填充格式
- 漸層填充樣式
- OLE 框架、表格、影片與音訊框架等
- 動畫與投影片屬性
- 轉換文字框與文字佔位符中的文字
