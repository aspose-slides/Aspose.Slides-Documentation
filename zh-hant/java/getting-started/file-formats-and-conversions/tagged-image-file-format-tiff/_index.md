## **關於 TIFF**

[Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) 以能在同一文件中儲存多張影像聞名，最初由 Aldus 開發。此格式廣受掃描、傳真及其他影像處理應用程式的支援。

## **Aspose.Slides for Java 中的 TIFF**

任何可在 Aspose.Slides for Java 載入的文件，都能直接由 Aspose.Slides for Java 轉換為 TIFF 文件，無需任何第三方元件。此外，您還可以選擇性地定義輸出 TIFF 文件中影像的尺寸。有關透過 Aspose.Slides for Java 將簡報文件匯出為 TIFF 文件的資訊，請參閱 [Convert PowerPoint Presentations to TIFF](/slides/zh-hant/java/convert-powerpoint-to-tiff/)。
