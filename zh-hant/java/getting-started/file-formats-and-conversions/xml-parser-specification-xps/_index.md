這是一個歷史頁面，保留供現有連結使用。它未描述 Aspose.Slides for Java 的目前版本。若要了解 Aspose.Slides for Java 載入、匯入、儲存與呈現的格式，以及每種格式的 API，請參閱 [Supported File Formats](/slides/zh-hant/java/supported-file-formats/)。欲查看目前的 XPS 轉換指南，請參閱 [Convert PowerPoint Presentations to XPS](/slides/zh-hant/java/convert-powerpoint-to-xps/)。

{{% /alert %}}

{{% alert color="info" title="Note" %}}

[XML Paper Specification](https://en.wikipedia.org/wiki/Open_XML_Paper_Specification) 是由 Microsoft 最初開發的頁面描述語言與固定文件格式。如同 PDF，XPS 設計用於保留文件真實度並提供裝置無關的文件外觀。

{{% /alert %}}

## **Aspose.Slides for Java 中的 XPS**
任何可由 Aspose.Slides for Java 載入的簡報文件皆可轉換為 XPS 格式。Aspose.Slides for Java 使用高保真頁面佈局與渲染引擎，產生固定版面的 XPS 文件格式輸出。
您可於 [Convert PowerPoint Presentations to XPS](/slides/zh-hant/java/convert-powerpoint-to-xps/) 了解如何透過 Aspose.Slides for Java 將簡報文件匯出為 XPS 文件。
