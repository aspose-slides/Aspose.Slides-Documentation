{{% alert color="info" %}} 

[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) 是一種簡報文件格式，可由不同版本的 Microsoft PowerPoint 建立、讀取、操作與寫入。這是 Microsoft 開發的二進位簡報文件格式。

{{% /alert %}} 

## **在 Aspose.Slides for Java 中的 PPT**
Aspose.Slides for Java 可以讀取以下軟體所建立的 PPT 檔案。

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

同樣地，Aspose.Slides for Java 所產生的 PPT 檔案也可被上述軟體讀取。

## **全面支援 PPT**
Aspose.Slides for Java 提供了幾乎所有 PPT 文件格式支援的功能。它不僅涵蓋了不同 Microsoft PowerPoint 版本提供的基本與進階功能，還包括 Microsoft PowerPoint 本身不支援的功能。使用 Aspose.Slides for Java API 函式庫的主要優勢在於處理這些功能時的簡易性。

除了建立、讀取與寫入 PPT 文件的基本工作之外，Aspose.Slides for Java 還提供多項功能：

- 將其他 Microsoft Office 檔案格式匯入為 [OLE objects into PPT documents]().
- [Export PPT documents to PDF](/slides/zh-hant/java/convert-powerpoint-ppt-and-pptx-to-pdf/).
- 將 PPT 文件中的投影片匯出為 SVG 格式。
- 將投影片渲染為 Java Framework 支援的任何影像格式。
- 設定 PPT 文件中投影片的尺寸。
- 管理圖形的動畫效果。
- 管理投影片秀。
- [Format text on slides]().
- 從 PPT 文件中擷取文字。
- [Handle tables on slides]().
- 使用 [the cloning feature]() 自動複製母片。
