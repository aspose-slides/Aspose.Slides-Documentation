{{% alert color="info" title="Note" %}}

[可攜式文件格式](https://en.wikipedia.org/wiki/PDF) 是由 Adobe Systems 所創建的檔案格式，用於在組織之間交換文件。此格式的目的是在不同平台上檢視時，保持內容與版面配置相同。Aspose.Slides for Java 讓您能將簡報檔轉換為 PDF。

{{% /alert %}}

## **Aspose.Slides for Java 中的 PDF**
任何可載入至 Aspose.Slides for Java 的簡報，都可以轉換為符合 [PDF 1.5](https://en.wikipedia.org/wiki/PDF)、[PDF/A-1a](https://en.wikipedia.org/wiki/PDF/A)、[PDF/A-1b](https://en.wikipedia.org/wiki/PDF/A) 或 [PDF/UA](https://en.wikipedia.org/wiki/PDF/UA) 的 PDF，視您的選擇而定。Aspose.Slides for Java 將簡報匯出為 PDF，且在大多數情況下，輸出的 PDF 與原始簡報完全相同。

Aspose.Slides 支援以下簡報功能在轉換為 PDF 時保留：

- 圖片、文字方塊與其他圖形。
- 文字與格式設定。
- 段落與格式設定。
- 超連結。
- 頁首與頁尾。
- 項目符號。
- 表格。

您可以直接使用 Aspose.Slides for Java 匯出簡報為 PDF：無需任何其他元件。此外，您還可以依照 [將 PPT 與 PPTX 轉換為 PDF](/slides/zh-hant/java/convert-powerpoint-to-pdf/) 中所說明的各種選項，自訂簡報至 PDF 的匯出方式。
