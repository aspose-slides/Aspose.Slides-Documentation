## **概觀**

此段落不包含當前版本的未解決問題列表。它包含三個頁面：

- [新增 OleObjectFrame 時的物件預覽佔位符](/slides/zh-hant/java/object-preview-issue-when-adding-oleobjectframe/) 說明為何使用 Aspose.Slides 新增的 OLE 物件會在其預覽更新之前顯示「EMBEDDED OLE OBJECT」圖像，以及如何設定您自己的預覽圖像。這是目前版本的設計行為。
- [Aspose.Slides for Java 14.3.0 已知問題（歷史）](/slides/zh-hant/java/known-issues-in-aspose-slides-for-java-14-3-0/) 和 [Aspose.Slides for Java 14.4.0 已知問題（歷史）](/slides/zh-hant/java/known-issues-in-aspose-slides-for-java-14-4-0/) 是隨這些版本一起發布的清單，保留作為參考。

關於每個版本的更改與修復，請參閱 [發行說明](https://releases.aspose.com/slides/zh-hant/java/release-notes/)。Aspose.Slides 寫入的具有固定值的中繼資料欄位在 [輸出中繼資料限制](/slides/zh-hant/java/api-limitations/) 中有說明。要檢查問題是否已被知道，或是回報新問題，請使用 [支援論壇](https://forum.aspose.com/c/slides/zh-hant/11)。
