{{% alert color="info" %}} 

Aspose.Slides for Java 14.4.0 為 PowerPoint 文件處理提供了新的決策。仍有一些限制與已知問題，這些問題將在未來的版本中移除：

- 某些圖形在序列化的 PPT 文件中幾何形狀錯誤（弧形、圓形箭頭、標註）。
- 並非所有 PPTX 文字格式化功能在 PPT 序列化時皆受支援（製表、縮排及段落格式限制）。
- 序列化的 PPT 文件中未包含文字語言與拼寫設定資訊。
- 並非所有 PPTX 主題功能在 PPT 序列化時皆受支援（僅支援填充格式、線條格式與字型的序列化）。
- OLE/ActiveX 在 PPT 序列化為 PPT 時存在已知問題。
- 不支援 WordArt 的序列化與呈現。
