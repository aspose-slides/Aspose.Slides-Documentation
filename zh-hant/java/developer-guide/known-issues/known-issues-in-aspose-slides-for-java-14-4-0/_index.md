{{% alert color="info" title="Note" %}}

這是一個歷史頁面。它列出了與 Aspose.Slides for Java 14.4.0 一起發布的限制與已知問題，並未描述目前的版本。欲了解各版本的變更，請參閱[發行說明](https://releases.aspose.com/slides/zh-hant/java/release-notes/)。

{{% /alert %}}

Aspose.Slides for Java 14.4.0 為 PowerPoint 文件處理提供了新的決策。存在一些限制與已知問題，這些問題將在未來的版本中移除：

- 某些形狀在序列化的 PPT 文件中幾何形狀不正確（弧形、圓形箭頭、標註）。
- 並非所有 PPTX 文字格式化功能在 PPT 序列化時皆受支援（制表符、縮排與段落格式限制）。
- 序列化的 PPT 文件中不包含文字語言和拼寫設定資訊。
- 並非所有 PPTX 主題功能在 PPT 序列化時受支援（僅支援填充格式、線條格式與字型的序列化）。
- OLE/ActiveX PPT 序列化為 PPT 時存在已知問題。
- 不支援 WordArt 的序列化與呈現。
