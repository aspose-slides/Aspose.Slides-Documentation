{{% alert color="info" title="Note" %}}

這是一個歷史頁面。它列出了與 Aspose.Slides for Java 14.3.0 發佈的已知問題，且不描述目前的版本。欲了解各版本的變更，請參閱[發佈說明](https://releases.aspose.com/slides/zh-hant/java/release-notes/)。

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) 提供了全新的 PPT 處理實作。改進了許多功能，包括 PPTX 轉換為 PPT 的部分轉換。但仍有一些未實作的功能：

- 某些圖形在序列化的 PPT 文件中具有錯誤的幾何形狀（Call outs）
- 並非所有 PPTX 文字格式化功能在 PPT 序列化中均受支援
- 序列化的 PPT 文件中缺少文字語言與拼寫設定資訊
- 並非所有 PPTX 主題的功能在 PPT 序列化中均受支援

**相較於 Aspose.Slides for Java 8.6.0，有一些差異：**

- 在 OLE/ActiveX PPT 序列化為 PPT 時存在已知問題

**相較於 Aspose.Slides for .NET 14.3.0，有一些差異：**

- 目前 Aspose.Slides for Java 尚未提供簡報列印支援
