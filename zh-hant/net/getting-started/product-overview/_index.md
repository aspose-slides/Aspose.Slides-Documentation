## **歡迎使用 Aspose.Slides for .NET！**

Aspose.Slides 是一套 Microsoft PowerPoint® 管理 API，讓應用程式在不使用 Microsoft PowerPoint® 的情況下讀取、寫入、建立與修改 PowerPoint 簡報。此函式庫支援處理簡報、投影片、圖形、表格、文字、動畫、音訊、影像以及其他簡報元素。

使用 Aspose.Slides，開發人員可以從不同來源開啟簡報，將其儲存為各種 PowerPoint 格式，將簡報匯出為 PDF、TIFF、XPS、SWF、HTML、SVG 等格式，並將投影片儲存為影像。API 亦提供管理文件屬性、套用保護、預覽投影片、編輯投影片內容、處理投影片註解，以及處理嵌入 OLE 物件等進階簡報元素的功能。

## **為何您應該使用 Aspose.Slides for .NET**

- Aspose.Slides for .NET 是首個也是唯一提供完整 PowerPoint® 文件管理功能的元件。
- Aspose.Slides for .NET 提供諸多關鍵功能，例如管理文字、圖形、表格與動畫、在投影片中加入音訊與影像、預覽投影片、將投影片匯出為 SVG、PDF 等格式，以及更多功能。
- Aspose.Slides for .NET 不僅能從不同來源開啟 PowerPoint 檔案，還能以多種方式儲存簡報。例如，您可以將簡報儲存為 PPT；也可以將投影片儲存為影像。
- Aspose.Slides for .NET 幾乎提供了 Microsoft PowerPoint 所有功能，除表格與各種圖形外，您還可以在投影片中加入文字、音訊與影像框架。
- Aspose.Slides for .NET 以受控的 C# 開發。您可以在任何 .NET 語言（如 C#、VB.NET、J# 等）中使用 Aspose.Slides for .NET，亦可用於任何類型的應用程式——Web 或 Windows 應用程式。
- Aspose.Slides for .NET 亦提供完整的示範與範例，協助開發人員深入了解 API。

## **Aspose.Slides 功能**
Aspose.Slides for .NET 的功能可分為以下幾組：

1. 簡報功能。
1. 投影片功能。
1. 圖形與多媒體功能。
1. 表格功能。
1. 文字與段落功能。
1. 進階功能。

### **簡報功能**
- 從不同來源開啟 Microsoft PowerPoint 簡報。
- 以不同的 Microsoft PowerPoint 格式儲存簡報。
- 從頭建立簡報。
- 在不使用其他元件的情況下將簡報轉換為 PDF 文件。
- 讀取或修改簡報的文件屬性。
- 為簡報套用保護。
- 匯出簡報為 PDF。
- 匯出簡報為 TIFF。
- 匯出簡報為 XPS。
- 匯出簡報為 SWF。
- 匯出簡報為 PDF 註解 / TIFF 註解。
- 匯出簡報為 HTML。

### **投影片功能**
- 從頭建立新投影片並加入簡報。
- 依投影片在簡報中的位置存取任何投影片。
- 複製或克隆投影片至相同或其他簡報。
- 編輯與刪除投影片。
- 同時複製投影片母版。
- 預覽投影片。
- 取得或設定投影片名稱。
- 將投影片儲存為影像。
- 匯出投影片為 SVG 格式。
- 在簡報中使用多個母版。
- 以任何支援的樣式填滿投影片背景。
- 新增或管理投影片註解。
- 動態設定新投影片母版與樣式。
- 新增或修改投影片秀過渡效果。
- 新增 Morph 過渡效果。

### **圖形與多媒體功能**
- 建立或管理線條、矩形、橢圓、折線等圖形。
- 管理圖形的線條樣式。
- 取得圖形的替代文字。
- 旋轉與翻轉圖形。
- 以不同樣式填充圖形——例如實線、漸層、圖案、紋理與圖片。
- 使用 48 種預定義圖案與 24 種紋理。
- 為圖形指派鏈結。
- 讀取、修改及為投影片與圖形新增動畫效果。
- 為簡報新增圖片並管理現有圖片。
- 為簡報新增圖片項目符號並管理現有項目符號。
- 為簡報新增音訊框架並管理現有音訊框架。
- 為簡報新增影像框架並管理現有影像框架。

### **表格功能**
- 從頭建立表格並加入投影片。
- 調整表格尺寸與位置。
- 存取表格中的任何儲存格。
- 變更任何儲存格的格式與邊框。
- 調整欄與列的大小。
- 新增與刪除欄與列。
- 為整個表格設定邊框寬度與顏色。

### **文字與段落功能**
- 取得與設定文字佔位元與文字框中的文字。
- 取得佔位元的類型。
- 變更文字框中的文字格式。
- 新增字型或管理簡報中已使用的字型。
- 變更文字與文字格式。
- 建立或管理文字的鏈結。
- 支援 Tab 與有效 Tab。
- 為幾乎所有類型的圖形新增文字框。
- 存取與修改文字框的邊距與文字環繞設定。
- 存取與修改段落縮排。

### **進階功能**
- 存取簡報中嵌入的 OLE 物件。
- 鎖定簡報。

## **信任等級需求**

在 .NET Framework 上，Aspose.Slides 需要完整信任，無法在 ASP.NET 部分信任（如 Medium Trust）環境執行。在 .NET 6 及更新版本中則不需設定信任等級。請參考 [信任等級需求](/slides/zh-hant/net/declaration/)。

## **常見問題**

### 是否支援用於歸檔與可及性之 PDF 相容等級 (PDF/A 與 PDF/UA)？

是的。您可以透過設定 [PDF 匯出選項](https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/) 以 PDF/A-2a/2b/2u、PDF/A-3a/3b 以及 PDF/UA 格式儲存為 PDF。

### 是否有字型替代機制，並支援自訂字型以確保正確的渲染？

是的。函式庫允許您 [載入自訂字型](/slides/zh-hant/net/custom-font/) 並 [定義回退規則](/slides/zh-hant/net/fallback-font/)，在轉換與渲染時可靠地替代缺少的字形。

### 是否能在未完整開啟檔案的情況下偵測檔案是否受密碼保護？

是的。您可以 [檢查簡報](/slides/zh-hant/net/examine-presentation/) 以判斷是否需要密碼才能載入完整文件。

### 處理與轉換時是否需要安裝 Microsoft PowerPoint？

不需要。Aspose.Slides 是獨立的引擎，伺服器或工作站上不必安裝 PowerPoint。

### 在多執行緒環境中處理簡報是否安全？

是的，您可以在不同執行緒中平行處理多個文件；只要避免在多執行緒間同時使用同一個簡報實例 [跨執行緒](/slides/zh-hant/net/multithreading/) 即可。

### 是否保留巨集，且能在 PPTM/PPSM 檔案中管理 VBA？

是的。支援含巨集的簡報 [已支援](/slides/zh-hant/net/presentation-via-vba/)，您也可以在這些檔案中 [檢查與管理 VBA 專案](https://reference.aspose.com/slides/net/aspose.slides.vba/)。

### 是否能將 PDF 或 HTML 轉回 PowerPoint 投影片？

是的。您可以 [匯入 PDF 頁面或 HTML 內容](/slides/zh-hant/net/import-presentation/) 以建立或填充簡報中的投影片。

### 是否支援 XPS 匯出，且能控制 XPS 輸出的品質與內容？

是的。提供 [匯出至 XPS](/slides/zh-hant/net/convert-powerpoint-to-xps/) 功能，且透過 [儲存選項](https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions/) 可調整輸出品質與內容。

### 是否能將投影片轉換為影像，並控制輸出品質？

是的。投影片可 [轉換為 PNG、JPEG、GIF、BMP、TIFF](/slides/zh-hant/net/convert-powerpoint-to-png/) 等格式，並可細緻控制大小與品質。

### 是否支援數學公式 (MathML/MathText)，且能匯出？

是的。您可以 [建立與編輯數學文字](/slides/zh-hant/net/powerpoint-math-equations/) 並 [匯出方程式](/slides/zh-hant/net/exporting-math-equations/)，包括匯出為 MathML。

### 函式庫如何處理加密與密碼（開啟、設定、移除）？

[它支援](/slides/zh-hant/net/password-protected-presentation/) 開啟加密簡報、設定或移除開啟與修改的密碼，並可檢查檔案的保護狀態。
