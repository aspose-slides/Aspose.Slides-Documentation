## **概覽**

本文說明如何獲得 Aspose.Slides 的支援以及如何有效地回報問題。它描述了主要的支援管道，提供提交問題的建議，並指向有用的技術資源，例如產品頁面、部落格、下載、支援論壇、文件與 API 參考。本文亦回答有關付費支援、問題升級，以及舊版函式庫支援的常見問題。

## **技術支援**
{{% alert color="info" %}}
Aspose 為其所有產品提供無限制的免費技術支援。此支援對所有使用者皆可使用（包括使用評估套件的使用者）。
{{% /alert %}} 

當您需要 Aspose.Slides for .NET 的協助時，請考慮以下事項：

- 支援的主要管道是 [Aspose.Forums](https://forum.aspose.com/c/slides/zh-hant/11)。在 Aspose.Slides 論壇發表您的問題——它會在數小時內得到回覆。Aspose.Slides 支援團隊會直接回答論壇上發佈的問題。
- 請注意，Aspose 不提供電話技術支援。電話支援僅限於銷售與購買相關問題。
- 在論壇期待回覆時，請保持耐心，並考慮時區差異。

當您在 Aspose.Slides for .NET 中遇到問題時，請遵循以下指導方針以最高效的方式解決：

- 在回報問題之前，先檢查並確認您使用的是最新的 Aspose.Slides for .NET 版本。也許您遇到的問題已在更新中得到解決。

  請參閱 Aspose.Slides 下載以取得最新版本資訊。

- 在回報問題之前，您可能想先瀏覽我們的論壇、此文件與 API 參考。也許您的問題答案已經提供。

- 回報問題時，請附上原始文件以及（如果可能）與問題相關的程式碼片段。如果需要附加多個檔案，請將它們壓縮成 ZIP 包。

  您可以安全地在 Aspose.Forums 中附加文件，因為 **僅** 您與 Aspose 開發人員可存取這些附件。

- 針對特定問題建立並使用單一討論串。若您遇到其他問題，必須建立另一個討論串進行回報。

## **常見問題**

### 有哪些付費支援等級且它們有何差異？

[Developer、Business 與 Enterprise](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。它們在所含事件數量、回應優先權以及可用的溝通管道上有所不同。

### 我可以直接將錯誤升級給工程團隊嗎？

是的。[付費支援](https://helpdesk.aspose.com/) 允許在問題需要更深入調查時將其升級給開發人員。

### 舊版函式庫是否受到支援，且會釋出修正嗎？

您可以使用較舊的版本，但只提供目前發行版的修正；不會為舊版釋出修補程式。
