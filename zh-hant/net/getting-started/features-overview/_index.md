|**功能**|**說明**|

|**功能**|**說明**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/zh-hant/net/ppt-vs-pptx/)|Aspose.Slides for .NET 為此簡報檔案格式提供最快的處理速度。|
|[PPT 轉換為 PPTX](/slides/zh-hant/net/convert-ppt-to-pptx/)|Aspose.Slides for .NET 支援將 PPT 轉換為 PPTX。|
|[Portable Document Format (PDF)](/slides/zh-hant/net/convert-powerpoint-ppt-and-pptx-to-pdf/)|您可以使用單一方法將所有支援的檔案格式匯出為 Adobe Portable Document Format (PDF) 文件。|
|[XML Parser Specification (XPS)](https://docs.aspose.com/slides/zh-hant/net/convert-powerpoint-to-xps/)|您可以使用單一方法將所有支援的檔案格式匯出為 XML Parser Specification (XPS) 文件。|
|[Tagged Image File Format (TIFF)](/slides/zh-hant/net/convert-powerpoint-to-tiff/)|您可以將所有支援的簡報檔案格式匯出為 Tagged Image File Format (TIFF)。|
|[PPTX 轉換為 HTML](/slides/zh-hant/net/convert-powerpoint-ppt-and-pptx-to-html/)|Aspose.Slides for .NET 支援將 PresentationEx 轉換為 HTML 格式。|

|**功能**|**說明**|
| :- | :- |
|.NET Supported Image Formats|使用 Aspose.Slides for .NET，您可以將簡報投影片及投影片中的影像渲染為所有 .NET 支援的圖形格式，例如 TIFF、PNG、BMP、JPEG、GIF 與圖增檔。|
|SVG Format|Aspose.Slides for .NET 也提供內建方法，讓您將簡報投影片匯出為 Scalable Vector Graphics (SVG) 格式。|

## **常見問題**

### 我需要在伺服器或 PC 上安裝 Microsoft PowerPoint 才能使用此函式庫嗎？

不需要。PowerPoint 並非必要；Aspose.Slides 為獨立的引擎，可用於建立、編輯、轉換與呈現簡報。

### 多執行緒如何運作？可以平行處理嗎？

在不同執行緒中處理不同文件是安全的；同一個[簡報](https://reference.aspose.com/slides/zh-hant/net/aspose.slides/presentation/)物件不能同時被[multiple threads](/slides/zh-hant/net/multithreading/)使用。

### 是否支援檔案密碼與加密？

是的。您可以[開啟受保護的簡報](/slides/zh-hant/net/password-protected-presentation/)，設定或移除開啟與寫入密碼，並檢查保護狀態。

### 在 Linux 容器中需要關心字型套件嗎？

是的。建議安裝常見的字型套件，或在應用程式中明確[指定字型目錄](/slides/zh-hant/net/custom-font/)，以避免意外的字型替換。

### 評估版有什麼限制？

在[evaluation mode](/slides/zh-hant/net/licensing/)下，輸出會加上浮水印，且會有特定限制；您可以取得[30 天臨時授權](https://purchase.aspose.com/temporary-license/)以完整測試所有功能。

### 是否支援將外部格式匯入簡報（PDF/HTML → PPTX）？

是的。您可以將[PDF 頁面與 HTML 內容](/slides/zh-hant/net/import-presentation/)新增至簡報，並將它們轉換為投影片。
