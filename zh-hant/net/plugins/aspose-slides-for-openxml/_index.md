## **什麼是 OpenXML？**
OpenXML SDK 是 Microsoft 提供的 .NET SDK，用於處理 Microsoft Office 2007 及以上版本的檔案格式。這些檔案格式基本上是 zip 壓縮的套件，而 Open XML SDK for Office 簡化了操作 Open XML 套件以及套件內底層 Open XML 架構元素的工作。Open XML SDK 中的類別封裝了開發人員在 Open XML 套件上常執行的許多工作，讓您只需幾行程式碼就能完成複雜的操作。

安裝了 Open XML SDK 2.5 後，打開您現有的專案或應用程式（Visual Studio），或建立新專案或應用程式。然後在您的專案或應用程式中，加入下列元件的參考：

- DocumentFormat.OpenXml
- WindowsBase
## **Aspose.Slides for .NET**
Aspose.Slides for .NET 是一套獨特的 PowerPoint® 管理元件，使 .NET 應用程式能在不使用 Microsoft PowerPoint 的情況下讀取、寫入及操作 PowerPoint 文件。

Aspose.Slides for .NET 是首個也是唯一提供在您自己的應用程式中管理 PowerPoint 文件功能的 .NET 元件。與所有 Aspose .NET 元件一樣，Aspose.Slides 以受管理的 C# 撰寫，價格實惠且執行速度極快。
