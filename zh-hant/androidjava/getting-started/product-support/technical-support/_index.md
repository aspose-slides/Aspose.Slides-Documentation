## **概述**

本文說明了如何取得 Aspose.Slides 的支援以及如何有效回報問題。它描述了主要的支援管道，提供提交問題的建議，並指向有用的技術資源，如產品頁面、部落格、下載、支援論壇、文件與 API 參考。本篇亦回答了關於付費支援、問題升級以及舊版函式庫支援的常見問題。

## **技術支援**

{{% alert color="info" %}} 

Aspose 為其所有產品提供無限制的免費技術支援。此支援對所有使用者皆開放（包括使用評估套件的使用者）。

{{% /alert %}} 

當您需要 Aspose.Slides for Android via Java 的協助時，請參考以下說明：

- 主要的支援管道為 Aspose.Forums。請在 Aspose.Slides 論壇發問，問題通常會在數小時內得到回覆。Aspose.Slides 支援團隊會直接在論壇回覆問題。
- 請注意，Aspose 不提供電話技術支援。電話支援僅限於銷售與購買相關問題。
- 在論壇期待回覆時，請耐心等待，並考量時區差異。

當您在 Aspose.Slides for Android via Java 中遇到問題時，請依照以下指引以最有效的方式解決：

- 在回報問題前，先確認您使用的是最新的 Aspose.Slides for Android via Java 版本。或許您所遇到的問題已在更新中被修正。 

  查看 Aspose.Slides 下載以取得最新版本的相關資訊。

- 在回報問題之前，您可以先瀏覽我們的論壇、此文件與 API 參考。也許答案已經在那裡提供。

- 回報問題時，請附上原始文件以及（若可能）與問題相關的程式碼片段。若需附加多個檔案，請將它們壓縮成 ZIP 包。 

  您可以安心在 Aspose.Forums 上上傳文件，因為只有您與 Aspose 開發人員能存取這些附件。

- 為特定問題建立並使用單一討論串。如果您遇到其他問題，請另開新討論串進行回報。

## **常見問題**

### 有哪些付費支援等級？它們有何不同？

[開發者、商務與企業](https://helpdesk.aspose.com/kb/faq/1-Introduction-to-Paid-Support-Services)。它們在包含的事件數、回應優先順序以及可使用的通訊管道上有所差異。

### 我可以直接將錯誤升級給工程團隊嗎？

可以。[付費支援](https://helpdesk.aspose.com/) 允許在問題需要更深入調查時升級給開發人員。

### 是否支援舊版函式庫，並提供修正？

您可以使用舊版，但僅對目前發行的版本提供修正；舊版不會發佈補丁。
