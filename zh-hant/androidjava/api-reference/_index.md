{{% alert color="info" %}} 

Aspose.Slides for Android via Java 是一個類別庫，可讓 Android 的 Java 應用程式在不使用 Microsoft PowerPoint® 或其他軟體的情況下讀寫簡報文件。Aspose.Slides for Android via Java 允許您管理文字、形狀、表格和動畫；向投影片新增音訊和影片；預覽投影片；以及將投影片匯出為 SVG、PDF 等格式。

最新的 API 參考可在 [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/zh-hant/androidjava/) 找到。
