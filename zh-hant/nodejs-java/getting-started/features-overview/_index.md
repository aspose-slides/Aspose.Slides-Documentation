## **支援平台**
Aspose.Slides for Node.js via Java 是一個平台無關的 API。只要安裝了 Node.js 7 或更新的版本，就可在任何平台（Windows、Linux、MacOS 等）上使用。另一個需求是 Oracle JDK 8 或更高版本。

## **檔案格式與轉換**
Aspose.Slides for Node.js via Java 支援大多數 PowerPoint 文件格式，並且能將它們匯出為組織常用且共享的檔案格式。請參閱以下細節：

|**功能**|**說明**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java 為此簡報文件格式提供最快的處理速度。|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java 支援 PPT 轉換為 PPTX。|
|Portable Document Format (PDF)|您可以使用單一方法將所有支援的檔案格式匯出為 Adobe Portable Document Format (PDF) 文件。|
|XML Parser Specification (XPS)|您可以使用單一方法將所有支援的檔案格式匯出為 XML Parser Specification (XPS) 文件。|
|Tagged Image File Format (TIFF)|您可以將所有支援的簡報檔案格式匯出為 Tagged Image File Format (TIFF)。|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java 支援將 PresentationEx 轉換為 HTML 格式。|

## **簡報呈現**
Aspose.Slides for Node.js via Java 支援將簡報投影片高保真度地渲染為不同的圖形格式。請參閱以下細節：

|**功能**|**說明**|
| :- | :- |
|Java Supported Image Formats|使用 Aspose.Slides for Node.js via Java，您可以將簡報投影片及投影片中的圖像渲染為所有 Java 支援的圖形格式，如 TIFF、PNG、BMP、JPEG、GIF。|
|SVG Format|Aspose.Slides for Node.js via Java 也提供內建方法，允許您將簡報投影片匯出為可伸縮向量圖形 (SVG) 格式。|

## **常見問題**

### 是否需要在伺服器或 PC 上安裝 Microsoft PowerPoint 才能使用此函式庫？

不需要。PowerPoint 並非必要條件；Aspose.Slides 是一個獨立的引擎，用於建立、編輯、轉換與呈現簡報。

### 多執行緒如何運作？處理程序能否平行化？

在不同執行緒中處理不同文件是安全的；同一個[presentation](https://reference.aspose.com/slides/zh-hant/nodejs-java/aspose.slides/presentation/) 物件不可同時被[multiple threads](/slides/zh-hant/nodejs-java/multithreading/) 使用。

### 是否支援檔案密碼與加密？

支援。您可以[/slides/zh-hant/nodejs-java/password-protected-presentation/] 開啟加密的簡報、設定或移除開啟與寫入密碼，並檢查保護狀態。

### 在 Linux 容器中是否需要注意字型套件？

需要。建議安裝常見的字型套件，或在應用程式中明確[specify font directories](/slides/zh-hant/nodejs-java/custom-font/)，以避免意外的字型替換。

### 評估版有什麼限制？

在[evaluation mode](/slides/zh-hant/nodejs-java/licensing/) 下，輸出會加入浮水印，且會有若干限制；可取得[30 天臨時許可證](https://purchase.aspose.com/temporary-license/) 以進行完整功能測試。

### 是否支援將外部格式匯入簡報 (PDF/HTML → PPTX)？

支援。您可以將[PDF 頁面和 HTML 內容](/slides/zh-hant/nodejs-java/import-presentation/) 加入簡報，並將其轉換為投影片。
