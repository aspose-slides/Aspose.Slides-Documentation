## **受支援的平台**
Aspose.Slides for Node.js via .NET 是一個平台無關的 API。它可以在任何安裝了 Node.js 7 或更高版本的平台（Windows、Linux、MacOS 等）上使用。Oracle JDK 8 或更高版本是另一項需求。

## **檔案格式與轉換**
Aspose.Slides for Node.js via .NET 支援大多數 PowerPoint 文件格式。它也讓您將這些文件匯出為組織常用且彼此共享的流行檔案格式。請參閱以下詳細說明：

|**功能**|**說明**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET 為此簡報文件格式提供最快的處理速度。|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET 支援 PPT 轉換為 PPTX。|
|Portable Document Format (PDF)|您可以使用單一方法將所有受支援的檔案格式匯出為 Adobe Portable Document Format（PDF）文件。|
|XML Parser Specification (XPS)|您可以使用單一方法將所有受支援的檔案格式匯出為 XML Parser Specification（XPS）文件。|
|Tagged Image File Format (TIFF)|您可以將所有受支援的簡報檔案格式匯出為 Tagged Image File Format（TIFF）。|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET 支援將 PresentationEx 轉換為 HTML 格式。|

## **簡報渲染**
Aspose.Slides for Node.js via .NET 支援將簡報中的投影片以高保真度渲染為不同的圖形格式。請參閱以下詳細說明：

|**功能**|**說明**|
| :- | :- |
|.NET Supported Image Formats|使用 Aspose.Slides for Node.js via .NET，您可以將簡報投影片和投影片內的圖像渲染為所有 .NET 支援的圖形格式，例如 TIFF、PNG、BMP、JPEG、GIF。|
|SVG Format|Aspose.Slides for Node.js via .NET 也提供內建方法，允許您將簡報投影片匯出為可縮放向量圖形（SVG）格式。|

## **內容功能**
Aspose.Slides for Node.js via .NET 讓您可以存取、修改或建立簡報文件中幾乎所有的項目或內容。請參閱以下詳細說明：

|**功能**|**說明**|
| :- | :- |
|Master Slides|母版投影片定義普通投影片的版面配置。Aspose.Slides for Node.js via .NET 允許您存取並修改簡報文件的母版投影片。|
|Normal Slides|使用 Aspose.Slides for Node.js via .NET，您可以建立不同類型的新投影片；同時也能存取並修改簡報中現有的投影片。|
|Cloning / Copying Slides|Aspose.Slides for Node.js via .NET 提供內建方法，允許您在同一簡報內部複製或克隆現有投影片。您也可以將複製或克隆的投影片從一個簡報移至另一個簡報。由於投影片會從母版投影片繼承版面配置，內建的克隆方法會自動在克隆時複製母版。|
|Managing Slides sections|提供將投影片組織於簡報不同區段的方法。|
|Place Holders and Text Holders|您可以存取投影片中的佔位符與文字佔位符。此外，您也可以使用適當的方法從頭建立含有文字佔位符的投影片。|
|Header and Footers|Aspose.Slides for Node.js via .NET 方便您處理投影片的頁首與頁尾。|
|Notes in Slides|使用 Aspose.Slides for Node.js via .NET，您可以存取與修改投影片的備註，亦可新增備註。|
|Finding a Shape|您也可以使用形狀相關的替代文字，從投影片中尋找特定形狀。|
|Backgrounds|Aspose.Slides for Node.js via .NET 允許您處理與母版或普通投影片相關的背景。|
|Text Boxes|文字方塊可以從頭建立。您可以存取現有的文字方塊，也能在不失去原始文字格式的情況下修改其文字內容。|
|Rectangle Shapes|您可以使用 Aspose.Slides for Node.js via .NET 建立或修改方形形狀。|
|Poly Line Shapes|您可以使用 Aspose.Slides for Node.js via .NET 建立或修改折線形狀。|
|Ellipse Shapes|您可以使用 Aspose.Slides for Node.js via .NET 建立或修改橢圓形狀。|
|Group Shapes|Aspose.Slides for Node.js via .NET 支援群組形狀|
|Auto Shapes|Aspose.Slides for Node.js via .NET 支援自動形狀|
|SmartArt|Aspose.Slides for Node.js via .NET 為 MS PowerPoint 中的 SmartArt 形狀提供支援|
|Charts|Aspose.Slides for Node.js via .NET 為 PowerPoint 中的 MSO 圖表提供支援|
|Shapes Serialization|Aspose.Slides for Node.js via .NET 支援大量形狀。當 Aspose.Slides for Node.js via .NET 缺乏對某個形狀的支援時，您可以使用序列化方法，將該形狀從現有投影片序列化。如此，您即可依需求再次使用該形狀。|
|Picture Frames|您可以使用 Aspose.Slides for Node.js via .NET 管理圖片框中的圖片。|
|Audio Frames|您可以在投影片的音訊框中連結或嵌入音訊檔案，使用 Aspose.Slides for Node.js via .NET。|
|Video Frames|您可以在投影片的視訊框中處理視訊檔案。Aspose.Slides for Node.js via .NET 亦提供連結與嵌入式視訊的支援。|
|OLE Frame|您可以使用 Aspose.Slides for Node.js via .NET 管理 OLE 框中的 OLE 物件。|
|Tables|Aspose.Slides for Node.js via .NET 支援投影片中的表格。|
|ActiveX Controls|支援 ActiveX 控制項|
|VBA Macros|支援在簡報內管理 VBA 巨集。|
|Text Frame|您可以透過與形狀相關聯的文字框存取該形狀的文字。|
|Text Scanning|您可以使用內建掃描方法，在簡報或投影片層級掃描文字。|
|Animations|您可以對形狀套用動畫。|
|Slide Shows|Aspose.Slides for Node.js via .NET 支援投影片放映與投影片過場動畫|

## **格式化功能**
使用 Aspose.Slides for Node.js via .NET，您可以在簡報投影片上格式化文字與形狀。請參閱以下詳細說明：

|**功能**|**說明**|
| :- | :- |
|Text Formatting|<p>在 Aspose.Slides for Node.js via .NET 中，您可以透過形狀關聯的文字框管理文字。因此，您可以使用文字框關聯的段落與文字片段來格式化文字。這些文字元素可透過 Aspose.Slides for Node.js via .NET 進行格式化。</p><p>- 字型類型</p><p>- 字型大小</p><p>- 字型顏色</p><p>- 字型色階</p><p>- 段落對齊</p><p>- 段落項目符號</p><p>- 段落方向</p>|
|Shape Formatting|<p>在 Aspose.Slides for Node.js via .NET 中，投影片的基本元素是形狀。您可以使用 Aspose.Slides for Node.js via .NET 對這些形狀元素進行格式化：</p><p>- 位置</p><p>- 大小</p><p>- 線條</p><p>- 填充（含圖案、漸層、純色）</p><p>- 文字</p><p>- 圖像</p>|
