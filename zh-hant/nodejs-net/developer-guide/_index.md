本 **開發者指南** 介紹如何在 JavaScript 中使用 Aspose.Slides for Node.js via .NET 執行常見的簡報操作。每篇文章皆包含可執行範例。執行之前，請依照 [安裝](/slides/zh-hant/nodejs-net/installation/) 中的說明建立專案。

- [**建立簡報**](/slides/zh-hant/nodejs-net/create-presentation/) – 建立簡報、加入文字方塊與投影片、設定投影片大小，並將結果儲存為 PPTX。
- [**開啟簡報**](/slides/zh-hant/nodejs-net/open-presentation/) – 從檔案或緩衝區開啟簡報、讀取投影片數量，並將其儲存為其他格式。
- [**PowerPoint 轉 PDF**](/slides/zh-hant/nodejs-net/convert-powerpoint-to-pdf/) – 將簡報轉換為 PDF，包括用於存檔的 PDF/A。
- [**投影片轉圖片**](/slides/zh-hant/nodejs-net/convert-slide/) – 依比例因子或以精確的像素尺寸將投影片渲染為 PNG 圖片。
- [**管理文字**](/slides/zh-hant/nodejs-net/manage-text/) – 加入文字方塊，然後變更其文字、字型大小與粗體樣式。
