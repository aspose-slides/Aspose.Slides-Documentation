## **แพลตฟอร์มที่สนับสนุน**
Aspose.Slides for Node.js via .NET เป็น API ที่ไม่ขึ้นกับแพลตฟอร์ม สามารถใช้ได้บนทุกแพลตฟอร์ม (Windows, Linux, MacOS ฯลฯ) ที่ติดตั้ง Node.js รุ่น 7 หรือสูงกว่า อีกข้อกำหนดคือ Oracle JDK รุ่น 8 หรือสูงกว่า.

## **รูปแบบไฟล์และการแปลง**
Aspose.Slides for Node.js via .NET รองรับรูปแบบเอกสาร PowerPoint ส่วนใหญ่ นอกจากนี้ยังช่วยให้คุณส่งออกไฟล์เหล่านี้ไปยังรูปแบบไฟล์ที่เป็นที่นิยมที่องค์กรต่าง ๆ ใช้และแชร์กัน ดูรายละเอียดต่อไปนี้:

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via .NET ให้การประมวลผลที่เร็วที่สุดสำหรับรูปแบบเอกสารการนำเสนอชนิดนี้.|
|PPT to PPTX conversion|Aspose.Slides for Node.js via .NET รองรับการแปลง PPT เป็น PPTX|
|Portable Document Format (PDF)|คุณสามารถส่งออกไฟล์รูปแบบที่รองรับทั้งหมดเป็นเอกสาร Adobe Portable Document Format (PDF) ด้วยวิธีการเดียว.|
|XML Parser Specification (XPS)|คุณสามารถส่งออกไฟล์รูปแบบที่รองรับทั้งหมดเป็นเอกสาร XML Parser Specification (XPS) ด้วยวิธีการเดียว.|
|Tagged Image File Format (TIFF)|คุณสามารถส่งออกไฟล์รูปแบบการนำเสนอที่รองรับทั้งหมดเป็น Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via .NET รองรับการแปลง PresentationEx เป็นรูปแบบ HTML.|

## **การเรนเดอร์การนำเสนอ**
Aspose.Slides for Node.js via .NET รองรับการเรนเดอร์สไลด์ในงานนำเสนอด้วยความละเอียดสูงเป็นรูปแบบกราฟิกต่าง ๆ ดูรายละเอียดต่อไปนี้:

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|.NET Supported Image Formats|โดยใช้ Aspose.Slides for Node.js via .NET คุณสามารถเรนเดอร์สไลด์การนำเสนอและภาพบนสไลด์เป็นรูปแบบกราฟิกที่ .NET รองรับทั้งหมด เช่น TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Node.js via .NET ยังมีเมธอดในตัวที่ช่วยให้คุณส่งออกสไลด์การนำเสนอเป็นรูปแบบ Scalable Vector Graphics (SVG).|

## **คุณลักษณะของเนื้อหา**
Aspose.Slides for Node.js via .NET อนุญาตให้คุณเข้าถึง, แก้ไข หรือสร้างรายการหรือเนื้อหาส่วนใหญ่ของเอกสารการนำเสนอ ดูรายละเอียดต่อไปนี้:

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|Master Slides|สไลด์แม่กำหนดเค้าโครงของสไลด์ปกติ Aspose.Slides for Node.js via .NET อนุญาตให้คุณเข้าถึงและแก้ไขสไลด์แม่ของเอกสารการนำเสนอ|
|Normal Slides|ด้วย Aspose.Slides for Node.js via .NET คุณสามารถสร้างสไลด์ใหม่ประเภทต่าง ๆ; คุณยังสามารถเข้าถึงและแก้ไขสไลด์ที่มีอยู่ในงานนำเสนอได้|
|Cloning / Copying Slides|มีเมธอดในตัวที่ Aspose.Slides for Node.js via .NET ให้เพื่อให้คุณทำการโคลนหรือคัดลอกสไลด์ที่มีอยู่ภายในงานนำเสนอ คุณยังสามารถใช้สไลด์ที่คัดลอกหรือโคลนจากงานหนึ่งไปยังอีกงานหนึ่ง เนื่องจากสไลด์สืบทอดเค้าโครงจากสไลด์แม่ เมธอดโคลนในตัวจะคัดลอกสไลด์แม่โดยอัตโนมัติในขณะโคลน|
|Managing Slides sections|เมธอดสำหรับจัดสไลด์เป็นส่วนต่าง ๆ ภายในงานนำเสนอ|
|Place Holders and Text Holders|คุณสามารถเข้าถึงตำแหน่งที่ถือไว้และตัวถือข้อความในสไลด์ นอกจากนี้คุณยังสามารถสร้างสไลด์พร้อมตัวถือข้อความตั้งแต่ต้นโดยใช้เมธอดที่เหมาะสม|
|Header and Footers|Aspose.Slides for Node.js via .NET ช่วยอำนวยความสะดวกในการจัดการส่วนหัว/ส่วนท้ายในสไลด์|
|Notes in Slides|ด้วย Aspose.Slides for Node.js via .NET คุณสามารถเข้าถึงและแก้ไขบันทึกที่เชื่อมโยงกับสไลด์และยังสามารถเพิ่มบันทึกใหม่ได้|
|Finding a Shape|คุณยังสามารถค้นหารูปร่างเฉพาะจากสไลด์โดยใช้ข้อความแทนที่เชื่อมโยงกับรูปร่างนั้น|
|Backgrounds|Aspose.Slides for Node.js via .NET อนุญาตให้คุณทำงานกับพื้นหลังที่เชื่อมโยงกับสไลด์แม่หรือสไลด์ปกติในงานนำเสนอ|
|Text Boxes|คุณสามารถสร้างกล่องข้อความตั้งแต่ต้น สามารถเข้าถึงกล่องข้อความที่มีอยู่แล้วและแก้ไขข้อความโดยไม่เสียรูปแบบต้นฉบับ|

|Poly Line Shapes|คุณสามารถสร้างหรือแก้ไขรูปเส้นโพลีไลน์ด้วย Aspose.Slides for Node.js via .NET|
|Ellipse Shapes|คุณสามารถสร้างหรือแก้ไขรูปวงรีด้วย Aspose.Slides for Node.js via .NET|
