## **ภาพรวม**

Aspose.Slides for Node.js via .NET เป็นแพ็กเกจ npm ชุดเดียวที่ใช้ได้ทั้งการประเมินและการใช้งานจริง หากไม่มีไลเซนส์ จะทำงานในโหมดประเมิน หลังจากที่คุณซื้อไลเซนส์หรือรับไลเซนส์ชั่วคราวฟรี 30 วัน คุณสามารถนำไปใช้ได้ด้วยโค้ดเพียงไม่กี่บรรทัด และข้อจำกัดของโหมดประเมินจะไม่ถูกใช้งานอีกต่อไป

## **ข้อจำกัดของเวอร์ชันประเมิน**

เวอร์ชันประเมินมอบฟังก์ชันการทำงานเต็มรูปแบบของผลิตภัณฑ์ โดยมีสองข้อจำกัด:

- **Watermark.** ทุกสไลด์ของพรีเซนเทชันที่คุณบันทึกจะได้รับลายน้ำการประเมิน: กล่องข้อความที่ล็อคอยู่ตรงกลางสไลด์ที่ระบุว่า “Evaluation only.” ลายน้ำเดียวกันนี้จะปรากฏบนการส่งออกเป็น PDF, XPS และ HTML รวมถึงภาพสไลด์ด้วย
- **Truncated text.** ข้อความที่โค้ดของคุณดึงกลับมาจากกรอบข้อความ ย่อหน้า หรือส่วนหนึ่ง จะถูกตัดเหลือเพียงห้าตัวอักษรแรก แล้วต่อด้วยข้อความ “… text has been truncated due to evaluation version limitation.” การส่งออกเป็น Markdown และ HTML5 จะถูกตัดในลักษณะเดียวกัน ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ

[Evaluate Aspose.Slides](/slides/th/nodejs-net/evaluate-aspose-slides/) อธิบายข้อจำกัดทั้งสองอย่างละเอียดและรวมสคริปต์ที่แสดงข้อจำกัดเหล่านั้น

## **เกี่ยวกับไลเซนส์**

ไลเซนส์เป็นไฟล์ XML แบบข้อความธรรมดาที่บรรจุรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ได้รับอนุญาต และวันหมดอายุของการสมัครใช้งาน ไฟล์นี้มีการลงลายเซ็นดิจิทัล ดังนั้นห้ามแก้ไข แม้แต่การเพิ่มบรรทัดว่างโดยบังเอิญก็จะทำให้ไฟล์ไม่ถูกต้อง

## **การนำไลเซนส์ไปใช้**

นำไลเซนส์ไปใช้ด้วยเมธอด `setLicense` ของคลาส `License`. เรียกใช้เมธอดนี้หนึ่งครั้งต่อกระบวนการ ก่อนที่คุณจะสร้างอ็อบเจ็กต์ `Presentation` ใดๆ การเรียกใช้ซ้ำจะไม่ก่อให้เกิดอันตราย แต่จะทำงานซ้ำที่ทำไปแล้ว

สคริปต์ต่อไปนี้นำไลเซนส์จากไฟล์ชื่อ `Aspose.Slides.lic`. เปลี่ยนชื่อเป็นชื่อหรือพาธเต็มของไฟล์ไลเซนส์ของคุณ; ไฟล์สามารถตั้งชื่ออะไรก็ได้

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { License } = asposeSlides;

const license = new License();
try {
    license.setLicense("Aspose.Slides.lic");
    console.log("License applied.");
} catch (error) {
    console.log("License not applied:", error.message);
}
```

ชื่อไฟล์หรือพาธสัมพันธ์จะถูกตีความตามโฟลเดอร์ปัจจุบันซึ่งเป็นโฟลเดอร์ที่คุณเรียก `node`. เก็บไฟล์ไลเซนส์ไว้ในโฟลเดอร์โครงการของคุณและรันสคริปต์จากที่นั้น หรือส่งพาธเต็ม

หากไม่พบไฟล์หรือไฟล์ไม่เป็นไลเซนส์ที่ถูกต้อง `setLicense` จะโยนข้อผิดพลาดและ Aspose.Slides จะอยู่ในโหมดประเมิน สคริปต์จะจับข้อผิดพลาดและพิมพ์ข้อความของมัน สำหรับกรณีไฟล์หาย ข้อความจะเริ่มด้วย `License "Aspose.Slides.lic" doesn't exist or access is restricted.` และแสดงรายการทุกตำแหน่งที่ได้ทำการค้นหา

ในแพ็กเกจนี้ไลเซนส์จะถูกนำไปใช้จากไฟล์เท่านั้น `License` ไม่รับสตรีมและแพ็กเกจไม่เปิดเผยการออกใบอนุญาตแบบตามการใช้งาน สำหรับคลาสที่แพ็กเกจหุ้มอยู่ โปรดดูที่ [License](https://reference.aspose.com/slides/net/aspose.slides/license/) ในเอกสารอ้างอิง API ของ Aspose.Slides for .NET
