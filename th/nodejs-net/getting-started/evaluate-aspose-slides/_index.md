## **ภาพรวม**

เวอร์ชันการประเมินของ Aspose.Slides สำหรับ Node.js ผ่าน .NET เป็นแพคเกจ npm เดียวกับเวอร์ชันที่มีลิขสิทธิ์. หากไม่มีลิขสิทธิ์ จะทำงานในโหมดการประเมิน: ทุกฟีเจอร์ทำงานได้, แต่การนำเสนอที่บันทึกและการส่งออกส่วนใหญ่จะมีลายน้ำ, และข้อความที่โค้ดของคุณอ่านกลับจะถูกตัดสั้น. บทความนี้อธิบายข้อจำกัดทั้งสองและแสดงวิธีการลบออก.

## **ข้อจำกัดของการประเมิน**

**ลายน้ำการประเมินบนทุกสไลด์.** เมื่อคุณบันทึกการนำเสนอโดยไม่มีลิขสิทธิ์, Aspose.Slides จะเพิ่มกล่องข้อความที่กลางของทุกสไลด์ของไฟล์ที่บันทึก. กล่องข้อความนี้ถูกล็อกและมีข้อความว่า "Evaluation only." ตามด้วยบรรทัดผลิตภัณฑ์และบรรทัดลิขสิทธิ์. ลายน้ำจะถูกบันทึกในไฟล์ที่บันทึก, ไม่ได้อยู่ในหน่วยความจำของการนำเสนอ, และการเปิดการนำเสนอจะไม่เพิ่มลายน้ำใหม่. อย่างไรก็ตามไฟล์ที่บันทึกในโหมดการประเมินแล้วมีอยู่แล้วจึงมีกล่องข้อความ, ดังนั้นการเปิดและบันทึกใหม่จะเพิ่มลายน้ำที่สองในแต่ละสไลด์.

ลายน้ำเดียวกันจะถูกวาดบนผลลัพธ์เมื่อคุณส่งออกเป็น PDF, XPS หรือ HTML, หรือเรนเดอร์สไลด์เป็นภาพ. หากคุณเรนเดอร์การนำเสนอที่บันทึกแล้วในโหมดการประเมิน, ภาพจะแสดงลายน้ำที่บันทึกและลายน้ำที่เรนเดอร์พร้อมกัน.

**ข้อความที่ถูกตัดสั้นเมื่อโค้ดของคุณอ่านมัน.** ข้อความที่โค้ดของคุณอ่านผ่านคุณสมบัติ `text` ของเฟรมข้อความ, ย่อหน้า หรือส่วนย่อยจะถูกตัดเหลือห้าตัวอักษรแรก, ตามด้วยข้อความ "... text has been truncated due to evaluation version limitation." ข้อความที่มีห้าตัวอักษรหรือน้อยกว่าจะถูกคืนเต็ม. สิ่งนี้ใช้กับทุกสไลด์, รวมถึงข้อความที่โค้ดของคุณเพิ่งกำหนด. การส่งออกเป็น Markdown และ HTML5 ก็ถูกตัดสั้นในลักษณะเดียวกัน.

ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็ม: ไฟล์ PPTX, หน้า PDF และภาพสไลด์จะมีข้อความครบถ้วน.

## **ดูข้อจำกัดในสคริปต์**

สคริปต์ต่อไปนี้แสดงข้อจำกัดทั้งสอง. สมมติว่าคุณได้ติดตั้งแพคเกจตามที่อธิบายใน [การติดตั้ง](/slides/th/nodejs-net/installation/) และคุณเรียกใช้งานจากโฟลเดอร์โปรเจกต์. สคริปต์จะเพิ่มสี่เหลี่ยมผืนผ้าพร้อมประโยคหนึ่งลงในสไลด์แรก, อ่านประโยคกลับ, บันทึกการนำเสนอเป็น `evaluation.pptx`, แล้วเปิดไฟล์ใหม่เพื่อจำนวนรูปร่างบนสไลด์.

```javascript
const asposeSlides = require("aspose.slides.via.net");
const { Presentation, ShapeType, SaveFormat } = asposeSlides;

const presentation = new Presentation();
try {
    const slide = presentation.slides.get(0);
    const rectangle = slide.shapes.addAutoShape(ShapeType.Rectangle, 50, 50, 500, 100);
    rectangle.textFrame.text = "Quarterly results are ready for review.";

    // หากไม่มีลิขสิทธิ์ จะส่งคืนเฉพาะห้าตัวอักษรแรกเท่านั้น.
    console.log("Text read back:", rectangle.textFrame.text);

    // การบันทึกจะเพิ่มลายน้ำการประเมินไปยังสไลด์ทุกอันของไฟล์.
    presentation.save("evaluation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}

const savedPresentation = new Presentation("evaluation.pptx");
try {
    // สไลด์นี้ตอนนี้มีสี่เหลี่ยมผืนผ้าและกล่องข้อความลายน้ำ.
    console.log("Shapes on the saved slide:", savedPresentation.slides.get(0).shapes.count);
} finally {
    savedPresentation.dispose();
}
```

โดยไม่มีลิขสิทธิ์, สคริปต์จะพิมพ์:

```text
Text read back: Quart... text has been truncated due to evaluation version limitation.
Shapes on the saved slide: 2
```

รูปร่างที่สองคือกล่องข้อความลายน้ำ. เปิด `evaluation.pptx` เพื่อดูประโยคเต็มในสี่เหลี่ยมผืนผ้าและลายน้ำกลางสไลด์.

## **FAQ**

**โหมดการประเมินจำกัดจำนวนสไลด์หรือไม่?**  
ไม่. การนำเสนอทั้งหมดจะถูกสร้าง, เปิดและบันทึกพร้อมสไลด์ทั้งหมด. ลายน้ำและการตัดข้อความจะใช้กับทุกสไลด์เท่าเทียมกัน.

**ทำไมภาพสไลด์ที่ส่งออกแสดงลายน้ำสองครั้ง?**  
การนำเสนอถูกบันทึกในโหมดการประเมินก่อนที่คุณจะเรนเดอร์, ดังนั้นไฟล์จึงมีอยู่แล้วกล่องข้อความลายน้ำ, และการเรนเดอร์โดยไม่มีลิขสิทธิ์จะวาดลายน้ำอีกอันหนึ่งบนมัน.

**ฉันสามารถตรวจสอบว่โค้ดของฉันสร้างข้อความที่ถูกต้องในโหมดการประเมินได้หรือไม่?**  
ได้. เปิดไฟล์ที่บันทึกหรือ PDF ที่ส่งออก: จะมีข้อความครบถ้วน. เพียงข้อความที่โค้ดของคุณอ่านกลับ, รวมถึงผลลัพธ์ Markdown หรือ HTML5, เท่านั้นที่ถูกตัดสั้น.
