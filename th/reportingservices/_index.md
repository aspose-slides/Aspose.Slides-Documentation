**ยินดีต้อนรับสู่ Aspose.Slides สำหรับ Reporting Services**

Aspose.Slides for Reporting Services เป็นโซลูชันเดียวในตลาดที่ทำให้สามารถสร้างรายงาน PPT และ PPS จริงใน Microsoft SQL Server 2005, 2008, 2012, 2016 และ 2017 Reporting Services (แบบ 32-bit และ 64-bit) ได้ ทั้งคุณลักษณะของรายงาน RDL รวมถึงตาราง, แมทริกซ์, แผนภูมิและรูปภาพ จะถูกแปลงด้วยความแม่นยำสูงสุดเป็นงานนำเสนอ Microsoft PowerPoint
