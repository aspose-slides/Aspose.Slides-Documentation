Aspose.Slides for Reporting Services เป็นส่วนขยายการแสดงผลสำหรับ Microsoft SQL Server Reporting Services และ Power BI Report Server ที่เพิ่มรูปแบบการนำเสนอในรายการส่งออกของรายงานแบบแบ่งหน้า (RDL) โดยไม่ต้องใช้ Microsoft PowerPoint บนเซิร์ฟเวอร์

มันส่งออกรายงานเป็นการนำเสนอและสไลด์โชว์ในรูปแบบ PPT, PPTX, PPS และ PPSX, รวมถึง ODP และ XPS

## **การส่งออกครั้งแรกของคุณ**

ไม่มีโค้ดที่ต้องเขียน: คุณเพียงแค่ติดตั้งส่วนขยายบนเซิร์ฟเวอร์รายงาน และรูปแบบของมันจะปรากฏในรายการส่งออกของทุกรายงานแบบแบ่งหน้าบนเซิร์ฟเวอร์นั้น

1. ตรวจสอบว่าเซิร์ฟเวอร์รายงานตรงตาม [ความต้องการระบบ](/slides/th/reportingservices/system-requirements/), รวมถึง .NET Framework 3.5.
2. จาก [หน้าโหลด](https://releases.aspose.com/slides/reportingservices/), ดาวน์โหลดตัวติดตั้ง MSI, *Aspose.Slides for Reporting Services*. หากต้องการติดตั้งด้วยตนเอง ดาวน์โหลดแพคเกจ ZIP, *Aspose.Slides for Reporting Services (DLLs Only)*.
3. ติดตั้งส่วนขยายบนเซิร์ฟเวอร์รายงาน: รัน MSI ด้วยสิทธิผู้ดูแลตามที่อธิบายใน [ติดตั้งด้วยตัวติดตั้ง MSI](/slides/th/reportingservices/install-with-msi-installer/), หรือทำตาม [ติดตั้งด้วยตนเอง](/slides/th/reportingservices/install-manually/) สำหรับแพคเกจ ZIP.
4. ในเบราว์เซอร์, เปิดพอร์ทัลเว็บของเซิร์ฟเวอร์รายงาน (Report Manager บน SQL Server 2014 หรือก่อนหน้า) โดยค่าเริ่มต้นที่อยู่คือ `https://<ComputerName>/reports`.
5. เปิดรายงานแบบแบ่งหน้า บนแถบเครื่องมือของรายงาน, เปิดรายการ **ส่งออก** แล้วเลือก **PPTX - PowerPoint 2007 Presentation via Aspose.Slides**. หากแถบเครื่องมือมีปุ่ม **ส่งออก** แยกต่างหาก เช่นเดียวกับ Report Manager ให้เลือกปุ่มนั้น.
6. เปิดหรือบันทึกไฟล์ PPTX ที่เบราว์เซอร์ดาวน์โหลด.

หากไม่มีลิขสิทธิ์ การนำเสนอที่ส่งออกจะมีลายน้ำการประเมิน — ดูที่ [การจัดลิขสิทธิ์](/slides/th/reportingservices/license-aspose-slides-for-reporting-services/). สำหรับรูปแบบอื่น ๆ ในรายการส่งออก, ดูที่ [รูปแบบไฟล์ที่สนับสนุน](/slides/th/reportingservices/supported-file-formats/).
