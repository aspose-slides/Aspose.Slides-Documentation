## **บทนำ**

ใน PowerPoint 2019, Microsoft ได้แนะนำการตั้งค่า **Always Open Read-Only** เป็นหนึ่งในตัวเลือกที่ผู้ใช้สามารถใช้เพื่อปกป้องงานนำเสนอของตน คุณอาจต้องการใช้การตั้งค่า Read-Only นี้เพื่อปกป้องงานนำเสนอเมื่อ

- คุณต้องการป้องกันการแก้ไขโดยบังเอิญและเก็บเนื้อหาของงานนำเสนอให้ปลอดภัย
- คุณต้องการแจ้งให้ผู้คนทราบว่าผลงานนำเสนอที่คุณให้เป็นเวอร์ชันสุดท้าย

หลังจากคุณเลือกตัวเลือก **Always Open Read-Only** สำหรับงานนำเสนอ เมื่อผู้ใช้เปิดงานนำเสนอ พวกเขาจะเห็นคำแนะนำ **Read-Only** และอาจเห็นข้อความในรูปแบบนี้: *เพื่อป้องกันการเปลี่ยนแปลงโดยบังเอิญ ผู้เขียนได้ตั้งค่าไฟล์นี้ให้เปิดแบบอ่านอย่างเดียว.*

คำแนะนำ Read-Only เป็นการรบกวนที่เรียบง่ายแต่มีประสิทธิภาพ ซึ่งทำให้ผู้ใช้ไม่ต้องการแก้ไข เพราะผู้ใช้ต้องทำขั้นตอนเพื่อเอาออกก่อนจึงจะสามารถแก้ไขงานนำเสนอได้ หากคุณไม่ต้องการให้ผู้ใช้ทำการเปลี่ยนแปลงงานนำเสนอและต้องการบอกพวกเขาอย่างสุภาพ คำแนะนำ Read-Only อาจเป็นตัวเลือกที่ดีสำหรับคุณ.

> หากงานนำเสนอที่มีการป้องกัน **Read-Only** ถูกเปิดใน Microsoft PowerPoint รุ่นเก่า—ที่ไม่รองรับฟังก์ชันที่เพิ่งแนะนำ—คำแนะนำ **Read-Only** จะถูกละเลย (งานนำเสนอจะเปิดตามปกติ).

## **ใช้โหมด Read-Only**

Aspose.Slides for Android via Java ช่วยให้คุณตั้งค่าการนำเสนอเป็น **Read-Only** ซึ่งหมายความว่าผู้ใช้ (หลังจากเปิดการนำเสนอ) จะเห็นคำแนะนำ **Read-Only** ตัวอย่างโค้ดนี้แสดงวิธีตั้งค่าการนำเสนอเป็น **Read-Only** ใน Java โดยใช้ Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 
**หมายเหตุ**: การแนะนำ **Read-Only** มีวัตถุประสงค์เพื่อไม่ให้ผู้ใช้แก้ไขหรือหยุดการเปลี่ยนแปลงโดยบังเอิญใน PowerPoint หากบุคคลที่มีความตั้งใจ—ที่รู้ว่ากำลังทำอะไร—ตัดสินใจแก้ไขงานนำเสนอของคุณ พวกเขาสามารถลบการตั้งค่า Read-Only ได้ง่าย หากคุณต้องการป้องกันการแก้ไขโดยไม่ได้รับอนุญาตอย่างจริงจัง คุณควรใช้ [การป้องกันที่เข้มงวดมากขึ้นซึ่งรวมถึงการเข้ารหัสและรหัสผ่าน](https://docs.aspose.com/slides/th/androidjava/password-protected-presentation/).
{{% /alert %}} 

## **คำถามที่พบบ่อย**

### 'Read-Only recommended' แตกต่างจากการป้องกันด้วยรหัสผ่านเต็มอย่างไร?

'Read-Only recommended' จะแสดงเพียงคำแนะนำให้เปิดไฟล์ในโหมดอ่านอย่างเดียวและง่ายต่อการข้ามผ่าน [การป้องกันด้วยรหัสผ่าน](/slides/th/androidjava/password-protected-presentation/) จริงๆ แล้วจำกัดการเปิดหรือแก้ไขและเหมาะสมเมื่อคุณต้องการการควบคุมความปลอดภัยที่แท้จริง.

### สามารถรวม 'Read-Only recommended' กับลายน้ำเพื่อป้องกันการแก้ไขเพิ่มเติมได้หรือไม่?

ได้. คำแนะนำนี้สามารถจับคู่กับ [ลายน้ำ](/slides/th/androidjava/watermark/) เป็นการรบกวนด้วยภาพ; ทั้งสองเป็นกลไกที่แยกกันและทำงานร่วมกันได้ดี.

### แมโครหรือเครื่องมือภายนอกยังสามารถแก้ไขไฟล์ได้หรือไม่เมื่อเปิดใช้งานคำแนะนำนี้?

ได้. คำแนะนำนี้ไม่ได้บล็อกการเปลี่ยนแปลงโดยโปรแกรม เพื่อป้องกันการแก้ไขอัตโนมัติ ใช้ [รหัสผ่านและการเข้ารหัส](/slides/th/androidjava/password-protected-presentation/).

### 'Read-Only recommended' มีความเกี่ยวข้องกับเมธอด 'isEncrypted' และ 'isWriteProtected' อย่างไร?

พวกเขาเป็นสัญญาณที่แตกต่างกัน 'Read-Only recommended' เป็นการแจ้งเตือนแบบนุ่มนวลและเป็นออปชัน; [isWriteProtected](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/protectionmanager/#isWriteProtected--) และ [isEncrypted](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/protectionmanager/#isEncrypted--) บ่งบอกถึงการจำกัดการเขียนหรือการอ่านจริงที่ขึ้นอยู่กับรหัสผ่านหรือการเข้ารหัส.
