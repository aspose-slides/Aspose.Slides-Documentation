## **ภาพรวม**

เมื่อการนำเสนอถูกโหลด, เรนเดอร์, หรือแปลงเป็นรูปแบบอื่น, Aspose.Slides จะตรวจสอบว่าฟอนต์ที่ใช้ในการนำเสนอมีอยู่ในระบบปฏิบัติการหรือไม่ หากฟอนต์ที่ต้องการหายไป, Aspose.Slides จะเลือกฟอนต์ทดแทนที่ใกล้เคียงที่สุดกับฟอนต์ที่ PowerPoint จะใช้

Aspose.Slides จะค้นหาฟอนต์ที่เลือกในระบบปฏิบัติการก่อน หากพบฟอนต์นั้นจะใช้มัน หากไม่พบจะใช้ฟอนต์ทดแทนที่เหมาะสม เมื่อกฎการแทนที่ฟอนต์ถูกกำหนดผ่าน `FontSubstRule` กฎเหล่านั้นก็จะถูกพิจารณาด้วย

คุณยังสามารถเพิ่มฟอนต์ในเวลารันของแอปพลิเคชัน, ใช้ฟอนต์ฝังจากการนำเสนอ, หรือโหลดฟอนต์ภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF

## **การเลือกฟอนต์**

กฎบางอย่างจะนำไปใช้กับฟอนต์ในการนำเสนอเมื่อการนำเสนอถูกโหลด, เรนเดอร์, หรือแปลงเป็นรูปแบบอื่น ตัวอย่างเช่น เมื่อคุณพยายามแปลงการนำเสนอ (สไลด์ของมัน) เป็นภาพ, ฟอนต์ของการนำเสนอจะถูกตรวจสอบเพื่อยืนยันว่าฟอนต์ที่เลือกมีอยู่ในระบบปฏิบัติการหรือไม่ หากพบว่าฟอนต์หายไปจะถูกแทนที่ — ดูที่ [**การแทนที่ฟอนต์**](https://docs.aspose.com/slides/th/androidjava/font-replacement/) และ [**การทดแทนฟอนต์**](https://docs.aspose.com/slides/th/androidjava/font-substitution/)

นี่คือกระบวนการที่ Aspose.Slides ปฏิบัติตามเมื่อจัดการกับฟอนต์:

1. Aspose.Slides ค้นหาฟอนต์ในระบบปฏิบัติการเพื่อหารหัสฟอนต์ที่ตรงกับฟอนต์ที่เลือกในการนำเสนอ.  
2. หากพบฟอนต์ที่เลือก, Aspose.Slides จะใช้มัน มิฉะนั้น Aspose.Slides จะใช้ฟอนต์ทดแทนที่ใกล้เคียงที่สุดกับฟอนต์ที่ PowerPoint จะใช้.  
3. หากมีกฎการแทนที่ฟอนต์ที่ตั้งค่าไว้ผ่าน [FontSubstRule](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/fontsubstrule/), กฎเหล่านั้นจะถูกนำไปใช้.

Aspose.Slides อนุญาตให้คุณเพิ่มฟอนต์ในเวลารันของแอปพลิเคชันและจากนั้นใช้ฟอนต์เหล่านั้น. ดูที่ [**ฟอนต์แบบกำหนดเอง**](https://docs.aspose.com/slides/th/androidjava/custom-font/)

เมื่อฟอนต์เพิ่มเติมถูกใส่ในการนำเสนอ, จะเรียกว่า [**ฟอนต์ฝัง**](https://docs.aspose.com/slides/th/androidjava/embedded-font/)

Aspose.Slides อนุญาตให้คุณเพิ่มฟอนต์ที่ใช้กับเอกสารผลลัพธ์ *เท่านั้น* ตัวอย่างเช่น หากการนำเสนอที่คุณต้องการแปลงเป็น PDF มีฟอนต์ที่หายจากระบบและฟอนต์ฝัง, คุณสามารถเพิ่มหรือโหลดฟอนต์ที่จำเป็นเป็น **ฟอนต์ภายนอก**

{{% alert title="Note" color="info" %}} 
เราไม่ได้จัดจำหน่ายฟอนต์ใด ๆ ทั้งแบบที่ต้องจ่ายเงินหรือแบบฟรี API ของเราช่วยให้คุณโหลดฟอนต์ภายนอกและฝังลงในเอกสาร, แต่คุณต้องทำด้วยฟอนต์ตามดุลยพินัยและความรับผิดชอบของคุณเอง.
{{% /alert %}}

## **คำถามที่พบบ่อย**

### ฉันจะตรวจสอบฟอนต์ที่ใช้จริงในการนำเสนอก่อนการแปลงได้อย่างไร?

Aspose.Slides ให้คุณตรวจสอบฟอนต์ที่ใช้ผ่าน [font manager](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/fontsmanager/), เพื่อให้คุณสามารถตัดสินใจว่าจะ [ฝัง](/slides/th/androidjava/embedded-font/), [แทนที่](/slides/th/androidjava/font-replacement/), หรือเพิ่ม [แหล่งฟอนต์ภายนอก](/slides/th/androidjava/custom-font/) หรือไม่ สิ่งนี้ช่วยป้องกันการแทนที่ฟอนต์ที่ไม่ต้องการระหว่างการเรนเดอร์และการส่งออก

### ฉันสามารถเพิ่มไดเรกทอรีฟอนต์เพิ่มเติมโดยไม่ต้องติดตั้งบนระบบปฏิบัติการได้หรือไม่?

ได้. คุณสามารถลงทะเบียน [แหล่งฟอนต์ภายนอก](/slides/th/androidjava/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำสำหรับการเรนเดอร์และการส่งออก สิ่งนี้จะลดการพึ่งพาฟอนต์ของระบบโฮสต์และทำให้การจัดวางคาดเดาได้

### ฉันจะป้องกันการเปลี่ยนไปใช้ฟอนต์ที่ไม่เหมาะสมโดยอัตโนมัติเมื่อไม่มี glyph ได้อย่างไร?

กำหนด [การแทนที่ฟอนต์](/slides/th/androidjava/font-replacement/) และ [กฎการสำรองฟอนต์](/slides/th/androidjava/fallback-font/) อย่างชัดเจนล่วงหน้า โดยการวิเคราะห์ฟอนต์ที่ใช้และตั้งค่าลำดับความสำคัญที่ควบคุมสำหรับฟอนต์ทดแทน, คุณจะทำให้การพิมพ์มีความสม่ำเสมอและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด
