## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญสำหรับการพิมพ์และการแสดงบนหน้าจอ

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (4:3 Aspect Ratio)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (16:9 Aspect Ratio)**: แนะนําใช้กับโปรเจคเตอร์และจอแสดงผลสมัยใหม่

ควรทำให้การตั้งค่าขนาดและอัตราส่วนสไลด์สอดคล้องกันทั่วทั้งงานนำเสนอ เนื่องจากขนาดและอัตราส่วนเดียวกันจะใช้กับทุกสไลด์ เพื่อผลลัพธ์ที่ดีที่สุด ควรกำหนดขนาดสไลด์ตั้งแต่ขั้นตอนแรกของการสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหา

{{% alert color="primary" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3.
{{% /alert %}}

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

โค้ดตัวอย่างนี้จะแสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย Java โดยใช้ Aspose.Slides:

```java
Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **ระบุขนาดสไลด์กำหนดเองในงานนำเสนอ**

หากคุณพบว่าขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะสมกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่เฉพาะเจาะหรือต่างจากมาตรฐาน ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนเค้าโครงหน้ากระดาษกำหนดเอง หรือหากคุณตั้งใจแสดงงานนำเสนอบนหน้าจอประเภทพิเศษ คุณจะได้ประโยชน์จากการตั้งค่าขนาดสไลด์กำหนดเองสำหรับงานนำเสนอ

โค้ดตัวอย่างนี้จะแสดงวิธีการใช้ Aspose.Slides สำหรับ Android ผ่าน Java เพื่อระบุขนาดสไลด์กำหนดเองสำหรับงานนำเสนอใน Java:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์สำหรับงานนำเสนอ เนื้อหาบนสไลด์ (เช่น รูปภาพหรือวัตถุ) อาจเกิดการบิดเบี้ยว โดยค่าเริ่มต้น วัตถุจะถูกปรับขนาดโดยอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตาม เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถระบุการตั้งค่าที่กำหนดว่า Aspose.Slides จะจัดการกับเนื้อหาบนสไลด์อย่างไร

ขึ้นอยู่กับสิ่งที่คุณต้องการทำหรือบรรลุ คุณสามารถใช้การตั้งค่าใดก็ได้ต่อไปนี้:

- `DoNotScale`

  หากคุณไม่ต้องการให้วัตถุบนสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `EnsureFit`

  หากคุณต้องการปรับสเกลให้ได้ขนาดสไลด์ที่เล็กลงและต้องการให้ Aspose.Slides ปรับขนาดวัตถุบนสไลด์ให้เล็กลงเพื่อให้ทั้งหมดพอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้

- `Maximize`

  หากคุณต้องการปรับสเกลให้เป็นขนาดสไลด์ที่ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุบนสไลด์ให้สอดคล้องกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้

โค้ดตัวอย่างนี้จะแสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```java
Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **คำถามที่พบบ่อย**

**ฉันสามารถกำหนดขนาดสไลด์กำหนดเองโดยใช้หน่วยอื่นนอกเหนือจากนิ้ว (เช่น จุดหรือมิลลิเมตร) ได้ไหม?**

ใช่ Aspose.Slides ใช้หน่วยจุดเป็นพื้นฐาน โดย 1 จุด เท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใดก็ได้ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้

**ขนาดสไลด์กำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับสเกลการเรนเดอร์ที่สูงขึ้นจะทำให้ใช้หน่วยความจำเพิ่มและเวลาการประมวลผลยาวนานขึ้น ควรกำหนดขนาดสไลด์ให้เหมาะสมและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งค่าแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [merge presentations](/slides/th/androidjava/merge-presentation/) เมื่อมีขนาดสไลด์ต่างกัน — ก่อนอื่นให้ปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่ง เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการเนื้อหาเดิมผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณสามารถรวมสไลด์โดยคงรูปแบบไว้ได้

**ฉันสามารถสร้างภาพย่อสำหรับรูปทรงเดี่ยวหรือพื้นที่เฉพาะของสไลด์ได้หรือไม่ และภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ใช่ Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [entire slides](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) ผลลัพธ์ภาพจะสะท้อนขนาดสไลด์และอัตราส่วนภาพในปัจจุบัน เพื่อให้กรอบและรูปทรงคงที่
