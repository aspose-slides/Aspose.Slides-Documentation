## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรเพื่อปรับขนาดสไลด์และอัตราส่วนของภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงผลบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะกับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่

ควรใช้ขนาดสไลด์และอัตราส่วนเดียวกันตลอดงานนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนเดียวกันจะใช้กับสไลด์ทั้งหมด เพื่อลดความซับซ้อนให้ตั้งค่าขนาดสไลด์ตั้งแต่เริ่มต้นการสร้างงานนำเสนอ

{{% alert color="info" title="Note" %}}
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3
{{% /alert %}}

หน้ากระดาษบันทึกและหน้าจัดทำเอกสารมีขนาดที่แตกต่างจากสไลด์ทั่วไป ดูที่ [Notes Page Size](/slides/th/androidjava/notes-size/) เพื่อเปลี่ยนขนาดและการวางแนวของหน้าเหล่านี้

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

โค้ดตัวอย่างนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย Java และ Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **กำหนดขนาดสไลด์ที่กำหนดเองในงานนำเสนอ**

หากขนาดสไลด์ที่ใช้บ่อย (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่เฉพาะเจาะจงหรือไม่ซ้ำใคร ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์เต็มขนาดจากงานนำเสนอบนรูปแบบหน้าแบบกำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางประเภท การตั้งค่าขนาดสไลด์ที่กำหนดเองจะเป็นประโยชน์

โค้ดตัวอย่างนี้แสดงวิธีการใช้ Aspose.Slides for Android ผ่าน Java เพื่อตั้งค่าขนาดสไลด์ที่กำหนดเองสำหรับงานนำเสนอใน Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากคุณเปลี่ยนขนาดสไลด์ของงานนำเสนอแล้ว เนื้อหาในสไลด์ (เช่น รูปภาพหรือวัตถุต่าง ๆ) อาจถูกบิดเบือน โดยค่าเริ่มต้นวัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตาม เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถกำหนดการตั้งค่าที่กำหนดว่าผลิตภัณฑ์ Aspose.Slides จะจัดการกับเนื้อหาในสไลด์อย่างไร

ขึ้นอยู่กับสิ่งที่คุณต้องการทำหรือบรรลุ คุณสามารถใช้การตั้งค่าใดก็ได้ต่อไปนี้:

- `DoNotScale`

  หากคุณ **ไม่ต้องการ** ให้วัตถุในสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `EnsureFit`

  หากคุณต้องการ缩小สไลด์และต้องการให้ Aspose.Slides ปรับขนาดวัตถุลงเพื่อให้อยู่ในสไลด์ทั้งหมด (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้

- `Maximize`

  หากคุณต้องการขยายสไลด์และต้องการให้ Aspose.Slides เพิ่มขนาดวัตถุให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้

โค้ดตัวอย่างนี้แสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งค่าขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?**

ได้ Aspose.Slides ใช้หน่วย “จุด” ภายใน ซึ่ง 1 จุด เท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใดก็ได้ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์

**ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ การมีขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับสเกลการเรนเดอร์ที่สูงจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและเวลาในการประมวลผลยาวนานขึ้น ควรเลือกขนาดสไลด์ที่เหมาะสมและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพเอาต์พุตที่ต้องการ

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งขนาด แล้วผสานสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [merge presentations](/slides/th/androidjava/merge-presentation/) เมื่อสไลด์มีขนาดแตกต่างกัน — ก่อนอื่นให้ปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่ง เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการเนื้อหาเดิมผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/slidesizescaletype/) หลังจากขนาดตรงกันแล้ว คุณสามารถผสานสไลด์โดยคงรูปแบบไว้ได้

**ฉันสามารถสร้างรูปย่อสำหรับรูปทรงแต่ละอันหรือพื้นที่เฉพาะของสไลด์ได้หรือไม่ และรูปย่อจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ได้ Aspose.Slides สามารถเรนเดอร์รูปย่อสำหรับ [entire slides](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) รวมถึงสำหรับ [selected shapes](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/shape/#getImage-int-float-float-) ภาพที่ได้จะแสดงขนาดสไลด์และอัตราส่วนปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่อย่างสอดคล้องกัน
