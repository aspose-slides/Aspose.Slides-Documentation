## **แปลง PPT เป็น PPTX**

Aspose.Slides สำหรับ Android ผ่าน Java ตอนนี้อำนวยความสะดวกให้ผู้พัฒนาสามารถเข้าถึงไฟล์ PPT ด้วยคลาส [Presentation](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/presentation) และแปลงเป็นรูปแบบ [PPTX](https://docs.fileformat.com/presentation/pptx/) ปัจจุบันรองรับการแปลงบางส่วนของ [PPT ](https://docs.fileformat.com/presentation/ppt/)เป็น PPTX.

Aspose.Slides สำหรับ Android ผ่าน Java ให้คลาส [Presentation](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/presentation) ที่แสดงไฟล์งานนำเสนอ **PPTX**. คลาส Presentation สามารถเข้าถึง **PPT** ผ่าน Presentation เมื่อสร้างอ็อบเจ็กต์. ตัวอย่างต่อไปนี้แสดงวิธีแปลงงานนำเสนอ PPT เป็น PPTX Presentation.

```java
import com.aspose.slides.*;

// สร้างอ็อบเจกต์ Presentation ที่แทนไฟล์ PPT
Presentation pres = new Presentation("Aspose.ppt");
try {
// บันทึกงานนำเสนอ PPT เป็นรูปแบบ PPTX
    pres.save("ConvertedAspose.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```
