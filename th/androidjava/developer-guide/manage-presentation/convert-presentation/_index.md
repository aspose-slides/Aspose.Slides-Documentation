## **ภาพรวม**

Aspose.Slides for Android via Java สามารถโหลดไฟล์นำเสนอ PowerPoint และ OpenDocument และบันทึกหรือแปลงเป็นรูปแบบอื่น ๆ มากมายได้โดยไม่ต้องใช้ Microsoft PowerPoint, OpenOffice หรือ LibreOffice คุณสามารถแปลงไฟล์ PPT เก่าเป็น PPTX สมัยใหม่ ส่งออกการนำเสนอเป็นเอกสารแบบคงที่เช่น PDF และ XPS, เผยแพร่สไลด์เป็น HTML หรือแปลงสไลด์เป็นไฟล์ภาพเพื่อใช้เป็นภาพตัวอย่าง, รูปย่อ และการจัดเก็บ

การแปลงเอกสารส่วนใหญ่ใช้กระบวนการทำงานทั่วไปเดียวกัน: โหลดไฟล์ต้นทาง, เลือกรูปแบบผลลัพธ์ที่ต้องการ, และใช้ตัวเลือกเฉพาะรูปแบบเมื่อจำเป็น สำหรับรูปแบบภาพแต่ละสไลด์จะถูกแปลงแยกกันแล้วบันทึกเป็นภาพแบบแรสเตอร์หรือเวกเตอร์ บทความเฉพาะด้านที่ลิงก์ด้านล่างให้รายละเอียดการดำเนินการสำหรับแต่ละกรณี

## **การแปลง PowerPoint และ OpenDocument**

Aspose.Slides for Android via Java รองรับการแปลงจากรูปแบบการนำเสนอที่ใช้บ่อยเช่น PPT, PPTX, PPS, PPSX, POT, POTX และ ODP API การแปลงเดียวกันใช้สำหรับไฟล์ PowerPoint และ OpenDocument, ดังนั้นกระบวนการที่บันทึกไฟล์ PPTX เป็น PDF มักสามารถใช้กับไฟล์ ODP ได้โดยเปลี่ยนเฉพาะไฟล์อินพุต

เมื่อแปลงไฟล์ ODP, จำไว้ว่าแอปพลิเคชัน PowerPoint และ OpenDocument ไม่รองรับทุกการจัดเลเยอร์และคุณลักษณะการจัดรูปแบบในลักษณะเดียวกัน หากไฟล์ ODP ถูกสร้างใน LibreOffice หรือ OpenOffice Impress, ตรวจสอบผลลัพธ์และใช้ตัวเลือกที่อธิบายใน [แปลงการนำเสนอ OpenDocument](/slides/th/androidjava/convert-openoffice-odp/) เมื่อคุณต้องการคำแนะนำเฉพาะรูปแบบ

## **การแปลง PPT เป็น PPTX**

PPT คือรูปแบบ PowerPoint แบบไบนารีเก่า, ในขณะที่ PPTX คือรูปแบบ Office Open XML สมัยใหม่ Aspose.Slides for Android via Java รองรับการแปลง PPT เป็น PPTX ด้วยความแม่นยำสูงโดยคงโครงสร้างการนำเสนอที่ซับซ้อนเช่น มาสเตอร์, เลย์เอาต์, สไลด์, ชาร์ต, รูปร่างที่กลุ่มกัน, พื้นที่จัดเก็บ, เฟรมข้อความ, เนื้อผ้า, และการเติมภาพ

สำหรับรายละเอียด, ดู [แปลง PPT เป็น PPTX](/slides/th/androidjava/convert-ppt-to-pptx/) และ [PPT กับ PPTX](/slides/th/androidjava/ppt-vs-pptx/).

## **การส่งออกแบบคงที่**

PDF, XPS, และ TIFF มีประโยชน์เมื่อผลลัพธ์ต้องดูเหมือนกันในทุกอุปกรณ์และไม่ควรแก้ไขเป็นการนำเสนอ บทความเฉพาะสำหรับ PDF, XPS, และ TIFF อธิบายวิธีควบคุมความสอดคล้อง, สไลด์ที่ซ่อน, บันทึก, คุณภาพภาพ, การบีบอัด, รูปแบบพิกเซล, และขนาดผลลัพธ์

## **การส่งออก HTML และภาพ**

การส่งออก HTML และ HTML5 มีประโยชน์สำหรับการดูในเบราว์เซอร์, การเผยแพร่เว็บ, และการแชร์แบบเบา การส่งออกภาพมีประโยชน์เมื่อแต่ละสไลด์ต้องเป็นภาพตัวอย่าง, ภาพย่อ, หรือทรัพยากรแรสเตอร์ ใช้บทความ PNG, JPG, และ SVG เพื่อคำแนะนำการเรนเดอร์เฉพาะรูปแบบ

## **คำถามที่พบบ่อย**

**ฉันต้องใช้ Microsoft PowerPoint เพื่อแปลงการนำเสนอหรือไม่?**

ไม่. Aspose.Slides for Android via Java เป็นไลบรารีแบบสแตนด์อโลนและไม่ต้องการ Microsoft PowerPoint หรือการทำงานอัตโนมัติของ Office.

**ฉันสามารถแปลงหลายการนำเสนอเป็นชุดได้หรือไม่?**

ใช่. โหลดการนำเสนอแต่ละไฟล์, บันทึกเป็นรูปแบบที่ต้องการ, และทำลายอ็อบเจ็กต์การนำเสนอหลังจากประมวลผล สำหรับการประมวลผลแบบขนาน, ใช้ตัวอย่างการนำเสนอแยกกันและปฏิบัติตามแนวทาง [หลายเธรด](/slides/th/androidjava/multithreading/).

**ฉันสามารถส่งออกเฉพาะสไลด์ที่เลือกได้หรือไม่?**

ใช่. วิธีการส่งออกหลายอย่างอนุญาตให้คุณระบุดัชนีสไลด์หรือเรนเดอร์สไลด์แต่ละอัน, ขึ้นอยู่กับรูปแบบผลลัพธ์ ดูบทความเฉพาะสำหรับรูปแบบเป้าหมาย.

**ฉันสามารถรวมสไลด์ที่ซ่อนเมื่อส่งออกเป็น PDF หรือ XPS ได้หรือไม่?**

ใช่. ใช้การตั้งค่าการส่งออกสไลด์ที่ซ่อนที่อธิบายในบทความการแปลง [PDF](/slides/th/androidjava/convert-powerpoint-to-pdf/) และ [XPS](/slides/th/androidjava/convert-powerpoint-to-xps/).

**ฉันสามารถสร้างผลลัพธ์ PDF/A ได้หรือไม่?**

ใช่. การตั้งค่าการปฏิบัติตาม PDF มีให้สำหรับการส่งออก PDF. ดู [แปลง PowerPoint เป็น PDF](/slides/th/androidjava/convert-powerpoint-to-pdf/) สำหรับรายละเอียด.

**ฟอนต์ถูกจัดการอย่างไรระหว่างการแปลง?**

Aspose.Slides สามารถใช้ฟอนต์ที่ฝัง, ฟอนต์สำรอง, และการตั้งค่าการแทนฟอนต์ ดู [ฟอนต์ที่ฝัง](/slides/th/androidjava/embedded-font/), [ฟอนต์สำรอง](/slides/th/androidjava/fallback-font/), และ [การแทนฟอนต์](/slides/th/androidjava/font-substitution/).
