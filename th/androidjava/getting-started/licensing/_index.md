## **ภาพรวม**

Aspose.Slides สามารถใช้ได้ในโหมดประเมินผลหรือด้วยลิขสิทธิ์ที่ถูกต้อง รุ่นประเมินให้ฟังก์ชันการทำงานเท่ากับรุ่นที่ได้รับลิขสิทธิ์ แต่จะเพิ่มลายน้ำการประเมินเมื่อเปิดหรือบันทึกงานนำเสนอและจำกัดการสกัดข้อความไว้ที่หนึ่งสไลด์

บทความนี้อธิบายว่าการให้ลิขสิทธิ์ทำงานอย่างไรใน Aspose.Slides และวิธีการนำลิขสิทธิ์ไปใช้ก่อนใช้ไลบรารี ลิขสิทธิ์สามารถโหลดจากไฟล์, สตรีม หรือทรัพยากรที่ฝังไว้โดยใช้คลาส `License` บทความนี้ยังแสดงวิธีการตรวจสอบว่าลิขสิทธิ์ถูกนำไปใช้ถูกต้องหรือไม่

## **การให้ลิขสิทธิ์ใน Aspose.Slides**

* รุ่นประเมินจะกลายเป็นรุ่นที่มีลิขสิทธิ์หลังจากคุณซื้อไลเซ่นสและเพิ่มบรรทัดโค้ดไม่กี่บรรทัด (เพื่อใช้ลิขสิทธิ์)
* ไฟล์ลิขสิทธิ์เป็นไฟล์ XML แบบข้อความธรรมดาที่มีรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนนักพัฒนาที่ได้รับลิขสิทธิ์ วันที่หมดอายุการสมัครสมาชิก เป็นต้น
* ไฟล์ลิขสิทธิ์ถูกลงนามดิจิทัล ดังนั้นคุณต้องไม่แก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างโดยไม่ได้ตั้งใจก็จะทำให้ไฟล์ไม่สามารถใช้งานได้
* Aspose.Slides for Android via Java มักจะค้นหาลิขสิทธิ์ในตำแหน่งต่อไปนี้:
  * เส้นทางที่ระบุอย่างชัดเจน
  * โฟลเดอร์ที่มี Aspose.Slides.jar
* เพื่อหลีกเลี่ยงข้อจำกัดของรุ่นประเมิน คุณต้องตั้งค่าลิขสิทธิ์ก่อนใช้ **Aspose.Slides** คุณต้องตั้งค่าลิขสิทธิ์เพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

## **การใช้ลิขสิทธิ์**

ลิขสิทธิ์สามารถโหลดจาก **file** หรือ **stream** ได้

{{% alert color="info" %}}

Aspose.Slides มีคลาส [License](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/license/) สำหรับการดำเนินการเกี่ยวกับลิขสิทธิ์

{{% /alert %}} 

{{% alert color="warning" %}}

ลิขสิทธิ์ใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับรุ่น 21.4 หรือใหม่กว่า เวอร์ชันก่อนหน้าใช้ระบบลิขสิทธิ์ที่แตกต่างและจะไม่รับรู้ลิขสิทธิ์เหล่านี้

{{% /alert %}}

### **ไฟล์**

วิธีที่ง่ายที่สุดในการตั้งค่าลิขสิทธิ์คือต้องวางไฟล์ลิขสิทธิ์ไว้ในโฟลเดอร์ที่มี Aspose.Slides.jar หรือไฟล์ jar ของแอปพลิเคชันของคุณ

นี้คือโค้ด Java ที่แสดงวิธีตั้งค่าไฟล์ลิขสิทธิ์:

``` java
// สร้างอินสแตนซ์ของคลาส License
com.aspose.slides.License license = new com.aspose.slides.License();

// ตั้งค่าเส้นทางไฟล์ลิขสิทธิ์
license.setLicense("Aspose.Slides.Android.via.Java.lic");
```

{{% alert color="warning" %}} 

หากคุณวางไฟล์ลิขสิทธิ์ในไดเรกทอรีอื่น เมื่อเรียกเมธอด[SetLicense](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-) ชื่อไฟล์ลิขสิทธิ์ที่ส่วนท้ายของพาธที่ระบุต้องตรงกับไฟล์ลิขสิทธิ์ของคุณ

เช่น คุณสามารถเปลี่ยนชื่อไฟล์ลิขสิทธิ์เป็น*Aspose.Slides.Android.via.Java.lic.xml* แล้วในโค้ดของคุณต้องส่งพาธไปยังไฟล์ (จบด้วย*Aspose.Slides.Android.via.Java.lic.xml*) ให้เมธอด[SetLicense](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/license/#setLicense-java.lang.String-)

{{% /alert %}}

### **สตรีม**

คุณสามารถโหลดลิขสิทธิ์จากสตรีมได้ โค้ด Java นี้แสดงวิธีใช้ลิขสิทธิ์จากสตรีม:

``` java
// สร้างอินสแตนซ์ของคลาส License
com.aspose.slides.License license = new com.aspose.slides.License();

// ตั้งค่าลิขสิทธิ์ผ่านสตรีม
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Android.via.Java.lic"));
```

## **การตรวจสอบลิขสิทธิ์**

เพื่อเช็คว่าลิขสิทธิ์ถูกตั้งค่าอย่างถูกต้องหรือไม่ คุณสามารถตรวจสอบได้ โค้ด Java นี้แสดงวิธีตรวจสอบลิขสิทธิ์:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Android.via.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **ความปลอดภัยของเธรด**

{{% alert title="Note" color="warning" %}} 

เมธอด[SetLicense](https://reference.aspose.com/slides/th/androidjava/com.aspose.slides/license/#setLicense-java.io.InputStream-) ไม่ปลอดภัยต่อการทำงานหลายเธรด หากเมธอดนี้ต้องถูกเรียกพร้อมกันจากหลายเธรด คุณอาจต้องใช้กลไกการซิงโครไนซ์ (เช่น lock) เพื่อหลีกเลี่ยงปัญหา

{{% /alert %}}

## **คำถามที่พบบ่อย**

### ฉันสามารถนำลิขสิทธิ์ไปใช้ในสภาพแวดล้อมที่ไม่มีการเชื่อมต่ออินเทอร์เน็ต (ออฟไลน์) ได้หรือไม่?

ได้ การตรวจสอบลิขสิทธิ์ทำที่เครื่องโดยใช้ไฟล์ลิขสิทธิ์; ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่ ลิขสิทธิ์เป็นแบบถาวร: คุณสามารถใช้งานเวอร์ชันที่ปล่อยก่อนวันที่สิ้นสุดการสมัครสมาชิกได้ต่อไป; แต่คุณจะไม่ได้รับสิทธิ์ใช้รุ่นใหม่กว่าหากไม่ได้ต่ออายุ
