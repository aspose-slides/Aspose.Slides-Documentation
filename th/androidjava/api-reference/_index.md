Aspose.Slides for Android via Java เป็นไลบรารีคลาสที่ช่วยให้แอปพลิเคชัน Java สำหรับ Android สามารถอ่านและเขียนเอกสารพรีเซนเทชันได้โดยไม่ต้องใช้ Microsoft PowerPoint® หรือซอฟต์แวร์อื่น ๆ. Aspose.Slides for Android via Java อนุญาตให้คุณจัดการข้อความ, รูปร่าง, ตารางและการเคลื่อนไหว; เพิ่มเสียงและวิดีโอลงในสไลด์; ดูตัวอย่างสไลด์; และส่งออกสไลด์เป็น SVG, PDF และรูปแบบอื่น ๆ อีกมากมาย.

สามารถหาอ้างอิง API ล่าสุดได้ที่ [Aspose.Slides for Android via Java API Reference](https://reference.aspose.com/slides/th/androidjava/).
