## **บทนำ**

Aspose.Slides มีเครื่องมือครบชุดเพื่อปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจ็กเตอร์และจอแสดงผลสมัยใหม่

ควรรักษาความสม่ำเสมอทั่วทั้งงานนำเสนอโดยใช้ขนาดสไลด์และอัตราส่วนเดียวกันสำหรับทุกสไลด์ เพื่อให้ได้ผลลัพธ์ที่ดีที่สุด ให้ตั้งขนาดสไลด์ตั้งแต่ต้นกระบวนการสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหาในภายหลัง

{{% alert color="info" title="Note" %}}
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วน 4:3 มาตรฐาน
{{% /alert %}}

หน้าบันทึกย่อและหน้าแจกจ่ายมีขนาดแยกต่างหากจากสไลด์ปกติ ดูที่ [Notes Page Size](/slides/th/nodejs-java/notes-size/) เพื่อเปลี่ยนขนาดและทิศทางของหน้านั้น

## **การเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

โค้ดตัวอย่างนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย JavaScript โดยใช้ Aspose.Slides:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **กำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่กำหนดเอง เช่น หากต้องการพิมพ์สไลด์เต็มขนาดบนรูปแบบหน้ากระดาษที่กำหนดเอง หรือจะแสดงงานนำเสนอบนหน้าจอประเภทพิเศษ การตั้งค่าขนาดสไลด์แบบกำหนดเองอาจเป็นประโยชน์ต่อคุณ  

โค้ดตัวอย่างนี้แสดงวิธีใช้ Aspose.Slides for Node.js ผ่าน Java เพื่อกำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอด้วย JavaScript:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **การจัดการปัญหาเมื่อเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

เมื่อคุณเปลี่ยนขนาดสไลด์ของงานนำเสนอ เนื้อหาในสไลด์ (เช่น รูปภาพหรือวัตถุต่างๆ) อาจเกิดการบิดเบี้ยว โดยค่าเริ่มต้น วัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตาม คุณสามารถระบุการตั้งค่าที่กำหนดว่าการจัดการกับเนื้อหาในสไลด์ของ Aspose.Slides จะทำอย่างไรเมื่อเปลี่ยนขนาดสไลด์  

ตามความต้องการของคุณ สามารถใช้การตั้งค่าใดก็ได้ต่อไปนี้:

- `DoNotScale`

  หากคุณ **ไม่ต้องการ** ให้วัตถุในสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `EnsureFit`

  หากคุณต้องการปรับให้สไลด์ขนาดเล็กลงและต้องการให้ Aspose.Slides ปรับขนาดวัตถุให้พอดีกับสไลด์ (เพื่อป้องกันการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้

- `Maximize`

  หากคุณต้องการปรับให้สไลด์ขนาดใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุให้สัดส่วนตรงกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้

โค้ดตัวอย่างนี้แสดงวิธีใช้การตั้งค่า `Maximize` ขณะเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```javascript
var aspose = aspose || {};
aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **FAQ**

**ฉันสามารถกำหนดขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น พอยต์หรือมิลลิเมตร) ได้หรือไม่?**

ได้ค่ะ Aspose.Slides ใช้หน่วยพอยต์ภายในซึ่ง 1 พอยต์เท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใดก็ได้ (เช่น มิลลิเมตรหรือเซนติเมตร) ไปเป็นพอยต์แล้วใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์

**ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ค่ะ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นพอยต์) คูณกับสเกลการเรนเดอร์ที่สูงจะทำให้ใช้หน่วยความจำเพิ่มขึ้นและเวลาการประมวลผลนานขึ้น ควรเลือกขนาดสไลด์ที่เหมาะสมและปรับสเกลการเรนเดอร์ตามความจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งแบบแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [merge presentations](/slides/th/nodejs-java/merge-presentation/) ได้หากสไลด์มีขนาดต่างกัน — ต้องปรับขนาดงานนำหน้าให้อยู่ในขนาดเดียวกันก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการกับเนื้อหาเดิมผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/slidesizescaletype/) หลังจากขนาดตรงกันแล้ว คุณจึงสามารถรวมสไลด์โดยคงรูปแบบเดิมไว้ได้

**ฉันสามารถสร้างรูปย่อของรูปร่างเดียวหรือส่วนที่ระบุของสไลด์ได้หรือไม่ และรูปย่อเหล่านั้นจะคำนึงถึงขนาดสไลด์ใหม่หรือไม่?**

ได้ค่ะ Aspose.Slides สามารถเรนเดอร์รูปย่อสำหรับ [entire slides](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/slide/#getImage) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/shape/#getImage) ได้ด้วย รูปภาพที่ได้จะสะท้อนขนาดและอัตราส่วนของสไลด์ในปัจจุบัน ทำให้การกรอบและเรขาคณิตคงที่ตามขนาดสไลด์ใหม่
