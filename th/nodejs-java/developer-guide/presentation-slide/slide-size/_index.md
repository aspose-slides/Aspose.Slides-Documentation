## **บทนำ**

Aspose.Slides ให้เครื่องมือครบถ้วนสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **มาตรฐาน (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า  
- **จอแนวกว้าง (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่  

ตรวจสอบให้แน่ใจว่ามีความสม่ำเสมอตลอดงานนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนภาพเดียวกันจะถูกนำไปใช้กับสไลด์ทั้งหมด เพื่อลดปัญหา ให้ตั้งค่าขนาดสไลด์ตั้งแต่ขั้นตอนเริ่มต้นของการสร้างงานนำเสนอ

{{% alert color="primary" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วน 4:3 แบบมาตรฐาน
{{% /alert %}}

## **การเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

 ตัวอย่างโค้ดนี้แสดงวิธีการเปลี่ยขนาดสไลด์ในงานนำเสนอด้วย JavaScript ผ่าน Aspose.Slides:

```javascript
var pres = new aspose.slides.Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.OnScreen16x9, aspose.slides.SlideSizeScaleType.DoNotScale);
    pres.save("pres-4x3-aspect-ratio.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **กำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากขนาดสไลด์ทั่วไป (4:3 หรือ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่กำหนดหรือเฉพาะเจาะจง ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางประเภท คุณอาจได้รับประโยชน์จากการตั้งค่าขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอของคุณ  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้ Aspose.Slides สำหรับ Node.js ผ่าน Java เพื่อกำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอด้วย JavaScript:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, aspose.slides.SlideSizeScaleType.DoNotScale);// ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **การจัดการปัญหาเมื่อเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

หลังจากที่คุณเปลี่ยนขนาดสไลด์ของงานนำเสนอแล้ว เนื้อหาในสไลด์ (เช่น รูปภาพหรืออ็อบเจกต์) อาจเบี้ยวหรือผิดรูปโดยอัตโนมัติ ตามค่าเริ่มต้นอ็อบเจกต์จะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตามเมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถระบุการตั้งค่าที่กำหนดว่าด้วย Aspose.Slides จะจัดการกับเนื้อหาในสไลด์อย่างไร  

ขึ้นอยู่กับสิ่งที่คุณต้องการทำหรือบรรลุผล คุณสามารถใช้การตั้งค่าใด ๆ ต่อไปนี้:

- `DoNotScale`

  หากคุณ **ไม่ต้องการ** ให้วัตถุในสไลด์ถูกปรับขนาด ให้ใช้การตั้งค้านี้

- `EnsureFit`

  หากคุณต้องการปรับขนาดสไลด์ให้เล็กลงและต้องการให้ Aspose.Slides ปรับขนาดวัตถุในสไลด์ให้พอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค้านี้  

- `Maximize`

  หากคุณต้องการปรับขนาดสไลด์ให้ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุในสไลด์ให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค้านี้  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```javascript
var pres = new aspose.slides.Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(aspose.slides.SlideSizeType.Ledger, aspose.slides.SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) {
        pres.dispose();
    }
}
```

## **คำถามที่พบบ่อย**

**ฉันสามารถกำหนดขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?**

ได้ค่ะ Aspose.Slides ใช้หน่วยจุดภายในโดยที่ 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตรหรือเซนติเมตร) ไปเป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้  

**ขนาดสไลด์แบบกำหนดเองขนาดใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ค่ะ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับอัตราส่วนการเรนเดอร์ที่สูง จะทำให้การใช้หน่วยความจำเพิ่มขึ้นและเวลาการประมวลผลยาวนานขึ้น ควรเลือกขนาดสไลด์ที่เหมาะสมและปรับอัตราส่วนการเรนเดอร์ตามความจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ  

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งค่า แล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [merge presentations](/slides/th/nodejs-java/merge-presentation/) ได้หากสไลด์มีขนาดแตกต่าง — ต้องปรับขนาดงานนำหน้าให้ตรงกันก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีการจัดการเนื้อหาเดิมผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/slidesizescaletype/) หลังจากขนาดสอดคล้องกันแล้ว คุณสามารถรวมสไลด์โดยคงรูปแบบไว้ได้  

**ฉันสามารถสร้างภาพย่อสำหรับรูปร่างเดี่ยวหรือบริเวณเฉพาะของสไลด์ได้หรือไม่ และภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ได้ค่ะ Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [entire slides]((https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/slide/#getImage)) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/shape/#getImage) ด้วย ภาพที่ได้จะแสดงขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงสภาพเดิมอย่างสอดคล้อง
