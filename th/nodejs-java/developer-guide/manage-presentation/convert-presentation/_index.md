## **ภาพรวม**

Aspose.Slides for Node.js ผ่าน Java สามารถโหลดงานนำเสนอ PowerPoint และ OpenDocument แล้วบันทึกหรือเรนเดอร์เป็นรูปแบบอื่น ๆ มากมายโดยไม่ต้องใช้ Microsoft PowerPoint, OpenOffice หรือ LibreOffice. คุณสามารถแปลงไฟล์ PPT แบบเก่าเป็น PPTX สมัยใหม่, ส่งออกงานนำเสนอเป็นเอกสารแบบจัดหน้าแบบคงที่เช่น PDF และ XPS, เผยแพร่สไลด์เป็น HTML, หรือเรนเดอร์สไลด์เป็นไฟล์ภาพสำหรับพรีวิว, รูปย่อ และการเก็บถาวร.

การแปลงเอกสารส่วนใหญ่ใช้กระบวนการทำงานทั่วไปเดียวกัน: โหลดไฟล์ต้นฉบับ, เลือกรูปแบบผลลัพธ์ที่ต้องการ, และกำหนดตัวเลือกเฉพาะรูปแบบเมื่อจำเป็น. สำหรับรูปแบบภาพ, แต่ละสไลด์จะถูกเรนเดอร์แยกจากกันแล้วบันทึกเป็นภาพเรสเตอร์หรือเวกเตอร์. บทความเฉพาะที่ลิงก์ด้านล่างนี้ให้รายละเอียดการทำงานสำหรับแต่ละกรณี.

## **การแปลง PowerPoint และ OpenDocument**

Aspose.Slides for Node.js ผ่าน Java รองรับการแปลงจากรูปแบบงานนำเสนอที่ใช้ทั่วไปเช่น PPT, PPTX, PPS, PPSX, POT, POTX และ ODP. API การแปลงเดียวกันถูกใช้สำหรับไฟล์ PowerPoint และ OpenDocument, ดังนั้นกระบวนการที่บันทึกไฟล์ PPTX เป็น PDF สามารถนำไปใช้กับไฟล์ ODP ได้โดยเพียงเปลี่ยนไฟล์อินพุตเท่านั้น.

เมื่อต้องแปลงไฟล์ ODP, จำไว้ว่าแอปพลิเคชัน PowerPoint และ OpenDocument ไม่สนับสนุนทุกการจัดเรียงและรูปแบบในลักษณะเดียวกันอย่างเต็มที่. หากไฟล์ ODP ถูกสร้างใน LibreOffice หรือ OpenOffice Impress, ให้ตรวจสอบผลลัพธ์และใช้ตัวเลือกที่อธิบายไว้ใน [แปลงงานนำเสนอ OpenDocument](/slides/th/nodejs-java/convert-openoffice-odp/) เมื่อคุณต้องการคำแนะนำเฉพาะรูปแบบ.

## **การแปลง PPT เป็น PPTX**

PPT คือรูปแบบ PowerPoint แบบไบนารีเก่า, ขณะที่ PPTX เป็นรูปแบบ Office Open XML สมัยใหม่. Aspose.Slides for Node.js ผ่าน Java รองรับการแปลง PPT เป็น PPTX ด้วยความแม่นยำสูง โดยคงโครงสร้างงานนำเสนอที่ซับซ้อนเช่นมาสเตอร์, เลย์เอาต์, สไลด์, แผนภูมิ, รูปร่างที่จัดกลุ่ม, พื้นที่เก็บข้อมูลชั่วคราว, เฟรมข้อความ, เนื้อผิว, และการเติมภาพ.

สำหรับรายละเอียดเพิ่มเติม, ดูที่ [แปลง PPT เป็น PPTX](/slides/th/nodejs-java/convert-ppt-to-pptx/) และ [PPT vs PPTX](/slides/th/nodejs-java/ppt-vs-pptx/).

## **การส่งออกแบบจัดหน้าแบบคงที่**

PDF, XPS, และ TIFF มีประโยชน์เมื่อผลลัพธ์ควรดูเหมือนกันในทุกอุปกรณ์และไม่ควรแก้ไขเป็นงานนำเสนอ. บทความเฉพาะของ PDF, XPS, และ TIFF อธิบายวิธีควบคุมการปฏิบัติตาม, สไลด์ที่ซ่อน, บันทึกย่อ, คุณภาพภาพ, การบีบอัด, รูปแบบพิกเซล, และขนาดผลลัพธ์.

## **การส่งออก HTML และภาพ**

การส่งออก HTML และ HTML5 มีประโยชน์สำหรับการดูในเบราว์เซอร์, การเผยแพร่เว็บ, และการแชร์ที่เบา. การส่งออกรูปภาพมีประโยชน์เมื่อแต่ละสไลด์ต้องเป็นพรีวิว, รูปย่อ, หรือทรัพยากรเรสเตอร์แยกกัน. ใช้บทความ PNG, JPG, และ SVG สำหรับคำแนะนำการเรนเดอร์เฉพาะรูปแบบ.

## **คำถามที่พบบ่อย**

**ฉันต้องการ Microsoft PowerPoint เพื่อแปลงงานนำเสนอหรือไม่?**

ไม่. Aspose.Slides for Node.js ผ่าน Java เป็นไลบรารีแบบสแตนด์อโลนและไม่ต้องการ Microsoft PowerPoint หรือการทำงานอัตโนมัติของ Office.

**ฉันสามารถแปลงหลายงานนำเสนอเป็นชุดได้หรือไม่?**

ได้. โหลดงานนำเสนอแต่ละไฟล์, บันทึกเป็นรูปแบบที่ต้องการ, แล้วทำลายอ็อบเจ็กต์งานนำเสนอหลังจากประมวลผล. สำหรับการประมวลผลแบบขนาน, ใช้ตัวอย่างงานนำเสนอแยกกันและปฏิบัติตามแนวทาง [การทำหลายเธรด](/slides/th/nodejs-java/multithreading/).

**ฉันสามารถส่งออกเฉพาะสไลด์ที่เลือกได้หรือไม่?**

ได้. วิธีการส่งออกหลายวิธีอนุญาตให้คุณส่งค่าอันดับสไลด์หรือเรนเดอร์สไลด์แต่ละหน้า, ตามรูปแบบผลลัพธ์. ดูบทความเฉพาะสำหรับรูปแบบเป้าหมาย.

**ฉันสามารถรวมสไลด์ที่ซ่อนได้เมื่อส่งออกเป็น PDF หรือ XPS หรือไม่?**

ได้. ใช้การตั้งค่าส่งออกสไลด์ที่ซ่อนตามที่อธิบายในบทความการแปลง [PDF](/slides/th/nodejs-java/convert-powerpoint-to-pdf/) และ [XPS](/slides/th/nodejs-java/convert-powerpoint-to-xps/).

**ฉันสามารถสร้างผลลัพธ์ PDF/A ได้หรือไม่?**

ได้. มีการตั้งค่าการปฏิบัติตาม PDF สำหรับการส่งออก PDF. ดูที่ [แปลง PowerPoint เป็น PDF](/slides/th/nodejs-java/convert-powerpoint-to-pdf/) สำหรับรายละเอียด.

**แบบอักษรจัดการอย่างไรในระหว่างการแปลง?**

Aspose.Slides สามารถใช้แบบอักษรที่ฝัง, การสำรองแบบอักษร, และการตั้งค่าการแทนที่แบบอักษร. ดูที่ [Embedded Font](/slides/th/nodejs-java/embedded-font/), [Fallback Font](/slides/th/nodejs-java/fallback-font/), และ [Font Substitution](/slides/th/nodejs-java/font-substitution/).
