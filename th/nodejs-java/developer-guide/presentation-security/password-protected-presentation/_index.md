## **บทนำ**

เมื่อคุณตั้งรหัสผ่านเพื่อปกป้องการนำเสนอ หมายความว่าคุณกำหนดรหัสผ่านซึ่งบังคับใช้ข้อจำกัดบางอย่างบนการนำเสนอ การลบข้อจำกัดเหล่านี้จำเป็นต้องใส่รหัสผ่าน การนำเสนอที่มีการปกป้องด้วยรหัสผ่านถือเป็นการนำเสนอที่ล็อกไว้

โดยทั่วไปคุณสามารถตั้งรหัสผ่านเพื่อบังคับใช้ข้อจำกัดเหล่านี้บนการนำเสนอ:

- **การแก้ไข**

  หากคุณต้องการให้ผู้ใช้บางคนเท่านั้นที่สามารถแก้ไขการนำเสนอของคุณได้ คุณสามารถตั้งข้อจำกัดการแก้ไขได้ ข้อจำกัดนี้จะป้องกันไม่ให้ผู้คนแก้ไข เปลี่ยนแปลง หรือคัดลอกสิ่งต่าง ๆ ในการนำเสนอของคุณ (ยกเว้นเมื่อพวกเขาใส่รหัสผ่าน)

  อย่างไรก็ตามในกรณีนี้ แม้ไม่มีรหัสผ่าน ผู้ใช้ก็ยังสามารถเข้าถึงเอกสารของคุณและเปิดได้ ในโหมดอ่านอย่างเดียว ผู้ใช้สามารถดูเนื้อหา หรือสิ่งต่าง ๆ — ลิงก์, แอนิเมชัน, เอฟเฟกต์ และอื่น ๆ — ภายในการนำเสนอของคุณ แต่ไม่สามารถคัดลอกรายการหรือบันทึกการนำเสนอได้

- **การเปิด**

  หากคุณต้องการให้ผู้ใช้บางคนเท่านั้นที่สามารถเปิดการนำเสนอของคุณได้ คุณสามารถตั้งข้อจำกัดการเปิดได้ ข้อจำกัดนี้จะป้องกันไม่ให้ผู้คนดูเนื้อหาของการนำเสนอของคุณ (ยกเว้นเมื่อพวกเขาใส่รหัสผ่าน)

  โดยเทคนิคแล้ว ข้อจำกัดการเปิดยังป้องกันผู้ใช้จากการแก้ไขการนำเสนอของคุณด้วย: เมื่อผู้คนไม่สามารถเปิดการนำเสนอได้ พวกเขาจึงไม่สามารถทำการแก้ไขหรือเปลี่ยนแปลงใด ๆ ได้  

  **หมายเหตุ** เมื่อคุณตั้งรหัสผ่านเพื่อป้องกันการเปิด การไฟล์การนำเสนอจะถูกเข้ารหัส

## **การป้องกันรหัสผ่านสำหรับการนำเสนอใน Aspose.Slides**
**รูปแบบที่รองรับ**

Aspose.Slides รองรับการป้องกันรหัสผ่าน, การเข้ารหัส, และการดำเนินการคล้ายคลึงกันสำหรับการนำเสนอในรูปแบบต่อไปนี้:

- PPTX และ PPT - Microsoft PowerPoint Presentation
- ODP - OpenDocument Presentation
- OTP - OpenDocument Presentation Template

**การดำเนินการที่รองรับ**

Aspose.Slides ให้คุณใช้การป้องกันรหัสผ่านบนการนำเสนอเพื่อป้องกันการแก้ไขโดยวิธีต่อไปนี้:

- การเข้ารหัสการนำเสนอ
- การตั้งค่าการป้องกันการเขียนบนการนำเสนอ

**การดำเนินการอื่น ๆ**

Aspose.Slides ให้คุณทำงานอื่น ๆ ที่เกี่ยวข้องกับการป้องกันรหัสผ่านและการเข้ารหัสได้ดังนี้:

- การถอดรหัสการนำเสนอ; การเปิดการนำเสนอที่เข้ารหัส
- การลบการเข้ารหัส; การปิดการป้องกันรหัสผ่าน
- การลบการป้องกันการเขียนจากการนำเสนอ
- การดึงคุณสมบัติของการนำเสนอที่เข้ารหัส
- การตรวจสอบว่าการนำเสนอถูกเข้ารหัสหรือไม่
- การตรวจสอบว่าการนำเสนอมีการป้องกันรหัสผ่านหรือไม่

## **การเข้ารหัสการนำเสนอ**

คุณสามารถเข้ารหัสการนำเสนอโดยตั้งรหัสผ่าน จากนั้นผู้ใช้ต้องใส่รหัสผ่านจึงจะสามารถแก้ไขการนำเสนอที่ล็อกไว้ได้

เพื่อเข้ารหัสหรือป้องกันการนำเสนอด้วยรหัสผ่าน คุณต้องใช้เมธอด `encrypt` (จาก [ProtectionManager](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager)) เพื่อกำหนดรหัสผ่านให้กับการนำเสนอ คุณส่งรหัสผ่านให้เมธอด `encrypt` แล้วใช้เมธอด `save` เพื่อบันทึกการนำเสนอที่เพิ่งเข้ารหัส

โค้ดตัวอย่างนี้แสดงวิธีการเข้ารหัสการนำเสนอ:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().encrypt("123123");
    presentation.save("encrypted-pres.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **การตั้งค่าการป้องกันการเขียนบนการนำเสนอ**

คุณสามารถเพิ่มเครื่องหมาย “ห้ามแก้ไข” ลงในการนำเสนอ วิธีนี้ทำให้คุณบอกผู้ใช้ว่าคุณไม่ต้องการให้พวกเขาเปลี่ยนแปลงการนำเสนอ

**หมายเหตุ** กระบวนการป้องกันการเขียนไม่ได้เข้ารหัสการนำเสนอ ดังนั้นผู้ใช้—หากต้องการจริง ๆ—สามารถแก้ไขการนำเสนอได้ แต่เมื่อบันทึกการเปลี่ยนแปลง จะต้องสร้างการนำเสนอที่มีชื่อแตกต่างกัน

เพื่อกำหนดการป้องกันการเขียน คุณต้องใช้เมธอด [setWriteProtection](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager#setWriteProtection-java.lang.String-) นี้ ตัวอย่างโค้ดแสดงวิธีการตั้งค่าการป้องกันการเขียนบนการนำเสนอ:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().setWriteProtection("123123");
    presentation.save("write-protected-pres.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **การถอดรหัสการนำเสนอ; การเปิดการนำเสนอที่เข้ารหัส**

Aspose.Slides ให้คุณโหลดไฟล์ที่เข้ารหัสโดยส่งรหัสผ่านเข้าไป เพื่อถอดรหัสการนำเสนอ คุณต้องเรียกเมธอด [removeEncryption](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager#removeEncryption--) โดยไม่มีพารามิเตอร์ แล้วคุณจะต้องใส่รหัสผ่านที่ถูกต้องเพื่อโหลดการนำเสนอ

โค้ดตัวอย่างนี้แสดงวิธีการถอดรหัสการนำเสนอ:

```javascript
var loadOptions = new aspose.slides.LoadOptions();
loadOptions.setPassword("123123");
var presentation = new aspose.slides.Presentation("pres.pptx", loadOptions);
try {
    // ทำงานกับการนำเสนอที่ถอดรหัสแล้ว
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **การลบการเข้ารหัส; การปิดการป้องกันรหัสผ่าน**

คุณสามารถลบการเข้ารหัสหรือการป้องกันรหัสผ่านบนการนำเสนอ ทำให้ผู้ใช้สามารถเข้าถึงหรือแก้ไขการนำเสนอได้โดยไม่มีข้อจำกัด

เพื่อเอาการเข้ารหัสหรือการป้องกันรหัสผ่านออก คุณต้องเรียกเมธอด [removeEncryption](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager#removeEncryption--) นี้ ตัวอย่างโค้ดแสดงวิธีการลบการเข้ารหัสจากการนำเสนอ:

```javascript
var loadOptions = new aspose.slides.LoadOptions();
loadOptions.setPassword("123123");
var presentation = new aspose.slides.Presentation("pres.pptx", loadOptions);
try {
    presentation.getProtectionManager().removeEncryption();
    presentation.save("encryption-removed.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **การลบการป้องกันการเขียนจากการนำเสนอ**

คุณสามารถใช้ Aspose.Slides เพื่อลบการป้องกันการเขียนที่ใช้บนไฟล์การนำเสนอ วิธีนี้ทำให้ผู้ใช้สามารถแก้ไขได้ตามต้องการโดยไม่มีคำเตือนใด ๆ

คุณสามารถลบการป้องกันการเขียนจากการนำเสนอโดยใช้เมธอด [removeWriteProtection](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager#removeWriteProtection--) นี้ ตัวอย่างโค้ดแสดงวิธีลบการป้องกันการเขียนจากการนำเสนอ:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().removeWriteProtection();
    presentation.save("write-protection-removed.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **ดึงคุณสมบัติของการนำเสนอที่เข้ารหัส**

โดยทั่วไปผู้ใช้มักประสบปัญหาในการดึงคุณสมบัติเบื้องต้นของการนำเสนอที่เข้ารหัสหรือถูกป้องกันด้วยรหัสผ่าน อย่างไรก็ตาม Aspose.Slides มีกลไกที่ให้คุณปกป้องการนำเสนอด้วยรหัสผ่านพร้อมยังคงให้ผู้ใช้เข้าถึงคุณสมบัติได้

**หมายเหตุ:** ตามค่าเริ่มต้น เมื่อ Aspose.Slides เข้ารหัสการนำเสนอ คุณสมบัติเบื้องต้นของเอกสารการนำเสนอจะถูกป้องกันด้วยรหัสผ่านด้วย หากคุณต้องการให้คุณสมบัติของเอกสารสามารถเข้าถึงได้แม้หลังจากการเข้ารหัส Aspose.Slides อนุญาตให้ทำเช่นนั้นได้

หากคุณต้องการให้ผู้ใช้ยังคงเข้าถึงคุณสมบัติของการนำเสนอที่เข้ารหัสได้ ให้ส่งค่า `false` ไปยัง `setEncryptDocumentProperties` บน [ProtectionManager](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/protectionmanager/) ตัวอย่างโค้ดนี้แสดงวิธีการเข้ารหัสการนำเสนอพร้อมยังคงให้ผู้ใช้เข้าถึงคุณสมบัติเบื้องต้นของเอกสาร:

```javascript
const presentation = new aspose.slides.Presentation("pres.pptx");
try {
    presentation.getProtectionManager().setEncryptDocumentProperties(false);
    presentation.getProtectionManager().encrypt("123123");
    presentation.save("encrypted-pres.pptx", aspose.slides.SaveFormat.Pptx);
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **โหลดเฉพาะคุณสมบัติเอกสารจากการนำเสนอที่เข้ารหัส**

เพื่อทำการตรวจสอบเมตาดาต้าของการนำเสนอที่เข้ารหัสโดยไม่โหลดสไลด์หรือเนื้อหาอื่น ๆ ให้สร้างอ็อบเจกต์ [LoadOptions](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/loadoptions/) และส่งค่า `true` ไปยัง `setOnlyLoadDocumentProperties` ในโหมดนี้ Aspose.Slides จะละเว้นรหัสผ่านและโหลดเฉพาะคุณสมบัติเอกสารที่เปิดเผยสู่สาธารณะ

โค้ดตัวอย่างต่อไปนี้อ่านคุณสมบัติเอกสารที่สร้างมาโดยอัตโนมัติและที่กำหนดเองผ่าน `getDocumentProperties` บน [Presentation](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/presentation/):

```javascript
const loadOptions = new aspose.slides.LoadOptions();
loadOptions.setOnlyLoadDocumentProperties(true);

const presentation = new aspose.slides.Presentation("encrypted-pres.pptx", loadOptions);
try {
    const documentProperties = presentation.getDocumentProperties();

    // อ่านคุณสมบัติเอกสารที่สร้างมาโดยอัตโนมัติ.
    console.log("Title: " + documentProperties.getTitle());
    console.log("Author: " + documentProperties.getAuthor());

    // อ่านคุณสมบัติเอกสารที่กำหนดเอง.
    const customPropertyCount = documentProperties.getCountOfCustomProperties();

    for (let propertyIndex = 0; propertyIndex < customPropertyCount; propertyIndex++) {
        const propertyName = documentProperties.getCustomPropertyName(propertyIndex);
        const propertyValue = documentProperties.get_Item(propertyName);

        console.log(propertyName + ": " + propertyValue);
    }
} finally {
    presentation.dispose();
}
```

การทำงานนี้ทำได้เฉพาะเมื่อคุณสมบัติของเอกสารถูกทิ้งไว้โดยไม่เข้ารหัส (สาธารณะ) เมื่อการนำเสนอถูกเข้ารหัส หากคุณสมบัติของเอกสารถูกเข้ารหัส การส่งค่า `true` ไปยัง `LoadOptions.setOnlyLoadDocumentProperties` จะทำให้เกิดข้อยกเว้นเพราะรหัสผ่านจะถูกละเว้นในโหมดนี้ หากต้องการเข้าถึงคุณสมบัติเอกสารที่เข้ารหัสหรือโหลดการนำเสนอเต็มรูปแบบรวมสไลด์และเนื้อหาอื่น ๆ ให้ส่งรหัสผ่านที่ถูกต้องผ่าน `LoadOptions.setPassword` บน [LoadOptions](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/loadoptions/)

## **ตรวจสอบว่าการนำเสนอถูกป้องกันด้วยรหัสผ่านหรือไม่ก่อนโหลด**

ก่อนที่คุณจะโหลดการนำเสนอ คุณอาจต้องการตรวจสอบและยืนยันว่าการนำเสนอไม่ได้รับการป้องกันด้วยรหัสผ่าน วิธีนี้ช่วยให้คุณหลีกเลี่ยงข้อผิดพลาดและปัญหาอื่น ๆ ที่อาจเกิดขึ้นเมื่อโหลดการนำเสนอที่ป้องกันด้วยรหัสผ่านโดยไม่มีรหัสผ่าน

โค้ด JavaScript นี้แสดงวิธีการตรวจสอบการนำเสนอเพื่อดูว่ามีการป้องกันรหัสผ่านหรือไม่ (โดยไม่ต้องโหลดการนำเสนอเอง):

```javascript
var presentationInfo = aspose.slides.PresentationFactory.getInstance().getPresentationInfo("example.pptx");
console.log("The presentation is password protected: " + presentationInfo.isPasswordProtected());
```

## **ตรวจสอบว่าการนำเสนอถูกเข้ารหัสหรือไม่**

Aspose.Slides ให้คุณตรวจสอบว่าการนำเสนอถูกเข้ารหัสหรือไม่ เพื่อตรวจสอบนี้คุณสามารถใช้คุณสมบัติ [isEncrypted](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager#isEncrypted--) ซึ่งจะคืนค่า `true` หากการนำเสนอถูกเข้ารหัสหรือ `false` หากไม่ได้ถูกเข้ารหัส

โค้ดตัวอย่างนี้แสดงวิธีการตรวจสอบว่าการนำเสนอถูกเข้ารหัสหรือไม่:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    var isEncrypted = presentation.getProtectionManager().isEncrypted();
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **ตรวจสอบว่าการนำเสนอถูกป้องกันการเขียนหรือไม่**

Aspose.Slides ให้คุณตรวจสอบว่าการนำเสนอถูกป้องกันการเขียนหรือไม่ เพื่อตรวจสอบนี้คุณสามารถใช้คุณสมบัติ [isWriteProtected](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/ProtectionManager#isWriteProtected--) ซึ่งจะคืนค่า `true` หากการนำเสนอถูกป้องกันการเขียนหรือ `false` หากไม่ได้ถูกป้องกัน

โค้ดตัวอย่างนี้แสดงวิธีการตรวจสอบว่าการนำเสนอถูกป้องกันการเขียนหรือไม่:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    var isEncrypted = presentation.getProtectionManager().isWriteProtected();
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

## **การตรวจสอบหรือยืนยันว่ามีการใช้รหัสผ่านเฉพาะเพื่อป้องกันการนำเสนอ**

คุณอาจต้องการตรวจสอบและยืนยันว่ามีการใช้รหัสผ่านเฉพาะเพื่อป้องกันเอกสารการนำเสนอ Aspose.Slides มีเครื่องมือให้คุณตรวจสอบรหัสผ่าน

โค้ดตัวอย่างนี้แสดงวิธีการตรวจสอบรหัสผ่าน:

```javascript
var presentation = new aspose.slides.Presentation("pres.pptx");
try {
    // ตรวจสอบว่ารหัสผ่านตรงกับ
    var isWriteProtected = presentation.getProtectionManager().checkWriteProtection("my_password");
} finally {
    if (presentation != null) {
        presentation.dispose();
    }
}
```

มันจะคืนค่า `true` หากการนำเสนอถูกเข้ารหัสด้วยรหัสผ่านที่ระบุ มิฉะนั้นจะคืนค่า `false`

## **FAQ**

**Aspose.Slides รองรับวิธีการเข้ารหัสแบบใดบ้าง?**

Aspose.Slides รองรับวิธีการเข้ารหัสสมัยใหม่รวมถึงอัลกอริทึมที่ใช้ AES ซึ่งทำให้การรักษาความปลอดภัยข้อมูลของการนำเสนอของคุณอยู่ในระดับสูง

**จะเกิดอะไรขึ้นหากใส่รหัสผ่านผิดขณะพยายามเปิดการนำเสนอ?**

ระบบจะขว้างข้อยกเว้นเมื่อใช้รหัสผ่านผิด ซึ่งจะแจ้งให้คุณทราบว่าการเข้าถึงการนำเสนอถูกปฏิเสธ ซึ่งช่วยป้องกันการเข้าถึงโดยไม่ได้รับอนุญาตและปกป้องเนื้อหาการนำเสนอ

**การทำงานกับการนำเสนอที่ป้องกันด้วยรหัสผ่านส่งผลต่อประสิทธิภาพหรือไม่?**

กระบวนการเข้ารหัสและถอดรหัสอาจทำให้เกิดภาระเล็กน้อยระหว่างการเปิดและบันทึกในบางกรณี อย่างไรก็ตามผลกระทบต่อประสิทธิภาพมักจะเล็กน้อยและไม่ได้ส่งผลอย่างมีนัยสำคัญต่อเวลาการประมวลผลโดยรวมของงานการนำเสนอของคุณ.
