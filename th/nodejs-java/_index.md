**ยินดีต้อนรับสู่ Aspose.Slides สำหรับ Node.js ผ่าน Java**

![โลโก้ผลิตภัณฑ์ Aspose.Slides สำหรับ Node.js ผ่าน Java](aspose_slides-for-nodejs-via-java.png)

Aspose.Slides for Node.js ผ่าน Java เป็นไลบรารีคลาสที่ช่วยให้แอปพลิเคชันของคุณสามารถอ่านและเขียนเอกสาร PowerPoint® โดยไม่ต้องใช้ Microsoft PowerPoint®.

Aspose.Slides for Node.js ผ่าน Java เป็นส่วนแรกและเดียวที่ให้ความสามารถในการจัดการเอกสาร PowerPoint®.

Aspose.Slides for Node.js ผ่าน Java มีคุณลักษณะสำคัญหลายอย่าง เช่น การจัดการข้อความ, รูปร่าง, ตารางและแอนิเมชัน, การเพิ่มเสียงและวิดีโอลงในสไลด์, การแสดงตัวอย่างสไลด์, การส่งออกสไลด์เป็นรูปแบบ SVG, PDF และอื่น ๆ อีกมากมาย.

{{% /alert %}}
