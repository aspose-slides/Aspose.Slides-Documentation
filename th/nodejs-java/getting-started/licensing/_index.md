## **ประเมิน Aspose.Slides**
คุณสามารถดาวน์โหลด Aspose.Slides เพื่อประเมินได้อย่างง่ายดาย แพคเกจประเมินมีเนื้อหาเดียวกับแพคเกจที่ซื้อ เวอร์ชันประเมินจะกลายเป็นมีใบอนุญาตหลังจากคุณเพิ่มโค้ดไม่กี่บรรทัดเพื่อใช้ใบอนุญาต

## **ขีดจำกัดของเวอร์ชันประเมินผล**
เวอร์ชันประเมินของ Aspose.Slides (โดยไม่มีการระบุใบอนุญาต) ให้ฟังก์ชันการทำงานของผลิตภัณฑ์เต็มรูปแบบ แต่มีสองข้อจำกัด:

* จะเพิ่มกล่องข้อความลายน้ำการประเมินลงในสไลด์ทุกสไลด์ของการพรีเซนเทชั่นแต่ละไฟล์ที่บันทึก
* ข้อความที่ยาวกว่าห้าตัวอักษรที่โค้ดของคุณอ่านจากการพรีเซนเทชั่นจะถูกตัดให้เหลือห้าตัวอักษรแรก แล้วตามด้วย `... text has been truncated due to evaluation version limitation.` ข้อความที่มีห้าตัวอักษรหรือน้อยกว่า จะถูกคืนค่าโดยไม่มีการเปลี่ยนแปลง และข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มที่

## **เกี่ยวกับการออกใบอนุญาต**
คุณสามารถดาวน์โหลดเวอร์ชันประเมินของ Aspose.Slides สำหรับ Node.js ผ่าน Java ได้อย่างง่ายดายจาก [หน้าดาวน์โหลด](https://releases.aspose.com/slides/nodejs-java/). เวอร์ชันประเมินมีคุณสมบัติเช่นเดียวกับเวอร์ชันที่มีใบอนุญาต โดยมีข้อจำกัดตามที่อธิบายข้างต้น นอกจากนี้ เวอร์ชันประเมินจะกลายเป็นมีใบอนุญาตหลังจากคุณซื้อใบอนุญาตและเพิ่มโค้ดไม่กี่บรรทัดเพื่อใช้ใบอนุญาต

ใบอนุญาตเป็นไฟล์ XML แบบข้อความธรรมดาซึ่งบรรจุรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ได้รับใบอนุญาต วันที่หมดอายุการสมัครสมาชิก เป็นต้น ไฟล์นี้มีลายเซ็นดิจิทัล ดังนั้นห้ามแก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างโดยบังเอิญในเนื้อหาไฟล์ก็จะทำให้ไฟล์ใช้ไม่ได้

เพื่อหลีกเลี่ยงข้อจำกัดที่เกี่ยวข้องกับเวอร์ชันประเมิน คุณต้องตั้งค่าใบอนุญาตก่อนใช้ **Aspose.Slides** คุณจำเป็นต้องตั้งค่าใบอนุญาตเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

### **การตั้งค่าใบอนุญาตใน Aspose.Slides สำหรับ Node.js ผ่าน Java**

สามารถใช้ใบอนุญาตจากตำแหน่งต่อไปนี้:
* เส้นทางระบุชัดเจน
* สตรีม
* เป็นใบอนุญาตแบบ Metered – กลไกการออกใบอนุญาตใหม่

{{% alert color="info" title="Note" %}}
ใช้เมธอด **setLicense** เพื่อออกใบอนุญาตให้กับคอมโพเนนต์ แม้ว่าการเรียกเมธอด **setLicense** หลายครั้งจะไม่ทำให้เกิดอันตราย แต่ก็เป็นการเสียทรัพยากร (หน่วยประมวลผล) อย่างไม่จำเป็น
{{% /alert %}}

#### **การใช้ใบอนุญาตโดยใช้ไฟล์**

ส่วนโค้ดต่อไปนี้ใช้เพื่อตั้งค่าไฟล์ใบอนุญาต: **Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");

const license = new asposeSlides.License();
license.setLicense("Aspose.Slides.lic");
console.log("The license was applied.");

// Aspose.Slides ทำงานในเครื่องเสมือน Java ที่ทำให้ Node.js ยังคงทำงาน ดังนั้นต้องจบกระบวนการอย่างชัดเจน.
process.exit(0);
```

เมื่อเรียกเมธอด setLicense ชื่อใบอนุญาตควรตรงกับชื่อไฟล์ใบอนุญาตของคุณ ตัวอย่างเช่น คุณสามารถเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น "Aspose.Slides.lic.xml" จากนั้นในโค้ดของคุณต้องส่งชื่อใบอนุญาตใหม่ (Aspose.Slides.lic.xml) ไปยังเมธอด setLicense หากไฟล์หายหรือไม่มีใบอนุญาตที่ถูกต้อง, [setLicense](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) จะโยนข้อยกเว้นซึ่งทำให้สคริปต์หยุดทำงานพร้อมข้อผิดพลาด

#### **การใช้ใบอนุญาตจากสตรีม**

เพื่อใช้ใบอนุญาตจากสตรีม ให้ส่งอ็อบเจกต์ [License](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/) และสตรีมที่อ่านได้ไปยังเมธอดสแตติก [setLicenseFromStream](https://reference.aspose.com/slides/nodejs-java/aspose.slides/license/setlicense/) สตรีมจะถูกอ่านแบบอะซิงโครนัส และคอลแบ็คจะรับข้อผิดพลาดหากสตรีมไม่มีใบอนุญาตที่ถูกต้อง:

**Node.js**

```javascript
const asposeSlides = require("aspose.slides.via.java");
const fs = require("fs");

const license = new asposeSlides.License();
const readStream = fs.createReadStream("Aspose.Slides.lic");
asposeSlides.License.setLicenseFromStream(license, readStream, function (error) {
    if (error) {
        console.error("The license was not applied:", error.message);
    } else {
        console.log("The license was applied.");
    }

    // Aspose.Slides ทำงานในเครื่องเสมือน Java ที่ทำให้ Node.js ยังคงทำงาน ดังนั้นจึงต้องจบกระบวนการอย่างชัดเจน.
    process.exit(0);
});
```

ใบอนุญาตจะถูกนำไปใช้เมื่อสตรีมทั้งหมดถูกอ่านครบก่อนที่คอลแบ็คจะทำงาน ดังนั้นให้เริ่มงาน Aspose.Slides อื่น ๆ จากคอลแบ็ค

ตัวอย่างทั้งสองเรียก `process.exit(0)` เมื่อเสร็จสิ้น เนื่องจาก Java Virtual Machine ที่รัน Aspose.Slides ทำให้ Node.js ยังคงทำงานอยู่ ในแอปพลิเคชัน ให้ดำเนินโค้ด Aspose.Slides ของคุณต่อไปแทนการปิดกระบวนการ
