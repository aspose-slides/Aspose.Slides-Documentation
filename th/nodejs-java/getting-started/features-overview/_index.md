## **แพลตฟอร์มที่รองรับ**
Aspose.Slides for Node.js via Java เป็น API ที่ไม่ขึ้นกับแพลตฟอร์ม สามารถใช้ได้บนแพลตฟอร์มใดก็ได้ (Windows, Linux, macOS ฯลฯ) ที่ติดตั้ง Node.js รุ่น 7 หรือสูงกว่า และต้องมี Oracle JDK รุ่น 8 หรือสูงกว่าเป็นข้อกำหนดเพิ่มเติม

## **รูปแบบไฟล์และการแปลง**
Aspose.Slides for Node.js via Java รองรับรูปแบบเอกสาร PowerPoint ส่วนใหญ่ รวมทั้งการส่งออกไปยังรูปแบบไฟล์ที่องค์กรนิยมใช้และแชร์กัน รายละเอียดมีดังนี้

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Node.js via Java ให้การประมวลผลที่เร็วที่สุดสำหรับรูปแบบเอกสารการนำเสนอนี้|
|PPT to PPTX conversion|Aspose.Slides for Node.js via Java รองรับการแปลงจาก PPT ไปเป็น PPTX|
|Portable Document Format (PDF)|คุณสามารถส่งออกไฟล์รูปแบบที่รองรับทั้งหมดเป็นเอกสาร Adobe Portable Document Format (PDF) ด้วยวิธีเดียว|
|XML Parser Specification (XPS)|คุณสามารถส่งออกไฟล์รูปแบบที่รองรับทั้งหมดเป็นเอกสาร XML Parser Specification (XPS) ด้วยวิธีเดียว|
|Tagged Image File Format (TIFF)|คุณสามารถส่งออกไฟล์รูปแบบการนำเสนอที่รองรับทั้งหมดเป็น Tagged Image File Format (TIFF)|
|PPTX To HTML Conversion|Aspose.Slides for Node.js via Java รองรับการแปลง PresentationEx เป็นรูปแบบ HTML|

## **การเรนเดอร์การนำเสนอ**
Aspose.Slides for Node.js via Java รองรับการเรนเดอร์สไลด์ในงานนำเสนอด้วยความแม่นยำสูงไปยังรูปแบบกราฟิกต่าง ๆ รายละเอียดมีดังนี้

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|Java Supported Image Formats|ด้วย Aspose.Slides for Node.js via Java คุณสามารถเรนเดอร์สไลด์และรูปภาพบนสไลด์เป็นรูปแบบกราฟิกที่ Java รองรับทั้งหมด เช่น TIFF, PNG, BMP, JPEG, GIF|
|SVG Format|Aspose.Slides for Node.js via Java ยังมีเมท็อดในตัวที่ช่วยให้คุณส่งออกสไลด์การนำเสนอเป็นรูปแบบ Scalable Vector Graphics (SVG)|

## **FAQ**

### ฉันต้องติดตั้ง Microsoft PowerPoint บนเซิร์ฟเวอร์/PC เพื่อให้ไลบรารีทำงานหรือไม่?

ไม่จำเป็น PowerPoint ไม่ต้องการ; Aspose.Slides เป็นเอนจิ้นสแตนด์อโลนสำหรับสร้าง, แก้ไข, แปลง, และเรนเดอร์การนำเสนอ

### การทำงานแบบหลายเธรดทำอย่างไร? สามารถทำงานประมวลผลแบบขนานได้หรือไม่?

ปลอดภัยที่จะประมวลผลเอกสารต่าง ๆ ในเธรดต่าง ๆ; ไม่ควรใช้วัตถุ [การนำเสนอ](https://reference.aspose.com/slides/th/nodejs-java/aspose.slides/presentation/) เดียวกันโดย [หลายเธรด](/slides/th/nodejs-java/multithreading/) พร้อมกัน

### รองรับรหัสผ่านไฟล์และการเข้ารหัสหรือไม่?

ใช่ คุณสามารถ [เปิด](/slides/th/nodejs-java/password-protected-presentation/) งานนำเสนอที่ถูกเข้ารหัส ตั้งหรือเอารหัสผ่านสำหรับการเปิดและการเขียนออกได้ และตรวจสอบสถานะการป้องกัน

### ต้องใส่ใจเรื่องแพ็กเกจฟอนต์ในคอนเทนเนอร์ Linux หรือไม่?

ใช่ แนะนำให้ติดตั้งแพ็กเกจฟอนต์ทั่วไปและ/หรือระบุไดเรกทอรีฟอนต์อย่างชัดเจน [/slides/th/nodejs-java/custom-font/](/slides/th/nodejs-java/custom-font/) ในแอปพลิเคชันของคุณเพื่อหลีกเลี่ยงการแทนที่ที่ไม่คาดคิด

### มีข้อจำกัดในเวอร์ชันประเมินหรือไม่?

ใน [โหมดประเมิน](/slides/th/nodejs-java/licensing/) จะมีลายน้ำเพิ่มในผลลัพธ์และมีข้อจำกัดบางประการ; มีใบอนุญาตชั่วคราว 30 วัน [/slides/th/nodejs-java/licensing/](/slides/th/nodejs-java/licensing/) พร้อมให้ทดลองฟีเจอร์เต็ม

### รองรับการนำเข้ารูปแบบภายนอกเข้าสู่การนำเสนอ (PDF/HTML → PPTX) หรือไม่?

ใช่ คุณสามารถเพิ่ม [หน้า PDF และเนื้อหา HTML](/slides/th/nodejs-java/import-presentation/) ไปยังการนำเสนอและแปลงเป็นสไลด์ได้
