## **ภาพรวม**

ทำตามขั้นตอนสี่ขั้นตอนด้านล่างตามลำดับ แต่ละขั้นตอนระบุว่าต้องทำอะไรและเชื่อมโยงบทความที่มีรายละเอียด การประเมิน การให้ใบอนุญาตและการสนับสนุนจะถูกอธิบายหลังจากขั้นตอนเหล่านั้น

## **ขั้นตอน 1: ตรวจสอบความต้องการของระบบ**

Aspose.Slides for .NET ทำงานบน Windows, Linux และ macOS. [ข้อกำหนดระบบ](/slides/th/net/system-requirements/) แสดงรายการระบบปฏิบัติการและเวอร์ชัน .NET ที่แต่ละแพคเกจสนับสนุน รวมถึงไลบรารีที่ Linux ต้องการเพิ่มเติม

## **ขั้นตอน 2: ติดตั้งแพคเกจ**

Aspose.Slides for .NET แจกจ่ายผ่าน NuGet เป็นสองแพคเกจที่ให้คลาสเดียวกัน เพิ่มหนึ่งในนั้นลงในโครงการของคุณ:

- บน Windows: `dotnet add package Aspose.Slides.NET`
- บน Linux และ macOS: `dotnet add package Aspose.Slides.NET6.CrossPlatform`. บน Linux ให้ติดตั้งไลบรารี `fontconfig` ก่อน.
- บน Alpine Linux และบนระบบ Linux ที่ glibc เก่ากว่า 2.23 (x64) หรือ 2.39 (ARM64): Aspose.Slides.NET พร้อมกับไลบรารี `libgdiplus` ที่ติดตั้งแล้ว.

[การติดตั้ง](/slides/th/net/installation/) ให้คำสั่ง Linux การตั้งค่าเริ่มต้นเพิ่มเติมที่ Aspose.Slides.NET จำเป็นต้องใช้บน Linux และขั้นตอนสำหรับ Visual Studio.

## **ขั้นตอน 3: สร้างการนำเสนอแรกของคุณ**

ส่วน [เริ่มต้นอย่างเร็วบนหน้าแรกของ Aspose.Slides for .NET](/slides/th/net/#your-first-presentation) เป็นโปรแกรมคอนโซลเต็มรูปแบบ: มันเพิ่มกล่องข้อความลงในสไลด์และบันทึกการนำเสนอเป็นไฟล์ PPTX. [สร้างการนำเสนอ](/slides/th/net/create-presentation/) อธิบายขั้นตอนเดียวกันอย่างละเอียดและแสดงวิธีเปิดการนำเสนอที่มีอยู่และบันทึกเป็นรูปแบบอื่น.

## **ประเมินและการให้ใบอนุญาต**

หากไม่มีใบอนุญาต Aspose.Slides จะทำงานในโหมดประเมิน: จะเพิ่มลายน้ำในทุกสไลด์ที่บันทึกและตัดข้อความที่อ่านจากการนำเสนอ

- [ประเมิน Aspose.Slides](/slides/th/net/evaluate-aspose-slides/) อธิบายข้อจำกัดของการประเมินและวิธีขอใบอนุญาตชั่วคราว
- [การให้ใบอนุญาต](/slides/th/net/licensing/) แสดงวิธีใช้ใบอนุญาตจากไฟล์, สตรีม หรือทรัพยากรฝังตัว
- [การให้ใบอนุญาตแบบตามการใช้งาน](/slides/th/net/metered-licensing/) ครอบคลุมการให้ใบอนุญาตที่คิดค่าใช้จ่ายตามการใช้งาน
- [รูปแบบไฟล์ที่รองรับ](/slides/th/net/supported-file-formats/) รายการรูปแบบที่ Aspose.Slides สามารถโหลดและบันทึกได้

## **คำถามที่พบบ่อย**

**ต้องการติดตั้ง Microsoft PowerPoint หรือไม่?**

ไม่. Aspose.Slides อ่านและเขียนไฟล์การนำเสนอด้วยตนเองและไม่ได้ใช้ PowerPoint ดังนั้นจึงสามารถทำงานบนเซิร์ฟเวอร์และบน Linux ได้เช่นกัน

**ควรใช้แพคเกจใดสำหรับแอปพลิเคชัน .NET Framework?**

Aspose.Slides.NET. มันมีบิลด์สำหรับ .NET Framework 4.6.2 ขึ้นไป, .NET 6 ขึ้นไป, และ .NET Standard 2.0. Aspose.Slides.NET6.CrossPlatform ต้องการ .NET 6 หรือใหม่กว่า
