{{% alert color="info" %}} 

ส่วนประกอบ Aspose .NET ทั้งหมดต้องการชุดสิทธิ์ Full Trust เนื่องจากบางครั้งจำเป็นต้องเข้าถึงการตั้งค่ารีจิสทรี ไฟล์ระบบ และไฟล์ที่จัดเก็บในตำแหน่งอื่น (นอกจากไดเรกทอรีเสมือน) สำหรับการดำเนินการบางอย่าง (เช่นการแยกประมวลผลฟอนต์) นอกจากนี้ส่วนประกอบ Aspose .NET ยังอิงกับคลาสระบบ .NET หลัก ซึ่งในหลายกรณีก็ต้องการชุดสิทธิ์ Full Trust 

{{% /alert %}} 

ผู้ให้บริการอินเทอร์เน็ต (ISP) ที่โฮสต์แอปพลิเคชันหลาย ๆ ตัวจากบริษัทต่าง ๆ ส่วนใหญ่บังคับใช้ระดับความปลอดภัย Medium Trust ในกรณี .NET 2.0 ระดับความปลอดภัยนี้จะมีข้อจำกัดต่อไปนี้: 

- OleDbPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถใช้ผู้ให้บริการข้อมูล OLE DB ที่จัดการโดย ADO.NET เพื่อเข้าถึงฐานข้อมูลได้
- EventLogPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถเข้าถึงบันทึกเหตุการณ์ของ Windows ได้
- ReflectionPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถใช้การสะท้อน (reflection) ได้
- RegistryPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถเข้าถึงรีจิสทรีได้
- WebPermission มีข้อจำกัด หมายความว่าแอปพลิเคชันของคุณสามารถสื่อสารได้เฉพาะกับที่อยู่หรือช่วงของที่อยู่ที่คุณกำหนดในองค์ประกอบ <trust> เท่านั้น
- FileIOPermission มีข้อจำกัด หมายความว่าคุณสามารถเข้าถึงไฟล์ได้เฉพาะในโครงสร้างไดเรกทอรีเสมือนของแอปพลิเคชันของคุณเท่านั้น

{{% alert color="info" %}} 

จากเหตุผลข้างต้น ส่วนประกอบ Aspose .NET สามารถใช้งานได้เฉพาะบนเซิร์ฟเวอร์ที่ให้ชุดสิทธิ์ Full Trust เท่านั้น
