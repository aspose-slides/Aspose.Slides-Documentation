## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดนักพัฒนาควรเลือกใช้ Open XML SDK หรือ Aspose.Slides สำหรับทำงานกับไฟล์งานนำเสนอ โดยอธิบายว่า Open XML SDK เป็นไลบรารีสำหรับจัดการแพ็คเกจ OOXML และองค์ประกอบ XML ที่เป็นฐานของมัน ส่วน Aspose.Slides นำเสนอเป็นไลบรารีการประมวลผลงานนำเสนอที่มีโมเดลวัตถุระดับสูงและรองรับงานที่เกี่ยวกับ PowerPoint จำนวนมาก

บทความเปรียบเทียบตัวเลือกทั้งสองตามรูปแบบที่รองรับ, โมเดลการเขียนโปรแกรม, การเรนเดอร์, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้งานทั่วไป นอกจากนี้ยังชี้แจงว่า Open XML SDK อาจเหมาะกับการทำงานพื้นฐานกับ PPTX หรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ในขณะที่ Aspose.Slides จะเหมาะกับงานนำเสนอที่ซับซ้อนเช่นการทำงานกับหลายรูปแบบ PowerPoint, การคัดลอกหรือทำสำเนา shape, การแทนที่ข้อความ, การใส่แอนิเมชัน, และการแปลงงานนำเสนอเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
บางครั้งเราจะได้รับคำถามนี้: *ทำไมเราต้องใช้ผลิตภัณฑ์ของ Aspose แทน Open XML SDK ที่ฟรี?* 

เราพบว่าการตอบคำถามนี้ง่ายเมื่ออิงจากคุณลักษณะและฟังก์ชันการทำงาน

ตามที่ [ห้องสมุด MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) ระบุ Open XML SDK มีคำจำกัดความดังนี้:

> "Open XML SDK 2.0 ทำให้การจัดการแพ็คเกจ Open XML และองค์ประกอบสกีม่า Open XML ภายในแพ็คเกจง่ายขึ้น Open XML SDK 2.0 รวมงานทั่วไปหลายอย่างที่นักพัฒนาทำบนแพ็คเกจ Open XML เพื่อให้คุณสามารถทำงานที่ซับซ้อนได้ด้วยไม่กี่บรรทัดของโค้ด เอกสาร OOXML โดยพื้นฐานคือไฟล์ XML ที่บีบอัดและ Open XML SDK เป็นชุดคลาสที่ช่วยให้คุณทำงานกับเนื้อหาเอกสาร OOXML ด้วยวิธีที่มีประเภทที่แน่นหนา ซึ่งหมายความว่าแทนที่จะต้องแตกไฟล์เพื่อดึง XML, โหลด XML ไปยังโครงสร้าง DOM, และทำงานกับองค์ประกอบและแอตทริบิวต์ XML โดยตรง Open XML SDK มีคลาสที่ทำสิ่งเหล่านั้นให้คุณ"

## **Aspose.Slides คืออะไร?**
Aspose.Slides เป็นคลาสไลบรารีที่ให้แอปพลิเคชันทำงานประมวลผลงานนำเสนอเหล่านี้ได้:

- การเขียนโปรแกรมด้วยโมเดลวัตถุของงานนำเสนอ
- การแปลงคุณภาพสูงที่รองรับรูปแบบ PowerPoint ยอดนิยมทั้งหมด รวมถึงการแปลงเป็น PDF, XPS และ TIFF
- การสร้างภาพย่อของสไลด์ในรูปแบบที่รู้จักกันดีเช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG
- การสร้างงานนำเสนอจากศูนย์หรือโดยรวมองค์ประกอบจากเอกสารหนึ่งหรือหลายเอกสาร
- การเพิ่มแอนิเมชัน, OLE Frame, ตาราง, การสร้างและจัดการแผนภูมิ
- การควบคุม (ควบคุมอย่างละเอียด) และจัดการการจัดรูปแบบข้อความใน TextFrames, Paragraphs และ Portions

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับฟีเจอร์ที่มีให้ โปรดดูหน้าที่ [คุณสมบัติของ Aspose.Slides](/slides/th/net/product-overview/)

## **เปรียบเทียบ Open XML SDK กับ Aspose.Slides**
ตารางนี้เปรียบเทียบความสามารถและฟีเจอร์ของ Open XML SDK กับ Aspose.Slides

|**คุณลักษณะหรือหมวดคุณลักษณะ**|**Open XML SDK**|**Aspose.Slides**|
| :- | :- | :- |
|รูปแบบการนำเสนอที่รองรับ|PPTX|PPT, POT, PPS, PPTX, POTX, PPSX, ODP|
|การแปลงจาก PPT เป็น PPTX|No|Yes|
|<p>การเขียนโปรแกรมระดับสูงด้วย Presentation Document Object Model (DOM): </p><p>- ค้นหาและแทนที่ข้อความ</p><p>- ประกอบสไลด์ในงานนำเสนอ</p>|No|Yes|
|การเขียนโปรแกรมเชิงรายละเอียดด้วย document object model; การเข้าถึงองค์ประกอบและการจัดรูปแบบแต่ละส่วนเช่น TextHolders, TextFrames, Paragraphs และ Portions.|Yes|Yes|
|การเข้าถึงระดับต่ำโดยตรงและครบถ้วนต่อองค์ประกอบและแอตทริบิวต์ XML เช่นตัวระบุความสัมพันธ์, ตัวระบุรายการของเอกสาร OOXML.|Yes|No|
|<p>การเรนเดอร์งานนำเสนอ:</p><p>- เรนเดอร์งานนำเสนอเป็น PDF, PDF Notes, XPS, ภาพ TIFF</p><p>- เรนเดอร์ภาพย่อของสไลด์เป็น PNG, JPEG, BMP, SVG และ TIFF</p><p>- กำหนดความละเอียดภาพ, คุณภาพ, การบีบอัดและตัวเลือกอื่น ๆ</p>|No|Yes|
|แพลตฟอร์มที่รองรับ|Windows, .NET|Windows, Linux, Java, .NET, Mono|

## **สรุป**
Open XML SDK และ Aspose.Slides ไม่ได้แข่งขันกันโดยตรงเพราะตอบสนองต่อความต้องการที่แตกต่างอย่างมากและมุ่งเป้าไปยังผู้ใช้กลุ่มต่างกัน

{{% alert color="info" %}} 

Open XML SDK คือคลาสไลบรารีที่ให้วิธีการทำงานกับเอกสาร OOXML ด้วยประเภทที่แน่นหนาในขณะที่ Aspose.Slides เป็นไลบรารีการประมวลผลงานนำเสนอที่มีประโยชน์อย่างยิ่งและสนับสนุนรูปแบบไฟล์ Microsoft PowerPoint เกือบทั้งหมด 

{{% /alert %}} 

หากโฟลว์การทำงานของคุณเป็นการดำเนินการเขียนโปรแกรมพื้นฐานบนเอกสาร PPTX แล้ว Open XML SDK อาจเป็นตัวเลือกที่ดี ด้วย Open XML SDK คุณควรจะทำงานง่าย ๆ เช่นการสร้างเอกสาร PPTX อย่างง่ายหรือการลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การสกัดรูปภาพ หรืออื่น ๆ งานบางอย่างทำได้ด้วย Open XML SDK แต่ทำไม่ได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบและแอตทริบิวต์ XML ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK

หากคุณต้องการทำงานที่ซับซ้อนบนเอกสาร—เช่นรายการด้านล่าง—Aspose.Slides คือทางเลือกที่ดีที่สุดของคุณ

- งานที่เกี่ยวข้องกับรูปแบบ PowerPoint เก่า (และ PPTX ด้วย)
- การคัดลอกหรือทำสำเนา shape ภายในสไลด์ในแบบที่รวมวัตถุ, สไตล์, และองค์ประกอบการจัดรูปแบบอื่น ๆ อย่างเหมาะสม
- การแทนที่ข้อความที่มีการจัดรูปแบบหรือไม่มีการจัดรูปแบบ
- การใส่แอนิเมชันและการใช้คอนเนคเตอร์กับ shape
- การแปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้ดูเหมือน Microsoft PowerPoint ทำการแปลง
- การพัฒนาแอปพลิเคชัน .NET หรือ Java ทั้งบนเดสก์ท็อปและเว็บ
