## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดที่นักพัฒนาอาจเลือกใช้ Open XML SDK หรือ Aspose.Slides สำหรับการทำงานกับเอกสารพรีเซนเทชัน โดยอธิบาย Open XML SDK ว่าเป็นไลบรารีสำหรับจัดการแพคเกจ OOXML และองค์ประกอบ XML ภายในแพคเกจ ในขณะที่ Aspose.Slides ถูกนำเสนอเป็นไลบรารีการประมวลผลพรีเซนเทชันที่มีโมเดลอ็อบเจกต์ระดับสูงและรองรับงานที่เกี่ยวข้องกับ PowerPoint จำนวนมาก

บทความเปรียบเทียบตัวเลือกทั้งสองตามรูปแบบที่รองรับ, โมเดลการเขียนโปรแกรม, ความสามารถในการเรนเดอร์และพิมพ์, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้งานทั่วไป นอกจากนี้ยังชี้แจงว่า Open XML SDK อาจเหมาะสำหรับการดำเนินการพื้นฐานกับ PPTX หรือการเข้าถึงโดยตรงไปยังองค์ประกอบ OOXML ในขณะที่ Aspose.Slides จะเหมาะกับงานพรีเซนเทชันที่ซับซ้อน เช่น การทำงานกับหลายรูปแบบ PowerPoint, การคัดลอกหรือจำลองรูปทรง, การแทนที่ข้อความ, การใช้แอนิเมชัน, และการแปลงพรีเซนเทชันเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
บางครั้งเราจะได้รับคำถามนี้: *ทำไมเราต้องใช้ผลิตภัณฑ์ของ Aspose แทน Open XML SDK ที่ฟรี?* 

เราพบว่าคำตอบง่าย ๆ คืออิงตามคุณลักษณะและฟังก์ชันการทำงาน

ตามข้อมูลจาก [MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK ถูกกำหนดไว้อย่างนี้:

> "Open XML SDK 2.0 ทำให้การจัดการแพคเกจ Open XML และองค์ประกอบสคีม่า Open XML ภายในแพคเกจเป็นเรื่องง่ายขึ้น Open XML SDK 2.0 รวมงานทั่วไปหลายอย่างที่นักพัฒนามักทำบนแพคเกจ Open XML เพื่อให้คุณสามารถทำการดำเนินการที่ซับซ้อนได้ด้วยเพียงไม่กี่บรรทัดของโค้ด เอกสาร OOXML คือไฟล์ XML ที่บรรจุเป็น zip และ Open XML SDK คือชุดคลาสที่ช่วยให้คุณทำงานกับเนื้อหาของเอกสาร OOXML ด้วยรูปแบบที่เป็น strongly‑typed นั่นหมายความว่าแทนที่จะต้องอันซิปไฟล์เพื่อดึง XML, โหลด XML นั้นเข้าสู่โครงสร้าง DOM, แล้วทำงานกับองค์ประกอบและแอตทริบิวต์ XML โดยตรง Open XML SDK มีคลาสที่ทำสิ่งเหล่านั้นให้คุณ"

## **Aspose.Slides คืออะไร?**
Aspose.Slides คือไลบรารีคลาสตาซึ่งทำให้แอปพลิเคชันสามารถทำงานการประมวลผลพรีเซนเทชันต่อไปนี้ได้:

- การเขียนโปรแกรมด้วยโมเดลอ็อบเจกต์ของพรีเซนเทชัน
- การแปลงคุณภาพสูงที่รองรับรูปแบบ PowerPoint ยอดนิยมทั้งหมด รวมถึงการแปลงเป็น PDF, XPS, TIFF และการพิมพ์
- การสร้างรูปย่อของสไลด์ในรูปแบบที่รู้จักกันดีเช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG
- การสร้างพรีเซนเทชันตั้งแต่เริ่มต้นหรือโดยการผสานองค์ประกอบจากเอกสารหนึ่งหรือหลายเอกสาร
- การเพิ่มแอนิเมชัน, OLE Frames, ตาราง, การสร้างและจัดการแผนภูมิ
- การควบคุม (ควบคุมอย่างกว้างขวาง) และจัดการรูปแบบข้อความในระดับ TextFrames, Paragraphs และ Portions

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับคุณสมบัติที่มีให้ โปรดดูที่หน้า [คุณสมบัติของ Aspose.Slides](/slides/th/net/product-overview/)

|**คุณลักษณะหรือหมวดคุณลักษณะ**|**Open XML SDK**|**Aspose.Slides**|
| :- | :- | :- |
|รูปแบบพรีเซนเทชันที่รองรับ|PPTX|PPT, POT, PPS, PPTX, POTX, PPSX, ODP|
|การแปลงจาก PPT เป็น PPTX|No|Yes|
|<p>การเขียนโปรแกรมระดับสูงด้วย Presentation Document Object Model (DOM):</p><p>- ค้นหาและแทนที่ข้อความ</p><p>- ประกอบสไลด์ในพรีเซนเทชัน</p>|No|Yes|
|การเขียนโปรแกรมเชิงละเอียดด้วยโมเดลองค์ประกอบเอกสาร; เข้าถึงองค์ประกอบและการจัดรูปแบบแต่ละรายการเช่น TextHolders, TextFrames, Paragraphs และ Portions.|Yes|Yes|
|การเข้าถึงระดับล่างโดยตรงและเต็มรูปแบบต่อองค์ประกอบ XML และแอตทริบิวต์พื้นฐาน เช่น ตัวระบุความสัมพันธ์, ตัวระบุรายการของเอกสาร OOXML.|Yes|No|
|<p>การเรนเดอร์และการพิมพ์:</p><p>- เรนเดอร์พรีเซนเทชันเป็น PDF, PDF Notes, XPS, ภาพ TIFF</p><p>- เรนเดอร์รูปย่อสไลด์เป็น PNG, JPEG, BMP, SVG และ TIFF</p><p>- ระบุความละเอียดของภาพ, คุณภาพ, การบีบอัดและตัวเลือกอื่น ๆ</p><p>- พิมพ์พรีเซนเทชันโดยใช้โครงสร้างการพิมพ์ของ .NET ส่วนประกอบมีเมธอดพิมพ์ในตัวเพื่อพิมพ์พรีเซนเทชันตามที่แสดงใน Print Preview ของ MS PowerPoint</p>|No|Yes|
|แพลตฟอร์มที่รองรับ|Windows, .NET|Windows, Linux, Java, .NET, Mono|

## **สรุป**
Open XML SDK และ Aspose.Slides ไม่ได้แข่งขันโดยตรงกันเพราะพวกมันตอบสนองต่อความต้องการที่แตกต่างกันอย่างมากและมุ่งเป้าไปยังกลุ่มผู้ใช้ที่ต่างกัน

{{% alert color="primary" %}} 

Open XML SDK คือไลบรารีคลาสที่มอบวิธี strongly‑typed สำหรับการทำงานกับเอกสาร OOXML ในขณะที่ Aspose.Slides เป็นไลบรารีการประมวลผลพรีเซนเทชันที่มีประโยชน์อย่างยิ่งและให้การสนับสนุนที่ดีเยี่ยมสำหรับแทบทุกรูปแบบไฟล์ Microsoft PowerPoint 

{{% /alert %}} 

หากกระบวนการทำงานของคุณเป็นการดำเนินการเขียนโปรแกรมพื้นฐานบนเอกสาร PPTX, Open XML SDK อาจเป็นตัวเลือกที่ดี ด้วย Open XML SDK คุณควรสบายใจในการทำงานง่าย ๆ เช่น การสร้างเอกสาร PPTX อย่างง่าย หรือการลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การสกัดภาพ หรืออื่น ๆ งานบางอย่างทำได้ด้วย Open XML SDK แต่ไม่สามารถทำได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบและแอตทริบิวต์ XML ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK

หากคุณต้องการทำงานที่ซับซ้อนบนเอกสาร—เช่นรายการด้านล่าง—Aspose.Slides จะเป็นตัวเลือกที่ดีที่สุดสำหรับคุณ

- การดำเนินการที่เกี่ยวข้องกับรูปแบบ PowerPoint เก่า (และ PPTX ด้วย)
- การคัดลอกหรือจำลองรูปทรงภายในสไลด์ในลักษณะที่รวมวัตถุ, สไตล์, และองค์ประกอบการจัดรูปแบบอื่น ๆ อย่างเหมาะสม
- การแทนที่ข้อความที่มีการจัดรูปแบบหรือไม่มีการจัดรูปแบบ
- การใช้แอนิเมชันและการเชื่อมต่อด้วยคอนเน็กเตอร์กับรูปทรง
- การแปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้มีลักษณะเหมือน Microsoft PowerPoint ทำการแปลง
- การพัฒนาแอปพลิเคชัน .NET หรือ Java ทั้งในสภาพแวดล้อมเดสก์ท็อปและบนเว็บ
