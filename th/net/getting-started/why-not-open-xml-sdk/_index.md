## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อไหร่ผู้พัฒนาอาจเลือกใช้ Open XML SDK หรือ Aspose.Slides สำหรับทำงานกับเอกสารพรีเซนเทชั่น โดยอธิบายว่า Open XML SDK เป็นไลบรารีสำหรับจัดการแพ็กเกจ OOXML และองค์ประกอบ XML ด้านใน ในขณะที่ Aspose.Slides นำเสนอเป็นไลบรารีการประมวลผลพรีเซนเทชั่นที่มีโมเดลออบเจกต์ระดับสูงและรองรับงานที่เกี่ยวกับ PowerPoint มากมาย

บทความเปรียบเทียบตัวเลือกทั้งสองตามรูปแบบที่สนับสนุน, โมเดลการเขียนโปรแกรม, ความสามารถด้านการเรนเดอร์และการพิมพ์, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้งานทั่วไป นอกจากนี้ยังชี้แจงว่า Open XML SDK อาจเหมาะสำหรับการดำเนินการพื้นฐานกับ PPTX หรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ในขณะที่ Aspose.Slides เหมาะกับงานพรีเซนเทชั่นที่ซับซ้อนเช่นการทำงานกับหลายรูปแบบ PowerPoint, การคัดลอกหรือคลอนรูปทรง, การแทนที่ข้อความ, การใส่แอนิเมชัน, และการแปลงพรีเซนเทชั่นเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
บางครั้งเรามักได้รับคำถามนี้: *ทำไมเราต้องใช้ผลิตภัณฑ์ของ Aspose แทน Open XML SDK ที่ฟรี?*  

เราพบว่าตอบคำถามนี้ได้ง่ายเมื่อพิจารณาจากคุณลักษณะและฟังก์ชันการทำงาน  

ตามที่กำหนดใน [ห้องสมุด MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK มีคำอธิบายดังนี้:

> "Open XML SDK 2.0 ทำให้การจัดการแพ็กเกจ Open XML และองค์ประกอบสคีม่า Open XML ด้านในของแพ็กเกจเป็นเรื่องง่ายขึ้น Open XML SDK 2.0 สรุปงานทั่วไปหลายอย่างที่นักพัฒนาทำบนแพ็กเกจ Open XML ให้คุณสามารถทำงานซับซ้อนได้ด้วยเพียงไม่กี่บรรทัดของโค้ด เอกสาร OOXML เป็นไฟล์ XML ที่บีบอัดเป็น zip และ Open XML SDK คือชุดคลาสที่ช่วยให้คุณทำงานกับเนื้อหาของเอกสาร OOXML อย่างมีประเภทที่แข็งแรง ซึ่งไม่ได้ต้องการการแตกไฟล์เพื่อดึง XML โหลด XML ไปยังโครงสร้าง DOM แล้วทำงานกับองค์ประกอบและแอตทริบิวต์ XML โดยตรง Open XML SDK ให้คลาสเพื่อทำสิ่งนั้นแทน"

## **Aspose.Slides คืออะไร?**
Aspose.Slides เป็นไลบรารีคลาสที่ช่วยให้แอปพลิเคชันทำงานประมวลผลพรีเซนเทชั่นได้ดังต่อไปนี้:

- การเขียนโปรแกรมด้วยโมเดลออบเจกต์ของพรีเซนเทชั่น
- การแปลงคุณภาพสูงที่รองรับรูปแบบ PowerPoint ที่เป็นที่นิยมทั้งหมด รวมถึงการแปลงเป็น PDF, XPS, TIFF และการพิมพ์
- การสร้างภาพย่อสไลด์ในรูปแบบที่รู้จักกันดี เช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG
- การสร้างพรีเซนเทชั่นตั้งแต่ต้นหรือโดยการผสานส่วนประกอบจากเอกสารหนึ่งหรือหลายเอกสาร
- การเพิ่มแอนิเมชัน, OLE Frames, ตาราง, การสร้างและจัดการแผนภูมิ
- การควบคุม (การควบคุมอย่างกว้างขวาง) และจัดการรูปแบบข้อความในระดับ TextFrames, Paragraphs และ Portions  

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับคุณลักษณะที่มีให้ โปรดดูที่ [คุณลักษณะของ Aspose.Slides](/slides/th/net/product-overview/)

## **เปรียบเทียบ Open XML SDK กับ Aspose.Slides**
ตารางต่อไปนี้เปรียบเทียบความสามารถและคุณลักษณะของ Open XML SDK กับ Aspose.Slides

|**คุณลักษณะหรือหมวดคุณลักษณะ**|**Open XML SDK**|**Aspose.Slides**|
| :- | :- | :- |
|รูปแบบพรีเซนเทชั่นที่สนับสนุน|PPTX|PPT, POT, PPS, PPTX, POTX, PPSX, ODP|
|การแปลงจาก PPT เป็น PPTX|No|Yes|
|<p>การเขียนโปรแกรมระดับสูงด้วย Presentation Document Object Model (DOM): </p><p>- ค้นหาและแทนที่ข้อความ</p><p>- จัดเรียงสไลด์ในพรีเซนเทชั่น</p>|No|Yes|
|การเขียนโปรแกรมละเอียดด้วยโมเดลออบเจกต์ของเอกสาร; เข้าถึงองค์ประกอบและการจัดรูปแบบแต่ละส่วนเช่น TextHolders, TextFrames, Paragraphs และ Portions.|Yes|Yes|
|การเข้าถึงระดับต่ำโดยตรงและครบถ้วนต่อองค์ประกอบ XML และแอตทริบิวต์พื้นฐาน เช่น ตัวระบุความสัมพันธ์, ตัวระบุรายการของเอกสาร OOXML.|Yes|No|
|<p>การเรนเดอร์และการพิมพ์:</p><p>- เรนเดอร์พรีเซนเทชั่นเป็น PDF, PDF Notes, XPS, รูปภาพ TIFF</p><p>- เรนเดอร์ภาพย่อสไลด์เป็น PNG, JPEG, BMP, SVG และ TIFF</p><p>- กำหนดความละเอียดของภาพ, คุณภาพ, การบีบอัดและตัวเลือกอื่น ๆ</p><p>- พิมพ์พรีเซนเทชั่นโดยใช้โครงสร้างการพิมพ์ของ .NET คอมโพเนนท์มีเมธอดพิมพ์ในตัวเพื่อพิมพ์พรีเซนเทชั่นตามที่แสดงใน Print Preview ของ Microsoft PowerPoint</p>|No|Yes|
|แพลตฟอร์มที่สนับสนุน|Windows, .NET|Windows, Linux, Java, .NET, Mono|

## **สรุป**
Open XML SDK และ Aspose.Slides ไม่ได้แข่งขันกันโดยตรงเพราะพวกมันตอบสนองต่อความต้องการที่แตกต่างกันอย่างมากและมีกลุ่มเป้าหมายที่ต่างกัน  

{{% alert color="info" %}}  

Open XML SDK เป็นไลบรารีคลาสที่ให้วิธีการทำงานกับเอกสาร OOXML อย่างมีประเภทที่แข็งแรง ส่วน Aspose.Slides เป็นไลบรารีการประมวลผลพรีเซนเทชั่นที่มีประโยชน์อย่างมากและรองรับรูปแบบไฟล์ Microsoft PowerPoint เกือบทั้งหมด  

{{% /alert %}}  

หากกระบวนการทำงานของคุณเป็นการดำเนินการโปรแกรมพื้นฐานบนเอกสาร PPTX, Open XML SDK อาจเป็นตัวเลือกที่ดี ด้วย Open XML SDK คุณควรจะสามารถทำงานง่าย ๆ เช่น การสร้างเอกสาร PPTX แบบง่าย การลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การดึงรูปภาพ หรืออื่น ๆ งานบางอย่างทำได้ด้วย Open XML SDK แต่ทำไม่ได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบ XML และแอตทริบิวต์ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK  

หากคุณต้องการทำงานที่ซับซ้อนบนเอกสาร—เช่นรายการด้านล่าง—Aspose.Slides จะเป็นตัวเลือกที่ดีที่สุดของคุณ  

- การดำเนินการที่เกี่ยวข้องกับรูปแบบ PowerPoint เก่า (และ PPTX ด้วย)
- การคัดลอกหรือคลอนรูปทรงภายในสไลด์ในลักษณะที่รวมวัตถุ, สไตล์, และองค์ประกอบการจัดรูปแบบอื่น ๆ อย่างเหมาะสม
- การแทนที่ข้อความที่มีรูปแบบหรือไม่มีรูปแบบ
- การใส่แอนิเมชันและการใช้คอนเนคเตอร์กับรูปทรง
- การแปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้ดูเหมือน Microsoft PowerPoint ทำการแปลง
- การพัฒนาแอปพลิเคชัน .NET หรือ Java ทั้งในสภาพแวดล้อมเดสก์ท็อปและเว็บ
