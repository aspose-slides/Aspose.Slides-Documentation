## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดนักพัฒนาจึงอาจเลือกใช้ Open XML SDK หรือ Aspose.Slides สำหรับการทำงานกับเอกสารนำเสนอ โดยอธิบายว่า Open XML SDK เป็นไลบรารีสำหรับจัดการแพ็คเกจ OOXML และองค์ประกอบ XML พื้นฐานของมัน ในขณะที่ Aspose.Slides ถูกนำเสนอเป็นไลบรารีการประมวลผลการนำเสนอที่มีโมเดลอ็อบเจ็กต์ระดับสูงและรองรับงานที่เกี่ยวกับ PowerPoint มากมาย

บทความเปรียบเทียบทั้งสองทางเลือกโดยพิจารณาจากรูปแบบที่รองรับ, โมเดลการเขียนโปรแกรม, การเรนเดอร์, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้ทั่วไป นอกจากนี้ยังชี้แจงว่า Open XML SDK อาจเหมาะกับการดำเนินการ PPTX พื้นฐานหรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ในขณะที่ Aspose.Slides จะเหมาะกับงานนำเสนอที่ซับซ้อน เช่น การทำงานกับรูปแบบ PowerPoint หลายรูปแบบ, การคัดลอกหรือทำสำเนารูปร่าง, การแทนที่ข้อความ, การเพิ่มเอฟเฟ็กต์การเคลื่อนไหว, และการแปลงงานนำเสนอเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**

บางครั้ง เราได้รับคำถามนี้: *ทำไมเราต้องใช้ผลิตภัณฑ์ของ Aspose แทน Open XML SDK ที่ฟรี?*

เราพบว่าการตอบคำถามนี้เรื่องคุณลักษณะและฟังก์ชันการทำงานเป็นเรื่องง่าย

ตามข้อมูลจาก [MSDN Library](https://learn.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK ถูกกำหนดไว้ดังนี้:

> "Open XML SDK 2.0 ทำให้การจัดการแพ็คเกจ Open XML และองค์ประกอบสคีมา Open XML ภายในแพ็คเกจเป็นเรื่องง่ายขึ้น Open XML SDK 2.0 รวมเอาหน้าที่ทั่วไปหลายอย่างที่นักพัฒนาทำบนแพ็คเกจ Open XML ไว้เพื่อให้คุณสามารถทำการดำเนินการที่ซับซ้อนได้ด้วยเพียงไม่กี่บรรทัดของโค้ด เอกสาร OOXML นั้นโดยพื้นฐานคือไฟล์ XML ที่บีบอัดเป็น zip และ Open XML SDK เป็นชุดคลาสที่ช่วยให้คุณทำงานกับเนื้อหาของเอกสาร OOXML อย่างเป็นชนิดที่แน่นอน ซึ่งหมายความว่าตรงแทนที่จะต้องแตกไฟล์เพื่อดึง XML โหลด XML นั้นเข้าสู่โครงสร้าง DOM แล้วทำงานกับองค์ประกอบและแอตทริบิวต์ XML โดยตรง Open XML SDK จะให้คลาสที่ทำสิ่งนั้นให้"

## **Aspose.Slides คืออะไร?**

Aspose.Slides เป็นไลบรารีคลาสที่ช่วยให้แอปพลิเคชันทำงานด้านการประมวลผลการนำเสนอเหล่านี้ได้:

- เขียนโปรแกรมด้วยโมเดลอ็อบเจ็กต์ของการนำเสนอ
- การแปลงคุณภาพสูงที่รองรับรูปแบบการนำเสนอ PowerPoint ที่นิยมทั้งหมด รวมถึงการแปลงเป็น PDF, XPS, และ TIFF
- สร้างภาพย่อของสไลด์ในรูปแบบที่เป็นที่รู้จักเช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG
- สร้างการนำเสนอจากศูนย์หรือโดยการรวมองค์ประกอบจากเอกสารหนึ่งหรือหลายเอกสาร
- เพิ่มการเคลื่อนไหว, OLE Frames, ตาราง, สร้างและจัดการแผนภูมิ
- ควบคุม (การควบคุมอย่างครอบคลุม) และจัดการการฟอร์แมตข้อความในระดับ TextFrames, Paragraphs และ Portions

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับฟีเจอร์ที่มีอยู่ โปรดดูที่หน้าที่ [Aspose.Slides Features](/slides/th/net/product-overview/)

## **สรุป**

Open XML SDK และ Aspose.Slides ไม่แข่งขันกันโดยตรง เพราะพวกมันตอบสนองต่อความต้องการที่แตกต่างกันอย่างชัดเจนและมุ่งเน้นผู้ใช้กลุ่มต่างกัน

{{% alert color="info" title="Note" %}}
Open XML SDK เป็นไลบรารีคลาสที่ให้วิธีการทำงานกับเอกสาร OOXML อย่างเป็นชนิดที่แน่นอน ในขณะที่ Aspose.Slides เป็นไลบรารีการประมวลผลการนำเสนอที่มีประโยชน์อย่างยิ่งและให้การสนับสนุนที่ครอบคลุมสำหรับไฟล์ฟอร์แมตของ Microsoft PowerPoint ส่วนใหญ่
{{% /alert %}}

หากกระบวนการทำงานของคุณเป็นการดำเนินการโปรแกรมพื้นฐานบนเอกสาร PPTX แล้ว Open XML SDK อาจเป็นตัวเลือกที่เหมาะสม ด้วย Open XML SDK คุณควรจะสะดวกในการทำงานง่ายๆ เช่น การสร้างเอกสาร PPTX อย่างง่าย การลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การดึงรูปภาพ หรืออื่นๆ งานบางอย่างสามารถทำได้ด้วย Open XML SDK แต่ไม่สามารถทำได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบ XML และแอตทริบิวต์ของเอกสาร OOXML อย่างโดยตรง คุณควรใช้ Open XML SDK

หากคุณต้องการทำงานที่ซับซ้อนบนเอกสาร—เช่นงานในรายการด้านล่าง—Aspose.Slides จะเป็นตัวเลือกที่ดีที่สุดของคุณ

- การดำเนินการที่เกี่ยวกับรูปแบบ PowerPoint เก่า (และ PPTX ด้วย)
- คัดลอกหรือทำสำเนารูปร่างภายในสไลด์โดยวิธีที่รวมวัตถุ, สไตล์, และองค์ประกอบการฟอร์แมตอื่นๆ อย่างเหมาะสม
- การแทนที่ข้อความที่มีการฟอร์แมตหรือไม่มีการฟอร์แมต
- การใส่เอฟเฟ็กต์การเคลื่อนไหวและใช้คอนเนคเตอร์กับรูปร่าง
- การแปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้มีลักษณะเหมือนที่ Microsoft PowerPoint ทำการแปลง
- การพัฒนาแอปพลิเคชัน .NET หรือ Java ทั้งในสภาพแวดล้อมเดสก์ท็อปและเว็บ
