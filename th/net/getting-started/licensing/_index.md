## **ภาพรวม**

Aspose.Slides สามารถใช้งานในโหมดประเมินผลหรือพร้อมใบอนุญาตที่ถูกต้องได้ เวอร์ชันประเมินผลให้ฟังก์ชันเดียวกับเวอร์ชันที่ได้รับใบอนุญาต แต่จะเพิ่มลายน้ำประเมินผลเมื่อเปิดหรือบันทึกงานนำเสนอและจำกัดการสกัดข้อความไว้ที่สไลด์หนึ่งสไลด์

บทความนี้อธิบายวิธีการทำงานของใบอนุญาตใน Aspose.Slides และวิธีการใช้ใบอนุญาตก่อนใช้ไลบรารี ใบอนุญาตสามารถโหลดจากไฟล์ สตรีม หรือทรัพยากรฝังตัวโดยใช้คลาส `License` บทความนี้ยังแสดงวิธีตรวจสอบว่าใบอนุญาตถูกนำไปใช้ถูกต้องหรือไม่

## **การให้ใบอนุญาตใน Aspose.Slides**
* เวอร์ชันประเมินผลจะกลายเป็นเวอร์ชันที่มีใบอนุญาตหลังจากคุณซื้อใบอนุญาตและเพิ่มบรรทัดโค้ดสองสามบรรทัด (เพื่อใช้ใบอนุญาต)  
* ใบอนุญาตเป็นไฟล์ XML แบบข้อความธรรมดาที่มีรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ได้รับใบอนุญาต วันที่หมดอายุการสมัครสมาชิก เป็นต้น  
* ไฟล์ใบอนุญาตถูกลงนามดิจิทัล ดังนั้นคุณต้องไม่แก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างเพิ่มเติมหนึ่งบรรทัดในเนื้อหาไฟล์ก็จะทำให้ใบอนุญาตไม่เป็นผล  
* Aspose.Slides for .NET จะพยายามค้นหาใบอนุญาตในตำแหน่งต่อไปนี้:  
  * เส้นทางที่ระบุโดยชัดเจน  
  * โฟลเดอร์ที่บรรจุ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides)  
  * โฟลเดอร์ที่บรรจุแอสเซมบลีที่เรียกใช้ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides)  
  * โฟลเดอร์ที่บรรจุแอสเซมบลีเริ่มต้น (ไฟล์ .exe ของคุณ)  
  * ทรัพยากรฝังตัวในแอสเซมบลีที่เรียกใช้ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides)  
* เพื่อหลีกเลี่ยงข้อจำกัดของเวอร์ชันประเมินผล คุณจำเป็นต้องตั้งค่าใบอนุญาตก่อนใช้ Aspose.Slides คุณต้องตั้งค่าใบอนุญาตเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

## **การใช้ใบอนุญาต**
ใบอนุญาตสามารถโหลดจาก **ไฟล์**, **สตรีม**, หรือ **ทรัพยากรฝังตัว**  

{{% alert color="info" %}}

Aspose.Slides มีคลาส[License](https://reference.aspose.com/slides/th/net/aspose.slides/license)สำหรับการทำงานเกี่ยวกับใบอนุญาต  

{{% /alert %}} 

{{% alert color="warning" %}} 

ใบอนุญาตใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับเวอร์ชัน 21.4 หรือใหม่กว่า เวอร์ชันก่อนหน้านั้นใช้ระบบใบอนุญาตแบบอื่นและจะไม่รับรู้ใบอนุญาตเหล่านี้  

{{% /alert %}}

### **ไฟล์**
วิธีที่ง่ายที่สุดในการตั้งค่าใบอนุญาตคือใส่ไฟล์ใบอนุญาตในโฟลเดอร์เดียวกับ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides) และระบุเฉพาะชื่อไฟล์โดยไม่ต้องใส่เส้นทาง  

โค้ด C# นี้แสดงวิธีตั้งค่าไฟล์ใบอนุญาต:  

``` csharp
// สร้างอินสแตนซ์ของคลาส License
Aspose.Slides.License license = new Aspose.Slides.License();

// ตั้งค่าพาธไฟล์ใบอนุญาต
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" %}} 

หากคุณวางไฟล์ใบอนุญาตในไดเรกทอรีอื่น เมื่อเรียกใช้เมธอด[SetLicense](https://reference.aspose.com/slides/th/net/aspose.slides/license/setlicense/#setlicense_1)ชื่อไฟล์ใบอนุญาตที่ส่วนท้ายของเส้นทางที่ระบุต้องตรงกับชื่อไฟล์ใบอนุญาตของคุณ  

เช่น คุณอาจเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น*Aspose.Slides.lic.xml* จากนั้นในโค้ดของคุณต้องส่งเส้นทางไปยังไฟล์ (ลงท้ายด้วย*Aspose.Slides.lic.xml*)ให้เมธอด[SetLicense](https://reference.aspose.com/slides/th/net/aspose.slides/license/setlicense/#setlicense_1)  

{{% /alert %}}

### **สตรีม**
คุณสามารถโหลดใบอนุญาตจากสตรีม โค้ด C# นี้แสดงวิธีใช้ใบอนุญาตจากสตรีม:  

``` csharp
// สร้างอินสแตนซ์ของคลาส License
Aspose.Slides.License license = new Aspose.Slides.License();

// เปิดไฟล์ใบอนุญาตเป็นสตรีม
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// ตั้งค่าใบอนุญาตผ่านสตรีม
license.SetLicense(licenseStream);
```

### **ทรัพยากรฝังตัว**
คุณสามารถบรรจุใบอนุญาตกับแอปพลิเคชันของคุณ (เพื่อหลีกเลี่ยงการสูญหาย) โดยเพิ่มไฟล์ใบอนุญาตเป็นทรัพยากรฝังตัวในหนึ่งในแอสเซมบลีที่เรียกใช้ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides)  

นี่คือวิธีเพิ่มไฟล์ใบอนุญาตเป็นทรัพยากรฝังตัว:

1. ใน Visual Studio เพิ่มไฟล์ใบอนุญาต(.lic) ไปยังโปรเจกต์โดยไปที่**File**>**Add Existing Item**>**Add**  
2. เลือกไฟล์ใน**Solution Explorer**  
3. ในหน้าต่าง**Properties**ตั้งค่า**Build Action**เป็น**Embedded Resource**  
4. เพื่อเข้าถึงใบอนุญาตที่ฝังอยู่ในแอสเซมบลี ให้เพิ่มไฟล์ใบอนุญาตเป็นทรัพยากรฝังตัวในโปรเจกต์ แล้วส่งชื่อไฟล์ใบอนุญาตให้เมธอด`SetLicense`  

คลาส`License`จะค้นหาไฟล์ใบอนุญาตในทรัพยากรฝังตัวโดยอัตโนมัติ คุณไม่จำเป็นต้องเรียกเมธอด`GetExecutingAssembly`และ`GetManifestResourceStream`ของคลาส`System.Reflection.Assembly`ใน Microsoft .NET Framework  

โค้ด C# นี้แสดงวิธีตั้งค่าใบอนุญาตเป็นทรัพยากรฝังตัว:  

``` csharp
// สร้างอินสแตนซ์ของคลาส License
Aspose.Slides.License license = new Aspose.Slides.License();

// ส่งชื่อไฟล์ใบอนุญาตที่ฝังไว้ในแอสเซมบลี
license.SetLicense("Aspose.Slides.lic");
```

## **ตรวจสอบใบอนุญาต**

เพื่อเช็คว่าใบอนุญาตถูกตั้งค่าอย่างถูกต้องหรือไม่ คุณสามารถตรวจสอบได้ โค้ด C# นี้แสดงวิธีตรวจสอบใบอนุญาต:  

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **FAQ**

### ฉันสามารถใช้ใบอนุญาตในสภาพแวดล้อมที่ไม่มีการเชื่อมต่ออินเทอร์เน็ตเลยได้หรือไม่?

ได้ การตรวจสอบใบอนุญาตทำงานแบบออฟไลน์โดยใช้ไฟล์ใบอนุญาต ไม่ต้องเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่ ใบอนุญาตเป็นแบบถาวร คุณสามารถใช้งานเวอร์ชันที่ปล่อยก่อนวันที่สิ้นสุดการสมัครสมาชิกได้ต่อไป เพียงแค่คุณจะไม่สามารถใช้เวอร์ชันใหม่กว่าได้หากไม่ได้ต่ออายุการสมัครสมาชิก
