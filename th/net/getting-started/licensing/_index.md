## **ภาพรวม**

Aspose.Slides สามารถใช้ได้ในโหมดประเมินหรือพร้อมใบอนุญาตที่ถูกต้อง เวอร์ชันประเมินให้ฟังก์ชันการทำงานเดียวกับเวอร์ชันที่มีใบอนุญาต แต่จะเพิ่มลายน้ำการประเมินลงในแต่ละสไลด์ของแต่ละการนำเสนอที่บันทึกและตัดข้อความที่โค้ดของคุณอ่านจากการนำเสนอ

บทความนี้อธิบายวิธีการทำงานของการให้ใบอนุญาตใน Aspose.Slides และวิธีการใช้ใบอนุญาตก่อนใช้ไลบรารี ใบอนุญาตสามารถโหลดจากไฟล์, สตรีม หรือทรัพยากรฝังโดยใช้คลาส `License` บทความนี้ยังแสดงวิธีการตรวจสอบว่าใบอนุญาตได้ถูกตั้งค่าอย่างถูกต้องหรือไม่

## **ประเมิน Aspose.Slides**

{{% alert color="info" title="Note" %}}
คุณสามารถดาวน์โหลดเวอร์ชันประเมินของ **Aspose.Slides for .NET** จาก[หน้าดาวน์โหลด NuGet ของมัน](https://www.nuget.org/packages/Aspose.Slides.NET/) เวอร์ชันประเมินให้ฟังก์ชันการทำงานเดียวกับเวอร์ชันที่มีใบอนุญาตของผลิตภัณฑ์ แพ็คเกจประเมินเหมือนกับแพ็คเกจที่ซื้อ เวอร์ชันประเมินจะกลายเป็นใบอนุญาตได้โดยเพียงเพิ่มบรรทัดโค้ดเล็กน้อย (เพื่อใช้ใบอนุญาต)

เมื่อคุณพอใจกับการประเมิน **Aspose.Slides** ของคุณแล้ว คุณสามารถ[ซื้อใบอนุญาต](https://purchase.aspose.com/pricing/slides/th/net/) เราแนะนำให้คุณตรวจสอบประเภทการสมัครสมาชิกต่าง ๆ หากมีคำถาม ติดต่อทีมขายของ Aspose

ทุกใบอนุญาตของ Aspose จะมาพร้อมการสมัครสมาชิกหนึ่งปีสำหรับการอัพเกรดฟรีไปยังเวอร์ชันใหม่หรือการแก้ไขที่ปล่อยภายในระยะการสมัครสมาชิก ผู้ใช้ที่มีผลิตภัณฑ์ที่มีใบอนุญาตหรือแม้แต่เวอร์ชันประเมินจะได้รับการสนับสนุนทางเทคนิคฟรีและไม่จำกัดจำนวน
{{% /alert %}} 

**ข้อจำกัดของเวอร์ชันการประเมิน**

* เวอร์ชันประเมิน (โดยไม่ได้ระบุใบอนุญาต) ให้ฟังก์ชันการทำงานเต็มรูปแบบของผลิตภัณฑ์ แต่จะเพิ่มกล่องข้อความลายน้ำการประเมินลงในแต่ละสไลด์ของแต่ละการนำเสนอที่บันทึก
* ข้อความที่โค้ดของคุณอ่านจากการนำเสนอจะถูกตัดให้เหลือเพียงไม่กี่อักขระแรก ตามด้วยข้อความแจ้งเกี่ยวกับข้อจำกัดของการประเมิน ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ

## **การให้ใบอนุญาตใน Aspose.Slides**
* เวอร์ชันประเมินจะกลายเป็นใบอนุญาตเมื่อคุณซื้อใบอนุญาตและเพิ่มบรรทัดโค้ดไม่กี่บรรทัด (เพื่อใช้ใบอนุญาต)
* ใบอนุญาตเป็นไฟล์ XML แบบข้อความธรรมดาที่มีรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ได้รับการอนุญาต, วันหมดอายุการสมัครสมาชิก เป็นต้น
* ไฟล์ใบอนุญาตถูกลงนามดิจิทัล ดังนั้นคุณจะต้องไม่แก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างเพิ่มเติมหนึ่งบรรทัดในเนื้อหาไฟล์ก็จะทำให้ไฟล์ใช้ไม่ได้
* Aspose.Slides for .NET มักจะค้นหาใบอนุญาตในตำแหน่งต่อไปนี้:
  * เส้นทางที่ระบุโดยชัดเจน
  * โฟลเดอร์ที่มี DLL ของคอมโพเนนต์ (รวมใน Aspose.Slides)
  * โฟลเดอร์ที่มี Assembly ที่เรียกใช้ DLL ของคอมโพเนนต์ (รวมใน Aspose.Slides)
  * โฟลเดอร์ที่มี Assembly เริ่มต้น (ไฟล์ .exe ของคุณ)
  * ทรัพยากรฝังใน Assembly ที่เรียกใช้ DLL ของคอมโพเนนต์ (รวมใน Aspose.Slides)
* เพื่อหลีกเลี่ยงข้อจำกัดของเวอร์ชันประเมิน คุณต้องตั้งค่าใบอนุญาตก่อนใช้ Aspose.Slides คุณต้องตั้งค่าใบอนุญาตเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

## **การใช้ใบอนุญาต**
ใบอนุญาตสามารถโหลดจาก **ไฟล์**, **สตรีม**, หรือ **ทรัพยากรฝัง** ได้

{{% alert color="info" title="Note" %}}
Aspose.Slides มีคลาส[License](https://reference.aspose.com/slides/th/net/aspose.slides/license) สำหรับการดำเนินการเกี่ยวกับใบอนุญาต
{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}
ใบอนุญาตใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับเวอร์ชัน 21.4 ขึ้นไป เวอร์ชันก่อนหน้านี้ใช้ระบบการให้ใบอนุญาตที่แตกต่างและจะไม่รับรู้ใบอนุญาตเหล่านี้
{{% /alert %}}

### **File**
วิธีที่ง่ายที่สุดในการตั้งค่าใบอนุญาตคือวางไฟล์ใบอนุญาตในโฟลเดอร์เดียวกับ DLL ของคอมโพเนนต์ (รวมใน Aspose.Slides) และระบุเฉพาะชื่อไฟล์โดยไม่ต้องระบุเส้นทาง

โค้ด C# นี้แสดงวิธีตั้งค่าไฟล์ใบอนุญาต:

``` csharp
// สร้างอินสแตนซ์ของคลาส License 
Aspose.Slides.License license = new Aspose.Slides.License();

// ตั้งค่าเส้นทางไฟล์ใบอนุญาต
license.SetLicense("Aspose.Slides.lic");
```

{{% alert color="warning" title="Warning" %}}
หากคุณวางไฟล์ใบอนุญาตในไดเรกทอรีอื่น เมื่อคุณเรียกใช้เมธอด[SetLicense](https://reference.aspose.com/slides/th/net/aspose.slides/license/setlicense/#setlicense_1) ชื่อไฟล์ใบอนุญาตที่อยู่ท้ายเส้นทางที่ระบุต้องตรงกับชื่อไฟล์ใบอนุญาตของคุณ

ตัวอย่างเช่น คุณสามารถเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น*Aspose.Slides.lic.xml* จากนั้นในโค้ดของคุณต้องส่งเส้นทางไปยังไฟล์ (ลงท้ายด้วย*Aspose.Slides.lic.xml*) ให้เมธอด[SetLicense](https://reference.aspose.com/slides/th/net/aspose.slides/license/setlicense/#setlicense_1)
{{% /alert %}}

### **Stream**
คุณสามารถโหลดใบอนุญาตจากสตรีมได้ โค้ด C# นี้แสดงวิธีใช้ใบอนุญาตจากสตรีม:

``` csharp
// สร้างอินสแตนซ์ของคลาส License
Aspose.Slides.License license = new Aspose.Slides.License();

// เปิดไฟล์ใบอนุญาตเป็นสตรีม
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// ตั้งค่าใบอนุญาตผ่านสตรีม
license.SetLicense(licenseStream);
```

### **Embedded Resource**
คุณสามารถบรรจุใบอนุญาตไว้ในแอปพลิเคชันของคุณ (เพื่อหลีกเลี่ยงการสูญหาย) โดยเพิ่มใบอนญาตเป็นทรัพยากรฝังในหนึ่งใน Assembly ที่เรียกใช้ DLL ของคอมโพเนนต์ (รวมใน Aspose.Slides)

วิธีเพิ่มไฟล์ใบอนุญาตเป็นทรัพยากรฝัง:

1. ใน Visual Studio เพิ่มไฟล์ใบอนุญาต(.lic) ไปยังโปรเจคโดยไปที่**File** > **Add Existing Item** > **Add**  
2. เลือกไฟล์ใน**Solution Explorer**  
3. ในหน้าต่าง**Properties** ตั้งค่า**Build Action**เป็น**Embedded Resource**  
4. เพื่อเข้าถึงใบอนุญาตที่ฝังอยู่ใน Assembly ให้เพิ่มไฟล์ใบอนุญาตเป็นทรัพยากรฝังในโปรเจค แล้วส่งชื่อไฟล์ใบอนุญาตให้เมธอด`SetLicense`

คลาส`License`จะค้นหาไฟล์ใบอนุญาตในทรัพยากรฝังโดยอัตโนมัติ คุณไม่จำเป็นต้องเรียกเมธอด`GetExecutingAssembly`และ`GetManifestResourceStream`ของคลาส`System.Reflection.Assembly`ใน Microsoft .NET Framework

โค้ด C# นี้แสดงวิธีตั้งค่าใบอนุญาตเป็นทรัพยากรฝัง:

``` csharp
// สร้างอินสแตนซ์ของคลาส License
Aspose.Slides.License license = new Aspose.Slides.License();

// ส่งชื่อไฟล์ใบอนุญาตที่ฝังอยู่ใน assembly
license.SetLicense("Aspose.Slides.lic");
```

## **ตรวจสอบใบอนุญาต**

เพื่อเช็คว่ามีการตั้งค่าใบอนุญาตอย่างเหมาะสมหรือไม่ คุณสามารถตรวจสอบได้ โค้ด C# นี้แสดงการตรวจสอบใบอนุญาต:

```c#
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## **FAQ**

### ฉันสามารถใช้ใบอนุญาตในสภาพแวดล้อมที่ไม่มีการเชื่อมต่ออินเทอร์เน็ตได้หรือไม่ (ไม่มีการเข้าถึงอินเทอร์เน็ต)?

ได้ การตรวจสอบใบอนุญาตทำงานในเครื่องโดยใช้ไฟล์ใบอนุญาต; ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่ ใบอนุญาตเป็นแบบถาวร: คุณสามารถใช้งานเวอร์ชันที่ปล่อยก่อนวันที่สิ้นสุดการสมัครสมาชิกของคุณต่อไปได้; แต่คุณจะไม่สามารถใช้เวอร์ชันใหม่ ๆ ได้หากไม่ได้ต่ออายุ
