## **การประเมิน Aspose.Slides**

คุณสามารถดาวน์โหลด Aspose.Slides เพื่อการประเมินได้ แพ็คเกจการประเมินเหมือนกับแพ็คเกจที่ซื้อ; จะได้รับใบอนุญาตหลังจากคุณเพิ่มโค้ดไม่กี่บรรทัดเพื่อใช้ใบอนุญาต

หากไม่มีใบอนุญาต Aspose.Slides จะให้ฟังก์ชันเต็มในโหมดประเมิน โดยมีข้อจำกัดสองประการ: จะเพิ่มกล่องข้อความลายน้ำการประเมินในทุกสไลด์ของพรีเซนเทชันที่บันทึก และข้อความที่โค้ดของคุณอ่านจากพรีเซนเทชันจะถูกตัดสั้นเหลือเพียงไม่กี่ตัวอักษรแรก ตามด้วยคำแจ้งเกี่ยวกับข้อจำกัดการประเมิน ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกอย่างเต็มที่

![สไลด์ที่มีลายน้ำการประเมิน](evaluate-aspose-slides_1.png)

หากคุณต้องการทดสอบ Aspose.Slides โดยไม่ต้องเผชิญกับข้อจำกัดของรุ่นประเมิน คุณสามารถขอ **ใบอนุญาตชั่วคราว 30 วัน** ได้ โปรดดูที่ [วิธีขอรับใบอนุญาตชั่วคราว?](https://purchase.aspose.com/temporary-license) สำหรับข้อมูลเพิ่มเติม.

## **ติดตั้งแพ็คเกจการประเมิน**

```bash
dotnet add package Aspose.Slides.NET
```

บน Linux และ macOS คุณสามารถใช้แพ็คเกจ Aspose.Slides.NET6.CrossPlatform แทน; ดูที่ [การติดตั้ง](/slides/th/net/installation/).

## **ใช้ใบอนุญาต**

นี่คือ “โค้ดไม่กี่บรรทัด” ที่ทำให้แพ็คเกจการประเมินกลายเป็นแบบมีใบอนุญาต ใช้ใบอนุญาตหนึ่งครั้งเมื่อตัวแอปพลิเคชันเริ่มทำงาน ก่อนที่ออบเจ็กต์ `Presentation` ใดจะถูกสร้าง — พรีเซนเทชันที่สร้างก่อนหน้านี้จะคงลายน้ำการประเมินไว้

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` ยังรับ `Stream` อีกด้วย ซึ่งเป็นตัวเลือกที่ดีกว่าเมื่อใบอนุญาตถูกฝังเป็นทรัพยากรแทนที่จะเป็นไฟล์บนดิสก์ หากเส้นทางผิดหรือไฟล์หมดอายุ การเรียกจะโยนข้อยกเว้น ทำให้การล้มเหลวปรากฏทันทีเมื่อตัวแอปพลิเคชันเริ่มทำงาน แทนที่จะกลับไปเป็นโหมดประเมินอย่างเงียบๆ

เมื่อใบอนุญาตถูกใช้ พรีเซนเทชันที่บันทึกจะไม่มีลายน้ำอีกต่อไป และข้อความจะถูกอ่านอย่างเต็มที่

## **คำถามที่พบบ่อย**

### ฉันสามารถทดสอบพรีเซนเทชันหลายชุดพร้อมกันในเธรดต่างๆ ในโหมดประเมินได้หรือไม่?
ได้. คุณสามารถประมวลผลเอกสารต่างๆ พร้อมกันได้; คุณไม่ควรแชร์ออบเจ็กต์พรีเซนเทชันเดียวกัน [ข้ามเธรด](/slides/th/net/multithreading/) โหมดประเมินไม่ส่งผลต่อเรื่องนี้.

### ฉันต้องติดตั้ง Microsoft PowerPoint เพื่อประเมินไลบรารีบนเซิร์ฟเวอร์หรือใน CI หรือไม่?
ไม่. Aspose.Slides เป็นเอนจินแบบสแตนด์อโลนและไม่ต้องการให้ติดตั้ง PowerPoint ทั้งสำหรับการประเมินหรือการใช้งานจริง.

### ฉันสามารถทดสอบการแปลง PPT/PPTX เป็น PDF และรูปภาพอย่างเต็มที่ในโหมดประเมินได้หรือไม่?
ได้. ตัว [ตัวแปลง](/slides/th/net/convert-presentation/) ทำงาน; ผลลัพธ์จะมีลายน้ำ.

### ฉันสามารถใช้ใบอนุญาตชั่วคราวสำหรับการทดสอบโหลดโดยไม่ต้องมีลายน้ำได้หรือไม่?
ได้. ใบอนุญาตชั่วคราว 30 วันจะลบข้อจำกัดของโหมดประเมินและอนุญาตให้ทดสอบโดยไม่มีลายน้ำ.
