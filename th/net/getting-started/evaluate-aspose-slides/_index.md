## **การประเมิน Aspose.Slides**

คุณสามารถดาวน์โหลด Aspose.Slides เพื่อการประเมินได้ แพ็คเกจการประเมินมีลักษณะเดียวกับแพ็คเกจที่ซื้อ; จะกลายเป็นมีลิขสิทธิ์หลังจากคุณเพิ่มบรรทัดโค้ดไม่กี่บรรทัดเพื่อใช้ลิขสิทธิ์

หากไม่มีลิขสิทธิ์ Aspose.Slides จะให้ฟังก์ชันเต็มในโหมดการประเมิน โดยมีข้อจำกัดสองข้อ: จะใส่กล่องข้อความลายน้ำการประเมินบนทุกสไลด์ของแต่ละงานนำเสนอที่บันทึก, และข้อความที่โค้ดของคุณอ่านจากงานนำเสนอจะถูกตัดให้เหลือเพียงไม่กี่อักขระแรก ตามด้วยคำแจ้งเกี่ยวกับข้อจำกัดการประเมิน. ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ.

![สไลด์ที่มีลายน้ำการประเมิน](evaluate-aspose-slides_1.png)

{{% alert color="info" title="Note" %}}
หากคุณต้องการทดสอบ Aspose.Slides โดยไม่มีข้อจำกัดของรุ่นการประเมิน คุณสามารถขอ **ลิขสิทธิ์ชั่วคราว 30 วัน** ได้ โปรดดูที่ [วิธีขอรับลิขสิทธิ์ชั่วคราว?](https://purchase.aspose.com/temporary-license) สำหรับข้อมูลเพิ่มเติม.

## **ติดตั้งแพ็คเกจการประเมิน**

```bash
dotnet add package Aspose.Slides.NET
```

บน Linux และ macOS คุณสามารถใช้แพ็คเกจ Aspose.Slides.NET6.CrossPlatform แทน; ดูที่ [การติดตั้ง](/slides/th/net/installation/).

## **ใช้ลิขสิทธิ์**

นี่คือ "บรรทัดโค้ดไม่กี่บรรทัด" ที่ทำให้แพ็คเกจการประเมินกลายเป็นแบบที่มีลิขสิทธิ์ ใช้ลิขสิทธิ์ครั้งเดียวเมื่อแอปพลิเคชันเริ่มทำงาน ก่อนที่อ็อบเจ็กต์ `Presentation` ใดจะถูกสร้าง — งานนำเสนอที่สร้างก่อนหน้านี้จะยังคงมีลายน้ำการประเมิน.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` ยังรับ `Stream` อีกด้วย ซึ่งเป็นตัวเลือกที่ดีกว่าเมื่อลิขสิทธิ์ถูกจัดส่งเป็นทรัพยากรฝังตัวแทนไฟล์บนดิสก์ หากเส้นทางผิดหรือไฟล์หมดอายุ คำเรียกจะโยนข้อยกเว้น, ทำให้ความล้มเหลวปรากฏทันทีเมื่อตัวแอปเริ่มทำงาน แทนที่จะกลับสู่โหมดการประเมินโดยเงียบ ๆ.

เมื่อลิขสิทธิ์ถูกใช้ งานนำเสนอที่บันทึกแล้วจะไม่มีลายน้ำอีกต่อไปและข้อความจะถูกอ่านเต็มรูปแบบ.

## **คำถามที่พบบ่อย**

### ฉันสามารถทดสอบงานนำเสนอหลายไฟล์พร้อมกันในเธรดต่าง ๆ ในโหมดการประเมินได้หรือไม่?
ได้ คุณสามารถประมวลผลเอกสารต่าง ๆ พร้อมกันได้; คุณไม่ควรแชร์อ็อบเจ็กต์งานนำเสนอเดียวกัน [ข้ามเธรด](/slides/th/net/multithreading/). โหมดการประเมินไม่ได้ส่งผลต่อสิ่งนี้.

### ฉันจำเป็นต้องติดตั้ง Microsoft PowerPoint เพื่อประเมินไลบรารีบนเซิร์ฟเวอร์หรือใน CI หรือไม่?
ไม่ Aspose.Slides เป็นเครื่องยนต์อิสระและไม่จำเป็นต้องติดตั้ง PowerPoint ทั้งในโหมดการประเมินหรือการผลิต.

### ฉันสามารถทดสอบการแปลงไฟล์ PPT/PPTX ไปเป็น PDF และภาพอย่างเต็มที่ในโหมดการประเมินได้หรือไม่?
ได้ ตัวแปลง [การแปลง](/slides/th/net/convert-presentation/) ทำงาน; ผลลัพธ์จะมีลายน้ำ.

### ฉันสามารถใช้ลิขสิทธิ์ชั่วคราวสำหรับการทดสอบโหลดโดยไม่มีลายน้ำได้หรือไม่?
ได้ ลิขสิทธิ์ชั่วคราว 30 วันจะลบข้อจำกัดของโหมดการประเมินและให้การทดสอบโดยไม่มีลายน้ำ.
