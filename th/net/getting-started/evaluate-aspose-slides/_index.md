## **การประเมินผล Aspose.Slides**

คุณสามารถดาวน์โหลด Aspose.Slides เพื่อการประเมินได้อย่างง่ายดาย แพ็กเกจการประเมินเป็นเหมือนกับแพ็กเกจที่ซื้อ เวอร์ชันการประเมินจะกลายเป็นมีลิขสิทธิ์หลังจากที่คุณเพิ่มโค้ดไม่กี่บรรทัดเพื่อใช้งานลิขสิทธิ์

เวอร์ชันการประเมินของ Aspose.Slides (โดยไม่ได้ระบุลิขสิทธิ์) ให้ฟังก์ชันการทำงานของผลิตภัณฑ์เต็มรูปแบบ แต่จะแทรกลายน้ำการประเมินที่ด้านบนของเอกสารเมื่อเปิดหรือบันทึก อีกทั้งคุณยังถูกจำกัดให้เฉพาะหนึ่งสไลด์เมื่อสกัดข้อความจากสไลด์การนำเสนอ

## **ติดตั้งแพ็กเกจการประเมิน**

```bash
dotnet add package Aspose.Slides.NET
```

## **ประยุกต์ใช้ลิขสิทธิ์**

นี่คือ “โค้ดไม่กี่บรรทัด” ที่ทำให้แพ็กเกจการประเมินกลายเป็นแบบที่มีลิขสิทธิ์ ให้ใช้ลิขสิทธิ์ครั้งเดียวเมื่อตัวแอปพลิเคชันเริ่มทำงาน ก่อนที่จะสร้างอ็อบเจกต์ `Presentation` ใด ๆ — การนำเสนอที่สร้างไว้ก่อนหน้านี้จะยังคงมีลายน้ำการประเมิน

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` ยังรับ `Stream` ซึ่งเป็นตัวเลือกที่ดีกว่าเมื่อไลเซนส์ถูกจัดส่งเป็นทรัพยากรฝังตัวแทนไฟล์บนดิสก์ หากเส้นทางผิดหรือไฟล์หมดอายุ คำเรียกจะโยนข้อผิดพลาด ทำให้การล้มเหลวปรากฏทันทีเมื่อตัวแอปพลิเคชันเริ่มทำงาน แทนที่จะกลับสู่โหมดการประเมินอย่างเงียบ ๆ

เมื่อใช้ลิขสิทธิ์แล้ว ลายน้ำจะหายไปและข้อจำกัดการสกัดข้อความจากหนึ่งสไลด์จะถูกยกเลิก

## **คำถามที่พบบ่อย**

### ฉันสามารถทดสอบหลายการนำเสนอพร้อมกันข้ามเธรดต่าง ๆ ในโหมดการประเมินได้หรือไม่?
ใช่ คุณสามารถประมวลผลเอกสารต่าง ๆ พร้อมกันได้; คุณไม่ควรแชร์อ็อบเจกต์การนำเสนอเดียวกัน [ข้ามเธรด](/slides/th/net/multithreading/) โหมดการประเมินไม่ได้มีผลต่อเรื่องนี้.

### ฉันจำเป็นต้องติดตั้ง Microsoft PowerPoint เพื่อประเมินไลบรารีบนเซิร์ฟเวอร์หรือใน CI หรือไม่?
ไม่ Aspose.Slides เป็นเอนจินแบบสแตนด์อโลนและไม่จำเป็นต้องติดตั้ง PowerPoint ทั้งในโหมดการประเมินหรือการผลิต.

### ฉันสามารถทดสอบการแปลง PPT/PPTX เป็น PDF และภาพอย่างเต็มรูปแบบในโหมดการประเมินได้หรือไม่?
ใช่ [ตัวแปลง](/slides/th/net/convert-presentation/) ทำงาน; ผลลัพธ์จะมีลายน้ำ.

### ฉันสามารถใช้ใบอนุญาตชั่วคราวสำหรับการทดสอบโหลดโดยไม่มีลายน้ำได้หรือไม่?
ใช่ ใบอนุญาตชั่วคราว 30 วันจะลบข้อจำกัดของโหมดการประเมินและทำให้สามารถทดสอบโดยไม่มีลายน้ำ.
