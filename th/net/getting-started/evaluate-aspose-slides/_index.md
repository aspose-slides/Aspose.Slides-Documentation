## **การประเมิน Aspose.Slides**

คุณสามารถดาวน์โหลด Aspose.Slides เพื่อการประเมินได้อย่างง่ายดาย แพคเกจการประเมินมีลักษณะเดียวกับแพคเกจที่ซื้อแล้ว เวอร์ชันการประเมินจะกลายเป็นลิขสิทธิ์ได้ทันทีหลังจากคุณเพิ่มโค้ดไม่กี่บรรทัดเพื่อใช้ใบอนุญาต

เวอร์ชันการประเมินของ Aspose.Slides (โดยไม่มีการระบุใบอนุญาต) ให้ฟังก์ชันการทำงานของผลิตภัณฑ์เต็มรูปแบบ แต่จะใส่น้ำลายน้ำการประเมินที่ด้านบนของเอกสารเมื่อเปิดหรือบันทึก คุณยังถูกจำกัดให้ใช้หนึ่งสไลด์เมื่อสกัดข้อความจากสไลด์การนำเสนอ

## **ติดตั้งแพคเกจการประเมิน**

```bash
dotnet add package Aspose.Slides.NET
```

## **ใช้ใบอนุญาต**

นี่คือ “โค้ดไม่กี่บรรทัด” ที่ทำให้แพคเกจการประเมินกลายเป็นรุ่นที่มีลิขสิทธิ์ ใช้ใบอนุญาตเพียงครั้งเดียวเมื่อตัวแอปพลิเคชันเริ่มทำงาน ก่อนที่จะสร้างอ็อบเจกต์ `Presentation` ใดๆ – การนำเสนอที่สร้างไว้ก่อนหน้านี้จะยังคงมีน้ำลายน้ำการประเมิน.

```csharp
using Aspose.Slides;

var license = new License();
license.SetLicense("Aspose.Slides.NET.lic");
```

`SetLicense` ยังรับพารามิเตอร์เป็น `Stream` ซึ่งเป็นตัวเลือกที่ดีกว่าเมื่อใบอนุญาตถูกส่งเป็นทรัพยากรฝังตัวแทนไฟล์บนดิสก์ หากเส้นทางไม่ถูกต้องหรือไฟล์หมดอายุ การเรียกจะทำให้เกิดข้อยกเว้น ดังนั้นความล้มเหลวจะแสดงขึ้นทันทีเมื่อตัวแอปเริ่มทำงานแทนที่จะกลับไปเป็นโหมดการประเมินอย่างเงียบๆ

เมื่อใช้ใบอนุญาตแล้ว น้ำลายน้ำจะหายไปและข้อจำกัดการสกัดข้อความจากหนึ่งสไลด์จะถูกยกเลิก.

## **คำถามที่พบบ่อย**

### ฉันสามารถทดสอบหลายการนำเสนอพร้อมกันในหลายเธรดในโหมดการประเมินได้หรือไม่?
ใช่ คุณสามารถประมวลผลเอกสารต่างๆ พร้อมกันได้; คุณไม่ควรแชร์อ็อบเจกต์การนำเสนอเดียวกัน [across threads](/slides/th/net/multithreading/) โหมดการประเมินจะไม่กระทบต่อสิ่งนี้.

### ฉันต้องติดตั้ง Microsoft PowerPoint เพื่อประเมินไลบรารีบนเซิร์ฟเวอร์หรือใน CI หรือไม่?
ไม่. Aspose.Slides เป็นเอนจินแบบสแตนด์อโลนและไม่ต้องการให้ติดตั้ง PowerPoint ทั้งในโหมดประเมินและการผลิต.

### ฉันสามารถทดสอบการแปลง PPT/PPTX เป็น PDF และรูปภาพอย่างเต็มที่ในโหมดการประเมินได้หรือไม่?
ใช่ ตัว [converters](/slides/th/net/convert-presentation/) ทำงาน; ผลลัพธ์จะมีน้ำลายน้ำ.

### ฉันสามารถใช้ใบอนุญาตชั่วคราวสำหรับการทดสอบโหลดโดยไม่มีน้ำลายน้ำได้หรือไม่?
ใช่ ใบอนุญาตชั่วคราว 30 วันจะลบข้อจำกัดของโหมดการประเมินและทำให้สามารถทดสอบโดยไม่มีน้ำลายน้ำ.
