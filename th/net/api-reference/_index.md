Aspose.Slides for .NET เป็นไลบรารีคลาสที่ช่วยให้แอปพลิเคชัน .NET สามารถอ่านและเขียนเอกสารการนำเสนอได้โดยไม่ต้องใช้ Microsoft PowerPoint® หรือโปรแกรมอื่น ๆ Aspose.Slides for .NET อนุญาตให้จัดการข้อความ รูปร่าง ตารางและแอนิเมชัน เพิ่มเสียงและวิดีโอบนสไลด์ ดูตัวอย่างสไลด์ ส่งออกสไลด์เป็นรูปแบบ SVG, PDF และอื่น ๆ

สามารถพบคำอ้างอิง API ล่าสุดได้ที่ [Aspose.Slides for .NET API Reference](https://reference.aspose.com/slides/th/net).
