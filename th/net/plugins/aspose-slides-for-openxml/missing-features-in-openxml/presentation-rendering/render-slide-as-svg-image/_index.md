SVG—ย่อมาจาก Scalable Vector Graphics—เป็นประเภทหรือรูปแบบกราฟิกมาตรฐานที่ใช้ในการเรนเดอร์ภาพสองมิติ. SVG เก็บภาพเป็นเวกเตอร์ใน XML พร้อมด้วยรายละเอียดที่กำหนดพฤติกรรมหรือรูปลักษณ์ของภาพ  

SVG เป็นหนึ่งในรูปแบบภาพไม่กี่รูปแบบที่ตอบสนองมาตรฐานสูงในแง่ต่อไปนี้: ความสามารถในการปรับขนาด, ความโต้ตอบ, ประสิทธิภาพ, การเข้าถึง, ความสามารถในการเขียนโปรแกรม, และอื่น ๆ. ด้วยเหตุผลเหล่านี้จึงมักถูกใช้ในการพัฒนาเว็บ  

คุณอาจต้องการใช้ไฟล์ SVG ในสถานการณ์ต่อไปนี้:

- เมื่อคุณวางแผนพิมพ์งานนำเสนอของคุณในรูปแบบขนาดใหญ่มาก. ภาพ SVG สามารถปรับขนาดได้ถึงความละเอียดหรือระดับใดก็ได้. คุณสามารถปรับขนาดภาพ SVG จำนวนหลายครั้งโดยไม่ลดคุณภาพ
- เมื่อคุณต้องการใช้แผนภูมิและกราฟจากสไลด์ของคุณในสื่อหรือแพลตฟอร์มต่าง ๆ. ผู้อ่านส่วนใหญ่สามารถตีความไฟล์ SVG ได้
- เมื่อคุณต้องการใช้ขนาดของภาพที่เล็กที่สุดเท่าที่จะเป็นไปได้. ไฟล์ SVG มักมีขนาดเล็กกว่าความละเอียดสูงของรูปแบบอื่น ๆ, โดยเฉพาะรูปแบบที่อิงบิตแมพ (JPEG หรือ PNG)

Aspose.Slides for .NET ให้คุณส่งออกสไลด์ในงานนำเสนอของคุณเป็นภาพ **SVG**. เพื่อสร้างภาพ SVG จากใด ๆ ทำตามขั้นตอนต่อไปนี้:

- สร้างอินสแตนซ์ของคลาส Presentation
- วนซ้ำผ่านสไลด์ทั้งหมดในงานนำเสนอ
- เขียนแต่ละสไลด์เป็นไฟล์ SVG แยกกันโดยใช้ FileStream

{{% alert color="info" %}} 
คุณอาจต้องการลองใช้[แอปพลิเคชันเว็บฟรี](https://products.aspose.app/slides/th/conversion/ppt-to-svg)ของเรา ซึ่งเราได้ทำฟังก์ชันการแปลง PPT เป็น SVG จาก Aspose.Slides for .NET
{{% /alert %}} 

โค้ดตัวอย่างนี้ใน C# แสดงวิธีแปลง PPT เป็น SVG ด้วย Aspose.Slides:

``` csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("pres.pptx"))
{
    for (var index = 0; index < pres.Slides.Count; index++)
    {
        ISlide slide = pres.Slides[index];

        using (FileStream fileStream = new FileStream($"slide-{index}.svg", FileMode.Create, FileAccess.Write))
        {
            slide.WriteAsSvg(fileStream);   
        }
    }
}
```
