## **เมลเมิร์จในงานนำเสนอ PowerPoint**

Aspose.Slides for .NET ช่วยให้คุณสร้างงานนำเสนอ PowerPoint โดยอัตโนมัติจากเทมเพลตและแหล่งข้อมูล เมลเมิร์จจะเติมค่าลงในตัวพักของเทมเพลตและสร้างงานนำเสนอเดียวที่มีสไลด์เทมเพลตซ้ำสำหรับแต่ละชุดข้อมูลหรือสร้างงานนำเสนอแยกต่างหากสำหรับแต่ละชุดข้อมูล

ฟังก์ชันนี้มีประโยชน์สำหรับการสร้างแค็ตาล็อกสินค้า งานนำเสนอส่วนบุคคล รายงาน ใบรับรอง ข้อเสนอ รายการราคา และเอกสารอื่น ๆ ที่โครงสร้างของงานนำเสมออยู่แต่เนื้อหาต่างกัน

![Mail Merge: before and after](mail-merge-before-after.png)


## **วิธีทำงานของเมลเมิร์จ**

เมลเมิร์จกำหนดงานนำเสนอ PowerPoint เป็นเทมเพลตและแทนที่ตัวพักด้วยค่าจากแหล่งข้อมูล

![Mail Merge workflow](mail-merge-workflow.png)

ตัวพักคือชื่อฟิลด์ที่อยู่ในวงเล็บเหลี่ยมคู่ เช่น `{{title}}` หรือ `{{price}}` ตัวพักสามารถใส่ในข้อความของรูปทรง เซลล์ตาราง รูปทรงที่จัดกลุ่ม และโน้ตของผู้พูดได้

ตัวอย่างเช่น สไลด์เทมเพลตอาจมีข้อความต่อไปนี้:

- `Product: {{title}}`
- `Price: {{price}}`
- `Description: {{description}}`

เมื่อแหล่งข้อมูลมีค่าดังต่อไปนี้:

| Field | Value |
|---|---|
| title | Laptop X1 |
| price | $999 |
| description | 14‑inch display, 16 GB RAM |

เมลเมิร์จจะแทนที่ตัวพักด้วยค่าที่สอดคล้องกัน ทำให้ได้สไลด์ที่มีข้อมูลสินค้าจริง

ชื่อฟิลด์ไม่สนใจตัวพิมพ์ใหญ่‑เล็ก ดังนั้น `{{title}}` และ `{{Title}}` อ้างถึงฟิลด์เดียวกัน

กฎต่อไปนี้ใช้เมื่อแทนที่ตัวพัก:

- ตัวพักจะถูกแทนที่ในสไลด์รวมถึงรูปทรงที่จัดกลุ่มและเซลล์ตาราง รวมถึงโน้ตของผู้พูด
- ตัวพักบนมาสเตอร์สไลด์และเลย์เอาท์สไลด์จะไม่ถูกแทนที่
- ตัวพักที่ฟิลด์ไม่อยู่ในชุดข้อมูลจะคงอยู่โดยไม่เปลี่ยนแปลง
- ค่าฟิลด์ว่างจะแทนที่ตัวพักด้วยสตริงว่าง
- ข้อความที่แทรกจะสืบทอดการจัดรูปแบบของอักษรตัวแรกของตัวพัก
- ค่าจะต้องไม่ประกอบด้วยข้อความตัวพัก เพราะข้อความที่แทรกอาจถูกประมวลผลซ้ำและแทนที่ด้วยฟิลด์อื่น

เทมเพลตต้นฉบับจะไม่ถูกแก้ไขระหว่างกระบวนการเมอร์จและต้องมีสไลด์อย่างน้อยหนึ่งสไลด์

## **แหล่งข้อมูลที่รองรับ**

เมลเมิร์จรองรับวิธีการให้ข้อมูลสองแบบ:

- สร้างแหล่งข้อมูลโปรแกรมmatically ด้วย `IMailMergeDataSource`
- อ่านข้อมูลจากไฟล์หรือสตรีม CSV, XLSX, JSON หรือ XML

รูปแบบข้อมูลจะถูกตรวจจับจากเนื้อหา ไม่ได้อิงจากส่วนขยายไฟล์ สตรีมที่ไม่รองรับการ seek ก็ได้รับการสนับสนุนเช่นกัน

แหล่งข้อมูลต้องมีอย่างน้อยหนึ่งชุดข้อมูล แต่ละชุดข้อมูลแทนหนึ่งสำเนาของเทมเพลตที่จะถูกเติมค่าตามข้อมูลของชุดนั้น

หากไม่สามารถจำแนกรูปแบบข้อมูลเป็นรูปแบบที่รองรับ `NotSupportedException` จะถูกโยน หากรูปแบบถูกจำแนกแต่ไม่เป็นไปตามข้อกำหนด `InvalidDataException` จะถูกโยน ข้อความของข้อยกเว้นจะบอกตำแหน่งของข้อผิดพลาดในข้อมูล

### **JSON**

แหล่งข้อมูล JSON ต้องมีออบเจ็กต์รากที่มีแอเรย์ `sets` แต่ละสมาชิกของแอเรย์แทนชุดข้อมูลและต้องมีแอเรย์ `fields` ทุกฟิลด์ต้องมีสตริง `name` และ `value`

คุณสมบัติ `version` ที่ไม่จำเป็นต้องเป็น `"1.0"` และคุณสมบัติ `type` ของฟิลด์ที่ไม่จำเป็นต้องเป็น `"text"` ชื่อคุณสมบัติจะแยกแยะตามตัวอักษร (case‑sensitive) คุณสมบัติที่ไม่รู้จักจะถูกละเว้น

JSON จะอ่านเป็น UTF‑8 หรือ UTF‑16 เมื่อข้อมูลเริ่มต้นด้วย byte order mark (BOM)

ตัวอย่างต่อไปนี้มีสองชุดข้อมูล:

```json
{
  "version": "1.0",
  "sets": [
    {
      "fields": [
        { "name": "title", "value": "Laptop X1" },
        { "name": "price", "value": "$999" }
      ]
    },
    {
      "fields": [
        { "name": "title", "value": "Tablet S2" },
        { "name": "price", "value": "$499" }
      ]
    }
  ]
}
```

### **XML**

แหล่งข้อมูล XML ต้องมีอิลิเมนต์ราก `template` ที่มีอิลิเมนต์ `sets` ทุกอิลิเมนต์ `set` มีอิลิเมนต์ `field` และแต่ละฟิลด์ต้องมีอิลิเมนต์ `name` และ `value`

อิลิเมนต์ `value` ที่ว่างจะถือเป็นสตริงว่าง ชื่ออิลิเมนต์แยกแยะตามตัวอักษร (case‑sensitive) อิลิเมนต์และคอมเมนต์ที่ไม่รู้จักจะถูกละเว้น การเข้ารหัสจะกำหนดโดยประกาศ XML DTD ไม่ได้รับอนุญาต

```xml
<?xml version="1.0" encoding="utf-8"?>
<template>
  <sets>
    <set>
      <field>
        <name>title</name>
        <value>Laptop X1</value>
      </field>
      <field>
        <name>price</name>
        <value>$999</value>
      </field>
    </set>
    <set>
      <field>
        <name>title</name>
        <value>Tablet S2</value>
      </field>
      <field>
        <name>price</name>
        <value>$499</value>
      </field>
    </set>
  </sets>
</template>
```

### **CSV**

CSV ใช้เครื่องหมายเซมิโคลอนเป็นตัวคั่นค่า

แถวแรกมีชื่อฟิลด์และสิ้นสุดที่ชื่อฟิลด์ว่างแรก ทุกแถวถัดไปแทนหนึ่งชุดข้อมูล ข้อมูลสิ้นสุดที่แถวว่างแรก

กฎต่อไปนี้ใช้:

- ค่าที่ขาดหายในตอนท้ายของแถวจะถือเป็นสตริงว่าง
- ค่าที่อยู่หลังชื่อฟิลด์ที่กำหนดจะถูกละเว้น
- ค่าที่มีเซมิโคลอน เครื่องหมายอัญประกาศ หรือการขึ้นบรรทัดใหม่ต้องอยู่ในเครื่องหมายอัญประกาศ
- เครื่องหมายอัญประกาศภายในค่าที่อยู่ในอัญประกาศต้องทำซ้ำสองครั้ง
- ข้อมูลจะอ่านเป็น UTF‑8 หรือ UTF‑16 เมื่อเริ่มต้นด้วย BOM

ตัวอย่าง:

```csv
title;price;description
Laptop X1;$999;"14"" display; 16 GB RAM"
Tablet S2;$499;
```

### **XLSX**

XLSX จะอ่านจากเวิร์กชีตแรก

เวิร์กชีตใช้กฎเดียวกับ CSV:

- แถวแรกมีชื่อฟิลด์และสิ้นสุดที่เซลล์ว่างแรก
- แถวต่อไปแต่ละแถวแทนชุดข้อมูลหนึ่งชุด
- ข้อมูลสิ้นสุดที่แถวว่างแรก
- เซลล์ว่างถือเป็นสตริงว่าง
- ค่าตัวเลขจะถูกแปลงเป็นข้อความโดยใช้ invariant culture

## **สร้างงานนำเสนอเดียว**

เมธอด `MergeToSinglePresentation` สร้างงานนำเสนอหนึ่งไฟล์ที่มีสำเนาสไลด์เทมเพลตสำหรับทุกชุดข้อมูล แต่ละสำเนาจะเติมค่าตามข้อมูลที่สอดคล้อง

ลำดับของชุดข้อมูลกำหนดลำดับของกลุ่มสไลด์ในงานนำเสนอผลลัพธ์

### **เมอร์จข้อมูลจากไฟล์**

ตัวอย่างต่อไปนี้โหลดเทมเพลตและไฟล์ข้อมูล JSON สร้างงานนำเสนอเดียวที่มีสไลด์สำหรับทุกชุดข้อมูลและบันทึกผลลัพธ์

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, "products.json"))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

ข้อมูลสามารถอ่านจากสตรีมได้ สตรีมจะอ่านตั้งแต่ตำแหน่งปัจจุบันและไม่ถูกปิดโดยเมลเมิร์จ

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xml"))
using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, data))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

### **สร้างแหล่งข้อมูลในโค้ด**

คุณสามารถสร้างแหล่งข้อมูลโปรแกรมmatically ด้วย `MailMergeDataSource` และ `MailMergeDataSet` เพิ่มชุดข้อมูลสำหรับแต่ละระเบียนและกำหนดฟิลด์โดยใช้เมธอด `AddText`

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet laptop = source.AddDataSet();
laptop.AddText("title", "Laptop X1");
laptop.AddText("price", "$999");

IMailMergeDataSet tablet = source.AddDataSet();
tablet.AddText("title", "Tablet S2");
tablet.AddText("price", "$499");

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, source))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

ในตัวอย่างนี้สไลด์เทมเพลตจะถูกทำซ้ำสองครั้ง: ครั้งหนึ่งสำหรับแล็ปท็อปและอีกครั้งสำหรับแท็บเล็ต ตัวพักจะถูกเติมค่าจากแต่ละชุดข้อมูล

## **สร้างหลายงานนำเสนอ**

หากต้องการงานนำเสนอแยกสำหรับแต่ละชุดข้อมูล ใช้เมธอด `MergeToMultiplePresentations`

เมธอดนี้จะประมวลผลชุดข้อมูลทีละชุด สร้างงานนำเสนอจากเทมเพลต เติมข้อมูลปัจจุบัน และส่งงานนำเสนอผลลัพธ์ให้กับตัวจัดการ

ตัวจัดการจะถูกเรียกหนึ่งครั้งต่อชุดข้อมูลตามลำดับเดิมของข้อมูล

### **บันทึกแต่ละงานนำเสนอ**

ตัวอย่างต่อไปนี้อ่านข้อมูลจากไฟล์ CSV และบันทึกงานนำเสนอที่สร้างแต่ละไฟล์เป็นไฟล์แยก

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.csv",
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

คุณสมบัติ `args.Index` ให้ดัชนีที่เริ่มจากศูนย์ของชุดข้อมูลปัจจุบัน ตัวอย่างใช้ดัชนีเพื่อสร้างชื่อไฟล์ต่อเนื่องตั้งแต่ `product_1.pptx`

ข้อมูลสามารถอ่านจากสตรีมได้เช่นกัน:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xlsx"))
using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        data,
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

### **ใช้ค่าชุดข้อมูลเป็นชื่อไฟล์**

ตัวจัดการรับงานนำเสนอที่สร้างและข้อมูลชุดข้อมูลที่ใช้สร้างคุณสามารถใช้ค่าชุดข้อมูลเพื่อสร้างชื่อไฟล์ที่มีความหมาย

ตัวอย่างต่อไปนี้บันทึกแต่ละงานนำเสนอโดยใช้ชื่อสินค้าจากฟิลด์ title

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string title = args.DataSet.GetText("title");
            string fileName = title != null
                ? title
                : "product_" + (args.Index + 1);

            presentation.Save(fileName + ".pptx", SaveFormat.Pptx);
        });
}
```

คุณสมบัติ `DataSet` จะคืนชุดข้อมูลที่ใช้เติมงานนำเสนอปัจจุบัน เมธอด `GetText` ดึงค่าของฟิลด์ที่ระบุ หรือคืน `null` หากฟิลด์ไม่มี

สิ่งนี้ทำให้คุณใช้ค่าข้อมูลสำหรับตั้งชื่อไฟล์ จัดระเบียบผลลัพธ์ หรือทำการประมวลผลเพิ่มเติมในตัวจัดการ

## **การจัดการงานนำเสนอที่สร้าง**

`MergeToMultiplePresentations` ใช้ตัวแทน `MailMergedPresentationHandler` เพื่อประมวลผลงานนำเสนอแต่ละไฟล์

ตัวจัดการรับอาร์กิวเมนท์สองตัว:

- `presentation` — งานนำเสนอที่สร้างจากเทมเพลตและเติมด้วยชุดข้อมูลปัจจุบัน
- `args` — ข้อมูลเกี่ยวกับงานนำเสนอที่สร้าง รวมถึงดัชนีชุดข้อมูลและชุดข้อมูลเอง

งานนำเสนอที่สร้างเป็นของเมลเมิร์จและจะถูกปล่อย (dispose) ทันทีหลังจากตัวจัดการคืนค่า ดังนั้นคุณต้องบันทึกหรือคัดลอกข้อมูลที่จำเป็นภายในตัวจัดการ อย่าเก็บอ้างอิงไว้หลังจากตัวจัดการคืนค่า หรือทำการ dispose เอง

ตัวจัดการทำงานบนเธรดที่เรียก ใช้ครั้งละหนึ่งงานนำเสนอ ตามลำดับของชุดข้อมูล มีงานนำเสนอที่โหลดอยู่ในหน่วยความจำเพียงงานเดียว ทำให้วิธีนี้เหมาะกับการประมวลผลแหล่งข้อมูลขนาดใหญ่โดยไม่ต้องโหลดงานนำเสนอทั้งหมดพร้อมกัน

หากตัวจัดการโยนข้อยกเว้น กระบวนการเมลเมิร์จจะหยุดและข้อยกเว้นจะถูกส่งต่อไปยังผู้เรียกโดยไม่เปลี่ยนแปลง งานนำเสนอที่ประมวลผลแล้วจะไม่เสียหาย และชุดข้อมูลที่เหลือจะไม่ถูกประมวลผล

ตัวอย่างต่อไปนี้บันทึกงานนำเสนอที่สร้างลงในไดเรกทอรีเฉพาะ

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

string outputFolder = "output";
Directory.CreateDirectory(outputFolder);

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string path = Path.Combine(
                outputFolder,
                "product_" + (args.Index + 1) + ".pptx");

            presentation.Save(path, SaveFormat.Pptx);
        });
}
```

## **ทำงานกับข้อมูลเมลเมิร์จ**

คลาส `MailMergeDataSource` แสดงคอลเลกชันที่เรียงลำดับของชุดข้อมูล สามารถใช้สร้างข้อมูลในโค้ด ตรวจสอบจำนวนชุดข้อมูล และเข้าถึงชุดข้อมูลแต่ละชุดโดยดัชนี

### **รับจำนวนชุดข้อมูล**

คุณสมบัติ `Count` คืนจำนวนชุดข้อมูลในแหล่งข้อมูล

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine("Presentations to create: " + source.Count);
```

### **เข้าถึงชุดข้อมูลโดยดัชนี**

คุณสมบัติ `Item(int)` ให้เข้าถึงชุดข้อมูลตามดัชนีศูนย์‑ฐานที่ระบุ

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine(source[1].GetText("title"));
```

ตัวอย่างนี้ดึงค่า title ของชุดข้อมูลที่สอง

### **เพิ่มฟิลด์ข้อความ**

เมธอด `AddText` เพิ่มฟิลด์ข้อความที่มีชื่อให้กับชุดข้อมูล ค่าของฟิลด์จะแทนที่ตัวพักที่ตรงกันทั้งหมดในเทมเพลต

```csharp
MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet dataSet = source.AddDataSet();
dataSet.AddText("title", "Laptop X1");
dataSet.AddText("subtitle", string.Empty);
```

ค่าที่ว่างจะลบตัวพักที่สอดคล้องออกจากข้อความผลลัพธ์ หากฟิลด์ไม่ได้เพิ่มลงในชุดข้อมูล ตัวพักจะคงอยู่โดยไม่เปลี่ยนแปลง

### **อ่านฟิลด์ข้อความ**

เมธอด `GetText` ดึงค่าของฟิลด์ตามชื่อ ชื่อฟิลด์ไม่สนใจตัวพิมพ์ใหญ่‑เล็ก

```csharp
IMailMergeDataSet dataSet = source[0];

string title = dataSet.GetText("title");
string price = dataSet.GetText("price");
```

หากฟิลด์ไม่มีหรือชื่อฟิลด์ที่ระบุเป็น `null` `GetText` จะคืน `null`

## **สรุป**

เมลเมิร์จใน Aspose.Slides for .NET ให้วิธีที่สะดวกในการสร้างงานนำเสนอที่ขับเคลื่อนด้วยข้อมูลจากเทมเพลตร่วมใช้ได้หลายครั้ง

คุณสามารถใช้เพื่อ:

- เติมค่าลงในเทมเพลตงานนำเสนอจากแหล่งข้อมูล
- สร้างงานนำเสนอเดียวที่มีสไลด์เทมเพลตซ้ำสำหรับหลายชุดข้อมูล
- สร้างงานนำเสนอแยกสำหรับแต่ละชุดข้อมูล
- อ่านข้อมูลจากไฟล์หรือสตรีม CSV, XLSX, JSON และ XML
- สร้างแหล่งข้อมูลโดยตรงในโค้ด
- ประมวลผลและบันทึกงานนำเสนอที่สร้างตามลำดับด้วยตัวจัดการ

โดยการผสมผสานเทมเพลตที่ใช้ซ้ำได้กับข้อมูลที่มีโครงสร้าง คุณสามารถอัตโนมัติการสร้างงานนำเสนอจำนวนมากขณะที่แยกการออกแบบเทมเพลตและตรรกะการประมวลผลข้อมูลออกจากกัน

## **คำถามที่พบบ่อย**

**ฉันสามารถใช้ตัวพักเดียวกันหลายครั้งในเทมเพลตได้หรือไม่?**

ได้ ทุกตำแหน่งที่มีตัวพักที่มีชื่อฟิลด์ตรงกันจะถูกแทนที่ด้วยค่าที่สอดคล้องจากชุดข้อมูลปัจจุบัน

**ชื่อฟิลด์ต้องแยกแยะตามตัวอักษรหรือไม่?**

ไม่ ชื่อฟิลด์และตัวพักไม่สนใจตัวพิมพ์ใหญ่‑เล็ก ยกตัวอย่าง `{{title}}`, `{{Title}}` และ `{{TITLE}}` อ้างถึงฟิลด์เดียวกัน

**จะเกิดอะไรขึ้นหากฟิลด์หายไปจากชุดข้อมูล?**

หากชุดข้อมูลไม่มีฟิลด์ที่ตัวพักอ้างถึง ตัวพักนั้นจะคงอยู่โดยไม่เปลี่ยนแปลงในงานนำเสนอที่สร้าง

**จะเกิดอะไรขึ้นหากฟิลด์มีค่าว่าง?**

ค่าฟิลด์ว่างจะแทนที่ตัวพักด้วยสตริงว่าง ตัวพักจะถูกลบออกโดยไม่มีข้อความใด ๆ อยู่ในตำแหน่งนั้น

**ฉันสามารถรักษาการจัดรูปแบบของตัวพักเมื่อแทนที่หรือไม่?**

ข้อความที่แทนที่จะสืบทอดการจัดรูปแบบของอักษรตัวแรกของตัวพัก ปรับการจัดรูปแบบของตัวพักในเทมเพลตก่อนทำเมอร์จเพื่อให้ได้ผลลัพธ์ที่ต้องการ

**เมลเมิร์จแทนที่ตัวพักบนมาสเตอร์สไลด์หรือเลย์เอาท์สไลด์หรือไม่?**

ไม่ เมลเมิร์จแทนที่ตัวพักในเนื้อหาที่สนับสนุนบนสไลด์งานนำเสนอ รวมถึงรูปทรง รูปทรงที่จัดกลุ่ม เซลล์ตาราง และโน้ตของผู้พูด ตัวพักบนมาสเตอร์และเลย์เอาท์สไลด์จะไม่ถูกแทนที่

**เทมเพลตงานนำเสนอถูกแก้ไขระหว่างเมอร์จหรือไม่?**

ไม่ เทมเพลตต้นฉบับจะไม่ถูกแก้ไขโดยกระบวนการเมอร์จ คุณสามารถนำกลับมาใช้ซ้ำเพื่อสร้างงานนำเสนอจากแหล่งข้อมูลเดียวหรือหลายแหล่ง

**ฉันสามารถสร้างงานนำเสนอแยกสำหรับแต่ละชุดข้อมูลได้หรือไม่?**

ได้ ใช้ `MergeToMultiplePresentations` แล้วบันทึกงานนำเสนอแต่ละไฟล์ภายในตัวจัดการ ตัวจัดการจะถูกเรียกตามลำดับสำหรับแต่ละชุดข้อมูล

**ฉันสามารถรวมทุกชุดข้อมูลไว้ในงานนำเสนอเดียวได้หรือไม่?**

ได้ ใช้ `MergeToSinglePresentation` ซึ่งจะสร้างงานนำเสนอผลลัพธ์เดียวที่มีสำเนาสไลด์เทมเพลตสำหรับแต่ละชุดข้อมูล ตามลำดับของแหล่งข้อมูล

**ฉันสามารถใช้แหล่งข้อมูลโดยไม่ต้องบันทึกเป็นไฟล์ได้หรือไม่?**

ได้ คุณสามารถสร้าง `MailMergeDataSource` ในโค้ด เพิ่มชุดข้อมูลและเติมฟิลด์ด้วย `AddText` ซึ่งเป็นประโยชน์เมื่อข้อมูลมีอยู่แล้วในแอปพลิเคชันของคุณ

**เมลเมิร์จตรวจจับรูปแบบข้อมูลจากส่วนขยายไฟล์หรือไม่?**

ไม่ รูปแบบข้อมูลจะตรวจจับจากเนื้อหา ดังนั้นแหล่งข้อมูลที่รองรับไม่จำเป็นต้องมีส่วนขยายไฟล์เฉพาะ

**ฉันสามารถอ่านข้อมูลจากสตรีมที่ไม่รองรับการ seek หรือไม่?**

ได้ เมลเมิร์จรองรับสตรีมที่ไม่สามารถ seek ได้

**จะเกิดอะไรขึ้นหากแหล่งข้อมูลว่างหรือไม่มีชุดข้อมูล?**

แหล่งข้อมูลต้องมีอย่างน้อยหนึ่งชุดข้อมูล ตรวจสอบให้แน่ใจว่ามีระเบียนอย่างน้อยหนึ่งรายการก่อนเริ่มเมอร์จ

**จะเกิดอะไรขึ้นหากแหล่งข้อมูลมีรูปแบบไม่ถูกต้อง?**

หากเนื้อหาไม่ตรงกับรูปแบบข้อมูลที่รองรับ `NotSupportedException` จะถูกโยน หากรูปแบบถูกจำแนกแต่โครงสร้างผิด `InvalidDataException` จะถูกโยน ข้อความข้อยกเว้นจะบอกรายละเอียดตำแหน่งข้อผิดพลาด

**ฉันสามารถใช้งานนำเสนอที่สร้างหลังจากตัวจัดการคืนค่าหรือไม่?**

งานนำเสนอที่ส่งให้ตัวจัดการ `MergeToMultiplePresentations` เป็นของเมลเมิร์จและจะถูก dispose หลังจากตัวจัดการคืนค่า คุณต้องบันทึกหรือคัดลอกข้อมูลที่ต้องการภายในตัวจัดการ และไม่ควรเก็บอ้างอิงหรือทำการ dispose ด้วยตนเอง

**ตัวจัดการจะถูกเรียกแบบขนานหรือไม่?**

ไม่ งานนำเสนอที่สร้างจะถูกประมวลผลตามลำดับบนเธรดของผู้เรียก มีงานนำเสนอที่อยู่ในหน่วยความจำเพียงงานเดียวในแต่ละเวลา

**จะเกิดอะไรขึ้นหากมีข้อยกเว้นในตัวจัดการ?**

กระบวนการเมอร์จจะหยุดและข้อยกเว้นจะถูกส่งต่อไปยังผู้เรียกโดยไม่เปลี่ยนแปลง ชุดข้อมูลที่ประมวลผลแล้วจะไม่ถูกกระทบและชุดข้อมูลที่เหลือจะไม่ถูกประมวลผล

**ฉันสามารถใช้ค่าฟิลด์เพื่อสร้างชื่อไฟล์ผลลัพธ์ได้หรือไม่?**

ได้ ตัวจัดการให้เข้าถึงชุดข้อมูลปัจจุบันผ่านอาร์กิวเมนท์ ใช้ `GetText` เพื่อดึงฟิลด์และสร้างชื่อไฟล์สำหรับแต่ละงานนำเสนอ ตรวจสอบให้ค่าที่ใช้เป็นชื่อไฟล์ถูกต้องตามข้อกำหนดของสภาพแวดล้อมที่ใช้งาน.
