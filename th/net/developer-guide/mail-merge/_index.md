# การรวมจดหมายในงานนำเสนอ PowerPoint

Aspose.Slides for .NET ช่วยให้คุณสามารถสร้างงานนำเสนอ PowerPoint โดยอัตโนมัติด้วยเทมเพลตและแหล่งข้อมูล การรวมจดหมายจะเติมตำแหน่งตัวแปรในเทมเพลตด้วยข้อมูลและสร้างหรือทั้งงานนำเสนอเดียวที่มีสไลด์เทมเพลตทำซ้ำสำหรับทุกชุดข้อมูลหรือสร้างงานนำเสนอแยกสำหรับแต่ละชุดข้อมูล

ฟังก์ชันนี้มีประโยชน์สำหรับการสร้างแคตาล็อกสินค้า งานนำเสนอส่วนบุคคล รายงาน ใบรับรอง ข้อเสนอ รายการราคา และเอกสารอื่น ๆ ที่โครงสร้างของงานนำเสนอคงที่แต่เนื้อหาเปลี่ยนแปลงได้

![Mail Merge: before and after](mail-merge-before-after.png)


## วิธีการทำงานของการรวมจดหมาย

การรวมจดหมายใช้ไฟล์งานนำเสนอ PowerPoint เป็นเทมเพลตและแทนที่ตำแหน่งตัวแปรด้วยค่าจากแหล่งข้อมูล

![Mail Merge workflow](mail-merge-workflow.png)

ตำแหน่งตัวแปรคือชื่อฟิลด์ที่อยู่ในวงเล็บเหลี่ยมคู่ เช่น `{{title}}` หรือ `{{price}}` สามารถวางตำแหน่งตัวแปรในข้อความของรูปร่าง เซลล์ตาราง รูปร่างที่จัดกลุ่ม และบันทึกผู้บรรยาย

ตัวอย่างเช่นสไลด์เทมเพลตอาจมีข้อความต่อไปนี้:

- `Product: {{title}}`
- `Price: {{price}}`
- `Description: {{description}}`

เมื่อแหล่งข้อมูลมีค่าดังต่อไปนี้:

| Field | Value |
|---|---|
| title | Laptop X1 |
| price | $999 |
| description | 14‑inch display, 16 GB RAM |

การรวมจดหมายจะแทนที่ตำแหน่งตัวแปรด้วยค่าที่สอดคล้องกัน สร้างสไลด์ที่มีข้อมูลสินค้าจริง

ชื่อฟิลด์ไม่สนใจขนาดตัวอักษร ดังนั้น `{{title}}` และ `{{Title}}` จะอ้างอิงถึงฟิลด์เดียวกัน

กฎต่อไปนี้ใช้เมื่อทำการแทนที่ตำแหน่งตัวแปร:

- ตำแหน่งตัวแปรจะแทนที่บนสไลด์รวมถึงรูปร่างที่จัดกลุ่มและเซลล์ตารางและในบันทึกผู้บรรยาย
- ตำแหน่งตัวแปรบนสไลด์มาสเตอร์และสไลด์เลย์เอาต์จะไม่ถูกแทนที่
- หากฟิลด์ที่ตำแหน่งตัวแปรอ้างอิงไม่ได้อยู่ในชุดข้อมูล จะคงเดิมไม่เปลี่ยน
- ค่าฟิลด์ว่างจะทำให้ตำแหน่งตัวแปรถูกแทนที่ด้วยสตริงว่าง
- ข้อความที่แทรกจะสืบทอดรูปแบบจากอักขระตัวแรกของตำแหน่งตัวแปร
- ค่าไม่ควรมีข้อความตำแหน่งตัวแปรอยู่ในตัวเอง เพราะข้อความที่แทรกอาจถูกประมวลผลซ้ำและแทนที่ด้วยฟิลด์อื่น

เทมเพลตงานนำเสนอเดิมจะไม่ถูกแก้ไขระหว่างการรวมและต้องมีอย่างน้อยหนึ่งสไลด์

## แหล่งข้อมูลที่รองรับ

การรวมจดหมายรองรับวิธีการให้ข้อมูลสองวิธี:

- สร้างแหล่งข้อมูลโปรแกรมmatically โดยใช้ `IMailMergeDataSource`
- อ่านข้อมูลจากไฟล์หรือสตรีม CSV, XLSX, JSON หรือ XML

รูปแบบข้อมูลจะถูกตรวจจับจากเนื้อหา ไม่ได้จากส่วนขยายไฟล์ สตรีมที่ไม่สนับสนุนการเลื่อนตำแหน่งก็ได้รับการสนับสนุนเช่นกัน

แหล่งข้อมูลต้องมีอย่างน้อยหนึ่งชุดข้อมูล แต่ละชุดข้อมูลแทนที่สำเนาเทมเพลตหนึ่งชุดด้วยค่าที่สอดคล้อง

หากเนื้อหาข้อมูลไม่สามารถระบุเป็นรูปแบบที่รองรับ `NotSupportedException` จะถูกโยน หากระบุได้แต่ไม่เป็นไปตามข้อกำหนดรูปแบบ `InvalidDataException` จะถูกโยน ข้อความข้อยกเวลาดูตำแหน่งของข้อผิดพลาดในข้อมูล

### JSON

แหล่งข้อมูล JSON ต้องมีอ็อบเจ็กต์รากที่มีอาเรย์ `sets` แต่ละอิลิเมนต์ของอาเรย์แทนชุดข้อมูลและต้องมีอาเรย์ `fields` ฟิลด์แต่ละฟิลด์ต้องมีสตริง `name` และ `value`

คุณสมบัติเสริม `version` ต้องเป็น `"1.0"` และคุณสมบัติ `type` ของฟิลด์ต้องเป็น `"text"` ชื่อคุณสมบัติจัดเป็น case‑sensitive คุณสมบัติที่ไม่รู้จักจะถูกละเว้น

ข้อมูล JSON อ่านเป็น UTF‑8 หรือ UTF‑16 เมื่อข้อมูลเริ่มด้วย BOM

ตัวอย่างต่อไปนี้มีสองชุดข้อมูล:

```json
{
  "version": "1.0",
  "sets": [
    {
      "fields": [
        { "name": "title", "value": "Laptop X1" },
        { "name": "price", "value": "$999" }
      ]
    },
    {
      "fields": [
        { "name": "title", "value": "Tablet S2" },
        { "name": "price", "value": "$499" }
      ]
    }
  ]
}
```

### XML

แหล่งข้อมูล XML ต้องมีอีลีเมนต์ราก `template` ที่มีอีลีเมนต์ `sets` แต่ละอีลีเมนต์ `set` มีอีลีเมนต์ `field` และแต่ละฟิลด์ต้องมีอีลีเมนต์ `name` และ `value`

อีลีเมนต์ `value` ว่างจะถือเป็นสตริงว่าง ชื่ออีลีเมนต์เป็น case‑sensitive อีลีเมนต์และคอมเมนต์ที่ไม่รู้จักจะถูกละเว้น การเข้ารหัสกำหนดโดยคำประกาศ XML DTD ไม่ได้รับอนุญาต

```xml
<?xml version="1.0" encoding="utf-8"?>
<template>
  <sets>
    <set>
      <field>
        <name>title</name>
        <value>Laptop X1</value>
      </field>
      <field>
        <name>price</name>
        <value>$999</value>
      </field>
    </set>
    <set>
      <field>
        <name>title</name>
        <value>Tablet S2</value>
      </field>
      <field>
        <name>price</name>
        <value>$499</value>
      </field>
    </set>
  </sets>
</template>
```

### CSV

ข้อมูล CSV ใช้เครื่องหมายเซมิโคลอนเป็นตัวคั่นค่า

แถวแรกมีชื่อฟิลด์และสิ้นสุดที่ชื่อฟิลด์ว่าง แถวต่อมาทีละแถวแทนชุดข้อมูลหนึ่ง ชุดข้อมูลสิ้นสุดที่แถวว่างแรก

กฎต่อไปนี้ใช้:

- ค่าที่หายไปที่ท้ายแถวจะถือเป็นสตริงว่าง
- ค่าที่เกินกว่าชื่อฟิลด์ที่กำหนดจะถูกละเว้น
- ค่าที่มีเซมิโคลอน เครื่องหมายอัญประกาศ หรือการขึ้นบรรทัดใหม่ต้องใส่ในเครื่องหมายอัญประกาศ
- เครื่องหมายอัญประกาศภายในค่าที่อัญประกาศต้องซ้ำสองครั้ง
- ข้อมูลอ่านเป็น UTF‑8 หรือ UTF‑16 เมื่อเริ่มด้วย BOM

ตัวอย่าง:

```csv
title;price;description
Laptop X1;$999;"14"" display; 16 GB RAM"
Tablet S2;$499;
```

### XLSX

ข้อมูล XLSX อ่านจากแผ่นงานแรก

แผ่นงานปฏิบัติตามกฎเดียวกับ CSV:

- แถวแรกมีชื่อฟิลด์และสิ้นสุดที่เซลล์ว่างแรก
- แถวต่อมาทีละแถวแทนชุดข้อมูลหนึ่ง
- ชุดข้อมูลสิ้นสุดที่แถวว่างแรก
- เซลล์ว่างถือเป็นสตริงว่าง
- ค่าตัวเลขจะแปลงเป็นข้อความโดยใช้ invariant culture

## การสร้างงานนำเสนอเดียว

เมธอด `MergeToSinglePresentation` สร้างงานนำเสนอหนึ่งไฟล์ที่มีสำเนาสไลด์เทมเพลตสำหรับทุกชุดข้อมูล แต่ละสำเนาจะเติมด้วยข้อมูลที่สอดคล้อง

ลำดับของชุดข้อมูลกำหนดลำดับของกลุ่มสไลด์ในงานนำเสนอผลลัพธ์

### การรวมข้อมูลจากไฟล์

ตัวอย่างต่อไปนี้โหลดเทมเพลตและไฟล์ข้อมูล JSON สร้างงานนำเสนอเดียวที่มีสไลด์สำหรับทุกชุดข้อมูลและบันทึกผลลัพธ์

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, "products.json"))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

ข้อมูลยังสามารถอ่านจากสตรีมได้ สตรีมจะอ่านจากตำแหน่งปัจจุบันและไม่ได้ถูกปิดโดยการทำงานของการรวมจดหมาย

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xml"))
using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, data))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

### การสร้างแหล่งข้อมูลในโค้ด

คุณสามารถสร้างแหล่งข้อมูลโปรแกรมmatically ด้วย `MailMergeDataSource` และ `MailMergeDataSet` เพิ่มชุดข้อมูลสำหรับทุกระเบียนและกำหนดฟิลด์โดยใช้เมธอด `AddText`

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet laptop = source.AddDataSet();
laptop.AddText("title", "Laptop X1");
laptop.AddText("price", "$999");

IMailMergeDataSet tablet = source.AddDataSet();
tablet.AddText("title", "Tablet S2");
tablet.AddText("price", "$499");

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
using (IPresentation result = mailMerge.MergeToSinglePresentation(template, source))
{
    result.Save("catalog.pptx", SaveFormat.Pptx);
}
```

ในตัวอย่างนี้สไลด์เทมเพลตจะทำซ้ำสองครั้ง: ครั้งหนึ่งสำหรับแล็ปท็อปและอีกครั้งสำหรับแท็บเล็ต ตำแหน่งตัวแปรจะถูกเติมด้วยค่าที่กำหนดในแต่ละชุดข้อมูล

## การสร้างงานนำเสนอหลายไฟล์

หากต้องการงานนำเสนอแยกสำหรับแต่ละชุดข้อมูล ให้ใช้เมธอด `MergeToMultiplePresentations`

เมธอดนี้จะประมวลผลชุดข้อมูลหนึ่งต่อหนึ่ง สร้างงานนำมาจากเทมเพลต เติมข้อมูลปัจจุบัน แล้วส่งงานนำเสนอที่ได้ให้กับตัวจัดการ

ตัวจัดการจะถูกเรียกหนึ่งครั้งต่อชุดข้อมูลตามลำดับข้อมูลเดิม

### การบันทึกแต่ละงานนำเสนอ

ตัวอย่างต่อไปนี้อ่านข้อมูลจากไฟล์ CSV และบันทึกงานนำเสนอที่สร้างแต่ละไฟล์เป็นไฟล์แยก

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.csv",
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

คุณสมบัติ `args.Index` ให้ดัชนีเริ่มที่ศูนย์ของชุดข้อมูลปัจจุบัน ในตัวอย่างใช้เพื่อสร้างชื่อไฟล์ต่อเนื่องตั้งแต่ `product_1.pptx`

ข้อมูลยังสามารถอ่านจากสตรีมได้:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Stream data = File.OpenRead("products.xlsx"))
using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        data,
        (presentation, args) =>
        {
            presentation.Save(
                "product_" + (args.Index + 1) + ".pptx",
                SaveFormat.Pptx);
        });
}
```

### ใช้ค่าชุดข้อมูลเป็นชื่อไฟล์

ตัวจัดการรับทั้งงานนำเสนอที่สร้างและข้อมูลชุดข้อมูลที่ใช้สร้าง คุณสามารถใช้ค่าชุดข้อมูลเพื่อสร้างชื่อไฟล์ที่มีความหมาย

ตัวอย่างต่อไปนี้บันทึกแต่ละงานนำเสนอโดยใช้ชื่อผลิตภัณฑ์:

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string title = args.DataSet.GetText("title");
            string fileName = title != null
                ? title
                : "product_" + (args.Index + 1);

            presentation.Save(fileName + ".pptx", SaveFormat.Pptx);
        });
}
```

คุณสมบัติ `DataSet` คืนชุดข้อมูลที่ใช้เติมงานนำเสนอปัจจุบัน เมธอด `GetText` ดึงค่าของฟิลด์ที่ระบุ หรือ `null` หากฟิลด์ไม่มี

วิธีนี้ทำให้คุณใช้ค่าข้อมูลในการตั้งชื่อไฟล์ จัดการผลลัพธ์ หรือทำการประมวลผลเพิ่มเติมในตัวจัดการ

## การจัดการงานนำเสนอที่สร้าง

`MergeToMultiplePresentations` ใช้ตัวแทน `MailMergedPresentationHandler` เพื่อประมวลผลงานนำเสนอที่สร้างแต่ละไฟล์

ตัวจัดการรับอาร์กิวเมนต์สองตัว:

- `presentation` — งานนำเสนอที่สร้างจากเทมเพลตและเติมด้วยชุดข้อมูลปัจจุบัน
- `args` — ข้อมูลเกี่ยวกับงานนำเสนอที่สร้าง รวมถึงดัชนีชุดข้อมูลและชุดข้อมูลเอง

งานนำเสนอที่สร้างเป็นของการดำเนินการ Mail Merge และจะถูกกำจัดโดยอัตโนมัติหลังจากตัวจัดการคืนค่า ดังนั้นคุณต้องบันทึกหรือคัดลอกข้อมูลที่ต้องการภายในตัวจัดการ อย่าเก็บอ้างอิงถึงมันหลังจากตัวจัดการคืนค่า หรือทำการกำจัดด้วยตนเอง

ตัวจัดการทำงานบนเธรดเรียกใช้ หนึ่งงานนำเสนอต่อครั้ง ตามลำดับของชุดข้อมูล มีเพียงงานนำเสนอที่สร้างหนึ่งไฟล์อยู่ในหน่วยความจำในแต่ละครั้ง ทำให้วิธีนี้เหมาะกับการประมวลผลแหล่งข้อมูลขนาดใหญ่โดยไม่ต้องเก็บงานนำเสนอทั้งหมดในหน่วยความจำพร้อมกัน

หากตัวจัดการโยนข้อยกเว้น การทำงานของ Mail Merge จะหยุดและข้อยกเว้นจะถูกส่งต่อไปยังผู้เรียกโดยไม่มีการเปลี่ยนแปลง งานนำเสนอที่ได้ประมวลผลแล้วจะไม่ถูกกระทบ และชุดข้อมูลที่เหลือจะไม่ถูกประมวลผล

ตัวอย่างต่อไปนี้บันทึกงานนำเสนอที่สร้างลงในไดเรกทอรีเฉพาะ

```csharp
using Aspose.Slides;
using Aspose.Slides.MailMerge;
using System.IO;

string outputFolder = "output";
Directory.CreateDirectory(outputFolder);

MailMergeProcessor mailMerge = new MailMergeProcessor();

using (Presentation template = new Presentation("template.pptx"))
{
    mailMerge.MergeToMultiplePresentations(
        template,
        "products.json",
        (presentation, args) =>
        {
            string path = Path.Combine(
                outputFolder,
                "product_" + (args.Index + 1) + ".pptx");

            presentation.Save(path, SaveFormat.Pptx);
        });
}
```

## การทำงานกับข้อมูล Mail Merge

คลาส `MailMergeDataSource` แสดงคอลเลกชันที่เรียงลำดับของชุดข้อมูล สามารถใช้สร้างข้อมูลในโค้ด ตรวจสอบจำนวนชุดข้อมูล และเข้าถึงชุดข้อมูลแต่ละชุดโดยดัชนี

### การรับจำนวนชุดข้อมูล

คุณสมบัติ `Count` คืนจำนวนชุดข้อมูลในแหล่ง

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine("Presentations to create: " + source.Count);
```

### การเข้าถึงชุดข้อมูลตามดัชนี

คุณสมบัติ `Item(int)` ให้เข้าถึงชุดข้อมูลที่ตำแหน่งดัชนีเริ่มที่ศูนย์

```csharp
MailMergeDataSource source = new MailMergeDataSource();

source.AddDataSet().AddText("title", "Laptop X1");
source.AddDataSet().AddText("title", "Tablet S2");

Console.WriteLine(source[1].GetText("title"));
```

ตัวอย่างนี้ดึงชื่อเรื่องของชุดข้อมูลที่สอง

### การเพิ่มฟิลด์ข้อความ

เมธอด `AddText` เพิ่มฟิลด์ข้อความที่มีชื่อให้กับชุดข้อมูล ค่าฟิลด์จะแทนที่ตำแหน่งตัวแปรที่ตรงกันทั้งหมดในเทมเพลต

```csharp
MailMergeDataSource source = new MailMergeDataSource();

IMailMergeDataSet dataSet = source.AddDataSet();
dataSet.AddText("title", "Laptop X1");
dataSet.AddText("subtitle", string.Empty);
```

ค่าที่ว่างจะลบตำแหน่งตัวแปรจากข้อความผลลัพธ์ หากฟิลด์ไม่ถูกเพิ่มในชุดข้อมูล ตำแหน่งตัวแปรจะคงเดิม

### การอ่านฟิลด์ข้อความ

เมธอด `GetText` ดึงค่าของฟิลด์ตามชื่อ ชื่อฟิลด์ไม่สนใจขนาดตัวอักษร

```csharp
IMailMergeDataSet dataSet = source[0];

string title = dataSet.GetText("title");
string price = dataSet.GetText("price");
```

หากฟิลด์ไม่มีหรือชื่อฟิลด์ที่ระบุเป็น `null` `GetText` จะคืน `null`

## สรุป

การรวมจดหมายใน Aspose.Slides for .NET ให้วิธีที่สะดวกในการสร้างงานนำเสนอที่ขับเคลื่อนด้วยข้อมูลจากเทมเพลตที่ใช้ซ้ำได้

คุณสามารถใช้เพื่อ:

- เติมเทมเพลตงานนำเสนอด้วยค่าจากแหล่งข้อมูล
- สร้างงานนำเสนอเดียวที่มีสไลด์เทมเพลตทำซ้ำสำหรับหลายชุดข้อมูล
- สร้างงานนำเสนอแยกสำหรับแต่ละชุดข้อมูล
- อ่านข้อมูลจากไฟล์หรือสตรีม CSV, XLSX, JSON และ XML
- สร้างแหล่งข้อมูลโดยตรงในโค้ด
- ประมวลผลและบันทึกงานนำเสนอที่สร้างตามลำดับโดยใช้ตัวจัดการ

โดยการผสานเทมเพลตที่ใช้ซ้ำกับข้อมูลที่มีโครงสร้าง คุณสามารถอัตโนมัติการสร้างงานนำเสนอจำนวนมากพร้อมคงแยกออกการออกแบบเทมเพลตและตรรกะการประมวลผลข้อมูล

## คำถามที่พบบ่อย

### สามารถใช้ตำแหน่งตัวแปรเดียวกันหลายครั้งในเทมเพลตได้หรือไม่?

ได้ ทุกการปรากฏของตำแหน่งตัวแปรที่มีชื่อฟิลด์ตรงกันจะถูกแทนที่ด้วยค่าที่สอดคล้องจากชุดข้อมูลปัจจุบัน

### ชื่อฟิลด์แยกแยะตัวพิมพ์ใหญ่‑เล็กหรือไม่?

ไม่ ชื่อฟิลด์และตำแหน่งตัวแปรไม่สนใจขนาดตัวอักษร เช่น `{{title}}`, `{{Title}}` และ `{{TITLE}}` จะอ้างอิงถึงฟิลด์เดียวกัน

### จะเกิดอะไรขึ้นหากฟิลด์หายไปจากชุดข้อมูล?

หากชุดข้อมูลไม่มีฟิลด์ที่ตำแหน่งตัวแปรอ้างอิง ตำแหน่งตัวแปรนั้นจะคงเดิมในงานนำเสนอที่สร้าง

### จะเกิดอะไรขึ้นหากฟิลด์มีค่าว่าง?

ค่าฟิลด์ว่างจะแทนที่ตำแหน่งตัวแปรด้วยสตริงว่าง ตำแหน่งตัวแปรจะถูกลบออกโดยไม่มีข้อความใด ๆ ปรากฏแทนที่

### สามารถคงรูปแบบของตำแหน่งตัวแปรไว้เมื่อแทนที่ได้หรือไม่?

ข้อความที่แทนที่จะสืบทอดรูปแบบจากอักขระตัวแรกของตำแหน่งตัวแปร ให้ตั้งค่ารูปแบบที่ต้องการไว้ที่ตำแหน่งตัวแปรในเทมเพลตก่อนทำการรวม

### การรวมจดหมายจะแทนที่ตำแหน่งตัวแปรบนสไลด์มาสเตอร์หรือเลย์เอาต์หรือไม่?

ไม่ การรวมจดหมายจะแทนที่ตำแหน่งตัวแปรในเนื้อหาที่รองรับบนสไลด์งานนำเสนอ รวมถึงรูปร่าง, รูปร่างที่จัดกลุ่ม, เซลล์ตารางและบันทึกผู้บรรยาย ตำแหน่งตัวแปรบนมาสเตอร์และเลย์เอาต์จะไม่ได้รับการแทนที่

### เทมเพลตงานนำเสนอถูกแก้ไขระหว่างการรวมหรือไม่?

ไม่ เทมเพลตเดิมจะไม่ถูกแก้ไขโดยการดำเนินการรวม คุณสามารถนำมันไปใช้ซ้ำเพื่อสร้างงานนำเสนอจากแหล่งข้อมูลเดียวหรือหลายแหล่งได้

### สามารถสร้างงานนำเสนอแยกสำหรับแต่ละชุดข้อมูลได้หรือไม่?

ได้ ใช้ `MergeToMultiplePresentations` และบันทึกงานนำเสนอที่สร้างภายในตัวจัดการ ตัวจัดการจะถูกเรียกแบบต่อเนื่องสำหรับแต่ละชุดข้อมูล

### สามารถรวมทุกชุดข้อมูลเป็นงานนำเสนอเดียวได้หรือไม่?

ได้ ใช้ `MergeToSinglePresentation` มันจะสร้างงานนำออกเดียวที่มีสำเนาสไลด์เทมเพลตสำหรับแต่ละชุดข้อมูลตามลำดับของแหล่งข้อมูล

### สามารถใช้แหล่งข้อมูลโดยไม่ต้องบันทึกเป็นไฟล์ได้หรือไม่?

ได้ คุณสามารถสร้าง `MailMergeDataSource` ในโค้ด เพิ่มชุดข้อมูลและเติมฟิลด์โดยใช้ `AddText` ซึ่งเหมาะกับกรณีที่ข้อมูลมีอยู่แล้วในแอปพลิเคชันของคุณ

### การรวมจดหมายตรวจจับรูปแบบข้อมูลจากส่วนขยายไฟล์หรือไม่?

ไม่ รูปแบบข้อมูลจะตรวจจับจากเนื้อหา ดังนั้นแหล่งข้อมูลที่รองรับไม่จำเป็นต้องใช้ส่วนขยายไฟล์ใดเป็นพิเศษ

### สามารถอ่านข้อมูลจากสตรีมที่ไม่สนับสนุนการเลื่อนตำแหน่งได้หรือไม่?

ได้ การรวมจดหมายรองรับสตรีมที่ไม่สามารถเลื่อนตำแหน่งได้

### จะเกิดอะไรขึ้นหากแหล่งข้อมูลว่างหรือไม่มีชุดข้อมูล?

แหล่งข้อมูลต้องมีอย่างน้อยหนึ่งชุดข้อมูล ตรวจสอบให้แน่ใจว่ามีข้อมูลอย่างน้อยหนึ่งระเบียนก่อนเริ่มการรวม

### จะเกิดอะไรขึ้นหากแหล่งข้อมูลมีรูปแบบไม่ถูกต้อง?

หากเนื้อหาไม่เป็นรูปแบบที่รองรับ `NotSupportedException` จะถูกโยน หากเป็นรูปแบบที่รับรู้ได้แต่มีโครงสร้างผิด `InvalidDataException` จะถูกโยน ข้อความข้อยกเวลาดูตำแหน่งของข้อผิดพลาด

### สามารถใช้งานนำเสนอที่สร้างหลังจากตัวจัดการคืนค่าได้หรือไม่?

งานนำเสนอที่ส่งให้ตัวจัดการ `MergeToMultiplePresentations` เป็นของ Mail Merge และจะถูกกำจัดหลังจากตัวจัดการคืนค่า คุณต้องบันทึกหรือคัดลอกข้อมูลที่ต้องการภายในตัวจัดการและไม่ควรเก็บหรือกำจัดงานนำเสนอนั้นด้วยตนเอง

### ตัวจัดการถูกเรียกแบบขนานหรือไม่?

ไม่ งานนำเสนอที่สร้างจะถูกประมวลผลต่อเนื่องบนเธรดของผู้เรียก มีเพียงงานนำเสนอที่สร้างหนึ่งไฟล์อยู่ในหน่วยความจำในแต่ละครั้ง

### จะเกิดอะไรขึ้นหากเกิดข้อยกเว้นภายในตัวจัดการ?

การดำเนินการรวมจะหยุดและข้อยกเว้นจะถูกส่งต่อไปยังผู้เรียกโดยไม่มีการเปลี่ยนแปลง งานนำเสนอที่ประมวลผลแล้วจะไม่ถูกกระทบ และชุดข้อมูลที่เหลือจะไม่ถูกประมวลผล

### สามารถใช้ค่าฟิลด์เพื่อสร้างชื่อไฟล์ผลลัพธ์ได้หรือไม่?

ได้ ตัวจัดการให้ข้อมูลชุดข้อมูลปัจจุบันผ่านอาร์กิวเมนต์ ใช้ `GetText` ดึงค่าฟิลด์และสร้างชื่อไฟล์สำหรับแต่ละงานนำเสนอ ตรวจสอบให้ค่าที่ใช้เป็นชื่อไฟล์นั้นเป็นไปตามกฎของระบบไฟล์ในสภาพแวดล้อมของคุณ
