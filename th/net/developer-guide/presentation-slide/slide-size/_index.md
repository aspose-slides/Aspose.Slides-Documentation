## **บทนำ**

Aspose.Slides for .NET มีเครื่องมือครบวงจรสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่

ควรรักษาความสอดคล้องตลอดการนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนเดียวกันจะนำไปใช้กับสไลด์ทั้งหมด เพื่อผลลัพธ์ที่ดีที่สุด ให้กำหนดขนาดสไลด์ตั้งแต่ขั้นตอนเริ่มต้นของการสร้างงานนำเสนอ เพื่อหลีกเลี่ยงปัญหา  

{{% alert color="info" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วน 4:3 มาตรฐาน
{{% /alert %}}

## **วิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างนี้แสดงการเปลี่ยนขนาดสไลด์ของงานนำเสนอด้วย Aspose.Slides ใน C#:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **ระบุขนาดสไลด์ที่กำหนดเอง**

การปรับขนาดสไลด์ให้ตรงกับความต้องการเฉพาะของคุณ เช่น สำหรับเค้าโครงกระดาษหรือสเปคหน้าจอที่ไม่เหมือนใคร สามารถเป็นประโยชน์ได้ ต่อไปนี้คือวิธีกำหนดขนาดสไลด์ที่กำหนดเองด้วย Aspose.Slides for .NET:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากปรับขนาดแล้ว เนื้อหาสไลด์อาจบิดเบี้ยว คุณสามารถควบคุมวิธีที่ Aspose.Slides จัดการการปรับขนาดนี้ได้:

- **`DoNotScale`**: รักษาวัตถุที่ขนาดเดิมเพื่อหลีกเลี่ยงการปรับขนาด
- **`EnsureFit`**: ปรับขนาดวัตถุให้พอดีกับสไลด์ขนาดเล็กลง เพื่อป้องกันการสูญเสียเนื้อหา
- **`Maximize`**: ขยายวัตถุให้เหมาะกับสไลด์ขนาดใหญ่ขึ้น เพื่อความสอดคล้องด้านสุนทรียะ

ตัวอย่างการใช้การตั้งค่า `Maximize` สำหรับการปรับขนาดสไลด์:

```csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **คำถามที่พบบ่อย**

### ฉันสามารถกำหนดขนาดสไลด์ที่กำหนดเองโดยใช้หน่วยที่ไม่ใช่นิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?

ได้ Aspose.Slides ใช้หน่วยจุดเป็นหน่วยภายใน โดย 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้  

### ขนาดสไลด์ที่กำหนดเองขนาดใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?

ได้ ขนาดสไลด์ที่ใหญ่กว่า (เป็นหน่วยจุด) ร่วมกับสเกลการเรนเดอร์ที่สูงกว่าจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและใช้เวลาในการประมวลผลยาวนานขึ้น ควรกำหนดขนาดสไลด์ที่เหมาะสมและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ  

### ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งแบบแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?

คุณไม่สามารถ [merge presentations](/slides/th/net/merge-presentation/) ได้เมื่อพวกมันมีขนาดสไลด์ที่แตกต่างกัน — ก่อนอื่น ให้ปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่ง เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีการจัดการเนื้อหาที่มีอยู่ผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/net/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณสามารถรวมสไลด์โดยคงรูปแบบเดิมไว้  

### ฉันสามารถสร้างภาพย่อสำหรับรูปร่างแต่ละอันหรือบริเวณเฉพาะของสไลด์ได้หรือไม่ และภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?

ได้ Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [สไลด์ทั้งหมด](https://reference.aspose.com/slides/th/net/aspose.slides/slide/getimage/) รวมถึงสำหรับ [รูปร่างที่เลือก](https://reference.aspose.com/slides/th/net/aspose.slides/shape/getimage/) ภาพที่ได้จะสะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและรูปทรงคงสม่ำเสมอ
