## **คำนำ**

Aspose.Slides for .NET มีเครื่องมือครบวงจรในการปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่

ตรวจสอบให้การนำเสนอของคุณสอดคล้องทั่วทั้งงาน เนื่องจากขนาดสไลด์และอัตราส่วนภาพเดียวกันจะถูกใช้กับทุกสไลด์ เพื่อผลลัพธ์ที่ดีที่สุด ควรกำหนดขนาดสไลด์ตั้งแต่ต้นกระบวนการสร้างการนำเสนอเพื่อหลีกเลี่ยงปัญหา  

{{% alert color="primary" %}} 
โดยค่าเริ่มต้น การนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3
{{% /alert %}}

## **วิธีเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ของงานนำเสนอด้วย Aspose.Slides ใน C#:

```csharp
using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **ระบุขนาดสไลด์แบบกำหนดเอง**

การปรับขนาดสไลด์ให้เหมาะกับความต้องการเฉพาะของคุณ เช่น สำหรับรูปแบบกระดาษที่ไม่ธรรมดาหรือสเปคหน้าจอเฉพาะ สามารถเป็นประโยชน์ ต่อไปนี้คือวิธีกำหนดขนาดสไลด์แบบกำหนดเองด้วย Aspose.Slides for .NET:

```csharp
using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **จัดการเนื้อหาในสไลด์หลังการปรับขนาด**

หลังการปรับขนาด เนื้อหาในสไลด์อาจเสียรูปทรง คุณสามารถควบคุมวิธีที่ Aspose.Slides จัดการการปรับขนาดนี้ได้:

- **`DoNotScale`**: รักษาวัตถุให้อยู่ในขนาดเดิมเพื่อหลีกเลี่ยงการปรับสเกล
- **`EnsureFit`**: ปรับสเกลวัตถุให้พอดีกับสไลด์ที่เล็กลง เพื่อป้องกันการสูญเสียเนื้อหา
- **`Maximize`**: เพิ่มขนาดวัตถุให้เหมาะกับสไลด์ที่ใหญ่ขึ้นเพื่อความสอดคล้องด้านสุนทรียะ

ตัวอย่างการใช้การตั้งค่า `Maximize` สำหรับการปรับขนาดสไลด์:

```csharp
using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลิเมเตอร์) ได้หรือไม่?**

ใช่ Aspose.Slides ใช้หน่วยจุดเป็นหน่วยภายใน โดย 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมเตอร์หรือเซนติเมตร) ไปเป็นจุดและใช้ค่าที่แปลงแล้วเพื่อกำหนดความกว้างและความสูงของสไลด์ได้  

**การกำหนดขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ มิติของสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับสเกลการเรนเดอร์ที่สูงจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและเวลาการประมวลผลยาวนานขึ้น ควรตั้งขนาดสไลด์ให้เป็นประโยชน์และปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ตามที่ต้องการ  

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งขนาดแล้วจากนั้นรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ[รวมงานนำเสนอ](/slides/th/net/merge-presentation/)ในขณะที่มีขนาดสไลด์ต่างกันได้ — ต้องปรับขนาดงานนำเสนออย่างหนึ่งให้ตรงกับอีกงานหนึ่งก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการกับเนื้อหาที่มีอยู่ผ่านตัวเลือก[SlideSizeScaleType](https://reference.aspose.com/slides/th/net/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณสามารถรวมสไลด์ได้โดยคงรูปแบบไว้  

**ฉันสามารถสร้างรูปย่อสำหรับรูปร่างแต่ละอันหรือส่วนเฉพาะของสไลด์ได้หรือไม่ และรูปย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ใช่ Aspose.Slides สามารถเรนเดอร์รูปย่อสำหรับ[สไลด์ทั้งหมด](https://reference.aspose.com/slides/th/net/aspose.slides/slide/getimage/)รวมถึง[รูปร่างที่เลือก](https://reference.aspose.com/slides/th/net/aspose.slides/shape/getimage/) ภาพที่ได้สะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่อย่างสม่ำเสมอ
