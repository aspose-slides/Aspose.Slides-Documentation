## **บทนำ**

Aspose.Slides for .NET มีเครื่องมือครบวงจรสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (4:3 Aspect Ratio)**: เหมาะสำหรับจอและอุปกรณ์รุ่นเก่า
- **Widescreen (16:9 Aspect Ratio)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่

ควรทำให้สไลด์ทั้งหมดมีขนาดและอัตราส่วนภาพเดียวกันทั่วทั้งงานนำเสนอ เพื่อความสอดคล้อง ตั้งค่าขนาดสไลด์ตั้งแต่เริ่มสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหาต่อมาที่อาจเกิดขึ้น

{{% alert color="info" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้ขนาดมาตรฐาน 4:3
{{% /alert %}}

หน้าธ notasและเอกสารแจกมีขนาดที่แตกต่างจากสไลด์ทั่วไป ดูที่ [Notes Page Size](/slides/th/net/notes-size/) เพื่อเปลี่ยนขนาดและการจัดวาง

## **วิธีเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างนี้แสดงการเปลี่ยนขนาดสไลด์ของงานนำเสนอด้วย Aspose.Slides ใน C#:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation-4x3.pptx"))
{
    pres.SlideSize.SetSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.Save("presentation-16x9.pptx", SaveFormat.Pptx);
}
```

## **ระบุขนาดสไลด์ที่กำหนดเอง**

การปรับขนาดสไลด์ให้เหมาะกับความต้องการเฉพาะของคุณ เช่น สำหรับการจัดวางกระดาษหรือสเปคจอที่ไม่ธรรมดา สามารถทำได้โดยใช้ Aspose.Slides for .NET:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation("presentation.pptx"))
{
    pres.SlideSize.SetSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.Save("presentation-a4.pptx", SaveFormat.Pptx);
}
```

## **จัดการเนื้อหาสไลด์หลังจากการปรับขนาด**

หลังจากปรับขนาด สไลด์อาจเสียรูปสัดส่วน คุณสามารถควบคุมวิธีที่ Aspose.Slides จัดการการปรับขนาดนี้ได้:

- **`DoNotScale`**: รักษาวัตถุไว้ที่ขนาดเดิมเพื่อหลีกเลี่ยงการสเกล
- **`EnsureFit`**: สเกลวัตถุให้พอดีกับสไลด์ที่เล็กลงเพื่อป้องกันการสูญหายของเนื้อหา
- **`Maximize`**: ขยายวัตถุให้เหมาะกับสไลด์ที่ใหญ่ขึ้นเพื่อความสวยงามสอดคล้อง

ตัวอย่างการใช้การตั้งค่า `Maximize` เพื่อปรับขนาดสไลด์:

```csharp
using Aspose.Slides;

using (Presentation pres = new Presentation("presentation.pptx"))
{
   pres.SlideSize.SetSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
}
```

## **คำถามที่พบบ่อย**

### ฉันสามารถตั้งขนาดสไลด์ที่กำหนดเองโดยใช้หน่วยที่ไม่ใช-inch (เช่น พอยท์หรือมิลลิเมตร) ได้หรือไม่?

ได้ Aspose.Slides ใช้พอยท์เป็นหน่วยภายใน โดย 1 พอยท์เท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นพอยท์แล้วใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์

### ขนาดสไลด์ที่กำหนดเองใหญ่เกินไปจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?

ได้ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นพอยท์) รวมกับสเกลการเรนเดอร์ที่สูงจะทำให้ใช้หน่วยความจำเพิ่มขึ้นและเวลาประมวลผลยาวนานขึ้น ควรเลือกขนาดสไลด์ที่เหมาะสมและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ

### ฉันสามารถกำหนดขนาดสไลด์ที่ไม่ได้มาตรฐานหนึ่งแบบแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?

คุณไม่สามารถ [merge presentations](/slides/th/net/merge-presentation/) ขณะที่สไลด์มีขนาดแตกต่างกัน — ต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานก่อน เมื่อเปลี่ยนขนาดสไลด์คุณสามารถเลือกวิธีจัดการเนื้อหาเดิมผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/net/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้เท่ากันแล้วจึงสามารถรวมสไลด์ได้โดยรักษาฟอร์แมตเดิมไว้

### ฉันสามารถสร้างภาพย่อสำหรับรูปทรงเดี่ยวหรือส่วนที่กำหนดของสไลด์ และภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?

ได้ Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [entire slides](https://reference.aspose.com/slides/th/net/aspose.slides/slide/getimage/) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/net/aspose.slides/shape/getimage/) ด้วย ภาพที่ได้จะสะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่และสอดคล้องกัน
