## **ภาพรวม**

เมื่อการนำเสนอถูกโหลด, แสดงผล, หรือแปลงเป็นรูปแบบอื่น, Aspose.Slides จะพิจารณาแบบอักษรที่ฝังอยู่และแบบอักษรที่พร้อมใช้งานสำหรับแอปพลิเคชัน หากแบบอักษรที่ต้องการไม่สามารถใช้ได้, Aspose.Slides จะเลือกแบบอักษรทดแทนที่ใกล้ที่สุดกับแบบอักษรที่ PowerPoint จะใช้.

แบบอักษรที่มีอยู่สามารถรวมถึงแบบอักษรของระบบ, แบบอักษรที่โหลดโดยแอปพลิเคชัน และแบบอักษรที่ฝังอยู่ในงานนำเสนอ สำหรับแบบอักษรที่ฝังและที่ลงทะเบียนตรงกัน, การตั้งค่า .NET 26.11 ที่อธิบายด้านล่างจะกำหนดว่าอันไหนมีลำดับความสำคัญกว่ากัน กฎการทดแทนแบบอักษรที่กำหนดผ่าน [FontSubstRule](https://reference.aspose.com/slides/net/aspose.slides/fontsubstrule/) เป็นกลไกที่แยกออกมา.

คุณยังสามารถเพิ่มแบบอักษรในระหว่างการทำงานของแอปพลิเคชัน, ใช้แบบอักษรที่ฝังจากงานนำเสนอ, หรือโหลดแบบอักษรภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF.

## **การเลือกแบบอักษร**

ข้อความสามารถอ้างอิงแบบอักษรธีม, เช่น `+mn-lt`, แทนชื่อครอบครัวที่ระบุอย่างชัดเจน ดู [แก้ไขการอ้างอิงแบบอักษรธีม](/slides/th/net/presentation-theme/#resolve-theme-font-references) เพื่อรับชื่อครอบครัวที่ระบุโดยธีมที่ใช้งาน การแก้ไขอ้างอิงนั้นแยกจากการตรวจสอบความพร้อมของแบบอักษรและการใช้การทดแทนระหว่างการเรนเดอร์หรือการสำรอง glyph; มันไม่ได้ระบุไฟล์แบบอักษรที่ใช้ในขั้นสุดท้ายเพื่อเรนเดอร์ข้อความ.

เมื่อทำการเรนเดอร์สไลด์หรือแปลงงานนำเสนอ, ตรวจสอบว่าแบบอักษรที่ร้องขอได้ถูกฝังหรือมีอยู่จากแหล่งที่ลงทะเบียนแล้ว แบบอักษรที่ขาดหาอาจต้องการการแทนที่หรือการทดแทน; ดู [**การแทนที่แบบอักษร**](/slides/th/net/font-replacement/) และ [**การทดแทนแบบอักษร**](/slides/th/net/font-substitution/).

เมื่อสำรวจการเลือกแบบอักษร:
1. แก้ไขครอบครัวและสไตล์ที่ร้องขอ, รวมถึงการอ้างอิงธีมใดๆ
2. ตรวจสอบแบบอักษรที่ฝังและแหล่งที่ลงทะเบียน, รวมถึงแบบอักษรของระบบและแบบอักษรที่โหลดโดยแอปพลิเคชัน ใช้การตั้งค่าต่อไปนี้เมื่อแบบอักษรที่ฝังและที่ลงทะเบียนตรงกันแข่งขันกัน
3. ตรวจสอบ [กฎการทดแทนแบบอักษร](https://reference.aspose.com/slides/net/aspose.slides/fontsubstrule/) และการสำรอง glyph หากแบบอักษรหรืออักขระที่ร้องขอไม่มี

Aspose.Slides อนุญาตให้คุณเพิ่มแบบอักษรในระหว่างการทำงานของแอปพลิเคชันและจากนั้นใช้แบบอักษรเหล่านั้น ดู [**แบบอักษรกำหนดเอง**](/slides/th/net/custom-font/).

เมื่อแบบอักษรเพิ่มเติมถูกวางไว้ภายในงานนำเสนอ, พวกมันจะถูกเรียกว่า [**แบบอักษรฝัง**](/slides/th/net/embedded-font/).

Aspose.Slides อนุญาตให้คุณเพิ่มแบบอักษรที่ใช้เฉพาะในเอกสารผลลัพธ์เท่านั้น *เท่านั้น* สำหรับตัวอย่าง, หากงานนำเสนอที่คุณต้องการแปลงเป็น PDF มีแบบอักษรที่ขาดหายจากระบบและแบบอักษรฝัง, คุณสามารถเพิ่มหรือโหลดแบบอักษรที่จำเป็นเป็น **แบบอักษรภายนอก**.

{{% alert title="Note" color="info" %}} 
เราจะไม่แจกจ่ายแบบอักษรใดๆ ไม่ว่าจะเป็นแบบที่ต้องชำระเงินหรือฟรี API ของเรายอมให้คุณโหลดแบบอักษรภายนอกและฝังไว้ในเอกสาร, แต่คุณทำเช่นนั้นด้วยแบบอักษรที่คุณเลือกและรับผิดชอบ.
{{% /alert %}}

## **ควรใช้แบบอักษรที่ลงทะเบียนเหนือแบบอักษรฝัง**

ตั้งแต่ .NET 26.11, [IFontsManager.PreferRegisteredFontsOverEmbedded](https://reference.aspose.com/slides/net/aspose.slides/ifontsmanager/preferregisteredfontsoverembedded/) ทำให้แบบอักษรที่ลงทะเบียนตรงกันมีลำดับความสำคัญเหนือแบบอักษรที่ฝังในระหว่างการส่งออก ค่าเริ่มต้นคือ `false`. การจับคู่อาศัยชื่อแบบอักษรและสไตล์; ชื่อครอบครัวที่แตกต่างไม่ถือเป็นการแทนที่ที่ตรงกัน. แบบอักษรที่ลงทะเบียนสามารถมาจากระบบหรือ [แหล่งแบบอักษรที่โหลดโดยชัดเจน](/slides/th/net/custom-font/).

ตัวอย่างต่อไปนี้ใช้แพคเกจ **Aspose.Slides.NET6.CrossPlatform 26.11** บน .NET 8. ปฏิบัติตาม [คู่มือการติดตั้ง](/slides/th/net/installation/) สำหรับสภาพแวดล้อมของคุณ ให้ไฟล์ `embedded-fonts.pptx` พร้อมแบบอักษรที่ฝังและ `preferred.ttf` ที่มีชื่อครอบครัวและสไตล์เดียวกัน ไฟล์แบบอักษรสองไฟล์ควรแตกต่างกันอย่างชัดเจนหากคุณต้องการเปรียบเทียบผลลัพธ์.

```csharp
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

var fontBytes = File.ReadAllBytes("preferred.ttf");
FontsLoader.LoadExternalFont(fontBytes);
using var presentation = new Presentation("embedded-fonts.pptx");

presentation.FontsManager.PreferRegisteredFontsOverEmbedded = false;
presentation.Save("embedded-preference.pdf", SaveFormat.Pdf);

presentation.FontsManager.PreferRegisteredFontsOverEmbedded = true;
presentation.Save("registered-preference.pdf", SaveFormat.Pdf);

presentation.FontsManager.PreferRegisteredFontsOverEmbedded = false;
presentation.Save("restored-preference.pdf", SaveFormat.Pdf);
```

การตั้งค่านี้เปลี่ยนลำดับความสำคัญของแบบอักษรในระหว่างการส่งออก; มันไม่ได้เปลี่ยนชื่อแบบอักษรของข้อความ, ลบข้อมูลแบบอักษรฝัง หรือฝังไฟล์ที่ลงทะเบียนใหม่. นี่เป็นการตั้งค่าในระหว่างการทำงาน: ตั้งค่าใหม่หลังจากเปิดงานนำเสนออีกครั้ง. หากไม่มีแบบอักษรที่ลงทะเบียนตรงกัน, การเปิดใช้งานการตั้งค่านี้จะไม่จัดหาแบบอักษร; ตรวจสอบแบบอักษรและการจัดวางที่ได้ในสภาพแวดล้อมเป้าหมายของคุณ.

ผลลัพธ์ PNG และ PDF ที่ใช้แบบอักษรปกติที่โหลดโดยชัดเจนได้ถูกตรวจสอบตามการตั้งค่าข้างต้น. ตรวจสอบไฟล์แบบอักษรของคุณ, สไตล์, การสร้าง SDK และรูปแบบผลลัพธ์ก่อนพึ่งพาผลลัพธ์ที่เหมือนกัน. เมตริกของแบบอักษรอาจเปลี่ยนการตัดบรรทัดและตำแหน่ง. ใช้ [การแทนที่แบบอักษร](/slides/th/net/font-replacement/) หรือ [การทดแทน](/slides/th/net/font-substitution/) เมื่อคุณต้องการครอบครัวที่แตกต่าง, และ [การดำเนินการแบบอักษรฝัง](/slides/th/net/embedded-font/) เมื่อคุณต้องการเปลี่ยนแบบอักษรที่จัดเก็บในงานนำเสนอ.

## **คำถามที่พบบ่อย**

**ฉันจะตรวจสอบว่าแบบอักษรใดที่ใช้จริงในงานนำเสนอก่อนการแปลงได้อย่างไร?**

Aspose.Slides ให้คุณตรวจสอบแบบอักษรที่ใช้ผ่าน [ผู้จัดการแบบอักษร](https://reference.aspose.com/slides/net/aspose.slides/presentation/fontsmanager/), เพื่อให้คุณสามารถตัดสินใจว่าจะ [ฝัง](/slides/th/net/embedded-font/), [แทนที่](/slides/th/net/font-replacement/), หรือเพิ่ม [แหล่งภายนอก](/slides/th/net/custom-font/) หรือไม่. สิ่งนี้ช่วยให้คุณป้องกันการทดแทนที่ไม่ต้องการระหว่างการเรนเดอร์และการส่งออก.

**ฉันสามารถเพิ่มไดเรกทรีแบบอักษรเพิ่มเติมโดยไม่ต้องติดตั้งบนระบบปฏิบัติการได้หรือไม่?**

ใช่. คุณสามารถลงทะเบียน [แหล่งแบบอักษรภายนอก](/slides/th/net/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำสำหรับการเรนเดอร์และการส่งออก. สิ่งนี้ช่วยลดการพึ่งพาแบบอักษรของระบบโฮสต์และทำให้การจัดวางคาดเดาได้.

**ฉันจะป้องกันการสำรองที่เงียบโดยอัตโนมัติไปยังแบบอักษรที่ไม่เหมาะสมเมื่อ glyph หายไปได้อย่างไร?**

กำหนดการ [แทนที่แบบอักษร](/slides/th/net/font-replacement/) และ [กฎการสำรองแบบอักษร](/slides/th/net/fallback-font/) อย่างชัดเจนล่วงหน้า. โดยการวิเคราะห์แบบอักษรที่ใช้และตั้งค่าลำดับความสำคัญที่ควบคุมสำหรับการทดแทน, คุณจะทำให้การออกแบบตัวอักษรสอดคล้องและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด.
