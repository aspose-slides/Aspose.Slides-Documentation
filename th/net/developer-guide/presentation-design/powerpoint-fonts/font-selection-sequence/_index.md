## **ภาพรวม**

เมื่อโหลด การแสดงผล หรือแปลงงานนำเสนอเป็นรูปแบบอื่น Aspose.Slides จะตรวจสอบว่าแบบอักษรที่ใช้ในงานนำเสนอมีอยู่ในระบบปฏิบัติการหรือไม่ หากแบบอักษรที่ต้องการขาดหายไป Aspose.Slides จะเลือกแบบอักษรแทนที่ที่ใกล้เคียงที่สุดกับแบบอักษรที่ PowerPoint จะใช้

Aspose.Slides จะค้นหาแบบอักษรที่เลือกในระบบปฏิบัติการเป็นอันดับแรก หากพบแบบอักษรจะถูกใช้ หากไม่พบจะใช้แบบอักษรแทนที่ที่เหมาะสม เมื่อนิยามกฎการแทนที่แบบอักษรผ่าน `FontSubstRule` กฎเหล่านั้นก็จะถูกนำมาพิจารณาด้วย

คุณยังสามารถเพิ่มแบบอักษรระหว่างการทำงานของแอปพลิเคชัน ใช้แบบอักษรฝังจากงานนำเสนอ หรือโหลดแบบอักษรภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF

## **การเลือกแบบอักษร**

กฎบางอย่างจะนำไปใช้กับแบบอักษรในงานนำเสนอเมื่อโหลด แสดงผล หรือแปลงเป็นรูปแบบอื่น ตัวอย่างเช่น เมื่อคุณพยายามแปลงงานนำเสนอ (สไลด์) เป็นภาพ แบบอักษรของงานนำเสนอจะถูกตรวจสอบเพื่อยืนยันว่ามีแบบอักษรที่เลือกอยู่ในระบบปฏิบัติการหรือไม่ หากยืนยันว่าแบบอักษรขาดหาย จะมีการแทนที่ — ดูที่ [**การแทนที่แบบอักษร**](https://docs.aspose.com/slides/th/net/font-replacement/) และ [**การสับเปลี่ยนแบบอักษร**](https://docs.aspose.com/slides/th/net/font-substitution/)

นี่คือขั้นตอนที่ Aspose.Slides ปฏิบัติตามเมื่อจัดการแบบอักษร:

1. Aspose.Slides ค้นหาแบบอักษรในระบบปฏิบัติการเพื่อหาความตรงกับแบบอักษรที่เลือกในงานนำเสนอ
2. หากพบแบบอักษรที่เลือก Aspose.Slides จะใช้มัน มิฉะนั้น Aspose.Slides จะใช้แบบอักษรแทนที่ที่ใกล้เคียงที่สุดกับที่ PowerPoint จะใช้
3. หากมีกฎการแทนที่แบบอักษรที่ตั้งค่าผ่าน [FontSubstRule](https://reference.aspose.com/slides/th/net/aspose.slides/fontsubstrule/) จะถูกนำไปใช้

Aspose.Slides ให้คุณเพิ่มแบบอักษรในช่วง runtime ของแอปพลิเคชันและใช้แบบอักษรเหล่านั้น ดูที่ [**แบบอักษรกำหนดเอง**](https://docs.aspose.com/slides/th/net/custom-font/)

เมื่อแบบอักษรเพิ่มเติมถูกวางไว้ในงานนำเสนอ จะเรียกว่า [**แบบอักษรฝัง**](https://docs.aspose.com/slides/th/net/embedded-font/)

Aspose.Slides ให้คุณเพิ่มแบบอักษรที่ใช้กับเอกสารผลลัพธ์ *เท่านั้น* ตัวอย่างเช่น หากงานนำเสนอที่คุณต้องการแปลงเป็น PDF มีแบบอักษรที่ระบบของคุณและแบบอักษรฝังไม่มีอยู่ คุณสามารถเพิ่มหรือโหลดแบบอักษรที่ต้องการเป็น **แบบอักษรภายนอก**

{{% alert title="Note" color="info" %}} 
เราไม่ได้จัดจำหน่ายแบบอักษรใดๆ ไม่ว่าจะเป็นแบบชำระเงินหรือแบบฟรี API ของเรารองรับให้คุณโหลดแบบอักษรภายนอกและฝังลงในเอกสาร แต่คุณต้องทำเช่นนั้นด้วยแบบอักษรตามดุลยพินิจและความรับผิดชอบของคุณเอง
{{% /alert %}}

## **คำถามที่พบบ่อย**

### ฉันจะตรวจสอบว่าแบบอักษรใดที่ใช้งานจริงในงานนำเสนอก่อนการแปลงได้อย่างไร?

Aspose.Slides ให้คุณตรวจสอบแบบอักษรที่ใช้ผ่าน [font manager](https://reference.aspose.com/slides/th/net/aspose.slides/presentation/fontsmanager/) เพื่อให้คุณตัดสินใจว่าจะ [embed](/slides/th/net/embedded-font/), [replace](/slides/th/net/font-replacement/), หรือเพิ่ม [external sources](/slides/th/net/custom-font/) หรือไม่ การทำเช่นนี้ช่วยป้องกันการแทนที่ที่ไม่ต้องการขณะแสดงผลและส่งออก

### ฉันสามารถเพิ่มไดเรกทอรีแบบอักษรเพิ่มเติมโดยไม่ต้องติดตั้งบนระบบปฏิบัติการได้หรือไม่?

ได้ คุณสามารถลงทะเบียน [external font sources](/slides/th/net/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำสำหรับการแสดงผลและส่งออก วิธีนี้จะลดการพึ่งพาแบบอักษรของระบบโฮสต์และทำให้การจัดวางคาดเดาได้

### ฉันจะป้องกันการเปลี่ยนไปใช้แบบอักษรที่ไม่เหมาะสมโดยไม่แจ้งเตือนเมื่อไม่มี glyph ได้อย่างไร?

กำหนด [font replacement](/slides/th/net/font-replacement/) และกฎ [fallBack rules](/slides/th/net/fallback-font/) ของแบบอักษรอย่างชัดเจนล่วงหน้า โดยการวิเคราะห์แบบอักษรที่ใช้และตั้งลำดับความสำคัญที่ควบคุมสำหรับแบบอักษรทดแทน คุณจะทำให้การพิมพ์เป็นแบบสม่ำเสมอและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด
