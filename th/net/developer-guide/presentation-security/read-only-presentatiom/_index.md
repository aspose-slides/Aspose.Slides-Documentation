## **คำนำ**

ใน PowerPoint 2019, Microsoft ได้นำการตั้งค่า **Always Open Read-Only** มาเป็นหนึ่งในตัวเลือกที่ผู้ใช้สามารถใช้เพื่อปกป้องการนำเสนอของตน คุณอาจต้องการใช้การตั้งค่าอ่านอย่างเดียวนี้เพื่อปกป้องการนำเสนอเมื่อ

- คุณต้องการป้องกันการแก้ไขโดยไม่ได้ตั้งใจและรักษาเนื้อหาของการนำเสนอให้ปลอดภัย
- คุณต้องการแจ้งให้ผู้คนทราบว่าการนำเสนอที่คุณให้คือเวอร์ชันสุดท้าย

หลังจากคุณเลือกตัวเลือก **Always Open Read-Only** สำหรับการนำเสนอ เมื่อผู้ใช้เปิดการนำเสนอ พวกเขาจะเห็นคำแนะนำ **Read-Only** และอาจเห็นข้อความรูปแบบนี้: *เพื่อป้องกันการเปลี่ยนแปลงโดยไม่ได้ตั้งใจ ผู้เขียนได้ตั้งค่าไฟล์นี้ให้เปิดเป็นอ่านอย่างเดียว*

คำแนะนำ Read-Only เป็นวิธีการที่ง่ายแต่มีประสิทธิภาพในการกั้นการแก้ไข เพราะผู้ใช้ต้องทำขั้นตอนเพื่อเอาคำแนะนำออกก่อนจึงจะสามารถแก้ไขการนำเสนอได้ หากคุณไม่ต้องการให้ผู้ใช้ทำการเปลี่ยนแปลงการนำเสนอและต้องการบอกพวกเขาในวิธีที่สุภาพ คำแนะนำ Read-Only อาจเป็นตัวเลือกที่ดีสำหรับคุณ

> หากการนำเสนอที่มีการป้องกัน **Read-Only** ถูกเปิดในโปรแกรม Microsoft PowerPoint รุ่นเก่าซึ่งไม่รองรับฟังก์ชันที่เพิ่งแนะนำ คำแนะนำ **Read-Only** จะถูกละเลย (การนำเสนอจะเปิดตามปกติ)

## **ใช้โหมดอ่านอย่างเดียว**

Aspose.Slides for .NET อนุญาตให้คุณตั้งค่าการนำเสนอเป็น **Read-Only** ซึ่งหมายความว่าผู้ใช้ (หลังจากเปิดการนำเสนอ) จะเห็นคำแนะนำ **Read-Only** ตัวอย่างโค้ดนี้แสดงวิธีตั้งค่าการนำเสนอเป็น **Read-Only** ใน C# ด้วย Aspose.Slides:

```c#
using Aspose.Slides;
using Aspose.Slides.Export;

using (Presentation pres = new Presentation())
{
    pres.ProtectionManager.ReadOnlyRecommended = true;
    pres.Save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
}
```

{{% alert color="info" %}} 

**หมายเหตุ**: คำแนะนำ **Read-Only** มีจุดประสงค์เพื่อกั้นการแก้ไขหรือหยุดผู้ใช้จากการทำการเปลี่ยนแปลงโดยไม่ได้ตั้งใจในไฟล์ PowerPoint หากบุคคลที่มีความตั้งใจ—ซึ่งรู้ว่าตนกำลังทำอะไร—ตัดสินใจแก้ไขการนำเสนอของคุณ พวกเขาสามารถลบการตั้งค่า Read-Only ได้อย่างง่ายดาย หากคุณต้องการป้องกันการแก้ไขโดยไม่ได้รับอนุญาตอย่างจริงจัง คุณควรใช้ [การป้องกันที่เข้มงวดมากขึ้นที่รวมการเข้ารหัสและรหัสผ่าน](https://docs.aspose.com/slides/th/net/password-protected-presentation/) 

{{% /alert %}} 

## **คำถามที่พบบ่อย**

### 'Read-Only recommended' แตกต่างจากการป้องกันด้วยรหัสผ่านเต็มอย่างไร?

'Read-Only recommended' เพียงแสดงข้อเสนอแนะให้เปิดไฟล์ในโหมดอ่านอย่างเดียวและสามารถข้ามได้ง่าย [การป้องกันด้วยรหัสผ่าน](/slides/th/net/password-protected-presentation/) จะจำกัดการเปิดหรือการแก้ไขจริงและเหมาะสมเมื่อคุณต้องการการควบคุมความปลอดภัยจริง

### 'Read-Only recommended' สามารถรวมกับลายน้ำเพื่อยับยั้งการแก้ไขเพิ่มเติมได้หรือไม่?

ใช่ คำแนะนำสามารถจับคู่กับ [ลายน้ำ](/slides/th/net/watermark/) เป็นการกั้นแบบเชิงภาพ; พวกมันเป็นกลไกแยกกันและทำงานร่วมกันได้ดี

### แมคโครหรือเครื่องมือภายนอกยังคงสามารถแก้ไขไฟล์ได้เมื่อคำแนะนำเปิดอยู่หรือไม่?

ใช่ คำแนะนำไม่บล็อกการเปลี่ยนแปลงโดยโปรแกรม; เพื่อป้องกันการแก้ไขอัตโนมัติ ใช้ [รหัสผ่านและการเข้ารหัส](/slides/th/net/password-protected-presentation/)

### 'Read-Only recommended' เกี่ยวข้องกับแฟล็ก 'IsEncrypted' และ 'IsWriteProtected' อย่างไร?

พวกมันเป็นสัญญาณที่แตกต่างกัน 'Read-Only recommended' เป็นพรอมต์แบบอ่อนและเป็นทางเลือก; [IsWriteProtected](https://reference.aspose.com/slides/th/net/aspose.slides/protectionmanager/iswriteprotected/) และ [IsEncrypted](https://reference.aspose.com/slides/th/net/aspose.slides/protectionmanager/isencrypted/) แสดงข้อจำกัดการเขียนหรือการอ่านจริงที่ขึ้นอยู่กับรหัสผ่านหรือการเข้ารหัส
