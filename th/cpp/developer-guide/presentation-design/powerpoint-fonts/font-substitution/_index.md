## **ภาพรวม**

การทดแทนแบบอักษรทำให้ Aspose.Slides สามารถใช้แบบอักษรอื่นเมื่อแบบอักษรของงานนำเสนอเดิมไม่พร้อมใช้งานระหว่างการเรนเดอร์หรือการแปลง คุณสามารถตรวจสอบว่าแบบอักษรใดถูกทดแทนได้โดยใช้เมธอด `GetSubstitutions` จากอินเทอร์เฟซ `IFontsManager`.

Aspose.Slides ยังอนุญาตให้คุณกำหนดกฎการทดแทนแบบอักษรได้ ตัวอย่างเช่น คุณสามารถระบุว่าแบบอักษรที่ไม่สามารถเข้าถึงได้ควรถูกแทนที่ด้วยแบบอักษรที่พร้อมใช้งานอื่นแล้วใช้กฎเหล่านั้นผ่านตัวจัดการแบบอักษรของงานนำเสนอ

## **ตั้งค่ากฎการทดแทนแบบอักษร**

Aspose.Slides อนุญาตให้คุณตั้งค่ากฎสำหรับแบบอักษรที่กำหนดว่าจะทำอะไรในสภาวะบางอย่าง (เช่น เมื่อไม่สามารถเข้าถึงแบบอักษรได้) ด้วยวิธีต่อไปนี้:

1. โหลดงานนำเสนอที่เกี่ยวข้อง
2. โหลดแบบอักษรที่ต้องการแทนที่
3. โหลดแบบอักษรใหม่
4. เพิ่มกฎสำหรับการแทนที่
5. เพิ่มกฎลงในคอลเล็กชันกฎการแทนที่แบบอักษรของงานนำเสนอ
6. สร้างภาพสไลด์เพื่อดูผลลัพธ์

โค้ด C++ นี้แสดงกระบวนการทดแทนแบบอักษร:

```c++
// เส้นทางไปยังไดเรกทอรีเอกสาร
const String outPath = u"../out/RuleBasedFontsReplacement_out.pptx";
const String templatePath = u"../templates/DefaultFonts.pptx";


// โหลดงานนำเสนอ
SharedPtr<Presentation> pres = MakeObject<Presentation>(templatePath);

// กำหนดแบบอักษรที่จะแทนที่และแบบอักษรใหม่
SharedPtr<IFontData> sourceFont = MakeObject<FontData>(u"SomeRareFont");
SharedPtr<IFontData> destFont = MakeObject<FontData>(u"Arial");
	
// เพิ่มกฎแบบอักษรสำหรับการแทนที่แบบอักษร
SharedPtr<FontSubstRule> fontSubstRule = MakeObject<FontSubstRule>(sourceFont, destFont, FontSubstCondition::WhenInaccessible);

// เพิ่มกฎลงในคอลเลกชันของกฎการทดแทนแบบอักษร
SharedPtr<FontSubstRuleCollection> fontSubstRuleCollection = MakeObject<FontSubstRuleCollection>();
fontSubstRuleCollection->Add(fontSubstRule);

// เพิ่มคอลเลกชันกฎแบบอักษรไปยังรายการกฎ
pres->get_FontsManager()->set_FontSubstRuleList ( fontSubstRuleCollection);


// บันทึก PPTX ลงดิสก์
pres->Save(outPath, Aspose::Slides::Export::SaveFormat::Pptx);
```

## **ข้อจำกัดสำหรับแบบอักษรสมการคณิตศาสตร์**

กฎการทดแทนแบบอักษรมีส่วนร่วมในกระบวนการเลือกแบบอักษรมาตรฐานที่ใช้ระหว่างการเรนเดอร์และการแปลง มันเหมาะสำหรับสถานการณ์ข้อความทั่วไปที่ Aspose.Slides สามารถแทนที่แบบอักษรที่ไม่สามารถเข้าถึงได้ด้วยแบบอักษรที่พร้อมใช้งานอื่นตามกฎที่กำหนด

อย่างไรก็ตาม สมการคณิตศาสตร์ของ Office มีข้อจำกัดสำคัญ หากสมการถูกสร้างด้วย **Cambria Math** Aspose.Slides อาจยังต้องการแบบอักษร **Cambria Math** ดั้งเดิมเพื่อคำนวณและเรนเดอร์เค้าโครงสมการอย่างถูกต้อง ด้วยเหตุนี้การทดแทน **Cambria Math** ด้วยแบบอักษรคณิตศาสตร์อื่น เช่น **STIX Two Math** ไม่ได้รับการสนับสนุนสำหรับการเรนเดอร์สมการและอาจยังทำให้เกิดข้อยกเว้นที่ระบุว่าต้องการ **Cambria Math**

เพื่อแปลงงานนำเสนอเหล่านี้ให้สำเร็จ โปรดตรวจสอบว่า **Cambria Math** พร้อมใช้งานสำหรับ Aspose.Slides ในช่วงรันไทม์ คุณสามารถติดตั้งแบบอักษรนี้ในระบบปฏิบัติการหรือจัดหาเป็น [แบบอักษรภายนอก](/slides/th/cpp/custom-font/) เพื่อให้มันมีส่วนร่วมในกระบวนการเลือกแบบอักษรปกติระหว่างการเรนเดอร์และการแปลง

ข้อจำกัดนี้เฉพาะสำหรับการเรนเดอร์สมการ กฎการทดแทนแบบอักษรมาตรฐานที่อธิบายไว้ข้างต้นยังคงใช้กับข้อความทั่วไปของงานนำเสนอเมื่อแบบอักษรเดิมไม่สามารถเข้าถึงได้

## **คำถามที่พบบ่อย**

**ความแตกต่างระหว่างการเปลี่ยนแบบอักษรและการทดแทนแบบอักษรคืออะไร?**  
[Replacement](/slides/th/cpp/font-replacement/) คือการบังคับแทนที่แบบอักษรหนึ่งด้วยอีกแบบหนึ่งทั่วทั้งงานนำเสนอ การทดแทนคือกฎที่ทำงานเมื่อเงื่อนไขเฉพาะเกิดขึ้น เช่น เมื่อแบบอักษรเดิมไม่พร้อมใช้งาน แล้วใช้แบบอักษรสำรองที่กำหนด

**กฎการทดแทนจะถูกนำไปใช้เมื่อใด?**  
กฎเหล่านี้มีส่วนร่วมในลำดับการ [การเลือกแบบอักษร](/slides/th/cpp/font-selection-sequence/) มาตรฐานที่ประเมินระหว่างการโหลด, การเรนเดอร์, และการแปลง; หากแบบอักษรที่เลือกไม่พร้อมใช้งาน การแทนที่หรือการทดแทนจะถูกนำไปใช้

**พฤติกรรมเริ่มต้นคืออะไรหากไม่มีการกำหนดการแทนที่หรือการทดแทนและแบบอักษรไม่มีในระบบ?**  
ไลบรารีจะพยายามเลือกแบบอักษรระบบที่ใกล้เคียงที่สุดที่พร้อมใช้งาน คล้ายกับพฤติกรรมของ PowerPoint

**ฉันสามารถแนบแบบอักษรภายนอกที่กำหนดเองในช่วงรันไทม์เพื่อหลีกเลี่ยงการทดแทนได้หรือไม่?**  
ใช่ คุณสามารถ [เพิ่มแบบอักษรภายนอก](/slides/th/cpp/custom-font/) ในช่วงรันไทม์เพื่อให้ไลบรารีพิจารณาใช้ในการเลือกและการเรนเดอร์ รวมถึงการแปลงต่อไป

**Aspose แจกจ่ายแบบอักษรใดกับไลบรารีหรือไม่?**  
ไม่ Aspose ไม่ได้แจกจ่ายแบบอักษรทั้งแบบที่ต้องจ่ายเงินหรือฟรี; คุณต้องเพิ่มและใช้แบบอักษรด้วยดุลยพินิจและความรับผิดชอบของคุณเอง

**มีความแตกต่างในการทำงานของการทดแทนบน Windows, Linux, และ macOS หรือไม่?**  
มี การค้นหาแบบอักษรเริ่มจากไดเรกทอรีแบบอักษรของระบบปฏิบัติการ ชุดแบบอักษรเริ่มต้นที่พร้อมใช้งานและเส้นทางการค้นหาจะแตกต่างกันตามแพลตฟอร์ม ซึ่งส่งผลต่อความพร้อมใช้งานและความจำเป็นของการทดแทน

**ฉันควรเตรียมสภาพแวดล้อมอย่างไรเพื่อให้น้อยที่สุดการทดแทนที่ไม่คาดคิดในระหว่างการแปลงแบบชุด?**  
ซิงโครไนซ์ชุดแบบอักษรระหว่างเครื่องหรือคอนเทนเนอร์, [เพิ่มแบบอักษรภายนอก](/slides/th/cpp/custom-font/) ที่จำเป็นสำหรับเอกสารผลลัพธ์, และ [ฝังแบบอักษร](/slides/th/cpp/embedded-font/) ในงานนำเสนอเมื่อทำได้เพื่อให้แบบอักษรที่เลือกพร้อมใช้งานในระหว่างการเรนเดอร์
