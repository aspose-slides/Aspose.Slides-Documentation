## **ภาพรวม**

Aspose.Slides ช่วยให้คุณกำหนดแบบอักษรเริ่มต้นที่ใช้เมื่อการนำเสนอถูกเรนเดอร์ ซึ่งเป็นประโยชน์เมื่อต้องสร้างภาพย่อสไลด์หรือส่งออกการนำเสนอเป็นรูปแบบต่าง ๆ เช่น PDF และ XPS แบบอักษรเริ่มต้นจะถูกกำหนดผ่าน `LoadOptions` ก่อนที่จะโหลดการนำเสนอ

The method `set_DefaultRegularFont` กำหนดแบบอักษรเริ่มต้นสำหรับข้อความทั่วไป ในขณะที่ `set_DefaultAsianFont` กำหนดแบบอักษรเริ่มต้นสำหรับข้อความแบบเอเชีย หลังจากกำหนดตัวเลือกเหล่านี้แล้ว การนำเสนอสามารถโหลดและเรนเดอร์โดยใช้แบบอักษรที่ระบุได้

## **ใช้แบบอักษรเริ่มต้นสำหรับการเรนเดอร์การนำเสนอ**
Aspose.Slides ให้คุณตั้งค่าแบบอักษรเริ่มต้นสำหรับการเรนเดอร์การนำเสนอเป็น PDF, XPS หรือภาพย่อ บทความนี้แสดงวิธีกำหนด DefaultRegular Font และ DefaultAsian Font เพื่อใช้เป็นแบบอักษรเริ่มต้น โปรดทำตามขั้นตอนด้านล่างเพื่อโหลดแบบอักษรจากไดเรกทอรีภายนอกโดยใช้ Aspose.Slides for C++ API:

1. สร้างอินสแตนซ์ของ LoadOptions.
2. ตั้งค่า DefaultRegularFont ให้เป็นแบบอักษรที่คุณต้องการ ในตัวอย่างต่อไปนี้ ฉันได้ใช้ Wingdings.
3. ตั้งค่า DefaultAsianFont ให้เป็นแบบอักษรที่คุณต้องการ ฉันได้ใช้ Wingdings ในตัวอย่างต่อไปนี้.
4. โหลดการนำเสนอโดยใช้ Presentation และตั้งค่าตัวเลือกการโหลด.
5. จากนั้นสร้างภาพย่อสไลด์, PDF และ XPS เพื่อตรวจสอบผลลัพธ์.

การนำไปใช้ของด้านบนแสดงไว้ด้านล่าง

```cpp
// ใช้ตัวเลือกการโหลดเพื่อกำหนดแบบอักษรปกติและแบบอักษรเอเชียเริ่มต้น
auto loadOptions = MakeObject<LoadOptions>(LoadFormat::Auto);
loadOptions->set_DefaultRegularFont(u"Wingdings");
loadOptions->set_DefaultAsianFont(u"Wingdings");

auto pptx = MakeObject<Presentation>(u"DefaultFonts.pptx", loadOptions);

auto image = pptx->get_Slide(0)->GetImage(1, 1);
image->Save(u"DefaultFonts_out.png", ImageFormat::Png);
image->Dispose();

pptx->Save(u"DefaultFonts_out.pdf", SaveFormat::Pdf);
pptx->Save(u"DefaultFonts_out.xps", SaveFormat::Xps);

pptx->Dispose();
```

## **คำถามที่พบบ่อย**

**DefaultRegularFont และ DefaultAsianFont มีผลอย่างไรบ้าง—เฉพาะการส่งออก หรือรวมถึงภาพย่อ, PDF, XPS, HTML, และ SVG ด้วยหรือไม่?**

พวกเขามีส่วนร่วมในขั้นตอนการเรนเดอร์สำหรับผลลัพธ์ที่รองรับทั้งหมด ซึ่งรวมถึงภาพย่อของสไลด์, [PDF](/slides/th/cpp/convert-powerpoint-to-pdf/), [XPS](/slides/th/cpp/convert-powerpoint-to-xps/), [รูปภาพแรสเตอร์](/slides/th/cpp/convert-powerpoint-to-png/), [HTML](/slides/th/cpp/convert-powerpoint-to-html/), และ [SVG](/slides/th/cpp/render-a-slide-as-an-svg-image/), เนื่องจาก Aspose.Slides ใช้ตรรกะการจัดวางและการแก้ไข glyph เดียวกันในเป้าหมายเหล่านี้

**แบบอักษรเริ่มต้นจะถูกนำไปใช้เมื่อทำการอ่านและบันทึกไฟล์ PPTX เพียงอย่างเดียวโดยไม่ได้ทำการเรนเดอร์หรือไม่?**

ไม่ แบบอักษรเริ่มต้นมีความสำคัญเมื่อข้อความต้องถูกวัดและวาด การเปิด‑บันทึกแบบตรงของการนำเสนอไม่ทำให้การเรียงแบบอักษรที่จัดเก็บหรือโครงสร้างของไฟล์เปลี่ยนแปลง แบบอักษรเริ่มต้นจะมีผลในระหว่างการดำเนินการที่ทำการเรนเดอร์หรือเรียงข้อความใหม่

**หากฉันเพิ่มโฟลเดอร์แบบอักษรของตนเองหรือให้แบบอักษรจากหน่วยความจำ จะได้รับการพิจารณาเมื่อเลือกแบบอักษรเริ่มต้นหรือไม่?**

ใช่ [แหล่งแบบอักษรแบบกำหนดเอง](/slides/th/cpp/custom-font/) จะขยายแคตตาล็อกของครอบครัวและ glyph ที่มีให้แก่เอนจิน ใช้แบบอักษรเริ่มต้นและ [กฎสำรอง](/slides/th/cpp/fallback-font/) จะถูกตรวจสอบกับแหล่งเหล่านั้นก่อน ทำให้การรองรับบนเซิร์ฟเวอร์และคอนเทนเนอร์เชื่อถือได้มากขึ้น

**แบบอักษรเริ่มต้นจะส่งผลต่อเมตริกของข้อความ (การจัดระยะห่าง, การก้าวหน้า) และทำให้การตัดบรรทัดและการห่อข้อความเปลี่ยนแปลงหรือไม่?**

ใช่ การเปลี่ยนแบบอักษรจะทำให้เมตริกของ glyph เปลี่ยนแปลงและอาจทำให้การตัดบรรทัด, การห่อ, และการแบ่งหน้าเปลี่ยนแปลงในระหว่างการเรนเดอร์ เพื่อความเสถียรของการจัดวาง ควร [ฝังแบบอักษรต้นฉบับ](/slides/th/cpp/embedded-font/) หรือเลือกครอบครัวแบบอักษรเริ่มต้นและสำรองที่เข้ากันในเชิงเมตริก

**มีประโยชน์ใดในการตั้งค่าแบบอักษรเริ่มต้นหากแบบอักษรทั้งหมดที่ใช้ในการนำเสนอมาถูกฝังไว้หรือไม่?**

โดยส่วนใหญ่ไม่จำเป็น เนื่องจาก [แบบอักษรที่ฝังไว้](/slides/th/cpp/embedded-font/) ทำให้การแสดงผลคงที่อยู่แล้ว แต่แบบอักษรเริ่มต้นยังคงเป็นประโยชน์เป็นเส้นสนับสนุนกรณีตัวอักษรที่ไม่ได้ครอบคลุมโดยชุดฝังหรือเมื่อไฟล์ผสมข้อความที่ฝังและไม่ได้ฝัง
