## **ภาพรวม**

Aspose.Slides ให้คุณเปลี่ยนฟอนต์หนึ่งเป็นอีกฟอนต์หนึ่งทั่วทั้งงานนำเสนอ เมื่อฟอนต์ถูกเปลี่ยน ทุกการอ้างอิงของฟอนต์ต้นฉบับจะถูกแทนที่ด้วยฟอนต์ใหม่.

เพื่อทำการแทนที่ฟอนต์ ให้โหลดงานนำเสนอ กำหนดฟอนต์ต้นฉบับและฟอนต์ที่จะแทนที่ เรียกใช้เมธอดการแทนที่ฟอนต์ แล้วบันทึกงานนำเสนอที่แก้ไขเป็นไฟล์ PPTX วิธีนี้มีประโยชน์เมื่อคุณต้องการสลับฟอนต์จากตระกูลหนึ่งไปยังอีกตระกูลหนึ่งทั่วทั้งงานนำเสนอโดยเจตนา.

## **แทนที่ฟอนต์**

หากคุณเปลี่ยนใจเกี่ยวกับการใช้ฟอนต์ คุณสามารถแทนที่ฟอนต์นั้นด้วยฟอนต์อื่นได้ การอ้างอิงทั้งหมดของฟอนต์เก่าจะถูกแทนที่ด้วยฟอนต์ใหม่.

Aspose.Slides ให้คุณแทนที่ฟอนต์ด้วยวิธีนี้:

1. โหลดงานนำเสนอที่เกี่ยวข้อง. 
2. โหลดฟอนต์ที่ต้องการแทนที่. 
3. โหลดฟอนต์ใหม่. 
4. ทำการแทนที่ฟอนต์. 
5. บันทึกงานนำเสนอที่แก้ไขเป็นไฟล์ PPTX.

โค้ด C++ นี้แสดงการแทนที่ฟอนต์:

``` cpp
// โหลดงานนำเสนอ
auto presentation = System::MakeObject<Presentation>(u"Fonts.pptx");

// โหลดฟอนต์ต้นฉบับที่จะถูกแทนที่
auto sourceFont = System::MakeObject<FontData>(u"Arial");

// โหลดฟอนต์ใหม่
auto destFont = System::MakeObject<FontData>(u"Times New Roman");

// แทนที่ฟอนต์
presentation->get_FontsManager()->ReplaceFont(sourceFont, destFont);

// บันทึกงานนำเสนอ
presentation->Save(u"UpdatedFont_out.pptx", SaveFormat::Pptx);
```

{{% alert title="Note" color="warning" %}} 
เพื่อกำหนดกฎที่ระบุว่าจะทำอย่างไรในบางเงื่อนไข (เช่น ฟอนต์ไม่สามารถเข้าถึงได้) ให้ดูที่ [**การทดแทนฟอนต์**](/slides/th/cpp/font-substitution/).

## **คำถามที่พบบ่อย**

**ความแตกต่างระหว่าง "font replacement", "font substitution", และ "fallback fonts" คืออะไร?**

การแทนที่เป็นการสลับโดยเจตนาจากตระกูลฟอนต์หนึ่งไปยังอีกตระกูลหนึ่งทั่วทั้งเอกสาร. [การทดแทน](/slides/th/cpp/font-substitution/) คือกฎเช่น “หากฟอนต์ไม่พร้อมใช้งาน ให้ใช้ X.” [ฟอนต์สำรอง](/slides/th/cpp/fallback-font/) จะถูกนำไปใช้แบบเจาะจงสำหรับ glyph ที่หายเมื่อฟอนต์ฐานถูกติดตั้งแต่ไม่มีอักขระที่ต้องการ.

**การแทนที่มีผลกับสไลด์มาสเตอร์, เลย์เอาต์, โน้ต, และคอมเมนต์หรือไม่?**

ใช่ การแทนที่มีผลต่อวัตถุทั้งหมดในงานนำเสนอที่ใช้ฟอนต์ต้นฉบับ รวมถึงสไลด์มาสเตอร์และโน้ต; คอมเมนต์ก็เป็นส่วนหนึ่งของเอกสารและจะถูกพิจารณาโดยเอนจินฟอนต์.

**ฟอนต์จะเปลี่ยนในวัตถุ OLE ที่ฝังอยู่ (เช่น Excel) หรือไม่?**

ไม่. [เนื้อหา OLE](/slides/th/cpp/manage-ole/) ถูกควบคุมโดยแอปพลิเคชันของมันเอง การแทนที่ในงานนำเสนอไม่ได้จัดรูปแบบข้อมูล OLE ภายในใหม่; มันอาจจะแสดงเป็นภาพหรือเป็นเนื้อหาที่แก้ไขได้จากภายนอก.

**ฉันสามารถแทนที่ฟอนต์เฉพาะบางส่วนของงานนำเสนอ (ตามสไลด์หรือพื้นที่) ได้หรือไม่?**

การแทนที่แบบเจาะจงเป็นไปได้หากคุณเปลี่ยนฟอนต์ระดับวัตถุ/ช่วงที่ต้องการแทนที่จะทำการแทนที่ทั่วทั้งเอกสารโดยรวม ตรรกะการเลือกฟอนต์โดยรวมระหว่างการเรนเดอร์ยังคงเหมือนเดิม.

**ฉันจะตรวจสอบล่วงหน้าว่างานนำเสนอใช้ฟอนต์อะไรบ้าง?**

ใช้ [ผู้จัดการฟอนต์](https://reference.aspose.com/slides/th/cpp/aspose.slides/fontsmanager/): มันให้รายการของ [ตระกูลที่ใช้งาน](https://reference.aspose.com/slides/th/cpp/aspose.slides/fontsmanager/getfonts/) และข้อมูลเกี่ยวกับ [การทดแทน/ฟอนต์ "ไม่ทราบ"](https://reference.aspose.com/slides/th/cpp/aspose.slides/fontsmanager/getsubstitutions/), ซึ่งช่วยวางแผนการแทนที่.

**การแทนที่ฟอนต์ทำงานเมื่อแปลงเป็น PDF/รูปภาพหรือไม่?**

ใช่ ในระหว่างการส่งออก Aspose.Slides ใช้ [ลำดับการเลือก/การทดแทนฟอนต์](/slides/th/cpp/font-selection-sequence/) เดียวกัน ดังนั้นการแทนที่ที่ทำล่วงหน้าจะได้รับการเคารพขณะแปลง.

**ฉันจำเป็นต้องติดตั้งฟอนต์เป้าหมายในระบบหรือสามารถแนบโฟลเดอร์ฟอนต์ได้หรือไม่?**

ไม่จำเป็นต้องติดตั้ง: ไลบรารีอนุญาตให้ [โหลดฟอนต์ภายนอก](/slides/th/cpp/custom-font/) จากโฟลเดอร์ของผู้ใช้เพื่อใช้ระหว่าง [การเรนเดอร์และการส่งออก](/slides/th/cpp/convert-powerpoint/).

**การแทนที่จะทำให้ “tofu” (สี่เหลี่ยม) แทนตัวอักษรหายได้หรือไม่?**

เฉพาะเมื่อฟอนต์เป้าหมายมี glyph ที่ต้องการจริง ๆ หากไม่มีก็ต้อง [กำหนดค่าฟอนต์สำรอง](/slides/th/cpp/fallback-font/) เพื่อครอบคลุมอักขระที่ขาดหาย.
