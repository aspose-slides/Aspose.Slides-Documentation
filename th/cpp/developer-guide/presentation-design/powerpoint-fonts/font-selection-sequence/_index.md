## **ภาพรวม**

เมื่อการนำเสนอถูกโหลด, เรนเดอร์, หรือแปลงเป็นรูปแบบอื่น, Aspose.Slides จะตรวจสอบว่าฟอนต์ที่ใช้ในการนำเสนอมีในระบบปฏิบัติการหรือไม่ หากฟอนต์ที่ต้องการหายไป, Aspose.Slides จะเลือกฟอนต์ทดแทนที่ใกล้เคียงที่สุดกับฟอนต์ที่ PowerPoint จะใช้

Aspose.Slides จะค้นหาฟอนต์ที่เลือกในระบบปฏิบัติการก่อน หากพบฟอนต์นั้นจะใช้ฟอนต์นั้น หากไม่พบจะใช้ฟอนต์ทดแทนที่เหมาะสม เมื่อมีการกำหนดกฎการแทนที่ฟอนต์ผ่าน `FontSubstRule` กฎเหล่านั้นก็จะถูกนำมาพิจารณาด้วย

คุณยังสามารถเพิ่มฟอนต์ในเวลารันของแอปพลิเคชัน, ใช้ฟอนต์ที่ฝังมาจากการนำเสนอ, หรือโหลดฟอนต์ภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF ได้อีกด้วย

## **การเลือกฟอนต์**

มีกฎบางอย่างที่ใช้กับฟอนต์ในการนำเสนอเมื่อการนำเสนอถูกโหลด, เรนเดอร์, หรือแปลงเป็นรูปแบบอื่น ตัวอย่างเช่นเมื่อคุณพยายามแปลงการนำเสนอ (สไลด์) เป็นรูปภาพ, ฟอนต์ของการนำเสนอจะถูกตรวจสอบเพื่อยืนยันว่าฟอนต์ที่เลือกมีอยู่ในระบบปฏิบัติการหรือไม่ หากฟอนต์ถูกยืนยันว่าขาดหายไป, จะมีการแทนที่ — ดูที่[**การแทนที่ฟอนต์**](https://docs.aspose.com/slides/th/cpp/font-replacement/)และ[**การทดแทนฟอนต์**](https://docs.aspose.com/slides/th/cpp/font-substitution/)

นี่คือกระบวนการที่ Aspose.Slides ปฏิบัติตามเมื่อจัดการฟอนต์:

1. Aspose.Slides ค้นหาฟอนต์ในระบบปฏิบัติการเพื่อหา ฟอนต์ที่ตรงกับฟอนต์ที่เลือกของการนำเสนอ  
2. หากพบฟอนต์ที่เลือก, Aspose.Slides จะใช้ฟอนต์นั้น หากไม่พบ, Aspose.Slides จะใช้ฟอนต์ทดแทนที่ใกล้เคียงที่สุดกับที่ PowerPoint จะใช้  
3. หากมีกฎการแทนที่ฟอนต์ที่ตั้งค่าผ่าน[FontSubstRule](https://reference.aspose.com/slides/th/cpp/aspose.slides/fontsubstrule/), กฎเหล่านั้นจะถูกนำไปใช้  

Aspose.Slides อนุญาตให้คุณเพิ่มฟอนต์ในเวลารันของแอปพลิเคชันแล้วใช้ฟอนต์เหล่านั้น ดูที่[**ฟอนต์ที่กำหนดเอง**](https://docs.aspose.com/slides/th/cpp/custom-font/)  

เมื่อฟอนต์เพิ่มเติมถูกใส่ไว้ในการนำเสนอ, ฟอนต์เหล่านั้นจะเรียกว่า[**ฟอนต์ฝัง**](https://docs.aspose.com/slides/th/cpp/embedded-font/)  

Aspose.Slides อนุญาตให้คุณเพิ่มฟอนต์ที่ใช้เฉพาะกับเอกสารผลลัพธ์เท่านั้น ตัวอย่างเช่นถ้าการนำเสนอที่คุณต้องการแปลงเป็น PDF มีฟอนต์ที่หายจากระบบและฟอนต์ฝัง, คุณสามารถเพิ่มหรือโหลดฟอนต์ที่ต้องการเป็น**ฟอนต์ภายนอก**ได้  

{{% alert title="Note" color="primary" %}} 
เราไม่ได้จัดจำหน่ายฟอนต์ใดๆ ไม่ว่าจะเป็นแบบจ่ายเงินหรือแบบฟรี API ของเราช่วยให้คุณโหลดฟอนต์ภายนอกและฝังลงในเอกสารได้, แต่คุณต้องทำเช่นนั้นด้วยฟอนต์ของคุณเองโดยรับผิดชอบเต็มที่
{{% /alert %}}

## **คำถามที่พบบ่อย**

**ฉันจะกำหนดว่าฟอนต์ใดถูกใช้จริงในการนำเสนอก่อนการแปลงได้อย่างไร?**

Aspose.Slides ให้คุณตรวจสอบฟอนต์ที่ใช้ผ่าน[ผู้จัดการฟอนต์](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/get_fontsmanager/), เพื่อให้คุณตัดสินใจว่าจะ[ฝัง](/slides/th/cpp/embedded-font/), [แทนที่](/slides/th/cpp/font-replacement/), หรือเพิ่ม[แหล่งฟอนต์ภายนอก](/slides/th/cpp/custom-font/) นี้ช่วยป้องกันการทดแทนที่ไม่ต้องการระหว่างการเรนเดอร์และการส่งออก

**ฉันสามารถเพิ่มไดเรกทอรีฟอนต์เพิ่มเติมโดยไม่ต้องติดตั้งบนระบบปฏิบัติการได้หรือไม่?**

ได้ คุณสามารถลงทะเบียน[แหล่งฟอนต์ภายนอก](/slides/th/cpp/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำสำหรับการเรนเดอร์และการส่งออก สิ่งนี้จะลบการพึ่งพาฟอนต์ของระบบโฮสต์และทำให้การจัดวางคงที่

**ฉันจะป้องกันการใช้ฟอนต์สำรองที่ไม่เหมาะสมเมื่อไม่มี glyph ได้อย่างไร?**

กำหนด[การแทนที่ฟอนต์](/slides/th/cpp/font-replacement/)และ[กฎการ fallback ฟอนต์](/slides/th/cpp/fallback-font/) อย่างชัดล่วงหน้า โดยการวิเคราะห์ฟอนต์ที่ใช้และตั้งค่าความสำคัญที่ควบคุมสำหรับฟอนต์ทดแทน, คุณจะได้ตัวอักษรที่สอดคล้องและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด
