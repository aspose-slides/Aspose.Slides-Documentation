## **ภาพรวม**

เมื่อการนำเสนอถูกโหลด, แสดงผล, หรือแปลงเป็นรูปแบบอื่น, Aspose.Slides ตรวจสอบว่าฟอนต์ที่ใช้ในการนำเสนอมีอยู่ในระบบปฏิบัติการหรือไม่ หากฟอนต์ที่จำเป็นขาดหายไป, Aspose.Slides จะเลือกฟอนต์สำรองที่ใกล้เคียงที่สุดกับฟอนต์ที่ PowerPoint จะใช้.

Aspose.Slides จะค้นหาฟอนต์ที่เลือกในระบบปฏิบัติการเป็นอันดับแรก หากพบฟอนต์นั้นจะใช้มัน หากไม่พบจะใช้ฟอนต์สำรองที่เหมาะสม เมื่อกฎการแทนฟอนต์ถูกกำหนดผ่าน `FontSubstRule` กฎเหล่านั้นก็จะถูกพิจารณาด้วย.

คุณยังสามารถเพิ่มฟอนต์ในระหว่างการทำงานของแอปพลิเคชัน, ใช้ฟอนต์ที่ฝังอยู่จากการนำเสนอ, หรือโหลดฟอนต์ภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF.

## **การเลือกฟอนต์**

กฎบางอย่างจะใช้กับฟอนต์ในการนำเสนอเมื่อการนำเสนอถูกโหลด, แสดงผล, หรือแปลงเป็นรูปแบบอื่น ตัวอย่างเช่น เมื่อคุณพยายามแปลงการนำเสนอ (สไลด์ของมัน) เป็นภาพ, ฟอนต์ของการนำเสนอจะถูกตรวจสอบเพื่อยืนยันว่าฟอนต์ที่เลือกมีอยู่ในระบบปฏิบัติการหรือไม่ หากฟอนต์ถูกยืนยันว่าขาดหายไป จะมีการแทนที่ — ดู [**Font Replacement**](https://docs.aspose.com/slides/th/cpp/font-replacement/) และ [**Font Substitution**](https://docs.aspose.com/slides/th/cpp/font-substitution/).

นี่คือขั้นตอนที่ Aspose.Slides ปฏิบัติตามเมื่อจัดการกับฟอนต์:

1. Aspose.Slides ค้นหาฟอนต์ในระบบปฏิบัติการเพื่อค้นหาฟอนต์ที่ตรงกับฟอนต์ที่เลือกในการนำเสนอ. 
2. หากพบฟอนต์ที่เลือก, Aspose.Slides จะใช้มัน มิฉะนั้น Aspose.Slides จะใช้ฟอนต์สำรองที่ใกล้เคียงที่สุดกับฟอนต์ที่ PowerPoint จะใช้.
3. หากมีกฎการแทนที่ฟอนต์ที่ตั้งค่าผ่าน [FontSubstRule](https://reference.aspose.com/slides/th/cpp/aspose.slides/fontsubstrule/), จะนำมาใช้. 

Aspose.Slides อนุญาตให้คุณเพิ่มฟอนต์ในระหว่างการทำงานของแอปพลิเคชันและจากนั้นใช้ฟอนต์เหล่านั้น ดู [**Custom fonts**](https://docs.aspose.com/slides/th/cpp/custom-font/). 

เมื่อฟอนต์เพิ่มเติมถูกวางไว้ภายในการนำเสนอ, จะเรียกว่า [**Embedded fonts**](https://docs.aspose.com/slides/th/cpp/embedded-font/).

Aspose.Slides อนุญาตให้คุณเพิ่มฟอนต์ที่ใช้กับเอกสารผลลัพธ์ *เท่านั้น* ตัวอย่างเช่น หากการนำเสนอที่คุณต้องการแปลงเป็น PDF มีฟอนต์ที่ขาดหายจากระบบและฟอนต์ที่ฝังอยู่, คุณสามารถเพิ่มหรือโหลดฟอนต์ที่จำเป็นเป็น **external fonts**. 

{{% alert title="Note" color="info" %}} 
เราไม่ได้แจกจ่ายฟอนต์ใด ๆ ไม่ว่าจะเป็นแบบจ่ายเงินหรือฟรี API ของเราตอนให้คุณโหลดฟอนต์ภายนอกและฝังลงในเอกสาร, แต่คุณต้องทำด้วยฟอนต์ตามดุลยพินิจและความรับผิดชอบของคุณเอง.
{{% /alert %}}

## **คำถามที่พบบ่อย**

### วิธีการกำหนดว่าฟอนต์ใดที่ใช้จริงในการนำเสนอก่อนการแปลง?

Aspose.Slides ให้คุณตรวจสอบฟอนต์ที่ใช้ผ่าน [font manager](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/get_fontsmanager/), เพื่อให้คุณสามารถตัดสินใจว่าจะ [embed](/slides/th/cpp/embedded-font/), [replace](/slides/th/cpp/font-replacement/), หรือเพิ่ม [external sources](/slides/th/cpp/custom-font/) หรือไม่ สิ่งนี้ช่วยป้องกันการแทนที่ฟอนต์ที่ไม่ต้องการระหว่างการแสดงผลและการส่งออก.

### ฉันสามารถเพิ่มโฟลเดอร์ฟอนต์เพิ่มเติมโดยไม่ต้องติดตั้งในระบบปฏิบัติการได้หรือไม่?

ใช่ คุณสามารถลงทะเบียน [external font sources](/slides/th/cpp/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำเพื่อการแสดงผลและการส่งออก สิ่งนี้ลบการพึ่งพาฟอนต์ของระบบโฮสต์และทำให้การจัดวางคาดเดาได้.

### ฉันจะป้องกันการเปลี่ยนฟอนต์โดยไม่ได้แจ้งเมื่อ glyph หายไปอย่างเงียบ ๆ อย่างไร?

กำหนด [font replacement](/slides/th/cpp/font-replacement/) และกฎ [fallBack rules](/slides/th/cpp/fallback-font/) ของฟอนต์อย่างชัดเจนล่วงหน้า โดยการวิเคราะห์ฟอนต์ที่ใช้และตั้งค่าลำดับความสำคัญที่ควบคุมได้สำหรับฟอนต์ทดแทน, คุณจะทำให้การจัดรูปแบบตัวอักษรสอดคล้องและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด.
