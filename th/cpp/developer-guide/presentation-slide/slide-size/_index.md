## **Introduction**

Aspose.Slides มีเครื่องมือครบวงจรสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (4:3 Aspect Ratio)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า  
- **Widescreen (16:9 Aspect Ratio)**: แนะนำสำหรับโปรเจคเตอร์และหน้าจอสมัยใหม่  

ให้ความสอดคล้องตลอดการนำเสนอของคุณโดยใช้ขนาดสไลด์และอัตราส่วนภาพเดียวกันสำหรับทุกสไลด์ สำหรับผลลัพธ์ที่ดีที่สุด ให้ตั้งค่าขนาดสไลด์ตั้งแต่เริ่มต้นกระบวนการสร้างการนำเสนอเพื่อหลีกเลี่ยงปัญหา  

{{% alert color="info" %}} 
โดยค่าเริ่มต้น การนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วน 4:3 มาตรฐาน.  
{{% /alert %}}

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

โค้ดตัวอย่างนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย C++ โดยใช้ Aspose.Slides:  

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **ระบุขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากคุณพบว่าขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจเลือกใช้ขนาดสไลด์ที่เฉพาะหรือเป็นเอกลักษณ์ ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนเลย์เอาต์หน้ากระดาษที่กำหนดเอง หรือหากคุณต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางประเภท คุณจะได้รับประโยชน์จากการตั้งค่าขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอของคุณ  

โค้ดตัวอย่างนี้แสดงวิธีใช้ Aspose.Slides สำหรับ C++ เพื่อกำหนดขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอใน C++:  

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// ขนาดกระดาษ A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **จัดการเนื้อหาสไลด์หลังจากการเปลี่ยนขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์สำหรับงานนำเสนอ เนื้อหาของสไลด์ (เช่น รูปภาพหรือวัตถุต่าง ๆ) อาจสูญเสียสัดส่วน โดยค่าเริ่มต้น วัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตาม เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถระบุการตั้งค่าที่กำหนดว่า Aspose.Slides จะจัดการกับเนื้อหาบนสไลด์อย่างไร  

ขึ้นอยู่กับสิ่งที่คุณต้องการทำหรือบรรลุ คุณสามารถใช้การตั้งค่าใด ๆ ต่อไปนี้:

- `DoNotScale`

  หากคุณ **ไม่ต้องการ** ให้วัตถุบนสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้.  

- `EnsureFit`

  หากคุณต้องการปรับสเกลเป็นขนาดสไลด์ที่เล็กลงและต้องการให้ Aspose.Slides ย่อวัตถุบนสไลด์เพื่อให้ทุกอย่างพอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้.  

- `Maximize`

  หากคุณต้องการปรับสเกลเป็นขนาดสไลด์ที่ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุบนสไลด์ให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้.  

โค้ดตัวอย่างนี้แสดงวิธีใช้การตั้งค่า `Maximize` เมื่อต้องการเปลี่ยนขนาดสไลด์ของงานนำเสนอ:  

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **คำถามที่พบบ่อย**

### ฉันสามารถตั้งค่าขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยที่ไม่ใช่นิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?

ใช่. Aspose.Slides ใช้หน่วยจุดเป็นหน่วยภายใน โดย 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้.  

### ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?

ใช่. ขนาดสไลด์ที่ใหญ่ขึ้น (ในหน่วยจุด) ร่วมกับอัตราสเกลการเรนเดอร์ที่สูงกว่าจะทำให้ใช้หน่วยความจำเพิ่มขึ้นและใช้เวลาประมวลผลนานขึ้น ควรกำหนดขนาดสไลด์ให้เหมาะสมและปรับอัตราสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ.  

### ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งขนาดแล้วค่อยรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?

คุณไม่สามารถ [รวมงานนำเสนอ](/slides/th/cpp/merge-presentation/) ได้เมื่อมีขนาดสไลด์ที่แตกต่าง — ต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการกับเนื้อหาที่มีอยู่ผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/cpp/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณสามารถรวมสไลด์โดยคงรูปแบบไว้ได้.  

### ฉันสามารถสร้างภาพย่อสำหรับรูปทรงเดี่ยวหรือพื้นที่เฉพาะของสไลด์ได้หรือไม่ และภาพย่อเหล่านั้นจะคำนึงถึงขนาดสไลด์ใหม่หรือไม่?

ใช่. Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [สไลด์ทั้งหมด](https://reference.aspose.com/slides/th/cpp/aspose.slides/slide/getimage/) รวมถึง [รูปทรงที่เลือก](https://reference.aspose.com/slides/th/cpp/aspose.slides/shape/getimage/) ผลลัพธ์ภาพจะสะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่.
