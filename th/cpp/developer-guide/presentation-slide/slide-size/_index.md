## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรเพื่อปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ.

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (4:3 Aspect Ratio)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า.
- **Widescreen (16:9 Aspect Ratio)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่.

ให้ความสอดคล้องตลอดงานนำเสนอของคุณโดยใช้ขนาดสไลด์และอัตราส่วนภาพเดียวกันสำหรับทุกสไลด์. เพื่อผลลัพธ์ที่ดีที่สุด ให้ตั้งค่าขนาดสไลด์ตั้งแต่ตอนเริ่มสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหาในภายหลัง.

{{% alert color="info" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้ค่าอัตราส่วนภาพมาตรฐาน 4:3.
{{% /alert %}}

หน้าโน้ตและหน้าเอกสารแจกจ่ายมีขนาดที่แยกจากสไลด์ปกติ. ดู[ขนาดหน้าโน้ต](/slides/th/cpp/notes-size/)เพื่อเปลี่ยนขนาดและแนวตั้ง/แนวนอนของหน้าเหล่านั้น.

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างโค้ดนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย C++ โดยใช้ Aspose.Slides:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **ระบุขนาดสไลด์ที่กำหนดเองในงานนำเสนอ**

หากขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับการทำงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่กำหนดเอง ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเองหรือหากต้องการแสดงงานนำเสนอบนอุปกรณ์หน้าจอประเภทเฉพาะ คุณอาจได้รับประโยชน์จากการตั้งค่าขนาดสไลด์ที่กำหนดเองสำหรับงานนำเสนอของคุณ.

ตัวอย่างโค้ดนี้แสดงวิธีการใช้ Aspose.Slides for C++ เพื่อระบุขนาดสไลด์ที่กำหนดเองสำหรับงานนำเสนอด้วย C++:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// ขนาดกระดาษ A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **จัดการเนื้อหาสไลด์หลังจากปรับขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์สำหรับงานนำเสนอแล้ว เนื้อหาของสไลด์ (เช่น รูปภาพหรือวัตถุ) อาจผิดรูป. โดยค่าเริ่มต้น วัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่. อย่างไรก็ตาม เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถระบุการตั้งค่าที่กำหนดว่า Aspose.Slides จะจัดการกับเนื้อหาในสไลด์อย่างไร.

ขึ้นอยู่กับเป้าหมายของคุณ คุณสามารถใช้ตั้งค่าใดก็ได้ต่อไปนี้:

- `DoNotScale`

  หากคุณต้องการให้วัตถุบนสไลด์ไม่ถูกปรับขนาด ให้ใช้การตั้งค่านี้.

- `EnsureFit`

  หากคุณต้องการปรับสไลด์ให้เล็กลงและต้องการให้ Aspose.Slides ปรับขนาดวัตถุให้พอดีบนสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้.

- `Maximize`

  หากคุณต้องการขยายสไลด์ให้ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้.

ตัวอย่างโค้ดนี้แสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

``` cpp
#include <DOM/ISlideSize.h>
#include <DOM/Presentation.h>
#include <DOM/SlideSizeScaleType.h>
#include <DOM/SlideSizeType.h>
using namespace Aspose::Slides;

auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **คำถามที่พบบ่อย**

### ฉันสามารถตั้งค่าขนาดสไลด์ที่กำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?

ใช่. Aspose.Slides ใช้หน่วยจุดภายใน โดยที่ 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วเพื่อกำหนดความกว้างและความสูงของสไลด์.

### ขนาดสไลด์ที่กำหนดเองขนาดใหญ่จะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?

ใช่. ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับสเกลการเรนเดอร์ที่สูงขึ้นจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและเวลาในการประมวลผลนานขึ้น ควรเลือกขนาดสไลด์ที่เป็นประโยชน์และปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพเอาต์พุตที่ต้องการ.

### ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งขนาดแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?

คุณไม่สามารถ[รวมงานนำเสนอ](/slides/th/cpp/merge-presentation/)ในขณะที่สไลด์มีขนาดต่างกัน — ก่อนอื่นให้ปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่ง. เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีการจัดการเนื้อหาที่มีอยู่ผ่านตัวเลือก[SlideSizeScaleType](https://reference.aspose.com/slides/th/cpp/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณสามารถรวมสไลด์ได้โดยคงรูปแบบไว้.

### ฉันสามารถสร้างภาพย่อสำหรับรูปทรงแต่ละรูปหรือส่วนเฉพาะของสไลด์ได้หรือไม่ และภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?

ใช่. Aspose.Slides สามารถสร้างภาพย่อสำหรับ[สไลด์ทั้งหมด](https://reference.aspose.com/slides/th/cpp/aspose.slides/slide/getimage/)รวมถึงสำหรับ[รูปร่างที่เลือก](https://reference.aspose.com/slides/th/cpp/aspose.slides/shape/getimage/)ได้ ผลภาพที่ได้จะสะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้การจัดกรอบและเรขาคณิตสม่ำเสมอ.
