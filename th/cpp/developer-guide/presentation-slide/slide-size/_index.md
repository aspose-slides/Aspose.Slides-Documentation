## **บทนำ**

Aspose.Slides มีเครื่องมือครบถ้วนสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจคเตอร์และจอแสดงผลสมัยใหม่

ควรรักษาความสอดคล้องตลอดงานนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนภาพเดียวจะใช้กับสไลด์ทั้งหมด เพื่อผลลัพธ์ที่ดีที่สุดให้กำหนดขนาดสไลด์ตั้งแต่เริ่มต้นกระบวนการสร้างงานนำเสนอ เพื่อหลีกเลี่ยงปัญหาในภายหลัง

{{% alert color="primary" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3
{{% /alert %}}

## **การเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างโค้ดนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย C++ โดยใช้ Aspose.Slides:

``` cpp
auto pres = System::MakeObject<Presentation>(u"pres-4x3-aspect-ratio.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
```

## **กำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่เฉพาะหรือไม่ซ้ำใคร ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางอย่าง การตั้งค่าขนาดสไลด์แบบกำหนดเองจะเป็นประโยชน์มาก

ตัวอย่างโค้ดนี้แสดงวิธีการใช้ Aspose.Slides สำหรับ C++ เพื่อกำหนดขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอใน C++:

``` cpp
auto pres = System::MakeObject<Presentation>(u"pres.pptx");
// ขนาดกระดาษ A4
pres->get_SlideSize()->SetSize(780.0f, 540.0f, SlideSizeScaleType::DoNotScale);
pres->Save(u"pres-a4-slide-size.pptx", SaveFormat::Pptx);
```

## **จัดการเนื้อหาในสไลด์หลังการปรับขนาด**

หลังจากคุณเปลี่ยนขนาดสไลด์ของงานนำเสนอ เนื้อหาในสไลด์ (เช่น รูปภาพหรือวัตถุ) อาจเกิดการบิดเบี้ยว โดยค่าเริ่มต้น วัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตาม เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถกำหนดการตั้งค่าที่กำหนดว่า Aspose.Slides จะจัดการกับเนื้อหาในสไลด์อย่างไร

ขึ้นกับสิ่งที่คุณต้องการทำหรือบรรลุผล คุณสามารถใช้การตั้งค่าเหล่านี้ได้:

- `DoNotScale`

  หากคุณ **ไม่ต้องการ** ให้วัตถุบนสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `EnsureFit`

  หากคุณต้องการลดขนาดสไลด์ลงและต้องการให้ Aspose.Slides ย่อวัตถุในสไลด์เพื่อให้พอดีกับสไลด์ทั้งหมด (เพื่อป้องกันการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้

- `Maximize`

  หากคุณต้องการเพิ่มขนาดสไลด์และต้องการให้ Aspose.Slides ขยายวัตถุในสไลด์ให้สัดส่วนตรงกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้

ตัวอย่างโค้ดนี้แสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

``` cpp
auto pres = System::MakeObject<Presentation>(u"pres.pptx");
pres->get_SlideSize()->SetSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งค่าขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลีเมตร) ได้หรือไม่?**

ได้ Aspose.Slides ใช้หน่วยจุดเป็นพื้นฐาน ซึ่ง 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลีเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้

**ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ส่งผลได้ การเพิ่มขนาดสไลด์ (หน่วยจุด) พร้อมกับสเกลการเรนเดอร์ที่สูงขึ้น จะทำให้ใช้หน่วยความจำมากขึ้นและใช้เวลาประมวลผลนานขึ้น ควรเลือกขนาดสไลด์ที่เป็นประโยชน์จริงและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพเอาต์พุตที่ต้องการ

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งครั้งแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [merge presentations](/slides/th/cpp/merge-presentation/) เมื่อสไลด์มีขนาดต่างกัน — ต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการเนื้อหาที่มีอยู่ผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/cpp/aspose.slides/slidesizescaletype/) หลังจากขนาดตรงกันแล้ว คุณสามารถรวมสไลด์ได้โดยคงรูปแบบไว้

**ฉันสามารถสร้างรูปย่อสำหรับรูปร่างเดี่ยวหรือพื้นที่เฉพาะของสไลด์ และรูปย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ได้ Aspose.Slides สามารถเรนเดอร์รูปย่อสำหรับ [entire slides](https://reference.aspose.com/slides/th/cpp/aspose.slides/slide/getimage/) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/cpp/aspose.slides/shape/getimage/) ภาพที่ได้จะแสดงขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่เสมอ
