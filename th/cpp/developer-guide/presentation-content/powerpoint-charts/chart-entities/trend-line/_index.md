## **ภาพรวม**

บทความนี้อธิบายวิธีเพิ่มเส้นแนวโน้มให้กับแผนภูมิการนำเสนอโดยใช้ Aspose.Slides โดยแสดงวิธีสร้างแผนภูมิ, เพิ่มเส้นแนวโน้มให้กับซีรีส์ของแผนภูมิ, และทำงานกับประเภทเส้นแนวโน้มหลายประเภท รวมถึงเส้นแนวโน้มแบบเอ็กซ์โพเนนเชียล, เส้นตรง, ลอการิทึม, ค่าเฉลี่ยเคลื่อนที่, พหุนาม, และพาวเวอร์

นอกจากนี้ยังอธิบายวิธีเพิ่มเส้นกำหนดเองลงในแผนภูมิโดยการแทรกรูปร่างเส้น และรวม FAQ สั้น ๆ เกี่ยวกับค่าการฉายเส้นแนวโน้มไปข้างหน้าและข้างหลัง รวมถึงว่าจะมีการเก็บรักษาเส้นแนวโน้มเมื่อนำออกเป็น PDF หรือ SVG หรือเมื่อเรนเดอร์แผนภูมิเป็นภาพหรือไม่

## **เพิ่มเส้นแนวโน้ม**
Aspose.Slides for C++ มี API ที่ง่ายสำหรับจัดการเส้นแนวโน้มของแผนภูมิหลายประเภท:

1. สร้างอินสแตนซ์ของคลาส [Presentation](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/)
2. รับอ้างอิงของสไลด์โดยใช้ดัชนีของมัน
3. เพิ่มแผนภูมิพร้อมข้อมูลเริ่มต้นและประเภทที่ต้องการ (ตัวอย่างนี้ใช้ ChartType.ClusteredColumn)
4. เพิ่มเส้นแนวโน้มแบบเอ็กซ์โพเนนเชียลให้กับซีรีส์แผนภูมิที่ 1
5. เพิ่มเส้นแนวโน้มแบบเชิงเส้นให้กับซีรีส์แผนภูมิที่ 1
6. เพิ่มเส้นแนวโน้มแบบลอการิทึมให้กับซีรีส์แผนภูมิที่ 2
7. เพิ่มเส้นแนวโน้มค่าเฉลี่ยเคลื่อนที่ให้กับซีรีส์แผนภูมิที่ 2
8. เพิ่มเส้นแนวโน้มแบบพหุนามให้กับซีรีส์แผนภูมิที่ 3
9. เพิ่มเส้นแนวโน้มแบบพาวเวอร์ให้กับซีรีส์แผนภูมิที่ 3
10. เขียนงานนำเสนอที่แก้ไขแล้วลงไฟล์ PPTX

## **เพิ่มเส้นกำหนดเอง**
Aspose.Slides for C++ มี API ที่ง่ายสำหรับเพิ่มเส้นกำหนดเองในแผนภูมิ เพื่อเพิ่มเส้นธรรมดาแบบเรียบง่ายลงในสไลด์ที่เลือกของงานนำเสนอ โปรดทำตามขั้นตอนด้านล่าง:

- สร้างอินสแตนซ์ของคลาส Presentation
- รับอ้างอิงของสไลด์โดยใช้ Index ของมัน
- สร้างแผนภูมิใหม่โดยใช้เมธอด AddChart ที่เปิดให้ใช้งานโดยอ็อบเจ็กต์ Shapes
- เพิ่ม AutoShape ประเภท Line โดยใช้เมธอด AddAutoShape ที่เปิดให้ใช้งานโดยอ็อบเจ็กต์ Shapes
- ตั้งค่า Color ของเส้นรูป
- เขียนงานนำเสนอที่แก้ไขแล้วเป็นไฟล์ PPTX

## **FAQ**

**What do 'forward' and 'backward' mean for a trendline?**

พวกมันหมายถึงความยาวของเส้นแนวโน้มที่ฉายไปข้างหน้า/ข้างหลัง: สำหรับแผนภูมิกระจาย (XY) — หน่วยของแกน; สำหรับแผนภูมิที่ไม่ใช่กระจาย — จำนวนหมวดหมู่. ค่าอนุญาตเฉพาะค่าที่ไม่เป็นลบ

**Will the trendline be preserved when exporting the presentation to PDF or SVG, or when rendering a slide to an image?**

ใช่. Aspose.Slides แปลงงานนำเสนอเป็น [PDF](/slides/th/cpp/convert-powerpoint-to-pdf/)/[SVG](/slides/th/cpp/render-a-slide-as-an-svg-image/) และเรนเดอร์แผนภูมิเป็นภาพ; เส้นแนวโน้มในฐานะส่วนหนึ่งของแผนภูมิจะถูกเก็บไว้ระหว่างการดำเนินการเหล่านี้ อีกทั้งยังมีเมธอดสำหรับ [export an image of the chart](/slides/th/cpp/create-shape-thumbnails/) ด้วย
