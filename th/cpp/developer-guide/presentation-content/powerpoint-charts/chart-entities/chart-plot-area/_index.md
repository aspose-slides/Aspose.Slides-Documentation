## **ภาพรวม**

บทความนี้แสดงวิธีการทำงานกับพื้นที่พล็อตของแผนภูมิใน Aspose.Slides โดยอธิบายวิธีการรับตำแหน่งและขนาดจริงของพื้นที่พล็อตโดยการตรวจสอบการจัดวางแผนภูมิและอ่านค่า X, Y, ความกว้างและความสูงของมัน

นอกจากนี้ยังแสดงวิธีกำหนดโหมดการจัดวางของพื้นที่พล็อตเมื่อการจัดวางถูกตั้งค่าแบบมือ ด้วยการใช้ `LayoutTargetType` เพื่อกำหนดว่าพื้นที่พล็อตจะคำนวณจากพื้นที่ภายในหรือจากพื้นที่ภายนอกรวมกับแกนและป้ายแกน

## **รับความกว้างและความสูงของพื้นที่พล็อตแผนภูมิ**
Aspose.Slides for C++ มี API ง่ายสำหรับ .

1. สร้างอินสแตนซ์ของคลาส[Presentation](https://reference.aspose.com/slides/th/cpp/class/aspose.slides.presentation)
2. เข้าถึงสไลด์แรก
3. เพิ่มแผนภูมิพร้อมข้อมูลเริ่มต้น
4. เรียกเมธอด IChart::ValidateChartLayout() ก่อนเพื่อรับค่าจริง
5. รับตำแหน่ง X จริง (ซ้าย) ขององค์ประกอบแผนภูมิสัมพันธ์กับมุมซ้ายบนของแผนภูมิ
6. รับตำแหน่งบนจริงขององค์ประกอบแผนภูมิสัมพันธ์กับมุมซ้ายบนของแผนภูมิ
7. รับความกว้างจริงขององค์ประกอบแผนภูมิ
8. รับความสูงจริงขององค์ประกอบแผนภูมิ

``` cpp
auto pres = System::MakeObject<Presentation>(u"test.Pptx");
    
auto chart = System::ExplicitCast<Chart>(pres->get_Slides()->idx_get(0)->get_Shapes()->AddChart(ChartType::ClusteredColumn, 100.0f, 100.0f, 500.0f, 350.0f));
chart->ValidateChartLayout();

double x = chart->get_PlotArea()->get_ActualX();
double y = chart->get_PlotArea()->get_ActualY();
double w = chart->get_PlotArea()->get_ActualWidth();
double h = chart->get_PlotArea()->get_ActualHeight();

// บันทึกการพรีเซนเทชันพร้อมแผนภูมิ
pres->Save(u"Chart_out.pptx", SaveFormat::Pptx);
```

## **ตั้งค่าโหมดการจัดวางของพื้นที่พล็อตแผนภูมิ**
Aspose.Slides for C++ มี API ง่ายสำหรับการตั้งค่าโหมดการจัดวางของพื้นที่พล็อตแผนภูมิ โดยคุณสมบัติ **LayoutTargetType** ถูกเพิ่มไปยังคลาส **ChartPlotArea** และ **IChartPlotArea** หากการจัดวางของพื้นที่พล็อตถูกกำหนดด้วยตนเอง คุณสมบัตินี้จะระบุว่าจะจัดวางพื้นที่พล็อตโดยภายใน (ไม่รวมแกนและป้ายแกน) หรือโดยภายนอก (รวมแกนและป้ายแกน) มีสองค่าเป็นไปได้ที่กำหนดใน enum **LayoutTargetType**

- **LayoutTargetType.Inner** - ระบุว่าขนาดของพื้นที่พล็อตจะกำหนดขนาดของพื้นที่พล็อต โดยไม่รวมเครื่องหมายติ๊กและป้ายแกน
- **LayoutTargetType.Outer** - ระบุว่าขนาดของพื้นที่พล็อตจะกำหนดขนาดของพื้นที่พล็อต รวมเครื่องหมายติ๊กและป้ายแกน

## **คำถามที่พบบ่อย**

**ActualX, ActualY, ActualWidth, และ ActualHeight คืนค่าเป็นหน่วยอะไร?**

เป็นหน่วย point; 1 นิ้ว = 72 point ซึ่งเป็นหน่วยพิกัดของ Aspose.Slides

**พื้นที่พล็อตแตกต่างจากพื้นที่แผนภูมิอย่างไรในแง่ของเนื้อหา?**

พื้นที่พล็อตคือเขตวาดข้อมูล (ชุดข้อมูล, เส้นตาราง, เส้นแนวโน้ม ฯลฯ) ส่วนพื้นที่แผนภูมิรวมถึงองค์ประกอบรอบข้าง (หัวเรื่อง, คำอธิบาย, ฯลฯ) ในแผนภูมิ 3 มิติ พื้นที่พล็อตยังรวมถึงผนัง/พื้นและแกนด้วย

**X, Y, ความกว้างและความสูงของพื้นที่พล็อตตีความอย่างไรเมื่อการจัดวางเป็นแบบมือ?**

พวกมันเป็นสัดส่วน (0–1) ของขนาดโดยรวมของแผนภูมิ; ในโหมดนี้การวางตำแหน่งอัตโนมัติจะถูกปิดและจะใช้สัดส่วนที่คุณกำหนด

**ทำไมตำแหน่งของพื้นที่พล็อตจึงเปลี่ยนหลังจากเพิ่ม/ย้ายคำอธิบาย?**

คำอธิบายอยู่ในพื้นที่แผนภูมิด้านนอกพื้นที่พล็อต แต่มีผลต่อการจัดวางและพื้นที่ที่ใช้ได้ ดังนั้นพื้นที่พล็อตอาจเลื่อนได้เมื่อการวางตำแหน่งอัตโนมัติทำงาน (นี่เป็นพฤติกรรมมาตรฐานของแผนภูมิ PowerPoint)
