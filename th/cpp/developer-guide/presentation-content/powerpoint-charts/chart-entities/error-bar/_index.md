## **ภาพรวม**

บทความนี้อธิบายวิธีทำงานกับแท่งความผิดพลาดในแผนภูมิการนำเสนอโดยใช้ Aspose.Slides แสดงวิธีเพิ่มแท่งความผิดพลาดให้กับซีรีส์ของแผนภูมิ, ตั้งค่าการกำหนดค่าแท่งความผิดพลาดแกน X และ Y, และใช้ประเภทค่าต่าง ๆ เช่น ค่าคงที่, เปอร์เซ็นต์, และค่าที่กำหนดเอง.  
บทความยังแสดงวิธีกำหนดค่าตำแหน่งแท่งความผิดพลาดแบบกำหนดเองสำหรับจุดข้อมูลแต่ละจุดในซีรีส์โดยใช้คอลเลกชันของจุดข้อมูลที่สอดคล้องกัน นอกจากนี้ยังมีบันทึกย่อสั้น ๆ เกี่ยวกับการทำงานของแท่งความผิดพลาดระหว่างการส่งออก, ความเข้ากันได้กับเครื่องหมายและป้ายข้อมูล, และตำแหน่งที่สามารถค้นหาคลาสและเอนัมที่เกี่ยวข้องในเอกสารอ้างอิง API

## **เพิ่มแท่งความผิดพลาด**
Aspose.Slides for C++ มี API ที่ง่ายสำหรับการจัดการค่าตำแหน่งแท่งความผิดพลาด ตัวอย่างโค้ดนี้ใช้เมื่อใช้ประเภทค่าที่กำหนดเอง เพื่อระบุค่าให้ใช้คุณสมบัติ **ErrorBarCustomValues** ของจุดข้อมูลเฉพาะในคอลเลกชัน **DataPoints** ของซีรีส์:

1. สร้างอินสแตนซ์ของคลาส [Presentation](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/)
1. เพิ่มแผนภูมิบับเบิลบนสไลด์ที่ต้องการ.
1. เข้าถึงซีรีส์แผนภูมืแรกและตั้งค่าฟอร์แมตของแท่งความผิดพลาด X.
1. เข้าถึงซีรีส์แผนภูมืแรกและตั้งค่าฟอร์แมตของแท่งความผิดพลาด Y.
1. ตั้งค่าค่าและฟอร์แมตของแท่ง.
1. บันทึกการนำเสนอที่แก้ไขเป็นไฟล์ PPTX.

## **เพิ่มแท่งความผิดพลาดแบบกำหนดเอง**
Aspose.Slides for C++ มี API ที่ง่ายสำหรับการจัดการค่าตำแหน่งแท่งความผิดพลาดแบบกำหนดเอง ตัวอย่างโค้ดนี้ใช้เมื่อคุณสมบัติ **IErrorBarsFormat.ValueType** มีค่าเท่ากับ **Custom** เพื่อระบุค่าให้ใช้คุณสมบัติ **ErrorBarCustomValues** ของจุดข้อมูลเฉพาะในคอลเลกชัน **DataPoints** ของซีรีส์:

1. สร้างอินสแตนซ์ของคลาส [Presentation](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/)
1. เพิ่มแผนภูมิบับเบิลบนสไลด์ที่ต้องการ.
1. เข้าถึงซีรีส์แผนภูมืแรกและตั้งค่าฟอร์แมตของแท่งความผิดพลาด X.
1. เข้าถึงซีรีส์แผนภูมืแรกและตั้งค่าฟอร์แมตของแท่งความผิดพลาด Y.
1. เข้าถึงจุดข้อมูลแต่ละจุดของซีรีส์แผนภูมิและตั้งค่าค่าแท่งความผิดพลาดสำหรับจุดข้อมูลของซีรีส์แต่ละตัว.
1. ตั้งค่าค่าและฟอร์แมตของแท่ง.
1. บันทึกการนำเสนอที่แก้ไขเป็นไฟล์ PPTX.

## **FAQ**

**อะไรเกิดขึ้นกับแท่งความผิดพลาดเมื่อส่งออกการนำเสนอเป็น PDF หรือภาพ?**

พวกมันจะถูกเรนเดอร์เป็นส่วนหนึ่งของแผนภูมิและคงอยู่ระหว่างการแปลงพร้อมกับรูปแบบแผนภูมิส่วนอื่น ๆ โดยสมมติว่ามีเวอร์ชันหรือเรนเดอร์เดอร์ที่เข้ากันได้.

**สามารถรวมแท่งความผิดพลาดกับเครื่องหมายและป้ายข้อมูลได้หรือไม่?**

ใช่ แท่งความผิดพลาดเป็นองค์ประกอบแยกออกจากกันและเข้ากันได้กับเครื่องหมายและป้ายข้อมูล; หากองค์ประกอบทับซ้อนกันอาจต้องปรับรูปแบบ.

**ฉันจะพบรายการของคุณสมบัติและเอนัมสำหรับการทำงานกับแท่งความผิดพลาดใน API ได้จากที่ไหน?**

ในเอกสารอ้างอิง API: คลาส [ErrorBarsFormat](https://reference.aspose.com/slides/th/cpp/aspose.slides.charts/errorbarsformat/) และเอนัมที่เกี่ยวข้อง [ErrorBarType](https://reference.aspose.com/slides/th/cpp/aspose.slides.charts/errorbartype/) และ [ErrorBarValueType](https://reference.aspose.com/slides/th/cpp/aspose.slides.charts/errorbarvaluetype/).
