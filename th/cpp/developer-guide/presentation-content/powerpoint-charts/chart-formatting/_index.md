## **ภาพรวม**

บทความนี้อธิบายวิธีจัดรูปแบบแผนภูมิในงานนำเสนอ PowerPoint โดยใช้ Aspose.Slides แสดงวิธีปรับแต่งองค์ประกอบสำคัญของแผนภูมิเช่น แกน, เส้นกริด, ชื่อเรื่อง, คำอธิบาย, พื้นที่พล็อต, และการเติมสีผนังเพื่อปรับปรุงรูปลักษณ์และความอ่านง่ายของข้อมูลแผนภูมิ

นอกจากนี้ยังสาธิตวิธีตั้งค่าคุณสมบัติแบบอักษรสำหรับข้อความในแผนภูมิ, การใช้รูปแบบตัวเลขที่กำหนดล่วงหน้าและกำหนดเองกับข้อมูลแผนภูมิ, และการเปิดใช้งานมุมโค้งสำหรับพื้นที่แผนภูมิ ตัวอย่างเหล่านี้แสดงวิธีควบคุมทั้งสไตล์การแสดงผลและการนำเสนอข้อมูลของแผนภูมิในงานนำเสนอ

## **จัดรูปแบบ Entity ของแผนภูมิ**
Aspose.Slides for C++ ให้ผู้พัฒนาสามารถเพิ่มแผนภูมิกำหนดเองลงในสไลด์ตั้งแต่แรกได้ บทความนี้อธิบายวิธีจัดรูปแบบ Entity ของแผนภูมิต่าง ๆ รวมถึงแกนประเภทและค่า

Aspose.Slides for C++ มี API ง่ายสำหรับจัดการ Entity ของแผนภูมิต่าง ๆ และจัดรูปแบบโดยใช้ค่าที่กำหนดเอง:

1. สร้างอินสแตนซ์ของคลาส **Presentation**.
1. รับอ้างอิงสไลด์โดยใช้ดัชนีของมัน.
1. เพิ่มแผนภูมิเพิ่มด้วยข้อมูลค่าเริ่มต้นพร้อมประเภทที่ต้องการ (ในตัวอย่างนี้จะใช้ ChartType.LineWithMarkers).
1. เข้าถึง **Value Axis** ของแผนภูมิและตั้งค่าคุณสมบัติดังต่อไปนี้:
   1. ตั้งค่า **Line format** สำหรับเส้นกริดหลักของ Value Axis
   1. ตั้งค่า **Line format** สำหรับเส้นกริดรองของ Value Axis
   1. ตั้งค่า **Number Format** สำหรับ Value Axis
   1. ตั้งค่า **Min, Max, Major and Minor units** สำหรับ Value Axis
   1. ตั้งค่า **Text Properties** สำหรับข้อมูลของ Value Axis
   1. ตั้งค่า **Title** สำหรับ Value Axis
   1. ตั้งค่า **Line Format** สำหรับ Value Axis
1. เข้าถึง **Category Axis** ของแผนภูมิและตั้งค่าคุณสมบัติดังต่อไปนี้:
   1. ตั้งค่า **Line format** สำหรับเส้นกริดหลักของ Category Axis
   1. ตั้งค่า **Line format** สำหรับเส้นกริดรองของ Category Axis
   1. ตั้งค่า **Text Properties** สำหรับข้อมูลของ Category Axis
   1. ตั้งค่า **Title** สำหรับ Category Axis
   1. ตั้งค่า **Label Positioning** สำหรับ Category Axis
   1. ตั้งค่า **Rotation Angle** สำหรับป้ายกำกับของ Category Axis
1. เข้าถึง **Legend** ของแผนภูมิและตั้งค่า **Text Properties** ให้กับมัน
1. ตั้งค่าให้แสดง Legend ของแผนภูมิโดยไม่ทับซ้อนกับแผนภูมิ
1. เข้าถึง **Secondary Value Axis** ของแผนภูมิและตั้งค่าคุณสมบัติดังต่อไปนี้:
   1. เปิดใช้งาน **Secondary Value Axis**
   1. ตั้งค่า **Line Format** สำหรับ Secondary Value Axis
   1. ตั้งค่า **Number Format** สำหรับ Secondary Value Axis
   1. ตั้งค่า **Min, Max, Major and Minor units** สำหรับ Secondary Value Axis
1. ตอนนี้แสดงซีรีส์แรกของแผนภูมิบน Secondary Value Axis
1. ตั้งค่าสีเติมของผนังด้านหลังของแผนภูมิ
1. ตั้งค่าสีเติมของพื้นที่พล็อตของแผนภูมิ
1. เขียนงานนำเสนอที่แก้ไขแล้วลงในไฟล์ PPTX

## **ตั้งค่ารูปแบบตัวเลข**
Aspose.Slides for C++ มี API ง่ายสำหรับจัดการรูปแบบข้อมูลของแผนภูมิ:

1. สร้างอินสแตนซ์ของคลาส [Presentation](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/) .
1. รับอ้างอิงสไลด์โดยใช้ดัชนีของมัน.
1. เพิ่มแผนภูมิเพิ่มด้วยข้อมูลค่าเริ่มต้นพร้อมประเภทที่ต้องการ (ตัวอย่างนี้ใช้ **ChartType.ClusteredColumn**).
1. ตั้งค่ารูปแบบตัวเลขจากค่าที่กำหนดล่วงหน้าที่เป็นไปได้.
1. ไปตามเซลล์ข้อมูลของแผนภูมิในแต่ละซีรีส์และตั้งค่ารูปแบบตัวเลขของข้อมูลแผนภูมิ.
1. บันทึกงานนำเสนอ.
1. ตั้งค่ารูปแบบตัวเลขที่กำหนดเอง.
1. ไปตามเซลล์ข้อมูลของแผนภูมิในทุกซีรีส์และตั้งค่ารูปแบบตัวเลขที่แตกต่างกัน.
1. บันทึกงานนำเสนอ.

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งค่าการเติมกึ่งโปร่งแสงสำหรับคอลัมน์/พื้นที่ได้โดยคงขอบให้เป็นสีทึบหรือไม่?**

ได้ การกำหนดความโปร่งแสงของการเติมและเส้นขอบทำแยกจากกัน ซึ่งช่วยปรับปรุงการอ่านของกริดและข้อมูลในภาพที่หนาแน่น

**ฉันจะจัดการกับป้ายข้อมูลที่ทับซ้อนได้อย่างไร?**

ลดขนาดแบบอักษร, ปิดใช้งานส่วนประกอบของป้ายที่ไม่จำเป็น (เช่น หมวด), ตั้งค่าการชิด/ตำแหน่งของป้าย, แสดงป้ายเฉพาะจุดที่เลือกหากจำเป็น, หรือเปลี่ยนรูปแบบเป็น “value + legend”

**ฉันสามารถใช้การเติมแบบไล่สีหรือรูปแบบให้กับซีรีส์ได้หรือไม่?**

ได้ ทั้งการเติมแบบสีทึบและแบบไล่สี/รูปแบบมักจะพร้อมใช้งาน ในการใช้งานจริงควรใช้ไล่สีอย่างระมัดระวังและหลีกเลี่ยงการผสมที่ทำให้ความคมชัดของกริดและข้อความลดลง
