## **ภาพรวม**

Aspose.Slides for C++ สามารถโหลดงานนำเสนอ PowerPoint และ OpenDocument และบันทึกหรือเรนเดอร์เป็นรูปแบบอื่น ๆ อีกหลายรูปแบบโดยไม่ต้องใช้ Microsoft PowerPoint, OpenOffice หรือ LibreOffice คุณสามารถแปลงไฟล์ PPT เก่าเป็น PPTX สมัยใหม่, ส่งออกงานนำเสนอเป็นเอกสารแบบจัดรูปแบบคงที่เช่น PDF และ XPS, เผยแพร่สไลด์เป็น HTML, หรือเรนเดอร์สไลด์เป็นไฟล์รูปภาพสำหรับการพรีวิว, ภาพย่อ, และการเก็บถาวร

การแปลงเอกสารส่วนใหญ่ใช้กระบวนการทำงานทั่วไปเดียวกัน: โหลดไฟล์ต้นฉบับ, เลือกรูปแบบผลลัพธ์ที่ต้องการ, และใช้ตัวเลือกที่เฉพาะเจาะจงของรูปแบบเมื่อจำเป็น สำหรับรูปแบบภาพแต่ละสไลด์จะถูกเรนเดอร์แยกจากกันและจากนั้นบันทึกเป็นภาพแรสเตอร์หรือเวกเตอร์ บทความเฉพาะที่ลิงก์ด้านล่างให้รายละเอียดการดำเนินการสำหรับแต่ละกรณี

## **การแปลง PowerPoint และ OpenDocument**

Aspose.Slides for C++ รองรับการแปลงจากรูปแบบการนำเสนอที่ใช้บ่อย เช่น PPT, PPTX, PPS, PPSX, POT, POTX, และ ODP API การแปลงเดียวกันถูกใช้สำหรับไฟล์ PowerPoint และ OpenDocument, ดังนั้นกระบวนการที่บันทึกไฟล์ PPTX เป็น PDF มักจะสามารถนำไปใช้กับไฟล์ ODP ได้โดยเปลี่ยนเพียงไฟล์อินพุต

เมื่อต้องแปลงไฟล์ ODP, จำไว้ว่าแอปพลิเคชัน PowerPoint และ OpenDocument ไม่รองรับทุกการจัดวางและคุณลักษณะการจัดรูปแบบในแบบเดียวกัน หากไฟล์ ODP ถูกสร้างใน LibreOffice หรือ OpenOffice Impress, ตรวจสอบผลลัพธ์และใช้ตัวเลือกที่อธิบายไว้ใน [แปลงงานนำเสนอ OpenDocument](/slides/th/cpp/convert-openoffice-odp/) เมื่อคุณต้องการคำแนะนำที่เฉพาะเจาะจงของรูปแบบ

## **การแปลง PPT เป็น PPTX**

PPT เป็นรูปแบบ PowerPoint แบบไบนารีเก่า, ส่วน PPTX เป็นรูปแบบ Office Open XML สมัยใหม่ Aspose.Slides for C++ รองรับการแปลง PPT เป็น PPTX ด้วยความแม่นยำสูงพร้อมคงโครงสร้างการนำเสนอที่ซับซ้อนเช่น มาสเตอร์, เลย์เอาต์, สไลด์, ชาร์ต, รูปร่างที่จัดกลุ่ม, พื้นที่จอง, กรอบข้อความ, พื้นผิว, และการเติมรูปภาพ

สำหรับรายละเอียด, ดูที่ [แปลง PPT เป็น PPTX](/slides/th/cpp/convert-ppt-to-pptx/).

## **การส่งออกรูปแบบคงที่**

PDF, XPS, และ TIFF มีประโยชน์เมื่อผลลัพธ์ต้องดูเหมือนกันบนอุปกรณ์ทุกเครื่องและไม่ควรแก้ไขเป็นงานนำเสนอ บทความเฉพาะของ PDF, XPS, และ TIFF อธิบายวิธีควบคุมการปฏิบัติตาม, สไลด์ที่ซ่อน, โน้ต, คุณภาพภาพ, การบีบอัด, รูปแบบพิกเซล, และขนาดผลลัพธ์

## **การส่งออก HTML และรูปภาพ**

การส่งออก HTML และ HTML5 มีประโยชน์สำหรับการดูผ่านเบราว์เซอร์, การเผยแพร่บนเว็บ, และการแชร์แบบเบา ๆ การส่งออกรูปภาพมีประโยชน์เมื่อแต่ละสไลด์ต้องกลายเป็นพรีวิว, ภาพย่อ, หรือทรัพยากรแรสเตอร์ ใช้บทความ PNG, JPG, และ SVG สำหรับคำแนะนำการเรนเดอร์ที่เฉพาะเจาะจงของรูปแบบ

## **คำถามที่พบบ่อย**

**ฉันต้องการ Microsoft PowerPoint เพื่อแปลงงานนำเสนอหรือไม่?**

ไม่. Aspose.Slides for C++ เป็นไลบรารีแบบสแตนด์อโลนและไม่ต้องการ Microsoft PowerPoint หรือการทำงานอัตโนมัติของ Office.

**ฉันสามารถแปลงงานนำเสนอหลายไฟล์เป็นกลุ่มได้หรือไม่?**

ใช่. โหลดงานนำเสนอแต่ละไฟล์, บันทึกเป็นรูปแบบที่ต้องการ, และทำลายอ็อบเจกต์งานนำเสนอหลังการประมวลผล สำหรับการประมวลผลแบบขนาน, ใช้อินสแตนซ์งานนำเสนอแยกกันและปฏิบัติตามคำแนะนำของ [การทำงานหลายเธรด](/slides/th/cpp/multithreading/).

**ฉันสามารถส่งออกเฉพาะสไลด์ที่เลือกได้หรือไม่?**

ใช่. วิธีการส่งออกหลายวิธีอนุญาตให้คุณส่งค่าอินเด็กซ์ของสไลด์หรือเรนเดอร์สไลด์แต่ละอัน, ขึ้นกับรูปแบบผลลัพธ์ ดูบทความเฉพาะสำหรับรูปแบบเป้าหมาย.

**ฉันสามารถรวมสไลด์ที่ซ่อนได้เมื่อส่งออกเป็น PDF หรือ XPS หรือไม่?**

ใช่. ใช้การตั้งค่าการส่งออกสไลด์ที่ซ่อนตามที่อธิบายไว้ในบทความ [PDF](/slides/th/cpp/convert-powerpoint-to-pdf/) และ [XPS](/slides/th/cpp/convert-powerpoint-to-xps/).

**ฉันสามารถสร้างผลลัพธ์ PDF/A ได้หรือไม่?**

ใช่. มีการตั้งค่าการปฏิบัติตามของ PDF สำหรับการส่งออก PDF ดูที่ [แปลง PowerPoint เป็น PDF](/slides/th/cpp/convert-powerpoint-to-pdf/) สำหรับรายละเอียด.

**ฟอนต์จะถูกจัดการอย่างไรระหว่างการแปลง?**

Aspose.Slides สามารถใช้ฟอนต์ฝัง, ฟอนต์สำรอง, และการตั้งค่าการแทนที่ฟอนต์ ดูที่ [ฟอนต์ฝัง](/slides/th/cpp/embedded-font/), [ฟอนต์สำรอง](/slides/th/cpp/fallback-font/), และ [การแทนที่ฟอนต์](/slides/th/cpp/font-substitution/).
