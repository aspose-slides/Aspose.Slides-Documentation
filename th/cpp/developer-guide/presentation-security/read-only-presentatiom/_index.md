## **บทนำ**

ใน PowerPoint 2019, Microsoft ได้นำการตั้งค่า **Always Open Read-Only** มาเป็นหนึ่งในตัวเลือกที่ผู้ใช้สามารถใช้เพื่อปกป้องการนำเสนอของตน คุณอาจต้องการใช้การตั้งค่า Read-Only นี้เพื่อปกป้องการนำเสนอเมื่อ

- คุณต้องการป้องกันการแก้ไขโดยไม่ได้ตั้งใจและรักษาเนื้อหาในการนำเสนอของคุณให้ปลอดภัย
- คุณต้องการแจ้งให้ผู้ใช้ทราบว่าการนำเสนอที่คุณให้เป็นเวอร์ชันสุดท้าย

หลังจากที่คุณเลือกตัวเลือก **Always Open Read-Only** สำหรับการนำเสนอ เมื่อผู้ใช้เปิดการนำเสนอ พวกเขาจะเห็นคำแนะนำ **Read-Only** และอาจเห็นข้อความในรูปแบบนี้: *เพื่อป้องกันการเปลี่ยนแปลงโดยไม่ได้ตั้งใจ ผู้เขียนได้ตั้งไฟล์นี้ให้เปิดในโหมดอ่านอย่างเดียว*  

คำแนะนำ Read-Only เป็นการขัดขวางที่เรียบง่ายแต่มีประสิทธิภาพซึ่งทำให้ผู้ใช้ไม่ต้องการแก้ไข เนื่องจากผู้ใช้ต้องทำขั้นตอนเพื่อเอามันออกก่อนที่จะได้รับอนุญาตให้แก้ไขการนำเสนอ หากคุณไม่ต้องการให้ผู้ใช้ทำการเปลี่ยนแปลงและต้องการบอกพวกเขาอย่างสุภาพ คำแนะนำ Read-Only อาจเป็นตัวเลือกที่ดีสำหรับคุณ.  

> หากการนำเสนอที่มีการป้องกัน **Read-Only** ถูกเปิดในแอปพลิเคชัน Microsoft PowerPoint รุ่นเก่าซึ่งไม่รองรับฟังก์ชันที่เพิ่งแนะนำใหม่ คำแนะนำ **Read-Only** จะถูกละเว้น (การนำเสนอจะเปิดตามปกติ).

## **ใช้โหมด Read-Only**

Aspose.Slides for C++ ช่วยให้คุณตั้งค่าการนำเสนอเป็น **Read-Only** ซึ่งหมายความว่าผู้ใช้ (หลังจากเปิดการนำเสนอ) จะเห็นคำแนะนำ **Read-Only** ตัวอย่างโค้ดนี้แสดงวิธีตั้งค่าการนำเสนอเป็น **Read-Only** ใน C++ ด้วย Aspose.Slides:

``` cpp
#include <DOM/IProtectionManager.h>
#include <DOM/Presentation.h>
#include <Export/SaveFormat.h>
using namespace Aspose::Slides;
using namespace Aspose::Slides::Export;

auto pres = System::MakeObject<Presentation>();
pres->get_ProtectionManager()->set_ReadOnlyRecommended(true);
pres->Save(u"ReadOnlyPresentation.pptx", SaveFormat::Pptx);
```

{{% alert color="info" %}} 

**หมายเหตุ**: คำแนะนำ **Read-Only** มีจุดประสงค์เพื่อหลีกเลี่ยงการแก้ไขหรือป้องกันไม่ให้ผู้ใช้ทำการเปลี่ยนแปลงโดยไม่ได้ตั้งใจในการนำเสนอ PowerPoint หากบุคคลที่มีความตั้งใจ—ซึ่งรู้ว่าตนทำอะไร—ตัดสินใจแก้ไขการนำเสนอของคุณ พวกเขาสามารถลบการตั้งค่า Read-Only ได้อย่างง่ายดาย หากคุณต้องการป้องกันการแก้ไขโดยไม่ได้รับอนุญาตอย่างจริงจัง คุณควรใช้ [การป้องกันที่เข้มงวดขึ้นซึ่งรวมถึงการเข้ารหัสและรหัสผ่าน](https://docs.aspose.com/slides/th/cpp/password-protected-presentation/).

## **FAQ**

### ‘Read-Only recommended’ แตกต่างจากการป้องกันด้วยรหัสผ่านเต็มอย่างไร?

‘Read-Only recommended’ เพียงแสดงข้อเสนอแนะให้เปิดไฟล์ในโหมดอ่านอย่างเดียวและสามารถข้ามได้ง่าย [การป้องกันด้วยรหัสผ่าน](/slides/th/cpp/password-protected-presentation/) จริง ๆ แล้วจำกัดการเปิดหรือแก้ไขและเหมาะสมเมื่อคุณต้องการการควบคุมความปลอดภัยจริง

### ‘Read-Only recommended’ สามารถผสานกับลายน้ำเพื่อยับยั้งการแก้ไขเพิ่มเติมได้หรือไม่?

ได้ การแนะนำนี้สามารถจับคู่กับ [ลายน้ำ](/slides/th/cpp/watermark/) เป็นการขัดขวางด้วยภาพ; พวกมันเป็นกลไกที่แยกจากกันและทำงานร่วมกันได้ดี

### แมโครหรือเครื่องมือภายนอกยังคงแก้ไขไฟล์ได้เมื่อเปิดใช้งานคำแนะนำนี้หรือไม่?

ได้ การแนะนำนี้ไม่ได้บล็อคการเปลี่ยนแปลงโดยโปรแกรม เพื่อตัดการแก้ไขอัตโนมัติ ใช้ [รหัสผ่านและการเข้ารหัส](/slides/th/cpp/password-protected-presentation/)

### ‘Read-Only recommended’ มีความสัมพันธ์อย่างไรกับค่าสถานะ ‘is encrypted’ และ ‘is write protected’?

พวกเขาเป็นสัญญาณที่แตกต่างกัน ‘Read-Only recommended’ เป็นการแจ้งเตือนแบบอ่อนและไม่บังคับ; [get_IsWriteProtected](https://reference.aspose.com/slides/th/cpp/aspose.slides/protectionmanager/get_iswriteprotected/) และ [get_IsEncrypted](https://reference.aspose.com/slides/th/cpp/aspose.slides/protectionmanager/get_isencrypted/) บ่งบอกข้อจำกัดการเขียนหรือการอ่านจริงที่ขึ้นอยู่กับรหัสผ่านหรือการเข้ารหัส.
