**ยินดีต้อนรับสู่ Aspose.Slides for C++**

Aspose.Slides for C++ เป็น API การจัดการ Microsoft PowerPoint® ที่ช่วยให้แอปพลิเคชัน C++ สามารถอ่านและเขียนเอกสาร PowerPoint® ได้โดยไม่ต้องใช้ Microsoft PowerPoint®. Aspose.Slides for C++ เป็นส่วนประกอบแรกและส่วนเดียวที่ให้ความสามารถในการจัดการเอกสาร PowerPoint®. Aspose.Slides for C++ มีคุณลักษณะสำคัญมากมาย เช่น การจัดการข้อความ, รูปร่าง, ตารางและแอนิเมชัน, การเพิ่มเสียงและวิดีโอในสไลด์, การแสดงตัวอย่างสไลด์, การส่งออกสไลด์เป็นรูปแบบ SVG, PDF และอื่น ๆ.
