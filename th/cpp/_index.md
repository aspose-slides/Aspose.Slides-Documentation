**ยินดีต้อนรับสู่ Aspose.Slides for C++**

Aspose.Slides for C++ เป็น API การจัดการ Microsoft PowerPoint® ที่ทำให้แอปพลิเคชัน C++ สามารถอ่านและเขียนเอกสาร PowerPoint® ได้โดยไม่ต้องใช้ Microsoft PowerPoint®. Aspose.Slides for C++ คือส่วนประกอบแรกและ唯一ที่ให้ความสามารถในการจัดการเอกสาร PowerPoint®. Aspose.Slides for C++ มีคุณลักษณะสำคัญหลายอย่าง เช่น การจัดการข้อความ, รูปร่าง, ตารางและแอนิเมชัน, การเพิ่มเสียงและวิดีโอลงในสไลด์, การแสดงตัวอย่างสไลด์, การส่งออกสไลด์เป็น SVG, PDF และอื่น ๆ
