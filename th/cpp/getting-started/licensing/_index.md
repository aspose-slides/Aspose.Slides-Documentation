## **ภาพรวม**

Aspose.Slides สามารถใช้งานได้ในโหมดประเมินหรือด้วยใบอนุญาตที่ถูกต้อง เวอร์ชันประเมินให้ฟังก์ชันการทำงานเดียวกับเวอร์ชันที่ได้รับใบอนุญาต แต่จะเพิ่มลายน้ำการประเมินเมื่อพรีเซนเทชันถูกเปิดหรือบันทึกและจำกัดการสกัดข้อความให้อยู่ที่หนึ่งสไลด์เท่านั้น

บทความนี้อธิบายวิธีการทำงานของการให้ใบอนุญาตใน Aspose.Slides และวิธีการใช้ใบอนุญาตก่อนใช้งานไลบรารี ใบอนุญาตสามารถโหลดจากไฟล์, สตรีม หรือทรัพยากรที่ฝังอยู่โดยใช้คลาส `License` บทความยังแสดงวิธีการตรวจสอบว่าใบอนุญาตถูกตั้งค่าอย่างถูกต้องหรือไม่

## **การให้ใบอนุญาตใน Aspose.Slides**

* เวอร์ชันประเมินจะกลายเป็นแบบมีใบอนุญาตหลังจากคุณซื้อใบอนุญาตและนำไปใช้โดยเพิ่มไม่กี่บรรทัดโค้ด
* ใบอนุญาตเป็นไฟล์ XML แบบข้อความธรรมดาที่มีรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนนักพัฒนาที่ได้รับอนุญาต วันหมดอายุการสมัครสมาชิก ฯลฯ
* ไฟล์ใบอนุญาตถูกเซ็นดิจิทัล ดังนั้นจึงต้องห้ามแก้ไข แม้แต่การเปลี่ยนแปลงโดยบังเอิญ—เช่นการเพิ่มบรรทัดใหม่—ก็จะทำให้ไฟล์ไม่ถูกต้อง
* Aspose.Slides for C++ ปกติจะค้นหาไฟล์ใบอนุญาตในตำแหน่งต่อไปนี้:
  * เส้นทางที่ระบุอย่างชัดเจนในโค้ดของคุณ
  * โฟลเดอร์ที่บรรจุ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides)
  * โฟลเดอร์ที่บรรจุแอสเซมบลีที่เรียกใช้ DLL ของคอมโพเนนต์
* เพื่อลดข้อจำกัดของเวอร์ชันประเมิน คุณต้องตั้งค่าใบอนุญาตก่อนใช้ Aspose.Slides ใบอนุญาตต้องตั้งค่าเพียงครั้งเดียวต่อแต่ละแอปพลิเคชันหรือกระบวนการ

## **การใช้ใบอนุญาต**

ใบอนุญาตสามารถโหลดจาก **ไฟล์**, **สตรีม**, หรือ **ทรัพยากรที่ฝังอยู่** ได้

{{% alert color="info" %}}

Aspose.Slides มีคลาส [License](https://reference.aspose.com/slides/th/cpp/class/aspose.slides.license/) สำหรับการดำเนินการเกี่ยวกับใบอนุญาต

{{% /alert %}} 

{{% alert color="warning" %}}

ใบอนุญาตใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับเวอร์ชัน 21.4 หรือใหม่กว่า เวอร์ชันก่อนหน้านี้ใช้ระบบใบอนุญาตที่แตกต่างและจะไม่รับรู้ใบอนุญาตเหล่านี้

{{% /alert %}}

### **ไฟล์**

วิธีที่ง่ายที่สุดในการตั้งค่าใบอนุญาตคือวางไฟล์ใบอนุญาตไว้ในโฟลเดอร์เดียวกับ DLL ของคอมโพเนนต์ (รวมอยู่ใน Aspose.Slides) และระบุเฉพาะชื่อไฟล์โดยไม่มีเส้นทาง

โค้ด C++ ต่อไปนี้แสดงวิธีการตั้งค่าไฟล์ใบอนุญาต:

```c++
#include <Util/License.h>
#include <system/smart_ptr.h>
#include <system/string.h>

using namespace Aspose::Slides;
using namespace System;

int main()
{
    auto license = MakeObject<License>();
    license->SetLicense(u"Aspose.Slides.lic");

    return 0;
}
```

{{% alert color="warning" %}} 

หากคุณวางไฟล์ใบอนุญาตในไดเรกทอรีอื่น แล้วเมื่อเรียกเมธอด [License::SetLicense](https://reference.aspose.com/slides/th/cpp/aspose.slides/license/setlicense/) จะต้องให้ชื่อไฟล์ที่ส่วนท้ายของเส้นทางที่ระบุอย่างชัดเจนตรงกับชื่อไฟล์ใบอนุญาตของคุณอย่างแม่นยำ

ตัวอย่างเช่น หากคุณเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น *Aspose.Slides.lic.xml* คุณต้องส่งเส้นทางเต็มที่ลงท้ายด้วย *Aspose.Slides.lic.xml* ไปยังเมธอด [License::SetLicense](https://reference.aspose.com/slides/th/cpp/aspose.slides/license/setlicense/) ในโค้ดของคุณ

{{% /alert %}}

### **สตรีม**

คุณสามารถโหลดใบอนุญาตจากสตรีมได้ โค้ด C++ ต่อไปนี้แสดงวิธีการใช้ใบอนุญาตจากสตรีม:

```c++
#include <Util/License.h>
#include <system/io/file.h>
#include <system/smart_ptr.h>
using namespace Aspose::Slides;
using namespace System;
using namespace System::IO;

auto license = MakeObject<License>();

auto stream = File::OpenRead(u"Aspose.Slides.lic");

license->SetLicense(stream);
```

## **ตรวจสอบใบอนุญาต**

เพื่อเช็คว่าใบอนุญาตตั้งค่าอย่างถูกต้องหรือไม่ คุณสามารถตรวจสอบได้ โค้ด C++ ต่อไปนี้แสดงวิธีการตรวจสอบใบอนุญาต:

```c++
#include <Util/License.h>
#include <system/console.h>
using namespace Aspose::Slides;
using namespace System;

auto license = MakeObject<License>();

license->SetLicense(u"Aspose.Slides.lic");

if (license->IsLicensed())
{
    Console::WriteLine(u"License is good!");
    Console::ReadKey();
}
```

## **ความปลอดภัยของเธรด**

{{% alert title="Note" color="warning" %}} 

เมธอด [License::SetLicense](https://reference.aspose.com/slides/th/cpp/aspose.slides/license/setlicense/) **ไม่ปลอดภัยต่อเธรด** หากคุณจำเป็นต้องเรียกเมธอดนี้จากหลายเธรดพร้อมกัน แนะนำให้ใช้กลไกการซิงโครไนซ์ (เช่น lock) เพื่อป้องกันปัญหาที่อาจเกิดขึ้น

{{% /alert %}}

## **คำถามที่พบบ่อย**

### ฉันสามารถใช้ใบอนุญาตในสภาพแวดล้อมที่ออฟไลน์โดยสมบูรณ์ (ไม่มีการเชื่อมต่ออินเทอร์เน็ต) ได้หรือไม่?

ได้ การตรวจสอบใบอนุญาตทำในเครื่องโดยใช้ไฟล์ใบอนุญาต ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่มี ใบอนุญาตเป็นแบบถาวร: คุณสามารถใช้เวอร์ชันที่ปล่อยก่อนวันที่สิ้นสุดการสมัครสมาชิกได้ต่อไป แต่จะไม่สามารถใช้เวอร์ชันใหม่ที่ออกหลังจากนั้นได้หากไม่ได้ต่ออายุ
