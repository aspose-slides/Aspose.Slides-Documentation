คอมโพเนนต์ Aspose C++ ทั้งหมดต้องการชุดสิทธิ์ Full Trust. สาเหตุคือ คอมโพเนนต์ Aspose C++ จำเป็นต้องเข้าถึงการตั้งค่าบัญชีรีจิสทรี, ไฟล์ระบบที่ไม่ใช่ไดเร็กทอรีเสมือนสำหรับการดำเนินการบางอย่าง เช่น การวิเคราะห์แบบอักษร เป็นต้น. นอกจากนี้ คอมโพเนนต์ Aspose C++ ยังอิงตามคลาสระบบ C++ หลักที่หลายกรณีก็ต้องการชุดสิทธิ์ Full Trust อีกด้วย.
