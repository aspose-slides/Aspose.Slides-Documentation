## **ภาพรวม**

Aspose.Slides รองรับไฟล์งานนำเสนอจาก Microsoft PowerPoint 97 ถึง Office 365 รวมถึง Microsoft PowerPoint สำหรับ Mac บทความนี้แสดงรายการเวอร์ชัน PowerPoint ที่ไลบรารีสนับสนุนและให้ตารางรูปแบบไฟล์ที่สามารถโหลด บันทึก หรือทั้งสองอย่างได้

บทความนี้ยังตอบคำถามทั่วไปเกี่ยวกับการปฏิบัติตามมาตรฐาน PDF, การฝังฟอนต์, ไฟล์ที่ป้องกันด้วยรหัสผ่าน, ฟอนต์แบบกำหนดเอง, กลไกการสำรองฟอนต์, และตัวเลือกการส่งออก XPS

## **เวอร์ชัน Microsoft PowerPoint ที่รองรับ**
- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint สำหรับ MAC
- Office 365

## **คำถามที่พบบ่อย**

**ฉันสามารถบันทึกงานนำเสนอเป็น PDF ที่ตรงตามมาตรฐานการจัดเก็บและการเข้าถึง (PDF/A และ PDF/UA) ได้หรือไม่?**

ใช่ Aspose.Slides รองรับการส่งออกเป็น PDF พร้อมระดับการปฏิบัติตามเช่น PDF/A-2a, PDF/A-2b, PDF/A-2u, PDF/A-3a, PDF/A-3b รวมถึง PDF/UA ผ่านการตั้งค่า [compliance](https://reference.aspose.com/slides/th/cpp/aspose.slides.export/pdfoptions/set_compliance/) ใน [PDF export options](https://reference.aspose.com/slides/th/cpp/aspose.slides.export/pdfoptions/)  

**ไลบรารีนี้รองรับการฝังฟอนต์เมื่อส่งออกเป็น PDF พร้อมการควบคุมละเอียดว่าฟอนต์อะไรจะถูกฝังบ้างหรือไม่?**

ใช่ คุณสามารถควบคุมได้ว่าฟอนต์จะถูกฝังอย่างเต็มรูปแบบหรือเป็นส่วนย่อย (เฉพาะตัวอักษรที่ใช้) กำหนดวิธีจัดการกับฟอนต์ระบบที่ทั่วไป และกำหนดพฤติกรรมสำหรับข้อความ ASCII ผ่าน [PDF export options](https://reference.aspose.com/slides/th/cpp/aspose.slides.export/pdfoptions/)  

**ฉันสามารถตรวจจับว่าไฟล์ถูกป้องกันด้วยรหัสผ่านหรือไม่ก่อนที่จะโหลดจริงหรือไม่?**

ใช่ โดยใช้ [factory-based inspection API](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentationfactory/) คุณสามารถสอบถามไฟล์งานนำเสนอเพื่อระบุว่ามีการป้องกันด้วยรหัสผ่านหรือไม่โดยไม่ต้องเปิดไฟล์เต็มรูปแบบ  

**มีกลไกการสำรองฟอนต์และการสนับสนุนฟอนต์แบบกำหนดเองหรือไม่?**

ใช่ ไลบรารีสนับสนุนการ [loading](/slides/th/cpp/custom-font/) และการ [embedding](/slides/th/cpp/embedded-font/) ฟอนต์แบบกำหนดเองและให้กฎ [fallback](/slides/th/cpp/fallback-font/) เพื่อป้องกันการขาดตัวอักษรขณะเรนเดอร์และแปลง  

**ฉันสามารถส่งออกสไลด์เป็น XPS ได้หรือไม่ และมีตัวเลือกในการปรับแต่งผลลัพธ์ XPS หรือไม่?**

ใช่ [Export to XPS](/slides/th/cpp/convert-powerpoint-to-xps/) ได้รับการสนับสนุนและคุณสามารถปรับ [save options](https://reference.aspose.com/slides/th/cpp/aspose.slides.export/xpsoptions/) ที่เกี่ยวข้องเพื่อควบคุมคุณภาพและเนื้อหาของเอกสาร XPS.
