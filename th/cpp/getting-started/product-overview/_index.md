## **ยินดีต้อนรับสู่ Aspose.Slides for C++!**

Aspose.Slides for C++ เป็น API การจัดการ Microsoft PowerPoint® ที่ช่วยให้แอปพลิเคชัน C++ สามารถอ่านและเขียนเอกสาร PowerPoint® ได้โดยไม่ต้องใช้ Microsoft PowerPoint® Aspose.Slides for C++ เป็นคอมโพเนนต์ตัวแรกและตัวเดียวที่ให้ความสามารถในการจัดการเอกสาร PowerPoint® Aspose.Slides for C++ มีคุณลักษณะสำคัญหลายอย่าง เช่น การจัดการข้อความ, รูปร่าง, ตาราง & แอนิเมชัน, การเพิ่มเสียงและวิดีโอลงในสไลด์, การดูตัวอย่างสไลด์, การส่งออกสไลด์เป็น SVG, PDF และอื่น ๆ อีกมากมาย

## **คำอธิบายผลิตภัณฑ์**
Aspose.Slides for C++ พัฒนาด้วย Native C++ ปัจจุบันคอมไพล์สำหรับสภาพแวดล้อม Windows x64 แต่จะมีการคอมไพล์สำหรับสภาพแวดล้อม Linux ด้วย

Aspose.Slides for C++ ไม่เพียงแค่เปิดไฟล์ PowerPoint จากแหล่งต่าง ๆ เท่านั้น ยังอนุญาตให้คุณบันทึกการนำเสนอในรูปแบบต่าง ๆ ด้วย ตัวอย่างเช่น คุณสามารถบันทึกการนำเสนอเป็น PPT, PDF และแม้แต่บันทึกสไลด์เป็นภาพ Aspose.Slides for C++ ให้คุณสมบัติเบื้องต้นที่คุณอาจพบใน Microsoft PowerPoint ความหลากหลายของ Aspose.Slides for C++ อยู่ที่คุณสามารถเพิ่มตารางและรูปทรงประเภทต่าง ๆ ลงในสไลด์ รวมถึงเฟรมหลายประเภท (เช่น ข้อความ, เสียง & วิดีโอ)

## **ชุดคุณลักษณะที่ครบครัน**
คุณลักษณะของ Aspose.Slides for C++ สามารถแบ่งออกเป็นหัวข้อต่าง ๆ ดังนี้

1. คุณลักษณะของการนำเสนอ
1. คุณลักษณะของสไลด์
1. คุณลักษณะของกราฟิกและสื่อหลายรูปแบบ
1. คุณลักษณะของตาราง
1. คุณลักษณะของข้อความ & ย่อหน้า
1. คุณลักษณะขั้นสูง

### **คุณลักษณะของการนำเสนอ**
- เปิดไฟล์ Microsoft PowerPoint จากแหล่งต่าง ๆ
- บันทึกการนำเสนอในรูปแบบ Microsoft PowerPoint ต่าง ๆ
- สร้างการนำเสนอจากศูนย์
- แปลงการนำเสนอเป็นเอกสาร PDF โดยไม่ต้องใช้คอมโพเนนต์อื่น
- อ่านหรือแก้ไขคุณสมบัติของเอกสารการนำเสนอ
- ตั้งค่าการป้องกันการนำเสนอ
- ส่งออกการนำเสนอเป็น PDF
- ส่งออกการนำเสนอเป็น XPS
- ส่งออกการนำเสนอเป็น SWF
- ส่งออกบันทึกย่อของการนำเสนอเป็น PDF
- ส่งออกการนำเสนอเป็น HTML

### **คุณลักษณะของสไลด์**
- สร้างสไลด์ใหม่จากศูนย์และเพิ่มลงในการนำเสนอ
- เข้าถึงสไลด์ใด ๆ ผ่านตำแหน่งของมันในการนำเสนอ
- คัดลอกหรือโคลนสไลด์ไปยังการนำเสนอเดียวกันหรืออื่น ๆ
- แก้ไขและลบสไลด์
- คัดลอกมาสเตอร์พร้อมสไลด์โดยอัตโนมัติ
- ดูตัวอย่างสไลด์
- รับหรือกำหนดชื่อสไลด์
- บันทึกสไลด์เป็นภาพ
- ส่งออกสไลด์เป็นรูปแบบ SVG
- ทำงานกับมาสเตอร์หลายตัวในการนำเสนอ
- เติมพื้นหลังสไลด์ด้วยสไตล์ที่รองรับใด ๆ
- เพิ่มหรือจัดการบันทึกย่อของสไลด์
- ตั้งค่ามาสเตอร์และสไตล์ของสไลด์ใหม่แบบไดนามิก
- เพิ่มหรือแก้ไขการเปลี่ยนสไลด์โชว์
- เพิ่มการเปลี่ยนแบบ Morph

### **คุณลักษณะของกราฟิก & สื่อหลายรูปแบบ**
- สร้างหรือจัดการรูปทรง เช่น เส้น, สี่เหลี่ยม, วงรี และโพลีไลน์
- จัดการสไตล์ของเส้นในรูปทรง
- รับข้อความแทนที่ของรูปทรง
- หมุนหรือพลิกรูปทรง
- เติมรูปทรงด้วยสไตล์ต่าง ๆ เช่น ทึบ, ไล่ระดับสี, แบบลาย, เนื้อผ้าและรูปภาพ
- ใช้ลายลักษณ์ 48 แบบที่กำหนดล่วงหน้าและเนื้อผ้า 24 แบบ
- เชื่อมโยงลิงก์กับรูปทรง
- อ่าน, แก้ไขหรือเพิ่มเอฟเฟกต์แอนิเมชันให้กับสไลด์และรูปทรง
- เพิ่มรูปภาพใหม่ในการนำเสนอหรือจัดการรูปภาพที่มีอยู่
- เพิ่มจุดสัญลักษณ์รูปภาพใหม่ในการนำเสนอหรือจัดการจุดสัญลักษณ์ที่มีอยู่
- เพิ่มเฟรมเสียงใหม่ในการนำเสนอหรือจัดการเฟรมที่มีอยู่
- เพิ่มเฟรมวิดีโอใหม่ในการนำเสนอหรือจัดการเฟรมที่มีอยู่

### **คุณลักษณะของตาราง**
- สร้างตารางจากศูนย์และเพิ่มลงในสไลด์
- ปรับขนาดและย้ายตาราง
- เข้าถึงเซลล์ใด ๆ ในตาราง
- เปลี่ยนรูปแบบและเส้นขอบของเซลล์ใด ๆ
- ปรับขนาดคอลัมน์และแถว
- เพิ่มและลบคอลัมน์และแถว
- กำหนดความกว้างและสีของเส้นขอบสำหรับตารางทั้งหมด

### **คุณลักษณะของข้อความ & ย่อหน้า**
- รับและกำหนดข้อความในตัวแทนข้อความและเฟรมข้อความ
- รับประเภทของตัวแทนข้อความ
- เปลี่ยนการจัดรูปแบบข้อความในเฟรมข้อความ
- เพิ่มหรือจัดการแบบอักษรที่ใช้ในการนำเสนอ
- เปลี่ยนข้อความและการจัดรูปแบบข้อความ
- สร้างหรือจัดการลิงก์ในข้อความ
- รองรับแท็บและแท็บที่มีประสิทธิภาพ
- เพิ่มเฟรมข้อความใหม่ในรูปทรงเกือบทุกประเภท
- เข้าถึงและแก้ไขขอบเขตและการตัดข้อความของเฟรมข้อความ
- เข้าถึงและแก้ไขการเยื้องของย่อหน้า

## **FAQ**

**รองรับระดับการปฏิบัติตามมาตรฐาน PDF สำหรับการจัดเก็บและการเข้าถึง (PDF/A และ PDF/UA) หรือไม่?**

ใช่ คุณสามารถบันทึกเป็น PDF พร้อม PDF/A-2a/2b/2u, PDF/A-3a/3b รวมถึง PDF/UA โดยกำหนดค่า [ตัวเลือกการส่งออก PDF](https://reference.aspose.com/slides/th/cpp/aspose.slides.export/pdfoptions/)

**มีกลไกการทดแทนแบบอักษรและการรองรับแบบอักษรกำหนดเองเพื่อให้การแสดงผลถูกต้องหรือไม่?**

ใช่ ไลบรารีอนุญาตให้คุณ [โหลดแบบอักษรกำหนดเอง](/slides/th/cpp/custom-font/) และ [กำหนดกฎการสำรอง](/slides/th/cpp/fallback-font/) เพื่อให้กลีฟที่ขาดหายไปถูกแทนที่อย่างเชื่อถือได้ระหว่างการแปลงและการแสดงผล

**สามารถตรวจจับไฟล์ที่มีการป้องต้นด้วยรหัสผ่านโดยไม่ต้องเปิดครบหรือไม่?**

ใช่ คุณสามารถ [ตรวจสอบการนำเสนอ](/slides/th/cpp/examine-presentation/) เพื่อตรวจจับว่าต้องการรหัสผ่านก่อนโหลดเอกสารเต็มหรือไม่

**ต้องใช้ Microsoft PowerPoint สำหรับการประมวลผลและการแปลงหรือไม่?**

ไม่ Aspose.Slides เป็นเอนจินอิสระ; ไม่จำเป็นต้องติดตั้ง PowerPoint บนเซิร์ฟเวอร์หรือเวิร์กสเตชัน

**ปลอดภัยหรือไม่ที่จะประมวลผลการนำเสนอจากหลายเธรดพร้อมกัน?**

ใช่ คุณสามารถประมวลผลเอกสารหลายไฟล์โดยขนานในเธรดแยกต่างหาก; เพียงหลีกเลี่ยงการใช้วัตถุตัวเดียวพร้อมกัน [ข้ามเธรด](/slides/th/cpp/multithreading/)

**แมโครยังคงอยู่และสามารถจัดการ VBA ในไฟล์ PPTM/PPSM ได้หรือไม่?**

ใช่ การนำเสนอที่มีแมโคร [ได้รับการสนับสนุน](/slides/th/cpp/presentation-via-vba/), และคุณสามารถ [ตรวจสอบและจัดการโปรเจกต์ VBA](https://reference.aspose.com/slides/th/cpp/aspose.slides.vba/) ในไฟล์เหล่านั้น

**สามารถแปลง PDF หรือ HTML กลับเป็นสไลด์ PowerPoint ได้หรือไม่?**

ใช่ คุณสามารถ [นำเข้าหน้า PDF หรือเนื้อหา HTML](/slides/th/cpp/import-presentation/) เพื่อสร้างหรือเติมสไลด์ในการนำเสนอ

**รองรับการส่งออก XPS หรือไม่ และสามารถควบคุมคุณภาพและเนื้อหาของผลลัพธ์ XPS ได้หรือไม่?**

ใช่ มี [การส่งออกเป็น XPS](/slides/th/cpp/convert-powerpoint-to-xps/) ให้ใช้ได้และ [ตัวเลือกการบันทึก](https://reference.aspose.com/slides/th/cpp/aspose.slides.export/xpsoptions/) ช่วยปรับคุณภาพและเนื้อหาที่รวมอยู่

**สามารถแปลงสไลด์เป็นภาพและควบคุมคุณภาพของผลลัพธ์ได้หรือไม่?**

ใช่ สไลด์สามารถ [เรนเดอร์เป็น PNG, JPEG, GIF, BMP, TIFF](/slides/th/cpp/convert-powerpoint-to-png/) และรูปแบบอื่น ๆ พร้อมการควบคุมขนาดและคุณภาพอย่างละเอียด

**รองรับสูตรคณิตศาสตร์ (MathML/MathText) และสามารถส่งออกได้หรือไม่?**

ใช่ คุณสามารถ [สร้างและแก้ไขข้อความคณิตศาสตร์](/slides/th/cpp/powerpoint-math-equations/) และ [ส่งออกสมการ](/slides/th/cpp/exporting-math-equations/) รวมถึงเป็น MathML

**ไลบรารีจัดการการเข้ารหัสและรหัสผ่าน (เปิด, ตั้งค่า, ลบ) อย่างไร?**

[รองรับ](/slides/th/cpp/password-protected-presentation/) การเปิดการนำเสนอที่เข้ารหัส, การตั้งหรือลบรหัสผ่านสำหรับการเปิดและแก้ไข, รวมถึงการตรวจสอบสถานะการป้องกันของไฟล์
