## **รูปแบบไฟล์และการแปลง**
Aspose.Slides forC++ รองรับรูปแบบเอกสาร PowerPoint ส่วนใหญ่และยังสามารถส่งออกเป็นรูปแบบที่ได้รับความนิยมซึ่งใช้กันอย่างกว้างขวางสำหรับการแลกเปลี่ยนระหว่างองค์กร ตารางต่อไปนี้แสดงรูปแบบเหล่านั้น:

|**ฟีเจอร์**|**คำอธิบาย**|
| :- | :- |
|[Microsoft PowerPoint (PPT)](/slides/th/cpp/microsoft-powerpoint-ppt/)|Aspose.Slides for C++ ให้การประมวลผลที่เร็วที่สุดสำหรับรูปแบบเอกสารการพรีเซนเทชันนี้.|
|[Portable Document Format (PDF)](/slides/th/cpp/portable-document-format-pdf/)|รูปแบบไฟล์ที่รองรับสามารถส่งออกเป็นเอกสาร Adobe Portable Document Format (PDF) ด้วยวิธีเดียว.|
|[XML Parser Specification (XPS)](/slides/th/cpp/xml-parser-specification-xps/)|รูปแบบไฟล์ทั้งหมดที่รองรับสามารถส่งออกเป็นเอกสาร XML Parser Specification (XPS) ด้วยวิธีเดียว.|
|[PresentationML (PPTX, XML)](/slides/th/cpp/presentationml-pptx-xml/)|Aspose.Slides for C++ รองรับการประมวลผลรูปแบบการพรีเซนเทชัน OOXML ที่รู้จักกันในชื่อ PresentationML หรือ PPTX.|
|[PPTX To HTML Conversion](https://docs.aspose.com/slides/th/cpp/convert-powerpoint-to-html/)|Aspose.Slides for C++ รองรับการแปลงพรีเซนเทชันเป็นรูปแบบ HTML.|

## **การเรนเดอร์พรีเซนเทชัน**
Aspose.Slides for C++ รองรับการเรนเดอร์สไลด์ในเอกสารพรีเซนเทชันด้วยความแม่นยำสูงเป็นรูปแบบกราฟิกต่างๆ ตามที่ระบุด้านล่าง:

|**ฟีเจอร์**|**คำอธิบาย**|
| :- | :- |
|รูปแบบภาพที่รองรับโดย C++|โดยใช้ Aspose.Slides for C++ คุณจะสามารถเรนเดอร์สไลด์พรีเซนเทชันไม่เพียงแค่สไลด์เท่านั้น แต่ยังรวมถึงรูปภาพบนสไลด์เป็นรูปแบบกราฟิกที่ C++ รองรับทั้งหมด เช่น PNG, BMP และ JPEG|
|รูปแบบ SVG|Aspose.Slides for C++ ยังมีเมธอดในตัวสำหรับส่งออกสไลด์พรีเซนเทชันเป็นรูปแบบ Scalable Vector Graphics (SVG).|

## **ฟีเจอร์ของเนื้อหา**
Aspose.Slides forC++ ช่วยให้คุณสามารถเข้าถึง แก้ไข หรือสร้างเนื้อหาต่างๆ ของเอกสารพรีเซนเทชันได้เกือบทั้งหมด.

|**ฟีเจอร์**|**คำอธิบาย**|
| :- | :- |
|สไลด์แม่|สไลด์แม่กำหนดเค้าโครงของสไลด์ปกติ Aspose.Slides for C++ ทำให้คุณสามารถเข้าถึงและแก้ไขสไลด์แม่ของเอกสารพรีเซนเทชัน|
|สไลด์ปกติ|โดยใช้ Aspose.Slides for C++ คุณไม่เพียงแต่สร้างสไลด์ใหม่หลายประเภท แต่ยังสามารถเข้าถึงและแก้ไขสไลด์ที่มีอยู่ในเอกสารพรีเซนเทชัน|
|การทำสำเนา / คัดลอกสไลด์|Aspose.Slides for C++ มีเมธอดในตัวสำหรับทำสำเนาหรือคัดลอกสไลด์ที่มีอยู่ไม่เฉพาะภายในพรีเซนเทชันเดียว แต่ยังสามารถคัดลอกจากพรีเซนเทชันหนึ่งไปยังอีกพรีเซนเทชันหนึ่งได้ เนื่องจากสไลด์สืบทอดเค้าโครงจากสไลด์แม่ เมธอดทำสำเนาในตัวจะคัดลอกสไลด์แม่ด้วยโดยอัตโนมัติ|
|Place Holders และ Text Holders|คุณสามารถเข้าถึง Place Holders และ Text Holders ในสไลด์ได้ นอกจากนี้คุณยังสามารถสร้างสไลด์ที่มี Text Holders ตั้งแต่ต้นโดยใช้เมธอดที่เหมาะสม|
|หัวเรื่องและท้ายเรื่อง|Aspose.Slides for C++ ยังอำนวยความสะดวกในการจัดการหัวเรื่อง / ท้ายเรื่องในสไลด์|
|บันทึกโน้ตในสไลด์|ด้วย Aspose.Slides for C++ คุณไม่เพียงแต่เข้าถึงและแก้ไขโน้ตที่เกี่ยวข้องกับสไลด์เท่านั้น แต่ยังสามารถเพิ่มโน้ตได้|
|ค้นหา Shape|คุณยังสามารถค้นหา Shape เฉพาะจากสไลด์โดยใช้ข้อความแทนที่เชื่อมโยงกับ Shape นั้น|
|พื้นหลัง|Aspose.Slides for C++ ทำให้คุณทำงานกับพื้นหลังที่เชื่อมโยงกับสไลด์แม่หรือสไลด์ปกติของพรีเซนเทชันได้|
|กล่องข้อความ|กล่องข้อความสามารถสร้างจากศูนย์ได้ สามารถเข้าถึงกล่องข้อความที่มีอยู่และแก้ไขข้อความโดยไม่สูญเสียรูปแบบข้อความเดิม|

## **คำถามที่พบบ่อย**

### ฉันต้องติดตั้ง Microsoft PowerPoint บนเซิร์ฟเวอร์/PC เพื่อให้ไลบรารีทำงานหรือไม่?
ไม่. จำเป็นต้องติดตั้ง PowerPoint; Aspose.Slides เป็นเอนจินอิสระสำหรับการสร้าง, แก้ไข, แปลงและเรนเดอร์พรีเซนเทชัน.

### การทำงานของมัลติเทรดเป็นอย่างไร? สามารถทำการประมวลผลแบบขนานได้หรือไม่?
ปลอดภัยในการประมวลผลเอกสารต่างๆ ในเธรดต่างๆ; วัตถุ [presentation](https://reference.aspose.com/slides/th/cpp/aspose.slides/presentation/) เดียวกันไม่ควรใช้งานโดย [multiple threads](/slides/th/cpp/multithreading/) พร้อมกัน.

### รองรับรหัสผ่านไฟล์และการเข้ารหัสหรือไม่?
ใช่. [คุณสามารถ](/slides/th/cpp/password-protected-presentation/) เปิดพรีเซนเทชันที่เข้ารหัส ตั้งหรือเอารหัสผ่านการเปิดและเขียนออก และตรวจสอบสถานะการป้องกัน.

### จำเป็นต้องใส่ใจแพ็กเกจฟอนต์ในคอนเทนเนอร์ Linux หรือไม่?
ใช่. แนะนำให้ติดตั้งแพ็กเกจฟอนต์ทั่วไปและ/หรือระบุ [font directories](/slides/th/cpp/custom-font/) อย่างชัดเจนในแอปพลิเคชันของคุณเพื่อหลีกเลี่ยงการแทนที่ที่ไม่คาดคิด.

### มีข้อจำกัดในเวอร์ชันทดลองหรือไม่?
ใน [evaluation mode](/slides/th/cpp/licensing/) จะมีลายน้ำเพิ่มลงในผลลัพธ์และมีข้อจำกัดบางประการ; [ใบอนุญาตชั่วคราว 30 วัน](https://purchase.aspose.com/temporary-license/) มีให้สำหรับการทดสอบเต็มคุณลักษณะ.

### รองรับการนำเข้ารูปแบบภายนอกเข้าสู่พรีเซนเทชัน (PDF/HTML → PPTX) หรือไม่?
ใช่. คุณสามารถเพิ่ม [PDF pages and HTML content](/slides/th/cpp/import-presentation/) ลงในพรีเซนเทชันและแปลงเป็นสไลด์ได้.
