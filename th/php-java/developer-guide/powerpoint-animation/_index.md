## **บทนำ**

เนื่องจากการนำเสนอมีจุดประสงค์เพื่อแสดงบางอย่าง ลักษณะภาพและพฤติกรรมเชิงโต้ตอบจึงต้องคำนึงถึงเสมอในระหว่างการสร้าง

**PowerPoint animation** มีบทบาทสำคัญในการทำให้การนำเสนอน่าสนใจและดึงดูดผู้ชม Aspose.Slides for PHP via Java ให้ตัวเลือกหลากหลายเพื่อเพิ่มการเคลื่อนไหวให้กับไฟล์ PowerPoint:

- ใช้เอฟเฟกต์การเคลื่อนไหวของ PowerPoint หลากหลายประเภทกับรูปร่าง แผนภูมิ ตาราง วัตถุ OLE และองค์ประกอบการนำเสนออื่นๆ
- ใช้เอฟเฟกต์การเคลื่อนไหวหลายอย่างบนรูปร่างเดียว
- ใช้ไทม์ไลน์การเคลื่อนไหวเพื่อควบคุมเอฟเฟกต์การเคลื่อนที่
- สร้างการเคลื่อนไหวแบบกำหนดเอง

ใน Aspose.Slides for PHP via Java สามารถใช้เอฟเฟกต์การเคลื่อนไหวกับรูปร่างต่างๆ ได้ เนื่องจากทุกองค์ประกอบบนสไลด์ รวมถึงข้อความ รูปภาพ วัตถุ OLE และตาราง ถือเป็นรูปร่าง จึงสามารถนำเอฟเฟกต์การเคลื่อนไหวไปใช้กับองค์ประกอบใดก็ได้บนสไลด์

## **เอฟเฟกต์การเคลื่อนไหว**
Aspose.Slides รองรับ **เอฟเฟกต์การเคลื่อนไหวกว่า 150 รายการ** รวมถึงเอฟเฟกต์พื้นฐานเช่น Bounce, PathFootball, และ Zoom รวมถึงเอฟเฟกต์เฉพาะเช่น OLEObjectShow และ OLEObjectOpen คุณสามารถดูรายการทั้งหมดได้ในคลาส [EffectType](https://reference.aspose.com/slides/th/php-java/aspose.slides/effecttype/)

นอกจากนี้ เอฟเฟกต์การเคลื่อนไหวเหล่านี้สามารถนำไปใช้ร่วมกับพฤติกรรมต่อไปนี้ได้:

- [ColorEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/ColorEffect)
- [CommandEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/CommandEffect)
- [FilterEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/FilterEffect)
- [MotionEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/MotionEffect)
- [PropertyEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/PropertyEffect)
- [RotationEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/RotationEffect)
- [ScaleEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/ScaleEffect)
- [SetEffect](https://reference.aspose.com/slides/th/php-java/aspose.slides/SetEffect)

## **การเคลื่อนไหวแบบกำหนดเอง**

สำหรับตัวอย่าง PHP ฉบับเต็มที่สร้าง ตรวจสอบ และแก้ไขพฤติกรรมและเส้นทางการเคลื่อนที่ที่แก้ไขได้ ดูที่ [Custom Animation](/slides/th/php-java/custom-animation/)

คุณสามารถสร้าง **การเคลื่อนไหวแบบกำหนดเอง** ของคุณเองใน Aspose.Slides ได้ ด้วยการรวมพฤติกรรมหลายอย่างเป็นการเคลื่อนไหวแบบกำหนดใหม่

[Behavior](https://reference.aspose.com/slides/th/php-java/aspose.slides/behavior/) เป็นบล็อกพื้นฐานของเอฟเฟกต์การเคลื่อนไหว PowerPoint ผสานพฤติกรรมเพื่อปรับแต่งเอฟเฟกต์ หรือเพิ่มพฤติกรรมเพื่อขยายเอฟเฟกต์ที่กำหนดไว้ การทำซ้ำกำหนดผ่านการตั้งค่าเวลา ไม่ใช่พฤติกรรมทำซ้ำแยกต่างหาก

[Animation Point](https://reference.aspose.com/slides/th/php-java/aspose.slides/point/) คือจุดที่ควรใช้พฤติกรรม

## **ไทม์ไลน์การเคลื่อนไหว**
[Sequence](https://reference.aspose.com/slides/th/php-java/aspose.slides/sequence/) เป็นคอลเลกชันของเอฟเฟกต์การเคลื่อนไหวที่สามารถกำหนดเป้าหมายให้กับรูปร่างต่างๆ

[Timeline](https://reference.aspose.com/slides/th/php-java/aspose.slides/animationtimeline/) เป็นชุดของ Sequence ที่ใช้ในสไลด์เฉพาะ มันเป็นเครื่องยนต์การเคลื่อนไหวที่ถูกแนะนำใน PowerPoint 2002 ในเวอร์ชันก่อนหน้าของ PowerPoint การเพิ่มเอฟเฟกต์การเคลื่อนไหวให้กับการนำเสนอเป็นเรื่องท้าทายและต้องอาศัยวิธีแก้ปัญหาต่างๆ ไทม์ไลน์ให้โมเดลวัตถุที่ชัดเจนยิ่งขึ้นสำหรับการเคลื่อนไหวของ PowerPoint สไลด์หนึ่งสามารถมีไทม์ไลน์การเคลื่อนไหวได้เพียงอันเดียว

## **การเคลื่อนไหวแบบโต้ตอบ**
[Trigger](https://reference.aspose.com/slides/th/php-java/aspose.slides/effecttriggertype/) ช่วยให้คุณกำหนดการกระทำของผู้ใช้ เช่น การคลิกปุ่ม เพื่อเริ่มการเคลื่อนไหวเฉพาะ

## **คำถามที่พบบ่อย**

**การเคลื่อนไหวจะคงอยู่เมื่อส่งออกเป็น PDF หรือไม่?**

ไม่ใช่ PDF เป็นรูปแบบคงที่ ดังนั้นการเคลื่อนไหวและ [slide transitions](/slides/th/php-java/slide-transition/) จะไม่ทำงาน หากต้องการเคลื่อนไหวให้ส่งออกเป็น [HTML5](/slides/th/php-java/export-to-html5/), [animated GIF](/slides/th/php-java/convert-powerpoint-to-animated-gif/), หรือ [video](/slides/th/php-java/convert-powerpoint-to-video/) แทน

**ฉันสามารถแปลงการนำเสนอที่มีการเคลื่อนไหวเป็นวิดีโอและกำหนดอัตราเฟรมและขนาดเฟรมได้หรือไม่?**

ได้ คุณสามารถ [render the presentation as frames](/slides/th/php-java/convert-powerpoint-to-video/) แล้วเข้ารหัสเป็นวิดีโอ (เช่น ผ่าน ffmpeg) โดยเลือกรูปแบบ FPS และความละเอียด การเคลื่อนไหวและการเปลี่ยนสไลด์จะถูกเล่นระหว่างการเรนเดอร์

**การเคลื่อนไหวจะคงอยู่เมื่อทำงานกับ ODP (ไม่ใช่แค่ PPTX) หรือไม่?**

PPT, PPTX, และ ODP รองรับการ [reading](/slides/th/php-java/open-presentation/) และ [writing](/slides/th/php-java/save-presentation/) แต่ไม่ได้รับประกันว่าการเคลื่อนไหวจะคงอยู่ ข้อมูลการเคลื่อนไหวแบบกำหนดเองอาจสูญหายเมื่อแปลงเป็น ODP ดูที่ [Custom Animation](/slides/th/php-java/custom-animation/) สำหรับตัวอย่างและแนวทางตรวจสอบความเข้ากันได้ของฟอร์แมต
