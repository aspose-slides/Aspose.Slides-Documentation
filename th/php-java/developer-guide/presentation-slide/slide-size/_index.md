## **บทนำ**

Aspose.Slides มีเครื่องมือครบครันในการปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจคเตอร์และจอแสดงผลสมัยใหม่

ควรใช้ขนาดสไลด์และอัตราส่วนเดียวกันตลอดงานนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนที่กำหนดจะใช้กับทุกสไลด์ เพื่อผลลัพธ์ที่ดีที่สุด ให้กำหนดขนาดสไลด์ตั้งแต่เริ่มต้นกระบวนการสร้างงานนำเสนอ เพื่อลดความซับซ้อนในภายหลัง

{{% alert color="primary" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วน 4:3 แบบมาตรฐาน
{{% /alert %}}

## **การเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างโค้ดนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอโดยใช้ Aspose.Slides:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **กำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่เฉพาะหรือไม่ซ้ำใคร ตัวอย่างเช่น หากต้องการพิมพ์สไลด์เต็มขนาดจากงานนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางประเภท คุณจะได้รับประโยชน์จากการตั้งค่าขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอของคุณ  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้ Aspose.Slides for PHP via Java เพื่อตั้งค่าขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอ:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// ขนาดกระดาษ A4

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์ของงานนำเสนอ เนื้อหาในสไลด์ (เช่นรูปภาพหรือออบเจ็กต์) อาจบิดเบี้ยว โดยค่าเริ่มต้น ออบเจ็กต์จะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตามเมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถกำหนดค่าที่กำหนดว่าการทำงานของ Aspose.Slides กับเนื้อหาในสไลด์จะเป็นอย่างไร  

ขึ้นอยู่กับสิ่งที่คุณต้องการทำหรือบรรลุ คุณสามารถใช้การตั้งค่าใดๆ ต่อไปนี้:

- `DoNotScale`

  หากคุณไม่ต้องการให้วัตถุในสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `EnsureFit`

  หากคุณต้องการปรับให้เข้ากับขนาดสไลด์ที่เล็กลงและต้องการให้ Aspose.Slides ปรับขนาดออบเจ็กต์ให้พอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้

- `Maximize`

  หากคุณต้องการปรับให้เข้ากับขนาดสไลด์ที่ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายออบเจ็กต์ให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งค่าขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?**

ได้ Aspose.Slides ใช้หน่วยจุดภายใน โดย 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใดก็ได้ (เช่นมิลลิเมตรหรือเซนติเมตร) ไปเป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์  

**ขนาดสไลด์กำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับอัตราส่วนการเรนเดอร์ที่สูงจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและใช้เวลาประมวลผลนานขึ้น ควรกำหนดขนาดสไลด์ที่เป็นประโยชน์และปรับอัตราส่วนการเรนเดอร์เฉพาะตามที่จำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ  

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งขนาดแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ[merge presentations](/slides/th/php-java/merge-presentation/)ขณะมีขนาดสไลด์ต่างกัน — ต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่งก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการเนื้อหาที่มีอยู่ผ่านตัวเลือก[SlideSizeScaleType](https://reference.aspose.com/slides/th/php-java/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณสามารถรวมสไลด์พร้อมรักษาการจัดรูปแบบไว้ได้  

**ฉันสามารถสร้างรูปภาพย่อ (thumbnail) สำหรับรูปร่างเดี่ยวหรือพื้นที่เฉพาะของสไลด์ได้หรือไม่ และจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ได้ Aspose.Slides สามารถเรนเดอร์รูปภาพย่อสำหรับ[entire slides](https://reference.aspose.com/slides/th/php-java/aspose.slides/slide/#getImage)และสำหรับ[selected shapes](https://reference.aspose.com/slides/th/php-java/aspose.slides/shape/#getImage)ได้ รูปภาพที่ได้จะแสดงขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ส่งผลให้กรอบและเรขาคณิตสอดคล้องกัน
