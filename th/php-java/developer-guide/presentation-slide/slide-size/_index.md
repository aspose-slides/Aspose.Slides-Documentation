## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **มาตรฐาน (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **แบบกว้าง (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจคเตอร์และจอแสดงผลสมัยใหม่  

ตรวจสอบให้แน่ใจว่ามีความสม่ำเสมอตลอดการนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนภาพเดียวกันจะใช้กับสไลด์ทั้งหมด เพื่อให้ได้ผลลัพธ์ที่ดีที่สุด ควรกำหนดขนาดสไลด์ตั้งแต่ต้นกระบวนการสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหา  

{{% alert color="info" title="Note" %}}
โดยค่าเริ่มต้นงานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3
{{% /alert %}}

หน้าบันทึกย่อและหน้าสำหรับแจกจ่ายมีขนาดที่แยกต่างหากจากสไลด์ทั่วไป ดูที่ [ขนาดหน้าบันทึกย่อ](/slides/th/php-java/notes-size/) เพื่อเปลี่ยนขนาดและการจัดแนว  

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างโค้ดนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอโดยใช้ Aspose.Slides:

```php
  $pres = new Presentation("pres-4x3-aspect-ratio.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::OnScreen16x9, SlideSizeScaleType::DoNotScale);
    $pres->save("pres-4x3-aspect-ratio.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **ระบุขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากคุณพบว่าขนาดสไลด์ที่พบทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจเลือกใช้ขนาดสไลด์ที่เฉพาะเจาะหรือไม่เหมือนใคร ตัวอย่างเช่น หากคุณตั้งใจพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนการจัดหน้าที่กำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนหน้าจอประเภทบางอย่าง การตั้งขนาดสไลด์แบบกำหนดเองจะช่วยให้คุณได้ประโยชน์  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้ Aspose.Slides สำหรับ PHP ผ่าน Java เพื่อระบุขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอ:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(780, 540, SlideSizeScaleType::DoNotScale);// ขนาดกระดาษ A4

    $pres->save("pres-a4-slide-size.pptx", SaveFormat::Pptx);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์ของงานนำเสนอ เนื้อหาสไลด์ (เช่น รูปภาพหรือวัตถุต่าง ๆ) อาจผิดรูปบิดเบี้ยว โดยค่าเริ่มต้นวัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตามขณะเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถกำหนดการตั้งค่าที่กำหนดว่า Aspose.Slides จะจัดการกับเนื้อหาบนสไลด์อย่างไร  

ขึ้นอยู่กับสิ่งที่คุณตั้งใจทำหรือบรรลุ คุณสามารถใช้การตั้งค่าใดก็ได้ต่อไปนี้:

- `DoNotScale`

  หากคุณ **ไม่** ต้องการให้วัตถุบนสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้  

- `EnsureFit`

  หากคุณต้องการปรับขนาดให้เหมาะกับสไลด์ที่เล็กลงและต้องการให้ Aspose.Slides ปรับขนาดวัตถุบนสไลด์ลงเพื่อให้ทั้งหมดพอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้  

- `Maximize`

  หากคุณต้องการปรับขนาดให้เหมาะกับสไลด์ที่ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุบนสไลด์ให้เป็นสัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```php
  $pres = new Presentation("pres.pptx");
  try {
    $pres->getSlideSize()->setSize(SlideSizeType::Ledger, SlideSizeScaleType::Maximize);
  } finally {
    if (!java_is_null($pres)) {
      $pres->dispose();
    }
  }
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยที่ไม่ใช inches (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?**  

ใช่ Aspose.Slides ใช้หน่วยจุดเป็นหน่วยภายใน โดย 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตรหรือเซนติเมตร) ไปเป็นจุดและใช้ค่าที่แปลงแล้วเพื่อกำหนดความกว้างและความสูงของสไลด์ได้  

**ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**  

ใช่ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) พร้อมกับสเกลการเรนเดอร์ที่สูงขึ้นจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและใช้เวลาในกระบวนการทำงานนานขึ้น ควรเลือกขนาดสไลด์ที่เหมาะสมและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ  

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งค่าแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**  

คุณไม่สามารถ [merge presentations](/slides/th/php-java/merge-presentation/) ขณะที่มีขนาดสไลด์ต่างกัน — ก่อนอื่นต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่ง เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการเนื้อหาที่มีอยู่ผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/php-java/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้ว คุณจึงสามารถรวมสไลด์โดยคงรูปแบบได้  

**ฉันสามารถสร้างภาพย่อสำหรับรูปร่างเดี่ยวหรือพื้นที่เฉพาะของสไลด์ได้หรือไม่และภาพย่อนั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**  

ใช่ Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [entire slides](https://reference.aspose.com/slides/th/php-java/aspose.slides/slide/#getImage) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/php-java/aspose.slides/shape/#getImage) ได้ ภาพที่ได้จะแสดงขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่เสมอ
