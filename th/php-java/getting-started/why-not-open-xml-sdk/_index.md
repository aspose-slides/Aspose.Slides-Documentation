## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดนักพัฒนาควรเลือกระหว่าง Open XML SDK หรือ Aspose.Slides สำหรับการทำงานกับเอกสารงานนำเสนอ โดยอธิบายว่า Open XML SDK เป็นไลบรารีสำหรับจัดการแพ็กเกจ OOXML และองค์ประกอบ XML ที่อยู่ภายใน ในขณะที่ Aspose.Slides นำเสนอเป็นไลบรารีการประมวลผลงานนำเสนอที่มีโมเดลออบเจกต์ระดับสูงและรองรับงานที่เกี่ยวกับ PowerPoint มากมาย

บทความเปรียบเทียบทั้งสองตัวเลือกตามรูปแบบที่รองรับ โมเดลการเขียนโปรแกรม การเรนเดอร์ การสนับสนุนแพลตฟอร์ม และกรณีการใช้งานทั่วไป รวมถึงการชี้แจงว่า Open XML SDK อาจเหมาะสำหรับการทำงานพื้นฐานกับ PPTX หรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ในขณะที่ Aspose.Slides เหมาะกับงานนำเสนอที่ซับซ้อน เช่น การทำงานกับหลายรูปแบบ PowerPoint การคัดลอกหรือโคลนรูปร่าง การแทนที่ข้อความ การใช้แอนิเมชัน และการแปลงงานนำเสนอเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
ตามข้อมูลจาก[MSDN Library](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK ถูกกำหนดว่า:

Open XML SDK 2.0 ทำให้การจัดการแพ็กเกจ Open XML และองค์ประกอบสคีม่า Open XML ภายในแพ็กเกจง่ายขึ้น Open XML SDK 2.0 รวมงานทั่วไปหลายอย่างที่นักพัฒนาทำบนแพ็กเกจ Open XML ไว้ให้ ทำให้คุณสามารถทำการปฏิบัติการที่ซับซ้อนได้ด้วยเพียงไม่กี่บรรทัดของโค้ด

เอกสาร OOXML โดยพื้นฐานคือไฟล์ XML ที่บีบอัดเป็น zip และ Open XML SDK คือชุดคลาสที่อนุญาตให้คุณทำงานกับเนื้อหาเอกสาร OOXML แบบ strongly‑typed นั่นหมายความว่า แทนที่จะต้องแตกไฟล์เพื่อดึง XML โหลด XML ไปยังโครงสร้าง DOM แล้วทำงานกับองค์ประกอบและแอตทริบิวต์ XML โดยตรง Open XML SDK จะให้คลาสทำสิ่งเหล่านั้นแทน

## **Aspose.Slides คืออะไร?**
Aspose.Slides เป็นคลาสไลบรารีที่ทำให้แอปพลิเคชันของคุณสามารถทำงานประมวลผลงานนำเสนอต่อไปนี้ได้:

- การเขียนโปรแกรมด้วยโมเดลออบเจกต์ **Presentation**
- การแปลงคุณภาพสูงระหว่างรูปแบบงานนำเสนอ PowerPoint ที่สนับสนุนทั้งหมด รวมถึงการแปลงเป็น PDF, XPS และ TIFF
- ความสามารถในการสร้างภาพย่อของสไลด์ในรูปแบบที่เป็นที่รู้จัก เช่น PNG, JPEG และ BMP พร้อมกับการส่งออกสไลด์เป็น SVG
- ความสามารถในการสร้างงานนำเสนอจากศูนย์หรือโดยการรวมจากเอกสารหนึ่งหรือหลายเอกสาร
- การสนับสนุนการเพิ่มแอนิเมชัน, Ole Frames, ตาราง, การสร้างและจัดการแผนภูมิ
- การควบคุมอย่างละเอียดสำหรับการจัดการรูปแบบข้อความใน TextFrames, Paragraphs และ Portions

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับคุณสมบัติที่สนับสนุน โปรดเยี่ยมชม[Aspose.Slides Features](/slides/th/php-java/product-overview/)

## **สรุป**
{{% alert color="info" %}} 

Open XML SDK และ Aspose.Slides ไม่ได้แข่งขันกันโดยตรงเพราะพวกมันตอบสนองต่อความต้องการและกลุ่มผู้ใช้ที่ค่อนข้างต่างกัน Open XML SDK เป็นไลบรารีคลาสที่ให้วิธีแบบ strongly‑typed สำหรับทำงานกับเอกสาร OOXML ส่วน Aspose.Slides เป็นไลบรารีการประมวลผลงานนำเสนอที่มีประโยชน์มากและให้การสนับสนุนที่ครอบคลุมต่อเกือบทุกรูปแบบไฟล์ Microsoft PowerPoint

หากสิ่งที่คุณต้องการทำคือการปฏิบัติการโปรแกรมพื้นฐานบนเอกสาร PPTX แล้ว Open XML SDK อาจเป็นตัวเลือกที่เหมาะสม ด้วย Open XML SDK คุณจะรู้สึกสบายในการทำงานง่าย ๆ เช่น การสร้างเอกสาร PPTX อย่างง่าย การลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การดึงรูปภาพหรืออื่น ๆ งานบางอย่างทำได้ด้วย Open XML SDK แต่ทำไม่ได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบและแอตทริบิวต์ XML ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK อย่างไรก็ตาม หากคุณต้องการทำการปฏิบัติการที่ซับซ้อนบนเอกสาร เช่น งานต่อไปนี้ การใช้ Aspose.Slides จะเป็นตัวเลือกที่ดีที่สุด:

- รองรับรูปแบบ PowerPoint เก่าเพิ่มเติมนอกเหนือจาก PPTX
- คัดลอกหรือโคลนรูปร่างภายในสไลด์โดยผสานวัตถุ, สไตล์และการจัดรูปแบบอื่น ๆ อย่างเหมาะสม
- แทนที่ข้อความที่มีรูปแบบหรือไม่มีรูปแบบ
- การใช้แอนิเมชันและการเชื่อมต่อด้วยคอนเนกเตอร์กับรูปร่าง
- แปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้ได้ผลเหมือนที่ Microsoft PowerPoint จะแปลง
- พัฒนาแอปพลิเคชัน .NET หรือ Java ทั้งบนเดสก์ท็อปและเว็บ
