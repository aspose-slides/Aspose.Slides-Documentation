## **ประเมิน Aspose.Slides**
คุณสามารถดาวน์โหลด Aspose.Slides เพื่อประเมินได้อย่างง่ายดาย แพ็กเกจประเมินมีลักษณะเดียวกับแพ็กเกจที่ซื้อ เวอร์ชันประเมินจะกลายเป็นเวอร์ชันที่ได้รับใบอนุญาตโดยการเพิ่มบรรทัดโค้ดไม่กี่บรรทัดเพื่อใช้ใบอนุญาต.

## **ข้อจำกัดของเวอร์ชันประเมิน**
เวอร์ชันประเมินของ Aspose.Slides (ไม่มีการระบุใบอนุญาต) ให้ฟังก์ชันการทำงานทั้งหมดของผลิตภัณฑ์ โดยมีข้อจำกัดสองประการ:
* มันจะเพิ่มกล่องข้อความลายน้ำการประเมินไว้กลางแต่ละสไลด์ของการนำเสนอที่บันทึก
* ข้อความที่โค้ดของคุณอ่านจากการนำเสนอจะถูกตัดสั้นเหลือไม่กี่ตัวอักษรแรก ตามด้วยข้อความแจ้งข้อจำกัดของการประเมิน ส่วนข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ

{{% alert color="info" title="Note" %}}
หากคุณต้องการทดสอบ Aspose.Slides โดยไม่เจอข้อจำกัดของเวอร์ชันประเมิน คุณสามารถขอ **ใบอนุญาตชั่วคราว 30 วัน** ได้ โปรดดูที่ [วิธีรับใบอนุญาตชั่วคราว?](https://purchase.aspose.com/temporary-license) สำหรับข้อมูลเพิ่มเติม.
{{% /alert %}} 

## **เกี่ยวกับใบอนุญาต**
คุณสามารถดาวน์โหลดเวอร์ชันประเมินของ Aspose.Slides สำหรับ PHP ผ่าน Java ได้อย่างง่ายดายจาก [หน้าโหลด](https://packagist.org/packages/aspose/slides) เวอร์ชันประเมินให้ **ความสามารถที่เหมือนกันทั้งหมด** กับเวอร์ชันที่มีใบอนุญาตของ Aspose.Slides ยิ่งไปกว่านั้น เวอร์ชันประเมินจะกลายเป็นเวอร์ชันที่มีใบอนุญาตเมื่อคุณซื้อใบอนุญาตและเพิ่มโค้ดสองสามบรรทัดเพื่อใช้ใบอนุญาต.

ใบอนุญาตเป็นไฟล์ XML แบบข้อความธรรมดาที่บรรจุรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ได้รับใบอนุญาต วันที่หมดอายุการสมัครสมาชิก เป็นต้น ไฟล์นี้มีลายเซ็นดิจิทัล ดังนั้นห้ามแก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างโดยไม่ได้ตั้งใจในเนื้อหาไฟล์ก็จะทำให้ไฟล์เป็นโมฆะ.

เพื่อหลีกเลี่ยงข้อจำกัดที่เกี่ยวข้องกับเวอร์ชันประเมิน คุณต้องตั้งค่าใบอนุญาตก่อนใช้ **Aspose.Slides** คุณจำเป็นต้องตั้งค่าใบอนุญาตเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ.

คุณอาจต้องการดู [การให้ใบอนุญาตแบบจํานวนการใช้](/slides/th/php-java/metered-licensing/).

### **ตั้งค่าใบอนุญาตใน Aspose.Slides สำหรับ PHP ผ่าน Java**
ใบอนุญาตสามารถนำไปใช้จากแหล่งต่อไปนี้:
* เส้นทางโดยระบุชัดเจน
* สตรีม
* เป็นใบอนุญาตแบบจํานวนการใช้ – กลไกการให้ใบอนุญาตแบบใหม่

{{% alert color="info" title="Note" %}}
ใช้เมธอด **setLicense** เพื่อให้ใบอนุญาตกับคอมโพเนนต์

แม้ว่าการเรียก **setLicense** หลายครั้งจะไม่เป็นอันตราย แต่ก็เป็นการเสียทรัพยากร (ตัวประมวลผล) ที่ไม่จำเป็น.
{{% /alert %}}

{{% alert color="warning" title="Warning" %}}
ใบอนุญาตใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับเวอร์ชัน 21.4 หรือใหม่กว่า เวอร์ชันก่อนหน้านั้นใช้ระบบการให้ใบอนุญาตที่ต่างกันและจะไม่รับรู้ใบอนุญาตเหล่านี้.
{{% /alert %}}

#### **ใช้ใบอนุญาตด้วยไฟล์**
โค้ดตัวอย่างนี้ใช้เพื่อกำหนดไฟล์ใบอนุญาต:

**PHP**

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/th/lib/aspose.slides.php");

use aspose\slides\License;

$license = new License();
$license->setLicense(__DIR__ . "/Aspose.Slides.lic");
```

ตัวอย่างคาดว่าไฟล์ใบอนุญาตอยู่เคียงกับสคริปต์และส่งเส้นทางแบบเต็ม: Aspose.Slides ทำงานภายใน Tomcat จึงไม่สามารถแก้ไขเส้นทางสัมพัทธ์ตามโฟลเดอร์สคริปต์ของคุณได้ เมื่อเรียกเมธอด setLicense ชื่อใบอนุญาตควรตรงกับชื่อไฟล์ใบอนุญาตของคุณ ตัวอย่างเช่น คุณสามารถเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น "Aspose.Slides.lic.xml" จากนั้นในโค้ดของคุณต้องส่งชื่อใบอนุญาตใหม่ (Aspose.Slides.lic.xml) ไปยังเมธอด setLicense

#### **ใช้ใบอนุญาตจากสตรีม**
โค้ดตัวอย่างนี้ใช้เพื่อใช้ใบอนุญาตจากสตรีม:

```php
<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once(__DIR__ . "/vendor/aspose/slides/th/lib/aspose.slides.php");

use aspose\slides\License;

$stream = new Java("java.io.FileInputStream", __DIR__ . "/Aspose.Slides.lic");

$license = new License();
$license->setLicense($stream);

$stream->close();
```

## **คำถามที่พบบ่อย**

### ฉันสามารถตั้งค่าใบอนุญาตในสภาพแวดล้อมออฟไลน์อย่างสมบูรณ์ (ไม่มีการเชื่อมต่ออินเทอร์เน็ต) ได้หรือไม่?
ได้ การตรวจสอบความถูกต้องของใบอนุญาตทำโดยใช้ไฟล์ใบอนุญาตบนเครื่องท้องถิ่น ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต.

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?
ไม่ ใบอนุญาตเป็นแบบถาวร คุณสามารถใช้เวอร์ชันที่ปล่อยก่อนวันสิ้นสุดการสมัครของคุณต่อไปได้ แต่คุณจะไม่สามารถใช้เวอร์ชันใหม่หลังจากนั้นได้หากไม่ได้ต่ออายุ.
