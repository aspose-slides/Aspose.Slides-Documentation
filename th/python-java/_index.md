Aspose.Slides สำหรับ Python ผ่าน Java เป็นไลบรารีสำหรับการสร้าง อ่าน แก้ไข และแปลงงานนำเสนอ PowerPoint และ OpenDocument ในแอปพลิเคชัน Python โดยไม่ต้องใช้ Microsoft PowerPoint; มันทำงานโดยรันเอ็นจิน Aspose.Slides Java ในกระบวนการ Python ของคุณผ่าน JPype.

ไลบรารีนี้สามารถโหลดและบันทึกไฟล์ PPT, PPTX, PPS, POT และ ODP รวมถึงรูปแบบที่มีมาโครและเทมเพลตได้ และสามารถส่งออกเป็น PDF, XPS, HTML, SVG, TIFF, Markdown และภาพต่าง ๆ.

## **การนำเสนอแรกของคุณ**

ติดตั้ง Python และ JDK ตั้งค่า `JAVA_HOME` แล้วสร้างและเปิดใช้งาน virtual environment ตามที่อธิบายไว้ใน [การติดตั้ง](/slides/th/python-java/installation/). จากนั้นติดตั้ง JPype และ Aspose.Slides จาก PyPI:

```sh
python -m pip install JPype1 aspose-slides-java
```

บันทึกโค้ดนี้เป็น *hello.py* โค้ดนี้จะเริ่มต้นเครื่องเสมือน Java, เพิ่มรูปทรงเมฆพร้อมข้อความไปยังสไลด์แรกของการนำเสนอใหม่, และบันทึกการนำเสนอนั้น:

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat, ShapeType

# สร้างการนำเสนอพร้อมสไลด์เปล่า 1 หน้า.
presentation = Presentation()
try:
    # ดึงสไลด์แรก.
    slide = presentation.getSlides().get_Item(0)

    # เพิ่มรูปทรงเมฆและตั้งค่าข้อความของมัน.
    auto_shape = slide.getShapes().addAutoShape(ShapeType.Cloud, 20, 20, 200, 80)
    auto_shape.getTextFrame().setText("Hello, Aspose!")

    # บันทึกการนำเสนอเป็นไฟล์ PPTX.
    presentation.save("new_presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

เรียกใช้ใน virtual environment เดียวกัน:

```sh
python hello.py
```

สคริปต์นี้จะบันทึก *new_presentation.pptx* ที่มีสไลด์หนึ่งซึ่งมีรูปทรงเมฆพร้อมข้อความ "Hello, Aspose!". หากไม่มีใบอนุญาต ไฟล์ที่บันทึกจะมีลายน้ำการประเมิน — ดูที่ [การออกใบอนุญาต](/slides/th/python-java/licensing/). สำหรับวิธีเพิ่มเติมในการสร้างและเติมข้อมูลการนำเสนอ ดูที่ [สร้างการนำเสนอ](/slides/th/python-java/create-presentation/).
