Aspose.Slides for Python via Java เป็นไลบรารีสำหรับการสร้าง, อ่าน, แก้ไขและแปลงงานนำเสนอ PowerPoint และ OpenDocument ในแอปพลิเคชัน Python โดยไม่ต้องใช้ Microsoft PowerPoint; มันทำงานด้วยเอนจิน Aspose.Slides Java ในกระบวนการ Python ของคุณผ่าน JPype.

มันสามารถโหลดและบันทึกไฟล์ PPT, PPTX, PPS, POT และ ODP รวมถึงเวอร์ชันที่เปิดใช้งานแมโครและเทมเพลต, และส่งออกเป็น PDF, XPS, HTML, SVG, TIFF, Markdown และรูปภาพ.

## **งานนำเสนอแรกของคุณ**

ติดตั้ง Python และ JDK ตั้งค่า `JAVA_HOME` และสร้างและเปิดใช้งาน virtual environment ตามที่อธิบายไว้ใน [การติดตั้ง](/slides/th/python-java/installation/). จากนั้นติดตั้ง JPype และ Aspose.Slides จาก PyPI:

```sh
python -m pip install JPype1 aspose-slides-java
```

บันทึกโค้ดนี้เป็น *hello.py*. โค้ดนี้จะเริ่ม Java Virtual Machine, เพิ่มรูปร่างเมฆพร้อมข้อความลงในสไลด์แรกของงานนำเสนอใหม่, และบันทึกงานนำเสนอ:

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpame.startJVM()

from asposeslides.api import Presentation, SaveFormat, ShapeType

# สร้างงานนำเสนอด้วยสไลด์ว่างหนึ่งสไลด์.
presentation = Presentation()
try:
    # ดึงสไลด์แรก.
    slide = presentation.getSlides().get_Item(0)

    # เพิ่มรูปร่างเมฆและตั้งค่าข้อความ.
    auto_shape = slide.getShapes().addAutoShape(ShapeType.Cloud, 20, 20, 200, 80)
    auto_shape.getTextFrame().setText("Hello, Aspose!")

    # บันทึกงานนำเสนอเป็นไฟล์ PPTX.
    presentation.save("new_presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```

เรียกใช้งานใน virtual environment เดียวกัน:

```sh
python hello.py
```

สคริปต์จะบันทึกไฟล์ *new_presentation.pptx* ที่มีสไลด์หนึ่งซึ่งมีรูปร่างเมฆพร้อมข้อความ "Hello, Aspose!". หากไม่มีลิขสิทธิ์ ไฟล์ที่บันทึกจะมีลายน้ำแบบประเมิน — ดูที่ [การให้สิทธิ์ใช้งาน](/slides/th/python-java/licensing/). สำหรับวิธีเพิ่มเติมในการสร้างและเติมข้อมูลลงในงานนำเสนอ, ดูที่ [สร้างงานนำเสนอ](/slides/th/python-java/create-presentation/).
