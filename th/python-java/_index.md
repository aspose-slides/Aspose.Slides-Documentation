**ยินดีต้อนรับสู่ Aspose.Slides for Python via Java**

![โลโก้สินค้า Aspose.Slides for Python via Java](aspose_slides-for-python-via-java.png)

Aspose.Slides for Python via Java เป็นไลบรารีคลาสที่ช่วยให้แอปพลิเคชัน Python ของคุณอ่านและเขียนไฟล์นำเสนอ PowerPoint® ได้โดยไม่ต้องใช้ Microsoft PowerPoint®.

คุณสมบัติหลักของมันรวมถึงการจัดการข้อความ, รูปทรง, ตาราง, และแอนิเมชัน; การเพิ่มเสียงและวิดีโอลงในสไลด์; การแสดงตัวอย่างสไลด์; และการส่งออกสไลด์เป็นรูปแบบ SVG, PDF และรูปแบบอื่น ๆ.

{{% /alert %}}
