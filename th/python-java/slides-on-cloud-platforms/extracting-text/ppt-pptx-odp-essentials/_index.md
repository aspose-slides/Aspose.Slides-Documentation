## **บทนำ**

การสกัดข้อความจากการนำเสนอทำให้เนื้อหาสไลด์สามารถค้นหา, วิเคราะห์, เข้าถึงได้, และทำการแปลภาษาได้ ในแอปพลิเคชัน Python ข้อความที่สกัดได้สามารถป้อนเข้าไปในดัชนี, ระบบจัดการเอกสาร, หรือสายนำการประมวลผลภาษา ผู้ทำงานบนคลาวด์สามารถใช้กระบวนการเดียวกันกับไฟล์ที่ได้รับจากการอัปโหลดหรือที่เก็บวัตถุได้

บทความนี้อธิบายว่า PPT, PPTX, และ ODP จัดเก็บข้อความอย่างไรและความแตกต่างเหล่านั้นส่งผลต่อการสกัดอย่างไร Aspose.Slides for Python via Java รองรับการโหลดทุกสามฟอร์แมต; ดู [ฟอร์แมตไฟล์ที่รองรับ](/slides/th/python-java/supported-file-formats/)

## **การประยุกต์ใช้การสกัดข้อความอย่างเป็นรูปธรรม**

- **เวิร์กโฟลว์เอกสาร:** นำเข้าข้อมูลการนำเสนอเข้าสู่ระบบจัดการเอกสารและเชื่อมโยงกับเมตาดาทาไฟล์ต้นฉบับ
- **การทำดัชนีการค้นหา:** ทำดัชนีข้อความสไลด์พร้อมเก็บชื่อการนำเสนอและหมายเลขสไลด์สำหรับแต่ละผลลัพธ์
- **การวิเคราะห์เนื้อหา:** ระบุหัวข้อ, คำสำคัญ, และธีมที่เกิดซ้ำในคลังการนำเสนอ
- **การเข้าถึงและการแปลภาษา:** ให้ข้อความสำหรับเครื่องมือช่วยเหลือหรือกระบวนการแปล, พร้อมการตรวจสอบลำดับการอ่านและบริบทเพิ่มเติม
- **การวิเคราะห์โครงร่าง:** รวมข้อความกับตำแหน่งวัตถุเมื่อตรวจสอบโครงสร้างสไลด์หรือเตรียมการส่งออกแบบมีโครงสร้าง

## **ภาพรวมของฟอร์แมตการนำเสนอ**

### **PPT: ฟอร์แมต PowerPoint แบบเดิม**

PPT คือฟอร์แมตไบนารีที่สัมพันธ์กับ PowerPoint 97–2003 เรคคอร์ดของมันไม่สามารถประมวลผลเป็นเอกสาร XML ได้ ตัวพาร์เซอร์ต้องเข้าโครงสร้างไบนารีและความสัมพันธ์ของมันเพื่อสร้างเนื้อหาสไลด์ใหม่

ข้อความอาจปรากฏในวัตถุสไลด์, โน้ต, และคอมเมนต์ การทำงานสกัดควรกำหนดแหล่งที่มาที่จะรวมไว้, ไม่ใช่ถือว่าการนำเสนอเป็นข้อความต่อเนื่องเดียว

### **PPTX: Office Open XML**

PPTX คือแพ็กเกจ ZIP ที่บรรจุส่วน XML และทรัพยากรอื่น ๆ ข้อความสไลด์มักอยู่ใน `ppt/slides/th/slideX.xml` ภายในองค์ประกอบ `a:t` โน้ตถูกจัดเก็บในส่วนโน้ต-สไลด์แยกต่างหาก, และคอมเมนต์มีส่วนของตนเองที่เชื่อมต่อผ่านความสัมพันธ์ของแพ็กเกจ

การอ่านเฉพาะองค์ประกอบข้อความจาก XML ของสไลด์อาจพลาดเนื้อหาที่เก็บไว้ในส่วนอื่นของแพ็กเกจ อีกทั้งไม่ทำการสร้างรูปแบบหรือลำดับการอ่านใหม่ กระบวนการเต็มรูปแบบอาจต้องคำนึงถึงเลย์เอาต์, รูปร่างที่จัดกลุ่ม, ตาราง, แผนภูมิ, และส่วนที่เกี่ยวข้อง

### **ODP: การนำเสนอ OpenDocument**

ODP คือฟอร์แมตการนำเสนอ OpenDocument ที่บรรจุในแพ็กเกจ ZIP เช่นเดียวกับ PPTX แต่ใช้คำศัพท์และโครงสร้างของ OpenDocument

เนื้อหาการนำเสนอส่วนใหญ่เก็บใน `content.xml` ข้อความย่อหน้าจะใช้องค์ประกอบเช่น `text:p` พร้อมกับองค์ประกอบย่อยสำหรับสแปนและคุณลักษณะข้อความอื่น ๆ คำถาม XML ที่ออกแบบมาสำหรับ PPTX จึงไม่สามารถนำมาใช้โดยตรงกับ ODP ได้

## **ใช้โมเดลการนำเสนอทั่วไปใน Python**

คลาส [Presentation](https://reference.aspose.com/slides/th/python-java/aspose.slides/presentation/) โหลดไฟล์การนำเสนอที่รองรับเพื่อให้โค้ดแอปพลิเคชันสามารถทำงานกับสไลด์และวัตถุต่าง ๆ ได้โดยไม่ต้องสร้างพาร์เซอร์ไบนารีหรือแพ็กเกจแยกสำหรับแต่ละฟอร์แมต

ก่อนผสานการสกัดเข้าสู่ผู้ทำงานบนคลาวด์, ให้ทำตาม [การติดตั้ง](/slides/th/python-java/installation/) สำหรับการปรับใช้และข้อควรพิจารณาชีววัฏจักรของ JVM, ดู [สไลด์บนแพลตฟอร์มคลาวด์](/slides/th/python-java/slides-on-cloud-platforms/)

เก็บการตัดสินใจเหล่านี้ให้ชัดเจนในออกแบบการสกัด:

- **ขอบเขตของเนื้อหา:** กำหนดว่าจะจัดการกับข้อความสไลด์, โน้ต, คอมเมนต์, ตาราง, และป้ายชื่อแผนภูมิอย่างไร
- **ลำดับการอ่าน:** รักษาขอบเขตสไลด์และใช้ข้อมูลเลย์เอาต์เมื่อการเรียงลำดับวัตถุไม่เพียงพอ
- **ข้อความในภาพ:** ใช้กระบวนการ OCR แยกต่างหากเมื่อข้อความฝังอยู่ในภาพหน้าจอหรือสไลด์ที่สแกน
- **โครงสร้างผลลัพธ์:** เก็บตัวระบุแหล่งที่มาและเขียนข้อความด้วยการเข้ารหัสที่รองรับภาษาที่ต้องการ, เช่น UTF-8

## **สรุป**

PPT ต้องการการจัดการรูปแบบไบนารี, ขณะที่ PPTX และ ODP ใช้โครงสร้างแพ็กเกจ XML ที่แตกต่างกัน ไลบรารีการนำเสนอให้จุดเริ่มต้นร่วมสำหรับการทำงานกับฟอร์แมตเหล่านี้ใน Python การกำหนดขอบเขตเนื้อหาและลำดับการอ่านช่วยทำให้ข้อความที่ได้มีประโยชน์สำหรับการทำดัชนี, การวิเคราะห์, และการแปลภาษา

## **คำถามที่พบบ่อย**

**ฉันสามารถสกัดข้อความจาก PPT โดยการแตกไฟล์ ZIP ได้หรือไม่?**

ไม่มี. PPT ใช้โครงสร้างไบนารี วิธีการแตกไฟล์ ZIP และอ่าน XML ใช้ได้เฉพาะฟอร์แมตที่บรรจุเป็นแพ็กเกจเช่น PPTX และ ODP เท่านั้น

**โน้ตและคอมเมนต์ถูกเก็บร่วมกับข้อความสไลด์หลักใน PPTX หรือไม่?**

พวกมันใช้ส่วนแพ็กเกจแยกต่างหาก การอ่านเฉพาะ XML ของสไลด์จะไม่รวมโน้ตและคอมเมนต์โดยอัตโนมัติ

**การสกัดเป็นข้อความธรรมดาจะจับข้อความในภาพหน้าจอได้หรือไม่?**

ไม่ได้. ข้อความในภาพหน้าจอเป็นส่วนของภาพ ไม่ใช่ข้อความสไลด์ที่แก้ไขได้ จึงต้องใช้ OCR เพื่อสกัดข้อความนั้น
