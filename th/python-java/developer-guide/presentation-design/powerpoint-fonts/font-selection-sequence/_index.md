## **ภาพรวม**

เมื่อการนำเสนอถูกโหลด, เรนเดอร์ หรือแปลงเป็นรูปแบบอื่น Aspose.Slides จะตรวจสอบว่าแบบอักษรที่ใช้ในการนำเสนอมีอยู่ในระบบปฏิบัติการหรือไม่ หากแบบอักษรที่ต้องการหายไป Aspose.Slides จะเลือกแบบอักษรทดแทนที่ใกล้เคียงที่สุดกับแบบอักษรที่ PowerPoint จะใช้

Aspose.Slides จะค้นหาแบบอักษรที่เลือกในระบบปฏิบัติการก่อน หากพบแบบอักษรจะนำไปใช้ หากไม่พบจะใช้แบบอักษรทดแทนที่เหมาะสม เมื่อมีการกำหนดกฎการแทนที่แบบอักษรผ่าน [FontSubstRule](https://reference.aspose.com/slides/th/python-java/aspose.slides/fontsubstrule/) ก็จะนำกฎเหล่านั้นมาพิจารณาด้วย

คุณยังสามารถเพิ่มแบบอักษรระหว่างการทำงานของแอปพลิเคชัน, ใช้แบบอักษรที่ฝังอยู่ในงานนำเสนอ, หรือโหลดแบบอักษรภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF ได้เช่นกัน

## **การเลือกแบบอักษร**

มีกฎบางประการที่นำไปใช้กับแบบอักษรในงานนำเสนอเมื่อทำการโหลด, เรนเดอร์, หรือแปลงเป็นรูปแบบอื่น ตัวอย่างเช่น เมื่อคุณพยายามแปลงงานนำเสนอ (สไลด์) เป็นภาพ, จะมีการตรวจสอบแบบอักษรของงานนำเสนอเพื่อยืนยันว่ามีแบบอักษรที่เลือกอยู่ในระบบปฏิบัติการหรือไม่ หากพบว่าแบบอักษรหายไปจะถูกแทนที่ — ดู [การแทนที่แบบอักษร](/slides/th/python-java/font-replacement/) และ [การทดแทนแบบอักษร](/slides/th/python-java/font-substitution/)

นี่คือกระบวนการที่ Aspose.Slides ปฏิบัติตามเมื่อจัดการกับแบบอักษร:

1. Aspose.Slides ค้นหาแบบอักษรในระบบปฏิบัติการเพื่อหาแบบอักษรที่ตรงกับแบบอักษรที่เลือกในงานนำเสนอ
2. หากพบแบบอักษรที่เลือก Aspose.Slides จะใช้มัน มิฉะนั้น Aspose.Slides จะใช้แบบอักษรทดแทนที่ใกล้เคียงที่สุดกับที่ PowerPoint จะใช้
3. หากมีการตั้งค่ากฎการแทนที่แบบอักษรผ่าน [FontSubstRule](https://reference.aspose.com/slides/th/python-java/aspose.slides/fontsubstrule/) จะนำกฎเหล่านั้นมาใช้

Aspose.Slides อนุญาตให้คุณเพิ่มแบบอักษรระหว่างการทำงานของแอปพลิเคชันและใช้แบบอักษรเหล่านั้นได้ ดู [แบบอักษรแบบกำหนดเอง](/slides/th/python-java/custom-font/)

เมื่อมีการวางแบบอักษรเพิ่มเติมภายในงานนำเสนอ จะเรียกว่า [แบบอักษรฝังอยู่](/slides/th/python-java/embedded-font/)

Aspose.Slides อนุญาตให้คุณเพิ่มแบบอักษรที่ใช้ *เฉพาะ* กับเอกสารผลลัพธ์เท่านั้น ตัวอย่างเช่น หากงานนำเสนอที่คุณกำลังจะแปลงเป็น PDF ใช้แบบอักษรที่ไม่ได้ติดตั้งบนระบบหรือไม่ได้ฝังอยู่ในงานนำเสนอ คุณสามารถเพิ่มหรือโหลดแบบอักษรที่จำเป็นเป็น **แบบอักษรภายนอก** ได้

{{% alert title="Note" color="info" %}}
เราไม่ได้จัดจำหน่ายแบบอักษรใดๆ ทั้งแบบที่ต้องจ่ายเงินหรือแบบฟรี API ของเราช่วยให้คุณโหลดแบบอักษรภายนอกและฝังลงในเอกสารได้ แต่คุณต้องทำด้วยความระมัดระวังและรับผิดชอบด้วยตนเอง
{{% /alert %}}

## **คำถามที่พบบ่อย**

**ฉันจะตรวจสอบว่าแบบอักษรใดถูกใช้จริงในงานนำเสนอก่อนการแปลงได้อย่างไร?**

Aspose.Slides ให้คุณตรวจสอบแบบอักษรที่ใช้ผ่าน [font manager](https://reference.aspose.com/slides/th/python-java/aspose.slides/fontsmanager/) เพื่อให้คุณตัดสินใจว่าจะ [ฝัง](/slides/th/python-java/embedded-font/), [แทนที่](/slides/th/python-java/font-replacement/) หรือเพิ่ม [แหล่งแบบอักษรภายนอก](/slides/th/python-java/custom-font/) การทำเช่นนี้ช่วยป้องกันการทดแทนที่ไม่ต้องการระหว่างการเรนเดอร์และการส่งออก

**ฉันสามารถเพิ่มไดเรกทอรีแบบอักษรเพิ่มเติมโดยไม่ต้องติดตั้งบนระบบปฏิบัติการได้หรือไม่?**

ได้ คุณสามารถลงทะเบียน [แหล่งแบบอักษรภายนอก](/slides/th/python-java/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำสำหรับการเรนเดอร์และการส่งออก สิ่งนี้ช่วยลดการพึ่งพาแบบอักษรของระบบโฮสต์และทำให้การจัดวางคงที่

**ฉันจะป้องกันการสำรองโดยอัตโนมัติเพื่อใช้แบบอักษรที่ไม่เหมาะสมเมื่อไม่มี glyph ไหม?**

กำหนด [การแทนที่แบบอักษร](/slides/th/python-java/font-replacement/) และ [กฎการสำรองแบบอักษร](/slides/th/python-java/fallback-font/) อย่างชัดเจนล่วงหน้า โดยการวิเคราะห์แบบอักษรที่ใช้และตั้งค่าลำดับความสำคัญของแบบอักษรทดแทน คุณจะได้การพิมพ์ที่สม่ำเสมอและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด
