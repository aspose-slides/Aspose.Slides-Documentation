## **บทนำ**

ฟอนต์สำรองจะถูกใช้เมื่อฟอนต์ที่ระบุสำหรับข้อความมีอยู่ในระบบแต่ไม่มี glyph ที่ต้องการ ในกรณีนี้ Aspose.Slides สามารถใช้หนึ่งในฟอนต์สำรองที่ระบุเพื่อแทนที่ glyph ที่หายไป

## **ฟอนต์สำรอง**

Aspose.Slides อนุญาตให้คุณสร้างฟอนต์สำรอง, เพิ่มฟอนต์เหล่านั้นเข้าไปในคอลเลกชันฟอนต์สำรอง, ตั้งค่าคอลเลกชันฟอนต์สำรองสำหรับการนำเสนอบางชุด, ลบฟอนต์สำรองออกจากการนำเสนอ, ระบุกฎสำหรับการใช้ฟอนต์สำรอง, และดำเนินการอื่น ๆ ที่เกี่ยวข้อง

เพื่อทำความคุ้นเคยกับฟีเจอร์เหล่านี้, ใช้ลิงก์ต่อไปนี้:

- [สร้างฟอนต์สำรอง](/slides/th/python-java/create-fallback-font/)
- [สร้างคอลเลกชันฟอนต์สำรอง](/slides/th/python-java/create-fallback-fonts-collection/)
- [เรนเดอร์การนำเสนอด้วยฟอนต์สำรอง](/slides/th/python-java/render-presentation-with-fallback-font/)

## **คำถามที่พบบ่อย**

**ฟอนต์สำรองแตกต่างจากการแทนที่ฟอนต์อย่างไร?**

ฟอนต์สำรองจะถูกนำไปใช้แบบต่ออักขระหรือช่วง Unicode เมื่อฟอนต์หลักไม่มี glyph เฉพาะ; มันจะเติมเฉพาะอักขระที่หายไปเท่านั้น.[Substitution](/slides/th/python-java/font-substitution/) แทนที่ฟอนต์ที่หายไปหรือไม่พร้อมใช้งานสำหรับชุดข้อความหรือส่วนของข้อความทั้งหมดด้วยฟอนต์อื่น. สามารถใช้ร่วมกันได้, แต่ขอบเขตและตรรกะการเลือกจะแตกต่างกัน

**การตั้งค่าฟอนต์สำรองจะถูกบันทึกไว้ในไฟล์การนำเสนอหรือไม่?**

ไม่. การกำหนดค่าฟอนต์สำรองดำเนินการในช่วงการประมวลผล/เรนเดอร์ในไลบรารีและไม่ได้ถูกทำให้เป็นซีเรียลไลซ์ในไฟล์ PPTX. การนำเสนอจะไม่มีการเก็บกฎฟอนต์สำรองของคุณ

**ฟอนต์สำรองมีผลต่อองค์ประกอบที่สร้างโดยอ็อบเจกต์ของ PowerPoint (SmartArt, แผนภูมิ, WordArt) หรือไม่?**

ใช่. ข้อความภายในอ็อบเจกต์เหล่านี้จะผ่านไปยังไพรไลน์การเรนเดอร์เดียวกัน, ดังนั้นกฎฟอนต์สำรองเดียวกันจึงใช้กับข้อความเหล่านี้เช่นเดียวกับข้อความปกติ
