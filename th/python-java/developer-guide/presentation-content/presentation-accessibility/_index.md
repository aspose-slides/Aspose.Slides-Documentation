## **บทนำ**

การเข้าถึงในการนำเสนอทำให้ผู้ใช้เทคโนโลยีช่วยเหลือ—เช่น ตัวอ่านหน้าจอ, หน้าจอเบรลล์, หรือการนำทางด้วยแป้นพิมพ์เท่านั้น—สามารถเข้าใจและนำทางสไลด์ของคุณได้อย่างมีประสิทธิภาพเทียบเท่ากับผู้ชมที่มองเห็นและใช้เมาส์ การปฏิบัติที่ดีมุ่งเน้นที่ลำดับการอ่านที่ชัดเจน, ข้อความแทนที่มีความหมายสำหรับภาพข้อมูล, ความแตกต่างสีที่เพียงพอ, การพิมพ์ตัวอักษรที่อ่านง่าย, ข้อความลิงก์ที่อธิบาย, และหลีกเลี่ยงการสื่อความหมายด้วยสีหรือตำแหน่งเพียงอย่างเดียว เมื่อการเข้าถึงถูกวางแผนตั้งแต่เริ่มต้น ผลลัพธ์จะเป็นโครงสร้างที่สะอาดกว่า, ภาพที่สอดคล้องกันมากขึ้น, และเนื้อหาที่เข้าถึงผู้ชมทุกคนโดยไม่ต้องใช้วิธีแก้ไข

## **ทำเครื่องหมายเป็นการตกแต่ง**

ทำเครื่องหมายเป็นการตกแต่งเป็นการระบุภาพที่เป็นเพียงการประดับเท่านั้นเพื่อให้ตัวอ่านหน้าจอข้ามผ่าน ลดเสียงรบกวนและทำให้โฟกัสอยู่ที่เนื้อหาที่มีความหมาย ใช้กับพื้นหลัง, ลวดลาย, และช่องว่าง—ไม่ใช้กับแผนภูมิ, ไอคอน, หรือภาพที่สื่อข้อมูล Aspose.Slides เปิดเผยฟล็ากนี้เพื่อการตรวจจับและการตรวจสอบความถูกต้อง ทำให้สามารถตรวจสอบการเข้าถึงโดยอัตโนมัติและทำความสะอาดได้

![ทำเครื่องหมายเป็นการตกแต่ง](mark_as_decorative.png)

ตัวอย่างโค้ดต่อไปนี้แสดงวิธีตรวจสอบว่ารูปร่างถูกทำเครื่องหมายเป็นการตกแต่งหรือไม่

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import Presentation

presentation = Presentation("sample.pptx")
try:
    shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0)
    print(f"Is shape decorative: {shape.isDecorative()}")
finally:
    presentation.dispose()
```
