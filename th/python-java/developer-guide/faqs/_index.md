## **ภาพรวม**

FAQ นี้ครอบคลุมรูปแบบไฟล์ที่รองรับ, การใช้หน่วยความจำกับการนำเสนอขนาดใหญ่, ขนาดและการแสดงตัวอย่างของสไลด์, การดึงข้อความ, ขอบของตาราง, การวางภาพ, และความแตกต่างของแบบอักษรเมื่อนำเสนอแปลงเป็น PDF หรือรูปภาพ.

## **คำถามที่พบบ่อย**

### **รูปแบบไฟล์ที่รองรับ**

**Aspose.Slides for Python via Java รองรับรูปแบบไฟล์อะไรบ้าง?**

ดู [Supported File Formats](/slides/th/python-java/supported-file-formats/) สำหรับรูปแบบการนำเสนอ, เอกสาร, และรูปภาพที่รองรับ รวมถึงความสามารถในการนำเข้าและส่งออกของแต่ละรูปแบบ.

### **ข้อยกเว้น**

**ทำไมฉันถึงได้รับข้อผิดพลาด out-of-memory ขณะโหลดการนำเสนอขนาดใหญ่ที่มีภาพ? มีขนาดไฟล์จำกัดหรือไม่?**

ไม่มีเกณฑ์ขนาดไฟล์เดียวที่บ่งบอกว่าการนำเสนอจะสามารถใส่ในหน่วยความจำได้หรือไม่ ข้อกำหนดเรื่องหน่วยความจำขึ้นอยู่กับโครงสร้างของการนำเสนอ, ภาพที่ทำการแตกบีบอัด, เอฟเฟกต์, และการดำเนินการที่คุณทำ ภาพสามารถใช้หน่วยความจำมากกว่าขนาดที่บีบอัดบนดิสก์อย่างมาก.

Aspose.Slides for Python via Java ใช้เอนจิน Java ผ่าน JPype ดังนั้น heap ของ JVM ต้องมีพื้นที่เพียงพอสำหรับการประมวลผล แรมของระบบที่ใช้งานได้เพียงอย่างเดียวไม่บ่งบอกว่าหน่วยความจำที่ JVM สามารถใช้ได้เท่าใด ปล่อยการนำเสนอโดยใช้ [Presentation.dispose](https://reference.aspose.com/slides/th/python-java/aspose.slides/presentation/#dispose) เมื่อคุณเสร็จสิ้นการใช้งานสำหรับการตั้งค่า environment ดู [ข้อกำหนดของระบบ](/slides/th/python-java/system-requirements/) และ [การติดตั้ง](/slides/th/python-java/installation/).

### **การทำงานกับสไลด์**

**ฉันสามารถเปลี่ยนขนาดของสไลด์ในการนำเสนอได้หรือไม่?**

ได้. ใช้ [Presentation.getSlideSize](https://reference.aspose.com/slides/th/python-java/aspose.slides/presentation/#getslidesize) เพื่อเข้าถึงการตั้งค่าขนาดสไลด์ของการนำเสนอ จากนั้นใช้ [SlideSize.setSize](https://reference.aspose.com/slides/th/python-java/aspose.slides/slidesize/#setsize) เพื่อกำหนดมิติและเลือกว่าคอนเทนต์ที่มีอยู่จะสเกลอย่างไร.

**สไลด์ในการนำเสนอเดียวกันสามารถมีขนาดต่างกันได้หรือไม่?**

ไม่ได้. เอกสาร Microsoft PowerPoint กำหนดขนาดสไลด์ในระดับการนำเสนอ ดังนั้นสไลด์ทั้งหมดจึงใช้มิติเดียวกัน.

**ฉันสามารถดูตัวอย่างสไลด์ก่อนบันทึกการนำเสนอได้หรือไม่?**

ได้. เรนเดอร์สไลด์เป็นรูปภาพและแสดงรูปนั้นในแอปพลิเคชันของคุณ ไม่จำเป็นต้องบันทึกการนำเสนอก่อน.

### **การทำงานกับข้อความ**

**ฉันสามารถดึงข้อความทั้งหมดจากการนำเสนอได้หรือไม่?**

ได้. คลาส [SlideUtil](https://reference.aspose.com/slides/th/python-java/aspose.slides/slideutil/) มีเมธอดสำหรับดึงข้อความจากการนำเสนอและสไลด์แต่ละสไลด์.

**ทำไมขนาดย่อหน้าจึงต่างกันบน Windows และ Linux?**

ขนาดย่อหน้าขึ้นอยู่กับเมตริกของแบบอักษรที่ใช้ในการแสดงข้อความ หากแบบอักษรหายไป ตัวทดแทนอาจมีความกว้างของอักขระและความสูงของบรรทัดที่ต่างกัน ซึ่งทำให้การตัดบรรทัดและขนาดย่อหน้าต่างกัน ติดตั้งแบบอักษรเดียวกันบนทั้งสองระบบหรือโหลดไฟล์แบบอักษรเดียวกันด้วย [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/th/python-java/aspose.slides/fontsloader/#loadexternalfonts) ก่อนสร้างหรือโหลดการนำเสนอ.

### **การจัดรูปแบบและภาพ**

**ฉันสามารถตั้งค่าสีของขอบตารางได้อย่างไร?**

ใช้ [Cell.getCellFormat](https://reference.aspose.com/slides/th/python-java/aspose.slides/cell/#getcellformat) เพื่อเข้าถึงการจัดรูปแบบขอบของแต่ละเซลล์และตั้งค่าสีเติมสำหรับขอบที่เกี่ยวข้อง หากต้องการเปลี่ยนทุกขอบ ให้ประมวลผลทุกเซลล์ หากต้องการเปลี่ยนเฉพาะกรอบของตาราง ให้อัปเดตขอบที่หันออกด้านนอกของเซลล์ที่อยู่บนขอบของตารางเท่านั้น.

**หน่วยใดใช้ในการกำหนดตำแหน่งและขนาดของรูปภาพ?**

พิกัดและขนาดของรูปร่างวัดเป็นหน่วย point หนึ่งนิ้วเท่ากับ 72 point; ค่าดังกล่าวไม่ใช่พิกเซล.

### **การทำงานกับแบบอักษร**

**ทำไมแบบอักษรจึงเปลี่ยนเมื่อฉันแปลงการนำเสนอเป็น PDF หรือรูปภาพ?**

แบบอักษรที่จำเป็นอาจไม่มีในเครื่องที่ทำการแปลง ติดตั้งแบบอักษรต้นฉบับหรือใช้ [FontsLoader.loadExternalFonts](https://reference.aspose.com/slides/th/python-java/aspose.slides/fontsloader/#loadexternalfonts) เพื่อเพิ่มโฟลเดอร์ที่เก็บแบบอักษรเหล่านั้น โหลดแบบอักษรภายนอกก่อนสร้างหรือเปิดการนำเสนอ.

ตัวอย่างต่อไปนี้ลงทะเบียนโฟลเดอร์แบบอักษร เปลี่ยนเส้นทางเป็นโฟลเดอร์ที่มีไฟล์แบบอักษรของคุณอยู่แล้ว ตัวอย่างนี้สมมติสภาพแวดล้อมที่อธิบายไว้ใน [การติดตั้ง](/slides/th/python-java/installation/).

```python
import jpype
import asposeslides

if not jpype.isJVMStarted():
    jpype.startJVM()

from asposeslides.api import FontsLoader

font_folders = jpype.JArray(jpype.JString)(["path_to_a_folder_with_fonts"])
FontsLoader.loadExternalFonts(font_folders)
```

ตัวอย่างนี้ทำให้ JVM ทำงานต่อสำหรับการดำเนินการนำเสนอถัดไป สำหรับการใช้งานโน๊ตบุ๊กและข้อจำกัดอายุการทำงานของ JVM ดู [ข้อจำกัดและความแตกต่างของ API](/slides/th/python-java/limitations-and-api-differences/).
