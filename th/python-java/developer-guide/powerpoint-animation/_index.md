## **บทนำ**

ทั้งลักษณะการแสดงผลและพฤติกรรมเชิงโต้ตอบจะถูกพิจารณาเมื่อต้องสร้างงานนำเสนอ

**PowerPoint animation** มีบทบาทสำคัญในการทำให้งานนำเสด่นดูกดดึงดูดผู้ชม Aspose.Slides มีตัวเลือกที่หลากหลายสำหรับเพิ่มแอนิเมชันในงานนำเสนอ PowerPoint:

- ใช้เอฟเฟกต์แอนิเมชัน PowerPoint ประเภทต่าง ๆ กับรูปร่าง, แผนภูมิ, ตาราง, วัตถุ OLE และองค์ประกอบอื่น ๆ ของงานนำเสนอ
- ใช้หลายเอฟเฟกต์แอนิเมชัน PowerPoint บนรูปร่างเดียว
- ใช้ไทม์ไลน์แอนิเมชันเพื่อควบคุมเอฟเฟกต์แอนิเมชัน
- สร้างแอนิเมชันแบบกำหนดเอง

ใน Aspose.Slides สามารถนำเอฟเฟกต์แอนิเมชันต่าง ๆ ไปใช้กับรูปร่างได้ เนื่องจากทุกองค์ประกอบบนสไลด์ รวมถึงข้อความ, รูปภาพ, วัตถุ OLE, และตาราง ถือเป็นรูปร่าง จึงสามารถใส่เอฟเฟกต์แอนิเมชันให้กับองค์ประกอบใด ๆ บนสไลด์ได้

## **เอฟเฟกต์แอนิเมชัน**

Aspose.Slides รองรับ **เอฟเฟกต์แอนิเมชันกว่า 150 รายการ** รวมถึงเอฟเฟกต์พื้นฐานเช่น Bounce, PathFootball, และ Zoom, รวมถึงเอฟเฟกต์เฉพาะเช่น OLEObjectShow และ OLEObjectOpen คุณสามารถดูรายการเต็มได้ในคลาส [EffectType](https://reference.aspose.com/slides/th/python-java/aspose.slides/effecttype/)

นอกจากนี้ เอฟเฟกต์แอนิเมชันเหล่านี้สามารถใช้ร่วมกับพฤติกรรมต่อไปนี้ได้:

- [ColorEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/coloreffect/)
- [CommandEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/commandeffect/)
- [FilterEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/filtereffect/)
- [MotionEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/motioneffect/)
- [PropertyEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/propertyeffect/)
- [RotationEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/rotationeffect/)
- [ScaleEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/scaleeffect/)
- [SetEffect](https://reference.aspose.com/slides/th/python-java/aspose.slides/seteffect/)

## **แอนิเมชันแบบกำหนดเอง**

สำหรับตัวอย่าง Python ผ่าน Java ที่ครบถ้วนซึ่งสร้าง, ตรวจสอบ, และแก้ไขพฤติกรรมและเส้นทางการเคลื่อนที่ที่แก้ไขได้ ดูที่ [Custom Animation](/slides/th/python-java/custom-animation/)

คุณสามารถสร้าง **custom animations** ของคุณเองใน Aspose.Slides ได้ โดยการรวมพฤติกรรมหลายอย่างเข้าด้วยกันเป็นแอนิเมชันแบบกำหนดเองใหม่

[Behavior](https://reference.aspose.com/slides/th/python-java/aspose.slides/behavior/) เป็นบล็อกพื้นฐานของเอฟเฟกต์แอนิเมชัน PowerPoint รวมพฤติกรรมเพื่อปรับแต่งเอฟเฟกต์ หรือเพิ่มพฤติกรรมเพื่อขยายเอฟเฟกต์ที่กำหนดไว้ การทำซ้ำกำหนดโดยการตั้งค่าเวลา แทนการใช้พฤติกรรมทำซ้ำแยกต่างหาก

[Point](https://reference.aspose.com/slides/th/python-java/aspose.slides/point/) คือจุดที่ควรใช้พฤติกรรม

## **ไทม์ไลน์แอนิเมชัน**

[Sequence](https://reference.aspose.com/slides/th/python-java/aspose.slides/sequence/) คือคอลเลกชันของเอฟเฟกต์แอนิเมชันที่สามารถกำหนดเป้าหมายให้กับรูปร่างต่าง ๆ

[AnimationTimeLine](https://reference.aspose.com/slides/th/python-java/aspose.slides/animationtimeline/) คือชุดของ Sequence ที่ใช้บนสไลด์เฉพาะ มันเป็นเครื่องยนต์แอนิเมชันที่แนะนำใน PowerPoint 2002 ในเวอร์ชัน PowerPoint ก่อนหน้านี้ การเพิ่มเอฟเฟกต์แอนิเมชันลงในงานนำเสนอเป็นเรื่องท้าทายและต้องอาศัยวิธีแก้ไข ไทม์ไลน์ให้โมเดลวัตถุที่ชัดเจนมากขึ้นสำหรับแอนิเมชัน PowerPoint สไลด์สามารถมีไทม์ไลน์แอนิเมชันได้เพียงอันเดียว

## **แอนิเมชันเชิงโต้ตอบ**

[EffectTriggerType](https://reference.aspose.com/slides/th/python-java/aspose.slides/effecttriggertype/) ให้อนิยาศักย์การกระทำของผู้ใช้ เช่น การคลิกปุ่ม เพื่อเริ่มแอนิเมชันที่ระบุ

## **คำถามที่พบบ่อย**

**การแอนิเมชันจะคงอยู่เมื่อนำออกเป็น PDF หรือไม่?**

ไม่ PDF เป็นรูปแบบแบบคงที่ ดังนั้นแอนิเมชันและ [slide transitions](/slides/th/python-java/slide-transition/) จะไม่ทำงาน หากต้องการเคลื่อนไหว ให้ส่งออกเป็น [HTML5](/slides/th/python-java/export-to-html5/), [animated GIF](/slides/th/python-java/convert-powerpoint-to-animated-gif/), หรือ [video](/slides/th/python-java/convert-powerpoint-to-video/) แทน

**ฉันสามารถแปลงงานนำเสนอที่มีแอนิเมชันเป็นวิดีโอและควบคุมอัตราเฟรมและขนาดเฟรมได้หรือไม่?**

ได้ คุณสามารถ [render the presentation as frames](/slides/th/python-java/convert-powerpoint-to-video/) และเข้ารหัสเป็นวิดีโอ (เช่น ผ่าน ffmpeg) โดยเลือก FPS และความละเอียด แอนิเมชันและการเปลี่ยนสไลด์จะถูกเล่นขณะเรนเดอร์

**แอนิเมชันจะคงอยู่เมื่อติดทำงานกับ ODP (ไม่ใช่แค่ PPTX) หรือไม่?**

PPT, PPTX, และ ODP รองรับสำหรับ [reading](/slides/th/python-java/open-presentation/) และ [writing](/slides/th/python-java/save-presentation/) แต่ไม่ได้รับประกันว่าจะแอนิเมชันจะคงอยู่ ข้อมูลแอนิเมชันแบบกำหนดเองอาจสูญหายเมื่อแปลงเป็น ODP ดู [Custom Animation](/slides/th/python-java/custom-animation/) สำหรับตัวอย่างและแนวทางตรวจสอบความเข้ากันของรูปแบบ
