## **แพลตฟอร์มที่รองรับ**
Aspose.Slides for Python via Java เป็น API ที่ไม่มีการผูกติดกับแพลตฟอร์มใด สามารถใช้งานบนแพลตฟอร์มใดก็ได้ (Windows, Linux, MacOS ฯลฯ) ที่ติดตั้ง Python 3.7 หรือใหม่กว่า อีกข้อกำหนดคือ JDK 8 หรือใหม่กว่า.

## **รูปแบบไฟล์และการแปลง**
Aspose.Slides for Python via Java รองรับรูปแบบเอกสาร PowerPoint ส่วนใหญ่ อีกทั้งยังช่วยให้คุณส่งออกไปยังรูปแบบไฟล์ที่นิยมใช้และแชร์กันภายในองค์กร โปรดดูรายละเอียดต่อไปนี้:

|**ฟีเจอร์**|**คำอธิบาย**|
| :- | :- |
|Microsoft PowerPoint (PPT)|Aspose.Slides for Python via Java ให้การประมวลผลที่เร็วที่สุดสำหรับรูปแบบเอกสารการนำเสนอนี้.|
|PPT to PPTX conversion|Aspose.Slides for Python via Java รองรับการแปลงจาก PPT เป็น PPTX|
|Portable Document Format (PDF)|คุณสามารถส่งออกรูปแบบไฟล์ที่รองรับทั้งหมดเป็นเอกสาร Adobe Portable Document Format (PDF) ด้วยวิธีเดียว|
|XML Parser Specification (XPS)|คุณสามารถส่งออกรูปแบบไฟล์ที่รองรับทั้งหมดเป็นเอกสาร XML Parser Specification (XPS) ด้วยวิธีเดียว|
|Tagged Image File Format (TIFF)|คุณสามารถส่งออกรูปแบบไฟล์การนำเสนอที่รองรับทั้งหมดเป็น Tagged Image File Format (TIFF).|
|PPTX To HTML Conversion|Aspose.Slides for Python via Java รองรับการแปลง PresentationEx เป็นรูปแบบ HTML.|

## **การเรนเดอร์การนำเสนอ**
Aspose.Slides for Python via Java รองรับการเรนเดอร์สไลด์ในงานนำเสนอด้วยความแม่นยำสูงไปยังรูปแบบกราฟิกที่แตกต่างกัน โปรดดูรายละเอียดต่อไปนี้:

|**ฟีเจอร์**|**คำอธิบาย**|
| :- | :- |
|Java Supported Image Formats|โดยใช้ Aspose.Slides for Python via Java คุณสามารถเรนเดอร์สไลด์การนำเสนอและภาพบนสไลด์ไปยังรูปแบบกราฟิกที่รองรับโดย Java ทั้งหมด เช่น TIFF, PNG, BMP, JPEG, GIF.|
|SVG Format|Aspose.Slides for Python via Java ยังมีเมธอดในตัวที่อนุญาตให้คุณส่งออกสไลด์การนำเสนอไปยังรูปแบบ Scalable Vector Graphics (SVG).|

## **คุณลักษณะเนื้อหา**
Aspose.Slides for Python via Java ทำให้คุณสามารถเข้าถึง แก้ไข หรือสร้างรายการหรือเนื้อหาเกือบทั้งหมดของเอกสารการนำเสนอได้ โปรดดูรายละเอียดต่อไปนี้:

|**ฟีเจอร์**|**คำอธิบาย**|
| :- | :- |
|Master Slides|Master Slides กำหนดรูปแบบของสไลด์ปกติ Aspose.Slides for Python via Java ทำให้คุณสามารถเข้าถึงและแก้ไข Master Slides ของเอกสารการนำเสนอ|
|Normal Slides|ด้วย Aspose.Slides for Python via Java คุณสามารถสร้างสไลด์ใหม่หลายประเภทได้; คุณยังสามารถเข้าถึงและแก้ไขสไลด์ที่มีอยู่ในงานนำเสนอ|
|Cloning / Copying Slides|มีเมธอดในตัวที่ Aspose.Slides for Python via Java ให้มา ซึ่งอนุญาตให้คุณทำการโคลนหรือคัดลอกสไลด์ที่มีอยู่ภายในงานนำเสนอ คุณยังสามารถใช้สไลด์ที่คัดลอกและโคลนจากงานนำเสนอหนึ่งไปยังอีกงานหนึ่ง เนื่องจากสไลด์สืบทอดรูปแบบจาก master slide เมธอดโคลนในตัวจะคัดลอก master โดยอัตโนมัติเมื่อทำการโคลน|
|Managing Slides sections|เมธอดสำหรับจัดระเบียบสไลด์เป็นส่วนต่าง ๆ ภายในงานนำเสนอ|
|Place Holders and Text Holders|คุณสามารถเข้าถึง place holders และ text holders ในสไลด์ได้ นอกจากนี้คุณยังสามารถสร้างสไลด์พร้อม text holders ตั้งแต่ต้นโดยใช้เมธอดที่เหมาะสม|
|Header and Footers|Aspose.Slides for Python via Java ช่วยอำนวยความสะดวกในการจัดการ header/footer ในสไลด์|
|Notes in Slides|ด้วย Aspose.Slides for Python via Java คุณสามารถเข้าถึงและแก้ไขโน้ตที่เชื่อมโยงกับสไลด์ และยังสามารถเพิ่มโน้ตใหม่ได้|
|Finding a Shape|คุณยังสามารถค้นหา shape เฉพาะจากสไลด์ได้โดยใช้ข้อความแทน (alternative text) ที่เชื่อมโยงกับ shape นั้น|
|Backgrounds|Aspose.Slides for Python via Java ทำให้คุณทำงานกับพื้นหลังที่เชื่อมโยงกับ master หรือสไลด์ปกติในงานนำเสนอได้|
|Text Boxes|สามารถสร้าง text box ตั้งแต่ต้นได้ คุณสามารถเข้าถึง text box ที่มีอยู่แล้ว และยังสามารถแก้ไขข้อความภายในโดยไม่สูญเสียรูปแบบข้อความเดิม|
|Rectangle Shapes|คุณสามารถสร้างหรือแก้ไข rectangle shape ด้วย Aspose.Slides for Python via Java|
