บทความนี้อธิบายความสามารถในการประมวลผลงานนำเสนอของ Aspose.Slides for Python via Java สำหรับระบบปฏิบัติการและการพึ่งพาที่รองรับ ดูที่ [System Requirements](/slides/th/python-java/system-requirements/).

## **รูปแบบไฟล์และการแปลง**

Aspose.Slides for Python via Java ให้คุณแปลงระหว่างรูปแบบการนำเสนอและส่งออกการนำเสนอเป็นรูปแบบเอกสารและเว็บ ดูที่ [Supported File Formats](/slides/th/python-java/supported-file-formats/) สำหรับตารางรูปแบบที่สมบูรณ์และความแตกต่างระหว่างการโหลดการนำเสนอ, การนำเข้าข้อมูล, และการส่งออกผลลัพธ์

## **การเรนเดอร์การนำเสนอ**

Aspose.Slides for Python via Java ให้การเรนเดอร์สไลด์ความละเอียดสูงเป็นภาพราสเตอร์หรือเวกเตอร์สำหรับพรีวิวและผลลัพธ์ภาพอื่น ๆ นอกจากนี้ยังสามารถเรนเดอร์ภาพบนสไลด์ได้ สำหรับรูปแบบภาพที่รองรับและบันทึกการส่งออก ดูที่ [Supported File Formats](/slides/th/python-java/supported-file-formats/#supported-file-formats).

## **คุณลักษณะการจัดรูปแบบ**

Aspose.Slides for Python via Java ให้คุณจัดรูปแบบข้อความและ Shape บนสไลด์การนำเสนอ ดังที่อธิบายด้านล่าง:

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|การจัดรูปแบบข้อความ|<p>คุณสามารถจัดการข้อความผ่านกรอบข้อความที่เชื่อมโยงกับ Shape และจัดรูปแบบย่อหน้าและส่วนของข้อความแต่ละส่วน ตัวเลือกการจัดรูปแบบต่อไปนี้พร้อมให้ใช้:</p><p>- แบบอักษร</p><p>- ขนาดฟอนต์</p><p>- สีฟอนต์</p><p>- การไล่เฉดสีฟอนต์</p><p>- การจัดแนวย่อหน้า</p><p>- การเยื้องและแท็บของย่อหน้า</p><p>- สัญลักษณ์หัวข้อย่อยของย่อหน้า</p><p>- ทิศทางของย่อหน้า</p>|
|การจัดรูปแบบ Shape|<p>Shape เป็นองค์ประกอบพื้นฐานของสไลด์ คุณสามารถปรับคุณสมบัติเบื้องต้นต่อไปนี้ของ Shape:</p><p>- ตำแหน่ง</p><p>- ขนาด</p><p>- การหมุน</p><p>- สไตล์เส้น</p><p>- การเติม (รวมถึงการเติมแบบสีทึบ, ไล่สี, ลาย pattern, texture, และภาพ)</p><p>- ข้อความ</p><p>- รูปภาพ</p>|
