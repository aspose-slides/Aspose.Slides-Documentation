## **ภาพรวม**

Aspose.Slides for Python via Java อ่านและเขียนงานนำเสนอ PowerPoint และ OpenDocument นอกจากนี้ยังนำเข้าข้อมูล PDF และ HTML ไปยังสไลด์และส่งออกงานนำเสนอหรือสไลด์เดี่ยวเป็นรูปแบบเอกสาร เว็บ และภาพ

ตารางด้านล่างแยกความแตกต่างระหว่างการโหลดงานนำเสนอ การนำเข้าข้อมูลและการเรนเดอร์สไลด์ สำหรับภาพรวมของความสามารถในการแก้ไขและเรนเดอร์ ดูที่ [Features Overview](/slides/th/python-java/features-overview/)

## **หมายเหตุการนำเข้าและส่งออก**

- **การนำเข้า PDF และ HTML:** ใช้ [SlideCollection.addFromPdf](https://reference.aspose.com/slides/th/python-java/aspose.slides/slidecollection/#addfrompdf) หรือ [SlideCollection.addFromHtml](https://reference.aspose.com/slides/th/python-java/aspose.slides/slidecollection/#addfromhtml) เพื่อสร้างสไลด์จากเนื้อหาแหล่งที่มาและเพิ่มลงในงานนำเสนอ
- **การส่งออกงานนำเสนอ:** [SaveFormat](https://reference.aspose.com/slides/th/python-java/aspose.slides/saveformat/) แสดงฟอร์แมตการบันทึกงานนำเสนอที่มีให้เลือก รวมถึงตัวเลือกการส่งออกเป็น HTML และ HTML5 แยกต่างหาก
- **การส่งออกภาพ:** การส่งออกสไลด์เป็นภาพจะสร้างภาพที่แสดงลักษณะของสไลด์นั้น คอลัมน์ “โหลด / นำเข้า” ไม่ได้อธิบายว่าภาพสามารถแทรกลงในงานนำเสนอได้หรือไม่

## **คำถามที่พบบ่อย**

**ฉันสามารถแปลงงานนำเสนอ PPT เป็น PPTX หรือ ODP ได้ไหม?**

ใช่. PPT รองรับเป็นฟอร์แมตอินพุต และทั้ง PPTX กับ ODP รองรับเป็นฟอร์แมตเอาต์พุต ผลการแปลงขึ้นอยู่กับคุณสมบัติที่มีในฟอร์แมตปลายทาง

**การนำเข้า PDF หรือ HTML จะเปิดไฟล์ต้นฉบับเป็นไฟล์ PowerPoint หรือไม่?**

ไม่. การนำเข้าจะสร้างสไลด์จากหน้าต่าง PDF หรือเนื้อหา HTML แล้วคุณจึงสามารถบันทึกงานนำเสนอที่ได้ในฟอร์แมตงานนำเสนอที่สนับสนุน

**ฉันสามารถโหลด PNG หรือ SVG ที่ส่งออกเป็นงานนำเสนอที่แก้ไขได้หรือไม่?**

ไม่. การส่งออกเหล่านี้เป็นการแสดงลักษณะของสไลด์เท่านั้น ให้เก็บงานนำเสนอต้นฉบับไว้เมื่อคุณต้องการแก้ไขข้อความ รูปร่าง แผนภูมิ และวัตถุอื่น ๆ ในภายหลัง
