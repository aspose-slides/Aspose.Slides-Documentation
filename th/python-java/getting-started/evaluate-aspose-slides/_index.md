คุณสามารถดาวน์โหลด Aspose.Slides สำหรับ Python via Java เพื่อประเมินคุณลักษณะของมันได้ แพ็กเกจการประเมินนั้นเหมือนกับแพ็กเกจที่มีลิขสิทธิ์ เพื่อใช้โดยไม่มีข้อจำกัดการประเมิน ให้เพิ่มบรรทัดโค้ดบางบรรทัดเพื่อใช้ลิขสิทธิ์

เวอร์ชันการประเมินของ Aspose.Slides (ใช้โดยไม่มีลิขสิทธิ์) ให้ฟังก์ชันการทำงานเต็มของผลิตภัณฑ์ แต่จะใส่ลายน้ำการประเมินที่ด้านบนของเอกสารเมื่อคุณเปิดหรือบันทึกมัน การสกัดข้อความถูกจำกัดไว้ที่หนึ่งสไลด์ต่อการนำเสนอหนึ่งชุด
