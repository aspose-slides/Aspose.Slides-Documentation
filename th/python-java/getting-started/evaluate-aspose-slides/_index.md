คุณสามารถดาวน์โหลด Aspose.Slides for Python via Java เพื่อประเมินคุณลักษณะของมันได้ แพ็คเกจการประเมินมีลักษณะเหมือนกับแพ็คเกจที่มีลิขสิทธิ์ เพื่อใช้งานโดยไม่มีข้อจำกัดการประเมิน ให้เพิ่มบรรทัดโค้ดบางส่วนไปที่ [ใช้ลิขสิทธิ์](/slides/th/python-java/licensing/).

เวอร์ชันการประเมินของ Aspose.Slides (ใช้งานโดยไม่มีลิขสิทธิ์) ให้ฟังก์ชันการทำงานของผลิตภัณฑ์เต็มรูปแบบ แต่มีข้อจำกัดสองประการ:

- มันจะเพิ่มกล่องข้อความวอเตอร์มาร์กการประเมินลงในสไลด์ทุกสไลด์ของแต่ละงานนำเสนอที่บันทึก การเปิดงานนำเสนอจะไม่เพิ่มวอเตอร์มาร์ก แต่การบันทึกไฟล์ที่มีวอเตอร์มาร์กอยู่แล้วจะเพิ่มอีกหนึ่งรายการ
- ข้อความที่โค้ดของคุณอ่านจะถูกตัดให้เหลือเพียงไม่กี่ตัวอักษรแรก พร้อมด้วยข้อความแจ้งข้อจำกัดการประเมิน สิ่งนี้ใช้กับทุกสไลด์ รวมถึงข้อความที่โค้ดของคุณตั้งค่าใหม่และข้อความที่โหลดจากไฟล์ด้วย ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มที่
