**ยินดีต้อนรับสู่ Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports เป็นไลบรารีที่ออกแบบและพัฒนาโดยเฉพาะสำหรับนักพัฒนาที่ต้องการส่งออกรายงานจาก JasperReports ไปยังรูปแบบ Microsoft PowerPoint Presentation (PPT) และ Microsoft PowerPoint Show (PPS) อย่างง่ายดายในแอปพลิเคชัน Java ของพวกเขา รายการคุณลักษณะของรายงานทั้งหมดจะถูกแปลงด้วยความแม่นยำสูงสุดเป็นพรีเซนเทชัน Microsoft PowerPoint Aspose.Slides for JasperReports รวมการสนับสนุนสำหรับ JasperReports 5+.
