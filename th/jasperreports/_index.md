**ยินดีต้อนรับสู่ Aspose.Slides for JasperReports**

Aspose.Slides for JasperReports เป็นไลบรารีที่ออกแบบและพัฒนาเป็นพิเศษสำหรับนักพัฒนาที่ต้องการส่งออกรายงานจาก JasperReports ไปยังรูปแบบ Microsoft PowerPoint Presentation (PPT) และ Microsoft PowerPoint Show (PPS) อย่างง่ายดายในแอปพลิเคชัน Java ของพวกเขา คุณลักษณะทั้งหมดของรายงานจะถูกแปลงด้วยความแม่นยำสูงสุดไปยังงานนำเสนอ Microsoft PowerPoint Aspose.Slides for JasperReports รองรับ JasperReports 5+.
