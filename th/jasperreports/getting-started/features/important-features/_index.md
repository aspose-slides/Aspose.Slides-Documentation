ส่วนนี้ให้คำอธิบายโดยละเอียดของคุณลักษณะของ Aspose.Slides for JasperReports. คลิกที่ลิงก์ในตารางเพื่อเรียนรู้เพิ่มเติมเกี่ยวกับคุณลักษณะ.

|**คุณลักษณะ**|**รายละเอียด**|
| :- | :- |
|[การส่งออก PPT, PPTX, PDF และ HTML](/slides/th/jasperreports/ppt-pptx-pdf-and-html-export/)|ส่งออกรายงานเป็นงานนำเสนอ PPT และ PPTX เอกสาร PDF และไฟล์ HTML จากแอปพลิเคชันของคุณโดยไม่ต้องใช้ Microsoft PowerPoint.|
|ความแม่นยำสูงต่อการออกแบบรายงาน|รายงาน PPT และ PPTX มีเลย์เอาต์และลักษณะการแสดงผลเดียวกับ PDF และรูปแบบอื่นๆ.|
|การปรับใช้ที่ง่ายและเบา|Aspose.Slides for JasperReports เป็นโปรแกรมส่งออกของ JasperReports และ JasperServer ไปยังรูปแบบ Microsoft PowerPoint.|
|[การให้สิทธิ์ใช้งานที่ง่ายและคุ้มค่า](/slides/th/jasperreports/licensing/)|ใบอนุญาตหนึ่งใบต่อเซิร์ฟเวอร์หรือใบอนุญาตหนึ่งใบสำหรับเซิร์ฟเวอร์ทั้งหมดของคุณ.|
|[การสนับสนุนด้านเทคนิคฟรีระดับโลก](/slides/th/jasperreports/technical-support/)|การสนับสนุนด้านเทคนิคไม่จำกัดจำนวนจะถูกจัดหาโดยตรงจากนักพัฒนาที่ทำงานกับผลิตภัณฑ์.|
