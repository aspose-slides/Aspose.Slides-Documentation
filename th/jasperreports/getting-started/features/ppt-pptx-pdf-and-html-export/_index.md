{{% alert color="info" %}} 

JasperReports และ JasperServer ไม่มีความสามารถในตัวสำหรับการส่งออกรายงานเป็นงานนำเสนอ Microsoft PowerPoint แต่ด้วย Aspose.Slides for JasperReports คุณจะได้เข้าถึงรูปแบบการส่งออกเพิ่มเติม:

- งานนำเสนอ Microsoft PowerPoint (PPT)
- งานนำเสนอ Microsoft PowerPoint (PPTX)
- HTML
- PDF

{{% /alert %}} 

เพื่อสร้างเอกสารในรูปแบบเหล่านี้ Aspose.Slides for JasperReports พึ่งพาเวอร์ชันในตัวของ [Aspose.Slides for Java](https://products.aspose.com/slides/th/java/), ซึ่งเป็นไลบรารีการประมวลผลงานนำเสนอที่เป็นผู้นำตลาดจาก Aspose. Microsoft PowerPoint ไม่ได้ถูกใช้ในการสร้างเอกสารเหล่านี้.
