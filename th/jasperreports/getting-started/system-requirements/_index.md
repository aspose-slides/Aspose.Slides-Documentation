## **JasperReports**

Aspose.Slides for JasperReports ทำงานร่วมกับ JasperReports ตั้งแต่เวอร์ชัน 3.7.2 ถึง 6.16.0. ไฟล์ดาวน์โหลดมีไฟล์ jar แยกต่างหากสำหรับแต่ละช่วงเวอร์ชันสามช่วง — ดู [การติดตั้ง Aspose.Slides สำหรับ JasperReports](/slides/th/jasperreports/installing-aspose-slides-for-jasperreports/) เพื่อเลือกใช้ไฟล์ที่เหมาะสม. ไม่มีไฟล์ jar สำหรับ JasperReports 6.17.0 หรือใหม่กว่า รวมถึง JasperReports 7.

การสนับสนุน JasperReports เวอร์ชัน 2.0.3 ถึง 3.7.1 สิ้นสุดลงใน Aspose.Slides for JasperReports 17.6. เวอร์ชัน 17.5 และก่อนหน้านั้นก็สนับสนุนเวอร์ชันเหล่านั้นเช่นกัน.

## **Java**

ไฟล์ jar ถูกคอมไพล์สำหรับ Java 6 หรือใหม่กว่า ตามที่ *JDK 1.6* ในชื่อโฟลเดอร์ระบุ ดังนั้นเวอร์ชัน Java ที่คุณต้องการคือเวอร์ชันที่ JasperReports ของคุณต้องการ. กับ JasperReports 6.16.0 การส่งออกทำงานบน Java 11, 17, 21 และ 25.

## **Operating system**

ไฟล์ jar มีเพียงคลาสและทรัพยากร Java เท่านั้น ไม่มีไลบรารีเนทีฟและไม่ได้ใช้ Microsoft PowerPoint. บน Linux, JasperReports ต้องการ fontconfig และอย่างน้อยหนึ่งฟอนต์ที่ติดตั้งเพื่อเติมรายงาน.

## **JasperReports Server**

สำหรับ JasperReports Server ให้ใช้ไฟล์ jar ทั้งสองจากโฟลเดอร์ที่ตรงกับเวอร์ชัน JasperReports ที่เซิร์ฟเวอร์ของคุณทำงาน — ดู [การบูรณาการกับ JasperServer](/slides/th/jasperreports/integration-with-jasperserver/).
