## **บทนำ**

Aspose.Slides ให้เครื่องมือที่ครบถ้วนสำหรับการปรับขนาดสไลด์และอัตราส่วนในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **มาตรฐาน (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **หน้าจอกว้าง (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจคเตอร์และจอแสดงผลสมัยใหม่

ให้แน่ใจว่าการนำเสนอของคุณสม่ำเสมอตลอดโดยใช้ขนาดสไลด์และอัตราส่วนเดียวกันบนทุกสไลด์. เพื่อผลลัพธ์ที่ดีที่สุด, ควรกำหนดขนาดสไลด์ตั้งแต่ขั้นตอนเริ่มต้นของการสร้างการนำเสนอเพื่อหลีกเลี่ยงปัญหา

{{% alert color="info" title="Note" %}}
โดยค่าเริ่มต้น, การนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3.
{{% /alert %}}

หน้าจอ Notes และเอกสารประกอบมีขนาดที่แตกต่างจากสไลด์ปกติ. ดูที่ [ขนาดหน้าจอโน๊ต](/slides/th/python-net/notes-size/) เพื่อเปลี่ยนขนาดและทิศทางของพวกมัน

## **เปลี่ยนขนาดสไลด์ในการนำเสนอ**

ตัวอย่างโค้ดนี้แสดงวิธีเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย Python และ Aspose.Slides:

```py
import aspose.slides as slides

with slides.Presentation("AccessSlides.pptx") as pres:
    pres.slide_size.set_size(slides.SlideSizeType.ON_SCREEN_16X9, slides.SlideSizeScaleType.DO_NOT_SCALE)
    pres.save("pres-16x9-aspect-ratio.pptx", slides.export.SaveFormat.PPTX)
```

## **กำหนดขนาดสไลด์แบบกำหนดเอง**

หากขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ, คุณอาจต้องการใช้ขนาดสไลด์ที่เฉพาะเจาะหา. ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์เต็มขนาดจากการนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเองหรือแสดงงานนำเสนอบนประเภทหน้าจอบางอย่าง, การกำหนดขนาดสไลด์แบบกำหนดเองจะเป็นประโยชน์

ตัวอย่างโค้ดนี้แสดงวิธีใช้ Aspose.Slides for Python via .NET เพื่อกำหนดขนาดสไลด์แบบกำหนดเองสำหรับงานนำเสนอใน Python:

```py
import aspose.slides as slides

with slides.Presentation("AccessSlides.pptx") as pres:
    pres.slide_size.set_size(780, 540, slides.SlideSizeScaleType.DO_NOT_SCALE) # ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", slides.export.SaveFormat.PPTX)
```

## **จัดการเนื้อหาในสไลด์หลังการปรับขนาด**

หลังจากคุณเปลี่ยนขนาดสไลด์สำหรับงานนำเสนอ, เนื้อหาสไลด์ (เช่นรูปภาพหรือวัตถุต่าง ๆ) อาจเสียรูป. ตามค่าเริ่มต้น, วัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่. อย่างไรก็ตาม, เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ, คุณสามารถกำหนดการตั้งค่าที่บ่งบอกว่า Aspose.Slides จะจัดการกับเนื้อหาในสไลด์อย่างไร

คุณสามารถใช้การตั้งค่าใด ๆ ต่อไปนี้ตามความต้องการ:

- `DO_NOT_SCALE`

  หากคุณ **ไม่ต้องการ** ให้วัตถุบนสไลด์ถูกปรับขนาด, ใช้การตั้งค่านี้

- `ENSURE_FIT`

  หากคุณต้องการย่อขนาดสไลด์และต้องการให้ Aspose.Slides ปรับขนาดวัตถุบนสไลด์ให้พอดี (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา), ใช้การตั้งค่านี้

- `MAXIMIZE`

  หากคุณต้องการขยายขนาดสไลด์และต้องการให้ Aspose.Slides ขยายวัตถุบนสไลด์ให้สัดส่วนกับขนาดสไลด์ใหม่, ใช้การตั้งค่านี้

ตัวอย่างโค้ดนี้แสดงวิธีใช้การตั้งค่า `MAXIMIZE` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```py
import aspose.slides as slides

with slides.Presentation("AccessSlides.pptx") as pres:
   pres.slide_size.set_size(slides.SlideSizeType.LEDGER, slides.SlideSizeScaleType.MAXIMIZE)
```

## **คำถามที่พบบ่อย**

**ฉันสามารถกำหนดขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยที่ไม่ใช่นิ้ว (เช่น พอยต์หรือมิลลิเมตร) ได้หรือไม่?**

ใช่. Aspose.Slides ใช้หน่วยพอยต์ภายใน, โดย 1 พอยต์เท่ากับ 1/72 นิ้ว. คุณสามารถแปลงหน่วยใดก็ได้ (เช่นมิลลิเมตรหรือเซ็นติเมตร) เป็นพอยต์และใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์

**ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่. ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นพอยต์) พร้อมกับอัตราการเรนเดอร์ที่สูงขึ้นจะทำให้ใช้หน่วยความจำมากขึ้นและเวลาประมวลผลนานขึ้น. ควรกำหนดขนาดสไลด์ที่เป็นไปได้จริงและปรับอัตราการเรนเดอร์ตามความจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [รวมการนำเสนอ](/slides/th/python-net/merge-presentation/) เมื่อมีขนาดสไลด์ที่แตกต่างกัน — ต้องปรับขนาดการนำเสนอหนึ่งให้ตรงกับอีกอันก่อน. เมื่อเปลี่ยนขนาดสไลด์, คุณสามารถเลือกวิธีจัดการกับเนื้อหาที่มีอยู่ผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/python-net/aspose.slides/slidesizescaletype/). หลังจากปรับขนาดให้สอดคล้อง, คุณสามารถรวมสไลด์โดยคงรูปแบบไว้

**ฉันสามารถสร้างภาพย่อสำหรับรูปร่างแต่ละอันหรือพื้นที่เฉพาะของสไลด์ได้หรือไม่และภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ใช่. Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ [สไลด์ทั้งหมด]((https://reference.aspose.com/slides/th/python-net/aspose.slides/slide/get_image/)) รวมถึง [รูปร่างที่เลือก]((https://reference.aspose.com/slides/th/python-net/aspose.slides/shape/get_image/)). ภาพที่ได้จะสะท้อนขนาดและอัตราส่วนของสไลด์ปัจจุบัน, ทำให้กรอบและเรขาคณิตคงที่.
