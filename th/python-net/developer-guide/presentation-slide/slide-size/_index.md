## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรเพื่อปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงผลบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **มาตรฐาน (อัตราส่วน 4:3)**: เหมาะกับหน้าจอและอุปกรณ์เก่า
- **จอกว้าง (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจคเตอร์และหน้าจอสมัยใหม่  

รักษาความสอดคล้องตลอดงานนำเสนอของคุณโดยใช้ขนาดสไลด์และอัตราส่วนภาพเดียวกันสำหรับสไลด์ทั้งหมด เพื่อผลลัพธ์ที่ดีที่สุด ให้กำหนดขนาดสไลด์ตั้งแต่เริ่มต้นกระบวนการสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหา  

{{% alert color="primary" %}} 
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้ค่าอัตราส่วนมาตรฐาน 4:3
{{% /alert %}}

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

ตัวอย่างโค้ดนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย Python โดยใช้ Aspose.Slides:

```py
import aspose.slides as slides

with slides.Presentation(path + "AccessSlides.pptx") as pres:
    pres.slide_size.set_size(slides.SlideSizeType.ON_SCREEN16X9, slides.SlideSizeScaleType.DO_NOT_SCALE)
    pres.save("pres-4x3-aspect-ratio.pptx", slides.export.SaveFormat.PPTX)
```

## **ระบุขนาดสไลด์ที่กำหนดเอง**

หากคุณพบว่าขนาดสไลด์ทั่วไป (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจเลือกใช้ขนาดสไลด์ที่เฉพาะเจาะหรือต่างจากมาตรฐาน ตัวอย่างเช่น หากคุณต้องการพิมพ์สไลด์เต็มขนาดจากงานนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเอง หรือหากคุณต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางประเภท คุณอาจได้รับประโยชน์จากการตั้งค่าขนาดสไลด์ที่กำหนดเองสำหรับงานนำเสนอของคุณ  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้ Aspose.Slides สำหรับ Python ผ่าน .NET เพื่อระบุขนาดสไลด์ที่กำหนดเองสำหรับงานนำเสนอใน Python:

```py
import aspose.slides as slides

with slides.Presentation(path + "AccessSlides.pptx") as pres:
    pres.slide_size.set_size(780, 540, slides.SlideSizeScaleType.DO_NOT_SCALE) # ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", slides.export.SaveFormat.PPTX)
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์ของงานนำเสนอ เนื้อหาบนสไลด์ (เช่น รูปภาพหรือวัตถุต่าง ๆ) อาจถูกบิดเบือนโดยอัตโนมัติ ตามค่าเริ่มต้น วัตถุจะถูกปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตาม เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถระบุการตั้งค่าที่กำหนดว่าควรจัดการกับเนื้อหาบนสไลด์อย่างไร  

ขึ้นอยู่กับสิ่งที่คุณต้องการทำหรือบรรลุ คุณสามารถใช้การตั้งค่าใดก็ได้ต่อไปนี้:

- `DO_NOT_SCALE`

  หากคุณ **ไม่ต้องการ** ให้วัตถุบนสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `ENSURE_FIT`

  หากคุณต้องการย่อขนาดสไลด์และต้องการให้ Aspose.Slides ปรับขนาดวัตถุบนสไลด์ลงเพื่อให้ทั้งหมดพอดีบนสไลด์ (เพื่อป้องกันการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้  

- `MAXIMIZE`

  หากคุณต้องการขยายขนาดสไลด์และต้องการให้ Aspose.Slides ขยายวัตถุบนสไลด์ให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้  

ตัวอย่างโค้ดนี้แสดงวิธีการใช้การตั้งค่า `MAXIMIZE` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```py
import aspose.slides as slides

with slides.Presentation(path + "AccessSlides.pptx") as pres:
   pres.slide_size.set_size(slides.SlideSizeType.LEDGER, slides.SlideSizeScaleType.MAXIMIZE)
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งขนาดสไลด์ที่กำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น พอยท์หรือมิลลิเมตเตอร์) ได้หรือไม่?**

ใช่ Aspose.Slides ใช้พอยท์ภายในโดยที่ 1 พอยท์เท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใด ๆ (เช่น มิลลิเมตเตอร์หรือเซนติเมตร) เป็นพอยท์และใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้  

**ขนาดสไลด์ที่กำหนดเองขนาดใหญ่จะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ มิติสไลด์ที่ใหญ่ขึ้น (เป็นพอยท์) ร่วมกับสเกลการเรนเดอร์ที่สูงจะทำให้การใช้หน่วยความจำเพิ่มขึ้นและใช้เวลาประมวลผลนานขึ้น ควรกำหนดขนาดสไลด์ที่เป็นไปได้จริงและปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ตามที่ต้องการ  

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งอันแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ[รวมงานนำเสนอ](/slides/th/python-net/merge-presentation/)ขณะมีขนาดสไลด์ต่างกันได้ — ต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่งก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีการจัดการกับเนื้อหาที่มีอยู่ผ่านตัวเลือก[SlideSizeScaleType](https://reference.aspose.com/slides/th/python-net/aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้สอดคล้องกันแล้วคุณสามารถรวมสไลด์ได้โดยคงรูปแบบเดิมไว้  

**ฉันสามารถสร้างภาพย่อสำหรับรูปร่างเดี่ยวหรือส่วนของสไลด์ที่ระบุเฉพาะและภาพย่อเหล่านั้นจะเคารพขนาดสไลด์ใหม่หรือไม่?**

ใช่ Aspose.Slides สามารถสร้างภาพย่อสำหรับ[สไลด์ทั้งหมด](https://reference.aspose.com/slides/th/python-net/aspose.slides/slide/get_image/)รวมถึง[รูปร่างที่เลือก](https://reference.aspose.com/slides/th/python-net/aspose.slides/shape/get_image/)ได้ ภาพที่ได้จะสะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน ทำให้กรอบและเรขาคณิตคงที่และสอดคล้องกัน
