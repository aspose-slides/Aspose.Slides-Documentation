## **ภาพรวม**

Aspose.Slides สามารถใช้ได้ในโหมดประเมินหรือด้วยใบอนุญาตที่ถูกต้อง รุ่นประเมินให้ฟังก์ชันเดียวกับรุ่นที่มีใบอนุญาต แต่จะเพิ่มลายน้ำประเมินลงในทุกสไลด์ของแต่ละงานนำเสนอที่บันทึกและจะตัดข้อความที่โค้ดของคุณอ่านจากงานนำเสนอให้สั้นลง

## **ประเมิน Aspose.Slides**

คุณสามารถดาวน์โหลดรุ่นประเมินของ **Aspose.Slides for Python via .NET** ได้จาก [หน้าดาวน์โหลด](https://pypi.org/project/Aspose.Slides/). รุ่นประเมินให้คุณสมบัติเหมือนกับผลิตภัณฑ์ที่มีใบอนุญาต แพคเกจประเมินนั้นเหมือนกับแพคเกจที่ซื้อและจะกลายเป็นใบอนุญาตหลังจากคุณเพิ่มบรรทัดโค้ดบางบรรทัดเพื่อใช้ใบอนุญาต

เมื่อคุณพอใจกับการประเมิน **Aspose.Slides** ของคุณแล้ว คุณสามารถ [ซื้อใบอนุญาต](https://purchase.aspose.com/pricing/slides/th/python-net/). เราแนะนำให้ตรวจสอบตัวเลือกการสมัครสมาชิกที่มี หากคุณมีคำถามใด ๆ โปรดติดต่อทีมขายของ Aspose

ใบอนุญาตแต่ละใบของ Aspose จะรวมการสมัครสมาชิกหนึ่งปีพร้อมการอัปเกรดฟรีไปยังเวอร์ชันใหม่และการแก้ไขที่ปล่อยในช่วงเวลานั้น ผู้ใช้ที่มีใบอนุญาตและผู้ใช้รุ่นประเมินได้รับการสนับสนุนทางเทคนิคฟรีไม่จำกัดจำนวน

**ข้อจำกัดของรุ่นประเมิน**

* รุ่นประเมิน (เมื่อไม่ได้ใช้ใบอนุญาต) ให้ฟังก์ชันเต็มแบบเดียวกับรุ่นเต็ม แต่จะเพิ่มกล่องข้อความลายน้ำประเมินลงในทุกสไลด์ของแต่ละงานนำเสนอที่บันทึก
* ข้อความที่โค้ดของคุณอ่านจากงานนำเสนอจะถูกตัดให้เหลือเพียงไม่กี่อักขระแรก ตามด้วยประกาศเกี่ยวกับข้อจำกัดการประเมิน ส่วนข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ

## **การให้ใบอนุญาตใน Aspose.Slides**

* รุ่นประเมินจะกลายเป็นใบอนุญาตหลังจากคุณซื้อใบอนุญาตและเพิ่มบรรทัดโค้ดสองสามบรรทัดเพื่อใช้มัน
* ใบอนุญาตเป็นไฟล์ XML แบบข้อความธรรมดาที่มีรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ครอบคลุม วันหมดอายุการสมัครสมาชิก เป็นต้น
* ไฟล์ใบอนุญาตมีลายเซ็นดิจิทัล ดังนั้นคุณต้องไม่แก้ไข แม้แต่การเพิ่มบรรทัดว่างหนึ่งบรรทัดก็จะทำให้ไฟล์ใช้ไม่ได้
* Aspose.Slides for Python via .NET ค้นหาใบอนุญาตจากเส้นทางที่คุณส่งให้ หากใช้เส้นทาง relative หรือชื่อไฟล์โดยไม่มีเส้นทาง จะอ้างอิงจากไดเรกทอรีทำงานปัจจุบัน ซึ่งอาจไม่ใช่โฟลเดอร์ที่มีสคริปต์ Python ของคุณ
* เพื่อหลีกเลี่ยงข้อจำกัดของการประเมิน ให้ตั้งค่าใบอนุญาตก่อนใช้งาน Aspose.Slides คุณต้องตั้งค่าเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

## **การใช้ใบอนุญาต**

ใบอนุญาตสามารถโหลดจาก **ไฟล์** หรือ **สตรีม** ได้

{{% alert color="info" title="Note" %}}

Aspose.Slides มีคลาส [License](https://reference.aspose.com/slides/th/python-net/aspose.slides/license/) เพื่อจัดการการให้ใบอนุญาต

{{% /alert %}}

{{% alert color="warning" title="Warning" %}}

ใบอนุญาตใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับเวอร์ชัน 21.4 ขึ้นไป รุ่นก่อนหน้าใช้ระบบการให้ใบอนุญาตที่ต่างกันและจะไม่รู้จักใบอนุญาตเหล่านี้

{{% /alert %}}

### **ไฟล์**

วิธีที่ง่ายที่สุดในการตั้งค่าใบอนุญาตคือส่งเส้นทางของไฟล์ใบอนุญาตไปยังเมธอด [set_license](https://reference.aspose.com/slides/th/python-net/aspose.slides/license/set_license/) หากคุณส่งเฉพาะชื่อไฟล์เท่านั้น เช่นในตัวอย่างด้านล่าง Aspose.Slides จะค้นหาไฟล์ในไดเรกทอรีทำงานปัจจุบัน

โค้ด Python ด้านล่างแสดงวิธีตั้งค่าไฟล์ใบอนุญาต:

```py
import aspose.slides as slides

# สร้างอินสแตนซ์ของคลาส License. 
license = slides.License()

# ตั้งค่าพาธของไฟล์ใบอนุญาต.
license.set_license("Aspose.Slides.lic")
```

{{% alert color="warning" title="Warning" %}}

หากคุณวางไฟล์ใบอนุญาตในไดเรกทอรีอื่น เมื่อเรียก [License.set_license](https://reference.aspose.com/slides/th/python-net/aspose.slides/license/set_license/#str) ชื่อไฟล์ที่อยู่ท้ายเส้นทางต้องตรงกับชื่อไฟล์ใบอนุญาตของคุณ

ตัวอย่างเช่น คุณสามารถเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น *Aspose.Slides.lic.xml* แล้วในโค้ดของคุณส่งเส้นทางเต็มของไฟล์นั้น (ลงท้ายด้วย Aspose.Slides.lic.xml) ไปยังเมธอด [License.set_license](https://reference.aspose.com/slides/th/python-net/aspose.slides/license/set_license/#str)

{{% /alert %}}

### **สตรีม**

คุณสามารถโหลดใบอนุญาตจากสตรีม ตัวอย่าง Python ด้านล่างแสดงวิธีใช้ใบอนุญาตจากสตรีม:

```py
import aspose.slides as slides

# สร้างอินสแตนซ์ของคลาส License.
license = slides.License()

# ตั้งค่าใบอนุญาตจากสตรีม.
with open("Aspose.Slides.lic", "rb") as stream:
    license.set_license(stream)
```

## **การตรวจสอบใบอนุญาต**

เพื่อยืนยันว่าใบอนุญาตถูกใช้เรียบร้อยแล้ว คุณสามารถตรวจสอบได้ โค้ด Python ด้านล่างแสดงวิธีตรวจสอบใบอนุญาต:

```py
import aspose.slides as slides

license = slides.License()

license.set_license("Aspose.Slides.lic")

if license.is_licensed():
    print("License is good!")
```

## **ความปลอดภัยของเธรด**

{{% alert color="warning" title="Warning" %}}

เมธอด [License.set_license](https://reference.aspose.com/slides/th/python-net/aspose.slides/license/set_license/) ไม่ปลอดภัยต่อการทำงานหลายเธรด หากคุณต้องการเรียกใช้พร้อมกันจากหลายเธรด ให้ใช้ primitive การซิงโครไนซ์ เช่น `threading.Lock` เพื่อหลีกเลี่ยงปัญหา

{{% /alert %}}

## **คำถามที่พบบ่อย**

### ฉันสามารถใช้ใบอนุญาตในสภาพแวดล้อมที่ไม่มีการเชื่อมต่ออินเทอร์เน็ตได้หรือไม่ (ไม่มีการเข้าถึงอินเทอร์เน็ต)?

ได้. การตรวจสอบใบอนุญาตทำงานแบบออฟไลน์โดยใช้ไฟล์ใบอนุญาต ไม่ต้องเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่. ใบอนุญาตเป็นแบบถาวร: คุณสามารถใช้เวอร์ชันที่ออกก่อนวันที่สิ้นสุดการสมัครสมาชิกได้ต่อไป แต่คุณจะไม่สามารถใช้เวอร์ชันใหม่กว่าได้หากไม่ได้ต่ออายุ
