## **แพลตฟอร์มที่รองรับ**
แพลตฟอร์ม Aspose.Slides for Python via .NET สามารถใช้บน Windows x64 หรือ x86 และหลายดิสทริบิวชันของ Linux ที่ติดตั้ง Python 3.5 หรือใหม่กว่า มีความต้องการเพิ่มเติมสำหรับแพลตฟอร์ม Linux เป้าหมาย:
- ไลบรารีรันไทม์ GCC-6 (หรือใหม่กว่า)
- ขึ้นอยู่กับ .NET Core Runtime. ไม่จำเป็นต้องติดตั้ง .NET Core Runtime เอง
- สำหรับ Python 3.5-3.7: จำเป็นต้องใช้การสร้าง Python แบบ `pymalloc`. ตัวเลือกการสร้าง Python `--with-pymalloc` เปิดใช้งานโดยค่าเริ่มต้น โดยทั่วไป การสร้าง Python แบบ `pymalloc` จะมีส่วนต่อท้าย `m` ในชื่อไฟล์
- `libpython` ไลบรารี Python แบบแชร์. ตัวเลือกการสร้าง Python `--enable-shared` ปิดใช้งานโดยค่าเริ่มต้น, การแจกจ่ายบางรุ่นของ Python ไม่มีไลบรารี `libpython` แบบแชร์. สำหรับบางแพลตฟอร์ม Linux, ไลบรารี `libpython` แบบแชร์สามารถติดตั้งได้ผ่านตัวจัดการแพคเกจ, ตัวอย่างเช่น: `sudo apt-get install libpython3.7`. ปัญหาทั่วไปคือไลบรารี `libpython` ถูกติดตั้งในตำแหน่งที่ต่างจากตำแหน่งมาตรฐานของระบบสำหรับไลบรารีแบบแชร์. ปัญหานี้สามารถแก้ไขได้โดยใช้ตัวเลือกการสร้าง Python เพื่อกำหนดเส้นทางไลบรารีทางเลือกขณะคอมไพล์ Python, หรือโดยการสร้างลิงก์สัญลักษณ์ไปยังไฟล์ไลบรารี `libpython` ในตำแหน่งมาตรฐานของระบบสำหรับไลบรารีแบบแชร์. โดยทั่วไป ชื่อไฟล์ไลบรารี `libpython` แบบแชร์คือ `libpythonX.Ym.so.1.0` สำหรับ Python 3.5-3.7, หรือ `libpythonX.Y.so.1.0` สำหรับ Python 3.8 หรือใหม่กว่า (เช่น `libpython3.7m.so.1.0`, `libpython3.9.so.1.0`).

หากคุณต้องการการสนับสนุนสำหรับแพลตฟอร์มเพิ่มเติม, ค้นหาผลิตภัณฑ์ "พี่น้องคู่แฝด" อย่าง Aspose.Slides for .NET หรือ Aspose.Slides for Java.

## **คำถามที่พบบ่อย**

### ฉันต้องติดตั้ง Microsoft PowerPoint บนเซิร์ฟเวอร์/PC เพื่อให้ไลบรารีทำงานหรือไม่?
ไม่จำเป็น. PowerPoint ไม่ต้องการ; Aspose.Slides เป็นเอนจิ้นแบบสแตนด์อโลนสำหรับสร้าง, แก้ไข, แปลงและแสดงผลการนำเสนอ.

### การทำงานของมัลติโธรดเป็นอย่างไร? สามารถทำการประมวลผลแบบขนานได้หรือไม่?
ปลอดภัยที่จะประมวลผลเอกสารต่างๆ ในเธรดที่แตกต่างกัน; วัตถุ [งานนำเสนอ](https://reference.aspose.com/slides/th/python-net/aspose.slides/presentation/) เดียวกันต้องไม่ถูกใช้โดย [หลายเธรด](/slides/th/python-net/multithreading/) พร้อมกัน.

### รองรับการตั้งรหัสผ่านไฟล์และการเข้ารหัสหรือไม่?
ใช่. [คุณสามารถ](/slides/th/python-net/password-protected-presentation/) เปิดงานนำเสนอที่เข้ารหัส, ตั้งหรือลบรหัสผ่านสำหรับการเปิดและการเขียน, และตรวจสอบสถานะการป้องกัน.

### ฉันต้องใส่ใจแพ็กเกจฟอนต์ในคอนเทนเนอร์ Linux หรือไม่?
ใช่. แนะนำให้ติดตั้งแพ็กเกจฟอนต์ทั่วไปและ/หรือระบุ [ไดเรกทอรีฟอนต์](/slides/th/python-net/custom-font/) อย่างชัดเจนในแอปพลิเคชันของคุณเพื่อหลีกเลี่ยงการแทนที่ที่ไม่คาดคิด.

### มีข้อจำกัดในเวอร์ชันทดลองหรือไม่?
ใน [โหมดทดลอง](/slides/th/python-net/licensing/) จะมีการเพิ่มลายน้ำในผลลัพธ์และมีข้อจำกัดบางประการ; มี [ลายเซ็นชั่วคราว 30 วัน](https://purchase.aspose.com/temporary-license/) สำหรับการทดสอบคุณสมบัติเพ็ม.

### รองรับการนำเข้ารูปแบบไฟล์ภายนอกเข้าสู่การนำเสนอ (PDF/HTML → PPTX) หรือไม่?
ใช่. คุณสามารถเพิ่ม [หน้า PDF และเนื้อหา HTML](/slides/th/python-net/import-presentation/) ไปยังงานนำเสนอ, ทำให้เป็นสไลด์.
