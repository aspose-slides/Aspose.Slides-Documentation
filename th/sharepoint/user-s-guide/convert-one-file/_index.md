เพื่อแปลงการนำเสนอในไลบรารีเอกสาร:

1. เปิดเมนูของไฟล์ PPT หรือ PPTX (Edit Control Block ของมัน) แล้วเลือก **Convert via Aspose.Slides**. ใน SharePoint 2007 รายการเมนูจะถูกตั้งชื่อว่า **Convert with Aspose.Slides**.

   **การเลือก Convert with Aspose.Slides ในเมนูของเอกสารบน SharePoint 2007**

   ![เมนูของเอกสารในไลบรารีเอกสาร SharePoint 2007 พร้อมรายการ Convert with Aspose.Slides](convert-one-file_1.png)

2. ในหน้าการแปลง ให้เลือกรูปแบบผลลัพธ์ภายใต้ **Convert to**. หากต้องการ สามารถเปลี่ยนชื่อไฟล์ปลายทางและโฟลเดอร์ปลายทางได้.
3. คลิก **Convert**.
4. เมื่อการแปลงเสร็จสิ้น ให้คลิก **Source Library** หรือ **Destination Library** เพื่อกลับไปที่ไลบรารีเอกสาร ไฟล์ที่แปลงแล้วจะอยู่ในโฟลเดอร์ปลายทาง.

ขั้นตอนเดียวกันพร้อมภาพหน้าจอของแต่ละหน้าอยู่ใน [การแปลงเอกสาร Microsoft PowerPoint ไปเป็นรูปแบบอื่น](/slides/th/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/).
