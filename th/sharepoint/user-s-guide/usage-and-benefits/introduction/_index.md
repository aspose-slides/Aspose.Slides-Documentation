{{% alert color="info" title="Note" %}}

ไซต์ SharePoint มีวัตถุประสงค์เพื่อการทำงานร่วมกัน การสื่อสาร และการจัดเก็บเนื้อหา เพื่อสนองความต้องการทางธุรกิจเฉพาะ พวกมันช่วยให้กลุ่มบุคคลสามารถบรรลุเป้าหมายร่วมกันโดยอำนวยความสะดวกในการแบ่งปันข้อมูลและการสื่อสาร ข้อมูลส่วนใหญ่จะมีให้ในรูปแบบเว็บไซต์และเข้าถึงผ่านเว็บเบราว์เซอร์

{{% /alert %}}

## **SharePoint และ Aspose.Slides คืออะไร?**

Aspose.Slides for SharePoint เป็นโซลูชันสำหรับแปลงงานนำเสนอ Microsoft PowerPoint (PPT และ PPTX) เป็นรูปแบบอื่น ๆ ได้แก่ PDF, TIFF, XPS, HTML, SWF, ODP, PPS, PPSX, PPTM, PPSM, POTX และ POTM ช่วยให้คุณสามารถแปลงไฟล์ PowerPoint ในไซต์ SharePoint โดยไม่ต้องใช้ Microsoft PowerPoint รายการรูปแบบทั้งหมดสามารถดูได้ใน [Supported File Formats](/slides/th/sharepoint/supported-file-formats/).
