{{% alert color="info" title="Note" %}}

เมื่อ Aspose.Slides for SharePoint ถูกติดตั้งบนเซิร์ฟเวอร์ SharePoint และเปิดใช้งานสำหรับคอลเลกชันไซต์ มันจะเพิ่มรายการ **Convert via Aspose.Slides** ลงในเมนูเอกสารของไลบรารีเอกสารตามที่แสดงด้านล่าง ใน SharePoint 2007 รายการนี้มีชื่อว่า **Convert with Aspose.Slides**.

**การติดตั้ง Aspose.Slides for SharePoint จะเพิ่มรายการ Convert via Aspose.Slides ลงในเมนูเอกสาร**

![เมนูเอกสารที่มีรายการ Convert via Aspose.Slides](converting-microsoft-powerpoint-documents-into-other-formats_1.png)

{{% /alert %}}

## **แปลงการนำเสนอ**

เพื่อลงมือแปลงงานนำเสนอ Microsoft PowerPoint (PPT หรือ PPTX) จากไลบรารีเอกสารของ SharePoint:

1. เลือกงานนำเสนอ Microsoft PowerPoint ในไลบรารีเอกสาร
2. เปิดเมนูของมันและคลิก **Convert via Aspose.Slides**.

   **เมนูของไฟล์ Presentation 2 ที่แสดงรายการ Convert via Aspose.Slides**

   ![เมนูของการนำเสนอในไลบรารีเอกสารพร้อมไฮไลท์รายการ Convert via Aspose.Slides](converting-microsoft-powerpoint-documents-into-other-formats_2.png)

3. เลือกรูปแบบผลลัพธ์ภายใต้ **Convert to** หากต้องการสามารถเปลี่ยนชื่อไฟล์ผลลัพธ์และโฟลเดอร์ปลายทางได้
4. คลิก **Convert** เพื่อแปลงไฟล์.

   **หน้าการแปลงให้คุณเลือกรูปแบบผลลัพธ์ ชื่อไฟล์และปลายทาง**

   ![หน้าการแปลงพร้อมรูปแบบผลลัพธ์ ไฟล์ปลายทางและโฟลเดอร์ปลายทาง](converting-microsoft-powerpoint-documents-into-other-formats_3.png)

5. เมื่อการแปลงเสร็จสมบูรณ์ จะแสดงข้อความสำเร็จ.

   **การแปลงสำเร็จ**

   ![หน้าผลลัพธ์การแปลง](converting-microsoft-powerpoint-documents-into-other-formats_4.png)

6. คลิก **Source Library** (เพื่อไปยังโฟลเดอร์ต้นทาง) หรือ **Destination Library** (เพื่อไปยังโฟลเดอร์ที่ไฟล์ถูกบันทึกไว้).

   เอกสารที่แปลงแล้วจะปรากฏในไลบรารีเอกสาร.

   **เอกสารที่แปลงแล้วแสดงในไลบรารีที่บันทึก**

   ![ไฟล์ที่แปลงแล้วในไลบรารีเอกสาร](converting-microsoft-powerpoint-documents-into-other-formats_5.png)

{{% alert color="info" title="Note" %}}

ภาพหน้าจอเหล่านี้ถ่ายจากเวอร์ชันก่อนหน้าที่มีเพียงรูปแบบ PDF, TIFF และ XPS เท่านั้น หน้าการแปลงในปัจจุบันมีรูปแบบผลลัพธ์เพิ่มเติม; ดู [Multiple Format Support](/slides/th/sharepoint/multiple-format-support/).

{{% /alert %}}

บน SharePoint 2010 และเวอร์ชันถัดไป คุณสามารถเลือกหนึ่งหรือหลายงานนำเสนอในไลบรารีและคลิก **Convert Slides** บนแท็บริบบอน **Aspose Tools** มันจะเปิดหน้าการแปลงเดียวกัน.
