เพื่อถอนการติดตั้ง Aspose.Slides for SharePoint:

1. เรียกใช้โปรแกรมติดตั้งที่คุณใช้เพื่อติดตั้งมัน ตัวอย่างเช่น *Setup2019.exe* บน SharePoint Server 2019.
   เมื่อพบว่าเวอร์ชันเดียวกันได้ถูกติดตั้งแล้ว โปรแกรมติดตั้งจะเสนอให้ซ่อมหรือถอนการติดตั้ง หากพบเวอร์ชันที่แตกต่างกัน จะเสนอให้อัปเกรดหรือถอนการติดตั้ง.
2. เลือก **Remove** แล้วคลิก **Next** เพื่อถอนการติดตั้ง Aspose.Slides for SharePoint.

**การถอนการติดตั้ง Aspose.Slides for SharePoint**
