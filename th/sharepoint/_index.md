Aspose.Slides for SharePoint เป็นโซลูชันแบบฟาร์มสำหรับ SharePoint 2007 ถึง 2019 ที่แปลงงานนำเสนอ PowerPoint ที่จัดเก็บอยู่ในไลบรารีเอกสารบนเซิร์ฟเวอร์โดยไม่ต้องใช้ Microsoft PowerPoint และไม่ต้องเขียนโค้ด

มันแปลงไฟล์ PPT และ PPTX เป็น PDF, TIFF, XPS, HTML, SWF และ ODP, รวมถึงรูปแบบ PowerPoint PPS, PPSX, PPTM, PPSM, POTX และ POTM และบันทึกผลลัพธ์ไว้ในไลบรารีเอกสาร

## **การส่งออกครั้งแรกของคุณ**

Aspose.Slides for SharePoint ถูกติดตั้งครั้งเดียวบนฟาร์มและแล้วจะถูกใช้จากไลบรารีเอกสารใดก็ได้ที่เปิดใช้งานมัน:

1. ดาวน์โหลดไฟล์ ZIP จาก [หน้าดาวน์โหลด](https://releases.aspose.com/slides/sharepoint/) และคลายออกบนเซิร์ฟเวอร์ในฟาร์ม SharePoint ของคุณ
2. รันโปรแกรมติดตั้งที่ตรงกับเวอร์ชัน SharePoint ของคุณ: *Setup2007.exe*, *Setup2010.exe*, *Setup2013.exe*, *Setup2016.exe* หรือ *Setup2019.exe*. ใช้บัญชีที่สามารถติดตั้งและปรับใช้โซลูชัน SharePoint ได้. ยอมรับข้อตกลงใบอนุญาต, เลือกคอลเลกชันไซต์ที่จะเปิดใช้งานคุณลักษณะและให้การตั้งค่าปรับใช้โซลูชัน. แต่ละหน้าจออธิบายไว้ใน [การติดตั้ง](/slides/th/sharepoint/installing-aspose-slides-for-sharepoint/)
3. เปิดไลบรารีเอกสารในหนึ่งในคอลเลกชันไซต์เหล่านั้น, เปิดเมนูของไฟล์ PPT หรือ PPTX, แล้วเลือก **แปลงผ่าน Aspose.Slides**. ใน SharePoint 2007 รายการเมนูมีชื่อว่า **แปลงด้วย Aspose.Slides**
4. ภายใต้ **Convert to**, เลือก **PDF - Adobe Portable Document**. เปลี่ยนชื่อไฟล์และโฟลเดอร์ปลายทางหากต้องการ, แล้วคลิก **Convert**
5. เมื่อการแปลงเสร็จสิ้น, คลิก **ไลบรารีปลายทาง** เพื่อเปิดโฟลเดอร์ที่บรรจุไฟล์ PDF ใหม่

หากไม่มีใบอนุญาต, ไฟล์ที่แปลงจะมีลายน้ำการประเมิน — ดู [การออกใบอนุญาต](/slides/th/sharepoint/installing-aspose-slides-for-sharepoint-license/). สำหรับขั้นตอนเดียวกันพร้อมภาพหน้าจอ, ดู [การแปลงเอกสาร Microsoft PowerPoint เป็นรูปแบบอื่น](/slides/th/sharepoint/converting-microsoft-powerpoint-documents-into-other-formats/)
