## **บทนำ**

ใน PowerPoint 2019 Microsoft ได้เพิ่มการตั้งค่า **Always Open Read-Only** เป็นหนึ่งในตัวเลือกที่ผู้ใช้สามารถใช้เพื่อปกป้องงานนำเสนอของตน คุณอาจต้องการใช้การตั้งค่าแบบอ่าน‑อย่างเดียวนี้เพื่อปกป้องงานนำเสนอเมื่อ

- คุณต้องการป้องกันการแก้ไขโดยอุบัติเหตุและรักษาเนื้อหาให้ปลอดภัย  
- คุณต้องการแจ้งให้ผู้คนทราบว่ารุ่นที่คุณให้เป็นเวอร์ชันสุดท้ายแล้ว  

เมื่อคุณเลือกตัวเลือก **Always Open Read-Only** สำหรับงานนำเสนอ ผู้ใช้ที่เปิดงานนำจะเห็นคำแนะนำ **Read-Only** และอาจเห็นข้อความในรูปแบบต่อไปนี้: *เพื่อป้องกันการเปลี่ยนแปลงโดยไม่ตั้งใจ ผู้เขียนได้ตั้งค่าไฟล์นี้ให้เปิดแบบอ่าน‑อย่างเดียว*

คำแนะนำ **Read-Only** เป็นวิธีที่ง่ายแต่มีประสิทธิภาพในการหลีกเลี่ยงการแก้ไข เนื่องจากผู้ใช้ต้องทำขั้นตอนเพื่อเอาคำแนะนำออกก่อนจึงจะสามารถแก้ไขงานนำเสนอได้ หากคุณไม่ต้องการให้ผู้ใช้ทำการเปลี่ยนแปลงใด ๆ กับงานนำเสนอและต้องการบอกอย่างสุภาพ คำแนะนำ **Read-Only** อาจเป็นตัวเลือกที่ดีสำหรับคุณ  

> หากงานนำเสนอที่มีการป้องกัน **Read-Only** ถูกเปิดในแอปพลิเคชัน Microsoft PowerPoint รุ่นเก่าซึ่งไม่รองรับฟังก์ชันที่เพิ่งแนะนำ คำแนะนำ **Read-Only** จะถูกละเว้น (งานนำเสนอจะเปิดตามปกติ)

## **เปิดใช้โหมดอ่าน‑อย่างเดียว**

Aspose.Slides for Java เปิดให้คุณตั้งค่างานนำเสนอเป็น **Read-Only** ซึ่งหมายความว่าผู้ใช้ (หลังจากเปิดงานนำเสนอ) จะเห็นคำแนะนำ **Read-Only** ตัวอย่างโค้ดนี้แสดงวิธีตั้งค่างานนำเสนอให้เป็น **Read-Only** ใน Java ด้วย Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation();
try {
    pres.getProtectionManager().setReadOnlyRecommended(true);
    pres.save("ReadOnlyPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

{{% alert color="info" %}} 

**หมายเหตุ**: คำแนะนำ **Read-Only** มีไว้เพื่อหลีกเลี่ยงการแก้ไขหรือป้องกันผู้ใช้จากการทำการเปลี่ยนแปลงโดยบังเอิญใน PowerPoint หากบุคคลที่มีเจตนามารแก้ไขงานนำเสนอของคุณ พวกเขายังสามารถลบการตั้งค่า Read‑Only ได้อย่างง่ายดาย หากคุณต้องการป้องกันการแก้ไขโดยไม่ได้รับอนุญาตอย่างจริงจัง คุณควรใช้ [การป้องกันที่เข้มงวดกว่า ซึ่งรวมถึงการเข้ารหัสและรหัสผ่าน](https://docs.aspose.com/slides/th/java/password-protected-presentation/)

## **คำถามที่พบบ่อย**

### “Read‑Only recommended” แตกต่างจากการป้องกันด้วยรหัสผ่านเต็มรูปแบบอย่างไร?

“Read‑Only recommended” เพียงแค่แสดงคำแนะนำให้เปิดไฟล์ในโหมดอ่าน‑อย่างเดียวและสามารถข้ามได้ง่าย [การป้องกันด้วยรหัสผ่าน](/slides/th/java/password-protected-presentation/) จะจำกัดการเปิดหรือการแก้ไขและเหมาะเมื่อต้องการควบคุมความปลอดภัยจริง

### สามารถผสาน “Read‑Only recommended” กับลายน้ำเพื่อยับยั้งการแก้ไขเพิ่มเติมได้หรือไม่?

ได้ คำแนะนำนี้สามารถจับคู่กับ [ลายน้ำ](/slides/th/java/watermark/) เป็นการเตือนด้วยภาพ; ทั้งสองเป็นกลไกแยกจากกันและทำงานร่วมกันได้อย่างดี

### แมคโครหรือเครื่องมือภายนอกยังสามารถแก้ไขไฟล์ได้เมื่อเปิดใช้งานคำแนะนำหรือไม่?

ได้ คำแนะนำไม่บล็อกการเปลี่ยนแปลงโดยโปรแกรม เพื่อต้องการหลีกเลี่ยงการแก้ไขอัตโนมัติ ให้ใช้ [รหัสผ่านและการเข้ารหัส](/slides/th/java/password-protected-presentation/)

### “Read‑Only recommended” เกี่ยวข้องกับเมธอด ‘isEncrypted’ และ ‘isWriteProtected’ อย่างไร?

ทั้งสองเป็นสัญญาณที่ต่างกัน “Read‑Only recommended” เป็นการเตือนแบบอ่อนและเลือกได้; [isWriteProtected](https://reference.aspose.com/slides/th/java/com.aspose.slides/protectionmanager/#isWriteProtected--) และ [isEncrypted](https://reference.aspose.com/slides/th/java/com.aspose.slides/protectionmanager/#isEncrypted--) แสดงข้อจำกัดจริงในการเขียนหรืออ่านที่ขึ้นกับรหัสผ่านหรือการเข้ารหัส
