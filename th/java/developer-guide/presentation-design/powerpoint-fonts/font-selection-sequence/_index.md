## **ภาพรวม**

เมื่อโหลด การแสดงผล หรือแปลงงานนำเสนอเป็นรูปแบบอื่น Aspose.Slides จะตรวจสอบว่าแบบอักษรที่ใช้ในงานนำเสนอมีอยู่ในระบบปฏิบัติการหรือไม่ หากแบบอักษรที่จำเป็นหายไป Aspose.Slides จะเลือกแบบอักษรทดแทนที่ใกล้เคียงที่สุดกับแบบอักษรที่ PowerPoint จะใช้

Aspose.Slides จะค้นหาแบบอักษรที่เลือกในระบบปฏิบัติการเป็นอันดับแรก หากพบแบบอักษรนั้นจะใช้มัน หากไม่พบจะใช้แบบอักษรทดแทนที่เหมาะสม เมื่อกำหนดกฎการแทนที่แบบอักษรผ่าน `FontSubstRule` กฎเหล่านั้นก็จะถูกพิจารณาด้วย

คุณยังสามารถเพิ่มแบบอักษรในระหว่างการทำงานของแอปพลิเคชัน ใช้แบบอักษรที่ฝังอยู่ในงานนำเสนอ หรือโหลดแบบอักษรภายนอกสำหรับเอกสารผลลัพธ์เช่นไฟล์ PDF ได้

## **การเลือกแบบอักษร**

มีกฎบางอย่างที่ใช้กับแบบอักษรในงานนำเสนอเมื่อโหลด แสดงผล หรือแปลงเป็นรูปแบบอื่น ตัวอย่างเช่น เมื่อคุณพยายามแปลงงานนำเสนอ (สไลด์) เป็นรูปภาพ แบบอักษรของงานนำเสนอจะถูกตรวจสอบเพื่อยืนยันว่ามีแบบอักษรที่เลือกอยู่ในระบบปฏิบัติการหรือไม่ หากแบบอักษรถูกยืนยันว่าหายไป จะทำการแทนที่ — ดูที่ [**การแทนที่แบบอักษร**](https://docs.aspose.com/slides/th/java/font-replacement/)และ[**การทดแทนแบบอักษร**](https://docs.aspose.com/slides/th/java/font-substitution/)  

นี่คือกระบวนการที่ Aspose.Slides ทำตามเมื่อจัดการกับแบบอักษร:

1. Aspose.Slides ค้นหาแบบอักษรในระบบปฏิบัติการเพื่อหแบบอักษรที่ตรงกับแบบอักษรที่เลือกในงานนำเสนอ.  
2. หากพบแบบอักษรที่เลือก Aspose.Slides จะใช้มัน มิฉะนั้น Aspose.Slides จะใช้แบบอักษรทดแทนที่ใกล้เคียงที่สุดกับสิ่งที่ PowerPoint จะใช้.  
3. หากมีการตั้งค่ากฎการแทนที่แบบอักษรผ่าน [FontSubstRule](https://reference.aspose.com/slides/th/java/com.aspose.slides/fontsubstrule/), จะถูกนำไปใช้.  

Aspose.Slides อนุญาตให้คุณเพิ่มแบบอักษรในระหว่างการทำงานของแอปพลิเคชันและจากนั้นใช้แบบอักษรเหล่านั้น. ดูที่ [**แบบอักษรแบบกำหนดเอง**](https://docs.aspose.com/slides/th/java/custom-font/).  

เมื่อเพิ่มแบบอักษรเพิ่มเติมในงานนำเสนอ จะเรียกว่า [**Embedded fonts**](https://docs.aspose.com/slides/th/java/embedded-font/).  

Aspose.Slides อนุญาตให้คุณเพิ่มแบบอักษรที่นำไปใช้กับเอกสารผลลัพธ์ *เท่านั้น* ตัวอย่างเช่น หากงานนำเสนอที่คุณต้องการแปลงเป็น PDF มีแบบอักษรที่หายไปจากระบบและแบบอักษรที่ฝังอยู่ คุณสามารถเพิ่มหรือโหลดแบบอักษรที่จำเป็นเป็น **external fonts**.  

{{% alert title="Note" color="info" %}} 
เราไม่ได้จัดจำหน่ายแบบอักษรใด ๆ ทั้งแบบที่ต้องชำระเงินหรือแบบฟรี API ของเราช่วยให้คุณโหลดแบบอักษรภายนอกและฝังลงในเอกสารได้ แต่คุณต้องทำเช่นนั้นด้วยแบบอักษรตามดุลยพินิจและความรับผิดชอบของคุณเอง.
{{% /alert %}}

## **คำถามที่พบบ่อย**

### ฉันจะตรวจสอบว่าแบบอักษรที่ใช้จริงในงานนำเสนอคืออะไรก่อนการแปลงได้อย่างไร?

Aspose.Slides ให้คุณตรวจสอบแบบอักษรที่ใช้ผ่าน [font manager](https://reference.aspose.com/slides/th/java/com.aspose.slides/fontsmanager/), เพื่อให้คุณตัดสินใจว่าจะ [embed](/slides/th/java/embedded-font/), [replace](/slides/th/java/font-replacement/), หรือเพิ่ม [external sources](/slides/th/java/custom-font/) หรือไม่ สิ่งนี้ช่วยป้องกันการทดแทนที่ไม่ต้องการระหว่างการแสดงผลและการส่งออก.

### ฉันสามารถเพิ่มไดเรกทอรีแบบอักษรพิเศษโดยไม่ต้องติดตั้งในระบบปฏิบัติการได้หรือไม่?

ใช่ คุณสามารถลงทะเบียน [external font sources](/slides/th/java/custom-font/) เช่น โฟลเดอร์หรือสตรีมในหน่วยความจำสำหรับการแสดงผลและการส่งออก สิ่งนี้จะลบการพึ่งพาแบบอักษรของระบบโฮสต์และทำให้การจัดวางคาดเดาได้.

### ฉันจะป้องกันการสลับแบบอักษรอย่างเงียบโดยใช้แบบอักษรที่ไม่เหมาะสมเมื่อไม่มี glyph ได้อย่างไร?

กำหนด [font replacement](/slides/th/java/font-replacement/) และ [fallback rules](/slides/th/java/fallback-font/) อย่างชัดเจญล่วงหน้า โดยการวิเคราะห์แบบอักษรที่ใช้และตั้งค่าความสำคัญที่ควบคุมสำหรับการทดแทน คุณจะทำให้การพิมพ์แบบอักษรสม่ำเสมอและหลีกเลี่ยงผลลัพธ์ที่ไม่คาดคิด.
