## **การเพิ่มข้อความแบบไดนามิก**
วิธีการทั้งสองทำตามขั้นตอนต่อไปนี้:

1. สร้างการนำเสนอ
1. เพิ่มสไลด์เปล่า
1. เพิ่มกล่องข้อความ
1. ตั้งค่าข้อความบางส่วน
1. บันทึกการนำเสนอ
## **ตัวอย่างโค้ด VSTO**
