## **ภาพรวม**

Aspose.Slides for Java สามารถโหลดการนำเสนอ PowerPoint และ OpenDocument แล้วบันทึกหรือเรนเดอร์เป็นรูปแบบอื่น ๆ มากมายโดยไม่ต้องใช้ Microsoft PowerPoint, OpenOffice หรือ LibreOffice คุณสามารถแปลงไฟล์ PPT เก่าเป็น PPTX สมัยใหม่ ส่งออกการนำเสนอเป็นเอกสารแบบจัดวางคงที่เช่น PDF และ XPS, เผยแพร่สไลด์เป็น HTML หรือเรนเดอร์สไลด์เป็นไฟล์รูปภาพสำหรับพรีวิว, รูปย่อ, และการเก็บถาวร

การแปลงเอกสารส่วนใหญ่ใช้กระบวนการทั่วไปเดียวกัน: โหลดไฟล์ต้นฉบับ, เลือกรูปแบบผลลัพธ์ที่ต้องการ, และใช้ตัวเลือกเฉพาะรูปแบบเมื่อจำเป็น สำหรับรูปแบบภาพแต่ละสไลด์จะถูกเรนเดอร์แยกจากกันและบันทึกเป็นภาพแรสเตอร์หรือเวคเตอร์ บทความเฉพาะที่เชื่อมต่อด้านล่างนี้ให้รายละเอียดการดำเนินการสำหรับแต่ละกรณี

## **การแปลง PowerPoint และ OpenDocument**

Aspose.Slides for Java รองรับการแปลงจากรูปแบบการนำเสนอที่ใช้บ่อย เช่น PPT, PPTX, PPS, PPSX, POT, POTX, และ ODP API การแปลงเดียวกันใช้กับไฟล์ PowerPoint และ OpenDocument ดังนั้นกระบวนการที่บันทึกไฟล์ PPTX เป็น PDF สามารถนำไปใช้กับไฟล์ ODP ได้โดยเปลี่ยนเพียงไฟล์อินพุต

เมื่อแปลงไฟล์ ODP จำไว้ว่าการใช้งาน PowerPoint และ OpenDocument ไม่รองรับทุกการจัดวางและฟีเจอร์การฟอร์แมตในลักษณะเดียวกัน หากไฟล์ ODP ถูกสร้างใน LibreOffice หรือ OpenOffice Impress ให้ตรวจสอบผลลัพธ์และใช้ตัวเลือกที่อธิบายไว้ใน [แปลงการนำเสนอ OpenDocument](/slides/th/java/convert-openoffice-odp/) เมื่อคุณต้องการคำแนะนำเฉพาะรูปแบบ

## **การแปลง PPT ไปเป็น PPTX**

PPT คือรูปแบบไบนารี PowerPoint เก่า ในขณะที่ PPTX คือรูปแบบ Office Open XML สมัยใหม่ Aspose.Slides for Java รองรับการแปลง PPT ไปเป็น PPTX ด้วยความแม่นยำสูง พร้อมคงรักษาโครงสร้างการนำเสนอที่ซับซ้อน เช่น มาสเตอร์, เลย์เอาต์, สไลด์, แชต, รูปร่างกลุ่ม, พื้นที่เก็บข้อมูล, เฟรมข้อความ, เนื้อผ้า, และการเติมรูปภาพ

ดูรายละเอียดได้ที่ [แปลง PPT เป็น PPTX](/slides/th/java/convert-ppt-to-pptx/) และ [PPT เทียบกับ PPTX](/slides/th/java/ppt-vs-pptx/)

## **การส่งออกแบบจัดวางคงที่**

PDF, XPS, และ TIFF มีประโยชน์เมื่อผลลัพธ์ต้องการลักษณะที่เหมือนกันบนอุปกรณ์ทั้งหมดและไม่ควรถูกแก้ไขเป็นการนำเสนอ บทความเฉพาะ PDF, XPS, และ TIFF อธิบายวิธีควบคุม compliance, สไลด์ที่ซ่อน, บันทึกย่อ, คุณภาพภาพ, การบีบอัด, รูปแบบพิกเซล, และขนาดผลลัพธ์

## **การส่งออก HTML และรูปภาพ**

การส่งออก HTML และ HTML5 มีประโยชน์สำหรับการดูในเบราว์เซอร์, การเผยแพร่บนเว็บ, และการแบ่งปันแบบเบา การส่งออกรูปภาพมีประโยชน์เมื่อแต่ละสไลด์ต้องแปลงเป็นพรีวิว, รูปย่อ, หรือสินทรัพย์แรสเตอร์ ใช้บทความ PNG, JPG, และ SVG เพื่อรับคำแนะนำการเรนเดอร์เฉพาะรูปแบบ

## **คำถามที่พบบ่อย**

**ฉันต้องใช้ Microsoft PowerPoint เพื่อแปลงการนำเสนอหรือไม่?**

ไม่ Aspose.Slides for Java เป็นไลบรารีอิสระและไม่ต้องการ Microsoft PowerPoint หรือการทำงานอัตโนมัติของ Office

**ฉันสามารถแปลงหลายการนำเสนอเป็นชุดได้หรือไม่?**

ได้ โหลดแต่ละการนำเสนอ, บันทึกเป็นรูปแบบที่ต้องการ, แล้วทำลายวัตถุการนำเสนอหลังการประมวลผล เพื่อการประมวลผลขนาน ให้ใช้อินสแตนซ์การนำเสนอแยกกันและทำตามคำแนะนำของ [multithreading](/slides/th/java/multithreading/)

**ฉันสามารถส่งออกเฉพาะสไลด์ที่เลือกได้หรือไม่?**

ได้ วิธีการส่งออกหลายวิธีให้คุณระบุดัชนีสไลด์หรือเรนเดอร์สไลด์เดี่ยว ขึ้นอยู่กับรูปแบบผลลัพธ์ ดูบทความเฉพาะรูปแบบที่เกี่ยวข้อง

**ฉันสามารถรวมสไลด์ที่ซ่อนเมื่อต้องการส่งออกเป็น PDF หรือ XPS ได้หรือไม่?**

ได้ ใช้การตั้งค่าการส่งออกสไลด์ที่ซ่อนที่อธิบายไว้ในบทความ [PDF](/slides/th/java/convert-powerpoint-to-pdf/) และ [XPS](/slides/th/java/convert-powerpoint-to-xps/)

**ฉันสามารถสร้างผลลัพธ์ PDF/A ได้หรือไม่?**

ได้ มีการตั้งค่า compliance สำหรับการส่งออก PDF ดูรายละเอียดที่ [แปลง PowerPoint เป็น PDF](/slides/th/java/convert-powerpoint-to-pdf/)

**ฟอนต์จะถูกจัดการอย่างไรระหว่างการแปลง?**

Aspose.Slides สามารถใช้ฟอนต์ที่ฝังอยู่, การสำรองฟอนต์, และการแทนที่ฟอนต์ได้ ดูที่ [Embedded Font](/slides/th/java/embedded-font/), [Fallback Font](/slides/th/java/fallback-font/), และ [Font Substitution](/slides/th/java/font-substitution/)
