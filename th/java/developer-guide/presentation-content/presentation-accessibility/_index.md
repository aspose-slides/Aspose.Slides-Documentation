## **บทนำ**

ข้อความแทนภาพช่วยให้ผู้ใช้เทคโนโลยีเสริมเข้าใจความหมายของรูปภาพ แผนภูมิ และรูปร่างข้อมูลอื่น ๆ บทความนี้อธิบายวิธีอ่านและอัปเดตหัวข้อและคำอธิบายข้อความแทนภาพด้วย Aspose.Slides for Java แยกความแตกต่างระหว่างคำอธิบายการเข้าถึงและชื่อรูปร่างที่ใช้ในโค้ด และตรวจสอบว่ารูปร่างถูกทำเครื่องหมายว่าเป็นแบบประดับหรือไม่  

คุณลักษณะเหล่านี้รองรับการเข้าถึงงานพรีเซนเทชั่น แต่ไม่รับประกันความสมบูรณ์ การตรวจสอบลำดับการอ่าน ความต่างสี ความอ่านง่ายของข้อความ และข้อกำหนดการเข้าถึงอื่น ๆ ยังต้องทำการทบทวนเพิ่มเติม

## **จัดการชื่อและคำอธิบายข้อความแทนภาพ**

ใช้ข้อความแทนภาพเพื่ออธิบายความหมายของรูปภาพ แผนภูมิ และรูปร่างข้อมูลอื่น ๆ ให้กับผู้ที่ไม่สามารถมองเห็นได้ วิธีการและเนื้อหาต่อไปนี้มีวัตถุประสงค์ที่แตกต่างกัน:

| วิธีการหรือเนื้อหา | วัตถุประสงค์ |
| --- | --- |
| [getAlternativeTextTitle](https://reference.aspose.com/slides/th/java/com.aspose.slides/ishape/#getAlternativeTextTitle--) | ชื่อสั้นสำหรับคำอธิบายทางเลือก |
| [getAlternativeText](https://reference.aspose.com/slides/th/java/com.aspose.slides/ishape/#getAlternativeText--) | คำอธิบายที่มีความหมายของเนื้อหา หรือจุดประสงค์ของรูปร่างในบริบทของสไลด์ |
| [getName](https://reference.aspose.com/slides/th/java/com.aspose.slides/ishape/#getName--) | ชื่อของรูปร่าง ซึ่งโค้ดสามารถใช้เพื่อค้นหารูปร่างเฉพาะในงานพรีเซนเทชั่น |
| ข้อความที่มองเห็น | เนื้อหาที่แสดงบนสไลด์ เช่น ข้อความของรูปร่างหรือชื่อและฉลากของแผนภูมิ การอัปเดตข้อความแทนภาพจะไม่เปลี่ยนเนื้อหานี้ |

เมื่อพรีเซนเทชั่นถูกใช้ซ้ำเป็นเทมเพลต โค้ดอาจค้นหารูปร่างโดยใช้ชื่อที่คืนค่าจาก [getName](https://reference.aspose.com/slides/th/java/com.aspose.slides/ishape/#getName--) ก่อนทำการอัปเดต ชื่อนี้มีจุดประสงค์แตกต่างจากข้อความแทนภาพที่อธิบายว่าภาพที่มองเห็นสื่ออะไรให้ผู้อ่าน การค้นหาตามชื่อช่วยให้ผู้เขียนปรับปรุงหรือแปลคำอธิบายโดยไม่ต้องเปลี่ยนวิธีที่โค้ดค้นหารูปร่างได้ ชื่อสามารถแก้ไขได้และไม่ได้รับการรับประกันว่ามีความเป็นเอกลักษณ์ ดังนั้นควรตรวจสอบว่าชื่อสอดคล้องกับรูปร่างที่ต้องการ; ดูที่ [Identify and Find Shapes](/slides/th/java/shape-manipulations/#identify-and-find-shapes)

ตัวอย่างต่อไปนี้ต้องการไฟล์ `input.pptx` ที่มีภาพของทางเข้าหน่วยงานเป็นรูปร่างแรกบนสไลด์แรก ภาพนั้นไม่ควรถูกทำเครื่องหมายว่าเป็นแบบประดับ ตัวอย่างจะอ่านและพิมพ์หัวข้อและคำอธิบายข้อความแทนภาพปัจจุบัน, อัปเดตค่าทั้งสอง, แล้วบันทึกพรีเซนเทชั่นเป็น `output.pptx` ปรับคำอธิบายให้ตรงกับภาพจริงและข้อมูลที่สื่อ

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);

    System.out.println("Alternative text title: " + shape.getAlternativeTextTitle());
    System.out.println("Alternative text description: " + shape.getAlternativeText());

    shape.setAlternativeTextTitle("Office entrance");
    shape.setAlternativeText("The office entrance has a wheelchair ramp to the right of the steps.");

    presentation.save("output.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

การเพิ่มข้อความแทนภาพเพียงอย่างเดียวไม่รับประกันการเข้าถึงพรีเซนเทชั่นหรือการปฏิบัติตามมาตรฐานการเข้าถึง ควรตรวจสอบความถูกต้องและความเกี่ยวข้องของคำอธิบาย รวมทั้งตรวจสอบลำดับการอ่าน ความต่างสี ข้อความที่อ่านได้ และข้อกำหนดการเข้าถึงอื่น ๆ ภาพข้อมูลไม่ควรถูกทำเครื่องหมายว่าเป็นแบบประดับ; ส่วนต่อไปจะแสดงวิธีตรวจสอบ [isDecorative](https://reference.aspose.com/slides/th/java/com.aspose.slides/ishape/#isDecorative--)

## **ทำเครื่องหมายเป็นแบบประดับ**

ทำเครื่องหมายเป็นแบบประดับใช้กับภาพที่เป็นเพียงการตกแต่งเพื่อให้โปรแกรมอ่านหน้าจอข้ามไปเลย ลดเสียงรบกวนและให้ความสนใจอยู่กับเนื้อหาที่มีความหมาย ใช้กับพื้นหลัง ลวดลาย หรือช่องว่าง—ไม่ควรใช้กับแผนภูมิ ไอคอน หรือภาพที่สื่อข้อมูล Aspose.Slides เปิดเผยฟลักนี้เพื่อการตรวจจับและตรวจสอบอัตโนมัติในการทำความสะอาดการเข้าถึง

![Mark as Decorative](mark_as_decorative.png)

โค้ดตัวอย่างต่อไปนี้แสดงวิธีตรวจสอบว่ารูปร่างถูกทำเครื่องหมายว่าเป็นแบบประดับหรือไม่

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("sample.pptx");
try {
    IShape shape = presentation.getSlides().get_Item(0).getShapes().get_Item(0);
    System.out.println("Is shape decorative: " + shape.isDecorative());
} finally {
    presentation.dispose();
}
```

## **FAQ**

**ต้องใส่อะไรในหัวข้อและคำอธิบายข้อความแทนภาพ?**  
ใช้หัวข้อสั้นเพื่อระบุหัวข้อและใช้คำอธิบายเพื่ออธิบายข้อมูลที่ภาพสื่อในบริบทของสไลด์ สำหรับแผนภูมิ ควรอธิบายแนวโน้มหรือการเปรียบเทียบที่เกี่ยวข้อง แทนการบอกเพียงว่า “แผนภูมิ”

**ควรใช้ข้อความแทนภาพเพื่อค้นหารูปร่างในเทมเพลตหรือไม่?**  
ควรค้นหารูปร่างโดยใช้ชื่อที่คืนค่าจาก [getName](https://reference.aspose.com/slides/th/java/com.aspose.slides/ishape/#getName--) และตรวจสอบว่ามันเป็นรูปร่างที่คาดหวังว่าเป็น ข้อความแทนภาพอาจถูกแก้ไขหรือแปลซึ่งอาจทำให้โค้ดที่ค้นหาโดยคำอธิบายที่ตรงกันพังได้; ดูที่ [Identify and Find Shapes](/slides/th/java/shape-manipulations/)

**ควรทำเครื่องหมายรูปร่างว่าเป็นแบบประดับเมื่อใด?**  
ใช้ฟลักแบบประดับกับภาพที่ไม่มีข้อมูลเพิ่มเติม เช่น ลวดลายตกแต่ง ภาพและแผนภูมิที่สื่อความหมายต้องมีคำอธิบายที่เหมาะสมแทน

**การเพิ่มข้อความแทนภาพทำให้พรีเซนเทชั่นเข้าถึงได้ครบถ้วนหรือไม่?**  
ไม่ การใส่ข้อความแทนภาพครอบคลุมเพียงส่วนหนึ่งของการเข้าถึง ควรตรวจสอบลำดับการอ่าน ความต่างสี ความอ่านง่ายของข้อความ และข้อกำหนดที่เกี่ยวข้องอื่น ๆ; การตั้งค่าเหล่านี้เพียงอย่างเดียวไม่ทำให้เป็นไปตามมาตรฐาน
