## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรสำหรับปรับขนาดสไลด์และอัตราส่วนภาพในงานนำเสนอ PowerPoint ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงบนหน้าจอ  

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **Standard (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **Widescreen (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจคเตอร์และจอแสดงผลสมัยใหม่

ควรรักษาความสอดคล้องตลอดงานนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนภาพหนึ่งชุดจะใช้กับทุกสไลด์ ตั้งค่าขนาดสไลด์ตั้งแต่เริ่มสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหาในภายหลัง

{{% alert color="info" title="Note" %}}
โดยค่าเริ่มต้น งานนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วน 4:3 แบบมาตรฐาน
{{% /alert %}}

หมายเหตุและหน้าเอกสารประกอบมีขนาดแตกต่างจากสไลด์ปกติ ดูที่ [Notes Page Size](/slides/th/java/notes-size/) เพื่อเปลี่ยนขนาดและทิศทาง

## **การเปลี่ยนขนาดสไลด์ในงานนำเสนอ**

 ตัวอย่างโค้ดต่อไปนี้แสดงวิธีการเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย Java และ Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **กำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากขนาดสไลด์มาตรฐาน (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์ที่เฉพาะเจาะหรือตามต้องการ ตัวอย่างเช่น หากต้องการพิมพ์สไลด์เต็มขนาดจากงานนำเสนอบนเลย์เอาต์หน้าแบบกำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนหน้าจอประเภทเฉพาะ การตั้งค่าขนาดสไลด์แบบกำหนดเองจะช่วยให้คุณได้ผลลัพธ์ที่ต้องการ

ตัวอย่างโค้ดต่อไปนี้แสดงวิธีการใช้ Aspose.Slides for Java เพื่อกำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอด้วย Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากที่คุณเปลี่ยนขนาดสไลด์ของงานนำเสนอแล้ว เนื้อหาในสไลด์ (เช่น รูปภาพหรือออบเจ็กต์) อาจบิดเบี้ยวโดยอัตโนมัติ Aspose.Slides จะปรับขนาดออบเจ็กต์ให้พอดีกับขนาดสไลด์ใหม่โดยค่าเริ่มต้น อย่างไรก็ตามเมื่อเปลี่ยนขนาดสไลด์ คุณสามารถกำหนดค่าที่บ่งบอกว่าระบบจะจัดการกับเนื้อหาอย่างไร

ขึ้นกับเป้าหมายที่คุณต้องการ คุณสามารถใช้ค่าใดค่าหนึ่งต่อไปนี้:

- `DoNotScale`

  หากคุณ **ไม่** ต้องการให้วัตถุในสไลด์ถูกปรับขนาด ให้ใช้ค่านี้

- `EnsureFit`

  หากต้องการปรับขนาดให้สไลด์เล็กลงและต้องการให้ Aspose.Slides ปรับขนาดออบเจ็กต์ให้พอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้ค่านี้

- `Maximize`

  หากต้องการปรับขนาดให้สไลด์ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายออบเจ็กต์ให้สัดส่วนตรงกับขนาดสไลด์ใหม่ ให้ใช้ค่านี้

ตัวอย่างโค้ดต่อไปนี้แสดงวิธีใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **คำถามที่พบบ่อย**

**ฉันสามารถตั้งค่าขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยอื่นนอกจากนิ้ว (เช่น จุดหรือมิลลิเมตร) ได้หรือไม่?**

ได้ Aspose.Slides ใช้หน่วยจุดภายใน โดย 1 จุดเท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใดก็ได้ (เช่นมิลลิเมตรหรือเซนติเมตร) เป็นจุดและใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์ได้

**ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?**

ใช่ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นจุด) ร่วมกับสเกลการเรนเดอร์ที่สูงขึ้นจะทำให้หน่วยความจำใช้เพิ่มขึ้นและเวลาประมวลผลนานขึ้น ควรเลือกขนาดสไลด์ที่เป็นประโยชน์และปรับสเกลการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพผลลัพธ์ที่ต้องการ

**ฉันสามารถกำหนดขนาดสไลด์ที่ไม่มาตรฐานแล้วรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?**

คุณไม่สามารถ [merge presentations](/slides/th/java/merge-presentation/) ขณะที่สไลด์มีขนาดต่างกัน — ต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่งก่อน เมื่อเปลี่ยนขนาดสไลด์ คุณสามารถเลือกวิธีจัดการเนื้อหาเดิมได้ผ่านตัวเลือก [SlideSizeScaleType](https://reference.aspose.com/slides/th/java/com.aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้เท่ากันแล้ว คุณจึงสามารถรวมสไลด์โดยคงรูปแบบไว้ได้

**ฉันสามารถสร้างภาพย่อย (thumbnail) สำหรับรูปแบบเฉพาะหรือพื้นที่ของสไลด์ได้หรือไม่ และภาพเหล่านั้นจะคำนึงถึงขนาดสไลด์ใหม่หรือไม่?**

ได้ Aspose.Slides สามารถเรนเดอร์ภาพย่อยสำหรับ [entire slides](https://reference.aspose.com/slides/th/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-) รวมถึง [selected shapes](https://reference.aspose.com/slides/th/java/com.aspose.slides/shape/#getImage-int-float-float-) ผลลัพธ์จะสะท้อนขนาดสไลด์และอัตราส่วนภาพปัจจุบัน เพื่อให้กรอบและเรขาคณิตคงที่สม่ำเสมอ
