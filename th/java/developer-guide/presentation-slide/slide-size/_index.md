## **บทนำ**

Aspose.Slides มีเครื่องมือครบวงจรเพื่อปรับขนาดสไลด์และอัตราส่วนในงานพาวเวอร์พอยท์ ซึ่งสำคัญทั้งสำหรับการพิมพ์และการแสดงผลบนหน้าจอ

ขนาดสไลด์และอัตราส่วนที่นิยม:

- **มาตรฐาน (อัตราส่วน 4:3)**: เหมาะสำหรับหน้าจอและอุปกรณ์รุ่นเก่า
- **จอกว้าง (อัตราส่วน 16:9)**: แนะนำสำหรับโปรเจกเตอร์และจอแสดงผลสมัยใหม่

ควรใช้ขนาดสไลด์และอัตราส่วนเดียวกันตลอดงานนำเสนอ เนื่องจากขนาดสไลด์และอัตราส่วนเดียวกันจะนำไปใช้กับทุกสไลด์ เพื่อผลลัพธ์ที่ดีที่สุด ให้ตั้งค่าขนาดสไลด์ตั้งแต่ตอนเริ่มสร้างงานนำเสนอเพื่อหลีกเลี่ยงปัญหาในภายหลัง

{{% alert color="info" %}}โดยค่าเริ่มต้น การนำเสนอที่สร้างด้วย Aspose.Slides จะใช้อัตราส่วนมาตรฐาน 4:3{{% /alert %}}

## **เปลี่ยนขนาดสไลด์ในงานนำเสนอ**

โค้ดตัวอย่างนี้แสดงวิธีเปลี่ยนขนาดสไลด์ในงานนำเสนอด้วย Java และ Aspose.Slides:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres-4x3-aspect-ratio.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.OnScreen16x9, SlideSizeScaleType.DoNotScale);
    pres.save("pres-16x9-aspect-ratio.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **กำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอ**

หากขนาดสไลด์มาตรฐาน (4:3 และ 16:9) ไม่เหมาะกับงานของคุณ คุณอาจต้องการใช้ขนาดสไลด์เฉพาะตัว ตัวอย่างเช่น หากต้องการพิมพ์สไลด์ขนาดเต็มจากงานนำเสนอบนรูปแบบหน้ากระดาษที่กำหนดเอง หรือหากต้องการแสดงงานนำเสนอบนประเภทหน้าจอบางประเภท การกำหนดขนาดสไลด์แบบกำหนดเองจะเป็นประโยชน์

โค้ดตัวอย่างนี้แสดงวิธีใช้ Aspose.Slides for Java เพื่อกำหนดขนาดสไลด์แบบกำหนดเองในงานนำเสนอด้วย Java:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(780, 540, SlideSizeScaleType.DoNotScale); // ขนาดกระดาษ A4
    pres.save("pres-a4-slide-size.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```

## **จัดการเนื้อหาสไลด์หลังการปรับขนาด**

หลังจากเปลี่ยนขนาดสไลด์ของงานนำเสนอ เนื้อหาของสไลด์ (เช่น รูปภาพหรือวัตถุต่างๆ) อาจบิดเบี้ยว โดยค่าเริ่มต้นวัตถุจะปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดสไลด์ใหม่ อย่างไรก็ตามเมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ คุณสามารถระบุการตั้งค่าที่กำหนดวิธีที่ Aspose.Slides จัดการกับเนื้อหาบนสไลด์ได้

ขึ้นอยู่กับเป้าหมายของคุณ คุณสามารถใช้การตั้งค่าเหล่านี้ได้:

- `DoNotScale`

  หากคุณไม่ต้องการให้วัตถุบนสไลด์ถูกปรับขนาด ให้ใช้การตั้งค่านี้

- `EnsureFit`

  หากต้องการปรับขนาดสไลด์ให้เล็กลงและต้องการให้ Aspose.Slides ลดขนาดวัตถุบนสไลด์เพื่อให้ทั้งหมดพอดีกับสไลด์ (เพื่อหลีกเลี่ยงการสูญเสียเนื้อหา) ให้ใช้การตั้งค่านี้

- `Maximize`

  หากต้องการปรับขนาดสไลด์ให้ใหญ่ขึ้นและต้องการให้ Aspose.Slides ขยายวัตถุบนสไลด์ให้สัดส่วนกับขนาดสไลด์ใหม่ ให้ใช้การตั้งค่านี้

โค้ดตัวอย่างนี้แสดงวิธีใช้การตั้งค่า `Maximize` เมื่อเปลี่ยนขนาดสไลด์ของงานนำเสนอ:

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("pres.pptx");
try {
    pres.getSlideSize().setSize(SlideSizeType.Ledger, SlideSizeScaleType.Maximize);
} finally {
    if (pres != null) pres.dispose();
}
```

## **คำถามที่พบบ่อย**

### ฉันสามารถตั้งค่าขนาดสไลด์แบบกำหนดเองโดยใช้หน่วยที่ไม่ใช่นิ้ว (เช่น พอยต์หรือมิลลิเมตร) ได้หรือไม่?

ได้ Aspose.Slides ใช้หน่วยพอยต์ภายใน โดย 1 พอยต์เท่ากับ 1/72 นิ้ว คุณสามารถแปลงหน่วยใดก็ได้ (เช่น มิลลิเมตรหรือเซนติเมตร) เป็นพอยต์และใช้ค่าที่แปลงแล้วกำหนดความกว้างและความสูงของสไลด์

### ขนาดสไลด์แบบกำหนดเองที่ใหญ่มากจะส่งผลต่อประสิทธิภาพและการใช้หน่วยความจำระหว่างการเรนเดอร์หรือไม่?

ได้ ขนาดสไลด์ที่ใหญ่ขึ้น (เป็นพอยต์) ร่วมกับระดับการเรนเดอร์ที่สูงทำให้ใช้หน่วยความจำเพิ่มขึ้นและใช้เวลาประมวลผลนานขึ้น ควรกำหนดขนาดสไลด์ให้เป็นขนาดที่เป็นประโยชน์และปรับระดับการเรนเดอร์เฉพาะเมื่อจำเป็นเพื่อให้ได้คุณภาพที่ต้องการ

### ฉันสามารถกำหนดขนาดสไลด์ที่ไม่เป็นมาตรฐานหนึ่งแบบแล้วจึงรวมสไลด์จากงานนำเสนอที่มีขนาดต่างกันได้หรือไม่?

คุณไม่สามารถ[รวมงานนำเสนอ](/slides/th/java/merge-presentation/)ขณะที่มีขนาดสไลด์แตกต่างกัน — ก่อนอื่นต้องปรับขนาดงานนำเสนอหนึ่งให้ตรงกับอีกงานหนึ่ง เมื่อเปลี่ยนขนาดสไลด์คุณสามารถเลือกวิธีจัดการเนื้อหาที่มีอยู่ผ่านตัวเลือก[SlideSizeScaleType](https://reference.aspose.com/slides/th/java/com.aspose.slides/slidesizescaletype/) หลังจากปรับขนาดให้ตรงกันแล้วคุณสามารถรวมสไลด์โดยรักษาการจัดรูปแบบไว้ได้

### ฉันสามารถสร้างภาพย่อสำหรับรูปร่างเดี่ยวหรือบริเวณเฉพาะของสไลด์ได้หรือไม่และภาพย่อจะสอดคล้องกับขนาดสไลด์ใหม่หรือไม่?

ได้ Aspose.Slides สามารถเรนเดอร์ภาพย่อสำหรับ[สไลด์ทั้งหมด](https://reference.aspose.com/slides/th/java/com.aspose.slides/slide/#getImage-com.aspose.slides.IRenderingOptions-float-float-)รวมถึง[รูปร่างที่เลือก](https://reference.aspose.com/slides/th/java/com.aspose.slides/shape/#getImage-int-float-float-) ผลลัพธ์ภาพจะแสดงขนาดสไลด์และอัตราส่วนปัจจุบัน เพื่อให้กรอบและเรขาคณิตสอดคล้องกันอย่างสม่ำเสมอ
