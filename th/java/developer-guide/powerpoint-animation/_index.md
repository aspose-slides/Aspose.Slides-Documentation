## **บทนำ**

เนื่องจากการนำเสนอมีจุดมุ่งหมายเพื่อแสดงสิ่งใดสิ่งหนึ่ง รูปลักษณ์ภาพและพฤติกรรมเชิงโต้ตอบจึงได้รับการพิจารณาเสมอระหว่างการสร้าง

**PowerPoint animation** มีบทบาทสำคัญในการทำให้การนำเสนอดึงดูดสายตาและน่าสนใจสำหรับผู้ชม Aspose.Slides มีตัวเลือกหลากหลายเพื่อเพิ่มแอนิเมชันให้กับการนำเสนอ PowerPoint:
- ใช้เอฟเฟกต์แอนิเมชัน PowerPoint ประเภทต่างๆ กับรูปร่าง, แผนภูมิ, ตาราง, วัตถุ OLE, และองค์ประกอบการนำเสนออื่นๆ
- ใช้หลายเอฟเฟกต์แอนิเมชัน PowerPoint บนรูปร่างเดียว
- ใช้ไทม์ไลน์ของแอนิเมชันเพื่อควบคุมเอฟเฟกต์แอนิเมชัน
- สร้างแอนิเมชันแบบกำหนดเอง

In Aspose.Slides, สามารถนำเอฟเฟกต์แอนิเมชันต่างๆ ไปใช้กับรูปร่างได้ เนื่องจากทุกองค์ประกอบบนสไลด์ รวมถึงข้อความ, รูปภาพ, วัตถุ OLE, และตาราง ถูกพิจารณาเป็นรูปร่าง ดังนั้นเอฟเฟกต์แอนิเมชันจึงสามารถนำไปใช้กับองค์ประกอบใดก็ได้บนสไลด์

## **เอฟเฟกต์แอนิเมชัน**

Aspose.Slides รองรับ **150+ animation effects** รวมถึงเอฟเฟกต์พื้นฐานเช่น Bounce, PathFootball, และ Zoom รวมถึงเอฟเฟกต์เฉพาะเช่น OLEObjectShow และ OLEObjectOpen คุณสามารถดูรายการเต็มได้ในคลาส [EffectType](https://reference.aspose.com/slides/th/java/com.aspose.slides/effecttype/)

นอกจากนี้ เอฟเฟกต์แอนิเมชันเหล่านี้สามารถใช้ร่วมกับพฤติกรรมต่อไปนี้:
- [ColorEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/ColorEffect)
- [CommandEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/CommandEffect)
- [FilterEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/FilterEffect)
- [MotionEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/MotionEffect)
- [PropertyEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/PropertyEffect)
- [RotationEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/RotationEffect)
- [ScaleEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/ScaleEffect)
- [SetEffect](https://reference.aspose.com/slides/th/java/com.aspose.slides/SetEffect)

## **แอนิเมชันแบบกำหนดเอง**

สำหรับตัวอย่าง Java แบบครบถ้วนที่สร้าง, ตรวจสอบ, และแก้ไขพฤติกรรมและเส้นทางการเคลื่อนที่ที่แก้ไขได้ ดูที่ [แอนิเมชันแบบกำหนดเอง](/slides/th/java/custom-animation/).

คุณสามารถสร้าง **custom animations** ของตัวเองใน Aspose.Slides ได้ ซึ่งสามารถทำได้โดยการรวมหลายพฤติกรรมเข้าด้วยกันเป็นแอนิเมชันแบบกำหนดเองใหม่

[Behavior](https://reference.aspose.com/slides/th/java/com.aspose.slides/behavior/) เป็นบล็อกสร้างของเอฟเฟกต์แอนิเมชัน PowerPoint การรวมพฤติกรรมเพื่อปรับแต่งเอฟเฟกต์ หรือเพิ่มพฤติกรรมเพื่อขยายเอฟเฟกต์ที่กำหนดไว้ การทำซ้ำกำหนดค่าผ่านการตั้งค่าเวลาแทนการใช้พฤติกรรมทำซ้ำแยกต่างหาก

[Animation Point](https://reference.aspose.com/slides/th/java/com.aspose.slides/point/) คือจุดที่ควรนำพฤติกรรมไปใช้

## **ไทม์ไลน์แอนิเมชัน**

[Sequence](https://reference.aspose.com/slides/th/java/com.aspose.slides/sequence/) คือคอลเลกชันของเอฟเฟกต์แอนิเมชันที่สามารถกำหนดเป้าหมายให้กับรูปร่างต่างๆ

[Timeline](https://reference.aspose.com/slides/th/java/com.aspose.slides/animationtimeline/) คือชุดของ sequences ที่ใช้ในสไลด์เฉพาะ มันเป็นเอนจิ้นแอนิเมชันที่เปิดตัวใน PowerPoint 2002 ในเวอร์ชันก่อนหน้าของ PowerPoint การเพิ่มเอฟเฟกต์แอนิเมชันลงในการนำเสนอเป็นเรื่องยากและทำได้เฉพาะด้วยวิธีแก้ปัญหาต่างๆ ไทม์ไลน์ให้โมเดลวัตถุที่ชัดเจนยิ่งขึ้นสำหรับแอนิเมชัน PowerPoint สไลด์หนึ่งสามารถมีไทม์ไลน์แอนิเมชันได้เพียงหนึ่งเดียว

## **แอนิเมชันเชิงโต้ตอบ**

[Trigger](https://reference.aspose.com/slides/th/java/com.aspose.slides/effecttriggertype/) ช่วยให้คุณกำหนดการกระทำของผู้ใช้ เช่น การคลิกปุ่ม ที่จะเริ่มแอนิเมชันเฉพาะ

## **คำถามที่พบบ่อย**

**แอนิเมชันจะถูกเก็บรักษาไว้เมื่อส่งออกเป็น PDF หรือไม่?**

ไม่ PDF เป็นรูปแบบแบบคงที่ ดังนั้นแอนิเมชันและ [slide transitions](/slides/th/java/slide-transition/) จะไม่เล่น หากคุณต้องการการเคลื่อนไหว ให้ส่งออกเป็น [HTML5](/slides/th/java/export-to-html5/), [animated GIF](/slides/th/java/convert-powerpoint-to-animated-gif/), หรือ [video](/slides/th/java/convert-powerpoint-to-video/) แทน

**ฉันสามารถแปลงการนำเสนอที่มีแอนิเมชันเป็นวิดีโอและควบคุมอัตราเฟรมและขนาดเฟรมได้หรือไม่?**

ได้ คุณสามารถ [render the presentation as frames](/slides/th/java/convert-powerpoint-to-video/) แล้วเข้ารหัสเป็นวิดีโอ (เช่น ผ่าน ffmpeg) โดยเลือก FPS และความละเอียด การแอนิเมชันและการเปลี่ยนสไลด์จะถูกเล่นขณะเรนเดอร์

**แอนิเมชันจะคงอยู่เมื่อตำแหน่งทำงานกับ ODP (ไม่ใช่แค่ PPTX) หรือไม่?**

PPT, PPTX, และ ODP รองรับการ [reading](/slides/th/java/open-presentation/) และ [writing](/slides/th/java/save-presentation/) แต่ไม่ได้รับประกันว่าจะแอนิเมชันจะคงอยู่ ข้อมูลแอนิเมชันแบบกำหนดเองอาจสูญหายเมื่อแปลงเป็น ODP ดู [Custom Animation](/slides/th/java/custom-animation/) สำหรับตัวอย่างและคำแนะนำในการตรวจสอบความเข้ากันของรูปแบบ
