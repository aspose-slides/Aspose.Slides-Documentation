{{% alert color="info" title="Note" %}}

นี่เป็นหน้าประวัติศาสตร์ ซึ่งแสดงรายการข้อจำกัดและปัญหาที่ทราบอยู่ที่เผยแพร่พร้อมกับ Aspose.Slides for Java 14.4.0 และไม่ได้อธิบายเวอร์ชันปัจจุบัน สำหรับการเปลี่ยนแปลงในแต่ละเวอร์ชัน โปรดดู [release notes](https://releases.aspose.com/slides/th/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.4.0 มีการตัดสินใจใหม่สำหรับการประมวลผลเอกสาร PowerPoint มีข้อจำกัดและปัญหาที่รู้จักบางประการ ซึ่งจะถูกลบในรุ่นต่อไป:

- รูปร่างบางประเภทมีเรขาคณิตไม่ถูกต้องในไฟล์ PPT ที่ทำการซีเรียลไลซ์ (โค้ง, ลูกศรวงกลม, คำอธิบาย)
- ฟีเจอร์การจัดรูปแบบข้อความบางอย่างของ PPTX ไม่ได้รับการสนับสนุนในการซีเรียลไลซ์เป็น PPT (การกำหนดแท็บ, การเยื้องและข้อจำกัดในการจัดรูปแบบย่อหน้า)
- ข้อมูลเกี่ยวกับภาษาข้อความและการตั้งค่าการตรวจสอบตัวสะกดไม่มีอยู่ในไฟล์ PPT ที่ทำการซีเรียลไลซ์
- ฟีเจอร์ธีมของ PPTX ไม่ได้รับการสนับสนุนในการซีเรียลไลซ์เป็น PPT (เฉพาะการซีเรียลไลซ์ของรูปแบบการเติม, รูปแบบเส้นและฟอนต์)
- มีปัญหาที่รู้จักในการซีเรียลไลซ์ OLE/ActiveX จาก PPT ไปยัง PPT
- การซีเรียลไลซ์และการเรนเดอร์ WordArt ไม่ได้รับการสนับสนุน
