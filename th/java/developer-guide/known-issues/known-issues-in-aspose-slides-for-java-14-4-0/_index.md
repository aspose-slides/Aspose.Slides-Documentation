{{% alert color="info" %}} 

Aspose.Slides for Java 14.4.0 มีการตัดสินใจใหม่สำหรับการประมวลผลเอกสาร PowerPoint มีข้อจำกัดและปัญหาที่ทราบอยู่บางประการ ซึ่งจะถูกแก้ไขในรุ่นต่อไป:

- รูปทรอมบางอย่างมีเรขาคณิตไม่ถูกต้องในเอกสาร PPT ที่ทำซีเรียลไลซ์ (โค้ง, ลูกศรวงกลม, คำอธิบาย)
- ฟีเจอร์การจัดรูปแบบข้อความบางอย่างของ PPTX ไม่ได้รับการสนับสนุนในการทำซีเรียลไลซ์เป็น PPT (การจัดแท็บ, การเยื้องและข้อจำกัดของการจัดรูปแบบย่อหน้า)
- ข้อมูลเกี่ยวกับภาษาข้อความและการตั้งค่าการตรวจสอบการสะกดไม่มีอยู่ในเอกสาร PPT ที่ทำซีเรียลไลซ์
- ฟีเจอร์ธีมของ PPTX ไม่ได้รับการสนับสนุนทั้งหมดในการทำซีเรียลไลซ์เป็น PPT (มีเพียงการทำซีเรียลไลซ์ของรูปแบบการเติม, รูปแบบเส้นและแบบอักษร)
- มีปัญหาที่ทราบอยู่ในการทำซีเรียลไลซ์ OLE/ActiveX จาก PPT ไปยัง PPT
- การทำซีเรียลไลซ์และการเรนเดอร์ WordArt ไม่ได้รับการสนับสนุน
