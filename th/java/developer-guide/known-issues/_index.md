## **ภาพรวม**

ส่วนนี้ไม่ได้มีรายการปัญหาเปิดในเวอร์ชันปัจจุบัน แต่มีสามหน้า:

- [ตัวยึดตัวอย่างวัตถุเมื่อเพิ่ม OleObjectFrame](/slides/th/java/object-preview-issue-when-adding-oleobjectframe/) อธิบายว่าทำไมวัตถุ OLE ที่เพิ่มด้วย Aspose.Slides จะแสดงภาพ “EMBEDDED OLE OBJECT” จนกว่าตัวอย่างจะอัปเดตและวิธีตั้งค่าตัวอย่างของคุณเอง นี่เป็นพฤติกรรมตามการออกแบบของเวอร์ชันปัจจุบัน
- [ปัญหาที่ทราบใน Aspose.Slides for Java 14.3.0 (Historical)](/slides/th/java/known-issues-in-aspose-slides-for-java-14-3-0/) และ [ปัญหาที่ทราบใน Aspose.Slides for Java 14.4.0 (Historical)](/slides/th/java/known-issues-in-aspose-slides-for-java-14-4-0/) เป็นรายการที่เผยแพร่พร้อมเวอร์ชันเหล่านั้นเพื่อการอ้างอิง

สำหรับการเปลี่ยนแปลงและการแก้ไขในแต่ละเวอร์ชัน ดู [บันทึกการเปิดตัว](https://releases.aspose.com/slides/th/java/release-notes/). ฟิลด์เมตาดาต้าที่ Aspose.Slides เขียนด้วยค่าคงที่ถูกอธิบายใน [ข้อจำกัดเมตาดาต้าผลลัพธ์](/slides/th/java/api-limitations/). เพื่อตรวจสอบว่าปัญหาเป็นที่ทราบแล้วหรือเพื่อรายงานปัญหา ให้ใช้ [ฟอรั่มสนับสนุน](https://forum.aspose.com/c/slides/th/11).
