{{% alert color="info" title="Note" %}}

นี่คือหน้าประวัติศาสตร์ ซึ่งแสดงรายการปัญหาที่ทราบและเผยแพร่กับ Aspose.Slides for Java 14.3.0 และไม่ได้อธิบายเวอร์ชันปัจจุบัน สำหรับการเปลี่ยนแปลงในแต่ละเวอร์ชัน ให้ดู [release notes](https://releases.aspose.com/slides/th/java/release-notes/).

{{% /alert %}}

Aspose.Slides for Java 14.3.0 (14.4.0) ให้การนำเสนอการทำงานของ PPT ด้วยการนำไปใช้ใหม่อย่างสมบูรณ์ มีการปรับปรุงหลายอย่าง รวมถึงการแปลงบางส่วนจาก PPTX ไปเป็น PPT แต่ยังมีฟีเจอร์บางอย่างที่ยังไม่ถูกนำมาใช้:

- รูปร่างบางประเภทมีรูปทรงผิดพลาดในไฟล์ PPT ที่ถูกทำซีเรียลไลซ์ (Call outs)
- ฟีเจอร์การจัดรูปแบบข้อความของ PPTX ไม่ได้รับการสนับสนุนทั้งหมดในกระบวนการซีเรียลไลซ์ PPT
- ข้อมูลเกี่ยวกับภาษาข้อความและการตั้งค่าการตรวจสอบการสะกดไม่ปรากฏในไฟล์ PPT ที่ถูกทำซีเรียลไลซ์
- ฟีเจอร์ของธีม PPTX ไม่ได้รับการสนับสนุนทั้งหมดในกระบวนการซีเรียลไลซ์ PPT

**มีความแตกต่างบางประการเมื่อเทียบกับ Aspose.Slides for Java 8.6.0:**

- มีปัญหาที่ทราบในการซีเรียลไลซ์ OLE/ActiveX PPT ไปเป็น PPT

**มีความแตกต่างบางประการเมื่อเทียบกับ Aspose.Slides for .NET 14.3.0:**

- การพิมพ์งานนำเสนอยังไม่มีให้บริการใน Aspose.Slides for Java
