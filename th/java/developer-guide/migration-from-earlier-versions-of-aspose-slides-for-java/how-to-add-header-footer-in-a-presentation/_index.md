{{% alert color="info" %}} 

ได้เปิดตัว [Aspose.Slides for Java API](https://docs.aspose.com/slides/th/java/) ใหม่ และตอนนี้ผลิตภัณฑ์เดียวนี้รองรับความสามารถในการสร้างเอกสาร PowerPoint ตั้งแต่เริ่มต้นและแก้ไขเอกสารที่มีอยู่แล้ว

{{% /alert %}} 
## **การสนับสนุนโค้ดเก่า**
เพื่อใช้โค้ดที่พัฒนาด้วย Aspose.Slides for Java เวอร์ชันก่อนหน้า 13.x คุณจำเป็นต้องทำการเปลี่ยนแปลงเล็กน้อยในโค้ดของคุณและโค้ดจะทำงานเช่นเดิม ทั้งคลาสที่เคยอยู่ใน Aspose.Slides for Java เดิมภายใต้เนมสเปซ Aspose.Slide และ Aspose.Slides.Pptx ตอนนี้ถูกรวมเป็นเนมสเปซ Aspose.Slides เดียวกัน โปรดดูตัวอย่างโค้ดง่าย ๆ ต่อไปนี้สำหรับการเพิ่มส่วนหัวและส่วนท้ายในงานนำเสนอด้วย Aspose.Slides API เวอร์ชันเก่าและทำตามขั้นตอนที่อธิบายวิธีการย้ายไปยัง API ที่รวมใหม่
