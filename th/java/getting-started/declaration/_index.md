{{% alert color="info" %}} 

ส่วนประกอบ Aspose Java ทั้งหมดต้องการชุดสิทธิ์ Full Trust. เหตุผลคือส่วนประกอบ Aspose Java จำเป็นต้องเข้าถึงการตั้งค่าลงทะเบียน, ไฟล์ระบบที่ไม่ใช่ไดเร็กทอรีเสมือนสำหรับการทำงานบางอย่างเช่นการวิเคราะห์ฟอนต์ เป็นต้น. นอกจากนี้ส่วนประกอบ Aspose Java ยังอิงกับคลาสระบบหลักของ Java ที่ในหลายกรณีก็ต้องการชุดสิทธิ์ Full Trust ด้วย. 

{{% /alert %}} 

ผู้ให้บริการอินเทอร์เน็ต (ISP) ที่โฮสต์แอปพลิเคชันหลายตัวจากบริษัทต่างๆ ส่วนใหญ่บังคับใช้ระดับความปลอดภัย Medium Trust: 

- OleDbPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถใช้ผู้ให้บริการข้อมูล OLE DB ที่จัดการโดย ADO.NET เพื่อเข้าถึงฐานข้อมูลได้.
- EventLogPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถเข้าถึงบันทึกเหตุการณ์ของ Windows ได้.
- ReflectionPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถใช้การสะท้อน (reflection) ได้.
- RegistryPermission ไม่พร้อมใช้งาน หมายความว่าคุณไม่สามารถเข้าถึงรีจิสทรีได้.
- WebPermission ถูกจำกัด หมายความว่าแอปพลิเคชันของคุณสามารถสื่อสารได้เฉพาะกับที่อยู่หรือช่วงของที่อยู่ที่คุณกำหนดในองค์ประกอบ <trust> เท่านั้น.
- FileIOPermission ถูกจำกัด หมายความว่าคุณสามารถเข้าถึงไฟล์ได้เฉพาะในโครงสร้างไดเร็กทอรีเสมือนของแอปพลิเคชันของคุณเท่านั้น.

{{% alert color="info" %}} 

เนื่องจากเหตุผลที่ระบุข้างต้น ส่วนประกอบ Aspose Java ไม่สามารถใช้บนเซิร์ฟเวอร์ที่ให้ชุดสิทธิ์อื่นนอกจาก Full Trust ได้.
