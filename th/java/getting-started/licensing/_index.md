## **ภาพรวม**

Aspose.Slides สามารถใช้ได้ในโหมดประเมินหรือโดยใช้ใบอนุญาตที่ถูกต้อง รุ่นประเมินให้ฟังก์ชันการทำงานเดียวกับรุ่นที่มีใบอนุญาต แต่จะเพิ่มลายน้ำประเมินลงในทุกสไลด์ของแต่ละงานนำเสนอที่บันทึกและตัดข้อความที่โค้ดของคุณอ่านผ่าน API

บทความนี้อธิบายวิธีการทำงานของใบอนุญาตใน Aspose.Slides และวิธีการใช้ใบอนุญาตก่อนใช้ไลบรารี ใบอนุญาตสามารถโหลดจากไฟล์, สตรีม หรือทรัพยากรฝังโดยใช้คลาส `License` บทความยังแสดงวิธีตรวจสอบว่าใบอนุญาตถูกนำไปใช้อย่างถูกต้องหรือไม่

## **ประเมิน Aspose.Slides**

{{% alert color="info" title="Note" %}}

คุณสามารถดาวน์โหลดรุ่นประเมินของ **Aspose.Slides for Java** ได้จาก [หน้าดาวน์โหลด](https://releases.aspose.com/java/repo/com/aspose/aspose-slides/) รุ่นประเมินให้ฟังก์ชันการทำงานเดียวกับรุ่นที่มีใบอนุญาตของผลิตภัณฑ์ แพ็คเกจประเมินเหมือนกับแพ็คเกจที่ซื้อแล้ว รุ่นประเมินจะกลายเป็นรุ่นที่มีใบอนุญาตเมื่อคุณเพิ่มบรรทัดโค้ดเล็กน้อย (เพื่อใช้ใบอนุญาต)

เมื่อคุณพอใจกับการประเมิน **Aspose.Slides** แล้ว คุณสามารถ [ซื้อใบอนุญาต](https://purchase.aspose.com/pricing/slides/java/) เราแนะนำให้คุณพิจารณาประเภทการสมัครสมาชิกต่าง ๆ หากมีคำถาม ติดต่อทีมขายของ Aspose

ใบอนุญาตทุกใบของ Aspose มาพร้อมการสมัครสมาชิกหนึ่งปีสำหรับการอัพเกรดฟรีไปยังเวอร์ชันใหม่หรือการแก้ไขบั๊กที่เผยแพร่ภายในช่วงระยะเวลาการสมัคร สมาชิกที่มีผลิตภัณฑ์ที่ได้รับใบอนุญาต (หรือแม้แต่รุ่นประเมิน) จะได้รับการสนับสนุนทางเทคนิคฟรีและไม่จำกัด

**ข้อจำกัดของรุ่นประเมิน**

* รุ่นประเมิน (โดยไม่ได้ระบุใบอนุญาต) ให้ฟังก์ชันการทำงานเต็มรูปแบบของผลิตภัณฑ์ แต่จะเพิ่มกล่องข้อความลายน้ำประเมินลงในทุกสไลด์ของแต่ละงานนำเสนอที่บันทึก
* ข้อความที่โค้ดของคุณอ่านผ่าน API รวมถึงข้อความที่เพิ่งตั้งค่า จะถูกตัดให้เหลือเพียงไม่กี่อักขระแรก ตามด้วยข้อความแจ้งข้อจำกัดของการประเมิน ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ

เพื่อทดสอบ Aspose.Slides โดยไม่มีข้อจำกัด คุณสามารถขอ **ใบอนุญาตชั่วคราว 30 วัน** ดูหน้า [How to get a Temporary License](https://purchase.aspose.com/temporary-license) สำหรับข้อมูลเพิ่มเติม

## **การให้ใบอนุญาตใน Aspose.Slides**

* รุ่นประเมินจะกลายเป็นรุ่นที่มีใบอนุญาตหลังจากคุณซื้อใบอนุญาตและเพิ่มบรรทัดโค้ดสองสามบรรทัด (เพื่อใช้ใบอนุญาต)
* ใบอนุญาตเป็นไฟล์ XML รูปแบบข้อความธรรมดาซึ่งมีรายละเอียดเช่น ชื่อผลิตภัณฑ์ จำนวนผู้พัฒนาที่ได้รับใบอนุญาต วันที่หมดอายุของการสมัครสมาชิก ฯลฯ
* ไฟล์ใบอนุญาตมีลายเซ็นดิจิทัล ดังนั้นคุณต้องไม่แก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างเพิ่มเติมในเนื้อหาไฟล์เดียวกันก็จะทำให้ใบอนุญาตไม่ถูกต้อง
* Aspose.Slides for Java โดยปกติจะพยายามค้นหาใบอนุญาตในตำแหน่งต่อไปนี้:
  * เส้นทางที่ระบุโดยตรง
  * โฟลเดอร์ที่มี Aspose.Slides.jar
* เพื่อหลีกเลี่ยงข้อจำกัดของรุ่นประเมิน คุณต้องตั้งค่าใบอนุญาตก่อนใช้ **Aspose.Slides** คุณต้องตั้งค่าใบอนุญาตเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

คุณอาจต้องการดู [Metered Licensing](/slides/th/java/metered-licensing/)

## **การใช้ใบอนุญาต**

ใบอนุญาตสามารถโหลดจาก **ไฟล์** หรือ **สตรีม** ได้

{{% alert color="info" title="Note" %}}

Aspose.Slides มีคลาส [License](https://reference.aspose.com/slides/java/com.aspose.slides/license/) สำหรับการทำงานเกี่ยวกับใบอนุญาต

{{% /alert %}} 

{{% alert color="warning" title="Warning" %}}

ใบอนุญาตใหม่สามารถเปิดใช้งาน Aspose.Slides ได้เฉพาะกับเวอร์ชัน 21.4 หรือใหม่กว่า เวอร์ชันก่อนหน้านั้นใช้ระบบใบอนุญาตอื่นและจะไม่รับรู้ใบอนุญาตเหล่านี้

{{% /alert %}}

### **File**

วิธีที่ง่ายที่สุดในการตั้งค่าใบอนุญาตคือการวางไฟล์ใบอนุญาตไว้ในโฟลเดอร์ที่มี Aspose.Slides.jar หรือ jar ของแอปพลิเคชันของคุณ

โค้ด Java นี้แสดงวิธีตั้งค่าไฟล์ใบอนุญาต:

``` java
// สร้างอินสแตนซ์ของคลาส License
com.aspose.slides.License license = new com.aspose.slides.License();

// ตั้งค่าเส้นทางไฟล์ใบอนุญาต
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" title="Warning" %}}

หากคุณวางไฟล์ใบอนุญาตในไดเรกทอรีอื่น เมื่อเรียกใช้เมธอด [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-) ชื่อไฟล์ใบอนุญาตที่อยู่ท้ายเส้นทางที่ระบุต้องตรงกับชื่อไฟล์ใบอนุญาตของคุณ

เช่น คุณอาจเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น *Aspose.Slides.Java.lic.xml* จากนั้นในโค้ดของคุณต้องส่งเส้นทางไปยังไฟล์ (สิ้นสุดด้วย *Aspose.Slides.Java.lic.xml*) ไปยังเมธอด [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-)

{{% /alert %}}

### **Stream**

คุณสามารถโหลดใบอนุญาตจากสตรีมได้ โค้ด Java นี้แสดงวิธีใช้ใบอนุญาตจากสตรีม:

``` java
// สร้างอินสแตนซ์ของคลาส License
com.aspose.slides.License license = new com.aspose.slides.License();

// ตั้งค่าใบอนุญาตผ่านสตรีม
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **PHP/Java Bridge**

หากคุณใช้ Aspose.Slides for PHP ผ่าน Java คุณสามารถตั้งค่าใบอนุญาตผ่าน PHP/Java Bridge สะพานนี้ช่วยให้คุณใช้คลาส Java ในไวยากรณ์ PHP รายละเอียดเพิ่มเติมดูที่ [License in PHP](/slides/th/php-java/licensing/)

## **การตรวจสอบใบอนุญาต**

เพื่อให้แน่ใจว่าได้ตั้งค่าใบอนุญาตอย่างถูกต้อง คุณสามารถตรวจสอบได้ โค้ด Java นี้แสดงวิธีตรวจสอบใบอนุญาต:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **ความปลอดภัยของเธรด**

{{% alert color="warning" title="Warning" %}}

เมธอด [setLicense](https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.io.InputStream-) ไม่เป็น thread‑safe หากเมธอดนี้ต้องถูกเรียกพร้อมกันจากหลายเธรด คุณอาจต้องใช้กลไกการทำงานร่วมกัน (เช่น lock) เพื่อหลีกเลี่ยงปัญหา

{{% /alert %}}

## **FAQ**

### ฉันสามารถใช้ใบอนุญาตในสภาพแวดล้อมออฟไลน์โดยสมบูรณ์ (ไม่มีการเชื่อมต่ออินเทอร์เน็ต) ได้หรือไม่?

ได้ค่ะ การตรวจสอบใบอนุญาตทำโดยอิสระในเครื่องโดยใช้ไฟล์ใบอนุญาต ไม่ต้องการการเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกแบบปีหนึ่งหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่ไลบรารียังคงทำงานได้ต่อไป: ใบอนุญาตเป็นอายุถาวร คุณสามารถใช้เวอร์ชันที่ออกก่อนวันสิ้นสุดการสมัครได้ แต่จะไม่สามารถใช้เวอร์ชันใหม่หลังจากหมดอายุโดยไม่ได้ต่ออายุ
