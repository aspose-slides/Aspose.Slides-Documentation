## **ภาพรวม**

Aspose.Slides สามารถใช้ในโหมดทดลองหรือด้วยใบอนุญาตที่ถูกต้อง เวอร์ชันทดลองให้ฟังก์ชันเดียวกับเวอร์ชันที่มีใบอนุญาต แต่จะใส่น้ำลายน้ำทดลองเมื่อเปิดหรือบันทึกงานนำเสนอและจำกัดการดึงข้อความไว้ที่หนึ่งสไลด์เท่านั้น

บทความนี้อธิบายการทำงานของการให้ใบอนุญาตใน Aspose.Slides และวิธีการใช้ใบอนุญาตก่อนใช้งานไลบรารี ใบอนุญาตสามารถโหลดจากไฟล์, สตรีม หรือทรัพยากรฝังตัวโดยใช้คลาส `License` บทความนี้ยังแสดงวิธีตรวจสอบว่าใบอนุญาตถูกนำไปใช้ถูกต้องหรือไม่

## **การให้ใบอนุญาตใน Aspose.Slides**

* เวอร์ชันทดลองจะกลายเป็นเวอร์ชันที่มีใบอนุญาตเมื่อคุณซื้อใบอนุญาตและเพิ่มโค้ดสองสามบรรทัดเพื่อใช้ใบอนุญาต

* ไฟล์ใบอนุญาตมีลายเซ็นดิจิทัล ดังนั้นห้ามแก้ไขไฟล์ แม้แต่การเพิ่มบรรทัดว่างเพิ่มเติมในเนื้อหาไฟล์ก็จะทำให้ใบอนุญาตเสียหาย
* Aspose.Slides for Java มักจะค้นหาใบอนุญาตในตำแหน่งต่อไปนี้:
  * เส้นทางที่ระบุอย่างชัดเจน
  * โฟลเดอร์ที่มีไฟล์ Aspose.Slides.jar
* เพื่อหลีกเลี่ยงข้อจำกัดของเวอร์ชันทดลอง คุณต้องตั้งค่าใบอนุญาตก่อนใช้ **Aspose.Slides** คุณต้องตั้งค่าใบอนุญาตเพียงครั้งเดียวต่อแอปพลิเคชันหรือกระบวนการ

Aspose.Slides มีคลาส[License](https://reference.aspose.com/slides/th/java/com.aspose.slides/License)สำหรับทำงานเกี่ยวกับใบอนุญาต

{{% /alert %}}

### **ไฟล์**

วิธีที่ง่ายที่สุดในการตั้งค่าใบอนุญาตคือใส่ไฟล์ใบอนุญาตไว้ในโฟลเดอร์ที่มี Aspose.Slides.jar หรือ jar ของแอปพลิเคชันของคุณ

โค้ด Java ตัวอย่างที่แสดงวิธีตั้งค่าไฟล์ใบอนุญาต:

``` java
// สร้างอินสแตนซ์ของคลาส License
com.aspose.slides.License license = new com.aspose.slides.License();

// ตั้งค่าพาธไฟล์ใบอนุญาต
license.setLicense("Aspose.Slides.Java.lic");
```

{{% alert color="warning" %}} 
หากคุณวางไฟล์ใบอนุญาตในไดเรกทอรีอื่น เมื่อเรียกใช้เมธอด[SetLicense](https://reference.aspose.com/slides/th/java/com.aspose.slides/License#setLicense-java.lang.String-) คุณต้องแนบชื่อไฟล์ใบอนุญาตที่ส่วนท้ายของเส้นทางที่ระบุให้ตรงกับไฟล์ใบอนุญาตจริงของคุณ

เช่น คุณอาจเปลี่ยนชื่อไฟล์ใบอนุญาตเป็น*Aspose.Slides.Java.lic.xml* แล้วในโค้ดของคุณต้องส่งพาธไปยังไฟล์ (ลงท้ายด้วย*Aspose.Slides.Java.lic.xml*) ให้เมธอด[SetLicense](https://reference.aspose.com/slides/th/java/com.aspose.slides/License#setLicense-java.lang.String-)
{{% /alert %}}

### **สตรีม**

คุณสามารถโหลดใบอนุญาตจากสตรีมได้ โค้ด Java ตัวอย่างที่แสดงวิธีนำใบอนุญาตจากสตรีมไปใช้:

``` java
// สร้างอินสแตนซ์ของคลาส License
com.aspose.slides.License license = new com.aspose.slides.License();

// ตั้งค่าใบอนุญาตผ่านสตรีม
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **PHP/Java Bridge**

หากคุณใช้ Aspose.Slides for PHP ผ่าน Java คุณสามารถตั้งค่าใบอนุญาตผ่าน PHP/Java bridge สะพานนี้ทำให้คุณใช้คลาส Java ด้วยไวยากรณ์ PHP รายละเอียดเพิ่มเติมดูที่[License in PHP](/slides/th/php-java/licensing/)

## **การตรวจสอบใบอนุญาต**

เพื่อเช็คว่าได้ตั้งค่าใบอนุญาตอย่างถูกต้องหรือไม่ คุณสามารถตรวจสอบได้ โค้ด Java ตัวอย่างที่แสดงวิธีตรวจสอบใบอนุญาต:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **FAQ**

### ฉันสามารถนำใบอนุญาตไปใช้ในสภาพแวดล้อมที่ไม่มีการเชื่อมต่ออินเทอร์เน็ต (ออฟไลน์) ได้หรือไม่?

ได้ การตรวจสอบใบอนุญาตทำงานในเครื่องโดยใช้ไฟล์ใบอนุญาต ไม่ต้องการการเชื่อมต่ออินเทอร์เน็ต

### จะเกิดอะไรขึ้นเมื่อการสมัครสมาชิกหนึ่งปีหมดอายุ? ไลบรารีจะหยุดทำงานหรือไม่?

ไม่ ใบอนุญาตเป็นแบบถาวร: คุณสามารถใช้เวอร์ชันที่ออกก่อนวันสิ้นสุดการสมัครสมาชิกต่อไปได้ แต่จะไม่สามารถใช้เวอร์ชันใหม่ที่ออกหลังจากนั้นโดยไม่ต่ออายุ
