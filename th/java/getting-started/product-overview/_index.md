## **ยินดีต้อนรับสู่ Aspose.Slides for Java!**

Aspose.Slides for Java คือ API การจัดการ Microsoft PowerPoint® ที่ทำให้แอปพลิเคชัน Java สามารถอ่านและเขียนเอกสาร PowerPoint® ได้โดยไม่ต้องใช้ Microsoft PowerPoint®  

Aspose.Slides for Java เป็นคอมโพเนนต์แรกและเดียวที่ให้ฟังก์ชันที่จำเป็นสำหรับการจัดการเอกสาร PowerPoint®  

Aspose.Slides for Java มีคุณลักษณะสำคัญมากมาย เช่น การจัดการข้อความ, รูปร่าง, ตาราง & แอนิเมชัน, การเพิ่มเสียงและวิดีโอบนสไลด์, การแสดงตัวอย่างสไลด์, การส่งออกสไลด์เป็น SVG, PDF และรูปแบบอื่น ๆ  

## **คำอธิบายผลิตภัณฑ์**

Aspose.Slides for Java ไม่เพียงแต่ให้คุณเปิดไฟล์ PowerPoint จากแหล่งต่าง ๆ เท่านั้น แต่ยังอนุญาตให้คุณบันทึกงานนำเสนอของคุณในหลายรูปแบบ เช่น คุณสามารถบันทึกงานนำเสนอเป็น PPT; คุณยังสามารถบันทึกสไลด์เป็นภาพได้  

Aspose.Slides for Java มอบคุณลักษณะเกือบทั้งหมดที่คุณอาจพบหรือไม่พบใน Microsoft PowerPoint. ด้วยความหลากหลายของ Aspose.Slides for Java นอกจากตารางและรูปทรงหลายประเภทแล้ว คุณยังสามารถเพิ่มเฟรมประเภทต่าง ๆ — เฟรมข้อความ, เสียง, และวิดีโอ — ไปยังสไลด์ของคุณได้  

Aspose.Slides for Java ยังมีการสาธิตเต็มรูปแบบและตัวอย่างการทำงานสำหรับนักพัฒนาเพื่อทำความเข้าใจ API ได้ดีขึ้น  

### **คุณลักษณะของงานนำเสนอ**

- เปิดงานนำเสนอ Microsoft PowerPoint จากแหล่งต่าง ๆ  
- บันทึกงานนำเสนอในรูปแบบ Microsoft PowerPoint ต่าง ๆ  
- สร้างงานนำเสนอจากศูนย์  
- แปลงงานนำเสนอเป็นเอกสาร PDF โดยไม่ต้องใช้คอมโพเนนต์อื่น  
- ความสามารถในการอ่าน Open Document Presentation (ODP)  
- ความสามารถในการแปลง PPT เป็น PPTX หรือกลับกัน  
- อ่านหรือแก้ไขคุณสมบัติของเอกสารงานนำเสนอ  
- ส่งออกงานนำเสนอเป็น PDF  
- ส่งออกงานนำเสนอเป็น TIFF  
- ส่งออกงานนำเสนอเป็น XPS  
- ส่งออกงานนำเสนอเป็น SWF  
- ส่งออกงานนำเสนอเป็นบันทึก PDF / บันทึก Tiff  
- ส่งออกงานนำเสนอเป็น HTML  

### **คุณลักษณะของสไลด์**

- สร้างสไลด์ใหม่จากศูนย์และเพิ่มลงในงานนำเสนอ  
- เข้าถึงสไลด์ใด ๆ ผ่านตำแหน่งในงานนำเสนอ  
- คัดลอกหรือทำสำเนาสไลด์ไปยังงานนำเสนอเดียวกันหรืออื่น  
- แก้ไขและลบสไลด์  
- คัดลอกมาสเตอร์พร้อมสไลด์โดยอัตโนมัติ  
- แสดงตัวอย่างสไลด์  
- รับหรือกำหนดชื่อสไลด์  
- บันทึกสไลด์เป็นรูปภาพ  
- ส่งออกสไลด์เป็นรูปแบบ SVG  
- ทำงานกับมาสเตอร์หลายตัวในงานนำเสนอ  
- เติมพื้นหลังสไลด์ด้วยสไตล์ที่รองรับ  
- เพิ่มหรือจัดการโน้ตของสไลด์  
- กำหนดมาสเตอร์และสไตล์ของสไลด์ใหม่แบบไดนามิก  
- เพิ่มหรือแก้ไขการเปลี่ยนภาพของการนำเสนอ  
- เพิ่มการเปลี่ยนแบบ Morph  

### **คุณลักษณะกราฟิกและมัลติมีเดีย**

- สร้างหรือจัดการรูปทรงเช่น เส้น, สี่เหลี่ยม, วงรี, และโพลีไลน์  
- จัดการสไตล์ของเส้นในรูปทรง  
- รับข้อความแทนรูปทรง  
- หมุนหรือพลิกรูปทรง  
- เติมรูปทรงด้วยสไตล์ต่าง ๆ เช่น สีทึบ, ไล่ระดับสี, ลาย, เทกเจอร์และภาพ  
- ใช้ลายที่กำหนดไว้ล่วงหน้า 48 แบบและเทกเจอร์ 24 แบบ  
- กำหนดลิงก์ให้กับรูปทรง  
- อ่าน, แก้ไข, และเพิ่มเอฟเฟกต์แอนิเมชันใหม่ให้กับสไลด์และรูปทรง  
- เพิ่มรูปภาพใหม่ในงานนำเสนอและจัดการรูปภาพที่มีอยู่  
- เพิ่มรูปภาพ bullet ใหม่ในงานนำเสนอและจัดการรูปที่มีอยู่  
- เพิ่มเฟรมเสียงใหม่ในงานนำเสนอและจัดการเฟรมที่มีอยู่  
- เพิ่มเฟรมวิดีโอใหม่ในงานนำเสนอและจัดการเฟรมที่มีอยู่  

### **คุณลักษณะของตาราง**

- สร้างตารางจากศูนย์และเพิ่มลงสไลด์  
- ปรับขนาดและย้ายตาราง  
- เข้าถึงเซลล์ใด ๆ ในตาราง  
- เปลี่ยนรูปแบบและเส้นขอบของเซลล์ใด ๆ  
- ปรับขนาดคอลัมน์และแถว  
- เพิ่มและลบคอลัมน์และแถว  
- กำหนดความกว้างและสีของเส้นขอบสำหรับตารางทั้งหมด  
- ใช้สไตล์ที่ตั้งล่วงหน้าให้กับตาราง  

### **คุณลักษณะข้อความและย่อหน้า**

- รับและกำหนดข้อความใน text placeholder และ text frame  
- รับประเภทของ placeholder  
- เปลี่ยนการจัดรูปแบบข้อความใน text frame  
- เพิ่มฟอนต์ใหม่หรือจัดการฟอนต์ที่ใช้ในงานนำเสนอ  
- เปลี่ยนข้อความและการจัดรูปแบบข้อความ  
- สร้างหรือจัดการลิงก์ในข้อความ  
- รองรับแท็บและแท็บที่มีประสิทธิภาพ  
- เพิ่ม text frame ใหม่ให้กับเกือบทุกประเภทของรูปทรง  
- เข้าถึงและแก้ไขการตั้งค่าขอบและการตัดข้อความของ text frame  
- เข้าถึงและแก้ไขการเยื้องของย่อหน้า  

### **คุณลักษณะขั้นสูง**

- เข้าถึงวัตถุ OLE ที่ฝังในงานนำเสนอ  
- ล็อคงานนำเสนอ  
- เพิ่มลายน้ำให้กับงานนำเสนอ  
- ใช้แอนิเมชันกับรูปทรงภายในสไลด์  

## **คำถามที่พบบ่อย**

### รองรับระดับความสอดคล้องของ PDF สำหรับการจัดเก็บและการเข้าถึง (PDF/A และ PDF/UA) หรือไม่?

ใช่ คุณสามารถบันทึกเป็น PDF ด้วย PDF/A-2a/2b/2u, PDF/A-3a/3b รวมถึง PDF/UA ได้โดยกำหนดค่า [PDF export options](https://reference.aspose.com/slides/th/java/com.aspose.slides/pdfoptions/).

### มีกลไกการทดแทนฟอนต์และการสนับสนุนฟอนต์แบบกำหนดเองเพื่อให้การเรนเดอร์ถูกต้องหรือไม่?

ใช่ ไลบรารีอนุญาตให้คุณ [load custom fonts](/slides/th/java/custom-font/) และ [define fallback rules](/slides/th/java/fallback-font/) เพื่อให้ glyph ที่ขาดหายไปถูกแทนที่อย่างเชื่อถือได้ระหว่างการแปลงและการเรนเดอร์.

### สามารถตรวจจับว่าไฟล์ถูกป้องด้วยรหัสผ่านโดยไม่ต้องเปิดเต็มหรือไม่?

ใช่ คุณสามารถ [inspect a presentation](/slides/th/java/examine-presentation/) เพื่อตรวจสอบว่าต้องการรหัสผ่านก่อนโหลดเอกสารเต็มหรือไม่.

### จำเป็นต้องใช้ Microsoft PowerPoint สำหรับการประมวลผลและการแปลงหรือไม่?

ไม่ Aspose.Slides เป็นเอนจิ้นแบบสแตนด์อโลน; ไม่จำเป็นต้องมี PowerPoint บนเซิร์ฟเวอร์หรือเวิร์กสเตชัน.

### ปลอดภัยหรือไม่ในการประมวลผลงานนำเสนอจากหลายเธรด?

ใช่ คุณสามารถประมวลผลเอกสารต่าง ๆ แบบขนานในเธรดแยกกัน; เพียงหลีกเลี่ยงการใช้อินสแตนซ์งานนำเสนอเดียวกันพร้อมกัน [across threads](/slides/th/java/multithreading/).

### แมคโครถูกเก็บรักษาและฉันสามารถจัดการ VBA ในไฟล์ PPTM/PPSM ได้หรือไม่?

ใช่ งานนำเสนอที่มีแมคโคร [are supported](/slides/th/java/presentation-via-vba/), และคุณสามารถ [inspect and manage VBA projects](https://reference.aspose.com/slides/th/java/com.aspose.slides/presentation/#getVbaProject--) ในไฟล์เหล่านั้น.

### สามารถแปลง PDF หรือ HTML กลับเป็นสไลด์ PowerPoint ได้หรือไม่?

ใช่ คุณสามารถ [import PDF pages or HTML content](/slides/th/java/import-presentation/) เพื่อสร้างหรือเติมสไลด์ในงานนำเสนอ.

### การส่งออก XPS ได้รับการสนับสนุนหรือไม่, และฉันสามารถควบคุมคุณภาพและเนื้อหาของผลลัพธ์ XPS ได้หรือไม่?

ใช่ [Export to XPS](/slides/th/java/convert-powerpoint-to-xps/) มีให้ใช้, และ [save options](https://reference.aspose.com/slides/th/java/com.aspose.slides/xpsoptions/) ช่วยให้คุณปรับคุณภาพผลลัพธ์และเนื้อหาที่รวมอยู่ได้.

### สามารถแปลงสไลด์เป็นภาพและควบคุมคุณภาพผลลัพธ์ได้หรือไม่?

ใช่ สไลด์สามารถ [rendered to PNG, JPEG, GIF, BMP, TIFF](/slides/th/java/convert-powerpoint-to-png/) และรูปแบบอื่น ๆ โดยควบคุมขนาดและคุณภาพได้อย่างละเอียด.

### รองรับสูตรคณิตศาสตร์ (MathML/MathText) หรือไม่และสามารถส่งออกได้หรือไม่?

ใช่ คุณสามารถ [create and edit mathematical text](/slides/th/java/powerpoint-math-equations/) และ [export equations](/slides/th/java/exporting-math-equations/) รวมถึงเป็น MathML.

### ไลบรารีจัดการการเข้ารหัสและรหัสผ่าน (เปิด, ตั้งค่า, ลบ) อย่างไร?

[It supports](/slides/th/java/password-protected-presentation/) การเปิดงานนำเสนอที่เข้ารหัส, การตั้งหรือการลบรหัสผ่านสำหรับการเปิดและแก้ไข, และการตรวจสอบสถานะการป้องกันของไฟล์.
