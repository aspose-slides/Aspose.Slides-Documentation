## การเปลี่ยนแปลง Classifier ของ Artifact จาก `jdk16` ไปเป็น `jdk8`

ตั้งแต่รุ่น **26.10**, เราได้ทำการเปลี่ยน classifier ที่ใช้ใน artifact ที่เผยแพร่จาก **`jdk16`** (Java 6) ไปเป็น **`jdk8`** (Java 8).

### สิ่งที่เปลี่ยนแปลง

| | ก่อน | หลัง |
|---|---|---|
| ตัวจำแนก | `jdk16` | `jdk8` |
| เวอร์ชัน Java ขั้นต่ำ | Java 1.6 | Java 8 |

**ก่อน:**
```
com.aspose:aspose-slides:26.10:jdk16
```

**หลัง:**
```
com.aspose:aspose-slides:26.10:jdk8
```

### ทำไมเราจึงทำการเปลี่ยนแปลงนี้

หลังจากการทบทวนภายใน เราตัดสินใจ **ยกเลิกการสนับสนุนเวอร์ชัน Java เก่า** ที่ไม่ให้คุณค่าอีกต่อไปและทำให้การบำรุงรักษายากขึ้น Java 8 ถูกเลือกเป็นฐานที่ปลอดภัยใหม่สำหรับผู้ใช้ทั้งหมด.

ในส่วนนี้ classifier ถูกอัปเดตเพื่อสะท้อนเวอร์ชันขั้นต่ำที่สนับสนุนจริง เราได้ปรับให้สอดคล้องกับแนวทางตั้งชื่อของ Oracle ปัจจุบัน ซึ่งผลิตภัณฑ์ถูกเรียกอย่างเป็นทางการว่า **JDK 8** (แทนรูปแบบเดิม `1.8`).

### สิ่งที่คุณต้องทำ

1. **อัปเดต classifier** ในประกาศการพึ่งพาของคุณจาก `jdk16` ไปเป็น `jdk8`.

   **Maven:**
   ```xml
   <dependency>
     <groupId>com.aspose</groupId>
     <artifactId>aspose-slides</artifactId>
     <version>26.10</version>
     <classifier>jdk8</classifier>
   </dependency>
   ```

   **Gradle:**
   ```groovy
   implementation 'com.aspose:aspose-slides:26.10:jdk8'
   ```

2. **ตรวจสอบสภาพแวดล้อมการทำงานของคุณ** เป็น Java 8 หรือสูงกว่า.

3. **รีเฟรชไฟล์ล็อกใดๆ** หรือแคชการพึ่งพาที่กำหนด classifier เก่าไว้.

### หมายเหตุการย้าย: jdk16 และ jdk8

ตั้งแต่รุ่น 26.10, ทั้ง classifier jdk16 และ jdk8 จะให้ JAR ที่เข้ากันได้กับ Java 8–compatible JARs (สร้างด้วยการตั้งค่า source/target compatibility เป็น Java 8).

 - `jdk16` → ยังคงถูกเผยแพร่เพื่อความเข้ากันย้อนหลัง (การรวมระบบที่มีอยู่).
 - `jdk8` → ถูกแนะนำเป็น classifier ที่แนะนำใหม่สำหรับสภาพแวดล้อม Java 8.

⚠️ หมายเหตุ: ระยะเวลาการเผยแพร่คู่นี้มีกำหนดสิ้นสุดในวันที่ 31 มีนาคม 2027. หลังจากวันนั้น classifier jdk16 จะถูกยกเลิก, และจะสนับสนุนเฉพาะ jdk8 เท่านั้น.

### หมายเหตุความเข้ากันได้

- ตัวจำแนก `jdk16` **ไม่ได้เผยแพร่อีกต่อไป** หลังจาก **31 มีนาคม 2027**.
- หากคุณยังต้องการการสนับสนุน Java 1.6 โปรดอยู่ในสายเวอร์ชันหลักก่อนหน้าจนกว่าจะย้ายได้.
