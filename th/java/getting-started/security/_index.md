## **บทนำ**

บทความนี้รวบรวมข้อมูลที่การตรวจสอบความปลอดภัยของแอปพลิเคชันที่ใช้ Aspose.Slides for Java ปกติแล้วต้องการ: วิธีที่ไลบรารีประมวลผลงานนำเสนอ สิ่งที่เพิ่มเข้าไปในการพึ่งพาของโครงการของคุณ วิธีตรวจสอบว่าไฟล์ JAR มาจาก Aspose และส่วนประกอบของบุคคลที่สามที่ไฟล์ JAR มีอยู่

## **ความปลอดภัยใน Aspose.Slides**

Aspose ปฏิบัติตามแนวทางที่ดีที่สุดเมื่อตีพิมพ์ผลิตภัณฑ์ของตน

* Aspose.Slides for Java ใช้เพื่อสร้าง แก้ไข และแปลงงานนำเสนอ มันไม่ได้รันสคริปต์ในงานนำเสนอ Aspose.Slides จะวิเคราะห์โครงสร้างงานนำเสนอและทำให้โค้ดของคุณทำงานกับโมเดลวัตถุ
* Aspose.Slides ทำหน้าที่เป็นไลบรารีที่วิเคราะห์และตีความเอกสารโดยไม่ต้องดำเนินการโค้ดจากระยะไกล ผลิตภัณฑ์ Aspose ทั้งหมดทำงานบนเครื่องของคุณ ไม่ได้ส่งข้อมูลใด ๆ ไปยัง Aspose ข้อยกเว้นเดียวคือ[การให้สิทธิ์แบบจ่ายตามการใช้](/slides/th/java/metered-licensing/): หากคุณใช้มัน จะมีเพียงข้อมูลการใช้ API ของคุณที่ถูกประมวลผล
* ส่วนประกอบของ Aspose ทำงานในบริบทผู้ใช้เดียวกับแอปพลิเคชันทั่วไป ดังนั้นส่วนประกอบของ Aspose จึงไม่เป็นความเสี่ยงต่อทรัพยากรระบบที่สำคัญ ยิ่งกว่านั้น เมื่อส่วนประกอบของ Aspose เปิดเอกสาร แมโครจะไม่ถูกรันโดยอัตโนมัติ

## **การพึ่งพา Maven**

อาร์ติแฟกต์ Maven ของ Aspose.Slides for Java, `com.aspose:aspose-slides`, ไม่ได้ประกาศการพึ่งพาใด ๆ: ไฟล์ POM ของมันมีเพียงพิกัดของอาร์ติแฟกต์เท่านั้น เมื่อคุณเพิ่มมันไปในโครงการ Maven จะเพิ่มไฟล์ JAR นี้เพียงไฟล์เดียวและไม่มีอย่างอื่น เพื่อแสดงรายการอาร์ติแฟกต์ทั้งหมดที่โครงการของคุณแก้ไขได้ รวมถึงการพึ่งพาแบบถ่ายทอด ให้รันคำสั่งต่อไปนี้ในโฟลเดอร์โครงการ:

```bash
mvn dependency:tree
```

ในโครงการจาก[การติดตั้ง](/slides/th/java/installation/), ผลลัพธ์แสดง Aspose.Slides เป็นการพึ่งพาเดียว:

```text
[INFO] com.example:hello-slides:jar:1.0
[INFO] \- com.aspose:aspose-slides:jar:jdk16:26.9:compile
```

## **ตรวจสอบไฟล์ JAR**

Aspose ลงนามไฟล์ JAR เพื่อตรวจสอบลายเซ็น ให้รันเครื่องมือ `jarsigner` จาก JDK ในโฟลเดอร์ที่มีไฟล์ JAR:

```bash
jarsigner -verify aspose-slides-26.9-jdk16.jar
```

คำสั่งจะแสดง `jar verified.` เมื่อลายเซ็นถูกต้องและไม่มีรายการใดเปลี่ยนแปลงตั้งแต่ไฟล์ถูกลงนาม ข้อความนี้ไม่แสดงชื่อผู้ลงนาม เพื่อตรวจสอบว่า Aspose เป็นผู้ลงนามไฟล์ ให้เพิ่มตัวเลือก `-verbose` และ `-certs` แล้วตรวจสอบว่าหนังสือรับรองของผู้ลงนามออกให้กับ `CN=ASPOSE PTY LTD` เมื่อ Maven ดาวน์โหลดไฟล์ JAR มันยังตรวจสอบค่าตรวจสอบ SHA‑1 ที่ที่เก็บข้อมูลเผยแพร่พร้อมไฟล์ด้วย

## **ส่วนประกอบของบุคคลที่สาม**

Aspose.Slides for Java มีโค้ดและข้อมูลจากส่วนประกอบของบุคคลที่สาม พวกมันเป็นส่วนหนึ่งของไฟล์ JAR ไม่ได้เป็นอาร์ติแฟกต์ Maven แยกต่างหาก ดังนั้น `mvn dependency:tree` และเครื่องมืออื่น ๆ ที่อ่านการพึ่งพา Maven จะไม่แสดงรายการเหล่านี้ ไฟล์ JAR มีประกาศ *META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf* ซึ่งระบุส่วนประกอบและใบอนุญาตของพวกมัน:

| ส่วนประกอบ | ใบอนุญาตที่ระบุในประกาศ |
|---|---|
| DotNetZip | Microsoft Public License (Ms-PL) |
| Bouncy Castle | ใบอนุญาตสไตล์ MIT |
| Mono | ใบอนุญาต MIT; บางส่วนอยู่ภายใต้ใบอนุญาตอื่นที่ประกาศระบุ |
| RSWOP.ICM color profile | เงื่อนไขใบอนุญาตของ Microsoft |
| sRGB_v4_ICC_preference.icc color profile | สิทธิ์ ICC ให้ใช้ คัดลอก และเผยแพร่ไฟล์ที่ไม่ได้เปลี่ยนแปลง |
| Apache | Apache License 2.0 |
| ANTLR | BSD License |
| sfntly | Apache License 2.0 |

เพื่อสกัดไฟล์ประกาศจากไฟล์ JAR ให้รันเครื่องมือ `jar` จาก JDK ในโฟลเดอร์ที่มีไฟล์ JAR:

```bash
jar xf aspose-slides-26.9-jdk16.jar "META-INF/ThirdPartyLicenses-Aspose.Slides for Java.pdf"
```

## **คำถามที่พบบ่อย**

**Aspose.Slides for Java ใช้แพ็คเกจภายนอกหรือไม่?**

ไม่มีการพึ่งพา Maven อย่างแสดงใน[การพึ่งพา Maven](#maven-dependencies) แต่มีส่วนประกอบของบุคคลที่สามที่ระบุใน[ส่วนประกอบของบุคคลที่สาม](#third-party-components) ให้รวมไฟล์ JAR และส่วนประกอบเหล่านี้ในการตรวจสอบความปลอดภัยของคุณ

**Aspose.Slides for Java ต้องการการเชื่อมต่อเครือข่ายหรือไม่?**

ไม่ การสร้าง การบันทึก และการแสดงผลงานนำเสนอทำงานบนระบบที่ไม่มีการเชื่อมต่อเครือข่าย ฟีเจอร์เดียวที่ส่งข้อมูลไปยัง Aspose คือ[การให้สิทธิ์แบบจ่ายตามการใช้](/slides/th/java/metered-licensing/) ซึ่งรายงานการใช้ API

**Aspose.Slides for Java มีโค้ดเนทีฟหรือไม่?**

ไม่ ไฟล์ JAR มีเพียงคลาส Java และทรัพยากรเท่านั้น จึงไม่ได้เพิ่มไลบรารีเนทีฟให้กับแอปพลิเคชันของคุณ บน Linux การรองรับฟอนต์ของรันไทม์ Java ต้องใช้ไลบรารี fontconfig และฟอนต์จากระบบปฏิบัติการ; ดู[ข้อกำหนดระบบ](/slides/th/java/system-requirements/#linux)
