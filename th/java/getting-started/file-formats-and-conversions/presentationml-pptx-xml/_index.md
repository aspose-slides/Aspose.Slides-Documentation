PresentationML คือชื่อของกลุ่มรูปแบบที่ใช้ XML สำหรับเอกสารการนำเสนอ Office OpenXML (OOXML) เป็นรูปแบบที่ใช้ XML ที่แนะนำในแอปพลิเคชัน Microsoft Office 2007 Office OpenXML เป็นรูปแบบคอนเทนเนอร์สำหรับหลายภาษามาร์กอัปที่ใช้ XML พิเศษ PresentationML เป็นภาษามาร์กอัปที่ Microsoft Office PowerPoint 2007 ใช้ในการจัดเก็บเอกสาร

{{% /alert %}}

## **PresentationML ใน Aspose.Slides for Java**
เอกสาร OOXML PresentationML มีรูปแบบเป็นไฟล์ PPTX ซึ่งเป็นแพ็กเกจ XML ที่บีบอัดตามสเปกของ [OOXML ECMA-376](https://ecma-international.org/publications-and-standards/standards/ecma-376/) Aspose.Slides for Java รองรับการสร้าง อ่าน แก้ไข และเขียนเอกสาร PresentationML อย่างครอบคลุม นอกจากนี้ Aspose.Slides for Java ยังสามารถส่งออกเอกสาร PresentationML เป็นรูปแบบเอกสารที่ใช้กันอย่างกว้างขวางเช่น PDF ได้ นั่นเป็นไปได้เพราะ Aspose.Slides for Java ถูกออกแบบมาเพื่อจัดการเอกสารการนำเสนอและ PresentationML โดยพื้นฐานคือเก็บการนำเสนอของเอกสารในรูปแบบแพ็กเกจ XML ที่บีบอัด

## **PresentationML เป็นแบบเปิด ทำไมต้องใช้ Aspose.Slides for Java?**
เนื่องจาก PresentationML เป็นรูปแบบที่ใช้ XML ทำให้สามารถสร้างแอปพลิเคชันเพื่อประมวลผลและสร้างเอกสาร PresentationML ด้วยคลาส XML ได้โดยไม่ต้องอิงไลบรารีจากบุคคลที่สามเช่น Aspose.Slides for Java อย่างไรก็ตาม การใช้ Aspose.Slides for Java มีข้อได้เปรียบหลายประการเมื่อเทียบกับการใช้คลาส XML กับเอกสาร PresentationML

สเปก OOXML มีหลายพันหน้า ดังนั้นการจัดการเอกสาร PresentationML อย่างเหมาะสมต้องใช้เวลาและความพยายามอย่างมากเพื่อทำความเข้าใจรูปแบบ ในทางกลับกัน ด้วย Aspose.Slides for Java เพียงใช้คลาสและเมธอดหรือพรอพเพอร์ตีของพวกมันก็สามารถทำการดำเนินการที่ดูซับซ้อนได้หากทำด้วยคลาส XML

คุณลักษณะบางอย่างที่ Aspose.Slides มีให้ไม่สามารถใช้ได้เมื่อทำงานกับเอกสาร PresentationML ผ่านคลาส XML:

- ส่งออกเอกสาร PPT เป็นรูปแบบ PDF.
- เรนเดอร์สไลด์เป็นรูปภาพใด ๆ ที่สนับสนุนโดย Java Framework.
- คัดลอกมาสเตอร์จากการนำเสนอแหล่งอัตโนมัติโดยใช้ฟีเจอร์การโคลน.
- ตั้งค่าการป้องกันให้กับรูปร่าง.

ด้านล่างเป็นตัวอย่างเอกสาร PresentationML ที่มีสไลด์เดียวซึ่งมีกล่องข้อความที่มีข้อความ “Hello World” การอ่านข้อความโดยใช้คลาส XML ต้องเขียนโปรแกรมเพื่อแยกข้อความง่าย ๆ นี้จากส่วนประกอบต่อไปนี้ Aspose.Slides ทำให้คุณไม่ต้องทำเอง

``` xml

<p:sld xmlns:a="http://schemas.openxmlformats.org/drawingml/2006/main" xmlns:r="http://schemas.openxmlformats.org/officeDocument/2006/relationships" xmlns:p="http://schemas.openxmlformats.org/presentationml/2006/main">
  <p:cSld>
    <p:spTree>
      <p:nvGrpSpPr>
        <p:cNvPr id="1" name=""/>
        <p:cNvGrpSpPr/>
        <p:nvPr/>
      </p:nvGrpSpPr>
      <p:grpSpPr>
        <a:xfrm>
          <a:off x="0" y="0"/>
          <a:ext cx="0" cy="0"/>
          <a:chOff x="0" y="0"/>
          <a:chExt cx="0" cy="0"/>
        </a:xfrm></p:grpSpPr><p:sp>
          <p:nvSpPr><p:cNvPr id="4" name="TextBox 3"/>
          <p:cNvSpPr txBox="1"/>
            <p:nvPr/>
          </p:nvSpPr>
          <p:spPr>
            <a:xfrm>
              <a:off x="2819400" y="2590800"/>
              <a:ext cx="1297086" cy="369332"/>
            </a:xfrm>
            <a:prstGeom prst="rect">
              <a:avLst/>
            </a:prstGeom>
            <a:noFill/>
          </p:spPr>
          <p:txBody>
            <a:bodyPr wrap="none" rtlCol="0">
              <a:spAutoFit/>
            </a:bodyPr>
            <a:lstStyle/>
            <a:p>
              <a:r>
                <a:rPr lang="en-US"/>
                <a:t>Hello World
                </a:t>
              </a:r>
              <a:endParaRPr lang="en-US"/>
            </a:p>
          </p:txBody>
        </p:sp>
    </p:spTree>
  </p:cSld>
  <p:clrMapOvr>
    <a:masterClrMapping/>
  </p:clrMapOvr>
</p:sld>
```
