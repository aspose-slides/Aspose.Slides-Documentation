{{% alert color="info" title="Note" %}}

บทความในส่วนนี้เป็นภาพรวมเก่าของรูปแบบไฟล์แต่ละประเภทที่เก็บไว้เพื่อรองรับลิงก์ที่มีอยู่ พวกมันไม่ได้อธิบายเวอร์ชันปัจจุบันของ Aspose.Slides for Java สำหรับรูปแบบไฟล์ที่ Aspose.Slides for Java โหลด นำเข้า บันทึก และแสดงผล รวมถึง API ของแต่ละรูปแบบ ดูที่[รูปแบบไฟล์ที่รองรับ](/slides/th/java/supported-file-formats/). สำหรับคู่มือการแปลง ดูที่[แปลงการนำเสนอ](/slides/th/java/convert-presentation/).
