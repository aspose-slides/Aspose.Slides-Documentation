นี่คือหน้าประวัติศาสตร์ ที่เก็บไว้เพื่อการเชื่อมโยงที่มีอยู่. มันไม่ได้อธิบายเวอร์ชันปัจจุบันของ Aspose.Slides for Java. สำหรับรูปแบบไฟล์ที่ Aspose.Slides for Java โหลด, นำเข้า, บันทึก และเรนเดอร์ รวมถึง API สำหรับแต่ละรูปแบบ ดูที่ [Supported File Formats](/slides/th/java/supported-file-formats/). สำหรับคู่มือการแปลง TIFF ปัจจุบัน ดูที่ [Convert PowerPoint Presentations to TIFF](/slides/th/java/convert-powerpoint-to-tiff/).

{{% /alert %}}

## **เกี่ยวกับ TIFF**

รูปแบบไฟล์ [Tagged Image File Format](https://en.wikipedia.org/wiki/TIFF) ซึ่งเป็นที่รู้จักสำหรับการเก็บหลายภาพในเอกสารเดียว ถูกสร้างขึ้นโดย Aldus เดิม รูปแบบนี้ได้รับการสนับสนุนอย่างกว้างขวางโดยโปรแกรมสแกน, แฟกซ์ และแอปพลิเคชันการจัดการภาพอื่น ๆ

## **TIFF ใน Aspose.Slides for Java**

เอกสารใดก็ได้ที่สามารถโหลดใน Aspose.Slides for Java สามารถแปลงเป็นเอกสาร TIFF ได้โดยตรงโดย Aspose.Slides for Java ทำให้ไม่ต้องใช้ส่วนประกอบของบุคคลที่สาม นอกจากนี้ คุณสามารถกำหนดขนาดของภาพในเอกสาร TIFF ที่ได้ตามต้องการ คุณสามารถค้นหาข้อมูลเกี่ยวกับการส่งออกเอกสารพรีเซนเทชันเป็นเอกสาร TIFF ผ่าน Aspose.Slides for Java ได้ที่ [Convert PowerPoint Presentations to TIFF](/slides/th/java/convert-powerpoint-to-tiff/).
