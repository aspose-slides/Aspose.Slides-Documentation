{{% alert color="info" title="Note" %}}
[PPT](https://en.wikipedia.org/wiki/Microsoft_PowerPoint) คือรูปแบบไฟล์เอกสารนำเสนอที่สามารถสร้าง, อ่าน, แก้ไขและเขียนโดยเวอร์ชันต่าง ๆ ของ Microsoft PowerPoint นี่เป็นรูปแบบไบนารีสำหรับเอกสารนำเสนอที่พัฒนาโดย Microsoft.
{{% /alert %}}

## **PPT ใน Aspose.Slides for Java**
Aspose.Slides for Java สามารถอ่านไฟล์ PPT ที่สร้างจากซอฟต์แวร์ที่ระบุด้านล่างนี้

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003

เช่นเดียวกันไฟล์ PPT ที่สร้างโดย Aspose.Slides for Java สามารถอ่านได้โดยซอฟต์แวร์ชุดข้างต้น

## **การสนับสนุนที่ครอบคลุมสำหรับ PPT**
Aspose.Slides for Java ให้การสนับสนุนเกือบทุกคุณลักษณะที่รูปแบบไฟล์เอกสาร PPT รองรับ ไม่เพียงแต่ครอบคลุมคุณลักษณะพื้นฐานและขั้นสูงที่เวอร์ชันต่าง ๆ ของ Microsoft PowerPoint ให้สำหรับการจัดการเอกสาร PPT เท่านั้น แต่ยังรวมถึงคุณลักษณะที่แม้ Microsoft PowerPoint จะไม่รองรับด้วย ความได้เปรียบหลักของการใช้ไลบรารี Aspose.Slides for Java API คือความง่ายในการจัดการคุณลักษณะเหล่านี้

นอกเหนือจากงานพื้นฐานที่เกี่ยวกับการสร้าง, อ่านและเขียนไฟล์เอกสาร PPT แล้ว ยังมีคุณลักษณะหลายอย่างที่ Aspose.Slides for Java มีให้:

- นำเข้ารูปแบบไฟล์ Microsoft Office อื่นเป็น [OLE objects into PPT documents](/slides/th/java/manage-ole/).
- [Export PPT documents to PDF](/slides/th/java/convert-powerpoint-to-pdf/).
- ส่งออกสไลด์ในเอกสาร PPT ไปเป็นรูปแบบ SVG.
- เรนเดอร์สไลด์เป็นรูปแบบภาพใด ๆ ที่ Java Framework รองรับ.
- กำหนดขนาดของสไลด์ในเอกสาร PPT.
- จัดการแอนิเมชันบนรูปร่าง.
- จัดการการแสดงสไลด์.
- [Format text on slides](/slides/th/java/text-formatting/).
- ดึงข้อความจากเอกสาร PPT.
- [Handle tables on slides](/slides/th/java/powerpoint-table/).
- คัดลอกมาสเตอร์โดยอัตโนมัติด้วย [the cloning feature](/slides/th/java/clone-slides/).
