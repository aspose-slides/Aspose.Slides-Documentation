การแปลง PPT เป็น PPTX ได้รับการสนับสนุนจาก Aspose.Slides for Java. คุณลักษณะส่วนใหญ่ของงานนำเสนอ - สไลด์แม่, โครงสร้าง ฯลฯ - จะถูกเก็บรักษาไว้เมื่อแปลงจากรูปแบบหนึ่งเป็นอีกรูปแบบหนึ่ง, แต่มี [ข้อจำกัดบางประการ](/slides/th/java/ppt-to-pptx-conversion/).

{{% /alert %}} 
## **คุณสมบัติที่รองรับในการแปลง**
Aspose.Slides for Java มีการสนับสนุนบางส่วนสำหรับการแปลงรูปแบบไฟล์ PPT ไปเป็น PPTX. การสนับสนุนการแปลงเพิ่งถูกแนะนำใน Aspose.Slides for Java, ดังนั้นจึงมีข้อจำกัดบางประการและทำงานได้ดีที่สุดกับงานนำเสนอที่เรียบง่าย. ความได้เปรียบหลักที่ Aspose.Slides for Java ให้เมื่อแปลง PPT เป็น PPTX คือความง่ายในการใช้ API. เพื่อดูตัวอย่างโค้ด, อ่านเกี่ยวกับ [การแปลง PPT เป็น PPTX](). ด้านล่างนี้รายการอธิบายว่าคุณสมบัติใดที่ได้รับการสนับสนุนและคุณสมบัติใดที่ไม่รองรับสำหรับการแปลง PPT เป็น PPTX.

## **คุณสมบัติที่รองรับ**
คุณลักษณะต่อไปนี้ได้รับการสนับสนุนสำหรับการแปลง:

- การแปลงโครงสร้างของมาสเตอร์, เลย์เอาต์และสไลด์.
- การแปลงแผนภูมิ.
- รูปร่างเป็นกลุ่ม.
- การแปลงออโต้เชปรวมถึงสี่เหลี่ยมผืนผ้าและวงรี. 
- รูปร่างที่มีเรขาคณิตที่กำหนดเอง.
- สไตล์การเติมพื้นผิวและรูปภาพสำหรับออโต้เชป.
- การแปลงตำแหน่งเก็บไว้.
- การแปลงเส้นและโพลีไลน์.
- รูปแบบเส้นและการเติม.
- สไตล์การเติมไล่สี.
- เฟรม OLE, ตาราง, เฟรมวิดีโอและเสียง ฯลฯ.
- คุณสมบัติการเคลื่อนไหวและการแสดงสไลด์โชว์.
- การแปลงข้อความในเฟรมข้อความและตัวเก็บข้อความ.
