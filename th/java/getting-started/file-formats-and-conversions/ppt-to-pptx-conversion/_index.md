การแปลงจาก PPT เป็น PPTX ได้รับการสนับสนุนจาก Aspose.Slides for Java คุณลักษณะส่วนใหญ่ของการนำเสนอ - สไลด์มาสเตอร์, โครงสร้างและอื่น ๆ - จะถูกเก็บไว้เมื่อนำไปแปลงจากรูปแบบหนึ่งเป็นอีกรูปแบบหนึ่ง แต่มีข้อจำกัดบางประการ

## **คุณสมบัติที่รองรับในการแปลง**
Aspose.Slides for Java ให้การสนับสนุนบางส่วนสำหรับการแปลงรูปแบบไฟล์ PPT ไปเป็น PPTX การสนับสนุนการแปลงเพิ่งได้รับการนำเสนอใน Aspose.Slides for Java ดังนั้นจึงมีข้อจำกัดอยู่บ้างและทำงานดีที่สุดสำหรับการนำเสนอที่เรียบง่าย ข้อได้เปรียบหลักที่ Aspose.Slides for Java ให้เมื่อแปลง PPT เป็น PPTX คือ API ที่ง่ายต่อการใช้งาน หากต้องการดูตัวอย่างโค้ด ดูที่ [แปลง PPT เป็น PPTX](/slides/th/java/convert-ppt-to-pptx/). รายการด้านล่างแสดงคุณสมบัติที่รองรับสำหรับการแปลง PPT เป็น PPTX.

## **คุณสมบัติที่รองรับ**
คุณสมบัติดังต่อไปนี้ได้รับการสนับสนุนสำหรับการแปลง:

- การแปลงโครงสร้างของมาสเตอร์, เลย์เอาต์และสไลด์
- การแปลงแผนภูมิ
- กลุ่มรูปร่าง
- การแปลงรูปร่างอัตโนมัติรวมถึงสี่เหลี่ยมและวงรี
- รูปร่างที่มีเรขาคณิตที่กำหนดเอง
- พื้นผิวและสไตล์การเติมรูปภาพสำหรับรูปร่างอัตโนมัติ
- การแปลง placeholder
- การแปลงเส้นและโพลีไลน์
- รูปแบบเส้นและการเติม
- สไตล์การเติมแบบไล่สี
- เฟรม OLE, ตาราง, เฟรมวิดีโอและเสียง ฯลฯ
- คุณสมบัติของการเคลื่อนไหวและการนำเสนอแบบสไลด์โชว์
- การแปลงข้อความในกรอบข้อความและตัวเก็บข้อความ
