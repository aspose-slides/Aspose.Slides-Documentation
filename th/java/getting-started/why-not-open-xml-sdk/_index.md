## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดนักพัฒนาจะเลือกใช้ Open XML SDK หรือ Aspose.Slides ในการทำงานกับเอกสารงานนำเสนอ โดยอธิบายว่า Open XML SDK คือไลบรารีสำหรับจัดการแพ็กเกจ OOXML และองค์ประกอบ XML ที่เป็นพื้นฐานของแพ็กเกจเหล่านั้น ในขณะที่ Aspose.Slides ถูกนำเสนอเป็นไลบรารีการประมวลผลงานนำเสนอที่มีโมเดลอ็อบเจ็กต์ระดับสูงและรองรับงานหลายอย่างที่เกี่ยวกับ PowerPoint

บทความเปรียบเทียบทั้งสองตัวเลือกตามรูปแบบที่สนับสนุน, โมเดลการเขียนโปรแกรม, ความสามารถในการเรนเดอร์และพิมพ์, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้งานทั่วไป อีกทั้งยังชี้แจงว่า Open XML SDK อาจเหมาะกับการดำเนินการพื้นฐานบน PPTX หรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ส่วน Aspose.Slides จะเหมาะกับงานนำเสนอที่ซับซ้อน เช่น การทำงานกับรูปแบบ PowerPoint หลายรูปแบบ, การคัดลอกหรือทำสำเนา shape, การแทนที่ข้อความ, การใส่แอนิเมชัน, และการแปลงงานนำเสนอเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
ตามข้อมูลจาก [ห้องสมุด MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK ถูกกำหนดว่า:

Open XML SDK 2.0 ทำให้การจัดการแพ็กเกจ Open XML และองค์ประกอบสกีมา Open XML ที่อยู่ภายในแพ็กเกจเป็นเรื่องง่ายขึ้น Open XML SDK 2.0 รวมงานทั่วไปหลายอย่างที่นักพัฒนามักทำบนแพ็กเกจ Open XML ไว้ด้วย ทำให้คุณสามารถดำเนินการที่ซับซ้อนได้ด้วยเพียงไม่กี่บรรทัดของโค้ด

เอกสาร OOXML เป็นไฟล์ XML ที่บีบอัดเป็น zip และ Open XML SDK เป็นชุดคลาสที่ช่วยให้คุณทำงานกับเนื้อหาเอกสาร OOXML ได้ในรูปแบบที่มีการระบุประเภทอย่างชัดเจน กล่าวคือ แทนการแตกไฟล์เพื่อดึง XML, โหลด XML นั้นเข้าไปในโครงสร้าง DOM แล้วทำงานกับองค์ประกอบและแ атทริบิวต์ของ XML โดยตรง Open XML SDK มีคลาสที่ทำสิ่งเหล่านั้นให้คุณ

## **Aspose.Slides คืออะไร?**
Aspose.Slides เป็นคลาสไลบรารีที่ช่วยให้แอปพลิเคชันของคุณทำงานประมวลผลงานนำเสนอได้ดังต่อไปนี้

- การเขียนโปรแกรมด้วยโมเดลอ็อบเจ็กต์ **Presentation**
- การแปลงคุณภาพสูงระหว่างรูปแบบงานนำเสนอ PowerPoint ที่นิยมทั้งหมด รวมถึงการแปลงเป็น PDF, XPS และ TIFF
- ความสามารถในการสร้างภาพย่อของสไลด์ในรูปแบบที่รู้จักกันดี เช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG
- ความสามารถในการสร้างงานนำเสนอจากศูนย์หรือโดยการรวมจากเอกสารหนึ่งหรือหลายเอกสาร
- รองรับการเพิ่มแอนิเมชัน, Ole Frames, ตาราง, การสร้างและจัดการแผนภูมิ
- ให้การควบคุมอย่างละเอียดสำหรับการจัดการรูปแบบข้อความบน TextFrames, Paragraphs และ Portions

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับคุณสมบัติที่สนับสนุน โปรดเยี่ยมชม [คุณสมบัติของ Aspose.Slides](/slides/th/java/product-overview/)

## **สรุป**
{{% alert color="info" %}} 

Open XML SDK และ Aspose.Slides ไม่ได้แข่งขันกันโดยตรงเนื่องจากตอบสนองต่อความต้องการและกลุ่มผู้ใช้ที่แตกต่างกัน Open XML SDK เป็นไลบรารีคลาสที่ให้วิธีการทำงานกับเอกสาร OOXML อย่างมีการระบุประเภทอย่างชัดเจน ส่วน Aspose.Slides เป็นไลบรารีการประมวลผลงานนำเสนอที่มีประโยชน์อย่างยิ่งและให้การสนับสนุนที่ดีสำหรับเกือบทุกรูปแบบไฟล์ Microsoft PowerPoint ทั้งหมด

หากสิ่งที่คุณต้องการทำคือการดำเนินการโปรแกรมพื้นฐานบนเอกสาร PPTX Open XML SDK อาจเป็นตัวเลือกที่เหมาะสม ด้วย Open XML SDK คุณจะทำงานง่ายๆ เช่น สร้างเอกสาร PPTX อย่างง่าย, ลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, ดึงภาพออก หรืออื่นๆ ได้อย่างสบายใจ งานบางอย่างทำได้ด้วย Open XML SDK แต่ทำไม่ได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบและแอททริบิวต์ XML ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK อย่างไรก็ตาม หากคุณต้องการดำเนินการที่ซับซ้อนบนเอกสาร เช่น งานต่อไปนี้ การใช้ Aspose.Slides จะเป็นตัวเลือกที่ดีที่สุด:

- รองรับรูปแบบ PowerPoint รุ่นเก่าเพิ่มเติมจาก PPTX
- คัดลอกหรือทำสำเนา shape ภายในสไลด์โดยผสานวัตถุ, สไตล์และการจัดรูปแบบอื่นๆ อย่างเหมาะสม
- แทนที่ข้อความที่มีการจัดรูปแบบหรือไม่มีการจัดรูปแบบ
- ใส่แอนิเมชันและใช้ตัวเชื่อมต่อกับ shape
- แปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้ได้รูปแบบที่เหมือนกับที่ Microsoft PowerPoint แปลง
- พัฒนาแอปพลิเคชัน .NET หรือ Java ในสภาพแวดล้อมเดสก์ท็อปและเว็บ
