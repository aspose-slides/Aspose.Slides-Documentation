## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดที่นักพัฒนาอาจเลือกใช้ Open XML SDK หรือ Aspose.Slides สำหรับการทำงานกับไฟล์งานนำเสนอ โดยอธิบายว่า Open XML SDK เป็นไลบรารีสำหรับจัดการแพ็คเกจ OOXML และองค์ประกอบ XML พื้นฐานของมัน ส่วน Aspose.Slides ถูกนำเสนอเป็นไลบรารีการประมวลผลงานนำเสนอที่มีโมเดลวัตถุระดับสูงและรองรับงานหลายอย่างที่เกี่ยวข้องกับ PowerPoint

บทความเปรียบเทียบทั้งสองตัวเลือกโดยพิจารณาจากรูปแบบที่รองรับ, โมเดลการเขียนโปรแกรม, การแสดงผล, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้งานทั่วไป พร้อมระบุว่ามีเหตุผลใดที่ Open XML SDK เหมาะกับการทำงานพื้นฐานกับ PPTX หรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ในขณะที่ Aspose.Slides เหมาะกับงานนำเสนอที่ซับซ้อน เช่น การทำงานกับหลายรูปแบบ PowerPoint, การคัดลอกหรือทำสำเนา Shape, การแทนที่ข้อความ, การใส่แอนิเมชัน, และการแปลงงานนำเสนอเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
ตามข้อมูลจาก[คลังข้อมูล MSDN](https://learn.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK ถูกกำหนดว่า:

Open XML SDK 2.0 ทำให้การจัดการแพ็คเกจ Open XML และองค์ประกอบสคีม่า Open XML ภายในแพ็คเกจง่ายขึ้น โดย Open XML SDK 2.0 รวมงานทั่วไปหลายอย่างที่นักพัฒนาทำกับแพ็คเกจ Open XML ไว้ เพื่อให้คุณสามารถทำงานที่ซับซ้อนได้ด้วยไม่กี่บรรทัดของโค้ด

เอกสาร OOXML คือไฟล์ XML ที่บีบอัดเป็น zip และ Open XML SDK คือชุดคลาสที่ให้คุณทำงานกับเนื้อหาเอกสาร OOXML ในรูปแบบที่มีชนิดข้อมูลที่ชัดเจน แทนการแตกไฟล์เพื่อดึง XML, โหลด XML ไปยัง DOM tree และทำงานกับองค์ประกอบและแอตริบิวต์ XML โดยตรง Open XML SDK จะให้คลาสทำสิ่งเหล่านั้นแทน

## **Aspose.Slides คืออะไร?**
Aspose.Slides เป็นไลบรารีคลาสที่ทำให้แอปพลิเคชันของคุณสามารถทำงานประมวลผลงานนำเสนอได้ต่อไปนี้

- การเขียนโปรแกรมด้วยโมเดลวัตถุ **Presentation**
- การแปลงคุณภาพสูงระหว่างรูปแบบงานนำเสนอ PowerPoint ที่นิยมทั้งหมด รวมถึงการแปลงเป็น PDF, XPS และ TIFF
- ความสามารถในการสร้างภาพ thumbnail ของสไลด์ในรูปแบบที่รู้จักกันดี เช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG
- ความสามารถในการสร้างงานนำเสนอจากศูนย์หรือโดยการรวมจากเอกสารหนึ่งหรือหลายเอกสาร
- การสนับสนุนการเพิ่มแอนิเมชัน, Ole Frame, ตาราง, การสร้างและจัดการแผนภูมิ
- ความพร้อมของการควบคุมอย่างละเอียดสำหรับการจัดการรูปแบบข้อความบน TextFrames, Paragraphs และ Portions

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับคุณสมบัติที่รองรับ โปรดเยี่ยมชม[คุณสมบัติของ Aspose.Slides](/slides/th/java/product-overview/)

## **สรุป**
{{% alert color="info" title="Note" %}}

Open XML SDK และ Aspose.Slides ไม่ได้แข่งขันกันโดยตรง เนื่องจากตอบสนองต่อความต้องการและกลุ่มผู้ใช้ที่แตกต่างกัน Open XML SDK เป็นไลบรารีคลาสที่ให้วิธีการทำงานกับเอกสาร OOXML ในรูปแบบที่มีชนิดข้อมูลที่ชัดเจน ส่วน Aspose.Slides เป็นไลบรารีการประมวลผลงานนำเสนอที่มีประโยชน์อย่างมากและรองรับไฟล์รูปแบบ Microsoft PowerPoint ทั้งหมด

หากสิ่งที่คุณต้องการทำคือการเขียนโปรแกรมพื้นฐานบนเอกสาร PPTX เพียงเล็กน้อย Open XML SDK อาจเป็นตัวเลือกที่เหมาะสม ด้วย Open XML SDK คุณจะสะดวกในการทำงานง่าย ๆ เช่น การสร้างเอกสาร PPTX อย่างง่าย, การลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การดึงภาพออก หรืออื่น ๆ งานบางอย่างทำได้ด้วย Open XML SDK แต่ไม่สามารถทำได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบและแอตริบิวต์ XML ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK อย่างไรก็ตาม หากคุณต้องการทำงานที่ซับซ้อนบนเอกสาร ได้แก่ งานต่อไปนี้ การใช้ Aspose.Slides จะเป็นทางเลือกที่ดีที่สุด

- รองรับรูปแบบ PowerPoint เก่าเพิ่มเติมนอกเหนือจาก PPTX
- คัดลอกหรือทำสำเนา Shape ภายในสไลด์ด้วยวิธีที่รวมวัตถุ, สไตล์และการจัดรูปแบบอื่น ๆ อย่างเหมาะสม
- แทนที่ข้อความที่มีหรือไม่มีการจัดรูปแบบ
- ใส่แอนิเมชันและใช้ตัวเชื่อมต่อกับ Shape
- แปลงเอกสารเป็น PDF, TIFF หรือ XPS ให้แสดงผลเหมือนที่ Microsoft PowerPoint ทำการแปลง
- พัฒนาแอปพลิเคชัน .NET หรือ Java ทั้งในสภาพแวดล้อมเดสก์ท็อปและเว็บ
