## **ภาพรวม**

บทความนี้อธิบายว่าเมื่อใดนักพัฒนอาจเลือกใช้ Open XML SDK หรือ Aspose.Slides สำหรับการทำงานกับเอกสารพรีเซนเทชัน โดยอธิบาย Open XML SDK ว่าเป็นไลบรารีสำหรับจัดการแพ็กเกจ OOXML และองค์ประกอบ XML ที่อยู่ภายใต้ ในขณะที่ Aspose.Slides นำเสนอเป็นไลบรารีการประมวลผลพรีเซนเทชันที่มีโมเดลอ็อบเจ็กต์ระดับสูงและรองรับงานที่เกี่ยวกับ PowerPoint มากมาย

บทความเปรียบเทียบตัวเลือกทั้งสองตามรูปแบบที่รองรับ, โมเดลการเขียนโปรแกรม, การเรนเดอร์, การสนับสนุนแพลตฟอร์ม, และกรณีการใช้งานทั่วไป อีกทั้งยังชี้ให้เห็นว่า Open XML SDK อาจเหมาะสำหรับการดำเนินการพื้นฐานบนไฟล์ PPTX หรือการเข้าถึงองค์ประกอบ OOXML โดยตรง ในขณะที่ Aspose.Slides จะเหมาะกับงานพรีเซนเทชันที่ซับซ้อน เช่น การทำงานกับหลายรูปแบบ PowerPoint, การคัดลอมหรือทำสำเนา shapes, การแทนที่ข้อความ, การใช้เอฟเฟกต์แอนิเมชัน, และการแปลงพรีเซนเทชันเป็น PDF, TIFF หรือ XPS

## **Open XML SDK คืออะไร?**
ตามที่อธิบายใน [ห้องสมุด MSDN](https://docs.microsoft.com/en-us/office/open-xml/open-xml-sdk) Open XML SDK ถูกกำหนดว่า: 

Open XML SDK 2.0 ทำให้การจัดการแพ็กเกจ Open XML และองค์ประกอบสคีม่า Open XML ที่อยู่ภายในแพ็กเกจง่ายขึ้น SDK นี้รวมเอางานทั่วไปหลายอย่างที่นักพัฒนาทำบนแพ็กเกจ Open XML ไว้ไว้ ทำให้คุณสามารถทำการดำเนินการที่ซับซ้อนได้ด้วยเพียงไม่กี่บรรทัดของโค้ด

เอกสาร OOXML คือไฟล์ XML ที่บีบอัดเป็นรูปแบบ zip และ Open XML SDK เป็นชุดคลาสที่ช่วยให้คุณทำงานกับเนื้อหาในเอกสาร OOXML ด้วยรูปแบบที่มีการกำหนดชนิดอย่างเข้มงวด ซึ่งแทนการคลาย zip เพื่อนำ XML ออกมา, โหลด XML นั้นเข้าสู่โครงสร้าง DOM แล้วทำงานกับองค์ประกอบและแอตริบิวต์ XML โดยตรง, Open XML SDK จะให้คลาสที่ทำเช่นนั้นให้คุณ

## **Aspose.Slides คืออะไร?**
Aspose.Slides เป็นไลบรารีคลาสที่ทำให้แอปพลิเคชันของคุณสามารถดำเนินการประมวลผลพรีเซนเทชันต่อไปนี้:

- การเขียนโปรแกรมด้วยโมเดลอ็อบเจ็กต์ **Presentation**.
- การแปลงคุณภาพสูงระหว่างรูปแบบพรีเซนเทชัน PowerPoint ที่สนับสนุนทั้งหมด รวมถึงการแปลงเป็น PDF, XPS และ TIFF.
- ความสามารถในการสร้างภาพย่อสไลด์ในรูปแบบที่เป็นที่รู้จัก เช่น PNG, JPEG และ BMP พร้อมการส่งออกสไลด์เป็น SVG.
- ความสามารถในการสร้างพรีเซนเทชันตั้งแต่ศูนย์หรือโดยการรวมจากเอกสารหนึ่งหรือหลายฉบับ.
- สนับสนุนการเพิ่มแอนิเมชัน, Ole Frames, ตาราง, การสร้างและจัดการแผนภูมิ.
- มีการควบคุมอย่างละเอียดสำหรับการจัดการรูปแบบข้อความบน TextFrames, Paragraphs และ Portions.

สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับคุณสมบัติที่สนับสนุน โปรดเยี่ยมชม [คุณสมบัติของ Aspose.Slides](/slides/th/java/product-overview/).

## **สรุป**
{{% alert color="info" %}} 

Open XML SDK และ Aspose.Slides ไม่แข่งขันกันโดยตรงเพราะพวกมันตอบสนองต่อความต้องการและกลุ่มผู้ใช้ที่แตกต่างกันอย่างมาก Open XML SDK เป็นไลบรารีคลาสที่ให้วิธีการทำงานกับเอกสาร OOXML อย่างมีการกำหนดชนิดอย่างเข้มงวด Aspose.Slides เป็นไลบรารีการประมวลผลพรีเซนเทชันที่มีประโยชน์อย่างยิ่งซึ่งให้การสนับสนุนที่ดีสำหรับรูปแบบไฟล์ Microsoft PowerPoint เกือบทั้งหมด

หากสิ่งที่คุณต้องการทำเป็นการดำเนินการการเขียนโปรแกรมพื้นฐานบนเอกสาร PPTX เท่านั้น Open XML SDK อาจเป็นตัวเลือกที่เหมาะสม ด้วย Open XML SDK คุณจะคุ้นเคยกับงานง่าย ๆ เช่น การสร้างเอกสาร PPTX อย่างง่าย หรือการลบคอมเมนต์, ส่วนหัว/ส่วนท้าย, การสกัดภาพ หรืออื่น ๆ งานบางอย่างทำได้ด้วย Open XML SDK แต่ทำไม่ได้ด้วย Aspose.Slides ตัวอย่างเช่น หากคุณต้องการเข้าถึงองค์ประกอบและแอตริบิวต์ XML ของเอกสาร OOXML โดยตรง คุณควรใช้ Open XML SDK อย่างไรก็ตาม หากคุณต้องการทำการดำเนินการซับซ้อนบนเอกสาร เช่น งานต่อไปนี้ การใช้ Aspose.Slides จะเป็นทางเลือกที่ดีที่สุดของคุณ:

- รองรับรูปแบบ PowerPoint รุ่นเก่านอกเหนือจาก PPTX
- คัดลอมหรือทำสำเนา shapes ภายในสไลด์ในลักษณะที่รวมวัตถุ, สไตล์ และการจัดรูปแบบอื่น ๆ อย่างเหมาะสม
- แทนที่ข้อความที่มีรูปแบบหรือไม่มีรูปแบบ
- ใช้แอนิเมชันและการเชื่อมต่อต่าง ๆ กับ shapes
- แปลงเอกสารเป็น PDF, TIFF หรือ XPS เพื่อให้แสดงผลเหมือนกับที่ Microsoft PowerPoint จะแปลง
- พัฒนาแอปพลิเคชัน .NET หรือ Java ในสภาพแวดล้อมเดสก์ท็อปและเว็บ
