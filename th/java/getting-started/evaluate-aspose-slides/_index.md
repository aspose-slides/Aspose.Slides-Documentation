## **การประเมิน Aspose.Slides**

คุณสามารถดาวน์โหลด Aspose.Slides เพื่อตรวจสอบได้ การดาวน์โหลดเพื่อประเมินมีลักษณะเดียวกับการดาวน์โหลดที่ซื้อ; จะได้รับใบอนุญาตหลังจากคุณเพิ่มบรรทัดโค้ดบางบรรทัดเพื่อใช้ใบอนุญาต

หากไม่มีใบอนุญาต Aspose.Slides จะให้ฟังก์ชันเต็มในโหมดการประเมินโดยมีข้อจำกัดสองประการ: จะเพิ่มกล่องข้อความลายน้ำการประเมินลงในสไลด์ทุกสไลด์ของแต่ละงานนำเสนอที่บันทึก และข้อความที่โค้ดของคุณอ่านผ่าน API รวมถึงข้อความที่เพิ่งตั้งค่าไว้ จะถูกตัดให้เหลือเพียงไม่กี่ตัวอักษรแรกตามด้วยข้อความแจ้งข้อจำกัดการประเมิน ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกเต็มรูปแบบ วิธี [getPresentationText](https://reference.aspose.com/slides/th/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) ซึ่งสกัดข้อความโดยไม่ต้องโหลดงานนำเสนอทั้งหมด จะคืนเพียงข้อความแจ้งการประเมินและไม่มีข้อความของสไลด์ใด ๆ

## **FAQ**

### สามารถทดสอบงานนำเสนอหลายไฟล์พร้อมกันในเธรดต่าง ๆ ในโหมดการประเมินได้หรือไม่?

ใช่ คุณสามารถประมวลผลเอกสารต่าง ๆ ได้พร้อมกัน; ไม่ควรแชร์ออบเจกต์งานนำเสนอเดียวกัน [ข้ามเธรด](/slides/th/java/multithreading/) โหมดการประเมินไม่ส่งผลต่อเรื่องนี้

### จำเป็นต้องติดตั้ง Microsoft PowerPoint เพื่อประเมินไลบรารีบนเซิร์ฟเวอร์หรือใน CI หรือไม่?

ไม่ Aspose.Slides เป็นเอนจิ้นแบบสแตนด์อโลนและไม่ต้องการ PowerPoint ติดตั้ง ไม่ว่าจะเป็นการประเมินหรือการใช้งานจริง

### สามารถทดสอบการแปลง PPT/PPTX เป็น PDF และรูปภาพอย่างเต็มที่ในโหมดการประเมินได้หรือไม่?

ใช่ [ตัวแปลง](/slides/th/java/convert-presentation/) ทำงาน; ผลลัพธ์จะรวมลายน้ำ

### สามารถใช้ใบอนุญาตชั่วคราวสำหรับการทดสอบโหลดโดยไม่มีลายน้ำได้หรือไม่?

ใช่ ใบอนุญาตชั่วคราว 30 วันจะลบข้อจำกัดของโหมดการประเมินและอนุญาตให้ทดสอบโดยไม่มีลายน้ำ
