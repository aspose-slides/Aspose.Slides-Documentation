## **การประเมิน Aspose.Slides**

คุณสามารถดาวน์โหลด Aspose.Slides เพื่อการประเมินได้ การดาวน์โหลดเพื่อการประเมินเหมือนกับการดาวน์โหลดที่ซื้อไว้; จะได้รับใบอนุญาตหลังจากคุณเพิ่มโค้ดไม่กี่บรรทัดเพื่อใช้งานใบอนุญาต

หากไม่มีใบอนุญาต Aspose.Slides จะให้ฟังก์ชันการทำงานเต็มรูปแบบในโหมดการประเมิน โดยมีข้อจำกัดสองข้อ: จะเพิ่มกล่องข้อความลายน้ำการประเมินให้กับแต่ละสไลด์ของทุกการนำเสนอที่บันทึก, และข้อความที่โค้ดของคุณอ่านผ่าน API รวมถึงข้อความที่เพิ่งตั้งค่าไว้ จะถูกตัดให้เหลือไม่กี่อักขระแรกตามด้วยประกาศเกี่ยวกับข้อจำกัดการประเมิน ข้อความที่โค้ดของคุณเขียนจะถูกบันทึกอย่างเต็มที่ วิธีการ [getPresentationText](https://reference.aspose.com/slides/th/java/com.aspose.slides/presentationfactory/#getPresentationText-java.lang.String-int-) ซึ่งดึงข้อความโดยไม่ต้องโหลดการนำเสนอทั้งหมด จะคืนค่าประกาศการประเมินเท่านั้นและไม่มีข้อความสไลด์

## **คำถามที่พบบ่อย**

### ฉันสามารถทดสอบการนำเสนอหลายไฟล์พร้อมกันในหลายเธรดในโหมดการประเมินได้หรือไม่?

ใช่ คุณสามารถประมวลผลเอกสารต่าง ๆ พร้อมกันได้; ควรไม่แชร์ออบเจ็กต์การนำเสนอเดียวกัน [ข้ามเธรด](/slides/th/java/multithreading/). โหมดการประเมินไม่ส่งผลต่อสิ่งนี้

### ฉันจำเป็นต้องติดตั้ง Microsoft PowerPoint เพื่อประเมินไลบรารีบนเซิร์ฟเวอร์หรือใน CI หรือไม่?

ไม่ Aspose.Slides เป็นเอนจินแบบสแตนด์อโลนและไม่ต้องการ PowerPoint ติดตั้ง ไม่ว่าจะเป็นการประเมินหรือการใช้งานจริง

### ฉันสามารถทดสอบการแปลงไฟล์ PPT/PPTX เป็น PDF และภาพอย่างสมบูรณ์ในโหมดการประเมินได้หรือไม่?

ใช่ [ตัวแปลง](/slides/th/java/convert-presentation/) ทำงาน; ผลลัพธ์จะรวมลายน้ำ

### ฉันสามารถใช้ใบอนุญาตชั่วคราวสำหรับการทดสอบโหลดโดยไม่มีลายน้ำได้หรือไม่?

ใช่ ใบอนุญาตชั่วคราวระยะเวลา 30 วันจะยกเลิกข้อจำกัดของโหมดการประเมินและอนุญาตให้ทดสอบโดยไม่มีลายน้ำ
