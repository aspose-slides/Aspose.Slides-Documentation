{{% alert color="info" title="Note" %}}

นี่เป็นหน้าประวัติศาสตร์ ซึ่งอธิบายบั๊กใน Aspose.Slides for Java รุ่น 23.2 ถึง 23.7 ซึ่งเปิดตัวในปี 2023 และรุ่นที่ได้แก้ไขบั๊กนี้ หน้าไม่ได้อธิบายรุ่นปัจจุบัน สำหรับการจัดการลิขสิทธิ์ในรุ่นปัจจุบัน ดูที่ [Licensing](/slides/th/java/licensing/).

{{% /alert %}}

## **Overview**

บทความนี้อธิบายบั๊กการจัดการลิขสิทธิ์ที่พบใน Aspose.Slides for Java รุ่น 23.2, 23.3, 23.4, 23.5, 23.6 และ 23.7 บั๊กนี้ทำให้ลิขสิทธิ์ถาวรไม่สามารถใช้งานได้ชั่วคราวหลังจากการสมัครสมาชิกหมดอายุ

## **Symptoms**

หลังจากการสมัครสมาชิกลิขสิทธิ์ถาวรของคุณหมดอายุ Aspose.Slides for Java รุ่น 23.2 - 23.7 อาจรายงานว่าลิขสิทธิ์หมดอายุ และทำให้ฟังก์ชันทั้งหมดเข้าสู่โหมดประเมินผล พฤติกรรมนี้ไม่ถูกต้องและไม่ได้ส่งผลต่อรุ่นก่อนหน้า 23.2 หรือหลังจาก 23.7

## **Resolution**

Aspose.Slides for Java ได้แก้ไขปัญหานี้และปล่อยเวอร์ชันอัปเดต (23.2.1, 23.3.1, 23.4.1, 23.5.1, 23.6.1, 23.7.1) พร้อมการแก้ไข

หากคุณกำลังใช้หนึ่งในรุ่นที่ได้รับผลกระทบของ Aspose.Slides for Java ในโครงการของคุณ โปรดเปลี่ยนไปใช้รุ่นที่ได้รับการแก้ไข

หากคุณพบปัญหาการจัดการลิขสิทธิ์ใด ๆ กับ Aspose.Slides for Java:

- ตรวจสอบรุ่นที่คุณใช้งานและให้แน่ใจว่าไม่ได้รับผลกระทบจากบั๊กที่อธิบายข้างต้น
- ดูที่ [Licensing](/slides/th/java/licensing/) เพื่อทราบวิธีการใช้และตรวจสอบลิขสิทธิ์
- ติดต่อ [Aspose support](https://forum.aspose.com/c/slides/th/11) เพื่อขอความช่วยเหลือเพิ่มเติม

## **Affected products and versions**

โปรดทราบว่าบั๊กนี้มีผลเฉพาะกับ Aspose.Slides for Java รุ่น 23.2 ถึง 23.7 เท่านั้น **ผลิตภัณฑ์ Aspose อื่น ๆ และรุ่นอื่น ๆ ของ Aspose.Slides จะไม่ได้รับผลกระทบ**.
