## **ภาพรวม**

Aspose.Slides for Java เป็นไลบรารีคลาสสำหรับสร้าง, อ่าน, แก้ไข, แปลง และเรนเดอร์งานนำเสนอ PowerPoint และ OpenDocument มันไม่มีส่วนติดต่อผู้ใช้ของตนเองและไม่ต้องการ Microsoft PowerPoint หรือ Microsoft Office บทความนี้สรุปสิ่งที่ไลบรารีครอบคลุมและลิงก์ไปยังบทความที่อธิบายแต่ละด้าน

## **แพลตฟอร์มที่รองรับ**

Aspose.Slides for Java เป็นไฟล์ JAR เดียว, เผยแพร่ใน Maven repository ของ Aspose ด้วย classifier `jdk16` เขียนด้วย Java บริสุทธิ์: JAR ไม่มีไลบรารีเนทีฟและไม่ขึ้นอยู่กับแพ็คเกจอื่น

- **Java:** Java 8 ขึ้นไป Aspose.Slides for Java 26.9 และเวอร์ชันก่อนหน้ายังทำงานบน Java 6 และ 7 ซึ่งเวอร์ชัน 26.10 ไม่รองรับอีกต่อไป; ดู [บันทึกประจำรุ่น 26.9](/slides/th/java/release-notes/2026/aspose-slides-for-java-26-9-release-notes/)
- **ระบบปฏิบัติการ:** ระบบปฏิบัติการใด ๆ ที่มี Java runtime เช่น Windows, Linux, และ macOS บน Linux จำเป็นต้องติดตั้งไลบรารี fontconfig และอย่างน้อยหนึ่งฟอนต์

[การติดตั้ง](/slides/th/java/installation/) แสดงวิธีเพิ่มไลบรารีในโปรเจกต์และรายการข้อกำหนดเบื้องต้นของ Linux [ข้อกำหนดระบบ](/slides/th/java/system-requirements/) รายละเอียดแพลตฟอร์มที่รองรับ

## **รูปแบบไฟล์และการแปลง**

Aspose.Slides เปิดและบันทึกไฟล์ PPT, PPTX, PPS, POT, PPSX, POTX, PPTM, PPSM, POTM, ODP, OTP, FODP, และงานนำเสนอ PowerPoint XML นอกจากนี้ยังนำเข้าเนื้อหา PDF และ HTML ไปยังสไลด์ และบันทึกงานนำเสนอเป็น PDF, XPS, HTML, HTML5, TIFF, GIF เคลื่อนไหว, SWF, Markdown, และ XAML [รูปแบบไฟล์ที่รองรับ](/slides/th/java/supported-file-formats/) แสดงรายการทุกรูปแบบพร้อม API ที่อ่านหรือเขียนได้

| :- | :- |
|[PPT และ PPTX](/slides/th/java/ppt-vs-pptx/)|อ่านและเขียนทั้งรูปแบบ PowerPoint 97-2003 แบบไบนารีและรูปแบบ Office Open XML|

## **การแสดงผลงานนำเสนอ**

Aspose.Slides เรนเดอร์สไลด์และรูปร่างแต่ละอันเป็นภาพ PNG, JPEG, BMP, GIF, TIFF, และ SVG, และเรนเดอร์สไลด์เป็นไฟล์เมตะ EMF ดู [แปลงสไลด์งานนำเสนอเป็นภาพ](/slides/th/java/convert-slide/), [เรนเดอร์สไลด์งานนำเสนอเป็นภาพ SVG](/slides/th/java/render-a-slide-as-an-svg-image/), และ [สร้างรูปย่อของรูปร่างในงานนำเสนอ](/slides/th/java/create-shape-thumbnails/)

## **คำถามที่พบบ่อย**

**จำเป็นต้องติดตั้ง Microsoft PowerPoint บนเซิร์ฟเวอร์หรือ PC เพื่อให้ไลบรารีทำงานหรือไม่?**

ไม่จำเป็น PowerPoint ไม่เป็นข้อกำหนด; Aspose.Slides เป็นเอ็นจิน์อิสระสำหรับการสร้าง, แก้ไข, แปลง, และเรนเดอร์งานนำเสนอ

**การทำงานแบบหลายเธรดทำอย่างไร? สามารถประมวลผลแบบขนานได้หรือไม่?**

การประมวลผลเอกสารต่าง ๆ ในเธรดต่าง ๆ เป็นเรื่องปลอดภัย; ไม่ควรใช้วัตถุ [การนำเสนอ](https://reference.aspose.com/slides/th/java/com.aspose.slides/presentation/) เดียวกันโดย [หลายเธรด](/slides/th/java/multithreading/) พร้อมกัน

**รองรับรหัสผ่านไฟล์และการเข้ารหัสหรือไม่?**

ใช่ คุณสามารถ [เปิด](/slides/th/java/password-protected-presentation/) งานนำเสนอที่เข้ารหัส, ตั้งหรือเอารหัสผ่านสำหรับการเปิดและการเขียนออก, และตรวจสอบสถานะการป้องกัน

**ต้องคำนึงถึงฟอนต์ในคอนเทนเนอร์ Linux หรือไม่?**

ใช่ บน Linux จำเป็นต้องติดตั้งไลบรารี fontconfig และอย่างน้อยหนึ่งฟอนต์, รวมถึงฟอนต์ที่ใช้ในงานนำเสนอของคุณหรือฟอนต์สำรองเพื่อให้ข้อความแสดงผลอย่างถูกต้อง คุณยังสามารถ [ระบุไดเรกทอรีฟอนต์](/slides/th/java/custom-font/) ในแอปพลิเคชันของคุณ ดู [การติดตั้ง](/slides/th/java/installation/#linux)

**มีข้อจำกัดในรุ่นทดลองหรือไม่?**

ใช่ หากไม่มี [ลิขสิทธิ์](/slides/th/java/licensing/) Aspose.Slides จะใส่ลายน้ำการประเมินผลในทุกสไลด์ที่บันทึกและตัดข้อความที่โค้ดของคุณอ่านผ่าน API จะมี [ลิขสิทธิ์ชั่วคราว 30‑วัน](https://purchase.aspose.com/temporary-license/) สำหรับการทดสอบฟีเจอร์ทั้งหมด

**รองรับการนำเข้ารูปแบบภายนอกเข้าสู่การนำเสนอ (PDF หรือ HTML เป็น PPTX) หรือไม่?**

ใช่ คุณสามารถเพิ่ม [หน้า PDF และเนื้อหา HTML](/slides/th/java/import-presentation/) ไปยังงานนำเสนอ ทำให้กลายเป็นสไลด์ได้
