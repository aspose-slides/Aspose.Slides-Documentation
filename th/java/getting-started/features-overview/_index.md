## **แพลตฟอร์มที่รองรับ**
Aspose.Slides for Java รองรับแพลตฟอร์มการพัฒนาและการปรับใช้ที่เป็นที่นิยมมากที่สุด.

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|แอปพลิเคชันเดสก์ท็อป|Aspose.Slides for Java สามารถใช้พัฒนาแอปพลิเคชัน Windows Forms|
|แอปพลิเคชันเว็บระดับองค์กร|การใช้ Aspose.Slides for Java ช่วยสร้างแอปพลิเคชันเว็บที่กำหนดเป้าหมาย. การสนับสนุนการใช้ Aspose.Slides for Java กับ PHP ก็มีให้ด้วย|
|Linux/Unix|Aspose.Slides for Java เป็น API ที่ไม่ขึ้นกับแพลตฟอร์มและสามารถทำงานในสภาพแวดล้อม Linux และ Unix|

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |

|[PresentationML (PPTX, XML)](/slides/th/java/presentationml-pptx-xml/)|Aspose.Slides for Java รองรับการประมวลผลรูปแบบการนำเสนอ OOXML (ที่รู้จักกันในชื่อ PresentationML หรือ PPTX).|

## **การแสดงผลการนำเสนอ**
Aspose.Slides for Java รองรับการเรนเดอร์สไลด์ในงานนำเสนอด้วยความแม่นยำสูงไปยังรูปแบบกราฟิกต่างๆ:

|**คุณลักษณะ**|**คำอธิบาย**|
| :- | :- |
|รูปแบบภาพที่รองรับ|โดยใช้ Aspose.Slides for Java คุณจะสามารถเรนเดอร์ไม่เพียงแค่สไลด์การนำเสนอเท่านั้น แต่ยังรวมถึงภาพบนสไลด์ ไปยังรูปแบบกราฟิกที่ได้รับความนิยมเช่น TIFF, PNG, BMP, JPEG, GIF และเมตาไฟล์.|
|SVG Format|Aspose.Slides for Java มีวิธีการในตัวเพื่อส่งออกสไลด์การนำเสนอเป็นรูปแบบ Scalable Vector Graphics (SVG).|

## **คำถามที่พบบ่อย**

### ฉันจำเป็นต้องติดตั้ง Microsoft PowerPoint บนเซิร์ฟเวอร์/PC เพื่อให้ไลบรารีทำงานไหม?
ไม่. PowerPoint ไม่จำเป็น; Aspose.Slides เป็นเอนจินแบบอิสระสำหรับการสร้าง, แก้ไข, แปลง, และเรนเดอร์การนำเสนอ.

### การทำงานของ multithreading เป็นอย่างไร? สามารถประมวลผลแบบขนานได้หรือไม่?
ปลอดภัยที่จะประมวลผลเอกสารต่างๆ ในเธรดที่ต่างกัน; ไม่ควรใช้วัตถุ [presentation](https://reference.aspose.com/slides/th/java/com.aspose.slides/presentation/) เดียวกันโดย [multiple threads](/slides/th/java/multithreading/) พร้อมกัน.

### รองรับรหัสผ่านไฟล์และการเข้ารหัสหรือไม่?
ใช่. [คุณสามารถ](/slides/th/java/password-protected-presentation/) เปิดการนำเสนอที่เข้ารหัส ตั้งหรือลบรหัสผ่านสำหรับเปิดและเขียน และตรวจสอบสถานะการป้องกัน.

### จำเป็นต้องใส่ใจแพ็กเกจฟอนต์ในคอนเทนเนอร์ Linux หรือไม่?
ใช่. แนะนำให้ติดตั้งแพ็กเกจฟอนต์ทั่วไปและ/หรือระบุ [font directories](/slides/th/java/custom-font/) อย่างชัดเจนในแอปพลิเคชันของคุณเพื่อหลีกเลี่ยงการแทนที่ที่ไม่คาดคิด.

### มีข้อจำกัดในเวอร์ชันประเมินหรือไม่?
ใน [evaluation mode](/slides/th/java/licensing/) จะมีการเพิ่มลายน้ำลงในผลลัพธ์และมีข้อจำกัดบางประการ; มี [ใบอนุญาตชั่วคราว 30 วัน](https://purchase.aspose.com/temporary-license/) สำหรับการทดสอบฟีเจอร์ครบถ้วน.

### รองรับการนำเข้ารูปแบบภายนอกเข้าสู่การนำเสนอ (PDF/HTML → PPTX) หรือไม่?
ใช่. คุณสามารถเพิ่ม [หน้า PDF และเนื้อหา HTML](/slides/th/java/import-presentation/) ไปยังการนำเสนอ ทำให้เป็นสไลด์.
